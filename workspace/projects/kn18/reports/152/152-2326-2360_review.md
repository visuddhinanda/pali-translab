# Review — 152:2326-2360（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§2326、§2333、§2345、§2346、§2351、§2356 标题行无 nissaya，略过）

## 跨段一致性
- **cintayati / cintayitabbaṃ**：§2329 同一句里，蛇的部分译“焦虑”，瑜伽行者的部分译“反省”。比喻靠前后两半同词呼应，换词后对应关系断了。nissaya 两处都是 `စိုးရိမ်၍ ကြံစည်` = 忧虑地思量 → 建议统一为“忧虑”。
- **ūnūdaro**：§2334 译“饿着肚子”，§2336 译“少食”。nissaya 两处都是 `ယုတ်လျော့သောဝမ်းရှိ` = 肚子不满 → 建议统一为“不吃饱／肚子不满”。§2336 是舍利弗偈，正是在呼应 §2334 的蟒蛇比喻。
- **sadattha / sārattha**：§2352 的比喻部分译“自己想要的东西”，合法部分译“自己的利益”；§2353–2354 的 sāratthe 译“真实的利益”。§2352 的引证本来就是为了呼应 sadatthe，nissaya 在 §2353–2354 也按异读 sadatthe 释为 `မိမိအကျိုး` = 自己的利益 → 建议 §2352 两半统一用“自己所求的”，引偈里的译法与之呼应。正文 sāratthe 按原文译，读法分歧记入报告。
- **cittakadharakumma**：§2356、§2357（三处）、§2360 都译“花纹龟”。nissaya 是 `ကုန်းလိပ်ပြောက်` = 有斑点的**陆龟**，“陆龟”正好解释了它为什么怕水、避水 → 建议五处统一为“斑纹陆龟”。
- **sāmañña / parihāna**：§2357 译“沙门的境界”，§2359 只译“退失”。nissaya 两处都补出 `မဂ်ဖိုလ်မှ` = 从道果（退失） → 建议 §2357 改为“沙门果”，两处退失的对象保持一致。

## §2327 句 152-2327-30-66
- **问题**：误读 — vilakkhaṇaṃ / salakkhaṇaṃ 被译成“与之不相应的／与之相应的”，所指不明。nissaya：`ဝိလက္ခဏံ= သဘောလက္ခဏာမမှန်သည်ကို`（不真实的特相【宾格】），`သလက္ခဏံ= ဟုတ်မှန်သောသဘောလက္ခဏာကို`（真实的特相【宾格】）。
- **建议**：改为“避开不真实的特相，修习真实的特相”。
- **问题**：风格（必改）— “以智慧而行”“心行于正理”是半文半白（以、而、于）。nissaya：`စရိတဗ္ဗံ= ကျင့်အပ်၏` = 应当修行。
- **建议**：改为“瑜伽行者应当用智慧来修行；用智慧修行的瑜伽行者，心循着正确的道理运行……”。

## §2328 句 152-2328-2-25
- **问题**：词法 — 合法部分的 caritabbaṃ，nissaya 释为 `ကျင့်အပ်၏` = 应当修行。译文“避开恶行而行”沿用了蛇的“行走”义，“而行”也偏文言。
- **建议**：改为“瑜伽行者应当避开恶行来修行”。

## §2329 句 152-2329-2-51
- **问题**：取词偏重 — kuvitakke 译“邪恶的念头”。nissaya：`မကောင်းသော အကြံအစည်` = 不善的念头。
- **建议**：改为“不善的念头”。
- **备注**：nissaya 把 `so` 释为“那位瑜伽行者”，从语法看 so 应指 divaso。译文取“这一天”，可以保留，不用改。

## §2329 句 152-2329-61-69
- **问题**：句法 — dvinnaṃ kinnarānaṃ，nissaya 作 `ကိန္နရာဖိုမနှစ်ဦးတို့သည်` = 紧那罗雌雄二者【主格】，即下面的偈是这对紧那罗说的话（偈中称呼“猎人啊”也印证了这一点）。译文“讲述两位紧那罗时”没有交代说话的人，也漏了“一雌一雄”。
- **建议**：改为“世尊在《跋拉帝耶本生》中借一对紧那罗夫妇之口也说过：”。

## §2330 句 152-2330-2-22
- **问题**：修饰关系误读 — akāmakā 修饰的是“分离”（不情愿地分离），译文挂到了“思念”上；“彼此……互相”也重复了。nissaya：`အကာမကာ= အလိုမရှိပါကုန်ဘဲ` …… `ဝိပ္ပဝသိမှ= …ဝေးသွေနေကြရကုန်ပြီ`。
- **建议**：改为“猎人啊，我们不情愿地分离了一夜，彼此思念着；”。

## §2336 句 152-2336-2-8
- **问题**：词义 — paribbaje，nissaya 释为 `ကျင့်သုံးရာ၏` = 应当修行、生活。译文“出家游行”过窄。“少食、节制饮食”语义重叠（ūnūdaro 见上文跨段一致性）。
- **建议**：改为“比丘应当不吃饱、饮食有度，保持正念地生活”。

## §2342 句 152-2342-2-8
- **问题**：词义 — peṇāhi 音译为“佩那喜鸟”。nissaya：`အောက်ခြင်းငှက်` = 犀鸟。
- **建议**：改为“犀鸟”，并与本品前面 peṇāhi 那一问的标题和正文译法核对、统一。

## §2347 句 152-2347-32-75
- **问题**：处格丢失 — tattheva 译“当场”。nissaya：`ထိုသတိပဋ္ဌာန်ကွန်ယက်ဗိဘာန်၌သာလျှင်` = 就在那念处网中。
- **建议**：改为“就应当在那里将它们消灭”。

## §2348 句 152-2348-2-11
- **问题**：句法误读 — chasu dvāresu 修饰的是 cittaṃ（在六门中生起的心），约束的落点是念处。译文却把心“约束在六门”。nissaya：`ဆသုဒွါရေသု= ခြောက်ဒွါရတို့၌။ ပဝတ္တံ= ဖြစ်သော။ စိတ္တံ= စိတ်ကို။ သတိပဋ္ဌာနဝရုတ္တမေ= …၌။ နိယမေ= အမြဲစွဲမှတ်ရာ၏`。
- **建议**：改为“应当把在六门中生起的心，牢牢系在最殊胜的念处上；”。

## §2352 句 152-2352-31-64
- **问题**：比喻对应断裂（见上文跨段一致性 sadattha）。另外，合法部分 nissaya 补出了 sadatthe 的所指：`မိမိအလိုဖြစ်သော အရဟတ္တဖိုလ်၌` = 自己所求的阿罗汉果。
- **建议**：比喻部分改为“执著于自己所求的”，合法部分改为“应当执著于自己所求的（阿罗汉果）”。
- **问题**：词义 — uddese / paripucchāya，nissaya 作 `ပါဠိသင်ခြင်း`（学习圣典）/ `အဋ္ဌကထာသင်ခြင်း`（学习义注）。“诵习、请问”过于笼统。
- **建议**：改为“学习圣典、请问义理”。

## §2357 句 152-2357-75-93
- **问题**：词义 — sāmaññā，nissaya 作 `မဂ်ဖိုလ်မှ` = 从道果。“沙门的境界”所指模糊。
- **建议**：改为“他不会从沙门果退失，而会走近涅槃”。

## §2358 句 152-2358-2-11
- **问题**：句法 — nissaya 中 `အပ္ပမာဒရတော` 与 `ဘယဒဿီဝါ` 都是修饰 `ဘိက္ခု= ရဟန်းသည်`（主格）的定语，说的是同一位比丘。译文“……的比丘，或是……的人”拆成了两个人。
- **建议**：改为“喜好不放逸、在放逸中看见危险的比丘，”。

## §2360 句 152-2360-2-4（原文疑问）
- **问题**：原文 — 本问标题 §2356 编号为“3.”，结语却作 catuttho（第四）。nissaya 同作 `စတုတ္ထီ`。译文忠实于原文，不改。
