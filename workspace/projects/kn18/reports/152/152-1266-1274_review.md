# Review — 152:1266-1274（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 注：本 chunk 的 nissaya 行与 pali 句的 `(word_start, word_end)` 有错位。§1267-39-67 行里放的是上一句末尾（aṭṭhānametaṃ…bhāsitaṃ）；§1267-68-90 行同时含 39-67 与 68-90 两句；§1272-27-105 行开头是上一句的 aññampi…suṇohi；§1273-112-128 行末尾混入了下一段的 api ca kho。下文按词实际所在的句子对照，不依行号。

## 跨段一致性

- **ovadati / anusāsati（及 anusiṭṭhi）**：§1267-91-134 中两词同时出现，ovadamānā / ovadeyyuṃ 译「教诫」，anusāsamānā / anusāseyyuṃ 译「教导」。nissaya 也分开释义：ovadati= ဆုံးမ，anusāsati= ကမြစ်。但 §1267-39-67 的 anusāsamānā / anusāsanti 和 §1267-68-90 的 anusiṭṭhi 都译成了「教诫」，与 ovadati 撞词。
  → 建议全 chunk 统一：ovadati =「教诫」，anusāsati / anusiṭṭhi =「教导」。据此改 §1267-39-67「在教诫的时候，都教诫人们……」为「在教导的时候，都教导人们……」，§1267-68-90「教诫也相同」为「教导也相同」。
- **calati…viddhaṃsati 八动词串**：§1268、§1269-67-91、§1269-92-131、§1270-67-108 四处译法彼此一致，但其中三个词的取义与 nissaya 不合（详见 §1268 条）。改时四处须同步改。
- **Api ca**：§1272-2-13 译「不过」，§1274-2-20 的 Api ca kho 译「此外」。nissaya 两处都作增补义（ထို့ပြင်လည်း「除此之外也」）。
  → 建议统一为「此外」。
- **mahanta**：§1274 系列句中，大地、大海、须弥山、虚空译「广大」，帝释、魔、大梵天、如来译「伟大」。按有情 / 无情分译本身可以接受。问题在于统摄句 §1274-27-39「世间其他广大的事物」只用了「广大」，覆盖不到后面译作「伟大」的四项。
  → 建议把统摄句改为不偏一边的说法，如「世间其他凡是大的，也都只有一个」。

## §1267 句 152-1267-91-134

- **问题**：词义收窄 / 增译。nissaya 把 obhāsajāto 释为 တရားရောင်ဖြစ်（生起法的光明），把 pabhāya 释为 တရားအရောင်တော်ဖြင့်（以法的光明）。译文作「光明普照」「两位佛陀的光芒」，丢了「法」的所指，「普照」也是原文没有的。另外 sukhaṃ ovadeyyuṃ 的 sukhaṃ 在 nissaya 是 ချမ်းသာစွာ（安乐地、顺利地），没有比较义，译文「更轻松」的「更」属于增译。
- **建议**：改为「单单一位佛陀出世，这个世界就已经有了法的光明；如果有第二位佛陀，凭着两位佛陀的法光，这个世界就会更加光明。两位如来教诫的时候，会教诫得很轻松；教导的时候，也会教导得很轻松。」
  tattha 在 nissaya 是 ထိုအယူ၌（关于这一点），「其中的理由」可改为「请您告诉我这件事的理由」。

## §1268 句 152-1268-2-38

- **问题**：动词取义。nissaya 在 §1269-67-91 的释义最清楚，§1268 / §1269-92-131 / §1270-67-108 与之大体一致：
  - namati= နိမ့်ရာ၏（低陷、下沉），§1268 作 နက်ရှိုင်း（陷深）
  - onamati= ညွတ်ရာ၏（弯垂）
  - vinamati= ယိမ်းယိုင်ရာ၏（倾侧、歪斜）
  - vikirati= ကြဲရာ၏（散落）
  - vidhamati= လွင့်ရာ၏（飘散、溃散）
  - viddhaṃsati= ပျက်ပြားရာ၏（毁坏）

  译文把 namati 译「倾斜」、onamati 译「下沉」，两者对调；vidhamati 译「崩塌」，与 nissaya 的「飘散」不合。
- **建议**：整串改为「摇动、震颤、下沉、弯垂、倾斜、散落、飘散、毁坏」，并在 §1269-67-91、§1269-92-131、§1270-67-108 三处同步替换。
- **（可选）**：dasasahassī lokadhātu 在 nissaya 是「具有一万轮围（စကြာဝဠာ）之量的这一世界界」，单数。「这一万个世界」可以接受；如果要贴近单数，可作「这个由一万个世界组成的世界界」。

## §1269 句 152-1269-36-66

- **问题**：语气误读。āgaccheyya、abhirūheyya 是祈愿式，nissaya 作 လာပြန်ငြားအံ့ / တက်စီးငြားအံ့，即「假如……来了 / 假如……登上」，是假设。译文「这时第二个人来了……他也登上了那条船」写成了已然发生的事实。
- **建议**：改为「假如这时又来了第二个人……他也登上那条船，大王，那条船还能承载得了两个人吗？」

## §1270 句 152-1270-2-44

- **问题**：词义分歧。nirantaro 在 nissaya 是 ကာလမခြားဘဲ（时间上毫无间隔），即「紧接着（又吃）」。译文「肚子里没有一点空隙」取的是空间义。
- **建议**：参照 nissaya 改为时间义，如「……昏沉困倦，身体僵直得像一根弯不下来的棍子，紧接着又再吃同样多的饭」。如果坚持取「饱满无隙」义，要在报告里说明依据。
- **记录（不改译文）**：pali 作 dhāto，nissaya 读作 tato（ထိုနောက်မှ「此后」）。译文按 dhāta 取「吃饱了」，与 pali 一致，可以保留。

## §1270 句 152-1270-45-66

## §1271 句 152-1271-2-17

- **记录（不改译文）**：nissaya 把 atidhammabhārena 读作 abhidhamma-bhāra（အဘိဓမ္မာဝန်「阿毗达摩的负担」），§1271-105-115 也一样。但同一组对比句 §1271-81-95 的 atiratanabhārena，nissaya 作 အလွန်သော（过度的），支持 ati-「过重」的读法。译文「法的负担太重」与 pali 和对比句都一致，可以保留。

## §1272 句 152-1272-2-13

- **问题**：连接词误读。Api ca 在 nissaya 是 ထို့ပြင်လည်း（此外、而且），是增补，不是转折。译文「不过」偏转折。
- **建议**：改为「此外，大王，这个理由是为了彰显佛陀的力量才举出来的。」（见跨段一致性）

## §1272 句 152-1272-27-105

- **问题**：引语表意不清。nissaya 作 တုမှာကံ ဗုဒ္ဓေါ= 你们的是佛陀 / 我们的是佛陀（判断句，各自认定「这位才是佛」）。译文「‘你们的佛陀，我们的佛陀’」只是两个名词短语并列，读者看不出争执的内容。三处引语（两处佛陀、一处大臣）都是这样。
- **建议**：改为「‘这是你们的佛陀’‘这是我们的佛陀’」，大臣一处同理改为「‘这是你们的大臣’‘这是我们的大臣’」。

## §1273 句 152-1273-112-128

- **问题**：小品词归属。Idampi 的 pi 附在「这个理由」上，nissaya 作 ဣဒမ္ပိ ကာရဏံ= ဤအကြောင်းကိုလည်း（这个理由也），意思是「这也是一个理由」。译文把「也」挂在了「你」上：「你也要从义理上接受它」。
- **建议**：改为「大王，这个理由也说明了两位正等正觉者为什么不在同一时刻出现，请你从义理上接受它。」

## §1274 句 152-1274-103-127

- **问题**：指代收窄。nissaya 把 te 释为 ထိုဘုရားစသည်တို့（那些佛陀等，即前面列举的大地、大海、须弥山……与佛陀），añña 释为 တစ်ပါးသော ဘုရားရှင် စသည်（另一个佛陀等），yattha 释为 အကြင်လောကဓာတ်၌（在哪个世界界中）。译文「他们……其他人」把指代限成了人，大地、大海、虚空等无情物都被排除在外。
- **建议**：改为「这些伟大的存在在哪个世界出现，那里就没有第二个出现的余地。所以，大王，如来、阿罗汉、正等正觉者在世间只出现一位。」

## §1267 句 152-1267-2-38 / §1272 句 152-1272-14-26

- **原文疑问（记下，不改）**：pali 作 dve arahanto sammāsambuddho / dve sammāsambuddho，「两位」后接单数主格，疑为 sammāsambuddhā 之讹。nissaya 两处都按复数 သမ္ဗုဒ္ဓါ 释读。译文按复数译出，无误。
