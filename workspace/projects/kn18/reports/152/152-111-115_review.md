# Review — 152:111-115（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya 单元，这些句略过）

## 跨段一致性

- **na hettha puggalo upalabbhati**：§112 译“因为在这里并找不到一个真实的人（puggala）”，§113 国王原样引述同一句，却译成“在这里并找不到一个人”。→ 引语必须与原话逐字一致，建议统一为“在‘那先’这个名字里，找不到一个实在的人”（见 §112 句 152-112-67-146），§113 引语去掉“因为”后照录。
- **musā bhaṇ-**：§113 `ko musā bhaṇati` 译“是谁说谎”，§115 `nāhaṃ musā bhaṇāmi` 译“我没有说妄语”。§114 `musāvādaṃ bhāsasi` 也译“说妄语”。→ 本 chunk 的论辩就围绕“妄语”这个指控展开，建议 §113 也改为“是谁说妄语”，让前后的指控与反驳相互呼应。
- **ñāyati / samudācaranti**：§112 问句 `kathaṃ bhadanto ñāyati` 译“人们怎样称呼您”，答句 `ñāyāmi` 译“人们称我为”，`samudācaranti` 又译“都叫我”。ñāyati 与 samudācaranti 被混成同一个“称呼”。nissaya：`ဉာယာမိ = ထင်ရှား၍ အများသိအပ်ပေ၏`（广为人知），`သမုဒါစရန္တိ = ခေါ်ဝေါ်ကုန်၏`（称呼）。→ ñāyati 统一译为“为人所知”一类说法，与“称呼”区分开（见下文两句）。
- **kallaṃ nu kho tadabhinanditun**：§113 与 §114 都译“这种说法能够赞同吗”，两处译法一致，但词义有偏差，需要两处同改（见 §113 句 152-113-2-36）。

## §112 句 152-112-48-66
- **问题**：词义 — `ကထံဉာယတိ = အသို့ထင ်ရှား၍ သိအပ်ပါသနည်း`，意思是“以什么而显明、被人知道”，是被动的“为人所知”，不是“称呼”。
- **建议**：“大德，您以什么名字为人所知？大德，您叫什么名字？”

## §112 句 152-112-67-146
- **问题 1**：词义 — `ဉာယာမိ = ထင်ရှား၍ အများသိအပ်ပေ၏`（广为众人所知）。现译“人们称我为‘那先’”，与后文 samudācaranti“叫我”重复，层次没有区分出来。
- **建议 1**：“大王，我以‘那先’之名为人所知；大王，同梵行者们都叫我‘那先’。”
- **问题 2**：补出成分 — `ဧတ္ထ = ဤနာဂသေနဟူရာ၌`（在“那先”这个名称里）。nissaya 明确指出 ettha 指的是这个名字，现译只作“在这里”，指代不清。另有 `ပုဂ္ဂလော = ပုဂ္ဂိုလ်သူငါ,သတ္တဝါ အထည်ဝတ္ထုကို`（作为实体的人、我、众生）和 `နဥပလဗ္ဘတိ = ဉာဏ်ဖြင့် ရှုကြည့်၍ မရအပ်ချေ`（以智观察也得不到）。
- **建议 2**：“因为在‘那先’这个名字里，找不到一个实在的人（puggala）。”§113 的引语同步修改。
- **问题 3**：句法 — `အပိစ = ထိုမှတပါး`（此外）。父母取名一句是在同梵行者称呼之外另起一层，现译没有译出这个转接。
- **建议 3**：句首补“此外，”。

## §113 句 152-113-2-36
- **问题 1**：词义 — `ကလ္လံနုခေါ = လျော်ကန်သင့်မြတ်ပါ အံ့လော`（是否恰当、是否合宜）。kallaṃ 问的是合不合适，不是“能不能够”。另外 `တံ = ထိုနာဂသိန်မထေရ်စကားကို`，赞同的对象明确是那先的这句话。
- **建议 1**：“赞同他这句话，合适吗？”§114 句 152-114-316-393 结尾同改。
- **问题 2**：引语不一致 — 内引语“在这里并找不到一个人”与 §112 原话译法不同（见跨段一致性）。
- **建议 2**：照录 §112 修订后的译文。
- **问题 3**（次要）：`ယောနကာ = ယောအမတ်တို့`，nissaya 读作“臾那诸大臣”。现译“臾那人”在字面上不算错，但可以考虑在首次出现的夹注里补出“随王的臾那大臣”这一身份。

## §113 句 152-113-37-148
- **问题 1**：词义 — `ကာရောတာဝါ = ပြုလုပ်စေမည့်ဟု`（使人去做的人）。kāretā 是中性的“使作者”，这里同时管善业与不善业。“教唆者”带贬义，套在善业上不通。
- **建议 1**：“善业与不善业的造作者，或者让别人去造作的人”。
- **问题 2**：补出成分 — nissaya 在 tasmā 前补出 `(ယသ္မာ = အကြင်သို့ ပုဂ္ဂိုလ်မရှိသောကြောင့်…)`（因为没有人去造作），tasmā 是承接这个因果的“因此”。现译“这样一来”语气偏弱。
- **建议 2**：改为“既然如此，就没有善……”或“因此，就没有善……”。
- **问题 3**（次要）：`ဖလံ = သာမညအကျိုး`／`ဝိပါကော = တူသောအကျိုး`，phala 与 vipāka 分别是一般的结果和相应的果报，现译“没有果，没有报”可以保留。`ဥပသမ္ပဒါ = ရဟန််းအဖြစ်`，现译“也没有受具足戒”把名词改成了动作，建议改为“也没有具足戒”，与前两项“没有阿阇梨，没有和尚”保持平行的名词结构。

## §113 句 152-113-149-167
- **问题**：句法 — `ဧတ္ထ = ဤစကား၌`（在这句话里）。现译“这里”可以接受，但引语里的名字没有加引号，与 §112“叫我‘那先’”的体例不一致。
- **建议**：“您说：‘大王，同梵行者们都叫我“那先”’，那么在这句话里，哪一个是那先？”嵌套引号按体例处理。

## §113 句 152-113-205-329
- **问题**（存疑）：词义 — `အန္တံ = အူမ`（大肠）、`အန္တဂုဏံ = အူသိမ်`（小肠）。现译“肠……肠间膜”沿用的是汉译三十二身分的传统译法，nissaya 则读作“大肠／小肠”。
- **建议**：两种读法有分歧。本句可以暂时保留传统译法，把这一处登记进 `terms.md` 定案，并压低本句的 confidence。

## §114 句 152-114-2-67
- **问题**（次要）：词义 — `ဥပဟညတိ = ညှိုးနွမ်းပေလိမ့်`（萎顿、受挫）。现译“心会受到困扰”偏离了原意。
- **建议**：“心情会沮丧”或“心会疲惫受挫”。

## §114 句 152-114-168-175
- **问题**：词义 — `ရထဏ္ဍကော = ရထားထောက်`（车的撑柱、支杆）。现译“车杆”很容易与 īsā“车辕”混淆，读者分不清这是两个部件。§114 句 152-114-237-250、152-114-260-274 和 §115 的列举都受影响。
- **建议**：改为“车撑”或“车的支柱”，四处统一，并登记进 `terms.md`。

## §114 句 152-114-316-393
- **问题 1**：句法 — `ပန = ထိုသို့ဖြစ်ပါလျက်`（虽然如此却……）。pana 在这里表示让步，`ကဿ = အဘယ်သူမှ`（从谁那里）与 `ဘာယိတွာ`（害怕）连读。现译“您是怕谁而说妄语呢”丢了让步语气，而且“而”字偏文言。
- **建议 1**：“大王，您是整个阎浮提最尊贵的国王，既然如此，您到底是怕谁，才说妄语呢？”
- **问题 2**：同 §113，“这种说法能够赞同吗”应改为“赞同他这句话，合适吗？”。

## §115 句 152-115-2-43
- **问题**（次要）：句法 — `ပဝတ္တတိ = ဖြစ်ချေ၏`。整串 `saṅkhā … nāmamattaṃ` 共同作 pavattati 的主语。现译把 nāmamattaṃ 拆成另一个分句“它仅仅是一个名字而已”，与 §112 句 152-112-67-146 的结构不对称。
- **建议**：“……依靠车撑，才出现‘车’这个称号、通称、施设、言说，仅仅是一个名字。”“车杆”同步改为修订后的译名。
