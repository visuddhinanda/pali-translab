# Review — 152:1455-1466（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次为 nissaya 词法复核）。本层为本文 mūla，没有父层，不做被解释词对照。

## 跨段一致性
- **bahusādhāraṇa**：§1455 句 145-187 和 §1456 句 2-21、句 22-47 中，身体译「众人共有的」，肉块译「众人共享的」，果树译「各种鸟群共享的」。§1456 两个比喻句前后半句本是同一个词（nissaya 同为 `အများနှင့်ဆက်ဆံ`），比喻要靠同词才能对上。→ 建议全部统一为「共享」。
- **atthavasa / kāraṇa**：§1464 的 atthavasa（句 2-18、67-79）译「理由」，§1466 句 2-21 的 kāraṇa 也译「理由」。nissaya 把 atthavasa 释为 `အကျိုးထူး`（特殊的利益），kāraṇa 释为 `အကြောင်း`（原因），两词有别。→ 建议 atthavasa 改为「利益」或「用意」，与 kāraṇa 区分开。
- **dinnaṃ pariccattaṃ … sarīraṃ** 中的 tassa / assa：§1455 句 117-144 和句 145-187 两处都误作属格「他的身体」，见下文分句意见。两处要一起改。

## §1455 句 152-1455-26-52
- **问题**：取义 / 词法。`အသဗ္ဘိကာရဏံ= သူယုတ်တို့၏ပြုကြောင်းတည်း`，意思是「这是卑劣之人（asabbhi）的做法」，带属格，是肯定判断。译文「这不是善人的做法」改成了否定句，语气减弱，也和后句「这才是善人的行为」（sappurisānaṃ kammaṃ）的正反对照失去了对称。
- **建议**：改为「……这是不善之人的做法」。

## §1455 句 152-1455-101-116
- **问题**：漏译强调词。`ပုတ္တဒါရံယေဝ= သားမယားကိုသာလျှင်`，意思是「施的正是儿女妻子」。yeva 呼应前文「求什么就施什么」（taṃ tadeva），译文「他就施舍了儿女和妻子」没有译出这层强调。
- **建议**：改为「……他施舍的也正是儿女和妻子」。

## §1455 句 152-1455-117-144
- **问题**：格误读（必改）。`တဿ= ထိုတောင းခံလာသူအား`，tassa 是与格「给那个乞求者」，不是属格「韦山达拉的」。原句的意思是：身体会成为施给乞求者、舍给他的东西。译文「他的身体就会成为已经施与、已经舍弃的东西」把 tassa 读成了身体的领属者。
- **建议**：改为「……他的身体就会成为施给那个乞求者、为他舍弃的东西」。主语里的「他的身体」可以保留，但必须补出与格对象。

## §1455 句 152-1455-145-187
- **问题 1**：格误读（必改），与上句相同。`အဿ= ထိုတောင်းခံသူအား`，yevassa 中的 assa 是与格「给那个乞求者」。
- **建议**：改为「……他的身体就会成为施给乞求者、为他舍弃的东西」。
- **问题 2**：取义偏移（建议改）。`နတပေယျံ= မပူပန်ရာ`，意思是「不会苦恼、不会忧煎」，侧重内心受煎熬，「懊悔」偏向追悔。
- **建议**：改为「他施舍之后也不会苦恼」。

## §1459 句 152-1459-72-90
- **问题**：修饰关系。nissaya 把 `အတုလံ / ဝိပုလံ / အနုတ္တရံ / ပိယံ / မနာပံ / ဒယိတံ / ပါဏသမံ` 全部系于 `ပုတ္တဒါရဒါနဝရံ= သားမယားအလှူမြတ်ကို`，也就是说这串形容词修饰的是那份殊胜的布施。译文把它们全挂在「儿女妻子」上，再另说「作为最殊胜的布施」，至少 atula / vipula / anuttara 应当属于布施。另外 vipula 和 anuttara 两个词被压成了「广大无上」。
- **建议**：改为「……把这样一份无可比拟、广大、无上、可爱、合意、珍爱、如同生命一般的儿女妻子的殊胜布施，施给了婆罗门」，或把句子拆开，让前三个词明确修饰布施。

## §1461 句 152-1461-2-15
- **问题**：误译（必改）。`ဥဘောပုတ္တာ= ဇာလီကဏှာသားသမီးနှစ်ဖြာတို့ကို`，nissaya 明示这里指 Jāli 和 Kaṇhā，一子一女。puttā 是阳性复数，泛指子女。译「两个儿子」与故事事实不符。
- **建议**：改为「两个孩子我并不憎恶」或「一儿一女我并不憎恶」。

## §1463 句 152-1463-2-22
- **问题**：异读取舍。正文作 puttadānaṃ（施舍儿女），nissaya 取的是异读 puttadāraṃ（ka.），释为 `သားမယားအလှူကို`（儿女妻子的布施）。译文「施舍了儿女之后」跟随正文，本身没有错。但同段 §1463 句 46-63 又译「把儿女和妻子施舍给婆罗门」，前后所施对象不一致。
- **建议**：保留正文读法也可以，但要确认是有意为之；如果要与本段后句对齐，可以改为「施舍了儿女和妻子之后」。

## §1463 句 152-1463-32-45
- **问题**：取义偏移（建议改）。`ပရိဝတ္တိတွာ= ယိုစီး၍` 的意思是「涌流、流淌」，译「翻滚着」偏离了 nissaya 的取义。`အဿာသပဿာသေ= ထွက်သက်ဝင်သက်တို့ကို` 指呼气和吸气，译文只说「呼出」。
- **建议**：改为「……他只好张嘴喘着灼热的气，眼泪涌流而出，化成血滴，从双眼流了出来」。

## §1464 句 152-1464-2-18、句 152-1464-67-79
- **问题**：取义。`ဒွေအတ္ထဝသေ= နှစ်ပါးသော အကျိုးထူးတို့ကို`，nissaya 取「两种利益」。下文列出的两项（布施之道不退、孩子获救）也确实是利益，不是一般意义上的「理由」。
- **建议**：两处统一改为「基于两种利益（用意）」。见跨段一致性第二条。

## §1457 句 152-1457-2-29
- **问题**：取义 / 补出成分。`အဇပထံ= ဆိတ်ဖြင့်သွားရသောခရီးကို`，意思是要赶着山羊走的路。「羊肠小道」是汉语成语，泛指窄而弯的路，丢掉了「山羊」这个实义。另外 `စရမာနော= လှည့်လည်သော`（四处奔走）没有译出。
- **建议**：改为「……为了寻求钱财四处奔走，走山羊才能走的路、靠钉桩攀爬的山路、攀着藤条的险路……」。

## 原文 / nissaya 数据疑问（记录，不改）
- §1455 句 101-116 的 nissaya 单元开头重复了上一句（81-100）的全部条目，是坐标切分问题。
- §1455 句 117-144 的 nissaya 中，`သရီရံ= မြတ်သောမင်းကြီး` 释义错位，且缺 yāceyya 和 na so 两项。
- §1465 句 2-34 的 nissaya 把 parittapuñño 写作 `ပရိပုညော`，疑似脱字。
