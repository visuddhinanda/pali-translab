# Review — 152:982-990（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（982、983-27-30、984、985、986-43-74、986-75-87、989-163-176 无 nissaya，已略过）

## 跨段一致性
- 被解释词对照：本层为本文，无父层，不适用。
- 复现套语「pūjetha naṃ pūjaniyassa dhātuṃ, evaṃ karā saggamito gamissathā」在 §984/§985/§986（两处）/§987 中译法一致。但其中 `ito`、`naṃ`、`evaṃkarā` 的处理按下文 §986 句 152-986-2-42 的意见修改后，**五处要同步改**，否则引文前后会对不上。
- 「供养并不是胜者之子的本分……供养则是其余的天神和人类应当做的」套语在 §987/§988/§989 三处一致。其中 `sadatthamanuyuñjanā` 按下文 §988 的意见修改后，**三处同步改**。
- 其余（胜者之子、吠舍和首陀罗、务农/经商/放牧）：无不一致。

## §986 句 152-986-2-42
- **问题**：取义（异释当主译）— `ito` 的 nissaya 主释是 `ဣတော= ဤကောာင်းမှုကြောင့်`（因此功德，从格表原因）。「从这人世间」是用 `ဝါ=` 引出的异释：`ဝါ= ဤလူ့ပြည်မှ`。译文「从这里去往天界」用的是异释。按 style.md 第四节，应取主译，异释作脚注。
- **建议**：改为「这样做的人，凭这份功德将去往天界」；异释「从此人间」放进脚注。§985、§986-43-74、§987 的引文同步改。
- **问题**：句法 — `naṃ` 的 nissaya 是 `နံဓာတုံ= ထိုသရီရဓာတ်တော်ကို`（那舍利，宾格），也就是说 `naṃ` 修饰 `dhātuṃ`。`pūjaniyassa` 作属格，nissaya 是 `ပူဇော်ထိုက်သောဘုရားရှင်၏`（值得供养的佛陀的）。译文「那位值得供养者的舍利」把「那」挂到了 `pūjaniyassa` 上。
- **建议**：「你们应当供养值得供养者的那舍利」，或「供养那舍利——值得供养者的舍利」。§984、§986-43-74、§987 同步改。
- **问题**：成分 — `evaṃkarā` 的 nissaya 是 `ဤသို့ပူဇော်ခြင်းပြုကုန်သူတို့သည်`（这样作供养的人们，主格），是名词性主语。译文「这样做，你们将……」改成了条件分句，意思没错，但主语的结构丢了。
- **建议**：「这样作供养的你们，将……」，或「这样做的人将……」。属次要项，可与上面 `ito` 的修改一并处理。

## §987 句 152-987-57-89
- **问题**：漏译连接词 — `Akammaṃ hetaṃ` 中的 `hi` 表示说明理由。nissaya 在上句末用 `ဟိ= …ကန့်ကွက်ခြင်းသည်၊အချက်တော်သင့်…`（因为……那禁止是恰当的）点出了这层因果关系。译文没有译出。
- **建议**：句首补「因为，」：「因为，大王，供养并不是胜者之子的本分；……」。§988、§989 的同一套语是放在 evameva 之后，不受影响。

## §988 句 152-988-2-54
- **问题**：误译 — `muddā` 的 nissaya 是 `ဂဏန်းအတတ်`（算术）。「手印算术」是两种解释拼在一起的结果。
- **建议**：改为「算术」。
- **问题**：误译 — `suti` 的 nissaya 是 `ဗေဒင်အတတ်`（吠陀之学），`sammuti` 的 nissaya 是 `ဓမ္မသတ်အတတ်`（法典之学）。「圣典传承」「世俗规约」都偏离了词义。
- **建议**：`suti` 改为「吠陀」，`sammuti` 改为「法典」。
- **问题**：取义 — `sadatthamanuyuñjanā` 的 nissaya 是 `အရဟတ္တဖိုလ်ဟူသောမိမိအကျိုးကိုအားထုတ်ခြင်း`（致力于自己的利益，即阿罗汉果）。nissaya 把 `sad-` 解作「自己的」，没有「真实」义。「自己的真实利益」把两种读法叠在了一起。
- **建议**：改为「致力于自身的利益」。§987、§989 同步改。

## §989 句 152-989-2-143
- **问题**：误译 — `antaracakkaṃ` 的 nissaya 是 `ခွေး၊သား၊ငှက်မှ တပါးသောသတ္တဝါတို့၏မြည်သံဟောအတတ်`（从狗、兽、鸟以外其他众生的叫声来占验的术）。这个词与方位无关，「中间方位的占验」是误译。
- **建议**：改为「其他动物叫声的占验」。
- **问题**：增译 — `sakuṇarutaravitaṃ` 的 nissaya 是 `ငှက်မြည်၊ငှက်အော်ဟောအတတ်`（鸟鸣、鸟叫的占验），只讲鸟。译文「鸟鸣兽叫」多出了「兽」，而且和前面的 `migacakka` 重复。
- **建议**：改为「鸟鸣的解读」。
- **问题**：译窄 — `migacakkaṃ` 的 nissaya 是 `သားငှက်မြည်တွန်ဟောအတတ်`（兽类、鸟类鸣叫的占验）。`miga` 在这里泛指兽类，不只是鹿。
- **建议**：改为「兽鸣的占验」。
- **问题**：取义（异释当主译）— `bhūmikammaṃ` 的 nissaya 主释是 `မြေအိမ်၌နေ၍ မန္တန်စုပ်ခြင်းအတတ်`（住在地窟中持诵咒语的术），「地震」是 `ဝါ= မြေကြန်` 引出的异释，对应校记异文 `bhūmikampaṃ`。译文取了异释。
- **建议**：主译改为「地窟持咒术」，脚注列出异释和异文（地震 / bhūmikampa）。
- **问题**：用词 — `purāṇaṃ` 的 nissaya 是 `ပုရာဏ်ကျမ်းအတတ်`（往世书之学）。「古事记」是日本古籍的书名，会误导读者。
- **建议**：改为「往世书」。
- **问题**：误译 — `keṭubhaṃ` 的 nissaya 是 `စကားပြောဆိုစီကုံးပုံနည်းနာကိုပိုင်းခြားပြဆိုသောကျမ်း`（剖析言辞如何组织的论书），意思近于修辞或作文法，不是「仪轨学」。
- **建议**：改为「修辞学」。
- **问题**：词义 — `devadundubhissaraṃ` 的 nissaya 是 `မိုးကြိုး… / တော်လည်းသံဟောအတတ်`（依雷声占验）。「天鼓的声音」是字面直译，读者看不出指的是雷。
- **建议**：改为「雷声的占验」。
- **问题**：译名冲突 — `nimittaṃ` 的 nissaya 是 `နိမိတ်ကောက်အတတ်`（占兆、解读征兆）。译文「占相」容易和前面 `lakkhaṇaṃ`（相术）混淆。
- **建议**：改为「占兆」。
- **问题**：句法 — 这一串宾语在 nissaya 里都带 `-အတတ်`（……之术），是「应当学习」的内容。译文里「月蚀、日蚀、金星与罗睺的运行、星宿交战、流星坠落、地震、四方火光」等只列出了现象本身，读成「学习月蚀」，意思不通。
- **建议**：这些项统一加上「占验」类后缀，例如「月蚀占、日蚀占、金星与罗睺运行的推算、星宿交战之占、流星占……」；或者在列举前加总括语「以及根据下列现象占验之术」。

## §989 句 152-989-144-162
- **问题**：补出成分 — `buddhapūjaṃyeva` 的 nissaya 是 `ဘုရား၏အလောင်းကိုကောင်းစွာပူဇော်ခြင်းကိုသာ`（只是好好供养佛的遗体）。nissaya 补出的宾语是「遗体」，正好回扣 `sarīrapūjā`。译文「供养佛陀的事」所指偏泛。
- **建议**：可改为「一心只去供养佛陀的遗体」，让论证与「不要为如来遗体的供养操心」前后呼应。属次要项。

## §990 句 152-990-2-4
- **问题**：原文疑问（记录，不改译文）— nissaya 的标目是 `ဗုဒ္ဓပူဇာယာနုညာတာနုညာတပဉှာသတ္တမီ`（Buddhapūjāya anuññātānanuññāta-pañhā，「佛陀供养之许与不许问」第七），和 VRI 本 `Buddhapūjanapañho sattamo` 的品题不同。这是版本异名，译文按 pali 译出没有问题。
- **建议**：可在脚注列出缅本标题。
