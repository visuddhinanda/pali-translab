# Review — 152:1800-1803（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **yasa / kitti**：§1801 `yasakāmo kittikāmo`、§1803 `ayasakāmo akittikāmo` 两处都译作「名声和称誉」。nissaya 的释义是 `ယသကာမော= အခြံအရံကိုလိုလားသော`（贪求随众、眷属），`ကိတ္တိကာမော= ဂုဏ်သတင်းပျံ့နှံ့ကျော်ကြားသည်ကိုတောင့်တသော`（渴望名声远扬）。也就是说，yasa 指的是随众，并不是名声，现在的译法把 yasa 和 kitti 都落在了「名声」一义上。→ **必改**：两段统一为「贪求利养、随众和名声」／「不贪求利养、随众和名声」。
- **sāmañña 与 samaṇa 混同**：§1800 中 sāmañña- 复合词出现九处（sāmaññabīja、sāmaññaguṇa、sāmaññattha、sakalasāmaññaariyadhamma 等），全部译作「沙门（的）」。§1801 `samaṇamahāpeto`、§1803 `samaṇadhammo` 同样译作「沙门」。nissaya 对 sāmañña 一律释为 `မဂ်ဖိုလ်`（道果），对 samaṇa 则释为 `ရဟန်း`（比丘、沙门），两个词判然有别。现在的译文把这两个词合成了一个。→ 建议把 sāmañña 与 samaṇa 区分开，统一译作「沙门性」，或依 nissaya 译作「沙门道果」。选定一种后，§1800 九处一并改。
- **譬喻与合法的平行措辞断裂**（§1800 同段内前后两半）：
  - `āhāro balāharaṇāya`「增长体力」对 `iddhibalāharaṇāya`「获得神通之力」。两处都是 āharaṇa，nissaya 都作 `ဆောင်ခြင်း`（带来）。建议统一为「带来体力」／「带来神通之力」。
  - `latā bandhanāya`「捆绑」对 `satisaṃvaranibandhanāya`「以正念的防护来约束自己」。合法这一句的结构走样了，详见下文 §1800 句 152-1800-2-189 第 2 条。
  - `āṇā anatikkamanāya`「不被违犯」对 `…santisukhamanatikkamanāya`「不偏离」。两处同为 anatikkamana，nissaya 都作 `မလွန်ခြင်း`（不逾越）。建议合法这一句也用「不违越」，保留平行。
  - `issariyaṃ vasavattanāya`「支配他人」对 `…ariyadhammavasavattanāya`「自在无碍」。nissaya 作 `အလိုသို့လိုက်ခြင်း`（随己意转），原文没有「他人」。建议统一为「使一切随己意」／「使沙门一切圣法随己意而转」，或者两处都译作「自在支配」。
  - `mantaṃ parijappanāya`「念诵」对 `sādhusajjhāyakaraṇāya`「好好修习」。nissaya 作 `သရဇ္ဈာယ်`（诵习）。现在平行断了，而且这一句有误读，详见下文 §1800 句 152-1800-2-189 第 1 条。
- **「X 之于 Y」句式**：§1803 一连用了八次「就像……之于……的人」，文言痕迹明显。nissaya 的结构是与格 `…သူအား … အရဟတိဝိယ`（就像 X 对 Y 是相宜的）。→ 建议改成现代说法，例如「就像素馨、茉莉等鲜花对刚沐浴涂香的人来说正合所需」，或「就像刚沐浴涂香的人渴望素馨、茉莉等鲜花」。八处统一改。

## §1800 句 152-1800-2-189

1. **问题**：误读（处格错作宾格）— 在 `sevitabbāsevitabbadhamme sādhusajjhāyakaraṇāya` 这一句里，nissaya 是 `သေဝိတဗ္ဗအသေဝိတဗ္ဗဓမ္မ၌`（处格「在……法上」）+ `သာဓုသဇ္ဈာယ= ကောင်းစွာသရဇ္ဈာယ်ခြင်းကို`（好好诵习）。现在的译文「好好修习应当奉行与不应当奉行的法」把处格读成了宾格，sajjhāya 也被译成「修习」，结果意思变成了「修习不应奉行的法」，与原意相反。
   **建议**（**必改**）：改为「为了就应当亲近与不应当亲近的法好好诵习」。这样也恢复了与「咒语是为了念诵」的平行。
2. **问题**：复合词结构 — 在 `satisaṃvaranibandhanāya` 中，nissaya 是 `သတိတည်းဟူသောစောင့်ရှောက်ခြင်းကိုအမြဲဖွဲ့ခြင်း`，意思是「把念这道防护牢牢系住」。sati 与 saṃvara 是同位关系（ဟူသော），saṃvara 是 nibandhana 的宾语（ကို）。译文「以正念的防护来约束自己」把 sati-saṃvara 变成了工具，又补了一个原文没有的宾语「自己」。
   **建议**：改为「为了牢牢系住正念这道防护」，与「藤蔓是为了捆绑」对应。
3. **问题**：同位误作属格 — 在 `jāti…upāyāsabhayavinodanāya` 中，nissaya 是 `…ဟူသောဘေးကိုဖျောက်ခြင်း`，「生……恼」与 bhaya 是同位关系（「生老病死……这些怖畏」）。译文「生、老……恼的恐惧」读成了「对生老病死的恐惧」。
   **建议**：改为「为了驱除生、老、病、死、愁、悲、苦、忧、恼这些怖畏」。
4. **问题**：用词偏离 nissaya — `abhisamayaassāsakaraṇāya` 的 nissaya 是 `…ဟူသောသက်သာရာကိုပြုခြင်း`（带来现观这一安慰）。译文「获得现观的安心」把 karaṇa（带来、造成）译成了「获得」。
   **建议**：改为「为了带来现观这一安心」，与「宝藏是为了让人安心」对应。
5. **问题**：修饰范围 — `sabbakilesapaṭisattutajjanāya`「威吓烦恼这一切仇敌」中，sabba 修饰的是 kilesa（nissaya `အလုံးစုံသောကိလေသာရန်သူ`），「这一切仇敌」的说法读来别扭。
   **建议**：改为「为了威吓一切烦恼仇敌」。
6. **问题**：nissaya 存疑 — `ākaro` 的 nissaya 是 `အားထုတ်ပြုလုပ်ခြင်းသည်`（努力作业），与 ākara（矿）的常义以及下文「出产珍宝」都不合，疑为 nissaya 的讹误。
   **建议**：保留「矿山」，不改。

## §1800 句 152-1800-190-223

- **问题**：词义与 nissaya 不符 — `āyataṃ` 的 nissaya 是 `အရှည်ခံ့၏`（长、长久），译文作「广大」；`vitthataṃ` 的 nissaya 是 `အရာကျယ်၏`（宽阔），译文作「深广」，多了原文没有的「深」义；`garukaṃ` 的 nissaya 是 `အလေးပြုအပ်၏`（应受尊重），译文作「庄重」，偏离了原义。
  **建议**：依次改为「长远」「宽阔」「可敬重」。另外，`evaṃ` 的 nissaya 是 `ဤသို့`（如此），译文「所以」加进了因果关系，建议改为「这样说来」。

## §1801 句 152-1801-2-111

1. **问题**：副词误作比喻 — 在 `pheṇuddehakaṃ samparivattakaṃ paccati` 中，nissaya 是 `အမြှုပ်တက်ပေ၍`（冒着泡沫）+ `ပြန်လှန်လျက်`（翻转着）+ `ကျက်ရ`（被煮）。pheṇuddehakaṃ 是描写被煮状态的副词，并不是比喻。译文「像泡沫一样沸腾翻转」译错了，而且与前文「上下左右地翻滚着」重复翻转之义。
   **建议**（**必改**）：改为「上下左右翻转，冒着泡沫，被煎煮……」，「翻转」只保留一次。
2. **问题**：类名被拆成描述语 — `nijjhāmataṇhiko samaṇamahāpeto` 的 nissaya 是 `နိဇ္ဈာမတဏှိတမည်သော`（名为 nijjhāmataṇhika 的），这是饿鬼的类名，用来修饰「沙门大饿鬼」。译文拆成一个独立分句「被渴爱焚烧」，原文的名称关系丢失了。
   **建议**：改为「成为一个焚渴饿鬼类的沙门大饿鬼」，或「成为名叫‘焚渴’的沙门大饿鬼」。
3. **问题**：yasa 误译，见上文跨段一致性一节。

## §1803 句 152-1803-2-82

1. **问题**：原文疑问 — nissaya 有 `ဒေဝါနဉ္စ … မနုဿာနဉ္စ`（天与人），pali 只有 `devānañca`。译文按 pali 只译了「天神」，这样处理没有问题。此处记为原文异文存疑，不改。
2. **问题**：词义偏窄 — `atthakāmassa` 的 nissaya 是 `အကျိုးစီးပွါးကိုလိုသောသူ`（欲求利益的人），译文作「求财的人」，范围偏窄。
   **建议**：改为「求利益的人」。
3. **问题**：用语 — `manoharamaṇiratanaṃ` 的 nissaya 是 `မနောဟရပတ္တမြားရတနာ`，保留 manohara 作宝名，没有展开解释。译文「动人心魄」把它当作形容词理解，可以接受，但译文的信心应当压低。
   **建议**：可改为「名为摩诺诃罗（Manohara）的宝珠」，二者择一。
4. **问题**：翻译腔 — `arahattaphalādhigamamanuttaraṃ`「无上的阿罗汉果之证得」中，「之证得」读来生硬。
   **建议**：改为「就像对求法的人来说，无上的证得阿罗汉果正合所需」（与跨段一致性一节「之于」的改法一并处理）。
5. **问题**：yasa 误译，见上文跨段一致性一节。
