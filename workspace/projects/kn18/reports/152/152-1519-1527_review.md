# Review — 152:1519-1527（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1519、1526 句 57-64 无对应 nissaya 单元，略过）

## 跨段一致性

- **nimitta**：§1520、§1521、§1522、§1523、§1527 一律译作“征兆”。nissaya 在这些位置都释为 `အာရုံ`（所缘、对象），只有复合词 pubbanimitta 释为 `ရှေးဦးနိမိတ်`（前兆）。也就是说，“前兆”与单用的 nimitta 在 nissaya 里是两个词。现在单用的 nimitta 也译成“征兆”，读者会把“进入心的视域的东西”理解成“预兆”，与 §1520 六种梦里只有一种出于前兆的说法相冲突。
  - 建议：单用的 nimitta 统一改为“所缘”或“影像”。pubbanimitta 保持“前兆”。
  - 依据：`နိမိတ္တံ= အာရုံသည်။`（§1521、§1527）、`ဧတံနိမိတ္တံ= ဤအာရုံသည်။`（§1520）。
- **supinaṃ passati**：§1520 答句、§1524 句 49-58/59-85、§1525–1527 译作“做梦”；§1520 问句译“见它”；§1522、§1523 句 97-139、§1524 句 2-29/30-48 译作“见到梦”。同一个问答（§1524 问“见到梦”、答“做梦”）里前后不一。
  - 建议：统一为“做梦”。只在“见到梦的那个心”（yaṃ cittaṃ supinaṃ passati）这类以心为主语的地方保留“见”。
- **āpātha(ṃ)**：§1520、§1521 心的场合译“视域”，§1521 句 66-134 镜子的场合译“映照范围”，§1527 又回到“视域”。
  - 建议：比喻里可以保留语境化的译法，但这一处要确认是有意为之。nissaya 一律释为 `ရှေးရှုသက်ရောက်ခြင်း`（显现于前）。
- **attha**：§1522 句 30-63 与 §1523 句 97-139 译“含义”，§1523 句 16-67 译“这件事”，§1527 译“讯息”。nissaya 的释义是：§1522、§1523 为 `အကျိုးအပြစ်`（吉凶后果），§1527 为 `အကြောင်းနိမိတ်`（因由、征相）。
  - 建议：§1522、§1523 三处统一译“吉凶”或“后果”；§1527 见下方单句条目。
- **middha 的程度**：§1524 句 49-58 的 okkante middhe 译“昏沉已经降临”，middhasamārūḷha（§1524 句 59-85、§1525、§1526、§1527）一律译“被昏沉笼罩”。nissaya 区分了两层：前者释为 `ငိုက်မြည်းခြင်း`（打瞌睡），后者释为 `အိပ်ပျော်ခြင်းသို့ကောင်းကောင်းတက်ရောက်`（完全沉入睡眠）。这是本章的论证关键：浅睡时做梦，深睡时心落入有分、不做梦。现在两处译文读不出深浅差别。
  - 建议：middhasamārūḷha 统一改为“完全沉入睡眠”或“深深陷入昏睡”，与“昏沉已经降临”明确拉开层次。

## §1520 句 152-1520-47-69

- **问题**：标点。本句在原文里没有收尾引号（’’ti 在句 70-119 末尾），译文却在句末加了“””，导致句 70-119 的收尾引号失去配对。
- **建议**：删去本句末的“””。另外按跨段一致性第一条，“征兆（nimitta）”改为“所缘”或“影像”，并保留夹注。

## §1520 句 152-1520-70-119

- **问题 1**：取义 — vātiko / pittiko / semhiko，nissaya 释为 `လေနာရှိသူ`、`သည်းခြေနာရှိသူ`、`သလိပ်နာရှိသူ`，意思是“患风病、胆病、痰病的人”，指失调或病症，不是“体质”。
- **建议 1**：改为“风失调的人”“胆汁失调的人”“痰失调的人”，或者用“风病的人”等说法。
- **问题 2**：词义 — devatūpasaṃhārato，nissaya 释为 `နတ်တို့ဆောင်ပြသောကြောင့်`，即“因天神带来、展示”。译文“引入”太模糊。
- **建议 2**：改为“有人因天神送来（梦境）而做梦”。

## §1521 句 152-1521-37-65

- **问题**：增译 — taṃ yeva nimittaṃ，nissaya 释为 `ထိုအာရုံသည်သာ`（只是那个所缘）。yeva 是限定语气，不是“自己”。译文“那个征兆自己进入”容易让人误以为与上文的 sayaṃ（心自己）形成主动对比。
- **建议**：改为“而只是那个所缘本身进入了心的视域”。

## §1522 句 152-1522-30-63

- **问题**：词义 — atthaṃ，nissaya 释为 `အကျိုးအပြစ်ကို`（吉凶后果，宾格）。译文“其中的含义”偏离了这个意思。
- **建议**：改为“然后别人为他说出（梦预示的）吉凶”。

## §1523 句 152-1523-2-15

- **问题**：语气 — iṅgha，nissaya 释为 `တောင်းပန်ပါ၏`（恳请）。“请吧”在现代汉语里是“您先请”的意思，与原意不符。
- **建议**：改为“那先尊者，请您为我说明理由”。kāraṇaṃ 按 nissaya `အကြောင်း` 译作“理由”或“缘由”更贴切。

## §1523 句 152-1523-16-67

- **问题 1**：词义 — tilakā 的 nissaya 是 `မှည့်`（痣），译文“斑点”偏宽。yasāya / ayasāya 的 nissaya 是 `အခြံအရံများ／နည်း`（随从多、随从少），译文“名声或恶名”与之不符。
- **建议 1**：tilakā 改为“痣”。yasa 按 nissaya 改为“随从众多或稀少”；如果要保留“名声”的通行译法，需要在报告里说明取舍。
- **问题 2**：句法 — 引语“imaṃ nāma mayaṃ atthaṃ nipphādessāma”是 jānitvā 的宾语（nissaya 用 `ဣတိ= ဤသို့။ ဇာနိတွာ= သိကုန်၍။` 连接）。译文把它拆成了“长出来，心想‘…’”，变成长出之后另起的念头。另外 atthaṃ 的 nissaya 是 `အကျိုးအပြစ်`，译文“这件事”太泛。
- **建议 2**：改为“这些疖子是先知道了‘我们要带来这样的吉凶’才长出来的吗？”

## §1523 句 152-1523-97-139

- **问题**：同 §1522 句 30-63，atthaṃ 译为“含义”。
- **建议**：改为“吉凶”，与 §1522 逐字一致。

## §1524 句 152-1524-49-58

- **问题**：层次 — okkante middhe 的 nissaya 是 `ငိုက်မြည်းခြင်း`（打瞌睡），这一层与后文的 middhasamārūḷha（沉入睡眠）必须分开（见跨段一致性第五条）。
- **建议**：改为“在睡意已经袭来、还没有进入有分（bhavaṅga）的这段时间里做梦”。

## §1524 句 152-1524-59-85

- **问题**：程度 — middhasamārūḷhassa 的 nissaya 是 `အိပ်ပျော်ခြင်းသို့ကောင်းကောင်းတက်ရောက်သောသူ၏`（完全沉入睡眠的人的，属格）。“被昏沉笼罩”漏掉了“完全”这一层，与上句的“昏沉已经降临”分不出深浅。
- **建议**：改为“完全沉入睡眠的人，心落入有分”。§1525 句 2-38、§1526 句 2-46、§1527 句 2-46 同步修改。

## §1527 句 152-1527-47-76

- **问题 1**：词义 — akiriyaṃ 的 nissaya 是 `ကောင်းသောအမူအရာမရှိသော`（没有良好举止的），译文“靠不住”取义不同。
- **建议 1**：改为“举止不端的”。
- **问题 2**：词义 — dibbo attho 的 nissaya 是 `နတ်၌ဖြစ်သော အကြောင်းနိမိတ်`（来自天神的因由、征相）。“神圣的讯息”丢掉了“属于天神”的意思，也和 §1520 的 devatūpasaṃhāra（天神送来）断了关联。
- **建议 2**：改为“来自天神的征相”。句 77-117 同步修改。

## §1527 句 152-1527-77-117

- **问题**：同上，dibbo attho 译为“神圣的讯息”。另外 bhinnājīvaṃ 的 nissaya 是 `အာဇီဝပျက်သော`（活命已破），“生活不清净”偏泛。
- **建议**：dibbo attho 改为“来自天神的征相”；bhinnājīvaṃ 改为“活命不正的”。
