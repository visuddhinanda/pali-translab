# Review — 122:2246-2246（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 —（本段即义注 *Dhammapada-aṭṭhakathā* 4. Koṇḍadhānattheravatthu，未注入复注作释义参照）／父层本文 —（未注入；本段为故事叙述，无黑体被解释词，被解释词对齐项不适用）

## 跨段一致性
- **pubbe**：§2246 句 184-209、210-225 译「以前」，句 226-282 的 pubbakamma 译「前世」。前两处 nissaya 都作 `ပုဗ္ဗေ= ရှေးဘဝ၌`（前世），与句 226 同指一事 → 建议统一为「前世」。句 45-67 的 pubbe 指今生先前，译「以前」正确，不改。
- **kathesi / kathetha / kathehi**：句 127-135、136-149 译「说（那些话）」，句 163-209 译「那样说」，句 226-282 译「争辩」。同一动词、同一场景 → 建议统一为「说」，见下文句 226-282。
- **bhante**：通篇译「尊者」，前后一致。但这里是比丘称呼世尊，可考虑改用「世尊」或「大德」。属术语表未登记项，留待定案，非必改。
- **koṇḍa**：句 32-44、45-67 都译「无赖」，前后一致。语义存疑，见下文句 32-44。

## §2246 句 122-2246-2-27
- **问题**：nissaya 分歧 — 原文是 `rañño pāpakiriyaṃ`（国王的恶行），nissaya 却切作 `ပါပရညော= ယုတ်မာသောမင်း၏`（那个恶劣国王的）+ `ကိရိယံ= အမူအရာကို`（所作所为），把 pāpa 归给了国王。
- **建议**：译文按原文读作「国王做的坏事」，可以保留。两种切分的分歧记入报告，不必改译文。

## §2246 句 122-2246-32-44
- **问题**：存疑 — koṇḍa 译「无赖」依据不足。nissaya 只作音写 `ကောဏ္ဍော`，没有释义。此词与人名 Koṇḍadhāna（君头波汉）中的 koṇḍa 是同一个字，故事的讥讽正是借这个名字发挥（“君头”对应 koṇḍa）。译成「无赖」，双关就丢了。
- **问题**：nissaya 分歧 — nissaya 读作 `ဣဒါနိပိ … ရာဇာ= ကောသလမင်းကြီးသည်။ ကောဏ္ဍော … ဇာတော`（如今国王也成了 koṇḍa）。原文是 `idānisi`（= idāni asi，“你现在是”），译文按原文译作「你现在成了国王的…」，读法正确。
- **建议**：「无赖」可暂时保留，但应压低 confidence。建议 footnote 步补注，说明 koṇḍa 与长老名字的关联。待定译后补进 `terms.md`。

## §2246 句 122-2246-163-183
- **问题**：轻度误读 — `ete tāva disvā kathenti` 中的 tāva 表示让步对比（“他们至少是看见了才说的”），与下句「你却没看见」相对。译「毕竟」，对比的意味就弱了。
- **建议**：改为「他们至少是看见了才说的」。

## §2246 句 122-2246-184-209
- **问题**：误译 — `pubbe` 指前世，nissaya 作 `ပုဗ္ဗေ= ရှေးဘဝ၌`。按故事，长老在过去佛时期曾离间两位比丘，今生的遭遇是那一世的果报。译成「以前」，读者会理解为今生先前。
- **建议**：改为「前世不正是因为你的恶见，才落到这个地步的吗？」
- **问题**：译宽 — `adisvāva` 是“（你）没有看见（女人）”，nissaya 作 `သူတို့မြင်သကဲ့သို့ မမြင်ပဲလျှင်`（不像他们那样看见）。「什么也没看见」说过了头。
- **建议**：改为「你自己并没有看见，为什么也对他们那样说？」

## §2246 句 122-2246-210-225
- **问题**：误译 — 同上，`pubbe` 应为「前世」。nissaya 作 `ပုဗ္ဗေ= ရှေးဘဝ၌ … ကတံ= ပြုအပ်သော မကောင်းမှုကံ`（前世所作的恶业）。
- **建议**：改为「尊者，那么他前世做了什么呢？」

## §2246 句 122-2246-226-282
- **问题**：译窄 — `vippakāraṃ` 译「羞辱」。nissaya 作 `ဤမာတုဂါမ နောက်ကလိုက်သောအားဖြင့် ဖောက်ပြန်သောအခြင်းအရာ`（被女人跟随这种反常的境况），所指是那桩怪异遭遇本身，不只是受辱。
- **建议**：改为「才落到这种反常的境地」或「才遭遇这种怪事」。
- **问题**：添义 — `mā … kiñci kathehi` 是“不要说什么”，nissaya 作 `တစုံတခုသော စကားကို … မဆိုလင့်`。译「争辩」是添加的意思，也和前文 kathesi 译「说」不一致。
- **建议**：改为「不要再对比丘们说什么」。
- **问题**：轻度添补 — 「这两首偈颂」中的「两」，原文 `imā gāthā` 并未明说。按 Dhp 133–134 确实是两偈，补出无误。
- **建议**：可以保留。
- **问题**：nissaya 多出成分 — nissaya 有 `တံ ဩဝဒန္တော`（为了教诫他），原文无对应词（taṃ ovadanto）。疑为 nissaya 所据底本异读，记录备查，译文不必补。
