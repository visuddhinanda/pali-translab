# Review — 122:48-53（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 —（本块就是义注层）／复注 ❌（本书没有对应复注）
> **父层（本文）译文没有注入**：被解释词与父层逐字同译这一项**无法核查**。本块是故事叙述，里面的黑体（ganthadhuraṃ / vipassanādhuraṃ）是故事内部的定义用语，不是从本文引出的被解释词，所以这一缺项对本块影响有限。

## 跨段一致性

- **tāta（兄长称呼弟弟）**：§48 句 136-160、219-231、232-255、269-299 和 §51 句 2-23 都译成“孩子”。这几处统一，但译错了：nissaya 是 `တာတ= ငါ့ညီ!`（我的弟弟）。哥哥叫弟弟“孩子”会让读者误以为是父子 → **必改**，五处统一改为“弟弟”。
- **vatta / iriyāpatha 都译成“威仪”**：§52 句 27-90 把 vattasampanne 译为“威仪具足”，§53 句 48-68、140-155 把 iriyāpatha 也译为“威仪”（四威仪、三威仪）。两个不同术语共用一个译名，读者会把“威仪具足”理解成行住坐卧。nissaya：`ဝတ္တသမ္ပန္နေ= ကျင့်ဝတ်နှင့်ပြည့်စုံကုန်သော`（具足行仪/义务）→ **必改**，vatta 改译“行仪”，“威仪”只留给 iriyāpatha。
- **弟弟对哥哥的称呼“您 / 你”混用**：§48 句 161-171 用“您”，句 182-218 和 256-268 用“你”。巴利原文 tvaṃ / tumhe 本来就混用，但中文同一人物在同一场对话里改口很显眼 → 建议统一。弟弟称哥哥用“你”较自然，这样 161-171 就改为“那你要做什么呢？”。
- **dhamma**：§48 句 232-255 译“法”，§50 句 2-11 译“正法”。后者多加了“正”字 → 建议统一为“法”（见下）。

## §48 句 122-48-232-255
- **问题**：语法误读。atisaṇhasukhumaṃ 是宾格，修饰 tilakkhaṇaṃ，不修饰 dhammo。nissaya：`အတိသဏှသုခုမံ= အလွန်သိမ်မွေ့နူးညံ့သော။ တိလက္ခဏံ= သုံးပါးသောလက္ခဏာသို့`，意思是“极精细微妙的三相”。译文把“极其精细微妙”安在法上，“带入了三相”也不通顺。
- **建议**：“因为大师所说的法，把极其精细微妙的三相贯穿在里面，初善、中善、后善，住在家里的人没办法圆满它。弟弟，我要出家。”

## §48 句 122-48-136-160
- **问题**：(1) tāta 误译为“孩子”（见跨段一致性）。(2) saviññāṇaka / aviññāṇaka 译成“有情识的 / 无情识的”偏生硬。nissaya 给出的是 `သက်ရှိ / သက်မဲ့`（有生命 / 无生命，指奴仆牲畜与器物）。
- **建议**：“弟弟，我在这个家里的一切财产，不论是有生命的还是没有生命的，全都交给你负责，你好好管理吧。”

## §48 句 122-48-269-299
- **问题**：samaṇapaṭipattiṃyeva 的 -yeva 是“只”。译文“一定要圆满”换成了决心语气，丢了“只做这件事”的对比（对比的是不听弟弟、不留在家）。另外 tāta 也要改。
- **建议**：“……所以我不听你的话，我只要圆满沙门的修行。”

## §48 句 122-48-84-87 / 88-99
- **问题**：轻微。āha 在这里是提问，nissaya 作 `မေးတော်မူပြီ`（问），译文前句作“对他说”。
- **建议**：可改为“于是大师问他”。不改也不算错。

## §49–50 句 122-49-2-9 / 122-50-2-11
- **问题**：(1) 句法归属：nissaya 把 `ယဿ=အကြင်သူ၏` 接在 §49 的 hatthapādā 上，意思是“谁的手脚被衰老摧残”，§50 的 so 再承接这个人。译文把“一个人”移到下句，偈意没有错，可以保留。(2) dhammaṃ 译“正法”属于添义。
- **建议**：下句改为“一个人气力已经衰败，又怎么能修行佛法？”，或直接作“修法”。

## §51 句 122-51-2-23
- **问题**：tāta 误译“孩子”（见跨段一致性）。
- **建议**：“他说：‘弟弟，我还是要出家。’……”

## §51 句 122-51-63-105
- **问题**：误译。khayavaya 是“灭尽与坏灭”，不是“生灭”（那是 udayabbaya）。nissaya：`ခယဝယံ= ကုန်ခြင်း,ပျက်ခြင်းအာရုံရှိသော ဝိပဿနာဘာဝနာကို။ ပဋ္ဌပေတွာ= ဖြစ်စေ၍`，即“发起以灭尽、坏灭为所缘的观修”。nissaya 的句法注还特别否定了“使灭尽坏灭生起”的读法，因为灭尽坏灭是自然发生的，不是被造出来的。“确立生灭”既把所缘译错，也把 paṭṭhapetvā 译窄了。此外 sātaccakiriyavasena 是“持续不断地修”，译文加了“精进”，属于小幅添义。
- **建议**：“……在自身上发起观照灭尽与坏灭（khayavaya）的观，持续不断地修习，使观增长，证得阿罗汉果，这叫做**观禅责任**。”

## §52 句 122-52-27-90
- **问题**：(1) vattasampanne 译“威仪具足”，与 iriyāpatha 撞名（见跨段一致性）。(2) “建立在三皈依上”是翻译腔。
- **建议**：“村民一见到这些行仪具足的比丘……我们就会立足于三皈依，受持戒律。”

## §53 句 122-53-78-92
- **问题**：轻微。“难道不应该不放逸吗”是双重否定，读起来拗口。
- **建议**：“贤友们，这样合适吗？我们不是应该不放逸吗？”
