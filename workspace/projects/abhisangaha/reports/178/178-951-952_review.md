# Review — 178:951-952（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层对照（178:27-28 定稿译文）✅／nissaya ❌（未提供，词级格位判断仅据巴利语法，未经 nissaya 核对）／上层释义标准 ❌（本层即义注，无更高层释义可对）

## 被解释词核对（对父层）

- `pāpāhetukamuttāni`：父层译“除去恶（不善）心和无因心以外的心”，178-952-2-21 黑体译“**除去恶（不善）心和无因心以外的心**” → ✅ 逐字相同
- `sobhanānī(ti)`：父层黑体“**美心**”，178-952-22-53 黑体“**美心**” → ✅
- `vuccare`：父层译“被称为”，178-952-22-53 黑体“**被称为**” → ✅（语序也与父层“被称为美心”一致）
- `ekanavutipi`：父层译“也可以说有九十一种”，178-952-22-53 黑体只取“**九十一种**” → 核心词相同，但 `-pi` 在父层译作“也”，此处黑体与正文都没译出 → 见下文建议，非必改

## 跨段一致性

- pāpa（恶）：父层和 178-952-2-21 都作“恶（不善）心”，178-952-22-53 作“这些恶心和无因心” → 建议统一为“恶（不善）心”。理由：一是与父层一致；二是现代汉语“恶心”会被读成“想吐”，必改（见下）
- sobhana 作名称（vohāra）：178-952-2-21 作“确立‘美’这个名称”，父层与 178-952-22-53 都作“美心” → 建议改为“确立‘美心’这个名称”，或保留“美”但补夹注“‘美’（sobhana）这个名称”。要点是让读者看出这里讲的就是父层的“美心”

## §952 句 178-952-22-53

- **问题**：误读（句法） — `Attanā adhisayitassa apāyādidukkhassa pāpanato pāpehi`。`attanā` 是具格（施事），`adhisayitassa` 是过去分词属格，意思是“被它（恶心）所占据、所依附的那个〔人／相续〕”。全句意为：恶心把被它占据的人引向（pāpana）恶趣等痛苦，所以叫“恶”（pāpa）。译文“会导致自身所蕴含的恶趣等痛苦”把 `attanā adhisayita` 读成了修饰“痛苦”，意思偏了。（无 nissaya，格位判断仅据巴利语法，宜在有 nissaya 时复核）
- **建议**：改为“由于它会把被自己占据的人引向恶趣等痛苦，所以称为恶”。最好把 pāpana／pāpa 的词源双关点出来，例如“由于会引向（pāpana）……所以称为恶（pāpa）”，否则读者看不出为什么“导致痛苦”就叫“恶”

- **问题**：措辞歧义（必改） — “脱离了这些恶心和无因心的心”中的“恶心”在现代汉语里首先读作“想吐、厌恶”
- **建议**：改为“脱离了这些恶（不善）心和无因心的心”，与父层一致

- **问题**：漏译（轻微） — `ekanavutipi` 的 `-pi`（也）没有译出。父层作“也可以说有九十一种”
- **建议**：可改为“……分为五种，也就有**九十一种**心”。黑体只覆盖“九十一种”即可，与父层核心词保持一致

- **问题**：释词用词（轻微） — `vuccare kathīyanti` 是用同义词解释“被称为”。“被说成”口语化，而且带“被误说成”的贬义色彩
- **建议**：改为“‘被称为’就是被叫作、被说为的意思”，或“‘被称为’意思是被这样称说”
