## 理由
- **资源降级**：本次只注入了巴利原文和译文，**没有义注，也没有 nissaya**。准确性只能凭巴利原文本身的句法和上下文论证判断，无法按义注核对取义，也无法按 nissaya 逐词核对格位和覆盖面，所以信心指数压低。另外，注入头注明本层为义注，但各条 `layer` 字段写的是 `mula`，标注不一致。父层（《摄阿毗达摩义论》本文）也没有注入，所以 932 段中被解释词“寿尽 / 业尽 / 俱尽 / 横断”是否与父层逐字同译，**无法核验**。这一项需要在 harmonize 的两层配对结果里另行确认。
- **准确性**：论证链条整体译得清楚，包括女人不生为大梵天、梵辅天归入梵众天、驳《摩尼宝箧》、四种死、寿劫三因素、佛寿等部分。主谓宾判断没有发现错误，也没有违背教理的地方。
  - 主要问题在 932-49-69：“内外”（ajjhattabahiddhābhūte）修饰全部的危及生命的障碍，译文只让它修饰“疾病”，属于修饰关系错误。
  - 921-34-46 补出“将来会”，是对 anantare bhave 与 akaniṭṭhe nibbattamānāpi 关系的一种解读。它与 926 段的释文一致，取义合理，但没有义注或 nissaya 佐证，这里只注明分歧，不扣分。
  - 923-17-27 的“单独列出”是对 vuttattā 的引申，没有偏离论证方向，不扣分。
- **风格**：通篇是现代书面汉语，没有成段的文言。只有零星单音节文言词（“诸”），一处句式杂糅（“岂不是才合理”），以及少数用词生硬（“连读成”“势头”“在定上圆满实践”）。
- **一致性**：术语前后统一，包括梵众天 / 梵辅天 / 大梵天 / 统领者 / 八等至 / 一切知佛陀 / 寿命期。同层被解释词与引文基本逐字对应：922 的“梵天 / 梵天的随众”对应 923；921-52 的“成为梵天”；925 与 926 对应。唯一的不一致是 nibbattanti 在“投生在”和“生在”之间混用。

## 问题清单

### 🟧 error
- `23-932-49-69`｜错译（修饰关系）｜片段「引发内在和外在的种种疾病、陷入地中、遭受雷击等危及生命的障碍」
  - 问题：ajjhattabahiddhābhūte 修饰整个 jīvitantarāye（疾病属内，陷地、雷击属外）。译文把“内在和外在的”只挂在“种种疾病”上，读起来像是疾病分内外，陷地、雷击被排除在“内外”之外。
  - 建议：改为“引发种种疾病、陷入地中、遭受雷击等内在和外在的危及生命的障碍”。

### 🟨 warning
- `23-923-17-27`｜不导致误解的汉语语病｜片段「岂不是才合理」
  - 问题：反问“岂不是”与限定“才”杂糅，句式不通。
  - 建议：改为“岂不是更合理”或“才是合理的吧”。
- `23-921-52-67`｜文言语体｜片段「诸义注」
  - 问题：“诸”是单音节文言词。
  - 建议：改为“各部义注”或“义注”。
- `23-931-37-45`｜文言语体｜片段「下层诸地」
  - 问题：“诸”是单音节文言词。
  - 建议：改为“下层各地”或“较低的各个界地”。

### 🟦 suggestion
- `23-921-2-15`｜语言表达不够流畅｜片段「即使属于会退失的一类」
  - 问题：kuppadhamma 指禅会退失。“会退失的一类”没有说出退失什么，读者不易理解。
  - 建议：改为“即使禅定会退失”。
- `23-921-28-33`｜语言表达不够流畅｜片段「在定上圆满实践的人」
  - 问题：搭配生硬。
  - 建议：改为“在定学方面圆满实践的人”。
- `23-925-2-18`｜语言风格不统一｜片段「也只生在梵众天中」
  - 问题：同段的 nibbattanti 在其他各句都译作“投生在”，这里作“生在”。
  - 建议：统一为“也只投生在梵众天中”，同时检查 926 被解释词的引法是否需要随之调整。
- `23-932-2-10`｜语言表达不够流畅｜片段「应当连读成」
  - 问题：yojetabbaṃ 指把本文的具格词与“死”搭配起来解读。“连读成”意思不明。
  - 建议：改为“应当这样搭配理解：……”。
- `23-932-11-25`｜语言表达不够流畅｜片段「称为**寿尽**的**死亡**」
  - 问题：“寿尽的死亡”读来生硬，同样的问题也出现在 932 段其余三种死的定名句。由于涉及与父层逐字同译，需要先核对父层译法再定。
  - 建议：如果父层作“寿尽死”等，就改为“称为**寿尽**之**死**”以外的现代说法，例如“称为**寿尽**而**死**”，并与父层对齐。
- `23-932-49-69`｜语言风格不统一｜片段「使有情的五蕴相续在中途被截断」
  - 问题：原文是 khandhasantāna，没有“五”。横断死不限于五蕴有情，补“五”属于多补。
  - 建议：改为“使有情的蕴相续在中途被截断”。
- `23-932-84-93`｜语言表达不够流畅｜片段「按它本身的势头而耗尽」
  - 问题：“势头”偏口语，对 sarasa 的表达不够准确。
  - 建议：改为“按它自身的作用自然耗尽”。
- `23-933-2-6`｜复杂的嵌套句整句语言逻辑理解困难｜片段「所有的一切知佛陀」
  - 问题：容易被读成“所有的一切 / 知佛陀”。
  - 建议：改为“一切知佛陀全都本来有阿僧祇的寿命”。
