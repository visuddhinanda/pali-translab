## 理由

**资源情况**：本次注入的只有待评层（标为义注层，内容为 Paramatthadīpanī 对 Abhidhammatthasaṅgaha 第四品安止心路的解释）的巴利原文与译文。**没有注入它所解释的父层（本文）、义注标准和 nissaya**。因此评估退化为纯巴利对读，有两点无法验证：
- 词法和格无法逐词核对 nissaya；
- 被解释词与父层是否逐字同译无法核对，包括 716-41-51、716-52-62、716-169-174 的黑体引文，以及 716-30-40 的“因为在这里”。

信心指数因此压低。

**准确性**：全段主干判断正确，没有发现主谓宾误判或违背教理的地方。几处关键论证都译得准确：
- “仅”（eva）字的两重排除（第五、第二个心不能成为种姓）；
- “或”（vā）字区分慧钝与慧利；
- 《殊胜义注》的五次说被其他义注否定；
- 遍作、近行、随顺、种姓四名的词源解释。

扣分点有三处：
- 716-41-51 的黑体引文没有译出属格 aṭṭhannaṃ（“八种……之中”）；
- 716-117-120 在译文正文里增补了“即欲界”；
- 716-121-126 的 ettha 译成“在这里”，指代含糊。

**风格**：整体是现代书面汉语，通顺。发现一处文言虚词“之”（716-194-201）。716-52-62 的语序略显生硬。

**一致性**：
- gotta 译“族姓”、gotrabhū 译“种姓”，两者各自前后一致。但 gotrabhū 的词源（gotta + abhibhū）在汉译里断开了，读者看不出“种姓”是“胜过族姓”的意思，需要加注。
- “慧钝 / 慧利 / 慧力中等 / 慧大”的构词不统一。
- 716-154-159 与 716-160-168 之间的引号跨句开合，这是句级切分造成的，单句显示时引号不配对。暂不立条，提请 harmonize 留意。

**段尾**：717-2-4 与 718-2-18 是 “yaṃ pana … vuttaṃ” 关系从句，主句（taṃ …）应在第 719 段。译文在 718 句末用了句号，读起来是残句。

## 问题清单

### 🟨 warning
- `23-716-194-201`｜文言语体｜片段「更高之地」
  - 问题：“之”作文言虚词，违反现代书面汉语硬约束。
  - 建议：改为“更高的界地”或“更高的地”。
- `23-716-121-126`｜关键词语意不明确，或二意场合没有注释｜片段「族姓在这里被胜过、被截断，所以叫种姓（gotrabhū）」
  - 问题：gotrabhū = gotta（族姓）+ abhibhū（胜过）。汉译“族姓”与“种姓”字面上看不出这层联系，词源解释对读者失效。
  - 建议：加脚注，说明 gotrabhū 由 gotta（族姓）与 abhibhū（胜过）构成，意为“胜过（欲界）族姓者”。
- `23-716-121-126`｜代词指代不明确｜片段「在这里」
  - 问题：etthāti 指“在此（心）中”，即在该速行心里族姓被胜过。“在这里”容易被误读为“在这段文字里”，而本段其他地方的“这里”恰好都是这个意思。
  - 建议：改为“族姓在这个心中被胜过、被截断”。
- `23-718-2-18`｜整句逻辑表达不规范｜片段「无法以安止的方式安住”。」
  - 问题：717–718 是 yaṃ … vuttaṃ 关系从句，主句在后文。句末用句号使“至于在《阐明疏》中所说的……”成了残句。
  - 建议：句末改为逗号或冒号，与第 719 段的主句衔接。若 719 段由下一 chunk 处理，harmonize 时一并核对。

### 🟦 suggestion
- `23-716-41-51`｜语言表达不够流畅｜片段「**八种智相应欲界速行**」
  - 问题：巴利 kāmāvacarajavanānamaṭṭhannaṃ 是属格（“八种……的／之中”），译文省去了，与本文“aṭṭhannaṃ aññatarasmiṃ”的语法关系不明。另外，与父层是否逐字同译，因缺父层未能核对。
  - 建议：对照本文译法，统一为“八种智相应欲界速行中”或与本文完全一致的措辞。
- `23-716-52-62`｜语言表达不够流畅｜片段「凭借诸根平衡等从四周各方面，安止由它而被造作、被准备」
  - 问题：状语前置后再接被动主句，语序生硬，“凭借”与“由它”两个工具成分并列，容易混淆。
  - 建议：改为“安止由它凭借诸根平衡等四周各方面而被造作、被准备，所以叫遍作”。
- `23-716-117-120`｜语言表达不够流畅｜片段「也就是被称为“小”（paritta，即欲界）这一类别的族系」
  - 问题：句子缺主语，承接不明（实指上句的 gotta）。“即欲界”是正文增补的解释，宜移入注释。
  - 建议：改为“这里的族姓，就是被称为‘小’（paritta）这一类别的族系”，“小”即欲界放进脚注。
- `23-716-247-259`｜语言风格不统一｜片段「慧力中等」
  - 问题：同段“慧钝、慧利、慧大”都是“慧＋形容词”结构，“慧力中等”打破了这个格式。
  - 建议：改为“慧中等”或“中慧”，与同组用词保持一致。
