## 理由

**资源情况**：本次只注入了巴利原文与待评译文，**没有义注基准，也没有 nissaya**。本层就是被评估的注释书本身（《胜义灯》），上方没有另一层义注可作释义标准。因此评估降级为**纯巴利对读**：格位与句法角色按原文自行判断，没有逐词基准可比。父层（《摄阿毗达摩义论》本文）的译文也没有注入，所以**被解释词与父层是否逐字同译无法核验**。凡涉及被解释词的条目，都只就本层内部是否自洽来提。这些因素拉低了信心指数。

**准确性**：
- 整体取义准确，以下几处论证都译得清楚，没有发现主谓宾判断错误或违背教理的地方：
  - 对《阐明》(Vibhāvanī) 的三处驳议（533、537-538、547）的论证脉络
  - 受的二、三、五、六、十八、三十六、一百零八种分类
  - 五十五个舍俱心的计数（32 欲界 + 23 第五禅）
- 原文有几处疑似讹误，译文都按合理读法处理了，可取：
  - 534-20-26 的 `nīhoti`，当作 nīto hoti
  - 544-15-28 的 `sukhadukkhato manassa domanassa`，当作 sukha-dukkha-somanassa-domanassa
- 543-2-14 所引《阐明》作 `kāyika mānasika sātabhedato`，只有 sāta（适意）而没有 asāta。译文照字面译成“属身的适意与属心的适意”，把苦也放进了“适意”的分类里，义理上说不通。疑似原文脱漏 `asāta`，建议核对别本后决定是否加注。这里按原文直译，不扣准确性分。
- 主要扣分点：531-32-40 增出“这些分类”，把被阐述的对象“摄类”改成了“分类”。

**风格**：
- 现代书面汉语总体达标，没有成片的文言句式。
- 个别地方读起来不清楚：
  - “只依心生起”有歧义
  - “依分别想”含义不明
  - 541-99-105 的“这些法”指代不明
  - “在一个心中”是指在单单一个心里：被解释词和释文同义反复
- “按其相应情况彼此相应”中“相应”重复，读来拗口。

**一致性**：
- 统一得较好的方面：
  - 六种摄类的名称
  - “受的摄类 / 因的摄类”的定义句式
  - 《阐明》的书名
  - “心生起”(cittuppāda)
  - “属身的 / 属心的”
- 不统一的方面：537 与 547 是平行的两条《阐明》定义，一处用“依……的区分”，一处用“按……来区分……来归类”，句式不一致。

## 问题清单

### 🟧 error
- `23-531-32-40`｜错误多译｜片段「来阐述这两者名为摄类的这些分类」
  - 问题：原文 `saṅgaho nāma nīyate` 的主语是单数的“所谓摄类”。译文增出“这些分类”，并且让它取代“摄类”成了被阐述的对象，偏离了原句结构。
  - 建议：改为“现在按适当的情况，来阐述这两者所谓的摄类”。

### 🟨 warning
- `23-531-96-101`｜关键词语意不明确｜片段「“**只依心生起**”」
  - 问题：被解释词 `cittuppādavaseneva` 的意思是“只就心生起（心起）而言”。“只依心生起”容易被读成“只依靠心的生起”这一动作，与下文释义“只依心来阐述”衔接不上。这个词也是 533、534 两处驳议的焦点。
  - 建议：改成“只依心生起（的方式）”或“只就心生起而言”。需要与父层被解释词同步调整，由 harmonize 统一。
- `23-541-99-105`｜代词指代不明确｜片段「这些法也有两种」
  - 问题：原文 `tepi` 承接的是上句“舍所主导的那些法”。可是 541-77-88 刚用“这些法”指过乐、苦所主导的法，两处容易混淆。
  - 建议：改为“舍所主导的那些法也有两种”。
- `23-544-29-33`｜整句逻辑表达不规范｜片段「“**在一个心中**”是指在单单一个心里」
  - 问题：被解释词 `ekattha` 本义是“在一处”。译文把释文的“心”提前放进了被解释词，结果释义变成同义反复，看不出注释到底解释了什么。
  - 建议：被解释词按字面作“**在一处**”，释文作“是指在一个心中”。需要与父层被解释词对齐。
- `23-544-9-14`｜关键词语意不明确｜片段「依分别想」
  - 问题：`parikappanato` 指凭主观设想或构想（与“依自性”相对）。“分别想”不是通行术语，读者难以理解。
  - 建议：改为“依主观设想”，或者加注说明。

### 🟦 suggestion
- `23-531-2-19`｜语言表达不够流畅｜片段「按其相应情况彼此相应」
  - 问题：“相应”连用两次，`yathāyogaṃ` 的意思也没有译清楚。531-20-31 用的是同一译法。
  - 建议：改为“按其适当情况彼此相应”或“各依所宜而相应”。被解释词须与父层同译，应在本文层定案后由 harmonize 统一。
- `23-531-47-51`｜语言表达不够流畅｜片段「意思是说，各种法各自独有的特相。」
  - 问题：句子缺少判断成分，读着像半句话。
  - 建议：改为“意思是说，自性就是诸法各自独有的特相”。
- `23-543-2-14`｜不常用术语编写注释或者百科｜片段「按属身的适意与属心的适意来分类」
  - 问题：原文只有 sāta 而缺 asāta，把苦也归到“适意”之下，读者会困惑。
  - 建议：核对别本。若确有脱漏，就加脚注说明疑作 sātāsāta。
- `23-541-13-24`｜不常用术语编写注释或者百科｜片段「依家的有六种、依出离的有六种」
  - 问题：gehassita / nekkhammassita 直译为“依家的 / 依出离的”，普通读者不易理解。
  - 建议：首次出现时夹注巴利原词，或者简注“依家的，指依于欲乐世俗生活”。
- `23-547-2-13`｜语言风格不统一｜片段「按贪等因来区分，以及按与它们相应的法来归类而作的摄类」
  - 问题：与平行的 537-2-13（“依乐等受以及与它们俱行的心生起的区分而作的摄类”）句式不一致，而且增出了“来归类”。
  - 建议：比照 537 统一为“依贪等因以及与它们相应的法的区分而作的摄类”。
