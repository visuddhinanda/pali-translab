## 理由

**资源降级**：本次只注入了巴利原文与待评译文，**没有义注释义标准，也没有 nissaya 词级基准**。因此本次只按巴利原文核对，格与句法角色缺少 nissaya 佐证，信心指数相应压低。另外，本段文本（Paramatthadīpanī）自身是对《摄阿毗达摩义论》的解释，黑体被解释词（**地**、**善趣**、**地狱**、**畜生类**、**饿鬼境域**、**阿修罗众** 等）应与父层逐字同译，这一点本次无法读到父层，未能核对。

**准确性**：整体取义可靠，几处难点处理得好：
- 778-2-11 把讹断的 `tāva tiṃsesu` 正确识读为 Tāvatiṃsa（三十三天），没有把 tāva 另译。
- 777 段“五种阿修罗”的五项（毗摩质多罗等、堕处、有宫殿饿鬼、世界间地狱众生、迦罗坎奇迦饿鬼）与原文逐一对上。
- 777 段 peta 一般义译“亡者”，`idha pana` 之后的特指义转为“饿鬼”，分层合理。
- 773、774 两个长句的论证链条（《阐明疏》之说被驳 → 驳论理由）也还原到位。

扣分主要在两处：
- 778-29-57 的偈句名单中 `nottica` 未在译文里体现，`pettirājā` 是独立一项还是毗沙婆的同位称号也有疑问。原文疑有讹误，须用 nissaya 或别本确认。
- 777-28-41 的 `sukhasamussaya` 直译为“安乐的积聚”，义不明。

**风格**：全篇为现代书面汉语，未见文言虚词或文言句式。偶有“依…而宣说”这类偏书面的搭配，尚不到文言程度。标点全为全角，引号统一用弯引号，没有工作标记残留。
- 扣分点一：“转起”在本段兼指“转起时（pavattikāla，结生与死亡之间的生命期）”与“转起摄”。首次出现没有任何说明，普通读者难以区分。
- 扣分点二：778-29-57 嵌套过深。

**一致性**：以下译名前后一致：
- ussada 均作“小地狱”（778-68-88 与 778-118-130）
- yoni / visaya / kāya 均作“类 / 境域 / 众”
- 《阐明疏》在 772、775 两处一致

夹注巴利词在 777-64-80 与 777-81-84 对 sura 重复出现，属小瑕疵。

## 问题清单

### 🟧 error
- `23-778-29-57`｜漏译｜片段「也就是《论事》圣典中提到的毗沙婆、饿鬼王、苏摩、阎魔、毗沙门王等名字所指的那些」
  - 问题：原文 `vessabhū nottica petti rājā` 中的 `nottica` 在译文中没有对应。`pettirājā` 被译成独立的一项“饿鬼王”，但它也可能是毗沙婆的同位称号（“毗沙婆，饿鬼之王”）。原文疑有讹误，本次没有 nissaya，无法定案。
  - 建议：用 nissaya 或别本核对 `nottica` 与 `pettirājā` 的读法与归属。若 pettirājā 是同位语，应改为“饿鬼之王毗沙婆、苏摩、阎魔、毗沙门王”一类结构。

### 🟨 warning
- `23-771-2-16`｜关键词语意不明确，或二意场合没有注释｜片段「像这样在转起时显示了转起摄之后」
  - 问题：同一句里两个“转起”指不同的东西。`pavattikāla` 指结生与死亡之间的生命进程期，`pavattisaṅgaha` 指“转起摄”这一摄类。首次出现没有说明，读者容易把“转起时”和“转起摄”混为一谈。
  - 建议：首次出现时为“转起时”加脚注或简注，说明它指结生、死亡以外的生命期间（巴利 pavatti）。

- `23-777-28-41`｜关键词语意不明确，或二意场合没有注释｜片段「安乐的积聚」
  - 问题：`samussaya` 在此语境中常指身体或生存状态。直译为“积聚”，读者看不出“死后离开了安乐的积聚”说的是什么。
  - 建议：改为“离开了安乐的生存（身）”之类，或加注说明 sukhasamussaya 所指。

- `23-773-2-28`｜不导致误解的汉语语病｜片段「取了结生也就包括了死亡时」
  - 问题：“包括了死亡时”搭配别扭，宾语悬空。
  - 建议：改为“取了结生，也就把死亡时包括进来了”。

- `23-778-29-57`｜整句逻辑表达不规范｜片段「至于诸阎魔王，也就是《论事》圣典中提到的毗沙婆、饿鬼王、苏摩、阎魔、毗沙门王等名字所指的那些——毗沙婆等本身虽然」
  - 问题：主语“诸阎魔王”先被同位语打断，再用破折号另起“毗沙婆等”作主语，读者要回头重读才能接上主谓。
  - 建议：拆成两句，例如：先说“《论事》中以……等名字提到的就是诸阎魔王。”再接“毗沙婆等虽然……，但出于悲悯……也在下方的地狱世界中执掌统治。”

### 🟦 suggestion
- `23-771-17-23`｜语言表达不够流畅｜片段「（udīrito，也就是“说过”）」
  - 问题：这是原文 `udīrito kathito` 的同义词释，用夹注插进正文，读起来像校勘记。
  - 建议：正文只保留“宣说”，同义词释可省略或改为脚注。

- `23-778-89-100`｜代词指代可能不够明确｜片段「上方阎魔王们的命令」
  - 问题：`upari` 这里多半是“在他们之上（统辖）”，不一定指空间上的“上方”。而上一段刚说阎魔王在“下方的地狱世界”执掌统治，“上方”容易让读者读出矛盾。
  - 建议：改为“他们之上的阎魔王们的命令”或“统辖他们的阎魔王们的命令”。

- `23-778-68-88`｜不常用术语编写注释或者百科｜片段「《离婆多天宫》」

  - 建议：改为“《佛种姓义注》的因缘部分中”。

- `23-777-81-84`｜语言风格不统一｜片段「不是天神（sura）」

  - 建议：删去此处的“（sura）”，只保留“阿修罗”（asura）的夹注。
