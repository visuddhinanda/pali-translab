## 理由

**资源情况**：本次只注入了巴利原文和待评译文，没有义注释义标准，也没有 nissaya 词级基准。因此准确性只能按巴利原文直接核对，无法逐词比对格和句法角色，信心指数相应下调。另外两点需要交代：
- 注入说明把本段标为「义注」，但记录里的 `layer` 字段是 `mula`。《胜义灯》（Paramatthadīpanī）通常被视为《摄阿毗达摩义论》的复注。
- 父层文本没有注入，所以「被解释词与父层逐字同译」这条硬约束无法核验。涉及的黑体词有：昏沉、睡眠、疑、信、念、惭、愧、无贪。

**准确性**：整体取义可靠，没有发现主谓宾误判或违背教理的句子。以下几段处理得当：
- 不如实恶作的两种情形（466-79-92、466-93-106）
- 律的恶作与疑的关系（466-169-221）
- 昏沉、睡眠分别压制心与心所（468）
- 疑与信的「相似」型（paṭirūpaka）区分

主要问题是 466-14-17。原文只有 `vuttaṃ`，没有指明出处，译文却补出「圣典中」。「dvīhākārehi（以两种方式）」的说法更像出自义注（如《殊胜义》），所以标为疑似误指出处，需要核对。466-33-38 所引「我没有做身善行，我做了身恶行」可对应增支部二集《令热恼经》，在那里说「圣典中」可以接受。

**风格**：现代书面汉语执行得好，没有发现文言虚词或文言句式（「其中」是现代用法，不扣分）。全角标点和弯引号都符合规范。存在以下几类小问题：
- 「对……当作……」这类搭配不当（466-79-92、466-110-120）
- 少数长句层层嵌套，主语出现得很晚（478-8-31）
- 「套用理解」偏口语，与上下文语体不太一致

**一致性**：
- 词源释义中 cikicchā 先译「治」，后文又用「医治」，削弱了 vi + cikicchā 的构词呼应。
- 法相术语首次出现时夹注巴利原词的做法不统一：「疑」带了夹注，昏沉、睡眠、信、念、惭、愧、无贪都没有。
- 「相似的疑 / 相似的信 / 相似的念 / 相似的惭愧」对 paṭirūpaka 的译法统一，值得肯定。

## 问题清单

### 🟧 error
- `23-466-14-17`｜错误多译｜片段「因为圣典中说的是」
  - 问题：原文仅 `hi vuttaṃ`，没有指明出处。「dvīhākārehi」疑出自义注而非三藏圣典，补出「圣典中」可能误指出处。
  - 建议：改为「因为（论中）说的是“以两种方式”」或直接写「因为说的是“以两种方式”」。核实出处后再决定是否点明。

### 🟨 warning
- `23-469-9-11`｜关键词语意不明确｜片段「医治就叫作治（cikicchā）」
  - 问题：cikicchā 在此译「治」，到 23-469-16-22 又写成「医治已经离开了它」。同一个词前后两译，读者看不出 vicikicchā = vigata + cikicchā 的词源呼应。
  - 建议：统一用「医治（cikicchā）」，例如「医治叫作 cikicchā」；后文保持「医治已经离开了它」。
- `23-466-110-120`｜不导致误解的汉语语病｜片段「对没有过失的事当作有过失，对合宜的事当作不合宜，对不犯当作犯」
  - 问题：「对……当作……」搭配不当。
  - 建议：「把没有过失的事当作有过失，把合宜的事当作不合宜，把不犯当作犯」。
- `23-466-79-92`｜不导致误解的汉语语病｜片段「先前对善业也当作恶、看成恶而没有去做，对恶业也当作善、看成善而去做了」
  - 问题：同上，「对……当作」搭配不当。
  - 建议：「先前把善业也当作恶、看成恶而没有去做，把恶业也当作善、看成善而去做了」。

### 🟦 suggestion
- `23-466-110-120`｜语言风格不统一｜片段「等方式来套用理解」
  - 问题：「套用理解」偏口语，与上下文语体不协调。
  - 建议：「等方式类推」或「等方式来理解」。
- `23-466-79-92`｜语言表达不够流畅｜片段「就是这样的恶作：」
  - 问题：句首「就是这样的恶作：」与句尾「……而生起的恶作；」重复了「恶作」。
  - 建议：删去句首的「这样的恶作：」，改为「就是先前……后来因为懊悔而生起的恶作；」。
- `23-467-2-10`｜该使用而没有使用术语标记｜片段「所以叫作**昏沉**」
  - 问题：法相术语首次出现时没有夹注巴利原词。同类情况还有 23-468-2-13「**睡眠**」、23-471-2-7「**信**」、23-472-2-7「**念**」、23-473-2-8「**惭**」、23-474-2-8「**愧**」、23-478-2-7「**无贪**」。而 23-469-16-22 的「疑」带了夹注，前后做法不一。
  - 建议：确认这些词在本章是否首次出现；若是首次，统一夹注，如「**昏沉**（thina）」。
- `23-477-2-17`｜语言表达不够流畅｜片段「善人凭着惭对自己」
  - 问题：原文是 `yasmā … tasmā` 因果对举，译文只在后句保留了「所以」，前句缺少「由于 / 因为」。
  - 建议：句首补「由于」，即「由于善人凭着惭对自己……」。
- `23-478-8-31`｜复杂的嵌套句整句语言逻辑理解困难｜片段「因为对于自己认为有益、贪以执着的方式缠附在上面的那些所缘，无贪就在这些所缘上驱散那贪」
  - 问题：定语过长，主语「无贪」出现得太晚，读者难以一次读通。
  - 建议：拆成两句，例如：「因为贪会以执着的方式缠附在那些自己认为有益的所缘上；无贪就在这些所缘上驱散那贪，……」。
