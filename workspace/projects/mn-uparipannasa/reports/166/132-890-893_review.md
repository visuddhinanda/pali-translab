# Review — 132:890-893（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ✅（本层即义注）／父层对照 ✅（book 166，段 1134-1171）

## 一、被解释词与父层译文核对（首要项）

- **chadhāturo**（§890 句 132-890-2-7）：本层译“**六界具足者**”。父层（166-1140/1141）多次将同词译作“有六界”（如“这个人有六界”）。本层另一处（132-890-44-67）把同一词译成“具有六界”，与句 132-890-2-7 的“六界具足者”又不一致。→ **必改**：统一为贴近父层的“有六界（的人）”，不要新造“…具足者”这一名词化译法。

- **maññassa vā nappavattantī**（132-890-75-84）：本层译“我慢之流便不生起”。父层（166-1140-26-38）对应译文是“种种我慢之流便不再生起”。本层漏译“种种”与“再”。→ **必改**：补齐为“种种我慢之流便不再生起”，与父层逐字对齐。

- **muni santoti vuccatī**（132-890-85-93）：本层译“漏尽的牟尼被称为寂静、寂灭者”，父层（166-1140-26-38）对应译文是“就称为寂静的牟尼”。本层把落在“牟尼”上的核心称谓改成了“…者”，丢失了与父层一致的“牟尼”这一被解释词本身的译法。→ **必改**：核心句式应保留“称为寂静的牟尼”，可在其后另加“（漏尽、寂灭）”一类夹注来承载 nissaya 补充信息，不要把“牟尼”替换为“者”。

- **Paññaṃ nappamajjeyyā / Saccamanurakkheyyā / Cāgamanubrūheyyā / Santimeva so sikkheyyā**（132-890-94-130）：本层四句分别译“不应放逸于慧”“应守护真谛”“应增长舍”“应修学寂静”。父层（166-1140-39-67）对应译文是“不放逸于智慧，护持真谛，增长舍离，修学寂静”。差异点：
  - paññā：父层“智慧”，本层通篇（890-892 多处）用“慧”——**术语不一致**，见下方“跨段一致性”。
  - saccaṃ anurakkheyya：父层“护持真谛”，本层“应守护真谛”，动词选字不同，语体也不完全对齐。
  - cāgaṃ anubrūheyya：父层“增长舍离”，本层“应增长舍”，“舍离”被省成“舍”。
  → **建议**：这几处被解释词的核心名词/动词应与父层译文逐字一致（“智慧”“护持”“舍离”），本层可以加“应”字表述规范性语气，但核心词不应改动。

- **caturādhiṭṭhāno / yattha ṭhitan / phassāyatanan**：与父层核对一致，无问题。

## 二、跨段一致性

- **paññā（慧/智慧）**：父层统一译“智慧”，本层（890-892 全部相关句）统一译“慧”——两层用词系统性不一致，建议本层改回“智慧”以与父层保持被解释词逐字同译（见上）。
- **aṭṭhārasamanopavicāro**：父层（166-1143）译“十八种意的近伺察”，本层（132-890-44-67）译“十八意近伺察”，缺“种”“的”，与父层不完全逐字一致，建议对齐。
- **chadhāturo** 的译法在本层内部就不统一（“六界具足者” vs “具有六界”），见上第一条。

## §890 句 132-890-2-7
- **问题**：被解释词与父层不一致（见上第一条）
- **建议**：改为“有六界（的人）”一类贴近父层的译法
