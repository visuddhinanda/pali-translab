# Review — 166:278-281（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分段落含）／义注 ⚠️——未提供 book=166 本经的义注，仅注入了 book=132（另一部经 Sappurisadhammasutta）同类头陀支词条的平行义注，可作词义参考，但不能视为本经的正式释义标准。

## 跨段一致性

- 术语译法（āraññiko/paṃsukūliko/piṇḍapātiko/rukkhamūliko → 住阿兰若／穿粪扫衣／行乞食／住树下）四段内部前后一致，无漂移，无需改动。
- "attānukkaṃseti / paraṃ vambheti" → "抬高自己、贬低他人"，"nevattānukkaṃseti, na paraṃ vambheti" → "不因…而抬高自己，也不贬低他人"，四段统一，未见问题。
- "dhammānudhammappaṭipanno sāmīcippaṭipanno anudhammacārī" → "随法而行、如法而行、依法而行的人"，四段统一。
- **必改项（跨段共性问题）**：166-278/279/280/281 每段 nissaya 都带一条异释（ဝါ 形式的括注），指出 āraññiko / paṃsukūliko / piṇḍapātiko / rukkhamūliko 也可解作"受持该头陀支（dhutaṅga）的人"，而非仅"住/穿/行/住"字面义。跨经平行义注（132-262：`**Āraññiko**ti samādinnaāraññikadhutaṅgo.` = "受持阿兰若头陀支的人"）印证了这一异释才是传统正解的重心所在——巴利原文这几个词本身就是头陀支的专称，不是泛指居处/穿着/行乞习惯。现译文四处均只取字面异释（"住阿兰若的人"等），**丢失了头陀支（苦行/戒行）的含义，且按 `style.md` 规则异释应作脚注备列，目前完全未体现**。建议：
  - 主译改为体现头陀支义，如"受持阿兰若支的人"／"住阿兰若头陀行的人"（术语视后续统稿定案，四处需统一）；
  - 或维持字面主译，但按规范在四处各加一条脚注列出该异释来源（nissaya 括注 + 132 段平行义注）。
  - 因四段共用同一模式，此问题需一次性统一处理，不要分段各改各的。
