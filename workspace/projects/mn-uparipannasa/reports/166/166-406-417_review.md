# Review — 166:406-417（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ✅（部分句子无对应义注条目，已注明）

## 跨段一致性

- **taṇhacchido / vītarāgo / usabhacchidā / suvimuttacitto 等赞词的处理方式不统一**：
  义注（132-365）明确指出这类词是对**前一个专名的赞颂之辞（thuti）**，不是独立的第三人：
  - `Vītarāgo ti maṅgalassa thuti`（离贪者，是对满伽罗的赞叹）
  - `Suvimuttacitto ti ayaṃ kaṇhassa thuti`（心善解脱者，是对迦诃的赞叹）

  §414 译文正确地把 `suvimuttacitto` 处理成对“迦诃”的修饰（“以及迦诃佛，心已彻底解脱”），
  §407 也正确地把 `vītarāgo` 处理成对“曼伽罗”的修饰。**但 §406 把 `taṇhacchido`（断爱者）
  单独并列成第三个人名**（“优波尸企、断爱者、以及尸祗利”），与义注 132-365
  `Taṇhacchido ti sikharissāyaṃ thuti`（断爱者，是对尸祗利的赞叹）矛盾——这里只有
  “优波尸企”与“尸祗利”两个人，“断爱者”是尸祗利的修饰语，不该用顿号并列成独立条目。
  → 建议改译为：“优波尸企，以及断爱的尸祗利”（或类似句式，把“断爱者”依附到“尸祗利”上）。

- **§413 的 `vītarāgo` 译法与其余同段名字体例不一致**：本句 `Mānatthaddho sobhito vītarāgo`
  与 §411/§412 一样是并列人名的列举句式，“曼那塔他”“苏毗多”都是音译人名，唯独
  `vītarāgo` 被意译成“离贪欲者”而非音译成人名。若 `vītarāgo` 在此确是第三个人名
  （而非修饰前两者），应与其余两名同体例音译；若确认是修饰语则需要在句式上体现依附关系，
  不能用顿号并列。当前译法两头不靠，建议先核对 nissaya/其他版本确认 `vītarāgo` 在本句中的
  身份，再统一处理方式。

## §409 句 166-409-2-5

- **问题**：义注对照错误（必改项）——`opanīto` 被拆解漏译成人名。义注 132-365 明确：
  `Santaṃ padaṃ ajjhagamopanīto ti upanīto nāma so buddho santaṃ padaṃ ajjhagamā`
  （“证得寂静之处、优波尼多”：那位佛陀名叫优波尼多，因为他证得了寂静之处）。
  `-opanīto` 是专名“优波尼多”（Upanīto），不是被动动词“被引导到那里”。
  现译“证得了寂静之处，被引导到那里”把人名整个漏掉，变成了对同一件事的重复描述。
- **建议**：改为“证得了寂静之处的优波尼多”一类译法，把 Upanīto 作为人名译出，
  与 §406/§407/§414 对其他人名的处理方式保持一致。
