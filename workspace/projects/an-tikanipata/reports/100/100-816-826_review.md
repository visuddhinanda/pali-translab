- **ahampi dammo**：本层跟的是父层 §876 句 90-100，这没有问题。但父层在同一段的句 19-60 译成「小公牛」，前后两处不一致，导致对应关系不能唯一确定。这一点**需要交 harmonize 先统一父层**（nissaya `ဒမ္မော ဒမ္မမာနော= ဆုံးမလောက်သောနွား`，意为“可调教的牛”，支持「可调驯的牛」），本层保持不变。
- **diyaḍḍhasikkhāpadasataṃ**：父层的「多」来自 sādhikam，被拼进了被解释词中间，所以本层无法逐字截取。本层译「一百五十条学处」对应的是词本身，可以接受。建议在 harmonize 时确认是否在父层调整词序（例如「这些学处有一百五十多条」），让被解释词能完整地截出来。

## 跨段一致性

- **义注标题**：§817 / §819 / §821 作「……经义注」，§823 / §825 作「……经释义」 → 统一为「义注」。
- **段号格式**：§818 / §820 / §822 作「82. / 83. / 84.」，§824 / §826 作「八五、/ 八六、」 → 统一一种。父层同样混用（八二. / 84. / 八五、），建议一并统一。
- **经次引导语**：§818 / §820 / §822 作「第 N 经里」，§824 / §826 作「第 N 经中」 → 统一为「第 N 经里」。
- **释词格式**：「**X**，意思是……」（§818、§820、§822）、「**X**的意思是……」（§824、§826）、「**X**，指的是……」（§818 句 123-126）、「**X**就是……」（§824 句 13-17、52-56）、「**X**指的是……」（§826 句 56-60）五种混用 → 统一为「**X**，意思是……」。
- **missikāva kathitā**（nissaya `လောကီလောကုတ္တရာရောသည်သာလျှင်` = 世间出世间混合）：
  - §820 句 61-67、§822 句 32-37 作「讲说的也是世间与出世间混合的三学」；
  - §824 句 243-248 作「这里也是把三学混合在一起说的」，漏了“世间与出世间”，句式也不同 → **必改**，统一为「这里讲说的也是世间与出世间混合的三学」。
- **samaṇakaraṇīyāni**：§818 句 13-17 作「是沙门应做的」，句 110-118 作「沙门应做的」，父层作「沙门应当做的事」 → 统一为父层译法。
- **padaṃ**：§820 句 49-57 作「脚印」，父层 §876 作「足迹」 → 改为「足迹」。
- **sikkhitabba / sikkhati**：§818 句 67-80 作「学习」，§824 作「修学」，父层「学」「修学」并用 → 本层统一为「修学」。

## §818 句 100-818-2-12
- **问题**：被解释词不合父层。本层作「属于沙门」，父层作「沙门分内的事」。
- **建议**：「**沙门分内的事**，意思是属于沙门的东西。」释义部分与 nissaya `သမဏသန္တကာနိ= ရဟန်း၏ ဥစ္စာ`（沙门的所有物）相符。

## §818 句 100-818-13-17
- **问题**：被解释词不合父层。本层作「是沙门应做的」，父层作「沙门应当做的事」。改了之后，释义「沙门应当做的事务」与黑体几乎重复。nissaya 是 `သမဏေန= ရဟန်းသည်`（施事）+ `ကတ္တဗ္ဗကိစ္စာနိ= ပြုအပ်သောကိစ္စ`（应做之事）。
- **建议**：「**沙门应当做的事**，意思是由沙门来做的事务。」

## §818 句 100-818-67-80
- **问题**：指代不明。nissaya `တဒေဝ= ထိုအဓိသီလကိုပင်လျှင်` 指明 tadeva 是“正是这增上戒”。译文「正因为它」中的“它”容易被读成“一切戒”。「学习」也与本 chunk 的「修学」不统一。
- **建议**：「……出世间戒是增上戒；正是这增上戒，因为应当修学，所以称为学。」

## §818 句 100-818-110-118
- **问题**：「所以这样说」中的“这样说”是补出的成分。nissaya 只有 `ယသ္မာ…ဟောန္တိ` / `တသ္မာ= ထိုကြောင့်`（因为……所以），没有“说”。
- **建议**：「**所以**，意思是：因为这三件是沙门应当做的事，所以。」如果嫌句子收得太急，可以写「……所以（要这样修学）」。

## §820 句 100-820-13-28
- **问题**：句法切分有误。nissaya 把 `ဒမ္မော ဒမ္မမာနော` 合释为“可调教的牛”，`ဝဒမာနော`（说着）管的是整句引语，gāvī 属于引语之内。译文把“牛”拆到引号外，成了「说自己是牛」，变成另起一个判断。
- **建议**：「意思是它说着：‘我也是可调驯的、受调驯的牛。’」

## §820 句 100-820-49-57
- **问题**：「脚印」与父层「足迹」不一致（见跨段一致性）。
- **建议**：「就像毛色那样，叫声和足迹也都是另一个样子。」

## §822 句 100-822-2-11
- **问题**：pali 只有 paṭhamameva 一词，译文给了「一开始就、最先」两个译法。nissaya 的 `ပဂေဝပဌမမေဝ` 多出 pageva，是底本异读，不应据此译成两词。
- **建议**：「**预先**，意思是最先就（做好）。」

## §824 句 100-824-26-51
- **问题**：取义偏离了 nissaya。nissaya 把 avaṅko 释为 `လရေးကောက်သကဲ့သို့ မကောက်`（不像月牙那样弯），把 akuṭilo 释为 `ထွန်ကိုင်းခက်ကဲ့သို့ မကောက်`（不像犁柄那样曲），两词都是“不弯曲”的形象说法。译文「不虚伪，不狡诈」偏离了字面形象。
- **建议**：「……生性直率，不弯不曲，……」或「没有一点歪曲」。

## §824 句 100-824-57-73
- **问题**：漏了隐含成分。nissaya 补出 `မေ= ငါ့အား`（对我来说），sikkhantassa 修饰的是“我”，是比丘的自我判断。译文「……都要修学的人」成了泛指第三者。
- **建议**：「据说他心里想：‘我既然在修学这么多学处，修学三学也不是什么重担。’所以这样说。」

## §824 句 100-824-170-173
- **问题**：漏译。nissaya `ဧကံ= တပါးသော`，ekaṃ 是“一个”。这个故事的关键就在于“一个百捆”听起来只是一件东西，Uttara 才会答应。译文「一百捆你能拿吗」丢了 ekaṃ，§824 句 207-231 的“连这一个百捆都举不起”也就失去了照应。
- **建议**：「“一个一百捆的你能拿吗？”」或「“把一百捆捆成一捆，你能拿吗？”」，与句 207-231 呼应。

## §824 句 100-824-195-206
- **问题**：句类错误。nissaya `အသိ= ဖြစ်သလော` 标的是疑问，下句「是的，尊者」也是在作答。译文用了陈述句。
- **建议**：「“郁多罗，你好像很累了吧？”」

## §824 句 100-824-243-248
- **问题**：见跨段一致性。漏了 missikā 的“世间与出世间”，句式也与 §820、§822 不统一。
- **建议**：「这里讲说的也是世间与出世间混合的三学。」

## §826 句 100-826-2-18
- **问题**：「**随顺正直之道**而行的意思是」中，“而行”夹在黑体和释义标记之间，读起来像是被解释词的一部分。释义格式也与前文不统一。
- **建议**：「八六、第五经里，**随顺正直之道**，意思是：正直之道（ujumagga）指的是圣道，随顺这条道而修行的人。」

## 原文 / nissaya 底本疑问（只记录，不改译文）

- §820 句 49-57：nissaya 作 `ဂန္ဓမ္ပိ= အနံ့`（gandhaṃ，气味），pali 作 padaṃ（足迹）。nissaya 底本与 VRI 本不同，译文按 pali 译，正确。
- §822 句 19-24：nissaya 读作 sumattikataṃ / `မတ္တိယာ= မြေညက်`（用细土），pali 作 matiyā（用耙）。译文与父层脚注一致取“耙”，可以保留。
- §826 句 56-60：nissaya 读作 aññāvimuttiyā，并把 arahattaphalavimuttiyā 释为处格（`၌`），没有释 vimuttassa。pali 作 aññāvimuttassa，译文取具格「由……解脱」，与父层一致。
- §826 句 61-67：nissaya 读作 ñāṇañca hoti（与父层 ka. 本异读同），pali 作 ñāṇaṃ ve hoti，译文按 pali 译。
- §818 句 18-30、句 119-122：nissaya 中的 `အမိသိလ`、`တဗ္ဗော` 是录入讹误（应为 adhisīla、tibbo），不影响审读。
