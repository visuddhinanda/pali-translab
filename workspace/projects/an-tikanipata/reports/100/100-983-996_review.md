# Review — 100:983-996（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（983、984-2、990、991-2、992、994-996 等标题与编号行无 nissaya，已略过）
> 父层：book 86 §1276-1319 定稿译文

## 被解释词与父层对照

逐条核对的结果：āgāḷhā paṭipadā / nijjhāmā / majjhimā / acelako / muttācāro / hatthāpalekhano / na ehibhadantiko / na tiṭṭhabhadantiko / abhihaṭaṃ / uddissakataṃ / nimantanaṃ / na kumbhimukhā / na kaḷopimukhā / na eḷakamantaraṃ / dvinnaṃ / na gabbhiniyā / na saṅkittīsu / na yattha sā / saṇḍasaṇḍacārinī / thusodakaṃ / ekāgāriko / ekālopiko / dvāgārika / ekissāpi dattiyā / ekāhikaṃ / addhamāsikaṃ / pariyāyabhattabhojanaṃ / sākabhakkho / ubbhaṭṭhako / ukkuṭikappadhānamanuyutto / kaṇṭakāpassayiko / seyyaṃ / sāyatatiyakaṃ / kāye kāyānupassī / ayaṃ vuccati… majjhimā paṭipadā / samanuñño，都与父层同一处的译文逐字一致。

- **daṇḍamusalesu**：译作「**棍子和杵**」。父层原文是「隔着棍子递来的、隔着杵递来的」，两个词分开出现，所以本层合并后多出一个「和」字。两个核心词与父层一致，可以接受，不列为必改项。
- **ekissāpi dattiyā**：译作「**靠一小钵施食**」。父层原文是「靠一小钵（datti）施食」，本层省掉了夹注的巴利原词，汉字部分一致。

## 跨段一致性

- **datti**：§986-37 译「一个小钵」，与父层「小钵」一致；§986-43 却译「小碟子」。nissaya：`ခုဒ္ဒကပါတိ= ခွက်ငယ်`（小碗、小钵）。→ **必改**，统一为「小钵」。
- **na gaṇhāti**：§984-158、168、195 译「不拿」，§984-223 译「不拿取」，§985 各处译「不接受」。nissaya 一律是 `နဂဏှာတိ= မခံယူ`（不接受），父层也一律用「不接受」。→ 统一为「不接受」。
- **kaḷopī**：§984-168 释为「锅或者篮筐」，§985-80 也作「锅口、篮筐口」；但 §984-183 的 kumbhikaḷopiyo 只译成「瓮和锅」，把篮筐漏了。nissaya：`ထမင်းအိုး ထမင်းတောင်းတို့သည်`（饭锅和饭篮）。→ 改为「瓮和锅、篮筐」。
- **bhikkhā**：§984-74 译「乞来的食物」，§984-121、127、135、158 译「乞食」，§984-168 译「食物」。→ 统一为「乞食」。
- **eseva nayo**：§984-218、§986-32 译「道理也完全一样」，§991-39 译「也照这样理解」。§991-39 后面有 veditabbā（应当理解），措辞不同可以保留；但前两处与它语气差别较大，建议统一句式。
- **attakilamathānuyoga**：§984-17 译「修习自我折磨的苦行」，§988-10 只剩「自我折磨」，-anuyoga 没有译出来。与它并列的 kāmasukhallikānuyoga 也只译成「耽着欲乐」。nissaya：`…အားထုတ်ခြင်း`（致力于……）。→ 建议改为「致力于欲乐享受和致力于自我折磨」，与 §984-17 呼应。
- **集名**：§988-2 Ekakanipāta 译「《一集》」，§994 Tikanipāta 译「三法集」，一个加书名号一个不加，一个用「集」一个用「法集」。→ 统一体例，建议「《一集》」「《三集》」。
- **品名与标题格式**：§983 写「裸行者品」，没有书名号；§989「裸行者品第六」也没有；§990、§992 写「《略说品》」，有书名号。父层 §1290 是「《裸行者品》第六品」。→ 统一加书名号。
- **经号格式**：§984-2「157–163.」用阿拉伯数字，§990「十七至十八。」与 §991-2「一六四至一八四。」用汉字。父层本身也不一致（§1277 vs §1295）。→ 建议三层统稿时统一。
- **Kasmā 答句的「因为他想」**：§984-183、207 和 §985-114 的巴利原文带引号，加「他想」有依据；§984-236 和 §985-71 原文没有引号，nissaya 把末尾的 iti 读作 `ဣတိတသ္မာ`（因此），是表原因而不是表引述。→ 这两处去掉「他想」，见下文逐句意见。

## §984 句 100-984-6-16
- **问题**：词义 — nissaya：`ဝါဠာ(gāḷhā)= မြဲမြံသော`（牢固的），不是「粗重」。另外，nissaya 把 ito paresu 解作「从这第三个五十经组往后的各组里」（`ဣတော= ဤတတိယပဏ္ဏာသကမှ`、`ပရေသု= နောက်ဖြစ်သောပဏ္ဏာသကတို့၌`），译文「往后的几部经里」把范围限定成了「几部经」。
- **建议**：gāḷhā 改译「牢固」；「几部经里」改成中性的「从这里往后」，不限定单位。

## §984 句 100-984-56-73
- **问题**：误译 — 第二个 apalekhati 的意思是「擦、刮」。nissaya：`ဟတ္ထေန= လက်ဖြင့်`（用手）、`အပလေခတိ= ချစ်၏`（刮擦）。句子说的是他把手当成擦拭用的小棍，用手去擦，并不是「舔」。
- **建议**：「用手来舔刮」→「用手来擦」。（必改）

## §984 句 100-984-74-89
- **问题**：主语不清 — bhikkhāya gahaṇatthaṃ 的意思是「为了让他接受乞食」，说这话的是施主。译文「为了取得乞来的食物，别人对他说」读起来像是「别人」要去取食物。
- **建议**：「为了让他来接受乞食，别人对他说……」，同时按上文把 bhikkhā 统一为「乞食」。

## §984 句 100-984-168-180
- **问题**：动词 — nissaya：`တတောပိ= ထိုထမင်းအိုး ထမင်းတောင်းမှလည်း`、`ဒယျမာနံ= ပေးလှူအပ်သော`，意思是「从锅、篮里拿出来施给的」。译文「拿来的」把「施给」的意思弱化了，句末「不拿」也与全书的「不接受」不一致。
- **建议**：「从那里取出来给他的乞食，他也不接受」。

## §984 句 100-984-183-194
- **问题**：漏译 — kaḷopiyo 只译成「锅」，漏了「篮筐」。
- **建议**：「瓮和锅、篮筐会因为我而挨勺子敲打。」

## §984 句 100-984-236-238
- **问题**：补出成分无据 — nissaya：`ကဗလန္တရာယော= ထမင်းလုပ်၍အန္တရာယ်သည်`、`ဟောတိ= ဖြစ်၏`、`ဣတိ တသ္မာ= ထိုကြောင့်`。这里的 iti 作「因此」解，原文也没有引号，「因为他想」是译者加上去的。
- **建议**：「因为那会妨碍人家吃那一口饭。」

## §985 句 100-985-71-74
- **问题**：同上 — nissaya 把 `ဣတိတသ္မာ` 读作表原因，原文没有引号。
- **建议**：「因为那会妨碍这只狗得到一团食。」

## §986 句 100-986-43-53
- **问题**：术语不一致 — datti 译作「小碟子」，与本 chunk §986-37 和父层的「小钵」冲突。nissaya：`ခုဒ္ဒကပါတိ= ခွက်ငယ်`。
- **建议**：「所谓 datti，是一种小钵……」（必改）

## §987 句 100-987-41-44
- **问题**：指代误读 — nissaya：`အဿ= ထိုရေသို့သက်ခြင်းအား`（对于那下水的行为），assa 指的是下水的修行，不是修行的人。译文「傍晚是他的第三次」把所属关系挂到了「他」身上。
- **建议**：「傍晚是第三次下水，所以叫做**早、午、晚一天三次**。」

## §987 句 100-987-2-6
- **问题**：风格 — 「直立着站着」语义重复，读起来别扭。nissaya：`ဥဒ္ဓံ= အထက်၌`、`ဌိတကော= ရပ်လျက်`。
- **建议**：「是指笔直地站着」。

## §991 句 100-991-15-18
- **问题**：词义区分 — nissaya：`အဘိဇာနေတွာ= ထူးသောဥာဏ်ဖြင့် သိ၍`（以殊胜智了知）。译文「彻底了知」与 §991-35 pariññā 的「完全了知」几乎同义，abhiññā 与 pariññā 的区别看不出来了。
- **建议**：abhijānana 译「以殊胜智了知」，parijānana 保留「完全了知」或改「周遍了知」。

## §991 句 100-991-19-26
- **问题**：术语 — suññata samādhi 通常译「空定」，与「无相定」「无愿定」成套。「空性定」不算错，但偏离惯用译法。
- **建议**：改为「空定」，并在 terms.md 登记这三定的译名。

## §993 句 100-993-2-3
- **问题**：格位 — nissaya：`အင်္ဂုတ္တရအဋ္ဌကထာ၌`（在增支部义注中，处格），并与 §994 连成一句：「在《满足希求》增支部注释中，三集的注释结束。」译文只给了一个光秃秃的书名，与下一段之间的关系断了。
- **建议**：§993 改为「在《满足希求》增支部注释中，」，§994 改为「《三集》的注释结束。」（集名格式见跨段一致性一节）

## 原文与数据疑问（只记录，不改）
- nissaya 有几处切分与句子错位：§984-17 那一行带上了 majjhimā 的条目，§984-218 那一行带的是 §984-207 的条目，§984-223 那一行带上了 daṇḍamusalesu 的条目，§986-54 那一行带上了 addhamāsika 的条目，§991-27 和 §991-39 也各自带了相邻句的条目。这不影响审读结论，但对齐脚本要注意。
- §986-2：nissaya 读作 sabbasambhārehi，pali 原文是 sabbasassasambhārehi。
