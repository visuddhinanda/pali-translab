# Review — 100:614-619（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次为 nissaya 复核）

## 被解释词与父层对照

逐条核对了本 chunk 的黑体词：第一种明／无明／黑暗／光明／正像／不放逸／努力精勤／不顾身命而策励自己／明／他在心这样得到安定／了知诸漏灭尽的智／把心导向／这是苦／这些是漏／他这样了知、这样看见／从欲漏中／解脱出来／在已经解脱之中，生起“已经解脱了”的智／生已经穷尽／已经完成／梵行／该做的已经做好／再没有为了重来这种状态而要修的道了／这种状态／戒行平稳、没有高低起伏／已经得到自在／安稳地安住在所缘上／坚毅不移／已经舍弃了死亡／舍断了一切恶法的人／佛陀／持有最后一个身体的／佛弟子们礼敬的，就是这位乔达摩。

- 以上文字都与父层译文逐字相同，**没有必改项**。
- 「这是苦」「在已经解脱之中，生起“已经解脱了”的智」：父层用 ‘’，这里用 “”。原因是父层嵌在佛语引号之内，属于正常的引号层级转换，不必改。
- 100-614-78-89 的 **那样**：见下文该句。

## 跨段一致性

- **khīṇāsava**：§618 两处译「漏尽者」，§619（100-619-17-22）译「漏已尽的人」 → 建议统一为「漏尽者」。
- **Sesaṃ vuttanayameva**：§615 译「其余部分按前面说过的方式理解即可」，§618 译「其余的按前面说过的方式理解」。巴利完全相同 → 建议统一为「其余的按前面说过的方式理解」。
- **vijjā 的定义句式**：§615 作「天眼智这种明」，§618 作「阿罗汉道智的明」。两句结构平行（Idha vijjāti …ñāṇavijjā）→ 建议统一为「……这种明」。
- **āsavānaṃ khaya**：父层与 §616 黑体都是「诸漏灭尽」，100-616-17-29 正文作「诸漏的灭尽」。这里正是在解释该词 → 建议改为「诸漏灭尽」，让对应关系可见。
- **「自相」一词撞车**：§616 用「自相」译 sarasalakkhaṇa（自身的特相），§617（100-617-2-13）又用「自相」译 sarūpato（就其本来形态）。nissaya 对前者作 မိမိသဘောဟုဆိုအပ်သော လက္ခဏာ，对后者作 သရုပ်အားဖြင့်，两者不同 → §617 建议改为「直接按本来面目」。
- **vipassanā 夹注位置**：「观」在 §616（100-616-2-11、100-616-30-35）已经出现，夹注（vipassanā）却放在 §617（100-617-27-32） → 夹注应移到首次出现处 100-616-2-11，§617 删去夹注。

## §614 句 100-614-78-89
- **问题**：句法／对应 — 巴利只有 **tan** 是被解释词，注说它「只是虚词」（nissaya：တံ-ဟူသော ဤသဒ္ဒါ = 「taṃ 这个词」）。译文把 tan 对成「**那样**」，再说「那样只是一个虚词」。可是父层的「那样」承担的是 yathā 比喻的后半，有实义，读者会困惑。
- **建议**：改为「**正像**……**那样**，这里的**正像**表示比喻，taṃ 只是一个虚词，没有实义。」也就是虚词一项直接用巴利词指称，不套用汉语「那样」。

## §614 句 100-614-104-106
- **问题**：补出成分 — nissaya：ပေသိတတ္တဿ = 不顾身命、把心**送向涅槃**的人。译文「把自己完全投入于修行」丢了「送向（涅槃）」这个方向义，「投入于」的「于」也偏文言。
- **建议**：「意思就是：他已经把心送出去，投向涅槃。」

## §614 句 100-614-143-149
- **问题**：句法（次要）— nissaya 把 etassa padhānānuyogassa 读成「这位勤修者」（人，属／为格），「得到」的主体是此人。译文读成「与这努力相称」，也讲得通，但「凭着那样的精勤努力」又把 tena 处理成工具，等于 padhānānuyoga 被译了两遍。
- **建议**：「他得到的，正是与他这样精勤修行相称的结果。」

## §616 句 100-616-17-29
- **问题**：句法误读 — nissaya：တတြ = 在那阿罗汉道里；ဧတံ ဉာဏံ … ဟောတိ = 这个智就在其中；ပရိယာပန္နတ္တာ = 因为被包含在内。原意是「这个智是在『灭尽』（阿罗汉道）里的智，因为它包含在阿罗汉道中」。译文「这个智之所以指的就是它」意思走偏，句子也拗口。「被摄在」偏文言。
- **建议**：「……所以被称为诸漏灭尽；这个智就是在它里面的智，因为它包含在阿罗汉道之中。」

## §616 句 100-616-30-35
- **问题**：词义 — nissaya：အဘိနီဟရတိ = ရှေးရှုဆောင် （引向、导向）。译文「引发出观的心」把「导向」译成了「引发」。
- **建议**：「**把心导向**，就是他把观的心引向那里。」

## §616 句 100-616-36-85
- **问题**：风格（必改）— 「到达某一处**便**止息」中的「便」属于禁用的文言虚词。「不再转起」偏术语腔，nissaya：အပဝတ္တိ = မဖြစ်ခြင်း（不再发生）。
- **建议**：「便」改为「就」；「两者不再转起的状态」改为「两者不再发生的状态」。

## §617 句 100-617-33-36
- **问题**：标点（必改）— 「即‘从欲漏’」在这里不是嵌套引语，单引号用错了层级。
- **建议**：改为「即“从欲漏”」。

## §617 句 100-617-61-66
- **问题**：词义 — nissaya：ဘူမိ = ဖြစ်ရာ（它所起的领域、所及之处），指省察智所省察的范围，不是「基础」。
- **建议**：「用**生已经穷尽**等等这些话，显示那种省察智所省察的范围。」

## §618 句 100-618-16-27
- **问题**：补出成分 — nissaya：ဝသန္တိ နာမ = 「称为正在过（梵行）」，没有「才」的排他义。译文「才算是」多出了「只有他们」的意思。
- **建议**：「……七种有学都算是正在过着梵行的生活……」

## §618 句 100-618-93-117
- **问题**：格（必改）— nissaya：ဣတ္ထဘာဝတော = ဖြစ်ဆဲဖြစ်သောခန္ဓာအစဉ်**မှ**（从……），itthattāya 在这里要按从格读，取「从这种状态（之后）」的意思。译文「是就这种状态而言」丢了从格。§617 kāmāsavā 已经明确说明了从格读法，这里应当同样处理。
- **建议**：「或者，**这种状态**要按从格读，即‘从这种状态’。意思是：在现在正在进行的这一蕴相续之后，我不再有另一个蕴相续……」

## §618 句 100-618-118-125
- **问题**：重复 — nibbāyissanti 只有一个动词（nissaya：ငြိမ်းကုန်လတ္တံ့），译文却作「寂灭」和「熄灭」两次。
- **建议**：「他了知：这些五蕴会随着最后一个识的灭去，像没有燃料的火那样熄灭。」

## §619 句 100-619-17-22
- **问题**：词义 — nissaya：ဧကန္တဝဍ္ဎိတမေဝ = 必定只是增长的。「只是一直增长」中的「只是」读起来像「仅仅」。另外「漏已尽的人」需要统一，见跨段一致性。
- **建议**：「而漏尽者的戒必定始终是增长的。」

## §619 句 100-619-76-87
- **问题**：数／所指 — nissaya：တံ ဂေါတမံ = 那些属于乔达摩族系的**弟子们**（指弟子）。译文「那位乔达摩」容易读成佛陀本人，第二种解释就体现不出来了。
- **建议**：「……意思是天与人都礼敬那位身为佛弟子的乔达摩。」
- **附注**：父层把这句译成「佛弟子们礼敬的」，预设了第一种解释；第二种解释的礼敬者是天与人。被解释词已按父层逐字引用，这里不改，只记下这个分歧，供统稿时参考。
