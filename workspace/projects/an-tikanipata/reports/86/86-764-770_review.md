## 被解释词核对

本层是本文（mūla），**无父层**，故不存在「与父层逐字同译」的核查对象。反向约束仍成立：以下词句是义注取作黑体的被解释词，本文的译法一旦定下，将来义注译文必须逐字沿用，所以此处不能留两种译法——

- `rajjaṃ kāreyya` / `kapaṇaṃ mānusakaṃ rajjaṃ`：现在 §765 内部就有「统治」与「王位」两种，§766/§767 又作「王权」（见下）
- `mahapphalo / mahānisaṃso / mahājutiko / mahāvipphāro`：§764 与 §765 已一致，但 `mahāvipphāro` 的译法待定（见下）
- `aṭṭhaṅgasamannāgata`：「具备八支」与「具足八支」两种

## 跨段一致性

1. **`kapaṇaṃ mānusakaṃ rajjaṃ dibbaṃ sukhaṃ upanidhāya`：三处译法互不相同，且其中两处是对第一处的直接引用 → 必改。**
   - §765 句 `86-765-112-123` 译「毗舍佉，人间的王位和天上的快乐相比，是很微小的。」
   - §766 句 `86-766-79-89`、§767 句 `86-767-71-81` 译「‘与天上的快乐相比，人间的王权是微不足道的。’」
   - 前句明说 `Idaṃ kho panetaṃ … sandhāya bhāsitaṃ`（我正是针对这一点才说），引的就是 §765 那一句。引文与被引句不同字，对应关系直接断掉。建议把 §765 改成与引文完全相同的措辞：「毗舍佉，与天上的快乐相比，人间的王权是微不足道的。」依据：义注 `100-771-82-85` **义注**：`**Kapaṇan** ti parittakaṃ`（kapaṇa = 微小），两种译法均达义，分歧纯属未统稿。
2. **`rajja` 一词在 §765 内部就有两译**：`86-765-12-107` 译「统治」，`86-765-112-123` 译「王位」，§766/§767 译「王权」。义注 `100-771-41-47` **义注**：`**Rajjaṃ kāreyyā**ti evarūpaṃ cakkavattirajjaṃ kāreyya`（行使这样的转轮王统治）。建议名词统一作「王权」，动词短语作「行使…的王权」。
3. **`aṭṭhaṅgasamannāgata`**：§765、§766 译「具备八支」，§767、§768 译「具足八支」 → 统一为「具足八支」（与「具足」的常用搭配一致，且后续段落占多数）。
4. **寿量套语四句（`Tāya rattiyā…` / `Tena māsena…` / `Ṭhānaṃ kho panetaṃ…`）§766 与 §767/§768 逐句不同字** —— 原文这几句完全平行，译文必须逐字相同：

   | 原文 | §766 | §767 / §768 |
   |---|---|---|
   | `Tāya rattiyā tiṃsarattiyo māso` | 按这样的夜计算，三十夜为一个月。 | 按那样的昼夜算，三十个昼夜是一个月。 |
   | `Tena māsena dvādasamāsiyo saṃvaccharo` | 按这样的月计算，十二个月为一年。 | 按那样的月算，十二个月是一年。 |
   | `Ṭhānaṃ kho panetaṃ … vijjati yaṃ idhekacco` | 确实存在这样的情形：这里有某个女人或男人， | 这种情况是有的：这世上某个女人或男人 |

   取舍建议：`tiṃsarattiyo` 原文是「夜」（rattiyo），§767/§768 的「三十个昼夜」多出了「昼」，以 §766 的「三十夜」为准。**统一模板（§766–§770 及补译部分一律照此）**：

   ```
   “毗舍佉，人间的{N}年，相当于{天名}诸天的一个昼夜。
   按这样的夜计算，三十夜为一个月。
   按这样的月计算，十二个月为一年。
   按这样的年计算，{天名}诸天的寿量是天上的{M}年。
   毗舍佉，确实存在这样的情形：这里有某个女人或男人，守持了具足八支的斋戒，身坏命终以后，往生到{天名}诸天当中，成为他们的同伴。
   毗舍佉，我正是针对这一点才说：
   ‘与天上的快乐相比，人间的王权是微不足道的。’”
   ```
5. **数词「二 / 两」混用**：§768 译「人间的二百年」却译「天上的两千年」。统一用「二」：二百年、二千年。
6. **`mahāvipphāro` 的译法**（§764、§765 两处同时涉及）：现译「大影响」。义注 `100-756-171-178` **义注**：`**Na mahāvipphāro**ti vipākavipphārassa amahantatāya na mahāvipphāro`——vipphāra 指果报的**扩展、遍布**，不是「影响力」。建议统一改「大广布」或「广大遍布」，两段同改。

## §765 句 86-765-12-107

- **问题 1（释义，必改）**：`pahūtarattaratanānaṃ` 译「盛产珍宝的」。义注 `100-771-11-27` **义注**：`**Pahūtarattaratanānaṃ** ti pahūtena rattasaṅkhātena ratanena samannāgatānaṃ, sakalajambudīpatalaṃ bheritalasadisaṃ katvā kaṭippamāṇehi sattahi ratanehi pūritānanti attho`——义注解作「具足大量名为 ratta 的宝」，并把整个阎浮提地面铺平如鼓面、用七宝填到腰深。是**遍地堆满珍宝**，不是「出产珍宝」。「盛产」把 samannāgata（具足）改成了物产描述。
- **建议 1**：译「这十六个遍地珍宝的大国」或「珍宝堆积的十六大国」。
- **问题 2（术语，必改）**：`issariyādhipaccaṃ` 译「拥有主权和统治权」。两处错：(a) 义注 `100-771-28-40` **义注**：`**Issariyādhipaccan** ti issarabhāvena vā issariyameva vā ādhipaccaṃ`——issariya 与 ādhipacca 是同义互释（以主宰身份的统治／主宰性即统治权），不是两项并列；(b)「主权」是现代国际法概念，违反 `style.md` 第六节「不用现代政治术语对译法相」。
- **建议 2**：译「行使君主的统治权」，与义注把 `rajjaṃ kāreyya` 释为 `cakkavattirajjaṃ`（转轮王的统治，`100-771-41-47`）呼应。义注另注明 `na ettha sāhasikakammaṃ`（此处的统治不含暴虐），可作脚注，不必进正文。
- **问题 3（译名撞车，必改）**：十六国名列表里 `aṅgānaṃ` 与 `vaṅgānaṃ` 都译成了「鸯伽国」——第 8 国写作「鸯伽国（跋伽国）」，与第 1 国同名，读者会以为重复列了一国。
- **建议 3**：第 8 国直接用「跋伽国」（去掉「鸯伽国」与括注）。
- **问题 4（译名，建议）**：`macchānaṃ` 译「婆蹉国」。「婆蹉」是 Vaṃsa / Vatsa 的传统译名，与 Maccha（Skt. Matsya）不是一国；此表中无 Vaṃsa。
- **建议 4**：改「摩差国（Maccha）」。义注 `100-771-48-53` 只说 `**Aṅgānan** tiādīni tesaṃ janapadānaṃ nāmāni`（这些是国名），不定译名，此条依据为汉译地名惯例，请定案后补进 `terms.md`。
- **问题 5（漏义，建议）**：`aṭṭhaṅgasamannāgatassa uposathassa etaṃ kalaṃ nāgghati soḷasiṃ` 译「抵不上…斋戒的十六分之一」。义注 `100-771-54-69` **义注**：`**Kalaṃ nāgghati soḷasin** ti ekaṃ ahorattaṃ upavutthauposathe puññaṃ soḷasabhāge katvā tato ekaṃ bhāgañca na agghati`——十六分之一的是守持**一昼夜**斋戒的**功德**（puñña），不是斋戒本身。
- **建议 5**：译「抵不上守持具足八支斋戒所得功德的十六分之一」；「一昼夜」可入脚注。
