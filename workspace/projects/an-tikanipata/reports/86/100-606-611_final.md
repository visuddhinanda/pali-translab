## 理由

**基准缺失（影响信心）**：本次评估对象本身就是义注层（book=100，*Tikaṇṇasuttavaṇṇanā*），注入数据只有巴利原文与 channel 译文——**没有复注（ṭīkā）**可作释义标准，也**没有 nissaya**可作词级基准，被解释词所引的**本文层（AN 3.59）译文**同样未注入。因此：格与句法角色的核对只能依据原文本身的形态判断；跨层「被解释词与父层逐字同译」这一硬约束**无法验证**，相关条目只能提示待核（见 suggestion 中 `100-608-41-63`）。分数据此整体保守，信心压到 62。

**准确性（84）**：主干释义链条基本正确——*upasaṅkami* 的情节补足、*mayi…akathente* 的处格独立结构、*ubhato / saṃsuddhagahaṇiko / yāva sattamā pitāmahayugā* 的血统七代解说、*akkhitto / anupakkuṭṭho / jātivādena* 的问答式串讲、三吠陀与五明（nighaṇḍu / keṭubha / akkharappabheda / itihāsa）的名目，均与原文吻合，没有漏段、没有整句错判主谓宾，也没有违背教理的句子，故无 fatal。扣分集中在四处：*ghaṭṭessāmi* 译「触犯」属汉语词义偏移；*Aggañña* 引文内把 *ajjhāyaka* 夹注成「诵读者」，使「因不修禅故得此名」的词源推导自相矛盾；*gahaṇī* 增补「（胃）」与紧随其后的「由业所生的火界」冲突；*mātito ca pitito ca* 的从格义丢失且父母顺序与下文解说相反。

**风格符合度（82）**：**现代书面汉语这一硬约束执行得好**——通篇未见「此中／故为／彼等／是故／于…之际／答以」一类文言虚词与句式，单音节文言词也基本清除（「不曾」「所出」尚在可接受的现代书面语范围），本项无 warning 级文言条目。标点全角、引号统一用 “” ‘’、未出现 ASCII 引号与「」，符合 JSON 安全要求。失分在格式体例：相邻黑体引词被「……」割裂（两处），黑体内嵌汉语括注再套巴利夹注造成括号堆叠，以及译文正文中裸用拉丁字母 *gahaṇī / ajjhāyaka* 作名词，与 `knowledge/style.md`「显示巴利原文：否，只作圆括号夹注」不合。

**一致性（78）**：最弱的一项。*ajjhāyaka* 在相邻两句分别作「能诵读吠陀」与「诵读者」；*manta* 译「咒语」而同一所指在 611 段作「吠陀」，婆罗门学问体系内两名并行；黑体引词的夹注体例不统一（「语汇学（nighaṇḍu）」夹注在黑体外，「修辞学（诗法）」的注释塞在黑体内且无巴利词，「连同语音与词的分析」完全无夹注）。*Saha X…sa-X* 这种「连同…故名连同…」的构词释义有两处退化为同词重复句，*Anupakkuṭṭho* 一条则出现被解释词与解释语同义反复，读者看不出所释为何。

## 问题清单

### 🟧 error

- `100-607-114-125`｜错译（词义）｜片段「其实是想要触犯如来的智」
  - 问题：*ghaṭṭessāmi*（ghaṭṭeti）义为「碰撞、冲击、试探」，此处指婆罗门有意用称赞婆罗门的话去撞击、试探如来的智。汉语「触犯」意为冒犯律法或尊长，与「撞击／试探」不同义，读者会误解为「冒犯世尊」。
  - 建议：改为「其实是想要撞一撞如来的智」或「其实是想试探如来的智」。

- `100-610-2-41`｜义理或用词与注释书不符｜片段「于是‘ajjhāyaka（诵读者）、ajjhāyaka’这第三个称号就产生了」
  - 问题：引文（*dī. ni.* 3.132）的词源逻辑是 *na jhāyanti* → *ajjhāyaka*，即「不修禅者」，整段明说这是劫初对不修禅婆罗门的**指责语**。在引文内把 *ajjhāyaka* 夹注为「诵读者」，等于把后世转用的褒义塞回原始贬义处，使「这些人不修禅了，所以叫 ajjhāyaka」的推导不成立；「诵读者」一义应留给下一句 *Idāni pana…* 的转义。
  - 建议：引文内改注贬义，如「于是‘不修禅者（ajjhāyaka）、不修禅者’这第三个称号就产生了」；并在句末「本是针对不修禅定的婆罗门而起的一句指责」处保持呼应。

- `100-608-116-128`｜导致误解的表达｜片段「消化力均匀的 gahaṇī（胃）」
  - 问题：本句要点是 *gahaṇī* 一词在该经文语境中**不指母腹、而指业生火界**（消化之火）。增补「（胃）」把它定为器官，与同句后半「gahaṇī 指的是由业所生的火界」直接矛盾；同时正文裸用拉丁词 *gahaṇī*，违反「不显示巴利原文、只作夹注」的体例。
  - 建议：去掉「（胃）」，并把被引经句的汉译补出，如「不过在“消化均匀的胎火（gahaṇī）”这个说法里，这个词指的是由业所生的火界（kammajatejodhātu）」。

- `100-608-70-86`｜错译（词义、修饰关系）｜片段「**父母**（mātito ca pitito ca）」
  - 问题：*mātito / pitito* 是从格，义为「从母方、从父方（而言）」，与下一句「他父母双方的出身都纯正」构成「双方＝母方＋父方」的对应。黑体译作「父母」丢掉了「方面」这一层，且顺序与原文及紧随的解说（先母后父）相反。
  - 建议：改为「**从母方和父方**（mātito ca pitito ca）」，并与本文层译文核对后统一。

### 🟨 warning

- `100-607-40-45`｜整句逻辑表达不规范｜片段「**称赞**……**说**（vaṇṇaṃ bhāsati）——他为什么要说呢？」
  - 问题：*Vaṇṇaṃ bhāsati* 在原文是紧邻的两词，译文用「……」把黑体引词割成两段，读者会以为中间省略了内容；后接破折号＋设问又使句子结构松散。
  - 建议：合为一处，如「**称赞**（vaṇṇaṃ bhāsati）：他为什么要这样称赞呢？」

- `100-608-2-16`｜整句逻辑表达不规范｜片段「“**什么**……**呢**”（kathaṃ pana）是表示提问的词」
  - 问题：同上，*kathaṃ pana* 相邻两词被「……」拆开；同句前半的黑体「**依照**」又没有给出巴利夹注，两个被释词体例不一，读者无法与原文对位。
  - 建议：改为「**依照**（yathā）是表示原因的词，**那么…怎样**（kathaṃ pana）是表示提问的词」。

- `100-607-126-139`｜关键词语意不明确，二意场合没有注释｜片段「**具足三明的婆罗门就是这样的**」
  - 问题：此处 *tevijja* 指通达三吠陀的婆罗门，与佛教「三明」（宿住随念智等）同名异义；本段又正是全经界定该词的地方（611 段明言即三部吠陀）。首次出现既无巴利夹注也无简注，读者极易按佛教义误读。
  - 建议：首次出现处夹注并加一句简注，如「具足三明（tevijja，此处指通达三部吠陀）的婆罗门」。

- `100-607-140-146`｜关键词语意不明确｜片段「**正是凭这些**，他用这句话标明」
  - 问题：被释词 *itipi* 字面为「也是这样（如是）」，是本文层句末的语气成分；译作「正是凭这些」提前塞入了下一句 *ettakena kāraṇena* 的意思，与本文层用词难以对位，又无巴利夹注。后半「标明那些人有智慧等等是就哪些方面说的」也绕。
  - 建议：改为「**也是这样**（itipi）——这个词标明了他们‘有智慧’等等是就哪些方面说的」。

- `100-609-35-51`｜整句逻辑表达不规范｜片段「或者连下读，是说他不曾因出身的议论被人排斥」
  - 问题：*atha vā* 只是「或者」，「连下读」是译者增补的读法说明，原文无此语，混在正文里像是注释书自己的话。
  - 建议：删去「连下读」，仅作「或者，是说他不曾因出身的议论被人排斥…」；确需提示读法，放脚注。

- `100-609-68-79`｜关键词语意不明确｜片段「**不曾受到辱骂或责难**，是说没有被人责骂，从来没有遭到过辱骂或责难」
  - 问题：黑体引词与解释语同义反复，*upakkuṭṭha*、*akkosa*、*nindā* 三词在译文里被压成同一组字面，读者看不出所释为何，也读不出 *na akkosaṃ vā nindaṃ vā pattapubbo*（从未遭到过辱骂或责难）与被释词的区别。
  - 建议：黑体改「**不曾被谴责**（anupakkuṭṭha）」，解释作「是说没有被人非难，从来没有遭到过辱骂或责难」。

- `100-611-31-35`｜整句逻辑表达不规范｜片段「连同语音与词的分析，所以说**连同语音与词的分析**」
  - 问题：*Saha akkharappabhedena* → *sākkharappabhedānaṃ* 是「与 X 俱，故名『与 X 俱的』」的构词释义；译文前后用字完全相同，成为无信息的重复句，且黑体无巴利夹注。
  - 建议：显出构词关系，如「与语音和词的分析一起，所以说**连同语音与词的分析**（sākkharappabheda）」。

- `100-611-12-18`｜标点符号使用错误｜片段「所以说**连同语汇学、修辞学（诗法）**（sanighaṇḍukeṭubha）」
  - 问题：黑体内嵌汉语括注「（诗法）」，紧接着又套一层巴利夹注，两重圆括号相连；同句前半已把 *keṭubha* 译作「修辞学」，后半又写成「修辞学（诗法）」，一句之内两种写法。
  - 建议：择一处给出释名，如「连同语汇学（nighaṇḍu）和修辞学（keṭubha），所以说**连同语汇学与修辞学**（sanighaṇḍukeṭubha）」。

- `100-611-43-61`｜代词指代不明确｜片段「它对这些来说是第五，所以叫以古传说为第五的」
  - 问题：*pañcamo etesaṃ* 的「这些」指前文四部吠陀，译文里「它」「这些」连用且无先行词提示，读者难以确定所指；句末「以古传说为第五的」中心语缺失，悬一个「的」。
  - 建议：补出先行词，如「古传说对这四部吠陀而言是第五，所以（这些吠陀）叫‘以古传说为第五的吠陀’」。

- `100-611-24-30`｜关键词语意不明确｜片段「是讲各种作法安排的学问」
  - 问题：*kiriyākappavikappo* 指诗文作法的体裁、格式规定，「各种作法安排」过于空泛，读者无法知道所指为何种学问。
  - 建议：具体化，如「是讲诗文作法与体裁格式的学问，用来帮助诗人作诗」。

### 🟦 suggestion

- `100-610-42-55`｜语言风格不统一｜片段「所以叫诵读者（ajjhāyaka）」
  - 问题：同一词 *ajjhāyaka* 在上一句黑体作「能诵读吠陀」，此句作「诵读者」，术语两译。
  - 建议：统一为「诵读者（ajjhāyaka）」，被解释词的译法再与本文层核对。

- `100-610-56-59`｜该使用而没有使用统一术语｜片段「他能忆持咒语（mante dhāreti）」
  - 问题：*manta* 译「咒语」，而同一所指在 611 段作「吠陀」「三部吠陀」，婆罗门典籍在译文里有两个名字；「咒语」也偏向汉语民俗义。
  - 建议：统一为「明咒（manta）」或「吠陀经文」，并登记进 `knowledge/terms.md`。

- `100-609-2-14`｜语言表达不够流畅｜片段「祖父的一个世代（pitāmahassa yugaṃ）就叫祖父的世代（pitāmahayuga）」
  - 问题：一句内三处夹注、两个近乎同形的汉语词相接，构词说明的层次被夹注打断。
  - 建议：精简为「祖父的世代（pitāmahassa yugaṃ）就称为 pitāmahayuga」式的单注写法，或只在首处夹注。

- `100-607-71-99`｜代词指代可能不够明确｜片段「假如他不跟我说话」
  - 问题：此处「他」指世尊，但同一句稍后出现「沙门乔达摩」，两种称呼交替，读者需回溯上一句才能确定所指。
  - 建议：首处明确为「假如世尊不跟我说话」。

- `100-611-43-61`｜复杂的嵌套句整句语言逻辑理解困难｜片段「而所谓古传说，就是那种带有“据说如此，据说如此”这类说法的、被称为古代故事或者被称为帝王之学的东西」
  - 问题：单句套入三重定语，「的、……的东西」连环，对读者不友好。
  - 建议：拆为两句，先说古传说是带「据说如此」这类说法的文献，再说它又被称为古代故事或帝王之学。

- `100-609-52-67`｜语言风格不统一｜片段「把这个人赶走，要他干什么」
  - 问题：*kiṃ iminā* 译「要他干什么」口语色彩明显，与全篇书面语体略有落差。
  - 建议：改「把这个人赶走，留着他有什么用」。

- `100-608-41-63`｜该使用而没有使用统一译法（待跨层核对）｜片段「于是说了**乔达摩先生，在这里**等等这番话」
  - 问题：黑体引词把 *idha, bho gotama* 调整为「乔达摩先生，在这里」，语序与原文相反。汉语如此调序可读性更好，但「被解释词与父层逐字同译」是硬约束，本次未注入本文层（AN 3.59）译文，无法核对是否一致。
  - 建议：与本文层该句译文比对后统一；若本文层作「在这里，乔达摩先生」，此处应随之改回。
