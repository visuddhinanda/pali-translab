## 二、义注（父层）释义核对

### 必改项

**§696 句 182-696-86-89 `Sakalan ti sabbabhāgavantaṃ`**
- **问题**：术语对应断裂 — 本层把 `sakalaṃ` 译作「**完整**」，但父层 100-686-23-29 已把 `kevalaṃ` 译作「完整」（「这里的 **完整** 是“全部”的同义词」）。于是本 chunk 内「完整」同时承担 `kevala` 与 `sakala` 两个词，而这两个词在本段正是一组被区分的释义关系：复注先释 `kevala`（696-35-49「这里的 **完整** 一词表示毫无遗漏」），再释父层用来解释它的 `sakala`（696-86-89）。两者都译「完整」，读者看到的就是「完整就是具备一切部分」——自我定义，释义链断掉。
- **义注**：100-686-23-29「**Kevalaparipuṇṇan** ti ettha **kevalan** ti sakalādhivacanaṃ」——`sakala` 是用来**解释** `kevala` 的词，不是同一个词。
- **建议**：`kevala` 保留父层的「完整」不动（硬约束）；`sakala` 另译，取「全部」以承接父层「是‘全部’的同义词」这条释义线，即 696-86-89 改作「**全部**，就是具备一切部分」。这样 696-35-49「**完整** 一词……是‘全部’的同义词」→ 696-86-89「**全部**，就是具备一切部分」，释义链才连得上。相应地 696-90-94 `Paripuṇṇamevā`（父层「全都是完整无缺的」）不受影响。

**§694 句 182-694-23-31**
- **问题**：误译，与所释词义相反 — 译文作「由于发音时口腔张开，不让双唇接触就发出声音，所以叫**全是闭唇不开的音**」。前半「口腔张开、双唇不接触」（`vivaṭakaraṇatāya oṭṭhe aphusāpetvā uccāretabbato`）与后半的译名「闭唇不开」正好相反，同一句自相矛盾。
- **义注**：父层 100-683-36-59 把 `sabbaniroṭṭhabyañjanā` 译作「全是闭唇不开的音」。该译名本身有问题：`niroṭṭha` = `nir-oṭṭha`，「**离**唇、不用唇」，复注此处正是在给出理由——发音时双唇不相触，所以叫「无唇音」。父层译「闭唇不开」把 `nir-` 读成了「闭」，方向译反了。
- **建议**：这是**父层译文的错**，不是本层的错。本层受「黑体与父层逐字相同」硬约束，无法单方面改。处理方式：
  1. 本层**暂依父层**保留「全是闭唇不开的音」，但**删掉自相矛盾的理由句改写**，不能让一句话自己打自己；
  2. 同时把父层 100-683-36-59 的 `sabbaniroṭṭhabyañjanā` 译名列为**跨层待修项**，建议父层与本层一并改为「**全是不用唇的音**」或「**全是离唇音**」，届时本层理由句「由于发音时口腔张开，不让双唇接触就发出声音」正好成立。
- **注**：此项需 harmonize 步跨层统稿处理，review 不改译文。**务必不要只改本层**——单改本层会破坏被解释词对应。

**§694 句 182-694-32-39**
- **问题**：同类 — `vissajjanīya` 本义是「送气」（`vissaṭṭha` 放开、不收束），译文「由于一切音都带着送气」与译名「全是送气放开的音」方向一致，**本句无矛盾**。但请与上一条并看：父层把 `vissaṭṭha` 译「送气放开」、把 `niroṭṭha` 译「闭唇不开」，两个译名里都出现「不开/放开」，容易混。harmonize 时若调整 `niroṭṭha`，本条可不动。
- **建议**：不改，仅记录。

### 建议项（非必改）

**§695 句 182-695-29-32**
- **问题**：`Tadeva lahukaṃ lahukameva` 译作「短音本身就轻，所以它就是**轻音**」。巴利是「那个（短音）正是轻的，就是**轻音**」，译文补出的「所以」制造了因果推论，原文只是同一判断的复述。
- **建议**：改作「那（短音）本身就是轻的，所以就是**轻音**」或更贴原文「那个就是轻的，就叫做**轻音**」。属语气轻重问题，非错译。

**§695 句 182-695-37-41**
- **问题**：`Ṭhānakaraṇāni niggahetvā uccāretabbaṃ niggahitaṃ` 译「把发音部位和发音器官**收紧**之后发出的音，叫做**鼻音**」。`niggahetvā` = 抑制、收住，译「收紧」可；但本句与 695-2-12「放松」（`sithilāni`）、695-53-58「完全放开」（`vissaṭṭhāni`）构成一组三分，「收紧 / 放松 / 完全放开」在汉语里层级不整齐（「收紧」对「放松」，「完全放开」又在「放松」之上）。
- **建议**：三处统一为「收住 / 放松 / 完全放开」或「抑止 / 放松 / 放开」，让三分关系在译文里看得出来。

**§697 句 182-697-33-54**
- **问题**：`catuppamāṇikassa lokassa` 译「以四种标准来判断的世人」，可读，但下一句 697-55-71 出现「以法为标准和以外表粗朴为标准」（`dhammappamāṇa`、`lūkhappamāṇa`），是这「四种标准」中的两种。译文没有任何提示让读者知道两句在说同一套分类。
- **建议**：697-33-54 改作「能使按四种标准（取信）的世人」，或在 697-55-71 加「四种标准中的……」字样点出关系。不必加夹注。

**§697 句 182-697-72-79**
- **问题**：`kosiyavatthu kathetabbaṃ` 译「应当讲说憍尸耶的事例」。`Kosiya` 此处为人名/天名音译，父层未出现该词，无对应可循。「憍尸耶」是 `Kosiya`（憍尸迦/帝释别名，亦有长老名）的一种汉译，但按 `terms.md` 未登记。
- **建议**：译名可用，但宜首次出现夹注巴利原词：「应当讲说憍尸耶（Kosiya）的事例」。符合 `style.md` 第二节「罕见术语首次出现附简注」。定案后补进 `terms.md`。

## 三、跨段一致性

- **`byañjana`**：本 chunk 译法分布 — §694/§695 多作「字音」，§696-11-34 作「词句与字音」（`padabyañjanāya`，此处 `pada`+`byañjana` 合译，合理），§694-48-60 与 §696 的黑体引用处作「文辞」（随父层）。**判定：可接受**，但分工须说清：黑体引自父层者用「文辞」（父层定译），复注自身展开讨论语音时用「字音」。目前正是这样处理的，一致性成立。⚠️ 唯一隐患是 §694-48-60 一句内同时出现「字音」与「文辞」（「全都只按字音中的一部分来发声，因此字音并不完备，就这样说它们是**“文辞不完备的”**」）——读者可能以为是两个概念。建议该句改作「……因此字音并不完备，所以说它们是**“文辞不完备的”**（字音即文辞）」，或在本 chunk 首次出现「字音」处加一次夹注「字音（byañjana，父层译作‘文辞’）」。**列为建议项**。
- **`akkhara`**：§695 一律译「字音」（695-2-12、13-22、59-69、70-77）。但 `akkhara` 与 `byañjana` 是两个词，§695-59-69 一句内两词并出：「对**字音**的分辨……也就是产生**字音**的那个心」——前者 `byañjanabuddhiyā`，后者 `akkharuppādaka`，译文合为一词，读者看不出原文在区分。§695-70-77 同样：「因为一切**字音**都是由心生起的……所以叫做**字音**」（`sabbāni akkharāni` / `byañjanāni`），原文正是在说「一切 akkhara 都是心生的，而且因为显示义，所以也叫 byañjana」——这是一条**定义性**的句子，两词合译后整句变成同义反复，释义失效。
  - **必改**：`akkhara` 另译「字母」或「音字」。建议 695-70-77 改作「因为一切**字母**都是由心生起的，而且由于它们显示出所要表达的意义，所以也叫做字音（byañjana）」；695-59-69 改作「……也就是产生字母的那个心，有十种类别」。

## 四、逐句问题汇总（按坐标）

### §694

**句 182-694-23-31**
- **问题**：误译/自相矛盾（见第二节）— 理由句与译名方向相反。
- **建议**：交 harmonize 跨层处理，父层 `sabbaniroṭṭhabyañjanā` 译名一并修正为「不用唇的音」；本层不单改。

### §695

**句 182-695-29-32**
- **问题**：因果连词 `所以` 为译文所加，原文无推论关系。
- **建议**：改「那（短音）本身就是轻的，就叫做**轻音**」。

**句 182-695-37-41 / 182-695-2-12 / 182-695-53-58**
- **问题**：`niggahetvā` / `sithilāni` / `vissaṭṭhāni` 三者在译文中作「收紧 / 放松 / 完全放开」，层级不整。
- **建议**：统一为「收住 / 放松 / 放开」一组。

**句 182-695-59-69 与 182-695-70-77**
- **问题**：**必改** — `akkhara` 与 `byañjana` 合译为「字音」，使定义性句子变成同义反复，释义失效。
- **义注**：父层 100-685-2-12 把 `byañjanabuddhiyā pabhedo` 定为「对字音的分辨……十种类别」，`byañjana`=「字音/文辞」已被占用；`akkhara` 须另立译名。
- **建议**：`akkhara` → 「字母」。695-70-77 改作「因为一切**字母**都是由心生起的，而且由于它们显示出所要表达的意义，所以也叫做字音」；695-59-69 的「产生字音的那个心」改「产生字母的那个心」。

### §696

**句 182-696-35-49**
- **问题**：**必改** — 引号形制与父层不一致（单引号 ‘全部’ vs 父层双引号 “全部”）。
- **建议**：改为 `因此说**“是“全部”的同义词”**` → 嵌套冲突，故改作：外层用双引号、内层「全部」用单引号，即 `因此说**“是‘全部’的同义词”**`。**此处原译正是嵌套内层，判定原译正确，撤回本条**。详见下方更正。

**句 182-696-86-89**
- **问题**：**必改** — `sakala` 与父层 `kevala` 的译名撞车，释义链断裂（见第二节）。
- **建议**：改作「**全部**，就是具备一切部分」。

**句 182-696-155-179**
- **问题**：引号 — `‘他这样说法……就阐明了梵行’` 处于「因此说**“……”**」的内层，用单引号正确。✅ **本条撤回**。
- **另**：「同格」（`samānādhikaraṇa`）为语法术语直译，一般读者难解。
- **建议**：改「他把与**梵行**这个词指同一事物的所有词句连起来」，或保留「同格」并夹注巴利原词。**建议项**。

**句 182-696-72-85**
- **问题**：「宣讲所为的那个目的」略带文言省略。
- **建议**：改「宣讲所要达到的那个目的」。

### §697

**句 182-697-29-32**
- **问题**：`Tathānurūpānan ti tādisānaṃ` 译「**这样的**，就是那样的」——汉语里「这样的」与「那样的」几乎同义，整句成了空转，读者不知所云。原文是用近义词互释（`tathānurūpa` ← `tādisa`），但汉语做不到这种互释。
- **建议**：改为点出所指，如「**这样的**，就是像上面所说那样的」。这是复注常见的同义互释句，译文须补出指向才成话。**必改**。

**句 182-697-55-71**
- **问题**：`lūkhappamāṇa` 译「以外表粗朴为标准」。按传统四分（`rūpappamāṇa` 色量 / `ghosappamāṇa` 声量 / `lūkhappamāṇa` 粗量 / `dhammappamāṇa` 法量），`lūkha` 指以修行者的简朴苦行外相来判断，译「以外表粗朴为标准」达意。✅ 不改。
- **另**：「另外那一句」（`itarena itaresaṃ`）指代过虚，读者不知指哪一句。
- **建议**：改「而另一句（即“那位乔达摩尊者是什么样的……”）显示的是能使其余众生生起净信」，或至少作「而前面那一句」。**建议项**。

**句 182-697-72-79**
- **问题**：`Kosiya` 首次出现未夹注巴利原词。
- **建议**：作「憍尸耶（Kosiya）」。

**句 182-697-80-84**
- **问题**：`ubhayapakkhikā` 译「两边都占的」，与所释的「两边都靠的人」（父层定译）用字不同，同一概念在一句内出现两种说法。
- **建议**：改「是说他们按邪见和正见来说是两边都靠的」，与被解释词用字统一。**必改**（一致性）。
