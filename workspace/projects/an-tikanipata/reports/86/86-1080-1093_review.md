# Review — 86:1080-1093（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分句有，无 nissaya 的句子不出单句意见）

## 跨段一致性

- **samphappalāpī**：§1081 译“说没有意义的废话”，§1088 译“说绮语（samphappalāpa）” → 建议统一为“说没有意义的废话”。依据：nissaya 给 `သမ္ဖပ္ပလာပီ= ပြိန်ဖျင်းသော စကားကို ပြောဆိုသူသည်`（说空洞无益的话的人），另一种释义是“说毁坏利益安乐、没有意义的事”。§1088 的夹注用了名词形 samphappalāpa，与原文 -ī 形容词形不符。而且这个词首次出现在 §1081，那里没有夹注，第二次出现才加，不合“首次出现夹注”的规矩。
- **abhijjhālu / anabhijjhālu**：§1082 译“心怀贪求”、§1085 译“不怀贪求”，§1089 译“有贪欲”、§1092 译“没有贪欲” → 建议统一为一组，例如“贪求心重／贪求心不重”。依据：nissaya 对 -ālu 的释义是 `များသော အဘိဇ္ဈာလောဘရှိသည်`（有很多贪求）、`အားကြီးသော အဘိဇ္ဈာလောဘမရှိသည်`（没有强烈的贪求），强调“程度重”，两组现译都没有表达出来。
- **viparītadassano / aviparītadassano**：§1083 译“所见颠倒”、§1086 译“所见不颠倒”，§1090 译“见解颠倒”、§1093 译“见解不颠倒” → 建议统一为“所见颠倒／所见不颠倒”。依据：nissaya 把 diṭṭhi 释为 `အယူ`（见解），把 dassana 释为 `အမြင်`（看法、所见），两者是不同的词。§1090/§1093 把两者都译成“见解”，同一句里出现“持有错误的见解，见解颠倒”，区分丢失，读来重复。
- **natthi/atthi dinnaṃ… 一句的处理**：§1083 和 §1086 字面译为“没有布施，没有祭祀，没有供养”，§1090 和 §1093 译为“布施没有果报，祭祀没有果报” → 两种处理必须统一。依据 nissaya，建议采用补出“果报”的处理（详见 §1083 句 22-74）。
- **同一句里 abhiññā sacchikatvā 的译法**：§1083 和 §1086 作“亲身以证智证知”，§1090 和 §1093 作“亲自以智慧证知、现证” → 建议统一，并保留“证知”与“现证”两步（依据见 §1083 句 22-74）。
- **samaṇabrāhmaṇā**：§1083 和 §1086 作“沙门和婆罗门”，§1090 和 §1093 作“沙门、婆罗门” → 建议统一为“沙门和婆罗门”。
- **apāyaṃ**：§1083 译“苦界”，§1090 译“恶处” → 建议统一为一个译法。
- **kāyassa bhedā**：§1083 和 §1086 作“身体毁坏”，§1090 和 §1093 作“身体破坏” → 建议统一为“身体毁坏”。
- **upapajjanti 及处所的句式**：§1083 和 §1086 作“投生到……地狱／天界”，§1090 和 §1093 作“就投生到……之中” → 建议统一句式，去掉多出的“就”和“之中”。
- **sugatiṃ saggaṃ lokaṃ**：§1086 译“善趣、天界”，§1093 译“善趣、天上的世界” → 建议统一为“善趣、天界”。
- **“…hetu vā”的“或”**：§1083 和 §1086 每句都译出“或者”。§1093-48-63 的单句译文没有“或”，§1090-85-97 和 §1093-99-133 的“由于……”也都略去了 vā → 建议统一，把“或”保留下来。
- **段号格式**：§1081 作“118.”，§1088 作“一一九、” → 建议统一为一种格式。
- **Katamā tisso**：§1081 译“是哪三种呢？”，§1088 和 §1091 译“哪三种呢？” → 建议统一为“是哪三种呢？”。
- **Imā kho … tisso**：§1083 和 §1086 作“这就是三种失坏／成就”，§1090 和 §1093 作“这就是那三种失坏／成就” → 建议统一为“这就是三种……”。依据：nissaya 给 `ဣမာ တိဿော`（这三种），imā 是近指，不该译成“那”。
- **apaṇṇaka**：经题 §1087 译“不退堕经”，正文 §1090 和 §1093 的 apaṇṇako 没有译出，只留了夹注 → 经题与正文应当用同一个译法，详见 §1090 句 71-84。

## §1082 句 86-1082-11-19
- **问题**：词义程度 — abhijjhālu 的 -ālu 表示“多、重”。nissaya：`အဘိဇ္ဈာလု= များသော အဘိဇ္ဈာလောဘရှိသည်`（有很多贪求）。“心怀贪求”没有体现程度。
- **建议**：改为“贪求心重”之类，并与 §1085、§1089、§1092 统一（见跨段一致性）。

## §1083 句 86-1083-22-74
- **问题**：隐含成分没有补出 — nissaya 对 dinnaṃ / yiṭṭhaṃ / hutaṃ 都补出了“果报”：
  - `ဒိန္နံ= လှူဖွယ်ဝတ္ထုပေးလှူရခြင်း၏ အကျိုးသည်`（布施的果报）
  - `ယိဋ္ဌံ= …ပေးလှူပူဇော်ခြင်း၏ အကျိုးသည်`（大供祭的果报）
  - `ဟုတံ= ဧည့်သည်တို့အား…ပေးကမ်းပြုစုရခြင်း၏ အကျိုးသည်`（款待宾客的果报）

  nissaya 还特别注明：dinna 字面只指施物，这里要理解到施物的果报。所以“没有布施”的字面译法会让读者误以为否定的是布施这件事本身。
- **建议**：改为“布施没有果报，祭祀没有果报，款待没有果报”。这样也与 §1090 一致。
- **问题**：隐含成分 — nissaya 对 mātā / pitā 同样补出了果报：`မာတာ= အမိ၌ ရိုသေစွာ ပြုစုခြင်း, ရိုင်းစိုင်းစွာ ပြုမူခြင်း၏ ကောင်းကျိုးဆိုးကျိုးသည်`（善待或恶待母亲的善恶果报），父亲同理。
- **建议**：至少要与上面“布施”一项的处理方针一致。如果补出果报，可以译成“孝敬或冒犯母亲没有善恶果报”之类。如果为保留经文字面而不补，也要在全书统一，并且要整句一起考虑。
- **问题**：hutaṃ 的词义 — nissaya 释为“给宾客好的物品、加以款待”，“供养”的所指太宽。
- **建议**：考虑译成“款待”或“待客”。
- **问题**：漏译 — abhiññā 与 sacchikatvā 是两步。nissaya：`အဘိညာ= …ဉာဏ်ဖြင့် သိတော်မူကြ၍`（以智了知），`သစ္ဆိကတွာ= မျက်မှာက် ပြုကြကုန်၏`（现证、亲见）。“以证智证知”把两步并成了一步，sacchikatvā 没有译出。
- **建议**：改为“亲自以证智了知并现证此世与他世，然后宣说”。
- **问题**：多出成分 — pavedenti 是直陈式。nissaya 作 `ဟောပြောသိစေတော်မူကြကုန်၏`（宣说、使人知道），没有“能够”的意思。
- **建议**：删去“能够”。
- **问题**：句法 — sammaggatā 在 nissaya 中是 `…နိဗ္ဗာန်လမ်းကြောင်းသို့ ဖြောင့်မှန်စွာ ကြွသွားတော်မူကြကုန်သော`（正确地行走在通往涅槃的道路上的）。“正行”一词在汉语里容易被读成名词。
- **建议**：考虑改为“行于正道、正确修行的”。不改也可以，但要与 §1086 一致。

## §1083 句 86-1083-82-97（同理适用于 98-113、114-130）
- **问题**：句法关系 — nissaya 把 apāyaṃ / duggatiṃ / vinipātaṃ 处理为修饰 nirayaṃ 的定语：`…ကင်းသော`、`…ဖြစ်ရာတည်ရာဖြစ်သော`、`…ကျရောက်ရာဖြစ်သော`、`နိရယံ= …ငရဲသို့`，结构是“……的地狱”。译文“苦界、恶趣、堕处、地狱”是四项并列，与 nissaya 的句法读法不同。
- **建议**：这一组是固定套语，可以保留并列译法，但应当在全书统一。如果依照 nissaya，可以改为“投生到苦界、恶趣、堕处的地狱”。（§1086 的 sugatiṃ saggaṃ lokaṃ 在 nissaya 中同样以 lokaṃ 为中心词，现译“善趣、天界”已经把 sagga 和 loka 合在一起，可以接受。）

## §1086 句 86-1086-20-70
- **问题**：与 §1083 句 22-74 相同。atthi dinnaṃ 等项缺少隐含的“果报”，sacchikatvā 漏译，多出了“能够”。
- **建议**：按 §1083 的改法同步修改，“有”和“没有”两句保持严格对称。

## §1090 句 86-1090-71-84
- **问题**：漏译 — apaṇṇako 是 maṇi 的定语。nissaya：`အပဏ္ဏကော= မချွတ်မလွှဲ အထိုင်မြဲသော`（不偏不失、落地必定稳住的），`မဏိ= မျက်နှာပြင် ခြောက်ဖက်ရှိသော အံစာလုံးသည်`（有六个面的骰子）。译文“六面的骰子”只译了 maṇi，apaṇṇako 只出现在夹注里，正文没有对应的词。而且 apaṇṇaka 正是经题用的词，经题译“不退堕”，正文却没有这个词，两处对应断了。
- **建议**：改为“就好像一颗落地必稳的六面骰子（apaṇṇako maṇi）”，并按这个词义重新斟酌经题，例如“无偏失经”或“必稳经”，让经题与正文同译。
- **问题**：用词 — suppatiṭṭhitaṃyeva patiṭṭhāti 在 nissaya 中是 `မယိုင်မလဲ အထိုင်မြဲလျက်သာလျှင် ထိုင်နေ၏`（不倾不倒、稳稳落定），说的是骰子落定，“立住”不够贴切。
- **建议**：改为“都稳稳地落定”。§1093-85-98 同步修改。
