# Review — 86:826-841（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **aveccappasāda**：§828 译“不动摇的净信”，§829、§830 译“不坏净信” → 建议统一为“不坏净信”（传统译法，本 chunk 出现次数也更多）。nissaya：`အဝေစ္စပ္ပသာဒေ= ဂုဏ်တော်တို့ကို ဟုတ်မှန်စွာ သိ၍ ခိုင်မြဲစွာ ကြည်ညိုခြင်း`（如实了知功德之后的坚固净信），“不坏”与“坚固”相合。
- **nivesetabbā**：§828 译“使他们安住”，§831 译“使他们进入” → 统一为“使他们安住”。nissaya：`နိဝေသေတဗ္ဗာ= စွဲမြဲသက်ဝင်စေထိုက်`（应使其深入并稳固）。§826 经题“住立经”（Nivesaka）也应随之改，建议作“安住经”，让经题与经文的关键词对得上。
- **samādapetabbā … patiṭṭhāpetabbā 整组**：§828 作“劝导他们、使他们安住、使他们确立”，§831 作“对他们……加以劝导、使他们进入、使他们确立” → 两处句式统一为 §828 的写法。
- **sotabbaṃ maññeyyuṃ**：§828 译“愿意听取你们话的人”，§831 译“认为值得听取你们话的人” → 统一为 §831。依据：nissaya `သောတဗ္ဗံ= နာယူထိုက်၏ဟူ၍ … မညေယျုံ= ထင်မြင်မှတ်သား`（认为“值得听”），这里的意思是“认为值得”，不是“愿意”。
- **开头套语**（§827 / §833 / §838）：“走到世尊面前”与“走到世尊那里”不一致；“向世尊致敬”与“向世尊礼敬”不一致；“这样说道”与“这样说”不一致；“那时”与“当时”不一致 → 同一套语全 chunk 统一，建议取“那时……走到世尊那里……向世尊礼敬……这样说道”。
- **Kittāvatā … bhavo hoti**：§833 译“到什么程度才有所谓的有呢”，§838 译“到什么程度才叫做有呢” → 统一。`hoti` 在 nissaya 里是 `ဖြစ်`（生起、成立），不是“叫做”，建议两处都作“到什么程度才有‘有’呢”。
- **api nu kho … bhavo paññāyetha**：§834–836 译“还能看出有欲有吗”，§839–841 译“还会有欲有被认知吗” → 统一。nissaya `ပညာယေထ= ထင်ရှားပါဦးမည်လော`（还会显现吗），建议作“欲有还会显现吗”。这样也避开了“有欲有”这种叠字别扭。
- **No hetaṃ, bhante**：§834–836 作“大德，不会的。”，§839、§840 作“大德，不会有。”，§841 作“大德，这是不会的。” → 统一为“大德，不会的。”
- **Iti kho**：§834–840 作“所以说”，§841 作“这样说来，业就是田地……” → 统一为“所以说，业是田地……”。nissaya `ဣတိ= ထို့ကြောင့်`（因此）。
- **avijjānīvaraṇānaṃ**：§834–836 作“被无明蒙蔽”，§839–841 作“被无明覆盖” → 统一，建议用“被无明遮蔽”。nissaya `အဝိဇ္ဇာသည်တားဆီးအပ်ကုန်သော`（被无明障碍的）。
- **hīnāya dhātuyā**：§834 作“低等的界”，§839 作“下劣的界” → 统一。中、上两级已统一为“中等”“殊胜”，下级建议取“低劣的界”，与“殊胜”对称。
- **patiṭṭhita**：§834–836 作“确立下来”，§839–841 作“安住于” → 两经主语不同（识／思、愿求），但用的是同一个动词，应统一，建议都作“安住于”。
- **punabbhavābhinibbatti**：§834–836 作“将来的再生”，§839–841 作“后有的生起” → 统一为“后有的生起”。nissaya `နောက်ထပ်ဘဝသစ် ဖြစ်ခြင်း`（再一次新有的生起）。
- **Evaṃ kho, ānanda, bhavo hoti**：§836 作“这样就有了有”，§841 作“就是这样才算是有” → 统一为 §836。nissaya `ဧဝံ= ဤအဝိဇ္ဇာ, တဏှာ, ကံ ဝိညာဏ်ဟူသော တရားအပေါင်းဖြင့် … ဟောတိ= ဖြစ်၏` 说的是“由此生起”，不是“算是”。
- **经题**：§832 作“第一有经”，§837 作“有经（第二）” → 统一为“第二有经”。
- **异读注的引号格式**：§834、§835 括注里写成“‘ 阿难，这样就有了有 ’”，引号内侧多了空格 → 去掉空格，改为“‘阿难，这样就有了有’”。

## §828 句 86-828-2-38
- **问题**：词义 — `sotabbaṃ maññeyyuṃ` 译成“愿意听取”。nissaya：`သောတဗ္ဗံ= နာယူထိုက်၏ဟူ၍ … မညေယျုံ= ထင်မြင်…ကုန်ငြားအံ့`，意思是“认为（你们的话）值得听取”。
- **建议**：改为“以及那些认为值得听取你们话的人”。
- **问题**：词义（次要） — `amaccā` 译“同僚”。nissaya 作 `သူငယ်ချင်း`（伙伴、知交），偏重私人交情，“同僚”带有官场色彩。
- **建议**：可考虑改为“同伴”；如果保留“同僚”，就压低该句 confidence。
- **问题**：词义（次要） — `samādapetabbā` 的 nissaya 是 `ကောင်းစွာ နာယူစေထိုက်`（应使其好好领受）。“劝导”只表达了劝，没有表达使对方领受。
- **建议**：可作“劝勉他们受持”。改的话，§828 与 §831 全组要一起改。

## §829 句 86-829-2-27
- **问题**：指代与句法 — `tatridaṃ aññathattaṃ` 译“这里所说的变异是指这个意思”，“这个意思”读起来像回指前文。nissaya：`တတြ= ထို "နတွေဝ" စသော ငါ့စကား၌ … ဣဒံ= ဤသည်ကား … အညထတ္တံ= (လားရာဂတိ၏) … ဖောက်ပြန်ပြောင်းလဲသည်အဖြစ်တည်း`，即“在‘不会变异’这句话里，所说的变异是指下面这个（去处的变异）”。`idaṃ` 指向下一句的堕恶趣。
- **建议**：改为“这里所说的变异，是指这样的情形：”，以冒号引出 §829 句 28–45。§830 同句同样处理。
- **问题**：格（次要） — nissaya 把圣弟子读作属格：`အရိယသာဝကဿ … အညထတ္တံ`，即圣弟子的（净信与去处的）变异。现译“圣弟子却不会发生变异”笼统说成人本身变异，与上文“四大……发生变异”（四大自身的性质变异）的语义层次不对应。
- **建议**：可作“圣弟子却不会有变异”，或在报告中备注“变异”指去处的改变，译文不必展开。

## §829 句 86-829-28-45
- **问题**：词义（次要） — `vata` 译“竟然”。nissaya 作 `အမှန်တကယ်ပင်`（确实、真的），是强调词，不带“出乎意料”的语气。
- **建议**：可作“阿难，说具足……的圣弟子会投生地狱……，这种情形确实是不存在的”。如果保留“竟然”，就压低该句 confidence。§830 句 36–54 同。

## §833 句 86-833-38-49
- **问题**：句法 — “到什么程度才有所谓的有呢”中，“所谓的”是多补的成分。nissaya：`ကိတ္တာဝတာ= အဘယ်မျှလောက် … အကြောင်းတရားဖြင့် … ဘဝေါ= ဘဝသည်။ ဟောတိ= ဖြစ်ပါသနည်း`（由多大范围的因法，有才生起）。
- **建议**：改为“大德，到什么程度才有‘有’呢？”，并与 §838 统一。

## §834 句 86-834-2-19
- **问题**：词义与表达 — `paññāyetha` 译“看出”，又跟“有欲有”连用，读起来像“看出存在欲有”，“有”字叠用。nissaya：`ပညာယေထ= ထင်ရှားပါဦးမည်လော`（还会显现吗），`ကာမဘဝေါ= ကာမဥပပတ္တိဘဝ`（欲界的生有）。
- **建议**：改为“阿难，如果没有会在欲界成熟果报的业，欲有还会显现吗？”。§835、§836、§839–841 同步处理。

## §834 句 86-834-29-57
- **问题**：格式 — 译文里夹着校勘括注“（异读作 sineho）”。这是巴利文本的校勘信息，与 sneho/sineho 的词义无关，汉译不需要体现。
- **建议**：从译文中删除，需要的话改作脚注。

## §834 句 86-834-58-96
- **问题**：格 — `sattānaṃ` 在 nissaya 里是属格（`သတ္တဝါတို့၏`），修饰 `viññāṇaṃ`，即“众生的识”。译文作“对于那些……众生，识在……”，属格关系被弱化成了话题结构。
- **建议**：改为“被无明遮蔽、被渴爱束缚的众生，他们的识安住于低劣的界”。不要用“其”。§835、§836、§839–841 同一结构，一并处理。
- **问题**：句法 — `evaṃ` 在 nissaya 里是 `ဤသို့တည်လသော်`（这样安住了以后），是条件从句。“这样就有了将来的再生”没有体现“安住之后”的条件关系。
- **建议**：改为“这样安住之后，将来就会有后有的生起”。

## §839 句 86-839-44-59
- **问题**：词义 — `cetanā` 与 `patthanā` 前加的“造业的”与 nissaya 不符。nissaya：`စေတနာ = ကံဟူသော စေတနာ`（即是业的思），`ပတ္ထနာ= ကံဟူသော တောင့်တတတ်သော တရား`（即是业的希求之法）。思和愿求本身就是业，并不是“造业”的思。
- **建议**：改为“作为业的思（cetanā）……作为业的愿求（patthanā）……”。§840、§841 同步改。
- **问题**：格 — `sattānaṃ` 属格，与 §834 同一问题。
- **建议**：改为“被无明遮蔽、被渴爱束缚的众生，他们那作为业的思安住于低劣的界……”。
