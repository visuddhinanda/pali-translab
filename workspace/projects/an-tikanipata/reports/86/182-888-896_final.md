**数据基准说明**：本次评估只拿到巴利原文与目标 channel 的现有译文，**没有注入义注（aṭṭhakathā）层与 nissaya 逐词注解**。本段本身是复注（ṭīkā），它所解释的父层（《增支部》义注 `anīhatadosa` / `adhicitta` / `abhiññā sacchikaraṇīya` 等条）文本缺失，因此：

- 「被解释词与父层逐字同译」这条硬约束**无法核验**——译文多处写「所以义注说**“……”**」（`182-890-2-23`、`182-893-13-22`、`182-894-2-35`），引号里的内容是否与义注层译文逐字一致，本次查不了。这是信心指数压到 68 的主要原因。
- 词级格/句法角色缺 nissaya 对照，准确性判断只能靠原文形态自证。

**准确性**（88）：整体词义与句法关系把握可靠，复注特有的「释词体」（`X-ti Y`、`A ca so B cāti AB`、`tassa bhāvo`）结构基本都译出来了，构词分析（`ya-kāralopa`、`ekaṃ udeti → ekodi`）处理得当。扣分主要在三处：`pahaṭamatta` 释为 `āhaṭamatta`，译文「只要刚一被打到」把 `matta`（仅、刚……就）的限定义与被动语态糊在一起，且与所释词的训释关系（打击/搬运之辨）未落地；`182-892-2-8` 整句的释词结构（有财释）译得缠绕，「这个定所剩下的……所以把它叫做……（的定）」用括号补「的定」，已属译者在正文里打补丁；`182-895-2-9` 的 `abhiññāpādā ca abhiññāpādakajjhānañca abhiññāpādakajjhānāni`（相违释合称）译为「合起来称为」尚可，但两个被合并项的区别在汉语里没立住。

**风格符合度**（82）：主体是合格的现代书面汉语，禁例表里的「此中/故为/彼等」一类完全没有出现，这点好。但残留若干单音节文言虚词与半文半白句式：「依着十善业道而生起」「而作为观的基础」「缘着」反复出现（`缘着`在 891 段出现 5 次，属所释词 `ārabbha` 的固定译法，一致性上可接受，但「着」字句整体偏旧）；`182-894-48-67` 的「谁有亲眼所见，谁就是见证者」是文言「……者，……也」句式的变体；`182-890-38-74` 「想着“我要到……”而出门的时候」中「而」字承接偏文。另有两处标点问题：`182-890-75-89` 与 `182-894-2-35` 使用了破折号「——」作解释引导，风格文档允许全角破折号，但此处均可用「因为」「这是」收句，且 894 段一句内既有破折号又有括号夹注，句子过载。

**一致性**（85）：术语层面 `citta`/`adhicitta`/`ekodibhāva`/`ekaggatā` 一组处理尚稳，但存在两组内部不统一：

2. **夹注巴利原词的时机**——`style.md` 规定「首次出现夹注，其后只用汉译」。`gocarajjhatta`（`182-893-7-12`）、`vipassanūpakkilesa`（`182-891-92-97`）、`samaṇadhamma`（`182-890-38-74`）夹注了，但同样罕见的 `vatthukāma`（`182-891-2-7`）夹注了而上半句的 `kāma` 也夹注，一句内两处夹注过密；反过来 `niyakajjhatta`（`182-893-2-6`）、`sakkhibhabbatā`（`182-894-48-67`）这类更需要夹注的生词一个都没给。

**无 fatal**：主谓宾判断未发现错误，也未发现违背基本教理原则之处。

## 问题清单

### 🟧 error

- `182-889-15-18`｜错译（词义）｜片段「就是只要刚一被打到」
  - 问题：`pahaṭamattaṃ` 释为 `āhaṭamattaṃ`，`-matta` 表「仅仅是、刚……」，整体是名词性的「仅仅是被打击（搬来）的状态」，指金矿砂刚从矿里取来、尚未加工的阶段。译文「只要刚一被打到」转成了条件从句＋被动动词，既丢了名词性，也把「取来/搬来」的训释义改成了「打到」，与复注用 `āhaṭa`（搬来的）解释 `pahaṭa` 的用意相反。
  - 建议：按名词性短语译，并把训释关系显化，如「**刚刚打出来的**，就是刚刚取来的（还没有加工的）」。

- `182-892-2-8`｜导致误解的表达｜片段「这个定所剩下的只有关于法的念头，所以把它叫做**剩下的还是关于法的念头**（的定）」
  - 问题：原文 `avasiṭṭhā dhammavitakkā etassāti avasiṭṭhadhammavitakko, vipassanāsamādhi` 是有财释（bahubbīhi）：「这个（定）所余的只是法寻，故名『余唯法寻』者，即观定」。译文把被定义项译成一个完整小句「剩下的还是关于法的念头」，再括号补「（的定）」，读者会把黑体部分误读为「念头」而非「定」，被解释词的词性被改掉了。
  - 建议：被定义项译为名词性定语结构，如「**所余唯有法寻者**，就是观的定」，不靠括号补语救场。

- `182-895-2-9`｜漏译／意思归属｜片段「证智的诸依处，以及作为证智依处的禅，合起来称为作为证智基础的诸禅」
  - 问题：`abhiññāpādā ca abhiññāpādakajjhānañca abhiññāpādakajjhānāni` 是相违释（dvanda）复合词的拆解，两个被合并项「证智的诸基础（即神通本身所依的诸法）」与「作为证智基础的禅」是**不同所指**；译文两处都用「依处/基础」同一个词面，读者看不出被合并的是两样东西，拆解等于白做。
  - 建议：区分两项用词，如「证智的诸基础，和作为证智所依的禅那，两者合称『证智所依禅等』」。

### 🟨 warning

- `182-894-2-35`｜整句逻辑表达不规范｜片段「却说成了“abhiññā”（证智）——这是把 ya 这个字母省略掉（ya-kāralopa），从而把它重新表示成了先行动作的形式」
  - 问题：一句内混用了拉丁转写直接入正文（`“abhiññā”`）、圆括号汉译、破折号、第二个圆括号夹注巴利术语，四层嵌套；且「重新表示成了先行动作的形式」语义含混（`puna kālakiriyāniddeso`指再次以「先行时」即连续体形式标示）。普通读者读不下来。
  - 建议：拆为两句，正文统一用汉译＋单层夹注：「这里本该说『以证智应当亲证的』，却只说了『证智』。这是省略了 ya 音（ya-kāralopa），于是又变成了表示先行动作的形式。」

- `182-894-48-67`｜文言语体｜片段「谁有亲眼所见，谁就是见证者」
  - 问题：`yassa paccakkhaṃ atthi, so sakkhī` 的「谁……谁就……」对译是半文半白的判断句式（文言「……者，……也」的变体），与 `style.md` 第一节禁例精神相违。
  - 建议：改为现代判断句，如「亲眼见到的人，就是见证者」。

- `182-890-2-23`｜不导致误解的汉语语病｜片段「依着十善业道而生起的心，只是心而已；而作为观的基础的八种等至的心以及观的心」
  - 问题：「依着……而」为旧白话句式；「作为观的基础的……的心」连用三个「的」，定语套叠；分号后的「而」字转折多余。
  - 建议：「由十善业道生起的心，只是『心』；至于作为观的基础的八种等至之心、以及观的心……」——减一层「的」，去掉「依着……而」与多余的「而」。

- `182-892-9-14` / `182-893-32-38` / `182-892-40-46`｜关键词语意不明确（术语译名不统一）｜片段「没有达到心一境的状态」「成为心一境」「这是对一境性的称呼」
  - 问题：`ekaggabhāva` / `ekaggaṃ` / `ekaggatā` 三处分别作「心一境的状态」「心一境」「一境性」，`abyaggabhāva` 又作「不散乱的状态」，同一词族在相邻四句里四种面貌，读者无法把它们认作一个概念。
  - 建议：统一为「一境性」系（`ekaggabhāva`→一境性、`ekaggaṃ hoti`→成为一境、`abyaggabhāva`→不散乱性），并补进 `knowledge/terms.md`。

- `182-889-2-10`｜关键词语意不明确｜片段「**瑕疵还没有去掉**，就是粗的黑渣还没有除掉」
  - 问题：被解释词 `anīhatadosa` 译「瑕疵」而释义作「粗的黑渣」，`dosa`（在淘金喻中指矿砂里的杂质）与「瑕疵」之间的对应没有交代；同段 `kasāva` 译「杂渣」、`kāḷaka` 译「黑渣」，三个词共用「渣」字而层级关系不清。
  - 建议：`dosa` 在此喻中改译「杂质」，并让释义与被解释词词面呼应：「**杂质还没有除去**，就是粗的黑粒还没有除掉」；`kāḷaka` 统一作「黑粒」以区别于「杂渣」。

- `182-893-2-6` / `182-894-48-67`｜该使用而没有使用夹注｜片段「**自身之内**，这是对自己这一相续的称呼」「就是能作证的能力」
  - 问题：`niyakajjhatta`、`sakkhibhabbatā` 属罕见术语，`style.md` 要求首次出现夹注巴利原词；同段的 `gocarajjhatta` 夹注了，形成体例不一致（一对概念只注其一）。
  - 建议：补为「**自身之内**（niyakajjhatta）」「能作证的能力（sakkhibhabbatā）」。

### 🟦 suggestion

- `182-890-38-74`｜复杂嵌套句理解困难｜片段「而且在这里，饭前出去乞食，饭后从乞食回来，带着坐具，想着“我要到某棵树下、或某处林间、或某处山崖下去修沙门法（samaṇadhamma）”而出门的时候，也算是在修习增上心」
  - 问题：单句 90 余字，含四个连动短语＋一段引语＋夹注，主语（比丘）始终不出现，读者须读到句末「也算是」才知道句子在说什么。
  - 建议：拆成两句并点出主语：「这里还要说明：比丘饭前出去乞食，饭后从乞食处回来，带上坐具，想着『我要到某棵树下、林间或山崖下修沙门法（samaṇadhamma）』就出门——这时候他已经在修习增上心了。」

- `182-890-24-37`｜语言风格不统一｜片段「一再地从事；意思就是在这件事上专心努力的人」
  - 问题：前半「一再地从事」承接的是动作，后半忽然落到「……的人」，主语在分号两侧由动作切换为人，`anuyuttassa` 的属格身份只在后半体现。
  - 建议：前后统一到人：「……一再地从事的人；意思就是在这件事上专心努力的人。」

- `182-891-8-14`｜语言表达不够流畅｜片段「与所谓欲贪的那种欲相应的念头」
  - 问题：「所谓……的那种……」为冗赘指代，`kāmarāgasaṅkhātena kāmena` 只是「即欲贪之欲」。
  - 建议：「与欲（即欲贪）相应的寻，就是**欲寻**」。

- `182-890-75-89`｜语言表达不够流畅｜片段「——因为他所做的正是为了这个目的，也因为可以用这个说法来称呼他」
  - 问题：`tadatthenapi taṃsaddavohārato` 两个理由译得松散，「可以用这个说法来称呼他」把 `vohāra`（名言施设）说成了口语化的「说法」。
  - 建议：「因为他的所作正趣向于此，也因为依名言可以这样称呼。」

- `182-891-58-91`｜语言表达不够流畅｜片段「而要像石造的伞盖那样把我看得很重」
  - 问题：`pāsāṇacchattaṃ viya garuṃ kareyyuṃ` 的喻点是「沉重」与「尊重」的双关，译文「看得很重」口语，喻体「石造的伞盖」对汉语读者缺解释。
  - 建议：加半句点明喻点，如「而要像看待石伞盖一样把我看得又重又尊贵」，或为「石伞盖」加简注。
