# Review — 86:74-83（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§77 首尾句、§78 首尾句、§81 部分句无 nissaya，已略过）

## 跨段一致性
- **vihiṃsā / byābādha**：§77 `vihiṃsūparatiyā` 译「免除伤害」，§80–81 `byābādha` 也译「伤害」。两者在 nissaya 中所指不同：vihiṃsā 是「饥渴之苦」，byābādha 是「使…受苦」。同用「伤害」会让读者以为是同一概念。建议 §77 改译（见下），「伤害」留给 byābādha。
- **经末标记**：§78 `Chaṭṭhaṃ` 译「第六。」，§81 `Sattamaṃ` 译「第七经。」，§83 `Aṭṭhamaṃ` 译「第八经。」。建议统一，或都作「第六经。」，或都去掉「经」。
- **Katamehi tīhi / Katame tayo**：§75 译「哪三种呢？」，§80、§81 译「是哪三种呢？」。建议统一为「是哪三种呢？」。

## §75 句 86-75-2-38
- **问题**：词义过度 — `āraddhā = အားထုတ်အပ်ပြီးသည်`，意思是「已经发起、已经着手努力」，并不含「圆满」。「策发圆满」多出了「完成」义。另外，「他身上那个…原因」是翻译腔：`assa = ထိုရဟန်း၏` 是属格，`yoni ca = အကြောင်းသည်လည်း` 是主格主语，直接作「他的…因」即可。
- **建议**：「……他已经为灭尽诸漏（āsava）发起了因」，或「他导向灭尽诸漏的因已经发起」。§78 句 86-78-75-97 是同一句，要同步修改。

## §76 句 86-76-27-53
- **问题**：句法 — 三处与 nissaya 不合：
  - **关系结构改成了条件句**：`yatvādhikaraṇaṃ = အကြင်…အကြောင်းကြောင့်`（因为这一原因）与 `tassa = ထိုစက္ခုန္ဒြေကို` 构成关系—相关结构，`tassa` 指的是眼根。译文写成「如果……因此」的条件句，`tassa` 的所指就丢了。
  - **目的格当成了宾语**：`saṃvarāya = ပိတ်ဆီးစောင့်ရှောက်ခြင်းငှာ` 是目的格（为了防护），`paṭipajjati = ကျင့်၏`（修行）。译文「修习对眼根的防护」把目的格当成了宾语。
  - **漏译**：`viharantaṃ = နေသော`（住着的）没有译出。
- **补充**：`anvāssaveyyuṃ` 在 nissaya 里有两解：`အစဉ်လိုက်`（随之而来）和 `ဖိစီးလွှမ်းမိုး`（侵袭、压倒）。译文取前一解，可以接受。
- **建议**：「由于他不防护眼根而住，贪欲和忧恼这些恶的、不善的法就会侵袭他；为了防护眼根，他如此修行：守护眼根，在眼根上做到防护。」

## §76 句 86-76-78-98
- **问题**：句法 — 与 86-76-27-53 相同（关系结构、`saṃvarāya` 的目的格、漏译 `viharantaṃ`）。
- **建议**：按上一句同步修改，两句保持逐字平行。

## §77 句 86-77-24-62
- **问题**：取义 — `vihiṃsūparatiyā = ဆာလောင်ငတ်မွတ်သိပ်ခြင်း ဆင်းရဲကင်းရုံ`（只为止息饥渴之苦），vihiṃsā 在这里指饥渴的苦恼，不是「伤害」。
  - **建议**：「为了止息饥渴之苦」。
- **问题**：取义 — `vibhūsanāya = အရေအဆင်း ကြည်လင်ခြင်းငှာ`（为了肤色光润，以伶人为例）。「妆饰」偏向外加的装扮，与 nissaya 不合。
  - **建议**：「不是为了容光焕发」或「不是为了肤色光润」。
- **问题**：对应 — nissaya 的主解中，`ṭhitiyā` 是「持续存续」，`yāpanāya` 是「使命根延续不断」。译文「维持这个身体、让它存续」与原文的先后对应是颠倒的。
  - **建议**：「只是为了这个身体的存续，为了维持生命」。
- **问题**：漏译 — `iti = ဤသို့ အာဟာရကို စားမျိုမှီဝဲခြင်းဖြင့်`（通过这样进食）没有译出，「消除旧受」与进食之间的因果关系因此断开。另外，`vedanaṃ` 在 nissaya 中都指苦受：旧受是饥渴之苦，新受是过量进食引起的苦。
  - **建议**：「这样（进食），我会消除旧的苦受，不让新的苦受生起」。

## §78 句 86-78-13-64
- **问题**：语序 — 句尾的 `karitvā`（心里确定好起身的时刻）是独立式，表示先于主动词 `kappeti`（侧卧）。nissaya 的语序也是：放脚 → 具念正知 → 作意起身之想 → 以右胁作狮子卧。译文把这些放在「卧下」之后，读起来像是躺下以后才做。
- **建议**：「夜晚的中间时分，左脚略错开地搭在右脚上，保持正念正知，心里确定好起身的时刻，以右胁像狮子那样侧卧」。

## §80 句 86-80-31-46
- **问题**：nissaya 数据错位 — 该行 nissaya 注的是 `nevattabyābādhāyapi … na saṃvattanti`，也就是 §81 的否定句，并附有「နေဝ+တ္တဗျာဗာဓာယပိ」的拆词说明，与本句的肯定句不符。译文是按 pali 原文译的，没有错。记录在此，审本句时不要以这行 nissaya 为准。
- **建议**：译文不改。

## §83 句 86-83-53-78
- **问题**：取义 — `yasena = အခြံအရံဖြင့်`（以随从、眷属），nissaya 取的是「随从、眷属」义，不是「名声」。
  - **建议**：「天界的随从」。
- **问题**：句法 — `iti … kira … aṭṭīyatha ကိရ = …ဆိုလျှင်`，nissaya 把 kira 读作「既然如你们所说…的话」，作为后句 `pageva` 的前提。「据说」变成了转述传闻，而世尊刚刚听比丘们亲口承认，语气不对。
  - **建议**：「比丘们，这么说来，既然你们对天界的寿命感到苦恼、羞愧、厌恶，对天界的容貌、天界的快乐、天界的随从、天界的权势感到苦恼、羞愧、厌恶，」后接 §83 句 86-83-79-100「那么你们更应该首先……」。
