# Review — 86:1294-1336（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核；无 nissaya 的句子不出逐句意见，只在跨段一致性里统计）

## 跨段一致性

- **主语与连接词**：§1295–§1306、§1308、§1314 都译作「他自己……又……」；§1307、§1309、§1310、§1311、§1312、§1313 却作「自己……也……」，省掉了「他」，「又」也换成了「也」。nissaya 对这组排比给的是同一结构，`အတ္တနာ စ=ကိုယ်တိုင်လည်း` / `ပရဉ္စ=သူတပါးကိုလည်း`。→ 建议统一为「他自己……又……」。
- **samādapeti（劝人去做）**：恶行一侧，§1295–§1305 译「教唆」，§1307、§1309、§1311、§1313 译「劝」；善行一侧，大多译「劝导」，只有 §1307 例外，它属于恶行一侧却也用了「劝」。nissaya 为 `ကောင်းစွာနာယူကျင့်သုံးစေ၏`（使人受持奉行），中性。→ 建议恶行一律用「教唆」、善行一律用「劝导」。§1307、§1309、§1311、§1313 必改。
- **samannāgato**：§1295、§1296 译「具足」，§1314 译「具备」。→ 统一为「具足」。
- **yathābhataṃ nikkhitto evaṃ sagge**：§1296 译「就像被人带来安放一样，就这样被放到天界」，§1314 译「就像被搬来安放在那里一样，会生到天界」，同一套语出现了两种译法。→ §1314 按 §1296 的句式统一。
- **byāpāda**：§1311、§1312 正文译「瞋恨」，§1318 摄颂译「瞋恚」。nissaya `ဗျာပါဒေ=စီးပွားချမ်းသာကို ဖျက်ဆီးတတ်သောဒေါသ`（会毁坏他人利益安乐的瞋）。→ 统一用一个译名。若取正文的「瞋恨」，就改 §1318。
- **abhijjhā 与 rāga 区分不开**：abhijjhā 译「贪欲」（§1309、§1310、§1318），rāga 译「贪」（§1321 起）。nissaya 对两者的解释不同：abhijjhā 是 `အလွန်တပ်မက်သော ဝိသမ လောဘ`（过度渴求的不正当之贪），rāga 是 `ကာမဂုဏ်ငါးပါး၌ တပ်မက်သော ရာဂ`（对五种欲乐的贪著）。同一 chunk 里「贪欲」和「贪」并列，读者会误以为是同一法。→ 建议 abhijjhā 改译「贪求」或「贪婪」，§1309、§1310、§1318 一并修改（建议项）。
- **peyyāla 标题**：§1294、§1315 作「业道略说」（§1315 加了书名号），§1320、§1325 作「贪略说品」，多了「品」字，也没有书名号。nissaya 对两者的解释是同一类：`ကမ္မပထ၏ မြှုပ်ကွက်` / `ရာဂ၏ ဆိုင်ရာမြှုပ်ကွက်`，都是「……的略说部分」，原文也不是 vagga。→ 统一为「贪略说」。书名号要么都加，要么都不加。
- **摄颂引导句**：§1316 作「这一部分的摄颂是——」，§1326 作「本品的摄颂——」。→ 统一，并去掉「品」字。
- **十个目的词（abhiññā…paṭinissagga）**：正文 §1322、§1323 与摄颂 §1332、§1333 译名全不对应，而且 cāga 与 paṭinissagga 的译名互相交错。

  | 巴利 | §1322/§1323 | §1332/§1333 |
  |---|---|---|
  | parikkhaya | 彻底尽除 | 彻底灭尽 |
  | khaya | 消尽 | 尽 |
  | vaya | 消散 | 坏灭 |
  | virāga | 离染 | 褪离 |
  | nirodha | 息灭 | 灭 |
  | cāga | **舍弃** | **弃舍** |
  | paṭinissagga | **弃舍** | 彻底放舍 |

  →「弃舍」在正文对应 paṭinissagga，在摄颂却对应 cāga，必改。建议以正文的译名为准，统一摄颂。
- **suññato / animitto / appaṇihito samādhi**：§1321 译「三昧」，§1334 译「（定）」，§1335 作「以定为根本」。→ 统一为一个译名。若取「三昧」，§1334 改为「空三昧、无相三昧以及无愿三昧」。

## §1322 句 86-1322-2-32
- **问题**：格与句法。nissaya 对这组目的与格区分了两种关系：
  - 宾格：`ရာဂဿ=ကို` + `ပရိညာယ` / `ပဟာနာယ` / `စာဂါယ`，即「遍知贪、舍断贪、舍弃贪」，贪是动作的宾语。
  - 属格：`ရာဂဿ=၏` + `ပရိက္ခယာယ` / `ခယာယ` / `ဝယာယ`，即「贪的尽、贪的消散」，贪是变化的主体。

  现译把整组压成「为了对贪的遍知……彻底尽除、舍断、消尽……」，只在第一项出现「为了」，后面九项成了无主无宾的并列名词。巴利原文每项之间都有「…」，表示每一项都要带全句重复。
- **建议**：照 §1323 的格式，每一项都带「为了」，并按 nissaya 区分宾属关系，例如：「比丘们，为了遍知贪……为了贪的彻底尽除……为了舍断贪……为了贪的消尽……为了贪的消散……为了贪的离染……为了贪的息灭……为了舍弃贪……为了弃舍贪，应当修习这三种法。」
  - 「中略」与 §1323 的「……」也要统一，建议都用「……」。
  - 「为了对贪的遍知」与 §1321「为了彻底了知贪」的句式也不一致，建议改成动宾式「为了遍知贪」。

## §1323 句 86-1323-2-61
- **问题**：术语所指与 nissaya 释义不合。
  - `သာရမ္ဘဿ=သူတပါးထက် နှစ်ဆ, သုံးဆ စသည်တိုးပွား, သာလွန်အောင် ကြိုးစားခြင်းဟူသော မာနကို`：sārambha 是想要胜过他人两倍、三倍的争胜之慢。现译「激愤」偏向情绪爆发，取义不对。
  - `ပဠာသဿ=ကိုယ့်ထက်သာသူ, တန်းတူယှဉ်တု, ဂုဏ်ပြိုင်မှုကို`：palāsa 是与胜过自己或与自己同等的人较量功德、互相攀比。现译「恼」读不出这层意思。
  - `ထမ္ဘဿ=ကောဓ, မာန အစွမ်းဖြင့် ကြမ်းတမ်းခက်ထန်ခြင်း`：thambha 是由忿或慢引起的强硬粗厉。现译「刚强」在现代汉语里常带褒义，容易误读。
- **建议**：
  - sārambha 改为「争强好胜」或「好胜」，必改。
  - palāsa 改为「攀比」或「争胜」，或者保留传统译名「恼」，首次出现时夹注巴利原词。
  - thambha 改为「顽固强硬」或「固执」。
  - 以上改动要同步到摄颂 §1328、§1329。

## §1321 句 86-1321-21-79
- **问题**：无词法错误。与 §1334、§1335 的「三昧／定」不一致，见跨段一致性一节。

## §1336 句 86-1336-2-4
- **问题**：无词法错误。nissaya 的末句 `ဤတိကနိပါတ်အဆုံးတွင် အင်္ဂုတ္တိုရ်ပါဠိတော်နိဿယ ပထမတွဲ ပြီး၏` 是 nissaya 本身的卷末题记，不属于巴利原文。现译没有混入这句，正确。
