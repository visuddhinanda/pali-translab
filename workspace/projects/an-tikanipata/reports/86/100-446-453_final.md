## 理由

**资源缺口（影响信心）**：本次只注入了待评估的义注译文与其巴利原文，**未注入 nissaya**，也**未注入被注释的本文层**（AN 三集 Avakujjasutta 本身）。因此两项核验无法完成：一是词级格位/句法角色无 nissaya 可比对，准确性判断只能依据巴利原文与通行义注读法；二是硬约束「被解释词与父层逐字同译」无法核验——本段大量黑体引文（`avakujjapañño` / `ucchaṅgapañño` / `ādikalyāṇaṃ` / `neva ādiṃ manasi karoti` / `seyyo etena vuccati` / `ākiṇṇāni` / `gantā` 等）是否与本文译文字字相同，本次一概没查。下面涉及黑体引文措辞的几条（`100-450-2-5`、`100-452-11-14`、`100-452-15-23`）若本文层用词与此不同，严重程度要上调；信心指数因此压在 72。

**准确性**：主干释义与义注体例相符，三个比喻段（罐倒扣 / 衣襟 / 罐口朝上）的四段对应关系（倒水—得法、水走/水不住—座上不能领受、起身后不能明辨）逐项落实，没有错配；`desanā` 与 `sāsana` 的两套「初中后」分层清楚，四组三分（戒定观 / 定观道 / 观道果 / 道果涅槃）与两两一组都没有漏项。扣分主要来自三处：`sikkhattayasaṅgahitaṃ` 的包含关系译反（见 error 第 1 条）；`ākiṇṇāni` 的被动分词被改成以人为主语的「兜着」；`navalokuttaradhamma` 处把原文没有的「四道、四果与涅槃」直接写进正文。

**风格**：整体是通顺的现代书面汉语，「这里应当这样理解」「获得听闻佛法的机会」等处理得当，没有「此中/故为/彼等」一类明显文言腔。仅 `100-452-33-36`「轮回之苦」用了文言虚词「之」，按 style.md 第一节禁例表单列一条并在此据以扣分；`100-452-24-32` 的「即」属同类但程度更轻，已并入该条建议。另有两处黑体引文译成不成句的片段（「开头不留心」「到……去」），其中「到……去」带省略号，读来像残留的占位，是最需要清掉的风格问题。

**一致性**：「X，就是Y」的释词格式全段统一，`uggaṇhana`→领受、`asallakkhaṇa`→明辨、`pubbapaṭṭhapanā`→最初的开端 三组关键词前后一致，是本段的长处。扣分在两对应当配套的词上：`nikujja`/`ukkujja` 一个译「倒扣着的」、一个译「口朝上的」，构词不成对；`vivaṭṭana` 在 449 作「水流走」、在 451 作「水不会泻出去」，同词两译且后者还丢了与前后文平行的「的时候」。

**非侵入声明**：本报告未改动译文一字，未写 channel，未在译文中插入任何标记。

## 问题清单

### 🟧 error

- `100-448-30-42`｜错译（修饰关系）｜片段「包含戒定慧三学的八正道」
  - 问题：`sikkhattayasaṅgahitaṃ` 是过去分词「被三学所摄的」，修饰 `maggaṃ`——是八支圣道被摄于三学，译文把包含方向反转成「八正道包含三学」。
  - 建议：改为「为戒定慧三学所摄的八支圣道」。
- `100-450-2-5`｜错译（词义、修饰关系）｜片段「**兜着**，就是把东西装放在里面」
  - 问题：`ākiṇṇāni` 是中性复数过去分词，与 `nānākhajjakāni`（各种吃食）一致，意为「（吃食）被放在里面的」；释词 `pakkhittāni` 同为被动分词。译文把黑体引文译成以人／衣襟为主语的动作「兜着」，词类与主语双重位移，且与 `100-450-12-47` 里「用衣襟兜着」的用法混同。
  - 建议：黑体引文改为「**放着的**」或「**装着的**」，释义作「就是被放进去的」；最终措辞须与本文层「ucchaṅge nānākhajjakāni ākiṇṇāni」的译文逐字对齐。
- `100-452-24-32`｜错误多译｜片段「九种出世间法（navalokuttaradhamma，即四道、四果与涅槃）」
  - 问题：「即四道、四果与涅槃」是原文所无的补充释义，直接写进了正文；按 style.md「不擅自补足」与「详释译为段后注释」，这类展开不应进正文。内容本身无误，但位置不对。另「即」属禁例表的文言虚词。
  - 建议：正文保留「九种出世间法（navalokuttaradhamma）」，把「四道、四果与涅槃」移到段后小字注释，并把「即」改为「指」或直接省略。

### 🟨 warning

- `100-447-56-69`｜关键词语意不明确｜片段「两句是中间」
  - 问题：`dve padāni majjhaṃ` 指四句偈的中间两句，「两句是中间」没说哪两句，读者会追问；与前后「第一句」「最后一句」不成平行。
  - 建议：改为「中间两句是中间」或「第二、三句是中间」。
- `100-452-11-14`｜关键词语意不明确｜片段「**到……去**，就是习惯于前往」
  - 问题：黑体引文用省略号作成不成句的片段，形同残留占位符；`gantā` 是「常去者」，指人。
  - 建议：按本文层措辞改为完整引文（如「**常去（寺院）**」或「**到寺院去**」），释义作「就是习惯于前往的人」。
- `100-452-15-23`｜代词指代不明确｜片段「**说他比前一种人更好**，就是说他比那个人更为殊胜」
  - 问题：黑体引文把 `etena` 译作「前一种人」，是带解释的改写；释义处同一个 `etasmā puggalā` 又译「那个人」，同一指称在一句内两种说法，读者难以确认是否同指。
  - 建议：黑体引文依本文层照译（如「**说他比这个人更好**」），释义统一为「就是说他比这个人更为殊胜」，若需点明所指再入注释。
- `100-452-33-36`｜文言语体｜片段「轮回之苦」
  - 问题：用了文言虚词「之」，违反 style.md 第一节禁例表（能用现代对应词就不用单音节文言虚词）。
  - 建议：改为「轮回的苦」。
- `100-453-2-4`｜关键词语意不明确｜片段「人品第三」
  - 问题：「人品」在现代汉语里首先理解为道德品格，与原意「关于人的那一品（章）」相冲突，是会被普通读者误读的译法。
  - 建议：改为「人之品，第三」或「第三品：人」。
- `100-448-43-52`｜整句逻辑表达不规范｜片段「**开头不留心**，就是对最初的开端部分不留心」
  - 问题：黑体引文 `neva ādiṃ manasi karoti` 是完整的谓语句（「他对开头也不作意」），译成「开头不留心」缺主语且丢了 `neva` 的「也不／既不」语气；黑体与释义用同一个「不留心」，整句成了同语反复。
  - 建议：黑体引文依本文层作「**他对开头也不作意**」一类完整说法，释义改为「就是不把最初的开端部分放在心上」。

### 🟦 suggestion

- `100-449-6-10` / `100-451-2-6`｜语言风格不统一｜片段「**倒扣着的**，就是把罐口向下放置」与「**口朝上的**，就是把罐口向上放置」
  - 问题：`nikujja` 与 `ukkujja` 是一对反义词，译文一边用「倒扣着的」、一边用「口朝上的」，构词不成对，读者看不出二者是同一对立面；两处释义又都从被动（`ṭhapito`）改成了无主语的主动「把罐口向下／向上放置」。
  - 建议：统一成对（「倒扣着的／正放着的」或「口朝下的／口朝上的」），释义改为「就是口朝下放着的／口朝上放着的」。
- `100-449-11-44` / `100-451-11-44`｜语言风格不统一｜片段「水流走的时候」与「水不会泻出去」
  - 问题：同一个 `vivaṭṭana` 两处两译（流走／泻出去）；且 451 处少了与前后三项平行的「的时候」，节奏断掉。
  - 建议：统一用「流走」，451 处补足为「水不流走的时候」。
- `100-452-37-44`｜语言表达不够流畅｜片段「就是能成为让这苦终止的人、给这苦划定界限的人、给这苦划出边际的人」
  - 问题：三个近义词 `koṭikara` / `paricchedakara` / `parivaṭumakara` 译成三个重复「这苦……的人」的长短语，后两项中文语义几乎重合，读来冗赘。
  - 建议：压缩共同成分，如「就是能让这苦到此为止、给它划定界限、把它围断的人」。
- `100-448-2-8`｜语言表达不够流畅｜片段「**有意义**，就是讲得有意义」
  - 问题：黑体与释义完全同词，中文看起来是空转（原文 `sātthaṃ`→`sātthakaṃ` 有词形差别，中文丢失了这层差别）。
  - 建议：释义改为「就是把法讲得有义利」，或在黑体处用「**有义利**」以示区别。
- `100-447-33-46`｜代词指代可能不够明确｜片段「那些比丘为他讲说佛法时」
  - 问题：`te` 补成「那些比丘」依赖本文层上文（`tassa bhikkhū dhammaṃ desenti`），在义注单段内读来没有先行词；按 style.md「不擅自补足省略主语」属边界情形。
  - 建议：保留补足但确认与本文层译文一致，或改为「那些人为他讲说佛法时」。
