## 理由

**取数条件（必须先交代）**：本次只注入了待评译文与巴利原文。**义注（释义标准）与 nissaya（词级基准）均未实际取到内容**——注入块仅标明「本次评估的文献层次：义注（aṭṭhakathā）（book=100）」，即被评对象本身就是义注层，而其上并无更高释义层可依；nissaya 一条未提供。因此本次评估**降级为「巴利原文 + 平行文献内部一致性 + 汉语表达」三条基准**，格与句法角色只能据原文形态自行判定，无 nissaya 交叉验证。信心指数因此压到 68，不宜更高。涉及传统取义的判断（见下 error 条）请在补齐 nissaya 后复核。

**准确性**：主干译得扎实。`titthāyatanāni` 的双解（titthabhūtāni āyatanāni / titthiyānaṃ vā āyatanāni）、三义（sañjāti / samosaraṇa / kāraṇa）的分述与回收、`parampi gantvā` 三种 paramparā 的铺排，层次都对得上原文。主要扣分在两处词形与一处指代：`titthakarā/titthikarā` 译「渡口的建立者」把 tittha 的喻义读死了，`attabhāva` 译「前生相续」超出词义，`Taṃ idha sabbampi` 的单数 taṃ 被译成「这三种意思」。

**风格**：现代书面汉语的底线守住了，没有「此中/故为/彼等」一类硬性文言。但有若干半文半白残留——「所谓…就是」连用五句略带注疏腔尚可接受，「即使追溯到其中任何一种」「连一个…都找不到」自然；真正该扣的是「加以追问」「追究其由来」「劝令舍离」三个被解释词的译法本身偏文言四字格，以及 100-644-103-120 整句「同指一事、同属一义、彼此相同、分量相等、由此而生、即是其自身」六个四字短语连排，读来像古译而非现代汉语。标点与引号合规：全角 “” 一致，未见 ASCII 引号，无 JSON 风险，无残留工作标记。

**一致性**：`āyatana` 全段统一作「处所」，`diṭṭhi` 统一作「见」，`paramparā` 统一作「传承」，`ācariya/pācariya/ācariyapācariya` 三级称谓统一，这几条做得好。失分在被解释词的跨句同译：100-644-66-73 / 74-83 / 84-93 三处黑体词在 100-644-103-120 的古义注引文里再次出现（`samanuyuñjati / samanuggāhati / samanubhāsati`），译文做到了逐字同译，这点合格；但 `titthakarā` 在 100-641-19-31 作「渡口的建立者」、100-641-37-42 作「渡口的建立者」而释语又作「创立者」，同句内两词分译，轻微不齐。另：`titthiyā` 译「外道」与 `titthāyatanāni` 译「外道见处」中的「外道」所指不同层（一指人、一指见），术语复用有歧义风险。

## 问题清单

### 🟧 error

- `100-641-37-42`｜错译（词义）｜片段「所谓渡口的建立者，就是那些见的创立者」
  - 问题：`titthikarā`（= titthakarā）在此语境中不是「建立渡口的人」，tittha 已被义注定义为「六十二种见」，故 titthakara 指**创立该见的宗师／外道教主**（传统即「渡口作者」之喻指外道祖师）。译「渡口的建立者」把喻体字面化，读者会误解为与水边渡口有关；且同句后半又译「见的创立者」，前后自相解释、同词两译。
  - 建议：被解释词与释语分开处理——「所谓渡口的创立者，就是那些见的创始人」，或在 100-641-19-31 首次出现处即定译「创立见的宗师」并全段统一。

- `100-645-2-13`｜错译（词义）｜片段「前生相续的传承」
  - 问题：`attabhāvaparamparā` 的 `attabhāva` 指**自身／身体／这一生的个体存在**，此处三种 paramparā 并列为「师承—主张—自身」，第三种是沿着师徒各自「自身」上溯，并非「前生」。译「前生相续」引入了原文没有的轮回义，且与 100-645-92-118 自己把 attabhāvo 译作「这一生」不一致。
  - 建议：统一译「自身的传承」或「各人自身的传承」，与 100-645-92-118 的「这一生」口径拉齐。

- `100-644-27-32`｜代词指代错误｜片段「这三种意思在这里全都讲得通」
  - 问题：`Taṃ idha sabbampi labbhati` 的 `taṃ` 是**单数中性**，承指上文 `āyatanaṃ` 一词，意为「这个（āyatana 一词的含义）在此处全都取得」。译成「这三种意思」把单数改成了复数计数，虽然语义结果接近（下文确实回收三义），但把原文的「该词」偷换为「三义」，并与紧接的 100-644-33-60「正是这三处／这三个原因」重复报数。
  - 建议：「这个词在这里三种意思全都讲得通」，保留单数承指，由下文自然展开三项。

### 🟨 warning

- `100-644-103-120`｜文言语体｜片段「同指一事、同属一义、彼此相同、分量相等、由此而生、即是其自身」
  - 问题：六个四字文言短语连排，「同指一事」「由此而生」「即是其自身」均为文言句式，无古文基础的读者读来即「像古文」，违反 `knowledge/style.md` 第一节硬约束。原文 `esese ekaṭṭhe same samabhāge tajjāte taññeva` 是同义词堆叠，可以用现代汉语平铺。
  - 建议：改为「这几个说法指的是同一件事、同一个意思，彼此一样、轻重相当、从同一处来，说的就是同一个东西」。

- `100-644-66-73`｜文言语体｜片段「**加以追问**」
  - 问题：「加以追问」为半文半白的书面套语；被解释词是译文中最显眼的位置，宜用现代词。
  - 建议：「被追问」或「受到盘问」，并与 100-644-103-120 引文内的同词译法保持一致。

- `100-644-84-93`｜文言语体｜片段「就是这样被正确地劝谕」
  - 问题：「劝谕」为文言单音词化表达；黑体词「劝令舍离」亦偏文言四字格。
  - 建议：「被这样好好劝告」；黑体词可作「劝人舍弃」。

- `100-644-99-102`｜关键词语意不明确｜片段「因此在古义注（aṭṭhakathā）中说」
  - 问题：本段本身即 aṭṭhakathā，而此处引的是更早的旧义注。译文夹注巴利原词 `aṭṭhakathā` 却未说明「古」与当前文本的层次关系，读者会困惑于「义注里引义注」。此为二意场合而未加注。
  - 建议：保留「古义注」译法，加一条脚注说明此指复注所承的旧《义疏》，或改作「旧《义注》」并统一全书口径。

- `100-641-56-74`｜错译（词义）｜片段「剑浮阇是马的产地，南方之路是牛的产地」
  - 问题：`dakkhiṇāpatha` 是地名专称（南印度／德干地区），非「南方之路」的字面义；译成「之路」与前句的国名 Kamboja 并列不协。
  - 建议：「南方地区（dakkhiṇāpatha）是牛的产地」，或音义并举「南路地方」并附夹注。

- `100-645-20-33`｜整句逻辑表达不规范｜片段「主张一切都由过去所造的业决定」
  - 问题：`pubbekatavādī` 的释义性扩写（「一切都由…决定」）在三句中重复三遍、每遍十余字，连同后两组共九句，汉语读来极为冗赘；原文靠 `pubbekata- / issaranimmāna- / ahetuapaccaya-` 的短词重复造出排比节奏，译文把短词扩成长句后节奏尽失。
  - 建议：首次出现时给全称并夹注巴利原词，其后用简称「宿作论者」「自在天创造论者」「无因无缘论者」，保住排比。

### 🟦 suggestion

- `100-644-74-83`｜语言风格不统一｜片段「**追究其由来**」
  - 问题：三个并列黑体词中，「加以追问」「劝令舍离」为动宾结构，此条带文言代词「其」，三者句式不齐。
  - 建议：三条统一为同一结构，如「被追问／被追究原因／被劝舍」。

- `100-640-2-4`｜该使用而没有使用术语标记｜片段「一、外道见处经的解释」
  - 问题：`titthāyatana` 作为本章核心术语，章题处首次出现未夹注巴利原词，而正文 100-641-2-18 的黑体被解释词处也未夹注；按 `style.md`「法相术语首次出现夹注巴利原词」应补。
  - 建议：章题或 100-641-2-18 首见处作「外道见处（titthāyatana）」。

- `100-641-43-50`｜语言表达不够流畅｜片段「就是那些喜欢、认可这些见的人」
  - 问题：`ruccanti khamanti` 两动词的主语在原文是「见」（这些见为他们所乐、所忍可），译文反转为人作主语虽通顺，但「喜欢、认可」两词语义过近，未译出 khamati「容受／忍可」的让步色彩。
  - 建议：「就是那些中意并接受这些见的人」。

- `100-645-119-135`｜复杂嵌套句理解困难｜片段「连一个亲自造作的人或指使他人造作的人都找不到」
  - 问题：`kattā vā kāretā vā na paññāyati` 译得准确，但「亲自造作」「指使他人造作」在无上下文铺垫时抽象难解，读者不易接上前文的「无所作为」。
  - 建议：「找不出一个自己动手做的人，也找不出一个让别人去做的人」，拆成两个短句。
