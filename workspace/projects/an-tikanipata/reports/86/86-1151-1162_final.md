## 理由

**基准缺失（影响信心）**：本次只注入了本文（mūla）层的巴利原文与译文，**未提供义注（aṭṭhakathā）与 nissaya**。因此「义注定释义、nissaya 定词法」两条基准都无法执行，下列判断全部出自巴利原文的词法/句法与教理常识，凡涉及传统取义的条目（`rittassāda` / `bāhirassāda` / `vibbhantacitta` / `goyogapilakkha` / `vighāta`）都存在被义注推翻的可能，信心按此压低。待义注层可取时应复评。

**准确性**：主干句法读得准。最值得肯定的是 1157/1158 这组偈颂——`aguttaṃ … asaṃvutaṃ` 的宾格身份被正确识别为 `anupatissanti` 的对象，`saṅkappā rāganissitā` 作主语，没有误读成「不守护的人……的意念」这类常见错误；散文反复出现的 `Taṃ vata … netaṃ ṭhānaṃ vijjatī` 这一「要说……，这是不可能的」双重否定格式也处理得干净、四处一致。扣分集中在三处词义外推：`goyoga`（牛轭／系牛处）译作「牛市」，`nānvāssavissanti`（流注而随、随之渗出）补成「叮咬」，`vighāta`（恼害、障难）概括成「苦」。三处都属译者替原文做了解释，而不是原文的意思。

**风格符合度**：整体是现代书面汉语，无「此中／故为／彼等／是故」类文言腔，标点全角、无 ASCII 引号、译文内无残留工作标记——硬约束均过。扣分在汉语本身：1152/1154 那串七项定语后置于「比丘」之后，句子读起来不成句；「只有苦的份」偏口语且语意不明；「无慧者」是文言式 `者` 名词化。

**一致性**：重复段（1153 对 1155、1152 对 1154、三处 `Taṃ vata` 公式）逐字一致，复述段与被复述段的人称转换（世尊→我、so bhikkhu 保持第三人称）处理正确；术语 `kaṭuviya`→污秽、`āmagandha`→腥臭、`makkhikā`→苍蝇全篇贯通，经题「污秽经」与经文答语对得上。唯一松动处是 `vitakka`→「思虑」与 `saṅkappa`→「意念」，散文与偈颂互为呼应却用了两个汉语词，读者不易看出是同一所指。另：1152-24-59 的夹注（rittassāda / bāhirassāda）在 1154-16-34 复述时未重复，符合「首次出现夹注」的策略，不作扣分。

## 问题清单

### 🟧 error

- `86-1152-24-59`｜错译（词义）｜片段「在牛市旁那棵榕树下」
  - 问题：`goyoga` 是「牛轭／套牛（系牛）处」，不是牲畜交易的「牛市」；`goyogapilakkha` 指系牛处旁的那株 pilakkha 树。另「那棵」把原文无定指的处所写成已知旧信息。
  - 建议：改为「在套牛处的榕树下」或「在系牛处那株榕树下」（后者保留定指须有义注支持）。`86-1154-16-34` 同句同改，保持两处一致。

- `86-1153-13-50`｜错误多译｜片段「不会追上来叮咬他」
  - 问题：`nānvāssavissanti`（← anu-ā-savati）意为「不会随之流注、不会跟着渗流」，与前句 `āmagandhena avassutaṃ`（被腥臭浸流）共用同一「流注」意象。「叮咬」是译者补入的动作，原文无此义，且切断了 avassuta / anvāssavati 的词根呼应。
  - 建议：改为「不会跟着流落到他身上」或「不会随之聚涌而来」。`86-1155-14-30`、`86-1156-19-38` 两处同一公式同改。

### 🟨 warning

- `86-1152-24-59`｜不导致误解的汉语语病｜片段「看见一位比丘内在的乐味空乏」
  - 问题：七项定语（空乏乐味、以外为乐、失念、不正知、心不安定、心思散乱、诸根放纵）全部后置于宾语「一位比丘」，「看见一位比丘内在的乐味空乏」单独读时不成句，像是「看见……的空乏」。
  - 建议：改成兼语式，如「看见一位比丘——内在空乏乐味、以外在为乐味、失念、不正知、心不安定、心思游移、诸根放纵」，或拆为「看见一位比丘，这位比丘……」。`86-1154-16-34` 同改。

- `86-1160-2-8`｜关键词语意不明确｜片段「只有苦的份」
  - 问题：`vighāta` 指恼害、挫败、障难，译作笼统的「苦」已失准；「只有……的份」是口语句式，与全篇书面语体不合，且「份」字歧义（份额／份儿）。
  - 建议：改为「只分得恼害」或「所得的只有恼害」。

- `86-1158-2-7`｜整句逻辑表达不规范｜片段「就像苍蝇一样扑落到他身上」
  - 问题：原文是同一关系而非比喻——1156-14-18 明说「恶的、不善的思虑就是苍蝇」，偈颂 `makkhikānupatissanti, saṅkappā rāganissitā` 以 `makkhikā` 与 `saṅkappā` 同位。译作「就像苍蝇一样」把世尊的界定降格为修辞比喻，与前文答语脱节。
  - 建议：改为「那些依于贪的意念，正是扑落到他身上的苍蝇」。

- `86-1162-2-17`｜整句逻辑表达不规范｜片段「愚人、无慧者四处行走」
  - 问题：`bālo dummedho` 是同一人的两个修饰语，译成以顿号并列的两个名词，读起来像两类人；「无慧者」属文言式 `者` 名词化，与「必须现代书面汉语」的要求相左。
  - 建议：改为「愚痴无慧的人四处游走」。

- `86-1158-2-7`｜标点符号使用错误｜片段「就像苍蝇一样扑落到他身上。」
  - 问题：偈颂的引号只开不闭。1157 开 “、1158 收尾无 ”；1159 开 “、1160 无 ”；1161 开 “、1162 无 ”。巴利底本按诗节重开 `‘‘` 是西文惯例，中文引号必须成对。
  - 建议：每段偈颂末句补右引号（`86-1158-2-7`「……扑落到他身上。”」、`86-1160-2-8`、`86-1162-2-17` 同），或改为后续诗节不再重开左引号、仅在最末句闭合。三段需统一处置。

### 🟦 suggestion

- `86-1152-24-59`｜语言风格不统一｜片段「心不安定、心思散乱」
  - 问题：`asamāhita`（未得定）与 `vibbhantacitta`（心游移、背离）在汉语里被译成两个近义词，区别消失；`vibbhanta` 另有「动摇欲退」的传统读法，待义注确认。
  - 建议：分化为「心未得定、心思游移」；取义待义注层可取时复核。

- `86-1156-14-18`｜语言风格不统一｜片段「恶的、不善的思虑就是苍蝇」
  - 问题：此处 `vitakka` 译「思虑」，偈颂 `86-1158-2-7` 的 `saṅkappa` 译「意念」。两处互为问答与总结，用词不呼应，读者看不出指同一事。
  - 建议：二者择一靠拢（如散文「思虑」、偈颂「意念（即上述思虑）」由 harmonize 统一），或在 `terms.md` 登记两词的固定对译后再统稿。

- `86-1161-2-28`｜语言表达不够流畅｜片段「没有为自己获得内心的寂止」
  - 问题：`samathamattano` 为「自己的寂止」，「为自己获得」属添译，三个「的／为」叠加也拖沓；「内心」亦为补入成分。
  - 建议：改为「没有得到自心的寂止」。
