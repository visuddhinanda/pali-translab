# Review — 86:402-421（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句没有 nissaya，这些句子只在跨段一致性一节涉及）

## 跨段一致性

- **jiṇṇā vuddhā mahallakā addhagatā vayoanuppattā vīsavassasatikā jātiyā**（套语）：§403、§404 译「年老、衰迈、高龄，走过了大半生，到了晚年，出生以来已经一百二十岁了」；§413、§414 译「年老、衰迈、年纪很大、人生已过了大半、到了晚年、出生以来已有一百二十岁」 → 两经逐字相同的套语应统一为一种译法，建议取 §403 的版本。
- **akatakalyāṇā akatakusalā akatabhīruttāṇā**：§403、§404 译「没有做过好事，没有做过善业，也没有为将来的恐惧准备下庇护」；§413、§414 译「没有做过善事，没有做过善业，没有为自己在恐惧中建立起庇护」 → 应统一。按 nissaya，bhīruttāṇa 是「防护恶趣怖畏的善业」（`ဘိရု= ဒုဂ္ဂတိဘေး` + `တာဏ = ကာကွယ်ရေးကုသိုလ်`），建议统一为「没有做过好事，没有做过善业，也没有做过防护恶趣怖畏的事」。
- **puñña / kusala**：kusala 在 §403 译「善业」；puñña 在 §408、§411 也译「善业」，在 §421 却译「福业」，§404 补出的成分又写作「（福业）」。结果是 kusala 与 puñña 混成一个词，puñña 自身前后也不一致 → 建议 puñña 统一译「福业」，kusala 保留「善业」。
- **saṃyama**：§404、§409 译「自制」，§414 译「节制」，§419 译「克制」 → 统一为「自制」。
- **idha**（`ဣဓ= ဤယခုဘဝ၌` 今生）：§404、§409 译「此世」，§414、§419 译「在这里」 → nissaya 明确指「今生」，统一为「今生」或「这一生」。「在这里」是误读，「此世」也偏文。
- **tassa petassa**：§404、§410 译「他去了他世以后」，§414、§420 译「他死后」 → 统一。nissaya 的释义是「转生到他世的人的」，建议统一为「他去了他世以后」。
- **tāṇa / leṇa / dīpa / parāyaṇa**：§404 译「保护、藏身处、可以立足的洲岛、依靠和归趣」，§414 译「保护、避难处、立足的岛屿、依靠和归宿」 → 统一。建议用「保护、藏身处、立足的洲岛、依靠和归宿」（「归趣」偏文）。
- **upanīyati / upanīyamāne**：§404 句 23-33 译「带走」，同段句 34-65 和 §405 译「牵引」 → 同一动词同一段内两译，统一为「牵引」。
- **jarā / maraṇa**：§404、§414 译「衰老」「死亡」，§417 译「老」「死」 → 统一为「衰老」「死亡」。
- **brāhmaṇā（呼格，复数）**：其余各处都译「婆罗门们」，只有 §404 句 34-65 译「婆罗门」 → 改为「婆罗门们」。
- **称谓与量词**：§403 用「两位婆罗门」「那两位婆罗门」，§413 用「两个婆罗门」「那两个婆罗门」 → 统一为「位」。
- **etadavocuṃ 后的标点**：§403 用「——」，§413 用「：」 → 统一为「：」。
- **upasaṅkamitvā**：§403 译「来到以后」，§413 译「到了以后」 → 统一为「来到以后」。
- **经题与结尾**：§402 译「第一两婆罗门经」，§412 译「第二婆罗门经」，漏了「两」；§411 结尾 paṭhamaṃ 译「第一经」，§421 结尾 dutiyaṃ 译「第二」 → 经题统一为「第二两婆罗门经」，结尾统一为「第一经」「第二经」。

## §403 句 86-403-44-59

- **问题**：句法 — 在 nissaya 里，`ဗြဟ္မဏာ= ပုဏ္ဏားတို့ပါတည်း` 是谓语名词（「是……的婆罗门」），jiṇṇā 等词作它的定语（`ကုန်သော`）。译文把这些形容词变成了谓语，又补出了原文没有的「这两个」。
- **建议**：改为「乔达摩先生，我们是年老、衰迈、高龄……出生以来已经一百二十岁的婆罗门；」。

## §403 句 86-403-60-65

- **问题**：词义 — akatabhīruttāṇā 按 nissaya 是「没有做过防护恶趣怖畏的善业」，译文的「为将来的恐惧准备下庇护」把所怖畏的对象泛化了。
- **建议**：改为「也没有做过防护恶趣怖畏的事」（与 §413、§414 统一）。

## §403 句 86-403-66-84

- **问题**：句法 — 按 nissaya，yaṃ 指「这种教导教诫」（`ယင်းသို့ ဆုံးမသွန်သင်ခြင်းသည်`），是 assa 的主语。译文补出「说一些……的话」，把主语换成了「话」，偏离了原句结构。
- **建议**：改为「请乔达摩先生教导我们，请乔达摩先生教诲我们，好让这教导能长久地为我们带来利益和快乐。」。§413 句 59-77 的「让我们能够长久地得到」同样丢了 yaṃ 的所指，应一并统一。

## §404 句 86-404-34-65

- **问题 1**：呼格 — brāhmaṇā 是复数，译文写成「婆罗门」。
- **问题 2**：格 — kāyena / vācāya / manasā 是具格（`ကိုယ်ဖြင့်` 以身、身门），译文译成属格式的「身的自制」，失去了工具义。
- **问题 3**：补出成分 — nissaya 补出的是「那自制善业」（`တံ= ထိုစောင့်စည်းမှု ကုသိုလ်သည်`）。译文在正文里夹写「（福业）」，这既是工作痕迹，所指也不准确。
- **问题 4**：idha 译「此世」，按 nissaya 是「今生」。
- **建议**：改为「婆罗门们，在世间这样被衰老、疾病、死亡牵引的时候，一个人今生以身所做的自制、以语所做的自制、以意所做的自制，这自制就是他去了他世以后的保护、藏身处、立足的洲岛、依靠和归宿。”」。

## §406 句 86-406-2-6

- **问题**：词义 — tāṇā 是复数主格，nissaya 释为「能救护守护的人」（`ကယ်ဆယ်စောင့်ရှောက်နိုင်သူတို့သည်`），指救护者，不是抽象的「保护」。
- **建议**：改为「被衰老牵引的人，没有能救护他的人；」。

## §409 句 86-409-2-12

- **问题**：idha 译「此世」，按 nissaya 是「今生」；kāyena 等是具格，与 §404 的问题相同。
- **建议**：改为「凡是今生以身、以语或以意所做的自制；」。§419 应同步改为同一句，因为它现在译成「在这里凡有身的克制」，idha 和 saṃyama 都译错了。

## §414 句 86-414-34-66

- **问题 1**：idha 译「在这里」，按 nissaya 是「今生」（`ဤ ယခုဘဝ၌`）。
- **问题 2**：taṃ 是单数，指上面的自制，译文写成「这些」。
- **问题 3**：manasā 译「以内心」，与 §404、§409 的「意」不一致。
- **问题 4**：saṃyama、tassa petassa 以及保护等五词与 §404 不一致，见跨段一致性一节。
- **建议**：改为「婆罗门们，在世间这样被衰老、疾病、死亡燃烧着的时候，一个人今生以身所做的自制、以语所做的自制、以意所做的自制，这自制就是他去了他世以后的保护、藏身处、立足的洲岛、依靠和归宿。”」（与 §404 只差「燃烧」一词）。

## §415 句 86-415-2-10

- **问题**：数 — yaṃ bhājanaṃ 是单数，nissaya 释为「财物」（`ပစ္စည်းဥစ္စာ`），译文写成「那些器物」。
- **建议**：改为「在燃烧着的房屋里，他搬出来的东西，」。§416「那些器物」相应改为「那东西」。

## §417 句 86-417-2-38

- **问题 1**：evaṃ 在 nissaya 里是「同样地」（`ဤအတူ`），用来承接上面的比喻，译文的「就这样」容易读成方式状语。
- **问题 2**：「这个」在原文里没有对应词。
- **问题 3**：老、死与前文的「衰老」「死亡」不一致。
- **建议**：改为「同样，世间被衰老和死亡燃烧着；」。

## §418 句 86-418-2-15

- **问题**：补出成分 — nissaya 补出了来源「从这燃烧着的世间」（`လောကာ`）和宾语「所施之物」。译文把宾语补成「器物」，又沿用了上个偈颂的比喻用词，「从世间搬出」这层意思没有体现。
- **建议**：改为「应当用布施把财物从这燃烧的世间搬出去，布施出去的，才算是妥善搬出。」。
