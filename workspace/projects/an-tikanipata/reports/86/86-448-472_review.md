# Review — 86:448-472（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§461、§462、§467 无独立 nissaya 行，其内容并在 §463、§468 行内；§449 部分行的 nissaya 与 pali 错位一行，审查时按内容对齐）

## 跨段一致性

- **danto … jāyati**：§456 与 §461 是平行句（`Yāsu kāsuci etāsu, danto jāyati …`），nissaya 两处结构相同（`ယာသု ကာသုစိ= 任何一种的` / `ဧတာသု= 在这些…中` / `ဒန္တော= 调顺的`），译文却不平行。
  - danto：§456 译“调驯好的”，§461 译“调伏”。
  - 句式：§456 是条件“生出了一头…”，§461 变成泛称断言“任何一种都会出生…”。
  - → 建议 danto 统一为“调伏的”或“调驯好的”。§461 改回与 §456 同构，例如“不论在这些种姓中的哪一种里，生出了一个调伏、善顺的人”。
- **jātiya / kula**：§459 jātiye 译“家族”，§461 同一所指（etāsu = 这些 jāti）译“种姓”，§471 kule 译“家族”。nissaya：`ဇာတိယေ= 族类/种姓`。
  - → 建议 §459 改为“种姓”，与 §461 一致；“家族”留给 §471 的 kula。
- **tiṇṇaṃ**：§450-56-72、§450-95-112 译“三者”，§450-73-75 译“三种”。
  - → 建议统一为“三者”：所指是施者、受者、自己，不是“种类”。
- **antarāyakaro**：§450-56-72、§450-95-112 译“作障碍的人”，§450-76-94 译“障碍者”。
  - → 建议统一用一种，推荐“作障碍的人”。
- **te（诽谤者）**：§449-96-114 译“那些这样说的人”，紧接的 §449-145-175 回指同一批人却译“这些人”。
  - → 建议统一为“那些人”。
- **夹注体例**：其他夹注都用词干形，如（samaṇa）（kāmacchanda）。例外有两处：
  - §468 用变格形（santo）；
  - §464 写成“（āsava，漏）”，夹了汉字。
  - → 建议 §468 改为（santa），§464 改为（āsava）。见下文对应句条目。
- **sante**：§468、§469 都译“寂静的圣者”，两处同错，见下文 §468 条目，须一起改。

## §449 句 86-449-145-175

- **问题**：词义/句法 — `vādānupāto` nissaya 释为“随乔达摩之言而起（的言论）”，异释为“他人言论的后续传述”。`gārayhaṃ ṭhānaṃ āgacchati` = “落到应受责难的地步/理由上”（`ဌာနံ= 境地、理由（宾格，趋向）`，`အာဂစ္ဆတိ= 到达`）。
  - 译文“言论推演”偏离了“随之而传的说法”。
  - 译文“会招致应受责难的理由”把 ṭhāna 处理成被招致之物，主谓关系不准。
- **建议**：改为“有没有任何合理的、随您的话而传开的说法，落到应受责难的地步呢？”

## §450 句 86-450-76-94

- **问题**：一致性 — antarāyakaro 在本句译“障碍者”，与前后句“作障碍的人”不一。
  - 附记：nissaya 把 `ပုညန္တရာယကရော` 释作“受者障碍”，是 nissaya 本身的笔误。译文按 pali 译作“施者功德的障碍”是对的，不改。
- **建议**：改为“他成了施者功德的作障碍的人……”，或全段统一用“障碍者”。

## §451 句 86-451-2-53

- **问题**：词义 — `thālidhovanaṃ` nissaya 释“洗锅（罐）的水”（`အိုးဆေးရည်`），`sarāvadhovanaṃ` 释“洗碗的水”（`ခွက်ဆေးရေ`）。译文“洗碗水、洗碟水”把锅译成了碗，碗又挪成了碟。
- **建议**：改为“把洗锅水或洗碗水倒在那里”。

## §451 句 86-451-59-78

- **问题**：语义加重 — `no tathā dussīlassa` nissaya 释“施给无戒者，我不说（它与施给有戒者）同等（大果）”（`တထာ= 与有戒者同等`）。原文是程度比较，译文“施给有戒行的人**才**有大果报”加了排他义，与后半句“则不是这样”的比较语气也不搭。
- **建议**：删“才”，改为“我说施给有戒行的人有大果报，施给无戒行的人则不是这样”。
- **附**：aṅga 全章译“成分”。nissaya 作 `အင်္ဂါ`（支分）。可考虑全章统一改为传统的“支”（五支），不改也须保持全章一致。

## §454 句 86-454-2-11

- **问题**：漏译/补出成分
  - `Iti` nissaya 释“像这样各种各样的”，译文未体现。
  - nissaya 每个颜色词后都补出 `ဂေါသု= 母牛们中`，译文本句无名词，要读到下一行“母牛”才落实，偈颂分行时可以接受。
  - `harīsu` nissaya 释“金黄色的”（`ရွှေဝါရောင်`）。
- **建议**：句首补“像这样，”。“黄色”可作“金黄色”。

## §456 句 86-456-2-12

- **问题**：词义 — `etāsu` nissaya 释“这些母牛中”。译文“这些牛当中的哪一种里”泛化了。
- **建议**：改为“在这些母牛当中”。danto 的统一见跨段一致性。

## §464 句 86-464-2-7

- **问题**：术语/夹注 — `anāsavo` nissaya 释“无漏烦恼的”（`အာသဝကိလေသာမရှိသော`）。āsava 是专门术语“漏”，译“烦恼”就和 kilesa 混了。夹注“（āsava，漏）”也不合体例。
- **建议**：改为“已无诸漏（āsava）”。

## §466 句 86-466-2-19

- **问题**：补出成分 — nissaya：`ဝိပုလာ= 以果报而言增长广大`。“广大”指的是布施的果报，译文“布施才成为广大的”语义不清。
- **建议**：改为“布施的果报才会广大”。

## §468 句 86-468-2-10

- **问题**：误译 — `sante` nissaya 释“以佛陀为首的善人们”（`ဘုရားအစရှိသော သူတော်ကောင်းတို့`）。这里是 santa“善人、正士”，不是“寂静的”。另外“把布施给到”不通顺。
- **建议**：改为“他们把布施送到这教法之外，确实不去亲近那些善人（santa）。”§469 同步改为“而那些亲近善人的人”。

## §469 句 86-469-2-11

- **问题**：误译 — `sante` 同 §468，应为“善人”。
- **建议**：改为“而那些亲近善人的人——亲近那些有智慧、为智者所推重的人，”。

## §471 句 86-471-2-12

- **问题**：添义 — `kule` nissaya 释“刹帝利、婆罗门、商人、农夫之家”，包括吠舍、农家。译文“高贵的家族”加了 nissaya 没有的限定。
- **建议**：删“高贵的”，改为“或者就在这人间生于（好的）家族中”。或直接作“生于人间的家族中”。

## §472 句 86-472-2-10

- **问题**：标点 — 本句是 §471 那首偈的下半，pali 此处没有开引号，只有结尾的 `’’ ti`。译文句首多了一个“，与 §471 句首的“重复，引号失衡。
- **建议**：删去句首“，改为“智者们循序渐进地证得涅槃。”
