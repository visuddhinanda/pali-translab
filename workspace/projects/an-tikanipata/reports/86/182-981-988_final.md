## 理由

**资源缺失（影响评分置信度）**：本次只注入了复注（ṭīkā，book=182）巴利原文与译文，**没有注入其所释的义注（aṭṭhakathā）文本，也没有 nissaya**。方法文档要求"义注定释义、nissaya 定词法"，两者皆缺，本次评估只能以巴利原文本身的词法与上下文为据，属降级评估。因此两点无法核验：

1. **被解释词与父层逐字同译**是硬约束。复注里的黑体引词（`asādhāraṇasikkhāpada` / `thiraṭṭhānato` / `pāsāṇalekhūpamo` / `anuseti` / `na khippaṃ lujjati` / `kakkhaḷena` / `sandhiyati` / `saṃsandati` / `sammodati`）必须与义注（《增支部注》Lekhasutta 一节）里的用词**逐字一致**。译文中多处黑体词译法是"解释式扩写"而非引词形态（见问题清单 🟧 第 1–3 条），在没有义注对照的情况下无法确认是否已对齐——**这是本次最大的未结风险，建议 harmonize 阶段取义注比对后复评**。
2. 词级格位与隐含成分（如 `parāparādhanibbattā` 的复合词内部关系、`dhammacchedakena` 的传统取义）无 nissaya 可校，只能据构词推定。

**准确性**：主谓宾判断整体正确，无 fatal。985-11-21 的关系从句（`yassa… so…`）、986-48-68 的三段式递进（`ādītova / yāva majjhā / yāva pariyosānā`）都处理得准确且清楚，后者"从一开始／到中途／直到做完"的层次感译出来了。扣分集中在三处：`thiraṭṭhānatova` 的 `eva` 与"所刻的"增译（985-2-10）、`dhammacchedakena` 译作"断绝情义"缺依据（985-62-67）、`na antarā nassati` 与 `kammaṭṭhāneneva` 的因果顺序虽不误但"只有靠…才"略强于原文语气。

**风格**：现代书面汉语基调达标，没有"此中/故为/彼等"一类硬性文言腔。但残留若干半文半白痕迹：**"谁…这样的人"的文言关系句式**（985-11-21）、"**正因为…才如此**"（985-2-10）、"**不半途退出**"中的"半途"与"**进行到中途不停**"的单音节紧缩，读起来仍有旧注疏味道。另外 982、985-2-10 的"**一三二、第九经中**""**一三三、第十经中**"沿用汉字数字编号，与原文 `132.`/`133.` 的对应关系尚可，但"第九经中"的"中"字可省。

**标点**：风格文件要求"引号一律用全角 "" ''，不要用直角引号「」"——译文中**未出现**任何引号，合规；全角逗号句号使用正确；ASCII 引号零出现，JSON 安全。986-2-17、986-18-30 等句中"**就像…那样**"前后用破折号或逗号的处理不统一（985-72-79 用了"——"，同类句 986 系列未用），计入一致性扣分。

**一致性**：三个核心术语 `sandhiyati / saṃsandati / sammodati` 在 986-2-17、986-18-30、986-31-47、986-48-68 四处**译法完全统一**（和好／毫无隔阂／完全和睦如一），这是本段最值得肯定的一致性表现。但 985-68-71、985-72-79 与 986 组的同词条目，在"是…的意思是…"句式上一处带破折号一处不带。另，`kodha` 全段统一译"怒气"，与 `kodhalekhā`"怒气之痕"协调。

**译文工作标记**：全段无候选、待定、问号、TODO 残留，合规。

## 问题清单

### 🟧 error

- `182-985-2-10`｜错译（增译）｜片段「正因为所刻的地方坚固才如此」
  - 问题：原文 `thiraṭṭhānatova` 仅为 `thiraṭṭhānato` + 强调词 `eva`，直译为"正是由于所在之处坚固"。译文增出"**所刻的**"三字——原文无 `likhita`/`lekhā` 任何成分，此处是复注对 `thiraṭṭhāna`（坚固之处）的同词复述，被解释词本身尚未限定为"刻痕之处"。增译把下一句才引入的"石上刻痕"意象提前，属无据增补。
  - 建议：改为"**由于所在之处坚固**的意思，正是指由于所在之处坚固"，保持复注"以同词复述作强调"的体例；若义注确有"刻处"之说，需取义注原文为据再定。

- `182-985-62-67`｜义理或用词与注释书不符（待核）｜片段「断绝情义」
  - 问题：`dhammacchedaka` 字面为"截断 dhamma 者"。传统注解多解为"**破坏法／不合法度**"或"截断（听者的）善法"，指话语之恶性质；译作"断绝情义"把 `dhamma` 读成"情义/人情"，缺乏构词与注释依据，且与前后 `atikakkhaḷena`（极粗硬）、`thaddhavacanena`（生硬话语）的"言辞性质"语义场不协调。
  - 建议：暫改"**违背法度的**"或"**损害善法的**"，并在 harmonize 阶段取《增支部注》对应条目定案。

- `182-985-68-71`｜错译（被解释词与父层未逐字同译，待核）｜片段「**毫无隔阂**的意思是彼此合为一体」
  - 问题：被解释词 `saṃsandati` 是动词（"汇合、融合"），译作"毫无隔阂"是**形容状态的意译**，不是引词的对应译法。更关键的是：同一 `saṃsandati` 在 986-18-30、986-48-68 作为黑体引词反复出现，若义注正文把它译作动词（如"融合"），则此处"毫无隔阂"与父层不同字，违反"被解释词与父层逐字同译"硬约束。同组 `sandhiyati`→"和好"、`sammodatī`→"完全和睦如一"存在同一风险。
  - 建议：取义注该段译文核对三词的既定译法，统一回引词形态（如 融洽／融合／和睦）；本条与下一条应同批处理，不要只改其中之一。

- `182-985-72-79`｜错译（同上，待核）｜片段「**完全和睦如一**的意思是相处毫无间隙」
  - 问题：同上条。另 `nirantaro hoti`（成为无间断的／无间隙的）译"相处毫无间隙"增出"相处"主语，在无 nissaya 核对隐含主语的情况下属推定增补；且"毫无间隙"与上条"毫无隔阂"用词过近，两个不同巴利词的释义在汉语里趋同，削弱了复注逐词区分的作用。
  - 建议：拉开两词区分度，如 `saṃsandati`→"融合"、`sammodati`→"和睦"，释义分别作"合为一体""（关系）持续不断"。

### 🟨 warning

- `182-985-11-21`｜文言语体｜片段「谁因他人的过错而生起的怒气之痕像石上的刻痕一样，这样的人」
  - 问题：以"**谁**…，这样的人…"对译 `yassa… so…` 关系从句，是文言/翻译腔句式，现代汉语不用疑问代词"谁"起首作关系词。读来像旧式注疏，违反 style.md"读给没有古文基础的读者不得觉得像文言"的判定标准。
  - 建议：改为"**有的人**因他人的过错而生起的怒气，像石头上的刻痕一样（留存不去），这样的人就与石上刻痕的比喻相合"。

- `182-985-2-10`｜文言语体｜片段「才如此」
  - 问题："正因为…**才如此**"是文言式紧缩收尾，"如此"作单音节文言指代词。
  - 建议：与本句上一条 error 一并重写，去掉"才如此"。

- `182-986-48-68`｜文言语体｜片段「进行到中途不停」
  - 问题："不停"单音节紧缩，且"进行到中途不停"主语脱落、语义含糊（是"不停止做事"还是"不停留"）。原文 `yāva majjhā pavattanto` 指"一直做到中途"。
  - 建议：改为"**一直做到中途都不中断**"。

- `182-986-48-68`｜文言语体｜片段「都不半途退出」
  - 问题："半途"为文言色彩词，且与前文"中途"同义异形，一句之内两种说法。
  - 建议：统一为"**直到事情做完都不退出**"。

- `182-985-30-39`｜整句逻辑表达不规范｜片段「因为它只有靠修习业处（kammaṭṭhāna）才会消失」
  - 问题：原文 `kammaṭṭhāneneva nassanato` 是具格+夺格表因由，意为"因为（它）只由业处而消失"。译文的"只有靠…才"把限定焦点说得比原文强，且"修习"二字为增译（原文只有 `kammaṭṭhāna`）。此外夹注"（kammaṭṭhāna）"是 `kammaṭṭhāna` 首次出现，合 style.md 夹注规则，保留无误。
  - 建议：改为"因为它**只由业处而消失**"，去掉"修习"与"只有…才"的双重强调。

- `182-982-2-19`｜不导致误解的汉语语病｜片段「与比丘尼不共通、只为比丘制定的学处」
  - 问题："共通"在汉语里需要"与…共通"的对象，"**不共通的学处**"单独作被解释词时读来不完整；且"共通/不共通"一对术语在佛教律学汉译中通常作"**共学处／不共学处**"（或"共通戒／不共通戒"）。terms.md 与 term-glossary.jsonl 均未登记此词，按 style.md"未定译名"条应择一有据译法并压低该句 confidence。
  - 建议：确认是否沿用"不共学处／共学处"；若保留现译，需把该分歧写入术语报告待定案。

- `182-985-40-61`｜关键词语意不明确｜片段「在第二天或再隔一天就结束」
  - 问题：`punadivase vā aparadivase vā` 的"第二天/再隔一天"对读者而言不易看出这是在举"短期内"的例子，与"不会在中途结束"的论点关系需要一点提示。
  - 建议：改为"**不会在中途结束，无论是第二天还是第三天**"，使并列项与"中途"的从属关系更清楚。

### 🟦 suggestion

- `182-985-40-61`｜语言表达不够流畅｜片段「只有到死的时候才结束」
  - 问题：`maraṇeneva niṭṭhāti` 为具格，"只因死亡而终止"。"到死的时候"偏口语，与全段书面语体略有落差。
  - 建议：改为"**只随着死亡才终止**"。

- `182-985-62-67`｜语言风格不统一｜片段「用极其粗硬、断绝情义、生硬僵硬的话语」
  - 问题：三个修饰语中"粗硬""生硬僵硬"语义高度重叠（`kakkhaḷa` 与 `thaddha` 本就近义），叠加后读来累赘；且被解释词本身已译"粗硬"，释义里再用"粗硬"构成同词循环解释。
  - 建议：被解释词与释义用词错开，如释义作"用极为严厉、违背法度、冷硬的话语"。

- `182-986-2-17`｜语言表达不够流畅｜片段「以身体与对方结合在一起」
  - 问题：`kāyena samodhānaṃ gacchati` 直译为"以身趋于结合"。"以身体与对方结合在一起"在汉语里有歧义联想，三处同构句（986-2-17 身／986-18-30 心／986-31-47 语）都用了"以…与对方结合在一起"。
  - 建议：改为"**在身体上与对方协同一致**／在心上与对方相契／在言语上与对方相应"，既去歧义，也让三层的区分更鲜明。

- `182-981-2-4` `182-984-2-4`｜该使用而没有使用术语标记｜片段「覆藏经注释」「刻痕经注释」

  - 建议：标题句作"覆藏经（Paṭicchannasutta）注释""刻痕经（Lekhasutta）注释"；983、987 的"结束"句不必重复夹注。

- `182-988-2-4`｜语言风格不统一｜片段「拘尸那罗品注释结束」
  - 问题：`Kusināravagga` 的"拘尸那罗"属 terms.md 未登记的地名，但属传统汉译常见形，保留妥当；仅提示与前两条经名的夹注策略应一并决定，避免品名有夹注而经名没有（或反之）。
  - 建议：与上一条同批处理，统一标题层的夹注体例。
