## 理由

**取数情况**：本次只注入了本文（mūla）巴利原文与 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。按 method 文档规定降级为纯 pali 对读。因此「与义注释义是否相符」「与 nissaya 的格/句法吻合」两条打分依据无法执行，准确性分数仅基于巴利原文本身的词法与句法核对，信心指数据此压低到 62。几处标注为 error 的判断（尤其 `davāya / madāya / maṇḍanāya / vibhūsanāya` 四项的取义、`yoni` 的释义）按传统注释书通例应能定案，但缺义注原文佐证，**定稿前建议补取义注复核**。

**准确性**：主谓宾判断整体正确，六根防护段、饮食知量段、警寤段的框架译得稳。扣分集中在三处：（1）食观四否定项中 `madāya`（为了骄慢/陶醉）、`maṇḍanāya`（为了装饰）、`vibhūsanāya`（为了美容/打扮）的分配有错位，译文把 `madāya` 译为「逞强自恃」、`maṇḍanāya` 译为「身体丰美」，与传统取义不符；（2）`yoni`（原因、根源）译为「他身上那个……原因」，把抽象因喻具身化，表达牵强；（3）`yātrā` 译为「维持生命」偏窄，且与前文 `yāpanāya`（让它存续）重复。

**风格**：现代书面汉语达标，未见文言虚词与文言句式，无「此中/故为/彼等」一类禁例，标点全角合规，`zh` 字段内无 ASCII 引号。扣分在少量表达不自然处（「他身上那个……原因」「对眼根做到防护」）。

**一致性**：三法名目（守护诸根之门 / 在饮食上知道节量 / 努力保持清醒）在 75、76、77、78 各段的提问、解说、收束三处均完全一致，首尾 75 与 78 的总说句逐字对应，术语夹注（āsava、五盖）出现位置合理。仅 `apaṇṇaka` 的处理可议——标题译「无误经」、句中译「无误之道」，自身一致。

## 问题清单

### 🟧 error

- `86-77-24-62`｜错译（词义）｜片段「不是为了逞强自恃，不是为了身体丰美」
  - 问题：四项否定的对应关系错位。`madāya` 是「为了骄慢、陶醉（于体力）」，不是「逞强自恃」；`maṇḍanāya` 是「为了装饰、修饰（身体）」，不是「身体丰美」。译文把 `maṇḍanāya` 的「装饰」义挪给了后面的 `vibhūsanāya`（「妆饰」），导致 `maṇḍanāya` 失去对应、被译成了结果状态而非目的。
  - 建议：改为「不是为了嬉戏，不是为了骄慢，不是为了装饰，不是为了美容」一类分配，使四项与 `davāya / madāya / maṇḍanāya / vibhūsanāya` 一一对位；定案前核对义注对此四词的释义。

- `86-75-2-38`｜错译（词义、修饰关系）｜片段「他身上那个导向灭尽诸漏（āsava）的原因，已经策发圆满」
  - 问题：`yoni cassa āraddhā hoti āsavānaṃ khayāya` 中 `yoni` 指「（证得漏尽的）根源、因」，`assa` 是属格「他的」，译文译为「他身上那个」把抽象的因处理成身体内的事物，且「策发圆满」给 `āraddhā` 加入了原文没有的「圆满」义（`āraddha` 是「已开始、已着手、已精勤发起」）。
  - 建议：改为「他灭尽诸漏（āsava）的根源已经发动」或「他已经着手于灭尽诸漏的根源」一类；去掉「身上那个」与「圆满」。

- `86-78-2-12` / `86-78-65-74` / `86-75-42-58`｜错译（词义）｜片段「努力保持清醒」
  - 问题：`jāgariyaṃ anuyutto` 指「致力于警寤（修行上的不眠警觉）」，是贯通昼夜三时的修行项目，不等于生理上的「保持清醒」。译文使三处收束句都偏向「不睡觉」，与 `86-78-13-64` 内明确包含中夜卧眠的描述自相矛盾。
  - 建议：统一改为「致力于警寤」或「勤修警寤」，三段提问、解说、收束同步替换。

### 🟨 warning

- `86-76-27-53` / `86-76-78-98`｜整句逻辑表达不规范｜片段「因此他修习对眼根的防护，守护眼根，对眼根做到防护」
  - 问题：`saṃvarāya paṭipajjati` 与 `saṃvaraṃ āpajjati` 都译成「防护」，同句三小句里「防护」出现两次、「守护」一次，读来像同义反复，原文递进（趋向防护—守护—达成防护）被压平。
  - 建议：三小句分别用「他为了防护而修行，守护眼根，于眼根成就防护」一类有层次的措辞；意根段同步处理。

- `86-76-27-53`｜关键词语意不明确｜片段「贪欲和忧恼这些恶的、不善的法就会随之流向他」
  - 问题：`anvāssaveyyuṃ`（随流入）的「流向他」在汉语里语意不明确，读者难以判断「流向」指什么；且 `abhijjhādomanassā`（贪与忧）作为复合词的两项与后面「恶的、不善的法」是同指关系，译文用「这些」连接尚可，但「流向他」一处仍需明确。
  - 建议：改为「就会侵入他的心」或「就会随之漏入」，并考虑为 `anvāssava`（随漏入）加一处简注。

- `86-78-13-64`｜关键词语意不明确（二意场合无注释）｜片段「使心从覆障之法（五盖）中清净」
  - 问题：`āvaraṇīyehi dhammehi` 直指「障碍法」，译文夹注「（五盖）」把它限定为五盖（nīvaraṇa），这是注释书的解释而非原文字面，但夹注格式上看像是巴利原词对照，容易被读作原文自带。按 `style.md` 第三节，夹注圆括号用于附巴利原词，此处放汉语解释属体例不一致。
  - 建议：巴利原词夹注改为「覆障之法（āvaraṇīya dhamma）」，「五盖」一说移入脚注或报告；若保留，需义注依据支持。

- `86-77-24-62`｜不导致误解的汉语语病｜片段「这样我就能维持生命，没有过失，安稳地生活」
  - 问题：`yātrā ca me bhavissati` 的 `yātrā` 是「（旅程般的）维生、支持」，译「维持生命」与前句「为了维持这个身体、让它存续」重复；三项并列中前两项是名词性、第三项是动词短语，结构不齐。
  - 建议：改为「这样我的行道得以持续，无可指责，安住安稳」一类，三项同为名词性。

- `86-78-13-64`｜不导致误解的汉语语病｜片段「心里确定好起身的时刻」
  - 问题：`uṭṭhānasaññaṃ manasi karitvā` 是「作意起身之想」，译文「确定好起身的时刻」把「想（saññā）」改成了「时刻」，并加入了原文没有的「确定」；虽不致误解，但属增译。
  - 建议：改为「心里作起身之想」。

### 🟦 suggestion

- `86-74-2-4`｜不常用术语编写注释或者百科｜片段「六、无误经」
  - 问题：`Apaṇṇaka` 是罕见词，经名「无误」缺少说明；南传汉译另有「不损减」「无疑」等处理。按 `style.md` 第二节，罕见术语首次出现宜附简注。
  - 建议：标题或 75 段首次出现「无误之道」处附巴利原词夹注「无误之道（apaṇṇakapaṭipadā）」，并在报告中登记待定译名，定案后补进 `terms.md`。

- `86-76-14-26`｜该使用而没有使用术语标记｜片段「不执取总相，也不执取细相」
  - 问题：`nimitta`（总相）与 `anubyañjana`（细相）是法相术语，首次出现未夹注巴利原词，与同段 `āsava` 的处理不一致。
  - 建议：首次出现处改为「不执取总相（nimitta），也不执取细相（anubyañjana）」。

- `86-78-13-64`｜语言表达不够流畅｜片段「左脚略错开地搭在右脚上」
  - 问题：`pāde pādaṃ accādhāya` 原文只说「足叠于足、略错开」，未指明左右；译文补出「左脚……右脚」属合理推断（右侧卧），但「略错开地搭在」一处略拗口。
  - 建议：改为「两脚相叠而稍稍错开」，既不补出左右，也更顺。

- `86-75-42-58` / `86-76-14-26` / `86-77-14-23` / `86-78-13-64`｜语言表达不够流畅｜片段「比丘们，在这里，比丘」
  - 问题：`Idha, bhikkhave, bhikkhu` 的 `idha` 译「在这里」四处重复，在汉语里指代空泛（实指「在此法与律中」）。
  - 建议：统一改为「比丘们，在这法与律中，比丘……」或径作「比丘们，一位比丘……」，四处保持一致。
