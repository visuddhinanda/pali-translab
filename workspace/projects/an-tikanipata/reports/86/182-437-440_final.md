## 理由

**基准缺失（降级评估）**：本次只注入了巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。复注是逐词解释义注的文体，本段 11 条里有 3 条引述义注原词（`phātiṃ kareyya` / `idhaloke` / `kathaṃ`），按硬约束「被解释词与父层逐字同译」必须与义注译文逐字核对，现在无法核对；`āyakosalla`、`sappaṭibhāga` 的取义也无义注可依。因此准确性只能按巴利本身判读，信心指数压到 62。补齐义注层后应重评。

**准确性**：绝大多数逐词注解（`Paṭipakkhavasenā` / `Sukka-` 与 `Kaṇha-sappaṭibhāgā` / `Ubhayattha` / `Na socati`）词义、格与句法角色判读正确；`pahāyakehi`（能断）与 `pahātabbehi`（应断）的主动／被动对比译准，是本段最见功力之处；`Ubhayatthā` 条把 `iti viggaho`（复合词的分解）与 `dassento … āha` 的句构完整还原，无漏译。主要扣分在 `182-438-2-36`：第二种人那一句的巴利是省略句（`dutiyopi` 后无谓语），译文自行补出了完整的判断句与「独眼的人」这一本段并未出现的词，属无依据增译。`182-439-2-14` 把工具格 `yādisehi`（凭这些财富）改作汉语主语，意思不错但施事关系被抹平。

**风格**：语体合格，通篇无文言句式、无「此中／故为／彼等／于…之际」一类禁例，标点全角、引号统一用 “”，译文 `zh` 内无 ASCII 引号，无残留工作标记（唯「使……增长」的省略号接近占位符，见清单）。唯一语体瑕疵是反复出现的「智慧之眼」用了文言虚词「之」，按 `knowledge/style.md` 第一节判为 warning。

**一致性**：同一词根在相邻条目里译法摇摆——`ubhayattha` 作「两处」而 `ubhayena` 作「两两并用地」；`paṭipakkha`（对立）与 `sappaṭibhāga`（有对应／相对）共用「对立」，原文的词义层级被合并；`Na socati` 的被释词作「不会心怀忧愁」而释义里同一词作「不忧愁」，复注文体中被释词与释义应可互相对应。「（义注）说」这一补主语的处理前后一致，是加分项；`āyakosalla` 夹注巴利原词合规。

## 问题清单

### 🟧 error
- `182-438-2-36`｜错误多译（无依据增译）｜片段「第二种人则因为两种眼只具备其中一种，被称为“独眼的人”」
  - 问题：本条巴利只有 `dutiyopi ,` 一个省略成分，既无谓语、也无 `ekacakkhu` 一词（本段引号内只出现 `andho` 与 `dvicakkhū`）。译文补出了完整的因果判断句和「独眼的人」这一译名，等于替原文写出了它没说的话；且「两种眼只具备其中一种」本身表述含混，读来像「两种眼各只有一半」。
  - 建议：按省略句处理，依义注补足并压低该句 confidence，例如「第二种人也是这样（只具备其中一种慧眼，所以称为一眼的人）」，或把补出的成分交代到脚注里；补出的译名须与义注层对 `ekacakkhu` 的译法逐字一致，待义注注入后核定。

### 🟨 warning
- `182-438-37-41`｜文言语体｜片段「智慧之眼」
  - 问题：用文言虚词「之」作定语标记，`182-438-2-36` 与本条共出现四次。`style.md` 第一节明确禁用作虚词的「之」。
  - 建议：统一改为「慧眼」（首次出现夹注 `paññācakkhu`）或「智慧的眼」，并同步改 `182-438-2-36` 的两处。
- `182-438-42-50`｜关键词语意不明确｜片段「使……增长」
  - 问题：省略号充当了被省略宾语的占位符，读者无从知道增长的是什么；译文不应留占位性标记。
  - 建议：按义注原文补出受事并用方括号标明，如「使〔财物〕增长」；补出的措辞须与义注层 `phātiṃ kareyya` 的译文逐字相同。
- `182-439-43-56`｜关键词语意不明确｜片段「两两并用地」
  - 问题：`ubhayena` 是工具格「以两者（并举）」，指义注把今世、来世两项合起来说；「两两并用地」既不是常用汉语搭配，也容易被读成「成对地反复使用」。且与上一条把 `ubhayattha` 译作「两处」不呼应。
  - 建议：改为「以两者并举」或「就两者合起来说」，并与「两处」统一为同一词根的译法。
- `182-438-63-69`｜代词指代不明确｜片段「它们与那些能够断除黑法的白法相对立」
  - 问题：「它们」的先行词（黑法）不在本句内，复注逐条独立呈现时读者无法确定所指；另「能够断除黑法的」中的宾语「黑法」是译者补出的，原文 `pahāyakehi` 只说「能断」。
  - 建议：把先行词显化为「这些黑法与……相对立」；补出的宾语加括号或依义注核定后保留。`182-438-70-76` 的「它们」同样显化为「这些白法」，两条保持对称。

### 🟦 suggestion
- `182-438-37-41`｜术语标记与译名｜片段「就是属于增益善巧（āyakosalla）的那种智慧之眼」
  - 问题：`āyakosallabhūtā` 是「即为／以……为体」，「属于」把等同关系弱化为所属关系；`āyakosalla` 通常与 `apāyakosalla` 对举，汉译多作「收益善巧／损失善巧」。
  - 建议：「就是以收益善巧（āyakosalla）为体的慧眼」；译名定案后补进 `knowledge/terms.md`。

  - 建议：两处统一为「不忧愁」，并与义注层对 `na socati` 的译法保持一致。
- `182-438-58-62` / `182-438-63-69`｜语言风格不统一｜片段「相对立」

  - 建议：`sappaṭibhāga` 改用「与……相对应／以……为对应的一方」，把「对立」留给 `paṭipakkha`。
