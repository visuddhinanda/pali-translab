## 理由

**取数情况（降级说明）**：本次注入的资源只有巴利原文与目标 channel 译文，**未取到 nissaya，也未取到更上层的复注（ṭīkā）**。本段本身即是义注层（aṭṭhakathā, book=100），按方法文档「义注定释义」的基准，这里只能以义注原文自身的内部逻辑、与所释本文（AN《瞿昙迦庙经》及《根本法门经》相关段）的通行理解为参照，无法做词级格位核对。因此信心指数压到 68：准确性判断主要基于巴利语法与教理常识，不是 nissaya 对读。有 nissaya 后，`100-930-74-90`、`100-931-93-117` 两处应重新核验。

**准确性**：主干译得稳。五处被解释词（`gotamake cetiye` / `etadavoca` / `abhiññāya` / `sanidānaṃ` / `sappāṭihāriyaṃ` / `alañca pana vo` / `tuṭṭhiyā` / `akampittha`）的黑体标记与父层引文位置都对得上，lemma 释义结构（「X，意思是 Y」）贯穿一致。主要扣分在三处：`mukhasampattameva kathetī` 的译法（`100-930-74-90`）把婆罗门比丘的讥谤内容译偏，`mayhaṃ kathā niyyāti` 的「说得通就行」是意译过头且逻辑不顺；`akampittha` 被译为「震动了」但该词在此是**不及物·中动**用于大地，lemma 行与后文主语不一致（见问题清单）；`bhavagga` 译「有顶」并夹注，处理可取，但同段后四句未再出现夹注却反复使用「有顶」，属于一致性正确、但首见夹注位置偏早的小问题。

**风格**：现代书面汉语基本达标，无「此中/故为/彼等/是故」类文言腔，`便/遂/乃` 未见。标点全角、无 ASCII 引号，符合 JSON 安全约束。扣分点为少量半文半白残留：「理应」「依仗」「依处」「正是恰当的」中「依处」最可疑（`upanissāya` 的术语化直译，普通读者读不懂）。

**一致性**：`avīci`→「无间地狱」、`bhavagga`→「有顶」、`cetiya`→「庙」、`satthā`→「导师」、`tathāgata`→「如来」全段统一；`100-932` 四个方位句采用完全平行的句式，复现了原文的重复体例，处理得当。唯一不统一是 `100-932-2-7` 的「震动了」与后文 `100-932-88-96` 的「震动了」虽同词，但前者缺少主语承接。

## 问题清单

### 🟧 error

- `100-930-74-90`｜错译（词义）｜片段「只想着‘我这话说得通就行’，随口现成的就拿来讲罢了」
  - 问题：`mayhaṃ kathā niyyāti` 的 `niyyāti` 是「（话头）接得下去／说得过去」，主语是 `kathā`，这是**被引述的比丘自己揣测佛的心思**；译文「只想着…就行」把心理动词补得过重，且「随口现成的就拿来讲罢了」把 `mukhasampattaṃ`（口头现成之语）与 `eva` 的限定义揉成了口语化的轻蔑表达，讥谤的具体内容（佛只是把口边凑手的话拿来讲，没有章法）与「说得通就行」两层意思重叠混淆。
  - 建议：改为贴近原文的双层结构，如「正等正觉者只是想着‘我的话能接得下去就行’，把口边现成的话拿来讲而已」。
- `100-932-2-7`｜导致误解的表达｜片段「**震动了**，意思是以六种方式震动了」
  - 问题：`akampittha` 此处主语是大地（见 `100-932-88-96` 的 `mahāpathavī akampittha`），lemma 行不带主语译作「震动了」，中文「震动了」可作及物（震动了某物），读者易误读为佛震动了什么。本文被释句是「大地震动」，释词应保持不及物。
  - 建议：lemma 行补出受动主体或改用不及物表达，如「**震动了**，意思是（大地）以六种方式震动」。

### 🟨 warning

- `100-929-35-44`｜关键词语意不明确｜片段「他以毗舍离为依处」
  - 问题：「依处」是生硬的术语化直译（`upanissāya`），非佛学读者无法理解，且「依处」在阿毗达摩中另有专义（`nissaya`/所依），在此引入歧义。
  - 建议：改为「他住在毗舍离附近」或「他以毗舍离为依止之地，住在…」。
- `100-931-85-92`｜文言语体｜片段「**而且你们理应**」
  - 问题：「理应」为半文半白的单音节化表达，且 `alaṃ + 与格` 是「对你们来说足以／恰当」，lemma 译「你们理应」改变了句法主体。下文释义「对你们来说是恰当的」是对的，lemma 与释义因此不一致。
  - 建议：lemma 改为「**而且对你们来说足以**」或「**而且你们尽可以**」，与释义口径一致。
- `100-931-93-117`｜整句逻辑表达不规范｜片段「生起满意正是恰当的」
  - 问题：长句「对于你们这些依功德忆念…这三宝的人来说，生起满意正是恰当的」中，「生起满意」为动宾搭配不自然（`tuṭṭhiṃ kātuṃ` 是「感到欢喜／生起欢喜」），且「满意」一词在三宝语境下偏弱，易被读成「对讲法内容表示满意」而非对三宝功德的欢喜。
  - 建议：「满意」改作「欢喜」，并与 `100-931-93-117` lemma 的「**感到满意**」一并统一为「**感到欢喜**」；句子改为「…你们感到欢喜正是恰当的」。
- `100-930-24-36`｜不导致误解的汉语语病｜片段「生起了自以为懂的骄慢，就不去闻法堂，心想：」
  - 问题：三个分句用「就」连接后直接接冒号引语，但原文 `na gacchanti` 后的引语是**理由**（`ti` 引述其想法作因），中文「心想：」是译者补出的衔接词，位置使因果倒置（先不去、后心想）。另「闻法堂」缺「去」的处所标记外，`dhammassavanaggaṃ` 是「听法的集会／讲堂」，译「闻法堂」偏术语化。
  - 建议：调整为「…生起了自以为懂的骄慢，心想『…』，就不去听法的集会」。

### 🟦 suggestion

- `100-931-2-47`｜语言表达不够流畅｜片段「意思是这样知道、通达、亲自现证：“这些是五蕴…七心”；同样地——」
  - 问题：原文 `jānitvā paṭivijjhitvā paccakkhaṃ katvā` 三个连续式动词在前、引文在后，译文把引文提到三个动词之后用冒号引出，与 `100-931-48-65` 的「又按…的方式，一一知道、通达并亲自现证那些法」语序相反，两句同构却句式不一，读者不易看出是同一套三动词。
  - 建议：两句统一语序，如「意思是知道、通达、亲自现证『这些是五蕴…』」与「又按『这些是四念处』等方式，知道、通达、亲自现证那些法」。
- `100-932-14-31`｜该使用而没有使用术语标记｜片段「直撞到有顶（bhavagga，最高的生存界）一样」
  - 问题：`bhavagga` 首次出现即夹注，做法正确；但同段 `avīci`→「无间地狱」属常见汉译未夹注、尺度合理，而 `bodhimaṇḍa`→「菩提座」为罕见术语却无夹注，两者尺度不一。
  - 建议：`100-932-8-13` 的「菩提座」首见处夹注「（bodhimaṇḍa，菩提树下的金刚座）」。
- `100-930-55-63`｜语言表达不够流畅｜片段「先取得他们亲口的承认」
  - 问题：`mukhapaṭiññaṃ gahetvā` 译「取得亲口的承认」准确，但「承认」承接的内容（承认自己确有此想）未显化，普通读者不知承认什么。
  - 建议：可作「先让他们亲口承认（确有此想）」。
- `100-931-75-84`｜语言风格不统一｜片段「**能破斥异议的**，意思是我以驳倒反对者的方式」
  - 问题：lemma 用「破斥异议」、释义用「驳倒反对者」，`paccanīka` 与 `pāṭihāriya` 的对译在一句之内换了两套词，略显跳脱。
  - 建议：统一为「破斥」一系，如「意思是我以破斥反对者的方式，讲说的都是能破斥（异议）的」。
