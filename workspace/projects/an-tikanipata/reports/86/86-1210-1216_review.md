## 一、必改项（与义注相悖，影响全经）

### 核心词 `assaparassa` / `purisaparassa` 译反了方向

**义注**：`Navame **assaparasse**ti assesu parasse .` / `**Purisaparasse**ti purisesu parasse , purisapuriseti attho .`

义注把 `assaparassa` 解作「诸马之中的 parassa」，把 `purisaparassa` 解作「诸人之中的 parassa」，并直接给出等义词 **`purisapurisa`（人中之人）**——这是巴利惯用的**褒义**格式（如 `nāgo nāgānaṃ`），指同类中的优异者。写本异读 `assasadasse` / `purisasadasse`（`sadassa` = 良马）同向佐证。

另有两条义注旁证：

- **义注**：`Imasmiṃ sutte tīṇi maggaphalāni kathitāni .`（此经说了三个道果）
- **义注**：`Tattha ayaṃ tīhi maggehi ñāṇajavasampannoti veditabbo .`（应知此人是以三种道成就了**智之速**〔ñāṇajava〕）

即：此人已得三果（至阿那含），义注称其「具足智速」，是**称许**，不是贬斥。本文内部结构也印证——三种之中第三种「速度、毛色、身量」三者俱全，整个三项是**优点递增表**，不可能是「劣马」。

现译把 `parassa` 一律作「劣」处理，与义注的释义正相反，属**误译**而非风格问题，须全 chunk 改。涉及句：

| 句 id | 现译 | 改法 |
|---|---|---|
| 86-1210-2-4 | 九、**驽马**经 | 九、良马经 |
| 86-1211-2-43 | 三种**劣马**…三种**劣人** | 三种良马…三种良士 |
| 86-1212-2-12 / 13-21 / 27-38 / 42-56 / 57-64 | **劣马** | 良马 |
| 86-1213-2-11 / 12-20 / 26-38 / 42-57 | **劣人** | 良士 |
| 86-1214-2-12 / 69-77 | **劣人** | 良士 |
| 86-1215-2-17 / 66-75 | **劣人** | 良士 |
| 86-1216-2-17 | **劣人** | 良士 |

译名建议：`assaparassa` →「良马」，`purisaparassa` →「良士」（首次出现可夹注巴利原词并说明义注训为「人中之人」）。**定名后须与义注层（100:966）的被解释词译文逐字一致**——义注黑体 `assaparasse` / `Purisaparasse` 是从本文原样引出的，本文译「良马」「良士」，义注那两句就必须同字，否则对应关系断裂。

### 标题与正文用词不一致（即便不改方向也必须修）

§1210 标题作「驽马」，正文一律作「劣马」。同一个 `assaparassa`，标题与正文两套译名，属硬性不一致。

## 三、跨段一致性

- **`Idamassa … vadāmi` 句式**：§1214-36-39 /§1215-35-38 /§1216-36-39 作「我说这就是他的**速度**」（名词结构），而 §1215-50-53 /§1216-51-54 作「我说这就是他**具足毛色**」（谓语结构），§1214-51-55 /§1214-64-68 作「我说这就是他**不具足**毛色／身量」。同一公式三种句型。→ 建议统一为名词结构：「我说这是他的速度／他的毛色／他的身量」，否定式作「我说这是他在毛色上的欠缺」，依据：原文 `javasmiṃ / vaṇṇasmiṃ / ārohapariṇāhasmiṃ` 均为处格同形公式，译文不应变换结构。
- **三德并列的连接词**：§1212-27-38「具足速度，**也**具足毛色」（无「既」），而完全平行的 §1213-26-38 /§1215-2-17 作「**既**具足速度，也具足毛色」。→ 统一加「既」。
- **`Evaṃ kho … javasampanno ca hoti`（§1215-66-75）**：现译「这样就是劣人**既**具足速度；」而下一句（76-81）「也具足毛色，却不具足身量。」——「既…」被分号切断在上一句末，读起来断气。→ 「既」移到后半句承接，或改为「这样，良士具足速度；也具足毛色，却不具足身量」。
- **`kho pana` 的转折词**：§1214-40-50 作「但是」、§1214-56-63 作「而且」、§1215-39-49 作「而且」、§1215-54-60 作「但是」。此处随上下文极性变化是对的（正→负用「但是」，负→负用「而且」），**不必统一**，但补译 §1216-55-60 时须延续同一逻辑（正→正，用「而且」）。
- **`abhidhamma` / `abhivinaya`**：全 chunk 一致作「阿毗达摩／阿毗毗奈耶」，内部无漂移 ✅。但与 `knowledge/term-glossary.jsonl` 登记的 `abhidhamma → 论` 不一致。此处二词对举，音译可取（译「论」会与「律」对举失衡），建议**保留音译**，按 `style.md` 第三节在首次出现处夹注巴利原词：「阿毗达摩（abhidhamma）」「阿毗毗奈耶（abhivinaya）」，并把这一例外补进 `terms.md`。

## 四、§1211-44-50 句 86-1211-44-50

- **问题**：取义偏窄 — `sādhukaṃ manasi karotha` 现译「好好地**在心里记住**」，偏向「记忆」；该语是「善加作意／用心领受」，重点在当下的专注，不是背诵。
- **建议**：「好好地用心领受」或「好好地专注听受」。

## 五、§1214 句 86-1214-40-50

- **问题**：`saṃsādeti` 现译「**含混推托**」，加入了「推托」所含的主观回避意味；该词是「陷住、卡住、答不下去」，说的是能力不及，不是存心敷衍。
- **建议**：「他就卡住，答不上来」；下文 §1215-39-49 /§1216-40-50 的 `no saṃsādeti` 相应作「不会卡住」。三处须同改同词。

## 六、§1214 句 86-1214-2-12、§1215 句 86-1215-2-17、§1216 句 86-1216-2-17

- **问题**：语序生硬 — 「怎样是劣人具足速度」，「怎样是」直接带主语+谓语，不是自然的现代汉语问句。
- **建议**：「比丘们，怎样才算良士具足速度，而不具足毛色、不具足身量呢？」

## 七、义注未落实之处（建议 footnote 步处理，本步不改译文）

- **义注**：`Tattha ayaṃ tīhi maggehi ñāṇajavasampannoti veditabbo .` — 义注明确把本经的「速」（`java`）定为**智之速（ñāṇajava）**，且指出此人是「以三种道」成就。本文字面只说「具足速度」，读者无从知道喻解。
- **建议**：在 §1214-36-39 首次出现「速度」处加脚注，标明层次：「**义注**：此处的『速』指智之速（ñāṇajava）；此人已由三种道成就之。」切勿把这层解释并入正文，那会把义注的说法混作经文本身的说法。
