## 理由

**基准可用性（信心下调主因）**：本次只注入了复注（ṭīkā）巴利原文与待评译文，**未提供父层义注（aṭṭhakathā）原文，也没有 nissaya**。因此"义注定释义、nissaya 定词法"两条基准都无法执行：
- 复注黑体引自义注（`accantaniṭṭho` / `dhuvaniṭṭho` / `accantayogakkhemī` / `accantabrahmacārī` / `pariyosāna` / `accantapariyosāno`，以及 1006-20-28 引述的 `antaṃ atikkantaniṭṭho`），**被解释词与父层逐字同译**这条硬约束本轮无法核验，只能作内部自洽性检查。
- 词级格与句法角色无 nissaya 可比对，下列格/修饰关系的判断仅据原文语法，故相关条目的确定性低于常规评估。
建议在父层义注译文可读回时补跑一次本步骤，专项核对黑体词与义注译名是否逐字一致。

**准确性**：主体词源解释句（`-ti ...` 定义链）处理得当：`akuppadhammatāya`→"不可动摇的法性"、`khayavayasaṅkhātaṃ antaṃ atītā`→"超越了被称为灭尽衰亡的终点"、`vusitattā`→"已经圆满成就"、`aparihāyana/avihāyana`→"不会退失"，取义与构词层次（"X 是究竟的 → 所以是究竟 X 者 → 意思是恒常 X 者"）都复现了。主要扣分在 1006-29-37：属格 `paṭividdhassa lokuttaradhammassa` 本应修饰 `dassanaṃ`，译文把它拆成句首状语，使"现见"与所缘脱钩。另有两处收尾句（1006-74-76、1009-6-9）把 `uttānattha + eva` 扩写成"文义浅显，**无须另释**"，语义方向不错但属增译。

**风格**：整体为现代书面汉语，无"此中／故为／彼等／是故"一类硬禁例，达标。残留问题集中在两类：单音节文言虚词"即"（style.md 明列应改"也就是"），以及"无须另释"这种半文半白的注疏套语。1006-6-19 在正文插入"（这完成）"补足主语，虽语义必要，但按 style「不擅自补足省略主语」与「圆括号只用于夹注巴利原词」两条，形式上越界。标点全角、无 ASCII 引号、无工作标记残留，JSON 安全这条没有风险。

**一致性**：`accanta`→"究竟"、`niṭṭhā`→"完成"、`brahmacariya`→"梵行"、`pariyosāna`→"终结" 在六段内稳定。两处不齐：`dhuva` / `nicca` / `satata` 三个近义词被压成"恒常／恒常／持续不断"，`dhuva` 与 `nicca` 同形，原文的区分丢失；以及"恒常**的**完成者"与"究竟完成者／究竟安稳者"构词体例不一。另 `accantayogakkhemī` 的译名脱落了 `yoga`，与紧邻的"四种结缚"解释失去字面挂钩。

## 问题清单

### 🟧 error
- `182-1006-29-37`｜错译（修饰关系）｜片段「因为对于已经通达的出世间法，并不存在所谓现见（dassana）动摇这回事」
  - 问题：`paṭividdhassa lokuttaradhammassa` 是修饰 `dassanaṃ` 的属格（"对已通达的出世间法之现见"），译文将其降为句首状语"对于…出世间法"，并把"现见"孤立成动摇的主体，所缘与现见的修饰关系断开；"这回事"亦偏口语。
  - 建议：改为"因为对于已经通达的出世间法所生起的现见（dassana），并不存在所谓的动摇"。
