## 问题清单

### 🟧 error

- `100-559-75-90`｜错译（修饰关系）｜片段「毒性被制伏、长老证得三种果位」
  - 问题：`visaṃ vikkhambhetvā therassa tiṇṇaṃ phalānaṃ pāpuṇanañca` 中 `vikkhambhetvā` 是从属于 `pāpuṇana` 的连续体，整体为**一**项。原文以 `ca` 并列的是四事（aruṇuggamana / pāpuṇana / pathavipavisana / dhammakathāniṭṭhāpana），译文把"毒性被制伏"拆成独立一项，变成五事并列，破坏了"同一刹那四事齐发"的结构，且丢失了"镇伏毒性→证果"的因果从属。
  - 建议：改为「黎明升起、长老镇伏毒性后证得三种果位、毒从被咬处退下并渗入地里、讲法长老讲完法，这四件事是在同一刻发生的。」

- `100-559-39-48`｜错译（修饰关系）｜片段「咬了他，就像用钳子夹住他的小腿肌肉一样」
  - 问题：`jaṅghapiṇḍimaṃsaṃ` 是 `ḍaṃsi` 的直接宾语（咬的部位），`saṇḍāsena gaṇhanto viya` 才是喻体。译文把真正的宾语挪入喻体，主句只剩"咬了他"，部位信息错位到比喻里，同时"用钳子夹住小腿肌肉"读起来像在描述别人的动作。
  - 建议：改为「这时，有一条毒蛇咬住他小腿的肌肉，像用钳子夹住一样。」

- `100-560-2-23`｜错误多译｜片段「在长水村也有这样的事」
  - 问题：`Dīghavāpi` 是锡兰东南部的地区／水库名（处格 `Dīghavāpiyampi`），原文无"村"；同句另有 `tissamahāgāme`（提舍大村）才是村落，并置之下"长水村"会误导读者以为两者同级。
  - 建议：去掉"村"，作「在长水（Dīghavāpi）也有这样的事」，或按既定地名策略统一音译。

### 🟨 warning

- `100-558-21-29`｜不导致误解的汉语语病｜片段「绕着塔园寺右绕一周」
  - 问题："绕着…右绕"中"绕"字重复，句子冗赘；另 `gantvā` 是"去"，与后半"来到"方向叙述不一致（前句已用"飞来"）。
  - 建议：「尖顶屋飞行在空中，右绕塔园寺一周，来到石塔所在的地方。」

- `100-558-30-40`｜关键词语意不明确｜片段「于是响起了千百声赞叹」
  - 问题：`sādhukārasahassāni` 是复数"数千声善哉"，"千百声"是汉语泛指套语，把确指的数量级译虚了。
  - 建议：「于是响起了数千声赞叹（善哉）。」

- `100-558-80-99`｜关键词语意不明确｜片段「我要依靠有福德的人来获得恭敬」
  - 问题：`labhissāma` 是第一人称**复数**，说话对象是 `āvuso`（随侍弟子），译作"我要…获得"抹掉了人称数；"获得恭敬"搭配生硬，`sakkāra` 此处指国王将献的供养礼敬。
  - 建议：「贤友们，依靠有福德的人，我们也能得到供养。」若判定此处 1pl 为自称谦辞，宜在报告或 `knowledge/known-issues.md` 留案说明取义依据。

- `100-558-118-126`｜整句逻辑表达不规范｜片段「国王以隆重的礼敬办理了遗体的事宜」
  - 问题：`kāretvā` 是使役态（令人办理），译文让国王亲自办理；"以礼敬办理事宜"动宾搭配不自然。
  - 建议：「国王命人以隆重的礼仪举行了荼毗（遗体）仪式，取得舍利后建造了塔。」

- `100-558-127-132`｜关键词语意不明确｜片段「渴望见到持戒的人」
  - 问题：结构歧义——"持戒的人"容易被读成"叫做…的人"的同位语甚至主语，整句可被误读为"持戒的人渴望见到（某人）"。`sīlavantānaṃ` 是 `dassanakāma` 的宾语属格。
  - 建议：「像这样就叫做渴望见到具戒者。」

- `100-559-12-31`｜关键词语意不明确，二意场合没有注释｜片段「大圣种」
  - 问题：`mahā-ariyavaṃsa` 是经／法门专名（圣种法门），光作"大圣种"读者无从理解，且与前面"以四种资具为满足、以修行为乐"的关系看不出是对同一法门的描述；已给出 `(a.ni.4.28)` 出处却无注。
  - 建议：作「《大圣种（Ariyavaṃsa）》——讲四种资具知足、乐于修行的法门」，并补一条脚注。

- `100-560-101-112`｜不导致误解的汉语语病｜片段「明天我们还会再讲」
  - 问题："还""再"语义重复。
  - 建议：「明天我们再讲一遍」。

### 🟦 suggestion

- `100-558-41-64`｜语言风格不统一｜片段「名叫大虎的长老」
  - 问题：同一段落内 `Kuṭṭatissa` 音译（鸠咤提舍），`Mahābyaggha` 却意译为"大虎"，人名策略不一致。
  - 建议：统一为音译并夹注原词，如「摩诃毗耶伽（Mahābyaggha，意为"大虎"）长老」。

- `100-558-65-79`｜代词指代可能不够明确｜片段「他的尖顶屋从空中飞过五由旬的路程来到这里」
  - 问题：原文 `kūṭāgāraṃ … āgataṃ` 无"他的"，属增补；`style.md` 第六节要求不擅自补足成分。
  - 建议：「那座尖顶屋从空中飞过五由旬的路程来到这里」。

- `100-558-80-99`｜语言表达不够流畅｜片段「也从空中飞去」
  - 问题：`ākāseneva āgantvā` 是"径由空中而来"，`eva` 的强调未体现，且"飞去"与随后"进入那座尖顶屋"方向相左。
  - 建议：「径由空中飞到那里，进入那座尖顶屋」。

- `100-559-2-11`｜该使用而没有使用术语标记｜片段「托钵长老」
  - 问题：`piṇḍapātika` 传统汉译多作"常乞食者（头陀支之一）"，"托钵"偏口语且丢失头陀行的意味；首次出现未夹注巴利原词。
  - 建议：首次出现作「常乞食长老（piṇḍapātika）」，其后沿用一个固定译名并登记进 `knowledge/terms.md`。

- `100-559-75-90` / `100-560-113-120`｜不常用术语编写注释｜片段「三种果位」「证得了初果」
  - 问题：两处果位体系未对齐也未加注，读者不知"三种果位"指初果至三果；`sotāpattiphala` 译"初果"虽通行，但与前文表述方式不统一。
  - 建议：前者注「指入流果、一来果、不还果」，后者作「入流果（sotāpatti，即初果）」。

- `100-559-138-150`｜语言表达不够流畅｜片段「我被蛇咬了」
  - 问题：`dīghajātika`（长类／长身者）是蛇的婉称，长老刻意用婉词，与前句"我捉到了一个贼"的诙谐语气相呼应；直译为"蛇"后这层语趣消失。
  - 建议：「如果我当时说被'长身者'咬了」并加注说明是蛇的婉称。

- `100-559-32-38`｜语言表达不够流畅｜片段「从后面来到」
  - 问题：`pacchābhāgena` 指从后方（会场后部）进来，"从后面来到"易被读成"后来才到"。
  - 建议：「从后面走进来，坐在一个隐蔽的地方」。

- `100-560-30-37`｜语言表达不够流畅｜片段「只听清了开头的偈颂和最后的偈颂」
  - 问题：`vavatthapesi` 是"辨明／记住"，译"听清"把问题归到听觉上；实际是疲乏致神思不属、只记住了首尾两偈。
  - 建议：「只记住了开头的一首偈颂和最后的一首偈颂」。

- `100-560-38-61`｜不常用术语编写注释｜片段「世尊说了这番话」
  - 问题：`idamavoca` 是经文／本生结语套语，引号内孤立出现时读者不易看出这是讲法收尾的标志。
  - 建议：加注说明「"世尊说了这番话"是经文结束的固定结语」。
