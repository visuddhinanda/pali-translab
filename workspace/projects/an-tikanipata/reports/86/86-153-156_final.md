## 理由

**数据基准缺失（影响信心）**：本次注入的资源只有巴利原文与 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。按方法文档降级处理，评估只能依据巴利原文本身的词法句法、本经的平行段落（154/155 互为正反对照）及 `knowledge/` 规则。因此"义理或用词与注释书不符"类问题无法核查，`gūthabhāṇī / pupphabhāṇī / madhubhāṇī` 三术语的注释书释义、`nelā`、`porī`、`āmisakiñcikkha` 等词的传统取义都没有标准可比对，信心指数据此压到 62。

**准确性**：整体句义正确，三种人的定义框架、问与答的对应、154 与 155 的肯定/否定镜像关系都译对了。扣分集中在三处：

1. `86-154-129-139` 与 `86-155-77-88` 把 `attahetu vā parahetu vā` 译成"为了自己或别人（的身体、财物）"——括号里的"身体、财物"在巴利原文里**没有对应词**，是注释书的解释内容。原文只有 `attahetu`（为自己的缘故）/ `parahetu`（为他人的缘故）。方法文档规定义注内容进脚注或报告，不得作为夹注混入正文；而 `style.md` 的夹注格式只许括注巴利原词，不许括注释义扩充。无 nissaya/义注在手，这个扩充也无从验证，属无据多译。
2. `86-155-77-88` 的否定范围译错。原文 `iti attahetu vā parahetu vā āmisakiñcikkhahetu vā **na** sampajānamusā bhāsitā hoti`，`na` 只否定 `sampajānamusā bhāsitā hoti`（不说明知的妄语），整句意思是"他不会为了自己、为了他人、或为了一点点财利而明知妄语"。译文把否定拆成两个并列的"不会…也不会…"，读起来像在分别否认两类动机，而原文是一次否定一个行为（在任何这些动机下都不妄语）。属"导致误解的表达"。
3. `86-155-31-76` 漏译 `pajānāsi` 与 `jānāsi` 的差别。154 作 `yaṃ jānāsi`，155 作 `yaṃ pajānāsi`，译文两处都作"你知道什么"。这一差别可能只是传本异读（也可能注释书有说明），但译文未作区分、也未在 confidence 上体现。鉴于无义注可查，按 suggestion 而非 error 计。

另：`86-154-35-65` 把异读 `[sabhāgato vā parisāgato vā (syā. kaṃ.)]` 整块照搬进译文正文，`86-154-77-128` 把 `[ma. ni. 1.440; pu. pa. 91]` 译成"［参见 ma. ni. 1.440；pu. pa. 91］"。这类版本记号与互见出处属原文校勘层，混在译文正文里对读者是噪音，且两处处理方式还不一致（一处原样搬、一处加了"参见"）——应统一移出正文或一律作注。又，`sabhaggato vā parisaggato vā` 译作"议事堂、或村里的集会"，"村里的"在原文无据（`parisā` 只是"会众、集会"），是小幅无据增译。

**风格**：现代书面汉语达标，未见文言虚词与文言句式，`86-156-26-40` 一串四字结构（"悦耳动听、让人喜爱、直入人心、文雅得体"）是汉语并列习惯，不算文言腔。标点全角、无 ASCII 引号、无工作残留标记。扣分只在校勘记号入正文带来的观感。

**一致性**：154 与 155 的共用句式（`Idha, bhikkhave, ekacco puggalo sabhaggato vā…`）两处译文完全一致，这点做得好；`Ayaṃ vuccati… puggalo X-bhāṇī` 三处统一为"这样的人就叫做X语者"，也一致。扣分在校勘记号处理方式不统一，以及 `jānāsi/pajānāsi` 未作区分。

## 问题清单

### 🟧 error
- `86-154-129-139`｜错误多译｜片段「为了自己或别人（的身体、财物）」
  - 问题：`attahetu vā parahetu vā` 只是"为了自己的缘故、为了他人的缘故"，"身体、财物"在巴利原文中无任何对应词，属注释书的释义内容。`style.md` 规定圆括号夹注只用于首次出现的巴利原词，不得用于塞入释义扩充；且本次无义注在手，该扩充亦无从验证。
  - 建议：正文回到原文范围（为了自己、或为了他人），释义扩充若确需保留，移入脚注并注明出自义注。

- `86-155-77-88`｜错误多译｜片段「为了自己或别人（的身体、财物）」
  - 问题：同上，与 `86-154-129-139` 同一问题，须一并处理以保持平行句一致。
  - 建议：同上。

- `86-155-77-88`｜导致误解的表达｜片段「他不会为了自己或别人（的身体、财物），也不会为了一点点贿赂，明知而说谎」
  - 问题：原文 `na` 否定的是 `sampajānamusā bhāsitā hoti` 这一个行为，`attahetu / parahetu / āmisakiñcikkhahetu` 三个动机是并列的状语，整句为"不论为己、为人、还是为一点财利，他都不说明知的妄语"。译文拆成"不会…也不会…"两段否定，读来像在分别否认两类动机，容易被理解为对动机本身的否认而非对妄语行为的否认。
  - 建议：改为单一否定、三动机并列的结构，如"就这样，他不会为了自己、为了他人、或为了一点财利而明知故妄语"。

### 🟨 warning
- `86-154-35-65`｜不该出现的校勘记号入正文｜片段「［sabhāgato vā parisāgato vā（syā. kaṃ.）］」
  - 问题：这是缅甸/暹罗传本异读的校勘记号，属原文校勘层，不是译文内容。整块拉丁字母夹在中文句子里，对目标读者（混合受众）是纯噪音，且该异读与所采读义同（`sabhaggato`≈`sabhāgato`），不影响汉译。
  - 建议：从正文移除，若需保留则作脚注说明"此处暹罗本、缅甸本作 sabhāgato vā parisāgato vā"。

- `86-154-77-128`｜不该出现的校勘记号入正文｜片段「［参见 ma. ni. 1.440；pu. pa. 91］」
  - 问题：互见出处记号（《中部》1.440、《人施设论》91）属编辑层信息，混入译文正文；且与上一条的处理方式不一致——一处原样照搬、一处加了"参见"二字。
  - 建议：与上一条统一，一律移出正文作脚注；保留的话出处名也应译出（《中部》《人施设论》）而非留拉丁缩写。

- `86-154-35-65`｜错译（无据增译）｜片段「或村里的集会」
  - 问题：`parisaggato` 的 `parisā` 指"会众、集会、随从群"，并无"村"的意思。"村里的"是无据添加，且与前面的"议事堂"形成一种原文没有的城/乡对照。
  - 建议：改为"或在集会当中"之类不添地点限定的译法；`sabhā` 与 `parisā` 的具体所指若有义注说明，取义注。

- `86-154-129-139`｜关键词语意不明确｜片段「为了一点点贿赂」
  - 问题：`āmisakiñcikkha` 字面为"些许财物/物质利益"，"贿赂"把它窄化为行贿受贿这一种情形，而证人作伪证的动机也可能是普通的财物好处。此处属二意场合而无注释。
  - 建议：改为"为了一点财物上的好处"一类较中性的译法，或保留"贿赂"但加注说明原词字面义。该词的传统取义需以义注核定。

### 🟦 suggestion
- `86-155-31-76`｜语言风格不统一｜片段「你知道什么就说什么」
  - 问题：154 原文作 `yaṃ jānāsi`，155 作 `yaṃ pajānāsi`（带 `pa-` 前缀，语气略强），译文两处完全相同，差别消失。这可能只是传本异读，但译文既未区分也未在该句 `confidence` 上反映。
  - 建议：确认是否为异读；若义注有说明则据以区分（如"你清楚知道什么"），否则维持同译并压低该句 confidence、在报告中记存疑。

- `86-156-26-40`｜该使用而没有使用术语标记｜片段「文雅得体」
  - 问题：`porī` 是个不常用的词（字面与"城市/都市的"相关，引申为"有教养的、文雅的"），`nelā`（无过失、无瑕）亦然。按 `style.md`，罕见或有争议的术语首次出现宜夹注巴利原词。
  - 建议：首次出现处夹注，如"文雅得体（porī）"、"没有过失（nelā）"，具体取义以义注为准。

- `86-154-21-26`｜不常用术语缺注释｜片段「粪语者、花语者、蜜语者」
  - 问题：三个名目是本经经名与全经骨架，直译保留了巴利喻象（好），但对一般读者"粪语/花语/蜜语"的喻意不明——尤其"花语"在现代汉语里已有"花卉象征意义"的固定用法，易生误读。
  - 建议：首次出现处夹注巴利原词并加一句简注说明喻意（粪=污秽的妄语、花=如实不妄、蜜=柔软悦耳），注释内容取自义注。
