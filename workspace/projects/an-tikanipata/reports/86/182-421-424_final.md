## 理由

**资源缺失（影响信心）**：本次只注入了巴利原文与 channel 译文，**义注（本层父层，即 Manorathapūraṇī 对 AN 3.25 的注释）与 nissaya 均未提供**。本段是复注（ṭīkā），全段 15 句中有 11 句是「**被解释词**ti 释义」结构，被解释词逐字引自义注——「逐字同译」这条硬约束**无法核对**，只能以本段内部的一致性与巴利语法做判断。因此下列对**被解释词译法**的意见（422-14-23、422-60-64、422-70-78、423-10-20、423-21-25）均为待核项：若义注层已另有定译，应以义注为准回头统稿。扣分也主要落在「可内部自证」的问题上。

**准确性**：整体取义可靠，复注特有的三类内容——字母连声说明（ka-kāro / tākāro padasandhikaro）、异读（Duṭṭhārutā）、以及 423-26-58 关于「下三道所断烦恼虽已断、仍说其智如电」的辨析——都读懂了，长难句 423-26-58 的双重让步结构（kiñcāpi…tathāpi…na…ti daṭṭhabbaṃ）逻辑完整，末句的否定项（不是因为「已断的烦恼还在」）没有译反，这是本段最容易译错的地方。扣分有两处：422-34-55 把 `kodhāsaṅga` 读成「对愤怒的执着」（属格关系误读，应是「愤怒这种黏着」），且同句末尾的并列项 `taṇhāsaṅga` 却译对为「贪爱的缠缚」，自相矛盾；423-21-25 把属格对释 `Caṇḍikatassā"ti kupitassa` 译成「副词 + 完整小句」，格与词性都丢了。

**风格**：现代书面汉语达标，**未发现文言/半文半白用例**（无「此中/是故/彼等/于…之际」类），全角标点、弯引号、夹注圆括号均合规，译文内无 ASCII 引号、无残留工作标记，JSON 安全。扣分来自：「弄成」口语化；多处对原文无依据的增补（「随后」「脓血等」）；423-26-58 单句 90 余字且含破折号插入，对读者不友好；「（即阿罗汉道）」是汉语解释性插注，按体例应入脚注而非正文。

**一致性**：主要问题是「疮」这一核心意象的译名在段内漂移——422-2-13「疮 / 陈旧的、溃烂的疮」→ 422-14-23「心像疮一样 / 心像**旧**疮一样的」→ 422-70-78 与 423-2-5「久不愈合的旧疮」，同一个 `aru / duṭṭhāruka / duṭṭhavaṇa` 词族出现三套措辞；其中「久不愈合」是译者添加的语义。另两处是被解释词与其释义在同句内不对应（422-60-64、423-21-25）。首尾篇题「金刚喻经注释」421 与 424 一致，良好。

## 问题清单

### 🟧 error
- `182-422-34-55`｜错译（修饰关系）｜片段「因为对愤怒的执着」
  - 问题：`kodhāsaṅgavasena` 是「以愤怒这种黏着之故」（kodha 即 āsaṅga 本身），不是「对愤怒的执着」（把愤怒读成了执着的对象）。同句末尾的并列项 `na taṇhāsaṅgavasena` 译作「而不是因为贪爱的缠缚」，取的正是正确读法，两处自相矛盾。
  - 建议：改为「由于愤怒这种黏着」或「因愤怒的黏缠」，与句末「贪爱的缠缚」在构词上对齐（如「愤怒的缠缚／贪爱的缠缚」）。
- `182-423-21-25`｜错译（词义/格与句法角色）｜片段「**凶暴地**，是说他已经发了怒」
  - 问题：`caṇḍikatassa` 与释语 `kupitassa` 同为属格过去分词，是「变得凶暴的（人）的」＝「发了怒的（人）的」。译文把被解释词处理成副词「凶暴地」，又把释语扩成完整小句「他已经发了怒」，格与词性双丢，且被解释词与释义在形式上不对应（全段其余句都守住了「X，是指 Y」的对释格式）。
  - 建议：按对释格式改为「**变得凶暴的**，是指发了怒的」；最终措辞须与义注中该词的译法逐字一致。

### 🟨 warning
- `182-422-70-78`｜关键词译名不一致（含增译）｜片段「**久不愈合的旧疮**」
  - 问题：`duṭṭhāruka` 中无「久不愈合」之义（duṭṭha ＝ 腐坏/溃烂），此为添加；且与 422-2-13 已立的「陈旧的、溃烂的疮」及同句释义「溃烂的疮」三套措辞并存。423-2-5 沿用了这一译法，漂移会扩散。
  - 建议：统一为「溃烂的旧疮」一套，段内（422-2-13 / 422-14-23 / 422-70-78 / 423-2-5）全部对齐，并与义注对 `duṭṭhāruka` 的译法一致。
- `182-422-14-23`｜不导致误解的汉语语病（兼译名不一致）｜片段「所以叫做**心像旧疮一样的**」
  - 问题：「心像旧疮一样的」以「的」收尾悬空，不成名词，无法承接「叫做」；`arukūpamacitto` 是指人的复合词。另外同句前半已译「他的心像疮一样」，被解释词却多出一个「旧」。
  - 建议：改为「所以叫做**心如疮者**」一类名词形式，并与前半句的「疮」保持同词；定译须与义注层核对。
- `182-422-70-78`｜不导致误解的汉语语病（标点）｜片段「失去了本来的状态、一直如此的溃烂的疮」
  - 问题：顿号连接了动词短语「失去了本来的状态」与定语「一直如此的」，层次不清；「一直如此的…的疮」三重「的」叠加。
  - 建议：改为「是指因血肉腐坏而失去本来状态、始终停留在这种状态的溃烂的疮」，或拆为两句。
- `182-422-34-55`｜关键修饰成分归属不明确｜片段「背后也用“你说什么”之类的话怀恨不舍（upanāha）地黏着」
  - 问题：`"kiṃ vadasī"tiādinā` 被整个挂到「背后」一侧，但「你说什么」是当面顶撞的话语，更可能属 `sammukhā`（当面），而 `parammukhā` 一侧对应的是 `upanayhanavasena`（怀恨）。原文逗号位置本身有歧义，译文选了较不自然的一读且未留出余地。
  - 建议：改为「当面以“你说什么”之类的话黏着，背后则怀恨不舍地黏着」；若义注另有断读，依义注，并把分歧记入报告。
- `182-422-34-55`｜夹注词形与原文不符｜片段「怀恨不舍（upanāha）」
  - 问题：原文此处作 `upanayhana`（动名词），夹注写成了 `upanāha`。按体例夹注应附原文词形。
  - 建议：改为「（upanayhana）」，或若要用术语标准形则在脚注说明二者关系。
- `182-423-26-58`｜用词不合书面语体｜片段「已被那些道弄成不会再生起的状态」
  - 问题：「弄成」口语化，与 `anuppattidhammataṃ āpāditattā`（令其成就「不生之法性」）的论义语体不配。
  - 建议：改为「已被那些道引至不再生起的状态」或「已使之成为不会再生起的」。

### 🟦 suggestion
- `182-422-60-64`｜该使用而未使用对应译法（被解释词与释义不对应）｜片段「**失去常态而心怀恶意**」
  - 问题：`byāpajjati` 的被解释词译得过长，且与释义「心已经败坏」（vipannacitto hoti）不对应——释义讲「心坏」，被解释词却多出「失去常态」与「心怀恶意」两层。
  - 建议：收短为「**心变坏**」或「**心怀恶意**」择一，与义注逐字同译后再定；释义可保留「是说他的心已经败坏」。
- `182-422-28-33`｜语言表达不够流畅（增补）｜片段「是说因为随后就没有了智慧的光明」
  - 问题：「随后」原文（`ñāṇobhāsavirahena`）无对应成分，是译者补出的时间关系。
  - 建议：改为「是说因为缺少智慧的光明，所以照亮的时间只有极短一瞬」。
- `182-423-6-9`｜语言表达不够流畅（增补）｜片段「脓血等不干净的东西」
  - 问题：`asuci`（不净）未指明为脓血，「脓血等」是推补。
  - 建议：改为「不干净的东西渗流出来」，需要具体化时放脚注。
- `182-423-10-20`｜语言表达不够流畅（属格未译出）｜片段「**像肿胀起来一样**」
  - 问题：`uddhumātassa viya` 是属格「像肿胀者的……一样」，译文未体现所属对象；需对照义注原句看被比的是什么（面相/身相）。
  - 建议：核对义注后补出「像肿胀者的……一样」。
- `182-423-26-58`｜复杂嵌套句整句理解困难｜片段「基于这一点，才说那几种智像闪电一样」
  - 问题：全句 90 余字，含「虽然…但…所以…——基于这一点…而不是…应当这样理解」多重嵌套，又插入破折号，读者不易跟住；「（即阿罗汉道）」是汉语解释性插注，按体例宜作脚注而非正文夹注。
  - 建议：在「——」处断为两句（「……才说那几种智像闪电一样。」／「这并不是说那些道已经断除的烦恼还存在；应当这样理解。」），并把「即阿罗汉道」移入脚注。
- `182-422-56-59`｜语言风格不统一｜片段「**发怒**，就是动怒」
  - 问题：被解释词与释语几近同义，复注在此作的区分（`kuppati` 起怒／`kujjhati` 忿恚）未体现，读者看不出释义做了什么。
  - 建议：如「**动怒**，就是心生忿恚」，使二者有可辨差别；并与 423-21-25 的「发怒」用词统一。
- `182-422-65-69`｜格式｜片段「**陷入僵硬的状态**」
  - 问题：原文是两个独立加粗段 `**Thaddhabhāvaṃ** **āpajjati**`，译文合并为单个加粗短语。若上游按词段标注加粗，建议保留两段结构。
  - 建议：视 channel 对加粗粒度的要求决定是否拆回；语义本身无误。
