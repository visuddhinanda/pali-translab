# Review — 86:753-762（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，按要求略过）

## 跨段一致性
- **visākhe**：§753 译「维萨卡」，§754–756 译「毗舍佉」 → **必改**，全 chunk 统一为「毗舍佉」（传统汉译，§754 起占多数）。
- **upakkamena**：§753 译「靠人为的办法」，§754–755 译「通过下功夫」 → 统一为一种。nissaya 在 §754 补出的 vāyāma 内容是放进炉里、吹火、用钳子翻动，属于「下功夫」，建议统一为「通过下功夫」。
- **devatā / tā devatā**：§753 译「诸天」「那些天」，§755 译「那些诸天」 → 统一为「那些天」。「那些诸天」里「诸」与「那些」重复。
- **devā（列举句）**：§753 译「四大王天的诸天」，§755 译「四大王天的天众」 → 统一为「…的诸天」。
- **devā tatuttari**：§753 译「还有比这些更高的诸天」，§755 译「有更上面的诸天」 → 统一。nissaya：`တတော= ထိုပဌမဈာန်ဘုံသားဗြဟ္မာတို့မှ` `ဥတ္တရိ= အထက်ပရိတ္တာဘာ စသည်`，意思是「比梵众天更高的（少光天等）」。建议统一为「还有比梵众天更高的诸天」。
- **ito cutā tatthupapannā**：§753 译「从这里死去后生到那里」，§755 译「从这里（人间）死去后往生到那里」 → 统一。nissaya：`ဣတော= ဤလူ့ဘဝမှ`（从这人间生命），`တတ္ထ= ထိုနတ်ဗြဟ္မာ အပေါင်း၌`（在那天众中）。建议统一为「从人间死去后，生到那些天当中」，不用括注。
- **saṃvijjati / tathārūpa**：§753 译「我也同样具有那样的…」，§755 译「我也同样具备这样的…」 → 统一为「我也具有那样的…」。tathārūpa 与 yathārūpa 呼应，用「那样」；「同样」与「那样」重复，可删。
- **pasīdati / pāmojjaṃ / pahīyanti**：§753 译「澄净下来／欢悦生起／被舍断了」，§755 译「澄净／喜悦生起／断除了」 → 统一，建议用「澄净／喜悦生起／被断除」。
- **施舍和慧 / 施舍与慧**（§753 vs §755）→ 统一连词。
- **ṭhāna**：§760 译「导致放逸的事」（pamādaṭṭhāna），§762 译「导致放纵的事」（复合词里没有 pamāda） → §762 不应添「放纵」，见下。
- **§760 句 86-760-11-20**（无 nissaya）与 86-760-2-10 措辞相同。下面对 majja 的修改要同步改到这一句。
- **§762 句 86-762-9-17**（无 nissaya）与 86-762-2-8 措辞相同。下面的修改要同步改到这一句。
- **「终其一生」**（§756–762 每段首句）、**「以利益之心」**（§756 两句）：文言虚词「其」「之」在多段反复出现 → 全 chunk 统一改为现代汉语，见下。

## §753 句 86-753-85-107
- **问题**：句法 — 「那些天具备了怎样的信，从这里死去后生到那里」，读起来像在问那些天具备什么信。nissaya 的结构是「具足**那样**的信（`ယထာ ရူပါယ= အကြင်သို့ သဘောရှိသော` 关系形容词）的那些天，从此人间死去，生在那天众中」。nissaya 还补出 tathārūpā 的含义：`(ထိုနတ်ဗြဟ္မာ အပေါင်း၌ ဖြစ်စေနိုင်ခြင်း သဘောရှိသော)`，即「能使人生到那里的那种」信。
- **建议**：「那些天具足了某种信，因而从人间死去后生到那里；我也具有那样的信。」或「那些天具足怎样的信而从人间死去、生到那里，我也具有那样的信。」戒、闻、施舍、慧四句（86-753-108-122 至 151-167）与 §755 的对应句同步修改。

## §753 句 86-753-168-200
- **问题**：格 — `တဿ=ထိုအရိယ သာဝက၏` 是属格，同时统领 anussarato 与 cittaṃ，即「**他的**心澄净」。译文只译了「心就澄净下来」，没有译出所属。
- **建议**：「当他随念……时，他的心就澄净了」。

## §754 句 86-754-15-43
- **问题**：词义 — `ဥက္ကဉ္စ= မီးဖိုကိုလည်း`，nissaya 的附注明确说这是**金匠的熔炉**（ကမ္မာရုဒ္ဓန），不是坩埚。「炉灶」会让读者理解成厨房灶台。
- **建议**：改为「熔炉」或「金匠的炉子」。

## §755 句 86-755-104-132
- **问题 1**：句法 — `(အဿ= ထိုအရိယသာဝက၏) စိတ္တံ … ဒေဝတာ= နတ်ဗြဟ္မာတို့ကို။ အာရဗ္ဘ= ၍`，意思是「他的心以诸天为对象而澄净」。ārabbha 的意思是「缘于、以…为所缘」，译文作「由于随念诸天」，添加了「随念」，并改成了因果关系。
- **建议 1**：「他的心缘于诸天而澄净」。
- **问题 2**：体例 — 括注「以诸天为见证而随念自身功德的布萨」是 nissaya 的**异释**（`ဝါ= နတ်ဗြဟ္မာတို့ကို သက်သေအရာ၌ထား၍…`）。按 style.md，异释应作脚注备列，不放进正文括注。
- **建议 2**：正文只保留「天布萨（devatuposatha）」，异释移到脚注。

## §756 句 86-756-14-27
- **问题 1**：文言（必改） — 「终其一生」含文言虚词「其」，「以利益之心」含「之」。
- **建议 1**：「诸位阿罗汉一辈子都……」；「怀着利益一切众生的心，怜悯一切有生命的众生」。
- **问题 2**：词义 — `လဇ္ဇိ= မကောင်းမှုမှ ရှက်ကုန်လျက်` 是「以恶为耻」，括注「（厌恶恶行）」把羞耻说成了厌恶，不对。
- **建议 2**：删去括注，或改为「（以作恶为耻）」。
- **问题 3**：词义 — `နိဟိတသတ္ထာ= ချထားအပ်သော အခြားလက်နက်ရှိကုန်လျက်` 是「放下了（棍杖以外的）其他武器」。括注「一切能伤害众生的器具」是自行添加的。
- **建议 3**：改为「放下了刀剑等兵器」，删去括注。

## §756 句 86-756-28-44
- **问题**：文言（必改） — 「以利益之心」。另外，`ဣမဉ္စ ရတ္တိံ` 的异释是 `ဤညဉ့်ပတ်လုံး`（整夜），表示持续一整段时间。
- **建议**：「我今天也在这整夜和整天里……怀着利益一切众生的心，怜悯一切有生命的众生而安住」。

## §756 句 86-756-45-69（§757–762 的同一句叠句一并修改）
- **问题**：格 — `မေ= ငါသည်` 是施事主格（被动句 upavuttho bhavissati 的行为者），不是属格「我的」。nissaya 还补出 `(ဧဝံကရောန္တေန)`「这样做的（我）」，而且 bhavissati 表示将来。译文「我的布萨也就守持成了」把施事误读成了属格。
- **建议**：「这样做，我也就守持了布萨」或「这样，布萨也就由我守持了」。

## §757 句 86-757-2-17
- **问题**：句法 — `အထေနေန … သုစိဘူတေန … အတ္တနာ= အတ္တဘောဖြင့်` 是具格，意思是「以不偷盗、清净的自身」而住。nissaya 补出 `(အထေနတ္တာ)`，说明清净的原因是不偷盗。译文「使自己成为…的人」添加了原文没有的使役义。另外「终其一生」须按文言必改项处理。
- **建议**：「自身不偷盗，因而清净地安住」。§757 句 86-757-18-35 同步修改。

## §758 句 86-758-2-20
- **问题 1**：词义 — `အဗြဟ္မစရိယံ= မမြင့်မြတ်သော မေထုန်အကျင့်ကို`，指不高尚的**淫行**。括注「即不高尚的行为」太泛，失去了所指。
- **建议 1**：括注改为「（abrahmacariya，指淫行）」或删去括注。
- **问题 2**：词义 — `မေထုနာ= မေထုန်အကျင့်မှ`，异释为 `ရာဂထလာ… အဖို့အမတို့၏…အကျင့်`（男女交合的行为），指的是行为。「淫欲」是欲望，不是行为。括注「义注所说的非正法」把注释层的说法放进了正文，属于层次混淆。
- **建议 2**：「远离淫行这种村民的行为」，删去括注。
- **问题 3**：`အာရာစာရီ= မေထုန်မှ ဝေးစွာ ကျင့်` 是「远远避开淫行而生活」。译文「远离非梵行而生活」与前文的「舍弃非梵行」重复，没有译出「远远」这层意思。
- **建议 3**：改为「远远避开淫行而生活」。
- **问题 4**：「终其一生」须按文言必改项处理。§758 句 86-758-21-34 同步修改问题 2、3。

## §760 句 86-760-2-10
- **问题**：句法 — nissaya 拆解为 `ပိဝန္တံ မဒယတီတိ မဇ္ဇံ`（令饮者迷醉的）修饰 `သုရာ, မေရယ`。majja 是 surā、meraya 的修饰语，不是并列的第三种东西。另外 ṭhāna 按 nissaya 是「饮用的思（cetanā），即放逸的根源」。译文「谷酒、果酒、醉品」把复合词拆成了三项并列。「终其一生」也须按文言必改项处理。
- **建议**：「舍弃饮用令人迷醉的谷酒、果酒（这是放逸的根源），远离……」。86-760-11-20 同步修改。

## §761 句 86-761-2-10
- **问题**：词义（必改） — nissaya 附注：`တနေ့၌ တကြိမ်သာ (တထပ်သာ) ဘုဉ်းပေးတော်မူကြသော`，即「一天只吃一次」，进食时段由 rattūparata、vikālabhojana 两句来限定。括注「不论次数」与 nissaya 相反。括注里的「依义注」也把注释来源写进了正文。另外 `ဝိကာလဘောဇနာ= နေမွန်းလွဲချန် စားခြင်းမှ`，指过午进食。「终其一生」也须按文言必改项处理。
- **建议**：括注改为「（ekabhattika，一天只吃一餐）」或删去；「远离过午进食」，或保留「非时进食」并在首次出现时注明「过午」。

## §762 句 86-762-2-8
- **问题 1**：词义 — 按 nissaya，nacca、gīta、vādita 包括自己歌舞奏乐和叫别人歌舞奏乐。visūkadassana 是「观看、聆听那些如芒刺般违逆佛陀教法的（歌舞表演）」（`ဆူးငြောင့် တံကျင် သဖွယ်ဖြစ်သော ကြည့်ရှုနားထောင်ခြင်း`），包含聆听。「有碍修行」把「违逆教法」说弱了。
- **建议 1**：「观看、聆听如芒刺般违逆教法的表演」。
- **问题 2**：句法 — nissaya 的搭配是：mālā 配 dhāraṇa（戴花鬘）；gandha、vilepana 配 maṇḍana（用香和香膏填补肤面低洼处）与 vibhūsana（涂抹美化）。译文「佩戴花与香」把 gandha 错配给了 dhāraṇa，「涂敷脂粉」也不准确，vilepana 是香膏。
- **建议 2**：「戴花鬘，用香料和香膏装扮、美化自己」。
- **问题 3**：ṭhāna 按 nissaya 是「这些事的根源（思）」，复合词里没有 pamāda，「导致放纵」是添加的。
- **建议 3**：改为「……这些事」或「这类事的根由」。另外「终其一生」须按文言必改项处理。86-762-9-17 同步修改问题 1–3。
