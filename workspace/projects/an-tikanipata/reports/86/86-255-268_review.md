# Review — 86:255-268（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **samanuyuñjati / samanugāhati / samanubhāsati**：§257、§261 译“提出质询／要他确认自己的说法／追问他的理由”；§264 译“追问、质询、责问”；§268 译“查问他、要他核实自己的说法、追问缘由”。建议统一为 §257 的译法。§264 的“追问”对应 samanuyuñjati，§257 的“追问”对应 samanubhāsati，同一个汉语词指了不同的巴利词，必改。依据：nissaya 三词释义分别为 `အဖြေပေးအောင် စစ်ဆေးမေးမြန်း`（为让他作答而审问）／`အယူအဆကို မပြောင်းမလဲ တည်မြဲစေကာ နှိုက်ယူမေးမြန်း`（让他立场不变，再逐层追问）／`အကြောင်းယုတ္တိ အမှန်သဘောပေါ်လာအောင် မေးမြန်း`（为让理由显明而问）。
- **devadūta 的量词**：§257、§261 用“第一个／第二个天使”，§264、§268 用“第三位天使”。建议统一为“个”。
- **Tamenaṃ … yamo rājā evamāha**：§258、§259、§260、§262、§263 译“于是阎摩王对他这样说”；§265、§266、§267 译“接着，阎摩王就对他这样说”。建议统一为前者。
- **So evamāha**：除 §261-86-88 译“他这样回答——”外，其余都译“他这样回答说——”。建议统一为“他这样回答说”。
- **‘… bhante’ 答句语序**：§257、§258、§259、§261、§262 是“尊者，我没有看见／我看见了／我做不到／我放逸了”；§264、§265、§266 改成“我没有看见，尊者”“我看见了，尊者”“我做不到，尊者”“我放逸了，尊者”。建议统一为“尊者”在前。
- **tassa te viññussa sato mahallakassa … anatīto … kāyena vācāya manasā**：§259、§262 译“你是个明白事理、又已上了年纪的人……我也是以老／病为本性的，逃不过衰老／疾病，那我就用身体、用言语、用心去做善事吗”。§266 改成“你既然有理解力，又已经年长……我自己也是会死的，没有超越死亡，那么我还是用身体、言语和心意来做善事吧”。这三段句式完全平行，§266 应照 §259 的格式改为“我也是以死为本性的，逃不过死亡，那我就用身体、用言语、用心去做善事吗”。manasā 在全 chunk 都译“心”，§266 的“心意”应改回“心”。
- **mittāmacca**：§260、§263 译“朋友僚属”，§267 译“朋友同伴”。依 nissaya（`အမစ္စာ= ထိုထိုကိစ္စ၌ အတူတကွ ဖြစ်ဖက် သူငယ်ချင်း`，意为在各种事务上共事的伙伴），amacca 在这里不是官员。建议统一为“朋友同伴”。
- **ñātisālohita**：§260、§263 译“亲属血缘”，§267 译“亲属血亲”。“血缘”是抽象名词，不能作“做”的施事者。建议统一为“亲属血亲”。nissaya：`ဆွေမျိုး သွေးသားတော်စပ်သူတို့သည်`（有血缘关系的亲属们〔主格〕）。
- **samaṇabrāhmaṇa**：§267 加了夹注“（samaṇabrāhmaṇa）”，§260、§263 没有。samaṇa 早已在 §256 出现过，按规则不再夹注。建议删去 §267 的夹注。
- **Taṃ kho pana te etaṃ pāpakammaṃ**：§260、§263 译“你这个恶业”，§267 译“而你的这件恶业”。建议统一为“你这个恶业”。

## §256 句 86-256-68-83
- **问题**：词义取舍。nissaya 对 amatteyyo / apetteyyo / asāmañño / abrahmañño 的主释是“不为母亲／父亲／沙门／婆罗门谋利益（不尽本分）”，`ဝါ=` 异释才是“冒犯、伤害”。译文“行为不端”两头都不贴，而且偏离了主释。
- **建议**：改为“不孝顺母亲，不孝顺父亲，不敬奉沙门，不敬奉婆罗门”，或“不尽对母亲……的本分”。

## §258 句 86-258-12-93
- **问题**：句法误读。nissaya 把 jātiyā 释为 `အမိဝမ်းမှ မွေးဖွားချိန်မှ စ၍`（从出生时算起），修饰 āsītikaṃ / nāvutikaṃ / vassasatikaṃ，表示岁数从出生起算。译文“年岁上已经衰老”把 jātiyā 挂到了 jiṇṇaṃ 上。
- **建议**：改为“出生以来已有八十岁、九十岁或一百岁，衰老不堪，像屋椽一样弯曲……”。
- **问题**：风格。“为衰老所苦”用的是文言被动句式“为…所”。āturaṃ 的 nissaya 释义是 `အိုမင်းမစွမ်း ပင်ပန်းနွယ်းနယ်` （衰老无力、疲惫不堪）。
- **建议**：改为“衰老无力”或“被衰老折磨”。
- **问题**：用词。bhoggaṃ 的 nissaya 释义是 `အလွန်ခါးကုန်းနေသော`（腰背极度佝偻，像被折断一样）。“身体折屈”不像现代汉语的说法。
- **建议**：改为“腰背佝偻”。

## §259 句 86-259-46-50（§262-42-46、§266-42-46 同）
- **问题**：时态。nissaya：`နာသက္ခိဿံ= ကုသိုလ်ပြုရန် မစွမ်းနိုင်ခဲ့ပါ`（当时没能去做善事），说的是过去。译文“我做不到”读起来像现在的能力判断。
- **建议**：改为“尊者，我没能做到”，三处一起改。

## §260 句 86-260-44-69（§263-24-35、§267-23-34 同）
- **问题**：句法误读，必改。nissaya：`ပမတ္တံ= မေ့လျော့သူကို`（对放逸的人〔宾格〕），`ကရောန္တိ ယထာ`（就像〔人们〕对其施以惩罚那样），`တထာ … တွံ= သင့်ကို … ကရိဿန္တိ`（同样也会对你施以惩罚），并注明 `[ယထာ တံ၌ တံကား အနက်မရှိ]`（yathā taṃ 中的 taṃ 无实义）。所以 pamattaṃ 泛指“放逸的人”，句意是“他们会像对待放逸的人那样对待你”。译文“照你放逸的样子处置你”把比较对象错成了“你自己的放逸”。
- **建议**：改为“喂，你这个人，他们确实会像对待放逸的人那样对待你”，三处同改。“喂”的取舍和本段其他 ambho purisa 保持一致。

## §260 句 86-260-132-145
- **问题**：nissaya 疑似讹误（记录，不涉及译文）。`ဧတဿ= ဤကောင်းမှုကံ၏`（这个善业的）与上下文矛盾，应是 `မကောင်းမှုကံ`（恶业）。译文作“它的果报”，没有问题。

## §268 句 86-268-29-33 / 34-39 / 40-44 / 45-50
- **问题**：隐含成分（仅供参考）。nissaya 把 hatthe 补为 `ယာဘက်လက်`（右手），dutiyasmiṃ hatthe 补为 `ဝဲဘက်လက်`（左手），pāde 补为 `ယာဘက်ခြေ`（右脚）。译文“一只手／另一只手”与原文字面一致。原文本身没有明说左右，按 style.md“不擅自补足”的规则可以不补。
- **建议**：维持现译。

## §268 句 86-268-57-83
- **问题**：漏译。原文有 dukkhā / tibbā / kharā / kaṭukā 四个形容词修饰 vedanā。nissaya 分别释为 `သည်းခံနိုင်ခဲ`（难以忍受）、`ထူထပ်`（浓重、剧烈）、`ကြမ်းတမ်း`（粗猛）、`ထက်မြက်စူးရှ ／ ခါးစပ်သော အရသာနှင့် တူ`（尖锐刺痛，像辛辣的滋味）。译文“剧烈、粗粝、难忍的苦受”只有三项，kaṭukā 漏了。另外“粗粝”通常形容质地，用来形容感受不贴切。
- **建议**：改为“他在那里感受着难以忍受、剧烈、粗猛、刺痛的苦受”。
