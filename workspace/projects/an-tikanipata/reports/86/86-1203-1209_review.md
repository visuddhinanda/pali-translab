# Review — 86:1203-1209（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 跨段一致性

- **vaṇṇa**：§1205 马作「毛色」，§1206-1209 人作「外貌」 → 本经是严格平行的比喻（三德名目在马、人两层逐字复用），译成两个无关的词，父子对应关系断裂；且与义注释义相悖（见必改项 1）。建议两层统一为「容色」（马：毛色不好 → 容色不佳；人：容色不足）。
- **ārohapariṇāha**：§1205 马作「身材（高大壮硕）」，§1206-1209 人作「体格（高大壮硕）」 → 同一词两译，同上，建议统一为「体格」或「身量」。
- **java**：马、人两层都作「速度」，一致 ✅；但人层需加义注依据的脚注（见建议项 1）。
- **khaḷuṅka**：§1203 题名「劣马经」、马「劣马」、人「劣人」，内部一致 ✅，但整体选词与义注不合（见必改项 2）。
- **套语**：「这里有一种／又有一种／还有一种」、「我说这就是他的…」、「如实地了知」在 §1205-1209 各段完全一致 ✅。
- **abhidhamma / abhivinaya**：§1207 首次出现夹注巴利原词、其后不再夹注，符合 style ✅；但「增上法」与 `term-glossary.jsonl` 登记的 `abhidhamma→论（阿毗达摩）` 不一致，需定案后补进 `terms.md`（见存疑项 1）。

## 必改项

### 1. §1206-1209 全段（vaṇṇa 组）：人层三德被实译成肉身属性，与义注释义相悖

- **问题**：义注释义 — **义注**：`Idamassa vaṇṇasmiṃ vadāmīti ayamassa guṇavaṇṇoti vadāmi`（我说这是他的**德色**）。本文人层的 vaṇṇa 所指是「能解答增上法、增上律之问」这项德行之美，不是相貌。译文 §1206-21「外貌不出众」、§1207-64「他在外貌上的欠缺」、§1208-57/§1209-57「这就是他的外貌」，会让读者直接理解为长相丑／长相好，这是义注明确排除的解读。
  - 同一问题见 **ārohapariṇāha**：**义注**：`ayamassa uccabhāvo parimaṇḍalabhāvoti vadāmī`（高大、丰圆），本文人层所指是四资具丰足；译文 §1207-76「他在体格上的欠缺」、§1209-67「这就是他的体格」同样被读成肌肉体格。
- **建议**：保留比喻词、不要实译成生理描写。
  - `na vaṇṇasampanno` → 「容色不足」（§1206-21、§1207-12、§1207-90）
  - `Idamassa na vaṇṇasmiṃ vadāmi` → 「我说这就是他在容色上的欠缺」
  - `Idamassa vaṇṇasmiṃ vadāmi` → 「我说这就是他的容色」
  - `ārohapariṇāha` 人层统一作「体格」并在 §1206 首次出现处加段后小字注：**义注**释为「高大、丰圆」，此处指四资具丰足。vaṇṇa 首次出现处同样加注：**义注**释为「德行之美（guṇavaṇṇa）」。
  - 改后须与 §1205 马层选词同步（见跨段一致性）。

### 2. §1203-2-4、§1204-2-18 及全 chunk：`khaḷuṅka` 译「劣」与义注的释义不合

- **问题**：**义注**：`Aṭṭhame **assakhaḷuṅko**ti assapoto`（assakhaḷuṅka 就是**马驹**）。义注把 khaḷuṅka 定为「未驯的幼马」，重点在未经调练，不在品质低劣；译作「劣马／劣人」把义注的释义收窄成价值判断，且与下文「速度快、容色好、体格壮」三者俱足的第三种马自相矛盾（既然三德俱足，何以称「劣」——称「未驯之驹」才讲得通）。
- **建议**：`assakhaḷuṅka` → 「劣马驹」或「未驯的马驹」；`purisakhaḷuṅka` → 「未驯之人」。题名 §1203「八、劣马经」须同步改（如「八、马驹经」）。此词是义注黑体被解释词，本文定稿后义注层须逐字沿用，**请在本 chunk 内先定案**。

### 3. §1207-41、§1208-42、§1209-42（`Idamassa javasmiṃ vadāmi`）：缺义注所指的限定

- **问题**：**义注**：`ayamassa ñāṇajavoti vadāmi`（我说这是他的**智速**）。译文「我说这就是他的速度」孤立成句时，读者无从知道所指为智慧之速，易与前句「如实了知四谛」脱节。
- **建议**：译文保留「速度」以存比喻，但在 §1207 首次出现处加段后小字注：**义注**释为「智慧的迅速（ñāṇajava）」。

## 建议项

- **§1204-19-25**（`Taṃ suṇātha, sādhukaṃ manasi karotha`）：`taṃ` 未译出，`manasi karotha`（作意、铭记于心）译「注意」偏弱。建议「你们要听，要好好地记在心里」。
- **§1207-2-11**（`Kathañca ... javasampanno hoti`）：「怎样的劣人是速度很快」句式略生硬（判断句套形容短语）。建议「比丘们，怎样的劣人速度很快，却…」。§1208-2、§1209-2 同式，一并调整以保持一致。
- **§1207-17 等三处**「……乃至……」：`…pe…` 的省略标记。「乃至」属半文言，但作省略标记是佛典惯例，可保留；若按 `style.md` 严格执行现代汉语，建议改「……（中略）……」。**全书须统一一种**，请定案后记入 `knowledge/style.md`。
- **§1207-69、§1208-61、§1209-61**（`cīvarapiṇḍapātasenāsanagilānappaccayabhesajjaparikkhārānaṃ`）：现译「衣服、饮食、住处和治病所需的医药用品」已是通顺的现代汉语 ✅；仅提示四资具的第四项原文是「病缘医药资具」，含「资具（parikkhāra）」一层，若后续义注层出现对应黑体词，须与此处逐字对齐。
