**准确性**：主谓宾判断与教理方向无误，无 fatal。整段核心句式 `yāni kānici bhayāni uppajjanti sabbāni tāni bālato uppajjanti` 的「从愚人生起」处理为「由愚人引起」，意思贴合，但把夺格 `-to`（ablative，从…而起）转成了汉语的施事「由…引起」，与原文「生起」的自动词性质有一点偏移——原文说的是怖畏「从愚人那里生起」，而非愚人主动「引起」。此处不扣为 error（义理方向一致、南传常见汉译亦多作「由愚人而起」），但列为 suggestion 并在此注明分歧。

真正扣分处集中在 para 9 的三组 bahubbīhi 复合词：`sappaṭibhayo / appaṭibhayo`、`saupaddavo / anupaddavo`、`saupasaggo / anupasaggo`。这三组是「有怖畏的 / 无怖畏的」结构，描述的是愚人自身**带有**怖畏、祸患、障难，而智者自身**没有**。译文把第一组译为「可畏的 / 不可畏的」（转成了对他人的被动可畏性），后两组译为「带来祸患的 / 不带来祸患的」（转成了及物的致使义），三组内部**互不同构**，且都偏离了 sa-/a- 前缀的「具有/不具有」本义。这是词义与修饰关系层面的问题，计 error 一条、warning 一条。

另 `86-7-36-53` 的 `Bhadante` 译「大德」可；原文方括号内异读 `[bhaddante (ka.)]` 未在译文反映属正常（异读不入正文）。`86-8-44-88` 的长句（aggi mutto + 四个形容尖顶屋的复合词）处理得相当完整，四项修饰（ullittāvalittāni / nivātāni / phusitaggaḷāni / pihitavātapānāni）无一漏译，是本段质量最高的一句。

**风格**：主体是合格的现代书面汉语，无「此中/故为/彼等/是故」等禁例。扣分点有二：一是 `86-9-2-16` 的「所以说」尚可，但同句「愚人是可畏的」这种「是…的」判断句连用六次（para 9 全段），读来生硬，属不够流畅；二是 `86-10-11-36` 的「受持奉行」是佛教固定语，可保留，但同句「凡具备了就可以知道是愚人的那三种法」定语过长、嵌套较深，对一般读者不友好。**未发现文言虚词或文言句式**，故风格分未按 style.md 第一节显著扣分。

## 问题清单

### 🟧 error

- `86-9-2-16`｜错译（词义、修饰关系）｜片段「愚人是可畏的，智者是不可畏的」
  - 问题：`sappaṭibhayo / appaṭibhayo` 是 bahubbīhi，义为「有怖畏的 / 无怖畏的」，描述愚人自身带有、伴随着怖畏。译文「可畏的 / 不可畏的」改成了「值得被畏惧 / 不值得被畏惧」，把 paṭibhaya 的归属从愚人身上转到了旁观者的感受上，且与上文 para 8「怖畏从愚人而起」的逻辑衔接断开——上文说愚人是怖畏的来源，此处总结应是「愚人有怖畏」。
  - 建议：改为「愚人是有怖畏的，智者是没有怖畏的」，与后两组同构。

### 🟨 warning

- `86-9-17-22`｜整句逻辑表达不规范｜片段「愚人是带来祸患的，智者是不带来祸患的」
  - 问题：`saupaddavo / anupaddavo` 同为 bahubbīhi「有祸患的 / 无祸患的」，译文用及物的「带来」把它变成致使结构，与 `86-9-23-28`「带来障难的」一致、却与 `86-9-2-16`「可畏的」不一致，三组并列句内部三种句式，排比尽失。
  - 建议：三组统一为「有…的 / 没有…的」：「愚人是有祸患的，智者是没有祸患的。」`86-9-23-28` 同改为「愚人是有障难的，智者是没有障难的。」
- `86-9-29-43`｜关键词语意不明确｜片段「没有由智者引起的怖畏」
  - 问题：`natthi paṇḍitato bhayaṃ` 直译是「不存在从智者而起的怖畏」。译文「由智者引起的」读起来像在排除一种特定来源的怖畏（仿佛还有别的怖畏存在），而原文是说怖畏不会从智者这边产生。语意指向略有偏差。
  - 建议：改为「比丘们，怖畏不会从智者而起，祸患不会从智者而起，障难不会从智者而起。」

### 🟦 suggestion

- `86-8-2-19`｜语言表达不够流畅｜片段「这一切都是由愚人引起的，不是由智者引起的」
  - 问题：`bālato uppajjanti` 的 `-to` 是夺格，表「从…生起」，uppajjati 本身是自动词。译为「由…引起」转成了施事+致使，虽不违义理，但与原文的「生起」视角有偏移，也与 para 9 的总结句（愚人自身有怖畏）衔接得不够顺。此句式在本段重复六次，改动需六处同步。
  - 建议：考虑统一为「这一切都从愚人而起，不从智者而起」，更贴近夺格，也更简洁。
- `86-10-11-36`｜复杂的嵌套句整句语言逻辑理解困难｜片段「凡具备了就可以知道是愚人的那三种法」
  - 问题：「凡…就可以知道是…的那三种法」把关系从句整个压成前置定语，20 字定语套一个「那三种法」，一般读者需读两遍。
  - 建议：拆为两段：「有三种法，具备了这三种法就可以知道是愚人——我们要避开这三种法；有三种法，具备了这三种法就可以知道是智者——我们要受持奉行这三种法。」
- `86-7-2-22`｜语言风格不统一｜片段「我听到的是这样的——」
  - 问题：`Evaṃ me sutaṃ` 的译法可，但破折号接「有一次」稍显松散；且全段其余处（`86-10-2-10`、`86-10-11-36`）也用破折号，破折号用途（引出引语 / 引出内容）不完全一致。
  - 建议：此处可作「我是这样听说的：有一次，……」，把破折号留给引出引语的场合。
