## 跨段一致性

### 两段散文的平行句（§767–768 与 §787–788）

两段的巴利原文逐字相同，但译法不同。建议以 §767–768 为准统一：

- **purimaṃ bhavaṃ purimaṃ niketaṃ**：§767 译「过去生、过去住处」，§787 译「过去的存在、过去的住处」。建议统一为「过去生、过去住处」。
- **manussabhūto samāno**：§767 译「身为人时」，§787 译「曾经身为人时」。建议统一为「身为人时」。
- **so tato cuto itthattaṃ āgato samāno**：§767 译「他从那里死后转生到这个世间时」，§787 译「他从那里死没、来到这个世间时」。
  - 两段原文相同，建议统一为「他从那里死后，来到这个世间时」。
  - §767 的「转生到」把 āgato 译重了。
- **So tassa kammassa kaṭattā**：
  - §767 译「他因为造作了那样的业」，§787 译「由于造作并积集了那样的业」。
  - §787 漏了句首主语 so「他」，且与 §767 的句式不一致。
  - §787 原文多出 upacitattā，「积集」应保留。§767 原文只有 kaṭattā，不必补。
  - 建议两段都以「他因为……那样的业」开头。
- **rājā samāno / buddho samāno**：§768 译「身为国王时 / 身为佛陀时」，§788 译「他成为王时 / 他成为佛陀时」。建议统一为「身为国王时 / 身为佛陀时」。
- **rājā**：§768 译「国王」，§788 译「王」。建议统一为「国王」。
- **在家者随众名单**（brāhmaṇagahapatikā … kumārā，§768 与 §788 原文完全相同）。建议统一为 §768 的译法，§788 的「城镇的人、乡村的人」可保留拆分方式，但两处必须一致：

  | 巴利词 | §768 | §788 |
  |---|---|---|
  | negamajānapadā | 城镇与地方的人 | 城镇的人、乡村的人 |
  | gaṇakamahāmattā | 司账的大臣 | 司理财政的大臣 |
  | anīkaṭṭhā | 军队将领 | 统率军队的人 |
  | pārisajjā | 朝臣 | 随从 |
  | rājāno | 诸小王 | 诸王 |
  | bhogiyā | 领地的臣属 | 封邑的领主（所指相反） |
  | kumārā | 王子们 | 王子 |

- **出家者随众名单**：
  - **devā**：§768 译「天人」，§788 译「天神」。
  - **manussā**：§768 译「人类」，§788 译「人」。
  - 建议统一为「天人、人」。
- **Etamatthaṃ bhagavā avoca**：§768 译「世尊说了这番话」，§788 译「世尊说了这个意思」。建议统一为「世尊说了这个意思」，attha 指意义。
