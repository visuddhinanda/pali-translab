# Review — 95:311-326（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核。§311、§315、§319、§322、§326 等句没有 nissaya，略过）

## 跨段一致性
- **vāseṭṭha**：§312–§314 译“婆西塔”，§316–§324 译“婆私吒”，同一 chunk 里出现两个译名 → 必须统一为“婆私吒”（出现次数多，§324 的 vāseṭṭhabhāradvājā 也用这个译法），改 §312、§313、§314 共 6 句。
- **brāhmaṇopi kho … pe …（省略句）**：§312–§314 译“也是如此”，§316 译“也是这样” → 统一为“也是这样”。
- **条件句引导词**：§312–§314 用“若以身……”，§316 用“如果身……” → 统一为“如果”。“若”字偏文言，不符合 style.md 的要求。
- **samaṇa 夹注**：§312、§313 都写“沙门（samaṇa）”，§314、§316 不加 → 按“首次出现才夹注”，只保留 §312 的夹注，删掉 §313 的。
- **-pi（khattiyopi / brāhmaṇopi / brahmunā pi）**：nissaya 一律释作 `သည်လည်း`（……也），译文各段都没译出“也”（§312、§313、§314、§316 句首，§318 的 brahmunā pesā）。这几处要统一处理。省略句（§312 第二句等）已经有“也是……”，所以只需补首句和 §318。
- **(etasmiṃ) jane**：§317、§319、§322 都译“众生当中”。nissaya 作 `ဤ လူအပေါင်း၌`（在这群人当中），指人，不是一切众生，也漏了指示词 etasmiṃ → 三处统一改为“在这些人当中”。
- **vaṇṇa 与 gotta 混用“种姓”**：§317 的 catunnaṃ vaṇṇānaṃ 译“四个种姓”，§319/§322 的 gottapaṭisārino 也用“种姓”。nissaya 区分了这两个词：vaṇṇa = `အမျိုး`（种类、阶层），gotta = `အနွယ်`（家族世系）。建议 gotta 改译“族姓／氏族”，和 vaṇṇa 分开。

## §312 句 95-312-2-44
- **问题**：词法／冗译。nissaya 的释义是：micchādiṭṭhikammasamādāno = `မိစ္ဆာဒိဋ္ဌိဖြင့် ဆောက်တည်အပ်သော ကံရှိသည်`（有以邪见受持的业，“以邪见”是具格），hetu = `…ကံဟူသော အကြောင်းကြောင့်`（因为以邪见受持的业）。译文“依邪见而受持邪见业”把“邪见”说了两遍；hetu 句只译“持邪见业”，丢了 samādāna（受持），前后两处译法也不一致。
- **建议**：改为“持有邪见，以邪见受持业，由于以邪见受持业的缘故”。

- **问题**：句法。nissaya 中 apāyaṃ = `…ကင်းသော`，duggatiṃ = `…ဖြစ်သော`，vinipātaṃ = `…ဖြစ်သော`，三词都带形容词性词尾 `သော`，只有 nirayaṃ 带方向格 `သို့`。也就是说，前三词是修饰 nirayaṃ 的同位语，不是并列的四个去处。
- **建议**：表明前三词修饰地狱，例如“投生到苦界、恶趣、堕处——也就是地狱”。§312 第二句（95-312-45-88）同样处理。

- **问题**：漏译。khattiyopi 的 `သည်လည်း`（也）没有译出。
- **建议**：“婆私吒，刹帝利也是，如果以身行恶行……”，或在主语后补“也”。

## §312 句 95-312-45-88
- **问题**：同 95-312-2-44，“依邪见而受持邪见业／由于持邪见业”冗译，前后不一致。地狱一串词的句法也一样。
- **建议**：照上句修改，两句保持一致。

## §313 句 95-313-2-40
- **问题**：冗译。sammādiṭṭhikammasamādāno 和 hetu 的问题与 §312 相同。
- **建议**：“持有正见，以正见受持业，由于以正见受持业的缘故”。

- **问题**：漏译、句法。nissaya 中 sugatiṃ = `…ဖြစ်သော`，saggaṃ = `…ကောင်းမြတ်သော`，两词都是修饰语；lokaṃ = `လောကသို့`（到世间），补注 `(လူ့ပြည် နတ်ပြည်သို့)`（到人界、天界）。译文“善趣、天界”漏了 lokaṃ，而且把 saggaṃ 落实成“天界”，范围比 nissaya 的说法窄。
- **建议**：“投生到善趣、天上的世间”，或“投生到属于善趣的天界世间”。要保留 lokaṃ，saggaṃ 作修饰语。§313 第二句（95-313-41-83）一并修改。

## §314 句 95-314-2-49
- **问题**：冗译。“依杂见而受持杂见业”“由于持杂见业”的问题与 §312 相同。nissaya 作 `ရောနှောသော အယူအားဖြင့် ဆောက်တည်အပ်သော ကံ`（以混杂的见解受持的业）。
- **建议**：“持有杂见，以杂见受持业，由于以杂见受持业的缘故”。

## §314 句 95-314-50-92
- **问题**：误译倾向。sukhadukkhappaṭisaṃvedī = `သုခဒုက္ခနှစ်မျိုးလုံးကို ခံစားရခြင်းရှိသည်`（乐与苦两种都会感受）。译文“苦乐参半”带有“各占一半”的意思，原文没有；词序也和 sukha-dukkha 相反。
- **建议**：“身坏命终后，乐与苦都会感受”。上句 95-314-2-49 一并修改。

- **问题**：冗译，同上一句。
- **建议**：同上一句。

## §316 句 95-316-2-33
- **问题**：词法。diṭṭheva dhamme = `…ပစ္စက္ခအတ္တဘော၌ပင်`（就在当下这一生），带强调词 `ပင်`（eva）；译文只有“在现法中”，强调没有译出。
- **建议**：“就在现法中般涅槃”，或“就在今生般涅槃”。

- **问题**：语气。parinibbāyati 是现在时直陈式，nissaya 作 `…အေးငြိမ်းရ၏`（得以平息），译文“就能……”多加了“能”这层能力意味。nissaya 还说明这里指 `ကိလေသာခပ်သိမ်း အေးငြိမ်း`（一切烦恼平息）。
- **建议**：去掉“能”，改为“……就在现法中般涅槃”。

## §316 句 95-316-34-70
- **问题**：同 95-316-2-33。
- **建议**：同上。

## §317 句 95-317-2-31
- **问题**：漏译。dhammeneva = `တရားအားဖြင့်သာ`（只凭法），`သာ` 表示“只、唯独”，译文“凭借法”漏了这层限定，削弱了和下句 no adhammena 的对比。
- **建议**：“他正是凭借法，才被称为他们当中最上的”，或“唯独凭借法”。

- **问题**：句法（参考）。nissaya 把 nesaṃ 释作 `ထိုအမျိုးလေးပါးတို့ထက်`（比那四个种姓），是比较义。译文“他们当中最上的”可以接受，不必改。

## §317 句 95-317-35-46
- **问题**：漏译。句首 hi 在 nissaya 中作 `မှန်၏`（的确、因为），说明本句是在解释上句，译文没有译出。etasmiṃ jane = `ဤ လူအပေါင်း၌`（在这群人当中），译文“在众生当中”既漏了“这”，又把“人”扩大成“众生”（见跨段一致性）。
- **建议**：“婆私吒，因为在这些人当中，无论现法还是来世，法都是最殊胜的。”

- **问题**：标点（必改）。“来世,都是”中用了 ASCII 半角逗号。
- **建议**：改成全角“，”。

## §318 句 95-318-2-16
- **问题**：漏译。brahmunā pesā（= brahmunā pi esā）在 nissaya 中作 `ဗြဟ္မာသည်လည်း`（梵天也），“也”没有译出；esā gāthā = `ဤဂါထာကို`（这首偈），译文“这样一首偈”稍有偏离。
- **建议**：“婆私吒，梵天常童子也说过这首偈：”（只改“也”和“这首”，专名不在本次复核范围内）。

## §320 句 95-320-2-9（连带 §319、§322）
- **问题**：句法。nissaya 的结构是：etasmiṃ jane（在这群人中），ye gottapaṭisārino（凡以族姓为依恃的人），补出 `(တေသု)`（在他们之中），khattiyo seṭṭho（刹帝利最殊胜）。也就是说，“以族姓为依恃的人”是比较范围。译文“对那些重视种姓的人来说”变成了评价者的视角；gottapaṭisārino = `အနွယ်ကို အားကိုးရာဟုပြုကြကုန်၏`（把族姓当作依靠），“重视”译得不够准。
- **建议**：把 §319、§322 两处同步改为“在这些人当中，在以族姓为依恃的人里，刹帝利最殊胜；”。§320、§323 的下半句不用改。

## §324 句 95-324-5-10
- 无词法问题。attamanā = `နှစ်သက် ဝမ်းမြောက်ကုန်သည်`，abhinanduṃ = `လွန်စွာနှစ်သက်…လက်ခံ`，和译文“满意地欢喜信受”对应。
