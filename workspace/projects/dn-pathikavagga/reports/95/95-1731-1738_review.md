# Review — 95:1731-1738（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 注入的各句都没有附带 nissaya 单元，所以逐句词法复核全部略过，只出跨段一致性意见）

## 跨段一致性

- **小节编号 ( Ja ) / ( Jha ) / ( Ña )**：§1731 译“（甲）”，§1732 译“（乙）”，§1737 译“（丙）”。原文是巴利字母序 ka kha ga gha ṅa ca cha ja jha ña，分别对应第 1 到第 10 问。ja、jha、ña 是第 8、9、10 问，不是第 1、2、3 问。
  - 照现在的译法，编号会与同一数目之下前面各问（ka…cha）的编号重复、错位。
  - 建议改为：( Ja ) →“（辛）”，( Jha ) →“（壬）”，( Ña ) →“（癸）”。
  - 改前请核对本书前面各段 ka…cha 的实际译法，按同一套天干顺延。
- **否定排比中的“他”**：yathāsutaṃ … deseti / sajjhāyaṃ karoti / anuvitakketi 各句的主语都是 bhikkhu，但译文带“他”的地方不统一。
  - §1734 句 95-1734-2-29：“也不是**他**依照所闻……为他人说法”。
  - §1735 句 95-1735-2-37、§1736 句 95-1736-2-46 中，第二项仍有“他”，后面各项又省去了。
  - 建议排比各项统一处理：要么都不加“他”，要么只在第一项出现。
