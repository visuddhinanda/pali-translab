# Review — 95:846-900（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（注入数据中所有句都没有 nissaya 字段，逐句词法复核无法进行，按任务要求逐句意见全部略过；下面只列跨段一致性）

## 跨段一致性

- **Rājā samāno / Buddho samāno**：§848 译“身为王时”“身为佛时”，§868–869 译“身为国王”“身为佛陀”。建议统一为“身为国王时”“身为佛陀时”。
- **kiṃ labhati / idaṃ labhati**：§848 译“得到什么呢／得到这个”，§868–869 译“获得什么呢／获得这些”。同经重复句式，建议统一为“获得什么呢／获得这个”（idaṃ 是单数）。
- **purimaṃ niketaṃ … manussabhūto samāno**：§847 译“过去住处身为人时”，§867 译“过去所住之处，曾作为人时”。重复句式应逐字一致，建议统一为“过去住处、过去身为人时”。
- **tato cuto itthattaṃ āgato samāno**：§847 译“来到这个状态”，§867 译“来到这个世间时”。建议统一为“来到这个世间时”。
- **appadhaṃsiya / suppadhaṃsiya 词族**：§848 译“不会被……所侵害”，§858（suduppadhaṃsiyo）译“难以被推翻”，§863（na suppadhaṃsiyo）译“无法使他退失”。同一词根有三种译法，§863 的“退失”离词义最远。建议统一用“侵害／难以侵害”一系。
- **tidivapuravarasamo**：§860 译“如同忉利天最胜之城”，§877 译“如三十三天殊胜之城的帝释天”。同一复合词，“忉利天”与“三十三天”混用，比喻对象一处是“城”、一处是“帝释天”，前后矛盾。需要统一天名，并统一比喻所指。
- **Ahitamapi ca apanudi / Hitamapi ca bahujanasukhañca**（§852–853、§873–874、§890 三处）：ahita 译作“无益之事”和“不利的事”，hita 译作“有益之事”和“有利的事”，bahujanasukha 译作“众人的安乐”“众人的快乐”“共享快乐”。重复偈句应统一，建议用“无益的事／有益的事／众人的安乐”。
- **vivaṭṭacchado**：§869 译“在世间揭开了遮蔽”，§892 译“遮障已除”。建议统一为“揭开遮蔽”。
- **段号**：§870 保留了“241.”，§847、§849、§867 删去了 238、239、240。应全部删去或全部保留。
- **偈颂开头引号**：§879（‘‘ Laddhānaṃ）和 §887（‘‘ Rañño）的原文都有颂首引号，译文却缺少“。其余各颂都有，应补齐。
- **格式标记**：§881、§882 的译文中有 markdown 粗体 `**牙齿**`。本文层不应出现粗体（粗体是义注、复注引用被解释词的体例），应去掉。
- **语体（文言残留，前后不一）**：
  - “就”与“便”混用：§847、§848、§891 用“就”，§868、§869 用“便会”。按 style.md，“便”应改为“就”。
  - 其他文言残留：§870“关于此”（§849 作“关于这点”）；§875“此人”（style.md 禁例，改“这个人”）；§852、§853“之事”；§860“最胜之城”；§868“使之……并安住其中”。均建议改为现代汉语写法。
