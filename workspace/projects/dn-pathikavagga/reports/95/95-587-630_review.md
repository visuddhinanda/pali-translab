## 跨段一致性
- **Eṇijaṅgha**：§611 标题译“鹿肠相”，§612 译“小腿如鹿腿一般”，§623 eṇeyyajaṅgha 译“羚羊腿” → 标题的“肠”是错字（jaṅghā = 小腿，§620 也译“小腿”），属必改项。建议统一为“鹿腿相”／“如鹿的小腿”／“鹿腿”，eṇi／eṇeyya 三处都译“鹿”。
- **purimaṃ bhavaṃ**：§588 译“过去生”，§612 译“过去有” → 建议统一为“过去生”。
- **manussabhūto samāno**：§588 译“还是人的时候”，§612 译“曾经身为人时” → 建议统一为“还是人的时候”。
- **tassa kammassa kaṭattā**：§588 译“那种业”，§612 译“这样的业” → tassa 是远指，建议统一为“那种业”。
- **… pe …**：§588、§589 译“……（如前所说）……”，§612、§613 译“……（中略）……”；§589、§613 句中“idaṃ labhati …”的省略号没有附注 → 建议全书统一为同一种略写标记。
- **samannāgato**：§589 译“具备”，§613 译“具足” → 建议统一。
- **rājā samāno / buddho samāno / kiṃ labhati**：§589 译“作为国王的时候”“作为佛陀的时候”“会得到什么呢”，§613 译“成为王时”“成为佛时”“获得什么呢” → 这是重复句式，建议逐字统一，以 §589 为准。
- **rājā hoti cakkavattī**：§589 译“就会成为转轮王”，§613 译“就成为转轮王” → 建议统一。
- **caraṇa / kamma**：§612 译“戒行”“业（了知业属自己的智慧）”，§615 偈颂中 vijjācaraṇesu kammesu 译“德行”“事业” → 同一组列举在散文和偈颂里不应换词，建议统一为“戒行”“业”。
- **Tatthetaṃ vuccati**：§590 译“213. 对此，有这样的偈颂——”，§614 译“在这里，这样说道：”，没有保留段号 215 → 建议句式和段号处理都统一。另外 §588（212.）、§612（214.）的段号在译文里也没有保留，与 §590 不一致。
- **章节标题编号**：§587 用“（9-10）”，§611 用“（十一）” → 建议统一用阿拉伯数字或统一用汉字。
- **uddhaggaloma**：§588 译“身毛上竖相”，§599 译“体毛向上竖起”，§622 译“毛向上竖立” → 建议统一为“身毛上竖”。
- **anoma-nikkamo / anoma-vikkamo**：§607 译“精进不懈”，§630 译“精进不凡” → 两处都是 anoma（不劣、卓越）修饰精进，建议统一，例如都译“精进卓越”。
- **语体**：§592 “说着此言”中的“此”属文言，与本 chunk 其余现代汉语不一致 → 建议改为“说着这样的话”。
