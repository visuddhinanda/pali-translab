# Review — 95:286-296（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句没有 nissaya 单元，这些句子略过）

## 跨段一致性
- **vāseṭṭha**：§287、§292–296 译“婆西塔”，§289、§290 译“婆西达” → 统一为“婆西塔”（多数译法）。
- **akaṭṭhapāka**：§286、§287 译“不耕而熟”，§289 译“不经耕种而自然生长” → 统一为“不耕而熟”。依据：`အကဋ္ဌပါကော= မထွန်အပ်သော မြေအရပ်၌မှည့်ရင့်သော`（长在未耕的地上、自己成熟的）。pāka 是“成熟”，不是“生长”。
- **sāli**：§286、§287 译“粳米”，§289、§292–295 译“稻米”，§296 译“稻子” → 全章统一。nissaya 一律作 `သလေး`（sāli 稻）。§287 的 nissaya 附注（见 §289 行内 **အမှာ**）专门说明：yaṃ taṃ / pakkaṃ / paṭivirūḷhaṃ / apadānaṃ 指的是**稻株**（`သလေးကောက်ပင်`），不是米粒。建议说稻株、收割的地方用“稻子”，说取来吃的东西用“稻米”，“粳米”不再使用。
- **kaṇa / thusa**：§287 akaṇo athuso 译“没有糠、没有麸”，§296 kaṇo / thuso 译“糠皮 / 谷壳” → 两处要对应。thusa 是 `ဖွဲ့ကြမ်း / စပါးခွံ`（谷壳），两处都应译“谷壳”。kaṇa 在 nissaya 里作 `ဆန်ကွဲ`（碎米），两处要用同一个词。“麸”的意思不对。
- **taṃbhakkhā tadāhārā**：§287 只译“以它为食物”，§289 译“以此为食物、以此为营养” → §287 漏了 tadāhārā。两处是同一个重复句式，译法应该一样。
- **methunaṃ dhammaṃ**：§289、§290 译“淫欲之事”，§292 译“淫欲之法”，标题 §291 译“淫欲法” → 三种说法要统一。nissaya 作 `မေထုန်အကျင့်`（淫欲的行为）。“之事”“之法”是文言的“之”，建议统一为“淫欲的行为”。
- **asaddhamma**：§292 两处译法不同，分别是“不善之法”和“不善之事” → 统一并去掉“之”。nissaya 作 `မသူတော်တို့၏ အကျင့်`（不良之人的行为，即淫事），“不善”容易和 akusala 混淆。建议译为“这种不正当的行为”。
- **paribhuñjantā**：§287 译“吃着”，§289 译“食用”（style.md 点名的文言词）→ 统一为“吃”。
- **diṭṭhānugatiṃ āpajjamāno**（§293、§294、§295）：三处都译“那个众生也仿效那个众生的做法”，两个“那个众生”指的不是同一个人，读者分不清 → 改为“这个众生仿效了前一个众生的做法”，三处统一。
- **evampi kira, bho, sādhū**（§293、§294、§295）：§294 和 §295 直接把引语接在叙述后面，没有“说”。nissaya 有 `ဣတိ= ဤသို့ပြောပြီ`（这样说） → 三处都补上“说：”，句式要一样。
- **Atha kho aññataro satto**：§293 译“那时另有一个众生”，§294、§295 译“于是又有另一个众生” → 统一为“于是”。
- **粗体标记**：§286、§287 把“不耕而熟”“帕达拉藤”加了粗体，§289 同一个词没加 → 要么全加，要么全不加。
- **标点**：§290（64-91）、§292（2-39、40-63、64-76）里有半角逗号“,” → 必改为全角“，”。

## §287 句 95-287-2-25
- **问题**：句法误读 — `ပဒါလတာယ= သည်။ အန္တရဟိတာယ= လသော်` 是时间性的绝对处格（“……消失了以后”），不表示原因。译文写成“因为……消失了以后”，把因果和时间混在了一起。
- **建议**：删掉“因为”，改为“帕达拉藤消失以后”。
- **问题**：误译 — taṇḍulapphalo 在 nissaya 里作 `ဆန်သီးရှိသော`（结的果实是米粒），没有“洁净”的意思。“洁净”已经由前面的 suddho 表达，这里重复了。
- **建议**：改为“结出的就是米粒”。athuso 改译“没有谷壳”（见跨段一致性）。

## §287 句 95-287-26-37
- **问题**：所指有误 — `ယံ တံ= အကြင်သို့သော ထို သလေးကောက်ပင်ကို`、`တံ= ထိုဆောင်ယူအပ်သော သလေးကောက်ပင်သည်`，nissaya 明确说是稻株。“那些米”不可能“重新长出来”。
- **建议**：改为“傍晚拿去做晚饭的那些稻子，到了早晨又长了回来，而且已经成熟”。

## §287 句 95-287-38-49
- **问题**：同上。对应的 nissaya 在 50-52 行（`ယံ တံ= ကို … တံ= သည်`），所指也是稻株。
- **建议**：“那些米”改为“那些稻子”，和上一句保持同一句式。

## §287 句 95-287-53-68
- **问题**：漏译 — nissaya 有 `တဒါဟာရာ= ထို သလေးဆန်ဟူသော အာဟာရရှိကုန်သည်`（以它为营养/食粮），译文没有。
- **建议**：补为“以它为食物，以它为营养”，和 §289 一样。

## §289 句 95-289-2-45
- **问题**：句法 — yathā yathā … tathā tathā 是“越……越……”的关联句式（`ယထာ ယထာ= ဖြင့်`）。译文改成了“因为……随着时间推移……越来越”，原文没有“因为”和“随着时间推移”。
- **建议**：改为“婆西塔啊，那些众生越是长久地吃不耕而熟的稻米、以它为食物、以它为营养，他们的身体就越来越粗糙，容貌上也显出了差异……”。
- **问题**：文言 — “食用”是必改项。
- **建议**：改为“吃”。

## §290 句 95-290-32-53
- **问题**：误译 — `အသုစိ= မစင်ကြယ်သူ (ညစ်ပတ်သူ)`（不洁的人、肮脏的家伙，呼格），`နဿ= ပျက်စီးပေတော့`（去毁灭吧、完蛋吧）。对象是人，不是“东西”。nassa 是咒骂，不是“消失吧”。
- **建议**：改为“‘肮脏的家伙，去死吧！肮脏的家伙，去死吧！’”，或“……滚开吧！”。

## §290 句 95-290-54-63
- **问题**：补出成分 — `သတ္တော= သတ္တဝါတစ်ယောက်သည်`、`သတ္တဿ= အခြားသတ္တဝါတစ်ယောက်၏အပေါ်၌`（一个众生对另一个众生）。译文写成“众生……对众生”，意思不清楚。
- **建议**：改为“‘一个众生怎么能对另一个众生做出这种事！’”。

## §292 句 95-292-2-39
- **问题**：隐含主语 — nissaya 补出 `တံ= ထိုမြေမှုံကို ပစ်ခြင်း အစရှိသည်`（扔泥土等做法）作主语。译文只写“……的事”，读者会以为说的是淫欲本身。`အဓမ္မဟု သမုတ်အပ်` 是“被认为不如法”，“合法”带有法律色彩。另有半角逗号。
- **建议**：改为“婆西塔啊，那时（扔泥土这类做法）被认为是不如法的，现在却被认为是如法的。”。

## §292 句 95-292-40-63
- **问题**：词义 — `ပဝိသိတုံ= ဝင်ခြင်းငှာ။ ဝါ= ဝင်ခွင့်ကို။ နလဘန္တိ`（得不到进入的许可），说的是被禁止进入，不是没有能力进入。“乃至”有文言色彩。另有半角逗号。
- **建议**：改为“……整整一个月、甚至两个月，都不准进入村庄或市镇。”。

## §292 句 95-292-64-76
- **问题**：术语 — asaddhamma 在 nissaya 里作 `မသူတော်တို့၏ အကျင့်ဖြစ်သော မေထုန်ပြုမှု`（不良之人的行为，即淫事），“不善之法”不对。句末是半角逗号。
- **建议**：改为“自从那些众生过度沉溺于这种不正当的行为以来，”（全角标点）。

## §292 句 95-292-77-84
- **问题**：语体 — tasseva 是“正是那个”（`ထို … ကိုပင်`），“那同一件不善之事”生硬，还带文言的“之”。
- **建议**：改为“于是他们开始建造房屋，正是为了遮掩这种不正当的行为。”。

## §293 句 95-293-65-80
- **问题**：指代不清 — `တဿ သတ္တဿ= ၏`（那个众生的）指先前的懒惰者，so satto 指后来的众生。译文前后都写“那个众生”，分不出是谁。
- **建议**：改为“于是这个众生仿效了前一个众生的做法，一次就取了够吃两天的稻米。”。

## §293 句 95-293-81-90
- **问题**：补出成分 — `ဣတိ= ဤသို့ပြောပြီ`（他这样说）。`ဧဝံပိ= ဤသို့ နှစ်ရက်စာ ဆောင်ယူခြင်းသည်လည်း` 指的是“这样取两天的量也……”。译文的引语前没有说话人。
- **建议**：改为“（他说：）‘朋友，这样也很好嘛。’”，并和 §294、§295 统一。

## §296 句 95-296-16-25
- **问题**：句法 — `တဏ္ဍုလုံ= သလေးဆန်ကို`（宾格）、`ပရိယောနန္ဓိ= ထက်ဝန်းကျင်မြှေးယှက်ပြီ`（四面裹住了）。主语是 kaṇa 和 thusa，宾语是米粒。译文把主语改成了“稻米”。（nissaya 在相邻的 2-15、26-36 行。）
- **建议**：改为“于是，糠裹住了米粒，谷壳也裹住了米粒；”，词和 §287 统一。

## §296 句 95-296-26-36
- **问题**：误译 — `လူနမ္ပိ= ရိတ်အပ်သော ကောက်ပင်သည်လည်း`（割过的稻株），不是“割过的地方”。`အပဒါနံ= ရိတ်အပ်ရာအရပ်သည်` 是“收割过的地方”。apadānaṃ paññāyittha 的意思是收割的痕迹能看出来了，译成“出现了缺损”是错的，而且和 §287 的“看不出被收割过的痕迹”对不上。
- **建议**：改为“割过的稻子不再长回来，收割过的痕迹看得出来了，稻子一丛一丛、零零散散地立着。”。
