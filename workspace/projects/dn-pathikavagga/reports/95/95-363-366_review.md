# Review — 95:363-366（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§363、§365 标题及 §366 除首句外各句无 nissaya，只在跨段一致性中涉及）

## 跨段一致性
- **etadānuttariyaṃ**：§364 译“无上之法”（首句、末句），§366 译“无上”（首句、末句）→ 建议统一为“无上”。anuttariya 指“无上性”，原文里没有“法”字。“之”是文言虚词，也违反 style.md。
- **Aparaṃ pana … etadānuttariyaṃ**：§364 译“还有另一项无上之法”，§366 译“还有另一种无上” → 建议统一为“还有另一项无上”。
- **yathā bhagavā dhammaṃ deseti**：§364 译“如世尊…所开示的法”，§366 译“即世尊如何教说…的法” → 两处是同一句式，建议统一为“就是世尊在……方面开示法的方式”或类似结构。
- **deseti / desanā**：§363 标题、§364 译“开示”，§365 标题、§366 译“教说” → 建议统一为“开示”。
- **sotāpanna / sakadāgāmī**：§364 译“入流者”“一来者”，§366 译“须陀洹”“斯陀含” → 意译与音译混用，建议全 chunk 统一一套，并登记进 terms.md。
- **rāgadosamoha**：§364 作“贪嗔痴”，§366 作“贪瞋痴” → 统一用字（建议“瞋”）。
- **loka**：§364 的 tasmā lokā 译“那个世界”，§364 的 imaṃ lokaṃ 与 §366 的 tasmā lokā 都译“世间” → 建议统一为“世间”。
- **Jānāti … paraṃ puggalaṃ … –**：§364 译“了知另一个人——”（破折号），§366 译“了知他人：”（冒号，且缺“大德”后的逗号节奏一致性）→ 措辞和标点统一为一种，建议“了知另一个人——”。
- **parikkhayā / khayā**：§364 用名词式“因三结的灭尽”“因诸漏的灭尽”，§366 用动词式“由于灭尽三结”“由于诸漏灭尽” → 建议统一句式。
- **sambodhiparāyaṇo**：§364 译“必定会走向正觉”，§366 译“决定趣向正觉” → 统一，见下文 §364 句 95-364-22-53。
- **语体**：§366 的“将于现法中”“自己以证智作证”带文言虚词“于”“以”，§364 对应处已是现代写法（“在现法中凭自己的证智”）→ §366 按 §364 统一。

## §364 句 95-364-2-21
- **问题**：风格 — “无上之法”用了文言虚词“之”，另外添出原文没有的“法”（见跨段一致性）。“如世尊在……中所开示的法”句式也与 §366 不一致。
- **建议**：“大德，还有另一项无上：就是世尊在教诫方式方面开示法的方式。”nissaya：anusāsanavidhāsu= 处格（“在教诫的诸类别中”），译“在……方面／中”可以保留。

## §364 句 95-364-22-53
- **问题**：句法 — nissaya 把 niyato（မဂ္ဂဓမ္မနိယာမအားဖြင့်မြဲသည်，“凭道法的决定性而确定，不再退转”）和 sambodhiparāyaṇo（以上三道为归趣）分成两个并列谓语。译文把 niyato 压成副词“必定”去修饰“走向正觉”，丢了“已经确定、不会退转”这个独立的义项。
- **建议**：分开译出，如“不会堕入恶趣，是已确定的，以正觉为归趣”。§366 对应句同步。

## §364 句 95-364-64-86
- **问题**：取义 — nissaya：imaṃ lokaṃ= ဤ ကာမဘုံသို့（这欲界），āgantvā= （以结生方式）返回；dukkhassa= 轮回苦（ဝဋ်ဒုက္ခ）。“究竟苦边”是旧译套语，现代读者不易懂。
- **建议**：“只再回到这个世间一次，就能终结苦。”“这个世间”可以保留，nissaya 的欲界之义不必补进正文。

## §364 句 95-364-97-117
- **问题**：用词 — nissaya：tasmā lokā= 从那梵天界，tattha= 在那梵天界。译文“那里”“那个世界”与前文“这个世间”对应得不够清楚。
- **建议**：“不再从那个世间返回”，与跨段统一。

## §364 句 95-364-149-154
- **问题**：补出成分／风格 — nissaya 补出了 “(ယာဒေသနာ အတ္ထိ)”（“所有的那种开示”），又以 etaṃ= 主格、anuttariyaṃ= 表语（“这是无上”），说明“这”指世尊在教诫方式方面的开示。译文“这就是教诫方式中的无上之法”漏了这层指涉，还用了“之”。
- **建议**：“大德，在教诫方式方面，这是无上的。”或“大德，世尊在教诫方式方面的这种开示，是无上的。”

## §366 句 95-366-2-21
- **问题**：句法 — nissaya：parapuggalavimuttiñāṇe= 处格，意思是“在了知（须陀洹等）他人从烦恼解脱的智方面”。译文“即世尊如何教说……的法”的句式与 §364 不一致，“教说”与“开示”也不统一。
- **建议**：“大德，还有另一项无上：就是世尊在了知他人解脱的智方面开示法的方式。”§365 标题“了知他人解脱智的教说”中，“了知”和“智”语义重复，建议同步改为“了知他人解脱之智的开示”→ 去掉“之”，作“关于了知他人解脱的智的开示”。
