# Review — 95:1485-1496（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 所有句子都没有取到 nissaya，因此不出逐句词法意见，只列跨段一致性）

## 跨段一致性

- **ātappāya anuyogāya sātaccāya padhānāya**：§1488 译“热忱、修习、坚持、精勤”，§1489 译“精勤、修习、恒常、努力”。§1489 把 ātappa 译成“精勤”，和 §1488 的 padhāna 撞词；同时 padhāna 在 §1485 的 padhāniyaṅga 里已定为“精勤”。→ 建议全 chunk 统一为 §1488 的“热忱、修习、坚持、精勤”，§1489 的四处（1489-25-48、1489-49-57、1489-141-167、1489-168-177）都要改。
- **nissaraṇa / nekkhamma 同译“出离”**：§1493 的 nissaraṇiyā dhātuyo 译“出离的界”，kāmānaṃ nissaraṇaṃ 译“对诸欲的出离”；同段的 nekkhamma 也译“出离”（1493-43-53）。两个不同的巴利词在同一段里共用一个译名，读者无法区分“修出离（nekkhamma）”和“从欲出离（nissaraṇa）”。→ 建议给 nissaraṇa 另定译名，例如“出离（远离、脱出）”改为“脱出”或“出离的途径”，§1493–1496 的“…的出离”五处（含标题）一并统一；或者把 nekkhamma 改为“离欲”。择定后登记到 `terms.md`。
- **Yo so … bhikkhu**：§1488 译“那个……的比丘”，§1489 译“那位……的比丘”。→ 统一为一种。
- **na namati**：同一句式，1489-25-48 和 1489-141-167 译“不会趋向”，1488 及 1489 其余句子译“不趋向”。→ 统一为“不趋向”。
- **avītarāgo（kāmesu / kāye / rūpe）**：1489-12-24 译“对欲贪没有远离”，1489-25-48 照抄；1489-63-110 译“对身体没有远离贪欲”“对色没有远离贪欲”。同一个结构（处格 + avītarāga），一处把贪归到“欲贪”，另一处说“对 X 没有远离贪欲”，句法前后不一致。→ 统一为“对诸欲没有离贪”，与“对身体没有离贪”“对诸色没有离贪”平行。同句的“欲欲没有消除”（avigatacchanda）读起来像笔误，建议改为“意欲没有消除”。
- **kāme / kāmesu、rūpe / rūpesu 的单复数**：§1493 译“作意于欲……心不趋入欲”，后文又译“脱离了诸欲”“对诸欲的出离”；§1496 是“作意于色……心不趋入诸色”。→ 同一段内建议统一，有“诸”就都加，没有就都不加。
- **段号标点**：§1485、§1486、§1488 用“三一七、”“三一八、”“三一九、”，§1489、§1493 用“三二〇。”“三二一。”。→ 统一为顿号“、”。
- **引语内层引号**：1485-22-40 的内层引语用 ‘’（正确）；1489-111-128 和 1489-141-167 的内层引语（原文 ‘…’ti）用了 “”，嵌在外层“…”里就冲突了。→ 这两处改为 ‘’。
- **1490-2-15 多出单引号**：译文开头是“‘**五种根**”。原文加粗的 ‘‘ 本身就是开引号，没有内层引语。→ 删去多余的 ‘，与 §1491、§1492 的“**五种根**”保持一致。
