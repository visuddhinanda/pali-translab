## 跨段一致性
- “abhibhū / anabhibhūto / aññadatthudaso / vasavattī / issaro / kattā / nimmātā / seṭṭho / sajitā / vasī / pitā bhūtabhabyānaṃ” 十一词尊号列（§96、§97、§100 三处均出现）→ zh 只译出十项（…遍观一切者、**自在者**、创造者…**自在主宰者**、众生的父亲），比对巴利词数少一项：**`vasavattī` 与 `issaro` 被合并成了一个“自在者”**，`vasī` 单独占用了“自在主宰者”。三处出现方式完全相同，是系统性漏译，建议为 vasavattī / issaro 分别定译（如“自在者、主宰者”），vasī 另译（如“操控者”），使十一词全部对应。
- “issarakuttaṃ brahmakuttaṃ **ācariyakaṃ** aggaññaṃ paññapenti”（§92、§100、§101）与 “khiḍḍāpadosikaṃ **ācariyakaṃ** aggaññaṃ paññapenti”（§101）中的 `ācariyakaṃ`（义注 105-53：ācariyabhāvaṃ ācariyavādaṃ，即“（该）教说/学说”）在 zh 中三处均未译出（“宣称世界的起源出于自在天所造、梵天所造” / “…由于游戏放逸而堕落造成的”），建议统一补上“……的学说 / 教说”，如“宣称……的教说是世界的起源”，以体现巴利原文明确标出这是一种“主张”而非直接断言。
- “manomayā pītibhakkhā sayaṃpabhā antalikkhacarā subhaṭṭhāyino”一语在 §93、§94、§95 三处译法一致（意生身、以喜悦为食、自身发光、能在空中飞行、安住在殊胜之处），格式统一，无问题。
- “aggaññañcāhaṃ, bhaggava, pajānāmi…nibbuti viditā…no anayaṃ āpajjati” 整段公式在 §91 与 §100（110-143）两次出现，译法逐字一致，且与义注 105-52 中标出的被解释词（paccattaññeva nibbuti viditā → 我自己内心便体证了寂灭；yadabhijānaṃ tathāgato → 如来正是这样以证知而行；no anayaṃ āpajjati → 不会陷入迷失之中）对应准确，无问题。
- “issarakuttaṃ brahmakuttaṃ” → “自在天所造、梵天所造” 与义注 105-53（issarakataṃ brahmakataṃ, issaranimmitaṃ brahmanimmitanti）一致，“kathaṃvihitakaṃ” → “具体是怎样造成的呢” 在 §92、§101 两处一致，均无问题。

## §92 句 95-92-2-19 / §100 句 95-100-81-90 / §101 句 95-101-2-18
- **问题**：`ācariyakaṃ`（“……的教说/学说”）未译出。
- **建议**：补译为“……的学说”或“……的说法”，与 issarakuttaṃ/brahmakuttaṃ、khiḍḍāpadosikaṃ 并列。

## §93/94/95 “subhaṭṭhāyino” 译法（存疑，非必改）
- **问题**：“subha-ṭṭhāyī”传统上理解为“以殊胜（庄严）之相而住”（形容自身状态，非处所），现译“安住在殊胜之处”偏向“处所”解，可能与原意有微小偏差。因手头义注未覆盖此句，无法核实取义，暂列为存疑，供定稿前核对。

其余句子（§91、§98、§99 等）经核对准确性、术语、现代汉语语体、逐字对应被解释词，均未发现问题。
