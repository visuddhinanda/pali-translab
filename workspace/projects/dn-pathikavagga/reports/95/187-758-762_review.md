# Review — 187:758-762（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／current_translation ✅／父层（book=105，义注，对应 187 之复注所释段落）✅／nissaya ❌（未提供，本次未核）

## 跨段一致性

- `savanamayaṃ`：§760（id 187-760-82-88）译为「**闻所成**」，但父层 105-735 对同一词的译法是「**闻法所成**」（与「说法所成」并列）。复注解释的正是义注中这个术语，译法必须与父层逐字一致 → 建议改为「闻法所成」。
- 「由于……之力」句式在 §758 中重复出现两次（id 187-758-48-63「并且由于思择之力而处于稳固的状态」；id 187-758-64-81「并且由于修习之力而处于稳固的状态」），是同一文言化短语的复现，非孤立笔误，应一并改法一致（见下）。

## §758 句 187-758-32-47
- **问题**：文言腔——「以此说明他没有称为破戒的愚痴」表达生硬，「没有称为……的愚痴」不是通顺的现代汉语搭配。
- **建议**：改为「以此说明他不具有破戒这种愚痴」或「说明他没有『破戒』这类的愚痴」。

## §758 句 187-758-48-63
- **问题**：①同上句式问题——「没有称为缺乏听闻的愚痴」；②「思择之力」含文言虚词「之」。
- **建议**：「说明他不具有缺乏听闻这种愚痴，并且由于思择的力量而处于稳固的状态」。

## §758 句 187-758-64-81
- **问题**：「修习之力」含文言虚词「之」，与上一处同一问题模式。
- **建议**：改为「由于修习的力量而处于稳固的状态」。

## §758 句 187-758-82-97
- **问题**：「显示他完全没有称为无明的愚痴」句式与前两句同类，略生硬。
- **建议**：改为「显示他完全不具有无明这种愚痴」。

## §760 句 187-760-82-88
- **问题**：被解释词 `savanamayaṃ` 译为「闻所成」，与父层 105-735 该词的定译「**闻法所成**」不一致（黑体被解释词须逐字同译）。
- **建议**：改为「凭借它而听闻，就是闻；闻本身就是**闻法所成**」。

其余句子核对被解释词与父层译文（`jātithero`生年长老 / `therakaraṇā dhammā`造就长老的法 / `sīlavā`具足戒 / `bahussuto`多闻 / `catunnaṃ jhānānaṃ lābhī`获得四种禅那 / `dānamayaṃ`布施所成 / `apacitisahagataṃ`伴随恭敬的 / `veyyāvaccasahagataṃ`伴随服务的 / `pattānuppadānaṃ`回向功德 / `pattabbhanumodanaṃ`随喜功德 / `desanāmayaṃ`说法所成 / `diṭṭhijugataṃ`正见相应 / `sīlamaye`持戒所成 / `dānamaye`布施所成 / `bhāvanāmaye`修习所成），均逐字一致，无问题。`vattasīse ṭhatvā → cārittasīlamayaṃ`（所行戒所成）是复注对父层「持戒所成」概念的进一步细分，非误译，标题短语本身与父层「以持守戒行的方式」一致，予以保留。未见工作标记、ASCII 引号或术语误用。
