# Review — 95:69-89（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（只有 §71、72、77–80、84–86 有 nissaya；§84、§85 的 nissaya 只是指向前文的说明，没有逐词释义）

## 跨段一致性

- **pāthikaputta**：§69、75、83、84、85（20-40、41-62、90-106、107-130）译「波提子」，§70、76 译「帕提子」，§85-63-83、§85-84-89、§87-35-57、§87-58-78 译「巴提迦子」。三种译法混用 → 统一为「波提子」（出现次数最多）。
- **jāliya**：§70、76 译「闍利耶」，§84 译「贾利耶」 → 统一为一种。
- **bhaggava**（呼格）：§70、76 译「跋葛婆」，§84–89 译「婆迦婆」 → 统一为一种。
- **acela**：§70、76 译「裸形者」，§84–87 译「裸行者」 → 统一为「裸行者」。
- **dārupattikantevāsī jāliyo**：§70、76 译「木钵弟子闍利耶」（定语前置），§84 译「贾利耶——木钵弟子——」（破折号插入） → 三段原文相同，句式应一致。
- **kotthu / siṅgāla / siṅgālaka**：§72、73、74 译「豺狼」，§81、82 译「野狐」，§80 的 kotthu 漏译（见下）。nissaya 统一释作 `မြေခွေး`（野狐/胡狼），没有「狼」的意思 → 全部统一为「野狐」。
- **āvuso**：§69、75 译「朋友」，§83 译「贤友」 → 统一为「朋友」。
- **叠句 Evameva kho tvaṃ … āsādetabbaṃ maññasi**（§69、75、83 原文完全相同）：
  - Evameva kho：「同样地」／「正是如此」
  - sugatāpadānesu jīvamāno：「依靠善逝的足迹生活」／「靠受用本该供养善逝的资具为生」
  - sugatātirittāni bhuñjamāno：「吃着善逝剩下的食物」／「享用善逝的剩余供养」
  
  → 三处应逐字统一。
- **叠句 Ke ca chave …**：§69、75 译「卑贱的波提子算什么？冒犯……又算什么呢？」，§83 译「卑贱的波提子能算什么，冒犯……又是什么呢？」；§74 译「卑贱的豺狼算什么？狮子吼又算什么呢？」，§82 译「卑贱的野狐能算什么，狮子吼又能算什么呢？」 → 句式和标点统一为 §69 的版本。
- **叠句 Tatheva so siṅgālakaṃ anadi**：§73 译「他仍旧只发出豺狼的叫声」，§81 译「这时那只野狐照样嗥叫」 → 统一。§81 的「这时」在原文里没有对应词，应删去。
- **叠句 Yato kho, bhaggava … cāvetuṃ**：§70、76 用「当……时，」，§84 用「就在……时，」；后半句 §70、76 译「离开那个座位」，§84 译「从座位上起身离开」 → 统一。
- **§85 套句 taṃ vācaṃ appahāya taṃ cittaṃ appahāya taṃ diṭṭhiṃ appaṭinissajjitvā**：20-40、41-62、107-130 译「那种言论……那种心念……那种见解」，90-106 译「那句话……那心念……那见解」 → 统一为「那种言论、那种心念、那种见解」。
- **引号嵌套**：§84–89 句首有开引号「“」，§70、76 没有；§69、75 的内层引语没有加 ‘ ’，§83 却只有闭引号「”」，没有对应的开引号。原文层次是：佛陀对跋伽婆说（“ ”）→ 闍利耶说（‘ ’） → 全章引号要按这个层次统一补齐。

## §71 句 95-71-2-10

- **问题**：格与句法误读、取义有误。根据 nissaya：
  - `အညံ= အခြားသတ္တဝါသို့`：aññaṃ 是「向别的野兽」，是 anucaṅkamanaṃ 的跟随对象，不是「别处」。
  - `အနုစင်္ကမနံ= အစဉ်လိုက်လျက် လှည့်လည်ရသော`：意思是「跟在后面走动的」，作定语修饰 attānaṃ。
  - `အတ္ထာနံ= ဆူဖြိုးနေသော မိမိကို`：宾格，意思是「（长得）肥壮的自己」。
  - `ဝိဃာသေ= သောက်ရေအကျန်၌`：处格，nissaya 补注说是池中其他野兽喝剩的水，不是「残羹」。
  
  句意是：「（野狐）在别的野兽喝剩的水里，看见自己跟在别的野兽后面走动、长得肥壮的样子。」现译「看到别处还有可走动的地方」完全误读了 aññaṃ 与 anucaṅkamanaṃ 的句法关系。
- **建议**：改为「它在别的野兽喝剩的水里，看见自己——那个跟在别的野兽后面走动、长得肥壮的自己；」（必改）

## §72 句 95-72-2-11

- **问题**：异释取舍、补出成分。
  - `ဗျဂ္ဃေါတိ= ခြင်္သေ့ဟူ၍`：主释是「狮子」。异释 `ဝါ= ခြင်္သေ့နှင့် ခွန်အားတူသော ကျားဟူ၍` 才是「和狮子一样有力的老虎」。现译取了异释。这里也和 §80 野狐自认 migarājā（`ခြင်္သေ့`）前后呼应。
  - `န ပဿတိ= အမှန်အတိုင်း မမြင်သေး（မြေခွေးဟု မမြင်သေး）`：nissaya 补出的意思是「还没有如实看出自己是野狐」。现译「没看清自己」可以，但「如实」的意思偏弱。
  - 主语 kotthu 见跨段一致性：应作「野狐」。
- **建议**：改为「只要还没有如实看清自己，野狐就一直以为自己是狮子。」「老虎」一解放进脚注备列。

## §77 句 95-77-2-13

- **问题**：词义偏差。
  - `ခလမူသိကာယော= တလင်းကြွက်တို့ကို`：nissaya 补注作「住在打谷场上的老鼠」，「田鼠」不准确。
  - `ဘေကေ= တွင်းအောင်းဖားတို့ကို`：「躲在洞里的青蛙」。可不补，但补出更贴切。
- **建议**：「吃了（洞里的）青蛙和打谷场上的老鼠，」

## §79 句 95-79-2-5

- **问题**：同位关系。nissaya 是 `သုညဝနေ= လူတို့မှ ကင်းဆိတ်သော တောဖြစ်သော` + `မဟာဝနေ= တောကြီးထဲ၌`，suññavane 是修饰 mahāvane 的同位语（「没有人迹的大森林」），不是并列的两个地点。现译「在大森林、空寂的森林中」读起来像两处。
- **建议**：「在没有人迹的大森林里长大，」（次要）

## §80 句 95-80-2-5

- **问题**：主语漏译、人称错误（必改）。nissaya 是：
  - `ကောတ္ထု= မြေခွေးသည်`：主格，「野狐」是 amaññi 的主语。
  - `အဟံ= ငါကား။ မိဂရာဇာ= …ခြင်္သေ့သည်။ အသ္မိ= ဖြစ်၏ဟု`：「我是兽王（狮子）」是野狐心里想的引语（`ဟု` = iti）。
  - `အမညိ= မှတ်ထင်ပြီ`：「以为」。
  
  现译「我曾以为自己是野兽之王」漏掉了主语 kotthu，把引语里的「我」当成了叙述者，整句变成了闍利耶的自白。
- **建议**：「野狐以为：‘我是兽中之王。’」（引号按全章嵌套层次调整）

## §86 句 95-86-2-67

- **问题 1**：词义过泛。`မဟာဝိဒုဂ္ဂါ= ကြီးစွာသော အထူး ခဲခဲယဉ်းယဉ်း ကူးမြောက်အပ်သော ဩဃလေးအင် ရေအယဉ်မှ`：mahāviduggā 是「难以渡过的大暴流（四暴流）」，是从格。`ဥဒ္ဓရိတွာ` 的补注说是把他们安置在涅槃这块陆地上。现译「巨大的困境」丢掉了「渡水」的意象。
  - **建议**：「将八万四千众生从难以渡过的大暴流中救度上岸」。
- **问题 2**：同上，`မဟာဗန္ဓနာ= ကြီးစွာသော ကိလေသာ အနှောင်အဖွဲ့မှ`：这里的束缚是烦恼的大束缚。现译「重大的束缚」可以保留，必要时补「烦恼」。
  - **建议**：可改为「从烦恼的大束缚中解脱出来」（次要）。
- **问题 3**：主语归属。`ပဇ္ဇလိတွာ= အလျှံလွတ်တော်မူ၍`、`ဓူမာယိတွာ= အခိုးလွှတ်တော်မူ၍`：这两个动词用了敬语 `တော်မူ`，施事是佛陀（「我放出火焰、放出烟」），和前面 abhinimminitvā 的主语相同。现译「火焰，燃烧着、冒着烟」把它们读成了火焰的状态。
  - **建议**：「……又化现出另一团七棵多罗树高的火焰，放出火光、放出烟，然后重新出现在大林的尖顶讲堂里。」
- **核对无误**：`သန္ဒိဿေသိံ / သမာဒေပေသိံ / သမုတ္တေဇေသိံ / သမ္ပဟံဿေသိံ` 四个动词的次序和对应关系正确；tejodhātuṃ samāpajjitvā（`တေဇောကသိုဏ်း…စတုတ္ထဈာန် သမာပတ်`）译「进入火界定」可以接受。
