## 跨段一致性

### 同一巴利词译法不一

- **veyyañjanikā**：§492 译“相师们”，§517 译“相士们” → 建议统一为“相师”。
- **akkhambhiyo / khambhanā**：
  - akkhambhiyo 在 §482 两处译“不会被……所动摇”，§496 译“不可阻挡”，§499 译“无法阻挡”。
  - khambhanā 在 §493、§502 译“阻碍”。
  - 同一词根前后分成“动摇”和“阻挡／阻碍”两系 → 建议统一为一系。散文和偈颂说的是同一果报，应当对应。
- **vivaṭṭacchado**：§482 译“揭开世间的覆障”（动宾结构），§506 译“世间的揭去障蔽者”（名词结构） → 同一定型句，建议统一句式和用词。
- **mahāyasaṃ**：§524 译“声名远播的人”，§530 译“大名称的” → 建议统一。“大名称”半文半白，也不通顺。
- **nekkhammachandābhirato vicakkhaṇo**：§501 译“喜好出离，明辨智慧”，§526 译“乐于出离、具有智慧” → 同一偈句，建议统一。
- **sace ca pabbajjamupeti tādiso**：§500 译“如果这样的人出家为僧”，§525 译“而如果这样的人出家” → 同一偈句，建议统一，去掉多出来的“为僧”。
- **anvabhi**：§489 译“享受”，§513 译“经历了” → 建议统一为“享受”。

### 同一定型句前后不一

- **so tena kammena divaṃ samakkami**：§488 译“他因那业，往生天界”，§512 译“由于那样的业，他往生天界” → 建议统一。
- **tato cavitvā punarāgato idha**：§490 译“再度来到这里”，§514 译“再来到这个世间” → 建议统一。
- **kaṭattā upacitattā ussannattā vipulattā**：
  - §481 译“已作、已积集、已增长、已广大”，§505 译“造作、积累、增长、扩大”。
  - 因果框架也不一样：§481 是“由于那业已……”，§505 是“由于造作……这样的业”。
  - → 建议统一。
- **sugatiṃ saggaṃ lokaṃ**：§481 译“善趣天界”，§505 译“善趣、天界” → 建议统一标点。
- **agārasmā anagāriyaṃ pabbajati**：§482 译“从家出家、成为无家者”，§506 译“从家出家为无家者” → 建议统一。
- **rājā / buddho samāno kiṃ labhati**：
  - §482 译“成为国王时，会得到什么？”，§506 译“他成为国王时得到什么呢？”。
  - 对应的 idaṃ labhati：§482 译“这就是成为国王时所得到的”，§506 译“他成为国王时得到这个”。
  - “成佛时”与“他成为佛陀时”也有同样问题。
  - → 两相同构，建议统一整套问答句式。
- **etamatthaṃ bhagavā avoca**：§482 译“这个意义”，§506 译“这个道理” → 建议统一。
- **tatthetaṃ vuccati**：§483 译“于是这样说道”，§507 译“关于这一点，这样说道” → 建议统一。
