## 跨段一致性

本 chunk 中，四大天王的偈颂按东、南、西三方重复出现（§1173–1190／§1191–1205／§1206–1220）。同一句巴利在三处译法各不相同，是本 chunk 最突出的问题。下面以首次出现的译法为基准，建议统一。

### 一、重复偈句译法漂移

- **vītasārada**：§1170、§1172 译「无畏」，§1185 译「无所畏惧」，§1200 译「远离怖畏」，§1218 译「超脱无畏」 → 建议统一为「无畏」。
- **mahantaṃ vītasāradaṃ**：§1172 译「伟大而无畏的」，§1185 译「伟大、无所畏惧的佛陀」，§1200 译「远离怖畏的伟大者」，§1218 译「超脱无畏的伟人」 → 建议统一为「伟大而无畏的（他）」。
- **namassanti**：§1185、§1218 译「致敬」，§1200 译「礼敬」 → 建议统一为「礼敬」，与 namatthu、vandati 的译法一致。
- **purisājañña**：§1186 译「卓越的人」，§1201 译「高贵的人」，§1219 译「人中良驹」 → 三处必须统一为同一个译法，建议「人中良驹」（ājañña 本指良种马）。
- **purisuttama**：§1186、§1201 译「至上的人」，§1219 译「人中至尊」 → 建议与上一项句式配套，统一为「人中至尊」。
- **samekkhasi**：§1187、§1202 译「观照」，§1220 译「观察」 → 建议统一为「观察」。
- **ādiccabandhu**：§1184 译「日种佛陀」，§1199、§1217 译「日种的佛陀」 → 建议统一为「日种的佛陀」。
- **ekanāmāti me sutaṃ**：§1182、§1215 译「据我所闻」，§1197 译「我听说」 → 建议统一为「我听说」（更白话）。
- **indanāmā**：§1183 译「都带因陀罗之名」，§1198 译「都叫因陀罗」，§1216 译「都叫‘因陀罗’」 → 建议统一为「都叫‘因陀罗’」。§1183 的「之名」是文言写法，属必改。
- **Asīti dasa eko ca**：§1183 译「八十加十加一，共九十一人」，§1198、§1216 只译「九十一」 → 三处做法要一致，建议都保留「八十、十、一」的列举。
- **mahabbalā**：§1183、§1198 译「力大无穷」，§1216 译「力大无比」 → 建议统一为「力大无穷」。
- **yasassi**：§1179 译「有名望」，§1194 译「声名显赫」，§1212 译「声名远扬」 → 建议统一为「有名望」。
- **iti naṃ ācikkhatī jano**：§1178 译「人们把…称为」，§1193 译「人们这样指点他」，§1211 译「人们如此指明它」 → 建议统一为「人们这样称呼它」。§1193 的「他」指代有误，naṃ 指方向，应为「它」。
- **samuddo saritodako**：§1176、§1177 译「汇聚众流之水的大海」，§1209、§1210 译「河水汇聚而成的大海」 → 建议统一为「河水汇聚而成的大海」。「众流之水」偏文雅，不如后者白话。
- **ādicco maṇḍalī mahā**：§1173 译「圆轮硕大的阿迭多」，§1206 译「浑圆巨大的日轮」 → 建议统一为「圆轮巨大的太阳（阿迭多）」，或者两处都意译。
- **Ramatī naccagītehi**：§1181 译「喜爱歌舞」，§1196 译「以歌舞为乐」，§1214 译「沉浸在歌舞之中」 → 建议统一为「喜爱歌舞」。
- **purakkhato**：§1181 译「围绕」，§1196 译「围绕拥戴」，§1214 译「簇拥」 → 建议统一为「围绕」。§1214 的「众龙众」重复了「众」字，必改。
- **adhipati**：§1180 译「主宰」，§1195 译「统领」，§1213 译「之主」 → 建议统一为「统领」。
- **Jinaṃ vandatha gotamaṃ**：§1189 译「礼敬…吧」，§1204 译「你们当礼敬」 → 建议统一为「你们礼敬胜者乔达摩吧」。§1204 的「当」偏文言。
- **Vijjācaraṇasampannaṃ buddhaṃ vandāma gotamaṃ**：§1190 保留了主语「我们」，§1205 省略了主语 → 建议统一保留「我们」。

### 二、天王名号体例不一

- §1160 用传统译名「毗沙门」，§1180 用意译「持国天王」，并额外加了「天王」二字，§1195 用新造音译「维卢哈」，§1213 用旧音译「毗楼博叉」。
- 建议四天王统一采用传统意译：持国、增长、广目、毗沙门，名号外加‘’。另外，§1180 的「天王」二字原文没有，应删去。

### 三、同词异译导致语义断裂

- **saṃvarī**：§1174 译「夜色」，§1208 音译为「萨温梨」 → 必改。§1208 应译为「‘夜晚’」，与 §1175 的「‘白昼’」形成对照。
- **方位句**：§1178 明确译出「东方」，§1193 明确译出「南方」，§1211「sā pacchimā disā」却译成「从这里往西，就是那个方向」，没有出现「西方」 → 必改，改为「‘那是西方’」，与前两处平行。
- **方位关系词**：§1173 的 yato 与 §1206 的 yattha 都译成方位，§1191 的 yena 却译成「因那样的行为」 → 与另外两段的平行结构断裂。此处 yena 应作方位解（「在那个方向」），即南方，建议改为「那个方向，人们称为饿鬼所在之处……」一类方位句式。

### 四、格式与标点

- **段号**：§1159、§1160、§1161 译文前有「二八五、二八六、二八七、」，§1173（288）、§1191（289）、§1206（290）却缺段号 → 必改，补上「二八八、」「二八九、」「二九〇、」。
- **引号层级混乱**：佛陀的话用 “”，毗沙门引述的偈颂用 ‘’，偈中再引的话应回到 “”。现状有以下问题：
  - §1173、§1182、§1186、§1191、§1194–1200 等句缺少开头的 ‘；
  - §1184、§1193、§1201、§1206、§1209、§1211、§1213、§1215、§1217、§1219 用了 “，层级错了；
  - §1175、§1177、§1179、§1181、§1172 句末单独加了 ’，其他句没有加。
  
  建议 revise 时按巴利原文的引号位置逐句重排，偈颂每节（每个 ‘ 起头的偈）开头用 ‘，只在整段引语结束处收 ’。
- **偈中引语**：§1177 给「汇聚众流之水的大海」加了引号，§1210 没有加，与巴利原文一致，可以保留。但 §1193、§1211 的内层引号与外层层级冲突，需要一并调整。

### 五、文言残留（必改）

- §1166「于一切处」 → 「在一切处」
- §1183「之名」 → 见上文 indanāmā 一项
- §1210「人们如此认识那里」、§1211「如此指明」 → 「这样」
- §1161「具眼而具吉祥者」、§1167「释迦子而具吉祥者」、§1163「具苦行者」 → 连用「而…者」读起来像文言，建议改为「有眼目、有吉祥的」「释迦之子、有吉祥的」「修苦行的」
