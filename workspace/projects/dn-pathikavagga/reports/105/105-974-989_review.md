# Review — 105:974-989（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 注入的数据中没有任何 nissaya 行，逐句词法复核全部略过；下面只列父层对照与跨段一致性问题）

## 被解释词与父层逐字核对

除下列各项外，其余黑体词都与父层译文逐字相同：怨恨的根由、这在这个人身上哪里能求得到呢、有情居处、能令烦恼寂止、经由烦恼的止息导向涅槃、趣向正觉、某个、次第住、次第灭、使人有所依怙的法、善友、善伴、善侣、易于劝谏、能忍受、善于领受教诫、大大小小、应做的事务、善巧方法、能够去做、能够妥善安排、爱乐于法、乐于为他人说法、论、强盛的欢喜、在善法中、遍／处、上、下、四方、纯一不杂、无量、识遍。

- **abhivinayo**（§987 句 105-987-56-59、105-987-74-76）：本层译「律的深义」。父层 §1639 把 abhivinaye 译作「律」（「对于论和律」），两处不一致，是**必改项**。
  - 难点在于本层 §987 把 vinayo 也译作「律」。如果照父层把 abhivinayo 改成「律」，「法／论／律／律」这组四分就分不开了。
  - 根源是父层把 abhidhamme abhivinaye 只译成「论和律」，丢掉了 abhi- 的层次，而这一层次正是义注 §987 四分（dhammo / abhidhammo / vinayo / abhivinayo）的立论基础。
  - **建议**：回改父层 95-1639-2-34 与 95-1639-35-61，把 abhivinaye 单独译出（例如「殊胜的律」），再让本层 abhivinayo 与之逐字同译。父层回改之前，本层这两句与 105-987-26-41、105-987-77-85 不能视为定稿。
- **Āghātaṃ bandhati**（105-975-23-30）：两个巴利词都是黑体，但译文只把「结」标黑。**建议**改为「“**结怨**”是指……」，黑体范围与父层「结怨」整词对应。
- **dhammo ca desiyati**（105-978-2-13）：黑体只覆盖了「被宣说」，漏了「法」。**建议**改为「“**法被宣说**”是指……」。
- **附带（父层问题，不影响本层）**：父层 95-1619-24-27 把 sattāvāso 译作「有情住处」，与同组其余八处的「有情居处」不一致。本层沿用「有情居处」是对的，建议在父层统一。

## 跨段一致性

- **段号格式**：§975 / §977-980 用「340.」「341.」等阿拉伯数字；§989 用「三百四十六、」。§984 的巴利原文有「345.」，译文却漏了段号。
  - **建议**：§984 补「345. 」，§989 改为「346. 」。
- **章节标题**：
  - §974「九集释义」、§982「九集释义已完毕」、§983「十法品注释」，三处结构不平行：「释义」与「注释」混用，§983 还多出一个「品」字。
  - Navakavaṇṇanā 与 Dasakavaṇṇanā 是同类标题。
  - **建议**：两处统一成同一格式，例如「九集释义」与「十集释义」；或者跟随父层，改为「十法释义」。
- **sāmaggirasa / navakavasena / desanaṃ ārabhi**：§975 与 §984 是完全平行的句式，译法却不一样。

  | | §975 | §984 |
  |---|---|---|
  | sāmaggirasa | 和合的意趣 | 和合的滋味 |
  | -kavasena | 以八法为例 | 以九法之组 |
  | desanaṃ ārabhi | 展开了这段教说 | 开始了这段说法 |

  **建议**：§984 按 §975 的格式统一。「之组」带文言腔，应改掉。
- **kopa**：
  - §975 译「愤怒」（kopaṃ bandhati）。
  - §976 译「反怨」（paṭikopaṃ）、「生怨之事」（kopakaraṇaṃ）、「生起怨恨」（kopaṃ kareyyaṃ）。
  - 这样 kopa 与 āghāta（怨恨）在 §976 混成了一个词。
  - **建议**：kopa 统一译作「愤怒」（「回以愤怒」「发怒这件事」），与 āghāta「怨恨」分开。
- **kasiṇa**：§989 里 kasiṇa 有时译「遍」，有时译「遍相」：
  - 用「遍」的地方：依遍来了知、地遍就只是地遍。
  - 用「遍相」的地方：只向上扩展遍相、其他遍相与之混杂、遍相除去后。
  - **建议**：作为 kasiṇa 本身时统一用「遍」，例如「扩展遍」「遍除去后的虚空」。只有确实指 nimitta 时才用「相」。
- **Tattha**：§975 / §977 译「这里」，§986 / §987 译「在这里」，§984 译「在这方面」。**建议**统一为「这里」。
- **akkhaṇa**：父层定为「不合时宜的、无暇修梵行的时机」，§978「Akkhaṇesu」却译成「在无暇的情况下」，读者看不出这是在指父层那一节。**建议**改为「在无暇修梵行的时机这一节中」。
- **黑体词的引号格式**：多数句子写作「“**X**”是指」，§984（「**使人有所依怙的法**是指」）没有加引号。**建议**统一为「“**使人有所依怙的法**”是指」。

## §984 句 105-984-2-17
- **问题**：漏段号。巴利原文以「345.」开头，译文没有对应的段号。
- **建议**：句首补「345. 」。语体按跨段一致性一节统一为「这样以九法为例说明了和合的意趣之后，现在为了以十法为例说明，再次展开了这段教说。」
