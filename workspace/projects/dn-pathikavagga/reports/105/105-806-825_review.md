# Review — 105:806-825（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 未取到任何 nissaya 单元，逐句词法核对全部略过；本报告只核对被解释词与父层 95:1418-1421 是否一致，以及跨段一致性）

## 跨段一致性

- **sannidhiparivajjanasantosa**：§810 译“远离**积蓄**知足”，§821 被解释词译“远离**积藏**知足” → 必改。§821 是 §810 所列名目的展开说明，两处必须逐字相同。建议统一为“远离积蓄知足”，与 §821 句中的“贮藏”区分开。
- **vissajjanasantosa**：§810 译“**施与**知足”，§822 被解释词译“**给予**知足” → 必改，理由同上。建议统一为“给予知足”，并把 §810 改成“……给予知足”。
- **-kkhetta**：§808、§809 中 piṇḍapātakkhetta 译“钵食的**场所**”，§824、§825 中 senāsanakkhetta 译“坐卧处的**范围**” → 必改，同一构词不应两译。从两处所列的内容看（§809 是各类供食，§825 是“从僧团、从亲属……而得”），都在说“从哪里得来”，建议统一为“钵食的来源”“坐卧处的来源”。
- **ayaṃ … nāma**：§811–§820 都译“这就称为……”，§821、§822 改成了“这就是……” → 统一为“这就称为”。
- **被解释词的引号**：§806、§807 的黑体被解释词不加引号，§808 起改为“**…**”加引号（§823 又不加） → 全 chunk 统一一种体例。建议跟 §806、§807 一样不加引号，只用黑体。
- **cīvara**：父层与 §806 都译“衣服”，§807 作“衣知足”，§817 作“衣中所说” → 建议统一用“衣服”：“对衣服的知足”“关于衣服所说的”。

## §807 句 105-807-10-31

- **问题**：被解释词与父层不一致（必改）。父层 nevattānukkaṃseti 译为“不因这种……而**自我抬高**”，被解释词这里写成“**不因此自我抬高**”，多出的“因此”在父层的这一处并没有逐字出现，读者对不上。
- **建议**：改成“**不**……**自我抬高**”或“**不自我抬高**”，只保留父层原有的字。后半句“是指不这样自我抬高”不用动。

## §806 句 105-806-2-7

- **问题**：被解释词需要核对。父层把 anesanaṃ appatirūpaṃ 译成“不正当的、不如法的追求”，所以 anesanaṃ 在父层是分开写的“不正当的……追求”，原样连起来的“不正当的追求”在父层里找不到。
- **建议**：因为父层被插入语隔开，这样写可以接受。如果要严格逐字对齐，可以写成“**不正当的**……**追求**”。§806 句 79-92“**了知出离的智慧**”、§807 句 91-96“**安住于圣者传统**”情况相同（后者省略了“古老、原始的”），可以保留。

## §808 句 105-808-2-8

- **问题**：格式问题。“**随得的****钵食**”中两段黑体连在一起，渲染后会显示成多余的星号，或者被当成两个词。被解释词“随得的钵食”与父层逐字相同。
- **建议**：合并成“**随得的钵食**”（引号按上面的体例统一）。

## §823 句 105-823-2-17

- **问题**：被解释词的黑体范围不对。被解释词是 piṇḍapātapaṭisaṃyuttāni 整个词，现在只把“钵食”加粗，“与……相关的”留在黑体外面。
- **建议**：改成“**与钵食相关的**头陀支有五种——……”，与 §808“与钵食相关的头陀支”的说法一致。
