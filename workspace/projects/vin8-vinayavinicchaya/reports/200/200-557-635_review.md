- valaya：§597 译“手镯”，§601 译“环” → 统一为“手镯”。
- mocetvā / mocita：§592 译“解开”，§594 译“解下” → 统一为“解开”。

## §562 句 200-562-2-7
- **问题**：误译 — “连同伤害植物的罪在内，都说是犯恶作”读起来像是伤害植物的罪也算恶作。**复注**：bhūtagāmapācittiyena saddhiṃ dukkaṭaṃ（除了伤害植物的波逸提，还犯恶作），并且 api 还把掘地的波逸提也合进来。“也”字漏译。
- **建议**：“除了伤害植物的罪，也说明犯恶作。”复注 201-505-137-142 与 201-505-143-147 的黑体及释文同步改为“**除了伤害植物的罪**”“**也**”。

## §564–565 句 200-564-2-11 / 200-565-2-7
- **问题**：误译 — 三种站位与三条判定界线各自对应，译文把它们混在一起；“在两边掘开的人”把第三种情况当成了总括。**复注**：站在里面掘开的，以外侧边缘；站在外面掘开的，以内侧边缘；两边都站过的，以中间。
- **建议**：§564“站在里面、站在外面、两边都站着掘开的人，”；§565“分别以外侧边缘、内侧边缘、中间来判定。”

## §575 句 200-575-2-7
- **问题**：误译 — “都按物品的价值判为波罗夷”等于说一律波罗夷。**复注**：agghavasena āpattiyo vattabbā，按价值分别判恶作、偷兰遮或波罗夷。
- **建议**：“以及拿取僧团的重物，都按物品的价值判定是否成立波罗夷。”

## §601 句 200-601-2-8
- **问题**：被解释词不符；“有知觉者”偏文言；“环”与 §597 的“手镯”不一致。
- **建议**：“因为是有意识的，这和树根处的手镯不一样。”

## §604 句 200-604-2-10
- **问题**：taṃ 漏译，复注有黑体“**它**”。
- **建议**：“而对方出于羞耻，没有立刻放开它，”。复注 201-520-30-39 黑体同步改为“**出于羞耻**……**没有立刻放开**”。

## §606 句 200-606-2-10
- **问题**：误译 — **复注**：Coropi ākaḍḍhati, so paropi ākaḍḍhati，是盗贼拉、对方也拉。译文写成“盗贼也在拉扯”，漏了对方也在拉扯；“在对方放手之前”是添加的内容。
- **建议**：“盗贼在拉扯，对方也在拉扯，这时还不算犯；”

## §609–610 句 200-609-2-8 / 200-610-2-7
- **问题**：误译 — **复注**把 nentassa 拆成 nento assa，assa 指“这位挑运的人”，所以第一步、第二步是**挑运者**被带离原处的步数。现译读起来像是盗贼自己迈步。
- **建议**：§609“连同挑运的人一起带走物品，他迈出第一步时”；§610 不变。复注 201-522-75-85 黑体同步改为“**带走物品**”。

## §618 句 200-618-2-9
- **问题**：误读结构 — **复注**：yathāvatthuṃ 是对“使它摇动”的判罪，意思是按物品价值相应地犯偷兰遮，不是修饰怎样摇动。现译漏了摇动时所犯的罪。
- **建议**：“使它摇动，就按照所设定的物品判罪；如果使它离开原处，就失坠了；”

## §631 句 200-631-2-6
- **问题**：漏译 — dātabbaṃ（应当归还）没有译出。复注 §529 问“为什么要赔偿”，正是承接这个词。
- **建议**：“物主要求归还时，应当归还；不归还的人就成立波罗夷。”

## §635 句 200-635-2-3
- **问题**：误译 — 复注 §517 把 haraṇaka 释为“别人携带着的物品”，本节讲的是携带物，不是“抢夺”。
- **建议**：“关于携带物的论述。”复注 201-530-2-3 同步改为“关于携带物的论述的解释”，并去掉书名号（其他节题都没有用）。
