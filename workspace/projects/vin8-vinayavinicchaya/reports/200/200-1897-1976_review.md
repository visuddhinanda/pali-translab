# Review — 200:1897-1976（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入）
> 本层是本文 mūla，没有父层，所以不做“被解释词与父层逐字相同”的检查。释义参照改用下一级注释书**复注**《Vinayavinicchaya-ṭīkā》（book=201）。复注黑体引自本层，凡是两边不一致的地方都在下面列出，交给 harmonize 定方向。原则是：复注释义表明本层译错的，改本层；只是措辞不同的，以本层为准回改复注。

## 跨段一致性

- **nissaggiya**：§1906、§1964、§1973、§1976 译“犯尼萨耆”；§1957 译“尼萨耆罪”；§1911 译“应舍的衣服”；§1930、§1933、§1936 译“应舍之物”。建议分两种情况统一：人作主语时用“犯尼萨耆”，衣服作主语时用“成为尼萨耆（应舍）”。“应舍之物”另有文言问题，见 §1930。
- **vatthaṃ**：§1930、§1954 译“衣服”，复注黑体（201-1134-53-58、201-1142-104-110）译“布”。复注专门说明此词是“在结果上借用原因的名称”，指的是衣。本层译“衣服”不算错，但对应关系断了。建议本层统一为“布”，或者复注改用本层译法后单独解释。harmonize 需要二选一。
- **passambhati（nissaya）**：§1930 译“不中断”，§1933、§1936 译“随之中断”。复注黑体译“不止息”，释义又说“依止关系不会解除”。建议三层统一为“解除”：本层用“并不解除”和“也随之解除”，复注黑体改为“不解除”。
- **garu**：§1929 本层译“长老”，复注黑体译“**师长**”，见该句。
- **aññātikā**：§1954 本层译“非亲属的”，复注黑体译“**非亲里的**”。建议统一为传统译法“非亲里”。
- **bhutta**：§1954 本层译“穿过的”，复注黑体译“**穿用过的**”（201-1142-37-59），复注 201-1146 也作“穿用过的布”。建议本层改为“穿用过的”。
- **pakāsitā / dīpitaṃ**：§1957、§1958 都译“说明”，复注黑体把 dīpitaṃ 译作“**已经阐明**”。另有语义问题，见 §1957。
- **ohīne**：§1927 本层译“落在了后面”，复注黑体是“**落在后面**”，差一个“了”。建议复注照本层，或本层去掉“了”，二者逐字一致即可。

## §1899 句 200-1899-2-7

- **问题**：措辞。vuttaṃ 指（律中）所说，“据说”带有传闻的意味，不合语境。
- **建议**：改为“说它是无心、不作为的，具三种心、三种受。”

## §1902–1905 句 200-1902-2-7 / 200-1903-2-7 / 200-1905-2-9

- **问题 1**：句法误读。**复注**说：Ekarattan ti vippavāsakiriyāya accantasaṃyoge upayogavacanaṃ，即“一夜”是修饰“离宿”的持续宾格。现译“哪怕只放置一夜”把“一夜”挂到了 ṭhapetvā（放置）上，等于说“放置的时长是一夜”，偏离了原意。
- **问题 2**：§1902 句末的“三衣”悬空，三行连起来读不通：“在村落等十五种处所，三衣 / 若没有僧团的认可，哪怕只放置一夜，/ 比丘也不可以与它离宿”。
- **建议**：
  - §1902：“把三衣放在村落等十五种处所，”
  - §1903：“若没有僧团的认可，哪怕只是一夜，”
  - §1905：“比丘也不可以与它离宿；”
  - 复注黑体“在村落等十五种处所”“若没有僧团的认可”“不可以与它离宿”保持不变。

## §1908–1909 句 200-1908-2-7 / 200-1909-2-10

- **问题**：语义欠准。**复注**说：nhāyantassevā … anādare sāmivacanaṃ，即这是表示“不顾”的属格，意思是正在沐浴时明相就出现了。“去沐浴”丢掉了“正当……之时”的同时性。
- **建议**：§1908 改为“有比丘夜里放下衣服，正在（远处）沐浴的时候，”。如采纳，复注黑体“**去沐浴**”要同步改。此条非必改，可由 harmonize 斟酌。

## §1917 句 200-1917-2-9

- **问题**：补出成分不准。**复注**说：Nivāsetvāti ettha “antaravāsakan” ti ca gahetvāti ettha “itarānī” ti ca seso，即“穿上”的宾语是下衣，“拿着”的宾语是其余的衣服。现译“穿上并拿着衣服”合成了一件衣服，读者会误以为穿上又拿着的是同一件。
- **建议**：“他应当穿上下衣、拿着其余的衣服，到一位比丘那里去，”

## §1921 句 200-1921-2-9

- **问题**：漏补宾语。“各犯一次”没有说犯什么。
- **建议**：“在披覆等使用上，每一个动作都各犯一次恶作。”

## §1924 句 200-1924-2-8

- **问题**：误译（必改）。**复注**说：Pariyāputan ti “… yo na dadeyya, āpatti dukkaṭassā” ti pāḷiyaṃ vuttanti attho，即 pariyāputaṃ 的意思是“在圣典中说过”，与“披覆”（pārupana）无关。现译“在披覆时犯恶作”是把它误认成了 pārupana。复注自己的黑体也跟着错成了“**在披覆时**”，与它自己的释义矛盾。
- **建议**：“不归还已舍出的衣服的人犯恶作，这在圣典中已经说过。”复注黑体同步改为“**圣典中已经说过**”之类。

## §1929 句 200-1929-2-8

- **问题**：被解释词不一致，释义也不准（必改）。**复注**说：Sace so thero nissayācariyo bhaveyyāti adhippāyenāha “garun” ti，即用 garu 是为了表明那位长老是他的依止师，复注黑体译“**师长**”。本层译“长老”，丢了“依止师”这一层意思，而后文“依止关系”的说法正是以此为前提。
- **建议**：“他还没赶上师长，如果明相就出现了，”

## §1930 / §1933 / §1936 句 200-1930-2-9 / 200-1933-2-9 / 200-1936-2-9

- **问题**：文言用词“应舍之物”（“之”），见上方跨段一致性。passambhati 的译法也要统一。
- **建议**：分别改为“衣服成为尼萨耆，依止关系并不解除。”“衣服成为尼萨耆，依止关系也随之解除。”（§1933、§1936 相同）

## §1938–1939 句 200-1938-2-6 / 200-1939-2-8

- **问题 1**：句法关联错误。**复注**说：Paccuddhāre antoyevāruṇeti iminā sambandho，即“舍除受持”要与“在明相出现之前”连读。现译只把“在明相出现之前”挂在“送出”上，“舍除受持时不犯”就成了不论时间的泛说。
- **问题 2**：vinassati，**复注**释为 corādīhi nassati（因盗贼等而失去）。“损坏”译窄了。
- **建议**：
  - §1938：“在明相出现之前舍除受持，不犯；获得认可的人也不犯；”
  - §1939：“或者在明相出现之前把它送给了别人，或者它已经失去，也不犯。”
  - 复注黑体“送出”“损坏”同步调整。

## §1945–1946 句 200-1945-2-6 / 200-1946-2-10

- **问题**：重复补译。sati paccāsāya 是一个独立属格结构，横跨两行，§1945 已经译出“在有补足希望时”，§1946 又加了“即使有希望”，同一个成分出现两次。
- **建议**：§1946 改为“超过这个期限，就不可以再存放。”复注黑体“**超过这个期限也不可以再存放**”需要对齐。

## §1948–1951 句 200-1948-2-3 / 200-1949-2-5 / 200-1950-2-4

- **问题**：句法误读（必改）。idha 管的是下一行 māsassātikkamo vutto，意思是“这里（第三学处）说的是超过一个月”。现译 §1949 写成“是这里第一迦絺那学处所说的”，又把“这里”安到了第一学处上。§1950 再出现一次“这里”，前后自相矛盾。
- **建议**：
  - §1948：“超过十天，”
  - §1949：“是第一迦絺那学处的情形；”
  - §1950：“这里说的则是超过一个月，”
  - §1951：“其余的都应当认为与它相同。”

## §1954–1955 句 200-1954-2-10 / 200-1955-2-8

- **问题 1**：被解释词不一致，涉及“穿过的 / 穿用过的”“非亲属的 / 非亲里的”“衣服 / 布”三处，见上方跨段一致性。
- **问题 2**：漏译（必改）。tato 没有译出。**复注**说：Tato dhovāpanādito，复注黑体译“**由此**”，指由让人洗等行为犯罪。本层没有任何对应。
- **问题 3**：复注把 ākoṭāpeti 的黑体译作“**让人捶打**”。本层的“让”统摄洗、染、捶打三项，语义上没错，但逐字不对应。
- **建议**：
  - §1954：“比丘如果让非亲里的比丘尼把穿用过的布”
  - §1955：“洗、染或者捶打，由此——”
  - 复注黑体“让人捶打”改为“捶打”，或者由 harmonize 统一处理。

## §1957–1958 句 200-1957-2-8 / 200-1958-2-9

- **问题**：语义误导。“这是由第一项说明的”读起来像是“第一项在解释这件事”。按**复注** Paṭhamenāti … yaṃ paṭhamaṃ kārāpeti, tenāti attho，“第一项”是具格，表示犯罪的依据，意思是以他让人做的第一项犯尼萨耆。pakāsitā 和 dīpitaṃ 的意思是这一判定已在律中宣示、阐明。
- **建议**：
  - §1957：“以第一项，判他犯尼萨耆罪，这是律中宣示的；”
  - §1958：“同样，以其余两项判犯两个恶作，这也已经阐明。”
  - 复注黑体“**已经阐明**”与此对齐。

## §1964 句 200-1964-2-7

- **问题**：主语不明。“就犯尼萨耆”紧接在“在比丘尼中受具足戒之后洗了衣服”后面，容易读成是受戒的那个人犯。实际犯戒的是交衣的比丘。
- **建议**：“她在比丘尼中受具足戒之后才洗，那位比丘就犯尼萨耆。”

## §1973 句 200-1973-2-7

- **问题**：指代不明。前句主语是“她”（比丘尼），这里的“他”缺少先行词。
- **建议**：“只因为洗这一项，那位比丘就犯尼萨耆。”
