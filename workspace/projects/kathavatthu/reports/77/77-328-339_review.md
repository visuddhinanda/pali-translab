# Review — 77:328-339（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入，词级核对从缺）／义注 ✅（book 98 §661–679，《人论·人所作论疏》）

## 跨段一致性
- **so karoti so paṭisaṃvedeti**：§329、§330 译“是同一个人造作，同一个人感受”，§337、§338 四句并列时译“是这个人造作、这个人感受” → 建议统一为“是同一个人造作，同一个人感受”。依据：**义注**（§672）：kiṃ soyeva karoti, so paṭisaṃvedeti（是不是正是那个人造作、那个人感受），重点在“同一”；§676 称后文为 ekatta-aññatta（同一与相异）之问。这句又是义注黑体被解释词（**so karotī**），本文自身有两种译法，义注层无法逐字对齐，必须先统一。
- **neva so karoti na so paṭisaṃvedeti**：§335、§336、§337、§338 都译“既不是这个人造作、这个人感受”。如果按上一条把 so 统一成“同一个人”，这里也要跟着改，例如“既不是同一个人造作并感受，也不是另一个人造作、另一个人感受”。四处同步修改。
- **nerayika dukkha**：§328 同一句里前半译“地狱的苦”，后半译“地狱之苦” → 统一为“地狱苦”（见下条）。

## §328 句 77-328-2-14
- **问题**：风格 — “地狱之苦的感受者”用了文言虚词“之”，和同句前半的“地狱的苦”也不一致。
- **建议**：“169. 既然地狱苦是可得的，那么地狱苦的感受者也是可得的吗？”

## §328 句 77-328-17-25
- **问题**：风格 — “地狱之苦”同上。
- **建议**：“地狱苦是一回事，地狱苦的感受者是另一回事吗？”

## §333 句 77-333-19-29
- **问题**：取义 — 译文用“一起造作……一起感受”，意思变成两人合作造业、共同受报。**义注**（§675）：kārakavedakānaṃ ekatta-aññatta-pucchāvasena vuttaṃ……purime dvepi naye ekato katvā paṭijānāti，意思是把“同一人造作并感受”和“另一人感受”这前两种说法合在一起承认，问的是造者与受者“既同又异”，不是合作。后面的推论“既是自己造成的，又是他人造成的”（§334）也对应这层意思。“一起”属于增译，而且译偏了。
- **建议**：去掉“一起”，例如“是这个人和另一个人都造作，这个人和另一个人都感受吗？”

## §334 句 77-334-2-16
- **问题**：同 §333，“一起”属于误增。
- **建议**：与 §333 同步修改。

## §337 句 77-337-19-53
- **问题**：
  1. 语法与取义 — “是……，是……，是……，还是……吗？”是选择问句，句末不能再加“吗”，属于病句。更关键的是，原文四项之间没有 vā（或），**义注**（§677）：cattāropi pañhā ekato puṭṭhā（四个问题一并提出）；对方答“是的”之后，紧接着被推出四种过失同时成立（sayaṃkatādidosappatti）。所以这是并列问句，要四项同时承认，不是让对方从中挑一项。译成“还是”就把问题的性质译反了。
  2. “一起”同 §333。
  3. so 的译法同跨段一致性第一条。
- **建议**：改成并列问句，例如“同一个人造作、同一个人感受，一个人造作、另一个人感受，这个人和另一个人都造作、都感受，既不是同一个人造作并感受、也不是另一个人造作并感受——这些都成立吗？”

## §338 句 77-338-2-39
- **问题**：与 §337 句 19-53 完全相同（选择问句加“吗”、并列被译成选择、“一起”、so 的译法）。
- **建议**：与 §337 逐字同改。

## §338 句 77-338-42-56
- **问题**：语法与取义 — 同样是“是……，是……，还是……吗？”。**义注**（§677）指出这里是四种过失一并推出，应译成并列。
- **建议**：“乐和苦是自己造成的，是他人造成的，是既由自己又由他人造成的，也是既不是自己造成、也不是他人造成，而是无因偶然生起的——是这样吗？”
