# Review — 77:1749-1756（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅ ／ nissaya ❌（**未注入，本次未做词级核对**）／ 义注 ✅（98:1001-1003，Anāgatañāṇakathāvaṇṇanā）
> 本层是本文（mūla），没有父层，所以不查“被解释词与父层逐字同译”。不过义注的黑体词都引自本段（mūlato / hetu / nidānaṃ / sambhavo / pabhavo / samuṭṭhānaṃ / āhāro / ārammaṇaṃ / paccayo / samudayo / na hevaṃ / anāgataṃ hetupaccayataṃ / gotrabhuno / pāṭaliputtassa）。本文译法定下后，义注层要逐字照抄，所以下面涉及这些词的问题都按必改项处理。

## 跨段一致性
- **nidāna 和 hetupaccaya 都译成了“因缘”**：§1750 把 nidānato 译成“从因缘上”，§1751 把 hetupaccayataṃ 译成“因缘性”。在阿毗达摩里，“因缘”是 hetupaccaya 的固定译名，nidāna 再用它就会和二十四缘的“因缘”混淆。义注层同时出现 **nidānaṃ** 和 **hetupaccayataṃ** 两个被解释词，到那时就分不开了。→ 建议 hetupaccaya 保留“因缘”，nidāna 改译“因由”（或“缘由”）。依据：二十四缘的通行译名，以及义注把 nidāna 释为“交出（果）”的 niyyāteti 义。
- **mūla / hetu / samudaya 的译法与义注释义不对应**：见 §1750 的具体意见。
- 其余“不应这样说……乃至……”“是的。”“对未来有智吗？”各段都统一，没有问题。

## §1750 句 77-1750-11-42
- **问题**：义注释义 / 术语——“从根本上知道”。现代汉语里“从根本上”是副词性的惯用语，意思是“彻底地、根本性地”，读者会理解成“彻底知道未来”，原文“以根（作为原因）的方式知道”的意思就丢了。**义注**：mūlato tiādīni sabbāni kāraṇavevacanāneva（mūla 等十个词都是“原因”的同义词）；又说 mūlayati patiṭṭhātīti mūlaṃ（在那里扎根、安立，所以叫“根”）。义注逐词作词源解释，要求本文把每个词都译成名词，而且十个词要能彼此区分。
- **问题**：语体——“从…上知道”连用十次，“从食上知道”“从缘上知道”读起来很拗口。
- **问题**：术语——samudaya 译成“集起”。义注释为 tato naṃ samudetīti samudayo（从那里集起，所以叫“集”），被解释词是名词 samudaya。四圣谛的“集”是现成译名，“集起”是动词性的说法，和义注层的名词释义对不上。
- **建议**：统一用“从〇知道”的句式，十个名词各自固定下来，例如：“能从根知道未来、从因知道、从因由知道、从生起知道、从起源知道、从等起知道、从食知道、从所缘知道、从缘知道、从集知道吗？”这里 hetu 也从“原因”改为“因”，和十个“原因同义词”的整体格局对齐。

## §1754 句 77-1754-24-61
- **问题**：句法——原文 Nanu vuttaṃ bhagavatā – ‘‘…’’ti!（与上一句 77-1754-20-23 连读）是反诘句，前句是“世尊不是说过——”，引文后面却没有收住反问，句子悬空了。
- **建议**：在出处后补“吗？”，即“…或者来自内部分裂。”［律藏·大品286；长部2.152；自说76］吗？或者调整成“世尊不是说过……吗？”的结构，使两句合读时反问完整。

## §1753 句 77-1753-2-17
- **问题**：省略结构——原文的 pe 是省略号，分别省去了“一来果的证得……对一来果有智吗？不应这样说”等整组问答。译文把三项串进同一个定语，读起来像“为证得一来、不还、阿罗汉果而修行的同一个人”。
- **建议**：保留省略，但让各项各自独立，例如：“正在为证得一来……乃至……不还……乃至……阿罗汉果而修行的人，对阿罗汉果有智吗？”可以改成“一来……乃至……不还……乃至……正在为证得阿罗汉果而修行的人，对阿罗汉果有智吗？”，与巴利语序一致，避免误读。（次要项）

## 存疑（不必改，供定案）
- sotāpatti 译“入流”，与“一来／不还”（玄奘系译名）并用时，汉传常配“预流”。两种都有依据，请在 `terms.md` 里定案，全书统一。
- gotrabhū 译“种姓者”可以接受。若 `terms.md` 另有定案（如“种姓”“种姓智者”），以术语表为准。义注层的 **gotrabhuno** 要逐字跟随本文。
