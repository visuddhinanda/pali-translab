## 理由

**资源降级**：本次注入的数据只有巴利原文和现有译文，没有义注（Kathāvatthu-aṭṭhakathā）和 nissaya。因此准确性只能凭巴利原文与论事（Kathāvatthu）问答体例来核对，无法逐词对照格位和传统取义，信心指数相应压低。`appiyaṃ karitvā`、`esese ekaṭṭhe same samabhāge tajjāte` 这组套语的取义尤其需要事后用义注复核。

**准确性**：
- 问答结构（问 / Āmantā / Na hevaṃ vattabbe）判断全部正确，主谓宾没有误判。
- 肯定与否定的方向逐句核对过，都无误。例如 718 的「不会舍弃色性吗？——是的」与「不会舍弃现在性吗？——不应该这样说」，逻辑与原文一致。
- 两组描写词都逐词对应，没有漏译或多译：
  - 灭尽组 niruddha / vigata / vipariṇata / atthaṅgata / abbhatthaṅgata
  - 未生组 ajāta / abhūta / asañjāta / anibbatta / anabhinibbatta / apātubhūta
- 711 首句「过去的」只加在「受」前，想、行、识前没有补，这与原文的省略一致，不算漏译。
- `… pe …` 统一译为「……乃至……」，处理得当。
- `re`（带呵斥语气的呼格小词）没有译出，但「你就确实不应该说」已经传达了论难语气，可以接受。

**风格**：通篇是现代书面汉语，没有文言虚词或文言句式。标点为全角，引号为弯引号，没有 ASCII 引号，也没有残留的工作标记。「尚未成」带单音节文言色彩，「同分」对一般读者不够透明，各立一条 suggestion。

**一致性**：

- 717 到 720 的「说“X”或者说“Y”……同一个东西、同一个意思、相同、同分、同类」四处逐字相同。
- 「现在性 / 色性 / 白性 / 布性」的构词统一。

## 问题清单

### 🟦 suggestion
- `77-711-19-27`｜语言表达不够流畅｜片段「已经离去」
  - 问题：vigata 在这里指“消失、不复存在”。「离去」带有空间移动的意味，放在识的灭尽语境里略显生硬。
  - 建议：改为「已经消失」。改的话，711-31-46 里的省略引用以及同组的其他出现处要同步调整。
- `77-712-9-18`｜语言表达不够流畅｜片段「尚未成」
  - 问题：单音节「成」偏文雅，与前后的双音节词节奏不协调。
  - 建议：改为「尚未形成」。
- `77-717-2-33`｜不常用术语编写注释或者百科｜片段「同分」
  - 问题：samabhāga 译作「同分」，一般读者难以理解它指什么。这组套语在 718、719、720 反复出现，首次出现时最好加注。
  - 建议：在首次出现处加注，说明它指“部分相同、属于同一部分”。如果义注另有解释，以义注为准。
