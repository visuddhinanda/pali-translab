## 理由

**可用基准有限。** 这次评的是义注层（《论事》义注·补特伽罗论·Purisakārānuyogavaṇṇanā）。上文没有提供以下三样资料：
- **nissaya**：词级核对只能依据巴利原文本身。
- **这一层的复注（ṭīkā）**：没有更高一层的释义标准，只能依据义注本身的文义来判断。
- **父层本文的现行译文**：黑体被解释词有没有和本文译文逐字一致，没法直接比对。这里只能根据巴利文和本段内部的用法来判断。

信心指数因此压低。

**准确性。** 整体理解是准确的：
- 他论者先否认、再承认、再否认的反复结构，译得清楚。
- suttavirodhabhayena（因为害怕与经文相违）和 suttavirodhavaseneva（因为与经文相违）这两个说法区分开了，没有混成一个。
- 四种选项（同一个、另一个、两者都是、两者都不是）的推演，以及落入哪种过失，都没有译错。

扣分主要有两处：
- **673-27-36**：本文里这是自论者的反问，译文改成了陈述语气，读者容易误以为正统一方主张“乐和苦是自己造成的”。
- **674-2-12**：añño 没有译出“另一个”的意思，和 so 的译法几乎分不开。

**风格。** 通篇是现代书面汉语，没有发现文言虚词或文言句式，标点也全部是全角。只有少数地方有翻译腔，或者用词别扭，比如“作出了承认”、“这些的意义”。

**一致性。** 四个选项里 so / añño 的译法前后不统一：
- so 一处译作“这个人”（674-2-13），两处译作“同一个人”（676-2-12、676-105-119）。
- añño 一处译作“一个人”（674-2-12），一处译作“另一个人”（675-2-13）。

这四个选项是并列的一组，被解释词又必须和本文逐字同译，所以这里扣分比较多，需要 harmonize 统一。

## 问题清单

### 🟧 error
- `98-673-27-36`｜导致误解的表达｜片段「就说“**乐和苦是自己造成的**”」
  - 问题：sayaṃkataṃ sukhadukkhan ti 在本文里是自论者向他论者提出的诘问（目的是“堵住他说话的余地”），不是自论者自己的主张。译成陈述句，读起来像是自论者肯定“乐和苦是自己造成的”。这和经中否定“苦乐自作”的教说相冲突，容易引起误解。
  - 建议：保留问句语气，并和本文译文逐字对齐，例如：就问：“**乐和苦是自己造成的吗？**”
- `98-674-2-12`｜错译（词义）｜片段「“**是一个人造作**”」
  - 问题：añño karoti 的 añño 是“另一个”，表示造作者和感受者不同。“是一个人造作”没有译出“另一个”的意思，和 so karoti（“同一个人造作”）在字面上几乎分不开，前后两个选项会被读者混淆。
  - 建议：改为“**另一个人造作**”，并和本文对应问句的译法逐字一致。

### 🟨 warning
- `98-675-2-13`｜关键词语意不明确｜片段「“**这个人和另一个人**”」
  - 问题：so 在这里译作“这个人”，在 676-2-12 和 676-105-119 译作“同一个人”。四个选项并列，so 的译法不统一，读者看不出这是“同一个人”的那个选项。
  - 建议：统一为“**同一个人和另一个人**”（以本文译文为准，三层逐字一致）。
- `98-677-42-47`｜不导致误解的汉语语病｜片段「这些的意义」
  - 问题：“这些的”缺中心语，读起来不通顺。
  - 建议：改为“这些方式的意义”或“这些选项的意义”。

### 🟦 suggestion
- `98-673-2-26`｜语言表达不够流畅｜片段「作出了承认」
  - 问题：这是名词化的翻译腔，和同一段里其他句子的“就承认了”语体不统一。
  - 建议：改为“……就承认了”。
- `98-676-13-48`｜复杂的嵌套句整句语言逻辑理解困难｜片段「所以感受者相对于造作者来说，既不是同一个人，也不是另一个人。基于这种想法，他承认了。」
  - 问题：这一句很长，“相对于造作者来说”这个说法有点绕，读起来吃力。
  - 建议：可以简化为“所以感受者和造作者既不是同一个人，也不是不同的人。他这样认为，就承认了。”
- `98-677-2-8`｜语言表达不够流畅｜片段「四个问题被合在一起来问」
  - 问题：cattāropi 的 pi（全部）没有译出，被动句式也比较生硬。
  - 建议：改为“最后，四个问题全部合在一起来问。”
- `98-678-2-3`｜不常用术语编写注释或者百科｜片段「关于人作为造作者的诘问释义」
  - 问题：purisakāra 的常见意思是“人的努力”。这里按上下文取“人作为造作者”是对的，但读者可能会疑惑为什么不按常见意思译。另外“关于……的诘问释义”作标题偏长。
  - 建议：加一条脚注，说明这里 purisakāra 指补特伽罗作为业的造作者；标题可以考虑精简为“人作者诘问释义”，并和本书其他章题的体例统一。
- `98-679-2-5`｜导致误解的表达（轻）｜片段「这一品的名称」
  - 问题：etasseva 指的是本节诘问。把它称作“品”，等于预先认定这一节是个 vagga，原文并没有这样说。
  - 建议：改为“‘善品’也是这一部分的名称”。
