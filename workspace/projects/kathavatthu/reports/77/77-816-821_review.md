# Review — 77:816-821（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（没有注入，本次没有做词级核对）／义注 ✅（98:796-797，Nasuttasādhanakathāvaṇṇanā）

## 跨段一致性
- 无。下面几组译法在 §816–821 中前后一致：
  - **āmantā**：一律译“是的”。
  - **na hevaṃ vattabbe**：一律译“不应这样说”。
  - **pe**：一律译“乃至”。
  - **khandha / āyatana / dhātu**：一律译“蕴 / 处 / 界”，合称时按巴利原文顺序译“蕴、界、处”。
  - **atīta / anāgata / paccuppanna**：一律译“过去 / 未来 / 现在”。
- 用作名词的 atītaṃ（如 §816 *atītaṃ dhātu*，中性形容词配阴性名词，说明 atītaṃ 是主语）译“过去”；修饰 rūpaṃ 时译“过去的色”。两种用法区分正确。

## 被解释词对应（供义注层翻译时对齐）
本层是本文，没有父层，所以不需要做“被解释词与父层逐字同译”的核对。义注引了本文的以下几处，义注层翻译时要逐字沿用本层译法：
- **atītaṃ khandhā** → “过去是蕴”（§816 句 77-816-2-6）
- **āmantā** → “是的”
- **atītaṃ natthī** → “过去不存在”（§816 句 77-816-2-6）

义注把本文的复合问句拆成两个被解释词来讲（**atītaṃ khandhā** 与 **atītaṃ natthī**）。现在的译文“过去是蕴，过去不存在吗？”两半都能单独认出来，可以保持，**不要改成融合句式**，否则义注层就对不上了。

## §816 句 77-816-2-6
- **问题**：义注释义（建议项，不是必改项）。**义注**：*atītassa khandhasaṅgahitattā*（因为过去被蕴所摄）。按这个解释，问句前半句的意思是“过去属于蕴”，后半句“过去不存在”与它构成对诘。现在的译法用逗号直接连接两个分句，没有古文基础的读者可能读不出两句之间的转折。
- **建议**：可以考虑译成“过去是蕴，而过去不存在吗？”。如果采纳，§816–817 的同类问句（77-816-9-13、27-31、45-49、65-72，77-817-2-6、9-13、39-45 等）要一起改；§820–821 的“……是蕴，……存在吗？”也要同步加“而”，保持全章一致。注意不要改动“过去是蕴”“过去不存在”这两个片段本身（见上一节）。

## 存疑（不涉及译文修改）
- 义注说 *atītaṃ natthīti pucchā paravādissa … paṭikkhepo sakavādissa*（“过去不存在吗”是对方的提问，自论者否定），而本文这一问之后的回答是 *Āmantā*（是的）。这里的 *paṭikkhepo* 应该是指自论者否定过去“存在”，也就是同意“过去不存在”，与本文并不矛盾，但读法需要义注层翻译时确认。译文按本文译“是的”没有问题，**不要改**。
- 没有 nissaya，所以无法从词级核对“atītaṃ khandhā”的格位读法（主格判断句，还是“过去［属于］诸蕴”）。目前按义注译成判断句是成立的。
