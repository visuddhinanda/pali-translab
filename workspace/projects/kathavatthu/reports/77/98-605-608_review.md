# Review：98:605-608（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层对照 ✅（本文 77:109-140）／nissaya ❌（未注入）／复注 ❌（未注入）
> 这次审的是义注层，释义只能拿父层本文和义注自身的上下文来核，没有 nissaya 做词级核对。

## 被解释词对照（父层逐字）

- **rūpaṃ upalabbhati**（98-607-5-26）：这句引的是父层 §127 起首（37-45 是他论者一方）。父层 §127 译作“依真实究竟义**可以找到**色”，现在的译文写成“**色**……**可得**”，两者不同，**必须改**。
  - 改法：把“以“**色**……**可得**”这样”改成“以“**可以找到色**”这样”（父层 §127 就是这个词序）。
  - ⚠ 父层自身不统一：§110-120 和 §132-139 用“以真实究竟义可得”，§121-131 用“依真实究竟义可以找到”。按“父层已定稿、逐字相同”的规则，这里照 §127 改。如果之后对本文做 harmonize，统一回“可得”，这里就恢复“**色**……**可得**”，两层要一起改。

## 跨段一致性

- **本 chunk 内**：没有问题。sakavādī/paravādī 都作“自论者/他论者”，upaladdhisāmañña 都作“同样可得”，saccikaṭṭhasaṃsandana 都作“真实义的对照”（§606、§608），niggaha/paṭikamma-pañcaka 作“驳斥五段/反击五段”，atthato/dhammato 作“在意义上/在法的方面”，前后一致。
- **父层（上游，报给本文 harmonize，不在这里改）**：
  - puggala：§110-136 作“补特伽罗”，§137-139 作“人”。义注 §607 用的是“补特伽罗”，所以父层要统一成“补特伽罗”。
  - upalabbhati：“可得”和“可以找到”混用（见上一节）。
  - Opammasaṃsandana：§109 作“类比对照”，§140 作“譬喻对照”。义注 §605/§608 用“类比”，所以父层 §140 要统一成“类比对照”。
  - Ājānāhi niggahaṃ / paṭikammaṃ：有“请承认你被驳倒了”“你要认清这一驳斥”“你要接受这个反驳”等几种译法，语体也前后不一（“应当”和“应该”、“乃至”和“（中略）”、冒号和破折号混用）。

## §607 句 98-607-5-26

- **问题**：被解释词与父层不一致（见上），**必须改**。
- **问题（次要）**：经文引语“有补特伽罗”是 atthi puggalo 的节引，父层全句是“有为了自身利益而修行的补特伽罗”。现在的写法像是完整引文。
- **建议**：改成“依据“有……补特伽罗”这句经文”，标出这是节引。
- **问题（次要）**：“把与色等同样可得强加到补特伽罗身上”读起来有点绕。
- **建议**：改成“把‘与色等同样可得’强加给补特伽罗”，用引号把要套用的概念框出来。

## §606 句 98-606-43-53／98-606-98-104

- **问题**：风格。“九百二十组驳斥五段”里，“组”和“五段”这两个量词叠在一起，不太顺。
- **建议**：改成“九百二十个驳斥五段”，同句的“反击五段”（98-607-31-38）一起改。
- 注：数字核对没有问题，20 + 132 + 306 + 462 = 920，各项（4×5、11×12、17×18、21×22）都和原文一致。

## §606 句 98-606-56-65

- **问题**：漏译了 tāva（“首先”），这是列举的起始标记。
- **建议**：改成“首先，在诸蕴中……”。这条可以不改，读者理解不受影响。
