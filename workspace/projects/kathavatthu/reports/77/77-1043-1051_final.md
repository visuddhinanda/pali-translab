## 理由
**依据缺失**：本次注入的数据里没有义注（aṭṭhakathā），也没有 nissaya，所以只能拿巴利原文核对，按规定降级评估。凡是需要以义注定释义的地方（比如“自法 / 他法”具体指什么，“paravitāraṇā”的论题背景），都无法核实。信心指数因此压低到 65。

**准确性**：论式的问答骨架（Āmantā / Na hevaṃ vattabbe / Attheva suttanto / Tena hi na vattabbaṃ）译得准确，没有漏译。pe 省略处都对应译成“……（略）……”，位置和原文一致。1045 与 1047 两段的省略方式不同（doso pahīno … pe … moho pahīno 与 doso pahīno, moho pahīno … pe …），译文都照原样区分了。主要问题出在 1048、1049 引的经文“jānatohaṃ … passato āsavānaṃ khayaṃ vadāmi”：属格 jānato / passato 表示诸漏灭尽属于“知者、见者”，译文却处理成“说给知道、见到的人听”，修饰关系弄错了，两处重复出现。其余引经（五蕴、四谛、“sabbaṃ abhijānaṃ”、《宝经》六重罪）取义正确。

**风格**：通篇是现代书面汉语，没有文言虚词或文言句式。全角标点和引号嵌套（“ ‘ ’ ”）都规范，没有残留工作标记。“依他度疑”“自法 / 他法”这几个关键词首次出现时没有夹注巴利原词，也没有注释，普通读者不容易看懂。

**一致性**：“paravitāraṇā”在全章统一译作“依他度疑”，但 1050 结论句改成了“需要由他人度疑”，跟其他三段完全相同的结论句不一致。这是统稿时漏掉的地方。

## 问题清单

### 🟧 error
- `77-1048-15-30`｜错译（修饰关系）｜片段「是对知道、见到的人说的，不是对不知道、没见到的人说的」
  - 问题：jānato / passato 是属格，意思是诸漏的灭尽属于知者、见者（为知者、见者而有）。它们不是“说”的对象。现在的译法把经义变成了“世尊只对知者说漏尽”。
  - 建议：改成“比丘们，我说诸漏的灭尽属于知道、见到的人，而不属于不知道、没见到的人。”
- `77-1049-12-27`｜错译（修饰关系）｜片段「是对知道、见到的人说的，不是对不知道、没见到的人说的」
  - 问题：同上，是同一句引经的同一误读。
  - 建议：与 `77-1048-15-30` 同步修改，两处保持逐字一致。

### 🟨 warning
- `77-1043-2-6`｜关键词语意不明确｜片段「精通他法」
  - 问题：“他法 / 自法”（paradhamma / sadhamma）直译后所指不清楚，读者难以判断是指“他人的事 / 自己的事”，还是“外道教法 / 本宗教法”。缺义注，无法核定。
  - 建议：查义注确定所指，在首次出现时加注说明。

### 🟦 suggestion
- `77-1050-50-58`｜语言风格不统一｜片段「阿罗汉需要由他人度疑」
  - 问题：同一个论题公式，其余各段都译作“阿罗汉有依他度疑”。这里换了措辞，复述对方论点的句子就不再逐字一致了。
  - 建议：统一改成“阿罗汉有依他度疑。”
- `77-1043-2-6`｜该使用而没有使用术语标记｜片段「依他度疑」
  - 问题：本章的核心术语首次出现，没有夹注巴利原词。
  - 建议：首次出现时写作“依他度疑（paravitāraṇā）”，必要时加一条注释说明“由他人帮助度过疑惑”的意思。
- `77-1051-12-25`｜不常用术语编写注释或者百科｜片段「见具足」
  - 问题：“见具足”（dassanasampadā）指证得入流道，“六种极重的罪行”指杀母等六重罪（abhiṭhāna）。不加注释的话，读者很难看出这句引经和“阿罗汉无疑”有什么关系。
  - 建议：加脚注说明“见具足”指入流，被省略的部分包括舍断疑（vicikicchā），并列出六重罪。
