## 跨段一致性
- **iminā / upādāya 都用了“依”**：upādāya 在 §3079、§3080 译“依于”，iminā 在全 chunk 译“依据这个”。两个巴利词用同一个“依”字，读者会以为 iminā 就是 upādāya 的复述。**义注**：iminā = iminā rūpena vā … viññāṇena vā（§2279），又举 iminā chattena vā khaggena vā（凭这把伞盖、这把剑，§2281），是具格“凭借”的意思。建议 iminā 统一译“凭这个”，“依”只留给 upādāya。
- **avakāriṃ karitvā**：§3081、§3085、§3089、§3090 四处都译“不加分别地当作整体”，意思译反了（见下文 §3081），四处要一起改。
- **asmi 与 bhavissaṃ 不对称**：asmi 译“我是”，bhavissaṃ 却译“我将存在”。两者是同一组的现在式和将来式（**义注**：bhavissan tiādīni cattāri anāgatavasena vuttāni，§2271），汉语一个用“是”一个用“存在”，平行关系看不出来。另外“我是”单独出现，语义不完整。建议统一成“我存在／我将存在”，或者都用“是”。要和前面“依于内在的”一节已经定的译法一起定，因为义注 **Asmīti hotī** 是被解释词。
- **“却”的有无**：§3084 译“我却不是那样的刹帝利”，§3088 译“我将不是那样的刹帝利”，少了“却”。两段的句式相同，建议 §3088 也补上“却”。
- **sassata**：标题 asasmi 译“我是常住的”，§3089 正文 sassatosmi 译“我是永久的”。**义注**：Asmīti sassato asmi（§2271），asasmi 的义就是 sassata，两处用词最好一致。建议 sassata 统一译“常住”，或者标题改成“我是永久的”。

## §3079 句 74-3079-2-6
- **问题**：风格。“依于”的“于”是文言虚词，而且“依于外在的”后面缺了中心语，读起来像没说完。

## §3080 句 74-3080-12-96
- **问题**：取义错误（必改）。siyaṃ 四句译成“但愿我存在／但愿我是这样的……”，把它们当成了愿望。**义注**：siyan tiādīni cattāri saṃsayaparivitakkavasena vuttāni（§2271），这四句表达的是疑惑和揣测，不是愿望。真正表达愿望的是 apāhaṃ siyaṃ 四句。**义注**：apāhaṃ siyan tiādīni pana cattāri “api nāmāhaṃ bhaveyyan” ti evaṃ patthanākappanavasena vuttāni。
- **建议**：siyaṃ 一组改为“我或许存在／我或许是这样的／我或许是同样的／我或许是不同的”（也可以用“我会不会……”）。
- **问题**：误译（必改）。apāhaṃ siyaṃ 一组译成“但愿我**也**存在……”，把 api 读成了“也”。**义注**把 apāhaṃ 解释为 api nāma ahaṃ，这里的 api nāma 是表示祈愿的小品词，不是“也”。
- **建议**：去掉“也”，改为“但愿我存在／但愿我是这样的／但愿我是同样的／但愿我是不同的”。
- **问题**：随 iminā 统一（见跨段一致性），“依据这个”改为“凭这个”。

## §3081 句 74-3081-14-43
- **问题**：误译（必改）。“不加分别地当作整体”是 **an**avakāriṃ 的意思（见上一节“依内在的”），本段原文是 avakāriṃ，意思正好相反。**义注**：Niddesavāre pana avakāriṃ karitvāti vinibbhogaṃ katvā（§2280），又说 pañcakkhandhe ekadesato gahetvā iminā ‘ahan’ti chandādīni paṭilabhati，意思是把五蕴拆开、只取其中一部分。“依内在的”一节恰好相反。**义注**：anavakāriṃ karitvāti … avinibbhogaṃ katvā … samūhatova gahetvā（§2275）。内、外两节的分别全在这一个前缀上，译反之后两节就分不开了。
- **建议**：改为“把某一法分离出来——色……受……想……行……识——凭这个而得到‘我是’的欲……”。色到识是任取其一，不要译成五蕴合在一起的列举。
- 另：§3089 原文有异读注 [avakārī (sī.)]，意思不变，不影响译法。

## §3081 句 74-3081-44-61
- **问题**：指代撞车。“有了这个”的“这个”和全段 iminā 的“这个”是同一个词，读者会误以为 tasmiṃ 也指“凭借之物”。**义注**：tasmiṃ … vutte papañcattaye sati（§2276），指的是上面说的欲、慢、见这三种戏论。
- **建议**：改为“这些存在的时候，就会生起这些戏论：……”，或者“有了它们，就会……”。
- **问题**：句子不完整。“依据这个‘我是这样的’”缺了动词，和前后句“依据这个而有……”不一致。
- **建议**：可以补成“凭这个而有‘我是这样的’”，后面各句同样处理。§3082、§3085-39-59、§3086 同理。
