# Review — 97:2028-2033（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层译文对照（74:2458-2511）✅／nissaya ❌（本次没有提供）／释义标准 ⚠️：本层就是义注，没有更上层的释义标准，所以只依据父层译文和巴利原文审查。
> 层次：义注（aṭṭhakathā），解释的是《分别论·智分别》十法第六力（74:2476-2491）。

## 被解释词对照（父层逐字核查）

逐条核对了黑体被解释词，都能在父层 §2476 / §2477 的译文里逐字找到，**没有必改项**。只有一处建议改：

- **§2029 句 97-2029-48-51**：**mahārajakkhā** 译作“**尘垢多的**”，是父层 §2476 “慧眼中尘垢少的还是尘垢多的”承前省略后剩下的部分，单看字面并不算错。但它的对偶词 apparajakkhā 在本句前面完整译成了“**慧眼中尘垢少的**”。现在一个有“慧眼中”、一个没有，两者看起来不对称，读者可能以为它们是不同层面的概念。
  - **建议**：改为“**慧眼中尘垢多的**”。父层 §2476 也应该相应补全（见下文“父层遗留”）。

## 跨段一致性

- **黑体被解释词的引号用法不统一**：§2029 只有“**慧眼中尘垢少的**”加了引号，其余（**意乐**、**随眠**、**所行**……**不堪能的**）都没加；§2030、§2031 基本都加了引号，但 §2030 句 99-108 的 **有性** / **无性** 又没加。→ 建议统一：凡是“被解释词＋是指／就是”的结构，黑体词一律加全角引号“”。
- 其余术语在本 chunk 内前后一致：意乐、住处（nivāsaṭṭhāna / vasanaṭṭhāna）、常见／断见、有见／无有见、依止轮回／依止还灭、观智、道智、……乃至……，没有发现漂移。

## 父层遗留（不是本层的错，但会让被解释词的对应关系断掉，交给 harmonize 处理）

本层的被解释词正确地对齐了父层的论母句 §2476。但父层自己的后文（§2479–2491）对同一组词用了别的译法，读者从义注回查父层的详释段时会对不上：

| 巴利 | §2476 论母（本层所对齐的） | 父层后文的不同译法 |
|---|---|---|
| carita | 所行（carita） | §2479 性行（carita） |
| apparajakkha / mahārajakkha | 慧眼中尘垢少的／尘垢多的 | §2483–2484 眼中尘垢多／少 |
| tikkhindriya / mudindriya | 根锐利的／根迟钝的 | §2485–2486 钝根／利根 |
| svākāra / dvākāra | 行相良好的／行相不良的 | §2487–2488 善相／恶相；§2489 资质良好／不良 |
| suviññāpaya / duviññāpaya | 容易／难以使之领悟的 | §2489 容易／难以使之领会的 |
| bhabba / abhabba | 堪能证入圣道的／不堪能的 | §2490–2491 有能力的／没有能力的 |
| indriyaparopariyatta | 诸根高下 | §2491 诸根胜劣 |

→ 建议 harmonize 时以 §2476 为准，统一父层 §2479–2491。统一时要同步核查本层的黑体词，以及复注里引用这些词的地方。

## §2029 句 97-2029-48-51
- **问题**：准确性（轻）— 原文 *tasseva mahantatāya* 的意思是“由于那（尘垢）大／多”，*eva* 只是强调指代对象就是前句说的尘垢，没有因果上的“正是”意味。
- **建议**：改为“由于这尘垢多，所以称为**慧眼中尘垢多的**”（同时补全被解释词，见上文）。

## §2031 句 97-2031-16-22
- **问题**：可读性 — *ete vā panā* 拆成“**而**……**这**”，两个黑体单字和原文的对应关系虽然可以机械核对，但读者很难看出它在解释什么。
- **建议**：被解释词保持不变，把释义补完整：“其中，“**而**……**这**”，是说“正是这些”（指上文的常见与断见）。”

## §2032 句 97-2032-110-113
- **问题**：风格 — “所以这样说是说得很好的”结构重复，读起来拗口。
- **建议**：改为“所以这个说法是正确的。”或“所以这话说得对。”

## §2032 句 97-2032-114-126
- **问题**：漏译（轻）— 句首的 *Idaṃ*（指“这种意乐”）没有译出，*appavattikkhaṇe* 中的“刹那”也被泛化成了“时候”。
- **建议**：改为“而世尊了知众生的这种意乐，即使在这些见、观智、道智都没有生起的刹那，也照样了知。”

## §2033 句 97-2033-29-63
- **问题**：OCR／原文疑问 — 巴利原文“ālokasaññaṃ nekkhammaṃ sevantaññeva jānāti sevantaññeva jānāti”中，*nekkhammaṃ* 和 *sevantaññeva jānāti* 疑似重复衍文；句末的 `’’` 和开头的单引号 `‘` 也不配对。译文已经正确略去了重复部分，不用改。记入 `known-issues.md`（OCR／原文问题）。
- **问题**：可读性（轻）— “瞋恚……乃至……无瞋恚……昏沉睡眠……乃至……”是一串光秃秃的名词，和后半句“正当一个人亲近光明想的时候”在语法上接不上。
- **建议**：把句式补完整：“正当一个人亲近瞋恚……乃至……无瞋恚……昏沉睡眠……乃至……光明想的时候，世尊就了知：‘……’”

## §2033 句 97-2033-2-16 / 17-28
- **问题**：风格（轻）— “胜解于欲”“胜解于出离”是“动词＋于”的格式，带一点半文言的味道。
- **建议**：改为“对欲起胜解”“对出离起胜解”，和父层 §2498 “只对‘净’起胜解”的句式一致。
