# Review — 74:67-78（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入）
> 本层是本文（mūla），没有父层，不用核对被解释词。缺少义注和 nissaya，所以这份意见**没有核对义注释义，也没有核对 nissaya 的格与句法**。下面只涉及准确性、术语、风格和跨段一致性，拿到两项资源后应再补审一遍。

## 跨段一致性

- **-viññeyya 系列（§68 / §74 / §75 / §76）**：§68 译作“可由六识**识知**的”，§75、§76 译作“可由意界**识知**的”“可由意识界**识知**的”，但 §74 的 manoviññeyyaṃ 译作“可由**意识知**的色”。
  - 这句读者很容易断成“意识 + 知”，也就是理解为“意识（manoviññāṇa）所知”，和 §75 的 manoviññāṇadhātuviññeyya（“意识界识知”）撞在一起。实际上 §74 说的是意（mano）所识知，与 §75 把意界、意识界分开讲是两回事。
  - 眼、耳、鼻、舌、身各项的“可由眼识知”也有同样的歧读，可以理解成“眼识 + 知”。
  - 建议整组统一成“X 所识知的色”：§74 作“眼所识知的色……意所识知的色”，§75、§76 作“意界所识知的色、意识界所识知的色”，§68 作“六识所识知的”。
- **upādā 否定式（§71 / §72）**：§72 肯定式用“凡是所造的色”，否定式用“凡不是所造的色”，一对句子不对称。建议否定式改为“凡是非所造的色”，与肯定式对齐。

## §68 句 74-68-9-121

- **问题**：风格（文言虚词）— nevavipākanavipākadhammadhammaṃ 译作“既非异熟也非异熟法**之**法”。这里的“之”是文言结构助词，属于 style.md 禁例。
- **建议**：改成“既非异熟、也非异熟法的法”，或改成“既非异熟、也非具有异熟性质的法”。

## §68 句 74-68-9-121

- **问题**：术语辨异（存疑）— parāmaṭṭhaṃ 译作“被执取的”。同一段里 upādāniyaṃ 译“顺取”，§69 的 upādinnaṃ 译“有执受”。“执取”一词同时碰上了“执”和“取”，而这三个词分别来自 parāmāsa、upādāna、upādinna 三个不同的概念，读者会以为它们互相关联。
- **建议**：parāmaṭṭha 换一个不带“取”的译法，比如“被执著的”或“被固执的”。定下来后登记到 terms.md。等拿到义注再确认。

## §68 句 74-68-9-121

- **问题**：风格（列举体例）— 同一个长列举里，有的项带“的”（世间的、被执取的、小的、欲界的、系属的、不定的……），有的不带（非因、无因、有缘、有为、有漏、顺结、无记……），显得杂乱。
- **建议**：统一体例。一种是全部用术语式、不加“的”（如“世间、小、欲界……”），另一种是统一加“的”。前一种更接近汉译论书的惯例。

## §69 句 74-69-2-23

- **问题**：体例（存疑）— 校勘注〔nupādā（锡兰本、柬埔寨本）〕直接写进了正文。另外，“ka.”对应哪个底本还没有核实，不能确定是“柬埔寨本”。
- **建议**：先核对 VRI 的版本缩写表，确认 ka. 指的是哪个本子。项目需要定一个统一规则：异读是放进脚注，还是留在正文方括号里。

## §69 句 74-69-111-118

- **问题**：术语（轻微）— ajjhattikaṃ / bāhiraṃ 译作“内在的 / 外在的”。汉译论书一般作“内 / 外”，而“内在”在现代汉语里偏向心理、抽象的意思。
- **建议**：改为“内的 / 外的”，然后登记到 terms.md，全书统一。

## §70 句 74-70-2-12

- **问题**：背景（轻微）— 《色品》指的是《法集论》（Dhammasaṅgaṇī）的色品。单独读的话，读者不知道它出自哪一部书。
- **建议**：可以改成“《法集论·色品》”。最好等义注确认出处后再改。
