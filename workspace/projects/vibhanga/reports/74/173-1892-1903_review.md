# Review — 173:1892-1903（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层译文（复注 173:761-817）✅／nissaya ❌（本次没有注入，词级核对只依据巴利原文）／义注 ❌（本层是复复注，释义标准改用已定稿的父层复注）

## 被解释词与父层对照（逐字核对）

以下黑体词都与父层译文逐字相同，**没有必改项**：
- 擅自处分重物 / 用来抵偿重物的 / 补偿 / 前面所说的 / 抱持，或者养育
- 说的是替在家人做这种事 / 以食换食 / 为了得到食物 / 不如理地处置
- 牛 / 抖落 / 就可以除去的 / 以自制来处理的 / 以防护来处理的 / 不构成犯
- 指的是就功德而言的比丘 / 凭某一次受持就受持了全部的学 / 多次受持
- 以不违犯……乃至……等方式 / 因为违犯而有所残缺

需要留意的一处：173-1903-77-80 的 **Tan**。父层 779-48-70 的译文没有把 taṃ 单独译出（只写成“那么即使只有一次”），所以本层的“**它**”在父层里找不到可以对应的字。见下文该句。

## 跨段一致性

- **pātī / pātīni**：§1892 译成“堕落处”（指六处），§1893 译成“堕落者”（指轮回）。轮回不是人，用“者”会误导读者。建议 §1893 改成“有堕落的”（pātī），和 §1892 的“堕落处”区分开，同时不带人称意味。
- **saṃyama-**：父层的黑体用“自制”（以自制来处理的），§1902-23-58 同一句里却又用“节制”译 saṃyamanīya / saṃyamana / saṃyama。同一个词根在一句里出现两种译法，读者看不出“以自制来处理的”解释的是哪个词。建议统一成“自制”。
- **patimokkha**：§1894、§1895、§1896-2-16 都保留转写 patimokkha，§1896-21-28 却把 anavajja-patimokkhaṃ 译成“无过失的解脱”，词源链断了。建议统一保留转写。
- **sikkhā**：本 chunk 和父层都译成“学”，只有 §1903-51-76 把 upasampanna-sikkhā 译成“学处”。建议改为“学”，因为“学处”在本层对应的是 sikkhāpada（§1903-117-137）。
- **出典称呼**：§1892 引的是《相应部》，写“经中说”没有问题；§1894-45-62 引的是 mahāva.135（律藏《大品》），也写成了“经中说”，层次不对。见下文。

## §1893 句 173-1893-2-15
- **问题**：误导性措辞。pātī 在这里是“具有堕落的”（-ī 表示具有，见 assa atthīti），指的是轮回；译成“堕落者”像是指人。
- **建议**：改为“或者，它具有堕落、坠落，所以称为‘有堕落的’（pātī），这指的是轮回；……”。

## §1894 句 173-1894-45-62
- **问题**：出典层次错误。mahāva.135 是律藏《大品》（布萨犍度），不是经，写“经中说”不对。《大品》单独出现时也容易和别的《大品》混淆。
- **建议**：改为“正因为这样，律中说：……（《律·大品》135）”。

## §1895 句 173-1895-58-75
- **问题**：语体。“随其所应地”带文言色彩。另外，原文的 kilesanibbāpanato 是整句的理由，译文只把它挂在后半句上。
- **建议**：“随其所应地”改为“按各自的情况”。可以考虑把理由提到前面：“因为它按各自的情况让烦恼熄灭，所以属于抉择分的戒防护就像日出前的曙光，是涅槃的升起，好像是涅槃的对应物……”。不调整也可以，但要注意语序不要显得因果断开。

## §1896 句 173-1896-21-28
- **问题 1**：术语前后不一致。anavajjapatimokkhaṃ 译成“无过失的解脱”，丢掉了 pati，和上文一连串 patimokkha 的词源解释接不上。
- **问题 2**：文言虚词“之”（“波罗提木叉之主”）。
- **问题 3**：存疑。jinapātimokkho 的结构不清楚，译文补出“作为波罗提木叉之主”属于推断。这一点应当在报告里存疑，并压低该句的 confidence，而不是让译文显得很确定。
- **建议**：改为“至于要从一切方面来解说这无过失的 patimokkha，也就是波罗提木叉，只有胜者的波罗提木叉的主人——世尊——才能做到”，或者用更稳妥的“只有世尊才能做到”，把 jinapātimokkho 的理解留到报告里讨论。
- **原文疑问**：Sabbākaārena 疑为 sabbākārena 的讹写，只记录，不改。

## §1897 句 173-1897-2-9
- **问题**：同一句里的词源和被解释词不一致：前面写“以处分重物的行为为成因”，黑体写“**擅自处分重物**”，前面少了“擅自”。
- **建议**：前面改为“以擅自处分重物的行为为成因”。

## §1900 句 173-1900-2-13
- **问题**：漏译了词源的关键。原文 Gacchanti 是 gāvo（go）的词源（“走、行”），译文只留下“运转”，读者看不出为什么叫“牛”。
- **建议**：改为“它们‘行走’，也就是在各自的境界中运转，所以称为**牛**（gāvo），也就是眼等诸根”。

## §1902 句 173-1902-23-58
- **问题 1**：saṃyama 前后不一致（见跨段一致性一节）。
- **问题 2**：标点。“所以说‘**不构成犯**’的”里，“的”落在引号外面，读起来不通。
- **建议**：改为“或者，应当自制的就是**以自制来处理的**；心里下定决心‘以后不再这样做了’，这种自我约束就是自制；应当以自制来处理的，就是**以防护来处理的**。注释师认为，自制和防护都只取决于心，所以说‘**不构成犯**的’”。

## §1902 句 173-1902-59-69
- **问题**：称谓含糊。antevāsikatthero 指的是上一句“注释师”（ācariya）的弟子，只译“弟子长老”，读者不知道是谁的弟子。
- **建议**：改为“而注释师的弟子长老则认为……”。

## §1903 句 173-1903-30-50
- **问题**：Tathā ca vuttaṃ 是“也正是这样说的”，起佐证作用，不是因果；译成“所以”逻辑不对。标注“义注”是对的（vibha.aṭṭha）。
- **建议**：改为“义注也正是这样说的：……”。

## §1903 句 173-1903-51-76
- **问题**：sikkhā 译成了“学处”，和本句黑体及父层的“学”不一致。
- **建议**：“……就毫无遗漏地受持了已受具足戒者的全部的学那样”。

## §1903 句 173-1903-77-80
- **问题**：对应关系弱。父层译文没有单独译出 taṃ，“**它**”在父层里找不到可以逐字对应的字，读者看不出这条注在注哪个词。
- **建议**：不算必改。可以在 harmonize 时考虑把父层 779-48-70 补成“那么这个受持即使只有一次……”，再让本层黑体改为“**这个受持**”；或者维持现状，在报告里注明。
