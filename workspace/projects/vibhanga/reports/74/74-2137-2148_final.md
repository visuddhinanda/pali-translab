## 理由

**资源情况**：本次只有巴利原文和现有译文。义注（aṭṭhakathā）与 nissaya 都没有提供，所以准确性只能凭巴利原文和阿毗达摩论母的通行译法来核对，没有经过释义标准与词级基准的校验。信心指数因此下调。

**准确性**：这 12 句都是“论母二法”式的对举短语（X paññā / 非 X paññā），句法结构简单，主谓宾不成问题。各句对照如下：

- **2137–2141**：savicāra / sappītika / pītisahagata / sukhasahagata / upekkhāsahagata 分别译作“有伺”“有喜”“与喜俱行”“与乐俱行”“与舍俱行”，用的是通行译法，词义无误。
- **2142–2144**：na kāmāvacarā 等译作“非欲界的慧”，否定词的位置与原文一致。
- **2145**：pariyāpanna 译作“属于三界的”。这是释义式译法，与义注所说的 tebhūmaka（三界所摄）相合，取义没有错。不过它把注释内容直接放进了正文，没有保留术语的原形，见问题清单。
- **2146 / 2148**：niyyānika 译作“导向出离的”，sauttara / anuttara 译作“有上 / 无上”，都无误。
- **2147**：niyata 译作“决定的”是传统译法，可以接受。但单看译文，读者无法知道是“在什么方面决定”（义注指果报决定，主要就道慧而言）。

漏译和错误多译：没有发现。

**风格**：现代书面汉语，没有文言虚词或文言句式。标点为全角，没有残留工作标记。

**一致性**：

- 否定的处理有一条清楚的规则：na 译“不 / 非”，前缀 a- / an- 译“无 / 不”，两类没有混用。
- 术语夹注不统一：同为法相术语，只有 2147 加了 niyata 的夹注，2145（pariyāpanna）和 2146（niyyānika）都没有加。

## 问题清单

### 🟦 suggestion
- `74-2145-2-9`｜不常用术语编写注释或者百科｜片段“属于三界的慧，不属于三界的慧”
  - 问题：pariyāpanna / apariyāpanna 直接按义注意思译出，正文里丢掉了“所摄 / 非所摄”这组术语的原形。读者无法把它和其他论典里的同一术语对应起来。
  - 建议：可以保留现译，同时在首次出现处夹注“（pariyāpanna）”，或加脚注说明“指三界所摄；不属于三界，指出世间”。也可以改为“（三界）所摄的慧，非所摄的慧”并加注。
- `74-2147-2-9`｜关键词语意不明确，或二意场合没有注释｜片段“决定（niyata）的慧”
  - 问题：单说“决定的慧”，没有说明是在哪方面决定（果报决定）。一般读者容易理解成“确定无疑的慧”。
  - 建议：加脚注说明 niyata 指果报决定（主要就道慧而言）。补进义注以后，以义注的解释为准。
- `74-2145-2-9`｜语言风格不统一｜片段“属于三界的慧”
  - 问题：同一组法相术语，2147 夹注了巴利原词，2145 和 2146 都没有，处理不统一。
  - 建议：由 harmonize 统一体例：要么三处都在首次出现时夹注（pariyāpanna / niyyānika / niyata），要么都不夹注、改用脚注。
