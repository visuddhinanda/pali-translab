## 理由

**资源情况**：本次评的是义注层（book 97 Kāyānupassanāuddesavaṇṇanā）。上文没有注入这一层对应的释义标准（复注 ṭīkā），也没有 nissaya，所以只能拿巴利原文逐句核对，无法借复注确认取义、也无法借 nissaya 核对格与句法。信心指数因此下调。另外，黑体被解释词（sampajāno / satimā / vineyya loke abhijjhādomanassaṃ / vineyyā / loke）是否与本文层逐字同译，上文没有本文译文可比对，这一项没有核实，需在 harmonize 报告里另行确认。

**准确性**：全部 21 句都对上了原文，没有发现漏译、多译，也没有主谓宾判断错误。难点句处理得比较好：
- 1117-15-32 / 33-70 的 yasmā…tasmā 句子中间插了一段经文引文，因果链条在译文里保留住了。
- 1117-71-97 的 upāyāpariccāge anupāyāpariggahe（不放弃正确方法、不抓取错误方法）这对双重否定，取义准确。
- 1119-2-36 的三组 abhijjhā / domanassa 对举，六项的所属关系都没有弄错。

扣分集中在两处：一是 kāyabhāvanā 译成“修身”，在现代汉语里有歧义；二是被解释词 vineyyā 下的释语 vinayitvā 用“来调伏”，没有保住完成义。

**风格**：通篇是现代书面汉语，没有文言虚词或文言句式。标点全部是全角，引号都是弯引号，没有 ASCII 引号残留，也没有工作标记残留。有少数句子稍嫌生硬（1118-25-36 两次“这里”叠用；1120-17-22“用所说的住”语义不够透明）。新出现的法相术语（彼分调伏、镇伏调伏、相应支、舍断支）没有按 style.md 的要求在首次出现时夹注巴利原词。

**一致性**：yoga 系词语的译法不统一：yogāvacara 作“瑜伽行者”，yoga 作“修行”，ayaṃ 补作“修行者”，kammaṭṭhānika 作“修业处者”。“瑜伽行者”在汉语佛学语境里容易联想到瑜伽行派，建议统一为“修行者”一类的说法。其余术语（念、正知、精勤、随观、业处、舍断、贪忧）在四段内前后一致。

## 问题清单

### 🟨 warning
- `97-1119-2-36`｜关键词语意不明确｜片段「对修身的不喜好」
  - 问题：kāyabhāvanā 指“对身的修习（身随观）”。“修身”在现代汉语里是固定词，指儒家式的品德修养，读者容易理解偏。
  - 建议：改为“对身的修习不感兴趣”或“对修习身随观不喜乐”。

### 🟦 suggestion
- `97-1118-16-24`｜语言风格不统一｜片段「来调伏」
  - 问题：被解释词 vineyyā 译作“调伏了”，释语 vinayitvā 却作“来调伏”，完成义丢了，和 1118-37-42 的“调伏了贪忧”也不一致。
  - 建议：改为“是指通过彼分调伏或镇伏调伏而调伏了”。
- `97-1118-16-24`｜不常用术语编写注释或者百科｜片段「彼分调伏或镇伏调伏」
  - 问题：tadaṅgavinaya / vikkhambhanavinaya 是法相术语，首次出现没有夹注巴利原词，普通读者不容易明白。
  - 建议：改为“彼分调伏（tadaṅgavinaya）或镇伏调伏（vikkhambhanavinaya）”，必要时加脚注简释。
- `97-1118-2-15`｜不常用术语编写注释或者百科｜片段「相应支」
  - 问题：sampayogaṅga / pahānaṅga（相应支／舍断支）首次出现没有夹注原词。
  - 建议：改为“相应支（sampayogaṅga）”“舍断支（pahānaṅga）”。
- `97-1119-37-44`｜语言风格不统一｜片段「瑜伽行者」
  - 问题：同一组文字里，yoga 译“修行”，ayaṃ 补作“修行者”，yogāvacara 却用“瑜伽行者”，称谓不统一，而且容易让人联想到瑜伽行派。
  - 建议：改为“修行者”，或在 terms.md 定下一个译名后统一使用。
- `97-1118-25-36`｜语言表达不够流畅｜片段「在这个词里，那个被把握、分为内在等类别的身，在这里就叫作世间」
  - 问题：ettha 与 idha 都译成“这里”，读起来重复。
  - 建议：改为“‘世间’：被把握的、分为内在等类别的那个身，在这里就叫作世间。”
- `97-1120-17-22`｜语言表达不够流畅｜片段「在“住”这里，用所说的住」
  - 问题：句式和前后句（“在‘精勤’等词里”）不平行；“所说的住”具体指什么，读者不清楚。
  - 建议：改为“在‘住’这个词里，用这里所说的住（即威仪上的安住），说出了修业处者对身的维持。”
- `97-1117-71-97`｜语言表达不够流畅｜片段「他的那个业处」
  - 问题：“他的那个”是直译 assa taṃ，汉语里显得累赘。
  - 建议：改为“因此他的业处就无法成就”。
