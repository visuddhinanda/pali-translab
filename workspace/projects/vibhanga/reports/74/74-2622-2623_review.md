# Review — 74:2622-2623（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入，本次没有做词级格位核对）／义注 ✅
> 义注说明：本段对应的义注是 97:2156（§881 卑慢的解说），原文为：Omānaniddeso hīnamānaniddesasadisoyeva。意思是卑慢的解说与劣慢的解说完全相同，所以被解释词的对照以 97:2146（§868 劣慢的解说）为准。事由列表（jātiyā … dhanena）对照 97:2144（§866 胜慢的解说），vijjāṭṭhāna / suta 对照 97:2163（§884 邪慢的解说）。这几段义注黑体引出的本文词形和本段完全一样。

## 跨段一致性

本 chunk 只有两段，内部没有漂移。下面列的是和其他章节（胜慢、等慢、劣慢、邪慢）共用词的对应问题，这些位置需要在 harmonize 时一起统一：

- **gotta**：本段译“族姓”，义注 97:2063 用“依**族姓**”，97:2144 却用“以**姓氏**”，义注自己就前后不一致。→ 建议全书统一为“族姓”（本段维持不变，97:2144 改成“族姓”）。依据：族姓憍、族姓解释等处都已经用“族姓”。
- **vijjāṭṭhāna**：本段译“学问领域”，义注 97:2163 的黑体是“恶的**学问**”。→ 建议统一为“学问”。
- **suta**：本段译“博学多闻”，义注 97:2163 的黑体是“恶的**所闻**”。→ 建议统一为“所闻”（理由见下面 §2623 句 9-37）。
- **ayaṃ vuccati**：本段译“这称为”，义注全书的黑体都译成“**这叫作**”（97:2063、2086、2087、2088、2157 等）。→ 建议统一为“这叫作”。

## §2623 句 74-2623-38-57

- **问题**：被解释词和义注不对应（必改）。97:2146 的黑体词与本句译法逐一对照：

  | 巴利 | 本文译 | 义注黑体译 |
  |---|---|---|
  | omaññanā | 自我看低 | **自卑** |
  | omaññitattaṃ | 自我看低的状态 | **自卑的状态** |
  | hīḷanā | 轻视 | **轻贱** |
  | ohīḷanā | 贬低 | **深自轻贱** |
  | ohīḷitattaṃ | 贬低的状态 | **深自轻贱的状态** |
  | attuññā | 自我贬抑 | **自轻** |
  | attavaññā | 自我轻视 | **自蔑** |
  | attaparibhavo | 自我轻侮 | **自辱** |
  | ayaṃ vuccati | 这称为 | **这叫作** |

  omāno（卑慢）一致。
- **问题**：取义偏差（义注释义）。**义注**：hīḷanā ti jātiādīhi attajigucchanā（因出身等而厌恶自己）；ohīḷanā ti atirekato hīḷanā（格外地轻贱自己）。可见这三个词在卑慢里都是**指向自己**的。本文译成“轻视、贬低、贬低的状态”，没有宾语，读者很容易理解为轻视、贬低别人，和义注相反；“自我看低”这一组前面带了“自我”，到这里又去掉了，句内也前后不一致。
- **建议**：被解释词全部对齐义注译法，整句改为：“凡是这样的卑慢、自卑、自卑的状态、轻贱、深自轻贱、深自轻贱的状态、自轻、自蔑、自辱——这叫作‘卑慢’。”如果译者认为义注的译法（如“自蔑”“自辱”）太简省，要改的话就两层一起改，不能只改一边。

## §2623 句 74-2623-9-37

- **问题**：被解释词和义注不对应（必改）。97:2144 的黑体词：**以出身**／**以姓氏**／**以名门子弟的身份**／**以容色美好**／**以财富**。本句译成“因为出身／因为族姓／因为出自名门／因为容貌美好／因为财富”，有三处不同：
  - kolaputtiya：“出自名门”和“名门子弟的身份”不同
  - vaṇṇapokkharatā：“容貌美好”和“容色美好”不同。**义注**：vaṇṇasampannasarīratāya（身体具足美好的容色），vaṇṇa 取的是“容色”，和 97:2073“依**容色**”一致
  - 格的处理：本文用“因为”，义注用“以”
- **建议**：vaṇṇapokkharatā 改为“容色美好”。kolaputtiya 两层统一为“名门子弟的身份”或“出身名门”中的一种。具格的“因为／以”在胜慢、等慢、劣慢、卑慢四段本文和 97:2144 之间统一成一种：本文是一长串并列，用“因为”读起来更通顺，建议改义注一侧。gotta 见跨段一致性。
- **问题**：suta 译成“博学多闻”有增译。suta 是“所闻、学识”，本身不带“博、多”的评价；在卑慢里，正是学识不足让人自卑，译成“博学多闻”反而和语境冲突。义注 97:2163 黑体作“**所闻**”。
- **建议**：改为“或因为所闻”。
- **问题**：vijjāṭṭhāna 译“学问领域”，和义注 97:2163 黑体“**学问**”不同。
- **建议**：改为“学问”。
- **存疑（不需要改）**：ajjhena 译“学习经典”，义注没有解释，传统上指诵习吠陀等典籍，现在的译法可以接受。这一句没有 nissaya 核对，格位判断只依据巴利原文。
