# Review — 74:1691-1702（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入，本次未做词级格位核对）／义注 ✅（book 97，Vibhaṅga-aṭṭhakathā·Jhānavibhaṅga 释，仅有巴利原文，**没有义注中文译文**）
>
> 层次说明：本 chunk 是本文（mūla），没有父层，所以本文本身不需要做被解释词逐字核对。但义注里有一批黑体词引自本 chunk（Thinamiddhaṃ / Santā hontī / Sato sampajāno / cattattā……pahīnapaṭinissaṭṭhattā / Uddhaccakukkuccan / Vūpasantacitto 一系），本文译法定稿后就是义注的锚点。下面的必改项改完以后，harmonize 要以修订后的本文译法为准，去对齐义注。

## 跨段一致性

- **vūpasanta**：在 §1701-2 的标题词“心已寂静”和 §1701-42 的“内心已寂静”里译作“寂静”，在 §1698-35 和 §1701-34 的同义词串里却译作“寂灭”。结果标题词“心已寂静”的释文变成“寂静的、止息的、寂灭的”，读者会以为“寂静”对应的是 santa，被解释词和释文的对应关系断了。**必改**。建议统一为 santa＝平静、samita＝止息、vūpasanta＝寂静。
- **santa**：§1698-35 译“平息”，§1701-34 译“寂静”，建议统一为“平静”（理由同上，见 §1701 句 34-41）。
- **ajjhattaṃ**：§1701-34 译“在内部”，§1701-42 译“内心”，建议统一。另外“内心”已经被 §1698 的 manovilekhā 占用（见 §1698 句 6-34），ajjhattaṃ 最好固定为“于内”或“内在地”。
- **moceti / vimoceti / parimoceti**：§1695 译作“解脱、脱离、彻底脱离”，没有照 sodheti / visodheti / parisodheti（清净、净化、彻底清净）那样逐级加强，三词也不同根。见 §1695 句 16-31。
- **补出的主语“他”**：只有 §1695-16 补了“他使这个心……”，同类句（§1698-35、§1701-34）都没补。按 style.md“不擅自补足省略主语”，建议删掉，保持一致。

## §1695 句 74-1695-16-26

- **问题**：一致性 / 义注 — 义注（97-1669）：**义注**：“āsevanto sodheti, bhāvento visodheti, bahulīkaronto parisodheti … Mocetī tiādīsupi eseva nayo”，即 moceti 三词和 sodheti 三词一样，是“修习、修持、多作”的逐级加强。现在的“解脱、脱离、彻底脱离”第二词没有加强，第三词又换了词根，看不出层级。另外开头补出的“他”没有必要。
- **建议**：改为“使这个心从这昏沉睡眠中清净、净化、彻底清净，使它脱离、解脱、彻底解脱。”（或者三词都用“解脱”系，逐级加“完全”“彻底”。）

## §1698 句 74-1698-6-34

- **问题**：准确性 — kukkuccaṃ / kukkuccāyanā / kukkuccāyitattaṃ 是同一词根的三联（名词、动作、状态），和 §1697 的 uddhacca 定义句式相同。现在译成“恶作、追悔、懊悔的状态”，三个词换了三个字，看不出是同一个法的展开。另外 manovilekhā 译“内心的抓挠”，把 mano（意）译成“内心”，和 cetaso（心）分不开，又和 ajjhattaṃ（§1701）撞了词。
- **建议**：“……凡是这样的恶作、作恶作、恶作的状态、心的追悔、意的抓挠——这称为‘恶作’。”如果嫌“作恶作”太生硬，也可以写成“恶作、恶作之行、恶作的状态”，关键是三词要同根。

## §1698 句 74-1698-35-52

- **问题**：一致性 — santā 译“平息”、vūpasantā 译“寂灭”，与 §1701 的同一词串不一致（见跨段一致性）。**义注**（97-1675、97-1671）：“Idhāpi ‘santā hontī’ti purimanayeneva vacanabhedo veditabbo”，santā hontī 用复数，是因为掉举和恶作是两个法；而且这里的 santa 是“nirodhasantatāya santā”，即因灭而平静。译文“已经平息……终结了”的完成义是对的，只需要统一用词。
- **建议**：“……已经平静、止息、寂静、消失、完全消失、灭除、彻底灭除、枯竭、彻底枯竭、终结了。”

## §1699 句 74-1699-2-19

- **问题**：义注释义 — **义注**（97-1674）：“Muttattāti idaṃ santatito vinimocanavasena”，意思是从（心的）相续中解开、放开。译文“（掉举恶作）被解脱”会让人读成烦恼本身得到了解脱，取义有误。**义注**又说 paṭinissaṭṭhattā 是“pubbe ādinnapubbassa nissaggadassanavasena”（舍掉先前执取的东西）；pahīnapaṭinissaṭṭhattā 是“yathāvikkhambhanavaseneva pahānaṃ hoti, punappunaṃ santatiṃ na ajjhāruhati”。“被舍断舍离”只是把两个词拼在一起，意思不清楚。
- **建议**：muttattā 改为“已从相续中被放开”或“被解开”；pahīnapaṭinissaṭṭhattā 改为“已舍断而舍离”。另外标题词“不掉举”作为标题略像否定动词，可以考虑改成“无掉举者”，并和 §1700 以后其他标题词的体例统一。

## §1701 句 74-1701-17-33

- **问题**：术语 — tajjāmanoviññāṇadhātu 译“与之相应的意识界”。“相应”在阿毗达磨里是 sampayutta 的定译，用在这里会让人误以为在讲相应法。tajjā 的意思是与彼（所缘、触等）相称、由彼而生。mānasaṃ 译“意态”，依据不足，建议在报告里留存疑。
- **建议**：改为“与之相称的意识界”。mānasaṃ 的译法沿用术语表；术语表没有收录的，等全书一并定案。

## §1701 句 74-1701-34-41

- **问题**：一致性 — santaṃ 译“寂静”、vūpasantaṃ 译“寂灭”，和标题词 vūpasantacitto“心已寂静”对不上；ajjhattaṃ 译“在内部”，和同段 §1701-42 的“内心”不一致。
- **建议**：“这个心于内是平静的、止息的、寂静的。”同时把 §1701-42 改成“所以说‘于内心已寂静’”，或者两处都用“内心”。只要和 manovilekhā 的译法分开就行。
