## 理由

**本次评估缺少两个基准**：注入的数据里没有义注（aṭṭhakathā），也没有 nissaya。所以本次只对照巴利原文核对，没能逐词核对格位与传统取义。信心指数因此下调。

**准确性**
- 5 句的主谓宾判断都正确。
- `sadisassa`（属格）+ `hīnohamasmīti`（引语）+ `māno` 的结构，译成“相等者认为‘我比较差’的慢”，理解正确，没有漏译或多译。
- 74-2609-12-30 里，`aññataraññatarena vatthunā` 被归到 `sadiso hoti`，作为“在哪方面相等”的依据。从原文语序看，它也能理解为修饰 `hīnaṃ attānaṃ dahati`。两种读法意思差别不大，没有扣分。有义注时建议再核对一下。
- `jappeti` 译成“生起”，属于常见的取义，可以接受。
- 本文自始至终讲的是“自轻”，但同义词串里的“轻视”“贬低”“贬抑”都没写出对象。普通读者容易理解成轻视别人，这里扣了少量准确性分。

**风格**
- 整体是现代书面汉语，标点全部是全角，没有残留工作标记。
- `hīna` 译成“比较差”偏口语，放在法相名目（标题）里语体落差明显，扣了少量风格分。
- “名门之子”是现代汉语常用的固定说法，不算文言，不扣分。

**一致性**
- 标题（74-2608-2-7）、问句（74-2609-2-11）、结语（74-2609-37-58）三处的被解释语完全一致。
- `omāna` 首次出现时夹注了巴利原词，符合体例。
- 同义词串里 `omāno / omaññanā / omaññitattaṃ` 同出一个词根，译成“卑慢 / 轻视 / 轻视的状态”，第一项和后两项用字断开了，词根上的关联看不出来。

## 问题清单

### 🟨 warning
- `74-2609-37-58`｜关键词语意不明确｜片段「轻视、轻视的状态、贬低、贬抑、贬抑的状态」
  - 问题：`omaññanā / hīḷanā / ohīḷanā` 在这里指看低自己。译文没写对象，读者容易理解为轻视或贬低别人，与本段讲的“卑慢”方向相反。
  - 建议：给对象加上限定，如“自我轻视、自我轻视的状态、自我贬低、自我贬抑、自我贬抑的状态”。也可以保留现在的译法，在段后加注说明这几个词都指看低自己。有义注后再定。

### 🟦 suggestion
- `74-2608-2-7`｜语言风格不统一｜片段「我比较差」
  - 问题：作为法相名目的标题，“比较差”偏口语，与“卑慢”“慢”等术语放在一起不协调。这个译法会在 74-2609-2-11、74-2609-37-58 中重复出现，同类各章（seyyassa / sadisassa / hīnassa…）也应该统一。
  - 建议：考虑改成“我较低劣”或“我不如人”。定案后登记到 `terms.md`，同类各章一起改。
- `74-2609-37-58`｜语言风格不统一｜片段「卑慢、轻视、轻视的状态」
  - 问题：`omāno / omaññanā / omaññitattaṃ` 同一词根，原文是“名词 / 动作 / 状态”的递进格式，译文第一项和后两项用字不同，看不出这个格式。后面的 `hīḷanā / ohīḷanā / ohīḷitattaṃ` 则译成了“贬低 / 贬抑 / 贬抑的状态”，基本保留了递进。前后两组处理不一致。
  - 建议：可以改成“卑慢、自卑轻视、自卑轻视的状态”之类，或者和上一条的修改一起处理，让三组同义词都保持“名词—动作—状态”的格式。
