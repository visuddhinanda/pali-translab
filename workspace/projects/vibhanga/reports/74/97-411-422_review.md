# Review — 97:411-422（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层译文（74:696-711）✅／nissaya ❌（未注入，本报告不做词级格位核对）／释义标准：本层就是义注，不能拿自己当标准；复注未注入，所以取义判断只依据本层原文，存疑的地方单独标出

## 被解释词与父层对照

父层 74-699-9-33 的译法是：老、老的样态、齿甲残缺、毛发变白、皮肤起皱、寿命减损、诸根熟坏；这叫做“老”。

- **Jarā** → 老 ✅
- **Jīraṇatā** → 老的样态 ✅
- **Khaṇḍiccaṃ** → 齿甲残缺 ✅
- **Pāliccaṃ** → 毛发变白 ✅
- **Valittacatā** → 皮肤起皱 ✅
- **Āyuno saṃhāni** / **indriyānaṃ paripāko** → 寿命减损 / 诸根熟坏 ✅
- **Ayaṃ vuccati jarā** → 这叫做“老” ✅

被解释词全部和父层逐字相同，没有必改项。黑体 pākaṭajarā / paṭicchannajarā / avīcijarā / savīcijarā，以及 416 的 ‘Jarāya dukkhaṭṭho veditabbo’，父层里都没有出现，不受逐字对照的约束。

## 跨段一致性

- **paripāka**：§413 译“熟坏”（indriyānaṃ paripāko 和 paripakkāni 都是），§415 句 97-415-95-103 的 khandhaparipāka 译“成熟”。建议统一为“熟坏”，写成“诸蕴熟坏”。理由有两条：父层定的是“诸根熟坏”；“成熟”偏褒义，放在讲老的上下文里会让人误读。
- **niddesa 的三类说明**：§412 头几句用长式，即“就行相而作的说明”“就时间推移中的作用而作的说明”“就本然状态而作的说明”；后面几句和 §413 用短式，即“行相说明”“作用说明”“本然状态说明”。指的是同一组概念，建议全部统一成一种。长式里“就…而作”半文不白（见 97-412-11-14），建议统一为短式，或改成“从…方面作的说明”。
- **引号层级**：§414 的 ‘**显现的老**’ 等和 §416 的 ‘**应当了解…**’ 是顶层引语，却用了单引号 ‘’；§413 的“寿命减损”、§412 的“老”这个词用的是双引号 “”。现在是照搬巴利文 ‘ 和 ‘‘ 的区别，但中文里顶层引语应当用 “”，单引号只留给嵌套引语。建议 §414、§416 改成 “”。
- **黑体加引号的格式**：句 97-412-50-55 和 97-412-56-64 写成“**毛发变白**”（引号加黑体），句 97-412-44-49 的“齿甲残缺”只有引号没有黑体。这和巴利文的黑体标注一致，可以保留，这里只是记下来。
- **jarāvāta 译作“老之风”**：§415 出现三次（句 26-36、50-64、65-79），三处译法一致，但有文言“之”，见下面的风格项。

## §412 句 97-412-11-14 / 97-412-15-20 / 97-412-21-24 / 97-412-2-10
- **问题**：风格（必改）：“依自性而作的”“就行相而作的”“就…作用而作的”“就本然状态而作的”都是半文句式“就/依…而作”。
- **建议**：改成“从自性上作的主格表述”“从行相上作的说明”，或者直接用短式（见跨段一致性）。

## §412 句 97-412-25-35
- **问题**：语序：“因为这个老，用‘老’这个词是从自性上来显示的”主语断开了，翻译腔很重。
- **建议**：“因为用‘老’这个词，是从自性上来显示这个老的，所以……”

## §412 句 97-412-121-126
- **问题**：术语：cakkhuviññeyyā 是“能被眼识了知的”，“眼睛所能认知”说得太松。
- **建议**：“因为老不是眼识所能了知的。”

## §414 句 97-414-23-33
- **问题**：术语：arūpadhamma 译成“名法”，把“非色”换成了“名”（nāma），前后两句 rūpadhamma／arūpadhamma 的对举也就断了。
- **建议**：“而非色法中的老……”，和上一句的“色法”对举。

## §414 句 97-414-34-44
- **问题**：句法存疑：译文把 tādisānaṃ dantādīnaṃ 读成 suviññeyyattā 的属格（“由于那样的牙齿等容易认知”），逻辑说不通。这个属格更可能是修饰 vaṇṇo 的：看到的残缺，只是那样的牙齿等的颜色（可见的色相）。suviññeyyattā 说的是这颜色容易认知。
- **建议**：“其中，所看到的残缺等状态，只是那样的牙齿等的颜色而已，因为它容易认知。”这里没有 nissaya，建议有资源时再核对一次格位；这句的 confidence 要压低。

## §414 句 97-414-45-71
- **问题**：措辞：“系在水处的牛角等”，“水处”生硬，读者也看不出系牛角是作标记用的。
- **建议**：“就像看到系在有水的地方作标记的牛角等，就知道下面有水一样。”

## §414 句 97-414-81-102 / 97-414-103-115
- **问题**：风格：“由于其间颜色等的差别”，“其间”带文言“其”（这两处都有）。
- **建议**：改成“中间”，比如“由于中间颜色等的差别难以察觉”。
- **补充**（97-414-103-115）：yathāvuttesu 译成“上述以外的那些事物”，把 aññesu 和 yathāvuttesu 并成了一个意思。建议写成“而在除此以外、像前面所说（牙齿等）那样的事物中”。

## §415 句 97-415-26-36 / 97-415-50-64 / 97-415-65-79
- **问题**：风格（必改）：“老之风”里的“之”是文言虚词。
- **建议**：三处都改成“被老这股风吹袭的时候”。父层的被解释词是“老”，这样改和它保持一致。

## §415 句 97-415-37-44
- **问题**：存疑：“tambāpi honti kāḷakāpi setāpi”译成“有的是…有的是…有的是”，是按不同人之间的差别来读的。下文讲皮肤（odātānaṃ odātabhāvo, kāḷakānaṃ kāḷakabhāvo）也是在讲个体差别，所以这个读法站得住；不过这里上下文讲的是有间隙的老的阶段变化，也有可能是指依次变色。
- **建议**：译文可以不动，但这句的 confidence 要压低，等有复注或 nissaya 再定。

## §415 句 97-415-95-103
- **问题**：跨段一致性：khandhaparipāka 译作“诸蕴成熟”。
- **建议**：改成“诸蕴熟坏”（见跨段一致性）。

## §416 句 97-416-2-20
- **问题**：取义：dukkhaṭṭho 是“苦的意义（苦义）”，这是陈述。译成“老在什么意义上是苦”，变成了疑问口吻，而后文的“katarassa dukkhassa?”才是真正的问句，两处会混。另外顶层引号用了 ‘’。
- **建议**：“在“**应当了解老的苦义**”这句话中……”

## §419 句 97-419-2-7
- **问题**：取义存疑：satādīnaṃ vippavāsā 放在衰老的语境里，sati 更可能指记忆（记性），不是修行意义上的正念。
- **建议**：考虑改成“由于记性等离他而去”；如果保留“正念”，要在报告里记下有分歧。

## §421 句 97-421-2-10
- **问题**：用语：mānasaṃ 译成“心理上的”，带现代心理学色彩（`style.md` 第六节），和父层 74-704 “心上的”（cetasika）那一对说法也不协调。
- **建议**：“无论是身体上的还是心上的”。
