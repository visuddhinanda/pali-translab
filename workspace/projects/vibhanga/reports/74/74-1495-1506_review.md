# Review — 74:1495-1506（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入）
> 本次缺少义注和 nissaya 两项标准，下面的意见只依据巴利原文、术语表和 style.md。凡是涉及取义的条目，等义注取到后需要再核一遍。
> 层次：本文（mūla），没有父层，所以不查被解释词。

## 跨段一致性

- **samannāgata**：标题句（§1496）和 §1499 的结句“因此说”都译作“具足”。但 §1499 的同义词列里，samannāgato 译成了“成就”，“具足”反而给了 samupeto。这样一来，“因此说‘具足……’”在前面的列举里找不到对应的词。→ **必改**，见 §1499 句 74-1499-25-46。
- **iddhi**：§1495、§1500 标题词、§1501 至 §1506 都译作“神”（神足），但 §1500 定义列的第一项也是 iddhi，却译成了“成功”。被定义的词和定义列的首项本来是同一个巴利词，现在用了两个译法。→ 建议统一处理，见 §1500。
- **tajjā- 与 sampayutta**：§1506 把 tajjāmanoviññāṇadhātu 译成“与之**相应**的意识界”，下一句的 sampayutta 也译作“**相应**”（与心神足相应）。两个巴利词共用“相应”，而“相应”在阿毗达摩里是专门术语，对应 sampayutta。→ **必改**，见 §1506。
- **定型句（§1496 / §1504 / §1505 / §1506）**：四段的“出世间禅那”句式译法完全一致，这一点很好。不过下面 §1496 指出的结构问题这四段都有，改的时候要四处同步改。
- 其他重复句式，如“其中，什么是……”“凡是……——这称为……”“道支、道所包含的”“其余的法与……相应”，前后一致，没有问题。

## §1496 句 74-1496-11-43（§1504 / §1505 / §1506 同型句同改）

- **问题**：句法归属。`diṭṭhigatānaṃ pahānāya paṭhamāya bhūmiyā pattiyā` 是两个与格目的语，修饰的是谓语 `bhāveti`（为断诸见、为得初地而修习）。现在的译文把它们放进破折号插入语，和“这禅那能导向出离……”并列，读起来像是在描述禅那的性质。`dukkhapaṭipadaṃ dandhābhiññaṃ` 是宾格，和 `jhānaṃ` 同格，描述的是禅那（初禅）。“以苦的方式修行，迟缓地证知”把它译成了比丘的行为方式，主语也偏了。
- **问题**：用词。“以苦的方式修行”是翻译腔，传统译法是“苦行道（苦迟通）”。
- **建议**：按这个方向重组：“这里，比丘为了断除各种邪见、为了证得初地，修习能导向出离、能导向消解的出世间禅那——离开诸欲……乃至……进入并安住于行道艰难、证知迟缓的初禅——在那个时候，……”。改动要四段同步。这条在拿到 nissaya 后用格助词复核一遍。
- **问题（次要）**：apacayagāmiṃ 译作“能导向消解”，意思不够明确。它通常解作“趣向（轮回的）减损”。
- **建议**：可改为“导向减损”。这条等义注确认，暂不列为必改。

## §1497 句 74-1497-2-9

- **问题**：术语。vīmaṃsā 译“观”，单看汉语容易和 vipassanā（观）混淆。“观神足”虽然是传统译名（另有“思惟神足”），单独出现的“什么是观？”“这称为‘观’”却很难和观禅区分开。
- **建议**：标题保留“观神足”，没有问题。建议在 vīmaṃsā 首次单独出现时夹注巴利原词：“观（vīmaṃsā）”。定案后登记进 `terms.md`。

## §1499 句 74-1499-25-46

- **问题**：术语对应断裂（必改）。七个同义词现在的对应是：upeto 具有 / samupeto 具足 / upāgato 达到 / samupāgato 完全达到 / upapanno 具备 / sampanno 圆满 / samannāgato 成就。下一句“因此说‘具足观定勤行’”里的“具足”对应 samannāgato，可列表中 samannāgato 是“成就”，“具足”成了 samupeto。
- **建议**：samannāgato 改译“具足”，samupeto 另选一个词，例如“完全具有”。语序也可以照巴利原样：“具有、完全具有、达到、完全达到、具备、圆满、具足”。

## §1500 句 74-1500-2-6 / 74-1500-7-21

- **问题**：被定义词和定义首项译法不一致。标题词 iddhi 译“神”，定义列首项 iddhi 译“成功”。读者看不出“神”就是列表里的第一项。
- **建议**：首项改为与标题呼应的词，例如“神（iddhi）：就是那些法的神变（iddhi）、成功、成就……”；也可以保留“成功”，但在首项后夹注“（iddhi）”，标明这是同一个词。另外，iddhi 首次出现其实在 §1495 标题“观神足”中，夹注是否挪到首次出现处，请一并斟酌。

## §1501 句 74-1501-4-11

- **问题**：措辞有歧义。“处于这种状态的人所有的触”中，“所有的”容易读成“全部的”。
- **建议**：改为“处于这种状态者所具有的触……乃至……策励、不散乱”。

## §1506 句 74-1506-9-55

- **问题**：术语撞车（必改）。tajjā-（由彼而生、与彼相适）译成“与之相应”，和下一句 sampayutta 的“相应”重复。阿毗达摩里“相应”专指 sampayutta，这样译会误导。
- **建议**：改为“由此而生的意识界”或“与之相适的意识界”，全书统一后登记进 `terms.md`。
- **问题（次要）**：mānasaṃ 译“意所”，容易和“心所”（cetasika）混淆。
- **建议**：考虑改为“意（mānasa）”的其他译法，或者首次出现时夹注巴利原词。此条压低信心，等定案。

## §1505 句 74-1505-9-56

- **OCR / 原文疑问**：原文作 `maggariyāpannaṃ`，§1497、§1498、§1499 的同一位置都是 `maggapariyāpannaṃ`，这里疑似脱了 `pa`。译文已经按 maggapariyāpanna 译作“道所包含的”，是正确的。原文不改，记入 `known-issues.md` 的 OCR 一节。
