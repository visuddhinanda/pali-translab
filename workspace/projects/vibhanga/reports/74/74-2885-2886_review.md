# Review — 74:2885-2886（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入，本次未做词级格位核对）／义注 ✅（Sammohavinodanī，book 97 §2212；注入数据的 `layer` 字段误标为 `mula`，实为义注）
>
> 本层是本文，没有父层，所以不做被解释词比对。但义注 §2212 用黑体逐字引用了本段的 chandāgatiṃ gacchati / dosāgatiṃ gacchati / mohāgatiṃ gacchati / bhayāgatiṃ gacchati / agati / agatigamanaṃ / chandagamanaṃ / vaggagamanaṃ / vārigamanaṃ。**本段定下的译法就是义注层的逐字基准**，下面的统一问题要在本层先改定，否则会一路传到义注、复注。

## 跨段一致性
- **agatigamana**：§2885 与 §2886 句 20-31 末尾（imāni cattāri agatigamanāni）译「不正行」，同一句中的单数 agatigamanaṃ 却译「走不正之道」。同一个词在同一句里出现两种译法，义注黑体 **agatigamanaṃ** 会无法对应。→ 建议全段统一为「不正行」，依据：标题和问句都已用「不正行」，出现次数最多。
- **chanda**：句 7-19 的 chandāgatiṃ 译「贪欲」，句 20-31 的 chandagamanaṃ 译「欲」（随欲而行）。→ 两处要用同一个词，建议改为「偏爱」，依据见 §2886 句 74-2886-7-19。
- **gacchati**：句 7-19 译「走上」，句 20-31 的 agatigamanaṃ 译「走」。改定 agatigamana 后，这里的动词也要统一。

## §2886 句 74-2886-7-19
- **问题**：取义 — chanda 译「贪欲」偏离了义注的解释。**义注**：chandena pemena agatiṃ gacchati（凭偏爱、凭情分而走上不正之道）。义注举的例子是：因为“这是我的朋友、熟人、亲近的人、亲戚，或者给过我贿赂”，就把不是主人的人判为主人；分配东西时，因为偏爱而多给。这里说的是**因私情而偏袒**，不是一般的贪欲。译成「贪欲」把术语的所指译偏了，也和后面「随欲而行」不一致。汉传对应的四不应行一般作「爱、恚、痴、怖」，可供参照。
- **建议**：改为「因偏爱而走上不正之道」（或「因爱」）。其余三项：dosa「嗔恨」与义注说的“宿怨或一时的忿怒”相合，保留；moha「愚痴」、bhaya「恐惧」与义注相合，保留。

## §2886 句 74-2886-20-31
- **问题 1**：一致性（必改）— 同一句里，agatigamanaṃ 译「走不正之道」，imāni cattāri agatigamanāni 译「四种不正行」，同一个巴利词出现两种译法。
- **建议 1**：前一处改为「不正行」，整句例如：“凡是这样的不正之道、不正行、偏爱之行、偏党之行、随水之行——这些就是四种不正行。”（具体措辞跟随 chanda 的定稿译法。）
- **问题 2**：取义 — chandagamanaṃ 译「随欲而行」，和 chanda 的定稿译法脱节。**义注**：chandena gamanaṃ chandagamanaṃ（凭 chanda 而行）。
- **建议 2**：跟随句 7-19 改为「因偏爱而行」或「偏爱之行」。
- **问题 3**：取义（轻）— vārigamanaṃ 译「如水随流而行」，「随流」不够准确。**义注**：vārino viya yathāninnaṃ gamanaṃ（像水一样往低处流去），重点在“哪边低就往哪边去”，即随势倾倒、没有定准。
- **建议 3**：改为「如水往低处流般而行」，或者简洁一些作「随水之行」。
- **问题 4**：语法（轻）— imāni 是复数，「这就是四种不正行」读起来像在指单数。
- **建议 4**：改为「这些就是四种不正行」。
- **备注（不必改）**：vaggagamanaṃ 译「偏袒一方而行」与**义注**相合（Sakapakkharāgañca parapakkhadosañca purakkhatvā asamaggabhāvena gamanaṃ：偏爱自己一方、憎恶对方，以不公正的方式而行）。不过义注在这里分别说明了 agati、agatigamana 通用于四者，chandagamana 只就单项而言，vaggagamana 通用于 chanda 与 dosa，vārigamana 通用于四者。说明这几个词是同义异名的排列，不是另外四种。译文用破折号收束成“这些就是四种不正行”，已经能表达这一点，不需要补注。

## §2885 句 74-2885-2-6
- **问题**：体例（轻）— 术语 agatigamana 第一次出现在标题，夹注的巴利原词却放在 §2886 的问句里。
- **建议**：标题一般不加夹注，现在的做法可以保留；如果项目规定夹注必须跟在第一次出现处，就移到标题。由统稿时统一决定。
