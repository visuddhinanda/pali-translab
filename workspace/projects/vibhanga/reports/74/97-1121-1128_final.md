## 理由

**基准缺失**：本次评估的是义注层（Vedanānupassanādiuddesavaṇṇanā），本身没有更上一层的义注可作释义标准。本次也没有注入复注（ṭīkā）和 nissaya，所以只能对照巴利原文逐句核对。注入数据里各句的 `layer` 字段都标成了 `mula`，和任务说明的“义注层”不一致，建议核对元数据。父层（Mahāsatipaṭṭhāna 本文）的译文没有注入，“被解释词与父层逐字同译”这一条无法核验，包括 1122-2-7 的“**内在的**”和 1122-26-36 的“**在受上随观受**”。以上几点是信心指数偏低的主要原因。

**准确性**：
- 主谓宾判断全部正确，没有漏译和错译。
- 几处容易出错的地方都处理对了：
  - `cetā` 正确拆为 ca + etā，译作“所有这些受”。
  - 1124 的 `santaṃ` 取“寂静”义，1127 的 `santāsanta` 取“存在／不存在”义。两处同形异义，都分辨正确。
  - 心随观一句的 `aniccādinupassanānaṃ` 没有像法随观那样误加“七种”。
  - `nānācittakkhaṇika` 译为“在不同心刹那中”，准确。
- 扣分点在个别连接词的添加或语气偏移上，没有造成实质误读（见问题清单）。

**风格**：通篇是现代书面汉语，没有发现文言虚词或文言句式。标点统一用全角，引号都是弯引号，没有残留工作标记。“诚然”在现代书面语里常用，不算文言。

**一致性**：以下术语全段统一，前后对应也一致：
- anupassanā → 随观
- satipaṭṭhāna → 念处
- uddesa／niddesavāra → 总说／释义部分
- abhijjhādomanassa → 贪忧
- aniccādisattānupassanā → 无常等七种随观（1126 与 1127 一致）

## 问题清单

### 🟨 warning
- `97-1127-2-12`｜整句逻辑表达不规范｜片段「在心和法方面也是如此：」
  - 问题：原文 `Cittadhammesupi` 的 `pi` 只表示“在心和法方面也〔应随观〕”，并没有说方法和受随观相同。紧接着列出的恰恰是心、法各自不同的随观方式。“也是如此”容易让读者以为心、法的随观方式与受相同，和下文矛盾。
  - 建议：改为“在心和法方面，首先，心应当依照……来随观”，或“至于心和法：首先，心应当……”。

### 🟦 suggestion
- `97-1122-69-84`｜语言表达不够流畅｜片段「只要知道」
  - 问题：`Kevalaṃ … veditabbo` 意为“这里只需这样理解”。“只要”在汉语里偏向表示充分条件（“只要…就…”），和后文“就称为”连读，容易误解成条件句。
  - 建议：改为“而在这里只需知道”。
- `97-1126-9-10`｜语言表达不够流畅｜片段「因为这样说过」
  - 问题：原文 `Vuttañcetaṃ` 是 ca（“并且、而”），不是 hi，没有因果连词。“因为”加重了因果语气，属于轻微多译。
  - 建议：改为“正如这样说过：”或“这是说过的：”，和本段其他几处“正如所说”保持统一。
- `97-1122-2-7`｜语言风格不统一｜片段「**内在的**等语」
  - 问题：被解释词与“等语”直接连写，没有加引号。同段 1122-26-36 的被解释词“**在受上随观受**”加了引号，两处体例不一。
  - 建议：改为““**内在的**”等语”。另外需要人工确认“内在的”与本文层 `ajjhattaṃ` 的译法是否逐字一致。
