## 理由

**评估依据与缺失**
- 本次只注入了巴利原文和待评译文，没有义注释义标准、nissaya 和父层（本文）译文，所以本报告**只能依据巴利原文逐句核对**。凡是要以注释书定取义的地方，比如 1917-149-165 的异读、1917-94-110 的 tejussada，都只能给出倾向性判断，信心指数因此压低。
- 没有父层译文，就无法核对“被解释词与父层逐字同译”这条硬约束。各条黑体词，例如“不可能”“没有这样的余地”“具足正见的人”“使如来出血”，都需要另行拿本文定稿逐字比对。
- 数据标签不一致：任务头写的是义注层（Paṭhamabalaniddeso，book 97），每条记录的 `layer` 字段却是 `mula`。这不影响本次评分，但应查明上游标注。

**准确性**
- 整体取义可靠。句法主干，即主语、谓语、宾语，没有发现判断错误；fatal 级问题为零。
- 主要失分点：
  - 1920-53-64 的修饰关系处理不当，读起来像“导师教法本身违背法律”。
  - 1917-94-110 把 tejussada 译成“火势炽盛”，用在出世间行上容易引起误解。
  - 1920-116-127 缺了具格施事，句子逻辑不清。

**风格**
- 基本是现代书面汉语，没有发现文言虚词或文言句式。
- 存在几处问题：
  - 括号里夹带译者说明，例如 1917-30-34。
  - 个别“即使……假如……”套叠，读来别扭。
- 引号一律用的全角弯引号，没有 ASCII 引号残留，标点合规。

**一致性**
- ṭhāna 一词有三种译法：aṭṭhāna 译“不可能”，1917-20-29 译“处”，netaṃ ṭhānaṃ 译“这种情况”。义注在这里恰恰是解释 ṭhāna 等于 kāraṇa，译名一换，读者就看不出这层解释，词义链断开了。
- yaṃ 在两处保留巴利原形，又与汉译混排，与其他被解释词的处理方式不统一。

**分歧说明**
- 1917-149-165 原文作 “sucikāmo pokkhabrāhmaṇo”，其中 pokkha 在译文里没有体现。其他版本可能作 “sucikāmo brāhmaṇo”，因此不按漏译扣分，只建议核对异读并加注。

## 问题清单

### 🟧 error
- `97-1920-53-64`｜错译（修饰关系）｜片段“会教你们接受违背法、违背律的导师教法”
  - 问题：原文 uddhammaṃ ubbinayaṃ satthusāsanaṃ gāheyya 的意思是“把违法、违律的东西当作导师的教法让你们接受”。现译让“违背法、违背律”直接修饰“导师教法”，读起来像佛陀的教法本身违法违律，容易误解。
  - 建议：改为“像我这样的人，会让你们把违背法、违背律的东西当作导师的教法来接受”。

- `97-1917-94-110`｜导致误解的表达｜片段“由于火势炽盛”
  - 问题：tejussadattā 说的是出世间行本身威势炽盛，铁球的“热”只是比喻。现译用“火势”直接描述出世间行，把比喻里的东西当成了本体的属性。
  - 建议：改为“由于威力炽盛”或“由于威光炽盛”，保留后面的铁球比喻。

### 🟨 warning
- `97-1920-116-127`｜整句逻辑表达不规范｜片段“因为以阐明十八事的方式来宣说，为了让他们对此生起喜好而宣告”
  - 问题：原文 voharantena … anussāvetvā … gāhitāya 有具格施事（宣说的人），现译没有主语，三个动作是谁做的、彼此什么关系都不清楚。
  - 建议：改为“因为即使有人以阐明十八事的方式宣说，为了让他们对此生起喜好而宣告，甚至已经让他们拿了筹，僧团也还没有分裂”。

- `97-1917-20-29`｜关键词语意不明确｜片段“它的果的“处”（ṭhāna）”
  - 问题：本句解释的是 aṭṭhāna 和 ṭhāna 为什么指原因。可是前文 aṭṭhāna 译作“不可能”，后文 ṭhāna 译作“这种情况”，读者无法把这三处联系起来，义注的解释落空。
  - 建议：在前文“不可能”首次出现处夹注（aṭṭhāna），或在本句加脚注，说明 ṭhāna 本义是“处、立足之地”，引申为原因，因而 aṭṭhāna 就是“没有成立的原因”，即“不可能”。

- `97-1917-69-75`｜语言风格不统一｜片段“**yaṃ** **凡夫**”
  - 问题：同一黑体被解释词里巴利原形和汉译混排；1917-30-34 也保留了 yaṃ。整段其他被解释词都是汉译，这两处不统一。
  - 建议：照父层本文对该句的汉译取对应词，例如“**凡夫会……**”。如果父层确实保留了 yaṃ，就两处都加脚注说明，不在正文括注。

### 🟦 suggestion
- `97-1917-30-34`｜不常用术语编写注释或者百科｜片段“（引出下面这件事的关系词）”
  - 问题：圆括号按体例只用来夹注巴利原词，这里却放进了译者的语法说明。
  - 建议：把说明移到脚注。

- `97-1917-149-165`｜不常用术语编写注释或者百科｜片段“好洁净的婆罗门”
  - 问题：原文 pokkhabrāhmaṇo 中的 pokkha 没有体现，可能是异读（别本作 brāhmaṇo）。“逃进粪坑”也是对 gūthaṃ 的意译补足。
  - 建议：核对异读后加脚注说明取舍。

- `97-1918-7-11`｜代词指代可能不够明确｜片段“阿罗汉是指身为人的漏尽者”
  - 问题：原文 manussabhūtova 的 -va（eva）有限定作用，这关系到杀阿罗汉是否构成无间业。1924-2-23 同类句子译出了“只有”，这里没有译出。
  - 建议：改为“阿罗汉只是指身为人的漏尽者”。

- `97-1918-22-31`｜语言表达不够流畅｜片段“即使圣弟子已转生到另一生，连自己是圣弟子都不知道，假如有人这样对他说”
  - 问题：“即使……假如……”两个让步/假设连词套叠。原文 sacepi 管的是 vadeyya。
  - 建议：改为“假如圣弟子已转生到另一生，连自己是圣弟子都不知道，即使有人这样对他说”。

- `97-1918-77-84`｜语言表达不够流畅｜片段“这是为了显示凡夫状态有重大的过失”
  - 问题：pana 的转折没有译出。前文刚说过这本来就不可能，这里是反过来交代为什么还要说，缺了转折，逻辑衔接弱。
  - 建议：句首加“不过，”。

- `97-1918-85-98`｜语言表达不够流畅｜片段“因为凡夫甚至会造杀母等无间业”
  - 问题：yatra hi nāma 带惊叹语气，现译平铺直叙，语气减弱。
  - 建议：改为“凡夫状态真是有过失，凡夫竟然连杀母等无间业都会造”。

- `97-1919-8-16`｜语言风格不统一｜片段“在活着的身体上弄出血来”
  - 问题：被解释词作“使如来出血”，释文的动词却换成了“弄出血来”，前后用词不呼应。
  - 建议：改为“在活着的身体上使之出血”。

- `97-1920-72-84`｜语言表达不够流畅｜片段“以这样的方式在耳边说话”
  - 问题：原文 tiādinā nayena 里的“等”没有译出，读者会以为宣告的话只有前面这几句。
  - 建议：改为“以这样等等的方式在耳边说话”。

- `97-1921-2-10`｜代词指代可能不够明确｜片段“这样，具足正见的人分裂僧团”
  - 问题：evaṃ 指“以上述五种方式”，放在句首容易被读成“这样一来”，作承上的连接词理解。
  - 建议：改为“具足正见的人会这样分裂僧团，这种情况不存在”。

- `97-1924-24-50`｜不常用术语编写注释或者百科｜片段“大塔（mahācetiya）”
  - 问题：Mahācetiya 指锡兰阿努拉德普勒的大塔（Ruwanweliseya），普通读者不知道它有多大，比喻的分量体会不到。
  - 建议：加脚注简介。
