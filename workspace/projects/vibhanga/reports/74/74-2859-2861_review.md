## 跨段一致性
- līna- 词族：§2859 标题和 §2860 问句都把 līnatta 译作“退缩”。但在 §2860 的定义句里，olīyanā、līnaṃ、līyanā 也都落成了“退缩”或“退缩状态”。结果标题词和定义里的同义词撞成同一个词，读者看到的就是“退缩是退缩”的循环定义。建议：līnatta 保留“退缩”，定义里的各个同义词改用能区分的译法（见下）。
- -anā 与 -tta 的译法不分：līyanā 译成“退缩状态”，thiyanā 译成“惛沉状态”。-anā 是动作或样态名词，-tta 才是抽象的“状态”，而 līyitattaṃ、thiyitattaṃ 已经译成“已…的状态”。前者也带“状态”二字，两类后缀就分不开了。建议统一成：-anā →“…的样态”，-tta →“已…的状态”。

## §2860 句 74-2860-8-31
- **问题**：误译（同义词合并）。这串同义词有 11 项：akalyatā / akammaññatā / olīyanā / sallīyanā / līnaṃ / līyanā / līyitattaṃ / thinaṃ / thiyanā / thiyitattaṃ（cittassa 首尾各出现一次）。译文里“退缩”出现了两次（olīyanā 和 līnaṃ），“极度退缩”“退缩状态”“已退缩的状态”又都是同一个词根。olīyanā 和 līnaṃ 完全同译，等于原文的两个不同词在译文里少了一个，违反同义词串应逐项可辨的原则。
- **建议**：olīyanā 带前缀 o-（向下），可以译成“沉没”或“下沉”。sallīyanā 带前缀 saṃ-（加强、收拢），可以译成“蜷缩”或“深深沉没”。līnaṃ 译“退缩”，līyanā 译“退缩的样态”，līyitattaṃ 译“已退缩的状态”。thina 组照同一格式：“惛沉、惛沉的样态、已惛沉的状态”。最终取哪个词，等补到义注（《殊胜义》对这串词的逐词解释）后再定。在那之前，revise 先做到逐项可区分，并压低这句的 confidence。
- **问题**：术语、语体。akammaññatā 译成“不适业”，是传统法相译语，但对一般读者不透明，而且“适业”是文白夹杂的说法。
- **建议**：首次出现时改成“不适于工作（akammaññatā）”或“不堪用”。如果项目决定沿用“不适业”，就登记到 `terms.md`，并在首次出现处夹注巴利原词。
- **问题**：取义存疑。akalyatā 译成“不健全”，偏向结构或品质上的缺陷，而这个词更接近“不适、不健康”（kalla = 健康、合适）。
- **建议**：改成“不适”或“不健康的状态”，具体等义注核定。
