## §2244 句 97-2244-2-10
- **问题**：术语／歧义。“只是常见执著的种种方式”里的“常见”，现代读者第一反应是“经常看到的”，整句会读成“只是常见的执著方式”，意思完全偏了。

## §2244 句 97-2244-60-72 / 73-77 / 78-85 / 86-97（第一解）
- **问题**：误译（必改）。第一解把 **na so jāto nāhosi** 读作“na jāto（没有出生）＋ na ahosi（没有‘成为、生起’）”。理由是：自我具有不生的性质，始终存在，所以谈不上“生起”。后文的解释也是这个思路：“Yo hi jāto so ahosi, yo ca jāyissati so bhavissati”，意思是出生了的，才谈得上“曾经生起”；将要出生的，才谈得上“将会生起”。译文把 nāhosi 译成“不曾不存在”，多了一层否定，和第一解的论证正好相反：
  - 78-85 “它在过去不曾不存在，在未来也不会不存在”，原文是 atīte **nāhosi**, anāgatepi **na bhavissati**，只有一层否定，意思是“过去没有生起，未来也不会生起”；
  - 86-97 的“曾经存在／将会存在”也接不上上一句的“不曾不存在”，整段论证读不通。
- **建议**：
  - 60-72：被解释词按父层定，正文改为“这个自我因为具有不生的性质，所以说它没有出生”；
  - 78-85：“正因为这样，它在过去没有生起，在未来也不会生起。”
  - 86-97：“因为凡是出生了的，才能说它‘曾经生起’；凡是将要出生的，才能说它‘将会生起’。”
  - ahosi／bhavissati 在这里译作“生起／成为”，不要译作“存在”，否则会和 vijjamāna（存在）混在一起。

## §2244 句 97-2244-98-120（第二解）
- **问题**：漏了读法上的关键。第二解把 jāto 读成 **jātu**（“从来”），所以才得出“从来不曾不存在”这个双重否定。译文只引了“它不曾出生，也不曾不存在”，读者看不出这个解释是从哪里来的，两种解释的区别也看不出来。
- **建议**：“或者，‘na so jāto nāhosi’ 也可以（把 jāto 读作 jātu‘从来’）理解为：它因为始终存在，所以在过去从来不曾不存在，在未来也从来不会不存在。”引语保留巴利原文，或者加一个译者小注，说明这是另一种读法。
