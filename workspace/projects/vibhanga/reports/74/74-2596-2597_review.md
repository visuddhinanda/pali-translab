# Review — 74:2596-2597（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次没有提供，词级与格位没有核对）／义注 ✅（book 97，§2146 是 868 劣慢解说的义注；§2144、§2163 解释同一组事由词，用来对照）

## 跨段一致性
- **hīnohamasmīti māno**：§2596、§2597 两句（共 3 处）都译成“我是低劣者”；义注 §2146–§2152 一律译成“我是**较劣者**”，与“较胜者／相等者”成套 → 必须统一为“我是较劣者”，依据：义注的被解释词（§2149 **Seyyassa hīnohamasmī** → “较胜者的‘我是较劣者’”）。
- **ajjhena／vijjāṭṭhāna**：§2597 把 ajjhena 译成“学问”、vijjāṭṭhāna 译成“学科知识”；义注 §2163 把 **vijjāṭṭhānaṃ** 译成“学问” → 两词的译法撞车。建议 vijjāṭṭhāna 改为“学问”，ajjhena 改为“学习”或“诵习”（指诵读、学习经典）。
- **suta**：§2597 译“博闻”，义注 §2163 **sutaṃ** 译“所闻” → 建议统一为“所闻”。“博闻”是褒义，放在卑慢的语境里不合适。
- **gotta／vaṇṇapokkharatā**（同一组事由在 866 胜慢、867 等慢、868 劣慢里重复出现）：§2597 译“姓族”“容貌端好”；义注 §2144 引的被解释词 **Gottenā**、**Vaṇṇapokkharatāyā** 译成“以姓氏”“以容色美好” → 建议统一为“姓氏”“容色美好”，并同时核对本文 866、867 两段的译法。
- **vuccati**：§2597 用“叫做”，义注全书统一用“叫作” → 建议统一为“叫作”。

## §2596 句 74-2596-2-6
- **问题**：被解释词不对应。义注把 hīnohamasmi 译成“我是较劣者”，这里译成“我是低劣者”。
- **建议**：改为“（51）‘我是较劣者’的慢”。

## §2597 句 74-2597-2-9
- **问题**：被解释词不对应，同上。
- **建议**：改为“868. 其中，什么是‘我是较劣者’的慢（māna）？”

## §2597 句 74-2597-10-58
- **问题 1：被解释词不对应（必改）**。逐词对照义注 §2146 的黑体：
  | 巴利 | 本文译 | 义注译 | |
  |---|---|---|---|
  | omānaṃ jappeti | 生起卑慢 | 生起卑慢 | ✅ |
  | omāno | 卑慢 | 卑慢 | ✅ |
  | omaññanā omaññitattaṃ | 自卑、自卑的状态 | 自卑、自卑的状态 | ✅ |
  | hīḷanā | 轻贱 | 轻贱 | ✅ |
  | ohīḷanā | 自贬 | **深自轻贱** | ❌ |
  | ohīḷitattaṃ | 自贬的状态 | **深自轻贱的状态** | ❌ |
  | attuññā | 看低自己 | **自轻** | ❌ |
  | attavaññā | 轻视自己 | **自蔑** | ❌ |
  | attaparibhavo | 自我蔑视 | **自辱** | ❌ |
- **释义依据**：**义注**说：“Ohīḷanāti atirekato hīḷanā”（格外地轻贱）。前缀 o- 表示加强，“自贬”把这层加强的意思译丢了，也和 hīḷanā（轻贱）脱了钩。
- **建议**：后半句改为“凡是这样的卑慢、自卑、自卑的状态、轻贱、深自轻贱、深自轻贱的状态、自轻、自蔑、自辱——这就叫作‘我是较劣者’的慢。”
- **问题 2：事由词与义注、上下段不一致**，见“跨段一致性”（姓族／容貌端好／学问／学科知识／博闻）。
- **建议**：改为“……或因为出身，或因为姓氏，或因为名门子弟的身份，或因为容色美好，或因为财富，或因为学习，或因为职业，或因为技艺，或因为学问，或因为所闻，或因为辩才……”
- **问题 3：原文异读（只记录，不改）**：本文是 attavaññā，义注引作 attāvaññā，元音长短不同。

## 结论
本文 868 段的被解释词有 5 处（ohīḷanā、ohīḷitattaṃ、attuññā、attavaññā、attaparibhavo）与义注不一致，标题和问句里的“低劣者”（共 3 处）也与义注不一致，都属于必改项。没有发现文言写法，也没有工作标记。
