# Review — 97:2074-2085（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／现有译文 ✅／nissaya ❌（未提供，词级核对没有做）／义注：本层就是义注
> 父层对照 ⚠️：只提供了 74:2546-2547（§843 出身憍）。本 chunk 解释的是父层 §844（多闻憍…圆满憍）、§845（憍）、§846（放逸），这几节的父层译文**没有提供**，下面的黑体词**无法逐字核对**，必须在 harmonize 时补查：
> sutamado / paṭibhānamado / rattaññumado / piṇḍapātikamado / anavaññātamado / iriyāpathamado / iddhimado / yasamado / sīlamado / jhānamado / sippamado / ārohamado / pariṇāhamado / saṇṭhānamado / pāripūrimado / katamo mado / cittassa vossaggo / vossaggānuppadānaṃ / asakkaccakiriyatā / asātaccakiriyatā / anaṭṭhitakiriyatā / olīnavuttitā / nikkhittachandatā / nikkhittadhuratā / anadhiṭṭhānaṃ / ananuyogo / pamādo / yo evarūpo pamādo
> 能核对的部分：父层 §843 把 mada 译作“憍”、māna 译作“慢”，句式是“其中，什么是…？”。本 chunk 的“X憍”“慢”和 §2084“其中，**什么**是**憍**”与此一致。

## 跨段一致性
- **majjana（本 chunk 每段都有 majjanavasena）**：父层 §843 把 majjanā 译作“沉醉”，本层 §2074–2083 一律译作“以这样**自我陶醉**的方式”。义注里的 majjana 就是父层同义词串里的 majjanā，建议统一为“以这样**沉醉**的方式生起的慢”，跨层才对得上。
- **pāsādika**：§2079 译“让人生起净信”，§2083（53-70）译“让人喜欢”。两处语境不同（一个说威仪，一个说身形），分开译可以接受，但要定下规则写进 terms.md。说身形时建议译“端庄好看”，和 manāpa（悦意）分开。
- **pamajjana / pamajjanā / pamajjitatta**：§2085（130-133）把 pamajjanaṃ 译作“放逸**的**行为”，§2085（145-171）把 pamajjanā 译作“放逸行为”、pamajjitatta 译作“放逸状态”。建议统一，并比照父层 §843 的 majjanā / majjitattaṃ 译法（沉醉／沉醉的状态），改成“放逸行为／放逸的状态”，最终以父层 §846 定稿为准。
- **rattaññū**：§2076 句中译“阅历久远的人”，黑体却译“**资深**憍”，同一个词前后不一样，读者对不上。建议句中改成“我是资深的人”，或者黑体随句中改译。

## §2085 句 97-2085-2-16
- **问题**：重复译 — 译文末尾的“意思是缺乏正念。”是下一句 97-2085-17-19（sativirahoti attho）的内容，这句又译了一遍，channel 里会出现两次。
- **建议**：删掉本句末尾的“意思是缺乏正念。”，以分号结尾：“846. 在放逸的解释中，**心的放纵**：在这么多情况下不用正念去约束，而放纵心；”

## §2081 句 97-2081-8-14
- **问题**：背景没有补出来 — 义注的意思是：yasa 前面已经归进眷属憍，所以这里的 **yasamado** 指的是侍从憍。译文“而在这里所讲的是侍从憍”没点出说的是 yasamado，读者看不出侍从憍和后面的**名望憍**是什么关系。
- **建议**：改成“而在这里，（名望憍）指的是**侍从憍**。”括注里的“名望憍”要和父层 §844 的 yasamado 译法逐字相同。

## §2085 句 97-2085-20-24
- **问题**：取义偏了 — vossaggassa anuppadānaṃ 的意思是“一再交付给放纵”，下一句义注自己解释为 punappunaṃ vissajjanaṃ。“给放纵留出余地”是另加的引申，意思变软了。
- **建议**：“**一再放纵**：就是对放纵一再地放任；”（黑体部分以父层 §846 为准）

## §2085 句 97-2085-134-144
- **问题**：语体 — 黑体“**凡如此类的放逸**”中“凡如此类”是文言句式。
- **建议**：如果父层 §846 定稿用的就是这个译法，必须照抄，同时提请父层改；如果父层不是这样，按父层逐字照抄。现代说法可参考“像这样的任何放逸”。

## §2082 句 97-2082-18-38
- **问题**：措辞 — cittekaggatā natthi 是“没有心一境性”，“做不到心一境性”搭配不通顺。
- **建议**：“……那么短的时间里都没有心一境性……”

## §2085 句 97-2085-45-48
- **问题**：格式 — 和前一句“持续不断的状态叫作持续。”句式相同，这句却多了逗号。
- **建议**：“不是持续不断的状态，叫作不持续。”去掉逗号，与前句一致。

## §2085 句 97-2085-120-125
- **问题**：待核 — anadhiṭṭhānaṃ 的义注释作 patiṭṭhābhāvo（没有立足点），黑体译“不坚定”。意思大致说得通，但“没有立足点”和“不坚定”之间对应得不太紧。
- **建议**：以父层 §846 的译法为准；如果父层还没定，可以考虑译“不立足”，和义注的释义对齐。
