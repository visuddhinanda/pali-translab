## §1840 等 20 个问句（必改）

范围：§1840、§1844 … §1916，每 4 段一句；首句 id 217-1840-2-5。

- **问题 1**：取义 — “所举出的条目”不合义注的取义。
  - **义注**：yāni tattha samukkaṭṭhāni uttamāni padāni vuttāni（那一犍度里说到的 samukkaṭṭha、uttama 的条目），以 uttama（最上、最重要）释 samukkaṭṭha。
  - nissaya：`သမုက္ကဋ္ဌပဒါနံ= မြတ်သော ပုဒ်တို့၏`（殊胜的条目的）。
  - 两重标准都取“殊胜、最重要”，都不取“举出”。
- **问题 2**：格与句法 — “在……中”把属格译成了处所。
  - nissaya 的助词 `၏` 是属格。
  - **义注**：sā tassa tassa padassa āpattīti vuccati（那一种犯就称为那一个条目的犯），说明这里说的是“条目的犯”，不是“条目里有犯”。
- **问题 3**：风格 — “所举出的”带“所”字结构，改译后可一并消除。
- **建议**：
  - §1840 改为“最重要的条目（samukkaṭṭhapada）有几种犯？”
  - 其余问句改为“最重要的条目有几种犯？”
  - nissaya 的异释 `ဝါ= အာပတ်ကိုပြတတ်သော ပုဒ်တို့၏`（显示犯的条目）按 `style.md` 第四节作脚注备列。
  - 定案后把该词登记进 `terms.md`。
- **连带修改**：义注的被解释词要逐字同步，否则对应关系会断。
  - 142-91-24-42：黑体要改；释文“举出的、最重要的条目”也要调整，避免改后重复。
  - 142-91-60-70：引文要改。
  - 这两处交 harmonize 一并处理。

## §1842 等 18 个答句（必改）

范围：§1842、§1846 … §1914，每 4 段一句，§1866 除外（见下节）；首句 id 217-1842-2-5。

- **问题**：同上，“在所举出的条目中，有 X 种犯”的取义和属格都有误。nissaya 同样用属格：`သမုက္ကဋ္ဌပဒါနံ= တို့၏ … ဒွေ= န်သော … အာပတ္တိယော`。
- **建议**：改为“最重要的条目有 X 种犯。”犯数不变。义注黑体“两种犯”“三种”“一种”的对应不受影响。

## §1866 句 217-1866-2-15（必改）

- **问题 1**：准确性 — tattha 译成“这里”，义注的同语译作“那里”。
  - **义注**：Kathinaṃ kevalaṃ paññattimeva, natthi tattha āpatti（《迦絺那》只是一种制定，那里没有犯）。
  - 译文 142-95-2-10 用的是“那里”。tattha 指《迦絺那》犍度，译“那里”更合词义，也与义注一致。
- **问题 2**：语病 — “在……中，这里没有犯”叠了两个处所词。
- **问题 3**：取义与属格 — 同前两节。
- **建议**：改为“至于最重要的条目，那里没有犯。”

## OCR / 原文疑问（只记录，不改）
- **§1866**：pali 带异读注 `[na katamā āpattiyo (ka.)]`，即 ka 本作“没有哪些犯”。本文取 natthi tattha āpatti，义注也用同语，现译的取舍成立，没有译出异读也合理。
- **§1842 nissaya**：`ဥပသမ္မဒံ` 疑为 `ဥပသမ္ပဒံ` 之讹，同段后文作 `ဥပသမ္ပဒံ`，不影响释义。
