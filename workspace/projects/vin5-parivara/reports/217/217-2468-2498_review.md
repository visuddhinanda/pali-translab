## 被解释词核对

本层是本文，没有父层。下面反向核对义注引用本文的被解释词，不同之处应以本文为准，在 harmonize 时改义注。

- **ayaṃ vivādo no adhikaraṇaṃ（必改，改义注侧）**：§2472 译「这种诤论不是诤事」，义注 142-295-9-30 译「这是诤论，不是诤事」，两者不逐字相同。
  - **建议**：义注改为「这种诤论不是诤事」。
  - **依据**：**义注**：ayaṃ mātāputtādīnaṃ vivādo … adhikaraṇaṃ na hoti。

义注释义核对：§2472 的译文与义注的解释（母子等人之间的争论因无须以灭诤法处理，所以不是诤事）相符，未见取义相悖。

## 跨段一致性

**本层内部**

- **āpatti**：§2480-2484 译「犯」，§2471 译「粗重罪」 → 建议统一为「犯」，依据：术语表 `āpatti = 犯`（confirmed）。见 §2471 句 217-2471-8-24。
- **peyyāla（… pe …）**：§2469、§2471 译「……乃至……」，「乃」属风格禁用的文言虚词 → 建议统一为「……（略）……」；若要保留这一传统套语，需定案并登记进 `terms.md`。
- **列举后的 idaṃ**：§2473、§2478、§2483、§2488 译「这些诤事」，§2486、§2487 列四项却译「这种事务」 → 建议后者改为「这些事务」，依据：同类句式，且都是多项列举。
- **adhikaraṇañceva X ca 问句**：§2474、§2479、§2484、§2489 都有赘出「诤事」的问题，见下方对应条目。

**与义注之间（本文为准，义注侧在 harmonize 时改）**

- **anuvāda**：§2475-2479 译「指责」，义注 142-295-31-34 译「谴责」 → 建议统一为「指责」。
- **vivāda**：§2470-2474 译「诤论」，义注 142-295-9-30 同一句内既有「争论」又有「诤论」 → 建议统一为「诤论」。
- **vipatti**：§2476 译「败坏」，义注 §309 译「失坏」 → 建议统一为「败坏」。
- **ājīva**：§2476 译「生活方式」，义注 §309 译「活命」 → 建议统一为「活命」，本文也要改，见 §2476 句 217-2476-7-19。
- **bheda / vibhaṅga**：§2490、§2496 把 bheda 译为「分别」，义注 142-302-30-37 把 vibhaṅga 也译为「分别」，两个巴利词同译；现代汉语里「分别」也容易读成副词 → 建议 bheda 改为「分类」，§2490 作「诤事的分类结束」，§2496 与义注 §296 同步。
- **偈集标题**：§2497 Aparagāthāsaṅgaṇikaṃ 译「另一部偈集」，义注 §297 Dutiyagāthāsaṅgaṇikaṃ 译「第二偈集」。巴利用词不同，可以不同译，但读者看不出两者指同一部分 → 建议本文保留原译，在义注 §297 处加注说明对应关系。

## §2471 句 217-2471-8-24

- **问题**：术语 / 准确性 — 「粗重罪」不合术语表。aduṭṭhullā āpatti 是“不粗重的犯”，译成「这不是粗重罪」可能被读成根本不算犯。
- **建议**：「这是粗重的犯」或「这是不粗重的犯」。

## §2471 句 217-2471-25-47

- **问题**：风格 — aññathāvādo 译「别说」，现代读者容易读成“不要说”。
- **建议**：「异说、另一种说法」。

## §2474 句 217-2474-2-7

- **问题**：准确性 — 原文 katamaṃ adhikaraṇañceva vivādo ca 只问“哪种既是诤事又是诤论”，译文多出「诤事」作主语，读来同义反复。
- **建议**：「其中，什么既是诤事又是诤论？」

## §2476 句 217-2476-7-19

- **问题**：术语 / 风格 — ājīvavipatti 译「生活方式的败坏」，偏向一般生活习惯，义注则把它落实到因活命而制定的学处；句中「以」也是文言用法。
  - **义注**：ājīvahetupaññattehi chahi sikkhāpadehi codeti（以因活命而制定的六条学处举罪）。
- **建议**：「在这里，比丘们就戒的败坏、行为的败坏、见解的败坏或活命的败坏指责某位比丘。」

## §2479 句 217-2479-2-8

- **问题**：准确性 — 同 §2474。
- **建议**：「其中，什么既是诤事又是指责？」

## §2482 句 217-2482-8-15

- **问题**：准确性 / 可读性 — 问句译「哪种犯不是诤事」，答句却保留原词「āpatti」，读者看不出两句的关联，也不明白为什么预流、等至会被算作「犯」。此处是 āpatti 的另一义（进入、证入），属文字辨析。义注未解此句，这一判断依据词形（sota + āpatti、sam + āpatti），建议压低该句 `confidence`。
- **建议**：「预流（sotāpatti）、等至（samāpatti）——这种“犯”（āpatti，这里指“进入、证入”，不是犯戒）不是诤事。」
