# Review — 217:1979-1980（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

>
> - **nissaya 缺口**：217-1979-2-103、1980-45-64、65-86、87-109、110-132、133-154、173-197、198-216 无 nissaya 行。这些句子未作词级核对。
> - **nissaya 省略**：现有的 nissaya 对第 1、2 组三法只注明“已写于羯磨犍度”，对第 3 组只注明“按波罗提木叉 nissaya”。因此 bhaṇḍanakārako、āpattibahulo、anapadāno、gihisaṃsaṭṭho、kuladūsako 等词没有逐词释义，“不守规范”（anapadāno）的译法也未能核对。
> - **义注范围**：§1979 的羯磨条目在义注中没有逐条解释，义注只解释了 §1980 的部分词句。

## 跨段一致性

- **Tīhaṅgehi samannāgatassa**（必改）：本文全 chunk 译“三种条件”，义注 §134 译“三项条件”。
  → 建议以本文为准，义注 §134 改为“具备三种条件的比丘的律”。
- **bhaṇḍana / kalaha / vivāda / bhassa**（必改）：本文 §1979、§1980 依次译“纷争／争吵／争论／口角”，义注 §133 依次译 bhaṇḍana“争吵”、kalaha“口角”、vivāda“诤论”。同一个“争吵”和“口角”在两层对应不同的巴利词，对应关系是错位的。
  → 建议本文改为“制造争吵、制造口角、制造诤论、制造争辩”，义注不动。bhassa 没有义注依据，“争辩”是建议译法。
- **āpatti**（必改）：`term-glossary.jsonl` 已确认译“犯”，义注也用“犯／所犯”。本文却有三种译法：
  - “违犯”：§1979 的 āpattibahulo，§1980-173-197 的 āpatti；
  - “所犯”：§1979 的 adassane、appaṭikamme 等句；
  - “犯了戒”：§1980-155-172 的 āpattiṃ āpanno。

  义注 §132 还用“违犯”译 vītikkama（违犯学处），所以用“违犯”译 āpatti 会混淆两个术语。
  → 建议统一用“犯”；“所犯”可保留，与义注一致。
- **三支的切分**（必改）：同一段文字在两段切分不同。
  - §1980-2-28 切为：制造纷争… / 愚痴、无能，多有违犯，不守规范 / 与在家人混杂而住。
  - §1979 全部七条切为：制造纷争… / 愚痴、无能 / 多有违犯，不守规范，与在家人混杂而住（或第三支的其他内容）。

  → 建议统一为 §1980 的切法。巴利逗号在两段的位置也不同，见文末“OCR / 原文疑问”。本次资料未包含《小品》原文，定稿前请查 [小品 .6] 的切分。
- **passati**：同一句内 adassane 译“不见”，passituṃ 译“正视”。见 §1979 句 217-1979-104-240。

## §1979 句 217-1979-2-103

- **问题**：准确性 — 三支切分有误，āpattibahulo anapadāno 被划入第三支（见跨段一致性）。
- **建议**：呵责羯磨和依止羯磨两条改为“他愚痴、无能，多有犯，不守规范；他……与在家人混在一起生活”。驱出羯磨一条改为“他愚痴、无能，多有犯，不守规范；他败坏信众家庭，行为恶劣，他的恶行既被人看见，也被人听到”。

- **问题**：句法 — ananulomikehi gihisaṃsaggehi 是具格，修饰 gihisaṃsaṭṭho viharati，表示以什么方式混住。译文拆成了两个并列分句。本句无 nissaya，此判断只依巴利语法。
- **建议**：合为一句，如“他以不相宜的交往，和在家人混在一起生活”。

- **问题**：风格（必改）— “混杂而住”是半文半白句式，§1980-2-28 也有同样的问题。
- **建议**：改为“混在一起生活”。

- **问题**：格式 — “[小品 .6]”等出处标记用半角方括号，且带空格和半角点，本句与 217-1979-104-240 都有。
- **建议**：这不是本句独有的问题，请在 harmonize 时统一出处标记的体例。

## §1979 句 217-1979-104-240

- **问题**：误译（必改）— paribhāsati 译作“斥责”。nissaya 为 `ပရိဘာသတိ= ခြိမ်းချောက်၏`（威吓、恐吓），不是斥责。
- **建议**：改为“辱骂、恐吓在家人”。

- **问题**：不一致（必改）— passituṃ 译作“正视”，与同句 adassane 的“不见”不对应。nissaya 为 `ပဿိတုံ= ရှုခြင်းငှာ`（看），义注 §131 也作“不见所犯”。
- **建议**：改为“犯了之后不愿意见所犯”。

- **问题**：取义（建议）— appaṭikamma、paṭikātuṃ 译作“忏悔”。nissaya 为 `အပ္ပဋိကမ္မေ= မကုစားခြင်းကြောင့်`（因不对治、不补救）。义注 §130 另用“忏悔”译 desanā，两个概念被混为一个词。不过义注 §131 也把 appaṭikaronta 译作“不忏悔”，这是两层共有的问题。
- **建议**：两层一并改为“不补救所犯”或“不如法处理所犯”，定案后登记进 `terms.md`。

- **问题**：准确性 — 三支切分同 217-1979-2-103。
- **建议**：四条都改为“他愚痴、无能，多有犯，不守规范；他……”。

- **问题**：风格 — “因他不见所犯”“因他不忏悔所犯”“因他不舍弃恶见”中的单音节“因”偏文言。
- **建议**：改为“因为他……”。

## §1980 句 217-1980-2-28

- **问题**：术语（必改）— “纷争／争吵／争论／口角”与义注不对应（见跨段一致性），“多有违犯”不合术语表。
- **建议**：改为“制造争吵、制造口角、制造诤论、制造争辩……多有犯”。

- **问题**：风格（必改）— “混杂而住”。
- **建议**：同 217-1979-2-103。

## §1980 句 217-1980-155-172

- **问题**：术语（必改）— āpattiṃ āpanno 译作“犯了戒”。āpatti 不等于“戒”，术语表定为“犯”。nissaya 为 `အာပတ္တိံ= သို့။ အာပန္နော= ရောက်ပြီးသည်`（已陷入犯）。
- **建议**：改为“他有了犯、被作了羯磨之后，仍然为人授具足戒……”。

## §1980 句 217-1980-173-197

- **问题**：术语（必改）— 三处“违犯”不合术语表。
- **建议**：改为“僧团因为某种犯对他作了羯磨，他又犯那种犯，或者犯其他类似的犯，或者犯比那更恶劣的犯”。

## 存疑

- **“……乃至……”（pe）**：“乃”在 `style.md` 的文言虚词禁表内，但“乃至”是省略标记的惯用译法，这里未列为必改。建议全书定一个体例后写入 `style.md`。
- **Āgāḷhāya ceteyya**：nissaya 把 ceteyya 释为“督促、努力”（`စေ့ဆော် ကြိုးကုတ်, အားထုတ်ရာ၏`），并给出异释“再作举罪羯磨”。义注也把此句落实为作举罪羯磨。“决定从严处置”与义注的被解释词一致，可保留；具体所指可考虑由 footnote 步骤补出。

## OCR / 原文疑问（只记录，不改）

- **217-1979-2-103 的 `kuladūkako`**：疑为 `kuladūsako` 之讹，nissaya 作 `ကူလဒူသကော`（kuladūsako）。
- **217-1979-104-240 的 `āpatti bahulo`**：疑多一空格，其他各处都作 `āpattibahulo`。
- **逗号位置**：§1979 作 `bālo hoti abyatto , āpattibahulo anapadāno`，§1980 作 `bālo hoti abyatto āpattibahulo anapadāno ,`，这是译文切分不一致的来源。
- **nissaya 坐标**：217-1979-104-240 的 nissaya 行含第 3 组的 kuladūsako 词条，但该词在 217-1979-2-103 的范围内，这一行的覆盖范围与句坐标不完全对应。
