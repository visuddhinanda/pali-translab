## 跨段一致性
- **api ca**：216-2776-152-167、216-2776-229-243 译“而且”，216-2776-429-447、216-2776-470-487 译“不过” → 必改，统一为“不过”。依据：nissaya `အပိစ= ထိုသို့မေတ္တာဝိဟာရဖြင့် နေလေ့ရှိပါသော်လည်း`（虽然惯常这样安住）。
- **dhammavādī / dhammavādino**：216-2776-351-365、216-2776-393-407 译“如法而说的人”，216-2776-408-428、216-2776-448-469 译“说的合于法” → 必改，统一为“说的合于法”。
- **bhūmi 与 āvuso**：两个称呼都译“贤友”，读者看不出区别 → 建议保留现译，并在首次出现处夹注 bhūmi，与义注 141-657-2-14 一致。依据：**义注**：bhūmī ti piyavacanametaṃ（这是亲切的称呼）；nissaya `ဘူမိ= ငါ့ရှင်`。
- **bahulaṃ**：全章译“多半”，该词也常作“大概”解，“你现在多半安住在……”可能被读成猜测 → 建议统一改为“大多时候”，涉及 216-2776-85-97、98-113、114-124、152-167、168-183、184-196、197-208、229-243。义注 141-657-2-14 的被解释词要同步改，否则对应关系会断。
- **平行句式**：216-2776-43-58 无转折，216-2776-59-72 有“却” → 统一，见下方 216-2776-43-58。

## §2775 句 216-2775-2-19
- **问题**：准确性（建议）— “世间僧团的上座”可能被误读为“世俗的僧团”。pathabyā 指全大地。依据：`ပထဗျာ= တမြေပြင်လုံး၌`（在整个大地上）。
- **建议**：改为“是全世界僧团的上座”。

## §2776 句 216-2776-43-58
- **问题 1**：nissaya 词法（必改）— 漏了让步语气。依据：`မဟလ္လကော= အရွယ်တော်ကြီးသည်။ (ဟုတွာ= ၍။ ဝါ= ဖြစ်ပါလျက်)`（虽然年老）。
- **问题 2**：风格（必改）— “年事已高”偏文雅。
- **建议**：改为“这位长老年纪很大了，却还没有躺下。”

## §2776 句 216-2776-114-124
- **问题 1**：nissaya 词法（必改）— “听你这么说”把 kira 译成了转述，这里是恍然或感叹的语气。依据：平行句 `ဝိဟရတိ ကိရ= နေတော်မူပါတကား။ (နေတော်မူပါကလား)`（原来是这样住啊）。
- **问题 2**：术语（建议）— “小住”在现代汉语中常指短暂停留，容易误解。**义注**：Kullakavihārenā ti uttānavihārena（小住，就是浅显的住）；nissaya：`‌ပေါ်လွင်သော`（显露的）、`ပေါ့ပါးလွယ်ကူသော`（轻易的）。
- **建议**：改为“贤友，原来你现在多半安住在小住（kullakavihāra）之中。”若要换掉“小住”，须与义注 141-657-25-28 同步。

## §2776 句 216-2776-125-140
- **问题**：风格（建议）— “这慈”不够自然，也与 216-2776-209-219 的“这空”同样生硬。
- **建议**：改为“贤友，慈确实是一种小住。”216-2776-209-219 同样改为“大德，空确实是大人住。”

## §2776 句 216-2776-152-167
- **问题**：nissaya 词法（必改）— “而且”把让步关系译成了递进，依据见跨段一致性 api ca。
- **建议**：改为“所以我现在也多半安住在慈住之中，不过我证得阿罗汉果已经很久了。”

## §2776 句 216-2776-184-196
- **问题**：术语（建议）— “空住”首次出现未夹注，不符合 `style.md` 第二节。nissaya 明确其所指：`သုညတဝိဟာရေန= သုညတမည်သော ဖလသမာပတ်ဟူသော နေကြောင်းတရားဖြင့်`（名为“空”的果定这种安住之法）。
- **建议**：改为“空住（suññatāvihāra）”。“慈住”“大人住”的首次出现也应按此夹注。

## §2776 句 216-2776-197-208
- **问题**：nissaya 词法（必改）— “听您这么说”与 216-2776-114-124 同误。依据：`ဝိဟရတိ ကိရ= နေတော်မူပါတကား။`

## §2776 句 216-2776-351-365

## §2779 句 216-2779-44-46
