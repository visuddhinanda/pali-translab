# Review — 192:736-740（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 一、被解释词与父层逐字核对（必改项）

- **§738 句 192-738-154-157**：**Tassā** 在父层 130-652-89 句（Tassa sampāpakaṃ）译作“**那处**”（“能到达那处的圣道”），这里译成“它的”，和父层对不上 → 改为“**那处**”，是指苦灭。
- **§739 句 192-739-2-6**：**Kilesavasena** 在父层 130-653-2 句译作“**以烦恼**”（“按方式以烦恼来说明”），这里译成“依烦恼而说” → 改为“**以烦恼**”。
- **§739 句 192-739-19-25**：**Pariyāyato** 在父层译作“**按方式**”，这里译成“依方式而说” → 改为“**按方式**”。
- **§738 句 192-738-12-43**：
  - 引文 tatra cetaṃ ñāṇaṃ 在父层是“而这智慧就属于那道”，这里写成“而这智慧属于那（道）”，少了“就”字，“道”也多了括号 → 照父层原文引。
  - tappariyāpannattā 在父层是“因为它归属于那道的缘故”，这里写成“因属于那（道）之故” → 照父层原文引。
  - **āsavakkhayañāṇaṃ** 是黑体，但译文里没有加粗。
- **§738 句 192-738-119-129**：**Yaṃ ṭhānaṃ patvā** 在父层是“这两者**所到达**而灭尽**之处**”，被“而灭尽”隔开了。这里合写成“所到达之处”，可以接受，但不是逐字照引。harmonize 时可以考虑改成“所到达……之处”，或者调整父层语序。
- **§740 句 192-740-88-91**：**So** 在父层 130-653-111 句里直接译成“世尊”，父层没有“他”字，所以这里的“**他**”在父层找不到对应 → 必须对齐。建议父层改为“他（世尊）省察……”，或者这里改成“**世尊**”，但那样等于用释义去解释释义本身，不推荐，所以以改父层为宜。
- **§740 句 192-740-83-87**：**Taṃ**（taṃ so … abbhaññāsi）在父层 130-653-111 句里没有明确译出（只有句末的“就这样了知了”）。这里的“**它**”在父层找不到对应 → 交 harmonize 补进父层，例如“世尊……就这样了知了它（那生）”。
- **黑体标记丢失（通病）**：在 ‘‘…’’ 里引用的黑体词，译文都没有加粗。涉及 738-76、738-110、739-19、739-49、739-103、740-21、740-46、740-65 各句 → 统一补上 `**…**`。

## 二、跨段一致性

- **vaṇṇanā**：§736 译成“漏尽智论**释义**”，父层 §651/§657 是“漏尽智论**讲解**” → 统一为“讲解”。
- **khaṇa**：§739（192-739-103-127）写“道**剎那**”“果**剎那**”，父层 130-653-38 是“果位的**时刻**”“道的时刻”，而本句在引文里又照父层写了“时刻”，同一句里两种译法并存 → 统一为“时刻”。另外“剎”是异体字，就算保留“刹那”也要改成规范字“刹”。
- **vipassanā**：§737 首句写“**观禅**基础”（照父层），解释部分却写“**观**的近因”“观智”“观行”。按父层，独立出现的 vipassanā 是“观禅”（“连同观禅一起”“观禅之心”）→ 单用时统一为“观禅”，复合词（观智）可以保留。
- **vasena / ‑to**：本层混用“依……”“以……”“按……”，父层的说法是“按方式”“以烦恼”“以四道……的方式”。被解释词以外的地方也建议向父层靠拢。
- **文言残留（必改）**：
  - 738-12：“故说”“之故”→“所以说”“因为……”
  - 738-146：“故称”“在此”→“所以称为”“在这里”
  - 739-42：“实以举要的方式”→“其实是用举出要点的方式”
  - 739-134：“知之因、见之因”→“因为知、因为见”
  - 740-37：“以微理提出诘难”→“牵强地提出质疑”（lesa 是借口、牵强的理由）

## 三、逐句词法（有 nissaya 引用的 §740 各句）

### §740 句 192-740-13-20
- **问题**：格的误读。maggabhāvanāya 是具格，表示原因或手段，补足的是“khīṇā”（已尽）：意思是过去的生**不是因修道而尽**。译文“就道的修习而言”把具格读成了关涉范围。
- **建议**：“**他所尽的既不是过去的生**”，意思是：不是因为修道而尽的。

### §740 句 192-740-31-36
- **问题**：assa 的语法角色误读。这里是 yojanā，重述父层 na tāvassa（= tāva **assa**，代词属格“他的”），assa 应是属格“他的”。译文译成“会有的”，当成了 atthi 的祈愿式。
- **建议**：这句应连接为：也不是他未来的生已经尽了。

### §740 句 192-740-37-45
- **问题**：词义。lesena 是具格，表示方式，意思是“借着牵强的理由”。“以微理”意义不明，还带文言腔。
- **建议**：……是取“未来”这一共通义，牵强地提出质疑。

### §740 句 192-740-46-64
- **问题**：tassa 是属格代词，指上文的 anāgataviseso（特定的未来生），不是泛指的“它”。译文“灭尽它这件事”指代不清。
- **建议**：而要灭尽那特定的未来生，努力也是可以有的。

### §740 句 192-740-75-82
- **问题**：bhavattayaggahaṇaṃ 是动作名词，后面接目的的与格/‑atthaṃ，意思是“提到三有，是为了……”。“取三有一词”的说法生硬。
- **建议**：“**在一蕴、四蕴、五蕴的诸有中**”，提到三有，是为了按前面说的方式，表明生已经无余地尽了。

## 四、其他（无 nissaya，只记词法硬伤，供 revise 参考）

- **192-738-86-92**：sabhāvasaṅkhātassa lakkhaṇassa 是属格链，意思是“称为自性的那个相”。译文“通达所称的自相”结构残缺。另外，本句把 sarasa 解作 sabhāva（自性），和父层的“自相**与共相**”有出入。这是父层译法的问题，留给 harmonize 处理，不影响本句对黑体的照引。
- **192-739-141-150**：samavarodha 的意思是“包含、摄入”，不是“遮止”。句子结构是：“正如（有漏）包含有贪，也包含有见，所以应知见漏也摄在其中”。译文“对有贪的完全遮止”是误读。另外，“有漏”在汉传语境里通常指 sāsava，容易混淆，建议首次出现时夹注（bhavāsava）。
- **OCR 存疑**：192-738-53-61 的巴利原文（Ettakaṃ dukkhan ti dukkhassa ariyasaccassa tadā paccakkhato…）和上一句 44-52 的释文完全一样，紧接着的 62-68 又重复用 Ettakaṃ dukkhan 作被解释词，可能是底本衍文或切分错误。照原文记下，不改。
