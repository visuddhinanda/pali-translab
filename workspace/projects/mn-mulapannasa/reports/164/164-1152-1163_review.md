# Review — 164:1152-1163（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 跨段一致性

- **atirekapūjāya**：§1153 译「过度供养者」，§1155 译「格外的照顾」/「格外的供养」→ 建议统一为「格外的」一系（如「特别的礼敬/供养」）。「过度」带贬义（excessive），而 atireka 在此表「额外的敬重」，是正面义；§1153 用「过度」既与本 chunk 其余处不一致，也偏离了词义感情色彩，属必改项。
- **pītaṃ jānāti**：§1155（牧牛人义）「知道牛已经喝够了水」，§1155（比丘义列举）「知道喝够了」，§1162（标题及释义）「知道已经喝够了的」→ 三处措辞不一，建议统一，例如均定为「知道（牛/比丘）已喝够」这一固定短语，减少变体。
- 其余术语（rūpaññū / lakkhaṇakusalo / āsāṭikaṃ hāretā / vaṇaṃ paṭicchādetā / dhūmaṃ kattā / titthaṃ jānāti / vīthiṃ jānāti / gocarakusalo）在牧牛人义与比丘义之间用法基本一致，无需改动。

## §1157 句 164-1157-12-24
- **问题**：准确性 — "kammalakkhaṇo bālo, kammalakkhaṇo paṇḍito" 原意是「以业（行为）为标志可知愚者，以业为标志可知智者」（即：由其所作之业辨别愚智），而非"业相是由愚者/智者所造"。译文「这是愚者所造的业相，这是智者所造的业相」把主谓关系颠倒，变成"业相由谁制造"，偏离原意。
- **建议**：改为类似「愚者以其所作之业为标志，智者亦以其所作之业为标志」或「由所造之业可知何为愚者、何为智者」，更贴合"藉业辨识愚智"的原意。

## §1153 句 164-1153-2-23
- **问题**：术语/措辞 — 「过度供养者」使用「过度」，与本 chunk 内 §1155 的「格外的照顾/供养」不一致，且「过度」含负面义，误导为"给予过多"而非"给予特别的礼敬"。见跨段一致性条目。
- **建议**：改为「特别供养者」或「格外礼敬者」，与后文统一。

## §1155 句 164-1155-25-64、164-1155-110-148、§1162 句 164-1162-2-11 / 164-1162-30-38
- **问题**：跨段一致性 — pītaṃ jānāti 三处措辞不一。见跨段一致性条目。
- **建议**：统一译法，如均作「知道（是否）已喝够」。
