# Review — 164:89-94（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（164-90-31-57、164-93-2-4、164-93-5-11 无 nissaya，略过）

## 跨段一致性
- 无

## §91 句 164-91-2-21
- **问题**：补出成分 — 句首 `Yañhissa`（= yaṃ hi assa）与后半 `evaṃsa`（= evaṃ assa）中的 `assa` 指这位比丘，nissaya 以处格标出：`အဿ= ၌`，意为“对他而言”。`abhāvayato` 的对象也由 nissaya 补出：`အဘာဝယတော= ဗောဇ္ဈင်တရားကို မပွားများသော`，即“不修习觉支法的”。现译“若不修习……若修习了”既没有人，也没有对象，读者看不出不修习的是什么。另外，“若”带文言色彩。
- **建议**：改为“诸比丘，如果他不修习（觉支），就会生起使人苦恼、烦热的漏；他这样修习，这些使人苦恼、烦热的漏就不会生起。”

## §92 句 164-92-2-78
- **问题 1**：格与句法 — nissaya 把 `bhikkhuno` 标为属格：`ယတော ဘိက္ခုနော= အကြင်ရဟန်း၏`，即“比丘的”。漏是比丘的漏，比丘不是断除漏的人。现译“当比丘应由知见断除的漏，已由知见断除了”可以读成“比丘应当由知见去断除”，比丘就成了施事，与 nissaya 不符。
- **建议 1**：改为“当比丘那些应由见断除的漏已由见断除，那些应由防护断除的漏已由防护断除……”，用“比丘那些……的漏”把属格关系写明。
- **问题 2**：词义 — nissaya 对 `dassanā` 的释义是 `ဒဿနာပဟာတဗ္ဗာ= သောတာပတ္တိမဂ်သည် ပယ်အပ်ကုန်၏`，即“应由预流道断除的”。dassana 指见道，单作“见”就够。现译“知见”多出“知”字，又与 ñāṇadassana（知见）的通行译名相撞。
- **建议 2**：本句七处“由知见”都改为“由见”。本经前文如果也作“知见”，交 harmonize 全经统一。

## §92 句 164-92-79-83
- **问题**：格与句法 — nissaya 把 `ayaṃ` 与本句之后的 `bhikkhu` 连读：`အယံဘိက္ခု= ကို`，即“这位比丘”。被称作“……者”的是这位比丘，`ayaṃ` 不是泛指前述情形的“这”。现译“这就称为——”把主语译成了事态，下句引文又重复“比丘”，造成主语错位。
- **建议**：改为“诸比丘，这位比丘被称为——”。下句引文同步删去开头的“比丘”（见下条）。

## §92 句 164-92-84-119
- **问题 1**：格与句法 — nissaya 的 `ဟူ၍` 依次挂在 `viharati / acchecchi / vivattayi / akāsi` 上，全句是对“这位比丘”的一串称谓：“……而住的比丘”“已斩断渴爱的人”“已使结不再转起的人”“已终结苦的人”。`sabbāsavasaṃvarasaṃvuto` 是过去分词，nissaya 作 `၍`，意为“已防护了……而”。现译“安住于防护一切漏”把它弄成了“住于防护”的动宾结构。
- **建议 1**：引文改为“‘他以防护一切漏的防护而防护，这样安住；他已斩断渴爱，已转离结，以正确的方式现观并断除慢，已终结了苦。’”。引文开头不再重复“比丘”，与上句“这位比丘被称为”衔接。
- **问题 2**：漏译／增译 — `acchecchi taṇhaṃ` 中没有“一切”，nissaya 作 `တဏှံ= တဏှာကို`，即“渴爱”宾格，没有全称量词。现译“彻底斩断了一切渴爱”增出了“一切”和“彻底”。
- **建议 2**：改为“已斩断渴爱”。
- **问题 3**：词义 — nissaya 对 `vivattayi` 的释义是 `ဝိဝတ္တယိ= မလည်စေပြီးသူ`，即“已使之不再转动的人”，意思是转离、令不再转起。现译“解开”不贴切。`saṃyojana` 的通行译名是“结”，译作“结缚”属于增字。
- **建议 3**：改为“已转离结”。
- **问题 4**：格与句法、术语 — nissaya 对 `sammā` 的释义是 `သမ္မာ= သင့်သောအကြောင်းအားဖြင့်`，即“以正确的方式”，作具格副词，现译“如实”可以接受，但不如“以正确的方式”或“正确地”贴切。nissaya 对 `mānābhisamayā` 的释义是 `မာနကို သိခြင်းပယ်ခြင်းကြောင့်`，即“由于了知并断除慢”，从格表原因，现译的结构与此相符。不过 māna 应译“慢”，现译“我慢”多出“我”字。
- **建议 4**：改为“以正确的方式现观并断除慢”，即“我慢”改为“慢”。
- **问题 5**：增译 — nissaya 对 `antamakāsi dukkhassa` 的释义是 `ဒုက္ခဿ= ဆင်းရဲ၏ … အန္တံ= အဆုံးကို … အကာသိ= ပြုပြီးသူ`，即“已作了苦的终结的人”。现译“究竟灭尽了苦”中的“究竟”是增出的。
- **建议 5**：改为“已终结了苦”或“已作了苦的终结”。

## §94 句 164-94-2-5
- **问题**：误译 — nissaya 对 `dutiyaṃ` 的释义是 `ဒုတိယံ= သော`，作定语修饰主格 `Sabbāsavasuttaṃ`（`= သည်`），意思是“第二部经”。这里的序数说的是经在本品中的次序，原文没有“品”。现译“第二品”是误读。
- **建议**：改为“第二经《一切漏经》终。”或“一切漏经（第二经）完。”
