# Review — 164:545-550（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供）／义注：仅覆盖 §550（对应 book130 §1722-1728），§545-549 无对应义注段落，本报告对 §545-549 仅依据原文与术语一致性审查

## 跨段一致性
- `kāmānaṃ ādīnavo sandiṭṭhiko dukkhakkhandho`：§545/546/547/548 均译「欲的过患，是现前可见的苦聚」，用语统一 — 无问题
- `maraṇamattampi dukkhaṃ`：各段均译「遭受近乎死亡的痛苦」，统一 — 无问题
- 「抢劫」一词在 §548 内先后用于 `nillopampi haranti`（抢劫掠夺）与 `ekāgārikampi karonti`（实施抢劫），两个不同巴利词译法重叠，建议区分（`ekāgārikaṃ` 指"独家入室行劫"，可译"入室行劫"）
- 其余跨段术语与语体未见明显不一致

## §550 句 164-550-18-47
- **问题**：地名误译 — `isigilipasse`（仙人堕处山侧）被译为「耆阇崛山侧」，与前句 `gijjhakūṭe pabbate`（灵鹫山）混同为同一座山。**义注**：`**Isigilipasse**ti isigilipabbatassa passe`，明确 Isigili 是与 Gijjhakūṭa 不同的另一座山（前文 §1723 已单独为 `Gijjhakūṭe pabbate` 作词源解释），佛陀先住灵鹫山，后于傍晚"前往"（`yena isigilipasse... tenupasaṅkamiṃ`）另一座山会见尼乾子，若译作同一山则句意（"前往"的动作）失去着落
- **建议**：改译为「耆利仙人山侧」或「仙人堕处山侧」（Isigili 传统汉译），与「灵鹫山」区分开

## §550 句 164-550-48-64
- **问题**：同上，`isigilipasse kāḷasilāyaṃ` 再次被译为「耆阇崛山侧」，重复同一错误
- **建议**：同上，统一改为 Isigili 山侧的译名，与 §550-18-47 保持一致

## §548 句 164-548-64-117
- **问题**：漏译一项刑罚。原文列举 13 种刑罚（bilaṅgathālika / saṅkhamuṇḍika / rāhumukha / jotimālika / hatthapajjotika / **erakavattika** / cīrakavāsika / eṇeyyaka / baḷisamaṃsika / kahāpaṇika / khārāpatacchika / palighaparivattika / palālapīṭhaka），译文只给出 12 个刑名（粥锅刑/贝壳剃头刑/罗睺口刑/火鬘刑/手炬刑/草衣刑/羚羊皮刑/钩肉刑/钱币刑/碱水洗创刑/门闩转刑/稻草垫刑），`erakavattika`（传统译"草绳刑"，以草绳绞勒皮肤）未见对应译词，疑似被合并进「草衣刑」而丢失
- **建议**：在「手炬刑」与「草衣刑」（对应 cīrakavāsika）之间补译 `erakavattika` 一项（如"草绳刑"），使 13 项刑罚与原文一一对应

## §547 句 164-547-33-50
- **存疑**：`abhivaggenapi omaddanti` 译为「被铁钩击碎」，`abhivagga` 传统上多解为大型器具/重物压砸而非"钩"，与前一分句 `chakaṇakāyapi osiñcanti`（粪便浇洒）为一组刑罚描写。建议核实该词准确所指（压砸类刑具，而非钩类），如无更可靠依据，至少在报告中留存疑，不要以确定语气写入译文
