# Review — 192:381-387（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层（阿嗒卡他，book 130）译文 ✅／nissaya ❌（未提供，本次审查缺此项）

## 被解释词与父层核对（首要项）

复注中大量黑体词直接引自父层（book 130）阿嗒卡他中所引《无碍解道》原文（即父层段 330 的 "purimakammabhavasmiṃ moho avijjā, āyūhanā saṅkhārā..." 一段），父层译文已定稿为"X 是 Y"句式（如"痴是无明""积集是诸行"）。本次待审译文里，凡遇到这类 "X Y"（系表结构）的黑体短语，译者一律改译成了"X，即 Y"，与父层逐字不符，判定为必改项，需逐一改回父层的"是"字句式：

- §385 "**Moho** **avijjā**"：译文"**痴，即无明**" → 应改为"**痴是无明**"（父层 130-330："痴是无明"）
- §385 "**Āyūhanā** **saṅkhārā**"：译文"**积集，即诸行**" → 应改为"**积集是诸行**"（父层："积集是诸行"）
- §385 "**Nikanti** **taṇhā**"：译文"**喜爱，即爱**" → 应改为"**喜爱是爱**"（父层："喜爱是爱"）
- §385 "**Upagamanaṃ** **upādānan**"：译文"**趣入，即取**" → 应改为"**趣入是取**"（父层："趣入是取"）
- §385 "**Cetanā** **bhavo**"：译文"**思，即有**" → 应改为"**思是有**"（父层："思是有"）
- §386 "**Idha** **paṭisandhiviññāṇan**"：译文"**此世的结生识**" → 应改为"**此世的结生是识**"（父层："此世的结生是识"）
- §386 "**Okkanti** **nāmarūpan**"：译文"**入胎，即名色**" → 应改为"**入胎是名色**"（父层："入胎是名色"）
- §386 "**Pasādo** **āyatanan**"：译文"**净色，即处**" → 应改为"**净色是处**"（父层："净色是处"）
- §386 "**Phuṭṭho** **phasso**"：译文"**触及，即触**" → 应改为"**触及是触**"（父层："触及是触"）
- §386 "**Vedayitaṃ** **vedanā**"：译文"**所受，即受**" → 应改为"**所受是受**"（父层："所受是受"）

这是同一种句式在两段中被系统性地改写，不是偶发笔误，属于跨段一致性问题（见下），revise 时应统一按父层"是"字句式改回。

- §382 "**‘‘sattassā’’**"：译文"因此说“**属于众生**”" — 父层 130-326 对应译文为"“**有情**”是指**众生**"（sattassa → 众生，不含"属于"）。此处添了"属于"二字，与父层不完全逐字一致，建议改为"因此说‘**众生**’"。

其余黑体词核对无误，与父层逐字相同：
- §383 "**catusaṅkhepaṃ**"→"四支分"、"**tisandhiṃ**"→"三连结"、"**tiyaddhaṃ**"→"三时"、"**vīsatākāraṃ**"→"二十行相"，均与父层 130-327/328 一致。
- §383 "**yaṃ bodhirukkhamūle…pe…dassento**"译"坐在菩提树下……乃至……开示出来"，与父层 130-327 首尾用词一致。
- §382 "**Bhūtassā**"→"有情"，与父层一致。
- §384 "**Esa sabbo**"→"这全部"，与父层一致。
- §387 "**Idha paripakkattā āyatanānaṃ moho**"→"此世由于诸处成熟的缘故，痴"，与父层对应片段一致（未含 avijjā，未强行补"是无明"，处理得当）。

## 跨段一致性
- §385、§386 内五处"X 是 Y"型黑体短语被统一误译为"X，即 Y"，属系统性偏差，两段应一并改正为与父层一致的"是"字句式（见上）。
- 其余术语（结生、名色、六处、触、受、业有、生有等）在 §385–387 内前后译法一致，无漂移问题。

## §383 句 383-2-100（id = 192-383-2-100）
- **问题**：无实质性错误，仅提示——句子极长（一整句涵盖"即使……乃至……开示出来"），审读时需留意长句内部逻辑链是否清楚；目前逻辑连接词（"由于""因此""为了阐明"）使用得当，不算文言化，可保留。
