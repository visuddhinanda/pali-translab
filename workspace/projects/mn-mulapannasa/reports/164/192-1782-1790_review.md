# Review — 192:1782-1790（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供，本次未审词级）／义注 ✅（本层为复注，父层母本文+义注译文已提供，用于被解释词核对）

## 跨段一致性

- **nīhaṭaṃ + bhatta（携出之食 / 省下的饭食）**：§1787 复注对 `nīhaṭabhattena` 的被解释词译为“携出之食”，但父层 130-2161-42-52 中同一词已定译为“省下的饭食”（“世尊这样以省下的饭食教导他们”）。这是硬约束要求逐字同译的被解释词，必改，统一为“省下的饭食”。
- **maggaṃ āruḷhā 引文（走上了……同样的道路 / 已经走上了……所走过的道路）**：§1787 两处（word 58-73 与 145-153）引用义注原话“tumhepi mamañceva pañcavaggiyānañca maggaṃ āruḷhā, ariyapariyesanā tumhākaṃ pariyesanā”，均译作“你们也走上了我与五比丘同样的道路，圣的寻求就是你们的寻求”，与父层 130-2096-52-58/59-73 已定稿译文“你们也已经走上了我和五比丘所走过的道路……圣的寻求就是你们的寻求”不逐字一致（漏“已经”，“同样的道路”应为“所走过的道路”）。这是引自义注/母本的固定文句，两处都要改，且要与父层保持逐字一致。
- **paribhogaraso（受用之味 / 受用时所生的味）**：§1788“Paribhogaraso”译为“受用之味”，父层 130-2162-42-46 对同一概念的行文是“受用时所生的味”。此处父层未将该词加黑体，非强制逐字同译，但建议统一措辞为“受用时所生的味”以保持术语一致，非必改项，供参考。
