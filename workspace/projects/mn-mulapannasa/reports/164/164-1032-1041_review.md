# Review — 164:1032-1041（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核）

## 跨段一致性
- **samodhānaṃ gacchanti / saṅgahaṃ gacchanti**：§1033 两句都译成“归入”，前后两个动词没有区分。nissaya 分别作 `သမောဓာနံ= အကျုံးဝင်ခြင်းသို့`（纳入、被包容）和 `သင်္ဂဟံ= ရေတွက်အပ်သည်၏ အဖြစ်သို့`（被计入、被摄）。建议：象迹句保留“归入”，善法句改为“被摄入”或“都摄于”，这样喻体和合法两边的用词各有分别。
- **yāni kānici … sabbāni / ye keci … sabbe**：§1033 的喻体与合法是平行句式。喻体译成“一切走兽的足迹，全都……”，合法译成“无论是什么善法，全都……”，两句结构不一致，而且喻体里的“一切”和“全都”重复。建议喻体也改成“无论走兽有哪些足迹，全都……”，与合法对齐。
- **alābhā vata me … suladdhaṃ**：§1041 这个句组出现两次（句 32-72 与 115-152）。下面句 32-72 修订后，第二处要逐字同步。
- **文言残留**：§1038 句 54-68 的“短暂**之**身”，§1039 句 78-85 的“**便**投向”。各句的具体改法见下。

## §1033 句 164-1033-54-76
- **问题**：词法：jaṅgalānaṃ pāṇānaṃ 的语义范围。nissaya 作 `ဇင်္ဂလာနံ= မြေ၌ သွားကုန်သော`（在地上行走的）、`ပါဏာနံ= အခြေရှိသော သတ္တဝါတို့၏`（有足众生的，属格）。“走兽”勉强可以接受，但 kānici（`အချို့ကုန်သော`，任何一些）被译成了“一切”，与后面的 sabbāni“全都”重复。
- **建议**：改为“就好比地上行走的众生，无论有哪些足迹，全都归入象的足迹之中……”。

## §1033 句 164-1033-77-91
- **问题**：词法：saṅgahaṃ gacchanti 是“到达被计入、被摄的状态”（`ရေတွက်အပ်သည်၏ အဖြစ်သို့ ရောက်ကုန်၏`），与上句 samodhāna 不是同一个词。
- **建议**：改为“……全都被摄入四圣谛之中”。

## §1037 句 164-1037-26-65
- **问题 1**：误译：kharigataṃ 的 nissaya 是 `ကြမ်းတမ်း၏`（粗糙、粗糙），不是“坚固”。现在两处都译成“属于坚固性质的”，与 kakkhaḷaṃ“坚硬的”意思重叠。
- **建议**：两处都改为“粗糙的”。
- **问题 2**：词义：antaguṇaṃ 的 nissaya 是 `အူသိမ်`（细肠、小肠），antaṃ 是 `အူမ`（主肠、大肠），两者成对。译文作“肠系膜”，与 nissaya 不合。
- **建议**：按 nissaya 改为“小肠”，与前面的“大肠”成对。
- **问题 3**：句末“……被执取的东西”。nissaya 补出的主语是 `ယံ= အကြင်ပထဝီဓာတ်သည်`（凡是地界），“东西”泛化了所指，但这一处可以接受。

## §1038 句 164-1038-2-24
- **问题**：误译（译得过弱）：pakuppati 的 nissaya 是 `ပျက်စီး၏`（毁坏、败坏），指水界暴发成灾，“发生变动”太轻了。
- **建议**：改为“外在的水界暴发”或“外在的水界泛滥成灾”。

## §1038 句 164-1038-32-53
- **问题**：误译（khaya / vaya 对调）：nissaya 作 `ခယဓမ္မတာ= ကုန်ခြင်းသဘော`（尽的性质）、`ဝယဓမ္မတာ= ပျက်ခြင်းသဘော`（坏的性质）。译文把 khaya 译成“坏灭性”，把 vaya 译成“消逝性”，两者对应错位。
- **建议**：改为“……显现出无常性，显现出灭尽性，显现出坏灭性，显现出变易性”。

## §1038 句 164-1038-54-68
- **问题 1**：风格（必改）：“短暂**之**身”中的“之”是文言虚词。
- **建议**：改为“这个短暂存在的身体”。nissaya 作 `မတ္တဋ္ဌကဿ= အနည်းငယ် တည်ခြင်းရှိသော`（只存续片刻的）。
- **问题 2**：补出成分：nissaya 把 kiṃ pana 释为 `အဘယ်မှာလျှင် စွဲလမ်းနိုင်ပါအံ့နည်း`（哪里能执取呢），并把 kāyassa 作宾格处理（`ကာယဿ= ကို`）。所以这里的意思是“把它执为‘我’……”，不是“说”。
- **建议**：改为“……哪里还能把它执为‘我’或‘我的’或‘我是’呢？”

## §1038 句 164-1038-69-73
- **问题 1**：补出成分与连接词：nissaya 补出 `ဂါဟော= စွဲလမ်းခြင်း`（执取），并把 ettha 释为 `ဤအဇ္ဈတ္တိကပထဝီဓာတ်၌`（对这内在的地界）。译文漏了 ettha，把“执取”译成“这类想法”；atha kho 译作“因此”也不准确，它表达的是“而实际上”。
- **问题 2**：格式（必改）：句末缺句号。
- **建议**：改为“而他对此（内在的地界）根本没有这样的执取。”

## §1039 句 164-1039-2-18
- **问题**：词义：paribhāsanti 的 nissaya 是 `ရေရွတ်`（呵斥、数落），不是“诽谤”。rosenti 的 nissaya 是 `ချုတ်ချယ်`（骚扰、刁难），是他动、使役的意思，“恼怒”容易被读成施动者自己生气。
- **建议**：改为“辱骂、呵斥、刁难、恼害那位比丘”。

## §1039 句 164-1039-78-85
- **问题 1**：风格（必改）：“便”是文言虚词。另外，“于是”在原文中没有对应词。
- **问题 2**：词法与词义：nissaya 作 `ဓာတာရမ္မဏမေဝ= ဓာတ်ဟု ဆိုအပ်သော အာရုံ၌`（就在被称为“界”的所缘上，处格）。“投向唯以界为对象的境界”叠出了“对象”和“境界”两层。pasīdati 的 nissaya 是 `ကြည်လင်`（明净），不是“净信”。adhimuccati 的 nissaya 是 `ဆုံးဖြတ်`（确定、决意）。四个并列动词现在译成“得净信，安住，胜解”，结构参差不齐。
- **建议**：改为“他的心就投入‘界’这一所缘，变得明净、安住、确定。”

## §1040 句 164-1040-2-19
- **问题**：补出成分：nissaya 在 amanāpehi 下补出 `အတွေ့တို့ဖြင့်`（以……的触，具格）。三个形容词修饰的是“触”，不是“方式”。
- **建议**：改为“如果有人以不悦意、不可爱、不合意的触来对待那位比丘——以手触、以土块触、以棍棒触、以刀剑触”，与后文的“手的触碰”等保持一致。

## §1040 句 164-1040-49-74
- **问题 1**：漏译：ocarakā 的 nissaya 是 `ယုတ်သောအမှုကိုပြုကျင့်တတ်ကုန်သော`（惯做卑劣事的），译文没有译出。
- **问题 2**：句法：tatrāpi 的 nissaya 是 `ထိုသို့ ဖြတ်ရာ၌လည်း`（即使在被锯截的时候），tena 的 nissaya 是 `ထိုကြောင့်`（因此），而 tena 修饰的是后面“不是我教法的实行者”。译文把“因此”放进了“心生恶意”那一句，因果关系挂错了。
- **问题 3**：“把你们”在原文中没有对应词，aṅgamaṅgāni 是 `အင်္ဂါကြီးငယ်`（大小肢体）。
- **建议**：改为“诸比丘，即使卑劣的强盗用双柄锯把肢体一段段锯开，在那时若有人心怀恶意，他也因此不是我教法的实行者。”

## §1041 句 164-1041-32-72
- **问题**：误译：alābhā vata me 的 nissaya 是 `အရမတော်လေစွတကား`（我实在没有得到利益啊），不是“失去了”。lābhā 是 `အရတော်`（利得），译文第二分句“确实没有获得”漏了宾语。dulladdhaṃ 的 nissaya 是 `မကောင်းသဖြင့် ရအပ်၏`（得来不善），suladdhaṃ 是 `ကောင်းစွာရအပ်`（得来善好），都是说“得到的方式”。译文“获得不善”“获得善”会被读成得到了不善法或善法，句义变了。
- **建议**：改为“‘我真是没有利益，我确实没有得到利益；我真是得来不善，我确实没有得来善好——我这样忆念佛、这样忆念法、这样忆念僧，依止善法的舍却不能安立。’”。修订后，句 115-152 要逐字同步。

## §1041 句 164-1041-84-114
- **问题**：nissaya 疑讹：`တေန= ထိုသို့ တည်ခြင်းကြောင့်`（因那安立）与上下文“不安立”相反，疑似漏了否定词 `မ`。译文按“不安立”理解，是正确的，不用改。这里只作记录。

## §1041 句 164-1041-180-188
- **问题**：误译（译得过弱）：bahukataṃ 的 nissaya 是 `များစွာလိုက်နာရခြင်းကို ပြုအပ်သည်`（已做了很多依教奉行的事），“有所成就”太轻。Ettāvatāpi 的 nissaya 是 `ဤမျှ အတိုင်းအရှည်ဖြင့်လည်း`（即使只到这个程度，**也**），“仅仅……就已经”与原文让步的语气不合。bhikkhuno 是泛指比丘，不是“那位”。
- **建议**：改为“贤友们，即使只做到这一步，比丘也已经做了很多。”
