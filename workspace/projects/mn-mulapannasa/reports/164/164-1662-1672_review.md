# Review — 164:1662-1672（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **Tamenaṃ samannesamāno evaṃ jānāti**（1664-38、1665-44、1666-44、1667-40、1668-72、1669-45）：6 处都译「他这样考察之后，便这样了知」。这里有三个问题：
  - 「便」是禁用的文言虚词。
  - `သမန္နေသမာနော= ရှာမှီးသည်ရှိသော်`是现在分词，表示“考察的时候”，译成「之后」不对。
  - `တမေနံ= ထိုဘုရားကို`是宾格，宾语“如来”被漏译；`ဧဝံ`修饰的是 jānāti，不修饰“考察”。

  → 统一为「他考察如来的时候，这样了知：」
- **Yato naṃ … tato naṃ uttariṃ samannesati**（1665–1669 各段的 2-9 与 10-2x）：`ယတော= ကြောင့်`、`တတော= ထို့ကြောင့်`都是因果关系，译文却用了时间关系「当……之后」。「便」是文言虚词。两处 `နံ= ထိုဘုရားကို`（宾格）都漏了宾语。
  → 统一为「由于他考察如来时这样了知：‘……’，所以进一步考察如来：」
- **byākaramāno / byākareyya**：1669-102 译「解说」，1670-32 与 1671-16 译「会这样解说」，1672-16 译「在回答的时候，应当这样回答」。nissaya 一律作`ဖြေဆို`（回答），`ဗျာကရေယျ= ဖြေဆိုရာ၏`是可能语气。
  → 统一为「比丘们，如来回答时，会这样回答：」；1669-102 改为「正确回答的比丘会这样回答：」
- **abhayūparato**：1669-29、1669-50、1669-75 译「无所畏惧而止息（欲乐）的」，1669-155 却译「离于恐惧的」。后一种把 uparata（离、止）漏掉了，也把复合词误读成“离开恐惧”。nissaya 作`ဘေးမရှိသည်ဖြစ်၍ ကြဉ်ရှောင်ပြီးသူ`（因无所畏惧而离止的人）。
  → 四处统一，1669-155 改为「我是无所畏惧而离止的」。
- **ñattajjhāpanno … yasappatto**：1668-28 译「已经出名、获得声誉」，1668-40 与 1668-55 译「因出名而获得声誉」，1669-10 译「虽因出名而获得声誉」。nissaya 里两词并列（都带`သည်`），彼此没有因果关系，也没有让步关系。同一段引语前后必须逐字相同。
  → 统一为「已经出名、拥有众多随从」（yasa 的译法见 1668-28-39）。
- **saṃvijjanti**：多数地方译「存在」，1668-40 与 1668-55 译「显现出」，1672 译「具有」。nissaya 一律作`ရှိ`（有、存在）。
  → 统一为「存在」或「有」。
- **ekacce ādīnavā**：1668-28 译「某些过患」，1668-77 与 1669-10 译「那些过患」。nissaya 作`အချို့သော အပြစ်တို့`（某些过患）。
  → 统一为「某些过患」。
- **vodātā cakkhusotaviññeyyā dhammā**：1666–1667 译「那些由眼与耳所能识知的、清净的法，如来身上是否存在／都存在」。1672-2 与 1672-24 却译「凡是眼、耳所能识知的清净之法，如来是否具有／是具有的」，措辞和句式都不同。1672 还缺内层单引号，与 1670、1671 的写法不一致。「清净之法」的「之」是文言用法。
  → 以 1666 的译法为准统一，补‘’。1666-50 与 1667-10 的「都」原文里没有，统一时一并删去。
- **引号缺失**：1668-28-39 缺整对‘’；1669-29-35 与 1669-50-56 缺开头的‘；1663-49-88 缺结尾的”；1672-34-58 缺结尾的’。

## §1663 句 164-1663-49-88
- **问题**：句法误读。nissaya 采用异读 `ajānantena kinti`，读作疑问句：`ကိန္တိ= အသို့လျှင်`（如何）、`ကာတဗ္ဗာတိ= ပြုသင့်ပြုထိုက်သနည်း`（应当怎样做呢）。nissaya 的夹注也说明，Bhagavaṃmūlakā 之前的句子照例都是问句。另外，`ဣတိ ဝိညာဏာယ= သိရန်အလို့ငှါ`表示“为了知道‘是不是正等正觉者’”，iti 引出的是 viññāṇāya 的内容，不是考察的方式，译文「以‘……’这样来对如来进行考察」把它挂错了地方。句末还缺”。
- **建议**：「比丘们，一位善于审察、不能了知他人心的比丘，应当怎样考察如来，来了解他是不是正等正觉者？”」

## §1667 句 164-1667-27-39
- **问题**：用词。`သမာပန္နော= ဝင်စားသလော`的意思是“进入、安住”，「具足」更接近 samannāgata。
- **建议**：「这位尊者是长期安住于这善法，还是只短暂安住？」1667-45、1668-10 同改。

## §1668 句 164-1668-28-39
- **问题**：句法与工作标记，共四点。
  - 前半句在 nissaya 里是疑问句（`ထင်ရှားသူ၏ အဖြစ်သို့ ရောက်သလော`，后面还有夹注说也含“是否未达到”的意思），译文却说成了既成事实。
  - `အဿ= ထိုဆရာဘုရားဖြစ်သော ရဟန်း၏ (သန္တာန်၌)`是属格，指“在他身上”。译文「对于这样【已出名】的人」把它泛化成了一类人，其中的「【已出名】」是工作标记，必须删掉。
  - `ယသပ္ပတ္တော= အခြံအရံပြည့်စုံခြင်းသို့ရောက်သလော`的意思是“随众（眷属）圆满”，不是「声誉」。
  - `ဣဓ= ဤလောက၌`（在这世间）漏译；整句缺‘’。
- **建议**：「‘这位比丘尊者是否已经出名、拥有众多随从？在这世间，他身上是否存在某些过患？’」

## §1668 句 164-1668-40-54
- **问题**：句法与用词。nissaya 里两个谓语并列（`ဥတ္တဇ္ဈာပန္နော= သည်။ ယသပ္ပတ္တော= သည်။ န ဟောတိ`），译文「因出名而获得声誉」凭空加了因果关系。`န သံဝိဇ္ဇန္တိ= မရှိကုန်`是“不存在”，不是「不会显现出」。
- **建议**：「比丘们，只要比丘还没有出名、还没有众多随从，他身上就不会有某些过患。」

## §1668 句 164-1668-55-71
- **问题**：同上，「因出名而获得声誉」「才会显现出」都要改。`အထ`表示“那时”，译文里的「才」带有限定语气，原文没有。
- **建议**：「但是，比丘们，当比丘出了名、有了众多随从时，他身上就会有某些过患。」

## §1668 句 164-1668-77-89
- **问题**：句法。`ဧကစ္စေ အာဒီနဝါ= တို့သည်`是主语，`အဿ`是属格。「他并不存在那些过患」把“他”当成了主语，句子不通；「那些」也应作「某些」。
- **建议**：「‘这位比丘尊者已经出名、拥有众多随从，但他身上并没有某些过患。’」

## §1669 句 164-1669-29-35 / 164-1669-36-44
- **问题**：句法。这两行合起来是一个问句：Pali 句末是 `?`，nissaya 作`န သေဝတီတိ= မမှီဝဲသလော`（是不是不受用）。译文却写成了陈述句，开头也缺‘。`ခယာ= ကုန်ခမ်းခြင်းကြောင့်`与`ဝီတရာဂတ္တာ= …အဖြစ်ကြောင့်`都是表原因的从格，译文「贪欲已尽」没有体现出原因关系。另外，nissaya 给 uparata 的释义是“离止”（ရှောင်ကြဉ်），没有补出宾语；括注「（欲乐）」可以保留，但四处要一致。
- **建议**：「‘这位尊者是无所畏惧而离止的，不是因为恐惧而离止的吗？他是因为贪已灭尽、已经离贪，所以不受用欲乐的吗？’」

## §1669 句 164-1669-50-56
- **问题**：开头缺‘。
- **建议**：补上‘，措辞按跨段一致性一节统一。

## §1669 句 164-1669-75-92
- **问题**：用词。`အနွယာ= အလျော်သိခြင်း`的意思是“随之推知”，「根据」偏泛。
- **建议**：「尊者是依据什么样的迹象、什么样的推断，才这样说……」

## §1669 句 164-1669-102-110
- **问题**：`ဗျာကရမာနော= ဖြေဆိုသည်ရှိသော်`意为“回答”，`ဗျာကရေယျ`是可能语气，译成「应当」偏重。
- **建议**：「比丘们，正确回答的比丘会这样回答：」

## §1669 句 164-1669-111-154
- **问题**：句法误读，共四点。
  - nissaya 夹注明确否定把 `tattha` 读作“在那些僧众之中”，应读作“在这位尊者身边”（`ထို (အရှင်ဆရာဘုရား၏) အထံ၌`），译文「其中」正是被否定的那种读法。
  - `တေန= ထိုထိုအကျင့်ဖြင့်`是分配性的“以他们各自的行为”，`တံ= ထိုထို ပုဂ္ဂိုလ်ကို`也是“每一个人”。译文「因此而轻视他们」没有表达出分配义。
  - nissaya 注明 `tathā hi` 无实义，「正是这样」语气过重。
  - `ဣဓ= ဤသာသနာတော်၌`（在这教法中）漏译。
- **建议**：「‘这位尊者无论住在僧团中还是独自居住，在他身边，有行为良好的人，有行为不良的人，有教导团众的人；在这教法中，有些人明显沉溺于物质资具，有些人不受物质资具染污——这位尊者都不会因为他们各自的行为而轻视其中任何一人。」

## §1669 句 164-1669-155-178
- **问题**：「我是离于恐惧的」漏了 uparata，与前面的 abhayūparato 译法不一致（见跨段一致性一节）。
- **建议**：「我是无所畏惧而离止的，我不是因为恐惧而离止的；我是因为贪已灭尽、已经离贪，所以不受用欲乐的。」

## §1670 句 164-1670-2-16
- **问题**：句法与用词。
  - `တတြ= ထိုဝီမံသကဘိက္ခု ၂-ပါးတို့တွင်`，nissaya 补出施事是最初那位审察比丘（`မူလဝီမံသကရဟန်းသည်`），译文「在这种情况下」丢掉了这个指涉。
  - `တထာဂတောဝ= ကိုသာလျှင်`意为“唯独如来”，「如来本人」可以接受。
  - `ပဋိပုစ္ဆိတဗ္ဗော= တဖန်မေးအပ်၏`意为“应当再问”。「反问」在现代汉语里指以问句表达肯定，容易引起误解。
- **建议**：「比丘们，对此，那位审察的比丘还应当进一步向如来本人询问：」

## §1672 句 164-1672-16-23
- **问题**：与 1670、1671 的译法不一致（见跨段一致性一节）；「应当」应作可能语气。
- **建议**：「比丘们，如来回答时，会这样回答：」

## §1672 句 164-1672-34-58
- **问题**：句法。`ဧတံ ပထော`与`ဧတံဂေါစရော`都是以“我”为主语的有财释复合词（`အဟံ … အသ္မိ`），意思是“我以此为道、以此为行境”。译文「这是我的道」把主语换成了“这”。`တမ္မယော= တဏှာရှိသည်`、`နောစအသ္မီတိ= မဖြစ်`意为“我并不因此而有渴爱”，「贪着」可以接受。句末缺’。nissaya 补出“此”指以活命为第八的戒，按 style 不擅自补进正文，可以考虑作注。
- **建议**：「我以此为道，以此为行境，但我并不因此而有渴爱。’」

## 原文 / nissaya 疑问（记录，不改）
- 1668-28、1668-40、1668-55、1668-77 的 nissaya 词头都作 `ဥတ္တဇ္ဈာပန္နော`（uttajjhāpanno），与 pali 的 ñattajjhāpanno 不同，是异读。
- 1671-2-15 的 nissaya 先说“vītimissā 一段同前，只出不同处”，接着给出的却是 vodātā 的释义（`ဝေါဒါတာ= ဖြူစင်ကုန်သော`），疑似与 1672 错位。
