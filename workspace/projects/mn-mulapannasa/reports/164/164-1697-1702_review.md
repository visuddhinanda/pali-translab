# Review — 164:1697-1702（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **brahmaparisā / brahmapārisajja**：§1701 句 2-21 把 brahmapārisajjaṃ 译「梵天眷属」，§1701 句 246-256、257-267 把 brahmaparisaṃ 也译「梵天眷属」，§1702 句 38-59 又并列成「梵天眷属会众」和「梵天眷属」。nissaya 区分两者：`ဗြဟ္မပရိသံ= ဗြဟ္မာပရိသတ်ကို`（梵天的会众），`ဗြဟ္မပါရိသဇ္ဇံ= ဗြဟ္မပါရိသဇ္ဇာဗြဟ္မာကို`（梵众天这一类的梵天）。建议统一为 brahmaparisā →「梵天会众」，brahmapārisajja →「梵众天」（§1701 句 2-21 作「一位梵众天的梵天」）。
- **mārisa**：婆迦说话时（§1699）与魔说话时（§1701 句 163-183、226-245）都译「尊者」。nissaya 对两人的称呼分别作注：婆迦口中是 `မာရိသ= အရှင်ဘုရား`（尊者，敬称），魔口中是 `မာရိသ= အချင်း`（朋友，平辈称呼）。建议魔口中的两处统一改为「朋友」，婆迦口中保留「尊者」。
- **māra**：§1701 句 2-21、257-267 和 §1702 句 2-15 把 māro pāpimā 译「恶魔波旬」，§1702 句 33-37 把 māro 译「魔罗」。建议统一为「魔」：「波旬，你就是魔。」
- **acavanadhamma / cavanadhamma**：§1699 两处译「不消逝之法」，§1700 句 32-60 译「不消逝的」和「会消逝之法」，单位不统一，且「之法」带文言味。nissaya 的释义是 `ရွေ့လျောခြင်းသဘောမရှိ`（没有消逝的性质）。建议统一为「不会消逝的」/「会消逝的」。
- **vakkhati（nāma）**：§1700 三处分别译「会把…说成」「却要说」「却要说」，都当成将来时来译，需统一修正，见 §1700 句 32-60。
- **文言虚词「之」**：「不消逝之法」「会消逝之法」「之处」「众生之父」分布在 §1699 至 §1701，需统一改为现代说法，见各句。

## §1699 句 164-1699-29-65
- **问题**：格与句法、文言。
  - `ဟိ= မှန်၏`：nissaya 把 hi 释为「确实」（强调），译文译成「因为」，变成了因果连接。
  - 「不消逝之法」中的「之」是文言用法。
- **建议**：改为「……这是不会消逝的。确实，它不生、不老、不死、不消逝、不再生……」。§1699 句 135-164 的同句也照此修改。

## §1699 句 164-1699-125-134
- **问题**：补出成分。nissaya 的释义是 `ဣမံ ပရိယာယံ= ဤအလှည့်ကို … အကာသိ= ပြုပြီ`（你做了这一趟），主语是你、谓语是「做」。译文「才有机会来到这里」凭空添了「机会」，暗示是外部条件阻碍了他。
- **建议**：「尊者，你隔了好久才到这里来一趟。」

## §1700 句 164-1700-14-23（及 24-31）
- **问题**：格与数。nissaya 是 `ဘော= အိုဗြဟ္မာတို့`，bho 是呼格、复数，指在场的诸位梵天，不是在称呼某位尊者。译文「尊者」把听话对象搞错了：佛陀这句话是对梵天会众说的，用第三人称谈论婆迦。
  - `အဝိဇ္ဇာဂတော= မသိမမြင်ခြင်းနှင့် တကွဖြစ်`：意思是「具有无明」，「陷入」稍偏，可以接受。
- **建议**：「诸位梵天啊，梵天婆迦确实被无明所蒙蔽；」，两句同改。

## §1700 句 164-1700-32-60
- **问题**：时态与语气，以及文言。
  - nissaya 的句法注说明：vakkhati 与 nāma 连用时，是以将来时形式表达现在时的责备语气（`ဘဝိဿန္တိ ဝိဘတ် ဝတ္တမာနကာလ ဂရဟတ္ထ`），即「竟然说」。译文「会把…说成」译成了将来时，失去了责备意味。
  - `ယတြ= ယောနာမ`：指「这位竟然……的梵天」。「因为他会」可保留「因为」，但要去掉「会」。
  - 「会消逝之法」的「之」是文言。
- **建议**：「因为他竟然把明明是无常的说成是常的……把明明会消逝的说成是不会消逝的；」

## §1700 句 164-1700-61-71
- **问题**：补出成分、语气、文言。
  - nissaya 补出 yattha 的所指：`အကြင်ကာယနှင့်တကွသော ဗြဟ္မာ့ဌာန၌`（那个连同身体在内的梵天处）。
  - tañca 是 vakkhati 的宾语：`ထို…ဗြဟ္မာ့ဌာနကိုလည်း`（把那个梵天处也……）。译文漏了宾语 taṃ。
  - 「却要说」误作将来时，问题同上。
  - 「之处」是文言。
- **建议**：「对于这个有生、有老、有死、有消逝、有再生的地方，他竟然也说——」

## §1700 句 164-1700-87-101
- **问题**：语气。`ဝက္ခတိ နာမ= ဆိုဘိ၏` 表责备，「他却要说」误作将来时。
  - nissaya 补出 aññaṃ 的参照对象：`(ကာယဌာနနှစ်ဝမှ) တပါးသော`（这个身体与梵天处之外的另一种）。
- **建议**：「明明还有另一种更殊胜的出离，他竟然说‘没有比这更殊胜的出离了’。」

## §1701 句 164-1701-22-69
- **问题**：误译、重复、文言。
  - 译文出现「支配者、支配者」，同一个词重复了两次，说明 sajitā 与 vasī 被译成了同一个词。nissaya 的释义：
    - `သဇ္ဇိတာ= စီရင်တတ်သူ`：安排者、规划者。句法注说明它取异读 sajjitā。
    - `ဝသီ= (မိမိစိတ်နှင့် ဈာန်သမာပတ်တို့၌) နိုင်နင်းခြင်းရှိသူ`：对自己的心和禅定得自在的人。
  - `ဝသဝတ္တီ= မိမိအလိုသို့ လိုက်စေနိုင်သူ`：能让（一切）随顺自己意愿的人。这个意思与 vasī 不同，现在 vasavattī 占用了「自在者」，vasī 就没有词可用。
  - 「众生之父」中的「之」是文言。
- **建议**：「……征服者、不被征服者、确实能见一切者、令一切随其意者、主宰者、作者、创造者、最胜者、安排者、得自在者，是已生和当生众生的父亲。」

## §1701 句 164-1701-70-112
- **问题**：误译、漏译、取义。
  1. **漏译「地」，造成误读**：「厌恶地、厌离地」中漏了宾语「地」，读者会把「地」当作副词词尾（厌恶地……）。nissaya 明确标出这是地界：`ပထဝီဂရဟကာ= ပထဝီဓာတ်ကို ကဲ့ရဲ့ကုန်သည်`。句法注还特别说明「要译成地界，不要译成大地」。
  2. **gārahaka 与 jigucchaka 的对应错位**：nissaya 的释义是 `ဂရဟ = ကဲ့ရဲ့`（呵责）、`ဇိဂုစ္ဆ = စက်ဆုပ်`（厌恶）。译文把 garahaka 译「厌恶」、jigucchaka 译「厌离」，整体错了一位。
  3. **bhūta 取义错误**：nissaya 是 `ဘူတဂရဟကာ= နတ်တို့ကိုကဲ့ရဲ့`，句法注按排除法说明这里指四大王天的天众，不是「有情」。deva 指其余诸天；pajāpati 指魔与他化自在天众；brahma 只指光音天以下的梵天。「生主」可以保留为字面译法，但 bhūta 不能译「诸有情」。
  4. **漏译 tayā pubbe**：nissaya 是 `တယာ= သင်မှ။ ပုဗ္ဗေ= ရှေး၌`（在你之前），译文只有「从前」。
- **建议**：「比丘，在你之前，世间有一些沙门、婆罗门，呵责地界、厌恶地界，呵责水界、厌恶水界，呵责火界、厌恶火界，呵责风界、厌恶风界，呵责鬼神、厌恶鬼神，呵责诸天、厌恶诸天，呵责生主、厌恶生主，呵责梵天、厌恶梵天——他们身坏命终之后，都投生在低劣的身中。」

## §1701 句 164-1701-113-154
- **问题**：与上句相同。「赞叹地、喜爱地」漏了宾语「地界」，会被读成副词；bhūta 误译为「诸有情」；tayā pubbe 漏译（nissaya 是 `တယာ= သင်မှ။ ပုဗ္ဗေ= ၌`）。
- **建议**：「比丘，而在你之前，世间有一些沙门、婆罗门，赞叹地界、喜爱地界……赞叹鬼神、喜爱鬼神……」，与上句平行修改。

## §1701 句 164-1701-163-183
- **问题**：称谓。nissaya 是 `မာရိသ= အချင်း`（平辈称呼「朋友」），魔在这里不用敬称，译文「尊者」把语气译反了。
  - `ဣင်္ဃ= တိုက်တွန်း၏`（催促），译「来吧」可以。
- **建议**：「来吧，朋友，梵天说什么，你就照着做什么……」。§1701 句 226-245 的同句也照此修改。

## §1701 句 164-1701-184-225
- **问题**：句法与时态。
  1. 「又比如比丘，一个人……」中的呼格「比丘」夹在「比如」后面，容易读成「比如比丘」，也就是把比丘当成比喻的主体。
  2. nissaya 补出了主语：`ဣဒံ= ဤသာလွန်၍ ဖြစ်စေခြင်းသည်`（这种违背），谓语是 `ဘဝိဿတိ= ဖြစ်လတ္တံ့`（将会）。意思是「你违背梵天这件事，将会是这个样子」。译文「你的情况正与此相同」丢掉了主语和将来时。
- **建议**：「……又好比，比丘，一个人正坠入深渊，手脚却抓不到、踩不着地面——比丘，你若违背梵天，下场就会是这样。」

## §1701 句 164-1701-246-256
- **问题**：引号层级。pali 原文 `’ ti` 只关闭魔所说的话这一层，nissaya 也把它释为「我这样说」这一框架的引语结束，佛陀对比丘们的叙述仍在继续，下一句「比丘们，恶魔波旬就这样……」还是佛陀的话。译文用「’”」把外层引号也一起关闭了。
  - brahmaparisā 的译法见跨段一致性。
- **建议**：「比丘，你不是看见梵天会众已经聚集在这里了吗？’」，去掉「”」。

## §1702 句 164-1702-23-32
- **问题**：引号层级。nissaya 是 `န ဇာနာတီတိ= မသိ' ဟူ၍`：ti 标出的是魔心里的想法「他不认识我」，pali 原文的 `’ ti` 关闭的是这一段内层引语，不是佛陀对魔所说的整段话。译文在这里用「’」把佛陀对魔的话关闭了，后面「波旬，你就是魔罗……」那几句就落到了引号外面。
- **建议**：改为「你不要以为‘他不认识我’。」，佛陀对魔的话一直延续到 §1702 句 80-95 结尾，在那里关闭。§1702 句 67-79 中魔的想法也相应作为内层引语处理。
