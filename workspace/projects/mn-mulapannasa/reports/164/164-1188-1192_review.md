# Review — 164:1188-1192（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性
- **vādena vādaṃ samārabhati / vādaṃ āropeti**（同一组说法）：§1189 译“与我辩论较量”“与一根木柱辩论较量”，§1191 句 57-105 起译“在辩论中把沙门乔达摩……”，§1191 句 225-246、251-273 译“驳倒……的论点”。三种译法不统一。nissaya 的读法是 `ဝါဒံ= အပြစ်သို့`（置于过失）、`သမာရဒ္ဓေါ= တင်အပ်သည်ရှိသော်`（被置于过失时；注明 = āropito），也就是“用言论驳难、驳倒对方”，不是双方平等地“辩论较量”。→ 建议全 chunk 统一为“用言论驳难／驳倒”。
- **Aggivessana**：§1190（句 81-100、148-168）、§1192（句 54-70）都译作“火种居士”。nissaya 只有 `အဂ္ဂိဝေဿန`，是族姓称呼，原文没有“居士”的成分。萨遮迦是尼乾子之子、外道论师，加“居士”会让读者误以为他是在家信众。→ 三处统一为“火种”或音译“阿吉威萨那”。
- **Atha kho**：§1190 句 2-12、§1191 句 25-33、§1192 句 15-23 和 71-83 译“那时”，§1191 句 274-286 译“于是”。另外 *Tena kho pana samayena* 也译“那时”，两者混用了。→ 建议 *atha kho* 统一译“于是”，“那时”专用于 *tena samayena*。

## §1189 句 164-1189-2-19
- **问题**：增译。原文只有 `ဝေသာလိယံ= ၌`、`မဟာဝနေ= တောကြီး၌`，没有“城外”。
- **建议**：改为“住在毘舍离大林的重阁讲堂”。

## §1189 句 164-1189-20-32
- **问题**：误译。*paṇḍitavādo* = `ငါပညာရှိဟု ပြောဆိုတတ်သော`（惯于自称“我是智者”的），是自我标榜，不是“被认为是辩才敏捷的人”。另外 *sādhusammato bahujanassa* = `များစွာသောလူအပေါင်းသည်… ကောင်းသော အယူရှိသသူဟု သမုတ်အပ်သော`（被众人公认为持善见的人）。“受到许多人的推崇”可以接受，但没译出“善”的内容。
- **建议**：改为“……他善于发表各种言论，自称是智者，被许多人公认为贤善的人”。

## §1189 句 164-1189-40-76
- **问题 1**：修饰关系错位。nissaya 把 *paṭijānamānaṃ* 与 *arahantaṃ sammāsambuddhaṃ* 连读：`ပဋိဇာနမာနံအပိ= ဘုရားဟု ဝန်ခံသောသူကိုသော်လည်း`（即使是自称为佛的人）。“自称”只管“阿罗汉、正等正觉者”一项。译文把“自称”提前到“沙门或婆罗门”上，扩大了范围。
- **问题 2**：语态误读。*mayā vādena vādaṃ samāraddho* 是被动，意思是“被我用言论驳难”（见跨段一致性第一条）。译成“在与我辩论较量之后”，丢了被动义，也丢了“驳难”义。
- **建议**：改为“我没有见过任何沙门或婆罗门——无论是有僧团的、有徒众的、身为徒众导师的，甚至是自称阿罗汉、正等正觉者的人——被我用言论驳难时能够不动摇、不震颤、不发抖，腋下不流汗。”

## §1189 句 164-1189-77-93
- **问题**：同上，是语态和词义问题。nissaya：`စေ သမာရဘေယျံ= အကယ်၍ တင်သည်ဖြစ်အံ့`（假如我驳难），`သာပိ… သမာရဒ္ဓါ= တင်အပ်သည်ရှိသော်`（那根柱子被驳难时）。“因为与我辩论而”不对。
- **建议**：改为“如果我用言论去驳难一根没有心识的柱子，那根柱子被我驳难时，也会动摇、震颤、发抖。”

## §1189 句 164-1189-94-101
- **问题 1**：误译（必改）。*Ko pana vādo* 是惯用语，“还有什么可说的”。nissaya：`မနုဿဘူတဿ= လူဖြစ်သောသူ၏ (တုန်လှုပ်သော အဖြစ်၌)`、`ကော ပန ဝါဒေါ= အဘယ်ဆိုဘွယ်ရာရှိအံ့နည်း`，意思是“人（会动摇）就更不必说了”。这里的 *vādo* 不是“辩论”。
- **问题 2**：标点。这句的引语是从句 40-76 的“ 开始的，本句开头又加了一个“，前引号重复了。
- **建议**：改为“更何况是人呢！”，并删掉句首的前引号。

## §1190 句 164-1190-13-26
- **问题**：用词。*jaṅghāvihāraṃ anucaṅkamamāno anuvicaramāno* = `ခြေလျင်လျှောက်ခြင်းကို… ထိုရောက် ဤရောက်… လှည့်လည်လျက်`（为了走动而到处走、四处转）。“经行”是僧人修行的专用词，§1192 句 2-14 比丘 *caṅkamanti* 也译作“经行”。这里用在外道萨遮迦身上，容易让读者误以为他在修行。
- **建议**：改为“正在毘舍离城中四处散步、闲逛”。

## §1190 句 164-1190-169-184
- **问题**：词义与结构。*dussutaṃ* = `မကြားသင့်သောစကားကို`（不该听的话），不是“不好的消息”。*evaṃvādiṃ* 修饰 *samaṇaṃ gotamaṃ*：`ဧဝံဝါဒိံ= ဤသို့ အယူရှိ၏ဟူ၍`（听说他持这样的主张）。此外，译文里“我们听到这样的说法”是重复增出的。
- **建议**：改为“阿说示先生，我们真是听到了不该听的话——竟然听说沙门乔达摩持这样的主张。”

## §1190 句 164-1190-185-212
- **问题**：词义弱化。*pāpakā* = `ယုတ်မာသော`（卑劣的、邪恶的），译成“错误的”分量不够。
- **建议**：改为“使他脱离那种邪恶的见解”。

## §1191 句 164-1191-57-105
- **问题 1**：漏译。*me* 在两处都是 `ငါ၏ (မျက်မှောက်၌)`（在我面前）。nissaya 注明阿说示的立场是在萨遮迦面前承认的，萨遮迦也要求乔达摩在他面前同样承认。译文没译出来。另外，*patiṭṭhitaṃ* 依 nissaya 注引疏，指“所承认的（无常、无我）”，“坚持自己的立场”说得太宽泛。
- **问题 2**：误译。*eḷakaṃ* = `သိုးကို`（绵羊），不是“山羊”。
- **问题 3**：*vādena vādaṃ* 后面 nissaya 补出 `(အာရောပေတွာ= တင်၍)`，意思是先用言论把他驳倒，再拉扯他。“在辩论中”没表达出这层。
- **建议**：前半句改为“如果沙门乔达摩在我面前，也像他那位名叫阿说示的知名弟子在我面前那样承认（这一主张）”。“长毛山羊”改为“长毛绵羊”。后半句改为“我也要用言论驳倒沙门乔达摩，再把他往这边拽、往那边推、来回拖拉”。

## §1191 句 164-1191-106-129
- **问题**：词义不清。*soṇḍikākiḷañjaṃ* = `သေတင်းကုတ်၌ ခင်းအပ်သော ဖျာကို`（铺在酒坊里的席子），译成“酒垫”读者看不懂。“大力士酿酒工人”也不通顺。*kaṇṇe* = `(ဖျာ) အစွန်း၌`（席子的边缘）。
- **建议**：改为“就像一个强壮的酒坊工人，把一张酒坊用的大草席扔进深水潭里，抓住席子的边，往这边拽……”。

## §1191 句 164-1191-130-181
- **问题 1**：误译（必改）。*soṇḍikādhutto* = `သေသောက်ကြူးသည်`（酒徒、嗜酒的人）。译文“一个大力士酿酒工人的酒徒”是把上一句的主语混进来了，语义也不通。
- **问题 2**：误译。*vālaṃ* = `သေစစ်သောအိတ်ကို`（滤酒用的袋子），不是“毛毡”。
- **问题 3**：动词区分不足。*odhuneyya* = `မှောက်၍ ခါရာ`（倒过来抖），*niddhuneyya* = `လှန်၍ ခါရာ`（翻过来抖），*nipphoṭeyya* = `အကြိမ်ကြိမ်လှုပ်၍ ခါရာ`（反复甩打）。
- **建议**：改为“就像一个强壮的酒徒，抓住滤酒袋的边，把它倒过来抖、翻过来抖、反复甩打，我也要用言论驳倒沙门乔达摩，再把他倒过来抖、翻过来抖、反复甩打。”

## §1191 句 164-1191-182-201
- **问题**：句法与措辞。*samaṇaṃ gotamaṃ* 是宾格（`ကို`），所以是“拿沙门乔达摩来玩”，不是“在他身上玩”。*sāṇadhovikaṃ maññe* = `လျှော်မျှင်ဖွပ်ခြင်းနှင့် တူသော`（好像洗麻一样的）。这里的 *maññe* 表示“好像”，译成“我想”是硬译，读起来不通。
- **建议**：后半句改为“我也要拿沙门乔达摩来玩一场好像‘洗麻’一样的游戏”。

## §1191 句 164-1191-251-273
- **问题**：增译。*kiṃ so bhavamāno* = `ကိံ ဘဝမာနော= အဘယ်သို့သောသူဖြစ်သနည်း`（他算是什么人），nissaya 里没有“自视甚高”。
- **建议**：改为“尼乾子的儿子萨遮迦算什么人，能驳倒世尊？倒是世尊会驳倒尼乾子的儿子萨遮迦吧！”
