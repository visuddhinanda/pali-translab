## 被解释词与父层核对（首要）

- **§710** "**Bhiṃsanakānī**"→"令人惊惧的"、"gāmanigamādidvāresu"→"村落、市镇等门口"、"pūjanīyaṭṭhena"→"以应受供养之义"：均与父层 130-615 逐字相同 ✅

- **§711 id 192-711-134~155**：本层把 "sukhārammaṇaṃ rūpaṃ sukhamiva" 的黑体译为"**令人悦意的色相被称为乐**"，但父层 130-619 原译是"**令人悦意的色相因是乐的所缘，也被称为‘乐’**"——**丢了"因是乐的所缘"这个中间分句，必改**。

## 跨段一致性（高频问题：文言腔"之义/之事/之故"与"其"）

本 chunk 里"之义""之事""之故"以及"其意趣是"反复出现，均属项目风格规范明令禁止的文言写法，应逐处改为现代汉语：

| 位置 | 原文 | 建议改法 |
|---|---|---|
| §708（2处） | "表示相状**之义**"／"理解表相状**之义**" | "表示相状的意思"／"理解相状这层意思" |
| §708 | "**其**意趣是：因为相状**之义**……" | "这样解释的意思是：因为相状这层含义……" |
| §710 | "由于被天神所依附**之故**" | "由于被天神所依附的缘故" |
| §711 | "适合从事种种祭祀、祈愿**之事**" | "适合从事种种祭祀、祈愿的事" |
| §711（2处） | "**其**意趣是……"（摆动／兽名两处） | "这样说的意思是……" |
| §711 | "具有特指**之义**而说的" | "具有特指的意思而说的" |
| §711 | "怎能表示色所缘**之义**" | "怎能表示色所缘的意思" |
| §711 | "是指以眼睛看见**之义**"／"来理解**其**意义" | "是指以眼睛看见的意思"／"来理解这句话的意义" |
| §711 | "期待怖畏**之事**而安住；**其**意趣是" | "期待怖畏的事而安住；这样说的意思是" |
| §712 | "取**其**最接近**之义**"／"依辗转相续**之义**而取的" | "取最接近的一项"／"依辗转相续的关系而取的" |
| §712 | "依次第生起**之义**来说的" | "依次第生起的顺序来说的" |

这是逐段孤立审查发现不了的一类问题——本 chunk 几乎每段都有至少一处，建议整体过一遍替换。
