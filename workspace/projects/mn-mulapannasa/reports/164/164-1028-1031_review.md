## §1028 句 164-1028-108-121
- **问题**：义注对应（130-2233,「natveva tāva ariyasāvako niṭṭhaṃ gato hoti」）义注解释为：圣弟子此时因阿罗汉智尚未生起、所作尚未圆满，故“未得出结论”，是**否定式的结论未至**，而非“正在得出结论”的持续动作。译文“不过，圣弟子这时还没有得出结论，而是正在得出结论——”前后矛盾，読起来像是自相冲突（先说没得出结论，又说正在得出）。
  - **义注**：“maggakkhaṇepi apariyositakiccatāya na tāva niṭṭhaṃ gato hoti”（道智剎那因所作未圆满故尚未得出结论）；“apica kho pana maggakkhaṇe … iminā ākārena tīsu ratanesu niṭṭhaṃ gacchati”（但在道智剎那，以此方式对三宝已趋向结论）。
- **建议**：译文本身对应巴利“na tveva tāva … api ca kho niṭṭhaṃ gacchati”并无误译，但“正在得出结论”容易让读者误解为与前半句矛盾，可改为“不过，圣弟子这时还没有彻底得出结论，而是（在道智剎那）正趋向于这样的结论——”，加“彻底”或“趋向于”缓解语义冲突，帮助读者理解这是过渡阶段。可选改进，非硬伤。
