## 问题清单

### 🟧 error

- `130-474-15-53`｜错译（词义）｜片段「有这么多黄金，这么多白银」
  - 问题：hiraññaṃ（银/银钱）与 suvaṇṇaṃ（金）对应译名颠倒，译文将 hiraññaṃ 译作"黄金"、suvaṇṇaṃ 译作"白银"，恰好相反。
  - 建议：改为"有这么多白银，这么多黄金"（hiraññaṃ→白银，suvaṇṇaṃ→黄金）。

- `130-474-15-53`｜错误多译｜片段「这就是四念处。”这是详说。」
  - 问题：该片段属于下一句（130-474-54-72，对应巴利 "Ime cattāro satipaṭṭhānā'ti ... vitthāro"）的内容，被提前混入本句译文末尾，导致同一内容在 474-54-72 中重复出现一次。
  - 建议：从 130-474-15-53 的译文中删去"这就是四念处。”这是详说。"这部分，只保留到"……以及与它们相类似的法。”为止；重复内容留在 130-474-54-72 独立呈现即可。

- `130-475-6-30`｜漏译｜片段「萎靡、掉举、执着停滞、贪着世间乐、疲于劳苦、断见常见等诸多祸患」
  - 问题：原文 "līnuddhaccapatiṭṭhānāyūhana-kāmasukhattakilamathānuyoga-ucchedasassatābhinivesādīnaṃ" 实为八项过患并列（līna 萎靡 / uddhacca 掉举 / patiṭṭhāna 停滞 / āyūhana 躁进策励 / kāmasukhallikānuyoga 贪着欲乐 / attakilamathānuyoga 自苦劳形 / ucchedadiṭṭhi 断见 / sassatābhinivesa 常见执著），译文将 patiṭṭhāna 与 āyūhana 合并压缩为"执着停滞"一项，丢失了 āyūhana（过度策励/躁进，与"停滞"相对的另一极端）这一独立概念。
  - 建议：改为"萎靡、掉举、耽滞、躁进、贪着世间乐、疲于劳苦、断见常见等诸多祸患"，将 patiṭṭhāna（耽滞）与 āyūhana（躁进）分列为两项。

### 🟨 warning

- `130-476-83-88`｜术语标记不一致｜片段「念本身也就是觉支，也就是念觉支」
  - 问题：本句紧接前一句（130-476-77-82）刚给出的词源解释——"殊胜的觉支称为**等觉支**（sambojjhaṅgo）"——但此处将同一词 "sambojjhaṅgo" 简单译回"觉支"，未体现"等/殊胜"之义，与刚给出的词源阐释脱节。全文中"satisambojjhaṅgaṃ"也统一简化译为"念觉支"而非"念等觉支"，属于全篇一致的简化选择，但在紧邻词源解释处显得前后不搭。
  - 建议：此句可改为"这样，念本身也就是等觉支，也就是念觉支"，或在理由/注释中说明"等觉支"简称"觉支"的选择依据，以呼应上文词源分析。

- `130-472-2-8`｜关键词语意不明确｜片段「就意义、相等而言」

  - 建议：改为"就意义、相（等）而言"或"就意义、相状等而言"，避免与"相等（equal）"混淆。
