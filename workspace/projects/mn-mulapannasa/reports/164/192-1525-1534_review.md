## 被解释词与父层核对（首要）

- **§1526 id `192-1526-17-24`**：黑体 `‘‘vipassanāpādakaaṭṭhasamāpatticittan’’` 译作“作为观禅基础的八种等至心”，与父层 130-1810 该词的定稿译文“**以观禅为基础的八种等至的心**”不逐字相同（“作为…基础的”vs“以…为基础”，且脱漏“的”字）。
  **建议**：改为“以观禅为基础的八种等至的心”。
- **§1526 id `192-1526-25-61`**：同一黑体词再次出现，译文仍是“作为观禅基础的八种等至心”，同上问题（跨段内部倒是自我一致，但与父层不一致）。
  **建议**：同上，统一改为“以观禅为基础的八种等至的心”。
- **§1528 id `192-1528-2-7`**：黑体 `Chandasahagatā rāgasampayuttā`（此词组在父层 130-1813 的定稿译文中作“伴随着欲求、与贪相应”）本层译作“带着欲求、与贪相应”，“带着”与父层“伴随着”不逐字相同。
  **建议**：改为“伴随着欲求、与贪相应”。
- 其余核对到的黑体被解释词（“原因”“时时”“在每个时候”“以无主属性和暂时性的方式”“依止这五法”“愚痴之界”“应当依止”“保持警惕”“这不是理由”“他善于抉择应处与非处”“各种义理也会变得明了”“你贪染的是什么呢”“应当从不净的角度加以对治”“表皮的色泽”等）均与父层定稿译文逐字相符，通过。

## §1531 id `192-1531-17-62`

- **问题**：术语切分与父层不同——`kakacūpamovāda` 译作“《锯喻教诫》”（合并为一个书名），而父层 130-1815 将 `kakacopamovāda` 拆译为“《锯喻经》和教诫”两项。
- **建议**：因两处所引巴利词形/语境不完全相同（本层为义注自身概述性引用），不强制逐字对齐，但建议核实原意后统一为“《锯喻经》和教诫”或保留现译并在术语表记录该差异，避免读者误以为是两部不同经典。

## §1533 id `192-1533-22-36`

- **问题**：黑体 `Athassa moho pahīyatī` 译作“他的愚痴就会被舍弃”，父层 130-1820 同一小句定稿为“**那么他的愚痴就会被舍弃**”，脱漏“那么”。
- **建议**：补回“那么”，改为“那么他的愚痴就会被舍弃”，与父层逐字对齐。
