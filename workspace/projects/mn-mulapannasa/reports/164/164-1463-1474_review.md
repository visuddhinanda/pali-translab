# Review — 164:1463-1474（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本 chunk 只有 §1463 和 §1464 的前两句（2-20、21-31）带 nissaya，其余句子只查跨段一致性）

## 跨段一致性
- **dhammacārī / adhammacārī**：§1466、§1468–1474 把 adhamma- 译成“不如法而行”，把 dhamma- 译成“依法而行”。这一对正反词前面用了不同的字（如法／依法） → 建议统一为“如法而行／不如法而行”。
- **samacārī / visamacārī**：visama- 译成“不平等而行”，sama- 却译成“依正当而行”，正反两词对不上（§1466、§1468 对 §1473、§1474）。巴利原文是 sama／visama 这一对正反词，译文也应该成对 → 建议统一为“正当而行／不正当而行”，或者统一为“平等而行／不平等而行”，两边用同一个词根。
- **bhavant（尊称）**：§1464-55-64 把 bhavantaṃ gotamaṃ 译成“乔达摩尊者”，§1467-2-20 和 §1467-21-47 把 bhoto gotamassa／bhavaṃ gotamo 译成“乔达摩先生”。同一批婆罗门居士用同一个尊称称呼世尊，译法却不一样 → 建议统一为“乔达摩先生”，和呼格 bho gotama 的译法“乔达摩先生”（§1465）一致。
- **引号缺失**：§1474-2-13 是一段新话的开头，原文有 ‘‘，译文却没有开引号“。平行的 §1469-2-14、§1470-2-13、§1471-2-13 都有“ → 必改：在句首补上全角“。
- **kāyena / vācāya / manasā**：全 chunk 一律译成“由身体／由语言／由意”。“身体”“语言”是双音节，“意”是单音节，三者不对称 → 建议统一为“由身／由语／由意”，或者“以身／以语／以意”（属于可改项，不是必改项）。

## §1464 句 164-1464-21-31
- **问题**：词义／补出成分。nissaya：`ဝေရဉ္ဇကာ= ဝေရဉ္ဇရွာ၌နေကုန်သော`（住在韦兰迦村的），说明 verañjakā 是从村名派生出来的形容词，指“韦兰迦村的（人）”。译文“韦兰迦的”没有交代韦兰迦是一个村子。
- **建议**：首次出现时译成“韦兰迦村的婆罗门居士们”，后面各处（§1464-32-37、§1465、§1467）跟着统一，也可以只在首次出现时补“村”，后面简称。
- **问题**：数／限定词。nissaya：`ကေနစိဒေဝကရဏီယေန= တစုံတခုသော ပြုဘွယ်ကိစ္စကြောင့်သာလျှင်`（只是因为某一件该办的事）。原文是单数，带不定代词 kenaci 和强调词 eva。译文写“一些事务”，变成了复数，也没译出 eva 的强调。
- **建议**：改成“因为某件事务”，或者“正是因为某件要办的事”。
