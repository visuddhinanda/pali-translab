# Review — 164:248-254（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句有。164-249-2-73、164-250-26-52、164-251-47-61、164-251-84-87、164-252、164-253-69-83、164-253-106-126、164-254 没有 nissaya，不出单句意见。164-250-2-25、164-253-2-29 的 nissaya 只有段号，没有词条，也略过。）
> 本层是本文 mūla，没有父层，不做被解释词对照。

## 跨段一致性

- **ettāvatāpi … ariyasāvako sammādiṭṭhi hoti**：§248、§251、§253 的四谛式句译作“圣弟子就是正见了”，§249、§252、§254 的总结句译作“圣弟子就是这样正见了”。两处巴利文完全相同，译法不应分化。另外 `pi`（“也”）六处都漏译了。本经反复用 `pi` 表示“这也是一种方式”，与 §250 的“还有没有别的方式”前后呼应，漏掉后，这层递进关系在译文里就看不出来。
  → 建议六处统一为“贤友，到这个程度，圣弟子也就是正见者”。用不用“这样”，各处保持一致即可。
- **sabbaso rāgānusayaṃ pahāya**：§249 与 §252 译“完全舍断贪的随眠”，§254 译“彻底断除贪随眠”。
  → 统一为“完全舍断贪的随眠”。
- **… pe … dukkhassantakaro hoti**：省略号包含了 `diṭṭheva dhamme`。§252 在“乃至”之后又补出“在这现世中”，§254 没有补，两段处理不一致。
  → 建议都按省略处理，删去 §252 的“在这现世中”，写成“……乃至……成为苦的终结者”。§254 的“乃至成为”也补上后一个省略号，与其他段格式一致。
- **X-nirodhagāminī paṭipadā**：§253、§254 译“导向生灭的道路”。在汉语佛学语境里，“生灭”是固定词，指“生起与灭去”（udayabbaya），读者会误解为“导向生与灭的道路”。nissaya 的解释是 `ဇာတိနိရောဓဂါမိနိံ= ဇာတိ၏ချုပ်ရာ နိဗ္ဗာန်သို့ရောက်ကြောင်းဖြစ်သော`（通往生之灭处涅槃的），即“生”是属格，修饰“灭”。
  → 建议 §253、§254 各处统一改为“导向生之灭的道路”。“老死灭”“苦灭”没有这种歧义，可以不动。如果要三组句式一律加“之”，也行，但要全 chunk 同改。
- **“凡是那些众生在各自的众生群类中，…”句式**：§251（老）与 §253（生）都把属格 `tesaṃ tesaṃ sattānaṃ` 译成了主语，详见下面的单句意见。两段要同改。

## §248 句 164-248-62-104

- **问题**：句法误读。`yampicchaṃ na labhati tampi dukkhaṃ` 的 nissaya 是：`ယမ္ပိ= အကြင်မရနိုင်သောဝတ္ထု၌ တောင့်တခြင်းဖြင့်`／`တမ္ပိ= ထိုမရနိုင်သောဝတ္ထု၌ တောင့်တခြင်းသည်လည်း`。也就是说，`tampi` 的主格指的是“对得不到之物的那份渴求”，被判定为苦的是这份渴求本身。译文“想要的得不到也是苦”把主语读成了“得不到”这件事。
- **建议**：改为“求而不得的那种渴求也是苦”，或“想要却得不到的那种希求也是苦”。
- **问题**：句内一致。巴利文每一项都带 `pi`，nissaya 也都译为 `…သည်လည်း`（……也），但译文只有“死也是苦”“愁…恼也是苦”“…也是苦”带“也”，“生是苦，老是苦”“…聚合是苦”“…分离是苦”都没有。
- **建议**：要么全部加“也”，要么全部不加（“也”可以只留在末项之前）。

## §248 句 164-248-110-146

- **问题**：词义添加。`tatratatrābhinandinī` 的 nissaya 是 `ထိုထိုအာရုံ, ထိုထိုဘုံ၌ အလွန်နှစ်သက်တတ်၏`（对种种所缘、在种种界处惯于极度欢喜）。原文只说“欢喜”，没有“寻求”。译文“到处寻求欢喜”多出了“寻求”，意思也偏了：变成在找欢喜，而不是对所遇之处起欢喜。
- **建议**：改为“在种种处所、种种对象上欢喜不已的”，或“处处爱乐的”。

## §248 句 164-248-152-165

- **问题**：复合词结构。nissaya 把 `asesavirāganirodho` 作为一个单元解释：`တပ်ခြင်းကင်းသော မဂ်ဖြင့် အကြွင်းမဲ့ချုပ်ရာ နိဗ္ဗန်`（以离贪之道而无余灭尽之处）。这里 `virāga` 是灭的手段，`nirodha` 是中心词。译文“无余离贪与灭尽”用“与”把它拆成两个并列项，结构读错了。
- **建议**：改为“由离贪而无余灭尽”，或“无余的离贪灭”。
- **问题**：限定词漏译。`tassāyeva taṇhāya` 的 nissaya 是 `ထိုတဏှာ၏သာလျှင်`（正是那个渴爱的）。`eva` 指回上一句所说的那种渴爱，译文“对渴爱的”漏掉了这层回指。
- **建议**：改为“正是对那渴爱的……”。

## §251 句 164-251-62-83

- **问题**：格位误读。`tesaṃ tesaṃ sattānaṃ` 的 nissaya 是 `ထိုထိုသတ္တဝါတို့၏`，属格，修饰后面的 `jarā` 等词，意思是“种种众生的衰老”。译文“凡是那些众生在各自的众生群类中，衰老、老朽……”把众生读成了主语，“衰老”变成谓语，与后文“这就叫作老”的名词性定义对不上。
- **建议**：改为“凡是种种众生在种种众生群类中的衰老、老朽、齿落、发白、皮皱、寿命的衰减、诸根的衰熟——贤友，这就叫作老”。
- **问题**：词义添加。`indriyānaṃ paripāko` 的 nissaya 是 `စက္ခုစသော ဣန္ဒြေတို့၏ ရင့်ကျက်ခြင်း`（眼等诸根的成熟、熟透），没有“败坏”的意思。
- **建议**：“诸根成熟败坏”改为“诸根的衰熟”或“诸根的老熟”。
- **原文疑问（记录，不改）**：本句 nissaya 附有编者按语：前面没有“katamā āvuso jarā”这一问，所以下一句“katamañcāvuso maraṇaṃ”（164-251-84-87）的问句也不应该有。编者还引第 100 段名色章为证：那里只问总体，不问分项。这提示 §251 的“那么什么是死呢”可能是衍文，留待底本核对。

## §251 句 164-251-88-126

- **问题**：项目切分。nissaya 把 `maccu maraṇaṃ` 作为一项（`အကြင် သေခြင်း`，死亡），`kālaṃkiriyā` 是另一项（`အတ္တဘောကို ပစ်ချခြင်းကို ပြုခြင်း`，舍弃自体的作为）。译文“死亡、命终、命终的作为”多出一项，“命终”和“命终的作为”在意思上重复。
- **建议**：改为“……消失、死亡、命终、诸蕴的破坏……”，其中“死亡”对 maccu maraṇaṃ，“命终”对 kālaṃkiriyā。
- **问题**：用词。`kaḷevarassa nikkhepo` 的 nissaya 是 `ကိုယ်ကောင်ကို ပစ်ချခြင်း`（舍下躯体）。这里说的是舍下身体，不是事后处理遗体，“遗体的舍弃”容易被理解成丧葬。
- **建议**：改为“躯体的舍弃”。

## §251 句 164-251-127-137

- **问题**：指示词。`ayañca jarā idañca maraṇaṃ` 的 nissaya 是 `ဤအိုခြင်းသည်လည်း ဇရာမည်၏ ။ ဤသေခြင်းသည်လည်း မရဏမည်၏`，两个指示词都是“这”（ဤ），分别回指上文定义的老和死。译文“这是老，那是死”用了“这”“那”对举，像是在指两样不同远近的东西，回指关系变模糊了。
- **建议**：改为“这样，上面说的这个老和这个死——贤友，合起来就叫作老死”。

## §253 句 164-253-30-68

- **问题**：歧义（见跨段一致性）。“导向生灭的道路”会被误解为“生与灭”。nissaya `ဇာတိ၏ချုပ်ရာ` 明确是“生的灭”。
- **建议**：改为“导向生之灭的道路”。

## §253 句 164-253-84-105

- **问题**：格位误读，与 164-251-62-83 相同。`tesaṃ tesaṃ sattānaṃ` 的 nissaya 是 `တို့၏`（属格），而 `khandhānaṃ` 的 nissaya 是 `ဘဝသစ်ခန္ဓာတို့၏`（新有诸蕴的）。译文“凡是那些众生在各自的众生群类中，出生、诞生……”同样把众生译成了主语。
- **建议**：改为“凡是种种众生在种种众生群类中的出生、诞生、入胎、显现、诸蕴的显现、诸处的获得——贤友，这就叫作生”。句式要与 §251 的老、死两句一致。
- **问题**：译名。`okkanti` 的 nissaya 是 `ဥခွံတွင်း အမိဝမ်းတွင်းသို့ သက်ဝင်ခြင်း`（进入卵壳或母胎），比“入胎”的范围宽。传统上沿用“入胎”可以接受。如果要贴合 nissaya，可以改为“入胎（含入卵）”，或在脚注说明，正文不必改。
