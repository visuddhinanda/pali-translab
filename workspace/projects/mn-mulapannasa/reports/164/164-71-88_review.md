# Review — 164:71-88（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 164-72-73-94、164-73-2-25 两句没有 nissaya，已略过。164-77-9-23、164-78-9-35 没有单列 nissaya，但它们的 nissaya 已并在上一句（77-2-8、78-2-8）里，据此审查。

## 跨段一致性

- **bhikkhave**：§72 句 17-26、§81、§82 译“比丘们”，其余各段译“诸比丘” → 统一为“诸比丘”（本 chunk 多数用法）。
- **paṭisaṅkhā yoniso**：§72、§75–78、§81、§84 译“如理省察后”，§87 译“如理省思后” → 统一为“如理省察后”。
- **vighātapariḷāhā**：同一个词在本 chunk 有五种译法：
  - §72、§73 译“恼害热恼”
  - §79 译“使人苦恼、炽热”
  - §82 译“损恼与热恼”
  - §85 译“使人苦恼、烦热”
  - §88 译“使他忧恼焦热”

  nissaya 释为 `ဝိဃာတပရိဠာဟာ= ပင်ပန်းကြောင်း ဖြစ်သော ပူလောင်ခြင်း`，意思是“引起困苦的热恼”。建议统一为“困恼热恼”。句法问题见下一条。
- **āsavā vighātapariḷāhā 的句法关系**（各段同型句都有这个问题）：
  - nissaya 的主读法是两个并列主语：`ယံ-ယေ အာသဝါ= …တို့သည်၎င်း။ ယံ-ယေ ဝိဃာတပရိဠာဟာ= …တို့သည်၎င်း။`（§72）。§79 也一样用 `၎င်း` 并列。意思是“诸漏，以及困恼热恼”。
  - 把 vighātapariḷāhā 当作 āsavā 的定语（“带来困恼热恼的诸漏”），只是 §72 nissaya 末尾 `အနက်သမ္ဗန်နိုင်သေး၏` 所说的备选读法。
  - 现在 §72、§79、§82、§85、§88 全都按定语译，取的是备选义 → 建议各段统一改为并列：“……那些漏与困恼热恼就会生起；……那些漏与困恼热恼就不会生起”。
- **assa（那位比丘[的相续中]）**：nissaya 每句都把它释为 `ထိုရဟန်း၏ (သန္တာန်၌)`，即“在那位比丘身上”。§88 译出了“他”，§72、§79、§82、§85 都没译 → 统一补出“在他身上”或“他”。
- **evaṃ**：nissaya 释为 `ဤအကြောင်းအားဖြင့်`（因为这个缘故）。只有 §88 译出“这样”，其余都漏了 → 统一补“这样”。
- **na honti**：§88 译“就不会有”，其余译“不会生起” → 统一为“就不会生起”。
- **“便”（文言虚词）**：§72 句 27-47、§79 句 2-21 都用“便不会生起” → 必改为“就不会生起”。
- **“X pahātabbā” 标题与问句的句式**：
  - nissaya 一律把前项释为断除的手段，即“由 X 所应断”：
    - saṃvara = 防护之念（`သတိသည် ပယ်အပ်`）
    - paṭisevana = 受用之慧（`ဉာဏ်သည်`）
    - adhivāsana = 忍耐之无瞋（`အဒေါသသည်`）
    - parivajjana = 避开之思（`စေတနာသည်`）
    - vinodana = 驱除之精进（`ဝီရိယသည်`）
  - 现在的译法各段句式不一：
    - §71/72/73：应以律仪断除的诸漏
    - §74/75/79：通过受用而应断除的诸漏
    - §80/81/82：忍耐所应断的漏
    - §83/84/85：应远离而断除的诸漏
    - §86/87/88：应以驱除（来）断除的漏
  - 建议统一为“应以 X 断除的漏”：应以律仪／受用／忍耐／远离／驱除断除的漏。“诸漏”与“漏”也要二选一（建议都用“漏”，或都用“诸漏”）。
- **saṃvara 在同一段内也不一致**：§72 句 17-26 译“律仪”，句 27-47 译“之自制”（“之”是文言）→ 统一为“律仪”。
- **引号**：§81、§82、§87、§88 的句首有“，§72、§75、§84 没有，与原文的 ‘‘ 不对应 → 按原文统一处理开引号，并核对闭合。
- **pe 的译法**：§72 句 48-72 用“……乃至……”，§87 只用“……” → 统一为“……乃至……”。

## §72 句 164-72-17-26

- **问题**：格与句法。nissaya 释为 `စက္ခုန္ဒြိယသံဝရ သံဝုတော= စက္ခုန္ဒြိယသံဝရသီလဖြင့် စောင့်စည်းသည် ဖြစ်၍`，用的是具格 `ဖြင့်`：意思是“以眼根律仪戒防护着”，再接 `ဝိဟရတိ= နေ၏`（住）。译文“安住于守护眼根律仪”把具格误读成处格（“安住于……”），律仪从手段变成了住处。
- **建议**：“比丘以眼根律仪防护而住。”

## §72 句 164-72-27-47

- **问题**：
  1. nissaya 释为 `စက္ခုန္ဒြိယသံဝရံ= …သီလကို။ အသံဝုတဿ= မစောင့်စည်းသည်ဖြစ်၍`，意思是“不以眼根律仪（戒）防护”。译文“守护眼根之自制”既换了术语，又用了文言“之”。
  2. 漏译 assa（“那位比丘”）和 evaṃ。
  3. āsavā 与 vighātapariḷāhā 应为并列（见跨段一致性）。
  4. 用了“便”。
- **建议**：“诸比丘，他若不以眼根律仪防护而住，那些漏与困恼热恼就会在他身上生起；他以眼根律仪防护而住，这样，那些漏与困恼热恼就不会生起。”

## §72 句 164-72-48-72

- **问题**：同句 17-26，“安住于守护 X 根律仪”把具格误读成处格。
- **建议**：“如理省察后，以耳根律仪防护而住……乃至……以意根律仪防护而住。”

## §76 句 164-76-9-59

- **问题**：
  1. nissaya 对四个“不是为了”各有限定：
     - davāya：像村童那样嬉戏
     - madāya：像力士那样为力量而骄慢
     - maṇḍanāya：像宫女、妓女那样使肢体丰满
     - vibhūsanāya：像舞者那样使肤色美好

     其中 maṇḍanāya 释为 `အင်္ဂါကြီးငယ် ပြည့်ဖြိုးခြင်းငှါ`（为了肢体丰满），vibhūsanāya 释为 `အရေအဆင်း လှပတင့်တယ်ခြင်းငှါ`（为了肤色美好）。译文“装饰、美化”只是字面义，可以保留，但“骄逸”与 mada（骄慢、迷醉）有偏差。
  2. vihiṃsūparatiyā 的 nissaya 是 `ပင်ပန်းခြင်း ငြိမ်းရုံငှါ`（为了止息疲困），指饥饿之苦，不是“损害”。
  3. 句末 nissaya 释 `မေ= ငါ့အား`（对我，与格），后接三个主格名词 yātrā、anavajjatā、phāsuvihāro 和 bhavissati，意思是“我将有维生、无过失与安乐住”。译文改成“能存活、无过失，且能安住于安乐”，把名词改成了动词，“安住于”也是多补的。
- **建议**：“……不是为了嬉戏，不是为了骄慢，不是为了装饰，不是为了美化，只是为了这个身体的存续与维持，为了止息（饥饿的）困苦，为了资助梵行；这样，我将消除旧的（苦）受，不让新的（苦）受生起，我将能维持生命、没有过失、安乐地住。”

## §77 句 164-77-9-23（nissaya 见 77-2-8 行）

- **问题**：
  1. nissaya 把 utuparissayavinodanapaṭisallānārāmatthaṃ 释为一个整体：`ဥတုဘေးရန်ကို ပယ်ဖျောက်ခြင်း ကိန်းအောင်းမွေ့လျော်ခြင်း အကျိုးငှါသာလျှင်`，意思是“只是为了除去季节的危害、乐于独处”。其中 paṭisallāna 释为 `ကိန်းအောင်း`（隐居独处），译文的“禅修”是多补的。
  2. 标点：“为了防御炎热,”用了 ASCII 逗号，必改为全角“，”。
- **建议**：“……为了防御炎热，……只是为了除去季节的危害、乐于独处。”

## §78 句 164-78-9-35（nissaya 见 78-2-8 行）

- **问题**：
  1. nissaya 释为 `ဥပ္ပန္နာနံ= ဖြစ်ပြီး ဖြစ်ဆဲ`（已生、正生）、`ဝေယျာဗာဓိကာနံ= ဓာတ်ချောက်ချားခြင်းကြောင့်`（由四界失调所生）、`ယာဝ ပဋိဃာတာယ= ပယ်ဖျောက်ရုံငှါ`（只是为了消除）。对象是已经生起的感受，“防御”不通，应译为“消除”。
  2. abyābajjhaparamatāya 的 nissaya 是 `အနာကြောင့်ဖြစ်သော ဆင်းရဲခြင်း၏ မရှိခြင်းအကျိုးငှါ`，即以“没有病苦”为极致。译文“达到没有痛恼的状态”漏了 parama（最、极）的意思。
- **建议**：“只是为了消除已生起的、由身体失调而来的（苦）受，为了以无病苦为最。”

## §79 句 164-79-2-21

- **问题**：
  1. 漏译 assa 和 evaṃ。
  2. āsavā 与 vighātapariḷāhā 应为并列，nissaya 是 `ယံအာသဝါ= …၎င်း။ ယံဝိဃာတပရိဠာဟာ= …၎င်း`。
  3. 用了“便”。
  4. appaṭisevato 的 nissaya 是 `(သင့်သောအကြောင်းအားဖြင့်) ပစ္စည်းလေးပါးကို မမှီဝဲရသော`，即“不（如理）受用四资具”。译文“若不这样受用”的意思可以接受。
- **建议**：“诸比丘，他若不（如理）受用，那些漏与困恼热恼就会在他身上生起；他（如理）受用，这样，那些漏与困恼热恼就不会生起。”

## §81 句 164-81-32-61

- **问题**：
  1. nissaya 释 `ဒုရုတ္တာနံ= မကောင်းသဖြင့် ဆိုအပ်ကုန်သော`（说得恶劣的），`ဒုရာဂတာနံ= မကောင်းသဖြင့် ရောက်လာကုန်သော`（以恶劣方式传来的）。译文“粗恶、难堪”把后一个词意译掉了。
  2. 句法上，nissaya 用 `ခမော … ဟောတိ` 统摄虫触与言语，用 `အဓိဝါသကဇာတိကော ဟောတိ`（具有忍受的性情）统摄身体的感受。译文三处都写“能忍受”，没有体现后一项是“性情”。这一点可以接受，属于可选修改。
- **建议**：“……能忍受恶语、恶意传来的话语；对于身体上生起的痛苦、剧烈、粗猛、刺痛、不愉快、不合意、足以夺命的感受，他具有能够忍受的性情。”

## §82 句 164-82-2-20

- **问题**：
  1. 漏译 assa 和 evaṃ。nissaya 是 `အဿ= ထိုရဟန်း၏ (သန္တာန်၌)`。
  2. “损恼与热恼的漏”把并列读成了定语（见跨段一致性）。
- **建议**：“诸比丘，他若不忍耐，那些漏与困恼热恼就会在他身上生起；他忍耐，这样，那些漏与困恼热恼就不会生起。”

## §84 句 164-84-50-80

- **问题**：格与句法误读，这是本 chunk 最严重的一处。
  1. nissaya 把 `နိသိန္နံ= နေသော ရဟန်းကို`、`စရန္တံ= ကျက်စားသော ရဟန်းကို`、`ဘဇန္တံ= ဆည်းကပ်သော ရဟန်းကို` 三个分词都释为宾格“……的比丘”，它们是 okappeyyuṃ 的宾语。译文把它们改成“……之人的情形”，主宾结构被打乱了。
  2. nissaya 释 `ဝိညူ= ပညာရှိကုန်သော။ သဗြဟ္မစာရီ= သီတင်းသုံးဖော်တို့သည်`，即有智慧的同梵行者（主格）。
  3. nissaya 释 `ပါပကေသု ဌာနေသု သြကပ္ပေယျုံ= ယုတ်ညံ့ကုန်သော အရပ်တို့၌ ယုံကြည်/ဆုံးဖြတ်ကုန်ရာ၏`，意思是“会把他认定于恶处”。译文“怀疑他曾做过或将会做出这样的事”是多补的引申。
  4. 原文和 nissaya 都没有“交往恶劣、无戒行”，属于增译。
  5. nissaya 的注说明 mitte 带有 paṭirūpaka 义，即“伪友、似友”。可以简洁地译为“恶友”，不必用括注“（实非朋友）”。
  6. “同修”与 sabrahmacārī 的通行译法“同梵行者”不符。
- **建议**：“有智慧的同梵行者，会把坐在那种不适当的座处、行走在那种不适当的行处、亲近那种恶友的比丘，认定为身处恶处（有恶行）；他如理省察后，避开那不适当的座处、那不适当的行处，以及那些恶友。”

## §85 句 164-85-2-20

- **问题**：漏译 assa 和 evaṃ。āsavā 与 vighātapariḷāhā 应为并列。
- **建议**：“诸比丘，他若不远离，那些漏与困恼热恼就会在他身上生起；他远离，这样，那些漏与困恼热恼就不会生起。”

## §87 句 164-87-17-53

- **问题**：
  1. 覆盖不全。原文和 nissaya 有五个动词：
     - nādhivāseti：不接受（`လက်မခံ`）
     - pajahati：舍弃（`ပယ်စွန့်`）
     - vinodeti：驱除（`ပယ်ဖျောက်`）
     - byantīkaroti：使其有边际、终结（`ကင်းသော အပိုင်းအခြားရှိသည်ကို ပြု`）
     - anabhāvaṃ gameti：使其一再不生（`အဖန်ဖန် မဖြစ်ခြင်းသို့ ရောက်စေ`）

     译文只有四项，把 byantīkaroti 与 anabhāvaṃ gameti 并成了“使其归于灭无”。前后两处都漏了。
  2. “省思”与其他段的“省察”不一致。
  3. pe 处没有译“乃至”。
- **建议**：“诸比丘，比丘在这里如理省察后，对已生起的欲寻不接受、舍弃、驱除、终结它、使它不再生起；对已生起的恶意寻……乃至……对已生起的害寻……乃至……对每每生起的恶不善法，不接受、舍弃、驱除、终结它们、使它们不再生起。”

## §88 句 164-88-2-20

- **问题**：
  1. 把并列读成了定语（“使他忧恼焦热的漏”）。
  2. vighātapariḷāhā 又出现第五种译法。
  3. na honti 译作“不会有”，与他段的“不会生起”不一致。
- **建议**：“诸比丘，他若不驱除，那些漏与困恼热恼就会在他身上生起；他驱除，这样，那些漏与困恼热恼就不会生起。”
