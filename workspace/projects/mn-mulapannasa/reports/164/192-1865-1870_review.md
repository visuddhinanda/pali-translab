## 一、被解释词与父层译文核对（首要项）

- **§1866 id=192-1866-22-27**：`**Ṭhitiparittatāyā**ti …` — 该词逐字引自父层 130-2257 的黑体 `**ṭhitiparittatāya**`，父层译文为“**存续时间的短暂性**”，本层却译作“**从存续短暂性**”，漏了“时间的”。
  → **必改**：改为“从存续时间的短暂性”，与父层逐字一致。

- 其余检出的黑体被解释词经核对与父层一致，例举（无需改）：
  - `Taṇhupādinnassā` → “由渴爱所执取”（一致于 130-2259）
  - `Pariggahan`/`Paṭṭhapento` → “把握”/“确立”（一致于 130-2260）
  - `Vācāya ghaṭṭanameva vuttaṃ` → “就言语上的触恼而说的”（一致于 130-2260）
  - `Sampativattamānuppannabhāvenā`/`Samudācāruppannabhāvenā` → “顺应而生起”/“现行而生起”（一致于 130-2260）
  - `Pakkhandatī` → “投向”，`Pasīdatī` → “得净信”（均一致于 130-2260）

## 二、文言腔问题（逐处必改）

跨段反复出现“即”“故”“则”“其”等文言虚词，按 `style.md` 禁例表逐一列出：

- §1865 id=192-1865-55-69：“衰坏、毁坏之法是**其**自性，**故**称衰坏之法，它的状态**即**‘衰坏性’，就意义而言，**即**是耗尽。”
  → 改：“衰坏、毁坏之法是它的自性，所以称为衰坏之法，它的状态就是‘衰坏性’，就意义而言，也就是耗尽。”
- §1865 id=192-1865-39-50：“无有**即**‘无有性’，**即**不存在，是这样性质的法。”
  → 改：“无有就是‘无有性’，也就是不存在，是这样性质的法。”
- §1866 id=192-1866-2-13：“‘存续短暂’**即**极为短促的刹那。”
  → 改：“‘存续短暂’就是极为短促的刹那。”
- §1868 id=192-1868-45-64：“**若**其中之一过度，**则**寿行便会中断……**若**被过度的寒冷或过度的炎热所压服，**则**会丧命。”（“若…则”为明确禁例）
  → 改：“其中之一过度时，寿行就会中断……被过度的寒冷或过度的炎热压服时，就会丧命。”
- §1869 id=192-1869-10-30：“……所以说这三种随观必然能断除这些把持，**故**说……”
  → 改：“……所以说这三种随观必然能断除这些把持，所以说……”
- §1870 id=192-1870-192-196：“就意门速行的根本而言，**即**是‘遍知’。”
  → 改：“就意门速行的根本而言，就是‘遍知’。”
- §1870 id=192-1870-197-204：“……**则**应当就五门速行本身尚未生起、以及已生起这两种情形来理解。”
  → 改：“……应当就五门速行本身尚未生起、以及已生起这两种情形来理解。”
- §1867 id=192-1867-11-16：“因为舍受也因**其**非可爱非不可爱的性质，而被摄入苦与乐之中。”
  → 改：“因为舍受由于它非可爱非不可爱的性质，也被摄入苦与乐之中。”
