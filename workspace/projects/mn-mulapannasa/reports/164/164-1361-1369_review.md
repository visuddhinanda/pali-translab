# Review — 164:1361-1369（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本 chunk 仅 §1369 句 164-1369-2-33 有 nissaya，其余句只做跨段一致性核对）

## 跨段一致性

- **abhijjhā**：§1366（164-1366-13-32、164-1366-65-83）的 abhijjhādomanassā 译为“贪欲、忧恼”，§1368（164-1368-75-86）的 abhijjhaṃ / vigatābhijjhena / abhijjhāya 译为“贪爱”“离贪”。建议统一为“贪欲”。
  - 依据：本经是《大爱尽经》（Mahātaṇhāsaṅkhaya），“爱”是 taṇhā 的核心译名。用“贪爱”对译 abhijjhā，会让读者把它和 taṇhā 混同。
- **saṃvara**：§1366 句中 saṃvarāya、saṃvaraṃ 译为“摄护”，同段末句 indriyasaṃvarena 译为“根律仪”。同一词在一段内出现两种译法，建议统一：
  - 若取“律仪”，前文改为“为了律仪而修行……于眼根中达成律仪”；
  - 若取“摄护”，末句改为“根的摄护”。
- **vivekajaṃ pītisukhaṃ / samādhijaṃ pītisukhaṃ 的结构**：§1369 两句都把“…而生”接到“喜乐”上（“由远离而生喜乐的初禅”“由定而生喜乐”），即译成“离 / 定生出喜乐”。按下文 164-1369-2-33 的 nissaya，两词都是并列修饰 jhānaṃ 的定语。若前句按建议修改，164-1369-34-64 也应同步改为“由定而生、具有喜乐的第二禅”，以保持对应。
- **标点**：164-1361-2-28“到那里说,以离间这些人”中混入半角逗号 `,`，应改为全角“，”。

## §1369 句 164-1369-2-33

- **问题 1**：句法误读，定语归属错。
  - nissaya：`ဝိဝေကဇံ= ကင်းဆိတ်ခြင်းကြောင့်ဖြစ်သော`（由远离而生的）、`ပီတိသုခံ= ပီတိသုခရှိသော`（具有喜乐的）、`ဈာနံ= ကို`。
  - 也就是说，vivekajaṃ 与 pītisukhaṃ 是并列的两个定语，都修饰 jhānaṃ：初禅“由离而生”，初禅“具有喜乐”。
  - 译文“由远离而生喜乐的初禅”把 vivekaja 变成修饰“喜乐”，又把 pītisukha 当作被生出的宾语，主从关系不对。
- **建议**：“……进入并安住于有寻、有伺、由远离而生、具有喜乐的初禅。”
- **问题 2**：译义收窄。
  - nissaya：`ကာမေဟိ= ဝတ္ထုကာမ ကိလေသာကာမတို့မှ`（从事欲与烦恼欲），kāmehi 包括“事欲”和“烦恼欲”两类。
  - 译文“欲乐”偏指可享受的对象，范围变窄。
- **建议**：改为“远离诸欲”，或“远离欲”。
- **问题 3**：限定词遗漏（次要）。
  - nissaya：`ဝိဝိစ္စေဝ= ကင်း၍ ဆိတ်၍ သာလျှင်`，`သာလျှင်`对应 eva，表示“正是、唯有远离之后”，具有强调作用。
  - 译文未体现这层强调。
- **建议**：可补为“正是远离诸欲、远离不善法之后，……”。如果为了贴近惯用译法而不补，可以保留现状。
- **问题 4**：同位结构与措辞（次要）。
  - nissaya：`ဥပက္ကိလေသေ= ညစ်ညူးစေတတ်ကုန်သော`、`ဒုဗ္ဗလီကရဏေ= အားနည်းအောင်ပြုတတ်ကုန်သော`，两者都是修饰 nīvaraṇe 的定语（“令心染污的”“使慧衰弱的”），宾格的中心语是“这五盖”。
  - 译文用破折号把它们拆成同位语，并以“这些……东西”收尾，语义不错，但“东西”偏口语，也弱化了定语关系。
- **建议**：“他断除了这五种令心染污、使智慧衰弱的盖，……”
