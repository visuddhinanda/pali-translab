# Review — 164:367-379（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **uppajjamānā uppajjati / nivisamānā nivisati**：§369-20-33 至 §379-2-32 前的各句都译成「就在那里生起，就在那里安住」，略掉了现在分词 uppajjamānā / nivisamānā；§379-2-32 译成「生起时就在这里生起，安住时就在这里安住」；§369-2-19 问句又是「在哪里生起就生起」。nissaya 一律是 `ဥပ္ပဇ္ဇမာနာ= ဖြစ်လတ်သော်`（生起时）、`နိဝိသမာနာ= ကိန်းလတ်သော်`（安住时）。
  → 建议全 chunk 统一为「生起时就在这里生起，安住时就在这里安住」，问句相应作「生起时在哪里生起？安住时在哪里安住？」。
- **ettha**：§369–§378 译「那里」，§379 译「这里」。nissaya 作 `ဧတ္ထ= ဤ…ရုပ်၌`，`ဤ` 是近指“此”。
  → 建议统一为「这里」。
- **sātarūpaṃ**：§369–§378 译「可喜」，§379 译「可乐」，而且 §379 省掉了顿号（「可爱可乐」）。
  → 建议统一为「可爱、可喜」。
- **etthesā taṇhā**：§369 有指示词，作「这渴爱」；§369-20-33 至 §378 只作「渴爱」；§379 又作「这渴爱」。
  → 建议统一保留「这渴爱」。
- **呼格 bhikkhave**：§368、§369 译「比丘们」，§379-33-40 译「诸比丘」。
  → 建议统一为「比丘们」（「诸」偏文言）。
- **句式模板**：§370–§378 作「X是世间……可爱、可喜的」，§379-2-32 改成「世间的**X**……凡是可爱可乐的」。两种句式结构不同，§379 那种是误读，详见下文 §379 一节。
  → 建议统一用 §370–§378 的主谓模板。
- **「乃至」**：§370-23-51 的巴利原文有 `… pe …`，译「乃至」是对的。§371–§379 的原文只有省略号、没有 pe，各段译文却都在第一项后加了「乃至」。
  → 建议 §371–§379 删去「乃至」，只用省略号，与原文对应。

## §367 句 164-367-2-2
- **问题**：准确性——原文 Samudayasaccaniddeso 只有「集谛」，没有 dukkha 和 ariya 两个成分，译文多出「苦」「圣」。
- **建议**：改为「集谛的解说」。如果出于全书标题体例需要保留，在报告中说明理由。

## §368 句 164-368-22-48
- **问题**：词法/取义——nissaya 给出 `တတြ တတြ= ထိုထိုအာရုံ ထိုထိုဘုံ၌`（于那些所缘、那些界处）和 `အဘိနန္ဒိနီ= အလွန်နှစ်သက်တတ်၏`（惯于极其喜好）。abhinandinī 的意思是「喜好、好乐」，不是「寻求」；tatra tatra 也不是泛泛的「到处」。
- **建议**：改为「……伴随喜贪、对种种对象处处好乐的渴爱」，或简作「处处好乐」。

## §369 句 164-369-2-19
- **问题**：句法——「在哪里生起就生起，在哪里安住就安住」把分词加定动词的结构译成了条件复句，意思不通。nissaya：`ဥပ္ပဇ္ဇမာနာ= ဖြစ်လတ်သော်` / `ကတ္ထ= အဘယ်၌` / `ဥပ္ပဇ္ဇတိ= ဖြစ်သနည်း`，即「生起时，在何处生起？」。
- **建议**：改为「比丘们，这渴爱生起时在哪里生起？安住时在哪里安住？」

## §369 句 164-369-20-33
- **问题**：句法——漏译分词 uppajjamānā / nivisamānā（见跨段一致性）。
- **建议**：改为「凡是世间可爱、可喜的事物，这渴爱生起时就在这里生起，安住时就在这里安住。」

## §370 句 164-370-9-22
- **问题**：格位——nissaya 作 `လောကေ= ၌`（处格），`စက္ခု= …သည်`（主格），`ပိယရူပံ= …မည်၏`（谓语「名为可爱之相」）。「眼是世间可爱、可喜的」勉强可读，但 loke 被读成了定语。主句的分词问题与上一句相同。
- **建议**：改为「眼在世间是可爱、可喜的，这渴爱生起时就在这里生起，安住时就在这里安住。」§370-23-51、§371–§378 照此统一。

## §379 句 164-379-2-32
- **问题 1**：格与句法（必改）——nissaya 明确 `ဓမ္မဝိစာရော= …ဝိစာရသည်`（主格），`ပိယရူပံ= ၏` / `သာတရူပံ= ၏`（谓语）。也就是说，「法伺」本身是可爱、可喜的。译文「世间的法伺，凡是可爱可乐的」把谓语误读成限定性关系从句，变成「伺中可爱的那部分」，意思走样。「世间的」又把处格 loke 当成了属格定语。
- **问题 2**：格式（必改）——译文中出现 `**色伺**` 等加粗标记。本文层不应带这种标记。
- **问题 3**：与本 chunk 其他各段的句式、用词不一致（见跨段一致性）。
- **建议**：改为「色伺在世间……声伺在世间……香伺在世间……味伺在世间……触伺在世间……法伺在世间是可爱、可喜的，这渴爱生起时就在这里生起，安住时就在这里安住。」

## §379 句 164-379-33-40
- **问题**：风格/一致性——「诸比丘」带文言色彩，与前文「比丘们」不统一。另外 nissaya 作 `ဣဒံ= ဤအလုံးစုံကို`（这一切），指以上全部内容。
- **建议**：改为「比丘们，这一切被称为苦集圣谛。」
