# Review — 164:976-988（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次为 nissaya 复核，只审词法）

## 跨段一致性
- **pāpimant / māra 混同**：§976、§977 句中 pāpimato 译“魔王”；§978 句 164-978-56-71 中 māraṃ 与 pāpimato 都译“魔王”；§986 句 164-986-24-39 中 māraṃ 译“魔”，pāpimato 译“恶魔”；句 164-986-60-68 中 pāpimato 译“恶魔”。nissaya 中 māraṃ= မာရ်နတ်ကို，pāpimato= မာရ်နတ်၏，指的是同一个对象，但两个巴利词不同，译名应当分开 → 建议全 chunk 统一为 māra 译“魔”，pāpimant 译“恶魔”（§976、§977 的“魔王”随之改为“恶魔”）。
- **adassanaṃ gato pāpimato**：§978 译“使魔王看不见，从而超越了他”，§979–985 的略句沿用“……超越了他”；§986 译“走到了恶魔看不见的地方”。nissaya 作 `အဒဿနံ= မမြင်ရာအရပ်သို့။ ဂတောတိ= ရောက်ပြီ`（到了〔恶魔〕看不见的地方），原文没有“超越”这层意思 → 统一为“去到了恶魔看不见的地方”，§979–985 的七处略句同步改为“比丘们，这称为……乃至……恶魔看不见的地方。”
- **andhamakāsi māraṃ / vadhitvā**：§978 译“使魔王眼盲……毁去魔眼”，§986 译“弄瞎了魔的眼睛，杀灭了魔眼”。nissaya 作 `အန္ဓံ အကာသီ`（使〔魔〕盲）、`ဝဓိတွာ= ဖျက်ဆီး၍`（毁坏），宾语是魔本身而不是“魔的眼睛”，vadhitvā 也不是“杀灭” → 两处统一为“使魔变盲……毁掉魔眼”。
- **apadaṃ 的归属**：§978 译“无迹可寻”，夹在两句之间；§986 译“使魔无迹可循”，挂在魔身上。nissaya 作 `မာရစက္ခုံ= ကို။ အပဒံ= တည်ရာမရှိအောင်။ ဝဓိတွာ`，apadaṃ 修饰 vadhitvā māracakkhuṃ，意思是“毁掉魔眼，使它无处立足” → 两处都按这个结构统一。
- **upasampajja viharati**：§978–985 译“具足……而住”，§986 译“成就并安住于想受灭” → 统一为“具足想受灭而住”。
- **Taṃ kissa hetu**：§978 译“这是什么缘故呢？”，§986 译“这是什么原因呢？” → 统一为“这是什么缘故呢？”
- **pāsarāsi**：§976 正文译“陷阱的绳网”，§988 经题译作《圣求经》，两处对不上（经题问题见 §988）。
- **baddho / abaddho**：§976 译“被捕获”，§977 译“没有被捕获”。nissaya 作 `ဗဒ္ဓေါ= ဖွဲ့နှောင်အပ်`（被缚住）。“被捕获”含有已被猎人带走的意思，和“躺卧在绳网上”的画面不合 → 两处改为“被套住 / 没有被套住”。
- **引号起头**：§979–985 各段首句都以“开头，§986 首句“再者，比丘们……”缺了开引号 → 补上。
- **文言虚词“其”**：§976 中“不见其过患”出现 2 处，“见到其过患”出现 2 处（含句 164-976-158-183 与 §977 对应句）→ 改为“看不到它们的过患 / 看到它们的过患”。

## §976 句 164-976-54-77
- **问题**：词法误读 — `အနိဿရဏပညာ= ထွက်မြောက်ကြောင်းဖြစ်သော ပစ္စဝေက္ခဏာဉာဏ် မရှိကုန်သည်ဖြစ်၍`，意思是“没有作为出离之因的〔省察〕智慧”，是一个表示“不具备”的有财释。译文“不知出离的智慧”变成了“不知道某种智慧”，结构错了。另外“不见其过患”中的“其”是文言虚词。
- **建议**：“……不见其过患，不知出离的智慧，而受用它们” → “……看不到它们的过患，没有出离的智慧，而受用它们”。

## §976 句 164-976-94-104
- **问题**：词义 — `ဗဒ္ဓေါ= ဖွဲ့နှောင်အပ်`（被缚住），`ပါသရာသိံ= ကျော့ကွင်းအပေါင်းကို`（一堆套索/罗网，宾格），`အဓိသယေယျ= ဖိ၍ အိပ်ရာ၏`（压在上面躺着）。“被捕获”“陷阱的绳网”都偏离了 nissaya。
- **建议**：“就好比一头野生的鹿被套住了，躺在一堆罗网上。”

## §976 句 164-976-125-150
- **问题**：与句 164-976-54-77 相同（nissaya 以 `ပ။` 承前略），anissaraṇapaññā 误读为“不知出离的智慧”，“其”字也同样需要改。
- **建议**：照句 164-976-54-77 的改法同步修改。

## §978 句 164-978-2-25
- **问题**：词义（次要）— `အရညေ ပဝနေ= တောအုပ်ကြီး၌`，nissaya 把这两个词作为一个单元，意思是“在大森林里”。译文“在森林、丛林中”拆成了两个并列地点。
- **建议**：改为“在大森林中游走”。

## §978 句 164-978-36-55
- **问题**：资源疑问（记录，不改）— 本句的 nissaya 单元末尾多出 `အဿ= … ပညာယစ= … ဒိသွာ= … အာသဝါ= … ပရိက္ခီဏာ= … ဟောန္တိ` 一段。这对应 §986 的 paññāya cassa disvā āsavā parikkhīṇā honti，不属于初禅句，应是 nissaya 对齐错位。译文没有受影响，不需要补译。

## §978 句 164-978-56-71
- **问题**：句法与增译（必改）— nissaya 的结构是：`အယံဘိက္ခု= ကို … ဝုစ္စတိ`，整句为“这位比丘被称为：‘使魔变盲’、‘毁掉魔眼使它无处立足，到了恶魔看不见的地方’”。具体有四处问题：
  1. “从而超越了他”在原文中没有依据，属于增译；
  2. “使魔王看不见”把 `အဒဿနံ ဂတော`（去到看不见之处）译成了致使义；
  3. apadaṃ 应当挂在 vadhitvā 上；
  4. māraṃ 与 pāpimato 都译成“魔王”，没有区分。
- **建议**：“比丘们，这称为：比丘使魔变盲，毁掉魔眼使它无处立足，去到了恶魔看不见的地方。”

## §979–985 句 164-979-25-33 等七处略句
- **问题**：沿用了 §978 的增译“超越了他”（必改）。
- **建议**：一律改为“比丘们，这称为……乃至……恶魔看不见的地方。”

## §986 句 164-986-40-55
- **问题**：句法 — nissaya 在 `တိဏ္ဏောတိ`、`ဂစ္ဆတီတိ`、`ကပ္ပေတီတိ` 后都带 ti，并在句法注中明确说明：这几句与前面的 andhamakāsi、apadaṃ vadhitvā 两句一样，都是由 ti 引出、作为 vuccati（“称为”）的内容。译文把它译成另起一句的叙述“他渡过了……”，称谓结构就断开了。另外，vissattho 作 `မကြောက်မရွံ့ ရဲဝံ့`（无所畏惧），“安心地”可以接受，但需要与 §978 保持一致（现在两处一致，不必改）。
- **建议**：与上一句衔接，表明仍属于“被称为”的内容，例如：“……去到了恶魔看不见的地方，已渡过世间的贪爱，安心地行走，安心地站立，安心地坐着，安心地躺卧。”上一句的句号相应改为逗号。

## §988 句 164-988-2-5
- **问题**：经题误译（必改）— `ပါသရာသိသုတ္တံ`，其中 pāsarāsi 在 §976 的 nissaya 中作 `ကျော့ကွင်းအပေါင်း`（一堆套索/罗网）。本经讲的是五种欲与鹿陷罗网的譬喻，不是《圣求经》。译文借用了 MN 26 别名的汉译题，与本经内容和 §976 正文的译法都对不上。
- **建议**：“第六《罗网堆经》终。”经题用词要与 §976 正文中 pāsarāsi 的定译（建议“一堆罗网”）保持一致。
