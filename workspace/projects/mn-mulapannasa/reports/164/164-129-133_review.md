# Review — 164:129-133（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **第一人称被译成第三人称（必改，涉及 §129、§130 共 7 句）**：世尊在向婆罗门自述，动词都是第一人称（abhininnāmesiṃ / passāmi / pajānāmi / abbhaññāsiṃ），§130 还有 `တဿ မေ= ထိုငါဘုရား၏`（我的）。译文的处理不一致：§129 句 102-120、121-150 与 §130 句 132-162 译作「我」，§129 句 2-24、25-43 与 §130 句 2-25、26-59、60-92、93-110、116-131 却译作「他」。这样前后叙述者对不上，读者会以为在说另一个人。→ 统一为「我」。句首的 So 在这里等于 so ahaṃ，应译「我」，或者省略主语。
- **sugata / duggata 与 sugati 混为一谈**：§129 句 25-43 和 102-120 里的 sugate duggate 是修饰 satte 的形容词，`သုဂတေ= ကောင်းသော ဂတိသို့ လားကုန်သော`，意思是去往善趣的有情；句 90-101 里的 sugatiṃ 才是趣处本身。译文三处都写「善趣」，前两处被读成了「看见善趣」这个处所。→ 前两处改为「去往善趣的、去往恶趣的有情」。
- **bhonto 两处都漏译**：§129 句 44-60 和 72-89 都有 `ဘောန္တော= အရှင် ဖြစ်ကုန်သော`。处理要统一，见下文分句意见。
- **araññavanapatthāni pantāni senāsanāni**：§131 句 17-33 和 43-67 都译作「林野中僻远的住处」，前后一致。但这一译法与 nissaya 的并列结构不合，两处要一起改，见下文分句意见。
- **文言残留**：§129 句 2-24 与 §130 句 2-25 用了「…之时」，属于 style.md 禁用的「当…之时」句式。→ 两处统一改为「…的时候」。

## §129 句 164-129-2-24
- **问题**：人称误读。So…abhininnāmesiṃ 是第一人称，译文作「他」。另有文言句式「当…之时」。
- **建议**：「我的心这样得定、清净、洁白、无瑕、离随烦恼、柔软、堪任、安住、达到不动的时候，我把心导向有情死生智。」nissaya 把 `စုတူပပါတဉာဏ်၏ အကျိုးငှါ` 释为「为了（得）死生智」，所以「导向」的宾语是心，智是目的。

## §129 句 164-129-25-43
- **问题 1**：人称误读。passāmi / pajānāmi 是第一人称，译文作「他」。
- **问题 2**：漏了宾语 satte，造成句法误读。nissaya 注明 `(သတ္တေ ပဿာမိကို ၄-ဒုကလုံး၌ ယှဥ်ပေးသည်)`，即「看见有情」要分别配到四对形容词上。hīne paṇīte、suvaṇṇe dubbaṇṇe、sugate duggate 都是修饰 satte 的宾格形容词。译文「看见卑贱、高贵……看见善趣、恶趣」把形容词当成了宾语。
- **问题 3**：yathākammūpage 的释义是 `အကြင် အကြင်ကံကြောင့် ကပ်ရောက်ကုန်သော`（因各自的业而趣往）。译文「随业流转」多出了「流转（轮回）」的意思。
- **建议**：「我以特别清净、超越常人的天眼，看见正在死去、正在投生的有情，看见卑劣的、殊胜的有情，看见容貌好的、容貌丑的有情，看见去往善趣的、去往恶趣的有情，了知有情依各自的业而趣往——」sugate / duggate 的异释（`ဝါ=` 富足的／贫穷的）按 style.md 作脚注备列。

## §129 句 164-129-44-60
- **问题**：漏译。bhonto 的释义是 `အရှင် ဖြစ်ကုန်သော`，是对有情的敬称修饰；vata 的释义是 `စင်စစ်`（确实）。两者都没有译出。
- **建议**：「‘这些尊贵的有情确实具足身恶行……’」，或者至少补出「确实」。与句 72-89 统一处理。

## §129 句 164-129-61-71
- **问题**：句法结构有出入。nissaya 中 apāyaṃ / duggatiṃ / vinipātaṃ 的释义都以 `ဖြစ်သော`（作为……的）结尾，是 nirayaṃ 的定语，只有 `နိရယံ= ငရဲ၌` 是处所。译文把四者并列成四个去处。
- **建议**：可改为「投生到作为苦处、恶趣、堕处的地狱」。如果为了沿用通行的并列译法而保留原样，也要和句 90-101 一并考虑。

## §129 句 164-129-72-89
- **问题**：vā pana 的释义是 `ထိုမှတပါး`（除此之外的、另外的），译文「而这些有情」与上一组的「这些有情」区分不开。bhonto 同样漏译。
- **建议**：「另一方面，这些尊贵的有情具足身善行……」

## §129 句 164-129-90-101
- **问题**：sugatiṃ 的释义是 `ဖြစ်သော`，是 saggaṃ lokaṃ 的定语，`သဂ္ဂံလောကံ= နတ်ပြည်လောက၌` 才是处所。译文把二者并列，与句 61-71 是同一类问题。
- **建议**：「投生到作为善趣的天界」。与句 61-71 统一。

## §129 句 164-129-102-120
- **问题**：本句用了「我」，人称正确。但「看见卑贱、高贵……看见善趣、恶趣」的宾语误读与句 25-43 相同。
- **建议**：按句 25-43 的改法逐字同步。

## §130 句 164-130-2-25
- **问题**：人称误读（abhininnāmesiṃ），并有「之时」文言句式。
- **建议**：与 §129 句 2-24 逐字对齐，导向的目标改为「漏尽智」，因为释义是 `အာသဝက္ခယဉာဏ်၏ အကျိုးငှါ`。

## §130 句 164-130-26-59
- **问题**：人称误读。abbhaññāsiṃ 是第一人称过去时，译文作「他」。
- **建议**：「我如实了知‘这是苦’……」

## §130 句 164-130-60-92
- **问题**：人称误读，与上句相同。
- **建议**：「我如实了知‘这些是漏’……」

## §130 句 164-130-93-110
- **问题**：人称误读。`တဿ မေ= ထိုငါဘုရား၏`（那个我的）是明确的第一人称属格，译文作「当他」。另外，nissaya 把 cittaṃ 归属于「我」（我的心），译文只写「心」。
- **建议**：「当我这样知、这样见的时候，我的心从欲漏解脱，从有漏解脱，从无明漏解脱。」

## §130 句 164-130-111-115
- **问题**：时态和隐含成分都有出入。vimuttasmiṃ 的释义是 `လွတ်ပြီးသော်`（解脱之后），译文「在解脱时」改变了时间关系。nissaya 补出了主语 `(မေ= ငါ၏ ။ စိတ္တံ= သည်။)`（我的心），译文没有补。
- **建议**：「心解脱之后，生起了‘（心）已解脱’的智。」

## §130 句 164-130-116-131
- **问题 1**：人称误读。abbhaññāsiṃ 是第一人称，译文作「他了知」。
- **问题 2**：取义有出入。nissaya 的主释是 `ဣတ္ထတ္တာယာ= ဤတဆယ့်ခြောက်ချက် မဂ်ကိစ္စ အလို့ငှါ… အပရံ= တပါးသော ကျင့်ဖွယ်ကိစ္စ… န= မရှိ`，意思是为了这（十六种道的作用）再没有别的要做的事；「此生之后再无他生」是 `(တနည်း…)` 给出的异释。译文「不再有后有了」取的是异释。
- **建议**：「我了知：‘生已尽，梵行已修成，该做的已经做完，再没有为此而要做的事了。’」按 style.md「异释作脚注备列」，把「此后不再有来生」放进脚注。若保留「不再有后有」，应在报告中说明这里取了异释。

## §131 句 164-131-17-33
- **问题**：并列关系误读。nissaya 中 `အရညဝနပတ္တာနိ= တို့ကို၎င်း` 与 `ပန္တာနိ… သေနာသနာနိ= တို့ကို၎င်း` 用的是「……以及……」的并列格式，表示「林野」与「边远的住处」是两个并列宾语。译文合成了「林野中僻远的住处」。
- **建议**：「……所以才住在林野和边远的住处。」与句 43-67 统一。

## §131 句 164-131-43-67
- **问题 1**：atthavase 的释义是 `အကြောင်းတို့ကို`（理由、缘由），译文「利益」偏离了原义。
- **问题 2**：sampassamāno 的释义是 `ကောင်းစွာ မြင်သည်ဖြစ်၍`（看到、考虑到），译文「为了」把它改成了目的句。
- **问题 3**：araññavanapatthāni / senāsanāni 的并列问题与句 17-33 相同。
- **建议**：「婆罗门，我是考虑到两个理由才住在林野和边远的住处：一是看到自己的现法乐住，二是怜悯后世的人们。」

## §132 句 164-132-2-21
- **问题**：句法角色与语气有出入。nissaya 中 `အယံ ဇနတာ`（这些人）是被动句的主语，`ဘောတာ ဂေါတမေန` 是施事，vata 的释义是 `စင်စစ်`（确实），句末 `…ပါပေ၏` 带赞叹语气。译文把整句名词化为「……的怜悯」，漏掉了 ayaṃ 与 vata。
- **建议**：「后世的这些人确实受到了乔达摩尊者的怜悯，就像受到阿罗汉、正等正觉者的怜悯一样。」

## §132 句 164-132-32-54
- **问题**：dhāreyya 的释义是 `ညှိထွန်းရာ`（点燃），译文「举起」与 nissaya 不合。
- **建议**：「……或在黑暗中点起油灯——」

## §132 句 164-132-77-89
- **问题**：修饰关系有出入。nissaya 中 `သရဏံဂတံ= ကိုးကွယ်ရာ ဟူ၍ ဆည်းကပ်သော` 与 `ပါဏုပေတံ`、`အဇ္ဇတဂ္ဂေ` 都是修饰 upāsakaṃ 的定语。译文把「从今日起终身皈依」放到句末，成了独立的补充说明。
- **建议**：「愿乔达摩尊者认可我是从今天起终身皈依的优婆塞。」
