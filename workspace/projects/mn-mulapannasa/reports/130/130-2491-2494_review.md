# Review — 130:2491-2494（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（130-2492-120-134 没有独立的 nissaya 行，它的释义并在 130-2492-87-119 行里）／父层对照 164:1263-1264 ✅

## 被解释词与父层对照（必改项优先）

- **130-2493-2-16**：黑体「即使当时听得清楚、记得牢固、用心思惟、掌握得很透彻，也很快就忘记了」把父层整句都框了进来。被解释词只有 `yaṃ no khippameva antaradhāyati`，父层里对应的是「也很快就忘记了」。
  → **必改**：黑体改为「**也很快就忘记了**」，前半句移出黑体，不再作为被解释词。
- **130-2494-13-18**：黑体「**聚集**」在父层译文中不存在。父层把 `samupabyūḷho ahosi` 译作「发生过（天与阿修罗之间的战争）」。
  → **必改**：黑体必须与父层逐字相同。这里有两个办法：
  - 黑体改为「**发生过**」；
  - 或者先改父层。父层的「发生过」没有译出 samupabyūḷha「两军集结对阵」的意思，建议父层改作「天与阿修罗两军集结交战」之类，本层黑体再随父层改。

  建议走后一种，并在报告中提请父层修订。
- **130-2491-124-148**：黑体「**尊者目犍连，您好久才找到机会来这里一趟**」包含了「来这里一趟」。这几个字属于下一个被解释词 `yadidaṃ idhāgamanāya`（130-2491-187-202 已经单独出黑体），而本条的被解释词只到 `pariyāyamakāsi`。
  → 建议黑体收窄为「**尊者目犍连，您好久才找到机会**」。这是父层逐字子串，与下一条也不重叠。
- **130-2492-22-57**（提请父层）：黑体「**不但有自己的事**」与父层一致，这里没有问题。但本句义注自己的解释是 `sakaraṇīyameva appaṃ mandaṃ, na bahu`，nissaya 释作 `မန္ဒံ= နည်း၏`（少）。也就是说 `appeva` 取的是「少」义，而父层译成了「不但有」，读者会看到黑体与释文互相矛盾。本层不能动黑体，建议父层改为「自己的事倒是少」之类。

## 跨段一致性

- **tūriya**：§2491 第 2-10 句译「天乐」（与父层同），第 11-23 句和第 64-77 句译「乐器」。
  → 黑体以外的泛称可以用「乐器」，但第 64-77 句的「五百种乐器」是在复述被解释词 `pañcahi tūriyasatehi`，建议统一为「五百种天乐」。
- **vevacana**：§2491 第 49-53 句和 §2492 第 17-21 句都译作「是同一个词的另一种说法」，读起来像是这个词自己的异说。nissaya：`တဿေဝ= ထိုသမပ္ပိတော-ဟူသောပုဒ်၏သာလျှင်`、`ထိုဗဟုကိစ္စာဟူသော-ပုဒ်၏`，指的是前一个词。
  → 统一改为「是‘齐备’的同义词」和「是‘事务繁多’的同义词」。
- **ātata / vitata / ātatavitata**：§2491 第 11-23 句、第 31-34 句、第 35-38 句的标签与释文不符，详见下面对第 31-34 句的意见。三处要一起改。
- **thera**：§2491 第 170-174 句译「尊者」，紧接着第 175-181 句译「长老」。
  → 建议统一为「长老」。nissaya：`မထေရ်`。
- **nāṭaka**：§2491 第 95-123 句译「歌舞乐队」，§2493 第 81-113 句译「歌舞队」。
  → 统一为「歌舞伎」或「歌舞队」。nissaya：`ကချေသည်`（舞者）。
- **sahāya**：§2494 第 83-97 句译「伙伴」，第 114-124 句译「同伴们」。
  → 统一为「伙伴」。

## §2491 句 130-2491-31-34

- **问题**：误译（自相矛盾）。黑体标签「张弦」配的释文是「两面都蒙皮的」。nissaya：`ဝိတတံ= နှစ်ဖက်ပိတ်-စည်`（两面蒙皮的鼓）。这里与弦无关。第 11-23 句的列举和第 35-38 句的「张皮兼张弦」也随之错位。
- **建议**：五种要素改为：
  - ātata：「单面蒙皮」
  - vitata：「双面蒙皮」
  - ātatavitata：「皮面绷弦」（nissaya：`အလုံးစုံမှေး၍ကြက်သော`，`tantibaddha` 意为用弦绳绷紧）
  - susira：「中空」
  - ghana：「实心」

  三句同步修改。

## §2491 句 130-2491-45-48

- **问题**：词义偏差。`upagato` 的 nissaya 是 `အနီးသို့ကပ်၍-လိုက်သည်`（靠近而伴随），说的是帝释为天乐所伴随。译文「到齐」把主语移到了乐器上。
- **建议**：「‘**齐备**’是指有（天乐）相伴。」

## §2491 句 130-2491-54-63

- **问题**：句法补出不足。nissaya：`တတောတတော= ထိုထိုသို့သော-အာရုံမှ`（从各种境界）、`ဣန္ဒြိယာနိ= စက္ခုအစရှိသောဣန္ဒြေ`、`စာရေတိ= ကျက်စားစေ၏`（使之游走），意思是让眼等诸根在各种境界上游走。
- **建议**：「是指享受那份富乐时，让眼等诸根在各种境界上游走。」

## §2491 句 130-2491-78-85

- **问题**：`apanetvā` 的 nissaya 是 `ဖဲ၍`（撤开、遣开），译文「使乐器停止」与下文 `nissaddāni kārāpetvā` 的「使它们安静下来」重复。
- **建议**：「是指把天乐撤开，也就是让它们静下来的意思。」

## §2491 句 130-2491-95-123

- **问题**：`paṭivinenti` 的 nissaya 是 `ဖျောက်`（遣散），宾语 `nāṭakāni` 是舞者，也就是人。译文「让歌舞乐队停下来」不够贴切。
- **建议**：「……于是遣退歌舞伎。天帝释看见长老时，也是这样做的。」

## §2491 句 130-2491-182-186

- **问题**：释文没有译出 `vāra`。nissaya：`ဝါရံ= အလှည့်ကို။ အကာသိ= ပြု၏`（做了一回、轮到一次）。译文「找到机会、找到一次时机」只是把黑体重复了一遍。
- **建议**：「这里，‘**找到机会**’是指来了一回（vāra）。」

## §2491 句 130-2491-187-202

- **问题**：句尾「这是在说这个意思」与前面重复，读起来拗口。
- **建议**：「‘**来这里一趟**’是说：尊者，您隔了好久才来这里一回。」

## §2492 句 130-2492-87-119（含 130-2492-120-134、130-2492-135-146）

- **问题**：主宾关系误读。nissaya 在这里补出了两方：
  - `ယေပန= အကြင်နတ်သားတို့သည်ကား` 和 `သီမန္တရေ … ဒေဝိတ္ထိယော= နတ်သမီးတို့သည်။ နိဗ္ဗတ္တန္တိ`：在交界处化生的是天女；
  - `တေ= ထိုနတ်သားတို့သည် … အဋ္ဋံကရောန္တိ`：打官司的是天子。

  译文写成「那些在两界交界处化生的……就会打起官司来」，把化生者当成了诉讼方。第 120-134 句的 `olokento ṭhito` 是天女站着望向某座宫殿，第 135-146 句的 `taṃ` 指那位天女（nissaya：`ထိုနတ်သမီးကို`），`ubhinnaṃ` 指两位天子。现在的译文都没有交代清楚是谁。
- **建议**：
  - 第 87-119 句：「但如果有天女在两处交界的地方化生，天子们无法判定‘她是我的’还是‘她是你的’，就会打起官司……帝释就说：她属于宫殿离得较近的那一位。」
  - 第 120-134 句：「……就说她属于她站着时所望向的那座宫殿的主人。」
  - 第 135-146 句：「如果她哪一座都不望向，为了平息两位天子的争执，帝释就把她归为自己所有。」

## §2492 句 130-2492-160-164

- **问题**：`apica` 的 nissaya 是 `တနည်းလည်း`（另一种解释），表示这是另一说，不是递进。
- **建议**：「另一种解释是：像这样的游乐，对他来说也算是要做的事。」

## §2493 句 130-2493-2-16

- **问题**：
  1. 黑体问题见上文；
  2. `yaṃ` 的 nissaya 是 `ယံပဉှာဝိဿဇ္ဇနံ`（那个问题的解答），不是「这些教说」；
  3. `amhākaṃ` 的 nissaya 是 `ငါတို့အား`（对我们来说，与格），不是属格「我们的」；
  4. `rūpagataṃ` 是形色，译「影像」不够准确。
- **建议**：「‘**也很快就忘记了**’是说，那个问题的解答对我们来说很快就看不见了，就像黑暗中的形色一样。」

## §2493 句 130-2493-60-76

- **问题**：误读。`idha katamettha pamussanti` 的 nissaya 是 `ကတံ= ပြုအပ်သောအမှုကို … ပမုဿန္တိ= မေ့လျော့ကုန်၏`。这里是 `kataṃ`（所做的事），不是疑问词 katama，整句是陈述句。译文「这里又怎么会不忘记呢？」误作了反问。
- **建议**：「……连自己吃过没吃、喝过没喝都不知道，在这里做过的事，到了这里自然就忘了。”」

## §2493 句 130-2493-81-113

- **问题**：译反了。`nāṭakānaṃ antaraṃ paviṭṭho` 的 nissaya 是 `အတွင်းသို့ … ဝင်၏`（进入其中），译文却写成「脱身而出」。
- **建议**：「……我刚在世上最上首的人那里学了问题回来，转眼就钻进了歌舞伎中间，长老恐怕会因此呵斥我……」。`tajjeyya` 的 nissaya 是 `ခြိမ်းခြောက်`，译「呵斥」比「责备」更贴切。

## §2493 句 130-2493-137-146

- **问题**：`somanassasaṃvegaṃ` 的 nissaya 是 `သောမနဿ၏အကြောင်းဖြစ်သော … သံဝေဂံ`（能引生喜悦的悚惧），译文「喜悦的悚惧之心」意思不清楚。
- **建议**：「因为长老让他生起了能引发喜悦的悚惧，驱散了他的愚暗（tama，nissaya 释为无明），所以他才记起来了。」

## §2494 句 130-2494-30-32

- **问题**：`nibbattakāle` 的 nissaya 是 `ပဋိသန္ဓေအားဖြင့်ဖြစ်၍ဖြစ်သောအခါ`（以结生投生到忉利天的时候），指的是那一刻，不是「那一世」。
- **建议**：「是在天帝释投生到三十三天的时候。」

## §2494 句 130-2494-33-51

- **问题**：音译。`macalagāme` 译作「摩伽罗村」，与紧接着的人名「摩伽」（Magha）字形相近，容易混淆，音也不准确。
- **建议**：改为「摩查拉村」或「摩遮罗村」。

## §2494 句 130-2494-52-57

- **问题**：「三十三位人」不通顺。
- **建议**：「他带领三十三个人一起行善。」

## §2494 句 130-2494-58-82

- **问题**：`kacavaraṃ ubhayato apabbahitvā` 的 nissaya 是 `နှစ်ဘက်မှ … ပယ်ရှား၍`。「两边」修饰的是清除的方向，译文「两边的垃圾」把它当成了垃圾的位置。
- **建议**：「……把村子中央大众聚会处的垃圾往两边清开……」

## §2494 句 130-2494-98-113

- **问题**：`mālāgaccharopana` 的 nissaya 是 `ပန်းချုံစိုက်ပျိုးခြင်း`（种植花丛），译文作「种植花园树木」。
- **建议**：改为「种植花丛」。

## §2494 句 130-2494-114-124

- **问题**：术语。`satta vatapadāni` 的 nissaya 是 `ခုနစ်ပါးသော-ဝတ်ဟုဆိုအပ်သော-အကြောင်း`（七条誓行、禁行），说的是持守的行为规约。译「誓愿」容易与 paṇidhāna 混淆。「三十三天天界」也重复了。
- **建议**：「摩伽圆满了七条誓行（vatapada），身坏命终后，与伙伴们一起投生到三十三天。」首次出现时加夹注。
