# Review — 130:2173-2179（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 被解释词与父层对照（必改项）

- **§2175 句 130-2175-62-67**：黑体「**我们要来驳倒他的说法**」在父层 164-1001-76-87 中找不到逐字对应。父层两处分别是「我们就这样来驳倒他的说法」「我们也这样来驳倒他的说法」，*vādaṃ āropessāma* 一词在父层的稳定译法是「来驳倒他的说法」。
  → 改为「**来驳倒他的说法**」，或改为「**我们……来驳倒他的说法**」。
- **§2177 句 130-2177-6-12**：黑体「**反而成了弟子**」在父层不是连续字串。父层 164-1001-169-175 原文是「结果他们反而成了沙门乔答摩的弟子」。另外「反而」对应的是 *aññadatthu*，这个词不在本条被解释词 *sāvakā sampajjanti* 之内。
  → 改为「**成了沙门乔答摩的弟子**」（或「**成了……弟子**」）。
- **§2179 句 130-2179-23-35**：被解释词是 *uccā kāḷārikā*，黑体只写了「**卡拉里卡**」，漏掉了 *uccā*。父层 164-1006-47-63 把 *uccā* 译为「体型高大」。
  → 黑体应包含父层对 *uccā* 的译法，例如：“**体型高大**”“**卡拉里卡**”。
- **§2179 句 130-2179-69-87**：被解释词是 *uccā kaṇerukā nāmā*，问题同上，漏了 *uccā*（父层 164-1007-54-70 译为「体型高大」），*nāmā* 在父层译为「叫作」。
  → 补上「**体型高大**」，必要时连同「**叫作卡涅卢卡**」一起标黑。

其余黑体逐字核对无误：理由／尊者，比如一位熟练的猎象人／猎象人／四种迹象／刹帝利中的智者／智者／精明／熟悉他人的论说／如同能射穿毛发的射手一般／他们仿佛用智慧击破了各种见解／准备好问题／竟然不向沙门乔答摩提出问题／结果／那无上的／梵行终点／尊者，我们险些丧失了自己／明明不是沙门，却／明明不是婆罗门／明明不是阿罗汉／感叹道／感叹／象足喻／象林猎人／矮象／踩踏的痕迹也很深／还有很深的牙齿刮痕／卡涅卢卡／他便下结论说。

## 跨段一致性

- **gotama**：130-2175-142-172 译「沙门乔**达**摩」；同一 chunk 的 130-2175-68-75 黑体，以及父层 §1001 起，都用「乔**答**摩」。本段注的是 §1001 的情节。
  → 统一为「乔答摩」。
- **kusalo**：130-2178-91-97 和 130-2178-125-131 译「熟练的」，130-2178-109-124 译「熟练的人」，而 130-2178-98-108 译「善巧的」。这几句注的都是 §1005，父层 164-1005-30-38 作「善巧的象林猎人」。
  → 全部统一为「善巧的」。
- **nāgavaniko（后文用法）**：130-2174-26-32 说后文那位习得技艺的人「被称为猎象人」。但后文（§1005 起）父层译作「象林猎人」，130-2178-86-90 黑体也是「象林猎人」。
  → 本句改为「……则被称为象林猎人」。
- **danta / dāṭhā（象牙）**：130-2179-23-35、130-2179-36-45、130-2179-46-53、130-2179-69-87 都译「牙齿」，130-2179-54-68 译「象牙」。nissaya 一律作 `အစွယ်`（象牙、獠牙）。
  → 统一为「象牙」。
- **naṭṭha / anassāma**：被解释词译为「丧失了自己」，但释文 130-2177-29-50 和 130-2177-51-56 用「灭亡」解释它，读者看不出两者在说同一个词。
  → 释文改为「就会丧失自己（毁掉了）」「才没有丧失自己」。
- **ettakā**：130-2175-106-141 中同一个 *ettakā* 先后译为「这么多」「那么多」「多少」。
  → 统一为「这么多」。
- **语体（便＝于是）**：以下几句用了 style.md 禁用的「便」：130-2175-142-172「便心生欢喜」、130-2176-2-33「心便生起」、130-2176-34-40「便这样想」、130-2176-41-61「便不再提问」、130-2178-12-42「便溢出…便漫溢」。
  → 都改为「就」。引自父层的黑体「他便下结论说」保持不动。

## §2173 句 130-2173-35-75
- **问题**：数与集合名词误读。*anekasatāhi upāsikāhi*（`ဥပါသိကာမတို့သည်` 指优婆夷们）、*anekehi bhikkhunisatehi*（`ရဟန်းမိန်းမ-အရာတို့သည်` 指数百比丘尼）、*anekasatehi bhikkhūhi* 这三处说的都是「数百位（个人）」，不是「数百个……众」。只有 *upāsakagaṇehi* 和 *brāhmaṇagaṇehi* 才是 gaṇa（众）。
- **建议**：改为「受数百位优婆夷称赞」「受数百位比丘尼称赞」「受数百位比丘称赞」。

## §2174 句 130-2174-6-18
- **问题**：漏译与格角色。*assa* 的 nissaya 是 `ထိုဇာဏုသောဏီ ပုဏ္ဏားအား`（对那位生闻婆罗门，与格），译文漏了说话的对象。
- **建议**：改为「于是遍行者向他说明自己生起信心的原因，说了……」。

## §2174 句 130-2174-19-25
- **问题**：误译。*anuggahitasippo* 的 nissaya 是 `မသင်အပ်သော အတတ်ရှိသော`，意思是「技艺尚未学成的」，是明确的否定，不是「未必已习得」。另外，*nāgavanavāsiko* 的 nissaya 补出了目的：`ဆင်တို့ကိုဖမ်းအံ့သောငှာနေလေ့ရှိသော`（为了捕象而常住的）。
- **建议**：改为「是指为捕象而住在象林中、但还没有学成技艺的人」。

## §2175 句 130-2175-14-20
- **问题**：用词。*saṇhe sukhumabuddhino* 的 nissaya 作一个整体：`နူးညံ့သိမ်မွေ့သော ပညာရှိ`（具有细腻精微智慧的）。「慧根」是法相术语（indriya），这里不该用。
- **建议**：改为「是指智慧细腻精微、能够洞察细微义理差别的人」。

## §2175 句 130-2175-34-52
- **问题**：
  1. 比喻缺主语。nissaya 中 *vālavedhi* 是主格 `လေးသမားသည်`（射手），*vālaṃ* 是宾格（毛发），比喻的是「像射手射穿毛发一样」，译文写成了「他们就像射穿毛发一样」。
  2. 语体。「将其击破而行」带文言腔。
- **建议**：改为「意思是：就像射穿毛发的射手射穿毛发一样，他们即使面对别人细微的见解，也好像能用自己的智慧把它们击破，就这样四处行走」。

## §2175 句 130-2175-62-67
- **问题**：添译。释义 *dosaṃ āropessāma* 里没有 *evaṃ*，「就这样」是多出来的；*āropessāma* 的 nissaya 是 `တင်ကုန်အံ့`（加上、安上）。
- **建议**：改为「是指我们要给他安上过失」。黑体按上一节修改。

## §2175 句 130-2175-92-105
- **问题**：误译。*ovaṭṭikasāraṃ katvā* 的 nissaya 是 `ခါးပိုက်ဖြင့်ဆောင်အပ်သော-မြတ်သောဥစ္စာနှစ်တို့ကဲ့သို့`，意思是「像藏在腰带里随身带着的珍宝那样」，不是「做成核心」。*guḷhaṃ rahassaṃ* 的 nissaya 是 `လွန်စွာလျို့ဝှက်သော`（极其隐秘的）。
- **建议**：改为「这些刹帝利中的智者，把极其隐秘的问题像藏在腰带里的珍宝一样带了过来」。

## §2175 句 130-2175-106-141
- **问题**：
  1. *ovaṭṭikasāraṃ katvā ānīte* 同上，也误译成了「做成核心带来的」。
  2. *pucchanto evaṃ puccheyya, vissajjento evaṃ vissajjeyya* 是祈愿式（nissaya：`မေးရာ၏`／`ဖြေရာ၏`），意思是「提问的人应当这样问，回答的人应当这样答」。译文作「若这样提问、若这样回答等等」，把规范义误读成了假设，「等等」也是添出来的。
  3. *ettakā* 前后译法不一，见上文跨段一致性一节。
- **建议**：改为「……提问时有这么多过失，在义理、文句、字母和回答上有这么多过失；问这些问题应当这样问，答的时候应当这样答——就这样，把他们像腰带里的珍宝一样带来的问题，放进说法当中，一一破解」。

## §2175 句 130-2175-142-172
- **问题**：
  1. 语态。*no … katvā samaṇo gotamo khipeyya* 的 nissaya 是：*samaṇo gotamo* 为主格施事，*no* 是对象，*khipeyya* 作 `ပစ်ပယ်ရာ၏`（抛开、驳倒）。译文「让我们无立足之地而被驳倒」把主动句改成了被动，句子前后错位。
  2. 「乔达摩」应作「乔答摩」，「便」应作「就」，见跨段一致性一节。
- **建议**：改为「……沙门乔答摩恐怕会让我们毫无立足之地，把我们驳倒。”刹帝利中的智者就这样想着，心里很欢喜」。

## §2176 句 130-2176-2-33
- **问题**：误译。*suphusitadantāvaraṇā* 中的 *dantāvaraṇa*（遮齿者）指嘴唇，nissaya 是 `ကောင်းစွာထိအပ်သော နှုတ်ခမ်းတော်ရှိ`（双唇闭合得宜的），不是「齿列整齐紧密」。
- **建议**：改为「双唇闭合得宜」。「便」改为「就」。

## §2176 句 130-2176-41-61
- **问题**：添义。*paccanīkaggāhaṃ gaṇhituṃ* 的 nissaya 是 `ဆန့်ကျင်ဘက်ဖြစ်၍ယူခြင်း`（站到对立面去持论），原文里没有「抓住他的破绽」。*na pucchanti* 只是「不问」，「不再」也多了一层意思。
- **建议**：改为「……我们没法跟说这种话的世尊唱反调。”他们就是因为自己心生信乐，所以不提问」。

## §2177 句 130-2177-29-50
- **问题**：*naṭṭhā bhaveyyāma* 是对被解释词 *anassāma* 的解释，译成「灭亡」后与黑体「丧失了自己」脱节，见跨段一致性一节。
- **建议**：改为「我们就会丧失自己了」。130-2177-51-56 同步改为「才没有丧失自己」。

## §2178 句 130-2178-12-42
- **问题**：
  1. *mānaṃ* 的 nissaya 是 `ခြင်ခွက်`（量器），不是一般的容器。
  2. 本句以「……一样，」收尾，下一句又以「同样地」开头，比喻框架重复了。
  3. 语体：「溢出之油」用了「之」，「便」也应改。
- **建议**：改为「量器盛不下」「溢出的油」。句末改为「……这叫作‘洪流’。」，下一句保留「同样地」。

## §2178 句 130-2178-78-85
- **问题**：漏补主语。nissaya 补出了主语 `သောဟတ္ထိပဒေါပမော`（那个象足喻之法），*dasseti* 作 `ပြတော်မူ၏`（敬语，施事是世尊）。译文两样都没有。
- **建议**：改为「世尊是在说明：光是这样，这个象足喻还没有详尽地圆满」。措辞与父层 164-1004-111-123 保持一致。

## §2178 句 130-2178-98-108
- **问题**：*vibhāgadassanato* 的 nissaya 是 `ဝိဘာဂကို မြင်သောကြောင့်`，意思是「因为（后文）显示了区分」。「这样的分别说明可见」句子不通。
- **建议**：改为「因为后文用‘善巧的’作了区分」。

## §2178 句 130-2178-109-124
- **问题**：句子不顺。「只有熟练的人，这时还不会……」中，「这时」是对 *tāva*（nissaya `ရှေးဦးစွာ`，暂且）的误解。
- **建议**：改为「因为谁都可能进入象林，但善巧的人暂时还不会下结论」。

## §2179 句 130-2179-2-13
- **问题**：误读。*āyāmatopi na dīghā* 的 nissaya 是 `အလျားအားဖြင့်လည်း မရှည်ကုန်`，指身长（长度）也不长，不是「不高长」。原文三个限定是并列的：矮小、身长不长、大腹。
- **建议**：改为「是指身材矮小、身长也不长、腹部很大的母象」。

## §2179 句 130-2179-23-35
- **问题**：误译。*kaḷāratāya* 的 nissaya 是 `ကားသောအစွယ်ရှိသည်၏အဖြစ်ကြောင့်`，意思是因为象牙向两边岔开，不是「牙齿粗糙不整」；下文 130-2179-46-53「两颗……间隔很宽」正好印证这一点。黑体的问题见上文第一节。
- **建议**：改为「……而且因为象牙向两边岔开，所以叫作卡拉里卡」。

## §2179 句 130-2179-54-68
- **问题**：*chinnaṭṭhānaṃ* 的 nissaya 是 `ဖြတ်ရာအရပ်`（被割开、截断的地方），「刮伤」程度偏轻。
- **建议**：改为「如同被斧头砍过一样、被象牙划开的地方」。

## §2179 句 130-2179-110-145
- **问题**：
  1. 句法误读（必改）。*…bhavissatīti niṭṭhaṃ na gato*：nissaya 在 *iti* 后补出 `ဤသို့နှလုံးပိုက်၍`（心里这样想着），所以 *iti* 引出的是**没有下结论的理由**，不是结论的内容。意思是「想到‘这可能是矮象的足迹’，所以没有下结论」。译文「并没有断定这会是矮象的足迹」把意思弄反了。第二处的卡拉里卡、卡涅卢卡同理。
  2. 添义。*tato orabhāge* 的 nissaya 是 `ဤမှာဘက်အတို့၌`（在那之后、这一侧的路段上），「更深的痕迹」是凭空添出来的。
  3. 人称。原文 *ahaṃ* 的 nissaya 是 `ငါ`，这是猎人的第一人称心语，译文改成了第三人称「他」。
- **建议**：改为「因为我最初看见足迹时，想到‘这可能是矮象的足迹’，所以没有下结论；之后在途中看见的足迹，也因为想到‘可能是卡拉里卡的，可能是卡涅卢卡的’，没有下结论。直到看见这头大象，他才下结论说：‘这一切都是这头大象的足迹。’」

## 父层疑问（不改本层，供上游参考）

- 164-1006-7-23「踩踏的痕迹也很深」、164-1007-8-30「很深的牙齿刮痕」：义注 §2179 把 *uccā* 解释为「高七八腕尺处」，*nisevitaṃ* 解释为在树干上磨蹭的地方。父层把 *uccā* 译成「很深」、把 *nisevitaṃ* 译成「踩踏」，与义注相悖。本层黑体受「与父层逐字相同」的约束只能照抄，造成黑体词与紧随其后的释文（高处、磨蹭）自相矛盾。建议父层改译后再同步本层。
- 164-1000-2-12 把 *kusalo nāgavaniko* 译为「熟练的猎象人」，164-1005-30-38 译为「善巧的象林猎人」，父层内部不一致，本层两处黑体只能分别照抄。
