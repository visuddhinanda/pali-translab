# Review — 130:2465-2472（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（130-2469-2-5 无 nissaya，略过）／父层对照 ✅（164:1238-1243, 1247, 1248；父层 1244-1246 未提供，故 Maṅguracchavī、Etāva paraman、Pitu sakkassa kammante…、Siyā nu kho…、Satānusāriviññāṇa、Yaṃ taṃ sukhan 等被解释词无从比对）

## 跨段一致性

- **被解释词与父层不一致（必改，逐条见下）**：mārisa（§2468 两处）、sīsaveṭhaṃ dadeyya（§2465）、halan’ti vadāmi（§2468）、paccupaṭṭhitā honti / bāhulliko / āvatto bāhullāya / nibbijja pakkamiṃsu（§2471）。
- **mārisa**：父层 1243 译“尊者”，本层 §2468 两处译“朋友” → 统一为“尊者”。
- **kammante**：§2469 被解释词译“劳作的时候”，§2469-62 译“劳作之地”，§2470 译“耕作之地”，§2470-166 引文又作“劳作的时候” → nissaya `ကမ္မန္တေ= လယ်ထွန် မင်္ဂလာ ပြုရာအရပ်၌` 是处格、指地点（举行耕种仪式的地方），统一为“耕作场（上）”。
- **pariveṇa**：§2465 漏译（“叶屋周围”），§2471 拆成“叶屋周围、庭院” → nissaya `ပရိဝုဏ်` 指叶屋所属的院落，统一为“叶屋的院子”。
- **pāṭihāriya**：§2470 两处译“神通现象” → nissaya `အံ့ဘွယ်သရဲ`（奇事），指树荫不移这件事，不是菩萨施展神通。统一为“奇迹”。
- **aṭṭhasata**：§2469-67 与 §2470-34 都译“一百零七具” → nissaya `အဋ္ဌသတံ= ရှစ်ရာ` 读作八百，`ဧကေန ဦနံ` 是少一，即七百九十九。两处要按同一读法统一（见下文具体条目）。
- **对国王的称呼**：§2466 和 §2467 前半用“您”，§2467-60 起改用“你”“你们” → tumhe / tumhākaṃ 是敬称复数，实指国王一人，统一为“您”。
- **vedanā**：父层译“苦受”“感受”，§2469-11 译“痛苦” → 改为“感受”，与父层同一体系。
- **ānāpānassatipaṭhamajjhāna**：§2470 三处都译“由出入息念所成的初禅”，内部一致；nissaya 作 `အာနာပါနလျှင်အာရုံရှိသော ပဌမဈာန်`（以出入息为所缘的初禅），可考虑统一改为“以出入息为所缘的初禅”。
- **段号体例**：§2465“378.”、§2468“379.”保留了段号，§2469 作“380—1。”（破折号加句号，与其他段不一），§2471“382.”、§2472“383.”漏掉了段号 → 统一保留，格式一律用“NNN.”。
- **文言残留（必改）**：“精勤修行之地”（§2466）、“稀有之事”（§2467）、“劳作之地 / 耕作之地”（§2469、§2470）、“初禅之乐”（§2470）、“围绕菩萨而坐”“就这件事而说”（§2470）。各处改法见下文。

## §2465 句 130-2465-16-27
- **问题**：被解释词／一致性 — 父层 1240 为“头部产生剧烈的头痛”，sīsavedanā honti 对应“产生……头痛”，中间隔着 adhimattā，所以“产生头痛”是可接受的抽取。但释文把同一个 honti 译成“生起”，前后不一。另外 nissaya `ဝါတေဟိ`（具格）`သမုဋ္ဌာပိတာ`（被引起的）表明头痛是“由风引起”的被动结构，现译把它拆成了因果两句。
- **建议**：“是指由无处可出的风所引起的猛烈头痛产生了。”

## §2465 句 130-2465-28-33
- **问题**：被解释词不符（必改）— 父层 1240 作“缠绕头部紧紧勒住”，本层译“紧勒头部”。另有格误：nissaya `သီသဝေဋ္ဌနံ= ဦးခေါင်း၌ ရစ်သည်ကို` 是宾格动名词（在头上的缠绕），`ဒဒေယျ= ပေးရာ၏` 是谓语，并没有“头带”这个工具。现译“用头带”把它误读成了具格工具。
- **建议**：“**缠绕头部紧紧勒住**”是指对头部加以缠绕。

## §2465 句 130-2465-34-42
- **问题**：漏译 — `ပဏ္ဏသာလပရိဝေဏသမန္တာ` 是叶屋院子的周围，现译漏了 pariveṇa。
- **建议**：“……住在菩萨经行道一端以及叶屋院子周围的天神。”

## §2466 句 130-2466-22-43
- **问题**：句法归属错（必改）— nissaya 的结构是：引出“vihārotveva so arahato”（他们所说的话），再接“arahanto nāma evarūpā honti matakasadisā”ti `လဒ္ဓိယာ`（具格，凭这种见解）`ဝဒန္တိ`。也就是说，他们说的是第一句，第二句是他们所持的见解。现译把第二句当成了他们说的话。第一句的措辞也宜贴近父层“阿罗汉就是有这样一种安住的状态”。
- **建议**：“‘这只是阿罗汉的一种安住状态’——他们是依‘阿罗汉就是这样，如同死人一般’的见解这么说的。”

## §2466 句 130-2466-69-77 / 78-85 / 86-96
- **问题**：补出成分 — nissaya 在这几句后分别补出 `ပုစ္ဆိ`（国王问）、`အာရောစေသုံ`（天神们回答）。现译三句直接相连，读者分不清谁在说话。§2466-78 的“精勤修行之地”是文言。
- **建议**：分别补“国王问：”“天神们说：”“国王说：”；“精勤修行之地”改为“精勤苦修的地方”。

## §2467 句 130-2467-41-44
- **问题**：补出成分 — nissaya 补 `ပုစ္ဆိ= မေးတော်မူ၏`（世尊问），现译没有标出说话人。
- **建议**：“世尊问：‘大王，您相信吗？’”

## §2467 句 130-2467-49-59
- **问题**：误译（必改）— `ကိံ သဒ္ဒဟိဿသိ= အဘယ်မှာ ယုံကြည်လတ္တံ့နည်း` 是“怎么会相信呢”，反诘的意思是不会相信（我已死）。现译“您还会不相信什么呢”把意思译反了。“稀有之事”是文言。
- **建议**：“大王，如今您从得梦那时起，一路看到种种稀有的事，又怎么会相信呢？”

## §2467 句 130-2467-60-121
- **问题**：
  - 句法归属（必改）：nissaya 的 `မဟာရာဇ ... အဝေါစုတ္ထ ... ဣတိ` 表明 mahārāja 是世尊话语里的呼格。现译把“大王”放进了叙述句“大王，正是依这段因缘，世尊说了……”，变成叙述者在称呼国王。
  - 称谓：通篇“你”“你们”应作“您”（见跨段一致性）。
- **建议**：“……那时您也说：‘我的儿子不会中途死亡，我不相信。’大王。”——正是依这段因缘，世尊讲了大法护本生。

## §2468 句 130-2468-2-14
- **问题**：被解释词不符（必改）— 父层 1243 作“尊者，请不要”，本层译“朋友啊，请不要这样”。另外 nissaya 补出宾语 `မံ`（对我）。
- **建议**：“**尊者，请不要**”，是天神们怀着亲爱对我说的。

## §2468 句 130-2468-15-21
- **问题**：随上条，“朋友”必须改为“尊者”，否则释文和被解释词就对不上了。
- **建议**：“据说‘尊者’（mārisa）这个称呼，是天神们表示亲爱、悦意的说法。”（“尊者”偏敬称，与“亲爱”的释义有张力，但父层已定，从父层。）

## §2468 句 130-2468-26-42
- **问题**：
  - 被解释词不符（必改）：父层 1243 作“说：‘够了。’”，本层译“我说：够了”。
  - 漏译：`ဣမိနာ= ဤအာဟာရဖြင့်`（这种营养）没有译出，“alaṃ iminā”只译了“够了”。
  - 原文疑问：nissaya 读作 `နယာပေဿာမိ`（我不维持），与 pali yāpessām’ahaṃ（我会维持）不同，这里按 pali 译，不改。
- **建议**：“**说：‘够了’**”是指我说“够了”，意思是：这种营养就不必了，不要这样做，我自己会维持生命——就这样加以拒绝。

## §2469 句 130-2469-6-10
- **问题**：取义参考 — nissaya `ပြောက်သောအရေပါးရှိသည်` 释为“皮肤有斑驳的”，与“灰白色皮肤”取义不同。父层 1245 未提供，无法比对。
- **建议**：先查父层 1245 的译法，被解释词照搬父层；释文可作“皮肤像满古罗鱼那样斑驳”。

## §2469 句 130-2469-11-20
- **问题**：漏译与术语 — tāsampi 的“也”没有译出；vedanā 译作“痛苦”，与父层的“受”系统不一。
- **建议**：“是指就连那些感受，这也就是它们的极限、最高的程度。”

## §2469 句 130-2469-21-43（及 130-2470-166-180 同句引文）
- **问题**：格误（必改）— `ကမ္မန္တေ` 是处格、指地点，现译“劳作的时候”误作时间；sakka 与 pitu 同位，指“释迦人”，不是“释迦族”。父层 1246 未提供，需要另行核对。
- **建议**：“**在父亲释迦人的耕作场上……乃至……进入并住于初禅**”，两处同改。

## §2469 句 130-2469-62-66
- **问题**：主宾误读（必改）— `ရညော= မင်း၏` 是属格（国王的），`ယောဇီယတိ= ကအပ်၏` 是被动；现译把国王当成了施事者。“之地”是文言。
- **建议**：“在国王的耕作场上，要套上十万具犁。”

## §2469 句 130-2469-67-74
- **问题**：数目（必改）— nissaya `အဋ္ဌသတံ= ရှစ်ရာ`，`ဧကေန ဦနံ` 为“少一”，合计七百九十九；现译作一百零七。“少了一具”还容易被读成比平常少一具。
- **建议**：“但那一天，他们套上的是八百少一具，也就是七百九十九具犁。”（若定案取 aṭṭhasata＝108，则须在报告中注明与 nissaya 的分歧，并与 §2470-34 同步。）

## §2469 句 130-2469-75-83
- **问题**：句法误读 — `ဗလီဗဒ္ဒရသ္မိယောတ္တေဟိ= နွားလား ဆွဲကြိုးတို့နှင့် သဒ္ဓိံ` 是“连同公牛的缰绳、挽绳”。现译“用公牛缰绳系着的挽具”多出了“系着”的关系。另外 `ရစ်အပ်` 是“包裹”，“镶嵌”略有偏差（§2469-84、89 同）。
- **建议**：“所有的犁，连同公牛的缰绳和挽绳，都像阇纳孙尼的车子那样包着银片。”

## §2470 句 130-2470-34-41
- **问题**：
  - 误译：`ဣတောစိတောစ= ထိုမှ ဤမှလည်း` 是“这里那里”，现译“从这边到那边”与下句国王的 orato pāraṃ 混同了。
  - 数目：随 §2469-67 统一。
  - 原文疑问：nissaya 多出“农夫拿其余的犁”一段，pali 原文没有，记下，不补译。
- **建议**：“大臣们拿起七百九十九具银犁，在各处耕作。”

## §2470 句 130-2470-69-85
- **问题**：增译 — `အာနာပါနေ= ထွက်သက် ဝင်သက်တို့ကို` 是宾格的“出入息”本身，现译“摄持出入息念”多加了“念”字。
- **建议**：“……结跏趺坐，把握住出入息，生起了初禅。”

## §2470 句 130-2470-86-103
- **问题**：漏译 — `ဝိစရမာနာ= ထိုမှ ဤမှ သွားလာကုန်သည်` 指在吃食之间走来走去，现译漏了这个动作。
- **建议**：“保姆们在各种嚼食、主食之间走来走去，耽搁了一会儿……”

## §2470 句 130-2470-104-122 / 142-161
- **问题**：取词 — `ထိုသပြေပင်ရိပ်၏မပြန်နစ်ခြင်းတည်းဟူသောအံ့ဘွယ်သရဲ` 明确说是“树荫不移这件奇事”，“神通现象”取词不当。
- **建议**：两处都改为“奇迹”（“那个奇迹”）。

## §2470 句 130-2470-162-165
- **问题**：文言 — “就这件事而说”的“而”是文言虚词。
- **建议**：“这句话正是就这件事说的——”

## §2470 句 130-2470-196-216
- **问题**：语气误译（必改）— `နဘဝိဿတိ= မဖြစ်လတ္တံ့` 是“将不会是”，现译“未必就是”把语气弱化了。另外 viññāṇa 译“觉知”不合通行术语“识”，可考虑改为“随念识”（被解释词须与父层 1246 同步核对）。
- **建议**：“……这不会是通向觉悟的道路，以出入息为所缘的初禅才会是——像这样，在一两次生起正念之后紧接着生起的识，就叫作随念识。”

## §2470 句 130-2470-217-224
- **问题**：文言 — “初禅之乐”。
- **建议**：“初禅的快乐”。

## §2471 句 130-2471-2-12
- **问题**：
  - 被解释词不符（必改）：父层 1247 作“在服侍”，本层译“已准备好”。
  - 误译：释文 `ဥပဋ္ဌိတာ` 即“服侍”，现译“来做好侍奉准备”偏离了原意；pariveṇa 被拆成两项（见跨段一致性）。
  - 段号“382.”漏掉。
- **建议**：382. “**在服侍**”是指以打扫叶屋院子等日常事务来服侍。

## §2471 句 130-2471-13-16
- **问题**：被解释词不符（必改）— 父层作“生活奢侈”，本层译“耽于丰厚供养的人”。nissaya 释 paccayabāhulliko 为“追求四种资具丰厚”。
- **建议**：“**生活奢侈**”是指在资具上追求丰厚。

## §2471 句 130-2471-17-25
- **问题**：被解释词不符（必改）— 父层作“退转到奢侈的生活中”，本层译“转向丰厚”；释文中的 āvatto 也要随之改为“退转”。
- **建议**：“**退转到奢侈的生活中**”是指贪着滋味，为了精美的钵食等而退转。

## §2471 句 130-2471-26-39
- **问题**：
  - 被解释词不符（必改）：父层作“心生厌离地离开了”，本层译“厌离而离去”（还带文言“而”）。
  - 时间误读：`ပတ္တကာလ`（临近证得的时候）被译成了“证得正觉的时候”。
- **建议**：“**心生厌离地离开了**”是指他们心生厌倦，依循法则离开了——这是为了在菩萨将证正觉的时候，给他身远离的机会，按法性自然发生的。

## §2471 句 130-2471-47-58
- **问题**：取词 — `ဗောဓိမဏ္ဍေ` 是菩提道场，现译“菩提座上的不败座上”重复且不通顺。
- **建议**：“……坐在菩提道场的不败宝座上，证悟了一切知智。”

## §2472 句 130-2472-2-12
- **问题**：段号“383.”漏掉。被解释词“远离欲望”与父层 1248 一致，无误。
- **建议**：补回“383.”。
