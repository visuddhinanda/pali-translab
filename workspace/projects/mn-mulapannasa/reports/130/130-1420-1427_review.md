# Review — 130:1420-1427（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1427-2-6、1427-53-56 两句无 nissaya，略过）

## 被解释词核查

- 本 chunk 的黑体词（vatthuvisadakiriyatā / indriyasamattapaṭipādanatā / nimittakusalatā / samaye cittassa paggahaṇatā 等）都**不出自父层**（164:340-349）。它们引自本层 §1422 的十一法列表。父层没有逐字对应要求，所以改为核对黑体词与 §1422 列表是否逐字一致：**全部一致**。
- 下面若干条建议会改动黑体词的译法（使根据地清净 / 使诸根均等地趣入 / 远离心不寂静的人 / 亲近心寂静的人）。改的时候**必须连同 §1422 列表一起改**，否则对应关系会断。

## 跨段一致性

- **kammassakatāpaccavekkhaṇa**：§1420 句 130-1420-43-54 译“省察自己和他人都是各自业的所有者”，§1427 句 130-1427-7-52 译“省察业为自己所有”。建议统一为“省察业为自己所有”。依据：nissaya 两处同作 `ကံသာလျှင် မိမိတို့၏ ဥစ္စာရှိသည်၏`（唯有业是自己的所有物）。
- **satta**：§1426、§1427 通篇作“众生”，唯独 nissattapaccavekkhaṇa 译“省察无有情”。建议改为“省察并无众生”，与上下文统一。
- **iriyāpatha / ṭhāna-nisajja-ādi**：§1420 句 2-19 作“站立等威仪”。§1420 句 61-75 与 §1424 句 63-68 作“站立坐卧等姿势”，“坐卧”和“姿势”都是增补，原文只有 ṭhāna、nisajjā 加 ādi。nissaya 作 `ရပ်ခြင်း ထိုင်ခြင်း အစရှိသည်`（站、坐等）。建议统一为“站、坐等威仪”或“站、坐等”。
- **“…之时”文言句式**：§1423 句 7-23、24-41、42-59 与 §1424 句 2-26 都用“在……之时”。这是 `style.md` 禁例里的“当…之时”。统一改为“在……的时候”。§1424 句 2-26 还有“之时，那时”的重复，应删去其一。
- **“之”作文言虚词**：多处出现，如“心散乱之人”“舍觉支之处”“无主之性”“恶趣之苦”“寂静之乐”。前三处必改为现代说法，详见各句；后两处属习惯搭配，可保留。

## §1420 句 130-1420-2-19
- **问题**：风格 / 词法。
  - “食用”属于禁用的单音节文言词组。
  - “于站立等威仪里”的“于”是文言虚词。
  - `sītuṇhesu utūsu` 的 nissaya 是 `အချမ်းအပူဟု ဆိုအပ်ကုန်သော ဥတု`，意思是“称为冷与热的气候”，只有冷、热两项，译文“寒热等”多出了“等”。
  - sevati 译“采用”不贴切，nissaya `မှီဝဲသော` 意为依从、受用。
- **建议**：因为吃精美、滋润、适宜的食物的人，以及在冷、热两种气候中、在站立等威仪中受用适宜的气候与威仪的人，都会生起轻安。

## §1420 句 130-1420-20-30
- **问题**：误译。mahāpurisajātiko 的 nissaya 是 `ကြီးမြတ်တော်မူသော ဘုရားကဲ့သို့ ဖြစ်ခြင်းသဘောရှိ၏`（具有如伟大的佛陀那样的本性），指禀性，**不是“大人相”**（三十二相）。`-kkhamova` 的 `ova`（`သည်သာလျှင်`）表强调，译文没有体现。
- **建议**：但如果有人天生具有大丈夫的禀性，能够忍受一切气候、一切威仪，这段话就不是针对他说的。

## §1420 句 130-1420-31-42
- **问题**：漏译。`tasseva` 的 nissaya 是 `ထိုပုဂ္ဂိုလ်အားသာလျှင်`（只有对这种人）。限定词 eva 漏译，句意变成了泛指。
- **建议**：气候与威仪对谁有相合、不相合之分，只有这样的人避开不相合的气候与威仪、受用相合的，也会生起轻安。

## §1420 句 130-1420-61-75
- **问题**：词义。sāraddhakāya 的 nissaya 是 `ပူပန်သော ကိုယ်`（焦躁不安的身体），“粗暴”偏离原义。“站立坐卧等姿势”的问题见跨段一致性。
- **建议**：“身体躁动不安的人”；“在站、坐等威仪中”。

## §1422 句 130-1422-2-26（连带黑体词 §1422 句 27-34）
- **问题**：词义。
  - vatthu 的 nissaya 是 `စိတ်စေတသိက်တို့၏ ဖြစ်ရာ ခန္ဓာကိုယ်… သင်္ကန်းအစရှိသော အတွင်းအပဝတ္ထု`，指心与心所所依的身体，以及袈裟等内外事物。“根据地”是现代军事/政治用语，会误导读者。
  - indriyasamattapaṭipādanatā 的 nissaya 是 `ဣန္ဒြေတို့၏ မျှသည်၏ အဖြစ်ကို ပြီးစေခြင်း`（使诸根达成平衡），“均等地趣入”把 paṭipādana 误读成了“趣入”。
- **建议**：“使所依事物清净”“使诸根平衡”。§1422 列表与句 27-34 的黑体两处同步修改。

## §1423 句 130-1423-7-23
- **问题**：词法 + 原文疑问。
  - `atisithilavīriyatādīhi` 的 nissaya 是 `အလွန်လျော့်သော လုံ့လရှိသည်၏ အဖြစ်`（精进过于松弛的状态）。“过度松懈精进”读起来像动宾结构。
  - pali 作 `dhammavicayavīriyasambojjhaṅga`，只有两支；nissaya 作 `ဓမ္မဝိစယဝီရိယပီတိဗောဇ္ဈင်္ဂ`，多出喜觉支，共三支。抑制心一句也是三支并列，pali 这里疑有脱文。
- **建议**：改作“因为精进过于松懈等原因而使心退缩的时候”。是否补“喜觉支”，请定稿时核对其他版本。暂按 pali 译出的话，压低该句 confidence。

## §1423 句 130-1423-42-59
- **问题**：词义补充。upasamasukha 的 nissaya 是 `နိဗ္ဗာန်ချမ်းသာ`（涅槃之乐）。“寂静之乐”可以保留，但读者不易看出所指。
- **建议**：可译作“寂静（涅槃）之乐”。

## §1424 句 130-1424-2-26
- **问题**：词法。
  - `byāpāraṃ na āpajjati` 的 nissaya 是 `ကြောင့်ကြအားထုတ်ခြင်းသို့ မရောက်`（不陷入操心费力），“不加以运用”不准确。
  - `assa`（`ထို…စိတ်ကို`，对那颗心）是动作对象，译文没有交代。
  - `ārammaṇe samappavattaṃ` 的 nissaya 是 `အာရုံ၌ အညီအမျှဖြစ်သည်`（在所缘上平衡运转），“趣向”不准确。
  - “之时，那时”重复。
- **建议**：……心依靠正确的修行而不退缩、不掉举、不乏味，在所缘上平稳运转，走上止的道路，这时就不再费心去策励、抑制、激励这颗心，就像驭者对平稳前进的（马匹不加干预一样）。

## §1424 句 130-1424-39-50 / 51-62（连带 §1422 列表）
- **问题**：词义 / 风格。
  - asamāhita 的 nissaya 是 `မတည်ကြည်သော`（不安定、不专注）；samāhitacitta 的 nissaya 是 `ကောင်းစွာ အာရုံ၌ထားအပ်သော စိတ်`（心善置于所缘）。两者指“得定与否”，译“寂静”不对应，寂静另有 santa / upasama。
  - “心散乱之人”中的“之人”是文言写法。
- **建议**：“远离心未得定的人”“亲近心已得定的人”。正文中改为“心散乱的人”“以近行定或安止定而心已得定的人”。§1422 列表与两处黑体同步修改。

## §1424 句 130-1424-69-73
- **问题**：风格 / 指代。“便”是禁用的文言虚词。esa 的 nissaya 是 `ဤသမာဓိသမ္ဗောဇ္ဈင်`（这定觉支），译“它”指代不明。
- **建议**：这样修行，这定觉支就会生起。

## §1425 句 130-1425-4-46 / 47-52
- **问题**：词义 / 风格。ṭhānīya 的 nissaya 是 `တည်ရာအကြောင်းဖြစ်ကုန်သော`（作为立足之因的），“之处”既不达义，又带文言色彩。
- **建议**：两处统一为“能作为舍觉支基础的诸法”。

## §1427 句 130-1427-7-52
- **问题**：词法。
  - 第二个 `kaṃ` 的 nissaya 是 `အဘယ်သဘောတရားကို`（什么法），不是人。前文已说“根本没有众生”，所以这里不能再译“谁”。
  - “无有情”的问题见跨段一致性。
- **建议**：……“从胜义上说，根本没有众生，那么你贪着的是什么呢？”；“省察并无众生”。

## §1427 句 130-1427-57-100
- **问题**：格位误读 / 风格。
  - `yaṭṭhikoṭiyā` 是具格，nissaya 是 `တောင်ဝှေးစွန်းဖြင့်`（用杖端），表工具，译文“丢弃在木棍尖端”误读为处所。
  - “无主之性”是文言写法。
- **建议**：……最后变成擦脚布，被人用木杖的尖端挑起丢掉……；“省察它没有主人”。

## §1427 句 130-1427-101-109
- **问题**：风格。“如同对袈裟这样”语序别扭。yojanā 的 nissaya 是 `ယှဉ်ခြင်း`（配合、套用）。
- **建议**：就像对袈裟那样，对钵等也应同样套用。
