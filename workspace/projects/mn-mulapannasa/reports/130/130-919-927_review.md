# Review — 130:919-927（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核，并核对父层 164:226-231 的被解释词）

## 被解释词与父层逐字核对（必改项）

- **§923 `seyyathāpī`**：本段注的是父层 §229（86.），父层译作“**比如说**”，本层作“**比如**” → 改为“**比如说**”。§921 注的是 §227，父层作“比如”，与本层一致，不改。
- **§925 `so vata cundā`**：本层作“**他**，**准陀啊，确实**”。父层 §230 作“纯陀，一个自己深陷泥沼的人……”，其中没有“他”“确实”，人名也是“纯陀”。→ 改为“**纯陀，一个……的人**”，按父层语序引出。
- **§925 `so`（句 130-925-20-25）**：父层与 `so` 对应的是“一个……的人”，没有“他” → 改为“**一个……的人**”。
- **§925 `palipapalipanno`**：本层作“**陷入泥沼**”，父层作“深陷泥沼” → 改为“**深陷泥沼**”。
- **§925 `palipanno`**：本层作“**陷入的**”，父层没有这个说法；父层“深陷泥沼”中与 palipanno 对应的是“深陷” → 改为“**深陷**”。`palipaṃ`“**泥沼**”与父层一致，保留。
- **§927 `adanto avinīto aparinibbuto`**：本层作“**未调伏**、**未训练**、**未证得寂灭**”，父层 §230 作“未经调伏、未受训导、未得清净” → 三处改为“**未经调伏**、**未受训导**、**未得清净**”。同段后面单独引出的 `adanto` / `avinīto` / `aparinibbuto` 也要逐一照改。
  - 附注：父层把 `parinibbuto` 译作“清净”，同经 `parinibbānāya` 却译作“寂灭”，父层内部不一致。本层只能照父层，这一分歧留给 harmonize 处理。

## 跨段一致性

- **cunda**：§920 作“纯陀”（与父层同），§922、§924、§925 作“准陀” → 全部统一为“纯陀”。
- **adhobhāgaṅgamanīya / uparibhāgaṅgamanīya**：§923 作“通向上分”，§924 作“通向下分”“通向上分”，父层 §229 作“导向下分 / 导向上分” → 统一为“导向”。§924 句末引的 `uparibhāgāya` 也要按父层改作“导向上分”。
- **vihiṃsā / vihiṃsaka**：§922 作“害 / 害人的人 / 不害”，§924 作“加害 / 加害者 / 不加害”。两段注的都是 §227、§229，父层这两段用的是“害人的人 / 不害” → 统一为“害人的人 / 害 / 不害”。
- **palipa / palipapalipanna**：§925 作“泥沼 / 陷入泥沼”，§926 作“烂泥” → 统一为“泥沼 / 深陷泥沼”，与父层一致。
- **uddharati**：§925 作“拔出”，§926 作“拉拔”，父层作“拉出来” → 统一为“拉出来”。
- **puthujjana**：§925 作“凡夫”，§926 作“普通人” → 统一为“凡夫”。
- **parinibbāpana**：§925 作“般涅槃”，§927 作“寂灭”，父层 §230 作“寂灭 / 清净” → §925 改为“寂灭”。
- **sukkapakkha**：§926 与 §927 都作“善的一面”，两处一致，但句法有误（见 §926 句 130-926-145-148）。

## §919 句 130-919-2-33
- **问题**：风格 — “其本身”中的“其”是文言虚词。另外整句由逗号连成一长串，`evañhi` 引出的“正因为这样生起了心念……”是一个新的论证层次，不该用逗号接在前一句后面。
- **建议**：改作“它本身”；在“原因”后用句号断开，下句作“正是因为这样生起了心念，后来……”。

## §920 句 130-920-2-20
- **问题**：词法与风格 — nissaya `တတ္ထ= ထိုကုသိုလ်တရားတို့၌`（在那些善法中），`niyojento`（策励、敦促）。译文“策励于此”用了文言“于此”，指代也不清楚。
- **建议**：改作“现在为了勉励人们投入这些善法，说了‘因此，纯陀’等语。”

## §921 句 130-921-2-22
- **问题**：格的误读 — `dassite sallekhe` 是处格（nissaya `သလ္လေခ၌`），意思是“在已用四十四种方式开示的净除这件事上”，它限定的是 `cittuppādassāpi bahūpakārataṃ`。译文拆成“开示了净除之后，又开示了心念……”两个先后动作，结构错了。`hitādhigamāya maggabhāvaṃ`：nissaya 释 `maggabhāvaṃ` 为“作为原因的状态”，`adhigama` 是“获得”，“利益成就”有歧义。
- **建议**：改作“这样开示了对以四十四种方式所说的净除，即使只是生起心念也大有助益之后，现在为了开示这净除本身是获得利益的途径，说了‘**比如**’等语。”

## §922 句 130-922-2-70
- **问题 1**：漏译 — `suparikammakato viya bhūmibhāgo`，nissaya 释作“像妥善平整过的地面那样的”，`viya` 没有译出，比喻被译成了事实。
- **问题 2**：误译 — `yaṃ paṭipanno`，nissaya 释作 `ယံတိတ္ထံ ... ဆင်းသက်သောသူ`（下到那个渡口的人），指的是渡口，译文作“走这条路的人”。
- **问题 3**：漏译 — `nhāyeyya vā uttareyya vā`，nissaya 释作“或沐浴、或上来”，“沐浴”漏了；`ajjhogāhetvā`（下到水里）被并进了“涉入或渡过”。
- **问题 4**：误加成分 — `samamaggasamatitthasadisā avihiṃsā`，nissaya 只有 `နှင့်တူသော`（如同），没有“具有”。另外“害的害人的人”读起来很别扭。
- **建议**：
  - 改作“另有一条像精心平整过的地面那样平坦的路”。
  - 改作“下到这个渡口的人，能轻松地进入那条河或那个池塘，沐浴或者上岸”。
  - 末句改作“同样，纯陀，对一个具有如同崎岖之路、崎岖渡口的害的人（害人的人）来说，如同平坦之路、平坦渡口的不害是用来回避它的。”
  - `papāta` 用“陡岸”比“悬崖”更贴近 nissaya `ကမ်းပါးပြတ်`。

## §922 句 130-922-71-99
- **问题**：词法 — `manussagatiṃ vā devagatiṃ vā`，gati 是“趣”，“人间的生处”不准确；`sampattiṃ`，nissaya 释作“人的安乐、天的安乐”。
- **建议**：改作“进入人趣或天趣，享受（人天的）富乐，或者超出世间。”

## §923 句 130-923-2-17
- **问题**：被解释词与术语（见上两节）。
- **建议**：改作“这样开示了这净除本身是获得利益的途径以后，现在为了开示它导向上分，说了‘**比如说**’等语。”

## §924 句 130-924-2-35
- **问题 1**：词法 — `dinnāyapi paṭisandhiyā vipākajanakā vā ajanakā vā`，nissaya 释作 `ပေးပြီး / မပေးသေး`，即“已生果报 / 尚未生果报”，是已然与未然的对立。译文作“能生 / 不能生”，与前半句的“能生结生 / 不能生结生”混同了。
- **问题 2**：误译 — `jātivasena`，nissaya 释作 `အကုသိုလ်ဇာတ်၏အစွမ်းအားဖြင့်`（就不善这一类别而言），jāti 指类别、性质，不是“生起”。
- **建议**：改作“即使已经给出结生，无论是已生果报还是尚未生果报的，所有这些就其不善的性质而言都称为‘导向下分’”。

## §924 句 130-924-36-75
- **问题**：同上一句的 `vipākajanakā / ajanakā` 与 `jātivasena` 两处，另有跨段术语问题。
- **建议**：照上一句的改法改；末句改作“同样，纯陀，对一个害人的人来说……乃至……是导向上分的。”

## §924 句 130-924-76-89 / 130-924-90-100
- **问题**：词法 — `ekā vihiṃsāpi`：`ekā` 强调“单单这一项”，指四十四项中的一项，“一种加害”容易被读成“一种类型”。“也是这样”省掉了谓语，nissaya 补出了“导向下分（四恶趣）”。
- **建议**：改作“哪怕只是害这一项，也是导向下分的”。§924 句 130-924-90-100 照此对称改。

## §924 句 130-924-101-112
- **问题**：词法 — `kira`，nissaya 用 `သတတ်`（据说、传闻语气），不是揣测；“大概”译错了语气。
- **建议**：改作“据说这里的用意就是这样。”

## §925 句 130-925-2-19
- **问题**：被解释词与术语（见上两节）。另外 `parinibbāpane samatthabhāvaṃ`，nissaya 释作“能使一切烦恼的热恼止息”。
- **建议**：改作“现在为了开示它有使人寂灭的能力，说了‘**纯陀，一个……的人**’等语。”

## §925 句 130-925-26-47
- **问题 1**：误译 — `tassa yoti imaṃ uddesavacanaṃ āharitvā`，nissaya 释作“为那个 `so` 补上 `yo` 这个起首词”。`uddesavacana` 指的是 `yo`（“凡是……的人”）。译文作“把这个指示句‘他……的’取来”，弄反了。
- **问题 2**：漏补成分 — nissaya 补出了 `ဧတံဌာနံ နဝိဇ္ဇတိ`（这是不可能的）。译文只说“确实能够拔出”，读起来像正面断言。
- **问题 3**：句末“应当这样理解”与前文“应当……理解为”重复。
- **建议**：改作“为‘一个……的人’（so）补上‘凡是’（yo）这个起首词，在所有语句中都应当这样理解它们的连接：凡是自己深陷泥沼的人，纯陀，这个人能把另一个深陷泥沼的人拉出来，这是不可能的。”

## §925 句 130-925-80-131
- **问题**：只有跨段用语问题（准陀、拔出），句法与 nissaya 相符。
- **建议**：“准陀”改“纯陀”，“拔出来”改“拉出来”，“陷入”改“深陷”。

## §926 句 130-926-2-22
- **问题 1**：格的误读 — `puthujjanānampi bhikkhu…upāsikānaṃ` 是属格，依附于 `dhammadesanaṃ`（nissaya `…တို့၏ ဓမ္မဒေသနံ`），意思是“听了身为凡夫的比丘……所作的说法”。译文把他们当成了听法的人。
- **问题 2**：句法 — `siyā ayuttametaṃ … tasmā palipapalipanno uddharatīti` 是反方意见，`taṃ na tathā daṭṭhabbaṃ` 是答辩。译文漏了 `ayuttam`，又把答辩并进了疑问里，读者分不清哪句是谁的立场。
- **建议**：改作“这里也许有人会说：‘这个说法不对。因为听了凡夫比丘、比丘尼、优婆塞、优婆夷说法后，确实有人通达法，所以深陷泥沼的人也能把人拉出来。’——不应当这样看。”“普通人”改为“凡夫”，“烂泥”改为“泥沼”。

## §926 句 130-926-23-35
- **问题**：词法 — `raññā pahitalekhavācako`，nissaya 释作“读国王派送的文书的人”，“替国王宣读”多出了“替”的意思。
- **建议**：改作“就像宣读国王所送书信的人一样”；“拉拔”改作“拉出来”。

## §926 句 130-926-79-106 / 130-926-127-141
- **问题**：句法 — 引号内是称赞的内容（nissaya `ဣတိ … ပသံသာမတ္တမေဝ`），不是受称赞的原因。
- **建议**：改作“读信的人只得到‘他念得口齿清楚、流利’这样的称赞而已”；130-926-127-141 照此改作“说法者只得到‘他们说法口齿清楚、流利’这样的称赞而已”。

## §926 句 130-926-145-148（§927 句 130-927-44-47 同）
- **问题**：格的误读 — `vuttavipariyāyena` 是具格，表示方式（nissaya `ပြန်သောအားဖြင့်`，“按相反的方式”），不是“与所说相反的”这个主语。
- **建议**：改作“白的一面（sukkapakkha）应当按与上面所说相反的方式来理解。”

## §927 句 130-927-2-11
- **问题**：词法 — `anibbisatāya`，nissaya 释作“贪等烦恼的毒还没有排出”，nibbisa 是“无毒”。“未曾平息（烦恼）”没有译出毒的比喻。
- **建议**：改作“由于（贪等烦恼的）毒还没有排除，所以是‘**未经调伏**’。”

## §927 句 130-927-12-14
- **问题**：词法 — `asikkhitavinayatāya`，nissaya 指“律仪调伏等五种调伏（vinaya）没有修学”，“律仪”把范围译窄了；被解释词也要照父层改。
- **建议**：改作“由于没有修学（五种）调伏，所以是‘**未受训导**’。”

## §927 句 130-927-20-43
- **问题 1**：词法 — `nibbisaṃ karissati`，nissaya 释作“使人没有烦恼之毒”，译文作“平息他人（的烦恼）”。
- **问题 2**：词法 — `tisso sikkhā sikkhāpessati` 是使役，意思是“使人修学三学”，译文作“教导他人三学”。
- **问题 3**：动词要与父层 `damessati vinessati parinibbāpessati`（调伏、训导、清净）对应。
- **建议**：改作“这样的人能调伏他人、使他人去除（烦恼的）毒，或者训导他人、使他人修学三学，或者使他人清净、止息他的烦恼——这是不可能的。”
