# Review — 130:1060-1074（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 被解释词与父层（164）对照

- **§1062 句 130-1062-2-18**：黑体「**以四大种为所依**」与父层 164-267-99-111「四大种**所造**之色」不一致 → **必改**，改为「**四大种所造**」。
- **§1062 句 130-1062-19-25**：黑体「**为所依**」与父层「所造」不一致 → **必改**，改为「**所造**」。（父层以「所造」译 upādāya，本层随后用 upādiyitvā / gahetvā 释其词义；两层的取义张力留给 harmonize 处理。本层的黑体词只能跟父层走。）
- **§1071 句 130-1071-2-16**：「于**苦**无知」与父层 164-273-83-105「对苦的无知」不一致。另外 pali 中 dukkhe 与 aññāṇan 都是黑体，译文只标了一个 → **必改**，改为「对**苦**的**无知**」。
- **§1071 句 130-1071-17-22**：「于**集**无知」与父层「对苦集的无知」不一致 → **必改**，改为「对**集**的**无知**」等。
- **§1073 句 130-1073-2-13**：「于**苦**」→ **必改**，按父层改为「对**苦**」。
- **§1073 句 130-1073-14-22**：「于**苦的集**」与父层「对苦集」不一致 → **必改**，改为「对**苦集**」。
- **§1073 句 130-1073-23-29**：「于**苦的灭**」「于**导向苦灭的道路**」与父层「对苦灭」「对导向苦灭之道」不一致 → **必改**，改为「对**苦灭**」「对**导向苦灭之道**」。
- **§1073 句 130-1073-39-48**：「由**漏之集**」与父层 164-273-106-126「由**诸**漏之集」不一致，缺「诸」 → **必改**，改为「由**诸漏之集**」。
- **黑体缺失**：以下句子的 pali 有黑体，译文漏标，应补黑体：
  - 130-1068-2-9：**行**
  - 130-1068-10-30：**身行**
  - 130-1068-31-43：**语行**
  - 130-1068-44-59：**心行**
  - 130-1068-60-71：**由无明之集**（字面与父层 164-271-98-118 一致）
- **黑体多标**：130-1065-31-47 的后半句「由**行之集**而有**识之集**」，pali 这里不是黑体，只是普通释文 → 去掉这两处黑体。

## 跨段一致性

- **vāra**：§1060/1061 译「分」，§1064/1065 译「分品」「分」，§1067/1068 译「组」，§1070/1071 译「门」 → 统一为「分」（名色分、识分、行分、无明分）。
- **vitthāravāra**：§1061 译「详释分」，§1068 译「详释组」 → 统一为「详释分」。
- **vaṇṇanā（品题）**：「释义」/「解说」/「解释」三种并用，§1067、1069 还加了书名号 → 统一为「××分释义」，不加书名号。
- **adhivacana**：§1061 译「别名」，§1065 译「称呼」，§1068 译「同义语」，§1071 译「同义词」 → 统一为「名称」或「别名」。
- **lakkhaṇa**：§1061 译「以……为特相」，§1068 译「的相是」 → 统一句式为「以造作为特相的是**行**」，与名、色两句平行。
- **Sesaṃ vuttanayamevāti**（§1062、1065、1068、1073）：四处四种译法 → 统一为「其余的与前面所说的方法相同。」
- **段号**：§1061 写「一百、」，后面各段写「一〇一、」等 → 统一为「一〇〇、」。
- **antogadhato / saṅgahato**：§1071 的 antogadhato 与 §1073 的 saṅgahato 都译「摄属」。nissaya 分别作 အတွင်းဝင် 与 ပေါင်းရုံး，可考虑把后者区分为「摄」，至少要在报告里知会。

## §1061 句 130-1061-13-18
- **问题**：漏译 — `အဿ= ထိုနာမ်ရုပ်၏`，assa 是属格「它（名色）的」，译文没有译出。
- **建议**：「而在它的详释分中，……」

## §1061 句 130-1061-30-43
- **问题**：句法 — sabbadubbalesupi cittesu 意为「即使在最弱的心中也」。nissaya 作 `အလုံးစုံသောစိတ်တို့အောက်အားနည်းကုန်သော… ပဉ္စဝိညာဉ်စိတ်တို့၌လည်း`，指双五识。「一切乃至最微弱的心中」语序拗口。
- **建议**：「但这三种连所有心中最弱的心（双五识）里也都有。」

## §1061 句 130-1061-65-82
- **问题**：用词 — vinicchayanaya 是 `အဆုံးအဖြတ်ဖြစ်သောနည်း`（判定、抉择的方法），不是「解释方式」；ettha 指那四种色（`ထိုလေးပါးသောရုပ်တို့၌`）。
- **建议**：「以及关于这四大种的其他抉择方法」。

## §1062 句 130-1062-19-25
- **问题**：词义 — nissaya `ဥပါဒိယိတွာ= မဟာဘုတ်တို့ကိုပစ္စည်းပြု၍`（以大种为缘），`ဂဟေတွာ= စွဲ၍`（依靠）。「取着、执取」带有 upādāna 的贬义，误导读者。
- **建议**：「“**所造**”，意思是依取、依凭。」

## §1062 句 130-1062-48-75
- **问题**：漏译 — sabbatthāpi（各处、一切情形）没有译出，abhidhammapāḷiyameva 的 eva（正是）也没有译出。
- **建议**：「如此，在各处都应知……正是在论藏巴利中以眼处等类别所说的……」

## §1065 句 130-1065-21-26
- **问题**：误读 — itaraṃ 指「另一个（五识以外的识）」，nissaya 作 `ဤပဉ္စဝိညာဉ်မှတစ်ပါးသောမနောဝိညာဉ်`。译文作「其余的情况」，误解了指代。
- **建议**：「而另一种，意本身就是识，所以称为“**意识**”。」

## §1068 句 130-1068-10-30 / 130-1068-31-43 / 130-1068-44-59
- **问题**：主谓颠倒 — nissaya `ဧတံ= ဤကာယသင်္ခါရဟူသောအမည်သည် … ကာယသဉ္စေတနာတို့၏ အဓိဝစနံ= အမည်တည်း`：etaṃ 是「身行」这一名称，属格才是二十种身思。译文「……二十种身思，这是它的同义语」把指代弄反了。
- **建议**：改为「……这是对二十种身思的称呼」，另两句（语思、意思）同样改。
- **问题（30-43）**：vacanabhedavasena，nissaya 作 `နှုတ်မြွက်သည်၏အစွမ်း`（发出言语），不是「言语区别」。
- **建议**：「以发出言语的方式」。
- **问题（44-59）**：manosañcetanā 译「意思」，在现代汉语里会被读成「含义」。
- **建议**：改为「意之思」，或首次出现时夹注（manosañcetanā）。
- **问题（10-30）**：copanavasena，nissaya 作 `ဝိညတ်၏အစွမ်း`（以表的方式）。「动转」可以保留，但宜补明是身表。

## §1068 句 130-1068-60-71
- **问题**：主宾颠倒（严重）— nissaya `အဝိဇ္ဇာ= အဝိဇ္ဇာသည်`（主格）、`ကုသလာနံ= ကုသိုလ်သင်္ခါရတို့အား`（与格）：是**无明**作为善行、不善行的缘。译文「成为无明的缘」把方向译反了。nissaya 还说明这里的近依止是本性近依止（pakatūpanissaya）；sahajātādivasenāpi 的 pi 也漏了。
- **建议**：「至于这里的“**由无明之集**”，应知：无明以近依止的方式作为善行的缘，对不善行则也以俱生等方式作为缘。」

## §1072 句 130-1072-54-64
- **问题**：误读 — nissaya `အန္ဓဘူတံ= အလွန်မိုက်သည်ဖြစ်၍ဖြစ်သော… နပဝတ္တတိ= အာရုံပြုသောအားဖြင့်မဖြစ်နိုင်`：andhabhūtaṃ 修饰 aññāṇaṃ（盲暗的无知），na 否定的是 pavattati。整句意思是「盲暗的无知不（以它们为所缘）在这上面生起」。译文「并非盲目地生起」理解错了。
- **建议**：「因为后二谛甚深，所以难见，盲暗的无知也不在这上面生起。」

## §1072 句 130-1072-65-75
- **问题**：原文疑问 — pali 作 vañcaniyaṭṭhena（能诳惑之义），nissaya 释为 `သဒ္ဒါ၏အနက်`，像是读作 vacanīya-（言说之义）。译文从 pali 不错，这里记下异读，不改。

## §1073 句 130-1073-30-38
- **问题**：漏主语 — nissaya 补出 `အဝိဇ္ဇာ= အဝိဇ္ဇာကို … နိဒ္ဒိဋ္ဌာ`：被指明的是无明，etena 是工具（通过这个词）。译文「这是就自性而总说的」主语不清。
- **建议**：「而通过不加区分的“**无知**”一词，应知无明是就其自性来指明的。」

## §1073 句 130-1073-49-51
- **问题**：风格 — 「唯以」是文言写法。
- **建议**：「无明漏则只以近依止的方式作为缘。」nissaya 补出了 `ပစ္စယော ဟောတိ`，句尾宜补「作为缘」。
