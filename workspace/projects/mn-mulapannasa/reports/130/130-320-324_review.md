# Review — 130:320-324（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§324 无 nissaya，略过）

## 被解释词与父层对照

- **阿罗汉**、**正等正觉者**（§321、§322）：与父层 164-47-2-17「如来、阿罗汉、正等正觉者」逐字相同 ✅
- **这已被如来遍知了**（§323 句 130-323-2-13）：与父层 164-47-46-52「“这已被如来遍知了”」逐字相同 ✅
- **去**（§320）、**《清净道论》**（§322）：父层无对应，不涉及。

## 跨段一致性

- **tathaṃ gato**：§320 句 130-320-2-10 译「如实而至」，句 130-320-46-52 译「如实而行践」。nissaya 两处都作 `ဂတော= ကျင့်တော်မူ၏`（实行）→ 建议统一为「行于如实（之道）」一类译法，不用「至」。「至」容易和 patto（到达）混淆。
- **gato 释义句式**：§320 前三句（22-31 / 32-38 / 39-45）都用「……，如实而去、已X，所以是如来」的格式，第四句（46-52）没有沿用 → 建议四句统一句式，第四句补出「已实行」。
- **paṭipadā 与 magga 同译「道」**：§320 句 46-52、93-105 把 paṭipadā 译作「道」，§323 句 23-37 把 maggena 也译作「道」，同一 chunk 内两词混同。nissaya 对 paṭipadā 作 `အကျင့်`（行持/修行），对 magga 作 `မဂ်` → 建议 paṭipadā 改为「道迹」或「行道」，「道」留给 magga。
- **maññanā**：§323 句 130-323-2-13 译「设想」，父层 164-47 把 maññati 一律译为「思量」→ 必须统一为「思量」。
- **tathāgatabhāva**：§320 句 142-147 译「如来之如来性」，句 148-154 译「如来的如来性」→ 统一用「如来的如来性」，并去掉文言的「之」。
- **文言虚词**：本 chunk 有「又，」（§320 句 2-10）、「之义」（同句）、「之」（§320 句 142-147）、「便」（§323 句 38-46），都要改成现代汉语，详见下面各句。

## §320 句 130-320-2-10
- **问题**：词法 + 文体。nissaya 区分了两个 gato：`တထာယ … ဂတော`（以不颠倒的〔遍知/作证〕而知、超越、到达，具格）和 `တထံ= မဘောက်မပြန်မှန်သောပဋိပတ်ကို။ ဂတော= ကျင့်တော်မူ၏`（实行真实的行道，宾格）。译文把第二个 gato 译成「如实而至」，与 nissaya 不符，而且和后文的 patto（到达）撞义。「以……之义为……」「又，」属于半文半白。
- **建议**：「另外，依如实（之道）而去，所以称为如来；行于如实（之道），所以也称为如来。」

## §320 句 130-320-22-31
- **问题**：句法。nissaya 把 `တထာယ= မဘောက်မပြန်သော` 读作修饰 `တီရဏပရိညာယ` 的形容词（以不颠倒的审察遍知），句中只有一个谓语 `ဂတောအဝဂတော= သိတော်မူ၏`。译文先说「了知了全部世间」，又说「如实而去、已了知」，同一个动词出现了两次。
- **建议**：「这里，以如实的审察遍知去到（即了知）整个世间，所以是如来。」

## §320 句 130-320-32-38
- **问题**：增译。原文唯一的动词是 gato = atīto（nissaya `လွန်တော်မူ၏` 超越），宾语是 lokasamudayaṃ。译文另外加了「了断了」，又和「已超越」重复。
- **建议**：「以如实的断遍知超越了世间的集，所以是如来。」

## §320 句 130-320-39-45
- **问题**：同上。动词只有 gato = patto（`ရောက်တော်မူ၏` 到达），译文「证得了」与「已到达」重复。
- **建议**：「以如实的作证到达了世间的灭，所以是如来。」

## §320 句 130-320-46-52
- **问题**：句法。nissaya 中 `တထံ= မှန်သော`（真实的）修饰 paṭipadaṃ，是宾语上的定语，不是副词「如实而」。「行践」也不是常用词。
- **建议**：「实行了导向世间灭的真实道迹，所以是如来。」（paṭipadā 的译法见跨段一致性）

## §320 句 130-320-106-136
- **问题**：格位误读（必改）。nissaya `လောကဿ= လောကသည်` 标的是主格（施事），lokassa 是「被世间所见、所闻……」的施事者，不是领属。nissaya 还补出了 `ဒိဋ္ဌံ … သုတံ … မုတံ … ဝိညာတံ … ယံအာရမဏ္ဏံ`（凡是所见、所闻、所觉、所识的所缘）。译文作「连同诸天……乃至……的世间的一切」，把施事译成了领属。
- **建议**：「诸比丘，凡是连同诸天的世间……乃至……所见、所闻、所觉、所识的一切，都已被如来现正等觉，因此称为如来。”（增支部4.23）」

## §320 句 130-320-137-141
- **问题**：语序。nissaya `တဿတထာဂတပဒဿ`（那个“如来”一词的）`အတ္ထော`（意义）。译文「这个词也应当这样理解意义」句式不通顺。
- **建议**：「“如来”这个词的意义，也应当这样理解。」

## §320 句 130-320-142-147
- **问题**：文体 + 词法。「之」是文言虚词。nissaya 把 `တထာဂတဿ= သဒ္ဒါဂတသဒ္ဒါ၏` 读作「“如来”这个词的」，指的是以上的语词分析，不是指佛本人。
- **建议**：「这些也只是阐明“如来”一词所以称为如来的一个开端而已。」

## §320 句 130-320-148-154
- **问题**：增译 + 取义（必改）。vaṇṇeyya 只出现一次，译文却译了「宣说」和「称叹」两个动词，「如来的如来性」也重复了两遍。nissaya `တထာဂတောဝ= တစ်ဆူသောဘုရားရှင်သည်သာလျှင်`、`တထာဂတဿ= တစ်ဆူသောဘုရားရှင်၏`，意思是「只有一位如来才能说出另一位如来的如来性」，没有「如来自己」的意思。pana（然而）也漏译了。
- **建议**：「然而，要从一切方面阐述如来的如来性，只有如来才能做到。」

## §321 句 130-321-2-24
- **问题**：漏译 + 句法（必改）。nissaya 分列了五个理由：`အာရကတ္တာ`（远离烦恼）、`အရီနံ … ဟတတ္တာ`（已杀烦恼之敌）、`အရာနံ … ဟတတ္တာ`（已毁轮回之轮的辐）、`ပစ္စယာဒီနံ အရဟတ္တာ`（应受资具等供养）、`ရဟာဘာဝါ`（无隐秘处）。hatattā 同时管 arīnaṃ 和 arānaṃ。译文把 arīnaṃ 并入了 ārakattā（「远离诸敌」），结果「杀敌」一项丢了，只剩四个理由。nissaya 还补出了主语 `ဘဂဝါ= မြတ်စွာဘုရားကို`（世尊）。
- **建议**：「至于“**阿罗汉**、**正等正觉者**”这两个词，首先，世尊应当依以下这些理由理解为“**阿罗汉**”：由于远离（烦恼），由于已杀诸敌（烦恼），由于已摧毁（轮回之轮的）诸辐，由于应受资具等的供养，由于造恶时没有隐秘之处。」

## §322 句 130-322-2-9
- **问题**：用词。nissaya `သာမံဧဝ= ကိုယ်တော်တိုင်သာလျှင်`（亲自）。「自行地」意思不够准确。
- **建议**：「又由于正确地、亲自觉悟了一切法，所以是“**正等正觉者**”。」

## §322 句 130-322-10-12
- **问题**：句法。nissaya `ဣတိအယံ`（以上所说）、`ဧတ္တ`（在此注释中）、`သင်္ခေပေါ`（简略说法），这是一个名词判断句。译文「这里简略地说，就是如此」把它译成了副词短语，语义也有些模糊。
- **建议**：「以上是这里的简要解释。」

## §323 句 130-323-2-13
- **问题**：术语（必改）。maññanāvatthu 译作「设想的根据」，与父层 maññati 的译法「思量」不一致。nissaya `ထိုပထဝီအစရှိသော … မညနာ၏အာရုံကို`（那以地为首的种种思量的所缘），所以 vatthu 应作「所缘/对象」。
- **建议**：「至于“**这已被如来遍知了**”，这里也可以理解为这样的意思：那以地等为对象的思量所缘，已被如来遍知了。」

## §323 句 130-323-14-22
- **问题**：取义 + 原文异读。本句把 pariññātantaṃ 拆作 pariññāta + antaṃ（遍知到了终点），译文「已被遍知」没有译出 anta。nissaya 读 pāraṃ 为 `ပရိညာတပါရိပူရံ`（遍知的圆满），与 pali「pāraṃ」不同（记下，不改原文）。
- **建议**：「所谓“遍知到了终点”（pariññātantaṃ），是说已到遍知的彼岸、已到遍知的终点，也就是毫无余留地遍知了。」

## §323 句 130-323-23-37
- **问题**：用词。nissaya `ထိုထိုသို့သောမဂ်ဖြင့်`（以各个道）。「此道或彼道」容易被理解成二选一。
- **建议**：「……虽然在以各个道断除烦恼这一点上没有差别，……」

## §323 句 130-323-38-46
- **问题**：文体（必改）。「便」作「于是/就」用，属于 style.md 禁例。
- **建议**：「因为诸弟子只思察四界中的一部分，就证得涅槃。」

## §323 句 130-323-47-54
- **问题**：原文异读（只记录，不改）。nissaya 把 aṇuppamāṇampi 读作 `အကုပ္ပမာနံ`（不坏的），把 atīritaṃ 读作 `အဝိဒိတံ`（未知的），与 pali 不同。译文按 pali 译作「极其微小」「不曾审察」，与 §320 的「审察遍知」用词一致，可以保留。nissaya 把 ñāṇena 释为 `မဟာဝဇီရဉာဏ်`（大金刚智），不需要译进正文。
- **建议**：维持原译。
