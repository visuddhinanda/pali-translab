# Review — 130:2087-2091（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照

- 黑体被解释词都已与父层逐字核对，全部相同：晾干身体的水分／出于悲悯／谈论佛法／等候／敲了敲门闩／打开了／在预先铺设好的座位上。
- **非黑体的本文引文有一处不同（必改）**：§2087 句 130-2087-147-158 引的是 164-902-18-26，父层译文是「在东门**水池**洗完身体上岸后，只穿着一件衣服站着」。本层少了「水池」，见下文该句。

## 跨段一致性

- **pubbakoṭṭhaka**：本层 §2087 各处都译「东门」，父层译「东门附近的水池」或「东门水池」。
  - nissaya 的释义是 အရှေ့မျက်နှာ-တံခါးမုတ်（东面的门楼）。本层的解释部分保留「东门」不算错。
  - 但凡是**引用或复述本文的句子**，都要跟父层走：147-158 是直接引文，必须改；65-79 复述了本文 tenupasaṅkami gattāni parisiñcituṃ，建议也改。
  - 两层对这个词的理解不一致，应提交 harmonize 定夺。
- **rattadupaṭṭa / dupaṭṭa**：§2087 三处（85-90、91-97、117-126）都译「（红色的）下裙」。nissaya 释义是 နှစ်ထပ်သင်းပိုင်（双层下衣），译文漏了「双层」。「下裙」也不是通行的僧衣译名。建议统一为「红色双层下衣」。
- **bhāriya / bhāra**：nissaya 两处都释为 ဝန်လေး（沉重、难办）。§2089 96-104 译「十分危险的事」，§2091 114-133 译「麻烦事」。前者偏离了 nissaya，建议改为「是件很难办的事」，两处统一用「难办／麻烦」这一路。
- **kulaputta**：§2091 50-93 译「良家子」，父层 164-903-115-132 译「良家子弟」。建议统一为「良家子弟」。
- **凭空添加「用双手」**：§2087 127-143 与 §2089 36-64 的原文都只有 (ubhosu/dvīsu) kaṇṇesu gahetvā（抓住两角），两处都多出「用双手」，建议删去。
- **译文里多余的黑体（必改）**：130-2087-109-116、130-2087-117-126、130-2088-19-41、130-2088-42-69 这几句的黑体都不是被解释词。注释层的黑体只能用来标被解释词，这些黑体会误导读者，全部去掉。
- **文言残留（必改，见各句）**：
  - 「之」：身相之美、功德之美、诸如此类之处、大出离之美、洗浴之法
  - 「便」：§2089 36-64、§2091 50-93
  - 「而」：侧耳而坐、就此而说

## §2087 句 130-2087-2-14
- **问题**：词法／补出成分。devorohaṇakāle 的 nissaya 是 နတ်ပြည်မှ-သက်တော်မူသောအခါ၌（从天界降下的时候），施事是世尊。译文「天降时」容易被读成「天神降临」。
- **建议**：改为「世尊从天界下降时阶梯落地之地」。

## §2087 句 130-2087-15-23
- **问题**：词义。
  - vīsatiusabha 的 nissaya 是 ဥသဘနှစ်ဆယ်-အတိုင်းအရှည်ရှိသော（规模为二十乌萨婆），没有「周长」的意思。
  - koṭṭhako 的 nissaya 是 တံခါးမုတ်（门楼），译文「一道门」不够准确。
- **建议**：改为「……寺院规模为二十乌萨婆（usabha）的时候，是东边大门的门楼」。

## §2087 句 130-2087-29-44
- **问题**：格与句法（必改）。
  - māpesi 的主语是 aciravatī（nissaya 作 အစီရဝတီမြစ်သည်，主格）。udakena bhinditvā 是「河水冲破（河岸）」，nissaya 作 ရေသည်… ပြတ်၍。
  - 译文「流到东门时被水冲开」用了被动，主宾关系错了，读起来像河被水冲开。
  - samatitthaṃ 的 nissaya 是 ညီညွတ်သောဆိပ်ရှိ（有平整的水岸台阶或渡口），译「水岸平整」偏窄。
- **建议**：改为「阿致罗筏底河环绕舍卫城流淌，流到东门门楼时，河水冲破河岸，形成了一个大水池，岸边的浴阶平整，水由浅渐深」。

## §2087 句 130-2087-45-64
- **问题**：原文疑问（只记录，不改）。原文是 pāṭiyekkāni（各自），nissaya 却作 ပဋိပါဋိယာ（依次），是异读。译文按原文译作「各自独立」，没有问题。
- **建议**：不改。

## §2087 句 130-2087-65-79
- **问题**：跨层一致。这一句复述本文的 yena pubbakoṭṭhako tenupasaṅkami gattāni parisiñcituṃ，父层译作「前往东门附近的水池洗身体」。
- **建议**：参照父层，改为「前往这样的东门水池洗身体」。

## §2087 句 130-2087-85-90
- **问题**：漏词。rattadupaṭṭaṃ 的 nissaya 是 နီမြန်းသော-နှစ်ထပ်သင်းပိုင်（红色的双层下衣），译文漏了「双层」。
- **建议**：改为「世尊脱下红色双层下衣，穿上了浴衣」。

## §2087 句 130-2087-91-97
- **问题**：与上一句同一个词。dupaṭṭena 的 nissaya 是 နှစ်ထပ်သင်းပိုင်တော်နှင့်（与双层下衣一起）。
- **建议**：改为「长老把双层下衣和大衣一起拿在自己手上」。

## §2087 句 130-2087-109-116
- **问题**：
  - 格式（必改）：「**用引水管**」不是被解释词，不能加黑体。
  - 词义：suvaṇṇarasadhārā 的 nissaya 是 ရွှေရည်အယဥ်（熔化的金液流），不是「金色的水流」。
  - 措辞：「那时刻，就像……」主语不清楚。
- **建议**：改为「那情景，就像用机关水管倾注出一道道熔金，又像展开一匹匹金布」。

## §2087 句 130-2087-117-126
- **问题**：
  - 主宾关系（必改）：dassetvā 的 nissaya 是 ပြတော်မူ၍，用了敬语「တော်မူ」，施事是世尊。nhatvā（ရေချိုးတော်မူ၍）与 paccuttiṇṇassa 也都指世尊。bhagavato 是与格（ဘုရားအား），表示把衣服交给世尊。译文「长老为世尊示范洗浴之法」把主宾颠倒了。
  - 格式（必改）：「**洗浴之法**」加了黑体，而且「之」是文言。
  - 漏词：dupaṭṭa 漏译。
- **建议**：改为「于是世尊示范了洗浴的规矩，洗完上岸后，长老就把红色双层下衣递给他」。

## §2087 句 130-2087-127-143
- **问题**：句法（必改）。
  - upanītaṃ 的 nissaya 是 အနီးသို့ဆောင်အပ်သည်ကို，被动，意思是「被递过来的」。前面的 saṃharitvā、katvā 都修饰这件大衣：大衣由长老折好递来。
  - 译文「把大衣……折叠起来……拿来后」把折衣和递衣都算到世尊头上。
  - antantena 的 nissaya 是 နှစ်ခုသော-အစွန်းဖြင့်（两边对齐），不是「从边角处」。
  - 「用双手」是添加的。
- **建议**：改为「世尊穿上它，系好像电光一样的腰带，接过长老两边对折、叠成莲花蕾形状递来的大衣，抓住两角站着」。

## §2087 句 130-2087-147-158
- **问题**：与父层引文不一致（必改）。父层 164-902-18-26 是「在东门水池洗完身体上岸后，只穿着一件衣服站着」，本层少了「水池」。
- **建议**：改为「“在东门水池洗完身体上岸后，只穿着一件衣服站着。”」

## §2088 句 130-2088-2-18
- **问题**：句法（必改）。
  - 莲池、波利质多罗树、天空三项都是宾格，是 avahasamānaṃ（嘲笑、胜过）的宾语。nissaya 的结构是「…ကိုလည်းကောင်း … သိရိယာ အဝဟသမာနံဝိယ」，意思是「以光彩胜过……」。
  - 译文先说身躯「就如同」这三者，又说「嘲笑它们」，前后矛盾。
- **建议**：改为「世尊这样站着时，身体光辉照耀，仿佛以自身的光彩嘲笑盛开的红白莲池、满树繁花的波利质多罗树和星光闪烁的天空一般」。

## §2088 句 130-2088-19-41
- **问题**：
  - 格式（必改）：「**这正是……好题材**」不该加黑体。
  - 句法：paṭipāṭiyā ṭhapitā（依次排列的）修饰的是后面的转轮王、天王、大梵天，见 nissaya 的 ဋ္ဌဝိတာ 位置。译文把「依次排列」挂在了太阳花鬘后面。
  - 词义：vaṇṇabhūmi nāmesā 的 nissaya 是 ဧဿ= ဤသို့ဖြစ်ခြင်းသည်။ ဝဏ္ဏဘူမိမည်၏，意思是「这种情形叫做称赞之地」，是一个称名句。
- **建议**：改为「……又像依次排列的三十二位转轮王、三十二位天王、三十二位大梵天一样，格外光辉照耀。这就是所谓的‘称赞的场合’（vaṇṇabhūmi）」。

## §2088 句 130-2088-42-69
- **问题**：
  - 格式（必改）：义理、譬喻、理由、充分地、力量那几处都加了黑体，全部去掉。
  - 词义：thāmo veditabbo 的 nissaya 是 အစွမ်းကို သိအပ်၏，意思是「说法者的本事应当在这里看出来」。译文「力量，应当这样理解」是误读。
  - 词义：vaṭṭati 是「适合、可以」，不是「应当」。
  - 词义：kāraṇāni 的 nissaya 是「把譬喻和所喻联系起来、讲清楚的因由」，「理由」可以接受，但最好译成「论证」。
  - 风格（必改）：「诸如此类之处」「身相之美」「功德之美」是文言。
- **建议**：改为「在这类场合，有能力的说法者可以用散文或偈颂，配上意义、譬喻和论证，把诸佛身体的美好或功德的美好充分地讲出来。说法者的本事，就要在这类场合看出来」。

## §2089 句 130-2089-17-28
- **问题**：词义（必改）。
  - kaṇṇikā 的 nissaya 是 မှို（霉、霉斑），不是「皱纹」。
  - dussati 的 nissaya 是 ပျက်စီး（损坏），不是「弄湿」。
- **建议**：改为「因为身体带着水就披上衣服的话，衣服上会长霉斑，随身的衣物用品也会损坏」。

## §2089 句 130-2089-36-64
- **问题**：
  - 添加：「用双手」是原文没有的。
  - 风格：「便」是文言。
- **建议**：改为「……于是抓住大衣的两角，遮住身前站着」。

## §2089 句 130-2089-70-81
- **问题**：词义。gamanābhihārato 的 nissaya 是 သွားခြင်းကို-ကြံတော်မူသည်မှ（从起意要去的那一刻起），译「一旦动身」偏离了。
- **建议**：改为「……一旦起意前往鹿母讲堂，就很难再让他回心转意了」。

## §2089 句 130-2089-82-89
- **问题**：主语（必改）。
  - 句子主语是 adhippāyakopanaṃ nāma，nissaya 作 အလိုတော်ကို-ဖျက်ဆီးရခြင်း-မည်သည်ကား（所谓违逆诸佛的心意），它的谓语是 96-104 的 bhāriyaṃ hoti。
  - 译文「诸佛一旦下定决心就难以改变」把主语换成了诸佛，意思也变了。
- **建议**：改为「因为要违逆诸佛的心意，就像为了捉住独行的狮子而伸出手；」

## §2089 句 130-2089-96-104
- **问题**：词义。bhāriyaṃ 的 nissaya 是 ဝန်လေး（沉重、难办），不是「危险」。参见跨段一致性。
- **建议**：改为「……又像去抓毒性猛烈的毒蛇的脖子一样，都是很难办的事」。

## §2090 句 130-2090-24-39
- **问题**：
  - 句法：vaṇṇaṃ kathayamānā 的 nissaya 是 ကျေးဇူးကို ခြီးမွမ်း（称颂功德），同时管「某一波罗蜜」和「大出离」两项。译文只让「之美」挂在大出离上。
  - 补出成分：nissaya 把 aññatarāya pāramiyā 补释为 နိက္ခမ-ပါရမီ（出离波罗蜜），译文可以随文夹注。
  - 风格：「之美」是文言。
- **建议**：改为「是指他们坐在一起，称颂十波罗蜜中的某一种波罗蜜（出离波罗蜜）和大出离的功德」。

## §2090 句 130-2090-65-73
- **问题**：风格。「侧耳而坐」是文言。
- **建议**：改为「因为他们一直竖着耳朵坐着听，所以当下就过来打开了门」。

## §2091 句 130-2091-50-93
- **问题**：
  - 词义：anamatagge 的 nissaya 是 အစမထင်သော（起点无从得知），即「无始」，不是「无穷无尽」。
  - 原文疑问（只记录，不改）：原文是 saṃsāressanti，nissaya 作 သံသီဒေန္တိ（使其沉没），是异读。
  - 风格：「便想」用了文言「便」。
  - 跨层：「良家子」见跨段一致性。
- **建议**：改为「……就想：‘……怎么能让不善的寻思压倒这位良家子弟，使他在无始的轮回苦中流转呢？’……」

## §2091 句 130-2091-163-171
- **问题**：术语。paṃsukūla 的 nissaya 是 ပံသကူသင်္ကန်း（粪扫衣）。
- **建议**：把「粪扫布」改为「粪扫衣」。

## §2091 句 130-2091-172-181
- **问题**：风格。「就此而说」带文言腔。
- **建议**：改为「……座位本来就已经铺好了，这句话就是指这个说的：」
