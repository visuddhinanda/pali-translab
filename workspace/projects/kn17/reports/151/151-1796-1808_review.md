# Review — 151:1796-1808（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句有，无 nissaya 的句子未审）
> 本层为本文 mūla，无父层，不做被解释词对照。

## 跨段一致性

- **「X + 动作名词」复合词的结构关系，四段译法不统一，且与 nissaya 不完全一致**：
  - §1796 `Nekkhammappaṭivedho`，译「出离的通达」。nissaya 作宾格：`နေက္ခမ္မကို ထိုးထွင်း၍သိခြင်း`（**对出离**作透彻了知）。
  - §1798 `Nekkhammakhanti`，译「对出离的忍可」。nissaya 作同位：`နေက္ခမ္မဟူသော နှစ်သက်ခြင်း`（**名为出离的**认可），出离本身就是忍可，不是忍可的对象。
  - §1799 `Nekkhammādhiṭṭhānaṃ`，译「出离的确立」。nissaya 作宾格：`နေက္ခမ္မကို ဆောက်တည်ခြင်း`（**确立出离**）。
  - §1800 `Nekkhammapariyogāhaṇaṃ`，译「深入出离」。nissaya 作趋向：`နေက္ခမသို့ သက်ဝင်ခြင်း`（进入出离）。与译文一致。
  - → 建议按 nissaya 分别处理：§1796 改为「通达出离」，§1799 改为「确立出离」，§1800 保持不变，§1798 改为同位结构（见下）。各段内的全部八项（出离……阿罗汉道）要同步改。
- **一性 / 多样性**（ekatta / nānatta）：§1797 中二者成对出现，「一性」与「多样性」字数、构词不对称。nissaya 把二者释为 `တခုတည်းဖြစ်` / `အထူးထူးဖြစ်`（单一 / 种种）。→ 建议统一为「单一性 / 多样性」，或「一性 / 种种性」。整段及 §1797-2-7、§1797-112-115 要一并改。

## §1796 句 151-1796-5-8

- **问题**：格与句法。nissaya `နေက္ခမ္မပဋိဝေဓော= နေက္ခမ္မကို ထိုးထွင်း၍သိခြင်းသည်`，出离带宾格 `ကို`，是「通达」的对象。「出离的通达」用「的」，读者会理解成属格或主语（出离所作的通达）。
- **建议**：改为「通达出离是空于欲贪的。」本段后续各项照此改，例如「通达无恶意……」「通达阿罗汉道……」。

## §1797 句 151-1797-14-19

- **问题**：词义与补出成分。
  - nissaya `စေတယတော= စေ့ဆော်သောသူအား`，意思是「对于意向、策发（于此）的人」，取的是 cetanā「思」（意志驱动）一义。「思惟」在汉语里容易被读成思考、寻思（vitakka）。
  - `suññaṃ` 是中性单数，与 `nekkhammekattaṃ` 一致，主语是这一性本身。译文的「那」指代不明。
- **建议**：改为「对意向出离这一单一性的人来说，这单一性是空于欲贪的。」同段其余各项「思惟……一性」照此统一。

## §1798 句 151-1798-5-8

- **问题**：格与句法。nissaya `နေက္ခမ္မခန္တိ= နေက္ခမ္မဟူသော နှစ်သက်ခြင်းသည်`，「ဟူသော」表示同位，即「名为出离的认可」。译文「对出离的忍可」把出离译成了忍可的对象，与 nissaya 不符。
- **建议**：改为「出离这种忍可是空于欲贪的。」本段八项（§1798-9-12 至 §1798-33-42）同步改为「无恶意这种忍可」……「阿罗汉道这种忍可」。

## §1799 句 151-1799-5-8

- **问题**：格与句法。nissaya `နေက္ခမ္မာဓိဋ္ဌာနံ= နေက္ခမ္မကို ဆောက်တည်ခြင်းသည်`，出离带宾格 `ကို`。「出离的确立」与 nissaya 不符。
- **建议**：改为「确立出离是空于欲贪的。」本段其余各项（§1799-9-12 至 §1799-33-43）照此改。

## §1801 句 151-1801-2-8

- **问题 1**：句法误读。nissaya `ပဝတ္တပရိယာဒါနံ= သော`，「သော」是定语标记；`sabbasuññatānaṃ= တို့တွင်`（在一切空性当中）也修饰 paramatthasuññaṃ。所以「正知者的转起的终结」是「胜义空」的同位定语，不是与它并列的另一项。译文用顿号把二者并列成两个问项，结构错了。
- **问题 2**：格式。「**一切空性中的****胜义空**」出现相邻加粗标记「****」，渲染会出错。
- **建议**：改为「什么是**正知者终结转起**这种在一切空性中最殊胜的**胜义空**？」去掉顿号，加粗只标被问的术语本身。

## §1801 句 151-1801-9-58

- **问题**：补出成分。nissaya `ဣဓ= ဤသာသနာတော်၌` 把「这里」补出为「在这教法中」。译文「在这里」所指不明。
- **建议**：改为「在这教法中，正知者……」。可选，但建议补出。

## §1801 句 151-1801-98-103

- **问题**：同 §1801-2-8 的句法误读。nissaya `ပဝတ္တ ပရိယာဒါနံ= ဖြစ်ခြင်းကိုကုန်စေခြင်းဟူသော`，同位定语标记「ဟူသော」修饰 `ပရမတ္ထသုညံ`。译文用顿号并列，结构错了。nissaya 另补出了 `ဣတိ … ဝေဒိတဗ္ဗံ`（应当这样理解）。
- **建议**：改为「应当这样理解：正知者终结转起，这就是一切空性中最殊胜的胜义空。」至少要去掉顿号，与 §1801-2-8 结构对应。

## §1803 句 151-1803-2-4

- **问题**：
  - **补出成分**：nissaya 补出 `နိဋ္ဌိတော= ပြီးပြီ`（结束了）。译文只有品名，没有谓语，也与 §1802「空论结束」不一致。
  - **格式**：「第二 双联品」中间夹了一个半角空格。
- **建议**：改为「第二双联品结束。」

## §1807 句 151-1807-2-8

- **问题**：主谓结构误读。nissaya `ဧသ-ဧသော ဝဂ္ဂေါ= ဤဝဂ်သည်` 把 esa 补为「这一品」，带主格 `သည်`，作主语。ṭhapito / asamo / dutiyo / pavaro 都带定语标记 `သော`，修饰主语；谓语在下一段 §1808 才出现（`ဝရဝဂ္ဂေါ … ဟောတိ`）。译文「这是……」把 esa 译成代词主语、后接判断，结构不对。另外，nissaya 对 `asamo` 的解释是 `တပါးသောဝဂ်နှင့် မတူသော`（与其他品不同），「无与伦比」略有拔高。
- **建议**：改为「这一由持部者确立、不同于其他各品、殊胜的第二品，」与 §1808 连读。

## §1808 句 151-1808-2-3

- **问题**：
  - **补出成分**：nissaya 补出谓语 `ဟောတိ= ၏`（是），以及 `ဣတိ … ဝေဒိတဗ္ဗံ`（应当这样理解）。`ဝရဝဂ္ဂေါ= ဝဂ်မြတ်` 的意思是「殊胜的品」。
  - **词义**：「上品」在现代汉语里容易被读成「上等货色」，或「上、下品」的分卷名。
- **建议**：改为「是最殊胜的一品。」与 §1807 合成完整的主谓句。
