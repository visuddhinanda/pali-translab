# Review — 151:655-658（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **-pakkhando**（同一构词）：§655 `vipathapakkhando` 译“走上了歧途”（主动），`mahoghapakkhando` 译“被卷进了大暴流”（被动）。nissaya 两处都是主动的“奔入、走入”（`လိုက်` / `ပြေးဝင်ကျရောက်`）。建议都用主动：“冲进了大暴流”。
- **X-ehi rajjati**：§656 五欲一句译“贪著五种欲”，把具格当成宾语；六爱身、九种以贪爱为根的法两句译“因……而贪著”。nissaya 三处都是 `ဖြင့်`（具格）。建议统一为“因五种欲而贪著”。
- **“系”字混用**：§656 `yutto`（轭）译“被四轭所系”，`ganthita`（gantha）译“被四系所缚”，`saññutto`（结）译“被七结／十结所系”。“系”既作 gantha 的名词，又作 yoga、saṃyojana 的动词，读者分不清“四系”与“所系”。nissaya `yutto= ယှဉ်လျက်ရှိ၏`（相结合），`saññutto= စပ်ယှဉ်၏`（连结）。建议 yutto 改为“与四轭结合”，让“系”只对应 gantha。
- **被动 / 主动不一致**：§656 `āghātito`（九事、十事两处）译“怀恨”（主动），而同段的 `pariyuṭṭhito / otthaṭo / ganthito` 都按 nissaya 译成被动。nissaya `āghātito= ထိပါးနှိပ်စက်အပ်၏` 是被动（被触击、被压迫）。见下文。

## §655 句 151-655-2-29
- **问题**：句法（轻微）— nissaya `acakkhuko= ပညာမျက်စိမရှိသည်ဖြစ်၍` 带因果连接（ဖြစ်၍ = 因为……所以），主句谓语是 `andho= အကန်းသဖွယ်ဖြစ်၏`。所以 acakkhuko 是 andho 的原因，不是并列的第二个谓语。`hatanetto … apariṇāyako`、`vipathapakkhando … añjasāparaddho` 也是同样的结构。
- **建议**：可以考虑译出因果：“世间众生没有眼睛，因而是盲目的”，后两组照此处理。现译不算错，属可选改进。

## §655 句 151-655-30-46
- **问题**：语态 — `mahoghapakkhando= …ရေအယဉ်သို့ ပြေးဝင်ကျရောက်လျက်ရှိ၏`，意思是众生自己奔入、落入暴流，是主动。译文“被卷进”改成了被动，施事也随之改变。
- **建议**：改为“世间众生冲进了大暴流”。

## §656 句 151-656-2-279
- **问题**：句法层次 — `catuyogayojito= …ဝဋ်ဆင်းခဲ၌ယှဉ်စေအပ်သည်ဖြစ်၍`，意思是被四轭驾套在轮回苦中，作为原因；主句是 `yutto= ယှဉ်လျက်ရှိ၏`（与四轭相结合）。译文“被四轭所系，被四轭套住”把两层意思平列，又重复了“四轭”。
- **建议**：改为“世间众生与四轭结合，被四轭套在轮回之苦上”。
- **问题**：漏义 — `pañcagatisamāruḷho= ငါးပါးသော ဂတိသို့ အဖန်တလဲလဲ တက်ရောက်`，意思是一再登上五趣。译文“登上了五趣”漏掉了“反复”。
- **建议**：改为“一再登上五趣”。
- **问题**：语法 — `anusaṭo= အစဉ်လျှောက်၍ဝင်အပ် ပျံ့နှံ့အပ်၏`，意思是被依次渗入、被遍布。“被七随眠潜伏”里“潜伏”是不及物动词，“被……潜伏”不成句。
- **建议**：改为“被七随眠渗透遍布”。
- **问题**：取义 — `samparivattati= တပြောင်းပြန်ပြန်လည်လျက်ရှိ၏`，意思是翻来覆去地转动。“流转”容易被读成轮回流转。
- **建议**：改为“随着八世间法翻来覆去”。
- **问题**：语态 / 取义 — `niyyāto= ထိုမှ ဤမှ ပြေးသွား၏`（八邪性、十邪性两处），nissaya 的意思是以邪性东奔西走，是主动。译文“被八邪性引向歧途”加了施事，改成了被动。
- **建议**：改为“随着八邪性四处奔走”，十邪性一句同改。
- **问题**：语态 — `āghātito= ထိပါးနှိပ်စက်အပ်၏`（九事、十事两处）是被动（被触恼、被压迫）。译文“因……而怀恨”改成了主动的情绪。
- **建议**：改为“被九嫌恨事所恼害”，十事一句同改。
- **问题**：取义 — `kilissati= ပူပန်စေအပ်,နှိပ်စက်အပ်၏`，nissaya 取“被热恼、被折磨”义；译文“受染污”取的是另一义。
- **建议**：改为“被十烦恼事所热恼”。
- **问题**：取义（轻微）— `dasavatthukāya= ဆယ်ပါးသော မှီရာဝတ္ထုရှိသော`，意思是有十种所依之事。“以十事为对象”把 vatthu 译窄了。
- **建议**：改为“以十事为依据的邪见 / 边执见”。
- **问题**：取义 — `papañcito= အကျယ်ချဲ့လျက်ရှိ၏`，意思是被扩展、蔓延。“所纠缠”偏离了这个意思。
- **建议**：改为“被一百零八种贪爱戏论所扩展蔓延”。
- **问题**：句法 — 结尾的 `buddhānaṃ= မြတ်စွာဘုရားတို့၏`（属格）修饰 `mahākaruṇā`，`sattesu= သတ္တဝါတို့၌`（处格）是大悲降入的地方。译文“对众生的大悲就降临了”把 sattesu 变成了“大悲”的定语，“降临”到哪里不清楚，读起来像大悲降临到佛身上。
- **建议**：改为“诸佛世尊……看到这一点时，他们的大悲就降注到众生身上”。

## §656 句 151-656-280-291
- **问题**：句法 — 结尾 `buddhānaṃ … sattesu mahākaruṇā okkamati` 的问题与上句相同。
- **建议**：与上句统一改法。

## §657 句 151-657-41-48
- **问题**：取义 — `parinibbuto= ကိလေသာမီးအလုံးစုံ ငြိမ်းပြီသည်`，意思是烦恼之火已全部熄灭。这里是在世的佛陀自述，“我已经般涅槃了”容易被读成入灭（命终）。
- **建议**：改为“我的烦恼之火已经完全熄灭，而世间还没有熄灭”。下句 `parinibbāpetuṃ` 同改。

## §657 句 151-657-49-77
- **问题**：补出成分 / 一致性 — nissaya 在每一分句都补出了 `pare ca= သူတပါးတို့ကိုလည်း`（也使他人），并用 `ဖြစ်၍` 连接“自己已经……”与“使他人……”。译文前五句用“就使”，末句用“也使”，前后不统一。“就使”单独看也容易被读成已经完成的动作，丢掉了不定式“能使”的意思。
- **建议**：统一为“自己已经渡过，所以能使别人也渡过；……自己的烦恼之火已经熄灭，所以能使别人的也熄灭”。
- **问题**：句法 — 结尾 mahākaruṇā okkamati 的问题同 §656。
- **建议**：同 §656 统一改法。
