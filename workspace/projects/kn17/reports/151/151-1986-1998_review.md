# Review — 151:1986-1998（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（以下句子没有 nissaya，本次略过：1987-27-33、1990-23 以后各句、1991-22 以后各句、1992-23 以后各句、1993-44 以后各句、1994 全段、1995-21 以后各句、1998 的 22-28／29-37／38-44／54-60／77-83）

## 跨段一致性
- **nirodho X nibbānaṃ 句式（§1998 全段）**：nissaya 把 `niccaṃ / sukhaṃ / ārogyaṃ / agaṇḍaṃ / visallaṃ` 都标成修饰 nibbānaṃ 的定语（都以 `-သော` 结尾），所以每句只有“灭 = 某种涅槃”一个表语。现在的译文“是常，是涅槃”拆成了两个并列表语，五组对句都是这样。必须统一改成“是常住的涅槃／是安乐的涅槃／是无病的涅槃／是无痈的涅槃／是无箭的涅槃”。各句的依据见下文 §1998。
- **agha 与 upaddava 共用“祸”字（§1997）**：aghato 译作“祸”，aghamūlato 译作“祸根”，upaddavato 译作“祸患”，两个不同的巴利词混在同一个字里。nissaya 的解释是 `အဃတော= မကောင်းမှု၏ တည်ရာဝတ္ထုဖြစ်၍ မကောင်းမှုနှင့် တူသောအားဖြင့်`（作为恶的依处、如同恶），`အဃမူလတော= မကောင်းမှု၏အကြောင်းရင်းမူလ`（恶的根本）。建议 agha 一组改译为“恶”“恶根”，“祸患”只留给 upaddava。
- **vata 一律没有译出（§1988–1995 各个 So vata 句）**：nissaya 为 `ဝတ-ဧကန္တေန= စင်စစ်အားဖြင့်`（确实、必定）。各句都没译出这个词，这一点前后是一致的。“这是不可能的／可能的”已经大致涵盖了它的语气，所以不列为必改。如果要补，就在每个 So vata 句里统一加“确实”。
- 其他术语前后一致：随顺忍、正性决定、进入、具足、看作，行（saṅkhāra）与法（dhamma）也区分开了，没有问题。

## §1987 句 151-1987-2-20
- **问题**：句法（次要）— 在 nissaya 里，`အနာထပိဏ္ဍိကဿ= အနာထပိဏ်သူဌေး၏။ အာရာမေ= အရာမ်ဖြစ်သော။ ဇေတဝနေ= ဇေတဝန်ကျောင်းတော်၌` 的 ārāme 是 jetavane 的同位语，意思是“作为给孤独长者园林的祇陀林”，两者是同一个地方。译文“祇树林中给孤独长者的园林里”读起来像园林位于祇树林之内，成了包含关系。
- **建议**：改为“住在舍卫城的祇陀林——给孤独长者的园林里”，或者用惯用的“祇树给孤独园”。“长者”是从 nissaya 的 `သူဌေး` 补出来的，有依据，可以保留。

## §1995 句 151-1995-2-20
- **问题**：资源疑问 — 这一行的 nissaya 是 `ကဉ္စိ= တစုံတခုသော။ သင်္ခါရံ= သင်္ခါရကို။ သုခတော= …`，也就是 §1990 “kañci saṅkhāraṃ sukhato” 的注解，和本句原文“nibbānaṃ sukhato”对不上，是错配，不能当作依据。
- **建议**：译文按巴利原文核对过，没有问题，不改。nissaya 错配的事记录下来备查。

## §1997 句 151-1997-2-14

## §1997 句 151-1997-15-71
- **问题**：误译 — vibhavato 译作“断灭”。nissaya 是 `ဝိဘဝတော= ကြီးပွါးမှုကင်းသောအားဖြင့်`，意思是没有增长、没有兴盛，并不是“断灭”（不是断见、无有爱那一类意思）。
- **建议**：改为“衰损”或者“无增长”。
- **问题**：用词与 nissaya 不符 — aghato 译“祸”，aghamūlato 译“祸根”（理由见上文跨段一致性）。
- **建议**：改为“恶”和“恶根”。
- **问题**：用词（次要）— mārāmisato，nissaya 为 `မစ္စုမာရ်တည်းဟူသော သေမင်း၏ အစာ`（死魔的食物）。“诱饵”带有引诱的意思，nissaya 没有这层含义。
- **建议**：改为“魔的食饵”，或者“死魔的食物”。
- **备注**：nissaya 补出了动词 `(ပဿတိ= ရှု၏။)`，译文加“把五蕴看作”与它一致。共 40 项，一项不缺。nissaya 本身漏注了 addhuvato，又把 asārakato、aghamūlato 各重复了一次，这是资源本身的问题，与译文无关。

## §1998 句 151-1998-13-21
- **问题**：句法 — nissaya 为 `နိစ္စံ= မြဲသော။ နိဗ္ဗာနံ= ငြိမ်းခြင်းပေတည်း`。niccaṃ 是 nibbānaṃ 的定语，意思是“灭是常住的涅槃”。译文“是常，是涅槃”拆成了两个表语。（另外，这一行注入的 nissaya 里写的是 sukhaṃ，属于错配，所以依据取自 151-1998-2-12 那一行 nissaya 里的同一句。）
- **建议**：改为“看到‘五蕴的灭是常住的涅槃’，就进入正性决定。”
