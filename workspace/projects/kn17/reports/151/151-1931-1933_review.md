# Review — 151:1931-1933（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅 §1931 有 nissaya 单元，挂在句 151-1931-2-29 上；单元内容延伸到同段后半句 30-97 的 sīle / patiṭṭhāya / bojjhaṅge / balāni / indriyāni。§1932、§1933 无 nissaya，略过）

## 跨段一致性
- **大地譬喻的句式**：§1931 译“它们全都是依靠大地、立足于大地**才做成的**，这些需要出力的工作**就是这样做成的**”，谓语“做成”出现了两次；§1932 译“它们全都是依靠大地、立足于大地，这些种子类、草木类的植物**才这样得以**增长、增益、广大”，谓语只出现一次。两段巴利句式相同（sabbe te … nissāya … patiṭṭhāya evamete … karīyanti / āpajjanti），都只有一个谓语。→ 建议统一为 §1932 的结构，依据：原文句式与谓语数目。

## §1931 句 151-1931-2-29
- **问题**：句法 — nissaya 把 `ကမ္မန္တာ= အမှုကို`（宾格标记的受事）与 `ကရီယန္တိ= ပြုအပ်ကုန်၏`（被动，“被做”）配对，全句只有这一个谓语，由 evamete 收束。译文在“sabbe te … patiṭṭhāya”后先补了一个“才做成的”，又在 evamete 后再译一次“就是这样做成的”，多出一个谓语，句子显得重复。格、数的理解没有错：ye keci / balakaraṇīyā 的 `ကုန်သော` 表复数定语，译文“各种”“全都”对得上。
- **建议**：去掉前一个谓语，改为“……它们全都依靠大地、立足于大地，这些需要出力的工作才得以这样做成；”，与 §1932 句式一致。

## 原文疑问（nissaya 数据，不改）
- §1931 nissaya 单元里有几处缅文残缺或讹写：`သ်ီလေ`（应为 သီလေ）、`ဘာဝေိ`（应为 ဘာဝေတိ）、`ဘာဝေတိ= ၏`（释义缺 ပွါးစေ）。这些都不影响词法判断，记录在此备查。
