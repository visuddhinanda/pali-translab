# Review — 151:2032-2034（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅 §2033、§2034 有；§2032 无 nissaya，逐句意见略过）

## 跨段一致性
- **品末／论末结语格式**：§2033 把 `Mātikākathā niṭṭhitā` 译为“论母论结束。”，带“结束”。§2034 把 `Paññāvaggo tatiyo` 译为“第三慧品。”，没有“结束”。nissaya 在 §2034 补出了谓语 `နိဋ္ဌိတော= ပြီးပြီ။`（已结束），两处结语句式应当一致。→ 建议统一为“……结束。”，见 §2034 条。
- **引号配对（§2032 句间）**：句 151-2032-97-104 末尾有闭引号“……染污的生活”——”，但前面的句 151-2032-80-90、151-2032-91-96 都没有开引号，形成孤立的闭引号。本段其余各处 `…ti – …sampanno` 都用“……”——这是……具足”的格式，这一处应保持一致。→ 建议在句 151-2032-80-90 开头补上开引号“。（只涉及标点配对，不涉及词法。）

## §2034 句 151-2034-2-4
- **问题**：补出成分。nissaya 在 `Paññāvaggo tatiyo` 之后补出了隐含谓语 `နိဋ္ဌိတော= ပြီးပြီ။`（已结束）。`ပညာဝဂ္ဂေါ= ပညာဝဂ်သည်။` 是主格主语，`တတိယော= သုံးခုမြောက်ဖြစ်သော။` 是修饰它的定语（“第三的”）。由此可知这是品末结语，即“第三慧品〔结束〕”，而不是品题。现译“第三慧品。”读起来像标题，与 §2033 “论母论结束。”的结语句式也不一致。
- **建议**：改为“第三慧品结束。”

- **问题**：原文疑问（只作记录，不改）。这一行 nissaya 的内容远超出 pali 词段 2-4 的范围：它还包括本品的摄颂（uddāna：`ပညာ / ဣဒ္ဓိ / အဘိသမယော / ဝိဝေကော / စရိယပဉ္စမော / ပါဋိဟာရိ / သမသီသီ / သတိပဋ္ဌာနာ / ဝိပဿနာ … ဒသ`）、全书三品的总摄（`မဟာဝဂ္ဂေါ / ယုဂနဒ္ဓေါ / ပညာဝဂ္ဂေါ … တယော`）、赞颂偈（`အယံ ဂန္ထော … ဉာဏဇောတနံ`）、`ပဋိသမ္ဘိဒါမဂ္ဂပါဠိ နိဋ္ဌိတာ`，以及缅文抄本跋语。其中 `ယုဂနဒ္ဓေါ စ=` 还重复了一次，疑为录入讹误。现有译文只译了 pali 词段 2-4，做法正确，不应据 nissaya 把这些内容补进本句。需要另查 pali 原文是否在别的段落收有摄颂与总结偈，如果有，应在对应段落另行翻译。
