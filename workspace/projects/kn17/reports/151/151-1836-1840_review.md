# Review — 151:1836-1840（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1837-113~128、1840-27~39、1840-101~180 等句无 nissaya 单元，这些句略过不审）

## 跨段一致性

- **ñāṇa 与 paññā 都译成了“智慧”**（必改）：
  - ñāṇa 译“智慧”：§1836 34-56「智慧之门」；§1837 2-9、10-15、16-21「随佛世尊的智慧而转」；§1837 22-39「佛世尊的智慧没有障碍」；§1837 133-138；§1838 11-16。
  - 同一组语境里，§1837 40-132 的 ñāṇa 又译成了“智”。
  - paññā 译“智慧”：§1836 24-33「以智慧」；§1839 40-49、50-57、117-124；§1839 125-133「智慧无与伦比者」；§1840 181-189、190-196。
  - 这两个词在 nissaya 里有区分：ñāṇa = ဉာဏ်（တော်），paññā = ပညာ。本 chunk 的标题词又是“广慧”“无比慧”，所以建议 **ñāṇa 统一译“智”，paññā 统一译“慧”**，buddhañāṇa 保持“佛智”。
- **pavattati 与 parivattati 都译成了“运转”**（建议）：
  - nissaya 的释义不同：pavattati = ဖြစ်（生起、起作用），parivattati = လည်၍ဖြစ်（回旋而存在）。
  - §1837 56-60「智不会超出所知而运转」和 §1837 133-138「智慧在一切法上运转」里的 pavattati，建议改“起作用”或“运作”。
  - parivattati 保留“运转”。§1839 的“游动”“飞行”是按语境变通，可以接受。
- **asāmantapañña 前后译法不同**（必改）：§1839 125-133 前半句「智慧无与伦比者」，后半句「无比慧」。建议统一为“无比慧者”。
- **abhibhavitā 共 4 处**（§1840 18-21、27-30、36-39、88-91）：要改就一起改，见 §1840 句 151-1840-18-21。
- **māyā 与 sāṭheyya**：§1840 40-87 和 119-163 两份清单要同步改，见 §1840 句 151-1840-40-87。

## §1836 句 151-1836-2-23
- **问题**：风格（文言）。「知其所应知，见其所应见」用了文言虚词“其”。
- **建议**：改为“知道应当知道的，见到应当见到的”。nissaya 依据：ဇာနံ-ဇာနိတဗ္ဗံ= သိအပ်သော တရားအပေါင်းကို（应知的诸法，宾格）。
- **问题**：词义。nissaya 对 cakkhubhūto / ñāṇabhūto 等四词都作比喻解：စက္ခုဘူတော= မျက်စိသဖွယ် ဖြစ်（如同眼睛）。现在的译文「已成为眼」读来像实指。
- **建议**：可改为“他如同眼目，如同智，如同法，如同梵”。
- **问题**：词义。atthassa ninnetā：nissaya 作 အနက်ကို ထုတ်ဖော်၍ပြတတ်（引出并显示义理），「义理的引导者」偏离原意。
- **建议**：改为“阐明义理者”。
- **说明**：dhammassāmī 在 nissaya 里有异释 ဝါ= 因法而为人天之主。按 style.md 取主译，异释可作脚注备列。

## §1836 句 151-1836-34-56
- **问题**：风格（轻微）。「智慧之门」带“之”，ñāṇa 也应改为“智”（见跨段一致性）。
- **建议**：改为“佛世尊的智门前”或“佛世尊的智的门口”。

## §1836 句 151-1836-57-74
- **问题**：句法误读（必改）。
  - nissaya 的读法是：yaṃ kiñci = 任何的，jānitabbaṃ = 应知的，修饰 neyyaṃ nāma（名为所知的法），atthi = 有。nissaya 附注说得很明确：jānitabbaṃ 是 neyyaṃ 的释语，此处的 “taṃ sabbaṃ” 是多余的；关系从句到这里还没结束（အနိယ ဝါကျလည်း မဆုံးသေး），主句在下一句的 “sabbaṃ taṃ antobuddhañāṇe parivattati”。nissaya 在 75-123 句末又把 yaṃ kiñci jānitabbaṃ neyyaṃ nāma atthi → taṃ sabbaṃ 连读了一遍。
  - 现在的译文把 jānitabbaṃ 当成独立谓语，句子自成一句完结，还加了原文没有的主语“佛”。
- **建议**：译成未完结的关系从句，与下句衔接，例如“凡是有任何应当知道的、称为所知的东西——”，并删去“佛”。

## §1836 句 151-1836-75-123
- **说明**：nissaya 把前五个 attho 释作 အကျိုး（利益），后面的释作 အနက်（义），译文的区分与之吻合。
- **建议**：上句改动后，「这一切」应能回指上句的“凡是所知”。nissaya 依据：တံ သဗ္ဗံ= ထိုအလုံးစုံ（那一切，回指 yaṃ kiñci neyyaṃ）。可改为“……那一切都在佛智之内运转”。

## §1837 句 151-1837-66-69
- **问题**：隐含成分。nissaya 把 te dhammā 明确为“那些所知的法与能知的智”：ထိုသိအပ်သောတရား သိတတ်သော ဉာဏ်တော်တို့。「这些法」所指不清。
- **建议**：改为“所知与智这两种法彼此以对方为边际而存在”。§1837 129-132 同改。

## §1837 句 151-1837-70-95
- **问题**：词义（轻微）。nissaya 把 samuggapaṭala 释作匣子的盖与底这两片（ပအုပ်အပြင်）。「下面的盖板」说法别扭。
- **建议**：改为“就像匣子的上下两片严密地合在一起，下片不超出上片，上片不超出下片……”。

## §1839 句 151-1839-2-25
- **问题**：词形。nissaya 把 timitimiṅgalaṃ 作单数宾格、一条大鱼的名字：တိမိတိမိင်္ဂလငါးကြီး。译文拆成了“提米鱼、提米伽罗鱼”两种鱼，而且 timiṅgala 音译成“提米伽罗”也不准。
- **建议**：按 nissaya 改为“乃至提米提明伽罗大鱼”。如果坚持按并列复合词理解，音译也应改为“提明伽罗”。

## §1839 句 151-1839-58-110
- **问题**：补出成分（轻微）。nissaya 给 gūḷhāni ca paṭicchannāni ca 补出了 ṭhānāni：ဂူဠှာနိ(ဌာနာနိ)= လျှို့ဝှက်သော အရာဌာနတို့ကို（隐秘的事项、要点）。现在的「隐秘的和隐藏的问题」与前文的 pañhaṃ 混在了一起。
- **建议**：改为“询问隐秘和深藏的要点”。

## §1839 句 151-1839-111-116
- **问题**：词义。nissaya 把 upakkhittakā 释作 အနီးခြေရင်း၌ချထား（安置在近旁脚下的人），即投到座下的弟子。「追随者」太泛。
- **建议**：改为“他们也就都成了世尊座下的弟子”。

## §1839 句 151-1839-117-124
- **问题**：漏译与句法。
  - nissaya 补出了 eva：ဘဂဝါဧဝ= မြတ်စွာဘုရားသည်သာလျှင်（唯独世尊）。
  - atirocati 释作 သာလွန်၍တင့်တယ်（超越众人而辉耀），「大放光彩」丢了 ati-（超出他人）这层意思。
  - yadidaṃ paññāya 释作“以那佛智之慧”（တာယ ပညာယ= 以那慧），是具格，表示凭借。「这就是在智慧方面」说得含混，也不通顺。
  - 句末 -ti 释作 ဣတိတသ္မာ= ထို့ကြောင့်（因此），引出下一句。
- **建议**：改为“于是唯独世尊在那里凭着慧超群而光耀”。“因此”放到下一句的开头。

## §1839 句 151-1839-125-133
- **问题**：句法衔接。nissaya 以上句的 iti（因此）领起 aggo asāmantapañño，即“因此是最上的、名为无比慧者”。译文缺了这层因果关系。
- **建议**：改为“所以他是至高者，是无比慧者。‘导向无比慧’——这就是无比慧。”

## §1840 句 151-1840-18-21
- **问题**：时态与语法角色。nissaya 把 abhibhavitā 释作 နှိမ်နှင်းပြီ（已经制伏了，完成体）。这样它与上句的 abhibhuyyati（နှိမ်နှင်းတတ်၏ = 能制伏）构成“能制伏 / 已制伏”的对照。「是征服者」把这层对照丢了。
- **建议**：按 nissaya 改为“已经征服了，所以是广慧”。§1840 27-30、36-39、88-91 同改。
- **说明**：从词形看，abhibhavitā 也可以读作施事名词，这一点存疑，定案时取舍。

## §1840 句 151-1840-40-87
- **问题**：词义（必改）。paḷāsa 在 nissaya 里是 ဂုဏ်ပြိုင်ခြင်း（与人比功德、较量），译“恼害”与之不符。
- **建议**：改为“竞比”或“跋扈”。
- **问题**：译名疑似对调。
  - nissaya：māyā = မိမိအပြစ်မပေါ်အောင်လှည့်ပတ်ခြင်း（耍手段掩盖自己的过失），sāṭheyya = မရှိသောဂုဏ်ဖြင့်ပလွှားခြင်း（拿自己没有的功德夸耀）。
  - 按汉译传统，掩盖自己过失的是“谄”，假装有德、迷惑他人的是“诳”。现在 māyā 译“诳”、sāṭheyya 译“谄”，正好反了。
- **建议**：改为 māyā“谄”、sāṭheyya“诳”。如果这里沿用另一套译名体系，就在 terms.md 里登记清楚。
- **问题**：词义（建议）。
  - thambha：nissaya 作 မောက်မာခြင်း（傲慢、倔强），「顽固」只译出了一半。可以考虑“倔傲”。
  - sārambha：nissaya 作 ချုပ်ချယ်ခြင်း（压制、专横）。如果 paḷāsa 改成“竞比”，sārambha 的“争胜”就与它语义重叠了，可以考虑改成“专横”。
- **说明**：makkha 在 nissaya 里作“抹杀他人功德”。传统译“覆”可以保留。
- 以上改动都要同步到 §1840 119-163。

## §1840 句 151-1840-181-189
- **问题**：补出成分。nissaya 为 bhūripaññā 补出了主语：(တဿ ပညာ= ထိုသို့သော ပုဂ္ဂိုလ်၏ ပညာသည်)（具备这种慧的人，他的慧）。译文没有主语，「具备……的智慧」读来像是在说慧本身具备慧。
- **建议**：改为“他具备那如大地一般广阔、宽大的慧，所以他的慧是广慧”。

## §1840 句 151-1840-190-196
- **问题**：连接词误读。nissaya 把 api ca 释作 တနည်းကား（另一种解释是），表示换一种说法，不是递进。etaṃ 指的是下句列出的三个名称（下句 nissaya：ဣတိ ဧတံ= 这三个名称）。
- **建议**：改为“另一种解释：这是慧的别名——”。

## §1840 句 151-1840-197-202
- **问题**：句法与补出成分。
  - nissaya 把 bhūri / medhā / pariṇāyikā 三者都当作慧的名称：bhūri = 乐于实有法的慧，medhā = 迅速了知的慧，pariṇāyikā = 善于引导、指示的慧，iti etaṃ … paññāya adhivacanaṃ。
  - 译文「广、明、引导」把三个名词并列成了动作，没有点出它们都是慧的名称，结果与上句断开了。
- **建议**：改为“‘广’、‘明’、‘导引’（这些都是慧的名称），所以是广慧”。pariṇāyikā 要译成名词“导引”或“导者”，不要译成动词。
