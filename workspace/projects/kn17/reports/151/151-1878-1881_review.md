# Review — 151:1878-1881（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1878-29-31、44-46、59-61、74-76、132-149、150-165 以及 1879-58-67 这几句没有 nissaya 行，已略过）

## 跨段一致性

- **abhinimmināti**：§1878 句 166-201、§1880 句 11-23 和句 122-133 都译作“化作”。
  - nissaya 释为 `အဘိနိမ္မိနာတိ= ဖန်ဆင်း၏`，意思是“造出、化现出”，宾语是另一个身体或形色。
  - 汉语“他化作一个身体”容易读成“他自己变成”，主宾关系会被误读。
  - 建议三处统一改为“化出”或“变化出”。
- **kāya**：§1878 句 2-20 译“以身”（单音节），本 chunk 其余各处都译“身体”。
  - 建议统一为“用身体／以身体”。
  - 改动时要同步义注层引用的黑体被解释词。
- **kāyavasena / cittavasena … pariṇāmeti**：§1878 句 97-114 的改法（见下）同样适用于没有 nissaya 的句 132-149 和句 150-165（“依照心来转变身体”）。四句要一起改，句式保持对称。
- **okkamitvā**：§1878 句 115-131 的改法（见下）同样适用于句 150-165，两句要同步。
- **“…ijjhatīti – ñāṇavipphārā iddhi”**：§1881 句 10-17 和句 18-41 都把 ti 译成“这就是”，与各段结尾的 “Ayaṃ … iddhi”（这就是…神变）混成了同一种说法。nissaya 对两者的处理不同（见下），需要区分开。
- **iddhi / iddhimā**：iddhi 译“神变”，iddhimā 译“有神通的人”，同一词根用了两个译名。这是可选项：如果要保留，建议把这一分工登记进 `terms.md`。

## §1878 句 151-1878-97-114

- **问题**：词义与句法。pariṇāmeti 的 nissaya 是 `ပရိဏာမေတိ= ညွတ်စေ၏`，意思是“使…倾向、使…弯向”；kāyavasena 的 nissaya 是 `ကိုယ်၏အစွမ်းအားဖြင့်`，意思是“凭借身体的力量、随着身体”。
  - 译文“依照身体来转变心”，容易读成“把心变成别的东西”。
  - 后半句“依照身体来决意心”也不通顺。
- **建议**：改为“他就使心随着身体而转，并随着身体来对心作决意”或类似说法。重点是“使心倾向、依随身体”，不要用“转变”。

## §1878 句 151-1878-115-131

- **问题**：补出成分与主宾关系。okkamitvā 的 nissaya 是 `ဩက္ကမိတွာ= ကိုယ်၌သက်စေ၍`，意思是“使（乐想与轻想）落入、安住在身体里”。
  - 乐想与轻想是被安置的对象，地点是身体。
  - 译文“进入乐想与轻想之后”把关系倒了过来，成了修行者进入想。
- **建议**：改为“使乐想与轻想遍入身中之后，就用看得见的身体前往梵天界”。

## §1878 句 151-1878-166-201

- **问题 1**：nissaya 的读法。nissaya 按异读 rūpaṃ 作名词宾语来释（`ရူပံ= အဆင်းကို`），manomayaṃ、sabbaṅgapaccaṅgaṃ、ahīnindriyaṃ 都是它的修饰语。
  - 正文是 rūpiṃ（形容词“有色的”），译文补出中心词“身体”，在句法上说得通。
  - 但“化作”有歧义，见跨段一致性。
- **问题 2**：nissaya 疑似讹误。ahīnindriyaṃ 的释义是 `မဟုတ်သော`，应是 `မယုတ်သော`（不低劣）之误，§1880 句 11-23 的写法可以佐证。
  - 译文“诸根不缺”与正确的读法相合，不需要改。
- **建议**：只改“化作”为“化出”。

## §1879 句 151-1879-2-9；§1880 句 151-1880-2-10；§1881 句 151-1881-2-9

- **问题**：格式。巴利逐词加粗，译文照搬后出现了 `**变化****神变****？**` 这样的连写星号，在 markdown 里会渲染异常。问号单独加粗也没有意义。
- **建议**：改为 `**变化神变**？`、`**意所成神变**？`、`**智遍满神变**？`。如果被解释词需要分开，就在词之间留出非粗体的分隔。

## §1879 句 151-1879-10-37

- **问题 1**：词义。viññāpesi 的 nissaya 是 `ဝိညာပေသိ= သိစေ၏`，意思是“使…知道、使…了解”，比“听到”更进一层。
- **问题 2**：nissaya 疑似讹误。sahassilokadhātuṃ 的释义是 `တသောင်းသော`（一万），与巴利 sahassi（千）不符，应是 nissaya 的笔误。
  - 译文“千世界”与巴利相合，保留。
- **建议**：改为“他站在梵天界，用声音让千世界都听见并明白”，或“用声音告知千世界”。

## §1879 句 151-1879-68-155

- **问题**：nissaya 疑似讹误。supaṇṇavaṇṇaṃ 的释义误抄成了 `သူငယ်၏အသွင်`（少年的形貌），与前一条重复。
  - 译文“金翅鸟的形貌”是对的，保留，此处只作记录。

## §1880 句 151-1880-11-23

- **问题**：补出成分。idha 的 nissaya 是 `ဣဓ= ဤသာသနာတော်၌`，意思是“在这个教法中”，不是泛指的地点。
- **建议**：“在这里”改为“在这个教法中”。“化作”的改法见跨段一致性。句 122-133 不涉及 idha，只改“化作”。

## §1881 句 151-1881-10-17

- **问题 1**：句法。ti 的 nissaya 是 `ဣတိ-တသ္မာ= ထို့ကြောင့်`（因此），后接 `ဉာဏဝိပ္ဖါရာဣဒ္ဓိမည်၏`（名为智遍满神变）。
  - 这是在用词源作解释：因为舍断的意义“成就”（ijjhati），所以称为“神变”（iddhi）。
  - 译文“这就是”丢掉了这层因果和命名关系。
- **问题 2**：主语。pahānaṭṭho 的 nissaya 是 `ပယ်ခြင်းသဘောသည်`，是主格，也就是全句的主语；niccasaññāya 的 nissaya 是 `ကို`，是被舍断的对象。
  - 译文先说“以无常随观舍断常想”，再用“这舍断之义”回指，主语关系被拆散了。
- **问题 3**：文体。“之义”是文言写法，属于必改项。
- **建议**：改为“用无常随观舍断常想的这一意义得以成就（ijjhati），所以叫作智遍满神变（iddhi）。”
- **原文疑问**：巴利作 Aniccānupassanā，后文的 nibbidānupassanāya 等带 -āya；nissaya 都按具格 `-ာယ…ဖြင့်` 来读。这里疑似漏了 -ya，只作记录，不改。

## §1881 句 151-1881-18-41

- **问题**：与句 10-17 相同，即 ti 应译为“所以叫作”，并去掉“这舍断之义”中的“之”。同句里的 dukkhānupassanā、anattānupassanā 也有同样的 -ya 疑问。
- **可选**：nandiyā 的 nissaya 是 `နှစ်သက်ခြင်း`（欢喜、喜爱）。如果希望与 pīti（喜）区分开，可以译作“喜爱”。
- **建议**：改为“……用舍遣随观舍断执取的这一意义得以成就，所以叫作智遍满神变。”

## §1881 句 151-1881-42-56

- **问题**：补出成分。nissaya 把三个人名都释为 `…မထေရ်အား`（属格／与格，意为“对于…”），并补出谓语 `ဟောတိ= ၏`（有）。译文只是“尊者薄拘罗的智遍满神变”这样的名词短语罗列，缺了谓语。
- **建议**：改为“尊者薄拘罗有智遍满神变，尊者僧吉迹有智遍满神变，尊者部多波罗有智遍满神变。”

## §1878 句 151-1878-2-20

- **可选**：“乃至”属于 style.md 所列的“乃”类文言虚词边缘用法，可以改为“甚至到梵天界”。“以身”的问题见跨段一致性。
- 这几处都是被解释词，改动时必须同步义注层的黑体。
