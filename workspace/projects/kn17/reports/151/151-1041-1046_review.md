# Review — 151:1041-1046（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 跨段一致性

- **`X-e / X-āya pañcahindriyehi`（处格 + 隐含 pavattehi）的译法前后不一**：nissaya 一律是 `X= ၌`（处格），后接补出的 `(ပဝတ္တေဟိ= ဖြစ်ကုန်သော)`（“生起的”），再接 `ပဉ္စဟိ ဣန္ဒြိယေဟိ= တို့မှ`（从……五根）。现有译文混用两种语序：
  - 「从 X **中的五根**出离」：§1043 初禅/第二禅/第三禅/第四禅，§1044 如实知见，§1045 预流道/一来道/不还道/阿罗汉道
  - 「从 X **的五根中**出离」：§1043 各等至，§1044 各随观，§1045 各果等至
  → 建议统一为「从在 X 中生起的五根出离」（或统一为「从 X 中的五根出离」）。依据：nissaya 对禅、等至、随观、道、果同样标 `၌` + `ပဝတ္တေဟိ`，句法完全相同，译文不应因所接名词不同而换语序。
- **`-vasena` 的归属（§1043–§1045 全部同型句）**：nissaya 为 `ဒုတိယဇ္ဈာနဝသေန= အားဖြင့်။ (ပဝတ္တာနိ= ကုန်သော။) ပဉ္စိန္ဒြိယာနိ= တို့သည်။`，补出的 `pavattāni` 把 `vasena` 接到主语五根上，意思是“依第二禅而生起的五根”。现译「凭借第二禅，五根……出离」把 `vasena` 处理成修饰“出离”的状语，主宾关系被改了。→ 建议句型统一改为「依第二禅而生起的五根，从在初禅中生起的五根出离」，§1043、§1044（含 93-120、121-127）、§1045 全部同改。
- **`tadanuvattakakilesehi`（§1042 五句）**：nissaya 每句都明示先行词，例如 `ထိုအဿဒ္ဓိယသို့ အစဉ်လိုက်ကုန်သော ကိလေသာ`（随**不信**而转的烦恼）、`ထိုကောသဇ္ဇသို့…`（随**懈怠**…）。现译五句都作「随之而转的烦恼」，“之”可能被读成“热恼”或该根本身。→ 建议五句统一写出先行词：「随不信而转的烦恼」「随懈怠而转的烦恼」「随放逸……」「随掉举……」「随无明……」。
- **术语首现夹注不一致**：§1042 五个“义”（adhimokkha 等）以及 §1046 的 nekkhamma 都夹注了巴利原词，但 §1043–§1045 的较罕见术语没有夹注，例如舍遣随观（paṭinissaggānupassanā）、转离随观（vivaṭṭanānupassanā）、审察随观（paṭisaṅkhānupassanā）、增上慧法观（adhipaññādhammavipassanā），§1046 的法的确定（dhammavavatthāna）也没有。→ 建议按 style.md 统一在首现处夹注。
- **abyāpāda / byāpāda（§1046）**：byāpāda 译「瞋恚」，abyāpāda 却译「无瞋」，两者没有对称。→ 建议改为「无瞋恚」，或把两处都改用「瞋」。

## §1042 句 151-1042-22-51

- **问题**：补出成分。nissaya 为 `ဗဟိဒ္ဓါ= အပြင်ပမည်ကုန်သော။ သဗ္ဗနိမိတ္တေဟိ စ= အလုံးစုံသော သင်္ခါရနိမိတ်တို့မှလည်း`，nimitta 指的是**诸行之相**（saṅkhāranimitta）。现译「外在的一切相」没有交代所指。
- **建议**：改为「也从外在的一切诸行之相中出离」。不要用「行相」二字，因为本 chunk 里「行相」已经用来译 ākāra（§1042 句 2-13、14-21）。§1042 其余四句（52-81 / 82-112 / 113-142 / 143-172）同改。

## §1043 句 151-1043-2-77

- **问题**：补出成分。nissaya：`ပုဗ္ဗဘာဂေ= ပဌမဈာန်၏ ဥပစာဖြစ်သော ရှေးအဘို့၌`，即“在作为初禅近行（upacāra）的前分中”，并补出 `(ပဝတ္တေဟိ)`。现译「前分的五根」没有点明前分指的是什么。
- **建议**：改为「依初禅而生起的五根，从在前分（初禅的近行）中生起的五根出离」。句型按“跨段一致性”中的 vasena 与处格两条统一处理。
