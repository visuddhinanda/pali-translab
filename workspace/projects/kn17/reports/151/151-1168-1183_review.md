# Review — 151:1168-1183（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句没有 nissaya，这些句子略过）

## 跨段一致性

- **vatthuvasena / pariyāyena 套句**：nissaya 把两个状语分别归到两个分句。`ဝတ္ထုဝသေန` 管“一个成为十个”，`ပရိယာယေန` 管“十个成为一个”。现译把两者并列放在句首，同时管两个分句，分配关系丢失了，词义也有偏差，详见 §1178 句 151-1178-9-24。这个套句在本 chunk 出现 8 次，必须一并统一改：151-1178-9-24、151-1178-100-115、151-1179-21-36、151-1180-35-54、151-1181-9-26、151-1181-131-146、151-1182-26-43、151-1183-41-59。
- **paṭisaññutta 与 saññutta 撞译**：§1169、§1170 的 rūpappaṭisaññutta 和 arūpappaṭisaññutta 译作“相系”，§1174 的 saññutta 也译作“相系解脱”。两个不同的巴利词用了同一个汉译，读者会以为 §1169 和 §1174 说的是同一类。nissaya 的释义也不同：paṭisaññutta 是 `စပ်သော`（关联、有关），saññutta 是 `ယှဉ်သော`（相合、相应）。建议把 paṭisaññutta 改为“与色有关的”“与无色有关的”，“相系／离系”留给 saññutta 和 visaññutta。
- **§1181–1183 中 -to／ablative 宾项译法不统一**：同一结构 `X-to sammohā aññāṇā`，前三项译“视为常／视为乐／视为我的愚痴”，后七项译“对喜／对贪／对集……的愚痴”。§1178 的 nissaya 给十项的格式完全相同（`X-အားဖြင့်`，“以 X 的方式”）。“视为集”“视为相”讲不通，所以应统一为一种句式，例如一律用“对常的愚痴、无知”……“对执着的愚痴、无知”。151-1182-2-25 和 151-1183-2-40 的“视为常”要同步改。
- **ādāna 与 abhinivesa**：“执取想”和“执着想”在汉语里几乎分不开。nissaya 的释义是：ādāna = `စွဲယူလက်ခံ`（抓取、领受），abhinivesa = `အတ္တဟု နှလုံးသွင်း`（作意为我、执为我）。建议 abhinivesa 改为“执我想”或“妄执想”，§1178–1183 全部同步。
- **“所以是想解脱／智解脱”**：nissaya 句末用 `မည်၏`（名为、叫作），说明这是一个命名判断。建议全 chunk 统一为“所以叫作想解脱／智解脱”。这是建议项，不是必改。
- **粗体格式**：多处是“\*\*解脱\*\*\*\*？\*\*”这样连续的粗体标记，渲染时容易出错，建议合并或去掉问号上的粗体。

## §1169 句 151-1169-6-12

- **问题**：补出成分。nissaya 释 `ရူပပ္ပဋိသညုတ္တော= ရုပ်နှင့်စပ်သော ရူပဈာန်ဟု ဆိုအပ်သော`，补出了所指“即色界禅”。译文只写“与色相系的”，读者看不出指的是什么；“相系”还和 §1174 撞译（见上）。
- **建议**：改为“与色有关的解脱（即色界禅）——这就是有味解脱。”

## §1170 句 151-1170-6-12

- **问题**：同上。nissaya 补出“即无色界禅”：`အရူပပ္ပဋိသညုတ္တော= ရုပ်နှင့်မစပ်သော အရူပဈာန်ဟုဆိုအပ်သော`。
- **建议**：改为“与无色有关的解脱（即无色界禅）——这就是无味解脱。”

## §1171 句 151-1171-2-6

- **问题**：粗体和词的对应错位。nissaya 释 `နိရာမိသာ= အာမိသကင်းသည်ထက်`（比无味）、`နိရာမိသတရော= သာ၍ အာမိသကင်းသော`（更无味的）。nirāmisataro 对应的应是“更无味的”整体，现在“更”没有加粗。
- **建议**：改为“什么是\*\*比无味\*\*\*\*更无味的\*\*\*\*解脱\*\*？”

## §1172 句 151-1172-2-5、151-1172-18-21

- **问题**：词法提示，建议项。nissaya 释 `ပဏိဟိတော= တဏှာဖြင့် တောင့်တအပ်သော`，是被动分词，意思是“被渴爱所愿求的”。“有愿／无愿”是通行译法，可以保留，但要知道这里是“被愿求”而不是“自己有愿”。
- **建议**：维持“有愿／无愿”，不改。

## §1178 句 151-1178-9-24

- **问题**：句法误读，必改。nissaya 的分句是：`ဧကော သညာဝိမောက္ခော ဝတ္ထုဝသေန ဒသ … ဟောန္တိ (ဣတိ စ) သိယာ` 和 `ဒသ … ပရိယာယေန ဧကော … ဟောတိ (ဣတိ စ) သိယာ`。vatthuvasena 只管“一成十”，pariyāyena 只管“十成一”。词义也有问题：
  - `ဝတ္ထုဝသေန= နိစ္စသညာစသောဝတ္ထု၏ အစွမ်းအားဖြင့်`：vatthu 指常想等所要脱离的对象，不是“所依的事物”。
  - `ပရိယာယေန= လွတ်ခြင်းပရိယာယ်အားဖြင့်`：意思是“就‘解脱’这一含义而言”，不是“按不同的角度”。
- **建议**：“从所脱离的事物（常想等）来说，一个想解脱可以成为十个想解脱；从‘解脱’这一含义来说，十个想解脱可以成为一个想解脱。”跨段 8 处同步改（见上）；§1181–1183 把“常想等”改为相应的对象。

## §1178 句 151-1178-28-35（同类：-36-42、-43-49、-50-56 及 -57 至 -99）

- **问题**：补出成分。nissaya 补出 `(ပဝတ္တာယ= ဖြစ်သော)`，`niccato … saññāya` 意为“从以常的方式生起的想中”。“常想”的压缩译法可以接受，但句末“所以是”应按 `မည်၏` 作命名（见跨段一致性）。
- **建议**：“……从常想中解脱，所以叫作想解脱。”

## §1178 句 151-1178-50-56

- **问题**：取义。nissaya 释 `နန္ဒိယာ= နှစ်သက်သောအားဖြင့်`，是喜爱、爱乐的意思。“喜想”容易和禅支的喜（pīti）混淆。
- **建议**：改为“喜爱想”；§1181-60-69 的“对喜的愚痴”同步改为“对喜爱的愚痴”。

## §1181 句 151-1181-9-26

- **问题**：句法误读，必改。句末 `siyāti` 里的 ti 是引出被解释词的标记，nissaya 释为 `သိယာတိဧတ္ထ= ဟူသောပုဒ်၌`（“在‘可以’这个词上”），它接的是下一句的设问 `Kathañca siyā`，表示“关于‘可以’：怎么说可以呢？”。现在把它译成独立的“这是说‘可以’”，意思不通。前半句的 vatthuvasena / pariyāyena 问题同 §1178。
- **建议**：前半句按套句改法改；句末改为“所谓‘\*\*可以\*\*’——”，接下句“怎么说可以这样呢？”

## §1181 句 151-1181-30-39（同类：§1181-40 至 -130、§1182-2-25、§1183-2-40）

- **问题**：格与句法。nissaya 释 `အနိစ္စာနုပဿနာ= အနိစ္စာနုပဿနာဟုဆိုအပ်သော`、`ယထာဘူတံ ဉာဏံ= ယထာဘူတဉာဏ်သည်`。Aniccānupassanā 是主格同位语（“叫作无常随观的那个如实智”），不是属格。“无常随观的如实智”中的“的”容易读成“属于无常随观的智”。
- **建议**：改为“无常随观这一如实智……”，十项和 §1182、§1183 同步改。
