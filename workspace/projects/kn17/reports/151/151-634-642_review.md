# Review — 151:634-642（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **sevati**：§636 的 `sevantaññeva` 各句都译「受用」，§639 的 `sevanti / seviṃsu / sevissanti` 译「亲近」。nissaya 两处都作 `မှီဝဲ`（依止、奉行），是同一个动词。「受用出离」「受用光明想」搭配不通，因为出离、光明想不能被「受用」。
  - 建议：§636 改为「奉行」或「亲近」，与 §639 统一。
- **sevantaññeva jānāti**：同一句巴利，§636-19-22、§636-49-52 译「就了知」，§636-34-37、§636-107-110、§636-169-172 等译「也了知」。巴利完全相同。nissaya 只有 `ပင်လျှင်`（正是、即便），没有「就／也」的区分，这是译文自行加的分化。
  - 建议：统一为「即使对正在奉行欲的人，也了知：」这一类句式。它对前后两种情况都成立，又能体现 `-eva` 的强调。
- **adhimutta / adhimuttika / adhimutti**：§636 的 `kāmādhimutto` 等译「倾心于」，§639 的 `hīnādhimuttikā` 等译「倾向于」，名词 `adhimutti` 译「胜解」。nissaya 三处同作 `နှလုံးသွင်း(ညွတ်ကိုင်း)ခြင်း`（心的倾向）。同一词根在同一节里用了三个译法，读者看不出 §636 的 `-adhimutto` 与 §639 的 `adhimutti` 是同一个概念。
  - 建议：形容词统一为「倾向于」或「倾心于」中的一个。名词「胜解」可以保留，但应与形容词形成可辨认的对应。
- **paṭigha 与 byāpāda 撞译**：§637 的 `paṭighānusayo` 译「瞋恚随眠」，§636 的 `byāpāda` 也译「瞋恚」。nissaya 分别保留 `ပဋိဃ` 与 `ဗျာပါဒ` 两个术语，没有合并。两词同译会让读者以为是同一个巴利词。
  - 建议：`paṭighānusaya` 改为「瞋随眠」，`byāpāda` 保留「瞋恚」。
- **bhabba / abhabba**：§635、§640、§641 都译「有能力／没有能力」，前后一致。但这个译法过泛，见 §635 句 151-635-13-32。

## §635 句 151-635-13-32

- **问题**：取义 — `bhabbābhabbe satte`= `ကျွတ်ထိုက်မကျွတ်ထိုက်ကုန်သော`，意思是「值得得解脱、不值得得解脱的」。§640 的 `abhabbā niyāmaṃ okkamituṃ` 也作 `မထိုက်`（不堪、不够格进入），所指是有没有能力证入圣道。译文「有能力的众生」没有说明是什么能力，读起来像泛指才能。
- **建议**：改为「能够证入正道的众生和不能证入正道的众生」，或者保留「有能力／没有能力」，在首次出现处补「（证悟）」。§640、§641 照此同步。

## §635 句 151-635-47-158

- **问题**：取义 — nissaya 把这四句中的 `tathāgato` 一律释为 `သတ္တဝါ`（众生），也就是把这里的 tathāgata 理解为「有情、众生」，而不是佛陀。译文作「如来死后存在」等。这是传统通行译法，不算误译，但与 nissaya 的取义不同。
- **建议**：正文可以保留「如来」。在 footnote 步补注：nissaya 释此处 tathāgata 为「众生」。

## §636 句 151-636-2-18

- **问题**：语法误读 — `idappaccayatāpaṭiccasamuppannesu dhammesu`= `ဣဒပ္ပစ္စယတာမည်သော အကြောင်းတရားနှင့်,စွဲမှီ၍ဖြစ်သော အကျိုးတရားတို့၌`。nissaya 用 `နှင့်`（与）连接，读作并列复合：「称为此缘性的因法」与「缘生的果法」两类。译文「由此缘性而缘起的诸法」把它读成依主关系，只剩果法，漏掉了因法。
- **建议**：改为「对于此缘性与缘起的诸法」，或「对于作为此缘性的因法和缘生的果法」。
- **问题**：补出成分 — nissaya 把 `anulomikā` 释为 `လောကုတ္တရာ တရားအားလျော်သော`（随顺于出世间法的）。译文「随顺忍」没有交代随顺什么。另外 nissaya 补出隐含施事 `(သတ္တေဟိ)`（被众生获得）。前句已有「众生」，可以不补。
- **建议**：可写成「获得了随顺（出世间法）的忍」。这一处由译者斟酌，非必改。
- **问题**：连接词 — nissaya 把 `pana` 释为 `ထိုမှတပါး`（除此之外、另外），把 `ete vā` 的 `vā` 释为强调（`ပင်လျှင်`），不作「或者」。句中表示选择的是后面的 `khanti vā … ñāṇaṃ vā`，这两处 nissaya 都标了 `ဝါ`。
- **建议**：句首「或者」改为「另外」或「又有」，句中保留「…随顺忍，或者获得了如实的智」。

## §637 句 151-637-50-65

- **问题**：格与词义 — `imesu dvīsu dhammesu` 是处格，nissaya 作 `၌`，即「在这两种法（可意、不可意所缘）中」。`anupatitā`= `အစဉ်လိုက်လျက် ကျရောက်၏`，意思是随之落入、伴随，不是 `anuseti`（潜伏）。译文「无明随着这两种法而潜伏」有两处偏差：把处格读成了「随着」，又把动词换成了上文的「潜伏」。
- **建议**：改为「这样，在这两种法中，无明都随之落入；应当知道，与它同处的慢、见、疑也是如此」。
- **问题**：隐含成分 — nissaya 把 `tadekaṭṭho` 释为「与那无明（随眠）同处的」，译文「与它同处」中的「它」指代清楚，可以保留。`daṭṭhabbā`= `မှတ်အပ်၏`（应当知道、应当记取），译「应当这样看待」可以接受。

## §638 句 151-638-6-13

- **问题**：术语所指 — `parittabhūmako`= `ကာမဘုံ၌…ဖြစ်သော`（属于欲界地的），`mahābhūmako`= `မဟဂ္ဂုတ်ဘုံ၌…ဖြစ်သော`（属于广大地，即色界、无色界的）。译文直译成「小地」「大地」。「大地」在现代汉语里指地面、土地，读者必然误解。这是必改项。
- **问题**：句法 — nissaya 把这两个修饰语放在三种行之前，表示它们修饰三行。译文把它们放在句末用「或者」并列，读起来像是第四、第五项。
- **建议**：改为「属于有限地（欲界）或属于广大地（色界、无色界）的福行、非福行、不动行」。

## §642 句 151-642-2-4

- **问题**：补出成分 — nissaya 补出 `နိဋ္ဌိတော`（完毕），译文的「完毕」有依据。不过「第六十九意乐随眠智的解说完毕」把序数直接粘在名称上，与 §634 的标题「69. 意乐随眠智的解说」对不齐，读起来也别扭。
- **建议**：改为「第六十九，意乐随眠智的解说完毕。」
