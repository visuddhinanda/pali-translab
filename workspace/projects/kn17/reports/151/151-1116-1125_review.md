# Review — 151:1116-1125（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1117、1119、1120 前半、1121–1124 部分句有 nissaya；其余句无 nissaya，不出意见）

## 跨段一致性

- **upaṭṭhāna / upaṭṭhāpeti / upaṭṭhita**：§1120 upaṭṭhānaṭṭhena 译“现起”，§1121、§1122 upaṭṭhāpeti / upaṭṭhāpitaṃ 译“立念”，§1124 upaṭṭhitassati 译“念已现起”。同一词根有两套译法，“立念”还补出了原文没有的“念”。nissaya：`ဥပဋ္ဌာနဋ္ဌေန= ထင်သော သဘောအားဖြင့်`（显现的性质），`ဥပဋ္ဌာပေတိ= ထင်စေ၏`（使显现，使役）。→ 建议统一用“现起”这个词根：upaṭṭhāpeti 译“使念现起”，upaṭṭhāpitaṃ 译“已使念现起”，§1124 保持“念已现起”。另一个办法是三处都改用“确立”系列。
- **samādhi / samādahati / samāhita**：§1120 samādhindriyaṃ 译“定根”，§1121、§1122 samādahati / samādahitaṃ 译“专注”，§1124 samāhito 译“心得定”。动词“专注”和“定根”“得定”脱了钩，读者看不出它们同出一源。nissaya：`သမာဒဟန္တော= ကောင်းစွာထားသည် ဖြစ်၍`（把心好好安置）。→ 建议统一为“定”系列，例如 samādahati 译“使心得定”，samādahitaṃ 译“心已得定”，与 §1124“心得定”和定根对应。
- **yaṃ … taṃ 关系句**：§1120 三处“那普眼就是慧根”（14-18、50-54、149-153），以及 §1123“那佛眼就是佛智，那佛智就是佛眼”，都把关系代词 yaṃ 译成了指示词“那”，关系结构没有了，读起来像“那只普眼”。四处需按同一方案改，见下文 §1120 句 151-1120-14-18 和 §1123。
- **“没有慧没触到的”**：§1120 43-49 和 143-148 两处措辞相同，都有歧义（见下文 §1120 句 151-1120-43-49）。143-148 没有 nissaya，但应随 43-49 一起改，保持一致。
- **apparajakkha / mahārajakkha**：§1123 与 §1124 黑体被解释词目前一致，都是“眼中尘垢少／多”。如果按下文 §1123 的建议补出“慧眼”，§1123、§1124 的黑体以及 §1124 各句的谓语都要同步改，不能只改一处。

## §1117 句 151-1117-2-9

- **问题**：补出成分 / 漏分 — nissaya 把三项拆开，每项各自补出 `ကိဉ္စိ … န အတ္ထိ`，并分出时态：
  - `အဒိဋ္ဌံ … မရှိ`（现在没有未见的）
  - `အဝိညာတံ … မရှိခဲ့`（过去没有未识知的）
  - `အဇာနိတဗ္ဗံ= လမသိအပ် မသိနိုင်သော … မရှိလတ္တံ့`（将来没有不能知道的）

  译文把 aviññātaṃ 和 ajānitabbaṃ 合成了一个“没有了知、不能知道的”，三项并列变成了两项。
- **建议**：至少把三项分开，例如“在这世间，没有什么是他没有见到的，也没有什么是他没有识知的，没有什么是他不能知道的”。nissaya 的三时区分可以斟酌是否体现，比如加“过去”“将来”，但不强求。另外 idha，nissaya 作 `ဤသုံးပါးသော လောကဓာတ်၌`（这三种世间），“这世间”可以保留。
- 附带核对：§1118 的 nissaya 也并在本段里。tathāgato 是 abhiññāsi 的主语（`မြတ်စွာဘုရားသည်`），tena = 因此，vuccati = 被称为。§1118 译文“凡是可以知道的一切，他都已证知，所以如来被称为普眼”，格位和成分都对得上，没有问题。

## §1120 句 151-1120-14-18

- **问题**：句法误读（必改）— nissaya：`ယံ-ယေန= အကြင်ဉာဏ်ကြောင့်`、`တံ= ထိုဉာဏ်သည်`，也就是把 yaṃ 读作 yena：“由于哪一种智而被称为普眼，那种智就是慧根”。主语是“智”，不是“普眼”本身。译文“那普眼就是慧根”不但没有体现这层意思，还把关系代词 yaṃ 译成了指示词“那”。
- **建议**：改为“使他成为普眼的那种智，就是慧根”。如果要贴近字面，也可以译作“所谓普眼，就是慧根”，但至少要去掉指示词“那”。§1120 50-54、149-153 同样处理。

## §1120 句 151-1120-43-49

- **问题**：句法歧义（必改）— nissaya：`ပညာယ= ဖြင့်`（被慧，具格）、`အဖဿိတော= မတွေ့အပ်သော`（未被触及的）、`ဒုက္ခဋ္ဌော … နတ္ထိ`（这样的苦义不存在）。译文“没有慧没触到的苦义”可以读成“没有慧”“缺乏慧”，具格施事和否定存在句的关系不清楚。
- **建议**：改为“没有哪一种苦义是慧没有触到的——所以是普眼”。§1120 143-148 同样改为“没有什么是慧没有触到的——所以是普眼”。

## §1120 句 151-1120-50-54

- **问题**：同 151-1120-14-18，yaṃ 应读作 yena（nissaya `ယံ-ယေန= ကြောင့်`）。
- **建议**：与 14-18 统一改法。
- 注：本句 nissaya 末尾的 `ပညိန္ဒြိယဿ= ၏` 属于下一句 55-68，是切分边界的问题，与译文无关。

## §1121 句 151-1121-8-13

- **问题**：补出成分 — nissaya `ဥပဋ္ဌာပေတိ= ထင်စေ၏` 是使役“使显现”，没有补出“念”。译文“立念”自己补了宾语，词根也和 §1120“现起”、§1124“念已现起”不一致。
- **建议**：按跨段一致性一节统一，例如“信的时候也在使念现起，使念现起的时候也在信”。§1121 其余含 upaṭṭhāpeti 的句子，以及 §1122 含 upaṭṭhāpitaṃ 的句子，同步修改。

## §1121 句 151-1121-74-79

- **问题**：术语 — nissaya `သမာဒဟန္တော= ကောင်းစွာထားသည် ဖြစ်၍`（把心好好安置），对应定根的“定”。译文“专注”和 samādhindriya、samāhito 的译法脱节。
- **建议**：按跨段一致性一节统一为“定”系列，例如“使心得定的时候也在了知……”。§1121、§1122 含 samādahati / samādahitaṃ 的各句同步修改。

## §1123 句 151-1123-2-40

- **问题 1**：句法（必改）— nissaya：`ယံ= အကြင်ဉာဏ်သည်… ဗုဒ္ဓစက္ခုမည်၏ / တံ= ထိုဉာဏ်သည်… ဗုဒ္ဓဉာဏ်မည်၏`，意思是“被称为佛眼的那种智，就是佛智”。译文“那佛眼就是佛智”把 yaṃ 译成了指示词。
- **建议**：改为“所谓佛眼，就是佛智；所谓佛智，就是佛眼”，或者“被称为佛眼的智，就是佛智……”，与 §1120 的改法同一体例。
- **问题 2**：关系结构 — `ယေန စက္ခုနာ= အကြင်စက္ခုဖြင့်` 是关系具格，“如来用来看见众生的那种眼”，用来说明前面的佛眼。译文另起一句“如来用这只眼”，“这只眼”还容易让人以为是肉眼。
- **建议**：改为“如来就是用这种眼看见众生的：……”，或者直接并入前句。
- **问题 3**：补出成分 — nissaya `အပ္ပရဇက္ခေ= ပညာမျက်စိ၌ နည်းသော ကိလေသာမြူရှိကုန်သော`（慧眼里烦恼尘少的），明确补出了“慧眼”和“烦恼尘”。译文“眼中尘垢少”没有说是哪只眼，读者可能理解成肉眼进了灰尘。
- **建议**：改为“慧眼中尘垢少／多”。§1124 的黑体被解释词和各句谓语一并同步修改，见跨段一致性一节。
- **问题 4**：语体小处 — 句中先用“有的”，到最后一对换成“有些人”。pali 在最后一对才出现 appekacce（nissaya `အချို့`），换词有依据，但读起来不连贯。
- **建议**：可以保留“有些人……有些人……”来标出原文的 appekacce，也可以全句统一用“有的”，两种都行。

## §1124 句 151-1124-2-12

- **问题**：nissaya 只给了参照（`ရှေးစာမျက်နှာ အမှတ် ၁၂၉ နိဿယနှင့် တူပြီ`），词法与 §1123 相同。黑体“眼中尘垢少”“眼中尘垢多”目前和 §1123 一致。
- **建议**：如果 §1123 改为“慧眼中尘垢少／多”，本句黑体和 §1124 各句谓语必须逐字跟着改。
