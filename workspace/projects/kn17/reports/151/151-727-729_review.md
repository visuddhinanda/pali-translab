# Review — 151:727-729（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，这些句已略过）

## 跨段一致性

- **attā 与 ahaṃ 混用「我」**（必改）：nissaya 把两者分得很清楚，`အဟံ= ငါ`（第一人称“我”），`အတ္တာ= အတ္တ-အထည် ကိုယ်`（作为实体的“自我”）。译文却有两种译法：
  - 引语内的 `me attā` 译作「我的**自我**」，见 §728、§729 句 23-29 / 103-109 / 97-103。
  - 标题句和结论句的 `attato` / `attānaṃ` / `attani` / `attañca` 都译作「**我**」，见 §727 句 2-10、11-26、36-50、145-149，§728 句 2-7、43-46、169-173，§729 句 2-7、39-42、113-116、157-161。
  - 这样在 §727 句 36-50 里，`ahaṃ`（“我就是意触所生的思”）与 `attañca`（“把意触所生的思与我视为不二”）都成了「我」，读者分不清哪个是说话人、哪个是被执取的自我。
  - **建议**：attā 统一译「自我」，ahaṃ 保留「我」。例如「怎样把诸行视为自我？」「他把意触所生的思与自我视为不二」「把自我视为具有诸行的」「把诸行视为在自我之中」。
- **saṅkhāra 译「诸行」还是「行」**：标题句和结论句译「诸行」，`imehi saṅkhārehi` / `ime saṅkhārā` 译「这些行」，复合词 `saṅkhāravatthukā` 译「以行为所依」。带指示词时省「诸」是合理的。但同为复数宾格 `saṅkhāre`，§727 句 2-10 和 §729 句 2-7 都译「诸行」，已经一致，这一点可以保持。**无须改动**，只是提醒统稿时不要再引入第三种译法。

## §727 句 151-727-36-50

- **问题**：句法（轻微）。nissaya 把 `advayaṃ` 释为 `နှစ်ခုမပြား တသားတည်းပြု၍`，意思是“不分为二、当作一体地”，作 samanupassati 的方式状语，宾语是 `cetanañca`、`attañca`（均为 `ကို၎င်း`，并列宾格）。译文「视为不二」把它当成了结果补语，意思大体不差，但“不二”偏佛学套语，一般读者不易懂。
- **建议**：可改为「他把意触所生的思和自我看作一体、不分为二」，同时把 attā 改为「自我」（见跨段一致性）。§727 句 82-104 也照此改。

## §727 句 151-727-51-74

- **问题**：格。nissaya `တေလပ္ပဒီပဿ= ဆီမီး၏` 是属格，表示“油灯的”，所修饰的是后文的 `acci`（火焰）和 `vaṇṇa`（光色）。译文「对一盏燃烧着的油灯」把属格改成了对象介词“对”，火焰、光色同油灯的从属关系没有表达出来。另外译文补出了主语「有人」，原句并无主语，承上省略。
- **建议**：可改为「譬如一盏正在燃烧的油灯，有人认为它的“火焰就是光色，光色就是火焰”，把火焰与光色看作一体、不分为二」。也可以保留现有句式，但要把“油灯的火焰与光色”的属格关系补出来。

## §727 句 151-727-133-144（§728 句 157-168、§729 句 145-156 同）

- **问题**：语气（轻微）。nissaya `သညောဇနာနိ= သံယောဇဉ်တို့သာမည်ကုန်၏` 带限定词 `သာ`，意思是“**只**名为结”。译文「这些是结，而不是见」少了这层限定语气。
- **建议**：可改为「这些只是结，而不是见」，三段统一改。

## §728 句 151-728-43-46、§729 句 151-729-77-80

- **问题**：数据对齐（不涉及译文）。这两行所挂的 nissaya 末尾是 `သေယျထာပိ= ဥပမာအားဖြင့်။ ရုက္ခော= သစ်ပင်သည်။` 和 `ပုပ္ဖံ= ပန်းသည်။ ဂန္ဓသမ္ပန္နံ= …`，实际是下一句譬喻起首（句 47-51 / 43-47）的释义，与本行原文不对应。拿后面这两句的译文对照：「譬如有一棵树，树荫浓密」「譬如有一朵花，香气浓郁」，主格和 `assa`（假设语气“会是”）都没有问题。
- **建议**：译文不用改。这是 nissaya 单元错位，记入已知数据问题即可。
