# Review — 151:1110-1115（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本 chunk 只有 §1111 句 151-1111-2-15 带 nissaya，其余句略过）

## 跨段一致性
- parivāra：§1113 句 151-1113-70-97、151-1113-98-105，以及 §1114 句 151-1114-50-57 都译作“眷属”。但在 §1113 句 151-1113-2-36 和 §1114 句 151-1114-2-17 中，复合词 `adhimokkha-parivāraṃ` 等里的 parivāra 被译成“作用”。同一个词在同一 chunk 里有两种译法，建议统一为“眷属”。另外，原句的主语是 `saddhindriyaṃ` 等（主格），“adhimokkhaparivāraṃ hoti”的意思是“信根是以胜解为方式的眷属”，现译把它拆成“以信根为眷属，信根以胜解为其作用”两层，结构走样。建议这两句一并改为“信根是〔未知当知根〕以胜解为方式的眷属……”这类格式。

## §1111 句 151-1111-2-15
- **问题**：风格 — “诸漏灭尽之智”的“之”是文言虚词，属于必改项。
- **建议**：改为“诸漏灭尽的智”。

- **问题**：格与句法 — 依据是 `ခယေဉာဏံ= ကုန်ခြင်း၌ဖြစ်သော ခယဉာဏ်မည်၏`：`khaye` 是处格（`၌`），意思是“在灭尽中生起的”智，nissaya 把它作为专名“灭尽智”处理。现译“诸漏灭尽之智”把处格关系读成了属格式的修饰，意思差别不大，但名称不够明确。
- **建议**：译为“诸漏灭尽时的智（漏尽智）”，或直接用“漏尽智”。

- **问题**：格与句法 — 依据是 `တိဏ္ဏန္နံ ဣန္ဒြိယာနံ= သုံးပါးကုန်သော…တို့၏`（属格）和 `ဝသီဘာဝတာ= လေ့လာသော အဖြစ်ဟု ဆိုအပ်သော`（“称为熟练／自在状态的”，修饰 `ပညာ`）。nissaya 的读法是“三根的自在状态，也就是这种慧”，vasībhāvatā 与 paññā 是同位关系。现译“对三根获得自在的慧”里的“对”没有体现属格，“获得”是另外补出的动作。
- **建议**：改为“以六十四种行相在三根上的自在性，这种慧就是诸漏灭尽时的智”，或保持现在的句式，把“对三根获得自在”改为“三根达到自在的”。

- **备注（数据）**：本句的 nissaya 末尾附有一段内容（`[ဤမှစ၍ … တူပြီ]` 之后的 `အနဝသေသော … ခီယန္တိ`），注明它与 book 111 §107 的 nissaya 相同。实际对应的是 §1115 句 151-1115-82-90 和 151-1115-91-94，其中 `ဧတ္ထ= ဤအရဟတ္တမဂ်၌`（“在这阿罗汉道中”）。这段内容和坐标没有对齐，本次没有用它审 §1115。
