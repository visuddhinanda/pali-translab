# Review — 151:554-558（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 跨段一致性
- 被解释词：§555 问句里的“种种法”“阐明”“显示义利”，在 §555–557 的黑体词中逐字一致。§557 结句引文与 §555 问句的译文也完全相同。✅
- pakāsanatā / pakāseti 一律译“阐明”，sandasseti 一律译“显示”。两组动词区分清楚，前后统一。✅
- §557 的 °atthaṃ 系列（nekkhamma° / abyāpāda° / ālokasañña° / avikkhepa° / dhammavavatthāna° / ñāṇa° / pāmojja° / paṭhamajhāna° / arahattamagga°）一律译“X的义利”，pajahanto 一律译“断除……的人”，体例统一。若按下文 §557 句 151-557-2-8 的建议调整，须整组同步改。
- 标题：§554“三十九、显示义利智的解说”与 §558“第三十九 显示义利智的解说（完）”名称一致。✅

## §557 句 151-557-2-8
- **问题**：句法（同位关系）。nissaya 的释义是 `နေက္ခမ္မတ္တံ= နေက္ခမ္မ ဟူသော အကျိုးကို`，意思是“名为出离的那个利益（宾格）”。`ဟူသော` 表示同位关系，说明 nekkhamma 就是这里的 attha，是持业释，不是“出离所具有的义利”。译文“出离的义利”读起来容易被当成领属关系。
- **建议**：可考虑改为“显示出离这一义利”。这样改的话，本段其余八处 °atthaṃ 要统一改成“X这一义利”。如果维持“X的义利”，也要全组保持不变。此项是可选改进，不是必改。

## §557 句 151-557-2-8
- **问题**：补出成分 / 异释。nissaya 对 pajahanto 给了两解。主解是 `စွန့်သော ယောဂီပုဂ္ဂိုလ်သည်`，即“断除的瑜伽行者（主格）”。异解（`ဝါ=`）是 `စွန့်စေသော ဒေသကပုဂ္ဂိုလ်သည်`，即“令人断除的说法者”。译文“断除欲贪的人”取的是主解，词法无误。
- **建议**：正文不动。按 style.md 第四节“异释作脚注备列”，footnote 步可以把“或解作：令人断除欲贪的说法者”列为脚注，挂在本段首句即可，后面各句不必重复。

## §557 句 151-557-52-58
- **问题**：词义细节。
  - pajānanaṭṭhena 的 nissaya 是 `အပြားအားဖြင့် သိတတ်သော အနက်သဘောကြောင့်`，意思是“因为能以种种方式了知的意义”，其中的 pa- 前缀 nissaya 明确释为“种种、各别”（`အပြားအားဖြင့်`）。译文“了知”没有体现这一点，和前半句的“知”区分不够。
  - taṃ 的 nissaya 是 `ထိုအတ္ထသန္ဒဿနဉာဏ်သည်`，指的是“那显示义利智”。译文“它”的指代没有错，但比较虚。
- **建议**：可考虑改为“从已知的意义来说，这是智；从详细了知的意义来说，这是慧”（或用“遍知”）。如果项目对 pajānana 已有统一译法，以术语表为准。此项不是必改。

## OCR / 原文疑问（只记录，不改）
- §555 问句作 `nānādhammappakāsanatā`（双 p），§557 结句作 `nānādhammapakāsanatā`（单 p），原文拼写前后不一。nissaya 两处都作 `ပ္ပကာသနတာ`。
- §555 nissaya 的 `အဋ္ဌာရသ ဓါတုယာ=` 和 `အဗျာကတာ ဓမ္မာ= အဗျာ` 释义残缺，且漏了 kāmāvacarā / rūpāvacarā / arūpāvacarā 三条。nissaya 本身不完整，不影响译文。
- §557 句 9-13 的 nissaya 混入了 `သဗ္ဗကိလေသေ… အရဟတ္တမဂ္ဂတ္ထံ` 两行，这两行属于句 39-51，是 nissaya 错位。
- §557 句 14-38 中，nissaya 把宾格的 thinamiddhaṃ / uddhaccaṃ / vicikicchaṃ / avijjaṃ / aratiṃ 标为属格 `၏`，把 °atthaṃ 标为具格 `ဖြင့်` 或 `မည်၏`。这和巴利原文的格位不符，应是 nissaya 的抄写问题。译文按原文作宾语处理，是正确的，不需要跟着 nissaya 改。
