# Review — 151:739-742（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **sakkāyadiṭṭhiyā … abhiniveso hoti**：§740 句 151-740-2-12 与 §741 句 151-741-75-88 是同一句式的问与答，两处都把“有身见”译成主语。按 nissaya，两处都应改为“有身见的执着……”（见下），**两处必须一起改**，保持问答对应。
- **samanupassati**：§741 全段统一译“看作”。§740 句 151-740-13-41 和 151-740-42-60 的四句式中，前两句用“看作”，后两句改用“认为”。nissaya 显示四个宾语共用同一个动词 `သမနုပဿတိ= ရှု၏`（`အတ္တာနံ ဝါ= အတ္တကိုမူလည်း။ … သမနုပဿတိ= ရှု၏။`）。建议四句统一用“看作”。例如“把色看作在自我之中，或者把自我看作在色之中”，或者保留“认为”但四句一律用“认为”。

## §740 句 151-740-2-12
- **问题**：格与句法（必改）。nissaya 为 `သက္ကာယဒိဋ္ဌိယာ= သက္ကာယဒိဋ္ဌိ၏`，是**属格**，意为“有身见的”。主格是 `အဘိနိဝေသော= သည်`，即“执着”。`ဟောတိ= ဖြစ်သနည်း` 是谓语“生起／存在”。译文“有身见以哪二十种行相而有执着”把属格的有身见译成了主语，把真正的主语“执着”降成了宾语。
- **建议**：改为“有身见的执着，以哪二十种行相而生起？”，或“有身见的执着是以哪二十种行相而有的？”

## §740 句 151-740-13-41
- **问题**：风格（必改）。“圣者之法”“善人之法”各出现两次，用了文言虚词“之”。
- **建议**：改为“圣者的法”和“善人的法”，也可以用“圣法”和“善人法”，但全句要统一。另外 nissaya 解 `အဒဿာဝီ= ဉာဏ်ဖြင့်မမြင်သည်ဖြစ်၍`，意为“不以智慧见”。现在译“不见圣者”也可以，若想补足传统取义，可译“未以智慧见到圣者”（可选）。
- **问题**：句法一致性。见上节“跨段一致性”中 samanupassati 一条，四个宾语共用同一个动词。

## §741 句 151-741-63-74
- **问题**：格与句法。nissaya 为 `သက္ကာယဒိဋ္ဌိ= သက္ကာယဒိဋ္ဌိသည်။ မိစ္ဆာဒိဋ္ဌိ= မိစ္ဆာဒိဋ္ဌိသည်။`，两词都带主格 `သည်`，是并列的列举项。如果“邪见”是表语，按惯例会作 `…မည်၏`，像本段 `သက္ကာယဒိဋ္ဌိ= …မည်၏` 那样。译文“有身见是邪见”把列举项改成了判断句。
- **建议**：改为并列列举：“有身见、邪见……乃至……这些是结，而不是见。”

## §741 句 151-741-75-88
- **问题**：格与句法（必改）。与 §740 问句同一结构：`သက္ကာယဒိဋ္ဌိယာ= ၏` 是属格，`အဘိနိဝေသော= သည်` 是主格。“有身见以这二十种行相而有执着”同样主宾颠倒。
- **建议**：后半句改为“……有身见的执着，就是以这二十种行相而有的。”，要与 §740 问句的改法对应。
- **OCR / 原文疑问**：nissaya `ဤနှစ်ဆယ်သော အခြားအရာတို့ဖြင့်` 中的 `အခြားအရာ`（“其他事物”）疑为 `အခြင်းအရာ`（“行相”）之讹，§740 对应处作 `အခြင်းအရာ`。这只影响 nissaya 文本，不影响译文，记录在此，不改。
