# Review — 151:1841-1844（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句没有 nissaya 单元，这些句不出意见）

## 跨段一致性

- **hāsa**：§1844 标题译“**欢喜慧**”（hāsapaññā），同段 hāsabahulo 却译“满怀**欢笑**”。同一个词 hāsa 有两种译法，被解释词和解释语之间的对应就断了。nissaya 的释义是 `ဟာသဗဟုလော= ရွှင်ခြင်းများသည်ဖြစ်၍`（多喜悦），意思是心里愉快，不是笑出声。建议全段统一为“欢喜”：hāsabahulo 改为“满怀欢喜”，§1844 的 8-17、18-26、27-36、37-45、46-103、104-112、113-122 各句一并修改。
- **夹注巴利原词**：§1842、§1843、§1844 的标题句都夹注了巴利原词（sīghapaññā／lahupaññā／hāsapaññā），§1841 的“多慧”却没有夹注。建议在 §1841-2-8 补上“多慧（paññābāhulla）”。
- **`… iti – X-paññā` 句式**：§1842、§1843、§1844 全部列举句都译成“……，这是 X 慧”。nissaya 在这里的读法一律是 `ဣတိတသ္မာ= ထို့ကြောင့်` + `X= X မည်၏`，意思是“因此**名为** X 慧”（§1843-8-14 说得更明白：`ထိုသို့ ပြည့်စေတတ်သော သတ္တိကြောင့်`，“因为有这种能圆满的能力”）。这一句式是在给名称下定义，不是在下判断。建议统一改为“……，所以叫作 X 慧”，三段的列举句一并修改。
- **idha ekacco**：§1841-9-47、§1841-85-111、§1844-8-17 都译成“这里有人”。nissaya 补出了处所：`ဣဓ= ဤသာသနာတော်၌`，§1841-85-111 的原文和 nissaya 更直接写作 `ဣဓ သာသနေ`，即“在这个教法里”。建议三处统一为“在这个教法里，有人……”。
- **重叠副词**：“很快很快地”（§1842）、“轻快轻快地”（§1843）。nissaya 的 `လျင်စွာလျင်စွာ`／`ပေါ့ပါးစွာပေါ့ပါးစွာ` 只是对原文叠词的照录，汉语照搬叠用读起来像翻译腔。建议改为“迅速地”“轻快地”，或者用“很快就能……”，两段统一处理。

## §1841 句 151-1841-9-47

- **问题**：误读 — “多于抉择／多于审择／多于观察／多于细察／多于此”。现代汉语里“多于 X”的意思是“比 X 多”，读者会理解成比较句。nissaya 的读法是 `ဝိစယဗဟုလော= …စိစစ်ဆင်ခြင်ခြင်းများသည်`（常常抉择、多作抉择），`တဗ္ဗဟုလော= ထိုပညာအဖြစ်များသည်`（多与慧相伴）。
- **建议**：“多于”一律改为“多作”或“常常”，例如“常作抉择、常作审择……”。tabbahulo 改为“多以慧而住”或“慧常现前”，不要用“多于此”。

- **问题**：隐含成分 — taccarito、taggaruko、tabbahulo、tanninno、tappoṇo、tappabbhāro、tadadhimutto、tadadhipateyyo 中的 tad- 都译作“此”，指代不明。nissaya 每一条都补出了指代对象 `ထိုပညာ`（那个慧），例如 `တန္နိန္နော= ထိုပညာ၌ ညွတ်သည်`。
- **建议**：首次出现时明示“以此（慧）而行”，或者直接写“以慧……”，让读者知道“此”指的是慧。§1841-85-111 同样处理。

- **问题**：词义 — paññāsayo 译作“以慧为意向”。nissaya 是 `ပညာလျှင်စိတ်၏ကိန်းဝပ်ရာ ရှိသည်`，意思是“以慧作为心所安住的地方”，āsaya 在这里取“住处、依止处”义，而不是“意向”。
- **建议**：改为“以慧为心的依止”或“心安住于慧”。

- **问题**：词义 — vibhūtavihārī 译作“住于明晰”，偏抽象。nissaya 是 `ထိုထိုတရားကိုထင်ရှားစေ၍ နေလေ့ရှိသည်`，意思是“惯于让种种法变得明晰而住”。
- **建议**：改为“常使诸法明晰而住”。

- **问题**：编注误标 — 〔另本作……（斯里兰卡本、柬埔寨本）〕。原文缩写 `syā.` 是 Syāmaraṭṭha，即泰国本，不是斯里兰卡本（斯里兰卡本的缩写是 `sī.`）。`ka.` 也需要按 CSCD 版本缩写表核实，不能直接译成“柬埔寨本”（柬埔寨本的通行缩写是 `kaṃ.`）。
- **建议**：把“斯里兰卡本”改为“泰国本”，`ka.` 核实后再标注。

## §1841 句 151-1841-48-84

- **问题**：词义译窄 — “热衷团体／衣服／钵／住处的人”。nissaya 对 -bāhuliko 的释义一律是 `…များခြင်းငှါ အားထုတ်သူ`，意思是“为了让 X 变多而努力的人”，例如 `စီဝရဗာဟုလိကောတိ= သင်္ကန်း များခြင်းငှါအားထုတ်သူ`。“热衷”丢掉了“求多、积攒”这层意思，这层意思正是本段拿“多慧”（paññābāhulla）作类比的着眼点。
- **建议**：改为“致力于多聚徒众的人”“致力于多积衣服的人”“致力于多积钵的人”“致力于多求住处的人”。

## §1841 句 151-1841-85-111

- **问题**：原文疑问 — pali 原文作 `paññā garuko`，被拆成了两个词，与同段 9-47 的 `paññāgaruko` 不一致，疑为排版或 OCR 讹误。只作记录，不改原文。
- **建议**：译文不受影响，可登记到 `known-issues.md` 的 OCR 一节。

## §1843 句 151-1843-15-21

- **问题**：nissaya 错位 — 这个单元的内容是 `လဟုပညာတာယ သံဝတ္တတိဧတ္ထ= ၌။ / အယံ= …/ လဟုပညာ= လဟုပညာတည်း။ (၁၂)`，属于本段的结语，应该对应 §1843-150-155，而不是“根律仪”这一句。
- **建议**：译文本身没有问题。这一句不能拿这个 nissaya 单元当词级依据，建议在 known-issues 中记下这处对齐错位。

## §1844 句 151-1844-8-17

- **问题**：词义 — hāsabahulo 译作“满怀欢笑”。nissaya `ရွှင်ခြင်း` 的意思是喜悦、愉快，不是笑（详见跨段一致性第一条）。其余三词的译法与 nissaya 相符：veda `ဝမ်းသာခြင်း` 欣喜，tuṭṭhi `နှစ်သိမ့်အားရခြင်း` 满足，pāmojja `ဝမ်းမြောက်ခြင်း` 愉悦。
- **建议**：改为“满怀欢喜、满怀欣喜、满怀满足、满怀愉悦地圆满诸戒”。
