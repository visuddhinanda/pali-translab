# Review — 151:1490-1492（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 三段均未提供 nissaya，逐句词法核对全部略过，下文只列跨段一致性）

## 跨段一致性

- **-ṭṭhaṃ 的译式不统一**：大多数句子译成“X的意义”，但以下几句省掉了“的”：§1490 46-51「舍断的舍弃意义」、52-58「修习的一味意义」、59-65「作证的触证意义」、84-89「诸有为法的有为意义」、90-95「无为法的无为意义」。
  → 建议统一为“……的……的意义”，例如「舍断的舍弃的意义」「修习的一味的意义」，与同段 66-83「诸蕴的蕴的意义」等句式保持一致。
  依据：同一个 -aṭṭha 结构在本 chunk 共出现 70 余次，其中“的意义”占绝大多数。

- **ekatta 与 ekoda 的区分**：§1492 全段把 ekatte 译成「在一境性中」。“一境性”是 ekaggatā 的通行译名，ekatta 一般译“一性”或“单一性”。同一段 26-46 的 ekodaṭṭhaṃ 又译「专一」，两个概念的边界容易被读混。
  → 建议把 ekatte 改为「在一性中」，全段统一替换。
  依据：词形不同（ekatta ≠ ekaggatā），且需与 §1490 22-26 ekoda「专一」区分开。

- **校勘注的体例不统一**：
  - §1490 27-39、§1491 20-32 的写法是「暹罗本作：<汉译>」，给的是汉译。
  - §1491 51-71 的写法是「暹罗本作 bhummaṭṭhaṃ；参见…」，给的是巴利原词，而且没有冒号。
  - §1492 26-46 的写法是「各本另有：…」。

  → 建议统一一种格式。推荐「（暹罗本作 <巴利词>：<汉译>）」，把巴利词和汉译都保留，便于核对异读。

- **sambujjhanaṭṭhaṃ 重复**：§1492 189-194 与 214-219 的巴利原文都是 sambujjhanaṭṭhaṃ，两处都译「正觉知」，译法本身一致。不过 214-219 位于 bodhana / anubodhana / paṭibodhana 的序列末尾，按序列应是 sambodhanaṭṭhaṃ（汉译相应为“正使觉悟”）。
  → 这是疑似原文讹误，记录在案，不改原文。译文暂时维持与原文一致。

- **bujjhanti 与名词 bujjhana 同译「觉知」**：§1492 171-176 译成「因为觉知在一境性中觉知的意义」，动词和宾语里的名词用了同一个词，读起来像笔误。这在跨段上是一致的，但可读性差。
  → 可以考虑把名词 bujjhana 改译为「觉了」，相应调整 anubujjhana / paṭibujjhana / sambujjhana 系列，即「随觉了 / 彻觉了 / 正觉了」，与动词「觉知」区分开。
