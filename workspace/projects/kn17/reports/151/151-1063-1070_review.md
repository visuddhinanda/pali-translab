# Review — 151:1063-1070（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（只覆盖 §1064 句 151-1064-2-16 和 §1070 句 151-1070-83-94，其余句不出词法意见）

## 跨段一致性
- cariyā：各段统一译“行”，一致。nissaya 释作 `စရိယာ= ဖြစ်ခြင်းကို`（“现起、运作”，宾格），“行”与此义相合，不需要改。
- ākāra / -aṭṭha / adhimokkha / paggaha / upaṭṭhāna / avikkhepa / dassana：全 chunk 分别统一为“行相 / 意义 / 胜解 / 策励 / 现起 / 不散乱 / 见”。“…增上的意义”的句式也前后一致。
- 语体：§1070 句 151-1070-43-82 的“导向苦灭**之**道圣谛”用了文言虚词“之”，全 chunk 其余地方都用“的”。建议统一为“导向苦灭的道圣谛”。如果项目决定把“导向苦灭之道”作为固定术语保留，请登记进 `terms.md`。

（两句有 nissaya 的句子逐词核对后没有发现问题：
- 句 151-1064-2-16：处格 `တို့၌` 对应“在四预流支中”，具格 `ဖြင့်` 对应“依信根来说”“以多少种行相”，属格 `တို့၏` 对应“五根的”，宾格 `ဖြစ်ခြင်းကို` 对应“行”，疑问 `သနည်း` 对应问句。
- 句 151-1070-83-94：格位与句法都相符，“这二十种”对应 `ဣမေဟိ`，陈述句 `၏` 对应句号。
所以不单列。）
