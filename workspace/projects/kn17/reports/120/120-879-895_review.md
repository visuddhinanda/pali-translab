# Review — 120:879-895（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（886、889、892、895 及 884-68~118 各句无独立 nissaya 单元，略过；884-68~118 的词法依据取自 884-138-142 单元里的补释）

## 父层被解释词核对

- **tathāgatānaṃ**（§884 句 120-884-156-168）：父层 151-235-59-68 译「如来」，本层黑体「**如来**」，一致 ✅
- **arahantānaṃ**（§885 句 120-885-2-18）：父层 151-235-59-68 译「阿罗汉」，本层黑体「**阿罗汉**」，一致 ✅
- 其余黑体词（tathavāditāya / tathākāritāya / abhibhavanaṭṭhena / gato）父层未出现，由本层自定译法。下文核对的是它们在本层内是否前后一致。

## 跨段一致性

- **abhibhavati / abhibhavana**：§882 标题与 §883 结句都译「胜伏」，但 §882 句 120-882-6-41 译「胜过一切众生」。这一句正是在解释「胜伏的意义」，nissaya 释为 `အဘိဘဝတိ= လွှမ်းမိုးတော်မူ၏`（压服、凌驾）→ 建议统一为「胜伏一切众生」，免得标题和释文脱节。
- **hatā（arā 轮辐）**：§885 与 §891 结句译「破尽了轮辐」，§891 正文译「砍断了……一切轮辐」，§892 译「以智剑砍断」。同一个 hatā 用了两种说法 → 建议正文统一为「砍断」，「由于破尽了轮辐」这个理由句可以保留作固定句式。另外两处结句也要相互一致。
- **sattha / asi**：§890 paññāsattha 与 §892 ñāṇāsi 都译「剑」。nissaya 分作 `လက်နက်`（兵器）与 `သန်လျှက်`（剑）→ 建议 §890 改为「慧刃」或「慧的兵器」，§892 保留「智剑」。
- **tathāya / tathaṃ 的处理**：§884 句 120-884-2-11 把 tathaṃ 译成宾语「去到真实」，句 120-884-21-49 却译成状语「如实地去行」，前后不一致。见下文具体意见。

## §879 句 120-879-6-80

- **问题**：词义偏弱。`ရာဂမဒနိမ္မဒနံ= ရာဂဖြင့် ယစ်ခြင်းကိုဖျက်ဆီးတတ်၏`，nimmadana 的意思是「破除」，不是「平息」。
- **建议**：「能破除贪的骄醉，破除瞋与痴的骄醉」。

## §881 句 120-881-23-33、120-881-34-44

- **问题**：结构误读。`ဂတော ပဝတ္တော= ဖြစ်တော်မူ၏` 是一个合并的释义：pavatto 是对 gato 的注释（gato 即 pavatto），不是两个并列动作。现在译成「怎样去、怎样运行」，读起来像两件事。
- **建议**：「身也就那样行进（gata，即运行）」；后一句照此改作「语也就那样行进（运行）」。

## §881 句 120-881-45-46

- **问题**：漏译。`တေနေဝ= သာလျှင်`，eva 表示强调，译文没有体现。
- **建议**：「正因如此，世尊说：」。

## §882 句 120-882-44-61

- **问题**：误译。nissaya 附注 `အညဒတ္ထူတိ ဧကံ သတ္တေ နိပါတော`，说明 aññadatthu 是表示「确定」的不变词；`ဒသော= မြင်စွမ်းနိုင်၏` 的意思是「能见者」。译文「遍见者」漏了 aññadatthu，又多出了「遍」。vasavattī 的 nissaya 释为 `ငါ၏ အလိုသို့ လိုက်စေ`，是使役义「使（众生）随其意转」，比「自在者」更具体。
- **建议**：「……如来是胜伏者，不被胜伏，必定是能见者，是使一切随其意转者」。如果保留「自在者」，至少要补出「必定是能见者」。

## §884 句 120-884-2-11

- **问题**：格与修饰关系误读。`တထာယ= ဟုတ်မှန်သော ပရိညာဉ်ဖြင့်`：tathāya 是阴性具格形容词，修饰省略的 pariññā，意为「以真实的遍知」，不是副词「如实」。`တထံ= ဟုတ်မှန်သော အကျင့်ကို`：tathaṃ 是宾格形容词，修饰省略的 paṭipadā，意为「真实的行道」。
- **建议**：「再者，以真实的（遍知）去到，所以是如来；去行真实的（道），也是如来」。

## §884 句 120-884-21-49

- **问题**：同上，修饰关系误读。tathāya 依次与 tīraṇapariññāya / pahānapariññāya / sacchikiriyāya 同格（nissaya `တထာယ= ဟုတ်မှန်သော … ဖြင့်`）；tathaṃ 与 paṭipadaṃ 同格（`တထံ= ဟုတ်မှန်သော … အကျင့်ကို`）。译文全部当成副词「如实地」处理。
- **建议**：「以真实的审察遍知去到、了达整个世间……以真实的断遍知去离、超越世间的集起……以真实的作证去到、到达世间的灭……去行、践行真实的导向世间灭的道路……」。

## §884 句 120-884-50-54 与 120-884-138-142

- **问题**：句法关联断裂。nissaya 补出 `ယံ ဝစနံ ဝုတ္တံ … တဿ ဝစနဿ ဧဝမ္ပိ အတ္ထော ဝေဒိတဗ္ဗော`，这是关系句「世尊所说的那段话，它的意义也应当这样理解」。tena 指「依据上面的解释」。译文把前半句译成「所以世尊说：」，后半句的「它」就没有着落，变成单纯的引经。
- **建议**：120-884-50-54 改为「因此，世尊所说的——」；120-884-138-142 改为「这段话的意义也应当这样理解」。

## §884 句 120-884-102-118

- **问题**：格关系误读。nissaya 把 `လောကဿ= သည်` 释为施事（「被有天的世间……以意随寻」），译文「有天的世间……以意随寻的一切」读起来像领属。
- **建议**：「凡是有天的世间……乃至……用意随寻过的一切，都已被如来证悟」。

## §884 句 120-884-143-148

- **问题**：词义偏差。`မုခမတ္တမေဝ= အမြွက်မျှသာ` 的意思是「只是略提一下」，不是「入口」。
- **建议**：「而这些也只是略说如来之所以是如来而已」。

## §884 句 120-884-156-168

- **问题**：漏译补出成分。nissaya 补出了施事 `ဓမ္မသေနာပတိတေရော= အရှင်သာရိပုတြာ`（法将舍利弗长老），以及方式 `ဗဟုဝစနဝသေန`（用复数）。这一句要解释的正是本文为什么用复数 tathāgatānaṃ，译文没有点出「复数」，读者看不出 yasmā…tasmā 在说明什么。
- **建议**：「但因为一切佛在如来的功德上也都完全相等，所以（舍利弗长老）就一切佛而用复数说“**如来**”」。黑体保持「如来」不变。

## §885 句 120-885-19-30

- **问题**：句法误读，另有增译。nissaya 的语序是 `မဂ္ဂေန … ပဟီနတ္တာ= ပယ်အပ်သည်၏ အဖြစ်ကြောင့်` → `အာရကာ`：「以道断除了烦恼」是「远离」的原因，不是与「远离」并列的另一个理由。此外，savāsanānaṃ kilesānaṃ 原文没有 sabba，译文多了「一切」。
- **建议**：「因为他以道断除了连同习气在内的烦恼，所以远离一切烦恼，住在离它们极远的地方，因此是阿罗汉」。

## §888 句 120-888-2-10 / §891 句 120-891-2-30

- **问题**：风格，必改。文言虚词「之」：「烦恼之敌」「精进之足」「信之手」「智之斧」「轮回之轮」「三有之车」。
- **建议**：分别改为「烦恼这些敌人」「精进的双足」「信心的手」「智慧的斧」「轮回的轮子」「三有的车」。§882 的「王中之王」「天中之天」是现代汉语里通行的固定说法，可以保留。

## §894 句 120-894-40-60

- **问题**：数字误译，必改。`ဆန္နဝုတိကောဋိ= ကိုးဆယ့်ခြောက်ကုဋေ`，即九十六 koṭi。一 koṭi 是一千万，合计九亿六千万，不是「九十六亿」。
- **建议**：「舍出九亿六千万财物」，或「舍出九十六俱胝（koṭi）的财物」。
- **另**：nissaya 把 aññesaṃ 释为 `တပါးသော သူတို့၏`（「其他人的」）。按这个读法，后半句应作「更不用说其他人所作的殊胜供养了」。当前译法在语法上也说得通，可以保留，但请留意这一读法。
