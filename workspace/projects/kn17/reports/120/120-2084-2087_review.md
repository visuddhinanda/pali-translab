# Review — 120:2084-2087（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照

逐条核对了本 chunk 的黑体被解释词（这十处 / 十处 / 谁的慧已熟习 / 善于应对法掉举 / 不会陷入迷惑 / 既散乱又受染污 / 既散乱 / 又受染污 / 心的修习就会退失 / 散乱而不受染污 / 修习就会衰减 / 修习却不衰减 / 心不散乱也不受染污 / 心的修习就不会退失 / 凭这四种情形 / 收摄 / 散乱）。全部与 151:1410–1416 的父层译文逐字相同，**无不一致**。2086-54-70 非黑体引用的“散乱而不受染污”也与父层一致。

## 跨段一致性
- mandapañña / majjhimapañña / tikkhapañña 三类人的称呼在 §2085 内来回变动：
  - §2085-17-24 用“慧钝的修行者”，§2085-52-60 用“慧钝的人”，§2085-72-86 用“慧钝者”。
  - 中等慧一类依次是“中等慧的修行者”（25-34）、“中等慧的人”（87-98）、“中等慧者”（99-112）。
  - 利慧一类依次是“利慧的修行者”（35-43）、“利慧的人”（113-124）、“利慧者”（125-143）。
  - **建议**：首次出现带 yogāvacaro 时保留“……的修行者”，之后统一用“慧钝者 / 中等慧者 / 利慧者 / 极利慧者”（§2085-44-51、144-161 已用“极利慧者”）。§2086-2-42 的“慧钝者等三位修行者”与此相合。

## §2084 句 120-2084-48-56
- **问题**：补出成分。nissaya `တမတ္ထံ= ထိုမတုန်လှုပ်ခြင်းအနက်ကို`（那个“不动摇”的意思），说明 tamatthaṃ 承上句指“不动摇”。译文“这个意思”所指不明。
- **建议**：改为“为了显示‘不动摇’这个意思”。

## §2084 句 120-2084-75-88
- **问题**：句法误读。nissaya `ဓမ္မုဒ္ဓစ္စဿ= …ဓမ္မ၏ပြန့်လွင့်ခြင်း၌`，把属格 dhammuddhaccassa 释作处格义（在法掉举这件事上），它是 cheko（善巧）的范围。`ယထာသဘာဝပရိဝေဓေန= …အားဖြင့်` 是方式具格。译文把法掉举当成“通达”的宾语，“善巧”就失去了着落，读成泛泛的“成为善巧的人”。
- **建议**：改为“以慧熟习了这十处的那位修行者，对前面所说那种法掉举，通过如实通达其本性而善巧”。

## §2084 句 120-2084-89-99
- **问题**：语序。“就通过破除渴爱、慢与见，也不会陷入迷惑”中，“就……也……”搭配别扭。nissaya 的结构是：原因 `ကုသလတာယေဝ= …ကြောင့်သာလျှင်` → 方式 `ဝသေန= ဖြင့်` → 谓语 `နဂစ္ဆတိ`。
- **建议**：改为“正因为善于应对法掉举，他通过破除渴爱、慢与见，也就不会陷入迷惑”。

## §2085 句 120-2085-72-86
- **问题**：误译，**必改**。两处都与 nissaya 相悖：
  1. `ဌာနတော= သာယာသောအားဖြင့် တည်ခြင်းကြောင့်`：ṭhānato 是表原因的从格，意思是“因为（以喜着的方式）停留”，与前面的 kilesesuyeva（`တို့၌သာလျှင်`，只在诸烦恼中）连读。译文作“从原有的位置退失”是误读。
  2. `ပဋိပက္ခာဝိဟတတ္ထာ`：这是 paṭipakkha-**a**vihata-tta，“未被对治所破”。nissaya 释为：没有用作为烦恼对治的三种随观，击破渴爱、慢、见三种烦恼。译文作“被对立的一方所损害”，把否定读反了。
- **建议**：改为“那位慧钝者的观心修习，由于只停留在诸烦恼中，而烦恼没有被对治所破除，所以退失，意思是坠落”。

## §2085 句 120-2085-99-112
- **问题**：原文疑问（记录，不改译）。pali 作 vipassanārambh**ābhāv**ena（没有开始修观）。nissaya 主释作 `ဝိပဿနာရမ္ဘသဗ္ဘာဝေန`（sabbhāva，有），异释 `ဝါ=` 才释为“没有”。译文依 pali 取“没有”，与文义一致，可保留。nissaya 的底本异读供参考。

## §2085 句 120-2085-125-143
- **问题**：补出成分。nissaya `တံ အဓိမာနဝိက္ခေပံ= ထိုအဓိမာနကြောင့် ဖြစ်သောဝိက္ခေပကို`，意思是“由那增上慢而起的散乱”。译文“那增上慢的散乱”结构含混，可能被读成“增上慢的那种散乱”或两者并列。
- **建议**：改为“也能舍弃那由增上慢而起的散乱”。

## §2086 句 120-2086-2-42
- **问题**：格。nissaya `ဒသဌာနေ= ၌` 是处格（在十处上）。译文“就光明等十处”读来像“关于”，与父层“正知……那十处”的宾语读法也不同。
- **建议**：改为“在光明等十处上”。
- **问题**：句子过长，主干被埋没。主干是“修行者……了知……的心”，中间夹着原因和手段两个具格、处格、主语的三个修饰语。
- **建议**：拆成两句，例如：“以现在所说的这四种情形为原因，或以它们为手段——远离散乱与烦恼生起的第四位善巧、大慧的修行者，在光明等十处上，从种种方面了知慧钝者等三位修行者那被心的收摄与散乱所扰乱的心，知道它‘是这样的，是这样的’。应按这样的连结来理解这里的释义。”

## §2086 句 120-2086-54-70
- **问题**：处格表达。nissaya `ဒွီသု ဌာနေသု= …အရာတို့၌` 是“在两处”。“依据‘散乱而不受染污’这两处所说的散乱”把“这两处”贴在引语后，读来像是引语本身有两处。
- **建议**：改为“依据在‘散乱而不受染污’出现的两处所说的散乱”。
