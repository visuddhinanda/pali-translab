## 被解释词与父层对照

全部黑体被解释词都已逐条和父层（151:660-670）译文比对，**没有发现不一致**：

- 什么是 / 如来 / 一切知智
- 一切 / 有为与无为 / 毫无遗漏地 / 在这方面没有障碍
- 过去 / 未来 / 现在 / 眼与诸色 / 就这样……那一切 / 凡是
- 无常的意义 / 色的 / 眼的……乃至……老死的
- 证知的 / 证知义 / 诸蕴的蕴义 / 善法 / 欲界法 / 苦的 / 根上下智
- 有天 / 有魔 / 有梵天 / 有沙门、婆罗门 / 天和人 / 众生

（附注：父层 §660-670 作“在这方面没有障碍”，§675-677 作“在这上面没有障碍”。本层引的是 §660 的那一处，对应无误。父层内部的分歧另行处理。）

## 跨段一致性

- **sattaloka / pajā**：§1521 先说 pajā 是 sattaloka 的同义词，但 pajā 译“众生”（父层定稿），sattaloka 译“有情世间”。读者看不出两者相等。§1521-45、§1521-51、§1521-73、§1522 共四处，建议 sattaloka 统一改为“众生世间”，使“众生”与“众生世间”的对应一目了然。
- **veditabba**：§1520-88 译“应当……来理解”，§1521-51、§1521-73 译“应当了解”。建议统一为“应当了解”。

## §1518 句 120-1518-36-54
- **问题**：句法 — 因果关系被改成了同位关系。nissaya 的结构是：`အသက္ကုဏေယျတာယ= မစွမ်းနိုင်သည်၏ အဖြစ်ကြောင့်`（因为不能）→ `နတ္ထိ`（所以没有障碍）→ `ဣတိ တသ္မာ ... ဝုစ္စတိ`（所以称为无障碍）。也就是说，“任何法、任何人都无法造成障碍”是“没有障碍”的原因。译文用“也就是”把两者并列，因果层次丢了。另外，`အာဝဇ္ဇနပဋိဗဒ္ဓတ္တာ` 由 `ကသ္မာ= ကား` 引出，是对整个论断再追问一层“为什么”。
- **建议**：改为“一切知智本身，因为无论什么法、什么人都无法对它造成障碍，所以‘没有障碍’，因此称为无障碍；这是因为一切法都系于转向。”

## §1518 句 120-1518-79-93
- **问题**：句法 — 漏了否定句的谓语。nissaya：`အနုပုဗ္ဗသဗ္ဗညူ= ကမသဗ္ဗညူ မည်တော်မူ၏ဟူ၍။ နစဝုစ္စတိ= မဆိုအပ်`。这里 `na ca` 否定的是 `vuccati`（不被称为），不是系词。译文“并不是次第的一切知者”成了对事实的判断，原文说的是“不这样称呼”。
- **建议**：“……而被称为一切知者，但并不被称为次第的一切知者。”

## §1518 句 120-1518-94-104
- **问题**：同上。`na ca sakiṃsabbaññū` 承接的也是 `vuccati`（nissaya `နစဝုစ္စတိ`）。
- **建议**：“……但并不被称为一时的一切知者。”

## §1519 句 120-1519-95-112
- **问题**：取义 — `nissaṅgattā` 的 nissaya 释义是 `ပြောင်းရွေ့ခြင်း မရှိသည်၏ အဖြစ်ကြောင့်`（没有移动、偏转的缘故），意思偏向“无所滞碍、不受阻隔”。译文“没有任何粘滞”带有“不执著”的意味，和 nissaya 的取向略有出入。
- **建议**：改为“无所滞碍”或“毫无阻隔”。这一句的 confidence 适当压低。

## §1520 句 120-1520-146-161
- **问题**：连接词 — nissaya 把 `pana` 补作 `ကန တထာပိ= ထိုသို့ မဟောအပ်သော်လည်း`（虽然不这样说，但……），是让步关系。`hotiyeva` 强调的是“仍然是”。译文“而……本来就是”没有译出让步语气。nissaya 还限定 `na vattabbaṃ` 是“不作为所缘来说”（`အာရုံအားဖြင့် မဟောအပ်`）。
- **建议**：“……这个智本身不必再作为所缘提出；不过，一切知智本身仍然是一切知智的所缘境。”

## §1521 句 120-1521-51-72
- **问题**：补出成分 — nissaya 把 `sammutideva` 释为 `သမ္မုတိနတ်တည်းဟူသောမင်း`（称为世俗天的国王）。“世俗天”对一般读者是罕见术语，不加说明会被误解成某一类天神。
- **建议**：首次出现时加简注，例如“世俗天（指国王）”。§1522 再出现时只用“世俗天”。

## §1522 句 120-1522-2-26
- **问题**：句法 — 后半句的并列关系译错了。nissaya：`စတုပရိသဝသေန= ပရိသတ်လေးပါး၏ အစွမ်းဖြင့်။ သမ္မုတိ ဒေဝေဟိဝါ= သမ္မုတိနတ်တို့နှင့်လည်း။ သဟ= ကွ။ မနုဿလောကော= မနုဿလောကကို လည်းကောင်း။ အဝသေသသတ္တလောကောဝါ= ကြွင်းသော သတ္တလောကကိုလည်းကောင်း`。这里两个 `vā` 都释作 `လည်း / လည်းကောင်း`（也、以及），是“既……又……”的连接，不是“或者”。并且“按四众”“连同世俗天”同属一个短语，共同修饰“人世间”。译文拆成三个“或者”选项，与 nissaya 的读法不符。
- **建议**：“用‘有沙门、婆罗门’等，按四众包括了连同世俗天在内的人世间，以及其余的有情（众生）世间。”原文 vā 本身可以两读，这一句的 confidence 适当压低。
