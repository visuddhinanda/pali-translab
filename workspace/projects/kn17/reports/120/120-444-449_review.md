# Review — 120:444-449（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词（与父层 151:160-164 逐字对照）

全部黑体词都与父层译文逐字相同：戒清净 / 心清净 / 见清净 / 就脱离的意义而言 / 解脱（vimokkha）/ 就通达的意义而言 / 明 / 就舍弃的意义而言 / 解脱（vimutti）/ 就断绝的意义而言 / 尽智 / 就止息的意义而言 / 无生智 / 欲 / 就根本的意义而言 / 作意 / 就等起的意义而言 / 触 / 就会合的意义而言 / 就汇聚的意义而言 / 应当证知 / 定 / 就上首的意义而言 / 念 / 就增上的意义而言 / 慧 / 就比它更高的意义而言 / 解脱 / 就核心的意义而言 / 入于不死的涅槃 / 就终极的意义而言 / 从“已知”的意义说，它是智 / 从“了知”的意义说，它是慧 / 所以说。

447-2-31 与 447-55-73 中非黑体的引文也与父层 §162 一致。

说明：445、446 的黑体把父层“就根本的意义而言，欲”的语序拆成“**欲**，**就根本的意义而言**”。这样排是随巴利原词的语序，每段黑体仍与父层逐字相同，可以保留。

## 跨段一致性

- **visodhanato**：§444-9 与 §444-26 译“能清除”，§444-30 译“清除了” → 统一为“能清除”。依据：nissaya 三处都是 `သုတ်သင်တတ်သောကြောင့်`（能清除，`တတ်` 表示能力或惯常）。
- **“所以说”的使用**：
  - §446-2、§446-57、§446-80 的原文有 `vuttā/vuttaṃ`，译“所以说”是对的。
  - §445-14（`mūlattā mūlaṭṭhena`）与 §445-27（`…ti samuṭṭhānaṭṭhena`）的原文没有“说”，nissaya 在这里补出的是 `အဘိညေယျော`（应当证知）。
  - 建议这两处改为“所以就根本（等起）的意义而言应当证知”，与 §446-105“……而言，应当证知”保持一致。
- **uttara**：§446-105 译“高于”，§446-135 译“更高”。但 nissaya 在 §446-116 与 §446-135 都把 uttara 解作 `လွတ်မြောက်တတ်သော`（超出、逃离）。两处非黑体的释文应该体现“超出”，详见下文 §446-135。黑体“就比它更高的意义而言”受父层约束，不动。

## §444 句 120-444-21-25
- **问题**：补出成分（轻）。nissaya：`ဟိ= သစ္စံ`（确实），`ဧတ္ထ= ဤစိတ္တဝိသုဒ္ဓိဟူသော ပုဒ်၌`（在“心清净”这个词里）。译文只说“这里”，所指不够明确。
- **建议**：“在‘心清净’这个词里，是以‘心’为名来指称定。”

## §444 句 120-444-30-37
- **问题**：取义分歧。
  - nissaya：`သတ္တဒိဋ္ဌိမလဝိသောဓနတော= ခုနစ်ပါးသော ဒိဋ္ဌိတည်းဟူသော အညစ်အကြေး…`，把 satta 读作“七”，即“七种见的垢秽”。
  - 译文取 satta = 有情，译“有情见的垢秽”。
  - 另外，nissaya 把 `ယထာသဘာဝဒဿနံ` 释为“如实观见的**慧**”（`ပညာ`），是名词性的主语。
- **建议**：
  - 依 nissaya 改为“如实见到名色本性的慧，因为能清除七种见的垢秽，所以是见清净”。
  - 如果坚持“有情见”的读法，就压低该句的 confidence。

## §444 句 120-444-51-69
- **问题**：词义（轻）。nissaya：`သစ္စပဋိဝေဓဋ္ဌေန= သစ္စာလေးပါးကို ထိုးထွင်း၍…`（通达四谛）。“真谛”在汉语里容易和真俗二谛相混。
- **建议**：“漏尽智就通达四谛的意义而言是明。”

## §444 句 120-444-95-107
- **问题**：句法误读（必改）。nissaya 的结构是：
  - `ပဋိသန္ဓိဝသေန= ကိလေသာတို့၏ တဖန်စပ်ပြန်သည်၏ အစွမ်းဖြင့်`：指**烦恼**再度结生的方式。
  - `အနုပ္ပါဒဘူတေ= မဖြစ်စေတတ်သည်ဖြစ်၍`：成为“使之不生”的。
  - `တံတံမဂ္ဂဝဇ္ဈကိလေသာနံ= …ကိလေသာတို့ကို`：对象是各道所断的烦恼。
  - `အနုပ္ပါဒပရိယောသာနေ= …အရိယာမဂ်၏ အဆုံး၌`：在令烦恼不再生起的**圣道**的终点。

  也就是说，“无生”指的是各道所断的烦恼不再以结生的方式生起，不是圣果本身“无生”。译文“这圣果就结生而言是无生的”把无生归给了圣果。另外，“各个道所断的烦恼”被挂到了“终点”上，与 nissaya 的分句不合。
- **建议**：“由于称为道的作用的那种努力已经止息，所以是圣果中的智。这圣果使各个道所断的烦恼不再以结生的方式生起，是在圣道令烦恼不再生起的终点上生起的。”

## §445 句 120-445-72-88
- **问题一**：补出成分有误（必改）。nissaya：`တိကသန္နိပါတပစ္စုပဋ္ဌာနောတိ= ဟူ၍။ ဝုတ္တတ္တာ`，只是“由于被说为……”。译文添出的“经中”没有依据。
- **问题二**：句法。nissaya 用 `လည်းကောင်း…လည်းကောင်း` 并列两个原因：`ပဝေဒိတတ္တာ`（由于依自己的原因而被宣说）和 `ဝုတ္တတ္တာ`（由于被说为“以三事和合为现起”）。两者共同引出 `သမောဓာနဋ္ဌေန အဘိညေယျော`。译文把前一个原因译成了独立的陈述。
- **建议**：“又因为触是依它自己的原因——称为三事和合的原因——来宣说的，也因为它被说为‘以三事和合为现起’，所以就会合的意义而言，触应当证知。”

## §446 句 120-446-23-38
- **问题一**：词义。nissaya：`သဗ္ဗံ= အလုံးစုံသော တဏှာဝတ္ထု တဏှာ၏ အကြောင်းကို`，把 taṇhāvatthu 释为“渴爱的原因（所依）”，不是“对象”。
- **问题二**：风格。`ပရိညေယျာနိ= …တရားတို့`，原指“法”，译成“东西”过于口语，与全段语体不合。
- **建议**：“一切应当遍知的法都汇聚在受中；受被遍知时，一切渴爱的所依就都被遍知了。”

## §446 句 120-446-57-76
- **问题**：补出成分（轻）。nissaya 在比喻里补出 `ပမုခါ…ဟောတိဝိယ`，意思是顶尖因为系结所有椽子而**居于上首**。比喻的落点是“上首”。译文只译了“连结”，喻体和喻义的对应因此变弱。
- **建议**：“就像尖顶楼阁的顶尖因为把所有椽子连结在一起而居于首位，定也因为把心与心所聚合在一起，而是善法的上首、最重要者，所以说……”

## §446 句 120-446-116-130
- **问题**：格与指代。nissaya 给出两种解析：
  - `တတော= ထိုကုသိုလ်တရားကြောင့်` + `ကိလေသဟိ`
  - 或 `တတော ကိလေသေဟိ= တို့မှ`（从那些烦恼）

  主读是 tato 与 kilesehi 同指，即“从那些烦恼”。译文“从那里——从烦恼”把 tato 译成了处所。
- **建议**：“或者说，它从那些烦恼，或者从轮回的循环中超出、越过，所以叫作 taduttarā；它的意义就是 taduttaraṭṭha。”

## §446 句 120-446-131-134
- **问题**：句法（轻）。nissaya：`တေန တဒုတ္တရဋ္ဌေန= အားဖြင့်`，tena 与 taduttaraṭṭhena 同格，意思是“以那个 taduttaraṭṭha（意义）”，不是“因此说”。原文也没有“说”。
- **建议**：“以这个意义，就是“**就比它更高的意义而言**”。”（黑体保持不变）

## §446 句 120-446-135-141
- **问题**：词义（必改）。nissaya：
  - `တတော= ထိုကိလေသာတို့မှ။ ဝါ= သံသရာဝဋ်မှ`：从那些烦恼，或从轮回。
  - `ဥတ္တရဋ္ဌေန= လွတ်မြောက်တတ်သော အနက်အားဖြင့်`：就能超出的意义而言。

  这是对异读 tatuttaraṭṭhena 的释义，而译文“比那更高”与 nissaya 的“超出”不合。
- **建议**：“意思是‘就从那些烦恼或轮回中超出的意义而言’。”

## §446 句 120-446-163-190
- **问题一**：格。`natthi etassa` 中的 etassa 是属格或与格。nissaya：`ဧတဿ= ထိုနိဗ္ဗာန်အား`，意为“它（涅槃）没有”。译文“这里没有”与后面 `natthettha`（ettha = 这里）相混。
- **问题二**：风格（必改）。“烦恼之毒”“轮回之苦”用了文言虚词“之”。
- **问题三**（轻）：nissaya 把 vāna 直接音写为 `ဝါနတရား`。译“林”是取了 vana 的字义，可以考虑只保留 vāna 并附简注。
- **建议**：“它没有称为死亡的死，所以叫作不死（amata）；因为它是烦恼这种毒的对治，是解药（agada），所以也叫作不死；……因为它是轮回的苦的平息……”

## §447 句 120-447-2-31
- **问题**：数与指代。nissaya：`တဿ= ထိုနိဂုံး၏။ အဘိမုခံ= ရှေးရှု`。tassa 是单数，指“那个结语”。译文“把它们置于面前”用了复数，指代的是诸法，与 nissaya 不合。这一句的确切义读拿不准，译文却写得很肯定。
- **建议**：依 nissaya 改为“意思是：面向这一结语，它们就成为已知的”，并压低该句的 confidence。
