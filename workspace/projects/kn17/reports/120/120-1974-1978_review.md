# Review — 120:1974-1978（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层对照（151:1178-1192）✅

## 被解释词对照父层

逐条比对了本层黑体与父层定稿译文：

- §1974 的 可以 / 按所依的事物 / 按不同的角度 / 怎么说可以这样呢 / 无常随观智 / 常想 / 乐想 / 我想 / 相想 / 相 / 喜想 / 贪想 / 集想 / 执取想 / 愿求想 / 执着想：✅ 一致
- §1975 的 无常随观的如实智 / 如实智 / 愚痴、无知 / 解脱：✅ 一致
- §1976 的 无常随观是无上的清凉之智 / 从执取为常而生的灼热、热恼与焦虑中解脱：✅ 文字一致
- §1978 的 无取的心的解脱 / 几种取：✅ 一致
- **§1977 句 120-1977-2-11**：❌ 不一致。父层 151-1187-9-19 是“出离在禅思，所以是禅”，本层作“**出离在禅思**……**所以是禅**”，把逗号换成了省略号。原文 *nekkhammaṃ jhāyatīti jhānaṃ* 是连续的一句，中间没有省略。→ **必改**：改成“**出离在禅思，所以是禅**”等。
- §1978 的 哪一种取 / 这一种取：父层对照里没有这两句（应在 1193 段以后），无法逐字核对。父层 1192 把 *ekupādānā* 译为“一种取”，本层与之相容。

## 跨段一致性

- *Tathā sesesupi*（§1974）译为“其余各处也是一样”，*Evaṃ sesesupi*（§1975）译为“其余各处也是这样”。两处功能相同，建议统一为“其余各处也是这样”。
- 下面几处是父层问题，供 harmonize 处理，本层黑体不能单方面改：
  - **父层 1181 “无常随观的如实智”**：本层 §1975 明说 *ubhayampi paccattavacanaṃ*（两词都是主格，属同位关系）。父层用“的”字，读起来像属格，与本层的解释相抵触。建议父层改为“无常随观这一如实智”之类的同位结构，再同步本层黑体。
  - **父层 1184 *daratha* 译“焦虑”**：本层 §1976 用 *uṇhaṭṭhena*（以“炎热”义）来解释这个词，nissaya 作 ပူအိုက်တတ်သော（闷热的）。读者会看到“因为炎热，所以称为焦虑”，比喻断了。建议父层改为“热苦”或“燠热”。
  - **父层 *vatthuvasena pariyāyena* 前后不一**：1178/1181 作“按所依的事物、按不同的角度”，1184/1188 作“依所依事、依方式”。本层 §1974 只注释一次，跟的是前一种。父层后几段与本注对不上。
  - **父层 *anupādā cittassa vimokkho* 前后不一**：1188 作“无取的心解脱”，1190 作“无执取之心的解脱”（含文言“之”）。另外，nissaya 把 *anupādā* 解为独立式（တဏှာဒိဋ္ဌိအားဖြင့် မစွဲလမ်းမူ၍，“不以渴爱、邪见执取”），修饰的是“解脱”，不是“心”。

## §1974 句 120-1974-62-65
- **问题**：误译／漏义。nissaya 写作 `အနိစ္စနုပဿနာ ဉာဏန္တိဝါ`，两词分开。也就是说，异读是不复合的两个词 *aniccānupassanā ñāṇaṃ*，正好与上句“是一个复合词”形成对照。译文只照抄了一个巴利词形，读者看不出差别在哪里。
- **建议**：改为“也有读本把它分作两个词（aniccānupassanā ñāṇaṃ）”。

## §1974 句 120-1974-44-57
- **问题**：漏译。*yaṃ vā* 的 *vā* 表示另一种解法，译文没有译出。
- **建议**：句首补“或者说：”，如“或者说，这是在问：被规定为‘可以’的，怎样才会是这样。”

## §1974 句 120-1974-100-110
- **问题**：取义不明。nissaya：`နန္ဒိသမ္ပယုတ္တာယ= တဏှာနှင့်ယှဉ်သော`，即 *nandi* 指渴爱（喜贪），不是 *pīti*。译文“与喜相应”容易被读成喜觉支的喜。
- **建议**：黑体不动，释文改为“与喜（即渴爱）相应的想”。

## §1974 句 120-1974-174-206
- **问题 1**：文言虚词。“……结缚的执着**之**想中解脱”用了“之”。→ **必改**：改为“……结缚的执着**这些**想中解脱”，或“对……的想”。
- **问题 2**：补出成分（可选）。nissaya 在这里补了 `အဘိနိဝေသာမုစ္စနဋ္ဌေန ဧကတ္တာ`（“因为‘从执着中解脱’这层意义相同”），说明为什么一句话就等于说了四种执着。
- **建议**：可在“就等于已经说了”前补“因为从执着中解脱这层意思相同，”。

## §1975 句 120-1975-15-19
- **问题**：语义不足。nissaya：`ဉာဏတ္ထော= ဉာဏဝိမောက္ခော ဟူသောပုဒ်၌ အကျုံးဝင်သော ဉာဏသဒ္ဒါ၏အနက်`，意思是这里说明的是“智解脱”一词中“智”的含义。
- **建议**：改为“‘**如实智**’说明的是（智解脱中）‘智’的含义”。下句 120-1975-29-33 同理，可改为“说明的是（智解脱中）‘解脱’的含义”。

## §1975 句 120-1975-23-28
- **问题**：格。nissaya：`အညာဏာ= မောဟမှ`，是从格“从……”。译文“作为愚痴的无知”丢掉了从格，与父层“从……中解脱”的句法也接不上。
- **建议**：改为“就是从作为愚痴的那种无知中”。

## §1976 句 120-1976-2-25
- **问题 1**：所指易误。nissaya 把 *anuttarassa* 解为 `လွန်ကဲသော တရားမရှိသော မဂ်ဖိုလ်နိဗ္ဗာန်`，即无有更胜者的道、果、涅槃。译文“无上者”容易被读成指人（佛陀）。
- **建议**：改为“或者因为它是无上之法（道、果、涅槃）的助缘”。为避免“之”，也可作“无上的法（道、果、涅槃）”。
- **问题 2**：格式。“**无上的****清凉之智**”两个黑体紧挨在一起，会出现 `****`，有的 markdown 渲染器会显示错乱。
- **建议**：合并为“**无上的清凉之智**”，文字与父层一致，不影响对应关系。

## §1976 句 120-1976-64-69
- **问题**：增义。原文 *idha pana vipassanā anuttaro sītibhāvo* 只是对比“这里所指”，并没有排他的意思，译文的“才是”多出了强调。
- **建议**：改为“但在这里，无上的清凉指的是观”。

## §1977 句 120-1977-12-18
- **问题**：句法不完整。句末“都只是顺抉择分的”悬空，*hoti* 的表语没有落实。nissaya 的异释作“只是趋向观的”。
- **建议**：改为“都只属于顺抉择分”。

## §1978 句 120-1978-65-69
- **问题**：误读。nissaya：`ပုဗ္ဗဉာဏပေက္ခံ= ရှေ့၌ဆိုအပ်ခဲ့ပြီးသော ဉာဏံဟူသောပုဒ်ကို ငဲ့သောပုဒ်`，即 *idaṃ* 是照应前文 *ñāṇaṃ* 这个词，指“这种智”。这是一条语法说明，不是“着眼于前面的智来说”这种泛泛的说法。
- **建议**：改为“或者，‘**这**’是照应前面的‘智’一词，指这种智”。

## §1978 句 120-1978-70-87
- **问题**：漏补出成分。nissaya 在 *upādānato muccanesu* 之后补了 `ဧဝံ ဝေဒိတဗ္ဗော`（“应当这样理解”）。缺了这一句，“在从取中解脱这方面”就没有着落。
- **建议**：改为“在从取中解脱这方面，应当这样理解：因为修行者起初……”。

## §1978 句 120-1978-109-124
- **问题 1**：句法误读。*sīlabbatena attā sujjhati* 中，*attā* 是主格，*sujjhati* 是不及物动词（我由戒禁而得清净）。译文“以戒禁使我清净”变成了使动、及物的句子。
- **建议**：改为“我通过戒禁而得清净”。
- **问题 2**：补出成分。nissaya：`ဒိဋ္ဌိပ္ပဟာနေနေဝ= ဒိဋ္ဌုပါဒါန်ကိုပယ်သဖြင့်`，这里的“见”指见取。
- **建议**：“断除了见”改为“断除了见取”。
