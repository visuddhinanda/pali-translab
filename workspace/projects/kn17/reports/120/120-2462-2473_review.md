# Review — 120:2462-2473（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（120-2470-59-65、120-2470-66-72 两句无 nissaya，略过；120-2470-45-51、120-2470-52-58 两行 nissaya 错位，见下文）

## 被解释词与父层对照

逐条核对了黑体被解释词与父层（book 151）定稿译文，结果如下：

- 四种 / 这 / 比丘们 / 念住 / 是哪四种 / 在这里 / 比丘：与 151-1971 一致 ✅
- 地身 / 水身 / 发身：与 151-1972、151-1974 一致 ✅
- 乐受 / 苦受 / 不苦不乐受 / 有世俗味的乐受 / 无世俗味的乐受 / 有世俗味的苦受 / 无世俗味的苦受 / 有世俗味的不苦不乐受 / 无世俗味的不苦不乐受：与 151-1976、151-1977 一致 ✅
- 有贪的心：与 151-1979 一致 ✅
- 其余的诸法：与 151-1983 一致 ✅
- 以那智：与 151-1972、1974、1976、1979、1981 一致 ✅。但父层 151-1983 作「以那个智」，父层内部不统一。本层不必改，请在 harmonize 时统一父层。
- 父层另有两处漂移，本层无需改动，供 harmonize 参考：
  - 151-1983 作「念处修习」，151-1985 作「念处论结束」，其余各处都作「念住」。本层一律用「念住」，没有跟着漂移。
  - 151-1983 起，父层的语体与句式也与前文不同，例如「随观为无常，而不是常」「（四）」。

## 跨段一致性

- **黑体被解释词的引号体例**：多数条目写作“**X**”，但 §2469 句 120-2469-35-46 的「**肾**等」、§2470 句 120-2470-19-22 的「**苦受**也是这样」没有加引号。建议统一加全角引号：“**肾**”等、“**苦受**”也是这样。
- **paṭṭhāna 的译法**：§2464 句 91-96 译「住处」，§2465 句 41-49、90-100、101-104 译「住」。nissaya 对三处的释义本来就不同：§2464 作 တည်ရာ「所立之处」，§2465-41 作 ဖြစ်စေအပ်သော「被建立者」，§2465-90 作 တည်တတ်「能安立者」。所以区分是有依据的，但 §2465-41 的「住」没有传达「被建立」这层意思，见下文该句。
- **钝根 / 利根的句式**：§2467 句 13-28 用「对于钝根的爱行者，粗显的身随观念住是清净之道」，句 29-38 起改用「对于见行者，钝根的以……为清净之道」。四组是平行结构，建议统一成一种句式。
- **「四X」的列举**：§2468 句 60-69 作「四暴流、四轭、四漏、四系、四取、四种不应行」，最后一项多了「种」字。建议统一为「四不应行」，或者全部加「种」。

## §2464 句 120-2464-2-19
- **问题**：补出成分。nissaya 把 `အတ္တနာ= မိမိဟုဆိုအပ်သော မထေရ်သည်`、`ဒဿေန္တေန= မထေရ်သည်` 都标明了施事者是长老（本论作者）。译文只写「自己」，又省略了「讲述」的主语，读者不知道是谁说了神变、谁讲了这部论。
- **建议**：补出施事者，例如：「现在，在同首论之后，长老为了显示能成就他自己所说的神变的七种随观差别，讲述了以经为先导的念住论；以下注释这部论中前面没有解释过的意义。」

## §2464 句 120-2464-20-36
- **问题**：风格 + 指代。nissaya `တေန= ထိုစတ္တာရော-ဟူသောပုဒ်ဖြင့်` 说明 tena 指的是「‘四’这个词」。译文「以此表明」用了文言式的「以此」，指代也不清楚。
- **建议**：改为「用这个词表明念住的范围」。

## §2464 句 120-2464-45-58
- **问题**：词法。`ပဋိဃာနုနယဝီတိဝတ္တတာ= …လွန်တော်မူသည်၏အဖြစ်` 是抽象名词「超越的状态」，译文译成了动词短语，句子缺少名词中心。另外，`ပဋိပန္နေသု= ကျင့်ကုန်သော` 是「修行」，译成「行事」意思太泛。
- **建议**：改为「导师对以三种方式修行的弟子们超越瞋恚与爱着的状态，也是念住」。§2465 句 2-40 的同一短语要同步修改。

## §2464 句 120-2464-91-96
- **问题**：补出成分。nissaya `တဿ= ထိုပါဠိ၏` 把 tassa 限定为「那段经文的」，`တသ္မိံ= ထို အာရုံ၌` 把 tasmiṃ 限定为「在那所缘上」。译文的「它」「在那里」都含糊不清。
- **建议**：改为「这段经文的意思是：在那所缘上安住，所以是住处」。

## §2465 句 120-2465-2-40
- **问题**：词法。
  - `အရဟတိ= ထိုက်၏` 表示「堪当、值得」，不是「能够」。
  - `သတ္ထာ… အရိယော= မြတ်စွာဘုရားသည်` 表明 satthā 与 ariyo 是同位的主语，不是「作为导师」。
  - `ဂဏံ= တပည့်သား အပေါင်း` 指弟子众，译成「大众」偏宽。
  - 同一句里「三种方式行事」的问题同 §2464 句 45-58。
- **建议**：改为「在‘有三种念住，是圣者所习行的；导师、圣者习行了它们，就堪当教导弟子众’（《中部》3.304、311）这里，导师对以三种方式修行的弟子们超越瞋恚与爱着的状态，被称为‘念住’」。

## §2465 句 120-2465-41-49
- **问题**：词法 + 指代。
  - nissaya `ပဋ္ဌပေတဗ္ဗော= ဖြစ်စေအပ်သောကြောင့်` 表示「因为应被建立」，paṭṭhāna 在这里取「被建立者」的意思。只译作「住」，词源解释就接不上了。
  - tassa 在 nissaya 中是 `ထို တယော သတိ ပဋ္ဌာနာ-ဟူသော ပါဌ်၏`（「‘三种念住’这句经文的」），译文的「它」含糊。
- **建议**：改为「这句经文的意思是：因为应当被建立，所以称为‘住’（paṭṭhāna），也就是应当被推行的意思」。

## §2465 句 120-2465-120-122
- **问题**：补出成分。nissaya `ဣဒံ= ဤတတိယမြောက်ဖြစ်သော သတိပဋ္ဌာန်ကို`、`ဣဓ= ဤပါဠိ၌` 明确指出：这里所指的是第三种念住（念本身），所在是这段经文。译文「这里所指的就是这个意思」没有说出是第三种，读者无法把它和前面的三分法对应起来。
- **建议**：改为「这段经文所指的就是这第三种，也就是念本身」。

## §2467 句 120-2467-11-12
- **问题**：格。nissaya `ဝေနေယျဟိတတ္တာ= …ဆောင်တတ်သည်၏အဖြစ်ကြောင့်` 是从格，表原因（「因为能带来利益」）。译文「为了利益」变成了表目的，与下文 §2468 真正表目的的 -atthaṃ（「为了舍断」）分不开。
- **建议**：改为「因为这样能利益应受调教的人」。

## §2467 句 120-2467-13-28（及 29-38、39-52、53-61）
- **问题**：风格（必改）。「清净之道」里的「之」是文言虚词。另外，`ဝိသုဒ္ဓိမဂ္ဂေါ= အရိယာမဂ်၏အကြောင်း` 表示这是「通往清净的道路」。
- **建议**：四句统一改为「清净道」或「通往清净的道路」。

## §2469 句 120-2469-29-34
- **问题**：主语不清。数量多的是头发等本身（kesādīnaṃ bahukattā），不是「发身」这个说法。nissaya `ကေသကာယ-အစရှိသော သဒ္ဒါတို့ကိုလည်း… ကတံ` 也表明，kesakāyādi 指的是被采用的那些词。译文「‘发身’等也因为数量多」读起来像是「发身」很多。
- **建议**：改为「‘**发身**’等也是这样：因为头发等数量很多，所以用了‘发身’等说法」。

## §2470 句 120-2470-45-51、120-2470-52-58
- **问题**：数据疑问，不是译文问题。这两行的 nissaya 内容是 `သာမိသံ အဒုက္ခမသုခံ…ဥပေက္ခာဝေဒနာ`、`နိရာမိသံ အဒုက္ခမသုခံ…`，对应的其实是后面 59-65、66-72 两句，与本行的 pali（sāmisaṃ / nirāmisaṃ dukkhaṃ）错位。译文按 pali 译出，内容正确，不需要改。nissaya 的对齐请另行核查。

## §2472 句 120-2472-2-12
- **问题**：风格（必改）。「三地之法」里的「之」是文言虚词。
- **建议**：改为「三地的法」。

## §2472 句 120-2472-21-31
- **问题**：句法歧义。nissaya `အဝုတ္တတ္တာနိ= မဖွင့်ဆိုအပ်သော အနက်ရှိကုန်သော` 意为「其意义没有被解释的（词）」。译文「没有解释意义的词」容易读成「没有意义的词」。
- **建议**：改为「这里中间夹杂的、意义没有解释的词，在前面相应的地方都已经解释过了」。
