# Review — 120:1767-1776（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（父层对照：151:913 定稿译文）

## 被解释词与父层对照

逐一比对，以下黑体词与父层 151:913 译文**逐字相同**，无必改项：

- Pītipaṭisaṃvedī → 觉知喜 ✅
- Cittasaṅkhāro → 心行 ✅（父层“觉知心行”“平息心行”）
- Passambhayaṃ cittasaṅkhāraṃ → 平息心行 ✅
- pīti / sukha（pade）→ 喜 / 乐 ✅（父层“觉知喜”“觉知乐”）
- Abhippamodayaṃ cittaṃ → 使心喜悦 ✅
- Samādahaṃ cittaṃ → 使心专注 ✅
- Vimocayaṃ cittaṃ → 使心解脱 ✅
- Aniccānupassī / aniccaṃ → 随观无常 / 无常 ✅
- Virāgānupassī → 随观离贪 ✅
- Nirodhānupassī → 随观灭 ✅
- Paṭinissaggānupassī → 随观舍遣 ✅

## 跨段一致性

- **-to 格（ārammaṇato / asammohato）**：§1767、§1768、§1769 统一译作“从所缘”“从不迷惑”。但 nissaya 两处都作 `အာရမ္မဏတော= အာရုံပြုသောအားဖြင့်`、`အသမ္မောဟတော= မတွေဝေသောအားဖြင့်`，用的是 `အားဖြင့်`（方式/途径，“通过……”），不是 `မှ`（从格）。“从”是按夺格字面硬译，读者会误以为喜“来自”所缘。建议三段一起改为“通过所缘”“通过不迷惑”，或“就所缘而言”“就不迷惑而言”，含黑体处同步。
- **pada 的译法**：§1769 句 68-79 “在**喜**一词中”“在**乐**一词中”译作“一词”；§1769 句 80-123 “两个心行句”、§1774 / §1775 / §1776 “这一句”、§1775 句 53-57 “一句”译作“句”。nissaya 把 pīti pade 释为 `ပီတိပဋိသံဝေဒီ အစရှိသည်ဖြင့် ဟောအပ်သော ပုဒ်`（以 pītipaṭisaṃvedī 开头的那一句），指的是整句而非单词。建议统一为“句”。
- **paṭisaṃviditā hoti 的语态**：§1767、§1768、§1769 前半用被动（“喜……被觉知”）；§1769 句 31-40 / 41-46 和 §1770 句 2-8 改成主动（“觉知乐”“觉知心行”“觉知心”）。nissaya 全部作 `ထင်စွာပြုအပ်သည်`（被弄清楚，被动）。建议统一，例如“乐被觉知”“心行被觉知”“心被觉知”。
- **lakkhaṇapaṭivedhena**：§1769 句 6-24 与 §1772 都译“通达诸相”，“诸相”含糊。nissaya 在 §1769 作 `ပီတိ၏ သင်္ခတလက္ခဏာ`（喜的有为特相），在 §1772 作 `လက္ခဏာရေးသုံးပါး`（三相）。建议统一为“通达特相”，或按 nissaya 分别补出。
- **veditabbo**：§1769 句 41-46 “应当理解为”，§1774 句 66-83、§1775 句 33-52、§1776 句 65-84 “应理解为”。建议统一为“应当理解为”。

## §1767 句 120-1767-2-18
- **问题**：漏译 — `အနုပဒဝဏ္ဏနာနယေနေဝ= …နည်းဖြင့်သာလျှင်`，-eva 表“只”，译文没译出。`ဧဝံ= ဤဆိုလတ္တံ့သောနည်းဖြင့်` 是指下文的“如下”，不是承上的“这样”。
- **建议**：“……所以只应当按照逐词解释的方式，如下理解它们的意义。”

## §1768 句 120-1768-8-22
- **问题**：隐含成分 — `တဿ= ထိုပုဂ္ဂိုလ်အား`（对他而言），译文没有体现。
- **建议**：“……对他来说，在入定的刹那……”。另外，nissaya 把 ārammaṇassa 释为 `ပဋိဘာဂနိမိတ်`（似相），可以考虑在报告或脚注中注明，正文不必改。

## §1769 句 120-1769-62-67
- **问题**：指代不明 — `သော= ထိုချုပ်ခြင်းကို`，nissaya 明确说 so 指“那种止灭”。译文只用“这”，读者看不出指什么。
- **建议**：“这种止灭，应当按照在身行那里所说的方法详细理解。”

## §1771 句 120-1771-5-19
- **问题**：补出成分 — `သမ္ပယုတ္တာယ ပီတိယာ= သမာပတ်နှင့် ယှဉ်သော ပီတိဖြင့်`，nissaya 补出“与入定相应”，译文只说“以相应的喜”，缺了和什么相应。nissaya 还把 āmodeti / pamodeti 分作“先使欢喜 / 后使欢喜”（`ရှေးဦးစွာ` / `နောက်၌`），可作参考。
- **建议**：“……以与入定相应的喜使心欣喜、喜悦。”

## §1772 句 120-1772-2-50
- **问题**：格 — `သမ္မသတော= သုံးသပ်သော ပုဂ္ဂိုလ်အား` 是与格（对于审察的人），下接 uppajjati（生起）。译文把它译成与后句并列的主动谓语“把……来审察，在观的刹那……就生起”，主从关系丢了。
- **建议**：“……对于把与禅那相应的心作为会灭尽、会坏灭的来审察的人，在观的刹那，由于通达三相，就生起刹那心一境性……”

## §1773 句 120-1773-2-35
- **问题**：补出成分 + 前后不对称。
  - nissaya 在第二禅、第三禅后都补出 `မောစေန္တော / ဝိမောစေန္တော`，译文这两处只有“脱离”，第一、第四禅却是“脱离、解脱”。
  - nissaya 在每个 mocento vimocento 后补出 `အဿသတိစေဝ ပဿသတိစ`（入息、出息），译文前半句缺主谓语，读来悬空。
- **建议**：四个禅那统一为“脱离、解脱”，第四禅句末补“而入息、出息”，例如“……以第四禅使心从乐与苦脱离、解脱而入息、出息；或者……”

## §1774 句 120-1774-27-28
- **问题**：取义参考 — nissaya 把 uppāda-vaya-aññathatta 释为 `ဥပါဒ်ခဏ ဘင်ခဏ ဌီခဏ`（生、灭、住三刹那），aññathatta 取“住”义。译文“变异”是字面义，不算错。
- **建议**：可以保留“变异”，在脚注里注明 nissaya 解作住刹那。

## §1774 句 120-1774-29-45
- **问题**：主语 — `နိဗ္ဗတ္တာနံ= ဖြစ်ကုန်ပြီးသော ခန္ဓာတို့၏`，nissaya 明确指已生起的诸蕴，译文泛化成“诸法”。`ခဏဘင်္ဂေန` 是具格（因刹那坏灭），不是处格。
- **建议**：“意思是：已经生起的诸蕴不以原来的样子持续，而因刹那坏灭而破灭。”

## §1774 句 120-1774-60-65
- **问题**：漏译成分 — `သမန္နာဂတော= ပြည့်စုံသော ပုဂ္ဂိုလ်တည်း`，被定义的是“人”，译文“是指具备那种随观”把人丢了，变成了定义随观本身。
- **建议**：“**随观无常**，是指具备那种随观的人。”

## §1774 句 120-1774-66-83
- **问题**：取义参考 — `ဣဓ= ဤခန္ဓာငါးပါး၌`，nissaya 把 idha 解作“在这五蕴上”，译文“在这里”容易被读成“在这段经文里”。
- **建议**：可以改为“对这五蕴随观无常”的结构，或者保留“在这里”、在脚注说明。

## §1776 句 120-1776-19-39
- **问题**：句法 — `တန္နိန္နတာယ= ထိုနိဗ္ဗာန်သို့ ညွတ်သည်၏အဖြစ်ဖြင့်` 是具格（由于倾向涅槃），修饰 pakkhandati（跃入）。译文把它抬成独立谓语“倾向于……，因而跃入涅槃”，“涅槃”也重复了一次。
- **建议**：“……又由于见到有为法的过患，因倾向于与它相反的涅槃而跃入涅槃，所以……”

## §1776 句 120-1776-57-64
- **问题**：格误读 — `ပုရိမဉာဏာနံ= ရှေ့ဖြစ်သော ဉာဏ်တို့ကို` 用宾格助词 `ကို`，前面各个智是被观照的对象。译文“随着前面各个智来观照”把它当成了伴随者。
- **建议**：“而这两者，都因为一再随后观照前面的各个智，所以称为随观。”
