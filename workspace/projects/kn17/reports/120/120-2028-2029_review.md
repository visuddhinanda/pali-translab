# Review — 120:2028-2029（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层对照（151:1292-1305）✅

## 被解释词与父层对照

逐个核对了黑体词。每个黑体词都与父层 151:1296-1304 译文中对应的定语部分逐字相同，父层在后面加的“业”字由本层句式承接，不算不一致：

| 黑体词 | 本层译法 | 父层译法 | 结论 |
|---|---|---|---|
| kusalaṃ / akusalaṃ | 善 / 不善 | 善业 / 不善业 | ✅ |
| sāvajjaṃ / anavajjaṃ | 有罪的 / 无罪的 | 有罪的业 / 无罪的业 | ✅ |
| kaṇhaṃ / sukkaṃ | 黑 / 白 | 黑业 / 白业 | ✅ |
| sukhudrayaṃ / dukkhudrayaṃ | 生起快乐的 / 生起痛苦的 | 生起快乐的业 / 生起痛苦的业 | ✅ |
| sukhavipākaṃ / dukkhavipākan | 带来快乐异熟的 / 带来痛苦异熟的 | 带来快乐异熟的业 / 带来痛苦异熟的业 | ✅ |

## 跨段一致性
- 无。句式“因为……所以是**X**”在 2028-33 至 2028-64 各句中统一使用。sukha 都译“快乐”，dukkha 都译“痛苦”，kusala 都译“善”，akusala 都译“不善”，前后一致。2028-21-32 的 -aṭṭhena 译作“就……的意义而言”，-ttā 译作“因为”，两者是不同的词尾，分开译是合理的。

## §2028 句 120-2028-33-41
- **问题**：格与句法（必改项）。“eva”的限定对象译错了。nissaya 是 `အကုသလမေဝ= သည်သာလျှင်`，“သာလျှင်”（唯、只）附在主格“သည်”上，限定的是主语“不善”，意思是“只有不善才有罪”。译文写成“不善**正是因为**……”，把 eva 挪到了原因状语上，变成强调理由，原文的排他判断就丢了。
- **建议**：改为“只有不善，因为与贪等过患相结合，才是**有罪的**；善因为没有这些过患，所以是**无罪的**。”
- **补充（可选）**：tadabhāvena 的 nissaya 是 `ထိုရာဂအစရှိသော အပြစ်နှင့်ယှဉ်ခြင်း၏ မရှိခြင်းကြောင့်`，意思是“因为没有**与**贪等过患**相结合**”，否定的是“相结合”这件事。译文“没有这些过患”意思基本不差，要更贴切可改为“因为不与这些过患相结合”。

## §2028 句 120-2028-56-63
- **问题**：词法（轻微）。sukhavuddhimattā / dukkhavuddhimattā 的 -mant 是“具有”的意思。nissaya `ပွားစည်းသော ချမ်းသာသော အကျိုးရှိသည်၏အဖြစ်ကြောင့်` 的意思是“因为具有不断增长的快乐果”，说的是善业**具有**这种增长，不是译文“能增长快乐”所暗示的主动使动。
- **建议**：可改为“善因为具有快乐的增长，所以是**生起快乐的**；不善因为具有痛苦的增长，所以是**生起痛苦的**”。也可以保留现译，影响不大。

## §2028 句 120-2028-64-75
- **问题**：术语区分（轻微）。本句是用 phala（果）来解释 vipāka（异熟）。sukhaphalavattā 在 nissaya 里只标了格（`အဖြစ်ကြောင့်`），没有另给词义，所以按原文取 phala，直译“果”。译文用“果报”，读者容易把它和被解释的“异熟”混为一谈，这样“用果来解释异熟”的层次就看不出来了。
- **建议**：“果报”改成“果”：“善因为有快乐的果，所以是**带来快乐异熟的**；不善因为有痛苦的果，所以是**带来痛苦异熟的**。”
