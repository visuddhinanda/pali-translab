# Review — 120:1450-1457（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§1452 偈颂上半无 nissaya，略过）／父层对照 ✅（book 151 §647-681）

## 被解释词与父层对照

逐条核对了 28 个黑体被解释词：Tantākulakajāto、Kulāgaṇṭhikajāto、Muñjapabbajabhūto、apāyo / duggati / vinipāto、Avijjāvisadosasallitto、Kilesakalalībhūto、Rāgadosamohajaṭājaṭito、Jaṭaṃ vijaṭetā、Taṇhā- 七项、Diṭṭhisaṅghāṭā、Anugato / Anusaṭo / Abhibhūto / Abbhāhato / Dukkhe patiṭṭhito、Taṇhāya uḍḍito、Jarāpākāraparikkhitto、Maccupāsena parikkhitto、Mahābandhanabaddho、Rāga- / Kilesa- / Duccarita-bandhanenā。它们**全部与父层译文逐字相同**，没有必改项。

另有一处疑问需要反馈给父层（本层不改）：
- **Kulāgaṇṭhikajāto**：父层译「像纠结的鸟巢」，取的是本段 §1450-123-135 所引「也有人说（eke）」的那个解释。本段的正解见 §1450-119-122：kulāgaṇṭhika = pesakārakañjikasutta。nissaya 对这两处都释为 `ယက္ကန်းသည်တို့၏ ပအုန်းရည်ဆွတ်သော ချည်ထွေး`（织工浸过米浆的线团）。父层的取义因此与本层主解相反，建议本文层重新斟酌。在本文层定案之前，本层黑体继续保持「像纠结的鸟巢」。

## 跨段一致性
- **khalita / pakkhalati**：§1450-8-47 的 khalitā 译「迷失」，§1450-72-98 的 pakkhalitvā 译「失足」。nissaya 两处都作 `ချော်ချွတ်`（滑脱、失足）。建议统一为「失足」。
- **agga / mūla**：§1450 共三处都译「头 / 尾」。nissaya 作 agga= `အဖျား`（末梢）、mūla= `အရင်း`（根部）。「头」在汉语里容易被理解为起头，反而对应 mūla。建议三处统一改为「梢 / 根」或「末端 / 根端」。
- **1456 组释词的语态**：被解释词在父层都是被动（被生追随、被老侵袭、被病压倒、被死打击），nissaya 的释词也多带被动标记 `အပ်၏`。本层译文却有的主动、有的被动，读起来前后不齐，具体见 §1456 各条。
- **「之」作定语**：§1454-36-54 的「无明之毒」可改为「无明的毒」。被解释词里的「渴爱之网 / 渴爱之流」来自父层，不动。

## §1450 句 120-1450-48-71
- **问题**：补出成分 — 「两位菩萨」误导读者以为是两个人。nissaya 补注：`ဒွေ ဗောဓိသတ္တေ= ဘုရားပစ္စေကဗုဒ္ဓါတို့၏ အလောင်းတို့`，即佛与辟支佛的菩萨；并说明这两者在得阿罗汉道之前就已了知缘起，所以称为菩萨。
- **建议**：改为「除了两种菩萨（未来的佛与辟支佛）以外」。
- **问题**：词义 — Tattha 的 nissaya 作 `ထိုဥပမာ ဥပမေယျ၌`（在那譬喻与所喻之中），「在这件事上」没有表达出来。
- **建议**：改为「在这里（譬喻与所喻之间）」，或改为「就这两者来说」。

## §1450 句 120-1450-162-217
- **问题**：词义 — koṭṭetvā koṭṭetvā 的 nissaya 作 `ခုတ်စဉ်း၍ / စိတ်၍`（砍削、劈开），不是「捶打」。
- **建议**：改为「把那些草一再劈开，搓成绳子」。
- **问题**：宾语脱落 — tampi 的 nissaya 作 `ဆွေးမြည့်လေပြီးသော မြက်ကြိုးကိုလည်း`（那条已经朽烂的草绳也），译文作「这件事」，宾语丢了。
- **建议**：改为「就连那条朽烂的草绳，也还可以靠各人自己的努力理顺」。另外 jiṇṇakāle 的 nissaya 作 `ဆွေးမြည့်`（朽烂），「旧了」可改为「朽烂了」。
- **问题**：与 §1450-48-71 同样的「两位菩萨」问题。
- **建议**：同步改为「两种菩萨（未来的佛与辟支佛）」。

## §1450 句 120-1450-8-47
- **问题**：跨段一致性 — khalitā 译「迷失」，参见上节。
- **建议**：改为「在缘起的方式上失足」。

## §1456 句 120-1456-7-10
- **问题**：语态 — anudhāvito 是过去被动分词，nissaya 作 `မပြတ်ပြေးသွား၏`，并对应被动的被解释词「被老侵袭」。「就是追逐」是主动说法。
- **建议**：改为「就是被追逐」。

## §1456 句 120-1456-11-14
- **问题**：语态 — pīḷito 的 nissaya 作 `နှိပ်စက်အပ်၏`，带被动标记。
- **建议**：改为「就是被折磨」。

## §1456 句 120-1456-15-21
- **问题**：语态 — abhiāhato / pahato 的 nissaya 作 `ရှေးရှုပြင်းစွာ ခတ်အပ်၏`，带被动标记。
- **建议**：改为「就是被迎面打击，被迎面狠狠地击打」。

## §1457 句 120-1457-8-20
- **问题**：词义取向 — nissaya 把 cakkhu 释为 `စက္ခုဝိညာဉ်`（眼识），sotādīni 释为 `သောတဝိညာဉ် အစရှိသည်`（耳识等）。
- **建议**：可以保留「眼 / 耳等」以贴合字面，但这里的取义应记入术语存疑。如果改译，后面 §1457-21-24 的「具有这些的世间」要同步改。

## §1457 句 120-1457-77-83
- **问题**：句法 — pali 用 atthi 并列两个分词：hetubhūtaṃ（作为解脱的因）与 bandhanamokkhabhūtañca（本身就是解脱）。nissaya 补出 sucarita 指 `လောကီ လောကုတ္တရာ`，即世间与出世间两类善行。译文把两者并成同一主语的两个属性，层次不清。
- **建议**：改为「至于善行，有的是解脱束缚的原因，有的本身就是对束缚的解脱（世间与出世间的善行）」。

## §1457 句 120-1457-49-59
- **问题**：补出成分 — 「贪本身就在束缚」缺宾语，读起来生硬。nissaya 作 `ဗန္ဓတိ= ဖွဲ့တတ်၏`，`စလိတုံ= ရွေ့ရှားခြင်းငှါ`（使之移动；异释为前往涅槃）。
- **建议**：改为「贪本身捆住众生，不让他们从轮回中挪动」。

## §1451 句 120-1451-2-9
- **问题**：并列项体例不齐 — nissaya 四项都作 `…ဘုံ`（界、地），译文却是「地狱、畜生、饿鬼界、阿修罗众」，有的带「界」、有的不带。
- **建议**：改为「地狱、畜生界、饿鬼界和阿修罗众」。

## §1451 句 120-1451-33-35
- **问题**：补出成分 — nissaya 补出 `ဧဝံ ဝေဒိတဗ္ဗံ`（应这样理解）。
- **建议**：可改为「至于另一个，也就是轮回，应当这样理解：」。属于可选项。
