# Review — 120:1419-1422（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照

逐条核对本层黑体词和父层（151:623-633）定稿译文，全部逐字一致：如来的／看见众生／少尘垢／多尘垢／利根／钝根／善相／恶相／容易教导／难以教导／有些人看见他世与罪过的可怖／有些人看不见他世与罪过的可怖／世间／罪过／有信的／没有信的／精进的／懈怠的／正念现前的／失念的／得定的／不得定的／有慧的／无慧的／有信的人是利根的／没有信的人是钝根的／有信的人是善相的／没有信的人是恶相的／看见他世与罪过的可怖／蕴世间／失败的有世间／失败的生起世间／成就的有世间／成就的生起世间／一种世间。**无必改项。**

## 跨段一致性
- **kucchita**：§1420 句 120-1420-118-135 译「低劣」，§1421 句 120-1421-55-64 译「可鄙的」。nissaya 两处都作 `ကုစ္ဆိတာ= စက်ဆုပ်အပ်သော`（可厌的）。建议统一为「可鄙」。
- **virūpa**：§1421 句 120-1421-204-212 译「丑陋的」，§1422 句 120-1422-35-54 译「丑恶的」。nissaya 两处都作 `ဖောက်ပြန်သော`（乖逆的、走样的）。建议统一为一个译法，推荐「丑恶」。
- **Te + 宾格复述句**：句 120-1420-84-86（Te apparajakkhe）与句 120-1420-182-186（Te paralokavajjabhayadassāvine）结构相同。两句都丢了宾格指向（见下文分句意见），应按同一方式一并修改。

## §1420 句 120-1420-53-68
- **问题**：风格（必改）——「以根上下智**之**眼」用了文言虚词「之」；「粘附**于**色等」用了文言介词「于」。
- **问题**：词法——nissaya `ဣန္ဒြိယပရောပရိယတ္တ ဉာဏေန= …ဟု ဆိုအပ်သော။ စက္ခုနာ= ပညာမျက်စိဖြင့်` 表明「眼」是慧眼，根上下智是这只眼的名称（同位关系），不是领属关系。
- **建议**：「因为以欲贪执着、粘附在色等上，所以称为众生；如来用称为根上下智的慧眼看见、观察这些众生。」

## §1420 句 120-1420-84-86
- **问题**：格与句法——nissaya `တေ အပ္ပရဇက္ခေ= ထိုအပ္ပရဇက္ခပုဂ္ဂိုလ်တို့ကို` 是宾格，表示这些少尘垢的人是本文 passati（看见）的宾语。现译「也就是这些少尘垢的人」看不出这一层承接关系。
- **建议**：「如来看见的就是这些少尘垢的人。」或「（看见）这些少尘垢的人。」

## §1420 句 120-1420-118-135
- **问题**：句法——nissaya 把 `အာကာရာ ကောဋ္ဌာသာ= အဖို့အစုတို့သည်` 合成一个单元，koṭṭhāsa 是对 ākāra 的同位释词，不是并列的另一项。现译「行相、部分美好」读起来像两样东西并列。
- **问题**：取义——kucchita 译「低劣」偏离 nissaya 的「可厌」，见跨段一致性。
- **建议**：「他们的信等行相（也就是组成部分）美好，所以是善相的；他们的信等行相（组成部分）可鄙、受人呵责，所以是恶相的。」

## §1420 句 120-1420-154-181
- **问题**：句法——这是第二解。nissaya 作 `ပရံဗာဠှံ= လွန်မင်းစွာ`，把 para 重新解为副词「极其」，并以处格 `ခန္ဓာဒိလောကေစ…၌ / ရာဂါဒိဝဇ္ဇေစ…၌` 表示「在蕴等世间和贪等罪过上，惯于极其强烈地看见可怖」。现译没有交代 para 在这里不再指「他世」，读者无法理解为什么仍称为「看见他世与罪过的可怖」。
- **问题**：重复——`ဂဟေတဗ္ဗော`（应当理解）在原文中只出现一次，属于句 120-1420-182-186。本句译文已经先说了「所以应当理解为」，下一句又说「应当这样理解它的意思」，两句重复。
- **建议**：删去本句的「所以应当理解为」，并点明 para 的取义。例如：「……不过，因为这个词的详释中唯独没有提到他世，所以这里的 para 是‘极其’的意思：对蕴等世间和贪等罪过，惯于极其强烈地看见可怖，因此称为看见他世与罪过的可怖的人。」下一句 120-1420-182-186 保留「应当这样理解它的意思」，并照句 120-1420-84-86 的方式补出宾格承接。

## §1421 句 120-1421-11-19
- **问题**：句法——okappanasaṅkhātā 修饰 saddhā，nissaya 作 `ဩကပ္ပနသင်္ခါတာ= သက်ဝင်ယုံကြည်ခြင်းဟု ဆိုအပ်သော။ သဒ္ဓါ`，意为「称为深信的那个信」，中心词是「信」。现译「具有对三宝的确信，也就是信」把中心词弄颠倒了。
- **建议**：「其中，他具有对三宝的信，也就是深信不疑，所以是**有信的**。」

## §1421 句 120-1421-20-30（附注，不改）
- 本句及 175-190、204-212 中，nissaya 把 assaddhiya 释为或异释为 `မစ္ဆေရ`（悭）。这与 pali 字面不合，属于 nissaya 自身的异释。译文取「不信」合乎原文，维持不变，只在这里备案。

## §1421 句 120-1421-230-249
- **问题**：风格（必改）——「与**之**相应」用了文言虚词「之」；「以**此**为缘」是半文言写法。
- **问题**：数——taṃ- 指前面的 saddhādīni（信等，复数），nissaya `ထို…သဒ္ဓါ ဝီရိယ သမာဓိ စသည်တို့`（那些信、精进、定等）明确是复数，用「之/此」单数指代不准。
- **建议**：「……凭借与这些信等相应的慧；或者，具足十分清净的信等的人，也凭借以这些信等为缘的慧，成为看见他世与罪过的可怖的人。」

## §1421 句 120-1421-250-262
- **问题**：句法与所指——nissaya `စတ္တာရော= လေးယောက်သော ပုဂ္ဂိုလ်တို့ကို`，并有异释「具足信、具足精进、具足念与定的」，指的是四种**人**（有信的、精进的、正念现前的、得定的），不是信等四法。现译「信等四者」容易被读成四种根或法。
- **建议**：「正因为这样，有信的人等四种人也被说成是‘看见他世与罪过的可怖’的。」

## §1422 句 120-1422-35-54／120-1422-79-98
- **问题**：词法（轻微）——bhavatīti bhavo，nissaya 作 `ဘဝတိ= ဖြစ်တတ်၏`（会生成、出现），是动态义。现译「因为存在」偏向静态。
- **建议**：「因为会生成，所以称为有」。两句同步修改。
- **问题**：virūpa 译「丑恶」，与 §1421 的「丑陋」不一致，见跨段一致性。

## §1422 句 120-1422-60-74／120-1422-104-118
- **问题**：词法——sambhavati etasmā phalan ti sambhavo 中，etasmā 是从格，nissaya 作 `ဧတသ္မာ= …မှ (ဝါ) ကြောင့်`，并把 `သမ္ဘဝေါ= ဖြစ်ကြောင်း` 释为「生起的来源、原因」，指的是业本身。现译「所以称为生起」读来像是在说果报的生起这件事。
- **建议**：黑体与术语保持「生起」不动，在释义处点明是来源义：「因为果报从它生起，所以它称为‘生起’（指果报生起的来源）；……」两句同步修改。
