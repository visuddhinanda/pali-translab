# Review — 120:1777-1784（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1779-214-216、1780-2-11 无 nissaya 单元，略过）

## 被解释词对照（父层 151:913-914）

逐条核对的结果：全部与父层逐字一致，**无必改项**。

- idhā = 这里 ✓
- imissā diṭṭhiyā = 这个见解 ✓
- diṭṭhi / khanti / ruci / ādāya / dhamma / vinaya / dhammavinaya / pāvacana / brahmacariya / satthusāsana = 见解／认可／喜好／所取持的教义／法／律／法与律／教说／梵行／导师的教法 ✓
- puthujjanakalyāṇako = 善良的凡夫 ✓
- sekkho = 有学 ✓
- akuppadhammo = 法不动摇的 ✓
- nikkhamitvā bahi indakhīlā = 出了界柱之外 ✓
- indakhīlo = 界柱 ✓

## 跨段一致性

- **seṭṭhacariya / visiṭṭhacariya**：§1779 译「最殊胜**之**行」，§1782 译「最殊胜的行」。「之」是文言虚词，属**必改项**。建议两处统一为「最殊胜的行」。
- **pariyāya**：§1784 中 vinayapariyāyena、suttantapariyāyena、abhidhammapariyāyena 三处译「说法」，pariyāyadesanā 却译「方便说」。同一段里有意用同一个词对举，译法断开后，读者看不出两者的关联。另外「方便」在汉传语境里易被读作 upāya。nissaya 以 `နိပ္ပရိယာယဒေသနာ= မုချဖြစ်သောဒေသနာ`（直接、本义的说法）作对照，建议改为「间接的说法／直接的说法」。
- **arañña / āraññaka**：§1784 中 arañña 一律译「森林」，āraññaka senāsana 却译「林野的住处」。建议改为「森林住处」，与「森林」「林住比丘」保持一致。
- **veditabba**：§1777 译「应当了解」，§1779 译「应当理解为」，§1782-207 译「应当这样理解」，§1782-212 又译「应当了解」。建议统一为「应当理解」。
- **āgataṃ / vuttaṃ 的引出语**：§1779-154 译「经中说」，§1784-2 译「经中说」（出处却是律），§1784-22 未译。建议不加「经中」，统一为「（这样）说」或「有这样的记载」。

## §1777 句 120-1777-54-61
- **问题**：句法／取义。
  - nissaya：`ယတ္ထ= အကြင်ဝိရာဂါနုပဿနာ အစရှိသည်တို့၌`，yattha 指「在离贪随观等之中」，不是空间上的「地方」。
  - nissaya：`အဘိန္နောယေဝ= မပြားသည်သာလျှင်` 与 `ဝါ= ဝိပဿနာ လေးပါးသော အခိုက်အတန့်အားဖြင့် ပြားသကဲ့သို့ မပြားသည်`。abhinna 的意思是「道不像观那样分成四个阶段」，不是「不另列」。
- **建议**：改为「而在（离贪随观等）中也能得到道的情况下，那个道并不（像观那样）分成不同阶段。」

## §1779 句 120-1779-27-65
- **问题**：
  1. 文言：「最殊胜之行」，见跨段一致性一节，为必改项。
  2. 词义：nissaya 释 pavutta 为 `အပြားအားဖြင့် ဟောအပ်သည်`（以多种方式宣说），译文「被宣说」丢了 pa- 的含义。
  3. 漏译：tadubhayenapi 的 pi 没有译出。
- **建议**：
  - 「就最殊胜的行的意义而言」
  - 「就被广为宣说而言」
  - 「就这两者而言，也叫作**法与律**」

## §1779 句 120-1779-66-105
- **问题**：语序。imissā 与 diṭṭhiyā 等同为阴性处格，修饰的是「见解」，不是「佛陀」。译文「这个佛陀的见解」容易读成「这位佛陀」。另外「这个佛陀导师的教法」读起来生硬。
- **建议**：改为「在佛陀的这个见解里……在佛陀这位导师的这个教法里」，十项照此调整。

## §1779 句 120-1779-106-116
- **问题**：连接词误读。nissaya：`အပိစ= တနည်းလည်း`，意思是「另一种解释」，而不是递进的「再者」。下文 khanti、ruci 等正是在重新逐项解释一遍。
- **建议**：句首改为「或者，另一种解释是：」

## §1779 句 120-1779-154-156
- **问题**：补出成分不当。引文同时出自增支部与小品（律），「经中」限定得过窄。
- **建议**：改为「正因如此才说：」

## §1779 句 120-1779-157-205
- **问题**：引语边界。pe 省略的是 `ye ca kho tvaṃ … dhamme jāneyyāsi` 这一整组条件，「……乃至……」不该放在内层引号里。
- **建议**：改为「凡是你知道‘这些法导向离贪，不导向有贪’……乃至……的法，乔达弥，你就可以确定地受持：……」

## §1782 句 120-1782-2-19
- **问题**：句法。nissaya：`နယမာနာနံ= ဆောင်ယူကုန်သော` + `ဝိဇာနတံ= ပညာရှိတို့အား`，把 nayamānānaṃ 当作 vijānataṃ 的修饰语，两者指同一群人。译文却拆成「以法引导的人」与「明智的人」两方。
- **建议**：改为「对以法来引导的明智者，又有什么可嫉妒的？」若要保留现在的理解，应在报告中说明另有依据。

## §1782 句 120-1782-20-24
- **问题**：格。dhammāya 是为格，nissaya 释为 `နိဗ္ဗာန်အလို့ငှါ`（为了涅槃）。「为了法的调伏」容易读成属格「法的调伏」。
- **建议**：改为「或者，它是为了法而进行的调伏，所以是法与律。」

## §1782 句 120-1782-25-31
- **问题**：词义。nissaya：`ဘဝဘောဂါမိသတ္ထံ= သုဂတိဘဝကို ရခြင်း, စည်းစိမ်ချမ်းသာကို ရခြင်း, လောကာမိသကို ရခြင်း`，三项分别是善趣的生存、财富享乐、世间利养。「存有」是哲学术语，「享受」也不对应 bhoga（财富）。
- **建议**：改为「不是为了（善趣的）生存、财富享乐与世间利养。」

## §1782 句 120-1782-88-96
- **问题**：数／所指。nissaya：`ဓမ္မတော= သံသရာ တည်း ဟူသော တရား, သောကအစရှိသော တရားမှ`，dhammato 指轮回之法、忧愁等法，下一句正是这样展开的。「诸法」容易被读成「一切法」。
- **建议**：改为「从（轮回等）法中引离的律，就是法与律。」

## §1782 句 120-1782-114-121
- **问题**：用词。dhammabhūta 的意思是「成为法、就是法」，nissaya：`ဓမ္မဖြစ်၍ ဖြစ်တော်မူ၏`。「化身」容易引出三身说的联想。
- **建议**：改为「因为世尊就是法」，必要时夹注（dhammabhūta）。

## §1782 句 120-1782-122-144
- **问题**：
  1. 取义：nissaya 把这里的 vinayo 释为 `အထူးအားဖြင့် သိတတ်သည်`（特别地辨知），取 vi-naya 的「辨知」义，与「在有情、命我上不是辨知」对照。只译「关于诸法的律」显示不出这一层。
  2. 语体：一句里连用两个「所以」。
- **建议**：改为「……所以这是在诸法上的律（辨知），不是在有情上、也不是在命我上的律，因此是法与律。」可考虑加注说明 vinaya 在这里的辨知义。

## §1782 句 120-1782-159-169
- **问题**：
  1. 第二解：nissaya：`သတ္ထုဘူတံ= ဘုရားသဖွယ်ဖြစ်၍ ဖြစ်သော／ဆရာ သဖွယ်ဖြစ်၍ဖြစ်သော`，意思是「这个教法本身如同导师」。译文「作为导师的教法」容易读成「导师所说的教法」，与第一解没有区分，也接不上下文「法与律本身就是导师」。
  2. 「天人」：一般读者易理解为天神，nissaya `ဒေဝမနုဿာနံ` 指天与人。
- **建议**：改为「它是天神与人类的导师——世尊——的教法，所以是导师的教法；或者，这个教法本身就如同导师，所以也叫导师的教法。」

## §1782 句 120-1782-212-244
- **问题**：
  1. 格与修饰关系：nissaya：`ဥဿုံသော အခြင်းအရာဖြင့် … ဖြစ်စေတတ်သော`，sabbākāra 是「以一切方式」生起，而不是「一切形态的」定。
  2. 漏译：aññatra 在 nissaya 中补出为 `တစ်ပါးသော တိတ္ထိတို့၏ သာသနာ၌`（在其他外道的教法里），译文「别处」可以更明确。
  3. 漏译：Pali 有 imissā 与 imasmiṃ 两种形式，译文只写了一个「这个」。
- **建议**：改为「……才有能以一切方式生起入出息念定的比丘，在其他（外道的）教法里没有，所以应当理解，各处说“这个”（imissā、imasmiṃ），是作了这样的限定。」

## §1783 句 120-1783-13-28
- **问题**：译文同义反复。nissaya：`ပုထုဇ္ဇနကလျာဏောဝ= ဟူသော ပုဒ်သည်ပင်လျှင်`，意思是 puthujjanakalyāṇa 这个词本身就是 puthujjanakalyāṇaka，-ka 只是同义后缀。译文「善良的凡夫，也就是善良的凡夫」读者看不懂。
- **建议**：参照父层「**遍**（pari）」的体例，改为「善良的凡夫（puthujjanakalyāṇa）这个词，也就是**善良的凡夫**（puthujjanakalyāṇaka）。」被解释词保持不变。

## §1783 句 120-1783-46-51
- **问题**：补出成分。nissaya 补出了 `သောပိ= ထိုရဟန္တာပုဂ္ဂိုလ်သည်လည်း` 和 `ဣမံသမာဓိံ= ဤအာနာပါနဿတိ သမာဓိကို`。「他」紧接在「法不动摇的」之后，所指不清；pi 强调的是「连阿罗汉也修」。
- **建议**：改为「因为阿罗汉也修习这个（入出息念）定。」

## §1784 句 120-1784-2-21
- **问题**：补出成分错误，为**必改项**。引文出自波罗夷（律），句首又说「依律的说法」，译文却写「经中说」，自相矛盾。
- **建议**：改为「在森林的解释中，首先依律的说法，有这样的记载：“除了村落与村落的近处，其余都是森林。”（波罗夷92）」

## §1784 句 120-1784-22-42
- **问题**：
  1. 术语：「林野的住处」，见跨段一致性一节。
  2. 漏译：āgataṃ 没有译出，与上句不对称。
- **建议**：改为「依经的说法，针对林住比丘，有这样的记载：“所谓森林住处，至少要相距五百弓。”（波逸提573）」

## §1784 句 120-1784-43-69
- **问题**：术语。「方便说／非方便说」，见跨段一致性一节。
- **建议**：改为「律与经二者都叫作间接的说法，论则是直接的说法……」
