# Review — 165:361-366（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供）／义注 ⚠️部分（同题材他经义注 book=131 作术语参照，非本段坐标对应的严格父层，仅供定释义用）

## 必改项

### 1. `pariyuṭṭhitena` / `paretena` 语义对调（§361，五处重复）
- **问题**：义注（131-472）明确 `sakkāyadiṭṭhipariyuṭṭhitena` = *sakkāyadiṭṭhiyā gahitena abhibhūtena*（被有身见**执取、征服/压倒**），`sakkāyadiṭṭhiparetena` = *sakkāyadiṭṭhiyā anugatena*（被有身见**随附、缠附**）。
  译文却把"占据"给了 `pariyuṭṭhitena`、"征服"给了 `paretena`——**征服义实际对应前一词，随附义对应后一词**，两词的强弱层次被颠倒/混同了。
  此模式在 §361 的五组重复中一致出现（sakkāyadiṭṭhi / vicikicchā / sīlabbataparāmāsa / kāmarāga / byāpāda 各一处，共五处），因为 `Sesapadesupi eseva nayo`（131-472）说明该义注适用于全部五项。
- **建议**：改为体现"执取征服"→"随附缠系"两层递进，例如："他的心不被有身见**执取征服**，不被有身见**随附缠系**"（各处替换对应烦恼名）。若保留"占据/征服"二词，至少应把顺序对调：`pariyuṭṭhitena`→"征服/压倒"，`paretena`→"占据/纠缠"，避免两词语义与义注定义相反。

## 建议项（不算必改，供参考）

### 2. `nissaraṇaṃ` 译得偏泛（§361，五处）
- 义注（131-472）：`nissaraṇan`ti diṭṭhinissaraṇaṃ nāma nibbānaṃ——**此处"脱离"特指涅槃本身**，不是泛泛的"脱离之道"。
- 译文"如实了知脱离之道"把 nibbāna 这一具体所指虚化成了抽象方法论。可考虑改为"如实了知（从有身见）出离之法，即涅槃"一类更贴合义注的译法。此问题同样在五处重复中一致出现，改动一处即可批量应用。

### 3. `kāyaduṭṭhullānaṃ` 与 `akusalānaṃ dhammānaṃ` 的所指未点破（§364）
- 义注（131-474）：`akusalānaṃ dhammānaṃ pahānā` = 断五盖（nīvaraṇappahānaṃ）；`kāyaduṭṭhullānaṃ paṭippassaddhiyā` = 身懈怠止息（kāyālasiyapaṭippassaddhi）。
- 译文"断除不善法"、"身体粗重完全止息"是可接受的直译（`duṭṭhulla` 传统常译"粗重"），但义注揭示的具体所指（五盖 / 身懈怠）未体现，读者较难对应到 jhāna 支的具体内容。非必改，视是否需要术语精确度决定是否补足。

### 4. `so tattha ṭhito` 指代模糊（§364）
- 义注（131-475）明确"于此"指"以三相为所缘的观"（tāya tilakkhaṇārammaṇāya vipassanāya ṭhito）。译文"他安住于此"的"此"依上下文可推知，但若脱离上文单独阅读会指代不清，可考虑补为"他安住于此（观）"。

## 跨段一致性
- `pariyuṭṭhitena` / `paretena` 译法（占据/征服）在 §361 五组重复中保持一致——一致性本身没问题，但如上所述这一致的译法本身与义注定义相反，需整体订正。
- "阿难"称谓、"这也是能断除五种下分结的道路，这也是能断除五种下分结的修行方法"套语句、无常/苦/病/痈/箭/祸/患/他/坏/空/无我十一词序列，在 §362-366 各处译法完全一致，无问题。
