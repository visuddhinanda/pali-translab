## 被解释词核对（首要）
本层黑体词多为义注自设术语解释（kasiṇa体例说明、subho/jātimā等形容词训释），父层645-701提供的是经文段落。经核对：
- §780"kasiṇāni/āyatanāni"（遍/处）：属义注对经文术语的构词训释，非直接引自父层某句，译文"遍""处"符合传统译法，无冲突。
- §781"subho/jātimā/suparikammakato/accho/vippasanno/sabbākārasampanno"对应父层691"maṇi veḷuriyo subho jātimā aṭṭhaṃso suparikammakato accho vippasanno sabbākārasampanno"，父层译文分别为"美丽、天然生成"…"八面磨制光滑、清澈透明、具备一切优点"。本层逐一训释：
  - "Subho: sundaro"译"美丽：即美好" — 与父层"美丽"一致 ✓
  - "Jātimā: suparisuddhaākarasamuṭṭhito"译"天然生成：即从极清净的矿源产生的" — 与父层"天然生成"一致 ✓
  - "Suparikammakato"译"磨制光滑：即经过精细加工、除去了石屑砂粒的" — 父层此词译在"八面磨制光滑"中，被解释词本身译"磨制光滑"，一致 ✓
  - "Accho"译"清澈" — 父层"清澈透明"中"清澈"对应，一致 ✓
  - "Vippasanno"译"透明：即极为透明" — 父层"清澈透明"中"透明"对应，一致 ✓
  - "Sabbākārasampanno"译"具备一切优点" — 与父层完全一致 ✓
- §784"Manomayan/Sabbaṅgapaccaṅgin/Ahīnindriyan"对应父层692"rūpiṃ manomayaṃ sabbaṅgapaccaṅgiṃ ahīnindriyaṃ"，父层译"有形色、由意所构成，四肢俱全、诸根无缺"：
  - "Manomayan"译"意所成：即由意所产生的" — 父层"由意所构成"，本层"意所成"与"由意所构成"不完全逐字一致，但两者语义相同，"意所成"是术语化简称，可接受，非硬性错误（**建议**：若追求逐字对应，可考虑训释句用"由意所构成"以贴合父层，但不影响理解）。
  - "Sabbaṅgapaccaṅgin"译"四肢俱全" — 与父层一致 ✓
  - "Ahīnindriyan"译"诸根无缺" — 与父层一致 ✓
- §785"Karaṇḍā"对应父层692"karaṇḍā"（"蛇篓"中"篓"字），父层译"蛇篓"，本层单独训释"篓"，与父层"篓"字一致 ✓
- §782-783"vipassanāñāṇaṃ""abhiññāvosānapāramippattā"等与父层690-691"证得神通、达到究竟"用词呼应，未见冲突。

**结论**：被解释词核对基本一致，仅"意所成"与父层"由意所构成"字面略有差异，建议关注但不构成必改项（因是名词化简称而非误译）。

## §780 句 131-780-2-16
- **问题**：文言残留 — "由于是……之义，所以叫**遍**"结构偏书面化但尚可接受；但"由此为所缘的诸法的境地之义，或是所决意之处的意义"中"之义"重复使用略显生硬。
- **建议**：可改为"由于是以此为所缘的诸法的境地，或是所决意之处，所以叫**处**"，去掉多余"之义"以更简洁现代。（非必改，风格建议）
