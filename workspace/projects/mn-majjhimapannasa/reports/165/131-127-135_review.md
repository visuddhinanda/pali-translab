## 被解释词与父层核对

逐一核对结果：以下黑体词与父层译文**逐字相同**，通过：

- `Bhagavantaṃ etadavocā` → “对世尊这样说”（父 165-69-194-213 同）
- `nacchannaṃ` → “不恰当”；`nappatirūpaṃ` → “不合适”（父 165-69-214-235 同）
- `ākārā` → “外表”，`liṅgā` → “特征”，`nimittā` → “标志”（父 165-69-236-258 同）
- `anovādī anupavādī` → “不加教诫、不加责备”（父 165-69-300-329 同）
- `ghāsacchādanaparamo viharāmi` → “只以维持基本的饮食衣着为满足地生活着”（父同）

- `vighātapariḷāhā` → “忧恼、热恼”（父同）

无必改项。

## 跨段一致性

- `vohāro`（世俗往来 / 用语）系列译名基本一致（`vohārasamucchedāya`→“断绝世俗往来”全篇统一），但四种子分类的译法**结构不对齐**：
  - `paṇṇattivohāro` → “施设意义上的世俗往来”
  - `vacanavohāro` → “言语意义上的世俗往来”
  - `cetanāvohāro` → “思意义上的世俗往来”
  - `byavahāravohāro` → **“日常交往用语”**（§132，131-132-2-5）——唯独这一处跳出了“X意义上的世俗往来”的平行句式
  - 建议统一为“交易/日常交往意义上的世俗往来”，与另外三条保持句式一致，读者才能看出这是同一分类框架下的并列四项。
- “杀生 / 偷盗 / 妄语 / 两舌语 / 贪欲 / 谴责恼怒 / 忿恼 / 过慢”八法对应的“戒律仪”译法（§134：身戒律仪／语戒律仪／意戒律仪）与各条目在前文（§129, §133）单独出现时的译法一致，无跨段漂移。
- “就这样自己责备自己”“……也会加以谴责”这一固定句式在 §127、§133、§135 多次复现，译法统一，未见随文顺滑而改写，符合 harmonize 前的一致性要求。

## §128 句 131-128-58-64
- **问题**：漏译连接词 `pana`（“而／但”），原文 “Ahaṃ **pana** ubhayampi taṃ na karomi” 中的转折语气未译出。
- **建议**：可改为“但我这两种都不做”，与上一句“教诫者／责备者”的对比语气衔接得更清楚。

## §132 句 131-132-2-5
- **问题**（跨段一致性，见上）：`byavahāravohāro` 译作“日常交往用语”，与同段落其余三类“X意义上的世俗往来”句式不一致。
- **建议**：改为“这就叫作交易（日常交往）意义上的世俗往来”，保持四项并列结构统一。

其余句子未见误译、漏译准确性问题；标点、术语、语体均为现代书面汉语，未见文言腔或工作标记。
