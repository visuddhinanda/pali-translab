# Review — 131:792-799（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注（本层）✅／父层译文（book 165，702-732）✅

## 跨段一致性 / 被解释词核对（首要）

- **经题不一致（必改，高优先级）**：父层 165-702 已将经名 `Samaṇamuṇḍikasuttaṃ` 定译为**“痴弟子经”**（165-732 篇末亦同：“第八，《沙门文祇经》终”……不，父层实际写的是"《痴弟子经》"）。本层两处经题译法均为“《沙门文祇经》”：
  - §792 word_start=2-4：`"zh":"八、《沙门文祇经》释义"`
  - §793 word_start=2-13：`"zh":"…这是《沙门文祇经》。"`

  必须统一改为**“《痴弟子经》释义”**与**“这是《痴弟子经》”**。“文祇”疑似把 `muṇḍika` 当专有名词音译，与父层取意译“痴（弟子）”的定案冲突——这是被解释词/书名对齐断裂，读者会看不出这条注在注哪部经。

- **人名 samaṇamuṇḍikāputto 未在本层出现完整对应译法**：本层各处只以“郁伽诃摩那”单称出现（如 §793-14-20、§796-2-27），未见把 `samaṇamuṇḍikāputto` 部分译出。若后续段落需要引用此复合名，应统一为父层的“郁伽诃摩那·痴弟子”，不要再用“文祇”系译法。

- 其余高频被解释词经与父层逐一核对，**均一致**，未见问题：
  - `samayappavādakaṃ` → “议论场所”（§793-35-40，一致于父层 703）
  - `tindukācīraṃ` → “多杜迦树篱”（§793-63-68，一致）
  - `ekasālako` → “只有一座房舍”（§793-69-93，一致）
  - `mallikāya ārāmo` → “末利园”（§793-94-108，一致）
  - `paṭivasati` → “住”（§793-116-120，一致）
  - `paṭisallīno` → “静修”（§793-137-149，一致于父层 703“世尊正在静修”）
  - `manobhāvanīyānaṃ` → “修心有成的”（§793-150-163，一致）
  - `yāvatā` / `ayaṃ tesaṃ aññataro` → “凡是”/“他们当中的一位”（§793-164-177，一致）
  - `sampannakusalaṃ` / `paramakusalaṃ` / `ayojjhaṃ` → “善行圆满”/“至善圆满”/“不可战胜”（§794，一致）
  - `neva abhinandi na paṭikkosi` → “既不赞同，也不反驳”（§795，一致）
  - `aññatra phanditamattā` / `roditamattā` / `vikūjitamattā` / `aññatra mātuthaññā` → “除了手脚的抽动之外”/“除了啼哭之外”/“乱哼乱叫”/“除了吃母乳之外”（§796，与父层 708 逐字一致）

## §799 术语备注（非必改，仅记录）

- `saṅkappo` 释为“思惟”（§799-84-91），与父层 165-712~713 后段的“思惟”译法一致；但父层 165-708 早段曾把同一词族译作“恶念/正念”，两处并非本层责任（父层已定稿），此处不作修改，仅记录以备术语表参考。

## §793 word_start=121-136（divā divassa）

- **问题**：轻微冗余——“白天，一天当中的”作为夹注式起头略显生硬，可考虑改为更顺畅的现代汉语衔接，但不影响准确性，非必改项。
