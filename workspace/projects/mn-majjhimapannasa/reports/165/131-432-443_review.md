- §441 id `131-441-2-12`：黑体「**Addasā kho āyasmā sāriputto**」对应父层 165-326-184-202「尊者舍利弗看见尊者罗睺罗…」，其中 addasa（看见）父层译作「看见」（无「了」）。本句译作「尊者舍利弗看见**了**」，多了「了」字，与父层动词不完全逐字一致。
  - **问题**：被解释词与父层译法不完全逐字相同。
  - **建议**：改为「尊者舍利弗看见，是说他在世尊出发之后随后跟去时看见的」，去掉「了」，与父层「看见」逐字对齐。
- §442 id `131-442-37-50`：黑体「**ānāpānassatin**」。本段紧接 mūla §338（"Ānāpānassatiṃ, rāhula, bhāvanaṃ bhāvehi"）与 §443（"mahapphalā hoti"）的义注，对应的父层段落是 165-338，其译文为「**出入息念**」，而本 chunk 全程（432、442-2-7、442-37-50）都译作「**入出息念**」。
  - **问题**：被解释词与所对应父层段落（165-338）译法不一致（父层用「出入息念」，本层用「入出息念」）。
  - 附注：父层本身在 §326（"入出息念"）与 §338（"出入息念"）两处译法不统一，这是父层遗留问题，不属本层职责，但本层应对齐**其实际所释之处**（§338）。
  - **建议**：把本 chunk 中所有「入出息念」统一改为「出入息念」，与 165-338 对齐；若认为应对齐 §326 的「入出息念」，需在报告中说明取舍依据，不能自行含糊两可。

## 跨段一致性

- 「且」字用法：§440 id `131-440-128-141`「你**且**不要返回」与 §440 id `131-440-144-157`「今天**且**让他先享用…」两处均用「且」表「暂且/姑且」，偏文言单字虚词，建议统一改为「先」或「暂且」，如「你先不要返回」「今天先让他享用」。
- 「入出息念」/「出入息念」不统一，见上文父层核对第 5 条。
