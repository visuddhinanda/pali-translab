# Review — 165:460-470（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供，本次审查按缺失处理，未做词级格核对）／义注 ✅（book 131:573-580，Goliyānisuttavaṇṇanā）

## 跨段一致性

- **“Kiṃ panimassāyasmato āraññikassa ekassāraññe serivihārena, yo ayamāyasmā … ”ti 句式漏译不一致**：§462、§463、§464 完整译出了“这位住阿兰若的尊者，在林中独自随意而住，又能得到什么好处呢？”这一反诘分句，但 §465、§468、§469、§470 的原文用的是**同一句式**（word 49-68 / 33-50 / 40-56 / 25-42），译文却直接跳过该分句，只译出后半（如“这位尊者过早入村、过晚返回。”）。这是系统性漏译，不是风格选择——四段都要补回反诘句。建议统一为：“这位住阿兰若的尊者，在林中独自随意而住，又能得到什么好处呢？这位尊者……”。
  - §466、§467 原文句式不同（`Ayaṃ/Idaṃ nūnimassāyasmato…viharato…bahulīkataṃ`），译文按该句式对应翻译，无问题，不在此列。
- **半角标点贯穿全篇**：所有段落的逗号均用了 ASCII 半角逗号 `,`（如“一时,世尊住在…”“住在僧团中时,应当…”），未按 `style.md` 用全角 `，`。这是硬约束（标点系统 + JSON 安全一节），需要整批替换为全角标点。

## §461 句 165-461-22-72

- **问题**：义注释义误取，词义译反 — 义注明确解释 `padasamācāro`＝`dubbalasamācāro oḷārikācāro`（**懦弱、粗率的行止**），并举实例说明此比丘因某事私许袈裟给多人、行事轻率，才被舍利弗提及。译文将其译为“行止端庄”，是**相反的意思**（褒义变贬义），会让读者完全误解此比丘被点名的原因。
- **建议**：改译为体现“行止粗率／懦弱随便”的负面含义，如“行止粗率”或“举止轻率”，并保持与后文舍利弗批评其失当行为的语境一致。

## §465 句 165-465-49-68

- **问题**：漏译。原文 `Kiṃ panimassāyasmato āraññikassa ekassāraññe serivihārena yo ayamāyasmā atikālena gāmaṃ pavisati atidivā paṭikkamatī’ti` 中前半反诘分句未译出，见上方跨段一致性。
- **建议**：补全为“这位住阿兰若的尊者，在林中独自随意而住，又能得到什么好处呢？这位尊者过早入村、过晚返回。”

## §468 句 165-468-33-50

- **问题**：同上，漏译反诘分句。
- **建议**：补全为“这位住阿兰若的尊者，在林中独自随意而住，又能得到什么好处呢？这位尊者多话、言语散乱。”

## §469 句 165-469-40-56

- **问题**：同上，漏译反诘分句。
- **建议**：补全为“这位住阿兰若的尊者，在林中独自随意而住，又能得到什么好处呢？这位尊者难以劝谏、有恶友。”

## §470 句 165-470-25-42

- **问题**：同上，漏译反诘分句。
- **建议**：补全为“这位住阿兰若的尊者，在林中独自随意而住，又能得到什么好处呢？这位尊者不守护根门。”
