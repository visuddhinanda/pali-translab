# Review — 134:188-188（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词对照（父层 168:147-150）

- **satthā sammukhībhūto** →「导师就在眼前」，与父层一致 ✅
- **tasmātiha, bhikkhave** →「所以，比丘们」，一致 ✅
- **saphalā** →「有果报」，一致 ✅
- **saudrayā** →「有增长」，一致 ✅
- **attatthaṃ vā hi, bhikkhave** →「比丘们，凡看到自己利益的人」，是父层原文的逐字片段 ✅
- **attatthaṃ** →「自己利益」，一致 ✅
- **appamādena sampādetuṃ** →「以不放逸来成办」，一致 ✅
- **paratthaṃ** →「他人利益」，一致 ✅
- 非黑体但引自父层的 maṇḍapeyya →「澄净可饮的醍醐」（§188 句 79-105），与父层一致 ✅
- desanāmaṇḍo / paṭiggahamaṇḍo / brahmacariyamaṇḍo 三处黑体出自《无碍解道》引文，父层没有，不受逐字约束。

## 跨段一致性

- **-maṇḍa 复合词的结构**：句 2-11、12-14、15-41、42-44、45-59、60-62、63-78、79-105 都译成「X 的醍醐」（说法的／领受者的／梵行的／胜解的）。nissaya 一律用 `ဟူသော` 表示同位（「名为 X 的澄净」），不是属格。见下文句 2-11 → 建议这几处统一改为「X 这一醍醐」。
- **niyojana**：句 151-166 的 niyojento 译「引向」，句 176-186 的 niyojana 译「劝导」。nissaya 两处都是 `တိုက်တွန်း`（劝勉、催促） → 建议统一为「劝勉」或「劝导」。

## §188 句 134-188-2-11
- **问题**：格与句法 — `ဒေသနာမဏ္ဍော= ဒေသနာဟူသော ကြည်လင်ခြင်း`、`ပဋိဂ္ဂဟမဏ္ဍော= တရားနာပရိသတ်ဟူသော ကြည်လင်ခြင်း`、`ဗြဟ္မစရိယမဏ္ဍော= မြတ်သောအကျင့်ဟူသော ကြည်လင်ခြင်း`。`ဟူသော` 表示同位，即「说法就是醍醐」。译文「说法的醍醐」读起来像领属关系。这个问题在句 45-59 最明显：译文说比丘等人「就是领受者的醍醐」，按字面成了「属于领受者的醍醐」，可原文的意思是会众本身就是醍醐。
- **建议**：改为「说法这一醍醐、领受者这一醍醐、梵行这一醍醐」，后面的问句与结论句同步改（句 12-14、15-41、42-44、45-59、60-62、63-78）。

## §188 句 134-188-45-59
- **问题**：补出成分 — `ဝိညာတာရော= သစ္စာတို့ကိုသိကုန်သော`，nissaya 补出了 viññātāro 的宾语「诸谛」。译文只说「能够领会的」，没有交代领会什么。
- **建议**：可补为「其他任何能了知诸谛的人」（可选）。另外「领受者的醍醐」按句 2-11 一并改。

## §188 句 134-188-79-105
- **问题**：格与句法 — `အဓိမောက္ခမဏ္ဍော= အဓိမောက္ခဟူသော မဏ္ဍ` 也是同位结构。「胜解的醍醐就是信根」同样误作领属关系。后面的 `သဒ္ဓိန္ဒြိယဿ … အဓိမောက္ခမဏ္ဍံ`（信根的胜解醍醐）是真正的属格，可以保留。
- **建议**：前半改为「胜解这一醍醐就是信根」。

## §188 句 134-188-123-138
- **问题**：词义 — `ဗာဟိရကံ= သာသနာတော်မှ အပဖြစ်သော`，nissaya 解作「教法以外的」，与后文「醍醐」指教法形成对比。译作「世间的」弱化了这层对照。
- **建议**：改为「教法以外的药的醍醐」或「外在的药的醍醐」。

## §188 句 134-188-151-166
- **问题**：词义与句法 — `နိယောဇေန္တော= တိုက်တွန်းတော်မူလိုသောကြောင့်`，意思是「劝勉」，译「引向」失义。`နေသံ= ထိုတပည့်သားတော်တို့အား` 指那些弟子。`အာဟ` 的主语是世尊（`ဘဂဝါ`），由 nissaya 补出。另外 `ပိဝထ` 是第二人称复数命令式，译文没有体现「你们」。
- **建议**：「……所以你们要努力精进地喝——世尊为了这样劝勉他们饮用醍醐，才说了**所以，比丘们**等等这段话。」其中「劝勉」与句 176-186 统一。

## §188 句 134-188-210-211
- **问题**：句法 — nissaya 读作 `ဒသဗလသုတ္တဝဏ္ဏနာ= ဒသဗလသုတ်၏ အဖွင့်သည်။ နိဋ္ဌိတာ= ပြီး…`，即「十力经的注释完」。这里是义注层的结尾，照搬父层的「第二经完」容易让读者误以为是经文结束。
- **建议**：改为「第二经的注释完」。如果项目各书的义注结尾已有统一体例，以体例为准。
