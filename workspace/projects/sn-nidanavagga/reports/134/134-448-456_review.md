# Review — 134:448-456（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§448、§451、§455 标题行无 nissaya，略过）

**被解释词对照父层（book=168）**：逐条核对，所有黑体被解释词都与父层译文同一处逐字相同，没有必改项。§456 句 134-456-19-27 的「**使……高涨**」用省略号代替宾语，与父层「使大河高涨」的骨架一致，可以接受。

## 跨段一致性

- **经末结语 Sattamaṃ / Aṭṭhamaṃ / Navamaṃ**：§450 译「第七经注释完。」，§454 译「第八经。」，§456 译「第九经。」 → 建议统一为「第X经注释完。」。依据：三处 nissaya 都有 `နိဋ္ဌိတံ= ပြီးခြင်းသို့ရောက်ပြီ`（已完结），本层是注释书，应带「注释完」。
- **经首引语 Sattame / Aṭṭhame / Navame**：§449 译「第七经中的」，§452 和 §456 译「在第X经中，」 → 建议统一为「在第X经中，」。依据：nissaya `သတ္တမေ= သတ္တမသုတ်၌` 是处格（在第七经中），与后两处一致。
- **被解释词的引号体例**：§449–§450 的黑体词外加全角引号（“**我们刚才**……”“**两捆芦苇**”“**三十六个理由**”），§452–§456 的黑体词不加引号（**不依靠**、**沉默不语**、**井**……） → 全 chunk 统一为同一种体例。建议去掉引号，只用黑体，因为后者占多数。
- **bhavanirodho nibbānaṃ 在注文中的引述**：§452 作「有（bhava）的灭就是涅槃」，§453 作「“有”的灭就是涅槃」，§454 作「‘有’的灭就是涅槃」 → 建议统一。这里引的是父层原句，父层各处一律作「有（bhava）的灭就是涅槃」，建议照此统一。
- **dhammakathika**：§450 句 134-450-25-35 译「说法者」，父层通篇作「说法比丘」 → 建议改为「说法比丘」。依据：nissaya `ဓမ္မကထိကဂုဏော= ဓမ္မကထိကရဟန်း၏ဂုဏ်` 明确是「说法比丘的品质」。

## §449 句 134-449-2-15
- **问题**：补出成分 — nissaya `ပုစ္ဆတိ= မိမိသံသယမရှိလျက် မေးသနည်း`（他自己没有疑惑，却还要问）补出了「自己无疑」这一隐含前提。这是本句发问的要点，后两句的两个答案（了解对方心意、让后人知道）都承接这一点。
- **建议**：改为「……：他自己并没有疑惑，为什么还要这样问？」

## §449 句 134-449-43-63
- **问题**：隐含成分 — nissaya `ဝုတ္တတ္တာ= အရှင်သာရိပုတ္တရာသည် မိန့်ဆိုဘူးသည်၏အဖြစ်ကြောင့်` 指明 vuttaṃ / vuttattā 的说话人是舍利弗。译文「前面说……接着又说……」没有主语，读者容易误以为是摩诃拘絺罗自己说的。
- **建议**：改为「是因为舍利弗长老前面说识是名色的缘，接着又说那同一个名色是识的缘」。

## §454 句 134-454-23-41
- **问题**：存疑（nissaya 分歧） — nissaya 把 `ဝိမုတ္တံ` 释为 `နိဗ္ဗာန်ကို`（涅槃，宾格），也就是「以十九种省察智……省察涅槃的省察智」。译文取「vimutta + 具格 = 脱离于、不在其中」，译作「在十九种省察智之外的另一种省察智」。从语法看，译文的读法成立，而且与上句「处在不还道」的语境（有学者的省察，不属于十九种之列）相合。nissaya 的读法在句法上比较勉强。
- **建议**：保留现译，把分歧记入报告，交定稿时裁定。

## §454 句 134-454-99-112
- **问题**：词义 — `arahattaphalasamayo nāma`，nissaya 释为 `အရဟတ္တဖိုလ်ကို ရခြင်း,သိခြင်းမည်သည်`（所谓证得、了知阿罗汉果这回事）。译文「阿罗汉果的阶段」把 samaya 译成「阶段」，偏向时间分期，没有译出「证得」义。
- **建议**：改为「在这之上，还有证得阿罗汉果这一步」，或「……还有阿罗汉果可证」。

## §456 句 134-456-52-56 / 134-456-71-76
- **问题**：词义 — `apagacchanto`，nissaya 释为 `ဆုတ်နစ်`（退下、退落）；`apagacchāpeti` 释为 `ဆုတ်နစ်စေ`（使退落）。说的是水位回落。「离去」「使行离去」偏向「走开」，与水退的意象不贴，也和本经「高涨／消退」的对照不协调。§456 句 134-456-57-70 的「离去、退落」同样如此。
- **建议**：apagacchati 统一改为「退去」：「退去、退落」「使行退去」。
