# Review — 134:25-37（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **被解释词 taṃ suṇātha**：父层 168-7-59-65 译“你们要听”，§26 句 2-7（黑体）和句 100-121（引文）都译成“你们要听我要说的那个缘起”，与父层不一致（**必改**，详见下面各句）。
- **五种提问的名称**：§30、§31–35 用“为阐明未见之事而问 / 为印证已见之事而问 / 为断除疑惑而问”，§36 句 28-32、56-59、68-71 改成“阐明未见之事的提问 / 印证已见之事的提问 / 断除疑惑的提问”。建议全部统一成 §30 的“为……而问”格式。
- **五种提问的夹注**：§34 的 anumatipucchā、§35 的 kathetukamyatāpucchā 加了巴利夹注，§31–33 没有加，而且这些术语首次出现在 §30 句 35-47，那里也没有夹注。建议首次出现时（§30 句 35-47）五个一起夹注，§34、§35 的夹注删掉。
- **“疑惑”一词对应两个巴利词**：§33 用“疑惑”对 vimati，“怀疑”对 saṃsaya（nissaya 的区分是 saṃsaya= အားနည်းသော ယုံမှား，即较弱的怀疑；vimati= အားရှိသော ယုံမှား，即较强的怀疑）。但 §36 句 60-67 又用“疑惑”对 tiṇṇa**vicikiccho**。这样 vimati 和 vicikicchā 就混在一起了。建议 vicikicchā 改用传统译名“疑”（“已经越过了疑”），“疑惑”只留给 vimati。
- **“讲说”一词对应多个巴利词**：§26 句 122-126 明确说 desessāmi（宣说）和 bhāsissāmi（讲说）分别表示简略和详细，“讲说”在这里已经是专门对应 bhāsati 的词。但 §30 句 2-24、§37 句 15-60、句 61-92 又用“讲说”译 avoca / katheti / kathesi。建议 katheti / kathesi 改用“讲”或“说”，“讲说”只用来对 bhāsati。
- **文言“之”**：“未见之事 / 已见之事”出现在 §30、§31、§32、§36 多处。建议统一改成“没有见过的事 / 已经见过的事”，并和上面五种提问的名称一起统一。

## §25 句 134-25-52-89
- **问题**：句法（次要）— nissaya 是 `သုဂဟိတံ= ကောင်းစွာသင်နာယူခြင်းကို။ ဂဏှန္တာ= ယူကုန်လျက်။`。gaṇhantā 是现在分词，表示伴随状态（“一边好好地掌握一边……”），从属于主句 suṇātha。译文把它译成了与“听”并列的第二个祈使句。
- **建议**：改为“你们要一边好好地掌握，一边牢牢地听这法”。

## §26 句 134-26-2-7
- **问题**：被解释词与父层不一致（**必改**）— 黑体 **taṃ suṇātha** 在父层 168-7-59-65 译“你们要听”，本句译“你们要听我要说的那个缘起”，多出了“我要说的那个缘起”。nissaya 里 `တံသုဏာထာတိ ဧတံ= တံ သုဏာထဟူသော ဤပုဒ်သည်` 只是把这两个词当作被解释的词组引出来，没有补出所指。
- **建议**：改为“现在，这里说‘**你们要听**’，是为了防止耳根散乱。”

## §26 句 134-26-8-15
- **问题**：被解释词形式（**必改**）— 黑体分成两段，“**好好地** **作意**”中间有空格。父层是“要好好地作意”，连续书写。
- **建议**：改为“说‘**要好好地作意**’……”（或“**好好地作意**”），去掉空格，与父层逐字相同。

## §26 句 134-26-22-31、句 134-26-32-59
- **问题**：句法（次要）— 两句里的 purimena / pacchimena 都是具格。nissaya 是 `ပုရိမေန= ရှေးဖြစ်သော သုဏာထဟူသောပုဒ်ဖြင့်`（“用前面的‘你们要听’这个词”），谓语 niyojeti / dīpeti 的隐含主语是世尊（`ပြတော်မူ၏` 用的是敬语）。译文“前一句是督促……”“前一句显示……”把具格的“这句话”当成了主语。
- **建议**：改为“世尊用前一句督促他们听法，用后一句督促他们……”；“用前一句表明‘……’，用后一句表明‘……’”。

## §26 句 134-26-60-78
- **问题**：词义（次要）— nissaya 是 `ဓမ္မဂမ္ဘီရော စ= ပါဠိအားဖြင့်လည်း နက်နဲ၏`，意思是“在法（文本）方面深”，与“在教说方面深”并列。译文“这法本身深奥”看不出这里的 dhamma 指文本层面，和后文的“意义深奥”也对不齐。
- **建议**：改为“因为这法在法（文本）上深奥，在教说上也深奥”，下一句（79-95）对应改为“在意义上深奥，在通达上也深奥”。

## §26 句 134-26-79-95
- **问题**：语气（次要）— `ယောဇနာ= အနက်ယောဇနာခြင်းကို။ ဝေဒိတဗ္ဗာ= သိအပ်၏` 是义务语气（veditabbā），译文“可以这样连接”把语气弱化成了许可。
- **建议**：改为“应当知道，连接就是这样的。”

## §26 句 134-26-100-121
- **问题**：引文与父层不一致（**必改**）— 引文“你们要听我要说的那个缘起”与父层“你们要听”不同（与句 2-7 是同一个问题）。
- **建议**：改为“对于在‘你们要听’这里所应许的教说……”。

## §28 句 134-28-2-24
- **问题**：句法（次要）— nissaya 是 `နိဂ္ဃေါသော ဣဝ= …တွန်မြည်သံကဲ့သို့။ ပဋိဘာနံ= နှစ်သက်ဖွယ်သော ချိုသာယာသောစကားကို။ ဥဒီရယိ= ဆိုတော်မူ၏`。结构是“像鹩哥的鸣声一样，[他]说出 paṭibhāna”，nigghoso 是比喻的喻体，不是主语的声音。nissaya 对 paṭibhāna 的解释是“令人喜爱、甜美的话语”，译文“应机的辩才”和“发出”搭配也不顺。
- **建议**：改为“他像鹩哥鸣叫一样，说出动听的言辞。”

## §36 句 134-36-33-55
- **问题**：风格（次要）— “以自己的智慧”里的“以”是文言介词。
- **建议**：改为“世尊用自己的智慧所通达的内容”。

## §36 句 134-36-60-67
- **问题**：术语混用（见“跨段一致性”）— tiṇṇavicikiccho 译“度过了疑惑”，与 §33 用“疑惑”对 vimati 的译法冲突。
- **建议**：改为“已经越过了疑”。

## §37 句 134-37-15-60
- **问题**：用词（次要）— “我要讲说那位父亲”读起来不自然。nissaya `ပိတရံ= အဘကို။ ကထေဿာမီတိ= ဆိုအံ့ဟူ၍` 的意思只是“我要说说父亲”。另外“讲说”与 §26 的专门用法冲突（见“跨段一致性”）。
- **建议**：改为“就像有人开头说‘我要讲讲父亲’，却先说出‘提沙的父亲、苏那的父亲’，这样连儿子也先提到了；同样，世尊开始讲缘的时候……也把缘生法一起讲了。”

## §37 句 134-37-61-92
- **问题**：格式（次要）— 品名加了书名号，写作《食品》。父层品名“佛陀品”不加书名号。
- **建议**：改为“食品”，去掉书名号，与父层体例一致。

## §37 句 134-37-114-129
- **问题**：隐含成分（次要）— nissaya 是 `ကထိတာ= ငါဆိုအပ်ပြီ`，补出了施事“我”，也就是义注作者自己。译文没有体现出来，读者看不出是作者在指自己的另一部著作。
- **建议**：改为“……顺观缘起论述，我已经在《清净道论》里讲过了，所以……”。

## §30–36（五种提问各处）
- **问题**：风格（**必改**）— “未见之事 / 已见之事”里的“之”是文言虚词。涉及 §30 句 35-47，§31 句 2-16、句 38-40，§32 句 2-4、句 23-25，§36 句 28-32、句 56-59。
- **建议**：统一改为“为阐明没有见过的事而问”“为印证已经见过的事而问”。§36 的三处同时改回“为……而问”的格式。
