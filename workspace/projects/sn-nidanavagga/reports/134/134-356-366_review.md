# Review — 134:356-366（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照

逐条核对了 §357–§366 的全部黑体词：assutavā、puthujjano、imasmiṃ、cātumahābhūtikasmiṃ、nibbindeyya / virajjeyya / vimucceyya、ācaya / apacaya / ādāna / nikkhepana、tasmā×2、citta / mano / viññāṇa、nālaṃ、ajjhosita / mamāyita / parāmaṭṭha、etaṃ mama / esohamasmi / eso me attā、varaṃ bhikkhave、attato upagaccheyya、bhiyyopi、rattiyā ca divasassa ca、aññadeva uppajjati aññaṃ nirujjhati、pavane、taṃ muñcitvā…。它们都能在父层译文中逐字找到，**没有不一致**。

## 跨段一致性

- **pariggaṇhāti / pariggahetabba 与 gāha / gaṇhāti 混用一个“执取”**：
  - §361 句 14-27 和 §363 句 10-39 把 pariggahetuṃ 译成“执取”，§361 句 30-47 却把 pariggahetabba- 译成“看清楚”。同一词根在相邻两句里取了两种意思。
  - 同时 gāho（§361、§363）、gaṇheyya（§363 句 40-47）、gahitaṃ（§362 多句）也都译作“执取”。读者分不清 pariggaha 和 gāha 是两个词。
  - 建议：pariggah- 全 chunk 统一用一个区别于“执取”的词，如“把握”或“摄取”。gāha 保留“执取”。§362 的 gahitaṃ 按下文单独处理。
- **mahāvana**：§366 句 2-5 把 mahāvana 释为“广大的森林”，§366 句 24-36 的 tasmiṃ mahāvane 却译“那片大林”（“大林”是 pavana 的译法）。建议 mahāvana 统一为“广大的森林”或“大森林”。
- **paveṇi 夹注位置**：首次出现在 §363 句 151-183（“前后相续”“相续的关系”），未夹注。夹注却放在 §364 句 50-77。建议把夹注移到首次出现处，后文只用“相续”。

## §357 句 134-357-13-20
- **问题**：句法 — nissaya 为 `ကိလေသာဒီနံ= ကိလေသာအစရှိသည်တို့ကို`（宾格）、`ဇနနာဒိကာရဏေဟိ= ဖြစ်စေခြင်းအစရှိသော အကြောင်းတို့ဖြင့်`（具格）。也就是说 ādi 同时出现在“烦恼等”和“生起等原因”两处。译文只保留了前一个“等等”，“生起等原因”的 ādi 丢了。“这些缘故”的说法也不通顺。
- **建议**：“**凡夫**，是因为生起众多、各种各样的烦恼等等，以及诸如此类的原因，所以叫做凡夫。”

## §357 句 134-357-23-34
- **问题**：误读 — nissaya `ဝတ္ထာရေတဗ္ဗံ= ပဋိသမ္ဘိဒါမဂ် မဟာနိဒ္ဒေသ၌လာသောနည်းဖြင့် ချဲ့အပ်၏`，意思是“按（原出处）所载的方式展开”。译文“照这样详细展开”会被读成按本句的说法展开。
- **建议**：“……全部内容都应当按原出处的说法详细展开。”

## §357 句 134-357-35-56
- **问题**：词义 — `ဝိသံသဋ္ဌော= မနှီးနှော` 是“不相混杂”，不是“不相往来”。“不相往来”是社交关系，偏离了原意。句末“是这样的人”也生硬，jano 作谓词，应与 visaṃsaṭṭho 连读。
- **建议**：“……被单独算作另外一类，是与具备戒、多闻等功德的圣者不相混同的人，所以叫做凡夫。”

## §357 句 134-357-57-70 ＋ §360 句 134-360-2-9（须联动修改）
- **问题**：句法误读（必改）：
  - 原文是一个跨段长句：Evametehi … dvīhipi padehi **ye te** [偈] dve puthujjanā vuttā, **tesu** andhaputhujjano gahito。
  - nissaya 标出 `ယေ တေ ပုထုဇ္ဇနာ= အကြင်ပုထုဇဉ်ပုဂ္ဂိုလ်တို့ကို`（关系从句）和 `တေသု= ထိုနှစ်ပါးသော ပုထုဇဉ်ပုဂ္ဂိုလ်တို့တွင်`（“在那两种当中”）。
  - 正确的意思是：用这两个词，在偈中所说的两种凡夫当中，取的是愚盲凡夫。
  - 现译 §357 说这两个词“指的就是……那两种凡夫”，与原意相反。§360 又另起一句“偈中说凡夫有两种”，关系结构断了。
- **建议**：
  - §357 句 57-70 改为：“这样，用‘没有听闻过佛法的凡夫’这两个词，在下面所说的——”
  - §360 句 2-9 改为：“这两种凡夫当中，取的是愚盲凡夫。”

## §361 句 134-361-30-47
- **问题**：句法与词义（必改）：
  - nissaya `ရူပေ= ရုပ်၌။ ဂါဟဿ= စွဲလမ်းခြင်း၏။ ပရိဂ္ဂဟေတဗ္ဗရူပတံ= ပိုင်းခြားယူအပ်သင့်သော သဘောရှိသည်၏အဖြစ်ကို`：dassetvā 的宾语是“对色的执取的（应被分辨把握的）性质”，gāhassa 是属格。现译“指出色本来就是可以看清楚的”把主体换成了色，属格丢失。“看清楚”也与前句 pariggahetuṃ 的译法不一致（见跨段一致性）。
  - `နိက္ကဍ္ဎေန္တော= ထိုတဏှာဂါဟစသည်မှ ထုတ်တော်မူလျက်` 的意思是把他们从执取中拉出来，现译“把他们在色上的执取拔出来”大体可以。
  - “太过厉害”偏口语。
- **建议**：保留“对色的执取”这个属格结构，pariggah- 改用全 chunk 统一的译词，例如：“……所以世尊指出他们对色的执取是应当加以分辨把握的，借此把他们从这种执取中拉出来，好让他们安立在非色上，才这样说。”“太过厉害”改为“过度”。此句理解难度高，revise 时宜压低 confidence。

## §362 句 134-362-28-34
- **问题**：格 — nissaya `တဏှာယ= တဏှာဖြင့်။ ဂိလိတွာ= မျို၍` 为具格，意思是“以贪爱吞下”，吞的主体是凡夫，对象是心。“被贪爱吞下去”把贪爱读成了施事。父层黑体“被贪爱吞没而执取”不能动，但释文本身应按 nissaya 写准。
- **建议**：“……是指以贪爱吞下、彻底认定之后加以执取。”

## §362 句 134-362-35-41
- **问题**：冗余 — “这是我的”出现两次，句子拖沓。taṇhāmamattena 为具格，意思是“以贪爱这种我所心”。
- **建议**：“……是指以贪爱这种‘我所’之心，认定‘这是我的’而加以执取。”

## §362 句 134-362-48-57、134-362-58-67、134-362-68-79（三句同病）
- **问题**：句法误读（必改）：
  - nissaya `တေန= ထိုဧတံ မမဟူသောပုဒ်ဖြင့်`，tena 指“这句话”，不是“这种执取”。
  - `ဂဟိတံ ဟောတိ` 在这里是“被涵盖、被包括”，不是心理上的执取。
  - 现译“由它就把一百零八种贪爱的活动都执取进来了”读起来像是执取行为把一百零八种贪爱抓进来，意思错了，也加重了“执取”一词的混用。
- **建议**：
  - 句 48-57：“**这是我的**是贪爱的执取，这句话涵盖了一百零八种贪爱的活动。”
  - 句 58-67：“……这句话涵盖了九种慢。”
  - 句 68-79：“……这句话涵盖了六十二种见。”

## §363 句 134-363-111-148
- **问题**：
  - 句式 — 本句与句 65-95 同属以 Nanu 起头的反问（nissaya `ဘိဇ္ဇန္တိ= ပျက်ကုန်၏မဟုတ်လော`）。现译以陈述句号收尾，反问语气断了，下一句“这确实是真的”就失去了着落。
  - 词义 — vītiharaṇa 的 nissaya 为“不碰到站立的脚、稍稍越过侧旁而移动”，“挪移”太泛。
- **建议**：句末改为“……噼噼啪啪地破灭掉吗？”vītiharaṇa 可译“侧移”。

## §364 句 134-364-50-77
- **问题**：格（必改）— nissaya `ပုရိမဝေဏိတော= ရှေ့ဖြစ်သောရုပ်၌ ဆိုအပ်ပြီးသောအစဉ်မှ။ ပရိတ္တကံ= နည်းသော`：ablative 与 parittaka 连用，是比较格，意思是“比前面（讲色身时）所说的相续短的”。现译“从前面的相续里取出一小段”把它读成了来源格。
- **建议**：“‘在夜里和在白天’这句话，是取了一段比前面讲色身时所说的相续更短的相续，只就相续来说的；……”

## §364 句 134-364-78-83
- **问题**：词义 — `အနေကာနိ= များစွာကုန်သော` 的意思是“许多”。aneka 不是“无数”，译“无数个”夸大了。
- **建议**：“……就有许多个十万俱胝（koṭisatasahassa）的心生起。”

## §365 句 134-365-2-34
- **问题**：风格 — “若把这么多稻粒……”中的“若”是文言假设词，属于 style.md 禁例（若…则）。
- **建议**：改为“如果把这么多稻粒……”。

## §366 句 134-366-24-36
- **问题**：术语 — tasmiṃ mahāvane 译“那片大林”，与 §366 句 2-5 对 mahāvana 的释义“广大的森林”不一致（见跨段一致性）。
- **建议**：“它在那片广大的森林中游走的时候……”
