# Review — 134:514-534（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 父层对照：book=168 §719-729（已定稿）

## 被解释词与父层对照

逐条对照父层定稿后，结果如下：

- **不一致（必改）**：§515 的 sanidānaṃ，§526 / §529 / §532 的 X-dhātuṃ bhikkhave。
- **一致**：kāmadhātuṃ bhikkhave paṭicca、kāmasaññaṃ paṭicca、tīhi ṭhānehi、micchā paṭipajjati、byāpādadhātuṃ / vihiṃsādhātuṃ bhikkhave、tiṇadāye、anayabyasanaṃ、evameva kho、visamagataṃ、na khippameva pajahati、na vinodeti、na byantīkaroti、na anabhāvaṃ gameti、pāṭikaṅkhā。
- **只需改格式**：§515 和 §517 的黑体标记写法有问题，用词没有问题。

## 跨段一致性

本 chunk 前半（§515-525）和后半（§526-534）的译法明显是两套，需要统一。下面的建议一般以前半为准。

- **被解释词的引出格式**：§515 / §518 / §521 写作 `在“**比丘们**，**X界**”这句话里`。§526 / §529 / §532 写作 `**X界（pāli），比丘们**——这句里`，没有引号，语序反过来，黑体里还带了巴利夹注。→ 统一为前一种格式。
- **Yathāha**：§515 / §518 / §521 译“正如所说：”。§526 / §529 / §532 译“正如《分别论》所说——”。
  - nissaya 的读法是 `ယထာဟ= ဘုရားအဘယ်ကဲ့သို့ဟောတော်မူသနည်း`，补出的是主语“世尊”。原文和 nissaya 都没有出现书名，出处已经在引文末尾标注“（《分别论》182）”。
  - → 统一为“正如所说：”。
- **Tattha katamā …?**：§516 / §519 / §522 译“这里，什么是X？”。§527 / §530 / §533 译“其中，什么是X呢？”。→ 统一。nissaya 读作 `တတ္ထ= ထိုဥဒ္ဒေသ၌`（在那个总说里），所以“其中”更贴切。建议两处都改成“其中，什么是X？”。
- **ayaṃ vuccati**：前半译“这叫做”，后半译“这就叫作”。→ 统一为“这叫做”。
- **dve kathā / duvidhā kathā**：§517 译“两种说法”，§528 译“两种讲法”。sabbasaṅgāhikā 在 §517 译“总括的说法”，在 §528 译“全部涵盖的讲法”。asambhinnā 在 §517 译“不相混的说法”，在 §528 译“不相混的讲法”。→ 统一为“总括的说法／不相混的说法”。
- **X-saññā nāma uppajjati**：§517 / §520 / §523 译“就生起了所谓的X想”。§528 / §531 / §534 译“就生起名为X想的想”。后一种写法里“想的想”重复。→ 统一为前者。
- **sahajātapaccayādivasena / sahajātādipaccayavasena**：§520 / §523 译“以俱生缘等方式”，§528 译“以俱生缘等为缘”。前句已经有“缘于”，“为缘”与之重复，而且 vasena 的意思是“以……的方式”。→ 统一为“以俱生缘等方式”。
- **巴利夹注**：前半一处都没有加。后半密集加注，有 nekkhammadhātu、abyāpādadhātu、avihiṃsādhātu、vitakka、abyāpāda、mettā、karuṇā。
  - vitakka 在 §515 起已经多次出现（欲寻、嗔寻），到 §528 才首次加注，不符合“首次出现夹注”的规则。
  - 这几个界名在父层已经有夹注，本层也不需要在黑体里重复。
  - → 后半删去这些夹注。若要保留，应移到本层各术语的首次出现处。
- **相应**：§516 / §519 / §522 / §527 / §530 / §533 把 paṭisaṃyutta 译作“相应”。§517 把 sampayogavasena 译作“以相应的方式”，§528 把 yathānurūpaṃ 译作“相应地”。三个不同的巴利词都译成了“相应”，而“相应”在阿毗达摩里是 sampayoga 的专名。
  - nissaya 对 paṭisaṃyutta 的读法是 `…နှင့်စပ်သော`／`…နှင့်စပ်ယှဉ်သော`（与……相连、有关的）。
  - → paṭisaṃyutta 改译“与X有关的”，“相应”留给 sampayoga。§528 的处理见该句。
- **出离**：§517 把 aniyyānika 译作“不能引向出离的”，与 nekkhamma 的定译“出离”撞词。§526 以下“出离”专指 nekkhamma，读者会误以为两者相关。处理见 §517 句 71-77。

## §515 句 134-515-2-16

- **问题**：被解释词与父层不一致（必改）。黑体“**有因缘**”，父层 §720 起 sanidānaṃ 一律译作“有因缘地”。本句随即说明它是 bhāvanapuṃsaka（作副词用的中性），父层加“地”正是体现这一点，去掉后注释就失去了对象。
- **建议**：改为“在第二经里，“**有因缘地**”这个词是作副词用的中性形式……”。

## §515 句 134-515-17-31

- **问题 1**：格式。`**缘于****欲界**` 中两段黑体首尾相接，渲染时会出现“****”或者断开。
- **建议 1**：合并为 `**缘于欲界**`，即 `在“**比丘们**，**缘于欲界**”这句话里`。
- **问题 2**：词法。kāmavitakkopi 的 -pi 漏译。nissaya 读作 `ကာမဝိတက္ကောပိ= ကာမဝိတက်သည်လည်း`，三项是并列的“……也是欲界”。
- **建议 2**：改为“欲寻也是欲界”，并与后面两个“也”对齐。
- **问题 3**：kāmāvacaradhammā 译作“欲界的诸法”，与“也是欲界”合起来读像同义反复。
- **建议 3**：改为“属于欲界范围的法”（kāmāvacara，意为在欲界运行的）。

## §516 句 134-516-8-21

- **问题**：术语。kāmapaṭisaṃyutto 译作“与欲相应的”，与 sampayoga（相应）冲突，见跨段一致性。nissaya 读作 `ကာမရာဂဟု ဆိုအပ်သော ကာမနှင့်စပ်သော`（与被称为欲贪的欲有关的）。
- **建议**：改为“与欲有关的思量、寻、思惟……”。§519 / §522 / §527 / §530 / §533 同样处理。

## §517 句 134-517-44-58

- **问题**：格式。`**缘于****欲想**` 的问题与 §515 相同。
- **建议**：改为 `**缘于欲想**`。

## §517 句 134-517-71-77

- **问题**：术语撞词。aniyyānikapaṭipadaṃ 译作“不能引向出离的道路”，“出离”在本 chunk 后半是 nekkhamma 的定译。nissaya 读作 `ဝဋ်ဆင်းရဲမှထွက်မြောက်ကြောင်းမဟုတ်သောအကျင့်ကို`（不是从轮回之苦中脱出之因的行道）。
- **建议**：改为“……不如实的道路、不能导向脱离轮回之苦的道路”。

## §522 句 134-522-18-34

- **问题**：词法与指涉。idha 译作“这里”，与同段 tattha（这里／其中）混同。nissaya 读作 `ဣဓ= ဤလောက၌`（在这世间）。
- **建议**：改为“在这世间，有人用手……”。

## §524 句 134-524-44-59

- **问题**：术语。“镇伏舍断、彼分舍断、正断舍断”中，“舍断”是硬拼出来的。pahāna 的通行译法是“断”：镇伏断、彼分断、正断断。
- **建议**：改为“……不用镇伏断、彼分断、正断断来舍弃已经生起的不善想……”。

## §525 句 134-525-22-30

- **问题**：词法漏译。bhaṅgamattampi 译作“连一点残余”，丢了 bhaṅga（坏灭）。nissaya 读作 `ဘင်္ဂမတ္တမ္ပိ= ဘင်မျှကိုလည်း`（连仅仅是坏灭〔刹那〕也……）。
- **建议**：改为“是说他没有做到连坏灭的刹那都不留下、使它彻底终结”。

## §525 句 134-525-31-38

- **问题**：存疑，不定为错。anuabhāvaṃ 按词形译作“随之归于不存在”。nissaya 给的是 `အနုဘာဝံ= အသစ်ဖြစ်ခြင်းသို့`，字面是“到新生起的状态”，与词源读法不同，可能是 nissaya 的特殊理解，也可能是讹误。译文按词源译可以保留。
- **建议**：维持现译，压低 confidence。分歧记入 known-issues。

## §528 句 134-528-31-38

- **问题**：见跨段一致性。“以俱生缘等为缘”与前句“缘于”重复，“名为出离想的想”也有重复。
- **建议**：改为“缘于这个出离界，以俱生缘等方式，就生起了所谓的出离想”。

## §528 句 134-528-39-43

- **问题 1**：词法。yathānurūpaṃ 译作“相应地”，与 sampayoga 撞词。nissaya 读作 `မိမိမိမိ၏ ပစ္စည်းအားလျော်စွာ`（各按自己的缘），并补出了谓语 `ဥပ္ပဇ္ဇန္တိ`。
- **建议 1**：改为“缘于想等，寻等也就各按自己的缘生起”。
- **问题 2**：夹注（vitakka）多余，见跨段一致性。
- **建议 2**：删去夹注。

## §526 句 134-526-2-12 / §529 句 134-529-2-10 / §532 句 134-532-2-10

- **问题**：被解释词格式（必改）。黑体写作“**X界（pāli），比丘们**”，语序与父层“比丘们，缘于X界”相反，黑体里还夹了巴利。这样写既不是父层原样，也与本层 §518 / §521 不一致。
- **建议**：分别改为：
  - 在“**比丘们**，**出离界**”这句话里，出离寻也是出离界，一切善法也都是出离界。
  - 在“**比丘们**，**无嗔界**”这句话里，无嗔寻也是无嗔界，无嗔本身也是无嗔界。
  - 在“**比丘们**，**无害界**”这句话里也是这样，无害寻也是无害界，悲也是无害界。

## §534 句 134-534-10-14

- **问题**：词法。“其余一切处”把 sesaṃ（宾语，其余的意思）和 sabbattha（处所，在各处）合成了一个名词短语。nissaya 的读法是：`သဗ္ဗတ္ထ= ခပ်သိမ်းသောပုဒ်တို့၌`（在所有词句中），`သေသံ= …ကြွင်းသောအနက်ကို`（其余的意思）。此外，“应依”偏文言。
- **建议**：改为“在各处，其余的意思都应当按照前面所说的来理解”。
