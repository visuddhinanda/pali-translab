# Review — 168:826-835（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 以下句子没有 nissaya，按要求不单独出意见：168-828-50-72、168-828-73-83、168-828-84-95、168-833-35-55、168-833-56-75、168-834-2-38、168-835-2-37、168-835-38-43、168-835-44-59。它们只在“跨段一致性”一节里提到。

## 跨段一致性

**abbhaññāsiṃ（了知）**
- §829、§830 译作“如实地知”。
- §834、§835 译作“如实地彻底了知”。
- nissaya 释作 `အဗ္ဘညာသိံ= ထူးသောဉာဏ်ဖြင့်သိပြီ`，意思是“以殊胜智了知”，带有“彻底了知”的分量。
- 建议四处统一为“如实地彻底了知”。
- 注意：§829、§830 原文有 evaṃ（这样），§834、§835 没有。两组之间这一处差异要保留，不要一起统一。

**宾语补足结构 assādañca assādato…**
- §829、§830 译作“知乐味为乐味”。
- §834、§835 译作“了知……的乐味是乐味”。
- 建议统一为“如实地彻底了知这四界的乐味是乐味、过患是过患、出离是出离”。

**paccaññāsiṃ（自称、宣称）**
- §829、§830 译作“自称已经现证”。
- §834、§835 译作“宣称自己已经证得了”。
- 建议统一为“宣称自己已经现证”。

**sabrahmake（有梵）**
- §829、§830 译作“有梵的世间”。
- §834、§835 译作“有梵天的世间”。
- 建议统一为“有梵天的”。

**sassamaṇabrāhmaṇiyā pajāya sadevamanussāya（众生一句）**
- §829、§830 译作“在沙门婆罗门、天、人的众生中”。
- §834、§835 译作“在有沙门、婆罗门、有天和人的众生中”。
- nissaya 释作 `သဿမဏဗြာဟ္မဏိယာ= ရဟန်းပုဏ္ဏားနှင့်တကွသော`，意思是“与沙门婆罗门一起的”，说明这里是“有…的”结构。
- 建议统一为后一种。前一种丢了“有”，读起来像在说“沙门婆罗门所属的众生”。

**sadevake loke（世间）**
- §829、§830 作“在这个有天……的世间”，§834、§835 没有“这个”。
- 原文没有指示词。建议去掉“这个”。

**ñāṇaṃ … dassanaṃ（智见）**
- §830 译作“智见”，§835 译作“智与见”。
- nissaya 释作 `ဒဿနံ= မြင်စွမ်းနိုင်သော။ ဉာဏဉ္စ= ပစ္စဝေက္ခဏာဉာဏ်သည်လည်း`，把 dassanaṃ 读成修饰 ñāṇaṃ 的定语，意思是“能见的智”，不是两个并列的事物。
- “智与见”与 nissaya 的句法不合。建议两处统一为“智见”。

**punabbhava（后有）**
- §830 是首次出现，没有夹注；§835 是第二次出现，却加了夹注“后有（punabbhava）”。
- 按夹注规则，应移到 §830 首次出现处，§835 删去。

**assāda / ādīnava / nissaraṇa（夹注位置）**
- 这三个词在 §827 首次出现，没有夹注；§832 才加“乐味（assāda）”“过患（ādīnava）”“出离（nissaraṇa）”。
- 应把夹注移到 §827-25-37，§832 删去。

**经题夹注**
- §826 作“正觉之前经”，没有夹注；§831 作“行求经（Acariṃsutta）”，有夹注。
- 建议两个经题体例一致：都夹注或都不夹注。

**“… pe …”的译法**
- §827、§828 作“……（略）……”；§832、§833 作“……乃至……”。
- “乃至”带文言色彩。建议统一为“……（略）……”。

**Sāvatthiyaṃ viharati（住在舍卫城）**
- §827 补了主语“（世尊）住在舍卫城”，§832 没有补。
- 建议 §832 也补“（世尊）”。

**§833 省略句的开头**
- §833-2-34 用“关于水界……”起头。§828-50-72 的同类省略句则保留原文句首，作“缘于水界……”。
- 原文是 Āpodhātuyāhaṃ，即“我对水界……”，没有“关于”。
- 建议改作“比丘们，我对水界……（略）……”，与 §828 的体例对齐。

## §827 句 168-827-25-37
- **问题**：取义，供参考。
  - nissaya 释作 `အဿာဒေါ= သာယာကြောင်း (တဏှာ) သည်`，把 assāda 解作“乐着之因（渴爱）”。
  - nissaya 卷末长注还说明：“地界的乐味”应理解为“依于地界而起的乐味”。
  - 译文“地界的乐味”与这个理解不冲突，可以保留，这里只提示传统读法。
- **建议**：不必改。

## §828 句 168-828-11-23
- **问题**：句法，存在分歧。
  - nissaya 把 yaṃ 读作表原因的不变词：`ယံ ခေါ= အကြင်ကြောင့်`，即“由于那个”。nissaya 所引复注说 `yanti hetuatthe nipāto`。
  - nissaya 对 ayaṃ 的释义是 `ဤချမ်းသာကြောင်း ဝမ်းမြောက်ကြောင်း (ဖြစ်သောတဏှာ) သည်`，即“这使乐与喜悦生起的（渴爱）”。
  - 照这样读，乐味指的是乐与喜悦生起的原因，不是乐与喜悦本身。译文“缘于地界而生起的乐与喜悦，这就是地界的乐味”把 ayaṃ 理解成乐与喜悦本身，与 nissaya 的格位读法不同。
- **建议**：可以按 nissaya 调整为“缘于地界而有乐与喜悦生起，使它们生起的，就是地界的乐味”。如果保留现译，要在报告中记下这处分歧，并压低这一句的 confidence。§828-50-72 的同类句也应跟着处理。

## §828 句 168-828-24-40
- **问题**：词义偏窄。
  - nissaya 释作 `ဝိပရိဏာမဓမ္မာ= ဖောက်ပြန်ခြင်းသဘောရှိ၏`，意思是“具有变易的性质”。
  - 译文“变坏的”丢了 -dhamma（性质）这一层，而且“坏”比“变易”说得重。
  - nissaya 对 yaṃ 的释义是 `အကြင်အခြင်းအရာအားဖြင့်`，即“以某种方式、状态”；对 ayaṃ 的释义是“这种不常、苦、变易的状态”。译文用“这一点”承接，基本对得上。
- **建议**：改为“地界是无常的、苦的、有变易性质的——这一点就是地界的过患”。§828-73-83 同步改。

## §828 句 168-828-41-49
- **问题**：语序有翻译腔。
  - nissaya 释作 `ပထဝီဓာတုယာ= ၏ ။ ယောဆန္ဒရာဂဝိနယော= …ပယ်ကြောင်း`，属格 pathavīdhātuyā 修饰欲贪。
  - 译文“对地界的欲贪调伏、欲贪舍断”是名词堆叠，不够通顺。
- **建议**：改为“调伏对地界的欲贪、舍断对地界的欲贪，这就是地界的出离”。§828-84-95 同步改。

## §829 句 168-829-2-50
- **问题**：用词偏弱。nissaya 释作 `န အဗ္ဘညာသိံ= ထူးသောဉာဏ်ဖြင့် မသိသေး`，意思是“还没有以殊胜智了知”，强调“还没有”和“以殊胜智”。译文“还没有……知”分量不够。
- **建议**：改为“只要我对这四界还没有这样如实地彻底了知……”。其余改动见“跨段一致性”一节。

## §830 句 168-830-2-38
- **问题**：同 §829。“已经这样如实地知”分量不足。
- **建议**：改为“已经这样如实地彻底了知”。

## §832 句 168-832-2-32
- **问题**：句法与用词。
  - nissaya 释作 `အဿာဒပရိယေသနံ= …ရှာမှီးခြင်းငှါ။ အစရိံ= လှည့်လည်ပြီ`：前者表目的（为了寻求），后者意思是“行走、游历”。nissaya 还引了注释 `ñāṇacārena acariṃ, anubhavanācārena`，即“以智而行、以亲身体验而行”。
  - acariṃ 是经题“行求经”的“行”。译文“我曾经进行对地界乐味的寻求”把它弱化成了“进行”，看不出与经题的对应，而且是翻译腔。
  - “以智慧”中的“以”偏文言。
- **建议**：
  - 改为“比丘们，我曾为了寻求地界的乐味而行”，或“……而去探求”。
  - 后半句改为“我都用智慧清楚地看见了”。
  - §832-33-53、§832-54-75，以及 §833 的三句同步改。

## §832 句 168-832-33-53
- **问题**：同 168-832-2-32。“进行对地界过患的寻求”是翻译腔，“以智慧”偏文言。
- **建议**：改为“我曾为了寻求地界的过患而行……我都用智慧清楚地看见了”。

## §832 句 168-832-54-75
- **问题**：同上。另外，nissaya 释作 `နိဿရဏပရိယေသနံ= ထွက်မြောက်ရာ နိဗ္ဗာန်ကို ရှာမှီးခြင်း`，把出离指为涅槃。译文“出离”可以保留，不必改译。
- **建议**：改为“我曾为了寻求地界的出离而行……我都用智慧清楚地看见了”。

## §833 句 168-833-2-34
- **问题**：
  - “关于水界……乃至……”这种体例不合，见“跨段一致性”一节。
  - nissaya 注明 `ပထဝီဓာတုယာဟံဟူသော ဝါကျကို မှီး၍ပေး`，即“依照地界那一句来展开”，所以句式应与 §832 完全平行。
- **建议**：改为“比丘们，我对水界……（略）……比丘们，我对火界……（略）……比丘们，我曾为了寻求风界的乐味而行……”。

## §830 句 168-830-39-45
- **问题**：nissaya 把 dassanaṃ 读作修饰 ñāṇaṃ 的定语，即“能见的（省察）智”。译文“智见”可以接受。
- **建议**：保留“智见”，§835 向这里统一。
