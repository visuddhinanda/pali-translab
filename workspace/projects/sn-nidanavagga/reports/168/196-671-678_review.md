# Review — 196:671-678（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位判定无独立依据）／本层义注 ❌（本层即复注 ṭīkā）／父层义注译文 ✅（book 134, §652-659，已定稿）
> 说明：缺 nissaya，下列词法判断仅凭原文与父层上下文，涉及格位的条目标注为「待 nissaya 复核」。

## 被解释词核对（与父层逐字对照）

逐条比对后，绝大多数黑体与父层译文逐字一致（知足的／所得的任何一种／粗厚的、细软的／随所得知足／体力／适宜／即使能得到也不接受／交换这件衣服／用轻便的衣服维持下去，这样他同样是知足的／尿渍诃子／是佛陀等人所称赞的／有一种人……自己知足，却不称赞知足／这位／不正当营求／惶恐／焦躁／贪欲的耽著／迷醉／过患／随所得等／就像大迦叶长老那样／以迦叶为榜样／把这种行持完整地修满，也正是我们的担子）。不一致或需调整的四处：

- **196-676-71-82**「**并不焦躁**」：父层同一处（134-658-62-92）作「并不像那样**焦躁不安**」。→ 建议改为「**并不焦躁不安**」，与父层该句逐字对齐（父层另一处 uttasati paritassati 作「惶恐焦躁」，两处本身有出入，但本层注的是后一处）。
- **196-676-15-26 / 27-38**：巴利黑体起自 `Na santuṭṭo hoti` / `Neva santuṭṭho hoti`，不含 `eko`；中译把「有一种人」也放进了黑体。→ 建议「有一种人」移到黑体外：「有一种人**自己不知足，却称赞知足**」「有一种人**既不知足，也不称赞知足**」，与上一条 §676-2-14 的处理（`**Eko**` 单独成黑体）保持同一规则。
- **196-676-100-106**「**只了知正当目的**」：巴利黑体只是 `Nissaraṇamevā`，「了知」对应的是黑体外的 `pajānanto`。父层对应处作「只了知……这一类正当目的」。→ 可保留，但更贴合的黑体是「**只是正当目的**」，把「了知」留在释义里。
- **196-677-25-36**「**宣说是担子**」：父层作「宣说……是**正等正觉者的**担子」，压缩后「是谁的担子」丢失，而下句「因为这与……誓言相符」正依赖这一层（誓愿是佛的）。→ 建议「**宣说……是正等正觉者的担子**」，或在释义里补出「（这担子属于正等正觉者）」。

## 跨段一致性

- **itarītara**：§672 内出现四种译法——「所得的任何一种」（672-17-24，引父层黑体）／「任何一种」（672-25-32）／「另一种」（672-45-50、51-56）／「这一种那一种」（672-57-60）。词形分析段用「另一种」有理据（复注正在拆 itara + itara），但四种并陈读者会失去线索。→ 建议：黑体引文保持「所得的任何一种」不动；分析段统一用「另一种（itara）」，并在 672-57-60 把主语写成 itarītara 本身，例如「因为 itarītara（“这一种那一种”）这类词，都是相对于另一方才说得上的」。
- **paritassati**：本层 §676-64-66 作「焦躁」，§676-71-82 作「焦躁」，父层同句作「焦躁不安」。→ 统一为「焦躁不安」（见上节）。
- **人名缺巴利夹注**：§676 一连出现三个罕见人名——薄拘罗长老、释迦子优波难陀长老、愚陀夷长老，均无夹注。按 `style.md` 第二节，罕见名相首次出现应附巴利原词；「愚陀夷（Lāḷudāyī）」尤其需要，否则易与常见的迦留陀夷（Kāḷudāyī）混淆。→ 建议补为「薄拘罗（Bākula）长老」「释迦子优波难陀（Upananda Sakyaputta）长老」「愚陀夷（Lāḷudāyī）长老」。
- **nidassana 的译词**：§677-22-24 黑体作「以迦叶为**榜样**」（承父层），释义却换成「示范」。→ 建议释义也用「榜样」：「就是把他当作榜样」。
- 一致性良好、无需改动的：gedha 全层作「耽著」（676-83-90 / 91-95），与父层「贪欲的耽著」同；pāpavitakka 作「恶寻」（674-6-13）与父层同；santoso 三分（随所得／随体力／随适宜）全层与父层一致。

## §674 句 196-674-2-5 【必改】

- **问题**：释义自相矛盾。黑体按硬约束取父层的「体质」（父层 `attano pakativiruddhaṃ` → 「与自己的体质不合」），但复注这条恰恰是在说 pakati 不限于身体——`vācāpakatiādikā`（言语习性等种种本性）。译文「**体质**：指言语习性等各种本性」读起来就是「体质＝言语习性」，不通。
- **建议**：黑体保持「体质」不动，在释义里点出词与义的落差并补巴利：「**体质**（pakati）：这里的 pakati 是指言语习惯等各方面的本性，不只是身体状况。」
- **附带（父层待核，不在本层改）**：复注这条说明父层把 pakati 一律译作「体质」偏窄（134-654-31-53、655-29-58、656-29-55、673-24-37 均涉及）。请在 harmonize 阶段一并定夺，本层报告仅记录。

## §676 句 196-676-107-110、196-676-111-114 【必改／跨层冲突】

- **问题**：复注明说 `yathāladdhādīnaṃ` = `yathāladdhapiṇḍapātādīnaṃ`（随所得的托钵食物等），并补一句这是**从整体中特指部分的属格**（niddhāraṇa）——也就是「在随所得的食物等当中，随便哪一种」。而父层译文（134-658-140-157）把同一个词读成「就前面所说的随所得等**三种知足**而言」，父层 134-653-16-31 也作「对以随所得知足为首的那几种知足当中的任何一种」。两层读法不同：一个指资具，一个指知足。读者对照两层会直接撞上矛盾，而本层译文没有任何提示。
- **建议**：本层译文本身准确，不必改动；但这是跨层必须拉齐的一处。处理方向二选一，交人工定夺后在 harmonize 执行：(a) 依复注修父层，把「随所得等三种知足」改为「随所得的食物等」；(b) 若保留父层读法，需在本层此条加一句说明复注对此词的读法与父层译文不同。本报告倾向 (a)——复注对「niddhāraṇa 属格」的分析只有在读作资具时才讲得通。

## §672 句 196-672-57-60

- **问题**：风格。「因为“这一种那一种”这类词都是**相互对待**而说的」——「相待／对待」是文言化的因明术语用法，没有古文基础的读者读不出「相对而言」的意思，违反 `style.md` 第一节。
- **建议**：「因为 itarītara（“这一种那一种”）这类词，都是相对于另一方才说得上的。」

## §673 句 196-673-24-37

- **问题**：风格。「反而会给身体带来**损恼**」——「损恼」是半文半白的词。原文 `sarīrabādhāvahaṃ` 即「使身体受苦／成为身体的负担」。
- **建议**：「反而会让身体难受」或「反而会成为身体的负担」。

## §673 句 196-673-53-79

- **问题**：格式与风格。黑体作「**自己拿他们……乃至……来穿**」，其中「乃至」是 `…pe…`（peyyāla 省略号）的传统译法，属文言标记；且省略号与「乃至」叠用，读者不易看出这是引文省略。
- **建议**：改为「**自己拿他们**……（中略）……**来穿，这样他同样是知足的**」，省略部分不加黑体。

## §673 句 196-673-80-87

- **问题**：夹注方向与 `style.md` 第三节相反（规定是汉译在前、巴利原词在圆括号内），此处成了巴利在前、汉译在括号里；另外把 api 单译作「也」，切断了与父层的对应——父层正是把 `…topi santuṭṭhova hoti` 译成「这样他**同样**是知足的」。
- **建议**：「同样，在其余资具的随体力、随适宜两段解说里，用上“也／同样”（api）这个词的用意，也应当照这样理解」——即父层「这样他同样是知足的」里那个“同样”。

## §675 句 196-675-2-12

- **问题**：主语缺失导致误读风险。`pūtibhāvena vā chaḍḍitattā` 说的是**尿**被当作腐臭之物而遭弃置（即所谓 pūtimutta「腐尿／陈弃」），译文「或者因为腐坏而被舍弃」没有主语，读者很容易以为腐坏被弃的是诃子。这是译得很确定、实则有歧义的一处。
- **建议**：「或者因为（所用的尿）被当作腐臭之物弃置不用，所以叫做尿渍诃子。」可顺带与下一条的「腐尿药」建立呼应。

## §676 句 196-676-44-49

- **问题**：`ayoniso` 的挂靠。原文 `ayoniso micchājīvavasena paccayapariyesanaṃ` 中 ayoniso 是修饰「寻求」这一行为的副词，译文「以**不如理的**邪命方式」把它降成了「邪命」的定语，读起来像是邪命还分如理与不如理。待 nissaya 复核。
- **建议**：「就是不如理地、以邪命的方式寻求资具。」

## §676 句 196-676-50-63

- **问题**：同义反复。「因为……这样的念头而**生起恐慌**，因此**惶恐不安**」把 `jātuttāsena uttasati`（因生起的恐怖而惶恐）拆成了两层意思重说一遍。
- **建议**：「**惶恐**：就是因为“我到底怎样才能得到呢”而心里生起恐怖，惶恐不安。」

## §676 句 196-676-83-90

- **问题**：补出成分。原文 `ārammaṇena saddhiṃ ganthanaṭṭhena bajjhanaṭṭhena` 只说「与所缘系结、捆缚」，译文补出了「把**心**与所缘」。补主语可读性更好，但 `style.md` 第六节要求不擅自补足；此处也可能是补「自身」而非「心」。待 nissaya 复核。
- **建议**：若保留，改为语义更中性的「因为它有与所缘系结、捆缚在一起的意思」；确需补出时用「（自身）」。

## §676 句 196-676-91-95

- **问题**：术语。`momūhattabhāva` 译作「极度**愚昧**的状态」，佛教语境下 moha 一系固定作「痴／愚痴」，「愚昧」是世俗用词。
- **建议**：「就是耽著，就是极度愚痴的状态。」并考虑登记 `terms.md`：momūha → 极度愚痴。

## §676 句 196-676-100-106

- **问题**：两点。① 用字：「不**粘**著」宜作「不黏著」或「不执取」，且与本层已用的「耽著」宜成一系；② 末句「也就是只了知这一正当目的」是对黑体的同义复述，整句变成回环。
- **建议**：「**只是正当目的**：就是对衣服先照见“这只是为了这个用处”，从而只了知那被称为“不黏著”的出离。」另可在此处点出父层引的“仅仅是为了防御寒冷”正是这个“只为此用”，帮读者接上父层 134-658-124-139。

## §677 句 196-677-37-46

- **问题**：风格。「因为导师的**教敕**必须恭敬地领受下来」——「教敕」是文言词。`sirasā sampaṭicchitabbato`（应以头顶戴受持）意译成「恭敬地领受」处理得好，前半不宜再文言化。
- **建议**：「因为导师的教导必须恭敬地领受下来。」
