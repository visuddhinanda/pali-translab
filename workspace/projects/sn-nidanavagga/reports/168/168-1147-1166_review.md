# Review — 168:1147-1166（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 跨段一致性

- **编号格式**：§1147「2. 善根经」、§1149「3.」、§1153「5.」、§1162「6.」、§1165「7.」用阿拉伯数字加点；§1151 用「四、白法经」，§1152 用「一八三、」，其余段号都是「181.」「182.」「184.」这种写法 → 建议统一为阿拉伯数字加点：「4. 白法经」「183.」。
- **lābhasakkārasiloka**：§1148（三句）译「利养、恭敬**和**名声」，§1150 起都译「利养、恭敬**与**名声」 → 建议统一为「利养、恭敬与名声」。依据：出现次数占绝对多数。
- **… pe …**：§1148、§1150、§1166 译「……乃至……」，§1152 译「……（略）……」，§1164 译「……（中略）……」 → 建议统一为「……乃至……」。
- **Sāvatthiyaṃ viharati**：§1148 补了主语「世尊住在舍卫城」，§1150、§1152、§1166 是「住在舍卫城」，§1163 的 Rājagahe viharati 也补了「世尊」 → 建议统一。style.md 要求不擅自补主语，但这里不补会让读者不知道是谁住，所以建议各处都补「世尊」。
- **samucchedaṃ agamā**（nissaya：`သမုစ္ဆေဒံ= အကြွင်းမဲ့ပြတ်ခြင်းသို့` 无余地断绝）：§1148 译「彻底断掉了」，§1150 译「彻底断绝了」，§1152 译「彻底断灭了」 → 三经句式完全平行，建议统一为「彻底断绝了」。
- **pariyādiṇṇacitta**（nissaya：`ပရိယာဒိဏ္ဏစိတ္တံ= ထက်ဝန်းကျင်မှ ယူအပ်သောစိတ်ရှိသည်` 心被四面完全攫取）：§1148 译「心思全被它们占满」，§1150、§1152 译「心被它们占据」，§1166 译「心被它完全占据」 → 建议统一为「心被它们完全占据」。nissaya 有「完全、四面」的意思，§1150、§1152 漏了「完全」；§1166 的「它」与前面的「它们」单复数不一致。
- **attavadhāya / parābhavāya 句**（§1154–1158，共 9 处）：句式问题全组相同，见下 §1154 句 168-1154-26-42 与 §1155 句 168-1155-2-16。改的时候要九处一起改。
- **bhattābhihāro abhiharīyati / āharīyissati 句**（§1163 三处、§1164 一处）：施事问题全组相同，见下 §1163 句 168-1163-12-31。
- **章末标号**：「第五经」（§1161）缺句号，其余各经都是「第X经。」 → 补「。」。

## §1154 句 168-1154-2-16
- **问题**：补出成分（轻）— nissaya 的句法注说明 acirapakkante devadatte 是特指时间（ဝိသေသ），对应 ekaṃ samayaṃ 这个泛指时间（သာမည），意思是「提婆达多刚离开教团（သာသနာမှ ဖယ်ခွါခါစ）的时候」。译文「离去不久」没说从哪里离去，读者可能理解成离开世尊身边。
- **建议**：可译为「那时提婆达多离开僧团不久」。译文现在拆成两句，时间关系也算清楚，补不补由译者决定。

## §1154 句 168-1154-26-42
- **问题**：格与句法 — 按 nissaya，attavadhāya 是 `မိမိကိုယ်ကို သတ်ခြင်းငှါ`（为了自我毁灭，目的与格），parābhavāya 是 `ဆုတ်ယုတ်ပျက်စီးခြင်းငှါ`（为了衰败），主句谓语是 udapādi `ဖြစ်ပြီ`（生起了）。译文改成「得到的…招致…」，谓语「生起」丢了，「为了」也变成了「招致」这种结果关系。另外 parābhava 原文没有「自身」，nissaya 也没有，「招致他自身的败亡」里的「自身」是添出来的。
- **建议**：「比丘们，提婆达多的利养、恭敬与名声生起，是为了他自己的毁灭；提婆达多的利养、恭敬与名声生起，是为了他的败亡。」同样的句子 168-1155-17-31、168-1156-17-31、168-1157-18-32、168-1158-17-32 一起改。

## §1155 句 168-1155-2-16
- **问题**：格与句法 — nissaya：`ကဒလီ= ငှက်ပျောပင်သည်`（芭蕉树，主格）、`အတ္တဝဓာယ= ငှါ`（目的）、`ဖလံ= အသီးကို`、`ဒေတိ= ပေး၏`，而且 phalaṃ deti 出现两次，分别搭配两个目的与格。译文只译了一次「结出果实」，加了原文没有的「反而」，把目的译成了结果（「招致」）。
- **建议**：「比丘们，就像芭蕉为自我毁灭而结果，为败亡而结果；」168-1156-2-16（竹子）、168-1157-2-17（芦苇）同样改。

## §1158 句 168-1158-2-16
- **问题**：格与句法 — 和上一条相同。nissaya `ဂဗ္ဘံ= ကိုယ်ဝန်ကို။ ဂဏှာတိ= ယူ၏`，gabbhaṃ gaṇhāti 出现两次；译文合成一次，又加了「反而」。
- **建议**：「比丘们，就像母骡为自我毁灭而怀胎，为败亡而怀胎；」

## §1161 句 168-1161-2-11
- **问题**：补出成分 — nissaya 把 sakkāro 释为 `လာဘ်ပူဇော် အကျော်အစော`，并且注明：「(လာဘသက္ကာရ သိလောကောဟု ဆိုလိုလျက် ရှေ့နောက် ၂-ပုဒ်ကို ချေထားသည်)」，意思是这里本来指利养、恭敬与名声三者，偈中省掉了前后两个词。译文只译「恭敬」，和散文部分的三项对不上，读者会以为偈颂只讲恭敬。
- **建议**：译成「利养恭敬」或「利养、恭敬与名声」，看偈句长度决定，例如「利养恭敬毁掉卑劣的人，就像胎儿毁掉母骡一样。」

## §1163 句 168-1163-12-31
- **问题**：补出成分 / 格 — nissaya 注明 abhiharīyati 是被动态，施事要补成 `အဇာတသတ္တု ကုမာရေန`（由阿阇世王子），并说 pañca thālipākasatāni 是表示数量的次要宾语，bhattābhihāro 是主要宾语。译文「还每天有多达五百锅的饭食送去给他」没有施事，读起来像来源不明。「多达」是另加的强调。
- **建议**：「那时，阿阇世王子每天早晚乘着五百辆车去侍奉提婆达多，还派人给他送去五百锅饭食。」同样的句子 168-1163-54-76、168-1163-87-119、168-1164-26-57 一起改。

## §1163 句 168-1163-87-119
- **问题**：OCR / 原文疑问（记录，不改）— nissaya 注：「အာဟရီယိဿတိဟု ရှိသည်ကား အဘိဟရီယတိ ဟူသော ရှေ့စကားနှင့်မညီ။ စူဠဝါ စာပိုဒ် ၃၃၅-၌လည်း အဘိဟရီယိဿတိပင် ရှိ၏」。意思是 āharīyissati 和前文的 abhiharīyati 不一致，《小品》第 335 段作 abhiharīyissati。§1164 句 168-1164-26-57 也是同样的写法。
- **建议**：译文按 abhiharīyissati 理解就行，现在的译法不用改，只在这里记一下。

## §1164 句 168-1164-2-25
- **问题**：词义 / 格 — nissaya：`နာသာယ= နှာခေါင်း (ဖု) ၌`（在鼻子上，处格），`ပိတ္တံ= (ဝံ ငါး) သည်းခြေကို`（熊或鱼的胆），并注明：在狗鼻子旁边弄破胆囊，就是把胆汁抹进去。译文「在一条凶暴的狗的鼻孔里弄破胆囊」有两个问题：「鼻孔里」比原文说得更具体；「胆囊」没说是谁的，容易读成狗自己的胆。另外 nissaya 把 bhiyyosomattāya 释为 `ပင်ကိုယ်အတိုင်းအရှည်ထက် လွန်စွာ`（比它原本的程度更甚），「更加凶暴」可以保留，也可以补出「比原来」。
- **建议**：「比丘们，譬如有人在一条凶狗的鼻子上弄破一个（熊或鱼的）胆，比丘们，那条狗就会比原来更加凶暴；」
- **原文疑问**（记录，不改）：nissaya 注「ဧဝံ ဟိ သော ဘိက္ခဝေဟု ရှိခြင်းသည်လည်း မကောင်းလှ။ ဘိက္ခဝေ မပါသင့်၊ ဣ မူ၌လည်း မရှိ」，认为第二个 bhikkhave 是衍文，另一个版本里没有。

## §1166 句 168-1166-38-47
- **问题**：用词（轻）— nissaya 把 sampajānamusā 释为 `သိလျက်ချွတ်ယွင်းသောစကား`（明知的妄语）。「明知故意地说谎」里「明知」和「故意」意思重复。下一句 168-1166-48-57 也一样。
- **建议**：两句都改为「明知而说谎」。

## §1166 句 168-1166-48-57
- **问题**：格（轻）— nissaya 把 abhibhūtaṃ 释为 `နှိပ်စက်အပ်သည်ဖြစ်၍`（被逼迫、被压制），把 pariyādiṇṇacittaṃ 释为「心被四面攫取」，两者都是 tam 的状语。译文结构没错，但「它」和前面各经的「它们」不一致，见跨段一致性一节。另外「我却看到」里的「却」是另加的转折，可以保留。
- **建议**：「后来，我看到他被利养、恭敬与名声压倒，心被它们完全占据，明知而说谎。」
