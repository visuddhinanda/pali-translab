# Review — 168:418-430（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§419、§421、§424、§427 等多处 nissaya 只有「同前」体例说明，无逐词释义；§424-425、§429-430 大部分句子无 nissaya，只在跨段一致性里覆盖）

## 跨段一致性

本 chunk 有三部经，句式几乎完全重复。§424-425（第二大树经）与 §427-430（幼树经）的译法明显与 §419-422 不同，像是分批译出后没有统稿。以下各项都应统一：

- **taṇhā**：§419-422、§427-430 译「渴爱」，§424-425 译「贪爱」 → 统一为「渴爱」。这是多数译法，也是十二缘起的通行译名。
- **upādāna**（缘起支）：§419-425 译「执取」，§427-429 译「取」 → 统一为「执取」，与同段 upādāniya「可被执取的」呼应。
- **dukkhakkhandha**：§419-422 译「苦的聚集」，§424-430 译「苦蕴」 → 二选一统一，建议「苦蕴」。
- **evametassa kevalassa dukkhakkhandhassa samudayo / nirodho hoti**：
  - §419-422、§424-425 译「这整个……就是这样生起／息灭的」
  - §427-430 译「这样，这全部的苦蕴就生起／息灭了」
  - → 统一为前一种句式。
- **nirujjhati / nirodha**：多数译「息灭」，§425 译「止息」 → 统一为「息灭」。
- **assādānupassino viharato**：
  - §419、§420 译「持续观看它们的可喜之处而生活」
  - §424 译「安住于观察它们的乐味」
  - §427-428 译「不断观察它们的乐味」
  - → 统一为一种。建议「如果一个人持续观察它们的乐味而生活」。
- **ādīnavānupassino**：§421-422 译「危害」，§425、§429-430 译「过患」 → 统一，建议「过患」。
- **dhammesu**：多数译「法」，§424、§425 译「事物（dhamma）」 → 统一为「法」。夹注巴利原词只在首次出现时加。
- **tadupādāno**（树喻中）：
  - §420 译「以它为执取」，§424 译「以此为执取（upādāna）」，§428 译「以此为依托」
  - nissaya §428：`တဒုပါဒါနော= ထိုမြေ, ရေဟူသော အမှီရှိသည်ဖြစ်၍`（以那土与水为依靠）。这里的 upādāna 是「依持、燃料」义，不是「执取」。
  - → §420、§424 改为「以此为依托」。
- **ojaṃ**：§420 译「精华」，§424 译「养分」 → 统一。nissaya 作 `ဩဇံ= အဆီကို`（汁液、养分），建议「养分」。
- **ciraṃ dīghamaddhānaṃ**：§420 译「很长的时间」，§424 译「长久地」 → 统一。
- **seyyathāpi**：§420、§422 译「就好比有」，§424-425 译「就像」，§428、§430 译「譬如有」 → 统一为「就好比有」。nissaya 补出 `(အတ္ထိ= ရှိ၏)`，「有」字应保留。
- **kuddālapiṭakaṃ**：§422、§430 译「锄头和筐子」，§425 译「锄头和篮子」 → 统一为「筐子」。
- **pavāheyya**：
  - §422 译「让它顺着湍急的河水冲走」，§425 译「投进……冲走」，§430 译「放进……冲走」
  - 宾语 §425 作「它们」，§422、§430 作「它」
  - masiṃ 是单数，指灰烬 → 统一为「它」，动词统一一种。
- **… pe …**：§419-422、§427-430 译「（中略）」，§424-425 译「乃至」 → 统一为「（中略）」。
- **经题与编号**：
  - 经题：§418「五、大树经」、§423「六、第二大树经」，§426「7. 幼树经」
  - 段号：§419「五十五、」、§424「五十六、」，§427「57.」
  - 经尾：§422「第五经。」、§425「第六经。」，§430「第七。」
  - → §426、§427、§430 依前例改为「七、幼树经」「五十七、」「第七经。」
- **Sāvatthiyaṃ viharati**：§419、§424 补「（世尊）」，§427 未补 → 统一补出。

## §420 句 168-420-26-37

- **问题**：词法误读。tadupādāno 在树喻中的意思是「以之为依持」，nissaya 同类句（§428）作 `ထိုမြေ, ရေဟူသော အမှီရှိသည်`，译成「以它为执取」不对。tadāhāro 的 nissaya 是 `ထိုအမြစ်ဟူသော အမှီရှိသည်ဖြစ်၍`（以那根为依靠），可见「它」指根所输送的养分；译文的「它」容易被读成大树自身。
- **建议**：「比丘们，这样一来，这棵大树以此为食、以此为依托，就能存续很长的时间。」§424-36-47 照此同改，并删去「（upādāna）」夹注。

## §422 句 168-422-22-46

- **问题**：漏义。nissaya 作 `ပလိခဏေယျ= ထက်ဝန်းကျင်မှ တူးရာ၏`（从四周挖掘），pali- 前缀表示「周围」，译文「掘开泥土」丢掉了这层意思。另外 `မူလာနိ= အမြစ်ဟူသမျှတို့ကို`（所有的根），强调「全部」。
- **建议**：「……砍断根以后在四周挖掘，挖开以后把所有的根都拔出来，连细得像香根草（usīra）须根那样的细根也一并拔出。」§425 的「挖开根部的土」同步统一。

## §422 句 168-422-68-107

- **问题**：词义偏差（轻微）。nissaya 作 `မသိံ= မီးသွေး (ပျာ) ကို`（炭、灰烬），译「灰」可以接受，但前后各句应保持一致。
- **建议**：保留「灰」，§425、§430 的代词按上文跨段一致性一节统一。

## §422 句 168-422-108-136

- **问题一**：词法误读。nissaya 作 `တာလာဝတ္ထုကတော= ထန်းပင်၏တည်ရာ (ကျင်း) ကဲ့သို့ ပြုအပ်ပြီးသည်`，意思是「被弄得像多罗树的生长处（只剩空坑）一样」。tālāvatthu 指树所立之处，不是「断了头的多罗树残株」。
- **问题二**：语法误读，兼有文言。nissaya 作 `အနုပ္ပါဒဓမ္မော= မဖြစ်ပေါ်ခြင်းသဘောရှိသည်`（具有不生起的性质），是修饰大树的形容性谓语。译成「成为不再生起之法」，误读成名词「一个法」，「之」又是文言虚词。这是必改项。
- **建议**：「比丘们，这样一来，这棵大树的根被彻底切断，被弄得像多罗树原来生长的地方一样（只剩空坑），再也不会长出来，将来不会再生起。」§425-37-49、§430-25-38 的「截去头的多罗树」「断了头的多罗树」同改。

## §422 句 168-422-166-167

- **问题**：格式不一致。§430 经尾作「第七。」
- **建议**：本句「第五经。」保持不变，§430 改为「第七经。」

## §428 句 168-428-11-59

- **问题**：增译。nissaya 作 `ပံသုံ= မြေမှုံ့ကို`（细土、土粉），原文没有「好」的意思。
- **建议**：「时时给它培土」或「时时给它添土」。

## §428 句 168-428-60-73

- **问题**：漏译。nissaya 作 `ဧဝံ ဟိ= လျှင်`（这样一来），译文缺了 evañhi，与 §420、§422 的平行句不一致。
- **建议**：「比丘们，这样一来，这棵幼树以此为食、以此为依托，就会成长、繁茂、壮大。」

## §430 句 168-430-65-66

- **问题**：格式不一致。§422、§425 都作「第X经。」
- **建议**：改为「第七经。」
