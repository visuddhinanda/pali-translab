# Review — 168:57-85（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§68 第 2 句起至 §74 末、§81 无 nissaya，按词法复核略过）

## 跨段一致性

- **经号、品号格式不统一**：§57、§58「5.」，§59、§60「六、」，§61、§62「七、」，§63、§64「8.」，§65、§66「九、」，§67「十、」，§68「10.」，§82「一 」，§83「十一 」 → 统一为一种格式（建议「N. 」阿拉伯数字加点，与巴利原文一致），经题行和经文首行同一套。
- **bhikkhave**：§62 译「诸比丘」，其余各段都译「比丘们」 → 统一为「比丘们」（「诸」作复数前缀偏文言）。
- **Vessabhū**：§59、§60 译「毗舍浮」，§78 摄颂译「毗舍婆」 → 统一为「毗舍浮」。摄颂要和经题对得上。
- **佛名夹注不统一**：§62「拘留孙（Kakusandha）」、§66「迦叶（Kassapa）」加了夹注，§58 尸弃、§60 毗舍浮、§64 拘那含牟尼都没有加 → 要么全部不加（这几位都是传统通用译名），要么全部加。建议全部不加。
- **「……（中略）……」后的句号**：§60、§66 有「。」，§58、§62、§64 没有 → 统一。
- **paccayā 句式**：§71「以无明为缘而有行」「以行为缘而有识」，§85「以无明为缘，就有行」「以行为缘，就有识」 → 同一个公式，建议统一为「以…为缘而有…」。
- **nirodha**：§72–§74 译「灭去」（「生灭去，老死就灭去」「行灭去，识就灭去」），§85 译「息灭」（「行也就息灭」「苦蕴就息灭了」） → 同一组缘起还灭公式，建议统一为一个译法。§74 的「‘灭，灭’」也要相应对齐。
- **dukkhakkhandha 夹注位置**：§71、§74 已经出现「苦蕴」，没有夹注；§85 才加「苦蕴（dukkhakkhandha）」 → 夹注应移到首次出现处，或者按经分别处理，但全书要统一一个规则。

## §58 句 168-58-2-18
- **问题**：格 / 漏译 — `သိခိဿ= သိခီမြတ်စွာဘုရား၏`，属格 ၏ 标出「尸弃世尊**的**」，后面省略的是被领属的内容。译文作「尸弃世尊、阿罗汉、正等正觉者……（中略）……」，漏了「的」。尸弃变成了主语，和 §60、§62、§64、§66 的同构句也不一致。
- **建议**：改为「5. 比丘们，尸弃世尊、阿罗汉、正等正觉者的……（中略）……」。

## §62 句 168-62-2-16
- **问题**：语体 — 「诸比丘」偏文言，并且与全 chunk 的「比丘们」不一致（见上）。
- **建议**：改为「七、比丘们，拘留孙世尊、阿罗汉、正等正觉者的……（中略）……」（格式按统一方案调整）。

## §78 句 168-78-2-6
- **问题**：译名不一致 — `ဝေဿဘူ= ဝေဿဘူသုတ်` 指 §59 的《毗舍浮经》，摄颂却译「毗舍婆」，和经题对不上。
- **建议**：改为「毗婆尸、尸弃与毗舍浮；」。

## §77 句 168-77-2-5
- **问题**：取义 — nissaya 把摄颂各词都释为经名：`ဒေသနာ= ပဋိစ္စသမုပ္ပါဒသုတ်`（缘起经）、`ဝိဘင်္ဂပဋိပဒါ= ဝိဘင်္ဂသုတ် ပဋိပဒါသုတ်`（分别经、道迹经）。译文「说法、分别、道迹」作为摄颂缩略可以成立，但读者不容易对应到本品前四经。
- **建议**：核对本品 §1–§4 的经题译法，让摄颂用词与经题对应（例如「说法」对应的经题如果译作「缘起经」，摄颂也要能对上）。不必加字，只求对应。

## §84 句 168-84-2-15（及同段 kiṃjātikā / -jātikā 各句）
- **问题**：词义 — `ကိံ ဇာတိယာ= အဘယ်လျှင် ဇစ်မြစ်ရှိကုန်သနည်း`，jātika 释为「根源、出处」。译文「以什么为生」在本经语境里容易和十二支的「生」（jāti）混淆，也可能被读成「以什么为生计」。
- **建议**：考虑改为「以什么为生起处」或「从什么而生」，同段各句（taṇhājātikā、vedanājātikā……avijjājātikā）一并调整。属于建议项，不是必改项。

## §85 句 168-85-12-22（及 §71、§74、§85-28-42 同句）
- **问题**：词义 — `ကေဝလဿ= သတ္တဇီဝမဖက်သက်သက်သော`，nissaya 取 kevala 为「纯粹的、不夹杂有情与命我的」。译文各处都作「整个」，取的是「全部」义。两种读法传统上都有，但和本层 nissaya 的取义不同。
- **建议**：如果按 nissaya，改为「这纯粹的苦蕴」。这是跨段术语决定，要改就 §71、§74、§85 两句一起改；不改的话，在术语表登记取「整个」的依据。

## §85 句 168-85-23-27
- **问题**：句法误读 — `အသေသဝိရာဂနိရောဓာ= တပ်ခြင်းကင်းသောမဂ်ဖြင့် အကြွင်းမဲ့ ချုပ်ခြင်းကြောင့်`，nissaya 把 virāga 释为「离贪之道」，带具格 ဖြင့်，表示灭的手段：以离贪（道）而无余灭。译文「无明无余地离贪、息灭」把 virāga 和 nirodha 当成并列的两个动作，丢掉了手段关系。另外，`အဝိဇ္ဇာယ တွေဝ= အဝိဇ္ဇာ၏သာလျှင်` 的限定「唯独」也没有体现。
- **建议**：改为「但是，正是由于无明经由离贪而无余息灭，行也就息灭；」（nirodha 的译法按跨段统一方案调整）。
