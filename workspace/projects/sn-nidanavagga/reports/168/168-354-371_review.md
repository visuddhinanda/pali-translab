# Review — 168:354-371（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya 单元，这些句子单独略过，只在跨段一致性里一起看）

## 跨段一致性

- **经题与段号体例**：经题有三种写法——§354 作「六、某位婆罗门经」，§359 作「7. 生闻经」，§364 作「八　世间论者经」。段号也有三种写法——§355 作「四六、」，§360 作「47.」，§365 作「四十八　」。→ 建议统一为一种，例如经题用「六、」「七、」「八、」，段号用「46.」「47.」「48.」。
- **Sāvatthiyaṃ viharati**：§355 译「有一次，世尊住在舍卫城」，§360 与 §365 译「世尊住在舍卫城」。巴利原文和 nissaya（`သာဝတ္ထိယံ= ၌` / `ဝိဟရတိ= ၏`）都没有「有一次」。→ 建议统一为「世尊住在舍卫城」，或者三处都补「有一次」，三处保持一致即可。
- **atha kho**：§355 译「那时」，§360 与 §365 译「这时」。→ 建议统一为「这时」（出现两次）。
- **upasaṅkamitvā**：§355 译「到了以后」，§360 译「走近以后」。→ 建议统一为「来到以后」或「走近以后」。
- **anto（ayameko anto / ayaṃ dutiyo anto）**：§356、§357 用「第一个极端／第二个极端」，§361、§362 用「第一种极端／第二种极端」。nissaya 释 ayaṃ 为 `ဤအယူဝါဒသည်`（「这种见解」），用「种」更贴切。→ 建议统一为「这是一种极端」「这是第二种极端」（关于 eko 的译法见下文 §356）。
- **ubho ante anupagamma majjhena**：§357 译「不走这两个极端，而以中道」，§362 译「不落入这两种极端，依中道」，§370 译「避开这两端，以中道」。nissaya：`အနုပဂမ္မ= မကပ်ရောက်မူ၍`（不靠近、不趋向），`မဇ္ဈေန= …ဖြင့်`（具格，「以、依」）。→ 建议三处统一为「如来不趋向这两个极端，依中道说法」。
- **缘起套语**：同一套语在三经中译法各异。
  - samudayo hoti：§357 作「集起」，§362 作「生起了」，§370 作「生起」。
  - nirodho：§357 作「灭」，§362 作「止息」，§370 作「灭尽」。
  - asesavirāganirodhā：§357 作「无余地离贪而灭」，§362 作「毫无残余地离贪、止息」，§370 作「彻底离贪、灭尽」。

  → 建议全部以 §357 为准统一：「集起／灭／无余地离贪而灭」。
- **pe 省略标记**：§357 作「……乃至……」，§362 只有「……」，§363 也只有「……」，§365 与 §370 作「……（中略）……」，§360 只有「……」。→ 建议统一用一种标记。
- **Evaṃ vutte**：§358 与 §371 补了「世尊」（「世尊这样说了以后」），§363 没补（「这样说了以后」）。→ 建议统一，三处都补「世尊」。
- **bho gotama**：§356–§363 译「乔达摩先生」，§366–§371 译「尊者乔达摩」。bho 是婆罗门对平辈的称呼，「尊者」一般留给 āyasmā / bhante。→ 建议统一为「乔达摩先生」。
- **皈依套语**：
  - abhikkantaṃ：§358、§363 译「太好了」，§371 译「太殊胜了」。
  - 皈依 / 归依：§358、§363 作「皈依」，§371 作「归依」。
  - 终生 / 终身：§358、§363 作「终生」，§371 作「终身」。

  → 建议统一为「太好了」「皈依」「终生」。

## §355 句 168-355-2-9

## §356 句 168-356-19-36
- **问题**：词法——nissaya 释 `ဧ‌ကော= တစ်ခုသော`，意思是「一种、其中一个」，不是序数「第一」。`အယံ= ဤအယူဝါဒသည်` 说明主语是「这种见解」。eko 与后文的 dutiyo 对举，译成「第一个」意思上说得通，但量词「个」和 §361 的「种」不一致。
- **建议**：改为「这是一种极端」，或者保留序数改作「这是第一种极端」，两经统一用「种」。

## §357 句 168-357-20-37
- **问题**：量词——「第二个极端」与 §362「第二种极端」不一致。
- **建议**：改为「第二种极端」。

## §357 句 168-357-38-50
- **问题**：词法——`အနုပဂမ္မ= မကပ်ရောက်မူ၍` 意思是「不趋近」，「不走」稍显口语，语义上没有错。`မဇ္ဈေန= အလယ်ကျင့်စဉ် မဂ္ဂင်လမ်းဖြင့်` 是具格，「以中道」正确。主要问题在与 §362、§370 的措辞不统一。
- **建议**：统一为「如来不趋向这两个极端，依中道说法——」。

## §358 句 168-358-2-9

- **建议**：统一为「种」。

## §365 句 168-365-9-26
- **问题**：术语——nissaya 释 lokāyatiko 为 `လောကာယတကျမ်း၌ပြုအပ်ပြီး‌‌သော လေ့ကျက်ခြင်းရှိသော`，意思是「在世间论（Lokāyata）典籍上下过研习功夫的」。「世间论者」大致对得上，但 lokāyata 是罕见术语，按 style.md 首次出现要夹注巴利原词，目前全经都没有夹注。
- **建议**：在首次出现处（经题或本句）加夹注：「世间论者（lokāyatika）婆罗门」。段号「四十八　」也按统一体例改。

## §366 句 168-366-16-30
- **问题**：词法与术语——nissaya：`ဧတံ= ဤအယူဝါဒသည်`（「这种见解」，主格）；`ဇေဋ္ဌံ= ရှေးဦးစွာသော`（「最先的」）；`လောကာယတံ= ဗာလပုထုဇ္ဇန်တို့ ကြံဆအပ်သော မိစ္ဆာအယူတည်း`（「愚痴凡夫臆想出来的邪见」）。「第一种世间论」在格位和句法上没有错，但 jeṭṭha 本义是「最先的、首要的」，和后文 dutiya、tatiya、catuttha 的序数词形不同。
- **建议**：可以保留「第一种」与后文对齐，也可以译作「这是最首要的世间论」。如果 lokāyata 首次夹注放在这里，就写「世间论（lokāyata）」。

## §368 句 168-368-2-15 / 168-368-16-30
- **问题**：词法——`ဧကတ္တံ= တစ်ခုတည်းသောသဘောရှိ` 意思是「具有单一的性质」。「一切是一」意思对，但比较简略，读者不容易看出是在说「同一体性」。
- **建议**：可以改为「一切是同一体吗」「‘一切是同一体’」，与 §369 一起调整。

## §369 句 168-369-2-16 / 168-369-17-32
- **问题**：词法——`ပုထုတ္တံ= အသီးသီးသော သဘောရှိ` 意思是「具有各别的性质」。「一切是多」丢掉了「各别、各异」的意思。
- **建议**：改为「一切是各别的吗」「‘一切是各别的’」，与 §368 的「同一体」对举。

## §370 句 168-370-2-16（无 nissaya 单元，只记原文疑问）
- **问题**：原文疑问——本经列了四种世间论，但套语仍作 ubho ante（「两端」），这是原文沿用前两经的套语造成的，不改原文。译文「这两端」忠实于原文，不算错。
- **建议**：保持原文，只在本报告里记录这一点。
