## 理由

**准确性**：全段主谓宾判断无误，无漏译、无增译，`saddhā / hirī / ottappa / vīriya / paññā` 五法与 `assaddha / ahirika / anottappī / kusīta / duppañña / kodhana / upanāhī` 七项的正反对照结构完整对应，省略号（`… pe …`）位置与原文一一吻合，未擅自补全省略段。扣分集中在一处系统性问题：`ovādakā`（作教诫者的比丘）译作「教诫的比丘」，中文读来是「受到教诫的比丘」，指向与原文相反，994/997 两处对称出现，属导致误解的表达。另有 `dubbacā` 译「难以劝诫」在中文里主动/被动两读，`pāṭikaṅkhā`（可以预期）的必然语气被「只会」吸收，属轻度损耗。

**风格**：通篇现代书面汉语，无文言虚词与文言句式，`Sādhu sādhu` 译「好啊，好啊」而非「善哉善哉」，`etarahi` 译「现在的」而非「今时」，符合 style.md 第一节硬约束；译文内无 ASCII 引号，引号一律全角，JSON 安全。扣分在体例：991 把校勘异读整块塞进正文括注，993 把术语夹注写成了长释义——按 style.md 第三、四节，夹注只附巴利原词，解释性内容应走段后注释。

**一致性**：同义句式跨段高度统一（「无论来的是夜晚还是白天」「他在各种善法上都只会…」「所谓‘…的人’，这就是…」全段一致），黑分/白分的四项动词对仗工整。唯一不对称是 993 给「黑分」加了释义而 996 的「白分」没有。

## 问题清单

### 🟧 error
- `168-994-75-86`｜导致误解的表达｜片段「没有教诫的比丘」
  - 问题：`ovādakā` 是 `ovāda` 的施事名词，指「担任教诫者的比丘」。译作「没有教诫的比丘」在中文里最自然的读法是「没有受到教诫的比丘」，施受颠倒；本条与前七项（人的品德缺失）并列，实指僧团中无人堪任教诫师。
  - 建议：改为「没有教诫者比丘」或「没有担任教诫的比丘」，使施事身份显豁。

- `168-997-74-87`｜导致误解的表达｜片段「有教诫的比丘」
  - 问题：同上，`santi bhikkhū ovādakā` 指「有比丘担任教诫者」，译文读来像「比丘受到了教诫」。与 994 对称出现，须一并修正。
  - 建议：改为「有教诫者比丘」或「有担任教诫的比丘」。

### 🟨 warning
- `168-992-2-18`｜关键词语意不明确｜片段「现在的比丘们难以劝诫」
  - 问题：`dubbacā` 是「难被劝谏、不受教」。中文「比丘们难以劝诫」既可读作「比丘们难以被劝」，也可读作「比丘们难以去劝诫别人」，歧义未消解。
  - 建议：改为「现在的比丘们难以受劝」或「不听劝诫」。

- `168-992-2-18`｜代词指代不明确｜片段「具有那些让自己难以被劝诫的品性」
  - 问题：「那些」是无所指的指示词，前文并未列举任何品性，读者找不到指代对象；原文 `dovacassakaraṇehi dhammehi` 只是「造成难以受劝的诸法」，无指示成分。
  - 建议：删去「那些」，作「具有让自己难以受劝的种种品性」。

- `168-991-2-18`｜整句逻辑表达不规范｜片段「〔异读：舍卫城／在那里说了这番话（锡兰本）〕」
  - 问题：校勘异读整块写进正文，打断叙事句；且括号用〔〕，与 style.md 第五节「一律中文全角标点（）」不符。异读属版本信息，应出正文。
  - 建议：正文只留「世尊住在王舍城的竹林。」，异读移至段后注释或脚注。

### 🟦 suggestion
- `168-993-2-28`｜不常用术语编写注释或者百科｜片段「黑分（kāḷapakkha，即月亮由盈转亏的半个月）」
  - 问题：按 style.md 第三节，夹注只附巴利原词，释义性文字应作段后小字注释；此处把整条百科塞进圆括号，正文被撑断。
  - 建议：正文作「黑分（kāḷapakkha）」，释义移入注释。

- `168-996-2-29`｜语言风格不统一｜片段「白分（juṇhapakkha）」
  - 问题：与 993 的「黑分」不对称——一个给了释义，一个没有。两词首次出现地位相同，处理应一致。
  - 建议：随上一条一并调整，两处同格式，释义同归注释。

- `168-991-45-52`｜语言风格不统一｜片段「迦叶，你为比丘们讲说佛法。」
  - 问题：与紧邻的前句「迦叶，你教诫比丘们吧；」同为祈使句（`ovada` / `karohi`），前句有语气词「吧」，此句没有，读来由请求滑成陈述。
  - 建议：补语气词，作「迦叶，你为比丘们讲说佛法吧。」

- `168-991-53-63`｜语言表达不够流畅｜片段「教诫比丘们的，要么是我，要么是你」
  - 问题：`ovadeyyaṃ` 是愿望式，原意「该由我或你来教诫比丘们」，译成判断式的分裂句后，劝请语气变成了事实陈述。
  - 建议：改为「迦叶，比丘们应当由我来教诫，或者由你来教诫；」。

- `168-992-19-78`｜语言表达不够流畅｜片段「都只会衰退」
  - 问题：`pāṭikaṅkhā`（可以预期、必定可期）的「预期」语义被「只会」吸收，语气略平。全段五处同构句式（992/993/995/996/998）同此。
  - 建议：可作「都只能预期衰退」，若维持现译则五处保持统一即可，不必逐处改。

- `168-993-2-28`｜语言表达不够流畅｜片段「月亮无论来的是夜晚还是白天」
  - 问题：`candassa` 是属格（「就月亮而言」），译文让「月亮」直接充当「来」的大主语，字面上像是月亮在来。
  - 建议：改为「对月亮来说，无论来的是夜晚还是白天」。

- `168-997-2-13`｜语言表达不够流畅｜片段「这就是不衰退」
  - 问题：`aparihāna` 译「不衰退」准确但生硬，且 997 全段八处重复，累积读感滞涩。
  - 建议：可考虑「这就是不退失」，全段八处统一替换；若维持现译亦可接受。
