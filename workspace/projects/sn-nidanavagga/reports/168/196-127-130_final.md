## 理由

**基准缺失说明（影响信心）**：本次评估只拿到巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未注入**。本层是复注（ṭīkā），其黑体被解释词全部引自义注，缺义注就无法核对「被解释词与父层逐字同译」这条硬约束，也无法确认释义取向是否与义注相符。以下判断只依据巴利原文形态与上下文推理，信心相应下调。凡涉及黑体词译法的条目，请在 revise 时对照义注实际用词再定。

**准确性**：长难句（`196-130-89-123`、`196-130-132-152`、`196-130-230-242`、`196-130-243-254` 等破斥有我论的整段推理）处理得相当扎实，属格链、同位关系、条件—结论结构都还原到位，`tassa kāraṇassa … kammassa upacitattā`、`uppādavināsavantīhi avatthāhi anaññassa attano` 这类嵌套属格没有误读。扣分集中在**词条式短句**上：这类句子是「黑体被解释词 + 释义」结构，一旦黑体词译名与紧随的释义对不上，读者就断了理解链条。`okāsa` 译「时间」而释义作「余地」、`antaraghara` 译「城里」而释义作「房屋内部／聚落之内」，两处都是自相矛盾；`desa` 与 `kāraṇa` 两个不同巴利词同译作「事」，词源解析（nirutti）的层次被抹平。另有 `196-130-333-343` 把未加黑体的 `laddhiyā` 当成词条来释，改变了原句句法。

**风格**：现代书面汉语基调达成，无「此中／故为／彼等」类文言腔，句子读来自然，破折号插入语与设问句的运用也贴合论辩文体。残留少量「之」作文言虚词（「族姓之名」「无益之事」），按 style.md 第一节禁例表须改。标点全角、无 ASCII 引号，JSON 安全无虞。

**一致性**：主要问题是**巴利夹注给得随意**——`mā`、`bhaṇi`、`assa`、`ayaṃ`、`jāti` 这类非术语加了夹注，而 `Liṅgena acelako`、`Nāmena`、`Yadākaṅkhasi`、`Sodhento`、`Parato` 等同样是黑体词条却不加，同一段内两套做法并行。此外 `assa` 与 `ayaṃ` 两个相邻词条都译作「他」，指代对象一为裸行者、一为世尊，读者无从分辨。术语层面 `nipāta`（不变词）、`kiriyāpada`（动词）、`vibhattivipariṇāma`（变换词尾）译法稳定，未见冲突。

## 问题清单

### 🟧 error

- `196-128-50-53`｜错译（词义）｜片段「**时间**（okāsa）」
  - 问题：本句自身把 okāsa 释为 `avasaṃsandanapadesaṃ`（可容纳、可插入的余地），是空间义；译作「时间」与紧接的释义直接冲突，读者会以为在解释一个时间概念。复注此处正是要展示「空间→时机」的引申，译「时间」把引申链条掐断，下句「时机、时候」也就失去着落。
  - 建议：黑体词改译「机会」或「余地」（视义注实际用词而定），使「机会：就是可以容纳、可以插入的那点余地」与下句「因此说时机、时候」构成完整推演。

- `196-128-63-65`｜错译（词义）｜片段「**城里**（antaraghara）」
  - 问题：antaraghara 指「屋内／家内」，本句释义即 `antonivesanaṃ`（房屋内部）；译作「城里」与释义不符。原文语境（比丘于 antaraghara 行走）与「城」无关。
  - 建议：改译「屋内」或「人家里」，与「房屋内部」呼应。

- `196-128-66-72`｜错译（词义）｜片段「所以叫做**城里**，也就是聚落之内」
  - 问题：同上一条的同一误译。本句是 antaraghara 的词源解析（`antare gharāni etassa`：其中有房屋者），译名「城里」既接不住「它里面有房屋」，也接不住「聚落之内」。
  - 建议：与 `196-128-63-65` 一并统一译名。

- `196-130-333-343`｜错译（修饰关系）｜片段「这里说的“主张”，指的是」
  - 问题：`Laddhiyā` 在原文中未加黑体，不是被解释词条，而是修饰 `micchāgahaṇassa` 的属格/具格（依其主张而起的邪执）。译文把它当作词条来释义（「这里说的‘主张’，指的是……」），凭空造出一个词条，并把「主张」与「错误执取」拉成同位关系，改变了原句句法。
  - 建议：改为不设词条的整句译法，如「这是为了遮止依着（他的）主张而生起的‘苦是自己造作的’这种错误执取」。

### 🟨 warning

- `196-128-44-49`｜关键词语意不明确｜片段「**事**（kāraṇa，即原因）」
  - 问题：上一句已把 `desa` 译作「事」，本句黑体 `kāraṇa` 又译「事」，两个不同巴利词共用一个汉语词，还要靠括注「即原因」来补救，读者会误以为二者同义。黑体词是引自义注的被解释词，译名须能独立成立。
  - 建议：`kāraṇa` 直接译「原因」或「缘由」，去掉「即原因」这种自我解释的括注；`desa` 的译名另行斟酌（须核对义注用词）。

- `196-130-13-19`｜关键词语意不明确｜片段「这里的“讲”，意思就是说」
  - 问题：原文 `kathesīti attho` 是用 `kathesi` 来释 `bhaṇi`。汉语里「讲」与「说」完全同义，译成「‘讲’的意思就是说」等于什么也没解释，读者只会觉得句子在同义反复。
  - 建议：或将两个词译得可区分（如黑体作「说」、释义作「告诉、讲述」），或改用括注巴利原词的方式点明是 bhaṇi 与 kathesi 两个动词的对释。

- `196-130-304-310`｜错译（词性／修饰关系）｜片段「意思是指他接下来要说的那些话」
  - 问题：`evaṃ vakkhamāno` 是现在分词主格，回答的是「为何这样说」——因为他正打算这样说下去。译文把分词处理成宾语（「要说的那些话」），把因果性的语法注解变成了指代性说明。
  - 建议：改为「意思是：因为他接下来正要这样说」。

- `196-130-315-320`｜代词指代不明确｜片段「**他**（ayaṃ）」
  - 问题：紧邻的 `196-130-311-314` 已把 `assa` 译作「他」（指裸行者），本句 `ayaṃ` 又译「他」（指世尊）。两个相邻词条译名相同而所指相反，读者无法分辨，正是复注词条注解最忌讳的情形。
  - 建议：`ayaṃ` 改译「这位」或「他这个人」，与前条的「他」拉开区别。

- `196-128-22-27`｜文言语体｜片段「按族姓之名而说」
  - 问题：「之」作文言虚词，属 style.md 第一节禁例。
  - 建议：改「按族姓的名字来说」。

- `196-130-89-123`｜文言语体｜片段「劝人远离无益之事、趣向有益之事的教诫」
  - 问题：「无益之事」「有益之事」两处「之」为文言虚词，同前条禁例。
  - 建议：改「劝人远离没有益处的事、趣向有益的事的教诫」，或「劝人舍离有害的、趣向有利的教诫」。

- `196-129-58-78`｜错译（词义）｜片段「再过这么久」
  - 问题：`ettakena kālena` 是具格表经历的时长（经过这么长时间／在这么久之内），译文的「再过」带出了未来推移义，与「等待众生智慧成熟」的语境所需的「经历了这么久」不合。
  - 建议：改「经过这么长时间」。

### 🟦 suggestion

- `196-128-92-109`｜语言风格不统一／存疑处理｜片段「虽然我拒绝了三次你还是要问」
  - 问题：`paṭikkhipantopi` 是现在分词主格，形态上与 `pucchasi` 同主语（即「你」）；译文把主语换成了「我」。语义结果（佛三次制止、迦叶仍问）虽相同，但改换分词主语需要依据。缺义注与 nissaya，无法判定是否为原文的独立主格式松散用法。
  - 建议：保留现读法可行，但应压低该句 confidence；若义注支持同主语读法，改为「你即使被拒绝了三次还是要问」。

- `196-129-26-45`｜语言表达不够流畅｜片段「**那么……为什么**」
  - 问题：黑体引文中使用省略号，在正文里易被误读为残留的工作标记或引文残缺。
  - 建议：核对义注原句后补全引文首语，或改为「**为什么**」并在句中交代「那么」的语气。

- `196-130-7-12`｜语言表达不够流畅｜片段「把省略的这个动词说了出来」
  - 问题：「省略的」是增译，原文 `punavacanavasena kiriyāpadaṃ vadati` 只说「以复说的方式说出动词」，未言省略。虽合上下文推断，但把推断写进正文会掩盖原文的简略。
  - 建议：改「以复说的方式说出了这个动词」，推断部分若确有必要可作脚注。

- `196-130-282-293`｜语言表达不够流畅｜片段「无缘无故地、偶然地，不凭任何原因」
  - 问题：「无缘无故」与「不凭任何原因」语义重复，句子显得拖沓。原文 `adhicca yadicchāya` 与 `kiñci kāraṇaṃ … vinā` 分属两层（副词性描述 + 否定条件），译文把两层压成同义并列。
  - 建议：改「偶然地、随意地生起，既没有任何原因，也没有任何在先的东西」。
