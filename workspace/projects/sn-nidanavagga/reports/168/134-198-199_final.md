## 理由

**基准可用性（先说明降级）**：本次评估对象本身就是义注层（book 134, `3._Upanisasuttavaṇṇanā`），注入数据只有巴利原文与译文，**未提供 nissaya，也未提供复注（ṭīkā）**。因此词级格位核对与"释义标准"两条基准都缺位，只能依巴利原文本身的句法与《清净道论》系统的通行术语传统判断。信心指数据此下调；`savikārā khandhajāti`（198-138-143）、`kusumbhagāminiyo`（199-43-47）这类需复注定夺的点，结论保留余地。

**准确性**：句法判断整体可靠，主谓宾与格关系没有发现误读。缘起逆推链（离贪←厌离←如实知见←定←乐←轻安←喜←欣悦←信←苦←生←有）的方向、`paccayo hoti` 的"是…的缘"归属逐句正确，没有把缘与果颠倒——这是本段最容易出错的地方。四组智名（怖畏现起智 / 过患随观智 / 欲解脱智 / 行舍智；诸行分别智 / 度疑智 / 思惟智 / 道非道智）取的都是通行汉译。199 段地形词的层级（山涧→干裂的地面→细水沟→小水洼→大水洼→小河→大河）与最后的比喻配当（无明=山、诸行=云、识等轮转=山涧等、解脱=大海）均正确。

个别可议但不扣分的取舍：`upanisā` 译作"亲依止"，实为 `upanissaya`（亲依止缘）的术语，严格说 `upanisā` 只是"依缘 / 近因"；但汉译传统（经名"亲依止经"）如此，属有据的选择。`kusumbha`（199-43-47）与 `kusobbha`（199-48-51）是两个词，译文都作"小水洼"；从经文水流次第看这种归并是自洽的，不算错译，但需要复注确认。

**风格**：绝大部分是干净的现代书面汉语，"因为它是…的缘""应当把…看作…"这类句式对读者友好，没有出现"此中""故为""彼等"一类文言腔。扣分点集中在"轮回之苦"这一处的文言属格"之"——同段其他并列位置（"强盛的喜""微弱的喜""诸蕴的生起"）一律用"的"，此处独用"之"，既违 `style.md` 第一节禁例，也造成同构句式内部不齐。另有引号层级不规范。

**一致性**：被解释词与释文之间的对应稳定，199 段词条（山涧 / 干裂的地面 / 细水沟 / 小水洼 / 大水洼 / 小河 / 大河）前后完全一致，`kandara` 在 199-78-86 复现时仍作"山涧"，这一点做得好。失分处是同一巴利成分的汉译摆动：`balava-` 在"强力观"与"强盛的喜"之间不统一；`saṅkhārā` 与 `abhisaṅkhārā` 在相邻两句里同作"诸行"（虽有夹注缓解）。释义引导语在"，是指…"与"，是…"之间交替，属自然变化，不计为问题。

## 问题清单

### 🟨 warning

- `134-198-129-132`｜文言语体｜片段「轮回之苦」
  - 问题：文言属格"之"，与同段并列句一律用"的"（"强盛的喜""微弱的喜"）不齐。
  - 建议：改为"轮回的苦"或"轮回苦"。

- `134-198-144-149`｜文言语体｜片段「轮回之苦的缘」
  - 问题：同上，"之"与后接的"的"在一句内并用，读感夹生。
  - 建议：改为"轮回的苦的缘"或重写为"因为它是轮回苦生起的缘"。

- `134-199-6-34`｜标点符号使用错误｜片段「被那名为‘kaṃ’（意为水）的水冲开」
  - 问题：同一句内，被引称的名"kaṃ"用全角单引号，而"山腰""河曲"用全角双引号，同类成分标点不一；且单引号按规范只用于双引号内的嵌套层。
  - 建议：统一改为“kaṃ”。

- `134-198-37-41`｜标点符号使用错误｜片段「被称为‘如其本性而了知’的那种见」
  - 问题：顶层引用使用了全角单引号，应为双引号。
  - 建议：改为“如其本性而了知”。

### 🟦 suggestion

- `134-198-6-16`｜语言表达不够流畅｜片段「各种烦恼褪落」
  - 问题："褪落"不是常用搭配，`virājento`（使褪去、令离染）用此词略生硬。
  - 建议：改为"使各种烦恼消退"或"令各种烦恼褪去"。

- `134-198-37-41`｜语言风格不统一｜片段「如其本性而了知」
  - 问题：`sabhāva` 通行汉译为"自性"，此处作"本性"，与该系统其他术语的译名传统略有出入。
  - 建议：考虑统一为"如其自性而了知"，并登记进 `terms.md`。

- `134-198-98-101`｜语言风格不统一｜片段「强盛的喜」
  - 问题：`balava-` 在 198-21-24 译作"强力"（强力观），此处译作"强盛"，同一构词成分两种处理。
  - 建议：择一固定，或明确"强力观"为固定术语、"强盛的喜"为一般描述，写进术语表备案。

- `134-199-2-5`｜语言表达不够流畅｜片段「大雨点的」
  - 问题：词条译文以悬空的"的"结尾，脱离原句（修饰 `deve`）后读者看不出所修饰对象。
  - 建议：改为"**下着大雨点**，是指雨点粗大"或加括注说明所修饰的是"雨"。

- `134-199-78-86`｜语言风格不统一｜片段「诸行（abhisaṅkhāra）」
  - 问题：上一句 `saṅkhārā` 已译作"诸行"，此处 `abhisaṅkhārā` 同译"诸行"，两个巴利词共用一个汉语词，仅靠夹注区分。
  - 建议：保留夹注的同时考虑作"诸造作（abhisaṅkhāra）"，或在段末小字注中说明二者所指相同。
