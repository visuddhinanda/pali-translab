# Review — 168:1086-1095（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 复核）

## 跨段一致性
- **sekhaṃ appattamānasaṃ**：§1087 译“心愿未满的有学”，§1090 译“心愿尚未成就的有学（sekha）”。建议统一，并按 nissaya 改为“还没有证得阿罗汉果的有学”（依据见 §1087 条）。另外，sekha 的巴利夹注应放在本 chunk 首次出现处（§1087），不要放在 §1090。
- **anupāpuṇātu**：§1087 译“找上”，§1090 译“降临到……身上”。建议统一为“找上”。
- **lābhasakkārasiloka 首次夹注**：本 chunk 首次出现在 §1087，那里没有夹注；夹注却放在 §1090。建议移到 §1087，§1090 删去。
- **pe 的译法**：§1087、§1090 用“（中略）”，§1093、§1095 用“乃至”。建议统一为一种。
- **段号格式**：§1090 作“一六三、”，§1087、§1093、§1095 作阿拉伯数字“162. / 164. / 165.”。建议统一为阿拉伯数字。
- **Sāvatthiyaṃ viharati 的主语**：§1087、§1093 作“（世尊）住在”，§1090 不补主语，§1095 作“世尊住在”，没有括号。建议统一为“（世尊）住在”。
- **adhigamāya 句尾**：§1087 作“对于证得（无上的安稳）是障碍”，§1090、§1095 作“妨碍证得无上安稳”，§1093 作“障碍（证得）无上的安稳”。这四处是同一重复句式，建议统一为“妨碍证得无上的安稳”。
- **sikkhitabbaṃ**：§1088、§1093 作“应当这样学习”，§1091、§1095 作“应当这样学”。建议统一为“学习”。
- **结经语**：§1088、§1091、§1093 作“第六经／第七经／第八经”，§1095 作“第九。”，漏了“经”。必改，统一为“第九经。”
- **adhivacana 句式**：§1088 作“‘雷电轮’是……的代称”，§1091 作“所谓‘矛’，正是……的代称”。这是同一句式（nissaya 两处都作 `…န္တိ ဧတံ= …ဟူသော ဤအမည်သည်` 加 `အဓိဝစနံ= အမည်တည်း`），建议统一为“比丘们，‘××’是利养、恭敬、名声的代称。”
- **abhibhūto**：§1093 作“压倒”，§1095 作“所征服”。nissaya 两处都是 `နှိပ်စက်အပ်သည်` 被压制、被逼迫。建议统一为“压倒”。
- **idhekacco bhikkhu**：§1093 作“在这里，有的比丘”，§1095 作“这里有一类比丘”。建议统一为“在这里，有的比丘”。

## §1087 句 168-1087-2-222
- **问题**：词法／取义——appattamānasaṃ = `အရဟတ္တဖိုလ်သို့ မရောက်သေးသော`（还没有到达阿罗汉果的）。nissaya 明确指出“所未得的”是阿罗汉果，“心愿未满”太泛，也看不出所指。
- **建议**：改为“还没有证得阿罗汉果的有学”。
- **问题**：句法——nissaya 的读法是：asanivicakkaṃ 作主格（`မိုးကြိုးစက်သည်`），kaṃ 作趋向（`အဘယ်ပုဂ္ဂိုလ်သို့` 到哪个人那里），āgacchatu = `လာရောက်နိုင်သနည်း` 能来到吗。按这个读法，雷电轮是“来到”谁那里，不是“击中”谁。“击中”属于意译，可以接受；但主语和格位应和 nissaya 一致。
- **建议**：可改为“比丘们，雷电轮会落到谁身上呢？”。如果保留“击中”，就不改。
- **问题**：存疑处混入正文——〔编者按〕之后的“底本此按语重出两次，内容相同，仅第二处作 taṃ sekhaṃ，第一处作 kaṃ sekhaṃ”是译者的说明，不是底本按语的译文。而且“内容相同”不准确：第二处还作 tariya、āgacchatūtica。
- **建议**：从译文删去这句。底本重出的情况写进审稿报告，或改用脚注体例处理。

## §1090 句 168-1090-24-104
- **问题**：句法误读（必改）。nissaya：kaṃ = `အဘယ်ပုဂ္ဂိုလ်ကို`（哪个人，宾格·疑问）；visallena / diddhagatena sallena = `အဆိပ်လူးသောမြှားဖြင့်`（用涂了毒的箭，具格）；vijjhatu = `ပစ်ဖောက်နိုင်သနည်း`（能射穿吗？疑问）。这一句和 §1087 是平行的疑问句：“要用毒箭射中谁？利养等要找上哪个有学？”。译文却改成“宁可……也不愿……”的比较、取舍句式。疑问代词 kaṃ 被译成泛指的“人”，句子结构和语气都错了，也和 §1087 不对应。
- **建议**：改为“比丘们，要用涂了毒的毒箭射中谁呢？利养、恭敬、名声要找上哪一个还没有证得阿罗汉果的有学呢？”，和 §1087 的句式对齐。
- **问题**：冗译——nissaya 说明 diddhagatena 只是修饰语“涂了毒的”（`ဂတအနက်မဲ့`，gata 没有实义），pali 再说一遍是为了把复合词 visalla 讲明白。“涂了毒的、抹上毒药的矛”重复了同一个意思。
- **建议**：合为一个修饰语，例如“涂了毒的毒箭”或“涂了毒的矛”。
- **说明**：nissaya 把 salla 译作“箭”（`မြှား`），但它的注里提到义注把 salla 解释为 satti（矛）。所以译文用“矛”（§1090、§1091）有依据，不用改，前后保持一致就行。

## §1093 句 168-1093-63-104
- **问题**：原文疑问／音译不合——pali 正文作 ukkaṇḍakena，译文音译为 ukkaṇṭaka（ṇṭ），是跟了 nissaya 的拼法 `ဥက္ကဏ္ဋက`。音译和所据正文不一致。
- **建议**：音译跟随正文，作 ukkaṇḍaka。nissaya 的异释把它解为疥癣（`ခွေးဝဲစားရောဂါ`），按罕见术语首次出现的体例，可以附简注：“一种名叫 ukkaṇḍaka（疥癣）的病”。

## §1095 句 168-1095-111-121
- **问题**：词义——anuddhaṃseti = `ပျက်စီးစေ၏`（使败坏、使毁坏）。“扰乱”程度偏轻。tassa 作属格，修饰 cittaṃ（他的心），译文的处理是对的。
- **建议**：改为“贪欲就败坏了他的心”。

## §1095 句 168-1095-122-128
- **问题**：同上，rāgānuddhaṃsitena = `ရာဂသည်ဖျက်ဆီးအပ်သော`（被贪欲败坏的）。
- **建议**：改为“他的心被贪欲败坏”，和上一句保持一致。

## §1095 句 168-1095-169-170
- **问题**：漏译。Navamaṃ = `ကိုးခုမြောက်သောသုတ်တည်း`（第九经），译文漏了“经”。
- **建议**：改为“第九经。”
