# Review — 168:405-417（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（405、406、407、408、409、410、411、412、414 末两句、415、416 首句、417 末句有 nissaya；其余句无 nissaya，不出单句意见）

## 跨段一致性

- **taṇhā**：§406–409（第2经）、§416–417（第4经）译「贪爱」，§411–414（第3经）译「渴爱」 → 三经统一为一个译法（建议「贪爱」，本 chunk 多数用它）。
- **upādāna（譬喻中作燃料）**：§407、§409、§416、§417 译「燃料」，§412-26-37 译「以此为取」，§414-26-41 译「先前的取」 → 统一为「燃料」。nissaya 两处都释作 `လောင်စာ`（燃料）：`တဒုပါဒါနော= ထိုဆီ, မီးစာဟူသော လောင်စာရှိသည်ဖြစ်၍`，`ဥပါဒါနဿ= လောင်စာ၏`。
- **assādānupassino viharato**：§406/§407「不断随观它们的甘味」，§411/§412「随观乐味而住的人」，§416「随观可爱味而住」 → 句式和 assāda 的译法都要统一。nissaya `အဿာဒါနုပဿိနော= သာယာဖွယ်ဟု အဖန်ဖန်ရှုလေ့ရှိသည်ဖြစ်၍`（惯于反复视为可享受的）。建议统一为「甘味」，句式取一种。
- **ādīnavānupassino viharato**：§408/§409「不断随观它们的过患」，§413/§414/§417「随观过患而住」 → 与上一条同步统一。
- **saṃyojana / saṃyojaniya**：经题 §410「结缚经」、§415「第二结经」；正文 §411/§412「会造成结缚的诸法」，§416/§417「能引生结（saṃyojana）的诸法」 → 统一。nissaya `သံယောဇဉ်တို့၏ အစီးအပွါး (အကြောင်းအာရုံ) ဖြစ်ကုန်သော`（作为结的助缘／所缘的），句式与 upādāniyesu 完全平行，建议照 §406「能引生取的诸法」改为「能引生结的诸法」，经题配套作「结经／第二结经」。
- **缘起顺观句式**：§406「由于有贪爱，就有取」，§411/§412「以渴爱为缘而有取」，§416「以贪爱为缘就有取」 → 统一一种句式。
- **bhava**：§406「就有有」，§411「而有‘有’（bhava）」，§412「而有‘有’」，§413「‘有’也灭」，§408「有就灭」 → 加不加引号、首次夹注放在哪里，要统一（首次夹注应放在 §406）。
- **还灭句式**：§408「由于贪爱灭，取就灭」，§413/§414「由于渴爱灭，取也灭」，§417「贪爱息灭，取就息灭」 → 统一。
- **samudayo hoti**：§406/§407「就生起了」，§411–§416「就集起了／就这样集起」 → 统一（建议「集起」）。
- **nirodho hoti / nirujjhati**：「灭去」（§408、§409）、「灭尽」（§413、§414）、「息灭」（§417） → 统一。
- **vaṭṭiṃ upasaṃhareyya**：§412、§414「续上灯芯」，§416、§417「拨整灯芯」 → 统一为「续上灯芯」。nissaya `ဥပသံဟရေယျ= ကပ်ဆောင်တပ်ထည့်ရာ၏`（拿过来装进去）是添入，不是拨整。
- **na kālena kālaṃ**：§409、§414「不时时添放／添油」，§417 同 → 「不时时」容易被读成「不时（=时常）+ 时」，意思正好反了。统一改为「并不时时」或「不再按时」。
- **经号**：§406「五二」，§411「五三」，§416「五十四」 → 统一体例。
- **Sāvatthiyaṃ viharati 的主语**：§406 补了「（世尊）」，§411、§416 没补 → 统一。
- **经末计数**：§409「第二。」，§414「第三经完。」，§417「第四经。」 → nissaya `ဒုတိယံ= နှစ်ခုမြောက်သောသုတ်တည်း`（第二部经），统一为「第二经。／第三经。／第四经。」。

## §407 句 168-407-2-25
- **问题**：格 — nissaya `ဒသန္နံ ဝါ ကဋ္ဌဝါဟာနံ= ဆယ်ဝါဟကုန်သော ထင်းတို့၏၎င်း`，用的是属格 `၏`，修饰主语 `မဟာအဂ္ဂိက္ခန္ဓော= ကြီးလှစွာသော မီးပုံသည်`，意思是「十车柴的（所成的）大火堆」。译文改成了具格「用…烧着」。意思大体不差，但车数说的是火堆的规模，不是燃烧的工具。
- **建议**：「譬如十车柴、二十车柴、三十车柴或四十车柴堆成的一大堆火在燃烧。」§409-2-21 同步改。

## §407 句 168-407-26-44
- **问题**：处格所指 — nissaya `တတြ= ထိုမီးပုံကြီး၌`（在那大火堆上），tatra 指的是火堆，不是地点。「在那里」指代不明。
- **建议**：「有一个人时时往那堆火里添放干草……」。§409-22-43 同改。

## §409 句 168-409-22-43
- **问题**：歧义（必改） — 「不时时添放」可以读成「不时（时常）添放」，与 nissaya `န ပက္ခိပေယျ= မထည့်ရာ`（不添入）的否定意思相反。tatra 的指代问题同 §407。
- **建议**：「有一个人并不时时往那堆火里添放干草，也不添放干牛粪，也不添放干柴。」

## §412 句 168-412-17-25
- **问题**：处格所指 — nissaya `တတြ= ထိုဆီမီး၌`（在那油灯上），同 §407。
- **建议**：「有个人时时给那盏灯添油、续上灯芯。」

## §412 句 168-412-26-37
- **问题**：误译（必改） — nissaya `တဒုပါဒါနော= ထိုဆီ, မီးစာဟူသော လောင်စာရှိသည်ဖြစ်၍`（以那油、灯芯为燃料）。在譬喻里 upādāna 是「燃料」，译「以此为取」是把法义术语错套进了譬喻，也和 §407、§416 的「燃料」不一致。
- **建议**：「以此为食、以此为燃料」。另外，tadāhāro 的 nissaya 是 `ထိုဆီ, မီးစာဟူသော အကြောင်း`，「此」实指油和灯芯，可以考虑译成「以这些为食」，与 §407 的「以这些为食」一致。

## §414 句 168-414-54-67
- **问题**：无词法问题；只有跨段术语不一致（渴爱／灭尽），见上节。
- **建议**：随跨段统一一并改。

## §416 句 168-416-2-24
- **问题**：nissaya 注明本经与前经相同，`(ဤသုတ်သည် ရှေးသုတ်နှင့်တူပြီ…)`。译文却把 telappadīpo jhāyeyya 译作「油灯依靠油、依靠灯芯而燃烧」，与 §412/§414 的「一盏油灯燃烧着」句式不同；同一段经文在相邻两经里应当同译。
- **建议**：照 §412-2-16 统一为「比丘们，就好比依靠油、依靠灯芯，一盏油灯燃烧着。」§417-2-15 同步改。
