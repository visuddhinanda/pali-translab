# Review — 168:1215-1232（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- sammappaññāya：§1216 译「用正慧」，§1218、§1219 译「用正确的智慧」 → 建议统一为「用正慧」。依据：这是同一套经文程式，nissaya 的释义也一致（`သမ္မပ္ပညာယ= ဝိပဿာနှင့်တကွသော မဂ်ပညာဖြင့်`）。
- passati / disvā 的「看」：§1216 译「如实地这样看见」，§1218、§1219 译「如实地这样看到」 → 两段的程式相同，统一为「看见」。
- jānato passato：§1216 译「怎样知道、怎样看见」「这样知道、这样看见」，§1218、§1219 译「怎样知、怎样见」「这样知、这样见」 → 统一用双音节的「知道、看见」，这样也合乎 style.md「能用双音节就不用单音节」的要求。
- 「无论是……的或……的」（§1216）和「不论是……还是……的」（§1218、§1219）：这两处是同一个 atītānāgatapaccuppannaṃ … santike vā 程式，句式应统一。建议都用「无论是……或……」。
- ahaṅkāramamaṅkāramāna-：§1216 译「我执、我所执与慢」，§1218、§1219 译「我执、我所执和慢」 → 统一用「和」。
- upasaṅkamitvā：§1216 译「来到之后」，§1218、§1229、§1230 译「到了之后」 → 统一为「到了之后」。
- abhivādetvā：§1216、§1218 译「礼敬」，§1230 译「顶礼」 → 统一为「礼敬」。
- ekamantaṃ nisīdi / nisinno：§1216、§1218 译「在一边坐下」「坐在一边的」，§1230 译「在一旁坐下」「在一旁坐下后」 → 统一为「一边」。§1230-27-35 的句式也应改回「坐在一边的勒叉那尊者对大目犍连尊者说」。
- āyasmā + 人名：§1216、§1218 译「尊者罗睺罗」（尊者在前），§1229–1231 译「勒叉那尊者」「大目犍连尊者」（尊者在后） → 本 chunk 内称谓的语序要统一。建议都用「尊者某某」，与 nissaya 的 `အရှင်လက္ခဏ`（尊者在前）语序一致。
- atha kho：§1216、§1218 译「那时」，§1229-42 译「于是」，§1229-95、§1230 译「后来」 → 这个叙事连接词的译法前后不一致。建议：时间推进处统一用「于是」，§1216、§1218 段首的「那时」可以保留。

## §1216 句 168-1216-31-54
- **问题**：格与句法（轻微）— nissaya 的主解把三项拆成三个并列处格：`ဣမသ္မိံ ကာယေ= ဤမိမိကိုယ််၌၎င်း`（自己这个有识之身）／`ဗဟိဒ္ဓါယ= ပြင်ပ…သူတစ်ပါး၏ကိုယ်၌၎င်း`（外在他人之身）／`သဗ္ဗနိမိတ္တေသု= …အာရုံတို့၌`（一切所缘）。译文「外在的一切相」把 bahiddhā 当作 nimitta 的修饰语，用的是 nissaya 末尾的「တစ်နည်းသမ္ဗန်」异释（`ဗဟိဒ္ဓါ စ သဗ္ဗနိမိတ္တေသု= ပြင်ပအလုံးစုံ…တို့၌၎င်း`）。
- **建议**：采用异释可以接受，但要和 §1218、§1219 保持一致（目前三段一致）。另外，「我执、我所执与慢随眠」容易读成只有「慢」是随眠。nissaya 把 `အဟင်္ကာရ မမင်္ကာရ မာနာနုသယာ= ဒိဋ္ဌိတဏှာမာနတို့သည်` 作为整体主格，三者都是随眠。建议改为「我执、我所执、我慢这些随眠（anusaya）」或「我执、我所执与慢的随眠」。

## §1230 句 168-1230-36-47
- **问题**：取义／格与句法 — idha 的 nissaya 是处格 `ဣဓ= ဤရာဇဂြိုဟ်ပြည်၌`（在这王舍城），译文译成时间副词「刚才」。
- **建议**：改为「大目犍连尊者在这里从灵鹫山下来的时候，在某个地方露出了微笑。」

## §1231 句 168-1231-2-15
- **问题**：漏译／补出成分 — 句首 Idhāhaṃ 的 idha（nissaya `ဣဓ= ၌`，处格）没有译出。另外，aṭṭhikasaṅkhalikaṃ 的 nissaya 是 `အရိုးဆက်ပြိတ္တာကို`（骨锁状的饿鬼），指一个众生，不是一具骨头。vehāsaṃ gacchantiṃ 的 nissaya 是 `ကောင်းကင်၌ သွားသည်ကို`（在空中行进），「飘行」带了原文没有的意味。
- **建议**：「学友，我在这里从灵鹫山下来的时候，看见一个骨锁状的众生在空中行进。」如果要保留「骨架」的意象，至少要让读者看出它是一个众生，这样才能接上后文的「这样的众生」。

## §1231 句 168-1231-16-44
- **问题**：格与句法 — nissaya 的主解把 phāsuḷantarikāhi 作「从格形式表处格义」（`ဖာသုဠန္တရိကာဟိ= နံကြားတို့၌`，在肋骨之间）。只有异释（vituḍenti 读法）才取从格义（`နံရိုးကြားတို့မှ`），配合「刺穿后飞过」。译文「从它的肋骨之间啄它」把主解的动词和异释的从格混在一起了。
- **问题**：词义 — 三个动词的 nissaya 分别是 vitudenti `နှိပ်စက်`（刺、折磨），vitacchenti `ဆိတ်ဆွဲ`（揪扯），virājenti `ဖောက်ခွဲ`（破开、撕裂）。译文「啄、撕、扯」把后两个译反了。kulalā 的 nissaya 是 `စွန်ရဲ`（鸢），译文作「鹰」。
- **建议**：「秃鹫、乌鸦和鸢紧追着它不放，在它的肋骨之间啄刺、揪扯、撕裂。」

## §1232 句 168-1232-8-17
- **问题**：取义 — cakkhubhūtā 的 nissaya 是 `စက္ခုရှိကြကုန်သည်ဖြစ်၍`（成为具（天）眼者），讲的是「具有」，不是「生起」。nissaya 还补出了 `တသ္မာ= ကြောင့်`，和下句的 `ယသ္မာ` 呼应，构成「因为……所以……」的因果框架。
- **建议**：「比丘们，弟子们真是具眼而住；」。「（天）眼」只作译者参考，不进正文。

## §1232 句 168-1232-18-38
- **问题**：取义 — ñāṇabhūtā 的问题同上（`ဉာဏ်ရှိကြကုန်သည်ဖြစ်၍`，具智者），「生起了智」应改为「具智」。evarūpaṃ 的 nissaya 是 `ဤသို့သဘောရှိသောသတ္တဝါကို`（这样的众生，宾格），译文泛化成了「这样的事」。
- **建议**：「比丘们，弟子们真是具智而住，因为弟子竟能知道、看到或亲自见证这样的众生。」sakkhiṃ karissati 的 nissaya 是 `မျက်မြင်သက်သေပြု`（作目睹的见证），所以「亲自证实」改为「亲自见证」更贴切。

## §1232 句 168-1232-101-132
- **问题**：补出成分（轻微）— nissaya 把 tassa kammassa 明确为 `ထိုအကုသိုလ်ကံ`（那个不善业），把 niraye paccitvā 释为「在地狱中被煮」。译文「受煎熬」可以接受。
- **建议**：维持原译，只在上述跨段一致性项中统一称谓。
