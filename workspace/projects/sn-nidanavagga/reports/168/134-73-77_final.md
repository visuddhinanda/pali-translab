## 理由

**评估基准的缺失（先交代）**：本次只注入了义注层巴利原文与译文，**未提供 nissaya**，也**未提供本文层（mūla）译文**。因此：词级格与句法角色无法用 nissaya 逐句核对，只能凭巴利原文语法判断；黑体被解释词与本文层「逐字同译」这一硬约束**无法验证**（134-76-143-152、134-77-8-31、134-77-32-46 的词条译法只能就义注内部自洽性评判）。信心指数据此下调。

**准确性**：主干无误。菩萨眼不瞬的因由（业生净色强弱）、vipassī 的三重词源释（不瞬而视 / 张目而视 / 审察而视）、arahant 三释（破贼、破轮辐、堪受资具）、bodhisatta 三释（有智者 / 将觉之有情 / 系着于觉）、abhisamaya 的两种句读（「以慧的现观」与「由如理作意并凭慧而有现观」）都译对了，格与句法关系读得准，genitive absolute（`Tassa taṃ aṅke katvā palāḷayamānasseva`）与 `kiñcāpi…pana` 的让步结构处理正确。仅发现一处实词漏译（`ṭhitaṃ`，见问题清单），且削弱了莲花譬喻的前提，故准确性扣至 91。

**风格**：整体是合格的现代书面汉语，`style.md` 的禁例（此中／故为／彼等／于…之际／身着盛装／端坐）基本没有出现——`alaṅkatapaṭiyattaṃ` 译作「打扮得华丽整齐」、`aṅke ṭhapayiṃsu` 译作「放在他的膝上」，都按现代改法走，值得肯定。扣分点集中在三处残留的文言化用词：「瞬目」（两处）、「出脱」、「足下」。全角标点与引号合规，`zh` 字段内未见 ASCII 引号，无 JSON 风险，也未见任何工作标记。

**一致性**：这是本段最弱的一维。同一巴利词在相邻句里换了译法：`kammajapasāda`（业生的眼净色 / 业生净色）、`paññā`（智慧 / 慧，且与 76-50-66 确立的 ñāṇa=智、paññā=慧 分工冲突）、`animisa`（瞬目 vs 别处的眨动/眨眼）、`viceyya`/`vicinitvā`（审察 / 辨察，导致释义关系在中文里看不出来）。术语层面的漂移不影响理解，但正是 harmonize 该收掉的东西。

## 问题清单

### 🟧 error
- `134-76-79-104`｜漏译｜片段「从水里长出来、已经成熟的莲花」
  - 问题：`ṭhitaṃ`（挺立、立于水面之上）未译。「从水里长出来」可被读作仍在水中生长，而譬喻成立的前提正是莲花已出水面、能被日光照触。
  - 建议：「又比如从水中挺出水面而立、已经成熟的莲花」。

### 🟨 warning
- `134-74-28-40`｜文言语体｜片段「不眨动、不瞬目的眼睛」
  - 问题：「瞬目」是文言单音节词的组合（瞬=眨眼、目=眼），同一批译文别处用的是「眨动／眨眼」，语体与用词都不统一。
  - 建议：「所以他看的时候眼睛一眨不眨」，或「用不眨动、不闭合的眼睛来看」。
- `134-74-44-74`｜文言语体｜片段「不瞬目地看」
  - 问题：同上，`animisanto` 用文言词译出，与现代书面汉语的要求不符。
  - 建议：「因为王子看东西时眼睛一眨不眨」。
- `134-76-37-49`｜整句逻辑表达不规范（循环定义）｜片段「在那之前就叫做正觉之前」
  - 问题：用「正觉之前」解释「正觉之前」，等于没解释；原文 `tato pubbeva` 只是把词条落回时间点，无需再复述词条。
  - 建议：「**在正觉之前**：正觉是指四道智，这里说的就是在那之前。」
- `134-76-125-128`｜关键词语意不明确（循环释义）｜片段「**苦**（kiccha），就是苦（dukkha）」
  - 问题：义注是用 `dukkha` 去解释较生僻的 `kiccha`，中文两边都作「苦」，释义完全落空，读者只能靠夹注的巴利词才看得出差别。
  - 建议：词条改用「困厄／艰难」，如「**困厄**（kiccha），就是苦（dukkha）」。
- `134-76-119-124`｜不导致误解的汉语语病（残句）｜片段「他仍然是菩萨的时候。」
  - 问题：作为独立句子缺谓语，读起来是半截话；原文是对词条 `bodhisattasseva sato` 的收束。
  - 建议：「这样，就依功德而生起的名号来说，（经文）才说他仍然是菩萨的时候。」
- `134-77-8-31`｜关键词语意不明确（术语不一致）｜片段「**以智慧现观到**」
  - 问题：同一句内 `paññā` 先作「智慧」（词条）、后作「慧」（释义「与慧一同」），并与 `134-76-50-66`「有智的、有慧的」中 ñāṇa=智 / paññā=慧 的分工冲突，模糊了智与慧的界限。
  - 建议：统一作「慧」，词条改为「**有了以慧的现观**」。
- `134-75-26-35`｜代词指代不明确｜片段「国王把他抱在膝上逗弄着」
  - 问题：上一句结尾「放在他的膝上」的「他」指国王，本句「把他抱在膝上」的「他」转指大士，相邻两句里同一个「他」换了所指。
  - 建议：把上一句改为「放在国王膝上」，本句保留「把他抱在膝上」。
- `134-76-129-132`｜关键词语意不明确｜片段「就是陷入了、达到了」
  - 问题：`anuppatto` 的双词释义中，「达到了」与所修饰的「苦」搭配不自然，且与词条「遭受着」的体貌（进行 vs 完成）不一致。
  - 建议：「**已遭受**，就是已经陷入、已经遭遇。」

  - 建议：释义句改为「意思是一再选择、辨别之后才看」，使释义相对词条确有增益。

  - 建议：统一作「（长部 2.40）」「（长部 2.41）」。

  - 问题：「足下」在现代汉语另有「阁下」义，易生歧读。
  - 建议：「在过去诸佛座前」。
- `134-76-157-163`｜语言表达不够流畅｜片段「已经从老死之苦中出脱了」
  - 问题：「出脱」在现代汉语中多指卖出、开脱，与此处 `nissaṭa`（出离、脱出）不合。
  - 建议：「因为涅槃已经脱离了老死之苦」。
- `134-75-90-103`｜该使用而没有使用术语标记｜片段「从那时起就变得很警觉」
  - 问题：`appamatta` 通译「不放逸」，此处改用日常词，术语标记丢失。
  - 建议：「从那时起就一直不放逸（appamatta）」。
- `134-76-143-152`｜语言风格不统一｜片段「**一再地命终又投生**」
  - 问题：黑体词条 `cavati ca upapajjati ca` 本身不含「一再」，该义出自释义中的 `aparāparaṃ`；词条应与本文层逐字同译，把释义内容提到词条里会破坏跨层对齐。
  - 建议：词条作「**又死又生**」，「一再、前后相续」只留在释义句中。
- `134-77-32-46`｜语言表达不够流畅｜片段「**由于如理作意，以智慧**」
  - 问题：词条引的是 `yoniso manasikārā ahu paññāya`，`ahu` 未译出，中文成了悬空短语。
  - 建议：「**由于如理作意、凭着慧而有（现观）**」。
- `134-77-47-62`｜代词指代可能不够明确｜片段「当生存在时就有老死」
  - 问题：「生」单用易被读作「生命」；同段前一句用的是「以生为缘就有老死」，此处宜呼应。
  - 建议：「当有出生时就有老死」。
