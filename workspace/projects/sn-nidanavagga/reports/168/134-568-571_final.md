## 理由

**基准可用性**：本次评估对象本身就是义注层（book 134，Pañcasikkhāpadasuttādivaṇṇanā），上层复注（ṭīkā / Sāratthadīpanī）与 nissaya 均未注入，因此无法做「义注定释义、nissaya 定词法」的外部核对。判断依据限于巴利原文自身的格与句法、段内前后文的互证，以及 `knowledge/` 的风格与术语规定。信心指数据此下调；若后续补入 nissaya，问题清单中「词义 / 句法角色」类条目应重新核验。

**准确性**：长列举（二十种 agamanīyaṭṭhāna、十二种女子、两处 cattāro sambhārā）的词项与数目全部核对无误，无漏译、无增译；appasāvajja / mahāsāvajja 的轻重对举、gahaṭṭha 与 pabbajita 的两组例证均译出正确。主要失分在 570 段：`Yena pana samphaṃ palapati … so samphappalāpo` 的阳性关系代词被译成「思」，与紧接的 `Tesaṃ mūlabhūtā cetanāpi …（也得到…名称）` 直接冲突——义注此处的论证结构是「前三条先就语/加行立名，再说其根本的思**也**得此名」，译成思后「也」字失去着落，这是本段唯一影响义理骨架的错误。另有 `parassa suññabhāvaṃ` 译作「一无所有」产生误导，以及 569 末句主语指代滑向听者。

**风格符合度**：整体为现代书面汉语，无「此中 / 故为 / 彼等 / 是故」等典型文言腔，标点全角、引号统一用 “”，未出现 ASCII 引号，符合 JSON 安全硬约束；译文中也未见任何候选、待定、问号之类工作标记。扣分来自三处：「转起」属方法文档明列的二意/不明确译语行话；「行非法之事」「水钵之礼」两处文言句式；以及「容受以道入道」六字硬搬术语、无从解析。

## 问题清单

### 🟧 error

- `134-570-48-56`｜错译（词义、修饰关系）｜片段「而用来胡乱说出无意义的话的那个思」
  - 问题：`Yena pana samphaṃ palapati niratthakaṃ, so samphappalāpo` 中 `yena … so` 为阳性，指语加行／言说本身，非 cetanā（阴性，须作 `yāya … sā`）。且下一句 `Tesaṃ mūlabhūtā cetanāpi pisuṇavācādināmameva labhati` 已译为「作为它们根本的那个思，**也**同样得到离间语等名称」——前句若已是「思」，此处的「也」无所指，前后两句自相矛盾。
  - 建议：改为「而凭它胡乱说出无意义的话的那种（言语）加行，就是**绮语**」，与前两句（570-2-25 以「话」为主语、570-26-47 以「话」为主语）保持同一立名层次。

- `134-570-2-25`｜导致误解的表达｜片段「使他人在他心里变得一无所有」
  - 问题：`parassa ca suññabhāvaṃ karoti` 指使第三者在听话人心中变得空无、毫无分量（即被疏远、失去地位）。汉语「一无所有」通常读作「没有财产、穷困」，与原意不符，且与前半「造成对自己的亲爱」的对举关系断裂。
  - 建议：「使别人在他心里变得一文不值（形同虚无）」或「把别人在他心里掏空」。

- `134-569-135-146`｜代词指代错误｜片段「他被妄语业所系缚」
  - 问题：`ayaṃ … bajjhati` 的主语是说妄语的人，但汉语上半句刚出现「他人因这个动作而了知」，「他」的最近先行词是听者，读者会误认为是被欺骗的一方受业系缚。
  - 建议：「这个说话的人就在引发这动作的思生起的刹那，被妄语业系缚」。

### 🟨 warning

- `134-568-16-22`｜关键词语意不明确｜片段「在身门上转起的」
  - 问题：「转起」是译语行话（pavatta），普通读者不解，方法文档亦将其列为二意/不明确词例；且此处无注释。
  - 建议：「通过身门发生的」或「在身门上生起的」。

- `134-568-16-22`｜文言语体｜片段「怀着行非法（asaddhamma）之事的意图」
  - 问题：「行…之事」为文言句式，「之」作文言虚词，违反 `knowledge/style.md` 第一节禁例。
  - 建议：「怀着要做非法（asaddhamma）之事的意图」仍偏文；宜作「出于非法（asaddhamma）的意图」。

- `134-568-23-63`｜文言语体｜片段「行水钵之礼而结成的妻子」
  - 问题：「行…之礼」为文言句式。
  - 建议：「通过水钵仪式结成的妻子」。

- `134-568-91-103`｜整句逻辑表达不规范｜片段「以及容受以道入道」
  - 问题：`maggena maggapaṭipatti-adhivāsana` 直搬为六字短语，缺主语与说明，汉语无法解析，与同列另外三项（「对象 / 心 / 加行」）的表述层次也不齐。
  - 建议：「以及对以道入道（maggena maggapaṭipatti）的容受，即接受其发生」，或正文作「以及接受交合的发生」，术语另入段后注。

  - 建议：首次出现处补作「身门（kāyadvāra）」「思（cetanā）」，其后只用汉译。

- `134-568-23-63`｜复杂的嵌套句整句语言逻辑理解困难｜片段「这是母亲所守护的等十种」

  - 建议：两组各另起一行或改用「（1）…（2）…」排列，收束语单独成句。

- `134-569-33-43`｜语言表达不够流畅｜片段「想要把不真实的事物当作真实而让他人了知，引发这种表达的思」
  - 问题：`viññāpetukāmassa … cetanā` 的领属关系（「想要…者的思」）在汉语里被拉平成两个并列动作，读来像是「思」自己想要。
  - 建议：「想要把不真实的事物当作真实而让他人了知的人，其引发这种表示（viññatti）的思，就是妄语」。
