## 理由

**基准可用性**：本次未取到该三段的义注（aṭṭhakathā）与缅文 nissaya，评估仅以巴利原文为据，词法与取义无法逐词对照核验，故信心指数压在 78。本段为《相应部·界相应》Abhinandasutta 型套语经，句式高度程式化、词汇量小，纯巴利核对的可靠度较高，但 `abhinandati` 在义注中是否另有释义分层（如「以渴爱与邪见欢喜」）无从确认——若义注对该词有渴爱/见二分的限定，译文「欢喜」属于合格的中性直译，不构成错误，但注释处理可能需要补。

**准确性**：主谓宾判断全部正确。`yo … so …` 关系句译为「凡是…的人，就是…」结构准确；`aparimutto / parimutto so dukkhasmā` 的否定与肯定对举没有混淆，`vadāmi` 的说话主体（佛陀第一人称）落位正确。四界术语 pathavī / āpo / tejo / vāyo 对译地/水/火/风界无误。扣分主要在两处：一是 847 段起首 `Sāvatthiyaṃ viharati` 原文无主语，译文补出「世尊」——虽是此类套语的通行处理，但 `style.md` 第六节「不擅自补足省略主语」是明列的偏好，此处属可补可不补；二是 `dukkhaṃ so abhinandati` 的宾格前置＋代词 `so`，译文作「就是欢喜苦」，代词脱落后句子从「他欢喜苦」滑向判断句语气，逻辑指向略有位移。

## 问题清单

### 🟦 suggestion
- `168-847-2-23`｜该使用而没有使用术语标记｜片段「欢喜地界的人」
  - 问题：`style.md` 第二节规定法相术语首次出现时夹注巴利原词。「地界」是本经的核心法相术语且为四界之首现，未附巴利原词；后文水/火/风界同此。
  - 建议：首现处作「地界（pathavīdhātu）」，其余三界在各自首现处同样夹注一次，此后只用汉译。

- `168-847-2-23`｜语言表达不够流畅｜片段「就是欢喜苦」
  - 问题：原文 `dukkhaṃ so abhinandati` 有明确代词主语 `so`，译文省略后成为无主判断句，读感上从「他（也就）欢喜苦」偏向「这等于欢喜苦」，主体略被虚化。同一处理见于 `168-847-33-49`、`168-848-2-18`、`168-848-28-43`。
  - 建议：可作「他就是欢喜苦」或「他也就欢喜苦」，四处统一调整；若保留现译，亦不影响教理判断。

- `168-847-2-23`｜语言表达不够流畅｜片段「世尊住在舍卫城」
  - 问题：原文 `Sāvatthiyaṃ viharati` 无主语，「世尊」为译者补出。此为套语经的通行补法，但与 `style.md`「不擅自补足省略主语」的偏好存在张力。
  - 建议：保留亦可（该省略在传统上确指世尊）；若要严守风格配置，可作「住在舍卫城……」，由上下文承接主语。此点宜整卷统一，不建议单段改动。
