### 🟧 error
- `168-1024-63-77`｜漏译｜片段「在那里，我的名字是这样」
  - 问题：`tatrāpāsiṃ` = `tatra + api + āsiṃ`，含动词 `āsiṃ`（我曾生／我曾在）与 `api`（也）。译文只保留了处所「在那里」，动词与 `api` 均未译出，与上一句（1024-47-62）「我曾生在那里，名字是这样」的平行结构断裂，读来像是转述地点而非"我也曾生于彼处"。
  - 建议：补足为「我在那里也曾生，名字是这样，……」，与上句句式对齐。

### 🟨 warning
- `168-1024-2-46`｜不该使用术语标记时使用了术语标记｜片段「（pubbenivāsa，宿住）」
  - 问题：`style.md` 规定夹注体例为"汉译（巴利原词）"，如"沙门（samaṇa）"。此处括号内同时塞入巴利原词与第二个汉译术语「宿住」，等于在正文里并列了两套译名，体例不一且加重阅读负担。
  - 建议：二选一——用「宿住（pubbenivāsa）」，或保留意译并只夹注原词：「种种过去世的生活经历（pubbenivāsa）」。
- `168-1023-2-93`｜关键词语意不明确｜片段「萎缩的心」
  - 问题：`saṃkhitta` 与下文 `vikkhitta`（散乱）相对，传统释为心的退缩、收摄（多与昏沉睡眠相关）。「萎缩的心」在现代汉语里易被误读为"衰退、萎靡不振"，且首次出现未加夹注，读者无从定位术语。
  - 建议：改用「退缩的心（saṃkhitta）」或「收摄的心（saṃkhitta）」，首次出现夹注巴利原词；待义注可用时按义注释义定案。
- `168-1023-2-93`｜关键词语意不明确｜片段「有上的心……无上的心」
  - 问题：`sauttara / anuttara` 属二意场合的法相术语，字面「有上／无上」对一般读者不构成有效信息，且与前后的「广大／不广大」并列时更难分辨，首次出现未加夹注或注释。
  - 建议：首次出现夹注巴利原词（如「有上的心（sauttara）」），或加简注说明其指"尚有更高层次可超越／已无更高层次可超越"。
- `168-1024-78-84`｜关键词语意不明确｜片段「连同细节」
  - 问题：`sauddesa` 与 `sākāra` 是一组定型搭配，传统义读偏向"连同名目／提示（名、姓等项目）"，「细节」过泛，与前面已译出的「种种情状」界限模糊，两者读起来近乎同义重复。
  - 建议：核对义注后定案；倾向改为「连同种种情状、连同名目」。（本次无义注可比对，暂按可理解性提出。）
