# Review — 168:971-975（channel: 73c03e1a…4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 未提供，词级格位核对降级为凭原文判断）／义注 ✅（仅 134:677-678 四条释义：`kulūpaka` / `dentuyeva me` / `sandīyati`，余句义注作 `Sesamettha vuttanayānusāreneva veditabbaṃ`，无逐句对照）

## 跨段一致性

- **`sandīyati`**：§971-975 全 chunk 统一译「心里不痛快」，内部一致，但与义注释义不符 → 见下方必改项，统一改后需全 chunk 一并替换（共 13 处）。
- **`kulāni upasaṅkamati`**：§973-2-15 / §974-2-14 / §975-2-11 译「走近各家人家」，而 §973-53-68 / §974-57-68 / §975-54-65 同一短语译「走近人家」 → 建议统一为「前往各俗家」。依据：义注释 **kulūpako**ti kulagharānaṃ upagantā（前往俗家者），`kula-` 在本经固定指「俗家」，与经题「出入俗家」应同词呼应；「人家」与「俗家」两词并用会让读者看不出这是同一概念。
- **`na denti`**：§973-53-68 / §974-57-68 / §975-54-65 译「得不到布施」（受方视角、被动化），而相邻平行句 `Thokaṃ denti, no bahukaṃ` 译「他们给得少，不给得多」（施方视角）。同一组排比里主语来回切换 → 建议统一为「他们不给」。
- **`dandhaṃ` / `thokaṃ` / `bahukaṃ`**：愿望句译名词式或叠词（「不要拖拖拉拉」「给我多的，不要给少的」），陈述句译副词式（「给得慢，不给得快」「给得少，不给得多」）。同一对词两套译法 → 建议愿望句也改为副词式：「快点给我，不要慢吞吞」「多给我，不要给得少」，使前后对举关系一眼可见。
- **`sakkaccaṃ` / `asakkaccaṃ`**：愿望句「恭恭敬敬地给／不要不恭敬」，陈述句「给得不恭敬，不是恭恭敬敬地给」。基本一致，但叠词「恭恭敬敬」与整体书面语体略脱节，可与上条一并收敛为「恭敬地给／不恭敬」。

## §973 句 168-973-53-68（并及 973-112-115、974-69-73、974-88-92、974-106-110、974-124-128、974-142-146、975-66-70、975-84-88、975-103-107、975-121-125、975-139-144）

- **问题**：义注释义不符（必改）— **义注**：`**Sandīyatī**ti aṭṭīyati pīḷiyati`（厌恼、受逼恼）。义注给的是相当重的心理苦受，紧接下句又以 `dukkhaṃ domanassaṃ paṭisaṃvedayati`（感受苦与忧）承接。译文「心里不痛快」语域偏轻、偏口语，把「厌恼逼恼」弱化成了一般的情绪波动，读者会觉得与下一句「感受到苦和忧」不成比例。
- **建议**：统一改为「感到懊恼」（或「心生厌恼」）。全 chunk 13 处同步；否定式作「不会感到懊恼」。

## §972 句 168-972-2-35

- **问题**：措辞（建议）— `arahati kulūpako hotuṃ` 译「配做出入俗家的人」。`arahati` 是「值得、堪任」，中性判断；现代汉语「配／不配」带明显轻蔑色彩，用在佛陀设问句里口吻失当。另「什么样的**比丘**配做出入俗家的**人**」一句之内「比丘/人」指同一对象，读来重复。
- **建议**：「什么样的比丘适合出入俗家，什么样的比丘不适合出入俗家？」§973-123-133、§974-154-163 三处同改。

## §972 句 168-972-2-35（同句前半）

- **问题**：可读性（建议）— 「住在舍卫城……」中文无主语句悬空。`style.md` 六「不擅自补足省略主语（除非语义必须）」，此处为经文起始套语，缺主语读者无法起句。
- **建议**：作「（世尊）住在舍卫城……」，用括号标明是补出的。

## §972 句 168-972-36-47

- **问题**：措辞（建议）— 「世尊就这样说：」中的「就」在此无语义承接作用（前面是省略号，不是因果）。
- **建议**：「世尊这样说：」。

## §973 句 168-973-16-22（并及 973-23-29、973-30-36、973-37-43、973-44-52，及 §974、§975 各对应句）

- **问题**：取义偏弱（建议）— `dentuyeva` / `bahukaññeva` / `paṇītaññeva` / `sīghaññeva` / `sakkaccaññeva` 五处 `-eva`（唯、就是要）全未译出。**义注**：`**Dentuyeva** **me**ti dadantuyeva mayhaṃ` —— 义注换词复述时特意保留了 `-eva`，说明这个强调正是这段所要刻画的贪求心态。译作「但愿他们给我」，语气变成温和的希望，与下文「得不到就懊恼」的因果链条脱钩。
- **建议**：改为强制语气，如「非给我不可，不许不给；就得多给我，不许给少……」。注意 §974 / §975 起首多了 `taṃ kutettha labbhā parakulesu`（在别人家里哪能强求），正是用来否定这种强求语气的，前后语气必须能对上。

## §974 句 168-974-2-14

- **问题**：措辞（建议）— 「而任何比丘带着……」句首单用「而」偏生硬。`Yo ca kho` 在此是与前段对举转折。
- **建议**：「比丘们，反过来，任何比丘如果带着这样的心前往各俗家——」。

## §975 句 168-975-152-164

- **问题**：句式冗余（建议）— 「我要用迦叶来教诫你们，或者用与迦叶相似的人来教诫你们。」后半重复「来教诫你们」；`yo vā panassa kassapasadiso` 是省略谓语的并列项。
- **建议**：「比丘们，我将以迦叶教诫你们，或以与迦叶相似的人教诫你们。」（保留一次谓语即可，或后半省作「或者以与迦叶相似的人」。）
