# Review — 168:289-301（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 复核，没有 nissaya 的句子不出意见）

## 跨段一致性

- **经号格式**：§290 写「36.」，§296 写「三七、」，§299 写「三八、」 → 建议统一为汉字加顿号「三六、」「三七、」「三八、」，和经题「六、」「七、」「八、」的体例保持一致。
- **pe 的译法**：§290、§292、§294 用「……（中略）……」，§296、§297 用「……乃至……」 → 建议统一为一种。本 chunk 用「（中略）」的地方多，建议统一为「……（中略）……」。
- **saṅkhārā**：§290、§292、§297 句 168-297-30-45 译「行」，§297 句 168-297-46-56 至 62-76 译「诸行」 → 建议统一为「行」。
- **缘起支的句式**：§290、§292 用「以无明为缘，就有行」「以行为缘，就有识」，§297 用「以无明为缘而有行」「以诸行为缘而有识」 → 建议统一为「以……为缘，就有……」。
- **kevalassa dukkhakkhandhassa**：§290、§297 译「整个苦蕴」，§299、§300、§301 译「这一整堆苦」 → 建议统一为「整个苦蕴」。
- **samudayo hoti**：§290、§297 译「集起了」，§299、§300 译「聚集起来了」 → 建议统一为「集起」。
- **nirodha／nirujjhati**：§297 译「灭」，§301 句 168-301-43-50 和 168-301-51-59 译「止息」 → 建议统一为「灭」。依据：nissaya 释为 `ချုပ်`（灭），与 §297 的缘起灭门是同一组词。
- **ārammaṇa 与 paccaya 都译成「缘」**：§299 至 §301 把 ārammaṇa 译为「缘」，同一 chunk 里 paccaya 也译「缘」（以无明为缘）。读者会把两个不同的词当成同一个术语 → 建议把 ārammaṇa 改译为「所缘」（传统译法），或改为「所依」。nissaya 把它释为 `အကြောင်း`（因、依据），可以作为选词的参考。
- **Sāvatthinidānaṃ**：§299 译「因缘在舍卫城」，读起来不通，而且和 §290、§296「住在舍卫城」的套语不一致 → nissaya 把它展开为 `သာဝတ္ထိယံ= ၌။ ဝိဟရတိ= ၏`（住在舍卫城），建议改为「（世尊）住在舍卫城……」，或者「缘起于舍卫城」。

## §296 句 168-296-22-34

- **问题**：句法误读，另有补出的成分。nissaya 把 `ဣဒံ သရီရံ= ဤကိုယ်ကို`（这个身体，宾格）当作 daṭṭhabbaṃ 的宾语。purāṇaṃ kammaṃ、abhisaṅkhataṃ、abhisañcetayitaṃ、vedaniyaṃ 四项各带 `ဟူ၍၎င်း`，是并列的判断内容，意思是「应把这个身体看作……」。具体如下：
  - 译文先断言「这是过去的业」，再接「应当把它看作……」，把并列的四项拆成了一个断言加三个修饰，主宾关系也偏了。
  - `ကမ္မံ= ကံကြောင့်ဖြစ်ပေါ်၏` 的意思是「由（旧）业所生」，不是「就是业」。
  - 「由诸缘造作」里的「诸缘」在 nissaya 里没有，nissaya 只说 `ပြုပြင်စီမံအပ်၏`（被造作、被安排）。
  - 「以思为根本而造作」与 nissaya 的 `စေ့ဆော်ကြံစည်အပ်၏`（被思所策发、所谋划）有出入。
  - vedaniyaṃ= `ဝေဒနာ၏ အစီးအပွါးဖြစ်၏` 的意思是「是受的所依（受由此而生）」，不是「应当被感受的」。
- **建议**：改为「比丘们，应当把这个身体看作是由过去的业所生、被造作的、被思所策发的、是受的所依。」夹注（cetanā）可以保留在「思」后面。

## §297 句 168-297-2-17

- **问题**：隐含成分没有译出。nissaya 把 `တတြ ခေါ= ထိုကံကြောင့်ဖြစ်ပေါ်လာသောကိုယ်၌` 释为「在那个由业所生的身体上」，tatra 回指上一段的身体，译文「在这里」把这层指涉丢了。
- **建议**：改为「比丘们，对于这个（由业所生的）身体，多闻的圣弟子正是对缘起如理地善加作意——」。

## §299 句 168-299-9-31

- **问题**：夹注用词与原文词形不符。原文是动词 ceteti 和 anuseti，译文夹注写成名词 cetanā、anusaya。nissaya 主释为 `စေ့ဆော်၏`（策发）、`ကိန်းအောင်း၏`（潜伏），是动词。nissaya 的异释（`ယဉ္စ= အကြင်စေတနာကိုလည်း`、`အကြင်အနုသယကိုလည်း`）把 yaṃ 读成宾格的「思」「随眠」，名词夹注依据的是这个异释，但译文正文又用了主释的动词结构，两种读法混在一起。另外，nissaya 把 viññāṇassa 明确为 `ကမ္မဝိညာဏ်`（业识）。
- **建议**：二选一。
  - 按主释译：「凡所思、凡所计划、凡所潜伏」，夹注改用原词形（ceteti、anuseti），或者去掉夹注。
  - 按异释译：「凡生起的思（cetanā）、计划、随眠（anusaya）」。
  
  ārammaṇa 的译法见上文跨段一致性一节。

## §299 句 168-299-38-45

- **问题**：句法误读。nissaya 是 `တသ္မိံ ဝိညာဏေ= ထိုကမ္မဝိညာဏ်သည်`，tasmiṃ 修饰 viññāṇe，意思是「那个识」，这是一个依格独立结构。译文「识在这缘上立住了」把 tasmiṃ 误读成「在这缘上」。virūḷhe= `စည်ပင်` 的意思是「增长、繁茂」，译成「生了根」偏离了词义。
- **建议**：改为「那个识住立了、增长了，未来就会有再生（后有）出现。」§300 句 168-300-29-36 与本句原文相同，需要同步修改。

## §300 句 168-300-2-22

- **问题**：补出的成分 nissaya 里没有。nissaya 只是 `အထ= ထိုသို့ဖြစ်သော်လည်း`（即使如此）和 `စေ အနုသေတိ= အကယ်၍ ကိန်းအောင်းသည်ဖြစ်အံ့`（如果潜伏），没有「未断除的」这层意思。此外，原文 anuseti 是第三人称单数动词，与 ceteti、pakappeti 同一主语，译文却把「随眠」改成了主语，和 §299「凡有所潜伏的」的结构不对应。
- **建议**：改为「比丘们，如果不思、也不计划，但仍有所潜伏，这潜伏就成为识得以住立的所缘。」nissaya 释 etaṃ 为 `ဤကိန်းအောင်းခြင်းသည်`（这潜伏），可以把它补出。

## §301 句 168-301-35-42

- **问题**：句法误读，与 §299 句 168-299-38-45 相同。nissaya 是 `တံ (တသ္မိံ) ဝိညာဏေ= သည်`，tad 修饰 viññāṇe，意思是「那个识」，不是「在这缘上」。avirūḷhe= `မစည်ပင်`，意思是「不增长」。
- **建议**：改为「那个识不住立、不增长，未来就不会有再生出现。」

## §301 句 168-301-43-50

- **问题**：用词不一致。nirujjhanti= `ချုပ်ကုန်၏`（灭），译文作「止息」，与 §297 的「灭」不一致。
- **建议**：改为「……愁、悲、苦、忧、恼就灭了。」

## §301 句 168-301-51-59

- **问题**：与上一句相同，nirodho 译作「止息」，与 §297「整个苦蕴就灭了」不一致，苦蕴的译法也不一致。
- **建议**：改为「这样，整个苦蕴就灭了。」
