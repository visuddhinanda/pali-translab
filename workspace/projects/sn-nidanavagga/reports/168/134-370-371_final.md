## 理由

**基准可用性（先说清楚）**：本次评估的对象本身就是义注层（book 134，`Dutiyaassutavāsuttavaṇṇanā`），注入数据中**没有复注（ṭīkā）**、**没有 nissaya**，也**没有对应本文（SN 12.62）层的译文**。因此：
- 释义标准只能退回到巴利原文自身的内证与阿毗达摩通义（俱生缘 / 亲依止缘、vatthu-ārammaṇa-phassa-vedanā 四项配对），无法用词级基准逐词核对格与句法角色；

**准确性**：主体译得扎实。缘起段（`134-371-25-38`）把 `sahajātapaccayena na hoti, upanissayapaccayena pana javanavedanāya hoti` 的两重缘分辨得清楚，`taṃ sandhāyetaṃ vuttaṃ` 译作「这句话就是针对这一点说的」准确；`aggicuṇṇo nikkhamati` 的遮遣（不是真有火星迸出）、`vevacana` 译作「另一种说法」都到位。扣分集中在两处：一是 `dvinnaṃ kaṭṭhānaṃ` 的被释词被提前译成「钻火木」，使 `dvinnaṃ araṇīnaṃ` 这条注释变成同义反复，注释的信息量被译没了；二是 `adhoaraṇī viya vatthu` 一组四个比喻的**喻体与本体方向整体颠倒**——巴利以法相（vatthu / ārammaṇa / phassa / vedanā）为主语、以钻火木为喻，译文倒过来以钻火木为主语。意思读者仍能领会，但主谓关系与原文相反，属专家有举必究之列。`tejo` 译「火力」在现代汉语里首义偏向军事，语意不够明确。

**风格**：完全是现代书面汉语，未见任何文言虚词或文言句式（无「此中/故为/彼等/是故/于…之际」一类），`style.md` 第一节禁例表零违反，这一项表现好。全角标点、全角括号统一，`zh` 字段内无 ASCII 引号，无残留工作标记。扣分在两点：`134-371-17-24` 的「…缘啊，不是吗？」把语气词「啊」和反问尾巴叠用，滑向口语，与其余各句的书面语体不统一；「等等」连用三处，书面语中作「等」更稳。

**一致性**：术语内部基本自洽（俱生缘 / 亲依止缘 / 速行 / 所依处 / 所缘 / 热界 / 触 / 受 均无混用），`usmākāra` 前后两处都作「发热的状态」，很好。扣分在夹注规则执行不齐：`style.md` 规定法相术语首次出现夹注巴利原词，但全段只有「（araṇi）」一处夹注，`sahajātapaccaya` / `upanissayapaccaya` / `javana` / `vatthu` / `ārammaṇa` / `usmādhātu` 一律未夹注；同一段内 `samodhāna` 先译「合拢」后译「聚合」。

## 问题清单

### 🟧 error
- `134-371-85-91`｜错译（词义）｜片段「钻火用的两支木（araṇi）」
  - 问题：被解释词 `dvinnaṃ kaṭṭhānaṃ` 已被译作「钻火木」，而注释正是要把泛称的 `kaṭṭha`（木、木块）落实为专称的 `araṇī`（钻火木）。译文使被释词与释词同义，整条注释变成「钻火木是指钻火用的木」的同义反复，原文的释义信息丢失。
  - 建议：被释词回到泛称，释词保留专称，例如「这里所说的**两支** **木头**，是指钻火用的两支钻火木（araṇi）」。改前须核对本文（SN 12.62）层 `kaṭṭha` 的既定译法，保持逐字同译。
- `134-371-92-108`｜错译（修饰关系）｜片段「下面的那支钻火木就像所依处」
  - 问题：巴利 `adhoaraṇī viya vatthu` 的主语是 `vatthu`，`adhoaraṇī viya` 是喻。译文把喻体当主语、本体当喻，四个比喻（vatthu / ārammaṇa / phassa / vedanā）方向全部颠倒。此处义注是以钻木取火喻解释心识生起，本体必须是法相。
  - 建议：整组回正为「所依处（vatthu）就像下面的那支钻火木，所缘（ārammaṇa）就像上面的那支钻火木，触就像两木相摩，受就像由此生起的热界」。

### 🟨 warning
- `134-371-72-84`｜关键词语意不明确｜片段「**火力** **现起**」
  - 问题：`tejo` 在此指火（火界、热力）。现代汉语「火力」首义为兵器射击威力，读者易误读；且下句自释「这只是对发热状态的另一种说法」，与「火力」搭配不顺。
  - 建议：改用「火（tejo）」或「火界」，如「**火** **生起**」；同样须与本文层 `tejo` 的定译对齐。

### 🟦 suggestion
