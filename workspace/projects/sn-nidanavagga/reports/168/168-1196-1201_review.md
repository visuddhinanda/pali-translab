## §1197 句 168-1197-57-92
- **问题**：准确性（轻微）— `rūpasmimpi … vedanāyapi … saññāyapi … saṅkhāresupi … viññāṇasmimpi` 里的 `-pi`（“也”）五处都没有译出。原文用它逐项强调“对色也、对受也……”都厌离，省掉后排比的语气变弱了。
- **建议**：改为“就对色也厌离……乃至……对受也厌离……对想也厌离……对行也厌离……对识也厌离”。

## §1197 句 168-1197-105-123
- **问题**：存疑 — `nāparaṃ itthattāya` 译作“不会再有下一世了”，属于意译。`itthatta` 字面是“这种状态”，传统上有两种解释：一是“不再有为了这种状态（的修道事务）”，二是“这一蕴相续之后不再有其他相续”。“下一世”偏向第二种，也把意思说窄了。本次注入的义注段没有解释这句，无法以义注裁定。
- **建议**：先核对本项目其他章节这句套语的定译，保持全书统一。如果还没有定译，可以考虑“不会再有这种存在状态了”，或沿用“不再有后有”并加注。

## §1200–1201 句 168-1200-2-9 / 168-1201-2-10
- **问题**：一致性（待核）— 摄颂里的每一项都是本品各经的经名（Cakkhu / Rūpa / Viññāṇa / Samphassa / Vedanā / Saññā / Sañcetanā / Taṇhā / Dhātu / Khandha）。摄颂译名必须和各经标题的译法逐字相同。本 chunk 只能核对到“蕴”（§1196“蕴经”）。
- **建议**：到 channel 里读回本品第 1–9 经的标题，逐一比对“眼、色、识、触、受、想、思、渴爱、界”。重点看 `sañcetanā`（“思”还是“意志”）和 `taṇhā`（“渴爱”还是“爱”）是否与经题一致，不一致的按经题统一。
