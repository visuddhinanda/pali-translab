# Review — 168:347-353（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位核对无法进行）／义注 ✅（book 134, §274-276）
>
> 本层为本文（mūla），无父层可比对。下列被解释词是义注黑体引出的词，本文译法将成为义注译文的硬约束，需先在本层定稿：`ñātike` / `giñjakāvasathe` / `dhammapariyāya` / `upassuti` / `addasā` / `assosi no` / `uggaṇhāhi`·`pariyāpuṇāhi`·`dhārehi` / `atthasaṃhito` / `ādibrahmacariyako`。

## 跨段一致性

- **`upassuti ṭhito`**：§353 句 `168-353-2-21` 译「站在世尊听得见的地方偷听」，句 `168-353-22-29` 译「站在旁边偷听」 → 同一短语两种译法，且两处都误加「偷听」。建议统一为「站在能听见世尊说话的地方」（依据：义注 `upassutiṭṭhānaṃ, yaṃ ṭhānaṃ upagatena sakkā hoti bhagavato saddaṃ sotuṃ`）。详见下方必改项。
- **`dhammapariyāya`**：§348、§353 各处一律译「（这段）法门」，一致 ✅。
- **`Tiṇṇaṃ saṅgati phasso`**：§349/§350/§351/§352 四处均译「这三者会合就是触」，一致 ✅。
- **`Tassāyeva taṇhāya asesavirāganirodhā upādānanirodho`**：§351、§352 两处译文完全相同，一致 ✅（但两处同样需按下方 §351 条目修改，改时要同步）。
- **`phassa` / `phoṭṭhabba`**：分别作「触」「触境」，未混用 ✅。
- 语体全 chunk 为现代书面汉语，未见文言虚词或半文半白句式 ✅。

## §353 句 168-353-2-21

- **问题**：误译 + 方向颠倒 —「站在世尊听得见的地方」把听的主体译反了。`upassuti` 是那位比丘能听见世尊声音的位置，不是世尊能听见比丘的位置。**义注**：`Upassutīti upassutiṭṭhānaṃ, yaṃ ṭhānaṃ upagatena sakkā hoti bhagavato saddaṃ sotuṃ, tattha ṭhitoti attho.`（走到那个地方就能听见世尊的声音，站在那里）。
- **问题**：增译 —「偷听」在原文与义注中都没有依据，且与义注叙事相悖。**义注**：`So kira gandhakuṭipariveṇasammajjanatthaṃ āgato attano kammaṃ pahāya bhagavato dhammaghosaṃ suṇanto aṭṭhāsi.`（他本是来打扫香室庭院的，放下自己的活儿，站着听世尊的法音）——是放下手中工作驻足聆听，不是窥伺偷听。「偷听」给读者植入了贬义。
- **建议**：改为「那时，有一位比丘正站在能听见世尊说话的地方。」

## §353 句 168-353-22-29

- **问题**：同上 —「站在旁边偷听」，「偷听」无据；且与前一句 `upassuti` 的译法不一致。
- **建议**：改为「世尊看见了那位比丘站在能听见（自己说话）的地方。」——与前句用同一短语，保持 `upassuti ṭhito` 逐字一致。

## §348 句 168-348-2-17

- **问题**：译窄 —「砖屋」把 `giñjakāvasatha` 缩成了普通房屋。**义注**：`Giñjakāvasatheti iṭṭhakāhi kate mahāpāsāde.`（用砖建成的大楼阁 / 大堂）。义注特意点出是 `mahāpāsāda`（大型楼阁），译作「屋」会让读者以为是小屋。
- **建议**：改为「砖砌的大堂里」或「砖造的大楼阁里」。此译法要与将来义注 `Giñjakāvasathe` 一条的译文逐字相同。
- **问题**（存疑，非必改）：`ñātike` 音译作「那提迦」。**义注**：`Ñātiketi dvinnaṃ ñātakānaṃ gāme.`（在两位亲族的村子里）——义注把它当作「两位亲族之村」解。作为地名音译可以保留，但义注该条的译文需与本文的「那提迦」挂得上钩（例如「那提迦（Ñātika），指两位亲族的村子」），否则被解释词的对应关系在读者眼里会断掉。请在 footnote 步补一条首次出现的简注。

## §348 句 168-348-18-26

- **问题**：措辞 —「独处静修的时候」。`rahogata paṭisallāna` 指独自静处、静坐思惟，「静修」偏泛（易被读作长期修行状态），而这里是当下独坐的一时之事。
- **建议**：改为「那时，世尊独自静坐思惟，说出了这段法门：」

## §351 句 168-351-22-26（§352 句 168-352-29-34 同）

- **问题**：句子逻辑重复且主语滑动 —「就由这爱的彻底离贪而灭尽，取也随之灭尽」。原文 `Tassāyeva taṇhāya asesavirāganirodhā upādānanirodho` 是「因爱的无余离贪灭 → 取灭」，前半的「灭」属于爱，译文把「灭尽」写了两遍，读者会误以为主语一直是取。另外「随之」是增译，因缘句不宜加时间先后的暗示。
- **建议**：改为「由于这爱的无余离贪、寂灭，取就灭；」——与下一句「取灭，有就灭」构成同一句式链。

## §353 句 168-353-58-67 / 68-75 / 76-83（uggaṇhāhi / pariyāpuṇāhi / dhārehi 三句连读）

- **问题**：三个动词的分工被压平。义注对三者有明确辨异：
  - **义注**：`Uggaṇhāhītiādīsu sutvā tuṇhībhūtova paguṇaṃ karonto uggaṇhāti nāma.`（听后默然地反复使之纯熟，叫作「学得」）
  - **义注**：`Padānupadaṃ ghaṭetvā vācāya paricitaṃ karonto pariyāpuṇāti nāma.`（逐字逐句连贯起来，出声念诵至纯熟，叫作「通习」）
  - **义注**：`Ubhayathāpi paguṇaṃ ādhārappattaṃ karonto dhāreti nāma.`（两方面都纯熟、达到能受持不忘，叫作「忆持」）

  现译「学习／熟记／牢牢记住」中，「熟记」与「牢牢记住」几乎同义，`pariyāpuṇāti` 的「出声念诵」这一层完全丢了，`dhāreti` 与 `pariyāpuṇāti` 的界线消失。
- **建议**：三句分别改为「你要学会这段法门」「你要念诵通习这段法门」「你要牢牢受持这段法门」。三词的定译要与义注 §276-18-26/27-34/35-41 的译文逐字对应。

## §353 句 168-353-84-113

- **问题**：误译 —「有意义」。**义注**：`Atthasaṃhitoti kāraṇanissito.`（依于因由、有道理依据）。`attha` 在此被义注读作 `kāraṇa`（因由、理据），不是泛指的「意义」；译成「有意义」会滑向「值得一读」的评价语。
- **问题**：译窄 —「是梵行的开端」。**义注**：`Ādibrahmacariyakoti maggabrahmacariyassa ādi patiṭṭhānabhūto.`（是道梵行的开端，是其立足的根基）。义注明确限定为「道梵行」（`maggabrahmacariya`），并补出 `patiṭṭhāna`（根基）一层，现译只取了「开端」。
- **建议**：改为「比丘，这段法门有理据，是梵行之道的开端和根基。」（若嫌「之道」偏文，可作「是圣道梵行的开端和根基」。）

## §353 句 168-353-35-48

- **问题**（存疑，非必改）：`assosi no` 的取义。**义注**给了两解：`Assosi noti assosi nu.`（主解：`no` 是疑问助词，「你听到了吗」）；`Atha vā assosi noti amhākaṃ bhāsantānaṃ assosīti.`（异解：`no` 是「我们的」，「你听到我们说的话了吗」）。现译「你听到这段法门了吗？」取的是主解，正确 ✅。
- **建议**：异解按 `style.md` 第四节，可在 footnote 步作脚注备列，正文不动。
