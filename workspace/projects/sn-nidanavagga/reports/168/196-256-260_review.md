## 被解释词核对（首要项）

逐条比对本层黑体与父层 book 134 定稿译文，**绝大多数逐字相同，通过**：
凡有所 / 摄取的是三界的善思与不善思 / 摄取的是渴爱的计划和见的计划 / 就十二种思而言 / 从俱生的一面 / 为了业识的住立 / 有了那个条件 / 识就有了立足之处 / 生了根 / 业速行（javana）之后 / 根已经生出来了 / 三界的思 / 不运转的那一刻 / 从尚未断除的一面 / 并没有被阻断 / 正是条件 / 第一句排除了三界的善思与不善思 / 排除了 / 在前面所说的那些 / 这里 / 四种 / 就四种不善思而言 / 把经中所说的那种排除在外 / 与前面的相同。

## 跨段一致性

- **paccaya 的译法自相矛盾（必改）**：父层已把这段的术语关系定死为 **ārammaṇa=缘、paccaya=条件**（134-253-80-86：「因为这里所说的“缘”（ārammaṇa…），指的是条件（paccaya）」）。本层多数处遵守（§257 句 130-141「有了那个条件」、句 112-123「缘就是条件」、§258 句 48-52「正是条件」），但 **§257 句 45-49「确定业识的缘」（paccayaniddhāraṇa）** 与 **§257 句 186-205「给了它缘」（laddhapaccayattā）** 把 paccaya 译回「缘」，正好抹掉本段要辨的那组区别。→ 统一改为「条件」。
- **pavatti / pavattati：运转 vs 活动**。多数处作「运转」（§257 句 124-129、§258 句 6-11、§259 句 25-32、§260 句 70-93），但 §257 句 64-81「它的活动更为明显」、§258 句 25-42「而有的活动」「它是…而活动的」、§260 句 70-93「从俱生的一面而活动的随眠」作「活动」。父层锚定的是「运转/不运转」。→ 建议统一为「运转」（如「随眠就谈不上从俱生的一面等等而有的运转」）。
- **viruḷha 一族译法不齐**：§257 句 157-160「生了根」（=父层）、句 161-176「生了根」✅，但句 186-205 同句内出现「也长出了根」。→ 统一用「生根／生了根」。
- **patiṭṭhita 的引文长度不一**：§257 句 142-156 把只含「tasmiṃ patiṭṭhite」的引文译成「识在这缘上立住了」（补入父层才有的「识」），句 161-176 同一词又只作「立住了」。→ 见该条。
- **语体混入口语**：讲得通（§257 句 112-123）、够得上（句 98-111）、撇开不算（§260 句 51-69、句 70-93）、排除掉了（§260 句 30-50）。全篇为现代书面语，这几处偏口语，建议：说得通／称得上／撇开不计／排除了。
- 文言腔整体控制良好，无「此中／故为／彼等」类问题；标点全角、无 ASCII 引号、无工作标记，JSON 安全项通过。

## §257 句 196-257-45-49

- **问题**：术语一致性 — `paccayaniddhāraṇa` 译作「确定业识的**缘**」，与父层「ārammaṇa=缘 / paccaya=条件」的分工冲突（同段句 112-123 自己也译「缘就是条件」）。
- **建议**：改为「这句是在确定业识的**条件**」。

## §257 句 196-257-64-81

- **问题**：准确性（轻） — `akusalesu pana pavatti pākaṭā`。`akusalesu` 承上文指不善思／不善心，译作「不善**法**」范围放宽；`pākaṭā`（明显）译作「**更为**明显」多出比较义。
- **建议**：「不过在不善（思）当中它的运转很明显」。

## §257 句 196-257-92-97

- **问题**：风格 — 「因为并不会由于时间的不同，相就跟着有所不同。」句式绕，且 `lakkhaṇa` 单用「相」对一般读者偏简。
- **建议**：「因为特相（lakkhaṇa）并不会因为时间不同而有所差别。」（首次出现夹注巴利原词，合 `style.md` 第三节）

## §257 句 196-257-98-111

- **问题**：准确性 — `nippariyāyato` 是技术词，指「不加转义地／严格意义上」（与 pariyāya 转义说相对），译作「直截了当地」偏向说话方式，丢了术语对立。另「够得上被…称为」句式拗口。
- **建议**：「其实只有未来的欲贪等，严格说来（nippariyāyato）才称得上是“随眠”。」

## §257 句 196-257-112-123

- **问题**：存疑 — `Paccayuppanno vaṭṭatīti āha…` 一句理解不明确。「由于缘所生的法也讲得通」既未点明主语是谁「讲得通」，也看不出与结论「缘就是条件」的推理关系；`vaṭṭati` 是「说得通／可以」，`paccayuppanna` 是「由缘而生（的法）」。现译读起来像已经确定，实则含混。
- **建议**：贴原文语序改为「因为“由缘生起的”这样理解说得通，所以（义注）说“缘就是条件”」，并把该句 `confidence` 压低；若后续能取到 nissaya，优先核对 `paccayuppanno` 的格与句法角色。

## §257 句 196-257-142-156

- **问题**：被解释词对应 — 巴利引文是 `‘‘patiṭṭhā hoti, tasmiṃ patiṭṭhite’’`，译文作「**有了立足之处，识在这缘上立住了**」。同一句里处理相反：前半按引文删掉了父层有的「识」（父层作「识就有了立足之处」），后半却补入引文没有的「识」（父层「识在这缘上立住了」对应的是 `tasmiṃ patiṭṭhite viññāṇe`）。且句 161-176 同词又只作「立住了」，三处不齐。
- **建议**：二选一并贯彻——① 一律用父层完整译法：「识就有了立足之处，识在这缘上立住了」；② 一律按引文截断：「有了立足之处，在这缘上立住了」，句 161-176 保持「立住了」。倾向 ②，与引文长度对得上，且与句 161-176 已有的「立住了」自洽。

## §257 句 196-257-161-176

- **问题**：格式 — 巴利本句 `Patiṭṭhiteti… ‘‘viruḷhe’’ti…` **无黑体**，译文却给「**生了根**」加了粗；本层黑体的意义是「引自父层的被解释词」，凭空加粗会让读者以为这里在标被解释词。
- **建议**：去掉加粗，作「“生了根”这句说的是业已经积集了」。（对照：§260 句 7-23 同样是 `‘‘ ’’` 引文而未加粗，处理正确）

## §257 句 196-257-186-205

- **问题**：① 术语一致性 — 「给了它**缘**」（laddhapaccayattā）应作「条件」，同上。② 句法 — `balappattāya sanniṭṭhāpakacetanāya` 是具格，业识是「凭着这有力的决定思」才得立足、生根；现译把「决定思变得有力」拆成并列小句，因果链条断成三段平铺。③ 用词 — 「长出了根」与前文「生了根」不一。
- **建议**：「这里，由于先前生起的那些业思给了它条件，决定思变得有力；业识凭着这有力的决定思得到了立足之处，也生了根，所以说“**根已经生出来了**”。」

## §258 句 196-258-21-24

- **问题**：风格 — 「就是就还没有被彻底断绝这一点而说」两个「就」相连，读感滞涩；且 `asamucchinna` 译「彻底断绝」与全篇「断除」用字不齐。
- **建议**：「指的是还没有被彻底断除这一点。」

## §258 句 196-258-25-42

- **问题**：① `pavatti / pavattati` 作「活动」，与同段「不运转」不一致（见跨段一致性）。② `karontassa abhāvato` 译「由于没有造作者」易被读成「没有作者（补特伽罗）」，此处指的是异熟等法中没有能造作（业）的成分。
- **建议**：「…随眠就谈不上从俱生的一面等等而有的运转；而在异熟等法当中，由于没有能造作的（心），它是从尚未断除的一面而运转的。」

## §258 句 196-258-43-47

- **问题**：准确性（轻） — `avāritabbattā` 是未来被动分词，意为「不会被／不必被遮止」，现译「没有被对治法阻挡住」作已然事实。
- **建议**：「是说它不会被对治法所遮止。」

## §259 句 196-259-2-24

- **问题**：被解释词对应 — 本句说的是**第三轮**，但引文 `‘‘no ce’’` 译作「**如果不**」，那是父层 §254（第二轮）的译法（「**比丘们，如果不思虑**」）；父层第三轮 §255 的定稿译法是「**既不思虑**」。读者按「如果不」回查会指到错误的一轮。
- **建议**：改为「在第三轮里用“**既不**”等语句显示了还灭」，或作「用“**既不思虑**”等语句」，与父层 §255 对上。
- **附**：`vaṭṭa/vivaṭṭa`「轮回／还灭」译法正确，建议首次出现各夹注一次巴利原词。`vāra`→「轮」与 `naya`→「方式」区分得当（§260 句 94-99 承父层「方式」），保持。

## §259 句 196-259-33-36

- **问题**：一致性（轻） — 同一 `nivattā` 上句作「排除了」，此句作「被排除了」。
- **建议**：如无主动被动之需，统一为「渴爱与见排除了」或上下句都用被动，择一。

## §260 句 196-260-7-23

- **问题**：风格 — 「这里是就思与计划的运转来显示对诸法的界定的」，「是…的」框架多余，句子偏长。
- **建议**：「这里是就思与计划的运转来显示对诸法的界定，所以说明“思虑摄取的是三界的善思与不善思”这一类讲法只出现在这里。」

## §260 句 196-260-24-29

- **问题**：准确性 — `paṭighadvayamohamūlasamāgatā catasso`：瞋根二心 + 痴根二心 = 四。现译「由两种瞋根心和痴根心合起来构成的四种不善思」只给出「两种瞋根心」的数目，痴根心不标数，读者无从看出 2+2=4，算术关系失落。
- **建议**：「就是两种瞋根心和两种痴根心合起来的四种不善思。」

## §260 句 196-260-30-50

- **问题**：风格（轻） — 「排除掉了」偏口语，「则被…」略带文言助词味。
- **建议**：「至于其余的，被“不计划”这句否定排除了。」

## §257 句 196-257-2-13（备注，非必改）

- **说明**：`ca-saddo aṭṭhāne` 译「放在了不该放的位置上」意思到位。「这里的 **ca**（和）这个词」中，圆括号里放的是汉义而非巴利原词，与 `style.md` 的夹注惯例（括号内放巴利原词）方向相反，但此处讨论对象本就是巴利虚词，可接受。
- **建议**（可选）：「这里的 **ca**（“和”）这个连词放在了不该放的位置上。」
