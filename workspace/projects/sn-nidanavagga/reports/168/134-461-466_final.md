## 理由

**基准可用性（降级说明）**：本次待评的是**义注层**（book 134，10. Susimasuttavaṇṇanā）。按方法文档，义注层的释义标准应为其上位注释（复注 ṭīkā），词级基准应为 nissaya——但本次注入的数据只有巴利原文与目标 channel 的译文，**复注与 nissaya 均未提供**。因此准确性判定退回到「巴利原文内部自洽 + 义注体例（词条—释义对应）」这一层，无法核验传统取义与格/句法角色。分数与信心指数据此下调；若后续补入 nissaya 或复注，个别判定（尤其 `nijjhānaka`、`paramappamāṇa`、`ciṇṇante` 的取义）可能需要修订。

**准确性**：整体译解准确，长句（`134-464-13-62` 的 maggo/phalaṃ 三重否定 + 三重肯定、`134-463-56-74` 的比丘内心话）结构与逻辑都立得住，`nissando / ānisaṃso / nipphatti` 三词分别译为「流出／带来的利益／所成就」层次清楚。扣分集中在**被解释词（黑体词条）与其解释项的对应**上：义注体例是「词条 = 释义」，词条必须与本文逐字同译，不能把释义内容倒灌进词条。`134-462-42-50` 把 `Kamathā`（行走）译成「或坐着或行走」，是把下文 gloss 的「nisīdituṃ vā gantuṃ vā」并入了词条；`134-461-55-70` 把 `Assosī`（他听到了）译成「听说」，在同一句里与「据说」撞义，读者会误解成传闻标记。这两条均属须改。其余若干处（`iddhikoṭṭhāsa`→「神通的种类」与词条「神变」同义打架、`paramappamāṇa`→「最高层次」、`parakuṭṭa` 名词译成动作短语）属可提升，不构成误读。

**风格**：现代书面汉语基本达标，**未发现文言/半文半白语体**——无「此中／故为／彼等／于…之际／答以」类禁例，虚词、句式都是白话。标点全为全角，引号统一用 “” ‘’，夹注巴利用全角圆括号（`sukkhavipassaka`、`Visuddhimagga`），译文中**未检出 ASCII 引号**，JSON 安全无虞。译文里**无任何残留工作标记**（候选／待定／问号／TODO）。扣分在个别汉语不自然处：「一位位比丘所在的地方」「那一番番谈话」是把巴利叠词 `tesaṃ tesaṃ` / `taṃ taṃ` 硬搬过来的翻译腔；`134-465-14-20` 因分句切分而成残句「**色是常的还是无常的？**等话。」，单独读不成句。

**一致性**：术语线索稳定——`aññā`→究竟智、`nijjhānaka + sukkhavipassaka`→没有禅那的干观者、`ājāneyyāsi vā`→「（无论）你了解也好」三处措辞统一；`satthā`→导师、`bhagavā`→世尊分别对译，未混用。黑体引文处理上有一个系统性偏移：`āvuso` / `āvuso susima` 在巴利原文中位于句中，译文一律提到句首（`134-463-19-35`、`134-463-36-50`、`134-465-28-38`），虽三处自洽且合汉语语感，但会削弱与本文层逐字对齐的可检索性。术语标记覆盖不全：「自恣」「名身」等未夹注巴利原词，而同段的「干观者」有夹注，标准不齐。

## 问题清单
按级别从高到低排列。

### 🟧 error

- `134-462-42-50`｜错误多译（被解释词倒灌释义）｜片段「或坐着或行走」
  - 问题：黑体词条对应的巴利是 `Kamathā`（kamati，行走／前进），词条本身不含「坐」。译文把其后 gloss「nisīdituṃ vā gantuṃ vā」（能坐或能走）的内容并进了词条，导致词条与本文层的被解释词无法逐字对应，也使「词条 = 释义」的义注体例失效（读起来像「或坐着或行走 = 能坐着或行走」的同语反复）。
  - 建议：词条改为与本文同译的「**行走**」，释义保持「这是问他们能不能坐着或者行走」，对应关系即恢复。

- `134-461-55-70`｜导致误解的表达｜片段「听说」
  - 问题：`Assosi` 是过去式「（他）听到了」，本文经句为须深听到诸比丘记说究竟智一事。译成「听说」在现代汉语中首义是「据传、听人说」，且紧接其后的释义就以「据说」开头，两者连读会让读者把词条读成传闻标记，与经文事件性陈述不符。
  - 建议：词条改为「**听到**」（或与本文层一致的「**听到了**」），释义部分不动。

### 🟨 warning

- `134-461-85-103`｜关键词语意不明确｜片段「最高层次」
  - 问题：`paramappamāṇa` 指「最高的标准／权衡的极限」，说的是究竟智在教法中被当作衡量高下的标尺；「最高层次」把「标准」偷换成「阶位」，与同句并列的「最为精要」「秘不外传的诀窍」失去语义梯度。
  - 建议：改为「最高的标准」或「衡量的最高尺度」。

- `134-463-19-35`｜术语标记不统一｜片段「以名身触及、获得」
  - 问题：同段内「干观者」夹注了巴利（sukkhavipassaka），而更需要注释的法相术语「名身」（nāmakāya，与「色身」相对）反而未夹注；一般读者会误以为是身体的某个部位，而此处恰恰是「慧解脱不以色身证得」的关键。
  - 建议：首次出现处补夹注，作「以名身（nāmakāya）触及、获得」。

- `134-465-14-20`｜整句逻辑表达不规范｜片段「**色是常的还是无常的？**等话。」
  - 问题：该句独立读为残句——主语与谓语（「世尊说了……等话」）留在上一句 `134-465-2-13` 的「就为他作三转开示，说：」，本句只剩宾语加「等话。」。逐句呈现或导出为条目时，读者看到的是一个无主谓的片段。
  - 建议：本句自足化，补为「世尊还说了**色是常的还是无常的？**等话。」，或与上句共用的「说」改为在本句收尾。

### 🟦 suggestion

- `134-461-55-70`｜语言表达不够流畅｜片段「一位位比丘所在的地方」
  - 问题：`tesaṃ tesaṃ` 的分配义用「一位位」叠量词生硬，属翻译腔。
  - 建议：改为「各个比丘所在的地方」或「这个那个比丘所在之处」。

- `134-461-55-70`｜语言表达不够流畅｜片段「那一番番谈话」
  - 问题：`taṃ taṃ kathaṃ` 的分配义用「一番番」不自然，且与前一处叠词连用，一句之内两次翻译腔。
  - 建议：改为「各种各样的谈话」或「这样那样的谈话」。

- `134-462-6-9`｜语言风格不统一（词条与释义同义打架）｜片段「神通的种类」
  - 问题：词条「神变」（iddhividha，本身即「神变之类」）与释义「神通的种类」几乎同义，`koṭṭhāsa`（部分、分支）的「部分」义未体现，解释未起到解释作用。
  - 建议：释义改为「就是神通的一个部分」或「神通的诸分支」。

- `134-462-24-27`｜语言表达不够流畅｜片段「就是穿到墙的另一边」
  - 问题：`parakuṭṭa` 是名词「墙的那一边／外墙」，与词条 `tirokuṭṭa` 构成名词对名词的同义替换；译成动作短语「穿到……」后，与紧接的「其余两个词也是同样的道理」（指 tiropākāra / tiropabbata 的同类替换）对不上。
  - 建议：释义改为「就是墙的另一边」。

- `134-462-38-41`｜语言风格不统一｜片段「**盘腿**：就是盘起双腿结跏趺坐」
  - 问题：词条用口语「盘腿」，释义用术语「结跏趺坐」，同一概念在一行内换了两套语域。
  - 建议：词条与释义统一，如「**结跏趺坐**：就是盘起双腿结成跏趺」。

- `134-461-23-41`｜不常用术语未编写注释｜片段「在举行了自恣之后」
  - 问题：「自恣」（pavāraṇā）是安居结束时的僧团仪轨，对一般读者不透明，而本段其他术语（干观者）已有夹注，标准不齐。
  - 建议：作「在举行了自恣（pavāraṇā）之后」。

- `134-463-75-82`｜代词/语意可能不够明确｜片段「它在前面生起」
  - 问题：`paṭhamataraṃ` 是时间上的「更先」，「在前面」易被读作位置或文本次序，尤其与下一句「它在后面生起」并置时。
  - 建议：改为「它先生起」，下句相应作「它后生起」。

- `134-463-19-35`｜语言风格不统一（黑体引文语序）｜片段「**贤友**，**我们是慧解脱者**」
  - 问题：巴利原文语序为 `Paññāvimuttā kho mayaṃ, āvuso`，`āvuso` 在句末；译文将其提到句首。虽合汉语习惯且与 `134-463-36-50`、`134-465-28-38` 三处处理一致，但会降低黑体词条与本文层逐字对齐的可检索性。
  - 建议：若本文层同句已按原序译出，此处宜与之保持同序；否则至少在全书范围内固定一种处理并记入 `knowledge/style.md`。

- `134-465-49-52`｜语言表达不够流畅｜片段「是为了揭示那些比丘是没有禅那的干观者」
  - 问题：原文 `nijjhānakānaṃ sukkhavipassakabhikkhūnaṃ` 无指示词，是泛指一类比丘；「那些」的限定虽可由上下文支撑，但与紧接的 `134-465-53-65`「那些比丘也同样是这样的人」重复同一指称手段，且此处正文尚未明确「那些」指谁。
  - 建议：改为「是为了显明这些比丘都是没有禅那的干观者」，或径作「是为了显明干观比丘的身份」。

- `134-465-39-48`｜复杂嵌套句对读者不友好｜片段「这一段，世尊为什么要说起呢」
  - 问题：黑体引文「**那么，须深，你**」本身是截断的半句，紧接「这一段」衔接生硬，读者会在断口处停顿。
  - 建议：改为「世尊为什么要说起**那么，须深，你**这一段呢？」，或在引文后补省略号示意截断。
