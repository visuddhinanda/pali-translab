# Review — 168:594-605（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供，词级格位核对只能依巴利原文自行判断）／义注 ✅（book 134 §472–475，是整个 Antarapeyyāla 的总释，与本 chunk 直接相关的只有 **satthā** 一条）
>
> 本层是本文（mūla），没有父层；它是义注被解释词的来源。基准译法：**satthā** → “导师”，**satthā pariyesitabbo** → “应当寻求导师”。义注 §473 翻译时，黑体必须与这两处逐字相同。
>
> 义注（§473）对 satthā 的解释是：“**义注**：buddho vā hotu sāvako vā, yaṃ nissāya maggañāṇaṃ labhati, ayaṃ satthā nāma”（无论是佛还是弟子，依靠他能得到道智的人，就叫作 satthā）。所以用“导师”而不用专指佛陀的“大师”是对的，保持不变。

## 跨段一致性

- **“不如实地知道、不如实地见到 X 的人”句式造成误读**（§595–§604，全部 11 句）：宾语 X 夹在动词和“的人”之间，单音节术语会和“的人”粘成别的词：
  - §596 “见到**有的人**”会读成“见到某些人”，这是**误读**；
  - §597 “取的人”、§599 “受的人”、§600 “触的人”、§603 “识的人”、§595 “生的人”都有类似歧义。

  → **必改**：统一改成“**对 X** 不如实地知道、不如实地见到的人”，把宾语提到前面，歧义就消除了。§604 的四个分句虽然没有歧义，也要一并改，保持句式统一。

  → 这个句式框架是 Antarapeyyāla 十二品共用的（义注：“dvādasa antarapeyyālavaggā”），第一导师经（§593，不在本 chunk）以及后面 sikkhā karaṇīyā 等各品也要同步改。建议在 harmonize 时整批处理。
- **paṭipadā 的译法**：§604 译作“道路”，容易与 magga（“道”／八正道）混淆。第四谛 dukkhanirodhagāminī paṭipadā 的传统译法是“道迹”。建议改为“道迹”，定案后登记到 `terms.md`。
- **与第一导师经对齐**：§595–§603 的“（中略）”省去的正是第一经（§593）的完整句式。§604 是本 chunk 里唯一完整展开的一段，它的措辞（集起／灭尽／了知／应当寻求）必须与 §593 逐字一致。本 chunk 看不到 §593，需要 harmonize 核对。

## §596 句 168-596-2-15
- **问题**：误读 — “不如实地见到有的人”会被读成“不如实地见到某些人”，bhava（有）的意思完全丢失。
- **建议**：（3）比丘们，对“有”不如实地知道、不如实地见到的人，……（中略）……。（“有”作为术语单独出现时容易被读成动词，这里可以加引号；其他各段是否也加引号由 harmonize 统一决定。）

## §595 句 168-595-2-16
- **问题**：歧义 — “见到生的人”可以读成“见到活人／生人”。
- **建议**：（2）比丘们，对生不如实地知道、不如实地见到的人，……（中略）……。

## §597 / §599 / §600 / §603（168-597-2-15、168-599-2-15、168-600-2-15、168-603-2-15）
- **问题**：歧义 — “取的人”“受的人”“触的人”“识的人”都会读成“拿取的人／承受的人／接触的人／认识的人”。
- **建议**：按跨段一致性第一条，改为“对取／受／触／识不如实地知道、不如实地见到的人”。

## §598 / §601 / §602（168-598-2-15、168-601-2-16、168-602-2-15）
- **问题**：句式统一 — 双音节术语（渴爱／六处／名色）本身没有歧义，但要与其他各段保持同一句式。
- **建议**：改为“对渴爱／六处／名色不如实地知道、不如实地见到的人”。

## §604 句 168-604-2-19 / 168-604-20-29 / 168-604-30-40
- **问题**：句式统一 — 同跨段一致性第一条。
- **建议**：
  - “比丘们，对诸行不如实地知道、不如实地见到的人，为了如实地了知诸行，应当寻求导师；”
  - “对诸行的集起不如实地知道、不如实地见到的人，……”
  - “对诸行的灭尽不如实地知道、不如实地见到的人，……”

## §604 句 168-604-41-55
- **问题**：术语 ＋ 句式 — paṭipadā 译作“道路”，与 magga 相混；“不如实地见到导向诸行灭尽的道路的人”连用两个“的”，读起来拗口。
- **建议**：“对导向诸行灭尽的道迹不如实地知道、不如实地见到的人，为了如实地了知导向诸行灭尽的道迹，应当寻求导师。”
