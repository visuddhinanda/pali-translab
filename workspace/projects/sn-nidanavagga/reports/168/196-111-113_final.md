**准确性**：整体理解扎实。`41-48` 的反诘句（`Aññathā kathaṃ … na jānanti`）译作“不然的话，连外道又怎么会不了知老死是苦呢”，语气与逻辑都到位；`49-59`/`60-63` 的 `keci` 引述与破斥、`99-103` 的 `yojanā`（“文句应当这样连读”）、`108-117` 的 `visesanabhāvena`（“作为限定语”）都处理准确。主要扣分在两处：`84-98` 把 `sataṇhā eva jāti jarāmaraṇassa samudayo` 按印本合成词读成“生是**生**老死的集起”，产出自指的循环命题；`118-140` 把省略引语的首词 `ariya` 补成“圣道”，是补足而非直译。

**风格符合度（本项扣分最重）**：主体是合格的现代书面汉语，无“此中/故为/彼等/是故”一类文言腔，标点与引号全部为全角、`zh` 字段无 ASCII 引号，符合 JSON 安全硬约束。但存在**一个系统性问题：正文里散布 4 处原文没有的圆括号夹注**——`（因而是沙门）（因而是婉罗门）`（按：`（因而是婆罗门）`）、`（粗显的）`、`（立名之由）`、`（所以只有十一处）`。style.md 只授权“术语首次出现夹注巴利原词”这一种圆括号用法（如 `（attabhāva）`，该处用法正确）；其余两类都越界：一类是插入释义性论证，一类是同一个词并列两个候选译法——后者实质上是**残留的草稿标记**，按 style.md 第七节“译文里不留任何工作标记”应清除，不确定就压低 `confidence` 并写进报告。其中 `（立名之由）` 本身还是文言短语。此外 `141-166` 全句“是依某个转起的根据……而确立在各自的意义上的”翻译腔较重，`转起` 恰是评估细则点名的语意不明确词。

**一致性**：术语层面稳定——samaṇa=沙门、brāhmaṇa=婆罗门、taṇhā=爱（未与“渴爱”混用）、jāti=生、samudaya 分辨“集谛/集起”得当；`vasena` 统一作“就……而言”；被释词体例统一为「**X**，指的是 Y」；`āha/vuttaṃ …ti` 统一作「所以说“X”」。扣分点是圆括号夹注的使用无统一标准（四处四种功能），以及 `111` 与 `113` 的篇题译法虽内部自洽，但未经与义注层比对。

## 问题清单

### 🟧 error

- `196-112-84-98`｜错译（修饰关系 / 断句）｜片段「唯有连同爱的生，才是生老死的集起」
  - 问题：按此译，“生”成了“生老死”的集起，命题自指、逻辑不通。原文 `sataṇhā eva jātijarāmaraṇassa samudayo` 更可能应断作 `sataṇhā eva jāti | jarāmaraṇassa samudayo`——“唯有连同爱的生，才是老死的集起”，这才承接上文“老死的集是生”“生即是爱”的论证链，也才解释得通为何要说 `saha taṇhāya`。
  - 建议：回查义注该句的原句读，若确为上述断句，改为“唯有连同爱的生，才是老死的集起”；若印本合成词有据，需在理由中给出能消解自指的解释。
- `196-112-118-140`｜错误多译（黑体引语补字）｜片段「**圣道……乃至……也是婆罗门法**」
  - 问题：原文省略引语首词只有 `ariya`，译文补成“圣道”；末尾 `brahmaññañca` 的 `ca` 被译成“也是”，也超出原文。黑体被解释词须与义注译文逐字同源，擅自补足会与父层对不上。
  - 建议：取义注该处译文原样回填（若义注作“圣八支道”，则黑体应为“圣……乃至……以及婆罗门法”一类逐字对应形式），不要在引语内自行补词。
- `196-112-2-36`｜错误多译｜片段「息灭了恶（因而是沙门）、遣除了恶（因而是婆罗门）的状态」
  - 问题：`samitabāhitapāpataṃ` 只说“息灭、遣除了恶的状态”，两处“（因而是沙门）（因而是婆罗门）”是译者补入的词源论证，原文没有，且未标为译注。
  - 建议：正文只保留“息灭了恶、遣除了恶的状态”；词源关联若要保留，移作脚注（走 pali-footnote），不留在正文括号里。
- `196-112-167-174`｜错误多译｜片段「（所以只有十一处）」
  - 问题：原文 `avijjāsamudayassa anuddhaṭattā` 只给出理由，没有“所以只有十一处”这一推论句；补入的结论进入正文且无标记。
  - 建议：删去括号内容，或改为脚注。

### 🟨 warning

- `196-112-84-98`｜残留候选译法｜片段「是明显可见的（粗显的）老死」
  - 问题：同一个 `pākaṭa` 并列给出两个译法，是草稿状态的候选标记，违反“译文不留工作标记”。
  - 建议：二选一（建议“粗显的”，与“刹那的”对举更清晰），删掉另一个。
- `196-112-141-166`｜文言语体｜片段「（立名之由）」
  - 问题：括号内是文言短语（“之由”），且同样是 `pavattinimitta` 的第二个候选译法，双重问题。
  - 建议：删去括号，正文改用现代表达，如“得名的根据”。
- `196-112-141-166`｜关键词语意不明确｜片段「是依某个转起的根据」
  - 问题：“转起”属细则点名的语意不明确词，脱离括号夹注后普通读者无法理解 `pavatti-nimitta` 指“词得以适用（转起）于某义的依据”。
  - 建议：改为“是依据某个使它得以用于该义的理由”一类明说的表述。
- `196-112-64-83`｜关键词语意不明确｜片段「在一个又一个有当中的最初出生」
  - 问题：单字“有”（bhava）孤立出现，无夹注，一般读者读不出是“生存/有”。
  - 建议：首次出现补巴利夹注，作“在各个有（bhava）当中的最初出生”。
- `196-112-141-166`｜关键词语意不明确｜片段「所以说“**这两个词中**”」
  - 问题：`ubhayatthāpi` 是处格“在两者当中”，上文讨论的是两个词各自**确立的意义**（`sake atthe niruḷho`），译作“这两个词中”把所指窄化到“词”，可能与义注原意不符；且此处是黑体引语，须与义注译文一致。
  - 建议：核对义注该处，若指两义则改为“在两者当中”一类不预设所指的译法。
- `196-112-2-36`｜汉语语病（重复）｜片段「即使身处外道的形相之中，也正因为他们即使处在那种形相中也具备这种能力」
  - 问题：两个“即使”叠用，“也”出现三次，`ṭhitāpi` 的让步义被重复表达一次。
  - 建议：改为“即使身处外道的形相之中，也正因为他们在那种形相中同样具备这种能力……”。

### 🟦 suggestion

- `196-112-2-36`｜复杂嵌套句，对读者不友好｜片段「也正因为他们即使处在那种形相中也具备这种能力，着眼于将来会有的息灭了恶、遣除了恶的状态，仍被认作是沙门、被认作是婆罗门」
  - 问题：一个句子里套了原因、着眼对象、结论三层，主语中途从“他们”隐性转到“（人们）认作”，读到句末才落地。
  - 建议：拆为两句，如“……也同样具备这种能力。着眼于他们将来会有的……状态，人们仍把他们看作沙门、看作婆罗门。”
- `196-112-64-83`｜语言表达不够流畅｜片段「而就相续来说，它就是爱；那个生正是爱」
  - 问题：原文本身反复，但中译两句几乎同义重出，读来像重复而非递进。
  - 建议：作“而就相续而言，它无非就是爱——那个‘生’本身即是爱”，以破折号标出后句的强调关系。
- `196-112-141-166`｜不常用术语没有注释｜片段「为了随顺所化者的意乐」
  - 问题：“所化者”“意乐”（veneyya / ajjhāsaya）对混合读者偏生僻，未夹注也未加注。
  - 建议：首次出现夹注巴利原词，或改作“为了顺应受教者的意向”。
- `196-112-2-36`｜语言风格不统一｜片段「**无力通达诸谛**」

  - 建议：核对义注译文，若无冲突则统一为“不能通达诸谛”。
- `196-111-2-4`｜语言风格不统一（跨层）｜片段「3. 沙门婆罗门经义注」

  - 建议：取义注层对应标题译文比对，两层保持完全一致。
