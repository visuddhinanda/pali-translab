## 跨段一致性

- `daṇḍa`：§891 标题译「杖」，§892 正文译「木杖」 → 建议统一。倾向正文保留「木杖」（现代读者更易解），标题相应作「木杖经」；或正文首见作「杖（daṇḍa）」。依据：同一篇内同一词的指称应可直接挂钩。
- `sandhāvataṃ saṃsarataṃ` / `sandhāvantā saṃsarantā`：词汇译法一致（「奔走、轮转」✅），但**句法处理不一致**——§892 句 19-28 译为主句谓语「众生不停地奔走、轮转，他们……」，§892 句 48-72 译为状语「众生在不停地奔走、轮转的时候」。原文两处都是与 `sattā(naṃ)` 同格的现在分词，属同一结构。建议统一为定语/状语式（以 48-72 的处理为准），改 19-28 为「……的众生，其最初的起点无法知晓」类结构。
- `anamatagga` 与 `pubbā koṭi`：两者分别译「没有可知的起点」「最初的起点」，两次 `anamatagga`（句 2-18、句 77-90）译法完全一致 ✅。惟「起点」一词同时承担两个不同巴利词，**待义注核**（义注对 `anamatagga` 的构词分析决定它该译「无始」还是「起点不可知」）。
- `imaṃ lokaṃ / paraṃ lokaṃ`：两处对举均作「这个世界／另一个世界」，一致 ✅，且避开了 `style.md` 禁用的「此世／彼世」文言写法，处理得当。
- **语体**：全 chunk 逐句扫描文言虚词（之／其／乃／便／即／谓／於／遂）与文言句式，**未发现文言或半文半白**；标点全角、无 ASCII 引号，符合 JSON 安全硬约束 ✅。

## §892 句 168-892-2-18

- **问题**：省略主语 — 「住在舍卫城……」全句无主语，中文读来悬空（原文 `viharati` 由动词人称承担，汉语无此手段）。按 `style.md` 六「不擅自补足省略主语（**除非语义必须**）」，经首套语属语义必须的情形。nissaya 通常会补出施事（`ဘဂဝါ= …သည်`），本轮缺 nissaya，无法据以确认。
- **建议**：补出为「（世尊）住在舍卫城……」或「世尊住在舍卫城……」，取哪种取决于项目对套语补字的惯例；存疑保留，不必视为必改。

## §892 句 168-892-19-28

- **问题**：增译 — 「不停地」在原文无对应词（`sandhāvataṃ saṃsarataṃ` 只是「奔走、轮转」的现在分词），属译者补出的语气成分。义理上不违背，但属无据增译。
- **建议**：可保留（两处一致，且不致误导），若求严谨则删去「不停地」，靠「奔走、轮转」并列本身表达持续义。
- **问题**：语义冗余 — 「最初的起点」中「最初」与「起点」义重。
- **建议**：改「起点无法知晓」，或按义注取义改为「最初的边际无法了知」（**待义注核**）。
- **问题**：句法结构与句 48-72 不一致（见「跨段一致性」）。
- **建议**：改为「被无明遮蔽、被渴爱束缚、奔走轮转的众生，他们最初的起点无法知晓。」

## §892 句 168-892-29-47

- **问题**：增译 — `sakimpi mūlena nipatati` 中的工具格表示「以某一端着地」，译文三处均作「先落地」，「先」字为补出。原文强调的是**落地时触地的部位**，不是先后次序。
- **建议**：改作「有时根部着地，有时中间着地，有时末端着地」。
- **问题**：`mūla` / `anta` 的具体所指（杖的粗端／细端）由义注给定，本轮无从核验。「根部／末端」是合理推定但未经证实。
- **建议**：暂留，取到义注后复核；若义注明言粗细两端，宜改为更直白的说法（如「粗的一头／细的一头」）。

## §892 句 168-892-77-90

- **问题**：**语气误读（必改项）** — `alaṃ vimuccituṃ` 是 `alaṃ` + 不定式的劝诫式结构，意为「足以（应当）解脱」，是对听者的策励；译文「**已经**足以从中解脱**了**」用「已经…了」把它变成了对既成事实的陈述，语气与原文相反。
- **建议**：改为「足以解脱了」或「就足以解脱了」，去掉「已经」。
- **问题**：指代悬空 — 「从中」的先行词在原文中是被 `…pe…` 省去的 `sabbasaṅkhāresu`（一切行），中译保留「从中」而先行词并未出现，读者无从落实「中」指什么。
- **建议**：删去「从中」（作「足以解脱了」），或补出省略内容「足以厌离一切行……足以解脱了」——后者须先经义注/全经套语确认再定，本轮不宜擅自展开。
