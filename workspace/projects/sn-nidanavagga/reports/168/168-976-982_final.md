## 理由

**资源缺失（降级说明）**：本次评估**未取到义注（aṭṭhakathā），也未取到 nissaya**，注入的资源只有巴利原文与 channel 译文。因此「以义注定释义、以 nissaya 定词法」两条基准都无法执行，准确性判断只能依据巴利原文本身的词法与句法、以及上下文（尤其 SN 16 相应内部的平行段）。信心指数据此压到 68——特别是下面 🟧 一条（`nibbasanāni`）必须回查义注才能定案。

**准确性**：句子骨架、格与句法角色整体正确，`ceva … ca vaṇṇavādī` 的「自己如此行 + 并称赞如此行」双支结构在十个头陀支项目上逐一落实，没有漏项；`dve atthavase` 的两条理由（现法乐住 / 悲悯后人）切分准确，`appeva nāma … āpajjeyyuṃ` 的愿望语气、`paṭipajjissanti / bhavissati` 的未来时都译对了。主要扣分在 `nibbasanāni` 一词被译成「世尊穿过后脱下的」，这是原文字面没有的施事补出，且出现两次、两次都在佛陀自己口中，属未经标注的增译（详见问题清单）。另有一处代词指代在汉语里会指向错误对象。

**风格**：现代书面汉语落实得好，通篇没有文言虚词与文言句式，`Sādhu sādhu` 译「好啊，好啊」而非「善哉善哉」、`Tasmātiha` 译「所以」、`nimantanāni bhuñjāhi` 译「接受别人的邀请去吃饭」都符合 `knowledge/style.md` 第一节的硬约束。标点全角，引号统一用 “ ” ‘ ’，未出现 ASCII 引号或「」，JSON 安全。术语处理符合混合策略：粪扫衣 / 三衣 / 少欲 / 知足 / 现法乐住等沿用传统汉译，`现法乐住（diṭṭhadhammasukhavihāra）` 首次出现夹注巴利原词且用全角圆括号。译文中无任何残留工作标记。

**一致性**：十支头陀的固定译语在 978 / 979 / 980 / 981 四段反复出现，用词完全一致，省略号（`… pe …` → 「……（中略）……」）处理方式统一；977 与 982 首尾呼应的 `sāṇāni paṃsukūlāni nibbasanāni` 译法也保持一致（虽然一致地错，见清单）。小瑕疵是 `sampassamāno` 在 979 作「着眼于」、在 980/981 作「看到了」，同一问答对里同一个词换了译法。

## 问题清单

### 🟧 error

- `168-977-39-54`｜错误多译（增译施事，待义注核实）｜片段「世尊穿过后脱下的麻布粪扫衣」
  - 问题：原文 `sāṇāni paṃsukūlāni nibbasanāni` 三个中性复数形容/名词并列修饰同一对象，`nibbasana` 的基本义是「（穿旧后）脱下、废弃的衣物」，主语即迦叶自己所穿；译文补出了原文没有的施事「世尊」，把它读成佛陀换给迦叶的旧衣。这一读法或许有《衣经》（SN 16.11）的背景，但本段巴利没有任何成分支持，属未标注的增译。更直接的问题是：本句说话人就是佛陀，译文却让佛陀称自己为「世尊」，人称错乱。
  - 建议：回查本段义注对 `nibbasanānī`ti 的释文再定案。义注若无「佛陀所赠」之说，改为「你这些已经穿旧的麻布粪扫衣」；义注若确有此说，也应把背景放进脚注，正文不补施事。
- `168-982-24-45`｜错误多译（同上，第二处）｜片段「继续穿那些世尊穿过后脱下的麻布粪扫衣」
  - 问题：与上条同源，且同样出自佛陀自己的话，「世尊穿过」在此处的人称冲突更明显。另外三个 `ca` 连接的祈使句都加了「继续」，原文 `dhārehi / carāhi / viharāhī` 只是祈使，「继续」是依上下文的补足——在此语境下可接受，但需与上条一并核定后统一。
  - 建议：与 `168-977-39-54` 采用同一改法，保持首尾一致。

### 🟨 warning

- `168-980-136-146`｜代词指代不明确｜片段「他们就会照着那样去修行」
  - 问题：巴利 `Te` 指的是 `pacchimā janatā`（后来的人），但汉语里这句紧接在引号内「……也称赞发起精进。’」之后，最近的先行词是「跟随佛陀而觉悟的弟子们」，读者极易把「他们」理解成那些弟子，而弟子恰恰不是「照着榜样去修行」的一方。
  - 建议：把先行词显化，例如「后来的人就会照着那样去修行」。

### 🟦 suggestion

- `168-979-2-57`｜语言风格不统一｜片段「着眼于什么理由」
  - 问题：同一个 `sampassamāno`，979 作「着眼于」，980「我是看到了两个理由」、981「我就是看到了这两个理由」作「看到」。问与答用词不接榫，削弱了这一组问答的回环结构。
  - 建议：三处统一，例如都用「看到」：「你是看到什么理由，才长久以来……」。
- `168-980-79-135`｜时态提示不足｜片段「长久以来一直住在林野」
  - 问题：此处动词是过去式 `ahesuṃ`，说的是已故的随佛觉悟的弟子；汉语「长久以来一直」偏向延续到现在，与上文「听说那些……弟子们」的追述语气略有拉扯。
  - 建议：加一个时间标记，如「当年长久地住在林野」。
- `168-978-2-73`｜语言表达不够流畅｜片段「一直不与人交往混杂」
  - 问题：`asaṃsaṭṭha` 的对译「交往混杂」两个动词/形容成分叠用，读来滞涩，且该短语在 978–981 重复出现五次，滞涩感被放大。
  - 建议：改为「不与人混处」或「不与人来往厮混」一类更顺的说法，四段同步替换。
- `168-977-55-83`｜该使用而没有使用术语标记｜片段「穿在家人施与的衣服」
  - 问题：`gahapatāni cīvarāni` 是与「粪扫衣」相对的固定范畴（居士施衣），译作泛称的「衣服」后，与同段「粪扫衣」的术语对举关系消失了。
  - 建议：改为「居士施与的衣（cīvara）」或「在家人施与的袈裟」，保住与粪扫衣的对照。
- `168-980-59-78`｜代词指代可能不够明确｜片段「跟着这样的榜样去做」
  - 问题：`diṭṭhānugatiṃ āpajjeyyuṃ` 是「效法所见到的（做法）」，译文的「这样的」所指要跨到上一句才能落实。
  - 建议：明确为「跟着（我）所做的样子去做」或「效法他们所看到的做法」。
