## 一、被解释词与父层逐字核对（首要）

整体状况良好，绝大多数黑体词与父层定稿逐字一致：究竟智 / 阿罗汉果 / 在光明上 / 心因这些而颤动 / 在现起上 / 这十种情况 / 凡是智慧熟习了 / 法掉举 / 不会…陷入迷乱 / 就叫做相似的证悟正法 / 《界论》 / 《毗陀罗藏》 / 不是佛所说的话 / 卖不出去 / 真金 / 不能 / 在佛陀成道后的最初时期 / 两藏 / 仍然没有隐没 / 什么原因呢 / 是行道的条件 / 行道是证果 / 不奉行教法的比丘 / 这里 / 在奉行 / 这四界当中 / 所以 / 这样说。以下为不一致或需定夺的几处。

### 1. `196-765-6-11`、`196-765-53-61`：**Upekkhāya ca** 译「在舍上」，父层无此对应（必改项，需跨层定夺）
- **问题**：父层 `134-764` 把 `Upekkhāvajjanāya ceva, upekkhāya ca nikantiyā` 译为「也在**舍与转向**上，在**对舍的欲求**上」——把 `upekkhāya` 读成修饰 `nikanti` 的属格。而本层复注明确拆成三项：`Upekkhāya cā ti vipassanupekkhāya ca`（舍＝观舍，独立一项）、`Upekkhā ti āvajjanupekkhā`（`upekkhāvajjanā` 是一个复合词＝转向舍）、`Nikanti nāma vipassanāya nikāmanā apekkhā`（欲求是**对观**的贪求，不是对舍的）。
- 三处冲突同源：父层把复合词 `upekkhāvajjanā` 拆成「舍与转向」两项，又把独立的 `upekkhāya` 并进 `nikanti` 读成属格，导致十随烦恼的项数与复注对不上。
- **建议**：本层译文按复注读法（在舍上／转向舍／对观的欲求）是对的，不要改成迁就父层；把父层 `134-764` 的分歧记入统稿单，由 harmonize 决定是否回改父层为「也在转向舍上，在舍上、在欲求上」。审稿阶段不动译文。

### 2. `196-766-2-11`：**这十种情况** 与复注释义相左（报告项，不改本层）
- **问题**：复注释 `ṭhānāni` 为 `upakkilesuppattiyā ṭhānāni upakkilesavatthūni`（随烦恼生起的**处所／依处**），父层译作「情况」。黑体必须跟父层，所以本层保留「这十种情况」正确，但同一句里紧接着自释为「处所」「依处」，读者会看到黑体与释义脱节。
- **建议**：列入统稿单，建议父层 `134-765` 改「这十种依处」或「这十处」，本层黑体同步。本步不改。

### 3. `196-772-10-16`：**不奉行教法的比丘** 与复注释义偏离（报告项）
- **问题**：复注 `sīlamattassapi na ārādhako dussīlo`——`anārādhaka` 是「连戒都不能**成就**」，落点在成就/圆满，不在「奉行教法」。父层译「不奉行教法的比丘」把范围放宽了。
- **建议**：记入统稿单，建议父层考虑「不成就（戒行）的比丘」一类译法；本层黑体暂维持与父层一致。

### 4. `196-771-39-44`：**教理才是标准**（轻微）
- **问题**：本句所注的是父层 `134-771-87-91`「即使就行道而言，也仍**以教理为标准**」，措辞与黑体「教理才是标准」不逐字同。同一短语在 `134-772-74-126` 作「教理无疑才是标准」。
- **建议**：择一锚定并写进统稿单——保留现译则统一到 `134-772` 的措辞（去掉「无疑」后正好是「教理才是标准」），可接受；若锚 `134-771`，应改为「以教理为标准」。

### 5. `196-770-54-67`：**Tadā** 译「那时」（轻微）
- 父层 `134-770-48-63` 的 `tadā` 落在「当……的时候」句式里，没有独立的「那时」二字。现译可读，不必改，但统稿时留意黑体首词的锚点。

## 二、跨段一致性

- **paṭipatti**：`196-770-25-36` 译「修行」（**圆满了修行**），`196-771-27-33 / 34-38` 译「行道」（**是行道的条件**／**行道是证果**）。两者都是被解释词，分别锚定父层 `134-770`（修行）与 `134-771`（行道）——**不一致是父层带进来的**。本层不宜单方面改动；请在统稿单注明：建议散文中的 `paṭipatti` 统一作「行道」，只保留复合词 `paṭipattisaddhamma`＝「修行正法」，届时三层一起改。
- **段首经号**：`196-763-2-15` 把 `156.` 译为「一五六。」，父层 `134-760` 的 `156.` 直接略去（只作「第十三经中」）。建议全书统一——要么两层都保留阿拉伯数字「156.」，要么两层都略去。
- **māna 系词**：`196-766-22-37` 的 `adhimāna` 译「增上慢」，`196-767-2-7` 的 `māni-bhāva` 译「自以为已经证得的心态」。同一语义群建议统一为「慢」系措辞，后者可作「自以为已经证得的慢心」。
- **ñāṇa／paññā**：全 chunk 稳定作「智／智慧」✅。**upakkilesa**＝随烦恼、**vipassanā**＝观、**vikkhepa**＝散乱、**osakkita**＝衰退（与父层 `134-772` 同）✅。
- **标点**：全 chunk 均为全角标点与弯引号 “ ”，未见 ASCII 引号 ✅。译文中无候选/待定/问号等工作标记 ✅。
- **语体**：整体现代书面汉语 ✅，仅 `196-771-34-38` 一处文言残留（见下）。

## 三、逐句问题

### §763 句 `196-763-2-15`
- **问题**：释义脱落 — 本句是 `aññā` 的构词释（nirutti）：`Ājānāti … jānāti paṭivijjhatī ti aññā`，起首的 `Ājānāti`（以 ā- 前缀表「彻底地知」）是词源落点，现译直接并入后半句，读者看不出「究竟智」这个名字从何而来。
- **建议**：补出词源环节，例如「**究竟智**（aññā）得名于『彻知』（ājānāti）：不超越下面各道所了知的界限而了知、通达，所以叫做**究竟智**，也就是最上道的智慧。」黑体部分保持不变。

### §763 句 `196-763-16-21`
- **问题**：可读性 — `Aññassa ayan ti aññā` 是同形异释（`aññā` 第二义＝「究竟智的到来」，指果），现译「究竟智的到来，所以叫做**究竟智**」在中文里成了同语反复，读者无从看出这是第二种构词解释。
- **建议**：点出是另一种解释并夹注词根，如「另一方面，『究竟智的到来（aya）』也叫做**究竟智**，指阿罗汉果。」

### §764 句 `196-764-6-16`
- **问题**：`padadvaya` 指的是巴利的两个词（`cittaṃ` 与 `vikampati`），中文「“心会动摇”**这两个词**」对不上字面——中文那是四个字、一个短句。
- **建议**：改为「要把『cittaṃ vikampati（心会动摇）』这两个词引过来构成关联」，或淡化词数：「要把『心会动摇』一语引过来与前句相连」。

### §765 句 `196-765-12-18`
- **问题**：歧义 — 「超出**观心所等起**的相续之外」中的「观心所」极易被读成「观**心所**（cetasika）」，而原文是 `vipassanācitta-samuṭṭhāna`（由观**心**等起）。
- **建议**：改为「由观心等起、超出（自身）相续之外而放光的色处」。

### §765 句 `196-765-23-29`
- **问题**：措辞 — `saddhādhimokkha` 译「信的胜解」略生硬。
- **建议**：「就是由信而起的胜解」或「就是信胜解」，并在术语表登记 `saddhādhimokkha` 的定译。

### §765 句 `196-765-53-61`
- **建议**：`anena … evaṃ vuttā` 的「以这个词」落点未译出，可作「这里是用这个词就它的平等中立而如此称说的」，与上一句「再一次说的」呼应更清楚。

### §767 句 `196-767-2-7`
- **建议**：`adhigatamāni-bhāva` 的「慢」义建议显化，改「因为它会带来在没有证得时自以为已经证得的**慢心**」，与 §766 的「增上慢」形成术语呼应（见跨段一致性）。

### §767 句 `196-767-44-55`
- **问题**：主语与句义存疑 — `Tattha sallaṃ upaṭṭhapenti` 现译「在这一点上**他们**提出了诘难」，主语「他们」在中文里无着落（上一句主语是「正觉者」），读者会误以为是佛陀一方在诘难。`sallaṃ upaṭṭhapenti` 字面是「立起箭（刺）」，作「提出诘难」是解释性译法。
- **建议**：明确主语并降低该句 confidence，如「关于那些书，（论师们）提出这样的责难：其中看不出有调伏烦恼的作用，反而成为烦恼生起的条件。」另见第四节存疑条。

### §768 句 `196-768-2-6`
- **问题**：时体 — `vikkayaṃ agacchantaṃ` 是「（当时）没有进入交易」的现在分词，译「就是没有**被**卖掉」带被动完成味，与黑体「卖不出去」时态不贴。
- **建议**：「就是卖不掉、没有成交」。

### §770 句 `196-770-25-36` ＋ `196-770-37-39`
- **问题**：问答脱榫 — 前句译成「是问：过去他们是在**什么时候**圆满……的呢？」，后句答语却是「就是在佛陀成道后最初时期的那些**比丘**」，问「何时」答「何人」。而紧接的 `196-770-40-48`（离开正确立志与过去所作福德就不会有那样的成就）表明答案的落点在**过去世的立志与福德**。
- **建议**：把答句的省略补出、扣回问句，例如「（那是）佛陀成道后最初时期的那些比丘（在过去世所圆满的）。因为离开了自己的正确立志和过去所作的福德，就不会有那样的成就。」若不愿补主语，至少把两句连成一个因果链。

### §771 句 `196-771-7-11`
- **问题**：句法 — `adhisīlasikkhāyaṃ ṭhitassa` 是属格（对安住于增上戒学的人而言），`itarasikkhādvaya-samuṭṭhāpitato` 的能引生者是波罗提木叉本身；现译把「引生」的主语给了「人」。
- **建议**：「因为它能使安住于增上戒学的人生起其余两种学」。（缺 nissaya，属格归属存疑，建议压低 confidence。）

### §771 句 `196-771-34-38`
- **问题**：**文言残留（必改）** — 「殊胜**之**相」用了文言虚词「之」，违反 `style.md` 第一节禁例。
- **建议**：改「因为它能通达各别的相状」或「因为它能通达殊胜的相」。另：`visesalakkhaṇa` 若取「各别相（自相）」义更贴观智语境，请在术语表定案。

### §773 句 `196-773-14-30`
- **建议**：`tasmā` 的回指可更清楚 —「**所以**，是说：既然……，所以（世尊）才这样说」，与父层 `134-773-42-53`「所以世尊这样说」的主语对齐。现译「所以才这样说」未点主语，尚可，但三层统稿时宜一致。

## 四、存疑与原文疑问（不改译文，记录备查）

1. `196-771-12-26` `anantaradhānaṃ`：可读作 `anantara-adhānaṃ`（随即隐没）或 `an-antaradhānaṃ`（不隐没）。现译取前者，与上下文（教理隐没则行道隐没）相符，但请压低该句 confidence，待核对别本。
2. `196-767-44-55` `kilesavinayaṃ na sandissati`：`kilesavinayaṃ` 为宾格，而 `sandissati` 需主格主语，疑原文当作 `kilesavinayo`（或 `na sandissate` 的被动读法）。疑似 VRI 讹误，记入 `known-issues.md` 第二节，不要径改。
3. `196-767-31-33` `Vādabhāsitan ti apare`：现译「异说者所讲的」。`vāda` 亦可指「（外道）论」「辩论」，另一读为「（只是）论师之说」。缺 nissaya 无法判定，建议压低 confidence 并在术语表留条。
4. `196-767-44-55` `sallaṃ upaṭṭhapenti`：直译「立起箭／刺」，作「提出诘难」属意译，暂无旁证。同上压低 confidence。
