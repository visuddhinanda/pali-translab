# Review — 168:768-783（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅经题、经号段与经末标记带 nissaya；正文重复句无逐词 nissaya）

## 跨段一致性

本 chunk 是三部结构相同的经（第8、9、10经）。三经的译法明显各自为政，同一巴利词在三经中译法不同。建议以第8经的译法为准统一，因为它出现次数最多，也最白话。

- **saṃsandanti samenti**：
  - 第8经（§769–774）译「走到一起、聚在一起」
  - 第9经（§776–779）译「会合、相聚」
  - 第10经（§781–783）译「聚合、结合」
  - → 统一为「走到一起、聚在一起」。这是全 chunk 出现最多的固定句式，三经应完全同译。
- **连词**：§776–779 用「与」，其余段用「和」 → 统一为「和」。
- **ahirika / hirimana**：
  - §769–770 译「没有惭的人／有惭的人」
  - §776–779 译「无惭的人／有惭心的人」
  - → 统一为「没有惭的人／有惭的人」。
- **anottappī / ottappī**：
  - §771、§781–783 译「没有愧／有愧」
  - §776 译「无愧」
  - §780 经题译「无愧」
  - → 正文统一为「没有愧」。经题见下文「经题」一条。
- **appassuta / bahussuta**：
  - §772 译「听闻很少／听闻很多」
  - §777 译「少闻／多闻」
  - §781 译「听闻少／听闻多」
  - → 统一为「听闻很少／听闻很多」。
- **duppañña**：
  - §769–779 译「智慧低劣」
  - §781–783 译「智慧差」
  - → 统一为「智慧低劣」。
- **āraddhavīriya**：
  - §773 译「精进的人」
  - §778 译「精进努力的人」
  - §782 译「已发起精进的人」
  - → 统一为一种。建议用「精进的人」，或者按字面统一为「发起精进的人」。
- **muṭṭhassati / upaṭṭhitassati**：
  - §774、§779 译「失去正念／正念现前」
  - §783 译「失念／念现前」
  - → 统一为「失去正念／正念现前」。
- **巴利夹注位置**：
  - 首次出现的术语夹注了巴利原词，但夹注不在本 chunk 的首次出现处。例如 dhātu、ahirika、anottappa 夹注在 §776，anottappa、appassuta、muṭṭhassati、upaṭṭhitassati 夹注在 §781 / §783。这些词在第8经都已出现过，却没有夹注。
  - §781 的「（anottappa，对恶行不知畏惧）」把释义写进了夹注，与体例「圆括号只附巴利原词」不符。
  - → 夹注统一放到各词在本 chunk 首次出现处，只附原词。后续经里的重复夹注删去。
- **Sāvatthiyaṃ viharati**：§769、§781 译「世尊住在舍卫城」，§776 译「住在舍卫城」 → 统一补「世尊」。
- **pe 标记**：第8、10经写「……（中略）……」，第9经（§776–779）只写「……」 → 统一为「……（中略）……」。
- **经题格式**：
  - §768 译「以没有信心为根本经」
  - §775 译「以无惭为根本的经」
  - §780 译「无愧根本经」
  - → 三题句式应一致。建议依次为「以没有信心为根本经」「以没有惭为根本经」「以没有愧为根本经」。
- **经末标记**：§774 译「第八经完」，§779、§783 译「第九经」「第十经」 → 统一（见 §774 条）。
- **小节编号**：第8、10经用「（一）（二）…」，第9经用「（1）（2）…」 → 统一为中文数字「（一）」。
- **结束引号**：
  - §781-53-64 与 §782-35-46 段末没有收引号。§783-35-43 有收引号。第8、9经的对应位置也有收引号。
  - → §781、§782 段末补「”」，与其他经一致。

## §774 句 168-774-50-54
- **问题**：增译。nissaya 为 `အဋ္ဌမံ= ရှစ်ခုမြောက်သောသုတ်တည်း။`（是第八经），没有「完」的意思。同 chunk 的 §779 `နဝမံ`、§783 `ဒသမံ` 也都只译作「第九经」「第十经」。
- **建议**：改为「第八经。（五）」。

## §775 句 168-775-2-4
- **问题**：经题词形。nissaya 为 `အဟိရိကမူလကသုတ်`，与 §768 `အဿဒ္ဓမူလကသုတ်`、§780 `အနောတ္တပ္ပမူလကသုတ်` 同构，都是「X-mūlaka」。但三处译文句式不一，本句又多出「的」字。
- **建议**：改为「以没有惭为根本经」，与 §768 同式，用词也与正文 ahirika 的统一译法一致。

## §776 句 168-776-2-37
- **问题**：
  - 跨段不一致集中在本句：漏「世尊」，缺「（中略）」，saṃsandanti samenti 译作「会合、相聚」，ahirika 译作「无惭」，用「与」。
  - nissaya 指明本经「以 ahirika 为根本、插入 anottappī 等，其余依前法」（`အဟိရိကကို မူတည်၍ … ရှေးနည်းမှီးပေး`）。也就是说，句式应完全沿用前经的译法。
- **建议**：按前经句式重写为：「103. 世尊住在舍卫城……（中略）……“众生正是依界而走到一起、聚在一起……（中略）……没有惭的人和没有惭的人走到一起、聚在一起，没有愧的人和没有愧的人走到一起、聚在一起，智慧低劣的人和智慧低劣的人走到一起、聚在一起；」。
- **连带**：§776–779 其余各句一并按「跨段一致性」一节统一。

## §780 句 168-780-2-4
- **问题**：经题句式与 §768 不一致（见 §775 条）。
- **建议**：改为「以没有愧为根本经」。

## §781 句 168-781-2-22
- **问题**：
  - nissaya 指明本经「以 anottappī 为根本、插入 appassuta 等，依前法」（`အနောတ္တပ္ပီကို မူတည်၍ … ရှေးနည်းမှီးပေး`），句式应沿用前经。
  - 本句把 saṃsandanti samenti 译作「聚合、结合」，与前经不同。
- **建议**：改为「……众生正是依界而走到一起、聚在一起的。」。§781–783 其余各句一并统一。
