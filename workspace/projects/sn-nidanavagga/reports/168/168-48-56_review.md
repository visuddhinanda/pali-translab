# Review — 168:48-56（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（`kimhi nu kho asati … ’ti ?` 问句各段均无 nissaya，已略过）

## 跨段一致性

- **Atha kho**：§48–54 每段首句（`…etadahosi`）译「接着」，同段第三句（`…abhisamayo`）译「于是」。nissaya 两处都作 `အထ ခေါ= ၌`（在那时），没有区分先后与因果的依据 → 建议统一为一种译法，例如两处都用「接着」，或两处都用「那时」。七段同形，改时须七段一起改。
- **yoniso manasikārā … paññāya abhisamayo** 句式：§48–54 共 7 处同译，问题相同，见下文 §48 句 168-48-29-41。改时须七段一起改。
- **nirodha**：§48–55 的条件句一律译「灭去」，§55 句 168-55-9-19 结句译「灭了」。属于句末收束，差异可以接受，列出供统稿参考。

## §48 句 168-48-29-41（同式：168-49-28-40 / 168-50-28-40 / 168-51-29-41 / 168-52-28-40 / 168-53-28-40 / 168-54-30-42）

- **问题**：格与句法。nissaya 的结构是：
  - `ဝိပဿိဿ= သော။ ဗောဓိသတ္တဿ= ၏`：菩萨为**属格**。
  - `ယောနိသော မနသိကာရာ= ဖြင့်၎င်း။ ပညာယ= ဖြင့်၎င်း`：如理作意与智慧都是**具格**，并且以 `၎င်း` 并列。
  - `အဘိသမယော= သည်။ အဟု= ပြီ`：「现观」是**主格**主语，`ahu` 是谓语「生起了」。
  
  句意是「毗婆尸菩萨的现观，通过如理作意和智慧而生起」。译文有两处与此不合：
  1. 把主语「现观」改成了动词「现观到」，又把属格的菩萨提成主语。
  2. 两个并列的具格成分分用「由于」（因果）和「以」（手段），并列关系没有体现出来。
- **建议**：恢复「现观」作主语、`ahu` 作谓语，两个具格同等并列。例如：「比丘们，那时，由于如理作意、由于智慧，毗婆尸菩萨生起了现观——」。七段一起改。

## §55 句 168-55-9-19

- **问题**：漏译。nissaya 作 `ဧတဿ ဒုက္ခက္ခန္ဓဿ= ၏`，即「这个苦蕴的」，指示词 `etassa` 在译文中没有体现。另外，`ဣဒံအယံ နိရောဓော= ဤချုပ်ကြောင်းသည်။ ဟောတိ= ဖြစ်၏` 以「灭」为主格主语、`hoti` 为谓语；译文把它改成了动词句「就灭了」。意思不变，可以接受。
- **建议**：补出「这」，例如「这样一来，这整个苦蕴就灭了。」

## §55 句 168-55-20-51

- **问题 1**：句法。`နိရောဓော နိရောဓောတိ ခေါ= ချုပ်ခြင်း ချုပ်ခြင်း ဟူ၍` 中的 `ဟူ၍` 是副词性引语（「如此地／就此」），说明菩萨是就「灭，灭」生起了眼、智等。译文用破折号把「‘灭，灭’」悬在句首，与后文没有句法联系，读者可能误以为「灭，灭」就是生起的东西。
- **建议**：把引语与后文连起来，例如：「比丘们，毗婆尸菩萨想到‘灭，灭’时，对于以前从未听闻过的法，生起了眼……」。
- **问题 2**：异释。nissaya 给出 `ဝါ= ချုပ်ကြောင်းချုပ်ကြောင်း`，即「灭因、灭因」。
- **建议**：依 style.md 第四节，异释作脚注备列，正文保持「灭，灭」。
