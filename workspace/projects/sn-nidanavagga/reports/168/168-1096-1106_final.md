## 理由
- **资源缺失**：本次注入的数据只有巴利原文和现有译文，没有义注（aṭṭhakathā）和 nissaya。评估只能依据巴利原文、本经上下文和相应部同类经文的惯常解读，无法逐词核对格位和传统取义，所以信心指数下调。有偈部分（1099–1102）的取义最该对照义注复核。
- **准确性**：散文部分（1097）主谓宾、格位关系判断都正确。三种情况（受恭敬 / 不受恭敬 / 两者兼有）的对应准确，“身体破坏、命终之后……”这一套句也完整。偈颂 1099–1102 在巴利原文里是一个完整的关系句（yassa … taṃ … āhu sappuriso）。译文拆成几句来译，整体意思没有偏离。1100 把校勘注当作正文译出了，内容本身没有译错，但位置不当。yogakkhema 译成“安稳”，丢掉了“轭”这层术语含义，属于可提升项。
- **风格**：总体是现代书面汉语，通顺，没有明显的文言虚词。“以无量而住”带有半文半白的句式。1101–1102 的定语链很长，“乐于取的灭尽”读起来稍显别扭。
- **一致性**：“利养、恭敬、名声”“可怕”“受到恭敬 / 不受恭敬”在全段统一。“有偈”在经题（1096）和摄颂（1106）中前后一致。摄颂中的各经题无法与本 channel 前九经的实际经题比对，没有核验。

## 问题清单

### 🟨 warning
- `168-1100-2-22`｜整句逻辑表达不规范｜片段「（异读作“以不放逸而住”，见 pī.、ka. 本；这里的“无量”指果定，不是念。）」
  - 问题：原文方括号里是校勘注（异读和编者说明），不属于偈颂正文。直接译进正文，打断了偈颂，读者也不清楚 pī.、ka. 指什么。
  - 建议：正文只保留偈句，校勘内容改为脚注（交给 pali-footnote 处理），并说明版本缩写的含义。
- `168-1100-2-22`｜文言语体｜片段「以无量而住」
  - 问题：“以…而住”是半文半白的句式。
  - 建议：改为“安住在无量（定）中的人”一类的现代表达。

### 🟦 suggestion
- `168-1097-2-23`｜不常用术语编写注释或者百科｜片段「无上的安稳」
  - 问题：yogakkhema 通译“瑜伽安稳 / 离轭安稳”，指涅槃。只译“安稳”，术语含义没有体现出来。
  - 建议：改为“无上的离轭安稳”，首次出现时夹注巴利原词（yogakkhema）。
- `168-1100-2-22`｜代词指代可能不够明确｜片段「他的定都不因此动摇」
  - 问题：原文 yassa…taṃ… 是关系句，“他”在上句没有先行词。“因此”是译文额外补出的。
  - 建议：改为“这样的人，他的定都不会动摇”，并去掉“因此”，与 1101 的“那位……”呼应得更清楚。
- `168-1101-2-10`｜语言表达不够流畅｜片段「以微细的知见进行观察」
  - 问题：diṭṭhi 在这里宜译为“见”。“知见”容易和 ñāṇadassana 混淆。vipassaka 可以考虑与“观 / 毗婆舍那”的术语对应。
  - 建议：改为“以微细的见观照（vipassanā）”，具体以义注的解释为准。
- `168-1102-2-10`｜语言表达不够流畅｜片段「乐于取的灭尽（即涅槃）的人」
  - 问题：“乐于取的灭尽”容易被误读，读者可能把“取的”当作“乐于”的宾语，结构不清。
  - 建议：改为“以取的灭尽（即涅槃）为乐的人”。
- `168-1106-2-8`｜语言表达不够流畅｜片段「豺狼」
  - 问题：siṅgāla 指豺 / 野干（jackal）。“豺狼”在汉语中偏指狼，或者用作比喻义。
  - 建议：改为“豺”或“野干”，并与本品对应经题的译名保持一致。
