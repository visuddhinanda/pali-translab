## 理由

**基准缺失（先交代）**：本次评估对象本身就是义注层（134 = Manorathapūraṇī），任务未注入更上层的复注（ṭīkā）、也未注入 nissaya，更没有注入被释的本文（AN 9.38 mūla）。因此「义注定释义、nissaya 定词法」两条基准都不可用，只能依巴利原文与义注惯用释词体例判断。**被解释词（黑体）与父层逐字同译**这一硬约束无法核验——`134-282-14-19` 的「**这是第一种世间论**」、`134-282-36-42/43-57` 的「**一**」「**多**」是否与本文译文用字一致，须回头比对本文 channel 后才能定案。信心指数已据此下调。

**准确性**：整体取义稳，术语（诡辩论典 / 世间论 / 常见 / 断见 / 自性）选择有据，`58-85` 的四见归类完全对应原文对称结构，`imā dvepi` 的 `api` 也译出（「这两种都是」）。扣分集中在三处：`jeṭṭha` 被译成「第一种」，既丢了「最尊、最古」的词义，又混入原文没有的「种类」概念，还使随后的释词「是指最初的世间论」变成同义空转；`parittaṃ bhāvaṃ` 的 `bhāva`（性质、状态）被译作「卑劣」，属无据的贬义添加；`36-42` 把中性的 `pucchati` 处理成反问「不就是…吗」，并补出原文没有的主语「一切」。

**风格**：符合硬约束——通篇现代书面汉语，无文言虚词与文言句式，标点为全角，引号为 “”，译文内无 ASCII 引号、无任何工作标记。扣分在「铺张之谈」（现代汉语里读作「浮夸铺排」，与 `āyata`「铺展、广被」的义注词源解释错位）与「指着断灭来问的」这类不够顺的搭配。

**一致性**：两处并列的 `…ti … pucchati` 释词（`36-42` 与 `43-57`）句式处理方式不同，一个作反问、一个作「他是指着…来问的」，同段内的平行结构被打散；`ekattaṃ / puthuttaṃ` 作黑体词头时译「一 / 多」，在 `58-85` 引文中作「一切是一 / 一切是多」，尚能对应，但词头过简，待与本文层核对。

## 问题清单

### 🟧 error

- `134-282-14-19`｜错译（词义）｜片段「第一种世间论」
  - 问题：`jeṭṭha` 是「最年长的、最首要的」，不是「第一种」；「种」引入了原文没有的分类义。且释词「是指最初的世间论」与之同义，整句退化为「第一种…是指最初的…」的循环解释，读者读不到义注实际在说什么。
  - 建议：词头按「最尊 / 最古老」方向译，让释词「最初的世间论」承担解释功能，例如「**这世间论是最尊的**，是指它是最早的世间论」。定稿前需与本文层该句译文比对，保证黑体词逐字同译。

- `134-282-20-35`｜错译（词义）／错误多译｜片段「其实渺小卑劣的见」
  - 问题：`parittaṃ bhāvaṃ diṭṭhigataṃ` 中 `bhāva` 是「性质、状态」，译文把它转成价值判断「卑劣」，属无据添加；原文只说「渺小」，贬抑由 `mahantaṃ gambhīran ti upadhāritabbaṃ`（被认作宏大深奥）与 `parittaṃ` 的反差自然带出，不必再加词。
  - 建议：改为「其实性质渺小的见」一类，只保留 `paritta` 的义。若沿用别本读作 `parittaṃ chavaṃ`，需在报告或注释中说明所据版本。

### 🟨 warning

- `134-282-36-42`｜整句逻辑表达不规范／错误多译｜片段「一切不就是恒常的自性吗」
  - 问题：`niccasabhāvamevāti pucchati` 是「他就『唯是恒常自性』一点发问」，译文改成反问句「不就是…吗」，语气由中性提问变为诱导性反诘；同时补出了原文没有的主语「一切」。style.md 明确不擅自补足省略主语。
  - 建议：改为陈述性引述，如「他所问的是：是否唯是恒常的自性」。

- `134-282-2-13`｜标点符号使用错误｜片段「对诡辩论典、也就是世间论已经熟习的人」
  - 问题：顿号用于并列成分，此处「诡辩论典」与「世间论」是同位关系（`vitaṇḍasatthe lokāyate` 两个同位处格），顿号加「也就是」自相矛盾，读者会误读成两个并列对象。
  - 建议：改用同位结构，如「对世间论这一诡辩论典已经熟习的人」，或用破折号隔开。

- `134-282-20-35`｜关键词语意不明确｜片段「只属于世间的铺张之谈」
  - 问题：`lokassa āyataṃ` 是义注给 `lokāyata` 做的词源分解，`āyata` 取「铺展、广被」义（在世间中广为流布）。「铺张」在现代汉语的首义是「奢侈铺排／浮夸」，会被读成对内容夸大其词的评价，偏离词源解释的本意。
  - 建议：改用「铺展开来的言说／广布于世间的言论」一类，并在两处保持同一译词以对应原文的重复。

### 🟦 suggestion

- `134-282-43-57`｜语言表达不够流畅｜片段「他是指着断灭来问的」
  - 问题：`sandhāya`（就…而言、针对）译作「指着…来问」，口语化且搭配不顺。
  - 建议：改为「他是针对断灭来问的」。

- `134-282-36-42`｜语言风格不统一｜片段「是指自性单一」
  - 问题：本句与 `134-282-43-57` 是完全平行的两条释词（词头 + 释义 + `…ti pucchati`），译文一处作反问、一处作「他是指着…来问的」，句式不对称，削弱了义注常见/断见对举的结构感。
  - 建议：两句统一为同一句式，如「**一**，是指自性单一；他所问的是：是否唯是恒常的自性。」「**多**，是指相对于先前的自性而言各自不同；他是针对断灭来问的：先以天、人等状态存在，之后便不存在。」

- `134-282-43-57`｜语言表达不够流畅｜片段「众生先以天、人等的状态存在」
  - 问题：原文未出主语，译文补出「众生」。此处虽属语义可接受的补足，但与 style.md「不擅自补足省略主语」相抵，且上一句同样省略主语时未补，前后不一致。
  - 建议：或两句都不补主语，或两句都补同一个主语，保持处理方式一致。
