# Review — 196:885-887（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入，词级核对按巴利原文自行判断）／父层义注（134:860-861，已定稿译文）✅
> 本层为复注（ṭīkā），释义标准取父层义注及其定稿译文。

## 被解释词与父层对照

- **Gomaṃsapesiyo katvā** → 本层「把牛肉切成肉片」，父层 134-861-2-24 中「他**把牛肉切成肉片**晒干」✅ 逐字相同
- **Sukkhāpetvā** → 本层「晒干」，父层同句「切成肉片**晒干**」✅ 逐字相同
- 标题「2. 肉片经注释」与父层 134-860-2-4 ✅ 相同
- 非黑体的 vallūra 本层译「肉干」，与父层「卖肉干」一致 ✅

## 跨段一致性

- go-（牛）：父层 goghātaka 译「屠牛的人」、gomaṃsa 译「牛肉」，本层 §886 gāviṃ 译「母牛」 → 建议统一为「牛」，依据见下条。
- pesi：本层被解释词作「肉片」，同句释文作「一片一片的肉」，后句又作「肉片」 → 可统一为「肉片」（可选，非必改）。

## §886 句 196-886-2-16

- **问题**：误译（取义过窄）。`gāviṃ` 是 go 的宾格形式之一（gāvuṃ / gāviṃ / gavaṃ 并用），泛指牛，不限定母牛。父层 goghātaka、gomaṃsa 均作「牛」，译成「母牛」会让读者以为复注特意补出了性别信息，实际没有。
- **建议**：「一次又一次地宰杀牛，把牛肉剖开，切成肉片。」

## §886 句 196-886-23-26

- **问题**：措辞（轻微）。`sukkhāpiyamāna` 是现在分词被动态，字面是“正在被晒的”。「正在晒干的肉片」可以接受，但容易让人理解成“只有晒到一半的才叫肉干”。复注这里是在说明“晒制的肉片”这一类东西通称 vallūra，用来解释父层“卖肉干”的说法。
- **建议**：可改为「因为晒制的肉片，就叫作“肉干”。」或保留原译。属于可选修改，不是必改。
