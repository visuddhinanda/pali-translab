## 理由

**基准资源缺失（影响信心）**：本次只注入了巴利原文与待评译文，**义注（aṭṭhakathā）与 nissaya 都没有拿到**。ṭīkā 是复注，其黑体被解释词逐字引自义注，缺义注就无法核对「被解释词与父层逐字同译」这条硬约束，也无法判定引号内所引义注原句（如「男子就是补特伽罗」「这样讲下去的，叫作世俗的说法」「因为它以世间的共许为依据」「也就等于取了十二支的缘起」）与父层译文是否一字不差。缺 nissaya 则无法做词级覆盖核对与格/句法角色的独立比对。因此准确性一项只能靠巴利原文本身、上下文自洽与教理常识判定，信心相应压低到 70。下列问题清单中凡涉及被解释词译法的条目（🟨 前两组），都需要拿到义注后再确认最终改法。

**准确性**：整体对复注的论证结构把握准确，长难句处理得好——309-100-119 的「世俗/胜义判别标准」、309-197-214 的「蕴之名依胜义而立、较补特伽罗更近」、309-222-250 的问难与回答，逻辑链条都完整传达，没有漏译整句的情况。术语层面基本可靠（terasacetanā 八欲界善思+五色界善思，数目对；puñña 的词源解释「净化自相续」取义正确；ukkaṭṭhaniddesa 作「就最殊胜的一种来说」正确；uttarapadalopa 作「省略后一个词」正确）。扣分集中在三处：`iti-saddo` 的括号夹注与该句主张自相矛盾；`upaga` 译作「相应」触碰阿毗达摩既有术语；`sammutiṃ amuñcitvā` 加译「的说法」，与本段自己刚立的「说法 vs. 世俗/胜义本身」之分冲突。

**风格符合度**：现代书面汉语基本达标，没有出现「此中/故为/彼等/是故」一类明确禁例，标点全角、引号统一为 “”，译文内无 ASCII 引号、无残留工作标记（候选、待定、问号），这几条硬约束都过。扣分在两处轻度半文言残留（「岂不…吗」「作为其所依」），以及一处单音节词充当被解释词（「先」）。另有一项系统性偏离：本 chunk 内 补特伽罗 / 胜义 / 世俗 / 施设 / 异熟 / 福行 等法相术语**一处巴利夹注都没有**，与 `knowledge/style.md` 第二节「法相术语首次出现夹注巴利原词」不符——但这些词是否已在 196 的前序段落首次出现并夹注过，本次无法核验，故只按 suggestion 计，未按 warning 重扣。

**一致性**：三层同译无法核验（缺义注）。层内一致性有两处松动：`sammuti` 在 309-82-88 被明确译作「世俗」（且刻意与「世俗的说法」区分），到 310-2-5 / 310-14-21 却变成「世俗谛 / 胜义谛」，加了原文没有的「谛」字；`kammapuññena` / `vipākapuññena` / `padīpujjalena` 三处工具格被解释词都译成「因…」，而紧随其后的释义分别是「作为业的」「称为异熟的」「与…同时」，被解释词与自己的释义打架。其余术语（自性法、相续、施设、约定俗成/共许、转起）前后统一，未见漂移。

## 问题清单

### 🟧 error

- `196-309-28-40`｜义理或用词与注释书不符｜片段「（引语词）这个词表示“等等”的意思」
  - 问题：这句复注的主张恰恰是——此处 `iti` **不作引语标记用**，而是 ādi-attha（「等等」义），由它把前面整段轮回与还灭的话再次收进来。译文却在词后夹注「（引语词）」，先给它定成引语词，再说它表示「等等」，自相矛盾，读者会误以为「引语词」就是该词在此处的功能。
  - 建议：删去「（引语词）」，或改为附巴利原词的中性夹注，如「**iti**（iti）这个词在这里表示“等等”的意思」。

- `196-311-41-62`｜错译（词义）｜片段「识就成为与非福相应的识」
  - 问题：`puññūpaga / apuññūpaga` 的 `upaga` 是「趋向、随往、附于」，指识随福行或非福行而趣往某处；译作「相应」与阿毗达摩既有术语 `sampayutta`（相应）撞车，会被读成「与福心所相应」这一完全不同的意思。同一误译在 `196-311-73-98` 的「识就成为与福相应的识」重复出现，两处须一并改。另外「识就成为……的识」句中重复「识」字，读来累赘。
  - 建议：改为「识就趋向非福 / 识就趋往非福」（对应句改「识就趋向福」），或「识成为趣往非福的识」。

- `196-309-251-262`｜错译（词义）｜片段「也不舍弃世俗的说法」
  - 问题：原文是 `sammutiṃ amuñcitvāva kathenti`，宾语是 `sammuti`（世俗、名言）本身，不是 `sammutikathā`。本段 309-82-88 刚刚特意点明「是指在世俗的说法与胜义的说法这两种说法当中，而不是在世俗与胜义这两者当中」，此处再把 `sammuti` 加译成「世俗的说法」，正好消掉了复注刚立起来的区分。
  - 建议：改为「即使在讲胜义，也不舍弃世俗（名言）而讲」。

### 🟨 warning

- `196-311-6-12`｜关键词语意不明确｜片段「造作出值得尊敬的有作为果报」
  - 问题：`pujjabhavaphala` 是「以可尊敬的『有』（bhava，存在／生存）为果」。译文「有作为果报」中「有作为」会被现代读者直接读成常用词「有作为（有出息）」，语义歧义严重，且「有」作为术语首次出现未加任何标记或夹注。
  - 建议：改为「造作出以可尊敬的有（bhava）为果报的东西」，或「造作出可尊敬之『有』的果报」。

- `196-311-13-16`｜关键词语意不明确｜片段「因业的福」
  - 问题：被解释词 `kammapuññena` 译作「因业的福」，引入了原文没有的因果关系；紧接着的释义却是「作为业的那个福」（kammabhūtena），前后打架，读者会误解为「由于业而产生的福」。
  - 建议：被解释词改作「业的福（kammapuñña）」或「作为业的福」，与释义保持同一取义；工具格语气若要保留，放在释义里交代。

- `196-311-17-20`｜关键词语意不明确｜片段「因异熟的福」
  - 问题：同上一条，被解释词「因异熟的福」与其释义「称为异熟的那个福」取义不一致。
  - 建议：改作「异熟的福（vipākapuñña）」或「作为异熟的福」。

- `196-312-31-35`｜整句逻辑表达不规范｜片段「因为点亮了灯」
  - 问题：被解释词译成因果（「因为点亮了灯」），释义却说「就是与点亮灯这个因同时」，读者难以理解为何解释会推翻被解释词。此处工具格取的是「俱有／伴随」义，正是复注要点明的地方，译文没把这层转折交代出来。
  - 建议：被解释词保留原义作「以点亮灯（padīpujjalena）」，释义写成「意思是与点亮灯这个因同时（而不是先后）」。

- `196-310-2-5`｜不该使用术语标记时使用了术语标记｜片段「世俗谛」
  - 问题：被解释词是 `sammuti`，原文无 `sacca`。加「谛」既是加译，也与同一 chunk 内 309-82-88「不是在世俗与胜义这两者当中」的译法不一致。是否加「谛」取决于义注原句用词，本次未取到义注，无法核验。
  - 建议：拿到义注比对被解释词后再定；若义注作 `sammuti`，此处改回「世俗」。

- `196-310-14-21`｜不该使用术语标记时使用了术语标记｜片段「胜义谛」
  - 问题：同上，`paramatthaṃ` / `sammuti` 两个被解释词都被译成「胜义谛 / 世俗谛」，与 310-6-13 刚给出的定义句「最高的、最上的义就是胜义」用词不统一（同一段内「胜义」与「胜义谛」并存）。
  - 建议：统一为「胜义」「世俗」，或全段统一加「谛」，二选一，并与义注被解释词对齐。

- `196-309-127-154`｜关键词语意不明确，或二意场合没有注释｜片段「以集合和相续的方式转起的色等法」
  - 问题：「转起」（pavatti）属于二意术语，本 chunk 内三处使用（另见 `196-309-237-250`「某种转起的依据」、`196-310-22-37`「依着世间共许的名称而转起的」），一次注释或夹注都没有，一般读者无从判断它指「生起并持续进行」。
  - 建议：首次出现处夹注巴利原词，作「转起（pavatti）」，或按语境改为「持续生起」。

- `196-309-222-236`｜文言语体｜片段「那么一切教说岂不都成了世俗的教说吗」
  - 问题：「岂不…吗」为文言反诘句式残留，与 `knowledge/style.md` 第一节要求的现代书面汉语不符（同为问难句，`196-309-184-196` 就用了「不也就是…吗」，更自然）。
  - 建议：改为「那么一切教说不就都成了世俗的教说吗」。

- `196-309-215-221`｜文言语体｜片段「所取的正是作为其所依的那些自性法本身」
  - 问题：「其」作文言虚词，属 style.md 禁例表所列；「作为其所依」是压缩的半文言表达。
  - 建议：改为「所取的正是它所依托的那些自性法本身」。

### 🟦 suggestion

- `196-309-2-27`｜语言表达不够流畅｜片段「本该完全从轮回的教说那里转回」
  - 问题：`nivattetabbā siyā` 一个谓语译成「转回、收束起来」两个动词，后半是加译；「从…那里转回」也略显松散。
  - 建议：改为「教说本该就此完全从轮回的教说转回」。

- `196-309-41-66`｜该使用而没有使用术语标记｜片段「“补特伽罗”这个词也能指另外两类」
  - 问题：一是「补特伽罗」作为法相术语首次出现未夹注 `puggala`（本 chunk 内 胜义、世俗、施设、异熟、福行、自性法 亦皆无夹注，是否前序段落已注无法核验）；二是「（女性、非男非女）」是译者补出的解释，按 style.md 圆括号应留给巴利原词，解释宜下沉为注释。
  - 建议：作「“补特伽罗”（puggala）这个词」，把三性的说明移入脚注或行文（「另外两类，即女性与非男非女」）。

- `196-312-16-21`｜语言表达不够流畅｜片段「这个词，是要显示断除无明与生起明是在同一个时刻」
  - 问题：被解释词 `paṭhamameva` 译成单字「先」，单音节孤立成词，且丢了 `eva` 的强调，读者不易与义注原句对上。
  - 建议：作「**最先**」或「**正是在最先**」，具体依义注原句用词定。

- `196-310-69-74`｜代词指代可能不够明确｜片段「因为这些话显示的是实有法的相」
  - 问题：「这些话」是译者补出的主语（原文 `dīpenti` 主语未明），指代对象在本句内没有落点，读者不知道指哪些话。
  - 建议：按义注上下文补明，如「因为“蕴、界”这些说法显示的是实有法的相」。

- `196-310-22-37`｜语言表达不够流畅｜片段「因为它以世间的共许为依据」
  - 问题：这是引自义注的被解释词 `lokasammutikāraṇaṃ`（世间共许为因），译文加了「因为它以…」的因果框架，作为引文与父层逐字对应的可能性下降；且紧随其后的解释「因为它是依着世间共许的名称而转起的」与之几乎同义，重复。
  - 建议：引文回归名词短语「以世间的共许为因」，因果关系由后半句承担。

- `196-312-58-70`｜复杂的嵌套句整句语言逻辑理解困难｜片段「也正因如此，就没有可怕的对象」
  - 问题：原文两个夺格是并列的理由（无贪爱现行 → 不爱著；正因无贪爱现行而无可怖之事 → 不害怕），译文把第二个理由写成了结论，与句首「也不害怕」之间的因果链断开，读者会觉得末句悬空。
  - 建议：改为「因为没有贪爱的现行，所以不生爱著；也正因没有贪爱的现行，就没有可怕的对象，所以不害怕」。
