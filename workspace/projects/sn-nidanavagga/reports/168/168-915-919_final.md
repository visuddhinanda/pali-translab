## 理由

**基准可用性（影响信心）**：本次只注入了巴利本文与待评译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此「义注定释义、nissaya 定词法」两条基准都无法执行——格与句法角色、传统取义、术语所指（尤其 `sasaṃyojanā`、`gunnaṃ sataṃ gobhūtānaṃ` 的 `sataṃ` 读作 sant 的属格而非「百」、`pāveyyakā/pāṭheyyakā` 异读的地名归属）只能凭原文与通行读法判断。信心指数据此压到 62；若补上义注与 nissaya 再评，准确性一栏可能上下浮动。

**准确性**：主谓宾判断整体正确，无违背教理之处，无 fatal。`sataṃ` 未误读为「一百」，六种畜生（水牛/绵羊/山羊/鹿/鸡/猪）对译无误，`pāripanthikā`（拦路劫匪）、`pāradārikā`（通奸者）取义正确，异读校记 `[ pāṭheyyakā … ]`、`[ mahisānaṃ … ]` 未误译入正文，处理得当。扣分主要在两处**增译**：918-65-129 与 918-130-142 的巴利句止于 `paggharitaṃ`，并无 `na tveva catūsu mahāsamuddesu udakaṃ`，译文却各补了一句「也比四大海里的水多」；原文此处是有意省略叠句，补出属于「错误多译」，且使同组三句的收尾互不一致。

**风格符合度**：语体总体是现代书面汉语，未见 `style.md` 禁例表中的文言写法（无「此中/故为/彼等/于…之际/答以」等），标点全角、引号统一为 “”‘’，译文内无 ASCII 引号、无残留工作标记——这几项硬约束都守住了。扣分在两点：一是「被砍下头颅所涌出、流淌的血」这一叠加定语在汉语里读起来别扭，且在五个平行句中重复出现，属不导致误解的语病；二是全篇**零巴利夹注**，`saṃyojana`（结缚）、`avijjā`（无明）、`taṇhā`（贪爱）、`āsava`（漏）、`saṃsāra`（轮回）等法相术语首次出现均未按 `style.md` 第二节夹注原词。「乃至」用作 peyyāla（…pe…）省略标记，是佛典既定体例而非文言腔，不按文言语体扣分，但与「必须现代汉语」的总原则略有张力，另列 suggestion 备选方案。

**一致性**：文本高度重复，五组叠句的译法基本统一（「在这漫长的时间里奔走流转」「而不是四大海里的水更多」「生为 X、做 X 的时候」句式一贯），`bhante/bhadante` 一律「尊师」，`anamatagga` 两处一律「没有可知的起点」，`anupādāya āsavehi cittāni vimucci-` 两处一律「不再执取，心从诸漏中解脱」。扣分主要来自上述三个「强盗」并列句收尾不一。

**待登记术语（`terms.md` 未收录）**：`bhante/bhadante`→尊师、`pāveyyaka`→波婆地方的、`āraññika/piṇḍapātika/paṃsukūlika/tecīvarika`→林野住支/常乞食支/粪扫衣支/但三衣支。建议定案后补进 `knowledge/terms.md`。

## 问题清单

### 🟧 error

- `168-918-65-129`｜错误多译｜片段「所涌出、流淌的血也比四大海里的水多」
  - 问题：本句巴利止于 `corā gāmaghātāti gahetvā sīsacchinnānaṃ lohitaṃ passannaṃ paggharitaṃ .`，并无 `na tveva catūsu mahāsamuddesu udakaṃ`。译文补出了原文有意省略的比较叠句。
  - 建议：删去「也比四大海里的水多」，保留省略形态，如「……被抓住而被砍下头颅，所涌出、流淌的血……」；比较句留给下文 143-161 一次说全。

- `168-918-130-142`｜错误多译｜片段「所涌出、流淌的血也比四大海里的水多」
  - 问题：同上，巴利句止于 `paggharitaṃ`，比较部分为原文所无。
  - 建议：与 918-65-129 同步处理，使三个并列的「强盗」句收尾一致。

### 🟨 warning

- `168-917-20-52`｜不导致误解的汉语语病｜片段「奔走流转、被砍下头颅所涌出、流淌的血多」
  - 问题：「奔走流转」与「被砍下头颅」原是修饰「你们」的状语／定语，「所涌出、流淌」才修饰「血」，三者被顿号并列后中心语错位，读来滞涩；该句式在 917-53-93、918-21-45、918-46-64、918-143-161 中重复出现。
  - 建议：改为「你们在这漫长的时间里奔走流转，被砍下头颅时流出的血多」一类分层结构，并在各平行句统一。

- `168-918-166-179`｜代词指代不明确｜片段「足以从中解脱出来」
  - 问题：`alaṃ vimuccituṃ` 前的「对一切行厌离、离贪」被 `…pe…` 省略，译文补出的「从中」失去先行词，读者无法判断是从轮回、从诸行还是从诸漏中解脱。
  - 建议：直接作「足以解脱」，把省略的完整叠句交给上下文或注释。

- `168-919-2-6`｜标点符号使用错误｜片段「“世尊说了这些话。」
  - 问题：巴利此处的 `‘‘ … ’’` 是版本排版遗留（第 919 段整段被引号包住），照搬为中文双引号后，「世尊说了这些话」「那些比丘心里满意」这类第三人称叙述被包在引号内，读者会误以为仍是世尊的话。
  - 建议：去掉 919 段这对引号，仅保留叙述句式；若要保留版本信息，写进报告而非译文。

### 🟦 suggestion

- `168-915-2-4`｜语言表达不够流畅｜片段「三、三十人经」
  - 问题：`Tiṃsamatta` 所指是三十位**比丘**，「三十人经」丢了这层限定。
  - 建议：作「三十比丘经」。

- `168-917-10-19`｜该使用而没有使用术语标记｜片段「被贪爱的结缚捆住」
  - 问题：`taṇhā`（贪爱）、`saṃyojana`（结缚）、同段 `avijjā`（无明）以及 916 段的 `āsava`（诸漏）、917 段的 `saṃsāra`（轮回）均属法相术语，按 `style.md` 第二节首次出现应以全角圆括号夹注巴利原词，全篇未夹注一处。
  - 建议：在各自首次出现处补夹注，如「无明（avijjā）」「贪爱（taṇhā）的结缚（saṃyojana）」「诸漏（āsava）」，其后只用汉译。

- `168-916-10-37`｜不常用术语编写注释或者百科｜片段「三十位波婆地方的比丘」
  - 问题：`pāveyyakā` 有 `pāṭheyyakā` 异读（校记已在原文括注，律藏大品迦絺那衣犍度亦作此读），两读指向不同地域；译文径取「波婆」而未记分歧。
  - 建议：译文保持现状不加标记，另为「波婆」条目补一则百科/注释说明异读，并把该判断写入 `knowledge/known-issues.md`。

- `168-916-10-37`｜语言表达不够流畅｜片段「全都受持林野住支」
  - 问题：`āraññikā / piṇḍapātikā / paṃsukūlikā / tecīvarikā` 字面是「住林野者、常乞食者、着粪扫衣者、但持三衣者」，「受持…支」是头陀支（dhutaṅga）框架下的引申说法。义注未注入，无法核验此处是否确以头陀支释之。
  - 建议：补义注后确认；若义注确作头陀支解，现译可保留，否则改为「全都住在林野、全都常行乞食……」更贴本文。

- `168-916-68-84`｜语言表达不够流畅｜片段「就在这个座位上不再执取」
  - 问题：`imasmiṃyeva āsane` 是「当场、不离座」的惯用语，「这个座位」易被读成具体的一把椅子；`anupādāya` 是「不取著」，「不再执取」多出了「再」的时间义。
  - 建议：可作「就在这座位上当下不取著，心从诸漏中解脱」。

- `168-916-85-91`｜语言风格不统一｜片段「于是世尊招呼比丘们说」
  - 问题：`āmantesi` 是「告、呼唤」，「招呼」口语色彩偏重，与同段 110-112「世尊说了这样的话」的叙述口吻不一致。
  - 建议：作「于是世尊唤比丘们说」或「于是世尊对比丘们说」。

- `168-917-10-19`｜语言表达不够流畅｜片段「不停地奔走流转」
  - 问题：`sandhāvataṃ saṃsarataṃ` 本身只是「奔走、流转」，「不停地」为译者增补的状语。
  - 建议：删去「不停地」，或在需要强调持续义时改用「长久地」以贴合下文 `dīghena addhunā`。

- `168-918-65-129`｜语言风格不统一｜片段「……乃至……」
  - 问题：`…pe…` 译作「乃至」是佛典既定体例，但与「必须现代书面汉语」的总原则略有张力；同段另有纯省略号「……」表示的省略，两种省略标记混用。
  - 建议：全项目统一一种处理（如一律「……（中略）……」，或一律「……乃至……」），并写进 `knowledge/translation-rules.md`。
