# Review — 168:243-255（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya 行，已略过）

## 跨段一致性
- **Sace pana taṃ, sāriputta, evaṃ puccheyyuṃ**：§251 译“如果有人**再**这样问你”，§252、§253、§254 译“如果有人这样问你” → 建议统一。pana 在这里只是承接下一轮问答，nissaya 释为 `သစေ ပန ပုစ္ဆေယျုံ= မေးကုန်မူကား`，没有“再”的意思。建议四处都去掉“再”，或四处都加。
- **问答引出标点**：§251 在“问你／问我／回答”后用冒号“：”，§252–§254 改用破折号“——” → 建议统一为冒号，与 §249、§250 一致。
- **四个“以什么为…”的并列**：§251 用逗号分隔（“以什么为因缘，以什么为集起，…”），§252–§253 用顿号（“以什么为因缘、以什么为集起、…”） → 建议统一用顿号。
- **attha**：§248 译“意思”（“这个意思并不是用这些词…”），§255 译“义理”（“简要解说这同一义理”） → 建议统一为“意思”。nissaya 两处都是 `အနက်`。
- **pariyāya**：§248 译“方式”（“无论用什么方式宣说”），§255 译“说法”（“的一种说法”） → 建议统一为“方式”。nissaya 分别作 `ပရိယာယ်`／`နည်း`，都指表达的方式。
- **法相术语夹注**：§251 “有（bhava）”首次出现有夹注，同组的取（upādāna）、渴爱（taṇhā）、受（vedanā）首次出现都没有夹注 → 建议体例统一：要么都夹注，要么都不夹注。
- **na upaṭṭhāsi**：§254 两处问句与答句都译“不再生起”，用词一致，但取义有偏差，见下方 §254 各条。

## §244 句 168-244-52-60
- **问题**：用词 — `အဿာသံ= မှီခိုအားထားရာ (အောက်မဂ်အောက်ဖိုလ် ခြောက်ပါး) ကို`，意思是“可依靠、可倚赖之处”（指下三道三果）。译作“依止”容易和僧团术语“依止（nissaya，依止师）”混淆。
- **建议**：改为“可依靠之处”或“依靠”，例如“想必那位尊者在这法与律中没有得到可依靠之处吧”。§244 句 168-244-61-71 的“已经得到依止了吗”要同步改为“已经得到可依靠之处了吗”。

## §245 句 168-245-14-22
- **问题**：补出成分 — nissaya 补出了省略的谓语：`(န ကင်္ခသိ= မယုံမှားသလော။)`，即“（将来）你也不怀疑吗”。现译“将来呢？”过于省略，读者不易看出问的是“将来是否也不怀疑”。
- **建议**：“那么贤友，将来呢？〔也不怀疑吗？〕”，或者直接写成“那么贤友，将来也不怀疑吗？”

## §248 句 168-248-52-56
- **问题**：nissaya 疑误 — 本行 nissaya 作 `ဘဂဝါ= သည်`（以世尊为主语），但巴利文这里的施事是上句的 so bhikkhu。译文以那位比丘为主语，是正确的。
- **建议**：译文不改，只记下 nissaya 此处的讹误。

## §248 句 168-248-161-181
- **问题**：句法 — nissaya：`အထ ခေါ= စင်စစ်အားဖြင့်`（毕竟、实际上）；`ဗျာကတံ= ဖြေဆိုအပ်သည်ကို`（所宣说的，作宾语）；`ဗျာကတတော= ဖြေဆိုသောအားဖြင့်`（作为宣说）；`ဒဋ္ဌဗ္ဗံ= မှတ်အပ်၏`（应当视为）。原文的意思是“所宣说的，应当视为〔已〕宣说”。现译“只要已经宣说了，就应当把它当作是已经宣说”把 byākataṃ 读成了条件从句，句意也变得循环。
- **建议**：“舍利弗，善男子无论用什么方式宣说究竟智，所宣说的都应当看作是〔究竟智的〕宣说。”

## §250 句 168-250-65-78
- **问题**：语法误读（必改）— `ယံနိဒါနာ= အကြင်အကြောင်းကြောင့်` 是关系代词“以**某个**因缘”，不是疑问词。现译“出生以什么为因缘”读起来像在提问，与后文“那个因缘”的呼应断了。nissaya 的整句结构是：`ဇာတိ= ပဋိသန္ဓေနေခြင်း`（结生）“出生由某个因缘而有 → 那个因缘（`တဿ နိဒါနဿ`）灭尽（`ခယာ`）→ 在它已经灭尽时（`ခီဏသ္မိံ`）→ 了知‘〔出生这一果〕已经灭尽’（`ခီဏာမှီတိ … ဝိဒိတံ`）”。
- **建议**：“贤友，出生由什么因缘而有，由于那个因缘灭尽，在它已经灭尽时，就了知：〔出生〕已经灭尽。”或者写得更明确：“贤友，出生所依的那个因缘，由于它灭尽……”

## §251 句 168-251-67-80
- **问题**：补出成分（参考）— nissaya 把 bhava 释为 `ကမ္မဘဝ`（业有）。
- **建议**：正文保留“有”即可，不必改。如果需要，可以加脚注说明这里的“有”指业有。

## §254 句 168-254-14-33
- **问题**：句法 — nissaya：`ဇာနတော= သိသောသူ၏ (သန္တာန်၌)`、`ပဿတော= မြင်သောသူ၏ (သန္တာန်၌)`，即“在这样知、这样见的人〔的相续〕中”；`သာ … န ဥပဋ္ဌာသီတိ= မထင်သနည်း`，即“那喜爱不显现”。原文是陈述“喜爱不现起”，没有使役义。现译“才使……不再生起”加进了“使”，变成舍利弗主动让喜爱不生，偏离了句法。另外，upaṭṭhāti 对应 nissaya 的 `မထင်`，意思是“显现、现前”，译“生起”略偏。
- **建议**：“舍利弗贤友，你是怎样知道、怎样看见，对各种受的喜爱（nandī）才不现起的呢？”

## §254 句 168-254-56-82
- **问题**：句法 — 与 168-254-14-33 相同，“才使……不再生起”的使役义不合 nissaya。
- **建议**：同步改为“……对各种受的喜爱才不现起的呢？”

## §254 句 168-254-113-132
- **问题**：补出成分与句法 — nissaya 补出了 `(တသ္မာ= ကြောင့်)`（因此），也就是“已经了知无常即苦，因此喜爱不现起”。现译“——这一点已被了知，对各种受的喜爱就不再生起了”的因果关系不够清楚，被动句“已被了知”也带翻译腔。`န ဥပဋ္ဌာသီတိ= မထင်ပါ` 同上，宜译“不现起”。
- **建议**：“已经了知：凡是无常的就是苦，因此对各种受的喜爱就不现起了。”
