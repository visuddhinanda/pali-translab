# Review — 91:191-205（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本层为本文 mūla，无父层对照，不适用被解释词逐字核查）

## 跨段一致性
- **sārathinā 的施事范围**：§193、§194、§195、§196、§197、§198、§199、§200、§201、§202、§203、§204、§205 这一组固定句式都译作“被人说‘走吧’，驾车人用刺棒刺它、催赶它的时候”。这样一来，同一施事被拆成了“人”和“驾车人”两个。nissaya 的语序是 `ပေဟိ ဣတိ သာရထိနာ ဝုတ္တော`（“走吧”这句话由驾车人说出），`sārathinā` 同时管 vutto / viddho / codito 三个过去分词。建议全部统一为：“被驾车人喊‘走吧’，又被他用刺棒刺、催着往前赶的时候”。共 13 处，按同一译法一次改齐。
- **kubbara 与 rathīsā 同译“车辕”**：§194、§202 把 kubbaraṃ 译作“车辕”，§195、§203 把 rathīsā 也译作“车辕”，两个不同的词合成了一个译法。按 nissaya 的长注，kubbara 是马用后腿能踢到的车前木杆，泛指含辕在内的各根车木（`ရထားသန် ရထားသစ်သားချောင်း`）。rathīsā 只取“车辕”一义（`ရထားသန်`）。nissaya 还专门说明两词并不重复。建议 rathīsā 保留“车辕”，kubbara 改译“车杠”或“车前木杆”，§194 和 §202 同步修改。
- **ummagga 译“岔路”**：§196、§204 都译作“走上岔路”。nissaya 作 `ဥမ္မဂ္ဂံ= လမ်းမဟုတ်သော အရပ်ကို`（不是路的地方），“岔路”仍然是路，意思译偏了。建议两处统一改为“偏离道路”或“往路外跑”。
- **laṅghati / purimakāyaṃ 的配对**：§197、§205 都译作“跳跃起来，抬起前半身，举起前腿”，把 purimakāyaṃ 配给了 paggaṇhati。nissaya 两处都配作 `ပုရိမကာယံ … လင်္ဃတိ`（前半身腾跃起来）和 `ပုရိမေ ပါဒေ … ပဂ္ဂဏှတိ`（抬起前腿）。建议两处统一改为“把前半身腾跃起来，高高抬起两条前腿”。
- **tathūpamāhaṃ … imaṃ puggalaṃ vadāmi**：§201、§202、§203、§204、§205 都译作“我说这样的人就和那匹马一样”。imaṃ 是“这个（人）”，nissaya 作 `ဣမံ ပုဂ္ဂလံ= ဤပုဂ္ဂိုလ်ကို`，并补出就是上文所说的那个人。比喻的对象在 nissaya 里是 `ထိုမြင်းရိုင်း`（那匹劣马）。建议统一为：“我说这个人就像那匹劣马。”
- **āpatti 术语**：§201 到 §205 一律译作“犯了戒”“犯了某某戒”，术语表登记的 āpatti 译法是“犯”。nissaya 作 `အာပတ္တိယာ= အာပတ်ဖြင့်`，是律学上的“犯”，不是泛称的“戒”。建议按术语表统一，例如“指控一位比丘有犯”“你自己就犯了某某犯”。若嫌后者生硬，至少在报告中定案，再补进 `terms.md`。

## §192 句 91-192-40-46
- **问题**：漏译宾语 — `တံ= ထို ငါဟောအပ်မည့် တရားတော်ကို`，taṃ 指“我将要讲的法”，是 suṇātha 的宾语，译文没有译出。nissaya 补出的隐含主语 `(တုမှေ)`，译文“你们”已经对应上了。
- **建议**：改为“你们要仔细听我讲的这个，好好地记在心里；”。

## §192 句 91-192-2-39
- **问题**：词义偏窄 — purisakhaḷuṅke 的 nissaya 是 `ကြမ်းတမ်း ရိုင်းစိုင်းသော ယောကျ်ား`（粗暴、难驯的人），assakhaḷuṅke 是 `မြင်းကြမ်းမြင်းရိုင်း`（性子野、难驯的马）。“劣人”在现代汉语里不成词，读者容易理解成“品行低劣”。
- **建议**：可考虑把“劣人”改为“难驯的人”。“劣马”是现成词，可以保留。若改，§201 到 §205 的“劣人”要全部同步。

## §194 句 91-194-2-29
- **问题**：动词误读 — `ဟနတိ= ချိုးဖဲ့ဖျက်ဆီး၏။ (နောက်ခြေထောက်နှစ်ဖက်တို့ဖြင့် မြှောက်ပင့်ရိုက်နှက်၍ …)` 的意思是抬起两条后腿踢打、把它弄断。“撞坏”没有译出用后腿踢这一动作。kubbara 的译名问题见跨段一致性。
- **建议**：改为“它却向后跳，用后腿把车杠踢断，折断车前的三根撑杆”。§202 句 91-202-41-65 同步修改。

## §195 句 91-195-2-26
- **问题**：动作误读 — `သတ္ထိံ= ပေါင်ကို။ ဥဿဇ္ဇိတွာ= ပစ်လွှတ်ရိုက်ခတ်၍` 是把大腿甩出去撞击，不是“抬起”。`အဇ္ဈောမဒ္ဒတိ= နင်းဖိ၏။ (ရှေ့ခြေနှစ်ချောင်းတို့ဖြင့်)` 是用两条前腿把车辕踩住压下去。yeva 强调“偏偏是车辕本身”，译文“就踩在车辕上面”把它弱化了。
- **建议**：改为“它却把大腿甩向车辕撞上去，再用前腿把车辕本身踩住压下”。§203 句 91-203-36-57 同步修改。

## §196 句 91-196-2-27
- **问题**：ummaggaṃ 误译，见跨段一致性。ubbaṭumaṃ 的 nissaya 补出了 `လမ်းမဟုတ်သော ကုန်းမြင့်အရပ် ဆူးရှိသော အရပ်`（没有路的高地、长刺的地方），译文“没有路的地方”可以保留。
- **建议**：前半句改为“它却离开道路，把车子拖到没有路的地方去”。§204 句 91-204-32-54 同步修改。

## §197 句 91-197-2-26
- **问题**：句法配对误读，见跨段一致性。
- **建议**：改为“它却把前半身腾跃起来，高高抬起两条前腿”。§205 句 91-205-24-47 同步修改。

## §200 句 91-200-2-40
- **问题**：动词偏差 — `စတ္တာရော ပါဒေ အဘိနိသီဒတိ= ဖိ၍ ဝပ်နေ၏`，意思是把四条腿压在身下趴伏不动。cattāro pāde 是宾格，表示压住的对象。“四条腿一起坐了下去”把四条腿当成了主语。
- **建议**：改为“就在原地把四条腿压在身下，趴着不动”。

## §202 句 91-202-25-33
- **问题**：并列定语被合并 — nissaya 把 bāla 释为 `မသိနားမလည်သူ`（愚笨，不懂犯与举罪的方式），把 abyatta 释为 `ဝိနည်းမတတ် မနှံ့စပ် မကျွမ်းကျင်သော`（不通律、不熟练）。两词各有所指，“愚昧无知”只译出了前一个。
- **建议**：改为“你这个又笨又不懂行的人，你说的话有什么用！”。

## §203 句 91-203-22-35
- **问题**：术语 — itthannāmaṃ āpattiṃ āpanno 被译作“犯了某某戒”，与术语表中 āpatti 的译法“犯”不一致，见跨段一致性。paṭikarohi 的 nissaya 是 `ကုစား`（补救、处理），“忏悔改正”可以接受。
- **建议**：随 āpatti 的定案一并修改，例如“你自己就有某某犯，你先去把它处理好吧。”
