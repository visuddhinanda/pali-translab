# Review — 91:475-483（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核；§475–477 无 nissaya，略过）

## 跨段一致性
- **Idaṃ kho panetaṃ … sandhāya bhāsitaṃ**：§479、§480、§481、§482、§483 都译成“正是针对这一点才这样说——”，五处都没有补出施事“我”（理由见 §479 句 91-479-69-77）。修改时五处要统一改。
- **十六大国国名**：§478 只有“跋伽人（Vaṅga）”一处带夹注，其余十五国都不带。体例不统一，建议要么都不夹注，要么只给罕见国名夹注。
- 其余反复出现的句式（“以这样的夜／月／年计算”“人间的 N 年，是 X 天的一个昼夜”“往生到 X 天的天众之中”）在 §479–483 中译法一致，没有漂移。

## §478 句 91-478-10-91
- **问题 1**：格与数，国名的指称有误。nissaya 把十六个国名都释作国土的属格，如 `အင်္ဂါနံ= အင်္ဂဇနပုဒ်၏လည်းကောင်း။`（鸯伽国的），并加注 `[ဧကဝုစ်အနက်ဆိုရမည်]`，意思是应按单数解读。也就是说，这些复数属格指的是“某国”，不是“某族人”。译文“鸯伽人、摩揭陀人……甘蒲遮人”把国土译成了族人。
- **建议**：改为“鸯伽国、摩揭陀国、迦尸国、憍萨罗国、跋耆国、末罗国、支提国、……甘蒲遮国”。这样也和前文“十六个……大国”相呼应。
- **问题 2**：音译误对。`မစ္ဆာနံ= မစ္ဆဇနပုဒ်၏` 说明原词是 Maccha。“婆蹉”是 Vaccha/Vaṃsa 的传统音译，两者是不同的国家。
- **建议**：改为“摩差（Maccha）”或“摩蹉”，并夹注巴利原词，以免和婆蹉国混淆。
- **问题 3**：漏译修饰成分。`ပဟူတရတ္တရတနာနံ= များစွာတပ်မက်ဖွယ် ရတနာရှိကုန်သော`，意思是“拥有众多可爱（令人贪爱）珍宝的”。ratta（可爱、令人喜爱）这一层在“盛产珍宝”中没有译出。
- **建议**：改为“拥有众多可爱珍宝的十六大国”。
- **问题 4**：属格关系含混，并且有文言虚词。nissaya 中，`ဧတံ= ဤဇနပုဒ်ကြီး (၁၆)ခုတို့၏ မင်းအဖြစ်ကို ပြုလုပ်ရခြင်းသည်`（统治这十六大国这件事）是主语；`ဥပေါသထဿ= …ဥပုသ်သီလ၏`（斋戒的）是 `ကလံ`（一分）的属格限定。译文“这与具足八支的斋戒相比，还不值其十六分之一”多出一个“相比”框架，又用文言代词“其”回指，主属关系读起来不清楚。按 style.md，“其”属于必改项。
- **建议**：改为“统治这十六大国这件事，还抵不上具足八支的斋戒的十六分之一”。

## §479 句 91-479-69-77
- **问题**：隐含成分没有补出。nissaya 在下一句补出了施事 `(မယာ= ငါသည်)`、`ဘာသိတံ= မိန့်ဆိုအပ်ပြီ`，意思是“（这话）是我说过的”。说话人是世尊本人，回指 §478 句末那句话。译文“正是针对这一点才这样说”没有主语，读者会以为是引述别人的话。
- **建议**：改为“比丘们，我正是针对这一点，才说——”。§480–483 同句一并照此修改。

## §479 句 91-479-44-68
- **问题**：语气略有偏差。nissaya 把 `ယံ` 释为 `ယေန ဌာနေန= အကြင်အကြောင်းကြောင့်`，把 `ဥပပဇ္ဇေယျ= ကပ်ရောက်ရာ၏` 释为可能式（“可能会往生”），再由 `ဧတံ ဌာနံ … ဝိဇ္ဇတိ` 总说“有这种可能（的道理）”。译文“往生到……”是直陈语气，和前面的“确实有这样的情形”合起来读大体通顺，但可能式的语气被弱化了。
- **建议**（可选，不是必改）：改为“……身坏命终之后，可以往生到四大王天的天众之中”。§480–483 同句保持一致。
