# Review — 91:876-885（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§883、§885 大部分句、标题行无 nissaya，按要求略过）

## 跨段一致性

- **parisāya**：§880、§881、§884 的 nissaya 都标作 `ပရိသာယ= အား`，是与格“对会众/为会众”，不是处格。各段译文统一译成“在众中无畏地说法”，把与格读成了处格。
  - 建议全 chunk 统一改为“无畏地为大众说法”。
  - 涉及 880-2-87、880-100-149、881-2-55、884-2-100、884-112-164，以及 885-2-32（同一句式）。
- **tena taṃ aṅgaṃ paripūretabbaṃ 中的 tena**：nissaya 作双重释义（`တေန= ထို့ကြောင့်` 因此；`တေန= ထိုရဟန်းသည်` 他），各段译文都只取了“他”，没有译出“因此”。
  - 建议统一改为“因此，他应当……”。
  - 涉及 878-58-62、879-24-28、880-94-99、883-27-31、884-107-111。
- **āruppā**：nissaya 释为 `အရူပဈာန်`（无色禅），§884 与 §885 都译作“无色”。
  - 建议两段统一为“无色禅”，句式同步调整（见 §884 条目）。
  - 涉及 884-2-100、884-112-164、885-33-55。
- **samantapāsādiko**：§881、§885 都译作“处处令人悦意”，按 nissaya 应改为“全面令人生起净信”，两段须同步修改（见 §881 条目）。

## §878 句 91-878-58-62

- **问题**：补出成分 / 句法。本句的 nissaya 合并在 91-878-63-72 行。
  - `တေန= ထိုသို့မပြည့်ဝ, မစုံလင်ခြင်းကြောင့်`：表原因，“因为不圆满”。
  - `တေန= ထိုရဟန်းသည်`：施事，“那位比丘”。
  - 译文“他应当把这一方面补足”只译出了施事义，漏了原因义的连接。
- **问题**：词义 / 宾格所指。`တံ အင်္ဂံ= ထိုသီလဟူသော ဂုဏ်အင်္ဂါကို`，即“那戒德支（宾格）”。译文“这一方面”可以接受，属次要问题。
- **建议**：改为“因此，他应当把这一方面补足——”。

## §880 句 91-880-2-87

- **问题**：格与句法。`ပရိသာယ= အား`（与格），`ဝိသာရဒေါ (ဟုတွာ)= 无畏地`。
  - 句义是“无畏地向会众说法”。
  - 译文“在众中无畏地说法”（两处）把它读成了处所。
- **建议**：两处都改为“无畏地为大众说法”。

## §880 句 91-880-100-149

- **建议**：改为“……能无畏地为大众说法……”。

## §881 句 91-881-2-55

- **问题**：格与句法。`(ဟုတွာ) ပရိသာယ= အား`（与格），译文“在众中无畏地说法”是处格误读。
- **建议**：改为“能无畏地为大众说法”。

## §881 句 91-881-62-80

- **问题**：词义取向。
  - nissaya：`သမန္တပါသာဒိကော စ= (သဒ္ဓါစသည်, ပြည့်စုံညီသဖြင့်) ပတ်လည်ဝန်းကျင်, ကုန်စင်ခပင်း, ကြည်ညိုခြင်းကို ဖြစ်စေတတ်သည်`，意思是“（因信等八法具足而）周遍、全面地令人生起净信”。
  - 译文“令人悦意”丢了 pāsādika“令人起净信”这层意思。
  - 译文“处处”偏向空间义，而 samanta 在这里指“周遍、全面”。
- **建议**：改为“就能全面地令人生起净信，并且在一切方面都完满”。
  - 885-62-80 同句同步修改。

## §884 句 91-884-2-100

- **问题**：格与句法，parisāya 的处格误读同上（`ပရိသာယ= အား`）。
- **问题**：句法结构 / 词义。nissaya 的结构是：
  - `ယေ တေ အာရုပ္ပါ= အကြင်အရူပဈာန်တို့သည်` 是中心词（主格），即“那些无色禅”。
  - `သန္တာ ဝိမောက္ခာ (ဟုတွာ)` 作说明，即“作为寂静的解脱”。
  - `ရူပေ= ရူပဈာန်နှင့် ကသိုဏ်းရုပ် အာရုံတို့ကို` 指色禅与遍处色所缘，`သမတိက္ကမ္မ` 是“超越”。
  - `တေ= ထိုအရူပဈာန်တို့ကို` 是“那些无色禅”（宾格），作 phusitvā 的宾语。
  - 译文“那些超越诸色、也就是无色的寂静解脱”把“无色”降成了同位插入语，中心词又换成了“解脱”。这与 nissaya 的主从关系不一致，而且“无色”缺了“禅”字。
- **问题**：补出成分（参考项）。`ကာယေန= သဟဇာတနာမကာယဖြင့်`，“身”在这里指俱生名身（心与心所），不是色身。正文可以保留“以身”，建议另出脚注说明。
- **建议**：改为“但不能以身触及那些超越诸色、作为寂静解脱的无色禅而安住”（前后两处同步）。

## §884 句 91-884-112-164

- **问题**：同 91-884-2-100：
  - parisāya 是与格；
  - āruppā 应译“无色禅”，并作中心词。
- **建议**：同步按 91-884-2-100 修改。
