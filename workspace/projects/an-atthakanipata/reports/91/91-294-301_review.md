# Review — 91:294-301（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性
- **bhante**：§295、§298、§299、§300 都译“大德”，只有 §301 句 91-301-2-19 译“尊者” → 必改，统一为“大德”。
- **cāga**：§300 句 91-300-53-61 译“布施”，§301 句 91-301-47-55 译“施舍”（§296 cāgavā 译“好施”） → 建议 §300 与 §301 统一为“施舍”。理由是 §295 的 dāna 已经用了“布施”，cāga 再译“布施”就和 dāna 撞词。nissaya 的释义是 စွန့်ကြဲပေးကမ်း，意思是“舍弃、施与”。
- **-kāmo（dassanakāmo / sotukāmo）**：§300 译“乐于见到”“乐于听闻”，§301 译“想要见”“想要听” → 建议统一为“想要”。nissaya 作 `ဒဿနကာမော= ဖူးမြင်ခြင်းငှာ အလိုရှိသည်`，意思是“想要瞻仰”，是“欲求”，不是“乐于”。
- **dhāraṇajātiko**：§300 译“记持”，§301 译“记住” → 统一为一个词（建议“记住”，更现代）。
- **para / paraṃ**：§300 前四句译“他人”，91-300-94-104 起改成“别人”，§301 全用“别人” → 统一为“别人”。
- **imeheva catūhi**：§295 三句都译“这同样的四种”，见下文 91-295-204-223，三处一并改。

## §295 句 91-295-14-25
- **问题**：漏译 — `pañcamattehi= ငါးခု အရေအတွက် ပမာဏရှိကုန်သော`。-matta 表示约数（“大约五百”），译文写成了确数“五百位”。
- **建议**：“由大约五百位优婆塞围绕着”。

## §295 句 91-295-41-50
- **问题**：用词 — `အယံ ပရိသာ= ဤပရိသတ်သည်`。parisā 指会众、随众，“群体”是现代社会学用词，用在这里不贴切。本经其余各句的“群体”是同一个问题。
- **建议**：全经统一改为“会众”（或“徒众”），例如“手诃多，你的这群会众真多啊”。nissaya 把 `မဟတီ` 释为 `များလှပေ၏`（数量很多），译成“多”比“大”更准确。

## §295 句 91-295-107-113 / 91-295-125-127 / 91-295-139-141
- **问题**：句法 — `ယံ= အကြင်ပရိသတ်ကို။ [ဇာနာမိ-၌စပ်]`。yaṃ 是关系代词，宾格，接 jānāmi，和后句的 taṃ 呼应（“凡我知道……的，我就……他”）。译文“我知道某个人——”把关系从句改成了不定陈述，yaṃ…taṃ 的对应关系就断了。另外 nissaya 把 yaṃ 的所指解为会众中的人，不是泛指“某个人”。
- **建议**：改为“大德，对于我知道——”／“对于我知道——”，后句接“‘这个人应该用布施来摄受’的，我就用布施来摄受他”，让关系从句完整。

## §295 句 91-295-142-152
- **问题**：取义 — nissaya 的主译是 `အတ္ထစရိယာယ= သူတို့၏ ဖြစ်ပေါ်လာသော ကိစ္စအဝဝကို ပြုကျင့်ဆောင်ရွက်ခြင်းဖြင့်`（替他们办理遇到的各种事务），并注明 attha 在这里作“事务”解。“做有益的事”对应的是异释 `ဝါ= အကျိုးစီးပွားကို ပြောဆိုပြုကျင့်ခြင်းဖြင့်`。按 style.md，译文应取主译，异释备列。
- **建议**：“这个人应该用替他办事来摄受”，我就“替他办事来摄受他”（或“帮他办事”）。异释可以作脚注。

## §295 句 91-295-177-186
- **问题**：句法 / 补出成分 — `ဒလိဒ္ဒဿ= လူမွဲ၏`（属格），nissaya 补出了 `(ဝစနံ= စကားကို)`，并把 `တထာ` 释为 `ထိုပစ္စည်းဥစ္စာကြွယ်ဝသူ၏ စကားနှင့် အလားတူပင်`（像富人的话那样）。译文“那样”没有交代比照的对象（富人），属格结构也被拆成了“对于……他的话”，读起来不顺。
- **建议**：“穷人的话，人们不会认为像（富人的话）那样值得听。”

## §295 句 91-295-194-203
- **问题**：误增 + 取义 — 原文是 `mahatiṃ parisaṃ`，没有 imaṃ，译文“这个大群体”多出了“这个”。`အယံ= (ဒါန, ပေယျဝဇ္ဇ…) ဤအကြောင်းလေးမျိုးသည်`：主语 ayaṃ 指这四种摄事。`ယောနိ= သင့်လျော်သော အကြောင်း`：yoni 是“恰当的途径”，不是一般意义上的“方法”。`သင်္ဂဟေတုံ= …ငှာ` 是目的不定式。
- **建议**：“手诃多，你的这（四种）正是摄受广大会众的恰当途径。”

## §295 句 91-295-204-223 / 91-295-224-244 / 91-295-245-267
- **问题**：词义 — `ဣမေဟေဝ သင်္ဂဟဝတ္ထူဟိ= ဤသင်္ဂဟဝတ္ထုတို့ဖြင့်ပင်လျှင်`。eva 是强调（“正是、就是”），不是比较（“同样的”）。
- **建议**：三句都改为“全都是用这四种摄受的事”／“正是用这四种摄受的事”。

## §296 句 91-296-2-20
- **问题**：用词 — `ဓမ္မိယာ ကထာယ= တရားရှိသော စကားဖြင့်`，意思是“合于法的谈话、法谈”。“佛法的谈话”读起来别扭。
- **建议**：“世尊用法谈为……开示”或“世尊为……讲说佛法，开示、劝勉……”。

## §299 句 91-299-17-45
- **问题**：漏译 — `သုရာမေရယ မဇ္ဇပမာဒဋ္ဌာနာ= မေ့လျော့ခြင်း၏ တည်ရာအကြောင်းဖြစ်သော မူးယစ်စေတတ်သော သေရည်အရက်ကို သောက်ခြင်းမှ`。surā / meraya / majja 三个实词被压缩成了“饮酒”。
- **建议**：“远离饮用谷酒、果酒等令人迷醉、作为放逸根源的酒”。

## §300 句 91-300-105-115
- **问题**：取义 — `ဓမ္မံ= ပါဠိကို။ အညာယ= သိ၍`：这里 dhamma 和 attha 对举，指“巴利经文”，attha 指“义理”。“了解了法”太泛，看不出义与文的对照。
- **建议**：“了解了义理、了解了经文以后，依法随法而行（dhammānudhammappaṭipanna）”。§301 句 91-301-89-111 同步修改。

## §301 句 91-301-2-19
- **问题**：称谓不一致 — `ဘန္တေ= ရား`，全经其余各处都译“大德”，这里作“尊者”（见跨段一致性）。
- **建议**：“那么大德，要具备什么条件……”
