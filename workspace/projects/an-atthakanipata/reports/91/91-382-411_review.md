# Review — 91:382-411（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性
- **sampadā / sampanna**（§398–411 偈颂）：这组偈颂以 sampadā 反复串连，译文大多译为“圆满”，但 §398 bījasampadā 译“优良的种子”，§402 bhojanasampadā 译“优良的饮食”，§398 khette sampanne 译“完备的田地”，§402 sampannasīlesu 译“持戒清净”。这样一来，同词复现的链条就断了。→ 建议统一为“圆满”，例如“圆满的种子”“圆满的饮食”“圆满的田地”“戒行圆满的人”。依据：nissaya 对 sampadā / sampanna 一律释为 ပြည့်စုံ（具足、圆满）。
- **dānavatthu**：§391 经题译“布施事经”，§392 正文译“布施的根据”，前后两种译法。→ 建议统一。nissaya 释为 ပေးလှူခြင်း၏ အကြောင်း（布施的缘由），正文可作“布施的缘由”，经题相应改为“布施缘由经”；如果保留“布施事”，正文也要改用“事”。
- **samaṇabrāhmaṇa**：§395 首句作“沙门、婆罗门”（中间有顿号），§395 后文与 §397 都作“沙门婆罗门”（无顿号）。→ 建议统一为一种写法。
- **imaṃ me dānaṃ dadato**：§384、§392 都译成“我作这样的布施”。imaṃ 是“这个”，指眼前这一次布施，不是“这样的”。→ 两处同改为“我作这个布施”或“我正在作这布施”。
- **cittālaṅkāracittaparikkhāratthaṃ**：§384、§392 都译“为了装备自己的心”。nissaya 把 parikkhāra 释为 အခြံအရံ（随从、资助、辅助），“装备”是硬译。→ 两处同改为“为了庄严心、资助心”。

## §384 句 91-384-28-67
- **问题**：词义 / 补出成分。āsajja 的 nissaya 是 `အလှူခံပုဂ္ဂိုလ် ရောက်လာ၍`（受施者来到时），异释为“因与受施者相遇”，并补注“不拖延，让对方稍坐即恭敬布施”。译文“一遇上就当即给出布施”缺了“遇上”的对象，读者无从知道遇上的是谁。
- **建议**：改为“有人在受施者来到时当即给出布施”。

## §384 句 91-384-68-94
- **问题**：格与指代。`မေ= ငါ၏`（属格）、`ဒဒတော= ပေးလှူသော`，意为“正在布施这个（施物）的我的”美名传扬。imaṃ 指“这个”布施，见跨段一致性一节。parikkhāra 的“装备”同上。
- **建议**：改为“有人想着‘我作这个布施，美好的名声就会传扬出去’……；有人为了庄严心、资助心而给出布施”。

## §392 句 91-392-18-86
- **问题**：增译。pasīdati 的 nissaya 是 `ကြည်လင်၏`（明净、澄清），译文“清净安适”多出了“安适”。imaṃ 与 parikkhāra 的问题同上。
- **建议**：改为“心就清净，生起满意和喜悦”。

## §394 句 91-394-2-41（§394-81-96、§396 同句式连带）
- **问题**：词义。phātiseyyaṃ 的 nissaya 详注是 `ဖာတိ(ဝုဍ္ဎိ)- စည်ပင်တိုးပွားသော။ သေယျာ- ကိန်းရာတည်ရာ`，指种子“栖身之处”即稻丛长得繁茂（`ဝီဟိထမ္ဗ`，稻丛、稻株丛聚）。“丰盛的长势”太泛，没有体现“稻丛”这个具体所指。mahassādaṃ 的 nissaya 是 `များသော … အရသာ`（多甘美的滋味），“好的滋味”丢了“多、大”。
- **建议**：改为“不会有大的收成，不会有丰厚的滋味，不会长成繁茂的稻丛”。§394-81-96、§396-2-16、§396-52-64 同步修改，肯定句相应改为“会长成繁茂的稻丛”。

## §394 句 91-394-45-80
- **问题**：词义（轻微）。mariyāda 的 nissaya 首释是 `ကံသင်းရိုး`（田埂），“田界”偏抽象。pāsāṇasakkharika 的 nissaya 是“大石、小石块、碎陶片”，原文没有“布满”的强度。
- **建议**：改为“没有良好的田埂”“有石块和碎砾”。§396 的肯定句同步修改。

## §395 句 91-395-2-22（§395-48-65、§397 两句同句式连带）
- **问题**：词义。nissaya 把四种果分别释为：mahapphala `ကံတူမူရင်းအကျိုး`（直接本果），mahānisaṃsa `ဆင့်ပွားအကျိုးအာနိသင်`（衍生利益），mahājutika `တောက်ပြောင်သော အကျိုး`（光明之果），mahāvipphāra `ကျယ်ပြန့်သော အကျိုး`（广大之果）。“果利”不是现代汉语常用词，“大的广布”语义不完整。
- **建议**：改为“不会有大的果报，不会有大的利益，不会有大的光辉，不会有广大的影响”。§395-48-65、§397-2-18、§397-44-60 同步修改。

## §399 句 91-399-2-15
- **问题**：漏译。sampādayantamhi 的 nissaya 是 `ကောင်းစွာ ရွာသွန်းလသော်`（雨好好地降下时）。译文“降下雨水”缺了“好好、适时”的意思，而这正是 sampad- 的词根义。
- **建议**：改为“而雨水又下得适时充足”。

## §402 句 91-402-2-9
- **问题**：词义。sampannasīlesu 的 nissaya 是 `ပြည့်စုံသောသီလရှိသော ပုဂ္ဂိုလ်`（具足戒的人），是“圆满、具足”，不是“清净”。bhojanasampadā 的问题见跨段一致性一节。
- **建议**：改为“同样，对戒行圆满的人，布施了圆满的饮食”。

## §403 句 91-403-2-9
- **问题**：补出成分。nissaya 把 taṃ kataṃ 补为 `ထိုကုသိုလ်ကောင်းမှု`（他所作的那件善业），把 sampadānaṃ 释为“善的圆满”（欲界、广大、出世间三种）。译文“圆满的事”过于空泛。
- **建议**：改为“就带来种种善的圆满，因为他所作的善业是圆满的”。

## §408 句 91-408-2-10
- **问题**：增译（轻微）。lokaṃ 的 nissaya 是 `ခန္ဓာငါးပါးဟူသော လောက`（五蕴世间），译文“这个世间”中的“这个”是原文没有的指示词，容易让人读成眼前的人世。
- **建议**：去掉“这个”，改为“如实地了知世间”。

## §409 句 91-409-2-6
- **问题**：误读，属**必改项**。āgamma 的 nissaya 是 `ရောက်၍`（到达），不是“依着……而行”。yāti 的 nissaya 是 `ရောက်၏`（到达），并补出宾语 `(ဟုတွာ … အရဟတ္တံ)`，即“成为心圆满者之后，到达阿罗汉果”。译文“心意圆满地前进”既把 sampannamānaso 误作状语，也丢了“到达”的终点。
- **建议**：改为“到达圆满的道，心意圆满，就趋向最高的果位”。如果不愿补出“阿罗汉果”，至少改作“到达圆满的道，心意圆满而前往（终点）”，不能只说“前进”。
