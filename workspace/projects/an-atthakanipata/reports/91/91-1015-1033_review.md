# Review — 91:1015-1033（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **paribhāsati**：§1016、§1017、§1019、§1020、§1022、§1023 都译作“诋毁”，用法一致，但与 nissaya 不符。`ပရိဘာသတိ= (ဘေးကိုပြ၍) ခြိမ်းခြောက်၏`（以危害相示而恐吓），§1017 否定式 `န ပရိဘာသတိ= မခြိမ်းခြောက်` 也是这样解。→ 六处统一改为“恐吓”，也就是“辱骂、恐吓比丘们”“不辱骂、不恐吓在家人”。经名、摄颂不受影响。
- **pavedeyyuṃ**：§1018 经名、§1019、§1020 都译作“宣告”。nissaya `ပဝေဒေယျုံ= သိစေထိုက်ကုန်၏။ ဝါ= သိအောင် ဖော်ပြထိုက်ကုန်၏`（使知道、显示出来），补注说明方式是不起座、不礼拜、不迎接、不布施，也就是用行动表示，不是口头宣布。§1020 `ပသာဒံ= ... ဝါ= ကြည်ညိုပုံအမူအရာကို`（表示信乐的举止）也支持这个理解。→ 统一改为“表明”：经名作“表明不信乐经”，正文作“可以向他表明不信乐／信乐”。
- **覆钵／翻钵的巴利夹注**：§1016 夹注 `pattanikkujjana`（带 patta-），§1017 夹注 `ukkujjana`（不带 patta-），两处体例不一致。→ 统一为 `pattanikkujjana`／`pattukkujjana`，或者两处都去掉 patta-。
- **dhammika**：§1022、§1023 译作“合法的承诺”。nissaya `ဓမ္မိကံ= တရားနှင့် လျော်ညီသော`（与法相符的），“合法”容易被理解成法律意义上的合法。→ 两处统一改为“如法的承诺”，与本 chunk §1024“如法行事”的“如法”用法相呼应。

## §1019 句 91-1019-2-19
- **问题**：词义 — `pavedeyyuṃ` 的取义见上文跨段一致性。另外，nissaya 给 `appasādaṃ` 补出了领属成分 `(မိမိတို့၏) မကြည်ညိုခြင်းသဘောကို`（他们**自己的**不信乐），`bhikkhuno` 是与格 `အား`（向这位比丘）。现译“宣告对他不信乐”把与格处理成了“对他”，意思能通，但动作方向是“向他表明”。
- **建议**：改为“在家信徒们如果愿意，可以向他表明自己的不信乐”。

## §1020 句 91-1020-2-17
- **问题**：同 §1019，`pasādaṃ` 指表示信乐的举止，`bhikkhuno` 是与格。
- **建议**：改为“可以向他表明自己的信乐”。§1020 句 91-1020-58-75 跟着同步修改。

## §1025 句 91-1025-2-59
- **问题**：误译（必改）— `na ca tena mūlena vuṭṭhāpetabbo`。nissaya 的解释是 `တေန မူလေန= ထိုတဿပါပိယသိကာကံ အပြုခံရသော ရဟန်းဟူသော အရင်းမူလပဓာနပုဂ္ဂိုလ်ဖြင့်`（以这位受了觅罪相羯磨的比丘为主导者），`န ဝုဋ္ဌာပေတဗ္ဗော= (အခြားရဟန်းကို သံဃာဒိသေသ်အာပတ်မှ) မထစေရ။ ဝါ= ... အဗ္ဘာနကံမပြုရ`（不得使**其他比丘**从僧残罪中出罪，即不得主持出罪羯磨）。可见 `tena mūlena` 不是“以此为由”，`vuṭṭhāpetabbo` 的对象也不是他本人，是别的比丘。现译“也不得以此为由而被复权”在主宾关系和词义上都错了。
- **建议**：改为“也不得由他主导，使其他比丘从僧残罪中出罪”。

- **问题**：词义／语体 — `na sāmaṇero upaṭṭhāpetabbo`，nissaya 作 `မပြုစု မလုပ်ကျွေးစေရ။ ဝါ= ပြုစုလုပ်ကျွေးမခိုင်းရ`（不得让沙弥服侍、供养自己）。“畜养沙弥”是律典旧译的写法，带文言色彩，意思也偏成了“收养”。
- **建议**：改为“不得让沙弥服侍自己”。

- **问题**：语体（次要）— `paccekaṭṭhāne`，nissaya 作 `သံဃကံဆောင် အကြီးအကဲရာထူးသီးခြားတခုခု၌`（主持僧团羯磨的某个特定的首领职位）。“首席的位置”意思大体不错，但不够明确。
- **建议**：改为“不得被安排担任任何主持僧事的职位”。

- **问题**：夹注（次要）— 沙弥是常见的传统译名，按 style.md 不需要夹注 `sāmaṇera`。
- **建议**：删去“（sāmaṇera）”。

- **原文疑问**：nissaya 在列出八项之前指出 `[ဤနေရာ၌ "ကတမေသု အဋ္ဌသု"ဟူသော ပုစ္ဆာဝါကျ ပါသင့်၏။ စာကျနေဟန်တူ၏]`，意思是这里应该有“Katamesu aṭṭhasu”这个问句，原文似乎脱漏了。只作记录，不改。

## §1031 句 91-1031-6-187
- **问题**：句法结构误读（必改）— nissaya 把每个人名都读作独立一经的主语：`အထခေါ= ထိုအခါ၌။ ဗောဇ္ဈာ= ...။ ဥပါသိကာ= သည်။ ယေန ဘဂဝါ ... ဥပသင်္ကမိ`，后面每个名字都重复 `အထခေါ ... သည်။ ယေန ... ပ။`，并且说明要按第 43 经《毗舍佉经》展开省略部分。nissaya 的长注还明确指出，不应当把这些名字“当作并列的计数清单”来译（`အရေအတွက်သင်္ချာအနေဖြင့် အနက်ပြန်ဆိုရန် မသင့်လျော်`）：这是 26 部经，每一部都是一位女信徒去见世尊、听闻八支布萨。现译“那时，女信徒薄奢……，还有西丽玛、巴杜玛……”把它们串成了一个名单，主语和谓语的关系也丢了，因为原文的省略里谓语是“来到世尊那里”。
- **建议**：按每人一经的结构改写，补出省略的谓语。例如：“那时，女信徒薄奢来到世尊那里……（同第四十三经，下同）。那时，女信徒西丽玛……；那时，女信徒巴杜玛……”，后面依次类推。至少要去掉“还有”这种并列连接，标明各自成经。

- **问题**：编者校注混入正文 — “（此处的‘那时’和‘女信徒’只见于义注，巴利文本中没有）”是原文方括号里的校勘注，不属于经文。而且其他校勘注（bojjhaṅgā、sudhanā、rūpī 等）都没有译，处理方式前后不一。
- **建议**：从译文正文中删去这条校注。如果需要保留，改为脚注。

- **问题**：身份补出（参考）— nissaya 补出了几个人的身份：`စုန္ဒီ= ... ရာဇကုမာရီ`（王女准底）、`သုမနာ= ... ရာဇကုမာရီ`（王女苏摩娜）、`မလ္လိကာ= မလ္လိကာမိဖုရား`（末利迦王后）、`ကောလိယဓီတာ= ကောလိကမင်းသ္မီး`（拘利族公主）。原文没有这些身份词，译文不必补，但“拘利族的女儿”可以考虑改成“拘利族公主”。
- **建议**：可选修改，不是必改项。
