# Review — 91:989-999（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（989、990-25-51 单列行、991-2-17、991-18-20、991-21-54、992 无独立 nissaya；990 与 991 八支列举的 nissaya 附在 52-66、55-72 行内，据此核对）

## 跨段一致性
- **nidhānakusalo**：§990、§991 都译「善于藏匿赃物」，与 nissaya 取义相反（见 §990 句 91-990-25-51）。两处须一起改，改法保持一致。
- **hanati**：§990「杀害女人」、§991「不杀害女人」两处一致，但都比 nissaya 的取义窄（见 §990）。如果修改，两处要同步。
- **yaṃ 的所指**：§994、§996 只译「所应证得的」，没有补出宾语；§995、§997 补成「无上的法」。按 nissaya，yaṃ 在四段中都指同一个「功德聚」（ဂုဏ်အပေါင်း）。建议四段统一处理：要么都不补宾语，要么都补「功德」。
- **称号夹注巴利原词**：§993 中「沙门（samaṇa）」「通达明智者（vedagū）」「医王（bhisakka）」加了夹注，「婆罗门」「无垢者」「离垢者」「有智者」「解脱者」没有加。同一组八个称号的夹注体例应统一：要么全加，要么只给非常见译名加。

## §990 句 91-990-25-51
- **问题**：误读 — **nidhānakusalo** 的 nissaya 是 `နိဓာနကုသလောစ= (မြတ်သော အလှူခံ ပုဂ္ဂိုလ်၌) လှူဒါန်းမြှပ်နှံခြင်း၌ လိမ်မာကျွမ်းကျင်သည်လည်း`，意思是「（在殊胜的受施者那里）以布施来储存的事上善巧」。nidhāna 取的是「把财物存放在福田」这一义，不是「藏匿赃物」。现译「又不善于藏匿赃物」与 nissaya 的取义相反。
- **建议**：改为「也不善于（把财物）布施给值得供养的人来储存福德」一类的说法。如果要保留字面上的「储藏」，至少不能写成「赃物」，可以写「不善于储藏财物（于福田）」。§991 的「并且善于藏匿赃物」同步修改。

- **问题**：语义偏差 — **appaharantassa** 的 nissaya 是 `မိမိကို ရိုက်နှိက်မည့် ရန်သူမဟုတ်သော ပုဂ္ဂိုလ်ကို`，意思是「不会打他、不是他仇敌的人」。补注又说明，这指持戒等有德行的人、老人和小孩。现译「没有攻击他的人」带有已经发生的时态色彩，好像只是对方「还没动手」，与 nissaya「本来就不会对他动手、不是敌人」的意思有出入。
- **建议**：「他攻击不与他为敌（不会打他）的人」。§991 的「不攻击没有攻击他的人」同步修改。

- **问题**：取义偏窄 — **hanati** 的 nissaya 是 `ညှဉ်းဆဲပုတ်ခတ် သတ်ဖြတ်၏`，包括折磨、殴打、杀害三层意思。现译只取了「杀害」。
- **建议**：「伤害女人」或「殴打、杀害女人」。§991 同步修改。

## §993 句 91-993-34-45
- **问题**：词义 — **vedagū** 的 nissaya 是 `လေးပါးသော မဂ်ဉာဏ်ဖြင့် နိဗ္ဗာန်ကို ထိုးထွင်းသိမြင်တော်မူသော ပုဂ္ဂိုလ်`，意思是「以四道智通达涅槃的人」。「通达明智者」中的「明智」容易被理解为「聪明、理智」，偏离了「以道智通达」的意思。
- **建议**：改为「通达者」或「明达者」。§995 同步修改。

## §995 句 91-995-2-8
- **问题**：修饰关系 — nissaya 把 `အနုတ္တရံ` 放在最前面，用来修饰 `ယံ= အကြင်ဂုဏ်အပေါင်းသို့`。也就是说，「无上」管的是整行的 yaṃ，vedagū 与 bhisakka 两个分句都包括在内。现译把「无上的法」只挂在医王一句上，并且把 yaṃ 的所指补成了「法」，而 nissaya 补的是「功德聚」。
- **建议**：「凡是通达者、医王所应证得的无上（功德）」，或者让「无上的」修饰两个分句的共同宾语。宾语的补法按跨段一致性一节统一。

## §997 句 91-997-2-9
- **问题**：同 §995 — **anuttaraṃ** 修饰 yaṃ，管 ñāṇī 与 vimutta 两个分句，现译只挂在后一句上，宾语也补成了「法」。另外，nissaya 把 **ñāṇinā ca** 释为 `သဗ္ဗညုတဉာဏ်တော်ရှင်သည်သာလျှင်`（唯有具一切知智者），ca 带强调义，现译没有体现出来。
- **建议**：调整修饰关系。强调义可以酌情补出，例如「唯有具智者……」。

## §998 句 91-998-2-10
- **问题**：补出成分 — nissaya 在 §994–§997 每个半偈后都补出了 `(တံ= ထိုဂုဏ်အပေါင်းသို့။ မယာ= ငါဘုရားသည်။ ပတ္တံ= ရောက်တော်မူအပ်ပြီ)`（那功德已被我证得）。现译把这一句集中放到本段开头，译成「这一切我都已证得」。这种处理在语义上成立。不过 **so ahaṃ** 的 so 是回指前文的「那位（证得者）我」，现译「我就是那在战斗中取胜的人」把 so 译成了「那……的人」，回指关系变了。
- **建议**：「这一切我都已证得。我已在战斗中取胜……」。so 回指已由前一分句承担，后一分句不要再造出「就是那……的人」的判断句。
- **问题**：补出成分 — **vijitasaṅgāmo** 的 nissaya 是 `အောင်အပ်ပြီးသော ငါးတန် ဆင်နွှဲ မာရ်စစ်ပွဲ`（已战胜的五魔之战），明确了战斗的对象。
- **建议**：可以译为「已战胜（魔军）之战」，括号内的内容按 nissaya 补出。

## §999 句 91-999-2-10
- **问题**：语态 — **paramadanto** 的 nissaya 是 `အမြတ်ဆုံးဓလေ့ ယဉ်ကျေးသိမ်မွေ့တော်မူသည်`，补注说明「不须师教，凭本具的殊胜智而调柔」。现译「已被最好地调伏」用「被」字被动句，暗示有另一个施事者来调伏他，与 nissaya「自己调御」的意思相反，而且有翻译腔。
- **建议**：「是最上调御的龙象」或「是调伏得最好的龙象」，去掉「被」。
- **问题**：词义提示 — **parinibbuto** 的 nissaya 是 `ကိလေသာဟူ အပူကင်းဝေး ငြိမ်းအေးတော်မူသည်`（远离烦恼热恼、已寂灭清凉）。这里说的是烦恼的寂灭，不是指入灭（去世）。「已经完全涅槃」容易被读成去世。
- **建议**：「烦恼已彻底寂灭」，或者「已经完全寂灭清凉」。
- **问题**：词义提示（可选）— **nāgo** 的 nissaya 是 `အကုသိုလ်အမှု မပြုရှောင်ကြဉ် သူတော်စင်`（不造恶业的圣者），取的是 na āguṃ karoti 的词源义。「龙象」是传统译法，可以保留，但要知道 nissaya 的取义并不是「大象」。
