# Review — 91:43-62（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核）

## 跨段一致性
- appiya / piya：§44、§45、§47、§48 的套句译作“不被同修梵行者喜爱 / 被……喜爱”，但 §44、§45 的复合词 appiyapasaṃsī / piyagarahī 却译作“不可爱的人 / 可爱的人”。建议统一用“（不）受喜爱”。依据：nissaya 两处都作“被（大家）喜爱 / 不被喜爱的人”。另外，“可爱”在现代汉语里多指外表讨喜，容易误读。
- lokadhammā / ete dhammā（八种世间法）的指代：§53 译“这些法”，§55、§56、§59 译“这些事物”，§57 译“合意的法”，§58 译“不合意的事物”。建议统一为“世间法”（回指时可以用“这些世间法”）。依据：nissaya 在 §53、§55、§57、§58 都明确释为 လောကဓံ（世间法）。
- paṭighāta（§58）与 virodha（§59）都译成“抗拒”，两个词被混为一词。建议分别译作“苦恼（或瞋恼）”和“反感”，详见各句。
- vipariṇāmadhamma：§54 译“必定变坏”，§56 译“会变坏的”。两处说法一致，但词义都偏窄，建议统一改为“会变异的”，见 §54。
- anavaññattikāmo：§47 译“希望不被轻视”，§48 却译“不是希望不被轻视的人”，同组其他各项都是“不 + 动词”结构。建议 §48 改为“不希望不被轻视”，与“不贪求利养，不贪求恭敬”平行。
- akkosakaparibhāsako：§47、§48 都译“辱骂毁谤”，两处同错，见 §47。
- lābha：§44、§45 的 lābhakāmo 译“利养”，§50、§51 的 lābho 译“得到”。语境不同，可以不强求同字，但 §50、§51 应补出宾语，见 §50。

## §44 句 91-44-30-59
- **问题**：词义 — appiyapasaṃsī= (အများရှင်လူတို့၏) မချစ်အပ်သူကို ချီးမွမ်း…（称赞不被众人喜爱的人），另一种解释（ဝါ）是称赞失去好感、被人厌恶的人。译文作“不可爱的人”，偏成了“长相 / 性情不讨喜”的意思。piyagarahī= ချစ်မြတ်နိုးခံရသူကို ကဲ့ရဲ့…，ကဲ့ရဲ့ 是“指责、批评”，译文作“诋毁”，语气过重。
- **建议**：改为“称赞不受人喜爱的人，指责受人喜爱的人”。

## §45 句 91-45-25-60
- **问题**：同 §44，“不可爱的人 / 可爱的人”、“诋毁”需要同步修改。
- **建议**：改为“不称赞不受人喜爱的人，不指责受人喜爱的人”。

## §47 句 91-47-29-59
- **问题**：误译 — akkosakaparibhāsako= ဆဲရေးတတ်, ဘေးကိုပြ၍ ခြိမ်းခြောက်တတ်…（辱骂，并以祸害相威胁、恐吓）。paribhāsaka 在这里是“恐吓”，不是“毁谤”。
- **建议（必改）**：改为“并且辱骂、恐吓同修梵行者”。
- **问题**：取义偏宽 — akālaññū= စကားပြောသင့်ရာ အချိန်အခါကို မသိ（不知道该说话的时机），另一种解释是在不该说话的时候说话。amattaññū 在 nissaya 里限定为“（就接受、使用资具而言）不知分量”。译文只作“不知时”“不知量”，读者无从知道指的是什么。
- **建议**：考虑改为“不知道说话的时机，（接受和使用资具时）不知节制”。若保留简译，至少让 §48 的正面句同步一致。

## §48 句 91-48-25-59
- **问题**：误译 — anakkosakaparibhāsako 同 §47，“毁谤”应为“恐吓”。另有结构不平行：“不是希望不被轻视的人”。
- **建议（必改）**：改为“……不希望不被轻视，知道说话的时机，知节制，清净，不多话，并且不辱骂、不恐吓同修梵行者”。

## §50 句 91-50-2-22
- **问题**：词义与句法 — lokaṃ= သတ္တဝါအပေါင်းသို့（向众生），loka 在这里是众生世间。anuparivattanti= အစဉ်တစိုက် လိုက်ပါကုန်၏（始终紧随）。lokadhammā 是主语，lokaṃ 是追随的对象。译文“随着世间转动”是逐字的翻译腔，“转动”也不合 nissaya 的“紧随”。
- **建议**：改为“这八种世间法总是紧随着众生，众生也总是紧随着这八种世间法”。§50 句 91-50-49-68 同步修改。

## §50 句 91-50-26-48
- **问题**：词义 — lābho= စီးပွားဥစ္စာရခြင်း（得到财物），alābho 是得不到财物。译文“得到和得不到”缺宾语，意思悬空。yaso= အခြံအရံ အကျော်အစောရှိခြင်း（有随从、有名望），译文“名声”只覆盖了一半。
- **建议**：改为“得利和失利，有名望和没有名望，受责备和受称赞，快乐和痛苦”。nindā、pasaṃsā 的另一种解释作被动“受责备 / 受称赞”，与“得利 / 失利”同为遭遇，读起来更顺。

## §51 句 91-51-2-9
- **问题**：同 §50，“得到和得不到”缺宾语，“名声”偏窄（ယသာယသော 同样释为“有 / 无随从名望”）。
- **建议**：与 §50 同步改为“得利和失利，有名望和没有名望”。

## §53 句 91-53-2-7
- **问题**：格 — manujesu= လူတို့၌（在人们当中，处格）。ete dhammā 是主语，nissaya 补出 (အဋ္ဌ) 八种。译文“人间的这些法”把处格改成了定语，“法”的指代也不清楚。
- **建议**：改为“在人们身上，这些世间法都是无常的”。

## §54 句 91-54-2-4
- **问题**：词义 — vipariṇāmadhammā= ဖောက်ပြန်ပြောင်းလဲခြင်းသဘောရှိ（具有变异、反转的性质）。nissaya 的注说明，这是指得与失、誉与毁交替出现，所以这八法都是 saṅkhāra。“必定变坏”只表达了由好变坏一个方向。
- **建议**：改为“不会长久，是会变异的”。

## §55 句 91-55-2-9
- **问题**：隐含成分与指代 — nissaya 补出 (ယော) 作关系主语，ete= ထိုလောကဓံ ရှစ်ပါးတို့ကို（这八种世间法，宾格）。译文作“这些事物”，指代泛化了。
- **建议**：改为“有正念、有智慧的人了知这些世间法”。

## §56 句 91-56-2-4
- **问题**：句法 — vipariṇāmadhamme= …သဘောရှိသော တရားများဟူ၍（“作为”会变异的法），是 avekkhati 的宾语补足语，表示观察的内容。译文“观察这些会变坏的事物”把它读成了定语，观察的内容就丢了。
- **建议（必改）**：改为“观察到它们是会变异的”。

## §58 句 91-58-2-5
- **问题**：词义与主语 — aniṭṭhato= …လောကဓံ အဆိုးဝါး တရားကြောင့်（因为不合意的世间法，从格表原因）。paṭighātaṃ= ဆင်းရဲညှိုးနွမ်းပင်ပန်းခြင်းသို့（陷入苦恼困顿），另一种解释是瞋恚。na eti 的主语，按 nissaya 承 §57 是 (အဿ စိတ္တံ) 他的心。译文“心生抗拒”不对应苦恼或瞋恚，也与 §59 的 virodha 撞了词。
- **建议（必改）**：改为“他的心也不会因为不合意的世间法而陷入苦恼”。异释“瞋恚”按 style.md 第四节放脚注。

## §59 句 91-59-2-9
- **问题**：格 — tassa= ထိုသတိပညာရှိပုဂ္ဂိုလ်၏（那位有正念智慧者的，属格），修饰 anurodhā / virodhā。另一种解释读作施事“被他”，连到 vidhūpitā。译文“对这些事物的”把 tassa 误读成了指世间法。
- **问题**：词义 — anurodhā= …လောကဓံအကောင်းတို့ကို လိုက်လျောခင်မင် လိုချင်မှု（对得利、名望等的迎合、贪恋）。virodhā= …လောကဓံ အဆိုးတို့ကြောင့် ဒေါသလွှမ်းမိုး…（因失利、恶名等而起的瞋恼、不快）。“顺从 / 抗拒”没有译出贪恋与瞋恼的意思。
- **建议（必改）**：改为“他对顺境的贪恋，或者对逆境的反感”。

## §60 句 91-60-2-6
- **问题**：词义与连贯 — vidhūpitā= (ဝိပဿနာဉာဏ် မဂ်ဉာဏ်ဖြင့်) ဖျက်ဆီးအပ်（被观智、道智摧毁），译文“驱散”偏弱。§59 若按主释取属格“他的”，这里的“被他”就与之重复，两句各取了一种解释。
- **建议**：改为“都已被摧毁、灭尽，不再存在”。

## §62 句 91-62-2-8
- **问题**：句法与隐含成分 — nissaya 的结构是：(သော) 这位有正念智慧者，bhavassa pāragū= ဘဝ၏ အပြီးအဆုံး…သို့ရောက်သော ရဟန္တာ（到达有之尽头的阿罗汉），后接 (ဟုတွာ) 已成为……。他了知 padaṃ= နိဗ္ဗာန်（涅槃）之后，sammā pajānāti= ကောင်းစွာ သိ（正确地了知），补出的宾语 (တံ) 是“自己已到达有之尽头这件事”，由省察智了知。译文“完全地了知，成为……到彼岸者”把 pāragū 当成了了知的结果，因果倒置，sammappajānāti 的宾语也丢了。bhavassa 是属格（“有 / 生存的”彼岸），“超越生存的”是误读。
- **建议（必改）**：改为“他已到达存在的彼岸，正确地了知这一点”。§61 的 padaṃ 按本行 nissaya 指涅槃，“无尘”指无烦恼之尘，现译“无尘无忧的境地”可以保留，必要时加脚注说明 padaṃ 指涅槃。
