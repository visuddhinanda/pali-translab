# Review — 99:1425-1442（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1425、1442 无 nissaya，略过）

## 被解释词对父层核对

逐条比对 84:293-302 定稿译文，以下黑体全部逐字相同：邪见、具有邪见的人、正见、具有正见的人、不如理作意、如理作意、比丘们，具有邪见的众生、具有正见、他随其见解而圆满受持、执取的身业、随其见解、还有思、思、希求、心愿、诸行、比丘们，因为他的见解是恶劣的、种、吸取、苦涩、不甜美。

切分有问题的一处见 §1432 句 99-1432-24-27。

## 跨段一致性

- **yathādiṭṭhiyaṃ ṭhitakāyakamma**：§1432 译“安立在见解上的身业”（两处，含黑体），§1440 句 99-1440-30-52 译“依其见解而起的身业” → 统一为「安立在见解上的身业」。
- **micchācāra**：§1432 译“邪淫”，§1440 句 99-1440-30-52 译“邪行” → 统一为「邪淫」。
- **gahita**：§1432 句 99-1432-28-31 用它解释 samādinnaṃ，译“取受”；同段句 99-1432-104-113 的 gahitaṃ 译“把持”；§1440 的 gahitā / gahitāni 译“取” → 统一为「取受」，至少 §1432 内部须一致。
- **yojanā / yojetvā**：§1432 句 99-1432-118-168 译“组句”，§1440 句 99-1440-30-52 译“配合起来” → 统一，建议「套用（这个句式）」。
- **“由此没有罪恶 / 福德”句式**：
  - 问题：三处译法不统一。
    - §1432 的 pāṇaṃ hanato… 两处译成动词串“杀生、取不与之物、行邪淫，由此并没有罪恶”，没有“对于…的人”。
    - 同段句 99-1432-118-168 的语业、意业部分译作“对于说谎的人……”。
    - §1440 也作“对于离杀生的人……来说”。
  - 依据：nissaya 对 hanato / ādiyato / carato 都补出 `(ပုဂ္ဂလဿ= ပုဂ္ဂိုလ်အား။)`，是与格的“对于…的人”。注文在句 99-1432-118-168 明说语业、意业“同样地”组句，所以句式必须平行。
  - 建议：§1432 三处都改为“对于杀生的人、拿取别人没有给的东西的人、行邪淫的人，由此并没有罪恶”。
- **diṭṭhi（单用）**：父层与 §1426/§1432 译“见解”，§1440 句 99-1440-2-15 的 diṭṭhīti 译“见”。
  - 依据：这里引的是本经 Diṭṭhi hissa… 一句的词，父层译文是“见解”。
  - 建议：改为“这里所说的‘见解’”。§1430 句 99-1430-63-97 的 diṭṭhi nāma 是泛称，可保留“见”。
- **Tattha**：§1429 译“这里”，§1430/§1431/§1432 译“其中”。
  - 依据：nissaya 作 `ထို…နှစ်ပါးတို့တွင်`，意思是“在这两者之中”。
  - 建议：统一为「其中」。
- **vaṇṇanā**：§1425 品题译“注释”，§1441 品末译“解释” → 统一（建议「注释」）。
- **语体**：句 99-1432-44-74、99-1432-75-103、99-1432-118-168 中的“取不与之物”带文言虚词“之”，为必改项 → 改为“拿取别人没有给的东西”。

## §1426 句 99-1426-2-15
- **问题**：误译。
  - nissaya：`ဒုတိယေ= ဒုတိယဝဂ်၌`，意为“在第二品”。
  - 译文却作“在第二经里”。
- **建议**：改为“在第二品里，**邪见**这个词……”。

## §1429 句 99-1429-12-25
- **问题**：补出成分越出依据。
  - nissaya：`ယာဝ နိယာမောက္ကမနာ= မိစ္ဆတ္တနိယာမသို့ သက်သည်တိုင်အောင်`，只补出这里的决定是“邪性决定（micchattaniyāma）”。
  - 译文补的“也就是成为不可转的决定邪见”多出“不可转”的解释，正文里不该有。
- **建议**：改为“……则会一直增长，直到进入邪性决定（micchattaniyāma）”。另把句首“这里”改为“其中”（见上）。

## §1430 句 99-1430-63-97
- **问题**：句法误读。
  - 主语误读：paṭikkhipitvā 的主语不是“这部经”。按 nissaya，结构是：`ဤအစီအရင်ကို ပယ်၍ … ဆိုအပ်၏`，即“排除这种分类之后……这样说”。
  - 状语误读：imasmiṃ sutte 是 vacanato 的状语，nissaya 作 `ဤသုတ်၌ … ဟောတော်မူသောကြောင့်`，即“由于在这部经里说了……”。
  - 漏译：句末 `…ti vuttaṃ`（这样说）没有译出，结果把注释家的论断说成了经文本身的主张。
- **建议**：改为“不过，（这里）排除了上面这种分类，说：由于这部经里说了‘比丘们，具有邪见的’，那么乃至……凡是叫做见的，都没有能力把人引向天界，而是一定会让人沉没在地狱里。”

## §1430 句 99-1430-98-125
- **问题**：漏译强调词。
  - nissaya：`မုဂ္ဂမာသပ္ပမာဏာပိ= …အတိုင်းအရှည်ရှိသည်လည်းဖြစ်ကုန်သော`。
  - -pi 表示“即使只有”，是比喻的要点：连极小的石子也会下沉。
- **建议**：改为“就像即使只有绿豆、黑豆那么大的石子，投进水里也绝不会浮起来……”。

## §1430 句 99-1430-2-33 / 99-1430-34-47（nissaya 讹误，记录）
- **问题**：nissaya 本身有讹误，译文按 pali 译，是正确的，不需要改。
  - saggāvaraṇā 与 maggāvaraṇā 两词的缅文释义互换了：句 99-1430-2-33 中 `သဂ္ဂါဝရဏာ စ= မဂ်ကို…`、`မဂ္ဂါဝရဏာ= နတ်ပြည်ကို…`。
  - 第三种（两者都不障碍）漏释。
- **建议**：不改译文，仅记录。

## §1431 句 99-1431-2-21
- **问题**：术语误读。
  - nissaya：`ကမ္မဿကတာသမ္မာဒိဋ္ဌိ= ကံလျှင်မိမိဥစ္စာရှိသည်၏အဖြစ်ကို မြင်တတ်သော`，意为“见到业才是自己所有物这一事实”。
  - sakatā 来自 saka（自己的），不是“自作”。“业自作”会被读成“自己造业”。
- **建议**：改为“业自性正见”（或“自业正见”）。句 99-1431-22-39 同步修改。

## §1432 句 99-1432-24-27 / 99-1432-28-31
- **问题**：被解释词切分与 nissaya 不符。
  - 父层“圆满受持、执取”在这里被切成“圆满受持 | 执取”两个被解释词。
  - nissaya：`သမတ္တံ= ပြည့်စုံစွာ`（只是“圆满”，副词），`သမာဒိန္နံ= ဆောက်တည်အပ်သော`（受持；句 99-1432-104-113）。
  - 结果“**圆满受持**的意思是完满”中，“受持”这部分没有得到解释。
- **建议**：被解释词改取父层子串——samattaṃ 取「**圆满**」，samādinnaṃ 取「**受持、执取**」。两者都与父层逐字相同。

## §1432 句 99-1432-44-74 / 99-1432-75-103
- **问题**：取义偏离 nissaya。
  - nissaya：`ပါပဿ= မကောင်းမှုကံ၏။ အာဂမော= ဖြစ်ခြင်းသည်။`，意为“罪恶的到来 / 发生”。
  - 译文“罪恶也不会有报应”把 āgama 解成了“果报”。
- **建议**：改为“罪恶也不会到来”。“取不与之物”与人称句式的问题见跨段一致性。

## §1437 句 99-1437-2-9
- **问题**：取义偏离 nissaya。
  - nissaya：`သာခါ= သရက်ခက်တို့သည်။ သာခံ= တမာခက်ကို။ နိသေဝရေ= ထိခိုက်ကုန်၏။`，意为“芒果树枝碰触苦楝树枝”。
  - “互相依靠”与原意不符。
- **建议**：改为“枝与枝相互碰触”。

## §1440 句 99-1440-30-52
- **问题**：
  - 一致性：“依其见解而起的身业”“离邪行”“配合起来”见跨段一致性。
  - 句式不平行：“没有由此而生的福德”与 §1432 的“由此并没有罪恶”结构不同。
- **建议**：改为“……来说，由此并没有福德”，并按跨段一致性统一术语。
