# Review — 99:1231-1241（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1231、1237-12-12 无 nissaya，略过）

## 父层被解释词核对

- §1232 **dāyikānan**：父层（84:247）译“布施者”，本层黑体“**布施者**” → ✅ 一致
- §1238 **visākhā**：父层译“毗舍佉”，本层黑体“**毗舍佉**” → ✅ 一致
- §1239 **pañca mahāpuññā**、**pañca amitabhogā**：父层未出现，由本层自定，无须比对

## 跨段一致性

- **visākhā migāramātā**：§1232 译“鹿子母毗舍佉”，父层 84:247 译“毗舍佉鹿子母” → 建议改为“毗舍佉鹿子母”。这处不是黑体被解释词，但同一人名的称法跨层应一致，巴利语序也是 visākhā migāramātā。
- **kāraṇākāraṇa-kusala**：§1239 句 99-1239-110-127 译“善于分辨该做什么、不该做什么”，§1241 句 99-1241-10-39 译“善于判断事情该不该办” → 同一复合词应统一。nissaya 两处都作 `အကြောင်းဟုတ်သည်, အကြောင်းမဟုတ်သည်၌ လိမ္မာ`（对“是因由／非因由”很精明），建议统一为“善于分辨什么该做、什么不该做”。
- **sālā**：§1241 三处（81-91、101-114、171-193）都译“会堂”。nissaya 作 `သာလံ= ဇရပ်သို့`，ဇရပ် 指路边或村口供人歇脚避雨的亭舍，不是集会用的厅堂 → 建议三处统一改为“亭舍”或“凉亭”。
- **Sumanadevī**：§1238 句 6-28 与 §1239 句 15-43 都译“苏摩那天女” → 见下方 §1238 条，两处须一并改。
- **对话引号**：§1241 句 171-193 与 194-205 都是那几个人说的话，nissaya 在 194-205 末尾补出 `(အာဟံသု= ဆိုကုန်၏)`。现译把它们拆成两段各自闭合的引号，读者容易误以为换了说话人。相比之下，206-217 与 218-238（毗舍佉的回答）是跨句连成一段引语的，体例前后不一 → 建议把 171-193 与 194-205 合成一段引语：删去 171-193 句末的“””和 194-205 句首的“““”。

## §1232 句 99-1232-2-17

- **问题**：词义 — nissaya 作 `ဒုတိယေ= ဒုတိယသုတ်၌`（在第二经中），译成“第二则里的”指代不清。
- **建议**：改为“第二经中的”。

## §1232 句 99-1232-18-40

- **问题**：词义译窄 — `အဓိကာရကမ္မံ= လွန်ကဲသော ကောင်းမှုကံကို` 是“殊胜的善业”，泛指功德行为。译成“殊胜的供养”，把它限定成了供养。
- **建议**：改为“做了殊胜的善业（adhikārakamma）”。

## §1232 句 99-1232-41-54

- **问题**：词义 — `ဂေဟေ= နန်းတော်၌`（在王宫中）。主人是国王，nissaya 明确作“王宫”，译成“家里”不够准确。
- **建议**：改为“出生在迦尸国王基基（Kiki）的宫中”。

## §1238 句 99-1238-6-28

- **问题**：专名误读 — nissaya 作 `သုမနဒေဝယာ နာမ= သုမနဒေဝီအမည်ရှိသော`（名叫 Sumanadevī 的），devī 是人名的一部分。她是凡人长者的妻子，译成“天女”会让读者误以为是天界女神。
- **建议**：音译全名，例如“苏摩那黛薇（Sumanadevī）”。§1239 句 15-43 同步修改。

## §1239 句 99-1239-15-43

- **问题**：格式 — “**五位****大福德者**”中四个星号相连，部分 markdown 渲染器会显示出错。
- **建议**：合并为“**五位大福德者**”。句 44-60 的“**五位****无量财富者**”同样处理。

## §1239 句 99-1239-44-60

- **问题**：省略成分未补、语义偏差 — nissaya 补出了省略的谓语：`မေဏ္ဍကသေဋ္ဌိယေဝ ... (အမိတဘောဂေါ= ...စည်းစိမ်ရှိသောသူသည်) န= မဟုတ်သေး`，意思是“拥有无量财富的不只文荼迦长者一人”。现译“不只是文荼迦长者……还有五位”，读起来像五人在文荼迦之外另有其人，但文荼迦本身就在这五人之中。
- **建议**：改为“而且拥有无量财富的不只文荼迦长者一人；在频毗娑罗大王统治的地方，有所谓的**五位无量财富者**，就是树提迦（Jotika）、阇提罗（Jaṭila）、文荼迦、富那、迦迦瓦利（Kākavaliya）。”

## §1239 句 99-1239-158-178

- **问题**：风格 — “第二天应供，第二天在自己家里”中“第二天”紧接重复。
- **建议**：后一个改为“次日”，或改写为“……应供。第二天，他在自己家里……”。

## §1240 句 99-1240-37-56

- **问题**：词义 — `အာယာစိံသု= တောင်းပန်ကုန်၏`（恳请、请求），nissaya 补出 `(ဝတွာ= လျှောက်ဆို၍)`，表示大臣们说完后提出请求。译成“举荐”，变成了推荐，动作性质不同。
- **建议**：改为“于是他们请求（国王）派文荼迦长者的儿子檀那阇耶长者去”。

## §1241 句 99-1241-121-147

- **问题**：**误译（必改）** — nissaya 作 `ကာရိတပတ္တံ ဝိယ= ပြုစေအပ်သောအဖြစ်သို့ ရောက်သကဲ့သို့`（好像到了“被造作出来”的状态），可见 patta 是 pāpuṇāti 的过去分词“达到”，不是“钵”。整句说的是：有些女子的美貌像是装扮造作出来的。现译“只像一只做得漂亮的钵罢了”把 patta 误读为钵，意思完全错了。
- **建议**：改为“不过有些女子的美貌，像是装扮出来的一样”。

## §1241 句 99-1241-194-205

- **问题**：句法存疑 — nissaya 把 kiṃ 读作“什么”，作 `ကရေယျာသိ` 的宾语：`ဧဝမေဝံ= ဤသို့လိုက်သည်ရှိသော်။ ကိံ ကရေယျာသိ= အဘယ်သို့ ပြုရာအံ့နည်း`（被这样追赶时，你会怎么做？）。现译把 kiṃ 当疑问语气词，把 evamevaṃ 当“也这样”，译作“你也会这样做吗”，与 nissaya 的分析不同。从上下文看，现译的读法也讲得通。
- **建议**：留给定稿人判断。若按 nissaya，改为“要是有大象或者马在后面追你，你会怎么办？”；若保留现译，压低该句 confidence。
