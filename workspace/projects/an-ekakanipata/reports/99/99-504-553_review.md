# Review — 99:504-553（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（多数段有，504-553 中 505-2-6、509-2-5、514、516、522、527、528、539-2-6 本行无 nissaya）

> 注：本 chunk 的 nissaya 行与句坐标有错位。不少行的内容属于前一句或后一句，例如 518 行是 519 的 sapañño naro，526 行后半是 528 的 yo sarabho / silāya / yoggaṃ。下文按**词的内容**对应句子引用，不按行号对应。

## 父层被解释词核对

- 本 chunk 的黑体词有 ciṇṇavasito、guṇātirekato、mahāmoggallānattheropi、mahākassapattheropi。它们都**不**引自父层 84:162-164，引自本层前文对四种理由和长老名单的列举，所以这里不适用父层逐字核对。
- 父层把 etadagga 译作“第一”。本层 etadaggaṭṭhāna 全部译作“第一的地位”，和父层一致，没有问题。
- 前文没有放进本 chunk：§540、§541 的黑体“娴熟自在”“功德超胜”需要和前文首次列出四种理由时的译法逐字相同，harmonize 时要核一下。

## 跨段一致性

- **mahāpaññatāya（作 etadagga 的范围）**：§540、§541 句末 nissaya 是 `မဟာပညတာယ= ကြီးကျယ်သော ပညာရှိသည်၏ အဖြစ်၌`，用的是**处格 ၌**，意思是“在大慧这一项上”获得第一，不是“凭着大慧”获得第一。现在 §539-7-29、§540-6-22、§541-6-24 三处都译成“凭着智慧广大而获得了第一的地位”，把处格译成了工具格，**必改**。建议三处统一改为“获得了智慧广大方面的第一地位”。§541 句中的 mahāpaññatāya（“在智慧广大上能与法将相比”）nissaya 用的是 ဖြင့်，现译正确，不用改。
- **四种理由的 -to 夺格**：aṭṭhuppattito 译“从事缘上”（§542、§548），āgamanato 译“从宿世来历上”（§539、§547、§553），ciṇṇavasito / guṇātirekato 译“因为……”（§540、§541、§547、§553）。nissaya 四者一律用 `ကြောင့်`（因为）。建议统一为一个句式，例如“因为事缘／因为宿世来历／因为娴熟自在／因为功德超胜而获得……”。
- **Kathaṃ?**：§542-15-16 译“怎样获得的呢？”，§548-12-13 译“怎么获得的呢？”。建议统一为“怎样获得的呢？”。
- **imehi kāraṇehi**：§542 译“理由”，§548 译“原因”。另外 §548 漏了“四种”，nissaya 补出了 `(စတူဟိ= လေးပါးကုန်သော)`。建议统一为“这全部四种原因”。
- **amuñcitvā / avijahitvā va**：这两处是平行结构。§540 译“总是不离开四谛来讲”，§553 译“从不舍弃十种论事来讲”，句式不一致，而且“从不舍弃……来讲”读起来容易理解成“从不……讲”。建议 §553 改成“总是不离开十种论事来讲”，和 §540 对齐。
- **本生引出句**：§506 译“……作为事缘，讲了另一个本生——”，§510 译“……作为事缘，讲了——”，两处处理不一致。而且这两处都和偈后的 §509“他讲了这个《月光本生》”、§539“他还讲了……《沙罗跋本生》”重复了“讲了”。nissaya 把 kathesi 只挂在偈后一处。建议 §506、§510 都以“……作为事缘——”收尾，动词只留在偈后。
- **āsīsetheva / vāyametheva 四句（§511、§513、§515、§517）**：四处都拆成“人……，有智慧的人……”两个主语，必须一起改，见下文 §511。
- **passāmi … 句（§512/§516、§514/§518）**：两组各自重复，要一起改，见下文。
- **parinibbutaṃ（§546、§552）**、**susamāhitindriyaṃ（§545、§551）**：两组要同步改，见下文。
- **pabbajī（§543、§549）**：译“出家修行”，而散文 §542、§548 的 isipabbajjaṃ pabbajito 译“出家做仙人”。nissaya 在偈中也补出了 `(ဣသိပဗ္ဗဇ္ဇံ)`。建议偈中也作“出家做仙人”，或至少两组偈内保持一致。

## §507 句 99-507-2-10
- **问题**：词义。gādhati 的 nissaya 是 `သက်ဝင်၏`（进入、深入）。§509 里 nissaya 把 `ဂါဓတိ ပဝိသတိ= ဝင်၏` 合起来释为“进入”。现译“立足于”偏离了这个释义。
- **建议**：改为“谁在这里能以智慧深入月光和日光”。§509 的“立足、进入、跃入”要同步改成“深入、进入、跃入”之类。

## §509 句 99-509-6-41
- **问题**：同 §507，gādhati 译成“立足”和 nissaya 不符。pakkhandati 的 nissaya 是 `ပြေး`（奔赴、冲入），“跃入”可以接受。
- **建议**：把“在这两者中立足、进入、跃入”改为“深入、进入、冲入这两者”。

## §511 句 99-511-2-10（§513、§515、§517 同）
- **问题**：句法，主语拆分。nissaya 是 `ပဏ္ဍိတော= ပညာရှိသော။ ပုရိသော= ယောက်ျားသည်။`，paṇḍito 是 puriso 的定语，全句只有一个主语“有智慧的人”，两个动词都归它。现译拆成“人……，有智慧的人……”，成了两个主语。另外 āsīsetheva 的 nissaya 是 `သုခဖြစ်ခြင်းငှာ တောင့်တရာသည်သာလျှင်`，-eva 表示“只管、始终”。
- **建议**：§511、§513 改为“有智慧的人应当始终抱有希望，不应灰心；”。§515、§517 改为“有智慧的人应当只管努力，不应灰心；”。

## §512 句 99-512-2-10（§516 同）
- **问题**：句法，隐含主语。nissaya 补出 `(သဋ္ဌိဟတ္ထာ နရကာ ဥဋ္ဌာနံ) ဣစ္ဆိံ … (တတော ဥဋ္ဌိတော) အဟု`，意思是“我希望从六十肘深坑出来……（我）从那里出来了”。ahu 的主语是“我”，ဥဋ္ဌိတော 和 attānaṃ 相应。现译“事情就怎样成了”把主语换成了“事情”。
- **建议**：改为“我确实看到自己：我当初怎样希望，我就怎样做到了”，或者“我确实看到自己如愿以偿”。

## §514 句 99-514-2-8（§518 同；nissaya 分别在 §513、§517 行）
- **问题**：语态。ubbhataṃ 的 nissaya 是 `တက်ပြီးသော`（已经上来的），是 attānaṃ 的定语，没有被动的“被救”义。现译“被从水中救上了陆地”是加译。
- **建议**：改为“我确实看到自己已经从水里上到了陆地”。

## §521 句 99-521-2-8 → 关联 §522 99-522-2-4
- **问题**：句法，隐含主语。nissaya 在本行补出 `(တေသု အဟိတဖဿေန ဖုဋ္ဌာ)= 在这两种遭遇中，被有害遭遇触及的众生`，并把它作 `ဥပဗ္ဗဇန္တိ= ရောက်ကုန်၏` 的主语。也就是说，upabbajanti 的主语是“众生”，不是“遭遇”。现译 §522“都是未曾料想到的，临到世人身上”把 phassā 当主语、macca 当宾语，和 nissaya 的句法分析不同。
- **原文疑问**：maccam- 也可能是 maccum-（死亡）。nissaya 的分析更像“（受有害遭遇触及、）未曾料想的人走向死亡”。记下备查，不改原文。
- **建议**：§522 压低 confidence。按 nissaya 可改为“没有料想到的人就走向了死亡”。如果维持现译，要在报告中写明这一分歧。

## §525 句 99-525-2-12
- **问题一**：词义。pure 的 nissaya 是 `ယမန်နေ့၌`（前些天、日前），指不久以前，不是久远的“从前”。
- **问题二**：句法。nissaya 是 `ယံ တွံ= အကြင် သင်မင်းမြတ်သည်`，把关系从句挂在“你（大王）”上：“你这位前些天在险峻山中追逐沙罗跋鹿的人”。现译把中心词放在“那只鹿”上，和下句 §526 衔接不上，形成悬空的话题。
- **建议**：§525 与 §526 合起来调整，例如“前些天你在难以通行的山中追逐沙罗跋鹿，”／“如今你能活着，靠的是那只心不退缩的鹿的奋勇。”

## §526 句 99-526-2-6
- **问题**：所指不明，并有加译。alīnacittassa 的 nissaya 是 `မတွန်သောစိတ်ရှိသော သမင်ဆီးဆောက်၏`，明确是“那只心不退缩的鹿的”（属格）。现译“那心不怯懦者”没有点明是鹿；“今天”在原文和 nissaya 里都没有。
- **建议**：改为“你能活着，靠的是那只心不怯懦的鹿的奋勇”。

## §528 句 99-528-2-6（nissaya 在 §526、§529 行）
- **问题**：格。silāya 的 nissaya 是 `ကျောက်အဆင့်ဆင့်ဖြင့်`（用一层层岩石，**具格**），yoggaṃ 是 `တက်ခြင်းငှာလျောက်ပတ်သည်`（适合攀爬的东西）。现译“在岩石上给你搭作踏脚之处”把具格译成了处格。
- **建议**：改为“那只沙罗跋鹿用石块为你垒成可以攀上来的台阶”。

## §530 句 99-530-2-6
- **问题**：词义。vadesi 的 nissaya 是 `ချီးမွမ်းပြောဆို`（称赞着说），现译“称它为”漏了称赞的意思。原文 `ta migaṃ` 疑为 `taṃ migaṃ` 的讹误，只记录，不改。
- **建议**：改为“你称赞那只鹿心不怯懦”。

## §533 句 99-533-2-5
- **问题**：补出成分。nissaya 补出 `(ဥဒါဟု တွံ)`（还是你……），这是选择问句的第二项。现译“你是……吗”没有体现选择关系，和 §532、§534 的“还是”不平行。
- **建议**：改为“或者你是已除去覆障、无所不见者呢，”。

## §534 句 99-534-2-7
- **问题**：词义。bhiṃsarūpaṃ 的 nissaya 是 `အားကြီးစွာသော သဘော ရှိ`（极其强大的），现译“令人敬畏”偏向情感色彩。
- **建议**：改为“婆罗门，还是你的智慧非常强大呢？”。

## §540 句 99-540-2-5（nissaya 在 §539 行）
- **问题**：句法，补出成分，**必改**。nissaya 是 `ဏ္ဏဝသိတော= …အဖြစ်ကြောင့်။ (ဧတေဒဂ္ဂဋ္ဌာနံ) ကထံ(လဘိ)`，意思是“因为娴熟自在，怎样（获得第一的地位）？”。-to 是夺格（因为），问的是“怎样获得”，不是“怎样是”。现译“怎样是娴熟自在呢？”把问句改成了下定义。
- **建议**：改为“怎样是因为**娴熟自在**（而获得第一的地位）呢？”。黑体部分保持和前文列举处逐字相同。

## §540 句 99-540-6-22
- **问题一**：格，**必改**，见跨段一致性第一条。句末 mahāpaññatāya 是处格，表示 etadagga 的范围。
- **问题二**：kira 的 nissaya 是 `(ဝိတ္ထာရေမိ)= 下面详细说`，作承上展开的标记，不作传闻义“据说”。和 nissaya 有分歧，供 revise 斟酌。
- **建议**：把句末改为“……长老也因为娴熟自在，获得了智慧广大方面的第一地位”。

## §541 句 99-541-2-5
- **问题**：同 §540-2-5，**必改**。nissaya 是 `ဂုဏာတိရေကတော= ဂုဏ်အားဖြင့် လွန်ကဲသည်၏အဖြစ်ကြောင့်။ (ဧတဒဂ္ဂဋ္ဌာနံ) ကထံ(လဘိ)`。
- **建议**：改为“怎样是因为**功德超胜**（而获得第一的地位）呢？”。

## §541 句 99-541-6-24
- **问题一**：格，**必改**。句末 mahāpaññatāya 的 nissaya 是 `…အဖြစ်၌`（处格），见跨段一致性。
- **问题二**：hi 的 nissaya 是 `(ဝိတ္ထာရေမိ)`（展开说明），不是表因果的连词。现译句首“因为”可以省去。
- **建议**：把句末改为“……获得了智慧广大方面的第一地位”。句首“因为”可以删掉。

## §542 句 99-542-17-29
- **问题**：nissaya 的读法是 `နန္ဒောပနန္ဒာဒီနိ နာဂရာဇာနိ`（以难陀优波难陀为首的龙王们，复数），和本行 pali 的 nandopanandasadisampi nāgarājānaṃ（单数）是异读。现译依据 pali，可以保留。Nandopananda 在 nissaya 里是一个名字，“难陀优波难陀”中间不要加顿号，以免读成两条龙。
- **建议**：维持现译；如要更清楚，可以写成“难陀优波难陀龙王那样的龙王”。

## §545 句 99-545-2-5（§551 同）
- **问题**：词义。susamāhitindriyaṃ 的 nissaya 是 `ကောင်းစွာစောင့်စည်းအပ်သော ဣန္ဒြေရှိသော`（诸根善加守护、收摄），现译“完全安定”偏向“定”的意思。
- **建议**：改为“诸根善加收摄的”。

## §546 句 99-546-2-8（§552 同）
- **问题**：词义。parinibbutaṃ 的 nissaya 是 `ကိလေသာတို့မှ ငြိမ်းပြီးသော`（已经从烦恼中息灭的），指烦恼的息灭，不是命终的般涅槃。现译“已证般涅槃”容易让人理解为入灭，§552 讲大迦叶时尤其明显。
- **建议**：改为“你们应当礼敬这位烦恼已经息灭的目犍连／大迦叶”。

## §547 句 99-547-7-36
- **问题**：词义。saccakathaṃ 的 nissaya 是 `သစ္စာ စကား`（讲谛的话），“讲说谛法”的说法生硬。
- **建议**：改为“讲说四谛的法”，和 §540 的“四谛”呼应。

## §548 句 99-548-2-11
- **问题**：所指不明。esa 的 nissaya 是 `ဤ မဟာမောဂ္ဂလာန် မထေရ်သည်`，明确指大目犍连。现译“这位长老”指代不清。另外漏了“四种”，见跨段一致性。
- **建议**：改为“就像大目犍连长老一样，**大迦叶长老**也是因为这全部四种原因而获得了第一的地位”。

## §548 句 99-548-14-27
- **问题**：重复冗余。“为了迎接这位长老……去迎他”说了两次迎接。nissaya 是 `ထေရဿ … ပစ္စုဂ္ဂမနံ ဂန္တွာ`（为长老前去迎接），只有一个动作。
- **建议**：改为“正等正觉者走了三伽浮多（gāvuta）的路程去迎接这位长老，……”。

## §553 句 99-553-6-19
- **问题**：句式。“从不舍弃十种论事来讲”读起来容易理解成“从不……讲”。avijahitvāva 的 nissaya 是 `မစွန့်မူ၍သာလျှင်`（始终不舍弃地）。
- **建议**：改为“总是不离开十种论事来讲”，和 §540 平行。

## §553 句 99-553-34-43
- **问题**：情态。vaṭṭati 的 nissaya 是 `ဝတ္တတိ= ဖြစ်၏`（可以、适宜），比“应当”弱。nissaya 还补出 tesaṃ tesaṃ therānaṃ 是 `ကောဏ္ဍည-စသော`（以憍陈如为首的各位长老）。
- **建议**：改为“依照这同一个准则，对以憍陈如为首的各位长老，也可以按他们各自所得来称扬他们的功德”。补“以憍陈如为首”可选；如果补，要和父层的“阿若憍陈如”对上。
