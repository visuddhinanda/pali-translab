# Review — 99:1202-1210（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（标题段 1202 / 1205 / 1208 没有 nissaya，略过）／父层对照 84:238-240 ✅

## 被解释词与父层对照（第一项）

- §1203 **paṇītadāyakānan**：父层 84:238 译作“在布施上妙物品的人中”，本层黑体译作“**在布施上妙美味的人中**”，两者不同 → **必改**，黑体改为“**在布施上妙物品的人中**”。后面讲“味”的部分（paṇītarasa）属于义注自己的解释，放在“意思是说”之后，可以保留。
- §1206 **manāpadāyakānan**：父层 84:239 译作“在布施可意物品的人中”，本层黑体译作“**在布施可意饮食的人中**”，两者不同 → **必改**，黑体改为“**在布施可意物品的人中**”。“合心意的饮食”（cittarucitabhojana）同样放在“意思是说”之后解释。
- §1209 **saṅghupaṭṭhākānan**：与父层“在侍奉僧团的人中”逐字相同 ✅

## 跨段一致性

- **paṇītadāyakānaṃ / manāpadāyakānaṃ**（指为谁立第一位）：§1203-15、§1204-118 译“布施上妙美味的人中”，§1206-19、§1207-114 译“布施可意饮食的人中”，与父层的“上妙物品”“可意物品”不一致。§1204-118 的 pali 正文就是 paṇītadāyakānaṃ（nissaya 注明 paṇītarasa- 是异读）。→ 建议这几处都改成父层译法，读者才看得出指的是同一个第一位。§1203-15 的 pali 写的是 paṇītarasadāyakānaṃ，如果想保留“美味”，至少 §1204-118 要改回“上妙物品”。
- **tīṇi maggaphalāni**：§1206-84 译“其余三种道果”，§1210-58 译“三种道果（入流、一来、不还）”。两处 nissaya 都只是“三种道果”，没有“其余”的意思 → 统一用 §1210 的译法（见下文 §1206 条）。
- **bhikkhusaṅghaparivuto**：§1207-2 译“在比丘僧团的围绕下”，§1210-11 译“在比丘僧团的簇拥下”。nissaya 两处都是 ခြံရံအပ်သည်（被围绕）→ 统一为“围绕”。
- **dasabalassa paṭhamadassaneyeva**：§1203-37 译“第一次见到十力者”，§1206-84 译“在初次见到十力者时”→ 统一为“第一次见到十力者时”。
- **bhante**（对佛的称呼）：§1207-48 和 §1207-69 译“尊者”，但 nissaya 是 မြတ်စွာဘုရား（世尊）。“尊者”一般用来称呼比丘，在家人当面称佛不宜这样译 → 改为“世尊”或“大德”，两处一致。

## §1204 句 99-1204-32-61
- **问题**：词形 — 括注“营养（oja）”用的不是词干形，nissaya 作 ဩဇာ（ojā）。
- **建议**：改为“（ojā）”。

## §1204 句 99-1204-95-106
- **问题**：风格 — “按照同样的办法，照样供养”中“同样”和“照样”意思重复。nissaya 里 teneva niyāmena 的意思是“就按先前那种方式”。
- **建议**：改为“仍然按照先前的方式，供养陆续到来的比丘僧团”。

## §1206 句 99-1206-71-74
- **问题**：风格 — “高卓”偏书面、生僻。另外 uggatā 和下一句“两方面都高”是同一个词的双关，译法应当连贯。nissaya：ဥဂ္ဂတာ= 升高（တက်）。
- **建议**：改为“他的德行也一样高”。

## §1206 句 99-1206-84-94
- **问题**：误译 — “其余三种道果”多出了“其余”，读起来变成他还证得了一来、不还、阿罗汉三果，也就是成了阿罗汉，跟本句原意不符。nissaya：တီဏိပိ= သုံးပါးလည်းဖြစ်ကုန်သော（三种）／မဂ္ဂဖလာနိ= 道果，没有“其余”。pi 在这里是强调或包括的意思。
- **建议**：改为“后来又现证了三种道果（入流、一来、不还）”，与 §1210-58 一致。

## §1206 句 99-1206-132-146
- **问题**：句法 — api nu kho … āgaccheyya 是表达愿望的祈愿句，译成了单纯的疑问句。nissaya 补出了 (အဟော ဝတ= 啊，那该多好)。
- **建议**：改为“要是导师知道我的心意，也能亲自来到我家门口，那该多好！”

## §1207 句 99-1207-11-47
- **问题**：主语误读 — bhattakiccapariyosāne 指佛和僧团用斋结束，译文“吃完饭后，他坐在一旁”把吃饭的人误读成了郁伽。nissaya：ဘတ္တကိစ္စပရိယောသာနေ= 斋食事务结束时。
- **建议**：改为“等佛和僧团用完斋饭，他坐在一旁，这样说道——”。

## §1207 句 99-1207-69-100
- **问题**：时态 — dinnameva 表示“一定施给”，是在向佛表明决心，译成“都已经布施给……了”变成了已经完成的事。nissaya 这一行对应到 ဒေတိ（施予，现在式），没有完成义。
- **建议**：改为“凡是我觉得可意的东西，我一定都布施给以佛为首的比丘僧团”。

## §1210 句 99-1210-11-22
- **问题**：取义 — nāgavana 的 nāga，nissaya 释作 ကံ့ကော်（铁力木，nāga 树），不是“龙”。
- **建议**：改为“那伽林园（Nāgavana）”，或者意译为“铁力木林园”。如果保留“龙林园”，至少不要误导成跟龙有关。

## §1210 句 99-1210-39-46
- **问题**：风格 — “所有的酒醉都消失了”读起来生硬。nissaya：သုရာမဒေါ= 醉意／အဗ္ဘတ္ထံ အဂမာသိ= 消失。
- **建议**：改为“他的醉意就完全消失了”。

## §1210 句 99-1210-108-121
- **问题**：风格 — “在施与所施之物时”重复拗口。nissaya：ဒေယျဓမ္မံ ပန= 至于所施物／သမစိတ္တေနေဝ ဒေတိ= 只以平等心施予。
- **建议**：改为“但布施东西的时候，他对每一位比丘都一视同仁”。

## §1210 句 99-1210-122-128
- **问题**：风格 — “称说”偏书面。nissaya：တမေဝ ဂုဏံ= 只说那些比丘的德行／ကထေတိ= 陈说。
- **建议**：改为“他也只讲比丘们的德行”。
