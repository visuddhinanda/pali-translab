# Review — 99:1494-1503（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照（必改项）

- **§1495 句 99-1495-117-136**：黑体「那么，对于反复修习第一禅的人，还用说吗」与父层 84-355-38-47「至于那些反复修习它的人，就更不用说了」不同 → 必改为「**至于那些反复修习它的人，就更不用说了**」。黑体后的解释部分保持现状（naṃ = paṭhamajjhānaṃ 由解释部分补出）。
- **§1498 句 99-1498-2-33**：黑体「在身上随观身体」与父层 84-357-6-15「在身上随观身」不同 → 必改为「**在身上随观身**」。同句末尾「用智慧随观那个身体」也一并改为「那个身」。
- **§1501 句 99-1501-20-23**：黑体「为了……不生起」，父层作「为了使……不生起」，漏了「使」 → 必改为「**为了使……不生起**」。
- **§1502 句 99-1502-13-16 / 17-20 / 21-24 / 25-28 / 29-32 / 33-36**：父层 84-358-60-77 作「为了使已经生起的善法住立、不丧失、一再增多、广大、增长、圆满」。六处黑体都漏了「使」 → 必改为「**为了使……住立**」「**为了使……不丧失**」「**为了使……一再增多**」「**为了使……广大**」「**为了使……增长**」「**为了使……圆满**」。

其余黑体与父层逐字相同：一弹指、第一、禅、第二、慈、心解脱、悲、就这样生活、精勤、正知、具念、除去对世间的贪欲和忧恼、在各种感受上随观感受、世间、在心上随观心、在各种法上随观法、尚未生起的、恶劣的、不善法、生起意愿、努力、发起精进、提起心、精勤不懈、已经生起的、善法。

## 跨段一致性

- **satipaṭṭhāna 复合词**：
  - 现有译法：§1498 作「身随观念处」，§1499-81 作「感受随观念处」，§1500-110 却作「随观感受的念处」「随观心的念处」「随观法的念处」。
  - 建议统一为「身随观念处／感受随观念处／心随观念处／法随观念处」。
- **pajānāti**：§1499 引文译「了知」，§1500-8-55 引文译「他知道」。两处是同一段经文的同一句式，建议统一为「了知」：「有贪的心，了知这是有贪的心」。
- **eseva nayo**：§1497-21 作「在**悲等**上面，也是同样的道理」，§1500-2 作「对于**心和法**，也是同样的道理」。建议统一为「对于……，也是同样的道理」，去掉口语化的「上面」。
- **kāyānupassī 的「身／身体」**：§1498-71-87 的解释句「就这样在身上随观身体而生活」与父层不符，句式也别扭。建议改为「在身上随观身，就这样生活」，与父层 84-357 句式一致。

## §1495 句 99-1495-61-68 / 69-74 / 75-82 / 83-86 / 87-109
- **问题**：术语 — upanijjhāna 在标题词里译作「静虑」，词源解释里译作「专注审察」。nissaya 的释义是 `ဥပနိဇ္ဈာနတော= ကပ်၍ရှုတတ်သည်၏အဖြစ်ကြောင့်`（因为贴近观看）。「静虑」与「审察」两个词对不上，读者看不出「所缘静虑」这个名称来自「审察所缘」。
- **建议**：可考虑改为「所缘审虑／相审虑」，让名称与解释在字面上相扣。如果保留「静虑」，就把解释句改成「专注地静虑……」以呼应名称。

## §1495 句 99-1495-87-109
- **问题**：漏译 — `နိဗ္ဗာနဿေဝ= နိဗ္ဗာန်ကိုသာလျှင်`（只对涅槃），eva 没有译出。
- **建议**：改为「果则只专注审察以空、无相、无愿为相的涅槃」。

## §1495 句 99-1495-110-116
- **问题**：句法 — `တတ္ထ= ထို အာရမ္မဏူပနိဇ္ဈာန, လက္ခဏူပနိဇ္ဈာန နှစ်ပါးတို့တွင်`（在这两种之中），译文作「这里」，与后面的「在这个意义上」重复，限定关系也模糊了。
- **建议**：改为「在这两种之中，就本处的意义来说，所指的是所缘静虑。」

## §1497 句 99-1497-26-47
- **问题 1**：句法 — 原文五个谓语都用 honti，结构平行。译文却把第一个译成「是轮转法」，其余译成「可以成为」，前后句式不一致。
- **问题 2**：nissaya 把两个词分开解释：`ဝဋ္ဋာ= ကိလေသာဝဋ်`（烦恼轮转）、`ဝဋ္ဋပါဒါ= ဝိပါကဝဋ်၏ အခြေ`（异熟轮转的基础）。译文作「轮转法／轮转的基础」，两者的区分不明显。
- **建议**：改为「这四种梵住可以成为轮转，可以成为轮转的基础，可以成为观的基础……」，统一用「可以成为」。两种轮转的区分不必写进正文。

## §1498 句 99-1498-34-38
- **问题**：取义 — `ဣရိယတိ= ဖြစ်တတ်၏ / ဝတ္တတိ= တည်၏`。下一句明说这里讲的是威仪（iriyāpatho）。「行动、活动」与威仪之间的联系不明显。
- **建议**：改为「就是以威仪而行、而住」，与下句的「威仪」相扣。

## §1498 句 99-1498-39-47
- **问题**：增译 — `ဣရိယာပထော= ဣရိယာပုထ်ကို။ ကထိတော= ဆိုလိုသည်`，意思只是「说的是威仪」。译文「他的威仪是怎样的」多出了「怎样」的意思。
- **建议**：改为「这句话讲的是修习这十八种身随观念处的比丘的威仪。」

## §1499 句 99-1499-2-16 与 99-1499-17-80
- **问题 1**：句段错位 — `နဝဝိဓံ … အနုပဿန္တော` 只在 17-80 句，但 2-16 已经写了「随观如下所说的九种感受」，17-80 又写「他就是这样随观所说的九种感受」，内容重复，坐标对应也乱了。
- **问题 2**：句法 — 原文是省略写法：每种感受都各自配一句「感受 X 时，了知我在感受 X」，`ဝါ`＝或。译文用顿号把八种感受并列，再接「了知我在感受离爱染的不苦不乐受」，读起来像是感受苦受时也了知「我在感受离爱染的不苦不乐受」。这是误读。
- **建议**：
  - 2-16 删去「随观如下所说的九种感受」，改为「……就是在乐等各种感受中，对于这样说的感受——“在感受乐受时，了知我在感受乐受。」
  - 17-80 改为「在感受苦受时……感受不苦不乐受时……感受有爱染的乐受……（中略）……在感受离爱染的不苦不乐受时，了知我在感受离爱染的不苦不乐受。”（长部 2.380；分别论 363；中部 1.113）——随观这样说的九种感受。」

## §1501 句 99-1501-30-35
- **问题**：释义 — 被解释词是「努力」，解释又说「付出努力」，用原词解释原词。nissaya 作 `ပယောဂံ ပရက္ကမံ= ပြင်းစွာအားထုတ်ခြင်းလုံ့လ`（强力的勤勉）。
- **建议**：改为「就是加功用、奋力而为」。

## §1503 句 99-1503-11-20
- **问题**：补出成分 — `သဗ္ဗပုဗ္ဗဘာဂေ= ခပ်သိမ်းသောလောကီ, လောကုတ္တရာမဂ်တို့၏ ရှေ့အဖို့၌`，nissaya 补出了「道的」前分。译文「一切前分阶段」不清楚是谁的前分。
- **建议**：改为「世间的正勤出现在一切道之前的前分阶段」。
