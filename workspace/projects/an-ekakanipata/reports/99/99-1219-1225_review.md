# Review — 99:1219-1225（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1219、1221-92-99、1221-100-122、1221-123-139、1222、1224、1225 无 nissaya 行）
>
> ⚠ **nissaya 行错位**：99-1221-42-50 行的 nissaya 后半段是那拘罗父的整段话（yato me … passitun ti），99-1221-51-74 行的 nissaya 实际是那拘罗母的话（yato ahaṃ … nakulapituno gahapatissa … kuto pana kāyena）。下面按 nissaya 的实际内容对照相应句子。

## 被解释词与父层对照
- **vissāsakānaṃ**：父层 84-243 译「在说话亲切坦诚的人中」，本层 §1220 黑体「**在说话亲切坦诚的人中**」→ 逐字相同 ✅
- 同词在 §1220（21-42）和 §1221（140-160）作「说话亲切坦诚者的第一位」，与父层用词一致 ✅

## 跨段一致性
- **etadagga 品名**：§1224 译「最为第一品」，§1225 译「是第一品」→ 建议统一为「最为第一品」（与 §1224 一致，也与父层「最为第一的」对应）。另外 §1225 的 *Sattama-* 只保留了编号「七、」，品名里漏了「第七」，见下面 §1225 条。
- **ānītā（嫁入）的与格对象**：§1221 夫妻两段对称的话都漏了「嫁给谁」（见下面 51-74、100-122 两条），修改时两处要用同一句式，保持对仗。
- **saññatti / yathāmanena**：§1220（171-187）和（188-198）连续两句都译成「得到满足」，前一句取义不准（见下文），改后可以消除重复。
- 其余称谓（导师 / 世尊 / 十力者、那拘罗父 / 那拘罗母、居士妇、尊者）各段前后一致。

## §1220 句 99-1220-54-63
- **问题**：词法 — `ဘိက္ခုသံဃပရိဝုတော= ရဟန်းအပေါင်းခြံရံအပ်သည်ဖြစ်၍`（被比丘众围绕），这是被动分词作主语的状语。译文「在比丘僧团的随行下」把「围绕」改成了「随行」，句式也偏翻译腔。
- **建议**：「导师也由比丘僧团围绕着四处游行，到了那座城，住在毗舍迦罗林。」

## §1220 句 99-1220-64-111
- **问题**：词义 — `နိပတိတွာ= ဝပ်၍`（俯伏、拜倒）。译文「倒在导师的脚下」容易读成跌倒或瘫倒。
- **建议**：改为「两人都拜倒在导师脚下说……」。

## §1220 句 99-1220-171-187
- **问题**：取义 — `ပညတ္တိံ(saññattiṃ)= ပိုင်းခြား၍သိခြင်းသို့`（达到分辨清楚、明白过来的状态）。nissaya 的意思是心「平复、回过神来」，不是「满足」。译文「心里还没有得到满足」偏离了 nissaya。另外 `အပေထ= ဖဲကုန်လော့` 是复数命令（你们退开）。
- **建议**：「只要他们的心还没有平复过来，导师就一直没有说“你们退开吧”。」

## §1220 句 99-1220-188-198
- **问题**：词义 — `သတိံ= သတိကို … ပဋိလဘိတွာ` 在这里指恢复清醒、回过神来，是日常义，不是修道术语。译文用「正念」显得过重，读者容易理解为修行上的正念。`မဇ္ဈတ္တဘူတာနံ`（属格复数，修饰 nesaṃ）表示「变得平静中立的他们」，译文把这层关系处理对了。
- **建议**：「后来，他们随着心意得到满足、恢复清醒、平静下来，导师知道了他们的心意倾向，就为他们说法。」如果上一句已改为「平复」，这句保留「心意得到满足」不会重复。

## §1221 句 99-1221-51-74
- **问题**：格 — 依 42-50 行所附 nissaya `ဒဟရဿေဝ= ငယ်နုသည်သာလျှင်ဖြစ်သော။ မေ= အကျွန်ုပ်အား`，`me` 是与格（嫁给我），`daharassa` 修饰 `me`。译文「在我年少时、她也年少时嫁了过来」丢了与格对象，「嫁给谁」只能靠读者猜。
- **建议**：「尊者，自从那拘罗母居士妇年少时嫁给同样年少的我，我不曾对那拘罗母居士妇有过哪怕只是心里的逾越，身体上更不必说。」

## §1221 句 99-1221-100-122
- **问题**：格 — 依 51-74 行所附 nissaya `နကုလပိတုနော= … ဂဟပတိဿ= သူကြွယ်အား။ … အဟံ= အကျွန်ုပ်ကို။ အနီတာ= ဆောင်အပ်၏`，`nakulapituno gahapatissa` 是与格（嫁给那拘罗父居士），主语是 `ahaṃ`。译文「自从那拘罗父居士年少时、我也年少时嫁了过来」把与格对象误读为时间状语的主语。
- **建议**：「尊者，自从我年少时嫁给同样年少的那拘罗父居士，我不曾对那拘罗父居士有过哪怕只是心里的逾越，身体上更不必说。」与 51-74 保持对仗。

## §1225 句 99-1225-2-7
- **问题**：漏译 / 一致性 — *Sattamaetadaggavaggo* 是「第七最为第一品」。译文「七、是第一品」既漏了 *sattama*，品名也和 §1224 不一致（见跨段一致性）。
- **建议**：「（十四）七、第七最为第一品」。

## OCR / 原文疑问（记录，不改）
- §1220（21-42）：nissaya 底本作 *vissāsikānaṃ*，注出 Chaṭṭha 本作 *vissāsakānaṃ*（与本文一致）。
- §1220（43-53）：nissaya 底本作 *Magadharaṭṭhe*（摩揭陀国），注出 Chaṭṭha 本作 *bhaggaraṭṭhe*。pali 是 *bhaggaraṭṭhe*，译文「婆伽国」从 pali，不改。nissaya 底本又作 *saṃsumāra-*，与 *susumāra-* 拼法不同。
- §1220（112-154）：nissaya 漏了 *cūḷapitā* 一项（pali 有，译文「叔父」不缺）。
- §1220（171-187）：nissaya 底本作 *paññattiṃ*，注出 Chaṭṭha 本作 *saññattiṃ*（与 pali 一致）。
