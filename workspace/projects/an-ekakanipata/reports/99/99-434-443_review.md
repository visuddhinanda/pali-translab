# Review — 99:434-443（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 父层对照：84:153-155（已定稿译文）

## 被解释词与父层逐字核对

- **arahaṃ** → 「阿罗汉」（§442），与父层 §154「如来、阿罗汉、正等正觉者」一致 ✅
- **sammāsambuddho** → 「正等正觉者」（§442 两处），与父层一致 ✅
- **tathāgato** → 「如来」（§434/436/437），与父层一致 ✅
- **pātubhāvo** → 「出现」（§443），与父层 §155「在世间的出现是难得的」一致 ✅
- **dullabho lokasmiṃ** → 「**在世间是难得的**」（§443 句 99-443-12-20）✖ **必改**。父层是「在世间的出现是难得的」，没有「在世间是难得的」这个连续字串，加粗的部分不是从父层原样引出来的。建议按父层的两段分别加粗：「**在世间**……**是难得的**，意思是……」。

## 跨段一致性

- **tatho aviparīto**：§435 译「真实的、不颠倒的」，§438 译「如实而不颠倒的」 → 建议统一为「真实而不颠倒的」。这两处是同一种构词说明（tatha + āgada），措辞应该相同。
- **tatha 作 -vāditā / -kāritā 的前项**：§434 是「说**真实**的话」，§436 是「**如实**而行」，§439 是「**如实**地行去」。这三处并列解释同一个 tatha，可以考虑统一用「真实」或「如实」中的一个；至少 §435 和 §438 那组必须统一（见上一条）。
- **dakārassa takāraṃ katvā**：§435 译「把 tathāgada 的 d 换成 t」，§438 译「再把其中的 d 音改成 t 音」 → 同一个公式，建议统一为「把 d 换成 t」。
- **kāyo / vācā**：§436 句 6-21、22-34 用「身」「语」，句 35-43 却变成了「身行」「语言」 → 应统一为「身」「语」。nissaya 的 ကာယော= ကိုယ်တော် 指身体，不是身行（kāyakamma）。
- **abhibhavati**：§437、§438 句 18-29 后半、§438 句 30-45 都译作「胜过」，但 §438 句 18-29 的比喻部分译成「制服毒蛇」。同一个动词在同一句里拆成两种译法，比喻就对不上了（详见下方 §438）。
- **desanāvilāso / puññussayo**：§438 句 13-17 译「说法的巧妙」「积累起来的福德」，句 30-45 译「说法巧妙」「福德积累」 → 建议统一为「说法的巧妙」「积累的福德」。
- **引文收尾 Tasmā tathāgatoti vuccati**：§434 句 115-130 译「所以就称为如来」，§436、437、440 译「所以被称为‘如来’」 → 建议统一为「所以被称为……」。§434 的巴利原文没有内层引号，可以不加‘’。

## §434 句 99-434-7-79

- **问题**：词义。nissaya 的解释是 `ရာဂမဒနိမ္မဒနံ= ရာဂဖြင့် ယစ်ခြင်းကို နှိပ်နင်းတတ်၏`，其中 ယစ်ခြင်း 是「迷醉」。mada 指的是迷醉，不是「骄慢」（骄慢对应 māna）。dosamohamada 同理。
- **建议**：改为「能摧破贪欲带来的迷醉，能摧破嗔与痴带来的迷醉」。

## §434 句 99-434-82-114

- **问题**：词义，属于必改项。nissaya 的解释是 `တထမေဝ= မဖောက်မပြန်သည်သာလျှင်`，意思是「正是不颠倒、真实的」。这句引文是用来论证 tathavāditā（说真实的话）的，译成「都是那样」就丢了「真实」的意思，后面 §434 句 131-135 对 gata 的解释也就失去了依据。
- **建议**：「……这一切都是真实的，而不是别样。」

## §434 句 99-434-131-135

- **问题**：虚词。nissaya 在这一段把 hi 释为 `ဟိ (သစ္စံ)= မှန်၏`，是表示「确实」的强调语气，不是表示原因。译成「因为」会让读者以为这句是在解释上一句的原因。
- **建议**：「这里的 gata 一词，确实是 gada（言说）的意思。」

## §435 句 99-435-9-21

- **问题**：句法。nissaya 是 `အဿ= ထိုမြတ်စွာဘုရားအား … အာဂဒေါ= ဆိုတော်မူခြင်းသည် (အတ္ထိ)`，也就是「他具有真实不颠倒的言说」这一有财释（bahubbīhi）结构。译文中「也就是说真实而不颠倒的话的人」既重复了前半句，句子也不完整。
- **建议**：「他具有真实而不颠倒的言说（āgada），因此把 d 换成 t，成为 tathāgata（如来）；应当知道，在这个意义上，这个词也是这样构成的。」

## §436 句 99-436-35-43

- **问题**：术语漂移。「身行」「语言」与上文的「身」「语」不一致。
- **建议**：「并且身怎么样，语也就那样行去，所以叫做如来。」

## §437 句 99-437-6-38

- **问题**：词法（次要）。nissaya 把 tulā、pamāṇa 释为人：`တုလာ= တူသောသူ`（与他相等的人）、`ပမာဏံ= နှိုင်းယှဉ်ဖက် ဖြစ်သောသူ`（可与他相比的人）。译文「也没有什么能量度他」把 pamāṇa 理解成了度量的工具。
- **建议**：「没有能与他相等的人，也没有能与他相比的人」。

## §438 句 99-438-2-9

- **问题**：风格。用圆括号补出的「（有一样东西）」看起来像译者的工作标记。按 style.md，圆括号只用来夹注巴利原词。
- **建议**：直接写进正文：「凡是像药一样的，也叫做 agada（药）」，或「这个像药一样的东西也叫做 agada」。

## §438 句 99-438-18-29

- **问题**：主语与比喻结构，属于必改项。nissaya 是 `ဧသ= ဤမြတ်စွာဘုရားသည်`（主语是世尊），而 `မဟာနုဘာဝေါ ဘိသက္ကော … ဝိယ` 是比喻里的医师。译文「这位有大威力的医师就像用……」直接把世尊说成了医师，混淆了比喻的主体和喻体。另外，比喻部分和本体部分都用同一个动词 abhibhavati，译文却拆成「制服」和「胜过」两种说法。
- **建议**：「凭着这药，他就像有大威力的医师用天界的药胜过毒蛇一样，胜过了一切持异论者以及包括诸天的世间。」

## §438 句 99-438-30-45

- **问题**：(1) 跨段不一致，见上方「tatho aviparīto」「d→t」两条。(2)「于是 tatha 与 agada 合成 tathāgada」是巴利原文没有的补充说明，可以保留，但应与 §435 的写法统一。

## §439 句 99-439-2-18

- **问题**：句法。nissaya 把 tathaṃ 释为 `မဖောက်မပြန်သော … အကျင့်ကို`（真实的修行道路，宾格），gato 释为 `ကျင့်တော်မူ၏`（践行了）。译文「行向如实」把 tathaṃ 理解成了行进的方向。
- **建议**：「因为践行了真实的道路，所以叫做如来」。

## §439 句 99-439-19-26

- **问题**：句法，属于必改项。nissaya 是 `တထာယ= မဖောက်မပြန်သော` + `တီရဏပရိညာယ= တီရဏ-ပရိညာဉ်ဖြင့်`，tathāya 是修饰 pariññāya 的阴性具格形容词（「以真实的……遍知」），不是副词「如实地」。
- **建议**：「其中，他以真实的审察遍知了知了整个世间，所以叫做如来。」

## §439 句 99-439-27-47

- **问题**：句法，同上。nissaya 在这一句里，tathāya 分别修饰 pahānapariññāya 和 sacchikiriyāya；第三小句读作 `တထံ= မဖောက်မပြန်မှန်သော`，修饰 paṭipadaṃ。
- **建议**：「他以真实的断遍知越过了世间的生起……；他以真实的现证到达了世间的灭……；他践行了真实的、通向世间灭的道路……」

## §440 句 99-440-51-64

- **问题**：格位。nissaya 是 `လောကဿ= လူအပေါင်းသည်`（施事：被世间所……），以及 `တံ= ထိုအာရုံကို`（那个所缘）。lokassa 是被省略的过去分词（所见、所闻……）的施事，不是表示「世间里面的东西」。
- **建议**：「比丘们，凡是包括诸天的世间……乃至……的，这一切都已由如来正觉。」

## §441 句 99-441-2-6

- **问题**：指代。nissaya 是 `တဿ= ထို တထာဂတော ဟူသောပုဒ်၏`，tassa 指引文中「如来」这个词，而不是整段引文。
- **建议**：「这段话里‘如来’一词的意思，也应当这样来理解。」

## §442 句 99-442-2-23

- **问题**：(1) nissaya 是 `ပါပကရဏေ= … ရဟာဘာဝါ= ဆိတ်ကွယ်ရာအရပ် မရှိသည်၏ အဖြစ်ကြောင့်`，意思是作恶时「没有隐秘之处」。译文「没有隐秘地作恶」偏离了原意。(2)「（轮回之）车轮」用圆括号补出成分，属于风格问题；「之」又是文言虚词。
- **建议**：「由于他没有可以暗中作恶的隐秘之处」；「也摧毁了轮回车轮的辐条（ara）」。

## §443 句 99-443-12-20

- **问题**：被解释词与父层不一致，属于必改项，见文首核对表。
- **建议**：「**在世间**……**是难得的**，意思是在这个有情世间里难得、极难得、最难得。」

## §443 句 99-443-24-67

- **问题**：补出成分（次要）。nissaya 在后半句仍是 `ဒိဝသံ … ပတ်လုံး`，意思是「整整……天（圆满布施波罗蜜）」，动词承接前文的 pūretvā。译文补出的「修」与前文「圆满」不对应。
- **建议**：「同样，圆满一天、两天……十万俱胝天也不可能。」
