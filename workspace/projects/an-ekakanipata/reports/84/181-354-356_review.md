# Review — 181:354-356（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／父层（本文=义注 book 99，段 155-217）✅
> 本层为复注（ṭīkā），黑体被解释词引自父层义注，故以父层已定稿译文为逐字比对基准。

## 跨段一致性

- `attaguttatthera` / `assaguttatthera`：§354 末句译作「**像阿说笈多长老那样**」，与父层 99:209 的「阿说笈多长老」一致 ✅。但本层原文写作 `attaguttattherasadise`（Atta-），父层写作 `assaguttatthera`（Assa-）。复注这条正是在补出「地点是瓦答尼林」，译名沿用父层可保持对应，但**两处拼写分歧应在报告中记录**（属异读，不改译文）。
- `paṭisaṅkhāna`：§354 两处均作「审思」，与父层 99:209「经常审思」一致 ✅。
- `uggaha`：§354 标题黑体译「学习慈相」（父层同），后文散句译「学习」「学取」混用（`Uggaho ca yāva upacārā daṭṭhabbo` → 「学习」；`Uggahitāya` → 「已经学取的」）。同一词根在一段内两种译法，建议统一为「学取」或「学习」，见下条明细。
- `balavatara`：§355 两处黑体引文分别译「更为有力」「更有力」，与父层 99:210 的「更为有力」「还要更有力」逐字一致 ✅。
- 语体：全 chunk 为现代书面汉语，未见文言腔；标点为全角，未见 ASCII 引号 ✅。

## §354 句 181-354-2-9

- **问题**：被解释词对应 — 黑体 `**mettānimittassa** **uggaho**` 译作「**学习慈相**」，父层 99:209 同一词译「学习慈相」，**逐字相同** ✅。但本句正文把 `mettāyanassa hitūpasaṃhārassa` 译成「对众生的慈爱，也就是给予利益的心态」，两个属格被并列处理成同指。原文是 `mettāyanassa`（慈爱之行）与 `hitūpasaṃhārassa`（利益的施与）两个并列的属格宾语，同受 `uppādanaṃ pavattanaṃ` 支配。
- **建议**：改为「在众生身上生起、发动慈爱与利益的施与，这就是**学习慈相**」——保留两项并列，不用「也就是」把后者降为前者的同位解释。

## §354 句 181-354-18-29

- **问题**：被解释词对应 — 黑体 `**kammassakatā**` 译「**业为自己所有**」，父层 99:209 译「省察业为自己所有（kammassakatā）」，词形一致 ✅。但前半句「业才是这些众生自己的东西，所以众生是‘业为己有的’」中，`kammassakā, sattā` 的译法「业为己有的」与黑体「业为自己所有」在同句内用了两种措辞，读者难以看出是同一词的构词分析。
- **建议**：统一为「业为自己所有」：「业才是这些众生自己的所有物，所以众生叫做‘业为自己所有者’（kammassaka），这种状态就是**业为自己所有**，也就是以业为遗产。」

## §354 句 181-354-41-55

- **问题**：术语一致性 — 黑体 `**Odissakaanodissakadisāpharaṇānan**` 译「**限定的、不限定的以及遍满诸方的**」，父层 99:209 译「不论用限定的、不限定的还是遍满诸方的哪一种方式」，核心三词逐字相同 ✅。
- **问题**：`attaatipiyamajjhattaverivasena` 译作「自己、极亲爱的人、中立的人、怨敌」。`majjhatta` 译「中立的人」可，但慈心修习传统汉译作「无关者／中庸者」；且四类中缺了通常与「极亲爱」并列的层次感。此处属可接受的译法，不作必改。
- **建议**：可将「中立的人」改为「不相干的人」，更贴近 `majjhatta` 在四类补特伽罗中的所指；非必改。

## §354 句 181-354-78-83

- **问题**：术语 — `upacāra` 译作「近行」。本层此前未出现，父层亦无对应。「近行（定）」是 `upacārasamādhi` 的传统汉译，此处单用 `upacārā`（夺格，「到近行为止」）指的正是近行定，译法有据 ✅。但「学习是到近行为止的」中 `Uggaho` 与 §354 开头黑体「学习慈相」的「学习」同词，而下一句 `Uggahitāya` 却译「已经学取的」。
- **建议**：三处统一。建议正文一律用「学取」（`uggaha` 是取相，与「修习 bhāvanā」相对），黑体因须与父层逐字相同，保留「学习慈相」不动；即：「而且应当知道，学取是到近行为止的。」「对已经学取的慈相反复修习，就是修习。」

## §354 句 181-354-88-102

- **问题**：漏译／译不尽 — `attabhāvapariyāpannā` 译作「一切含摄于自身之中的众生」。该词在慈心五类中指「摄属于个体自身的（生命）」，即 `attabhāvapariyāpannā`（凡摄于个体身内者）。译文「含摄于自身之中的众生」易被读成「包含在自己里面的众生」，指涉不明。
- **建议**：改为「一切摄属于个体自身的（生命）」或「一切归于个体自身所摄的」。另，`pāṇā` / `bhūtā` 译「一切生物／一切生类」区分度不足，建议依传统作「一切有息者（pāṇa）／一切已生者（bhūta）」。

## §354 句 181-354-103-119

- **问题**：术语一致性（必改） — 黑体 `**anodhisopharaṇā**` 译「**不限定的遍满**」，而 §354-41-55 黑体 `anodissaka...` 译「不限定的」——两处为 `anodhiso` / `anodissaka` 两个不同但同义的词形，译法一致是对的 ✅。问题在下一句：`**odhisopharaṇā**` 译「**限定的遍满**」，与本句「不限定的遍满」构成对立 ✅。但父层 99:209 的对应表述是「以限定、不限定或遍满诸方的方式」——父层把 `disāpharaṇa` 与前两者并列为第三项，本层却把 `odhiso/anodhiso` 当作 `pharaṇā` 的修饰语（「限定的遍满」）。两层结构解读不一致，读者会察觉矛盾。
- **建议**：本层译法（`odhisopharaṇā` = 限定的遍满）在复注语境下是正确的，因为复注正是在区分「限定遍满」与「不限定遍满」两类。**不改本层**，但应记入 `knowledge/known-issues.md`：父层 99:209 的并列译法与复注的解读有张力，若日后 harmonize 父层，宜把 99:209 改为「以限定遍满、不限定遍满或遍满诸方的方式」。

## §354 句 181-354-120-156

- **问题**：数字错误（必改） — 原文 `asītādhikacatusatappabhedā` 意为「四百加八十」＝ **四百八十种**（`catusata` 四百 + `asīti-adhika` 多八十）。译文作「五百二十种」，数字算错。
- **建议**：改为「就有四百八十种」。
- **问题**：`vinipātikā` 译「堕处众生」可 ✅；`sattādhikaraṇavasena` 译「以有情为对象」中 `adhikaraṇa` 此处是「依处／所依」，译「为对象」尚可，但与下文「以方位为对象」并列时，「对象」易与「所缘」混。
- **建议**：`adhikaraṇa` 统一译「依处」：「按有情为依处而进行的有七种」「按方位为依处而进行的有十种」。

## §354 句 181-354-179-181

- **问题**：句子不完整 — 译作「在瓦答尼林中的**像阿说笈多长老那样**。」这是复注的补注体（原文即省略动词，仅补出地点），但中译成了一个没有谓语的残句，读者读不通。
- **问题**：拼写异读 — 本层原文作 `attaguttattherasadise`（Attagutta），父层 99:209 作 `assaguttatthera`（Assagutta）。译名沿用父层「阿说笈多」以保持被解释词对应是对的，但异读须记录。
- **建议**：补出承接语：「**像阿说笈多长老那样**——指在瓦答尼（Vattani）林中的那位长老。」并把 Attagutta／Assagutta 的异读记入 `knowledge/known-issues.md` 第二节。

## §355 句 181-355-2-16

- **问题**：语义 — `tappaṭipakkhānaṃ visosanasabhāvatāya` 译「使与善法相违的诸法枯干的性质」。`visosana`（使枯干）译得直，可接受；但「相违的诸法」宜明确为「与之相反的（不善）法」。
- **问题**：逻辑连接 — 译文「所以精进是从发勤界开始转起的，因此说道」中连用「所以…因此…」，两个结果连词叠加。原文是 `...sabhāvatāya ca ... pavattavīriyanti āha`，即「因为具有…性质，（所以）这是从发勤界等开始转起的精进，于是说道」。
- **建议**：改为「…所以这是从发勤界起次第转起的精进，于是说道——」，去掉重复的「因此」。

## §355 句 181-355-24-32

- **问题**：被解释词对应 ✅ — 引文 `**kosajjato** **nikkhantattā** **tato** **balavataran**` 译「**因为它已经脱出了懈怠，所以比前者更为有力**」，父层 99:210 作「**精勤界**是指比前者更为有力的精进，因为它已经脱出了懈怠」，用词逐字相同（语序因引文独立成句而调整，可接受）✅。
- **问题**：`kosajjavidhamanaṃ thāmagamanañca natthi` 译「还没有摧毁懈怠，也还没有达到强盛」。`thāmagamana` 是「达到强力（thāma）」，译「达到强盛」可 ✅；但「摧毁懈怠」的 `vidhamana` 与下文 §355-43-56 的 `thāmagata` 译「强盛」一致 ✅，无须改。

## §355 句 181-355-43-56

- **问题**：术语 — `laddhāsevanaṃ` 译「变得纯熟」。`āsevana` 在本 chunk 父层 99:163 译作「习惯」（`laddhāsevanassa` → 「有了这样的习惯」），99:156 译「不曾习惯于」。此处复注用同一词指精进的「反复修习而得熟习」，译「纯熟」与父层「习惯」不一致。
- **建议**：此处语境是善法的反复修习（对比父层的烦恼习染），译「纯熟」在语义上更准；但为可追溯，建议作「一次又一次地生起而获得了修习的纯熟」，并在 `terms.md` 登记 `āsevana`：烦恼语境作「习染／习惯」，善法语境作「修习纯熟」。

## §356 句 181-356-2-16

- **问题**：被解释词对应 ✅ — `**āraddhavīriyo**` 两处均译「**发勤精进的人**」，与父层 99:211「**发勤精进的人**」逐字相同 ✅。
- **问题**：构词分析的两重意思被压平 — 原文是两重释义：`āraddhaṃ saṃsādhitaṃ paripūritaṃ vīriyaṃ`（已发动＝已成就、已圆满的精进）与 `āraddhaṃ paṭṭhapitaṃ vīriyaṃ`（已发动＝已建立的精进），即 `āraddha` 一词的两个解：「圆满」义与「起始／建立」义。译文两句都以「已经发动」开头，把被区分的那个词本身译成同一个词，读者看不出复注在区分什么。
- **建议**：改为「他的精进已经完成、已经成就、已经圆满，所以叫**发勤精进的人**，也就是精进已经成办的人；他的精进已经着手、已经建立起来，所以叫**发勤精进的人**。」——第一重用「完成」，第二重用「着手」，把 `āraddha` 的两义分开。

## §356 句 181-356-37-47

- **问题**：指代不明 — 译文以「他用…来说明」开头。本层前后句均无「他」的先行词（主语是复注作者），突然出现「他」使读者困惑；本 chunk 其余处理方式是省略主语（如 §355「所以说道——」）。
- **建议**：改为「接下来用“**既不过于退缩**”等等，来说明这离开四种过失的状态。」

## §356 句 181-356-56-60 / 61-65

- **问题**：被解释词对应 — `**atilīnatā**` 译「**过于退缩**」、`**ajjhattaṃ** **saṃkhittatā**` 译「**向内收缩**」、`**Atipaggahitatā**` 译「**过于振奋**」、`**Bahiddhā** **vikkhittatā**` 译「**向外散乱**」，与父层 99:211「既不过于退缩，也不过于振奋；既不向内收缩，也不向外散乱」**逐字相同** ✅。
- **问题**：`Bhāvanāvīthiṃ anajjhogāhetvā` 译「没有深入修习的轨道」。`vīthi` 是「道路」，译「轨道」可；但「深入…轨道」搭配生硬，且与下句「深入进去以后」的「深入」需呼应。
- **建议**：改为「还没有进入修习的轨道就发生退缩，这就是**过于退缩**；进入之后又在里面退缩，这就是**向内收缩**。」——两句用同一动词「进入」，对比才立得住。

## §356 句 181-356-73-80

- **问题**：被解释词对应（必改） — 黑体 `**kāyikaṃ**` / `**cetasikaṃ**` 译「**身的**」「**心的**」，父层 99:211 的对应黑体是 `**kāyikavīriyaṃ**` → 「**身的精进**」、`**cetasikavīriyaṃ**` → 「**心的精进**」。本层黑体只到形容词（原文确实只有 `kāyikaṃ` / `cetasikaṃ`），译成孤零零的「是**身的**」「是**心的**」，中文读不成句。
- **建议**：补出中心语并保持与父层用字一致：「这精进当中，带来经行等身体运作的是**身的**（精进），除此以外的是**心的**（精进）。」——括号补出，黑体本身仍只覆盖「身的／心的」，既读得通又不破坏对应关系。

## §356 句 181-356-95-101

- **问题**：被解释词对应 — `**Milakkhatissattherassa**` 译「**蔑隶车帝须长老**」。父层 99:173 译作「弥拉卡帝须（Milakkhatissa）长老」，父层 99:211 译作「蔑隶车帝须长老」。**父层自身两处不一致**，本层跟的是 99:211。
- **建议**：本层沿用「蔑隶车帝须长老」不改（与最近的父层出处一致）；应记入报告并在 harmonize 阶段统一父层 99:173 与 99:211 的译名，建议统一为「蔑隶车帝须（Milakkhatissa）长老」，首次出现夹注巴利原词。
- **问题**：`**mahāsīvattherassa**` 译「**摩诃希瓦长老**」。父层 99:189 译「**大私婆长老**（Mahāsīvatthera）」，99:211 译「摩诃希瓦长老」。**同样是父层内部不一致**，本层跟的是 99:211。
- **建议**：本层不改；harmonize 时统一父层两处。按 `style.md`「常见术语用传统汉译」，`mahā-` 复合的人名本 chunk 中已有「大迦叶」「大帝须」「大龙长老」等一律意译作「大」，故建议全书统一为「大私婆长老（Mahāsīvatthera）」，并同步修改 99:211 与本层 181:356。

## 必改项汇总

1. §354-120-156：`asītādhikacatusatappabhedā` = **四百八十种**，译文「五百二十种」算错。
2. §356-73-80：黑体「是**身的**」「是**心的**」缺中心语，中文不成句，须补出「（精进）」。
3. §354-179-181：「在瓦答尼林中的像阿说笈多长老那样。」无谓语残句，须补承接语。
4. §356-2-16：`āraddha` 的两重释义被压平成同一措辞，须分别用「完成」与「着手」区分。
5. §354-78-83 / 84-87：`uggaha` 正文译法「学习／学取」不统一，须统一（黑体保留「学习慈相」）。
