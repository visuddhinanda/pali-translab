## 理由

**基准可用性（重要）**：本次评估**既无义注（aṭṭhakathā）也无 nissaya** 注入——复注（ṭīkā）层的被解释对象是义注（Aṅguttara-aṭṭhakathā 相应段），但上文只给了复注自身的巴利原文与译文。因此"义注定释义、nissaya 定词法"两条基准**都缺位**，评估降级为"巴利原文 + 内部一致性 + 汉语表达"三条，无法核验的项目主要是：被解释词（黑体 lemma）是否与父层义注逐字同译、译文取义是否与传统取义一致。信心指数据此压到 68。

**准确性**：绝大多数句子词覆盖完整、格与句法角色判断正确，复注特有的"定义式句型"（`X-ti Y` / `Tato eva` / `Tenāha`）处理稳定，`lakkhaṇa / rasa / paccupaṭṭhāna`（特相/作用/现起）三支一贯译准。扣分集中在三处：`181-1040-6-11` 的 `kāyassābyapanaṃ` 译作"使喜遍满全身"，与原文 `abyapana`（不遍满/不散布）字面相反，且该句译文补出了原文没有的"也借着"因果链，属词义与修饰关系错误；`181-1042-2-6` 把 `samādhānaṃ`（安置、等持）释义为"使心专一安住"，把被释词和释词合为一体，丢了原句"正确地安置心=samādhāna"的定义结构；`181-1043-25-41` 的 `atthakaraṇe dhammaṭṭhe` 译为"法庭上审理案件、依法行事的人"，把两个处格/复数名词当作一组人，指代含糊。

**风格**：现代书面汉语基本达标，未见"此中/故为/彼等/是故"等禁例，关联词都用了"因为…所以""由于…"的现代连接。但保留了若干单音节文言残留：`181-1041-31-43` 的"**烦热**就是躁动"用"躁动"译 `sārambha` 尚可，同句"这是对…的称呼"重复两次读来生硬；`181-1043-25-41` 的"默然坐着"属半文半白（现代应作"一言不发地坐着"），"不放逸地"是未解释的术语直搬。另有多处"所以叫做…"句式高频重复，属可提升项而非错误。

**一致性**：术语内部统一度高——`sampayuttadhammā`→"相应的诸法"、`paccupaṭṭhāna`→"现起"、`daratha`→"烦热"全段一致；`bojjhaṅga`→"觉支"、`sambojjhaṅga`→"正觉支"区分清楚。夹注巴利原词的用法（pharaṇapīti / ubbegapīti / aṅga / bodhi）符合 style.md 的圆括号规范。标点全角、无 ASCII 引号残留、无工作标记残留。唯一不一致：`181-1043-45-70` 译文内部用了弯引号 “ ”，而同一句的巴利原文行里是 ASCII `''`——译文侧合规，仅记录。

## 问题清单

### 🟧 error

- `181-1040-6-11`｜错译（词义、修饰关系）｜片段「也借着由它所生起的殊妙色法，使喜遍满全身」
  - 问题：原文 `kāyassābyapanaṃ` 的核心词是 `abyapana`（a- 否定前缀 + byapana 遍布），字面为"身体的不遍满/不散布"；译文作"使喜遍满全身"，取义与词形相反。该句又补出"也借着…"的递进因果，原文无对应连词，`taṃsamuṭṭhānapaṇītarūpehi` 是具格直接修饰同一谓语。此处必须核对义注原文与 nissaya 后定案。
  - 建议：先取回对应义注段与 nissaya 确认 `abyapana` 的传统取义（部分传本作 `byāpana`=遍满，若所据底本为 `byāpana` 则译文无误，需据版本注明）；底本确为 `abyapana` 时改按否定义重译，并删去原文没有的递进连接。

- `181-1042-2-6`｜漏译 / 导致误解的表达｜片段「正确地安置心，就是**使心专一安住**」
  - 问题：原句是标准定义式 `Sammā cittassa ṭhapanaṃ samādhānaṃ`——"正确地安置心"是释词，`samādhāna` 是被释的黑体 lemma，二者是"定义=被定义"关系。译文把 lemma 译成"使心专一安住"，既与释词"安置心"语义重叠、读起来像同义反复，又丢了 `samādhāna`（等持/定）作为术语的身份。按硬约束，复注黑体词须与父层（义注）逐字同译，而父层译文未注入，无法核对。
  - 建议：取回义注该处对 `samādhāna` 的译法，复注黑体与之逐字对齐；若义注作"等持"或"定"，此处相应改为「正确地安置心，就是**等持**。」

- `181-1043-25-41`｜代词指代错误 / 导致误解的表达｜片段「也能让法庭上审理案件、依法行事的人不放逸地各自做自己的事」
  - 问题：`atthakaraṇe dhammaṭṭhe` 两词同格并列，传统指"（处理）诉讼事务的、持法的（officials）"，是国王役使的对象；译文"法庭上审理案件、依法行事的人"把 `atthakaraṇe` 当成处所（法庭上），又把两词压成一个含糊的"的人"，施动关系与数都不清楚。另"不放逸地"（appamatto）在原文是修饰国王还是修饰属官，译文归给了属官，需据注释确认。
  - 建议：核对义注/nissaya 的格助词后重译为明确的双重宾语结构，例如「…也能让审理诉讼的官员和持法的官员各自在自己的职务上毫不懈怠地办事」；`appamatta` 的归属按注释定。

- `181-1041-31-43`｜整句逻辑表达不规范｜片段「这是对那些作为苦与忧恼的因缘的掉举等烦恼的称呼，或者是对这样转起的四蕴的称呼」
  - 问题：单句内四重"的"字定语连环（作为…的因缘的…等烦恼的称呼），超出现代汉语可读负荷；"苦与忧恼"对 `dukkhadomanassa` 的处理与下文未再出现，术语形态未定。
  - 建议：拆为两句，例如「**烦热**就是躁动。这个词用来称呼掉举等烦恼——它们是苦和忧的因缘；也用来称呼这样转起的四蕴。」

- `181-1040-6-11`｜不导致误解的汉语语病｜片段「如同使相应的诸法喜悦那样」
  - 问题：承接上文"凭着使人喜悦的作用"，此处"使…喜悦"与前半句谓语重复，`viya` 的比较对象（相应诸法 vs 身）被两个同形谓语遮蔽，读来不知在比什么。
  - 建议：明确比较两端，如「就像它使相应的诸法得到喜悦那样，也…」；此条与上面同句的 error 一并重译即可消解。

### 🟦 suggestion

- `181-1037-28-49`｜复杂的嵌套句整句语言逻辑理解困难｜片段「由于随顺于观等原因而觉悟，由于以现见的方式正对着所应觉悟的诸谛而觉悟，所以说“各别地觉悟”」
  - 问题：原文是"三个前缀各配一个理由"的平行结构（anu- / paṭi- / sam-），译文把前两个理由并入一句后只落出一个引语"各别地觉悟"，第三个理由另起，前缀与理由的一一对应关系在译文里看不出来。另："各别地觉悟"对应的黑体是 `anubujjhanti`，而句末又译作"**随觉**"，同一个词在同句内出现了两种译法。
  - 建议：按前缀逐条分述，并统一 `anubujjhati` 的译法（建议正文与引语都作"随觉"），使读者能看出"前缀—义别"的对应。

- `181-1037-11-19` / `181-1038-2-6` / `181-1039-2-8` 等｜语言风格不统一（句式单调）｜片段「因为觉悟，所以叫做觉（bodhi）」

  - 建议：在不改变逻辑的前提下交替使用"…，这就叫做…""之所以称为…，是因为…"等句式；注意这属可读性优化，**不可为"更顺"而改动取义**，由 revise 酌情处理。

- `181-1042-30-38`｜该使用而没有使用术语标记｜片段「就像水使沐浴用的粉末黏聚起来那样」

  - 建议：首现处补夹注，如「沐浴粉（nhānīyacuṇṇa）」。

- `181-1043-42-44`｜语言表达不够流畅｜片段「由于它是不退缩、不掉举地转起的缘」
  - 问题：「…的缘」为直译 `paccayattā`，现代汉语里"缘"单用作名词读者不易接住。
  - 建议：改为「由于它是（相应诸法）不退缩、不掉举地转起的原因」。
