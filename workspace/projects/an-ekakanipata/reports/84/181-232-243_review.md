# Review — 181:232-243（channel: 73c03e1a…，复注层 Nidānavaṇṇanā-ṭīkā）

> 资源：pali ✅／父层义注（book 99，段 49-154）✅／nissaya ❌ **未注入**／现有译文 ✅
> 缺 nissaya，词级格与句法的判定只能依巴利原文形态与父层对照，凡属格/从格的判读在下文已注明依据。

## 被解释词与父层对照

- 本 chunk 的黑体词共四处：**vibhattihāro** / **parivatto hāro** / **vevacano hāro** / **paññattihāro**，都是复注自引《导论》（Netti）的十六引导名目，**不在父层 book 99 段 49-154 的范围内**，无父层译法可比对——无可核查项，不构成不一致。
- 间接引自本文/父层的经句 §235 `Itthirūpaṃ purisassa cittaṃ pariyādāya tiṭṭhati`，译作「女色……夺尽男子的心」，与父层 99-109-27-33「都能夺尽男子的心」、99-146-18-28「这一切都会夺尽男子的心」**逐字一致 ✅**；`itthirūpa`=「女色」亦与父层 99-147-15-32 一致 ✅。
- §238 的同义词串「色／颜色／可由眼识知的」与父层 99-56-94-113「可由耳识知的」构词平行 ✅；`purisa`=男子、`puggala`=人、`mātugāma`=女人，均与父层 99-147、99-145-50-62 一致 ✅。

## 跨段一致性

- **四段偈颂的收尾句式不统一**（同一巴利句型 `X nāma so hāro`）：§237 译「这一引导就叫做转换」，§240 译「那就是称为同义的引导」，§243 译「那就是称为施设的引导」。→ 建议统一为「那就是称为转换的引导」。§234 原文是 `neyyo vibhattī`（句式不同），保留现译即可。
- `hāra` = 「引导」，四处一致 ✅；`anekadhā paññattaṃ` = 「有多种施设」，§241 四处一致 ✅；`pariyādāya tiṭṭhati` = 「夺尽……的心」，§235/§238/§241 一致 ✅。
- 词源解释的定义句式：§235「或者说，对那些法的转换本身，就叫做转换」、§241「凭着它、或者在它这里……所以叫做施设」处理成同一模板 ✅，唯 §232 第二条定义脱离该模板（见下）。
- `Vuttampi cetaṃ` 译「也已经说过」、`Vuttañhetaṃ` 译「已经说过」，差异对应原文 `api` 的有无 ✅，非错。

## §232 句 181-232-54-59（`Vibhajanaṃ vā etesaṃ bhūmiyoti vibhatti`）

- **问题**：句法误读 — 现译「或者说，**它们的诸地就是对这些法的分别**，所以叫做分别」把 `bhūmiyo` 当成了主语、与 `vibhajanaṃ` 划等号，句子读不通。此处是与前句（karaṇa/adhikaraṇa 义）并列的**行为义（bhāva）**释词：`vibhajanaṃ ... etesaṃ bhūmiyo` = 「分别这些（法）的诸地」。同一篇中 §235-21-34 对 `parivattanaṃ vā tesaṃ` 正是按行为义译成「对那些法的转换本身」——同一模板在本句失落，属内部不一致。
- **建议**：改为「或者说，对这些法的诸地加以分别，就叫做分别。」

## §235 句 181-235-2-20

- **问题**（必改，语法层次）：`susaṃvutindriyattā` 是从格（-attā）表原因，`sīlesu samāhitassa` 与 `manasikaroto` 同为属格修饰同一人；现译「对于如理作意、根门善加守护、于戒中安定的人」把因果关系压平成三个并列定语，原文「因为诸根善加守护、在戒上安定，所以夺不去」的论证链断了。
- **问题**（必改，可读性）：「对于不如理作意的人，女色会夺尽**男子**的心」——「人」与「男子」指同一主体却重出，读者会误以为是两个人。
- **问题**（语体）：「于戒中安定」是「于…中」文言句式，对照 `style.md` 第一节禁例表应改写。
- **建议**：「男子若不如理作意，女色就会夺尽他的心；如果如理作意，由于诸根善加守护、在戒上得到安定，女色就夺不去他的心——这就是**转换引导**（parivatto hāro）。」

## §238 句 181-238-38-42（`Pariyādāya gahetvā khepetvā`）

- **问题**：术语过度specific — `gahetvā` 译「执取」。「执取」在汉译佛典里固定对应 `upādāna`，此处只是 `gaṇhāti`「取住、抓住」的同义解释，会把读者引向十二支的取支。父层 99-120-2-7 对 `gahaṇa` 用的是「钳住」这类实义。
- **建议**：改为「抓住」或「取住」，即「“夺尽”“抓住”“耗尽”是同义的说法」。

## §240 句 181-240-2-20

- **问题**：文言虚词 —「通晓经的人**若**能知道这一点」。`style.md` 禁例表「若…则 → 如果…就」。
- **建议**：「如果通晓经的人能知道这一点，那就是称为同义的引导。」

## §241 句 181-241-13-17（`Cittaṃ parittamahaggatādivasena`）

- **问题**：法相术语译得过白 —「心依**小的、大的**等等而有多种施设」。`paritta` / `mahaggata` 是一对固定的心的分类（欲界心 / 色无色界的广大心），译成「小的、大的」读者无法辨认，且 `mahaggata` 的常译是「广大」不是「大」。
- **建议**：「心依小（paritta）、广大（mahaggata）等等而有多种施设。」按 `style.md` 第二节，法相术语首次出现夹注巴利原词。

## §241 句 181-241-18-33

- **问题**（次要）：`vītikkama` / `pariyuṭṭhāna` 译作「违犯」「缠缚」取义无误，但这是烦恼三层次的固定术语对，首次出现未夹注巴利原词，与同段 `paññattihāra` 的处理不一致。
- **建议**：「……以及违犯（vītikkama）与缠缚（pariyuṭṭhāna）等等而有多种施设。」
- 同段 §232-60-69 的「近因」（padaṭṭhāna）同理，建议首次出现夹注。
