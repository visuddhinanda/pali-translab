## 理由

**基准可用性（降级说明）**：本次注入的资源只有巴利原文与目标 channel 的现有译文。**没有 nissaya 单元**，也**没有本层的复注（ṭīkā）**，而被评的本身就是义注层，因此「义注定释义」这一条无更高层标准可依；「nissaya 定词法」无法执行。所有格/句法角色判断只能靠原文内部证据与《清净道论》同源段落（本段 310–312 与 Vism 四资具三种知足段平行）推定。此外**本文层（mula）未注入**，义注黑体被解释词与本文译法是否逐字一致**本报告无法核对**——这是信心指数只给 72 的主因。以下问题清单中凡涉及词义取舍的条目，已注明属于内部证据推定。

**准确性**：整体忠实，逐句核对未发现漏译——310-2-9 的 leṇa / maṇḍapa / kūṭāgāra、310-10-21 与 312-8-22 的五类受者（thera / cirapabbajita / bahussuta / appalābha / gilāna）、317-8-16 的五项（assaddha / dussīla / appassuta / maccharī / duppañña）、317-17-28 的八项同义词均逐项落实，数目对得上。扣分集中在两处：316-27-29 把 `Vuttampi cetaṃ` 补成「经中」，与紧接的出处 `vibha. 901`（《分别论》，属论藏）自相矛盾；317-17-28 把 `bhatti` 译作「爱慕」，偏离 bhatti 的「敬奉、恭敬」义。另有 310-26-60 `thinamiddhaṃ okkamati` 的施受关系被调换（原文昏沉睡眠为主格施事），语义未失，按 suggestion 记。

**风格符合度**：合格——通篇现代书面汉语，**未发现文言/半文半白违例**：无「此中／故为／彼等／是故／之／其／乃／便／遂」等禁例，连接词用「于是／但是／而且／如果…就」，`paṭisañcikkhitvā`「这样省察」、`vuccamāno`「对他说」都作了白话化处理，符合 `knowledge/style.md` 第一节硬约束。标点全角、引号统一 “”，`zh` 字段内无 ASCII 引号，JSON 安全无隐患；黑体只用于被解释词，译文内**没有残留任何工作标记**（候选、待定、问号、TODO），这一项干净。扣分项为 method 文档明确点名的「转起」未加注（316-17-26），以及若干「的」字堆叠与「不正知就是不正知的状态」式同词循环定义。

**一致性**：三种知足术语在 310/311/312 五次出现中稳定为「随所得知足／随力量知足／随适宜知足」，`santuṭṭhova hoti` 稳定为「仍然是知足的」，`paramasantuṭṭho` 区分为「最为知足」，处理得当。不一致有两组：314 与 315 的对举词译成「不正知的人／**具**正知的人」，肯定式多出「具」字，破坏对称；316 的 pāpamitta 词族在同一句内混用「与恶友为伴／有恶友的人」两个落点，读者不易看出是同一词根的推导。

## 问题清单

### 🟧 error

- `99-316-27-29`｜错误多译（出处与实际不符）｜片段「而且经中也这样说过」
  - 问题：原文 `Vuttampi cetaṃ` 只说「而且这也曾说过」，并未指明出自经藏；而下文 317-29-40 给出的出处是 `vibha. 901`，即《分别论》，属**论藏**而非经藏。译文补出的「经中」与实际出处冲突，会让读者误判引文层级。
  - 建议：删掉补出的层级词，作「而且也曾这样说过——」；若要显化出处，改为「论中也这样说过——」。

- `99-317-17-28`｜错译（词义）｜片段「爱慕他们」
  - 问题：`bhatti` 义为敬奉、恭敬、信奉（与下一词 `sambhatti` 构成简式／加强式对），汉译传统作「信奉／敬奉」。「爱慕」在现代汉语带恋慕、爱恋的联想，属于导致误解的取义。
  - 建议：`bhatti`→「敬奉他们」，`sambhatti`→「一味敬奉他们」或「深深敬奉他们」，`sampavaṅkatā`→「倾心依附他们」，使三词的递进关系成立。

### 🟨 warning

- `99-316-17-26`｜关键词语意不明确（「转起」）｜片段「以那种方式转起的四蕴」
  - 问题：「转起」是 method 文档点名的二义术语，未加注时一般读者无法理解；「四蕴」也未说明指受、想、行、识（名法四蕴，不含色蕴）。
  - 建议：正文改为「以那种方式生起的四蕴」，并在段后小字注明「四蕴指受、想、行、识」。

- `99-317-8-16`｜整句逻辑表达不规范｜片段「那些人是无信的、破戒的、少闻的、吝啬的、恶慧的」
  - 问题：原文 `Ye te puggalā…` 是关系分句，与下一句 `Yā tesaṃ sevanā…` 共同作 `Ayaṃ vuccati pāpamittatā` 的主语；译文把它改写成带判断系词的独立陈述句（「那些人是…的」），关系链被切断，读者读到的是一句无着落的论断。
  - 建议：改为「凡是无信、破戒、少闻、吝啬、恶慧的那些人——」，用破折号把句子悬住，接续下一句的「凡是亲近他们……」。

- `99-312-32-66`｜代词指代不明确｜片段「如果用这两样中的任何一样也能治好他的病」
  - 问题：引号内是这位比丘的自我思量，`assa` 在此最自然的读法是指他自己，但译作「他的病」会被读成第三者的病，与上下文「他自己用尿渍诃子配药」脱节。缺 nissaya 与复注，`assa` 究竟指自己还是所照护的病人无法定案，但译文目前的措辞两头都不落实。
  - 建议：按自指读法改为「如果用这两样中的任何一样都能治好这病」，把人称悬置；若采他指读法，须补出「病人的病」。

- `99-311-31-54`｜关键词语意不明确｜片段「或者另外去寻找」
  - 问题：`aññadeva vā pariyesitvā` 的 `aññaṃ` 是宾语（另找别的药），译文只剩「另外去寻找」，宾语缺失，易被读成「到别处去找（油）」。
  - 建议：改为「或者另去寻求别的药」。

### 🟦 suggestion

- `99-310-26-60`｜语言风格不统一（施受关系）｜片段「坐在那里会陷入昏沉睡眠」
  - 问题：原文 `tattha nisinnassa thinamiddhaṃ okkamati` 以昏沉睡眠为主格施事、坐者为受动方；译文调换为人主动「陷入」。语义不失，但与义注惯用的「烦恼来袭」表达取向不同。
  - 建议：「坐在那里的人会被昏沉睡眠袭来」或「坐在那里，昏沉睡眠就会袭来」。

- `99-311-2-26`｜语言表达不够流畅（补出原文所无的提示语）｜片段「再说病缘药物：」
  - 问题：`Idha pana` 只是「而在这里」，译文补出的小标题式提示语原文没有。内容与下文 `gilānapaccaye` 相符，不构成错误，但属译者增补。
  - 建议：改为「而在病缘药物方面：有比丘……」，把承接交给状语而非新增提示语。

- `99-314-2-13`｜语言表达不够流畅（同词循环定义）｜片段「就是不正知的状态」
  - 问题：「不正知就是不正知的状态」在汉语里等于没有解释；原文 `asampajaññaṃ = asampajānabhāvo` 是抽象名词对状态名词的构词说明，直译后信息归零。
  - 建议：「**不正知**，就是不能清楚了知的状态」。同理 315-2-14 可作「**正知**，就是清楚了知的状态」。

- `99-315-15-18`｜语言风格不统一｜片段「具正知的人」
  - 问题：与 314-14-18 的「不正知的人」不对称，肯定式多出「具」字，破坏这对定义句的并列关系。
  - 建议：统一为「正知的人／不正知的人」。

- `99-316-2-16`｜语言风格不统一｜片段「就是有恶友的人」
  - 问题：同句内 `pāpamittatā` 作「与恶友为伴」、`pāpamitta` 作「有恶友的人」，两个落点看不出同一词根的推导，而下一句还要靠「有恶友的人的这种状态」把二者接起来。
  - 建议：黑体词保留「与恶友为伴」（须与本文层译法一致，本报告无法核对），定义句改为「有恶的、低劣的朋友，这样的人就是与恶友为伴的人」。

- `99-316-17-26`｜语言表达不够流畅｜片段「有恶友的人的这种状态」
  - 问题：连用三个「的」，读起来拗口。
  - 建议：「与恶友为伴的人所处的这种状态，就叫做与恶友为伴」。

- `99-312-23-31`｜不常用术语缺注释｜片段「还有一位比丘：有人在一个容器里放上尿渍诃子」
  - 问题：「尿渍诃子」与同句「四种甘味」都是一般读者无从索解的资具名；另外「还有一位比丘：」后接冒号、主语随即换成「有人」，跨句分行时略显突兀（此句在原文中与 312-32-66 同属一句，行内已尽力）。
  - 建议：段后小字注出「尿渍诃子：以牛尿浸渍的诃子，佛陀称许的粗劣药」与「四种甘味：蜜、糖、酥、油」；并把行首改为「还有一位比丘——有人在一个容器里……」。

- `99-312-71-79`｜代词指代可能不够明确｜片段「在这些各别的资具上」
  - 问题：`Imesaṃ` 与 `santosānaṃ` 同为属格、当指「这些知足」，译文把「这些」挂到了资具上。语义不失，指向略移。
  - 建议：「在各别的资具上，这每三种知足当中，随适宜知足最上。」
