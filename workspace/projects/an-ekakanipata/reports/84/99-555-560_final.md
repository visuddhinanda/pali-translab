## 问题清单

### 🟧 error

- `99-556-8-12`｜义理或用词与注释书不符｜片段「出家资历最深的」
  - 问题：lemma `rattaññū` 直接意译为「出家资历最深的」，把义注三条并列理由中的第一条（最早出家）当成词义定论；随后的「最先通达法故知那一夜」「漏尽者夜昼分际分明」两条与该译名无法衔接。
  - 建议：lemma 回归字面「知夜者」，把「出家资历最深」降为括注或脚注（如「**知夜者**（rattaññū，指出家最久、资历最深者）」），使下文三条理由都能落在同一个被解释词上。

- `99-557-28-43`｜漏译｜片段「憍陈如确实已经了知了」
  - 问题：原文 `aññāsi vata, bho, koṇḍañño` 的呼格／感叹语 `bho` 两处均未译出，说话者向在场者惊叹的语气丢失。
  - 建议：补出称呼，如「诸位，憍陈如确实已经了知了」（两处同改）。

### 🟨 warning

- `99-556-46-61`｜关键词语意不明确（同词两译）｜片段「在出家资历最深的弟子中」
  - 问题：同一词 `rattaññū` 在本段内既作「出家资历最深的」（本句及 `99-556-65-73`），又作「知夜者」（`99-556-13-30`、`99-556-31-45`），读者无法确认二者是同一个被解释词。
  - 建议：随 error 第一条统一为「知夜者」，全段一律，解释性说法只出现在括注／脚注里。

- `99-557-44-68`｜标点符号使用错误｜片段「就这样，具寿憍陈如就有了」
  - 问题：原文引文跨 `99-557-28-43` 与本句两段（`‘‘aññāsi vata…nāmaṃ ahosī’’ti`），译文已在上一句句末收了下引号，本句开头未重开引号，导致本句内容看起来在引文之外，引文范围错。
  - 建议：本句开头补上引号（或上句末不收引号、由本句统一收尾），使引文覆盖范围与原文一致。

- `99-557-2-20`｜整句逻辑表达不规范（体例：巴利原词直入正文）｜片段「就是 yo eso“这位”」
  - 问题：`yo eso`／`yaṃ etaṃ` 以拉丁巴利词形直接进入译文正文，与 `knowledge/style.md`「显示巴利原文：否、夹注用圆括号附巴利原词」的体例冲突；同句「（阳性）」「（中性）」为译者补注，全段他处并无同类补注。
  - 建议：改为「就是‘这位’（yo eso）」「就是‘这个’（yaṃ etaṃ）」；语法性别说明若要保留，宜降为脚注。

### 🟦 suggestion

- `99-559-80-95`｜语言表达不够流畅｜片段「像从水管里喷涌而出的金液水柱一样」
  - 问题：`yantanāḷikā` 指唧筒／机械喷管，译作「水管」弱化了器械义；「金液」与「水柱」搭配自相矛盾。
  - 建议：「像从唧筒管里喷出的金液流注一样」。

- `99-560-31-41`｜语言风格不统一｜片段「有些人成为须陀洹」
  - 问题：果位名采用北传音译（须陀洹／斯陀含／阿那含），与全篇南传语境及「阿罗汉果」的混用略显不齐。
  - 建议：统一为「入流者（sotāpanna）／一来者（sakadāgāmī）／不还者（anāgāmī）」，或保留音译但首次出现夹注巴利原词。

- `99-556-31-45`｜语言表达不够流畅｜片段「从他通达法的那个久远时候起」
  - 问题：`yadā tena dhammo paṭividdho` 与 `cirakālato paṭṭhāya` 被压成一个定语，「那个久远时候」指涉含糊。
  - 建议：「从他通达法的那一夜起，长久以来他一直知道那一夜」。

- `99-556-2-7`｜该使用而没有使用术语标记｜片段「**第一**这个词」
  - 问题：`etadagga` 是 `etaṃ + agga` 的复合，`99-557-2-20` 正是靠 `yadidaṃ = yaṃ etaṃ` 回指其中的 `etaṃ`；lemma 只译「第一」使后文这层呼应无从落地。
  - 建议：lemma 作「这是第一」（etadagga），或在括注中点出「etaṃ（这）+ agga（第一）」。

- `99-559-2-46`｜语言表达不够流畅｜片段「这朵莲花的外层花瓣有九十肘长」
  - 问题：`dhurapatta` 的 `dhura` 为「主要／前端」义，译作「外层花瓣」缺依据，与「花蕊／莲蓬／脚踏处」的由内向外次序也不协调。
  - 建议：改「主瓣」或「最前端的花瓣」，必要时脚注说明取义。
