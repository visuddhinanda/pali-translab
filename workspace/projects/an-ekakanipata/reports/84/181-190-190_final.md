**基准缺失（影响信心）**：本次只注入了巴利原文与待评译文，**没有义注（aṭṭhakathā）、没有 nissaya**。本段是复注（ṭīkā），被解释词（`**Imassa** **suttassa** **sukhāvagāhaṇatthan**`、`**bhagavato āmantanaṃ paṭiassosuṃ**` 等黑体）本应逐字比对义注译文，现在无从核对——「被解释词与父层逐字同译」这条硬约束**本轮未能验证**。词级格位也只能靠原文形态自判，无 nissaya 佐证。因此信心压到 70；若要出正式验收结论，需补齐义注层译文后重评。

**准确性（90）**：语法术语判定全部正确且到位——`sāmivacana` → 属格、`sampadānavacana` → 与格、`i-kāralopo` → i 元音脱落，`paṭissavasambandhena`（就它与应答的关系而言）这种句法层面的转折也译清楚了。`iti` 七种用法的列举（hetu / parisamāpana / ādiattha / padatthavipariyāya / pakāra / avadhāraṇa / nidassana）与后面七段例证一一对应，没有错位、没有漏项。`Māgaṇḍiyoti` 那条十个同义词（saṅkhā…abhilāpa）逐个落实，十对十，未合并未省略。四处经典出处（《相应部》3.79 / 《中部》1.19、3.124 / 《长部》1.13、2.96 / 《大义释》73、75）标注体例统一。末段 388 词的巨型复合句结构复原准确：三组 `viya` 明喻（titthaṃ / sopānaṃ / mahādvāraṃ）与各自的目的（sukhāvataraṇa / sukhārohana / sukhappavesana）配对无误，`nakkhattapathaṃ phusitukāmatāya viya` 的拟人也保住了。未发现 fatal 或 error 级问题；扣分主要来自 `padatthavipariyāya`、`visūkadassana` 两处取义偏笼统（见问题清单）。

### 🟨 warning
- `181-190-9-16`｜文言语体｜片段「“等等”之义」

  - 建议：改为「表示“等等”的意思」，与后文统一。
- `181-190-351-388`｜文言语体｜片段「宅中夹杂着金镯、脚镯等相互碰击的声响」
  - 问题：「宅中」是文言式处所表达，与整段现代白话基调不合。
  - 建议：改为「宅子里夹杂着金镯、脚镯等相互碰击的声响」。
- `181-190-346-350`｜整句逻辑表达不规范（译者注混入正文）｜片段「（义注那个长句中）词语的搭配关系是：yaṃ … nidānaṃ bhāsitaṃ」
  - 问题：括号内的「义注那个长句中」是译者补出的定位说明，原文 `Yaṃ nidānaṃ bhāsitanti sambandho` 无此内容；同时裸露了整串拉丁巴利短语。按 `style.md` 第四节，句法注不进正文。
  - 建议：正文只留原文所有的内容，如「这里的搭配关系是：所说出的那个序分」；定位说明与拉丁词形移到脚注。
- `181-190-106-131`｜关键词语意不明确｜片段「它用于词义的转换」
  - 问题：`padatthavipariyāya` 译成「词义的转换」过于含混，读者无法从中看出这里的 `iti` 是把所指从「词的意义」转到「词本身（作为名称）」——而这正是引《大义释》名称同义词串的理由。
  - 建议：改为「它用来把所指从词义转到词本身」，或保留原译并加脚注说明。
- `181-190-84-105`｜关键词语意不明确｜片段「舞蹈、歌唱、音乐、演艺的观看」
  - 问题：「演艺的观看」语序生硬；且 `visūka` 的「杂耍、不正当表演」贬义被中性化为「演艺」，与该戒条的语境不符。
  - 建议：改为「远离这样那样、诸如此类的观看舞蹈、歌唱、音乐和杂耍表演」。
- `181-190-263-273`｜代词指代不明确｜片段「他用‘比丘们’来招呼」
