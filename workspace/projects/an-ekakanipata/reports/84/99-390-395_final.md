## 理由

**基准可用性（影响信心指数）**
本次评估的对象本身就是义注层（book=99《13. Ekapuggalavaggavaṇṇanā》），因此没有更高一级的"释义标准"可比对；同时 **nissaya 未注入、被解释的本文层（AN 1.13 Ekapuggalavagga）译文也未注入**。这带来两项无法核验的内容：

1. 词级格位与句法角色只能凭巴利原文自行判读，无 nissaya 交叉验证；
2. **黑体被解释词与本文层是否逐字同译无法核对**——`Bahujanahitāya` / `Bahujanasukhāya` / `Lokānukampāya` / `Devamanussānaṃ` / `Katamo ekapuggalo` 这五处黑体引语的译法（"为了众多人的利益""天与人""是哪一个人"）必须与本文层译文逐字一致，这是硬约束，本次只能列为待核项。

信心指数因此压到 70；补齐 nissaya 与本文层译文后应重评。

**准确性**
主体叙事（初转法轮、十八俱胝梵天、五比丘、耶舍五十五人、贤众三十人、结发千人、频婆娑罗十一万、诸次集会人数、三十三天说阿毗达摩、四处无定数）与巴利逐句吻合，数目换算正确（`ekādasa nahutā`=十一万、`ekaṃ nahutaṃ`=一万、`dasahi pāṇasahassehi`=一万、`asīti devatāsahassāni`=八万、`cuddasa koṭiyo`=十四俱胝）。五种提问的定义段（392–395）用词覆盖完整，`aññātaṃ / adiṭṭhaṃ / atulitaṃ / atīritaṃ / avibhūtaṃ / abhāvitaṃ` 六项与正面六项均一一对应，未漏未增。

扣分集中在**一处句法主语误判**（`99-390-242-254`，见问题清单 fatal 条）：`vasenāpi ayamattho veditabbo` 的应知主语是"这个意思"，`patiṭṭhahantānaṃ ... vasena` 是"就……那些人而言"的凭依格结构，译文把"人"当成了理解的主体、把"这个意思"降为方式状语，整句逻辑倒转。这是本段唯一的阻塞性问题，改掉后准确性可回到 90 以上。

另有一处夹注原词与所据原文不符（`tālaṭṭhivane` 却夹注 `Laṭṭhivana`），属译文附带信息的错误，非正文取义错误。

**风格符合度**
整体是合格的现代书面汉语，**未发现文言/半文半白违例**：无"之/其/乃/便/即/於/遂"作虚词，无"……者……也""于……之际""答以"等句式；"当宣说……时""在……的时候"均为 `style.md` 许可写法；"此后""以后"属现代书面常用词，不计违例。全角标点与弯引号使用正确，译文内无 ASCII 引号，无残留工作标记（候选/待定/问号/TODO），符合 JSON 安全约束与"译文不留标记"要求。

失分在两类硬译：`patiṭṭhahiṃsu` 一律作"确立于"，配"阿罗汉果/预流果"尚可读，配"三归依"即不成话；`sahetukapaṭisandhike` 直译"结生具足因"对目标读者（混合受众）不透明。

**一致性**
- **数词体例不统一**：`nahuta` 折算成汉语"十一万/一万"，`koṭi` 却保留音译"俱胝"且全篇无注，同一段里出现"十一万"与"十八俱胝"两种处理。
- **夹注体例不统一**：`pañcavaggiyā`（主格复数原形）、`Yasa`、`Kappāsikavanasaṇḍa`、`Tirokuṭṭa`、`Khadiraṅgāra-jātaka`、`Jambuka`、`Pārāyana`、`sahetuka` 夹注了巴利原词，而阿若憍陈如、频婆娑罗、苏摩那花匠、护财象、阿难陀长者、双神变、象头山、波沙那支提一概不注；`style.md` 规定夹注用于法相术语首次出现，此处多为人名地名书名，标准需统一。
- **主语显隐不统一**：393 段作"就提出问题"（省主语），394/395 段作"他为了……提出问题"，同一组平行定义句体例不齐。
- 术语内部一致：`amatapāna` 全段统一作"不死之药"，`atthāya hitāya sukhāya` 统一作"福祉、利益和安乐"，`anukampāya uppanno` 统一作"出于对……的悲悯而出现的"，这几组做得好。

**存疑但不扣分**
`99-393-10-19` 原文作 `abhāvitaṃ`，与 `99-394-6-15` 的正面项 `vibhāvitaṃ` 不对称，通行读法应为 `avibhāvitaṃ`；译文按"没有弄清楚"处理，取的是对称读法，判断合理，仅在此备案。

## 问题清单

### 🟥 fatal
- `99-390-242-254`｜主谓宾判断错误｜片段「也应当按这个意思来理解这句话」
  - 问题：`ayamattho veditabbo` 的主语是"这个意思"（应被了知者），`sāsanaṃ nissāya saggamokkhamagge patiṭṭhahantānaṃ vasenāpi` 是"也就……那些人而言"的凭依格短语。译文把"确立于生天与解脱之道的人"当作"理解"的主语，又把"这个意思"改成理解的方式、另造出一个宾语"这句话"，主谓宾三项全部错位，整句从"此义亦须就后世得道者而言来理解"变成了"那些人应按此义理解此句"。
  - 建议：改为"直到今天、以及从此以后的未来，凡依靠教法而安立于生天与解脱之道的人——就这些人来说，这里的意思也应当这样理解。"（保持"这个意思"为被理解的对象）

### 🟧 error
- `99-390-134-160`｜导致误解的表达（夹注原词与原文不符）｜片段「多罗树苗林（Laṭṭhivana，即杖林）」
  - 问题：所据原文作 `tālaṭṭhivane`，译文正文按 `tāla-`（多罗树）译出"多罗树苗林"，夹注却给成 `Laṭṭhivana`（无 `tāla-`），还把另一读法"杖林"并列进正文。读者会认为底本原词就是 `Laṭṭhivana`，夹注反而提供了错误信息；同一括号里塞入音译词 + 异读义译两层信息，也超出 `style.md` 的夹注体例。
  - 建议：正文只留一个定名（依底本作"多罗树苗林"，或依通行本改作"杖林"并同步改正文），夹注与底本用词一致；异读"杖林/Laṭṭhivana"写进 `knowledge/known-issues.md` 并出脚注，不进正文括号。

### 🟨 warning
- `99-390-35-84`｜关键词语意不明确（二意/生词场合无注）｜片段「十八俱胝之数的梵天」
  - 问题："俱胝"（koṭi = 一千万）对一般读者不透明，且与同批译文里把 `nahuta` 直接折算成"十一万""一万"的做法冲突——同一段内既折算又音译，读者无法比较人数量级。
  - 建议：二者取一：全部折算（"一亿八千万位梵天"），或全部保留音译并在首次出现加简注（"十八俱胝（一俱胝为一千万）"）。定案后写进 `knowledge/terms.md`。
- `99-390-134-160`｜关键词语意不明确｜片段「确立于三归依」
  - 问题：`saraṇesu patiṭṭhitaṃ` 译成"确立于三归依"不成现代汉语，"确立于"只能接果位，接"归依"读不通。
  - 建议：改"另有一万人受持了三归依"或"另有一万人皈依了三宝"。
- `99-390-167-170`｜整句逻辑表达不规范｜片段「也有八万四千众生」
  - 问题：巴利原文靠 `caturāsītiyā ca` 承前省略 `amatapānaṃ pītaṃ`，但汉语句子单独成句后以"也有八万四千众生。"收尾，谓语缺失，读者不知道这八万四千众生"怎么了"。
  - 建议：补回承前谓语，如"在与苏摩那花匠相会的时候，也有八万四千众生喝下了不死的甘露。"
- `99-390-171-182`｜整句逻辑表达不规范｜片段「也有八万四千众生」
  - 问题：同上，该句三个分句末尾"有一万众生／有八万四千众生／也有八万四千众生"全部无谓语，整句悬空。
  - 建议：在句末或各分句补出"喝下了不死的甘露"（可只在末分句总收：「……也有八万四千众生喝下了不死的甘露。」）。
- `99-391-15-24`｜关键词语意不明确｜片段「结生具足因（sahetuka）」
  - 问题：`sahetukapaṭisandhika` 指"结生带有（二因或三因）之因者"，"结生具足因"四字对混合受众不可解，夹注 `sahetuka` 也不解释所指；且此处不是法相术语首现的标准夹注场景。
  - 建议：改为"那些结生具足善因（sahetuka-paṭisandhi）、有能力证得道与果的人"，并出一条简注说明二因/三因结生；术语定案后登记 `knowledge/terms.md`。
