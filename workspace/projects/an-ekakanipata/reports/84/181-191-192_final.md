## 理由

**基准缺失（降级说明）**：本次注入的数据只有巴利原文与目标 channel 的译文，**没有义注（aṭṭhakathā），也没有 nissaya**。按方法文档，评估降级为"纯巴利对照 + 内部一致性 + 风格"三项，准确性一项无法用释义标准和词级基准交叉验证，因此：

- 涉及"取义是否与注释书相符"的判断（如 `pubbacaraṇa`、`ekappamāṇatta`、`kapparacanā`、`pamāṇabhāva` 的具体所指）本次**一律不定 error**，只按"语意是否明确"降到 warning / suggestion；
- 本段是复注（ṭīkā），其黑体被解释词应与义注逐字同译——**缺义注，这条硬约束本次无法核对**，这是信心指数压到 62 的主要原因。唯一能查的是层内自引（见 warning 第 3 条），而那一条就出了偏差，提示跨层同译也需要在补齐义注后复核。

**准确性**：长复合词的拆解是这两段的主要难点，译文处理得相当稳。`kāladesadesakanimittaparisāpadesehi`（191-26-36，五项）与 `kāladesadesakaparisāpadesehi`（192-36-45，四项、无 nimitta）被正确区分，没有图省事套用同一串；191-112-135 那个跨行的超长复合句被拆成"染污—表明—成立"三段，因果链清楚且没有丢掉 `accantābhāva` / `abhibyañjanaka` 任一成分；192-17-35 用 `anusāsanaṭṭhena` 解释 `sāsana` 的词源式论证也完整译出。未发现漏译或主谓宾判断错误，故无 fatal。

另外，191-87-98 巴利原文 `sammāsambussa` 是明显的拼写讹误（当作 `sammāsambuddhassa`），译文按正读处理为"正等正觉者"，判断正确，不扣分；建议把这处讹字补进 `knowledge/known-issues.md` 第二节。

扣分集中在少数词的中文落点不明确："分量"（`pamāṇa`）、"准则"（`pamāṇabhāva`）、"毫不共有"（`anaññasādhāraṇa`）都属于意思大致到位但读者难以确解，且前两处是同一个巴利词在两段里译成了两个中文词。

**风格**：主体是合格的现代书面汉语，问答体、夹注（全角圆括号 + 巴利原词）、全角引号与 JSON 安全（未发现 ASCII 引号）均符合 `knowledge/style.md`。但残留两处文言虚词——"所知之法"的"之"、"其行持"的"其"——`style.md` 第一节禁例表明确要求改用现代对应词或省略，据此在风格维度显著扣分。另有反向的问题："秘而不传地留一手"过于口语，与全篇书面语调不统一，属于同一维度的另一端。

**一致性**：术语层面很稳——世尊 / 如来 / 正等正觉者 / 比丘式尊称 / 四无所畏 / 智慧与悲悯，全篇未见漂移，与 `term-glossary.jsonl` 一致。失分在两处：192-46-57 回指 191-136-151 的引文时改了措辞（应逐字回抄），以及 `nidānavacana` 在"说序分"与"序分的话"之间摆动。

## 问题清单

### 🟨 warning

- `181-191-87-98`｜文言语体｜片段「一切所知之法对他都是同等的分量」
  - 问题："之"作文言虚词连接，`style.md` 禁例表明确列出。
  - 建议：改为"一切所知法对他都是同等的"，或"对他来说一切所知的对象都是同等的"。

- `181-191-103-111`｜文言语体｜片段「所以他这位极其清净的人，其行持纯粹是为了摄受他人」
  - 问题："其"作文言虚词，半文半白。
  - 建议：改为"所以他这位极其清净的人，行持是为了摄受他人"，或"……他的行持是为了摄受他人"。

- `181-192-46-57`｜引语与前文译文不一致｜片段「而在这里，则是随顺那些看重色的人的心意……」
  - 问题：同一串巴利 `Idha pana rūpagarukānaṃ puggalānaṃ` 在 `181-191-136-151` 已译为"而在这里，则是显明他随顺那些看重色的人的心意"，此处回指时漏掉"显明他"，被引语与被引原句不能逐字对上。复注引文要求逐字同译，读者据引文回查会失配。
  - 建议：引文原样回抄为"而在这里，则是显明他随顺那些看重色的人的心意……"。补齐义注后，再核这一串是否同样与义注原句逐字一致。

- `181-191-87-98`｜关键词语意不明确｜片段「都是同等的分量」
  - 问题：`ekappamāṇatta` 译"分量"，中文"分量"指重量或重要程度，读者难以读出"对佛的智而言一切所知法无难易差别、皆为一味"的意思。
  - 建议：改为"一切所知法对他都是同等的"，或"在一切所知法上都是同一量度"，必要时加简注。

- `181-191-81-86`｜标点符号使用错误｜片段「因为如来、世尊不需要预备性的作业」
  - 问题：`Tathāgatassa bhagavato` 是同位语指同一人，译文用顿号并列，中文顿号表并列项，易被读成两位。
  - 建议：改为"如来世尊"或"如来、即世尊"，去掉并列歧义。

- `181-192-107-110`｜不导致误解的汉语语病｜片段「以上只是就序分的话的用意，作了纲要性的指示」
  - 问题："序分的话的用意"连用两个"的"，拗口。
  - 建议：改为"以上只是就序分之语的用意作了纲要性的说明"（如保留"之"不合风格，则作"以上只是对序分这段话的用意作了纲要性的说明"）。

### 🟦 suggestion

- `181-191-42-76`｜该使用而没有使用术语标记｜片段「就用“我这样听说”等等说出了这部经的序分」
  - 问题：`evaṃ me sutaṃ` 是经首定型套语，传统汉译"如是我闻"为混合受众共识度最高的形式，直译为"我这样听说"会让读者认不出这是经首套语。
  - 建议：改为"如是我闻"，首次可加夹注说明字面义。定案后补进 `knowledge/terms.md`。

- `181-191-42-76`｜不常用术语编写注释或者百科｜片段「《夺心经》是在哪里讲说的」
  - 问题：`Cittapariyādānasutta` 的汉译经名"夺心经"未见通行依据，读者无从回查原经。
  - 建议：核对该经在《相应部》中的对应出处，采用通行译名或加脚注注明巴利经名与出处。

- `181-191-99-102`｜语言风格不统一｜片段「没有教师的握拳（ācariyamuṭṭhi，即秘而不传地留一手）」
  - 问题：夹注中"留一手"为口语，与全篇书面语体落差明显。
  - 建议：改为"（ācariyamuṭṭhi，指老师保留关键内容不传授弟子）"。

- `181-191-103-111`｜语言表达不够流畅｜片段「其行持纯粹是为了摄受他人」
  - 问题："纯粹"在原文 `parānuggahappavatti` 中无直接对应词，是据上下文补出的强调。语义方向可从下段 `natthi niratthakā paṭipatti, attahitatthā vā` 得到支持，但在缺义注佐证时属于未标注的加译。
  - 建议：改为"他的行持是为了摄受他人"；若要保留"唯"的意味，待义注补齐后确认再定。

- `181-191-136-151`｜不常用术语编写注释或者百科｜片段「其中应当这样配释」
  - 问题："配释"（`yojetabba`）是注释体行话，一般读者不解其义。
  - 建议：改为"应当这样连读"或"应当这样与前文配合起来理解"。

- `181-192-69-92`｜语言表达不够流畅｜片段「是为了用显明导师本身就是准则（pamāṇa）的话来显示教法也是准则」
  - 问题："用……的话来显示"嵌套过长，一句里"准则"出现两次，读来费力；且 `pamāṇa` 在此为知识论意义上的"量/权威依据"，"准则"偏向规范义，落点不准。
  - 建议：拆句并统一术语，如"还有，说序分是为了显明导师本身就是可信的量（pamāṇa），由此显示教法同样是可信的量"。同一术语在本段内保持一处夹注、其后只用汉译。

- `181-192-17-35`｜关键词语意不明确｜片段「正是按照现法、来世与究竟这三种利益」
  - 问题：`paramattha` 译"究竟"，与前两项"现法""来世"不在同一语义平面，读者不易看出这是第三种利益（即涅槃）。
  - 建议：改为"现法利益、来世利益与胜义利益（paramattha）这三种利益"。

- `181-192-93-106`｜语言表达不够流畅｜片段「具备与他人毫不共有的、极其清净的智慧与悲悯等殊胜功德」
  - 问题："毫不共有"为 `anaññasādhāraṇa` 的字面直译，中文不自然。
  - 建议：改为"具备他人所不共有的、极其清净的智慧与悲悯等殊胜功德"。

- `181-191-77-80`｜语言风格不统一｜片段「说序分是为了显明导师的圆满」
  - 问题：`nidānavacana` 全篇在"说序分"（191-4-20、191-77-80、192-2-5 等）与"序分的话"（191-112-135、192-36-45、192-107-110）之间摆动，两种形态混用。
  - 建议：确定一种主译（建议主语位置用"序分之语／序分这段话"，动作化场合再作"说序分"），在 `knowledge/terms.md` 登记后统一回改。
