**准确性**：整体词覆盖完整，无漏译、无增译；主谓宾判断正确，`nibbedhikā` 的两重语源解析（`so etissā atthī` / `nibbijjhatī`）结构处理清楚；`anamatagge saṃsāre antaṃ pāpetvā` 的"使它终结"译得准确。扣分集中在三处词法/修饰关系：`abhiṇhappavattasaṃvego` 与 `utrastamānaso` 是复合形容词，译文却分别收作"…的人"，而同组的 `ukkaṇṭhanabahulo` 又没有"的人"；`bahimukho` 译成"心思向外"后又用"他的趣向就是…智"，`-mukha` 的取义在一句内摇摆；`tena` / `iminā` 两句的施事"他"无原文依据，属补足主语（style.md 第六节不擅自补足）。

**风格**：现代书面汉语基调达标，无文言句式堆砌，禁例表中的"此中/故为/彼等/是故"均已规避（`tattha` 作"其中"正确）。但残留文言虚词用法与单音节文言词若干（"所以慧叫做"前的"这洞穿是慧所具有的"、"满是厌倦"），另有标点硬约束问题一处——`181-1166-71-77` 的夹注使用了圆括号但内含逗号与解释语，格式与 style.md 第三节"首次出现用圆括号附巴利原词"的体例不一致（附的不只是原词）。

**一致性**：最弱的一维。同一组并列被解释词 `ubbegabahulo` / `uttāsabahulo` / `ukkaṇṭhanabahulo` / `aratibahulo` 的译法句式不统一（"充满惊怖"/"充满恐惧"/"满是厌倦"/"不乐"——前两个"充满"、第三个"满是"），而原文是同一 `-bahula` 构词系列；`Tena ādīnavānupassanamāha` 与 `Iminā nibbidānupassanamāha` 两句同构，译文却都作"以这句话他说的是…"，把 `tena`（阳性/中性具格，指前句）与 `iminā` 的区别抹平，且连用两次句式完全相同的"以这句话他说的是"读来生硬。另外 `nibbedha` 一词在 `181-1166-98-115` 内译"洞穿"、"能洞穿的"、"洞穿的智慧"三形，与标题句 `nibbedhikapaññaṃ` 在 `181-1166-2-28` 的"洞穿的智慧"尚能对上，但"穿透、通达，就是洞穿"把 `nibbijjhanaṃ paṭivijjhanaṃ` 两个同义词译成两个不同词后再归一，层次略乱。

## 问题清单
按级别从高到低排列。

### 🟧 error

- `181-1166-39-60`｜错译（词义、修饰关系）｜片段「对一切行不断生起悚惧的人」
  - 问题：`abhiṇhappavattasaṃvego` 是 bahubbīhi 复合形容词，释 `ubbegabahulo`（"充满惊怖"），其义为"悚惧不断生起（的状态/其人）"。译文加"的人"把释义词变成人称名词，而被释词"充满惊怖"本身没有译成人称，被解释词与释义在词性上对不上；同组 `ukkaṇṭhanabahulo` 条又未加"的人"，自相矛盾。
  - 建议：统一为状态性表述，如"对一切行不断生起悚惧"，与同组其余条目保持同一句式。

- `181-1166-61-67`｜错译（词义、修饰关系）｜片段「对一切行心多惊慌的人」
  - 问题：同上。`utrastamānaso` 是"心惊慌的"（bahubbīhi，`mānasa` 为末项），译"心多惊慌的人"中"多"对 `bahuso` 的位置处理可以，但"的人"同样把形容词实体化，与被释词"充满恐惧"不对称。
  - 建议：改为"对一切行心多惊慌"。

- `181-1166-87-94`｜错译（词义、修饰关系）｜片段「指的是他的趣向，就是那指向一切行之外的涅槃而运转的智」
  - 问题：`pavattañāṇamukho` 是 bahubbīhi，义为"以…运转之智为其趣向者"，整体修饰主语。译文拆成"他的趣向，就是…智"的判断句，把 `mukha` 与 `ñāṇa` 的关系说成"趣向＝智"，修饰关系错位；且与本句被释词译作"心思向外"在同一句内取义不一（前作"向外"、后作"趣向"）。
  - 建议：统一 `mukha` 的取义，如"**以外为趣向**：指的是以指向一切行之外的涅槃而运转的智为其趣向"。

- `181-1166-95-97`｜错译（词义、修饰关系）｜片段「也就是说，他的趣向就是这样运转起来的解脱门」
  - 问题：承上句，`tathā pavattitavimokkhamukho` 同为 bahubbīhi（"以如此运转的解脱门为趣向者"）。译文的"他的趣向就是…解脱门"同样把复合词判断句化；另"也就是说"对 `tathā` 的处理把 `tathā`（如前所说那样，修饰 `pavattita`）错置为篇章连接词。
  - 建议：「同样，也就是以这样运转起来的解脱门为趣向」。

### 🟨 warning

- `181-1166-68-70`｜不导致误解的汉语语病｜片段「以这句话他说的是过患随观」
  - 问题：「以这句话他说的是」为生硬的翻译腔，状语「以这句话」与主语「他」之间缺少停顿，读来不顺；`tena` 指代的是前一句整句，译作"这句话"尚可，但句式僵硬。
  - 建议：改为「他借这句话说的是过患随观」或「这句话说的是过患随观」。

- `181-1166-78-80`｜语言风格不统一｜片段「以这句话他说的是厌离随观」
  - 问题：与 `181-1166-68-70` 完全同形，但原文一处用 `tena`、一处用 `iminā`，两词的近指/远指差别被抹平；连续两句句式一字不差，行文呆板。
  - 建议：此句改用近指，如「他用这一句说的是厌离随观」，与上句区分开。

- `181-1166-71-77`｜文言语体｜片段「满是厌倦」
  - 问题：「满是」为半文半白的书面简省，且与同组 `-bahula` 系列已采用的「充满…」不一致（见下一致性条）。
  - 建议：统一作「充满厌倦」。

- `181-1166-71-77`｜关键词语意不明确，或二意场合没有注释｜片段「朝向离诸行（visaṅkhāra，即涅槃）」
  - 问题：style.md 第三节规定夹注只在术语首次出现时以圆括号附**巴利原词**；此处在括号内又塞入「即涅槃」的释义，体例越界。且 `visaṅkhāra` 等同涅槃是本句译者的推断，原文未明说——这类解释应进报告或脚注，不进正文夹注。
  - 建议：正文只留「离诸行（visaṅkhāra）」，「即涅槃」移至脚注或术语表。

- `181-1166-98-115`｜整句逻辑表达不规范｜片段「这洞穿是慧所具有的，所以慧叫做能洞穿的」
  - 问题：`so etissā atthīti nibbedhikā` 的语源解析，译文用「是…所具有的」＋「所以…叫做」勉强达意，但"这洞穿"与"慧"的指代链条绕；且同句后文「因为它能洞穿，所以叫做能洞穿的」出现"能洞穿的"重复定义，读者难以分辨两种语源解析的差别。
  - 建议：明确两解的对立，如「它（慧）有这洞穿，所以叫能洞穿者；或者，因为它自己洞穿，所以叫能洞穿者」。

- `181-1166-81-86`｜代词指代不明确｜片段「这同一种随观的一次又一次出现」
  - 问题：`tassā eva` 回指上句的 `nibbidānupassanā`（厌离随观），译文「这同一种随观」未点明是哪一种，隔句回指后读者需自行上溯；`aparāparūpapatti` 译「一次又一次出现」可，但主句缺谓语呼应（承前省 `āha`），中文读来不成句。
  - 建议：补明所指并补回谓语，如「他借**不乐**等等这几句，说的是这同一种厌离随观反复地生起」。

### 🟦 suggestion

- `181-1166-2-28`｜语言表达不够流畅｜片段「而不是以别的方式成就——为了从原因的角度来显示洞穿的智慧，」
  - 问题：`na aññathāti kāraṇamukhena … dassetuṃ` 一长句，译文用破折号把"不是以别的方式"与目的状语拼接，再以逗号结尾悬挂到下一句（下一句才是 `vuttaṃ`）。跨句承接在 channel 里分条存放，读者单看此句会觉得话没说完。
  - 建议：此句自身收尾，如「…而不是以别的方式成就。为了从原因的角度显示洞穿的智慧，」用句号断开，降低跨句依赖。

- `181-1166-29-38`｜语言风格不统一｜片段「所以说了“**对一切行充满惊怖**”等等这段话」
  - 问题：「所以」对应的原文并无连词（`tiādi vuttaṃ`，承前目的句），属译者增补的逻辑连接；与前句破折号结构叠加后，因果关系被加重。另「等等这段话」中「这段话」略赘。
  - 建议：「于是说了“**对一切行充满惊怖**”等等」。

- `181-1166-39-60`｜语言风格不统一｜片段「**充满惊怖**」
  - 问题：`-bahula` 系列四条被解释词译法分别为「充满惊怖」「充满恐惧」「满是厌倦」「不乐」，构词统一而译法不统一。其中 `aratibahulo` 译「不乐」漏掉了 `-bahula`。
  - 建议：全系列统一为「充满 X」，并把 `aratibahulo` 补足为「充满不乐」。**注意**：这四个词是复注引自义注的黑体被解释词，改动前须核对义注层译文，以父层为准。

- `181-1166-116-123`｜语言表达不够流畅｜片段「未曾贯穿到底、使它终结过的」
  - 问题：「使它终结过的」中"它"回指 `saṃsāra`，但本句语序下"它"离先行词较远；「过的」与前半「未曾」构成的否定范围也略含混。
  - 建议：「在无始的轮回中未曾贯穿它、使轮回终结」。

- `181-1166-124-132`｜该使用而没有使用术语标记｜片段「是对这同一点的释义」
  - 问题：`tasseva atthavacanaṃ` 的 `atthavacana`（释义语）是注释书体例术语，译「释义」正确但未作术语处理；同类表达在三层统译中应有固定译法，建议登记进 `terms.md` 以保跨段一致。
  - 建议：固定为「是对前者的释义语」并登记术语。
