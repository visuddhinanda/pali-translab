## 理由

**资源缺失（影响信心）**：本次只注入了巴利原文与 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此释义正确性无法以义注核对，格与句法角色无法以 nissaya 的缅文助词逐词核对，只能依巴利形态与上下文判断；本报告中涉及格、修饰关系的判断（见 error 第 1 条）属于形态学上可直接判定的部分，其余存疑处已降为 warning。另外本层是复注（ṭīkā），其黑体被解释词应与父层（《无碍解道》本文 / 义注）逐字同译——父层译文未注入，**「被解释词与父层逐字同译」这一硬约束本轮无法核验**，是本次评分的最大盲区，建议下一轮 harmonize 时连同父层一并读入复核（尤其是 `多有喜悦 / 多有欢喜 / 多有满足 / 多有欣悦`、`迅速地趣入无常`、`让它们彻底不再生起`、`彻底除尽` 这几个词条）。

**准确性**：整体忠实，释词格式（词条—释义）处理稳定，`anu abhāvaṃ`（74-89）这类词素拆解释义、`tulā / tīraṇa`（76-88）的喻义都译出来了，`indena vissaṭṭhavajiraṃ viya`（2-34）的比喻、`asamūhatuppanna`（32-51）的术语结构也准确。扣分集中在三处：`aniccato` 的从格义被当成了 `javati` 的宾语；`pabbhāra` 译作「倾注」与词义不合；`anabhāvaṃ gameti` 的词条译法（「彻底不再生起」）与同句释义（「归于无有」）互相矛盾。无漏译，无教理层面的错误，`byāpādavitakka / vihiṃsāvitakka / akosalla` 等术语取义正确，故无 fatal。

**风格符合度**：现代书面汉语达标——通篇未见「此中／故为／彼等／是故／于…之际」之类文言写法，`haṭṭhappahaṭṭho udaggūdaggo`（34-43）译成「兴高采烈、十分振奋」而非文言四字格，方向正确；标点全角，引号统一「“”／‘’」，无 ASCII 引号，JSON 安全无隐患；译文中无任何工作标记或残留候选。扣分在于若干处定语过长套叠、顿号连接非并列成分，以及「不予容忍」这类公文腔；另外法相术语的巴利夹注只给了 `pīti`、`somanassavedanā` 两处，而「行舍智／随顺智／彼分／镇伏／聚思惟／生灭随观」等更需要夹注的术语反而都没给，与 `style.md` 第二、三节的规定不符。

**一致性**：主要问题是 `vasena` 的处理在相邻句之间摇摆（「以…的观显示」／「就…来显示」／「就…而衡量」／「以…去判定」），`balava` 一会儿译「强的」一会儿译「强力的」，`pada` 全篇译作「句」（实为「词语」），以及 `sabhāva`（54-65「本性」）与 `dhammatā`（32-51「本性」）撞同一个汉语词。`javanapaññā` → 「疾速趣入的智慧」、`samuccheda` → 「彻底断绝」在三段内保持一致，是做得好的部分。

## 问题清单

### 🟧 error

- `181-1164-2-34`｜错译（格／修饰关系）｜片段「迅速地趣入无常」
  - 问题：`aniccato` 是 `-to` 从格形式，义为「以无常（之相）」，是 `javati` 的方式状语，不是宾语；译成「趣入无常」把它读作了宾格。同句释义本身也印证了这一点——「迅速地通达无常的特相」，所缘是特相，趣向的对象另有所指（参 121-133 的 `rūpanirodhe ... khippaṃ javati`，趣向的是色灭／涅槃）。
  - 建议：改为「就无常（这一点）迅速趣入」或「以无常之相迅速趣入」一类读法，并与父层该词条译法对齐。

- `181-1164-127-133`｜错译（词义）｜片段「倾向、趋向、倾注」
  - 问题：`ninna / poṇa / pabbhāra` 是形容地势「低洼、倾斜、下倾」的喻义三连词，描述心如水之就下趣向涅槃。「倾注」义为倾泻灌入，与 `pabbhāra`（斜坡、下倾）不合，且三词被译成两个近义词加一个异义词，喻象断了。
  - 建议：三词取同一喻系，如「低下、倾斜、下趋」或「倾、趣、向」，必要时在报告定案后登记进 `terms.md`。

- `181-1165-74-89`｜导致误解的表达｜片段「让它们彻底不再生起」
  - 问题：`anabhāvaṃ gameti` 是「令归于无有」，词条译作「彻底不再生起」把重心挪到了「不生」，而紧接着的释义又译作「归于无有」——同一句内词条与释义互相不照应，读者会以为是两件事。另外本层是复注，该词条引自父层，词条译法须与父层一致。
  - 建议：词条统一为「使它们归于无有」一类译法，与同句释义及父层保持逐字同译。

### 🟨 warning

- `181-1164-70-75`｜不导致误解的汉语语病｜片段「就没有坚实的意义来说」
  - 问题：「没有坚实」缺中心语，「坚实」在这里不能单独作名词；下文自己补出了「坚实核心」，词条反而没补。
  - 建议：改为「就没有坚实核心的意义来说」或「就无实的意义来说」。

- `181-1163-6-9`｜关键词语意不明确｜片段「这同一句的同义语」
  - 问题：`pada` 在此指 `hāsabahulo / vedabahulo` 这类被释的**词语**，不是句子；译作「句」会让读者以为在说整句。同病见 `181-1163-10-15`「是根本句」、`181-1163-16-23`「而说的解说句」、`181-1164-35-38`「其余各句」。另「这同一句」指代对象（`hāsabahulo`）不明确。
  - 建议：`pada` 统一译「词」（根本词／解说词），并把「这同一句」改为「这同一个词」或直接点明「多有喜悦」。

- `181-1163-24-28`｜整句逻辑表达不规范｜片段「就不太强的喜所呈现的满足样态而说的」
  - 问题：原文承前省略了 `niddesapadaṃ`，译文跟着省，结果「是就…而说的」缺中心语，句子悬空。`181-1163-29-33`「而说的」同病。
  - 建议：补出「解说词」，如「是就…满足样态而说的解说词」。

- `181-1164-82-88`｜标点符号使用错误｜片段「这同一种、此时作为判定的观智」
  - 问题：顿号连接了「这同一种」与「此时作为判定的」两个非并列成分，读起来像漏字；「这同一种」指代也偏虚。
  - 建议：改为「就是用同一种观智、此时作为判定者去判定」或「就是用这同一种观智——此时它充当判定——去判定」。

- `181-1165-52-58`｜标点符号使用错误｜片段「不让它进入心的相续、在那里停留下来」
  - 问题：顿号连接的是两个有先后关系的谓语，应用连词而非顿号。
  - 建议：改为「不让它进入心的相续并停留下来」。

- `181-1165-32-51`｜代词指代不明确｜片段「虽然已经由止和观以镇伏的方式」
  - 问题：整句无主语，被舍弃的是什么（烦恼／寻）要读到下文才能回推；原文靠 `pahīnampi` 的性数与上文 `kilese` 相照应，汉语没有这个手段。
  - 建议：补出「这些烦恼」作主语。

- `181-1164-96-102`｜关键词语意不明确（罕见术语无注）｜片段「就聚思惟而衡量」
  - 问题：「聚思惟」（`kalāpasammasana`）是不常用术语，首次出现无巴利夹注也无解释，一般读者无从索解；同段「生灭随观」「坏灭随观」情况类同。
  - 建议：首次出现夹注巴利原词，如「聚思惟（kalāpasammasana）」。

- `181-1164-54-65`｜整句逻辑表达不规范｜片段「就在哪里坏灭，具有坏灭的本性」
  - 问题：`bhijjanato` 与 `khayasabhāvattā` 是两个并列的原因（从格／因格），译文把后一个降成了并列陈述，因果层级丢了。
  - 建议：改为「…就在哪里坏灭，因而具有坏灭的自性」。

### 🟦 suggestion

- `181-1164-114-120`｜该使用而没有使用术语标记｜片段「以行舍智和随顺智使它显露出来」

  - 建议：按 `style.md` 第二节，法相术语首次出现一律夹注巴利原词，常见词不必夹注。涉及「彼分」「镇伏」等同处理。

- `181-1164-39-45`｜语言风格不统一｜片段「以取特相为所缘的观显示了」

  - 建议：全段统一为「就…而言」或「从…方面」，与 `181-1164-134-147`「就达到顶点的观来显示」取齐。

- `181-1163-29-33`｜语言表达不够流畅｜片段「强的喜」

  - 建议：统一为「较强的喜／不太强烈的喜／强力的观」一类双音节处理。

  - 建议：改为「以迅猛之势」或「带着急速的势头」。

- `181-1165-2-31`｜语言风格不统一｜片段「断绝对立面」

- `181-1164-121-126`｜复杂嵌套句理解困难｜片段「作为色蕴灭尽的涅槃当中」

- `181-1165-52-58`｜语言风格不统一｜片段「不予容忍」
