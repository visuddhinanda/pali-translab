# Review — 181:998-1000（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位判定无独立基准，下文凡涉格位均只据父层义注与上下文）／父层义注（book 99，段 1494-1591，已定稿译文）✅
> 本层为复注（ṭīkā），黑体被解释词引自父层义注，已逐条与父层译文核对。

## 跨段一致性

- **aṭṭhārasavidha**：§998 两处（句 `181-998-2-5`、`181-998-95-106`）译「以十八种方式」，父层三处（`99-1498-39-47`／`56-63`／`64-70`）一律译「十八种」（作定语，修饰「身随观念处」）→ **必须统一为「十八种」**，详见下条。
- **vinaya（abhijjhāvinaya / domanassavinaya）**：§999-45-79 译「调伏」；父层所释的 `vineyya` 译作「除去」（`99-1498-71-87`：「**除去对世间的贪欲和忧恼**」，释文作「排除、镇伏」）→ 本层正是在注这个词，建议统一为「除去」（「通过除去贪欲，就舍断了……」），否则读者看不出注的是哪个词。
- **assāda / sāta / rasa**：§1000 内 `assāda`（句 `8-17`）与 `sāta`（句 `44-60`）都译「美味」，而 `ārammaṇarasa` 译「所缘之味」（句 `67-71`，与父层 `99-1506-43-59`「所缘之味」一致 ✅）。三词同用「味」字且「心理上的美味」读来别扭 → 建议 `assāda`→「滋味／快意」，`sāta`→「适意」，`rasa` 保留「味」。
- **引出语（āha / tenāha）**：§998 作「正是因此才说——」「因此说——」，§999-2-9 作「所以说道——」。父层通例是「因此说——」「正如经中所说——」，「说道」在父层只用于人物对话（如 `99-1537-18-24`）→ §999-2-9 建议改为「所以说——」。
- **贪欲**：§999-28-44 同一句里「贪欲」既指 `abhijjhā` 又指 `kāmacchando`（「用“贪欲”一词就把贪欲盖包括进去了」）。父层两词都作「贪欲」（`99-1498-71-87`／`99-1506-2-18`），所以不宜改译名，但本句必须靠夹注区分 → 建议「用“贪欲”（abhijjhā）一词就把贪欲（kāmacchanda）这一盖包括进去了」。
- **ātāpa / ātāpana / ātapa**：现译「热炙／烧炙／炙热」三分，区分可用 ✅；但 §998-30-36 把巴利原形直接写进正文，格式需改（见该句）。

## §998 句 181-998-2-5

- **问题**：被解释词与父层不一致（必改） — 黑体 `Aṭṭhārasavidhenā` 现译「以十八种方式」，父层 `99-1498-39-47` 译「这**十八种**身随观念处」、`56-63`「能把握**十八种**身随观念处的智慧」，一律是定语「十八种」，不是「以……方式」。对应关系断了。
- **问题**：释义落空 — 原文 `aṭṭhārasavidhenā**ti** aṭṭhārasavidhā` 是把具格形还原为主格（说明这里的 -ena 不表「凭借某种方式」，而就是「有十八种」），现译「以十八种方式，就是十八种」在汉语里成了同语反复，读者看不出注的是什么。
- **建议**：改为「**十八种**——就是（身随观念处）有十八种。」保留父层字面「十八种」，把 gloss 译成「有十八种」以显出语法还原的用意。

## §998 句 181-998-95-106

- **问题**：同上（必改） — 所引父层原句黑体 `**aṭṭhārasavidhena** … pe … **sammā pajānanto**` 现译「“**以十八种方式**……（中略）……**而正确地了知**。”」。父层定稿为「就是用能把握**十八种**身随观念处的智慧而**正确地了知**」。
- **建议**：「“**十八种**……（中略）……**而正确地了知**。”」后半已与父层逐字相同 ✅，只需改前半。

## §998 句 181-998-30-36

- **问题**：格式违反 `knowledge/style.md` 第三节（必改） — 「不过就像 ātapa（炙热）这个词一样，ātāpa（热炙）这个词……」把巴利原形当正文、汉译入括号，与约定（不显示巴利原文；术语首现用「汉译（pali）」夹注）正好相反。
- **问题**：逻辑易误读 — 原文的类比点是「惯用固定（niruḷha）」这件事，不是「所指相同」。现译「就像 ātapa 这个词一样，ātāpa 这个词也是专门用在精进上的」，会被读成 ātapa 也指精进。
- **建议**：「不过，正如“炙热”（ātapa）一词有其固定的惯用所指，“热炙”（ātāpa）一词也同样固定地专用于精进。」

## §998 句 181-998-63-72

- **问题**：格式 — 「而这里的 ī 这个音」同样是裸巴利；且 `īkāra` 指的是词尾长音。
- **建议**：「而这里词尾的长音 ī 是表示赞叹或表示程度格外」，或「而“精勤”（ātāpī）一词词尾的长音」。`sammappadhāna` 译「正勤」与父层（`99-1502-37-43`「四正勤」、`99-1503-2-10`「正勤」）一致 ✅。

## §998 句 181-998-11-19

- **问题**：术语精度 — `tīsu bhavesu` 现译「三界」。`bhava` 是「有」（欲有、色有、无色有），「三界」通常对 `dhātu`，易混。
- **建议**：「在三有（tayo bhavā）中」，或「在三种生存界中」。

## §998 句 181-998-87-92

- **问题**：释义读来循环 — 「**正知**，就是具备被称为正知的智」。黑体 `Sampajāno` 必须沿用父层「正知」（`99-1498-56-63` ✅ 已一致），但 gloss 中的 `sampajañña` 是所依的那个法，需与作为人的「正知（者）」区分开。
- **建议**：「**正知**，就是具备那称为“正知”（sampajañña）的智。」

## §998 句 181-998-6-10

- **问题**：行文 — 「就是对于修习念处这件事的人」中的「这件事」累赘，`satipaṭṭhānabhāvaṃ bhāventassa` 是「修习念处之修习（的状态）」。
- **建议**：「**修习念处的人**——就是修习念处这一修习的人。」（父层该处指的是「比丘」，本层用「人」可，不算断链。）

## §998 句 181-998-107-129

- **存疑**（不改译文，记在报告）：`vacanattho` 列出 `sammā / samantato / sāmaṃ` 三项，译文如实译作「正确地、从各个方面、并且亲自地」✅；但随后的三段解释里，第三段 `uparūparivisesāvahabhāvena pavattiyā sammā pajānanto` 又回到 `sammā`，与「亲自（sāmaṃ）」对不上。可能是原文此处 `sāmaṃ` 的解释省略，或 `sammā` 作第二义重释。译文照字面处理是稳妥的，但请记入已知难点，待复注他处或别本比对后定案。

## §999 句 181-999-45-79

- **问题**：术语一致性 — `vinaya` 译「调伏」，见「跨段一致性」第 2 条，建议改「除去」。
- **问题**：擅补成分 — `kāyabhāvanāya anabhiratiyā` 现译「对修习身随观的不喜」，原文只作 `kāyabhāvanā`（身的修习）。上下文虽确在讲身随观，但「随观」是译者补出的。
- **建议**：「对修习身的不喜」；若保留「随观」，宜在报告中登记为有意补出。
- **问题**（轻）：`kāyasampatti / kāyavipatti` 译「身体的美好／败坏」，可考虑「身的圆满／身的损坏」以与后文「并不存在的清净、快乐」一组抽象语体齐平。

## §999 句 181-999-2-9

- **问题**：引出语不统一 — 「所以说道——」，见「跨段一致性」第 4 条，改「所以说——」。
- 其余 ✅：所引父层黑体「**在那个称为身的世间中**」（句 `181-999-10-18`）与父层 `99-1498-71-87` 逐字相同 ✅。

## §999 句 181-999-28-44

- **问题**：术语歧义 — 「贪欲」同句兼指 `abhijjhā` 与 `kāmacchanda`，见「跨段一致性」第 5 条。
- **建议**：加巴利夹注区分。`byāpāda`→「瞋害」与父层 `paṭigha`→「瞋恚」（`99-1498-71-87`）可区分开 ✅，保留。

## §1000 句 181-1000-8-17、18-34、44-60

- **问题**：词源双关在汉语中不可解 — `sukhā` ← `sukhayati` / `su+khādati` / `su+khanati`，`dukkhā` ← `dukkhayati` / `du+khādati` 的三重谐音，现译「咬食、挖除」只剩动作，读者无从知道这是在拆词。
- **建议**：首现处加圆括号夹注原词，如「所以叫做**乐**（sukha）」，并在拆词处点出所拆的词形（如「它很好地（su-）咬食（khādati）」）。按 `style.md`，不得在译文里留问号或候选标记，夹注即可。
- **问题**：`assāde` / `sātaṃ` 均译「美味」（「心理上的美味」别扭），见「跨段一致性」第 3 条。
- **建议**：「使与它相应的诸法和身体都得到滋味」「挖除身体上和心理上的适意」。
