# Review — 99:476-479（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层本文+定稿译文（book 84:163-174）✅／**nissaya ❌ 未注入**／**复注（ṭīkā）❌ 未注入**
> 本层是义注，其释义标准（复注）与词级基准（nissaya）都不在本次输入中，以下判断只能依据巴利原文、父层定稿译文与所引经证本身，**词法与传统取义部分未经独立核验**。

## 一、被解释词与父层对照（首查项）

| 被解释词 | 父层译法（84:164-174，已定稿） | 本层译法 | 判定 |
|---|---|---|---|
| **etadaggaṃ**（99-477-2-14） | 84-164「…最深的，**就是**…」；84-165~173「…的，**第一位就是**…」 | 「这是最上的」「最上」「最上的地位」「最上称号」 | ❌ **对应断裂，必改** |
| paṭhamavaggo（99-477-2-14） | 84-163「第一品」 | 「第一品」 | ✅ |
| mahāpaññatāya（99-478-35-42） | 84-165「智慧广大」 | 「智慧广大」 | ✅ |
| anuruddhatthera（99-479-2-20） | 84-168「阿那律」 | 「阿那律长老」 | ✅ |
| mahāmoggallānatthera（99-479-44-54） | 84-166「大目犍连」 | 「大目犍连长老」 | ✅ |
| sāriputta（99-478-14-34） | 84-165「舍利弗」 | 「舍利弗」 | ✅ |

**必改项说明**：整个 476-479 是在注解 `etadaggaṃ` 这一个词，而父层定稿把它译进了「（论）…的，第一位就是…」这个句式里（agga → 「第一位」），84-164 又作「最深的，就是」。本层一律译「最上」，读者看完这几段注，回头对照本文根本找不到被注的是哪个词——注与本文的挂钩完全断了。
建议（择一，全 chunk 统一执行）：
- **推荐**：首次出现处显式搭桥，如 99-477-2-14 译「…第一经中，**etadaggaṃ**（父层译作“第一位就是”，直译“这是最上的”）就是“这个最上”的意思」；其后 agga 的释义讨论仍用「最上」，但 `etadaggaṭṭhānaṃ`（478-14-34、478-35-42）改译「第一的地位／第一之位」。
- 或：全部改用「第一」为主译，「最上」只在四义辨析（seṭṭha 义）处出现。

另需注意：父层自身 164 与 165-173 译法就不一致（「最深的，就是」／「第一位就是」），父层已定稿不动，但本层搭桥时应以多数形式「第一位」为准。

## 二、跨段一致性

- **etadagga / agga**：§476「最上称号」／§477「最上者」「最上」／§478「最上称号」「最上的地位」 → 同一个被注词出现四种中译。建议依上节统一，且 §476、§478 的「称号」原文（`pada` / `sannikkhepa`）无对应成分，应去掉。
- **seṭṭha**：§477-15-21、106-138、139-144、156-164 译「最胜」，§477-145-155 译「最殊胜」 → 统一为「最胜」（四义表既已定名，后文不应换词）。
- **sāsana**（世尊传话）：§479-44-54「消息」、§479-71-80「消息」、§479-121-127「口信」 → 统一为「口信」（更贴 sāsana 在此的语义）。
- **dvādasayojanikā parisā**：§479-2-20「十二由旬范围内的全体大众」、§479-135-141「这十二由旬的大众」 → 后者补足为「这十二由旬范围内的大众」。
- **对话引号体例不统一**：§479 是一段连续问答，§479-2-20/21-28/29-36/37-43/44-54/55-62/92-107/108-120 用了引号，唯独 §479-63-70（阿那律的回答）没有。同一场对话必须统一。
- 一致且无需改动：satthā「导师」、bhagavā「世尊」、paṇḍukambalasilā「黄石座」、tāvatiṃsabhavana「三十三天」全 chunk 一致 ✅。

## §476 句 99-476-2-2
- **问题**：增译 + 体例 — `Etadaggapadavaṇṇanā` 中 `pada` 是「语句／词」，没有「称号」的意思；「称号」是译者添加，且与 §477「最上者」、§478「最上称号」三处打架。另外义注小节标题用书名号《》不妥（它不是书名）。
- **建议**：改为「〈最上〉一语的解释」或「“最上”句释」，并与第一节定下的 etadagga 统一译名保持一致。

## §477 句 99-477-2-14
- **问题**：被解释词断链（详见第一节，**必改**）；`Etadaggesu` 译「在“最上者”这一部分」——`etadaggesu` 指的是《最上品》诸经（复数指经文段落），不是「最上者」（人），「这一部分」也过于含糊。
- **问题**：括注「（这是最上的）」与紧接其后的释义「就是“这个最上”的意思」语义重复，形成循环解释。
- **建议**：「188.《最上品》（etadagga）诸经中，第一品第一经里，**etadaggaṃ**（父层译作“第一位就是”）就是“这个最上”的意思。」

## §477 句 99-477-15-21
- **问题**：括注「agga（最上、顶端）」是译者预先给出的两个义项，而这句的作用恰恰是宣告下文要辨四义（ādi／koṭi／koṭṭhāsa／seṭṭha）；预判会让读者以为只有两义。且「顶端」与下文 koṭi 的定译「末端」用词不一。
- **建议**：删去括注 —「这里 agga 这个词，用在开端、末端、部分、最胜这四个意义上。」（`dissati` 译「用在…意义上」可保留。）

## §477 句 99-477-22-48
- **问题**：称呼拆分 — `samma dovārika` 是一个呼语（对守门人的亲切称呼），译成「朋友，守门人啊」变成两个并列呼语，读者会以为在叫两个人。
- **问题**：例证功能丧失 — 本句是要证明 agga = ādi（开端），但 `Ajjatagge` 译「从今天开始」后，`-agge` 这个成分在译文里看不见了，读者无法看出例证在哪里。
- **建议**：「“守门人朋友啊，从今天这个开端起（ajjatagge），我要对尼乾子和尼乾女关上门”」——或至少在括注里点出 `ajja+agge`＝「以今天为开端」。

## §477 句 99-477-69-105
- **问题**：例证功能丧失（同上，此处更严重）— 本句证明 agga = koṭṭhāsa（部分／份），前半 `ambilaggaṃ` 等译「酸的那一份」保住了「份」✅，但后半 `vihāraggena vā pariveṇaggena vā` 译「按精舍来分配，或者按院落来分配」把 `-agga` 整个丢掉，这条引证在译文里不成立。
- **建议**：「…我允许按精舍份、或按院落份来分配」。

## §477 句 99-477-145-155
- **问题**：语病 — 「既是到达顶点的，**所以**是最上的；也是最殊胜的，**所以**是最上的」，「既…所以…；也…所以…」关联词错配，读不通。
- **问题**：`seṭṭhabhūta` 译「最殊胜」，与前文四义表的「最胜」不一致（见跨段一致性）。
- **建议**：「因为那些长老在各自的领域里，既因为到了顶点而称为最上，也因为是最胜的而称为最上。」

## §478 句 99-478-2-13
- **问题**：增译 — `āgamana` 指的是（长劫以来的）来历、资历、修行历程，译文作「宿愿本行」中的「愿」字原文无据，容易被读者当成「发愿授记」这一独立项（那是 abhinīhāra / patthanā）。
- **问题**：`etadaggasannikkhepo` 中「称号」同样是添加（见 §476）。
- **建议**：四因译名固定为「由事缘（aṭṭhuppatti）、由宿世来历（āgamana）、由长期修习纯熟（ciṇṇavasitā）、由功德超胜（guṇātireka）」，并在 §478-35-42 同步改「宿愿本行等」→「宿世来历等」。

## §478 句 99-478-98-123
- **问题**：文言／半文半白（**必改**）— 「享受荣华」是文言色彩词，且「荣华」带世俗富贵联想，`sampattiṃ anubhavati` 指的是享受天界的福报成就。
- **建议**：「…坐在长六十由旬的黄石座上，享受着天界的福乐」。

## §478 句 99-478-160-180
- **问题**：术语误用（**必改**）— `mātaraṃ kāyasakkhiṃ katvā` 中 `kāyasakkhī` 在此是「亲身在场的见证者」，译成「以母亲为身证者」会被读者读成佛教果位术语「身证（kāyasakkhī，七种圣者之一）」，意思完全跑偏。
- **建议**：「以母亲为亲自在场的见证者」，或「让母亲作亲证的听法者」。

## §479 句 99-479-29-36 与 99-479-37-43
- **问题**：引号跨句不成对 — 29-36 有上引号无下引号，37-43 有下引号无上引号。本层按 `(word_start, word_end)` 逐句入库、逐句显示，读者单看任一句都会看到孤立的引号。
- **建议**：每句自闭合：29-36 作「“尊者，我们没有见到导师是不会走的。”」；37-43 作「“导师什么时候回来呢？请您打听一下导师回来的日子吧。”」

## §479 句 99-479-63-70
- **问题**：缺引号（这是阿那律的回答，同场对话其余各句都带引号）。
- **问题**：行文拗口 — 「让大家看到有殊胜能力的人所具的殊胜」，「殊胜」连用两次且句子绕。
- **建议**：「“有能力。不过他是想让大家见识一下有特殊能力的人的本领，才这样说的。”」

## §479 句 99-479-121-127
- **问题**：跨段术语漂移 — `sāsana` 此前两处译「消息」，此处译「口信」。
- **建议**：统一为「口信」，并回改 §479-44-54、§479-71-80。

## §479 句 99-479-135-141
- **问题**：表述省略过头 — 「供给了这十二由旬的大众粥饭」，与 §479-2-20 的「十二由旬范围内的全体大众」不一致，单看此句「十二由旬的大众」不好理解。
- **建议**：「小给孤独长者在这三个月里，为这十二由旬范围内的大众供给了粥饭。」

## 存疑 / 原文问题（记录，不改）
