**准确性**：主体可靠。349 段四种断（tadaṅga / vikkhambhana / samuccheda / paṭippassaddhi / nissaraṇa，实为五种）的定义式句子（`etena … iti X`）处理得当，"由它而…，所以叫做…"的构词释义体例还原准确，`avayavabhūtena ñāṇaṅgena`、`paccanīkadhammānaṃ`、`asanivicakkābhihatassa` 等难点均无误。346 段那一长串师徒对答，译文正确识别出 `bhante` / `āvuso` 的说话人交替（弟子称长老 bhante、长老称弟子 āvuso），这一层在原文里只靠称谓区分，没译错说明读懂了。扣分集中在三处：`samucchedappahānaṃ` 的译名塌缩（见 error 第一条）、`maṇivaṇṇe` 的黑体词与释义不对位、`Kāḷakaṃ / tilako` 的对释方向可能反了。

**风格**：现代书面汉语的底子是稳的，未见"此中/故为/彼等/是故"一类硬性禁例，`style.md` 第一节禁例表基本守住。但仍有若干单音节文言残留（"凭着""不至于""总该""所以叫做"密集堆叠），以及 `nanu`、`siyā` 等语气词译得偏文。标点全部为全角，未发现 ASCII 引号，JSON 安全约束合规。黑体标记（`**…**`）与原文被解释词一一对应，未见越界加粗。

**一致性**：术语内部自洽——"彼分断/镇伏断/正断/止息断/出离断"五名成系统，`pahāna` 一律作"断"，`ñāṇa` 一律作"智"。跨句代词指代清楚。唯一系统性隐患是 `samucchedappahānaṃ` 与 `samuccheda` 共用"正断"一名（见下）。夹注巴利原词的用法（帝青宝（indanīla）、歇坐堂（āsanasālā）、方便（upāya））符合 style.md 的混合策略，但三处密度不均，属可提升项。

## 问题清单

### 🟧 error

- `181-349-58-74`｜错译（词义）｜片段「所以叫做**正断**」
  - 问题：`samucchedappahānaṃ` 是"正断断/断除断"这一整个复合名，译作"正断"后与前文刚定义的 `samucchedo`（"所以叫做正断"）同名，两个不同层级的概念塌缩成一个词。原文的构句正是 `samucchedo`（正断）→ `pahānaṃ`（断）→ `samucchedappahānaṃ`（正断之断），三步递进，译文把第一步和第三步压成同一个词，递进关系消失。同段 `181-349-75-91`「这样的断除就叫做正断」承袭同一问题。
  - 建议：与 `tadaṅgappahānaṃ`→彼分断、`vikkhambhanappahānaṃ`→镇伏断的构词方式保持一致，`samucchedappahānaṃ` 宜作"正断断"或"断除断"，`samuccheda` 单独出现时作"正断"或"彻底截断"，两者区分开。

- `181-346-228-231`｜义理或用词与注释书不符｜片段「**如宝珠般澄净**」
  - 问题：被解释词 `Maṇivaṇṇe` 的字面是"宝珠色/宝色"，释义 `indanīlamaṇivaṇṇe` 是"帝青宝之色"——整条讲的是**颜色**，不是澄净度。译文把黑体词译成"如宝珠般澄净"，加进了原文没有的"澄净"义，而紧接的释义却老实译成"那样的颜色"，导致黑体词与释义在同一句里打架。复注的黑体词是从上层义注原样引出的，按硬约束须与父层逐字同译，不能意译加义。
  - 建议：黑体词改为"**宝珠色**"或"**宝色**"，保持与释义"帝青宝那样的颜色"对位。（义注未注入，父层实际用词待核。）

- `181-347-23-36`｜错译（词义）｜片段「**黑点**这个词是就大的斑点说的，**斑痕**这个词是就小的斑点说的」
  - 问题：`kāḷaka`（黑斑）与 `tilaka`（痣、芝麻状小点）的大小对释，译文给出的对应关系需核。`tilaka` 由 tila（芝麻）而来，本义即小点，译作"斑痕"未体现"小"；而"黑点"在现代汉语语感里反而偏小，与释义"大的斑点"相抵。读者读到"黑点=大的、斑痕=小的"会觉得违反直觉，实为译名选择造成的误导。
  - 建议：`kāḷaka` 作"黑斑"，`tilaka` 作"斑点"或"痣"，使大小关系与词形直觉一致。

### 🟨 warning

- `181-346-34-106`｜整句逻辑表达不规范｜片段「据说那位长老说“朋友，不会有给你的机会”，他还是说」
  - 问题：这是全段最长的一句（73 词），原文是 `vuttepi … vatvā … vutte … vatvā …` 的多重嵌套引述，译文用"长老说…他就说…长老说…他就说…"铺开，读到第三轮时"他"指谁已需回读确认。且句首 `so kira thero`（据说那位长老）点出主语是长老，但整句真正的行为主体是来请教的弟子，译文的主语铺设与后续不接榫。
  - 建议：首句补明两方身份（如"据说那位长老对他说…"），后续交替处至少各点一次身份，不全用"他"。

- `181-346-34-106`｜关键词语意不明确｜片段「在寻思棚站立的时候」
  - 问题：`vitakkamāḷaka`（寻思棚/思惟场，僧众经行思惟处）属罕见术语，首次出现未夹注巴利原词，"寻思棚"三字对一般读者无法索解。同句的"歇坐堂（āsanasālā）"却夹注了，同一句内处理标准不一。
  - 建议：补作"寻思棚（vitakkamāḷaka）"。

- `181-346-209-227`｜关键词语意不明确｜片段「把三四个座位都坐热」
  - 问题：`tayo cattāro pallaṅke uṇhāpetvā` 字面即"使三四个结跏趺坐变热"，指连续多座不起、坐处生温，是形容用功不辍的成语式说法。直译"把三四个座位都坐热"会让读者误以为在换座位。且 `pallaṅka` 此处宜取"结跏趺坐（的坐次）"而非"座位"。
  - 建议：改为"接连坐上三四座、把坐处都坐暖"一类，或夹注说明这是形容久坐用功。

- `181-346-196-208`｜不导致误解的汉语语病｜片段「那您又怎么腾得出机会给死亡呢」
  - 问题：口语色彩过强（"腾得出""给死亡"），与全篇书面语体不统一；且原文 `maraṇassa … okāsaṃ labhissatha` 的意思是"你们哪里会从死亡那里得到（宽限的）机会"——即死亡不会给你机会，译文的施受方向反了，变成"你给死亡机会"。
  - 建议：改为"那您又怎么会从死亡那里得到机会呢"。

- `181-349-104-118`｜不该使用术语标记时使用了术语标记｜片段「所以叫做**出离断**」
  - 问题：与 `nissaraṇappahānaṃ` 对应的黑体无误，但同句"那就是涅槃"中的 `nibbānaṃ` 是同位语插入，译文用分号处理后语链断裂，读者易把"这出离本身就是断"读成承接"涅槃"而非承接"出离"。
  - 建议：调整为"…所以叫做出离，也就是涅槃；出离本身即是断…"。

- `181-349-92-103`｜标点符号使用错误｜片段「所以叫做止息，那就是果；这止息本身就是断」
  - 问题：同上，`phalaṃ`（果）作同位语，用逗号带出后紧跟分号，三个小句的层级被标点拉平。
  - 建议：同位语部分用破折号或"也就是"引出。

- `181-347-19-22`｜不导致误解的汉语语病｜片段「因为这种自恣只有阿罗汉才有」
  - 问题：`Arahantānameva hesā pavāraṇā` 的 `eva` 限定的是 `arahantānaṃ`，译文语序正确，但"才有"与句首"因为"搭配后读来像半截因果，缺少所因之果。
  - 建议：补足为"因为这种自恣是只有阿罗汉才作的"。

### 🟦 suggestion

- `181-349-8-26`｜复杂的嵌套句整句语言逻辑理解困难｜片段「凭着观的各个部分、也就是这样那样的智的成分，纯粹以对治的方式断除各个应断之法」
  - 问题：一句内套了三重限定（喻体—工具—方式），"这样那样的"连用两次（本句与下一句），读者不易把 `tena tena` 的"各别对应"义读出来。
  - 建议："这样那样"可改为"各别的"或"一一相应的"，并把灯喻拆为独立短句。

- `181-349-27-40`｜语言表达不够流畅｜片段「使欲贪等不至于缠住心而停留下来」
  - 问题：`pariyuṭṭhāya tiṭṭhanti` 的"缠住—停留"两个动作叠译后略绕。
  - 建议："使欲贪等不再缠缚住心"。

- `181-348-7-15`｜语言风格不统一｜片段「就是得到了方便（upāya）」
  - 问题：`upāya` 译"方便"是传统译法，但上半句 `laddhamaggaṃ` 已译"得到了方法"，同一句内"方法"与"方便"指同一事却用了两个词，读者会以为是两回事。
  - 建议：统一为"方法（upāya）"，或保留"方便"而在前句同步调整。

- `181-348-56-66`｜语言表达不够流畅｜片段「从来不曾对比自己年长的人所说的话，回以相违的第二句话」
  - 问题："对…所说的话，回以…"中间隔了长定语，"回以"本身也偏文。
  - 建议："对年长者说的话，从来不曾出言顶回第二句"。

- `181-346-184-195`｜语言风格不统一｜片段「针对这一点才说了下面这句话——」
  - 问题：`taṃ sandhāya etaṃ vuttaṃ` 是复注引出下文的固定套语，本段译作"针对这一点才说了下面这句话"，而 `181-346-2-10` 同类的 `ti vuttaṃ` 译作"所以说"，套语译法不统一。
  - 建议：全书统一一种引出式（如"针对这一点，才有下面这句话"）。

- `181-347-2-5`｜语言表达不够流畅｜片段「就是一直在精勤用功」
  - 问题：被解释词已译"一直这样努力着"，释义又作"一直在精勤用功"，两句的"一直"重复，而原文 `ghaṭentassa` / `vāyāmantassa` 的差别（致力／精进）未体现。
  - 建议：释义改为"就是正在精进用功"，把"一直"留给被解释词。
