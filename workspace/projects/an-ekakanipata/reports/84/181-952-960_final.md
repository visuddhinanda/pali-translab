## 理由

**基准缺失（影响信心）**：本次只注入了巴利原文与待评译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此
- 「义注定释义」一条无法执行：复注大量黑体引自义注（`tāyā`、`saddhammā`、`paramā`、`paricchedo`、`piṭṭhicakkavāḷe`、`paccatiyevā`、`mā khalī…evaṃladdhanāmo`），**被解释词是否与父层逐字同译完全无法核对**，这是本层最关键的一条硬约束，本报告只能从复注内部文义推断。
- 「nissaya 定词法」一条亦无法执行：格与句法角色的判定全部依靠原文形态自行分析，下面标为 error 的格/修饰关系问题置信度低于平时，建议配齐义注后复核。
- 信心指数因此压到 66；准确性分数按「可核的部分」给出，保留了两档不确定余量。

**准确性**：整体取义稳健，长句（`181-955-66-86`、`181-958-53-78`、`181-960-70-110`）的逻辑骨架、让步/因果关系都处理正确，`micchattaniyāma / sammattaniyāma` 的对举没有译反，`akusala` 弱 / `kusala` 强的论证链完整，跨段落的引文—主动词结构（`181-955-109-122` → `181-956` → `181-957-2-3` 的 `vuttaṃ`）接得上，没有断裂。扣分集中在三处：一处黑体被解释词被替换成了后文内容而非该词本身（`181-955-34-40`）；一处 locative absolute 的主语被挪给了别的事物（`181-959-21-29`）；一处 `patto …āvaraṇaṃ` 的主体关系在汉语里产生施受歧义（`181-958-79-105`）。未发现漏译、未发现违背基本教理的句子、未发现代词指代错误。

**风格**：主体是合格的现代书面汉语，口语节奏自然（"还有救"、"治不了"、"一个接一个地出家"），没有「此中/故为/彼等/是故」类文言腔，标点与引号全角、译文内无 ASCII 引号（JSON 安全达标），译文里也没有残留任何候选/待定标记。扣分来自三处「X之Y」文言属格（人之法、圣者之法、十善业道之法），以及两处汉语不顺（"逃了起来"、"抓住了他衣角"漏「的」）、一处用词偏口语（"正在烧的" 宜作 "正在燃烧的"）。

**一致性**：术语与重复句式的内部一致性好——`vaṭṭakhāṇu` 两处都作"轮转的木桩"，`bhavato vuṭṭhānaṃ natthi` 两处都作"没有办法从有当中出离"，三处 `Tenāha` 统一作"因此（义注）说"。扣分在体例层面：黑体标记在 `181-955-109-122` 与 `181-957-4-19` 两处丢失（其余段落均保留）；巴利夹注给得不匀——`micchattaniyāma`、`sammattaniyāma`、`Pāthikaputta`、`ariṭṭha` 加了，而同样属于法相术语或罕见译名的 `ānantariyakamma`、`lokantarikaniraya`、`samaṇa`（terms.md 明确要求首现夹注）没加。

**读者可读性的系统性风险**：`181-960` 整个故事的要点是外道教主之名由 `mā khali`（不要失足）得来，但译文通篇只作"不要失足"、"这个名字"，汉语读者看不到任何名字，也看不出谐音关系，故事的落点失效——这是本 chunk 最值得优先处理的一条（见 warning 第一条）。

## 问题清单

### 🟧 error

- `181-955-34-40`｜错误多译（被解释词未逐字对应）｜片段「具有这种邪见的人……」
  - 问题：原文被引的黑体只有一个词 `tāyā`（阴性具格/与格，"由于那个（见）"），`tiādi` 表示"以下等等"。译文没有译这个词，而是把义注后续的内容（上一句已出现过的"具有这种邪见的人"）填了进来，形成与被解释词不对应的替换式增译；复注黑体必须与义注同坐标文字逐字同译，此处做不到对齐。
  - 建议：按词本身译出并以省略号表示后续，如「“由于那种（见）……”等等」；配齐义注后以义注该处实际用词定稿。
- `181-959-21-29`｜错译（修饰/主语归属）｜片段「即使他所在的那一处没有在烧」
  - 问题：`cakkavāḷe jhāyamāne ajjhāyamānepi` 是一组独立处格，`jhāyamāne` 与 `ajjhāyamānepi` 同格同数，主语都是 `cakkavāḷa`（轮围世界燃烧时、以及不燃烧时）。译文把 `ajjhāyamānepi` 的主语改成"他所在的那一处"，凭空引入了原文没有的主体，并把两个并列情形改写成了对比关系。
  - 建议：改为「就是在轮围世界正在燃烧时、以至不燃烧时，他也由于自己业的力量，仍然在那里受着煎熬」。
- `181-958-79-105`｜导致误解的表达｜片段「他已经既障住了通往天界的路」
  - 问题：`patto saggamaggāvaraṇañceva mokkhamaggāvaraṇañca` 说的是此人**自己**得到了天道之障与解脱道之障（下文"连生到天界都不可能"正是就他自己而言）。汉语"他障住了通往天界的路"读起来是他去阻挡（他人的）道路，施受关系有被读反的风险。
  - 建议：补出归属，如「对他来说，通往天界的路和通往解脱的路都已经被堵死了」，或「他已经把自己通往天界和通往解脱的路都堵上了」。

### 🟨 warning

- `181-960-2-37`｜关键词语意不明确、二意场合没有注释｜片段「依据“不要失足”这句话而得到这个名字的」
  - 问题：全段故事的落点是外道教主之名（Makkhali）来自主人所说的 `mā khali`，但译文自始至终没有出现名字，也没有点出谐音，汉语读者读完不知道"这个名字"是什么名字、为何由此得来，整段叙事失去意义。`181-960-123-134` 的收尾句同样只作"得到这个名字的外道教主"。
  - 建议：首次出现处加夹注或段后小字注，说明"不要失足（mā khali）"与末伽梨（Makkhali）名字的谐音来源，使下文"这个名字"有所指。
- `181-955-51-65`｜关键词语意不明确｜片段「没有办法从有当中出离」
  - 问题：此处"有"是术语 `bhava`（三有、轮回之有），单字"有"在现代汉语里不成词义，读者极易读成"没有/有没有"的"有"。`181-958-79-105` 同一说法重复出现，同样不明确。
  - 建议：首现处夹注巴利原词并稍作展开，如「没有办法从有（bhava，轮回的存在）当中出离」，后文沿用。
- `181-958-53-78`｜关键词语意不明确｜片段「就像阿利吒（ariṭṭha）的刺一样」
  - 问题：音译"阿利吒"未加说明，读者无从知道这是带刺植物，且易与人名（比丘阿利吒）混淆，比喻落空；另夹注词形为 `ariṭṭha`，与原文 `ariṭṭhakaṇṭaka` 中的 `ariṭṭhaka` 不一致。
  - 建议：改为「就像阿利吒（ariṭṭhaka，一种带刺的树）的刺一样（扎进去就拔不出来）」。
- `181-954-11-18`｜整句逻辑表达不规范（修饰范围不明）｜片段「把已经圆满了波罗蜜的独觉菩萨以及一部分声闻菩萨」
  - 问题：`pūritapāramikā` 为复数主格，很可能同时修饰 `paccekabodhisattā` 与 `ekaccasāvakabodhisattā`。汉语按现有语序只能读成修饰"独觉菩萨"一项，修饰范围被收窄且无从判别。
  - 建议：若修饰两者，改为「把已经圆满了波罗蜜的独觉菩萨和一部分声闻菩萨」→「把波罗蜜已经圆满的独觉菩萨、以及一部分声闻菩萨」并在语序上使修饰语前置覆盖两项；配齐义注后确认归属。
- `181-953-18-37`｜文言语体｜片段「它也被称为人之法」
  - 问题：「人之法」为文言属格结构，违反 knowledge/style.md 第一节"之作文言虚词时须改写"的硬约束。
  - 建议：改为「它也被称为人的法」或直接作「人法（manussadhamma）」并夹注原词。
- `181-953-38-46`｜文言语体｜片段「不能使别人脱离圣者之法」
  - 问题：同上，「圣者之法」为文言属格。
  - 建议：改为「圣者的法」或「圣法（ariyadhamma）」。
- `181-953-49-55`｜文言语体｜片段「十善业道之法」
  - 问题：同上，引文内亦应为现代汉语。
  - 建议：改为「十善业道这种法」或「十善业道法」。
- `181-960-38-46`｜不导致误解的汉语语病｜片段「因为害怕主人就逃了起来」
  - 问题：「逃了起来」不是合法的现代汉语搭配（`palāyituṃ āraddho` 是"开始逃跑"）。
  - 建议：改为「因为害怕主人，就开始逃跑」。
- `181-960-47-51`｜不导致误解的汉语语病｜片段「抓住了他衣角」
  - 问题：缺结构助词，「他衣角」是文言式省略。
  - 建议：改为「抓住了他的衣角」。

  - 问题：`pathavigopaka` 直译后含义不透明（指长久留住此地、不得上升），读者难解。
  - 建议：保留直译并加简注说明其意为永久滞留于此、不得生天。
- `181-956-2-13`｜语言表达不够流畅｜片段「只是在这一生里是决定的」
  - 问题：「是决定的」承 `niyata`（决定、不可转的邪见决定）而来，但在汉语里语义空泛，读者不易接上前文"决定性邪见"。
  - 建议：作「只是在这一生里才是决定了的（niyata，不可转）」，或与 `181-958-53-78` 的"持决定性邪见的人"在用词上更贴近。
- `181-959-2-8`｜语言风格不统一｜片段「正在烧的轮围世界」
  - 问题：「烧」偏口语单音节，与全文书面语体略不协（本段及 `181-959-9-20`、`181-959-21-29` 共四处）。
  - 建议：统一作「正在燃烧的」。
- `181-955-66-86`｜复杂的嵌套句整句语言逻辑理解困难｜片段「从那里抬起头来」
  - 问题：`sīsukkhipana`（抬头=脱出）为比喻说法，直译后读者未必能读出"从那种见解里脱出"的意思；该句本身又是"不能说……绝不可能……"的双重否定长句。
  - 建议：补一点落点，如「而从那里抬起头来、脱出那种见解」。
- `181-953-16-17`｜语言风格不统一（补出成分的体例）｜片段「因此（义注）说」
  - 问题：圆括号在本项目体例里用于夹注巴利原词（见 style.md 第三节），此处用它补出省略主语，与夹注体例混用；同一写法在 `181-953-47-48`、`181-955-32-33` 共三处。
  - 建议：三处统一改为不带括号的「因此义注说」，把括号留给巴利夹注。
- `181-960-123-134`｜语言表达不够流畅｜片段「是依据‘不要失足’这句话」
  - 问题：被引的是义注里的一个名词性短语（`…evaṃladdhanāmo titthakaro`），译文冠一个"是"字后不成独立句，引文边界读起来别扭。
  - 建议：去掉句首"是"，作「“依据‘不要失足’这句话而得到这个名字的外道教主”」。
