## 理由

**基准可用性**：本次未注入 nissaya，也未注入更上层复注；待评段本身即义注层（book=99 Nidānavaṇṇanā），其中 132–142 是义注引述的《本生经》孔雀本生偈颂（jā.1.2.18），143 是义注自己的收束说明。因此词法基准缺位，判定只能依巴利原文形态与 Mora-jātaka 上下文，遇偈颂传统义读（cakkhumā / ekarājā / brāhmaṇā）无注释书可对，故信心打折。另：注入数据每行 `layer` 字段均为 `mula`，与任务头声明的"义注层"不一致——属元数据问题，不影响译文评估，但应在上游核对。

**准确性**：整体取义可靠。132 的 `atthaṅgataṃ sūriyamaṇḍalaṃ`（日已没）与 133 的 `apeta`（已离去）配合正确，说明译者认出这是晚课偈而非晨课偈（晨课作 `udetayaṃ`），这一处最容易错的地方没有错。143 的三重绝对分词链（`vītināmetvā` / `sutvā` / `asaritvā`）关系拆解正确，`parittakammato puretarameva`（在念护偈之前）、`raññā pesitassa luddakassa vasaṃ upagato`（落入国王所派猎人掌中）都无误。扣分主要在两处：135 把同一受礼敬对象拆成"你"与"…者"两个指称；143-22-28 未译出 `pariyādiyitvā tiṭṭhati` 的持续义，而这恰是义注此处要立的结论（女声之力"持续占据"其心），语义重量丢失。

**风格**：无文言腔，禁例表所列的文言虚词、文言句式、单音节文言词均未出现，符合 `knowledge/style.md` 第一节硬约束。标点为全角，译文内无 ASCII 引号，无候选/待定等工作标记。失分在两点：134"他金黄色"是名词性谓语缺系词的汉语语病；133/137 两次开引号只有 142 一次收引号，虽然忠实映射了巴利 `‘‘ … ‘‘ … ’’` 的偈颂引述体例，但在汉语里读成引号不配对。

**一致性**：术语内部自洽（礼敬 / 护卫偈 / 女声 / 金色孔雀贯通），但 139 用"觉悟"译 `bodhi`，与 `knowledge/style.md`"常见术语用传统汉译"的取向不合（应作"菩提"），与同偈"诸佛""解脱"都取传统译名的处理不齐。141→142 跨行主语由"它"变"孔雀"，两行合成一句时主语重出。专名给汉译的粒度也不齐：`Chātapabbata` 补了"山"，`Sudhāmuṇḍaka` 未补地名类别词。

## 问题清单

### 🟧 error

- `99-135-2-7`｜导致误解的表达｜片段「我礼敬你，礼敬这金黄色、照耀大地者」
  - 问题：`taṃ namassāmi harissavaṇṇaṃ pathavippabhāsaṃ` 中的两个形容词与 `taṃ` 同为对格、同指一个对象（太阳）。译文前半用第二人称"你"、后半改用第三人称"…者"，并重复"礼敬"，读起来像礼敬两个不同对象。
  - 建议：人称统一，合为一个受礼敬对象，如"因此我礼敬你——金色灿然、照耀大地的你"。

- `99-143-22-28`｜漏译｜片段「女声就夺尽了金色孔雀的心」
  - 问题：`pariyādiyitvā tiṭṭhati` 是"占尽之后持续如此"的惯用式，持续义是义注在此要下的结论；译文只作完成态，持续义未落地。`ti` 的引语收束也未体现（可不译，但语义层次应可辨）。
  - 建议：补出持续义，如"女人的声音就这样一直占据着金色孔雀的心"。

### 🟨 warning

- `99-134-2-4`｜不导致误解的汉语语病｜片段「他金黄色，照耀着大地」
  - 问题：形容词性成分"金黄色"直接充当谓语，缺系词，汉语不成句。
  - 建议：改为"他金色灿然，照耀大地"或"他身呈金色，照耀着大地"。

- `99-133-2-7`｜关键词语意不明确，二意场合没有注释｜片段「这位有眼的独一之王」
  - 问题：`cakkhumā`（有眼者）与 `ekarājā`（独一之王）都是偈颂对太阳的传统称谓，译文照字面直译，一般读者读不出指太阳；全段又无一处点明所礼敬者是日轮。
  - 建议：保留称谓，另加译注说明二者均指太阳；或首次出现处夹注巴利原词。

- `99-136-2-6`｜标点符号使用错误｜片段「度过这一夜。」
  - 问题：133 与 137 各开一个全角左引号，只有 142 一个右引号收束，汉语里引号不配对。巴利原文确为 `‘‘ … ‘‘ … ’’`，但汉译需自行配平。
  - 建议：在 136 句末补右引号，或 137 不再另开引号，全书统一一种偈颂引述办法。

- `99-137-2-8`｜关键词语意不明确｜片段「那些通达一切法的婆罗门」
  - 问题：此处 `brāhmaṇā` 依《本生经》义注指漏尽者（佛与阿罗汉），不是种姓婆罗门；直译无注会让读者理解为向婆罗门祈护。
  - 建议：加注说明"婆罗门"在此指漏尽者／诸佛。

### 🟦 suggestion

- `99-139-2-6`｜该使用而没有使用术语标记｜片段「礼敬觉悟」
  - 问题：`bodhi` 用"觉悟"，与同偈"诸佛""解脱者""解脱"都取传统译名不齐；"觉悟"在现代汉语更偏动词。
  - 建议：改作"礼敬菩提"，或"礼敬菩提（bodhi）"。

- `99-143-2-21`｜语言表达不够流畅｜片段「还没作护卫偈的念诵」
  - 问题："作……的念诵"是生硬的动名词堆叠，同句内又与「忘了作护卫偈的念诵」重复一次。
  - 建议：前句作"还没念护卫偈"，后句作"忘了念护卫偈"。

- `99-142-2-17`｜语言风格不统一｜片段「孔雀就安排了住处」
  - 问题：141 主语已作"它"，142 又出"孔雀"，两行连读主语重出；`vāsaṃ akappayī` 意为安顿下来歇宿，"安排了住处"偏事务性。
  - 建议：142 作"就这样安顿下来过夜"，主语承前省略。

- `99-143-29-39`｜语言风格不统一｜片段「苏陀蒙荼迦（Sudhāmuṇḍaka）」
  - 问题：同句 `Chātapabbata` 译为"查多山"补出了地名类别词，此处未补，读者不知是山、寺还是村。
  - 建议：查明所指后统一，如"苏陀蒙荼迦（Sudhāmuṇḍaka）寺"。

- `99-132-2-15`｜语言表达不够流畅｜片段「也念诵这首偈颂」
  - 问题：`oloketvāpi` 的 `pi` 附在"望"这一动作上（望见日落时同样也……），译文把"也"移到了主句谓语。
  - 建议：调整为"望见西沉的太阳时，同样念诵这首偈颂"。

- `99-132-2-15`｜语言表达不够流畅｜片段「西沉的日轮」
  - 问题："日轮"虽为佛典常用译名，但在纯叙事句中略显文雅，与整段现代白话的基调有落差。
  - 建议：叙事处可作"落下去的太阳"，偈颂中保留"日轮"。
