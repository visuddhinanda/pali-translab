**基准缺失（影响信心）**：本次只注入了巴利原文与待评译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此下列判断只能靠巴利词法/句法与段内互证（193–195 三段彼此定义同一组术语，内部一致性本身就是强证据），无法核对两条硬约束：一是 `193-64-72`「经的缘起方式有四种」、`195-73-79`「只是出于自己的心意而讲说」等**黑体引语是否与义注译文逐字相同**；二是 `195-80-124` 一串 `X ti Y` 词释的被解释词（vimuttiparipācanīyā dhammā / ajjhāsaya / khanti / mana / abhinīhāra / bujjhanabhāva / rūpagaruka）**在义注里的既有译法**。信心指数据此压到 66，问题清单中凡依赖父层的条目已逐条标注「需核对义注」。

**准确性**：整体是一份合格的复注（ṭīkā）译文。难点处理得当——`194-55-65` 的语音替换说明（ttha→ṭṭha）、`193-73-136` 四组交叉组合的枚举、`195-46-57` 把 vaṇṇāvaṇṇa 与 āmisuppāda 分别系于《梵网经》《法嗣经》，都译对了；`193-137-143` 的 tadantogadhattā、`195-37-45` 的 vinimutta…aṭṭhuppattibhāvena gahitattā 这类抽象论证也没有走形。扣分集中在两处实质误读：`194-97-107` 把 `dhammappaṭiggāhakānaṃ` 系到「说出的话」而非系到「提问」，使 pucchāvasika 变成**提问者自己的话**，与本段紧接着的「配合 nikkhepa 一词改用阳性」这一论点脱节，也与 `195-58-72`「因提问而讲说的，就是由于提问」自相矛盾；`195-88-91` 把 khanti 译作「忍耐力」，而同句释义是 diṭṭhinijjhānakkhanti（见审察忍），词义落在**智性上的信受/忍可**，与「忍耐」不是一个义项，黑体词与自己的释义打架。另有 `193-20-49` 的 nidāna 取「序分」（文本部分）而非「因由」：在 desanāsamuṭṭhāna 的语境里两读都有依据，未扣准确性分，仅列 suggestion 提示加注。

**风格**：语体检查通过——通读三段未见文言虚词（之/其/乃/便/即/遂/於）、未见文言句式（…者…也／于…之际／答以…）、未见「此中／彼等／故为／是故」类禁例，`195-34-36`「这样的责难是不应当提出的」、`194-2-12`「关于这一点，词义是这样的」都是干净的现代书面汉语，这是本段的明显优点。译文中无任何候选/待定/问号等工作标记残留。扣分在三点：一是**术语夹注不成体系**，`193-2-5`（nikkhittassa）、`195-100-106`（bujjhanabhāva）附了巴利原词，而同为法相术语的 khanti / mana / abhinīhāra / ajjhāsaya 一概没附；二是罗马字 nikkhepa / suttanikkhepa / pucchāvasikaṃ 直接进正文且不加汉译对应，一般读者读不下去；三是「讲说经的原因的产生」「由于出于自己的心意不依赖他人根的成熟等原因」这类多重「的」「由于…原因」套叠，属不致误解的汉语语病。标点符合全角规范，未见 ASCII 引号，未见「」，JSON 安全无风险。

**一致性**：同一个 nikkhepa 在 `193-6-19`、`194-2-12` 夹注为（安置），到 `194-97-107` 变成（缘起方式）；suttanikkhepa 时而译出、时而保留罗马字，同一句里两种形态并存（「所以叫做 suttanikkhepa——**经的缘起方式**」）。这是本次三项分数里最低的一项：术语骨架本身（attajjhāsaya=出于自己的心意 / parajjhāsaya=出于他人的心意 / pucchāvasika=由于提问 / aṭṭhuppatti=事件的发生）在 193–195 三段间是稳定的，问题只出在元语言层（nikkhepa 的夹注与形态）。

## 问题清单

### 🟧 error
- `181-194-97-107`｜错译（修饰关系）｜片段「领受法的人们因提问而说出的话就是 pucchāvasikaṃ（提问性的）」
  - 问题：`dhammappaṭiggāhakānaṃ`（属格）被系到 `vacanaṃ`（话），于是 pucchāvasika 成了「领受法者自己说的话」。但本句下文说「这同一个词为了配合 nikkhepa 一词改用阳性」，被指称的对象必须是可充当 suttanikkhepa 的**那场讲说**；`195-58-72` 也明说「因提问而讲说的，就是由于提问」。属格应系于复合词内的 `pucchā`：由领受法者的提问推动而说出的话。
  - 建议：改为「因领受法的人们提问而说出的话」一类处理，使 pucchāvasika 的指称与 195 段的定义一致。需核对义注/nissaya 的格助词后定稿。
- `181-195-88-91`｜错译（词义）｜片段「忍耐力」
  - 问题：黑体词 khanti 译作「忍耐力」，但紧随的释义是 diṭṭhinijjhānakkhanti，指对见解审察之后的**接受、信受**（智性的 khanti），不是忍受苦恼的耐力。同句「就是对见解加以审察后的忍可（diṭṭhinijjhānakkhanti）」已用「忍可」，与黑体词自相矛盾。
  - 建议：黑体词改为「忍可」（或「（对法的）接受力」），与释义用同一个词；确认义注该处的既有译法后统一。

### 🟨 warning
- `181-194-2-12`｜关键词语意不明确｜片段「经本身就是这个 nikkhepa，所以叫做 suttanikkhepa」
  - 问题：本段是 vacanattha（词义分析），nikkhepa 的立足点是「安置」；而黑体词却译作「经的缘起方式」。读者看到「安置→缘起方式」无从衔接，词源论证落空。
  - 建议：首次出现处加一句译者注，说明 suttanikkhepa 字面为「经的安置」、义为经之说起因由；或黑体词保留「经的安置（缘起方式）」双给。
- `181-194-97-107`｜关键词语意不明确｜片段「为了配合 nikkhepa（缘起方式）一词」
  - 问题：同一个 nikkhepa，`193-6-19` 夹注为（安置），此处夹注为（缘起方式），同一术语两副面孔。
  - 建议：全段统一 nikkhepa 的汉译与夹注，只在首次出现处夹注一次。
- `181-193-50-63`｜关键词语意不明确、二意场合没有注释｜片段「按染污分等安立（paṭṭhāna）的方式而分成的十六类」
  - 问题：paṭṭhāna 译「安立」且无注，读者极易与《发趣论》（Paṭṭhāna）混淆；此处实指《导论》(Nettippakaraṇa) 的 sāsanapaṭṭhāna（教说安立）以 saṃkilesabhāgiya 等分出的十六种。
  - 建议：加脚注点出出处与「十六类」所指，或译为「教说安立（sāsanapaṭṭhāna）」。
- `181-195-114-124`｜错误多译｜片段「指的就是那些看重色的人（的心意）」
  - 问题：原文 `tesaṃ rūpagarukānaṃ` 只是把黑体词的属格复数还原，并未出现「心意」。括注补出的成分不在巴利里，也未标明是译者补充。
  - 建议：删去「（的心意）」，或核对父层义注确认该属格所系的中心词后，以脚注形式补出。**需核对义注**。
- `181-195-2-14`｜不导致误解的汉语语病｜片段「由于出于自己的心意不依赖他人根的成熟等原因」
  - 问题：「由于…原因」外框里又套「出于…心意」，两层「由于/出于」叠加，主语归属一读之下不清楚。
  - 建议：拆为「出于自己的心意这一种，并不依赖他人根成熟等外缘」再接下文的「所以…是恰当的」。
- `181-195-37-45`｜不导致误解的汉语语病｜片段「讲说经的原因的产生才被取作事件的发生」
  - 问题：连用两个「的」构成三重定语，读起来滞涩。
  - 建议：改为「讲说经的因由如何生起，才被算作事件的发生」一类说法。

### 🟦 suggestion
- `181-193-20-49`｜不常用术语编写注释或者百科｜片段「就能正确地了解这部经的序分」
  - 问题：nidāna 取「序分」（义注的因缘分）一读，在 desanāsamuṭṭhāna 的语境里也可读作「因由、来由」。两读都有依据，但译文未作交代，读者会以为只在说文本分段。
  - 建议：保留现译并加注说明 nidāna 兼指「说经的因由」；或改用「因由」。**需核对义注**。
- `181-195-92-95`｜该使用而没有使用术语标记｜片段「就是以假名所说的心（paññatticitta）」
  - 问题：黑体词 mana 译作「心思」，偏口语，且与同组的「心意（ajjhāsaya）」易混；释义侧夹注了 paññatticitta，黑体词侧反而没夹注巴利原词。
  - 建议：黑体词改「意（mana）」，与 indriya / ajjhāsaya / khanti / abhinīhāra 一组法相术语统一夹注体例。**需核对义注**。
- `181-195-84-87`｜该使用而没有使用术语标记｜片段「就是倾向」
  - 问题：ajjhāsaya / adhimutti 两个术语在此句分别落到「心意」「倾向」，都是首次出现却均无巴利夹注，与 `193-2-5`「（nikkhittassa）」、`195-100-106`「（bujjhanabhāva）」的做法不一致。
  - 建议：按 `knowledge/style.md` 第三节，法相术语首次出现一律圆括号附巴利原词，全段体例统一。
- `181-193-73-136`｜复杂的嵌套句整句语言逻辑理解困难｜片段「但是当出于自己的心意等几种摆在前面时，由于事件的发生就与它们没有结合」
  - 问题：「摆在前面」直译 `purato ṭhitehi`，读者不知道是摆在哪里的前面（实指复合词/列举次序在前）。
  - 建议：明说「当出于自己的心意等几种列在前面时」，或加注说明这是就列举次序而言。
- `181-193-73-136`｜标点符号使用错误｜片段「即“既出于自己的心意又出于他人的心意”“既出于自己的心意又由于提问”」
  - 问题：四个引号短语连排无分隔，四项的边界靠引号硬分，读起来密不透风。
  - 建议：项间加顿号，或改用分项列举。
- `181-195-107-113`｜语言表达不够流畅｜片段「就是在五种所缘当中看重色所缘的人，也就是看重色的人」
  - 问题：末句「也就是看重色的人」等于把黑体词原样重说一遍，汉语里成了同义反复（巴利是「rūpārammaṇagarukā = rūpagarukā」的词形还原，汉译无此必要）。
  - 建议：删去末句，或改为「简称为看重色的人」。
- `181-195-114-124`｜语言表达不够流畅｜片段「向着色低垂」
  - 问题：ninna / poṇa / pabbhāra 三词同义叠用，汉译取「倾斜／倾侧／低垂」，其中「低垂」与「倾向于色」的语义关系较远。
  - 建议：三词可作「倾向色、趣向色、偏注于色」一类处理，保留叠用的修辞而不引入「低垂」这一形象。
- `181-194-13-24`｜语言风格不统一｜片段「经的 nikkhepa 就是 suttanikkhepa——**经的缘起方式**」
  - 问题：同一句内罗马字与汉译并行，三段中 suttanikkhepa 时而罗马字、时而汉译；破折号在 193–195 中被高频用作释义连接符（十余处），节奏单调。
  - 建议：确定一种策略（正文只用汉译、罗马字只进夹注），破折号部分改为「，意思是…」「，即…」以分散句式。
