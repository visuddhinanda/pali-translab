## 跨段一致性

1. **āpatti：「犯」与「罪」两套译名混用（必改）**
   - §146/§147/§149/§150 译「犯 / 无犯」（「把无犯说成是犯」），§145/§152 品名译「无犯品」；
   - §148/§151 同一词在复合词中译「罪」（轻罪 / 重罪 / 粗恶罪 / 非粗恶罪 / 有余罪 / 无余罪 / 可忏悔的罪）。
   - **义注**：`pañcāpattikkhandhā **lahukāpatti** nāma , dve āpattikkhandhā **garukāpatti** nāma`——义注是用 *āpattikkhandha*（罪聚）来定义这十个被解释词的，十词同属一个 *āpatti* 系列，译名必须同源。
   - **建议**：统一为「罪」。即 §146「把无罪说成是有罪」、§147「把有罪说成是无罪」、§149「把无罪说成是无罪」、§150「把有罪说成是有罪」，品名（§145、§152）改「无罪品」。
     备选（改动面更小但读感差）：统一为「犯」，§148/§151 改「轻犯 / 重犯 / 粗恶犯 / 非粗恶犯 / 有余犯 / 无余犯 / 可补救的犯 / 不可补救的犯」。**二选一，不能并存。**

2. **pasavati：「制造」与「积集」不对称（必改）**
   - §146/§147/§148「apuññaṃ pasavanti」→「制造了许多恶业」；§149/§150/§151「puññaṃ pasavanti」→「积集了许多功德」。
   - 同一动词的正反两版必须用同一个中文动词，否则对举结构消失。**建议**统一为「招来／招致」：「招来许多非福」／「招来许多福德」；或统一「生起」。

3. **apuñña / puñña：「恶业」对「功德」不对称（建议改）**
   - 原文只有 puñña / apuñña，没有 kamma。「恶业」是增译，且与「功德」不构成一对。**建议**「非福 / 福德」或「罪过 / 功德」，二者取一并全 chunk 贯彻（§146-34-50、§147-33-49、§148-92-109、§149-34-50、§150-34-50、§151-77-93）。

4. **anattha / attha 的正反对应错位（建议改）**
   - 负面版 `anatthāya ahitāya dukkhāya` 译「损害、不利和痛苦」；正面版 `atthāya hitāya sukhāya` 译「福祉、利益和安乐」。
   - attha ↔ anattha 应是同一组词的正反（利益／无益），hita ↔ ahita 是另一组（有益／不利）。现在 attha 译「福祉」、anattha 译「损害」，读者看不出这是同一词的否定。
   - **建议**：`anatthāya ahitāya dukkhāya`→「无益、不利和痛苦」；`atthāya hitāya sukhāya`→「利益、有益和安乐」（或「利益、福利、安乐」配「无益、损害、痛苦」，总之三对逐一对应）。

5. **antaradhāpenti / ṭhapenti 不对称（建议改）**
   - 「使这正法消失」／「使这正法住立」。「住立」是文言词（见 `style.md` 禁例的单音节文言词精神），且与「消失」不成对。**建议**「使这正法消失」／「使这正法长存」，或「让这正法隐没」／「让这正法存续」。

6. **省略标记不统一（可保留，需确认）**
   - §148 原文用 `…pe…`，译「……乃至……」；§151 原文只有 `…`，译「……」。原文本身有别，此处理可接受；若统一体例，建议两处都只用「……」，或都补「乃至」。

## §84-146-2-33

- **问题**：结构增译 — `bahuno janassa anatthāya ahitāya dukkhāya devamanussānaṃ` 被译成两个并列分句：「是为了众人的损害、不利和痛苦，为了天神和人类的损害、不利和痛苦」。原文只有一组 anattha/ahita/dukkha，`devamanussānaṃ` 是对 `bahuno janassa` 的补充说明（众多人，即天与人），译文把三个名词整组重复了一遍。
- **建议**：「给众多的人——天神和人类——带来无益、不利和痛苦」，或「为了众多天神与人的无益、不利和痛苦」。§147-2-32、§148-6-91、§149-2-33、§150-2-33、§151-6-76 **同一句式全部照改**。

- **问题**：风格（文言残留）— 「是在为许多人的不利、为许多人的不安乐而行道」。「而行道」对没有佛学背景的读者是半文言，`style.md` 判定标准下不合格。
- **建议**：`paṭipanna` 改说人的作为：「这些比丘的所作所为，是在损害许多人、让许多人不得安乐」。正面版同理：「是在利益许多人、让许多人安乐」。

## §84-148-6-91

- **问题**：术语一致性（必改）— 「轻罪 / 重罪 / 粗恶罪 / 非粗恶罪 / 有余罪 / 无余罪 / 可忏悔的罪 / 不可忏悔的罪」中的「罪」与 §146/§147 的「犯」是同一个 āpatti。见跨段一致性第 1 条。
- **建议**：按统一方案改写；本句八对术语的译名将来要与义注 99-366 的黑体逐字对应，改定后登记进 `knowledge/term-glossary.jsonl`。

- **问题**：术语取义（待确认，非必改）— `sappaṭikamma` 译「可忏悔的罪」。**义注**：`**Sappaṭikammāpatti** nāma sāvasesāpattiyeva , **appaṭikammāpatti** nāma anavasesāpattiyeva`——义注把它等同于「有余罪」（六罪聚），即可经作法补救者；paṭikamma 本义是「补救、对治作法」，不限于口头忏悔。
- **建议**：保留「可忏悔」尚属可接受的传统译法，但更贴义注的是「可补救的罪／不可补救的罪」。若保留「可忏悔」，建议在首次出现处加脚注引义注：「义注：可忏悔罪即有余罪，不可忏悔罪即无余罪（波罗夷）」。

- **问题**：读者可及性（建议）— 「有余罪 / 无余罪」对一般读者不透明。**义注**：`Cha āpattikkhandhā **sāvasesāpatti** nāma , eko pārājikāpattikkhandho **anavasesāpatti** nāma`（六罪聚为有余罪，唯波罗夷一聚为无余罪）；`pañcāpattikkhandhā **lahukāpatti** nāma , dve āpattikkhandhā **garukāpatti** nāma`。
- **建议**：首次出现时夹注巴利原词（`style.md` 第三节），义注释义放脚注，正文不展开。
