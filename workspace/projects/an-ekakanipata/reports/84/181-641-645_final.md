## 理由

**基准可用性（影响信心）**：本次只注入了巴利原文与待评译文，**没有义注（本层的父层，即《经集义注》/《增支部义注》相关段）与 nissaya**。因此「被解释词与父层逐字同译」这条硬约束**无法核验**——全部黑体 lemma（如 `181-642-2-24` 的「被称为古提甘那」、`181-644-89-97` 的「天上的夜晚已经来临」、`181-645-12-23` 的偈句）只能就本层自洽性判断，不能确认与父层黑体引文字面一致。词级格/句法也只能靠原文自行判读，没有 nissaya 的格助词兜底。信心指数因此压在 68，**不宜据此报告直接结案**；补齐父层与 nissaya 后应重评。

**准确性**：整体读来是有依据的译文，难句（`181-643-2-41` 三十二先兆的 yasmā…tasmā 长句、`181-644-68-86` 多重具格堆叠的装饰句）结构梳理正确，出处标注（《相应部》5.1081、《无碍解道》2.30、《大义释》84/192、《小义释·彼岸道赞颂偈释》97、《经集义注》1.153）转写无误。扣分集中在三处：`181-643-79-86` 把 lemma 的 `tassa`（属格，指 dhammacakka）译成「他」，与紧随其后的自注「指的是世尊已经转起那法轮」自相矛盾，是本轮最实质的错误；`181-642-25-28` 给 `kulagharikā` 添出原文没有的「优婆夷」身份；`181-645-2-11` 漏译 `-padesena**pi**` 的「也」，丢掉了「不仅说佛出世、也借赞夜德」这层递进。另有 `181-643-58-78` 把 `kena kāraṇena … jānāsi` 的「凭什么知道」与「因什么开花」两种读法压成同一句，使 ṭīkā 的两层释义读起来重复。

**存疑但不扣分**：`181-644-54-62` 原文末字作 `dibbāni`（中性复数），译文按后句 `dibbā ratti` 补出「这一夜叫做天上的」，把末词理解为修饰「夜」。VRI 此处字形可疑，译者的处理有下文支撑，属合理取舍，仅在此备案。

**风格**：主体是现代书面汉语，但有文言残留：`181-642-67-107` 的「便想」（`便`＝于是，属 `style.md` 第一节明令禁例）、`181-645-2-11` 的「夜晚之美」、`181-645-123-127` 的「决意之意」（`之` 连用且语义叠沓）。另有 `181-643-87-94`「留意起那声音的特征」搭配不自然。标点与引号全部为全角，`zh` 字段内无 ASCII 引号，符合 JSON 安全约束；译文内无残留工作标记。

**一致性**：同一 lemma `kulagharikā` 在同段出现「女子」与「优婆夷」两种落法；人名音译体例不齐（`输那·古提甘那` 带间隔号，`沙多祇利`/`醯摩瓦多` 不带）；`输那·古提甘那` 与 `181-642-2-24` 给出的正形「亿耳」之间没有任何桥接，读者接不上。术语层面 `世尊 / 比丘 / 阿罗汉 / 正等正觉者 / 涅槃` 均与 `term-glossary.jsonl` 一致。

## 问题清单

### 🟧 error

- `181-643-79-86`｜代词指代错误｜片段「他已经转起法轮这件事」
  - 问题：lemma `Tassa pavattitabhāvaṃ` 的 `tassa` 是属格，指前文的 `dhammacakka`（法轮），译文却当成人称「他」（读者会理解为世尊）。同句自注已写「指的是世尊已经转起**那法轮**这件事」，译文与自己的释义相悖。
  - 建议：改作「**那法轮已经转起这件事**，指的是世尊已经转起那法轮这件事。」

- `181-642-25-28`｜错误多译｜片段「住在本家的优婆夷」
  - 问题：`kulagharikā` 只是「在良家之中者」的阴性派生词，原文没有「优婆夷（upāsikā）」这一身份；同句前半又把同一构词译作「女子」，一词两译。
  - 建议：统一为「在良家（kulaghara）中的女子，就是**良家女**」，身份信息留给下一句的叙述（`181-642-29-36`）自然带出。

- `181-645-2-11`｜漏译｜片段「就这样以称赞夜晚之美的方式」
  - 问题：`rattiguṇavaṇṇanāpadesena**pi**` 的 `pi` 未译，丢掉「除讲说佛陀出世之外，**也**借称赞夜德」的递进语气。
  - 建议：「他就这样，**也**借着称赞夜色美好的方式，使朋友心生净信……」

### 🟨 warning

- `181-643-58-78`｜关键词语意不明确，二意场合没有注释｜片段「你知道是因为什么开花的吗」
  - 问题：`kena … jānāsi` 可读作「你**凭什么**知道（雪山开了花）」，也可读作「你知道它**因何**开花吗」。ṭīkā 先出 `kena kāraṇena … jānāsi`、再出 `yena kāraṇena … jātaṃ, taṃ jānāsi` 两层，译文把两层译成几乎相同的中文，第一层的字面结构消失，注释自身的推进看不出来。
  - 建议：第一层贴字面「**你是凭什么原因知道雪山开了花的呢**」，第二层保留现译，两层差异即自明。

- `181-642-49-64`｜代词指代不明确｜片段「他带着随从走到世尊面前」
  - 问题：紧前一句的主语是那位良家女（她），此处突然转为「他」（实指沙多祇利，要到 `181-642-67-107` 才由「想起了醯摩瓦多」透露），读者会误以为仍在说她。
  - 建议：首次出现处点名，「**沙多祇利**带着随从走到世尊面前」。

- `181-643-95-119`｜代词指代不明确｜片段「要让他（就是你）也知道这不死之法」
  - 问题：`taṃ` 是 `tvaṃ` 的宾格（你），译文先写「他」再用括注纠正为「就是你」，绕了一圈且容易被读成第三方。
  - 建议：直接译「要让**你**也知道这不死之法」。

- `181-642-67-107`｜文言语体｜片段「便想」
  - 问题：`便`（＝于是）属 `style.md` 第一节明令禁用的文言虚词。
  - 建议：改「**于是想**」或「**心里又想**」。

- `181-645-2-11`｜文言语体｜片段「以称赞夜晚之美的方式」
  - 问题：「夜晚之美」用文言属格 `之`，与同章其他句子的白话语体不一致。
  - 建议：「称赞夜色美好」。

- `181-645-123-127`｜文言语体｜片段「表示决意之意的语助词」
  - 问题：`之` 作文言虚词，且「决意之意」语义叠沓。
  - 建议：「**来吧**是表示决心的语助词。」

- `181-643-87-94`｜不导致误解的汉语语病｜片段「留意起那声音的特征」
  - 问题：「留意起」搭配不成立；且 `nimittaṃ gaṇhāti` 是「取相」这一固定说法，用「留意」把动作弱化了。
  - 建议：「**取了那声音的相**，就是辨察了那声音的样态。」

- `181-645-71-91`｜关键词语意不明确，二意场合没有注释｜片段「摧破了贪所以是世尊」
  - 问题：这是 `bhagga`（摧破）与 `bhagavā` 的语源双关，译成「世尊」后中文里看不出「摧破」与「世尊」有何关系，读者会觉得推理断裂。
  - 建议：首处加夹注，「摧破（bhagga）了贪，所以是世尊（bhagavā）」，或加一句脚注说明该语源解释。

### 🟦 suggestion

- `181-641-2-2`｜语言风格不统一｜片段「输那·古提甘那长老的故事」
  - 问题：标题纯音译，而 `181-642-2-24` 的注释说此名正形应为 `koṭikaṇṇa`（亿耳）；两处之间没有桥接，读者无法把「古提甘那」与「亿耳」对上。另人名体例不齐——此处用间隔号，「沙多祇利」「醯摩瓦多」不用。
  - 建议：标题作「输那·古提甘那（Soṇakuṭikaṇṇa，即亿耳）长老的故事」，并统一人名是否使用间隔号。

- `181-642-37-48`｜不常用术语编写注释｜片段「十力者」
  - 问题：`Dasabala` 首次出现无注，一般读者不知其为佛的异名。
  - 建议：「**十力者（Dasabala，即佛陀）**」。

- `181-643-2-41`｜不常用术语编写注释｜片段「结生」
  - 问题：`paṭisandhi` 译「结生」属论藏术语，此处与「出生、出家、成道、般涅槃」并列，一般读者难解。
  - 建议：首次出现夹注「结生（paṭisandhi，指投生入胎）」。

- `181-643-52-57`｜语言风格不统一｜片段「先头部队」
  - 问题：「部队」是现代军事词，与全篇佛典语体不谐。
  - 建议：「**前锋军众**指的是走在最前面的那些军众。」

- `181-644-68-86`｜不常用术语编写注释｜片段「彻底清净的天（visuddhideva，指世尊）」
  - 问题：原文作 `parivisuddhideva`，夹注漏了 `pari-`，与原词不符。
  - 建议：夹注改为 `parivisuddhideva`。

- `181-644-54-62`｜语言表达不够流畅｜片段「天上的东西」
  - 问题：「东西」过于口语，且所指是下文明确的「种种色（rūpāni）」。
  - 建议：「天上的事物」或「属于天界的种种事物」。
