# Review — 181:930-934（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未注入，词级格位无独立基准，词法判断仅凭原文与父层译文推定）／父层（义注 book 99:1416-1424）原文 + 定稿译文 ✅
> 本层为复注（ṭīkā），黑体被解释词引自父层义注，故以「与父层定稿译文逐字相同」为第一检查项。

## 被解释词与父层对照（第一检查项）

逐条核对 36 处黑体，其中 **30 处与父层定稿逐字相同**（自性单一的法 / 彻底地 / 对轮回 / 厌离 / 离染 / 褪去 / 消失 / 为了使贪等烦恼灭尽 / 或者为了使轮回本身止息 / 止息，是指为了使烦恼寂止 / 依无常等…从而证知 / 为了觉悟四谛 / 称为觉 / 非缘生的涅槃 / 毒刺 / 粗糖 / 糖浆 / 糖块 / 砂糖 / 随念 / 有两种 / 为了使心喜悦 / 为了修观 / 心 / 受到损害 / 生起厌倦 / 变得没有兴味 / 变得清净 / 摆脱了盖障 / 调伏了 / 怎么说呢 / 并不是别的什么 / 见到 / 这一切 / 这是色，前面的是无色 / 安止一段）。不一致的 3 处列在下面必改项。

## 跨段一致性

- `accanta-` / `ekanta-`：§931 句 `181-931-29-35` 把 **ekantena** 译「彻底地」（与父层一致），但同段 `181-931-68-74` 又把 **accantaṃ** 也译成「彻底地」；父层 §1422 定稿中 `accantūpasamo` 作「毕竟止息」。两个不同的巴利词在同一 chunk 内撞成同一个汉词 → 建议 `accantaṃ appavattikaraṇaṃ` 改为「毕竟地使它不再生起」或「永远地使它不再生起」，把「彻底」留给 ekantena。
- 引号体例：全 chunk 统一用全角 “”，**仅** `181-931-2-21` 出现直角引号「法」「自性」 → 必改（见下）。
- 「盖障（nīvaraṇa）」在 `181-933-69-74`、`181-933-75-80` 两处一致 ✅；「业处」「随念」「心所依处」「集谛/灭谛/道谛」与父层一致 ✅。
- 称 X 为 Y 的套语：父层 adhivacana 一律作「…的名称／称呼」，本层 `181-932-6-9` samaññā 作「别称」——巴利词不同，可保留，但若求整书一致可统一为「名称」。
- 罕见法相术语的夹注体例不统一：本 chunk 新出现「近行定」「心的荒秽」「不死界」「因相」四个术语均无巴利夹注，而父层对同类词（appaccaya、nīvaraṇa、ariyabhūmi、kathetukamyatā-pucchā）都夹注了原词 → 建议统一补注（见建议项）。

## §931 句 181-931-2-21

- **问题**：标点（必改）— 译文用了直角引号：「法」「自性」。`style.md` 第五节明令「不要用直角引号「」『」，统一为弯引号 “” ‘’」。
- **建议**：改为 ——「296. 在《一法篇释》中，这里的“法”这个词是“自性”的意思，就像在“善的诸法”等等地方那样，所以说——」。
- **问题**：翻译腔（建议）—「善的诸法」是 `kusalā dhammā` 的逐字排列。
- **建议**：用通行汉译「善法」或「诸善法」：「就像在“善法”等等地方那样」。

## §931 句 181-931-29-35

- **问题**：取义偏移 —「ekaṃsena」译作「无条件地」。该词义为「一向、决定、无疑」，「无条件」是现代条件逻辑概念，原文没有这层意思；下半句「avassan ti attho」已经说「意思是必定如此」，两句因此重复。
- **建议**：「**彻底地**，就是一向地、决定地，意思是必定如此。」

## §931 句 181-931-75-81

- **问题**：引文回指（建议）— 黑体引父层的 `appavattikaraṇatthāya`，父层定稿作「不再生起」（「是指为了使贪等烦恼灭尽、不再生起」），本层扩成「为了使它不再生起」，多出的「它」在父层无对应，且父层主语是复数的「贪等烦恼」。
- **建议**：「**“为了使〔贪等烦恼〕不再生起”**」，或直接「**“不再生起”**」。

## §931 句 181-931-106-125

- **问题**：指涉不明（建议）—「另外那两种轮回」未点出是哪两种。三轮（烦恼轮、业轮、果报轮）在本 chunk 首次出现，读者无法补。
- **建议**：「因为烦恼灭尽了，另外那两种轮回（业轮与果报轮）也就随之灭尽」。

## §931 句 181-931-144-151

- **问题**：句式别扭（建议）—「因为没有脱离四谛之外还应当了知的东西」，「脱离…之外」语义叠加。
- **建议**：「因为在四圣谛之外没有别的应当了知的东西。」

## §931 句 181-931-182-185

- **问题**：术语夹注（建议）—「不死界」（amatadhātu）首次出现，属罕见术语，按 `style.md` 第二节应首次夹注巴利原词。
- **建议**：「**非缘生的涅槃**，就是不死界（amatadhātu）。」

## §932 句 181-932-2-5

- **问题**：被解释词与父层不一致（必改）— 父层 `99-1418-13-19` 定稿为「为了使**众人**生起热忱」，本层黑体作「为了使**人**生起热忱」。黑体少一字，读者定位被解释词时就对不上。
- **建议**：「**为了使众人生起热忱**，就是为了使人对业处产生爱乐。」（下半句的「使人」是本层自己的释义，不受约束，可保留，也可改作「使他们」。）

## §932 句 181-932-6-9

- **问题**：措辞与父层不齐（建议）— 父层 `99-1418-20-24`「说的就是卖糖的商人」，本层作「卖糖商人」，少一个「的」。非黑体部分，不构成硬约束，但同一个称呼在三层间最好一字不差。
- **建议**：「**毒刺**，是卖糖的商人的别称。」

## §933 句 181-933-33-39

- **问题**：术语夹注（建议）—「近行定」（upacārasamādhi）本 chunk 首次出现，无夹注。
- **建议**：「因为心由近行定（upacārasamādhi）而得定以后，修观就能顺利地成就。」

## §933 句 181-933-69-74

- **问题**：术语夹注（建议）—「心的荒秽」（cetokhila）是罕见法相术语，无夹注读者难解。
- **建议**：「由于没有了疑惑等心的荒秽（cetokhila），就**摆脱了盖障**。」

## §933 句 181-933-75-80

- **问题**：语体（建议）—「桀骜」偏文语，`style.md` 要求把译文读给没有古文基础的读者不觉得像古文。`nibbisevana` 的意思是「野性已除、驯服」。
- **建议**：「**调伏了**，就是通过除去盖障，使心不再难以驾驭。」

## §934 句 181-934-2-15

- **问题**：引文顺序与父层相反（必改）— 父层 `99-1421-2-155` 定稿把该句译为「**以‘这位世尊就是……’等等方式作随念的，这究竟是谁呢？**」，即「作随念的」在前、「这究竟是谁」在后；本层黑体省略引作「这究竟是谁……乃至……作随念的」，首尾正好颠倒，读者按父层译文找不到这段引文的头尾。
- **建议**：「**作随念的……乃至……这究竟是谁呢**，就是：这究竟是谁住在我里面作随念呢？」（省略号两端取父层的实际首尾词）。

## §934 句 181-934-67-70

- **问题**：原文异读（记录，不要改）— 本层被解释词作 `Sambhāvikā`，而父层义注原文作 `pabhāvikā`（`tassa pabhāvikā taṇhā`）。两处词形不同（sam-/pa-），疑为版本异读或 OCR 讹误。译文两边都作「使它生起的」，把异读抹平了——词义上无碍（samuṭṭhāpikā 释义相同），但应记入 `knowledge/known-issues.md` 的「OCR / 原文问题」一节备查，不要在译文里改动任何一边。
- **建议**：黑体「**使它生起的**」与父层定稿「使它（苦谛）生起的」首尾一致，可保留。

## §934 句 181-934-71-74

- **问题**：被解释词在父层译文中无对应（必改）— 本层黑体「**它的**」引的是父层 `tassā nirodho` 的 `tassā`，但父层定稿把这个代词显化译掉了：「渴爱的灭是灭谛」——父层译文里没有「它的」三个字，黑体回指断链。内容本身与义注不冲突（ṭīkā 说 tassā 指集谛，父层显化为「渴爱」，所指相同）。
- **建议**：顺父层定稿改写，把「代词已被显化」这件事说出来，例如：「**渴爱的**〔原文作“它的”〕，就是集谛的。」或「这里的“渴爱的”，原文是代词，指的是集谛。」——不要保留孤立的「**它的**」。

## §934 句 181-934-75-78

- **问题**：术语可读性（建议）—「灭的因相」中「因相」是 `nimitta` 的硬译，一般读者无法解。此处 ṭīkā 的意思是：父层的「灭」指的是作为灭之依据（即涅槃）的那个东西，而非灭的行为本身。
- **建议**：「**灭**，就是作为灭之因的那个〔涅槃〕，即灭的因相（nimitta）。」或至少补夹注。

## §934 句 181-934-63-66

- **问题**：措辞（建议）—「句子的连接是」对 `yojanā` 偏口语化；本层后文还会反复出现这个注释套语，宜定一个固定译法。
- **建议**：统一作「〔文句〕的配释是：确定了五蕴之后。」或「应这样连读：…」，并登记进 `knowledge/terms.md`（`yojanā` → 配释）。
