## 二、跨段一致性

- **"死亡"的表述**：§574 `yathākammaṃ gatā` 译"随着各自的业力去了别处"，§576 `kālakatabhāvaṃ` 译"已经去世"。同一 chunk 内同一概念两种说法，且前者是误译（见下）→ 统一为"随业而去（去世）"／"去世"。
- **`mahāpurisa`**：§574-16-30、§574-53-64 均译"大人物"。这是相术术语（具三十二相之人），"大人物"是现代口语义，易被读成"重要人士"。→ 建议统一为"大人（mahāpurisa）"，首次出现夹注。
- **菩萨的称谓**：§574-93-113 同句内先"菩萨"（`bodhisatte`）后"大士"（`mahāsattaṃ`），原文确是两词，保留可以；但§575 全用"菩萨"、§577 全用"导师"，层次是清楚的，**此项无问题**，仅记录。
- **长引语的引号处理不统一**｜**必改**：§574 憍陈如的话跨四句（574-31-36 起引号 → 574-37-42、574-43-52 **无引号** → 574-53-64 收引号），中间两句形式上脱出引语之外；§576-2-63 至 §576-64-75 同样如此。→ 连续引语跨句子单元时，每个单元都应在句首重开引号（中文规范做法），或至少四句一致处理。
- **`sotāpattiphala`**：本 chunk 仅一处译"入流果"，与 `term-glossary.jsonl` 无冲突，保留；但建议补登术语表以免后续段落漂成"须陀洹果"。

## 三、逐句问题

### §574

- **99-574-2-15**｜**必改（误译 + 文本残留）**
  - **问题 A**：`sabbadaharo pana lakkhaṇapariggāhako koṇḍaññamāṇavo` 译作"只有**相看之术**最年轻的那位、负责察看相好的憍陈如青年"。"相看之术"是混进译文的残留片段，原文无对应词，且与后半"负责察看相好"语义重复。
  - **问题 B**：`yathākammaṃ gatā` 译"随着各自的业力去了别处"。此处是固定说法，指"随业而去"即已命终；下文 `arogo`（还健在）与 §574-43-52"如果你们的父亲还健在"两处互证，父辈确已去世。译成"去了别处"会让读者以为只是离开。
  - **建议**：`那时，其余七位婆罗门都已随业而去（去世），只有最年轻的、负责察看相好的憍陈如青年还健在。`

- **99-574-65-70**｜建议 — `ekacchandā bhavituṃ nāsakkhiṃsu` 译"没能全都达成一致的心愿"。`ekacchanda` 是"意愿一致"，不是"共同的心愿"。→ `他们没能全体意见一致。`

- **99-574-114-132**｜**必改（风格）** — "就开始**进用**粗实的食物"。`style.md` 明列"用膳→吃"，"进用"同属敬语/半文言。→ `就开始吃比较粗实的食物`。（同一问题见 §575"因为**进用**粗实的食物"，一并改。）

### §575

- **99-575-2-69**｜**必改（衍字）** — "面朝东方世界**界**"。`pācīnalokadhātuabhimukho` = 面向东方世界，末尾"界"是衍字。→ `面朝东方世界`。

- **99-575-2-69**｜**必改（术语误导）** — `pubbenivāsaṃ anussaritvā` 译"忆念起过去世的**住处**"。`pubbenivāsa` 传统译"宿住"，指过去生的生命经历，不是"住的地方"；直译"住处"会把宿住随念读成回忆房屋处所。
  **建议**：`初夜忆念起过去世的经历（宿住，pubbenivāsa）`。

- **99-575-2-69**｜**必改（风格）** — 本句内多处文言/半文半白，对照 `style.md` 第一节禁例：
  | 现译 | 改法 |
  |---|---|
  | 盛加称扬 | 大加赞颂／受到种种赞颂 |
  | 在不动**之**座上 | 在不动的座位上／在金刚座上 |
  | 结跏趺**而**坐 | 结跏趺坐 |
  | 立起具足四支的精进 | 下定具足四支的精进决心 |

- **99-575-2-69**｜建议（可读性） — 全段一句到底、逾二百字，中文读者难以把握。原文虽是长复合句，但 `style.md` 要求"通顺自然"，建议按"傍晚登座 / 摧魔 / 三夜证智 / 七日果定"切成四到五句，不改语序也能断开。

- **99-575-2-69**｜存疑（记录，不改） — `kālena nāgarājena` 译"迦拉龙王"。此龙王名 Kāla，通译"迦罗龙王"（或意译"黑龙王"）；"迦拉"非通行音译。→ 建议统一作"迦罗龙王（Kāla）"并登入术语表。

### §576

- **99-576-2-63**｜**必改（语气误读）** — `Yaṃnūnāhaṃ … deseyyaṃ`（跨至 576-64-75）译"我**是不是应该**先为这五位比丘说法**呢**"。`yaṃnūna` + 愿望语气是决意句式（"我何不……"／"我就……吧"），不是自问是否该做；译成疑问句会削弱下文"于是生起了这样的念头"的因果。
  **建议**：`我何不先为这五位比丘说法呢！`／`我就先为这五位比丘说法吧。`

- **99-576-2-63**｜建议（风格） — "坐在那里**思察**法的深奥"。`paccavekkhati` = 省察、观察；"思察"是生造的半文言词。→ `坐在那里省察到法的深奥`。

- **99-576-2-63**｜存疑（记录） — `rājāyatanamūle` 译"王座树下"。Rājāyatana 是树名（音译"罗阇耶多那"），"王座树"是拆字直译，容易被读成"王的座位旁的树"。→ 建议 `在罗阇耶多那树（rājāyatana）下`，或"王树下"加夹注。

- **99-576-94-107**｜建议 — `aggasassadānaṃ` 译"最上等的新谷"。`aggasassa` 指田里**最先成熟的那一份**收成（初熟之谷），重点在"初"不在"上等"。→ `九次以初熟的谷物（aggasassa）布施给以佛陀为首的比丘僧团`；同时"施与"改"布施给"（风格）。

- **99-576-94-107**｜建议 — "作了**成就此事的功业**"（`adhikārakammaṃ`）半文言且含糊。→ `积累了为此发愿的功德行（adhikāra）`。

### §577

- **99-577-68-75**｜**必改（数字错）** — `aṭṭhārasahi mahābrahmakoṭīhi` 译"十八**亿**大梵天"。`koṭi` = 千万（俱胝），十八俱胝应为一亿八千万，译"十八亿"多了一个数量级。
  **建议**：`与十八俱胝（一亿八千万）大梵天一同安立于入流果。`

- **99-577-45-59**｜**必改（擅自补足）** — "无上的、三转**十二行**的《转法轮经》"。原文只有 `teparivaṭṭaṃ`（三转），`dvādasākāra`（十二行相）是译者补入的。`style.md` 第六节"不擅自补足"。
  **建议**：删"十二行"，或作夹注 `三转（teparivaṭṭa）的《转法轮经》`。

- **99-577-45-59**｜建议（风格） — "以憍陈如长老为身证**之**人"，文言虚词。→ `以憍陈如长老作为身证者`。

- **99-577-76-112**｜**必改（内心思量误作口说 + 呼语误译）**
  - **问题 A**：原文结构是 `satthā "…" ti theraṃ ālapanto "aññāsi vata…" ti āha` —— 前一段引文是导师给出名号的**缘由/心念**，`ālapanto`（称呼着长老）是伴随状语，真正说出口的是后一句。译文"接着导师**说**：……于是称呼这位长老说：……"把前段也处理成口说，成了两次开口。
  - **问题 B**：`bho` 是巴利文里的泛用感叹呼语，此处并非在称呼某个"朋友"；译"朋友"会让读者以为佛陀在对某人这样叫。
  - **建议**：`接着导师心想："他最先就了知了我历经百般艰难才带来的法，所以这位名叫阿若憍陈如。"于是对长老说道："憍陈如确实已经了知了啊！憍陈如确实已经了知了啊！"`
