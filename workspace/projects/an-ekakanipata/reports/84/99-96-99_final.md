**风格**：译文主体是合格的现代书面汉语，句长随原文节奏，未见「此中／故为／彼等／是故」一类典型文言腔；标点全角，**未发现 ASCII 引号**，JSON 安全这一硬约束通过。扣分点是两处文言残留：`99-96-46-51` 的「超越常人之法」（文言虚词「之」，且该术语宜用传统译名「上人法」），`99-96-2-13` 的「用称说……等等」（「称说」为文言单音节词组，应作「提到／通过提到」）。另有体例混用：圆括号在 `style.md` 里规定用于首次出现的术语夹注巴利原词，但本段同时把它当作补语括号（99-96-30-37「亲近（世间）」、99-99-18-31「出家（离开在家生活）」）和构词成分注解（99-98-10-21 的 sīlatā / dhammatā / sādhukāritā 并非独立术语），读者无法区分括号的三种用途。

**一致性**：主要问题是黑体词条的处理不统一——`99-97-2-6` 给了「**当时**、**在那里**（tatra）」两个并列译法，等同在正文里留候选，违反「译文不留工作标记」；`99-97-58-66` 的词条直接留巴利「**kho**」，而其余词条都译成汉语；`99-97-101-108` 词条译作「**说**」而同句释义与 99-98 各句一律用「招呼」。术语层面 `arahaṃ` 译作「应供者」，与 `term-glossary.jsonl` 里 confirmed 的「阿罗汉」不符（如十号语境有意取「应供」，应在 `terms.md` 补登记并全书统一）。

## 问题清单

### 🟧 error
- `99-98-43-50`｜导致误解的表达（修饰关系）｜片段「也正是用这同一句显示出他想要讲说的话」
  - 问题：`kathetukamyatādīpakena vacanena` 是"那句显示出他有意讲说（之意愿）的话"，译文「显示出他想要讲说的话」会被读成"把他想讲的内容说出来"，宾语被读错。
  - 建议：改为「也正是这句透露出他有意讲说的话语，使他们生起想听闻的心」。
- `99-97-67-70`｜错误多译 / 错译（词义）｜片段「是说明他是世间的导师，为世间所尊崇」
  - 问题：`lokagaru` 一词被译成两句；且 `garu` 义为"受尊重者"，「导师」是 `satthu` 的义位（99-99 各句正用「导师」译 satthu），造成两词同名。
  - 建议：改为「是说明他为世间所尊崇」，「导师」留给 satthu 专用。

### 🟨 warning
- `99-96-46-51`｜文言语体｜片段「超越常人之法（uttarimanussadhamma）」
  - 问题：文言虚词「之」；且该词传统汉译为「上人法／过人法」。
  - 建议：「以实行上人法（uttarimanussadhamma，超越常人的法）为因缘」。
- `99-96-2-13`｜文言语体｜片段「用称说“祇树园”等等」
  - 问题：「称说」为文言词组，读来半文半白。
  - 建议：「通过提到“祇树林”等等」。
- `99-97-2-6`｜译文残留候选标记｜片段「**当时**、**在那里**（tatra）这个词」
  - 问题：黑体词条并列给出两个译法，等同在正文里留候选；且无法与本文层「tatra」的译法逐字对应。
  - 建议：取本文层实际所用的那一个（其余义放入释义正文，如"这个词既指处所也指时间"），词条只留一种写法。
- `99-96-90-117`｜术语不一致｜片段「就是如来、应供者、正等正觉者」
  - 问题：`arahaṃ` 译「应供者」，与 `term-glossary.jsonl` confirmed 的「阿罗汉」不符。
  - 建议：统一为「阿罗汉」，或在 `terms.md` 登记十号语境专用「应供」并全书贯彻。
- `99-97-101-108`｜汉语语病（冗余）｜片段「的意思是：招呼了、讲说了、唤起了注意——这就是这里的意思」
  - 问题：一句之内两次「意思」，句首句尾自我重复。
  - 建议：「**招呼**（āmantesi）即招呼、讲说、唤起注意——这里取的就是这个义。」并与本文层词条用词对齐。
- `99-98-6-9`｜汉语语病（冗余）｜片段「而这样称呼，是因为这一称呼由他们具备以乞食为本性等等功德而得以成立」
  - 问题：「称呼……这一称呼」重复，句子自缠。
  - 建议：「这样称呼，是因为他们具备以乞食为本性等功德，这一称呼才得以成立。」
- `99-99-32-37`｜汉语语病｜片段「在坐在那里的人当中」
  - 问题：「在……坐在」连用，读来拗口。
  - 建议：「在那里就座的人当中」。
- `99-98-33-42`｜代词指代不明确｜片段「他用这样一句话，使他们转过脸来面向世尊」
  - 问题：同一句里「他」与「世尊」指同一人（`attano` 即说话者自己），人称跳换，读者会误以为是两个主体。
  - 建议：「世尊用这样一句话，使他们转过脸来面向自己」。
- `99-98-33-42`｜整句逻辑表达不规范｜片段「先是悲心洋溢、心与目光柔和地投注过来」
  - 问题：原文是"以悲心洋溢而柔和的心与眼的投注为先导的话语"，属修饰话语的定语；译文抽成独立分句并用「投注过来」（视角落到比丘一侧），逻辑层次丢失。
  - 建议：「他以悲心洋溢、心与目光柔和地投注为先导，用这样一句话使他们转过脸来面向自己。」
- `99-98-10-21`｜体例误用（术语标记）｜片段「具备以乞食为本性（sīlatā）这一功德的人」
  - 问题：sīlatā / dhammatā / sādhukāritā 是复合词内的构词成分，不是独立术语，按 `style.md` 圆括号夹注只用于首次出现的术语原词。
  - 建议：改为整词夹注一次（bhikkhanasīlatā / bhikkhanadhammatā / bhikkhane sādhukāritā），或把构词分析移入脚注。
- `99-96-30-37`｜补出成分无据 / 括号用法混乱｜片段「他以悲心亲近（世间），后者显示他以智慧远离（世间）」
  - 问题：原文 `upagamanaṃ / apagamanaṃ` 无宾语；补出的「世间」未见依据（若依上下文更像"众生"），且括号此处作补语用，与术语夹注括号混同。
  - 建议：不补宾语（「以悲心亲近，以智慧远离」），或补出为不带括号的「亲近众生／远离世间」并在报告中备案依据。
- `99-96-130-138`｜关键词语意不明确｜片段「这里的意义配释应当按上面这样的方式来理解」
  - 问题：「意义配释」（atthayojanā）是未经解释的生造词组，普通读者读不懂。
  - 建议：「这里意思的配释（atthayojanā）应当按上面这样的方式来理解」，或径作「这里该如何连贯地解释文义」。
