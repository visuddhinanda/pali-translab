**取数降级（影响信心）**：本次只注入了复注（ṭīkā）巴利原文与 channel 译文，**未提供 aṭṭhakathā 正文与 nissaya**。因此"义注定释义、nissaya 定词法"两条基准都无法直接核对：

- 复注大量黑体词条（`Pañcakkhandhā pana vipassanāya bhūmi nāmā`、`Tesū`、`Anusayitakilesā`、`Idaṃ bhūmiladdhuppannaṃ nāmā`、`Purimanayenevā`、`Vitthāretabban` 等）是从义注逐字引来的，**"被解释词与父层逐字同译"这条硬约束本次无法验证**，只能从译文内部体例一致性反推（见问题清单第一条）。
- 词法判断只能靠语法与阿毗达摩教理内部一致性推断，没有缅文 nissaya 的格助词做裁决。涉及 `tadārammaṇaṃ`（1017-66-78）这类修饰关系悬疑处，结论标注为"待 nissaya 复核"。
- 外部引用（Atthasālinī / Sammohavinodanī 原文）亦未注入，译文对两家分歧的转述只能按复注自身文脉评估。

**准确性**：阿毗达摩术语体系整体把握准确——`uppanna` 四分（现行已生 / 受用后已过去的已生 / 已作机会的已生 / 得地的已生）、`bhutvā-vigata` 与 `bhūtāpagata` 的区分、`vipāka` / `kiriya` / `abyākata` 的对立、`vikkhambhana-pahāna` 与 `samuccheda-pahāna` 的两重断，译文都立得住；1017-24-65 把义注未明写的"受用后已过去"一侧补出，与 Dhs-a「bhutvā vigataṃ nāma kusalākusalaṃ, bhūtāpagataṃ nāma sesasaṅkhataṃ」的分判吻合，是有依据的增补，不扣分。1019-45-55 / 56-85 对 `paranipāta`（前语后置）这一语法要点的处理清楚，`aggi-āhita` 的类比也译对了。

扣分集中在两处：1017-66-78 把 `bhavitvāvigata`（存在过后已消失）译成"存在过而**未**消失"，凭空加了否定，使整句推论自相矛盾——这是本批唯一确定的硬错误；同句 `tadārammaṇaṃ` 的归属译成"异熟以业为所缘"，与异熟心所缘的教理不合，疑为修饰关系误读。

**风格符合度**：主体是合格的现代书面汉语，长复句切分得当，没有"此中/故为/彼等/是故"一类典型文言腔。但有两类残留：一是文言虚词"之"（"所缘之味"，同句两处），二是单音节文言词"置"（"已置了火的"）。另有若干"依以……这一点"、"这所说的那一类"式生硬结构，属汉语语病而非文言，一并列在 warning。夹注体例有偏差：按 `knowledge/style.md`，圆括号只用于首次出现时附巴利原词，本批出现了括号内塞解释语（"（bhūmi，即观所依的基础）"、"（anusaya，也就是上文所说潜伏的烦恼）"）与括号补中心语（"（烦恼）"）两种越界用法。全批标点均为全角，未发现 ASCII 引号、未发现 `「」`，JSON 安全无风险。

**一致性**：核心术语自洽（受用后已过去 / 存在过后已过去 / 得地 / 已作机会 / 现行 全批统一）。不一致有三处：`samuccheda` 在 1019-32-44 作"彻底断绝"、在 1020-27-30 作"正断（彻底断绝）"；`pavatta/pavatti` 在 1017 作"转起"、1020-16-22 作"现起"；黑体词条的后接标记在"——"与"，"之间摇摆（1018-16-22）。另外"转起"是方法文档点名的二意词，出现两次均未加注。

## 问题清单

### 🟧 error

- `181-1017-66-78`｜错译（词义、修饰关系）｜片段「所以业只是依存在过而未消失这一点」
  - 问题：`bhavitvāvigatamattavasena` = bhavitvā + vigata + matta + vasena，意为"仅依'存在过后便已消失'这一点"，其中 `vigata` 是肯定的"已消失"，没有否定前缀。译文加了"未"，与 `vigata` 正相反；更严重的是，本句前半已有 `avipakkapākassa sabbathā avigatattā`（未成熟的异熟并非全然消失）作为理由，后半若再说"未消失"，整句就成了"因为没消失，所以依没消失这一点而叫'受用后已过去'"，推论自相矛盾，普通读者读不通。
  - 建议：改为"所以业也只是依'存在过后就已消失'这一点，才叫做'受用后已过去'"——即前半讲异熟尚未全然消失、故业不能在完全义上说已受用尽，后半讲只能在"曾存在而后消失"这个弱义上称之。

- `181-1017-66-78`｜错译（修饰关系）｜片段「该异熟以它（业）为所缘」
  - 问题：`vipākānubhavanavasena tadārammaṇaṃ` 中 `tadārammaṇaṃ` 为中性主格，当与 `kammaṃ` 同格（"以此为所缘者"），讲的是"业借着异熟被领受"这层关系；译文反转成"异熟以业为所缘"，而异熟心并不以业为所缘，与阿毗达摩所缘论相悖。
  - 建议：暂改为中性表述，如"就异熟被领受而言，业即是与此相关者"；**此条须以 nissaya 的格助词复核后定稿**（本次 nissaya 缺失），复核前将该句 `confidence` 压低。
