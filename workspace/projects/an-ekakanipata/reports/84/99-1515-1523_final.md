## 理由

**资源情况（降级说明）**：本次只注入了巴利原文（义注层，book=99）与 channel 译文。**nissaya 未注入、所释的本文（Aṅguttara 本文层）亦未注入**，因此：词级的格/句法核对只能凭原文自身形态判断，无法以 nissaya 为准仲裁；1521/1522 的黑体被释词（`saddhābalaṃ`、`Satisambojjhaṅgaṃ bhāveti`）是否与本文译文逐字一致**无法验证**。信心指数因此压到 70。可内部核对的一处（1520 的 `gambhīrañāṇacariyaṃ paccavekkhato` 引自 1519 的无碍解道引文）做到了逐字同译——1519 作「省察深奥的智慧之行」，1520 词条亦作「省察深奥的智慧之行」，对齐正确。

**准确性**：主干判断整体可靠，没有主谓宾层级的误判，也没有违背教理的句子。几处关键难点处理得对：
- 1523-14-47 这一长句最容易把 bodhi 的指称归错（误作「圣弟子被称为觉」或「道被称为觉」），译文正确地让「法的和合」承接 bodhi，并在 1523-89-104 另立「圣弟子也被称为觉（者）」的第二义，与 1523-2-9「bodhiyā, bodhissa vā aṅgo」的双解一一呼应，结构读通了。
- 1523-14-47 的祸患清单 līna / uddhacca / patiṭṭhāna / āyūhana / kāmasukhānuyoga / attakilamathānuyoga / uccheda / sassatābhinivesa 八项无漏无增；七觉支成分（念、择法、精进、喜、轻安、定、舍）齐全。
- 1522 的 apilāpana 一词贯穿「特相—作用—弥兰王问譬喻」四句，统一译「一一称举」，并与譬喻中司库官报数的语境自洽；`kiccavaseneva hissā etaṃ lakkhaṇaṃ therena vuttaṃ`（长老就作用面说成特相）这层后设说明也没有丢。

扣分集中在三类：一是 1520-22-39 补出了原文没有的「各门修法」（见 🟧）；二是 1523-89-104 漏译 `ādayo`「等」；三是若干格的处理被拉平——1521-13-43 原文在 assaddhiye / uddhacce 用处格、kosajjena / muṭṭhassaccena 用具格，译文一律作「被…动摇」，语义不误但格的区别消失，无 nissaya 可据，故只记 suggestion 并在此交代。

**风格符合度**：绝大部分是合格的现代书面汉语，长复句拆分（1523-14-47 拆成四句）明显提升了可读性。标点合规：全程中文全角，引号一律 “”，**未出现 ASCII 引号，也未出现「」**，JSON 安全无隐患；译文内**无任何候选/待定/问号等工作标记**。扣分点是两处文体瑕疵：「执断执常」属四字文言压缩，「现正觉了无上的正等正觉」既生硬又自我重复（「正觉…正觉」）。另有 1522-2-17 的粗体被拆成 `**修习****念觉支**` 两段相邻标记，属格式缺陷。

**一致性**：五根段（1515–1519）的句式模板高度统一（「远离…的人，亲近、交往、侍奉…的人，省察…，由这三种方式，X根得到清净」），`imehi tīhākārehi`、`visujjhati`、`antara`（统一作「差别」）、`akampiyaṭṭhena`（统一作「由于不动摇的意思」）译法前后一致。唯一的术语隐忧是 `sambojjhaṅga` 与 `bojjhaṅga` 都译「觉支」，sam- 前缀在汉译中消失——1522-113-117 与 1523 整段在讨论的正是这两个词的构词理据，读者会看不出原文有两个词在被分别定义。

## 问题清单

### 🟧 error

- `99-1520-22-39`｜错误多译｜片段「在以信为主导（saddhādhura）等各门修法上建立起用功的着力点」
  - 问题：`saddhādhurādīsu` 是处格复数、所修饰的名词省略，原文并未指明是「修法」。译文补出「各门修法」为无据增译，且把 saddhādhura（以信为担／为主导）窄化成了一类法门名目。
  - 建议：按原文留白，作「在以信为主导（saddhādhura）等（诸法）上建立起用功的着力点」；若必须补足，宜补为上文刚讲完的「诸根」而非「修法」。
- `99-1523-89-104`｜漏译｜片段「就像军支、车支那样」
  - 问题：原文 `senaṅgarathaṅgādayo viya` 有 `ādayo`「等」，未译。同一篇 1523-80-88 的 `jhānaṅgamaggaṅgādayo viya` 译作「就像禅支、道支等那样」，译出了「等」，前后自相矛盾。
  - 建议：改为「就像军支、车支等那样」。

### 🟨 warning

- `99-1523-14-47`｜文言语体｜片段「执断执常」
  - 问题：四字文言压缩式（单音节动词「执」直接带宾），不是现代书面汉语，与 `knowledge/style.md` 第一节禁例同类。
  - 建议：改为「执着断见、执着常见」或「对断见与常见的执取」。
- `99-1523-51-79`｜不导致误解的汉语语病｜片段「现正觉了无上的正等正觉」
  - 问题：「现正觉了…正等正觉」同一语素在一句内重复，且「现正觉了」是硬译的译经腔，普通读者读不通。
  - 建议：改为「修习七觉支之后，证得了无上的正等正觉（sammāsambodhi）」。
- `99-1522-2-17`｜标点符号使用错误（粗体标记）｜片段「**修习****念觉支**」
  - 问题：原文两个黑体词 `Satisambojjhaṅgaṃ` 与 `bhāveti` 在汉语里语序颠倒后相邻，粗体被拆成两段、中间留下 `****`，部分渲染器会把它显示成裸星号。
  - 建议：合并为一段粗体「**修习念觉支**」。

### 🟦 suggestion

- `99-1522-113-117`｜该使用而没有使用术语标记｜片段「念本身就是觉支」
  - 问题：`sambojjhaṅga` 与 1523 通篇的 `bojjhaṅga` 同译「觉支」，sam- 消失；而 1522–1523 正是在分别为这两个词立释，读者看不出原文有两个词。
  - 建议：此处首次出现时夹注巴利原词，如「念本身就是等觉支（sambojjhaṅga）」，或统一用「等觉支」对译 sambojjhaṅga，与 bojjhaṅga「觉支」区分。
- `99-1522-18-39`｜语言风格不统一｜片段「它以现前为特相」
  - 问题：`upaṭṭhāna` 译「现前」，而同段末 `paccupaṭṭhāna` 译「现起」（1522-108-112），两词汉译仅一字之差，易混。
  - 建议：首次出现夹注原词，如「以现起（upaṭṭhāna）为特相」，或沿用「以不忘失为味／以面向所缘为现起」的四法体例统一标注。
- `99-1521-13-43`｜代词指代可能不够明确／格的处理｜片段「信不被不信动摇」
  - 问题：原文 assaddhiye、uddhacce 为处格（于不信中／于掉举中不动摇），kosajjena、muṭṭhassaccena 为具格，译文一律处理为被动「被…动摇」，格的区别被拉平。语义无误，但在无 nissaya 可依的情况下属可改进项。
  - 建议：处格句可作「信于不信之中不动摇」「定于掉举之中不动摇」，具格句保留「被…动摇」。
- `99-1520-2-21`｜语言表达不够流畅｜片段「根与力与觉支的差别」
  - 问题：连用两个「与」，现代汉语并列宜用顿号。
  - 建议：改为「根、力、觉支的差别」。
- `99-1523-80-88`｜复杂的嵌套句整句语言逻辑理解困难｜片段「它是那个被称为法的和合的觉的支分」
  - 问题：三层「的」连环套（被称为…的／和合的／觉的），读者难以一次解析。
  - 建议：拆为「所谓『觉』就是那个法的和合；它是这个觉的支分，所以也叫做觉支」。
- `99-1515-2-21`｜语言表达不够流畅｜片段「由这三种方式」
  - 问题：`imehi tīhākārehi` 是具格，「由」略生硬；该句式在 1515–1519 五处复用，统一改动收益较大。
  - 建议：统一改为「以这三种方式」（或「由这三种行相」，若 terms.md 决定保留 ākāra 的术语译法）。
- `99-1520-22-39`｜不常用术语编写注释或者百科｜片段「最后由还灭（vivaṭṭa，转离轮转）而证得阿罗汉果」
  - 问题：`vivaṭṭetvā` 是连续体动词（转离之后），译成名词「由还灭而」读起来像经过某个阶段；「还灭」对一般读者亦生僻，括注虽有但仍偏简。
  - 建议：改为「最后转离轮转（vivaṭṭa，即观还灭）而证得阿罗汉果」。
- `99-1522-43-69`｜语言表达不够流畅｜片段「就像国王的司库官向国王一一称举国王的财物」
  - 问题：一句三个「国王」，汉语累赘（原文 rañño 两次 + 呼格 mahārāja）。
  - 建议：改为「就像国王的司库官向国王一一称举王家的财物」。
- `99-1522-43-69`｜不常用术语编写注释或者百科｜片段「银钱有这么多」
  - 问题：`hirañña` 与 `suvaṇṇa` 对举时，`hirañña` 通常指（未铸或已铸的）金／钱财，译「银钱」是一种取义但非主流；无 nissaya 可裁。
  - 建议：考虑改为「金钱有这么多，黄金有这么多」，或保留现译并在 `knowledge/terms.md` 登记该取义，避免后续段落摇摆。
- `99-1521-50-53`｜语言风格不统一｜片段「这些也被说成既是世间的，也是出世间的」
  - 问题：原文 `lokiyalokuttarāneva`（唯被说为世间与出世间）的限定词 `eva` 两处（1520-54-59、1521-50-53）均未译；另该句无 `-pi`，「也」是承前补出，与 1520-54-59 的「imānipi」用同一个「也」，语气层次混同。
  - 建议：译出限定，如「这些同样只被说为世间与出世间两种」。
- `99-1523-105-107`｜语言风格不统一｜片段「因此诸义注师说」
  - 问题：「诸」为文言虚词式复数标记，与全篇现代汉语语体略有落差（未列入 style.md 禁例表，故不计 warning）。
  - 建议：改为「因此义注师们说」或「因此诸位义注师说」。
