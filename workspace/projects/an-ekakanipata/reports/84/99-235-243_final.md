**准确性**：全段无理解性错误，无违背基本教理的判断，fatal 为零。轮转/出离轮转（vaṭṭa/vivaṭṭa）、地狱四同义词（苦界/恶趣/堕处/地狱）、无明—明—涅槃—亲证这一串核心概念都译对了，`99-237-56-115` 那一长句（芒刺喻 ↔ 布施回向）的对应结构完整、主从关系清楚，是本段翻译质量最高的一处。扣分集中在两点：黑体被解释词被注释内容污染（多译出原文没有的成分）；`caranta` 统一译作「游动」，词义选得过窄——该词要同时统摄珠贝、螺、鱼与沙砾，义为「移动」，译成「游动」后下文「把沙砾和瓦砾也说成‘游动的’」在汉语里就站不住，而这恰恰是该段义注的论证落点。

**风格**：现代书面汉语这条硬约束守得不错——全段未见文言虚词（之/其/乃/便/即/谓/遂）、未见文言句式，「哪怕极少的善业」「严格说来」「不由自主地堕落到这里」都是干净的现代汉语；标点全角，无 ASCII 引号，无候选/待定等工作标记。扣分在体例：`99-242-17-24` 在正文里插了一处译者注（sagga=su+agga），而同类词源训释（apāya、duggati、sugati、nirassāda→niraya）一律没有注，体例不一且注释本该走脚注；`99-243` 几句夹注过密（三句 7 处巴利夹注）；音译「细帕尼刺」首字与同句「细小柔弱」相撞，读来自相矛盾。

**一致性**：术语层面稳定——「朝向不正 / 朝向端正」「放置得不正 / 放置端正」前后贯通（`236-113` ↔ `236-136` ↔ `237-2`），vaṭṭa/vivaṭṭa 全段统一。扣分在三处不统一：同一个 `caranta` 在 `243-42-52` 译「游动」、在 `243-53-105` 译「走动」，而这两句正是一个类比的两端，用词分叉削弱了类比；黑体引词的时态处理不一（「会刺破」保留将来时，「生起明」丢失）；夹注形式不一（`paccekabodhi` 漏 ñāṇa，`sabbaññutañāṇa` 完整）。

**词源训释的通病**：巴利训释（apāya←apeto、duggati←dukkhassa gati、sugati←sukhassa gati、niraya←nirassāda、sagga←su+agga）在译成既定汉译名后，「所以叫做…」的因果链对中文读者普遍失效。目前只有 sagga 一处补了说明，其余裸留。这不是错译，但是整段最值得系统处理的可读性问题，建议统一交给 footnote 步骤。

## 问题清单

### 🟧 error

- `99-237-19-29`｜错误多译｜片段「**被手按到或被脚踩到**（akkanta）」
  - 问题：巴利被解释词只有 `Akkantan ti` 一词，「用手按」「用脚踩」的区分是这句注释要讲的内容（`pādeneva akkantaṃ nāma hoti, hatthena uppīḷitaṃ`）。译文把注释结论提前塞进黑体，黑体范围超出被解释词，与本文层黑体引文无法逐字对应。
  - 建议：黑体只保留对应 akkanta 的译词（如「被踩到」），本文里「用手或用脚」的语境放在黑体之外叙述。

- `99-243-42-52`｜错译（词义）｜片段「其余的则既会游动也会静止」
  - 问题：`caranta` 在此统摄珠贝、螺、鱼、沙砾四类，义为「移动」；译作「游动」只适用于鱼，导致同段下文「把沙砾和瓦砾也说成‘游动的’」（`99-243-53-105`）在汉语里不成立，而这句正是该段义注的论证落点。
  - 建议：全段统一改为「移动」，牛喻处（`99-243-53-105`）亦同——类比两端必须用同一个词，才看得出「以多数者之名统称全体」的道理。

### 🟨 warning

- `99-241-28-35`｜整句逻辑表达不规范｜片段「**已然在地狱里**的意思应当说成：就这样已经处在地狱里了」
  - 问题：黑体 `Evaṃ niraye` 只是「就这样在地狱里」，「已然」来自注释 `ṭhitoyeva`，被混进了黑体；结果黑体与后半句的解释几乎同义反复，读者看不出注释在补什么。
  - 建议：黑体改为贴合原文的「就这样在地狱里」，解释部分承担「已经安处其中」的意思。

- `99-235-1-4`｜关键词语意不明确｜片段「心的朝向与澄净品释义」
  - 问题：品名 `Paṇihitaaccha` 两个词分属两组比喻——paṇihita 说心（芒刺喻），accha 说水池清澄（水池喻）。译文把「澄净」也系在「心」上，主体不明确，且预先替读者定了解读。
  - 建议：改为「朝向与澄净品释义」，两词的所指交给正文与脚注。

- `99-237-39-49`｜关键词语意不明确｜片段「为什么不取别的那些粗大的细帕尼刺（sepaṇṇi）」
  - 问题：音译首字「细」是常用形容词，与同句「细小柔弱的稻芒」直接冲突，「粗大的细帕尼刺」读起来自相矛盾。
  - 建议：换一个不带义涵的音译（如「塞盘尼刺」），并在 `terms.md` 登记。

- `99-241-42-62`｜整句逻辑表达不规范｜片段「它是苦的趣向、苦的归处，所以叫做**恶趣**」
  - 问题：训释的前提是「苦」（duggati = dukkha + gati），译名却落在「恶趣」，汉语读者看不出「所以」从何而来。同段 apāya、niraya 两处同病（「远离了称为福利的快乐，所以叫做苦界」「没有任何可喜可乐之处，所以叫做地狱」）。
  - 建议：在该句为 duggati 补一处夹注或脚注点出「dug-=苦/恶」，其余同类训释统一处理。

- `99-243-37-41`｜不导致误解的汉语语病｜片段「合称**鱼群**（macchagumba）」
  - 问题：前两句 sippisambuka、sakkharakaṭhala 是并列复合词，用「合称」合适；macchagumba 是「鱼的群」（属格复合），不存在两物并列，沿用「合称」不当。
  - 建议：改为「即**鱼群**」。

- `99-243-53-105`｜不导致误解的汉语语病｜片段「有的站着、有的卧着、有的躺倒」
  - 问题：`nisinnā` / `nipajjamānā` 译成「卧着」「躺倒」近义重复，三项读起来只有两个区别；「躺倒」还带跌倒的歧义。
  - 建议：「有的站着、有的趴着、有的躺着」。

### 🟦 suggestion

- `99-236-15-87`｜语言表达不够流畅｜片段「世尊有时用意义围绕着比喻来展示」
  - 问题：`atthena upamaṃ parivāretvā` 直译为「用意义围绕着比喻」，与后半句「用比喻围绕着意义」一起看，读者很难分辨这两种体例究竟差在哪里。
  - 建议：改为「先立意义、再用比喻把它围起来 / 先立比喻、再用意义把它围起来」一类可解读的表述，或加脚注说明两种说法体例。

- `99-236-147-154`｜不常用术语编写注释｜片段「在八处无所知的、浓厚稠密的大无明」
  - 问题：「八处」（四谛、过去、未来、过去与未来、缘起）是义注的固定数目法，未加注读者无从得知指什么。
  - 建议：首次出现处加脚注列出八项。

- `99-241-21-27`｜复杂的嵌套句整句语言逻辑理解困难｜片段「**像被拿来放下那样**就是如同被拿来放置在那里一样」
  - 问题：巴利本身是词形训释（`yathābhataṃ` = `yathā āharitvā`），照译成汉语后前后同义反复，读者读不出任何新信息。
  - 建议：解释侧改述为「就像被人搬运过来、就地丢在那里一样」，或加脚注说明这是对 yathābhataṃ 的拆词训释。

- `99-236-155-162`｜语言风格不统一｜片段「在**生起明**这句话里」
  - 问题：黑体引词的时态处理不一致——`Bhecchati` 译作「**会刺破**」保留将来时，`Vijjaṃ uppādessati` 的「**生起明**」丢了将来时。
  - 建议：统一为「**会生起明**」或统一都不带时态标记。

- `99-237-116-139`｜语言风格不统一｜片段「独觉菩提智（paccekabodhi），甚至一切知智（sabbaññutañāṇa）」
  - 问题：同一句里夹注体例不一（前者漏 `ñāṇa`，后者完整）；「甚至能够带来…甚至…」两个「甚至」重复。
  - 建议：夹注统一作 `paccekabodhiñāṇa`；第二个「甚至」改「乃至」或删。

- `99-237-56-115`｜不常用术语编写注释｜片段「像韦拉玛（velāma）那样大的布施善业」
  - 问题：韦拉玛布施（《增支部》9.20）是义注常引的典故，首次出现无注，读者不知其「大」在何处。
  - 建议：加一条脚注。

- `99-242-17-24`｜语言风格不统一｜片段「（巴利 sagga 在此拆作 su“极”加 agga“殊胜”来解释。）」
  - 问题：全段仅此一处在正文内插译者注，而 apāya / duggati / sugati / niraya 等同类词源训释一律没有；按 `knowledge/style.md` 第四节，这类说明应走段后注释而非正文夹注。
  - 建议：统一改为脚注（交 pali-footnote 处理），正文只留译文。

- `99-243-23-30`｜语言表达不够流畅｜片段「各种珠贝（sippi）与各种螺（sambuka），合称**珠贝和螺**（sippisambuka）」
  - 问题：连续三句共 7 处巴利夹注（sippi / sambuka / sippisambuka / sakkharā / kaṭhala / sakkharakaṭhala / maccha…），密度过高，打断阅读。
  - 建议：只在被训释的复合词处保留夹注，单词成分的夹注删去。
