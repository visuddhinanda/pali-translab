## 理由

**评估基准缺失（信心下调的主因）**
本次只注入了巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**，无法按「义注定释义、nissaya 定词法」逐句核对取义、格与句法角色。因此准确性分只能依据巴利原文本身、上下文连贯性与传统注释学常识给出，属降级评估。尤其两点无法核验：

1. 本段是**复注**，黑体被解释词（如「**由礼敬所成**」「**福德**」「**障难已被彻底破除**」「**以一法、二法等等所庄严的**」「**殊胜的增支圣典**」「**说法者中的牛王**」「**能生起丰富辩才的**」）按硬约束须与父层义注译文**逐字同译**，父层译文未注入，一致性无从比对——这是本次一致性扣分留有余量的原因。
2. 181-117-69-79 引用的「我将阐明义理」出自义注开篇偈，是否与父层译文字面一致同样未能核验。

**准确性**
整体取义稳健，词源解释（puñña / āgama / vara / aṅguttara / puṅgava）的三重或四重释义结构都完整传出，locative-instrumental-ablative 的词源套式（181-118-86-122）、bahubbīhi 复合（181-117-45-49、181-118-123-131）、`Nanu ca … Saccametaṃ …` 的问难—解答结构（181-118-54-60 / 66-74）都没有译错。经证引文坐标（增支部 6.10；11.11／长部义注 2.33 等）照录无误。实质性缺失只有一处：181-118-2-39 漏掉 `atthaṃ`（见问题清单）。

两处原文形态存疑，未据以扣分：181-119-2-15 的 `asantasanaparissayasahanassa` 带属格，疑为复合词 `…sahana-paripālana…` 被切开，译文按并列功德处理，是合理取舍；181-119-138-163 原文作 `sāratthappakāsanī`，译文按通行书名作 Sāratthappakāsinī《显扬真义》，属规范化，不算改动。

**风格**
现代书面汉语落实得好，通篇**未发现文言/半文半白违例**：没有单音节文言虚词（之／其／乃／便／即／谓／於／遂），没有「…者…也」「于…之际」「经…后」一类句式，`Tathā hi` 译「事实确实如此」、`Saccametaṃ paramatthato` 译「就究竟义而言，这话是对的」都是干净的现代汉语。标点全角，引号统一「“”」，译文中未出现 ASCII 引号，符合 JSON 安全约束。译文中也没有残留任何候选/待定/问号一类工作标记。扣分集中在几处对一般读者偏硬的表达（「依待…假立」「配释」「在它里面、由它、或从它」）。

**一致性**
同一元语言套式的措辞不统一是主要问题：「这里的属格指的就是」／「上文的属格指的就是」；同一个 `su/suṭṭhu` 在词目译「彻底」、在释义译「很好地」，使复注的「以词释词」关系在汉语里失效。夹注策略也略有摇摆：`aṅguttara` 两次夹注，`ācariya` 这种常见术语也夹注，与 `style.md`「首次出现夹注、其后只用汉译」不完全一致。「阿阇梨」一词分指两个不同对象（诸先师 vs. 义注师本人）而未加区分，是一致性之外还牵涉可读性的问题。

## 问题清单

### 🟧 error

- `181-118-2-39`｜漏译｜片段「现在他要解说的是那部法的教说」
  - 问题：原文 `yassā dhammadesanāya **atthaṃ** saṃvaṇṇetukāmo` 中的 `atthaṃ`（义）未译出。本段复注通篇讲的正是「解说其义（atthasaṃvaṇṇanā）」，丢掉「义」削弱了与下文 181-119-71-79「以解说义理和解说功德这两种方式」的呼应。此外原文是目的从句（「为了先以称扬功德的方式使人认识……，他说了……」），译文拆成「现在他要解说的是……，所以先……」，读来像是先下定义再说目的，逻辑层次与原文不同。
  - 建议：改为「现在，为了先以称扬功德的方式，让人认识他想要解说其义理的那部法的教说，他说了“……”等语句」。

### 🟨 warning

- `181-117-50-64`｜代词指代不明确｜片段「他用这句话显示」
  - 问题：这是本 chunk 中「他」的首次出现，前文没有任何先行词；同样的无主「他」还见于 181-118-2-39「现在他要解说的」、181-118-40-53「他用这句话显示」。读者不易判断指的是义注师（被复注的作者）还是复注师本人。
  - 建议：首次出现处点明主语，如「义注师用这句话显示：……」，其后再用「他」。

- `181-116-2-8`｜不导致误解的汉语语病｜片段「只有在佛等身上才能得到」
  - 问题：「佛等」实指佛、法、僧三宝，法宝与僧宝不宜说「身上」，搭配不当。
  - 建议：改为「只有在佛等三宝那里才有」或「只有佛等三宝才具备」。

- `181-119-105-110`｜关键词语意不明确｜片段「阿阇梨（ācariya）们说」
  - 问题：此处 `ācariyā` 指传承中的诸位先师，而 181-119-123-137「这位阿阇梨的一贯做法」指的是义注作者本人，两处同用「阿阇梨」而所指不同，容易误读为同一批人。另，「阿阇梨们」的复数表达在汉语里也偏生硬。
  - 建议：此处译「诸位先师说」或「古师们说」，把「阿阇梨」留给指称义注师的场合。

### 🟦 suggestion

- `181-117-80-87`｜语言风格不统一｜片段「这里的属格指的就是那由礼敬三宝所成的福德」
  - 问题：同一套「补出汉语无法承载的格」的处理，三处措辞不一——本句作「这里的属格」，181-118-123-131 与 181-119-2-15 作「上文的属格」。
  - 建议：统一为「上文的属格指的就是……」。

- `181-117-45-49`｜语言风格不统一｜片段「就是障难被很好地破除了」
  - 问题：词目译作「彻底破除」，释义译作「很好地破除」，而原文 `su` → `suṭṭhu` 正是以同词释同词；汉语两词不同，复注的释词关系在译文里看不出来。
  - 建议：释义也用「彻底」，作「就是障难被彻底地破除了」。

- `181-118-86-122`｜复杂的嵌套句整句语言逻辑理解困难｜片段「在它里面、由它、或从它，自利与利他等等将会到来」
  - 问题：这是依处格／具格／夺格三读作的词源解释，汉语直陈三个介词短语，读者无从知道为何要并列三种说法；且整句把四个词源解释串成一句，长约两百字。
  - 建议：拆成若干短句，并加一句说明「（āgama 一词可依处格、具格、夺格三种关系解释）」，或将该说明放入脚注。

- `181-118-86-122`｜不该使用术语标记时使用了术语标记｜片段「所以叫做“增支”（aṅguttara）」
  - 问题：`aṅguttara` 已在 181-118-40-53 首次夹注，按 `style.md` 其后只用汉译。此处虽因讲词源而重复夹注有其用处，但与全篇夹注策略不一致。
  - 建议：二者择一——或删去此处夹注，或在体例中明确「词源解释句可重复夹注」并一体适用（181-119-105-110 的「阿阇梨（ācariya）」则属常见术语，夹注可删）。

- `181-112-38-74`｜不常用术语编写注释或者百科｜片段「获得对义的喜悦（atthaveda）」
  - 问题：`atthaveda / dhammaveda` 传统汉译多作「义信受／法信受」或「得义受／得法受」，现译取义注系统「veda = pīti-somanassa」的读法，方向可取，但读者会与既有译名对不上。
  - 建议：首次出现处加一条脚注，说明 veda 在此取「喜悦」义及与传统译名的对应。

- `181-119-89-104`｜不常用术语编写注释或者百科｜片段「这种讲说被称为“散说”（pakiṇṇakadesanā）」
  - 问题：`pakiṇṇaka` 汉译传统多作「杂」（杂说、杂部），「散说」不常见。
  - 建议：改作「杂说」，或保留「散说」并加注说明即传统所称「杂说」。

- `181-118-66-74`｜语言表达不够流畅｜片段「不过圣典是依待那些经而假立的」
  - 问题：「依待……假立」是大乘论典的汉译术语腔，对一般读者门槛偏高，而原文 `upādāya paññatto` 在此只是说「就诸经（的集合）而施设的名称」。
  - 建议：改为「不过“圣典”只是就那些经而施设的名称」。

- `181-119-63-70`｜语言风格不统一｜片段「诸佛对真理的通达」
  - 问题：`sacca` 在佛教语境的通行汉译是「谛」，译作「真理」虽不误，但与全篇偏传统的术语选择（涅槃、圣谛、相续、结集）不协调。
  - 建议：改为「诸佛对谛的通达」，或「诸佛对四谛的通达」。

- `181-112-2-37`｜语言表达不够流畅｜片段「正是依着如来而趣向正直」
  - 问题：`tathāgataṃ ārabbha` 是「缘于如来／就如来而言」，「依着如来」偏向「依靠」，且「趣向正直」把 `ujugata`（已成正直）的状态义弱化为过程义。
  - 建议：改为「缘于如来，他的心在那个时候正是正直的」。

- `181-119-111-122`｜语言表达不够流畅｜片段「能在说法者中的牛王心里生起丰富的辩才」
  - 问题：「心里」是译文补出的成分，原文只是属格（为说法者中的牛王生起丰富辩才），补出后反而把辩才限定在心理层面。
  - 建议：删去「心里」，作「能为说法者中的牛王生起丰富的辩才」。
