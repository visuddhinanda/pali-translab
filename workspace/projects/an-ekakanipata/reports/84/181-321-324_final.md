**取数降级（影响信心）**：本次只提供了巴利原文与 channel 译文，**义注（释义标准）与 nissaya（词级基准）均未注入**。因此准确性判断只能依据巴利语法（格、性数、复合词切分）、复注自身的释词链，以及《清净道论》系统里固定的法相清单来做，无法核对「被解释词与父层逐字同译」这条硬约束——凡涉及黑体 lemma 是否与义注用词一致的条目（如 `181-322-2-9`、`181-324-25-31`），都只能按内部证据判定，信心相应压低。

**准确性（83）**：39 句中大部分处理稳妥，几处难点译得好——`181-321-53-87` 十八大观清单 18 项一项不落、「ādito vuttā … 那七种」的收束关系正确；`181-322-23-45` 刹那灭与积聚的反问句层次清楚；`181-323-42-53` 把 `phalavohārena` 译成「用果的名称来称呼因」并补出所指，是本段最好的一句。扣分集中在五处 error：`gaṇasaṅgaṇikaniddānavakammādiṃ` 里的 **niddā（睡眠）被译成「闲话」**，既是词义错，又与被解释词 bhassa（闲谈）撞车，逻辑上不可能——`ādi` 概括的必是 bhassa 之外的项；`bāhulla`（资具丰足、多求）译作「放纵」；`sakiṃ`（一次）译作「一旦」，把「曾生起过一次」改成了条件句；`181-323-54-61` 的 `tassa` 是阳/中性属格，不可能指阴性的 `akusalajavanappavatti`，译文的指代分配与性数不合；`181-321-53-87` 的 lemma 漏掉了 `vā` 与处格。

**风格（78）**：整体是现代书面汉语，没有出现「此中/故为/彼等/是故」一类文言腔，这点合格。但有 3 处文言虚词残留——「善法生起**之**道」「作为转向**之**缘」「**即**舍离了本来状态的样子」，按 `knowledge/style.md` 第一节禁例表属硬约束违例，据此在风格维度显著扣分（每处已单列）。另一项系统性缺口：`āvajjanā / anvāvajjanā / ābhoga / samannāhāra / manasikāra` 这一组阿毗达摩术语**全程没有夹注巴利原词**，与 style.md「法相术语首次出现夹注巴利原词」不符；`samannāhāra` 更被译成「因为它注意，所以叫做注意」，词源训释在汉语里退化成空转，读者得不到任何信息。标点与引号系统正确，未见 ASCII 引号，未见候选/待定一类残留工作标记。

**一致性（80）**：两条释词链在汉译里断了。一是 `bāhulla → bahulaṃ uppajjanti`：上句用「放纵」、下句用「大量地生起」，复注靠同根词建立的解释关系读者看不出。二是 `byāpatti / byāpajjana / byāpāda` 同根三词被译成「变质 / 变坏 / 瞋恚」，而这段复注的整个论证正是靠这个词根把「食物变质」推到「瞋恚」，汉译把桥拆了。此外 lemma 的译法体裁不统一：绝大多数黑体被解释词译为名词短语，`181-322-2-9` 独独译成一个带主语的因果小句「因为他不曾习惯于烦恼」，还增补了原词没有的「烦恼」与「他」。

## 问题清单

### 🟧 error
- `181-321-46-52`｜错译（词义）｜片段「闲话」
  - 问题：`gaṇasaṅgaṇika-niddā-navakamma-ādiṃ` 中 `niddā` 是**睡眠**，不是「闲话」。译成「闲话」后与被解释词 `Bhassādīsu`（闲谈等）重复，而 `ādi` 概括的恰恰是 bhassa 之外的项，自相矛盾；同时 niddā 一项实际被漏译。
  - 建议：改为「聚众、交游、睡眠、新建工程等等」，并把 `gaṇa`（众）与 `saṅgaṇikā`（交游）拆开，勿合成「聚众交游」一词。

- `181-321-17-20`｜错译（词义）｜片段「就是在衣服等资具上放纵」
  - 问题：`bāhulla` 的核心义是（资具的）**丰足、多求**，`cīvarādipaccayabāhullāya` 是表目的的与格「为了衣等资具的丰足」。译作「放纵」既丢了与格的目的义，也遮蔽了紧接下句 `bahulaṃ uppajjanti`（「大量地生起」）的同根呼应，使复注的释词链在汉译里断裂。
  - 建议：改为「**（贪求）丰足**，就是为了衣服等资具的丰足」，并使下句的「大量」与此处用词同根呼应。

- `181-321-53-87`｜漏译｜片段「**七种随观**」
  - 问题：lemma 原文是 `Sattasu vā anupassanāsū`ti，`vā`（或）与处格均未译出。丢掉「或」会让读者以为此处只有这一个选项，而原文是并列诸项之一。
  - 建议：改为「**或在七种随观中**」。

- `181-322-46-55`｜错译（词义）｜片段「一旦生起的欲贪」
  - 问题：`sakiṃ` 是「一次、一度」，不是表条件的「一旦」；此句正要说「已生起过一次的欲贪（不会就此停住）」，译成条件句改变了论证方向。另外「一旦生起的欲贪」在汉语里也读不通（「一旦」不能直接带「的」）。
  - 建议：改为「**一度生起的欲贪**」或「**生起过一次的欲贪**」。

- `181-323-54-61`｜代词指代错误｜片段「因为正是依着这意门不善速行，前面所说的转向等才成为」
  - 问题：`tassa` 是阳性/中性属格，不能回指上句阴性的 `akusalajavanappavatti`；`sā` 是阴性，才对应 `pavatti`。译文把两个代词的所指互换了。
  - 建议：改为「因为正是依着那（不如理作意）的力量，那先前生起的意门不善速行才成为不善生起的亲依止」。核对义注/nissaya 后定案；若义注支持别解，请在报告中注明分歧。

### 🟨 warning
- `181-321-21-32`｜不导致误解的汉语语病｜片段「就怎样**趋附**、照那样生活」
  - 问题：原文只有一个 `tathā`，统管 `āvattassa pavattassa` 两词；译文把它译了两遍（「就怎样」＋「照那样」），句子累赘。
  - 建议：「衣服等资具怎样大量地生起，他就照那样趋附、照那样过活」改为「……他就随之趋附而行」。

- `181-321-33-40`｜关键词语意不明确｜片段「异分的色」
  - 问题：`visabhāgarūpa` 在此指**异性的容色**（见异性色而障禅），直译「异分的色」对读者不成话，属二意场合且未加注。
  - 建议：改为「异性的色相」，首次出现夹注巴利原词。

- `181-321-53-87`｜整句逻辑表达不规范｜片段「是指：无常随观」
  - 问题：「七种随观……是指：」后面直接跟出 18 项清单，首读极易误解为「七随观＝这 18 项」，靠句末破折号才能纠回。
  - 建议：调整为「这里的七种随观，是指下列十八种大观中最先说到的七种——（列出十八项）——即从无常随观到舍遣随观的那七种」。

- `181-322-2-9`｜整句逻辑表达不规范｜片段「因为他不曾习惯于烦恼」
  - 问题：lemma `Anāsevanatāya` 只是「由于没有习染」，译文增补了原词没有的「烦恼」与主语「他」，并把名词短语改写成因果小句，与其余条目的 lemma 体裁不一；且 `āsevana` 在同句内先译「习惯」后译「习染」。
  - 建议：统一为「**因为没有习染**，就是说前一世已用禅镇伏了烦恼的人，没有欲贪等的习染」，并与义注该词的译法核对后定稿。

- `181-322-56-59`｜不导致误解的汉语语病｜片段「这都是不可能的」
  - 问题：`etaṃ` 是单数，「都」无据，且此处只说一事。
  - 建议：改为「**这是不可能的**」。

- `181-323-2-5`｜关键词语意不明确｜片段「就是生起贪的」
  - 问题：`rāgajanaka` 是「能使贪生起的」，译文「生起贪的」后缺中心语，也可被读成不及物的「（它自己）生起贪」。
  - 建议：改为「就是**能引生贪的（所缘）**」。

- `181-323-31-36`｜文言语体｜片段「善法生起之道」
  - 问题：文言虚词「之」。
  - 建议：改为「不能成为善法生起的道路的作意」。

- `181-323-42-53`｜文言语体｜片段「作为转向之缘」
  - 问题：文言虚词「之」。
  - 建议：改为「作为转向的缘」。

- `181-324-25-31`｜文言语体｜片段「即舍离了本来状态的样子」
  - 问题：文言虚词「即」，且原文 `pakativijahanabhāvo` 并无「即」字，属增译；此句是义注引文，应与义注逐字同译。
  - 建议：改为「**就是舍离了本来状态的样子**」，并与义注原译核对。

- `181-323-78-80`｜整句逻辑表达不规范｜片段「因为它注意，所以叫做**注意**」
  - 问题：以「注意」释「注意」，词源训释在汉语里成了空转，读者得不到任何信息。
  - 建议：改为「因为它把所缘总摄拢来，所以叫做**总摄**（samannāhāra）」，或保留「注意」但夹注巴利原词并点明这是词源训释。

- `181-323-81-89`｜整句逻辑表达不规范｜片段「让那同一个所缘随逐自己而放到心里」
  - 问题：`attānaṃ anubandhitvā` 的连续体主语按常规应与主句主语一致，译文却把它的主语定为「所缘」，句法关系混乱，读者难以理解「让所缘随逐自己」指什么。
  - 建议：核对 nissaya 的格助词后重译，如「因为它在生起时随逐自身，把那同一个所缘放在心里、安置于心，所以叫做**作意**」。

- `181-323-90-99`｜不导致误解的汉语语病｜片段「这种以不恰当、走上邪路的作意为特征的，就叫做不如理作意」
  - 问题：「……为特征的」后缺中心语，句子悬空。
  - 建议：补出中心语：「这种以不恰当的作意、走上邪路的作意为特征的**作意**，就叫做不如理作意」。

### 🟦 suggestion
- `181-323-73-77`｜该使用而没有使用术语标记｜片段「所以叫做**专注**」
  - 问题：`āvajjanā / anvāvajjanā / ābhoga / samannāhāra / manasikāra` 这一组阿毗达摩术语全程无巴利夹注，与 `knowledge/style.md`「法相术语首次出现夹注巴利原词」不符；这组词汉译彼此相近（转向/随转向/专注/注意/作意），无原词读者难以分辨。
  - 建议：每词首次出现加圆括号夹注，如「**专注**（ābhoga）」「**注意**（samannāhāra）」。

- `181-324-32-40`｜不常用术语编写注释｜片段「所以叫做**瞋恚**」
  - 问题：`byāpatti`（变质）/`byāpajjana`（变坏）/`byāpāda`（瞋恚）同根，这段复注的论证正是靠词根把「食物变质」推到「瞋恚」；三词译成不同汉语后，读者看不出推论依据。同段又以「瞋」译 `paṭigha`，与「瞋恚」易混。
  - 建议：在 `byāpādo` 处夹注「**瞋恚**（byāpāda，字面即『变坏』）」，并在 `paṭigha` 首次出现处夹注原词。

- `181-321-2-16`｜语言表达不够流畅｜片段「受持十三种头陀支的功德来生活」
  - 问题：「受持……功德」搭配不顺，`samādāya vattati` 是「受持而行」。
  - 建议：改为「受持十三种头陀支的德目而生活」。

- `181-321-33-40`｜复杂的嵌套句整句语言逻辑理解困难｜片段「由于看见异分的色等某种造成禅的障碍的相而退失了禅」

  - 建议：拆开：「就是由于见到异性的色相等某种会障碍禅的因缘，因而退失了禅」。

- `181-323-6-13`｜语言表达不够流畅｜片段「把无常的等等看作常的等等」

  - 建议：改为「对无常等（法）作常等的颠倒作意」。

- `181-322-16-22`｜代词指代可能不够明确｜片段「**生了**，**生成了**等等就是这个词的同义语」
  - 问题：「这个词」需回指句首的 lemma，被逗号隔断后指代不够清晰。
  - 建议：改为「**生了**——**生成了**等等就是它的同义词」。
