# Review — 84:89-100（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过；本次仅做 nissaya 词法复核）

## 跨段一致性

- **parihāni**：§95、§97、§99 首句里，同一个 parihāni 在同一句中出现两次，却译成两个词。复合词 ñāti-/bhoga-/yaso-parihāni 译作「减少」，独立的 esā parihāni 译作「退失」；次句 paññāparihāni 又译作「退失」。nissaya 三处一律用同一个词 `ယုတ်လျော့ခြင်း / ဆုတ်ယုတ်ခြင်း`（衰损）。原文是有意重复同一个词（esā parihāni yadidaṃ X-parihāni），对照的 §96、§98 vuddhi 一律译「增长」，两处显得不对称。
  - 建议：parihāni 在这三经里统一用一个词，例如「损失」：「亲属的损失只是微小的损失……在各种损失中，智慧的损失才是最下劣的」。
- **na gacchanti**：§93 两句都用「不能达到」，同句前半的 nuppajjanti 却用「不会生起」。nissaya 两处都是单纯否定（`မဖြစ်ကုန်` 不生／`မရောက်တော့ကုန်` 不达），没有「能力」义。
  - 建议：统一为「不会达到」，与「不会生起」平行，也与 §94「会达到」对应。
- **ceva … ca**：§93、§94 次句的后半加了「也」，§90、§91、§92 次句同样是 ceva…ca 结构却没有加。
  - 建议：要么五经都加，要么都不加（不加更贴近前五经的已有体例）。

## §95 句 84-95-2-16

- **问题**：一词两译。见跨段一致性 parihāni 条。nissaya 把 `ဧသာ ပရိဟာနိ= ထိုဆွေမျိုးတို့ယုတ်လျော့ခြင်းသည်`（这亲属的衰损〔主格〕）与 ñātiparihāni 视作同一个主语，谓语只是 `အပ္ပမတ္တိကာ`（微小）。
- **建议**：「比丘们，亲属的损失只是微小的损失。」

## §99 句 84-99-2-16

- **问题**：取义不符（必改）。nissaya：`ယသောပရိဟာနိ= အကြင်အခြံအရံ ဆုတ်ယုတ်ခြင်းသည်`，yasa 取「随从、部众」（အခြံအရံ）义，不取「名声」义；次句 nissaya 也作 `ထိုအခြံအရံ ဆုတ်ယုတ်ခြင်းသည်`。译文「名声的减少」取了别义，没有依据。
- **建议**：「比丘们，随从的损失只是微小的损失。」（同时按 parihāni 统一的译法处理）

## §96 句 84-96-25-31（§98 句 84-98-26-32 同）

- **问题**：漏译（可选）。nissaya 分出 `ဣဟ= ဤသာသနာတော်၌`（在这教法中），即 tasmātiha = tasmā + iha，译文只译了 tasmā。
- **建议**：可译作「所以，比丘们，在这里你们应当这样学——」。若全书体例一律省略 iha，就保持现状，但要全书统一。

## §96 句 84-96-38-48（§98 句 84-98-39-48 同）

- **问题**：语气略弱（可选）。nissaya：`ဧဝံဟိ= ဤသို့နှလုံးသွင်း၍သာလျှင်`，hi 作强调（「正是这样」）。译文与前面的「你们应当这样学——」完全同形，强调义没有体现。
- **建议**：「比丘们，你们正应当这样学。」

## 资源数据疑问（不改译文，记录备查）

- **84-90-34-51**：nissaya 末尾混入 `အကုသလာနံ= … ဓမ္မာနံ= တရားတို့ကို`，这是 §91 的 akusalānaṃ dhammānaṃ，本句没有这个词。
- **84-92-2-38**：所附 nissaya 是「akusalānaṃ … anuyogā / kusalānaṃ … ananuyogā」，与 §91 次句（84-91-39-62）一致，与本句（kusala 致力、akusala 不致力）正好相反，不能用来核对本句。它倒是印证了 §91 次句 anuyogā 作从格（`အားထုတ်ခြင်းကြောင့်` 由于致力），现译「由于致力于」不误。
- **84-95-17-28**：nissaya 里夹着一段关于 bojjhaṅga 词源的代码块，属于 §93，挂错了位置。
- **84-99-17-28**：nissaya 内容是首句（esā parihāni … appamattikā）的重复，而且重复了两遍，本句没有可用的 nissaya。
