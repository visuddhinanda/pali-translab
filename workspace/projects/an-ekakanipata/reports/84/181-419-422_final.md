## 理由

**基准缺失（降级说明）**：本次注入只有巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**，且不允许调用工具取数。因此准确性核对只能依据巴利原文本身、段内论证链条（a- 的各类 nivatti 逐条对照）、以及 Dhammasaṅgaṇī 母题与 AN/MN/DN/Jā 出处的通行理解完成。**「被解释词（黑体）与父层逐字同译」这条硬约束本次无法验证**——419 的品名、420/421 的 `assutavā`、422 的 `uggaho / puripucchā / vinicchayo / āgamo / adhigamo` 是否与义注黑体词逐字一致，须在取到义注文本后复核；信心指数因此压到 62。

**准确性**：这是一段纯语法分析文字（`-vā` 后缀的三种用法 + 否定前缀 `a-` 的十余种 nivatti），最易出错的地方是每条「否定什么」的归类，译文逐条都对得上：`taṃsamāyoga`（结合）/ `taṃsambandhibhāva`（关联）/ `taṃsabhāva`（自性）/ `taggahetabbatā`（可被取）/ `taṃkicca`（作用）/ `tabbhāvamatta`（单单成为）/ `taṃsambhāvanīyaguṇa`（应具的德）/ `tadanappabhāva`（多→表少）/ `taṃsadisabhāva`（相似）/ `tadapariyosāna`（未完成），且每条后面的「因为…」论据句都与被否定项扣得住。421-188-215 的 `tadanappabhāva` 译出「否定该事物之多——也就是表示“少”，而不是“没有”」，把这条最易译反的加了正确的解释性补足；421-233-248 的四重理由（过去曾生、将生法部分缘已成、离时法现存、现在法更不必说）层次未乱；421-249-265 与 266-273 的「否定未完成／表明已完成」前后自洽。未发现主谓宾判断错误或违背教理的句子，**无 fatal、无 error**。

**存疑但不扣分的两处分歧**：
- `181-421-82-100` 的 `tathā ‘‘anāsavā dhammā’’ti`，译文按底本语序归入前一句的「可被（眼识）取之否定」。按义理 `anāsava` 更像是「否定与漏的结合」（`taṃsamāyoga`），此处归属在原文即有歧义，译文跟随语序是稳妥选择，不扣分，记作分歧。
- `181-422-80-82` 底本作 `puripucchā`，疑为 `paripucchā` 之讹；译文按 `paripucchā` 处理为「遍问」，合理，建议记入 `knowledge/known-issues.md` 的原文讹误一节。

**风格**：整体是现代书面汉语，禁例表里的文言虚词与句式基本没有出现（「于…之际」「便」「遂」「彼等」「此中」等零命中），全角标点与 “” 引号统一，无 ASCII 引号（JSON 安全）。扣分集中在三类：一是 421-233-248「所了知的是…相离」这类半文半白的佛典腔；二是同一句里「法则是」造成的汉语切分歧义；三是序号与括号嵌套的体例问题。

**一致性**：核心对译前后统一——`āgamo`＝传承所学、`adhigamo`＝自身证得，在 421-316-325 的偈颂与 422-89-101 的解释里完全一致，这是本段最关键的一致性要求，做到了；夹注策略（samaṇa / paccayākāra / sutamayañāṇa / asekkha / dukamātikā / tikamātikā 首次出现附原词）也贯彻。扣分在两处：419 品名序号用「六、」而 420 经号用「五十一。」；同一概念 `tadaññatā`（421-138-142「与那个东西不同」）与 `aññatthe`（421-274-308「别的」）译法脱节。

## 问题清单

### 🟨 warning
- `181-421-233-248`｜不导致误解的汉语语病（切分歧义）｜片段「超出时间范围的法则是现有的」
  - 问题：「法则是」易被读成名词「法则」，读者需回读才能断成「法／则是」。
  - 建议：改为「超出时间范围的法，本来就是存在的」。
- `181-421-233-248`｜文言语体｜片段「所以这里所了知的是与那种相似性相离」
  - 问题：「所了知的是…相离」是半文半白的佛典腔，现代读者会觉得像古文。
  - 建议：改为「所以这里要表达的是：它与那种相似性并不相同」。
- `181-421-183-187`｜不导致误解的汉语语病｜片段「因为这里所了解到的是责备」
  - 问题：「所了解到的是责备」句式生硬，与前后同型句（「这里指示出来的是相似」）一样属被动名物化堆叠。
  - 建议：改为「因为这里要表达的是责备」。
- `181-421-274-308`｜关键词语意不明确｜片段「意思就是“别的”」
  - 问题：`aññatthe` 译作「别的」过于笼统，读者无法知道「别的」指什么；且与 `181-421-138-142` 的「与那个东西不同」是同一概念却两种译法。
  - 建议：改为「意思就是“与有听闻的人不同”」，并与 138-142 的措辞统一。
- `181-420-113-124`｜整句逻辑表达不规范（冗余多译）｜片段「并且按照听来的内容把该做的事情做成」
  - 问题：`kattabbanipphattivasena` 只有「以成办应作之事的方式」，「按照听来的内容」是额外添加，且与同句前半的「听了应当听的内容」重复。
  - 建议：改为「并且以成办应作之事的方式去听」。
- `181-421-2-29`｜标点符号使用错误｜片段「（《法集论》二法母（dukamātikā）2）」
  - 问题：同型全角圆括号嵌套，层级看不清。`181-421-216-232` 的「（《法集论》三法母（tikamātikā）17）」同。
  - 建议：内层改用方括号或把夹注移出，如「（《法集论》二法母 dukamātikā 2）」。
- `181-420-2-32`｜标点符号使用错误｜片段「五十一。第六品的第一经中」
  - 问题：经号后用句号，读起来像上一句结束；且与 `181-419-2-4` 的「六、《弹指品》的注释」体例不一致。
  - 建议：统一为「五十一、第六品的第一经中」或保留阿拉伯数字「51.」。
- `181-422-2-13`｜代词指代不明确｜片段「他说了」
  - 问题：全段首次出现的「他」未交代所指（义注作者），读者会误以为指前句偈颂中的「没有听闻的人」。
  - 建议：改为「义注接着说了…」或「注释者说了…」。

### 🟦 suggestion
- `181-420-53-112`｜复杂并列对读者不友好｜片段「能够摧毁烦恼的、对圣典教法的听闻」
  - 问题：两个定语之间用「、」，而下文又有「以及…修行」的真并列，易被误读为两项。
  - 建议：改为「能摧毁烦恼的圣典教法听闻」。
- `181-421-54-70`｜该使用而没有使用术语标记｜片段「无见的诸法」
  - 问题：`anidassana` 属罕见法相术语，首次出现未夹注原词；同段「无对的诸法」（appaṭigha）、「无所缘的诸法」（anārammaṇa）同。
  - 建议：首次出现各附巴利原词，与 asekkha 的处理保持一致。
- `181-421-233-248`｜不常用术语缺注｜片段「超出时间范围的法」
  - 问题：`kālavinimutta`（离时法）指涅槃与概念法，不加注读者无从判断所指。
  - 建议：夹注原词并加一句简注。
- `181-422-89-97`｜语言表达不够流畅（同位关系被压缩）｜片段「领会传承下来的义与法」
  - 问题：`atthadhammānaṃ āgamanaṃ` 与 `sutamayañāṇavasena avabujjhanaṃ` 是两个同位主语，译文把前者降为定语，`āgamanaṃ`（传来）与被定义词 `āgamo` 的同源呼应随之消失。
  - 建议：改为「义与法的传来，也就是以闻所成智（sutamayañāṇa）对它们的领会」。
- `181-422-76-79`｜语言风格不统一｜片段「习诵受持」
  - 问题：其余黑体词都是对应单一巴利词的固定译名（遍问／抉择／传承所学／自身证得），此处用双译名并置。
  - 建议：单译为「受持」，并在取到义注后确认与义注黑体词逐字一致。
- `181-420-2-32`｜语言风格不统一｜片段「-vā 这个语尾」
  - 问题：下文一律作「a 字头」「这个字头」，此处用「语尾」，两处术语体例不齐。
  - 建议：统一为「-vā 这个词尾」与「a- 这个词头」。
