## 问题清单

### 🟨 warning

- `99-1506-2-18`｜关键词语意不明确（兼待核对被解释词同译）｜片段「**恶劣的**」
  - 问题：`pāpaka` 作为被解释词译为「恶劣的」，不是法相常规用语（通行作「恶的」，在本文层多作「恶不善法」的一部分）。本文层译文未注入，无法确认是否与母层逐字同译；若母层作「恶的」，此处即违反被解释词同译的硬约束。
  - 建议：与本文层 `anuppannānaṃ pāpakānaṃ akusalānaṃ dhammānaṃ` 的译法比对后统一，倾向改为「恶的」；该字在本段出现两次（另见 `99-1506-19-32`），须一并改。

- `99-1506-43-59`｜文言语体｜片段「那领受了所缘之味而后灭去的异熟」
  - 问题：「之」作文言虚词、「而后」为半文半白，属 `knowledge/style.md` 第一节禁例。
  - 建议：改为「那领受了所缘的味以后灭去的异熟」。

- `99-1506-43-59`｜关键词语意不明确，二意场合没有注释｜片段「当业已经速行之后」
  - 问题：两重问题。一是「速行」（javana）是阿毗达摩专名，此处无夹注，普通读者无从理解「业速行」是什么；二是「业已经」四字连读容易被误解为副词「业已」，造成「业已经速行」的歧义。
  - 建议：加夹注并断开歧义，如「在业的速行（javana，即造业的心的运转）发生之后」。

- `99-1506-19-32`｜关键词语意不明确｜片段「受用后已过去的已生」
  - 问题：`bhutvāvigata` 的 `vigata` 是「灭去／离去」，译作「已过去」弱化了「灭」义；更要紧的是，1508—1509 整段正在辩论烦恼是不是「过去的（atīta）」，同一报告段内「已过去」与「过去的」撞词，读者会误以为 `bhutvāvigatuppanna` 就是「过去的已生」，而原文恰恰要把二者分开（前者非道所断，后者不可说）。
  - 建议：改为「受用后已灭去的已生」或沿用通行译「受用已灭已生」；`99-1506-60-65`、`99-1508-2-26` 的同一名目须同步改。

- `99-1509-2-8`｜整句逻辑表达不规范（兼标点）｜片段「如果说他舍断过去的烦恼，」
  - 问题：`Hañci atīte kilese pajahati?` 是《无碍解道》设问—破斥体的设问句，原文带问号；译文改写成条件分句并以逗号接下句，设问—破斥的论辩结构被抹平，读者看不出这是被破斥的假设。`99-1509-27-31`、`99-1509-49-53` 同此处理。
  - 建议：保留设问，如「难道他舍断的是过去的烦恼吗？」下句以「若是这样，他就是在……」承接，三处一致。

- `99-1506-19-32`｜该使用而没有使用术语标记｜片段「正在进行的已生、受用后已过去的已生」
  - 问题：八个「已生」名目是本段的论述骨架，首次出现均未夹注巴利原词（另见 `99-1507-2-13`），与 `style.md` 第二节「法相术语首次出现夹注巴利原词」不一致；本段内 `vipassanā` / `bhūmi` / `samāpatti` / `bhavagga` / `anusaya` 都有夹注，更显突出。
  - 建议：在 `99-1506-19-32` 与 `99-1507-2-13` 的列举处为八名目各夹注一次巴利原词（vattamānuppanna / bhutvāvigatuppanna / okāsakatuppanna / bhūmiladdhuppanna / samudācāruppanna / ārammaṇādhiggahituppanna / avikkhambhituppanna / asamugghātituppanna），其后只用汉译。

- `99-1509-9-26`｜语言风格不统一｜片段「舍断那已经过去、并不存在的烦恼」
  - 问题：与 `99-1509-32-48` 的「舍断那还没有到来、并不存在的东西」完全平行，宾语却一处补「烦恼」一处补「东西」，削弱了引文三段齐整的归谬节奏。
  - 建议：两处统一补「烦恼」。

- `99-1509-9-26`｜语言表达不够流畅｜片段「把已经灭去的再灭去，把已经消失的再消灭」
  - 问题：`niruddhaṃ nirodheti` 与 `atthaṅgataṃ atthaṅgameti` 是两组不同的同根动词，译文「灭去／消灭」用词相近，三组的层次（尽—灭—没）区分不明显。
  - 建议：如「把已经灭尽的再去灭尽，把已经灭去的再去灭去，把已经消没的再去消没」，三组各用一组同形词。

- `99-1507-20-31`｜代词指代可能不够明确｜片段「在每一次回忆起它的时候」
  - 问题：「它」可指眼睛、所缘或所取之相，原文 `anussaritānussaritakkhaṇe` 回忆的对象是先前所取的「相（nimitta）」。
  - 建议：改为「在一再回忆起那个相的每一刹那」。

- `99-1509-32-48`｜语言表达不够流畅｜片段「舍断还没有出生的」
  - 问题：`ajāta` 对译「出生」带生物义，与后面 `anibbatta`（还没有产生）/`anuppanna`（还没有生起）的抽象层次不齐。
  - 建议：改为「舍断还没有生的」。
