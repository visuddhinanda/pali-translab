## 理由

**资源降级（影响信心）**：本次只注入了巴利原文与 channel 现有译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此准确性判断只能依据巴利形态、上下文与对举结构，无法按「义注定释义、nissaya 定词法」逐句核对；凡属取义分歧（如 `atikhiṇa`、`samattha`、`saṅkhārapiṭaka` 书名）的判定均为形态/语境推断，已在条目中注明。另外本段为复注（ṭīkā），**黑体被解释词是否与义注逐字同译无法核验**——这是硬约束，建议补入义注原文后再核一遍 harmonize 的结果。

**准确性**：整体忠实，缺词漏译极少，长句的格与修饰关系处理稳妥（`1148-12-27` 的 `sasādīhi viya mahāsamuddo … alabbhaneyyappatiṭṭhesu khandhesu` 双层比较、`1144-2-10` 的 `ajjhatta-bahiddhā-bheda / santāna-bheda` 两重区分都译对了）。扣分集中在三处词义与指代：`1149-44-61` 把 `abhisambhavituṃ` 的对象译成「他」（原文所企及者是前句的 paññā，非人）；`1149-17-37` 把 `samattha`（有能力、胜任）译作「相等」；`1142-141-164` 的 `atikhiṇo` 按「极尖」处理，与全列「白/黑、光滑/粗糙、直/弯」的对举格式相悖，形态上 `a-+tikhiṇa` 更可取（`ati+tikhiṇa` 当作 `atitikhiṇa`）。`1145-14-18` 的「本身没有意义」属正文增译。

**风格**：主体是合格的现代书面汉语，没有「此中/故为/彼等」一类成片文言腔，引号与括号一律全角，`zh` 字段内未发现 ASCII 引号，无残留工作标记（候选/待定/TODO），符合 `knowledge/style.md` 第七节。扣分点：`通于四地`（两处）用文言虚词「于」；`1149-2-16` 的「它不在旁边」、`1149-38-43` 的「由于能分别辨定义」（汉语易误读为「定义」）属表达生硬或歧义；`1142-55-88` 的「这棵树的是黑的」省略中心语，句子残缺。

**一致性**：术语与句式骨架高度统一——`puthu`→「为数众多」、`nānā`→「种类各别」、`ñāṇaṃ pavattati`→「有智运转」、`ñāṇa`/`paññā` 分别固定为「智」/「智慧」，1142–1143 的平行段落用了同一模板，这是本批最好的一面。失一致仅两处：`1142-55-88` 把同一谓语另译为「才这样知道」（与 `141-164` 的「而有智运转」构成同一谓语两译）；`1146` 组黑体引词在「在…上」与「法上/词上」两种形式间摆动。

**术语夹注**：首现夹注策略执行到位（upādinnadhātu / upacāra / padasandhi / vipula / mahanta）。但 `1142-17-33` 夹注写作 `cātubhūmaka`，该段原文形是 `cātubhūmikā`；`paṭibhāna`→「辩才」属不常用术语，首现未夹注。

## 问题清单

### 🟧 error

- `181-1149-44-61`｜代词指代错误｜片段「以智的运行达到他」
  - 问题：原文 `ñāṇagatiyā sampāpuṇituṃ` 所企及的是前句的 `paññā`（这智慧），不是某个人；译作「他」使指代落到人身上，且用「他」称智慧不通。
  - 建议：「没有任何别人能够凭智的运行企及它」。

- `181-1149-17-37`｜错译（词义）｜片段「没有任何可与它相等的（samattha）」
  - 问题：`samattha` 是「有能力、胜任」，非「相等」（相等当作 `sama`）；`kāyaci` 为阴性，所指是别人的慧。现译把「无人有此能力」改写成「无物与之相等」，并把末句的「无可相等的智慧」一并带偏。
  - 建议：「没有任何别的智慧有能力（samattha）与它相比，所以叫做无能相比的智慧」。

- `181-1142-141-164`｜错译（词义）｜片段「极尖的」
  - 问题：`atikhiṇo` 宜析为否定前缀 `a-` + `tikhiṇa`（不尖、钝）；若取「极尖」，形态上应是 `atitikhiṇa`。且本段整列为对举（白/黑、光滑/粗糙、厚皮/干皮、直/弯、青/红/白），「尖/极尖」破坏了对举。
  - 建议：改作「钝的」。**（无 nissaya/义注可核，属形态与对举推断；补入 nissaya 后请复核再定。）**

### 🟨 warning

- `181-1142-17-33`｜文言语体｜片段「两界通于四地」
  - 问题：单音节文言虚词「于」，违反 `style.md` 第一节总原则。
  - 建议：「另外两界则遍及四地」。

- `181-1143-17-31`｜文言语体｜片段「两处通于四地」
  - 问题：同上，平行句同一问题。
  - 建议：「另外两处则遍及四地」。

- `181-1142-55-88`｜不导致误解的汉语语病｜片段「这棵树的是黑的」
  - 问题：承上省略中心语，句子残缺（后续「这棵树的是光滑的」「这棵树的是粗糙的」同病）。
  - 建议：补出中心语「这棵树的树干是黑的／是光滑的／是粗糙的」。

- `181-1142-55-88`｜整句逻辑表达不规范｜片段「才这样知道」
  - 问题：本句无自身谓语，谓语 `ñāṇaṃ pavattati` 落在 `141-164`，那里已译为「而有智运转」；现译等于把同一谓语译了两次，且与全段固定译法不一致。
  - 建议：改为引出引语的说法（「而只有一切知者（sabbaññu）诸佛，才在外在未被执取的界的差别上——『由于这一界增强……』」），谓语留给末句。

- `181-1145-14-18`｜整句逻辑表达不规范（正文增译）｜片段「本身没有意义」
  - 问题：原文仅 `padasandhikaro`，无此断言；属译者补充的语法说明，不宜进正文。
  - 建议：删去，或移入脚注（归 pali-footnote 处理）。

- `181-1149-2-16`｜关键词语意不明确｜片段「对别人的智慧来说它不在旁边」
  - 问题：`na sāmantā` 意为「不与（他人的慧）相邻近」；「不在旁边」字面化，现代读者难解，与后半「而是极远」的对照也立不起来。
  - 建议：「别人的智慧根本挨不上它，而是相距极远、远之又远」。

- `181-1149-38-43`｜关键词语意不明确｜片段「由于能分别辨定义」
  - 问题：汉语会被断成「辨／定义」，读成 definition 之义，与 `atthavavatthāna`（对义的分际作确定）相悖。
  - 建议：「**由于确定了义的分际**：就是由于对义的种种差别作了如实的判定」。

- `181-1149-44-61`｜关键词语意不明确｜片段「这智慧是非常遥远的」
  - 问题：未点出「远」的对照方（远离他人的慧），孤立读来不知远于何物。
  - 建议：「所以这智慧远在他人之外，极远、极远」。

### 🟦 suggestion

- `181-1142-17-33`｜不常用术语注释不准｜片段「（cātubhūmaka）」
  - 问题：该段原文形作 `cātubhūmikā`，夹注与原文形不一致（`1143` 段才是 `cātubhūmakā`）。
  - 建议：夹注改为 `cātubhūmika`，或统一标注词干形并说明。

- `181-1142-55-88`｜该使用而没有使用术语标记｜片段「一切知（sabbaññu）的诸佛」
  - 问题：`sabbaññu` 是「一切知者」，作定语时「一切知的诸佛」略生硬。
  - 建议：「一切知者（sabbaññu）——诸佛」或「一切知的佛陀们」。

- `181-1142-110-140`｜语言表达不够流畅｜片段「果实是小的、大的」
  - 问题：与上下文句式脱节（上下句均以「这棵树的…」起）。
  - 建议：补「这棵树的果实是……」。

- `181-1146-9-13`｜语言风格不统一｜片段「**法上**」
  - 问题：同组条目在「在为数众多、种类各别的…上」与「法上／词上」（见 `181-1146-14-21`）之间摆动。
  - 建议：统一为「**在（种种）法上**」「**在（种种）词上**」。

- `181-1147-16-27`｜语言表达不够流畅｜片段「在它上面应当依假说（upacāra）的方式来理解」
  - 建议：「对它应当按假说（upacāra）来理解『为数众多』」。

- `181-1145-2-13`｜复杂的嵌套句整句语言逻辑理解困难｜片段「也正因为如此，这些法就女人、男人、我、我所等等来说是不可得的——也就是在这样自性不可得的法上」
  - 问题：一句内三层定语加破折号回指，读者需二次回读。
  - 建议：拆为两句，第二句另起「这些法就女人、男人、我、我所等等来说都是不可得的；黑体所指便是这样自性不可得的法。」

- `181-1147-2-15`｜语言表达不够流畅｜片段「所以本来就很清楚了」
  - 问题：与前半「就容易了解」语义重复（`suviññeyyattā` 与 `pākaṭa` 叠加）。
  - 建议：「其余各项依已说的方式即可推知，意思自然清楚」。

- `181-1146-22-36`｜不常用术语编写注释｜片段「辩才」
  - 问题：`paṭibhāna` 作无碍解之一，首现未夹注巴利原词，与本批其他术语处理不齐。
  - 建议：「**在为数众多、种类各别的辩才（paṭibhāna）上**」。
