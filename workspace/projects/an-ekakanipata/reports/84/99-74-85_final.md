## 理由

**基准缺失说明**：本次评估对象本身即义注层（aṭṭhakathā），其上位释义标准应为复注（ṭīkā / Līnatthappakāsinī），本次未注入；nissaya 亦未注入。因此词级格位与传统取义只能依巴利原文与义注内部自洽性判断，信心指数相应下调。以下判定凡涉及词法处，均以原文形态与本段义注自身给出的词义定义（`paṭilābho` / `pahānaṃ` / `paṭivedho` / `kālo attho`）为准。

**准确性**：整体句法解析可靠。长句部分表现好——99-77-27-74 的 `na sakkā ... dhāretuṃ vā uddisituṃ vā uddisāpetuṃ vā` 三重不定式与使役区分准确；99-79-89-113 的 `bhāvena bhāvalakkhaṇa` 概念、99-80-9-29 的 `hetubhūtena karaṇabhūtena` 双重具格、`paññāpayanto ... apekkhamāno` 双现在分词并列都处理到位；99-78 十类 samaya 与四组二分对举无漏无错。主要失分集中在一处：义注引经以证 `samaya` 的多义（获得 / 舍断 / 通达），而译文把三条引文里的 `abhisamaya` 一律译作固定术语「现观」，随后紧接「它的意思是获得 / 舍断 / 通达」，论证链在汉语里断裂，读者看不出引文何以支持该释义；其中「现观了我慢」一条还与义注自身给出的 `pahānaṃ` 直接相悖。

**风格**：主体是通顺的现代书面汉语，未见「此中／故为／彼等／于…之际」一类禁例，语法术语（处格／具格／业格）使用规范一致。扣分处为个别半文半白残留（「现法之乐」的「之」、「以悲悯而住」的「以…而住」）及一处非规定括号「〔〕」。

**一致性**：被解释词与三层对齐良好——`ekaṃ samayaṃ` 全段统一作「有一次」，`porāṇā / porāṇehi` 统一作「古代的师长们」，99-85 黑体 `Bhagavā` 保留且译「世尊」。较弱的是 `samaya` 作词项被论及时在「时间 / “时” / ‘时’」之间游移。全段未见工作标记残留，未见 ASCII 引号，JSON 安全无虞。

## 问题清单

### 🟧 error

- `99-76-14-33`｜义理或用词与注释书不符｜片段「由于正确地现观了我慢而终结了苦」
  - 问题：义注引此句正是为说明此处 `samaya` 取 `pahānaṃ`（舍断）义，译文却作「现观了我慢」，与紧随其后的「它的意思是舍断」自相矛盾；且「现观我慢」在汉语佛教语汇中不成立——我慢是所断，非所现观。
  - 建议：按义注所定之义译出，如「由于彻底断尽我慢而终结了苦」，并可在括号内附 `mānābhisamayā`，使「舍断」的释义有着落。

- `99-75-2-10`｜导致误解的表达｜片段「由于现观（abhisamayā）了这些利益」
  - 问题：此偈是义注为「`samaya` = 获得（paṭilābha）」所举的例证，译作「现观」后，下一句「它的意思是获得」失去依据，论证无法成立。另夹注给的是夺格屈折形 `abhisamayā`，非词干形。
  - 建议：译为「由于获得（abhisamaya）了这些利益」，或保留「现观」但补括注说明此处义注取「获得」义；夹注一律用词干形 `abhisamaya`。

### 🟨 warning

- `99-76-2-13`｜代词指代不明确｜片段「它的意思是获得」
  - 问题：「它」所指的被解释词 `samaya` 在本句及上文译文中从未露面（上文只出现「有一次」），读者无从回指。同一模式贯穿 99-76 全段。
  - 建议：首次出现处点明主语，如「在这样的经文（《相应部》1.129）等处，“时”（samaya）的意思是获得」，其后再用「它」。

- `99-76-57-61`｜关键词语意不明确｜片段「而在这里，它的意思是时间。」
  - 问题：同上，「它」无先行词；且此句是全段释义的落点（`idha panassa kālo attho`），承担转折功能，指代含混会削弱结构。
  - 建议：明写「而在这里，“时”取的是时间的意思。」

- `99-79-89-113`｜不导致误解的汉语语病｜片段「不论取作为处所的时间的意思」
  - 问题：原文 `Adhikaraṇaṃ hi kālattho samūhattho ca samayo` 是「取时间义与取聚集义的‘时’，都是依处」。译文把「处所」提前塞进「时间的意思」的定语里，造成「作为处所的时间」这一错误修饰关系，与句末「都是处所」重复打架。
  - 建议：改为「因为“时”无论取时间的意思还是取聚集的意思，都是依处（处所）」。

- `99-78-2-30`｜文言语体｜片段「安住于现法之乐的时候」
  - 问题：文言虚词「之」。
  - 建议：改为「安住在现法乐中的时候」或「安住于当下之乐」→「安住在当下安乐中的时候」。

- `99-81-9-23`｜文言语体｜片段「他整个那段时间都以悲悯而住」
  - 问题：「以…而住」为半文半白句式。
  - 建议：改为「他整段时间都安住在悲悯之中」。

- `99-79-2-68`｜标点符号使用错误｜片段「欲界〔善心生起〕」
  - 问题：补出成分用了「〔〕」，不在本项目规定的全角标点集内（，。、；：！？（）——）；夹注体例亦规定用全角圆括号。
  - 建议：统一改为「欲界（善心生起）」，或用破折号交代为译者补语。

- `99-79-2-68`｜整句逻辑表达不规范｜片段「反而不那样做，却用业格说了“有一次”来指示呢？」
  - 问题：全句已连用三个「不像…那样」，再加「反而不那样做」构成四重否定叠加，末端才出现正面陈述，句子过长且转折冗余。
  - 建议：把 `tathā akatvā` 并入转折，如「……为什么这里不采用以上任何一种，而用业格说“有一次”来指示呢？」

- `99-76-34-56`｜关键词语意不明确｜片段「有现观的意思」
  - 问题：义注随即判定此处 `samaya` 取「通达」义，译文却作「现观」，术语前后不咬合（与 99-75、99-76-14-33 同一问题的延伸，但此处「现观／通达」语义相近，危害较轻）。
  - 建议：译作「有通达的意思」，或保留「现观」并在括注中标出 `abhisamaya`。

### 🟦 suggestion

- `99-74-2-14`｜语言表达不够流畅｜片段「现法（diṭṭhe dhamme）中的种种利益」
  - 问题：原文 `yo attho` 为单数关系代词结构（「凡是…的利益」），「种种」属添加。
  - 建议：改为「凡是现法（diṭṭhadhamma）中的利益，以及凡是属于来世的利益」，与偈体的关系句式对应。

- `99-78-31-58`｜语言表达不够流畅｜片段「这是悲悯的事务的时候」
  - 问题：「的…的…的」三连，四组对举句皆用此模式，读来滞涩。
  - 建议：压缩为「这属于悲悯事务的时候」或「这是行悲悯之事的时候」（后者避免「之」则作「这是做悲悯之事…」→「这是施行悲悯的时候」）。

- `99-79-69-76`｜语言表达不够流畅｜片段「因为在那些地方是那样的意思成立」
  - 问题：「是…成立」结构生硬。
  - 建议：「因为在那些地方成立的是那样的意思，在这里成立的是另一种意思。」

- `99-81-9-23`｜语言表达不够流畅｜片段「因为世尊讲说这部经或别的经的那段时间里」
  - 问题：与后半句「整个那段时间」语义重复，`accantasaṃyoga`（全程持续）的强调反被稀释。
  - 建议：「世尊讲说这部经或别的经的那段时间，他自始至终都安住在悲悯之中。」

- `99-83-2-12`｜语言风格不统一｜片段「在别处说了‘时’」
  - 问题：同一被论及的词项 `samaya` 在全段出现「时间」「“时”」「‘时’」三种呈现方式，引号层级也随上下文变动。
  - 建议：统一为双引号「“时”（samaya）」，偈颂内因外层已有双引号方降为单引号，保持规则可预期。

- `99-85-6-15`｜语言表达不够流畅｜片段「在世间上」
  - 问题：「世间上」搭配不自然。
  - 建议：改为「在世间」或「在世俗用法中」（后者更贴合 `loke` 此处指世俗语用的语境）。

- `99-81-30-32`｜语言表达不够流畅｜片段「因此说了这样的话——」
  - 问题：`Tenetaṃ vuccati` 为「因此有这样的说法」，译文的「说了」引入了未指明的施事。
  - 建议：「因此有这样的说法——」或「因此说——」。
