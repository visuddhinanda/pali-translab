## 理由

**基准缺失（影响信心）**：本次只注入了巴利原文与 channel 译文。本层是复注（ṭīkā），其父层义注（aṭṭhakathā）与 nissaya 均未提供，因此无法执行「义注定释义、nissaya 定词法」的核对，也**无法验证「被解释词与父层逐字同译」这条硬约束**——所有黑体被解释词（如「以智慧为重」「以智慧为旗帜」「于饮食知量」）是否与义注/本文用字一致，这里判不了。准确性结论仅基于巴利原文的构词与句法自洽、以及译文内部互证，故信心压到 62；涉及引文（Paṭis. 1.114）与被解释词的几条，建议取齿母本再核一遍。

**准确性**：整体是直译路线，复注特有的「释词链」（X 是 Y，故名 Z）结构基本保住了，`assa`/`etassa` 的属格归属、`-vasena`/`-ṭṭhena` 的依格、`vā` 的异释分支都译对了；戒学一段（1162-40-54、55-65、73-102）术语与教理面处理得好（作持止持、四清净戒减根律仪、昼三夜二时分、沙门法）。扣分集中在三处：一是 1161-51-78 引《无碍解道》时把宾格现在分词 `sevantaṃ` 当成了 `jānāti` 的主语，施事判断错位（见 fatal）；二是 1160-127-134 把 `yāthāvato dassanadhammo sabhāvo` 的同位结构误读成「见这一法」，修饰关系错；三是 1160-2-12 用「以智慧为重」译 `paññābāhulla`，把 `bāhulla`（多）当成了 `garu`（重），词义错且与 1161 的「以它为重」（`taggaruka`）正面撞车。

**风格**：现代书面汉语达标，未见文言虚词与文言句式，无「此中/故为/彼等/是故」之类禁例，无残留工作标记，全角标点与弯引号合规，`zh` 字段内无 ASCII 引号，夹注巴利原词（paññābahula / sampekkhā / kalāpasammasana / samaṇadhamma）用法符合 style.md。唯一近似文言的是被解释词「于饮食知量」（`bhojane mattaññutā`），但它是黑体被解释词、须与父层逐字同译，逐字同译优先于语体偏好，**不扣分**；若父层并非此写法，再按「在饮食上知量」改。小瑕是个别处口语化（「弄明白」）和生硬的定语链（「自己作为智慧的工作」「以随顺的忍等等为区分的智慧」）。

**一致性**：`tanninna`→「倾向于它」、`adandha`→「不迟缓」、`sekkha/asekkha`→「有学/无学」等跨段一致，1160 的「以智慧为…」系列与 1161 的「以它为…」系列对位整齐，这部分做得好。失分在同一组被区分的近义词上：`vicinana` 在相邻两句分别译「辨别」与「简择」，使 `vicaya`/`pavicaya` 的区分变模糊；`okkhāyana`→「观察」与 `paccavekkhaṇañāṇa`→「观察智」同名；八种慧的命名体例不齐（迅捷/轻快/喜悦/锐利/洞穿是双字，`javanapaññā` 却作「疾速趣入的智慧」）。另有一类格式问题：译文照搬了原文的黑体标点（`**，**`、`**。**`）与引号黑体碎块（`**“****`），不影响阅读但不整洁。

## 问题清单

### 🟥 fatal
- `181-1161-51-78`｜主谓宾判断错误｜片段「尽管他正在享受欲乐，仍然知道」
  - 问题：`kāmaṃ sevantaṃyeva jānāti` 中 `sevantaṃ` 是宾格现在分词，是 `jānāti` 的**宾语**（被观察的那个人），知者另有其人（旁观者/能知者）。译文把享受欲乐的人当成了「知道」的主语，施事错位；连带使引文变成「正在享乐的人自己知道这个人看重出离」，指代混乱，也破坏了复注引此文要证的意思——看重出离是**前世以来的习性**，故旁人即便见其受欲，仍能判定其倾向。
  - 建议：改为「哪怕看到一个人正在享受欲乐，也能知道：这个人是看重出离的」之类，让知者与受欲者分开。**此条请对齿母本/义注后再定稿**。

### 🟧 error
- `181-1160-2-12`｜错译（词义）｜片段「以智慧为重」
  - 问题：`bāhulla` 是「多、丰盛」（由 `bahula` 派生），不是「重视」；本句前半已自译为「智慧多」，后半黑体却跳成「以智慧为重」，自相矛盾。更要紧的是复注在 1160-41-45 与 1161-20-29 明确区分 `garu`（重）与 `bahula`（多），此译使 `paññābāhulla` 与 `taggaruka`「以它为重」撞名，区分被抹掉。
  - 建议：统一为「慧多」或「智慧之多」，与下句「智慧的‘多’不过就是智慧的反复现起」接得上；并与父层被解释词用字核对。
- `181-1160-127-134`｜错译（修饰关系）｜片段「如实见这一法」
  - 问题：原文 `Sampekkhāyanaṃ vā yāthāvato dassanadhammo sabhāvo etassā` 中 `dassanadhammo` 与 `sabhāvo` 是同位语（「如实见的性质，即其本性」），`dhammo` 不是 `dassana` 的宾语。译文把 `dhammo` 读成「这一法」并当作「见」的对象，修饰关系错，还把同位结构拆成了两句主谓。
  - 建议：「或者说，审察的进行就是如实而见的性质，这是他的本性，所以叫做…」。
- `181-1160-75-79`｜导致误解的表达｜片段「同一个词的同义语」
  - 问题：`tasseva vevacanaṃ` 指「就是前面那个词（paññādhaja，以智慧为旗帜）的同义语」。译成「同一个词的同义语」逻辑上自指，读者无法得知所指为何，指代落空。
  - 建议：「**以智慧为标志**是前面那个（以智慧为旗帜）的同义语。」

### 🟨 warning
- `181-1162-2-17`｜不导致误解的汉语语病｜片段「很快完成自己作为智慧的工作」
  - 问题：`attano paññākiccaṃ` 是「自身慧的作用／该做的事」，「自己作为智慧的工作」把同位关系硬塞进定语，读来别扭。
  - 建议：「很快就把慧该起的作用完成」。
- `181-1162-159-161`｜关键词语意不明确｜片段「来势迅猛就是**迅速**」
  - 问题：`vegāyitatta` 是「有速度、急疾之性」，说的是慧的运作速度；「来势」凭空加入了方向与声势的意味，与被定义项「迅速」不对焦。
  - 建议：「运作迅疾就是**迅速**」。
- `181-1162-152-155`｜关键词语意不明确｜片段「急促的动作就是**迅捷**」
  - 问题：`turitakiriyā` 指「快速的作为」；「急促」偏贬义（慌忙），「动作」在描述慧时语域不合，和下两句「不迟缓」「来势迅猛」的句式也不齐。
  - 建议：「作为快速就是**迅捷**」。

### 🟦 suggestion
- `181-1160-85-94`｜语言风格不统一｜片段「对诸法自性的辨别」
  - 问题：同一个 `dhammasabhāvavicinana` 在本句作「辨别」、在紧接的 95-100 作「简择」，而这两句正是在区分 `vicaya` 与 `pavicaya`，用词摇摆会让区分读不出来。
  - 建议：两句统一用「简择」（或都用「辨别」），靠「以种种方式／遍」体现 `pa-` 的加强义。
- `181-1160-101-108`｜语言风格不统一｜片段「他这样的观察很多」
  - 问题：`okkhāyana` 译「观察」，与 1162-127-130 的 `paccavekkhaṇañāṇa`「观察智」同名，两个不同的词在同一章里共用一个汉语词。
  - 建议：`okkhāyana` 改「明察」或「审视」，把「观察」留给 `paccavekkhaṇa`。
- `181-1160-58-63`｜复杂的嵌套句理解困难｜片段「以随顺的忍等等为区分的智慧」
  - 问题：`anulomikakhantiādivibhāgā paññā` 是「有随顺忍等种类之分的智慧」，译文的「以…为区分的」定语套定语，读者难解。
  - 建议：「分为随顺忍等种类的智慧」。
- `181-1161-20-29`｜语言风格不统一｜片段「多修那智慧」
  - 问题：同句黑体作「**多行于它**」，前半的训释却用「多修」，`bahula`（多）被引入了「修」（bhāvanā）的义素，训释与被训释词脱节。
  - 建议：「他多行那智慧」，与黑体对齐。
- `181-1160-69-74`｜语言表达不够流畅｜片段「由于高举的意义」
  - 问题：`samussitaṭṭhena` 是「依高举之义（而说）」，「由于…意义」在汉语里像因果句，意思落空。
  - 建议：「就高举这一义来说，智慧是他的旗帜」。
- `181-1160-135-142`｜语言风格不统一｜片段「把一切法都弄明白」
  - 问题：「弄明白」偏口语，与全篇书面语域不一致。
  - 建议：「把一切法都照明、都辨明」。
- `181-1162-137-141`｜语言风格不统一｜片段「对疾速趣入的智慧的解说」
  - 问题：八种慧其余各名皆为双字（迅捷、轻快、喜悦、锐利、洞穿），`javanapaññā` 独作四字「疾速趣入」，命名体例不齐；`javana` 在论藏有既成译法。
  - 建议：统一为「速慧／捷慧」一类双字名，必要时首次夹注（javana）。
- `181-1162-142-151`｜不常用术语编写注释或者百科｜片段「对一切世间不欣喜的想」
  - 问题：`sabbaloke anabhiratasaññā` 传统作「一切世间不可乐想」，是有定名的观法；现译为描述性短语，读者不易与既有术语对应。
  - 建议：用「一切世间不可乐想」，或保留现译并首次夹注巴利原词。
- `181-1160-46-57`｜语言风格不统一｜片段「**以智慧而行****，**」
  - 问题：译文照搬了原文的黑体标点与引号黑体碎块（本句的黑体逗号，另见 `181-1160-69-74`、`181-1161-41-50` 的黑体句号，以及 `181-1160-13-32`、`181-1162-20-29` 的 `**“****` 形式）。不影响理解，但对读者端渲染是噪声。
  - 建议：黑体只覆盖被解释词本身，标点与引号留在黑体外。
- `181-1160-41-45`｜语言表达不够流畅｜片段「智慧对某个人来说是重的」
  - 问题：`ekassa` 在释词式里是「某人的」，照字面展开成「对某个人来说」偏啰嗦；黑体「**看重智慧**」也丢了 `-ko` 的「者」。
  - 建议：「某人以智慧为重，所以叫做**以慧为重（者）**」——最终用字须与父层核对。
