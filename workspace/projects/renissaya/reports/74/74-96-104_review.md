# Review — 74:96-104（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 基本缺失（只有 §97、§98 各一条，内容是科判说明，分别是 ubhatovaḍḍhaka 结束、bahuvidha 及 Abhidhammabhājanīya 结束，没有逐词释义，无法做词级核对）／义注 ❌ 缺失（释义核对无从进行，以下意见只依据巴利原文与本 chunk 内部的一致性）
> 本层是本文（mūla），没有父层，不做被解释词对照。

## 跨段一致性
- **pariyāpanna 与 gantha 撞字**：§96 句 74-96-73-78 / 74-96-79-85 / 74-96-86-91 把 gantha 译作“系”（顺系、与系相应），§96 句 74-96-297-302 又把 pariyāpanna 译作“所系的”。读者会把“所系的”误读成“被系（gantha）所系的”，术语对应就断了。建议 pariyāpanna 改为“所摄的”或“系属（三界）的”，gantha 保留“系”。两者都登记进 `terms.md`。
- **parāmāsa 与 upādāna 易混**：§96 parāmāsa 译“执取”（74-96-147-152 至 74-96-160-165），upādāna 译“取”（74-96-172-177 至 74-96-184-189）。“执取”在现代汉语佛学文献里常用来对译 upādāna，两组相邻出现，容易混淆。建议 parāmāsa 改为“执著”或“取著”，被动式相应改为“被执著的”。拿不准就先压低信心，交术语表定案。
- **否定式不统一**：na kāmāvacaro 译“非欲界的”，na pītisahagato 译“不与喜俱的”，na dassanena pahātabbo 译“不是应当由见断除的”。前两种都可以接受，第三种偏冗长，读起来别扭，见下方逐句意见。
- 其余一致项已核对，没有问题：saraṇa（§96 / §99）都译“有诤”，sahetuka（§96 / §103）都译“有因”，kusala/akusala/abyākata（§97 / §104）一致，“以 X 种方式，受蕴是：”与“这就是以十种方式来说的受蕴”（§97 / §100 / §104）一致，upādinnupādāniya（§100）与 §96 的“所执受”“顺取”对得上。

## §96 句 74-96-27-35
- **问题**：存疑。原文是 kenaci viññeyyo，“某些”的所指是 kenaci，原文没有“识”字。译文补“识”应是依义注（以眼识等某一识可知）补出的，但本次缺义注，无法核实。
- **建议**：补出可以保留，但要压低该句 confidence，等有义注时再核对。如果不打算依义注补，可改为“有可被某些（识）了知的”的不补版：“有可被某一种所了知的”。

## §96 句 74-96-196-201
- **问题**：术语区分不足。saṃkiliṭṭho 是过去分词（已被染污），译“杂染的”，和同组 saṃkilesiko“顺杂染的”只差一个“顺”字，看不出被动或完成义。同 chunk 里 parāmaṭṭho 译成了“被执取的”，处理方式也不一致。
- **建议**：改为“有被杂染的，有不被杂染的”，与 parāmaṭṭho 的被动式保持一致。

## §96 句 74-96-214-222 ／ 74-96-223-231
- **问题**：风格。“不是应当由见断除的”拗口。
- **建议**：改为“有应由见断除的，有不应由见断除的”。“由修断除”一句照此处理。

## §96 句 74-96-232-240 ／ 74-96-241-249
- **问题**：风格。“有它的因应当由见断除的”中“它的”多余，读着像翻译腔。
- **建议**：改为“有其因……”不行（“其”是文言）。建议用“有因应由见断除的，有因不应由见断除的”；如担心“有因”被误读为 sahetuka，可用“有带着应由见断除之因的”。

## §96 句 74-96-269-275
- **问题**：风格（轻微）。“俱”是单音节文言词，但“喜俱”是阿毗达摩定型术语。
- **建议**：保留，作为术语登记进 `terms.md`（pītisahagata＝与喜俱），避免 evaluate 时被当作文言误判。

## §96 句 74-96-297-302
- **问题**：术语撞字（见“跨段一致性”）。
- **建议**：“有所摄的，有非所摄的”。

## §101 句 74-101-2-3
- **问题**：误读结构。Dukamūlakaṃ 是科段结束的标题（“以二法组为根的一节”），不是句子。译成“以二法组为根。”读起来像一句陈述。
- **建议**：改为“以二法组为根（的一节）完。”或“二法组为根的部分。”，与其他科段结尾的标题体例统一。
