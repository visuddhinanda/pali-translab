# Review — 65:733-739（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️（§733 标题、§739 结语无 nissaya，其余各句齐全）／义注 ❌（未注入，本次释义判断仅依 nissaya，及其中引述的 ṭīkā 说法）

## 跨段一致性
- appiya：§735 和 §738 都译作“不可爱者”，前后一致。
- appiyasampayoga：§733、§734、§739 都译作“怨憎会”，前后一致。
- amanāpa / aniṭṭha / appiya 是三个不同的巴利词，分别译作“不合意 / 不可喜 / 不可爱”，区分得当，不需要统一。
- vatthu：§734 译“依处”，§737 也译“依处”，前后一致。
- samodhāna / samāgama：§734 两处都译作“聚合”，§738 的 samāgama 译作“相会”。这是两个不同的词，可以保留差异，但见下文 §734 句 2-10 的建议。

## §734 句 65-734-2-10
- **问题**：取义（轻）——samodhāna 的 nissaya 是 `သမောဓာနံ= တွေ့ကြုံပေါင်းဆုံရခြင်းသည်`，意思是“遭遇、碰在一起”，重点在“不得不碰上”。“聚合在一起”偏向“东西聚拢”，没有译出“遭遇”的意味，和标题“怨憎会”的“会”也不呼应。
- **建议**：改作“就是与不合意的有情和诸行相会”，或“……遭遇在一起”。§734 句 11-17 的“相聚合”随之改为“相会”。

## §734 句 65-734-11-17
- **问题 1**：术语所指偏窄——aniṭṭha 涵盖的是 sattasaṅkhāra（有情与诸行），译作“不可喜的**事物**”会把“有情”排除在外。nissaya 释为 `အနိဋ္ဌာရုံ`（不可喜的所缘）。
- **建议 1**：改作“特相是与不可喜者相会”，或“……与不可喜的对象相会”。
- **问题 2**：取义存疑——anatthabhāvapaccupaṭṭhāno 在 nissaya 里有两解：
  - 正解（标“ဤဋီကာအလို”）：`ကာယိကဒုက္ခ, စိတ္တဝိဃာတစသော အနတ္ထတို့၏ထင်ရှားရှိသည်၏အဖြစ်ကို ဖြစ်စေတတ်၏`，意思是“使身苦、心恼等不利益之事生起”，即把 bhāva 读作使役义“使……生起”；
  - 异释（`ဝါ`）：`ဥပဒ္ဒဝေါ၏အဖြစ်ဖြင့် … ရှေးရှုထင်တတ်၏`，意思是“以灾患的状态现起”，引 Mūlaṭīkā“anatthabhāvo upaddavabhāvo”。
  
  现译“现起是不利的状态”接近异释，但“不利”太弱，承担不起 anattha / upaddava（祸害、灾患）的分量。
- **建议 2**：取异释的话，改作“现起是祸害的状态”；取正解的话，改作“现起是带来身心的不利益”。等义注或复注到位后再定。本句 confidence 宜压低。
- **附**：nissaya 词头写作 `စိတ္တဝိဃာတကရုဏရသော`，“ကရုဏ”疑是 karaṇa 的讹写。这是 nissaya 的问题，pali 原文本身无误，记录在此，不改。

## §735 句 65-735-2-12 ／ §736 句 65-736-2-5
- **问题**：句法——yato（“因为”）统摄整首偈的前两句：“因为在这世间，一见到不可爱者，心中先生苦，随后身上又生起由其加害所致的苦”，然后 §737 的 tato（“所以”）承接它。nissaya 的语序也是这样：§735 先补出 `ဣဓ-ဣမသ္မိံ လောကေ= ၌`，§736 用 `ယတော-ယသ္မာ= ကြောင့်` 收束原因。现译把“因为在这世间是这样，”挂在 §736 句末，因果顺序被打乱，读起来像补缀，“是这样”还是凭空多出来的。
- **建议**：
  - §735 改作“因为在这世间，一见到不可爱者，心中首先就生起苦；”
  - §736 改作“接着，身上又生起由它们的加害所引起的苦，”
  - 删去“因为在这世间是这样”。
- **附（用词）**：upakkama 的 nissaya 是 `ပယောဂ`（所作所为、加害行为）。“侵害”可以接受，但对象包括无情的诸行（如荆棘、毒物），用“加害”比较中性。这一点可选改。

## §736 句 65-736-2-5（原文疑问）
- **问题**：OCR / 原文——pali 作 `Tadupakkamasambhūta-mathakāye`，应当是 `tadupakkamasambhūtam atha kāye` 被误连写了，连字符位置也不对。nissaya 拆读为 `တဒုပက္ကမသမ္ဘူတံ` / `အထ` / `ကာယေ`，可以佐证。
- **建议**：只记录，不改原文。译文已经按正确的拆读译出，没有问题。建议登记到 `known-issues.md`“OCR / 原文问题”一节。
