# Review — 96:697-707（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（703–705 三行没有单独的 nissaya，由 706 行整首偈颂一并覆盖）／义注 ❌
> - 本层本身就是义注（本生经因缘谈 Sumedhakathā），没有注入父层译文，也没有更下一级的注释书，所以**被解释词与父层逐字同译这一项无法核对**。
> - 本段的黑体都是佛名和人名标记（Dīpaṅkara / Koṇḍañña / Vijitāvī / Maṅgala 等），不是从父层引出的被解释词。
> - 释义只能以 nissaya 为依据。

## 跨段一致性

- **佛名的译法策略不统一**
  - §699 同一组四佛名里，maṅgala 译成「吉祥」、sumana 译成「善意」，用的是意译；revata「离婆多」、sobhita「苏毘多」用的是音译。
  - §698 vijitāvī 意译成「胜者」，而 §698 的城市名、父母名和弟子名都是音译加巴利夹注。
  - 建议：同一类专名统一处理。首次出现时一律夹注巴利原词，例如「吉祥（Maṅgala）」「善意（Sumana）」「离婆多（Revata）」「苏毘多（Sobhita）」。§697「憍陈如（Koṇḍañña）」首次出现也补上夹注。
- **用字不统一**：§699「苏毘多」用「毘」，§701「毗输安呾罗」用「毗」。建议统一用规范字「毗」，改成「苏毗多」。
- **集会人数后面的名词不统一**
  - §699-18 译「十万俱胝**比丘**」。
  - §697-18、§697-21、§699-27、§699-30 都译「…俱胝**人**」。
  - nissaya 在每一处都补出了 `ဘိက္ခူ= တို့သည်`（诸比丘），建议统一为「比丘」。
- **「钵」一字对应两个巴利词**
  - §699 用「钵」译 patta（神变所成的衣钵）。
  - §702 又用「金钵」译 suvaṇṇapāti。
  - 两者不是一回事，后者建议改为「金盘」或「金碗」。
- **sarīrappabhā / sarīrobhāsa 段末的固定句式**
  - §700-16、§700-94 都译「始终遍满一万个世界，持续不散」，原文有 niccakālaṃ / niccameva，这样译是对的。
  - §707 原文没有 nicca，译文却照搬了「始终」，见下文 §707 条。

## §697 句 96-697-21-26

- **问题**：原文疑问 — VRI 本作 `Dutiye koṭisahassaṃ`（一千俱胝），nissaya 却作 `ဒုတိယေပိ= … ကောဋိသတသဟဿံ`（十万俱胝）。nissaya 的按语还专门说明 pi 的作用：「na kevalaṃ paṭhamasannipāteyeva koṭisatasahassaṃ, atha kho dutiyasannipātepi koṭisatasahassaṃ」，可见它依据的底本是 `dutiyepi koṭisatasahassaṃ`。
- **建议**：译文按 VRI 底本译成「一千俱胝」，可以保留。异读记入 known-issues 待查，可以对照《佛种姓》本偈来定。

## §698 句 96-698-2-13

- **问题**：专名处理 — vijitāvī 意译为「胜者」，没有夹注巴利原词。「胜者」在汉译佛典里常用来称 Jina（佛），读者容易误解成佛的称号。
- **建议**：改为音译加夹注，或者至少写成「胜者（Vijitāvī）」，并按跨段一致性一节统一策略。

## §698 句 96-698-51-94

- **问题**：原文疑问 — nissaya 按语说「အနုရာဓော ဟူ၍လည်း စာအချို့ရှိ၏」，即有些本子的侍者名作 Anurādha。
- **建议**：译文按底本作「阿那律（Anuruddha）」不用改。异读记入 known-issues。

## §699 句 96-699-27-29

- **问题**：原文疑问 — 和 §697-21 是同一种情况。nissaya 作 `ဒုတိကေပိ= … ကောဋိသတသဟဿံ`（第二次也是十万俱胝），VRI 作 koṭisahassaṃ。
- **建议**：译文不改，异读一并记录。

## §699 句 96-699-58-76

- **问题**：术语／翻译腔
  - upanissaya 在这里指「宿因、过去积下的助缘」，译成阿毗达摩缘法术语「亲依止」，一般读者看不懂，也偏离了语境。
  - 「看到他们具备得到…的亲依止」这个句子结构生硬。
- **建议**：改为「看到他们有获得神变所成衣钵的宿缘（upanissaya）」。

## §699 句 96-699-77-91

- **问题**：语序 — 「威仪具足得像受戒六十年的长老一样」中，补语「得像…一样」挂在「具足」后面，读起来别扭。
- **建议**：改为「就像受戒六十年的长老一样威仪具足」。

## §700 句 96-700-25-33

- **问题**：误译倾向 — suvaṇṇapaṭa 的 nissaya 作 `သုဝဏ္ဏပဋ္ဋ… = ရွှေပြားဖြင့်`（用金片、金箔），读作 paṭṭa。译文「金色的布」有两处偏差：一是把「金」弱化成了「金色」，二是取了「布」这一义。
  - 另外 ukkhali 在 nissaya 里作 `ထမင်းအိုး`（饭锅），译文「锅碗」多出了「碗」。
- **建议**：改为「甚至连饭锅之类的东西，都像用金箔包裹起来一样」。如果坚持 paṭa 读法，也至少要作「金布」，不要作「金色的布」。

## §700 句 96-700-51-58

- **问题**：措辞 — vicariṃsu（nissaya 作 `လှည့်လည်ကုန်၏`，意为往来走动）译成「生活」，偏泛。
- **建议**：改为「始终借着佛的光明往来活动」。

## §701 句 96-701-27-44

- **问题**：语法误读倾向 — 「欢喜踊跃地震动了…大地」把 kampento（现在分词，伴随 adāsi）译成了以「欢喜踊跃地」为状语的主动行为，读起来像大士有意去震动大地。
- **建议**：改为「大士欢喜踊跃，说“我把孩子布施给婆罗门”，就把两个孩子都给了他，以水为边际的大地随之震动」。

## §702 句 96-702-6-44

- **问题**：误译倾向
  - ratanamattamakula 指金盘中央一肘高的花苞形凸起。nissaya 的异释说它是缠灯芯用的 `မီးစာရစ်စရာ အငုံအထွတ်`（花苞状顶座）。译文「花苞有一肘大小的金钵」让人看不出花苞和器物是什么关系。
  - pāti 译作「钵」，与 patta 冲突，见跨段一致性一节。
- **建议**：改为「…又把价值十万、中央有一肘高花苞形灯芯座的金盘盛满酥油…」。

## §702 句 96-702-45-58

- **问题**：措辞 — padumagabbha 是莲花的内部（花房、花苞），不是「花蕊」。
- **建议**：改为「就像进入了莲花苞里一样」。nissaya 补出了 `သီတလံ ဟောတိ`（是清凉的），可以考虑补成「…一样清凉」。

## §702 句 96-702-59-65

- **问题**：误译 — `attānaṃ rakkhantaṃ rakkhati` 里的 attānaṃ 是反身代词，回指主语 dhammo，意思是「法守护那守护法本身的人」。译文「守护那些守护自己的人」会让读者把「自己」理解成那个人自身，意思就变了。另外，nāma 表示的「所谓法」这层语气也没有译出来。
- **建议**：改为「因为所谓法，确实会守护那守护法的人」。这样也能和下一首偈「法确实守护奉行法的人」接上。

## §707 句 96-707-2-11

- **问题**：误译
  - `Imassāpi kammassa nissandena` 中的 api 修饰的是 kamma，意思是「也由于这一业的等流」，这是第二个原因，承接 §701 的发愿。译文把「也」挪到了光明上。
  - 原文没有 nicca，译文却加了「始终」。
- **建议**：改为「也由于这个业的等流，那位世尊身体的光明遍满一万个世界，持续不散」。
