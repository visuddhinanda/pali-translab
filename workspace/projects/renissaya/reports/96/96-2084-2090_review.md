## 被解释词待核（父层未注入，须补比对）

以下黑体词引自《法集论》本文。它们的译法必须与父层译文逐字相同，补跑时请逐一核对：

- 第一组（§2084）：青草色 / 芒果嫩芽色 / 长 / 短 / 小 / 大 / 圆 / 卵圆形 / 四角 / 六角 / 凹 / 凸
- 第二组（§2085–2086）：影 / 阳光 / 光明 / 黑暗 / 云 / 雾 / 月轮的色泽 / 月轮 / 日轮 / 星宿
- 第三组（§2088–2090）：镜面 / 摩尼宝珠 / 海螺 / 珍珠 / 琉璃 / 金 / 银 / 或者还有其他任何 / 色

其中两组对词须特别留意：

- **vaṭṭa / parimaṇḍala**：本文多译为“圆／球形（遍圆）”。

如果父层用的是这些译法，这里须照改，§2084 句 52-63 释文中的“与大相比”“与小相比”也要一并改。

## 跨段一致性

- **tāraka（tārakarūpa）**：§2086 译“星宿”，§2087 的 nakkhattatārakā 译“月宿和星辰”。“星宿”在汉语里通常指 nakkhatta（二十八宿），所以在这里同一个词出现了两种译法，而且“星宿”与 nakkhatta 的所指还发生了交叉。
  - 建议：tāraka 统一译为“星辰”（如果父层另有定译，就从父层），“星宿／月宿”只留给 nakkhatta。
- **cakkhuṃ petaṃ / rūpaṃ petaṃ**：§2090 句 50-65 中，前者译“这就叫眼”，后者译“也是色”。两者句式完全平行，都是 X pi etaṃ（“这也是 X”），但译法不对称。
  - 建议：统一为“这也是眼”和“这也是色”，并与父层引语对齐。
- **vatthu“事物”的复用**：§2084 和 §2085 把 vatthu（所依物）译为“事物”，这是合理的。但 §2085 句 23-39 把 taṃ taṃ（指大种的聚合）也译成“某种事物”，与 vatthu 混用，读者会以为两处说的是同一个概念。
  - 建议：该处改用别的说法，见下文该句条目。

## §2084 句 96-2084-22-30

- **问题**：措辞。“由布局构成而成立”中，“构成”与“成立”语义叠床。sannivesa 指聚合排列而成的形态。
- **建议**：改为“有的是由排列形态而成立的”。下一句 §2084 句 31-38 的“由布局构成的差别”同步改为“由排列形态的差别”。

## §2085 句 96-2085-23-39

- **问题 1**：误读，添加了因果关系。原文是陈述句：依于各种（大种的聚合）、以各种（长短等）形态存在的色处，在这里分别用“长”“短”等称呼来说。原文中没有“因为……才”的因果关系。
- **问题 2**：漏译。taṃ taṃ / tathā tathā / tena tena 都是叠用，表示“各别”，译文的“某种事物、某种方式”丢掉了这层意思。
- **nissaya 依据**：
  - `taṃ taṃ = ထိုထိုဘူတရုပ်အပေါင်းကို`，意思是“那各个大种的聚合”。
  - `tathā tathā = ထိုထိုအခြင်းအရာအားဖြင့်（အရှည်အတိုစသော…）`，意思是“以各种长短等形态”。
- **建议**：改为“应当了解：这里说的其实就是色处——它依于各种大种的聚合，以各种形态存在，于是分别用‘长’‘短’等称呼来说它。”

## §2085 句 96-2085-58-64

- **问题**：译窄。valāhaka 泛指云、云团，译文译成“雨云”，范围变窄了。
- **nissaya 依据**：`ဝဠာဟကော= တိမ်တည်း။（တိမ်တိုက်）`，意思是云、云层。
- **建议**：改为“云层”或“云团”。

## §2086 句 96-2086-2-18、96-2086-19-27

- **问题**：风格（半文半白）。“外覆白银”“外覆水晶”都是四字文言化的写法。
- **建议**：改为“外面覆盖着白银”“外面覆盖着水晶”。

## §2086 句 96-2086-28-36

- **问题**：术语，见上文跨段一致性一节。黑体“星宿”与 §2087 的 nakkhatta 发生冲突。
- **建议**：以父层译法为准。父层如果用的是“星宿”，§2087 的 nakkhatta 就需要换用别的译法。

## §2087 句 96-2087-20-24

- **问题**：存疑，涉及词法。nakkhattatārakā 有两种读法：
  - 可以读作持业复合词，意思是“诸宿之星”，指一类天体；
  - 也可以读作并列复合词，意思是“宿与星”。
- **nissaya 依据**：nissaya 写作 `နက္ခတ်ကြယ်တာရာတို့`，作为一个整体处理，更接近持业复合词的读法。译文按并列复合词译成了“月宿和星辰”。
- **建议**：复注到位后再定。在此之前保留现译。§2087 句 25-36 与此同步处理。

## §2088 句 96-2088-26-29

- **问题**：语法误读，主语和表语颠倒了。nissaya 显示主语是 satthuvaṇṇo，jātarūpa 是“所称之名”。原文的意思是：与大师同色的（那种金属）叫做 jātarūpa。译文“金被称为导师的颜色”把方向说反了。
- **nissaya 依据**：`သတ္ထုဝဏ္ဏော= မြတ်စွာဘုရား၏ အဆင်းတော်ကို။ ဇာတရူပံ= ဟူ၍။ ဝုစ္စတိ`
- **建议**：改为“**金**，指的是与导师同色的（金属）。”

## §2088 句 96-2088-37-61

- **问题 1**：句法误读。`ye ‘vohāraṃ gacchantī’ti vuttaṃ` 中的关系词 ye，回指前面的三种钱币（铜、木、紫胶）。意思是“律中说它们‘可以当作货币流通’”，而不是在三种钱币之外再加一项。译文写成“以及律中所说……”，变成了第四个并列项。
- **nissaya 依据**：`ယေ= အကြင်ပဲပိုက်ဆံတို့သည်`，意思是“这些豆钱”。
- **问题 2**：误译。jatu 是紫胶、虫胶，不是“树胶”。
- **nissaya 依据**：`ဇတုမာသကော= ချိပ်ဖြင့် ပြုအပ်သော`，ချိပ် 就是紫胶、封蜡。
- **建议**：改为“**银**，是指迦利沙波拏（kahāpaṇa）——铜币、木币、紫胶币，也就是律中所说‘当作货币流通的’那些（《波罗夷》584），这里全都包括在内。”

## §2089 句 96-2089-2-13

- **问题**：误译。kaṇṇika 在这里不是“耳饰”。nissaya 释为菌类、霉。
- **nissaya 依据**：`…ကဏ္ဏိကဝဏ္ဏ…= …မှိုအဆင်း…`，မှို 是菌、霉。
- **建议**：将“耳饰（kaṇṇika）”改为“霉菌（kaṇṇika）”。taṭṭika 和 pilotika 的译法“席垫、碎布”可以保留。

## §2090 句 96-2090-50-65

- **问题**：一致性。见上文跨段一致性一节，“这就叫眼”与“也是色”的句式不对称。
- **建议**：改为“那里有‘这也是眼’等十四个名称，这里有‘这也是色’等三个名称”，并与父层引语逐字对齐。
