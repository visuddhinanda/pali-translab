# Review — 96:1325-1327（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 部分可用／义注 —（本层即义注）
> - **父层缺失**：没有注入父层本文（《法集论》慧根释义段）的译文，所以**被解释词与父层逐字同译这一项无法机械核对**。下面所有黑体被解释词（慧、了知、简择、遍择、择法、观察、审视、各别审视、贤明、善巧、精巧、明辨、思察、审察、广慧、睿智、引导、观、正知、刺棒、慧根、慧力、慧的利剑、慧的殿堂、慧的光明、慧的光辉、慧的明灯、慧的珍宝、无痴、正见）都要补跑一次对父层的逐字核对。
> - **nissaya 质量**：以下各句的 nissaya 不是缅文逐词原式，而是英文/中文转述（疑为机器生成），只能作参考，不能作词级基准：1325 句 172-185、200-204、205-209；1326 全段除 2-16 之外的各句；1327 句 2-15、37-40、41-62。转述里还有明显乱码与讹误（如「非妃惑」「�lloha」「satthaṃpāsādo」）。
> - 没有下一级注释（复注）可作释义对照。

## 跨段一致性

- **paññāloka / paññāāloka**：§1326 句 2-6 译为“慧的光明”，§1326 句 52-56 译为“慧光”，而且后者在译文里夹注“（paññāloka，即上文的慧的光明）”。两者是同一个词（只是连声不同），应该统一成一个译法，并删去夹注。建议以父层本文的译法为准；如果父层用“慧光”，那么这一组都改成单名式。
- **“慧的X”系列**：利剑、殿堂、光明、光辉、明灯、珍宝都用“慧的X”，而 patodo 却译成“策励的刺棒”，不成系列。另外“慧的X”略带翻译腔，传统译法多作慧剑、慧光、慧灯、慧宝。建议整组按父层的译法统一。
- **pajjota**：§1326 句 12-16 和 77-114 译为“明灯”，§1326 句 17-29 译为“灯明”（ekapajjotā） → 统一为“明灯”。
- **sallakkhaṇā / upalakkhaṇā / paccupalakkhaṇā / upaparikkhā**：义注明说后两个只是 sallakkhaṇā 加了前缀（nissaya：前缀 upa- 和 pati- 不带意义），但译文分别是“观察 / 审视 / 各别审视”，看不出同根关系。同时“审视”和 upaparikkhā 的“审察”共用“审”字，读者会把不同的词当成同一组。建议保留共同词根，例如“察知 / 近察知 / 各别近察知”，与“审察”区开。
- **sallakkhaṇā“观察”与 vipassanā“观”**：两个法相用字重叠，容易混淆。建议 sallakkhaṇā 改用不带“观”的译法（见上一条）。
- **vicaya / pavicaya / dhammavicaya**：分别译为“简择 / 遍择 / 择法”。pavicaya 被说成 vicaya 加前缀，汉译应该看得出来：要么 vicaya 作“择”、pavicaya 作“遍择”，要么 vicaya 作“简择”、pavicaya 作“遍简择”。以父层为准。
- **lakkhaṇa**：§1325 句 151-160 译为“特征”，句 186-190 译为“特相”（同一个法相词） → 统一为“特相”。
- **jānāti 与 pajānanā**：§1325 句 13-21 和 166-171 的 jānāti 都译作“了知”，而被解释词 pajānanā 也是“了知”，前缀 pa- 的区分丢了。建议 jānāti 改为“知道”，“了知”只留给 pajānanā。
- **同型句的语体**：§1325 句 55-66 三个同型定义句，前两句是“X者的状态就是Y”，第三句中间加了逗号，长短也不一样 → 统一句式。

## §1325 句 96-1325-39-42
- **问题**：风格（文言虚词）——“四谛之法”。
- **建议**：改为“四谛的法”或“四圣谛法”。
- **另记**：nissaya 在这里多出一组 `အနိစ္စာဒီနံ … ဝိစိနာတိ … ဓမ္မဝိစယော`，pali 原文没有，疑是异读，记入原文疑问（见文末）。

## §1325 句 96-1325-87-92 / 104-110 / 124-132
- **问题**：同一段引文里，同一个词的处理前后不一。句 104-110 引文里作音译“bhūrī”，句 124-132 同一段引文里又作“广慧”。
- **建议**：引文内统一。可以都作“广慧（bhūrī）”，首见夹注一次；也可以引文内都保留音译，再在首次出现时说明。

## §1325 句 96-1325-111-123 / 96-1325-124-132
- **问题**：出处标注错位。pali 的“( mahāni .27)”在句 111-123 末尾，译文却把“（《大义释》27）”挪到了句 124-132 末尾，句 111-123 里反而没有。这是跨句挪动内容，坐标对应被破坏了。
- **建议**：把出处放回句 111-123 末尾，句 124-132 只保留引号收尾。

## §1325 句 96-1325-93-100
- **问题**：取义。saṇha 在 nissaya 注里指的是没有砂石、土质细软的好地（类比慧没有烦恼砂石），译作“细密”偏向致密、紧密的意思。
- **建议**：改为“细软”或“柔细”。

## §1325 句 96-1325-151-160
- **问题**：原文疑问。nissaya 作 `ဥပဋ္ဌာတိ`（upaṭṭhāti），pali 作 uppajjati；nissaya 注又指出 pariṇeti 有作 pariṇāmeti 的讹本。译文按 pali 译，这样处理是对的，只记录不改。另外“各自的特征”中的“各自的”是添加的，pali 只有 yāthāvalakkhaṇa（如实的特相）。
- **建议**：改为“…引导相应诸法通达如实的特相”，并按跨段一致性一节把“特征”统一为“特相”。

## §1325 句 96-1325-172-185
- **问题 1**：被解释词。pali 是单纯的 **patodo**，译成“**策励的刺棒**”增加了“策励”，而且前文刚说“它就像刺棒”，接着又说“所以叫做策励的刺棒”，自相矛盾。
- **建议**：被解释词以父层为准，一般作“**刺棒**”。句尾改为“…所以它像刺棒，叫做**刺棒**”。
- **问题 2**：风格（文言虚词）——“偏曲之心”。
- **建议**：改为“歪曲的心”或“偏曲的心”。
- **问题 3**：用词。vīthiāropana 是“让它回到路上”，译作“回到正道”，容易和 sammāmagga（正道）混同。
- **建议**：改为“回到正路”。

## §1325 句 96-1325-186-190
- **问题**：nissaya 词法。kāreti 是使役式，nissaya 补出了（sampayuttadhammehi），意思是令相应诸法在见的特相上奉它为主。译文“起着主宰的作用”丢掉了使役关系和相应法。
- **建议**：改为“它在见的特相上令相应诸法以它为主宰，所以叫做根”。

## §1325 句 96-1325-205-209
- **问题**：风格。“高耸卓立”偏文雅，四字套语味较重。
- **建议**：改为“由于高高耸立”。

## §1326 句 96-1326-17-29
- **问题**：误译。ekapallaṅkena nisinnassa 是“在一次结跏趺坐中坐着（不起座）”，“只要盘腿而坐”丢了“一次（同一座）”这层意思，变成了条件句。
- **建议**：改为“有慧的人在一次结跏趺坐当中，一万个世界就……”，并把“灯明”统一为“明灯”。

## §1326 句 96-1326-30-48 / 96-1326-77-114
- **问题**：句法衔接。pali 的结构是“三词中一词即足；然而 yāni etāni ‘…’ suttāni desitāni（那些经是顺众生意乐而说的），这里也依此而说”。句 30-48 的“正如下面这些话所说：”与 yāni…suttāni 的关系对不上，和句 77-114 的“这些经都是…”重复交代。
- **建议**：句 30-48 改为“…就已经成立了；不过，像“比丘们，有这四种光明……”，与句 77-114 的“这些经都是顺着众生的意乐而宣说的”连读成一句。

## §1326 句 96-1326-52-56
- **问题**：译文里留了工作性夹注“（paññāloka，即上文的慧的光明）”，属于必改项。“即”也是文言虚词。
- **建议**：删去夹注，按跨段一致性一节的结论统一成一个译法。

## §1327 句 96-1327-2-15
- **问题**：添义。anomasattaparibhoga 是“为不低劣（高尚）的众生所受用”，原文没有“只为”的排他意思。
- **建议**：改为“又为高尚的众生所受用”。

## §1327 句 96-1327-63-66
- **问题**：风格。“善的见”生硬。
- **建议**：改为“就是如实、能导向出离的善见”。

## OCR / 原文疑问
- §1325 句 39-42：nissaya 多出“aniccādīnaṃ vicinātīti dhammavicayo”一组，疑是异本，pali 不改。
- §1325 句 151-160：uppajjati / upaṭṭhāti 异读；nissaya 注又说 pariṇeti 有讹作 pariṇāmeti 的本子。
