# Review — 97:1867-1878（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1867、1868-2-12、1870-2-19、1877-2-5、1878-2-11、1878-15-19 这几行没有单独的 nissaya 单元，它们的释义并在紧接的下一行里，已合并核对）／**义注层的释义标准（复注 ṭīkā）缺**／**父层（分别论本文）译文缺**
>
> ⚠ 本层是义注，黑体被解释词引自分别论本文。由于没有注入父层译文，**被解释词与父层逐字同译这一项无法核查**。下面列出的被解释词问题只涉及本层内部的一致性和是否忠实于巴利原文。跨层对齐要等统稿（harmonize）时再补查。

## 跨段一致性
- **yoga / paññā**：1868-2-12 把 yoga 译成“智慧”，同一句里 paññā 又译成“慧”，读起来像“智慧就是慧”，成了循环定义。下一句（1868-13-16）的 paññāvihita 也是“由慧所造设”，和被解释词里的“由智慧所造设”不一致。→ 建议 paññā 统一译为“慧”，yoga 改用夹注说明（见下文该句）。
- **saccānulomika**：1873-22-26 被解释词译作“随顺四谛的**智**”，1873-27-33 的释名作“随顺四谛的”。巴利被解释词 saccānulomikaṃ 本身没有“智”字。→ 被解释词与释名统一为“随顺四谛的”，不要加“智”（kammassakataṃ 同理，见 1873-2-21）。
- **kammāyatana / sippāyatana / vijjāṭṭhāna**：这三项在本文是并列的一组，译文却作“职业领域 / 技艺领域 / 明处”，前两项用“领域”，第三项用“处”，并列关系看不出来。另外 1868-23-31 把 āyatana 释为“所依处”，和“领域”这个译名对不上，词源说明因此失效。→ 建议统一为“职业处 / 技艺处 / 明处”，或者统一用“领域”。最终以父层定稿为准，统稿时一并对齐。
- **samāpatti**：1877 把 samāpanna / samāpatti 译作“入定 / 定”，而“定”通常对应 samādhi，两者容易混淆。→ 建议译“等至”，或至少全书统一。
- 被解释词与释语的语法框架不一致：1878-15-19 被解释词作“在……身上”，释语却作“……的”（详见该句）。

## §1868 句 97-1868-2-12
- **问题**：术语/释义 — yoga 译作“智慧”，与 paññā“慧”构成循环定义。nissaya 补出了词源：`ယုဇ္ဇတိ ဧတေနာတိ ယောဂေါ`（藉此而致力于职业、技艺的，叫作 yoga）。可见 yoga 在这里取的是“藉以致力的东西”这一义，被注家指认为慧，并不是“智慧”的同义词。另外 vihita 的 nissaya 是 `စီရင်အပ်`（经安排、处置的），“造设”偏文雅。
- **建议**：“在三种智事的解释中，“**以 yoga 安排的**”：yoga 这里是指慧；”。被解释词的最终措辞要与父层对齐。

## §1868 句 97-1868-13-16
- **问题**：误译 — paññāpariṇāmita 的 nissaya 是 `ပညာဖြင့်ရင့်ကျက်စေအပ်ကုန်သော`（由慧使之成熟的），不是“运用”。
- **建议**：“意思是：由慧安排的、由慧使之成熟的。”。nissaya 注明这两个词修饰 kammāyatanesu，可以参考。

## §1868 句 97-1868-23-31
- **问题**：句法 — “职业就是领域，是生计等的所依处”漏掉了“既是……又是……”的并列结构（kammañca taṃ āyatanañca）。nissaya 的结构是：既是职业（ကမ္မဉ္စ），也是生计等的所依（အာယတနဉ္စ），所以叫 kammāyatana。
- **建议**：“或者，它既是职业，又是生计等的所依处，所以也称为**职业处**。”（译名跟随跨段统一的结论。）

## §1868 句 97-1868-52-60
- **问题**：取义 — gorakkha 的 nissaya 注 `[နွားကျောင်းသားမဟုတ်, နွားပိုင်ရှင် အလုပ်တည်း။]`：指的不是放牛人，而是牛主人经营畜牧。“牧牛”容易让人理解成放牛的雇工，而放牛属于低下的职业，与“高等职业”的归类相矛盾。
- **建议**：改为“养牛”或“畜牧”。1870-20-25 的“牧牛的行业”同步修改。

## §1868 句 97-1868-97-127
- **问题**：**严重误读（句法）** — 原文中 nāgamaṇḍalaparittasadisaṃ、phudhamanakamantasadisaṃ、sālākiyaṃ、sallakattiyaṃ 这四项共同由 `iti ādīni … vejjasatthāni` 收束，全部属于“医方”，并且全部“不取”。nissaya 的结构很明确：四项之后接 `ဣတိ အာဒီနိ= ကုန်သော။ ဝေဇ္ဇသတ္ထာနိ= …တို့ကို … န ဂဟိတာနိ`。译文却把前两项说成“就是这里所取的”，意思正好译反了。前两项的 sadisa 是说这类医术“类似于”龙圈护咒、吹气咒，并不是说护咒本身。
- **建议**：“至于类似龙圈护咒的、类似‘噗’声吹咒的，以及眼科、外科等医方，因为已经归入“老师，我想学习技艺”（《大品》329）所说的技艺处，所以这里不取。”

## §1869 句 97-1869-2-12
- **问题**：OCR / 原文疑问 — nissaya 注：`စာအုပ်တို့၌ "အတ္တနော စ" ဟု ရှိ၏, မကောင်း။ "အတ္တနောဝ" ဟုရှိရမည်။`（刊本作 attano ca，不妥，应作 attanova，意思是完全凭自己，排除向他人学习）。译文照 ca 译成“**也**出于自己的天性”，与后文“既不是看到别人在做……而是凭自己的天性”的主旨不合。
- **建议**：按 attanova 译作“完全凭自己的天性”，并在报告中记录这个异读（原文不改）。可以考虑登记到 `known-issues.md` 的 OCR 一节。

## §1869 句 97-1869-13-58
- **问题**：误译 — vayhasakaṭasandamānikā 的 nissaya 是 `ထမ်းစင်, လှည်း, ရထားပေါင်းချုပ်`（轿子／抬架、牛车、有篷的车）。译文“篷车、货车、轻便车”把 vayha 译错了，sandamānikā 也不是“轻便车”。另外“站在利益他人的立场上”中的“他人”在原文指的是人们（hitakiriyā，nissaya 作 `လူတို့၏ စီးပွါး`）。
- **建议**：“……创制了轿子、牛车、篷车等”。前半句可改为“他立意为人们谋利益，想到……”。

## §1873 句 97-1873-2-21
- **问题**：被解释词 — kammassakataṃ vā 被译成“或是业自有的**智**”，多出了巴利原文没有的“智”，“业自有的”也不通顺。释语“这个业是众生自己的”可以接受。nissaya 补出了取义：善业带来利益安乐，所以是“自己的”；不善业带来损害痛苦，所以“不是自己的”。可以参考 nissaya 的这一取义。
- **建议**：被解释词改为“**或是业为己有**”或“**或是自业性**”，以父层定稿为准。释语保持现状。

## §1873 句 97-1873-22-26
- **问题**：被解释词 — 同上，“随顺四谛的**智**”多了“智”字，与下一句释名“随顺四谛的”不一致。
- **建议**：改为“**或是随顺四谛的**”。

## §1874 句 97-1874-2-10
- **问题**：被解释词 / 句法 — 被解释词“**凡是**……**这样一种**”中的省略号和拆分是译者加的，巴利原文是连续的 yaṃ evarūpiṃ。nissaya 注：yaṃ 接的是 khantiṃ，不接 anulomikaṃ（`"အနုလောမိကံ" ကား ပဓာနမဟုတ်`）。译文“凡是具有……性质的、随顺的”没有交代被修饰的是“忍”等词。
- **建议**：被解释词作“**凡是这样的**”。释语改为“凡是具有上面所说性质的、随顺的（忍等）”，或者在表述上让读者看出修饰的中心是后面的“忍”。

## §1874 句 97-1874-16-26
- **问题**：取义 — apaccanīkadassanena 的 nissaya 是 `မဆန့်ကျင်ပုံကို ပြခြင်းဖြင့်`（通过**显示**不相违），译文“以不相违逆的方式**看待**”把 dassana 理解成了“看”。
- **建议**：“因为它显示出与前面所说的职业处等五种事由并不相违，从而随顺它们，所以是**随顺的**。”。如果坚持取“看”义，请在 confidence 中压低。

## §1874 句 97-1874-63-81
- **问题**：① 译名“**法经得起审察的忍**”生硬，传统上译作“审谛法忍”或“法审察忍”。② OCR / 原文疑问：刊本作 nijjhāyamānā（主格，修饰 dhammā），nissaya 所据的本子作 `နိဇ္ဈာယမာနာယ`（属格，“正在审察的慧的”）。两种读法的意思都通，译文跟随了刊本。
- **建议**：被解释词改为“**审谛法忍**”一类较通行的译名，以父层定稿为准。异读记入报告，译文不改。

## §1875 句 97-1875-2-12
- **问题**：被解释词 — “**不从他人那里听闻，而自己获得**”加了原文没有的“自己”（sayameva 在释语里，不在被解释词里），与 1876 的对应被解释词也不平行。
- **建议**：被解释词改为“**不从他人那里听闻而获得**”，与 1876 成对，“自己”留在释语中。

## §1876 句 97-1876-2-30
- **问题**：风格 — 被解释词“听闻**之后而**获得”和句末重复处的“之后而”带有半文半白的味道。
- **建议**：被解释词改为“**从他人那里听闻后获得**”，句末同步改为“都应当理解为是从他人那里听闻后获得的”。

## §1877 句 97-1877-2-5 / 97-1877-6-12
- **问题**：术语 — samāpatti 译作“入定 / 定”，与 samādhi 混同（见跨段一致性一节）。“具足入定的人的”也不通顺。
- **建议**：“**入等至者的**”：具备等至的人的；“意思是：在等至之中运作的慧，称为**修所成慧**。”

## §1878 句 97-1878-15-19 / 97-1878-20-22
- **问题**：① 被解释词作“在……身上”，释语作“……的”，语法框架不一致。nissaya 对 adhigacchantassa 和 pāpuṇantassa 一律释作 `…ပုဂ္ဂိုလ်၏သန္တာန်၌`（在……者的相续中）。② “成办”属于文言词。③ adhigacchati 与 pāpuṇāti 被分别译成“成办 / 达成”，释语起不到解释作用。nissaya 还指出这里的 dāna 指布施的思（`ဒါနံ= ဒါနစေတနာသို့`）。
- **建议**：被解释词作“**在达到布施的人身上**”，释语作“在达到布施的人身上；意思是：在到达布施（的思）的人身上”。用词以父层为准，但被解释词和释语至少要采用同一个框架。

## §1867 句 97-1867-2-6
- **问题**：措辞 — “三法释注解”不通顺（Tikaniddesa＝三法组的解释，vaṇṇanā＝注释）。
- **建议**：改为“（3.）三法组解释的注释”，或者沿用全书标题体例。
