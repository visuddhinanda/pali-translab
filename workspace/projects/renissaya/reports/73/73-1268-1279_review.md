## 跨段一致性

- **upādiṇṇupādāniya / anupādiṇṇupādāniya**：§1268–1272 都译作“执受顺取”和“非执受顺取”，前后一致。
- **sanidassana / sappaṭigha / mahābhūta / indriya / oḷārika·sukhuma / dūre·santike**：各段译法一致，都是“有见·无见 / 有对·无对 / 大种 / 根 / 粗·细 / 远·近”。
- **句式**：
  - 作谓语时用“有的是 X，有的不是 X”（§1270、1273、1274）。
  - 作主语限定时用“属于 X 的色”（§1275–1278）。
  - 这两种说法的分工固定，读起来也通顺，不需要统一。
- 结论：无。

## §1279 句 73-1279-2-7

- **问题**：句法误读，依据是 nissaya。
  - nissaya 在 diṭṭhaṃ、sutaṃ、mutaṃ 后面各补出了 `(ရူပံ အတ္ထိ)`，也就是“有……色”。最后一行是 `ရူပံ= သည်၊ (အတ္ထိ)`，表示“色”是主格，谓语 atthi 是隐含的。
  - 所以这句是四分法：有所见的色、有所闻的色、有所觉的色、有所识的色，各是一类。这也合乎本节“四法”（Catukka）的体例。
  - 现译“所见、所闻、所觉（muta）、所识的色。”把四个分词并列，共同修饰一个“色”。读者容易理解成“同一种色兼有这四种性质”，把分类读丢了。
- **建议**：把四类分开译，并补出“有”，例如：
  - “有所见的色、所闻的色、所觉（muta）的色、所识的色。”
  - 或者：“色有所见的、所闻的、所觉（muta）的、所识的。”
- **附注**（供参考，不是必改项）：
  - nissaya 对这四词都用 `ထိုက်သော`（“可以……的、应被……的”）来释，例如 diṭṭhaṃ = 眼识可以见到的；mutaṃ = 鼻、舌、身三识接触到才能知道的；viññātaṃ = 意识可以知道的。
  - 可见传统读法取的是“可被……”的意思，不是过去时的“已经被……”。
  - “所见／所闻”本身可以兼含这层意思，可以不改。如果要把 muta 的所指交代清楚，可以在段后注里写明“鼻、舌、身三识所触知”。
