# Review — 66:1161-1167（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌／父层译文 ❌
> **缺失说明**：本层是复注（ṭīkā），父层是《清净道论》入出息念一节，但本次没有注入父层的原文和译文。所以**被解释词与父层逐字同译这一项无法机械核查**。下面凡涉及被解释词（黑体）的意见，都要在 harmonize 时对照父层译文定稿；本报告只就复注本身的解释给出依据。
> 另：注入数据的 `layer` 字段写的是 `mula`，实际是复注，脚本标注有误，值得核对。

## 跨段一致性

- **Ittaravasena / Addhānavasena**（§1163）：前者被解释词译“依长时段”，后者译“短时段”，漏了“依”，两个平行词结构不对称 → 建议统一为“依短时段”（以父层译法为准）。
- **pubbābhisaṅkhāra**（事先的准备）：§1165-147 译“事先所作的准备”，§1167-29 译“预先准备” → 建议统一为“预先准备”。
- **ghaṭati / vāyamati / vīriya**（§1166）：ghaṭati 译“努力”，vāyamati 译“精进”，vāyāmaṃ karoti 又译“付出努力”；同一 chunk 里 §1166-25 的 vīriya 也译“精进”。这样 vāyamati 和 vīriya 撞了同一个译名，ghaṭati 和 vāyāma 也撞了“努力”，读者分不清这几个词。→ 建议 ghaṭati 译“致力”（ussahati 译“奋发”），vāyamati 译“努力”（vāyāmaṃ karoti 译“作出努力”），“精进”只留给 vīriya。
- **tattha**：§1165-46、§1165-58 译“在这里”，§1165-119、§1167-54 译“其中”，§1165-33 的 tattha tattha 译“在每一处”，§1167-29 的被解释词 tattha yasmā 译“这里”。同一个词“这里 / 那里 / 其中”来回换，而且和 ettha、idha 的译法相互干扰（见 §1162）。→ 句首引出注释的 tattha 统一译“其中”；被解释词按父层译法定。
- **tādiso / tādisena / tathābhūta / evaṃbhūta**：§1164 的 tādiso 译“这样”，§1165-159 的 tādisena 译“这样的人”，§1166-20 的 tathābhūtassa 和 §1165-119 的 evaṃbhūto 也都译“这样的人”；§1166-2 的 evaṃ 也译“这样”。§1164 的 tādiso 指气息的长短，不是“这样”这个副词 → 建议改为“这样的”，和 §1166 的 evaṃ 区分开。
- **pavatteti（使……运行）**：§1165-101、§1165-119、§1165-159、§1166-11 都译“使……运行”。用在“使入出息运行”“使心运行”上，翻译腔重 → 建议按语境改为“进行（入出息）”“让（与智相应的）心生起”等。

## §1162 句 66-1162-16-51

- **问题**：取义／被解释词 — 释文 etasmiṃ yathādassite … pāḷinaye 是“**这个**前面所示的经文方式”，被解释词 Etthā 却译成“那里”。ettha 和 idha 都是“这里”的意思，复注靠 etasmiṃ 和 imasmiṃ 来区分两者的所指。现在用“那里 / 这里”硬造远近对立，复注本身没有这层意思。
- **建议**：先看父层怎么译 ettha 和 idha。如果父层也是“那里 / 这里”，就保留，并在释文里补上“这个”（“是指上面所示的……这个经文方式”）；如果父层是别的译法，就逐字跟随父层。另外，引文“怎样在长长地入息时”不通顺，建议改为“怎样长入息时”。

## §1163 句 66-1163-2-5

- **问题**：被解释词增译 — Ayaṃ 只是“这个（人）”，复注释为 yogāvacaro。被解释词译成“这位比丘”，加了原文没有的“比丘”。
- **建议**：除非父层就是这样译的，否则改为“**这个人**”，释文“是指修行者”不变。

## §1164 句 66-1164-21-44

- **问题**：取义错误（必改） — 复注的要点是：偈颂里的 va 是 vā 为格律缩短而成，vā 是 aniyamattha（不限定），所以兼摄上唇。被解释词却译成“**就**在比丘的鼻端”，把 va 当成 eva（就、只）这个限定词来理解，正好和复注说的“不限定”相反。同一句的释文又说“表示不限定，也包括了上唇”，被解释词与释文自相矛盾。
  nissaya：`ဝါ-သဒ္ဒေါ … အနိယမတ္ထော`（vā 这个词……有不定之义）、`ဥတ္တရောဋ္ဌံ … သင်္ဂဏှာတိ`（摄入上唇）。
- **建议**：被解释词改为“**或在比丘的鼻端**”之类能表达“或”的译法。如果父层把这句偈颂译成“就在……”，那是父层的错，要在 harmonize 时把两层一起改，并在报告里注明。

## §1165 句 66-1165-58-90

- **问题**：句法误读（必改） — 按 nissaya，samānepi 修饰的是 paṭipattividhāne：`အဿာသပဿာသေသု = 在入出息上 / ယောဂိနော = 修行者的 / ပဋိပတ္တိဝိဓာနေ = 修行方法 / သမာနေပိ = 虽然相同`。意思是“虽然修行者对入息和出息的修行方法相同”，译文却成了“入息和出息虽然相同”，把“相同”安到了气息本身。此外，nissaya 补出了两处施事：desanā katā 是 `(ဘဂဝတာ)`，即世尊所作；atthavaṇṇanā katā 是 `(အာစရိယေန)`，即注释者（论师）所作。译文两处都没有施事，“开示”和“解释”是谁作的看不出来。
- **建议**：改为“……正如修行者对入息和出息的修行方法虽然相同，世尊为了显示对每一个都要认真地修，还是分别作了开示；同样，论师为了阐明这个意思，虽然两句意思相同，还是用‘整个’等话分别解释了这两句。”

## §1165 句 66-1165-101-118

- **问题**：句法 — nissaya 把 pākaṭīkaraṇaṃ、vibhāvanaṃ、asammuyhanaṃ 处理成同位关系：“使明显，也就是所谓使清楚，就是对入出息不迷惑”。译文用“使它明显、使它清楚、对它不迷惑，都是……”，读起来像三件并列的事。
- **建议**：改为“使它明显，也就是使它清楚，就是对入出息不迷惑；这是靠以智进行入出息才做到的……”。

## §1165 句 66-1165-119-139

- **问题**：可读性 — 引文“觉知全身，我要入息，我要出息，他学”是逗号硬串，读者看不出“觉知全身”是“入息、出息”的方式，也看不出“他学”管的是整句。
- **建议**：改为“所以佛陀等称这样的人为‘他学：我要觉知全身而入息，我要觉知全身而出息’”。具体语序和本文“sikkhati”句式的定译保持一致。

## §1165 句 66-1165-147-158

- **问题**：增译 — tathā pubbābhisaṅkhārassa pavattattā 的意思是“因为预先的准备是这样进行的”，译文加了“针对开头”，比原文说得更具体。
- **建议**：改为“因为预先准备就是这样进行的”。是否针对开头，留给读者根据上下文去理解。

## §1166 句 66-1166-33-43

- **问题**：释义不一致 — nissaya 在这里把 tāya 读作伴随义：`ထိုသတိနှင့်။ (သဒ္ဓိံ-၌စပ်)`，即“与那念一起”，和下一句 tena manasikārena 的“连同……一起”同一结构。译文这句只译“以……念”，下一句才补出“连同”，两句平行的注释处理不一致。
- **建议**：释文改为“就是与以入出息为所缘而生起的那个念一起”。被解释词“以那念”保持和父层一致。

## §1167 句 66-1167-2-9

- **问题**：措辞 — paṭhamavatthudvaya 指前两项修习（长、短），“前面两事”不够清楚。
- **建议**：改为“最初的两项”。

## §1167 句 66-1167-29-53

- **问题**：取义 — Idaṃ pana dukkaraṃ 里的 idaṃ，nissaya 解作 `ဤတတိယအစရှိသော ဝတ္ထုသည်ကား`，即“这第三项等”。译文“而这里是难的”把指代对象变成了地点，指代不清。另外，“预先准备”和 §1165 不一致（见跨段一致性）。
- **建议**：改为“而这第三项等是难的，就像人在剃刀刃上行走……”。

## §1167 句 66-1167-62-72

- **问题**：引文边界 — 巴利引文只有 saṃvarasamādānānaṃ saṅgaho，“‘等’字”是译者补出的，现在被放进了引号，看起来像是“有些人”的原话。
- **建议**：改为“但有些人说，这里的‘等’字是‘摄入防护和受持’。”

## §1161 句 66-1161-2-30

- **问题**：术语（存疑，不是必改） — karajakāya 译“业生身”。这个词通常指由业所生的色身，这样译可以，但请核对 `terms.md` 和父层是否已有定译（另有“所造身”“色身”等译法）。另外，yathārahaṃ 译“按情况”，偏口语。
- **建议**：yathārahaṃ 改为“相应地”。karajakāya 定案后补进 `terms.md`。
