# Review — 66:498-504（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌／父层译文 ❌
> 本层是复注（ṭīkā），没有注入上一级注释书，也没有父层（义注《清净道论》对应段）的译文。因此**被解释词与父层逐字同译这一项无法机械核对**。下文凡涉及黑体被解释词的意见，都要在 harmonize 时拿父层译文复核。释义判断只能依据 pali 与 nissaya。

## 跨段一致性

- **paccavekkhaṇā**：§498、§499 译“省察”（省察深奥的智慧所运作的范围、省察正勤），§504 句 66-504-57-92 译“审察”（审察禅那与解脱）。同一组觉支因缘里的同一个词 → 建议统一为“省察”。黑体被解释词要以父层为准。
- **byagga / avikkhepa**：两个词都译成“散乱 / 不散乱”。§502 句 66-502-73-81 和 66-502-91-96 讲的是 byagga 的词源，句 66-502-104-115 讲的却是 avikkhepa。两者混为一词后，句 104-115 成了“就不散乱这一义来说，它也叫做不散乱相”，变成同义反复，复注借 avikkhepa 解释 abyagga 的用意就看不出来了。建议 vikkhepa / avikkhepa 保留“散乱 / 不散乱”，byagga / abyagga 另译，比如“分散 / 不分散”，并保留巴利夹注。
- **pahaṃsana / sampahaṃsana / tosanā / assāda / pamodana**：五个词的译法互相重叠：
  - pamodana 译“欢悦”（§501）
  - pahaṃsana 译“欢悦”，sampahaṃsana 译“振奋”（§504）
  - tosanā 和 assāda 都译“喜悦”（§504）

  另外“喜悦”容易被读成 pīti（喜）。建议：
  - sampahaṃsana / pahaṃsana 统一为“振奋”
  - pamodana 用“欢悦”
  - tosanā 用“满足”
  - assāda 用“滋味”或“乐味”
- **sammā**：§499 sammappadhāna 译“正勤”，§504 sammāpavatta 的被解释词译“正常转起”，释文却说“正确地转起” → 建议统一为“正确”。
- **piṇḍa**：§499 句 66-499-44-58 的被解释词译“托钵所得的食物”，同一句释文又译“团食” → 建议统一。
- **经文出处的位置**：
  - 句 66-498-74-96 紧跟引文之后
  - 句 66-499-78-108 和 66-500-11-25 放在句号之外的句末

  → 建议统一为紧跟引文或所引经名之后、句号之前。

## §498 句 66-498-7-47

- **问题**：句法。nissaya 把 tassa tassa 标为属格，修饰 atthaṃ（ထိုထိုနိကာယံ၏ 各部尼柯耶的），意思是“请问各部尼柯耶的意义”。译文“向他们请问各处的意义”把它读成了向阿阇黎请问的对象。
- **建议**：改为“……亲近承事诸位阿阇黎，请问每一部尼柯耶的意义”。

## §498 句 66-498-48-56

- **问题**：被解释词。黑体里塞进了父层的释义（“身体、衣服、住处等内外用物”）。被解释词应只译出 vatthuvisadakiriyā 本身，并与父层逐字相同。
- **建议**：黑体按父层译法，比如“使所依事物清洁”。展开的内容不放进黑体。

## §498 句 66-498-74-96

- **问题**：逻辑。vuttaṃ 是引经为证，译成“所以说”，把引文变成了上句推出的结论。
- **建议**：改为“正如经中所说：‘心得定的人如实了知。’”。

## §498 句 66-498-97-105

- **问题**：取义存疑。nissaya 把 bhattanikkhitta-kāka / maṃsanikkhitta-sunakha 解为“丢下饭团的乌鸦、丢下肉的狗”（ထမင်းခဲကို လွှတ်ချသောကျီး，“လွှတ်ချ”是放掉、丢下），译文作“守着饭食的乌鸦、守着肉的狗”，两者不合。另外 nissaya 给 mandabuddhīnaṃ 的释义“ပညာစုံ”（慧具足）疑为“ပညာနုံ”（慧弱）的讹误，译文“心智迟钝”是对的，记下备查。
- **建议**：依 nissaya 改为“像丢下饭团的乌鸦、丢下肉块的狗一样”。这一句的 confidence 要压低。

## §498 句 66-498-121-132

- **问题**：增义 / 句法。“唯有以深奥的智慧才能行于其中”里的“唯有”是原文没有的限定。nissaya 把 gambhīrañāṇehi 解为“具深智的人”（施事），不是工具“以智慧”。
- **建议**：改为“那些具有深奥智慧的人所行的蕴、处、界等”。被解释词里的“运作的范围”也请对照父层。

## §499 句 66-499-21-34

- **问题**：语义重复，被解释词存疑。
  - “殊胜成就，获得它”中，“成就”与“获得”叠用了。
  - 黑体“看到依靠精进……乃至……的利益”的语序，是按汉语重排后再插入省略号，省略的位置未必与父层被解释词对得上。
- **建议**：
  - 释文改为“获得依靠精进而来的世间与出世间的殊胜之法，这本身就是利益”。
  - 黑体按父层译文取首尾，再加“……乃至……”。

## §499 句 66-499-44-58

- **问题**：同一句里“托钵所得的食物”和“团食”并用，见跨段一致性。释文叠了“回报、敬重”“团食，也就是乞来的食物”两层，太冗长。
- **建议**：改为“以自己的正确修行，使布施资具的人对自己所作的供养成为有大果报的供养，以此来回报、敬重托钵所得的食物”。

## §499 句 66-499-122-132

- **问题**：句法。nissaya 把 paṭipakkhavidhamana-paccayūpasaṃhāra 解为一个整体：“带来摧破相违之法的缘”（ဆန့်ကျင်ဖက်ကိုပယ်ဖျောက်ခြင်း၏အကြောင်းကိုဆောင်ပေး）。译文拆成了“摧破相违的法、并聚集助缘”两件事。
- **建议**：参照 nissaya 改为“以提供摧破相违之法的助缘的方式”。也可以保留现在的译法，但这一句的 confidence 要压低。

## §500 句 66-500-2-10

- **问题**：词义。lūkha 指的是心对佛等缺乏净信与亲爱，像谷壳一样干硬，不是举止“粗鲁”。siniddha 与它相对，指心地润泽、有亲爱，而不是“温和”。
- **建议**：分别改为“心地干硬的人 / 心地柔润的人”这一类。被解释词以父层为准。

## §500 句 66-500-36-45

- **问题**：增译。原文只有 ete，没有 yathāvutta，“上面所说的”是添的，而且和前一句 66-500-26-35 的“上面所说的”（那里有 yathāvutta）重复了。
- **建议**：删去“上面所说的”。

## §501 句 66-501-15-20

- **问题**：词性。uddhataṃ 是形容词，修饰心，意思是“掉举的（心）”，不是名词“掉举”（uddhacca）。
- **建议**：被解释词改为“掉举的（心）”，并对照父层。

## §502 句 66-502-2-32

- **问题**：被解释词里的“就”是多出来的。taṃ ākāraṃ sallakkhetvā 意思是“观察那种样子之后”。
- **建议**：改为“**观察那种样子之后**”，以父层为准。

## §502 句 66-502-33-55

- **问题**：增义。tīsupi padesu 是“在这三处（三句）中”，黑体“上面这三段经文里”添了“上面”“经文”。
- **建议**：黑体按父层译法，比如“**在这三处**”。

## §502 句 66-502-73-81、66-502-91-96

- **问题**：译法不清。
  - nissaya 把 agga 解为“部分、所缘”（အဖို့အစုအာရုံ），译成“顶端”太字面，读者看不懂。
  - 句 91-96 的“只有一个顶端”是译者补的。
- **建议**：agga 改为“所向 / 所缘”一类的译法，比如“它有种种不同的所向（agga），所以叫 byagga”。byagga 的译法见跨段一致性。

## §502 句 66-502-104-115

- **问题**：结构与上文失去平行，词义也混淆了。
  - 原文“tasseva … adhivacanaṃ”和句 66-502-56-72“samathassevetamadhivacanaṃ”是平行句，后者译成了“正是止的同义语”，本句却丢了“同义语”的结构。
  - avikkhepa 与 abyagga 同译，造成同义反复。
- **建议**：改为“**以不散乱的意义来说，不分散相也正是它的同义语**”。

## §503 句 66-503-31-36

- **问题**：被解释词与释文矛盾。释文说“身与心都带着热恼”（sadarathakāyacittā），黑体却译成“身体粗重躁动的人”，把范围限在身体，“粗重”也没有依据。
- **建议**：改为“**身心躁动的人**”这一类，以父层为准。

## §504 句 66-504-29-37

- **问题**：层次混乱。原文的结构是：sammadeva pahaṃsanatā，接着用“先悚惧、后生净信”来说明，最后落到 tosanā。译文叠了“欢悦 / 振奋 / 喜悦”三个词，“也就是使心振奋”是多余的。
- **建议**：改为“**使它振奋**，就是好好地使心振奋：先使心生起悚惧，再由此生起净信，使修习的心得到满足”。

## §504 句 66-504-38-51

- **问题**：“正常”与“正确”不一致，见跨段一致性。
- **建议**：被解释词改为“**正确转起的（心）**”。

## §504 句 66-504-57-92

- **问题**：被解释词译“审察”，与前文的“省察”不一致，见跨段一致性。
- **建议**：统一为“省察”，并对照父层。
