# Review — 67:1356-1359（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／**父层（义注，即《清净道论》本文）❌ 未注入**
> ⚠ 本层是复注，被解释词（黑体）全部引自义注。这次没有拿到父层的原文和译文，**所以无法核查被解释词是否和父层逐字同译**。本报告里涉及黑体译法的建议都以「先对齐父层」为前提。需要在 harmonize 时补查的被解释词有：adassanato / āyanti / uppajjanti / bhaggā gacchantudassanaṃ / vijjuppādo…vayanti ca / vivaṭṭakappato paṭṭhāya uppajjanakarūpaṃ / dhammatārūpaṃ / ayo / lohaṃ / tipu / sīsaṃ / suvaṇṇaṃ / muttā / maṇi / veḷuriyo / saṅkho / silā / pavāḷaṃ / lohitaṅgaṃ / masāragallaṃ / bhūmi / tadassa / taruṇapallavavaṇṇaṃ / sabhāgarūpasantatiṃ / anuppabandhāpayamānaṃ / so / taṃ / pariggahetvā / iminā nayena / sabbampi / dhammatārūpaṃ。

## 跨段一致性
- **taṃ**：§1357 句 130-136 译「这种色」（指法性色），§1359 句 6-9 也译「这种色」，但复注明确说它指的是**无忧树的叶子**。同一个代词、指代不同，却都套用「这种色」，§1359 那一处还自相矛盾。建议两处都按父层译法改成中性代词（「它」「那个」），所指交给释文去说明。
- **loha**：§1357 句 25-29 和 §1359 句 24-27 都把 loha 译为「铜」；§1357 句 30-37 又说「铜泛指金属」；§1357 句 63-80 说明 loha 除了赤铜以外还包括吠甘多金属和其余各类。复注本身已经说明 loha 是一个宽泛的类名，译成「铜」既太窄，又容易和 tambaloha「赤铜」混淆。建议先看父层怎么译：如果父层定为「铜」，这里要保持一致，但 §1357 句 30-37 的说法要改（见下）；如果父层可以调整，建议在 harmonize 时一起改成「金属」类译名。
- **释词句式**：同一个 chunk 里混用了「X，是说Y」（§1356、§1359）、「X是说Y」（§1356 句 6-9）、「X是指Y」（§1357、§1358、§1359）、「X是Y」（§1357 句 103-125）、「X泛指Y」（§1357 句 30-37）。建议统一：用 `ti` 引出的释义一律写成「**X**，是说……」，用 `nāma` 的定义句一律写成「**X**是指……」。
- **adassana「不可见处」**：§1356 句 2-5 和句 21-32 都译成「处」「地方」，带有处所义。但本段的主旨正是「不从某个堆积处来、也不去到任何地方」（见句 10-20、句 21-32 的 upagamanābhāvato）。两处应该一起改成状态义（见下）。

## §1356 句 67-1356-2-5
- **问题**：取义。「从不可见处，是说从不能被看见的地方」把 adassana 和 apassitabbato 都译成了处所。nissaya 的主释是 `အပဿိတဗ္ဗတော= မမြင်အပ်သည်မှ`（从不该被看见者），异释是 `မမြင်အပ်သည်၏ အဖြစ်မှ`（从不被看见的**状态**），都没有处所义。下一句恰好在否认有一个「来处」。
- **建议**：改为「**从不可见中**，是说从不能被看见的状态中」（黑体以父层为准）。

## §1356 句 67-1356-10-20
- **问题**：风格。「堆积之处」半文。
- **建议**：改为「从某个堆积的地方而来」。

## §1356 句 67-1356-21-32
- **问题**：取义。「去往不可见处」同样有处所义，和同一句里「不会去到任何地方」互相冲突；「又」在原文里没有。另外，nissaya 补出的主语是 `ပျက်ပြီးသောသင်္ခါရတို့`（已坏灭的诸行），译文写的是「法」。
- **建议**：黑体按父层译出，释文改为「已经坏灭的诸行也因为不去到任何地方，所以完完全全归于不可见，也就是归于不存在」。

## §1357 句 67-1357-30-37
- **问题**：误译，句子自相矛盾。原文 `lohaṃ nāma … catubbidhaṃ` 只说「loha 有四种」，没有「泛指」的意思。「**铜**泛指金属」在汉语里说不通，因为铜本身就只是一种金属。
- **建议**：改为「**铜**（loha）有四种：天然金属、异类金属、人造金属、毗舍遮金属」。loha 的定名见上面的跨段一致性一条。

## §1357 句 67-1357-38-49／50-52（jāti / vijāti）
- **问题**：术语。jāti 和 vijāti 是一对正反词，译成「天然」和「异类」，对应关系不明显。nissaya 是 `သတ္တုစစ်`（纯正金属）对 `အမျိုးမစစ်သော သတ္တု`（种类不纯的金属）。
- **建议**：改成成对的译名，例如「纯种金属／杂种金属」或「本类金属／异类金属」。附带说明：nissaya 把 vekantaka 释为 `သံမဏိ`（钢），把 nāganāsika 释为 `ထယ်သံ`（犁铁），异释 `သံကြွပ်`（脆铁、生铁）。音译和直译都可以保留，但这两处的 confidence 应该压低，并写进术语报告。

## §1357 句 67-1357-89-91
- **问题**：误译。rasaviddha 里的 rasa 指的是**水银**（炼金用语），不是「汁液」。nissaya：`ပြဒါးဝင်သောရွှေ`（掺入水银的金）。
- **建议**：改为「**金**有从矿里出产的、用水银点化而成的等种类」。

## §1357 句 67-1357-95-102／123-125（masāragalla）
- **问题**：术语，和 nissaya 冲突。译文把 masāragalla 译成「猫眼石」，但本句 nissaya 把**猫眼石**（`ကြောင်မျက်ရွဲ`）对应到 veḷuriya，把 masāragalla 释为 `ပတ္တမြားပြောက်`（带斑纹的宝石）。复注自己的释义 kabaramaṇi 也是「杂色宝珠」。「猫眼石」既缺依据，又和 veḷuriya 的传统解释相撞。
- **建议**：采用传统汉译「玛瑙」（七宝里 masāragalla 的常见对译），两处统一修改，结果写进 terms。

## §1357 句 67-1357-109-114
- **问题**：误译。paṇḍu 是淡黄色或灰黄色，不是「白」。nissaya：`သလင်းဝါ`（黄水晶）。
- **建议**：「白石」改为「黄白色的石头」。

## §1357 句 67-1357-115-119
- **问题**：漏译，同语反复。「**珊瑚**是指珊瑚（vidduma）」等于没有解释，还漏掉了 vaṭṭumaṃ。夹注写的 vidduma 和原文的 viddhamaṃ 拼写也对不上。nissaya：`ဝဋ္ဋုမံ= အလုံးဖြင့်ပြီးသော`（圆形的），`ဝိဒ္ဓမံ= ဖောက်ထွင်းခြင်းဖြင့်ပြီးသော`（穿了孔的）。
- **建议**：按 nissaya 改为「**珊瑚**是指磨圆了、穿了孔的珊瑚」，去掉夹注。
- **原文疑问**：vaṭṭumaṃ viddhamaṃ 可能是 vidduma 的讹写或误衍，记入 known-issues，不改原文。

## §1359 句 67-1359-6-9
- **问题**：所指错误。见跨段一致性一节：taṃ 在这里是宾格，指无忧树的叶子，译成「这种色」不对。
- **建议**：改为「**它**是指无忧树的叶子」（黑体以父层为准）。

## §1358 句 67-1358-14-19
- **问题**：语法。anuppabandhāpayamāna 是使役现在分词，意思是「使……相续不断」，译文丢掉了使役义。
- **建议**：改为「**使它相续不断**，是说以因果前后相连的方式让它运转下去」（黑体以父层为准）。
- **原文疑问**：pali 作 pavattanti，nissaya 作 `ပဝတ္တံ`（分词），疑似讹误，记下。

## §1359 句 67-1359-51-56
- **问题**：取义。tattha tattheva 被译成「在各自那里」，是空间义。nissaya：`ထိုထိုအခိုက်အတံ့၌သာလျှင်`（就在各个当下），是时间义。
- **建议**：改为「就在各自当下噼啪作响地坏灭了」。这句引的是父层原文，引文要和父层译文逐字一致。

## §1359 句 67-1359-24-27
- **问题**：漏译（轻）。sabbampi 里的 pi（「也」）没有译出。
- **建议**：改为「**一切**有铁、铜等种类的**法性色**也是这样」，或在下一句补出「也」（下一句已有「也是」，可以接受，不改也行）。
