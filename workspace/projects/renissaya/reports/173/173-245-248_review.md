# Review — 173:245-248（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§245 无）／义注 ❌
> 本层是复注（ṭīkā）。父层义注的原文与译文**都没有注入**，所以复注黑体被解释词（ādevo / palāpo / guṇadosakittanaraso / sambhamapaccupaṭṭhāno / vatthubhāvo / bhiyyo）是否与义注译文逐字相同，**本次无法核对**。这一项需要在跨层统稿时补查。本报告的释义判断只以 nissaya 为依据。

## 跨段一致性
- domanassa：§247 译“忧苦”（“身苦和忧苦”），§248 译“忧”（“引发悲的忧”）→ 建议统一为“忧”，§247 改作“身苦和忧”。依据：dukkha/domanassa 是身苦与心忧的固定对举，“忧苦”会把 dukkha 的义混进来。
- kāyika / cetasika dukkha：§247 用“身苦”，§248 用“身体上和心上的苦” → 建议统一为“身体上的和心里的苦”或“身苦和心苦”，二者择一。
- ādev- 词族：§246 句1 中，ādevanti 译“哭泣”，ādevo 译“哭喊”，ādevana-sadda 译“哭喊的声音” → 建议统一为“哭喊”。这是同根的词源释义（“凭借它而哭喊，所以叫哭喊”），动词和名词译法不同，词源关系就断了。
- parideva 与 paridevana：全 chunk 中名词 parideva 都译“悲”，paridevana（-sadda / -nimitta）都译“悲泣”。这一区分前后一致，保留即可。

## §245 句 173-245-2-2
- **问题**：风格 — “悲的解说的注释”连用两个“的”，读起来拗口。
- **建议**：先对照本书其他章题的格式。如果没有统一格式，可改为“悲的解释·注释”或“《悲的解释》注释”。

## §246 句 173-246-2-18
- **问题**：跨段/句内一致性 — 被解释词里 ādevanti 译“哭泣”、ādevo 译“哭喊”，同根异译，词源释义失效（见上）。
- **建议**：改为“**人们凭借它而哭喊，所以叫哭喊**”。
- **问题**：术语 — karaṇabhāvena 译“当作手段”。这里的 karaṇa 是语法上的“具格（工具）”义，nissaya 作 `ကရဏဘာဝေန= ငိုကြွေးကြောင်း ကရိုဏ်း၏ အဖြစ်ဖြင့်`（作为“哭喊之因”的具格义）。
- **建议**：改为“作为工具（karaṇa）来说”，或“当作哭喊所凭借的工具”。“手段”过于日常化。

## §246 句 173-246-19-24
- **问题**：取义 — vīhipalāpa 指稻谷的秕糠/空壳。nissaya 作 `ကောက်စပါးတို့၏ ဖွဲအဖျင်း`，并补注“（像糠秕里没有米仁那样）”。译成“空瘪的稻谷”意思偏了，而且丢了 palāpa（糠秕）与 palāpa（空话）的双关。
- **建议**：改为“像稻谷的秕糠等一样空洞无实的话，就是**胡言**”。如需保留双关，可在注释里说明 palāpa 兼有“秕糠”义。

## §246 句 173-246-31-68
- **问题**：取义 — sokavatthuavighātena 译“愁的事由无法消除”。nissaya 作 `မပျက်သေးခြင်း မပျောက်သေးခြင်းကြောင့်`，意思是“还没有消失、还没有灭去”，指亲属亡故等事仍留在心中，并不是“无法”消除。§248 nissaya 所附的说明（`စိတ်ထဲ၌ … ပျောက်မသွားသေးဘဲ တည်ရှိနေခြင်း`）也是这个意思。
- **建议**：改为“因为愁的事由还留在心里、没有消失而生的慌乱”。
- **问题**：补出成分（轻）— 第一解的 upaṭṭhāti，nissaya 补出“（在听到哭声的人那里）显现”。译文“现起”没有交代对谁显现，读者不容易理解第一解和第二解的区别。
- **建议**：可补为“在旁人看来，悲泣的声音就显现为这个人的慌乱状态”。补不补由译者决定，但第二解（慌乱作为结果借哭声显露）和第一解要区分清楚。

## §247 句 173-247-2-15
- **问题**：术语 — dukkhadomanassānaṃ 译“身苦和忧苦”（见跨段一致性）。
- **建议**：改为“身苦和忧”。
- **问题**：取义（轻）— ñātiabbhatthaṅgamana 译“亲属不在了”，口语化而且含糊。nissaya 作 `ချုပ်ပျောက်ပျက်စီးခြင်း`（灭没、亡失）。
- **建议**：改为“亲属的亡故”或“亲属的灭亡”。
- **问题**：补出成分（轻）— muṭṭhipothana 译“用拳头捶打”，没有宾语。
- **建议**：改为“用拳头捶打（自己）等”，或“捶胸等”。

## §248 句 173-248-2-25
- **问题**：句法 — 整句没有交代“更加”的主语是什么，读者看不出是什么比忧和苦更甚。nissaya 注 `ဘိယျော= အလွန်။ (အဓိမတ္တံ ပုဒ်၌စပ်)`，说明 bhiyyo 与上文 adhimatta（过度）相连，被比较的是悲所引起的苦。“剧烈”是译者补出的，可以保留，但要补出比较的主体。
- **建议**：改为“**更加**：指这苦比起……更甚；……——这样就把由悲引起的其他身体上的和心里的苦也包括进来了。”
- **问题**：术语一致性 — “身体上和心上的苦”与 §247 的“身苦”不统一（见上）。
- **建议**：按跨段一致性一节统一。
