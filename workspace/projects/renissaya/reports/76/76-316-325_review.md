# Review — 76:316-325（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 部分（重复句多以 `(ပေ)` 省略，76-316-67-78、76-317-132-140、76-318 大部、76-321 至 76-322 大部、76-323-2-12 等句没有逐词条目）／义注 ❌（本次没有注入义注，**释义核对一项缺位**，以下结论只依据 pali 与 nissaya）
>
> 本层是本文（mūla），没有父层，所以不做被解释词逐字核对。

## 跨段一致性

- **Idhekacco puggalo**：§316 译“在这里，有一类人”，§324、§325 译“在这里，有的人” → 建议统一为“在这里，有一类人”（本章各节的开头都要统一）。
- **…ūpama 类名的译式**：§316 译“如水上划痕者”，§317 译“如粗麻布的人”，§320 译“如迦尸布的人” → 建议统一为“如……的人”（“……者”是文言句式），§316 改为“如水上划痕的人”。夹注巴利原词的做法也要统一：§316 注了整个复合词（udakalekhūpama），§317 只注了 potthaka，§320 没有注 → 建议都在类名首次出现时注 *-ūpama* 整词，或者都只注喻体，二者选一。
- **Tattha**：§317 译“其中”，§320 译“在这里” → nissaya 两处都是 `တတ္ထ= ထို ဥဒ္ဒေသ၌`（在那个列举里），统一为“其中”。“在这里”已经用来译 idha，容易混淆。
- **navo / majjhimo（布）**：§317 译“刚织成的／用过一段时间的”，§320 译“新的／中等新旧的” → 两组是平行句，必须同译。nissaya 对 majjhimo 的解释是 `သုံးစွဲခြင်းအားဖြင့် အလယ်၌ဖြစ်သော`（按使用程度居中，即用过一阵的），建议统一为“新的／用过一段时间的／旧的”。“刚织成的”是增译。
- **navo（比丘）**：§317 译“新比丘”，§321 译“新学比丘” → 统一为“新学比丘”（与“中座比丘”“长老比丘”成一个系列）。
- **戒腊夹注**：§318 写“中座比丘（戒腊五到九年）”，§322 没有，§317、§321 的新学比丘也没有注 → 括号里的说明来自 nissaya（`၅ ဝါပြည့်`／`ဆယ်ဝါပြည့်ဝ`），不是本文，不该进正文。建议正文删去，交给 footnote 步骤在首次出现时出脚注（新学：未满五夏；中座：五夏以上；长老：十夏以上）。
- **pāpadhammo / kalyāṇadhammo**：§317、§318 译“品性卑劣”，§321 译“有善法”，§322 译“品性良善” → 两词是一对反义词，统一为“品性卑劣／品性良善”，§321 必改。
- **dubbaṇṇa / vaṇṇavant・suvaṇṇatā**：“颜色难看”对“色泽美好”，用词不对称 → 建议改为“色泽难看／色泽美好”（或“颜色难看／颜色好看”），全 chunk 统一。
- **sevanti bhajanti payirupāsanti diṭṭhānugatiṃ āpajjanti / tesaṃ taṃ hoti**：§317、§318、§322 译“亲近他、结交他、陪侍他、效法他的人，这种亲近会给他们带来……”，§321 译“侍奉他、追随他的见解……这会给他们……” → 统一为前者，§321 的错误见下文。
- **ānisaṃsa 与 hita 撞词**：“大利益”（mahānisaṃsa）和“利益和安乐”（hitāya sukhāya）用了同一个“利益”，§321、§322 在同一段里同时出现，读者区分不了 → 建议 mahānisaṃsa 改为“大功德”，hita 保留“利益”。
- **vikiṇṇavāco / avikiṇṇavāco**：§324 译“言语放纵”，§325 译“言语有节制”，反义关系对不上（理由见 §324）。

## §316 句 76-316-2-9

- **问题**：风格 — “如水上划痕者”中的“……者”是文言句式，与本章其他类名不一致。
- **建议**：改为“如水上划痕的人（udakalekhūpama）”，76-316-79-101 句末的引号内同步改。

## §316 句 76-316-10-66

- **问题**：取义（低优先，缺义注）— 按 nissaya，saṃsandati / sandhiyati / sammodati 是 `နှီးနှော`（交融）/ `ဆက်စပ်`（接合）/ `ရောနှော`（和合），指被骂之后很快又和对方合好。“融为一体”说得过重，像是本来就亲密。“被人用……的话说”读起来也有点生硬。
- **建议**：可改为“即使别人用严厉的话、刺耳的话、难听的话对他说，他也仍然和对方相合、相投、和睦”。76-316-79-101 同步改。等有义注再定最终的译法，把该句的 confidence 调低。

## §317 句 76-317-11-43

- **问题**：增译 — navo 译成“刚织成的”，巴利原文只有“新的”。
- **建议**：改为“新的粗麻布”，与 §320 统一（见跨段一致性）。

## §318 句 76-318-2-18

- **问题**：正文混入注释 —“（戒腊五到九年）”出自 nissaya，不是本文。
- **建议**：正文删去，转为脚注。

## §319 句 76-319-13-30

- **问题**：误读 — `kiṃ … bhaṇitena`，nissaya 释为 `ဘဏိတေန= ပြောဟောခြင်းကြောင့်。ကိံ နုခေါ= အဘယ်အကျိုးရှိအံ့နည်း`（因为说话，能有什么益处？），意思是“说了有什么用”。译文“说什么话呢”把它译成了斥责对方说的内容，丢掉了“无益”的意思。
- **建议**：改为“你这个愚笨无知的人说话有什么用！你也以为自己有资格说话吗？”

## §319 句 76-319-31-46

- **问题**：语序生硬，喻义没有落实 — 按 nissaya，ukkhipati 一边是喻体里的“扔出去”（`မြှောက်ကော်ပစ်ချ`），一边是对比丘作举罪羯磨（`ဥက္ခေပနီယကံ ပြု`），是双关。“让僧团因此举罪他的话”读起来不顺。
- **建议**：改为“他就会生气、不高兴，说出那种会让僧团因此对他作举罪羯磨的话——就像人们把那块粗麻布扔到垃圾堆上一样”。双关意思可以加脚注说明。

## §320 句 76-320-2-10

- **问题**：跨段不一致 — Tattha 译成了“在这里”，类名没有夹注。
- **建议**：改为“117. 其中，哪三种是如迦尸布的人？”，夹注做法按跨段一致性一节统一。

## §320 句 76-320-11-34

- **问题**：跨段不一致 — majjhimaṃ 译“中等新旧的”，§317 译“用过一段时间的”。
- **建议**：改为“用过一段时间的迦尸布”。

## §321 句 76-321-14-24

- **问题**：误译、跨段不一致 — kalyāṇadhammo 译成“有善法”，与 §322“品性良善”不统一，也和反义词 pāpadhammo“品性卑劣”对不上。
- **建议**：改为“如果新学比丘持戒、品性良善，这就是他的‘色泽美好’”（词对统一后同步改）。

## §321 句 76-321-34-49

- **问题**：误译（**必改**）— diṭṭhānugatiṃ āpajjanti 中的 diṭṭha 是“所见”，不是“见解”（diṭṭhi）。nissaya：`ဒိဋ္ဌာနဂတိံ= မြင်အပ်သော အမှုကို အတုလိုက်ခြင်းသို့`（照着所见的行为去仿效）。“追随他的见解”译错了。另外 payirupāsanti 译成了“侍奉”，taṃ 译成了“这”，都和平行句不一致。
- **建议**：改为“那些亲近他、结交他、陪侍他、效法他的人，这种亲近会给他们带来长久的利益和安乐”。

## §317 句 76-317-113-128（§318、§321、§322 同句同理）

- **问题**：取义（低优先）— nissaya 把 taṃ 释为 `ထိုခံယူခြင်း`（他的那个接受）。译文作“这样的布施”，主语从受者的“接受”换成了施者的“布施”，意思大体相当，但不贴原文。
- **建议**：可改为“对那些人来说，他的这种接受没有大果报，也没有大功德”；或者保留现译，在报告里记录这个分歧。四处同步处理。

## §323 句 76-323-28-38

- **问题**：增译 — ādheyyaṃ gacchati 按 nissaya 是 `စိတ်၌ ထားထိုက်သည်၏ အဖြစ်သို့ ဂစ္ဆတိ`（成为值得记在心里的），“珍重地顶戴”是多出来的。这里和 §319 一样有双关（喻体里迦尸布“被收藏起来”）。
- **建议**：改为“他的话会被大家记在心里，就像人们把那块迦尸布收藏在香匣里一样”。

## §324 句 76-324-11-33

- **问题 1**：误译（**必改**）— pākaṭindriyo 是“诸根显露”。nissaya：`ပေါ်လွင်ထင်ရှားသော ဣန္ဒြေ ရှိသည်`（诸根外露、明显）。译文“诸根不加守护”是照反义词 saṃvutindriyo 倒推出来的，丢了“外露、一看就知道”的意思，而这正是此人“容易测度”的原因。
- **建议**：改为“诸根外露”。
- **问题 2**：词义偏移 — vikiṇṇavāco 按 nissaya 是 `ဖရိုဖဲ ပြန့်ကျဲသော စကား`（话杂乱散漫），“言语放纵”偏向“放肆”。vibbhantacitto 是 `မရပ်မတည် ချာချာလည်သော စိတ်`（心不安定、打转），“心意迷乱”偏向“糊涂”。
- **建议**：改为“说话杂乱”“心意散乱”。§325 的反义词同步改为“说话不杂乱”。
- **问题 3**：跨段不一致 —“有的人”（见跨段一致性）。

## §325 句 76-325-10-33

- **问题**：跨段不一致 — avikiṇṇavāco 译“言语有节制”，与 §324 对不上；Idhekacco 译“有的人”。
- **建议**：改为“说话不杂乱”“在这里，有一类人”。
