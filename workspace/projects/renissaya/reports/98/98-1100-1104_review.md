## 跨段一致性

- **kāmaguṇa**：标题和多数句子译作“欲种”。但 98-1101-103-110 的释义、98-1103-2-12 和 98-1103-25-32 的被解释词都凭空加了“五”。只有 98-1101-58-74 的经文原有 pañca，那里译“五欲种”是对的。→ 建议原文无 pañca 处一律译“欲种”。依据是 nissaya：`ကာမဂုဏာ= ကာမဂုဏ်တို့`，没有数词。
- **sakasamaya / sakavādī、parasamaya / paravādī**：两组词都译成“自宗 / 他宗”。samaya 指宗义，vādī 指论者，二者不同。98-1102-8-22 已经出现“他宗……再被问到意时，**他**着眼于……”，用“宗”作人称主语并不自然。→ 建议 samaya 译“自宗 / 他宗”，vādī 译“自论者 / 他论者”（论事传统译法）。涉及 98-1101-10-20、98-1101-55-57、98-1101-84-96、98-1102-8-22、98-1102-23-34、98-1103-13-24，同时要与父层的说话人标签对齐。
- **kamanīyaṭṭhena / kamanaṭṭhena**：98-1101-21-30 至 98-1101-42-54 译作“因为是被欲求的 / 因为是能欲求的”，98-1101-128-137 和 98-1101-138-143 改成“就被欲求的意义来说 / 按能欲求的意义来说”。同一套 -aṭṭhena 公式前后两种句式。→ 建议统一为“因为是被欲求的 / 因为是能欲求的”。
- **chanda 与 kāma 撞词**：chanda 译“欲求”，kamana / kamanīya 也用“欲求”。于是 98-1101-128-137 读成“这些欲求……就被欲求的意义来说”，读者分不清 chanda 和 kāma。→ 建议 chanda 改译“意欲”。父层本文的 tappaṭisaṃyutto chando 也要同步。
- **paṭisaṃyutta**：同一词在被解释词里译“相关”，在释义里译“相连结”（98-1101-103-110）。→ 建议统一为“相关”。
- **“意思是 / 这就是意思”**：98-1101-103-110 用“意思是”，98-1101-138-143 用句末“——这就是意思”。→ 建议统一。句末形式也可以改为“意思是：……”前置。

## §1101 句 98-1101-21-30
- **问题**：词级 — sabhāvanissattasuññataṭṭhena 译“是空的”，范围过宽。nissaya：`အတ္တမှ ကင်းသည်၏အဖြစ်` 意为“离我的状态”，这里的 suññata 是空于我，不是泛泛的“空”。“具有自性”也略偏，nissaya 作 `ပရမတ္ထသဘာဝ၏ အဖြစ်`，即“是究竟自性”。
- **建议**：改为“因为是（究竟的）自性、不是有情、空无我，所以是界”。

## §1101 句 98-1101-97-102
- **问题**：误读倾向和翻译腔 — Nanu atthi 是反诘，意为“难道不是有……吗”，相当于“难道没有……吗”。现译“不是有……”读来像否定陈述。这里是被解释词，必须与父层一致。
- **建议**：先查父层的译法，照录。如果父层也是“不是有”，建议回到本文一起改为“难道没有……”。

## §1101 句 98-1101-103-110
- **问题**：被解释词断裂（必改）。
  - tappaṭisaṃyutto 字面是“与之相关的”。现译把义注的释义（kāmaguṇa）提前塞进了被解释词，结果变成“与欲种相关的，指与五欲种相连结”，同义反复，也几乎不可能与父层逐字相同。
  - 释义里多出了“五”。
- **建议**：被解释词照父层译文，大概是“与之相关的”。释义改为“就是与欲种相关的，意思是以欲种为所缘”。

## §1103 句 98-1103-33-43
- **问题 1**：格式 — “欲有（也就是欲界）”用圆括号作插注。按 style.md，圆括号只用于夹注巴利原词。kāmadhātusaṅkhāta 是定语，nissaya 作 `ကာမဓာတ်ဟု ဆိုအပ်သော`，即“称为欲界的”。
- **问题 2**：措辞 — 众生的 upaga 也译“导向”，即“众生也只是导向欲有的”，不够通顺。
- **建议**：改为“因为业只有导向称为欲界的欲有的，众生也只是往生欲有的”。

- **建议**：改为“所有问答都应当用这个方法来理解意思”。

## OCR / 原文疑问
- 98-1102-23-34 说 sabbopi tebhūmakamano kāmadhātuyeva，即“一切三地的意都是欲界”，教义上不寻常，色界和无色界的心也被归入欲界。译文忠于原文，不用改。但这一句应压低 confidence，等拿到复注后核对其用意（可能是就“五欲种以意为第六”的经证而言）。
