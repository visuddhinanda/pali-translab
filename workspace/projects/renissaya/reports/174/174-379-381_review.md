# Review — 174:379-381（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（内含 anuṭīkā 引文）／义注（父层）❌
> ⚠ 本层为复注，父层义注的原文与译文都没有注入，所以**被解释词与父层逐字同译的核对没法做**。需要补跑父层对照的有：§380 的 **cullāsīti … pe … ādivacanavasena**、**muhuttaṃ muhuttaṃ**，以及 §379 和 §381 的标题 Cittaṭṭhitikathā。

## 跨段一致性
- paravādī 的指称：§380 句 54-67 明确译作“他论者”。§380 句 2-22 中同一个主体（nissaya：`အဓိပ္ပါယော= ပရဝါဒီ၏ အလိုတည်း`）只译成“他认为”，读者看不出“他”是谁。建议统一明确为“他论者”。
- ṭhāna / tiṭṭhati（心的持续）：标题用“住”（心住论），§380 句 2-22 用“持续”，句 48-53 也用“持续”，而句 23-47 的偈文用“存活”。偈文说的是天神寿命，用“存活”可以接受。但讲**心**的场合，建议在“住”和“持续”之间定一个，与标题“心住”呼应，并登记进 `terms.md`。

## §380 句 174-380-2-22
- **问题**：句法与补出成分。`evaṃ yāvatāyukaṭṭhānaṃ` 的主体是“一个心”。nissaya 补出：`ဧဝံ= ဤသို့တစ်ခုတည်းသော စိတ်သည် အသက်ထက်ဆုံးတည်၏`，即“一个心持续到寿命终了”。译文“像这样持续整个寿命”缺了主体，意思悬空。
- **问题**：施事不明。“他认为……否认”中的“他”就是他论者（见上文跨段一致性）。
- **问题**：被解释词。粗体段扩写成了“依据‘那些天神存活八万四千劫’等说法”，原文粗体只有 cullāsīti … pe … ādivacanavasena。扩写内容必须与父层义注里这句偈的译文逐字一致，目前无法核对，需要补父层后复查。
- **建议**：改为“……意思是：他论者认为，一个心像这样持续到寿命终了，只是就无色界说的，不是就别处说的，所以否认（无色界以外的情况）。”

## §380 句 174-380-23-47
- **问题**：格误读。nissaya 把 `Etena` 释为 `ဤ…ပြောဆိုလေ့ရှိသောပရဝါဒီသည်`，意思是“持这种说法的他论者”。这里是具格施事，与 `passitabbā` 连读：这位他论者应当参看第二个半偈。anuṭīkā 的引文 `ဧကမေဝ စိတ္တံ…တိဋ္ဌတီတိ ဧဝံဝါဒိနာ` 说的也是同一回事。译文“由此”把它读成了工具或理由，是误读。
- **问题**：偈义添译。原句 `na tveva tepi tiṭṭhanti, dvīhi cittasamohitā`，nissaya 释为：`ထို ဗြဟ္မာတို့ သော်မှလည်း… ၂-ခုသော စိတ်တို့သည် အတူပေါင်း၍ ထားအပ်ကုန်သည် ဖြစ်၍ မတည်နိုင်ကုန်`，即“即使是那些梵天，也不能以两个心结合在一起而住”。译文“存活不过与两个心相连的时间”多出了“时间”和“存活不过”这层比较，意思走了样。
- **问题**：`dutiyāpi` 中的 api 修饰 dutiyā，意思是“第二个半偈也……”。译文把“也”挪到了动词前。
- **建议**：改为“不过，持这种说法的他论者也应当参看第二个半偈：‘但即使是他们，也不能以两个心结合在一起而住’（大义释10，文字略有不同）。”偈文的最终译法要与大义释的译文对齐。

## §380 句 174-380-48-53
- **问题**：背景补出不足。按 anuṭīkā（nissaya 引文 `ပုရိမာယ…ဝဿသတံ တိဋ္ဌတီတိ ပုစ္ဆာယ အာမန္တာတိ အနုညာ ကတာ`），“承认”指的是他论者在前面问到“住一百年吗”时回答“是”，与后面关于人类的否认相对。译文“前面对持续一百年等的承认”没交代是谁、在哪一问里承认的，读者难以理解为什么需要说明“不矛盾”。
- **建议**：改为“也应当说明，这与前面（他论者）认可‘住一百年’等说法并不矛盾。”其中“住”或“持续”按跨段一致性一节的定案统一。
