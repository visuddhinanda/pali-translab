# Review — 174:741-744（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌（父层译文未注入）
> ⚠ 本层是复注（ṭīkā），黑体被解释词引自义注。本次**没有父层译文**，所以被解释词逐字一致这一项**无法核查**，需要在 harmonize 时机械补查。涉及的被解释词有：**heṭṭhā**（前面）、**āgatapariyāpannakathāyaṃ**、Samāpattesiyan、**arūperūpakathāyaṃ**。

## 跨段一致性
- **avacara 与 pariyāpanna 译法相近，容易混淆**：
  - 741、742-5-17、743 把 `rūpāvacara / arūpāvacara` 都译成“**属于**色界、无色界”。
  - 742-5-17 把 `pariyāpanna` 译成“**所摄**”。
  - 本段正是把本论引回第十四品的 pariyāpanna 论来讨论，两个概念需要分清。但“属于”在现代汉语里恰好就是 pariyāpanna（“包含在…之内”）的意思，读者会把 avacara 与 pariyāpanna 看成同一个东西。
  - 建议：avacara 改译“色界的／无色界的”，或用法相译名“色界所行”，把“属于／所摄”留给 pariyāpanna。
  - 依据：这是两个独立的法相术语。品题与本文、义注逐字相关，**改之前须先核对本文与义注的品题译法**，三层统一改，不要只改复注。
- `arūpa` 与 `arūpāvacara`：742-26-57 的“无色界中有色”（arūpe）与“属于无色界的色”（arūpāvacaraṃ）区分得当。如果按上一条修改，后者要随之变为“无色界的色”。

## §742 句 174-742-18-25
- **问题**：被解释词未核／取义 — `samāpattesiya`（samāpatti + esiya）在第十四品 pariyāpanna 论中与 `upapattesiya` 成对出现，指“以等至为所求的”。“寻求等至的”字面上不算错，但脱离上下文难懂。另外，这是引自义注的被解释词，必须与义注、以及第十四品本文的译法逐字相同。
- **建议**：先对照义注和第十四品本文的译法，照原样采用；本句不要单独另译。

## §742 句 174-742-26-57
- **问题**：句法归属略有偏移。nissaya 的分析是：`အရူပါဝစရကမ္မဿ ... ကတတ္တာ= ပြုအပ်ပြီး၏ အဖြစ်ကြောင့်`（因为造作了无色界业）修饰 `ယံ ရူပံ ... ဝုတ္တံ`（所说的那种色）。意思是：**以无色界业为理由**，把那种色说成“属于无色界”，这是论敌立论的依据。译文“指的是由于造作了无色界业而生的色”把它变成了对术语的定义，原文中“以业为由而说”的立论意味被弱化了。
- **建议**：可改为“这里因为造作了无色界业，就把那种色说成‘有无色界的色’；对此应当说的，都按第八品**关于‘无色界中有色’的讨论**（论事义注524-526）中已经说过的方式理解。”其中“无色界的”的写法随跨段一致性那一条的决定调整。

## §742 句 174-742-5-17
- **问题**：被解释词未核 — **前面**（heṭṭhā）、**出现过的关于‘所摄’的讨论**（āgatapariyāpannakathāyaṃ）都要与义注逐字相同。nissaya 标注 `(ဝုတ္တနယမေဝ= ၌စပ်။)`，说明这里的处格要连到下一句的 vuttanayameva。译文拆成两句，用“那里”承接，意思没有断，可以保留。
- **建议**：只补核被解释词，不必改句式。
