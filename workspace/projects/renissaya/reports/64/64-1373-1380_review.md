# Review — 64:1373-1380（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 部分（64-1376-24-55、64-1376-56-67、64-1377-20-25 无 nissaya；64-1377-2-19 的 nissaya 只有首尾，中间以 ပ 省略；64-1378-2-8 只有两个词条）／义注 ❌ 未注入（本书是《清净道论》，所以本层就是本文；其注释书《大疏》本次没有提供，释义只能依据 nissaya 与原文）

## 跨段一致性
- jhāna：§1376 句 56-67 译“禅那”，§1376 句 68-74 译“禅” → 建议统一为“禅那”。依据：同一段前后两句说的是同一个禅那；“禅支”（jhānaṅga）是复合词，可以保留。
- kathā：§1373 标题译“论”，§1380 结语 vitthārakathā 译“详细解说” → 建议标题也改为“解说”，与结语呼应。例如“6. 天随念（devatānussati）的解说”。此外，现在的夹注插在“天随念”和“论”中间，读起来也不顺。
- appamāda／修习：§1378 译“不放逸”，§1379 又加了“勤修”，同一个 appamādaṃ kayirātha 被拆成两个谓语（详见下文 §1379）。
- 其余用词前后一致：sakkhiṭṭhāne ṭhapetvā 都译“以天神作为见证”，rāgapariyuṭṭhitaṃ 都译“被贪所缠”，guṇa 都译“功德”。

## §1374 句 64-1374-15-58
- **问题**：取义 / 补出成分 — ito 与 tattha 只译成“从这里”“那里”。nissaya：`ဣတော= ဤလူ့ဘုံမှ`（从这人间），`တတ္ထ= ထိုနတ်ဘုံ၌`（在那天界）。现在的译法读者不易看出“这里”和“那里”各指什么。
- **建议**：改为“从这人间死后，生到了那天界”。后面 64-1374-68-101 的同一句式也照此统一。
- **问题**：可读性 — “那些天神具备了怎样的信……我也有同样的信”是 yathārūpa…tathārūpa 的关联句式。“具备了怎样的信”单独读像疑问句，后面三个省略句（“具备了怎样的戒……”等）尤其明显。
- **建议**：改成关联句式，例如“那些天神具备什么样的信，从这人间死后生到了那天界，我也有那样的信”，戒、闻、舍、慧各句照此改。

## §1376 句 64-1376-2-23
- **问题**：句法 — anussarato cassa 是属格，意思是“对随念者来说”。译文写成“……的人，“在那个时候，他的心……”，主题悬空，又和引文里的“他”重复。
- **建议**：改为“所以，对于先随念天神的功德、然后随念自己所具有的信等功德的人来说，“在那个时候，他的心不会被贪所缠，”。另外，nissaya 把 pubbabhāge 释为 `ဘာဝနာအားထုတ်စ၌`（开始修习时），把 aparabhāge 释为后面的正式修习阶段，现在的“先……然后……”可以保留。

## §1376 句 64-1376-56-67
- **问题**：误读倾向 — nānappakāraguṇānussaraṇādhimuttatāya 的意思是“心倾向于随念多种多样的功德”。所缘分散，所以达不到安止。“专注于”在汉语里暗示心一境性，这恰好是安止的条件，和原文的因果关系正好相反。
- **建议**：改为“或者由于倾心于随念种种不同的功德”。

## §1376 句 64-1376-68-74
- **问题**：漏译补出成分 — nissaya：`ဂုဏသဒိသသဒ္ဓါဒိဂုဏာနုဿရဏဝသေန= …တူသော မိမိသဒ္ဒါစသော ဂုဏ်ကို…`，明确说随念的是“与天神功德相似的**自己的**信等功德”。译文没有“自己的”，读者会误以为随念的仍是天神的功德，这正是本章 1374–1376 反复辨明的要点。
- **建议**：改为“这个禅那因为是随念自己那些与天神功德相似的信等功德，所以称为“天随念”。”（同时按跨段一致性统一为“禅那”。）

## §1379 句 64-1379-2-7（连同 §1378 句 64-1378-2-8）
- **问题**：误译 / 增译 — 偈颂的结构是：有智慧的人应当常常在（locative）这样具有大威力的天随念上不放逸。nissaya：`ဒေဝတာနုဿတိယာ= ၌`，`သဒါ= သိမ်း`，`အပ္ပမာဒံ= ကို`，`ကယိရာထ= ရာ၏`。译文第一行已有“应当不放逸”，第二行又加了原文没有的谓语“勤修”，合起来成了“应当不放逸，时常勤修……”两个并列动作。
- **建议**：只保留一个谓语，并保留分行。例如：
  - 第一行：“所以，有智慧的人确实应当不放逸地”
  - 第二行：“时常修习这样具有大威力的天随念。”

## §1380 句 64-1380-2-5
- **问题**：漏译 — vitthārakathāmukhaṃ 里的 mukha（门径、纲要）没有译出。nissaya：`ဝိတ္ထာရကထာမုခံ= တည်း`。
- **建议**：改为“以上是关于天随念的详细解说的纲要”。如果前几章同类结语已有定译，就跟前几章一致。

## §1376 句 64-1376-24-55
- **问题**：术语（存疑，记录待定）— dosa 译“嗔”。传统汉译多作“瞋”，terms.md 目前未登记。本句无 nissaya。
- **建议**：先查看前几章（佛随念、法随念等）的 dosa 用字，统一后补进 terms.md。
