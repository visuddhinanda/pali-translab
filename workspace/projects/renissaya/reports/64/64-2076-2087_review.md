# Review — 64:2076-2087（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§2085、§2087 无 nissaya 单元，§2085 的词释并入 §2086）／义注 ❌ 未注入。本书是《清净道论》，没有严格意义上的义注；其注释书为复注 Paramatthamañjūsā。nissaya 在 §2079、§2082 两处引了 ṭī 1.420 / 1.421，但复注原文没有注入，所以本报告的释义判断只依据 pali 与 nissaya。

## 跨段一致性

- **makkhita / makkheti**：§2078 译“涂满”，§2079 译“涂上了”，§2080 又译“涂满” → 建议统一。§2079 的明喻（像涂了油一样）宜用“涂上”，§2078、§2080 是实写，可以保留“涂满”；或者全文统一为“涂满”。
- **kuṇapa**：§2081 的 kuṇapagandha 译“尸臭”，复合词里的 kuṇapa 译“死蛇、死狗、死人”，§2083 的 nānākuṇapāni 译“尸秽之物” → 后者含文言“之”，另见 §2083 条。
- **结句“evaṃ … paṭikkūlatā paccavekkhitabbā”的标点**：§2076、§2078、§2079、§2080、§2081、§2082 都用“——应当这样从…方面省察它的可厌性”，§2083 却断成“。应当这样…” → 统一用破折号。
- **偈颂引号**：§2085 开了“，§2086 偈末没有闭合，§2087 又开了一个“，全角引号不配对 → 核对后文偈颂的收尾位置，保证引号成对。

## §2076 句 64-2076-14-23
- **问题**：漏译 — 呼格 **bho** 没有译出。nissaya：`ဘော= အချင်းတို့`（诸位、朋友们）。
- **建议**：“诸位啊，食物实在令人厌恶！”或“朋友们，唉，食物实在令人厌恶啊！”

## §2077 句 64-2077-8-31
- **问题**：增译 — “邀请他**一起**吃”。nimantetum 只是“邀请（他享用）”，“一起”是译者加的。
- **建议**：“还可以邀请他（来吃）”。

## §2079 句 64-2079-8-24
- **问题**：语法误读 — **pavisamāno** 是现在分词（“正在进入时”），译文“进入体内**之后**”译成了完成义。nissaya 在此特意加注，说明作者为什么用 pavisamāno 而不用 paviṭṭho，理由见 ṭī 1.420。可见这里的时态区分是有意的，不能抹平。
- **建议**：“这样被受用的食物正在进入体内的时候，……”

## §2079 句 64-2079-31-42、64-2079-43-51
- **问题**：术语 — “摩度迦油”“那伽巴拉叶”是音译的罕见植物名，首次出现没有附巴利原词或简注，不符合 style.md 第二节。nissaya 的释义分别是 `သစ်မည်စည်ဆီ`（某种树油）、`ဝက်ချေးနဲရွက်ရည်`（某种植物叶汁）。
- **建议**：首次出现时夹注，如“摩度迦（madhuka）树油”“那伽巴拉（nāgabala）叶汁”。

## §2080 句 64-2080-34-54 + 64-2080-55-64
- **问题**：误译（必改） — 原文是省略式：二十岁的人吃下去就停二十年，……九十岁的人就停九十年。nissaya 把省略补全了：`နဝုတိဝဿာနိ= အနှစ်ကိုးဆယ်တို့ပတ်လုံး … ပတိဋ္ဌဟတိ`（停留九十年）。现在的译文把二十到九十岁与一百岁并列，后面只接“一百年”，读者会理解成所有人吃下的食物都停留一百年。
- **建议**：34-54 补成“如果是二十岁、三十岁……九十岁的人吞下它，它就分别停留在像二十年、三十年……九十年没有清洗过的粪坑那样的地方；”；55-64 保留“如果是一百岁的人吞下它，它就停留在一个像一百年……”。

## §2081 句 64-2081-8-57
- **问题**：译窄 — **tato purime divasepi** 意思是“比昨天更早的那些日子”。nissaya：`ရှေးရှေးသောနေ့`（更早更早的日子）。译文的“前天”只指一天。
- **建议**：“当天、昨天以及更早以前吞下的一切”。

## §2083 句 64-2083-8-25
- **问题 1**：语体（必改） — “各种尸秽**之**物”用了文言虚词“之”。
- **建议**：“各种像腐尸一样污秽的东西”。
- **问题 2**：词义错位 — nissaya：`ကဏ္ဍု= ယားနာ`（痒疹）、`ကစ္ဆု= ဝဲနာ`（疥）。译文的“疥、痒疹”与 kaṇḍu、kacchu 的顺序对调了。
- **建议**：改为“癣、痒疹、疥、麻风……”。
- **问题 3**：标点 — 见跨段一致性，“。应当这样”改为“——应当这样”。

## §2084 句 64-2084-23-27
- **问题**：连词不当 — api 在这里是“也、可以”，不是让步。“哪怕……；……却……”与下一句接不上。
- **建议**：“吃的时候，可以有一大群人陪着一起吃；”。

## §2084 句 64-2084-45-52
- **问题**：取义偏重 — **maṅkubhūto** 意思是难堪、窘迫。nissaya：`နှလုံးနာ`（心里难受）。“羞愧难当”偏重了“愧”，而且与下一句 harāyamāno 的“羞耻”重叠。
- **建议**：“满心作呕，十分难堪”。

## §2086 句 64-2086-2-7
- **问题**：格式 — 偈颂引号没有闭合，与 §2087 的开引号嵌套不配对（见跨段一致性）。
- **建议**：按原文偈颂的起止补“”，保证全角引号成对。
