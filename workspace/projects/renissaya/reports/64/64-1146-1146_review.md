# Review — 64:1146-1146（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌（本层未注入义注，释义核对只能依 nissaya 与本文上下文，结论需在有义注时复核）
> 层次：本文（mūla），无父层，被解释词对父层的核查不适用。本段的黑体词（vaṇṇato / liṅga / saṇṭhānato / disokāsā / paricchedato / ninnato / thalato / sandhito / vivarato / samantato）是引自前文“十一种方式”列举的词，须与那一段（约 §1145）的译法逐字一致，本 chunk 里看不到那一段，需另行核对。

## 跨段一致性
- **-to 类方式词的句式**：§1146 首句 vaṇṇato 译成“按**颜色**去看”，其后 liṅgato / saṇṭhānato / paricchedato / ninnato / thalato / sandhito / vivarato / samantato 都译成“从 X 方面”。这是同一组“十一种方式”，建议首句统一为“从**颜色**方面”。另外“按”在其余各句专门对应 `vasena`（按手、脚……／按长、短……），首句用“按”译 `-to`，与后文的分工冲突。
- **pana 的译法**：§1146 句 33-37、58-68、84-90、96-105 句首都用“而”。nissaya 这几处作 `ထိုမှတပါး`（此外）／`ဆက်၍ဆိုအံ့`（接着说），是递进而不是转折。连用四个转折义的“而”，读起来像在逐条反驳前句。建议改为“此外／再者”或直接省略。
- **ninna / thala**：句 58-68 译“凹处／凸处”，句 69-83 讲的是人和骨所在的地势，也译“凹处／凸处”。nissaya 后者作 `နိမ့်ဝှမ်းသောအရပ်`（低洼处）／`မြင့်မိုသော ကုန်းကြည်း`（高地）。建议两句统一用“低处／高处”，既能指骨面的高低，也能指地势（见下）。

## §1146 句 64-1146-2-15
- **问题**：误增成分。译文说“那个**相**就不会显现”，但原文 `na upaṭṭhāti` 的主语是 `taṃ`（骨）。nissaya 把 `တံ အဋ္ဌိကံ` 释作宾格／主格两读，并补出 `(သဘာဝတော= ပဋိကူလသဘောအားဖြင့်)`，即“（它）不以厌恶的本性显现”。nimitta 要到本段末句才出现，这里增出“相”，改变了句意。
- **建议**：“但如果从**颜色**方面把它看作白的，它就不会以厌恶的样子显现，而会与白遍相混。”

## §1146 句 64-1146-21-26
- **问题**：术语，需复核。liṅga 译“形相”，与紧接着的 saṇṭhāna“形状”太接近，读者难以分辨这两种方式。而且本句自己就解释了 liṅga 指“手等部位”，“形相”在汉语里又常让人联想到 nimitta／ākāra。
- **建议**：考虑译为“肢分”或“部位”（如“所谓**肢分**，在这里是手等部位的名称”），并与 §1145 列举处同步统一。有义注时据义注定案；在此之前该句 confidence 宜压低。

## §1146 句 64-1146-38-41
- **问题**：语句不通顺。“方位、处所同前面所说的方法一样”，主语和“方法”搭配不当。
- **建议**：“**方位**和**处所**，就按前面所说的方法。”

## §1146 句 64-1146-42-57
- **问题**：指代错误。`yadeva` 在 nissaya 中作 `အကြင် အရိုးသည်သာလျှင်`（哪一块骨），`ettha` 作 `ဤ အရိုးအပေါင်းတို့တွင်`（在这些骨之中）。译文的“这里面哪一**处**”把“骨”泛化成了“处”。
- **建议**：“……确定之后，在这些骨中，哪一块变得清晰、显现出来，就取那一块来达到安止。”

## §1146 句 64-1146-58-68
- **问题**：译法与下句不兼容（见跨段一致性）。
- **建议**：“此外，应当从**低处**和**高处**方面，按每一块骨低陷的部位和隆起的部位加以确定。”

## §1146 句 64-1146-69-83
- **问题 1**：误译地势。nissaya 指地势的低洼与高地，“我站在凹处”不合汉语习惯。
- **问题 2**：语气弱化。`-pi vavatthapetabbaṃ` 是“也应当确定”，译成“也可以”把义务变成了许可。
- **建议**：“也应当按位置来确定：我站在低处，骨在高处；我在高处，骨在低处。”

## §1146 句 64-1146-91-95
- **问题 1**：异释未处理。nissaya 对 `antaravasena` 给出异释 `ဝါ= အခေါင်း အပေါက်၏ အစွမ်းဖြင့်`（按孔洞），按 style.md 第四节应主译加脚注备列。
- **问题 2**：漏译与文言倾向。`aṭṭhikānaṃyeva` 的 `yeva`（只是骨与骨之间）未译出；“诸骨”偏文言。
- **建议**：“应当从**间隙**方面，按骨与骨之间的空隙加以确定。”另加脚注：“或解作：按骨中的孔洞。”

## §1146 句 64-1146-96-105
- **问题**：文言虚词，必改。“以智”中的“以”作文言介词，属 style.md 禁例表所列。另有句首“而”的问题，见跨段一致性。
- **建议**：“再者，要在所有地方都用智慧逐一审察，确定‘在这个地方是这块骨’，这样从**周遍**方面加以确定。”
