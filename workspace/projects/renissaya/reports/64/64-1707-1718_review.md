# Review — 64:1707-1718（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌（本次只注入本文与 nissaya，没有义注。释义只能以 nissaya 及其编者按里引用的大疏说法为参照，结论的可靠性因此降低）
> 父层对照：本层是本文（mūla），没有父层，被解释词逐字核对不适用

## 跨段一致性
- **cuti**：§1716 cuticarimakā 译“死亡最后”，同段 cuticitta 译“死心” → 建议统一用“死”，改为“死最后”，与“死心”成套，也合传统译法（叶均本）
- **vaya / bhaṅga / bheda**：§1708 vaya 译“坏灭”，bheda 译“破灭”；§1709 khaṇabhaṅga、§1717 bhaṅga 也译“坏灭” → vaya 与 bhaṅga 是不同的词，建议 vaya 改为“灭”（生、灭、变异），“坏灭”专留给 bhaṅga
- **samādhi**：§1713-2-28 译“入出息念定”，§1713-29-44 samādhiantarāya 译“障碍禅定” → 建议统一为“定”（“障碍定的寻思”）。“禅定”容易和本 chunk 里的 jhāna“禅那”混淆
- **vipassanā-magga 并列**：§1709 译“观和道”，§1710 译“观与道” → 小差异，建议统一为“观与道”
- **专名译法**：§1718 Devaputtamahāraṭṭha 意译为“天子大国”，同句其他地名（拘吒山寺、大迦兰吉耶寺、支提罗山寺）都是音译加“寺”，体例不一 → 建议按本项目专名体例统一（音译，或音译后首次夹注）
- **首次夹注**：§1716 三种 carimaka 夹注了巴利原词，同 chunk 首次出现的 khayavirāga / accantavirāga（§1709）、pariccāga- / pakkhandana-paṭinissagga（§1710）却没有夹注 → 按 style.md“法相术语首次出现夹注巴利原词”补齐，或统一都不夹注

## §1708 句 64-1708-11-26
- **问题**：准确性（轻）— nibbattānaṃ 指的是五蕴（nissaya：`နိဗ္ဗတ္တာနံ= ဖြစ်ကုန်သောခန္ဓာတို့၏`），译文作“已经生起的法”，把所指泛化了；tesaṃyeva 的强调（“正是这些”）也没有译出
- **建议**：“……是指正是这些五蕴的生起、灭和变异……意思是，已经生起的诸蕴不以原样存续，而以刹那坏灭的方式破灭。”

## §1711 句 64-1711-2-22
- **问题**：风格（必改）— “与之相反的涅槃”中的“之”是文言虚词
- **建议**：改为“与它相反的涅槃”或“与有为法相反的涅槃”
- **问题**：术语（存疑）— khandhābhisaṅkhāra 译“诸蕴与诸业行”。nissaya 编者按把它解为蕴魔与行作魔（abhisaṅkhāra），“业行”是否过窄可再定。暂不改，建议定案后登记进 terms.md

## §1711 句 64-1711-41-48
- **问题**：句法／清晰度 — “随着前面一个接一个的智一再地观察”读起来像是“观察前面的智”。nissaya 编者按据大疏把 anu anu 解为“在前前诸智之后相继（观察）”，并举道智在种姓智之后见涅槃为例
- **建议**：“这两者都因为是在前面各个智之后相继观察，所以称为‘**随观**’。”

## §1712 句 64-1712-21-30
- **问题**：误译 — “依十六事来说”变成了“就某种说法而言”，原意是“这样依十六事修习的入出息念”有大果大利益（nissaya 补出 `ဘာဝိတော= ပွါးစေအပ်ဘိမူကား` 如果修习了）。另据 nissaya，ca 是并列，承接下段“也依寂静性等”，pana 标示要讲果报
- **建议**：“而这样依十六事修习时，这入出息念有大果、大利益。”

## §1713 句 64-1713-29-44
- **问题**：句法（轻）— “能截断心随着障碍禅定的寻思四处奔驰”中，“截断”的宾语边界不清，可能被读成截断“心”
- **建议**：“能截断心因障碍定的寻思而四处奔驰的情形，使心只朝向入出息这个所缘。”（“禅定”改“定”的理由见跨段一致性）

## §1716 句 64-1716-2-14
- **问题**：可读性 — “有最后”容易被读成“存在一个最后”
- **建议**：可以保留传统的“有最后”，但首次出现时建议补成“有（bhava）最后”或加注说明“有”指三有；同时按跨段一致性把“死亡最后”改为“死最后”

## §1717 句 64-1717-2-21 / 64-1717-22-28 / 64-1717-29-36
- **问题**：风格（必改）— “注意其生起时／注意其住立时／注意其坏灭时”中的“其”是文言虚词
- **建议**：改为“注意它们的生起时”“注意它们的住立时”“注意它们的坏灭时”

## §1718 句 64-1718-2-16
- **问题**：句法（轻）— bhāvetvā 是先后关系（修习后证得），译文作“因为修习……而证得”，把它变成了因果。句首的 hi 才是承接上文的说明语气，没有体现出来
- **建议**：“修习入出息念以外的其他业处而证得阿罗汉果的比丘，对自己的寿量，可能知道界限，也可能不知道。”（ito 补出所指，避免“这个以外”指代不清）

## 附记（不必改，供参考）
- §1708-42-59 的 nissaya 把 assasanto 释为出息（`ထွက်သက်`），编者按指出与前文不合；§1711-49-68 的 nissaya 则释为入息（`ဝင်သက်`）。译文全程用“吸气／呼气”，前后一致，不受影响。出入息孰先孰后的定义请与本书前文核对
- §1716-41-56 的“第十六个心”：nissaya 引大疏，指出也可以把死心算作界限，读成十七心刹那。译文按字面译是对的，不必改
