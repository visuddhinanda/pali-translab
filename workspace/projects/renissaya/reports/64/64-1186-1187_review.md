# Review — 64:1186-1187（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌（未注入。本层是本文，没有父层，所以不做被解释词比对。释义核对只依据 nissaya 夹注里转引的 ṭīkā）

## 跨段一致性
- itipi：§1186 和 §1187 都译作“因这样的缘故……也是”，两段一致。§1187 句 19-26 用 kāraṇa 解释它，却译成“原因”，和前面的“缘故”接不上，见下文该句。
- evaṃ / iti … anussarati：§1186 译“这样随念”，§1187 译“如此随念”。是同一个动作的引导语，建议统一为“这样随念”。

## §1186 句 64-1186-2-52
- **问题**：准确性 — `paṭisallīnena` 译作“静默禅修”。“静默”和“禅修”在原文里都没有。nissaya 是这样解的：ပဋိသလ္လီနေန= အပ၌ အထူးထူးသော သဘောရှိသော အာရုံမှဖဲခွါစေ၍ ကမ္မဋ္ဌာန်းဟူသော တခုသောအာရုံ၌သာ ကောင်းစွာငြိတွယ်……စိတ်ရှိသည်ဖြစ်၍，意思是心离开外面的种种所缘，只专注在业处这一个所缘上。这个词讲的是“心的独处”，和 `rahogatena`（nissaya 注：တေန ကာယဝိဝေကံ ဒဿေတိ，表示身远离）分别指身和心两方面。
- **建议**：改为“去到僻静处，内心从外缘收摄回来”，或“独处静处，心专注收摄”。要让“身远离”和“心远离”两层意思都看得出来。

- **问题**：准确性（次要）— 开头的 `Iti` 译作“这样”，读者会以为它指下文。nissaya 注作 ဣတိ ဝုတ္တနယေန= ဖြင့်，意思是“按前面所说的方式”，指的是上文列举的十随念。
- **建议**：改为“如上所说，在这十种随念当中……”。

- **问题**：句法（次要）— “应当是已具备不坏净信的人”这一句，把定语 `aveccappasādasamannāgatena` 改成了判断句。根据 nissaya 所引 ṭīkā（တာဒိသဿ ဗုဒ္ဓါနုဿတိဘာဝနာ ဣဇ္ဇျတိ၊ နေတရဿ，只有这样的人修佛随念才能成功，别人不能），这个“条件”的意思可以成立，但原文的主干是“由……的瑜伽者随念功德”，这样一改，主干被切断了。
- **建议**：把它恢复为修饰“瑜伽者”的定语，比如：“想要先修习佛随念、并且具备不坏净信（aveccappasāda）的瑜伽者，应当……这样随念佛陀世尊的功德”。

## §1187 句 64-1187-19-26
- **问题**：格式／工作标记 — 句首的“（itipi）”是译者加的标签，原文没有。用括号里的巴利词开头，读起来像草稿里的标注。
- **建议**：删掉括号，改用正文交代所指，比如：“这是说：‘因为这个原因，也因为那个原因。’”

- **问题**：漏译 — `iminā ca iminā ca` 里的两个 `ca` 被省掉了。nissaya 是 ဣမိနာ စ ကာရဏေန= ဤအကြောင်းကြောင့်လည်း 重复两次，意思是“因这个原因也……因这个原因也”。这两个 `ca` 正是用来解释 itipi 里的 `pi`（“也”），漏掉以后，这句解释就和前面译文里的“也是”对不上了。
- **建议**：译为“因为这个原因，也因为这个原因”，或者“因为这样的缘故，也因为那样的缘故”。如果选后一种，可以和前面 itipi 的译法“因这样的缘故”在用词上呼应（缘故／原因二选一，统一使用）。
