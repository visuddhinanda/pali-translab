# Review — 64:337-341（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§337、§341 2-15 无独立单元；§341 的 nissaya 挂在 16-19，覆盖 2-19 整组问句）／义注 ❌（本次未注入。本书为《清净道论》，其注释是大复注 Paramatthamañjūsā，未提供，所以**释义层面的核对没有做**，以下只依 pali 与 nissaya）
> 本层是本文（mūla），没有父层，被解释词逐字核对不适用。

## 跨段一致性
- **pañcaka**：§337 译“第二组五种戒”，§338 译“第二组五法” → 建议统一为“第二组五种戒”，因为标题 Dutiyasīlapañcakaṃ 明确是戒的五法组，§340 67-70 的结论“戒有五种”也与此呼应。
- **veramaṇī**：§339（两处）译“离”，§340 38-60 译“远离” → 建议统一为“离”，与“离是戒”的固定句式保持一致。
- **samādhāna / samādāna**：§340 14-29 译“受持”，§340 30-37 的 upadhāraṇasamādhāna 译“安立” → 两句指的是同一个概念（后句用 pubbe vutta 回指前句），必须统一，详见 §340 14-29。
- **sīlana / sīlaṭṭha**：§340 30-37 与 61-66 都译“持守”，本 chunk 内一致；但这里回指前文（Vism I.19）对 sīlana 的定义，需核对前面章节的译法是否也是“持守”。
- **lakkhaṇa / rasa / paccupaṭṭhāna / padaṭṭhāna**：§341 再次夹注巴利原词。这组术语在前文（四种问句首次提出处、I.20 以下答相味处）已经出现过，按 style.md 应只在首次出现时夹注，需核对前文。

## §338 句 64-338-2-8
- **问题**：准确性 — pāṇātipātādīnaṃ pahānādivasena 里有两个 ādi（杀生**等**的舍断**等**）。现译“舍断杀生等等的方式”只保留了一个“等”，读者分不清“等等”挂在“杀生”还是“舍断”上，而且把后面的离、思、防护、不违犯都丢了。“第二组五法”与 §337 不一致（见上）。
- **建议**：改为“在第二组五种戒中，应当依照对杀生等的舍断等来理解它的意思。”

## §339 句 64-339-22-173
- **问题**：风格（建议项）— 整段约四十处“以 X 舍断 Y”用“以”表示工具，属于书面偏文的用法。style.md 把“以”（作文言虚词时）列入禁例，这里处在边界上。
- **建议**：可以改为“用 X 舍断 Y”或“通过 X 舍断 Y”。如果保留“以”，要全段统一，不要混用。
- **问题**：术语 — abhijjhā 译“贪婪”，偏日常用语，与同组的“嗔恚、邪见”语域不齐；abyāpāda 译“无嗔”，与 byāpāda 的“嗔恚”不成对。
- **建议**：abhijjhā 改“贪欲”（十不善的传统译法）；abyāpāda 改“无恚”，或者把 byāpāda 统一成“嗔”。定案后补进 terms.md。
- **问题**：存疑（低）— āyūhana 译“造作”，容易和 saṅkhāra 的常见译法相混；nissaya 作 ပြုပြင်ရုံးစုခြင်း（造作积聚）。ālayābhinivesa 译“贪恋的执著”，nissaya 作“把诸行误当作依靠处的作意”，“贪恋”偏离了“依托、依恋”的意思。
- **建议**：āyūhana 考虑改“积集”；ālaya 考虑改“依恋”。分歧写进术语报告。
- 其余条目逐项对过 pali，九种不善、七种盖障、四禅、四无色、十八大观、四道，没有漏译。aṇusahagatānaṃ 按 nissaya 的 tabbhāva 注译作“微细”，正确。

## §339 句 64-339-174-234
- **问题**：增译 — “最终导向纯粹的厌离”里的“最终”是原文没有的；ekanta 修饰 nibbidā，意思是“完全的、绝对的”（nissaya：စင်စစ်，确实地），“纯粹”不够贴切。
- **建议**：改为“导向完全的厌离、离贪、灭、寂止、证知、觉悟、涅槃。”

## §340 句 64-340-2-13
- **问题**：语句 — “除了上面说过的那几类杀生等等仅仅不生起以外”，修饰语堆在一起，读起来费力。
- **建议**：改为“除了前面所说的各类杀生等只是不再生起以外，并没有哪一种法叫做‘舍断’。”（引号写入时用全角‘’）

## §340 句 64-340-14-29
- **问题**：术语 / 句法 — (1) upadhāraṇa 译“执持”，带有“抓取”的意思。nissaya 作“善能承载／所依处”，原文 patiṭṭhānaṭṭhena 也是“作为立足处”，意思是**支持、承托**。(2) samādānaṃ 译“受持”，但 nissaya 读作 samādhānaṃ（ကောင်းစွာ အညီအညွတ်ထားခြင်း，妥善安置、协调），下一句复合词也是 upadhāraṇa**samādhāna**，回指的是 Vism I.19 对 sīlana 的定义（协调、不散乱）。所以“受持”是误译，并且与下句的“安立”矛盾。(3) yasmā…tasmā 跨两句，现译开头没有译出“因为”，下一句又起一个“所以”，因果链断开了。
- **建议**：改为“但是，因为每一种舍断是相应善法的立足处，从这个意义上说是支持；又因为它使心不动摇，所以是协调；”。后句相应改作“所以，依照前面说过的、称为支持与协调的持守的意义，才说它是戒。”

## §340 句 64-340-30-37
- **问题**：风格（必改）— “持守之义”中的“之”是文言虚词。术语“安立”需要与上句统一（见上）。
- **建议**：改为“……称为支持与协调的持守的意义……”

## §340 句 64-340-38-60
- **问题**：准确性 / 语句 — (1) tato tato、tassa tassa 指前面所说的杀生等各项，译成“各种对象”是增译，意思也偏了。(2) “……这几方面来说的——都是针对……而说的”出现两次“说的”，原文只有一个 vuttā，vasena 与 sandhāya 是同一个陈述。(3) veramaṇī 译“远离”，与 §339 的“离”不一致。
- **建议**：改为“其余四种法，是就心中确实有这样的运作而说的：从杀生等各项离开、对各项的防护、与这两者相应的思，以及不违犯各项的人的不违犯。”

## §341 句 64-341-2-6 至 64-341-16-19
- **问题**：句法误读（必改）— Ettāvatā ca 统摄整组问句，问句以 …sīlanti 的 ti 结束引语，再接 imesaṃ pañhānaṃ vissajjanaṃ niṭṭhitaṃ。nissaya 也把 kiṃ sīlaṃ。ပ။ sīlanti 当作一个整体（“名为‘什么是戒……’的那些”）。全句的意思是：“到这里，‘什么是戒？……这戒有几种？’这些问题的解答已经完成。”现译把五个问句当成新提出的问题，“到这里为止，什么是戒？”读起来像是重新发问，意思错了。另外，16-19 的“以及”放在问句里很别扭；ca 只是连接词，不必译出。
- **建议**：用引号把五问括成引语，跨句开合（全角）：
  - 2-6：到这里，“什么是戒？
  - 7-9：以什么意义说是戒？
  - 10-12：它的相、味、现起、足处是什么？
  - 13-15：戒有什么利益？
  - 16-19：这戒有几种？”
  - 20-24：对这些问题的解答，到此已经完成。

## §341 句 64-341-10-12
- **问题**：风格 / 术语 — “即作用”“即近因”中的“即”是文言虚词。这组术语前文已经出现过，按规定不应再夹注（待核前文）。
- **建议**：前文已经夹注的，就删去括注；如果确实需要保留解释，改用“指作用”“指近因”。
