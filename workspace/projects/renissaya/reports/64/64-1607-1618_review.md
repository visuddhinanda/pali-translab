# Review — 64:1607-1618（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌（未注入，本次释义核对仅依 nissaya 与原文自身的解释，取义类判断可信度降低）
> 父层对照：无。本层是本文，被解释词（araññagato、pallaṅkaṃ、parimukhaṃ satiṃ 等）引自经文，经文译本未注入，**无法做跨层逐字核查**，只做了本 chunk 内部的一致性核查。

## 跨段一致性

- **araññagato / rukkhamūlagato / suññāgāragato**：§1608、§1614 引句和 §1615 被解释词都译成“到森林去 / 到树下去 / 到空屋去”，但 §1615 的释义一律译成“到了……”（gato 是过去分词，指已到达的人）。被解释词读起来像祈使句，和释义对不上。→ 建议被解释词统一改为“**去到森林**／**去到树下**／**去到空屋**”（或“到了森林的人”等），§1608、§1614、§1615 三处引句同步修改，§1615-61-70 的“也可以说是‘到空屋去’”也要一起改。
- **parimukhaṃ**：§1616-82-89 的被解释词译为“把念安立在**面前**”，§1616-104-127 同一个词组却译为“**遍面念**”，§1616-90/96 又把 pari 拆成“遍”、mukha 拆成“面”。同一个巴利词组出现两种译法，第一种解释（面向业处）和第二种解释（把握＋出离）之间的对应也就断了。→ 建议保留“面前”作为正式译法；§1616-104 的引句改为“因此称为 parimukhaṃ satiṃ（遍面念）”，表明这里是在做词源拆解，不是另立一个译名。
- **出处格式**：§1613、§1615 用中文书名加编号（《波罗夷义注》2.165、《分别论》529）；§1616-104 写成“**《无碍解道》**（《无碍解道》1.164）”，书名重复；§1618-46 保留了巴利缩写“（paṭi. ma. 1.165）”。→ 统一为“（《无碍解道》1.164）”“（《无碍解道》1.165）”的格式。
- upaṭṭhapeti 译“安立”（§1616-82、§1617-2），upaṭṭhāna／upaṭṭhitā 译“现起”（§1616-100、§1618-10/36）。§1616-100 正是在解释前面的 upaṭṭhapetvā，两个译词不同源，读者看不出这层呼应。→ 可选：§1616-100 改为“念是现起（安立）的意思”，或者全段统一用一个字根。

## §1608 句 64-1608-2-20
- **问题**：词义偏差（nissaya）— `ဂါမန္တံ= ရွာနားကျောင်းကို`，指村落附近的寺院、住处，不是“村落边缘”这个地带。
- **建议**：改为“如果不离开……喧闹的村边住处”或“村落附近的住处”。

## §1608 句 64-1608-21-39
- **问题**：词级补出（nissaya）— `အာနာပါနစတုတ္ထဇ္ဈာနံ= အာနာပါနလျှင် အာရုံရှိသော စတုတ္ထဈာန်`，意思是以入出息为所缘的第四禅；“入出息第四禅”字面上难以理解。`သင်္ခါရေ= တေဘူမကသင်္ခါရ`，sammasitvā 指审察、触知，“思惟”偏弱。
- **建议**：改为“生起以入出息为所缘的第四禅，再以它为基础审察诸行”。可以不补“三地”，但“思惟”宜改为“审察／观察”。

## §1609 句 64-1609-2-66
- **问题**：用词 — vatthuvijjācariya 是精通宅地相法的师傅，“大师”拔高了身份，“宅地学”也不通行。
- **建议**：改为“宅地相师”或“精通宅地之学的师傅”，全句两处同改。

## §1610 句 64-1610-8-36
- **问题**：用词一致 — tiṇagahana／vanagahana／pabbatagahana 三个词都以 gahana（茂密难入之处）收尾。前两个译成“茂密的草丛”“密林”，第三个译成“险峻的山”，丢了 gahana 的意思。
- **建议**：改为“山间密林”或“茂密的山林”，和前两项保持平行。

## §1614 句 64-1614-2-14
- **问题**：误译倾向 — parakkama-java-yogga-bhūmi 的 yogga 是“训练、演练”。nissaya `ဘာဝနာကိုအားထုတ်သော အစွမ်းအားသင့်သည်ကို ပြုရာမြေ` 的意思是“修习精进、发挥力量的场地”。“施展精进和速度”把 java 直译成“速度”，读来不通。
- **建议**：改为“也就是适合他锻炼精进与迅猛之力的场地”（这里接着上文的豹喻，java 指扑击的迅猛）。

## §1615 句 64-1615-55-60
- **问题**：增译 — nissaya 把 `သုညံ-ဝိဝိတ္တောကာသံ` 当作同位语，合译为“僻静处”。“没有人”是额外加上的解释。
- **建议**：改为“到了空寂、僻静的地方”。

## §1616 句 64-1616-2-15
- **问题**：句法 — 原文是 `upadisanto … nisīdatīti āha`，意思是“在指示……时说了‘坐下’”，没有因果关系。“所以说”多加了一个因果连接。
- **建议**：改为“……又为他指示既不偏于退缩、也不偏于掉举的寂静威仪，说了“**坐下**”。”

## §1616 句 64-1616-104-127
- **问题**：① 出处重复（见跨段一致性）；② 句子结构 — 从 pari、mukha、sati 的释义到 `tena vuccati parimukhaṃ satin` 都属于《无碍解道》的说法，`evaṃ` 收束的是这一整段。现在的译文用破折号切开，读者会以为“所以说遍面念”是作者自己的话。
- **建议**：改为“因此称为‘parimukhaṃ satiṃ（遍面念）’——也可以照《无碍解道》这样的说法理解这里的意思（《无碍解道》1.164）。”

## §1616 句 64-1616-128-134
- **问题**：可读性 — “让念成为已把握出离的念”读不通。nissaya `ပရိဂ္ဂဟိတနိယျာနံ သတိံ` 的意思是：念已被完全把握，并且能从对立面（忘失）中出离。
- **建议**：改为“简单地说，就是使念成为已被把握、能出离（忘失）的念”。

## §1618 句 64-1618-46-65
- **问题**：出处格式 — 保留了巴利缩写，没有转成中文书名（见跨段一致性）。
- **建议**：改为“（《无碍解道》1.165）”。
