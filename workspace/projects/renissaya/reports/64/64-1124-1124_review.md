# Review — 64:1124（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌（未注入本段义注，释义层面的取义核对未做，只按 nissaya 与原文审）
> 本层为本文（mūla），无父层，不做被解释词对齐检查。

## 跨段一致性
- **uddhumātaka**：句 64-1124-10-15 译“肿胀的尸体”，句 64-1124-120-139 与 64-1124-140-160 译“肿胀相” → 建议统一为“肿胀尸”（或“肿胀的尸体”）。依据：原文是 uddhumātaka（肿胀之物 / 肿胀尸），不是 nimitta（相），“相”是添加的。巴利夹注应放在首次出现处，即句 64-1124-10-15，而不是句 64-1124-120-139。
- **vivara**：标题译“孔隙”，列举项译“空隙”“空处” → 建议统一为“空隙”，标题改为“**就空隙而言**”。
- **ninna / thala**：标题译“凹处 / 凸处”，“或者”一句译“低处 / 高处”。后者说的是行者与尸体所处的地势，用不同词有道理，但两句之间的词形呼应断了 → 建议标题改为“**就低凹处而言**”“**就高凸处而言**”，“或者”句保留“低处 / 高处”。
- **-to 标题句式**：“就…而言”五处统一，没问题。但“就周遍而言”不通顺，见句 64-1124-113-119。

## §1124 句 64-1124-2-9
- **问题**：准确性（轻微）— asītisatasandhito 是从格，和 sandhito 同构，意思是“从一百八十个关节（来确定）”。译成“是指一百八十个关节”，把方式状语变成了名词。
- **建议**：“这里，**就关节而言**，是指就一百八十个关节而言。”

## §1124 句 64-1124-16-39
- **问题 1**：术语所指偏窄 — nissaya 注明手部三节是“肩、肘、腕”，脚部三节是“胯、膝、踝”。hattha / pāda 在这里指整条上肢和下肢，译成“手 / 脚”会让读者以为是手指、脚趾的关节。
- **建议**：改为“右臂有三个关节……右腿有三个关节……”。
- **问题 2**：风格 — “按照十四个大关节来就关节而言加以确定”是翻译腔，把标题词硬套进了句子。
- **建议**：“——就这样按十四个大关节，从关节方面加以确定。”

## §1124 句 64-1124-40-51
- **问题**：误译（增译）— hattantaraṃ 在 nissaya 里是“两手（臂）之间的空隙”，译文“手臂与身体之间的空隙”多出了“与身体”，和 nissaya 不符。
- **建议**：“两臂之间的空隙”。另外，“腹部内的空处”可按 nissaya（脐处的腹中 / 腹内）改为“腹腔”或“腹部中间”。标题按上文统一为“空隙”。

## §1124 句 64-1124-113-119
- **问题**：风格 — “是指应当对整个身体周遍地加以确定”读起来生硬，“是指应当”接得别扭，“周遍”偏书面。
- **建议**：标题改为“**就四周而言**”（nissaya：ထက်ဝန်းကျင် = 四周、周围），正文改为“就是应当从四周把整个身体都确定下来”。

## §1124 句 64-1124-120-139
- **问题 1**：术语 — ñāṇa 译“智慧”，容易和 paññā 混淆。ñāṇaṃ cāretvā 是“让智在全身移动、遍及”（nissaya：လှည့်လည်စေ၍ = 使之周转）。
- **建议**：“让智遍及整个身体”。
- **问题 2**：术语一致性 — “肿胀相（uddhumātaka）”见上文跨段一致性一节。
- **建议**：“……就应当在那里把心安住于‘肿胀尸、肿胀尸’。”

## §1124 句 64-1124-140-160
- **问题**：误译 — udarapariyosānaṃ 在 nissaya 里是“以腹部为终端的上半身”（ဝမ်းအဆုံးရှိသော အထက်ကိုယ်），也就是从上到腹部为止的那一段身体，不是“腹部的末端”。atirekauddhumātakaṃ 在 nissaya 里是“比其他部位更加肿胀、可厌”。hoti 是陈述，不是推测，译文里的“会”不该加。
- **建议**：“如果这样仍然没有哪一处清楚地显现出来，那么（身体）到腹部为止的部分比别处肿胀得更厉害，就应当在那里把心安住于‘肿胀尸、肿胀尸’。”
