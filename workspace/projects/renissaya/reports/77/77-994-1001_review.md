# Review — 77:994-1001（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 基本缺失／义注 ❌ 缺
> - **义注缺失**：本次未注入义注，释义核对（取义、术语所指）无法做。涉及 sadhamma / paradhamma 的取义只能列为存疑，需补义注后复核。
> - **nissaya 基本缺失**：只有 §998 句 77-998-2-8 带了一条 nissaya。它的内容是 yadā have 等三偈的释义，还提到 Aṭṭhasālinī 的缅文复注，和本句 “Atthi arahato kaṅkhāti” 不对应，疑为错挂。所以本次没有做 nissaya 词级核对。
> - 本层是本文（mūla），没有父层，不做被解释词对齐检查。

## 跨段一致性
- **pahīno / bhāvito / vīta-** 的完成态标记不统一。§995–997 同一组排比里，“已经断除了”、“已修习了”、“已离贪”混用，“已经”和“已”交替出现。建议统一为“已经…”，例如“已经修习了…道”、“已经离贪、离嗔、离痴”。依据：同一段排比句应保持同一语体。
- **abhabbo / bhabbo**：§1000 前半句译“不可能”，后半句译“才能够”，这对反义词没有对称译出；§1001 的 abhabba 又译“不可能”。建议统一为“不能够 / 能够”。
- **jānato … passato** 的“…的人”时有时无：§998 和 §999 的 77-998-32-44、77-999-28-38 两句省掉了“的人”，而前后两句都补了“的人”。见下文各句条目。
- **sadhammakusala / paradhammakusala**：§994–997 一律译作“精通自己的法 / 精通他人的法”，用法本身一致，但取义存疑，见 §994 条目。

## §994 句 77-994-2-6（同样适用于 §994–997 所有含 sadhamma- / paradhammakusala 的句子）
- **问题**：存疑 / 术语所指。“自己的法”“他人的法”字面可通，但没有义注就无法确认所指：是“自宗（佛陀教法）/ 他宗（外道教说）”，还是“自己所证之法 / 他人的名字、族姓等世俗事务”？这两种解读会直接影响论辩的意思。另外，“精通他人的法的阿罗汉”连用两个“的”，读起来累赘。
- **建议**：补取义注后确定所指，再统一改为明确的说法，例如“精通自宗教法的 / 精通他宗教说的”，或者按义注改作别的说法。定案后登记进 `terms.md`。在此之前，这些句子的 confidence 应压低。

## §996 句 77-996-83-97
- **问题**：标点 / 可读性。Pali 在这一句里先给出回答（Na hevaṃ vattabbe），接着用 pe 省略，然后开始一个新的问题。译文“不应该这样说……乃至……精通他人的法的阿罗汉已经断除了贪，他就没有疑惑吗？”把回答和新问题连成一句，读者看不出问答已经换了一轮。（§997 结构相同的地方处理得一样，也有这个问题。）
- **建议**：在“乃至……”之后加句号断开：“不应该这样说……乃至……。精通他人的法的阿罗汉已经断除了贪，他就没有疑惑吗？”

## §998 句 77-998-32-44
- **问题**：句法。jānato / passato 是“知者、见者”（属格 / 与格分词），句意是“对于知道什么、见到什么的人，诸漏才会灭尽”。译文“知道什么、见到什么，诸漏才会灭尽呢？”丢了“的人”，和前后两句的“知道的人、见到的人”“这样知道、这样见到的人”对不上。
- **建议**：改为“比丘们，知道什么、见到什么的人，诸漏才会灭尽呢？”

## §999 句 77-999-28-38
- **问题**：同 77-998-32-44。
- **建议**：同上。

## §1000 句 77-1000-12-24
- **问题**：句法误读风险。sabbaṃ 是宾格，作 anabhijānaṃ 等分词的宾语，意思是“不证知……一切的人”。译文“对一切不证知、不遍知、不离染、不舍断的人”可以被读成“对于所有不证知……的人”，把“一切”误读成修饰“人”。
- **建议**：改为“比丘们，不证知、不遍知、不离染、不舍断一切的人，不能够灭尽苦；”

## §1000 句 77-1000-25-39
- **问题**：同上句，sabbaṃ 的宾语关系不清。bhabbo 译作“才能够”，和上句的“不可能”不成对。
- **建议**：改为“比丘们，证知、遍知、离染、舍断一切的人，能够灭尽苦。”如果想保留对比语气，可以用“就能够”。

## §1001 句 77-1001-12-26
- **问题**：
  1. **术语冲突**：“犯下六种重罪”中的“犯”是术语表里 āpatti 的固定译名（律藏术语）。用来译 abhiṭhāna（六种重大恶行）会让人误以为说的是戒律上的“犯”。
  2. **取义**：sahā 是“与……同时”，强调见具足的那一刻三种法就已经舍断，其中包括被 pe 省略的 vicikicchā（疑），这正是本段引这部经反驳“阿罗汉有疑”的要点。“随着”偏向“逐渐”的意思，不够准确。
  3. dassanasampadā 是一个复合词，夹注只注了 dassana，不完整。
- **建议**：改为“就在他具足见（dassanasampadā）的同时……乃至……他不可能做出六种重罪。”“犯下”改成“做出 / 造作”。如果要把“见具足”指见道（预流道）这一点写清楚，需要有义注依据，可以放进脚注，不要写进正文。
