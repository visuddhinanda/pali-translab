# Review — 77:2332-2341（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 部分（仅 §2333、§2334 前两句、§2339、§2340 有，其余句无）／义注 ❌ 未提供。本层是本文，没有父层，所以不做被解释词对照。释义核对缺义注标准，本报告只依 pali 原文、nissaya 和平行句式审查。

## 跨段一致性
- 无。maggasamaṅgī「具足道者」、samannāgata「具备」、Na hevaṃ vattabbe「不应这样说」、pe「（略）」、lokiya/lokuttara「世间/出世间」在 §2333–2339 全部一致。
- 说明：「世间戒」不带「的」，「世间的触 / 世间的正语」带「的」。「世间戒、出世间戒」是固定术语，这个差别可以接受，不用改。

## §2334 句 77-2334-9-31
- **问题**：OCR / 原文疑问，同时涉及准确性。这一句的法数列表是 phassa / vedanā / **paññā** / cetanā / citta / saddhā / vīriya / sati / samādhi / **paññā**，paññā 出现了两次。对照 §2333 的平行列表（phassa、vedanā、**saññā**、cetanā…paññā），第三项应作 **saññāya**（想），lokiyāya paññāya 很可能是 lokiyāya saññāya 的讹误。译文照抄讹文，把第三项也译成了「世间的慧」，结果同一句里「世间的慧」出现两次，读者会以为是译者笔误。
- **建议**：第三项依平行句改译为「世间的想」，并压低本句 confidence。pali 原文不改，把这条讹误记进 `knowledge/known-issues.md` 的「OCR / 原文问题」一节，待核其他版本（如缅甸第六次结集版 CST）确认。

## §2333 句 77-2333-2-11
- **问题**：术语（可选，不是必改）。「具足道者」可以有两种读法：「具足 + 道 + 者」（具足了道的人），或「具足道 + 者」（「具足道」被读成名词「圆满的道」）。nissaya：`မဂ္ဂသမင်္ဂီ= မဂ်နှင့်ပြည့်စုံခြင်းရှိသောပုဂ္ဂိုလ်သည်` 意为「具有道、与道相具足的人」，取的是前一种读法，现译文义理不错。
- **建议**：维持现译。如果要彻底消除歧义，可以考虑「道具足者」或「与道相具者」。要改的话需全书统一，并登入 `terms.md`。

## §2339 句 77-2339-28-33
- **问题**：无误。附记以备 harmonize 参考：dussīlo 的 nissaya 是 `သီလမရှိသော`（无戒的），译作「破戒的人」符合传统译法；nissaya 补出的 `(ပုဂ္ဂလော)` 在译文里已经补成「人」，处理正确。
- **建议**：不改。
