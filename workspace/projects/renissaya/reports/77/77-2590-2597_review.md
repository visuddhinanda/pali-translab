# Review — 77:2590-2597（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠ 部分（2591、2592 有逐词 nissaya；2593–2595 的经证引文没有逐词释义，nissaya 只注明“已在第七品《受用所成福论》、第三品《解脱中论》释过”）／义注 ❌ 缺（本次未注入，取义无法按义注核对）

## 跨段一致性
- jahati：各段一律译“舍断”，一致。
- nivuto / nīvaraṇa：标题、§2591、§2594、§2595、§2596 一律译“被盖覆的人”和“盖”，一致。首次出现已夹注 nīvaraṇa。
- Na hevaṃ vattabbe → “不应这样说”，Na vattabbaṃ → “不应该说”。两者是不同句式，区分得当，各自前后一致。
- Kusalākusalā … sammukhībhāvaṃ āgacchanti：§2592、§2593 两处全句逐字相同，§2593 的略引也一致。
- Nanu vuttaṃ bhagavatā / Attheva suttanto / Tena hi na vattabbaṃ：各段译法统一。
- **跨章待核**：nissaya 指出，§2593 的 cattārimāni… 经证已在第七品《受用所成福论》出现过，§2594 的 so evaṃ samāhite… 经证已在第三品《解脱中论》出现过。本章这两段经证的译文应与那两章逐字一致，需要在 harmonize 时比对。本 chunk 内无法核查。

## §2592 句 77-2592-10-19
- **问题**：句法误读。dvinnaṃ phassānaṃ … dvinnaṃ cittānaṃ 是属格，修饰句末的 samodhānaṃ（会合）。“pe” 省略的是“两个受、两个想、两个思”等同型属格。现译“会有两个触……”把属格读成了存在句，前半截变成“有两个触”，与后半截“两个心同时会合”结构断开。
- **建议**：改为“两个触……两个心会同时会合吗？”，或“会有两个触……两个心的会合吗？”。

## §2592 句 77-2592-20-31
- **问题**：语气（次要）。nissaya 把 akusalo、kusalo 释为 `အကုသိုလ် မဟုတ်လော`（不是不善吗）、`ကုသိုလ်မဟုတ်လော`（不是善吗），是要求对方确认的反问。现译“贪是不善的，道是善的吗？”是一般疑问句，语气偏弱。
- **建议**：可改为“贪不是不善的、道不是善的吗？”。若保留现译，意思不算错，可以不改。

## §2593 句 77-2593-30-51
- **问题**：译文在省略号处悬空。“这是第一种相距极其遥远的……”以“的”收尾后直接接省略号，读者会以为句子被截断，而不是 pe 略去了后面三种。idaṃ paṭhamaṃ suvidūravidūraṃ 本身是完整的一句。
- **建议**：补足中心词，改为“这是第一种相距极其遥远的事物……”，与前句“四种相距极其遥远的事物”呼应。

## §2595 句 77-2595-23-44
- **问题**：漏译。kāmāsavāpi 与 avijjāsavāpi 各带一个 api，是并列的“也……也……”。现译只在后一项译了“也”，前一项的 api 没有译出。
- **建议**：改为“心也从欲漏解脱……心也从无明漏解脱”，两处对称。也可以前一项不加“也”，但要统一处理，并在 harmonize 时与第三品的同一经证对齐。

## §2591 句 77-2591-2-10
- **问题**：存疑（不改正文）。nissaya 把 jahati 释为 `စွန့်နိုင်သလော`（能舍弃吗），带有“能够”的意味。现译“舍断盖吗”没有译出这一层。本论争点是“正被盖覆着的人能否同时舍断盖”，“能”字有助于读者理解论点。没有义注，无法确定取哪个读法。
- **建议**：可考虑改为“被盖覆的人能舍断盖吗？”。若采用，§2594、§2595 的同一句及引文要一起改，以保持一致。这一条应在补上义注后再定。

## §2597 句 77-2597-2-4
- **问题**：存疑。“13. Terasamavaggo”位于本论结束标记之后，按体例可能是第十三品的结束标题，而不是新一品的开头。
- **建议**：确认 VRI 体例。如果是品末标题，可以考虑译为“第十三品（终）”或沿用全书统一做法。这一条不作为必改项。
