# Review — 77:1812-1819（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 跨段一致性
- 无。以下几处已核对，前后一致：
  - `Āmantā`：全部译为“是的”。
  - `Na hevaṃ vattabbe … pe …`：全部译为“不应这样说……乃至……”。
  - `tāṇa`：1813-11-19 与 1813-49-56 都译为“庇护所”。
  - `accuta`（不退没）与 `cavanti`（退没）同源，译法相互照应。
  - `ākāsānañcāyatanūpaga` 修饰“业”时译“能往生”，修饰“众生”时译“往生”，这个区分合理。
  - `āruppā`：“四无色”与“无色论”一致。

## §1813 句 77-1813-49-56
- **问题**：语序／可读性 — `antarikā vā` 是 pe 省略的一串并列项（界限 vā… 间隔 vā）的最后一项。`vā` 表示并列列举。译成“或者有间隔吗？”，读起来像另起的一个选择问句，与前面的“有两个庇护所”脱节。
- **建议**：去掉“或者”，改为“有两个庇护所……乃至……有间隔吗？”。也可以保留“或”，但要贴近列举语气，例如“……乃至……或间隔吗？”。属次要项，可酌情处理。

## §1814 句 77-1814-7-15
- **问题**：风格（翻译腔） — `attabhāvapaṭilābho` 译为“自体的获得”，是名词化直译，现代读者读来生硬。nissaya：`အတ္တဗ္ပဋိလာဘော= အတ္တဘောကို ရခြင်းလော`，意为“获得自体”，动宾结构。
- **建议**：改为“获得自体”。1814-18-27 同句式，要同步改，保持两句一致。
- **附注**：`yoni` 译“生处”、`viññāṇaṭṭhiti` 译“识住”、`sattāvāsa` 译“有情居”，这三个词 `terms.md` 都未登记。译法有依据，建议定案后补登术语表。

## §1814 句 77-1814-18-27
- **问题**：同上，`attabhāvapaṭilābho`“自体的获得”。
- **建议**：随 1814-7-15 改为“获得自体”。

## §1816 句 77-1816-33-34
- **问题**：原文疑问／数据对齐（记录，不改译文） — 这一句的 nissaya 单元除 `အာမန္တာ` 外，还挂着下一组问句的释义：`အာကာသာနဉ္စာယတနံ … စတုဝေါကာရဘဝေါ= စတုဝေါကာရဘဝ မဟုတ်လော`，意为“空无边处不是四蕴有吗”。这一部分对应的应是 1816-42-50 的后半句。另外，nissaya 用 `မဟုတ်လော`（“不是……吗”）作反问，而巴利原文 `ākāsānañcāyatanaṃ catuvokārabhavoti ?` 没有 `nanu`。
- **建议**：译文“是的”无误，不改。1816-42-50 译为“空无边处是四蕴有吗？”，与巴利原文一致，应保留，不要照 nissaya 改成反问。这处 nissaya 坐标错位，可记入 `known-issues.md`。

## §1817 句 77-1817-29-48
- **问题**：漏译（次要） — `tena vata re vattabbe` 中的 `re` 是论辩中对对方的呼格小品词，语气近于“喂／朋友”，译文未体现。另外，“那么，就确实应该说”中“那么”与“就”语义重复。
- **建议**：可改为“那么，朋友，确实应该说‘四无色是无为’”。`re` 的处理要与本书其他各论的 `Hañci … tena vata re vattabbe` 统一。如果全书惯例是省略，就只删去“就”，改为“那么，确实应该说……”。
