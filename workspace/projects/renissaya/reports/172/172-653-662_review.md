# Review — 172:653-662（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌／父层译文 ❌
> 本层是复注（ṭīkā），父层是义注。本次没有注入义注原文和义注译文，所以**无法逐字核对被解释词**。下文末尾列出本 chunk 全部黑体被解释词，统稿时要逐条对照父层译文。释义方面只能依据 nissaya 及其附注判断。

## 跨段一致性

- **visabhāgapaccaya**：§655 句 9-32 译作“**异类的缘法**”，§655 句 33-46 译作“异类的缘”。前后指的是同一个概念，建议统一为“异类的缘”。“法”字只保留在 samuppannadhamma（所生的法）里。
- **ajjava / ujutā / ujukatā**：§656 句 2-25 把 ajjava 和 ujukatā 都译成“正直”，ujutā 译成“端直”。这样一来，“‘正直’说的其实就是……正直”成了同义反复，复注要说明的对应关系（ajjava = ujutā / ujukatā）就看不出来了。建议 ajjava 用“正直”，ujutā / ujukatā 统一用“端直”，或者另定一组能区分开的译名。maddava“柔和”和 mudutā“柔软”已经区分开，可以保留。
- **sakamana / attamana**：§657 句 14-22 和句 23-34 把 sakamana(tā) 译作“自己的心”，§657 句 35-42 把 attamanatā 译作“悦意”。nissaya 把两者都释作“有自己的心”（မိမိစိတ်ရှိသော），附注也说明这两种说法是对同一概念的不同解法。译名差得太远，读者看不出它们相关。建议用“自意 / 自意性”贯通这几句。如果 attamanatā 保留“悦意”，就要在首次出现处说明它和 sakamanatā 的关系。
- **saṃvara / asaṃvara / saṃvuta**：§661 统一译作“防护 / 未防护”，§662 句 24-55 却混用了“关闭”（城门）和“守护”（门等）。比喻部分用“关闭”可以接受，但比喻的本体（速行、门、有分）应当回到“防护”，这样才能和 §661 对上。
- **paññā 的数目**：§653 句 30-60 把五种慧合译成“这种慧”做五件事，下一句 §653 句 61-92 又说“这五种慧”，前后对不上（详见下文该句）。

## §653 句 172-653-2-16

- **问题**：误读 — `uggahamanasikārajānanapaññā` 的 nissaya 是 `ဥဂ္ဂဟမနသိကာရကို သိသောပညာ`（以学习与作意为宾语的“了知的慧”）。译文“学习、作意并加以了知的慧”把学习、作意读成了慧自己发出的动作，宾语关系丢了。这样也和本段后文的“**对学习的了知**”“**对作意的了知**”不一致。另外，译文添出的“义注的用意是”原文没有（原文只是 `adhippāyena`“以这样的用意”），会把复注的推断说成义注本身的立场。
- **建议**：改为“……其中一部分是作意善巧。按照这个用意，前一句也说到了**了知学习与作意的慧**。”此外，黑体部分要与义注译文逐字核对。

## §653 句 172-653-30-60

- **问题**：句法误读 — nissaya 在每个分词后都补出了 `(ပညာစ= ပညာကိုလည်းကောင်း)`，说明 uggaṇhantī / manasikarontī / suṇantī / dhārentī / jānantī 是五种并列的慧，合称 `uggahapaññādikā`（“学习的慧等”）。译文合成了一个慧做五件事，把五分结构抹掉了，下一句“这五种慧”因此没了着落。
- **建议**：改为“其中，学习界的圣典的慧、对它作意的慧、听闻其意义的慧、从文句和意义两方面忆持它的慧，以及了知界的界限的慧（按自性说‘这叫作眼界’等，按数目说‘只有十八种’），这些被称为**学习的慧**等。”

## §653 句 172-653-61-92

- **问题**：误读 — 原文 `tato ca pavatto aniccādimanasikāro ‘uggahamanasikāro’ti vutto` 是说“由学习而进行的无常等作意，称为‘学习作意’”。nissaya 附注把这个复合词拆成 `ဥဂ္ဂဟတော+မနသိကာရော`（从学习而来的作意）。译文却说成“作意是‘作意’，两者合起来称为‘学习、作意’”，把复合词的构成读错了。
- **建议**：改为“在后一句里，这五种慧都是‘学习’，由它而进行的无常等作意称为‘学习作意’。对它的了知，就是使它进行……”

## §653 句 172-653-111-131

- **问题**：句法 — nissaya 把这句处理成两个**并列**理由（`ဣတိ= ကြောင့်လည်းကောင်း`……`ဣတိ= ထို့ကြောင့်လည်းကောင်း`），共同解释上一句为什么“两者都称为作意善巧”。译文用“因此”把第二个理由写成第一个理由的推论，句首的 `hi` 也没有接上上句。
- **建议**：改为“这是因为：学习也和作意相应，适合得到‘作意’这个名称；而且，应当作意的对象和作意的方法，全都可以称为作意。”

## §654 句 172-654-2-16

- **问题**：指代 — nissaya 把 `tassā` 释作 `ထိုကုသလတာ`（那善巧），译文作“这种慧”，指代对象错了。
- **建议**：改为“……这是说，这种善巧也有学习等的性质。”

## §654 句 172-654-34-42

- **问题**：风格（次要） — “则兼有”里的“则”带文言色彩。
- **建议**：改为“思惟和作意是兼有世间和出世间的”。黑体部分以父层译文为准。

## §656 句 172-656-2-25

- **问题**：译窄 — `ujukatāmudutāniddesehi` 指正直性、柔软性的解说。《法集论》这两组都分身与心两类，译文“心的正直、心的柔软”添了“心的”，范围变窄了。同句的术语混淆问题见跨段一致性一节。
- **建议**：改为“比起端直性和柔软性的解说”。

## §657 句 172-657-14-22

- **问题**：取义偏窄 — `abyāpanno` 的 nissaya 是 `ဖောက်ပြန်ခြင်းသို့ မရောက်သော`（没有变坏的）。附注虽然举了“不处于瞋、忧”作说明，但词义本身是“未变坏”，译成“没有瞋恚”就窄了。被解释词“**心是自己的心**”也不自然，且无法确认是否与义注一致。
- **建议**：改为“意思是心没有变坏、属于自己的心意状态。”被解释词按跨段一致性一节的建议（自意性）与义注对齐。

## §657 句 172-657-35-42

- **问题**：格式 — “attamana（悦意的）”把巴利词放在正文、汉译放在括号里，与 `style.md`“汉译（巴利）”的夹注体例相反。
- **建议**：改为“或者，‘自意的’（attamana）指人，这种人的状态就是自意性（attamanatā）。”译名按跨段一致性一节统一。

## §659 句 172-659-66-83

- **问题**：表达 — 第二处 `tattha` 译成“或者，‘**在这样的人身上**’的 tattha 指的是在那言语上”，叠了两层引述，读起来绕。“原文 tattha”的说法也像译注夹进了正文。
- **建议**：改为“‘**在这样的人身上**’（tattha）：也可以解作‘在前面所说的说出这个动作上’；或者解作‘在那言语上’。”被解释词要先与义注译文核对：义注若未把 tattha 解作“在人身上”，这个黑体就得跟着改。

## §660 句 172-660-2-19 / 句 20-28

- **问题**：术语（存疑） — āmisa 译作“财物”偏窄，它指饮食、衣物等物质供养，与“法”相对。
- **建议**：考虑改为“物质”或“财物供养”，两句要统一。定案后补进 `terms.md`。

## §661 句 172-661-17-36

- **问题**：误读（轻） — `na asaṃvarassa` 的意思是“没有说‘那不防护的’”。nissaya 附注说明这是在比较不定句与定句的措辞，原文说的是措辞上没有加 asaṃvara，而译文“而不是说把那不防护关闭起来”把它说成了一个动作。
- **建议**：改为“……而没有说成‘那眼根的不防护’。”

## §662 句 172-662-24-55

- **问题**：术语漂移 — 见跨段一致性一节。比喻部分可以保留“关闭”，比喻的本体（速行、门等）要统一用“防护 / 未防护”。
