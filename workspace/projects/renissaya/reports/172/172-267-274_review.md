# Review — 172:267-274（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层（义注 Atthasālinī 根聚部分）译文 ❌／下一级注释书（anuṭīkā）❌，仅有 nissaya 夹引的 anuṭīkā 片段
> ⚠ **未注入父层译文，被解释词逐字核对没有做。** 下面所有黑体被解释词（268 Saddahanti etāya / Indaṭṭhaṃ kāreti / Pakkhandana / Paṅko / Paṇakaṃ / Okappanalakkhaṇā / akālusiyaṃ / saddheyyāni / sotāpattiyaṅgāni / hattho·vittaṃ·bījaṃ；269 Vīrabhāvo / paggaho；270 upaṭṭhānaṃ / apilāpanaṃ / apilāpeti / Gatiyo / Aparo nayo / asammoso / kāyādisatipaṭṭhānā；271 Vikkhepassa / Paññāpeti / Ekālokā hoti / mano / Vijānāti；272 Pītisomanassasampayogato；273 Pavattasantatādhipateyyaṃ / attanā avinibhuttadhammānaṃ / atthikkhaṇeyeva / Tassa tassā / Sādhanato）都要在 harmonize 时与义注译文逐字比对。下面凡是建议改被解释词的，都要连同义注一起改，不能只改本层。

## 跨段一致性
- **“成就”一词对应三个巴利词**：sampatti（§268 “成办一切成就”）、nipphatti（§270 “去向……成就”）、sādhana（§273 “成就”“这种成就”）。同一 chunk 里读者会把它们当成同一个概念。建议这样分开：sampatti →“圆满”，nipphatti →“成就”，sādhana →“完成”。sādhana 若在义注里已定为“成就”，就改另外两个。
- **“作用”同时译 kiriyā、rasa、kicca**：§268 saddahanakiriyā 译“相信这一作用”，§270 rasādi 译“作用等”，kicca 也译“作用”。rasa 与 kicca 同义，可以共用“作用”。kiriyā 是“动作／行为”，建议改为“相信这一动作”，以免与“作用（rasa）”这一法相术语混同。
- **“相应”的技术义被泛用**：§268 sampayuttadhamme 译“相应的诸法”是术语义。§269 anurūpapaccavekkhaṇā 又译“与之相应的省察”，这里应是“适当的”，见该句。
- **apilāpana／apilāpeti 不一致**：§270 句 11-26 译“**不浮泛**”，句 27-30 的 apilāpeti 却译“**记起而不浮泛**”，平白多出“记起”。见该句。
- **sumana／somanassa**：§272 把 sumana 译成“善意者”，与 somanassa“悦”脱节，读者看不出词源关系。见该句。

## §268 句 172-268-2-13
- **问题**：取义 — 被解释词译“**人们**凭借它而相信”，把主语定成了人。可是复注本句与下句的解释恰恰是：真正“相信”的是以相信这一动作而转起的**诸法**（nissaya：`ဓမ္မာနံ= သမ္ပယုတ်တရားတို့အား` 相应诸法）；“某人相信”只是由此而来的世俗说法（vohāra）。译文的被解释词与复注的解释自相抵触。另外 `tattha` 按 nissaya 是“在那胜解的特相上”（`ထို အဓိမောက္ခ လက္ခဏာ၌`），译“在其中”指代不明。
- **建议**：被解释词去掉“人们”，改为“**凭借它而相信**”，须与义注同步改。“在其中”改为“在（胜解）这一点上”。“这是显示”改为“这是表明”。

## §268 句 172-268-14-29
- **问题**：准确性 — 原文是 `sati`（“当……时”），没有“只有”的排他义。`puggalo` 译“这个人”指代过实。
- **建议**：“因为当信对诸法起到这样的缘的作用时，才有‘某人相信’这种说法。”

## §268 句 172-268-30-37
- **问题**：用词 — `pasādanīyaṭṭhānesu` 按 nissaya 指佛等所缘（`ဘုရား အစရှိသော အာရုံတို့၌`），译“地方”太实。
- **建议**：改为“值得净信的对象”。

## §268 句 172-268-38-45
- **问题**：术语 — `yevāpanaka` 译“或者还有的法”，读不通，也不是通行译法。首次出现没有夹注巴利原词。
- **建议**：采用“若有余法（yevāpanaka）”一类定译，首次夹注，并登记进 `terms.md`。该句 confidence 压低，等术语定案。

## §268 句 172-268-70-73
- **问题**：用词 — `saṃsīdanaṃ` 译“沉入其中”，“沉”在汉语里偏消极（下沉、沉没）。nissaya 释为 `ကောင်းစွာသက်ဝင်ခြင်း`（好好地进入），并注明复注这样解释是为了排除“飞跃”义。
- **建议**：改为“深入其中”。

## §268 句 172-268-74-78
- **问题**：**必改** — nissaya 词法。`kaddamato` 是比较离格，nissaya 作 `ကဒ္ဒမ ညွန်ထက်`（**比**淤泥更……），不是来源格。译文“由淤泥变得浓稠而成”误读了格。此外 paṅka 的意思是比 kaddama 更稠，“泥浆”却偏稀，与释义正相反。
- **建议**：“**稠泥**（paṅka）比淤泥更浓稠。”被解释词须与义注同步改。

## §268 句 172-268-79-82
- **问题**：**必改** — 误译。`paṇakaṃ` 按 nissaya 是 `ရေညှိ`（水苔／水藻），释义是“滑腻的水垢”。“浮萍”是有根有叶的水生植物，与“污垢”的释义矛盾。
- **建议**：“**水苔**，是水中滑腻的污垢。”须与义注同步改。

## §268 句 172-268-83-85
- **问题**：**必改** — 结构虚构。原文 `Pītaṃ udakaṃ` 没有“X ti Y”的释词结构，是复注引用义注的读法（nissaya：接义注的 `āharatha`；又注“义注诸本作 pānīyaṃ”）。译文加了括号“（饮用水）就是……”，自造了一个被解释词，括号也形同工作标记。
- **建议**：直接译为“可以喝的水。”义注异读（pānīyaṃ）写进报告，不进译文。

## §268 句 172-268-86-91
- **问题**：补出成分 — `anupavisitvā` 按 nissaya 是“依次进入**所信的对象**”，译文“深入进去”没有交代进入什么。
- **建议**：“就是以深入所信的对象、认定‘正是这样’为特相。”

## §268 句 172-268-92-97
- **问题**：准确性 — 被解释词与释义都是“不浑浊”，成了同义反复。`akālusiyaṃ` 是抽象名词，`anāvila` 与 `akalusa` 也被译得几乎一样。nissaya 补注：不浑浊即**澄净**，所以 saddhā 兼有“信”与“净”两义。
- **建议**：“没有浑浊的状态就是**无浊**，意思是澄净的状态。”被解释词须与义注对齐。

## §268 句 172-268-98-100
- **问题**：语序 — 原文是以释义解被解释词（saddheyyāni = 佛等对象），译文读起来像一个断言。
- **建议**：“**值得相信的**，指佛等对象。”nissaya 说明“等”包括法、僧、业、业果，可以写在报告里供参考。

## §268 句 172-268-101-103
- **问题**：术语 — 汉传通行的译法是“**预流支**”（四预流支）。
- **建议**：改为“预流支”，按 style.md“常见术语用传统汉译”；须与义注同步。

## §268 句 172-268-104-117
- **问题**：**必改** — 复合词误析。`amatakasiphala` 按 nissaya 是“耕作所得的不死之果”（`လယ်ထွန်ခြင်းကြောင့် ရအပ်သောအမြိုက်သီး`），典出《相应部·婆罗门相应》“这样耕作，结出不死之果”。译文“不死这一农作的果实”把“不死”当成了农作本身。另外“成办”偏书面。
- **建议**：“……在成就一切圆满上就像**财富**，在使耕作结出不死之果上就像**种子**。”

## §269 句 172-269-17-68
- **问题**：**必改** — ① `anurūpapaccavekkhaṇāsahitāni` 是“伴有**适当的**省察”（nissaya：适合精进生起的省察），译成“与之相应的”会和术语“相应（sampayutta）”混淆。② 整句缺谓语：原文是“这八者……**就是**发起精进的事由”，译文只有破折号后一串名词，没有判断。
- **建议**：“……——这八者，连同适当的省察，就是八种发起精进的事由；或者说，以这些为根本的省察就是（发起精进的事由）。”

## §270 句 172-270-27-30
- **问题**：**必改** — 跨句不一致，并且添字。`apilāpeti` = `apilāpe karoti`（nissaya：使之成为不浮泛的），译文“记起而不浮泛”多出了“记起”，与上句 apilāpana“不浮泛”对不上。
- **建议**：“**使不浮泛**：就是使（所缘）成为不浮泛的。”须与义注同步。

## §270 句 172-270-31-37
- **问题**：用词 — `sambhavato` 按 nissaya 是“由生起的原因（能生、支持之缘）”，译“发生”不够清楚。
- **建议**：“指从起因和结果两方面说的成就。”这里的“成就”见跨段一致性一节。

## §271 句 172-271-63-72
- **问题**：**必改** — 误译。`sañjānana` 译“想念”，现代汉语里“想念”是思念某人，意思全错。
- **建议**：“……而不是像想和慧那样，以标记认取和通达的方式来知道。”

## §272 句 172-272-2-24
- **问题**：**必改** — ① `sumano` 译“善意者”，现代汉语里“善意”是好心、友善，与“心情愉悦”无关，也切断了与 somanassa“悦”的词源联系。按 nissaya，被称为 sumana 的是心，不是人。② “适意之受”中的“之”属文言虚词。③ `vutte` 指义注已经这样说了（nissaya：“如义注所说”），“如果说成”像在设想另一种说法。
- **建议**：“义注说‘**由于与喜和悦相应**’：既然使心成为悦意的那个法叫做悦，喜也就会成为悦；所以应当这样解读：即使不依身这个依处，也是由于与适意的受相应。”被解释词须与义注对齐。

## §273 句 172-273-2-7
- **问题**：取义 — 被解释词译“对**正在转起的**相续”，把 pavatta 当成了修饰语。可是复注的解释是“称为转起的相续”，pavatta 是相续的同位语。被解释词的译法与复注的解释相抵触。
- **建议**：被解释词改为“**主导转起的相续**”或类似说法，不预设“正在”，须与义注同步。释义保留“就是对称为转起的相续起主导作用”。

## §273 句 172-273-8-45
- **问题**：准确性 — `avisesena` 按 nissaya 是“不凭业的差别，而凭一般的命根”，译“不加区分地说”成了说话方式，偏离原意。
- **建议**：“或者不论业的差别，一直到般涅槃为止……”

## §273 句 172-273-46-48
- **问题**：**必改** — 被解释词添字。被解释词只是 `atthikkhaṇeyeva`，`anupāletabbānaṃ` 是复注补出的。译文把“那些法”塞进了黑体，又在释义里补一遍，结构颠倒。
- **建议**：“**只在存在的刹那**：指应当被护持的诸法存在的刹那。”须与义注同步。

## §273 句 172-273-57-61
- **问题**：用词 — `tassa tassā` 译“这各项”，不通顺。
- **建议**：改为“**各自的**”或“**那一一**”，须与义注对齐。

## §273 句 172-273-62-65
- **问题**：格位 — 被解释词 `sādhanato` 是离格（由于……），释义 `sādhanena` 是具格。译文被解释词只作“成就”，丢了“由于”。
- **建议**：“**由于完成**：就是凭着完成。”用词见跨段一致性一节，须与义注同步。
