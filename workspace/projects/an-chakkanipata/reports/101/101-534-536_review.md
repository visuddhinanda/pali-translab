# Review — 101:534-536（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 数据注记：§534 的 nissaya 与句的对应错了一位。`101-534-57-69` 没有挂 nissaya；`101-534-70-85` 挂的实际是 57-69 句（kammāsaṃ）的 nissaya；`101-534-86-122` 的 nissaya 开头含有 70-85 句（sabbena sabbaṃ abhinnāni）的内容。下文按内容对回原句审查。57-69 句也据此核过，没有词法问题。

## 被解释词与父层对照

- **Akhaṇḍānī / khaṇḍaṃ / chiddaṃ / sabalaṃ / kammāsaṃ / akhaṇḍāni…akammāsāni**：不破／破／穿／斑／杂，与父层 §55 逐字相同 ✅
- **bhujissāni / viññuppasatthāni / aparāmaṭṭhāni / samādhisaṃvattanikāni**：使人自主／为智者所赞叹／不被执取／能导向定，与父层 §55 逐字相同 ✅
- **Sīlasāmaññagato viharati**：“都安住于同样的戒”，与父层 §55 逐字相同 ✅
- **Ariyā / niyyānikā / takkarassa / dukkhakkhayāya / diṭṭhisāmaññagato**：圣者的／能导向出离的／照此修行的人／苦的灭尽／同样的见，与父层 §56 逐字相同 ✅
- **Yāyaṃ diṭṭhī**：译作“那种……见”，用省略号连接父层“那种圣者的、能导向出离的见”的首尾，“那种”“见”两处与父层逐字相同。可以接受，不列为必改项。

## 跨段一致性

- **bhinna 与被解释词 khaṇḍa 同译“破”**：§534 各句里，动词 bhinna（nissaya `ပျက်` 坏、毁）一律译“破”，被解释词 khaṇḍa 也是“破”，于是读成“破了头末学处的，戒叫做**破**；中间破了的，叫做**穿**”，定义同义反复。读者分不清哪个“破”是术语。
  - 建议：被解释词按父层锁定为“破”不动，动词 bhinna 改译“毁犯”或“犯了”，§534 四处（2-22、23-34、35-56、57-69）以及 70-85 的 abhinna（改“未毁犯”）一并统一。
- **§535 与 §536 的平行句式**：sīlasāmaññagato 的释文（samānabhāvūpagatasīlo viharati）与 diṭṭhisāmaññagato 的释文（samānadiṭṭhibhāvaṃ upagato hutvā viharati）是同一结构。§536 译作“达到见解相同的状态而安住”，§535 却拆成“他的戒与……的戒已经达到同一状态，他就这样安住”，两处句式不平行。
  - 建议：§535 改成与 §536 同构，见下条。

## §534 句 101-534-86-122

- **问题**：措辞 — `ပရာမဋ္ဌုံ` 是“错误地触及、指摘”，译文作“来指摘触犯”。“触犯”在汉语里容易读成“犯戒”，与上下文的“犯过这样的罪”相混。
- **建议**：删去“触犯”，作“没有任何人能够以‘你从前犯过这样的罪’来指摘”。

## §535 句 101-535-2-15

- **问题**：句法 — nissaya 中 `ဘိက္ခုဟိ သဒ္ဓိံ= ရဟန်းတို့နှင့် တကွ` 是“与比丘们一起”（伴随），`သမာနဘာဝူပဂတသီလော= …သီလရှိသည်ဖြစ်၍` 是有财释，修饰主语“具有达到相同状态之戒的（他）”，谓语是 `ဝိဟရတိ= နေ၏`。译文把 saddhiṃ 改成了戒与戒的比较，又把 viharati 弱化成“他就这样安住”，主干被拆散了。
- **建议**：“**都安住于同样的戒**，意思是他与住在各个地方的比丘们一起，持有已达到相同状态的戒而安住。”

## §535 句 101-535-16-30

- **问题**：误读 — `မဂ္ဂသီလေ= မဂ်သီလ၌`（处格单数）、`နာနတ္တံ= အထူးသည်`，意为“在道戒上没有差别”。译文“各圣道的戒之间没有差别”变成了不同道（如入流道与阿罗汉道）的戒彼此无别，偏离原意。原意是不同的人同证一道时，道戒相同。
- **建议**：“……是完全相同的，道戒并没有差别。”
- **问题（次要）**：`သမုဒ္ဒန္တရေ= သမုဒ္ဒရာအလယ်၌` 是“在海中、在海之间”，译“海的另一边”偏了一层。
- **建议**：作“远隔大海”或“在海那边的洲上”均可。若求贴合 nissaya，作“住在海中（洲上）”。

## §536 句 101-536-12-14

- **问题**：句法 — `နိယျာနိကာ= ဝဋ်ဆင်းရဲမှ ထွက်မြောက်တတ်၏`：niyyāti 是不及物动词，意为“（它自己）出离”，nissaya 还补出了出离的起点“从轮回苦”。译文“能把人导出去”改成了使役句，并补出了宾语“人”。
- **建议**：“因为它能（从轮回之苦）出离（niyyāti），所以叫做 **能导向出离的**。”

## §536 句 101-536-21-24

- **问题**：补出成分 — nissaya 在本句前补了 `တဿ= ထိုဘုရားဆုံးမတော်မူတိုင်းပြုကျင့်လေ့ရှိသောရဟန်းအား`，即“对那个照佛所教去做的比丘”。这是上一句 yo…（凡是……的人）的关系词呼应，原文省略了。
- **建议**：译文现在可以不补，但 §536-15-20 可以作“就是照着（佛所教的）这样去做的人”，让上下句的指代更清楚。属于可选项。
