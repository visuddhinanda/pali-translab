# Review — 89:98-98（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本段只有 3 行附 nissaya：89-98-14-23、89-98-24-40、89-98-108-109）

## 跨段一致性
- 89-98-2-13 与 89-98-86-95 是同一句巴利（Lābhā te … suladdhaṃ te），89-98-14-23 与 89-98-96-107 也是同一句（Yassa te nakulamātā …）。两组现有译法彼此一致。下面针对 89-98-24-40、89-98-14-23 提出的改法，**须同步改到对应的重复句**，否则会出现前后不一致。
- nakulamātā gahapatānī：五处都译作“女居士那拘罗母”，一致。

## §98 句 89-98-24-40
- **问题**：nissaya 错位 + 词法 + 文言。这一行 nissaya 的前半部分（`တဿ တေ= ထိုသင့်မှာ။` 到 `သုလဒ္ဓံ= ကောင်းစွာရအပ်ပါပေ၏။`）讲的是 Lābhā te / suladdhaṃ te，也就是句 89-98-2-13 的内容，不属于本句。不过它暴露了 89-98-2-13 与 89-98-86-95 译文的两个问题：
  1. `လာဘာ= ကောင်းမြတ်သောအဆုံးအမသြဝါဒလာဘ်လာဘတို့ကိုရရှိခြင်းတို့သည်` 中，lābhā 是复数主格，指“得到良好劝导、教诫这些利益”，由 `(ဟောန္တိ)` 补出谓语“是有的”。现译“你真有所得”方向对，但“有所得”太空泛。
  2. `(မနုဿတ္တံ= လူ့ဘဝကို)` / `သုလဒ္ဓံ= ကောင်းစွာရအပ်ပါပေ၏`：nissaya 为 suladdhaṃ 补出了隐含的主体 manussattaṃ（人身），意思是“你的人身得来得好”。现译“你得之甚善”用了代词“之”，却没有补出“得”的是什么，同时也违反现代汉语硬约束（之、甚）。
- **建议**：89-98-2-13 与 89-98-86-95 同步改为“居士，你真有福气！居士，你这一生的人身没有白得！”（或在意思相近的范围内换一种现代说法，但必须去掉“之”“甚”）。
- **本句本身**：sīlesu 是复数处格（`သီလေသု= တို့၌`），“在戒上”可以改为“在各项戒上”，属于可选项。其余成分与 nissaya 一致：yāvatā / gihī 是主格，tāsaṃ 表示“在那些人当中”，aññatarā 意为“其中之一”。

## §98 句 89-98-14-23
- **问题**：句法角色。nissaya 作 `ယဿ တေ= အကြင်သင့်ကို`（宾格，“你”是受事）、`ဂဟပတာနီ= သည်`（那拘罗母是主格施事）、`အနုကမ္ပိကာ= (စီးပွားဖြင့်)ငဲ့ညှာထောက်ထားသနားလျက်`、`အတ္ထကာမာ= အကျိုးကိုလိုလားလျက်`（这两个以 `လျက်` 结尾，是伴随状语）、`သြဝါဒိကာ= ဆုံးမပါပေ၏`、`အနုသာသိကာ= သွန်သင်ကံမြစ်ပါပေ၏`（这两个才是主句谓语）。也就是说，原句的结构是“那拘罗母怀着怜悯、希望你得到利益，劝导你、教诫你”。现译把“你”改成了“有”的主语，并把四个词平列成四个谓语，主宾关系和状语、谓语的层次都被抹平了。另外，nissaya 补出的 `(စီးပွားဖြင့်)`（“以利益”来怜悯）在译文中没有体现。
- **建议**：改为“女居士那拘罗母怜悯你、希望你得到利益，她劝导你、教诫你。”89-98-96-107 同步修改（保留句末的 ”）。
- **附**：本行 nissaya 里混入了 `ဂဟပတိ= အိမ်ရှင်ဒါယကာ`（呼格“居士”），这个词不在本句的巴利范围内，属于对齐偏差，只作记录。
