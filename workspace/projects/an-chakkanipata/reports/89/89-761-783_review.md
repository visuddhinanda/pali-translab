# Review — 89:761-783（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- diṭṭhisampadā / diṭṭhisampanna：§765、§766 把 diṭṭhisampadaṃ 译成「见的具足」，§768–§778 把 diṭṭhisampanno 译成「具足见的人」。两处是同一词干，nissaya 对两者的释义都是「具足知见的须陀洹道／须陀洹人」，但现在一处是名词偏正结构，一处是动宾结构，读者看不出是同一概念。→ 建议统一为「见具足」与「见具足者」，或「具足正见」与「具足正见的人」。§765、§766 各两处，§768–§778 各处跟着一起改。
- attha / anattha：§762 和 §763 都译成「有意义的内容／没有意义的内容」，两段之间是一致的，但与 nissaya 的取义不符，见下文 §762 条。两段要同步改。
- 属格作施事：§768 首句与末句（`89-768-36-49`）句式相同，都把 diṭṭhisampannassa puggalassa 处理成「对于……」。按下文 §768 条修改时，末句也要同样改，保持首尾呼应。

## §762 句 89-762-26-64
- **问题**：误读（词义）— anatthaṃ / atthaṃ 在 nissaya 中是 `အနတ္တံ= မကြီးပွား မတိုးတက်မှုကို။ ဝါ= ဆုတ်ယုတ်မှုကို။`（不增长不进步的事，或：衰退），`အတ္တံ= ကြီးပွားတိုးတက်မှုကို။`（增长进步的事）。这里取的是「利益／无益」，不是「意义／无意义」。
- **建议**：改为「执取无益的东西，舍弃有益的东西」。
- **问题**：术语译窄 — khanti 在 nissaya 中是 `ခန္တိယာ= အလိုအကြိုက် အယူအဆနှင့်။`（喜好、见解），ananulomika 是 `သာသနာတော်အား မလျော်သော`（与教法不相应的）。「不随顺的忍」容易被读成忍辱的「忍」，也没有说出随顺的对象。
- **建议**：改为「具有不合于教法的见解（khanti）」，或「具有不随顺教法的认可（khanti）」。
- **问题**：补出成分 — aññā cittaṃ upaṭṭhāpeti 在 nissaya 中补出了所缘：`(တရားအာရုံ၌) စွဲကပ်မတည်နေစေ`（不使心系住于法这一所缘）。现译「不把心用在求了知上」没有体现「安住」，也没有体现对象是法。
- **建议**：改为「不为了了知而把心安住在法上」。

## §763 句 89-763-23-45
- **问题**：误读（词义）— 与 §762 相同，atthaṃ / anatthaṃ 应取「有益／无益」，anulomikāya khantiyā 是 `သာသနာတော်အားလျော်သော … အလိုအကြိုက် အယူအဆ`（合于教法的见解）。
- **建议**：改为「执取有益的东西，舍弃无益的东西」「具有合于教法的见解」；「把心安住在法上」也与 §762 同步改。

## §765 句 89-765-2-18
- **问题**：翻译腔 — diṭṭhisampadaṃ 在 nissaya 中是 `ဉာဏ်အမြင်နှင့်ပြည့်စုံသော သောတာပတ္တိမဂ်ကို`（具足智见的须陀洹道），是一个整体术语。「见的具足」拆开直译，读起来不通。
- **建议**：改为「证得见具足」。§765-37-48、§766 两句同样改。

## §768 句 89-768-2-17
- **问题**：格与句法 — nissaya 把属格 diṭṭhisampannassa puggalassa 释作施事主格：`ပုဂ္ဂလဿ= သောတာပန်ပုဂ္ဂိုလ်သည်။ … ပဟီနာ= ပယ်အပ်ကုန်ပြီ။`（须陀洹人已经舍断）。现译「对于具足见的人，这六种法已经舍断」把施事者弄成了旁格，谁舍断的不清楚。
- **建议**：改为「比丘们，具足见的人已经舍断了这六种法」。末句 `89-768-36-49` 同步改。

## §772 句 89-772-17-63
- **问题**：误译（术语）— sikkhāya 在 nissaya 中是 `(သီလ, သမာဓိ, ပညာအားဖြင့် သုံးပါးသော) အကျင့်သိက္ခာ၌`（戒、定、慧三种学）。这里的 sikkhā 指三学，不是 sikkhāpada（学处、戒条）。
- **建议**：改为「对学（戒定慧三学）不恭敬」，或直接译「对修学不恭敬」。
- **问题**：补出成分 — anāgamanīyaṃ vatthuṃ 在 nissaya 中补出了所指：`(ပါဏာတိပါတအစရှိသော ရန်ငါးပါးနှင့် ၆၂-ပါးသော မိစ္ဆာဒိဋ္ဌိ…)`（杀生等五种怨敌和六十二邪见）。「不应回去的事物」太空泛。
- **建议**：正文可改为「回到不应趋近的事上」。所指（五怨、六十二见）放在报告里备查，不进正文。
- **问题**：用词 — aṭṭhamaṃ bhavaṃ 在 nissaya 中是 `ရှစ်ခုမြောက်သော … ကာမာဝစရဘဝ ပဋိသန္ဓေကို`（第八次欲界的有、结生）。「生起第八次的生命」把 bhava 说成了「生命」。
- **建议**：改为「不可能再受第八次生」，或「不可能产生第八次的存在（bhava）」。

## §774 句 89-774-17-104
- **问题**：夹注不当 — 「无间业（ānantariya kamma，直接导致下一生堕落的重业）」。按 style.md，首次出现只用圆括号附巴利原词，释义不进夹注。另外，释义本身与 nissaya 不符：nissaya 是 `စုတေသေလွန်သည်နှင့်တပြိုင်နက် မချွတ်မလွဲအပါယ်ငရဲ ပဋိသန္ဓေအကျိုးကိုပေးသော`（死后立即、必定给予恶趣地狱结生之果的业），「堕落」既不准确也偏弱。
- **建议**：正文只写「无间业（ānantariya kamma）」。如需说明，作脚注：「死后必定立即投生地狱的业」。
- **问题**：句法 — kotūhalamaṅgalena 是具格，表示原因。nissaya 是 `ကြီးပွားကြောင်းမင်္ဂလာဟု လူဗာလတို့ကြံဆအပ်သော အထူးအဆန်း…အာရုံကြောင့်`（因为愚人认为是吉祥的稀奇见闻）。suddhiṃ 是 `စင်ကြယ်…ရရှိ၏ဟု ယုံကြည်ယူဆမှုသို့`（相信能得到清净与福乐的看法）。「由好奇而来的吉兆」不通，也没有译出「愚人认为是吉祥」这一层。
- **建议**：改为「不可能回到‘凭稀奇的吉祥征兆就能得到清净’这种看法上」。

## §776 句 89-776-17-61
- **问题**：冗余 — 「另外奉别的导师为师」中「另外」和「别的」重复。nissaya 是 `မြတ်စွာဘုရားမှ တပါးသော … ဆရာကို … မိမိဆရာဟု ညွှန်ပြပြောဆိုခြင်းငှာ`（指称佛陀以外的老师为自己的老师）。
- **建议**：改为「不可能奉佛陀以外的人为自己的导师」，或「不可能把别人认作自己的导师」。

## §778 句 89-778-18-73
- **问题**：词义 — adhiccasamuppannaṃ 在 nissaya 中是 `အကြောင်းမဲ့ အလိုအလျောက် ဖြစ်ပေါ်လာ၏`（无因、自然生起），并注明属于 `အဟေတုကဒိဋ္ဌိ`（无因见）。「偶然生起」没有体现「无因」，与无因见的对应关系就不清楚了。
- **建议**：后三处的「偶然生起」统一改为「无因而生」。
- **问题**：补出成分 — 第三项 sayaṃkatañca paraṃkatañca 在 nissaya 中是 `တချို့တဝက် ပြုလုပ်အပ်၏`（一部分是自作、一部分是他作），第六项同理。「既是……又是……」容易被读成全部自作、同时全部他作。
- **建议**：改为「回到苦乐一部分是自己所作、一部分是他人所作的看法上」。第六项相应改为「既不是部分由自己所作，也不是部分由他人所作，而是无因而生」。
