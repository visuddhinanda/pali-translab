# Review — 89:158-165（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（只有部分句子有 nissaya，没有 nissaya 的句子不出意见）

## 跨段一致性
- 无。§159–§165 的重复句式（ujugatamevassa… / ‘Gedho’ti… / Idampi… visujjhanti）各段译法完全一致。不过下面列出的词法问题是这些重复句**共有**的，修订时要六段同步修改，否则会造成新的漂移。

## §159 句 89-159-67-77
- **问题**：词法 / 隐含成分 — `ဥဇုဂတမေ၀ဿ= ဖြောင့်မတ်စွာသွားသည်သာလျှင်ဖြစ်သော`（“正是正直地行进的”；`ဝါ=` 的解释是“正是达到了正直状态的”）。`eva`（`သာလျှင်`“正是、唯独”）承接前句“不被贪、瞋、痴占据”，起转折强调作用。现译“是正直的”漏掉了 eva，也没有体现 gata（达到、趋向）的意思。
- **建议**：改为“而是变得正直”或“他的心在那个时候正是正直的”，补出 eva 的转折强调。§160 / §161 / §162 / §165 的同一句要同步修改。

- **问题**：词法 / 取义 — `ဂေဓမှာ= တပ်မက်ဖွယ်အာရုံမှ`（“从值得贪恋的所缘对象中”）。nissaya 把 gedha 解作**被贪着的对象**，不是贪着这种心理本身。下一句也说 gedha 是“五种欲（对象）”的名称，可以印证这一点。现译“从贪着中出离”把对象译成了心理活动。
- **建议**：改为“从贪恋的对象中出离”，或保留“贪着”但确保下一句的定义与之对得上（见下条）。各段同步修改。

## §159 句 89-159-78-89
- **问题**：词法 / 取义 — `ကာမဂုဏာနံ= ကာမဂုဏ်တို့၏`，异释 `ဝါ= ဝတ္ထုကာမအနှောင်အဖွဲ့တို့၏`／`ဝါ= ဝတ္ထုကာမအစုအဝေး၏`（“对象欲（vatthukāma）的束缚／集合”）。nissaya 明确指向色、声、香、味、触这些**欲的对象**。“欲乐”容易被读成快乐的感受，与 `ဂေဓာတိ ဧတံ= …ဝါ= တပ်မက်ဖွယ်အာရုံဟူသောဤနာမည်`（“‘值得贪恋的所缘’这个名称”）的对象义不贴合。
- **建议**：改为“五种欲的对象”或“五欲”（如果术语表另有定译就依术语表），并与上一句 gedha 的译法统一为“对象”义。属格 `၏` 加上 `အဓိဝစနံ= နာမည်` 的结构，现译“……的别名”是对的。各段同步修改。

## §159 句 89-159-90-100
- **问题**：漏译 — `ဣဒမ္ပိ= ဤဗုဒ္ဓါနုဿတိကမ္မဋ္ဌာန်းကိုလည်း`，`လည်း` 对应 pi（“也”）。现译“就是以这个”把“也”译成了带排他意味的“就是”，意思正好相反。
- **建议**：改为“也以这个……”。

- **问题**：词法 / 取义 — `အာရမ္မဏံ= အခြေခံအကြောင်းကို`（“作为基础、所依的因”）。nissaya 在这里把 ārammaṇa 解作“基础、凭借”，而不是认知意义上的“所缘”。异释 `ဝါ= …ရအပ်သောဥပစာရဈာန်ကိုလည်း`（“依此随念所得的近行定”）也说明这里讲的是以它为修行的凭借。
- **建议**：改为“以这个为基础”或“凭借这个”。

- **问题**：隐含成分 — `ဣဒမ္ပိ` 补出了指代对象“这个佛随念业处”，`ဧဝံ` 的异释补出了“像这样随念佛的功德”。现译“这个”“这样”太空泛。
- **建议**：可以补成“也以这种随念为基础，像这样（随念佛的功德）”，至少把“这个”落实为“这种随念”。

- **问题**：词法 — `ဣဓ= ဤလောက၌`（“在这个世间”）。现译“在这里”容易被误解为在本经或本处。
- **建议**：改为“在这个世间”。

## §160 句 89-160-76-86
- **问题**：同 89-159-90-100。`ဣဒမ္ပိ= ဤဓမ္မာနုဿတိကမ္မဋ္ဌာန်းကိုလည်း` 中的 pi 被译成了“就是”；ārammaṇa 应取“基础”义；`ဧဝံ= ဤသို့တရားဂုဏ်တော်ကိုဆင်ခြင်အောက်မေ့ခြင်းဖြင့်`（“像这样随念法的功德”）；`ဣဓ= ၌` 承前省略，指“世间”。
- **建议**：与 §159 同步修改。

## §161 句 89-161-77-87
- **问题**：同上。`ဣဒမ္ပိ= ဤသံဃာနုဿတိကမ္မဋ္ဌာန်းကိုလည်း`，pi 漏译；`ဧဝံ` 的异释是“像这样随念僧的功德”。
- **建议**：与 §159 同步修改。

## §162 句 89-162-68-78
- **问题**：同上。`ဣဒမ္ပိ= ဤသီလာနုဿတိကမ္မဋ္ဌာန်းကိုလည်း`，pi 漏译；`ကရိတွာ= ၍`；`ဧဝံ` 的异释是“像这样随念自己的戒”。
- **建议**：与 §159 同步修改。

## §165 句 89-165-61-71
- **问题**：同上。pi 漏译、ārammaṇa 的取义、`ဣဓ` 的问题都与 §159 相同；`ဧဝံ` 的异释是“像这样修习天随念业处”。
- **建议**：与 §159 同步修改。
