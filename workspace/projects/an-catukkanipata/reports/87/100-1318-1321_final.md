## 理由

**取数条件（必须先交代）**：本次评估只拿到巴利原文与待评译文两项资源。本段所评对象自身即义注层（book=100，`Kusinārasuttavaṇṇanā` / `Acinteyyasuttavaṇṇanā`），故无更上一层的"义注"可作释义标准；**nissaya 亦未注入**。因此准确性一维缺少词级基准交叉核对，格/句法角色的判定全凭原文本身与上下文推断，分数与问题清单的把握度相应下调——这是信心指数只给 68 的主因。涉及格位、修饰关系的几条（尤其 `100-1319-181-190`、`100-1319-34-91`）若事后取到 nissaya，建议复核。

**准确性**：绝大多数被解释词（`upavattana` / `antarena yamakasālānaṃ` / `kaṅkhā` / `vimati` / `acinteyyāni` 等）取义稳当，`dveḷhaka`→"两头摇摆、拿不定主意"、`vinicchituṃ asamatthatā`→"没有能力作出判断"都准确且可读。主要扣分来自两处格位/指代处理：`Imesañhi, ānandā` 的属格 `imesaṃ` 被译成"在这五百位比丘当中"，把属格读成了处格关系，且该句是"被解释词 + 释义"体例（`imesaṃ … pañcannaṃ bhikkhusatānaṃ` 是对 `imesaṃ` 的展开），译文把黑体部分扩写成完整句，破坏了体例对应；另 `taṃ vo vadāmi` 的 `taṃ` 译作"我就是为这个对你们说的"，指代落点含混（`taṃ` 指所疑之事，非"为此而说"）。`cattāro paccayā` 补注"（衣、食、住处、医药）"属合理补足，不扣分。

**风格**：这是本次主要失分维度。`knowledge/style.md` 第一节是硬约束——现代书面汉语、禁文言腔。译文整体口吻偏现代、可读性好，但仍有若干文言虚词与半文半白残留：「正中之处」「是针对…本人说的」尚可，而「谁心里要是生起这样的猜疑」口语化过度与「我就是为这个对你们说的」的生硬并存，语体在同一句内不统一；多处「就是」「是指」「意思是」三种释义套语混用，缺少统一。另有标点体系问题：译文多处使用破折号「——」承接释义（`100-1319-109-131`、`100-1319-34-91`），在义注"词→释"的固定体例里不属必要，且与其余各句的处理不一致。

**一致性**：`…ti` 释义套语在 20 句里分别译作「是指」「就是」「意思是」「这是在表明」，虽各自合法，但同一篇注释内缺少规约；`visayo` 在 `100-1321-34-45` 与 `100-1321-46-49` 统一译"范围"（黑体仍作"境界"），黑体与释义用词不一致，读者会以为是两个词。被解释词的黑体与父层逐字同译一项无法核对（本文层未注入）。

## 问题清单

### 🟧 error

- `100-1319-181-190`｜错译（修饰关系 / 格误读）｜片段「**阿难，在这五百位比丘当中**，是指坐在帷幕里面的这五百位比丘」
  - 问题：`Imesañhi, ānandā` 中 `imesaṃ` 是属格（复数），被解释的是"这些（人）的"；释义 `imesaṃ antosāṇiyaṃ nisinnānaṃ pañcannaṃ bhikkhusatānaṃ` 整体仍是属格短语，意为"这坐在帷幕内的五百位比丘的"。译文把黑体改写成"在这五百位比丘当中"，一是把属格读成处格，二是把下文释义的内容提前搬进了被解释词，使"词→释"体例失效（黑体与释义变成同义重复）。
  - 建议：黑体严格对应原词，释义保留属格关系，例如黑体作「**阿难，这些人的**」，释义作「是指坐在帷幕里面的这五百位比丘的」。

- `100-1319-34-91`｜代词指代错误｜片段「我就是为这个对你们说的」
  - 问题：`taṃ vo vadāmi pucchatha` 中 `taṃ` 回指前面"谁若生起这样的猜疑"所疑之事，意为"（关于）那件事，我对你们说：你们问吧"。译文"为这个对你们说的"把 `taṃ` 处理成了原因/目的状语，指代落点偏移，读者会误解为"我说话的动机是这个"。
  - 建议：改为「关于那件事，我对你们说：比丘们，你们问吧」。

### 🟨 warning

- `100-1321-34-45`、`100-1321-46-49`｜关键词语意不明确（黑体与释义用词不一）｜片段「**诸佛的境界**，就是诸佛的范围」／「**禅定境界**，就是神通之禅的范围」
  - 问题：同一个 `visaya` 在黑体里译"境界"、在释义里译"范围"，两句都如此。读者会以为被解释词和释义词是两个不同的词，而原文正是同词复现（`buddhavisayo ti buddhānaṃ visayo`）。
  - 建议：黑体与释义统一取同一个译法（取"境界"或"范围"其一），全段贯彻。

- `100-1319-34-91`｜文言语体 / 语体不统一｜片段「谁心里要是生起这样的猜疑」
  - 问题：同一句内「心里要是」偏口语，而后半「我就是为这个对你们说的」「这里的大意就是这样」偏硬译，语体在一句内跳动。
  - 建议：统一为中性现代书面语，如「如果有人生起这样的疑问…」。

- `100-1319-109-131`｜标点符号使用错误｜片段「也不该生起疑惑。”——如果你们是像这样出于对导师的恭敬而不提问。」
  - 问题：引号后用破折号接条件分句，且整句以"如果…而不提问。"收尾，条件句无主句，读来是残句。本段体例是"引述想法 + `sace evaṃ … na pucchatha`"，汉语需补出完整句式。
  - 建议：改为「…也不该生起疑惑。”——如果你们是出于这样对导师的恭敬而不提问（那么就让同伴代问）。」或直接去掉破折号，整句另行组织。

- `100-1319-92-108`｜整句逻辑表达不规范｜片段「是指这样的想法：“我们是在导师身边出家的」
  - 问题：被解释词是"出于对导师的恭敬而**不**提问"，但释义只引出一段想法，否定动作（不提问）与这段想法的因果关系在汉语里没有落地；且该引述一直延续到下一句（`100-1319-109-131`）才闭合，跨句引号在 channel 里按句呈现时读者看不到闭合。
  - 建议：在本句末补出引述未完的提示，或与下一句统一处理成"因为有这样的想法…所以不提问"的完整链条。

- `100-1321-30-33`｜关键词语意不明确｜片段「**痛苦**，就是苦」
  - 问题：`vighātassā ti dukkhassa` 以"苦"释"痛苦"，汉语里两者几乎同义，等于没有解释，读者得不到信息。原文的要点是把 `vighāta`（挫折、损害）归到 `dukkha` 这一法相术语上。
  - 建议：黑体改用非术语的"挫折/损害"一类词，释义保留术语"苦（dukkha）"，使释义关系可见。

### 🟦 suggestion

- `100-1319-2-17`｜语言表达不够流畅｜片段「那排向东延伸、在北侧折转而立的娑罗树列的正中之处」
  - 问题：三层定语连环套在一个"的"字串上（…延伸、…折转而立的｜娑罗树列的｜正中之处），嵌套较深，读者需回读。
  - 建议：拆开，如「娑罗树排成一列向东延伸，到北侧折转；优波跋多那就在这一列树的正中」。

- `100-1319-171-180`｜语言表达不够流畅 / 术语标记｜片段「如来在这件事上有的是亲自现见他们没有疑惑这一事实的智，而不只是信」
  - 问题：「有的是…的智」句式别扭，且"智"作为 `ñāṇa` 的对译首次出现未夹注巴利原词（按 `style.md` 第二节，法相术语首次出现宜夹注）。
  - 建议：改为「如来在这件事上具有的是亲自现见他们没有疑惑的智（ñāṇa），而不只是信（saddhā）」。

- `100-1319-132-162`、`100-1321-12-18` 等｜语言风格不统一｜片段「这是在表明：」／「正因为它们是不可思量的，所以」
  - 问题：`…ti … dasseti` 与 `…ti` 直接释义两类句式的汉语套语全篇不统一（「是指」「就是」「意思是」「这是在表明」四种混用）。
  - 建议：约定一套对应关系（如 `…ti X` → "是指"；`…ti … attho` → "意思是"；`…ti … dasseti` → "这是在表明"）并全篇贯彻，写进 `knowledge/style.md`。

- `100-1321-57-87`｜语言表达不够流畅｜片段「是谁造出了山岳？是谁造出了芒果树、多罗树、椰子树等等呢？」
  - 问题：连续五个"是谁造出了…"排比中，句末语气词「呢」只在首尾两句出现，中间三句省略，节奏不齐。
  - 建议：统一加或统一不加。
