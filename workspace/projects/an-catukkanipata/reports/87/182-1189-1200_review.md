## 跨段一致性

- `brahmacariya`：1191 / 1197 / 1199 / 1200 一律作「梵行」→ ✅ 一致。
- `vata`：1191、1192 均作「誓戒」→ ✅ 一致。
- **`Imasmiṃ X-e Y-e` 定型句（1195 / 1198 / 1199 / 1200）**：四处句式统一为「在这篇 X 里，它是在 Y 的意义上出现的」，形式一致 ✅，但**四处共用同一个缺陷主语「它」**（见下「必改项 1」），需一并同改，不要只改一处。
- **出处名的量词不统一**：1195「这篇…本生」／1198「这篇…饿鬼事」／1199「这篇…本生」／1200「这篇…经」。`Petavatthu` 的一则故事用「篇」不合汉语习惯，经用「篇」亦偏轻。→ 建议四处一律去掉量词，统一作「在《X》中」，既统一又避开量词选择。
- **跨层术语 `virāga`**：父层 100:1116 把 `virāgatthaṃ` 译作「为了远离贪等烦恼」、释语作「离染」；本层 1200 作「离贪」。本层该处是**引《大典尊经》原文**、非黑体被解释词，故不构成硬约束，但两层读者会连读 → 建议本层保留「离贪」而在父层/本层择一口径时倾向「离贪」，或至少不要再出现第三种译法。

## 必改项

### §1195 / §1198 / §1199 / §1200 句 `182-1195-2-16`、`182-1198-2-14`、`182-1199-2-25`、`182-1200-2-36`

- **问题**：句法误读（主语指称错） — `āgato` 是**阳性**主格分词，而 `brahmacariyaṃ` 是中性。阳性主语只能是省略的 `brahmacariya-saddo`（「梵行」**这个词**）。本段整体是在罗列 brahmacariya 一词的诸义（dāna / veyyāvacca / pañcasikkhāpadasīla / brahmavihāra），说的是**词义归属**，不是「梵行这件事出现在某处」。译文一律用「它是在…的意义上出现的」，「它」在中文里最自然的回指是「梵行」本身，而非「『梵行』一词」，读者会误解为梵行这一修行出现在该经中。
- **建议**：四处补出主语并统一句式，例如：
  - 1195：「在《富那迦本生》（jā.2.22.1595）中，『梵行』一词用于**布施**的意义。」
  - 1198：「在《鸯俱罗饿鬼事》（pe.va.275,277）中，用于**服务效劳**的意义。」
  - 1199：「……在《鹧鸪本生》（cūḷava.311）中，用于**五学处之戒**的意义。」
  - 1200：「……在《大典尊经》（dī.ni.2.329）中，用于**梵住**的意义。」
  - （后三处若嫌重复，可省主语承前，但第一处必须把「『梵行』一词」立出来。）

### §1200 句 `182-1200-2-36`

- **问题**：术语译名 — `pañcasikha` 译作「五顶」。Pañcasikha 是乾达婆名，传统汉译为「五髻」（亦有音译「般遮翼」），「五顶」无传统依据，属自造译名，`term-glossary.jsonl` 亦未登记。
- **建议**：改「五髻啊」，首次出现按 `style.md` 第三节夹注巴利原词：「五髻（Pañcasikha）啊」；定案后补进 `knowledge/terms.md` 与 `term-glossary.jsonl`。

### §1192 句 `182-1192-2-6`

- **问题**：窄译 — `Tassa suciṇṇassa ayaṃ vipāko` 中 `tassa suciṇṇassa` 承前句 `taṃ me vataṃ taṃ pana brahmacariyaṃ`，**同时指誓戒与梵行两者**（两词皆中性单数，属格形式可同时统摄）。译文「善加实行**那誓戒**所得的果报」把梵行排除在外，与上一句刚刚并列提出的两项对不上。
- **建议**：「这就是善加实行那些所得的果报」或「善加实行那誓戒与梵行，这就是它的果报」——保留承前的双指。

## 建议项（非必改）

### §1193 句 `182-1193-2-5`

- **问题**：术语取向 + 标点 — `iddhi` 译「神变」。`iddhi` 在天宫（vimāna）语境中指天人所享的**威神/神通力**，「神变」偏向 `iddhi-pāṭihāriya`（神变示现）这一动作义，此处是所具之力。另外「神变、光彩，还有力量和精进的具足」在一行偈颂内混用「、」与「还有」，节奏被打断。
- **建议**：「神通、光彩、力量与精进的具足，」；`iddhi` 定案后入术语表。

### §1190 句 `182-1190-2-5`

- **问题**：夹注位置 — 原文是复合词 `samaṇabrāhmaṇā`，译文在偈颂行中把巴利夹注切给前半「沙门（samaṇa）」，偈颂行被括号打断，且夹注与所释词并不等价。
- **建议**：偈颂行内不夹注，或改为整体夹注「沙门和婆罗门（samaṇa-brāhmaṇā）」；`style.md` 第五节要求偈颂保留分行节奏，括注宜让给散文部分。

### §1197 句 `182-1197-2-12`

- **问题**：漏译代词 — `Kena te brahmacariyena` 的 `te`（你的）未译出，上一行却补了「你的手」，同一问句内前后不匀。
- **建议**：「是凭你哪一种梵行，让功德在你手上成就？」

### §1199 句 `182-1199-2-25`

- **问题**：行文生硬 — 「那个叫做鹧鸪梵行的，就是这样的」把 `taṃ … nāma` 直搬成「那个叫做…的」，读来不顺；`pañcasikkhāpadasīle` 译「五学处的戒」中「学处」与「戒」语义叠套。
- **建议**：「比丘们，那所谓的鹧鸪梵行就是这样的。」；后半作「用于五学处之戒的意义」。

### §1192 句 `182-1192-2-6`（风格）

- **问题**：「善加实行」中「善加」偏半文半白。按 `style.md` 判定标准（给无古文基础读者读不应有文言感），属边缘用例，非典型禁例。
- **建议**：可改「好好实行」「切实实行」；若保留「善加」，全书需统一，不要与「好好…」混用。

## 存疑 / 待核（不要据此改译文）

- **§1195 `puṇṇakajātake` 的书名译法**：现作「普纳卡本生」，是无依据的新音译。Puṇṇaka 是《毘陀罗贤者本生》中的夜叉，传统音译多作「富那迦」；且本 chunk 其余三处书名都采用了传统译名（鸯俱罗饿鬼事／鹧鸪本生／大典尊经），此处独用新造音译，风格不齐。**但这是黑体被解释词**，而父层对照本次失配、无法核对父层定译 → 不应在本步擅改。建议：取到真正对应的父层（book=100 中含 `puṇṇakajātake` 的那一段）译文后再定案，若父层无此词则按传统译名定为「富那迦本生」。
- **§1198 `veyyāvacce`**：译「服务效劳」。此词传统汉译有「执事／给侍／奉事」等，`terms.md` 未登记。现译义不误，待定案后补表。
