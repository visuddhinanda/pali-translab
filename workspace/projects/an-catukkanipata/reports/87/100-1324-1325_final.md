## 理由

**数据基准缺失**：本次只注入了巴利原文与待评译文，**nissaya 与更上层注释（复注/ṭīkā）均未提供**。本段本身即是义注（aṭṭhakathā）层对《增支部》Vaṇijjasutta 的释文，故"义注定释义"这一基准对本层不适用——只能以巴利原文内部逻辑、同段平行结构与常规巴利词法为准判断。词级基准（nissaya）缺失，格与句法角色的核验无外部权威支撑，因此信心指数压到 70，下面标为 error 的几条请在有 nissaya 时复核。

**准确性**：绝大多数句子释义关系（被解释词 + "是说" + 释文）处理正确，补出的隐含成分（如 `100-1325-78-86` 补"他许约的那一份"）有原文 `taṃ` 的支撑，属合理。主要扣分在三处：`chedagāminī` 与 `parādhippāyā hoti` 两个**被解释词的译法脱离了原文字面**（原文是"走向断绝/亏折"、"成为他人心愿之物"类结构，译文直接给出了结果性意译"亏损""收获超过了预期"），以及 `samaṇa/brāhmaṇa` 那句把 `samitapāpa`（息灭恶）与 `bāhitapāpa`（排除恶）的**对应关系拆成"分别"**，但原文 `samaṇabrāhmaṇatā veditabbā` 是一个合成概念，"分别叫作"是译者加入的归属判断，原文未明说哪一项对哪一项（传统释义中二者确有分属，但此处属补出，宜降 confidence 或加注）。

**被解释词与父层逐字同译（硬约束）**：本段的黑体被解释词引自本文（Vaṇijjasutta 经文），其译法必须与本文层译文逐字一致。本次未注入本文层译文，**无法核对**。`亏损` / `达不到预期` / `收获超过了预期` / `一点也不给` / `给得比对方期望的少` 等均为意译式短语，与本文层经文的对应译法是否逐字相同存在实际风险——这是本次评估最大的未验证项，必须在 harmonize 阶段比对本文层后才能放行。

**风格**：现代书面汉语，未见文言虚词与文言句式，`style.md` 第一节禁例表无命中。标点全角、无 ASCII 引号、无工作标记残留，均合规。`100-1325-54-70` 的破折号"——这样许约、这样邀请"稍显生硬但不违规。

**一致性**：`ajjhāsaya` 一词在本段出现四次，译法在"心愿"（`28-35`、`36-43`）与"期望"（`104-113`、`114-122`）、"对方的心愿"（`87-103`）之间游移；`pavāreti` 则统一译为"许约"，一致性良好。前者是本段最明显的一致性问题。

## 问题清单
按级别从高到低排列。

### 🟧 error
- `100-1325-20-27`｜漏译｜片段「全都亏掉了」
  - 问题：原文 `nassati` 是"失去、毁坏、荡然无存"，译文"亏掉了"把语义缩窄为商业亏损，且 `sabbaṃ`（全部）与 `nassati`（丧失）的力度被弱化；`patthitaṃ`（所希求的）译"希望得到的"可接受，但"亏掉"与前句 `chedagāminī` 的译法重复叠加，掩盖了原文"所求尽失"的释义。
  - 建议：改为"意思是：凡是所希求的，全都丧失了"。

- `100-1325-36-43`｜错译（修饰关系）｜片段「**收获超过了预期**」
  - 问题：被解释词 `Parādhippāyā hoti` 的 `para-` 指"他人（的）"，释文 `parajjhāsayā ... adhikataraphalā hoti` 意为"成为（顺)他人心愿的、果报比（自己）心愿更多的"。译文把被解释词直接译成结果句"收获超过了预期"，丢掉了 `para`（他人）这一关键语素，与同段 `114-122` 的 `Parādhippāyaṃ deti`（译"超过对方的期望"，保留了"对方"）自相矛盾。
  - 建议：被解释词改为"**超过所期望的**"或与本文层一致的译法，释文保留"超出心愿，所得之果比心愿更多"。需与本文层经文译法比对后定稿。

- `100-1325-44-53`｜义理或用词与注释书不符｜片段「才分别叫作沙门和婆罗门」
  - 问题：原文 `samitapāpabāhitapāpatāhi samaṇabrāhmaṇatā veditabbā` 中 `-tāhi` 是具格复数，两项并列作原因，但原文并未以文字标明"息灭恶→沙门、排除恶→婆罗门"的一一对应；"分别"是译者补入的归属判断。另"才"字加入了原文没有的排他语气。
  - 建议：改为"这里应当知道，沙门与婆罗门之名，是依息灭了恶、排除了恶而说的"，分属关系若要点明则移入脚注。

### 🟨 warning
- `100-1325-14-19`｜关键词语意不明确｜片段「**亏损**，是说走向亏损」
  - 问题：被解释词与释文用同一个词"亏损"自我解释，读者得不到任何信息增量。原文 `chedagāminī hoti` → `chedaṃ gacchati` 是以同根动词换说法，汉译需要用不同措辞体现"趋向/导致"的过程义。
  - 建议：释文改为"是说走向折损"或"是说会导致本钱的损失"，与被解释词用词区分开。

- `100-1325-28-35`｜语言风格不统一｜片段「不符合他的心愿」
  - 问题：此处"他"的指代对象在本句内无着落——被解释词讲的是经商之事"达不到预期"，而"他"须回溯到经文中的商人。本段其余各句（`87-103` 起）均明确写出"对方"，此处孤立使用"他"造成指代不明确。
  - 建议：改为"是说不符合（经商者）自己的心愿"，或与下文统一的指代方案。

- `100-1325-2-13`｜整句逻辑表达不规范｜片段「**同样的**，是说与那一样的、与那相似的」
  - 问题："同样的，是说与那一样的"同义循环，与 `14-19` 同病；且 `taṃsadisā` / `taṃsarikkhakā` 两个近义词在汉语里只剩"一样的/相似的"的细微差别，连用后读者无法理解为何需要两说。
  - 建议：释文改为"是说与那些相同、与那些类似"，并考虑在"与那一样"后括注所指对象。

- `100-1325-28-35` / `100-1325-36-43` / `100-1325-87-103` / `100-1325-104-113` / `100-1325-114-122`｜语言风格不统一｜片段「心愿」「期望」

- `100-1325-54-70`｜语言表达不够流畅｜片段「——这样许约、这样邀请」

  - 建议：改为"——这就叫许约，也就是邀请"。

- `100-1325-114-122`｜语言表达不够流畅｜片段「给的时候却像倾倒一样，给了很多」

  - 建议：改为"给的时候却倾囊而出，给得很多"。

- `100-1324-2-4`｜不常用术语编写注释或者百科｜片段「《经商经》释义」

  - 建议：保留现译并附夹注"《经商经》（Vaṇijjasutta）"，译名在 `terms.md` 登记定案。
