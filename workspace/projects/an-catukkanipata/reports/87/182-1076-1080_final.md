## 理由

**基准资源缺失（直接压低信心）**：本次只注入了巴利原文与待评译文，**没有 nissaya，也没有本层所注释的父层（义注 Manorathapūraṇī）文本**。因此：
- 词级格/句法角色无法按 `(word_start, word_end)` 与 nissaya 对齐核对，格位判断只能依原文形态自行判定；
- 复注的硬约束「**被解释词与父层逐字同译**」（黑体引自义注）**本次无法验证**——`carato` / `ṭhitassa` / `jāgarassa` / `ātāpī` / `ottāpī` 等黑体词条是否与义注、本文译文用词一致，须在有义注译文时复核；
- 下列判定中凡与传统释义相关者（ottappa、bhaṅgamatta、anu anu、dutiyassa paṭhame）均为依巴利形态与常规注疏体例推断，若义注/nissaya 另有取义，以其为准。

**准确性**：整体忠实，复注特有的「词目＋释义」结构处理得当，`uppajjati ce` 与后续各句的 `ce` 串联关系（1077-33-55、1077-155-167）照顾到了，黑/白两分（1077–1078 对 1079–1080）的对称结构也完整保留。扣分集中在三处：一是 `anottāpī / ottāpī` 的词目译法与**紧接其后的释义自相矛盾**（释义说「对恶的畏惧」，词目却译成「怕受责备」），这是本批最实质的问题；二是 `Dutiyassa paṭhame` 的篇章定位译错（应为「第二品的第一经」，Caravagga 第一经即 AN 4.11，与段首「11.」吻合）；三是 1078-52-69 把 `yathā`（如何/如是）读成「哪些」，并补出原文没有的宾语「恶念」。

**风格**：完全符合「现代书面汉语」硬约束——未发现文言虚词、文言句式或单音节文言词，`knowledge/style.md` 第一节禁例表零命中。标点全为全角，引号统一用 “”，**译文中无 ASCII 引号、无任何工作标记（候选/待定/问号）**，JSON 安全。扣分在于：个别法相术语（彼分舍断 tadaṅgappahāna、镇伏舍断 vikkhambhanappahāna、正勤、白分）首次出现未按 style 规定夹注巴利原词；1080-2-32 单句逾 130 字，嵌套过深，对读者不友好。

**一致性**：核心词目跨段统一度高——`adhivāseti`「任它留住」、`vinodeti`「驱除」、`byantīkaroti`「彻底断除」、`anabhāvaṃ gameti`「让它归于消失」、`ātāpī`「有热忱」在黑白两分中前后一致，1077 与 1079/1080 的对照读起来成立。扣分点：`ottappa` 在释义里译「愧」、在词目里译「怕受责备」，同一概念两套说法；同一个固定搭配 `vuccati kathīyati` 在 1078-27-45 译「这样被说到」、在 1080-47-53 译「被说成」。

## 问题清单

### 🟧 error

- `182-1078-17-21`｜义理或用词与注释书不符｜片段「不怕受责备」
  - 问题：同句释义已把 `ottappa` 定义为 `pāputrāsalakkhaṇa`（以对恶的畏惧为特征），并已译出「愧（ottappa）」；词目却译成「不怕受责备」（畏惧他人责难），与自身释义相悖，读者会得到与注释相反的概念。
  - 建议：词目改为与释义同源的译法，如「**没有愧**」或「**无愧**」，使「词目—释义」闭合。

- `182-1080-33-39`｜义理或用词与注释书不符｜片段「怕受责备」
  - 问题：同上。前半句刚译「完全具足了对恶的畏惧」，词目却落在「怕受责备」，且与 1078-17-21 的「愧（ottappa）」不成对。
  - 建议：改为「**有愧**」，与 1078 的「没有愧」构成黑白两分的对称词目。

- `182-1077-2-14`｜错译（篇章定位）｜片段「第二集的第一经中」
  - 问题：`Dutiyassa paṭhame` 是省略式属格，所省之词按注疏体例为 `vaggassa`，即「第二品的第一经」；本段段首「11.」正对应四集第二品（Caravagga）的第一经 AN 4.11。译作「第二集」会被读作第二个五十经集（dutiyapaṇṇāsaka），定位错误。
  - 建议：改为「第二品的第一经中」。（若义注原文此处另有所指，请以义注为准后再定。）

- `182-1078-52-69`｜错误多译 / 错译｜片段「会生起哪些恶念」
  - 问题：`yathā … sambhavanti` 的 `yathā` 是「如何、以何方式」，不是「哪些」；原文 `sambhavanti` 无宾语，「恶念」是译者补出的，属多译。`bhāvitattā`（因已久修习）译成「由于长期如此」亦过松。
  - 建议：改为「为了指出〔那些寻〕如何因与它相应的人长期熏习而生起」，并把补出的成分限制在语义必须的范围内。

### 🟨 warning

- `182-1078-52-69`｜整句逻辑表达不规范｜片段「由于躺卧这种威仪特别属于懈怠的一边」
  - 问题：全句要解释的是「为什么经文不说『躺卧的人』而说『醒着的人』」，但译文只给出前因与「就说了」，中间的取舍关系没有落在字面上，读者无法看出结论从何而来。
  - 建议：把对比显化，如「……所以经文没有顺着『躺卧』说下去，而是说『对醒着的人』」。

- `182-1079-2-31`｜关键词语意不明确｜片段「长时间熏习过」
  - 问题：`cirakālabhāvitattā` 的受熏对象（即欲念等烦恼）在译文里完全缺位，「熏习过」成了无宾语的悬空动词，可能被误读为「长期修习善法」——与上下文正相反。
  - 建议：补出对象，如「由于这些〔烦恼〕在无始的轮回中已被长期熏习」。

- `182-1080-47-53`｜整句逻辑表达不规范｜片段「也就是被说成，是把心导向涅槃的人」
  - 问题：原文是「被称为『把心遣向涅槃者』」，被称者为上句的 `pahitatto`；译文把词目「被称为」提到句首、释义拆成两截，主谓关系断裂，读者看不出「谁被称为什么」。
  - 建议：按「〔全心投入〕就是『把心导向涅槃的人』——这就是『**被称为**』的意思」之类顺序重排。

- `182-1077-125-143`｜关键词语意不明确，或二意场合没有注释｜片段「哪怕只剩一点碎片也不留」
  - 问题：`bhaṅgamatta` 有二解——日常义「仅一点碎片」与阿毗达摩义「仅坏灭（刹那）分」。译文取前解且未加注，二意场合无提示。
  - 建议：保留现译但加脚注说明另一解；若 nissaya 或义注取坏灭义，则改译并相应调整 1079-58-76 的平行句。

- `182-1077-144-154`｜关键词语意不明确｜片段「也就是不使它一点一点地归于不存在」
  - 问题：复注用 `anu anu abhāvaṃ` 拆解 `anabhāvaṃ`，`anu anu` 是「随…随…／彻底地」的重叠式，并不必然含「渐进、一点一点」之义；「一点一点地」给读者加入了原文未必有的渐次色彩。同一问题见 `182-1079-83-100`。
  - 建议：改为「使它随起随灭地归于不存在」或「使它彻底归于不存在」，两处统一。

- `182-1077-104-116`｜不导致误解的汉语语病｜片段「不把它从自己的心的相续中推开」
  - 问题：「自己的心的相续」连用两个「的」，读来拗口。
  - 建议：改为「自己的心相续」或「自心的相续」。

### 🟦 suggestion

- `182-1077-97-103`｜该使用而没有使用术语标记｜片段「不以彼分舍断等方式把它放下」
  - 问题：「彼分舍断」是法相术语且在本批首次出现，按 `style.md` 应夹注巴利原词；`182-1079-83-100`「以镇伏舍断的方式」同样缺注。
  - 建议：首次出现处作「彼分舍断（tadaṅgappahāna）」「镇伏舍断（vikkhambhanappahāna）」，其后只用汉译。

- `182-1078-9-16`｜语言风格不统一 / 词义偏强｜片段「能烧尽烦恼的精进」
  - 问题：`ātāpana` 是「炙燃、烧灼」，强调令烦恼受热逼迫，不等于「烧尽」（使之灭尽）；「烧尽」把结果写进了特征。`182-1080-2-32`「以烧尽烦恼为特征的精进」同。
  - 建议：两处统一改为「炙燃烦恼」或「烧灼烦恼」。

- `182-1079-2-31`｜语言风格不统一 / 术语｜片段「在光明分方面」
  - 问题：`sukkapakkha` 的习用汉译是「白分／净分」，与前文的 `kaṇhapakkha`（黑分）成对；「光明分」非惯例，且前面黑分一侧未加对应标示，对称性丢失。
  - 建议：改为「在白分（sukkapakkha）方面」，并考虑在 1077 开头相应点出黑分一侧。

- `182-1078-27-45`｜语言风格不统一｜片段「也就是这样被说到」
  - 问题：同一固定搭配 `vuccati kathīyati` 此处译「这样被说到」，`182-1080-47-53` 译「被说成」；且「被说到」在汉语里意为「被提及」，与 `kathīyati`（被这样说、被称说）不合。
  - 建议：统一为「也就是这样被称说」。

- `182-1078-27-45`｜语言表达不够流畅｜片段「由于在善法上退失」
  - 问题：`parihāpayitvā` 是使役式，主语令善法衰减；译文把主语变成了自身「退失」，施受关系略偏。
  - 建议：改为「由于使善法衰减」。

- `182-1080-2-32`｜复杂的嵌套句整句语言逻辑理解困难｜片段「并且由于那种心地上的成就以及由它引起的修行上的成就」
  - 问题：全句一逗到底逾一百三十字，串起「不任留住→心地清净→两重成就→戒清净／守根门／知食量／念正知／勤警醒→具足精进→有热忱」七层，读者难以把末端的「所以是**有热忱**的人」接回句首。
  - 建议：在「修行上的成就」后断句，分成两到三句，末句单独收「……所以是**有热忱**的人」。

- `182-1077-2-14`｜语言表达不够流畅｜片段「对正在行走的人」
  - 问题：`carato` 是属格（寻生起的所属者），「对……的人」读作与事，易被理解为「对别人做什么」；`182-1078-46-51`「对站立的人」、`182-1078-52-69`「对醒着的人」同一句式。
  - 建议：三处统一为「（在）正在行走的人〔心中〕」一类表述，或加一句总说明该属格的用法，以免整组词目都偏。

- `182-1077-155-167`｜不常用术语编写注释｜片段「把“如果”这个词配上去」
  - 问题：`ce-saddaṃ` 指巴利小词 `ce` 本身；译成「“如果”这个词」后，读者无法知道被配上去的是原文虚词。
  - 建议：作「把“如果”（ce）这个词配上去」。

- `182-1077-104-116`｜语言风格不统一（格式）｜片段「驱除它」
  - 问题：原文把 `na` 与动词分作两处黑体，译文用零宽空格隔开两段加粗（「不」＋「驱除它」），与 `182-1079-58-76` 合并为单段加粗的做法不一致，不同渲染环境下可能出现可见的异常间隙。
  - 建议：同一组对照句（1077 与 1079/1080）采用同一种加粗切分方式。
