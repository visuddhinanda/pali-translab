# Review — 87:989-1000（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

本 chunk 中，瓶经（§989–994）与水池经（§995–1000）是同一套句式，但两经的译法明显各自为政，应统一。

- **经号格式**：§990 译“一〇三、”，§996 译“104、” → 统一为一种，建议“一〇三、”“一〇四、”。
- **经末标记** Tatiyaṃ / Catutthaṃ：§994 译“第三经。”，§1000 译“第四。” → 统一为“第三经。”“第四经。”。
- **abhikkantaṃ paṭikkantaṃ**：§991/992/993/994 译“前行、返回”，§997/998/999/1000 译“前进、后退” → 建议统一为“前进、后退”。
  - 依据：nissaya `အဘိက္ကန္တံ= ရှေ့သို့ သွားခြင်း`（向前走）、`ပဋိက္ကန္တံ= နောက်သို့ပြန်လှည့်လာခြင်း`（向后转回来）。
- **samiñjitaṃ pasāritaṃ**：§991–994 译“弯曲、伸展”，§997–1000 译“屈伸肢体” → 建议统一为“屈伸肢体”。
  - 依据：nissaya 补出了宾语 `လက်ခြေစသည်တို့ကို ကွေး／ဆန့်တန်း`（弯曲／伸展手脚等），“弯曲、伸展”漏了这个隐含宾语。
- **saṅghāṭipattacīvaradhāraṇaṃ**：§991–994 译“持僧伽梨、钵和衣”，§997–1000 译“持用僧伽梨、钵和袈裟” → 统一为一种，建议“持用僧伽梨、钵和袈裟”。
  - 依据：nissaya `ကိုင်ဆောင်ဝတ်ရုံခြင်း`（拿着、穿披），“持用”比“持”更贴近。
- **pāsādikaṃ**：§991–994 译“端正好看”，§997–1000 译“端正可喜” → 必须统一。
  - 依据：nissaya `ကြည်ညိုမှုကို ဖြစ်စေနိုင်သည်`（能引生净信），`ဝါ= ကြည်ညိုဖွယ်ကောင်းသည်`（令人敬信）。两个译法都偏向外表好看，没有译出“令人生信”这层意思。
  - 建议统一为“庄严，令人生起净信”或“令人敬信”。
- **pajānāti / nappajānāti**：§991/993 译“不能如实地了知”，§992/994 译“能如实地了知”，§997–1000 译“（不）如实了知” → 统一为“（不）如实了知”。
  - 原文是直陈动词，不带“能／不能”的意思。
  - nissaya 在 §991-49-59 的补注作 `ထိုးထွင်းမသိခြင်း`（不透彻了知），也没有能力义。
- **So 的承接词**：§991/992 用“但是他”，§993/994 用“而且他”，§997–1000 只用“他” → 统一处理。
  - 原文只有 so，没有转折或递进的连词。建议一律译“他”，或四种人统一用同一个承接词。
- **内层引号**：§991–994 的内层用 ‘这是苦’，嵌套正确；§997–1000 的内层用 “这是苦”，与段首的外层 “ 重复，嵌套错误 → §997/998/999/1000 改为 ‘这是苦’ ‘这是通向苦灭的道路’。
- **Evaṃ kho … puggalo … hoti**：§991–994 译“这样一个人就是……”，§997–1000 译“这样的人就是……” → 统一为“比丘们，一个人就是这样成为……的”。
  - 依据：nissaya `ဧဝံ= ဤသို့ဤပုံအားဖြင့်`（以这种方式）。evaṃ 是方式状语，修饰 hoti，不是修饰 puggalo 的定语。“这样的人”把它读成了定语（详见 §997、§998、§999 条目）。
- **tathūpamāhaṃ … vadāmi**：§991–994 译“我说这个人就像那个瓶一样”，§997–1000 译“我说这个人就与它相似” → 两经统一句式，建议都采用“我说这个人就像那个瓶／那个水池一样”。
  - 依据：nissaya `တထူပမံ= ထိုရေအိုးဥပမာ ရှိ၏ဟူ၍`（说他以那个水瓶为喻）。
- **ime … cattāro kumbhā / udakarahadā**：§990 译“这些就是四种瓶”，§996 译“这就是四种水池” → 统一为“这些就是”。
  - 依据：ime 是复数。
- **结句 Ime kho … santo saṃvijjamānā lokasmiṃ**：§994 译“这些就是在世间确实存在着的四种像瓶一样的人”，§1000 译“世间确实有的，就是这四种像水池一样的人” → §1000 改用与 §994 相同的句式，后者语序拗口。
- **起首句 Evamevaṃ kho, bhikkhave**：§990 译“比丘们，同样地，在世间确实存在着”，§996 译“同样地，比丘们，世间确实有这样四种” → 呼格位置和谓语统一，建议都译“比丘们，同样地，世间确实存在着四种……”。
- **“空的而盖着的”这一类结构**：两经都用了“……的而……的”，属于翻译腔 → 建议改为“空而盖着的”“满而敞着的”；水池经的“浅而看起来深的”保持不变即可。

## §990 句 87-990-2-13
- **问题**：取义（非必改）— nissaya `ကုမ္ဘာ= ရေအိုးတို့သည်`，指的是“水罐、水瓶”。单译“瓶”容易让读者联想到细颈小瓶，和“盛满水、盖上盖子”的比喻不够贴合。
- **建议**：可考虑改为“水罐”。如果采用，全 chunk 的“瓶”要一并替换。

## §990 句 87-990-17-36
- **问题**：词义细节 — nissaya `တုစ္ဆော= အတွင်း၌ အချည်းနှီးသည်`（里面是空的）、`ပူရော= အတွင်း၌ ရေဖြင့်ပြည့်နေသည်`（里面盛满了水）。这里明确是“里面”空或满，与“外面”盖着或敞着形成对比，而这一内外对比正是全经比喻的关键。
- **建议**：可以保留“空／满”，但要按跨段一致性一节去掉“的而”。如需点明内外对比，可译成“里面空而盖着的”等形式（非必改）。

## §990 句 87-990-60-71
- **问题**：补出成分 — nissaya 在每一项后都补出了 `(ပုဂ္ဂလော= ရေအိုးနှင့်တူသော ပုဂ္ဂိုလ်)`（像水瓶的人）。这里列举的是人，不是瓶，但译文和上面列举瓶的那句一字不差，读者分不出所指。
- **建议**：改为“空而盖着的人、满而敞着的人、空而敞着的人、满而盖着的人”，或在句末补“……这四种人”。

## §991 句 87-991-13-28
- **问题**：格与句法、补出成分 — nissaya `ပုဂ္ဂလဿ= ပုဂ္ဂိုလ်၏`（属格）：这些动作是“某些人的”，pāsādikaṃ 是它们的表语，译文结构正确。但 samiñjitaṃ／pasāritaṃ 漏了 nissaya 补出的宾语“手脚等”，pāsādikaṃ 的“令人生信”义也没有译出（见跨段一致性一节）。“都很”在原文中没有对应。
- **建议**：改为“比丘们，在这里，有的人前进、后退、向前看、向两旁看、屈伸肢体、持用僧伽梨、钵和袈裟，都令人生起净信。”

## §991 句 87-991-49-59
- **问题**：格与句法 — nissaya `ဧဝံ= ဤသို့ဤပုံအားဖြင့်`，补注是“仅有可敬的威仪，却不透彻了知四谛”。evaṃ 是方式状语，表示“以这种方式”成为空而盖着的人。“这样一个人”容易被读成“这样的一个人”。
- **建议**：改为“比丘们，一个人就是这样空而盖着的。”

## §992 句 87-992-14-30
- **问题**：同 §991-13-28 — 动作缺宾语，pāsādikaṃ 取义偏差。否定句应与 nissaya 的 `ပါသာဒိကံ … န ဟောတိ= မဖြစ်` 对应，即“不令人生信”。
- **建议**：改为“……持用僧伽梨、钵和袈裟，都不令人生起净信。”

## §992 句 87-992-51-60
- **问题**：格与句法 — 同 §991-49-59，evaṃ 是方式状语。
- **建议**：改为“比丘们，一个人就是这样满而敞着的。”

## §993 句 87-993-50-59
- **问题**：格与句法 — 同 §991-49-59。
- **建议**：改为“比丘们，一个人就是这样空而敞着的。”

## §994 句 87-994-2-12
- **问题**：数据对齐 — 本句是 Kathañca 问句，但挂在这里的 nissaya 内容是 `ဧဝံ= ဖြင့်…ဟောတိ= ၏`，实际属于本段后面的 Evaṃ 结句（87-994-51-60）。译文本身没有问题，只是这一行 nissaya 错位，不能作为本句的词级依据。
- **建议**：译文不需要改。nissaya 错位的情况请记入数据问题。

## §996 句 87-996-2-13
- **问题**：格式 — 经号写作“104、”，与 §990 的“一〇三、”不一致。
- **建议**：改为“一〇四、”。

## §996 句 87-996-17-36
- **问题**：词义与数 — nissaya `ဂမ္ဘီရောဘာသော= နက်ယောင် ထင်ရသော`，其中 ယောင် 表示“看似、显得”，“看起来深”可以接受。句末 ime 是复数，“这就是”应改为“这些就是”。
- **建议**：改为“……比丘们，这些就是四种水池。”

## §996 句 87-996-37-55
- **问题**：补出成分 — 前面已经有 evamevaṃ（“同样地”），原文没有“这样”的对应词。呼格的位置也和 §990 不一致。
- **建议**：改为“比丘们，同样地，世间确实存在着四种像水池一样的人。”

## §996 句 87-996-59-71
- **问题**：补出成分 — nissaya 补出了 `(ပုဂ္ဂလော= ရေအိုင်နှင့်တူသော ပုဂ္ဂိုလ်)`（像水池的人），但译文和上面列举水池的那句完全一样，读者分不出这里说的是人。
- **建议**：每一项后补“的人”，或在句末补“这四种人”，与 §990-60-71 同样处理。

## §997 句 87-997-49-58
- **问题**：格与句法 — nissaya `ဧဝံ= ဤသို့ ဤပုံအားဖြင့်`，补注是“仅具威仪，却不透彻了知四谛”。“这样的人”把方式状语 evaṃ 误读成了 puggalo 的定语。
- **建议**：改为“比丘们，一个人就是这样浅而看起来深的。”

## §997 句 87-997-68-75
- **问题**：句式一致 — nissaya `တထူပမံ= ထိုရေအိုင် ဥပမာရှိ၏ဟူ၍`（说他以那个水池为喻）。“就与它相似”中的“它”指代不明确，句式也与瓶经不统一。
- **建议**：改为“比丘们，我说这个人就像那个水池一样。”§998、§999、§1000 的同一句也照此统一。

## §998 句 87-998-52-61
- **问题**：格与句法 — 同 §997-49-58，evaṃ 是方式状语。
- **建议**：改为“比丘们，一个人就是这样深而看起来浅的。”

## §998 句 87-998-71-78
- **问题**：同 §997-68-75。

## §999 句 87-999-70-77

- **建议**：改为“比丘们，我说这个人就像那个水池一样。”
