## 问题清单

### 🟧 error
- `100-1298-2-15`｜错误多译｜片段「**并在将来招致痛苦的增长**」
  - 问题：被解释词黑体部分应只对应巴利原文词 `dukhudrayaṃ`（招致痛苦的／带来痛苦的）。译文把释义里的 `āyatiṃ`（将来）与连词 `ca` 一并写入黑体，使黑体标注不再是本文原词的逐字对译，随后的释义"并且在未来带来痛苦的增长"与之几乎完全重复，注释结构被抹平。按三层逐字同译的硬约束，黑体须与本文该词的译法一致。
  - 注：此条实际落在句 `100-1298-21-25`，黑体与释义重复为同一问题，见下条。
  - 建议：黑体改为只覆盖 `dukhudraya` 本身的译法，`将来`与`并且`留在释义里。

- `100-1298-21-25`｜错误多译｜片段「**并在将来招致痛苦的增长**这句是说：并且在未来带来痛苦的增长」
  - 问题：黑体被解释词与其后的释义内容重叠度近 100%，读起来像同一句说了两遍。`āyatiñca` 属释义方才补出的成分，不应前置进被解释词；另外同一个 `āyatiṃ`／`dukkhavaḍḍhi` 在黑体与释义中分别译作"将来／痛苦的增长"与"未来／痛苦的增长"，同词异译。
  - 建议：黑体收窄为本文原词对应的译法（如"招致痛苦的"），释义保留"并且在未来带来痛苦的增长"；"将来/未来"二者择一统一。

- `100-1298-2-15`｜错译（修饰关系）｜片段「**由痴而生的**、**那些没有智慧的人**这句是说：也是由痴而生的」
  - 问题：注释 `mohajaṃ cāpi aviddasū apaṇḍitā` 的拆读是：`cāpaviddasū` = `ca + api + aviddasū`，故 `cāpi`（也／而且）本属第二个被解释词的前半，注释正是借 `mohajaṃ cāpi` 交代连词归属，再以 `apaṇḍitā` 释 `aviddasū`。译文把"也是"挂在"由痴而生"上，使读者以为注释在补释第一个词 `mohajaṃ`，连词的归属与拆读顺序被倒置。
  - 建议：释义改为先交代 `mohajaṃ` 与连词的连读（如"由痴而生的，而且……"），再接"没有智慧的人就是不具智慧的愚人"，使拆读顺序与原注一致。

### 🟨 warning
- `100-1298-30-43`｜代词指代不明确｜片段「他们的自性就正是那样」
  - 问题：黑体标注里出现"他们"，但该词在本文偈颂中对应的是前文的 `acakkhukā`（无慧眼者），而黑体部分 `yathā dhammā tathā santā` 原文并无显性人称代词。黑体内自行补出"他们"，既违"不擅自补足省略主语"，又使指代对象悬空；下句释义用"那些人"，两处称代不一。
  - 建议：黑体去掉"他们的"，改为对 `tathā santā`（即如此存在着）的直译；人称留到释义里由"那些人"承担，或统一为同一称代词。

- `100-1298-30-43`｜不导致误解的汉语语病｜片段「贪等诸法怎样存在着，那些人就正是具有那样的自性」
  - 问题：黑体句用"是怎样存在的……就正是那样"，紧接的释义又说"怎样存在着……就正是具有那样的自性"，两句句式与用词高度重合，"正是"连用两次，句子冗赘；`sabhāvāva hutvā` 的 `-va`（正／即）强调语气在两处都用"正是"表达，重复。
  - 建议：释义部分换一种表述（如"就保持着那样的本性"），避免与黑体句同形复述。

- `100-1298-59-64`｜关键词语意不明确｜片段「所说的也都只是流转（vaṭṭa，即世间轮回）」
  - 问题：`vaṭṭa` 在注释书里与 `vivaṭṭa`（还灭／出世间）成对，此处 `vaṭṭameva kathitaṃ` 的要点是"只讲了流转（而未讲还灭）"。夹注只给"即世间轮回"，未点出这组对举，一般读者读不出"只"字的分量。`style.md` 要求二意或关键术语场合给注释，此处注释偏薄。
  - 建议：夹注扩为点明与"还灭"对举的含义，或把说明放进脚注。

### 🟦 suggestion
- `100-1298-26-29`｜语言风格不统一｜片段「缺少智慧的眼睛」
  - 问题：`paññācakkhurahitā` 释义译作"智慧的眼睛"，与同段黑体的"慧眼"不同形；而"智慧"一词在上一句又用于译 `aviddasū/apaṇḍitā`（`paññā` 之外的另一组词），一词多职，读者难以回推巴利对应词。
  - 建议：此处释义统一用"慧眼（paññācakkhu）"或"智慧之眼"，并与 `aviddasū` 句的"智慧"做区分（如后者改为"明智／有智之人"）。

- `100-1298-44-58`｜语言表达不够流畅｜片段「他们不认为"我们就是这样存在的、就是这样的自性"，意思就是他们不这样想」
  - 问题：`na maññantīti attho` 是注释固定收束语（"意思是……"），译文已先完整译出引语句，再补"意思就是他们不这样想"，在汉语里成了同义重复。虽忠实于原注的两段式，但读者会觉得啰嗦。
  - 建议：保留注释结构的同时压缩收束句（如"意思就是不作此想"），或把前句引语收紧。

- `100-1297-2-4`｜该使用而没有使用术语标记｜片段「6、有贪经的注释」
  - 问题：`Sarāgasutta` 为经名，首次出现未附巴利原词；`vaṇṇanā` 译"注释"妥当，但全篇"注释"兼指注释书与动词义，经名无原词时读者无法定位该经。
  - 建议：首次出现处附巴利经名，如"有贪经（Sarāgasutta）的注释"。
