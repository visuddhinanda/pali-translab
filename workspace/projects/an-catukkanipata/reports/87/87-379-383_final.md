## 理由

**基准缺失（影响信心）**：本次只注入了巴利原文与待评译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。按方法文档应「义注定释义、nissaya 定词法」，此处只能以巴利原文、常规注释传统（AN-a 对 `ariya ñāya` = 圣道、`vitakkapatha` = 寻之范围的通解）和汉译惯例作判断，词级覆盖与格/句法角色无法逐词核对。故信心压到 70；准确性结论中凡依赖注释书取义的条目已在清单里注明依据来源。

**准确性**：全篇骨架准确——人物（摩揭陀大臣婆罗门 / 世尊）、四法的列举与应答结构、`neva … anumodāmi na paṭikkosāmi` 的双否定、`nikāmalābhī akicchalābhī akasiralābhī` 三项并列、`sayaṃ abhiññā sacchikatvā upasampajja viharati` 的套语都译到位，无漏句、无主谓宾错判、无违教理之处，因此无 fatal。扣分集中在一处**反复出现的错译**：`ākaṅkhati vitakketuṃ` 译作「想起」。现代汉语「想起」= 回忆，而原文是「想要生起（寻）」，否定式「不想起哪个寻」更会被读成「没回忆起」，属导致误解的表达，且在三句中重复（382-49-66、382-67-83、383-62-97），是本段最该改的问题。其次 `vitakkapathe` 的 `patha` 未译出，`tatrupāyāya` 多出「随时」、`yadidaṃ` 扩写为「说的都是这同一件事」属无据增译，`bhagavatā saddhiṃ sammodi` 的互相性被译成单向。

**风格**：主体是现代书面汉语，禁例表里的文言腔（此中／彼等／故为／即证／答以）基本没有，`sati`/`vitakka`/`saṅkappa`/`ariya ñāya` 首次夹注巴利原词、其后只用汉译，符合 style.md 第二、三节。残留两处单音节文言虚词用法「他于寻得心的自在」，且该句「于寻得」连读易生歧义，是风格扣分的主要来源。标点全用全角，译文内无 ASCII 引号，无候选／待定等工作标记，符合 JSON 安全与第七节约束。

**一致性**：跨五段的人名（瓦萨卡罗／乔达摩先生）、术语（寻／思／增上心／现法／漏／心解脱·慧解脱）、四法套语（「具备这四种品质的人称为大智慧的大人物」）、382 与 383 的平行句式都严格对齐，重复段落措辞统一，harmonize 的效果明显。仅「品质」对 `dhamma` 的处理使术语性丢失，属取舍而非不一致。

## 问题清单

### 🟧 error
- `87-382-49-66`｜错译（词义）／导致误解的表达｜片段「他想起哪个寻（vitakka），就起那个寻」
  - 问题：`ākaṅkhati vitakketuṃ` 是「希望／想要生起（寻）」，译作「想起」在现代汉语中义为「回忆起」，整句被读成「他回忆起哪个寻就起那个寻」；否定式「不想起哪个寻」误解更深。
  - 建议：改为「他想要生起哪个寻，就生起那个寻；不想生起哪个寻，就不生起那个寻」。
- `87-382-67-83`｜错译（词义）／导致误解的表达｜片段「想起哪个思（saṅkappa），就起那个思」
  - 问题：同上，`ākaṅkhati saṅkappetuṃ` = 想要生起（思）。
  - 建议：改为「想要生起哪个思，就生起那个思；不想生起哪个思，就不生起那个思」。
- `87-383-62-97`｜错译（词义）／导致误解的表达｜片段「因为乔达摩先生想起哪个寻，就起那个寻」
  - 问题：同上，婆罗门复述句沿用了同一误译，四处寻／思皆同病。
  - 建议：与 382-49-66、382-67-83 一并改为「想要生起…就生起…」，保持三句同改。

### 🟨 warning
- `87-382-84-88`｜文言语体／关键词语意不明确｜片段「这样，他于寻得心的自在。」
  - 问题：一是「于」作单音节文言虚词，违 style.md 第一节总原则；二是「他于寻得心的自在」中「于寻得」连读极易误断为动词「寻得」；三是 `vitakkapatha` 的 `patha`（寻的范围／领域）未译出。
  - 建议：改为「这样，他在寻的范围内获得了心的自在。」
- `87-383-98-102`｜文言语体／关键词语意不明确｜片段「因为乔达摩先生于寻得心的自在。」
  - 问题：同上，同句式在婆罗门复述处重复。
  - 建议：改为「因为乔达摩先生在寻的范围内获得了心的自在。」
- `87-381-53-80`｜错误多译｜片段「随事随时都能想出办法的审察力」
  - 问题：`tatrupāyāya vīmaṃsāya samannāgato` = 具备「针对该事的方法之审察」，原文无时间义，「随时」系无据增译。
  - 建议：改为「具备能针对这些事想出办法的审察力」。
- `87-382-39-48`｜错误多译／整句逻辑表达不规范｜片段「说的都是这同一件事」
  - 问题：`yadidaṃ` 只是「即／也就是」，把两个并列语的同指关系扩写成一句解释性断言，属把译注写进正文；另「使许多人在圣道上安立」搭配生硬（`patiṭṭhāpitā` 宜「安立于…」）。
  - 建议：改为「他把许多人安立于圣道（ariya ñāya），也就是安立于善美之法性、善法性。」
- `87-383-40-61`｜错误多译｜片段「说的都是这同一件事」
  - 问题：同上，复述句沿用同一增译。
  - 建议：与 382-39-48 同改。
- `87-380-23-27`｜不导致误解的汉语语病（互相性丢失）｜片段「向世尊致意问候」
  - 问题：`bhagavatā saddhiṃ sammodi` 是「与世尊互相问候」，译成单向的「向世尊致意」；下一句又作「互致了…」，前后对同一动作的处理不齐。
  - 建议：改为「来到之后，与世尊互相问候。」
- `87-380-28-34`｜用字不规范｜片段「值得记念」
  - 问题：现代规范写法为「纪念」；且 `sāraṇīya` 在此指「值得回味／令人难忘」，用「纪念」亦不贴切。
  - 建议：改为「值得回味的问候话语」。
- `87-381-21-38`｜关键词语意不明确｜片段「在这里，他博学多闻」
  - 问题：`idha` 是「就这一点来说／这样的人」的引出语，直译「在这里」在紧接「住在王舍城竹林」之后会被读成地点。
  - 建议：改为「乔达摩先生，这样的人博学多闻…」或删去「在这里」。
- `87-382-30-38`｜关键词语意不明确｜片段「婆罗门，在这里，他为了众多人的利益」
  - 问题：同上，世尊应答句中的 `idha` 同病。
  - 建议：改为「婆罗门，这样的人为了众多人的利益…」。
