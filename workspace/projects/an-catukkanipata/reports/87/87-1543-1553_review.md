# Review — 87:1543-1553（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）
> 注：本 chunk 的 nissaya 单元常挂在后一句上、内容却覆盖前一句（如 1544-23-29 的 nissaya 实为 14-22 的释义，1546-13-17 含 2-12，1553-27-31 含 17-26）。下文按 nissaya 内容对应到句子，不按挂载行。

## 跨段一致性

- **kāya / vācā / manas（身语意）**：§1545「在身体上…在言语上…在心意上」，§1549–1551「身的造作／语的造作／意的造作」，§1553「以身体为界限」「用身触到」。nissaya 在 §1545 与 §1549–1551 一律释为 `ကာယဒွါရ / ဝစီဒွါရ / မနောဒွါရ`（身门／语门／意门），说明两处指的是同一组概念。→ 建议统一为「身／语／意」，§1545 改为「在身、语、意上有防护」。§1553 的 kāyapariyantika 属另一用法，可保留「身体」。
- **avijjāvirāgā vijjuppādā 的句法归属**：§1545（2-17）把它译成防护的原因，即「由于无明的灭尽、明的生起，他…有防护」。§1552（2-24）则译成诸漏不生的原因，与 nissaya 一致。两处结构前后矛盾，§1545 的问题详见下文。§1547-34-47 是复述，改动时要同步。
- **antarākathā**：§1545-71-83 与 §1547-103-116 译作「还没有谈完的谈话」，§1547-13-22 却译作「你们**中间**那场还没有谈完的谈话」。nissaya 把 `အန္တရာ` 释为「世尊到来之前的中途时段」，是时间义，不是「你们之间」。→ §1547-13-22 去掉「中间」，统一为「（刚才）还没有谈完的谈话」。
- **No hetaṃ, bhante**：§1549–1552 四处都译作「大德，这是没有的」，修改时四处同步（理由见 §1549 句 87-1549-84-92）。
- **ettha（§1548）**：11-35 和 57-79 译作「就在这里」，36-56 和 92-99 译作「在这件事上」。nissaya 前两处释为「在这句（没弄懂的）话上」（`ဤစကား၌`），后两处释为「在这个问题上」（`ဤပြဿနာ၌`），所以前两处的「在这里」应改，见下文。
- **「灭除之道」**：§1549–1552 的 sandiṭṭhikā nijjarā 句都用了文言「之」，四处同步修改，见 §1549 句 87-1549-25-65。

## §1545 句 87-1545-2-17
- **问题**：句法误读 — nissaya 在本句只释出 `kāyena saṃvuto … manasā saṃvuto … assa`（这个人在身、语、意上有防护）。`avijjāvirāgā = အဝိဇ္ဇာ၏ ကုန်ခန်းပျက်စီးခြင်းကြောင့်`、`vijjuppādā = မဂ်ဉာဏ် ဝိဇ္ဇာ၏ဖြစ်ခြင်းကြောင့်` 两项被放进下一句，补出主语 `(tassa purisassa santāne)`，与「你还看得到那个原因吗」连读。nissaya 括注的总结是：「在防护身门等的人的心相续中，由于无明灭尽、道智之明生起，你还看得到他来世生起烦恼诸漏的原因吗」。可见「无明灭尽、明生起」描述的是这个人的状态，作为发问的前提，不是他得到防护的原因。译文译成「由于…，他…有防护」，因果关系颠倒了。
- **建议**：本句只译防护部分，例如「瓦帕，假设这里有一个人，在身、语、意上都有防护，他的无明已经灭尽，明已经生起。」不再把它写成防护的原因。§1547-34-47 同步修改。

## §1545 句 87-1545-18-42
- **问题**：补出成分 — nissaya 的总结句用的是 `မြင်ရသေးသလော`（还看得到吗），带「还」的语气。译文「你看得到那个原因吗」少了这层意思。
- **建议**：改为「瓦帕，你还看得到那个原因吗——…」。下文 §1547-48-64、§1549–1552 的同句一并统一。

## §1545 句 87-1545-52-60
- **问题**：主语与修饰关系 — nissaya 为 `(yassa purisassa santāne) … yaṃ pāpakammaṃ … assa`，主语是恶业，人只是属格或处所。`avipakkavipākaṃ = မရင့်ကျက်သေးသော အကျိုးရှိသော / အကျိုးပေးခွင့်မရသေးသော`，修饰的是业：其果报还没有成熟、还没有得到起作用的机会。译文「而还没有到受报的时候」把它写成了人的状态。
- **建议**：改为「大德，假设这里有一个人，他从前造下的恶业，果报还没有成熟。」

## §1547 句 87-1547-13-22
- **问题**：误读 antarā — 见跨段一致性一节。nissaya 的 `အန္တရာ = မြတ်စွာဘုရား ကြွလာတော်မမူမီ အကြားကာလ၌` 是「世尊到来之前的中途」。
- **建议**：改为「你们刚才还没有谈完的谈话又是什么呢？」

## §1548 句 87-1548-11-35
- **问题**：
  1. 指代不清 — `ettha = ဤစကား၌（ဤမသိနားမလည်အပ်သေးသောအနက် အဓိပ္ပါယ်ရှိသော စကား၌）`，指那句没弄懂的话，不是地点。译文「就在这里」容易被读成场所。
  2. 漏强调 — `mameva = ငါ့ကိုပင်လျှင်`（就问我本人），译文漏了 eva。
- **建议**：改为「…就这句话进一步反问我本人——」。

## §1548 句 87-1548-57-79
- **问题**：同上 — `ettha = ဤစကား၌`；`bhagavantaṃyeva = မြတ်စွာဘုရားကိုပင်လျှင်`，漏了 eva。
- **建议**：改为「…我就这句话进一步反问世尊本人——」。

## §1549 句 87-1549-2-24
- **问题**：
  1. 补出成分 — `evaṃsa = evaṃ + assa`，nissaya 释 `assa = ထိုပုဂ္ဂိုလ်၏ (သန္တာနေ)`（在这个人的心相续中）、`evaṃ = ဤသို့သော`（这样的）。译文把 assa 并进「对于已经远离…的人来说」，可以接受；但「这些漏」没有译出 evaṃ（这样的）。
  2. 词义 — `kāyasamārambha = ကာယဒွါရဖြင့် အားထုတ်အပ်သော ကာယကံ`，即经由身门发动的身业。「身的造作」意思不够明确。
- **建议**：可改为「以身门所造的业为缘」或「以身的造作（身业）为缘」，§1550、§1551 的「语／意」同步修改。

## §1549 句 87-1549-25-65
- **问题**：
  1. 文言（必改）— 「灭除之道」用了文言「之」。
  2. 词义（opaneyyikā）— nissaya 释为 `မိမိစိတ်မှာ, မကွာစွဲအောင်, ဆွဲကပ်ဆောင်လင့် ဖြစ်စေသင့်သော`（应当引入自己心中、使它紧贴不离）。译文「能够导向涅槃」与 nissaya 的取义不同。
  3. 词义（akālikā）— nissaya 释为 `အချိန်ကာလကြာမြင့်မှ…ပြုတတ်သည် မဟုတ်သော / ယခုချက်ချင်း…ပြုတတ်သော`（不需要很长时间才起作用，当下立即起作用）。译文「不受时间限制」偏离了「即时」义。
  4. 补出成分 — nissaya 补出 `(tassa)`（对他来说），并把 `nijjarā` 释为「使烦恼朽坏消亡的（阿罗汉道之行）」。译文「这是…」的主语悬空。
- **建议**：例如「对他来说，这是当下可见、即时生效、值得邀人来看、应当引入自心、智者各自亲身体证的消磨（烦恼）之路。」其中「之路」也要换成「的道路」，避免「之」。§1550–1552 的同句同步修改。

## §1549 句 87-1549-84-92
- **问题**：句法 — `etaṃ = ဤသို့မြင်ခြင်းသည်`（这样的看见）、`no hi = မဖြစ်နိုင်ပါ`（不可能）。被否定的是「看得到原因」这件事。译文「这是没有的」主语不明，像是在说原因不存在。
- **建议**：改为「大德，我看不到。」或「不，大德，看不到。」§1550–1552 同步修改。

## §1552 句 87-1552-2-24
- **问题**：补出成分 — `assa = ထိုပုဂ္ဂိုလ်မှာ`（在这个人身上），译文没有译出；同时 `evaṃ`（这样的）也漏了。
- **建议**：改为「…由于无明灭尽、明生起，在这个人身上，这样的漏、苦与热恼就不会有了。」

## §1553 句 87-1553-2-16
- **问题**：词义 — nissaya 释 `evaṃ = ဤနည်းအားဖြင့်`（按照上面「瓦帕，你怎么想…」所说的方法）、`sammā = အကြောင်းမှန် နည်းလမ်းမှန်အားဖြင့်`（凭正确的原因、正确的方法）。译文「这样正确地解脱」大体可以，但「这样」容易被读成程度副词。
- **建议**：改为「瓦帕，内心以这种方式正确解脱的比丘…」。此为可选修改。

## §1553 句 87-1553-67-71
- **问题**：原文疑问 — 46-66 的 pali 作 `manasā dhammaṃ viññā`，nissaya 作 `ဝိညာယ = သိ၍`（viññāya）。「viññā」疑为 viññāya 的截略或讹误，需记录，不改原文。另外，44-44 与 45-45 两行的 pali 和 zh 都只有「.」，疑为切分残片，提请检查。
- **建议**：译文按 viññāya（知道后）处理，现译「知法的时候」可以保留。

## §1553 句 87-1553-96-111
- **问题**：
  1. 词义 — `idheva = ဤဘဝ၌သာလျှင်`（就在今生），不是地点意义上的「此处」。
  2. 补出成分越界 — nissaya 的括注 `(ပဋိသန္ဓေနေသော အားဖြင့် နောက် ဒုတိယဘဝသို့ မသွားဘဲ)` 是解释性补充。译文把它写进正文成了「不再转生他处」，属于把句法注写进了正文。
  3. 补出成分 — `anabhinanditāni = (တဏှာစသည်တို့ဖြင့်) မနှစ်သက်အပ်ကုန်ဘဲ`。「不被欢喜」意思不清，可以补出施事。
- **建议**：改为「他知道：‘身体坏灭、寿命终结以后，一切感受都不再被（渴爱）喜好，就在今生变得清凉。’」「不再转生」如需要可改作脚注。
