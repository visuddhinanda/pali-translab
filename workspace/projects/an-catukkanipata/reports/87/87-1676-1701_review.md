# Review — 87:1676-1701（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（只有部分句子有 nissaya；没有 nissaya 的句子不出意见，只在跨段一致性一节列出相关问题）

## 跨段一致性

- **pāpadhamma / kalyāṇadhamma**：nissaya 解作“具有……品性的人”，不是“法”。§1683、§1684 的 nissaya 都把 `pāpadhammo` 释为 `ယုတ်မာသော သဘောရှိသောသူ`（品性卑劣的人）。§1684 的定义也是 `ekacco pāṇātipātī hoti…`（有的人杀生……），说的是人。但第九经 §1683–1687 和第十经 §1689–1693 通篇都译成“恶法／比恶法更恶的法／善法／比善法更善的法”。第八经 §1677–1681 用的“恶人／比恶人更恶的人”和 nissaya 的读法一致。→ **必改项**：两经的 `pāpadhamma`、`pāpadhammatara`、`kalyāṇadhamma`、`kalyāṇadhammatara` 统一改成指人的译法。建议：
  - 品性恶劣的人
  - 比品性恶劣的人更恶劣的人
  - 品性良善的人
  - 比品性良善的人更良善的人
  
  问句也要从“什么是……呢”改成“什么样的人是……呢”，跟第八经一致。经名《恶法经》是篇名，可以不动。
- **§1689 夹注**：“恶法（pāpadhamma）”“善法（kalyāṇadhamma）”这两处夹注会让读者把它当成法相术语。按上一条改译以后，夹注可以删掉，或者改注在新译法后面。§1683 是这组词第一次出现，却没有夹注，前后不一致。
- **pāpadhammo / kalyāṇadhammo 作定语**：
  - §1700、§1701 译成“行恶法的／行善法的”，读起来是动宾结构，意思是“奉行恶法”。
  - nissaya 用的是表示“具有”的 `ရှိသော`：`ပါပဓမ္မော= ယုတ်ညံ့သော သဘောရှိသော`（具有低劣品性的），`ကလျာဏဓမ္မော= ကောင်းသောသဘောရှိသော`（具有良善品性的）。这是表示属性的形容词。
  - → 改成“品性恶劣的／品性良善的”，和第九、十经的改法统一。
- **经末标记**：§1681 译“第八经。”，§1687 译“第九。”，§1693 译“第十经终。”，§1701 译“第一经。”。→ 统一为“第 X 经。”，§1687 补“经”字，§1693 删“终”字。
- **经号、段号格式**：
  - 经号：§1676 用“八、”，§1682 用“9.”，§1688 用“十、”，§1699 用“一、”。
  - 段号：§1677 用“二〇八、”，§1683 用“209.”，§1689 用“二一〇、”，§1700 用“二一一、”。
  - → 统一用汉字数字加顿号，§1682 改成“九、”，§1683 改成“二〇九、”。
- **经名格式**：§1676 是“第二恶法经”，§1682 是“第三恶法经”，§1688 却是“恶法经第四”。→ 统一成“第四恶法经”。
- **Taṃ suṇātha**：§1677 译“你们听着”，§1683 译“这些你们要听好”，§1689 译“你们要听好这些法”。→ 统一成“你们听着”。§1689 的“这些法”还和上面的人称读法冲突。
- **Idha ekacco**：§1678 译“这里有一种人”，§1684 译“这世上有的人”，§1690 译“在这里，有的人”。→ 统一成一种说法。
- **samādapeti**：
  - §1679 译“劝导别人持”。
  - §1685、§1687 译“劝别人也”。
  - §1691、§1693 译“劝导别人受持”。
  - → 统一成“劝导别人……”。
- **micchādiṭṭhiko hoti**：§1678 译“持邪见”，§1684 译“持有邪见”，§1690 译“有邪见”。正见同样不统一。→ 统一。

## §1683 句 87-1683-19-23

- **问题**：词法 — 这条 nissaya 覆盖本段全部名词：
  - `ပါပဓမ္မဉ္စ= ယုတ်မာသော သဘောရှိသောသူကိုလည်းကောင်း`：品性卑劣的人（宾格）
  - `ပါပဓမ္မေန= …သဘောရှိသောသူအောက်`：比……的人（比较的基准）
  - `ပါပဓမ္မတရဉ္စ= သာ၍ ယုတ်မာသော သဘောရှိသောသူကို`：更卑劣的人
  - kalyāṇa 一组同样都是“……的人”
  
  本句和上句 87-1683-2-18 都译成“善法／恶法”，把人误读成了法。
- **建议**：本句改成“还要讲说品性良善的人，以及比品性良善的人更良善的人。”上句同样改：“我要为你们讲说品性恶劣的人，以及比品性恶劣的人更恶劣的人；”。`ဝေါ= သင်တို့အား`（为你们）和补出的主语 `(အဟံ= ငါသည်)`（我）译文都已体现，不用动。

## §1684 句 87-1684-2-10

- **问题**：词法 — `ပါပဓမ္မော= ယုတ်မာသော သဘောရှိသောသူဟူသည်` 是主格，意思是“所谓品性卑劣的人”。译文“什么是恶法呢”把主语译成了法。
- **建议**：改成“比丘们，什么样的人是品性恶劣的人呢？”。本段的结句 87-1684-24-30，以及 §1685–1687、§1690–1693 各句，按跨段一致性第一条一起改。

## §1700 句 87-1700-18-36 / 37-45 / 46-53 / 54-61

- **问题**：词法 — nissaya 是 `ဒုဿီလော= သီလမရှိသော`（没有戒的）和 `ပါပဓမ္မော= ယုတ်ညံ့သော သဘောရှိသော`（具有低劣品性的），两个并列定语修饰 `ဘိက္ခု= ရဟန်းသည်`（主格）。谓语是 `ပရိသဒူသနော= ပရိသတ်ကိုဖျက်ဆီးတတ်၏`（惯于败坏会众）。译文“行恶法的”把表示属性的定语译成了动宾结构。
- **建议**：四句都改成“比丘们，破戒、品性恶劣的比丘（比丘尼／男居士／女居士），是败坏会众的人”。

## §1701 句 87-1701-13-21 / 22-29 / 30-37 / 38-45

- **问题**：词法 — `ကလျာဏဓမ္မော= ကောင်းသောသဘောရှိသော` 意思是“具有良善品性的”，是属性定语。`သီလဝါ／သီလဝတီ= သီလရှိသော` 意思是“有戒的”。译文“行善法的”问题和 §1700 一样。
- **建议**：四句都改成“持戒、品性良善的比丘（比丘尼／男居士／女居士），是庄严会众的人”。
