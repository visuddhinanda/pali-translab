## 必改项

### A. `apañjasā` / `pañjasā` 被误作独立主语「气流」
句 `87-803-84-93`、`87-803-94-102`、`87-804-71-79`、`87-804-80-88`

- **问题**：义注依据明确 —
  **义注**：`**Apañjasā**ti maggato apagatā, ummaggagāmino hutvā vāyantīti attho.`（apañjasā = 离开了道路，成为走邪路者而吹）
  **义注**：`**Pañjasā**ti maggappaṭipannā, maggeneva vāyanti, no amaggenāti attho.`（pañjasā = 循道而行，只沿着道吹，不走非道）
  可见 `apañjasā` / `pañjasā` 是形容 `vātā`（风）的主格复数形容词，与 `visamā` / `samā` 并列作同一主语的两个谓语性修饰语；§803-94-102 的 `visamesu apañjasesu` 更是与 `vātesu` 同格的处格同位语。译文另立「气流」为第二个主语，等于把一阵风拆成两样东西，对应关系断裂，且义注核心的「偏离常道／循常道」之义完全失落。
- **建议**：
  - §803-84-93 →「季节和年岁的循环不正常时，风也吹得不正常：风力不匀，而且偏离了常道。」
  - §803-94-102 →「风吹得不正常、风力不匀又偏离常道时，诸天就愤怒了。」
  - §804-71-79 →「季节和年岁的循环正常时，风也吹得正常：风力匀和，循常道而行。」
  - §804-80-88 →「风吹得正常、风力匀和又循常道时，诸天就不愤怒。」

### B. `visamā` / `samā` 的释义被泛化为「不正常／正常」
句 `87-803-84-93`、`87-803-94-102`、`87-804-71-79`、`87-804-80-88`

- **问题**：**义注**：`**Visamā**ti na samā, atithaddhā vā atimudukā vāti attho.`（不匀，即过猛或过柔）；**义注**：`**Samā**ti samappavattino nātithaddhā nātimudū.`（匀和地行，不过猛不过柔）。义注给的是**风力强弱**这一具体所指，译文笼统作「不正常」，与同句作副词的 `visamaṃ`（义注另释为 `asamayena vāyanti`，不按时节而吹）撞成同一个词，两个不同的义注义项在中文里被压平了。
- **建议**：副词 `visamaṃ`／`samaṃ` 保留「（不）正常地吹」或按义注作「不按时节／正当其时」；形容词 `visamā`／`samā` 落实为「风力不匀（过猛或过弱）」／「风力匀和（不猛不弱）」。改法已并入 A 的句子。

### C. `sammā dhāraṃ anuppavecchati` 的 `sammā` 误作「充足」
句 `87-803-103-110`、`87-803-111-137`、`87-804-89-95`、`87-804-96-103`

- **问题**：**义注**：`Tasmā devatā parikupitā bhavanti, tā devassa sammā vassituṃ na denti. Tena vuttaṃ **devo** **na** **sammā** **dhāraṃ** **anuppavecchatī**ti.`（诸天愤怒，不让雨天好好地下雨，所以说「天不好好降下雨流」）。`sammā` 是「如常地、好好地、适时地」，不是雨量的「充足」。译文四处均作「充足的雨水」，把义注的「不让它*好好*下」偷换成了「下得不够多」——而全经的因果链讲的正是「失序」，不是「不足」。
- **建议**：
  - §803-103-110 →「诸天愤怒时，天就不好好降雨。」
  - §803-111-137 →「天不好好降雨时，庄稼的成熟就参差不齐。」
  - §804-89-95 →「诸天不愤怒时，天就好好降雨。」
  - §804-96-103 →「天好好降雨时，庄稼的成熟就齐整。」

### D. `rājāyuttā`「国王的臣属们」译泛，与义注所指不合
句 `87-803-2-23`、`87-803-24-31`、`87-804-2-18`、`87-804-19-26`

- **问题**：**义注**：`**Rājāyuttā**ti rañño janapadesu kiccasaṃvidhāyakā āyuttakapurisā.`（在国王各地方上掌理事务的受任官员）。义注指的是**派驻各地的行政官吏**，「臣属」中文容易读成宫廷近臣或泛指一切下属，既译窄了职能、又译宽了范围，并且丢掉了「国王→地方官→城里婆罗门居士→镇民乡民」这条**从中央逐级下到地方**的递推线索。
- **建议**：统一译为「王家官吏」或「国王派驻各地的官吏」（首次出现可加「（rājāyutta）」夹注），四处一致。

### E. 偈颂开引号在 chunk 内无一处闭合
句 `87-805-2-12`、`87-807-2-10`、`87-810-2-11`、`87-812-2-11`

- **问题**：巴利原文每则偈颂起首都带 `‘‘`，闭引号只在整组偈颂末尾（§814 之后）。译文照搬成四个全角开引号「“」而本 chunk 内零个闭引号，读者在任何按段呈现的界面上都会看到四处悬空引号。§803／§804 的散文段同样只有 §804-104-123 收了一个闭引号，§803-2-23 开的引号在 §803-138-159 也没有闭合。
- **建议**：定一条规则并在本 chunk 内贯彻——推荐**每段自闭**（每段首加「“」、段末加「”」，中文竖排横排皆通行的做法）；若选择只在整组首尾加引号，则 §805、§807、§810、§812 的开引号应只保留 §805 一处，其余删去。两种都可以，但不能像现在这样半开半闭。

## 建议项

### §803-24-31 / §803-32-39 / §804-19-26 / §804-27-34 — `brāhmaṇagahapatikā` 漏掉义注的「城内」限定
- **问题**：**义注**：`**Brāhmaṇagahapatikā**ti antonagaravāsino brāhmaṇagahapatayo.`（住在城内的婆罗门与居士）。这一限定不是闲笔，它与下一级 `negamajānapadā`（**义注**：`nigamavāsino ceva janapadavāsino ca`，集镇居民与乡邑居民）构成「城—镇—乡」的递降对照。译文作「婆罗门和居士们」，对照关系看不出来。
- **建议**：首次出现译「城里的婆罗门和居士」，其后可简作「婆罗门和居士」。

### §803-32-39 / §803-40-46 / §804-27-34 / §804-35-40 — `negamajānapadā`「城镇和乡村」与上一级用词撞车
- **问题**：`nigama` 是集镇，`janapada` 是乡邑地方；译文用「城镇」，而上一级义注讲的恰是 `nagara`（城）内居民，中文「城镇」把两级并到一起。
- **建议**：译「集镇和乡间的居民」。

### §803-94-102 / §803-103-110 / §804-80-88 / §804-89-95 — 「诸天神」
- **问题**：`devatā` 汉译传统作「诸天」；「诸天神」中「诸…神」叠加，略冗。
- **建议**：统一作「诸天」。另：`parikupitā` 义注给的因由是「树木折断、天宫毁坏」（**义注**：`vātesu hi visamesu apañjasesu vāyantesu rukkhā bhijjanti, vimānāni bhijjanti`），「愤怒」比「发怒」更贴 `pari-` 的程度义，可酌。

### §803-111-137 / §803-138-159 / §804-96-103 / §804-104-123 — `visamapākāni`「成熟不整齐」
- **问题**：译意方向正确，**义注**：`ekasmiṃ ṭhāne gabbhīni honti, ekasmiṃ sañjātakhīrāni, ekaṃ ṭhānaṃ paccati`（一处还在孕穗，一处已乳熟，一处已熟透）——指的是**同时不同熟**。「不整齐」偏向外观齐不齐。
- **建议**：「庄稼成熟参差不齐」／「庄稼成熟齐整」。

### §803-138-159 / §804-104-123 — `dubbaṇṇā` / `vaṇṇavanto`「面色难看／好看」
- **问题**：`vaṇṇa` 兼指肤色光泽与整体容貌，「面色难看／好看」偏口语且窄到脸。
- **建议**：「气色差／气色好」或「相貌不佳／相貌端正」，两处取同一组对举词。

### §805-2-12 — `jimhaṃ gacchati` 丢失义注的「不走渡口」
- **问题**：**义注**：`**Jimhaṃ** **gacchatī**ti kuṭilaṃ gacchati, atitthaṃ gaṇhāti.`（走弯路，从非渡口处下水）。`atittha`（非渡津）一词正好反证了 `taramānānaṃ` 取「渡水」义——译文「正在渡河」据此是对的 ✅。但「走偏了路」与「正在渡河」并置略显违和，读者不易明白牛在水边偏的是什么。
- **建议**：「如果牛群正要渡水，领头的公牛却走偏了、从不是渡口的地方下水」；或正文从简、把「非渡口」放进脚注。§810 对应的 `ujuṃ gacchati` 则作「径直走向渡口」以成对举。

### §808-2-10 / §813-2-27 — `pageva itarā pajā`「更不用说了」语义悬空
- **问题**：`pageva` 是「何况／更会如此」，省略的谓语是上句的 `adhammaṃ carati` / `dhammaṃ carati`。中文「更不用说了」本身不含方向，§808 读者尚能从上文补出「更不如法」，§813 配上「如果他行为如法」后，「更不用说了」几乎读不通——听着像在说民众反而不如法。
- **建议**：§808 →「其余的民众就更会这样」；§813 →「其余的民众就更会这样」。两处用同一句式，让对举立住。

### §806-2-11 / §811-2-11 — 「只要」加重了原文没有的条件
- **问题**：`nette jimhaṃ gate sati` 是处格绝对结构，单纯陈述「在引领者走偏时」；条件已由 §805／§810 的 `ce` 承担，译文再加「那么只要…」是叠加。
- **建议**：§806 →「在领头的牛走偏时，所有的牛都跟着走偏。」§811 →「在领头的牛走正时，所有的牛都跟着走正路。」（`nettā` 有义注依据：**义注**：`nayatīti nettā`，引领者故名 nettā，译「领头的牛」✅）
