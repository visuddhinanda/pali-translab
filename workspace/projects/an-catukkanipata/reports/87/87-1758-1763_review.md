# Review — 87:1758-1763（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1758、1759 两段及 1761、1762 段的部分句无 nissaya，相关句略过）

## 跨段一致性
- **akaṇhaasukkavipākaṃ**：§1760–1762 中同构复合词 kaṇhavipākaṃ / sukkavipākaṃ / kaṇhasukkavipākaṃ 一律译「有 X 果报的」。§1763 句 87-1763-2-13、87-1763-14-83（以及 §1759 句 87-1759-47-56）却译作「果报也非黑非白的」，句式改了。nissaya 对四者的处理完全平行（`အကဏှ အသုက္ကဝိပါကံ= သော။`，与 `ကဏှဝိပါကံ= သော။` 同为定语）→ 建议统一为「非黑非白的、有非黑非白果报的、导向业灭尽的业」。
- **seyyathāpi**：§1760「例如地狱的众生」、§1761「例如遍净天的诸天」、§1762「例如人、某些天和某些堕处者」三处都用「例如」。nissaya 三处都是比喻结构 `…သေယျထာပိ= …ကဲ့သို့။ (ဧဝံ= ဤအတူ။)`，意思是「就像……那样，（他）也同样……」，是比况，不是举例 → 三处统一改为「就像……那样」（见下文各句）。
- **ekantadukkhaṃ / ekantasukhaṃ / vokiṇṇasukhadukkhaṃ**：三段都把这个 vedanaṃ 的定语拆成后置分句（「，完全是苦的」「，完全是乐的」「，苦与乐交杂在一起」）。nissaya 三处都标为修饰 vedanaṃ 的定语（`= …ဖြစ်သော။`）。三段的处理是一致的，但都偏离了词法（见下文），要改就三处同改。
- **devā**：§1761 译「诸天」，§1762 译「天」。指称对象不同（前者为遍净天梵天，后者为欲界天），但量词／称谓宜统一，建议都用「天神」，或都用「天」。

## §1760 句 87-1760-52-60
- **问题**：句法 — `ဥပပန္နံ= လားရောက်လျက်။ သမာနံ= ဖြစ်နေသော။ တမေနံ= ထိုပုဂ္ဂိုလ်ကို။`：upapannaṃ samānaṃ 是修饰宾格 tamenaṃ 的状态定语（「已投生到……的那个人」），不是先后关系。译文「……以后」把它译成了时间先后。另外，nissaya 把 phassā 释为 `အကျိုးဝိပါက်ဖဿ`（果报之触），译文直接作「触」，可以接受，不必补字。
- **建议**：可改为「有恼患的触触及已投生到有恼患世间的他」，或保留现有语序、把「以后」改为「之后，在那里」。属于非必改项。§1761 句 87-1761-47-55、§1762 句 87-1762-52-63 同构，若改则一并改。

## §1760 句 87-1760-61-88
- **问题 1**：格 — `ဧကန္တဒုက္ခံ= ဧကန်စင်စစ် ဒုက္ခဖြစ်သော။ … ဝေဒနံ= ဝိပါက်ဝေဒနာကို။`：ekantadukkhaṃ 与 sabyābajjhaṃ 同为 vedanaṃ 的宾格定语。译文「感受有恼患的感受，完全是苦的」把它拆成了另一个谓语分句。
- **问题 2**：句法 — `နေရယိကာ= ငရဲ၌ဖြစ်ကုန်သော။ သတ္တာ သေယျထာပိ= သတ္တဝါတို့ကဲ့သို့။ (ဧဝံ= ဤအတူ။)`，另一种读法为「就像地狱众生感受……那样，他也同样感受……」。这是比况，「例如」把它误读成了举例。
- **建议**：「在有恼患的触触及他时，他感受有恼患的、纯然是苦的感受，就像地狱众生那样。」

## §1761 句 87-1761-56-69
- **问题 1**：格 — `ဧကန္တ သုခံ= ဧကန်စင်စစ် သုခဖြစ်သော။`：ekantasukhaṃ 是 vedanaṃ 的定语，译文拆成了「，完全是乐的」。
- **问题 2**：句法 — `ဒေဝါ သေယျထာပိ= ဗြဟ္မာတို့ကဲသို့။ (ဧဝံ= တူ။)`：这里是比况，不是举例。nissaya 指出 devā 是遍净天的梵天。
- **建议**：「……他感受没有恼患的、纯然是乐的感受，就像遍净天的天神那样。」

## §1762 句 87-1762-64-84
- **问题 1**：格 — `ဝေါကိဏ္ဏသုခ ဒုက္ခံ= ရောနှောသောသုခဒုက္ခဖြစ်သော။`：这是 vedanaṃ 的定语，译文拆成了「，苦与乐交杂在一起」。
- **问题 2**：句法 — `…ဝေဒိယန္တိ သေယျထာပိ= ခံစားကြကုန်သကဲ့သို့။ ( ဧဝံ= တူ။)`：这里是比况，不是举例。三个并列主语带 `စ= …လည်းကောင်း`，ekacce 同时修饰 devā 与 vinipātikā，译文「某些天和某些堕处者」的结构是对的。nissaya 释 devā 为 `ကာမာဝစရနတ်`（欲界天），释 vinipātikā 为 `ဗိမာန်ပိုင်ရှင် ဝိနိပါတိကပြိတ္တာ`（有宫殿的堕处饿鬼）。正文不必补出这些。
- **建议**：「……他感受既有恼患又没有恼患的、苦乐交杂的感受，就像人、某些天和某些堕处者那样。」

## §1763 句 87-1763-2-13
- **问题**：跨段一致 — 「果报也非黑非白的」与前文「有 X 果报的」句式不平行。nissaya 的处理是平行的（`အကဏှ အသုက္ကဝိပါကံ= သော။`）。
- **建议**：「诸比丘，什么是非黑非白的、有非黑非白果报的、导向业灭尽的业呢？」

## §1763 句 87-1763-14-83
- **问题 1**：跨段一致 — 句末「果报也非黑非白的」同上，需要统一。
- **问题 2**：补出成分 — nissaya 每个 yā cetanā 之后都带 `လည်းကောင်း`（三者并列），末尾补 `ဟောတိ= ရှိ၏။`（「有」），没有「生起」之义。译文三次补出「而生起的」，属于增义，但不影响句法，可以保留。nissaya 还把三处的 cetanā 都释为 `လောကုတ္တရာမဂ်စေတနာ`（出世间道思），但正文不必补出，符合「不擅补」的原则。
- **建议**：句末改为「……这就叫做非黑非白的、有非黑非白果报的、导向业灭尽的业。」「生起」二字可以改为「的」，例如「为了舍断……业的思」。属于非必改项。
