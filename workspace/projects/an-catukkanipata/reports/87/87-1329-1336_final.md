## 理由

**基准缺失（影响信心）**：本次注入的资源只有巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**，无法做"义注定释义、nissaya 定词法"的逐句核对。以下判断仅依据巴利原文形态与句法、经文内部的平行结构（1331/1332/1333 三段完全同构，1335 与 1336 互为"佛说—舍利弗解说"对应）。因此信心压到 68：涉及传统取义的几条（`khetta` / `vatthu` / `adhikaraṇa` 的所指、`attabhāvapaṭilābha` 的义注定义、`kamati` 的释义）在拿到义注后应重核。

**准确性**：主干教理表达正确——身/语/意存在时以三种"思"为因生起内在苦乐、唯以无明为缘、无明无余灭则所缘之身语意及田事处依处不复存在、四种自体获得与对应的命终之因，层级关系与经文一致，无违背基本教理之处，故无 fatal。扣分集中在两点：
1. `pare vāssa taṃ kāyasaṅkhāraṃ abhisaṅkharonti` 的句法读错。`abhisaṅkharonti` 是主动态复数（主语 `pare` 别人们），`assa` 是属格/与格（他的／为他），全句为"别人为他／造作他的那个身行"；译文作"别人**使他**造作"把非使役动词读成了使役，并把 `assa` 当成了被使动者——施动者从"别人"滑回了"他"，与紧接的 `sāmaṃ`（自己造作）一句的对比正好失效。该错在身/语/意三段原样重复 3 次，是本段最实质的问题。
2. `attabhāvapaṭilābha` 复合词中心语被移位。中心语是 `paṭilābha`（获得），`attabhāva` 是其宾语，应为"自体（自身存在）的获得"；译文"所获得的自体"把中心语换成了"自体"，使 `cattāro attabhāvapaṭilābhā`（四种获得）变成"四种自体"。1335-13-26 起把 `yasmiṃ attabhāvapaṭilābhe` 进一步简作"在这种自体之中"，丢掉了"获得"。此条待义注核对 `attabhāvapaṭilābha` 的释义后定稿，但就原文构词而言译法偏移。

**风格**：现代书面汉语基本合格，无"此中／故为／彼等／于…之际／答以"一类文言腔，连词用"就／因为／而不是"，符合 `style.md` 硬约束，这一维度不扣文言分。扣分来自冗长与节奏：`yaṃpaccayāssa taṃ uppajjati ajjhattaṃ sukhadukkhaṃ` 固定译作"以此为缘，在他自身之内就生起乐与苦"，在 1334 一句之内连出四次全译形式，加上三次"就不存在了"，整句长而读者难以追踪；"随附着无明""我是这样详细地理解它的意思的"略有翻译腔。`……乃至……` 作为 `…pe…` 的省略标记属佛典惯例，未按文言语体计扣，但列入可提升项。

**一致性**：术语与句式高度稳定——`saṅkhāra`→身行/语行/意行、`sañcetanā`→意图、`ajjhattaṃ`→在（他）自身之内、`bhante`→大德、`sukhadukkha`→乐与苦，全段无游移；1335 与 1336 的四分结构用语严格对应，便于读者对读。失分只在 `deva` 一处时译"天"、一处译"诸天"，以及 `cetanā`（经名）与 `sañcetanā`（正文）未作区分、同作"意图"。标点全角合规，多段引语按中文惯例逐段开引号、末段闭合，译文 `zh` 字段内未出现 ASCII 引号，无残留工作标记。

## 问题清单

### 🟧 error
- `87-1331-19-42`｜错译（修饰关系／句法角色）｜片段「或是别人使他造作那身行」
  - 问题：`pare`（主格复数）是 `abhisaṅkharonti` 的施动者，`assa` 为属格／与格"他的／为他"，动词非使役态。译作"使他造作"把施动者又拉回"他"，与上一句 `sāmaṃ`（自己造作）的对比消失，整组四句（自作／他作／知而作／不知而作）的对立结构被破坏。
  - 建议：改为"或是别人为他造作那身行"（或"别人造作他的那个身行"）。
- `87-1332-19-28`｜错译（修饰关系／句法角色）｜片段「或是别人使他造作那语行」
  - 问题：同上，`pare vāssa … abhisaṅkharonti` 误读为使役。
  - 建议：改为"或是别人为他造作那语行"。
- `87-1333-19-33`｜错译（修饰关系／句法角色）｜片段「或是别人使他造作那意行」
  - 问题：同上，`pare vāssa … abhisaṅkharonti` 误读为使役。
  - 建议：改为"或是别人为他造作那意行"。
- `87-1335-2-9`｜错译（复合词中心语偏移）｜片段「有这四种所获得的自体」
  - 问题：`attabhāvapaṭilābha` 的中心语是 `paṭilābha`（获得），`attabhāva` 为其宾语；`cattāro attabhāvapaṭilābhā` 是"四种自体（自身存在）的获得"，不是"四种被获得的自体"。译法把动作名词换成了受动对象。
  - 建议：统一改为"四种自体的获得"／"四种自身存在的获得"；1335、1336 全部八处同步改，并待义注核定该词释义。
- `87-1335-13-26`｜漏译（复合词成分）｜片段「在这种自体之中」
  - 问题：`yasmiṃ attabhāvapaṭilābhe` 中的 `paṭilābha`（获得）被整个省去，只剩"自体"，与前句的译名也不再一致。
  - 建议：改为"在这种自体的获得之中"；1335-27-40、1335-41-54、1335-55-68 及 1336 各句同处一并处理。

### 🟨 warning
- `87-1336-96-118`｜语言风格不统一｜片段「应当见为哪些天呢」
  - 问题：同一问答中 `devā` 此处作"天"、下一句 `87-1336-119-131` 作"诸天"，且单字"天"易被读作"天界／天空"。
  - 建议：两处统一为"诸天"，如"应当见为哪些诸天呢"或"应当认为是哪些天神呢"。
- `87-1334-2-86`｜关键词语意不明确｜片段「那个田（khetta）」
  - 问题：`khetta` 直译"田"，在无注释的情况下现代读者无法把握其"业生长之地"的喻义；且原文校勘记 `[ vatthuṃ taṃ ( sabbattha )]` 表明各本此处多作 `vatthu`，与紧随的 `vatthu` 构成异读问题，译文未作任何交代。
  - 建议：保留"田（khetta）"但加脚注说明喻义，并在脚注注明各本异读作 `vatthuṃ`。
- `87-1334-2-86`｜整句逻辑表达不规范｜片段「以它为缘而在他自身之内生起乐与苦的那个身，就不存在了」
  - 问题：同一长句内重复四次同形长定语 + 三次"就不存在了"，再夹入两处"……乃至……"，句子逻辑链过长，读者难以把"那个身／语／意"与"无明灭"的因果挂上。
  - 建议：首次全译该定语，后续改用回指（"那个语也同样不存在了"），或在"由于无明毫无残余地完全褪尽、灭尽"后断句另起。
