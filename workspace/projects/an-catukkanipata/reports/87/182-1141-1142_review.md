## 跨段一致性

1. **ṭhito = “安住不动”（§1141 六处：8-22 / 23-35 / 36-49 / 50-62 / 63-73 / 74-86）**
   - **问题**：增译 + 与父层术语撞车。`ṭhito` 只是“住立／安住”，原文没有“不动”义；而父层 100-1084-100-131 用“不动摇”对译 `niccalika`（记牢到不动摇的程度）。本层把 `ṭhito` 一律译作“安住不动”，读者会以为对应的是 `niccalika` 一类词。
   - **建议**：六处统一改为“**而安住**”（或“而住立”）。改后句式仍整齐，不损可读性。

2. **sacchikiriyā 词族：黑体译“证得”，同句释义译“现证”（§1141 63-73）**
   - **问题**：同一词根在一句之内两种译法，黑体与释义的对应关系断开。
   - **建议**：释义随黑体，统一用“证得”（详见下条）。

3. **“四道”称法**：§1141 36-49 作“四道”、87-100 作“四道的梵行”、101-111 作“道梵行” → 第三处需与前两处对齐（见下条）。

4. 其余跨段项一致：`pāraṃ gato` 一律“到达了彼岸”✅；`…ti attho` 一律“意思是说”✅；全角标点、无 ASCII 引号、无工作标记 ✅。

## §1141 句 182-1141-8-22

- **问题**：误译 + 成分重复（必改）。`sabbadhamme` 是 `jānitvā` 的宾语（对格复数），`abhivisiṭṭhāya` 是与 `paññāya` 同格的具格修饰语，意为“极为殊胜的”。译文“**超越一切法的**最殊胜的最上道慧”把 `sabbadhamme` 又挂到 `abhivisiṭṭhāya` 上充当“超越…的”，于是 `sabbadhamme` 被译了两遍（“超越一切法的”＋“了知了一切法”），并且把“殊胜”误解成“超越（一切法）”。
- **建议**：删去“超越一切法的”，改为：「意思是说，他已经用最为殊胜的最上道慧了知了一切法而安住。」

## §1141 句 182-1141-63-73

- **问题**：术语内部不一致。黑体依父层作“在**证得**上到达彼岸”，但释义改口作“通过**现证**灭（nirodha）”“他已经**现证**了灭”。
- **建议**：释义随黑体统一为“证得”：「**在证得上到达彼岸**，就是通过证得灭（nirodha）而到达了彼岸；意思是说，他已经证得了灭而安住。」

## §1141 句 182-1141-87-100

- **问题**：语序别扭，“那种”为冗余指示词；`yaṃ … tena samannāgato` 的关联结构在中文里拆得过碎。
- **建议**：「**完整地成就了梵行**，就是：梵行的完整，也就是齐备的状态，他具备了这一点；意思是说，他完整地过着四道的梵行生活。」

## §1141 句 182-1141-101-111

- **问题**：半文半白、压缩过度（必改）。“意思是道梵行圆满具足”把 `paripuṇṇamaggabrahmacariyo` 整块搬成“道梵行”这个生造复合词，没有谓语主语，读来像文言注语；对照 `style.md` 第一节，应拆成现代汉语句子。另与上一句“四道的梵行”称法不统一。
- **建议**：「因此说**“梵行完整齐备”**，意思是说，他四道的梵行已经圆满具足。」
