## 理由

**基准可用性（降级说明）**：本次只注入了巴利原文与待评译文。本层即义注（book=100 为 `8._Attantapasuttavaṇṇanā`），**没有注入 nissaya**，也**没有注入本文（mula）与复注**。因此两项核对无法执行，必须明确交代：
1. 词级核对（格、句法角色、覆盖率）只能依巴利原文自评，无 nissaya 旁证；
2. **「被解释词与父层逐字同译」这条硬约束无法验证**——本段密集出现黑体引词（`Kaṃso` / `Mānakūṭaṃ` / `Ukkoṭanaṃ` / `Vañcanaṃ` / `Nikatī` / `Sāciyogo` / `Chedanaṃ` / `Vadho` / `Bandho` / `Viparāmoso` / `Ālopo` / `Sahasākāro` / `So santuṭṭho hotī`），这些词的汉译是否与本文译文逐字一致，**需取本文坐标回查后才能定论**。下面问题清单中凡涉及黑体词选词的条目，都以此为前提：若本文已采同一译名，则属一致性正常，不应据此改动义注译文。

**准确性**：叙事与界说部分整体忠实，骗术三案（金盘、斗量三法、鹿与小鹿）的情节逻辑、数目计算（一迦利沙槃 + 值一迦利沙槃的小鹿 = 两迦利沙槃）、八资具清单与偈颂对应（三衣+钵+刀+针+带+滤水囊=八）都准确，无漏译、无教理性误读，**无 fatal**。主要扣分在术语层：`parikkhāra` 与 `paccaya` 共用「资具」一词（见问题清单 🟧），读者会把「四种资具」与「八种资具」误当同一系列。`-kūṭa` 复合词译成「假金器／假量器」把**诈骗行为**说成了**器物**，导致「用它行骗就是假金器」一句主谓不相称。`yogavasena` 译「药物手段」取义偏窄，缺依据说明。

**与原文的分歧（不扣分，备记）**：`1614-22-42` 的 `samagghataraṃ dātukāmā honti`，译文取「卖方愿意低价出让」。此读法与通行解读一致，但 `honti` 为复数、而上下文骗子一直是单数（`karoti` / `gacchati`），后句 `tehi ... vutte` 的复数又明确指那户人家，故「买方想压价」在语法上同样可立。此处不扣分，但建议定稿前以 nissaya 的格助词确认主语归属。

**风格**：现代书面汉语达标，全程全角标点与弯引号，无 ASCII 引号，无残留工作标记（候选/待定/问号），口语对白自然（「喂，我不要小鹿了」「他说得有道理」）。禁例表中的文言写法基本未出现；仅 `1617-62-70` 的「乃至」略带经文腔，属可提升项，非违规。

**一致性**：人物称呼（猎人／骗子）、数词单位（迦利沙槃）、「弯曲不正的手段」贯通三处，均稳定。失分点为上述「资具」混用，以及 `1618-2-16` 同一词根 `santuṭṭha / santosa` 在一句内分作「满足」与「知足」，被解释词与释义之间的对应关系被切断。另有多个黑体词采用「描述式长译名」（收受贿赂枉断是非、持刀强取、掠夺村镇、埋伏劫掠），使「X 就是〈X 的同义改写〉」式界说句读起来同义反复，影响可读性。

## 问题清单

### 🟧 error

- `100-1618-17-39`｜导致误解的表达（术语混同）｜片段「有八种资具是允许的」
  - 问题：上一句 `1618-2-16` 已把 `paccaya`（衣、食、住、药四事）译作「资具」，此处 `parikkhāra`（随身用具）又译作「资具」。两个不同的巴利术语共用同一汉译，读者会把「四种资具」和「八种资具」当成同一分类的两套数目，产生「四种怎么又变八种」的误解。
  - 建议：保留 `paccaya`＝「资具」，把 `aṭṭha parikkhārā` 改为「八种用具」或「八种随身物品」；若本文已有 `parikkhāra` 的既定译名，以本文为准并回查统一。

### 🟨 warning

- `100-1614-2-9`｜整句逻辑表达不规范｜片段「用它行骗就是**假金器**」
  - 问题：`kaṃsakūṭa` 的 `kūṭa` 指**欺诈行为**，原文 `tāya vañcanaṃ kaṃsakūṭaṃ` 是「以它行骗（这件事）叫 kaṃsakūṭa」。译名「假金器」是一个器物名，于是「行骗（行为）＝假金器（器物）」主谓不相称。
  - 建议：若本文未锁定译名，改为「金器诈欺／以金器行骗」之类的行为名，使界说句成立；若本文已作「假金器」，则保留译名，但把本句调整为「用它行骗，就叫作**假金器**（之诈）」一类不把行为等同于器物的说法。

- `100-1615-2-7`｜关键词语意不明确｜片段「所谓**假量器**，分内里作假（hadayabheda）」
  - 问题：同上，`mānakūṭa` 是「量器欺诈」，译「假量器」后紧接三种「作假（手法）」，名（器物）与所分（行为）不在同一层面。
  - 建议：与 `1614-2-9` 一并决定 `-kūṭa` 的统一处理方式，并与本文译名对齐。

- `100-1618-2-16`｜关键词语意不明确（被解释词与释义脱节）｜片段「**他满足**」
  - 问题：黑体被解释词译「满足」，同句释义中的 `santosa` 译「知足」，同一词根在一句之内两种汉译，读者看不出「他满足」正是由「十二种知足」来界定的。
  - 建议：以本文译名为准统一（本文作「知足」则黑体改「他知足」；本文作「满足」则释义改「十二种随得随用的满足」）。**须先取本文坐标回查**再改。

- `100-1616-142-159`｜关键词语意不明确，二意场合无注｜片段「借着药物手段或者幻术」
  - 问题：`yogavasena` 译为「药物手段」把 `yoga`（方术、配方、机巧手法）窄化到「药物」，而下文所举的腰饰、宝珠、黄金作伪并非药物所致；取义缺依据，也未加注交代。
  - 建议：改为较中性的「借着方术手段或者幻术」，或保留现译并加简注说明 `yoga` 在此指作伪的配方与机巧。

- `100-1617-49-61`｜关键词语意不明确（译名预含释义）｜片段「**持刀强取**就是使用暴力强行夺取的行为」
  - 问题：`sahasākāra` 本义为「强暴行为」，译名已写成「持刀强取」，把后文才给出的「把刀抵在胸口」这一细节提前写进词名，于是首个界说句成为同义反复，释义失去信息量。
  - 建议：若本文译名可动，改为「强暴行为／强横夺取」，让「闯进人家、刀抵胸口」留给释义；若本文已作「持刀强取」则保留，不必为此改义注。

### 🟦 suggestion

- `100-1616-2-10`｜复杂嵌套句对读者不友好｜片段「在**收受贿赂枉断是非**等几项里，**收受贿赂枉断是非**是指」
  - 问题：七字描述式译名在一句内重复两次，句子臃肿且界说近乎自我重复。
  - 建议：考虑短译名加夹注，如「**枉法受贿**（ukkoṭana）」，首次出现附巴利原词（需与本文一致）。

- `100-1616-168-175`｜语言表达不够流畅｜片段「收受贿赂枉断是非这种弯曲不正的手段、欺骗他人这种弯曲不正的手段、以假充真这种弯曲不正的手段」
  - 问题：三项并列各自重复十字长名，读来极为冗滞，虽忠实于复合词拆解，但对读者负担过重。
  - 建议：改为「收受贿赂、欺骗他人、以假充真这三者各自与『弯曲不正的手段』相合，即：……」式表述，或在确定短译名后再并列。

- `100-1616-11-18`｜语言风格不统一（译名含释义成分）｜片段「**欺骗他人**是指用种种手段欺骗别人」
  - 问题：黑体词 `vañcana` 本身只是「欺骗」，「他人」来自释义中的 `paresaṃ`，译名把宾语吃进去后，界说句又重说一次「别人」。
  - 建议：黑体改「**欺骗**」（以本文为准），释义保留「用种种手段欺骗别人」。

- `100-1617-7-10`｜语言表达不够流畅｜片段「**杀害**就是杀死他人」
  - 问题：`vadho`＝`māraṇaṃ` 的汉译近乎同词互训，且「他人」为增译。
  - 建议：「**杀害**就是致人死亡」或「就是夺取性命」。

- `100-1614-22-42`｜语言表达／增译｜片段「他愿意卖得比市价便宜不少」
  - 问题：`samagghataraṃ` 只是比较级「更便宜些」，「比市价」与「不少」都是译者补出的参照与程度。
  - 建议：改为「他愿意比别处卖得便宜些」。主语归属另见上文「分歧」一节。

- `100-1614-43-68`｜增译（有助理解但超出原文）｜片段「他只把那只真金的盘子在石头上磨给他们看」
  - 问题：「只」「真金的」为原文所无的提示性补充（原文仅 `suvaṇṇapātiṃ pāsāṇe ghaṃsitvā`）。此补充点明了骗术关键，意思正确，但属译者解读。
  - 建议：可保留；若要贴原文，改作「他把那只金盘在石头上磨给他们看」，骗局细节由上文「两三个铜盘做成金色」自然透出。

- `100-1620-2-10`｜语言表达｜片段「就是精勤修行的比丘所需的全部资具」
  - 问题：「全部」为增译，使偈颂带上「仅此八物、别无其他」的排他断言；原文 `aṭṭhete yuttayogassa bhikkhuno` 未作此强调。另「资具」一词同样涉及上文 `parikkhāra / paccaya` 混同问题。
  - 建议：「加上滤水囊，这八种，就是精勤修行的比丘的用具。」

- `100-1617-62-70`｜语言风格｜片段「乃至持刀强取这些行为」
  - 问题：「乃至」承经文略写（`…pe…`）的传统用法，略带经文腔，对无佛教背景读者稍显生硬（非禁例表所列文言，故不计入风格扣分）。
  - 建议：「他就这样远离砍断肢体……一直到持刀强取这些行为。」
