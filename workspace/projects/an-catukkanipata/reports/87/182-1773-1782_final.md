## 理由

**资源缺口（直接压低信心）**：本次只注入了巴利原文与 channel 译文，**义注（本层为复注 ṭīkā，其父层 aṭṭhakathā）与 nissaya 均未提供**。因此：

- 「被解释词与父层逐字同译」这条硬约束**无法核验**——所有黑体 lemma（`Saṃvohārenā` / `Manasi karotā` / `Paññavatā` / `Thāmo` / `Sākacchāyā` / `Ñātivināso` / `Pañhummaggo` / `Atappakaṃ` / `Saṇhaṃ`）是否与被引的本文/义注用词一致，只能按巴利词形推断。
- 词级格位、隐含成分（如 `na sakkā dassetuṃ` 的施事、`jānitabbo` 的指称对象）没有 nissaya 可比对，相关判断按语境推定，未计入扣分。
- 经名 `Ṭhānasutta` 的取义缺少义注支持，只能按经文内容（四事由四「处/依据」可知）质疑现译，列为 warning 而非 error。

**准确性**：句句有译、无漏译，坐标与原文词段一一对应，10 段 36 句全覆盖。主谓宾判断未见错误，无违背教理之处，故无 fatal。扣分主要来自两处**增译**（`182-1780-6-13`「只在表面上打转」、`182-1781-36-42`「总也听不够、不觉厌倦」）——原文无对应成分，在复注这种逐词对释文体里，读者无法区分哪句是注释、哪句是译者的解说。`asuci/sucisīla` 系列、`vohāra` 四义的分判（买卖交易 / 意图 / 假名 / 言谈说法）处理准确，经证引文（中部 2.457、经集 619、长部 3.313、法集论 1313-1315、相应部 1.25）出处与译法均无误。

**风格**：现代书面汉语达标，**未检出文言禁例**（无「此中/故为/彼等/是故/于…之际/答以」等），标点全角、引号统一用 “ ”，译文内无 ASCII 引号，无 JSON 风险，无残留工作标记。扣分在三点：「存心」在现代汉语里偏贬义；「路数」口语且带贬色；lemma 一律译成「…的人」（`Manasi karotā` / `Paññavatā`）丢掉了工具格「由…才可了知」的句法味，而 `182-1774-30-46` 又把 lemma 译成了完整谓语句，前后体例不一。

**一致性**：`sammukhā/parammukhā`、`purima/pacchima`、「合得起来／合不起来」在 1778 全段统一，`Thāmo→力量` 在 lemma 与引文中一致，经名在 1773 与 1782 首尾一致。主要失分是 `saṃvohāra`（1775）与 `sākacchā`（1780）被压成同一个汉语词「依交谈」——这两者在母经里是两条不同的「处」（前者判洁净，后者判智慧），合译会让读者以为是同一项。

## 问题清单

按级别从高到低排列。

### 🟧 error

- `182-1780-2-5`｜导致误解的表达（术语撞车）｜片段「**依交谈**（sākacchāya）」
  - 问题：`sākacchā`（1780）与 `saṃvohāra`（1775，见 `182-1775-2-7` 片段「**依交谈**（saṃvohārena）」）译成完全相同的「依交谈」。母经四「处」中这是两项不同的判据——`saṃvohāra` 判 soceyya（洁净），`sākacchā` 判 paññā（智慧）；1778 自己也把 `vohāra` 定为 kathāvohāra（言谈上的说法），与「讨论」不是一回事。合译后读者无法分辨两段在讲不同的事。
  - 建议：拆开。`saṃvohāra` → 「依言谈往来」或「依言语交往」；`sākacchā` → 「依讨论」（释语「就是依互相谈论」可保留）。两处圆括号夹注原词保留。
- `182-1780-6-13`｜错误多译｜片段「只在表面上打转」
  - 问题：原文只有 `udake geṇḍu viya uppilavati`（像球在水上浮起），没有「只在表面上打转」这一层断言。这是译者补出的解说，混在正文里读者当成注释原话。
  - 建议：删去，作「就像球浮在水面上一样（浮而不沉）」或把解说移入脚注。
- `182-1781-36-42`｜错误多译｜片段「总也听不够、不觉厌倦」
  - 问题：原文 `atittikaraṭṭhena atappakaṃ sādurasabhojanaṃ viya` 只说「因为不令饱足，故不令厌倦，犹如美味的食物」，并未点出「听」这一具体行为。补出「听」把所释对象（问难／谈论）窄化为听闻，属无据增译。
  - 建议：改为「**不令人厌倦**，是说它不会让人饱足，就像美味的食物一样」，不再补动词。

### 🟨 warning

- `182-1773-2-4`｜关键词语意不明确｜片段「理由经」
  - 问题：`Ṭhāna` 在本经里指「可据以了知的四种事项／依据」（cattāri ṭhānāni catūhi ṭhānehi veditabbāni），译「理由」会被读成「原因」，与经文「以共住知戒、以言谈知净、以危难知力、以讨论知慧」的结构不合。本层复注未glos该词，现无义注可据。
  - 建议：暂改「处经」或「依据经」，并在取到父层义注后复核定案；`182-1782-2-4` 同一译名需同步（片段「理由经的注释结束」）。
- `182-1774-56-74`｜关键词语意不明确｜片段「存心“我要来把握他的戒行”」
  - 问题：「存心」在现代汉语里多带贬义（存心害人），而此处 `manasikaronta` 是正面的作意、留心。
  - 建议：改「抱着“我要来把握他的戒行”这样的想法，用心留意并反复观察的人才能知道」。
- `182-1779-6-23`｜不导致误解的汉语语病｜片段「就像走进一所没有门的房子一样走来走去」
  - 问题：`advārakaghara` 是「无（出）门之屋」，喻找不到出路；汉语说「走进一所没有门的房子」自相矛盾（没有门如何走进），读者会卡住。
  - 建议：改「就像进了一间找不到门的屋子，只能团团打转」。
- `182-1781-8-15`｜整句逻辑表达不规范｜片段「财产的灾祸就是**财产之灾**」
  - 问题：原文是「以释语先、被释复合词后」（`Bhogānaṃ byasanaṃ bhogabyasanaṃ`），直移到汉语成了同义反复，读者看不出在解释什么；且「之」为文言虚词，与 style.md 第一节冲突（此处虽作固定词组，仍宜避开）。
  - 建议：调成被释词在前——「**财产之灾**（bhogabyasana）就是财产遭受的灾祸，意思是由于国王、盗贼等而丧失财产」。
- `182-1781-26-35`｜关键词语意不明确（语域不当）｜片段「**问难的路数**」
  - 问题：「路数」口语且常带贬义（路数不对），作术语译名不稳；`pañhummagga` 是「问题的进路／提问的门径」。
  - 建议：改「**问难的门径**」或「**提问的进路**」，并在取到父层后与被解释词统一。

### 🟦 suggestion

- `182-1774-75-80`｜语言风格不统一｜片段「**有智慧的人**，就是说这一点也只有有智慧的贤者才能知道」
  - 问题：lemma 与释语都落到「有智慧」，在汉语里成了同义循环；`sappañña`（有慧）与 `paṇḍita`（贤者）的区分没体现。
  - 建议：lemma 保「**有智慧的人**」，释语改「也只有具备智慧的贤者才能知道」。
- `182-1774-56-74` / `182-1774-75-80`｜语言风格不统一｜片段「**要留心观察的人**」
  - 问题：工具格 lemma 一律译成「…的人」，而 `182-1774-30-46` 的 lemma 译成了完整谓语句（「**而且要经过很长的时间，不是短时间**」），同段内 lemma 体例不一致。
  - 建议：统一为「由…才可了知」式或统一为名词式，全章一个体例。
- `182-1774-2-11`｜语言表达不够流畅｜片段「**依共同生活**（saṃvāsena）就是依一起居住」
  - 问题：「依+名词」连用两次，略生硬。
  - 建议：「**依共同生活**（saṃvāsena）就是通过一起居住（来了解）」。
- `182-1774-12-29`｜语言表达不够流畅｜片段「这个人是持戒的，还是破戒的」
  - 问题：`dussīla` 是「品行恶劣／戒行不好」，「破戒」会被读成已犯具体戒条的既成事实。
  - 建议：改「这个人戒行好，还是戒行不好」。
- `182-1778-115-129`｜代词指代可能不够明确｜片段「为了说明这一点，才这样说」
  - 问题：`pakāsento evamāha` 的施事（世尊）未补出，`182-1779-24-36`「所以说」、`182-1781-16-25`「所以说」同样省略，读者不易确定是谁在说。
  - 建议：至少在首次出现处补出主语（「因此（世尊）这样说」），全章保持一致。
