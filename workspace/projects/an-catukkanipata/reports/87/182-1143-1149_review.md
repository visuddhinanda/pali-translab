## 一、被解释词与父层逐字对照（硬约束，首查项）

核对通过（逐字相同）：世间 / 苦谛（`“世间指的是苦谛”`）/ 不为整个世间所系缚 / 如来 / 了知 / “比丘们，凡是” / 被看见的指的是色处 / 被听到的 / 被觉知的 / 被认知的 / 被获得的 / 被寻求的 / “经过寻求，或者没有经过寻求” / “以乐、苦等为内容的法所缘” / 被心反复游历过的 / 心生喜悦 / 心生不悦 / 保持中性 / 没有获得的 / “没有用智慧亲自证得的”。
`**不为整个世间所系缚**` 在本层是孤立词条，带「整个世间」略显冗长，但按父层逐字规则保留是**正确**的，不要改。
§1148-22-42 把义注的说法明确标为「不过义注里说的是……」，层次标注正确，这是本 chunk 的正面样板——问题在于同样的情形在别处没有这样标（见第三节）。

偏差项：

- **§1148 句 182-1148-152-172 — 必改**
  - **问题**：对位断裂 — 引语 `“pattaṃ vā appattaṃ vā”` 原样引自父层 §1089「**被寻求的**，指的是寻求了而获得的，或者寻求了却没有获得的」，父层把这两个词译作「寻求了而获得的／寻求了却没有获得的」，本层却译成「获得了的，或者没有获得的」，读者无法对位。（父层在 §1090 另一处把 `appattaṃ` 简译为「没有获得的」，所以本层用词本身不算错译，但这里引的是 §1089。）
  - **建议**：改为 `**“寻求了而获得的，或者寻求了却没有获得的”**`；前半句已说明「两种情况都同样是寻求过的」，重复不碍事，可读性让位于对应关系。
- **§1149 句 182-1149-2-9 — 必改**
  - **问题**：`**Pītakantiādī**` 父层 §1090 作「**黄色等**色所缘」，本层作「**黄色等等**」，多一字即对位不严；且本层把 `ādi saddena` 统一译作「“等等”一词」，与被引词形不自洽。
  - **建议**：词条改「**黄色等**」，`ādi saddena` 改「用**“等”**一词」（§1149-38-64 同处一并改），全层统一。
- **§1148 句 182-1148-99-107 — 轻微偏差**
  - **问题**：引语 `“patvā gahetabbato”` 在父层 §1089 作「**被觉知的**，**由于要接触到才能把握**，指的是香处……」，带「由于」对应夺格 `-to`；本层引作「“要接触到才能把握”」，丢了夺格。
  - **建议**：改为 `**“由于要接触到才能把握”**`，机械核查才能对上。
- **§1149 句 182-1149-88-100 — 轻微偏差**
  - **问题**：`**Tatheva** **gatattā**` 父层 §1091 对应处作「他就正是那样**如实地了知了**」，本层作「**由于正是那样地了知了**」，少「如实」，与父层字面不合。
  - **建议**：改为「**由于正是那样如实地了知了**」。

## 二、跨段一致性

- **tathāgatabhāva**：§1147-59 译「如来之性」，§1148-2 译「自己是如来」（与父层 §1089「说明自己是如来」一致）→ 统一为后者，依据：父层定稿 + 本层后出用法。「之」另属文言禁例，见第三节。
- **paṇava / mudiṅga**：§1149-38 把 `paṇavasaddo` 译「小鼓声」，但父层 §1090 的「小鼓声」是 `mudiṅgasaddo`，两词撞车，读者会以为是同一项 → 建议 `paṇava` 改「铜鼓声（paṇava）」或「手鼓声」，把「小鼓声」留给 mudiṅga。
- **saṃyojana / yoga / gantha**：§1144-31 `sabbesaṃ saṃyojanānaṃ` 译「一切系缚」，而父层 §1092 的「四种系缚」是 `yoga`、「四种结缚」是 `gantha` → 本层的「一切系缚」会被读成那四个 yoga。建议首次出现夹注：「一切系缚（saṃyojana）」。
- **vitakka / vicarita**：§1149-18 用「寻思」译 `vitakka`，而父层 §1089 的「心所反复寻思的」是 `anuvicarita` → 建议 §1149 作「寻思（vitakka）」夹注区分。
- **eseva nayo**：§1148-81 译「也是同样的方式」，§1149-34 译「都是这个方式」→ 统一为「同样的方式」。
- **paccakkha**：§1144-60 译「亲身现证」，父层 §1088 作「亲自现证」→ 统一「亲自现证」。
- **ñāta / gata** 的分工（gata=了知、ñāta=知晓）本层前后一致，且让父层强制的「了知=gata」保持唯一对应，这是对的，**不要**改回去。
- **引语主语**（义注 vs 世尊）在本 chunk 内不统一，见第三节首条。

## 三、逐句意见

### §1144 句 182-1144-22-30
- **问题**：层次标注 — 「因此**他**说」的「他」指义注作者（所引 `“lokoti dukkhasaccan”` 正是父层 §1088 的义注原文），但读者极易读成世尊。skill 规定引义注必须标明层次；本层 §1148-22-42 自己已用「义注里说」，前后也不一致。
- **建议**：改「因此义注说——」。**同类必改处**：§1148-99-107、§1148-112-124、§1148-135-145、§1148-152-172、§1149-73-81（均引父层义注原文，一律作「因此义注说／所以义注说」）；§1148-53-80「由此**他**显示」、§1148-173-184「**他**用这两句显示」主语亦是义注，改「由此可见／义注由此显示」「义注用这两句显示」。反之 §1145-19-20 的 `Yathāha` 所引是《相应部》《无碍解道》经文，主语是世尊 → 改「正如世尊所说——」。

### §1144 句 182-1144-2-11
- **问题**：可读性 — 「是由于会破坏、会崩毁的意思而称为世间」，「由于……的意思而」生硬。
- **建议**：「**世间**，因为有破坏、崩毁的意思，所以叫做世间。」

### §1144 句 182-1144-31-44
- **问题**：`tato vippamutto` 译「从那里获得了解脱」，「那里」指代空悬。
- **建议**：「因此从一切系缚中解脱了出来」。术语夹注见第二节。

### §1144 句 182-1144-60-64
- **问题**：用词不一致（见第二节）+ 句式绕 — 「是指已经使它成为自己亲身现证的」。
- **建议**：「**已亲自证得**，是指已经使它成为自己亲自现证的事。」

### §1144 句 182-1144-65-72 — 必改
- **问题**：术语 — `ariyo aṭṭhaṅgiko maggo` 译「八支圣道」，与 `term-glossary.jsonl`（`aṭṭhaṅgika magga` → 八正道，status=confirmed）及 `style.md`「常见术语用传统汉译：……八正道」相悖。
- **建议**：「是指含摄戒等三蕴的八正道。」`sīlādikkhandhattaya` 建议首次夹注「三蕴（khandha）」。

### §1144 句 182-1144-73-87 — 必改（文言）
- **问题**：风格 — 「圣者们为了那个目标而**依之**修行」，「之」是文言虚词，`style.md` 第一节明列禁例。
- **建议**：「圣者们为了达到那个目标而依照它修行」。同一问题见 §1147-2-16 的「到达、依之修行」→「到达、依照它修行」。

### §1147 句 182-1147-59-65 — 必改（文言 + 一致性）
- **问题**：「按照显明**如来之性**这个意思来理解」——文言「之」；且与父层「说明自己是如来」、本层 §1148-2「显明了自己是如来」不统一。
- **建议**：「这样，这段经文的含义就应当按『显明世尊是如来』这一点来理解。」

### §1148 句 182-1148-2-21
- **问题**：可读性 — 「现在为了也以在那当中彻底觉悟被看见的等等来说明这一点」，三层介词套叠，读不下来。
- **建议**：「……现在为了再从『在那当中彻底觉悟了被看见的等等』这一点来说明它，就说了**“比丘们，凡是”**等这段话。」（父层对应句式可参照 §1089。）

### §1148 句 182-1148-53-80
- **问题**：① `yaṃ samavāye passeyya` 译「在会合的场合可能看见的」——`samavāya` 指众缘聚合，「场合」失义；② `“duddhan”` 译「被挤出的奶」，读者看不出它为何能作例证（它是个不限时态的过去分词）；③ 主语「他」见第三节首条。
- **建议**：①「在因缘聚合时会看见的」；②「就像“已挤的（奶）”这个说法一样」，并考虑加一条脚注说明「它是过去分词却不限于过去」——这才是举例的要点。

### §1148 句 182-1148-81-85
- **问题**：搭配 — 「在**被听到的**等等**词上**也是同样的方式」。
- **建议**：「对**被听到的**等等也是同样的方式。」

### §1148 句 182-1148-90-98 — 存疑
- **问题**：`sanissaye indriye nissayaṃ muñcitvā pāpuṇitvā gahetabbaṃ` 译「在带有依处的根上，离开所依而到达了才能够把握的东西」——字面直译，但「离开所依」指谁离开谁不明；按下句所引义注「由于要接触到才能把握」，这里讲的应是香、味、触三者必须与根接触（不像色、声可隔距而取）。现译让读者无从把握要点。
- **建议**：改为「**被觉知的**，是指对于有所依的根来说，必须让对象离开自己的所依、接触到了才能把握的东西。」若仍不确定，保留直译但压低该句 confidence，并在定稿前以 nissaya 的格助词复核 `sanissaye indriye`（处格）与 `nissayaṃ`（宾格）的归属。

### §1148 句 182-1148-112-124
- **问题**：冗赘 — 「脱离了被看见的等等**之外而**可以被认知的」，「脱离……之外」语义重复。
- **建议**：「而由于那是在被看见的等等之外另有的可认知之物，所以义注说——**“以乐、苦等为内容的法所缘”**。」

### §1149 句 182-1149-10-17
- **问题**：`rāgavasena lobhavasena` 译「由于贪染、由于贪欲」，两词在汉语里几乎同义，看不出义注为何并列。
- **建议**：首次出现夹注：「由于贪染（rāga）、由于贪欲（lobha）」。

### §1149 句 182-1149-18-25 — 必改
- **问题**：`byāpādavitakka` / `vihiṃsāvitakka` 译「害心的寻思」/「伤害的寻思」，两者几乎无从区别，而这是一组固定对举的术语。
- **建议**：「由于瞋害的寻思（byāpāda-vitakka），或者由于恼害的寻思（vihiṃsā-vitakka）」。

### §1149 句 182-1149-26-33
- **问题**：「由于有智而保持中性」，「有智」单音节化。
- **建议**：「或者由于具有智慧而保持中性」。

### §1149 句 182-1149-34-37 — 必改（文言）
- **问题**：「**在一切处**都是这个方式」——半文半白，且与 §1148-81 用词不一。
- **建议**：「其余各处也都是同样的方式。」

### §1149 句 182-1149-38-64 — 存疑
- **问题**：① `paṇavasaddo` 与父层撞词（见第二节）；② `upādinnaṃ anupādinnaṃ` 译「被执取的、不被执取的」，作为触所缘的举例，传统译法多作「所执受的／非所执受的」（指业生与非业生），现译易误读为「被人抓住的」。
- **建议**：②改「所执受的、非所执受的（upādinna / anupādinna）」，或保留现译但加夹注；拿不准就压低 confidence，不要在译文里留标记。

### §1149 句 182-1149-82-87 — 必改（最严重）
- **问题**：格读自相矛盾 — 同一行里词条译「**世间被了知**」（把 loka 当被了知的对象），释义却译「就是被世间所知晓」（把 `lokena` 当具格施事）。本层义注原文 `Lokena gatanti lokena ñātaṃ` 明确是具格（由世间），所以词条译错。
  **与父层的分歧需记录**：父层 §1091 定稿作「世间是以怎样的实况被了知的，他就正是那样如实地了知了」，是把 loka 读成被了知的对象，与本层 ṭīkā 的具格释读不一致。按规范以上层义注为释义标准、本层不得改父层定稿，故此处只能在译文中忠实呈现 ṭīkā 的读法，并把分歧留在本报告。
- **建议**：改为「**被世间所了知的**，就是被世间所知晓的。」若后续 harmonize 需要父层与本层口径统一，这属于父层定稿的释读问题，应另起议题，不要在本层悄悄抹平。

### §1149 句 182-1149-88-100
- **问题**：除第一节的「如实」缺失外，`gatasaddena ekattaṃ buddhiatthaṃ` 译「与“知解”同义」——「知解」是自造词，且父层 §1091 把 `ekatthaṃ` 译作「意思相同」。
- **建议**：「意思是：它与“了知”（gata）一词意思相同，而该词的意义就是『知』。」`buddhi-attha` 若要保留专名，建议作「知的意义（buddhi-attha）」并与 §1149-101 的「知解的意义」统一（现为两种说法）。

### §1149 句 182-1149-101-107
- **问题**：轻微 — `akkharacintakā` 译「语法学者们」可接受；`buddhiatthā` 与上一句用词不一（见上条）。
- **建议**：「因为声明学者们（akkharacintaka）说，表示行走意义的词根也具有『知』的意义。」
