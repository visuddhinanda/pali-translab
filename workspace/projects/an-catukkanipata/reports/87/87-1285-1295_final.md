## 理由

**基准缺失说明**：本次注入的资料只有本文（mūla）巴利原文与 channel 译文，**没有义注（aṭṭhakathā）、没有 nissaya**。因此"义注定释义、nissaya 定词法"两条基准都无法执行，词级覆盖与格/句法角色的核对只能依据巴利原文本身与四部《增支部》平行段落的常规读法。本报告的准确性评分与问题定级据此下调信心指数（68），其中涉及取义分歧的条目（`paṭibhaṇḍati`、`vacanapathānaṃ` 等）在拿到义注后应复核。

**准确性**：整体句法骨架正确，四种 paṭipadā 的框架、六根防护句式、五个动词串（pajahati / vinodeti / sameti / byantīkaroti / anabhāvaṃ gameti）都完整落地，无漏译、无显著增译。主要扣分集中在三点：（1）`bhaṇḍantaṃ paṭibhaṇḍati` 译作"对打他的人就回打"，把语言行为误作肢体行为——`bhaṇḍati` 是"争吵、口角"，与前两项 `akkosati`（骂）/ `roseti`（恼怒、冒犯）构成语言三连，译成"打"属错译且破坏了三项的递进。（2）`yatvādhikaraṇam enaṃ … anvāssaveyyuṃ, tassa saṃvarāya paṭipajjati` 译为"由于他不防护眼根而住，……就会侵袭他，他便为防护眼根而修行"，把条件句读成了既成事实的因果句——原文是"因为（若）不防护眼根而住，恶不善法会侵入，所以他为防护而行道"，译文现在的表述暗示他已经不防护了，与紧接着的"守护眼根"自相矛盾。（3）`vātātapa` 拆成"风吹、日晒"可，但 `duruttānaṃ durāgatānaṃ vacanapathānaṃ` 译"恶意冲来的言语"中 `durāgata` 通常解作"不受欢迎的 / 不中听的"，"冲来"是字面化的意译，偏生硬。

**风格**：现代书面汉语达标，无文言虚词、无文言句式，未出现 `style.md` 禁例表中的写法。标点为全角，无 ASCII 引号，无残留工作标记。小幅扣分在"实行防护""生性能够忍受"两处略带公文/翻译腔，以及 1292/1293 两段长句一个句号内堆叠过多并列成分，对一般读者偏重。

**一致性**：术语全段统一（paṭipadā→行道、khama→忍耐、dama→调御、sama→止息、nimitta→形相、anubyañjana→细相、indriya→根、saṃvara→防护），1286/1287 与 1292/1293 的正反对举句式严格对称，1288 与 1294 的六根段用词一致。唯一不一致是夹注巴利原词的处理：1289 给 `kāmavitakka` / `byāpādavitakka` / `vihiṃsāvitakka` 加了圆括号夹注，1295 同样三词却全部无夹注——按 `style.md`"首次出现夹注、其后只用汉译"的规则，1295 不夹注本身正确，但 1289 中 `byāpādavitakka` 与 `vihiṃsāvitakka` 出现在省略号（…pe…）之后的缩略列举位置，此处夹注反而打断了缩略体例。

## 问题清单

### 🟧 error
- `87-1286-39-64`｜错译（词义）｜片段「对打他的人就回打」
  - 问题：`bhaṇḍantaṃ paṭibhaṇḍati` 的 `bhaṇḍati` 义为"争吵、口角、斗嘴"，是语言行为，不是"打"。原文三项 `akkosantaṃ paccakkosati / rosantaṃ paṭirosati / bhaṇḍantaṃ paṭibhaṇḍati` 同属言语相争的递进，译成"打"引入了肢体暴力，既是词义错译，也破坏了三项的同类并列。
  - 建议：改为"对与他争吵的人就回头争吵"或"对跟他吵的人就跟他吵回去"。
- `87-1287-12-28`｜错译（词义）｜片段「对打他的人不回打」
  - 问题：同上，`bhaṇḍantaṃ na paṭibhaṇḍati` 误作肢体打击。与 1286 对举句一并需改，否则正反两段同错。
  - 建议：改为"对与他争吵的人不回头争吵"。
- `87-1288-25-39`｜错译（修饰关系 / 句式）｜片段「由于他不防护眼根而住，贪欲和忧恼这些恶的、不善的法就会侵袭他，他便为防护眼根而修行」
  - 问题：`yatvādhikaraṇam enaṃ cakkhundriyaṃ asaṃvutaṃ viharantaṃ … anvāssaveyyuṃ` 是以 `anvāssaveyyuṃ`（愿望/可能语气）表达的条件设想——"由于若不防护眼根而住，恶不善法便会侵入"，`tassa saṃvarāya paṭipajjati` 的 `tassa` 回指"那（眼根）"。译文用"由于他不防护眼根而住……就会侵袭他"陈述为已然事实，与紧接的"他守护眼根"矛盾，读者会理解为此人既不防护又在守护。
  - 建议：改为"因为若不防护眼根而住，贪欲和忧恼这些恶的、不善的法就会侵入，所以他为防护眼根而行道"。
- `87-1288-72-86`｜错译（修饰关系 / 句式）｜片段「由于他不防护意根而住」
  - 问题：同 `87-1288-25-39`，意根段同一条件句被陈述化。
  - 建议：同上，改作"因为若不防护意根而住……"。
- `87-1294-51-64`｜错译（修饰关系 / 句式）｜片段「由于他不防护意根而住」
