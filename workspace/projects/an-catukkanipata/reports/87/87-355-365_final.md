## 理由

**资源缺失（影响信心）**：本次只注入了巴利原文与 channel 现有译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。按方法文档，释义标准与词级基准都无法核对，因此准确性一项只能依据巴利文本本身的词法与句法作判断；凡涉及传统取义的词（下文 `yasassino`、`tādino`、`vijambhati`）只能标为待核，不作扣分定论。信心指数因此压到 62。

**准确性**：散文部分（356、357）词覆盖完整，无漏译；连续体（`nikkhamitvā / vijambhitvā / anuviloketvā / naditvā`）的承接关系逐句对应正确；三联近义词 `bhayaṃ saṃvegaṃ santāsaṃ` 在 356 与 357 两处译法一致，`aniccā / addhuvā / asassatā` 与 `niccaṃ / dhuvaṃ / sassataṃ` 的三组对立也分别用「无常／不持久／不永恒」区分开，没有混同，这是本段最扎实的地方。版本异读（`udakaṃ udakāsayā`、`sakkāyassa atthaṅgamo`）两处都如实译出并给了出处，没有擅自取舍。

扣分集中在偈颂（358–365）。这组偈是**一句话**：`Yadā buddho … pavattayī`（时间从句）→ `Yepi dīghāyukā devā … bhītā santāsamāpāduṃ`（主句），`satthā appaṭipuggalo` 是 `buddho` 的同位语，`Sakkāyañca … maggaṃ` 四个宾格受 `pavattayī` 统辖。译文把同位语改成了独立判断句「他是……世间之师」，又给宾格群补出谓语「他宣说」，结果 358 的「当……的时候」全程悬空，362–363 天神受惊与转法轮之间的时间呼应断掉。坐标按段切分、不能合并，这确实构成约束，但可以在不动坐标的前提下用「正当……转动法轮之时」「——那时」一类承接词把呼应保住。

**风格**：现代书面汉语的大方向守住了，没有「此中／故为／彼等／答以」一类禁例。但残留三处文言属格「之」（「有身之灭」「世间之师」「有身之中」），且与同一组偈中「苦的止息」「有身的生起」的「的」字处理不统一；「悚惧」属现代读者不常用的词。按 style.md 的判定标准（读给无古文基础的读者），「世间之师，无人能与他相比」一句最接近文言腔。

**JSON 安全**：全文检查无 ASCII 双引号或单引号，引号一律全角 “” ‘’，符合硬约束。

**一致性**：术语与重复句式（`evaṃ mahiddhiko / mahesakkho / mahānubhāvo` 两次均作「神力／权势／威势」）对齐良好；但偈颂四段各自开了全角左双引号 “ 而全程未闭合，`’’ ti` 的收尾引号在 87-365-2-20 丢失，共 4 个未配对引号，这是本段最明显的格式缺陷。

## 问题清单

### 🟧 error

- `87-359-2-7`｜错译（修饰关系）｜片段「他是包括天界在内的世间之师，无人能与他相比」
  - 问题：`sadevakassa lokassa satthā appaṭipuggalo` 是主格、作 358 句 `buddho` 的同位语，整体仍在 `yadā` 从句内。译成独立判断句后，读者会理解为「佛在转法轮的那一刻才成为世间之师」，并使 358 的时间从句失去主句。
  - 建议：改为限定语形式，如「——他是包括天界在内的整个世间的导师，无人能与他相比——」，或并入 358 读作「当佛，这位……的导师，证知后转动法轮时」。

### 🟨 warning

- `87-365-2-20`｜标点符号使用错误｜片段「才这样想的［参见《相应部》3.78］。」
  - 问题：原文 `’’ ti` 的收尾引号未译出。偈颂 358／360／362／364 各开一个全角左双引号 “，全段无一处闭合，共 4 个引号未配对。
  - 建议：本句末补「”」；并把 360／362／364 多余的开引号去掉，整组偈只在 358 开、365 闭。
- `87-357-29-69`｜文言语体｜片段「这就是通向有身之灭的道路」
  - 问题：文言属格「之」；且与同段「有身的生起」「有身的灭」的「的」字处理不统一。
  - 建议：「这就是通向有身灭尽的道路」。
- `87-357-127-138`｜文言语体｜片段「是包含在有身之中的」
  - 问题：同上，「之中」为文言属格残留，且 `sakkāyapariyāpannā`（被有身所摄）译成「包含在……之中」语义偏松。
  - 建议：「我们都在有身的范围之内」或「我们都属于有身」。
- `87-358-2-12`｜整句逻辑表达不规范｜片段「当佛证知之后转动法轮的时候，」
  - 问题：「当……的时候」从句直到 365 都没有对应主句（主句应是 362–363 的天神受惊），读者读到结尾无法回扣。
  - 建议：保留从句，但在 362 句首补出呼应，如「那时，就连那些……的天神」。
- `87-360-2-12`｜整句逻辑表达不规范｜片段「他宣说有身和有身的灭，也宣说有身的生起」
  - 问题：`Sakkāyañca nirodhañca … sambhavaṃ` 是 `pavattayī`（转动法轮）的宾格，译文另补谓语「宣说」，把一句拆成两件事；且「也宣说」与 361「还宣说」重复堆叠。
  - 建议：改为承接 358 的法轮，如「他所转的法轮宣示了有身、有身的灭和有身的生起」，361 续作「以及通向苦止息的八支圣道」。
- `87-362-2-10`｜关键词语意不明确｜片段「随从众多的天神」
  - 问题：`yasassino` 取「随从众多」是义注系取义（yasa = parivāra）之一，但也常作「有大名声／有威势」。本次未取到义注，无从核定；译文又未加注，读者无法判断。
  - 建议：按义注核定后定稿；若取「随从众多」宜加简注，否则用与散文段 `mahesakkho`（权势）同一体系的「有大威势」。
- `87-356-41-62`｜关键词语意不明确｜片段「恐惧、悚惧和惊骇」
  - 问题：「悚惧」非现代常用词，与 style.md「能用双音节现代词」的要求有张力；三个近义词连排，读者难以分辨 `bhaya / saṃvega / santāsa` 的差别。（同一译法另见 `87-357-70-92`，一并处理。）
  - 建议：统一改为「恐惧、震动和惊骇」一类现代词，或保留三联但首次出现夹注巴利原词。

- `87-356-108-134`｜复杂的嵌套句整句语言逻辑理解困难｜片段「就连那些在村落、集镇、王都里被坚韧皮索牢牢捆住的国王的象」

  - 建议：拆为「就连国王的那些大象——它们在村落、集镇、王都里被坚韧的皮索牢牢捆着——也会……」。

  - 建议：「通向苦之止息的八支圣道」会引入文言「之」，宜作「通向苦止息的八正道」。

  - 问题：「惊恐」与「惊骇」近义相叠，读来重复。
  - 建议：「也都害怕得陷入惊骇」或「也都因恐惧而战栗」。

  - 建议：按传统作「无上士、调御丈夫」，或明确合为「无上的调御丈夫」并保持与前后分隔一致。
- `87-365-2-20`｜代词指代可能不够明确｜片段「他们是听了那位已彻底解脱、不为得失所动的阿罗汉的话」

  - 建议：「那些天神是听了……才这样想的」；`tādino` 按义注核定后定稿。
