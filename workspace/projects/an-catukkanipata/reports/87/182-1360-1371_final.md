## 理由

**基准缺失（降级说明）**：本次只注入了巴利原文与待评译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此无法按「义注定释义、nissaya 定词法」逐句核对，所有判断只能基于巴利原文本身、上下文连贯性与 knowledge 配置。两处尤其无法核验，信心指数因此压到 68：

1. **被解释词与父层逐字同译**这条硬约束无法验证。本段是复注，黑体引自义注（`ukkāhi dhāriyamānāhi` / `Vijjantarikāyā` / `Antarato` / `Ayojiyamāne upayogavacanaṃ na pāpuṇāti` / `Sakalajambudīpe … vūpasametvā` 等），这些词的汉译必须与义注层译文字字一致。报告中对被解释词的意见（见 🟧/🟨 各条）须先与义注译文比对后再定取舍；若义注层已这样译，则应改义注层而非只改此处。
2. `pāṇini 3.2.5` 与 `mūlavibhūjādipakkhepena` 的具体所指（波尼尼规则编号与词群名）无第三方文献可核，译文照搬未判对错，此处不扣分。

**准确性**：长难句处理是本段的亮点。`182-1362-19-85`（三重引文嵌套 + 「应举 antarā 而不应举 antara/antarika」的对比结构）与 `182-1363-2-19`/`37-54`（同义互通、加 `ika` 扩词、所举例与应举例无矛盾）均理解正确，`tadantaraṃ` 取「缘由」义、`kāraṇavemajjha` 的两义切分、`cittakkhaṇavivara` 的三义切分都到位，没有把语法讨论译糊。故事段（`1364-*`）的格关系（`sesarājūhi … kataṃ vivādaṃ`、`mallehi saddhiṃ`、`dhātūnaṃ atthāya`）与偈颂的跨行句（`na hi sādhu yaṃ … siyā sampahāro` 拆在 1367/1368 两行）都没有错。

扣分主要来自一处时体与主语的增译（`1364-2-32`「他将平息」，绝对分词译成将来式，且与同句后文「他平息了这场争执」自相矛盾），以及几处词义偏移（`na jāniṃsu`→「没有听进去」）与被解释词的增译（`Vijjantarikāyā`→「借…」）。无 fatal：未发现主谓宾判断错误，也无违背基本教理之处。

**风格**：现代书面汉语达标，这是本段最稳的一项。全篇未见 `style.md` 禁例表中的文言虚词与句式（无「此中/故为/彼等/于…之际/答以」），`便/遂/乃/谓` 均未出现，「就」「于是」「所以」等现代连接词使用自然。标点全角合规，引号统一用 “” ‘’，未出现直角引号，`zh` 字段内无 ASCII 引号，JSON 安全无风险。扣分点只有「良家」一处单音节文言色彩残留，以及引文省略号的添加。

关于语法段保留拉丁词形（`antarā` / `antara` / `antarika` / `ika` / `antarikā` / `mūlavibhūja`）：`style.md` 第三节写「显示巴利原文：否」，但本段是对 antara- 一族**词形本身**的讨论，不出示词形则论证不可读。**这属于「偏离配置但确有依据」，不扣准确性与风格分**，只在一致性里计入「三套策略混用」的代价，并建议在 `style.md` 补一条语法讨论的例外条款。

**一致性**：三个问题。一是 `vemajjha` 在 `1362-10-14` 译「之间」、在 `1362-19-85` 译「中途」；二是同一个 antarā 既作被解释词译成汉语「中途」，又在讨论里以拉丁 `antarā` 出现，而 `1363-20-36` 又把被讨论的词形 `yassantarato` 换成义译「内心之中」——同一个词在三句里有三种呈现方式；三是专名策略分叉：`Ukkaṭṭhā`/`Setabya` 走音译（郁伽罗/设多毗亚），antara- 一族走拉丁，读者难以建立预期。`dhātu`「舍利」与 `sarīra`「遗体」并用虽各自正确，但指同一事，宜在偈颂处点明。

## 问题清单

### 🟧 error

- `182-1364-2-32`｜错译（时体错误 + 主语增译）｜片段「他将平息整个瞻部洲兴起的大争执」
  - 问题：`vūpasametvā` 是绝对分词，意为「平息了…之后」，原文无将来时、无显性主语。译作「他将平息」既增译了主语「他」，又把已成事实说成未发生；同一句的释义部分又译「他平息了这场争执」，一句之内时体自相矛盾，读者会以为复注在预言而非解释已发生的事。
  - 建议：改为「**平息了整个瞻部洲兴起的大争执**」（被解释词按义注层措辞定稿，须与义注译文逐字一致）。

### 🟨 warning

- `182-1362-2-5`｜关键词语意不明确｜片段「借电光一闪的瞬间」
  - 问题：原文 `Vijjantarikāyā` 无「借」义，「借」把处格/具格的时点关系改写成了手段关系，是无据增译。更要紧的是，下文 `1362-19-85` 要论证 `antarikā` 用于「间隙（vivara）」一义、不该作 antarā 的例证，而此处译成「一闪的瞬间」完全抹掉了「间隙」的构词线索，使后面的论证无从落地。
  - 建议：改为「**在电光的间隙里**」或「**电光一闪之间**」，保留 antarikā 的「间隙」义；是否最终采用，以义注层该词译法为准。

- `182-1363-20-36`｜关键词语意不明确｜片段「在“内心之中”这一句里」
  - 问题：本句讨论的是词形——`antarā` 为了偈颂顺口而**短音化**成 `antara`。译文把被引的词形 `yassantarato` 换成了汉语义译「内心之中」，汉语里看不出任何「短音」可言，读者无法理解「把它变成短音」指的是什么。同段 `1363-37-54` 却保留了拉丁 `antarikā` 与 `ika`，处理方式前后不一。
  - 建议：引文处保留词形，如「在“yassantarato（内心之中）”这一句里」。

- `182-1362-19-85`｜关键词语意不明确（术语不一致）｜片段「原因和中途这两义」
  - 问题：`vemajjha` 在 `1362-10-14` 译作「之间」（「在开始与完成之间」），此处同一词译作「中途」，读者不会意识到这里回指的正是上文那一义。
  - 建议：统一为「原因和中间这两义」，并在 `1362-10-14` 的释义中保持同一用词。

- `182-1364-72-79`｜错译（词义偏移）｜片段「连一个词都没有听进去」
  - 问题：`na jāniṃsu` 是「不知道、没听明白」，指认知结果；「没听进去」偏向注意力/态度。下一句转折点在于第二诵分结束时他们**听出**那是老师的声音，对应的反面应是「没听明白」而非「没留意」。
  - 建议：改为「连一句都没有听明白」。

- `182-1364-100-120`｜文言语体｜片段「出生在良家的人里」
  - 问题：`kulaghare jāto` 译「良家」属单音节文言词残留，现代读者只在「良家妇女」固定搭配中见过此词，单用显得文言。
  - 建议：改为「出生在有地位的人家里」或「出生在名门人家的人里」。

### 🟦 suggestion

- `182-1362-6-9`｜语言表达不够流畅（被解释词与释义同义重复）｜片段「是指在心里」
  - 问题：全句成为「内心之中，是指在心里」，汉语里被解释词与释义几乎同形，这条注释读起来是空转。同类情况见 `182-1362-15-18`「是指在两者中间的地带」与 `182-1361-2-19`「是指举着火炬」。
  - 建议：被解释词后夹注巴利原词以显出所释对象，如「**内心之中**（antarato），是指在心里」；此改动涉及与义注层的逐字对齐，宜在 harmonize 阶段连同义注层一起定。

- `182-1362-19-85`｜语言风格不统一｜片段「antarā 一词」
  - 问题：全段对巴利词有三套呈现：音译（郁伽罗、设多毗亚）、拉丁原形（antarā / antara / antarika / ika / mūlavibhūja）、纯义译（内心之中、中途）。语法讨论保留拉丁是必要的，但首次出现未加任何说明，一般读者不知 antarā 是什么。另 `antarāsaddā` 是复数，译「antarā 一词」略窄。
  - 建议：首次出现处加简注，如「antarā（表「中间、由于」的词）」；并在 `knowledge/style.md` 第三节补一条「语法/构词讨论可保留拉丁词形」的例外，避免后续段落反复摇摆。

- `182-1361-37-57`｜语言表达不够流畅｜片段「它立在火把之中」
  - 问题：`Ukkāsu ṭhāti ukkaṭṭhā` 是构词推导式（`ukkāsu` + 词根 `ṭhā` → `ukkaṭṭhā`），译成完整小句「它立在火把之中」会被读成一句陈述，推导关系丢失。
  - 建议：明示为推导，如「“在火把之中”加上词根 ṭhā（立），构成**郁伽罗**」。

- `182-1361-37-57`｜不常用术语编写注释或者百科｜片段「波尼尼 3.2.5」
  - 问题：`Pāṇini` 首次出现未夹注原名，`mūlavibhūja` 词群对读者完全陌生，无法判断这是梵语语法书的规则编号。
  - 建议：「波尼尼（Pāṇini）3.2.5」，并为 mūlavibhūjādi 加一句脚注说明这是梵语语法的一类构词词群。

- `182-1364-33-71`｜不常用术语编写注释或者百科｜片段「长达两个诵分的那番话」
  - 问题：`bhāṇavāra`「诵分」是巴利文献的篇幅计量单位，一般读者不知其量级，「两个诵分」传达不出「讲了很长一段」的实感。
  - 建议：首次出现加注说明（约八千音节的诵读单位），或作「两个诵分（bhāṇavāra）那么长的一番话」。

- `182-1368-2-5`｜代词指代可能不够明确｜片段「竟为分配遗体而动起手来」
  - 问题：散文部分用「舍利」（dhātu），偈颂此处用「遗体」（sarīra），两词各自对应原文、均无错，但指的是同一件事，读者可能当成两回事。
  - 建议：此处作「竟为分配遗体（舍利）而动起手来」，或在 `knowledge/terms.md` 登记 dhātu/sarīra 的分工与首次互指方式。

- `182-1366-2-6`｜语言表达不够流畅｜片段「我们的佛陀生前宣说忍辱」
  - 问题：`khantivādo` 是「以忍辱为教说者」的表语名词，「生前」为补出成分；现译重心落在「宣说」这一行为，弱化了「佛陀本身就是忍辱的倡导者」这层定性。
  - 建议：「我们的佛陀是宣说忍辱的人」。

- `182-1362-19-85`｜标点符号使用错误｜片段「谁能知道其中的缘由呢……」
  - 问题：原文引语仅 `tadantaraṃ ko jāneyya`，译文加「……」暗示引文有省略；虽然增支部原句确有下文，但复注并未标示省略。
  - 建议：删去省略号，或在注释中补全所省部分。

- `182-1360-2-4`｜语言风格不统一｜片段「六、度那经义注」
  - 问题：本段属复注层，章题「Doṇasuttavaṇṇanā」是复注沿用义注的章题。译作「义注」在复注层的导出文件里会与层次标注冲突，读者可能误判所读层次。
  - 建议：若义注层同名章题已译「度那经义注」，则保持一致不动（硬约束优先），改由导出时的层次标记区分；若义注层译法不同，以义注层为准统一。
