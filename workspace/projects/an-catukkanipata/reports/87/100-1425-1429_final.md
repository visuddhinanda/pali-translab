## 理由

**数据基准缺失**：本次只注入了译文与巴利原文。被评段落本身就是义注层（`aṭṭhakathā`，book=100），没有更上层的复注可作释义对照；nissaya 也未注入（`versions` 结果不在上下文中），因此**词级格/句法基准缺位**。准确性判断只能依据巴利原文本身的词法形态、《增支部》四集结缚经／应辩经的教理语境与术语表，无法用 nissaya 核对词覆盖与格助词。这是信心压到 68 的主因——下列 error 条目中涉及格关系的判断（尤其 `100-1427-30-56`）若有 nissaya 支撑可升级确认，目前按原文形态判定。

**准确性**：绝大多数句子取义准确，被解释词（黑体 `upapattipaṭilābhiyāni` / `bhavapaṭilābhiyāni` / `sakadāgāmissa` / `yuttappaṭibhāno` 等）与本文层用词对应一致，逐字同译的硬约束守住了。扣分集中在两处：`100-1427-30-56` 把 `antarā upapatti natthi` 处理成「不会再有中途的投生」并把 `tattha` 译成「在所生的那一生中」，与中般涅槃者的教理定位相悖——中般涅槃者正是**已经投生**到净居天后、在寿量中途未及一半即般涅槃者，此处义注说的是「中间（指从一生到下一生之间）没有投生」，而 `tattha` 指「在那里（他投生之处）」，译文的「再」与「所生的那一生中」把时间关系做实了，可能引导读者误以为他另有一次投生；同句 `taṃ kusalattā … teva saṅkhyaṃ gacchati` 的 `teva`（= `tad eva`，强调「正是／仍旧只」）译作「仍然只被算作」尚可，但「由于是善的」漏掉了 `kusalattā` 与「算作投生有之缘」之间的推理语气。另一处是 `100-1427-2-15`：`Catutthassa paṭhame` 直译为「在第四个五十经集的第一经中」，「五十经集」（paññāsaka）是译者补出的、原文未出现的成分，属推断性增译，虽符合《增支部》注释书的习惯指称，但无 nissaya 佐证前应视为增译风险。

**风格**：整体现代书面汉语，口吻一致，第三人称叙述，没有发现 `style.md` 禁例表中的文言虚词或文言句式（无「此中／故为／彼等／于…之际」等）。「不过」「可是」「所以」「而」等连接词均为现代词。标点全角，无 ASCII 引号，引号统一为 “”，符合 JSON 安全约束。译文内无任何工作标记（候选／待定／问号／TODO），这一项干净。扣分来自 `100-1427-30-56` 的长句嵌套——「不过，中般涅槃者…可是他在…所入的禅定，由于是善的，仍然只被算作…」三层转折套在一句里，普通读者需要回读，属第四类可提升。

**一致性**：`saṃyojana` 统一作「结缚」，`upapattibhava` 统一作「投生有」，`orambhāgiya` 作「下分」，`sakadāgāmī` 作「一来者」，术语在段内与段间无漂移。`paṭilābhiyāni` 在 `100-1427-2-15` 译「导致投生的」、在 `100-1427-16-21` 译「导致获得有的」，两处构词处理方式不同（前者省去「获得」），虽各自通顺，但同一后缀在相邻两句呈现不对称，建议统一。标题层 `Paṭibhānasuttavaṇṇanā` 作「应辩经的解释」与 `Saṃyojanasuttavaṇṇanā`「结缚经的解释」格式一致。

## 问题清单

### 🟧 error
- `100-1427-30-56`｜义理或用词与注释书不符｜片段「中般涅槃者不会再有中途的投生」
  - 问题：`antarāparinibbāyissa antarā upapatti natthi` 说的是「中般涅槃者在（两生）中间没有投生」，即他不会在往生净居天与般涅槃之间再取一次生。译文加了「再」字并作「中途的投生」，容易让读者理解为他原本有一次中途投生、现在没有了；也可能被读成否定他的那次投生本身。
  - 建议：改为「中般涅槃者在中间并没有投生」或「中般涅槃者（在那一生与下一生）之间不存在投生」，去掉「再」字。

- `100-1427-30-56`｜错译（修饰关系）｜片段「他在所生的那一生中所入的禅定」
  - 问题：`yaṃ pana so tattha jhānaṃ samāpajjati` 中 `tattha`（处格副词）指「在那里」，即他投生之处；译文作「在所生的那一生中」把处所改读成时段，并补出「所生」这一原文没有的限定，与上一分句的时间关系纠缠在一起。
  - 建议：改为「他在那里所入的禅定」。

- `100-1427-2-15`｜错误多译｜片段「在第四个五十经集的第一经中」
  - 问题：原文 `Catutthassa paṭhame` 只有「第四（者）的第一（经）中」两个词，「五十经集」为译者补出。虽与《增支部》注书指称习惯相合，但在无 nissaya 佐证的情况下属增译，且与下句 `Dutiye` 译「在第二经中」（未补）形成不对称。
  - 建议：译作「在第四（五十经集）的第一经中」，把补出成分放进括号；或与 `100-1429-2-24` 统一处理方式。

### 🟨 warning
- `100-1427-22-29`｜关键词语意不明确｜片段「按最高的一位来取的」
  - 问题：`uttamakoṭiyā gahitaṃ` 意为「按最高限／上限而取」，指在结缚未断的圣者中以一来者为上限举例。译文「最高的一位」会被读成「某一个具体的人」，而原文说的是**类别的上限**。
  - 建议：改为「是按最高的那一类来举的」或「是取其上限而说的」。

- `100-1427-30-56`｜整句逻辑表达不规范｜片段「由于是善的，仍然只被算作“投生有的条件”」
  - 问题：`taṃ kusalattā … teva saṅkhyaṃ gacchati` 的论证是「因为它是善的，所以仍归入投生有之缘这一项」。译文「仍然只被算作」中的「只」与「仍然」语义重叠，且「被算作」弱化了 `saṅkhyaṃ gacchati`（归入某一计数／名目）的分类含义，读者不易看出这是在回答「为何说他 bhavapaṭilābhiya 未断」。
  - 建议：改为「由于它是善的，就仍归入“获得投生有的缘”这一项」。

- `100-1429-2-24`｜关键词语意不明确｜片段「**回答得贴切**，**但回答得不敏捷**」
  - 问题：`yuttappaṭibhāna` / `muttappaṭibhāna` 是一组对称术语（辩才「切合」与辩才「畅达／无滞」），`paṭibhāna` 指辩才、机辩。译文用「回答得贴切／不敏捷」把名词性术语化为动补短语，两词的对称关系被拆散，且「敏捷」只覆盖了 `mutta`（解脱、无滞）的速度面，丢了「流畅无碍」这一面；此处为术语首现，按 `style.md` 第二节应考虑夹注巴利原词。
  - 建议：考虑作「辩才切合而不畅达（yuttappaṭibhāna, muttappaṭibhāna）」一类对称处理，保留术语性与对称；至少在首现处夹注巴利原词。

### 🟦 suggestion
- `100-1427-2-15`｜语言风格不统一｜片段「就是凭着它们，紧接着就获得投生」
  - 问题：与下一句 `100-1427-16-21`「就是能促成获得投生有的那些条件」相比，同为被解释词的释义，一句用关系从句直译（「凭着它们…」），一句用名词短语（「…的那些条件」）。两句紧邻，句式落差明显。
  - 建议：统一为名词短语收束，如「就是那些能使人紧接着就获得投生的（结缚）」。

- `100-1427-30-56`｜复杂的嵌套句整句语言逻辑理解困难｜片段「不过，中般涅槃者不会再有中途的投生，可是他在所生的那一生中所入的禅定，由于是善的，仍然只被算作“投生有的条件”。」
  - 问题：一句内含「不过」「可是」「由于」「仍然」四个逻辑连接，两层转折叠加，读者需回读才能定位主干（禅定仍归入投生有之缘）。
  - 建议：拆为两句：「不过，中般涅槃者在中间并没有投生。但他在那里所入的禅定，由于是善的，仍归入“获得投生有的缘”这一项。」

- `100-1427-72-87`｜语言表达不够流畅｜片段「而在下分结缚方面，由于还有没有断除的」
  - 问题：「还有没有断除的」连用三个否定／存在性词（还有／没有／断除），读来拗口，且「有没有」易被误读为疑问结构。
  - 建议：改为「由于其中仍有未断除的」。

- `100-1427-88-90`｜语言表达不够流畅｜片段「这里其余的部分意思很明白」
  - 问题：`Sesamettha uttānameva` 是注释书套语，译文可读但「部分意思」四字连读有歧义（「部分意思」易被读成「一部分意思」）。
  - 建议：改为「这里其余部分的意思很明白」或沿用统一套语「其余部分意思浅显」。
