# Review — 87:1417-1427（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- akkhaṇavedhī：§1419（两处）、§1422（两处）都译作“能射中闪动的目标”。四处一致，但取义与 nissaya 不符（详见 §1419 句 87-1419-28-47），需要四处一起改。
- mahato kāyassa padāletā：§1419、§1423 都译作“击破庞大的聚集”，§1423 的比喻正文是“击破庞大的无明聚”。nissaya 把 kāya 释为 `အထည်ကိုယ်ထု`（实体、团块），不是“聚集”。“聚集”容易读成人群或集会。建议统一为“射穿巨大的物体”，比喻处相应改为“击穿庞大的无明团块”（详见 §1419 句 87-1419-28-47、§1423 句 87-1423-14-22）。
- sīlavā：§1420 句 87-1420-26-34 的 nissaya 把 ṭhāna 释为“具足波罗提木叉律仪戒”（`ပါတိမောက္ခသံဝရသီလနှင့် ပြည့်စုံခြင်း`）。同段句 87-1420-12-25 把 sīlavā 译作“具足戒”，这个词与受具足戒（upasampadā）的专称同形，读者会误解。建议改为“持戒”“有戒行”，与 nissaya 的“具备戒”一义对齐。
- pāṭibhogo：nissaya 释为“作担保的人”（`အာမခံပုဂ္ဂိုလ်`），正文各处“没有任何人能作保证”与此相合。经题“保证经”可以考虑改为“保证人经”，与正文的人称取义一致（可选）。
- mā + 不定过去时（mā jīri / mā byādhiyi / mā mīyi / mā nibbatti）：§1426 四句都译作“不要……”，语气是命令或禁止。nissaya 明确说这是祈愿语气（详见 §1426 各句），四句要统一改成“愿……不……”。

## §1419 句 87-1419-28-47
- **问题**：取义 — akkhaṇavedhī 的 nissaya 是 `မလွဲမချော်ပစ်နိုင်သည်`，意思是“能射而不偏不失”，讲的是射得准、不失手，没有“闪动的目标”这个宾语。译文补出的对象在 nissaya 里没有依据。
- **建议**：改为“射得准”或“百发百中”，例如“他善于站位，射得远，射得准，又能射穿巨大的物体”。
- **问题**：词义 — mahato kāyassa padāletā 的 nissaya 是 `မဟတော= ကြီးစွာသော။ ကာယဿ= အထည်ကိုထုကို။ ပဒါလေတာ= ဖောက်ထွင်းနိုင်သည်`，意思是“能穿透巨大的实体”。kāya 指团块、实体，padāletā 是“穿透、射穿”。“击破庞大的聚集”把对象译成了集合体，动作也偏向“打散”。
- **建议**：改为“能射穿巨大的物体”。

## §1419 句 87-1419-88-107
- **问题**：同上 — akkhaṇavedhī 与 mahato kāyassa padāletā 两处沿用了比喻段的误译。
- **建议**：与 87-1419-28-47 同步修改。

## §1421 句 87-1421-12-56
- **问题**：主宾关系 — nesohamasmi 的 nissaya 是 `ဧသော= ဤရုပ်သည်။ အဟံ= ငါသည်။ န အသ္မိ= မဟုတ်`，即“这个色不是我”。主语是 eso（这个色），我是表语。译文“我不是这个”把主语换成了“我”，句法角色颠倒。
- **建议**：改为“这不是我”。全句作“‘这不是我的，这不是我，这不是我的自我。’”

## §1421 句 87-1421-57-110
- **问题**：同上 — nesohamasmi 的 nissaya 是 `ဧသော= ဤ ဝိညာဏ်သည်။ အဟံ= ငါသည်။ … န အသ္မိ= မဟုတ်`，主语是 eso。
- **建议**：同步改为“这不是我”。

## §1422 句 87-1422-2-12
- **问题**：取义 — akkhaṇavedhī 的 nissaya 是 `မလွဲမချော်ရအောင် ပစ်နိုင်သည်`（能射而不失），没有“闪动的目标”。
- **建议**：改为“比丘怎样才算射得准呢？”

## §1422 句 87-1422-13-36
- **问题**：词义 — paṭipadā 的 nissaya 是 `အကျင့်ဖြစ်သော မဂ္ဂသစ္စာ`，意思是“作为修行的道谛”，核心义是“修行、践行”，不是“道路”。
- **建议**：改为“通向苦灭的修行之道”或“导向苦灭的行道”，与 paṭipadā 的“修行”义对应。

## §1422 句 87-1422-37-45
- **问题**：取义 — akkhaṇavedhī 的 nissaya 是 `မလွဲမချော်ရအောင် ပစ်ခွင်းနိုင်သည်`（以道智之箭射中四谛而不失），译文“闪动的目标”无据。
- **建议**：改为“比丘们，这样，比丘就是射得准。”

## §1423 句 87-1423-14-22
- **问题**：词义 — avijjākkhandhaṃ 的 nissaya 是 `အဝိဇ္ဇာဟူသော အထည်ကိုယ်ထု`，即“名为无明的团块、实体”。padāletā 是 `ဖောက်ခွဲ`（击穿、破开）。“无明聚”可以接受，但它和比喻段的“聚集”都偏向“集合”义。
- **建议**：配合比喻段改为“他能击穿庞大的无明团块”，让比喻与正文对应。

## §1423 句 87-1423-23-33
- **问题**：同上 — mahato kāyassa padāletā 沿用了“击破庞大的聚集”。
- **建议**：与比喻段统一，改为“能射穿巨大的物体”。

## §1426 句 87-1426-7-31
（nissaya 单元附在 87-1426-80-120 上，内容覆盖本段四句。）
- **问题**：主语与语气。
  - **主语**：nissaya 的句法注明确说 jarādhammaṃ 是 mā jīri 的主语（`ဇရာဓမ္မံပုဒ်သည် ဇီရိ၏ ကတ္တား`），并补出属格：`ဇရာဓမ္မံ= ငါ၏ အိုခြင်းသဘောသည်`，即“我的会衰老的本性”。译文“凡是本性会衰老的”漏了“我的”，泛化成一切会衰老的东西，原句说话人自愿的意味没有了。
  - **语气**：nissaya 说 mā jīri 中的“使”义不是使役，而是动词词尾的祈愿（`အာသိဋ္ဌ(ပတ္ထနာ)`）义：`မအိုပါစေသတည်း`，即“愿不衰老”。译文“不要衰老”读作命令或禁止，与祈愿语气不符。
- **建议**：改为“‘愿我这会衰老的不衰老’”或“‘但愿我会衰老的身躯不衰老’”。

## §1426 句 87-1426-32-55
- **问题**：同上 — nissaya 是 `ဗျာဓိဓမ္မံ= ငါ၏ မကျန်းမမာ နာခြင်းသဘောသည်။ မာဗျာဓိယိ= မနာ ပါစေသတည်း`，即“愿我的会生病的本性不生病”。译文漏了“我的”，“不要”也应改为祈愿。
- **建议**：改为“‘愿我这会生病的不生病’”。

## §1426 句 87-1426-56-79
- **问题**：同上 — nissaya 是 `မရဏဓမ္မံ= ငါ၏ သေခြင်းသဘောသည်။ မာ မီယိ= မသေပါစေသတည်း`，即“愿我的会死亡的本性不死亡”。
- **建议**：改为“‘愿我这会死亡的不死亡’”。

## §1426 句 87-1426-80-120
- **问题**：语气与连接词。
  - **语气**：mā nibbatti 的 nissaya 是 `မဖြစ်ပါစေသတည်း`，即“愿不生起”，是祈愿语气。译文“它们的果报不要生起”是命令语气。
  - **连接词**：pana 的 nissaya 是 `ထိုမှတစ်ပါး`，意思是“此外”，表示这是在前三项之外另列的第四项，译文没有体现。
  - **词义**：nissaya 把 kammāni 明确为不善业（`အကုသိုလ်ကံ`），与“恶业”相合。saṃkilesikāni 的 nissaya 是 `ကြည်လင်နေသောစိတ်ကို ညစ်နွမ်းစေတတ်`，即“使清净的心染污”，译文“会带来污染”的宾语不明。
- **建议**：改为“对于‘此外，过去自己所造的那些恶业——它们会使心染污、会导致再生、会令人怖畏、会带来痛苦的果报、将来会引生生老死——愿它们的果报不生起’，没有任何人能作保证……”
