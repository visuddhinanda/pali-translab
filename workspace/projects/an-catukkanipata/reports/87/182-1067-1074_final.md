## 理由

**基准缺失（影响信心）**：本次只注入了复注（ṭīkā）本层的巴利原文与译文，**没有义注（aṭṭhakathā）文本，也没有 nissaya channel**。因此两条核心基准都无法执行：

1. 「义注定释义」无法核对——本层大量句子是在解释义注的用词（`samudayanti uppattin`、`atthaṅgamanti bhedan`、`cakkhādīnaṃ cakkhusamphassādikāraṇānan`、`visaṃyogāti visaṃyojanakāraṇānī` 等），这些**黑体被解释词与引文必须与义注层译文逐字同译**，是项目硬约束，但此处只能判断其内部自洽，不能判断是否与义注层对齐。
2. 「nissaya 定词法」无法核对——格、句法角色、隐含成分的判定只能依据原文本身推定。

下列评分是在「仅凭巴利原文 + 内部一致性」基础上给出的，准确性一项的不确定度主要来自这一降级。**如需作为正式验收结论，建议补取义注与 nissaya 后重评。**

**准确性**：句法判读整体可靠。`kammaṃ vipākena bhavādiṃ, bhavantarādīhi dukkhena sattaṃ yojenti` 的三组宾语-具格配对处理正确；`pageva paccayānaṃ suggahitattā`（事先已很好把握诸缘）、`byatirekavasena anussavādito`（通过排除、依据传闻）、`ārammaṇato / asammohato` 的对举、`uttarapadalopena` 与 `purimapadassa okārantatā` 这段构词分析，都译得准确且站得住。`itarampi` 补出「也就是坏灭的灭没」、`tadantogadhattā` 补出「四谛」，属于有依据的指代消解，不扣分。扣分点集中在 `yojenti ghaṭenti` 同义动词对中 `ghaṭenti` 未落译。

**风格**：无文言/半文半白违例——通篇未出现「此中／故为／彼等／是故／之／其／乃／便／即／谓」等禁例，句式为现代书面汉语，长句也拆得开。标点全角、引号统一用 “”、无 ASCII 引号，符合 JSON 安全硬约束。扣分点：核心术语「轭」（yoga）自始至终没有巴利夹注，而次要术语 bhavadiṭṭhi 反倒夹注了，夹注策略与 `style.md` 第二节不一致；且「即常见」属译者解释，按配置应入脚注而非正文。1071 段大量罗马字巴利词（punobhava / ika / āpūpika / ponobhavika / mano）出现在正文，与「显示巴利原文：否」相左，但该段本身就是构词分析、所讨论对象即词形，属合理偏离，不扣分。

**一致性**：同根词汉译有数处漂移：`uppāda`→「生起」而 `uppatti`→「出现」；`vaya`→「灭」与 `nirodha`／`atthaṅgama`→「灭／灭没」撞车；引述动词时而「注释者说了」、时而无主语「所以说了」。`punabbhava`→「再有」、`ponobhavika`→「导致再有的」、`visaṃyoga`→「离轭」在本层内部前后统一，但同样需与义注层核对后才能定。

### 🟧 error

### 🟨 warning
- `182-1070-8-13`｜关键词语意不明确｜片段「不再转起的灭」
  - 问题：「转起」属二意/生僻译词（方法文档明确举此为例），未加注，一般读者无法判断指「相续运转」还是「生起」。
  - 建议：改为「不再继续生起的灭」或保留「转起」并首次出现加注（appavatti）。
- `182-1069-16-29`｜整句逻辑表达不规范｜片段「“生起着”、“生起这件事”叫做生起；“由它而生起”也叫做生起」
  - 问题：这是 `samudayate / samudayanaṃ / samudayo` 与 `samudeti etasmāti samudayo` 的语源分析，用意是区分「刹那生起＝动作义」与「缘生起＝由之生起者」；现译把两类都收成「叫做生起」，分别反而被抹平，读者看不出「saddatthato bhedo」在哪。
  - 建议：显化构词关系，如「『生起』（samudayate）这一动作、这一『生起之事』（samudayana），叫做 samudaya；而『诸法由它生起』，也叫做 samudaya——可见两种生起连在语词意义上也有分别」。
- `182-1068-70-76`｜代词指代不明确｜片段「因为这部注释本来就是对经藏的解说」

- `182-1071-34-45`｜代词指代不明确｜片段「已经把那层意思表达出来了」
  - 问题：「那层意思」即前句省略掉的 `karaṇa`（造成）这一动作义，译文未点明，衔接断了。

- `182-1070-26-46`｜关键词语意不明确｜片段「在从尽、灭的角度思察等的时候」
