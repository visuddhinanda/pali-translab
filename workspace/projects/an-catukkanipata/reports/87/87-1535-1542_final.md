## 理由

**数据基准说明（重要）**：本次评估**没有拿到义注（aṭṭhakathā）与 nissaya**，注入的资源只有巴利原文与 channel 读回的译文。按方法文档的降级规定，准确性判断只能依巴利原文的词法、格与句法，以及 AN 四部定型句（pericope）的平行文本来做；凡涉及"义注怎么解"的条目，下面都只能标为可疑而不能定性为"与义注不符"。因此信心指数压到 72，不宜据此报告直接判定定稿合格。

**准确性**：主体叙事与四支框架译得准确，呼格、`vuccati` 被动式、`Katamāni cattāri` 等定型句处理无误。扣分集中在三处添加成分：`paññāya` 被译为"以观慧（vipassanā-paññā）"、`anuggahessāmi` 的处所 `tattha tattha` 被译成"在各个场合"后又在下句被读作"在那扶持上"、`phusati` 被译为"以智触触证"。这些都是注释书层面的解释，原文无对应词；在没有义注可核的情况下属于**超出原文的增译**，且括注的 `vipassanā-paññā` 并非该句原文词形，违反 `style.md`「夹注巴利原词」的用法。1541 段 `rajanīyesu dhammesu` 译作"成为贪因的可意所缘"同样把一个形容词扩成了十字解释，并把 `dhamma` 定为"所缘"，这是取舍而非直译，无义注支撑难以成立。

**风格**：整体是现代书面汉语，无文言虚词堆砌，达标。但 `samādāya sikkhati sikkhāpadesu` 译成"受持学处而学习"保留了"而"字连接的半文半白节奏，且"学处而学习"读来不成话。另有一处硬约束问题：`style.md` 第五节明令引号统一用全角 "" ''、**不要用直角引号「」**，而四个 `Iti ...ti` 句一律用了 ASCII 风格的弯双引号 "" 包裹内心语——这一项其实合规；真正越界的是 1540 段用了单引号 ' ' 包裹 `idaṃ dukkhan ti`，与同层 1537 段"正理（ñāya）"的处理方式不一致，属格式不统一而非违禁。

**一致性**：四支的 `Iti evarūpiṃ...` 定型句四处用语高度一致，术语（清净勤支 / 虎路族 / 观慧 / 离染）前后统一，这是本段最强项。`byagghapajjā` 全篇统一为"虎路族的人啊"，呼格处理一致。首次出现夹注的规则在 `pārisuddhipadhāniyaṅga`、`ñāya`、`sammāvimutti` 上执行了，但 1542 段"正理"复现时正确地未再夹注，符合规范。

## 问题清单

### 🟧 error

- `87-1538-32-67`｜错误多译｜片段「以观慧（vipassanā-paññā）扶持它」
  - 问题：原文 `paññāya` 只是"以慧"（instrumental, paññā），并无 `vipassanā` 一词。译文把义注的解释并入正文，又在圆括号里夹注了一个**原文根本不存在的巴利词形** `vipassanā-paññā`，读者会以为原文如此。`style.md` 规定夹注是"术语首次出现附巴利原词"，不是附注释书的推定词。
  - 建议：正文改为"以慧扶持它"，若确需交代是观慧，放脚注或报告，不入正文夹注；夹注若保留只能写 `paññā`。

- `87-1539-33-68`｜错误多译｜片段「以观慧扶持它」
  - 问题：同上，`paññāya` 增译为"观慧"。此处虽未夹注巴利词，但增译性质相同。
  - 建议：统一改为"以慧"。

- `87-1540-41-77`｜错误多译｜片段「以观慧扶持它」
  - 问题：同上。
  - 建议：统一改为"以慧"。

- `87-1541-61-96`｜错误多译｜片段「以观慧扶持它」
  - 问题：同上。四处一致地增译，属同一决策，需一并回退。
  - 建议：统一改为"以慧"。

- `87-1541-41-53`｜错误多译｜片段「以智触触证正解脱」
  - 问题：`sammāvimuttiṃ phusati` 字面是"触达/证得正解脱"。"以智触触证"把"触"这一动词拆成"以智触"（增出工具）＋"触证"（重复同一动词），原文既无 `ñāṇa` 也无第二个动词，是一词译三次。
  - 建议：改为"触证正解脱（sammāvimutti）"或"证得正解脱"。

- `87-1541-10-40`｜错译（词义、修饰关系）｜片段「从那些成为贪因的可意所缘离染」
  - 问题：`rajanīyesu dhammesu` 是"于应被染著的诸法"，`-anīya` 是未来被动分词（可被染著的），译文反向处理成"成为贪因的"（使人生贪的原因），施受颠倒；又把 `dhammā` 固定为"所缘"。同句后半 `vimocanīyesu dhammesu` 译成"应当使心从中解脱出来的所缘"长达十一字，与前半不对称。
  - 建议：前后对齐处理，如"于应染著的诸法令心离染，于应解脱的诸法令心解脱"。

- `87-1541-41-53`｜错译（词义、修饰关系）｜片段「对那些应当使心从中解脱出来的所缘使心解脱」
  - 问题：同一短语在 1541-10-40 与 1541-41-53 两句中结构相同，但译法一长一短、介词一处用"从…离染"一处用"对…"，同句内两次出现也不统一。
  - 建议：与上条一并统一为同一句式。

### 🟨 warning

- `87-1538-32-67`｜整句逻辑表达不规范｜片段「在各个场合以观慧扶持它。"在那扶持上想要去做的意欲」
  - 问题：`tattha tattha` 先译为"在各个场合"，紧接的 `yo tattha chando` 的 `tattha` 又译为"在那扶持上"。同一指示词在相邻两处指向不同，读者无法判断"那扶持"回指何物；且 `chando` 已是"意欲"，前面再加"想要去做的"是同义重复。
  - 建议：后一 `tattha` 译为"在这件事上"或"于此"，并删去"想要去做的"。

- `87-1539-33-68`｜整句逻辑表达不规范｜片段「在那扶持上想要去做的意欲」

  - 建议：同上统一修改。

- `87-1540-41-77`｜整句逻辑表达不规范｜片段「在那扶持上想要去做的意欲」

  - 建议：同上统一修改。

- `87-1541-61-96`｜整句逻辑表达不规范｜片段「在那扶持上想要去做的意欲」

  - 建议：同上统一修改。

- `87-1538-11-24`｜不导致误解的汉语语病｜片段「受持学处而学习」
  - 问题：`samādāya sikkhati sikkhāpadesu` 的"学处"与"学习"同根叠用，加上文言式"而"字连接，读来不成句，且与 `style.md` 禁用半文半白的要求相抵。
  - 建议：改为"受持学处而修学"或"在诸学处中受持修学"。

- `87-1541-10-40`｜整句逻辑表达不规范｜片段「他就使心从那些成为贪因的可意所缘离染」
  - 问题：原文 `Sa kho so ... samannāgato ... cittaṃ virājeti` 是一个以三个 `samannāgato` 并列修饰主语的长句，译文在第三个"具足"后插入"他就"另起小句，把并列修饰读成了因果（"具足了…他就…"），原文无因果连词。
  - 建议：删去"就"，或改为"他具足…具足…具足…，于应染著的诸法令心离染"。

- `87-1540-10-33`｜标点符号使用错误｜片段「如实地了知'这是苦'」
  - 问题：`style.md` 第五节要求单引号一律用全角 ' '，此处为内层引语，但全篇其他引语（1538/1539/1540/1541 的 `Iti...ti`）都用双引号 ""，同一文本内引语层级标记不统一。
  - 建议：内层引语统一为全角单引号 ' '，外层为 ""，并检查全篇层级一致。
