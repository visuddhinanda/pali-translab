**准确性**：定型句的骨架译得准。`abhiññāya` 一律作「为了证知」，九个与格串（`pariññāya / parikkhayāya / pahānāya / khayāya / vayāya / virāgāya / nirodhāya / cāgāya / paṭinissaggāya`）逐项对出，无漏项；`vineyya loke abhijjhādomanassaṃ` 把 `loke` 正确处理为 `abhijjhādomanassa` 的限定（「对世间的贪求与忧恼」）；四正勤的五个动词（`chandaṃ janeti / vāyamati / vīriyaṃ ārabhati / cittaṃ paggaṇhāti / padahati`）全部落地。扣分集中在两处：`kāye kāyānupassī` 的「于身—观身」双层结构被压成单层「对身体的随观」，处格成分在汉语里消失；`padahati` 译作「坚持不放弃」是解释性意译，补出了原词没有的否定面，且切断了与篇题「正勤经」（`sammappadhāna`）的词面联系。

## 问题清单

### 🟨 warning
- `87-1940-22-36`｜整句逻辑表达不规范｜片段「安住于对身体的随观」
  - 问题：`kāye kāyānupassī viharati` 是「于身（处格）—随观身—而住」三重结构，译文压成单层「对身体的随观」，处格 `kāye` 在汉语里无着落，念处的「所依—所观」区分丢失。
  - 建议：改为「于身随观身而住」或「安住于观身为身」。同句式另见 `87-1940-37-54`（受／心／法三处同样处理），改动需四处同步。

- `87-1944-29-41`｜导致误解的表达｜片段「以及具备审察三摩地与精勤造作的神足」
  - 问题：四神足是四个独立修习对象，原文以 `… pe …` 省略并列；用「以及」收尾会读成「一个神足同时具备四种三摩地」。且「具备」只出现在首项和末项，中间「心三摩地」裸列。
  - 建议：去掉「以及」，照前两经只用省略号衔接，如「修习具备精进三摩地与精勤造作的神足……略……心三摩地……略……审察三摩地……」。

- `87-1942-20-38`｜关键词语意不明确｜片段「坚持不放弃」
  - 问题：`padahati` 义为「奋力、精勤从事」，译文补出原词没有的否定面（「不放弃」），并切断了与本经篇题「正勤经」（`sammappadhāna`）的词面呼应。
  - 建议：改为「精勤努力」或「全力以赴」。同词另见 `87-1942-39-71`，须一并统一。

- `87-1946-6-40`｜关键词语意不明确｜片段「为了尽……为了衰灭」
  - 问题：`khayāya` 作「为了尽」、`nirodhāya` 作「为了灭」，单音节词独用，违反 `style.md`「能用双音节就不用单音节」；「尽」「灭」与前面的「遍尽」字面重叠，读者无法分辨九项的层次。
  - 建议：「为了灭尽」「为了止灭」，并与「遍尽（parikkhaya）」「衰灭（vaya）」拉开词面距离。

- `87-1940-22-36`｜不该使用术语标记时使用了术语标记｜片段「在这（佛法）中」
  - 问题：圆括号按 `style.md` 第三节只用于首次出现时夹注巴利原词，此处用作义理补说，体例不符；「在这（佛法）中」读起来也不像自然汉语。
  - 建议：写成「在这佛法中」或「在佛陀的教法中」，不用括号。另见 `87-1942-20-38`、`87-1944-20-28` 两处同样写法，须同步。

- `87-1946-6-40`｜标点符号使用错误｜片段「应当修习四种法……略……。」
  - 问题：省略号后再加句号，中文标点不这样用；另外本句以全角上引号「“」开启，直到段末及 `87-1946-41-42` 都没有下引号收尾（巴利原文因 `… pe …` 省略亦无闭合引号），汉语读者会看成引号失配。
  - 建议：删去省略号后的句号；引号按汉语习惯补上闭合「”」，或整句不用引号。
