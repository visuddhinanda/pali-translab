## 理由

**基准缺失（影响信心）**：本次只注入了巴利原文与待评译文，**没有义注（aṭṭhakathā）译文、没有 nissaya**。本段是复注（ṭīkā），黑体被解释词全部引自义注，而「被解释词与父层逐字同译」这条硬约束**无法核验**；词级格位与句法角色也没有 nissaya 可比对。因此下面涉及黑体词（`bhava` / `abhava` / `bhavābhava` / `itthabhāvaññathābhāva` / `sappinavanītādīni`）的判断，是依巴利内部逻辑与译文自身的自洽性作出的；若义注层确已定下同样译法，则应回到义注层一并修正，不要只改复注。信心据此压到 62。

**准确性**：句子骨架、`vā` 引出的多重异释层次、`Tenevāha` / `Tenāha` 的引述结构都处理正确，偈颂与出处长串引文完整无误、没有漏译整句。主要失分在三处：(1) `itthabhāva` / `aññathābhāva` 统一译作「此生 / 来生」，与紧随其后的两组释义（`manussattaṃ` ／ 其余众生居处；同类 ／ 不同类自体）直接冲突，形成三句不自洽；(2) 「蜜猎人」譬喻中 `papātakaṃ acintetvā` 的主体被改派给猎物；(3) 刚说「a 音表示增长」，紧接着把 `saṃvarāsaṃvara` / `phalāphala` 译成「种种…」，论证与例证脱节。另有若干小幅多译（「等食品」「麻油」「相续不断」「行蕴句」）。

**风格**：这是本段最好的一块。全段现代书面汉语，**未发现任何文言或半文半白用例**（无 此中／故为／彼等／於／遂／端坐／用膳 一类），长句处理成「因为…以…的方式…，使他…」这样的现代复句而非文言串接；标点全角、引号统一 “ ” ‘ ’、无直角引号、无 ASCII 引号，JSON 安全无隐患；译文里没有任何候选、待定、问号类工作标记。扣分只来自 `182-1061-65-79` 的「不借…而借…」等两三处可读性塌陷。

**一致性**：同一段内 `bhava` 出现「受用」「有」「种种更精美的受用」三种汉译、`abhava` 出现「增有」「非有」两种，这在训诂上是正确的（复注确实在给不同的词源解释），但译文没有给读者任何提示，读者会以为译名混乱；`itthabhāva` 的「此生」在三组释义下含义漂移。「义注说」「诸蕴、诸界、诸处」「贪爱」「集谛」等在跨段上保持一致，这部分没有问题。

## 问题清单

### 🟧 error

- `182-1061-102-109`｜错译（词义）｜片段「**来生**是指除此之外其余的众生居处」
  - 问题：`aññathābhāva` 本义是「成为别样的状态」，此处被义注限定为「人以外其余的众生居处（avasiṭṭhasattāvāsā）」，指的是**处所/生类**，不是时间上的下一生。译作「来生」后，整句变成「来生是指其余的众生居处」，逻辑不通。
  - 建议：`itthabhāva` / `aññathābhāva` 改取状态义（如「这样的状态 / 别样的状态」），本句即可通顺；若义注层已定「此生/来生」，需两层一并改。

- `182-1061-121-130`｜错译（词义）｜片段「与现在同类的另一个自体也是**此生**，不同类的就是**来生**」
  - 问题：同一误译的连带后果——「另一个自体」却称「此生」，自相矛盾。
  - 建议：随上一条统一改为状态义。

- `182-1061-84-101`｜导致误解的表达｜片段「轮回就叫做‘有此生与来生的（itthabhāvaññathābhāva）’」
  - 问题：此句是词构分析（相违释→有财释），译名一旦取「此生/来生」，后面三组释义中有两组落不下来；且「有此生与来生的」作为汉语名相难以索解。
  - 建议：改为状态义并保留夹注巴利原词，使 102-109 / 110-120 / 121-130 三组释义都能挂上。

- `182-1061-23-48`｜错译（修饰关系）｜片段「只用甜味诱捕、不管猎物会摔下悬崖的猎人」
  - 问题：`taṃ papātakaṃ acintetvā madhuggaṇhanakaluddakā viya` 中不顾悬崖的是**取蜜的猎人自己**（为了蜜而不计脚下深坑），`madhuggaṇhanaka` 是「取蜜」而非「用甜味诱捕」。译文把悬崖改派给猎物、把猎人改成施饵者，譬喻的受害方向整体反转，与下文「贪爱只向他显示好处」的对应关系也随之错位。
  - 建议：改为「就像只顾取蜜、不顾脚下悬崖的猎人一样」。

- `182-1060-18-31`｜错译（词义）｜片段「“saṃvarāsaṃvara（种种防护）”、“phalāphala（种种果实）”」
  - 问题：本句正在论证「这个 a 音表示**增长**（vuddhiattha）」，两个例词必须体现增长义（越来越多/大大小小以至于大），译作「种种」是「多样」义，使例证无法支持论点。
  - 建议：改为「层层加深的防护」「越来越多的果实」一类，使与前句的 vuddhi 义呼应。

### 🟨 warning

- `182-1060-66-74`｜关键词语意不明确｜片段「**非有（abhava）**就是失坏」
  - 问题：同段 `182-1060-14-17` 已把 `abhava` 译作「增有」（取 a = 增长），此处又作「非有」（取 a = 否定）。两处都对，但译文未作任何提示，读者会判为译名前后矛盾。
  - 建议：在此句句首加一句过渡（如「若把 a 取作否定义，则…」），让两种词源解释显形。

- `182-1060-48-57`｜整句逻辑表达不规范｜片段「**种种更精美的受用**应当理解为小的和大的生有」
  - 问题：被解释词沿用义注的「种种更精美的受用」，而本句释义是「小的和大的生有（upapattibhava）」，两者在汉语里不构成「A 就是 B」的关系，读者无从知道这是在解释同一个巴利复合词。同样的断裂出现在 `182-1060-83-94`「或者因为种种更精美的受用」。
  - 建议：被解释词保持与义注同译的前提下，首次出现处夹注巴利原词 `bhavābhava`，使后续各组异释可挂钩。

- `182-1060-32-39`｜错误多译｜片段「**酥油、奶油等食品**」
  - 问题：`sappinavanītādīni` 只是「酥油、生酥等」，「食品」是原文所无的添加；且它所含摄的 `tela`（油）并不都属食品。
  - 建议：删去「食品」。

- `182-1064-2-15`｜错误多译｜片段「**诸蕴、诸界、诸处的相续不断**」
  - 问题：被引黑体仅 `khandhadhātuāyatanānaṃ paṭipāṭiṃ`（相续），「不断」是引文之外加入的，不应混进引号内的被解释词。
  - 建议：引文内删「不断」，其义已由后半句「一个接一个地不断转起」承担。

### 🟦 suggestion

- `182-1061-65-79`｜语言表达不够流畅｜片段「不借善法而借不善法、不借欲界等的善法而借色界等的善法」
  - 问题：以「借」译具格 + `vinā` 的对举，汉语里指向不明（借助？凭借？），读者难以判断「谁借谁」；本句是「贪爱何以独为殊胜因」的关键论据，表述塌陷会让整段论证落空。
  - 建议：改为「它不是与善法、而是与不善法一同，不是与欲界等善法、而是与色界等善法一同，成为产生诸有的特别因缘」。

- `182-1060-32-39`｜语言表达不够流畅（过度具体化）｜片段「麻油」
  - 问题：`tela` 是泛称的油，译「麻油」把范围窄化为芝麻油，原文无此限定。
  - 建议：改作「油」。

- `182-1063-2-89`｜语言风格不统一｜片段「《分别论义注》226 行蕴句的解说」
  - 问题：`saṅkhārapada` 是「『行』这一词条」，不是「行蕴」；同句「《法集论义注·因缘论》」中 `nidānakathā` 通译「因缘谈／序分」，作「论」与前后书名层级混淆。
  - 建议：改为「『行』一词的解说」与「因缘谈」。

- `182-1065-2-19`｜复杂的嵌套句理解困难｜片段「这个作为一切轮转之苦的根源、作为其集起的贪爱这一过患」
  - 问题：三层定语连缀在「贪爱」前，读到句末才落到中心语，对读者不友好。
  - 建议：拆为「意思是认清贪爱这一过患——它是一切轮转之苦的来源，是苦的集起」。

- `182-1065-31-47`｜语言表达不够流畅｜片段「是由于舍弃了称为四种取的一切执取而没有任何执取」
  - 问题：「没有任何执取…而没有任何执取」同形循环，读起来像自我定义。
  - 建议：改为「之所以说他没有任何执取，是因为他已舍弃了称为四取的一切执取」。
