## 理由

**取数降级说明**：本次注入的只有义注（book=100）自身的巴利原文与译文。**没有 nissaya**（无法做词级格/句法核对，词覆盖只能靠巴利原文目视比对），**也没有被注释的本文（AN 4.186 Ummaggasutta）原文及其译文**。这直接影响两件事：

1. 义注大量用黑体引本文词句（`parikassati` / `ummaggo` / `cittassa uppannassa vasaṃ gacchati` / `atthamaññāya dhammamaññāya` …），**「被解释词与父层逐字同译」这条硬约束本次无法验证**——下面凡涉及黑体引词的条目，判据只有「黑体部分是否与所引巴利词项逐字对应」这一内部一致性，不涉及与本文译文的字面一致。请在 harmonize 阶段带上本文译文复核。
2. 词级错误（格、修饰关系）只能从上下文推断，故准确性分与信心指数都压低。

**准确性**：句意主干与义注的释义结构（`X ti Y` = 「X，就是 Y」）处理得稳，四谛那三句（66-76、81-91、92-97）与「以第四问答说阿罗汉果」（98-102）取义正确，`ṭhapetvā taṇhaṃ`（除渴爱外）、`vaṭṭamūlakataṇhā`（作为轮转根本的渴爱）、`saha sīlena pubbabhāgappaṭipadaṃ`（连同戒在内的前分行道）都没有丢成分。扣分集中在**黑体被解释词的处理**：`parikassati` 的语态与释词 `ākaḍḍhiyati`（被动）相反；29-43 与 44-50 两条在黑体里补进了巴利词项没有的成分（「世间」「它的」），属于在被解释词上多译。

**风格**：现代书面汉语达标，**未发现文言 / 半文半白用例**（无「此中/故为/彼等/于…之际/答以」之类）；标点全角、引号用弯引号 “”、无 ASCII 引号，符合 `style.md` 第五节的 JSON 安全约束；译文内无任何残留工作标记。少量「的…的」套叠与定语过长影响流畅度。

**一致性**：主要问题是 `ummagga` 与 `nibbedhika` 在同一段内都落到「通达」，而义注正是在同段里把这两个词做不同解释（前者=浮出/智慧涌现，后者=洞穿），同形汉译抹掉了区别；`paññā` 在相邻两句中「智慧 / 慧」混用。另外 `ummagga` 译「通达」与它自己的释词「冒出水面」之间缺少可理解的桥梁，读者无法看懂为什么「通达」会被解释成「冒出水面」。

## 问题清单

### 🟧 error
- `100-1555-2-10`｜错译（语态）｜片段「**拖拽**，就是被牵拉」
  - 问题：被解释词 `parikassati` 的释词是 `ākaḍḍhiyati`（被动，「被拖拉」），黑体却译成主动的「拖拽」，与紧随其后的「被牵拉」语态相反，读者会以为义注在用被动解释主动。本文语境为「（世间）被心拖着走」。
  - 建议：黑体改为被动，使之与释词同向，如「**被拖拽**，就是被牵拉」；最终形式须与本文译文中该词的译法逐字一致（待取本文译文复核）。

- `100-1555-29-43`｜错误多译｜片段「**心一旦生起，世间就落入它的支配之下**」
  - 问题：黑体所引巴利词项只有 `cittassa uppannassa vasaṃ gacchati`（「落入已生起之心的支配」），其中没有 `loka`／「世间」。「世间」是从下文「这里（『世间』一词）所摄取的只是…」反推出来的主语，把它写进黑体，等于在被解释词里添字，破坏了黑体与本文引文的逐字对应。
  - 建议：黑体只留所引词项（如「**落入已生起之心的支配之下**」），需要的主语放在黑体之外或保持省略；本文主语的补出交给后半句的说明承担。

- `100-1555-44-50`｜错误多译 + 错译（预先代入释义）｜片段「**了知它的义理、了知它的文句**」
  - 问题：两处毛病。其一，「它的」在 `atthamaññāya dhammamaññāya` 里没有对应成分，属黑体内添字。其二，更要紧的是把黑体里的 `dhamma` 直接译成「文句」——这正是本句释词 `pāḷiñca jānitvā` 要揭示的内容。被解释词先说了答案，后半句「就是了知义理和圣典的文句」就变成同义重复，义注「以 pāḷi 释 dhamma」的训释关系被抹掉。
  - 建议：黑体按本文字面作「**了知义、了知法**」（具体用字以本文译文为准），释词保留「就是了知义理和圣典的文句」，训释关系即可显现。

- `100-1555-62-65`｜导致误解的表达（术语撞车）｜片段「**有通达慧者**」
  - 问题：同一段里 `ummagga`（100-1555-11-17、18-24、以及标题 100-1554-2-4）译「通达」，`nibbedhika` 也译「通达」。义注在这段的作用恰是区分二者（一个释为「浮出/智慧涌现」，一个释为「洞穿」），汉译同形会让读者以为是同一个词或同一能力。
  - 建议：保留较有传承依据的「通达慧」给 `nibbedhikapañño`，改动 `ummagga` 一侧（见下条 warning）；二者择一改名即可，但必须在三层统稿时一并改，包括标题。

### 🟨 warning
- `100-1555-11-17`｜关键词语意不明确，二意场合无注释｜片段「**通达**，就是冒出水面，意思是智慧的运行」
  - 问题：`ummagga`（ud + majj，「浮出、涌出」）译作「通达」后，与紧接的释词「冒出水面」失去语义联系，读者读到「通达，就是冒出水面」只会困惑；而义注这句的全部价值就在这个词源式训释。标题 `100-1554-2-4`「通达经的注释」同源。
  - 建议：改用能承接「浮出」义的译名（如「涌出」「智慧涌现」），或保留「通达」但首次出现夹注巴利原词并加一句短注说明其字面义为「浮出水面」。标题与 18-24 须同步。

- `100-1555-51-61`｜关键词语意不明确，无注释｜片段「前分行道」
  - 问题：`pubbabhāgappaṭipadā` 直译为「前分行道」，对一般读者不可解，且本段未作任何说明；按 `style.md` 第二节，罕见术语需首次出现附简注。
  - 建议：改为可读的表述并附原词，如「属于预备阶段的行道（pubbabhāgapaṭipadā）」，或保留「前分行道」并加注「即证出世间法之前的预备修行」。

- `100-1555-92-97`｜代词/指代不明确｜片段「其余两处的意思也应当按这个方式了解」
  - 问题：`sesadvaye` 指的是四谛中尚未解释的后两谛（灭谛、道谛），译作「其余两处」把谛说成了「处」，指代对象落空；「这个方式」亦未明确指前两谛的解释套式。
  - 建议：译为「其余两谛（苦灭、苦灭之道）的意思也应当照此了解」之类，把所指点明。

### 🟦 suggestion
- `100-1555-62-65`｜语言表达不够流畅｜片段「就是具有能够洞穿的慧的人」
  - 问题：「的…的…的」三层套叠，定语偏长。
  - 建议：改为「就是具有洞穿之慧的人」或「就是慧能洞穿的人」。

- `100-1555-77-80`｜语言风格不统一｜片段「**以智慧**，就是以道慧」
  - 问题：同一个 `paññā` 在一句之内先作「智慧」后作「慧」（且与 62-65 的「慧」并存），术语形态不统一。
  - 建议：统一为「慧」或「智慧」择一，复合词中可省作「道慧」，但黑体与释词应取同一基词。

- `100-1555-18-24`｜语言表达不够流畅｜片段「正是智慧因为有冒出水面的意思，才被称为通达」
  - 问题：`ummujjanaṭṭhena` 是具格表「依…义」，译成「因为有…的意思」略啰嗦，且与前句的「意思是」用法重叠。
  - 建议：改为「或者说，智慧本身依其『浮出』之义而被称为…」。

- `100-1555-25-28`｜该使用而未统一的译名｜片段「才叫做**应机的辩才**」
  - 问题：`paṭibhānaṃ` 译作「应机的辩才」是在黑体内加入了解释性修饰「应机的」，而「当下显现」的意思已由前面的释词交代；黑体宜保持与本文引词同形。
  - 建议：黑体作「**辩才**」（或与本文译文一致的形式），「应机」之义由释词承担。
