# Review — 87:1009-1020（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **sagavacaṇḍo / paragavacaṇḍo**（必改）：§1016 句 41-67 及各段比喻句（§1017-1020 的 41-51、42-52、38-48、42-53）译「对自群牛凶暴／对他群牛凶暴」。§1016 句 83-100 与 §1017-1020 讲人的各句，同一个巴利词却译成「对自己人凶暴／对外人凶暴」。
  - nissaya 在牛和人两处给的是同一释义：`သဂဝစဏ္ဍော= မိမိနွားအုပ်၌သာ ကြမ်းတမ်းသည်`（只在自己牛群中凶暴）。讲人时只补出 `ပုဂ္ဂလော= နွားလားနှင့်တူသော ပုဂ္ဂိုလ်`（像公牛的人）。也就是说，人的分类直接沿用牛的词，比喻关系就靠这个同词来维系。
  - 建议两处统一为同一译法，例如「对本群凶暴、对外群不凶暴」。这个译法既能指牛群，也能指会众。
- **夹注位置**（必改）：巴利夹注（sagavacaṇḍa）出现在 §1016 句 83-100，不在首次出现处 §1016 句 41-67。按 style.md，应移到首次出现处。
- **cattāro …ūpamā puggalā santo saṃvijjamānā lokasmiṃ**：
  - 老鼠经 §1010 句 49-60 与 §1014 句 98-112 译作「世上存在着、确实可以见到四种像老鼠一样的人」。
  - 公牛经 §1016 句 68-79 与 §1020 句 62-76 译作「世上确实存在着可以用这四种公牛来比喻的人」。
  - 两经句式完全平行，译法应统一。建议都用老鼠经的结构：「世上存在着、确实可以见到四种像公牛一样的人」。数词的归属问题见下文 §1016 句 68-79。
- **Kathañca … puggalo … hoti**：
  - 老鼠经 §1011-1014 句 2-15 译「怎样的人是……的呢」。
  - 公牛经 §1017-1020 句 2-15 译「一个人怎样才是……呢」。
  - nissaya 为 `ကထဉ္စ= ဖြင့်`，是具格，表示方式（以什么方式）。公牛经的译法更贴切，建议老鼠经统一为「一个人怎样才是……的呢」。
- **tathūpamāhaṃ … imaṃ puggalaṃ vadāmi**：
  - 老鼠经 §1011-1014 译「我说这个人就像那样」。
  - 公牛经 §1017-1020 译「我说这个人就跟那样的公牛相似」。
  - nissaya：`တထူပမံ= ထိုကြွက်ဥပမာရှိ၏ဟူ၍`，意为「（这个人）以那只老鼠为喻」，比喻对象是明确的。老鼠经的「就像那样」丢掉了比喻对象。建议统一为「我说这个人就像那只老鼠／那头公牛」。
- **seyyathāpi sā mūsikā / so balībaddo**：
  - 老鼠经译「就像那种……的老鼠」，公牛经译「就像那头……的公牛」。
  - nissaya 为 `သာ မူသိကာ= ထိုကြွက်သည်`，指「那只老鼠」，是单数的个体，不是「种类」。建议老鼠经改为「那只」，与公牛经的「那头」对应。
- **ekacco puggalo**：
  - 老鼠经 §1011-1014 句 16- 译「有某个人」，公牛经 §1017-1020 句 15/16- 译「有一种人」。
  - 建议统一为「有某个人」。

## §1010 句 87-1010-49-60
- **问题**：格与句法（轻）— nissaya 为 `မူသိကူပမာ= ကြွက်ဟူသော ဥပမာရှိကုန်သော`（以老鼠为喻的），修饰 `ပုဂ္ဂလာ`。「像老鼠一样的人」可以接受。本句的问题是须与公牛经平行句统一，见上一节。
- **建议**：保留现译，作为两经统一的基准。

## §1011 句 87-1011-89-96
- **问题**：补出成分 — nissaya 补出 `တထူပမံ= (တွင်းတူးရုံသာတူး၍ မခိုအောင်းသော) ထိုကြွက်ဥပမာရှိ၏ဟူ၍`，即以那只只挖洞不住洞的老鼠为喻。译文「就像那样」没有说出比喻对象。§1012 句 91-99、§1013 句 93-100、§1014 句 90-97 同样有此问题。
- **建议**：改为「比丘们，我说这个人就像那只老鼠。」同时把前一句的「那种老鼠」改为「那只老鼠」。

## §1016 句 87-1016-41-67
- **问题**：
  - 首次出现处缺巴利夹注。
  - nissaya 用处格 `၌`（在牛群中），「自群牛／他群牛」是生造的词，读起来生硬。
- **建议**：改为「对本群凶暴（sagavacaṇḍa）而对外群不凶暴的，对外群凶暴而对本群不凶暴的，对本群凶暴、对外群也凶暴的，对本群不凶暴、对外群也不凶暴的——比丘们，这就是四种公牛。」各段比喻句同步改。

## §1016 句 87-1016-68-79
- **问题**：格与句法（必改）— nissaya：`စတ္တာရော= လေးမျိုးကုန်သော`、`ဗလီဗဒ္ဒူပမာ= နွားလား ဥပမာ ရှိကုန်သော`、`ပုဂ္ဂလာ`。「四」是主格复数，修饰的是 puggalā（人），不是公牛。译文「可以用这四种公牛来比喻的人」把数词挪给了公牛，还多出原文没有的「这」。§1020 句 62-76 也有同样问题，该句没有 nissaya，但两句平行，应一并修正。
- **建议**：改为「同样地，比丘们，世上存在着、确实可以见到四种像公牛一样的人。」

## §1016 句 87-1016-83-100
- **问题**：术语一致（必改）— nissaya 在此仍释作 `မိမိနွားအုပ်၌သာ ကြမ်းတမ်းသည်`，并补出 `ပုဂ္ဂလော= နွားလားနှင့်တူသော ပုဂ္ဂိုလ်`。也就是说，词义不变，只是主体换成了像公牛的人。译文改成「对自己人凶暴」，切断了与上文公牛分类的同词对应。另外，夹注放在了这里，而不在首次出现处。
- **建议**：改为「对本群凶暴而对外群不凶暴的，对外群凶暴而对本群不凶暴的，对本群凶暴、对外群也凶暴的，对本群不凶暴、对外群也不凶暴的。」删去本句夹注。§1017-1020 各句的「对自己人／对外人」同步改为「对本群／对外群」。

## §1017 句 87-1017-16-28
- **问题**：词法（轻）— nissaya：`ဥဗ္ဗေဇေတာ= ထိတ်လန့်စေတတ်သည်`，异释 `ဝါ= ခြိမ်းခြောက် ငေါက်ငမ်းတတ်သည်`。助词 `တတ်` 表示惯常（常会这样做），异释的意思是「恐吓、呵斥」。现译「使……惊恐不安」意思不错，但没有体现惯常性。
- **建议**：可选改为「他常使自己的会众惊恐不安」。§1018 句 16-28、§1019 句 15-25、§1020 句 15-28 同步调整。异释（恐吓、呵斥）按 style.md 可作脚注备列。
