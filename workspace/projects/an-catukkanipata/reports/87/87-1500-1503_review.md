# Review — 87:1500-1503（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无独立 nissaya 行，已由相邻行覆盖的按覆盖范围核对，其余略过）

## 跨段一致性
- **atha**（atha so satto khippaṃyeva visesagāmī hoti）：§1501、§1502×2、§1503×2 共 5 处都译作「但」。nissaya 每处都作时间副词：`အထ= ထိုအခါ၌`（在那时），并补出所指的时机：§1501 是「法句浮现的那时」，§1502 是「听比丘说法、思惟起来的那时」。原文不是转折，建议 5 处统一改为「于是 / 那时」，例如「……忆念的生起虽然缓慢，但那时那个众生很快就趣向殊胜」或「……是缓慢的；而一旦忆起，那个众生很快就……」。转折的意味只能落在 dandho 一句（nissaya `လေးနှေးနေသေး၏`，「还慢」），不能落在 atha 上。
- **diṭṭhiyā**：全 chunk 共 8 处都译「以见」。nissaya 作 `ဒိဋ္ဌိယာ= ပညာဖြင့်`（以慧）。单字「见」容易被读成「见解 / 邪见」的见。建议统一改为「以智慧」或「以正见」，8 处同步。
- **na heva kho … plavanti**：§1502、§1503 共 4 处都译「却没有浮现出来」。nissaya 作 `မပေါ်လွင်မထင်ရှားသေးကုန်`，带 `သေး`（尚未）。建议统一改为「还没有浮现出来」，这样和后文「经提醒才忆起」的情节衔接得上。

## §1501 句 87-1501-2-26
- **问题**：取义 — `ဒိဋ္ဌိယာ= ပညာဖြင့်`，diṭṭhi 在此即慧，见跨段一致性一节。
- **问题**：格 — nissaya 作属格结构 `ဓမ္မာနံ= …တို့၏` + `အာနိသံသာ= …ကို`，即「（已随耳而入……的）那些法的四种利益」。译文用条件句「法若已……便可期待……」处理，意思不错，但把属格关系换成了假设关系。可以接受，若要贴合可改为「对于已随耳而入……的法，可以期待四种利益」。另外 `ပါဋိကင်္ခါ` 的异释 `ဝါ= ဧကန်ရရှိနိုင်ကုန်၏`（必定可得），可在报告备列，不必改正文。
- **建议**：「以见透彻通达」改「以智慧透彻通达」。

## §1501 句 87-1501-71-85
- **问题**：词义 — `မုဋ္ဌဿတိ= လွတ်ကင်းသော သတိရှိလျက်`，意为「念已失落」。「正念不现前」把 sati 加译成了「正念」，在这里也不够贴切：nissaya 在下文把 sati 补成 `ဘုရားစကားတော်ကို အမှတ်ရမှု`（对佛语的记忆）。
- **建议**：改为「他在失念的状态下命终」或「他忘失忆念而命终」，§1502、§1503 共 5 处同步。

## §1501 句 87-1501-86-104
- **问题**：句法 — `သုခိနော= ချမ်းသာသုခရှိနေသော` 修饰 `တဿ= ထိုပုဂ္ဂိုလ်မှာ`，是「对那位安乐者而言」的定语结构，不是独立谓语。译文「他在那里安享快乐，种种法句便浮现出来」拆成了两件并列的事。
- **问题**：词义 — `ဓမ္မပဒါ= ပရိယတ္တိပါဠိ အဖို့အစု တို့သည်`，指生前所学教法经文的各个部分。「法句（dhammapada）」加上夹注，容易被误认成《法句经》。
- **建议**：改为「在那里安乐的他，心中会浮现出所学经文的语句」。dhammapada 改译「法的语句」或「经文语句」，夹注可保留，但不要单作「法句」。§1502、§1503 的同句结构同步调整。

## §1501 句 87-1501-111-117
- **问题**：句法 — atha 误作转折，见跨段一致性一节。另外 `ဝိသေသဂါမီ= နိဗ္ဗာန်တရားထူးသို့ ရောက်သည်`，「殊胜」所指是涅槃这一殊胜法。「趣向殊胜」可以保留，但「到达」比「趣向」更贴近 `ရောက်`。
- **建议**：「于是那个众生很快就达到殊胜（之境）」。§1502、§1503 的同句同步。

## §1502 句 87-1502-62-72
- **问题**：补出成分 — nissaya 补 `ဘိက္ခု= ရဟန္တာဖြစ်သော ရဟန်းသည်`（身为阿罗汉的比丘）。译文没有补，原文也没有这个词，不补是合理的。这里只记录供后续核对，不改。

## §1502 句 87-1502-96-102
- **问题**：句法 — `အထ= ထိုအခါ၌（ထိုရဟန်း၏ တရားကိုနာယူ၍ ဆင်ခြင်စဉ်းစားမိရာ ထိုအခါ၌）`，「但」应改为时间承接。
- **建议**：同跨段一致性一节。

## §1502 句 87-1502-111-115
- **问题**：词义 / 语气 — `အဒ္ဓါနမဂ္ဂပဋိပန္နော= ရှည်ဝေးသော ခရီးကိုသွားသည်`，意为「走远路」，没有「大路」的意思。`သုဏေယျ= ကြားရာ၏` 是假设语气（譬喻里的「假如听到」），译文写成已然的「听到了」。
- **建议**：「他在长途旅行中听到鼓声」。§1503 的螺贝声一句同步。

## §1502 句 87-1502-203-213
- **问题**：nissaya 对齐异常 — 该行 nissaya 是 `နပိ ဒေသေတိ= ဟောသည်လည်း မဟုတ်`（也不说法），和本句原文 api ca kho bhikkhu … deseti（然而有比丘说法）正好相反，内容对应的是 §1503 的 napi bhikkhu … deseti，疑似错挂。译文跟随巴利原文，是正确的，**不改**。nissaya 数据错位需要另行记录。
