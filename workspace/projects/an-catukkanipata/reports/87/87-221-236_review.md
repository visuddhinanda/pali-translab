# Review — 87:221-236（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（221、222 部分句、224-27-52、225-2-19、226-20-46、227-2-19、229-79-96/97-114、230、232、234 没有单独的 nissaya 行；其中有些句子的内容，由同一段或相邻句的 nissaya 行用 `ပ`（同前略）连带覆盖，下文只按这些 nissaya 实际给出的内容引用）

## 跨段一致性

- **gārava / garu（尊重）**：garuṃ katvā（§223–229、§236）、saddhammagaruno（§233）、garukātabbo（§235）、gāravo（§236）都译「尊重」。只有 §223 的 agāravo 译成「不恭敬」，而「恭敬」在全 chunk 是 sakkatvā 的译法。这样两个词就混了。→ 建议 §223 改为「不尊重」。依据：`အဂါရဝေါ= လေးစားထိုက်သူတို့၌ ရိုသေလေးစားခြင်းမရှိသော`（对值得尊重的人没有尊重），与 `ဂါရဝေါ= လေးစားသည်၏ အဖြစ်`（§236）同根。
- **sampanna 与 paripūra**：§224–227 的 aparipūrassa … pāripūriyā 译「不圆满……使它圆满」；sīla-/samādhi-/paññā-/vimutti-sampannataraṃ 也译「比我更圆满」。两个词混成了一个。nissaya 分得很清楚：`ပါရိပူရိယာ= ပြည့်စုံခြင်းငှာ`（为了圆满），`သီလသမ္ပန္နတရံ= သီလနှင့် သာလွန်၍ ပြည့်စုံသော`（以戒更为具足的）。→ 建议 §224/225/226/227 的「在戒／定／慧／解脱上比我更圆满」统一改为「在戒／定／慧／解脱方面比我更具足」。
- **yvāyaṃ dhammo … tameva dhammaṃ**：§228 译「这个法」，§236 译「那个法」，两处巴利完全相同。→ 统一为「这个法」。两处的 eva 也都漏了，见下文各句。
- **mahatta**：§234 的 mahattaṃ 与 §236 的 mahattena 都译「伟大」，但 nissaya 取义不同。§234 是 `မဟတ္တံ= မြင့်မြတ်သည် အဖြစ်`（崇高）；§236 是 `မဟတ္တေန= များသည်အဖြစ်နှင့်`（众多、广大，并补出「以 rattaññūmahatta 等四种广大」）。两处不能共用一个词，见 §236。
- **§224–227 的四组平行句**：「如果我的X蕴还不圆满……我就应该……」这个句式四段都有，问题见 §224，同样的修改要贯彻到 225-2-19、226-2-19、227-2-19。

## §223 句 87-223-2-17

- **问题**：专名误作意译。`အဇပါလနိဂြောဓေ= အဇပါလမည်သော ပညောင်ပင်အောက်၌`，意思是「在名为阿阇波罗的榕树下」，nissaya 把它当专名。译文「牧羊人榕树」是拆字的词源义。
- **建议**：改为「阿阇波罗榕树（Ajapālanigrodha）下」。
- **问题**：句法归属不对。nissaya 补出 `( ဟုတွာ= ဖြစ်၍။)`，把句子读作 abhisambuddho hutvā paṭhamaṃ … viharāmi，又说明 `ပဌမံ= ရှေးဦးစွာ`（在其他地方住之前，最先）是修饰 viharāmi 的状语。也就是说，paṭhamaṃ 说的是「最先住在这里」，不是「证得正觉不久」。
- **建议**：改为「比丘们，有一次，我证得正觉之后，最先住在优楼频螺，尼连禅河岸边的阿阇波罗榕树下」。

## §223 句 87-223-30-36

- **问题**：词义取窄。`အပ္ပတိဿော= မှီခိုထိုက်သော အကြီးအကဲမရှိသော`，意思是「没有可以依止的尊长」，异释是「不把任何人放在依止、尊长的位置」。译文「不敬顺任何人」偏向「听从命令」一解，没有表达出「无所依止」，与下一句「依止他生活」也接不上。
- **问题**：语法角色。`ဒုက္ခံခေါ= ခက်ခဲစွာသာလျှင်` 是状语（艰难地），nissaya 还补出主语 `( ပုဂ္ဂလော= ပုဂ္ဂိုလ်သည်။)`（一个人）。
- **建议**：改为「‘一个人不尊重任何人、没有可依止的尊长，这样生活是苦的。」agāravo 的改法见跨段一致性。

## §223 句 87-223-37-64

- **OCR / 原文疑问**：nissaya 注 `“ကံ” ဟုရှိသင့်၏`，认为 Kiṃ 应作 kaṃ（参《有偈品》140）。译文「哪一位」已经按 kaṃ 理解，译文不用改，这里只记录原文疑点。

## §224 句 87-224-2-26（同样适用于 225-2-19、226-2-19、227-2-19）

- **问题**：句法误读。`အပရိပူရဿ= မပြည့်စုံသေးသော`（尚未圆满的）是 sīlakkhandhassa 的定语，不是条件从句。译文「如果我的戒蕴还不圆满」多出了一个假设。
- **问题**：情态。`ဝိဟရေယျံ= နေလို၏`（想要住）。译文「就应该」是义务语气，与 nissaya 不符。
- **建议**：改为「为了使尚未圆满的戒蕴得以圆满，我愿意恭敬、尊重另一位沙门或婆罗门，依止他生活」。

## §224 句 87-224-27-52（依 225-20-45 的 nissaya）

- **问题**：`သီလသမ္ပန္နတရံ= သီလနှင့် သာလွန်၍ ပြည့်စုံသော`，是「以戒更为具足」。译文「在戒上比我更圆满」与上句的 pāripūri 混成一个词。
- **建议**：改为「在戒方面比我更具足」。225-20-45、226-20-46、227-20-48 照此改。

## §227 句 87-227-20-48

- **OCR / 原文疑问**：226-2-19 的 nissaya 注明，原文缺「aparipūrassa kho ahaṃ vimuttiñāṇadassanakkhandhassa pāripūriyā …」这一组。《有偈品》141 有这一组，nissaya 也给出了 `ဝိမုတ္တိဉာဏဒဿနက္ခန္ဓဿ`（解脱知见蕴）的释义。按现有原文翻译即可，这里只记录疑点，不改。

## §228 句 87-228-12-42

- **问题**：漏译 eva。`တမေဝ ဓမ္မံ= … ထိုလောကုတ္တရာတရား ကိုးပါးကိုသာလျှင်`，意思是「只以那个法」。译文没有译出「只」。
- **建议**：改为「‘我何不就以我所证悟的这个法为对象，恭敬它、尊重它，依止它生活呢？’」

## §229 句 87-229-51-71

- **问题**：补出成分没有译出。`ဧကံသံ= … လက်ဝဲဘက် ပခုံးပေါ်၌`，意思是「搭在左肩上」。译文「整理到一边肩上」没有说是哪一肩，读者看不出是偏袒右肩的礼仪。
- **建议**：改为「把上衣搭在左肩上（偏袒右肩）」。

## §229 句 87-229-79-96（依 229-115-132 的 nissaya）

- **问题**：漏译谓语。`အဟေသုံ= ပွင့်ထွန်းတော်မူခဲ့ကြကုန်ပြီ`，意思是「曾经出现」。下一句的 bhavissanti 已译成「将要出现的」，这一句的 ahesuṃ 却没有译，两句不对称。
- **建议**：改为「尊师，过去世曾经出现的那些阿罗汉、正等正觉者……」

## §229 句 87-229-115-132

- **问题**：句法误读。arahaṃ sammāsambuddho 是 bhagavā 的同位定语：`အရဟံ= …ထိုက်သော`、`သမ္မာသမ္ဗုဒ္ဓေါ= …တော်မူသော`，都带定语标记 သော。原句的谓语只有 viharatu。译文「现在世尊是阿罗汉、正等正觉者」把定语读成了判断句。
- **建议**：改为「尊师，现在身为阿罗汉、正等正觉者的世尊，也请只恭敬、尊重法，依止法生活吧。’”」

## §235 句 87-235-2-11（连带 234-2-19）

- **问题**：取义偏差。`အတ္တကာမေန= မိမိ၏စီးပွားချမ်းသာကို အလိုရှိသော`，意思是「希求自身利益安乐的」。译文「爱惜自己」意思偏了，容易读成自爱、自惜。
- **建议**：234-2-19 改为「所以，希求自身利益、渴望崇高的人，」。mahattaṃ 照 nissaya 的 `မြင့်မြတ်သည် အဖြစ်` 译「崇高」，与 §236 区分开。

## §236 句 87-236-19-48

- **问题**：漏译 eva；与 §228 不统一（§228 译「这个法」，本句译「那个法」）。
- **建议**：改为「……就以我所证悟的这个法为对象，恭敬它、尊重它，依止它生活」。

## §236 句 87-236-49-68

- **问题**：取义。`မဟတ္တေန= များသည်အဖြစ်နှင့်`，nissaya 补出「以 rattaññū-mahatta 等四种广大」，指僧团在规模、资历等方面的广大、众多，不是抽象的「伟大」。
- **建议**：改为「比丘们，当僧团也成就了广大时，我对僧团也生起了尊重。”」
