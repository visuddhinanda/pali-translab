## 理由

**资源缺失（影响信心）**：本次只注入了巴利本文与现有译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此准确性判断只能依据巴利原文形态、句法与通行术语对照，无法按「义注定释义、nissaya 定词法」逐词核验格与传统取义。涉及 `samādapeti` 的受格宾语（`assaddhiye / ahirikatāya / anottappe / kosajje / muṭṭhassacce / duppaññatāya`，处格与属格混用）是否各有特定释义，以及 `assaddha` 的具体所信对象，都未能用义注确认。信心分据此压低。

**准确性**：七支对举（assaddha / ahirika / anottappī / appassuta / kusīta / muṭṭhassati / duppañña）及其正面对应项（saddha / hirimā / ottappī / bahussuta / āraddhavīriya / satimā / paññavā）全部译出，无漏译、无增译；`asappurisena asappurisataro` 的具格比较结构处理正确（「比不善的人更为不善」）；`attanā ca … parañca … samādapeti` 的「自己…还劝别人…」对称结构贯通七句，`upaṭṭhitassati / satiupaṭṭhāne` 译为「正念现前 / 使正念现前」贴合词形；异读（`asaddhāya` / `muṭṭhasacce` / `hirisampadāya` / `satipaṭṭhāne`）未进正文，处理得当。主要扣分点是 `assaddha` 译作「没有信心」——词义方向不错，但在现代汉语里默认读作「缺乏自信」，属导致误解的表达。

**风格符合度**：通篇现代书面汉语，无文言虚词、无文言句式，未出现禁例表中的任何写法；标点全角，引号用全角 “”，跨段连续引语按「每段开引、末段收引」处理，正确；译文内无 ASCII 引号，JSON 安全；无任何残留工作标记（候选 / 待定 / 问号）。扣分来自术语夹注只做了前四项、后三项（懈怠、失念、智慧薄弱）与正面七项（除「信心」外）均无巴利夹注，与 `style.md`「法相术语首次出现夹注巴利原词」的要求只落实了一半。

**一致性**：`asappurisa` 译「不善的人」而 `sappurisa` 译「善人」，正反两侧命名不对称；`āraddhavīriya` 在 1644 作「精勤」、在 1645 又与「精进」并用；夹注词形一侧取形容词（assaddha）、一侧取名词（saddhā）；七句排比中唯 `duppaññatāya` 一句多出「变得」，破了句式节奏。都不造成误解，但属于可提升的统一性问题，是本段扣分最集中处。

## 问题清单

### 🟧 error
- `87-1642-11-36`｜导致误解的表达｜片段「他没有信心（assaddha）」
  - 问题：现代汉语「没有信心」的默认义是对自己或对成败缺乏自信，而 `assaddha` 指对佛法僧三宝不具信（信根缺失），读者极易误读为心理层面的不自信。
  - 建议：改为「他不具信（assaddha，指对佛法僧缺乏信心）」，或「他没有信（assaddha）」，把宗教意义上的「信」与日常「信心」区分开。
- `87-1643-12-32`｜导致误解的表达｜片段「他自己没有信心，还劝别人也没有信心」
  - 问题：同上条，且与 `samādapeti`（劝导他人安住于某状态）连用后，「劝别人也没有信心」更像劝人泄气，而非劝人不信佛法。
  - 建议：改为「他自己不具信，还劝导别人也不具信」。与 1645-12-26「信心具足」一并统一为「信」系术语。

### 🟨 warning
- `87-1642-11-36`｜关键词语意不明确，或二意场合没有注释｜片段「失念」
  - 问题：`muṭṭhassati` 译作「失念」，对无佛学背景的读者语意不明（易读作「失去记忆」），且未夹注巴利原词、无注释，与同句前四项都有夹注的处理不一致。
  - 建议：改为「正念丧失（muṭṭhassati）」或保留「失念（muṭṭhassati）」并加一条简注。
- `87-1645-61-69`｜整句逻辑表达不规范｜片段「自己精勤，还劝别人也发起精进」
  - 问题：同一支（`āraddhavīriya` / `vīriyārambha`）在一句之内用了「精勤」与「精进」两个词面，前后像两件事；1644-12-37 又只用「精勤」。
  - 建议：统一为「自己精进勤勉，还劝别人也发起精进」，或两处都用「精勤」。

### 🟦 suggestion
- `87-1641-2-18`｜语言风格不统一｜片段「不善的人，以及比不善的人更为不善的人」
  - 问题：`asappurisa` 作「不善的人」、`sappurisa` 作「善人」（见 1644-12-37、1644-38-44），正反两侧构词不对称，排比读来失衡。
  - 建议：统一为「不善人 / 善人」或「不善的人 / 善的人」，全段一致。
- `87-1642-11-36`｜该使用而没有使用术语标记｜片段「懈怠，失念，智慧薄弱」
  - 问题：同句前四项都夹注了巴利原词，后三项（kusīta / muṭṭhassati / duppañña）却无；1644-12-37 的正面七项中也只有「信心（saddhā）、惭（hiri）、愧（ottappa）、多闻（bahussuta）」有夹注，「精勤、有正念、有智慧」无。
  - 建议：首次出现的七支及其正面对应项一律夹注，或一律不注，取其一。
- `87-1644-12-37`｜语言风格不统一｜片段「他有信心（saddhā）」
  - 问题：夹注词形与 1642-11-36「（assaddha）」不对称——一侧取形容词，一侧取抽象名词；同句「有惭（hiri）、有愧（ottappa）」又回到名词形。
  - 建议：夹注统一取词典形（saddha / assaddha，或 saddhā / assaddhiya），全段一个体系。
- `87-1643-92-100`｜语言风格不统一｜片段「还劝别人也变得智慧薄弱」
  - 问题：七句排比中前六句都是「还劝别人也 + X」，唯此句插入「变得」，句式破格。
  - 建议：改为「还劝别人也智慧薄弱」。
