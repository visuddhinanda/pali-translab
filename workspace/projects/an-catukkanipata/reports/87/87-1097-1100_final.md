## 问题清单

### 🟧 error

- `87-1098-51-85`｜错译（修饰关系）｜片段「在这个法与律当中，有一位良家子从家中出来、过上无家的出家生活，他也应当预期会有四种怖畏」
  - 问题：`imasmiṃ dhammavinaye` 在原文中修饰的是 `pabbajitassa`（在此法律中出家者），即「于此法律中出家」；译文把它提到句首作整句的场所状语（「在这个法与律当中…应当预期」），改变了修饰归属。同时 `idhekaccassa kulaputtassa` 的 `idha`（「在这里／于此（教法中）」）未译出，与 1099/1100 两段译「在这里」不一致。
  - 建议：按「比丘们，同样地，这里有一位良家子，在此法与律中从家中出来、过无家的出家生活，他应当预期会有这四种怖畏」之类的语序，把「在此法与律中」贴回「出家」上，并补出 `idha`。
- `87-1099-55-87`｜错误多译｜片段「你应当这样弯曲肢体，你应当这样伸展肢体」
  - 问题：`samiñjitabbaṃ` / `pasāritabbaṃ` 原文无宾语（即「这样屈、这样伸」，传统指屈伸手足的威仪），译文补出了原文没有的「肢体」，且与前后「向前走／往回走／向前看／向旁看」都不带宾语的处理不对称。按 `style.md` 第六节「不擅自补足省略主语（除非语义必须）」，此处补足非必须。
  - 建议：改作「你应当这样屈，你应当这样伸」，或若确需明示，统一在整组威仪上加一句总说，而不是单给两项加宾语。
- `87-1099-55-87`｜错译（词义）｜片段「你应当这样持用僧伽梨、钵和衣」
  - 问题：`saṅghāṭi-patta-cīvaraṃ` 是三物并列复合词（重衣／僧伽梨、钵、衣），译文虽列出三项，但「僧伽梨」已是 `saṅghāṭi` 的音译、「衣」是 `cīvara` 的意译，三项并列中两项都指衣物而译名体例不一，读者难以分辨「僧伽梨」与「衣」的区别；且 `dhāretabba` 对「钵」用「持用」尚可，对衣物应为「披着／穿着」。
  - 建议：统一体例，如「你应当这样披持僧伽梨（saṅghāṭi）、钵和衣」，或「重衣、钵与衣」并在首次出现夹注巴利原词。

### 🟨 warning

- `87-1099-37-46`｜关键词语意不明确｜片段「但愿这全部苦聚的终结能够显现出来！」
  - 问题：`appeva nāma … paññāyetha`（愿望语气 + `appeva nāma`）表达的是「或许就能／但愿能够」的审慎期望，译作「但愿…能够显现出来」语气偏强且「显现出来」对 `paññāyetha`（被了知、被看见、得以明了）取义偏窄，容易被读成「苦的终结自己出现」而非「我得以证知苦的终结」。本段与 1100-37-46 同句同问题。
  - 建议：改作「但愿我能看到这整个苦聚的终结」或「或许我能了知这整个苦聚的终结」，使施受关系明确。
- `87-1099-102-113`｜整句逻辑表达不规范｜片段「我看年纪只够当我的儿子、只够当我的孙子」
  - 问题：`puttamattā maññe nattamattā maññe` 中的 `maññe` 是语气词（「我看／简直是」），译文把「只够当」重复两次、又前置一个「我看」，三重语气叠加，句子冗赘；且「年纪只够当我的孙子」在汉语里与前句递进关系不清。
  - 建议：精简为「这些人我看简直只是我的儿子、孙子辈」。
- `87-1100-55-166`｜不该/该使用术语标记不一致｜片段「这个你可以嚼食，这个你不可以嚼食；这个你可以正食」
  - 问题：「嚼食／正食／尝食」是 `khādanīya / bhojanīya / sāyanīya` 的律藏专门译法，对一般读者几乎不可解，而按 `style.md` 第二节「法相术语首次出现夹注巴利原词」，此处首次出现未夹注；同句内 `kappiya` 却夹注了「（kappiya）」，同一句术语标记策略自相矛盾。
  - 建议：首次出现处补夹注，如「嚼食（khādanīya）／正食（bhojanīya）／尝食（sāyanīya）」，与 `kappiya` 的处理对齐。
- `87-1100-262-293`｜关键词语意不明确｜片段「这些同梵行者也好像要把我的嘴封起来一样」
  - 问题：原文 `tatrapime … mukhāvaraṇaṃ maññe karonti` 的主语是 `ime`（这些人），译文补出「同梵行者」属解释性补足——原文此处只作「这些人」，与同段 1099-102-113 译「这些人」不一致；`mukhāvaraṇaṃ`（口之遮障／塞口）传统指「给嘴上盖子、堵住嘴」，「把嘴封起来」意思可通但偏口语化。此条本应以义注取义为准，而本次**无义注可核**，故按 warning 而非 error 处理。
  - 建议：与 1099 统一作「这些人」；表达可改为「简直是给我的嘴加上了盖子」。
- `87-1099-114-120` / `87-1099-121-132`｜语言风格不统一（同一套语两种译法）｜片段「退回到低下的在家生活」与「退回在家低下生活的人」
  - 问题：`hīnāya āvattati` / `hīnāyāvatto` 两处译法语序不一（「低下的在家生活」vs「在家低下生活」），后者汉语搭配不顺。1100-294-300 与 1100-301-312 同样一对。
  - 建议：统一为「退回到低下的在家生活」，后者作「…而舍弃学处、退回低下的在家生活的人」。

- `87-1099-10-21`｜语言表达不够流畅｜片段「有一位良家子因为信心而从家中出来，过上无家的出家生活，他想：」
  - 问题：`saddhā`（因信心）译作「因为信心而」稍显生硬，「过上无家的出家生活」中「过上」带有「终于达成」的语感，与出家的语境略有温差；末尾「他想：」是译者补出的引导语（原文此处无 `tassa evaṃ hoti`，引语直接接在 `pabbajito hoti –` 后），虽为汉语所需，但与 1099-88-91 真正的 `Tassa evaṃ hoti` 译文「他心里就这样想：」形成两个相似的引导语，读者易混。
  - 建议：首句可作「出于信心而离家、过无家的出家生活，心想：」，与后文「他心里就这样想：」拉开区别。
- `87-1100-171-188` 起四句｜语言表达不够流畅｜片段「想嚼什么就嚼什么，不想嚼的就不嚼」
  - 问题：此处把「嚼食/正食/尝食/饮用」缩成单字「嚼／正食／尝／饮用」，与同段 55-166、225-261 的完整译法不一致（如 201-212 作「想尝什么就尝什么」而 225-261 作「尝食」），四组的内部体例参差。
  - 建议：四组统一用同一组词形（嚼食／正食／尝食／饮用），避免同段内三种写法。
- `87-1100-225-261`｜复杂嵌套句对读者不友好｜片段「合乎规定的也嚼食，不合规定的也嚼食；…过了时间也饮用；」
  - 问题：原文本身是 16 项排比，译文忠实保留，但整句过长、无分层，连续「也…也…」易让读者失去位置感。
  - 建议：可在「合乎规定/不合规定」与「在许可时间/过了时间」两组之间加一处语义停顿（如「不论…还是…，都…」的概括句式），在不删内容的前提下降低阅读负担。
