## 问题清单

### 🟧 error

- `87-1595-49-57`｜错译（修饰关系）｜片段「他具备这样无过失的圣戒蕴（sīlakkhandha），在自身中感受到没有过失的快乐」
  - 问题：原文 `iminā ariyena sīlakkhandhena samannāgato ajjhattaṃ anavajjasukhaṃ paṭisaṃvedeti` 中，`anavajja`（无过失）只修饰后面的 `sukhaṃ`，`sīlakkhandha` 的修饰语只有 `ariyena`（圣）。译文把"无过失"提前加到了戒蕴上，再在后半句重复一次"没有过失"，等于把一个修饰语用了两遍，且前一处无原文依据。
  - 建议：前半句删去"无过失的"，作"他具备这样的圣戒蕴（sīlakkhandha）"。

- `87-1596-80-88`｜错译（修饰关系）｜片段「他具备这样无过失的圣根律仪（indriyasaṃvara）」
  - 问题：同上。原文 `iminā ariyena indriyasaṃvarena samannāgato` 只有 `ariyena`，无 `anavajja`；本句的 `abyāseka`（不杂染）修饰的是 `sukhaṃ`，译文后半句"不被烦恼染污的快乐"已正确对应，前半句的"无过失的"是无依据的增译。
  - 建议：改作"他具备这样的圣根律仪（indriyasaṃvara）"。

- `87-1595-12-18`｜错误多译｜片段「都把全部资具随身带着就走」
  - 问题：原文 `samādāyeva pakkamati` 只是"带着（自己的东西）就走"，`samādāya` 没有"全部资具"的词面内容。"全部资具"（八资具/衣钵）是注释书的补充说明，写进正文属于把注释内容当原文译出；且本句紧接下文的鸟喻，鸟只带翅膀，喻意正在于"随身所有极少"，译文却说"全部"，与喻意方向相反，容易使读者误解。
  - 建议：改作"他无论到哪里去，都带着自己的（衣钵等）随身物就走"，或仅作"都带着随身的东西就走"，"全部资具"的解释移入脚注。

- `87-1595-40-48`｜错误多译｜片段「都把全部资具随身带着就走」
  - 问题：与 `87-1595-12-18` 同一处问题的重复出现（本句是定型句的第二次复现）。两处须同时修改，否则一致性被破坏。
  - 建议：与上一条采用完全相同的改法。

- `87-1595-19-30`｜错译（词义）｜片段「都只带着自己的翅膀飞」
  - 问题：`sapattabhāro` 是 `sa-patta-bhāra`（以羽翼为负担者），核心词 `bhāra`（负担、所负之物）被完全丢掉。原文的喻意是"所背负的只有一身羽毛"，译文"只带着自己的翅膀"把 bhāra 译空，且"带着翅膀飞"在汉语中近乎同义反复（鸟本来就是用翅膀飞），喻点失落。
  - 建议：改作"都只以自己的一身羽毛为负担地飞"，或意译"所背负的只有自己的一身羽毛"。

- `87-1593-125-135`｜义理或用词与注释书不符｜片段「说有益于现世与来世的话」
  - 问题：`attavādī` 一词有歧解（attha = 义/利益；或传统释为"说有义利的话"），译文直接取"现世与来世"这一层并写入正文，是把一种解释当定解；且与同句后面的 `dhammavādī`（说合乎法的话）形成语域跳脱——其余五项 `kālavādī / bhūtavādī / dhammavādī / vinayavādī` 都是"合乎 X / 符合 X"的同构译法，唯独此项变成了效用判断。此处无义注可据，按分歧处理但仍需降分。
  - 建议：改为与并列项同构的"说有意义、有利益的话"，把"现世与来世"的解释移入脚注；义注取回后据义注定稿。

- `87-1597-2-46`｜错误多译｜片段「他前进后退时保持正念正知」
  - 问题：`sampajānakārī` 只含 `sampajāna`（正知），`sati`（念）在本句原文中并未出现。译作"正念正知"是把四念住语境里的常见搭配搬进来，属增译；本段全句七处同样处理，读者会以为原文每处都并举念与知。
  - 建议：统一改为"保持正知"或"以正知而行"，全句七处一并修改。

### 🟨 warning

- `87-1594-9-14`｜文言语体｜片段「他只在午前那一段时间受用饭食」
  - 问题：「受用饭食」是半文半白写法（"受用"为文言动词，"饭食"为文言名词组），`style.md` 第一节禁例表明确要求"用膳→吃"这类改写，本处同属一类。
  - 建议：改作"他只在午前那一段时间吃饭"或"他一天只吃一顿（午前的）饭"。

- `87-1594-2-8`｜语言风格不统一（并列句译词摇摆）｜片段「他戒除损毁种子类和草木类植物的行为」
  - 问题：`paṭivirato hoti` 在 1594 段连续出现近二十次，仅本句译作"戒除"，其余均作"远离"；`87-1593-37-45` 又作"戒绝"。同一词在紧邻的并列定型句中用三种译法，读者会误以为三者程度不同。
  - 建议：全段统一为"远离"（或统一为"戒除"），仅保留一种。

- `87-1593-37-45`｜关键词语意不明确｜片段「戒绝这种凡夫俗人的不正当行为」
  - 问题：两处。一是"戒绝"与全段"远离"不统一（见上条）；二是 `asaddhammā gāmadhammā` 是两个并列的从格（非正法、村人法/凡俗之法），译文把两者并成一个带指示词的名词组"这种…行为"，`asaddhamma`（不正之法）与 `gāmadhamma`（村人之法）的并列结构消失，且"凡夫俗人"在汉语中带贬人色彩，而原文贬的是"法/行为"不是人。
  - 建议：改作"远离不正之法、远离village 村人的淫欲之法"一类并列译法；至少去掉"凡夫俗人"的人身指向，作"远离这种不正当的、村人（世俗）的行为"。

- `87-1594-72-75`｜关键词语意不明确｜片段「他远离用假秤、假金器、假量器行骗」
  - 问题：`kaṃsakūṭa` 的"假金器"译法可疑。此词传统上多释为伪造铜器/以劣质铜冒充金器行骗，也有释为"假币"；但与前后 `tulākūṭa`（假秤）、`mānakūṭa`（假量器）并列，三者都是计量/交易欺诈手段，译作"假金器"读者难以把它与"行骗"的手段联系起来，语意不明。
  - 建议：取回义注后据义注定取义；暂可作"以铜器冒充金器行骗"并加简注，使手段关系明确。

- `87-1594-76-79`｜关键词语意不明确｜片段「以假充真这些弯曲不正的手段」
  - 问题：`sāciyoga` 的译法"弯曲不正的手段"与前面 `nikati`（诈术）译出的"以假充真"之间界限模糊，读者看不出这是四项并列（ukkoṭana / vañcana / nikati / sāciyoga）中独立的一项，而像是对前三项的总结性修饰。
  - 建议：把四项译成明确并列，`sāciyoga` 单独给一个可辨识的译法（如"用迂回手段取利"），并加简注。

- `87-1594-80-83`｜关键词语意不明确｜片段「埋伏劫掠、掠夺村镇、持刀强取这些行为」
  - 问题：原文 `chedana-vadha-bandhana-viparāmosa-ālopa-sahasākāra` 为六项并列，译文"埋伏劫掠 / 掠夺村镇 / 持刀强取"分别对应 `viparāmosa / ālopa / sahasākāra`，但三者语意高度重叠（都含"抢"），读者无法分辨差别；其中 `ālopa` 译"掠夺村镇"补出了原文没有的"村镇"，`sahasākāra` 译"持刀强取"补出了原文没有的"持刀"。两处补足都来自注释传统，但未加注说明。
  - 建议：三项改为可辨识且不越出词面的译法（如"途中埋伏抢劫 / 公然抢夺 / 强暴夺取"），注释内容移入脚注。

- `87-1594-28-31`｜关键词语意不明确｜片段「他远离接受金和钱币」
  - 问题：`jātarūpa-rajata` 的 `rajata` 本义是银（在戒律语境中引申指一切货币）。译作"钱币"是取引申义而丢字面义，读者看不出原文的"金银"对举；`jātarūpa` 译"金"则保留了字面。两者处理标准不一。
  - 建议：作"金和银"并加简注说明在戒律中涵盖一切货币；或统一取引申义作"金银钱财"。

- `87-1593-84-101`｜整句逻辑表达不规范｜片段「见到、听到和睦就欢喜」
  - 问题：`samagganandī` 只是"以和睦为乐/喜欢和睦"，"见到、听到"是译者补出的具体化动作，原文无此二字，且与前项 `samaggarato`（乐于和睦）语意重复，三项 `samaggārāmo / samaggarato / samagganandī` 的递进在译文里变成了交叉重叠。
  - 建议：三项译为可区分的层次（如"喜好和睦、乐于和睦、以和睦为欢喜"），删去"见到、听到"。

- `87-1593-2-22`｜关键词语意不明确｜片段「圆满遵行比丘们的学处和佛所制定的共同戒条」
  - 问题：`sikkhāsājīvasamāpanno` 中 `sājīva`（共同生活的规范）译作"佛所制定的共同戒条"，补出了"佛所制定"四字，原文无此限定；该补充来自注释，但正文未加标记也未加注。
  - 建议：作"具足比丘们的学处与共住规范"，"佛所制定"移入脚注。
