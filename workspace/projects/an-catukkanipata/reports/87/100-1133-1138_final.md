## 理由

**资源降级（影响信心）**：本次评估对象本身就是义注层（`8._Ariyavaṃsasuttavaṇṇanā`），上游没有可作「释义标准」的更高注释层；注入材料中也**没有 nissaya**（无 `type=nissaya` 内容），因此无法做词级格/句法角色核对。判断只依据巴利原文本身、律制与《清净道论》衣知足—头陀支的通行解释。涉及冷僻染材名（`kāḷakacchaka`、`somavakkala`）与度量术语（`timaṇḍala`、`kusi`）的取义，缺 nissaya 佐证，信心相应压低；分数在准确性一项上按「未见与原文冲突」计，而非按「已逐词验证」计。

**准确性**：整体忠实。二十种衣知足的名目（gamana / pariyesana / paṭilābha / mattapaṭiggahaṇa / loluppavivajjana / yathālābha / yathābala / yathāsāruppa / udaka / dhovana / karaṇa / parimāṇa / sutta / sibbana / rajana / kappa / paribhoga / sannidhiparivajjana / vissajjana）与加粗被释词一一对应，无漏项、无串位；`vattabheda`、`adhiṭṭhāna`、`sannidhi`、`sāraṇīyadhamma` 等律制概念取义正确；`mahāsīvatthera` 的引语范围划得准（「没有受持的才成为储存」整句归长老）。一处修饰关系误读：`paṇṇāni pakkhipitvā tāpitaudakena` 是「投入树叶后煮热的水」，译文把投叶与用热水洗拆成两个并列动作，见问题清单 🟧。`vajjetuṃ vaṭṭati` 译作「可以避开不用」，把「宜避」弱化为「允许」，属取向偏软而非误译，列入 🟦。

**风格符合度**：基本是现代书面汉语，未见 `此中/故为/彼等/是故/谓/乃/遂` 一类禁例，无「曰/云」「于…之际」「端坐」类句式；标点全角、引号统一用 “”，译文 `zh` 字段内未出现 ASCII 引号，JSON 安全无隐患；译文里没有残留候选、问号、TODO 等工作标记。扣分点集中在两处：`而知足`（「就所得到的而知足」）属半文半白的「就…而…」句式；以及 `yāpana` 统一译成「来应付」，在汉语里偏向「对付/敷衍」，与「维持日用」的本义有温差，`凑合着过` 又把语域拉到口语，与全篇书面语体不齐。

**一致性**：术语内部自洽——`cīvara` 一律「衣」、`dussa` 作「布料」、`santosa` 一律「知足」、`-santoso nāma` 一律「这叫做…知足」，加粗词与巴利被释词逐项对位。首次出现的罕见词都带了圆括号巴利夹注，符合 `style.md` 的夹注体例。唯 `yāpana` 三处同译「应付」虽一致但同时一致地偏了，故不计一致性扣分，只在风格与建议项处理。

## 问题清单

### 🟧 error
- `100-1135-40-47`｜错译（修饰关系）｜片段「也可以放进树叶，用煮热的水来洗」
  - 问题：`paṇṇāni pakkhipitvā tāpita-udakena` 中 `pakkhipitvā` 修饰 `tāpita`，指「投入树叶后煮热的（叶汁）水」，是一种水；译文用逗号把「放进树叶」与「用煮热的水洗」并列成两个动作，读者会理解为先往衣上/盆里放叶子、再另用热水洗。
  - 建议：改为「也可以用投入树叶煮热的水来洗」。

### 🟨 warning
- `100-1136-10-22`｜整句逻辑表达不规范｜片段「哪位比丘不去帮他，那位比丘也不算违犯义务（vattabheda）」
  - 问题：「哪位…那位…」不是规范的现代汉语关联结构，读来像设问未答；原意是任指（`yo … tassa`，凡不做帮手者皆不犯）。
  - 建议：「因为对这样缝制的人，任何比丘不做他的帮手，也不算违犯义务（vattabheda）。」
- `100-1137-47-53`｜代词指代不明确｜片段「也可以把它受持为敷具」
  - 问题：「它」可指上一句「给不出去的那件衣」，也可指本句新出现的「另外那件衣」；原文 `aññasmiṃ cīvare sati paccattharaṇam-pi adhiṭṭhātuṃ vaṭṭati` 受持的是手上这件（另有衣在，故此件可持为敷具）。
  - 建议：「如果另外还有衣，也可以把这一件受持为敷具。」
- `100-1138-30-35`｜关键词语意不明确｜片段「他就以衣知足的大圣族而知足」
  - 问题：「以…大圣族而知足」生硬，`vasena` 的「依…而成立／就…这一方面」没落实，读者难判断是「因圣族而满足」还是「在圣族这一项上满足」。
  - 建议：「守护这两支，他就在衣知足这一大圣族上得到满足。」
- `100-1133-34-58`｜文言语体｜片段「都只就所得到的而知足」
  - 问题：「就…而…」属半文半白句式，与全篇现代书面语不一致。
  - 建议：「无论粗的细的，都只以得到的为满足」。

### 🟦 suggestion
- `100-1134-2-11`｜语言风格不统一｜片段「任何一种都能凑合着过的人，就只用所得到的来应付」
  - 问题：`yāpeti / yāpana` 是「维持（生活、日用）」，译「应付」易被读成「敷衍对付」；「凑合着过」偏口语，与书面语体不齐。此译法在 `100-1134-12-23`「用能够支撑得住的那一种来应付」、`100-1134-24-34`「自己用任何一种来应付」同样出现，建议三处一并统一。
  - 建议：统一作「维持（日用）」，如「粗劣的也好、精美的也好，任何一种都能维持日用的人，就只用得到的来维持」。
- `100-1135-23-28`｜语言表达不够流畅｜片段「可以避开不用」
  - 问题：`vajjetuṃ vaṭṭati` 在此是「宜避开」的指示性语气，「可以」读来像可选项。
  - 建议：「宜避开不用」。
- `100-1135-67-71`｜不常用术语编写注释｜片段「足以遮蔽三轮（timaṇḍala）的大小」
  - 问题：「三轮」对一般读者完全不透明，夹注巴利原词也不解决理解问题。
  - 建议：首次出现加简注，说明指脐轮与两膝轮（即须遮覆的三处）。
- `100-1136-79-87`｜该使用而没有使用术语标记｜片段「做出一个连坐在象背上的人也看得清的作净（kappa）记号」
  - 问题：此处 `kappa` 即衣上的净点，汉传通行译名为「点净／净点（kappabindu）」，「作净记号」是自造说法。
  - 建议：改用「点净（kappabindu）」并保留「连坐在象背上的人也看得清」的描述。
- `100-1136-46-59`｜不常用术语编写注释｜片段「迦喀车迦（kāḷakacchaka）之类的染材」
  - 问题：纯音译加巴利夹注，读者无法知道这是何物；同句「苏摩树皮（somavakkala）」已意译出「树皮」，两者处理方式不齐。
  - 建议：加一句简注（某种可作染料的树木），或改为「迦喀车迦树（kāḷakacchaka）」以提示词性。
- `100-1136-2-9`｜不常用术语编写注释｜片段「缝接衣边的时候」
  - 问题：`kusi` 是僧衣特定的边条部件，「衣边」虽不误，但丢掉了术语身份。
  - 建议：首次出现作「缝接衣边（kusi）的时候」。
- `100-1138-20-29`｜语言表达不够流畅｜片段「正在圆满衣知足这一大圣族的比丘」
  - 问题：以进行体「正在圆满…的」作长定语，是明显的翻译腔。
  - 建议：「这样，圆满衣知足这一大圣族的比丘，守护着这两种头陀支。」
- `100-1138-2-7`｜语言风格不统一｜片段「**与衣相关的头陀支**（dhutaṅga）」
  - 问题：巴利被释词是两段独立加粗（`Cīvarappaṭisaṃyuttāni` / `dhutaṅgāni`），译文合并为一段加粗，与逐词对位的加粗体例略有出入（不影响语义）。
  - 建议：如需严格对位，拆为「**与衣相关的**／**头陀支**（dhutaṅga）」。
