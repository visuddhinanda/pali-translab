## 理由

**基准缺失（信心打折的主因）**：本次注入的资源只有巴利原文与 channel 现有译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。本段是复注（ṭīkā），其中 `khippanisāmano` / `sundaravacano` / `guṇaparipuṇṇāyā` / `sukhumālattanena` / `apalibuddhāyā` / `adosāyā` / `agaḷitapadabyañjanāyā` / `anelagalāyā` 等黑体词句全部是**引自义注的被解释词**，按硬约束必须与义注层译文逐字同译——没有义注文本就无法核对这一项，也无法确认释义取向是否与义注相符。因此准确性与一致性的判定仅限于原文内部的自洽性（lemma 与其自带 gloss 是否对得上、同词前后是否统一），信心指数压到 60。下列问题清单中凡涉及"与义注用词是否一致"的，只能标为待核。

**准确性**：绝大多数句子的词覆盖完整，格与句法角色读对了（`vācā assāti` 的"他有这样的言语"式有财释、`tāya poriyā` 的具格回指、`ubhayametaṃ…imasseva atthavacanaṃ` 的"两项都是同一词的释义"都处理正确）。实质错误一处：`agaḷitapadabyañjanāyā` 的 lemma 译法与它紧跟的释义（apatita / avirahita）方向不符，且把前一 lemma `adosāyā` 的释义内容（含混、迟缓）窜入了本 lemma，属错译＋释义归属错误。

**风格**：现代书面汉语，**未发现文言禁例**（无 之/其/乃/便/即/遂 作虚词，无"…者…也""于…之际""答以"类句式），标点全角、引号统一弯引号，`zh` 字段无 ASCII 引号——JSON 安全。扣分主要来自两处汉语不顺（"发声的音声"同义赘叠、形容词后置）与拉丁巴利词直接充当正文句子成分（`style.md` 第三节设定"显示巴利原文：否"，仅允许圆括号夹注）。

**一致性**：`kalyāṇa` 在同一组释义内出现三种译法（优美 / 美好 / 好听）；`khippa-` 复合词的构词顺序在相邻两句中倒置（迅速领悟 / 领悟敏捷）；`attha` 在同句内译作"义理"与"意思"；`gal-` 词根在 93-100 与 106-114 两句译法互相矛盾。均属同一 chunk 内可见的漂移，是 harmonize 该收拢而未收拢的部分。

## 问题清单

### 🟧 error
- `182-1544-93-100`｜错译（词义）＋义理与释义不符｜片段「**字句不含糊迟滞**，是指字句没有脱落、字句没有缺失」
  - 问题：lemma `agaḷitapadabyañjanāyā` 被译为"字句不含糊迟滞"，但其自带释义是 `apatitapadabyañjanāya avirahitapadabyañjanāya`（不脱落、不缺失）。`a-galita` 来自 √gal"脱落、漏失"，与"含糊迟滞"无关；"含混不清、迟缓拖延"是前一 lemma `adosāyā` 所释 `sandiddha-vilambita-` 的内容，被重复挪用到本 lemma，造成两个 lemma 的释义混淆。同一句内 lemma 与 gloss 自相矛盾。
  - 建议：lemma 改为与释义同向的译法，如"**字句不脱漏**"或"**字句不脱落**"，并与 `182-1544-106-114` 中 `agala` 的译法统一。

### 🟨 warning
- `182-1544-40-46`｜不导致误解的汉语语病｜片段「他说话的方式，也就是发声的音声，美好甜美」
  - 问题："发声的音声"同义字重叠（udāhāra-ghosa 一词即"吐字之声"）；谓语"美好甜美"被同位语隔断后置，读来不顺。
  - 建议：改为"他吐字的声音美好甜美，所以叫做……"一类的单句结构。
- `182-1544-47-55`｜整句逻辑表达不规范｜片段「这种语言存在于 pūra（即充满圆满的状态）之中」
  - 问题：这是 porī 的词源推导句，但把拉丁转写 `pūra` 当作汉语句子的处所成分，违反 `style.md`"显示巴利原文：否、巴利原词只作圆括号夹注"的设定，中文读者无从读通"存在于 pūra 之中"。
  - 建议：以汉语为主、巴利为夹注，如"这种语言存在于充满圆满（pūra）的状态之中，所以叫做 porī"。
- `182-1544-87-92`｜代词指代不明确｜片段「是指不被胆汁、痰液等所缠绕」
  - 问题：原文该词与 `vācāya` 同格，被缠绕的是"语言／声音"；译文省略受事主语后，容易读成"（说话的人）不被胆汁痰液缠绕"。
  - 建议：补出受事，如"是指（语言）不被胆汁、痰液等所阻滞"。
- `182-1547-2-4`｜关键词语意不明确｜片段「第二五十经篇结束」
  - 问题："第二五十"易被误读为"第二五十（＝二百五十）"，`paṇṇāsaka` 是"五十经为一组"的单位。同一问题见 `182-1548-2-4` 的「第三五十经篇」。
  - 建议：统一作"第二个五十经篇"或"第二五十经集（dutiyapaṇṇāsaka）"，并与本书其他 paṇṇāsaka 收尾句保持一致。

### 🟦 suggestion
- `182-1544-6-11` / `182-1544-12-19`｜语言风格不统一｜片段「**迅速领悟**，是指智慧敏捷的人」「**领悟敏捷**」
  - 问题：同一组 `khippa-` 复合词，前句译"迅速领悟"（偏动作），后句译"领悟敏捷"（偏性状），构词顺序倒置；且 lemma 译作动作短语、释义却落到"……的人"，词性不对位。
  - 建议：统一为同一构词模式（如"领悟迅速（者）"／"领悟敏捷（者）"），并使 lemma 与释义同为人称性状描述。
- `182-1544-25-31` / `182-1544-32-39` / `182-1544-40-46`｜语言风格不统一｜片段「言语优美」「言语美好」「说话的声音好听」

  - 建议：固定 `kalyāṇa`＝"优美"，差异交给后一成分（优美的言语／优美的吐字声），并登记进 `knowledge/terms.md`。

  - 建议：简化为"又不脱漏（agala）"，并与上一句 lemma 的修正译法统一。
- `182-1544-115-124`｜语言风格不统一｜片段「**能够让人明白义理**，是指……让人明白所说的意思」

  - 建议：lemma 改为"能够让人明白意思"，全句统一用"意思"。
- `182-1544-47-55` / `182-1544-64-74`｜不常用术语编写注释｜片段「porī（圆熟完美的语言）」「porī（城里的女子）」

  - 建议：在第二句点明这是对同一词的第二种词源解释（如"另一种解释是：porī 一词本指城里的女子……"）。
