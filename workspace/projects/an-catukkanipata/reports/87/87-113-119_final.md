## 理由

**资源缺失说明**：本次评估只注入了巴利原文与待评译文，**义注（aṭṭhakathā）与 nissaya 均未提供**，无法做释义核对与词级（格/句法角色）核对。因此下列判断只依据巴利原文本身的词法与《增支部》四集此经的常规理解，信心指数据此压到 72。涉及义注才能定案的两处（`sānuseti` 的句法归属、`sadarehi` 的取义）在问题清单中标为 warning 而非 error，待补义注后复核。

**准确性**：四轭—四离轭的框架译得完整，`samudaya / atthaṅgama / assāda / ādīnava / nissaraṇa` 五支固定译为「生起、灭没、甘美、过患、出离」，`kāmarāga…kāmataṇhā` 八项逐一对应，无漏译。主要扣分在两点：一是 `sānuseti`（sā anuseti，「它随逐、潜伏、持续」）全篇译作「便会生起」，把「随逐/潜伏」译成了「生起」——原文此处强调的是贪等随顺潜伏而行，与 `samudaya`（生起）并非同义；离轭段的 `sā nānuseti` 相应译成「便不生起」，同一偏差。二是 87-117-49-75 的一串形容词有归属与取义问题：`saṃyutto`（被结缚）译作「被…所围绕」弱化了「结缚」之义，`sadarehi`（有怖畏/有苦恼）译作「伴有热恼」与前句 `pariḷāha`（炽恼）的译名撞车。

**风格**：现代书面汉语达标，未见文言虚词与文言句式，`于…之际`「便」「遂」等禁例均未出现（「便会生起」中的「便」为现代副词连用，可接受但建议改「就」）。标点全用全角，无 ASCII 引号，无残留工作标记。夹注巴利原词处理合规：`yoga / bhavayoga / phassāyatana / visaṃyoga / punabbhava` 首次出现附括号。扣分项是 `bhavayoga` 的夹注晚于 `yoga`，位置可接受但「有轭」这一关键歧义词（「有」=存在/生存）只给巴利原词、未作任何提示，一般读者会误读为「拥有」。

**一致性**：四段平行结构句式高度统一，欲/有/见三段用词完全对称，离轭段与轭段呼应良好。扣分在 87-115-52-55 起的 `Iti …` 收束句译法：原文是单一枚举「这样是欲轭、有轭」，译文拆成重复「这样是…，这样是…」，到 87-117-49-75 变成四连重复，汉语显得冗赘；且同一结构 87-114-107-109 只有一项时译「这样是欲轭」，与后面的处理逻辑不同步。

## 问题清单

### 🟧 error
- `87-114-56-99`｜错译（词义）｜片段「欲渴爱便会生起」
  - 问题：`sānuseti` = `sā` + `anuseti`，意为「它便随逐而行／潜伏相续」，不是「生起」。本段前文刚用「生起」译 `samudaya`，此处重复用「生起」既失原义，又使两个不同的巴利词在同一句内同形。
  - 建议：改为「……欲渴爱便随逐不舍」或「便潜伏相随」。同一处理适用于 `87-115-24-44`、`87-116-23-53`、`87-117-25-41`。
- `87-118-43-64`｜错译（词义）｜片段「欲渴爱便不生起」
  - 问题：`sā nānuseti` 是「它便不再随逐」，指已如实了知者贪等不再潜伏相续，而非「不生起」。与上条同源。
  - 建议：改为「便不再随逐」。同一处理适用于 `87-119-24-46`。
- `87-117-49-75`｜错译（词义）｜片段「他被种种恶的、不善的法所围绕」
  - 问题：`saṃyutto` 是「被结缚、被系住」，与本经主题 `yoga`（轭、系缚）/ `visaṃyoga`（离系）同根，译「围绕」切断了与「轭」的词族关联，也弱化了被束缚之义。
  - 建议：改为「他被种种恶的、不善的法所结缚」。

### 🟨 warning
- `87-117-49-75`｜关键词语意不明确｜片段「伴有热恼」
  - 问题：`sadara`（< `dara`，怖畏／苦恼）译作「热恼」，与同篇 `pariḷāha` 的译名「炽恼」几乎同形，读者无法区分两个不同的巴利词；且 `dara` 的核心义偏「怖畏」。此处取义需义注定案，暂列 warning。
  - 建议：改为「带来怖畏」或「伴有忧怖」，与「炽恼」区分开。
- `87-114-56-99`｜整句逻辑表达不规范｜片段「他心中那缘于诸欲的」
  - 问题：原文 `yo kāmesu kāmarāgo…`，`kāmesu` 是处格「于诸欲中」，译作「缘于诸欲」加入了因果关系，并补出了原文没有的「心中」。`style.md` 第六节要求不擅自补足成分。
  - 建议：改为「他对诸欲的欲贪、欲喜……」。四段同构处同改。
- `87-117-10-24`｜关键词语意不明确｜片段「六触处（phassāyatana）」
  - 问题：此处是本经唯一一处轭的所缘不与轭名同词的地方（无明轭的所缘是六触处，非「无明」），译文未作任何提示，读者易疑原文有误。按 `style.md` 第四节，此类二意／易疑处应加注。
  - 建议：加段后小字注，说明无明轭以六触处为观察对象。
- `87-115-52-55`｜不导致误解的汉语语病｜片段「这样是欲轭，这样是有轭」
  - 问题：原文 `Iti kāmayogo bhavayogo` 是一次性枚举，译文重复「这样是」，到 `87-117-49-75` 累积为四连重复，汉语冗赘。
  - 建议：改为「以上是欲轭、有轭」，`87-117-49-75` 相应作「以上是欲轭、有轭、见轭、无明轭」。
- `87-117-76-79`｜关键词语意不明确｜片段「所以说他未脱离诸轭、得不到安稳」
  - 问题：`ayogakkhemī` 是 `yogakkhema`（安稳、瑜伽安泰）的否定，为一个固定复合概念，译文拆成「未脱离诸轭」+「得不到安稳」两项，等于把 `yoga` 再解一次，与原词结构不符；此词取义亦需义注定案。
  - 建议：改为「所以说他得不到安稳」，并以注释交代 `ayogakkhemī` 与 `yoga` 的词源关联。

### 🟦 suggestion
- `87-114-2-14`｜该使用而没有使用术语标记｜片段「有轭（bhavayoga）」
  - 问题：`87-114-18-25` 给 `bhavayoga` 附了巴利原词，但「有」字对一般读者歧义最大（易读作「拥有」），仅附原词不足以消歧。
  - 建议：首次出现时加简注，说明「有」指生存、存在（三有）。
- `87-114-56-99`｜语言表达不够流畅｜片段「欲贪、欲喜、欲染、欲迷、欲渴、欲炽恼、欲耽著、欲渴爱」
  - 问题：八项全用「欲+单字/双字」，其中「欲渴」（`pipāsā`，渴）与「欲渴爱」（`taṇhā`，渴爱）首字重合，读来难辨；「欲迷」亦偏生硬。
  - 建议：`pipāsā` 改「欲干渴」或「欲饥渴」，`mucchā` 改「欲昏迷」，以拉开区分度。
- `87-114-56-99`｜语言风格不统一｜片段「便会生起」
  - 问题：「便」虽可作现代副词，但与 `style.md` 禁例表中「便（=于是）」接近，全篇高频出现易读出半文言味。
  - 建议：统一改为「就」。
