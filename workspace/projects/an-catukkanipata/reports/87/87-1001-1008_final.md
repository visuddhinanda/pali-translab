## 理由

**基准资源缺失（降信心的主因）**：本次只注入了巴利原文与待评译文，**未提供义注（aṭṭhakathā）与 nissaya**。释义标准与词级基准都不在手，因此下列判断全部基于巴利原文本身的词法、句法与四圣谛公式的常规读法；凡涉及「āmo / pakko 用于人时的具体所指」「pāsādika 的释义边界」这类必须由义注定夺的点，只能标注为待核，不计入准确性扣分。信心指数据此压到 62。

**准确性**：核心譬喻框架（四类芒果 → 四类人）与四圣谛公式的肯定/否定对应完全正确，这是本经最容易出错的地方——1003（āmo pakkavaṇṇī）配 `pāsādikaṃ` + `nappajānāti`、1004（pakko āmavaṇṇī）配 `na pāsādikaṃ` + `pajānāti`、1005（āmo āmavaṇṇī）配 `na pāsādikaṃ` + `nappajānāti`、1006（pakko pakkavaṇṇī）配 `pāsādikaṃ` + `pajānāti`，四组内外项的交叉关系逐一核过，无一错配。`abhikkanta / paṭikkanta / ālokita / vilokita / samiñjita / pasārita` 六项威仪与 `saṅghāṭipattacīvaradhāraṇa` 的并列关系、`pāsādikaṃ hoti` 的谓语归属都处理正确；`santo saṃvijjamānā` 作同义复用合并译为「存在着」，属可接受的汉语处理，不计漏译。扣分集中在 1008 这条校勘附注：括号内的异读内容被压缩成概括式转述，变体读法本身（`ukkānatthameva` 对 `uttānatthameva`）丢失，而这正是该方括号存在的全部理由。

**风格符合度**：通篇为现代书面汉语，未见文言虚词（之/其/乃/便/即/遂）或文言句式，无「此中/故为/彼等/是故」一类禁例，`knowledge/style.md` 第一节的禁例表逐项比对后无命中。「屈身、伸身」「持用僧伽梨、钵和衣」属汉译佛典的常规固定说法，不按文言计。标点全为全角，内层引语统一用全角 ‘ ’，跨段连续引语「每段开引号、末段收引号」的处理符合汉语规范；全文未检出 ASCII 引号，JSON 安全无虞。译文中无任何候选、待定、问号之类的残留工作标记。扣分来自 1008 的 〔〕 括号体例与风格配置中列举的括号不一致，以及「令人喜悦」对 `pāsādika` 的覆盖偏窄。

**一致性**：四段平行结构（1003–1006）的用词、句式、标点高度统一，同一巴利句在不同段落的译法完全一致——1004-13-29 与 1005-13-29 原文相同、译文逐字相同，这是跨段统稿到位的证据。`bhikkhave`→「比丘们」、`puggalo`→「一个人/人」、`yathābhūtaṃ pajānāti`→「如实地了知」、`…pe…`→「……中略……」全程无漂移。术语与 `term-glossary.jsonl` 相符（bhikkhu→比丘）。唯一的小瑕疵是 1002-17-59 的指示词在一句内由「这」跳到「那」。

## 问题清单

### 🟧 error
- `87-1008-2-47`｜漏译｜片段「异读本同此说明，并推测经文大概是以」
  - 问题：方括号内的校勘异读被概括掉了。原文 `[‘‘chaṭṭhaṃ ukkānatthamevā’’ti aṭṭhakathāyaṃ dassitaṃ…]` 的要点在于义注该句另有读法 `ukkānatthameva`（对正文的 `uttānatthameva`），译文以「同此说明」一笔带过，变体读法本身没有出现，读者无从知道这条括注在校勘什么。
  - 建议：把异读词形译出或照录，例如改为：义注另一读作「第六经意思浅显（ukkānattha）」，其余与上同；并推测经文……

### 🟨 warning
- `87-1002-85-96`｜关键词语意不明确｜片段「有生的、外表却像熟的人；熟的、外表却像生的人」
  - 问题：芒果用「生/熟」没问题，但直接套到人身上说「生的人」「熟的人」，汉语读者无法得知「生」指内在未成熟（不如实知四谛）、「熟」指内在成熟，而 vaṇṇī 指外在威仪的观感。此处是二义场合且是全经譬喻的枢纽，却无任何注释。
  - 建议：首次出现处加一句译者注，点明人之「生/熟」就内证说、「像生/像熟」就外在威仪说；或译作「内里是生的、外表却像熟的人」。此条的最终措辞须以义注对 `āmo`、`pakkavaṇṇī` 的释义为准，建议补齐义注后再定。
- `87-1008-2-47`｜代词指代不明确｜片段「并推测经文大概是以」
  - 问题：「推测」的主体没有交代。`pāṭho bhaveyya` 是校勘者（非义注、非佛陀）的拟测，译文省掉主语后，读者容易误读为义注或经文自身的说法，而上一句刚提到「义注中说」，指代会顺延过去。
  - 建议：补出主体，如「校勘者推测经文大概是以……开头」。
- `87-1002-17-59`｜不导致误解的汉语语病｜片段「这就是那四种芒果」
  - 问题：`imāni kho…cattāri ambāni` 是近指，一句之内「这就是那」近指与远指混用，读来别扭。
  - 建议：改为「这就是四种芒果」或「比丘们，这就是那四种芒果」拆开为「以上就是四种芒果」。

### 🟦 suggestion
- `87-1003-13-29`｜语言表达不够流畅｜片段「向前看、向四周看」
  - 问题：`ālokita / vilokita` 一对的传统分别是前视与顾视（侧后方向）。「向四周看」把 vilokita 放大成环视，略失对称，且与前项的工整并列感不合。
  - 建议：考虑「向前看、向旁看」或「前瞻、旁顾」式的工整对举；具体取义待 nissaya 的缅文释义核对后定。
- `87-1003-13-29`｜该使用而没有使用术语标记｜片段「持用僧伽梨、钵和衣」
  - 问题：「僧伽梨」是音译术语且在本章首次出现，按 `style.md` 的混合策略应夹注巴利原词。
  - 建议：首次出现处写「僧伽梨（saṅghāṭi）」，其后沿用汉译。
- `87-1003-13-29`｜语言风格不统一｜片段「都显得令人喜悦」
  - 问题：`pāsādika` 侧重「令人起净信、观之端正可喜」，「令人喜悦」偏向情绪愉快，语义覆盖偏窄；同一词在 1004/1005 以「不令人喜悦」出现，若改动需四处同步。
  - 建议：考虑「都令人观之生信」「都端正可喜」一类译法。此词的释义边界须以义注为准，建议补齐义注后统一定稿。
- `87-1003-70-77`｜代词指代可能不够明确｜片段「我说这个人就和它相似」
  - 问题：「它」跨句回指上一句的芒果，四段重复出现；在偈颂式平行结构里读者容易一时失焦。
  - 建议：改为「我说这个人就像这样的芒果」，四段同步。
- `87-1008-2-47`｜语言风格不统一｜片段「〔异读本同此说明」

  - 建议：统一为（）加层次词，或在项目 `style.md` 里登记〔〕的用途后再沿用。
