## 理由

**数据缺口（降信心的主因）**：本次只注入了巴利原文与 channel 现有译文，**没有 nissaya，也没有被引本文（mūla）层**。本段是义注，通篇靠黑体引述本文词目（`rogātaṅka` / `phuṭṭha` / `urattāḷiṃ kandati` / `akatakalyāṇa` / `kusala` / `bhīruttāṇa` / `katapāpa` / `ludda` / `kibbisa` / `kaṅkhī` / `vicikicchī`）展开，**「被解释词与父层逐字同译」这条硬约束无法核验**；格与句法角色也只能依巴利形态自判，无 nissaya 旁证。下列评分仅覆盖「义注内部自洽 + 巴利形态 + 汉语表达」三项，一致性分数里的不确定部分已折入信心指数。

**准确性**：释义骨架全部站得住。`kalyāṇaṃ vuccati puññakammaṃ` 的有财释分析（`taṃ akataṃ etenā`→「他没有做过这种善事」）处理正确；`kusalaṃ`←`kosallasambhūta`、`pāpaṃ`←`lāmakaṃ akusalakammaṃ`、`luddaṃ`←`kakkhaḷakamma` 等词源式释义都如实译出。**八处疑的列举完整且与 `aṭṭhasu ṭhānesu` 条数吻合**（佛/法/僧功德三项＋学＋过去＋未来＋过去未来＋缘起＝8），没有并列项合并或丢失，这是本段最容易塌的地方，译文守住了。扣分集中在两处词目译法：`bhīruttāṇa` 把受保护者 `bhīru`（怯弱者）改写成时间状语＋反身的「在恐惧时…自己」，与同句自带的释义 `bhītassa parittāyakattā`（已正确译为「能保护害怕的人」）自相矛盾；`rogātaṅka` 译「疾病」与 `roga` 译「病」几乎同形，使「病本身就称为疾病」这一句在汉语里读成同义反复，义注要讲的「`ātaṅka` 不另加义、仍即是病」反而看不出来。

**风格**：现代书面汉语，**未发现文言虚词与文言句式**（无之/其/乃/便/即/遂，无「…者…也」「于…之际」「答以」类写法），「所谓…，就是…」「叫做」「其余各词也是同样的道理」均为合格的现代释义口吻；标点全为全角，译文内无 ASCII 引号，无残留工作标记（候选/待定/问号）。扣分项是「一切处的意思」这类佛教汉语硬译残留，以及个别长句（第 1549-2-11 句）嵌套偏重。

**一致性**：译语体系整体稳定且有意区分（`kalyāṇa`＝善事 / `kusala`＝善行；`kaṅkhā`＝疑惑 / `vicikicchā`＝犹豫，后者属合理分化，非错）。主要问题是**巴利夹注的取舍无规律**：`roga` / `rogātaṅka` / `kosalla` / `bhīru` / `bhīruttāṇa` / `vicikicchā` 附了原词，而同等陌生的 `phuṭṭha` / `ludda` / `kibbisa` / `kaṅkhī` 一律不附，读者无从判断标注依据。另外 `bhīruttāṇa` 用整句意译充当词目，几乎不可能与本文层「akatabhīruttāṇo」的译法逐字对齐，属一致性风险点。

**与标准的分歧说明**：`pubbanta` / `aparanta` 译「过去世 / 未来世」偏离传统「前际 / 后际」，但在混合受众定位下为可接受的现代化处理，**不扣分**，仅记录。

## 问题清单

### 🟧 error

- `100-1549-41-51`｜错译（词义、修饰关系）｜片段「在恐惧时能保护自己的事」
  - 问题：`bhīruttāṇa` 是「`bhīru`（怯弱者）之 `tāṇa`（庇护）」，被保护者就是那个怯弱的人；译文把 `bhīru` 处理成时间状语「在恐惧时」并补出反身的「自己」，修饰关系错位。同句自带的释义 `bhītassa parittāyakattā` 已正确译作「能保护害怕的人」，词目与释义在一句之内互相打脸；且这种整句意译无法与本文层「akatabhīruttāṇo」的词目译法逐字对齐。
  - 建议：改为名词性短语，如「**怯弱者的庇护**（bhīruttāṇa）」或「**怖畏者的救护**」，并与本文层该词译法保持同形。

### 🟨 warning

- `100-1549-2-11`｜关键词语意不明确｜片段「病本身就称为」
  - 问题：`roga` 译「病」、`rogātaṅka` 译「疾病」，两词汉语几乎同形，整句落成「病本身就称为疾病」，读起来是同义反复；义注此处要说明的是 `ātaṅka` 并不另添新义、`roga` 即 `rogātaṅka`，这层意思在译文里被抹平了。
  - 建议：令两词汉语有形可辨，如 `rogātaṅka` 取「病患／病苦」：「……病本身就称为**病患**（rogātaṅka）」，使「即是病」的判断读得出来。
- `100-1549-2-11`｜整句逻辑表达不规范｜片段「就病（roga）是使人难以存活的原因这一点而言」
  - 问题：两处可改。一是 `kicchājīvita` 指「生活艰难、日子难过」，译「难以存活」偏向性命不保，语义过强；二是「就……这一点而言」套在长定语上，使全句成为三层嵌套，读者须回读才能接上后半句。
  - 建议：拆为因果直叙，如「第四经中，因为病是使人生活艰难的原因，所以病本身就称为**病患**（rogātaṅka）」。

### 🟦 suggestion

- `100-1549-68-89`｜该使用而没有使用术语标记｜片段「对学处」
  - 问题：此处 `sikkhā` 指三学／增上学这一整体修学，「学处」在汉译传统中对应 `sikkhāpada`（具体戒条），所指偏窄。
  - 建议：改「对学（sikkhā）」或「对戒学」，并按首次出现规则夹注原词。
- `100-1549-63-67`｜不常用术语编写注释或者百科｜片段「污秽的事」
  - 问题：`kibbisa` 本义为罪过、罪恶，义注用 `samalaṃ aparisuddhakammaṃ` 从「染污不净」角度作释；译文直接以释义「污秽的事」替换词目，词目本身的「罪」义丢失，且与后半句「带有污垢、不清净的行为」构成近义重复。
  - 建议：词目取「**罪过**（kibbisa）」，释义保留「就是带有污垢、不清净的行为」，词目与释义各司其职。
- `100-1549-12-17` / `100-1549-59-62` / `100-1549-63-67` / `100-1549-68-89`｜语言风格不统一｜片段「所谓**被侵袭**」
  - 问题：巴利夹注取舍无规律——`rogātaṅka` / `kosalla` / `bhīru` / `bhīruttāṇa` / `vicikicchā` 附原词，而同等陌生的 `phuṭṭha`、`ludda`、`kibbisa`、`kaṅkhī` 一概不附。
  - 建议：统一为「凡被解释的黑体词目首次出现即夹注原词」，或「仅法相术语夹注」，择一贯彻全段。
- `100-1549-105-110`｜语言表达不够流畅｜片段「一切处的意思都应当按照这个方式来理解」
  - 问题：「一切处」是硬译残留，现代读者易误读为「每一个地方」；句子也是先状语后主语的生硬语序。
  - 建议：「其余各处的意思都应依此类推。」
- `100-1549-90-104`｜语言表达不够流畅｜片段「对作为正法的教法没有得到确定的结论」
  - 问题：「确定的结论」在一句内连用两次，略显拖沓；「作为正法的教法」同位结构也偏重。
  - 建议：「……对正法教法下不了定论，也无法通过学习和请教获得定论。」
