# Review — 100:1558-1562（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层（book 87, 1475-1486）本文译文 ✅／nissaya ❌（未提供，词级格位核对降级为凭原文形态判断）／本层即义注层，无更高释义标准可依

## 被解释词与父层对照（首要项）

逐条核对全部 24 处黑体，与父层定稿译文**一致**，无必改项：

- 优波迦 / 曼迪卡之子 / 走到 / 指责别人 / 生不起善法，就应受责备 / 有过失 / 刚把头探出水面的人 / 这也是不善 / 盐村的小子 / 居然 / 想到可以去冒犯 / 你走开 / 用身 / 应当亲自证知的 / 用念 / 用眼 / 用慧 — 均与父层逐字相同。
- 两处**可接受的轻微出入**（不必改，记录备查）：
  - `100-1559-73-92` 黑体「他全然生不起善法」：父层原句把「他」与「全然生不起善法」分置于两个小句（「他在指责别人的时候，全然生不起善法」），本层合并为一句，用词未变。
  - `100-1560-91-99` 黑体「这个人竟然这样毁人功德」：父层对应处作「这个盐村的小子竟然这样毁人功德」，本层以「这个人」补出 ayaṃ（父层的名词在黑体范围之外），核心词「竟然这样毁人功德」逐字相同。

## 跨段一致性

- **「说法」一词三义混用**（必改）：父层已把 `dhammadesanā` 固定译作「说法」（§1478「无量的说法」），但本 chunk 又用「说法」译了另外两个词——§1559 `vacanaṃ`（「把自己的说法讲得站得住」，两处）、§1560 `vādaṃ`（「抓住他自己的说法」）。读者无法分辨哪一个是「如来的说法（desanā）」。父层 §1477 已给出 `vāda` 的译法为「言论」（「言论的大套索」）。→ 建议：`dhammadesanā` 保留「说法」；`vādaṃ` 改「言论」；`vacanaṃ` 改「话／自己的主张」。
- **「坏话」撞车**（必改）：§1559 `avaṇṇaṃ` 译「坏话」（「会说我的好话，还是会说我的坏话」，正确），但同段 `paragarahaṃ katheti` 也译成「说别人的坏话」。后者是「责备、非难他人」，不是背后议论。→ 建议：`paragarahaṃ katheti` 改「就是责备别人、非难别人」，「坏话」只留给 `avaṇṇa`。
- **ghaṭṭ- 两个译法**（必改）：§1560 `ghaṭṭetabbaṃ` 译「触犯」（用来解释黑体「冒犯」= āsādetabbaṃ），而 §1559 `satthāraṃ ghaṭṭetukāmo` 又译「想要冒犯导师」。「冒犯」已被父层占用给 āsāde-，ghaṭṭ- 必须另有固定译法。→ 建议：§1559 改「想要触犯导师」，与 §1560 的「触犯」统一。
- **慧类复合词构词不齐**（建议）：§1562 作「禅定的慧／观的慧／道的慧／果的慧／省察的慧」，五项中只有第一项用双音节「禅定」。→ 建议统一为「禅的慧／观的慧／道的慧／果的慧／省察的慧」，或整组改用「禅慧／观慧／道慧／果慧／省察慧」。
- **「诸漏灭尽」与父层不齐**（建议）：§1562 末作「诸漏灭尽」，父层 §1486 作「诸漏的灭尽」。此处非黑体，无硬约束，但同一词组同章两形，建议从父层。

## 跨层问题（需上报 harmonize，本层不动）

- 父层 §1483 的译文把本层义注内容写进了本文夹注：「用身（这里指名身 nāmakāya，即心与心所，不是肉身）」「用念（这里指宿住随念，即忆念前世的住处）」「用眼（这里指天眼 dibbacakkhu，不是肉眼）」。这三条正是本层 `100-1562` 的 `kāyenāti nāmakāyena` / `satiyāti pubbenivāsānussatiyā` / `cakkhunāti dibbacakkhunā`。**义注是解释，不是本文**——父层译文不应预先吐露义注的释义，否则义注层整段变成冗余，且读者会把义注的判断当成经文本身的判断。建议在父层删去这三处夹注（「用身」「用念」「用眼」保留原样），释义交还本层。

## §1559 句 100-1559-46-66

- **问题**：风格（半文半白） — 引文内「无可救治」（atekiccho）为文言式否定。
- **建议**：改「无法救治」。整句：「提婆达多将生于地狱，要在那里住满一劫，无法救治」。

## §1559 句 100-1559-67-72

- **问题**：释义偏移 + 跨段撞车 — `paragarahaṃ katheti` 译「说别人的坏话」。`garahā` 是公开的责备、非难，父层把 `parūpārambha` 定译为「指责别人」，义注在此是用 `paragarahā` 同义替换，译文应落在「责备」上；且「坏话」已用于 `avaṇṇa`。
- **建议**：「**指责别人**：就是责备别人、非难别人。」

## §1560 句 100-1560-2-12

- **问题**：代词归属误读 — 「抓住他自己的说法，把它套回到他自己的脖子上」。原文 `tassa vādaṃ gahetvā tasseva gīvāya paṭimuñcanto`：强调词 `eva` 只在后半（tass**eva** gīvāya，「套回他本人的脖子上」），前半 `tassa vādaṃ` 无强调。现译在前半也加「自己」，主语是世尊，读者可能误解为「世尊自己的说法」。
- **建议**：「于是世尊抓住优波迦的言论，把它套回到他本人的脖子上，就说了**指责别人**等等这段话。」（同时按跨段一致性把 `vādaṃ` 改「言论」）

## §1560 句 100-1560-20-31

- **问题**：可读性 — 「在**在这一施设当中，如来有无量的语句**等句子里」，外层「在」与黑体开头的「在」叠在一起，句子起头读不通。
- **建议**：去掉外层的「在」：「**在这一施设当中，如来有无量的语句**等句子里，意思是：在那个“这是不善”的施设当中，语句也好、字句也好、说法也好，全都是无量的。」
- **补记**（非问题）：原文此处用 `akkharāni` 替换父层的 `byañjanā`，译文随父层作「字句」，对应关系成立，保留。

## §1560 句 100-1560-64-84

- **问题**：取义偏移 — `apariyādinna`（未被取尽、取之不竭）译作「还没有讲尽」。现译读成「目前尚未讲完」，是时间上的未完成；原意是无穷无尽、怎么取都取不完，正好支撑上文「即使换一种方式讲，说法同样无量」。
- **建议**：「如来的说法取之不尽，法的语句字句也取之不尽。」（或「无穷无尽」）

## §1560 句 100-1560-85-90

- **问题**：增译 — `sabbavāresu` 是「所有各段／一切轮次」，译文作「其余各段」，凭空加了排除义。
- **建议**：「所有各段的意思都应当按这个方式来理解。」

## §1560 句 100-1560-104-111

- **问题**：释义不成话 — 「**居然**：就是“竟然这样的人”。」被释词「居然」是副词，拿「…的人」去解释它，中文读不通。原文 `yatra hi nāmāti yo hi nāma` 是用关系代词 `yo` 替换 `yatra`，说明该词在此当关系代词用、指人。
- **建议**：点出替换关系，例如「**居然**：这里的 yatra hi nāma 相当于 yo hi nāma，即“哪个人竟然……”。」

## §1560 句 100-1560-127-133

- **问题**：主语歧义 — 「而且他这样说了以后，还叫人抓住优波迦的脖子」。上一句整句是国王的话，此处「他」指国王，但紧接在国王的直接引语之后，读者容易把「他」读成被骂的优波迦（下半句又出现「优波迦」，更易误接）。
- **建议**：「而且国王这样说了以后，还叫人抓住优波迦的脖子，把他拖了出去。」

## §1562 句 100-1562-12-16

- **问题**：措辞冗余 + 释义略偏 — 「**应当亲自证知的**：就是应当亲自现前见到的。」一句内两个「亲自」；`paccakkhaṃ kātabbā` 是「应当使之成为现前（当下直接面对）」，「见到」把它窄化成视觉义，与紧随其后的「用眼（天眼）」一项易生混淆。
- **建议**：「**应当亲自证知的**：就是应当使之现前、直接面对的。」

## §1562 句 100-1562-44-53

- **问题**：风格（半文半白） — 「则是以省察的方式」中的「则」。按 `style.md`，文言虚词应换现代对应词或省略。
- **建议**：「至于被称为诸漏的灭尽的阿罗汉果，就是以省察的方式、用省察的慧来证知的。」（「诸漏的灭尽」从父层）

## 存疑（不作必改，供定稿参考）

- §1560 `imināpi kāraṇena imināpi kāraṇena` 译「由于这个理由也是不善，由于那个理由也是不善」。原文两处同形重复，表示理由多端；现译用「这个／那个」区分，读来自然，但严格说并非原文的对举。若要贴原文可作「由于这样的理由也是不善，由于那样的理由也是不善」。保留现译亦可。
- 全 chunk `satthā` 一律作「导师」，前后一致；`term-glossary.jsonl` 未登记此词，建议定案后补入。
- 「脖子」（gīvā，两处）口语色彩偏重，但符合现代汉语要求、两处一致，保留。
