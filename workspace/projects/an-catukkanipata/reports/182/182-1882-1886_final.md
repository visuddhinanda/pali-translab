## 理由

**基准可用性（影响信心）**：本次只注入了巴利原文与 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此以下三项无法核验，分数按"无反证"从宽给出，信心指数相应压低：

1. **被解释词与父层逐字同译**这一硬约束无法验证。本段黑体引词密集（`sesapadesupī` / `dutiyādayopi hī` / `cattāro sassatavādā` / `cattāro ekaccasassatavādā` / `cattāro antānantikā` / `rittā` / `tucchā`），复注黑体引自义注，其汉译必须与义注层译文逐字一致。译文内部自身是自洽的（如"四种常住论/四种一分常住论/四种有边无边论者"成系列），但与义注层的对齐未经核对。
2. 词级格位与句法角色（主/宾/属、隐含成分）无 nissaya 可比，只能按原文形态自行判读。
3. 引文出处与所引经文的既有译法（DN 2.214、MN 3.126、Udāna 1 等）未与对应 channel 比对。

**准确性**：句法判读整体可靠。难点处理得当——`antānanta` 的三重解释（sāmaññaniddesa / ekasesa / sahacarita / sannissaya）层次清楚，`kuntā caranti`、`mañcā ghosanti` 两个修辞例补出了"持矛的人在走""床上的人在叫"的意思，这是正确且必要的；四种有边无边论对应的 kasiṇa 扩大方式（未扩大／已扩大／只横向扩大）与原文 `tiriyaṃ vaḍḍhetvā uddhamadho avaḍḍhita` 吻合；问答结构（`Kasmā pana…ti? Veneyyajjhāsayato.`、`kathaṃ…ti? …vasena pavattavādattā eva.`）都如实译出，没有压平成陈述。
扣分主要来自一处因由从句的**反向误译**：`samitapāpasamaṇaggahaṇato` 被译成"这一义是另处所取的"，原文并无否定词或"另处"义，属增译并致理解相反（见问题清单 🟧）。另有若干处把原文没有的数量/指代补进正文（"这四种果"）。

**风格符合度**：扣分集中在**文言残留**。`knowledge/style.md` 第一节为硬约束，而译文里仍有"之身死没""他于正理之法上行于一分""唯远离诸欲"这类半文半白表达。其中引用经文的两处尤需注意：引文也是给现代读者看的译文，不能靠"这是经句"豁免文言。此外有两处解释性插注（"即下文得宿住随念智者""即省略同类词只留一个"）直接写进了正文圆括号，按 style §四 应作段后小字注释，圆括号只留巴利原词。
标点合规：全程中文全角，引号统一用 “”，未见直角引号，`zh` 字段内未发现 ASCII 引号，无 JSON 风险。译文内无 TODO/候选/问号等工作标记。

**一致性**：术语前后统一——`takkī`→"靠推理思辨的人"（三处一致）、`phalaṭṭhaka`→"住于果位的沙门"、`maggaṭṭha`→"住于道的人"、`kasiṇa`→"遍"、`anta/ananta`→"边／无边"；1884-48-79 与 1884-80-95 两处引同一句"我和世界都是常住的"，用字完全相同，跨句未漂移。唯 `pavādā` 译"诸异说"而紧邻句的 `samaya` 译"宗义"，两个相关概念的汉译未呼应，属轻微不统一。

## 问题清单

### 🟧 error
- `182-1883-103-109`｜错译（增译致义反）｜片段「这一义是另处所取的」
  - 问题：原文 `samitapāpasamaṇaggahaṇato` 是单纯的因由夺格"因为（此处）所取的是‘恶已息灭’的沙门"，并无否定词，也没有"另处 / aññattha"一类成分。译文把它反转为"这一义是另处所取的"，使因果关系颠倒：原文是**用 samitapāpa 这一取义来论证此处只指住果沙门**，译文却变成了把该取义排除出去。
  - 建议：改为"因为这里把沙门取作‘恶已息灭’之义"一类表述，保持它作为"只取住果沙门"的理由。另：获得义注层后应核对此句所据的义注原文，确认取义方向。

### 🟨 warning
- `182-1885-12-29`｜文言语体｜片段「之身死没而来生此处」
  - 问题：文言虚词"之"＋单音节文言结构，违反 style 第一节硬约束。
  - 建议：改为"从梵众天、戏忘天、意愤天的身中死去、来生到这里的那些人"。
- `182-1883-122-157`｜文言语体｜片段「他于正理之法上行于一分」
  - 问题：引文译得文言（"于…之法上""行于一分"），现代读者会读成古文。引文同样须为现代书面汉语。
  - 建议：改为"他只在正理之法上走了一段／他只行到正理之法的一部分"，并与 DN 2.214 对应 channel 的既有译法核对后统一。
- `182-1883-21-84`｜文言语体｜片段「唯远离诸欲」
  - 问题：半文半白。该句的限定义（`eva`）正是本段论点所在，用现代汉语译出更清楚。
  - 建议：改为"正是远离了诸欲"或"只有远离诸欲"，与下文"必须取带有限定的意思"相呼应。
- `182-1883-6-20`｜整句逻辑表达不规范（同语反复）｜片段「是指在“这里有第二沙门”等其余各句中也是这样」
  - 问题：黑体被解释词已是"在其余各句中"，释文又用"其余各句中"原词回环解释，等于没释义，读者看不出复注在说什么（原文 `sesapadesupi` 的释义重点在 `pi` 所指的范围）。
  - 建议：释文改从所指处落笔，如"指的是‘这里有第二沙门’等后面几句，那几句里也一样（要补上这个限定）"。
- `182-1884-17-29`｜注释位置不当（解释性插注进正文）｜片段「（lābhī，即下文得宿住随念智者）」
  - 问题：圆括号按 style §三只用于首次出现时夹注巴利原词；"即下文得宿住随念智者"是译者补充的解释，应作段后小字注释。
  - 建议：正文只留"（lābhī）"，解释移为脚注。
- `182-1885-2-11`｜不导致误解的汉语语病｜片段「主张一部分是常住的，这样提出来的主张就是一分常住论」
  - 问题：一句内"主张"出现三次（含动词、名词混用），读来拗口。
  - 建议："在众生和诸行当中，认为其中一部分是常住的——这样成立的论说就是一分常住论。"

### 🟦 suggestion
- `182-1883-85-93`｜语言表达不够流畅｜片段「因为第二沙门等也…」
  - 问题：引文用省略号截断，后面又跟"等语句"，`tiādi` 被重复标示了两次；"因为…也"悬在半空。
  - 建议：取"因此义注说**“第二沙门等也是如此”**等语句"，或把引文补到可独立成句处。
- `182-1886-2-13`｜复杂的嵌套句整句语言逻辑理解困难｜片段「amati 就是“去到”：终结（vosāna）在此处到达」
  - 问题：词源解析里直接出现拉丁转写的 `amati` 而未说明这是在拆解 `anta` 的词根，一般读者无法跟上。
  - 建议：补一句点明性质，如"（这里是按词源解释 anta：amati 意为‘去到’……）"，或把词源整体移入脚注。
- `182-1883-94-102`｜代词指代可能不够明确｜片段「所以这里是依这四种果而宣说了四种沙门」
  - 问题：原文 `tesaṃ vasena` 只回指"沙门果"，译文补出"四种"，数量是推断而来，且与后半"四种沙门"叠用显得循环。
  - 建议：改为"所以这里是依这些果而宣说了四种沙门"。
- `182-1883-103-109`｜语言表达不够流畅｜片段「只是住于四种果位的沙门」
  - 问题：`cattāro` 修饰 `samaṇā`，宜作"四种住果沙门"；现译把数词挪到"果位"上，虽不致误解但偏离结构。
  - 建议："所指的只是那四种住于果位的沙门"。
- `182-1886-18-48`｜不常用术语注释处理｜片段「（ekasesa，即省略同类词只留一个）」
  - 问题：同上，解释性文字进了正文括号；且"单遗余"这一译名较生僻，值得正式立注。
  - 建议：正文保留"单遗余（ekasesa）"，释义移作脚注并举 `nāmarūpa` 之例说明。
- `182-1886-160-167`｜语言表达不够流畅｜片段「也仍然以边和无边为对象，因为它正是针对这两者而提出的」
  - 问题：一句内两个"因为"叠用（句首"因为那种…"与句末"因为它正是…"），因果层级被压扁。
  - 建议：末句改为"——它本来就是针对这两者而提出的"。
- `182-1883-177-180`｜语言表达不够流畅｜片段「空无内容的」
  - 问题：`vivittā` 释 `rittā`，重在"空无所有"，"空无内容"略显抽象，且与下句"没有实质""内核"的用词不成系列。
  - 建议：改为"空无所有的"，与下句"没有实质"构成递进。
