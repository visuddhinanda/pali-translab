# Review — 182:1625-1627（channel: 73c03e1a）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入；本层为复注 ṭīkā，父层义注与本文均未提供）

⚠ **资源缺失说明**：本次审读只有复注巴利原文与现有译文。**父层（义注 aṭṭhakathā）文本未注入，故方法文档要求的「第一项查被解释词是否与父层逐字相同」无法执行**——复注黑体引自义注，没有义注译文就无从比对。以下关于黑体词的意见，仅凭复注自身的释义上下文推断，确认仍需调取父层译文。nissaya 缺失，词级格位判断依巴利形态自行判读。

## 跨段一致性

- `ugghaṭitaññū`：§1625 篇题译「《略闻即悟经》」，§1626 释文译「略闻即悟者」，§1627 结语又回「《略闻即悟经》」 → 人／经名区分得当，**一致，无问题**。
- `dhammābhisamayo`：§1626 三处分别译「法的通达就发生了」「法的通达是逐步发生的」「法的通达不会发生」 → 核心词「法的通达」统一，一致。
- `arahatta`：§1626 四处分别作「取得阿罗汉果」「证得阿罗汉果」「证得阿罗汉果」（`arahattappatti`→「证得阿罗汉果」）→ 「取得」与「证得」混用。建议统一为「证得」，依据：`gaṇhituṃ` 与 `pāpuṇituṃ`／`patti` 在汉译传统中同归「证得」，且本 chunk 内三比一。
- `mātikā`：§1626 两处皆译「纲目」，一致。
- `saṃkhittena` / `vitthārena`：「简略地」／「详细」成对出现两次，用词一致。
- 语体：全 chunk 为现代书面汉语，未见文言虚词（之／其／乃／便／即／谓／於／遂）与文言句式，**语体统一，合格**。

## §1626 句 182-1626-6-18

- **问题**：术语漏译／结构错位 — 复注在解释 `ugghaṭanaṃ nāma ñāṇugghaṭanaṃ`，是**定义式**（`nāma` 标示「所谓…就是…」）。译文「这里所说的开示，指的是智的开示」把 `ugghaṭana` 译作「开示」，与后文 `desanā`（教法的开示，见 33-67 句）撞词。`ugghaṭana` 本义是「揭开、打开（盖子）」，此处指智的「启开」，不是对听者说法的「开示」。两词同译会让读者误以为 `ugghaṭitaññū` 的得名在于「别人为他开示」，而复注恰恰说得名在于「他自己的智一启开就懂」。
- **建议**：`ugghaṭana` 改译「启开」（或「揭开」），`ñāṇugghaṭanaṃ`→「智的启开」，`ugghaṭitamatteyeva`→「只要智一启开」。并与篇题「略闻即悟」的立名逻辑对上。
- **问题**：`ettha` 的位置 — 译文「在第三经中，**略闻即悟者**这里所说的开示」，「在第三经中」与「这里」语义重叠且断句生硬；`Tatiye` 是处格，指「在第三经里」，`ettha` 回指黑体词。
- **建议**：改为「第三经中，**略闻即悟者**——这里的『启开』指的是智的启开，意思是……」。

## §1626 句 182-1626-19-24

- **问题**：误译（词义） — `udāhaṭavelāyā`／`udāhāre`／`udāhaṭamatteyeva` 三处词根 `udāharati` 译作「举说」。`udāhāra` 在此指**举出教法纲目来说**，译文把 `udāhāre`（处格）译成「在举说当中」尚可，但「只要一举说出来」与前句的「只要智一开示」失去呼应。更要紧的是「举说」是生造词，现代读者不解其义。
- **建议**：统一译「说出」或「举示」：**在说出的同时**，意思是在举示教法时，刚一说出来（他就通达了）。并补出省略的结果（见下句衔接），或以破折号留给下句。

## §1626 句 182-1626-25-32

- **问题**：语法误读（具格 `saddhiṃ` 的管辖对象） — 原文 `catusaccadhammassa ñāṇena saddhiṃ abhisamayo`：`catusaccadhammassa` 属格，受 `abhisamayo` 管辖；`ñāṇena saddhiṃ` = 「与智一同」，修饰 `abhisamayo`，意即「对四谛法的通达是与智同时发生的（通达即智的生起）」。译文「对四谛法与智一同通达」把「智」读成了与「四谛法」并列的**通达对象**——成了「通达四谛法，也通达智」，是实质误译。
- **建议**：改为「**法的通达就发生了**，意思是对四谛法的通达与智同时发生」或「……即随智一同生起的、对四谛法的通达」。
- **备注**：此句结论依赖父层义注对 `dhammābhisamaya` 的释义，建议 revise 前调父层核对。

## §1626 句 182-1626-33-67

- **问题**：引文来源标注 — `( vibha .355)` 译作「（《分别论》三五五）」。`Vibha.` 在此语境通指 *Vibhaṅga*（《分别论》，Abhidhamma 第二部）。但「四念处」纲目的出处，也可能指律藏 *Vibhaṅga*。现有译法未必错，但**书名简称歧义未排除**，且全 chunk 仅此一处外部引文。
- **建议**：revise 时核实该编号实指；确认后在 `knowledge/terms.md` 登记 `Vibha.` 的固定译名。页码／段号建议保留阿拉伯数字「355」，与「三五五」混排不如统一（§1626 开头 `133-4.` 已译为「一三三至一三四」，经号用汉字、引文段号用阿拉伯数字可形成区分，但需定规则）。
- **问题**：语序造成因果倒置 — 译文「这个人就能顺着教法的开示把智运用过去，从而取得阿罗汉果」中「这个人」提前，而原文 `puggalo` 的修饰语链（`…samattho puggalo`）整体是被定义项，主句是「这样的人被称为『略闻即悟者』」。现译前半已出现「这个人就能……」，末尾又出现「这样的人被称为」，主语重复宣告两次。
- **建议**：改为「……当以『四念处』等方式简略立出纲目时，能顺着教法的开示运转其智而证得阿罗汉果的人，就被称为『略闻即悟者』」。同一改法适用于 74-96 句（结构完全平行，应与此句同构处理）。
- **问题**：`ṭhapiyamānāya` 为现在被动分词独立处格（与 74-96 句 `bhājiyamāne` 对应），表「当……正被立出时」。现译「当……立出纲目时」漏掉被动，读者不知施事是说法者。
- **建议**：补出施事或保留被动：「当（说法者）刚把纲目简略立出时」。

## §1626 句 182-1626-68-73

- **问题**：`vipañcitaṃ vitthāritameva` — 复注以 `vitthārita` 训 `vipañcita`，是**同义训释**（「所谓 vipañcita，就是 vitthārita」）。译文「在义理被详加分别、被详细展开之后」把两个同义词并列铺开成两个动作，读来像是两道工序。
- **建议**：改为「因为他是在义理被详细展开之后才明白的」，或保留训释关系：「`vipañcita` 就是详细展开；他是在义理被详细展开之后才明白的，所以叫做**广说乃悟者**」。
- **问题**：`-aññū` 一组四名的译名体系 — 本 chunk 四个人格类型译为「略闻即悟者」「广说乃悟者」「应受引导者」「以文句为极限者」。前两个采意译四字格，后两个字数与构词风格不齐（「应受引导者」为被动短语，「以文句为极限者」为介词短语，长达七字）。
- **建议**：整组统一为同一构词模式，例如「略闻即悟者／广说乃悟者／待引方悟者／止于文句者」。此为**体系性决定，建议提交用户定案后写入 `knowledge/terms.md`**，不由 revise 自行改定。

## §1626 句 182-1626-97-100

- **问题**：`uddesādīhi` 译「通过提示等等」。`uddesa` 在三藏语境中是「略说、标目」（与 `niddesa` 详说相对），正与上文 `mātikā`（纲目）、`saṃkhittena`（简略）同一语义场。译作「提示」切断了这条线索，也与紧接的 `anupubbena`（逐步）失去逻辑连接。
- **建议**：`uddesādīhi`→「通过略说等等」或「通过标目等方式」。

## §1626 句 182-1626-107-111

- **问题**：`Byañjanapadameva paramaṃ assā` 直译为「因为他只以文句为极限」。`byañjanapada` = 字句、文句（相对于义理 `attha`），`paramaṃ assa` = 「（文句）是他的顶点」，即他最多只能到文句、到不了义理。译文「以文句为极限」字面无误，但「极限」一词现代读者易读作「能力上限」之褒义中性，而原文是贬义判定（止步于文字，不入义理）。
- **建议**：改为「因为他顶多只停在字句上，所以叫做**止于文句者**」，或保留原译名而把释文说清：「因为对他来说文句就是终点（到不了义理）」。

## §1626 句 182-1626-112-132

- **问题**：`tena attabhāvena` 译「他以那个生命体」。`attabhāva` 指「此身、这一生的自体」，与黑体 `tāya jātiyā`（在那一生中）同指。「生命体」是现代生物学味的生造词，且「以……生命体」的工具格读法让句子别扭。
- **建议**：改为「意思是说，他在那个身体里（这一生中）无法生起禅那、毗婆舍那、道或果」。
- **问题**：四重 `vā` 的译法冗赘 — 「无法生起禅那、也无法生起毗婆舍那、无法生起道、也无法生起果」四次重复谓语，且「也」字出现位置不规律（一、三项无，二、四项有）。
- **建议**：合并为「无法生起禅那、毗婆舍那、道或果中的任何一种」，或四项全部并列、谓语只出现一次。

## §1626 句 182-1626-133-135

- **问题**：`Catutthaṃ uttānameva` — `uttāna` 意为「浅显、明白无须解释」，`eva` 是限定语气（「只是浅显而已」，故复注不再注）。译文「第四经的意思很明白」可，但未传达「所以此处不作注解」的功能性含意，读者会疑惑注释为何到此为止。
- **建议**：改为「第四经的意思浅显易明（无须解释）」，或「第四经文义浅显，不另作解释」。

## §1625 / §1627 篇题与结语

- **问题**（轻，非必改）：§1625 句 `182-1625-2-3` 「三至四。」与 §1626 句 `182-1626-2-5` 「一三三至一三四。」——前者是本品内经序号（3-4），后者是全书经号（133-4）。两处都只给汉字数字而无单位词，并列阅读时易混。
- **建议**：确认导出格式后统一处理（如保留阿拉伯数字「3-4.」「133-134.」），属 export 层格式决定，不在 revise 范围内。
- **问题**：§1625 句 `182-1625-4-4` 「《略闻即悟经》等的注释」与 §1627 「《略闻即悟经》等的注释结束」——「等的注释」的「的」可省，且 `vaṇṇanā` 在复注层严格说是「解说／释」。此处为复注对义注篇题的照引，**必须与父层义注的篇题译文逐字一致**，而父层译文未注入，无法核验。
- **建议**：revise 前调父层 `vaṇṇanā` 篇题译法，以父层为准；若父层作「……等的解说」，此处须随之改动。
