# Review — 100:997-1009（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（997–1000、1003、1006、1008 为标题行，无 nissaya）

## 被解释词与父层逐字核对

- §1002 `parinibbuto`：父层 87-13 译作“具眼者**已经般涅槃**”，本层黑体作「**般涅槃**」，少了“已经”。→ 必改：黑体改为「**已经般涅槃**」。
- §1009 `mātari pitari ca`：父层 87-38 译作“凡是**对母亲和父亲**行为错误的人”，本层黑体拆成「**母亲**、**父亲**，**和**」。这样拆开后，“和”孤零零地成了一个被解释词，也和父层词序不符。→ 必改：改为「“**对母亲和父亲**”等处」。
- §1009 `tāya`：父层 87-41 作“**由于那种**对父母的不如法行为”，本层黑体只有「**那种**」，丢了表具格的“由于”。→ 必改：改为「**由于那种**」。
- 其余黑体词（ananubodhā / appaṭivedhā / dīghamaddhānaṃ / sandhāvitaṃ / saṃsaritaṃ / mamañceva tumhākañca / ariyassa / bhavataṇhā / bhavanetti / anuttarā / dukkhassantakaro / cakkhumā / papatito / cutā patanti / giddhā / punarāgatā / kataṃ kiccaṃ / rataṃ rammaṃ / sukhenānvāgataṃ sukhaṃ / nindiyaṃ / pasaṃsiyo / vicināti… / kalinā tena… / sabbassāpi… / yo sugatesu / sataṃ sahassānaṃ / chattiṃsati / pañca ca / yamariyagarahī / bahuñca / pasavati / pecca / apāyaṃ gacchati）都与父层一致。

## 跨段一致性

- **品题、经题标题格式**：§998 作「第一五十经**集**」，父层 87-4 作「第一五十经**篇**」。→ 必改：统一为「第一五十经篇」。
- **经注标题后缀**：§1000 作「…经的**注释**」，§1003 作「…经的**解释**」，§1006 作「…经的**注释**」，§1008 作「…经**义注**」。→ 统一为「…经的注释」。
- **编号格式**：§1008、§1009 用「4.」，其余各段用「一、二、三、」。→ 统一为「四、」。
- **khata 经名**：§1006「第一损坏经」与 §1008「第二毁损经」都照抄了父层，但父层本身前后不一（87-19 / 87-35）。本层按逐字规则不能自行改动，应回报父层统稿。
- **释词引导语**：§1001–1002 用「…的意思是，」，§1004–1007 用「…，意思是」，§1009 用「“…”，就是」。§1009 还给黑体加了引号，其他段不加。→ 统一为「**X**，意思是…」，黑体外不加引号。
- **集名书名号**：§1001「四集的第一经中」不加书名号，§1007 作「《二集》」。→ 统一加书名号：「《四集》的第一经中」。
- **garahati**：§1007-16-19 的释语 `garahati` 译作「责难」，§1007-119-130 的 `garahanto` 承父层译作「诋毁」。→ 两处语境不同，可以保留，但 §1007-16 的「责难」与 `nindati`「责备」的界限应在释语里说清楚。建议 `garahati` 改为「批评、指责」，避免与「诋毁」混用。
- **ramitabbayuttaka**：§1005-55-61 释语作「**应当**喜乐的」，父层同一处作「**值得**喜乐的」。→ 统一为「值得喜乐的」。

## §1001 句 100-1001-16-20
- **问题**：词法/语体 — `apaccakkhakiriyāya`= မျက်မှောက်မပြုနိုင်ခြင်းကြောင့်（因为不能使之现前）。译文“没有作现前的证验”生硬，近似翻译腔。
- **建议**：改为“由于没有洞穿它、没有亲自证见它”。

## §1001 句 100-1001-61-64
- **问题**：补出成分 — `niddosassa`= အပြစ်မရှိသော（无过失的），nissaya 没有补“不被烦恼染污”。
- **建议**：括注删去，或改为脚注；正文只留“无过失的”。

## §1001 句 100-1001-65-78
- **问题**：原文疑问（记录，不改）— pali 作 `maggaphalasampayuttā**va**`（唯、只），nissaya 读作 `မဂ္ဂဖလသမ္ပယုတ္တာ**စ** … ဝိမုတ္တိ**စ**`（与道果相应，**以及**解脱），是异读。译文“只是”从 pali，可以接受，但两读的分歧记在这里。

## §1001 句 100-1001-94-109
- **问题**：词法/术语 — 末句 `bhavanettīti vuccati` 是说「所以叫做 **bhavanetti**」，被称呼的是被解释词本身。译文却写成“被称为**诸有的绳索**”，那是 `bhavarajju` 的释语，对应关系断了。
- **建议**：改为“所以它被称为牵引众生流转于诸有的渴爱之绳”。

## §1002 句 100-1002-6-10
- **问题**：语体 — “在生死中流转**之**苦”用了文言虚词“之”。
- **建议**：改为“在生死中流转的苦”。`antakaro` 是施事名词（အဆုံးကိုပြုတတ်သော，能作终结者），也可译作“是终结了轮回之苦的人”→“是终结了轮回苦的人”。

## §1002 句 100-1002-2-5
- **问题**：术语 — `lokuttarā` 通行译法是“出世间的”。“超越世间的”是意译，与通行术语不一致。
- **建议**：改为“出世间的”。

## §1004 句 100-1004-17-30
- **问题**：补出成分 — nissaya 在 `sotāpannādayo` 后补出 `တယော`（三种人，即须陀洹、斯陀含、阿那含），译文只写“须陀洹等圣者”。
- **建议**：改为“须陀洹等三种圣者”，范围更明确。

## §1007 句 100-1007-10-15、100-1007-20-23
- **问题**：词法 — `ninditabbayuttakaṃ` 和 `pasaṃsitabbayutto` 都是单一复合词（ကဲ့ရဲ့ခြင်းငှါသင့်သော / ခြီးမွမ်းခြင်းငှါသင့်သည်，适于被责备 / 适于被称赞）。译文各拆成两个并列短语（“该受责备、适合加以责难的人”），多出了原文没有的叠义。
- **建议**：分别改为“适合受到责备的人”“适合受到称赞的人”。
- **附注**：本句 nissaya 只有 `gāthāsu pana … attho evaṃ veditabbo`，`nindiyan` 的 nissaya 落在下一行（16-19）。这是数据对齐错位，不影响审读。

## §1007 句 100-1007-89-96
- **问题**：词法 — `mahantatarabhāvaṃ`= အထူးသဖြင့်ကြီးမြတ်သည်၏အဖြစ်ကို（「更大」这一状态，宾格），是比较级。译文“究竟大到什么程度”偏成了问程度，丢了“比前者更大”的比较义。
- **建议**：改为“现在，为了显示它比那种厄运更大，就说了**十万个**等等”。

## §1009 句 100-1009-2-31
- **问题**：补出成分 — “（即本经）”是 nissaya 和 pali 都没有的补注。
- **建议**：删去。

## §1009 句 100-1009-40-45
- **问题**：格 — `tāya … adhammacariyāya` 的 nissaya 作 `ကျင့်ခြင်းဖြင့်`（具格，“由于／以那种行为”），译文“是指那种…不如法行为”丢了具格。
- **建议**：改为“**由于那种**，意思是由于那种被称为错误行为的不如法行为”。

## §1009 句 100-1009-46-50
- **问题**：词法 — `ito`= ဤပစ္စုပ္ပန်ဘဝမှ（从今生），`gantvā`= တမလွန်ဘဝသို့သွား၍（去往来世）。译文“从这个世间离去”把“今生”泛化成了“世间”。
- **建议**：改为“从今生去往来世以后”。
