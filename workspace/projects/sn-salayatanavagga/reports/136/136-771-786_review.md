## 被解释词与父层对照

- kāye kāyānupassī：与 §1903 一致。
- khemā / paṇḍitā / viyattā / medhāvinī / bahussutā：与 §1929–1932 一致。
- gaṇako / muddiko / saṅkhāyako / gambhīro / appameyyo / duppariyogāho / yena rūpena tathāgataṃ / taṃ rūpaṃ tathāgatassa pahīnaṃ / rūpasaṅkhāya vimutto / hoti tathāgato paraṃ maraṇā / na hoti tathāgato paraṃ maraṇā：与 §1935、§1940 一致。

## 跨段一致性

- acchariya：§780 译“**希有**”，父层 §1942 译“稀有”。→ 建议统一为“稀有”。依据：父层定稿用字，同一巴利词全书应一致。
- 注释书篇题：§771、§776 译“……的注释”，§781 译“……的注释结束”，§783 却译“差摩经**义注**”。→ 建议 §783 统一为“差摩经的注释”。
- 本 chunk 内 “世尊/他” 指称、pe 的译法（“……（中略）……”）前后一致，无问题。

## §772 句 136-772-57-64
- **问题**：词法/取义 — `ဣတော = ဤတရားဟောခြင်းကိစ္စမှ။ ပရံ ပန= နောက်၌မူကား။`。nissaya 明确 ito 指“说法这件事”，即说法之外（之后）的事。译文“从这以后”读成了时间先后，失去了与“说法”的对照。
- **建议**：改为“说法以外的事，也就是实践，是弟子们要做的。”或“在说法之后，实践就是弟子们的事了。”

## §772 句 136-772-87-95
- **问题**：漏译成分 — `ဒါယဇ္ဇံ= ကိုယ်တော်၏ အမွေကို။`（世尊自己的遗产）；`ယောဂါနုရူပံ= ကမ္မဋ္ဌာန်းစီးဖြန်းခြင်းငှာ လျောက်ပတ်သော။`。译文“把遗产交付出去”没有交代是谁的遗产、交给谁。
- **建议**：“他用这两者指出适合修习业处的住处，把自己的遗产交付给弟子们。”

## §773 句 136-773-2-18
- **问题**：增译 — “禅思有两种——”原文与 nissaya 都没有。原文只是以 ārammaṇūpanijjhāna 和 lakkhaṇūpanijjhāna 两种方式解释 jhāyatha = upanijjhāyatha。
- **建议**：删去“禅思有两种——”。改为：“**你们要修习禅思**，是说：要以所缘静虑审察三十八种所缘，以相静虑从无常等方面审察蕴、处等；也就是说，要增长止与观。”
  - 另：upanijjhāyatha 是 jhāyatha 的释词，nissaya 作 `ကပ်၍ ရှုကြကုန်`（贴近地审视），用“审察”比“观察”更能显出与“禅思”的对应。可酌。

## §773 句 136-773-25-66
- **问题 1（必改）**：误译 — `မင်္ကုသာနံ ... = ကြမ်းပိုးတို့၏။ ဘတ္တံ= အစာသည်။ ဟုတွာ = ဖြစ်၍။`。maṅkulabhattaṃ hutvā 意为“成了臭虫的食物”，即日夜躺在床上任臭虫叮咬。§773-67-84 的 nissaya 也称这类比丘为 `ကြမ်းပိုးထမင်း ရဟန်းဖျင်း`（臭虫食的懈怠比丘），可以互证。译文“日夜饱食昏沉”与原意不符。
- **建议**：“日日夜夜躺在床上，成了臭虫的食物”。
- **问题 2**：补出成分 — `ယေ ဘိက္ခူ` / `တေ ဘိက္ခူ`，nissaya 补出主语是比丘。译文“那些人”泛化了。
- **建议**：“那些比丘……他们……”。
- **问题 3**：取义 — `ဝိပတ္တိကာလေ = ဘတ္တသပ္ပါယစသည်ကိုမရ ဝိပတ္တိကာလ`，指得不到饮食等适宜条件的衰败之时，与前文“七种适宜等条件具足”相对。“失坏的时候”太含糊。
- **建议**：“条件衰败、得不到适宜饮食等的时候”。
- **问题 4**：词义 — `မိဒ္ဓသုခံ = တငိုက်မျည်းမျည်း နေခြင်းကြောင့်ဖြစ်သော ချမ်းသာ`（打盹昏沉之乐），`သေယျသုခံ = တစင်းစင်းအိပ်ခြင်း`（伸直身子躺卧之乐）。
- **建议**：“躺卧之乐和昏睡之乐”，可酌。

## §777 句 136-777-6-16
- **问题**：补出成分 — `ပရတော= နောက်ဖြစ်သော မဟာဝဂ္ဂသံယုတ်၌။`，nissaya 指明“后面”就是大品。
- **建议**：可补为“将在后面的大品中说明”。可酌。

## §778 句 136-778-2-7
- **问题**：夹注位置 — 巴利夹注（anata）放在了第二次出现处，首次出现的黑体“无倾向”反而没有。
- **建议**：夹注移到首次出现处：“**无倾向**（anata）等句中：……所以是无倾向。”

## §780 句 136-780-24-26
- **问题**：词义 — `ဗျာဗဇ္ဈာဘာဝေနေဝ= ကြောင့်ကြမရှိသည်၏ အဖြစ်ကြောင့်`，nissaya 把 byābajjha 解作忧烦、焦虑，不是“恼害”（加害）。
- **建议**：考虑“正因为没有苦恼，所以是**无苦恼**”。如果保留“无恼害”作为传统译名，压低 confidence。

## §784 句 136-784-2-38
- **问题**：属格归属（必改）— nissaya 作 `ဗိမ္ဗိသာရဿ = ဗိမ္မိသာရမင်းကြီး၏။ ဩရောဓဘူတာ= ကိုယ်လုပ်တော်ကြီးဖြစ်သော။ ဥပါသိကာ= မြတ်စွာဘုရား ဥပါသိကာမဖြစ်သော။`：
  - bimbisārassa 修饰的是“妃子”（orodha）；
  - upāsikā 是“世尊的女居士”。
  
  译文“频婆娑罗王的女居士”把属格挂错了对象。
- **建议**：“**差摩**，是指在家时是频婆娑罗王的妃子、身为（世尊的）女居士，因为信心而出家的大长老尼……”
- **原文疑问**：nissaya 底本有 orodhabhūtā，所给 pali 中没有，疑为版本异读。记下，不改原文。

## §785 句 136-785-13-17
- **问题**：词义 — `ပိဏ္ဍဂဏနာယ = အပေါင်းရေတွက်နည်း`，指加总合计的算法。“估算”多出了“约略”的意思。
- **建议**：“擅长汇总合计的人”。

## §785 句 136-785-33-46
- **问题**：词义（必改）— `သာမော= ရွှေသောအဆင်းရှိ၏။`，nissaya 把 sāmo 解作金色。译文“黑”与之相反。
- **建议**：“说他高、矮、金色、白”。

## §785 句 136-785-47-57
- **问题**：格（释文部分）— `သဗ္ဗညုတထာဂတဿ = သဗ္ဗညုဖြစ်သောဘုရားသည်။ ပဟီနံ= ပယ်အပ်လေပြီ။`，nissaya 把属格读作施事：已被一切知的如来舍断。
- **建议**：黑体被解释词保持与父层一致，不动。释文可改为“……由于断除了集，已被一切知者如来舍断”。可酌。

## §785 句 136-785-58-72
- **问题 1**：词义 — `ရူပါရူပကောဋ္ဌာသေနပိ = ရုပ်နာမ်အဖို့အစုအားဖြင့်လည်း`，arūpa 在这里指名法。
- **建议**：“按色与名的类别”。
- **问题 2**：词义 — `ဧဝရူပေါ နာမ= ဤသို့သဘောရှိသည်မည်သည်`，evarūpo 意为“如此这般的”，范围包括名色两方面。译成“形色”就窄化成了只指色。
- **建议**：“他将会是如此这般的”。

## §785 句 136-785-82-124
- **问题**：补出成分 — `ယံ ခန္ဓပဉ္စကံ= အကြင်ခန္ဓာငါးပါးအပေါင်းကို။ ဥပါဒါယ= စွဲ၍။` / `တဒဘာဝေန= ထိုခန္ဓာငါးပါးအပေါင်း၏ မရှိခြင်းကြောင့်။`。nissaya 明确 yaṃ / tad 指五蕴。译文写成“那个……东西”，指涉不清。
- **建议**：“……依据五蕴而有‘被称为有情的如来’这一施设；由于五蕴已不存在，对于看到那个施设也不存在的人来说……”

## §786 句 136-786-8-12
- **问题**：词义 — `နိရန္တရံ= အထူးမရှိသည်။`，nissaya 解作“没有差别”。译文“不会有任何间隙”是按字面译 nirantara，与黑体“毫无出入”的意思也接不上。
- **建议**：“是说两者不会有任何差别”。

## §786 句 136-786-22-25
- **问题**：增译 — nissaya 只作 `ဒေသနာ၌`。“佛的说法”中的“佛的”是增出的，而且此处的说法兼指导师与女弟子两方，加“佛的”会把所指缩窄。
- **建议**：“**最高的教说**，指的是说法（desanā）。”
