## 跨段一致性

- **pakiṇṇaka-kathā / -dhammadesanā**：§491 两处译“杂谈”，§503 译“零散讲说的法”。建议统一为“零散的法谈”。
  - 依据：nissaya 两处都作 `ပြိုးပြွမ်းသောတရားစကား / ဒေသနာ`（零散的法语、说法）。
  - “杂谈”丢掉了“法”的含义，读起来像闲聊。
- **virocati**：§483 译“光辉照耀”，§486、§490 译“光辉灿烂”。同一偈组内建议统一为“光辉灿烂”。
- **daratha（跨层）**：§505 把 kāyikacetasikadarathā 译为“身心的疲乏”，父层 170-1200 把同词根的 sadarā 译为“有热恼的”。
  - nissaya：`ကိုယ်စိတ်၌ဖြစ်သော ပူပန်ခြင်း`（身心的焦灼、热恼）。
  - 建议改为“身心的热恼”，与父层统一。
- **nāgavikkanta-**：§473 与 §479 一致，但两处都多出了“威猛”。见下文，两处要一起改。
- **paṇḍukambala / nekkha**：§484 与 §485 一致，但两处取义都与 nissaya 不合。见下文，两处要一起改。

## §468 句 136-468-2-9
- **问题**：格与句法。
  - aghaṭṭayanto 是使役现在分词，nissaya：`အချင်းချင်းမထိခိုက်စေမူ၍`（不使〔膝、踝〕互相碰撞）。主语是走路的人，两膝、两踝是宾语。
  - 译文“两膝和两踝互不碰撞”把膝、踝写成了主语。
- **建议**：改为“他走出去时，不让两膝、两踝互相碰撞。”

## §469 句 136-469-2-9
- **问题**：取义。sampannacaraṇo 的 nissaya 是 `ကြန်လက္ခဏာပြည့်စုံစွာသည့် ခြေတော်ရှိသော`（具有相好圆满之足的），把 caraṇa 解作“足”。这和上下文讲步态正好吻合。译文“行为圆满”取的是另一个意思。
- **建议**：改为“双足具足相好的牟尼”。

## §471–472 句 136-471-2-13 / 136-472-2-9
- **问题一**：格与句法。
  - 471 句的上、下、横、方、维都是 pekkhamāno 的宾格宾语（nissaya 都标 `ကို`）。
  - 472 句译成泛泛的“都不东张西望”，宾语就脱落了，471 句成了悬空的列举。
- **问题二**：nissaya 把 `တိရိယဉ္စ ဒိသံ` 合为一项，作“横向的方位”（ဖီလာအရပ်）。译文“横向，以及四方”拆成了两项。
- **建议**：
  - 471 句改为“上方、下方、横向各方，以及四维，”
  - 472 句改为“他行走时都不去张望，目光只落在身前一轭之地。”

## §473 句 136-473-2-11；§479 句 136-479-2-8
- **问题**：增译。nāgavikkantacāro / -cāraṇo 的 nissaya 是 `ဆဒ္ဒန်ဆင်မင်း၏သွားခြင်းနှင့် တူသော`（如六牙象王般的行走），只讲步态像象王。“威猛”是加出来的。
- **建议**：两处统一为“步态如象王”。

## §475 句 136-475-2-9
- **问题**：增译与句法。
  - nissaya 让 sobhanto 统摄两个比喻：`အသွားတင့်တယ်တော်မူသော`（行走庄严优美）。
  - 后半句的“威严”在原文中无对应。
- **建议**：改为“他像月亮那样、像四足行走的雄狮那样，行走时庄严优美，”

## §477 句 136-477-35-45
- **问题**：词义。itarā pajā 的 nissaya 是 `ပစ္စေကဗုဒ္ဓါသာဝကမှစ၍ ရှိရှိသမျှသတ္တဝါ`（从辟支佛、声闻起的一切众生）。“其余的人”把范围译窄了。
- **建议**：改为“何况其余众生”。

## §477 句 136-477-46-58
- **问题一**：词义。nissaya 作 `သကျရာဇပုရံ = သာကီဝင် မင်းနေပြည်`（释迦王族的都城）。“王族的居处”易被理解为宫室。
- **问题二**：漏译。gandha / dhūma / vāsa / cuṇṇa 是四项，nissaya 作 `နံ့သာ အခိုး အထုံး မှုန့်`（香、烟、熏、粉）。译文只译出三项。
- **建议**：
  - “居处”改为“都城”。
  - 供品改为“香、香烟、熏香、香粉等”。

## §478 句 136-478-9-27
- **问题**：词义细节。
  - ① rattakambalapaliveṭhite 的 nissaya 是 `လွှမ်းရစ်အပ်သော`（覆裹的），不是“铺着”。
  - ② dukūlacumbaṭaka 的 nissaya 是 `ဖွဲ့ဖြူပုဆိုးကျစ်`（细布卷成的布团）。“细棉布”丢了“团”的意思，dukūla 也不限于棉布。
- **建议**：改为“用细布团拭干水分……安放在覆裹着红色毛毯的座台上”。

## §479–480 句 136-479-2-8 / 136-480-2-7
- **问题**：主语分裂。nissaya 中 lokaggo 是 gantvā 与 nisīdi 共同的唯一主语。译文 479 句用“这位……的人”，480 句又用“世间最上者”，读起来像两个人。
- **建议**：
  - 479 句改为“这位步态如象王的世间最上者，走到圆形的集会堂，”
  - 480 句改为“放射光明，坐在殊胜的座位上。”

## §483 句 136-483-2-6（必改）
- **问题**：格与句法误读。
  - buddhāsane 是处格，nissaya 把它与 481 句的 nisinno 连读：`ဗုဒ္ဓါသနေ= ဘုရားနေရာတော်၌ … နိသိန္နော`（坐于佛座上）。
  - majjhagato 的 nissaya 是 `နောက်တော်ကသံဃာ ရှေ့မျက်နှာကမင်းများ နှစ်ပါးပရိသတ် အလယ်၌`（处在身后的僧团与面前的诸王这两众之间）。
  - 所以是“在两众中间”，不是“在佛座中央”。
- **建议**：改为“坐在佛座上，处在两众中间，光辉灿烂，”

## §484–485 句 136-484-2-5 / 136-485-2-9
- **问题**：词义。
  - paṇḍukambale 的 nissaya 是 `ပဏ္ဍုကမ္ဗလာကျောက်ဖျာထက်၌`（在黄毯石座上），即帝释的黄毯石。
  - nekkha 的 nissaya 是 `နိက္ခအချိန်မျှသောရွှေစိုင်`（一尼卡重的金块）。“金饰”取义不合。
- **建议**：两处统一改为“黄毯石座上的金块”。
  - 484 句：“就像放在黄毯石座上的金块。”
  - 485 句：“如同阎浮檀金的金块，放在黄毯石座上；”

## §491 句 136-491-2-15（必改）
- **问题一**：被解释词与父层不一致。父层把 dhammiyā kathāya 译为“说法”，把 bahudeva rattiṃ 译为“说了大半个夜晚”，两者不连续。本层黑体改写成“说了大半个夜晚的法”。
- **问题二**：增译。santhāgārānumodanāpaṭisaṃyuttā 的 nissaya 是 `ကျောင်း၏ အနုမောဒနာနှင့် စပ်သော`（与集会堂〔布施〕的随喜相关）。“落成”是加出来的。
- **问题三**：pakiṇṇakakathā 的译法，见“跨段一致性”。
- **建议**：改为“**为迦毗罗卫的释迦族人说法**……**说了大半个夜晚**——这里所说的说法，应当知道是指与集会堂布施的随喜相关的零散法谈。”

## §491 句 136-491-16-42
- **问题**：词义。madhubhaṇḍa 的 nissaya 是 `ပျားလဘို့ကြီး`（大蜂巢）。“蜜块”不准确。
- **建议**：改为“一由旬大的蜂巢”。

## §491 句 136-491-43-75（必改）
- **问题一**：漏译。tumhākaṃ āvāso 的 nissaya 是 `သင်မင်းများတို့၏ အရိပ်အာဝါသကို`（你们的住处）。译文没有译出，“我使用过了”缺了宾语。
- **问题二**：隐含成分。nissaya 补出 mahantaṃ **puññaṃ**（是很大的功德），“大布施”不够准确。
- **问题三**：mahārāja 的 nissaya 作复数 `မင်းများတို့`。听众是释迦诸王，译文用单数“大王”。
- **建议**：改为“诸位大王，所谓布施住处，是很大的功德。你们的住处我已经使用过了，比丘僧团也使用过了……”

## §491 句 136-491-76-81
- **问题**：sabbadānaṃ 的 nissaya 是 `ကျောင်းမှကြွင်းသော အလုံးစုံသောဒါန`（住处以外的一切布施）。“布施了一切”容易被读成“施出一切财物”。
- **建议**：改为“就等于做了一切布施”。

## §493 句 136-493-2-9
- **问题**：句法。nissaya 把 sisire 与 vuṭṭhiyo 分作两个宾语：`သိသိရေ = ချမ်းအေးသောအတွေ့`（寒冷的触感）、`ဝုဋ္ဌိယော = အမှတ်မဲ့ရွာသော မိုဃ်းရည်`（不时降下的雨水）。“寒季的雨水”把两项并成了一项。
- **建议**：改为“挡住蛇蝎之类和蚊虫，也挡住寒冷和雨水。”

## §497 句 136-497-2-9
- **问题**：句法。sampassaṃ atthamattano 的 nissaya 是 `မိမိ၏ အကျိုးစီးပွားကို ကောင်းစွာမြင်သော`（清楚看到自己利益的）。“看到对自己有利益”不通顺，也没有体现宾格。
- **建议**：改为“所以，清楚看到自身利益的智者，”

## §502 句 136-502-2-18
- **问题**：词义。idha 的 nissaya 是 `ဤသာသနာတော်၌`（在这教法中），不是“此世”。
- **建议**：改为“他在这教法中了知了这法以后，就成为无漏者而般涅槃。”

## §504 句 136-504-9-26
- **问题**：句法。gamanakālo tumhākaṃ, gacchatha 都在 vuttaṃ hoti 的引述范围之内，nissaya 是 `… ဂစ္ဆထ ဣတိ ဝုတ္တံ ဟောတိ`。译文“意思是……也就是说”把一层引述拆成了两层，“看该走的时间”也不够顺。
- **建议**：改为“意思是：你们自己考虑该走的时候——你们该走了，请回去吧。说的就是这个。”

## §504 句 136-504-35-45
- **问题**：语气。uppajjeyya 是祈愿式，nissaya 作 `ဖြစ်ရာ၏`（可能会生起）。“会生起”说得太肯定。
- **建议**：改为“身上可能会生起病痛”。

## §505 句 136-505-2-24
- **问题一**：隐含成分。nissaya 补出 `ကေစိ ဝဒန္တိ`（有些人说），并标明 etaṃ 指“这些人的说法”。译文只写“据说”，看不出这是被驳斥的他说。
- **问题二**：akāraṇaṃ 的 nissaya 是 `အကြောင်းမဟုတ်ခဲ့`（不成理由）。“但这不是理由”不通顺。
- **问题三**：acālayiṃsu 是“一动不动”，“没有动摇过”偏抽象。
- **建议**：改为“有人说，比丘们在那里前两个时分里不论站着还是坐着都一动不动……——这个说法站不住脚。”

## §505 句 136-505-25-51（必改）
- **问题一**：术语误译。kāyacittalahutā 的 nissaya 是 `ကိုယ်စိတ်ပေါ့ပါးခြင်း`（身心的轻快），是 lahutā（轻快性），不是 passaddhi（轻安）。
- **问题二**：daratha 的译法，见“跨段一致性”。
- **建议**：改为“不会有身心的热恼，反而会生起身轻快性、心轻快性等”。

## §505 句 136-505-52-59
- **问题**：隐含成分。āha 的 nissaya 用敬语 `ဟောတော်မူ၏`，主语是世尊。
- **建议**：改为“所以世尊说：“已经离开了昏沉睡眠”。”
