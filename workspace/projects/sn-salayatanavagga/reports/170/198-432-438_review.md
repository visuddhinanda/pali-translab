## 被解释词核对（与父层逐字对照）

与父层译文逐字一致、无问题的：**这段话** / **领会了前面的意思** / **他** / **为了向他宣讲法** / **同一个意思** / **都不会有盗贼的顾虑** / **为了装饰城市** / **同时也确实有防盗的用途** / **门扇框架** / **在那里**（边境城市） / **这身体的** / “一对快使” / **作为心所依处（hadayavatthu）所依的四大种** / **所依色的** / **是什么样子** / **它因为同样具足八支，也就是那个样子** / **来时的路** / **以上是这里** / **对应则是这样的** / **城主的比喻** / 十字路口的比喻 / **所讲的就是四谛** / **因为城市的全部构成成分** / **城市的构成成分所讲的正是苦谛** / 六道门。

## 跨段一致性

- `saṅkhāta` 译法不统一：§432-25-30 译“**那个称为**见清净的意思”、§432-99-103 译“**称为**熟练的本领”、§436-2-15 译“**称为**有身的城市”，但 §432-104-110 译“**所谓**临机生起的智慧”，§432-88-98 的 `jānanañāṇasaṅkhātena` 则整个省略未译出。→ 建议统一为“称为…的”，§432-104-110 改作“**所谓临机生起的智慧**”保留（该处 `saṅkhātāya` 本身在被解释词内，译“所谓”可接受），但 §432-88-98 应补出：“他具备这样的、称为了知之智的**贤明**”。
- `nagarasambhāra` 译法一致（城市的构成成分／城市的全部构成成分，后者对应 `sakalena`，正确区分）✅
- “比喻”“见清净”“漏尽者”“十字路口”“所依色／心所依色”“业处”全 chunk 一致，且与父层一致 ✅
- 夹注体例一致：`hadayavatthu` 只在 §436-27-40 随父层原样带出，`khīṇāsava` 不重复夹注 ✅

## §432 句 198-432-37-46

- **问题**：层间对应断裂（必核） — 复注被解释词作 **Tipurisubbedhānī**（三人高），译“**有三人高的**”；但父层 136:531 的义注原文作 `purisubbedhāni`，父层定稿译文为“建得有**一人高**的”。被解释词与父层译文不对应，读者看不出这条注在注哪个词。
- **建议**：这是**版本异读**，不是译错——复注译文按其自身原文作“三人高”是对的，**不要改复注去迁就父层**。请在 harmonize 时核对父层 136:531 的原文读法：若父层确为 `purisubbedhāni`，在复注此句加脚注说明“复注所据本作 tipurisubbedhāni（三人高），义注本作 purisubbedhāni（一人高）”；父层译文不动。

## §432 句 198-432-17-24

- **问题**：可读性 — “使他已经获得的殊胜进一步增长”中“殊胜”作名词，一般读者难解（`laddhavisesa` 指已证得的殊胜成就）。
- **建议**：改为“使他已经获得的殊胜成就进一步增长”。

## §432 句 198-432-72-87 / 198-432-88-98

- **问题**：指代混淆（必改） — 原文 `imehi … imesaṃ vasena` 是**两组对举**（由某些人带来利益、由另一些人带来损害），译文两处都作“依靠这些人”，对立关系完全丢失，读者会读成同一批人既有利益又有损害。
- **建议**：改为“……而且就其中而言，由**这一些人**能给城市和城主带来利益，由**那一些人**则会带来损害”。

## §432 句 198-432-99-103

- **问题**：语感生硬 — “具备称为熟练的本领”为字对字迁就 `paṭubhāvasaṅkhātena`。
- **建议**：“在阻挡陌生人这件事上熟练老到，这就是**具足明敏**。”

## §432 句 198-432-37-46（词义存疑）

- **问题**：存疑 — `nānābhittivicittāni` 译“墙面上装饰着各种彩绘”，`vicitta` 此处更可能泛指“有各式纹饰／花样”，未必是彩绘；译文把它坐实了。
- **建议**：改为“饰有各式墙面纹样”，并压低该句 confidence。

## §433 句 198-433-13-23

- **问题**：存疑（待父层核对） — `tassa ṭhānaṃ vibbhamo jāto` 译作“他的职守就荒废混乱了”。`vibbhama` 亦可作“散失、失去”，即“他的职位就丢了”；主格 `vibbhamo` 与 `ṭhānaṃ` 的句法关系不明。
- **建议**：待 136:532-534 父层文与 nissaya 补齐后定夺；暂保留现译并压低 confidence。

## §433 句 198-433-24-32

- **问题**：引文待核 — “**撤掉了一切审断的处所等等**”对应父层 136:532-534，未注入无法核对；`hāretvā` 是“令搬走／拆除”，“撤掉”方向大致可，但父层若已定稿为别的说法，此处必须逐字改齐。
- **建议**：harmonize 时以父层译文为准替换。

## §434 句 198-434-34-57

- **问题**：原文疑问（记录，不要改） — `tatthovādapaṭikarattapatto`、`odameyya` 两处词形可疑，前者复合词切分不明，后者动词形态罕见，疑为讹误或异读。现译“他在那里领受教诫、照着改正，就会收敛下来”属合理推读，但依据不足。
- **建议**：保留现译，压低 confidence，并登记进 `knowledge/known-issues.md` 的“OCR / 原文问题”。
- **问题**：语感 — “你要装出一副奉我的命令**要**砍下他的头的样子”一句两个“要”，拗口。
- **建议**：“你就做出奉我的命令、正要砍下他的头的样子”。

## §436 句 198-436-2-15

- **问题**：可读性 — “是指那座称为有身的城市的；”以“的”悬空收尾，读者会卡住；后半“要把上文‘说成“门”’一句牵引过来连成一句读”未把补足后的完整读法给出。
- **建议**：“**这身体的**，是指那座称为有身的城市；要把上文的“说成‘门’”牵引过来，连成“（那座城市的六处）被说成‘门’”来读。”

## §436 句 198-436-59-67

- **问题**：增译 — 原文 `sammādiṭṭhiādīnaṃ vasena` 只说“就正见等来说”，译文补出“八支”。虽由下句 `aṭṭhaṅgasamannāgatattā` 可推，但属擅自补足。
- **建议**：改为“就是就正见等诸支来说”，“八支”留给下一句自己点出。

## §436 句 198-436-87-98

- **问题**：**文言虚词（必改）** — “……上述比喻，**其**对应就是这样。”“其”作文言虚词，违反 `style.md` 第一节禁例。
- **建议**：“**以上是这里**，是说在这里、在这部经中为了说法而引用的上述比喻，它的对应就是这样。”

## §437 句 198-437-50-54

- **问题**：主语脱落致意思模糊 — “因为是用这些来比喻六触处等等的”，谁比喻谁不清楚。
- **建议**：“因为六触处等等正是用这些（城市的构成成分）来作比喻的。”

## §438 句 198-438-2-4

- **问题**：层次标识 — “紧叔迦树喻经的注释结束。”与父层 136:515 的章题“紧叔迦树喻经（kiṃsuka）的注释”同形，但本层是**复注**，读者会误以为是义注结束。
- **建议**：确认本书（198）各章尾的统一体例；若全书一律直译，则保持现状不动，在 harmonize 时统一处理，不要只改这一处。
