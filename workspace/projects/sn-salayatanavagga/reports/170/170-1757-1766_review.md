# Review — 170:1757-1766（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句有）
> 注：170-1759-14-20 挂的 nissaya 实际是 33-59 句（yo so yodhājīvo saṅgāme ussahati vāyamati）的释义；170-1759-60-78 的 nissaya 前半（tassa … duppaṇihitaṃ）也属 33-59 句。下文按实际内容对齐引用。

## 跨段一致性

战士经（§1757-1760）与马兵经（§1763-1766）巴利原文几乎逐字相同，只换了兵种名，但两经译法全面分叉，需要统一。下表的建议依据 nissaya，没有 nissaya 依据的项按战士经译法统一，或取较准确的一种：

| 巴利 | 战士经 | 马兵经 | 建议 |
|---|---|---|---|
| parajitānaṃ devānaṃ | 战败诸天 | 败亡诸天 | 统一，并按专名处理，见 §1758 句 170-1758-38-65 |
| parajito nāma nirayo | 名为“战败”的地狱 | 名叫败亡的地狱（无引号） | 统一为「名为“战败”的地狱」 |
| ussahati vāyamati | 奋战努力 | 奋勇作战、竭力拼杀 | 统一。nissaya：ဥဿဟတိ= အားထုတ်၏（努力）、ဝါယမတိ= လုံ့လပြု၏（精勤），后一种增译过重 |
| pare | 别人 | 敌人 | 统一 |
| pariyāpādenti | 置于死地 | 结果了性命 | 统一。nissaya：သေခြင်းသို့ ရောက်စေ（使至于死） |
| ācariyapācariyānaṃ | 历代师长 | 老师和老师的老师 | 统一 |
| tiṭṭhatetaṃ / mā maṃ etaṃ pucchī | 搁下 / 不要问我这件事 | 放下 / 不要问我这个 | 统一 |
| … pe … | ……乃至…… | ……（中略）…… | 统一 |
| etadavoca | 这样说 | 这样说道 | 统一 |
| Evaṃ vutte | 这样说了以后 | 世尊这样说的时候 | 统一 |
| ucchijjantu | 被断灭 | 被铲除 | 均需改，见 §1759 句 170-1759-60-78 |
| mā ahesuṃ | 但愿他们根本不曾存在 | 让他们不复存在 | 统一为后者的意思，见 §1759 |
| gahitaṃ dukkaṭaṃ duppaṇihitaṃ | 存着／做得恶劣的／安置得恶劣的 | 执持住／恶劣地造作／错误地导向 | 统一，见 §1759 |
| 归依句结尾 | 请世尊接受我从今天起终生归依 | 从今天起，我终身归依 | 统一句式，「终生／终身」择一 |

其他两项单独说明：

- **na labhāmi / nālatthaṃ**：
  - §1759、§1760 译「没能让你答应」。
  - §1765、§1766 译「没能从你这里讨到这句话」。这是误读：“alaṃ … pucchī” 是世尊自己的话，不是向村长讨来的。nissaya 在 §1759 作 `တေ= အား`（与格「对你」），意思是：我对你说“够了……”，你却不肯接受。
  - 建议统一为「我对你说‘……’，你却不肯罢休」一类译法。
  - §1760「我正是**为了**这个，才没能……」把 etaṃ（这就是〔我没能让你接受的〕）译成了目的，也要改。
- **段号格式**：§1764 作「三五七、」，§1758、§1762 作「355.」「356.」→ **必改**，改为「357.」。同句「当时」与另两经的「那时」也统一为「那时」。

## 全篇 gāmaṇi（§1758 / §1762 / §1764 各篇首句）
- **问题**：词义。nissaya 把 gāmaṇi 释为 `ဂါမဏိ= စစ်သူကြီးသည်`（军队首领、将领），不是「村长」。§1762 `ဟတ္ထာရောဟော= ဆင်စီးသူရဲဖြစ်သော ဂါမဏိ= စစ်သူကြီး` 指「身为象兵的将领」，§1764 指「身为马兵的将领」。「战士村长／象兵村长／马兵村长」读来像是统管村落的人，与语境（谈战死往生）不合。
  §1758 nissaya 另有 `ယောဓာဇီဝေါ= ယောဓာဇီဝအမည်ရှိသော`，把 Yodhājīva 当作人名；异释 `ဝါ=` 则作「以战斗为生的」。
- **建议**：gāmaṇi 改为「首领／将领」，三经一致。例如「以战斗为生的首领」「象兵首领」「马兵首领」，经题可保留。若项目沿用「村长」作为本相应的固定译名，应在 terms.md 登记，并把分歧写入 known-issues。

## §1758 句 170-1758-38-65（及各处同句复现）
- **问题 1**：专名处理。nissaya 作 `ပရဇိတာနံ= ပရဇိတအမည်ရှိကုန်သော`（名为 Parajita 的），把 parajita 当作这群天神的名称。译文「战败诸天」按普通形容词理解，与下文「名为‘战败’的地狱」的专名处理也不对称。
- **建议 1**：改为「名为‘战败’的诸天」。所有复现处同步修改，包括 1758-114-141、1759-104-133、1760-64-92，以及马兵经各处。
- **问题 2**：格位存疑。nissaya 作 `ပရေ= သူတပါးတို့ကို`（宾格「他人」），`တမေနံ= ထိုစစ်ထိုးခြင်းကို`（「那场战斗」宾格），`ဥဿဟန္တံ= သော်`（「……时」）。照此读法是「他在那场战斗中奋力时，杀死他人」。译文取的是 pare 为主格「别人杀死他」。动词 hananti 是复数，主语应为复数，所以现译在语法上站得住。§1759-79-85 的 nissaya 同样作 `ပရေ= တို့ကို`。
- **建议 2**：保留现译，但在 known-issues 记录这处 nissaya 的分歧，请人工确认。

## §1759 句 170-1759-60-78（含其 nissaya 覆盖的 33-59 句）
- **问题 1**：误译。nissaya 作 `ဥစ္ဆိဇ္ဇန္တု ဝါ= (လက်ခြေစသည်တို့၌) ဖြတ်မှုလည်းဖြတ်ကြကုန်လော့`，意思是在手脚等处砍断。译文「被断灭」既偏离词义，又容易与断见（uccheda）术语混淆。§1765「被铲除」同样不对。
- **建议 1**：改为「被砍断（手脚）」或「被砍伤肢体」，两经一致。
- **问题 2**：时态误读。nissaya 作 `မာ ဝါ အဟေသုန္တိ= မဖြစ်ပါစေကုန်လင့်`（愿他们不存在），这是 mā + 不定过去时的禁止／祈愿式。译文「根本不曾存在」把它读成了过去时。
- **建议 2**：改为「或者但愿他们不再存在」。
- **问题 3**：语气。nissaya 对 haññantu 等作命令式（`…ကြကုန်လော့`），译文用「让……被……」处理，方向正确。但四个「被」字之间的「或」字有的有、有的没有，与 §1765 不一致，统一即可。
- **问题 4**：属 33-59 句。nissaya 作 `တဿ= ထိုစစ်သူကြီး၏`（那首领的）、`တံ စိတ္တံ= ကို`、`ဂဟိတံ= ယူအပ်၏`（被执取）、`ဒုက္ကဋံ= မကောင်းသဖြင့်ပြုအပ်၏`（以不善方式造作）、`ဒုပ္ပဏိဟိတံ= မကောင်းသဖြင့်ထားအပ်၏`（以不善方式安置）。译文「他那颗心先前就已经这样存着了」中「存着」不准确：gahitaṃ 是「执取」，不是「存着」。
- **建议 4**：改为「他的心早先就已经被恶劣地执取、恶劣地造作、恶劣地安置」。§1765「错误地导向」也照此统一。

## §1759 句 170-1759-86-96
- **问题**：无误。nissaya 作 `(အတ္ထိ= ၏။)`，补出「有」：「有名为 Parajita 的地狱，他就投生到那里」，与译文一致。nissaya 原文的 `ပရိဇိတော` 疑为 `ပရဇိတော` 之误，只记录，不影响译文。

## 原文 / 资源疑问
- 170-1759-60-78 的 nissaya 附有一条注（`၁။ ဋီကာအလို န ရောဒါမိ၊ သည်းမခံနိုင်ပါ`）。按复注，「na rodāmi」可解作「我无法忍受」，应对应 §1760 / §1766 的「Nāhaṃ … etaṃ rodāmi」，被挂错了位置。现译「我不是因为……才哭的」取的是常解。此处只记录供人工参考，不列为必改。
- 170-1759-33-59 原文的异读 `[hīnaṃ (sī. pī.)]` 指 gahitaṃ 一作 hīnaṃ。现译取 gahitaṃ，无需改动。
