## 理由

**资源缺口（影响信心）**：本次只拿到巴利原文与 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**，无法按「义注定释义、nissaya 定词法」逐词核对。下列判断依据巴利原文形态、段内平行结构（1784 与 1785/1786 是对举的两段套语）与教理常识作出，信心相应下调。涉及 `yathābhataṃ nikkhitto` 这类高度固定的套语，结论参照的是该套语的通行理解，不是义注原文，标注为 error 但保留复核余地。

**准确性**：主谓宾判断与教理立场无误，反面（外道师徒）与正面（如来弟子）两段的论旨都译对了，尤其 `na metaṃ pāpaṃ kammaṃ akataṃ bhavissati`（"恶业不会因此成为没有做过的"）这一关键句没有走样。格与句法层面：`Yo kho pana mayā pāṇo atipātito … taṃ na suṭṭhu` 的关系句、`tappaccayā vippaṭisārī assaṃ` 的让步、`diṭṭhiṃ paṭilabhati` 在引语之外归给叙述者，都处理正确；异文（`evaṃdiṭṭhī (ka.)`、`ahañce (?)`、`pāpakammaṃ (syā.)`）未译入正文，符合体例。扣分集中在 `yathābhataṃ nikkhitto evaṃ niraye` 一处套语：译文补出了原文没有的施事"人"，并把被动的"被安置"改成主动的"落入"。另有 `Evametassa pāpassa kammassa pahānaṃ hoti` 这组名词句被改写成"他舍断了"，与紧邻上句形成表面张力。

**风格符合度**：通篇现代书面汉语，未见文言虚词与文言句式，无"此中/故为/彼等/是故"一类禁例，也没有残留的工作标记（候选、待定、问号）。标点全角，引号统一为 “” ‘’，三层引语（佛陀说 → 弟子自思 → 引师说）的 “／‘／“ 套层正确，`zh` 字段内无 ASCII 引号。唯一标点缺失在 1786 段首：巴利 `‘‘‘` 是外层引语跨段重开加内层，译文只开了内层 ‘。十号连称属汉传固定译名，保留可接受，但对一般读者不透明，未加任何注释。

**一致性**：四组套语（`āpāyiko nerayiko`、`garahati vigarahati`、`viramatha`、`yathābhataṃ nikkhitto…`、`Evametassa…pahānaṃ/samatikkamo`）在 1784–1786 各次出现的译法完全一致，重复段落逐字相同，这是本段最扎实的地方。失分在两处非套语的平行点：对举的 `Idha` / `Idha pana` 译法不对称；同结构的"我杀生这件事" / "我做过的不与而取"句式不齐。

## 问题清单

### 🟧 error

- `170-1784-108-124`｜错误多译（兼词义/语态偏差）｜片段「就像被人搬来放下一样，必定落入地狱」
  - 问题：`yathābhataṃ nikkhitto` 中并无施事，译文补出的"人"是原文没有的成分；该套语的施事按传统理解是业，不是某个人，补"人"会让读者误以为有外力押送。另 `nikkhitto` 是被动过去分词"被安置（于地狱）"，译作主动的"落入地狱"，且"放下"后缺落点，读来悬空。
  - 建议：改为"就像被带来安置在那里一样，他就这样被安置在地狱中"。同一套语在 `170-1784-153-170`、`170-1784-208-224`、`170-1784-258-274` 三处逐字重复，须一并改，改后仍保持四处完全一致。

### 🟨 warning

- `170-1785-175-180`｜整句逻辑表达不规范｜片段「他就这样舍断了这个恶业」
  - 问题：原文 `Evametassa pāpassa kammassa pahānaṃ hoti` 是名词句，主语是"舍断"本身，重心在"如此便有对该恶业的舍断"。译成"他就这样舍断了这个恶业"，一来与前文"这个恶业也不会因此成为没有做过的"表面冲突，易被读成过去的业被消除；二来与上一句"他这样思量之后，就舍断了杀生"语义重叠，原文的收束语气丢失。
  - 建议：改为"这个恶业就这样被舍断了"／"这个恶业就这样被超越了"。同结构另见 `170-1785-181-186`、`170-1786-74-79`、`170-1786-80-85`，四处同步改。
- `170-1786-2-15`｜标点符号使用错误｜片段「‘世尊用许多方式谴责、呵斥不与而取」
  - 问题：巴利段首 `‘‘‘` 表示外层引语（佛陀对村长说）跨段重开、并叠加内层（弟子自思）。译文段首只有内层 ‘，外层 “ 未重开，与 1785 段首的 “ 失去接续，读者会以为佛陀的话已在 1785 段末结束。
  - 建议：段首改为「“‘世尊用许多方式……」，并确认整篇跨段引语只在最末一处收 ”。

### 🟦 suggestion

- `170-1784-2-20`｜语言风格不统一｜片段「这里有一位导师」
  - 问题：`Idha` 与 1785 段的 `Idha pana` 是对举的两种情形，后者译作"另一种情况是"，前者译作"这里"，句式不对称；且"这里"在汉语里首先读作空间义，容易被当成"此地"。
  - 建议：改为"村长，有一类导师持这样的主张、这样的见解——"，与 1785 的"另一种情况是"形成对照。
- `170-1784-2-20`｜该使用而没有使用术语标记｜片段「村长」
  - 问题：`gāmaṇi` 译名有分歧（村长／聚落主／首领），按 `knowledge/style.md` 第二节，有争议的术语首次出现宜夹注巴利原词。
  - 建议：首次出现作"村长（gāmaṇi）"，其后仍用"村长"。
- `170-1785-2-24`｜不常用术语编写注释｜片段「明行足、善逝、世间解、无上士调御丈夫、天人师」
  - 问题：十号为汉传固定译名，保留合理，但对无佛教背景的读者完全不透明，且与同列的"阿罗汉、正等正觉者、佛、世尊"在可读性上落差明显。
  - 建议：首次出现处加一条脚注串讲九／十号，或对最不透明的几项夹注巴利原词。
- `170-1785-109-127`｜语言风格不统一｜片段「我杀生这件事，不论多少」
  - 问题：与 `170-1786-27-44` 的平行句"我做过的不与而取，不论多少"句式不齐，同一套语两种说法。
  - 建议：统一为"我做过的杀生，不论多少"。
- `170-1785-109-127`｜语言表达不够流畅｜片段「那都不好，那都不善」
  - 问题：`na suṭṭhu` 与 `na sādhu` 两个近义否定在汉语里被译成"不好／不善"，区别度低，连读像重复凑字。
  - 建议：改为"那是不妥当的，那是不善的"，或径作"那不妥当，那不善"。
