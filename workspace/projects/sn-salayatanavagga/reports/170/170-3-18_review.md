# Review — 170:3-18（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 跨段一致性

- **经题**：§11 作「三、内无我经」，§17 作「六、外**处**无我经」，与 §13「外无常经」、§15「外苦经」不对称 → 建议统一为「六、外无我经」。依据：Bāhira- 在 §13、§15 均译「外」，不加「处」。
- **段首编号残留**：§18 句 170-18-2-13 开头多了「六、」。§10、§12、§14、§16 对应句都不带编号（编号已在经题里）→ 删去「六、」。
- **rūpā 等复数**：§18 作「各种色」「各种声……各种香……各种法」，§14、§16 作「色」「声……香……法」。nissaya 两处都标复数（`ရူပါ= တို့သည်`），但全 chunk 多数不译出复数 → 建议 §18 统一为「色是无我的」「声……香……味……触……法是无我的」。
- **phoṭṭhabba**：§14、§16 译「触」，§18 译「各种所触（phoṭṭhabba）」，而且在非首次出现时加了夹注 → 统一为「触」，不加夹注。
- **sammappaññāya / daṭṭhabbaṃ 句式**：§8–§16 作「就应当用正慧如实地这样观察它」，§18（170-18-14-31、170-18-43-61）作「对它就应当用正确的智慧如实地这样看待」→ 统一为前者。依据：出现 13 次对 2 次。nissaya `သမ္မပ္ပညာယ= ဝိပဿနာပညာ, မဂ်ပညာဖြင့်`、`ဒဋ္ဌဗ္ဗံ= ရှုမှတ်အပ်၏` 也支持「正慧」「观察」。
- **Evaṃ passaṃ … pe … 结句**：§10、§12、§14、§16 作「这样观察的时候……（中略）……他明白：‘此后不再有这样的存在。’”」；§18（170-18-62-73）作「他这样看的时候……乃至……他就明白：不再有这样的存在状态了。”」。三处不一致：pe 译成「乃至」而不是「（中略）」，passaṃ 译成「看」而不是「观察」，内层引号缺失 → 统一为前者（itthattāya 的改法见下文 170-8-155-173，统一后一并同步）。

## §7 句 170-7-14-22

- **问题**：处格义 — nissaya `သာဝတ္ထိယံ= သာဝတ္ထိပြည်အနီး၌`（在舍卫城**附近**），`အနာထပိဏ္ဍိကဿ= …၏`、`အာရာမေ= အရာမ်ဖြစ်သော` 表明祇园是「给孤独长者的园林」。译文「舍卫城的祇树给孤独园」中的「的」容易读成园在城内。
- **建议**：「有一次，世尊住在舍卫城附近的祇树给孤独园。」（次要项，可酌情处理。）

## §8 句 170-8-19-36（§8 其他同句、§10、§12、§14、§16 各同句同理）

- **问题**：主语取法 — nissaya 把 nesohamasmi 读作 `ဧသော= ဤစက္ခုပသာဒသည်။ အဟံ= ငါသည်။ န အသ္မိ= မဖြစ်။`，以「这（眼净色）」为主语，与前后两分句（etaṃ… / eso… attā）的主语一致。译文「我不是这个」改换了主语，三分句失去平行。
- **建议**：可改作「这不是我的，这不是我，这不是我的自我」，与 nissaya 的读法和三分句的平行结构对齐。asmi 是第一人称，「我不是这个」在语法上也说得通，所以这一条列为建议，不是必改项。

## §8 句 170-8-47-53 / 170-8-54-57 / 170-8-62-79

- **问题**：nissaya 对齐疑问（不涉译文）— pali 是 jivhā aniccā，nissaya 却是 `မနော= လောကီစိတ်သည်။`，其后两句 nissaya 也都以「心（စိတ်）」为主语。这一组 nissaya 单元实际对应 mano 一节（83 起），坐标错位。译文按 pali 译作「舌」，正确，不用改。
- **建议**：记入 known-issues 的数据问题，译文不动。

## §8 句 170-8-150-154（§14 句 170-14-111-115 同句须同步）

- **问题**：补出成分 / 性数 — nissaya 补出 `(မေ= ငါ၏။ စိတ္တံ= စိတ်သည်။)`，即「我的**心**已解脱」。vimuttaṃ 是中性单数，主语是 cittaṃ，不是「我」。译文「‘我已经解脱’」把主语换成了人。另外 `ဉာဏံ= ပစ္စဝေက္ခဏာဉာဏ်သည်` 表明这里的智是省察智；vimuttasmiṃ 是处格独立结构（「已解脱时」）。
- **建议**：「解脱了的时候，就生起‘心已经解脱’的智。」或只说「‘已经解脱了’」，不补主语。

## §8 句 170-8-155-173（§10、§12、§14、§16、§18 的结句须同步）

- **问题**：格与句法 — nissaya `ဣတ္ထတ္ထာယ= ဤတစ်ဆယ့်ခြောက်ချက် မဂ်ကိစ္စအလို့ငှာ`（为了这十六种道的作用，**为格**），`အပရံ= တပါးသောပြုဖွယ်သည်`（另外要做的事，**主格**），`နာတိ= မရှိ`（没有）。也就是说，aparaṃ 是「其他应作的事」，itthattāya 是目的为格。译文「此后不再有这样的存在」把 itthatta 理解为「这种存在状态」，aparaṃ 理解为「此后」，与 nissaya 的格位判读不同。
- **次要**：`ဝုသိတံ= ကျင့်သုံးအပ်ပြီ`（已经修行过了）。「已经圆满」可以接受，但「已经修成」更贴近 nissaya。
- **建议**：「……应该做的都已做完，为了这（道的作用），再也没有其他要做的了。」改动牵涉本 chunk 全部 6 处结句，revise 时须统一。

## §18 句 170-18-2-13

- **问题**：格式 / 一致性 — 段首残留编号「六、」；「各种色」与前文不统一（见跨段一致性）。nissaya `ရူပါ= တို့သည်။ အနတ္တာ= အတ္တမဟုတ်ကုန်` 词法无误。
- **建议**：「“比丘们，色是无我的。」
