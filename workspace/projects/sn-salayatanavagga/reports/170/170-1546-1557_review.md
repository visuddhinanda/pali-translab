# Review — 170:1546-1557（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分句有 nissaya，无 nissaya 的句子只在跨段一致性中涉及）

## 跨段一致性

本 chunk 的六部经句式完全平行，但 §1546–1551（漏、无明、爱）与 §1552–1557（暴流、取、有）明显是两种译法，需要统一。

- **段号格式**：§1547/1549/1551 用「321.」「322.」「323.」（阿拉伯数字加 ASCII 句点），§1553/1555/1557 用「三二四．」「三二五．」「三二六．」（汉字数字加全角句点）。
  - 建议统一为一种。推荐「321．」式：阿拉伯数字与原文段号一致，句点用全角，符合 `style.md` 第五节。
- **ariyo aṭṭhaṅgiko maggo**：§1547/1549/1551 译「八支圣道」，§1553/1555/1557 译「八正道」。
  - 建议统一为「八正道」，依据是 `term-glossary.jsonl`（aṭṭhaṅgika magga = 八正道，confirmed）。
  - 如果要保留 ariya 的「圣」，就全部改为「八支圣道」，并补登术语表。两种译法不要并存。
- **Atthi panāvuso … ti?（问有无）**：
  - 前三经：「可是朋友，有没有道、有没有行道，能够断除…呢？」
  - 后三经：「朋友，有没有道，有没有行道，能断除…呢？」
  - 两处不同：后三经丢了 pana 的「可是」；并列项分隔前用「、」后用「，」。
  - 建议统一为前三经的写法。
- **Atthi kho … ti.（答有）**：前三经「是有道、有行道，能够断除…的。」，后三经「有道、有行道，能断除…。」。建议统一为前者，kho 的肯定语气由「是…的」承担。
- **Katamo panāvuso …（问何者）**：前三经「那么朋友，…」，后三经「朋友，…」，后者漏了 pana。建议统一为「那么朋友，…」。
- **能够 / 能**：前三经「能够断除」，后三经「能断除」「能遍知」。建议统一为一种。
- **Bhaddako … bhaddikā paṭipadā**：前三经「这道很好，这行道很好」，后三经「这是好的道，这是好的行道」。建议统一为前者。
- **Alañca panāvuso sāriputta, appamādāya**：
  - 前三经：「这也足以让人不放逸了」。
  - 后三经：「这就足以让人精进不放逸了」。
  - 问题有两处：后三经凭空加了「精进」，原文没有对应词；ca 的「也」被改成「就」。
  - 建议统一为「朋友舍利弗，这也足以让人不放逸了。」
- **「X 有这 N 种」句式**：前三经「漏有这三种」「爱有这三种」以主题词开头，后三经「有这四种暴流」「有这四种取」「有这三种有」把主题词放到句末。
  - nissaya 的结构是 `အာသဝါ/ဩဃာ/ဥပါဒါနာနိ/ဘဝါ= တို့သည်`（主语）＋ `ဣမေ … = တို့တည်း`（表语）。
  - 建议统一为主语在前的写法，各句具体改法见下文。

## §1549 句 170-1549-31-59

- **问题**：词法/取义。nissaya 的释义是 `ဒုက္ခသမုဒယေ= ဒုက္ခ၏ ဖြစ်ကြောင်း သမုဒယသစ္စာ၌`，即「苦的生起之因」（集谛）。`ဖြစ်ကြောင်း` 指成因，不指苦生起这件事本身。译文「对苦生起的无知」读起来像是「苦正在生起时的无知」，因的意思没有出来。
- **建议**：改为「对苦的集起的无知」或「对苦的起因的无知」。其余三项（苦、苦息灭、通向苦息灭的行道）与 nissaya 的四谛结构对应无误。

## §1547 句 170-1547-59-73（同类见 §1549-60-75、§1551-57-72、§1553-58-73、§1555-57-72、§1557-57-72）

- **问题**：格与句法（建议项，非必改）。nissaya 的结构是：
  - `ဧတေသံ အာသဝါနံ= …တို့ကို`：宾格，「这些漏」是断除的对象。
  - `ပဟာနာယ= ငှါ`：目的格，「为了断除」。
  - `ပရိညာယ= …အကျိုးငှါ`：目的格，「为了遍知」。

  原文表达的是「为断除而设的道」，译文「能够断除」把目的改成了能力。意思大体不错，但句法角色有偏移。
- **建议**：可改为「有没有用来断除这些漏的道、行道呢？」或「…为了断除这些漏呢？」。
  - 要改就全 chunk 六部经同类句一起改，包括无 nissaya 的答句和总结句。
  - 不改则保持现状，但要先按上一节统一「能够 / 能」。

## §1557 句 170-1557-31-39

- **问题**：句法/可读性。nissaya 为 `ဘဝါ= တို့သည်`（主语）、`ဣမေ တယော= တို့တည်း`（表语），意为「诸有就是这三种」。译文「朋友，有这三种有」中，第一个「有」是动词、第二个是术语，读者很难分清，而且语序与前三经不一致。
- **建议**：改为「朋友，有分为这三种。」或「朋友，所说的有，有这三种。」，与「漏有这三种」的主语在前句式对齐。

## §1553 句 170-1553-31-38

- **问题**：句法与跨段一致。nissaya 为 `ဩဃာ= တို့သည်`（主语）、`ဣမေ စတ္တာရော= တို့တည်း`（表语）。译文「有这四种暴流」把主语放到了宾语位置。
- **建议**：改为「朋友，暴流有这四种。」

## §1555 句 170-1555-31-38

- **问题**：同上。nissaya 为 `ဥပါဒါနာနိ= ဥပါဒါန်တို့သည်`（主语，见上一行末尾）、`ဣမာနိ စတ္တာရိ= တို့တည်း`（表语）。
- **建议**：改为「朋友，取有这四种。」
