# Review — 170:500-556（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **vedanā**：§514/519/524/529/534/539 译「感受」，§544/549/554 译「受」 → 建议统一为「感受」。依据：出现次数更多，且动词 vedeti 在本 chunk 一律译「感受」，名词与动词同形，读者能看出两者的对应。
- **tañca ajjhosa tiṭṭhati 中的 taṃ**：§513/518/523/528/533/538/543/548/553 一律译「那个所缘」。nissaya 每段都指明了具体对象：§513 `တဉ္စ= ထိုရူပါရုံကိုလည်း`，§518 `ထိုသဒ္ဒါရုံကိုလည်း`，§523 `ထိုဂန္ဓာရုံကိုလည်း`，§533 `ထိုဖောဋ္ဌဗ္ဗာရုံကိုလည်း`，§538 `ထိုဓမ္မာရုံကိုလည်း`。→ 建议各段分别译为「那色／那声／那香／那味／那所触／那法」，并补出 ca（「也」）。
- **ajjhosa 的译法**：全部 9 处都译作「吞没（了）……」，误读，详见 §513 条。修正时 9 处要一起统一。
- **phassa 与「触」撞词**：§508 的「触」对应 phoṭṭhabba。§532 却把 phassa 也译「触」，并夹注（phassa），于是同一个「触」对应了两个巴利词。nissaya 说明这里的 phassa 指所触境：§534 `ဖဿသမ္ဘဝါ= ဖောဋ္ဌဗ္ဗာရုံလျှင်ဖြစ်ကြောင်း ရှိကုန်သော`。动词也不一致：phusati 在 §508 译「接触」，phussa 在 §532 译「触到」。→ 建议 §532 改为「接触到所触」，§534 改为「从所触生起的」。
- **巴利原词夹注的位置**：rūpa、sadda 在 §504、§505 已经出现，「色」「声」都没有夹注，到 §512、§517 才夹注（rūpa）（sadda）。gandha、rasa、dhamma 也是同样情况。→ 按 style.md「首次出现夹注」的规定，夹注应移到 §504–§509 的首次出现处，§512 以后去掉。
- **ettha**：§502、§510 都译「在这里」。nissaya 两处都有具体所指：§502 `ဧတ္ထ= ဤသင်၏အဆုံးအမကို တောင်းရာ၌`（就你请求教诫这件事），§510 `ဧတ္ထ(ဧတေသု)ဓမ္မေသု`（在这些法当中）。→ 两处分别按所指改译，详见各条。
- **§510 内部时态**：第一句「将只有……」，第二句「只有……」，同一组 bhavissati 前后译法不同。→ 统一，详见 §510 条。
- **paṭissato 与 sato**：§542/547/552 译「具念」（偏文言），§545/550/555 译「保持正念」。两词本身不同，可以有区别，但「具念」需要白话化，详见 §542 条。

## §502 句 170-502-2-14
- **问题**：句法／补出成分。ettha 被泛译成「在这里」。nissaya 的释义是 `ဧတ္ထ= ဤသင်၏အဆုံးအမကို တောင်းရာ၌`，即「在你请求教诫这件事上」，指的是下文「你这样年老还来求教」这件事。nissaya 还补出了主语 `(မယံ= ငါတို့သည်။)`，译文的「我们」已经体现。
- **建议**：「摩罗迦子，你这样来请求教诫，那现在我们对年轻的比丘们还能说什么呢！」

## §502 句 170-502-15-33
- **问题**：词义（存疑，供定稿参考）。nissaya 把 mahallako 释为 `အမျိုးစည်းစိမ်အားဖြင့် ကြီးမြတ်သော`，即「在门第、财富上尊大」，不是单纯指年纪。译文「年迈」与「年老、年高」意思重复。§503 同一串词沿用了同样的译法。
- **建议**：可以考虑把 mahallako 改译为「尊长」一类兼顾身份的词，§502 与 §503 同步修改。如果维持「年迈」，revise 时说明理由即可。

## §504–§509 句 170-504-2-26 / 170-505-2-20 / 170-506-2-20 / 170-507-2-20 / 170-508-2-20 / 170-509-2-22
- **问题**：时态。「na ca te hoti passeyyanti」在 nissaya 中作 `ပဿေယျတ္တိ= မြင်လို၏ဟူ၍။ န စ ဟောတိ= ဖြစ်လည်း မဖြစ်`，是现在时：「你心里也不会生起‘想要见’的念头」。译文「不曾起过」把它译成了过去完成，和前面「现在也不见」的现在时脱节。
- **建议**：改为「你心里也没有‘我想见它’的念头」，六段同步修改（见／听／嗅／尝／接触／识知）。

## §510 句 170-510-2-27
- **问题 1**：格与句法。nissaya 作 `ဧတ္ထ(ဧတေသု)ဓမ္မေသု= ဤတရားတို့တွင်`，ettha 等于 etesu，修饰 dhammesu，意思是「在这些……法当中」。译文把它拆成独立的「在这里」，再接「对于……诸法」，结构错了。
- **问题 2**：漏译主语。nissaya 作 `တေ= သင်သည်`（te = 你，主格）。译文本句完全没有「你」。
- **问题 3**：词法。diṭṭhe 等是处格独立结构：`ဒိဋ္ဌေ= …မြင်အပ်သည်ရှိသော်`（见到的时候）。diṭṭhamattaṃ 意为 `မြင်အပ်ကာမျှ`（仅仅是所见而已）。「将只有所见那么多」是翻译腔，意思也不清楚。
- **问题 4**：风格。「诸法」偏文言。
- **建议**：「摩罗迦子，在这些所见、所闻、所觉、所识的法当中，你在见的时候将只是见而已，闻的时候只是闻而已，觉的时候只是觉而已，识的时候只是识而已。」

## §510 句 170-510-28-52
- **问题**：与上一句同构，同样有「只有……那么多」的翻译腔，而且丢了 bhavissati 的将来时，与上一句不一致。
- **建议**：「摩罗迦子，当你在这些所见、所闻、所觉、所识的法当中，见的时候只是见而已……识的时候只是识而已；」，措辞与上一句统一。

## §510 句 170-510-53-60 / 170-510-61-68
- **问题**：格（具格所指）。nissaya 作 `တေန= ထိုရာဂ, ဒေါသ, မောဟဖြင့် (တပ်မက်ပြစ်မှား တွေဝေသည်)`，tena 指「那贪、瞋、痴」这些烦恼，不是指所见的对象。nissaya 脚注引作 `tena rāgena vā ratto, dosena vā duṭṭho, mohena vā mūḷho na bhavissati`。译文「因它」中的「它」只能回指前面的所见所闻，具格的所指被译错了。nissaya 还给了一个异释（`တနည်းကား… တေန= ထိုမြင်ခြင်း စသည်နှင့်စပ်သော ရာဂ, ဒေါသ, မောဟနှင့် တကွ`）：「不会与那系于见等的贪瞋痴相伴」。按体例，异释可入脚注。
- **建议**：「那么，摩罗迦子，你就不会被那贪所染、被那瞋所恼、被那痴所迷。」第二句相应改为「摩罗迦子，当你不被那贪、瞋、痴所染、所恼、所迷时；」。

## §510 句 170-510-69-77 / 170-510-78-85
- **问题**：风格（必改）。「系着于其中」中的「于」「其」是文言虚词。另外，nissaya 指明了 tattha 的所指：`တတ္ထ= ထိုဒိဋ္ဌသုတမုတဝိညာတအာရုံ၌`，即那所见、所闻、所觉、所识的境。nissaya 补出的 `ပဋိဗဒ္ဓေါ`（系缚）、`ပတိဋ္ဌိတော`（安立）与译文的「系着」相合。
- **建议**：「那么，摩罗迦子，你就不会系缚在那所见、所闻、所觉、所识上。」以及「摩罗迦子，当你不系缚在那上面时；」。

## §510 句 170-510-86-98
- **问题**：取义错误（必改）。nissaya 作 `ဥဘယန္တရေန= ပစ္စုပ္ပန် တမလွန် နှစ်ပါးစုံသောလောက၌`，意思是「在此世与他世两者」，不是「两者之间」。nissaya 在 §516 行的脚注里列举了「两者之间指色界」「指心心所」等别家解释，并注明 `တံ သဗ္ဗံ အဋ္ဌကထာသု နတ္ထိ`，明确否定了「之间」这一读法。译文「两者之间」正好采用了被否定的那个解。
- **建议**：「那么，摩罗迦子，你就不会在此世，不会在他世，也不会在这两处。」

## §510 句 170-510-99-104
- **问题**：小问题。esa-eva 的 eva，nissaya 作 `သာလျှင်`（唯独、正是），译文「就是」的强调力度不够。
- **建议**：「这正是苦的终结。」

## §513 / §518 / §523 / §528 / §533 / §538 句 170-513-2-15 / 170-518-2-8 / 170-523-2-8 / 170-528-2-8 / 170-533-2-8 / 170-538-2-8
- **问题 1**：词义误读（必改）。nissaya 作 `အဇ္ဈောသ= မျိုမတတ်စွဲလမ်း၍`，意为「（紧得）几乎像要吞下去那样地执着」，是比喻性的「执取、黏着」。译文「吞没了」把比喻当成了实义，而且主宾关系反了：「吞没」读起来像是所缘被他吞掉了，或者他被吞没了。
- **问题 2**：taṃ 的所指被泛化为「那个所缘」，ca 漏译，见跨段一致性一节。
- **问题 3**：风格。「……而住」是半文言句式。
- **建议**：§513 改为「他以贪染的心去感受，也紧紧执着着那色，停留在那里。」其余各段把「色」替换为声／香／味／所触／法。

## §514 / §519 / §524 / §529 / §534 / §539 句 170-514-2-10 / 170-519-2-11 / 170-524-2-10 / 170-529-2-10 / 170-534-2-10 / 170-539-2-10
- **问题**：风格（必改）。「便增长」中的「便」是 style.md 禁例表所列的文言虚词。§534 另有一个问题：「从触生起的」，nissaya 释为「以所触境为因」，见跨段一致性 phassa 条。
- **建议**：「他的种种感受就增长起来，都是从色生起的；」，各段同步修改，§534 改为「从所触生起的」。

## §516 / §521 / §526 / §531 / §536 / §541 句 170-516-2-8 / 170-521-2-8 / 170-526-2-8 / 170-531-2-8 / 170-536-2-8 / 170-541-2-8
- **问题**：格。nissaya 作 `အာစိနတော= ဆည်းပူးသောသူမှ`，是离格「离……」。§531 行脚注说明这是属格作离格用，与 ārā（远）构成远离句式。所以句意是「涅槃离这样的人很远」。译文「对……的人，涅槃被说是遥远的」把格关系弱化成了泛泛的「对于」。
- **建议**：「对这样积聚苦的人，人们说涅槃离他很远。」或者「这样积聚苦的人，被说是离涅槃很远。」

## §532 句 170-532-2-14
- **问题**：词法与术语。见跨段一致性 phassa 条。nissaya 作 `ဖဿံ= အတွေ့အထိကို။ ဖုဿ= တွေ့ထိ၍`。「触到触」既与 §508 撞词，读起来也别扭。
- **建议**：「接触到所触时，对可爱的相作意的人，念就失去了；」，夹注移到首次出现处。

## §542 / §547 / §552 句 170-542-2-12 / 170-547-2-12 / 170-552-2-13
- **问题**：句法与风格。nissaya 补出了关系结构：`(ယော ပုဂ္ဂလော)…ပဋိဿတော (ဟောတိ)… သော…န ရဇ္ဇတိ`，意为「凡是见色时保持着念的人，那个人就不贪着诸色」。译文的语序把条件和结果颠倒并列了。「具念」偏文言。
- **建议**：「看见色时保持着念的人，就不会贪着种种色；」，声、香两段同步修改。

## §543 / §548 / §553 句 170-543-2-8 / 170-548-2-8 / 170-553-2-8
- **问题**：与 §513 组相同。nissaya 作 `အဇ္ဈောသ= မျိုမတတ်စွဲလမ်း၍။ န တိဋ္ဌတိ= မတည်`。「不吞没」误读，「那个所缘」泛化，「而住」偏文言。
- **建议**：「他以离染的心去感受，也不执着那色而停留在那里。」声、香两段相应替换。

## §544 / §549 / §554 句 170-544-2-11 / 170-549-2-12 / 170-554-2-11
- **问题 1**：句法。yathā 在 nissaya 中作 `ယထာ= အကြင်သို့သော အခြင်းအရာအားဖြင့်`，意为「以那样的方式」，与下句的 evaṃ（`ဤသို့သောအခြင်းအရာအားဖြင့်`）前后呼应，表示方式。译文「当……时」把它译成了时间，呼应关系就丢了。
- **问题 2**：词义。sevato 译「习近」，既偏文言，意思也不对。nissaya 脚注说明这里是指领受、经历感受（`ဝေဒနာကို ခံစား`）。
- **问题 3**：cāpi。nissaya 脚注说明这里是让步语气：「即使看见了、即使领受了感受，（苦）也不增长」。译文「并且」既不是这种让步，也不是脚注里另一种「略去 ca/api 不译」的处理。
- **问题 4**：术语。vedanā 在这里译「受」，与 §514 组的「感受」不一致。
- **建议**：「他看见色，即使也领受着感受，却是以这样的方式——」，与 §545 的「他就这样……」相接。声、香两段同步修改。

## §545 / §550 / §555 句 170-545-2-9 / 170-550-2-9 / 170-555-2-9
- **问题**：补出成分与词义。nissaya 补出的主语是 `(ဝဋ်ဆင်းရဲ ကိလေသာဆင်းရဲသည်)`，即「轮回之苦与烦恼之苦」，译文的「苦和烦恼」大体相合。khīyati 的 nissaya 释义是 `ကုန်ခြင်းသို့ရောက်`（趋于消尽），译「灭尽」略重，可以接受。sato carati 的 nissaya 释义是 `သတိနှင့်ပြည့်စုံသည်ဖြစ်၍…ကျင့်`（具足念而修行），译文「生活」偏离了「修行」义。
- **建议**：「苦和烦恼就逐渐消尽，不再积聚；他就这样带着正念修行；」。

## §546 / §551 / §556 句 170-546-2-8 / 170-551-2-8 / 170-556-2-8
- **问题 1**：词义。nissaya 作 `အပစိနတော= ဖျက်ဆီးသောသူမှ`，apacinati 是「拆除、消减」。译文「不再积聚」只是「不积聚」，把这个主动消减的动作译弱了，而且和 §545 的「不积聚」（nopacīyati）撞词。
- **问题 2**：格。nissaya 的异释 `ဝါ= နှင့်` 表示「与……相近」，与 §516 组同理，应译出「离……近」。
- **建议**：「对这样消减苦的人，人们说涅槃离他很近。」，与 §516 组的「离他很远」对仗。

## nissaya 原文疑问（不改译文，仅记录）
- §528 nissaya 在 rasa 段写 `ဝါ= ထိုအနံ့ကိုလည်း`（那香），疑为从 §523 照抄的错误，应为味。
- §533 nissaya 写作 `ဝေဒေဟိ`，疑为 `ဝေဒေတိ` 之讹。
