## 理由

**资源缺失说明**：本次评估只拿到巴利原文与目标 channel 译文。**义注（aṭṭhakathā）与 nissaya 均未注入**——本段是复注（ṭīkā），其父层义注（《相应部注》对 Ejāsutta 的注释）本应作为释义标准，nissaya 本应作为词级基准，两者都不可得。因此准确性一项只能凭原文词法与复注内部体例判断，**信心指数因此显著压低（62）**。尤其是被解释词与父层逐字同译这条硬约束，在没有义注文本的情况下无法核验——下列一致性问题多为**疑点**而非确证，需补齐义注后复核。

**准确性**：整体词义处理稳妥。`ejā` 释为「摇动/动荡不定」、`pīḷana` 释为「逼迫」、`chindana` 释为「切割」，均与词根义相符。复注「被解释词 + 释词」的体例（`X-ṭṭhena` = `Y-ṭṭhena`，即用同义词替换）在译文中基本还原。扣分主要在两处：`anto dosanaṭṭhena` 的黑体范围与译文加粗范围不一致（详见 error 条），以及 `nikantana` 释为 `chindana` 时，译文把被解释词与释词都译成「割截/切割」而丢失了复注此处的辨析意图（`nikantana` 更近「切断、割舍」，复注正是用 `chindana` 来定其义，二者同译尚可接受，但「有割截的意思：就是有切割的意思」读起来近乎同义反复，对读者无信息增量）。

**风格**：现代书面汉语基调达成，无文言虚词、无文言句式，未见「此中／故为／彼等／是故」等禁例。标点为中文全角，未见 ASCII 引号。「有……的意思」的句式贯穿全段，符合复注释词体例。仅 `198-145-12-19` 的「因此他说」主语省略，读者不易知道「他」指义注作者，属指代不明确（warning）。

**一致性**：这是本段最弱的一环，扣分集中于三点。其一，被解释词的译名与其父层义注是否逐字相同**无法核验**（义注缺失），而 `ejā` 一词在译文中同时出现「动摇」（黑体术语，及经名「第一动摇经」）与「摇动」「动荡不定」三种处理，虽分属术语与释义两种位置，仍存在读者串不起来的风险。其二，两个经名 `maññitasamugghātasāruppasutta` 与 `maññitasamugghātasutta` 译为《妄想断除相称经》《妄想断除经》，夹注巴利原词只给了前者、后者未给，处理不对称。其三，冒号与逗号在「被解释词＋释义」的连接上不统一：`198-145-20-22` 用逗号，`198-145-23-29`／`30-33` 用冒号，`41-43` 又用逗号，同一体例三种标点。

## 问题清单

### 🟧 error

- `198-145-23-29`｜错译（修饰关系）｜片段「**有内里溃烂的意思**」
  - 问题：原文黑体只覆盖 `Anto dosanaṭṭhenā`，`anto`（内、内部）+ `dosana`（败坏、污损）。译文加粗部分作「内里溃烂」，但下半句自释为「在内心之中败坏」，同一个词在一句之内给了「溃烂」与「败坏」两个不同的汉译，且「溃烂」带有生理性色彩，超出 `dosana` 的语义范围（`dosa`/`dus-` 为败坏、污染，非化脓溃烂）。被解释词与释词在复注体例中应当彼此呼应，此处断裂。
  - 建议：被解释词与下文自释统一，如「**有内在败坏的意思**：就是在内心之中败坏的意思」；若义注确作「溃烂」义，则需依义注定夺并在全篇统一。**此条待义注补齐后复核**。

### 🟨 warning

- `198-145-12-19`｜代词指代不明确｜片段「因此他说」
  - 问题：「他」在复注语境中指义注作者（觉音），但译文未作任何提示，读者无从判断是佛陀、经文叙述者还是注释者。复注全篇首次出现该指代，尤其需要明确。
  - 建议：改为「因此注释者说」或「因此义注说」，与后续同类句式统一。

- `198-145-30-33`｜关键词语意不明确｜片段「**有割截的意思**：就是有切割的意思」
  - 问题：被解释词与释词译成近义的「割截」「切割」，整句成为同义反复，读者读不出复注在此作了什么解释。`nikantana` 侧重「割断、断除（渴爱等）」，`chindana` 是义注用来定其义的常用词。
  - 建议：拉开二者措辞，如「**有割断的意思**：就是有斩断的意思」，或在释词侧补出所断对象（若义注有据）。**依赖义注确认，暂不自行补足。**

- `198-145-20-22` / `198-145-23-29` / `198-145-30-33` / `198-145-41-43`｜标点符号使用错误｜片段「**有恼害的意思**，就是有逼迫的意思。」
  - 问题：同为「被解释词＋释义」体例，`20-22` 与 `41-43` 用逗号，`23-29` 与 `30-33` 用冒号，四句三种连接方式不统一。
  - 建议：全段统一为冒号（复注释词的标准连接），即「**有恼害的意思**：就是有逼迫的意思。」

- `198-145-41-43`｜关键词语意不明确｜片段「《妄想断除经》」
  - 问题：同段前一句 `198-145-34-40` 的经名给了夹注巴利原词（maññitasamugghātasāruppasutta），本句经名未给。两经名仅差 `sāruppa` 一词，极易被读者误认为同一部经，恰恰是最需要夹注区分的场合。
  - 建议：补夹注为「《妄想断除经》（maññitasamugghātasutta）」。

### 🟦 suggestion

- `198-145-6-11`｜语言风格不统一｜片段「它摇动，就是在六种所缘的相上动荡不定，所以叫做**动摇**。」
  - 问题：`ejā` 相关词在本段有「摇动」（动词 `ejati`）、「动荡不定」（`kampati`）、「动摇」（名词 `ejā`，亦即经名用词）三种译法。虽分属动词／释义／术语三个位置，但复注此处正是在建立三者的同源关系，译文的分化削弱了这层关联。另「它摇动」句首代词无先行词，突兀。
  - 建议：考虑「所谓动摇，就是在六种所缘的相上摇动、震颤，所以叫做**动摇**」，使词族关系显豁。

- `198-145-34-40`｜语言表达不够流畅｜片段「**前面已经讲过的内容**：就是前面在《妄想断除相称经》（maññitasamugghātasāruppasutta）里已经出现过的内容」
  - 问题：「前面」「已经」「内容」在一句内各出现两次，冗赘。
  - 建议：「**前面已经讲过的**：就是在前面《妄想断除相称经》（maññitasamugghātasāruppasutta）里出现过的。」

- `198-144-4-4` / `198-146-2-4`｜该使用而没有使用术语标记｜片段「第一动摇经等的注释」
  - 问题：章题与结语中的经名「第一动摇经」未加书名号，而正文 `198-145-34-40`、`41-43` 的经名用了《》，同一文档内经名标记不一致。
  - 建议：统一为「《第一动摇经》等的注释」。
