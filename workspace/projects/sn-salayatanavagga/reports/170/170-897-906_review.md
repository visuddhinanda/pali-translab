# Review — 170:897-906（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分句有 nissaya，无 nissaya 的句子不单独出意见）

## 跨段一致性

- **Taṃ / Sā / So / Te vo pahīnaṃ hitāya sukhāya bhavissati**：§900、§902 共十余处，都译成「把它舍弃了，将会给你们带来利益与安乐」，把 `vo` 当成受益者（与格）。nissaya 把 `vo` 释为施事主格：`ဝေါ= သင်တို့သည်`，`pahīnaṃ` 释为条件分句：`ပယ်အပ်သည်ရှိသော်`（被舍弃时）。建议全部统一改为「你们舍弃了它，就会带来利益与安乐」，复数句改为「你们舍弃了它们，……」。§900-17-23 的意见见下文。
- **aniccasambhūtaṃ / dukkhasambhūtaṃ**：§904 译为定语结构「由无常的因缘所生的眼」，§906 译为主谓结构「眼由苦所生」，两段句式不一致。nissaya 两处都作定语：`ဒုက္ခကြောင့်ဖြစ်သော`（因苦而生的）。建议 §906 统一为「由苦的因缘所生的眼／舌／意」。
- **yopi hetu yopi paccayo … uppādāya, sopi …**：§904 译「眼生起的因，以及眼生起的缘，也是无常的」，§906 拆成两句「使眼生起的因，也是苦；使眼生起的缘，也是苦」。两经句式完全相同，译法应该统一。nissaya 把因与缘并列为一个主语，再用 `သောပိ= ထိုအကြောင်းသည်လည်း` 合指，`uppādāya= ဖြစ်ခြင်းငှါ`（为了生起）。建议两段都统一为「使眼生起的因与缘，也是无常的／也是苦」。
- **evaṃ passaṃ**：§904 译「这样看的时候」，§906 译「这样观察时」，建议统一。
- **khīṇā jāti**：§904 译「我生已尽」，§906 译「生已尽」。原文没有「我」，建议统一为「生已尽」。
- **句末标点**：§904-77-85 原文用 `!`，译文用「？」；§906-73-81 同样的句式译文用「！」。建议统一。

## §900 句 170-900-17-23

- **问题**：格与句法。`vo` 被译成受益者「给你们」。nissaya：`ဝေါ= သင်တို့သည်`（你们，施事主格），`ပဟီနံ= ပယ်အပ်သည်ရှိသော်`（被舍弃时），`ဟိတာယ= အစီးအပွါးအလို့ငှါ`（为了利益）。句意是「它被你们舍弃时，将会带来利益与安乐」，舍弃的施事者是「你们」。
- **建议**：改为「你们舍弃了它，就会带来利益与安乐」。本段及 §902 的同型句一并改，见跨段一致性。

## §904 句 170-904-14-24

- **问题**：句法。`cakkhussa uppādāya` 的 nissaya 是 `စက္ခုပသာဒ၏ ဖြစ်ခြင်းငှါ`（为了眼的生起），表示目的或作用。「眼生起的因」读起来像「眼在生起时的因」，没有把「使眼生起」的意思译出来。
- **建议**：改为「使眼生起的因与缘，也是无常的」，与 §906 统一。

## §906 句 170-906-14-23

- **问题**：句法。nissaya 中 `ယောပိ ဟေတု= သည်၎င်း။ ယောပိ ပစ္စယော= သည်၎င်း။ … သောပိ= သည်လည်း။` 是两个主语并列后用 `sopi` 合指一次。译文拆成两个分句、重复两次谓语，结构与原文不符。
- **建议**：改为「使眼生起的因与缘，也是苦」。§906-38-48 和 §906-63-72 同样处理。

## §906 句 170-906-24-37

- **问题**：句法。nissaya `ဒုက္ခသမ္ဘူတံ= ဒုက္ခကြောင့်ဖြစ်သော`（因苦而生的）是修饰 `cakkhu` 的定语。译文「眼由苦所生，怎么会是乐呢」把它变成了谓语，使得反问句的主语不清楚，也和 §904 的句式不一致。
- **建议**：改为「比丘们，由苦的因缘所生的眼，怎么会是乐的呢……乃至……舌是苦。」§906-49-62 和 §906-73-81 同样处理。
