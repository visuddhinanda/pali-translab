## 理由

**资源缺失说明**：本次评估**未取到义注（aṭṭhakathā）与 nissaya**——注入数据中只有巴利原文与目标 channel 译文两项。因此「义理或用词与注释书不符」「词级格位核对」两条基准无法执行，下列判断全部基于巴利原文本身的词法句法、平行经文（SN 36.3 / AN 与《相应部》受相应同套偈颂）及通行传统释义。信心指数据此从 90 下调至 72，其中偈颂部分（1269–1278）的把握明显低于长行部分。

**准确性（84）**：长行（1268）三受、三随眠、断随眠的对应关系准确，`Yato ... ayaṃ vuccati` 的从句结构处理正确。主要扣分集中在 1268 末尾的经典定型句与两处偈颂：

1. `acchecchi taṇhaṃ` 译作「彻底断尽了一切渴爱」，原文无「一切」（sabbaṃ）——属增译；`acchecchi`（chindati 的不定过去式）已含「断尽」义，「彻底」尚可视为语气补偿，「一切」则无据。
2. `vivattayi saṃyojanaṃ` 译「连根拔除了结缚」：`vivaṭṭeti` 义为「翻转、卷回、解开」，定型句传统作「解开了结缚」；「连根拔除」是 `samūlaṃ ubbhāsi` 一类表达的译法，用在此处属加重。
3. `sammā mānābhisamayā` 译「由于如理现观我慢」：`abhisamaya` 在此定型句中是「彻底看穿而灭尽」（现观→止息）之义，传统读作「由于正确地看破我慢（而灭除之）」。「如理现观」尚可，但接续的「而作尽了苦的边际」措辞有误，见下。
4. `antamakāsi dukkhassa` 译「作尽了苦的边际」：定型义为「作了苦的终结」。「作尽……边际」既不合汉语搭配，也把 `antaṃ akāsi`（作出终点）读成了「穷尽边际」。
5. `sammaddaso` 译「是如实正见的人」——`sammā-dassāvin` 为「正确地见者／具正见者」，「如实」（yathābhūta）系另词，属轻度增译，未单列。
6. 1273–1274 两颂跨句衔接有实质问题：`Adukkhamasukhaṃ santaṃ, bhūripaññena desitaṃ; Tañcāpi abhinandati, neva dukkhā pamuccati.` 通行读法是「广慧者开示不苦不乐受为寂静（santaṃ 作补语）；若他连这个也欢喜，仍不解脱于苦」。译文把 `santaṃ` 处理成定语「那寂静的不苦不乐受」，丢掉了「被开示为寂静」这一谓述关系，也使「他」在 1274 句首无先行词。
7. 1277 `diṭṭhe dhamme anāsavo` 译「在现法中成为无漏者」准确；夹注「（anāsava）」用了词干形而非原文形 `anāsavo`，属体例小瑕，未单列。
8. 1278 `saṅkhyaṃ nopeti` 译「不再被施设」方向正确（不落入名数／不可计量），但「被施设」偏术语化且无夹注，普通读者难解；`vedagū` 译「通达者」可接受。

**风格符合度（90）**：整体为现代书面汉语，无文言禁例表所列句式，标点全角、引号用弯引号 “‘’”，未出现 ASCII 引号，符合 JSON 安全硬约束。译文中无候选、待定等残留工作标记。扣分项为「作尽了苦的边际」「不再被施设」两处生硬表达，以及 1269/1271 用「如果」译属格独立结构 `vedayamānassa ... appajānato`，使偈颂读来像条件推理句，原文实为「对于正在感受乐而不了知此受的人，（在他那里）有贪随眠」。

**一致性（92）**：三受、三随眠术语前后统一；1270 与 1272 平行句式处理一致（`anissaraṇadassino` 两处同译「因为他看不见出离」，属格因由的补出前后一致，可取）。1268 长行「贪随眠／瞋随眠／无明随眠」与偈颂部分一致。唯一不一致处：1270 有「他就有贪随眠」，1272 作「他就有瞋随眠」——原文 1270 有 `So`、1272 无，译文补出一致，无碍；但 1277「他遍知了这一切感受」中的「这一切」与 1276「一切感受」指涉重复，属衔接冗余。

## 问题清单

### 🟧 error

- `170-1268-45-107`｜错误多译｜片段「彻底断尽了一切渴爱」
  - 问题：`acchecchi taṇhaṃ` 中无 `sabbaṃ`／「一切」的对应词，属增译。
  - 建议：改为「断尽了渴爱」或「斩断了渴爱」。

- `170-1268-45-107`｜错译（词义）｜片段「连根拔除了结缚」
  - 问题：`vivattayi saṃyojanaṃ` 的 `vivaṭṭeti` 为「翻转、解开、卷回」，定型句作「解开了结缚」；「连根拔除」对应的是另一类表达，此处加重了原文。
  - 建议：改为「解开了结缚」。

- `170-1268-45-107`｜导致误解的表达｜片段「而作尽了苦的边际」
  - 问题：`antamakāsi dukkhassa` 是「作了苦的终结」，译文读成「穷尽苦的边际」，既误解结构（`antaṃ akāsi` = 作出终点），汉语搭配也不成立。
  - 建议：改为「终结了苦」或「作成了苦的终结」。

- `170-1273-2-9` / `170-1274-2-8`｜错译（修饰关系）｜片段「广慧者开示了那寂静的不苦不乐受；」
  - 问题：`Adukkhamasukhaṃ santaṃ, bhūripaññena desitaṃ` 中 `santaṃ` 通行读作谓述补语——「广慧者开示不苦不乐受为寂静」，而非定语「那寂静的不苦不乐受」。定语化处理丢失「被宣说为寂静」的意味，也使下句 1274「他若仍然欢喜它」的「他」失去先行词。
  - 建议：1273 改为「不苦不乐受被广慧者开示为寂静；」，1274 相应改为「若有人连它也欢喜，就依然不能从苦中解脱。」

### 🟨 warning

- `170-1268-45-107`｜关键词语意不明确｜片段「是如实正见的人」
  - 问题：`sammaddaso` = 「正确地见者」，「如实」对应 `yathābhūta`，原文无此词；且「如实正见的人」在此定型句中易与「正见（sammādiṭṭhi）」混淆。
  - 建议：改为「是正确地看见的人」或「具正见者」。

- `170-1268-45-107`｜关键词语意不明确｜片段「由于如理现观我慢」
  - 问题：`sammā mānābhisamayā` 中 `abhisamaya` 在此定型句指「看穿而灭尽」，译「现观」虽为传统对译，但单独出现且无注，读者难以理解「现观我慢」如何导致苦的终结。
  - 建议：保留术语但补注，或改为「由于彻底看破我慢（mānābhisamaya）」。

- `170-1278-2-12`｜关键词语意不明确｜片段「不再被施设」
  - 问题：`saṅkhyaṃ nopeti` 指「不落入计量／名数」，译「被施设」属论书术语借用，未加注，一般读者无法理解，且与「施设（paññatti）」一词所指不同。
  - 建议：改为「不再落入任何计量」，或保留现译并夹注 `saṅkhyaṃ nopeti`。

- `170-1269-2-18` / `170-1271-2-9`｜整句逻辑表达不规范｜片段「正在感受乐的人，如果不了知这感受，」
  - 问题：原文 `Sukhaṃ vedayamānassa, vedanaṃ appajānato` 为两个并列属格分词，描述同一主体的状态（「对于正在感受乐、而不了知此受的人」），并非条件从句。译作「如果」把偈颂改写成条件推理，也与下句「他就有贪随眠」构成因果链，语气强于原文。1271 同此。
  - 建议：改为「正在感受乐、却不了知这感受的人，」；1271 作相应处理。

### 🟦 suggestion

- `170-1277-2-11`｜语言表达不够流畅｜片段「他遍知了这一切感受」

  - 建议：改为「他遍知了诸受」或「他既已遍知这些感受」。

- `170-1277-2-11`｜该使用而没有使用术语标记｜片段「无漏者（anāsava）」
  - 问题：夹注用词干形 `anāsava`，与原文实际词形 `anāsavo` 不一致；本项目体例未明确规定夹注取词干还是取原形，建议统一。
  - 建议：全书统一取词干形（现译做法）并在 `knowledge/terms.md` 记一条，或改注 `anāsavo`。

- `170-1278-2-12`｜不常用术语编写注释或者百科｜片段「这位安住于法的通达者」
  - 问题：`vedagū`（明达者／到达吠陀[真知]者）为偈颂罕见术语，译「通达者」可接受但未附原词，读者无从查考。
  - 建议：首次出现处夹注「通达者（vedagū）」。
