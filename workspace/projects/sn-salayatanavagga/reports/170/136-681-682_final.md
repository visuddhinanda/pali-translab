## 理由

**准确性**：七句均无主谓宾判断错误、无漏译、无教理性错误。关键处核对如下：
- `2-15` `sandhāya etaṃ vuttaṃ` 的「就……而说」关系译准，`yeva` 的限定义用「正是」承接，`niccanimittādīni pahāya pavattaṃ` 的「舍弃常相等之后……的毗婆舍那定」修饰关系正确。
- `16-28` 原文是两重绝对结构（属格 `viharato` + 处格 `vahamāne`），无主句；译文把两重条件都译出，但自行补了一个主句（见问题清单）。
- `29-71` 属格绝对句「对于砍树而时时去看斧刃的人，砍伐的事不成」与 `evaṃ` 对句的对应译准，`nikanti` 首见夹注巴利原词，合 `style.md` 第二节。
- `89-106` `animittaṃ … cetosamādhiṃ` 与 `nibbānārammaṇaṃ uparimaggaphalasamādhiṃ` 两个同格宾语，译文用「以及」按**两项**处理。此处原文无连词，理论上也可作同位语读；但至出起观相应之定与道果定分属不同心，同位读会自相矛盾，故「两项」是更有据的取法，不扣分，在此备案。

**风格**：主要失分在语体。「便」（`16-28`、`77-88` 各一处）属 `style.md` 第一节禁例表中明列的文言虚词，应作「就」；「转起」是方法文档点名的二意词，未作处理。「斧头运转得好」为巴利动词 `vahati` 的直译残留，汉语不自然。标点、引号全为全角，`zh` 字段内无 ASCII 引号，符合 JSON 安全硬约束。

**一致性**：「毗婆舍那」首见夹注、其后单用，全段统一；「识便随着相而转」作为被释词在 `16-28` 与 `77-88` 两处逐字一致，符合被解释词同译要求（该译法本身的「便」字问题另计）。`89-106` 引文与释义的人称处理不一致。

**基准缺失**：本次为义注层自身的评估，上下文未注入该段 nissaya，也无复注可作词级对照，词法判断仅依巴利原文与义注内部逻辑，信心指数据此下调。

## 问题清单

### 🟨 warning
- `136-682-16-28`｜文言语体｜片段「识便随着相而转」
  - 问题：「便」是禁例表中的文言虚词（便＝于是/就）。
  - 建议：改为「识就随着相而转」；该译法是被释词，须与 `77-88` 同步改。
- `136-682-77-88`｜文言语体｜片段「识便随着相而转」
  - 问题：同上，被释词引文中的「便」。
  - 建议：与 `16-28` 一并改为「识就随着相而转」。
- `136-682-2-15`｜关键词语意不明确｜片段「转起的毗婆舍那（vipassanā）定」
  - 问题：「转起」是方法文档明列的二意词，普通读者难以确定指「开始生起」还是「持续进行」。此处 `pavattaṃ` 指舍弃常相等之后所生起并持续的观定。
  - 建议：改为「生起并持续的毗婆舍那（vipassanā）定」。
- `136-682-16-28`｜整句逻辑表达不规范｜片段「的时候，识便随着相而转」
  - 问题：本句巴利只有两重绝对结构（`viharato` / `vahamāne`），主句要到后文的譬喻与 `taṃ sandhāya vuttaṃ` 才收束；译文自行补出主句，等于把被释词原样搬进释义，句内重复一次，也提前给出了原文尚未给出的结论。
  - 建议：保留条件句的未完形态，如「意思是：在他这样以毗婆舍那定安住、毗婆舍那智变得敏锐有力地运转的时候——」，把收束交给 `77-88`。

### 🟦 suggestion
- `136-682-29-71`｜语言表达不够流畅｜片段「我的斧头真是运转得好啊」
  - 问题：`vahati` 用于斧头时指「好使、下得快」，「运转」是直译残留，汉语不自然。
  - 建议：「我这把斧头可真好使啊」；与下句「智……运转」的呼应可靠「真得力」一类词保留。
- `136-682-29-71`｜语言表达不够流畅｜片段「我的智真是变得有力，运转得好啊」
  - 问题：`sūraṃ hutvā … vahati` 只有「变得有力地运转」，「得好」是从上句 `suṭṭhu` 挪来的赘语，读来拖沓。
  - 建议：「我的智真是变得有力，运转得快啊」或「……真是运转得有力啊」。
