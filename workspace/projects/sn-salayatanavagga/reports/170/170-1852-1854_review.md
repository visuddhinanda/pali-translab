# Review — 170:1852-1854（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1853-2-49、1854 段除 55-112 以外的各句没有 nissaya，这些句子不单独出意见，只参与跨段一致性核对）

## 跨段一致性

§1853 和 §1854 前半部分的巴利原文几乎逐字相同，只有邪见句和正见句的 natthi／atthi 对调。两段译文本应只在肯定、否定上不同，现在却在很多处出现了不同译法，下面全部列为**必改项**。

- **abhijjhā / vigatābhijjho**：§1852、§1853 译“贪婪”，§1854 译“贪欲” → 建议统一为“贪婪”（三处里有两处这样译）。
- **byāpāda**：§1852、§1853 写作“嗔恚”，§1854 写作“瞋恚” → 用字要统一，建议都写“瞋恚”，或都写“嗔恚”，全书只用一种。
- **asammūḷho**：§1853 译“不迷乱”，§1854 译“没有迷惑” → 建议统一为“不迷乱”。
- **mettāsahagatena cetasā**：§1853 译“以与慈俱行的心”，§1854 译“怀着与慈俱的心” → 建议统一为“怀着与慈俱行的心”。“以”在这里是文言的具格用法，应当改成现代汉语。
- **ekaṃ disaṃ / dutiyaṃ…**：§1853 译“一方／第二方”，§1854 译“一个方向／第二个方向” → 二选一，建议用“一方……第二方……”，句式要整句对齐。
- **vipulena mahaggatena**：§1853 译“广大的、博大的”，§1854 译“宽广的、广大的”。两段里“广大”分别对应 vipula 和 mahaggata，对应关系是错开的 → 建议统一为 vipula=“广大”、mahaggata=“博大”。
- **tiriyaṃ / sabbadhi**：§1853 译“四方／一切处”，§1854 译“四周／一切地方” → 建议统一为“四方／一切处”。
- **natthi dinnaṃ … natthi mātā, natthi pitā**（§1853）和 **atthi dinnaṃ … atthi mātā, atthi pitā**（§1854）：
  - dinnaṃ / yiṭṭhaṃ / hutaṃ 两段都按“（布施等）有／没有果报”译，体例一致；
  - mātā / pitā 不一致：§1853 译“孝敬母亲没有果报”，§1854 却直译成“有母亲，有父亲”。两段正反相对，体例必须相同。nissaya 只给出 `နတ္ထီတိ= မရှိ`（不存在），没有说明是哪一种解读，所以先选定一种体例，两段一起套用。
- **ayaṃ loko / paro loko**：§1853 译“今世／来世”，§1854 译“这个世间／另一个世间” → 建议统一为“今世／来世”（§1853 后面 `ဧတ္ထ= ဤပစ္စုပ္ပန်တမလွန်ဘဝ၌`（现世与来世）的用法与此一致）。
- **sammaggatā sammāpaṭipannā**：§1853 译“走上正道、走对了路的”，§1854 译“正行的、如实修行的” → 选一种用于两段。
- **sayaṃ abhiññā sacchikatvā pavedenti**：§1853 译“凭自己的证智亲证……并宣说出来”，§1854 译“亲自以证智证知了……之后向人宣说” → 统一，并去掉§1854 里的“以”。
- **yvāyaṃ satthā**：§1853 译“那位导师”，§1854 译“这位导师” → 统一。
- **sace tassa bhoto satthuno**：§1853 译“就算那位可敬的导师”，§1854 译“如果这位尊敬的导师” → nissaya 作 `သစေ ဟောတိ= အံ့`（如果），建议两段都用“如果”，“可敬／尊敬”也统一。
- **apaṇṇakatāya mayhaṃ**：§1853 译“我这条路对我来说也是万无一失、没有过失的”，§1854 译“我这样做对我来说也是没有差失、没有过失的” → nissaya 补出了 `အယံ ပဋိပဒါ= ဤအကျင့်`（这种修行），两段都应补出“这种修行”，后面的谓语也要统一。
- **byābādhemi**：§1853 译“恼害”，§1854 译“伤害” → 统一为“恼害”。
- **ubhayamettha kaṭaggāho**：§1853 译“在这里我两方面都是得胜的”，§1854 译“在这件事上，两方面我都是得胜的” → 统一（具体改法见下文 §1853 句 151-199）。
- **kāyena / vācāya / manasā saṃvuto**：§1853 译“身有防护、语有防护、心有防护”，§1854 译“在身体上有防护、在言语上有防护、在心意上有防护” → 统一。
- **kāyassa bhedā**：§1853 译“身体败坏”，§1854 译“身体崩坏” → 统一。
- **tassa pāmojjaṃ jāyati**：§1853 加了“于是”，§1854 没有 → 统一（原文没有连接词，建议两处都不加）。
- **pamuditassa / sukhino**：§1853 译“心怀欢悦的人／有快乐的人”，§1854 译“欢悦的人／快乐的人” → 统一。
- **pajaheyyāsi / imaṃ kaṅkhādhammaṃ**：§1852、§1853 译“舍弃这种疑惑”，§1854 译“舍断这个疑惑” → 统一为“舍弃这种疑惑”。

## §1852 句 170-1852-10-15
- **问题**：补出成分。nissaya 补出了 `(ဌိတော= တည်သော)`（住立于），并写明 `တတြ= ထို ဓမ္မသမာဓိ၌`。“在这法等持中”在汉语里读起来像是指获得的地点，没有译出“立足于法等持”这一层。
- **建议**：改为“如果你立足于这法等持，获得了心等持（cittasamādhi）”。§1853 句 228-239、§1854 句 185-196 同样处理。

## §1853 句 170-1853-111-150
- **问题 1**：补出成分。nissaya 补出了主语 `အယံ ပဋိပဒါ= ဤအကျင့်သည်`（这种修行），以及谓语 `(သံဝတ္တတိ)`（导向）。译文的“我这条路”接近这个意思，但不准确。
- **建议**：改为“……那么我的这种修行也是万无一失、没有过失的”。
- **问题 2**：连词误读。`သစေ … အံ့` 是条件“如果”，译文写成“就算”，变成了让步关系。
- **建议**：改为“如果”。
- **问题 3**：时态。byābādhemi 是现在时，nissaya 作 `မညှဉ်းဆဲ`（不恼害）。“不曾”是过去义。
- **建议**：改为“我不恼害任何人”。nissaya 对 kiñci 的释义是 `တစုံတယောက်သောသူကို`（任何人），译“任何众生”也可以接受。
- **问题 4**：异释。nissaya 给 tasaṃ／thāvaraṃ 列了异释 `ဝါ= တဏှာနှင့်တကွ`／`တဏှာမရှိ`（有渴爱的／无渴爱的）。
- **建议**：正文保留“会走动的／不会走动的”，异释按 style.md 作脚注备列。

## §1853 句 170-1853-151-199
- **问题**：取义不足。nissaya 给 ettha 的释义是 `ဤပစ္စုပ္ပန်တမလွန်ဘဝ၌`（在这现世与来世中），给 ubhayaṃ 的释义是 `(ဥဘယသ္မိံ)= နှစ်ပါးစုံသော`。nissaya 注 4 还根据 MN 2.95 和复注主张这里应读作 ubhayattha kaṭaggāho（在今生、来世两方面都得胜）。译文的“在这里”太虚，没有把“今生与来世”译出来。
- **建议**：改为“无论今生还是来世，两方面我都是得胜的”。§1854 句 134-157 照此统一。

## §1853 句 170-1853-208-211
- **问题**：所指译窄了。nissaya 给 kāyo 的释义是 `နာမကာယ ရူပကာယသည်`（名身与色身），“身体”只对应色身。
- **建议**：改为“身变得轻安”，或“身心变得轻安”。§1854 句 166-169 同改。

## §1853 句 170-1853-212-215
- **问题**：问题同上。nissaya 给 passaddhakāyo 的释义是 `ငြိမ်းပြီးသောနာမကာယ ရူပကာယရှိသော`（名身、色身已经平息的人），给 sukhaṃ 的释义是 `ကိုယ်၏ ချမ်းသာခြင်း စိတ်၏ချမ်းသာခြင်း`（身乐与心乐）。
- **建议**：把“身体轻安的人”改为“身已轻安的人”。§1854 句 170-173 同改。

## §1853 句 170-1853-54-110
- **问题**：语体与体例。具体见“跨段一致性”一节中 mātā / pitā、ayaṃ loko / paro loko、sammaggatā 各条。本句是这几处不一致的源头，改动时以本句和 §1854 句 55-112 成对修改。
- **建议**：选定一种体例后，两段同时修改。

**结果**：本 chunk（book 170，§1852–1854，Pāṭaliya 经）审完。按 nissaya 有 7 处句级意见，跨段不一致有 21 条，全部列为必改项。

- **跨段不一致最集中**：§1853 和 §1854 原文几乎相同，只是 natthi／atthi 对调，但两段的译法在很多地方各不相同。最严重的有两处：一是 vipula／mahaggata 都译出了“广大”，但分别对应两个不同的词；二是 mātā／pitā 一段按“孝敬……没有果报”解读，另一段却直译。
- **句级问题**：一处把 sace 的“如果”误作“就算”；kāyo 被译窄成“身体”，nissaya 释义是名身与色身；nissaya 补出的“立足于法等持”和“这种修行”在译文里没有译出来。
- **没有出意见的句子**：没有 nissaya 的句子按要求略过，只用来核对跨段一致性。
