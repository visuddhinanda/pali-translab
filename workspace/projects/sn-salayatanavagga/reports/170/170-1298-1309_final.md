**风格符合度（84）**：**无文言腔**——通篇未见「此中／故为／彼等／是故／于…之际」一类禁例，单音节文言虚词也没有，这一项合格。扣分在偈颂（1299–1309）：为了贴合逐句坐标，1299/1300 出现「不像凡夫那样去领受」「也不那样领受」的回指式凑句，1303/1304 连续两个「对于…的人」悬垂而无主句落点，读起来是切碎的半句，不是诗行。另有法相术语（随眠、出离、乐味、过患）首次出现均未按 `style.md` 第三节夹注巴利原词。

## 问题清单

### 🟨 warning

- `170-1298-13-19`｜整句逻辑表达不规范｜片段「接着没有用第二支箭随着前一箭再射他」
  - 问题：`na vijjheyya` 是愿望式（optative），与上句 `vijjheyya`「就好比有人用箭射中」同属假设情境；译成「没有用」变为对已发生事件的陈述，与前句的假设语气断裂，读者会误以为在叙述实事。
  - 建议：改为假设语气的否定，如「而不再用第二支箭随着前一箭射他」。

- `170-1298-79-91`｜不导致误解的汉语语病｜片段「便不会随之增长潜伏」
  - 问题：`anuseti` 的两种传统译（「随增」与「潜伏」）被并置成「随之增长潜伏」，动词叠加后搭配不成立——「不会增长」与「不会潜伏」是两件事，连写读不通。
  - 建议：择一固定，如「便不会潜伏随增」或直接「便不会随增」，并在全篇统一。

- `170-1298-118-128`｜不导致误解的汉语语病｜片段「便不会随之增长潜伏」
  - 问题：同上，同一拗口结构第二次出现。
  - 建议：与 `170-1298-79-91` 采用同一译法。

- `170-1298-141-159`｜不导致误解的汉语语病｜片段「便不会随之增长潜伏」
  - 问题：同上，第三次出现；三处重复使该译法成为全段的稳定缺陷。
  - 建议：三处一并统一。

- `170-1298-186-211`｜语言风格不统一｜片段「不被生、老、死、忧愁、悲叹、苦、忧、恼所系缚，不与苦系缚在一起」
  - 问题：同一个 `visaññutto` 在本句内用了「不被…所系缚」和「不与…系缚在一起」两种译法，而前三句（160-168 / 169-177 / 178-185）用的是第三种「不在系缚中」。同一词三译并存。
  - 建议：统一为一种，如全部作「离系」或全部作「不被…系缚」。

- `170-1298-212-231`｜关键词语意不明确｜片段「这就是特异之处」
  - 问题：`adhippayāsa` 译作「特异之处」，与同句的「差别」「不同」语义几乎重合，读者无法分辨三者区别；且「特异之处」本身语意含糊。（缺义注，无法确认此处传统取义是「殊胜」还是「特别的用力」，取义待义注定案。）
  - 建议：三词分别译出层次，如「差别／殊胜／不同」，或在译文外的报告中标注分歧，暂取一义并压低该句 confidence。

- `170-1298-2-12` / `170-1299-2-8` / `170-1303-2-7` 与 `170-1298-212-231`｜标点符号使用错误｜片段「比丘们，就好比有人用箭射中一个人。」与「这就是不同。”」
  - 问题：原文的成对引号 `‘‘ … ’’` 在三处段首均未译出左引号，而 `170-1298-212-231` 句末保留了右引号 `”`，全篇引号不配对，出现孤立的收尾引号。
  - 建议：或在 `170-1298-2-12`、`170-1299-2-8`、`170-1303-2-7` 补出左引号「“」使之配对，或统一省略引号、删去 `170-1298-212-231` 末尾的 `”`。

- `170-1303-2-7`｜整句逻辑表达不规范｜片段「对于已了知并审度诸法、博学多闻的人，」
  - 问题：与下一句 `170-1304-2-14`「对于观察此世与他世的人；」连成两个悬垂状语，直到 `170-1305-2-7` 才出现主句「可意的事物不会扰乱他的心」，中间隔了一个分号，衔接断裂，读者读到第二个「对于…的人」时会失去落点。（`saṅkhātadhamma` 译作「已了知并审度」看似双译，但巴利注释传统确有 `ñāta-／tulita-` 两解，缺义注无法定案，暂不计入准确性扣分。）
  - 建议：把 1303/1304 的「对于…的人」合并为一个统领结构，或将 1304 末的分号改为逗号，使三行读作一句。

### 🟦 suggestion

- `170-1299-2-8`｜语言表达不够流畅｜片段「有智慧的人不像凡夫那样去领受那些受」
  - 问题：「凡夫」在原文中要到 `170-1301-2-5`（`puthujjanena`）才出现，此处提前补出比较对象；同时「领受那些受」中「那些」无先行词。补出的比较义可能有义注支持，但本次未取到义注，无从核实。
  - 建议：改为「有智慧的人并不（如常人一般）领受诸受」，或把比较对象留到 1301 再点明。

- `170-1300-2-5`｜语言表达不够流畅｜片段「这位博学多闻的人也不那样领受」
  - 问题：「也不那样领受」纯靠回指上一行，本行独立读时语义空转；且「领受」在相邻两行重复。
  - 建议：本行以「无论乐受还是苦受，多闻者亦复如是」之类自足表达收束，避免跨行回指。

- `170-1302-2-17`｜代词指代可能不够明确｜片段「对这位善巧的智者来说」
  - 问题：`kusalassa` 与 1301 的 `dhīrassa` 同指一人，译文两行各点一次「智者」，读者可能误以为是两类人。
  - 建议：本行改用回指，如「对他这样的善巧者而言」，避免第二次立名。

- `170-1307-2-7`｜语言表达不够流畅｜片段「他的随顺与违逆」
  - 问题：`athavā`（或）被译作「与」，把选择关系改成了并列关系；另「他的」在偈颂开头指代对象尚未出现（承自 1305「他的心」），略远。
  - 建议：改为「他的随顺或违逆」。

- `170-1298-30-57`｜语言表达不够流畅｜片段「不疲惫」
  - 问题：`na kilamati` 在此组四连否定（socati / kilamati / paridevati / kandati）中属情绪性的困顿苦恼，译作「不疲惫」偏向体力义，与前后「不忧愁／不悲叹／不拍打胸膛地哭泣」不在同一语义层。取义须以义注为准，本次缺义注。
  - 建议：候选「不憔悴」「不困顿」，取义待义注定案后统一。

- `170-1298-79-91` 等处｜该使用而没有使用术语标记｜片段「嗔恚随眠」
  - 问题：法相术语「随眠」「乐味」「过患」「出离」首次出现均未按 `knowledge/style.md` 第三节夹注巴利原词。
  - 建议：首次出现处补夹注，如「随眠（anusaya）」「乐味（assāda）」「过患（ādīnava）」「出离（nissaraṇa）」，其后只用汉译。
