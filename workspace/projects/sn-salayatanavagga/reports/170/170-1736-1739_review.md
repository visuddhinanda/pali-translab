# Review — 170:1736-1739（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 未提供）／义注 ⚠️ 部分——只有 136:726–727，仅覆盖 §1737 的 `kīvaciraṃ pabbajitassa` / `uttari manussadhammā` / `alamariyañāṇadassanaviseso` / `naggeyya` / `muṇḍeyya` / `pavāḷanipphoṭanā` 六条词释；§1738、§1739 全无义注对照，相关判断仅据巴利原文，标注为存疑。

## 跨段一致性

- `macchikāsaṇḍa`：§1737-2-19 与 §1737-25-37 均译「摩叉止陀山」——译法一致，但**一致地错**（见下）。
- `uttarimanussadhamma`：§1737-95-123 / §1737-124-152 / §1737-174-205 / §1738-33-53 / §1738-202-234 五处均作「超越常人的法」——一致，但与义注定义相悖（见下）。
- `pāvaḷanipphoṭanā`：§1737-124-152 / §1737-174-205 均作「拍打屁股」——一致，但与义注相悖且语体失当（见下）。
- `alamariyañāṇadassanaviseso` 五处均作「够得上圣者的殊胜知见」✅；`phāsuvihāro` 五处均作「能够安乐地生活」✅。
- `purāṇagihisahāyo` 三处（§1737-2-19 / §1737-25-37 / §1739-20-30）均作「从前在家时的朋友」✅。
- 称谓：`citto gahapati`「居士质多」、`acelo kassapo`「裸形者迦叶」全篇统一 ✅；第二人称分工（质多称迦叶用「您」、迦叶称质多用「你」）前后一贯，属合理的礼节区分 ✅。
- **`Dhammassa svākkhātatā` 两处译法不同**：§1737-174-205 作「这个法竟然被说成是善说的」（反讽读法），§1738-202-234 作「这个法真是善说的」（正面读法）。语境确实相反，但目前译文没有任何线索让读者看出前者是反讽，读起来像译者自相矛盾。建议前者改为「这法被称作善说的法，竟然……」或加脚注说明质多在此是反诘裸形外道之法。本句义注缺失，读法存疑，需在定稿前确认。

## §1737 句 170-1737-2-19

- **问题**：专名误译 — `macchikāsaṇḍa` 的 `saṇḍa` 是「丛、林」，不是山。译作「摩叉止陀山」是凭空添加地貌。
- **建议**：改「摩叉止陀」或「摩叉止陀林」，§1737-25-37 同改。

## §1737 句 170-1737-25-37

- **问题**：同上，「摩叉止陀山」。
- **建议**：与 §1737-2-19 统一改。

## §1737 句 170-1737-53-59

- **问题**：用词/错字 — 「寒暄叙谈了一番值得记念的话以后」。`sāraṇīya` 意为令人忆念的、亲切友好的；「记念」是错字（应作「纪念」或「忆念」），且「值得记念的话」在现代汉语里不成话。
- **建议**：改「互相寒暄、亲切地叙谈了一番之后，就在一旁坐下。」

## §1737 句 170-1737-95-123

- **问题**：术语与义注相悖 — **义注**：`manussadhammo nāma dasakusalakammapathā, tato manussadhammato uttari`（「人法」指十善业道，超过这个人法）。可见 `uttarimanussadhamma` 是「超过人法（即十善业道）的法」，不是「超越常人（能力）的法」。现译把 `manussadhamma` 当成「常人的（普通）状态」，义注给的所指是具体的十善业道，译窄/译偏了。
- **建议**：改用传统译名「上人法」并在首次出现处夹注，如「超越人法的（uttarimanussadhamma，义注释「人法」为十善业道）」；其余四处统一。
- **问题（次）**：`alamariyañāṇadassanaviseso` — **义注**：`ariyabhāvaṃ kātuṃ samatthatāya alamariyoti saṅkhāto ñāṇadassanaviseso`（因有能力成就圣性而被称为 alamariya 的殊胜知见）。现译「够得上圣者的」偏向「配得上」，义注的重点是「足以造就圣者」。
- **建议**：改「足以成就圣者的殊胜知见」。
- **问题（次）**：`phāsuvihāro` 是与「殊胜知见」并列/同位的名词（安乐住），现译「能够安乐地生活」处理成结果补语，尚可，但五处都如此，读来像附带条件。
- **建议**：可统一为「……殊胜知见，而得安乐住？」保持名词性。

## §1737 句 170-1737-124-152

- **问题**：**误译（必改）** — `pāvaḷanipphoṭanā` 译成「拍打屁股」。**义注**：`pāvaḷanipphoṭanato, bhūmiyaṃ nisīdantassa ānisadaṭṭhāne laggānaṃ paṃsurajavālikānaṃ phoṭanatthaṃ gahitamorapiñchamattato`（为拂掉坐在地上时粘在臀部处的尘土沙粒而持的一束孔雀翎而已）。这里说的是裸形外道随身只有一把拂尘（孔雀翎），用来掸去坐地时沾上的沙土——不是「拍打屁股」这个动作本身。
- **建议**：改「除了赤身裸体、剃光头发，以及拿一束拂子掸去（坐地时沾在身上的）尘土之外」，并加脚注引义注说明「拂子」即一束孔雀翎、掸的是坐地时粘在臀部的沙土。
- **问题**：语体 — 「屁股」是口语俚俗词，与全篇书面语体不合（`style.md` 一、语体：现代书面汉语）。即便保留动作义也应作「臀部」。
- **建议**：随上条一并改掉。
- **问题**：`naggeyya` / `muṇḍeyya` 是抽象名词（裸体状态、剃发状态），**义注**作 `naggabhāvato` / `muṇḍabhāvato`。现译「裸体、剃光头」把状态译成了动作/事物，尚可但略粗。
- **建议**：改「赤身裸体、剃除须发」更贴合 `-bhāva`。

## §1737 句 170-1737-174-205

- **问题**：同 §1737-124-152 的「拍打屁股」必改项。
- **问题**：反讽读法无提示，见「跨段一致性」一节。本句无义注对照，读法存疑。
- **建议**：整句重排，例如「这法竟被称作善说的法！可是三十年里，除了赤身裸体、剃除须发、拿一束拂子掸尘之外，竟没有证得任何超越人法的、足以成就圣者的殊胜知见与安乐住！」

## §1738 句 170-1738-2-16

- **问题**：术语未定 — `upāsakattaṃ upagatassa` 译「成为在家信徒」。`upāsaka` 在 `terms.md` / `term-glossary.jsonl` 未登记，传统译「优婆塞」或「在家信士」。「在家信徒」不算错，但与 §1738-202-234 的 `gihī odātavasano`「穿白衣的在家人」并列时，读者分不清两者是不是同一身份。
- **建议**：统一为「优婆塞（upāsaka）」首现夹注，或至少改「在家信士」以与「在家人」区分；定案后补进 `terms.md`。

## §1738 句 170-1738-81-94（`Tiṃsamattāni`，见 §1737-81-94）

- **问题**：`tiṃsamatta` 的 `-matta` 表约数（三十来年）。现译「已经有三十年了」把约数说死。
- **建议**：可作「三十来年」；若取整数译法，全篇（§1737-81-94 / §1737-95-123 / §1738-17-32 / §1738-33-53）保持一致即可，属可选项。

## §1739 句 170-1739-36-43

- **问题**：术语 — 「衣服、饮食、住处和治病的药品这些资具」。四资具是固定法数，`cīvara` 传统作「衣」，`gilānappaccayabhesajjaparikkhāra` 作「病缘医药资具」。「张罗」偏口语。
- **建议**：改「我会为他操办衣、饮食、住处、病缘医药这四种资具。」

## §1739 句 170-1739-55-83

- **问题**：语序造成理解障碍 — `yassatthāya … tadanuttaraṃ` 的关系从句被破折号后置，结果「安住于那无上的梵行终点——善男子们正是为了这个目的才……」让读者先遇到「那」再遇到先行词，中文里指代落空。
- **建议**：前置从句，如「受具足戒不久，迦叶尊者便独自远离人群，精勤、热诚、专心致志地安住；没有多久，他就在现世中亲自以证智证悟、证得并安住于那无上的梵行终点——善男子们正是为此才从家中出家、过无家的生活。」
- **问题（次）**：`appamatto ātāpī pahitatto` 三词被压缩成「精勤不放逸，专心致志」，`ātāpī`（热诚、有热力）与 `appamatta`（不放逸）合并了。
- **建议**：三词分列为「不放逸、热诚、专心致志」。

## §1739 句 170-1739-102-108

- **问题**：`ca pana` 译作「于是」偏强，此处是叙事收束而非因果。
- **建议**：改「迦叶尊者也就成了众阿罗汉中的一位。」
