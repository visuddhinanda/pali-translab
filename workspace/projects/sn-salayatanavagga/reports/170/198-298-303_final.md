**准确性**：句子骨架基本正确，黑体被解释词（`Pākaṭaṃ hoti` / `Okkhāyati paccakkhāyati` / `vimuttiparipācaniyā dhammā`）都保留了黑体并给出了译文。主要扣分点在 `198-299-6-16` 的 yojanā（连读）句：`samādhivikalānaṃ` 与 `paṭisallānavikalānaṃ` 是复注补出的属格补足语，原意是「对于缺少定的人（补出所缺项）」，而译文把 `vikalānaṃ`（缺少…的人）与 `labhantānaṃ`（得到…的人）并列成「缺少定而得到心一境性的人」，用「而」把两个属格分词连成转折关系，句法归属存疑——更可能是复注在说明义注正文里 `cittekaggataṃ labhantānaṃ` 这一语的省略成分即「缺少定者」。无 nissaya 可裁，故按 error 计一条而非 fatal。

`198-299-24-32` 结构基本可取，但 `Okkhāyati paccakkhāyati` 两词的区分（「显现」与「历历在目/如在眼前」）在译文中被处理成近义叠用，语义分辨度不足；`vibhūtabhāvena` 译作「以清晰的方式」偏弱。

`198-299-33-43` 的省略引文 `dvīsupi … pe … kathitā` 译作「这两部经里……乃至……讲说的都是」，把 `kathitā`（阴性/复数被动分词，承 `dhammā`/`saccāni` 之类）译成「讲说的都是」而句末悬空，读者无法判断讲说的是什么；且 `…pe…`（peyyāla）在汉译中直接写成「乃至」属文言省略符的惯用译法，此处可接受，但整句作为引文残缺，可读性差。

**风格**：整体为现代书面汉语，无「此中/故为/彼等/是故」等禁例。`198-302-12-24`「是通过这些教说才使诸根成熟的」句式自然。标点全角、无 ASCII 引号、无工作标记残留——这几项均合规。仅 `198-299-33-43` 的「乃至」与整句文白夹杂感略重。

## 问题清单

### 🟧 error

- `198-299-6-16`｜错译（修饰关系）｜片段「对于缺少定而得到心一境性的人」
  - 问题：`samādhivikalānaṃ` 与 `cittekaggataṃ labhantānaṃ` 被「而」连成同一批人的转折描述。按 yojanā（连读指示）的通例，复注是在为义注正文的 `cittekaggataṃ labhantānaṃ` 补出所省略的限定语 `samādhivikalānaṃ`，二者是同位补足关系而非转折并列。后半「缺少独处而得到身远离和心一境性的人」同此。若此读成立，则译文颠倒了复注的注释意图。
  - 建议：改为同位读法，如「连读应作：（对于）缺少定的人，即得到心一境性的人；（对于）缺少独处的人，即得到身远离和心一境性的人」。**需先取回 198 段对应的义注正文核对被解释语原貌再定稿**，不要凭本条直接改。

- `198-299-33-43`｜导致误解的表达｜片段「这两部经里……乃至……讲说的都是」
  - 问题：`kathitā` 的主语（被讲说的东西）在省略号中被吞掉，译文句末「讲说的都是」后无宾语，读者读到的是一个断句。引文虽本身省略，汉译也应补出可读的收尾。
  - 建议：按义注原文补出被省略的主语再定，如「这两部经里都讲说了……乃至……」。

### 🟨 warning

- `198-299-24-32`｜关键词语意不明确｜片段「**显现出来**、**现前呈现**」
  - 问题：`okkhāyati` 与 `paccakkhāyati` 是复注要区分的一对被解释词，译文两者语义几乎重合，读者看不出为何需要两个词。`paccakkhāyati` 含 `paccakkha`（现量、亲见）之义，应体现「如在眼前、亲自可见」的层次。
  - 建议：区分译出，如「显现、历历在目」，并按 style.md 对罕见术语首次出现夹注巴利原词。

- `198-299-17-23`｜关键词语意不明确｜片段「清晰地显现出来」
  - 问题：`vibhūtaṃ hutvā upaṭṭhāti` 直译为「成为分明而现起」，译文用「清晰地」作状语，把 `vibhūtaṃ hutvā`（成为分明的状态）弱化为程度副词，且与下一句 `198-299-24-32` 中 `vibhūtabhāvena`「以清晰的方式」用词重复但结构不统一。
  - 建议：统一 `vibhūta` 的译法，如「变得分明而显现」「以分明的状态」。

- `198-302-12-24`｜整句逻辑表达不规范｜片段「长老当时信等诸根尚未成熟，是通过这些教说才使诸根成熟的」
  - 问题：后半句「使诸根成熟」的施事不明——原文 `thero … indriyaparipākamagamāsi` 主语是长老自己（长老因这些教说而达到诸根成熟），译文的「使」带使役义，读起来像是教说使某人成熟，主语滑移。
  - 建议：改为「长老正是因这些教说而达到了诸根成熟」。

### 🟦 suggestion

- `198-299-6-16`｜语言表达不够流畅｜片段「连读应作：」
  - 问题：`yojanā` 的译法「连读应作」为本段首次出现，属复注体例术语，未夹注巴利原词，读者不易理解这是注释体例用语。
  - 建议：首次出现处夹注，如「连读（yojanā）应作：」。

- `198-302-6-11`｜语言风格不统一｜片段「无常随观等就叫作」
  - 问题：「就叫作」偏口语，与本段其余句子的书面语体略有落差。
  - 建议：改为「即名为」过于文言，宜作「就是所说的」或「称为」。
