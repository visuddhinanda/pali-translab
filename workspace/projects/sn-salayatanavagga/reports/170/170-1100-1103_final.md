**准确性**：套语结构（`yo rāgo so natthi … so pahīno`）、譬喻（乳树、斧、乳汁）、问答框架都译得完整，无漏译、无多译，主谓宾判断正确，无 fatal。主要问题集中在两处词义处理：

1. `adhimattā`（极多、强盛）与 `parittānaṃ`（少量、微小）是一组**量的对举**——「即使强烈的色落入眼界也不能占据其心，何况微弱的？」译文把这组对举改译成了性质对举「引人贪爱 / 不引人贪爱」，这是把量词解释成了性质词。虽然意思方向不悖，但属于对原文修饰关系的改换，且 `paritta` 的「微小」义在 nissaya/义注里几乎必有明确交代，风险较高。计 error 两条（1100-2-62 与 1101-2-58 各一，两个 `ko pana vādo` 句因与前句共用同一处理，一并归入相应条目，不重复计数）。

2. `terovassiko`（经年的、隔年的）译作「枯死一年多了」——「一年多」的「多」是原文没有的量的追加，属轻微多译，计 warning。另 `sukkho kolāpo`（干枯、中空无髓）译「已经干枯、成了朽木」，`kolāpa` 的传统释义偏「空心/无汁髓」而非「腐朽」，「朽木」偏了一档，计 suggestion。

3. `khīrarukkho assattho vā nigrodho vā …` 的同位关系译作「有乳汁的树——菩提树、榕树……」处理正确（乳树是总称，四种是举例），破折号用法恰当。`pilakkha` 译「波利叉树」、`udumbara` 译「优昙钵树」，音译选择与 `knowledge/terms.md` 未登记项的处理原则一致，但这两个是罕见术语，按 `style.md` 第二节应首次出现附简注，现无注，计 suggestion。

## 问题清单

### 🟧 error
- `170-1100-2-62`｜错译（词义、修饰关系）｜片段「即使引人贪爱的法浮现于他的意中」
  - 问题：`adhimattā`（adhimatta）意为「极多的、强盛的、突出的」，是**量/强度**的修饰，不是「引人贪爱」这一性质判断。与之对举的 `parittānaṃ`（微少的）同样是量词。译文把一组「强 vs 弱」的对举改换成「引人贪爱 vs 不引人贪爱」的性质对举，偏离原文修饰关系。
  - 建议：改为「即使强烈的法浮现于他的意中」，并使下句 `ko pana vādo parittānaṃ` 相应作「更不用说微弱的法了」。**待义注复核后定案**——若义注明确以「可意/悦意」释 `adhimatta`，则本条可撤销。

- `170-1101-2-58`｜错译（词义、修饰关系）｜片段「即使引人贪爱的色落入他的视野」
  - 问题：同上，`adhimattā cakkhuviññeyyā rūpā` 是「强烈的、显著的色」，非「引人贪爱的色」。此处与 `170-1101-59-63`「更不用说不引人贪爱的色了！」及 `170-1103-2-58`、`170-1103-59-63` 的对应片段是同一处理，须一并改。
  - 建议：改为「即使强烈的色落入他的视野」，下句作「更不用说微弱的色了」。四处（1101-2-58、1101-59-63、1103-2-58、1103-59-63）连同 1100 段两处统一修改，保持套语一致。

### 🟨 warning
- `170-1100-105-122`｜不导致误解的汉语语病（多译）｜片段「枯死一年多了」
  - 问题：`terovassika` 意为「经过一年的、隔年的」，原文只说「经年」，「一年**多**」的「多」是译文追加的量，原文无据。
  - 建议：改为「已经枯死一年了」或「枯了一年」。

- `170-1100-154-166`｜整句逻辑表达不规范｜片段「凡有乳汁的，那乳汁已经没有了」
  - 问题：原文 `Yañhi, bhante, khīraṃ taṃ natthi` 刻意呼应前面 `yo rāgo so natthi` 的套语，保留呼应有理据；但汉语「凡有乳汁的」主语悬空、不知所指，读来像病句——贪瞋痴是可断的烦恼，乳汁是树的物质，同一句式套上去汉语不成立。
  - 建议：改为「尊者，因为那树里原有的乳汁，已经没有了。」——既保留「已经没有了」与套语的呼应，又消除主语悬空。

### 🟦 suggestion
- `170-1100-105-122`｜不常用术语编写注释或者百科｜片段「波利叉树或优昙钵树」
  - 问题：`pilakkha`、`udumbara` 属罕见术语，按 `knowledge/style.md` 第二节「罕见或有争议的术语用巴利音译，**首次出现附简注**」，此处两个音译均无注，读者无从知其所指。
  - 建议：首次出现夹注巴利原词，如「波利叉树（pilakkha）或优昙钵树（udumbara）」；若需更详，可加段后小字注说明二者分别为无花果属的两种乳汁树。

- `170-1100-105-122`｜语言表达不够流畅（取义偏移）｜片段「已经干枯、成了朽木」
  - 问题：`kolāpa` 的传统释义偏「中空无汁髓的」（缅甸传统与义注多作「空心、无髓」），译作「朽木」偏向「腐朽」，与「干枯中空」有一档差距。
  - 建议：改为「已经干枯、中空无髓」或「已经干枯、成了空心的枯木」。**待义注复核**。

- `170-1100-2-62`｜复杂的嵌套句整句语言逻辑理解困难｜片段「凡有贪的，那贪已经没有了；凡有瞋的，那瞋已经没有了；凡有痴的，那痴已经没有了；凡有贪的，那贪已经断除了」
  - 问题：六个分句排比后接破折号再转出主句，单句过长（全句约 150 字），普通读者读到主句时已丢失前项。这是原文套语所致，保留排比有理据，故仅列为可提升项。
  - 建议：可在第三个分句后用句号断开，主句另起「这样的比丘或比丘尼，即使……」；若坚持贴合原文节奏则维持现状，不必强改。
