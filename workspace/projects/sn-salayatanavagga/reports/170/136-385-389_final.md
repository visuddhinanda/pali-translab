## 理由

**数据条件**：本次评估仅有巴利原文与目标 channel 译文注入，**未取到义注（本段本身即义注层 aṭṭhakathā，其上只有复注 ṭīkā）与 nissaya**。因此词法与取义的核对只能依据巴利原文本身的形态与上下文，缺少 nissaya 的格助词佐证与复注的释义佐证。凡涉及格/句法角色的判定（尤其 `pamajji` / `pamādaṃ āpajji`、`aṅguliṃ cāletvā`、`idamatthiyaṃ`、`paribhogapamāṇaṃ paccavekkhaṇapayojanaṃ`）均属无外部基准的独立判读，故信心压到 72。

**准确性**：叙事部分（385–387 鹧鸪肉故事）整体忠实，句子主谓宾归属正确，未见教理性偏差，无 fatal。主要失分集中在三处：`apaccamāno` 的译法带入了「不自己煮食」这一并非原文字面的限定；`aṅguliṃ cāletvā` 译作「动一动手指」未能传达沙弥示意侍者的动作意图（此处 nissaya 本可定案，缺）；`tittire upanesi/upanāmesi` 的「端上来」把国王的亲手供奉动作弱化。387 末尾的论义段（140–171）是全段最难处，`paccavekkhaṇapayojanaṃ` 译作「其着力处就在省察」属意译，`payojanattā` 又译作「作用正在于」，同一词根两处落点不一致，读者难以看出二者是同一论证环节。

**风格符合度**：符合 `knowledge/style.md` 的现代书面汉语要求，未发现文言虚词（之/其/乃/便/遂/谓）或文言句式，叙事流畅自然。标点全角，引号统一为弯引号，未见 ASCII 引号，JSON 安全无虞。夹注巴利原词（亲教师（upajjhāya）、阿闍梨（ācariya））符合首次出现夹注的约定。扣分处：`136-387-125-135` 的「像这样于受取知量的人」，「于……知量」是文言式的介词结构，与全篇现代语体不协调；`136-387-140-162` 一句四个分句连缀、嵌套过深，属对读者不友好的长句。

**一致性**：`mahāthero` / `thero` / `mahallakatthero` 三个称谓在 386–387 内部区分清楚，未混淆。但 `hatthaṃ pidahi` 在 `136-386-84-90` 与 `136-387-32-38` 译法一致（「以手遮掩表示不受」），是好的；而 `upanesi`（386-53-58）与 `upanāmesi`（387-7-13、387-26-31）三处，前两处都译「端了上来」、第三处译「递给」，同一动作动词译法摆动。`aṭṭha dhuvabhattāni` 的「八份常食」与后续五轮「八份」保持一致，可。

## 问题清单

### 🟧 error

- `136-385-2-28`｜错译（词义）｜片段「不自己煮食的比丘僧团又从哪里能得到呢？」
  - 问题：`apaccamāno` 是 `pacati`（煮）的现在分词否定式，此处修饰 `bhikkhusaṅgho`，指僧团不自炊。译文「不自己煮食」字面无误，但「又从哪里能得到呢」把国王的感慨落在「得不到」上，而原文 `kuto labhissatī` 的修辞重点是「连我这国王三年都求不到，遑论托钵为生的僧团」。译文把因果链条拆断了，读者读不出「因为不自炊所以更难得」这一层。
  - 建议：调整为「何况是不自己开伙、只靠托钵的比丘僧团，又哪里能得到呢？」使「不自炊」与「更求不得」的因果显出来。

- `136-387-14-25`｜错译（修饰关系）｜片段「沙弥动一动手指，让人把另一只从中间切开」
  - 问题：`aṅguliṃ cāletvā majjhe chindāpetvā` 是沙弥以手指示意（使役 `chindāpetvā`，让人切），译文「动一动手指」过于字面，读者无法理解这是「以手势示意侍者」的动作；且「另一只」是译者补出的，原文只说 `majjhe chindāpetvā`，切的是国王呈上的那一只，不必然是「另一只」。
  - 建议：「沙弥用手指示意，让人把鹧鸪从中间切开」，去掉「另一只」的补足。

- `136-387-140-162`｜义理或用词与注释书不符｜片段「受用的量，其着力处就在省察」
  - 问题：`paribhogapamāṇaṃ paccavekkhaṇapayojanaṃ` 是「受用之量以省察为其用途/所为」，`payojana` 在此与下文 `paccavekkhitaparibhogasseva payojanattā` 同词根、构成同一论证。译文前处译「着力处」、后处译「作用正在于」，同词异译使论证链断裂，读者看不出这是「因为 X 的 payojana 是 Y，所以它才叫 Y-量」的推理。
  - 建议：两处统一，如「受用的量，是以省察为其用处的」与「正因为它的用处在于省察之后的受用」，使前后呼应。

- `136-386-53-58`｜错译（词义）／一致性｜片段「国王把几只鹧鸪端了上来」
  - 问题：`upanesi` / `upanāmesi` 指亲手奉上、递呈（供养动作），主语是国王本人。「端了上来」偏向仆役上菜的语感，弱化了国王亲自供养的场面；且同一动词在 `136-387-26-31` 译作「递给」，三处不统一。
  - 建议：统一译为「奉上」或「呈上」，如「国王把鹧鸪奉给他们」。

### 🟨 warning

- `136-387-125-135`｜文言语体｜片段「像这样于受取知量的人」
  - 问题：「于……知量」是文言介词结构（`于` 作文言虚词），违反 `knowledge/style.md` 第一节禁例表「之/其/乃/便/即/於/遂」的总原则。
  - 建议：改为「像这样懂得接受多少才合适的人」或「像这样在接受供养上知道分寸的人」。

- `136-387-140-162`｜复杂的嵌套句整句语言逻辑理解困难｜片段「而“我吃的是有这样用处的食物”这样的省察，作用正在于经过省察之后的受用，所以它才叫做受用的量——这里所指的就是它」
  - 问题：单句内含引语、判断、因果、回指四层，破折号后的「这里所指的就是它」指代对象需要读者回溯两个分句才能确定。属第四类「复杂的嵌套句」，但因指代回溯距离过长已影响理解，按 warning 计。
  - 建议：拆为两句，末句明写「这里所说的量，指的就是受用的量」。

- `136-386-25-35`｜关键词语意不明确｜片段「就没有加以留意」
  - 问题：`pamajji` 与下句 `pamādaṃ āpajji` 是同一概念的两种表达（长老疏忽、大臣之子也疏忽），原文用词变化构成对仗。译文分别作「没有加以留意」与「疏忽过去了」，语义虽通，但「没有加以留意」偏弱，读者读不出这是双方各自失察、以致外人混入的关键转折。
  - 建议：两句分别用「就没有细究」「也就没有细究」之类对称表达，凸显双方同时失察。

- `136-387-58-64`｜关键词语意不明确｜片段「两只耳朵里就流出了脓」
  - 问题：`kaṇṇehi pubbo nikkhami` 是国王宿业感果的示现，译文字面正确，但突兀出现且无任何提示，普通读者会误以为是食物中毒或疾病描写，而非业报示现。此处正是第三类「二意场合没有注释」。
  - 建议：保留字面译法，另加脚注说明此为宿业现报之相。

- `136-386-16-24`｜不导致误解的汉语语病｜片段「另外有一位年老出家的比丘，像是长老的随从沙门一样，跟在后面也进去了」
  - 问题：「跟在后面也进去了」中「也」的位置使句子重心偏移，`anubandhanto pāvisi` 的主干是「尾随而入」，「也」是译者补出的关联词，放在「进去了」前造成轻微的语序失衡。
  - 建议：「跟在后面一起进去了」。

### 🟦 suggestion

- `136-386-84-90`｜语言风格不统一｜片段「长老以手遮掩表示不受，那位年老出家的比丘却接受了」
  - 问题：前半「以手遮掩表示不受」是解释性译法（把动作与意图都说出），后半「接受了」是直译，两半详略不对称；同一句内一繁一简。
  - 建议：或前半简化为「长老以手遮住钵口」，或后半补足为「却伸手接了过去」。

- `136-387-86-92`、`136-387-97-101`｜该使用而没有使用术语标记｜片段「我的亲教师（upajjhāya）」
  - 问题：`upajjhāya` / `ācariya` 已按 style.md 首次出现夹注巴利原词，处理正确；但 `136-387-106-109` 的「跟我同一位亲教师的比丘们」（`samānupajjhāyānaṃ`）是同一术语族的复合词，未与前面建立显式关联，读者不易看出这是「同一 upajjhāya 门下」。
  - 建议：改为「跟我同出一位亲教师（upajjhāya）门下的比丘们」，或在该处不再夹注但用「同一亲教师门下」使关联更显。

- `136-387-39-57`｜语言表达不够流畅｜片段「靠着这些学好规矩的人，我们才得以吃到一只半鹧鸪」
  - 问题：`uggahitavatte nissāya` 承接 386 国王对长老说的 `uggahitavattaṃ bhikkhuṃ`，是明显的呼应与反讽。译文两处分别作「已经学好规矩的比丘」与「这些学好规矩的人」，用词接近但未完全对齐，反讽的回环略减弱。
  - 建议：两处统一为「学好规矩的（比丘）」，如「靠着学好规矩的比丘，我们才吃得上一只半鹧鸪」。

- `136-388-2-14`｜不常用术语编写注释或者百科｜片段「享受欲乐者的卧法、饿鬼的卧法、狮子的卧法、如来的卧法」
  - 问题：四种 seyyā 的分类是此段论述的框架，`sīhaseyyā`（狮子卧）作为修行威仪的专名，首次出现时未夹注巴利原词，与 387 段 `upajjhāya` 的处理标准不一致。
  - 建议：首次出现处加夹注「狮子的卧法（sīhaseyyā）」，或为四种卧法整体加一条简注。

- `136-389-27-39`｜语言表达不够流畅｜片段「周身只是骨节交结」
  - 问题：`aṭṭhisaṅghāṭajaṭitā` 意为「被骨骼связ结缠结而成」，译文「骨节交结」简洁但略生硬，「只是」的限定也稍显突兀。
  - 建议：「浑身只剩骨头架子相连」或「通身只是一副骨架盘结」。
