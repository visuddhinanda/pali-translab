## 理由

**基准可用性**：本次仅注入了巴利原文与目标 channel 译文。被评的这一层本身就是义注（`136` = Saṃyutta 义注 *Dukkhadhammasuttavaṇṇanā`），没有更上一层的复注（ṭīkā）可作释义旁证；nissaya 亦未注入。因此**释义标准与词级基准都缺失**，准确性判断只能依巴利原文词法与上下文自查，信心相应压低到 72。凡涉及阿毗达摩心路术语（javanavāra / voṭṭhabbana / bhavaṅga）与律部人物（Sudinna / Raṭṭhapāla）的判断，建议取到 nissaya 或复注后复核。

**准确性**：主谓宾判断整体正确，无教理性错误，无 fatal。扣分集中在三处：`136-513-24-41` 与 `136-513-50-64` 把 `javanavāra` 一律译作"速行心路"，而 `vāra` 在此指同一所缘上的**第几次速行（回合/轮次）**，不是一条完整心路（vīthi）——"第二个速行心路"会让读者误以为发生了两次独立的心路过程；`136-513-50-64` 的 `Anacchariyañcetaṃ … pana` 结构，译者把"难得/稀奇"的对比关系补成"而真正难得的是"，方向对，但原文 `pana` 后并无"难得"一词，属增译定性；`136-514-2-33` 的 `abhihaṭṭhuṃ pavāreyyuṃ` 是一个固定的"捧持而奉请"惯用语，译文拆成"拿财物来供、出言相邀"并用顿号并列，与下文"或者亲自搬来七宝，或者用言语说"的二分重复了一次，被解释词与释文层次略乱。

**一致性（与父层逐字同译）**：被解释词（黑体）译法与随后的释文基本对得上（苦法／树林／前面有刺／别让刺扎着我／烧得你难受等），这是本段的强项。但 `136-511-26-31` 的被解释词 `Tathā kho panassā` 译成整句"**他看见诸欲的方式就是这样的**"，`136-511-49-66` 的 `Aṅgārakāsūpamā kāmā diṭṭhā honti` 译成"**看见诸欲就像那个炭火坑一样**"——引自本文的黑体词按硬约束应与本文（mūla）译文逐字相同，此处是义注式的意译扩写，且"那个炭火坑"的指示词"那个"在本文中未必有对应。本文层译文未注入，无法核对，只能列为 warning 待查。

**风格**：现代书面汉语基本达标，句子读来不隔。但有若干处仍带文言或半文半白残留（"斩截"、"荒僻的林野"、"随顺着"、"留驻"、"黏着不去"、"谈不上退转还俗"中的"谈不上"尚可，"不去"则偏文），已按 warning 逐条列出。标点全角，无 ASCII 引号，无残留工作标记，符合硬约束。夹注巴利原词的用法（javana / vipassanā / bhavaṅga / āvajjana / voṭṭhabbana / cetanā / anusenti / Sudinna）一致且只在首次出现处加注，符合 `style.md` 第二节。

## 问题清单

### 🟧 error

- `136-513-24-41`｜错译（词义）｜片段「在第二个速行（javana）心路里」
  - 问题：`dutiyajavanavārena` 的 `vāra` 指同一所缘上速行的**第二个回合/第二轮**，不是第二条心路（vīthi）。译成"心路"会让读者理解为另起了一次完整的认知过程，与阿毗达摩的心路结构相悖。
  - 建议：改为"第二轮速行（javana）"或"第二次速行时"；下文 `tatiye javanavāre`、`tatiyajavanavāre` 同步改为"第三轮速行"。

- `136-513-50-64`｜错译（词义）｜片段「就止住那即将到来的烦恼速行心路」
  - 问题：同上，`sampattakilesajavanavāraṃ` 的 `vāra` 是速行的轮次；另 `sampatta` 是"已经到来/已现前"，译作"即将到来"弱化了原文"烦恼速行已然临门"的语感。
  - 建议：改为"止住那已经临头的烦恼速行（javana）一轮"。

- `136-514-2-33`｜错误多译｜片段「拿财物来供、出言相邀」
  - 问题：被解释词 `abhihaṭṭhuṃ pavāreyyuṃ` 是"捧持（财物）而奉请"一个动作，译文先用顿号拆成身、语两项，随后释文又完整给出"或者亲自把七宝搬来，或者用言语说…"的身语二分，同一层意思出现两遍，被解释词与释文的层次被抹平。
  - 建议：被解释词按本文译法处理（如"捧持奉请"），把身/语二分留给释文承担。

### 🟨 warning

- `136-511-26-31`｜被解释词与父层同译｜片段「**他看见诸欲的方式就是这样的**」
  - 问题：黑体 `Tathā kho panassā` 引自本文，按硬约束应与本文译文逐字相同；此处是扩写成的完整句，很可能与本文层不一致。
  - 建议：取本文层（Dukkhadhammasutta 正文）该处译文核对后回填；若本文作"他就是这样"之类，此处照抄。

- `136-511-49-66`｜被解释词与父层同译｜片段「**看见诸欲就像那个炭火坑一样**」
  - 问题：同上；且"那个"为译者添加的指示词，原文 `aṅgārakāsūpamā` 无对应成分，本文中是否有"那个"须核对。
  - 建议：与本文层逐字对齐，删去无据的"那个"。

- `136-511-12-25`｜文言语体｜片段「斩截、杀害、系缚等种种痛苦」
  - 问题："斩截"为文言单音节复合词，现代读者陌生。
  - 建议：改为"砍杀、杀害、捆绑"或"被砍、被杀、被捆缚"。

- `136-511-40-48`｜文言语体｜片段「随顺着行走与安住而行走的时候」
  - 问题："随顺着"是佛典文言腔；且"行走…而行走"在一句里重复，读来绕口。
  - 建议：改为"依照他的行止（cāra）与安住（vihāra）而行走的时候"。

- `136-512-2-5`｜文言语体｜片段「荒僻的林野」
  - 问题："林野"偏文言。`aṭavi` 即野林、荒林。
  - 建议：改为"荒野的树林"或"荒僻的森林"。

- `136-513-2-23`｜文言语体｜片段「无法继续留驻」
  - 问题："留驻"为文言词。
  - 建议：改为"无法继续停留"。

- `136-514-42-48`｜文言语体｜片段「黏着不去」
  - 问题："不去"为文言否定式。
  - 建议：改为"黏在身上不掉下来"。

- `136-512-20-28`｜关键词语意不明确｜片段「不过下面的刺是在双脚踩踏之处的附近」
  - 问题：原文 `Heṭṭhā pana` 后省略了 `kaṇṭako`，译文补出"下面的刺"没问题，但整句要表达的是"下方的刺只在脚踩处近旁、并不正扎在踩踏点上"，译文"并不是正好在踩踏的地方"读起来像在否定刺的存在位置，逻辑指向不够清楚。
  - 建议：改为"至于下方，刺是在双脚落脚处的近旁，并不正在落脚的那一点上"。

- `136-514-49-64`｜整句逻辑表达不规范｜片段「**比丘们，那颗心**——之所以这样说，是因为」
  - 问题：破折号后直接接"之所以这样说"，把 `idaṃ yasmā …` 的因果拆得较硬；且"那颗心"用量词"颗"与全篇书面语体略有出入。
  - 建议：改为"**比丘们，那样的心**，这样说是因为…"。

### 🟦 suggestion

- `136-513-50-64`｜复杂嵌套句理解困难｜片段「当可意的所缘进入视野、有分（bhavaṅga）转起、转向心（āvajjana）等生起之后」
  - 问题：一句内连缀四个阿毗达摩术语与两重时间状语，对一般读者负担偏重。
  - 建议：拆为两句，先交代所缘现前、有分转起，再说转向等诸心生起。

- `136-513-50-64`｜增译定性｜片段「而真正难得的是：」
  - 问题：原文 `Anacchariyañcetaṃ …, pana` 的对比由前句"这还算不上稀奇"承担，此处补"真正难得的是"虽合文意，但属译者添加的评价语。
  - 建议：改为"而这样才是稀奇的："或直接用"但是："以保留原文的克制。

- `136-514-34-41`｜语言风格不统一｜片段「**烧得你难受**」
  - 问题：被解释词用了口语化的第二人称"你"，与全篇第三人称叙述、书面语体不一致；释文随即又改回第三人称"烧灼着他"。
  - 建议：与本文层译法核对后统一，宜作"烧灼着"一类不带人称的译法。

- `136-512-29-35`｜术语标记｜片段「四面是刺的屋子」
  - 问题：`kaṇṭakagabbha` 译"四面是刺的屋子"达意，但 `gabbha`（内室）是常见建筑词，首次出现可考虑附巴利原词。
  - 建议：作"刺房（kaṇṭakagabbha）"或保留意译并加夹注。
