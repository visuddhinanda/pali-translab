# Review — 198:203-210（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入，本次未作词级核对）／父层义注 ✅（book=136 §195-202，原文 + 已定稿译文）
> 本层为复注（ṭīkā），释义标准取父层义注译文；凡黑体被解释词以父层定稿译文为准。

## 一、被解释词与父层逐字核对

逐条比对了本 chunk 全部黑体词，**绝大多数与父层定稿逐字一致**（尽头／我要称赞／具有这样的情况／意思是像这个样子／知道时确实知道／因为是以见来引导的缘故／宣说者／弘传者／把意义引出来／不死的给予者／让人为难／由于眼／认作世间／还没有断除（我）见的／他的／靠行走／不能／就坏灭的意思／用这些语句／用这些字母连缀成的词／用一个一个的字母／智者／大的义）。以下为不一致或需处理项：

- **必改** `198-209-33-53` **taṃ byākatan** 译作「**所解答的那样**」，与父层 `136-202-44-54`「阿难怎样解答了它」不一致（taṃ = 「它」）。更严重的是：本条注的论点正是「第二种解释里 taṃ 是**回指**（paccāmasana）而非语助词」，译文却仍把 taṃ 译成「那样」（＝第一种解释的语助词读法），把这条注自己要区分的两解抹平了。
  → 改为：因此说“**解答了它**”。
- **建议** `198-206` 的 **cakkhubhūto / ñāṇabhūto / dhammabhūto / brahmabhūto** 译作「**眼**／**智**／**法**／**梵**」，父层定稿作「**眼（cakkhubhūta）**／**智（ñāṇabhūta）**／**法（dhammabhūta）**／**梵（brahmabhūta）**」，夹注被删。单字「智」「法」「梵」作被解释词时歧义极大（读者会误为 ñāṇa／dhamma 本身），建议按父层补回巴利夹注，四处一并处理。
- **提示** `198-205-68-76` **Passitabbameva passatī** 译「**他所看见的正是应当看见的**」，父层作「他所看见的，正是应当看见的」（有逗号）。作黑体引词可不加标点，保持现状亦可，但若要严格逐字，补一个「，」。
- **提示** `198-208-9-19` / `198-208-20-32` 引父层释文时去掉了「（pada）」「（byañjana）」夹注。作引文可接受，不列为必改。

## 二、跨段一致性

- **loka 的「世界／世间」分工**：§204 黑体 **loko** 作「世界」（含 `198-204-13-17` 诸行义那一条），§207 正文一律作「世间」。核对父层 `136-196`：黑体一律「世界」，释文里 saṅkhāraloka 作「诸行世间」——**本层用法与父层一致，保持现状**，不要为「统一」把 §204 的黑体改成「世间」。
- **abhisaṅkhāraloka**（`198-207-90-97`）译「行作世间」，与 §204 的「诸行」（saṅkhāra）、父层的「诸行世间」（saṅkhāraloka）是三个不同措辞。二者确实不是同一词，建议首次出现补夹注「行作世间（abhisaṅkhāraloka）」以免读者误判为笔误。
- **jānaṃ jānāti / passaṃ passati** 句式：§205 三处（19-26、77-94、95-108）一律「知道时确实知道／看见时确实看见」，与父层一致 ✅。
- **-aṭṭhena** 的译法在本 chunk 有「因为…的缘故」（206-2-25）与「就…的意思」（204-13-17、206-50-69、207-90-97）两式。两式各自都与父层对应处一致（父层同样两式并用），属语境差异，**不必强改**。
- **cakkavāḷa／cakkavāḷaloka** 分别作「轮围」「轮围世界」，前后统一 ✅。
- 标点：全角引号、全角括号、破折号使用规范，未见 ASCII 引号 ✅。

## 三、逐条问题

### §204

`198-204-22-28`
- **问题**：语体（必改） — 「samānetvā avirodhetvā」译作「相会通，**使之**没有抵触」，「使之」是文言虚词，违反 `style.md` 第一节禁例（之／其／乃…）。
- **建议**：改为「…相会通，不让两者互相抵触」或「…相会通，使两者没有抵触」。

### §205

`198-205-2-9`
- **问题**：格的方向（必改） — 「idaṃ mama ajjhesanaṃ」译作「这是我的请求」。依父层 §198 语境，**义注**：「不要让我们一再请求，请把话说得让我们容易理解」——请求是比丘们**向阿难**提出的，说话人（我）是被请求者。此处 mama 为宾格义属格（对我的请求），译成「我的请求」把方向译反了。
- **建议**：「就是这样成就的、应当这样看待的——你们对我提出的这个请求（就是这样）」；或「意思是：你们对我提的这个请求是这样成就的、应当这样看待的」。顺带解决现译把「这是我的请求」读成独立短句、与前两个定语脱节的问题。

`198-205-27-34`
- **问题**：术语 — 「padesaññāṇe ṭhito」译「安住在**局部智**上的人」，padesañāṇa 传统作「一分智／少分智」，「局部智」是新造词且未夹注。
- **建议**：「安住在一分智（padesañāṇa）上的人」，或保留「局部智」但首次出现夹注。

`198-205-35-55`
- **问题**：术语 — 「ukkaṭṭhaniddesena」译「按**最高的说法**」，语义含混（读者会理解为「最高明的讲法」）。ukkaṭṭhaniddesa 指以最殊胜者立言的表述法。
- **建议**：「因为是就最殊胜者而作的说明（ukkaṭṭhaniddesa），又因为取法上不加限定…」。

`198-205-95-108`
- **问题**：误译（必改） — 「diṭṭhidassanassa abhāvā」译「由于没有**见取**上的错见」。原文只有 diṭṭhi + dassana，「见取」是 diṭṭhupādāna，本句无此词；「错见」也是补出来的。前半句已用「已经断除颠倒」对 pahīnavipallāsattā，此处对应的是「不以（邪）见而见」。
- **建议**：「由于没有依邪见而起的见（diṭṭhi-dassana），所以看见时确实看见」。

### §206

`198-206-2-25`
- **问题**：可读性 — 「所以**就引导看见这项作用的意思**而说是**眼**」，一句内「成办…成办」「就…的意思」叠用，读起来拗口。
- **建议**：「所以从『引导看见这一作用』的意思上说他是**眼（cakkhubhūta）**」。

`198-206-74-79`
- **问题**：风格 — 「使对谛的通达**流转下去**而宣说」，pavatteti 此处是「使之长久相续」，「流转下去」易与轮回义的「流转」混淆（§199 父层正用「流转」指轮回）。
- **建议**：「因为他长久地使对谛的通达传续下去而宣说」。

`198-206-99-102`
- **问题**：风格 — 「诸菩提分法**系属于**他」，「系属」偏文言。
- **建议**：「因为诸菩提分法都归属于他，所以是**法主**」。

### §207

`198-207-17-25`
- **问题**：原文疑问 + 引文对应 — 本层引作「cakkhuñhi **loko**」，父层义注原文作「cakkhuñhi **loke** appahīnadiṭṭhi puthujjano…」（`136-199-10-33`），定稿译文为「把眼认作世间」。译文「**因为眼就是世间**」是照 loko 读法译的，与父层译文对不上，读者会以为复注引错了父层。
- **建议**：两条路——(a) 依父层文本作「因为在世间，…眼…」并在报告/脚注注明异读；(b) 保持现译，但必须在该处出脚注说明「复注所据本作 loko，义注传本作 loke」。**倾向 (b)**，因为下一句「离开内处就没有世间这个称呼」正支持 loko 这个读法。此条留给 footnote 步处理，不要在 revise 时悄悄改掉。

`198-207-26-45`
- **问题**：术语歧义 — 「不能作**密集的剖析**」，ghanavinibbhoga 是「破解（色法等的）密集相」，现译会被读成「细密的剖析」，意思正好落空。
- **建议**：「他不能破解密集（ghanavinibbhoga），于是把部分当作整体…」。

`198-207-46-60`
- **问题**：数目对不上 — 「把『认作世间、思量为世间』这**三个词**牵引过来」。所牵引的是 `lokoti / sañjānāti / maññati` 三词，中文只呈现为两项，读者数不出三。
- **建议**：「是把『世间』『认作』『思量』这三个词牵引过来」，或「把『…认作世间、思量为世间』一语中的三个词（『世间』『认作』『思量』）牵引过来」。

### §209

`198-209-2-18`
- **问题**：可读性 — 「tāya ito gato patto」译「由它**从这里前往**、到达」，「从这里」无所指，读者不知从何处到何处。这是词源解（paṇḍā → paṇḍita）。
- **建议**：「由慧而行、而到达，所以叫**智者**」，并可补一句说明这是就词源立说。

`198-209-33-53`
- **问题**：术语 — 「只是个**语助词**」。nipāta 现代语法书通行作「不变词／虚词」。
- **建议**：「在第一种解释中只是一个虚词（nipāta）」。另参本报告第一节的必改项，同句后半须改「所解答的那样」为「解答了它」。
