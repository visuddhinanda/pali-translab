# Review — 170:1815-1821（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅 7 句带 nissaya，且多为缩略体：只释出开头几个词，其余标注 `အကြွင်းလွယ်၏၊ နည်းမှီး၍ပေးလေ`，意为“其余易解，照前例补出”）

## 跨段一致性

§1815–§1820 前半与 §1820 后半至 §1821 的译法明显不一致。从 `170-1820-68-73` 起，整套对应词都换了，应统一回 §1815–§1820 前半的译法（覆盖 6 段、出现次数占绝大多数）：

- **ṭhāna**：前面译“理由”，§1820 后半与 §1821 译“点”（“在哪一点上”“就凭这一点”）。建议统一为“理由”。
- **gārayho / pāsaṃso**：前面译“应受责备／应受称赞”，§1820 后半与 §1821 译“应当受到责备／值得称赞”。建议统一为前者。
- **gāmaṇi**（呼格）：前面译“村长”，§1820-86-100 与 §1821 全段译“村长啊”。建议统一为“村长”。
- **kāmabhogī**：前面译“享用欲乐的人”，§1820-86-100 与 §1821 译“享受欲乐的人”。建议统一为“享用欲乐的人”。
- **Ayaṃ … kāmabhogī**：前面译“这个享用欲乐的人”，§1820-86-100 与 §1821 译“这样一个享受欲乐的人”。指示词 ayaṃ 指前面那一个人，“这样一个”不准确。建议统一为“这个”。
- **dhammena … asāhasena**：前面译“以合法的方式、不用粗暴的手段”，§1821 译“如法地、不强横地”。建议统一为前者。
- **saṃvibhajati puññāni karoti**：前面译“分给别人，也做种种福业”，§1820-74-85 与 §1821 译“与亲友分享，也做福德的事”。建议统一为前者。
- **问句 Katamena/Katamehi … ṭhānena …?**：前面译“是因哪一个理由而应受……呢？”，§1820-68-73、§1821-50-54、§1821-84-88 改为“在哪一点上……呢？”。建议统一为前者。
- **引语句 …ti, iminā … ṭhānena …**：前面译“‘……’——因这第 X 个理由而应受……”，§1820-74-85 与 §1821 改为“……——就凭这第 X 点，他……”，并补出主语“他”。建议统一为前者，并去掉补出的“他”。
- **嵌套引号**：整段话已由开头的 “ 起引，段内引语应用单引号 ‘’（§1815–§1820 前半都是这样）。§1820-74-85、§1821-55-64、§1821-65-73、§1821-74-83、§1821-89-103 用了双引号 “”，与外层冲突。**必改**，改为 ‘’。
- **pariyesitvā 分句的重复修饰语**：
  - §1815、§1819、§1820、§1821 把 adhammena／dhammena、sāhasena／asāhasena 在 pariyesitvā 分句里完整重复译出。
  - §1816、§1817、§1818 只用“这样追求到财富以后”概括，dhammādhammena 与 sāhasenapi asāhasenapi 在第二分句没有逐词落实。
  - 建议按 §1815/§1819 体例补全，见下。

## §1816 句 170-1816-2-35

- **问题**：句法／覆盖。
  - nissaya 释 `သာဟသေနပိ= ဖြင့်၎င်း။ အသာဟသေနပိ= ဖြင့်၎င်း။`：两个具格并列，`၎င်း … ၎င်း` 表示“既以……也以……”，是两种手段并举。译文“有时用粗暴的手段，有时不用”把并列具格改成了时间交替，语义大致可通，但偏离 nissaya 的格读法。
  - pariyesitvā 分句里的 dhammādhammena、sāhasenapi asāhasenapi 被“这样”吞掉，nissaya 逐词覆盖时这几个词没有对应。
- **建议**：改为“以合法与非法的方式、既用粗暴也用不粗暴的手段追求财富；以合法与非法的方式、既用粗暴也用不粗暴的手段追求到财富以后，……”。前后两个分句同样展开。

## §1817 句 170-1817-2-31

- **问题**：同 §1816。并列具格 sāhasenapi asāhasenapi 被读成“有时……有时不用”；第二分句的修饰语被“这样”省去。
- **建议**：照 §1816 的改法统一。
- **附记**：本行 nissaya 内容是 `ဓမ္မေန … အသာဟသေန`（dhammena asāhasena），与本句 pali 的 dhammādhammena 不符，属 nissaya 段落错位（见文末）。本句意见依据的是 §1816 行的同类 nissaya。

## §1818 句 170-1818-2-27

- **问题**：同 §1816。并列具格读成时间交替；第二分句修饰语省去。
- **建议**：照 §1816 的改法统一。

## §1821 句 170-1821-2-36

- **问题**：句法与一致性。
  - nissaya 在同类各段均以 `ယွာယံ= သည်`（主格）、`ကာမဘောဂီ= သော`（定语）读作“那个享用欲乐的人”，直接作主语。译文改成“有这样一个享受欲乐的人：他……”，另起存在句并补出主语“他”，结构与 §1815–§1820 不一致。
  - dhammena／asāhasena 改译“如法地、不强横地”，saṃvibhajati 改译“与亲友分享”，都与前文不一致。
- **建议**：改为“村长，在这些人当中，那个享用欲乐的人，以合法的方式、不用粗暴的手段追求财富，以合法的方式、不用粗暴的手段追求到财富以后，让自己快乐、让自己满足，也分给别人，也做种种福业；但他对那些财富贪着、迷醉、耽溺，看不到其中的过患，也不明白如何从中出离，就这样享用那些财富。”

## §1821 句 170-1821-74-83

- **问题**：一致性。“他与亲友分享，也做福德的事——就凭这第三点，他值得称赞”，在引号、主语补出、ṭhāna 与 pāsaṃso 的译法上都和 §1815-70-78、§1818-65-73 的同句不一致。
- **建议**：改为“‘分给别人，也做种种福业’——因这第三个理由而应受称赞。”
- **附记**：本行挂的 nissaya 是下一节苦行者的内容（`တပဿီ … လူခဇီဝီ … တီဟိ … ဂါရယှော`），不对应本句，不作词法依据。

## nissaya 数据问题（记录，不改）

- **§1815 行**：nissaya 为 `ဓမ္မာဓမ္မေန … သာဟသေနပိ … အသာဟသေနပိ`，对应的是 §1816 那一型（合法与非法），与本句 pali 的 adhammena … sāhasena 不符。
- **§1817 行**：nissaya 为 dhammena asāhasena 型，与本句 pali 不符。
- **§1820 行**：nissaya 后半 `စတူဟိ … ဣမေဟိ ဌာနေဟိ … ပါသံသော`（catūhi … pāsaṃso）属于后面第十类欲乐者的结语，不属本段。
- **§1821-74-83 行**：nissaya 属于后文苦行者一节。
- **小结**：本 chunk 的 nissaya 与 pali 段落存在整体错位，加上多为缩略体，可用作词级依据的只有共同开头部分：
  - `ဂါမဏိ= ကြီး`：呼格
  - `တတြ= တို့တွင်`：复数处格“在这些人当中”
  - `ကာမဘောဂီ= သော`：定语
  - `ယွာယံ= သည်`：主语
  - `ဘောဂေ= တို့ကို`：复数宾格
  
  以上各段译文都处理正确。
