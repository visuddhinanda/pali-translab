## 理由

**资源缺失（降信心的主因）**：本次只注入了巴利本文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**，因此「义注定释义、nissaya 定词法」两条基准都无法执行。下列判断仅基于巴利原文语法与常见传统释读，词级覆盖率、格/句法角色、传统取义都未经核对——准确性分数据此保守给出，不代表已通过词级验收。尤其 `itthikāmehi rājā maññe paricārento`（1836）、`rājaverī`（1837-90-111）两处属注释书有明确释读的点，需补义注复核。

**准确性**：十不善业道（1834）名相与句式套用稳定，`yathāpaṭipanno … tañca pajānāmi` 的「知道…是怎样行事，才会…投生」处理合理，未漏 `vipāka` / `tañca` 任何一支。1836 `rañño paccatthikaṃ pasayha jīvitā voropesi`（夺去国王仇敌的性命）与 1837 `rājaverī … tena naṃ rājāno gahetvā`（国王的仇敌→被国王们抓起来施刑）的正反对照译得清楚，赏与罚的因果关系没有译反，这是本段最容易出错的地方。1837 的被动链（`bandhitvā / karitvā / parinetvā / nikkhāmetvā / chijjamāno`）统一用「被人…」串起，主语归属正确。未发现 fatal 或 error 级问题。

**风格**：全段是现代书面汉语，未见文言虚词与文言句式（无「此中/故为/彼等/是故/于…之际」一类）。「投生到苦界、恶趣、堕处、地狱」「身体败坏、死亡之后」属传统固定译名，不计入文言扣分。标点为全角，引号用 “” ‘’，译文内无 ASCII 引号，符合 JSON 安全约束。扣分点在 1834 段首左引号未闭合、1835 又新开一个左引号，读者层面会看到引号悬空。

**一致性**：主要扣分项。1834 用名相形式（偷盗／欲邪行），1835 换成动词短语（拿取没有给予之物／在欲乐上行邪行），巴利原文确实是 `adinnādāna` 与 `adinnaṃ ādiyati` 的形态差别，这样处理站得住，但读者不易看出是同一条业道。另有同一巴利句 `Tamenaṃ evamāhaṃsu` 在同段内按语境译成两种说法（谈论／回答），属有意的上下文化，不算错，但两段之间应有统一口径。
