- 「被解释词与父层逐字同译」这条硬约束**无法核对**——本层是复注，各条黑体被解释词（`Pariyāpādenti`、`Duṭṭhu ṭhapitaṃ`、`Taṃ sandhāya`、`Etaṃ…vuttaṃ` 等）引自义注，其汉译是否与义注层已有译文逐字一致，本次评不了，需在有义注译文时补核。
- 涉及传统取义的判定（如 `Duṭṭhu ṭhapitaṃ` 的被修饰对象、`parajito nirayo` 的专名处理）只给到 suggestion/warning，未按 error 处理。

**准确性**：整体忠实，复注特有的「被解释词＋释义」结构基本都译出来了，`Yujjhanaṃ yodho, so ājīvo etassā`（658-6-13）的析词、`Parehi saṅgāme jitā hatā ettha jāyanti`（658-60-69）的地狱释名都处理得准确、逻辑清楚。扣分集中在两处：`ussāhaṃ vāyāmaṃ` 的「奋战」把「努力／精进」窜成了「作战」，属词义错译；`Taṃ sandhāya` 的被解释词里提前塞进了释义内容「战士」，使随后的解释沦为同义反复，也破坏了与父层逐字同译的前提。

**风格**：语体总体是现代书面汉语，未见文言虚词与文言句式，标点全角、无 ASCII 引号、无残留工作标记，符合 `knowledge/style.md`。扣分在「安放得很糟糕」的口语化用词，以及 658-49-59、658-81-90 两句多层定语／首尾割裂造成的可读性下降。

**一致性**：`yodhājīva`→战士、`yujjhana/yuddha`→打仗、被解释词一律加粗、释义一律用「……，就是……」句式，全段统一。仅编号体例（「三～五、」与「355-357.」）两套写法并存，属体例小瑕。

## 问题清单

### 🟧 error

- `198-658-16-33`｜错译（词义）｜片段「作出奋战、付出努力」
  - 问题：`ussāha` 是「努力、奋发、精勤」，`vāyāma` 是「精进、用功」，两词都在说使力，不含「作战」义；「奋战」把上文的 `yujjhana`（打仗）串进了被解释词本身。结果是被解释词与其释义「以打仗的方式作出奋战、付出努力」重复，读者看不出注释在补充什么。
  - 建议：被解释词作「作出努力、付出精进」，释义作「就是以打仗的方式作出努力、付出精进」——差别落在「以打仗的方式」上，注释的作用才显出来。

- `198-658-73-80`｜错误多译（被解释词掺入释义内容）｜片段「针对那个战士」
  - 问题：被解释词只有 `Taṃ sandhāya`＝「针对那个」，「战士」是释义 `taṃ yodhājīvaṃ puggalaṃ` 才点明的。提前写进被解释词后，全句变成「针对那个战士，就是针对战士那个人说的」，等于同义反复；且复注黑体须与义注原词逐字对应，多译一个词就对不上了。
  - 建议：「**针对那个**，就是针对战士那个人说的。」

### 🟨 warning

- `198-658-49-59`｜关键词语意不明确 / 语体口语化｜片段「安放得很糟糕」
  - 问题：一是「很糟糕」口语，与全段书面语体不谐；二是「安放」在汉语里需要宾语，此处既未出现施动者也未出现受动对象，读者不知道是「什么被安放」，而释义又转成了「所做／行为」，前后对不上。
  - 建议：改为「安置得不好」或依上下文的受动对象显化（如「安立得不正」），并在有义注译文时与父层用词对齐。

- `198-658-81-90`｜整句逻辑表达不规范｜片段「这就是所**说的**」
  - 问题：`Etaṃ … vuttaṃ` 是一头一尾夹住释义的被解释词，译文把它拆成「这句话」与「这就是所说的」两截，中间插入释义后再补尾巴，读来重复拗口，末句几乎不承载信息。
  - 建议：合并为一句，如「**这**，是指以“凡是那个……”开头的那段经文，**这样说的**。」或直接「**所说的这句话**，是指以“凡是那个……”开头的那段经文。」

### 🟦 suggestion

- `198-658-49-59`｜复杂嵌套句整句理解困难｜片段「就是以恶劣的方式所做、没有达到能给自己和他人带来利益的状态的那种行为」
  - 问题：三重定语连用后再收一个「的那种行为」，句子重心被推到最末，对读者不友好。
  - 建议：拆成两小句，如「就是以恶劣的方式所做的行为，没有达到能给自己和他人带来利益的状态」。

- `198-658-60-69`｜不常用术语宜加注｜片段「名为“战败”的地狱」
  - 问题：`Parajita` 是地狱专名，首次出现只给意译，读者无从回查。
  - 建议：按 `style.md` 术语策略夹注巴利原词——「名为“战败”（parajita）的地狱」。

- `198-658-70-72`｜语言表达可提升｜片段「锤」
  - 问题：`gadā` 传统汉译多作「棒／杵」，「锤」易与 mudgara 一类混淆，且五武器并列时宜用较通行的对译。
  - 建议：考虑作「棒」或「铁棒」。

- `198-658-95-104`｜代词指代可能不够明确｜片段「这正是第三经中所说的那个道理」

  - 建议：点明「第三经（即《战士经》）」。

- `198-658-2-5`｜语言风格不统一｜片段「355-357.」

  - 建议：统一体例（经号保留阿拉伯数字可以，但连接号与句点宜与全段标点规范一致）。
