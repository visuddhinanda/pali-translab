## 跨段一致性

- **sāmisa / nirāmisa（必改）**：§646 一律译「有染 / 无染」（且黑体处已被父层锁定为「有染的」），§647 却改译「有欲染的 / 无欲染的」——同一 chunk 内同一巴利词两套译法，读者会误以为是两个概念。
  - 建议：§647 统一为「有染的 / 无染的」，即「……才叫做有染的；……就叫做无染的」。
  - 依据：本层黑体被解释词已定「有染的」（136-646-2-11），且父层定义句 170-1415-2-24 起至 170-1422-37-44 全用「有染 / 无染」，出现次数占优。

- **父层自身漂移（需在 harmonize 阶段回修父层，本层不作改动依据）**：父层 170-1415～1422 用「有染 / 无染 / 更加无染」，到 170-1423～1426 改用「有欲染 / 无欲染 / 无欲染中更无欲染」，同一经内前后不一。§647 现译法正是跟随了父层后半段的漂移。建议 harmonize 时把父层 §1423-1426 统一回「有染 / 无染 / 比那无染的…更加无染」，届时本层 §647 自然对齐。**在父层未改定前，本层仍应以黑体锁定的「有染 / 无染」为准。**

## §646 句 136-646-39-52

- **问题**：误译（力度失真）— `pādena paharanto` 是「用脚踢（踹）」，`paharati` 为击打义；现译「用脚碰撞到」弱化为无意的接触，比喻失去了「恃宠而骄、公然无礼」的意味。
- **建议**：改为「即使用脚踢到长者、大将军这些人」。

- **问题**：术语 — `seṭṭhi` 现译「大富商」。南传常见汉译作「长者」（巨富居士之通称），且与下文「大将军」并列时更合体例。
- **建议**：「大富商」→「长者」。

- **问题**：增译 — `rājakulaṃ pavisanto` 只说「进入王宫」，译文作「进出王宫」多出「出」。
- **建议**：改为「不用通报就能随意进入王宫」。

## §647 句 136-647-2-16

- **问题**：术语不一致（必改，同「跨段一致性」第一条）— 「有欲染的 / 无欲染的」应改为「有染的 / 无染的」。
- **建议**：「……正是就它自身所缘的色这种染着而言，才叫做有染的；以无色为所缘的解脱，因为没有色这种染着，就叫做无染的。」

- **问题**：行文冗赘 — 「以色为所缘的解脱，正是就它自身所缘的色……」中「所缘」连出两次，读来绕口（原文 `attano ārammaṇabhūtena` 确为「作为自己的所缘」，可保留但宜换说法）。
- **建议**：「……的解脱，正是因为作为它自身所缘的色这种染着，才叫做有染的」。
