# Review — 170:536-547（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位无法独立校验）／义注 ✅（书 136 §159-167，对应段齐全）
> 本层为本文（mūla），无父层被解释词可核。反向核对义注黑体引词（**Ācinato** / **Sati muṭṭhā** / **Tañca ajjhosā** / **Abhijjhā ca vihesā cā** / **Cittamassūpahaññatī** / **Paṭissato** / **Sevato cāpi vedanaṃ** / **Khīyatī** / **Ārā nibbāna vuccatī**）在本文均有落点，重复句（536 ≡ 541）译法一致。

## 跨段一致性

- **dhamma（作六尘之一）**：§537「了知了法」、§539「从法生起的」。本组偈颂与 §542「看见色」、§547「听见声」是同一系列的六根门，`dhammaṃ ñatvā` 是意门认知法尘，与 `rūpaṃ disvā` / `saddaṃ sutvā` 严格平行。现译「了知了法」「从法生起」会被读成"了知佛法""从佛法生起" → 建议统一译为「法尘」或「（意的对象）法」，如「认知法尘之后」「从法尘生起的」。依据：偈颂六门排比结构 + 义注对本经的整体判语（**义注**：`Iti imasmiṃ sutte gāthāhipi vaṭṭavivaṭṭameva kathitaṃ` — 偈颂讲的是轮回与还灭，即六门的染净两分）。
- **ajjhosa tiṭṭhati**：§538 译「执取着它不放」，§543 译「不执取它不放」 → 否定式直接套用肯定式措辞，成了病句（见下）。建议统一为「执取它而停住」／「不执取它、不停住于它」。
- **apacinato / khīyati**：§545 `khīyati` 译「消减」，§546 `apacinato` 译「灭除」 → 两词轻重倒置，且 `apacinato` 与 §536/541 `ācinato`「积聚」是同一词根的正反对，译文未对仗。建议 `apacinato` 译「不再积聚／消减」，`khīyati` 译「灭尽」。
- **paṭissato / sato**：§542、§547 `paṭissato` 与 §545 `sato` 同译作「保持正念」，两词区别被抹平。**义注**：`**Paṭissato**ti paṭissatisaṅkhātāya satiyā yutto`（具足称为"随念"的念）。建议 `paṭissato` 译「保持随念」或「时时正念」，`sato` 保留「具念／带着正念」。
- **nibbānamuccati**（536/541/546）：三处一致地略去了被动的"被说为"。**义注**：`**Ārā nibbāna vuccatī**ti evarūpassa puggalassa nibbānaṃ nāma dūre pavuccati`（对这样的人，涅槃被说为遥远）。现译「离涅槃还很遥远」作为偈颂读法可接受，但若要贴义注，宜作「就说这样的人离涅槃很远」。至少三处保持现状的一致，不必分头改。

## §537 句 170-537-2-13

- **问题**：取义（首要） — `Dhammaṃ ñatvā` 译作「了知了法」。本颂是六门系列的意门一颂，`dhamma` 指意所缘的法尘，与 §542 `rūpaṃ disvā`、§547 `saddaṃ sutvā` 平行；译作「了知了法」会让读者误解为"了知佛法"，与偈颂讲染污生起的脉络相反（既已了知佛法，何以"失掉正念、作意可爱相"）。
- **建议**：改为「认知法尘之后却失去了正念」或「意识到法（意的对象）以后，正念却失落了」。
- **问题**：添加转折 — 原文无 `pana` 一类转折词，「却」是译者加的。若已按上条改为"法尘"，转折反而合理（认知后本应具念）；保留「却」需自觉是补出，不再额外加「了知了」的完成感。
- **建议**：`sati muṭṭhā` 依 **义注**`**Sati muṭṭhā**ti sati naṭṭhā`（念失去了）作「正念失落」即可，现译「失掉了正念」无误。

## §538 句 170-538-2-8

- **问题**：风格（翻译腔） — 「内心染着地感受它」中「染着地」是把 `sārattacitto`（有贪染之心者，持有格复合词作主语同位语）硬转成副词，不是自然的现代汉语。
- **建议**：「他怀着贪染的心去领受它」。
- **问题**：语义重复 — 「执取着它不放」中「执取」已含不放，且 `ajjhosa tiṭṭhati` 的 `tiṭṭhati` 是"停住/持续"。**义注**：`**Tañca ajjhosā**ti taṃ ārammaṇaṃ gilitvā`（把那个所缘吞没）。
- **建议**：「并且吞住那个所缘、停在那里」或「并且执取着那所缘而住」。同时把「它」明确为「那个所缘／那个相」，现译的「它」跨段回指 §537 的「可爱的相」，偈颂分行后指代不清。

## §539 句 170-539-2-10

- **问题**：取义 — 「都是从法生起的」同 §537，`dhammasambhavā` 的 `dhamma` 是法尘。
- **建议**：「他的种种感受不断增长，都是从法尘生起的」。

## §540 句 170-540-2-8

- **问题**：取义（义注主解／异解取反） — 现译「贪欲和恼害也随之增长，他的心因此受到伤害」把 `abhijjhā ca vihesā ca` 当成 `vaḍḍhanti` 的主语，这是**义注的异解**，不是主解。**义注**：`**Abhijjhā ca vihesā cā**ti abhijjhāya ca vihiṃsāya ca`（= 具格：因贪欲、因恼害），并在 §167 明确 `**Cittamassūpahaññatī**ti abhijjhāvihesāhi assa cittaṃ upahaññati`（他的心被贪欲和恼害所损害）。主语作主语的读法义注是以 `Atha vā ... "tassa vaḍḍhantī"ti padenāpi saddhiṃ yojetabbaṃ` 引出的第二解。
- **建议**：主译取具格 —「由于贪欲和恼害，他的心受到损害」；异解（"这两法也在他身上增长"）依 `style.md` 第四节作脚注备列。现译把两解各取一半拼在一起，还用「因此」把因果指向前句的"增长"，两边都不合。
- **建议**（措辞）：`upahaññati` 依义注是"被损坏/被扰乱"，「受到伤害」偏日常化，可作「受到损害」。

## §543 句 170-543-2-8

- **问题**：必改 — 「并且不执取它不放」是病句：否定式照搬了 §538 的「执取着它不放」，两个否定叠在一起，读者无法判定是"不执取"还是"不放"。
- **建议**：「也不执取它、不停住于它」或「并且不吞住那个所缘、不停在那里」，与 §538 改后的措辞成正反对。
- **问题**：风格（翻译腔） — 「内心离染地感受它」同 §538。
- **建议**：「他以离染的心去领受它」。

## §544 句 170-544-2-11

- **问题**：取义（义注给出所指） — `sevato cāpi vedanaṃ` 现译「也在体验感受的时候」，未反映义注对此处 `vedanā` 的限定。**义注**：`**Sevato cāpi vedanan**ti catumaggasampayuttaṃ nibbattitalokuttaravedanaṃ sevantassa`（受用与四道相应而生起的出世间受）。偈颂正文直译"感受"本身不算错，但读者会默认是前半染污段的同一种受，恰好相反。
- **建议**：正文保留「领受感受」不加料，**加脚注**注明义注判为"与四道相应的出世间受"；或作「也在领受（出世间的）感受时」。此句 `confidence` 相应下调。

## §545 句 170-545-2-9

- **问题**：漏出义注补出的主语 — `khīyati` 无主语，译文补作「苦」。**义注**：`**Khīyatī**ti khayaṃ gacchati. Kiṃ taṃ? Dukkhampi kilesajātampi.`（灭尽的是什么？苦，以及烦恼类）。现译只补"苦"，漏掉"烦恼"。
- **建议**：「苦和烦恼都只会灭尽而不会积聚」。
- **问题**：风格（半文半白） — 「他就这样保持正念而行」中的「而行」是文言句式，`style.md` 第一节明令避免单音节文言词与文言句式。
- **建议**：「他就这样带着正念生活」或「他就这样时时具念地行走坐卧」（`carati` 此处即"行持、生活"）。

## §546 句 170-546-2-8

- **问题**：对仗与轻重 — `apacinato` 是 `ācinato`（§536/541「不断积聚」）的反义，现译「逐渐灭除」既丢了对仗，又比原词重（灭尽是 §545 的 `khīyati`）。
- **建议**：「这样不再积聚痛苦的人，离涅槃已经很近了」，与 §536/541 构成正反对。

## §542、§547

- 与义注一致，`paṭissato` 见跨段一致性一节的措辞建议，无其他问题。

## 原文疑问

- 无。§536 与 §541 pali 完全相同，是偈颂叠句，非重复录入错误。
