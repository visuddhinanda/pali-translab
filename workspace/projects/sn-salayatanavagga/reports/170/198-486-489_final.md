## 理由

**资源缺失说明**：本次评估仅注入了复注（ṭīkā）原文与待评译文，**未注入对应的义注（aṭṭhakathā, SN-a 1.1 Samādhisuttavaṇṇanā）正文，也未注入 nissaya**。而本段复注的性质是逐句摘引义注词句加以疏解——译文中所有加粗片段（`upacārena vā appanāya vā samāhito`、`samudayasaccavasena pajānāti`、`nittaṇho`、`catubhūmakadhammaparicchedo vutto` 等）都是**义注原文的引文**，按硬约束「被解释词与父层逐字同译」，这些片段必须与义注层译文逐字一致。**本次无法核验这一条**，这是信心指数只给 68 的主要原因。下列判断只能依据复注自身文本的内部一致性、巴利词法与教理常识作出。

**准确性**：主体释义方向正确。三受、苦谛遍知、集谛（taṇhā-avijjā-kamma-phassa 等 uppattikāraṇa）、nibbāna 为 vedanānirodha、khayagāmī、nicchāto 的词源解释、sabbasaṅgāhika 与 catubhūmaka 诸法，均与阿毗达摩及义注通说相合。扣分集中在三处：`Yatthā` 的释义处理（见 error 1）、`nicchāto` 词源句中 `kāmānaṃ pātukāmatāvasena` 的对译（见 error 2）、以及 `sātisayasamādhāna` 译作"格外殊胜的内心专注"虽可通但与后文"内心专注"的术语层级未拉开（见 warning）。

**风格符合度**：整体是现代书面汉语，无"此中/彼等/是故"类文言腔，达到 `style.md` 第一节的底线。扣分在两点：一是「**依苦谛**，就是以苦谛的性质而言」中的"而言"与"就是以…的性质"略带半文半白的注疏腔；二是标点上出现了 ASCII 逗号与直角引号的混用问题——经逐句核对，译文引号全部为全角 “”，未见 ASCII 引号，这一条**合格**，`zh` 字段 JSON 安全无风险。此外术语夹注（saccābhisambodha / parijānana / sabhāvadhamma / catubhūmaka）的使用是恰当的，但 `khayagāmī`、`nicchāto` 这两个本段重点疏解的词反而没有夹注原词，详略失衡。

**一致性**：`vedanā` 统一作"各种感受/感受"，`nirodha` 统一作"息灭"，`samāhito` 统一作"内心专注"，`sampajāno` 统一作"有正知"，`sato` 统一作"有正念"，`Tenāha` 三处统一作"因此注释者说"——跨句一致性良好。唯一不统一处是 `samudaya` 在 `198-488-48-53` 译作"集"、在同句内又展开为"产生原因"，而 `198-488-54-62` 的引文作"集谛"，衔接尚可接受。

**关于"注释者说"**：`Tenāha` 直译为"因此他说"，主语按复注体例指义注作者（aṭṭhakathācariya）。译文补出"注释者"是合理的显化，与 `style.md`「不擅自补足省略主语（除非语义必须）」的例外相符——此处不补主语会让读者误以为是世尊说的，属"语义必须"。不扣分。

## 问题清单

### 🟧 error

- `198-488-63-75`｜错译（词义）｜片段「**地方**，就是以什么为因缘」
  - 问题：`Yattha` 在此被复注释为 `yaṃnimittaṃ`（以什么为因缘），即复注明确指出这个 `yattha` **不是**处所义，而是原因/依据义。译文把被解释词 `Yatthā` 译成"**地方**"，等于把复注要纠正的那个误读写进了正文，随后又接"就是以什么为因缘"，自相矛盾。被解释词的译法应服从其在义注/复注中被给定的释义（此处是"在何处/依何者"指向 nibbāna 作为依据），而非孤立取字典首义。
  - 建议：被解释词改译为体现依据义的形式（如"**在何处**"并让下文的"以什么为因缘"自然承接，或直接作"**依何者**"），使"被解释词—释义"链条自洽。同时核对义注层该词的译法，保持逐字同译。

- `198-488-91-104`｜错译（修饰关系）｜片段「因为它以渴饮诸欲的方式转起」
  - 问题：`kāmānaṃ pātukāmatāvasena pavattanato` 中 `pātukāmatā` = `pātuṃ`（饮）+ `kāmatā`（欲求），即"想要饮用（诸欲）的状态"，`kāmānaṃ` 是 `pātu-` 的宾语属格。译文"渴饮诸欲"把"想要饮"压缩为"渴饮"，丢失了 `-kāmatā`（欲求状态）这一层，且"渴饮"一词在现代汉语中不成词，读者难以确知是"渴望饮用"还是"饥渴地饮"。此处正是复注解释 `chāta`（饥渴）取譬的关节，词义须精确。
  - 建议：改为"因为它以想要饮用诸欲的状态而转起"或"因为它表现为对诸欲的饮求"，把"欲求"一层还原出来。

### 🟨 warning

- `198-488-2-35`｜关键词语意不明确｜片段「必须以格外殊胜的内心专注为前提」
  - 问题：`sātisaya-samādhāna` 的 `samādhāna` 与下文被解释的 `samāhito`（内心专注）同根，复注正是要说明"了知诸受"以一种**更高程度的** samādhāna 为前提，因而世尊才用 `samāhito` 一词。译文两处都作"内心专注"，读者看不出"格外殊胜的内心专注"与引文"内心专注"是同一个词的程度差，论证链条（因为需要 X 的加强形态，所以世尊说 X）被抹平。
  - 建议：在"格外殊胜的内心专注"后夹注巴利原词（samādhāna），使其与 `samāhito` 的同源关系对读者可见。

- `198-488-84-90`｜关键词语意不明确｜片段「这里说的就是**通向灭尽的**道路」
  - 问题：`taṃ khayagāminaṃ` 中的 `taṃ` 是复指前文所释之词的指示代词（对格），复注在此只是把定义式 `khayaṃ gameti → khayagāmī` 回扣到义注原文里出现的对格形 `khayagāminaṃ`，并未指明所修饰的是"道路"。译文补出"道路"是一个未加标注的实词增补；`khayagāmī` 在《定经》语境中所修饰的对象需与义注核对（通常承 `maggaṃ` 或承受者），不宜在复注层径自坐实。
  - 建议：或改为不坐实的形式（"这里说的就是那个**通向灭尽的**"），或在核对义注后确认所修饰词再补，并保持与义注层译文一致。

- `198-488-41-47`｜不导致误解的汉语语病｜片段「就是以苦谛的性质而言」
  - 问题：「以…的性质而言」是半文半白的注疏腔，且"而言"与后半句"意思是以遍知的方式"的句式不平行，读起来像两截。
  - 建议：改为"就是作为苦谛"或"就是就它的苦谛性质来说"，与后半句句式拉齐。

- `198-488-91-104`｜代词指代不明确｜片段「在这个人身上不再有饥渴」
  - 问题：`natthi etasmiṃ chātaṃ` 的 `etasmiṃ`（处格）指代对象在原文中未显化，可能指人，也可能指其相续/身心。译文径自坐实为"这个人"，且前文主语一直是"渴爱"，读者读到"这个人"会有主语跳跃感。
  - 建议：改为"在他身上"并确保上文已出现承指对象，或用"在其中"保留原文的不确定度。

  - 建议：作"没有饥渴的（nicchāta）"，并核对该词在义注层的译法。

- `198-488-117-129`、`198-488-130-141`、`198-488-142-152`｜语言表达不够流畅｜片段「而用另外两句讲的只是对四谛的觉悟」

- `198-488-63-75`｜语言表达不够流畅｜片段「也就是依靠什么而由欲爱、无明等的息灭带来感受的息灭」

  - 建议：拆为两小句，如"也就是依靠它，欲爱、无明等得以息灭，从而带来感受的息灭"。
