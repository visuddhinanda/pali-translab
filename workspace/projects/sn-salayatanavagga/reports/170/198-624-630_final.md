## 理由

**基准缺失说明（重要）**：本次任务只注入了复注（ṭīkā）巴利原文与目标 channel 译文，**未提供义注（aṭṭhakathā）文本，也未提供 nissaya**。按方法文档，评估应「义注定释义、nissaya 定词法」；两者皆缺，只能降级为「巴利原文 + 上下文 + 术语表」核对。因此：

- 凡涉及**术语取义**（如 `pariggaha`/`dassana`、`saṅkhāranimitta`、`vikappa`）的判定，只给出语言层面的问题，不对「是否与义注相符」下结论；
- 复注大量黑体词是从义注原样引来的被解释词，**无法核验「与父层逐字同译」这条硬约束**。这是本次信心指数偏低的主因（扣约 25 分）。建议补齐义注后就 624–628 的黑体引语重跑一次评估。

**准确性**（84）：无违背教理原则的错误，无漏译，段落与句子切分严格跟随原文，主谓宾判断整体正确，术语体系（灭尽定 / 果定 / 有分 / 空·无相·无愿 / 道·果 / 随观智）稳定可靠，长复合词（`soḷasa ñāṇacariyā`、`anavasesaggahaṇalakkhaṇa`、`paṭippassaddhasabbussukka`）都拆解到位。扣分集中在三处：一是 `soḷasahi ñāṇacariyāhi` 的具格被译成介词「对」，与同段并列的「九种定行」体例相左；二是 `saṅkhāranimitta` 译作「行相」，与汉传既有术语（ākāra）撞车，属于会导致误解的译名；三是若干增译（「四道四果」「何必深究」「在运用唯作心的」）虽多属正确补足，但原文无对应成分。

**风格符合度**（79）：主体是合格的现代书面汉语，「暂且不谈」「怎样确定下来的」「为什么这样说呢」等处理得当，未出现「此中／故为／彼等／是故」一类典型文言腔，标点全角、引号全角、无 ASCII 引号（JSON 安全项通过），译文中也**未发现任何候选/待定/问号等工作标记**。扣分在半文残留与语病：「偏趋」「揭除」属非现代常用词，「就其自身的性质」用了文言虚词「其」，「就是八种等至是八种定行」「就只能说成三者取一的说法」「这里说的正是就有分心的时候而说的」是明显的汉语冗赘或双动词叠用。另有一处疑问句后用逗号收尾的标点问题。

**一致性**（85）：术语与句式模板在七段间基本统一，`X nāma Y` 的「叫作……因为……」格式贯穿 627–628 未走形，`phalasamāpatti`→「果定」、`assāsapassāsa`→「入息出息」全程一致。扣分点：同类引语式 lemma（`Dvīhi balehīti` / `Soḷasahi ñāṇacariyāhīti` / `Navahi samādhicariyāhīti`）三者处理方式不一，只有中间一条加了介词「对」；624-2-5 内部「不过这段」与「那段」近指远指混用；`vaṇṇanā` 类引文的来源标注（「经文说的是」）与实际所引层次不符。

## 问题清单

### 🟧 error

- `198-624-19-32`｜错译（格 / 修饰关系）｜片段「对十六种智行」
  - 问题：`Soḷasahi ñāṇacariyāhi` 是具格，与下句 `Navahi samādhicariyāhi`、前句 `Dvīhi balehi` 完全平行，表「以……（而成就）」。译作介词「对」改变了句法角色，且同段另两条并未加介词，体例自相矛盾。
  - 建议：统一为「以十六种智行」或与另两条一致地直接作「十六种智行」。

- `198-627-50-58`｜导致误解的表达｜片段「行相」
  - 问题：此处 `saṅkhāranimitta` 指「诸行之相」（与 `rāganimitta` 并列作为被无相果定所无的相）。但「行相」在汉传佛教文献中是 ākāra 的固定对译，读者极易误读为「认识的行相」，与原意无关。
  - 建议：改作「诸行的相」或「行之相」，避免与既有术语撞名。

### 🟨 warning

- `198-624-19-32`｜关键词语意不明确（方法文档点名的二意词）｜片段「这十六种智的转起」
  - 问题：「转起」（pavatti）在全篇多次出现（624、626、628、629 各段），属二意场合且无注释，普通读者无从判断是「生起」「持续运作」还是「流转」。
  - 建议：首次出现处夹注巴利原词并加一句简注，其后沿用；或统一改为「生起并持续」一类明义译法。

- `198-624-33-49`｜不导致误解的汉语语病｜片段「就是八种等至是八种定行」
  - 问题：一句内两个判断动词「就是……是……」，句子失衡。
  - 建议：改为「八种等至就是八种定行」。

- `198-624-80-97`｜标点符号使用错误｜片段「进入这种定的呢」
  - 问题：疑问语气已由「呢」收束，后面却直接接逗号连到「所以说了」，疑问句没有收尾标点。
  - 建议：改为「……进入这种定的呢？所以说了……」。

- `198-627-2-8`｜代词指代不明确｜片段「这是就作为所缘的东西而说的」
  - 问题：「这」既可指「空触」这个说法，也可指所缘本身；「东西」过于口语且含糊，未点明所缘是什么。
  - 建议：改为「这是就它作为所缘而说的」，并明确「它」所指。

- `198-627-2-8`｜文言语体｜片段「就其自身的性质来说」
  - 问题：文言虚词「其」，`knowledge/style.md` 第一节列为禁例。
  - 建议：改为「就它自身的性质来说」。

- `198-628-2-15`｜整句逻辑表达不规范｜片段「来路在这里，或者说凭它而有来路」
  - 问题：这是词源析义（`āgamanaṃ ettha, etāya vā`），直译成「来路在这里」在汉语中不成句，读者无法看出这是在拆解构词。
  - 建议：改为「因为来路在它这里，或者说因为凭着它而有来路，所以叫作……」。

- `198-628-21-25`｜非现代常用词（半文半白）｜片段「揭除了常的相」
  - 问题：「揭除」非现代书面汉语常用搭配。
  - 建议：改为「破除了常的相」或「去掉了常的相」。

- `198-628-26-34`｜关键词语意不明确｜片段「不是把握和见」
  - 问题：`pariggaha`（遍取／把握）与 `dassana`（见）在此是观禅阶段的专名，光写「把握和见」读者无从索解。
  - 建议：夹注巴利原词，或译作「不是（观智的）遍取与见」。

- `198-628-40-46`｜表达不清｜片段「清楚地见到了空无众生」
  - 问题：`sattasuññatāya sudiṭṭhattā` 是「（因）众生空性被善见」，译文的「空无众生」像在说一个空荡荡的场景，且主语被处理成主动的「它」。
  - 建议：改为「因为清楚地见到了没有众生这一点（众生空）」。

- `198-628-57-67`｜不导致误解的汉语语病 + 增译｜片段「就只能说成三者取一的说法」
  - 问题：「说成……的说法」叠用；且「三者取一」是译者补出的解释，原文 `vikappo` 只是「（名称）成了不确定的或然之说」。
  - 建议：改为「名称就会变得不确定」，把「三者取一」的解释放到注释或去掉。

- `198-628-111-121`｜关键词语意不明确｜片段「三重的触在接触」
  - 问题：`tividho phasso`（单数，一触而有三种）译作「三重的触」，与上文「三种触」的对照关系反而被遮蔽，读者看不出这句反证的着力点。
  - 建议：改为「一种具三相的触在接触」或「三种的触（单数）在接触」，并保证与上句「三种触会接触」形成可见的对比。

- `198-629-7-22`｜非现代常用词｜片段「倾斜、偏趋」
  - 问题：`ninna-poṇa` 是固定套语，「偏趋」为生造词，非现代汉语。
  - 建议：改为「倾向、趣向」或「一心倾向」。

- `198-629-7-22`｜代词指代不明确｜片段「它就是四蕴的不转起，以毫无遗漏地摄取为特相」
  - 问题：`anavasesaggahaṇalakkhaṇaṃ` 形态上既可修饰 `appavattiṃ` 也可修饰 `nirodhasamāpattiṃ`（同为阴性宾格），但译文拆成两个并列小句后，「以……为特相」的主语变得含糊，读起来像在说灭尽定而非那个「不转起」。缺义注无法定夺取哪一读，故只按表达问题记。
  - 建议：合并为「才会进入以四蕴毫无遗漏地不转起为特相的灭尽定」，或明确补出主语。
