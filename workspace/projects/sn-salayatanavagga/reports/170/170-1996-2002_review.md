# Review — 170:1996-2002（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未注入，词级格位核对无法进行，格/数判定仅据巴利原文）／义注 ✅（book 136, §791-792，仅覆盖 kutūhalasālā、dūrampi gacchati、imañca kāyaṃ nikkhipati、anupapanno hoti 四处）

## 跨段一致性

- **upapatti / upapanna / anupapanna**：§1998、§1999、§2000 译「转生」（「转生之处」「某人转生在某处」），§2001 译「再生」（「有取的才会再生」），§2002 译「投生」（「还没有投生到另一个身体」）。同一词根在同一经内三译并存，而 §2001-2002 正是在回答 §1998-2000 提出的问题，译名断了读者才看得出的呼应。→ **必改，统一为「投生」**：§1998/1999/2000「记说他投生的地方」「某人投生在某处」，§2001「我说有取的才会投生」，§2002 维持「还没有投生」。依据：义注释 `anupapanno hoti` 为 `paṭisandhicittassa anuppannattā`（结生心未生起），指的就是同一个投生事件。
- **upādāna**：§2001-32-43 火喻译「燃料」（「火有燃料才会燃烧」），§2001 正文与 §2002 全部译「取」（「以风为取」「以渴爱为取」）。原文火喻与法义用的是同一个 upādāna，一词双关正是此经论证的枢纽；分译成两个词，读到 §2002「火焰以风为取」时，读者无法接回 §2001 的「燃料」。→ **必改**：火喻处改为「火有取（即燃料）才会燃烧，没有取就不会」，或「火有燃料（upādāna，即“取”）才会燃烧」，让双关显形。
- **kaṅkhā / kaṅkhanīya**：§2000「产生了疑惑」、§2001「产生疑惑是应该的」，但 §2001-14-21 的 `kaṅkhanīye ṭhāne` 译「应当怀疑的地方」。同词根换词。→ 建议统一作「应当疑惑的地方」。

## §1998 句 170-1998-2-22

- **问题**：背景/义注 — 「聚集在好奇堂里」易让读者以为有一座专名叫「好奇堂」的建筑。**义注**：`kutūhalasālā nāma paccekasālā natthi, yattha pana nānātitthiyā samaṇabrāhmaṇā nānāvidhaṃ kathaṃ pavattenti, sā bahūnaṃ “ayaṃ kiṃ vadati, ayaṃ kiṃ vadatī”ti kutūhaluppavattiṭṭhānato kutūhalasālāti vuccati.`——并没有一座单独的「好奇堂」，是各派沙门婆罗门在那里各说各话、众人好奇「这个说什么、那个说什么」，所以那地方被叫作好奇堂。
- **建议**：译名「好奇堂」保留（与义注得名之由一致），但加译者注点明「不是专设的厅堂，而是各派论议聚谈之处，因众人好奇而得名」。译名须与 §1996 经名「好奇堂经」保持一致，将来译义注时 `kutūhalasālāyaṃ` 也必须逐字用「好奇堂」。
- **问题**：`nānātitthiyānaṃ` 译「不同外道的」。义注作 `nānātitthiyā`，意为「各种（教派的）外道」。
- **建议**：改「各种外道的沙门、婆罗门、游方者」。

## §1998 句 170-1998-40-46

- **问题**：数不一致 — `sāvakaṃ` 是单数，译文「对已经去世、命终的弟子记说他们的转生之处」，前半「弟子」后半「他们的」，读来像一次记说多名弟子。§1999-68-74、§2000-20-26 三处同文，同一问题。
- **建议**：三处一并改为「他也会记说某个已经去世、命终的弟子投生的地方」。

## §1999 句 170-1999-2-67

- **问题**：译名规范 — 「尼乾子·若提子」。`nigaṇṭha` 是教派名（尼乾／尼乾陀），`nāṭaputta` 是其人（若提子／亲子），中间加间隔号会让「尼乾子」被误读成一个人名，且与「子…子」重复。
- **建议**：改「尼乾陀·若提子」或「尼乾若提子」。其余五师译名（富兰那·迦叶、末伽梨·瞿舍梨、删阇耶·毗罗胝子、波拘陀·迦旃延、阿夷多·翅舍钦婆罗）无问题。
- **问题**：`…pe…` 译「乃至」，是文言省略套语，与 `style.md` 第一节「必须现代汉语」的总原则相抵。
- **建议**：改「……（中略）……」或「……（下同）……」。若项目决定沿用佛典惯例「乃至」，请登记进 `knowledge/terms.md` 备案，避免每轮重复争议。

## §1998/1999 句 170-1998-58-70、170-1999-86-98

- **问题**：半文言 — 「最上之人、最高之人」（`uttamapuriso paramapuriso`）。「之人」是文言构词。
- **建议**：改「最上等的人、最高的人」，或取传统术语「最上士、最胜士」并首次夹注巴利原词；两者择一，勿混用。

## §2000 句 170-2000-79-92

- **问题**：取义偏软 — `sammā mānābhisamayā` 译「由于彻底地看透我慢」。`abhisamaya` 是「现观、贯通」，`sammā` 是「正确地／完全地」，不是程度副词「彻底」。
- **建议**：改「由于完全洞察了我慢」或「由于正确现观我慢」。
- **问题**：`vivattayi saṃyojanaṃ` 译「解开了结缚」，`saṃyojana` 尚未登记在 `term-glossary.jsonl`。
- **建议**：译法本身可用；定案后补进术语表（「结」或「结缚」二选一），避免后续章节漂移。

## §2000 句 170-2000-93-105

- **问题**：`ahu deva kaṅkhā` 实为 `ahudeva`（ahu + eva），`eva` 是强调「确实就生起了」；译文「因此我心里就产生了疑惑」把 `eva` 化入了「就」，可接受，但「因此」是原文所无的因果连词（`tassa mayhaṃ` 只是承接性属格）。
- **建议**：改「乔达摩先生，我心里于是生起了疑惑，生起了犹豫——」。

## §2002 句 170-2002-59-90、170-2002-91-113

- **问题**：指称错误（必改）— 主语是 `satto`（有情），译文却用「它」：「乔达摩先生认为这时它以什么为取呢」「我说它这时是以渴爱为取」。有情指人，中文不能用「它」。§2002 前半说火焰用「它」没问题，正因为如此，后半沿用「它」会让读者误以为仍在说火焰，恰好丢掉了从火到有情的类比转折。
- **建议**：改「这时他以什么为取呢」「我说他这时是以渴爱为取」「因为那个时候渴爱就是他的取」。
- **问题**：义注核对（通过）— **义注**：`Imañca kāyaṃ nikkhipatīti cuticittena nikkhipati`（以死心舍弃）、`Anupapanno hotīti cutikkhaṇeyeva paṭisandhicittassa anuppannattā anupapanno hoti`（就在死的刹那，因结生心尚未生起而未投生）。译文「舍弃了这个身体，还没有投生到另一个身体」与义注一致 ✅。将来译义注时，`nikkhipati` 须逐字用「舍弃」、`anupapanno` 须逐字用「没有投生」，不得改用「舍去／未受生」等。

## §2002 句 170-2002-2-27、170-2002-28-45

- **问题**：义注补出的背景未见于译文 — **义注**：`Dūrampi gacchatīti yāva ābhassarabrahmalokā gacchati`（远到光音天）。译文「飘到很远的地方」字面无误，但义注给出的「远」有确指。
- **建议**：正文维持「飘到很远的地方」（本文用的就是泛指的 `dūrampi`），加脚注注明「**义注**：远至光音天（ābhassara 梵天界）」。
- **问题**：称谓冗余 — 「乔达摩先生，当火焰……时，乔达摩先生认为这时它以什么为取呢？」一句内两次「乔达摩先生」（呼格 `bho gotama` + 敬体第三人称 `bhavaṃ gotamo`）。巴利敬语如此，中文重复读来滞涩。
- **建议**：后一处改「您认为这时他／它以什么为取呢」。§2002-59-90 同。
