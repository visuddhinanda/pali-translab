# Review — 170:675-682（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入）。本次仅凭巴利原文与现有译文审查，**释义标准与词级基准均缺**；凡涉及传统取义的判断（尤其 `saṃyojaniya` / `upādāniya` 的动词方向、`anabhijānaṃ` 一组现在分词的主语归属）只能列为待核项，需取义注与 nissaya 后复核。父层（义注）未注入，**被解释词逐字对照一项本次无法执行**。

## 跨段一致性

- `saṃyojaniya` / `upādāniya`：§676 译「可被结缚的法」，§678 译「可被取着的法」——构词同为 `-iya` 形容词，译法结构一致，✅ 无漂移。但 `upādāna` 在同一句内译「取」（§678「什么是取？」「这就是取」），而 `upādāniya` 译「取着」，同根词的汉译词干不统一（着/无着）。建议统一词干：`upādāna`=「取」则 `upādāniya`=「可被取的法」，或 `upādāna`=「取着」则通篇用「取着」。同段落内两种词干并存，读者会误以为是两个概念。
- `Chaṭṭhaṃ. / Sattamaṃ. / Aṭṭhamaṃ. / Navamaṃ.`：§676「第六经」／§678「第七经」／§680「第八经」／§682「第九经」，✅ 一致。
- 经题编号「六、结缚经」「七、取着经」「八、遍知内处经」「九、遍知外处经」，✅ 体例一致。
- `Yo tattha chandarāgo, taṃ tattha`：§676 与 §678 均译「对它的欲贪，就是其中的结缚/取」，✅ 句式一致。但「对它」与「其中」同译 `tattha`，一句内同一词两种译法（详见下文 §676-40-59）。
- `abhijānaṃ parijānaṃ virājayaṃ pajahaṃ` 四支：§680 与 §682 均译「证知、遍知、离贪、舍弃」，✅ 跨段一致。
- 语体：全 chunk 为现代书面汉语，未见文言虚词（之/其/乃/便/即/谓/於/遂）或文言句式，✅ 风格合格。
- 标点：全角，无 ASCII 引号，✅ 合规。

## §676 句 170-676-2-18

- **问题**：增译 — 原文 `desessāmi` 只是「我将讲说」，译文作「我要**为你们**讲说」，补出了与格受者。虽然呼格 `bhikkhave` 在场使受者不言自明，但 `style.md`「不擅自补足省略主语（除非语义必须）」同样适用于受者，此处非语义必须。
- **建议**：改为「比丘们，我要讲说可被结缚的法和结缚。」（§678-2-16 同一问题，同改。）

## §676 句 170-676-40-59

- **问题**：一词两译 — `tattha … tattha` 同一句内先译「对它」后译「其中」。前一个 `tattha` 承 `cakkhuṃ` 指对象（对眼的欲贪），后一个指处所（结缚在那里），传统上两处同指同一所缘，汉译宜显出同指。
- **建议**：改为「对它的欲贪，就是对它的结缚。」或「其中对它的欲贪，那就是其中的结缚。」——两处用同一指代词。（§678-39-58、§676-60-67、§678-59-66 同一问题，同改。）
- **待核**：`saṃyojaniya` 的被动方向（「可被结缚的法」）是否合传统取义，需义注核。若义注解为「能结缚（众生）的法」则方向译反，属必改项。同理 `upādāniya`。

## §676 句 170-676-68-81

- **问题**：术语一致性 — 「这些被称为可被结缚的法，这就是结缚」中 `idaṃ saṃyojanaṃ` 与前文 `taṃ tattha saṃyojanaṃ` 的「结缚」同词，✅；但与 §678 对应句的「这就是取」相比，词干处理不一（见跨段一致性第一条）。
- **建议**：随 `upādāna` 词干统一方案一并调整 §678，本句无须改。

## §680 句 170-680-2-18

- **问题**：增译主语 — 原文 `anabhijānaṃ aparijānaṃ avirājayaṃ appajahaṃ` 是四个现在分词（阳性单数，与 `abhabbo` 同格，作主语的同位修饰），译文补出「……的**人**」。补「人」使句子可读，但原文无 `puggalo`／`so`；`abhabbo` 本身已是「不可能者」。
- **建议**：可保留「的人」（语义必须，汉语无此则悬空），但需一致；本 chunk 四处均作「的人」，✅ 已一致。**待核**：nissaya 若给这组分词补出了别的隐含主语（如「比丘」），则应随 nissaya。
- **问题**：`avirājayaṃ` 译「不离贪」 — `virājaya` 为使役形现在分词（`vi-rāj-`／`vi-rajj-`），传统或解为「不使（对它的贪）褪去」「不令离染」。译「不离贪」把使役义抹平了。
- **建议**：**待核**——需义注／nissaya 判定使役义是否需在汉译显出；若义注作使役解，改为「不使（对它的贪）消退」一类。四支对称（`abhijānaṃ parijānaṃ virājayaṃ pajahaṃ`）下，第三支与其余三支的形态不同，译文宜有所反映。

## §680 句 170-680-35-63

- **问题**：省略号层次 — 原文 `… pe … jivhaṃ … kāyaṃ … manaṃ`，即 peyyāla 之后仅列舌／身／意，而译文正确照此处理，✅。但前句 §680-19-34 列「耳……鼻……舌……身……意」，本句列「舌……身……意」，两句根数不同乃原文所致，不是译文问题——**仅提示 revise 步不要「补齐」成六根**。
- **问题**：`Cakkhuñca kho` 的 `ca kho` 语气转折（与前段否定相对）未译出；译文以「才可能」承担了对比，可接受。
- **建议**：无须改；若求精确可在句首加「而」：「而比丘们，证知……」。

## §682 句 170-682-2-20

- **问题**：术语 — `Rūpe`（复数处格／宾格复数）译「色」，`Sadde … gandhe … rase … phoṭṭhabbe … dhamme` 译「声……香……味……触……法」，与 §680 六根对应的六境，术语✅。但原文为**复数**（rūpe/sadde…），§680 六根为**单数**（cakkhuṃ/sotaṃ…），汉译一律无数标记，不构成错误。
- **待核**：`phoṭṭhabbe` 译「触」——`terms.md` 未登记六境。六境中 `phassa`(触) 与 `phoṭṭhabba`(所触/触境) 是两个概念，此处若与后文 `phassa` 同译「触」会混同。
- **建议**：首次出现夹注巴利原词，作「触（phoṭṭhabba）」，并把「所触境」候选与本条分歧记入术语表待定项；依 `style.md`，译文本身不留标记。
