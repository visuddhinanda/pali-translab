# Review — 179:1837-1841（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层对照（book 177，已定稿译文）✅／独立义注 ⚠ 未注入（本层即复注，释义标准取父层原文 + nissaya；另 §1840 引《法集论义注》一处可据以核对）

## 被解释词核对（与父层 177 逐字同译）

绝大多数黑体与父层定稿逐字一致，核对通过：肉眼也 / 就是具成分眼和净色眼 / 下方以眼窝骨为界 / 上方 / 两侧以眼角为界 / 内侧以脑髓为界 / 由筋腱的索系连 / 而这整个世间 / 像莲花的花瓣一样 / 认定 / 但那个被这样执取的东西并不是所谓的眼 / 只能说它是那（胜义）眼的所依处 / 那（胜义）眼的 / 而这个 / 色、香 / 性色 / 生 / 形状 / 这十种 / 各有四种生起之因 / 而依着这些色法 / 周遍团聚而成的 / 智者们 / 阐明 / 在这具成分眼当中依住 / 四界的净色 / 这黑色圆圈中央 / 所见圆 / 由具有支持……得到资助 / 由时节、心等 / 又由命根加以守护 / 被色、香、味等 / 等 / 以相当于虱子头那样的大小 / 安住。

不一致或格式有问题的三处：

- **必改**｜§1839 句 `179-1839-2-27`：引文作「**眼**……（中略）……以及命色」，父层 177:2157 中 `Cakkhu` 定译为「**眼净色**」（"眼净色、身净色、性色，以及命色"）。引文首词应作「眼净色」，否则读者看不出这条注的是 2157 哪一项。
- **必改**｜§1839 句 `179-1839-2-27`：黑体范围把连词括进去了——「**四十**种色**和四**种色」中「和」不是被解释词（pali 黑体为 `cattālīsañca cattāri ca`）。且中文读起来不成句。建议改为「所以成为**四十**种色和**四**种色，意思是合成四十四种色」。
- **建议**｜§1837 句 `179-1837-44-49`：zh 给「具成分眼」加了黑体，但该句 pali（`Sasambhārañca nāma maṃsapiṇḍo pavuccatīti sambandho`）并无黑体标记。黑体只用于标被解释词，此处应去掉，以免与真正的 lemma 混淆。

## 跨段一致性

- **pālana / rakkhati**：§1841 `36-42` 同一句内黑体作「守护」、随后 gloss 作「被……所保护」，紧接 `43-46` 又作「守护」 → 统一为「守护」（依据：父层 177:2253「命根以守护俱生的色为特相」）。
- **samudīraṇa**：§1841 `5-22` 译「推动」，父层 177:2109 定译「动摇」（风界「以动摇为味」），177:2099 作「能动摇、推移」 → 统一为「动摇」。
- **dvāra**：§1841 `71-79` 先作「门户」（"眼识转起的门户"），同句后半与全 chunk 其余处均作「门」 → 统一为「门」。
- **bhūta / dhātu**：§1840 `86-105`「**四界的净色**，是说四大种的……」——黑体「四界」承父层 177:2164（父层把 `bhūtānaṃ` 译作「四界」），而 gloss 按 pali 作「四大种」，同一词在一句里出现两个名目，读者会以为是两物。黑体不可改，建议 gloss 处写「四界（即四大种）」搭一道桥。本 chunk 其余「四界」均对应 `dhātu`（1838 `73-83`、1841 `5-22`/`43-46`/`126-143`），本身无误。
- **泛指主语的「说」**：`vadanti`/`āha`/`apare` 三种译法混用——「并且他们说」（§1841 `29-35`，「他们」无先行词）、「是说他所指的」（§1838 `37-41`，「他」指谁不明）、「另有一些人」（§1840 `178-199`，妥当）。建议统一：`apare`→「另有一些人」，`vadanti`→「诸师说」，`āha`→「（论主）说的是」或直接「这里指的是」。
- **samuṭṭhāna**：本层统一作「等起」（1837 `34-39`、1838 `84-92`、1839、1841 `23-28`），而黑体处承父层作「生起之因」。属父层已定稿造成的层间差异，不改；若后续 harmonize 动父层，此处需同步。

## §1837 句 179-1837-111-124

- **问题**：可读性（译文自我重复） — 黑体「**但那个被这样执取的东西并不是所谓的眼**」之后，gloss 又写「是说那个被这样执取的东西并不是所谓的眼」，一字不差地重复一遍，读者看不出复注在解释什么。根因是父层 2139 已把复注的 `tathā gayhamānaṃ` 吸收进本文译文。
- **建议**：黑体保持不动，gloss 改为点出 nissaya 的区分：nissaya `စက္ခုနာမ= ပရမတ္ထစက္ခုမည်သည်`（"所谓的眼"＝胜义眼）。可译「意思是说，像上面那样被执取的那个肉团，并不是胜义上所说的眼。」

## §1837 句 179-1837-125-137

- **问题**：省略了设问的来源 — nissaya `ဣတိ စောဒိတဗ္ဗတော`（"因为会被这样质问"），译文「为此说了」把质问这层关系压掉了。
- **建议**：「因为会有人这样质问，所以（论主）说了『……』。」

## §1837 句 179-1837-99-106

- **问题**：风格 — 「是说由于宽阔、广大、青色，就像青莲花的花瓣一样」，形容词短语直接作原因，读着夹生。
- **建议**：「是说由于它宽阔、广大而呈青色，就像青莲花的花瓣一样。」（「宽阔、广大、青色」三词需与父层 2137 一致，不要改词。）

## §1838 句 179-1838-28-36

- **问题**：风格（啰嗦） — 「是指在女人那里是女性的状态、在男人那里是男性的状态这样所得到的性的状态」，三个「状态」叠在一句里。
- **建议**：「是指在女人身上是女性的状态、在男人身上是男性的状态，这样可以得到的那种状态。」

## §1838 句 179-1838-37-41

- **问题**：**词义漏失（必改）** — `sambhavabhūta` 译作「作为生的」。nissaya 明说 `သမ္ဘဝဘူတံ= သုက်သွေးဖြစ်၍ဖြစ်သော`（＝**成为精血的**）；父层 177:2349 也把 `sambhavarūpa` 定译为「精血色」。译文把实指丢成了抽象的「生」。
- **建议**：黑体「**生**」保留（承父层 2144），gloss 改为「这里所指的就是作为精血（sambhava）而存在的水界本身。」（父层 2144 的复注夹注「即水界」正与此呼应。）

## §1838 句 179-1838-53-65

- **问题**：指代过虚 — 「既有成为那样的水界等，也有不成为那样的水界等」，「那样」指什么没有落地。nissaya 两处都展开为 `ထိုသို့ အာပေါဓာတ်, ဝဏ္ဏာယတန အခြင်းအရာအားဖြင့်`（以水界、色处那样的形态）。
- **建议**：「这是因为在前面所说的肉团里，既有以精血、形状那种状态而存在的水界等，也有不以那种状态存在的水界等。」

## §1838 句 179-1838-66-72

- **问题**：`avatthāvisesa` 译「某种特殊状态」偏虚；nissaya `အခိုက်အတန့် အထူး` 指**时位／阶段**上的差别。
- **建议**：「它们在某一阶段上的特殊状态，就是生与形状。」

## §1838 句 179-1838-73-83

- **问题**：读者算不出「十」 — 「四界，以及依靠它们的色等」，nissaya 明示 `ဝဏ္ဏစသော ခြောက်ပါး`（色等**六种**）。
- **建议**：「就是四界，以及依靠四界的色等六种（色、香、味、食素、生、形状），这样一共十种。」

## §1840 句 179-1840-24-60

- **问题 1**：**原文校勘（记录，不改）** — nissaya 在本段后附缅文编者注，明言此段复注文句「ပါဌ်နေ အလွန် ရှုပ်ထွေး ပျက်စီး」（抄本严重错乱），是编者据《殊胜义》（Aṭṭhasālinī）色品·眼处释补订的。译文是按印本 pali 直译的，与编者订正本未作比对。建议把这条校勘记进 `knowledge/known-issues.md`，并在定稿前拿《殊胜义》眼处段核一遍词序。
- **问题 2**：用词加码 — `pariḍayhati`（nissaya `လောင်ကျွမ်း၏` 燃烧）译「感到灼热」多了主观的「感到」；`sambhamati`（nissaya `ရွေ့ရှားတုန်လှုပ်၏` 移动颤动）译「转动不停」多了「不停」。
- **建议**：「由于火多就灼热，由于风多就动摇颤动。」另 `paggharati` 作「流出水液」可改「就渗出液体」（父层 177:2109 `paggharaṇa` 定译「流动」，此处为动词义，不必强求同字）。
- **问题 3**：`idaṃ pana` — nissaya 读作 `ယံ ပန`（yaṃ pana，"凡是那样的眼"）。译文「而这个具成分眼」是按 `idaṃ` 读的，与 nissaya 的句读不同。属异读，建议在报告留档；若取 nissaya 读法，应作「而其中凡是……的，就由于痰多而成为白色」。

## §1840 句 179-1840-86-105

- **问题**：术语 — `pasannatā`（nissaya `ကြည်လင်သည်၏အဖြစ်` 澄明）译作「清净明净」，「清净」在汉译佛典里偏指戒行／心的清净，易误导；且两个同义词叠用。
- **建议**：「是说四大种的澄明（pasannatā）之性就是净色。」

## §1840 句 179-1840-157-177

- **建议**（非必改）：「**义注**」已正确标明层次 ✅。所引为《殊胜义》（nissaya `အဋ္ဌသာလိနီရူပကဏ္ဍအဋ္ဌကထာ`），译文作「《法集论义注》596」亦不误；若要让读者查得到，可写「《法集论义注》（《殊胜义》）596」。

## §1841 句 179-1841-5-22

- **问题**：双关丢失（影响理解） — 比喻的着力点在 `dhātī`（乳母）与 `dhātu`（界）同音：四位乳母照料王子，四界资助净色。中文「四位乳母」与「四界」看不出关联，比喻就成了无根之喻。
- **建议**：首次出现处夹注巴利原词：「就像刹帝利王子由……四位乳母（dhātī）照料一样，它由……四界（dhātu）得到资助」。另 `samudīraṇa` 改「动摇」（见跨段一致性）。

## §1841 句 179-1841-36-42

- **问题**：同句内「守护／保护」两译（见跨段一致性）。
- **建议**：「是指被那依于四界的命根所守护。」

## §1841 句 179-1841-80-89

- **问题**：**误译（必改）** — `tadārammaṇāvasānānaṃ` 译成「以那同一所缘为对象、直到最后的」，把术语当成了描述语。nissaya 作 `တဒါလမ္ဗနာဝသာနာနံ`（tadālambana＝**彼所缘**心），整语意为「从领受心起、直到彼所缘心为止的那些心」——这是阿毗达摩固定的心路序列末位，不是「以那同一所缘为对象」。
- **建议**：「而从领受心起、直到彼所缘（tadārammaṇa）心为止的那些心，由于依的是另一个所依，所以它只成就门的状态，并不成就所依处的状态。」
- **问题 2**：`aññanissitattā` 译「依于别的所依」过虚，nissaya 已点明是 `ဟဒယဝတ္ထုကို မှီ`（依心所依处，异于眼所依处）。
- **建议**：补出「依的是眼所依处以外的心所依处」。

## §1841 句 179-1841-71-79

- **问题**：`pavattimukha` 译「门户」，与全篇「门」不一（见跨段一致性）；nissaya `ဖြစ်ခြင်း၏ အဦးအစ`（生起之端首）。
- **建议**：「又由于它是眼识转起的门，所以成就门的状态。」

## §1841 句 179-1841-126-143

- **问题**：歧义 — 「以及命、色等等」中的「色」承 `vaṇṇa`（颜色），但紧邻上下文满是 `rūpa`（色、色聚），读者十成会读成 rūpa。nissaya 作 `ဇီဝိတ, ဝဏ္ဏ စသည်`。
- **建议**：「作为它所依的四界，以及命（āyu）、颜色（vaṇṇa）等等……」（父层 177:2365 已有 `vaṇṇo`→「颜色」的先例，不与黑体冲突。）
