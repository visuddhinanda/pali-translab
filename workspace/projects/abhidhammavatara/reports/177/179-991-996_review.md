# Review — 179:991-996（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层（book 177）定稿译文 ✅／**nissaya ❌ 未提供**／**本层上层注释 ❌ 无（本层即复注，无更上层释义标准）**
> ⚠ 因缺 nissaya，词级形态（格、数、句法角色）与一词多义取义**没有独立基准**，下列词法类意见仅据巴利原文与父层译文推定，置信较低；义理类意见以父层定稿译文为锚。

## 一、被解释词（黑体）与父层逐字核对

全部 11 处黑体均与父层定稿**逐字相同**，无断链：

| 本层 | 译法 | 父层出处 |
|---|---|---|
| sārammaṇato / sārammaṇaṃ | 就有所缘而言 / 有所缘 | 177-35-2-9 |
| Ekavidhaṃ | 一种 | 177-35-2-9 |
| Savipākāvipākato | 就有异熟与无异熟而言 | 177-35-2-9 |
| tattha savipākaṃ | 其中，有异熟的 | 177-35-10-17 |
| Abyākataṃ | 无记 | 177-35-10-17 |
| tividhaṃ | 三种 | 177-35-18-20 |

| Kusena / Lātabbattā | 由那被称为“茅草（kusa）”的智 / 应当去把取 | 177-39-2-8 |

**但有两处因父层译法带入了释义，被本层注文反证出冲突**——本层不要改黑体，这是 harmonize 该处理的跨层问题：

1. **§994-45-52（salanato）**：本层给的第二解是 `saṃvaraṇato, pidahanato`（防护、关闭），译文因此写成「**摧毁**的意思是防护、关闭」，字面自相矛盾。根因是父层把 `salana` 坐实为「摧毁」。建议 harmonize 时把父层 177-38 的 `salanato` 调为中性词（如「除去」），或本层保留黑体并补夹注：「**摧毁**（salana）在这里的意思是防护、关闭」。
2. **§994-154-164（kusena）**：父层把 `kusena` 译为「由那被称为“茅草（kusa）”的智」，已把 kusa 坐实为「智」；而本层这里给的**第二解明确说 kusa 是「信等诸根」（saddhādīni indriyāni），且单数是类名词用法、实义为复数**。于是译文成了「**由那被称为“茅草（kusa）”的智**这个词……但意思是 “由那些 kusa”」——「智」与「信等诸根」打架，读者会读不通。建议 harmonize 时把父层 177-39 改为不含「智」的形式（把「智」降为夹注/脚注），使本层两解都能挂上。

## 二、跨段 / 跨层一致性

- **vipāka**：本 chunk 一律「异熟」（与父层 177-35、177-43 一致 ✅）；但 §993-17-21、§993-22-31 的 `vipākacitta` 译「异熟心」，父层 177-121 起大量用的是「**果报心**」（与「唯作心」对举）。→ 建议 §993 的 `vipākacitta` 改「果报心」，`savipāka/avipāka` 保留「有异熟／无异熟」（父层 177-35 已定），并把「vipāka 在父层有 异熟／果报 两译」记入 known-issues，留给 harmonize 全书统一。**必改项**（否则读者看不出本层注的就是父层那两类心）。
- **byāpāra = 「作用」与 rasa = 「作用」撞车**：§992-119-139「带着**作用**而转起」。父层 177-43 等处「作用」专指 rasa（味），且 §993-22-31 已把 `ussāha` 译「功用」（同父层 177-123）。→ 改「带着**功用**而转起」。**必改项**。
- **「等等」vs「等」**：本层出现约 14 处「等等」（§991-32-63、§991-64-83、§991-120-145、§992-21-41、§992-42-57、§992-63-69、§992-140-156、§994-33-44、§994-66-79、§994-80-91、§994-92-98、§994-165-183…），父层通篇只用「等」（「布施等功德」「眼识等」）。→ 统一为「等」；`tiādīsu` 统一译「等处」而非「等等处」。**必改项**（语体漂移，逐段审查看不出）。
- **tanu-**：§994-106-123「使它们**变薄**」，父层 177-101 同根 `tanuttakaraṃ` 作「使……变得**薄弱**」。→ 统一为「变得薄弱」。
- **全角引号前后夹了半角空格**：§991-32-63、§991-64-83、§991-98-119、§992-21-41、§992-42-57、§993-64-77、§994-154-164 均作「在 “……” 等等处」。style.md 要求一律中文全角标点，引号与汉字之间不应留空格（拉丁词 kusa 两侧的空格可保留）。**必改项**（格式一致性）。

## 三、逐句意见

### §991 句 179-991-2-19
- **问题**：风格（文言）— 「**若**不加以分类」用文言条件连词，style.md 禁例表明列「若…则 → 如果…就」。
- **建议**：改「如果不加以分类，就无法阐明它们的自性」。**必改**。

### §991 句 179-991-32-63
- **问题**：取义可读性 — DN 3.80 的 `ārammaṇa` 在该经中是「依托／可乘之机」，译文照搬「所缘」虽保住了本层论证所需的词形，但读者会误以为经中说的是认识对象。
- **建议**：保留词形并加夹注：「魔得到了所缘（即依托）……」，或在该句末补「——此处的“所缘”即指缘」。

### §992 句 179-992-42-57
- **问题**：术语构词 — 「有异熟法**之**法」含文言「之」（style.md 禁），且与前一项「异熟诸法」构词不平行。
- **建议**：改「“有异熟的法”（vipākadhammadhammā）」。**必改（之字）**。
- 同句「三法母题」：Dhs `mātikā` 传统汉译作「论母／摩帝迦」。建议统一为「三法论母（tikamātikā）」，§992-21-41 一并改。

### §992 句 179-992-63-69
- **问题**：汉语生硬 — 「就会落到不被 “有异熟” 这一项含摄的结果里去」。
- **建议**：「就会造成神通善心等不被“有异熟”一项所含摄的结果」。

### §992 句 179-992-70-118
- **问题**：行文重复 — 「因为它们正是在善与不善的**解说**里被**解说**出来的」。
- **建议**：「因为它们本来就是在善与不善这两项下被解说的」。

### §992 句 179-992-119-139
- **问题**：**原文复合词切分存疑** — `anupacchinnāvijjamānataṇhānusayasmiṃ` 译作「无明、**慢**、爱的随眠」，即读为 `avijjā-māna-taṇhā-anusaya`；但该串也可读为 `anupacchinna-avijjamāna-...`（a+vijjamāna，「并非不存在的」）。缺 nissaya 无法裁定。
- **建议**：维持现读（avijjā/taṇhā 是轮回根本，māna 亦在七随眠内，语境通顺），**压低该句 confidence**，并把两读写入 known-issues 待查缅文 nissaya 或别本。
- 另：「带着作用而转起」→「带着功用而转起」（见第二节）。

### §993 句 179-993-32-51 / 179-993-52-63
- **问题**：可读性 — 「**有的根本**已被断除的相续」「有的根本还没有被断除」。单字「有」在汉语里会被读成「有／没有」的「有」，首次出现无夹注，读者无法识别这是 bhava。父层惯例是加括注（「生有（upapattibhava）」「欲有」）。
- **建议**：首处改「**有（bhava）的根本**」，后一处沿用「有的根本」。

### §993 句 179-993-17-21 / 179-993-22-31
- **问题**：术语对应断链 — 「异熟心」「唯作」应与父层 177-121「果报心与唯作心（kiriyacitta）」对齐（「唯作」已对齐 ✅，「异熟心」未对齐）。
- **建议**：改「果报心」，详见第二节。**必改**。

### §994 句 179-994-13-25
- **问题**：取义偏具体 — `asuci` 译「粪秽」。该词在此类比喻中泛指不净物，译「粪秽」把范围坐窄。
- **建议**：「像不净的东西一样」。（非必改）

### §994 句 179-994-124-131 / 179-994-165-183
- **问题**：风格（文言虚词）— 「应当……在相续中被**使之**转起」「应当由它们……**使之**转起」，「之」为文言代词，且被动套使役读起来绕。
- **建议**：分别改「应当以俱生与亲依止的方式，使它在相续中转起」／「就是说应当由它们按上面所说的方式，使它在相续中转起」。**必改**。

### §995–§996 句 179-995-2-12 / 179-996-2-11
- **问题 1**：论证要点丢失 — 偈颂两句的区别正是 `kuso`（单数）与 `kusā`（复数），呼应 §994-154-164「类名词故用单数」；译文作「像茅草那样／像那些茅草那样」，读者看不出是单复数之别。
  - **建议**：补夹注「像茅草（kuso，单数）那样割除，或者像那些茅草（kusā，复数）那样割除」。
- **问题 2**：引号跨行不自足 — §995 开引号、§996 才闭引号，单行读取（导出、逐句核对）时两行都是不配对引号。
  - **建议**：若按行独立呈现，则每行自成引文；否则至少在 harmonize 时确认导出流程会把两行拼接。
- 「摧毁卑劣（ku）」中 `saleti` 译「摧毁」与 §994 的 salana=摧毁 一致 ✅，保留。

## 四、OCR / 原文疑问（记录，不改）

- §992-119-139 `anupacchinnāvijjamānataṇhānusayasmiṃ`：复合词切分有两读，见上。
