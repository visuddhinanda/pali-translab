## 二、跨段一致性

- **khaya / vaya（必改，§2431 句 179-2431-2-30）**：同句里 `khayadassana` 与 `vayadassana` 都译成「观见坏灭」，两个不同的巴利词被压成同一个汉语词，整句变成「观见生起只是为了观见坏灭，所以为了表明观见坏灭才是主要的」——读者无法看出前后是两个词。nissaya 也作区分：`ခယဒဿနတ္ထံ= ကုန်ခန်းပျက်စီးခြင်းကို ရှုခြင်းအကျိုးငှါ`（尽坏）／`ဝယဒဿနဿ= ပျက်ခြင်းကိုရှုခြင်း၏`（坏）。→ 建议 khaya 作「观见灭尽」，vaya 作「观见坏灭」。
- **udaya / vaya 的两套译法**：定义句用单字（179-2430-12-19「生起之相就是生」、179-2430-20-22「变异之相就是灭」），叙述句用双字（179-2428-13-24「生与灭」、179-2429-2-20「生起与坏灭」、179-2431「观见生起／观见坏灭」）。与父层（177-4234/4235 的「生」「灭」）不冲突，可保留，但须作为定则固定下来：**作为被定义项时「生」「灭」，作描述时「生起」「坏灭」**，并确保复合 `udayabbaya` 一律「生灭」（现状已一致 ✅）。
- **udayabbayadassana**：父层 177-4270 定稿作「生灭观见」；本层 §2431 把 udayadassana / vayadassana 拆译为「观见生起／观见坏灭」（拆开出现，可接受）。如本层后续再出现复合形 `udayabbayadassana`，须沿用「生灭观见」。
- **nicaya / rāsi / sannicaya / cayo**：现状「积聚／堆积／积存」三分，与父层（177-4241「积聚」「堆积」、177-4246「积聚起来」）不冲突 ✅，保持即可。
- **「所依的努力」构式不一致**：179-2427-104-119 作「对道非道智见之观应当努力修习」，179-2427-120-129 作「应当在聚的思惟上努力修习」。nissaya 两处都是处格（`မဂ္ဂါမဂ္ဂဉာဏဒဿနဝိပဿနာ၌`／`ကလာပသမ္မသနေ`）。→ 统一为「在…上努力修习」。
- **语体**：无文白混杂的句式问题，但有多处单音节文言虚词「之」，见第三节必改 2。
- 术语与父层一致项（无需改）：随烦恼 / 光明 / 聚（kalāpa）/ 琵琶 / 名色 / 正等正觉者 ✅；「度疑清净」「相续现在」「刹那现在」父层未出现，本层自定，建议定案后补进 `knowledge/terms.md`。

## 三、必改 2：文言虚词「之」（style.md 第一节硬约束）

- §2427 句 179-2427-104-119：「对**道非道智见之观**应当努力修习」→「在**道非道智见的观**上应当努力修习」（同时解决上条构式问题）。

- §2432 句 179-2432-37-85：「用一个属于**整体之一部分**的比喻」→「用一个属于**那个整体的一部分**的比喻」。

## 四、逐句问题

### §2427 句 179-2427-2-34
- **问题**：背景缺失 —「三相」未作任何提示，一般读者无从知道指无常、苦、无我；style.md 规定罕见术语首次出现附简注。
- **建议**：「有了对三相（tilakkhaṇa，即无常、苦、无我）的观的时候」。

### §2427 句 179-2427-61-91
- **问题**：指代不明 —「聚的思惟是在**这两种清净**之间进行的」，前文只出现过「度疑清净」和「道非道智见清净」各一次，且相隔较远，读者难以确定所指。nissaya 明确点名：`ဝိသုဒ္ဓီနံ= ကင်္ခါဝိတရဏဝိသုဒ္ဓိ, မဂ္ဂါမဂ္ဂဉာဏဒဿနဝိသုဒ္ဓိတို့၏`。
- **建议**：「聚的思惟是在度疑清净与道非道智见清净这两种清净之间进行的」。

### §2427 句 179-2427-104-119
- **问题**（除上述两项外）：`kalāpato, kalāpānaṃ vā` 译作「从聚的角度、或者对诸聚进行思惟」，nissaya 两处都补出了被思惟的对象是名色法（`ကလာပတော= နာမ်ရုပ်တရားတို့ကို အပေါင်းအစည်းအားဖြင့်`／`ကလာပါနံ= အပေါင်းအစည်းဖြစ်သော နာမ်ရုပ်တရားတို့ကို`），现译偏空。
- **建议**：「……以确定的方式把名色法当作聚来思惟，或者思惟那些成聚的名色法」。

### §2427 句 179-2427-130-154
- **问题 1**：措辞 —「为了避免**文篇冗长**」不是现代汉语常用搭配。
- **建议**：「为了避免行文过于冗长」。
- **问题 2**：漏译句末 `iti`（nissaya 补出 `ဝေဒိတဗ္ဗံ= ၏`，「应当这样知道」）；另 nissaya 把 `idha` 指实为「本《入阿毗达摩论》」。
- **建议**：「……本论这里没有加以说明——应当这样理解。」

### §2430 句 179-2430-26-49
- **问题**：`…pe…` 译作「中略」可，但「已生的受……中略……想……诸行……识……已生的眼」中，`saññā / saṅkhārā / viññāṇaṃ` 前都省掉了「已生的」，而 nissaya 对每一项都挂着 `ဇာတာ/ဇာတံ`。省略符号间的并列项省「已生的」尚可读，但「已生的眼」之后又恢复，节奏不一。
- **建议**：统一为「已生的受……乃至……已生的想……已生的诸行……已生的识……已生的眼……乃至……已生的有是现在的」，或全段都省，不要半省半留。

### §2432 句 179-2432-15-27
- **问题**：句法归属与 nissaya 不合。现译把 `uppajjamānaṃ` 接到「前来」的主语上（「没有可以让那正在生起的名色从中前来的地方」），而 nissaya 读作属格复数并接到 `aladdhattabhāvassa`：`ဥပ္ပဇ္ဇမာနာနံ= ဖြစ်ဆဲဖြစ်ကုန်သောတရားတို့၏။ အလဒ္ဓတ္တဘာဝဿ= မရအပ်...သဘောရှိသောအဖြစ်၏`。两读都讲得通，但本层须有据，且 nissaya 是词级基准。
- **建议**：改为「……并没有可以从中前来的积聚或堆积；因为那些正在生起的法尚未获得自体，完完全全不存在」，或保留现读但在 review 报告中定案后统一（本条倾向改为 nissaya 读法）。

### §2432 句 179-2432-28-36、86-98、37-85（「他说了」）
- **问题**：三处主语都是光秃秃的「他」，全章未出现过指称对象，读者无从知道是谁。nissaya 明确：`ဒဿေန္တော= ပြတော်မူလိုသော အရှင်ဗုဒ္ဓဒတ္တဆရာသည်`（想要显示的佛授阿阇梨）。
- **建议**：首次出现处补出「论主（阿阇梨佛授，Buddhadatta）」，其后再用「他」。

### §2432 句 179-2432-37-85
- **问题 1**：`rūpārūpadhammā` 译「色法与非色法」，nissaya 作 `ရူပါရူပဓမ္မာနံ= ရုပ်နာမ်တရားတို့၏`，即「色法与名法」。字面义不错，但按词级基准应点出所指。
- **建议**：首次出现作「色法与非色法（即色法与名法）」，其后（如 179-2432-137-171）沿用「色法与非色法」。
- **问题 2**：`aṭṭhakathāya` 译「**义注**（visuddhi.2.723）」，层次标注正确 ✅；但 nissaya 指实为「大义注（Mahā-aṭṭhakathā）」，而括注编号指向《清净道论》，与上文 179-2427-130-154 的「《清净道论》（visuddhi.2.692）」并置时读者会误以为是两本书。
- **建议**：作「**义注**（指大义注；参《清净道论》visuddhi.2.723）」，或至少在首次出现时说明该引文见于《清净道论》。

### §2432 句 179-2432-99-110
- **问题**：行文打结 ——「**这个意思**是指：在阐明“……”这个意思的时候。」一句里「这个意思」出现两次，且「是指……的时候」搭配不顺。
- **建议**：「**这个意思**，就是指在显示“本来并不存在的东西才生起，已经生起的东西后来又归于不存在”这一点上（讲了琵琶的比喻）。」

### §2432 句 179-2432-137-171
- **问题 1**：`vīṇavādanaṃ` 译「依于弹奏」。nissaya 把它释为器物而非动作：`ဝီဏဝါဒနဉ္စ= စောင်းတယောကို တီးထိုးခြင်း၌ အဆောက်အဦဖြစ်သော ကြိုးရစ်ရာတုတ်တန်ကို`（弹奏琵琶所用的、缠弦的木轴），并注明《清净道论》与《无碍解道》义注作 `upavīṇaṃ`。三者并列（琵琶／×／人的用力）中，器物一项才合于比喻。
- **建议**：译「以及依于弹奏用的琴轴（upavīṇa）」，或保留「弹奏」而加脚注说明 nissaya 与 Vism 的异读（style.md 允许异释作脚注）。
- **问题 2**：`disāvidisāgamanaṃ` 作「不去往四方四维」，父层 177-4244 同义处定稿为「不去往任何方向」。此处非黑体，且本层原文多了 `vidisā`，保留「四方四维」有据 ✅——仅提示：若后文再出现单 `disā`，须回到「任何方向」，不要互串。

## 五、OCR / 原文疑问（记下，不改）
