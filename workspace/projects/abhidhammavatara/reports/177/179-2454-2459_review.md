## 二、跨段一致性

1. **`-gata` 系复合词三种译法，其中一处直接误读**（见 §2459 必改项）：
   - 2459-2-34 `sabbabhavagatesu` → 「一切有和趣」
   - 2458-81-107 / 2459-84-113 / 137-164 `saṅkhāragata(ṃ/esu)` → 「一切与诸行有关的东西」
   - 2458-108-127 `sabbabhavayoni…` → 「一切有、胎、趣…当中的」
   **建议**：`saṅkhāragata` 统一作「凡属诸行的一切」（或径作「诸行」），`bhavagata` 统一作「存在于一切有中的」。
2. **`tīraṇa` 译法漂移**：2456-53-64「度量」／2458-81-107「思量」（tulayato tīrayato「衡量、思量」）／2458-136-162「思量」；而术语 `tīraṇapariññā` 作「度遍知」。**建议**：`tīraṇa` 统一为「度量/审度」，与「度遍知」同源；「审察」留给 `paṭisaṅkhā`（已这样用，勿混）。
3. **`yoga / abhiyoga` 译法不一**：2458-2-15「再加功用」／2458-18-39「下功夫修习」。父层 §4366 作「下功夫修习」。**建议**：统一「下功夫修习／精勤修习」，弃「加功用」（半文言的汉传腔，见 style.md 一）。
4. **`upekkhā / majjhatta` 不一**：2459-137-164「保持舍置」／2459-165-184「保持中立」。**建议**：统一「舍置」。
5. **「名为 X 智的智」句式连出五次**（2458-81-107、2459-2-34、35-58、59-83、137-164），其中「名为过患智的智」「名为欲解脱智的智」「名为行舍智的智」重复一个「智」字。**建议**：统一为「名为……的智便生起了」（2459-35-58「名为厌离随观的智」是对的范式）。
6. **篇题标记不一**：2454 用《行道智见清净的解说》，正文内引篇名/术语一律用全角 “”（如 “怖畏现起智”）。**建议**：2454 改作 “行道智见清净的解说”的注释；另父层 §4348 作「行道智见清净的解说」、§4412 作「行道智见清净解说」，本层随 §4348 即可。
7. **巴利夹注系统性缺失**（见下「必改·style」）：全 chunk 零夹注，而父层译文对 vuṭṭhānagāminī / gotrabhu / yogāvacara / upakkilesa 等均有夹注。

## 三、必改项

### §2456 句 179-2456-19-32 — 释义方向译反
- **问题**：误译（句法关系）。`tīraṇapariññāya patiṭṭhaṃ` 译作「**是**度遍知**的立足处**」，把生灭随观智当成了度遍知的所依。nissaya 作 `တီရဏပရိညာယ= တီရဏပရိညာဉ်**၌**`（处格）+ `ပတိဋ္ဌိတံ`，即「**住立于**度遍知**之中**」；其附注更明说多数本作 `patiṭṭhaṃ`，但须与清净道论大疏「kiñcāpi hi udayabbayañāṇaṃ tīraṇapariññantogadhameva」（生灭智虽**被摄入**度遍知）校读，`patiṭṭhitaṃ` 才合。方向一反，「虽然…但也是行道智见」的让步关系就讲不通了。
- **建议**：「这里面，生灭随观智虽然是安立在度遍知之中的（即摄属于度遍知），但按照上面所说的意思，它也确实就是行道智见，所以这里也把它说了进来。」另：nissaya 把 `idha` 释为「在断遍知这一范畴中」，译文的「这里」太空，建议补作「所以在断遍知这里也把它说了进来」。

### §2456 句 179-2456-40-44 — 取读致全段自相矛盾
- **问题**：误译（异读取舍）。译文作「**还不熟练的**生灭智…就成了断遍知的依处」，与本段结论 2456-65-80「所以，**达到了熟练的**生灭智，应当看作正是属于断遍知这一边的」正相反；也与上一句「别处是针对它刚生起、还不熟练的情形说的」冲突。nissaya 的词条是 `ပဂုဏံ= လေ့ကျက်အပ်သော`（**熟练的**，无否定），其附注明言：多数本作 `appaguṇañhi`，但**无否定的 `paguṇañhi` 才与清净道论大疏一致、文义才顺**。
- **建议**：依 nissaya 取 `paguṇañhi`，译作「因为**熟练的**生灭智，由于成就了对常想等的舍断，就成了断遍知的依处。」并在报告/译者注记下 VRI 原文作 `appaguṇañhi` 的异文。

### §2459 句 179-2459-2-34 — `bhavagata` 误读为 `gati`
- **问题**：误译。`sabbabhavagatesu saṅkhāresu` 译作「在**一切有和趣**当中的诸行里」。nissaya：`သဗ္ဗဘဝဂတေသု= အလုံးစုံသော ဘဝတို့၌ဖြစ်ကုန်တည်ကုန်သော`，即「**存在于一切有中的**诸行」——`-gata` 是「所属/存在于」，不是 `gati`（趣）。凭空多出一个法数。
- **建议**：「在存在于一切有当中的诸行里，找不到…」。

### §2458 句 179-2458-81-107 — 同一主语被译成两件事
- **问题**：误译（指代断裂）。`saṅkhāragataṃ` 是 `upaṭṭhāti` 的唯一主语，`attano lahuupaṭṭhānena` 是「由于它自身迅速现起」。译文把它拆成「由于**诸行**自己现起得很快」与「**一切与诸行有关的东西**都隐去了生起等阶段」两个不同措辞的主语，读者会以为是两样东西。
- **建议**：「由于凡属诸行的一切自身现起得快，又由于智很锐利，它们便隐去了生起等的分别（`bheda`，nissaya `အပြားရှိသည်`，非「阶段」），只以正在坏灭的样子现起…」。

### §2458 句 179-2458-108-127 — `yoni` 译窄
- **问题**：术语误译。`sabbabhavayonigatiṭṭhitinivāsesu` 译「一切有、**胎**、趣、住、居」。nissaya 逐条给出法数：`ဘ၀သုံးပါး`（三有）、`ယောနိလေးပါး`（**四生**）、`ဂတိငါးပါး`（五趣）、`ဝိညာဏဋ္ဌိတိခုနစ်ပါး`（七识住）、`သတ္တာဝါသကိုးပါး`（九有情居）。`yoni` 传统汉译为「〔四〕生」，译「胎」把卵生/湿生/化生排除在外。
- **建议**：「在一切〔三〕有、〔四〕生、〔五〕趣、〔七识〕住、〔九有情〕居当中的诸行…」——法数不补出，中文读者无法辨认这是五组法门。

### style.md 六：现代政治语汇对译法相（两处同根）
- **2456-53-64 / 2456-65-80**：`paṭipakkha` 译「**对立面**」（「舍断对立面」）。nissaya `ဆန့်ကျင်ဘက်တရား` = 相反/敌对之**法**。「对立面」是现代政治—哲学语汇，且丢了「法」。**建议**：「舍断与之相反的〔烦恼〕法」。
- **2459-165-184**：`majjhatta` 译「保持**中立**」。**建议**：「只是保持舍置」（与 2459-137-164 的 upekkhā 译法统一）。

### style.md 二：法相术语首次出现未夹注巴利原词（系统性）
- **问题**：格式。style.md 规定「法相术语首次出现夹注巴利原词（圆括号）」，父层译文确实照办（vuṭṭhānagāminī、gotrabhu、yogāvacara、mahesi、upakkilesa 均有夹注）。本 chunk **一个夹注都没有**，而其中本层首现、父层未出现过的法相术语至少有：度遍知（tīraṇapariññā）、断遍知（pahānapariññā）、遍知所依/立足（patiṭṭhā）、相续（santati）、威仪（iriyāpatha）、密集（ghana）、三有地（tebhūmaka）、空性（suññatā）、二句（dvikoṭika）。
- **建议**：为上列词补全角圆括号夹注；父层已夹注过的（如 upakkilesa、vipassanā）本层不必重复。

### §2455 句 179-2455-46-59 — 语体 + 格关系
- **问题**：风格（文言）＋ 句法。「因为凭着它就可以**行于圣道**」，`于` 作文言介词（style.md 一禁例）；且 `ariyamaggo` 是主格，nissaya 两读 `အရိယမဂ္ဂေါ= အရိယမဂ်ကို`／`ဝါ= သည်`，动词释为 `သိအပ်၏`（被证得）／`ဖြစ်တတ်၏`（生起），并非「人行于道」。
- **建议**：「因为凭着它，圣道就得以行进〔得以生起〕，所以叫做**行道**」。另：本句以 `iti katvā` 收束（nissaya `ဣတိ ကတွာ ဣမိနာ ဝစနတ္ထေန`＋`ပဝုစ္စတိ`），译文停在「所以叫做**智见**」，没有收回「因此才合称为行道智见〔清净〕」，语义链断在半空。建议补一句收束。

## 四、建议项（依 nissaya 补出/校读，非硬错）

- **2455-20-32**：nissaya 补出 `အတ္တဋ္ဌမာနံ`（以**自身**行舍智**为第八**的生灭智等八智）。这是关键一笔——否则读者会以为八智不含行舍智本身，而本句恰在说「它达到顶点是依这八智」。**建议**：「是依着以它自己为第八的生灭智等八种智」。
- **2456-33-39**：`itarattha` nissaya 作「在此之外的、**度遍知**的场合」。译文「至于在别的地方**不把它算进来**」是补出的反向解释，容易让读者以为别处只是「不算」，而实情是别处把它**归入度遍知**。**建议**：「至于在另一处〔把它归入度遍知〕，那是针对它刚刚生起、还不熟练的情形说的。」
- **2456-53-64**：`yāthāvasarasato`／`sāmaññākārānaṃ` → 译文「事物真实的自性」「共通行相」。nissaya 作 `မိမိ၏`（**自身**的）与共相。**建议**：「按照〔诸行〕自身真实的自性」「仅凭对共相的度量」。
- **2457-34-58**：构词推导丢了一层。`muccitukāmaṃ`（欲解脱的，指心或人）→ `tassa bhāvo muccitukamyatā`（它的**状态**）。译文让「欲解脱」同时承担 kāma 形与 kamyatā 抽象名词，推导看不出来。**建议**：「想要解脱，所以叫做“欲解脱的”（muccitukāma），这指的是心，或者是人；它的状态就是**欲解脱〔性〕**」。
- **2457-72-75**：`visandhiniddeso` nissaya 明确指出被拆的是哪一处——偈中写作 `saṅkhāre upekkhāñāṇaṃ` 而未连声作 `saṅkhārupekkhāñāṇaṃ`。译文「原文这样的写法…为了**凑合**偈颂的格律而作的拆开连声的表述」既含糊又带贬义。**建议**：「偈中之所以写作‘saṅkhāre upekkhāñāṇaṃ’而不连声作 saṅkhārupekkhāñāṇaṃ，是为了便于结成偈颂。」
- **2457-76-82**：nissaya 补出两处关键内容：遮蔽的是「**四谛**」，黑暗即「**愚痴**（moha）」（`သစ္စာလေးပါးကို ဖုံးလွှမ်းတတ်သော မောဟတည်းဟူသောအမိုက်တိုက်`）。译文只有「最能遮蔽谛的黑暗」。**建议**：「由于那遮蔽四谛的、最为粗重的愚痴黑暗已经消失，它就顺应于对四谛的通达…」。
- **2458-40-80**：`cassa` nissaya 释为「那**无常等**的〔相〕」的属格，不是瑜伽者；译文「是由于**他**没有作意于生灭等」属擅补主语（style.md 六）。**建议**：「是由于没有作意于生灭等」。另引号内「无常、苦、无我」宜与父层 §4371「诸行是无常、是苦、是无我」对齐。
- **2459-35-58**：`tibhavapariyāpannesu` nissaya 补出所指为「摄属三有的**诸行**」，译文作「包含在三有之内的**一切**」偏空；`santipade` nissaya 径释为「**涅槃**」。**建议**：「对摄属三有的诸行生起厌离…在远离一切行的寂静处（santipada，即涅槃）中获得欢喜」。
- **2459-84-113**：`aniccantikatā` 译「并非恒常」（读作 a-niccantika）；nissaya 作 `အနိစ္စလျှင် အဆုံးရှိသည်၏အဖြစ်`（以无常为终极）。`ajaññakatā` 译「不干净」；nissaya 作 `နှစ်သက်ဖွယ်မရှိသည်၏အဖြစ်`（不可喜）。**建议**：「依着终归无常等等…依着不可喜等等安立可厌性」。
- **2459-114-136**：`idaṃ` nissaya 补出为「这**名色**法」。且本句「还应当去把握那种用…所说的、分成二分等种类的空性」四重定语套叠，可读性差。**建议**拆句：「…还应当把握那种空性——就是用“这〔名色〕是空的，没有我，也没有我所”等等说法所说的、分成二句（dvikoṭika）乃至四句的空性。」
- **2459-137-164**：`vissaṭṭhabhariyassa` nissaya 作「已经**舍弃了**妻子的男人」，译文「已经和妻子**分开**的人」中性化，丢了主动舍离的喻意（这正是 upekkhā 的要点）。**建议**：「就像一个已经舍弃了妻子的人那样」。`na sampasāriyati` nissaya 补「不因耽乐而散布/伸展」，可酌补。
- **2459-165-184**：`disākāka` nissaya 释为「在海上**辨识方位**的乌鸦」，译文作「被放出去**寻找陆地**的乌鸦」（意译传统喻），与 nissaya 取义不同。**建议**：「就像〔海船上〕辨识方位的乌鸦一再依靠桅杆停住一样」。
- **2459-2-34**：`tāṇaṃ / leṇaṃ / parāyaṇaṃ` nissaya 分别作「救护之法／藏身处／归投处」，译文「庇护、藏身的地方或者归趣」中「归趣」与前文 `gati`（趣）用字相撞。**建议**：「找不到可以救护的、可以藏身的、可以归投的〔处所〕」。另 `ukkhittāsiko` 的 `asi` nissaya 作 `သန်လျက်`（剑），建议「举着剑的仇敌」。
