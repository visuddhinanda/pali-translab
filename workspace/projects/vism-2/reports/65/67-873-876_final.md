## 理由
- **评估依据**：注入的数据只有巴利原文和现有译文，缺少义注（本层是复注，父层是《清净道论》本文）和 nissaya。准确性只能对照巴利原文判断，词级的格与句法没有 nissaya 可以对照。父层译文也没有注入，所以**被解释词是否与父层逐字同译无法核对**（如 873-22-36、875-26-32 等引自父层的黑体词）。信心指数因此压低。
- **准确性**：873 段的 a- 前缀诸义（taṃyoga / taṃsambandhitā / taṃsabhāva / taṃkicca / tabbhāva / tabbhāvamatta / sambhāvanīyaguṇa / anappa / taṃsadisa / tadapariyosāna 等排除义）大体译对了，推理链条清楚。875 段各个比喻（悬崖、草火炬、灯焰与涂蜜刀刃、玩粪、吞毒、鬼城）的配合关系都没错。明显有问题的是 873-140-146 的句读：把 nidassana 当作“看不见”的宾语，结果与上一句“可见就是能被看见”互相矛盾。另外，874-79-94 中 upanentā 的宾语疑似指错了。
- **风格**：整体是现代书面汉语，比较通顺。残留两处文言“之”（“善趣果之缘”“不肖之子”）。“转起”这类词对一般读者意思不明确。个别句子有冗余（“……的时候，……在任何时候”）。
- **一致性**：aññāṇa 统一作“无知”，abhāva 统一作“缺无”，ārabhati 统一作“造作”，前后一致。874-119-125 的被解释词“求不死的苦行”受父层译法所限，与本句“能置人于死”的释义字面上冲突，需要加注说明。875-26-32 的被解释词“为了它”与复注的释义“作为……之缘”也不对应。

## 问题清单

### 🟧 error
- `67-873-140-146`｜错译（修饰关系）｜片段「由于眼识看不见这种“可见”」
  - 问题：上一句刚说“可见就是能被看见”，这里又说眼识“看不见可见”，自相矛盾。原文更可能的读法是：或者，nidassana 指眼识；这些法眼识看不见，所以是排除“应由眼识把握”的性质。
  - 建议：改为“或者，‘可见’指眼识；由于眼识看不见这些法，所以它是用来排除应由眼识把握的性质。”

### 🟨 warning
- `67-874-79-94`｜代词指代不明确｜片段「把他们引向渴爱」
  - 问题：taṇhāya upanentā 是把眼等、色等渴爱对象献给渴爱，就像随从为主人奉上物品。译文的“他们”容易读成“具有它们的人”，指代可能错了。
  - 建议：改为“……交给具有它们的人，把这些东西奉给渴爱，就好像是渴爱的随从一样。”
- `67-874-119-125`｜关键词语意不明确｜片段「所以这种苦行叫作**求不死的苦行**（amaratapo）」
  - 问题：本释义把 amara 作 mara（致死）解，但被解释词仍作“求不死的苦行”。与前半句“能置人于死”字面冲突，读者会困惑，要读到下一句才明白。
  - 建议：被解释词保留与父层一致，交 pali-footnote 加注，说明此解中 amara 取“致死”义，意为“致死的苦行”。
- `67-875-26-32`｜文言语体｜片段「善趣果之缘」
  - 问题：“之”是文言虚词。
  - 建议：改为“**为了它**，是指那作为善趣果的缘的福行，而这善趣果的本性就是坏苦。”
- `67-875-26-32`｜关键词语意不明确｜片段「**为了它**」
  - 问题：复注把 tappaccayaṃ 释为“作为它的缘”，被解释词“为了它”与释义不对应。
  - 建议：先核对父层译法。如果父层确实作“为了它”，就交 harmonize 与父层一并斟酌（如“以它为目的／成为它的缘”），或加脚注说明复注的读法。
- `67-873-251-281`｜文言语体｜片段「不肖之子」
  - 问题：含文言虚词“之”。
  - 建议：改为“不配做儿子的人”。
- `67-874-2-18`｜关键词语意不明确｜片段「渴爱在那里转起」
  - 问题：“转起”对一般读者意思不明确。
  - 建议：改为“以此说明渴爱对它生起、运作”，或保留“转起”并加注。

### 🟦 suggestion
- `67-873-22-36`｜语言表达不够流畅｜片段「还没有断除……无知」

  - 建议：核对父层原句。如果父层作“称为无明的无知还没有断除”，就照此引用，去掉省略号。
- `67-873-14-21`｜语言表达不够流畅｜片段「因为没有无明的时候，行在任何时候都不会生起」

  - 建议：改为“因为没有无明，行在任何时候都不会生起。”
- `67-873-287-314`｜语言表达不够流畅｜片段「您是否少病（无病）」

  - 建议：正文作“您是否少病”，另加脚注说明 anāmaya 字面是“无病”，此处取“少病”义。

  - 建议：改为“或成为诸天中的某一位”。
