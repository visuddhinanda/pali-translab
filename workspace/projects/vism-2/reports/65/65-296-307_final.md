## 理由
- **资源**：本次只注入了巴利原文和现有译文，没有义注（aṭṭhakathā，对本书来说就是复注 Paramatthamañjūsā）和 nissaya。准确性只能对照巴利原文，按语法和上下文逐句核对。取义和格位没有外部基准复核，所以信心指数压低到 68。
- **准确性**：整体理解可靠。
  - 三种善巧（增益、损减、方便）译得准确。
  - 苦、集、灭、道四智，以及四无碍解中义、法的界定（因所生的果、缘），都译得准确。
  - 引自《分别论》的文句，句读和“乃至”省略处理得当。
  - 主要问题在 305 段首句：原文是关系从句 `yā … sabhāvanirutti`，界定的是智的对象（自性言词）。译文写成“对……的智：是指……自性言词”，把智本身等同成了言词，造成主宾关系误读。
  - 另外，302 段中 dhamma 从 dahati 得名的词源双关，译文没有交代。
- **风格**：通篇是现代书面汉语，没有文言虚词和文言句式。“临机”“而生、而成”略带书面色彩，但仍在可接受范围内。
  - 305-15-40、306-2-24 两句嵌套较深，读者理解吃力。
  - “四种的部分”这个说法生硬。
- **一致性**：以下译名在本段内和引文前后完全一致：
  - 增益 / 损减 / 方便善巧
  - 苦智 / 苦集智 / 苦灭智 / 趣苦灭道迹智
  - 义 / 法 / 词 / 辩无碍解
  - 精细分别（pabhedagata）

  术语首现括注巴利原词的体例也统一执行了。唯一不齐的是 Catukkesu 在 300 段译作“四种的部分”，下文都用“第 X 组四法”。

## 问题清单

### 🟧 error
- `65-305-2-14`｜错译（修饰关系）｜片段「是指在那义与法之中的自性言词，也就是不会偏离的言说」
  - 问题：原文 `yā tasmiṃ atthe ca dhamme ca sabhāvanirutti abyabhicārī vohāro` 是关系从句，引出下一句 `tassā … sabhāvaniruttiyā … pabhedagataṃ ñāṇaṃ`，说明智所缘的对象。译文用“是指”直接接在被解释词“对其中法词表达的智”之后，把“智”说成“自性言词”，混淆了能知的智和所知的言词。
  - 建议：改为“**对其中法词表达的智**：在那义与法上，有自性言词，也就是不会偏离的言说；”，让后句的“对那称为法词的自性言词……达到精细分别的智”承接出主语。

### 🟨 warning
- `65-300-2-13`｜关键词语意不明确｜片段「在**四种的部分**中」
  - 问题：Catukkesu 指“诸四法组”，“四种的部分”意思不清，也和下文“第一组四法”“第二组四法”不一致（前文三法组译作“第四组三法”）。
  - 建议：改为“在**四法组**中，第一组四法里……”。

### 🟦 suggestion
- `65-302-56-71`｜不常用术语编写注释｜片段「因为缘安立种种果」
  - 问题：原文用 dahati（安立、保持）来解释 dhamma 的得名，是词源双关（dhamma ← √dhā）。中文读者看不出“所以称为‘法’”的理由。
  - 建议：在“安立”后夹注（dahati），或加脚注说明 dhamma 与 dahati 同根。
- `65-297-2-14`｜语言表达不够流畅｜片段「因不利益生起而衰退」
  - 问题：“不利益”不太像现代汉语的常用说法。anattha 指有害、无益之事。
  - 建议：改为“因损害生起而衰退”或“因无益之事生起而衰退”。
- `65-305-51-58`｜不常用术语编写注释｜片段「“phassā”、“vedano”这样的话」
  - 问题：一般读者看不出这两个词形错在哪里（词尾和性、数不合规范），这句的意思就落空了。
  - 建议：加脚注，说明这是屈折不合规范的形式，所以不是自性言词。
- `65-305-15-40`｜复杂嵌套句理解困难｜片段「这样，对那称为法词的自性言词，即摩揭陀语、一切众生的根本语，达到精细分别的智，是**词无碍解**」
  - 问题：整句前面有“在……时，一听到……就知道……”，后面接很长的同位成分，读者难以把握主干。
  - 建议：在“这样”处断句，主干压缩为“这样，对自性言词达到精细分别的智，是**词无碍解**”，把“称为法词的、即摩揭陀语、一切众生的根本语”改用破折号或逗号插入。
- `65-306-2-24`｜语言表达不够流畅｜片段「这就是**辩无碍解**——这是这句话的意思」
  - 问题：“这就是……——这是……的意思”前后重复，读起来拖沓。
  - 建议：改为“……详细了知的智，就是**辩无碍解**。这是这句话的意思。”或者直接省去“这就是”。
