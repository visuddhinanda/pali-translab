# Review — 67:1467-1473（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次没有注入，词级核对降级为只看巴利原文）／父层对照 ✅（book 65 段 1661-1708，已定稿译文）
> 层次：复注（ṭīkā）。父层译文就是黑体被解释词的比对基准。

## 跨段一致性
- **aggahaṇa / ādāna / ādiyati**：§1469 把 uppādādīnaṃ aggahaṇato 译成“不再**执取**生等”。父层和本 chunk 都已经用“执取”对译 ādāna / ādiyati（舍遣而不执取）。这里的 aggahaṇa 意思是“不再以生等为对象、不再注意它们”，和父层 §1699“放下……生、住、转起和相”对应。现在用“执取”，读者会误以为这里讲的是舍遣与执取那一对 → 建议改成“因为他不再取生等为所缘”。
- **-ūpamā 的比喻**：§1469 连续三处用“……之喻”，是文言结构，见下文必改项。统一改为“……的比喻”。
- **bheda / bhaṅga / bhijjati**：§1469 里 bhedameva 译“坏灭”，bhedadassana 译“破坏”，vināsa 译“毁灭”，水泡的 bhijjanti 译“破灭”。这和父层用法一致（父层同样混用“坏灭 / 破坏 / 破灭”），暂不强求统一，只作记录。
- **upaṭṭhāna**：§1467、§1468 统一译“现起”，和父层 §1697、§1698 一致。父层 §1691 自己把它译成“显现为空”，这是父层内部的不一致，复注按 §1697 跟译是对的。建议在统稿（harmonize）时处理父层这一处。

## §1467 句 67-1467-2-78
- **问题**：引文与父层不一致。引用《无碍解道》那句，父层 §1663 译作“心以色为所缘而生起，然后坏灭；省察了那个所缘**之后**”，这里的引文省掉了“之后”。复注是在原样引用父层引过的经文，引文应当逐字一致。
- **建议**：补成“……省察了那个所缘之后”。
- **问题（次要）**：“这些虽然分成三种来说，也就叫做增上慧观”这句里，“也”字不顺。tidhā vuttāpi 的意思是“虽然分三种说，（合起来）都叫作”。
- **建议**：改为“……虽然分成三种来说，都**就叫做增上慧观**”。也可以只让“叫做增上慧观”几个字落在黑体里，只要黑体部分仍和父层 §1697 逐字相同即可。

## §1469 句 67-1469-2-13
- **问题**：被解释词不一致。sambandho 指出本句要连到 bhedameva passati 来理解，译文引号里写的是“只看见坏灭”，父层 §1699 的译法是“只看见**它们的**坏灭”，两者不是逐字相同。
- **建议**：改为“这一句要连到‘只看见它们的坏灭’来理解”，引号用全角。

## §1469 句 67-1469-14-28
- **问题**：风格（必改）。“易碎器皿**之**喻 / 飞散的细尘**之**喻 / 被炒芝麻**之**喻”都用了文言虚词“之”。
- **建议**：改成“易碎器皿的比喻 / 飞散细尘的比喻 / 被炒芝麻的比喻”。
- **问题**：被解释词不完全对应。这里的黑体复合词是从父层 §1699 的比喻里拆出来的，父层写的是“易碎的器皿”“细微的尘土正在飞散”“正在被炒的芝麻”。译文里的“细尘”和父层的“细微的尘土”对不上。
- **建议**：写成“**易碎的器皿**的比喻”“**正在飞散的细微尘土**的比喻”“**正在被炒的芝麻**的比喻”，保证读者能在父层找到同样的字。
- **原文疑问（只记录，不改）**：复注作 bhijjiyamāna-tila（正在破碎的芝麻），父层作 bhajjiyamānānaṃ tilānaṃ（正在被炒的芝麻）。可能是异读或讹误。译文按父层译成“被炒”，这个处理可以接受，建议在 known-issues 登记。

## §1469 句 67-1469-29-35
- **问题**：被解释词不一致（必改）。黑体译成“**只看见坏灭**”，父层 §1699 是“只看见它们的坏灭”。另外巴利黑体只有 bhedameva，passati 是在释文里单独加黑的。
- **建议**：被解释词改成“**只看见它们的坏灭**”，或者只把“坏灭”相关的部分加黑，但要和父层的字对得上。
- **问题**：术语误导。“因为他不再**执取**生等”：aggahaṇa 不是 ādāna 意义上的执取，见上文跨段一致性一节。
- **建议**：改为“因为他不再取生等为所缘”。

## §1470 句 67-1470-25-30
- **问题**：用词不够准确。punabbhavābhāvato 译成“不再有来世的生命”，意思偏松。punabbhava 是“再有 / 后有”，也就是再生。
- **建议**：改为“……之后就不再有后有（再生）”，或者“就不再投生”。

## §1471 句 67-1471-34-37
- **问题**：取义偏窄。icchācāra 在义注传统里指出于恶欲、贪求而做的不当行为（诡诈、暗示求取等邪命之类），“随欲望行事的作为”没有把它和“活命清净”的关联说出来。
- **建议**：改为“由于远离了出于贪求的种种不当行为，所以**活命清净**”。

## §1472 句 67-1472-8-18
- **问题**：表达不清。“**ma**这个音是连接词语用的”：padasandhikara 说的是这个 m 为了连声、连接前后词而插入（aṭṭhaguṇa-m-uttamāni），现在的译法读者看不明白。
- **建议**：改为“**ma** 这个音是为了连接前后词语而加进去的”。

## 父层引文的逐字核对（通过项，只作记录）
- 下列被解释词与父层逐字相同，无需修改：增上慧观、坏灭随观、现起为空、无常随观等、厌离等、三种现起、就像易碎的器皿、同样、都在坏灭、都在坏灭、就像看着海市蜃楼、世间、死王就看不见他、断除有见、舍弃对生命的贪恋、时时、勤勉精进、活命清净、断除焦虑、没有恐惧、获得忍耐与柔和、能够忍受不乐与乐、这八种最殊胜的功德、在其中。
- §1468 的“**见**……**不会**……**动摇**”与父层 §1698“不会因……各种各样的见而动摇”一致。
