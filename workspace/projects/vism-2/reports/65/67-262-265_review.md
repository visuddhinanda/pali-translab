## 被解释词与父层逐字核对

以下 20 处逐一比对，都与父层译文逐字相同，没有必改项：
- 譬如 / 还不懂事的 / 日常使用 / 真的 / 假的 / 只值一半 / 这些方面
- 想 / 识 / 慧 / 从种种方面去知
- 不一定有慧 / 并不分离 / 那些法 / 所以…说 / 非色的心和心所
- 诸法的自性 / 慧以通达诸法的自性为特相 / 以不迷惑为现起 / 定是慧的近因

有两处可以接受，只作说明：
- 67-262-41-49：**这样** 对应父层 280「这样的区分」里的「这样」，对得上。
- 67-265-36-43：**摧毁**…**愚痴黑暗为作用** 分两段加粗，每段都与父层「以摧毁遮蔽诸法自性的愚痴黑暗为作用」逐字相同，对应没有断。中间多了「上述」，这来自原文 yathāvutta，不是改动被解释词。

## 跨段一致性
- paccupaṭṭhāna／paccupatiṭṭhati（现起）：§265 句 60-68 和黑体被解释词都译「现起」，§265 句 44-59 的动词 paccupatiṭṭhati 却译成「现前」。
  - **建议**：统一为「现起」。这句正是在解释 asammoha**paccupaṭṭhāna** 的来由，动词和术语不同字，读者就看不出这层词源上的对应。
- cittuppāda：§264 句 2-7 和句 8-19 译「心生起」，句 20-25 译「心的生起」（「二因心和无因心的生起」）。
  - **建议**：统一为「心生起」。句 20-25 可改为「在二因和无因的心生起中」。

## §263 句 67-263-7-16
- **问题**：风格。piṇḍavaseneva 译成「整团地」，汉语里不自然。
- **建议**：改为「笼统地」或「只是整体地把握所缘」。

## §263 句 67-263-17-26
- **问题**：风格（半文言）。「以如其所现的对象为近因」里的「如其所现」是文言结构。
- **建议**：改为「以按原样呈现出来的对象为近因」。

## §264 句 67-264-2-7
- **问题**：表达。「就是在哪一个心生起（cittuppāda）中」读起来像疑问句。原文 yasmiṃ cittuppāde 是关系代词，表示「在其中那个心生起」。
- **建议**：改为「**地方**：指的是心生起（cittuppāda），也就是在某一个心生起当中」，或者简写为「**地方**：指心生起（cittuppāda）」。

## §265 句 67-265-44-59
- **问题**：术语不统一，见上文跨段一致性。
- **建议**：「它以对诸法自性不迷惑的方式现前」改为「……的方式现起」。

## §265 句 67-265-82-128
- **问题**：格式。出处括注放在句号之后，本 chunk 和父层都是括注紧跟引文、再加句末标点。
- **建议**：「这句经文被作为依据引用（《相应部》3.5,99；《相应部》5.1071；《导论》40；《弥兰王问经》2.1.14）。」
- **可选**：nibandhanabhāvena āgataṃ 的意思是「作为根据出现在经中」。可以考虑改为「正因为如此，经中有‘得定的人如实了知’这句话作为根据」，更贴原文。

## §262 句 67-262-28-31
- **问题**：可能译宽了。mahāsāro 只说价值高，「成色十足」是译者补的。
- **建议**：可改为「**真的**：就是价值高的，也就是足值的」，或保留原译。这一处不是必改。

## 存疑（不必改译文，记录备查）
- 67-262-41-49：pādasāra / samasāra / paropādasāra 分别译作「值四分之一的 / 足值的 / 值四分之一以上的」。samasāra 和 paropādasāra 的确切币值没有旁证，建议查《清净道论大疏》其他版本或缅文 nissaya 核实。
- 67-262-50-57：indajālājātipupphādi 按「因陀罗网纹、茉莉花纹」拆分，词的切分（indajāla + jātipuppha）有待 nissaya 核实。
- 67-263-60-85：《小义释》品名 mogharāja 译「摩伽罗阇」。常见译法还有「莫伽罗阇」，建议查项目术语表后统一；术语表目前没有收录。

- 67-262-41-49：原文 `pādasāra samasāraparopādasārādīnaṃ` 在 pādasāra 后断开了，按语法应该连写成 `pādasārasamasāra…`。可能是录入时断开的，记下来，不改。
