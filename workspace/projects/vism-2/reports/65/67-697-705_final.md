## 理由

**资源情况**：这次只注入了巴利原文和定稿译文。本段是复注（ṭīkā），父层的义注段落和 nissaya 都没有提供，所以只能退一步，直接拿巴利原文逐句核对。下面两件事因此没法复核，信心指数也相应调低：
- 被解释词（黑体）是否与义注层逐字同译；
- 格和句法角色有没有 nissaya 的佐证。

**准确性**：取义整体扎实，逻辑论辩部分处理得尤其好：
- 有法不成（dhammiasiddhi）、所依不成（nissayāsiddha）、理由的特相（hetulakkhaṇa）都用了恰当的汉语术语。
- 反面 / 正面（byatireka / anugamana）也译得恰当。
- 698-25-31 对 apekkhadhammattā 的展开解释，符合"理由须为宗法"的论理，属于合理的意译。
- 701 段按倒序解释 ajāta / abhūta / akata / asaṅkhata 的链条，层次清楚，没有漏译。
- 705 段 yasmā … tasmā 跨了三行，译文用"就是用这些经文宣示了……所以……"承接，因果关系保住了。

**可能的原文问题**：697-2-30 的 sattasantānapariyāpanno ca（"包含在众生的相续中"）放在论辩里有些不顺。按论证逻辑，更像是 asattasantānapariyāpanno（"不属于任何众生的相续，所以应当像会堂那样人人共有"）。译文忠实于现有底本，不扣分，但建议对照别本核实，并记进 known-issues。

**风格**：通篇是现代书面汉语，没有发现文言虚词或文言句式。偶有语病和长句负担，见问题清单。

**一致性**：
- 同一个"注释书作者"，697 称"论主"，699 称"论师"，前后不统一。
- 被解释词的黑体和引号，704 与全篇其他地方的套法不一样。
- 本文引文（703）和复注的解释（701、704）之间，四个词的译法完全一致（不生 / 不成 / 不作 / 无为，已生 / 已成 / 已作 / 有为），"但是……因为"也与 703 对齐，这一点做得好。

## 问题清单

### 🟨 warning
- `67-699-57-74`｜不导致误解的汉语语病｜片段「因为它根本没有所住之处」
  - 问题：同一句里连用了两个"因为"（"因为涅槃不能被指定为……，因为它……"）。第二个是 yato，意思是"既然 / 原因在于"，两个"因为"叠在一起，句子读起来很拖沓。
  - 建议：改为"……或"在某个地方"，原因就在于它根本没有所住之处。"或者把第一个"因为"改成"其实"。
- `67-699-2-17`｜语言风格不统一｜片段「论师自己」
  - 问题：697-2-30 把 āha 的主语译作"论主"，这里 attanā 指的是同一位注释书作者，却译作"论师"，同一段里称谓不统一。
  - 建议：统一为"论主"（或统一为"论师"），并与全书统稿时的称谓保持一致。

### 🟦 suggestion
- `67-704-47-66`｜语言风格不统一｜片段「“**但是……因为**”」
  - 问题：全篇被解释词都把引号套在黑体里面（如 **“无为”**），只有这里是引号在外、黑体在内，格式不一致。
  - 建议：改为 **“但是……因为”**。
- `67-702-9-31`｜不常用术语编写注释或者百科｜片段「那些只能理解字句的人」
  - 问题：padaparama 是四种人（ugghaṭitaññū / vipañcitaññū / neyya / padaparama）中的专名。只译成描述性的话，读者看不出这是一个固定类别。
  - 建议：首次出现时夹注巴利原词，如"那些只能理解字句的人（padaparama）"，或者加脚注说明四种人的分类。
- `67-705-75-138`｜复杂的嵌套句整句语言逻辑理解困难（对读者不友好）｜片段「悲悯一切世间的正等正觉者就是用这些经文宣示了涅槃界在胜义上真实存在」
  - 问题：705-2-19 到这里，先连列了四处引文，再补主语和谓语，读者要读到本句中段才明白前面的引文是做什么用的。原文的 yasmā（"因为"）在 705-2-19 里也没有显出来。
  - 建议：在 705-2-19 开头补出因果框架，如"此外，在这件事上，因为……"，或者在引文列举前先交代"正等正觉者用下列经文宣示了……"。
- `67-705-75-138`｜语言表达不够流畅｜片段「也根本不会有疑惑」
  - 问题：原文 yadipi（"虽然"）带出一个让步关系，与下一句的 ye pana（"但是那些人……"）前后呼应。现在的译文把让步义丢了，两句之间的转折略显突兀。
  - 建议：改为"……虽然根本不会有疑惑，"，再接 705-139-149 的"但是，对于那些……"。或者在本句末尾用"固然"表达让步。
