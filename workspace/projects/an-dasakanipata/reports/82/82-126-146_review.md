# Review — 82:126-146（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- ekārakkho：§127、§130 译“只有一种守护”，§133（两句）译“有一种守护” → 建议统一为“有一种守护”。依据：`ဧကာရက္ခော= တခုသော အစောင့်အရှောက်တရားရှိသည်`，意思是“具有一种守护法”，没有“只有”这层限定义。
- 译文里有存疑工作标记：§135“（某些版本作 nuṇṇāni honti panuṇṇāni，存疑）”，§141“（某些版本作 yepi，存疑）”。两处做法相同，都要删掉，见下文分句意见。

## §127 句 82-127-37-69（§130 句 82-130-22-48 同）
- **问题**：词义 — ekārakkho 译成“只有一种守护”。nissaya `ဧကာရက္ခော= တခုသော အစောင့်အရှောက်တရားရှိသည်` 是“具有一种守护法”，“只有”多加了排他义。
- **建议**：改为“有一种守护”，与 §133 统一。
- **问题**（次要）：samavayasaṭṭhesano 的 nissaya 是 `ကောင်းမွန်စွာ စွန့်လွှတ်အပ်ပြီးသော အားလုံးစုံသော ရှာမှီးခြင်းရှိသည်`，意思是“一切追求都已被妥善舍弃”。“完全舍弃了追求”大意不错，但“一切”(samavaya) 没有落实到“追求”上。
- **建议**：可改为“舍弃了一切追求”。如果改，§136 的两句要同步改。

## §129 句 82-129-2-16
- **问题**：句法误读 — kammāsadhammaṃ nāma kurūnaṃ nigamo 是**主格**，不是处格。nissaya 专门说明：这个集镇里没有供世尊住的精舍，所以原文用主格 `နိဂမော`，不用处格 `နိဂမေ`，不能译成“世尊住在这个集镇里”。nissaya 补出的隐含成分是 `(အတ္တိ= ရှိ၏။ တံ နိဂမံ= ထိုနိဂုံးကို။ ဂေါစရဂါမံ= ဆွမ်းခံရွာကို။ ကတွာ= ပြု၍။)`，即“有（一个集镇），把它当作托钵的村落”。现译“在俱卢人一个名叫剑磨瑟昙的集镇里”把世尊的住处定在了集镇里，与 nissaya 相反。
- **建议**：改为“有一次，世尊住在俱卢国。俱卢人有一个集镇，名叫剑磨瑟昙。”或“……住在俱卢国，以俱卢人名叫剑磨瑟昙的集镇为托钵的村落。”**必改**。

## §129 句 82-129-17-25
- **问题**：取义 — tatra 的 nissaya 是 `ထိုအခါ၌`（在那时），并补出“世尊以剑磨瑟昙集镇为托钵处而住的那个时候”，是时间义。现译“在那里”是处所义，而且容易让读者再次以为世尊住在集镇里，与上一句的问题叠在一起。
- **建议**：改为“那时，世尊对比丘们说……（中略）……”。

## §135 句 82-135-14-25
- **问题**：格与句法 — bhikkhuno 的 nissaya 是 `ရဟန်းသည်`，并注明它要远接后文 nunnāni paṇunnāni，是那些被动分词的**施事**（“被比丘推开”）。现译“对这位比丘来说”把它读成了与格/关涉义，下句又补“被他推开”，等于施事说了两遍，而且前后不连贯。
- **建议**：本句去掉“对这位比丘来说”，直接写“比丘们，在这里，各种沙门（samaṇa）和婆罗门所持的种种个别的真理主张，也就是说：”。施事放到下句，写成“都已被比丘推开了……”。

## §135 句 82-135-26-137
- **问题**：工作标记 — 译文里有“（某些版本作 nuṇṇāni honti panuṇṇāni，存疑）”。读本异文和存疑都不该写进译文。**必改**。
- **建议**：删掉这个括注，异文另记到报告或脚注里。
- **问题**：取义 — tathāgato 的 nissaya 是 `တထာဂတော= သတ္တဝါသည်`，在这一组见解里指“有情、众生”，不指佛陀。现译四处都作“如来”，读者会理解成专指佛陀。
- **建议**：保留“如来”这个传统译名，但在首次出现处加脚注，说明这里的“如来”按传统解释指有情。也可以直接译成“有情”。至少要做其中一种处理。
- **问题**（次要）：jīva 的 nissaya 是 `အသက်ရှင်ကောင်အတ္တ`，指能存活的“我”（命我、灵魂）。“生命”偏向生物学意义，与 sarīra（身体）对举时会失焦。
- **建议**：可改为“命（jīva）和身体是同一个”“命是一个，身体是另一个”，首次出现夹注巴利原词。
- 七个分词 nunnāni / paṇunnāni / cattāni / vantāni / muttāni / pahīnāni / paṭinissaṭṭhāni 与 nissaya 逐一对得上，没有漏译。

## §140 句 82-140-12-51
- **问题**（次要）：词义 — anabhāvaṃkato 的 nissaya 是 `နောင်၌ဖြစ်ခြင်းမရှိအောင် ပြုအပ်ပြီ`，意思是“已被处理成以后不再生起”，是被动完成义。现译“已经不再存在”变成了状态描述，失去了“被弄成”的意味，也和后面的“将来不会再生起”意思重复。
- **建议**：可改为“已被彻底灭除”或“已被弄得不复存在”。痴的那一句同步改。

## §141 句 82-141-40-64
- **问题**：工作标记 — 译文里有“（某些版本作 yepi，存疑）”。**必改**。
- **建议**：删掉这个括注，改为“比丘们，现在凡是有圣者安住于圣住的，所有这些圣者安住的正是这十种圣住。”
