# Review — 82:298-320（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句有，无 nissaya 的句子不出意见）

## 跨段一致性
- **avakassanti / apakassanti**：§301、§303、§305、§311 都译成“拉拢人、分化人”（否定式为“不拉拢人，不分化人”）。按 nissaya，两词都是“拉拢、吸收会众”，后者是加强义（见 §301 句 82-301-94-121），“分化人”与 nissaya 相悖。四处要一起改，建议统一为“拉拢会众、极力拉拢会众”。
- **anāciṇṇa / āciṇṇa**：§301、§303、§305、§311 都译成“（没有）实行过”。nissaya 的释义是“惯常奉行的传统行持”（လေ့ကျက်အပ်သော အစဉ်အလာအကျင့်），说的是惯常的行持，不是某一次做过。建议四处统一为“如来（不曾）惯常奉行的”。
- **idha 的译法**：§301、§303 译“在这教法中，比丘们……”，与 nissaya 的 ဣဓ= ဤသာသနာတော်၌ 一致；平行的 §305、§311 译“这里有比丘……”。建议后两段统一为“在这教法中，比丘们……”。
- **经末序号的标点**：§299“第六经。”、§301“第七经。”、§303“第八经。”用句号；§309“第九经；”、§315“第十经；”用分号。建议统一为句号。
- **平行文献出处**：§303 的“（小品三五三）”把原文的平行出处标注写进了译文；§309 的异读与出处 [bhetvāna … cūḷava.354; itivu.18; kathāva.657] 没有进入译文。建议统一处理，通常是都不进正文。
- **yogakkhema**：§308、§314 都译“从安稳上退失”，两处一致，但译法本身有问题，见 §308。

## §299 句 82-299-2-23
- **问题**：无实质错误。nissaya 把 upaṭṭhāpetabbo 释为“使（沙弥）侍奉自己”，并补出“自己作为戒师（upajjhāya）收沙弥为侍者”。“让沙弥随侍”与此相符。
- **建议**：保留。

## §301 句 82-301-31-93
- **问题**：词义偏差。anāciṇṇaṃ = မလေ့ကျက်အပ်သော အစဉ်အလာအကျင့်ကို（不曾惯行的传统行持），āciṇṇaṃ 同理。译文“没有实行过 / 实行过”丢了“惯常、传统”的意思。
- **建议**：改为“把如来不曾惯常奉行的说成是如来惯常奉行的，把如来惯常奉行的说成是如来不曾惯常奉行的”。

## §301 句 82-301-94-121
- **问题 1**：误译。avakassanti = ပရိသတ်ကို ဆွဲဆောင်သိမ်းသွင်း（拉拢、吸收会众）；apakassanti = ပရိသတ်ကို အလွန်အကဲ ဆွဲဆောင်သိမ်းသွင်း（极力拉拢、吸收会众）。两词同向，都是拉人，后者程度更强。译文“分化人”与 nissaya 相悖。
- **问题 2**：隐含宾语。nissaya 补出的宾语是 ပရိသတ်（会众），译文泛称“人”，范围偏宽。
- **问题 3**：术语。kammāni = သံဃာ့ကံ（僧团羯磨）。“僧事”可以接受，但“僧团羯磨”更准确。
- **建议**：改为“他们以这十种事由拉拢会众、极力拉拢会众，另行举行僧团羯磨，另行诵说波罗提木叉。”

## §303 句 82-303-98-114
- **问题**：与 §301 同类误译。na avakassanti = ပရိသတ်ကို မဆွဲဆောင် မသိမ်းသွင်း（不拉拢、不吸收会众），“不分化人”与 nissaya 不符。
- **建议**：改为“他们不以这十种事由拉拢会众，不极力拉拢会众，不另行举行僧团羯磨，不另行诵说波罗提木叉。”

## §306 句 82-306-18-29
- **问题 1**：修饰关系不清。kappaṭṭhikaṃ = အာယုကပ်ပတ်လုံး အဝီစိငရဲ၌တည်နေရကြောင်းဖြစ်သော，意思是“使人在阿鼻地狱住满一个寿劫的”，修饰罪业的后果。译文“延续一劫的罪过”容易读成罪过本身持续一劫。
- **问题 2**：动词取义。pasavati 的主释是 ဖြစ်စေ၏（使产生、造下），“得到”（ရရှိ）是 ဝါ 后列的异释。kibbisaṃ = မကောင်းမှုအကုသိုလ်（恶业、不善）。
- **建议**：改为“阿难，他会造下令人在地狱住满一劫的罪业。”§306 句 82-306-2-17 和 82-306-30-42 随之调整。

## §306 句 82-306-43-51
- **问题**：所指可补明，属次要问题。nissaya 注明 kappaṃ 指阿鼻地狱的寿劫（即中劫 antarakappa），nirayamhi 指大阿鼻地狱。译文“一劫”“地狱”不算错。
- **建议**：可以保留。若要精确，可在译注中说明“劫”指地狱寿劫，正文不必改。

## §308 句 82-308-2-7
- **问题**：术语译得太泛。yogakkhemā = ယောဂလေးဖြာဘေးကုန်ရာ အရဟတ္တဖိုလ်မှ（从四轭止息的安稳，即阿罗汉果，退落）。“从安稳上退失”丢了“轭（yoga）”这层意思，“安稳上”也不太通顺。
- **建议**：改为“就从离轭的安稳中退失”。§314 同步改为“就不会从离轭的安稳中退失”。

## §312 句 82-312-19-30
- **问题**：程度过度。brahmaṃ = မြတ်သော（殊胜的、高尚的），nissaya 没有“最”的意思，“最上的福德”说过头了。
- **建议**：改为“殊胜的福德”，也可以用传统译法“梵福”。§312 句 82-312-31-43 同步修改。

## §313 句 82-313-2-11
- **问题**：句法误读，必改。samaggānaṃ = ညီညွတ်နေသော ပုဂ္ဂိုလ်တို့ကို（以那些和合的人为对象），是 anuggaho 的受事。anuggaho = （ညီညွတ်မှု မပျက်အောင်）အားပေးစောင့်ရှောက်ချီးမြှင့်ခြင်း（为了不让和合破坏，去鼓励、护持、扶助）。nissaya 引的 Vimatiṭīkā 也说 yathā samaggānaṃ sāmaggī na bhijjati, evaṃ anuggahaṇaṃ（护持他们，使他们的和合不坏）。所以这里是护持和合的人们，不是和合的人们“互相扶助”。
- **次要问题**：sukhā = ကိုယ်စိတ်နှစ်ဖြာ ချမ်းသာကြောင်း（身心安乐之因），可以译得更贴近一些。
- **建议**：改为“僧团的和合带来安乐，护持和合的人们也带来安乐；”

## §314 句 82-314-2-8
- **问题**：见 §308 的 yogakkhema 一条。另外，nissaya 把 dhammaṭṭho 释为“住于善法的人”（ကုသိုလ်တရား၌တည်သော），“立足于法”可以接受。
- **建议**：只改 yogakkhema 的译法。
