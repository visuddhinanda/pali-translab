# Review — 82:843-855（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 层次：本文 mūla，无父层，不查被解释词对齐。

## 跨段一致性

- **cetayita**：§852、§853、§854、§855 全部译作「由心思构想的」。这几处的译法本身前后一致，问题在于 nissaya 不支持这个取义，见 §852 句 82-852-46-54。改动时这四段要一起改。
- **kira（iti kira tvaṃ…）**：§847、§848 都译作「这么说」。nissaya 两处都读作条件句（အကယ်၍＝如果），改的话两段要统一，见 §847 句 82-847-2-16。
- **tadeveso āyasmā allīno / ajjhupagato**：§852、§853、§854 三处都是同一个译法，eva 的落点都有偏移，见 §852 句 82-852-69-78。三段要同步改。
- **te āyasmanto（§845）与 āyasmanto / āyasmā（§848 起）**：§845 是外道游行者在背后称呼乔达摩的弟子，nissaya 注明是「沙门乔达摩的出家、在家弟子们」。§848 起是长者当面称呼游行者。两处都译作「尊者」，读者容易把 §845 的「那些尊者们」理解成在场的游行者。建议 §845 改为「乔达摩的那些弟子」或「那些人」。

## §844 句 82-844-16-26

- **问题**：词义 — divā divassa 的 nissaya 是 `ဒိဝါ= မွန်းမတ်မတ်တည့်ရာ နေ့လည်အခါ၌`（日正当中的午间）。「在大白天里」没有译出「正午」这层意思。另外「就」暗示动身得早，nissaya 没有这个意思。
- **建议**：改为「那时，给孤独长者在正午时分离开舍卫城，要去见世尊。」

## §844 句 82-844-33-40

- **问题**：漏译 — tāva 的 nissaya 是 `ပဌမဦးဆုံး`（首先），并补出「（不先去游行者园林，而）首先」。译文把 tāva 弱化成了「现在还」，没有表达出「先去」的意思，下文「不如先到外道园林去」的对照也因此断了。
- **建议**：改为「现在先去见世尊，还不是时候。」

## §844 句 82-844-44-48 / 82-844-49-52

- **问题**：取义 — manobhāvanīya 的 nissaya 主释是 `စိတ်နှလုံးကို တိုးတက်ကြီးပွားစေတတ်ကုန်သော`（能令人心增长的），异释（ဝါ）是「值得以心称赞的」。译文「值得敬重的」接近异释，丢掉了主释「令心增长」的意思。
- **建议**：主译取「能令人心增上的比丘」，或「令人心生增上的比丘」。异释按 style.md 第四节放进脚注。两句要同步改。

## §845 句 82-845-12-27

- **问题**：术语偏窄 — tiracchānakathā 的 nissaya 是 `နတ်ပြည်နိဗ္ဗာန်လမ်းခရီးတို့၏ ဆန့်ကျင်ဘက်စကား`（与生天、涅槃之道相违的言谈）。「无意义的话题」只表达了「无聊」，没有表达出「背离解脱道」的意思。
- **建议**：改为「谈论着种种背离生天与涅槃之道的闲话」，或者用传统译名「畜生论」并首次夹注。定名后补进 terms.md。

## §845 句 82-845-38-41

- **问题**：误读 — saṇṭhāpesuṃ 的 nissaya 是 `ဣရိယာပုတ်လေးဖြာ, နှုတ်အမူအရာကို ကောင်းစွာစောင့်စည်းတည်နေစေကြကုန်ပြီ`（互相使四威仪与言语举止收敛、安住）。意思是互相提醒、让彼此收敛，不是「约定」。
- **建议**：改为「看见以后，他们互相提醒，要彼此收敛举止，说：」

## §845 句 82-845-52-60

- **问题**：补出成分 — ārāmaṃ 的 nissaya 是 `ငါတို့ကျောင်းတိုက်သို့`（到我们的园林）。
- **建议**：可改为「正到我们的园林来」，与上文长者要去「外道游行者们的园林」相呼应。此项为可选。

## §845 句 82-845-78-87

- **问题**：指称不清 — te āyasmanto 的 nissaya 补出 `ထိုရဟန်းဂေါတမ၏ တပည့်ရှင်လူတို့`（那位沙门乔达摩的出家、在家弟子们）。appasaddavinītā 的 nissaya 是「受（崇尚少声、言语有度的）导师乔达摩调教」，译文「受过安静的训练」没有写出施教者。
- **建议**：改为「乔达摩的那些弟子喜欢安静，受导师调教而崇尚安静，也称赞安静的人。」appasaddassa vaṇṇavādino 的 nissaya 是「称赞无声者之德」，所以译作「称赞安静的人」。

## §845 句 82-845-88-98

- **问题**：词义 — upasaṅkamitabbaṃ maññeyya 的 nissaya 是 `လာရောက်ထိုက်၏ဟူ၍ … မှတ်ထင်တန်ကောင်းရာပါ၏`（会认为值得过来）。重点在「认为值得」，不是「想要」。nissaya 还补出主语是这位长者。
- **建议**：改为「这位长者知道我们这群人很安静，也许会认为值得过来吧。」

## §847 句 82-847-2-16

- **问题**：句法 — 这里的 kira 按 nissaya 读作条件（`ကိရ န ဇာနာသိ= အကယ်၍ မသိအံ့`，若不知）。nissaya 附注引《无碍解道》义疏：「iti＝evam 义，kira＝yadi 义」。下句又补出 `ဧဝံ သတိ`（既然如此）。所以两句是「如果……那么……」的条件结构。
- **建议**：改为「长者，如果像你说的那样，你不知道沙门乔达摩的全部见解，」。下句「那么长者，你说说看……」保留。

## §848 句 82-848-2-21

- **问题**：句法 — 与 §847 同一结构，nissaya 同样读作 `ကိရ န ဇာနာတိ= အကယ်၍ မသိအံ့`。
- **建议**：改为「长者，如果像你说的那样，你既不知道沙门乔达摩的全部见解，也不知道比丘们的全部见解，」。与 §847 统一。

## §848 句 82-848-46-64

- **问题**：时态与漏译 — na bhavissati 的 nissaya 是 `မဖြစ်လတ္တံ့`（将不会），是将来时，译文「那并不难」译成了现在时。etaṃpi 的 nissaya 是 `ဤအကျွန်ုပ်အယူကိုလည်း`（这个也），这里的 pi 漏译了。
- **建议**：改为「请各位尊者先说明自己各自所持的见解，之后由我们来说明自己持什么见解，那也不会难。」

## §852 句 82-852-46-54

- **问题**：取义 — cetayita 的 nissaya 是 `အကြောင်းတရားတို့က စေ့ဆော်အားထုတ်ပြုလုပ်အပ်သော`（由诸因缘驱动造作的）。行为主体是因缘，不是「心思」。「由心思构想的」把它读成了主观构想。saṅkhata 的 nissaya 是 `အကြောင်းတရားတို့က ပေါင်းဆုံ၍ ပြုလုပ်အပ်သော`（由诸因缘聚合所造作）。两词都以「因缘」为施事。
- **建议**：cetayita 改为「被（因缘）驱动造作的」，或用「思所造的」。§852–§855 共六处同步修改。

## §852 句 82-852-55-64

- **问题**：补出成分 — yaṃ kiñci 的 nissaya 补出 `ရုပ်နာမ်ခန္ဓာတရားအပေါင်း`（一切名色诸蕴法）。「东西」偏口语，范围也模糊。
- **建议**：改为「凡是……的法」。§853、§854、§855 中的同一句同步修改。

## §852 句 82-852-69-78

- **问题**：强调落点 — tadeva 的 nissaya 是 `ထိုဒုက္ခဖြစ်သော တရားသို့သာလျှင်`（唯独向那苦法），eva 强调的是对象「苦」，不是动作。译文「就是执著于它」把重心放在了「执著」上。ajjhupagato 的 nissaya 是 `အလွန်အကဲကပ်ရောက်နေ၏`（过度趋近、投入），「陷入」的意思还可以接受。
- **建议**：改为「凡是苦的，这位尊者黏着的正是它，投身的也正是它。」§853 句 82-853-60-69 和 §854 句 82-854-104-116 同步修改。

## §853 句 82-853-12-36

- **问题**：pi 的位置 — nissaya 是 `အယံ ဒိဋ္ဌိပိ`（这个见解也），pi 修饰「见解」。译文另起一句「也是如此」，显得冗赘。
- **建议**：改为「这位尊者的这个见解，同样或是由于……，或是……」。§854 句 82-854-11-80 同步修改。

## §855 句 82-855-51-73

- **问题**：句法与补出成分 —
  - taṃ 的 nissaya 是 `ထိုဒုက္ခဖြစ်သော တရားအားလုံးကို`（对于那一切苦法，宾格）。nissaya 还补出谓语 `(ပဿာမိ= ရှုပါ၏)`（我观看为），表示长者「把苦看作非我所、非我、非我的自我」。译文「那就不是我的」把 taṃ 和 etaṃ 合并了，丢掉了「我这样看待」的结构。
  - nesohamasmi 的 nissaya 是 `ဧသော … အဟံ … န အသ္မိ`，以「这（苦法）」为主语，即「这不是我」。译文「我不是这个」主宾倒置。
- **建议**：改为「凡是苦的，我都看作：‘这不是我的，这不是我，这不是我的自我。’诸位尊者，我持这样的见解。」nissaya 另有一读（「诸位尊者，我对那苦持『这不是我的……』这样的见解」），可以放进脚注。
