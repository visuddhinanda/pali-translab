# Review — 82:1385-1391（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（82-1387-20-33、82-1388-28-53、82-1390-2-28 三句无 nissaya，已略过）

## 跨段一致性
- kāmaguṇa：§1385、§1386、§1387、§1388 四处都译“五种欲乐”。译法前后统一，但词义有偏差，见 §1385 句 82-1385-42-49。改译时四处要一起改。
- lābhī hoti：四处都译“能得到”，前后一致。nissaya 作 `လာဘီ= ရခြင်းရှိသည်`（是获得者），没有“能够”的情态。建议四处统一改为“得到”或“享有”，属可选项。
- 其余重复句式（远离杀生……乃至……、身体毁坏死亡以后、与人类／天神同住、施主也不会没有果报）在本 chunk 内一致，无漂移。

## §1385 句 82-1385-42-49
- **问题**：词义偏窄 — kāmaguṇa。nissaya 作 `ကာမဂုဏာနံ= ရူပါရုံစသော ကာမဂုဏ်တို့ကို`，意思是“以色所缘为首的诸欲功德”，指色、声、香、味、触这五种可欲的对象，属于宾格（`ကို`），是“所得之物”。译成“欲乐”就把它变成了感受上的快乐，偏离了“对象”这一义。
- **建议**：改为“五种欲功德”或“五种感官享受的对象”，与本句宾格的“得到”搭配。§1386、§1387、§1388 同改。
- **附**：tattha 在 nissaya 作 `ထိုလူ့ဘဝ၌`（在那人类生存中）。“在那里”可以接受；如果想让指代更清楚，可以写成“在人间”。§1387 的 tattha 对应 `ထိုနတ်ဘဝ၌`，同理可写成“在天界”。

## §1389 句 82-1389-14-36
- **问题**：句法误读 — yāva ca。nissaya 作 `ယာဝ စ= အလွန်အကဲပင်`（极其、非常），是修饰 `အလမေဝ`（实在适宜）的程度副词，不是独立的感叹句。译文把它单独译成“竟到这样的地步！”，割裂了句子结构。
- **问题**：因果关系的主次 — nissaya 先解 `ယတြ= အကြင့်ကြောင့်`（因为）……`အနိပ္ဖလော … ဟောတိ နာမ`，再接 `တသ္မာ= ထို့ကြောင့်`（所以），结构是“因为施主也不会没有果报，所以非常值得布施”。译文把原因放在句末补述，因果仍然成立，但重心偏了。
- **问题**：词义 — saddhāni。nissaya 作 `သေသူကို ရည်မှန်း၍ လှူဒါန်းအပ်သော အလှူတို့ကို`（为亡者而施的供施，宾格）。这是布施性质的供养，“祭祀”一词会引向献祭仪式。
- **建议**：参考译法：“乔达摩先生，既然连施主也不会没有果报，那么布施实在非常值得做，为亡者作追荐布施也实在非常值得做。”

## §1388 句 82-1388-54-64
- **问题**：轻微 — Api ca。nissaya 作 `အပိစ= ကား`，是带转折意味的提示（“但是／然而”），表示话题从亡者能否受益转到施主本身。“而且”偏向递进，语气不完全对。
- **建议**：改为“不过，婆罗门，施主也不会没有果报。”
