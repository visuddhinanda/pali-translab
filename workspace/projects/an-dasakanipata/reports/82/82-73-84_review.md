# Review — 82:73-84（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，那些句只在跨段一致性里涉及）

## 跨段一致性

- **katamassa = katame + assa**（§75、§77、§82、§84）：nissaya 把它拆成 `ကတမေ= အဘယ်မည်ကုန်သော`（哪些，修饰 cetokhilā）+ `အဿ= ထိုရဟန်းသည်`（那位比丘）。疑问的对象是“哪五种”，不是“哪一个人”。现译四处都译成“哪一个人的五种……”，主宾关系误读，应统一改为“他的哪五种……”。§84 2-9 无 nissaya，但句式相同，要一起改。
- **imassa = ime + assa**（§76 66-72、§78 110-115、§83 74-79）：nissaya 注 `[ဣမဿ= ဣမေ + အဿ။]`，即“这些（五种）+ 那位比丘”，是总结句“他的这五种……”。现译“这样的人，五种……”把 imassa 读成“这个人的”，丢了 ime（这些），应统一改为“他的这五种……”。§83 74-79 无 nissaya，但句式相同，要一起改。
- **khila 的译法**：cetokhila 译“心的荒芜”，同族词 khilajāto 却译“变得荒硬”，同一词根在本 chunk 里出现两种译法。nissaya 对两者的释义一致：cetokhilā = `စိတ်၏ ကြမ်းတမ်းခက်ထန်ကြောင်းတရား`（让心粗糙、僵硬的法），khilajāto = `ကြမ်းတမ်းခက်ထန်ကြောင်းဒေါသရှိသူ`（生起了让心粗硬的嗔恚）。核心义是“粗硬、刚硬”，不是“荒芜”。建议定一个词根两处共用（例如“心的顽硬”和“变得顽硬”），或者保留“荒芜”但把 khilajāto 也对应过来。定案后登记进 `terms.md`。
- **Yassa（关系代词）漏译**（§75 44-59、§76 50-65、§77 49-63、§78 95-109、§82 47-60、§83 60-73、§84 47-60）：每句都以“心不倾向于……”开头，没有译出 yassa（“谁的心”），与后面的 assa（他）失去对应。建议统一改为“谁的心不倾向于……，由于这样，他的……”。
- **evaṃ … ayaṃ**（同上 7 句）：nissaya 注 `ဧဝံ= ဤသို့ မညွတ်ကိုင်းခြင်းအားဖြင့်`（由于这样不倾向），`အယံ= ဤမည်သော`（这个，即……）。现译只有“这样，他的第 N 种……”，没有译出 ayaṃ，evaṃ 的因果义也偏弱。建议统一为“由于这样，他的这第 N 种……”。
- **ratti / divaso 的语序**（§74、§79、§80、§81）：巴利原文是先“夜”后“日”（yā ratti vā divaso vā，nissaya 也依此序），译文统一作“白天还是夜晚”。四处前后一致，属次要问题，可考虑改为“不论夜晚还是白天”。

## §74 句 82-74-2-37

- **问题**：词法 — appahīnā 的 nissaya 是 `မပယ်သတ်အပ်သေးကုန်အံ့`，asamucchinnā 是 `မပယ်ဖြတ်အပ်သေးကုန်အံ့`，含 `သေး`（尚未）和假设语气 `အံ့`（如果）。现译“没有断除、没有根除”缺了“尚未”的体貌。
- **建议**：可改为“还没有断除……还没有根除”。假设语气已由“如果”体现，不必另补。

## §75 句 82-75-2-9

- **问题**：语法误读 — 见跨段一致性：nissaya 的 `အဿ= ထိုရဟန်းသည်` / `ကတမေ= အဘယ်မည်ကုန်သော`。
- **建议**：改为“他的哪五种心的荒芜没有断除呢？”

## §75 句 82-75-44-59

- **问题**：漏译 — yassa 未译；ayaṃ 未译，nissaya 补出 `(ဤမြတ်စွာဘုရား၌ ယုံမှားတွေးတောမှု ဝိစိကိစ္ဆာ ဟူသော)`，即“对导师的怀疑”。
- **建议**：改为“谁的心不倾向于……，由于这样，他的这第一种心的荒芜就没有断除”。补出的成分可不进正文，ayaṃ 至少要译出“这”。

## §76 句 82-76-2-27

- **问题**：词义 — āhatacitto 译“心怀抵触”。依 §83 nissaya，`အာဟာတစိတ္တော` 是“心被嗔恚击打、折磨”，“抵触”与此不符。khilajāto 见跨段一致性。
- **建议**：āhatacitto 改为“心被嗔恚所伤”或“心受嗔恨冲击”一类；khilajāto 按定案术语改。

## §76 句 82-76-50-65

- **问题**：漏译 — 同 §75 44-59，yassa 与 ayaṃ 未译。nissaya 补出 `(ဤသို့ သီတင်းသုံးဖော်တို့၌ စိတ်ဆိုခြင်းဟူသော)`，即“对同梵行者恼怒”。
- **建议**：同上统一句式。

## §76 句 82-76-66-72

## §78 句 82-78-2-36

- **问题**：补出成分 — nissaya 对 kāye 补出 `(မိမိ၏ကာယ၌)`，即“自己的身体”；对 rūpe 补出 `(ဗဟိဒ္ဓရုပ်၌)`，即“外在的色”。现译“对身体……对色”，没有体现内外之别。
- **建议**：可译为“对自己的身体……对外在的色”。若坚持不补，至少保持现状不误导。属可选项。

## §80 句 82-80-2-25

- **问题**：词义 — ārohapariṇāhena 的 nissaya 是 `အရှည်အလျားနှင့် အကျယ်အပြန့်လုံးပတ်`（长度与宽度、周长）。现译“高度和周长”，“高度”对月亮不贴切。
- **建议**：改为“长宽和周长”或“大小”。
- **问题**：词义区分 — nissaya 注 `[အရောင်သေကို "ဝဏ္ဏ"... အရောင်ရှင်ကို "အာဘာ"]`：vaṇṇa 是月亮本身的色泽，ābhā 是向外放射的光芒。现译“颜色／光辉”已能区分，无需改动。仅说明 eva（`ဟာယတိ ဧဝ= ဆုတ်ယုတ်သည်သာ`，只有减退）的强调义，可视需要译出“只是在减退”。
