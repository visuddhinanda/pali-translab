# Review — 82:47-59（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§47、§48、§52–56 无 nissaya，略过）

## 跨段一致性

- **appa-（表示「没有」）**：§58 句 82-58-35-46 译 appābādho appātaṅko 为“少病少恼”；§59 句 82-59-12-40 中 appasaddaṃ / appanigghosaṃ 译“没有……”，同一句里 appaḍaṃsa… 却译“少有”。nissaya 一律释为 `မရှိ`（没有），并在 82-59-12-40 专门加注：此处 appa 与 appiccha 等词一样，表示「无」（abhāva）。→ **建议**：至少在 §59 同一句内统一为“没有”。§58 的“少病少恼”是固定译法，可以保留，但要意识到它与 nissaya 的读法不一致。
- **no … (anussarati / passati / viharati)**：nissaya 在 §49 这一串否定上都带 `သေး`（「还没有/尚未」），表示德目逐级递进，例如 `နော ပဿတိ= မမြင်နိုင်သေး`、`နော ဝိဟရတိ= မနေနိုင်သေး`。译文统一作“却不能”。→ **建议**：82-49-2-72、82-49-73-114 的各个“却不能”统一改为“却还不能”，体现逐级递进的语气。

## §58 句 82-58-24-34

- **问题**：格与指示词 — `သော ဘဂဝါ= … ထိုမြတ်စွာဘုရားသည်`，so 是远指（ထို＝那），译文作“这位世尊”。`ဣတိပိ= ဤအကြောင်းကြောင့်လည်း`，表示「因为这个缘故也」，带原因义。译文“就是这样”丢掉了 itipi 的因由义。
- **建议**：“‘那位世尊因为这个缘故也是……乃至……是世尊’”，也可采用通行的“‘那位世尊是……’”句式，但要保留“那位”。

## §58 句 82-58-47-59

- **问题**：宾语所指 — nissaya 释 `အတ္တာနံ= မိမိအပြစ်ကို`（自己的过失），`အာဝိကတ္တာ`＝公开坦白、认错。译文“如实地显露自己”没有点出显露的是过失。另外 nissaya 释 `အမာယာဝီ= မိမိအပြစ်ကို ဖုံးဖိလှည့်စားခြင်းမရှိ`（不掩盖、不搪塞自己的过失），“不狡诈”偏离了这个具体所指。
- **建议**：“他不虚伪、不隐瞒（过失），在导师面前或在有智慧的同修面前如实地揭露自己的过失”。

## §58 句 82-58-78-88

- **问题**：语法误读 — ariyāya 与 paññāya 同格，是修饰智慧的形容词，nissaya 释为 `ကိလေသာ အညစ်အကြေး ကင်းဝေးစင်ကြယ်သော`（远离烦恼垢染、清净的）。译文“圣者的智慧”把它读成了属格。此外，ariyāya / nibbedhikāya / dukkhakkhayagāminiyā 都是 paññāya 的定语，同属 samannāgato 的宾语，译文另起“这是……”一句，割断了这层修饰关系。
- **建议**：“他有智慧，具足能洞察生灭的、圣洁的、能穿透烦恼的、能正确地引向苦的灭尽的智慧。”若嫌定语太长，可以保留分句，但“圣者的”须改为“圣洁的”。

## §59 句 82-59-12-40

- **问题 1**：补出成分 — nissaya 为 nātidūraṃ / nāccāsannaṃ 补出参照点 `(ဆွမ်းခံရွာမှ)`，即「离乞食的村落」。译文“不太远也不太近”没有参照对象，读者不知道是离哪里远近。
- **问题 2**：同一句内 appa- 前后不一致，见「跨段一致性」。另外 nissaya 释 `အပ္ပသဒ္ဒံ= လူသံမရှိ`，指没有人声，译文“没有声响”过宽。
- **建议**：“住处离乞食的村子不太远也不太近，来去方便，白天不与人群混杂，夜里没有人声、没有喧闹，没有虻、蚊、风、烈日和爬虫的侵扰”。

## §59 句 82-59-41-49

- **问题**：隐含成分 — `ဝိဟရန္တဿ` 的异释为 `နေထိုင်သော ရဟန်းမှာ`（对住在那里的比丘而言），是与格（领受者）。译文“住在那个住处里，……就能得到”主语悬空。
- **建议**：“住在那个住处的比丘，不费力就能得到衣服、饮食、住处和治病的医药用品”。

## §59 句 82-59-64-70 / 82-59-71-83

- **问题**：词义分工 — nissaya 区分两个动词：`ပရိပုစ္ဆတိ= ပါဠိကိုလည်း မေးမြန်း`（问经文），`ပရိပဉှတိ= ပါဠိ၏အနက်ကိုလည်း မေးမြန်းစူးစမ်း`（探究经文的意义）。译文“询问、追问”只区分了程度，没有区分对象。idaṃ / imassa 在 nissaya 中都指同一句经文。
- **建议**：可保留“询问、追问”，但第二句宜作“‘大德，这句该怎样理解？这句是什么意思？’”，让“这”的所指（经句）前后一致。属于次要项。

## §59 句 82-59-84-98

- **问题**：词义所指 — nissaya 释 `ဓမ္မေသု= ခက်ဆစ်ခက်ရာ ပါဠိရပ်တို့၌`（艰涩难解的经文处），`အဝိဝဋ / အနုတ္တာနီကတ` 也都限定为“经文的意义”。译文“在种种容易引起疑惑的法上”把 dhamma 译成泛指的“法”，所指偏了。
- **建议**：“……在种种容易引起疑惑的经文难点上为他除去疑惑”。前两个分句可作“为他开显经文中还没有开显的意义，讲明还没有讲明的意义”。
