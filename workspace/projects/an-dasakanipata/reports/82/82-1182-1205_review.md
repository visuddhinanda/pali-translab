# Review — 82:1182-1205（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核）

## 跨段一致性

- **经末标记**：§1183～§1203 都译作“第X经终。”，§1205 `Navamaṃ` 译作“第九经。”，少了“终”字 → 统一为“第九经终。”
- **编号格式**：§1182～§1202 的经号和段号都用阿拉伯数字（“10.”“143.”），§1204 改成“九、”，§1205 改成“一五三、” → 统一为“9. 应当随念经”“153.”
- **连词**：总说句 §1183～§1203 都用“A与B”，§1205 用“A和B” → 统一为“与”
- **结句**：`ayaṃ vuccati` 在 §1183～§1203 都译作“这叫做”，§1205 两处（33-47、56-72）译作“这就叫做” → 统一为“这叫做”
- **巴利夹注**：只有 §1191 给“黑道”“白道”夹注了巴利原词。同组的圣道、正法、善人之法等都没有夹注 → 两种做法选一种全组统一，建议去掉 §1191 的夹注。
- **āsevitabba 与 bhāvetabba 的区分**：§1199 把 `āsevitabba` 译作“修习”，§1201 把 `bhāvetabba` 译作“培育”。“修习”是 bhāvanā 的通行译法，读者很容易以为 §1199 讲的就是 bhāvetabba。nissaya 对两个词的释义完全不同（见下面 §1199 一条）→ 建议 §1199 改译，让“修习”这个词不落在 āsevitabba 上。
- **saddhamma 与 sappurisadhamma 撞义**：nissaya 把 §1193 的 `saddhamma` 释为“善人的法”，把 §1195 的 `sappurisadhamma` 释为“好人们的法”，两者释义接近（见下面两条）。如果 §1193 改依 nissaya，必须与 §1195 的“善人之法”拉开距离。

## §1189 句 82-1189-2-18

- **问题**：句法角色 — nissaya 把 `ariyamaggaṃ`、`anariyamaggaṃ` 都释为修饰 `dhammaṃ` 的同位定语：`အရိယမဂ္ဂံ= …အကျင့်လမ်းစဉ်ဖြစ်သော`（“是……修行之道的”）+ `ဓမ္မဉ္စ= ကိုလည်း`（“法”，宾格）。意思是“作为圣道的那个法”。译文“圣道法”也可以读成“圣道的法”，即属格，与 nissaya 的同位关系不合。
- **建议**：改成“作为圣道的法与作为非圣道的法”，或者参照 §1193 省去“法”，译作“圣道与非圣道”。§1191“黑道法与白道法”的结构相同，应同步处理。

## §1191 句 82-1191-2-16

- **问题**：句法角色 — 与 §1189 相同，`ကဏှမဂ္ဂံ= …အကျင့်လမ်းစဉ်ဖြစ်သော` 是“作为黑道的”，修饰 `dhammaṃ`。
- **建议**：随 §1189 统一，例如“作为黑道的法与作为白道的法”。

## §1193 句 82-1193-2-16

- **问题**：取义 / 复合词关系 — nissaya 的释义是 `သဒ္ဓမ္မံ= သူတော်ကောင်းတရားဖြစ်သော`（“善人的法”）和 `အသဒ္ဓမ္မံ= သူယုတ်မာ တရားဖြစ်သော`（“卑劣者的法”）。它把 `sat-` 读成“善人”，与 `dhamma` 是属格关系。译文“正法 / 非正法”则把 `sat-` 读成“真正的”，是形容词。两种读法都有传统依据，但与 nissaya 不一致。
- **建议**：保留“正法”可以，但要注意分歧。如果改依 nissaya，需要与 §1195 的“善人之法”区分开，例如本经译作“善士法 / 非善士法”。这一处请定稿时取舍。

## §1197 句 82-1197-2-17

- **问题**：补出成分 — nissaya 的释义是 `ဥပ္ပါဒေတဗ္ဗံ= မိမိသန္တာန်၌ ဖြစ်စေသင့်သော`，补出了处格成分“在自己的身心相续中”。译文“应当令其生起”没有交代在哪里生起，“其”的指代也比较模糊。
- **建议**：可以改成“应当在自身中令它生起的法 / 不应当在自身中令它生起的法”。如果嫌累赘，至少把“令其”改为“让它”，避免文言代词“其”。本经后面的 18-31、32-46、47-55、56-72 四句以及 §1196 经题要随之统一。

## §1199 句 82-1199-2-17

- **问题**：词义 — nissaya 的释义是 `အာသေဝိတဗ္ဗံ= မှီဝဲသင့်သော`。`မှီဝဲ` 的意思是“依靠、亲近、经常从事”，侧重反复亲近、实行，不是“使之增长”。§1201 `bhāvetabba` 的释义 `ဖြစ်ပွားစေအပ်သော`（“使其生长增长”）才对应“修习 / 培育”。译文用“修习”译 āsevitabba，与 nissaya 的分工不合。
- **建议**：改成“应当亲近的法 / 不应当亲近的法”，或者“应当实行的法”。本经 18-31、32-46、47-54、55-71 四句以及 §1198 经题“应当修习经”同步修改。

## §1205 句 82-1205-73-74

- **问题**：漏译 / 格式 — `Navamaṃ= ` 和其他经末一样是序数标记，译文“第九经。”少了“终”字。
- **建议**：改为“第九经终。”

## §1205 句 82-1205-2-18

- **问题**：格式 — 段号写成“一五三、”，与全组的“153.”体例不一致。连词用“和”，与全组的“与”不一致（见跨段一致性）。
- **建议**：改为“153.“比丘们，我要为你们讲说应当随念的法与不应当随念的法。”
