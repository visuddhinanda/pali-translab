# Review — 81:2117-2132（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 未提供）／义注 ⚠️（注入的是 book 98 §2117-2132 的对应义注缺失——注入内容为 98:2219-2478，覆盖 Kusalattika 的 paṭiccavāra/paccayavāra/pañhāvāra 释义，**不含本 chunk 所在的 sahajātaduka / aññamaññaduka ghaṭanā 段**。下列义注依据仅限于可对照的术语层面，不作段级释义核对。）

## 跨段一致性
- `upanissaya`：全 chunk 一律译「亲依止缘」，统一，无问题。但义注区分 `ārammaṇūpanissaya / anantarūpanissaya / pakatūpanissaya`（98:2387「tevīsati bhedā」；98:2427 列 upanissaya 所摄九缘），本 chunk 只出现总名，译法无须细分，保留「亲依止」即可。
- `atthi` / `avigata`：§2120-2129 的 ghaṭana 标题译「有、不离去」，而缘名列表中译「非有缘／非离去缘」——同一词在标题与列表中分别作「有」「有缘」。属省略式复合语，可接受，但建议标题统一补「缘」：「俱生缘、依止缘、有缘、不离去缘」，与列表体例一致。
- `nonatthiyā` / `novigate`：全 chunk 一律译「非无有缘」「非离去缘」。**此处有系统性错误，见下。**
- `ghaṭanā`：§2119 译「组合（ghaṭanā）」，§2130 译「以俱生为根本的部分（sahajātamūlaka）」。两处夹注体例一致（圆括号附巴利原词），符合 `style.md`。
- 数词：`nava/pañca/tīṇi/ekaṃ` 全 chunk 一律「九/五/三/一」，统一。
- 语体：全 chunk 为缘名+数目的表册体，无文言虚词、无文言句式，符合 `style.md` 第一节。未发现「此中/故为/彼等/是故/於/遂」等禁例。标点全角，无 ASCII 引号，符合 JSON 安全约束。

## §2118 句 81-2118-2-68
- **问题**：术语误译（系统性） — `nonatthiyā` 译作「非无有缘」。`natthipaccaya` 是「无有缘」，其否定式 `nonatthipaccaya`（= `na-natthi`）才是「非无有缘」。原文 `nonatthiyā` 正是这个双重否定形，译「非无有缘」在字面上对，但与同句其他条目的构词体例不一致：同句 `nahetuyā`=「非因缘」、`naārammaṇe`=「非所缘缘」，都是单层 `na-`；唯 `nonatthiyā`/`novigate` 原文已是 `no-` 形。义注 98:2447 明确把这一组写作 `Noatthinoavigatesu`、98:2457 作 `**Noatthipaccayā**`，即 **`noatthi`（非有）与 `novigata`（非不离去）**，不是 `nonatthi`。
- **建议**：核对原文读法。若 VRI 原文确作 `nonatthiyā , novigate`，则对应 `natthi`（无有）与 `vigata`（离去）的否定，译「非无有缘、非离去缘」正确；但义注通篇用 `noatthi / noavigata`（见 98:2447 `Noatthinoavigatesu teyeva veditabbā`、98:2451 `noatthinoavigatā`、98:2457 `**Noatthipaccayā** **nahetuyā** **navā**ti`），**义注所据底本是「非有缘、非不离去缘」**。以义注为准，§2118 末二项应作「**非有缘有九，非不离去缘有九**」。同一处修正适用于 §2120、2121、2122、2123、2124、2125、2126、2127、2128、2129、2132（共 12 段、24 处）。这是本 chunk 最重要的必改项。

## §2120 句 81-2120-2-45
- **问题**：ghaṭana 标题的省略号处理 — 原文 `naupanissaye nava … pe … namagge nava`，译文作「非亲依止缘有九……中略……非道缘有九」。`…pe…`（peyyāla）是巴利缩略符，译「中略」可，但 chunk 内 §2118 等段无省略号而全列，体例上读者会以为中略处内容不同。
- **建议**：保留「……中略……」，但宜统一为与 §2118 同序的隐含项提示，或在首次出现处加译者注说明 `pe` 即前段同序诸缘的省略。若 `style.md` 规定不加注，则至少保证全 chunk 所有 `…pe…` 一律译「……中略……」（本 chunk 仅此一处，已一致）。

## §2124 句 81-2124-2-62
- **问题**：括注译法 — `( Avipākaṃ –5)` 译「（无异熟——五）」。`avipāka` 在义注中指「不含异熟缘的（组合）」，即这一批 ghaṭana 是 `avipākāni`（98:2394「sabbapaṭhamāni cattāri ghaṭanāni … avipākāni」、98:2403「pañca avipākāni, pañca savipākāni」）。译「无异熟」会被读作「没有异熟果」，而原意是「不与异熟缘相配的组合」。
- **建议**：改为「（不含异熟缘——五）」或「（无异熟缘者——五）」。同处 §2129 `( Savipākaṃ –5)`「（有异熟——五）」改为「（含异熟缘——五）」。依据：**义注**：`Tato parāni pañca ghaṭanāni vipākahetuvasena vuttāni`（98:2395）、`Tesu pañca avipākāni, pañca savipākāni`（98:2403），`sa-/a-` 前缀修饰的是 ghaṭana 是否带 vipākapaccaya。

## §2130 句 81-2130-2-3
- **问题**：层次标注与粗体体例 — `Sahajātamūlakaṃ .` 是章节收尾标目，译「以俱生为根本的部分（sahajātamūlaka）」。而 §2117 `Sahajātadukaṃ`、§2131 `Aññamaññadukaṃ` 译文加了粗体（`**俱生二缘组**`），§2119 `Sahajātaghaṭanā (10)`、§2130 未加。三处同为标目，格式不统一。
- **建议**：统一标目格式。§2119 与 §2130 的原文无粗体标记，§2117/§2131 原文亦无——译文自行加粗是**译者添加的格式标记**。按硬约束「译文里不留任何工作标记」的同类精神与「不显示原文格式之外的强调」，建议四处一律不加粗，或四处一律加粗，不要两种并存。倾向：去掉 §2117、§2131 的 `**`，与 §2119、§2130 一致。
- **问题（次）**：`mūlaka` 义注中反复作「以某缘为首/为根本而起的一系列 naya」（98:2397 `Hetumūlakaṃ niṭṭhitaṃ`、98:2453 `Nārammaṇamūlakādīsu`、98:2472 `Nahetumūlakaṃ`）。译「以俱生为根本的部分」中「部分」为译者增补，原文无对应词。
- **建议**：改为「俱生为根本（sahajātamūlaka）。」或「俱生根本门（sahajātamūlaka）。」，不增补「的部分」。依据：§2259「Paccayānulomavaṇṇanā .」一类收尾标目在义注中都是裸标题，无「部分」之类范畴词。

## §2119 句 81-2119-2-5
- **问题**：数目括注丢失位置 — 原文 `Sahajātaghaṭanā (10)`，译「俱生缘的组合（ghaṭanā）（十）」。夹注巴利原词与数目括注连排，两个全角圆括号相邻，可读性差；且 `(10)` 是阿拉伯数字，译文改为汉字「十」，与 §2118 末「（二十）」、§2132 末「（十九）」一致——这一点是对的。
- **建议**：调整为「俱生缘的组合（sahajātaghaṭanā）（十）」——夹注应是完整复合词 `sahajātaghaṭanā`，而非只取 `ghaṭanā`。首次出现夹注巴利原词时应取原文实际词形。

- `vippayutta`「不相应缘」、`sampayutta`「相应缘」、`purejāta`「前生缘」、`pacchājāta`「后生缘」：均为南传常见汉译，无异议。
