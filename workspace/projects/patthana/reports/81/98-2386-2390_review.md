# Review — 98:2386-2390（channel: 73c03e1a）

> 资源：pali ✅／nissaya ❌（未注入）／义注 —（本层即义注，父层 book=81 本文译文已注入 ✅）

## 跨段一致性

- **vissajjana**：§2386 译「解答」，§2389「七个解答」亦同，一致；但 §2389 末「所说示的那一分」把 `niddiṭṭhavāre` 的 `vāra` 译作「分」，而 §2386–2389 全篇把 `vissajjana` 译作「解答」、把计数单位译作「项」。`vāra` 在父层（book 81）通译「分」（缘生分、俱生分、问分），此处 `niddiṭṭhavāre` 指「所指示的那一轮/那一分」，与父层「分」一致，可保留，但建议在该句明确为「所指示的那一分（vāra）」以免与「项」混读。
- **数量单位**：全 chunk 用「项」计数（三项、七项、十三项），而 §2389 末的归类用「一法组／三法组／五法组」。父层对应的 `dukaṃ / tikaṃ / catukkaṃ` 译作「二缘组／三缘组／四缘组」（见 81-238、81-240 等）。此处 `ekakaṃ / tikā / pañcakaṃ / sattakā / navakā / dasakaṃ / terasakaṃ` 指的是「答数为一的那一类／为三的那一类」，译「一法组／三法组」与父层「N 缘组」的构词不一致，容易让读者误以为是另一套概念。建议统一为「一数组／三数组……」或「答数为一的一类……」，并在首次出现处夹注巴利原词。**必改项（跨段一致性）**。
- **「依…而有…」与「成为…的缘」两种句式混用**：§2386 用「成为…的缘」（kusalaṃ kusalassa → 善法成为善法的缘），§2387 用「以…而有…」（kusalena kusalaṃ → 以善法而有善法），§2389 同段内两种并用。原文确实有属格（-ssa）与具格（-ena）之别，译文作此区分是对的，但 §2386 第二句 `kusalena kusalaṃ, abyākataṃ…` 译「以善法为缘而有善法」，§2387 同构的 `kusalena kusalaṃ` 译「以善法而有善法」，少了「为缘」二字。建议统一为「以善法为缘而有善法」。

## §2386 句 98-2386-27-29

- **问题**：漏译／语义不完整 — `Tathā akusalena ;` 译「以不善法为缘的情形也一样」尚可，但紧接的 `abyākatena abyākatamevāti evaṃ satta` 被切到下一句，两句合读时「也一样」指的是「同样三项」这层意思没有点出。
- **建议**：改为「以不善法为缘的也同样是三项；」

## §2386 句 98-2386-35-40

- **问题**：术语不透明 — `ekamūlakaekāvasānāni nava` 译「以一法为始、以一法为终的那九项」。`mūlaka` 在父层固定译「根本」（81-420「以因缘为根本的部分」、81-353「非因根本」），`avasāna` 指「结尾／所成」。此处指「以单一法为根本、以单一法为结果」的九种配对（善-善、善-不善……）。译「以一法为始、以一法为终」把 `mūlaka` 从「根本」改成了「始」，与父层术语断了。
- **建议**：「以一法为根本、以一法为结果的那九项」，或「单法为根、单法为果的九项」。

## §2386 句 98-2386-94-102

- **问题**：**被解释词**与计数口径 — `ārammaṇādhipatipi sattadhā, sahajātādhipatipi sattadhāva` 中的 `ārammaṇādhipati / sahajātādhipati`，父层问分（81-1405 等）作「所缘增上（ārammaṇādhipati）」「俱生增上（sahajātādhipati）」，本句译「所缘增上」「俱生增上」与父层逐字相同 ✅。但 `sattadhā` 译「七种」，而本段上文把同类计数一律称「项」。
- **建议**：改为「所缘增上也有七项，俱生增上同样只有七项」。注意 `sattadhāva` 的 `eva`（只有／恰好）已译出为「同样」，建议显化为「恰好也是七项」。

## §2387 句 98-2387-66-70

- **问题**：指代不清 — `Ettha pana purejātampi labbhati .` 译「而在这里，前生的情形也是可以得到的」。`purejāta` 是缘名，父层通译「前生缘」（81-189「前生缘」）。此处作为缘的一种被列举，译「前生的情形」弱化了它的术语身份。
- **建议**：「而在这里，前生缘也是可以得到的。」下文 98-2387-71-76、77-81、82-94 的「俱生的／前生的」同此，建议一律补「缘」字或首次夹注巴利原词。

## §2387 句 98-2387-82-94

- **问题**：主语缺失致误读 — `Puna kusalābyākato sahajātapurejātato kusalassa` 译「再者，善法与无记法依俱生和前生而成为善法的缘」。原文 `kusalābyākato` 是复合主语（善与无记两者），译文「善法与无记法」正确；但紧接 `sahajātatova abyākatassa, tathā akusalābyākatoti` 译「只依俱生而成为无记法的缘；不善法与无记法也是这样」，其中「不善法与无记法也是这样」是另起一个主语组，中文读来像是前句的补充。
- **建议**：断为「再者，善法与无记法依俱生和前生成为善法的缘，只依俱生成为无记法的缘。不善法与无记法同此。」

## §2387 句 98-2387-101-106 / 107-117

- **问题**：术语与父层不一致（**必改项**）— `pakatūpanissaye nava` 译「自然亲依止有九项」。父层 81-1463 等处作「**惯行依止**（pakatūpanissaya）」，同段 81-1471 又作「**自然亲依止**（pakatūpanissaya）」——父层自身已不统一，但本层须择一并与父层对齐。同句的 `ārammaṇūpanissaya / anantarūpanissaya`，父层 81-1461 作「所缘依止／无间依止」，81-1482 作「所缘亲依止／无间亲依止」。本层译「所缘亲依止／无间亲依止／自然亲依止」，与父层后一种写法一致。
- **建议**：全 chunk 统一用「所缘亲依止／无间亲依止／自然亲依止」（即本层现用法），并在 `reports/` 记一条待回填父层 book 81 的术语统稿项——父层 81-1461～1463 的「所缘依止／无间依止／惯行依止」需改齐，否则读者在父子两层看到三套名目。这一条属跨层统稿（harmonize）范围，本步只报告。

## §2388 句 98-2388-25-33

- **问题**：术语译法可商 — `nānākkhaṇikakammampi` 译「异刹那业」。父层 81-1514 作「异刹那的」（`nānākkhaṇikā` 译「异刹那的」，与「俱生的」`sahajātā` 对举），本层译「异刹那业」在构词上是对的（kamma 在复合词内），与父层不冲突 ✅。
- **建议**：建议首次出现时夹注巴利原词：「异刹那业（nānākkhaṇika-kamma）」，与同句「俱生业」对举。

## §2388 句 98-2388-39-42

- **问题**：标题式列举的断句 — `**Āhāraindriyajhānamaggesu** **satta** hetusadisāneva .` 译「**在食缘、根缘、禅缘、道缘中各有七**，都与因缘的那些相同。」黑体范围与原文黑体一致 ✅。`hetusadisāneva` 的 `eva` 未译出。
- **建议**：「都与因缘的那些完全相同」。

## §2388 句 98-2388-52-82

- **问题**：**被解释词**与父层核对 — 本句 `vatthupurejātato` 译「依所依处的前生」。父层 81-1498 作「**依处前生**（vatthupurejāta）」，81-1562 亦作「前生者——眼处是眼识的前生缘」，而所依处在父层 book 81 中译法有两套：「所依处」（81-160、81-678）与「依处」（81-720、81-758）。本层此处用「所依处」。
- **建议**：这是父层自身的不统一，本层取「所依处」并无错，但与父层 81-1498「依处前生」这一被解释词的构词不同。**必改项**：改为「依所依处前生（vatthupurejāta）」，并把该术语登记进 `knowledge/terms.md`，同时记录父层需统稿。

## §2389 句 98-2389-2-40

- **问题**：长句可读性与成分归属 — 本句一气译完十三项，中间「又依俱生、前生、后生、食、根，以无记法而有无记法」一段，`sahajātapurejātapacchājātāhārindriyato` 是五个缘的复合夺格，译文列举正确 ✅；但「依所依处与所缘的前生」（`vatthārammaṇapurejātato`）处，父层无直接对应，读者难判断「所依处前生」与「所缘前生」是两种并列。
- **建议**：改为「依所依处前生与所缘前生两种前生」，使并列关系显化。

## §2389 句 98-2389-41-51 / 52-57

- **问题**：重复句的指代 — 两句都以「同样这二者依俱生、后生、食、根而成为无记法的缘」结尾（`sveva abyākatassa …`），但两句的「这二者」分别指「善法与无记法」（前句主语是 `kusalo ca abyākato ca` 对不善法）与「善法与无记法」（对善法），中文看不出主语已换过一轮。
- **建议**：分别写明：「同样，善法与无记法这二者依俱生、后生、食、根成为无记法的缘」。

## §2389 句 98-2389-77-120

- **问题**：如上「跨段一致性」第二条，`ekakaṃ / tikā / pañcakaṃ / sattakā / navakā / dasakaṃ / terasakaṃ` 译「一法组／三法组……」与父层「N 缘组」构词冲突，**必改项**。另 `sādhukaṃ sallakkhetvā` 译「应当依计数善加把握」，`sallakkheti` 是「审察、留意」，译「把握」偏弱但可接受；`dukatikādīsu paccayasaṃsandane` 译「在二法组、三法组等之中配合诸缘时」——此处 `duka / tika` 与父层 81-238「二缘组」「三缘组」同指，译「二法组／三法组」与父层不一致。
- **建议**：统一改为「二缘组、三缘组等之中配合诸缘（paccayasaṃsandana）时的计数」。

## §2390 句 98-2390-22-37

- **问题**：术语与父层核对 — `ṭhapetvā vīmaṃsaṃ sesādhipatino` 译「除了观慧增上以外的其余诸增上」。父层 81-1626 标题作「观慧（vīmaṃsā）增上组合」，本层「观慧增上」与之一致 ✅。
- **建议**：建议首次出现夹注：「观慧增上（vīmaṃsādhipati）」，与同段「所缘增上／俱生增上」的夹注体例统一。

## §2390 句 98-2390-40-42

- **问题**：译得过简、语义不明（**必改项**）— `Tathā bhāvābhāvato .` 译「因为有的是那样，有的不是那样。」这是对上一句「为什么呢」的回答，意思是「因为（在某些场合）有那种性质，（在另一些场合）没有那种性质」，即「由于有与无（那样的关系）」。现译「有的是那样，有的不是那样」把 `bhāva/abhāva`（有／无）读成了「是／不是」，并且用「有的」指代不明，读者无从知道指什么。下一句 98-2390-43-61 才展开解释。
- **建议**：改为「因为（这种缘的关系）有时成立、有时不成立。」或「因为有那样的情形，也有不那样的情形。」并与下句的展开呼应。

## §2390 句 98-2390-74-82

- **问题**：术语漏「缘」字 — `Purejātapacchājātasampayuttavippayuttaatthinatthivigatāvigatā ca aññamaññaviruddhā` 译「而前生与后生、相应与不相应、有与无有、离去与不离去，是彼此相违的」。四对术语全部省去「缘」字，而同段上文（98-2390-22-37）则写作「所缘、无间、等无间、亲依止、前生、后生、业、重复、食、禅、无有、离去诸缘」——以「诸缘」收尾。此处无收尾词，读者可能把「有与无有」读成普通词。
- **建议**：改为「而前生缘与后生缘、相应缘与不相应缘、有缘与无有缘、离去缘与不离去缘，是彼此相违的」。

## §2390 句 98-2390-83-100

- **问题**：被解释词与父层逐字核对（**必改项**）— 末尾黑体 `**hetupaccayā** **adhipatiyā** **cattārī**ti` 译「**依因缘，非增上缘中有四**」。本层所注的是 book 81 的「缘顺逆」段，父层对应句为 81-550：「`Hetupaccayā naārammaṇe satta, naadhipatiyā satta…`」，父层译「依因缘，非所缘缘有七，非增上缘有七……」。但本层原文黑体是 `adhipatiyā`（**不带 na**）、数目是 `cattāri`（四），译文却加了「非」字。查父层 81-440「以因缘为首：增上缘中有四（`Hetupaccayā adhipatiyā cattāri`）」——这正是本层所引的句子。
- **建议**：**删去「非」字**，改为「**依因缘，增上缘中有四**」，并与父层 81-440「以因缘为首：增上缘中有四」对齐措辞（父层作「以因缘为首：增上缘中有四」）。现译加「非」是实质误译，会把读者引到「缘顺逆」段而非「缘顺」段。同时建议把引文前半统一为父层的「以因缘为首」或把父层改为「依因缘」，二者需择一（跨层统稿项）。

## 其他（风格）

- 全 chunk 语体为现代书面汉语，未见文言虚词与文言句式违例 ✅。标点为中文全角，引号未出现 ASCII 引号 ✅。
- 「**在食缘、根缘、禅缘、道缘中各有七**」一句，黑体内含「在…中各有」为译者添加的结构词；原文黑体只是 `Āhāraindriyajhānamaggesu satta`。按体例黑体应尽量只覆盖被解释词本身。建议黑体仅保留「食缘、根缘、禅缘、道缘中有七」，「各」字移出黑体或删去。
