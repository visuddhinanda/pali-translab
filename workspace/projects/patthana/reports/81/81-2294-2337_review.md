# Review — 81:2294-2337（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 未提供任何 nissaya channel，词级核对无法进行）／义注 ⚠️（注入的是 book 98《善三法发趣论注》，对本 chunk 这批 ghaṭanā 枚举段**没有逐段对应的释文**，只有总说与平行句式，被解释词的逐字核对因此只能做结构性比对，不能做黑体对齐）

## 跨段一致性

1. **缘名一律脱落「缘」字**：§2295–2337 全部把 `indriya / sahajāta / nissaya / jhāna / magga / āhāra / adhipati / atthi / avigata` 译作「根、俱生、依止、禅、道、食、增上、有、不离去」。前面七个作为缘名可以接受（汉译传统常省），但「**有**」「**不离去**」「**食**」单用在现代汉语里读不出是缘名，「有、不离去」会被当成普通动词短语。
   **义注**依据：98-2463 把同类组合名整句展开为「kusalo dhammo kusalassa dhammassa hetupaccayena paccayo , sahajātanissayaatthiavigatapaccayena paccayo」——组合名是 `…paccaya` 的省写，不是独立名词。
   → 建议：至少把 `atthi / avigata / āhāra / jhāna` 译为「有缘／不离去缘／食缘／禅缘」，或整列统一加「缘」（「根缘、俱生缘、依止缘、禅缘、有缘、不离去缘」）。本 chunk 内部一致，但需与前面章节（因缘、所缘等 mūlaka 的 ghaṭanā）核对后统一，不可一半带缘一半不带。

2. **否定缘名同理**：「在非因中」「在非相互中」「在非亲依止中」——`nahetuyā` 是 `nahetupaccaya` 的处格省写。
   **义注**依据：98-2467 作「nahetupaccayena paccayo ārammaṇapaccayena paccayo」。
   → 建议统一为「在非因缘中」「在非相互缘中」等，与第 1 点同步决定。

3. **数词量词「种」用错范畴**：全 chunk 把 `satta / tīṇi / ekaṃ` 译成「有七种／三种／一种」。这些数字数的是**问答项（pucchāvissajjanavāra）**，不是缘的种类，「种」会让读者以为是「七种非因缘」。
   **义注**依据：98-2251「hetuyā navāti hetupaccaye nava **pucchāvissajjanavārā** honti」。
   → 建议统一改为「有七项／三项／一项」或「有七个问答／…」。出现频次极高（本 chunk 约 60 处），须整批改。

4. **组合名的并列关系被压扁，产生歧义**（§2304、§2314 以外的复合标题）：
   - §2305 标题「有禅道组合」：`Sajhāna-maggaghaṭanā` = 含「禅」与「道」两缘的组合，现译易读成「有禅道」这一个术语。
   - §2324「有增上食组合」：`Sādhipati-āhāraghaṭanā`，现译读起来像「有增上的食物」。
   - §2331「有增上道组合」：同病，且「增上道」在汉语佛教语境里本身是个词，误读风险最大。
   → 建议统一改为「含禅与道的组合」「含增上与食的组合」「含增上与道的组合」；§2294「有禅组合」、§2314「有食组合」相应改为「含禅的组合」「含食的组合」，保持一类标题同构。

5. 省略号标记一致：`… pe …` 全部作「……略……」，前后统一，无问题（若全书统一用「……中略……」需同步）。

6. 计数核对：§2295/2305/2315/2325/2332 的 7-3-7-3-3-7-7、§2296/2306/2316 的 3-…-1-3-3-3、各 ekaṃ 段的 1，以及标题括号数（9 = 4+5、6 = 3+3）与巴利逐一相符，**无漏译、无数字错误**。

## §2304 句 81-2304-2-5
- **问题**：术语歧义 — `Sajhāna-maggaghaṭanā` 的「禅」「道」是两个并列缘名，「有禅道组合」压成一个词，读者会误解为单一术语（见跨段一致性第 4 条）。
- **建议**：改「含禅与道的组合（九）」。

## §2324 句 81-2324-2-5
- **问题**：术语歧义 — 「有增上食组合」可被读作「有增上的食」。
- **建议**：改「含增上与食的组合（六）」。

## §2331 句 81-2331-2-5
- **问题**：术语歧义且与既有术语撞车 — 「增上道」易被当成一个固定词。
- **建议**：改「含增上与道的组合（六）」。
