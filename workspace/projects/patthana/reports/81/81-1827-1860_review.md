# Review — 81:1827-1860（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级核对缺失，格与句法项无法独立验证）／义注 ✅（book 98，对应段 2420–2459）
> 本作业层次为本文（mūla），**无父层**，故「被解释词与父层逐字同译」不适用；改作反向核对：义注黑体引用的本文词条与本文译法的对应关系见文末「供义注层对齐的词表」。

## 跨段一致性

- **aññamañña + nissaya**：§1828 句 81-1828-9-11、81-1828-18-25 与 §1829 句 81-1829-6-8 合译为「相互依止」（4–5 个可见项），而 §1828-12-14、§1829-9-11、§1829-15-22 作「相互、依止」（两项）。同一组缘在同一段内两种处理 → 统一为「相互、依止」。详见下方必改项。
- **gaṇanā / saṅkhyā 撞同一汉译**：§1831「anulomagaṇanā」译「顺计数」，§1850「Saṅkhyāvāro」译「计数分」。两个不同巴利词挤进「计数」，读者无法分辨。建议 `saṅkhyāvāra`→「数分」（或「摄数分」），`gaṇanā`→「计算／计数」，全书统一。
- **duka / tika / chakka / sattaka**：§1853「非因二法」、§1855「三法」、§1857「六法」、§1859「七法」四处同一错型（详见必改项 2），需一次性改齐。
- **atthi / natthi / vigata / avigata 四缘的否定式**：§1852「非有（noatthi）」与「非非有（nonatthi）」并列，前者既是 noatthi 的译名、又隐含 natthi=非有，造成一词两指（详见必改项 3）。
- **mūlaka 的译法**：§1830「以不离去为根的部分」加了原文没有的「的部分」。此标题在全书反复出现，须先定一种写法（建议「不离去为根」）再 harmonize 全书。
- **ghaṭanā / vāra / paccaya 名**：本 chunk 内 `ghaṭanā`→组合、`vāra`→分、24 缘名前后一致，无漂移。✅
- **计数核对**：§1828–1829（9/3/3/3/1 + 1/1/1/1/1，合 10）与 §1852、1854、1856、1858、1860 全部数字，逐条比对义注 98-2442~98-2450 及 98-2403/98-2421，**全部相符**，无误译、无错位。✅

## §1828 句 81-1828-9-11
- **问题**：漏译（合并致漏） — 原文 `Avigata-sahajāta-aññamaññanissaya-atthī` 是 5 个缘（avigata / sahajāta / aññamañña / nissaya / atthi），译文「不离去、俱生、相互依止、有」只呈现 4 项，`aññamañña` 与 `nissaya` 被并成一个「相互依止」。**义注**：98-2424-106-126 将 aññamañña 与 nissaya 分别论列（`aññamañña…` 归入俱生缘；`Nissayapaccayo sahajātapurejātabhedato duvidho`，98-2424-143-146），两者是两个独立缘，不能合称。VRI 原文此处未加连字符，但不改变缘的个数。
- **建议**：改「不离去、俱生、相互、依止、有，三。」

## §1828 句 81-1828-18-25
- **问题**：同上 — 原文 6 个缘（avigata / sahajāta / aññamañña / nissaya / vippayutta / atthi），译文「不离去、俱生、相互依止、不相应、有」只有 5 项。
- **建议**：改「不离去、俱生、相互、依止、不相应、有，一。（无异熟——五）」

## §1829 句 81-1829-6-8
- **问题**：同上 — 原文 6 个缘（avigata / sahajāta / aññamañña / nissaya / vipāka / atthi），译文少一项。
- **建议**：改「不离去、俱生、相互、依止、异熟、有，一。」

## §1848 句 81-1848-2-4
- **问题**：风格（行文） — 「问分的逆的列举。」连用两个「的」，读起来别扭。
- **建议**：「问分的逆列举。」（与 §1832「（二）逆列举」同步）

## §1853 句 81-1853-2-2／§1855 句 81-1855-2-2／§1857 句 81-1857-2-2／§1859 句 81-1859-2-2
- **问题**：误译（术语所指译反） — `Nahetudukaṃ` / `Tikaṃ` / `Chakkaṃ` / `Sattakaṃ` 数的是**参与组合的缘的个数**，不是「法」。译成「非因二法／三法／六法／七法」会被读成讨论二法、三法（dhamma），与 kusalattika 的「三法」撞车，是概念错误。
  - **义注**：98-2448-2-19「`dumūlakādivasena paccayagaṇanaṃ dassetuṃ`」——以二根等显示**缘的计数**；98-2453-11-23「`Tikādīsu pana bahupaccayasamāyoge`」——三（组）等里是**多缘的会合**。
  - 正文自证：§1858 列出「非因、非所缘、非增上、非无间、非等无间」5 个前置缘 + 所问缘 = 六；§1860 为 6 + 1 = 七。
- **建议**：统一改为缘组：「非因二缘组」「三缘组」「六缘组」「七缘组」（或「非因二缘」「三缘」…）；§1851「Suddhaṃ」随之改为与之配套的「单缘」／「单一」，现译「单举」与下文的「X缘组」不成系列。

## §1852 句 81-1852-2-78
- **问题**：术语歧义（必改） — `nonatthiyā` 译「非非有」、`noatthiyā` 译「非有」。按此译法，`natthi` 本身也只能是「非有」，于是「非有」同时指 noatthi 与 natthi，读者无法还原底层缘名。
- **建议**：`natthi`→「无有」，则 `nonatthi`→「非无有」；`atthi`→「有」、`noatthi`→「非有」保持不变。改后一段读作「……非相应，十一；非不相应，九；非有，九；非无有，十五；非离去，十五；非不离去，九。」四缘的否定式互不混淆。另：`naāsevane`→「非重复」可用，但 āsevana 尚未登记，见文末。

## §1856 句 81-1856-2-72
- **问题**：误译（体例符号） — `… pe …`（peyyāla，中略号）译作「……乃至……」。现代汉语「乃至」意为「以及／甚至」，不表示「此处省略」，读者会以为是原文的连接词；且 style.md 第一节把「乃」列为须回避的文言虚词。
- **建议**：改「……（中略）……」或「……中略……」，并在 harmonize 时统一全书 `…pe…` 的处理。

## §1827 句 81-1827-2-5
- **问题**：风格（可读性） — 「俱生的组合（十）」。**义注**98-2421-2-12：「`Yāni pana sahajātaṃ labbhanti, tāni sahajātaghaṭanāni nāmāti vuccanti`」——凡能得俱生（缘）的组合，才叫俱生组合；故这是「含俱生的组合」，不是「由俱生构成的组合」。多出的「的」还会让标题读成偏正结构。
- **建议**：「俱生组合（十）」；若要显义注之意可作「（含）俱生的组合」，但须与全书其他 ghaṭanā 标题（如 pakiṇṇakaghaṭanā）同形。

## §1828–1829 全段（裸列缘名的可读性）
- **问题**：风格 — 组合列表里的「有」「不离去」是裸词，「有，一」对非专业读者几乎不可解；style.md 的目标读者含一般读者。
- **建议**：要么该类列表每项加「缘」（「不离去缘、俱生缘、依止缘、有缘」），要么全部保持裸词；**不要在 §1828/1829 裸词、§1854 又作「从非因缘」**。注意 §1852 的方位格（`Nahetuyā`）不宜加「缘」——「非因缘，十五」会被读成「不是因缘」，现译「非因，十五」是对的，不要动。此项需 harmonize 一次定案。

## §1830 句 81-1830-2-3
- **问题**：擅自补足 — 「以不离去为根的部分」中「的部分」原文（`Avigatamūlakaṃ`）没有。
- **建议**：「不离去为根。」或「以不离去为根。」并在 harmonize 时与全书 `…mūlakaṃ` 标题统一。

## 存疑与「不要改」提示

1. **§1844 句 81-1844-2-15 / §1846 句 81-1846-2-15（含 §1845、§1847）——现译正确，revise 阶段不要「补全」**
   原文只作 `sahajātaṃ, purejātaṃ` / `sahajātaṃ, pacchājātaṃ, āhāraṃ, indriyaṃ`，省去 `paccayena paccayo`。这是刻意的：**义注** 98-2437-33-51「`kiñcāpi sahajātā, sahajātapaccayā pana na honti vatthumissakattā`」——与所依混在一起时虽是俱生，却**不是俱生缘**，只依 nissaya / atthi / avigata 成立；98-2438-95-99 亦云「`Pacchājātāhārindriyapaccayā panettha na labbhantiyeva`」。现译「是……的缘：俱生、前生」正好避开了「以俱生缘为缘」的断言，**是对的**。请在 revise / harmonize 时保留这一不对称，并由 footnote 步补一条脚注说明，不要为「整齐」改成「以俱生缘为缘」。
2. **原文体例（记录，不改）**：VRI 本段连字符不规范——`aññamaññanissaya`（§1828-9-11、§1828-18-25、§1829-6-8）与 `aññamañña-nissaya`（§1828-12-14、§1829-9-11）并存，`sahajātaaññamañña`（§1829-15-22）亦缺连字符。译文不应随连字符切分，须按缘的个数切。建议记入 `knowledge/known-issues.md`「OCR / 原文问题」。
3. **术语登记**：24 缘名（因、所缘、增上、无间、等无间、俱生、相互、依止、亲依止、前生、后生、重复、业、异熟、食、根、禅、道、相应、不相应、有、无有、离去、不离去）本 chunk 内用法一致且与传统汉译相合（`nissaya`=依止 / `upanissaya`=亲依止 的区分尤其正确），但 `term-glossary.jsonl` 一条未登记。建议定稿后批量补入，避免后续章节漂移。
