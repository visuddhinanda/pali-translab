> 说明：本层是 book=98 义注（`1._Kusalattikavaṇṇanā`），父层为 book=81 本文（段 153–2657）。以下首先核查黑体被解释词与父层定稿译文的逐字一致性。

## 一、被解释词与父层逐字一致性（硬约束）

- **§2281 `nahetupaccayā` / `ārammaṇe dve`** → 译「以非因缘」「在所缘缘中有二」。
  父层 book=81 段 544（`81-544-2-70`，即本文 190 段）定稿作「**以非因（hetu）为缘时**：**所缘（ārammaṇa）缘有两条**」。
  - **问题**：对应关系断裂 — 黑体被解释词译法与父层不一致：父层作「以非因为缘时」，义注作「以非因缘」；父层作「所缘缘有两条」，义注作「在所缘缘中有二」。读者无法看出这条注在注哪一句。
  - **建议**：改为父层字样「**以非因为缘时**」「**所缘缘有两条**」（必改项）。若判定父层本身译法需调整，则属 harmonize 阶段事，本步只能照父层对齐，不得反向改父层。

- **§2283 `nahetupaccayā` / `nārammaṇapaccayā` / `nāsevanapaccayā`** → 译「以非因缘」「以非所缘缘」「以非重复缘」。
  父层段 550、551（`81-550-2-15`、`81-551-2-13`）作「以非因为缘、以非所缘为缘、……以非重复为缘」，并明确「到非重复缘为止，全都相同」。
  - **问题**：同上，黑体词未照父层「以非…为缘」句式。父层「非重复」与本层「非重复」术语一致，但虚词结构不同。
  - **建议**：统一为「**以非因为缘**」「**以非所缘为缘**」「**以非重复为缘**」。

- **§2286 `Nārammaṇamūlake hetuyā pañcā`** → 译「在以非所缘缘为根本的部分中，在因缘中有五」。
  父层段 558、559（`81-558-2-2`、`81-559-2-47`）作「非所缘二缘组」「**以非所缘为缘时**：**因缘有五条**」。
  - **问题**：「在因缘中有五」与父层「因缘有五条」不逐字相同。
  - **建议**：改为「以非所缘为根本的部分中，**因缘有五条**」。

- **§2286 `Aññamaññe ekaṃ`** → 译「在相互缘中有一」。父层段 559 作「**相互缘有一条**」。
  - **建议**：改为「相互缘有一条」。

- **§2287 `Nādhipatimūlake hetuyā navā`、`Tīṇi`、`dve`** → 父层段 563、564（`81-564-2-71`）作「非增上二缘组」「**以非增上为缘时**：**因缘有九条**……」。
  - **建议**：「在因缘中有九」→「因缘有九条」；「三」「二」→父层对应作「有三条」「有两条」，应照改。

- **§2288 `Napurejātamūlake hetuyā sattā`** → 父层段 573、574（`81-574-2-72`）作「非前生二缘组」「**以非前生为缘时**：**因缘有七条**」。
  - **建议**：「在因缘中有七」→「因缘有七条」。

- **§2288 `Nakammamūlake hetuyā tīṇi`** → 父层段 591、592（`81-592-2-68`）作「非业二缘组」「**以非业为缘**：**因缘中有七**」。
  - ⚠ **数目分歧**：父层 592 段的非业根本门里「因缘中有七」，而本层义注说「在因缘中有三」。按 PTS/VRI 本文（`81-1037-2-69`，问分非业二缘组）确为「因缘中有七」，而缘生分（`81-592`）亦作七；义注此处说「三」是因为所讨论者为**缘生分·逆顺**（paccayapaccanīyānuloma）段中「非业缘下，顺向只得思（cetanā）一法，故按善/不善/无记三类计三」。原文 `cetanāva paccayuppannā` 正说明了这一点，译文也已译出「这里只有思是缘所生法」。
  - **结论**：数字本身无误，无需改动；但黑体词须照父层字样。
  - **建议**：「在因缘中有三」中的被解释词部分改作父层句式「**因缘中有三**」（父层 592 用「因缘中有七」句式，「在…中有…」与「…中有…」有一字差，应去掉「在」字以求逐字对齐）。

- **§2285 `nahetupaccayā ārammaṇe dve`（第二次引用）、`Vipāke ekaṃ`、`Magge ekaṃ`** → 父层段 544 作「**异熟（vipāka）缘有一条**」「**道（magga）缘有一条**」。
  - **问题**：本层译「在异熟缘中有一」「在道缘中有一」，与父层「异熟缘有一条」「道缘有一条」不一致。
  - **建议**：照父层改。

> 小结：本 chunk 所有黑体引文（共约 12 处）**无一处与父层定稿逐字相同**，一律以「在 X 缘中有 N」替换了父层的「X 缘有 N 条／X 缘中有 N」。这是本次审稿最严重的问题，属必改项，须整批对齐。

## 二、跨段一致性

- **`paccayuppanna`**：§2284 译「缘所生的诸法」、「缘所生法」；§2285 译「为缘所生法」；§2288 译「缘所生法」。
  - **建议**：统一为「缘所生法」（§2284 开头的「缘所生的诸法」可保留复数义，但宜作「诸缘所生法」以与后文一致）。

- **`paccanīkato ṭhite` / `anulomato labbhanti`**：§2281–2282 一贯译「处在逆的一边」「从顺的一边得到」，一致，良好。但 §2283 起同一概念改用「与非业缘相配」「顺向只得…」（§2283 的「顺的一边」在 2283 段内已变为「从顺的一边得到」与「别的得不到」混用），仍属可接受范围。
  - **建议**：全 chunk 固定「处在逆的一边」／「从顺的一边得到」一组表述，避免 §2283 出现「只取五个」「别的得不到」这类自由变体与前文不接。

- **`gaṇanā` / `gaṇanavāra`**：§2281 译「计数」，§2284 译「计数分」，§2285 译「计数」，§2288 译「计数」。父层对此概念作「计数分」（如 `81-344-2-4` 「2. 计数分」）。
  - **建议**：`gaṇanā` 作「计数」、`gaṇanavāra` 作「计数分」，并在 §2284「这里的计数分」处保留「分」；现状基本正确，无需大改，仅需确认 §2281「计数」未误指「计数分」。

- **`mūlaka`**：§2283 译「以…为首」（dumūlakādīsu → 「以哪一个缘为首」），§2286–2288 译「以…为根本的部分」。父层统一作「以…为根本的部分」（如 `81-353`、`81-420`、`81-425`）。
  - **问题**：同一词在 §2283 与 §2286–2288 译法不一。
  - **建议**：§2283 的「以哪一个缘为首」改为「以哪一个缘为根本」。

- **`duka`（二缘组）**：§2283 译「二缘组」，与父层（`81-347-2-2` 「非因二缘组」）一致，良好。

- **`sabbaṭṭhānika`**：§2284 译「在一切处都有的缘」，§2282 译「那些在一切处都有的缘」。一致，良好。

- **`arūpaṭṭhānika` / `arūpa`**：§2281 译「只在非色法处才有的缘」「只属于非色法的」；父层对 `arūpe` 作「在无色界」（如 `81-309-2-32`、`81-338-2-36`）。
  - **问题**：此处 `arūpa` 的两种所指（① 非色法=名法，② 无色界）在本 chunk 内混用而未区分：§2281 的 `arūpānaññeva` 按义注语境指**名法（非色法）**，译「非色法」正确；但 §2288 引父层文 `āruppe kusalaṃ ekaṃ khandhaṃ paṭicca` 译作「在无色界，缘于一个善蕴」，与父层 `81-309` 「在无色界，缘一个善蕴生起三蕴」基本对齐（仅「缘于」vs「缘」一字差）。
  - **建议**：§2288 的「缘于一个善蕴」改为父层字样「**缘一个善蕴**」；§2281 的「非色法」保留，但建议首次出现时夹注（arūpa）以免读者与「无色界」混淆。

## 三、逐句问题

### §2281 句 98-2281-25-57
- **问题**：句法与可读性 — 「在那被说为“只属于非色法的”九个缘当中」，其中「被说为」是被动式翻译腔；且引号内「只属于非色法的」是对 `arūpānaññeva` 的直译，读者难解。
- **建议**：改为「在前面说过的那九个只对名法起作用的缘当中」，并于「名法」后夹注（arūpa）。

### §2281 句 98-2281-68-91
- **问题**：标点与断句 — 「然而结生异熟从前生缘而言，以及一切异熟连同作用意界从重复缘而言，虽然不是由这些缘而生起，却仍然得到无间等缘」。两个「从…而言」并列后接「虽然…却…」，主语链过长，读者易失落主语。
- **建议**：拆为两句：「然而，结生异熟就前生缘来说，并不是由它生起的；一切异熟连同作用意界就重复缘来说，也不是由它生起的。但这两者仍然得到无间等缘。」

### §2282 句 98-2282-20-36
- **问题**：句长与结构 — 「除了那些在一切处都有的缘以及相互、业、食、根这些缘以外，其余的从顺的一边得不到；至于另外那些，则按能够相配的情形而得到」。「其余的」与「另外那些」所指重叠，逻辑上自相矛盾（既说「其余得不到」，又说「另外那些按情形得到」）。按巴利 `avasesā anulomato na labbhanti, itare yujjamānakavasena labbhanti`，`avasesā` 指被除外项之外的缘，`itare` 指被除外的那些（即一切处缘与相互/业/食/根）。
- **建议**：改为「……以外，其余的缘从顺的一边得不到；而被除外的那些，则按能相配的情形而得到。」把 `itare` 明确为「被除外的那些」。

### §2283 句 98-2283-68-102
- **问题**：存疑处未标明层次／来源 — 译文把僧伽罗语写本的记法与义注的解释混在一句里（「它的意思是：从非因缘起直到非业缘……」）。这是义注在解释一条写本旁注，宜让读者看出「这是义注对写本记法的解说」。
- **建议**：在「它的意思是」前补「**义注**解释说」，或在「用僧伽罗语写下的」后加「（写本旁注）」以标明层次。
- **附注**：父层 `81-551-2-13` 译文在同一处已加了长篇译者注（「注：义注说这句是僧伽罗语写本的记法……VRI 本此处作「有五问」，与义注所据的写本不同」）。本层与父层对同一事的处理应协调，不必在义注层重复该注，但须确认两处结论不冲突 —— 现状不冲突。

### §2283 句 98-2283-103-111
- **问题**：文言残留 — 「不要拘守字面」中「拘守」属半文言；另「只应取它所要表达的意思」中的「只应」偏文言。
- **建议**：改为「不要死抠字面，只要取它想表达的意思就可以」。

### §2283 句 98-2283-112-119
- **问题**：文言残留 — 「因为这类字句是古代的诸师为了便于自己记忆，用各自的语言写下来的」，「诸师」属半文言（`porāṇehi` 指古代论师）。
- **建议**：改为「古代的那些论师」或「从前的论师们」。

### §2284 句 98-2284-15-23
- **问题**：可读性 — 「那应当依无想有情中以及五蕴不全处在转起时的色命根来理解」，「五蕴不全处在转起时」极难断句（读者会读成「五蕴不全／处在转起时」还是「五蕴不全处／在转起时」）。`pañcavokāre pavatte` 指「在五蕴具足的生存地中、于转起（pavatti）时」——注意 `pañcavokāra` 通常指**五蕴俱全**（色界/欲界五蕴有情），不是「不全」。
- **问题分类**：**疑似误译**。`pañcavokāra` = 五蕴（pañca + okāsa/vokāra，「五种成分」），即名色俱全的有情；译作「五蕴不全」语义相反。
- **建议**：改为「那应当依无想有情的色命根，以及五蕴有情（pañcavokāra）在转起时的色命根来理解。」此处 nissaya 缺失，无法用词级基准独立确认，但从义理看：色命根在无想有情（只有色法）与五蕴有情的转起时期都由业缘而生、却不由（名法的）根缘而生，故应是「五蕴有情」。**存疑度中高，建议 revise 时核对 nissaya 或《发趣论注》他处用例后定案。**

### §2284 句 98-2284-46-62
- **问题**：句子过长、关系不清 — 「在业所生色只是依异刹那的业而得到业缘的地方，那里的色法得不到因缘、增上缘、异熟缘、根缘、禅缘、道缘，而那些在一切处都有的缘不会成为逆的一边。」末句「而」字转折突兀，与前半句无明显逻辑关系。
- **建议**：拆句并补出关系：「……那里的色法得不到因缘、增上缘、异熟缘、根缘、禅缘、道缘。至于那些在一切处都有的缘，则不会落在逆的一边。」

### §2284 句 98-2284-63-72
- **问题**：标点 — 「在无因的法里没有增上缘——依这些杂项，这里的计数分也应当毫不混乱地了解。」破折号前后是两件事（一条规则 + 总结语），用破折号连接会被读成同一句的解释。
- **建议**：改为「在无因的法里没有增上缘。依这些零散的要点，这里的计数分也应当毫不混乱地弄清楚。」`pakiṇṇaka` 父层未出现，本层译「杂项」可，但建议作「零散的要点」更贴近「散说」之意；若选「杂项」，需与下文可能出现的 `pakiṇṇakaghaṭanā`（父层 `81-1615` 等译「杂类组合」「杂项结合」）协调 —— 父层该词译法本身在「杂类组合／杂项结合／杂类结合」之间摇摆，本层宜固定一种。

### §2285 句 98-2285-2-26
- **问题**：句长 — 「首先是无因的痴以及无因的异熟与作用心为缘所生法，所以这里的“二”是就以不善生不善、以无记生无记而说的。」其中「无因的异熟与作用心」对 `ahetukavipākakiriyā`，`kiriyā` 在父层统一译「作用无记」「唯作无记」（见 `81-178-2-35`「作用无记」、`81-295-2-35`「唯作无记」），本层单作「作用心」。
- **问题**：跨层术语不一致，且父层自身 `kiriyā` 译法有「作用无记／唯作无记／作无记」三种并存。
- **建议**：本层统一作「作用（kiriyā）心」并在首次出现夹注；同时把此条记入术语报告，供 harmonize 阶段统一父层的 `kiriyābyākata`。

### §2285 句 98-2285-31-39
- **问题**：译文可读性 — 「但在重复缘中得不到异熟，作用意界也同样得不到。」原文 `Āsevane pana vipākaṃ na labbhati, tathā kiriyamanodhātu`，意为「在重复缘里得不到异熟（即异熟心不以重复为缘），作用意界也一样」。现译「作用意界也同样得不到」会被读成「得不到作用意界」，主宾关系含混。
- **建议**：改为「但在重复缘里，异熟是得不到的；作用意界也一样得不到。」

### §2286 句 98-2286-13-23
- **问题**：术语 — 「因为色法是缘于善、不善、无记、善与无记、不善与无记这五个部分而生起的。」`koṭṭhāsa` 译「部分」可，但「五个部分」在计数语境里易与「五」这一数目混淆。
- **建议**：改为「这五类」或「这五组」。

### §2286 句 98-2286-28-36 / 37-42
- **问题**：术语 — `bhūtarūpāni` 译「诸大种色」。父层统一作「大种」（`mahābhūta`，如 `81-160-73-101`「以一个大种（mahābhūta）为缘」）。`bhūtarūpa` 与 `mahābhūta` 同指四大。
- **建议**：统一作「诸大种」，去掉「色」字，或作「诸大种（即四大之色）」；避免与「所造色」（upādārūpa）系列混淆。
- **问题**：`vatthu` 译「所依处」，父层对 `vatthu` 的译法有「所依」（`81-160-65-72`「所依（vatthu，此处指心所依处）」）与「所依处」（`81-178-65-72`、`81-678-70-77`「所依处（vatthu）」）两种并存。
- **建议**：本层固定「所依处」（与父层多数处一致），并把父层的「所依」统一问题记入术语报告。

### §2288 句 98-2288-5-23
- **问题**：被解释词与父层对照（已列于第一节），另：「这就是前面以“在无色界，缘于一个善蕴”等等方式在前生缘里所显示的那些」—— 句末「所显示的那些」指代空泛。
- **建议**：补出所指：「……在前生缘那一节里所显示的那七句」。

### §2288 句 98-2288-63-76
- **问题**：标点 — 「至于“四、六、八”这三种计数，则根本没有。」句末巴利有 `natthevāti` 的 `ti`（结语标记），父层对应处（如 `81-279-2-10`）以括号收束。现译无误，但「根本没有」语气略强于 `natthevā`（只是「确实没有」）。
- **建议**：改为「至于“四、六、八”这三种计数，是没有的。」
