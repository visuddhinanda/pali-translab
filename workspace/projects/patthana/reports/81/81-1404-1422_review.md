## 跨段一致性

- **sekkha**：§1405 / §1413 译「有学的人们」，§1417 译「有学者」 → 建议统一为「有学者」（「人们」与「诸」并用显冗）。
- **vipākābyākata kiriyābyākata 并列连接**：§1412 / §1414 用「异熟无记**和**作用无记」，§1420 用「异熟无记**、**作用无记」 → 统一（建议用「、」，因 §1420 还要加「分别」，见下）。
- **法相术语夹注标准不一（必改）**：已夹注的有 ārammaṇādhipati / sahajātādhipati / sekkha / gotrabhū / vodāna / uposatha / vatthu / anuloma；同等陌生却未夹注的有 **出起（vuṭṭhāna）、果等至（phalasamāpatti）、有分心（bhavaṅga）、转向心（āvajjanā）、作用心（kiriyā）、非想非非想处（nevasaññānāsaññāyatana）、灭尽定（nirodha）**。依据 `knowledge/style.md`「法相术语首次出现夹注巴利原词，其后只用汉译」，应按同一标准补齐，否则读者会以为后一组是常见词。
- **「出起」一词两用**：§1405/§1407 作动词（jhānā/maggā vuṭṭhahitvā「从禅／从道出起」），§1417/§1419/§1420 作名词（vuṭṭhāna「成为出起的缘」）。名词处义注定为**三地异熟心**（见下），与动词同形会让读者读成「出定这个动作」 → 名词处建议作「出起〔心〕（vuṭṭhāna）」。
- **体标记（「了」）不统一**：§1405「布施以后，受持戒以后，作**了**布萨……以后」同一串并列，第三项带「了」前两项不带 → 统一（建议三项都带，或都不带）。
- 编号格式：段首「413.」用半角点，段末序号用全角「（1）」。影响小，可不改，但若后续章节要统一，宜一次定下。

## §1405 句 81-1405-16-42

- **问题**：误译（词义窄化/加价值判断） — `uposathakammaṃ katvā` 译作「作了布萨（uposatha）的**功德**以后」。**义注**：`**Uposathakammaṃ katvā**ti ... uposathadivasesu aṭṭhaṅgauposathakiriyaṃ katvā`（在布萨日作八支布萨的**行持**）。kamma 在此是「所作之业/行持」，不是「功德」；译成「功德」把因位的业换成了果报性评价。**必改项。**
- **建议**：「在布萨日受持了八支布萨（uposatha）以后」或「作了布萨（uposatha）的行持以后」。
- **问题**：`sīlaṃ samādiyitvā`「受持戒以后」偏简。**义注**：`pañcaṅgādivasena niccasīlaṃ gaṇhitvā`（以五支等受持常戒）。
- **建议**：「受持了戒以后」（并与同句另两项的「了」对齐）；若出脚注，可注明义注指「五戒等常戒」。

## §1405 句 81-1405-43-53

- **问题**：背景补出 — 译文平铺「有学的人们看重种姓心而省察，看重净化心而省察」，读者会以为同一批人两事并作。**义注**：`**Sekkhā gotrabhun**ti sotāpannaṃ sandhāya vuttaṃ ... **Vodānan**ti idaṃ pana sakadāgāmianāgāmino sandhāya vuttaṃ`（gotrabhū 约初果者说，vodāna 约二果、三果者说；`**Sekkhā**ti sotāpannasakadāgāmianāgāmino`）。
- **建议**：译文不必改动，加段后脚注说明二者分属不同圣位；并把「有学的人们」统一为「有学者」。

## §1407 句 81-1407-14-23

- **问题**：读者可能误解 — 本句标题是「善法成为**无记法**的缘」，而译文只说「阿罗汉从道出起以后，看重那道而省察」，无记法指什么没有落地。**义注**：`Paccavekkhaṇacittāni panassa kiriyābyākatāni`（阿罗汉的省察心是作用无记）；又 `Arahato uttamadhammaṃ adhigatattā lokiyakusalesu garukāro natthīti **aggamaggova** dassito`（阿罗汉处只举最上道）。
- **建议**：译文保持字面，加脚注：所省察的是阿罗汉道（最上道），能省察的心是作用无记——这正是「善→无记」成立的理由。

## §1414 句 81-1414-26-53

- **问题**：术语所指不明 — `vatthuṃ` 译「所依处（vatthu）」，与前后「眼、耳……诸触」并列时，读者会以为是泛指的「依处」。**义注**（同一藏的平行处）：`vipassanānukkamena oḷārikāyatanāni **vatthurūpañca**ti ekādasa rūpāni`、`vatthuggahaṇena cakkhādīni saṅgahitabbāni`——此处 vatthu 即心所依处（所依色）。
- **建议**：首见处作「所依处（vatthu，即心所依处）」或加脚注，其后仍用「所依处」。

## §1416 句 81-1416-24-40

- **问题**：缘名省略带来的中文歧义 — 前三段只作「随顺心成为种姓心的缘……种姓心成为道的缘」，中文「成为……的缘」单出时看不出是哪种缘（原文同样只在末尾出现一次 `anantarapaccayena paccayo`，故不算漏译）。
- **建议**：前三处补「〔以无间缘的方式〕」，或在第一处点明、其后省略；全书统一一种做法。
- **问题**：义注给出的分别未体现。**义注**：`**Anulomaṃ gotrabhussa, anulomaṃ vodānassā**ti nānārammaṇavasena. **Gotrabhu maggassa, vodānaṃ maggassā**ti nānābhūmivasena`（前两组是约**所缘不同**分说，后两组是约**地不同**分说）。
- **建议**：加脚注，说明为何四句要分列。

## §1417 句 81-1417-9-29

- **问题**：术语歧义（最重要的一处） — 「善心成为**出起**的缘」。**义注**：`**Kusalaṃ vuṭṭhānassā**ti ettha pana **kusalan**ti tebhūmakakusalaṃ. **Vuṭṭhānan**ti tebhūmakavipākaṃ. Tehi kusalajavanavīthito vuṭṭhahanti, tasmā vuṭṭhānanti vuccati. Taṃ duvidhaṃ hoti – tadārammaṇaṃ bhavaṅgañca`——vuṭṭhāna 是**三地异熟心**（彼所缘心与有分心两种）的名称，不是「出定」这个动作；此处 kusala 也限于三地善（不含出世间）。
- **建议**：作「出起〔心〕（vuṭṭhāna）」并加脚注：指从善速行心路出起的三地异熟心（彼所缘与有分两种）；可同时注明本句「善心」义注限定为三地善。
- **问题**：`phalasamāpatti` 两处同译而义注有别。**义注**：此处 `**Phalasamāpattiyā**ti sotāpattiphalasakadāgāmiphalaanāgāmiphalasamāpattiyāpi`（初、二、三果等至），下一处 `**Phalasamāpattiyā**ti anāgāmiphalasamāpattiyā`（专指三果等至）。
- **建议**：译文不变，脚注区分两处所指。

## §1420 句 81-1420-2-22

- **问题**：译文易被误读为交叉配对 — 「前前的异熟无记、作用无记的诸蕴……成为后后的异熟无记、作用无记的诸蕴的缘」，中文并列读起来像四种组合都成立。**义注**明确限定：`**Vipākābyākatā kiriyābyākatā**ti ettha vipākābyākatā vipākābyākatānaṃyeva, kiriyābyākatā kiriyābyākatānaṃyeva veditabbā`（异熟无记只作异熟无记的缘，作用无记只作作用无记的缘）。
- **建议**：加「分别」：「前前的异熟无记、作用无记的诸蕴，**分别**以无间缘的方式成为后后的异熟无记、作用无记的诸蕴的缘」，并可脚注义注原文。

## §1420 句 81-1420-23-42

- **问题**：术语范围未体现 — 「作用心成为出起的缘」。**义注**：`Tattha **kiriyā**ti kāmāvacarakiriyā. Sā duvidhassāpi vuṭṭhānassa anantarapaccayo hoti, mahaggatā bhavaṅgasseva`（此处作用心指欲界作用心，它是两种出起的无间缘；广大作用心只是有分的缘）。又 `**Bhavaṅgaṃ āvajjanāyā**tiādi vomissakavasena vuttaṃ`（此下诸句是混合而说）。
- **建议**：译文不变，脚注限定「作用心」为欲界作用心；同时按前述统一标准为「有分心（bhavaṅga）」「转向心（āvajjanā）」「作用心（kiriyā）」补首见夹注。
