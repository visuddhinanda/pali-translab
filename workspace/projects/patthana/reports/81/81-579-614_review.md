## 跨段一致性

- **`duka` / `tika` / `catukka`（§579/581/583/585/587/589/591/593/595/597/599/601/603/605/607/609/611/613）：全 chunk 一律译「二法／三法／四法」，这是误译，且是本 chunk 唯一的系统性错误。**
  这里的 duka/tika/catukka 数的是**串联起来的「缘」的个数**，不是「法」（dhamma）：
  - §580 = napacchājāta + hetu → 两个缘 → `duka`
  - §582 = napacchājāta + nahetu + ārammaṇa → 三个缘 → `tika`
  - §584 = napacchājāta + nahetu + naārammaṇa + sahajāta → 四个缘 → `catukka`
  - **义注**：`Hetuārammaṇaduke ārammaṇe vuttāni tīṇeva vissajjanāni labbhantīti attho`（98:2253）——「因–所缘**二（缘）组**」；`Hetārammaṇādhipati tike ārammaṇe vuttāni tīṇeva vissajjanāni labbhanti`（98:2254）——「因–所缘–增上**三（缘）组**」。义注同处又用 `dumūlaka / timūlaka`（二根／三根）指同一件事，数的都是缘。
  → 建议统一改为 **「非后生二缘组」／「三缘组」／「四缘组」**（或「二缘句／三缘句／四缘句」，择一贯彻全书）。「二法」在发趣论里是 dukapaṭṭhāna 的「二法组」专名，占用这个词会与四层文本里真正的 duka（法的二元组）相撞，必须避开。
  这一改动牵动全书所有数目章标题，定案后请补进 `knowledge/terms.md` 与 `known-issues.md`。

- **数目量词「…有九种」（全 chunk 23×17 处）**：原文 `hetuyā nava` 数的是**问答段**，不是「种类」。**义注**：`hetuyā navāti hetupaccaye nava pucchāvissajjanavārā honti`（98:2251）——「在因缘中有九个问答段」。译「九种」把计数单位换成了「种类」，读者会误以为是九类法。建议统一为「因缘九」或「因缘中有九（句）」。

- **「以非后生为缘」句式（§580/582/584/586/588/590/592/594/596/598/600/602/604/606/608/610/612/614）**：`na-…-paccayā` 是**对该缘的排除**，不是「以某个叫做『非后生』的缘为缘」。**义注**：`nahetupaccayāti hetupaccayapaṭikkhepo hetupaccayaṃ vinā aññena paccayena uppajjatīti attho`（98:2262）——「非因缘」即否定因缘，意为不借因缘而借其他缘生起。「以非后生为缘」字面自相矛盾。建议统一改为 **「非后生缘：…」**（标题式），或「不以后生为缘时：…」。

- 二十四缘译名全 chunk **完全一致**，无漂移：因／所缘／增上／无间／等无间／俱生／相互／依止／亲依止／前生／后生／重复／业／异熟／食／根／禅／道／相应／不相应／有／无有／离去／不离去。可直接固化进 `term-glossary.jsonl`。

- 语体一致，全 chunk 无文言虚词、无文言句式、无单音节文言词；标点全为全角，无 ASCII 引号，无任何工作标记。这几项通过。

## §584 句 81-584-2-44（§590、596、602、604、606、608、612 同）

- **问题**：措辞方向 — `( Saṃkhittaṃ .)` 意为「（以上）已略说／从略」，是对**前面已被压缩的枚举**的编者注；译「（以下省略。）」把方向指向了后文，暗示后面有内容被删，与原文所指不同。
- **建议**：统一改为「（略。）」或「（此处从略。）」，不指明方向。
