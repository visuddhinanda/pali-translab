## 跨段一致性

本 chunk 的主要问题是**同一句型在不同段落译法不一**，且其中三类是系统性词法误读，逐段孤立看不出来。

- **`cittasamuṭṭhānaṃ rūpaṃ upādārūpaṃ` / `kaṭattārūpaṃ upādārūpaṃ`（必改，涉及 6 处）**：译文一律作「生起心生色**与**所造色」「业所作色**与**所造色」，把两个受格当并列。但依四大种（mahābhūta）而生者唯有**所造色**，大种自身不属 upādā；两个受格同性同数同格，是**同位/修饰**关系，不是并列。应作「缘诸大种，生起心生的所造色」／「缘诸大种，生起业所作的所造色」。涉及 §3638-60-82、§3641-31-48、§3652、§3656-2-39、§3656-40-52、§3658-2-33。统一改掉，否则读者会误认为大种能直接生起大种以外的「心生色」这一独立项。
- **`bāhiraṃ … āhārasamuṭṭhānaṃ … utusamuṭṭhānaṃ ekaṃ mahābhūtaṃ`（必改）**：这三者是 `ekaṃ mahābhūtaṃ` 的同格修饰语（`bāhiraṃ` 为中性单数受格，与 `ekaṃ mahābhūtaṃ` 一致），不是三个独立的「色」。§3658-34-45 译成「外色……食生色……缘时节生的一大种」自身就不统一（前两项作名词、第三项作修饰语），§3664 又整体译成「外色……食生色……时节生色」。应统一为「缘外的一大种……〔缘〕食生的……〔缘〕时节生的一大种」。
- **`asaññasattānaṃ`（必改）**：属格复数，修饰 `mahābhūtaṃ`，不是「对于…而言」。§3656-40-52、§3663-52-61 均作「对于无想有情，缘一大种」，应作「缘无想有情的一大种」。
- **「非已执取可执取法」的切分歧义（建议，跨章决策）**：三法成员分别是 upādinnupādāniya / anupādinnupādāniya / anupādinna-anupādāniya。「非已执取可执取法」在中文里可被读成「非（已执取可执取）」，那样会同时涵盖第二、三法，语义反了。建议全书统一为「**非已执取而可执取法**」，与「非已执取非可执取法」形成清晰对照。此项影响全章乃至全书，定案后补进 `knowledge/terms.md` 再统一回改。
- **并列连词不统一**：§3638-31-52「三蕴**以及**业所作色」 vs §3663-2-39「三蕴**与**所依」，对译的都是 `… ca …`。建议统一用「以及」或「与」其一。
- **省略句补语不统一**：§3660 对 `anupādinnupādāniyo … pe …` 未补「生起」，§3661 对同构的 `anupādinnupādāniyo … pe …` 补出了「生起」。建议统一（倾向都不补，与原文省略对应）。
- **术语表缺登记**：`upādinna` / `upādāniya` / `mahābhūta` / `kaṭattārūpa` / `upādārūpa` / `cittasamuṭṭhānarūpa` / `vatthu` / `asaññasatta` / `paṭisandhikkhaṇa` 及各 vāra 名均未登记在 `term-glossary.jsonl`，而它们在本书高频复现。建议本章定稿后一次性反哺。

## §3633 句 81-3633-2-4
- **问题**：术语 — 「已执取三法」可接受；但义注 98-2504 称本三法全名为 `Upādinnupādāniyattika`，中文宜让读者知道这是省称。
- **建议**：保留现译，可考虑「4. 已执取三法（upādinnattika，即已执取可执取三法）」。非必改。

## §3638 句 81-3638-2-30
- **问题**：夹注 — `upādinnupādāniya` 是全章核心法相术语，本句是其首次出现，按 style.md 第二节「法相术语首次出现夹注巴利原词」应夹注，但未夹注（只有 §3633 的标题夹注了 `upādinnattika`）。

## §3638 句 81-3638-53-59
- **问题**：术语区分 — `vatthu` 译「所依」，而 §3666 `nissayapaccaya` 译「依止缘」，两者在中文里易混。`vatthu` 在此指色法的依处（义注 98-2504 以 `vatthu` 为前生缘之缘法）。
- **建议**：`vatthu` 改用「依处」，与「依止（nissaya）」分开。若保留「所依」，须在 terms.md 明确两词的分工。

## §3645 句 81-3645-2-22
- **问题**：修饰语分配 — 标题句说「缘**非已执取可执取法与非已执取非可执取法**」两类缘法，但释文译作「缘非已执取非可执取的**诸蕴与诸大种**」，让形容词管到两个名词，结果只剩一类缘法，与自己的标题自相矛盾。按论义，诸蕴是非已执取非可执取（出世间），诸大种应是非已执取而可执取（心生）。
- **建议**：断开修饰关系，如「缘非已执取非可执取的诸蕴，以及诸大种，生起心生色」，不把形容词铺到「诸大种」上；并在报告层面记下 VRI 原文此处可能省略了第二个形容词（`anupādinnupādāniye mahābhūte ca`），**不要改原文**。

## §3669 句 81-3669-2-16
- **问题**：存疑（不改译文，仅备注）— **义注**（98-2504）：`Upādinnupādāniyattikassa pañhāvāre "vatthu upādāniyānaṃ khandhānaṃ purejātapaccayena paccayo"ti pavattiṃ sandhāya vuttaṃ. Paṭisandhiyaṃ pana taṃ purejātaṃ na hoti.`——即「所依为可执取诸蕴的前生缘」一语只就**转起（pavatti）**而言，结生时该所依不是前生。该义注针对问分，本段属缘生分，故**不构成本段的必改项**；但若本章将来加脚注，这是前生缘唯一需要交代的限定。
