# Review — 71:4060-4109（channel: 73c03e1a）

> 资源：pali ✅／nissaya ❌（本次未注入）／义注 ❌（本次未注入）
> **本次仅凭巴利原文审读**，释义标准与词级基准均缺失。凡涉及「取义是否合义注」的判断本报告一律不下结论，只标注存疑。本层为本文（mūla），无父层被解释词可核。
> 本 chunk 几乎全是发趣论的格式化枚举与品目标题，问题集中在**术语统一**与**标题体例**，不在句法。

## 跨段一致性

1. **`vāra` 一词两译（必改）**：§4079 / §4088 / §4100 / §4109 译「分」（问分），§4071 / §4088 / §4094 / §4100 译「品」（俱生品、缘品、依止品、相杂品、相应品）。§4088、§4100 更是**同一句内「品」「分」混用**：「在俱生品中……乃至……在问分中」。
   → 建议统一为「分」（`pañhāvāra` 已固定译「问分」，出现 4 次，且是通行译名）：俱生分／缘分／依止分／相杂分／相应分／问分。

2. **`paṭiccavāra` 与 `paccayavāra` 撞名（必改，优先级最高）**：两者都译成「缘品」。§4071 因此自相矛盾——「俱生品、**缘品**、依止品、相杂品、相应品，都应当像**缘品**那样详细展开」，读者无法分辨后一个「缘品」指什么；§4063 / §4072 的标题「缘四句」所属的 `Paccayacatukkaṃ` 也与之混在一起。
   → 两名必须分开。建议 `paṭiccavāra` =「缘生分」，`paccayavāra` =「缘分」；或 `paṭiccavāra` =「依缘分」、`paccayavāra` =「缘分」。取哪一组都可以，但**不得共用同一译名**，并同步登记进 `knowledge/term-glossary.jsonl`。

3. **章节标题编号体例不一**：§4061 / §4083 / §4089 / §4097 / §4103 的 `1. / 2. / 3.` 译为「一、善句」「二、不善句」「三、无记句」（中文数字＋顿号），而 §4109 `7. Pañhāvāro` 译为「7. 问分」（阿拉伯数字＋点）。
   → §4109 改为「七、问分」。（§4062 / §4084 的「1-7.」是区间编号，保持原样即可。）

4. **一致且正确、应予保持**：`āsava/noāsava` 译「漏／非漏」（§4086、§4091、§4095、§4099），`sāsava/anāsava` 译「有漏／无漏」（§4105、§4106）——两组二法没有混用，这是本 chunk 最容易出错的地方，译文处理正确。
   同样保持一致的还有：`anuloma/paccanīya` =「顺论／逆论」、`avigata` =「不离去缘」、`āsevana` =「重复缘」、`niṭṭhitaṃ` =「结束」、`nava/tīṇi/ekaṃ` =「有九种／三种／一种」。

## §4060 句 71-4060-4-4（同 §4079、§4080 各处）

- **问题**：术语／语体 — `Kenaciviññeyya` 译「可被某些识知道」。「识知道」三字连读易被读成「识知／道」，且「知道」偏口语，与论书语体不合；`kenaci`（具格「被某者」）是否必指「识」，缺义注无法确认（Dhs 该二法传统上确按六识解，但本报告不替义注下结论）。
- **建议**：统一改为「可被某些心识认知的」，否定项 §4065-19-30「不可被某些识知道的善法」相应改为「不被某些心识所认知的善法」。改动涉及 §4060、§4065（三句）、§4079、§4080，须一次改齐。
- **存疑（待义注核）**：`kenaci` 的所指；义注取回后在 `knowledge/term-glossary.jsonl` 定案。

## §4071 句 71-4071-2-12

- **问题**：指代不明（见跨段一致性 2）— 「都应当像缘品那样详细展开」中的「缘品」译自 `paṭiccavāra`，但同句前面的 `paccayavāro` 也译作「缘品」，句子变成「缘品应当像缘品那样展开」。
- **建议**：按上文定下的区分改写，例如「（俱生分、缘分、依止分、相杂分、相应分，都应当像缘生分那样详细展开。）」

## §4077 句 71-4077-2-8

- **问题**：句式 — 「由因缘而在非所缘缘中有九种」。此处是顺逆对照的计数（anuloma-paccanīya），`hetupaccayā` 不是「生起的原因」，用「由……而……」会让读者读成因果句，与 §4069「由因缘而生起……」的用法撞车。
- **建议**：「以因缘为顺、非所缘缘为逆，有九种（略）。」或「因缘之下，非所缘缘有九种（略）。」

## §4078 句 71-4078-2-8

- **问题**：同 §4077，「由非因缘而在所缘缘中有九种」。
- **建议**：「以非因缘为逆、所缘缘为顺，有九种（略）。」两句改法须对称。

## §4088 句 71-4088-2-11（同 §4100 句 71-4100-2-28）

- **问题**：语体 — 「一切处都是一种」中的「一切处」（sabbattha）偏文言。
- **建议**：「各处都是一种」。非硬伤，但 `style.md` 要求「能用双音节现代词就不用文言词」，建议一并改。

## §4096 句 71-4096-2-52

- **问题**：夹注表述 —「（中间三种可得俱生增上）」。`majjhe tiṇṇaṃ` 指中间的三「句（答案）」而非三「种」，与同句「在增上缘中有九种」的「种」混为一谈；`labbhati` 的主语是「俱生增上〔缘〕」。
- **建议**：「（中间三句可得俱生增上缘）」。
