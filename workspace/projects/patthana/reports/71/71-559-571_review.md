# Review — 71:559-571（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> ⚠ 本次**缺 nissaya 与义注**，无法做词级格位核对与释义权威核对。下列意见仅凭巴利原文、发趣论定型句式与 `knowledge/style.md` 作出；凡涉及取义归属的条目（标注「待义注确认」）须待义注补齐后复核。本层为 mūla，无父层被解释词可核。

## 跨段一致性

- **vipassati**：§561、§562 均把 `aniccato … pe … vipassati` 拆成「以无常等观察…」＋「作观」两处译出，同一个动词译了两遍。两段写法一致，但一致地错。统一为单个动词：「把…作无常……乃至……而观察，品味、喜爱」。
- **列举项悬空**（§562 word 69-112、§563、§569）：`dānaṃ … pe … cakkhuṃ … pe … vatthuṃ + khandhe` 是同一串宾语，共享后面的 `vipassati` / `assādeti abhinandati` / `garuṃ katvā`。三处译文都只把动词挂在「诸蕴」上，前面的「布施／禅那／眼／所依」全部没有动词收尾。需按同一句式统一改写（动词前置统辖整串，或在串末补一个动词）。
- **diṭṭhi**：§561、§562、§566 一律译「见」——译法一致，但偏窄。发趣论此处定型句列 `rāgo / diṭṭhi / vicikicchā / domanassa`，`diṭṭhi` 指恶见（micchādiṭṭhi）。建议全书统一「邪见」，并在首次出现夹注。待义注确认。
- **pubbe 的补出策略不统一**：§561 `pubbe samudāciṇṇe … pe …` 补成「从前所行的烦恼」，§562 `pubbe … pe …` 补成「从前所修的善行」。两处都是在 `… pe …` 省略位上补词，补法与用词风格不一；需定一条规则（补什么、补到什么程度）并全书照办。
- **巴利夹注缺失**：本 chunk 法相术语密集（所缘缘、增上缘、俱生增上、掉举、他心智、宿住随念智、随业趣智、未来分智、转向、所依），全程无一处夹注巴利原词，与 `style.md` 第二节「法相术语首次出现夹注巴利原词（圆括号）」不符。若本书整体决定不夹注，请在项目 `knowledge/style.md` 里写明例外，否则全书不一致。
- **「出起」**（§562 两处）：`vuṭṭhahitvā` 译「出起」属译经腔，非现代汉语常用词，见下 §562 条。全书统一。
- 一致且正确、无需改动的：`assādeti abhinandati`→品味、喜爱；`garuṃ katvā`→重视；`paccavekkhati`→省察；`vatthu`→所依；`āvajjanā`→转向；`domanassa`→忧；`uddhacca`→掉举；`cittasamuṭṭhānānaṃ rūpānaṃ`→心生诸色；`sampayuttakānaṃ khandhānaṃ`→相应诸蕴。标点全角、无 ASCII 引号、无工作标记，均合规。

## §561 句 71-561-2-59

- **问题**：重复译（必改）— `bhāvanāya pahātabbe khandhe aniccato … pe … vipassati` 只有一个动词 `vipassati`，`aniccato` 是它的方式状语，`… pe …` 省略的是 `dukkhato anattato` 一类并列状语。译文「以无常等观察修所断的诸蕴……乃至……作观」把 `vipassati` 译了两次，读者会以为「观察」与「作观」是两个动作。
- **建议**：「……把修所断的诸蕴作无常……乃至……而观察，品味、喜爱，缘于它而生起……」
- **问题**：文言（必改）— 「从前所行的烦恼」中「所行」是文言构词，且意思不明（读者无法判断是「做过的」还是「生起过的」）。`samudāciṇṇa` 指素来惯行、反复现起的。
- **建议**：「以前反复生起过的烦恼」或「过去习行的烦恼」。
- **问题**：补出成分（建议，待义注确认）— 「省察」在本句原文中并不存在（被 `… pe …` 省略），是依定型句 `ariyā pahīne kilese paccavekkhanti` 补出的。按 `style.md` 第六节「不擅自补足省略成分」，此处补词需有据；补了就要与 §562 同句式处保持同一补法。

## §561 句 71-561-60-86

- **问题**：文言（必改）— 「具有修所断之心者」连用「之」「者」两个文言虚词，`style.md` 第一节明确禁「之」「其」「乃」等单音节文言虚词。
- **建议**：「以他心智了知与修所断的心相应的人的心」，或「以他心智了知心中有修所断法的人的心」。

## §562 句 71-562-2-68

- **问题**：文言（必改）— ①「从前所修的善行」：「所修」文言腔，改「以前所作的善行」；②「从禅那出起之后」「从道出起之后」：「出起」非现代汉语词，`vuṭṭhahitvā` 此处指出定／出离。
- **建议**：「从禅那出定之后」／「圣者们从圣道出起之后」如需保留术语「出起」，请在 `terms.md` 登记为固定译法并全书一致；否则统一改「出定之后」。
- **问题**：句子主语缺失致误解（必改）— 「圣者们从道出起之后……乃至……以所缘缘的方式成为果和转向的缘」，中文读起来像是「出起（这件事）成为果和转向的缘」，而原文 `phalassa, āvajjanāya … paccayo` 的主语在 `… pe …` 中被省略（定型句为所省察／所缘之法）。
- **建议**：断为两句，或在「乃至」后补出主语，例如「……圣者们从圣道出起之后省察道……乃至……（这些法）以所缘缘的方式成为果心和转向的缘」。补出内容待义注确认。
- **问题**：术语歧义（建议）— 「果」单字易被读成业果。建议「果心」或首次出现作「果（phala）」。

## §562 句 71-562-69-112

- **问题**：句法误读（必改）— 原文 `ariyā … pahīne kilese … pe … cakkhuṃ … pe … vatthuṃ … khandhe aniccato … pe … vipassati`，本句唯一的限定动词是 `vipassati`；`cakkhuṃ … vatthuṃ` 是它的宾语。译文把「眼……乃至……所依」挂在前面补出的「省察」下，再单独给「诸蕴」配「以无常等观察」，等于把一串同格宾语拆给了两个动词，其中一个还是译者补的。
- **建议**：「圣者们省察非修所断的已断烦恼……乃至……；把眼……乃至……所依、非修所断的诸蕴作无常……乃至……而观察，品味、喜爱，缘于它而生起……」（`pahīne kilese` 配「省察」是定型句，可留；`cakkhuṃ` 起的一串必须归到「观察」）。
- **问题**：重复译（必改）— `aniccato … pe … vipassati` 双译，同 §561，一并改。

## §562 句 71-562-113-130

- **问题**：主语缺失（建议）— 「以天眼见色……乃至……以所缘缘的方式成为随业趣智、未来分智和转向的缘」，中文会读成「见色成为…的缘」。原文 `… pe …` 省略了作主语的那一支（对照 §561 word 60-86 有明确主语 `khandhā`）。
- **建议**：在「乃至」后补出主语，如「……（非修所断的诸蕴）以所缘缘的方式成为……」，或改用「对……来说，以所缘缘为缘」的句式避开悬空。

## §563 句 71-563-2-51

- **问题**：列举项悬空（必改）— 「布施……乃至……持戒……乃至……禅那……乃至……眼……乃至……所依，品味、喜爱非修所断的诸蕴」：前面五项都是 `assādeti abhinandati` 的宾语，译文却让它们裸挂在句首，动词只收了「诸蕴」。
- **建议**：动词前置统辖整串：「品味、喜爱布施……乃至……持戒……乃至……禅那……乃至……眼……乃至……所依、非修所断的诸蕴，缘于它而生起……」

## §569 句 71-569-12-45

- **问题**：列举项悬空（必改）— 同 §563：「布施……乃至……所依，重视非修所断的诸蕴而品味、喜爱」，`garuṃ katvā` 应统辖「布施／禅那／眼／所依／诸蕴」整串。
- **建议**：「重视布施……乃至……禅那……乃至……眼……乃至……所依、非修所断的诸蕴而品味、喜爱，由于重视它们而生起修所断的贪。」并与 §563 采同一句式。

## §571 句 71-571-2-40

- **问题**：夹注入正文（建议）— `( dassanadukasadisā bhāvanā ninnānākaraṇā )` 是版本编者的提示语，不是本文正句。按 `style.md` 第四节，详释／编者注应作段后小字注释，不宜与正文同级内嵌。
- **建议**：移为段后注：「*编者注：修（所断）二法与见所断二法（dassanaduka）相同，无差别。*」；另「修所断二法」宜补足为「修（所断）二法」，与前文「非修所断法」的构词区分开。
- **OCR / 原文疑问**（只记录，不改）：`bhāvanā` 一词在此与 `dassanaduka` 对举，疑为 `bhāvanāduka` 脱字或缩写；`ninnānākaraṇā` 的性数与 `bhāvanā` 的呼应亦可疑。待核 VRI 原本。
