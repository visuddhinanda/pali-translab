## 跨段一致性

- **`paṭiccavāra` / `paccayavāra` 撞成同一个词（必改）**：§1957 把 `paccayavāro` 译作「缘分」，而 §1980 的 `Paṭiccavārādi` 也译作「缘分等」。《发趣论》七分（paṭicca / sahajāta / paccaya / nissaya / saṃsaṭṭha / sampayutta / pañhā）是七个互不相同的章节名，两者必须分开：建议 `paṭiccavāra`＝「缘分」（沿用 §1980），`paccayavāra`＝「缘生分」（或「依缘分」，择一登记进 `terms.md`）。详见 §1957 条。
- **「非因缘而有所缘缘」句式不统一（必改）**：§1955「因缘而非增上缘有九种」、§1974「因缘而非所缘缘有三种」用的是「而＋缘名＋有Ｎ种」；§1956、§1975 却写成「非因缘而**有**所缘缘有Ｎ种」，多出一个「有」，读起来像「非因缘而有」＋「所缘缘有九种」两截。统一为「非因缘而所缘缘有九种」。
- **`hetupaccayā`（从格）的中译**：全 chunk 作「因为因缘而生起」。意思不错，但与前面的「因法」连写成「因法因为因缘」，三个「因」相叠，易误读为因果连词。建议全 chunk 统一改「由于因缘而生起」（仅调整虚词，不动术语）。
- 以下术语在 §1950 / §1954 / §1970 / §1986 四处缘数表中均前后一致，无漂移：无间缘 / 等无间缘 / 俱生缘 / 相互缘 / 依止缘 / 亲依止缘 / 前生缘 / 后生缘 / 重复缘 / 异熟缘 / 食缘 / 根缘 / 禅缘 / 道缘 / 相应缘 / 不相应缘 / 有缘 / 无有缘 / 离去缘 / 不离去缘 ✅
- `saṃkhittaṃ`＝「略说」、`pe`＝「略」两者分工一致，未混用 ✅；数量词「两种/三种/九种/一种」一致 ✅；全角标点与引号合规，未见 ASCII 引号 ✅

## §1957 句 71-1957-2-11

- **问题**：术语撞车 — `paccayavāropi` 译「缘分」，`paṭiccavārasadisā` 也译「缘分」，结果整句变成「缘分……都应当依照缘分而同样地详细展开」，自我循环、逻辑上讲不通（被展开项与参照项同名）。原文明确是「（俱生分、缘生分、依止分、相杂分、相应分）应如 **paṭiccavāra** 那样详细展开」。
- **问题**：`saṃsaṭṭhavāro` 译「杂分」过简，与「相应分」并列时看不出 saṃsaṭṭha（相杂/混合）与 sampayutta（相应）的对举关系。
- **建议**：改为「（俱生分、缘生分、依止分、相杂分、相应分，都应当如缘分那样详细展开。）」；同时把 `paccayavāra`＝缘生分、`saṃsaṭṭhavāra`＝相杂分、`paṭiccavāra`＝缘分补进 `knowledge/terms.md`，避免后续章节再撞。

## §1971 句 71-1971-2-2

- **问题**：风格 — `Paccanīyuddhāro` 译「逆论的举出」。`uddhāra` 是「抽出、摘出（条目）」，「的举出」是动词硬作名词，不是自然的现代汉语标题。
- **建议**：改「逆论的抽出」或「逆论抽出」（标题宜短）。

## §1956 句 71-1956-2-10 ／ §1975 句 71-1975-2-10

- **问题**：句式 — 「非因缘而**有**所缘缘有两种／九种」，多一「有」，断句歧义（见「跨段一致性」第二条）。
- **建议**：「非因缘而所缘缘有两种。」「非因缘而所缘缘有九种。」

## §1965 句 71-1965-2-30

- **问题**：标点 — 「……三种（只有所缘增上）……略……。」结尾「……。」省略号后再加句号，与 §1969「……九种。」的收尾方式不一致。
- **建议**：统一为「……略……」结尾不加句号，或全 chunk 一律加；择一后在 `style.md` 登记。
- **待义注确认**：`ārammaṇādhipatiyeva` 译「只有所缘增上」，取「唯限于所缘增上」义。此处为编者夹注的限定语，义注若另有解读需复核。

## §1977 句 71-1977-2-4

- **问题**：可读性 — 「因二法受三法结束。」三个名词直接相连，读者看不出这是章节收尾标记。
- **建议**：「因二法受三法〔一章〕结束。」或「因二法受三法 终」。与 §1978 标题「因二法异熟三法」的译法本身一致，只需补出层级词。

## 原文疑问（记录，不改）

- §1950 列 23 项（含 `āsevane`、`purejāte`，无 `pacchājāte`），§1986 列 22 项（有 `purejāte`，无 `āsevane`）。译文条数与各自原文逐项吻合，非漏译；仅记录待与义注／缅本对校。
