## 跨段一致性

1. **章节标题里 duka 名的连接方式不统一**（必改）
   - §5073「已杂染二法·善三法」、§5085「与烦恼相应二法·善三法」用单成分名；
   - §5097「杂染与有杂染二法·善三法」、§5110「烦恼与已杂染二法·善三法」用「A 与 B」。
   - 后两条的「与」和分隔符「·」混用，读成「杂染 / 与有杂染二法 / 善三法」三截，层级不明。
   - 建议：双成分 duka 统一作「〔杂染·有杂染〕二法·善三法」，或改用顿号「杂染、有杂染二法·善三法」，全书一致。

2. **正文内引用其它章节时，章节名的写法与标题行不一致**（必改）
   - §5065「与**世间二法的善三法**相同」、§5072「与世间二法的无记三法相同」、§5106「与烦恼二法的不善三法相同」——用「…的…」；
   - 而标题行（§5073 / §5085 / §5097 / §5110）一律用「…二法·…三法」。
   - 同一个章节名出现两种形态，读者无法把交叉引用对回标题。建议正文引用改为与标题同形：「与「世间二法·善三法」相同」「与「烦恼二法·不善三法」相同」。
   - 另注：`Lokiyadukaabyākata`、`kilesadukaakusala` 中的 `abyākata` / `akusala` 是 tika 的**支分**，现译「无记三法」「不善三法」已把支分当成三法全名；若上条改为标题同形，宜作「与「世间二法·善三法」之无记分相同」。此处**缺义注无法定案**，列为存疑。

3. **`Hetuyā dve / ekaṃ / pañca / nava` 的译法缺谓语**（建议）
   - 全 chunk 一律作「因缘中二」「因缘中一」「因缘中五」「因缘中九」（§5065、§5067、§5072、§5077、§5080、§5083、§5089、§5092、§5095、§5101、§5106、§5108）。
   - 译法本身前后统一 ✅，但「因缘中二」不成句，属 `style.md` 禁的文言省略式。建议整段统一补谓语：「因缘中有二」「所缘缘中有一」。改则全 chunk 一起改，不要只改一处。

4. **`ceva … no ca` 的对举结构，两处译法不对称**（建议）
   - §5103 / §5105「**既是**烦恼**又**有杂染」——保留对举；
   - §5100 / §5104 / §5105 / §5107「有杂染**而不是**烦恼」——丢了前半的「既」。
   - 同一组对偶词项（`kileso ceva saṃkilesiko ca` ↔ `saṃkilesiko ceva no ca kileso`）译文读不出是一对。建议统一为「既有杂染、又不是烦恼的」。

5. **数字编号后的标点不统一**（建议）
   - §5074「一、缘生分等」用顿号；§5086 / §5098 / §5111「一至七。缘生分等」用句号；§5073 / §5085 / §5097 / §5110「七十七之一。」等亦用句号。
   - 编号 + 标题不是句子，句号读起来像断句。建议编号行统一不带句号（或统一用顿号），与「一、缘生分等」看齐。
   - 「77-1.」译「七十七之一」、「1-7.」译「一至七」——两种连字号读法不同但各自正确（前者品次分节，后者分段区间），**此项无需改**，仅记录以免后续统稿误「统一」。

6. **已核对一致、不要改动的项**（记录，防止后续误改）
   - `saṃkilesika` = 有杂染 / `asaṃkilesika` = 无杂染（§5063–5072、§5100–5107）与 `saṃkiliṭṭha` = 已杂染 / `asaṃkiliṭṭha` = 未杂染（§5073–5084、§5110）**全 chunk 严格区分，无一处串用** ✅。这两个 duka 相邻且极易混译，此处处理正确。
   - `paṭiccavāra` 缘生分 / `sahajātavāra` 俱生分 / `pañhāvāra` 问分、`hetupaccayā` 由于因缘、`avigate` 不离去缘、`ārammaṇe` 所缘缘、`sampayutta` 相应 / `vippayutta` 不相应、`pe` 乃至、`saṃkhittaṃ` 略——全 chunk 一致 ✅。
   - 建议把「有杂染／无杂染／已杂染／未杂染」四项与「缘生分／俱生分／问分」补进 `knowledge/term-glossary.jsonl`，锁死后续 chunk。

## §5075、§5087、§5099 句 71-5075-2-2 / 71-5087-2-2 / 71-5099-2-2

- **问题**：术语存疑 — `Paccayacatukkaṃ` 译「缘四法」。`catukka` 是「四句／四支一组」，指下文四个问答句式；而本 chunk 中「法」已固定用于 `duka`=二法、`tika`=三法（母题对偶／三分）。沿用同一「法」字会让读者以为存在一个与二法、三法并列的「四法」母题范畴，而实际并无此物。
- **建议**：改为「缘的四句」或「四缘句」；若决定保留「缘四法」以维持 duka/tika/catukka 的构词平行，也需在 `terms.md` 写明理由。**缺义注，无法定案，列为必须复核项**。

## §5097 句 71-5097-4-4
