# Review — 174:1477-1487（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注（父层 aṭṭhakathā）❌（未注入）／现有译文 ✅
>
> ⚠ **两重标准全缺**。本 chunk 是《发趣论》问数偈（Pucchāgaṇanagāthā），通篇由数词复合词构成，复合词切分一变、数值即差几个数量级——这恰恰是最依赖 nissaya 的一类文本。本报告只能据巴利词形与偈内体例一致性做形式审查，**凡涉及数值取义的条目均为"待据 nissaya 判定"，revise 前必须补取 nissaya 与父层义注的问数部分**。
> 同理，"被解释词与父层逐字同译"一项（本层为复注，父层为义注）**本次无法核查**，缺口要在 revise/harmonize 时补。

## 跨段一致性

- **数量单位体例自相矛盾（必改，chunk 级）**：§1477 用汉语大数单位「三百六十万」，而 §1478/1482/1483 用印度单位「X 个十万（lakkha）」「X 个俱胝（koṭi）」。同一首偈两套体例，读者无法把各句累加成总数。→ 建议统一为保留印度单位：§1477 改「三十六个十万」（chattiṃsati-sata-sahassa 即 36 lakkha），汉语换算值若要给，放脚注。
- **悬空数词（必改）**：§1478「又有九个」、§1481「共有三百四十四，还有一万三千」——数词后无单位，中文读来不知所指（九个什么？三百四十四个什么？）。偈颂中心词是承前的 `pucchā`（问题）或上句单位。→ 建议据 nissaya 补出单位或计数对象，如「又有九个（十万）」「问题共三百四十四……」。这是本 chunk 最成片的问题。
- **`honti` 译法不一**：§1479 译「共成为」，§1483 译「共有」。→ 统一为「共有」。
- **列举连接词不一**：§1478「有…个，又有…个，还有…个」／§1481「共有…，还有…」／§1482「又有…，以及…」／§1483「共有…，以及…」。同一首连续计数偈宜统一（建议一律「……，又……，又……」或并列顿号）。
- **`paṭṭhāna` 系书名体例不一**：§1480「全面发趣（samantapaṭṭhāna）」不加书名号，§1484/1485「《发趣论》」加书名号。samantapaṭṭhāna 在此指《发趣论》的四分体例之一（传统亦作「遍发趣」），是篇章名而非论名。→ 建议统一：论名《发趣论》，体例名「遍发趣／全面发趣」不加书名号（现译已不加，但须与 §1484 的处理在报告中说明理由，并把译名定案补进 `terms.md`）。
- **术语表待补**：`term-glossary.jsonl` 登记 `abhidhamma → 论`，而 §1487 作书名译「《阿毗达摩》」。此处作藏名/书名属合理例外，但应在 `terms.md` 补一条规则（作藏名、书名时译「阿毗达摩」），否则后续 term-check 会误判。

## §1477 句 174-1477-2-3

- **问题**：取义／复合词切分（待据 nissaya 判定） — `-ṭṭhakayuta-` 至少两解：①`aṭṭhaka + yuta`（"与八相连"，现译所取）；②`aṭṭha + (a)yuta`（八个 ayuta，ayuta = 一万，是大数列中的固定单位）。全偈其余成分（sata / sahassa / lakkha / koṭi / nahuta）**全是数量单位**，②与偈内体例相合；①则引入一个无单位的"八"，与上条"悬空数词"同病。
- **建议**：以 nissaya 的缅文释义判定切分；若取②，改作「八个阿由多（ayuta）与七个那由多」。取①则须在报告中说明"八"的所指，不能让"与八相连"原样留在译文里——现读法语义不明，一般读者无法理解。
- **问题**：术语 — `nahuta` 译「那由多」，易与 `nayuta`（传统汉译「那由他」）混同，二者在巴利大数列中不是同一单位。
- **建议**：保留「那由多（nahuta）」，首次出现加脚注给出其进位值与"非那由他（nayuta）"的辨异，并把这一条补进 `terms.md`。

## §1478 句 174-1478-2-9

- **问题**：句法／取义（待据 nissaya 判定） — `chacca cattālīseva navātha koṭiyo dasa ca` 的归并关系不清。现译拆成「四十六个 / 又有九个 / 还有十个俱胝」三段，其中「九个」无单位；另一可能是 `nava atha` 与后面 `koṭiyo dasa` 合读（九与十俱胝）。
- **建议**：据 nissaya 格助词与缅译数词确定 `nava` 修饰的单位后重译；无论取哪一解，译文都不得留下无单位的「九个」。

## §1479 句 174-1479-2-8

- **问题**：误译（句法） — `sattakoṭisatehi ca ... koṭisahassāni nava honti` 的 `-ehi ca` 是具格"连同"，表示七百俱胝**包含在**总数内；现译「再加上七百俱胝，共成为九千俱胝」把它读成先后相加，却又让总数仍是九千，逻辑上自相矛盾（加了 700 还是 9000？）。
- **建议**：改为「连同七百俱胝，共有九千（七百）俱胝。」——确切数值与 `nava` 的归属须据 nissaya 核定；若 nissaya 判定总数确为九千俱胝、七百俱胝为其中一项，则写「其中含七百俱胝，总计九千俱胝」。

## §1480 句 174-1480-2-8

- **问题**：汉语搭配 — 「乘以四倍」杂糅（「乘以四」与「增至四倍」二者择一）。
- **建议**：改「这些问题各乘以四」或「这些问题增为四倍」。
- **问题**：语序 — `Tā catuguṇitā pucchā` 为主句，locative `catuppabhede samantapaṭṭhāne` 后置；现译把处所状语提到句首，与下句 §1481 的数值承接关系变弱。
- **建议**：改「这些问题乘以四，在分为四类的全面发趣（samantapaṭṭhāna）中——」，使 §1481 的数字直接承上。

## §1481 句 174-1481-2-7

- **问题**：取义（待据 nissaya 判定） — `catucattālīsasatattayaṃ` 现译「三百四十四」（读作 sata-ttaya 三百 + 44）；另一解为「四十四个三百」。两解相差一个数量级。
- **建议**：据 nissaya 判定后给确值；并按上文"悬空数词"条补出单位。

## §1483 句 174-1483-2-10

- **问题**：可读性 — 「共有八百，以及三十八个十万，这就是总的计数」按巴利语序先小后大，中文读来像两笔并列的零散数字，而原文是"以上即总计"的收束句。
- **建议**：数值顺序改为由大到小并明确收束，如「共有三十八个十万零八百——这就是总数。」（具体数值与 `aṭṭhasatāni` 的位值须据 nissaya 核定）；`iti gaṇanā` 译「这就是总数」比「总的计数」自然。

## §1485 句 174-1485-2-4

- **问题**：漏译（可接受但需记录） — `pakaraṇa`（论典/本论）未译出，现译以「《发趣论》」的「论」字吸收。
- **建议**：维持现译即可，但须在 `terms.md` 记一条「`paṭṭhānapakaraṇa` → 《发趣论》，pakaraṇa 不另出字」，以免后续 term-check 反复报漏译。

## §1486 句 174-1486-2-5

- **问题**：称谓叠加 — `bhadanta-ānanda-ācariyaka` 译「尊者阿难陀阿阇梨」，前后各一重敬称，中文冗赘。
- **建议**：择一，作「阿难陀阿阇梨」或「尊者阿难陀论师」。
- **问题**：存疑未标 — 此「阿难陀」是《根本复注》作者（后世论师），非佛世的阿难尊者，读者极易误认。
- **建议**：首次出现加脚注说明（按 `style.md`，正文不留标记，辨异写脚注／本报告）。

## §1487 句 174-1487-2-5

- **问题**：句间关系断裂 — 巴利 §1486+§1487 是一句：`iti ... katā līnatthapadavaṇṇanā` 与 `abhidhammassa mūlaṭīkā` 同位，`samattā` 是全句谓语，意为"以上由阿难陀阿阇梨所作的《隐义句释》，即《阿毗达摩》的根本复注，至此完毕"。现译把 §1487 写成独立新句「《阿毗达摩》的根本复注结束。」，同位关系丢失，读者会以为这是另一部书的结尾。
- **建议**：段界不动（不合并不拆分），改为承接式读法：§1487 作「即《阿毗达摩》的根本复注，至此完毕。」
- **问题**：一致性 — `samattā` 在 §1485 译「结束」、§1487 同词同译「结束」✅；若采纳上条改「完毕」，须同时回改 §1485，保持同词同译。
