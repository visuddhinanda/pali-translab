## 跨段一致性

- **节号译法不统一（必改）**：`77.` → 「七七、」、`78.` → 「七八、」、`79.` → 「七九、」，但 `80.` → 「八十、」。前三者是逐字读数，汉语里「七七」会被读成 49/「七七四十九」式的乘法或叠词，与「八十」也不成体系。统一为「七十七、」「七十八、」「七十九、」「八十、」。
- **省略谓语的句式不统一**：全 chunk 以「以 X 缘的方式成为……的缘」为骨架，但 §1212 第二句改用「随顺**是**种姓的缘」「种姓**是**道的缘」等「是……的缘」式。建议统一为「成为……的缘」。
- **夹注巴利原词的取舍不统一**：`anantarapaccaya` / `samanantarapaccaya` / `sahajātapaccaya` / `aññamaññapaccaya` / `vuṭṭhāna` / `gotrabhu` / `vodāna` / `phalasamāpatti` 均首次夹注，但同属法相术语且更易误读的 `āvajjanā`（转向，§1213）、`vatthu`（所依，§1220）、`nevasaññānāsaññāyatana`（非想非非想处，§1212）、`mahābhūta`（大种，§1220）一律未注。按 `style.md`「法相术语首次出现夹注巴利原词」，至少 `āvajjanā` / `vatthu` 应补注。
- **`khandhā` 复数译法混用**：§1208/§1210 作「前面各个……蕴」，§1209/§1211/§1213/§1214 作「……的诸蕴」，§1226 作「诸蕴」。「各个」已由 `purimā purimā` / `pacchimānaṃ pacchimānaṃ` 承担，不冲突，但建议在无叠词修饰处一律用「诸蕴」，有叠词处一律用「各个……蕴」，不要交替。
- **`tīṇi`（§1218/§1219）译「三种」**：这里是发趣论的计数尾注，指「（以上）三问/三条」，不是「三类法」。两处都应改，见下。

## §1208 句 69-1208-2-26

- **问题**：风格/体例 — 「七七、」见上。
- **建议**：改「七十七、」。（§1216「七八、」→「七十八、」，§1218「七九、」→「七十九、」同改。）

## §1209 句 69-1209-2-22

- **问题**：可读性/术语 — 「出起（vuṭṭhāna）」裸译。`vuṭṭhāna` 在无间缘语境指「从前面那一串心流中出起的后续心」，中文「出起」在现代汉语里不表意，一般读者无从索解；混合受众的定位下需要提示。
- **建议**：首次出现加简注，如「出起（vuṭṭhāna，即从前心流中生起的随后之心）」，其后仍用「出起」。**此条待 nissaya / 义注核实所指后定稿**（§1211、§1212 的「出起」随之统一）。

## §1212 句 69-1212-28-58

- **问题 1**：句式 — 「随顺是种姓（gotrabhu）的缘……种姓是道的缘……」与全 chunk 的「成为……的缘」不一致。
- **建议 1**：一律改「随顺成为种姓（gotrabhu）的缘……种姓成为道的缘……」。
- **问题 2**：体例 — 同句内 `gotrabhu` / `vodāna` / `phalasamāpatti` 都夹注，`nevasaññānāsaññāyatana` 独不夹注。
- **建议 2**：补作「非想非非想处（nevasaññānāsaññāyatana）」，或统一只注前三者中的罕见项。
- **问题 3**：增译待核 — `nirodhā vuṭṭhahantassa` 译「从灭尽定出起的人」，把 `nirodha` 补成「灭尽定」。依传统此处确指 nirodhasamāpatti，但这是解释性增译，**缺义注无从立据**。
- **建议 3**：保留此译，待义注复核；若义注无明文，退为「从灭（nirodha）出起的人」。

## §1213 句 69-1213-2-21

- **问题**：术语/体例 — 「转向」首次出现未夹注。现代汉语「转向」有强烈的日常义（改变方向），与 `āvajjanā`（心对所缘的转注、省察前的作意）相去甚远，极易误读。
- **建议**：改「转向（āvajjanā）」，§1214 以后仍用「转向」。另请在 `terms.md` 登记后统一（亦可考虑「作意转向」，待 nissaya 的词级释义定案）。

## §1218 句 69-1218-2-16

- **问题**：误译 — `tīṇi` 译「三种」。此处是答数尾注（三条问答），「三种」会被读作「三种缘」或「三类法」。
- **建议**：改「……三。」或「……共三条。」；§1219 同改。

## §1220 句 69-1220-2-41

- **问题**：术语/体例 — 「所依」（`vatthu`）首次出现未夹注。结生刹那语境下 `vatthu` 指心所依处（心色），单作「所依」在中文里过泛。
- **建议**：改「所依（vatthu）」；是否进一步译「心所依处」**待 nissaya / 义注核实**，不要在本步直接改写。

## §1220 句 69-1220-42-73

- **问题（必改）**：误补中心词 — `bāhiraṃ … āhārasamuṭṭhānaṃ … utusamuṭṭhānaṃ … asaññasattānaṃ … pe …` 承接上文「ekaṃ mahābhūtaṃ tiṇṇannaṃ mahābhūtānaṃ（一大种成为三大种的缘）」的省略式，被省略的中心词是 **mahābhūta（大种）**，不是「色」。译文作「外在的**色**……食生**色**……时节生**色**……无想有情的**色**」，一是补错了词，二是违反 `style.md`「不擅自补足省略成分」。
- **建议**：改为不补中心词的省略式，如「外的……食生的……时节生的……无想有情的……乃至……」；若要补，须补「大种」而非「色」（「外的一大种成为三大种的缘」式）。

## §1226 句 69-1226-2-77

- **问题 1（必改）**：同上 — 「……一大种以相互缘的方式成为三大种的缘……乃至……**无想有情的色**……」中的「色」是误补，应作「无想有情的（大种）」或不补。
- **建议 1**：与 §1220 第二句统一处理。
- **问题 2**：术语 — 「所依」两处仍未夹注（首次夹注落在 §1220 后即可，此处只需与 §1220 定案一致）。
