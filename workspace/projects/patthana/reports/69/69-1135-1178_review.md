## 跨段一致性

- **natthipaccaya**：§1136、§1152、§1170 一律译「非有缘」。三段内部一致，但这个译法与本品大量 `na-` 前缀的**否定缘名**（nahetu 非因缘、naadhipati 非增上缘、navippayutta 非不相应缘…）在汉语里完全同形：`natthipaccaya`（无有缘，顺列表中的正项）与 `naatthipaccaya`（非有缘，逆列表中的否定项）是两个不同的缘，本书后文必然同时出现，届时两者将无法区分。→ **必改**：统一作「**无有缘**」，并写入 `knowledge/terms.md`（`atthi` 有缘 / `natthi` 无有缘 / `vigata` 离去缘 / `avigata` 不离去缘）。
- **「X-paccayā + 计数列表」的句内标点不统一**：§1136「依非因缘**：**所缘缘中有七……」、§1170「依非因缘**：**……」用冒号；§1167「依因缘**，**非增上缘中有三……」用逗号。同一句式应统一 → 建议一律用冒号（更清楚地标出「在 X 缘条件下」的总领作用）。
- **以下缘名跨段已一致，确认无漂移**：所缘缘 / 无间缘 / 等无间缘 / 俱生缘 / 相互缘 / 依止缘 / 亲依止缘 / 前生缘 / 后生缘 / 重复缘 / 业缘 / 异熟缘 / 食缘 / 根缘 / 禅缘 / 道缘 / 相应缘 / 不相应缘 / 有缘 / 离去缘 / 不离去缘；顺 / 逆 / 顺逆 / 逆顺；分别分 / 计数分 / 缘分 / 依止分 / 相杂分 / 相应分 / 问分；`saṃsaṭṭha`=相杂、`sampayutta`=相应 两者始终分用（§1145 vs §1175 ✅）；`paṭisandhikkhaṇa`=结生刹那（§1147、§1159 ✅）。

## §1145 句 69-1145-2-33

- **问题**：歧义（句式与计数段混同） — 「与见所断的一蕴相杂的**有三蕴**」中的「有三蕴」会被读成计数段的「……中**有七**／**有三**」那种「句数统计」，而此处 `saṃsaṭṭhā tayo khandhā` 是陈述「三蕴与一蕴相杂」，不是数目统计。同一句式见 §1147、§1159，**三处同病，一并改**。
- **建议**：改为「与见所断的一蕴相杂的**是三蕴**」，或还原语序「**三蕴**与见所断的一蕴相杂」。统一后与 §1152 的「因缘中有三」不再混淆。

## §1157 句 69-1157-2-23

- **问题**：行文 — 「与**和**疑俱行的诸蕴相杂的」，「与……和……俱行」两个介词叠用，读起来断不开句；`sahagata` 的常用译法本身就是「与……俱行」，此处前面还有一个 `saṃsaṭṭha` 的「与」，必须让其中一个让位。
- **建议**：「与**疑俱行的诸蕴**相杂的，是**疑俱行的痴**。」（`sahagata` 定为前置定语式「X 俱行的」，`saṃsaṭṭha` 保留「与……相杂」，全书统一；请同时写入 `terms.md`）
- **取义待核**：`vicikicchā` 归在「见所断」、`uddhacca` 归在「修所断」与阿毗达摩通说相合，译文无误；但「痴」(`moha`) 在此是与疑／掉举相应的无因心中的痴，义注通常会点明它为何「非因缘而生」（自身即是唯一的因，故对自身无因缘可言）—— 待义注核，现译无需改动。
