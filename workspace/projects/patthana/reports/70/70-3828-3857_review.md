## 跨段一致性

- **分项列举的句式不统一**（本 chunk 最突出的问题）：同一类「列出子类目」的句子有两种译法并存——
  - 「有…，有…」式：§3829 / §3830 / §3831「有俱生的，有异刹那的」，§3845 / §3851「有俱生的，有前生的」
  - 顿号罗列式：§3844 / §3848「俱生的、后生的（略）」，§3850「俱生的、食的、根的」，§3853「俱生的、后生的、食的、根的」
  → 建议统一为「有…的，有…的」式（如 §3850 改「有俱生的，有食的，有根的」）。理由：顿号式在中文里是残缺短语（「食的、根的」没有中心词，读不通），而「有…的」式本身成句；且「有…的」式在本 chunk 出现次数更多（5 : 3）。
- **标目词的排版不统一**：§3845 的 `Purejātaṃ`（原文未加粗）译作「前生的：…」用冒号，而 §3851「**前生的**——」、§3845「**俱生的**——」等一律是加粗加破折号。→ 建议 §3845 统一为「**前生的**——眼处是眼识的……」。原文该处未加粗疑为底本标记脱落，但译文排版应自身一致。
- **标目词译法一致** ✅：`Sahajātā/Sahajāto/Sahajātaṃ` 一律「俱生的」，`Nānākkhaṇikā`「异刹那的」，`Pacchājātā`「后生的」，`Purejātaṃ`「前生的」，阴阳中性变化未影响中译，正确。
- **核心术语一致** ✅：`sārammaṇa` 有所缘 / `anārammaṇa` 无所缘 / `cetanā` 思 / `vatthu` 所依 / `kaṭattārūpa` 业生色 / `cittasamuṭṭhānarūpa` 心生诸色 / `rūpajīvitindriya` 色命根 / `kabaḷīkāro āhāro` 段食 / `imassa kāyassa` 这个身体 / `paṭisandhikkhaṇe` 在结生刹那 / `… pe …`（中略）/ `saṃkhittaṃ`（略）—— 全 chunk 无漂移。

## §3850 句 70-3850-2-17
- **问题**：语体 / 成句性 —「有缘——俱生的、食的、根的」。「食的」「根的」在现代汉语中是残缺定语短语，没有中心词可挂，读者无法还原其指「以食为缘的情形／以根为缘的情形」。
- **建议**：改「有缘——有俱生的，有食的，有根的」（与 §3845 / §3851 句式统一）。§3844 / §3848 / §3853 同类处一并改。

## §3850 句 70-3850-18-33
- **问题**：语义 —「（乃至无想有情）」。`yāva asaññasattā` 是范围下限标记「（如此类推）直到无想有情（为止）」，而现代汉语「乃至」通读为「甚至／以及」，意思偏成「甚至包括无想有情」，与原文的「推到…为止」不同；且「乃」属 `style.md` 禁用的文言虚词。
- **建议**：改「（直到无想有情）」或「（依此类推，直到无想有情）」。

## §3851 句 70-3851-22-35
- **问题**：成句性 —「**前生的**——把眼……（中略）……把所依观为无常……（中略）……生起忧；」。句首「把眼」后紧接省略号，「把」字悬空无谓语，读者无法读通；原文此处 `cakkhuṃ … pe … vatthuṃ aniccato … pe …` 省掉的正是 `vipassati` 一类动词，译文在第二处补了「观为」，第一处却留着孤立的「把」。
- **建议**：改「**前生的**——观眼为无常……（中略）……观所依为无常……（中略）……生起忧；」，使被省略部分的两端各自成句。另：此处完整公式通常含 `dukkhato/anattato`（苦、无我）与喜忧两支，均落在 `… pe …` 内，**待义注/nissaya 到位后复核补语是否恰当**。

## §3851 句 70-3851-36-45
- **问题**：语体（可选）—「以天眼看见色，以天耳界听到声」。`style.md` 将「以」列入文言虚词禁例；此处作工具格介词虽属现代书面语可接受范围，但同句已用「看见／听到」的口语动词，文白略不匀。
- **建议**：可改「用天眼看见色，用天耳界听到声」。保留原译亦可，属偏好项，不是错译。注：`dibbena cakkhunā` / `dibbāya sotadhātuyā` 原文本身一为「眼」一为「耳界」，译文「天眼／天耳界」不对称是忠实原文，**不要改成对称**。
