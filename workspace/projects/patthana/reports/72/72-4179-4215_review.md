# Review — 72:4179-4215（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入）。本层为本文（mūla），无父层对照，故「被解释词与父层逐字同译」一项无法执行。以下仅凭巴利原文、`knowledge/style.md` 与术语表审查，释义归属未经义注核验。

## 跨段一致性

- **`paccayā` / `paṭicca` 未加区分**：全 chunk 一律译「缘」。原文明确交替使用两词（§4180/4181 用 `paccayā`，§4182/4187/4198 用 `paṭicca`，`paṭicca` 对应 paṭiccavāra 的标准句式）。建议统一策略并在本 chunk 一贯执行：`paṭicca` 译「缘…」、`paccayā` 译「以…为缘」，或至少在译文中保持两者可区分；现状是两个不同的巴利词被折叠成同一译法，读者无法还原属于哪一 vāra。
- **`na-` 前缀的句法位置摆动**：同一结构 `na X na Y dhammaṃ`，§4180/4181/4182 译作「缘既不是…也不是…、并且不是…的法」，§4189 起译作「缘不是…、并且不是…的法」。两种句式并存无依据，建议统一为后一种（更接近现代汉语），`ceva…ca` 并列才用「既…又…」。
- **`na X` 中 X 为「相应/相杂/俱生/随转」类词时译法不一致**：
  - §4201 `Nacittasampayuttaṃ` 译「与心不相应」（把否定移入了复合词内部）
  - §4202 `Nacittasaṃsaṭṭhaṃ` 译「不与心相杂」
  - §4204 `Nacittasahabhuṃ` 译「不与心俱生」
  - §4205 `Nacittānuparivattiṃ` 译「不随心转」
  - 而 §4206/4207/4208 同类复合词却译「不是与心相杂…的法」
  → 「与心不相应」与「不与心相杂」语义层次不同（前者像是肯定「不相应」这一法，后者是否定「相杂」），在 Paccanīya（否定门）里这个差别很要紧。建议全部统一为「不是与心相应的／不是与心相杂的…法」句式，与 §4206–4208 一致。
- **`citta` 作二法项目名时译法摇摆**：§4199 `Nocittaṃ` 译「不是心」、`citto` 译「是心的」。`citto kusalo dhammo` 此处 `citta-` 是二法范畴名（心／非心），译「是心的善法」与 §4200「是心所的善法」尚可并列，但 §4199 原文作 `No-cittaṃ`（`no` 而非 `na`），译文未体现与其余 `na-` 的差别，建议或统一或在术语表登记理由。
- **首次出现夹注巴利原词的规则执行不全**（`style.md` 二）：有夹注的是 saññojana / gantha / ogha / yoga / nīvaraṇa / parāmāsa / sārammaṇa / cetasika / cittasaṃsaṭṭha / cittasamuṭṭhāna / cittasahabhū / cittānuparivattī / ajjhattika / upādāna / kilesa；**漏夹注**的同级项目词有 §4180 `sāsava`「有漏」、`anāsava`「无漏」（仅 `āsava` 有夹注）、§4199 `citta`「心」、§4201 `cittasampayutta`「与心相应」、§4210 `noupādā`「非所造」、§4211 `anupādinna`「非所执受」。同一 chunk 内同类术语应一致处理。
- **章节标题的译法体例不一致**：§4184「漏不相应·有漏二法与善三法」、§4188「结等六聚与善三法」、§4195「大中间诸二法与善三法」、§4212「取二法等与善三法」、§4214「烦恼二法等与善三法」——`-ādi` 一处译「等」在前（「结等六聚」），两处译「等」在后（「取二法等」）。建议统一为「取等二法」「烦恼等二法」或统一为「…二法等」。

## §4180 句 72-4180-2-19

- **问题**：术语/逻辑 — `Naāsavañceva naanāsavañca` 译「既不是漏（āsava）也不是无漏」尚可，但 `sāsavo ceva noāsavo ca` 译「是有漏而不是漏的」把 `ceva…ca`（既…又…）译成了转折「而」。原文是并列双重限定（既是有漏、又是非漏），不是转折。
- **建议**：改为「生起既是有漏又不是漏的善法」。同一问题见 §4182（`sāsavo ceva no ca āsavo` 译「是有漏而不是漏的」）。
- **问题**：标题层 — 本段译文开头保留了阿拉伯数字编号「20.」，与 §4179 的「17-1.」并存，体例上没问题；但 §4184 标题编号为「19-1.」而其内容段编号为「21.」，§4179 标题「17-1.」对应内容「20.」——编号跳号（17-1 → 19-1）是原文如此还是 OCR 问题，无法从本 chunk 判定。
- **建议**：记入待查，不要擅改（见下「OCR / 原文疑问」）。

## §4181 句 72-4181-2-18

- **问题**：一致性 — `āsavo ceva sāsavo ca` 译「既是漏又是有漏的」，此处「既…又…」处理正确；与 §4180 同结构却译成「而」，自相矛盾。
- **建议**：以本句为准回改 §4180、§4182。

## §4185 句 72-4185-2-17 / 18-29

- **问题**：逻辑可疑 — 前句 `āsavavippayuttaṃ naanāsavaṃ` 的所缘法既「与漏不相应」又「不是无漏」，生起的果法却是 `anāsavo`「无漏」；后句同样的缘生起 `sāsavo`「有漏」。两句缘支完全相同（逐词一致），果支相反。这在 Paccanīya 门里可能正是原文设计（否定缘支下列举正反两果），但也可能前句缘支应为 `nasāsavaṃ`（对照 §4187 前句即作 `nasāsavaṃ`）。
- **建议**：译文照原文直译无误，但应在报告中标出；若有义注或别本可核，确认 §4185 前句缘支是否为 `nasāsavaṃ` 之讹。译文本身不改。

## §4187 句 72-4187-2-13 / 14-25

- **问题**：准确性 — 两句缘支分别为 `nasāsavaṃ`（不是有漏）与 `naanāsavaṃ`（不是无漏），译文已正确区分；但两句果支完全相同（`āsavavippayutto sāsavo abyākato`），译文也完全相同，逐字重复。这是原文结构所致，无需改。
- **建议**：无需修改，仅作确认记录。

## §4199 句 72-4199-2-27

- **问题**：风格（文言）— 括注内「在“不是不善”的情形下有三句」尚属现代汉语，但 `Saṃkhittaṃ` 译「此处略说」用了文言单音节词「略」加「此处」。对照 `style.md` 禁例，「此中」类属禁用。
- **建议**：改为「（以下省略。）」或「（此处从简。）」中的前者；更贴近原意可作「（省略。）」。
- **问题**：术语 — `Naakusale` / `Naabyākate` 是处格（locative），表示「在『不是不善』这一项下」，译文「在…的情形下」可接受，但与其余各段统一使用的「项下」（`hetuyā` 译「因缘项下」）体例不一。
- **建议**：统一为「“不是不善”项下有三句。“不是无记”项下有三句。」

## §4210 句 72-4210-2-14

- **问题**：准确性 — `Nanoupādā nakusalaṃ dhammaṃ paccayā noupādā kusalo dhammo`：`upādā` 是「所造（色）」范畴，`no-upādā` 为「非所造」，前面再加 `na-` 为双重否定。译文「缘不是“非所造”、并且不是善的法，生起是“非所造”的善法」在形式上对应，但双重否定 `na-no-upādā` 是否该读作「不是非所造的」（即「是所造的」）须有依据；译文取字面直译。
- **建议**：保留直译，但在译文或报告中标明这是 Paccanīya 门的双重否定形式，不要让读者误以为与果支矛盾。**另：引号使用违规** — 本句用了全角双引号 `“非所造”`，符合 `style.md`；确认无 ASCII 引号。无需改动引号。
- **问题**：夹注缺失 — `upādā` / `noupādā` 作为二法项目名首次出现，未夹注巴利原词。
- **建议**：首次出现处补作「非所造（no upādā）」。

## §4211 句 72-4211-2-15

- **问题**：同 §4210 — `Naanupādinnaṃ` 为 `na + an-upādinna` 双重否定，译「不是“非所执受”」字面对应，但 `anupādinna` 的传统译法通常作「非所执受」或「不被执取」，术语表未登记。
- **建议**：首次出现补夹注「非所执受（anupādinna）」，并将 `upādinna` / `anupādinna` 补入 `knowledge/terms.md` 定案。

## §4196 句 72-4196-2-14 / §4197 / §4198

- **问题**：一致性 — §4196 `sārammaṇo kusalo dhammo` 译「生起有所缘的善法」，§4198 `anārammaṇo abyākato dhammo` 译「生起无所缘的无记法」；而同类范畴词在别处（§4189 起）一律译「生起是结的…」「生起是缚的…」，此处省了「是」。
- **建议**：这里省「是」反而更自然，建议反向统一——把 §4189–4194、§4199、§4200、§4209、§4213、§4215 的「生起是结的不善法」等改为「生起作为结的不善法」或「生起是结的不善法」择一，全 chunk 一致。至少不要同一结构两种处理。

## 存疑处（不在译文留标记，列此）

- `paccayā` 与 `paṭicca` 的译法分工未定 → 需定案并补入 `knowledge/terms.md`。
- `saññojana`「结」/ `gantha`「缚」/ `ogha`「流」/ `yoga`「轭」/ `nīvaraṇa`「盖」/ `parāmāsa`「执取」六聚（chagocchaka）译名均未登记在 `term-glossary.jsonl`。其中 `nīvaraṇa` 传统汉译多作「盖」或「障」，`yoga` 作「轭」或「系」，`parāmāsa` 作「执取」或「现贪」，分歧较大。
- §4199 `Nocittaṃ` 的 `no` 与他处 `na` 之别，是原文体例还是讹误，未能判定。
- §4206–4208 的长复合词（`cittasaṃsaṭṭhasamuṭṭhāna-sahabhū` / `-ānuparivattī`）内部并列关系，译文作「与心相杂、由心等起并与心俱生」三项并列；但该复合词也可读作「与〔与心相杂并由心等起者〕俱生」。需义注核实后定案。
