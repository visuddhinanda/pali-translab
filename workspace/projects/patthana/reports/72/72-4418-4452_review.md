## 跨段一致性

1. **计数句的「有」字不统一**（高频、必改）
   - §4419–4438：`hetuyā tīṇi` → 「因缘中**有**三种」
   - §4439：`Hetuyā ekaṃ` → 「因缘中**有**一种」
   - §4443：`Nahetuyā ekaṃ , naārammaṇe tīṇi …` → 「非因缘中一种，非所缘缘中三种」（无「有」）
   - §4449：`Hetuyā dve , adhipatiyā dve …` → 「因缘中二种」（无「有」）
   - §4436/4437/4442：`Ekaṃ` → 「一种。」
   → 同一公式三种写法。建议全 chunk 统一为无「有」的紧凑式「因缘中三种／一种／二种」，枚举列表与单句一致。

2. **`paccanīya` 一词两译**（必改）
   - §4440 标题 `Paccanīyaṃ` → 「**逆分**」
   - §4450 行内 `paccanīyampi` → 「**逆**」；§4451 `Dhammapaccanīyānulome` → 「法**逆顺**」
   → 一是同词不同译；二是「分」在本 chunk 已被 `vāra` 占用（§4445「俱生**分**、缘**分**、依**分**」、§4446「问**分**」），`Paccanīyaṃ` 并非 vāra，译作「逆分」会让读者误以为它与「问分」同级。建议改为「**缘逆**」（此处标记的是 paccaya-paccanīya 段）或单作「**逆**」。

3. **`na-` 与 `a-` 两种否定的汉译对应未成体系**（建议，并登记进 `terms.md`）
   - `na-` 一律作「非」：非有寻／非有伺／非有诤／非决定／非出离
   - `a-` 则在「无」与「不」之间摆动：`avitakka` 无寻、`avicāra` 无伺、`araṇa` 无诤，但 `aniyyānika` **不**出离、`aniyata` **不**决定
   → 「无出离／无决定」确实不像现代汉语，摆动可以接受；但须明确写成规则（能搭「无」的用「无」，否则用「不」；`na-` 恒用「非」），否则下一章会再漂。**同时提醒**：§4433 的「非出离」与「不出离」在汉语里几乎无法分辨，读者无从知道这是两个不同的巴利形式——若 `terms.md` 不作约定，建议在章首加一次译注。

4. **两级计数的连接词**（低优先，倾向保留现状）
   §4444 `Hetupaccayā naārammaṇe tīṇi` → 「因缘**之下**，非所缘缘中三种」。单级计数用「…缘中」，两级用「…之下，…缘中」，区分是有意义的，建议保留并在 `knowledge/translation-rules.md` 记为固定句式，不要日后被「统一」掉。

5. 术语层面无漂移：`sanidassanasappaṭigha` 有见有对／`anidassanasappaṭigha` 无见有对／`anidassana-appaṭigha` 无见无对，全 chunk 一致且三者区分正确（§4438、§4439 的三分尤其正确）；`vāra` 恒作「分」，五分名目（俱生/缘/依/相杂/相应）正确。语体通篇为现代书面汉语，**未发现文言或半文半白**（「由于因缘而生起」「通过因缘成为…的缘」「应当详细展开」「就像…那样」「结束」均合格）。标点全角，`zh` 字段内无 ASCII 引号，符合 JSON 安全硬约束。
