## 一、首要问题：`na-` 否定算子与 duka 第二支译名撞车（系统性必改）

Paṭṭhāna 逆论（paccanīya）里有两层否定，译文把它们压成了同一个「非」，读者无从分辨：

- **第一层**：duka 本身的第二支，词内前缀 `no-` / `a-`（如 `nocitta`、`aparāmaṭṭha`、`anārammaṇa`）
- **第二层**：逆论加在支名上的否定 `na-`（如 `nacitta`、`naparāmaṭṭha`）

现译把两层都译「非」，于是同一个汉语词在本 chunk 内指两样东西：

| 句 id | 巴利 | 现译 | 实际所指 |
|---|---|---|---|
| 72-1247-2-16 | **No**parāmāsa | 非执取 | duka 支二 |
| 72-1250-2-16 | **na**parāmāso | 非执取 | 逆论否定支一 |
| 72-1248-2-16 | **na**parāmaṭṭha | 非被执取 | 逆论否定支一 |
| 72-1250-2-16 | na**a**parāmaṭṭha | 非**非**被执取 | 逆论否定「不被执取」 |
| 72-1264-2-12 | **na**citta | 非心 | 逆论否定支一 |
| 72-1264-13-20 | **na**(**no**citta) | 非非心 | 逆论否定支二 |
| 72-1269-2-12 / 13-20 | **na**cetasika / na(**a**cetasika) | 非心所 / 非非心所 | 同上 |

「非执取」既是 `noparāmāsa`（§1247）又是 `naparāmāsa`（§1250）；「非被执取」既是 `naparāmaṭṭha`（§1248）又是「非非被执取」里被否定的那个 `aparāmaṭṭha`。对一部全篇靠否定排列组合展开的论书来说，这不是风格问题，是**意思塌陷**。

反例可证此路可通：`anārammaṇa` 因为有现成独立译名「无所缘」，所以 §1259-13-20「非无所缘」毫不含糊。问题只出在没给第二支独立译名的那几个 duka。

**建议（必改）**——两条同时执行：

1. **给 duka 第二支固定独立译名**，不与 `na-` 的「非」共用字面：
   - `no parāmāsa` → 「无执取」（不再用「非执取」）
   - `aparāmaṭṭha` → 「不被执取」（不再用「非被执取」）
   - `acetasika` → 「非心所」、`nocitta` → 「非心」、`anārammaṇa` → 「无所缘」（这三个是既有标准译名，保留）
2. **逆论的 `na-` 一律译「非“X”」，用全角引号圈住被否定的支名**（符合 `style.md` 第五节，不属工作标记）：
   - `nacitta` → 非“心”；`nanocitta` → 非“非心”
   - `nacetasika` → 非“心所”；`naacetasika` → 非“非心所”
   - `naparāmaṭṭha` → 非“被执取”；`naaparāmaṭṭha` → 非“不被执取”
   - `naparāmāsa` → 非“执取”；`nanoparāmāsa` → 非“无执取”

改写示例（72-1264-13-20）：
> 现：缘非心之法，生起非非心之法，由因缘。
> 改：缘非“心”之法，生起非“非心”之法，由因缘。

改写示例（72-1250-2-16）：
> 现：缘非执取而又非非被执取之法，生起非执取而又非非被执取之法，由因缘。
> 改：缘非“执取”而又非“不被执取”之法，生起非“执取”而又非“不被执取”之法，由因缘。

这一改动波及 §1247–1255、§1264–1266、§1269–1271、§1274 全部句子，属 revise 步的统一批改，不宜逐句零散处理。

## 二、跨段一致性

- **`No-` 与 `Na-` 前缀**：§1243「Nooghaṃ / noyogaṃ」、§1247「Noparāmāsaṃ」用 `No-`，§1248 起一律 `Na-`。译文全作「非」，差别消失 → 见上节，按 `no-`=「无…」/`na-`=「非“…”」区分。
- **duka／gocchaka 标题编号格式不统一**：§1242「32—49。」、§1246「50—54。」用句号收尾，而 §1258「55、有所缘二法」、§1263「56、心二法」、§1268、§1273 用顿号接标题 → 建议统一为顿号式「32—49、暴流等诸二法」（编号与标题虽分属两条 row，译文仍可在前一条末尾用「、」）。
- **巴利夹注标准不统一**：`ogha`／`yoga`／`āsava`／`nīvaraṇa`／`saññojana`／`parāmāsa` 首现都夹注了巴利，但 §1258「有所缘二法」(`sārammaṇa`)、§1273「与心相应二法」(`cittasampayutta`) 未夹注 → `citta`／`cetasika` 属常见术语可不注，`sārammaṇa` 建议补为「有所缘（sārammaṇa）二法」，与同级 gocchaka／duka 标题取齐。
- **`ceva … ca` 与无连词并列都译「而又」**：§1250「Naparāmāsañ**ceva** naaparāmaṭṭhañ**ca**」译「…而又…」；§1253「Parāmāsavippayuttaṃ naparāmaṭṭhaṃ」原文两词直接连用、无连词，也译「与执取不相应**而又**非被执取」。前者是第四 duka 的复合支名（「既…又…」），后者是第五 duka 的偏正结构（「与执取不相应**的**非被执取之法」）→ 建议 §1253-2-14／15-24／25-41、§1254、§1255 一律改为「与执取不相应的非“被执取”之法」，把「而又」留给 `ceva…ca`。
- **术语一致项（无问题，已核）**：`gocchaka`=聚、`niṭṭhitaṃ`=完毕、`saṃkhittaṃ`=略说、`vitthāro`=详说、`…pe…`=「……中略……」、`hetupaccayā`=「由因缘」、`(3)/(1)`=「（三）／（一）」、`āmasana`=「处理方式」（§1243/§1244 一致）——全 chunk 统一。
- **语体**：未发现文言虚词、文言句式或单音节文言词；标点全角、无 ASCII 引号，符合 `style.md`。**唯一需全局决断的体例**见第四节。

## 三、§ 逐句问题

### §1250 句 72-1250-2-16 / 17-29 / 30-50，§1251 句 72-1251-2-18，§1252 句 72-1252-2-23
- **问题**：原文疑问（记下，**不要改译**） — 这三段属第四 duka（`parāmāsa-parāmaṭṭha-duka`），其两支是 `parāmāso ceva parāmaṭṭho ca` / `parāmaṭṭho ceva no ca parāmāso`，**不含 `aparāmaṭṭha`**。因此逆论形式理应作 `naparāmaṭṭha`，而文本作 `na**a**parāmaṭṭha`。对照 §1253–1255 的第五 duka（`parāmāsavippayutta-aparāmaṭṭha-duka`），那里的 `naaparāmaṭṭha` 是正确的（支二本就含 `aparāmaṭṭha`）。疑为 VRI 文本串入第五 duka 的词形或 OCR 衍 `a`。
- **建议**：译文按字面保留现状（「非不被执取」，即上节改法），**不代原文改字**；取到义注后核对此处支名，确认后补入 `knowledge/known-issues.md` 第二节「OCR / 原文问题」。

### §1250 句 72-1250-30-50 与 §1251 句 72-1251-2-18
- **问题**：形式变体 — 同一概念原文一处作连写 `nanoparāmāso`，一处作分写 `nano ca parāmāso`。译文均作「非非执取」。
- **建议**：**译法保持一致即可，不必区分**（现状正确）；按第一节改为「非“无执取”」后同样统一。此条仅作记录。

### §1274 句 72-1274-19-31
- **问题**：可读性 — 「生起非与心不相应之法」是双重否定叠在一个长定语里，读者极易解成「并非与心不相应」=「与心相应」，而此处 `nacittavippayutta` 是逆论对第二支 `cittavippayutta`（与心不相应）的否定，正是这个意思却必须让读者看出否定层次。
- **建议**：「缘非“与心相应”之法，生起非“与心不相应”之法，由因缘——缘心而生起心等起的色。」

### §1274 句 72-1274-2-18 / 19-31
- **问题**：增译 — 例示句 `cittaṃ paṭicca cittasamuṭṭhānaṃ rūpaṃ` 原文无动词（承前省略 `uppajjati`），译文补「生起」。
- **建议**：可接受（省略回填，符合 `style.md`「语义必须时才补」）；若求严整可作「缘心，而有心等起的色」。**低优先，不改亦可。**

### §1275 句 72-1275-2-13
- **问题**：取义存疑 — ①`Paccanīyadukamattāni` 译「逆论的这些二法」，是把 `matta` 读作「仅、只是」后略去不译；`matta` 亦可读作「量、数」（「逆论诸二法之数」）。②`karotu` 是第三人称命令式（「应作、令作」），译「都作」丢了祈使语气。③`nava nava` 的叠用（distributive，「每一项各九」）译成「各处都…九个」尚可，但与 ②合起来语气偏陈述。
- **建议**：暂作「（逆论的这些二法，为补足“不可说”之法，应各作九个问题。）」；`matta` 的取义待义注核定后定案，同时把「逆论」(`paccanīya`) 登记进 `knowledge/terms.md`——本 chunk 仅此一见，无从查跨段一致性。

### §1262 句 72-1262-2-14、§1272 句 72-1272-2-14
- **问题**：措辞 — 「（一切处都详说。）」中「都详说」偏口语，与同类括注「（略说。）」的书面度不齐。
- **建议**：「（一切处均作详说。）」；§1267「（一切处都有五）」同步改为「（一切处均为五）」。**低优先。**

### §1262 / §1267 括注句号位置
- **问题**：格式 — §1262 作「（…详说。）」句号在括号内，§1267 作「（…都有五）。」句号在括号外。两者确系跟随原文 `( … .)` 与 `( … ).` 的点位。
- **建议**：中文排版宜统一为句号在括号外「（…）。」；此项若决定忠实于原文点位，则在 `knowledge/style.md` 注明体例，免得下一 chunk 又出现摇摆。

## 四、需全局决断的体例问题（不列为本 chunk 必改）

**「缘…之法」的「之」**：`style.md` 第一节明令禁用文言虚词「之」，严格执行则本 chunk 几乎每句都违规。但「缘 X 之法，生起 Y 之法」是 Paṭṭhāna 汉译的定型句式，改成现代结构（如「以非“心”的法为缘，生起非“心”的法」）会让每句暴涨三成且更难读。

**建议**：保留「缘…之法」为 Paṭṭhāna 专用句式**例外**，并把这条例外写进 `knowledge/style.md`（或项目 `methods/` 的 translate/review 文档），否则每轮 review 都会重复争论同一件事。这是体例决策，请用户定夺后再统一落实，**不要在本轮 revise 里自行改动**。
