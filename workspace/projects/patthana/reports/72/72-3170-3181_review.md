# Review — 72:3170-3181（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入）／父层对照 ❌（本层即本文 mūla，无父层）
> **缺 nissaya 与义注**，本次审查仅凭巴利原文与《发趣论》逆缘（paccanīya）体例的内部结构推断，词级格位与传统取义**未能对校**。下列「取义」类意见请在有 nissaya 时复核。

## 跨段一致性

1. **`na-` 与 `no-` 两种否定在译文中同形为「非」，是本 chunk 最严重的问题（必改，且需跨全书统一）**
   - 二法（duka）的两个成员是 `citta`（心）与 `nocitta`（非心）；逆缘法在结果项上再加否定前缀 `na-`。于是原文有三种形态，译文却只有两种写法：
     | 巴利 | 性质 | 现译 |
     |---|---|---|
     | `cittaṃ` | duka 成员一 | 心法 |
     | `nocittaṃ` | duka 成员二 | **非心**法（§3174-3175） |
     | `nacitto` | 对成员一的逆缘否定 | **非心**的法（§3171-3173） |
     | `nanocitto` | 对成员二的逆缘否定 | 非非心的法 |
   - 结果：§3171「非善、非心的法」与 §3174「善的非心法」中的「非心」指的是**完全不同的东西**——前者是「不属于心这一类」的否定判断，后者是 duka 的第二支本身。读者无从分辨，而这一分辨正是本节全部内容所在。
   - **建议**：duka 成员保留「心法／非心法」，逆缘前缀 `na-` 一律改作「不是…」：
     - `nakusalo nacitto dhammo` → 「不是善、不是心的法」
     - `naakusalo nanocitto dhammo` → 「不是不善、不是非心的法」
     - `Kusalaṃ nocittaṃ dhammaṃ paṭicca` → 「缘于善的非心法」（不变）
   - 此方案比元亨寺式「非善非非心之法」啰嗦，但本项目 `style.md` 以现代汉语可读性为硬指标，且该区分是正文语义本身，不是风格偏好。**请先定案再改，避免 chunk 之间体例分裂。**

2. **`nacetasika` 与 `acetasika` 同形为「非心所」**（§3178-3180 vs §3181）
   - §3181 `Acetasikāni nava` 的 `acetasika` 是**整个「非心所」分门**的略称（与 §3176 `Abyākatāni tīṇi` 同类，是分门标目），而 §3178-3180 的 `nacetasiko` 是逆缘否定。现译都作「非心所」。
   - **建议**：随上条一并处理——分门标目作「非心所〔门〕九。」，逆缘否定作「不是心所的法」。

3. **数字体例不一致（必改）**
   - §3170 `1-56.` → 「一—五六。」、§3177 `1-57.` → 「一—五七。」（转汉字 + 破折号）
   - §3171 `33.`、§3174 `34.`、§3178 `35.` → 保留阿拉伯数字
   - 两者同属结构编号，应取同一体例。**建议统一保留阿拉伯数字**（「1-56.」「33.」），因为它们是检索用的章节号而非行文中的数词；`Pañca`/`Tīṇi`/`terasa` 这类行文数词则继续用汉字（「五。」「十三。」）。

4. 术语译法本身在 chunk 内前后一致：`paṭicca`→「缘于」、`hetupaccayā`→「由于因缘而生起」、`uppajjati`→「生起」、`kusala/akusala/abyākata`→「善／不善／无记」、`citta/cetasika`→「心／心所」、`Hetuyā`→「因缘中」。✅

5. 语体检查：全 chunk 无文言虚词、无半文半白句式，无工作标记（候选／待定／问号）。✅

## §3170 句 72-3170-2-3
- **问题**：体例 — 「一—五六。」与后文「33.」「34.」「35.」编号体例冲突（见跨段一致性第 3 条）。
- **建议**：改回 `1-56.`，与 §3177 的 `1-57.` 一并处理。

## §3171 句 72-3171-2-14 / 15-24 / 25-34（及 §3172、§3173 全部同型句）
- **问题**：取义歧义 — 「非善、非心的法」中的「非心」实为 `nacitta`（逆缘否定），与 §3174「善的非心法」中的 `nocitta` 撞词（见跨段一致性第 1 条）。
- **建议**：「缘于善的心法，不是善、不是心的法由于因缘而生起。」

## §3171 句 72-3171-35-48 / 49-62（及 §3172-32-46、47-61，§3173-22-35，§3178-36-49、50-63，§3179-33-46、47-60，§3180-22-36）
- **问题**：可读性 — 「非不善、非心的法与非无记、非心的法由于因缘而生起」一句中四个「非」加一个「与」，并列边界不清，读者容易把「非心的法与非无记」连读。
- **建议**：在「与」前补逗号并加「以及」标明并列层级，如「缘于善的心法，不是不善、不是心的法，以及不是无记、不是心的法，由于因缘而生起。」
- **问题（次要）**：原文 `dhammā uppajjanti` 为复数，与单数句 `dhammo uppajjati` 在译文中无区别。
- **建议**：复数句可作「两类法由于因缘而生起」或「…等法生起」，若决定不区分则无妨，但须全书一致。

## §3174 句 72-3174-2-14（及 15-24、25-38，§3175 全部同型句）
- **问题**：取义歧义 — 「非不善、非非心的法」三重否定，且「非非心」的内层「非心」与 §3171 的「非心」同形异指。
- **建议**：「缘于善的非心法，不是不善、不是非心的法由于因缘而生起。」——duka 成员用「非心法」，逆缘否定用「不是」，三重否定即化为两层，可读性明显改善。

## §3176 句 72-3176-2-4
- **问题**：标目 — 「无记三。」承自 `Abyākatāni tīṇi`，是「无记为缘的诸问共三」的分门小结，现译过简，与上文独立成句的「三。」（`Tīṇi`）混同。
- **建议**：「无记〔门〕三。」或「以无记为缘的，三。」并与 §3181「非心所九」取同一体例。

## §3181 句 72-3181-5-7
- **问题**：取义 + 同形 — `Acetasikāni nava` 是「非心所」分门的略称小结（该门内容省略，只留问数九），现译「非心所九。」既与 §3178-3180 的逆缘「非心所」撞词，也看不出这是**另起一门**的标目。
- **建议**：「非心所〔门〕九。」并与 §3176 统一。
- **附注**：§3176 的顺序是「无记三。因缘中九。」，§3181 是「因缘中十三。非心所九。」——原文顺序不同（前者分门小结在前、总计在后；后者总计在前、下一门略称在后），译文已如实跟随，✅ 不必改。
