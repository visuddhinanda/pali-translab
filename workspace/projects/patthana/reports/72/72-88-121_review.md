## 跨段一致性

1. **paṭicca / paccaya / paṭiccavāra 三者共用「缘」字，已造成术语碰撞（必改）**
   - 现状：`paṭicca`（§89,92,93,94,96,97,103–105,111,112,115–117）译「以…为缘」；`hetupaccayā` 译「由因缘而生起」；`paṭiccavārādi`（§100,120）与 `paṭiccavārasadisaṃ`（§106）译「缘分」；`paccayacatukkaṃ`（§88,101,121）译「缘四法」。
   - 问题：Paṭṭhāna 七分里 `paṭiccavāra` 与 `paccayavāra` 是**两个不同的分**（paṭicca / sahajāta / paccaya / nissaya / saṃsaṭṭha / sampayutta / pañhā）。把 `paṭiccavāra` 译成「缘分」，后文 `paccayavāra` 出现时必然撞名，读者无法分辨；§106「相应分也与缘分相同」尤其会被误读为「与 paccayavāra 相同」。
   - 建议：固定区分并登记进 `knowledge/terms.md`——
     - `paṭiccavāra` →「依分」（或「依缘分」），`paccayavāra` →「缘分」
     - `paṭicca`（动词性）→「依…」，如「依不善的染污而可染的法，不善的…法由因缘生起」；若保留「以…为缘」，则 `paṭiccavāra` 必须改名以避让
     - `paccayacatukkaṃ` →「缘的四法」或「四缘组」，与分名区隔
   - 这是本 chunk 唯一的结构性术语问题，且会扩散到全书，建议先定案再 revise。

2. **三法（ttika）名称的加字不一致（必改）**
   - §99 `Kusalattika-vitakkattikaṃ` →「善三法—有寻三法」
   - §119 `Kusalattika-pītittikaṃ` →「善三法—喜三法」
   - 问题：`vitakkattika` 是「寻三法」（三支为 savitakkasavicāra / avitakkavicāramatta / avitakkaavicāra），原文没有 `sa-`；`pītittika` 译「喜三法」反而对。两处同构却一处加「有」一处不加。
   - 建议：统一为 **「善三法—寻三法」**。

3. **`-vārepi` 系列公式句的句式前后不一（必改）**
   - 「在X分中」式：§91「在俱生分中……中略……在问分中」、§95、§98、§114
   - 裸列式：§106「俱生分……中略……相应分也与缘分相同」、§118「俱生分……中略……问分也都要详说」
   - 建议：全书统一为「在X分中……中略……在Y分中」，`-pi` 一律落在「也」上：
     §106 →「在俱生分中……中略……在相应分中也都与依分相同。」；§118 →「在俱生分中……中略……在问分中也都应详说。」

4. **`vitthāro` 与 `vitthāretabbaṃ` 未区分（建议改）**
   - 名词 `vitthāro`：§95、§114 → 「都要详说」
   - 未来被动分词 `vitthāretabbaṃ`：§98、§110、§118 → 同样「都要详说」
   - 建议：`vitthāretabbaṃ` →「应详说」，`vitthāro` →「详说如上／作详说」。这是 Paṭṭhāna 省略体例里有实际分工的两个词（一个是「此处即详说」，一个是「读者应自行展开」），宜在译文层面保留差别。

5. 一致且无须改动项（供确认）：`abyākata`→无记、`savitakkasavicāra`→有寻有伺、`avitakkavicāramatta`→无寻唯伺、`avitakkaavicāra`→无寻无伺、`ārammaṇe`→所缘缘、`avigate`→不离去缘、`hetuyā`→因缘、`… pe …`→……中略……、数词（ekaṃ/dve/tīṇi/pañca/nava 均核对无误）。标点全角，无 ASCII 引号，无工作标记——`style.md` 第五、七节合格。

## §89 句 72-89-2-18
- **问题**：术语存疑 — `saṃkiliṭṭhasaṃkilesika` 译「染污而可染」。`-ika` 后缀的所指（「作为染污之所缘」vs「能生染污」）须以义注为准，本次义注缺位无法核对；另 `saṃkiliṭṭha` 传统汉译多作「杂染」（南传大藏经作「杂染杂染法」），本译取「染污」自成一系但未登记。
- **建议**：暂不改动（全 chunk 内部一致）。待义注到位后核 `saṃkilesikā` 的释义，定案后把 `saṃkiliṭṭhasaṃkilesika` / `asaṃkiliṭṭhasaṃkilesika` / `asaṃkiliṭṭhaasaṃkilesika` 三支一并写入 `knowledge/terms.md`。此句及 §92–97 同族句的 `confidence` 应相应压低。
