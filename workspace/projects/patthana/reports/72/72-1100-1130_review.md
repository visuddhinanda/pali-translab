## 跨段一致性

- `paṭiccavāra` / `sahajātavāra` / `sampayuttavāra` / `pañhāvāra`：全 chunk 统一为「缘生分／俱生分／相应分／问分」→ 一致，无需改。
- `duka`：1106/1109/1113/1123/1130 统一作「二法」→ 一致。
- `hetuyā` / `ārammaṇe` / `adhipatiyā` / `avigate`：统一作「因缘／所缘缘／增上缘／不离去缘」→ 一致。
- `(3)` / `(2)`：统一作「（三）／（二）」→ 一致。
- **`-pi` 与 vāra 的格位处理前后不一**：§1119 `sahajātavārampi…sampayuttavārampi`（宾格+pi）译出了「也」；§1129 `sahajātavārepi…pañhāvārepi`（**处格**+pi）既没译出「也」，也没译出处格的「在…中」。两处句式本不相同，译文却被抹平成同一种。建议见下。
- **`hetupaccayā`（夺格，表「因为有因缘」）与 `hetupaccayena paccayo`（具格，表「以因缘的方式作缘」）都译成「由因缘」**，两种句法被合并。缘生分（§1101 等）作「由因缘」正确；问分（§1103、§1104、§1120、§1121）的「是…的缘，由因缘」读来像赘语，建议改为「以因缘为缘」或「…的因缘缘」。属全局性改法，建议与后续各 duka 一并定案后统一执行，不要只改本 chunk。
- **法相术语首次出现未夹注巴利原词**（`style.md` 第二节要求）：有为（saṅkhata）、有见（sanidassana）、有对（sappaṭigha）、有色（rūpī）、世间（lokiya）在 1106/1109/1113/1123/1130 各 duka 标题处首现，均无夹注。若前面 chunk 已夹注则不必重复，否则建议在标题处补上。
- 文言腔检查：全 chunk 未见禁例表中的文言虚词与句式。「乃至」「略说」「一切处」属《发趣论》定型译语，保留。

## 必改项一：`uppajjati` 译成及物的「生起 X 法」（系统性）

涉及句：`72-1101-2-13`、`72-1108-2-13`、`72-1111-2-13`、`72-1111-14-21`、`72-1111-22-38`、`72-1115-2-13`、`72-1115-14-21`、`72-1115-22-35`、`72-1116-2-11`、`72-1117-2-16`、`72-1125-2-13`、`72-1125-14-21`、`72-1125-22-35`、`72-1126-2-10`、`72-1126-11-18`、`72-1126-19-32`、`72-1127-2-10`、`72-1127-11-19`、`72-1127-20-37`

- **问题**：准确性（句法误读）—— `uppajjati` 是不及物动词，`naappaccayo dhammo` 等是**主格主语**，不是宾语。现译「缘非无缘法，**生起**非无缘法」在现代汉语里读作「（前者）产生（后者）」的及物结构，把主语读成了受事；`paṭicca` 的对象与 `uppajjati` 的主语关系被颠倒暗示。§1111-22-38 的 `uppajjanti` 为**复数**，主语是「非有见法与非无见法」两者，现译同样读成被产生的宾语。
- **建议**：主语前置，动词后置：
  - §1101 →「缘非无缘法，非无缘法生起，由因缘。」
  - §1111-22-38 →「缘非有见法，非有见法与非无见法生起，由因缘。（三）」
  - 其余各句同式类推。若嫌「X 法生起」句头过长，可作「缘 X 法，则有 Y 法生起」，但须全书统一，不要两式混用。

## 必改项二：`( Saṃkhittaṃ .` 与 `)` 被拆成两行，括号重复

涉及句：`72-1111-22-38` / `72-1111-39-39`、`72-1121-9-21` / `72-1121-22-22`、`72-1127-20-37` / `72-1127-38-38`

- **问题**：原文的左括号与右括号落在相邻两个 word 区间，前一句的巴利只有 `( Saṃkhittaṃ .`（无右括号），译文却补成了完整的「（略说。）」，后一句又单独译出「）」。连读即成「（略说。））」，多出一个右括号。
- **建议**：前句改为「（略说。」，右括号留给后一句；或前句收作「（略说。）」而后句置空——二选一，全书统一。考虑到坐标覆盖关系，推荐前者（按原文括号归属切分）。
- **对照**：§1102、§1105 的 `( Sabbattha vitthāro .)` 左右括号同在一行，现译「（一切处都详说。）」正确，不必动。

## §1129 句 72-1129-2-11

- **问题**：准确性（格位 + 漏译小词）—— `sahajātavāre**pi** … pañhāvāre**pi**` 是**处格 + pi**，意为「在俱生分中……在问分中**也**（同样如此）」。现译「（俱生分……乃至……问分，一切处都详说。）」既丢了处格的「在…中」，也丢了 `pi` 的「也」，与 §1119 对 `-pi` 的处理不一致（见跨段一致性）。
- **建议**：「（在俱生分中……乃至……在问分中，也都一切处详说。）」

## §1119 句 72-1119-2-10

- **问题**：一致性（与 §1129 的处理需同时定案）—— 本句 `sahajātavāra**ṃ**pi`（宾格）译作「俱生分……相应分**也**与缘生分相同」，译法本身正确；列出仅为提示与 §1129 一并统一「-pi」的呈现方式。
- **建议**：维持现译，§1129 按上条补齐即可。

## §1108 句 72-1108-14-20

- **问题**：清晰度（非错译）——「（与有缘二法相同。）」中的「有缘二法」是 duka 名（`sappaccayaduka`），读者可能误读为「有缘的两种法」。
- **建议**：若全书对 duka 采用「…二法」且标题处有夹注，可维持；否则作「（与有缘二法一节相同。）」或「（与有缘二法（sappaccaya-duka）相同。）」。
