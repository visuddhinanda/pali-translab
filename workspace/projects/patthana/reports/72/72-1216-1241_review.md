## 跨段一致性

### 1.（必查 · 跨章）否定词重载：「非系所系」「非系」各担两义

本 chunk 的译法在章内自洽，但两个关键词各被两种巴利形式共用，与本书顺说部分极可能冲突：

| 巴利 | 本 chunk 译法 | 隐含问题 |
|---|---|---|
| `ganthaniya` | （未出现，顺说部分为）系所系 | — |
| `aganthaniya` | 隐含为「非系所系」 | 与下一行撞车 |
| `naganthaniya` | 非系所系（§1217–1219、§1237–1239） | 与 `aganthaniya` 同形 |
| `naaganthaniya` | 非非系所系 | 只有在 `aganthaniya`=「非系所系」时才读得通 |
| `gantha` | 系 | — |
| `no ca gantho` | 隐含为「非系」 | 与下一行撞车 |
| `nagantho` | 非系（§1227 首句） | 与 `no ca gantho` 同形 |
| `na + no ca gantho` | 非非系 | 同上 |

即：译文同时用「非」对译 `na-` 与 `a-`／`no`，两层否定在字面上无法区分。章内靠位置还能读，但**与顺说部分（`aganthaniyā dhammā` 等）合并成书后，「非系所系」会指向两个相反的概念**。

- **建议**：先核对本书顺说段落已写入 channel 的译法；若顺说处 `aganthaniya` 已译「非系所系」，则本 chunk 必须改。推荐固定对应：`a-` → 「无」、`no` → 「非是」、`na-` → 「非」，即
  `aganthaniya`=无系所系 → `naaganthaniya`=**非无系所系**；`no ca gantho`=非是系 → `na+no ca gantho`=**非「非是系」**。
- **次选**（不动词形、仅消歧）：在多重否定处用全角引号分组，如 §1227 作「非“非系所系”且非“非系”」。
- 这是**跨章决策，不要在本 chunk 单独改**，应留到 harmonize 统一处理；同时把 `gantha`=系 / `ganthaniya`=系所系 / `ganthasampayutta`=系相应 / `ganthavippayutta`=系不相应 补登 `knowledge/terms.md`（目前 `term-glossary.jsonl` 完全没有系聚术语）。

### 2.（建议改）`vitthāra` 译「详说」与 `saṃkhitta`「略说」不成对

- §1225 / §1230 / §1235 / §1240：`Sabbattha vitthāro` → 「一切处都作详说」
- §1219 / §1224 / §1229 / §1234 / §1239：`Saṃkhittaṃ` → 「略说」
- **问题**：佛典惯例 `saṃkhitta` / `vitthāra` 是「略说 / **广说**」一对固定反义词，译成「略说 / 详说」丢掉了对举关系。
- **建议**：统一改为「一切处（皆）广说」，「略说」不动。全 chunk 五处，机械替换即可。
