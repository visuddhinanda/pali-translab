# Review — 72:1039-1068（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本段未注入）／义注 ❌（未注入）。本次仅有巴利原文与现有译文，**释义标准与词级基准均缺**，下列判断只能依据原文结构、《发趣论》固定句式与 `knowledge/style.md`；凡依赖传统释义定夺的条目已标「存疑」，须取到义注／nissaya 后复核。

## 跨段一致性

- **`paṭiccavāra`（必改）**：§1039 / §1054 标题译「缘相应分等」，§1046 又把 `sampayuttavāra` 译「相应分」，同一 chunk 内两个不同的 vāra 名撞车，读者无法分辨。`paṭiccavāra` 应为「缘分」（或「缘生分」），七分名建议固定为：缘分 / 俱生分 / 缘依分 / 依止分 / 杂分 / 相应分 / 问分。涉及 §1039-4-4、§1046-2-12、§1054-4-4。
- **数词量词体例（必改）**：§1042 作「一蕴 / 二蕴 / 三蕴」（无量词），§1057 作「一个大种 / 二个大种 / 三个大种」（有量词）。同一 chunk 同一句式应统一；建议随 §1042 作「一大种 / 两大种 / 三大种」。另「二个」非现代汉语常用形，须改「两个」或直接去量词。
- **`mahābhūta` 的「诸」字**：§1042「（直到大种）」、§1057「缘着一个大种」「缘着诸大种」三处对复数处理不一致。建议复数一律作「诸大种」，`yāva mahābhūtā` 作「（……直到诸大种为止）」。
- **计数词「三」/「三项」**：§1052「于因缘有三」vs §1058 / §1064「……三项」。同为 `tīṇi`，建议统一作「三项」。
- **`(3)` 与 `tīṇi` 的体例**：前者作「（三）」、后者作「三项」，源文确有区别，可保留，但建议在 `knowledge/terms.md` 登记此约定，避免后续分卷摇摆。
- **`sahagata` 与 `sampayutta` 合并（必改）**：§1057 把 `vicikicchāsahagataṃ`、`uddhaccasahagataṃ` 译「与疑相应的、与掉举相应的」，同段 `sampayuttakā khandhā` 也译「相应的诸蕴」；而 §1068 的品名正是 `hetusampayuttaduka`「因相应二法」。`sahagata` 建议改「与疑俱行的、与掉举俱行的」，把「相应」留给 `sampayutta`。

## §1045 句 72-1045-2-15（并及 §1052-2-24、§1060-2-16、§1066-2-15）

- **问题**：风格（文言虚词）— 「于因缘有九，于所缘缘有九……于不离去缘有九」。`style.md` 总原则禁用单音节文言虚词（之／其／乃／於…），`于…` 的处格直译属半文半白。
- **建议**：改为「因缘九项，所缘缘九项……不离去缘九项」，或「因缘：九项。所缘缘：九项。……不离去缘：九项。」四处同改。

## §1040 句 72-1040-2-2（并及 §1055-2-2）

- **问题**：术语存疑 — `Paccayacatukkaṃ` 译「缘四类」。`catukka` 在《发趣论》标题中通常指「四句」式的列举（此处下辖「因缘」与「因缘·所缘缘」两组），「类」字无依据。
- **建议**：暂作「缘四句」；取到义注后核定，并登记 `terms.md`。

## §1057 句 72-1057-2-41

- **问题**：句法（可能误读，必改待核）— `mahābhūte paṭicca cittasamuṭṭhānaṃ rūpaṃ kaṭattārūpaṃ upādārūpaṃ` 译成三项并列「心生色、业生色和所造色」。《发趣论》此定型句中 `upādārūpaṃ` 是中心语，`cittasamuṭṭhāna`／`kaṭattā` 是它的两个限定成分——即「心等起的所造色、业等起的所造色」，而非与所造色并列的第三项。按现译，读者会以为所造色是心生色、业生色之外的另一类色。
- **建议**：改「缘着诸大种，生起心生的所造色和业生的所造色。」存疑度：此判断依句式类推，须用 nissaya 的格助词（`kaṭattārūpaṃ` 是否与 `upādārūpaṃ` 同格同指）确认。
- **附**：`kaṭattārūpa` 当为 `katattārūpa`（`kammassa katattā`）之形，疑原文拼写讹误——**记下不改**，归入 `known-issues.md` 的 OCR／原文问题。

## §1057 句 72-1057-57-62

- **问题**：术语存疑 — `vatthuṃ` 译「所依处」。结生刹那的 `vatthu` 指心所依（hadayavatthu），传统汉译多作「所依」。
- **建议**：统一取一个译法并登记 `terms.md`；本 chunk 仅此一处，暂可保留「所依处」，但须与后续分卷一致。

## §1042 句 72-1042-57-75

- **问题**：标点 — 「在结生的刹那……略……缘着非因之法，非因之法和非非因之法以因缘而生起。（三）」省略号后直接接上新句，中间无句断，读起来像一句。
- **建议**：省略号后补句号或分隔：「在结生的刹那……略……。缘着非因之法，……」。

## §1065 句 72-1065-2-11

- **问题**：标点不一致 — 此处作「……的方式（以下省略）。」，而 §1044 / §1051 / §1059 作「（以下省略。）」（句号在括号内）。原文同为 `( saṃkhittaṃ .)`。
- **建议**：改「非有因之法作为非有因之法的缘，是以所缘缘的方式。（以下省略。）」
