## 必改 — §4730 / 4738 / 4742 / 4746 / 4750 / 4754 / 4758 / 4762 / 4766 / 4770（句 id 均为 `72-{para}-2-3`）

- **问题**：**误译 — 结构性误读，10 处**。`1-2.` / `1-3.` … `1-11.` 是「第一三法 × 第 n 三法」的**配对编号**，与紧随其后的标题「善三法－异熟三法」正好对应（1=kusalattika，2=vipākattika，3=upādinnattika…11=parittattika）。译文一律作「一至二、」「一至三、」…「一至十一、」，读成了**连续范围**。到 §4770「一至十一、善三法－小三法」矛盾最明显：标题只涉两个三法，却写成「一至十一」共十一个。另一证据是正文条目号自成一列（4.、5.、6.、7.…15.），与「1-2.」不同系，故「1-2.」不可能是条目区间。
- **建议**：改用与标题同形的连接号，`一至二、` → `一－二、`，以下类推（`一－三、`／`一－四、`／`一－五、`／`一－六、`／`一－七、`／`一－八、`／`一－九、`／`一－十、`／`一－十一、`）。全角连接号与标题行「善三法－异熟三法」的分隔符保持一致。

## §4744 句 `72-4744-2-14`

- **问题**：**原文疑问（勿改译文）** — 巴利条件项与结果项的三法成员不配对。本段属杂染三法第二支，条件是 `naasaṃkiliṭṭhasaṃkilesikaṃ`（非「未杂染而可被杂染」），按体例结果应为 `abyākato asaṃkiliṭṭhasaṃkilesiko`，但原文作 `asaṃkiliṭṭhaasaṃkilesiko`（第三支），而第三支已另立于 §4745。疑为 VRI 原文脱 `-saṃkilesika-` 一节或讹写。
- **建议**：译文**照原文直译（现状已忠实镜像，保留不动）**；此条记入 `knowledge/known-issues.md` 第二节「OCR / 原文问题」。**待义注／nissaya 核**：若 nissaya 的缅文释义给出 `asaṃkiliṭṭhasaṃkilesika`，即可确认为原文讹误。

## §4737 句 `72-4737-2-15`、§4757 句 `72-4757-2-18`、§4761 句 `72-4761-2-19`、§4765 句 `72-4765-2-14`、§4769 句 `72-4769-2-14`

- **问题**：**可读性（非误译）** — 逆论的「否定 + 内含双重否定」复合词叠成四重否定链，译文「非善非既非异熟亦非有异熟之法的法」「缘非善非以既不应以见断亦不应以修断者为因的法」连续五六个否定词无切分标记，一般读者无法判断「非」的辖域在哪里断开，有误读为「非善、非异熟」的风险（原文否定的是整个复合三法名）。语义本身翻对了。
- **建议**：给内层三法名加全角引号界定辖域，否定词只留最外一层。例：
  - §4737 → 缘非善、非“既非异熟亦非有异熟之法”的法，生起无记的“既非异熟亦非有异熟之法”的法
  - §4757 → 缘非善、非“既不应以见断亦不应以修断”的法，生起无记的“既不应以见断亦不应以修断”的法
  - §4761 → 缘非善、非“以既不应以见断亦不应以修断者为因”的法，…
  - §4765 → 缘非善、非“既不趋向积集亦不趋向损减”的法，…
  - §4769 → 缘非善、非“既非有学亦非无学”的法，…
  - 若采用，须**全 chunk 及后续 chunk 一致**（含 §4733、§4741、§4745 等双重否定处），不可只改几段。

## §4758 句 `72-4758-4-4`

- **问题**：**取词不对等（低优先）** — 标题 `Kusalattika-dassanahetuttikaṃ` 的缩略形是 `dassanahetu`（见因），译文作「见断因三法」，比缩略形多出「断」字；而同类缩略 §4754 `dassanattikaṃ` 译「见三法」并未展开为「见断三法」。两条标题口径不一。
- **建议**：统一为「善三法－见因三法」（与「见三法」平行），语义靠正文「以应以见断者为因」承担；或反向把 §4754 展开为「见断三法」。二者取一即可，**不要一处展开一处不展开**。

## §4739 句 `72-4739-2-18`

- **问题**：**措辞（低优先）** — `ārammaṇapaccayena paccayo` 译「以所缘缘成为缘」，「成为」在此是状态判断而非变化，略拗；且本 chunk 仅此一例，后续 chunk 遇 `paccayo` 极易漂移成「为缘」「是…的缘」。
- **建议**：定为「以所缘缘为缘」（现代汉语中「为缘」已是固定术语搭配，非文言虚用），并补入 `term-glossary.jsonl`：`paccayo`（谓语用法）→「为缘」、`ārammaṇapaccayena`→「以所缘缘」。

## 全局 — `hetupaccayā`（出现于 §4731-4737、4740-4741、4743-4745、4747-4749、4751-4753、4755-4757、4759-4761、4763-4765、4767-4769、4771-4773）

- **问题**：**措辞（低优先，全 chunk 统一，不构成一致性缺陷）** — `hetupaccayā` 是从格表原因，依附于 `uppajjati`；译「这是因缘」把原因状语转成了判断句，「这」的指代落点不明（易被读成「所生起的那个法是因缘」）。
