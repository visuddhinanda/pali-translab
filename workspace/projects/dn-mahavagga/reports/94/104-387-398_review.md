# Review — 104:387-398（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 被解释词与父层核对
逐一核对本层黑体被解释词与父层（book=94）译文，用字均逐字相同：
- 七识住 / 识住 / 二处 / 身体不同 / 想也不同 / 一部分天神 / 一部分堕苦处者 / 梵众天 / 初生的 / 光音天 — 全部一致，无问题。

## 跨段一致性
- “优多罗（Uttaramātā）”指代问题：§390 与 §395 均把 **Uttaramātā**（意为“优多罗之母”）译成“优多罗”本人（“鬼母优多罗夜叉女”“鬼母优多罗则是……”），两处译法虽彼此一致，但都把“某人之母”译成了“某人”，见下方问题条目。
- 术语“处”对应 āyatana 全篇一致（二处／处＝住处），无问题。
- “俱分解脱者”“慧解脱者”“须陀洹”等术语全篇一致，无问题。

## §390 句 104-390-93-111
- **问题**：准确性 — Uttaramātā yakkhinī 的 nissaya 明确释为“ဥတ္တရ၏ အမိဖြစ်သော … ယက္ခိနီ”（**优多罗的母亲**，那位夜叉女），而非以“优多罗”为其本名。译文“鬼母优多罗夜叉女”读来像是把“优多罗”当作她自己的名字，混淆了母子关系。
- **建议**：改译为“优多罗之母（夜叉女）”一类表述，明确“优多罗”是她儿子的名字，她本人无名或称“优多罗母”。

## §395 句 104-395-10-17
- **问题**：同上，"Uttaramātā pana bhagavato dhammaṃ sutvāva sotāpannā jātā" 译为“鬼母优多罗则是听闻世尊说法后，就成为须陀洹了”，延续了§390 的同一处误译，把“优多罗之母”译成了“优多罗”。
- **建议**：与 §390 一并改为“优多罗之母”，保持全篇一致。

## §394 句 104-394-2-21
- **问题**：准确性（次要）— “pisācayoniyā”译作“夜叉之胎”。Pisāca（食尸鬼/毗舍阇）与前文的 yakkhinī（夜叉女）并非同一类鬼众，径直译为“夜叉”混淆了两个不同的鬼类术语。
- **建议**：改译为“食尸鬼之胎”或音译“毗舍阇之胎”，与 yakkhinī 区分开来；若判定此处从宽等同处理，也应在报告中说明依据。

无其他必改项；风格（现代书面汉语）、句法核对（nissaya 格助词）、义注释义与本文对应关系检查均未发现问题。
