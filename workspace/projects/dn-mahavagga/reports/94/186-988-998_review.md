## 被解释词与父层核对（首要）

- §990 id 990-11-15：黑体“**牟尼**”对应父层 104-1125（`Pucchāmi muniṃ pahūtapaññaṃ`）译“具足广大智慧的牟尼”。父层原文该处译“我要问具足广大智慧的牟尼”，本层单独把“muniṃ”译“牟尼”——一致，无问题。
- §990 id 990-16-19：黑体“**具足广大智慧**”对应父层 104-1125 同句“具足广大智慧的牟尼”，逐字一致。
- §990 id 990-20-23：黑体“**已渡**”对应父层 104-1126（`Tiṇṇaṃ pāraṅgataṃ parinibbutaṃ ṭhitattaṃ`）译“渡到彼岸”，父层用的是“渡到”而非“已渡”，本层译“已渡”——**不一致**，应统一为父层的“渡到”或说明为何分开注释导致措辞不同（此处本层是拆开单字注释，可接受，但建议确认此类拆字注释是否要求逐字对应，若要求则改为“渡”）。
- §990 id 990-24-34：黑体“**到彼岸**”对应父层 104-1126“渡到彼岸”中的“彼岸”，父层是“渡到彼岸”整体表达，本层单独摘出译“到彼岸”，基本一致，可接受。
- §990 id 990-35-37：黑体“**已般涅槃**”对应父层 104-1126“已般涅槃”，逐字一致 ✅。
- §990 id 990-38-43：黑体“**安住不动**”对应父层 104-1126“安住不动”，逐字一致 ✅。
- §990 id 990-44-53：黑体“**离开家、舍弃诸欲**”对应父层 104-1127（`Nikkhamma gharā panujja kāme`）译“离开家、舍弃诸欲的比丘”，逐字一致 ✅。
- §990 id 990-54-74：黑体“**这样的比丘应当如何在世间正确地游行呢**”对应父层 104-1128“这样的比丘应当如何在世间正确地游行呢？”，逐字一致 ✅。
- §991 id 991-80-102：黑体“**依止山间洞穴而住的**”对应父层 104-1130（`Ye sitā girigabbharan`）译“依止山间洞穴而住的”，逐字一致 ✅；“**志向坚定**”“**心意专注**”分别对应父层 104-1130“志向坚定”“心意专注”，逐字一致 ✅。
- §988 id 988-2-65：文中提及 **pūrābhedasuttaṃ** 译“破前经”，与父层 104-1121“破前经”一致 ✅。

**必改项**：990-20-23 的“**已渡**”与父层“渡到”不一致，需按硬约束核实并统一（若父层定稿为“渡到彼岸”，此处单字注释宜改为“渡（到彼岸）”或类似写法，与父层用词一致）。

## 跨段一致性

- “**pucchāmi**”类的省察/提问动词：988 段多次用“省察”（如 988-66-81 的 manasākāsi 译“省察”），990-2-10 又将 **pucchāmi** 译为“我要问”，与父层 104-1121 的“想”“思量”体系不冲突，但注意 988 段与 989 段中“提问”“省察”交替出现，未见明显不统一，无需改。
- “**anupaṭipāṭiyā**”（依次）：991-54-57 译“依次”，997-15-24 又译“依次序”——轻微不统一，建议统一为“依次”。
- “辟支佛”译法在 988-119-139 中保持一致，无问题。
- 术语“阿罗汉道”（992-18-30）、“圣道”（992-31-36）用词前后一致，无问题。

## §988 句 988-2-65
