## 跨段一致性

- **`…ti attho` 的固定句式译法不统一**：同一 chunk 内，“…ti attho”（=这就是含义）在多处译成“**这就是含义**”（如 §822 id 34-41），但在另几处译成“**其含义是…**”（§822 id 46-53「其含义是证得神通的方法」、id 72-78「其含义是圆满成就、完成」、id 79-86「其含义是神的部类」、§823 id 79-87「其含义是最胜的」）。→ 建议统一为“这就是含义”一种句式（更贴近父层惯用译法，且避免下文提到的“其”这类偏文言代词）。
- **“之义”结构反复出现**（如“以成就之义”“以依止之义”“能作之义”“能作方法之义”等，见 §822 id 34-41/42-45/106-111，§823 id 95-169 多处）。此结构在父层 104-935-20-29 已存在（“以‘成就’之义为‘神’”），为保持与父层黑体对应不必强改父层已定稿部分；但本层自己新增的、非直接引自父层的同类表达（如“能作之义”“能作方法之义”，见 §823 id 95-169）建议按 `style.md` 改为更白话的“能作的意思”“能作的方法义”等，避免通篇“之义”堆叠显得文言化。
