# Review — 104:503-513（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／义注（本层即义注）✅／nissaya ✅（已随文提供，用作词级参考）／父层译文（book 94, 362-376）✅

## 跨段一致性

- **`Vajjīnaṃ paṭibāhāyā` 被解释词与父层不一致（必改）**：104-504-38-43 黑体词译为「**为了防御跋耆人**」，套用的是父层 94-363-176（"以防御跋耆人"）的措辞；但同一短语在父层 94-363-2-27 另译作「以断绝跋耆人的（财源）来路」，而且本条义注紧接的解释文字（`āyamukhapacchindanatthaṃ`）本身对应的正是「断绝…财源来路」这层意思，与「防御」并不同义。
  - 建议：黑体被解释词改为与 94-363-2-27 一致的「**为了断绝跋耆人的（财源）来路**」，使被解释词、译文正文与父层三者对齐；同时这也暴露了父层 94-363 两处译法本身不一致，建议一并反馈给父层统稿处理。
- 其余黑体被解释词（Sunidhavassakārā / Magadhamahāmattā / Pāṭaligāme nagaraṃ / Sahassevā / Vatthūni / Cittāni namanti nivesanāni māpetuṃ / Tāvatiṃsehi / Yāvatā ariyaṃ āyatanaṃ / Yāvatā vaṇippatho / Idaṃ agganagaraṃ / Puṭabhedanaṃ / Pubbaṇhasamayaṃ / Nivāsetvā / Pattacīvaramādāya / Sīlavantettha / Saññate / Tāsaṃ dakkhiṇamādiye / Pūjitā pūjayanti / Mānitā mānayanti / Tato naṃ / Orasaṃ / Bhadrāni passati）经比对均与父层译文逐字一致，无问题。
- 「苏尼陀」「跋沙迦罗」「波咤利村」「波咤利弗」等专名译法全 chunk 内一致，无问题。

## §504 句 104-504-16-29
- **问题**：措辞冗赘，非文言但表达不清——「即摩揭陀国王的大臣、大臣僚，或者说是……」中「大臣、大臣僚」并列重复、生造词感强。
- **建议**：改为「即摩揭陀国王的大臣、重臣，或者说是摩揭陀国境内的大臣……」。

## §506 句 104-506-68-80
- **问题**：数字翻译丢失关键信息。nissaya 明确给出「四座城门各十万（笔），共四十万（`cattāri satasahassāni`）；集会处一处十万（`ekaṃ satasahassaṃ`）；合计每日五十万」，但译文「四座城门每座各有一处，加上市集中一处，如此每天将会兴起五十万（笔交易）」把「各十万」这个量词丢掉，只留下「各有一处」，读者无法看出五十万是怎么算出来的，等于漏译了核心数字。
- **建议**：改为「此句表明，四座城门每座各有十万（笔交易），加上市集一处十万（笔），如此每天将会兴起五十万（笔交易）。」

## §508 句 104-508-58-85
- **问题**：轻微，非必改——「我们不如借此让人称此为城市的吉兆」语义略绕，"vadāpessāma"（我们将使人如此宣称）译得不够直接。
- **建议**：可改为「我们不如借此使人们都说这是城市的吉兆」，更贴合原意且更顺。

其余段落（504 其余句、505、507、509-513）经逐句核对，义注释义、nissaya 词法、被解释词对应关系、现代汉语语体均无问题。
