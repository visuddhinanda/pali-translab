# Review — 104:485-491（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 被解释词对齐核查（首要）

- `akhaṇḍāni / acchiddāni / asabalāni / akammāsāni / bhujissāni / viññupasatthāni / aparāmaṭṭhāni / samādhisaṃvattanikāni`（§488）与父层 94-334 译文「无缺、无穿、无杂、无染……自在……受智者称赞……不受执取……能导向禅定」逐一对照，**均逐字一致**，无问题。
- `takkarassa`（§490，"实行者"）与父层 94-335「实行者」一致，无问题。
- `iti sīlaṃ`（§491，"这就是戒"）与父层 94-337「这就是戒」一致，`sīlaparibhāvito…mahapphalo…mahānisaṃso`、`paññāparibhāvitaṃ cittaṃ sammadeva āsavehi vimuccati` 也与父层逐字一致，无问题。
- **`niyyānikā`（§490-13-15，译"能出离"）与父层 94-335 中该词的对应译法"能导向出离"不一致**——父层把 niyyānikā 融进"能导向出离、能使实行者……"这一整句，义注单独释此词时译成了"能出离"，少了"导向"二字。→ 建议改为「能导向出离」以与父层逐字对齐。
- **`sīlasāmaññagatā`（§489）译"戒行一致"、`diṭṭhisāmaññagatā`（§490）译"见解一致"，二者在父层（94-334/335）里从未以这一固定短语出现**，父层只把该词融入整句意译（"与同修梵行者一样受持这样的戒行/正见……无论在人前还是背后都保持一致"）。义注单独解释该词时新造了"戒行一致""见解一致"这两个术语性说法，与父层没有逐字对应点——**必改项**：需要与父层统一措辞（harmonize 步应回头核对），或至少在报告中留痕，避免读者对不上被解释词。

## 文言腔问题（必改，逐处列出）

1. **§104-485-2-8**："婆罗门帝须**之**难" — 文言虚词"之"作定语标记。改为「婆罗门帝须的灾难」。
2. **§104-485-92-116**："……**便**来到了兄弟村。" — "便"表"于是/随即"，属禁用文言虚词。改为「就来到了兄弟村」或「随即来到了兄弟村」。
3. **§104-486-73-109**："……说完**便**登上了路途。" — 同上，改为「说完就上路了」。
4. **§104-487-17-56**："……看着长老要走，**便**从树上下来……"；同段"让他做完**受食之事**并立下承诺" — "便"同上需改；"受食之事"中"之"为文言虚词，改为「让他把受食这件事做完，并让他立下承诺」或类似现代说法。

## §104-488-36-57

- **问题**：内容小瑕疵——"kāḷarattādīnaṃ aññataravaṇṇā"（黑、红等某种异色）被概括译为"异色斑纹"，丢失了"黑、红"这类具体颜色信息。
- **建议**：可考虑补出"如黑色、红色等异色斑纹"，与原文更贴合；若认为无关宏旨可保留现译法，但需在存疑处说明取舍。
