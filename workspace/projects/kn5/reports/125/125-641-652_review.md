# Review — 125:641-652（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层本文译文 ✅（book=159，§386-423）
> 本 chunk 本身就是义注层，所以没有更高一层的释义标准（复注 ṭīkā 未提供）。释义问题只能以巴利原文语法和 nissaya 为依据，凡涉及取义的结论都按「存疑」处理。

## 被解释词与父层对照

逐条核对了全部黑体被解释词，以下各条都与父层译文逐字相同：

- 拜火者婆罗豆婆遮婆罗门回答世尊说：“是的，先生。”
- 世尊这样说
- 易怒 / 怀恨 / 心怀恶意、抹杀他人恩德 / 见解错误 / 狡诈虚伪 / 应当知道他是贱民
- 一次出生的 / 两次出生的 / 伤害 / 对众生没有悲悯之心
- 摧毁 / 围困 / 村庄和城镇 / 被公认为压迫者
- 无论在村里还是在林中 / 别人所珍视的东西 / 他未经给予而偷偷拿走
- 借了债 / 被人催讨时就逃走 / 还说‘我不欠你的债’
- 贪图一点点财物 / 在路上行走的人 / 杀害后抢走那点财物
- 为了自己 / 为了别人 / 为了钱财 / 被传作证人 / 说谎
- 亲戚 / 朋友 / 妻子 / 私通 / 凭强力 / 两相情愿
- 母亲或父亲 / 年老体衰、青春已逝 / 有能力却不供养
- 岳母 / 动手打 / 激怒 / 用言语

**未发现必改项。**

有一处做法需要留意：§644 的「**凡是在这世上……生命**」用省略号把父层「凡是在这世上伤害生命的人」中不相邻的两段拼在一起。这样做可以接受，因为两段的字都取自父层原文。

## 跨段一致性

- **guṇa**：§642 正文译「长处」，而同句的被解释词 pāpamakkhī 在父层译作「……抹杀他人**恩德**」。读者会看不出两者是同一回事。
  - 建议：正文改为「抹杀、抹掉别人的恩德」。nissaya 作 ဂုဏ်ကျေးဇူး，「恩德」也有依据。
- **hanti / hanana**：§645 被解释词 hanti 依父层译「摧毁」，但同段的 hananaparirundhana 译成了「杀戮和围困」。hanana 就是 hanti 的动作名词，应当同译。
  - 建议：改为「由于这样的摧毁和围困」。
- **adinna（未经给予）**：§643 译「不与取」，§646 和父层 §405 用的是「未经给予而……拿走」。
  - 建议：§643 改为「杀生、未经给予而拿取等事」，或者直接写「杀生、偷盗等事」。
- **pāṇa**：父层 §398 作「伤害生命」。§644 的异读 pāṇāni hiṃsati 只是单复数不同，却译成「伤害众生」，读者会以为是另一句话。
  - 建议：异读处改为「伤害生命（pāṇāni hiṃsati）」，句 59-71 的复述也相应统一。
- **idha**：§644 被解释词作「在这世上」，紧接着的释文 yo idha 却译「在这里」。释文是在复述被解释词，应当同译。
  - 建议：改为「在这世上」。
- **ca（「和」字）**：§645 说「通过‘和’字」，这与父层 §401「村庄和城镇」对得上。但 §649 说「各处的‘和’字都是‘或者’的意思」，而父层 §413 已把 ca 译成「或者为了钱财」，那里根本没有「和」字，读者找不到这条注在注什么。
  - 建议：§649 写明是巴利词，例如「这里的 ca（和）字，在各处都表示‘或者’」。
- **语体**：本 chunk 总体是现代汉语。文言残留只有 §644「其生命」一处，见下文。

## §641 句 125-641-2-18
- **问题**：取义 / 比喻断裂。visīdantam**iva** 是说「好像要沉下去的」，与前半句 patiṭṭhaṃ labhissāmi（站稳脚跟）是一组比喻，nissaya 作「像溺水的人一样」。译文的「灰心丧气」丢了这个意象。另外，iva 只是比拟，译文却写成「那位婆罗门心想……」，把这个念头说成了实有的。tato（此后）也漏译了。
- **建议**：改为「此后，那位婆罗门就好像心想：‘这么深奥的法，我怎么能站稳脚跟呢？’快要沉下去一样。为了鼓励他，世尊就说：」

## §642 句 125-642-18-30
- **问题**：存疑，涉及父层。义注把 pāpamakkhī 拆成 pāpo（恶人）加 makkhī（抹杀者），父层的「心怀恶意」与「邪恶」对不太上。本层不能改被解释词，正文的「他既邪恶又……」本身没有错。
- **建议**：维持现状。在报告中记下这一点，供父层复审时参考。

## §642 句 125-642-43-50
- **问题**：术语。māyā 是法相术语，首次出现时应当夹注。
- **建议**：改为「具有欺诳（māyā）」。

## §642 句 125-642-51-76
- **问题 1**：存疑，涉及取义方向。vassanato / siñcanato / anvāssavanato 按语法可以理解成「他降下、浇灌这些低劣法」，也就是说他是施动者。nissaya 则读作 vasanato（栖居之处）、「被浇灌之处」，即他是这些法所在的地方。译文「在他身上降下、浇灌」偏向后一种理解。两种读法都说得通。
- **建议**：维持现状，压低 confidence。
- **问题 2**：存疑，涉及取义。brāhmaṇamatthake 译作「婆罗门的最上层」，nissaya 作 ပုဏ္ဏား မည်ကာမျှ၌（仅名为婆罗门），可能依据的是 -mattake 这个读法。
- **问题 3**：增补。「即使……也是贱民」超出了本句原文，与下一句 paramatthato vasalo eva 的内容重复。
- **建议**：压低 confidence。可以考虑改为「凡是具有这一切的人，即使生在婆罗门的上层……」，把判断留给下一句去说。

## §642 句 125-642-77-88
- **问题**：补出成分过宽。原文的意思是：婆罗门骂世尊是贱民，只是图自己心里痛快，被骂的人并不因此成为贱民。译文写成「随口骂别人是贱民」，泛化成了一般人。
- **建议**：点明是这位婆罗门。例如「至于这位婆罗门骂别人是贱民，只是图自己心里痛快，被骂的人并不因此就是贱民」。

## §642 句 125-642-89-117
- **问题 1**：词义。ādipada 是「第一个词」，指偈颂开头的 kodhano，不是「第一句」。正因为开头这个词是「易怒」，才说世尊一开口就制伏了婆罗门的愤怒。
- **建议**：改为「用第一个词」。
- **问题 2**：术语。puggalādhiṭṭhāna desanā 首次出现，应当夹注。
- **建议**：改为「以人为主的教说（puggalādhiṭṭhāna desanā）」。

## §644 句 125-644-33-39
- **问题**：语句不完整。「对于众生」悬空，idha 的译法也不一致（见上文「跨段一致性」）。
- **建议**：改为「是说凡是在这世上对众生〔下手〕的人」，或者「凡是在这世上的人，对众生」。

## §644 句 125-644-40-49
- **问题**：**必改**。「夺去**其**生命」中的「其」是文言虚词。
- **建议**：改为「夺去对方的生命」。

## §644 句 125-644-59-71
- **问题**：「这些类别的众生」读起来生硬。pāṇāni 的译法见上文「跨段一致性」。
- **建议**：改为「凡是在这世上伤害一次出生的或两次出生的种种生命」。

## §644 句 125-644-72-82
- **问题**：存疑，涉及句法。nissaya 把 etena 和 manasā 连读，作「以那颗（想杀的）心」。译文把 etena 理解成「这句话」，manasā 并入「心里」。两种读法都可以成立。
- **建议**：维持现状，在报告中记下这一分歧。

## §644 句 125-644-86-101
- **问题**：风格。「此后」重复出现，读起来累赘。
- **建议**：改为「从这以后的偈颂，我们不再说这么多，而是略过意思浅显的词，只解释还没解释过的词」。

## §645 句 125-645-26-34
- **问题**：hanana 译「杀戮」，与 hanti 的译法不一致（见上文「跨段一致性」）。
- **建议**：改为「这样的摧毁和围困」。

## §647 句 125-647-61-98
- **问题**：轻微。sakkhī 在 §649 是「证人」，这里译作「谁能证明」，前后的呼应弱了。
- **建议**：改为「谁是证人能证明是我借的？」，或者「有谁作证是我借的？」

## §649 句 125-649-21-24
- **问题**：译文所注的「和」字在父层找不到（见上文「跨段一致性」）。
- **建议**：改为「这里的 ca（和）字，在各处都表示‘或者’」。

## §651 句 125-651-2-20
- **问题**：术语。padaṭṭhāna 首次出现，应当夹注。
- **建议**：改为「近因（padaṭṭhāna）」。

## §652 句 125-652-2-8
- **问题**：表述。「也就是 sassuṃ」把巴利词直接放进句子，没有说明这是在注写法。
- **建议**：改为「**岳母**，原文 sasuṃ 就是 sassuṃ 的另一种写法」。
