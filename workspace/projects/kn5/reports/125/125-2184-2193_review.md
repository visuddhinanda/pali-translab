> **父层对照缺口**：父层 159:2650-2658 只覆盖《欲经》第 2–4 偈（Tassa ce kāmayānassa… / Yo kāme parivajjeti… / Khettaṃ vatthuṃ… Thiyo bandhū…）。缺两部分：

> - **第 5、6 偈**（abalā naṃ balīyanti… / tato naṃ dukkhamanveti… / tasmā jantu sadā sato… / te pahāya tare oghaṃ…）

> - §2191 的 abalā / balīyanti / parissayā / maddanti / tato / taṃ / dukkhaṃ / bhinnaṃ nāvaṃ / udakaṃ viya / anveti / tasmā / jantu / sadā sato / kāmāni parivajjaye / te / pahāya / tare oghaṃ / nāvaṃ / siñcitvā / pāragū

## 跨段一致性
- **abhibhūta / balīyanti / sahanti 译词互撞**：
  - sokābhibhūta 在 §2186 句 64-83、§2187 句 129-150 译“被忧伤**压倒**”。
  - §2191 句 5-61 的 balīyanti（黑体）也译“**压倒**”，sahanti 译“制伏”。
  - §2191 句 62-91 的 abhibhūtaṃ 又译“制伏”。
  - 结果是一个汉语词对应两个巴利词，读者无法分辨。
  - 建议：balīyanti 保持“压倒”（黑体，待父层核），sahanti 保持“制伏”，§2191 句 62-91 的 abhibhūtaṃ 改为“被……所困”之类，不与上面两词重复。
- **sampajjati / vipajjati 这一对**：
  - §2187 句 177-192 的 vipanne / sampanne 译“庄稼毁了 / 庄稼丰收了”。
  - 紧接着 §2187 句 193-209 的 sampajjanti / vipajjanti 译“成功 / 失败”。
  - 这两句是同一对词，而且后句（hi）正是前句的理由，译法断开就看不出论证关系。
  - 建议两句用同一对词，例如“兴盛 / 败坏”或“圆满 / 毁坏”。
- **parivajjeti / parivajjento**：§2191 句 92-106 同一句里，黑体 parivajjaye 译“远离”，非黑体 parivajjento 译“舍离”。§2190 的 parivajjeti 也是“远离”。建议统一为“远离”。
- **pāra**：§2191 句 119-158 里 pāragū 译“到达彼岸”，用来解释它的 pāraṃ gaccheyya 却译“抵达对岸”。义注是在用 pāraṃ gaccheyya 释 pāragū，两处换词会让解释关系变模糊。建议统一为“彼岸”。
- **法相术语夹注不统一**：
  - 只有“沙门（samaṇa）”按 style.md 在首次出现时夹注了巴利原词。
  - 以下首次出现都没有夹注：近依 upanissaya（§2186）、事欲 vatthukāma（§2188）、镇伏 vikkhambhana／断除 samuccheda（§2190）、身至念 kāyagatāsati、烦恼欲 kilesakāma（§2191 句 92-106）、暴流 ogha（§2191 句 107-118）、无余依涅槃界 anupādisesā nibbānadhātu（§2191 句 119-158）。
  - 建议首次出现时补上夹注。

## §2186 句 125-2186-2-12
- **问题**：被解释词，待核。“以‘对**欲乐**的**渴求**’开头”用“对……的”把分词 kāmayamānassa（“渴求着……的人”）改成了名词短语，和本偈原文的句式不符。父层首偈的译文未提供，无法逐字比对。
- **建议**：补取首偈父层译文，按原句照录，例如“以‘**渴求****欲乐**……’开头的”，具体以父层原句为准。§2188 中的 **欲乐** / **渴求** 也要一并核对。

## §2186 句 125-2186-46-63
- **问题**：术语。“近依”是法相术语，首次出现没有夹注。
- **建议**：改为“近依（upanissaya）”。

## §2186 句 125-2186-101-125
- **问题**：取义。saṅgaṇhāmi 译“接近他”，偏弱。nissaya 作 `သံဂဏှာမိ= သင်္ဂြိုဟ်တော်မူအံ့`，意思是关照、摄受。这里是佛陀有意先结善缘，好让对方日后肯听教诲，“接近”没有表达出这层意思。
- **建议**：改为“关照他”或“摄受他”。

## §2187 句 125-2187-177-192
- **问题**：译窄。vipanne / sampanne 是泛说“失败时 / 圆满时”。下句用 Kāmā hi nāma… 把它推广到一切欲乐。译文加了“庄稼”二字，把普遍的教诲缩成了只针对这块田。
- **建议**：去掉“庄稼”，改为“婆罗门，事情败坏时不应当忧愁，圆满时也不应当欢喜”，用词与下句保持一致（见跨段一致性）。

## §2189 句 125-2189-2-17
- **问题 1**：格式，必改。“**如果这个渴求欲乐**的：”中，“的”落在黑体外、冒号前，和全 chunk 的“**被解释词**：释义”体例不一致，读起来也不通。黑体部分与父层“如果这个渴求欲乐”逐字一致，这一点没问题。
- **建议 1**：删去“的”，改为“**如果这个渴求欲乐**：……”。
- **问题 2**：取义，存疑。kāmena vā yāyamānassa 是对 kāmayāna 的第二种析解：以欲为乘、被欲载着走。nissaya 把这里的 kāmena 释为 `လောဘဖြင့်`（以贪），也就是烦恼欲。译文“被欲乐驱使着前行”把它当成了事欲。
- **建议 2**：改为“或者是被贪欲驱使着前行”。另外，父层“渴求欲乐”只对应第一种析解，第二解在译文上看不出与“乘”字的联系。这一点记作父层存疑，本层不改黑体。

## §2189 句 125-2189-36-45
- **问题**：语句。“被铁箭等箭射中”中“箭”字重复，读起来别扭。黑体部分与父层“就会像被箭射中一样痛苦”逐字一致。
- **建议**：改为“就像被铁制等的箭射中一样受折磨”。

## §2190 句 125-2190-24-38
- **问题**：语句，建议改。“**他**这位比丘”是同位语，直接相连读不顺。黑体 **他** / **保持正念** / **就能超越** / **世间** / **贪着** 都与父层逐字一致。
- **建议**：改为“**他**——这位比丘——**保持正念**，**就能超越**……”。

## §2191 句 125-2191-5-61
- **问题**：父层存疑，仅记录，本层不改。黑体 **谁** / **田地** / **宅地** / **金子** / **牛马** / **妇女** / **亲属** / **种种欲乐** / **贪求** 都与父层逐字一致。但**义注**：kahāpaṇasaṅkhātaṃ hiraññaṃ，把 hirañña 释为迦哈巴那（钱币）。父层译“金子”，与义注释义不合。另外父层的 dāsaporisaṃ（奴仆和雇工）义注没有解释，本层也没有补，这样处理是忠实的。
- **建议**：本层保持“金子”，保证逐字一致。在父层的 review 中提出 hirañña 的译法问题；父层改定后，本层同步修改。

## §2191 句 125-2191-62-91
- **问题**：取义。nissaya 把 tato 释为 `ထိုကြောင့်`（因此），是因果关系。译文“**于是**”只表示先后。另外 abhibhūtaṃ 译“制伏”，与 sahanti 撞词（见跨段一致性）。
- **建议**：tato 改为“**因此**”，最终以父层第 5 偈的译文为准。abhibhūtaṃ 改为“被不明显的危难所困的**这个人**”。

## §2191 句 125-2191-92-106
- **问题**：取义，存疑。**义注**在这里明说要远离的是“依于色等事欲的一切烦恼欲”。nissaya 把 kāmāni 释为 `နှစ်ပါးသောကာမ`（两种欲），即事欲与烦恼欲。“**远离欲乐**”的“欲乐”偏向事欲，读者容易看不出这里也包括烦恼欲。§2191 句 107-118 的 te kāme 同样如此，nissaya 释为 `ကိလေသာကာမ`。
- **建议**：黑体要跟随父层，本层不能改。这一点作为 kāma 全书译法的存疑项提交统稿和术语讨论。非黑体“舍离”改为“远离”。

## §2191 句 125-2191-107-118
- **问题**：原文异文，仅记录。nissaya 起首作 `ဧကန္တေန`（一定地），对应 ekantena，而 pali 原文作 Evaṃ。疑为 nissaya 底本的异读，译文按 pali 原文译出，没有问题。
- **建议**：不改，记入 known-issues 的原文问题一节。
