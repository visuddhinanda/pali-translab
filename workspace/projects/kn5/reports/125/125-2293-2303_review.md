> **父层对照的问题（工具链，需先修）**：义注的偈号比父层本文大 1。例如义注 `832. … te vādakāmā` 对应父层 `831.`（2838–2839），义注 `839-40. vivādayanti` 对应父层 `838.`（2860）。照这个偏移推算：
> - 以下父层段落**没有注入**，所以对应的被解释词**无法核对**：父层 830（对应 2293）、836（对应 2298 的 `yā uṇṇatī` / `mānātimānaṃ` / `vighātabhūmi`）、837（对应 2299 全段）、839（对应 2300 的 `visenikatvā` / `kiṃ labhetho` / `pasūra` / `yesīdha natthi`）、840（对应 2301 全段）。
> - 注入的父层 2869–2872（九、摩犍提经 841）**配错了**。义注 2301 的「841.」注的是波须罗经最后一偈（父层 840：`pavitakkamāgamā … dhonena yugaṃ samāgamā …`），不是摩犍提经。看起来 plan_scan / pipeline_batch 是按偈号数字配的父层，应改为按 `cs_para` 对齐或按被解释词匹配。
> - 上述各处的黑体，harmonize 时必须补上父层再逐字核对一次。下文标「待核」的就是这些。

## 跨段一致性
- **sampayātave / sampayātuṃ**：§2301 黑体译「并驾齐驱」，紧接的释文用同一个动词 sampayātuṃ，却译成「同行」。义注是在复述被解释词，两处应该统一。建议释文改为「连一步也无法与他并驾齐驱」。
- **para**：§2295-80-85 黑体「伺机寻找**对方**的破绽」，释文 parassa 却译「别人」。建议统一为「对方」。
- **偈号格式**：§2294–2297 用「832.」（半角点、不展开），§2298 / §2300 用「836-837。」「839-840。」（全角句号、展开）。建议全书统一一种，按 pali 原样的「836-7.」或统一展开都可以，但不要混用。
- **sacca**：§2293 paccekasacca 译「各自的**真理**」，父层 2860 的 saccaṃ 译「真实」。语境不同，可以保留，但 harmonize 时应确认 paccekasacca 在父层 830 的译法（待核）。

## §2293 句 125-2293-2-20 / 125-2293-21-51
- **问题**：被解释词待核。idheva suddhī iti vādayanti、nāññesu dhammesu visuddhimāhu、nissitā、subhaṃ vadānā、puthū、paccekasaccesu、niviṭṭhā 都引自父层 830，但父层 830 未注入。
- **问题**（21-51，句法）：原文只有一个主语 puthū samaṇabrāhmaṇā，nissitā / vadānā hutvā / niviṭṭhā 都是它的谓语。译文先说「他们**依附**…」，再另起「**众多**沙门婆罗门就**执着**…」，读起来像两拨人。另外 tattheva 按 nissaya 是「就在那位导师的学说里」（ထိုဆရာ၏အယူဝါဒ၌သာလျှင်），译成「就在那里」所指不清。
- **建议**：「既然如此，**众多**沙门婆罗门**依附**自己的导师等，就在导师的学说里说“这个论点是美好的”，这样**宣称美好**，**执着**于“世界是常住的”等**各自的真理**。」黑体字面等父层 830 补上后再对。

## §2294 句 125-2294-51-67
- **问题**：误读。kusalavādā paṇḍitavādā 是「自称善巧、自称智者」（nissaya：လိမ္မာကုန်သောသူတို့ဟုဆိုကုန်၏ 「说自己是善巧的人」），与父层「自称善巧」同义。译文「说善巧之论的人、说智者之论的人」把 vāda 当成了「论」，意思偏了，「之论」也带文言腔。
- **建议**：「抱着“我们是善巧的人、是智者”这样的想法」。

## §2295 句 125-2295-19-25
- **问题**：文言。「争论**之**言」。
- **建议**：「热衷于争论的言谈的人」，或直接写「热衷于争论的人」。

## §2296 句 125-2296-2-17
- **问题**：语序别扭。「而且还有“他的论点”这首偈」容易读成偈本身是附加的。apica kho pana 承接的是「不只发怒，还会怎样」。
- **建议**：「他不只是发怒而已，下面“**他的论点**”这首偈说的就是这一点。」

## §2298 句 125-2298-5-52
- **黑体核对**：或者 / 在集会中 / 论点 / 在那里 / 受到了称赞 / 他因为 / 欢喜 / 得意，与父层 2851–2852 逐字一致 ✅。
- **问题 1**（误读）：‘‘sundaro ayan’’ 中的 sundaro 是阳性，不可能修饰阴性的 diṭṭhi。nissaya 把 ayaṃ 理解为「这份所得」（ဤလာဘ်ရခြင်းသည်）；从语境看，更自然的理解是指这个人。译成「这个**见解**真好」于语法不合，和后面的「凭着见解」也重复。
- **问题 2**（句法）：「所以即使得到了最大的利益，或者他……」中，「即使」引出的从句没有收尾，整句断裂。paramaṃ lābhaṃ labhantopi 的意思是：他所能得到的最大利益，也不过就是下面这样。
- **问题 3**（重复）：tuṭṭhiṃ 译「满心欢喜」，hasati 又按父层译「**欢喜**」，同一句出现两次「欢喜」。黑体不能动，tuṭṭhi 应换一种说法。
- **建议**：「第六首偈的意思是：正因为除了得到称赞之外再没有别的利益，所以他即使得到最大的利益，也不过是**在集会中**阐明那个**论点**，**在那里**因为见解而被人称赞“这个人真了不起”，**或者**说**受到了称赞**；于是**他因为**那个胜利的结果，或者心满意足，或者笑得露出牙齿，就**欢喜**起来，又因为慢心而**得意**。」黑体的位置可以再调，字面不能改。该句 confidence 宜压低：sundaro ayaṃ 的所指，nissaya 与文法推断不一致。

## §2298 句 125-2298-56-70
- **黑体核对**：得到了 / 结果 / 心中想要的 ✅。pali 的 **taṃ** 也是黑体，译文的「那个」没有加粗，建议补上。
- **待核**：「**那种得意**」（yā uṇṇatī）引自父层 836，未注入。

## §2298 句 125-2298-71-90
- **待核**：「**他却还在说慢和过慢**」，以及加了引号的「恼害的根源」（vighātabhūmi，也是父层 836 的偈中词），都要与父层 836 逐字对齐。

## §2299 句 125-2299-2-20
- **问题**：增译。asampaṭicchanto 是「不接受」，译文「**为了表明**不接受」多出了目的义。说偈的是世尊，tassa 指波须罗（nissaya：ထိုပသူရအား），译文的主语缺失。
- **建议**：「这样指出争论的过患之后，世尊现在不接受波须罗的论点，就说了“**勇士**”这首偈。」
- **待核**：本段全部黑体（勇士 / 靠国王的供给 / 咆哮着前来，寻求对手勇士 / 他在哪里，你就往哪里去 / 可以用来交战的东西，早先就已经没有了）引自父层 837，未注入。

## §2300 句 125-2300-33-39
- **问题**：语义残缺。偈文是 yesīdha natthi paramuggahītaṃ，即「那些在这里没有任何东西被执为至上的人」。黑体「那些在这里没有的人」单独读，会被理解成「不在这里的人」。释文「没有这些东西」里的「这些东西」也没有所指。
- **建议**：黑体等父层 839 补上后逐字照搬。释文补出所指：「就是那些在这里没有（任何执为至上的东西）的人」。
- **待核**：本段的摧毁了敌军 / 你能得到什么 / 波须罗啊（父层 839），以及 §2303 的经名「《波须罗经》」（父层经题未注入）。

## §2301 句 125-2301-2-19 / 20-29 / 30-51
- **待核**：心中思量 / 与洁净者结对交锋 / 你是没有办法与他并驾齐驱的，都引自父层 840。当前注入的父层（摩犍提经）是错配，见开头说明。

## §2302–2303 句 125-2302-2-3 / 125-2303-2-5
