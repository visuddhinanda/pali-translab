# Review — 125:2077-2088(channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9)

> 资源:pali ✅/nissaya ✅(125-2080-140-143 无单独 nissaya,已并入 144-154 行)/父层本文 ✅,但**缺**一首偈
> ⚠ 父层对照只给了 159:2342-2353(偈 685–688 的本文)。本章 §2078–2080 的被解释词(ānandajāte / patīte / sucivasane / dussaṃ gahetvā / asito isī / divāvihāre)出自前一首事缘偈(“Ānandajāte tidasagaṇe patīte…”)。这首偈不在注入范围内,所以这几处**无法核对是否与父层逐字相同**,需补取父层上一段后再查。
> 注:本层本身就是义注,释义标准即原文自身,下文“依据”主要引 nissaya 与父层译文。

## 被解释词与父层对照

可以核对的各处都与父层译文逐字一致,无必改项:看见诸天 / 为了什么缘故 / 兴高采烈 / 恭敬地 / 欢喜 / 即使从前 / 交战 / 诸天得胜 / 诸天看到了什么稀有的事,这样欢喜 / 欢呼 / 唱歌 / 奏乐 / 我请问你们 / 贤者们。§2084–2086 引偈三行也与父层 2346–2347 一致。

以下几处是父层的子串,可以接受:
- **拍打**:父层作“拍打手臂”。
- **住在须弥山顶的**:父层作“住在须弥山顶的诸位”。
- **拿着衣布**:父层 2344 作“拿着衣布挥舞作乐”。

## 跨段一致性

- **tuṭṭha**:§2079 句 125-2079-8-11 译“满足”,§2081 句 125-2081-27-30 的 tuṭṭharūpo 译“满心高兴”,父层 2353 的 tuṭṭhā 译“满心欢喜”。
  - 建议统一为“高兴/欢喜”一系。“满足”在现代汉语里偏指“知足、够了”,义偏。
- **deva**:多数处译“诸天”(与父层一致),但有几处混用“天神”:§2082“天神们的胜利”、§2083“那些天神”“这些天神”“天神与阿修罗之战中诸天的胜利”(同一句内两种译法)。
  - 建议:泛指一律用“诸天”。前有指示词时可用“天神”(“这些天神”)。
  - 125-2083-171-195 句内要统一,改为“诸天与阿修罗之战中诸天的胜利”,或改写为“那次天与阿修罗交战时诸天的胜利”。
  - §2082 的“天神们的胜利”另见下文具体条目。
- **喜悦类近义词**:ānandajāta=满怀喜悦,patīta=欢欣,pamudita/pamodita=欢喜,somanassajāta=生起喜悦,kalyarūpa=欢喜,pamodo=欢喜(§2087)。
  - 问题一:somanassajāta 的“喜悦”与 ānandajāta 的“满怀喜悦”撞字,读者会误以为两者互释。建议 somanassajāta 改作“心生愉悦”或“心里高兴”。
  - 问题二:§2087 的 pamodo,父层 2347 补出的名词是“欢腾”。可考虑改作“欢腾”,与父层呼应;不改也可以。
- **moneyya / moneyyapaṭipadā**:都译“牟尼道”。§2078 句 125-2078-48-61 的“moneyyaṃ te upaññissaṃ”是引经文(本经后文偈)。日后应与父层该偈译法核对,并确认 moneyya 与 moneyyapaṭipadā 是否要区分。暂记,不作必改。

## §2078 句 125-2078-13-47
- **问题**:措辞。kappasatasahassaṃ 是表时段的宾格,译“用十万劫圆满诸波罗蜜”读来别扭。
- **建议**:改为“在十万劫中圆满诸波罗蜜”。

## §2078 句 125-2078-62-81 / 125-2078-82-97
- **问题**:句读。前句以“那罗迦是由谁、在什么时候受到劝导,才去请问世尊的,”结尾,后句另起“阿难想把这一切都讲明白”,两段连读时主语断裂。
  - nissaya 把 yena 解作“由于什么原因”(အကြောင်းကြောင့်)。但 yena 与 samādapito 搭配,应是具格施事“由谁”,指阿私陀。译文取“由谁”是对的,不必依 nissaya 改。
- **建议**:
  - 前句末改为:“……那罗迦是由谁劝导、在什么时候受到劝导,才去请问世尊的——”
  - 后句改为:“阿难想把这一切都讲明白,……”
  - 或前句收为:“……对于那罗迦由谁、在什么时候受到劝导才去请问世尊这件事,”

## §2079 句 125-2079-8-11
- **问题**:义偏。tuṭṭhe 译“满足”,见跨段一致性。
- **建议**:“**欢欣**是指高兴。”

## §2079 句 125-2079-51-57
- **问题**:可读性。释义依赖词源(asita 意为“黑”),中文读者看不出“阿私陀”与“黝黑”有什么关系。
- **建议**:在黑体后夹注,例如“**阿私陀仙人**,是因为身体肤色黝黑(asita 意为‘黑’)而得到这个名字的仙人”。同时把单字“因”改为“因为”。

## §2081 句 125-2081-2-15
- **问题**:漏译,加上黑体用法不当。
  - 原文省略了谓语 āha,nissaya 补出“အာဟ= ဆို၏”(说)。译文没有补出“说”,结果“看见诸天……乃至……为了什么缘故”成了叙述句的一部分,而它实际是被引的偈文。
- **建议**:“686. 于是他这样看见之后,说了“**看见诸天**……乃至……**为了什么缘故**”这首偈。”

## §2081 句 125-2081-16-20
- **问题**:取义略过。abbhunnatakāye 意为身体昂扬、挺起(nissaya:အလွန်တက်ကြွသော ကိုယ်),“高高跃起”加了跳跃的动作。
- **建议**:“是指身体昂扬振奋。”

## §2082 句 125-2082-25-30
- **问题**:释义失效。父层已把 surānaṃ 译成“诸天”,本句释义(sura=deva)的作用在中文里看不出来,改成“诸天的胜利”就成了同义反复。
- **建议**:保留“天神”,并夹注点明替换关系,例如“**诸天得胜**,就是天神(deva)的胜利”。或者加一句说明:偈中的 sura 就是 deva。

## §2083 句 125-2083-58-67
- **问题**:措辞。pāricchattakapaṭicchannabhūtāya 意为“作为波利质多树的对应物”(nissaya:ပါရိစ္ဆတ္တကသဒိသာယ,“与波利质多相似”)。“代替”容易读成“取代、替换掉”。
- **建议**:“用一棵相当于波利质多树的彩色波吒厘树作装饰。”

## §2083 句 125-2083-68-101
- **问题**:前后衔接。“非天(asurā)”与下一句“从此就有了‘阿修罗’这个称号”之间缺一个连接,读者不易看出“非天”就是“阿修罗”的由来。
- **建议**:“已经成了非天(asurā,音译即阿修罗)了。”

## §2083 句 125-2083-126-141
- **问题**:可选的术语调整。indapaṭimā 译“因陀罗像”。本段一直用“帝释”,突然出现“因陀罗”,一般读者可能不知道是同一位。
- **建议**:改作“帝释(因陀罗)像”,或直接作“和自己一模一样的帝释像”。

## §2087 句 125-2087-10-23
- **问题**:措辞。pana 在这里表示转折对比(“可是今天”),“又”会让人误读为“再一次”。
- **建议**:“是说:可是今天,诸天究竟看到了什么稀有的事,这样欢喜?”

## §2088 句 125-2088-13-24
- **问题**:措辞。aṭṭhasaṭṭhi tūriyasahassāni 是数量(六万八千件乐器),“六万八千种”变成了种类。
- **建议**:“演奏六万八千件乐器。”
