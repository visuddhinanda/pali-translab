# Review — 90:385-394（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **bhante**：§386、§387 都译作「尊者」，而 §388–394 的 **āyasmā**（大目犍连、比丘）也译作「尊者」。天神称呼世尊的敬称和称呼弟子的敬称因此混成了同一个词。nissaya 的释义是 `ဘန္တေ= မြတ်စွာဘုရားကို`（世尊），所以 bhante 建议统一改为「大德」或「世尊」，「尊者」只留给 āyasmā。涉及 90-386-49-60、90-386-66-78、90-387-46-55、90-387-62-72。
- **Evampi kho … tesaṃ devānaṃ ñāṇaṃ hoti**：§392、§393、§394 三处都译成「那些天神也是这样有这样的智」，「这样」重复，读起来像翻译腔。nissaya 的释义是 `ဧဝမ္ပိ= ဤသို့ သိခြင်းကြောင့်လည်း`（由于这样知道，也……）。建议三处统一改为「目犍连贤友，那些天神就是这样，也有这样的智：」。
- **pajānanti / nappajānanti**：§391 两句的译法不对称。前一句是「不能如实了知」，多出一个原文没有的情态词「能」。后一句是「就能如实了知」，又漏掉了 nissaya 标出的限定「只有」。两句要成对修改，见下文 §391 的两条意见。
- **称谓 你／您**：提沙梵天称呼大目犍连，§389 全用「你」。nissaya 一律用敬语（`အရှင်`、`ကြွလာတော်မူ`、`ထိုင်တော်မူပါ`），而且提沙是大目犍连的弟子。建议整段统一用「您」。
- **anupādisesa / saupādisesa**：本 chunk 统一译作「余依」，内部是一致的。但 nissaya 对 upādi 的释义是 **ဥပါဒါန်**（取，upādāna），并引复注说明 upādi 与 upādāna 是同义词。如果采纳这个解释，§386–394 全部「余依」都要同步改为「残余的执取」之类，不能只改一处。

## §386 句 90-386-49-60
- **问题**：称谓。`ဘန္တေ= မြတ်စွာဘုရားကို`，这是天神对世尊的呼格，「尊者」与本经里 āyasmā 的译法撞车。
- **建议**：改为「大德，这些比丘尼已经解脱了。」（或「世尊，……」），与 §387 同步修改。

## §386 句 90-386-66-78
- **问题**：句法。nissaya 作 `အနုပါဒိသေသာ= ဥပါဒါန်အကြွင်းအကျန်မရှိကုန်သည်။ (ဟုတွာ= ဖြစ်ကြ၍) သုဝိမုတ္တာ= …`。anupādisesā 是与 bhikkhuniyo 同格的复数主格形容词，表示「成为无余者之后」，是一个状态，不是修饰 suvimuttā 的状语。译文「无余依地善解脱」把它当成了副词。另外 bhante 的称谓问题同上。
- **建议**：改为「大德，这些比丘尼已经没有残余的执取（或：已无余依），完全解脱了。」，§387 句 90-387-62-72 同步修改。

## §388 句 90-388-54-58
- **问题**：隐含主语。nissaya 只补出 `တတြာပိ= ထိုဗြဟ္မာ့ပြည်၌လည်း`（在那个梵天界里也），jānanti 的主语没有补出。译文补成「人们」，在梵天界的语境里不合适。
- **建议**：改为「在那个梵天界里，大家也都这样知道他——」，或者不补主语：「在那里，他也被这样看待——」。

## §389 句 90-389-59-71
- **问题**：句法与语体。nissaya 的结构是 `ဣဓ အာဂမနာယ … ပရိယာယော … ဣမံ ပရိယာယံ (တွံ) စိရဿံ ခေါ အကာသိ`，意思是「来这里的这一次机会，你隔了很久才做到」。译文「你好久才有这么一趟，也就是到这里来这件事」把 yadidaṃ 硬拆成补述，读起来很拗口。
- **建议**：改为「目犍连贤友，您隔了好久才找到机会到这里来。」

## §389 句 90-389-72-82
- **问题**：nissaya 作 `ပညတ္တံ= အရှင်အတွက် ခင်းထားအပ်သော`（为尊者铺设的），用的是敬语。
- **建议**：改为「请坐，目犍连贤友，这是为您铺好的座位。」（称谓见上文跨段一致性一节）

## §391 句 90-391-2-31
- **问题 1**：情态。`နပ္ပဇာနန္တိ= မသိကြကုန်`，意思只是「不知道」，没有「能不能」的意思。
- **问题 2**：词义。`ယသေန= အခြံအရံအကျော်အစောဖြင့်`，yasa 包括随从和名声两层意思，只译「名声」偏窄。
- **问题 3**：用词。`ဥတ္တရိ= ထိုထက် လွန်ကဲမြင့်မြတ်သော`（超过那些的、更殊胜的），「更上的」生硬。
- **建议**：改为「……满足于梵天的容色、梵天的快乐、梵天的声望、梵天的权势，他们并不如实了知更高的出离。」

## §391 句 90-391-49-80
- **问题**：限定成分漏译。nissaya 作 `တေ စ= … ထိုဗြဟ္မာတို့သည်သာလျှင်`，意思是「唯有那些梵天」，ca 在这里起限定作用。译文「他们就能如实了知」把限定意义丢了，又多出了「能」。
- **建议**：改为「……只有他们才如实了知更高的出离。」

## §392 句 90-392-2-12
- **问题**：处所。`ဣဓ= ဤသာသနာတော်၌`（在这个教法中），「这里」容易被读成梵天界或当时的处所。
- **建议**：改为「目犍连贤友，在这个教法中，有一位比丘是俱分解脱者。」§393 句 90-393-2-13 与 §394 句 90-394-2-13 同步修改。

## §392 句 90-392-43-54
- **问题**：见上文跨段一致性一节。nissaya 中的 evampi 表示「由于这样知道」，译文「也是这样有这样的智」重复冗赘。
- **建议**：改为「目犍连贤友，那些天神就是这样，也有这样的智：」，§393 句 90-393-44-54 与 §394 句 90-394-55-65 同步修改。

## §394 句 90-394-25-54
- **问题 1**：词义误读（必改）。`ဣန္ဒြိယာနိ= သဒ္ဓါအစရှိသော ဝိပဿနာ ဣန္ဒြေတို့ကို။ သမန္နာနယမာနော= ညီညီမျှမျှ ဆောင်ထားနိုင်လသော်`，意思是使信等观根保持均衡。这里的 indriya 指信、精进、念、定、慧诸根，samannānaya 是「使它们平衡」，不是守护六根的「调御」。
- **问题 2**：语气。`အပ္ပေဝနာမ ဝိဟရေယျ= နေနိုင်တန်ရာ၏`，表达的是天神对他的推断（应该能够安住），不是祈愿。「但愿」把天神的认知改成了天神的愿望，与上文「那些天神这样知道他」也接不上。
- **问题 3**：用词。`ပဋိသေဝမာနော= မှီခိုနေထိုင်`（依止居住），「使用住处」不贴切。
- **建议**：改为「这位尊者居住在适合修行的住处，亲近善友，使诸根保持平衡，应该能够就在现世中亲自以证智证得那无上的梵行终点，成就并安住在其中。善男子们正是为了这个目的，才正当地离开家庭、出家过无家的生活。」
