# Review — 90:348-359（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **sarena**：§349、§350、§351、§354 都译作“出声”。nissaya 是 `သရေန= ချိုသာသောအသံဖြင့်`（用悦耳的声音），“出声”漏掉了“悦耳”这层意思。建议各处统一改为“用优美的声音”。
- **ayyā / ayye**：§352 有三处译作“圣女”（47-61、62-81、82-96）。nissaya 是 `အယျာယ= အရှင်မ`、`ဧဝံ အယျေ= ကောင်းပါပြီ အရှင်မ`，意思是仆人对女主人的称呼（主母、夫人）。“圣女”会让读者以为这里说的是圣者。**必改**，三处统一改为“女主人”。
- **ātitheyya**：§351、§354 共六处译作“招待你／我的供养”。nissaya 是 `ဧည့်သည်တွက်တာ လက်ဆောင်ပဏ္ဏာ`（款待客人的礼物）。对方是作客的天王，不是僧众，用“供养”语域不对。建议统一改为“待客之礼”。
- **Na kho me … eseva acchariyo abbhuto dhammo**：§356、§357、§358、§359 四处都译作“我这件稀有难得的事，并不只是这一件”，句子自相矛盾（“这件事不只是这一件”）。**必改**，四处统一改为“尊者，我稀有难得的事并不只有这一件”。
- **nābhijānāmi**：§356、§357、§358 译作“不觉得……”。nissaya 是 `နာဘိဇာနာမိ= မသိပါ`，意思是“不知道曾经有过”，指的是回顾过去，而“不觉得”像是当下的感受。建议统一改为“我不记得……有过……”（§359 已经写成“不觉得自己故意违犯过”，也一并改）。
- **cittuppādampi parisodhessasi**：§356、§357、§358 三处译作“连心念的生起都能保持清净”。nissaya 的意思是“连（动摇、越轨的）心念生起这一点都能清除、遏止”，宾语是这个心念本身，不是“保持清净”的状态。建议统一改为“你竟然连这样的念头都不让它生起”。另外参见下文 §355 关于将来时表过去的条目。
- **bhagini / bhātā**：nissaya 是 `ဘဂိနိ= နှမ`（妹妹）、`ဘာတာ= အစ်ကို`（哥哥）。译文用的“姐妹／兄弟”是泛称，可以接受。如果改，§351、§354 的全部呼语要成对同步改为“妹妹／哥哥”。
- **idha**：§354 的“我在这里”、§356 的“我在这里有一个独子”都不自然。nissaya 是 `ဣဓ= ဤနေအိမ်၌`（在这个家里）。建议改为“我在家里”和“我家里有一个独子”。
- **§354 的转述段**：§354 83-92、§354 107-126 逐字重复 §351 的对话。下面 §351 80-91 与 115-136 的修改需要同步到这两句。

## §349 句 90-349-26-73
- **问题**：词义 — `သရေန= ချိုသာသောအသံဖြင့်`，“出声”漏掉了“悦耳”。
- **建议**：改为“用优美的声音诵出《彼岸道品》”。

## §351 句 90-351-80-91
- **问题**：误读指代 — nissaya 是 `ဧတဉ္စေဝ= ဤပါရာယနတရားတော်သည်လည်း`，etañceva 回指刚诵完的《彼岸道品》，意思是天王接受这份待客之礼。译文“下面这件事”把它读成了指向下文，意思反了。
- **建议**：“好啊，妹妹（姐妹），你诵的这部法就作为给我的待客之礼吧。”

## §351 句 90-351-115-136
- **问题**：漏译 — nissaya 是 `ဧတဉ္စေဝ= ဤဒါနကုသိုလ် အမျှပေးဝေခြင်းသည်လည်း`（这次回向布施功德也），ca…eva 的“也”没有译出。“这样，这就成了”与前一句也接不上。
- **建议**：“这（回向）也将是给我的待客之礼。”

## §352 句 90-352-33-46
- **问题**：词义 — `ကာလံ= ဆွမ်းဘုဉ်းပေးချိန်အခါကို`，“报时”太笼统，读者看不出是用斋的时间。`ဧဟိ= လာပါလော` 也没有体现。
- **建议**：“喂，你过来，到寺院去，告诉比丘僧团用斋的时间到了：”。§352 62-81 的“报时”同步改。

## §352 句 90-352-47-61
- **问题**：称谓 — “圣女”见跨段一致性。`ကာလော= ဆွမ်းဘုဉ်းပေးချိန်တန်ပါပြီ`，“时间到了”没有说明是什么时间。
- **建议**：“尊者们，用斋的时间到了，女主人难陀母家里的饭食已经准备好了。”§352 82-96 同步改。

## §352 句 90-352-62-81
- **问题**：称谓 — `ဧဝံ အယျေ= ကောင်းပါပြီ အရှင်မ`，“圣女”应改。
- **建议**：“是，夫人。”

## §352 句 90-352-115-127
- **问题**：漏义 — `သမ္ပဝါရေသိ= (တော်ပြီဟု) ကောင်းစွာ ငြင်းပယ်စေပြီ`，意思是一直供食，直到对方说“够了”而推辞。“吃得满意”没有表达这一点。
- **建议**：“……让他们吃饱，直到他们表示够了。”

## §355 句 90-355-12-25
- **问题**：时态 — nissaya 明确说明 sallapissasi 是将来时形式表过去，释为 `စကားပြောလိုက်ရပါပေပြီ`（已经交谈了）。“竟然能……交谈”读起来像在说能力，没有说出已经发生的事实。
- **建议**：“你竟然和毗沙门大王这样有大神力、有大威势的天子当面交谈过。”

## §356 句 90-356-33-41
- **问题**：词义 — `ပကရဏေ= အကြောင်းကြောင့်`（因为某种缘故），“案子”把意思说窄了。
- **建议**：“国王们因为某件事，把他强行抓走，夺去了他的性命。”

## §356 句 90-356-42-67
- **问题**：词义 — `အညထတ္တံ= တုန်လှုပ်ချောက်ချားသည်အဖြစ်ကို`（动摇、惊惶的状态），“异样”太模糊。nābhijānāmi 的问题见跨段一致性。
- **建议**：“……我都不记得自己的心有过任何动摇。”

## §357 句 90-357-35-41
- **问题**：语气 — `တေနေဝ= ……ဖြင့်ပင်လျှင်`，eva 的强调（正是以那个身体）没有译出。
- **建议**：“他就以生前的模样向我现身。”

## §357 句 90-357-42-56
- **问题**：词义 — 同 §356 42-67，“心有什么异样”应改为“心有过动摇”，“不觉得”应改为“不记得”。
- **建议**：“可是尊者，我不记得自己因为这件事心有过任何动摇。”

## §359 句 90-359-23-37
- **问题**：语态／主语误读 — nissaya 是 `(ဥပါသိကာဘာဝံ) ပဋိဒေသိတာ= လျှောက်ထားခဲ့ပြပြီ`，意思是她自己宣告成为优婆夷，是主动的。译文“被接受为优婆夷”把施事弄错了。**必改**。
- **建议**：“尊者，自从我宣告自己成为优婆夷以来，我不记得自己故意违犯过任何一条学处。”
