# Review — 90:410-421（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核）

## 跨段一致性

- **nimitta**：§412、§413、§414 都译作“迹象”，共 6 处（412-42、412-49、413-74、413-82、414-61、414-68）。nissaya 每处都释为 `ဧတံ နိမိတ္တံ= ဤစောဒနာခြင်း၏ အကြောင်းကို`，意思是“这种责难的根据”，并补注“由（有过失的）法与责难者两项构成的根据”。“迹象”偏离了这层意思，6 处要一起改为“根据”，例如“我看不到这样的根据”。
- **khemappatto abhayappatto vesārajjappatto**：§412、§413、§414 共 3 处，都译成“安住在安稳、无畏、确信自在之中”。这里有两个问题，详见 §412 句 90-412-49-69：
  - 三个 `-ppatto`（已到达）的意思丢了；
  - vesārajja 译作“确信自在”不准确。
  
  改法需要 3 处同步。
- **sikkhā**：§418、§419 都译作“戒学”。nissaya 释为 `သိက္ခာယ= သိက္ခာသုံးပါး၌`，即“三学”。两处要同步改，详见 §418。
- **idha**：§418、§419、§421 都译作“在这里”。nissaya 一律释为 `ဣဓ= ဤသာသနာတော်၌`，即“在这教法中”。建议三处统一改为“在这教法中”。
- **ājīva / micchāājīva**：§411 前一句把 ājīva 译作“生计”，后一句把 micchāājīva 译作“邪命”，前后语体不一致。nissaya 对后者的异释是 `ဝါ= ထိုယုတ်နိမ့်ညံ့ဖျင်း မသန့်ရှင်းသော အသက်မွေးမှု`，即“卑劣不清净的谋生方式”。建议统一为“生计清净……没有不正当的生计”，或统一为“活命清净……没有邪命”。
- **文言虚词“便”**：共 3 处，分别在 413-15、421-2、421-56（“便因”“不久便会”）。按 style.md，“便”要改为“就”。

## §411 句 90-411-37-45（连带 90-411-30-36；同构的 52-58/59-67、74-80/81-89、96-102/103-111 照此一并改）

- **问题**：句法误读，属必改项。依据 nissaya：
  - `ဣတိ= ဤသို့ မသိစေလိုသော သဘောဖြင့်`：iti 标示的是“不想让别人知道”的**意图**，不是说话的内容。
  - `ယံ= အကြင်ကာယဒုစ္စရိတ်…ကို … ရက္ခေယျ= ကာကွယ်ဖုံးအုပ်ထားရာ၏ … တံ … နတ္ထိ`：yaṃ 引出关系从句，意思是“没有那种如来会抱着这种念头去遮掩的身恶行”。

  现译“用不着防护说”有两处不对：一是把意图当成了言说（“说”）；二是把“不存在这种恶行”改成了“不需要去防护”。另外，`ရက္ခေယျ= ကာကွယ်ဖုံးအုပ်` 的意思是“护持并遮掩”，只译“防护”，读者看不出“遮掩不让人知”这层意思。
- **建议**：30-36 与 37-45 合起来改为：“如来没有那种需要遮掩、心想‘但愿别人不要知道我这件事’的身恶行。”如果坐标切分要求两句分开，可以这样拆：
  - 30-36：“如来没有那种他会遮掩起来、心想”
  - 37-45：“‘但愿别人不要知道我这件事’的身恶行。”

  语、意、邪命三组照此同构修改。

## §411 句 90-411-2-18

- **问题**：措辞，属建议项。`အရက္ခေယျာနိ= ကာကွယ်ဖုံးအုပ်ထားဖွယ်မလိုသော အကျင့်တရားတို့` 的意思是“不需要遮护的行为”。“防护”没有体现“遮掩”的意思，与上一条是同一个问题。
- **建议**：arakkheyya 改为“不需要遮护的事”，411-19、411-112、415-2 同步改。

## §412 句 90-412-8-14

- **问题**：语义重复，属建议项。nissaya 是 `သွာက္ခာတဓမ္မော= ကောင်းစွာ ဟောကြားအပ်သော တရားမြတ်ရှိတော်မူ၏`，是有财释，意思是“如来具有善说的法”。现译“所讲说的法是善加讲说的”重复了“讲说”。
- **建议**：“比丘们，如来的法是善说的。”34-41 相应改为“你的法并不是善说的”。

## §412 句 90-412-42-48（413-74、414-61 同）

- **问题**：误译 nimitta，属必改项。nissaya 是 `ဧတံ နိမိတ္တံ= ဤစောဒနာခြင်း၏ အကြောင်းကို`，指的是“责难的根据”，不是“迹象”。
- **建议**：“比丘们，我看不到这样的根据。”

## §412 句 90-412-49-69（413-82、414-68 同）

- **问题**：
  1. **成分丢失**，属必改项。nissaya 依次是：
     - `ခေမပ္ပတ္တော= …ငြိမ်းချမ်းသည်အဖြစ်သို့ ရောက်တော်မူလျက်`
     - `အဘယပ္ပတ္တော= …ရောက်တော်မူလျက်`
     - `ဝေသာရဇ္ဇပ္ပတ္တော= ဝေသာရဇ္ဇဉာဏ်သို့ ရောက်တော်မူလျက်`

     三者都是“已到达……”，是修饰主语的分词，后面才接 `ဝိဟရာမိ`。现译“安住在……之中”把“到达”变成了处所。
  2. **vesārajja 误译**，属必改项。nissaya 释为“无畏智”，异释为“无怖、勇毅、欢喜的省察智”。“确信自在”的意思不对。
- **建议**：“比丘们，因为看不到这样的根据，我已达到安稳、达到无畏、达到无所畏惧的自信而安住。”nimitta 同步改为“根据”。

## §413 句 90-413-15-31

- **问题**：文言虚词，属必改项。“便因诸漏灭尽”中的“便”改为“就”。
- **建议**：“……依照这条道路修行，就因诸漏灭尽而……”

## §413 句 90-413-60-73

- **问题**：语气误读，属必改项。nissaya 是 `ယထာ(ယံ ပဋိပဒံ)= ကို။ ပဋိပန္နာ … သာဝကာ … ဝိဟရန္တိ= ကုန်၏`，用的是陈述式，作为关系从句修饰上一句的 paṭipadā。现译“本可……”加入了原文没有的反事实语气。上一句用破折号断开，结构也显得零散。
- **建议**：
  - 51-59 改为：“‘就凭这一点，你并没有为弟子们善加施设那条通向涅槃的道路，”
  - 60-73 改为：“也就是你的弟子们依它修行，就因诸漏灭尽而……乃至……亲自证得后安住其中的那条道路。’”

## §417 句 90-417-2-40

- **问题**：处格义，属建议项。nissaya 是 `ကိမိလာယံ= ကိမိလာမြို့ အနီး၌`，意思是在金毗罗城**附近**。现译“金毗罗城的尼朱拉林”把它说成了城内的林子。
- **建议**：“世尊住在金毗罗城附近的尼朱拉林（niculavana）。”

## §417 句 90-417-64-85（418-50、419-2、419-70 同）

- **问题**：情态添加，属建议项。nissaya 是 `စိရဋ္ဌိတိကော= ကြာမြင့်စွာ တည်တံ့ခြင်းရှိသည်။ န ဟောတိ= မဖြစ်`，意思是“不会成为长久住世的”，没有“能力”的含义。“不能长久存续 / 能够长久存续”多出了能力义。
- **建议**：改为“不会长久存续 / 会长久存续”，四处同步。

## §418 句 90-418-2-49（419-23 同）

- **问题**：
  1. **术语译窄**，属必改项。nissaya 是 `သိက္ခာယ= သိက္ခာသုံးပါး၌`，sikkhā 指戒、定、慧三学，“戒学”只是其中一项。
  2. **idha**，属建议项。nissaya 是 `ဣဓ= ဤသာသနာတော်၌`，建议改为“在这教法中”。
  3. **paṭisanthāra**，属建议项。nissaya 是 `ပဋိသန္ထာရေ= အာမိသ, ဓမ္မ နှစ်ဌာနဖြင့် … ပျူငှာဝတ်ပြု`，指以财、法两种方式友好接待。“亲切款待”偏向物质招待。
- **建议**：
  - “对戒学”改为“对三学”或“对学”；
  - “对亲切款待”可改为“对友好接待”；
  - §419 同步修改。

## §421 句 90-421-2-25（421-56 同）

- **问题**：文言虚词，属必改项。“不久便会”中的“便”改为“就”。nissaya 是 `ဝိဟရေယျ= နေနိုင်၏`，意思是“能够安住”，用“就会”可以接受。
- **建议**：“……不久就能因诸漏灭尽而……乃至……亲自证得后安住其中。”

## §421 句 90-421-30-55

- **问题**：idha，属建议项。nissaya 是 `ဣဓ= ဤသာသနာတော်၌`。
- **建议**：“比丘们，在这教法中，比丘有信……”
