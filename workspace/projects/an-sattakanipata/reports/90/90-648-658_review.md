# Review — 90:648-658（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§653–656、§657 句 2-23 无 nissaya，已略过）

## 跨段一致性

- **yo so … so …（关系从句）与 so vata … bhavissatīti（假设命题）译成同一句式**：§648 句 26-43、§649 句 18-32、§650 句 24-48、§652 句 24-60 后半、§655 句 26-42、§656 句 19-33、§657 句 24-43 都译作「一个比丘敬重导师……，他也……」，与前面 so vata 句的「一个比丘敬重导师……——这是可能的」开头完全相同，读者分不出哪句是「这种情况可能／不可能」，哪句是「凡是……的比丘，他就……」。nissaya 依据：§648 `သော= ထိုရဟန်းသည်။ (…ရိုသေလေးစားခြင်းရှိသော ထိုရဟန်းသည်)`，sagāravo 用 `သော` 作定语修饰 bhikkhu，主句谓语是末尾的 `သဂါရဝေါ= ၏`。→ 建议 yo so 句统一改为「凡是敬重导师……的比丘，他也敬重友善相待」，与 so vata 句区分开。
- **attho / atthaṃ（意思）**：§651、§652 句 9-23 都译「理解它的意思」，§658 句 2-20 却漏掉 attho，只说「应当这样详细地理解」。→ 统一补出「意思」（见下文 §658 条）。
- **pe 后的句末标点**：§649 句 18-32、§656 句 19-33 作「……乃至……。」，§654 句 2-36 作「……乃至……」，没有句号 → 统一一种。

## §648 句 90-648-26-43
- **问题**：句法 — yo so … so 关系结构被拆成两个并列小句。nissaya：`သော= ထိုရဟန်းသည်။ (ရတနာသုံးဖြာ, သိက္ခာ, သမာဓိ, အပ္ပမာဒ၌ ရိုသေလေးစားခြင်းရှိသော ထိုရဟန်းသည်)`，前面的各项 sagāravo 都是修饰 bhikkhu 的定语；`ပဋိသန္ထာရေပိ= ၌လည်း။ သဂါရဝေါ= ၏။` 才是主句谓语。
- **建议**：「大德，凡是敬重导师……乃至……敬重不放逸的比丘，他也敬重友善相待。」

## §650 句 90-650-24-48
- **问题**：句法 — 同上。nissaya：`ယော သော ဘိက္ခု= သည်။ … သော= ထိုရဟန်းသည်။ ပဋိသန္ထာရေပိ= လည်း။ သဂါရဝေါ= ၏။`
- **建议**：「大德，凡是敬重导师、敬重法、敬重僧、敬重学处、敬重定、敬重不放逸的比丘，他也敬重友善相待。”」

## §652 句 90-652-24-60
- **问题**：句法 — 后半段 yo so … appamādepi so agāravo 也是关系结构，现译「一个比丘不敬重导师……，他也不敬重不放逸」，与前半的 so vata 句式混在一起，读起来像两个并列的假设句。
- **建议**：后半改为「……舍利弗，凡是不敬重导师、不敬重法、不敬重僧、不敬重学处、不敬重定的比丘，他也不敬重不放逸。」

## §657 句 90-657-24-43
- **问题**：句法 — 同 §648 句 26-43。nissaya：`သော= ထိုရဟန်းသည်။ ပဋိသန္ထာရေပိ= ၌လည်း။ သဂါရဝေါ= ၏။`
- **建议**：「舍利弗，凡是敬重导师……乃至……敬重不放逸的比丘，他也敬重友善相待。”」

## §658 句 90-658-2-20
- **问题**：漏译 — attho 没有译出。nissaya：`အတ္ထော= အနက်အဓိပ္ပါယ်ကို။`（意思／义理）、`ဣမဿ= ဤတရားစကား၏။`（这段法语的），说明 daṭṭhabbo 的对象是「这段话的意思」，不是「这段话」本身。现译「对于我简略说出的这段话，应当这样详细地理解」把对象换成了话本身，也和 §651、§652 的「理解它的意思」对不上。
- **建议**：「舍利弗，我简略说出的这段话，它的意思应当这样详细地理解。”」（nissaya 补出的隐含施事 `(တုမှေဟိ= သင်တို့သည်။)`「你们」可以不补，中文无主句已经通顺。）
