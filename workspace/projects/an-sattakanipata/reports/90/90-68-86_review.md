# Review — 90:68-86（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，这些句子只在跨段一致性里涉及）
> 注：§83–84 的 nissaya 行位置错开了。§83 那组否定句（30–58）的逐词注挂在 `90-84-24-50` 名下，§84 那组肯定句（24–50）的逐词注挂在 `90-84-51-72` 名下。下面按巴利词形对应回原句来审。

## 跨段一致性

- **vussati 的译法**：§69 句 2-18 和 §80 句 2-17 译成“……**才**修习梵行”，同段的 23-48、49-60 和 §80 的后两句都译成“……**而**修习梵行”。nissaya 只说 `ဝုဿတိ= ကျင့်သုံးအပ်၏`（被修习），没有“只有这样才”的排他意思。建议统一为“而修习梵行”。
- **vivattayi saṃyojanaṃ**：§69 句 100-119 和 §81 句 41-60 是同一句，按 §69 下面的意见修改时，两处要一起改成完全相同的文字。
- **mānābhisamayā**：同上，§69 和 §81 两处同步修改。
- **Ime/Imāni … satta X 这一收尾句**：§71 译“这就是七种结缚”，§78 译“这就是**以上**七种随眠”，§86 译“这就是**以上**七种人”。nissaya 只有 `ဣမေ သတ္တ`（这七种），没有“以上”。建议三处统一为“这就是七种……”。
- **dhana**：§72 品名译“财富品”，§74 摄颂里的经名译“财经”。同一个词前后不一样，建议统一（品名用“财品”，或者经名用“财富经”）。
- **anunaya**：§69 和 §71 都译“贪着结缚”，两处一致，但所指有问题，见 §69 句 23-48。

## §69 句 90-69-23-48

- **问题**：术语所指偏宽。nissaya：`အနုနယသံယောဇနဿ= ကာမရာဂသံယောဇဉ်ကို`，明确说 anunaya 就是**欲贪**（kāmarāga）。七结里另有“有贪”（bhavarāga）。“贪着”字面上把对色界、无色界“有”的贪也包括进去了，和“有贪结缚”重叠。§78 对应的随眠清单里，同一位置正是“欲贪随眠”。
- **建议**：用一个只指欲界贪爱的词，例如“随欲贪着结缚”或“爱欲结缚”，首次出现时夹注（anunaya）。§71 句 17-30 同步修改。

## §69 句 90-69-100-119

- **问题 1**：vivattayi 译得偏弱。nissaya：`ဝိဝတ္တယိ= (အမြစ်အရင်းနှင့်တကွ) ဆွဲနှုတ်စွန့်ပစ်ပြီး`，意思是连根拔出、抛弃。译文“解开了结缚”只是松开，没有把根除的意思译出来，和前面 ucchinnamūla（根已切断）那一系列说法也接不上。
- **建议**：改为“拔除了结缚”或“连根拔除了结缚”。
- **问题 2**：mānābhisamayā 取的是 nissaya 的异释，不是主释。nissaya 主释是 `ကိုးပါးသော မာနကို ပယ်ရှားခြင်းကြောင့်`（因为**断除**了九种慢），异释（`ဝါ=`）才是 `သိမြင်ခြင်းကြောင့်`（因为照见了慢）。译文“透彻理解了慢”只译了异释。
- **建议**：改成兼顾两层意思的“由于正确地彻底照见并断除了慢”。如果只取一解，就取主释：“由于正确地断除了慢”。

## §83 句 90-83-30-58

- **问题**：“有东西也对**他**藏起来”里的“他”在前文没有交代指谁。nissaya 补出了：`အဿ= ထိုရဟန်းအတွက်`（为了那位比丘），而本段之前没有出现过“比丘”这个对象。
- **建议**：改为“有东西也对来访的比丘藏起来，不拿出来”。另外，nissaya 对 asakkaccaṃ 的解释是 `ကိုယ်တိုင်မပြုစု`（不亲自侍奉）或“差别人去做、不尊重地给”，可以考虑译出“不亲手”这一层，例如“给的时候不亲手、不恭敬”。

## §84 句 90-84-24-50

- **问题 1**：“有东西**也**不对他藏起来”中的“也”是让步语气（即使有也……），这是从否定句照搬过来的。肯定句的 nissaya 是 `သန္တံ= ထင်ရှားရှိလသော်`（有的时候），属于条件关系，不是让步。
- **建议**：改为“有东西就不藏着不给”。
- **问题 2**：“他”的指代问题同 §83。
- **建议**：同步改为“对来访的比丘”。

## §86 句 90-86-2-21

- **问题**：语义方向有歧义。nissaya 把 āhuneyyā / pāhuneyyā / dakkhiṇeyyā 都释为 `…ခံယူတော်မူထိုက်`（值得**接受**……），说的是这些人有资格接受。译文“值得布施”在现代汉语里可能被读成“这些人值得去布施（别人）”，“值得招待”也有类似的歧义。
- **建议**：改为“值得接受供养，值得接受款待，值得接受布施，值得合掌礼敬”。§86 句 46-64 同步修改。
