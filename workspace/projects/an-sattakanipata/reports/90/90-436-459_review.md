# Review — 90:436-459（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§449、§451 两行无 nissaya，按规则略过；但这两句的词释分别挂在 §450、§452 两行里，疑为 nissaya 单元对齐错位，见文末）

## 跨段一致性
- **adaṇḍena**：§438、§448 都译作「不用刑杖」。nissaya 释为「ဥစ္စာဒဏ်, လက်နက်ဒဏ်မရှိဘဲ」，即不用罚财、不用兵刑，不只是杖刑 → 两处都建议改为「不用刑罚」。
- **devānamindo / devindo**：§438 译「天众之主」，§445 译「天主」，同一个称号用了两种译法 → 建议统一为「天主」，§438 改作「天主帝释」。
- **iddhimā / patāpavā**：§456 iddhimā 译「具有威势」，§455 patāpavā 译「威势显赫」，两个不同的巴利词落到了同一个「威势」上。nissaya 的区分是：iddhimā= ကြီးသောတန်ခိုးရှိသော，指大神力；patāpavā= 权位、财力的声威 → 建议 §456 改「具有大威力」，§455 保留「威势显赫」或改「声威显赫」。
- **ahuṃ / ahosiṃ（过去时）**：§444、§446 译「做过」，§447 却译「我是」，§438-2-16 也作「我就是」（homi，这里是现在时，可以保留）→ §447 建议改「我曾是」，与前后的过去时一致。

## §437 句 90-437-2-21
- **问题**：取义偏窄 — nissaya 详释说明，所怕的是「做功德」时要付出的施舍与约束：「ကုသိုလ်ကောင်းမှုပြုရမှာ မကြောက်ကြနဲ့」。「害怕功德」容易被读成害怕功德本身。
- **建议**：「比丘们，不要害怕做功德。」

## §437 句 90-437-46-95
- **问题**：句法误读 — nissaya 把第二个 dīgharattaṃ 挂在 paccanubhūtaṃ 上：`ဒီဃရတ္တံ= လုံး။ ပစ္စနုဘူတံ= ကိုယ်တိုင်ခံစားအပ်ဖူးသည်ကို`，意思是「我长久地亲身领受」。vipākaṃ 是 paccanubhūtaṃ 的宾语，主语是「我」（`အဟံ= ငါသည်`）。译文把功德改成了「带来」的主语，「长久」也挂错了位置。
- **建议**：「比丘们，我亲身确知：长久以来所造的功德，它们可意、可爱、合意的果报，我曾长久地亲身领受。」

## §438 句 90-438-2-16
- **问题**：词义偏移 — abhibhū= 「အခြားသော ဗြဟ္မာတို့ကို လွှမ်းမိုးအုပ်စိုးသော」，意思是压服并统御其他梵天，不是「超越」；anabhibhūto= 不被他们压服。此外 nissaya 把这几项都作为 brahmā 的定语，译文拆成了一串「是…」并列谓语，读起来比较散。
- **建议**：「超越者／不被超越者」改为「统御者／不被统御者」；或者整句改为「我就是梵天、大梵天，是统御者，不被他人统御，确实能见一切，随心自在」。

## §438 句 90-438-27-37
- **问题**：句法与词义
  - janapadatthāvariyappatto= 「ခိုင်မြဲသည် အဖြစ်သို့ ရောက်သောတိုင်းနိုင်ငံ ဇနပုဒ်ရှိသော」，是有财释，意为国土已经安定稳固。原文没有使役义，译文的「使」是添出来的。
  - vijitāvī= 战胜内外两种敌人。译文「征服一切」里的「一切」也是添出来的。
  - dhammiko 单列为「是如法的」，读起来不顺。nissaya 把这一串都作为 rājā 的定语。
- **建议**：「也曾数百次做过国王——如法的转轮法王，统治四方，战胜了敌人，国土安定稳固，具足七宝。」

## §438 句 90-438-38-64
- **问题**：词义 — pariṇāyakaratana 一词，nissaya 释为「ရှေ့ဆောင်ဦးစီး သားကြီးရတနာ」，并说明此宝是正宫所生的长子，负责辅佐、引导一切国事。「将军宝」把它窄化成了武职。另外 tassa mayhaṃ 里的「那时的我」（作为转轮王的我）在译文里没有译出。
- **建议**：改为「主导宝」，并加脚注说明此宝是辅政的长子；译名定案后补进 terms.md。句首改作「比丘们，那时的我拥有这七种宝」。

## §438 句 90-438-65-77
- **问题**：漏义、时态
  - sūrā 与 vīraṅgarūpā 是两个定语，被合并成了「勇敢威武」。nissaya 对 vīraṅgarūpā 的解释是：具有勇士那样的精进本性，可以整天作战而不疲倦（`တနေကုန်ခန်း၊ မပန်းမဟိုက်၊ စစ်တိုက်နိုင်ကုန်သော`）。
  - ahesuṃ 是过去时，译文作「我还有」。
- **建议**：「比丘们，我还曾有一千多个儿子，他们勇敢，具有英雄的精进气质，能够击破敌军。」

## §439 句 90-439-2-17
- **问题**：句法误读（必改） — kusalānaṃ 是 puññānaṃ 的定语：`ကုသလာနံ= ကုသိုလ်ဖြစ်ကုန်သော။ ပုညာနံ= ကောင်းမှုတို့၏`，意思是「属于善的功德」。原文只说了一种果报，译文却拆成了「功德的果报、善业的果报」两个并列宾语。
- **建议**：「追求快乐的人们啊，看看善功德的果报吧；」

## §445 句 90-445-2-6
- **问题**：句法与搭配 — nissaya 补出 `(ဟုတွာ= ဖြစ်၍)`，意思是「身为天主，执掌天王之位」。devarajjaṃ akārayiṃ 是行使王权，「统治着王位」这个动宾搭配不通。「统治着」的进行体也不符合过去时。
- **建议**：「三十六次身为天主，执掌天界的王权。」

## §452 句 90-452-2-17
- **问题**：词义 — sabbakāmehi= 「အားလုံးစုံသော လိုလားနှစ်သက်ဖွယ်အာရုံတို့」，指一切称心的欲乐对象，「所欲之物」偏向物品。
- **建议**：「那家族具足一切称心的享受，也具足七种宝；」

## §454 句 90-454-2-27
- **问题**：所指不清 — mahantassa= 「ကြီးကျယ်မြင့်မြတ်သော စကြဝတေးမင်းစည်းစိမ်」，指转轮王的伟大荣盛；eso 指的是修慈的善业。「伟大的原因」可以误读成「重大的原因」。na vipajjati 的意思是不会因敌人而动摇败亡。
- **建议**：「这就是我得享伟大荣盛的原因，我统治大地的王位不会动摇；」

## §455 句 90-455-2-16
- **问题**：词义 — nissaya 把 pahūtavittūpakaraṇo 拆为 `ဝိတ္တိ= နှစ်သက်ခြင်း၏ + ဥပကရဏ= အကြောင်း`，意思是丰足的、令人喜悦的资具或饰物。vitta 在这里取「喜悦」义，不是「财富」。
- **建议**：「我拥有丰足的赏心资具，成为威势显赫的国王。」（如果采纳跨段一致性的建议，「威势显赫」改为「声威显赫」。）

## §458 句 90-458-2-19
- **问题**：词义 — attakāmena= 「မိမိ၏ စီးပွားချမ်းသာကို အလိုရှိသော」，意思是希求自身利益与安乐的人。「爱惜自己」偏离了原意。
- **建议**：「所以，希求自身福祉、追求伟大的人，」

## 原文／数据疑问
- §449「Asāhasena kammena … anusāsi taṃ」本行没有 nissaya，它的词释（asāhasena / samena / kammena / taṃ / anusāsi）挂在了 §450 行的末尾。§451「Mahaddhane mahābhoge … ajāyihaṃ」同样没有 nissaya，词释挂在 §452 行的开头。两处都疑为 nissaya 单元的 `word_start/word_end` 对齐错位，不影响本次审读，记录备查。
- 仅供参考：按 §450 行所挂的词释，asāhasena 与 samena 都是 kammena 的定语，是同一项施政，而 §449 译文拆成了「以…作为、以…方式」两项。§451 句需要等 nissaya 对齐修正后再复核。
