# Review — 90:706-722（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分句有 nissaya，无 nissaya 的句子略过）

## 跨段一致性
- **§710 / §718**：两段的 ubhayāni … pātimokkhāni … anubyañjanaso 是同一句，译文也相同。§710 的修改（见下文）必须同步到 §718。
- **§712 / §720**：两段的 vinaye kho pana ṭhito hoti asaṃhīro 是同一句。§712 的修改必须同步到 §720。
- **§714 / §722**：两段的 sākāraṃ sauddesaṃ … anussarati 是同一句。§714 的修改必须同步到 §722。
- **sacchikatvā upasampajja viharati**：两组段落的译法不统一。
  - §708、§710、§712、§714 译作「证得……并且成就、安住于其中」。
  - §716、§718、§720、§722 译作「证得后，成就并安住于其中」。
  - 建议统一为「证得……并且成就、安住于其中」，因为它出现次数多，也与完整句式对应。

## §708 句 90-708-27-74
- **问题 1**：句法错位。
  - nissaya 的结构：`ပါတိမောက္ခသံဝရသံဝုတော= …စောင့်စည်းလျက်`，`အာစာရ+ဂေါစရ+သမ္ပန္နော= …ပြည့်စုံလျက်`，两者都是带「လျက်」的伴随状语，共同修饰 `ဝိဟရတိ= နေ၏`。
  - 译文写成「以波罗提木叉的约束防护自己，安住于其中，正行与行处都具足」，把 viharati 插在中间，使「具足」脱离了「住」。「于其中」也是原文没有的成分，读起来像是「安住在波罗提木叉里」。
- **问题 2**：隐含成分没有补出。nissaya 补出了防护的对象：`ကာယဒွါရ, ဝစီဒွါရတို့ကို ပိတ်ဆို့ စောင့်စည်းလျက်`（防护身门、语门）。译文只写「防护自己」，可以酌情补出。
- **问题 3**：必改项，文言虚词。「依之修学」里的「之」是文言用法。
- **建议**：改为「……他持戒，以波罗提木叉律仪防护身、语而住，正行与行处（gocara）都具足，……受持各条学处，并依照它们修学；……」

## §710 句 90-710-28-77
- **问题 1**：词义错配（必改）。
  - nissaya 释 `သွာဂတာနိ= ကောင်းမွန်ကျေပွန်စွာ နှုတ်၌ရောက်လာကုန်သည်`，意思是「熟练地到了口中」，也就是熟记成诵。
  - nissaya 释 `သုပ္ပဝတ္တီနိ= (သိလိုရာရာ စဉ်းစားလိုက်သမျှ ဌာနတိုင်း၌) ခိုင်မြဲကောင်းမွန် ကျေပွန်စွာ ဖြစ်ပေါ်လာခြင်း ရှိကုန်သည်`，意思是「无论想查哪一处，一想就牢固地现前」，也就是运用纯熟。
  - 译文把 svāgata 译成「通达」，把 suppavatti 译成「善能背诵」，两词的意思错位了。
- **问题 2**：vitthārena 误译。nissaya 释 `ဝိတ္ထာရေန= အကျယ်ဖြစ်သော ဝိဘင်းပါဠိတော်နှင့်တကွ`，意思是「连同详细的分别（Vibhaṅga）圣典」，是一个名词性的伴随成分。译文作副词「详细地」，丢掉了「连同分别」这层意思。
- **问题 3**：suttaso / anubyañjanaso 的格与所指都不对。
  - nissaya 释 `သုတ္တသော= …ဥဘတော ဝိဘင်းပါဠိအားဖြင့်`，`အနုဗျဉ္ဇနသော= ခန္ဓကပရိဝါရ ပါဠိတော်အားဖြင့်`，用的是「အားဖြင့်」（依……、就……而言），修饰 `သုဝိနိစ္ဆိတာနိ`。
  - 译文「连同经文与逐一的细节」把依据关系译成了伴随关系。「经文」也容易被误读为经藏，而它实际指两部分别；「细节」指的是犍度、附随。
- **问题 4**：隐含成分。nissaya 补出了 `ဥဘယာနိ= (ဘိက္ခု ဘိက္ခုနီ အားဖြင့်)`，即比丘、比丘尼两部。可以酌情补出，或在首次出现时注明。
- **建议**：改为「他对比丘、比丘尼两部波罗提木叉连同详细的分别都熟记成诵，善加分别，运用纯熟，并且依据经分别（sutta）以及附随细则（anubyañjana）善加抉择」。§718 同步修改。

## §712 句 90-712-21-64
- **问题**：隐含成分没有补出，词义也过泛。
  - nissaya 释 `ဌိတော= (လဇ္ဇီအဖြစ်ဖြင့်) ခိုင်မြဲတည်တံ့သည်`，即以知耻者的身份稳固地安立。
  - nissaya 释 `အသံဟီရော= (အယူအဆ ပြောင်းလဲအောင် ပရဝါဒီတို့က) မဆွဲဆောင်အပ် မဆွဲဆောင်နိုင်သည်`，即不会被他宗论者拉动而改变见解。nissaya 附注还举了甘蔗非时食的诘难作例子。
  - 译文「不被人动摇」没有交代施动者是他宗论者，也没有交代被动摇的是见解。「在律上立得稳」偏口语，和全篇的语体不一致。
- **建议**：改为「他安立于律，不会被他宗论者说动而改变见解」。§720 同步修改。

## §714 句 90-714-26-61
- **问题**：sauddesaṃ 误译（必改）。
  - nissaya 释 `သဥဒ္ဒေသံ= ညွှန်ပြ ပြောဆိုကြောင်း ဖြစ်သော နာမဂေါတ္တနှင့်တကွဖြစ်သော`，意思是「连同用来指称他的姓名与族姓」。译文作「连同细节」，所指不对。
  - nissaya 释 `သာကာရံ= (ဝဏ္ဏ, အာဟာရစသော) အခြင်းအရာတို့နှင့်တကွ`，意思是「连同容貌、饮食等情状」。译文「形相」偏窄，可以考虑改为「情状」。
- **建议**：把「他这样连同形相、连同细节」改为「他这样连同容貌等情状、连同姓名族姓」。§722 同步修改。
