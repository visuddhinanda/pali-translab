## 跨段一致性

- **nāmagottāni**：§540-2 译为“原来的**名称**”，§540-33／§540-75 译为“原来的**姓名**”。这是同一比喻的两端，用词必须相同，否则比喻的对应就断了。**义注**（1190）：“**河**、**低流**等是族姓（gotta），**恒河**、**阎牟那河**等是名称（nāma）。”可见河流也兼有名与族姓，“名称”译窄了。→ 建议三处统一为“原来的名字和族姓”。
- **mahī**：§540-2 译为“摩**酰**河”，义注 1189 译为“摩**希**河”。三层的专名应当统一。→ 建议统一为一个译名（倾向“摩希河”，与义注已定稿的一致），并登记进 `terms.md`。
- **saṃvasati**：§539-2 写大海“不与死尸**共处**”，§539-27 写“僧团不会与他**共住**”。动词同为 saṃvasati，比喻两端分别用“共处”和“共住”，可以接受（大海说“共住”不自然）。只需与义注 1183 的被解释词对齐，见下文 §539 句 157-539-2-13。
- **acchariyā abbhutā dhammā**：本文全 chunk 统一为“稀有、未曾有的特质”✓。但义注 1180 前半句作“稀有、未曾有的特质”，后半句作“稀有、**奇特**的特质”，而且说的是“八**种**”，本文 §536 作“八**个**”。这属于义注层的问题，留到 harmonize 时一并统一。

## §532 / §533 / §534 / §535 / §536 句 157-532-59-75 等（阿修罗喜乐句，共 5 处）

- **问题**：被解释词不一致。**义注**（1181）引作“**阿修罗们一再看到这些特质，就喜爱大海**”，其中 **abhiramantī** 单列为“**喜爱**”。本文各处统一作“阿修罗们一再**见到它**，就**乐于住在大海里**”（§535-110 作“它们”）。“看到／见到”“这些特质／它”“喜爱／乐于住在”三处都不同。
- **建议**：保留本文译法，改义注一侧。理由有三：
  - 本文这个句式在全经反复出现（本 chunk 内已有 5 次，比丘版还有 5 次），改本文的代价大。
  - **义注**解释 abhiramantī 为“感到欢喜，住在那里不觉厌倦”，“乐于住在”恰好兼顾了“喜”和“住”两层意思。
  - nissaya：`အဘိရမန္တိ= မွေ့လျော်ကုန်၏`（喜乐）。§537-32 那条错乱的 nissaya 里有 `ပျင်းသည်မရှိ ပျော်မွေ့`（无厌倦而喜乐），也指向同一方向。

  harmonize 时，把义注 1181 的引文改为“阿修罗们一再见到它们，就乐于住在大海里”，**abhiramantī** 改为“乐于住在”。同时请核对本经 §532 之前第一至第四特质的本文，确认用的也是同一句式。

## §537 句 157-537-2-16

- **问题**：被解释词不一致。**义注**（1182）：“**不是一下子就成为断崖**”（na āyatakeneva papāto），并解释为“不像断岸的大深坑那样，从一开始就是陡崖”。本文译作“并不是一开始就**陡然下落**”。papāta 是名词“断崖”，本文把它译成了动作“下落”，与义注所指的地形不符。
- **建议**：本文改为“并不是一开始就成为断崖”，与下句“并不是一开始就突然通达究竟智”的句式相对。义注 1182 的被解释词同步改成这一措辞。

## §539 句 157-539-2-13

- **问题**：被解释词不一致。**义注**（1183）引作“**不容死尸留在其中**”，本文译作“不与死尸共处”。
- **建议**：保留本文。“共处”贴合 saṃvasati，也能呼应后文僧团“不共住”；义注自己的解释也写作“不与任何象、马等的尸体共处”。改义注一侧，被解释词改为“不与死尸共处”。

## §539 句 157-539-14-26

- **问题**：被解释词不一致，而且两个动词译反了。
  - **义注**：“**推向岸边**就是把它送到岸边”（tīraṃ vāheti = apaneti）。
  - **义注**：“**冲上陆地**是说：好像用手抓起来一样，只凭浪的冲击就把它抛到陆地上”（thalaṃ ussāreti）。
  - 本文却作“冲到岸边，推上陆地”，正好与义注的分配相反。按义注，“冲”（浪击）属于 ussāreti，不属于 vāheti。
- **建议**：本文改为“很快就会把它推向岸边，冲上陆地”。

## §539 句 157-539-27-53（及 157-539-78-102 重复句）

- **问题**：被解释词不一致。义注 1175-1176 对这一串形容词逐个有黑体引文，对照如下：

  | 巴利 | 义注黑体 | 本文现译 | 判定 |
  |---|---|---|---|
  | dussīlo | 破戒 | 破戒 | ✓ |
  | pāpadhammo | **品行恶劣** | 作恶 | ✗ |
  | asuci | 不清净 | 不清净 | ✓ |
  | saṅkassarasamācāro | **行为可疑** | 行为令人怀疑 | ✗ |
  | paṭicchannakammanto | 所作所为遮遮掩掩 | 所作所为遮遮掩掩 | ✓ |
  | assamaṇo | 不是沙门 | 不是沙门 | ✓ |
  | samaṇapaṭiñño | **自称是沙门** | 自称沙门 | ✗ |
  | abrahmacārī / brahmacāripaṭiñño | 不修梵行／自称修梵行 | 同 | ✓ |
  | antopūti | 内心腐烂 | 内心腐烂 | ✓ |
  | avassuto | **欲念漏泄** | 被欲望浸透 | ✗ |
  | kasambujāto | **像垃圾一样** | 污秽不堪 | ✗ |

  义理上，本文的几处译法也偏离了义注：
  - **pāpadhammo**：**义注**释为“因破戒、志向低下而本性卑劣”（lāmakasabhāva）。nissaya：`ယုတ်မာသော သဘောရှိ၏`（具有卑劣的本性）。两者讲的都是本性，“作恶”却成了行为，译偏了。
  - **saṅkassarasamācāro**：**义注**给出两解，一是“令他人起疑”，二是“自己心中起疑”。nissaya 也列了这两解（`ဝါ=`）。“令人怀疑”只取了第一解，“行为可疑”能兼容两解。
  - **kasambujāto**：**义注**释为“生起贪等垃圾，又应被持戒者抛弃”。“污秽不堪”丢掉了“垃圾、应被抛弃”这个意象，而这个意象正是本段把破戒者比作死尸、被大海推上岸的关键。
- **建议**：本文这两句都改用义注的被解释词：品行恶劣、行为可疑、自称是沙门、欲念漏泄、像垃圾一样。这串词在本经前文（阿难请佛诵波罗提木叉、目犍连看见那个破戒者的段落）的本文里已经出现过，义注的黑体应当就是照那一段的译文引出的。请先读回那一段确认，三处本文必须完全一致。

## §534 句 157-534-13-29

- **问题**：nissaya 与译文有分歧，仅作记录，**不改**。nissaya 把 `ရဇတံ= ရွှေ`（金）、`ဇာတရူပံ= ငွေ`（银）对调了。rajata 是银、jātarūpa 是金，这是公认的词义，译文“银、金”是对的，nissaya 应属讹误。
- 另外，silā 译作“玉石”。nissaya 作 `ကျောက်သလင်း`（水晶类石），nissaya 附录引的义注说 silā 有白、黑、绿豆色等多种。“玉石”可以接受，但所指偏窄，建议压低该句 confidence，定案后登记进 `terms.md`。
