## §525 句 157-525-46-55

- **问题**：义注取义（语气）。**义注**：*Idampi garahaṇacchariyamevāti veditabbaṃ*（这也是带有责备意味的稀奇），并解释为“那个愚痴的人竟然要等到被抓住手臂……这真是稀奇”。现译「真是稀有！真是奇特！」在汉语佛典语境里通常是赞叹语，与 §527 以下赞叹大海特质的「稀有、奇特」完全同形，读者容易读成称赞。
- **建议**：改为带反讽意味、与义注 §1177 一致的说法，例如“目犍连，真是稀奇！目犍连，真是少见！”。这样会和 §527 起的「稀有、奇特」形成区分，这种区分以义注为据，属于有意为之。如果决定保留「稀有、奇特」以求字面统一，至少要压低该句 confidence，并在报告里记下义注的这一判读。

## §523 句 157-523-27-37

- **问题**：措辞欠准（不必改）。*manasākāsi* 的 nissaya 是 `မနသာကာလိ= နှလုံးသွင်းပြီ`（作意、留心），现译「加以审察」偏重分析义。*cetasā* 的 nissaya 是 `အရှင်မောဂ္ဂလ္လာန်၏ စေတောပရိယဉာဏ်ဖြင့်`（以尊者的他心智）；**义注** §1175 也说是 *cetopariyañāṇena … cittāni parijānanto*。现译「用自己的心」字面不错，但「每个人的」是增译。nissaya 对 *sabbāvantaṃ* 的释义是“包括上中下各类成员的”，即整个僧团。
- **建议**：可改为“以自己的心遍知整个比丘僧团的心，加以留意”。他心智的说明留给义注，本文不必补。

## §528–531 “Yampi … ; ayaṃ … dhammo” 句组（157-528-16-38 / 157-529-16-24 / 157-530-42-63 / 157-531-46-74）

- **问题**：句法（不必改）。nissaya 把 *yaṃ … ayaṃ* 处理为关系呼应：*yaṃ* 引出“大海如此这般”的情形，*ayaṃ* 回指它（如 §529 `အယံ= ဤတည်တံ့သော သဘောရှိခြင်း…`）。现译前半句以逗号悬空，后半句另起“比丘们，这是……”，回指关系靠读者自己补，可读性尚可。
- **建议**：如果要更清楚，可在后半句改用“这就是大海的第 N 种……”，四处同步改。不改也可以。
