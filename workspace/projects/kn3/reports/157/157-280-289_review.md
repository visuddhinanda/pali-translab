# Review — 157:280-289（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（284 的三句重复感叹 284-37-43、284-44-54、284-80-86、284-87-97 没有 nissaya 单元，按重复句处理）／义注 ✅（book 123 §742–758）
>
> 被解释词对齐：义注黑体共 25 处（sattāhaṃ ekapallaṅkena… / vuṭṭhāsī / tena kho pana samayena sakko… dātukāmo hoti / tantaṃ vināti / tasaraṃ pūreti / yena sakkassa… tenupasaṅkami / addasā kho… adāsī / ghaṭiyā / uddharitvā / anekasūpo / anekabyañjano / anekarasabyañjano / atha kho… etadahosi / kosiya / puññena attho / vehāsaṃ abbhuggantvā / ākāse antalikkhe / aho dānaṃ / aho / paramadānaṃ kassape suppatiṭṭhitaṃ / assosi kho bhagavā dibbāya sotadhātuyā / dibbāya sotadhātuyā / visuddhāya / atikkantamānusikāya / etamatthaṃ viditvā / piṇḍapātikassa），逐条比对，**本文译法与义注引用全部逐字一致，无断裂**。下面跨段一致性第一条若要改，必须本文与义注 123-750-2-18 同步改。

## 跨段一致性
- **piṇḍapāta**：§282 句 157-282-2-15 译“施食”，§283 句 157-283-83-98 也译“施食”；但 §283 句 157-283-2-13 译“饮食”（“想要布施饮食给尊者摩诃迦叶”）。→ 建议统一为“施食”。依据：本 chunk 多数译法，义注各处（750、751、753）也都作“施食”。⚠ 157-283-2-13 是义注 123-750-2-18 的被解释词，**两处必须同步改为**“那时，诸天之王帝释想要布施施食给尊者摩诃迦叶”（或“想要把施食布施给尊者摩诃迦叶”），否则对齐就断了。
- **atha kho 与 tena kho pana samayena 撞译**：§283 内 157-283-2-13 的 *tena kho pana samayena* 译“那时”，157-283-35-48 的 *atha kho* 也译“那时”。同一段里两个不同的时间连接词用了同一个译法，读者分不出“同时”与“接着”。→ 建议 157-283-35-48 改为“这时”或“于是”。*tena kho pana samayena*=“那时”在 §281/§282/§283 已经统一，保持不变。
- **atha kho … etadahosi**：157-281-57-65 译“…心里这样想”（没有译 atha kho），157-283-99-104 译“这时，…心里这样想”，157-283-121-126 译“接着，…又这样想”。第三处的“又”是承接上文第二个念头，属于合理补出，可以保留。157-281-57-65 建议补“这时”，与 157-283-99-104 一致（后者是义注 753 的被解释词，以它为准）。属于建议项，不是必改项。
- **udānaṃ udānesi**：帝释译“发出感叹”（157-284-2-18、157-284-55-71），世尊译“说了这首自说偈”（157-285-2-12）。同一个巴利短语有两个译法，但这是有意区分：世尊的 udāna 就是本经所属的文体，义注 757 也作“自说偈”。**不改**，在这里记录一下。

## §282 句 157-282-2-15
- **问题**：背景补出 — *devatā* 译“天神”，没有体现性别。**义注**：tā sakkassa devarañño paricārikā kakuṭapādiniyo（她们是天王帝释的侍女，脚像鸽子的脚一样）。nissaya：`ပဉ္စမတ္တာနိ ဒေဝတာသတာနိ= ငါးရာ…နတ်သမီးတို့သည်`（五百位天女）。义注和 nissaya 都指为女性天众。
- **建议**：可以改作“大约五百位天女”。如果为了保留 *devatā* 的字面泛称而维持“天神”，就要连同义注 123-750-19-62 的“那大约五百位天神”一起考虑，两处保持一致。属于可选项。

## §282 句 157-282-16-30
- **问题**：取义 — *atha kho* 译“然而”，带出了原文没有的转折语气。
- **建议**：改为“于是”或“这时”，即“于是尊者摩诃迦叶谢绝了那大约五百位天神……”。属于轻微问题。

## §283 句 157-283-105-120
- **问题**：取义 — *ko nu kho ayaṃ satto* 译“这究竟是什么样的众生”，容易读成问“哪一类众生”，原文问的是“这是谁”。nissaya：`ကော နု ခေါ= အဘယ်ပုဂ္ဂိုလ်နည်း`（是哪一个人）。**义注** 753 复述长老的心念，作“这究竟是谁呢？”。
- **建议**：“这位众生究竟是谁，竟然有这样的神通威力？”

## §283 句 157-283-179-185
- **问题**：格与句法（必改）— *amhākampi puññena karaṇīyaṃ* 译“我们也要做福德的事”，把具格 *puññena* 当成了“做”的宾语。这里的“X-ena karaṇīyaṃ”是“需要 X、要用到 X”的惯用式，与上句 *puññena attho* 平行。nissaya：`ပုညေန= ကောင်းမှုကုသိုလ်ဖြင့်`（以福德，具格）、`ကရဏီယံ= ပြုသင့်ပြုထိုက်ပါ၏`。
- **建议**：“我们也用得着福德。”或“我们也有要靠福德来成就的事。”与上句“我们也需要福德”构成平行。

## §287 句 157-287-2-4
- **问题**：术语所指（必改）— *anaññaposino* 译“不供养他人”。在汉语佛教语境里，“供养”是向三宝或尊长奉献，这样译会被读成“这位比丘不对别人作供养”，意思完全偏了。原义是不负担别人的生活。nissaya：`အနညပေါသိနော= မိမိမှတစ်ပါး အခြားတပည့်စသည်တို့အား…မွေးမြူခြင်း မရှိသော`（不养育自己以外的弟子等人）。*posin* 的意思是“养育、扶养”。
- **建议**：“只养活自己，不必养活别人”或“只维持自己的生活，不负担他人”。

## §289 句 157-289-2-8
- **问题**：句法 — *upasantassa sadā satīmato* 与 *piṇḍapātikassa bhikkhuno*、*attabharassa anaññaposino*、*tādino* 是同一组修饰语，都是 *pihayanti* 的对象（nissaya 句法注：…ပိဟယန္တိ ကြိယာ၏ အယှဉ်ဖြစ်၍…ကမ္မတ္ထသာ ယောဇနာပါ）。译文另起一句，用“他内心寂静，时时具有正念”，把它们变成了独立陈述，与诸天羡慕的对象脱开了。
- **建议**：让这一行仍然挂在被羡慕者身上，例如“那内心寂静、时时具有正念的人。”或者调整 §288 与 §289 的分行，比如 §288 作“诸天都羡慕这样如如不动、”，§289 作“内心寂静、时时具有正念的人。”偈颂保留分行，只调整句读。

## §285 句 157-285-2-12
- **问题**：取义（记录）— *etamatthaṃ* 译“这件事”。**义注** 757 把它释为一个道理：“安立在正确修行所成就的殊胜功德中的杰出之人，诸天和人类都会……极为羡慕。”也就是说，世尊“知道”的是事件所体现的道理，不只是事件本身。本文的“这件事”与义注被解释词逐字一致，而且字面上并没有错，所以**不改**。义注 123-757-2-25 中“知道了这样的道理”已经把这一层补出来了。
