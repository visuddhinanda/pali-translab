# Review — 123:659-666（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层（157:215-236 本文定稿）✅
> 本层自身就是义注。上层释义标准（复注 ṭīkā）未注入，所以释义核对以父层本文和 nissaya 为准。nissaya 依据的底本有几处读法与本 pali 不同，见文末「原文疑问」。

## 被解释词与父层对齐

逐条核对了 16 处黑体：Gharā nikkhamantassa / Upaḍḍhullikhitehi kesehi / Apaloketvā / Maṃ, bhante / Tuvaṭaṃ / Tamanussaramāno / atha kho…kakuṭapādānī / bāhāyaṃ gahetvā / Kakuṭapādānī / Passasi no / Abhirūpatarā / Dassanīyatarā / Pāsādikatarā / Paluṭṭhamakkaṭī / Evameva kho / Pañcannaṃ accharāsatānaṃ / Upanidhāya / Saṅkhyaṃ / Kalabhāgaṃ / Upanidhiṃ / Abhirama, nanda… / Ahaṃ te pāṭibhogo / Assosuṃ。

全部与父层译文逐字相同，或者是父层译文中的连续子串，或者用“……”标出了跳过的部分。**没有必改项。**

⚠ **父层自身的问题（本层不改，留待父层 revise／统稿处理）**：
- 157-225-2-11：*Abhirama, nanda* 父层译作“安心修梵行吧”。但本层 665-2-27 的义注明说世尊这里**没有提梵行**（*taṃ anāmasitvā*，“不再提它”），父层补出的“修梵行”正好与义注的解释相抵。
- 由于逐字同译的硬约束，本层黑体只能照抄父层。读者看到的局面就是：注文说“不再提梵行”，引文里却有“修梵行”。
- 建议父层改为“难陀，要安心啊！难陀，要安心啊！”一类的说法，改完再让本层同步。

## 跨段一致性

- **abhirati / abhiramati**：译法不统一。
  - 661-81 译“格外乐于过梵行生活”
  - 665-2 译“在梵行中安乐”
  - 父层 225 译“乐于在世尊座下修梵行”
  - 建议统一为“乐于（梵行）”。依据：父层用词，且与 anabhirato“心中不乐”正好成对。
- **sakka devarājā**：660-65 译“天王帝释”，父层 223 *sakka devānaminda* 译“天帝释”。巴利用词不同，两种译法都说得通。但同一个人物紧挨着出现两种称谓，建议统一为“天帝释”。
- **āgantuka-ārammaṇa / āgantuka-visaya**：
  - 665-41 译“外来的所缘”，666-6 译“外来的境”，两段讲的是同一件事（把贪欲转移到新对象上）。
  - 建议都用“对象”或都用“所缘”。“境”是单音节词，读者容易看不懂。
  - 用“所缘”的话，首次出现要夹注（ārammaṇa）。

## §666 句 123-666-6-70

- **问题 1：句法误读（必改）**。*āyasmante nande vattaṃ dassetvā attano divāṭṭhānaṃ gate* 是处格独立结构，逻辑主语是**难陀**：难陀尽完本分后，回到自己白天的住处。译文写成“世尊为尊者难陀指示了应行的本分”，把施事搞错了。
  - nissaya 依据：`အာယသ္မန္တေနန္ဒေ= အရှင်နန္ဒသည်`（主格），`ဝတ္တံ= ဝတ်ကို`，`ဒဿေတွာ= ပြ၍`，`ဒိဝါဋ္ဌာနဂတေ= နေ့နေရာသို့ကပ်လေသည်ရှိသော်`。
- **建议**：“那时，尊者难陀向世尊尽了应尽的本分，回到自己白天的住处以后，世尊就对前来侍候的比丘们讲了这件事。”
- **问题 2：误译（必改）**。*aññāya āṇiyā* 的 aññāya 是 añña 的阴性具格，与 āṇiyā 一致，意思是“用另一个楔子”，不是独立式“知道”。译文“知道某个楔子拔不出来”多出了“知道”。
  - nissaya 依据：`အညာယအာဏိယာ= တပါးသောပရစ်ဖြင့်`。
- **建议**：“就像一个熟练的人，用另一个楔子把拔不出来的楔子顶出来，然后再用手等摇动后插进去的那个楔子，把它取出来。”
  - “那个楔子”要说清是后插进去的那个。依据：nissaya `တံအာဏိံ= ထိုနောက်၌သွင်းအပ်သောပရစ်ကို`。
- **问题 3：文言（必改）**。“惯常之境”“修梵行之道”里的“之”是文言虚词。
- **建议**：分别改为“习惯的对象”“修梵行、证圣道”。
- **问题 4：可读性**。全句很长。建议在“讲了这件事。”和“于是吩咐说”之前断句，现在的断法基本可以。
- **问题 5：前后一致**。*etha* 译“你们去”，而父层 218 的 *ehi tvaṃ* 译“你来”。建议改“你们来”。

## §659 句 123-659-41-54

- **问题**：存疑但译得很确定。*aḍḍhakāravidhāna* 的含义不明，nissaya 只照录原词（且读作 aḍḍhūkā-），没有给出释义。“梳成半边的样式”是推测。
- **建议**：保留现译，压低 confidence，在报告里登记这个分歧。

## §659 句 123-659-55-62

- **问题**：取义与措辞。
  - *aḍḍhakkhinā* 字面是“半只眼”，nissaya 释为 `ထက်ဝက်မှိတ်သောမျက်စိဖြင့်`（半闭的眼睛）。
  - 译文“用眼角斜睨着”取了“侧目”一解。“睨”在现代汉语里带有轻蔑意味，与“流露浓浓爱意”冲突。
- **建议**：“用半眯着、流露出浓浓爱意的眼睛看着，好像要把他缠住一样。”

## §661 句 123-661-81-87

- **问题**：指代不明。
  - “为了那个目的”不知道指什么。*tadatthaṃ* 指上文的天女，或世尊带他去天界这件事。nissaya 把 *tadatthaṃ* 与下文 *tattha nesi* 连读，即“为此带他去”。
  - 句末的 *ti* 表示这是世尊的考虑，译文没有体现出来。
- **建议**：“因为这样一来，他就会为了天女而格外乐于修梵行。”这一句的 confidence 要压低。

## §664 句 123-664-67-95

- **问题**：*kalāyapi bhāgaṃ* 译成“一分中的一份”，读者看不出“一分”是什么。kalā 本义是十六分之一。
- **建议**：“就是十六分之一里的一份”，后面的解说保持不变。

## §665 句 123-665-2-27

- **问题**：语句歧义。“他在其中心中不乐”可能被读成“在其中心中不乐”。
- **建议**：“他心中不乐地修持的那种梵行”。

## §665 句 123-665-41-55

- **问题**：指代不清。“把它转移到……”里的“它”，可能被读成指“所缘”。实际上 *taṃ* 指贪欲，依据 nissaya `တံရာဂံ= ထိုရာဂကို`。
- **建议**：“把这份贪欲转移到……”。
