# Review — 123:1477-1483（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（有缺漏：§1477 漏掉 yāmesu / tusitesu / nimmānaratīsu 三处；§1481 句 2-8 没有单独的 nissaya 行，被并进了句 9-24）／义注 —（本层就是义注 Udāna-aṭṭhakathā，没有更高一层的释义标准，只能对照父层本文〔book=157〕和 nissaya 来审）

## 被解释词与父层对照

逐条核对的结果：

| 被解释词 | 本层译法 | 父层译法 | 结论 |
|---|---|---|---|
| Etamatthaṃ viditvā | 了知这件事以后 | 了知这件事以后 | ✅ 一致 |
| imaṃ udānaṃ udānesi | 说出了这首自说偈 | 说出了这首自说偈 | ✅ 一致 |
| Mohasambandhano loko, bhabbarūpova dissati | 世间被愚痴束缚，看起来却像是有能力的样子 | 同左 | ✅ 一致 |
| Upadhibandhano bālo, tamasā parivārito | 愚人被依著（upadhi）系缚，被黑暗所包围 | 同左 | ✅ 一致 |
| Sassatoriva khāyati | 看起来仿佛是恒常的 | 同左 | ✅ 一致 |
| Passato natthi kiñcanaṃ | 对于能如实见的人来说，却什么也没有 | 同左 | ✅ 一致 |

被解释词全部逐字一致。下面两条是**父层译法和义注释义之间的张力**。父层已经定稿，本层黑体不能动，所以这两条只登记下来，留给 harmonize 或父层复核处理：

- **bhabbarūpo**：父层译作“有能力的样子”。义注用 `hetusampanno viya`（好像具足了〔证悟的〕因）来解释，可见 bhabba 指的是“有成就〔道果〕潜质的”，不是一般意义上的“能干”。父层的“有能力”容易被读成能干、有本事。
- **kiñcanaṃ**：父层译作“什么也没有”。**义注**：`rāgādikiñcanaṃ natthi, yena saṃsāre bajjheyya`，把它解释为“贪等障碍（系着）”。父层译成泛指的“什么”，丢掉了这层所指，本层只好另用“挂碍（kiñcana）”来补，两层之间的对应只能靠夹注维持。

## 跨段一致性

- **bandhana / sambandhana**：父层定下 mohasambandhano 译“束缚”、upadhibandhano 译“系缚”，本层沿用，没有问题。但 §1481 句 139-148 的 `bandhanehi … baddho` 译成了“束缚系缚”，把两个词叠在一起用 → 建议只用“束缚”。
- **依著 / 依着**：§1481 句 25-78 里“依着欲依著……这些依著”，介词“依着”和术语“依著”同音近形，读者很难分清 → 介词改用“因为”“由于”，见下文该句。
- 其余高频词前后一致：anayabyasana“不幸与灾祸”、paliguṇṭhita“缠裹”、sassata“恒常”、upaṭṭhāti“显现”。

## §1477 句 123-1477-2-35
- **问题**：轻微 — `itarā` 译作“其余的人”。nissaya 把它补成“其余的斯陀含、须陀洹们”，指的是那些女子。
- **建议**：改为“其余的女子”，和上文“她们”呼应。

## §1478 句 123-1478-2-22
- **问题**：误译小品词 — `kira` 是传闻小品词（据说），不表示不确定。“听说”已经表达了传闻，再加“好像”就变成了推测。
- **建议**：“优填王听说沙玛瓦蒂的住处着火了，急忙赶来，可是等他到达那里的时候，她们已经被烧死了。”

## §1478 句 123-1478-23-41
- **问题 1**：语体 — “施以王法”是半文言句式（施以…）。
- **建议**：改为“就用王法惩处了她和她的亲族”。
- **问题 2**：措辞歧义 — “圣女弟子”可能被读成“圣女的弟子”。
- **建议**：`ariyasāvikāsu` 译为“女圣弟子”。
- **问题 3**：句法 — `codiyamāno` 是阳性主格，被驱使的是国王（nissaya：`တိုက်တွန်းအပ်သည်ဖြစ်၍`，“被推动了”），推动他的是摩犍提的恶业。现译“在她对……罪行的驱使下，他……”大体不错，但主语交代得不够清楚。
- **建议**：“他受到她对女圣弟子们所犯恶行的业力推动，就用王法惩处了她和她的亲族。”

## §1479 句 123-1479-2-22
- **问题**：句法（可选改）— `tadatthadīpanaṃ` 修饰 `imaṃ udānaṃ`，意思是“阐明这件事的这首自说偈”，现译把它改成了目的状语“为了阐明”。
- **建议**：受黑体逐字约束，可以保留现译；如果想贴近原文结构，可以写成“……就说出了阐明这件事的偈子，也就是**说出了这首自说偈**”，但不建议为此拆散黑体。列在这里，供 harmonize 参考。

## §1480 句 123-1480-2-33
- **问题**：取义 — `hetusampanno viya` 译作“仿佛具备了因缘”。“因缘”太宽泛，义注这里是用它来解释 bhabba 的，指的是具足证悟的因（潜质）。
- **建议**：“仿佛具足了〔证悟的〕因”，或者“好像具备成就的条件”。

## §1480 句 123-1480-43-67
- **问题**：指代跳跃 — 前半句的主语是“这个世间”，后半句忽然换成“他的自我”“他去做”，“他”没有先行词。
- **建议**：“这个世间被愚痴束缚、被愚痴缠裹，正因为这样，世间的人看自己的自我，就好像它是存续不变的、具有恒常的本性，显现得好像不老不死，因此他们去做杀生等不该做的事。”

## §1481 句 123-1481-2-8 ／ 123-1481-9-24
- **问题**：句读割裂了被解释词 — nissaya 把 `Upadhibandhano bālo, tamasā parivārito sassatoriva khāyatīti` 当成**一个**被解释词组。句 9-24 的解释（`na kevalañca mohasambandhano eva, apica … upadhibandhanopi … avijjātamasā parivārito`）其实是在解释“被依著系缚、被黑暗所包围”，不是在解释“看起来仿佛是恒常的”。现译在 2-8 末尾用了句号断开，在 9-24 又写成“**看起来仿佛是恒常的**：是说……被依著系缚……”，读者会以为后面这段解释是在注“恒常”。
- **建议**：2-8 末尾改用父层的分号，写成“**愚人被依著（upadhi）系缚，被黑暗所包围**；”，让它和 9-24 连成一个被解释词组；9-24 维持“**看起来仿佛是恒常的**：是说……”。另外，`andhabālaloko` 的“盲目愚痴的世间”可以改为“盲目的愚人世间”，和下文“愚人、盲目的凡夫”对齐。

## §1481 句 123-1481-25-78
- **问题 1**：误译 — 末句 `tato eva cassa sopadhissa passato sassato viya … khāyati` 的主语是依著（nissaya：`သောဥပဓိ`，“那三种依著”），现译补成“一切看起来仿佛是恒常的”，“一切”没有根据。
- **建议**：“也正因为这样，在这个带着依著的人看来，这些依著仿佛是恒常的、常住的，好像在一切时候都存在。”
- **问题 2**：措辞 — “他依着欲依著、烦恼依著、蕴依著这些依著而被依著系缚”里，“依着”和“依著”混在一起，很难读。
- **建议**：“所以他因为欲依著、烦恼依著、蕴依著这三种依著，而被依著系缚”。
- **问题 3**：轻微 — `aviparītaṃ` 译作“如实地”，可改为“不颠倒地”，与 `yathābhūtaṃ`（§1481 句 113-138，“如实地”）区分开。

## §1481 句 123-1481-88-107
- **问题 1**：误译 — `ekadeso viya khāyati` 的意思是“看起来就像是〔自我的〕一部分”。现译“看起来就像是只执取了一部分”加进了原文没有的“执取”，意思也偏了。
- **问题 2**：误译 — `upaṭṭhahatīti attho` 是在给 khāyati 释词（“看起来”就是“显现”的意思），现译“也就是这样显现出来的意思”没有译出释词关系。
- **问题 3**：存疑 — `attā sabbakālaṃ vijjati upalabbhatīti añño asassati aniccoti` 这一句的结构有歧义（asassati 怎么拆解，añño 指什么），nissaya 这里也有讹乱（`အသော= အသမည်၏` 等）。现译的读法是：自我是常，其余（依著/身体）是无常。这个读法说得通，但应该压低 confidence。
- **建议**：“这个读法的意思是：世间的人由于邪执，认为自我在一切时候都存在、都可以找到，而其余的东西是不恒常的、无常的，于是世间的这种依著在他们看来就像是〔自我的〕一部分。‘看起来’就是‘显现’的意思。”

## §1481 句 123-1481-108-112
- **问题**：漏译 — `hi`（因为）没有译出，而且没有交代这个 ra 出现在哪里。
- **建议**：“因为 sassatoriva 里的 **ra** 这个音，是用来连接前后词语的。”

## §1481 句 123-1481-139-148
- **问题**：用词重复 — “被无明、渴爱、邪见等束缚系缚在轮回之中”，“束缚”“系缚”叠用。
- **建议**：“意思是：正是不能这样看见的人，才会被无明、渴爱、邪见等束缚在轮回之中。”

## OCR / 原文疑问
- §1477 的 nissaya 缺 yāmesu / tusitesu / nimmānaratīsu 三项，是 nissaya 底本的缺漏，pali 原文完整。
- §1481 句 88-107 的 nissaya（`အသတတိဝိဇ္ဇတိ`、`အသော= အသမည်၏`、`နိစ္စဿ= မြဲသော`）和巴利原文对不上，疑似 nissaya 抄录有讹，这一句不宜把 nissaya 当作词级依据。
