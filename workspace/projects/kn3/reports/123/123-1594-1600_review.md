# Review — 123:1594-1600（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 本 chunk 本身就是义注层，释义依据是义注原文的自身释义加 nissaya；没有引用复注。

## 被解释词对照（与父层逐字比对）

所有黑体被解释词都与父层译文逐字一致，**无必改项**：

- 破戒 / 戒行败坏 / 由于放逸 / 坏名声 / 没有底气 / 临终时心神迷乱
- 身体毁坏 / 死去以后 / 苦界 / 恶趣 / 堕处 / 地狱 / 投生
- 持戒 / 戒行具足 / 财富 / 善趣、天界

§1600-42 把 saggo 和 loko 分别译作“**天**”“**界**”，与父层“天界”的拆分一致，可以保留。

## 跨段一致性

- **visārado**：父层 §887 译“充满自信”，avisārado 译“没有底气”。本 chunk §1596 两处 `visārado hutvā kathetuṃ` 都译“理直气壮地说话”。义注在这里是用 visārado 反释被解释词 avisārado，措辞断开后读者看不出两者的关系。建议改为“不能有底气地说话”，与被解释词“没有底气”呼应。
- **aya**：§1598-33 第一处译“进益”（aya），同句第二处 `sukhānaṃ ayassa` 却译成“快乐的来处”。§1598-75 又回到“进益”。三处都是同一个词源解释（apāya / niraya ← aya），建议统一用“进益”。见下文 §1598 句条目。
- **abbhuggacchati**：父层译“传扬开来”，§1595 两句译“传出”。它不是被解释词，不算必改，但建议统一为“传扬开来”。
- 其余术语前后一致，无漂移：放逸、过患、没有戒（sīlābhāva）、“用‘X’一词来指……”句式。

## §1594 句 123-1594-46-59
- **问题**：风格（文言虚词，必改）。“作为这里所说的过患**之**因的没有戒”用了文言“之”，整个定语也过长、读不顺。
- **建议**：改为“为了用以人为主体的说法，显示‘没有戒’正是这里所说那些过患的原因，所以说‘戒行败坏’。”

## §1594 句 123-1594-60-70
- **问题**：句法交代不清。nissaya：`တေန= ထိုသီလဝိပန္နောဟူသော ပါဌ်ဖြင့်`，意思是 tena 指“戒行败坏”这句话。译文“这是用来显示……”没有说明主语是什么。
- **建议**：改为“用这个词来显示‘破戒’一词的意思”，或“这是用‘戒行败坏’来显示……”。

## §1595 句 123-1595-2-24
- **问题**：用词。pāpadhammo 译作“行恶法”，偏书面、生硬；salākabhatta 传统多译“行筹食”。
- **建议**：pāpadhammo 改为“品行恶劣”。salākabhatta 用“签食”或“行筹食”均可，定下来以后登记进 terms.md。

## §1596 句 123-1596-2-39
- **问题 1**：存疑（avassaṃ 的归属）。本句的 avassaṃ 在引号外，译文让它修饰“走进去”，成了“一定是心怀恐惧地走进去”。但同构的 §1596-40 里，avassaṃ 在引语内修饰“会有人知道”（“一定会有人知道我做过的事”）。两句结构平行，这里大概率也是修饰“会有人知道”。
- **建议 1**：改为“心怀恐惧地走进去，心想：‘一定会有人知道我做过的事……’”，与 §1596-40 一致；该句 confidence 适当压低。
- **问题 2**：visārado 的译法，见“跨段一致性”。

## §1596 句 123-1596-40-71
- **问题**：术语。`uposathampi pavāraṇampi ṭhapetvā` 是律藏的“遮（暂停）布萨、遮自恣”，“停止”不够准确。visārado 的译法见“跨段一致性”。
- **建议**：改为“暂停我的布萨和自恣”，或用“遮止”。

## §1598 句 123-1598-33-48
- **问题 1**：风格（文言虚词，必改）。“作为生天和解脱**之**因的‘进益’”。
- **建议 1**：改为“作为生天和解脱原因的、被称为福德的‘进益’”。
- **问题 2**：取义。`sukhānaṃ vā ayassa, āgamanassa vā abhāvā` 里，āgamana 是对 aya 的换说（nissaya：`အယဿအာဂမနဿ= ဖြစ်လာခြင်း၏`）。译成“快乐的来处”就丢了 aya，词源解释也断了。
- **建议 2**：改为“或者因为其中没有快乐的‘进益’，也就是没有快乐的到来，所以叫苦界”。

## §1598 句 123-1598-49-61
- **问题**：存疑。dosabahulatā 译“嗔恨多”。在 du- 的词源语境里，dosa 也可能是“过失、污染”的意思，两解都说得通。
- **建议**：可以保留“嗔恨多”，但压低该句 confidence。如另有复注依据，再定。

## §1598 句 123-1598-75-80
- **问题**：用词。assādasaññito 译“被认为是快乐的”，assāda 本义是“乐味、可享受的滋味”，“快乐”偏泛。
- **建议**：改为“没有被称为乐味的‘进益’”。

## §1599 句 123-1599-49-74
- **问题**：用词。sabbasampattisamussaya 的 samussaya 是“积聚”，“兴盛”不贴切。
- **建议**：改为“从一切成就的积聚中堕落下来”。

## 原文 / nissaya 疑问（记录，不改）

- **§1596-2**：pali 作 `sabhayo`（有恐惧），nissaya 作 `သံသယော`（saṃsayo，有疑虑），疑为 nissaya 讹写。译文依 pali 是对的。pali `dassessati` 是单数，nissaya `dassissanti` 是复数。
- **§1596-72**：pali `susīlo viya`，nissaya 作 `ဒဗ္ဗိတောဝိယ`，对不上，疑为 nissaya 讹误。
- **§1594-85**：nissaya `ပါဏိဇာယ` 应为 vāṇijjāya，nissaya 讹写，不影响译文。
