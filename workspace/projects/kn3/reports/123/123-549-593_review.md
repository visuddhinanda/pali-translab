# Review — 123:549-593（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（553-28-43 无独立 nissaya 行，内容并入 553-44-54；588–592 各行 nissaya 与偈句错位一行，词级核对已按内容重新对上）／义注：本 chunk 即义注层，不另取／父层对照 ✅（只有 157-167-44-93 的 tathāgatassa 与本 chunk 直接对应）

## 被解释词与父层对照

- **tathāgato**：父层 157-167-44-93 译“如来”。本 chunk 各黑体 **tathāgato**（549、550、551、553 标题行）都译“**如来**”，逐字一致 ✅
- 其余黑体词（tathāvidho / tathā / pavattito / tathehi / agato / gatabhāvena）是义注自己的分析标目，父层没有，由本层自定译法。本层内部的一致性见下节。

## 跨段一致性

- **tathāgata（指法、僧时）**：553-8-15、553-16-25 译“如来（如此而去者）”，553-101-105 译“一切正法都是如来”，553-138-142、554-2-26、554-27-39、554-63-66 直接译“如来”。读者会以为“正法就是如来（佛）”。→ 建议：在 §553–554 中，凡指法、僧的 tathāgata，一律译“如此而去者”（首次出现时夹注 tathāgata）；“如来”只留给世尊的称号。依据：**义注**明说“Ko panesa tathāgato … Saddhammo”，这里的 tathāgata 指正法，不指佛。
- **§553 标目与 §554 结句不一致**：553-2-7 译“因为**如此**而**去者存在**”，553-8-15 译“因为如此而去者存在”，554-63-66 却译“因为如来存在，所以是如来”。→ 统一为“因为有‘如此而去者’存在，所以是如来”，三处同译。
- **sabbaññu**：549-53-64 译“一切遍知者”，558 译“一切知”。→ 建议统一为“一切知者／一切知的境地”，或都用“遍知”。
- **pahāna 系列**：553-28-43“正断舍断”、553-44-54“安息舍断”，和 549“彼分解脱、镇伏解脱、正断解脱、安息解脱、出离解脱”的体例不对称，而且“舍断”是生造词。→ 建议改为“以正断的方式舍断”“以安息的方式舍断”，或用通行的“正断断／安息断”。
- **偈中 tathā gato**：564 译“如此而去”，572 译“如此而达”。两处巴利字面完全相同，又都是在展示 tatha + gata 的构词，读者需要看到这层关联。→ 建议都用“如此而去／如此而达”中的一个；如果取义确实不同，至少让“如此”和“去／达”在结构上对应。
- **tenapi / tenāpi**：580、588 都把“也”放到了主语后面（“世间的导师也是如来”“胜者也是如来”），见下文逐句。

## §549 句 123-549-18-52
- **问题**：句法（轻）— 这里的具格 maggasīlena … vimuttiyā 表示“以……而具足”，nissaya 用 `နှင့်`（与……）。译成“在……上是什么类型”可以读通，但整句很长，“是什么类型”落在句末，读者要读到最后才明白。
- **建议**：改为“简略地说，过去诸世尊具足道戒、果戒……出离解脱，是怎样的类型”，或者把“是什么类型”提前。

## §549 句 123-549-119-129
- **问题**：存疑 — lokiyā，nissaya 作“သဒ္ဒါကျမ်းဆရာ”（语法学家），译文作“世间的人”。两种理解都说得通，不必改，只记录分歧。
- **建议**：维持原译，压低 confidence。

## §551 句 123-551-2-6 / 123-551-7-13 / 123-551-14-25；§552 句 123-552-15-25
- **问题**：原文异读（记录，不改）— nissaya 通篇读作 **āgato**（အာဂတော，“来到”），pali 作 **agato**（“无去”）。义注自释“natthi etassa gatanti agato”，支持 agato 的读法，译文从 pali 是对的。另外 551-7-13 的 etassa，nissaya 理解为“这个观察智”，译文理解为“他（世尊）”。下句“so panassa agatabhāvo … ñāṇehi”说明 assa 指世尊，智只是凭借的手段，所以译文的理解更顺。
- **建议**：维持原译，把分歧记进 known-issues。

## §552 句 123-552-15-25
- **问题**：句法（轻）— “由于证得有余依涅槃与无余依涅槃，他的这种无去是凭借……”中，“由于”把 -ppattiyā 译成了原因。原文的意思是：这种无去体现为证得两种涅槃，而凭借的是圣道智。
- **建议**：“他的这种无去，是凭借真实的圣道智，通过证得有余依涅槃与无余依涅槃而实现的；这样说来，世尊也是以真实而无去，所以是如来。”

## §553 句 123-553-110-137
- **问题**：取义 — tathāgataṃ 在这里是修饰 dhammaṃ 的形容词（nissaya：တထာဂတံ= …ဖြစ်စေအပ်သော，修饰 ဓမ္မံ），不是属格。“如来之法”把它译成了“如来的法”。这样一来，义注引这句偈要证明的“法本身就是如此而去者”就落空了。
- **建议**：“我们礼敬如此而去、受天和人供养的法，愿有吉祥！”（必改）

## §554 句 123-554-44-56
- **问题**：同上 — “如来之僧”应改为形容词用法。
- **建议**：“我们礼敬如此而去、受天和人供养的僧团，愿有吉祥！”（必改）

## §557–560 句 123-557-2-8 / 123-558-2-5 / 123-559-2-6
- **问题**：对应断裂 — 偈中 yathā … āgatā 与 tathā … āgato 构成对举，是本偈的论证核心。译文 558 用“达到”，559 用“到来”，对举看不出来。558 又重出主语“诸位牟尼”，读起来像另起一句。
- **建议**：“正如世间过去的大仙、诸位牟尼，来到这里证得一切知的境地；这位释迦牟尼也同样到来，所以这位具眼者被称为如来。”

## §563 句 123-563-2-6
- **问题**：结构 — purātanā 修饰 562 的 jinā。译文另起“古代的胜者如此”，和 562 的“胜者们……那样而去”重复。
- **建议**：562 改为“过去的胜者们凭着定与智那样而去”，563 改为“具有光辉的释迦牟尼”。

## §566 句 123-566-2-3
- **问题**：术语 — sabhāva / sāmañña 在这里是自相与共相的对举，“自性、共相”两边不对称。
- **建议**：“从自相、共相的分别与差别上”。

## §571 句 123-571-2-5
- **问题**：原文异读（记录）— nissaya 读作 yato（ယတော，“因为”），pali 作 nayato（“依理”）。译文从 pali。
- **建议**：维持原译，记入 known-issues。

## §580 句 123-580-2-5；§588 句 123-588-2-7
- **问题**：句法 — tenapi / tenāpi 的意思是“也因为这一点”，“也”管的是原因，不管主语。“所以世间的导师也是如来”“因此胜者也是如来”会被读成“导师/胜者也算如来”。
- **建议**：580 改为“也因为这一点，世间的导师是如来”；588 改为“也因为这一点，胜者是如来”。

## §581–582 句 123-581-2-8 / 123-582-2-6
- **问题**：误译（重复谓语）— pariññāya 与 tathāya 同为具格（nissaya：ပရိညာယ= 以三遍知），不是动词。“以真实的遍知全面地如实遍知”多造了一个谓语，和 582 的“了知世间”重复。582 的 pabhavaṃ 指世间的根源（nissaya：无明与贪爱），“超越了它的生起”容易误读。
- **建议**：581 改为“以真实的遍知，全面地”，582 改为“了知世间，超越了世间的根源；”。

## §585–586 句 123-585-2-8 / 123-586-2-5
- **问题**：误译 — 585 与 581 同病，paṭiññāya 也是具格，“全面地如实立誓”多造了谓语。586 的 yato 意思是“因为”（nissaya：ယထော= အကြင်ကြောင့်），译成“从那时起”是误读。
- **建议**：585 改为“以真实的誓愿，全面地”，586 改为“因为他为了世间的利益而到来；”。（必改）

## §589–590 句 123-589-2-8 / 123-590-2-4
- **问题**：格误读 — ñāṇāni 是宾格复数（nissaya：ဉာဏ်တော်တို့သို့，“向诸智”），意思是“到达了真实的诸智”。“凭着真实的诸智”是按具格理解的，不对。590 的 visayāvabodhato 是从格，表示原因或方式，译文把它译成了独立谓语。“如其自性”也偏书面。
- **建议**：589 改为“因为他到达了真实的诸智”，590 改为“由于按照境界本来的性质觉知它们；”。（必改）

## §591 句 123-591-2-4
- **问题**：取义 — 这里的 tathāgato 是“tathā gato”，意思是“像过去诸佛那样经历”（nissaya：တထာ= 如过去诸佛，ဂတော= 经历）。译文把它当作判断句的谓语“他就是如来”，和 592 的结句重复，也失去了这句的论证作用。
- **建议**：“从真实的诞生开始，他就像过去诸佛那样经历一切，”。

## §553 句 123-553-28-43
- **问题**：风格（轻）— “在正法当中，首先是圣道”中的“在……当中”是多出来的（hi 只表示解释）。
- **建议**：“就正法来说，首先是圣道：……”

## 存疑汇总（不改译文）

- 570 的 tathā，译文取“真实的”（形容词，与 569 的 tathāni 对举），nissaya 取“同样”。两解都可以，维持原译，压低 confidence。
