## 跨段一致性 / 义注释义核对（首要问题）

§317 的九处住处列举（araññaṃ / rukkhamūlaṃ / pabbataṃ / kandaraṃ / giriguhaṃ / susānaṃ / vanapatthaṃ / abbhokāsaṃ / palālapuñjaṃ）与对应义注（book 103:918）逐词对照，发现**两处被解释词译法互换、一处走样**：

- **araññaṃ**：义注 103-918-12-21 明确 `**araññan** ti … 都叫作**林间**`，但 §317 译文将 araññaṃ 译作「林野」→ **必改**：改为「林间」。
- **vanapatthaṃ**：义注 103-918-151-165 明确 `**Vanapatthan** ti … 这叫作**林野**`，但 §317 译文将 vanapatthaṃ 译作「林丛」→ **必改**：改为「林野」。
  - 上面两处等于把「林野」「林间」的对应关系整个用反了，需要一并改。
- **pabbataṃ**：义注 103-918-61-64 `**Pabbatan** ti selaṃ` → 「**山**」，§317 译文作「山岳」，虽不算错译但与义注逐字不符 → 建议改为「山」，与义注对齐。
- kandaraṃ→山谷、giriguhaṃ→山洞、rukkhamūlaṃ→树下：与义注逐字一致，无问题。
- susānaṃ、abbhokāsaṃ、palālapuñjaṃ：本次提供的义注片段未给出对应中译，无法核对，暂不处理。

## §317 句 93-317-2-45
- **问题**：被解释词译法与义注不符（见上"跨段一致性"）
- **建议**：将列举改为「林间、树下、山、山谷、山洞、坟地、林野、露地、稻草堆」（araññaṃ→林间，pabbataṃ→山，vanapatthaṃ→林野，其余不变）
