# Review — 188:623-625（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ⚠️（本层为复注 ṭīkā，无独立义注对照，父层 mula 103 译文已作为被解释词核对基准）

## 被解释词对齐核查（本层黑体词 vs 父层 103 译文）

逐条核对结果：**绝大多数黑体被解释词与父层译文逐字相同**，以下两处存在偏差：

- §624 `ṭhapitamatte dakkhiṇapāde`：父层 103-282-92 译作"当他的右脚刚踏在因陀罗柱之内时"（含"踏在……之内"），本层译作"当他的右脚刚踏下的时候"（改为"踏下"）。虽是节引子句，但核心动词短语的译法应与父层一致，建议改为"当他的右脚刚踏下（在因陀罗柱之内）的时候"或至少保留"踏"的同一译法以便读者对应。
- §625 `kāyūpagāni`：父层 103-282-33 译作"人们佩戴的饰物"（`kāyūpagāni ābharaṇāni` → "佩戴的饰物"），本层译作"佩戴在身上的"，虽语义相通，但用字扩展了，建议统一为"佩戴的"以便机械核查通过。

此外，§623 引自父层 103-282 的整句引文 `Upaṭṭhākānuggahaṇatthaṃ, sarīraphāsukatthañcā`（未加粗，但与父层 103-282-2-9 巴利完全同文）父层译作**"为体恤侍者、也为使身体舒适"**，本层却改译为**"为了照顾侍者，也为了身体舒适"**——虽未标黑体，但同一巴利词组在两层间应保持同译，否则读者看不出这是同一处引文，建议统一为父层译法。

## 跨段一致性
- `maṇḍalamāḷo`：§625 前段（`tattha gantvā maṇḍalamāḷe`、`upaṭṭhānasālā cettha maṇḍalamāḷo`）统一译作"圆形会堂"，但 §625-217（`gandhamaṇḍalamāḷe`，引自《满愿疏》）译作"**香圆会堂**"，丢了"形"字，与本 chunk 内其余处不一致 → 建议统一改为"香圆形会堂"。
- 其余术语（世尊、比丘、阿罗汉果、义疏/复注引用格式）本 chunk 内前后一致，无问题。

## 文言腔核查（必改项）

以下各处出现文言虚词"之""于"，应改为现代汉语：

- §623-2-23：`"殊胜之口"` → 建议改为 `"殊胜的口"`。
- §623-54-67：`"按在寺院中所穿之衣的替换方式穿的"` → 建议改为 `"是按照在寺院中所穿衣服的替换方式来穿的"`。
- §623-89-102：`"以此也把城市包括在选择范围内"` 前一句 `"选择之义"` → 建议改为 `"选择的意思"`。
- §625-46-62：`"才会接过世尊的钵"` 前一句 `"与之相称的食物"` → 建议改为 `"与那相称的食物"` 或 `"相应的食物"`。
- §625-63-73：`"以恭敬信从之心供养"` → 建议改为 `"以恭敬信从的心供养"`；`"即向他行受供之事"` → 建议改为 `"即让他受供这件事"`。
- §625-113-125：`"或于当天出家"` → 建议改为 `"或在当天出家"`。
