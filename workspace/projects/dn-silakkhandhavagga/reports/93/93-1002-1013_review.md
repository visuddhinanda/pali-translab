## 跨段一致性

- **专有名词 Vāseṭṭha**：正文全篇统一译作"婆私瑟咤"，但**标题**（93-1002）译作"婆蹉种青年经"，与正文名字不符，也与义注（103-1481-6-16 译"婆私咤"）不符 → 必改项，见下方 93-1002 详述。
- **专有名词 Vāseṭṭha 译法本身**：正文用"婆私瑟咤"，义注用"婆私咤" → 建议全篇统一为"婆私咤"（依义注为准），因义注是已确认的对照译本。
- **ujumaggo（直道）**：义注 103-1481-96-119 明确将 añjasāyano 释为"直道"的同义词，故 ujumaggo 的标准译法应为"直道"；正文 93-1009-144-156 却译作"正直之道" → 与义注术语不一致，必改。
- **añjasāyano / niyyāniko / niyyāti / brahmasahabyatāya 整句译法**：此句在 93-1009-144-156 与 93-1011-35-51 重复出现两次（另有 93-1009-130-143 起始句呼应），译文均为"这就是正直之道,这就是能引导出离的直捷之路,行者依此而出离,到达与梵天为伴的境界"。对照义注逐词释义（103-1481-96-119、103-1482-2-20）：
  - añjasāyano = 直道的同义词 / "能引向解脱的正确道路"
  - niyyāniko = "能引向解脱"（者）
  - niyyāti = "引向解脱"（行进）
  - brahmasahabyatāya = "与梵天同住"（103-1482-2-20 明确给出）
  正文用"出离""为伴的境界"，与义注给出的固定释义"引向解脱""与梵天同住"不同，属于取义偏离义注标准，应统一改用义注词汇。**必改**，两处重复段落须同步改。
- **appāṭihīrakataṃ bhāsitaṃ**（93-1010）：两次均译"没有根据的（话）"，一致，无问题。
- **标点系统**：全篇（93-1002 至 93-1013 每一句）使用半角逗号 `,`、半角问号 `?`、半角句号 `.`，未遵守 `style.md` 第五节"标点一律用中文全角"的硬约束 → **必改项，覆盖几乎全部句子**，需批量替换为全角标点（，。？！）。

## §1002 句 93-1002-2-2

- **问题**：标题误译 — "Vāseṭṭhamāṇavānuyogo" 中 Vāseṭṭha 是人名（正文即译作"婆私瑟咤"），义注亦明确其为 Pokkharasāti 的弟子"婆私咤"；译文却将标题译为"婆蹉种青年经"，"婆蹉"是完全不同的另一人名（Vaccha）音译，与本经人物无关，且与正文自身译法互相矛盾。
- **建议**：改为与正文统一的音译，如"婆私咤青年经"（依义注定为准的译法，见跨段一致性条）。

## §1008 句 93-1008-2-60 / §1009 句 93-1009-57-103
