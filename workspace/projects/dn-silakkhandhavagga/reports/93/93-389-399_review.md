# Review — 93:389-399（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供，本轮未据此审查）／义注 ✅（book=103 对应段落，作为释义标准）

## 义注被解释词核对（首要）

- **§390 "nāmagottaṃ"**：义注 103-1086 明确区分「**名与姓**」——"名"（paṇṇattivasena）与"姓"（paveṇīvasena）两层含义并存，但 §390-57-68、§393-101-114 均只译作"姓氏"，丢了"名"这一层。
  → 建议：改译为"名与姓氏"或"名姓"，两处统一处理。

- **§390-57-68 / §393-115-136 "ayyaputtā sakyā bhavanti, dāsiputto tvamasi sakyānaṃ"**：义注 103-1086 "**Ayyaputtā**ti sāmino puttā"——ayyaputtā 是"主人的儿子们"，与"dāsiputto"（婢女之子）构成"主人之子 vs 婢女之子"的**身份对举**（贵贱对比），不是单纯的"父系血统的子孙"。现译"释迦族人是你父辈一族的子孙，而你却是释迦族的婢女之子"把 ayyaputtā 处理成中性的"子孙"，抹掉了义注给出的贵贱对比，是**必改项**。
  → 建议：类似"（你若追溯古老姓氏）释迦族人对你而言正是贵胄之子，你却是释迦族婢女所生的儿子"，把 ayyaputtā 译出"贵胄／主家之子"的对比义，且 §390 与 §393 两处需同步改，保持统一。

- **§392-81-92 "tadagge kho pana ambaṭṭha sakyā paññāyanti; so ca nesaṃ pubbapuriso"**：义注 103-1098 "**So** **ca** **nesaṃ** **pubbapuriso**ti so okkāko rājā etesaṃ pubbapuriso"——"so"明确指**奥卡卡王本人**。现译"而他正是他们的先祖"，"他"字前一次明确提及奥卡卡王已隔多句（上一次是 §390），指代不清，容易被读者误读为指某位王子。
  → 建议：译为"而奥卡卡王正是他们的先祖"，避免代词悬空。

## 准确性问题

- **§393-54-84（pisāca 相关两句）**：
  - 原文 "manussā pisāce disvā 'pisācā'ti sañjānanti"（人们看见 pisāca 就认出"这是 pisāca"）现译"人们看见夜叉就认出‘这是夜叉’"——**把 pisāca 译成"夜叉"，与后文 §399 的 "yakkha"（执金刚夜叉）撞了译名**，两种不同的鬼神类别被译成同一个词，术语混淆。
  - 紧接一句 "manussā pisāce 'kaṇhā'ti sañjānanti"（人们看见 pisāca 就称之为"刚哈"——即 kaṇha 因传说而成了 pisāca 的代称）现译成"当时的人们看见刚哈就认出‘这是刚哈’"，**主语宾语关系被译反**：原文宾语是 pisāce（复数，"那些鬼怪"），不是"刚哈"本人；译文变成了同义反复的怪句，且丢失了"人们把 pisāca 泛称为 kaṇhā"这一层意思。这两处都是**必改项**。
  → 建议：pisāca 改用与 yakkha 区分的译名（如"魑魅""毘舍阇"），并把第二句改译为符合"人们看见鬼怪，就称之为‘刚哈’"这层意思。

## 跨段一致性 / 术语

- **kalyāṇavākkaraṇo**（§394、§395、§396 三次出现）：均译"言辞善巧"。义注 103-1100 释为"madhuravacano"（**言辞甜美/悦耳**），"善巧"偏向"能力"，与义注"甜美动听"的语感有出入，但三处译法本身彼此一致，不算跨段问题，仅记一笔供术语表参考，不强制改。

- **mantavho vs paṭimantetu**（§395）：同一句里 "tumhe mayā saddhiṃ mantavho asmiṃ vacane" 与随后 "ambaṭṭho māṇavo mayā saddhiṃ paṭimantetū" 两个不同动词（前者"商议"，后者"应答"）都被并入"对答"一类表述，动词区分度不足，读者看不出两者语义差异。
  → 建议区分译法，如 mantavho→"与我商议此事"，paṭimantetu→"与我应答"。

- **391-2-48 出现文言虚词"便"**：「便把年长的几位王子逐出国境」——违反 `style.md` 禁例表（便=于是，应改"就"）。同一 chunk 其余处均已正确使用"就"，此处是孤例。
  → 必改：改为"就把年长的几位王子逐出国境"。

- 其余术语（Sakyā/释迦族、Kaṇhāyana/刚哈亚那族、dāsiputto/婢女之子、pubbapuriso/先祖、paṭimantetu/对答）在全 chunk 内译法统一，无漂移。
