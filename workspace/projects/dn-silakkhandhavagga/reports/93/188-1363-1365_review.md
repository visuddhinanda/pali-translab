## 严重问题：段落内容缺失

- **§1365 id 188-1365-78-82**：`zh` 只有「（问）」，**没有实际译文**。原文 `Anāgatavisayā hi ete vādāti?`（意为「因为这些主张是以未来为境的［，不是吗］？」）应独立成句译出，但目前该句的实际内容被并入了前一句 `188-1365-56-77` 的译文尾部（「因为这些主张所涉及的是未来的境域」），导致这一坐标下没有对应译文、只留了一个占位标记。**必改**：应拆回两句，各自对齐坐标，`78-82` 补出实译文，不要用“（问）”这类工作标记顶替译文。

## 文言残留（必改项）

依 `style.md` 禁例表，以下用了被禁的文言虚词「其」「便」：

- **§1363 id 188-1363-38-43**：「至于第四种主张，**其**成立则是依处所的差别」→ 改「至于第四种主张，它的成立则是依处所的差别」。
- **§1363 id 188-1363-176-208**：「这两组主张之间的区别**便**得以成立」→ 改「…就得以成立」。
- **§1364 id 188-1364-7-39**：「因**其**我微小而又有想」→ 改「因为这个我很小而又有想」。
- **§1364 id 188-1364-40-49**：「**其**我无量而又有想」→ 改「那个我无量而又有想」。

「其」在两段中反复出现（1364-7-39 与 1364-40-49 皆用「其我」指代同一类主张的“我”），属跨段重复的文言习惯，建议统一改法。

## 跨段一致性

- **diṭṭhigatika（持（邪）见者）译法不统一**：
  - §1363 无对应句
  - **§1365 id 188-1365-31-47**：译作「见有见者」——生造词，语义不清，容易被误读成「见到有见者」。
  - **§1365 id 188-1365-150-163**：同一词译作「持见解者」。
  → 建议统一为「持见解者」（或「持邪见者」，视上下文是否需强调是错误见解），并把 `188-1365-31-47` 的「见有见者」改掉。**必改**。

## 轻微风格建议（非必改）
