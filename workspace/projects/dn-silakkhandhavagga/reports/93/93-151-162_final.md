## 问题清单

### 🟧 error
- `93-153-21-48`｜漏译｜片段「先生，这个自我就达到了最上的现法涅槃。」
  - 问题：原文 "ettāvatā"（仅凭此／以此程度）未译出。该词是本节整段论辩的关键——正面主张说"仅凭此已达到"，随后反驳说"并未仅凭此达到"，两者需呼应；反驳句（154-28-40 / 155-29-41 / 156-28-40 / 157-28-40）都准确译出了"因此"，但对应的五处正面主张句（153-21-48 / 154-59-94 / 155-55-90 / 156-55-107 / 157-55-92）均系统性省略了该词，呼应关系在译文里弱化。
  - 建议：五处主张句统一补上"仅凭此"或"因此"，例如"先生，仅凭此，这个自我就达到了最上的现法涅槃。"，与反驳句保持对称。

- `93-162-26-46`｜义理或用词与注释书不符｜片段「也了知比这更深的」
  - 问题：nissaya 对 "uttaritaraṃ" 的释义明确所指"သီလ သမာဓိသဗ္ဗညုတာဉာဏ်တော်"（戒、定、一切知智），即如来证得的更殊胜的功德/果证，而非对同一批六十二见"更深层次"的理解。译作"更深的"容易让读者误解为如来只是对这些见解认识得更透彻，而非超越见处、证得道果与一切知智。
  - 建议：改译为"也了知比这更殊胜的（如戒、定、一切知智）"，或视需要加注说明所指内容。

### 🟦 suggestion
- `93-156-55-107`｜语言风格不统一｜片段「而住于舍」
  - 问题：全篇四种禅那公式统一用"进入并安住于……"句式，此句改用"住于舍"，与主导句式略有差异（不影响理解）。
  - 建议：如追求全篇统一，可改为"而安住于舍"。

- `93-158-24-56`｜语言风格不统一｜片段「施设有情最上现法涅槃的沙门或婆罗门」
  - 问题：同一短语在 152-2-21 / 158-2-23 作"施设有情的最上现法涅槃"（带"的"），此处省略"的"，前后措辞不完全统一。
  - 建议：统一补上"的"，改为"施设有情的最上现法涅槃"。
