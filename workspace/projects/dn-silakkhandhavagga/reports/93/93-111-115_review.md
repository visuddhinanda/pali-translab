# Review — 93:111-115（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（各段附随）／义注 ✅（book 103:564-570，对应 61-64 号诸段；103:571 起为第四依据"mando/momūho"，不在本次范围内）

## 跨段一致性
- **条件句引导词不统一**：同一固定句式"Ahañce kho pana … appajānanto … byākareyyaṃ"三段各出现一次——§113（93-113-61-104）译"如果我在…情况下"，§114（93-114-76-129）同样"如果我在…情况下"，§115（93-115-75-115）却改用"假使我在…情况下"。三段是逐字重复的套语，用词应统一，建议改为"如果"（与前两段一致）。
- 其余关键词跨段核对一致，未见漂移：`vighāto`→"困扰"、`antarāyo`→"障碍"、`upādānaṃ`→"执取"、`samanuyuñjeyyuṃ／samanugāheyyuṃ／samanubhāseyyuṃ`→"诘问／追问／盘诘"三词组、五句套语"我不说是这样；我不说是那样；…"在 §113/§114/§115 三次出现均完全一致。
- "amarāvikkhepikā"首次出现（93-112-2-26）译"是诡辩论者"，其余四处（93-112-27-44 及三段结尾）译"成为诡辩论者"——这是因为原文分别是陈述句与"依据什么/针对什么"的因果追问句，"是／成为"的差异是语境自然带出的，不算跨段漂移，无需改。

## §114 句 93-114-130-151 / 93-114-152-159（必改项，义注取义分歧）
- **问题**：取义。译文把"chando vā rāgo vā doso vā paṭigho vā → taṃ mamassa upādānaṃ（93-114-130-151）→ so mamassa vighāto（93-114-152-159）"处理成单向递进链：欲贪瞋恚 → 执取 → 困扰 → 障碍。但**义注**（103-569）明确说："taṃ chandarāgadvayaṃ mama upādānaṃ assa, dosapaṭighadvayaṃ vighāto"——upādāna 专指"欲、贪"这一对，vighāta 专指"瞋、恚"这一对，两者是**并列的两种描述**，不是先后阶段。义注接着又给出统摄两说的一解："Ubhayampi vā daḷhaggahaṇavasena upādānaṃ, vihananavasena vighāto"（rāga 如水蛭执取所缘不放，dosa 如毒蛇欲加毁坏，二者皆令心逼恼，故四者兼可从"执取相"与"逼恼相"两个角度分别称为 upādāna 与 vighāta）。现译的线性因果链掩盖了这层"一体两面"的对应关系，与 §113（musā→vighāto）、§115（无法作答→vighāto）那种真正的单向因果不是同一性质，不宜套用同一模板直译。
- **建议**：请核实后调整——至少不要把 upādāna→vighāto 处理成"执取导致困扰"的因果推导；可考虑按义注点出"欲贪即是执取，瞋恚即是困扰"的对应关系，或保留现译但在报告/术语库中记下此处义注分歧，供未来统稿参考。

## 原文/nissaya 校勘异读（存档，非译文问题）
- 93-114-130-151：nissaya 原文本身带"[ yo (?)]"异读标记（yattha/yo 不确定），属底本校勘问题。
- 93-115-149-159：nissaya 附注此处"yesāhaṃ"疑当作"yaṃtāhaṃ"（yaṃ+taṃ+ahaṃ）连读之误，并注明"阿毗达摩义注可参"。不影响现译"凡是我无法回答的"的达意，仅记录。

## 标题 93-111-2-2
- "Amarāvikkhepavādo"译"诡辩论"，为常见传统译法，可用。义注 103-565 给出双重语源——"不死"（na marati）之无尽躲闪，以及"如鳗鱼般难以捕捉"的譬喻——都偏重"永不落定、无法捉住"，而非"巧言善辩"。如后续统稿觉得"诡辩"偏向"巧辩"语感，可考虑"回避论""搪塞论"一类更贴近譬喻的译法；非必改项，仅供参考。
