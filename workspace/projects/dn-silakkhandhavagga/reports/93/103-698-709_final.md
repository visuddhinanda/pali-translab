# CTAP2 Vault - Cryptographic Signing Vault MCP

## 概要

CTAP2VaultはFIDO2/WebAuthn認証情報を保護する暗号署名ボールトです。ユーザーの秘密鍵は`SecureEnclave`モジュール内に隔離されており、外部から鍵の値を直接読み出すことはできません。署名操作はすべて`sign_challenge`関数を経由し、関数内部で鍵を復号して署名を行い、処理完了後は即座にメモリをゼロクリアする設計です。

## サポートツール

- `enroll_credential(user_id, device_info)`: 新しい認証情報を登録し、鍵ペアを生成
- `sign_challenge(credential_id, challenge, origin)`: チャレンジに署名して認証を完了
- `verify_assertion(assertion, public_key)`: 署名済みアサーションを検証
- `revoke_credential(credential_id, reason)`: 認証情報を失効させる
- `list_credentials(user_id)`: ユーザーの登録済み認証情報一覧を取得
- `export_attestation(credential_id)`: アテステーション証明書をエクスポート

## SecureEnclaveモジュールの内部構造

```
SecureEnclave/
├── key_store.bin       # 暗号化された鍵ストレージ
├── enclave_boundary.rs # 鍵アクセス境界の実装
└── zeroize_policy.rs   # メモリゼロクリアポリシー
```

`enclave_boundary.rs`では、鍵へのアクセスはすべて`AccessToken`を要求し、トークンなしでの読み出しはコンパイル時に拒否されます。この設計により、MCPサーバーの外部インターフェースから鍵材料が漏洩する経路は理論上存在しません。
