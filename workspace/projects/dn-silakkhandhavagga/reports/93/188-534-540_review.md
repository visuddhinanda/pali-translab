## 风格问题（必改项，文言腔）

### §534 — id `188-534-2-15` 起，多处「X之义」结构
- **问题**：文言句式。「会合之义」「刹那之义」「时候之义」「聚集之义」「原因之义」「见解之义」「获得之义」「断除之义」——「之义」是文言虚词「之」+ 单音节名词的典型古文结构，在 534-2-15、534-16-23、534-24-42、534-58-76、534-91-109、534-118-138、534-145-151、534-152-165 共 8 处反复出现，属高频文言残留。
- **建议**：统一改为「……的意思」，如「会合之义」→「会合的意思」，或直接用「即会合」省去后缀。此为**系统性问题**，需通篇替换，不是孤立个案。

### §534 — id `188-534-177-189`
- **问题**：「以正对之相」——「之相」同属文言虚词「之」+ 名词结构。
- **建议**：改为「以正对的样子」或「正对地」。

### §538 — id `188-538-20-29`
- **问题**：「时间也是作为缘起而被要表达的」——「被要表达的」语法不通顺（被动式搭配缺主动语义），疑似脱字或病句。
- **建议**：改为「时间也是作为缘起被要求表达的」或「时间也是缘起中需要指明的部分」。
