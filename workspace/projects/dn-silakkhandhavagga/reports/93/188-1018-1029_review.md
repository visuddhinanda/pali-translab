# Review — 188:1018-1029（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 被解释词与父层核对

- **§1018 id 188-1018-2-13**：黑体 `**Tathāya** **gato**` / `**tathaṃ** **gato**` 引自父层同一对短语。父层 103-409（`Tathāya gatotipi tathāgato, tathaṃ gatotipi tathāgato.`）已定稿译为「**因如实而至**」/「**行至真如**」，但本句译为「**如是而至**」/「**如是而去**」，与父层译法不一致，且「如是而去」实际对应的是另一 pali 表述（`tathaṃ gato`≠`tathā gato`），混淆了两个不同的词条。
  - **建议**：改为「'因如实而至'是就前三谛而说的，'行至真如'则是就最后一谛而说的」，与父层 103-409 逐字对齐。

## 跨段一致性

- `veditabbo`（了知）：父层多处（如 103-410、103-412）稳定译作「了知」；本 chunk §1019 id 188-1019-118-130 却译成「理解」（"用……作出了……对应说明"中的 "**这也应当这样理解其意义**"）→ 建议统一改为「了知」，依据：父层 103-412 原句 "Tassapi evaṃ attho veditabbo" 已定稿译为「这也应当这样了知其意义」。
- 其余「至」「了达」「经历」「行践」「如来」等术语在本 chunk 内部及与父层对照均保持一致，无问题。

## §1019 句 188-1019-118-130
- **问题**：术语一致性——见上「跨段一致性」条目。
- **建议**：「理解」→「了知」。

无其他必改项：段落语体统一为现代书面汉语，未见文言腔；其余黑体被解释词（如「世间」「阐明如来之所以为如来」「导向世间灭的道」等）与父层译文逐字相符。
