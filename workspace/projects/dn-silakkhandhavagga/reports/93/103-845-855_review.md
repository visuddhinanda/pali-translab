# Review — 103:845-855（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（除845首句、847、849、850外多数段落有）／义注 — 本层本身就是义注，注入的"父层对照"（93:310-311）内容与本 chunk 出现的黑体词（不痴正知、有益正知、前视/旁视等）不重叠，**无法据此核对被解释词逐字一致性**，此项从略。

## §845 句 103-845-66-126
- **问题**：风格/一致性 — 同一列举句中，部分弟子称号译文加了"……第一"（天眼第一、持律第一、说法第一、住阿兰若第一、多闻第一），另一些没有加（大智慧、大神通、行头陀行第一——此项又加了、喜好乞食、佛子），标准不统一。原文九项均为同构的 "mahāpañño / mahiddhiko / dhutavādo / dibbacakkhuko / vinayadharo / dhammakathiko / āraññiko / bahussuto / bhikkhākāmo / buddhaputto"，句法地位相同。
- **建议**：九项称号统一处理——要么全部按"……第一"格式（义注 nissaya 提示这是等达伽 aggasāvaka 语境，可支持"第一"译法），要么全部去掉"第一"改为纯定语（大智慧、大神通、行头陀、天眼、持律、说法、住阿兰若、多闻、乐乞食、佛子）。

## §853 句 103-853-86-94
- **问题**：术语 — "āgantukatā"（mūlapariññā āgantukatāva kālikabhāvavasena）译为"新生而暂时存在"，"新生"容易让读者理解成"新出生"，但原意是就心路过程而言"客位性/外来性"（相对于恒常的有分心而言，五门心路过程中的诸心是访客式、暂驻的），与"新生儿"义无关。
- **建议**：改译为"客位性"或"外来性"，如"应当依其客位性、暂时性来理解"。

## §846 句 103-846-92-94
- **问题**：译法可斟酌 — "atiharaṇavītiharaṇesu" 译为"移动脚和跨出脚"，但据 nissaya，atiharaṇa 指"越过原位、直到前脚落地为止的持续动作"，vītiharaṇa 指"为避开障碍物（树桩等）而侧移移送"，二者语义比"移动脚/跨出脚"更具体（一为直行推进，一为避让侧移）。
- **建议**：如篇幅允许可改为"直行送脚和避让送脚"一类更贴合 nissaya 的译法；若维持现译需在术语表中固定该译法，避免后续章节漂移。

## §846-847-848 跨段问题
- **问题**：跨段一致性/完整性 — nissaya 明确标注 103-846-180-185（"tasmiṃ tasmiṃ koṭṭhāse saddhiṃ rūpena"）应与 847 偈颂中的 "uppajjati / nirujjhati" 相接，即"心与色法一起生起、与色法一起灭去"。现译文中 846 段译为"在每一个部位，都是与色法一起的"，847 段单独译"这一个心生起，那一个心灭去"，二者拆开后"与色法一起"这一修饰未能落实到"生起/灭去"两个动作上，读者难以看出连接关系。
- **建议**：受限于按巴利段落切分不能合并译文，此为原文结构造成的局部损失，属于可接受的取舍，仅记录存疑，不强制改动（也可考虑在 847 译文末尾补一句"（皆与色法俱）"作为衔接提示，供参考）。
