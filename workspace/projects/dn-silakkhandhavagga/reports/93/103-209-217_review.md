# Review — 103:209-217（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 ❌（本 chunk 本身即义注层，无更上层义注）／父层对照（book=93）✅

## 跨段一致性（本 chunk 高频问题）

- **“之”字系统性残留**：本 chunk 多处使用文言虚词“之”，应逐一替换为现代白话结构。出现处：
  - §209 句 103-209-9-12：“所说**之**识” → 建议“所说的识”
  - §211 句 103-211-27-37：“所把握**之**境” → 建议“所把握的境”
  - §212 句 103-212-16-31：“听闻作用**之**识”“识**之**力”“听闻作用**之**名” → 建议“具足听闻作用的识的人，以识的力量，用从听闻作用中得来的名称”
  - §213 句 103-213-114-119：“两者**之**力” → 建议“两者的力量”
  - §215 句 103-215-41-49：“不适宜**之**地” → 建议“不适宜的地方”
  - §215 句 103-215-66-88：“旭日东升前的曙光**之于**太阳升起”“如理作意**之于**善业”“世尊**之**言” → 见下方单独列出，问题最严重
  - §217 句 103-217-2-23：“非善士**之**地” → 建议“非善士之地”改“不是善士的境地”
  - §217 句 103-217-24-28：“善士**之**地” → 建议“善士的境地”
  → **必改项**：全 chunk “之”字出现共 8 处以上，需统一替换为现代结构，这是文言腔的典型标志。

- **“其”字残留**：
  - §211 句 103-211-2-13：“把握种种义与文，就是指明**其**种种方式” → 建议“指明它的种种方式”
  - §215 句 103-215-2-36：“指明**其**种种方式”（同一短语重复出现，与 211 句几乎逐字相同）→ 与上句一并统一改法，两处应保持同一改法以维持跨段一致
  → **必改项**。

- **“依于”重复使用**（§213 两句）：
  - 103-213-37-52：“是因**依于**种种事物而说的”
  - 103-213-53-61：“是**依于**见等而说的”
  → “依于”是半文言介词结构，建议统一改为“依靠”或“依据”：“是因为依靠种种事物而说的”“是依靠见等而说的”。两句应保持改法一致。
