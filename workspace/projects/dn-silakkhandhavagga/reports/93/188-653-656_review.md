- **vaṇṇa / avaṇṇa**：188-656 译作「称赞」「诋毁」，与父层 103-256~322 一贯译法完全一致（「诋毁」「称赞」）。✅ 被解释词核对通过。
- **antevāsī**：188-656-76「antevāsī vaṇṇan」译「弟子的称赞」，与父层 103-264/273「antevāsī」译「弟子」一致。✅
- **ajjhāsaya**：188-654 译作「意乐」；父层 103-204「nānajjhāsayasamuṭṭhānaṃ」译作「意趣」。两处上下文虽不同（一为词条注释、一为叙述性文句），译法不完全统一，建议留意后续同词是否需要统一为「意趣」或「意乐」，此处不算必改项，仅记录以备术语表补录。
- 其余黑体词（anajjhiṭṭho / hāro / paripakkā / vimuttiparipācanīyā / khaya / khanti / mana / abhinīhāra / bujjhanabhāva / avekkhitvā / cattāro vaṇṇā / mahārājāno 等）在本轮提供的父层坐标范围（103:200-322）内均无对应黑体词条，无法核对，不代表无问题——若后续能取到本段对应的本文/义注坐标，应重新核对这些词是否有更早层级的定译。

## §655 句 188-655-2-12

- **问题**：**译文与释义自相矛盾**。原文 `**Cattāro vaṇṇā**ti cattāri kulāni, cattāro vā rūpādipamāṇā sattā.` 头词 `vaṇṇā` 被译作「四种**色**」，但紧接的释义第一义项却是「四种**种姓**」（kula）。此处 `vaṇṇa` 应取「种姓/族类」义（与下文「四大王」各守护一方种姓相呼应），而非「颜色」。头词译法与释义脱节，读者无法看出两者在说同一个词。
- **建议**：头词改译为「四种族类」或「四姓」，与「四种种姓」对齐；第二义项「或者是以色等为量度的四类有情」可保留「色」字，因为那里 `rūpādipamāṇā` 确指以色蕴等为标准划分的四类有情，两个义项本身并不矛盾，只是头词选错了字。

## §653 句 188-653-2-13

- **问题**：**加粗（黑体）标记未对应**。原文对 `attano ajjhāsayeneva katheti` 加粗，译文「只是凭自己的意愿而说」未加粗，与本 chunk 其余各处（如 188-656-322、188-656-440、188-656-499）黑体词均被如实保留加粗的做法不一致。
- **建议**：补上加粗，改为「**只是凭自己的意愿而说**」，与格式惯例统一。
