## 理由
- **资源缺失**：本次没有注入义注（这里是复注层，父层是《清净道论》本文）、nissaya，也没有注入父层译文。因此只能对照巴利原文核对准确性。被解释词是否与父层逐字同译无法核对，只查了本层内部的一致性。这是信心指数偏低的主要原因。
- **准确性**：整体理解可靠，句法主干基本没有误读。随观链（无常 → 苦 → 无我 → 厌离 → 离贪 → 灭 → 舍遣）和“生起、坏灭、变异”三相的解说都译得清楚。有两处疑似错译：
  - 1235 段 pākabhāva / vināsabhāva 被按“先无 / 坏无”理解。这和上一句“以‘有了’表示‘无’以生起为先”的论证方向相反。
  - 1232 段“灭随观”的第二种解释，从“使诸行灭而不再生”的作用义，被译成了随观的内容。
  - 另外有一处代词 tāya 漏译。
- 1231-153-169 的 khandhābhisaṅkhārehi，译文作“诸蕴和业行”，按并列复合词拆开。也可以理解为“产生诸蕴的业行”。两种读法都有依据，这里不扣分，只注明分歧。
- **风格**：全篇是现代书面汉语，没有发现文言虚词或文言句式。标点用全角，弯引号使用规范。只有个别句子层次偏密（1230 首句），另有少数指代不够明确。
- **一致性**：本层内部的被解释词前后对应良好：“使脱离”、“在观的刹那”、“从常想中”、“具备”、“无常随观”都与引文一致。有一处不统一：abhinandati 在相邻两句里分别译作“喜好”和“欢喜”。vatthu 前后分别作“所依的实体”和“实体”，也不统一。

## 问题清单

### 🟧 error
- `66-1235-39-43`｜错译（词义、修饰关系）｜片段「坏灭之后的无（坏无），以未生之前的无（先无）为先」
  - 问题：pākabhāva 是短 a 连写，应拆作 pāk + bhāva，意思是“先前的有”，不是 pāk + abhāva（先无）；vināsabhāva 是“坏灭的状态”。上一句刚说“无”以生起为先，所以用 hutvā（有了）。本句是承接那一句，说明坏灭必以先前的存在为前提。译文把它理解成“坏无以先无为先”，论证方向反了。
  - 建议：改为“这就显示：坏灭的状态以先前的存在为先”，或意思相同的译法。

- `66-1232-74-87`｜错译（修饰关系）｜片段「或者，这样随观：诸行只是灭去，将来不再以再有的方式生起」
  - 问题：yathā … evaṃ anupassanā 表示随观起作用的方式，意思是“以使诸行只是灭去、将来不再因再有而生起的方式随观”。下一句用“因为这是已经得力的欲解脱”说明理由，也支持这种作用义。译文把它译成了随观的内容，意思偏了。
  - 建议：改为“或者，以这样的方式随观，使诸行只是灭去，将来不再以再有的方式生起，就是灭随观”。

- `66-1231-17-36`｜漏译｜片段「所以作坏灭随观的修行者」
  - 问题：原文 tasmā tāya bhaṅgānupassako 里的 tāya（凭借那坏灭随观 / 那无常性）没有译出。对意思影响不大，但属于漏词。
  - 建议：补为“所以凭借它作坏灭随观的修行者”，或者根据复注的具体所指补出“凭借这种（坏灭）随观”。

### 🟨 warning
- `66-1234-55-71`｜导致误解的表达｜片段「所依的实体」
  - 问题：这里的 vatthu 指法本身（体），不是“所依处”。加上“所依的”容易让人联想到依处（如心所依处），而且和 1234-82-102 只作“实体”不一致。
  - 建议：删去“所依的”，统一作“实体”，或统一作“本体”。

- `66-1231-75-92`｜代词指代不明确｜片段「他就对它厌离」
  - 问题：tasmiṃ 指前面的 saṅkhāragata，译文前面刚说“诸行”，这里改用单数“它”，读者不容易对上。
  - 建议：改为“他就对这些行厌离”。

- `66-1230-2-29`｜整句逻辑表达不规范｜片段「或者由于定达到高峰、达到不动而完全正确地安住」
  - 问题：长句前半用“使它……”，分号后的“完全正确地安住”缺少主语，也缺少和“使”的衔接。“yathā … evaṃ 安置”的层次读不出来。
  - 建议：改为“……使心由于诸根平衡运作而不失衡，或者由于定达到高峰、达到不动而完全正确地安住——像这样以安止的方式来安置心”，或拆成几句。

### 🟦 suggestion
- `66-1231-67-74`｜语言风格不统一｜片段「凡是不应当欢喜的」
  - 问题：abhinanditabba 在上一句（1231-56-66）译作“喜好”，这里作“欢喜”，同一个词前后译法不同。
  - 建议：统一作“喜好”。

- `66-1231-153-169`｜不常用术语编写注释或者百科｜片段「舍弃的舍遣和投入的舍遣」
  - 问题：pariccāgapaṭinissagga / pakkhandanapaṭinissagga 是两个固定术语。用“……的舍遣”容易读成一般的偏正短语，看不出是术语。
  - 建议：按术语处理，作“舍弃舍遣”和“投入舍遣”，首次出现时夹注巴利原词，定名后登记到 terms.md。

- `66-1231-153-169`｜语言表达不够流畅｜片段「倾向与它相反的涅槃而投入涅槃」
  - 问题：“涅槃”在同一小句里重复出现，读起来拖沓。
  - 建议：改为“倾向并投入与它相反的涅槃”。

- `66-1234-72-81`｜代词指代可能不够明确｜片段「这称为刹那衰老」
  - 问题：yā 指 jarā，“这”可能被误读成指前面整个论证。
  - 建议：改为“这种衰老称为刹那衰老”。

- `66-1232-31-35`｜关键词语意不明确｜片段「也包括了心和见」
  - 问题：这里指常想之外，还包括与它同类的颠倒之心和颠倒之见（心颠倒、见颠倒）。只说“心和见”，读者不容易看出所指。
  - 建议：改为“也包括了（常）心和（常）见”，或加注说明“想、心、见三颠倒”。

- `66-1230-46-59`｜关键词语意不明确｜片段「不被对立面压伏」
  - 问题：paṭipakkha 在这里指定的对立法（诸盖等），“对立面”太宽泛。
  - 建议：改为“不被对立之法压伏”。

- `66-1232-88-92`｜语言表达不够流畅｜片段「已经得力的欲解脱」
  - 问题：“欲解脱”作名词，放在“得力的”后面，读起来别扭。
  - 建议：改为“这是已经变得有力的欲解脱（之心）”，或“这是强而有力的欲解脱”。
