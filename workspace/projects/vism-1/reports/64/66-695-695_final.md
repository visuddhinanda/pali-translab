## 理由

**资源缺失说明**：本次评估未注入义注（aṭṭhakathā）与 nissaya 数据——本段是复注（*Vinicchayakathāvaṇṇanā*，book 66），被解释的父层（义注 *Samantapāsādikā* 或相应论义注）文本与缅文逐词注解均不可得。因此「义注定释义、nissaya 定词法」两条基准都无法执行，准确性评分只能依据巴利原文本身的词法/句法、以及清净道论系统内部众所周知的禅支生起次第（*vitakka → vicāra → pīti → passaddhi → sukha → ekaggatā*）来判断。信心指数据此显著下调至 72。

**准确性**：整段是典型的复注体裁——引被释词（黑体）＋ 给同义替换。译文对这一体裁把握准确，绝大多数条目都正确还原了「A ti B」= 「A，是指 B」的释义结构。术语处理稳妥：*paṭibhāganimitta* 译「似相」并夹注巴利、*uggahanimitta* 译「取相」、*abhiniropanalakkhaṇa* 译「以令趣入为特相」、*ekaggatā* 译「心一境性」、*upacārajjhāna* 译「近行禅」，均合南传传统汉译。66-695-73-93 处理 *paṭi…pe…gamo* 的省略号复合词析词，把两段析词与最终释义分层译出，是全段最难的一句，处理得当。

扣分主要来自两处词义问题：`66-695-58-61` 与 `66-695-62-72` 把 *anumajjana* 译作「摩触」，而把 *anuvicaraṇa / anuparibbhamana* 译作「反复游行／反复盘旋」——*anumajjana*（< *majjati*，磨、擦、按摩）作为伺（vicāra）的作用，传统汉译多作「审察／随伺察」，「摩触」是逐字直译且对中文读者不可解；同一句内又用「游行」译 *anucaraṇa* 类词，二者共同把一个本已抽象的心所功能变成了两个物理动作。另有 `66-695-113-125` 的 *passaddhinimittaṃ* 与 `66-695-126-129` 的 *sukhanimittā*，译文统一作「以…为缘」，但紧随其后的释词分别是 *passaddhihetukaṃ*「以轻安为因」、*sukhapaccayā*「以乐为因」——复注正是用 *hetuka/paccayā* 来解释 *nimitta*，译文把被释词和释词都归并到「缘／因」一组，释义关系（A 是什么意思 → B）被压扁成了近义反复，读者看不出复注在解释什么。

**风格**：整体是合格的现代书面汉语，句子铺得开，没有文言句式堆叠。但仍有若干单音节文言词与文言虚词残留：「凡是那个…」句中的「以后」尚可，「作为它的相似形态的」偏翻译腔；`66-695-179-187` 的「用意是说」可，但「并不是只有…而已」略生硬。最突出的是 `66-695-73-93` 与 `66-695-94-96` 中「就叫做」「是指…的」结尾悬空的属格译法——「是指心与喜俱起的人的。」以「的」收尾成句，是为贴合巴利属格而牺牲汉语句子完整性，属第三类「不导致误解的汉语语病」。

**一致性**：跨句术语高度统一，*paṭibhāganimitta*「似相」、*nimitta*「相」、*passaddhi*「轻安」、*pīti*「喜」全段一致；黑体被释词与父层逐字同译的约束在可见范围内得到遵守（如 *tasmiññeva cā* 在 66-695-2-26 与 66-695-27-45 两句中均作「就在那个（相）上」）。`66-695-96` 与 `66-695-102-112` 两处 *pītimanassa* 同译「心中有喜的人」，引文与释词呼应正确。扣分点在 *nimitta* 一词：作「相」（似相、取相）与作「缘／因」（*passaddhinimittaṃ*）两义在段内并存而未作任何区分提示，属「关键词语意不明确，二意场合没有注释」。

## 问题清单

### 🟧 error

- `66-695-58-61`｜错译（词义）｜片段「对相的摩触，就是在似相上反复游行。」
  - 问题：*anumajjana* 译「摩触」系逐字直译（*majjati* 本义擦磨），用于伺（vicāra）的心所作用时不可解；*anuvicaraṇa* 译「反复游行」同样把抽象的审察活动物化。两个动作词并置，读者会误以为在描述某种触觉或位移。
  - 建议：*anumajjana* 依传统作「审察／随审察」，*anuvicaraṇa* 作「反复审察／随伺察」；如确要保留「摩触」的直译意味，应加夹注巴利原词并在首次出现处说明其为伺的作用。

- `66-695-62-72`｜错译（词义）｜片段「这就是**摩触的作用**」
  - 问题：同上，*anumajjanakicca* 沿用了「摩触」。本句用蜜蜂盘旋莲花之喻说明伺「反复审察所缘」，喻体（盘旋）与本体（摩触）在中文里对不上——喻是位移，本体却成了摩擦。
  - 建议：与 66-695-58-61 统一改为「审察的作用」，使喻体「反复盘旋」与本体「反复审察」在「反复」这一共同点上接榫。

- `66-695-113-125`｜义理或用词与注释书不符｜片段「**以轻安为缘的**，就是以轻安为因的**乐**」
  - 问题：复注的释义结构是用 *passaddhihetukaṃ*（以轻安为因）去解释被释词 *passaddhinimittaṃ*（以轻安为 nimitta），重点在于说明此处 *nimitta* 当作「因」解，而非「相」。译文把被释词译成「以轻安为缘」、释词译成「以轻安为因」，「缘」与「因」在汉语佛学语境中近乎同义，整句读来是同义反复，复注的解释意图丢失。
  - 建议：被释词保留 *nimitta* 的字面歧义（如「以轻安为相的」并夹注 *passaddhinimittaṃ*），释词作「就是以轻安为因的乐」，使「此处 nimitta 训为因」这一释义关系显露出来。

- `66-695-126-129`｜义理或用词与注释书不符｜片段「**以乐为缘的**，就是以乐为因的**心一境性**」
  - 问题：与上条同构，*sukhanimittā / sukhapaccayā* 被译为「以乐为缘／以乐为因」，同样压扁了被释词与释词的区别。
  - 建议：与 66-695-113-125 采同一方案改写，保持两句释义结构平行。

### 🟨 warning

- `66-695-113-125`｜关键词语意不明确（二意场合无注释）｜片段「以轻安为缘的」
  - 问题：*nimitta* 在本段前半（66-695-27-45、66-695-162-173、66-695-174-178）一律作「相」，到此处忽然转为「缘／因」义，段内两义并存而无任何提示，读者难以察觉这正是复注要解释的点。
  - 建议：在首次出现 *nimitta* 作「因」解处夹注巴利原词或加一句译者说明。

- `66-695-94-96`｜不导致误解的汉语语病｜片段「是指心与喜俱起的人的。」
  - 问题：以结构助词「的」收尾成句，汉语句子不完整。这是为贴合巴利属格 *pītisahitacittassa* 所致，但中文读者读到句号会觉得话没说完。
  - 建议：补全为「是指心与喜俱起的人」，属格关系交由上下文承担；或改为「（此词）指的是心与喜俱起的人」。

- `66-695-46-50`｜不导致误解的汉语语病｜片段「是指与该禅支相应的那个心的。」
  - 问题：同上，「的」字结尾断句。另 *attanā sampayuttacittassa* 的 *attanā*（与「自己」相应）译作「与该禅支相应」属合理补足，但「那个心的」中「那个」为增译且无所指。
  - 建议：改为「是指与自身相应的心」。

- `66-695-27-45`｜整句逻辑表达不规范｜片段「凡是那个像是把原样现起的取相打破以后现起的、作为它的相似形态的似相（paṭibhāganimitta），就在那个相上。」
  - 问题：单句内嵌三重定语（「像是…打破以后现起的」「作为它的相似形态的」）后接中心词，再以「就在那个相上」收束，定语总长超过中心词数倍，属复杂嵌套句，读者需回读才能理清。*paṭicchannabhūtaṃ* 译「作为它的相似形态」亦偏离——该词本义为「被覆盖的／隐蔽的」，此处指似相是取相的「覆影」。
  - 建议：拆为两句先释似相、再收「就在那个相上」；*paṭicchannabhūta* 参照 66-695-174-178 处已用的「影像」译法统一处理。

- `66-695-174-178`｜文言语体｜片段「是说作为与初禅相似的影像」
  - 问题：「是说作为…」句式生硬；且此处 *paṭicchannabhūtaṃ* 译「相似的影像」，与 66-695-27-45 同一词译「相似形态」不一致。
  - 建议：统一 *paṭicchannabhūta* 的译法，句式改为「指的是与初禅相似的影像」。

### 🟦 suggestion

- `66-695-2-26`｜语言表达不够流畅｜片段「为了以“由这些而舍断那些盖”这样从舍断的角度加以说明的方式，把禅支按各自的自相显示出来」
  - 问题：「为了以…的方式，把…显示出来」中间插入 27 字的引文与修饰成分，目的状语与主干被拉得过远。
  - 建议：拆分为「正因为如此，为了把禅支按各自的自相显示出来——即以“由这些而舍断那些盖”这种从舍断角度加以说明的方式——才说了…」。

- `66-695-73-93`｜语言表达不够流畅｜片段「殊胜本身因为是应当证得的，所以叫做殊胜的证得；已经获得的那个殊胜的证得，就叫做已获得的殊胜的证得。」
  - 问题：析词（*nibbacana*）译得准确，但「殊胜的证得／已获得的殊胜的证得」连续复现，中文读来像绕口令。此类析词句是复注体裁的固有难点，可考虑加简短译者注说明这是在拆解复合词。
  - 建议：在「就叫做…」后补一括注（如「以上为复合词析义」），帮助读者识别体裁。

- `66-695-179-187`｜语言表达不够流畅｜片段「用意是说：并不是只有舍断诸盖而已。」
  - 问题：*adhippāyo* 译「用意」可，但「并不是只有…而已」双重限定叠加，语气略拗。
  - 建议：改为「言外之意是：此时并非只是舍断了诸盖」。

- `66-695-130-161`｜该使用而没有使用术语标记｜片段「因为有“有乐的人，心就得定”这样的说法（长部 1.466；增支部 3.96、11.12）」
  - 问题：出处夹注格式与前面两处同类引文（66-695-102-112、66-695-113-125）不一致——那两处引文无出处，此处有。三条引文同属一组经证链（*pītimanassa kāyo passambhati / passaddhakāyo sukhaṃ vediyati / sukhino cittaṃ samādhiyati*），出自同一经文序列，建议统一处理。
  - 建议：三处引文或都补出处，或只在末句统一标注并说明涵盖前引。
