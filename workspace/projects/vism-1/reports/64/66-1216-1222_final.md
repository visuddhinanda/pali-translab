## 理由
- **资源降级**：本次只注入了巴利原文和译文，**没有注入义注（父层）和 nissaya**。所以释义没法按义注逐条核对，格位和句法角色也没法按 nissaya 逐词核对，准确性只能凭巴利原文判断，信心因此下调。加粗的被解释词是否与父层逐字同译也核对不了。另外，数据里每句的 `layer` 字段都是 `mula`，与本次标明的复注层不一致，这是数据标注问题，不影响对译文的评判。
- **准确性**：句子主干和义理判断整体可靠。几处较难的句子都理解正确：施事义属格（1220 段 tassā → tena、kattuatthe sāmivacanaṃ）、十九种省察的计数（阿罗汉无残余烦恼）、观智次第（生灭随观 → 坏灭随观 → 过患随观、厌离随观 → 欲解脱智等 → 种姓智 → 道智）、蛇穴的譬喻。没有发现主谓宾判断错误，也没有违背教理的地方。扣分主要在个别句子表达易生误解：1222 段 satokāritā / pītipaṭisaṃveditā 两个抽象名词的处理，以及 paṭisaṃvedī 一词构词解释的传达。
- **风格**：全篇是现代书面汉语，没有发现文言虚词或文言句式。标点全部用全角，没有残留工作标记。少数释词残句和长嵌套句读起来略拗口。
- **一致性**：同一个巴利词 paṭisaṃvidita 在譬喻里译成“察知”、在喻义里译成“觉知”，削弱了譬喻两边的对应。paṭisaṃvedī / saṃvedana 译成“觉知 / 觉受 / 感受”三种，使 paṭi- 的构词解释在汉语里看不出来。

## 问题清单

### 🟨 warning
- `66-1219-26-55`｜关键词语意不明确｜片段「“‘一再地觉受’就是‘觉知’（paṭisaṃvedī）”」
  - 问题：原文是在拆解构词：paṭisaṃvedī = paṭi（一再）+ saṃvedī（觉受）。但汉语“觉知”里看不出有“一再”的成分，读者无法理解这句构词说明。同段 1219-2-25 又把 vedanā / vedayamāno 译作“感受”，词形互相不对应。
  - 建议：在“觉知”后夹注构词，例如“觉知（paṭisaṃvedī，即 paṭi‘一再’+ saṃvedī‘觉受’）”。或者在本段内把 saṃvedana 系列统一译成“觉受”，让拆解能看出来。
- `66-1222-26-40`｜整句逻辑表达不规范｜片段「这里则是为了觉知喜」
  - 问题：原文的 satokāritā、pītipaṭisaṃveditā 都是抽象名词（正念而行的状态、觉知喜的状态），意思是“那里引圣典是就显示正念而行来说的，这里是就觉知喜来说的”。现在的译文容易被读成“这里引圣典的目的是去觉知喜”。前半句“显示成为正念而行的人”也把状态译成了人。
  - 建议：改为“那里引出圣典是为了显示正念而行，这里则是就觉知喜而言”。
- `66-1222-41-58`｜不导致误解的汉语语病｜片段「就是依作为所缘的长入息而了知的人，那喜就被觉知了」
  - 问题：pajānato 是施事义属格（与 1220 段的 tassā 同理），现在译成“……的人，那喜就被觉知了”，主语悬空，句子不通。
  - 建议：改为“就是对于依作为所缘的长入息而了知的人来说，那喜就被他觉知了”。
- `66-1222-91-107`｜代词指代不明确｜片段「现起于它的所缘」
  - 问题：tassa 指禅那，但这句的主语是“念”，读者容易把“它”理解成念。
  - 建议：改为“现起于禅那的所缘”。

### 🟦 suggestion
- `66-1220-63-97`｜语言风格不统一｜片段「那条蛇也就等于被察知」
  - 问题：譬喻和喻义用的是同一个词 paṭisaṃvidita，前面译“察知”、后面译“觉知”，两边的平行对应减弱了。
  - 建议：统一为“觉知”，或者都用“察知 / 觉知”这类能看出对应的译法。
- `66-1216-10-25`｜不常用术语编写注释或者百科｜片段「依观察与转离」
  - 问题：sallakkhaṇā、vivaṭṭanā、pārisuddhi 是入出息念八个阶段（数、随结、触、安止、观察、还灭、遍净、观彼）的专名。vivaṭṭanā 的通行译法是“还灭”，“转离”读者不易认出是阶段名。
  - 建议：改用“还灭”，首次出现时夹注巴利原词，并说明这是八阶段之一。
- `66-1216-43-53`｜语言表达不够流畅｜片段「是入出息的集起」
  - 问题：“集起”作名词表示“生起之因”，读者容易当成动词来读。
  - 建议：改为“显示身和心是入出息生起的原因”。
- `66-1217-171-176`｜语言表达不够流畅｜片段「而**有十九种的**（省察）」
  - 问题：释词残句的结尾“有十九种的（省察）”读起来生硬。
  - 建议：改为“……的区分，（省察）分为**十九种**”。
- `66-1218-2-13`｜复杂的嵌套句整句语言逻辑理解困难｜片段「是为依第一个四法已经证得禅那的人，依受随观、心随观和法随观而开示的」
  - 问题：两个“依”连用，还套了定语从句，读者很难一次读懂。
  - 建议：拆成两句，例如“因为（其余三个四法）是对已经依第一个四法证得禅那的人开示的，分别就受随观、心随观、法随观而说”。
