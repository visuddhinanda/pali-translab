# Review — 66:826-835（channel: 73c03e1a…，本层=复注 ṭīkā，父层=义注 book 64）

> 资源：pali ✅／父层义注译文 ✅（book 64, 1236-1271）／nissaya ❌（本次未注入，词级核对无法执行，格与句法判断仅据巴利原文与父层）

## 一、被解释词与父层逐字核对（首要）

已逐条比对全部黑体词。**以下为不一致项，均为必改**；未列出的黑体词（三千四百 / 三百五十 / 被称为 / 安立 / 如此安立 / 这里 / 也同样高出海面那么多 / 自须弥山起 / 依次为前者的一半 / 持双山 / 持轴山 / 巍峨 / 在须弥山的四周 / 雪山高五百由旬 / 名叫那伽 / 树干和枝条伸展五十由旬 / 向四周 / 宽达一百由旬，高也同样是一百由旬 / 由于这棵阎浮树的威势 / 金翅鸟的木棉树 / 尸利沙树 / 月轮 / 日轮 / 阿修罗的住处 / 阎浮洲 / 西牛货洲 / 东胜身洲 / 北俱卢洲 / 在这些轮围世界之间的空隙里 / 世界间的地狱 / 无边的 / 世尊用无边的佛智知道了）与父层译文逐字相同 ✅。

### 1. `66-826-10-13` **Cakkavāḷan**ti → 译「轮围」，父层同处（64-1236-12-26）作「一个轮围界（cakkavāḷa）」
- **问题**：被解释词断链。本条正是注 64:1236 那句里的 `ekaṃ cakkavāḷaṃ`，父层该处定稿译「轮围界」，本层译「轮围」。
- **附带**：父层自身不一致——1236「轮围界」、1270-33-39「一个轮围（cakkavāḷa）」、1268「轮围山」、1271「轮围世界」。
- **建议**：黑体处改为「所谓**轮围界**，就是指一个世界」，其后解释性行文（826-14-27「所以叫做“轮围”」）随之改为「所以叫做“轮围界”」；同时把父层 1236/1270 的不一致作为 harmonize 阶段的待统一项上报（本层不得自行改父层）。

### 2. `66-826-2-9` `Okāsaloko` → 译「器世间」，父层被引句（64-1271-14-18）作「空间世间」
- **问题**：本句是标出父层文句连读关系的引用，引的就是 64:1271「Evamassa okāsalokopi sabbathā vidito」，父层该处译「空间世间」，本层译「器世间」，对应关系断了。父层 1236-2-11 又作「器世间（okāsaloka）」——父层内部同样不一致。
- **建议**：术语统一为「器世间」（与父层 1236 及传统汉译一致），并把父层 1271-14-18「空间世间」列入 harmonize 待统一项。

### 3. `66-826-50-53` **Nahutānī**ti → 译「那由他（nahuta）」，父层把 nahuta 全部折算进数字
- **问题**：父层 1240「二十万，再加上四万」、1243「四十万，再加上八万」中，`nahutāni` 已被算成「万」，字面没有「那由他」，读者无从知道这条注在注哪个词。
- **建议**：补出桥接，例如「所谓**那由他**（nahuta，即上文“四万”“八万”中作单位的那由他），就是一万」。父层此处为折算译法，属不可机械对齐的情形，必须在本层显式点明。

### 4. `66-833-8-17` **Sattaman**ti → 译「第七」，父层同处（64-1266）作「共成七棵」
- **问题**：父层 `sirīsena bhavati sattamanti` 译「加上尸利沙树共成七棵」，黑体「第七」在父层译文里找不到落点。
- **建议**：「所谓**共成七棵**（sattamaṃ，字面是“第七”），是用了性的变换（liṅgavipallāsa）来说的，意思是尸利沙树成为第七棵。」

### 5.（低）`66-834-27-29` **Avīci** → 译「无间地狱」，父层作「无间大地狱」
- **问题**：父层 1270-12-17 译 `avīcimahānirayo` 为「无间大地狱」，多出的「大」来自 `mahā`，本层词头只有 `avīci`。读者尚能对上，属轻微。
- **建议**：可保持现译；若求严格，写「**无间**（大地狱）在阎浮洲的下面」。

## 二、跨段一致性

- **cakkavāḷa**：本 chunk 内有「轮围」（§826、§827）、「轮围山」（§826、§829）、「轮围世界」（§834、§835）三种。`cakkavāḷapabbata` 译「轮围山」正确（原文带 pabbata）；但单独的 `cakkavāḷa` 在 §826/§827 作「轮围」、在 §834-50/§834-56/§835-16 作「轮围世界」，需统一。建议：**词头处随父层作「轮围界」，行文中一律「轮围界」**，只有 `cakkavāḷapabbata` 作「轮围山」。
- **vadanti（`66-829-103-109`、`66-834-42-49`）**：两处都译「他们说」，中文里没有先行词，读者不知「他们」是谁。原文 `vadanti` 指传承诸师，父层 1264-25-27 对 `porāṇā` 定译「古代的论师们说」。建议统一改为「诸师说」或「有人说」。
- **引证套语**：`66-827-30-31`「这一点经中是这样说的」与 `66-829-66-97`「因为经中这样说过」尚属一致，但后者所引含《小品》（cūḷava. 384，属律藏），称「经中」不确。建议改为「因为圣典中这样说过」或「因为有这样的说法」。
- **「高出海面」系列**：§827、§829 用法与父层 1250「高出海面那么多」一致 ✅。
- 语体全 chunk 为现代书面汉语，未发现文言/半文半白句式 ✅（「巍峨」为父层定稿黑体，须保留）。

## §826 句 `66-826-2-9`
- **问题**：风格 — 「器世间也在一切方面被知道了」是被动式翻译腔；父层同一句作主动「世尊也就在一切方面知道了空间世间」。
- **建议**：「137. 这一句要与前文连读：（世尊）也在一切方面知道了器世间。」（术语按上文第 2 条统一）

## §826 句 `66-826-41-49`
- **问题**：准确性（轻） — `upaḍḍhacatutthāni` 意为「第四个只有一半」，即三个半；译文「第四个百只取一半」把 `satāni`（百）提前塞进了词义解释里，而 `satāni` 是词头后面才出现的成分。
- **建议**：「所谓**三百五十**（aḍḍhuḍḍhāni），就是三个半，即前三个之外第四个只取一半；意思是三百又五十。」

## §828 句 `66-828-2-28`
- **问题**：术语 — `Sineru pabbatarājā` 译「山王须弥」，语序拗口，传统定译为「须弥山王」。
- **建议**：「比丘们，须弥山王长八万四千由旬，宽八万四千由旬。」

## §829 句 `66-829-46-65`
- **问题**：可读性 — 「大海怎样一直到轮围山脚下都是逐渐低下去的，同样也一直到须弥山脚下都是这样」逐字直译后，「逐渐低下去」的方向不明，读者看不出这正是「持双山虽只没入一半仍能立在海底」的理由（海底由须弥山向外渐浅）。
- **建议**：补出方向，如「大海从须弥山脚下向轮围山脚下一路逐渐变浅（即由外向内逐渐加深），所以持双山……」；至少把两个分句的对比关系说清。

## §829 句 `66-829-66-97`
- **问题**：用词 — 「逐渐坡降」是现代水利术语，读来生硬；另「经中」不含律藏（见跨段一致性）。
- **建议**：「因为圣典中这样说过：“比丘们，大海是逐渐低下、逐渐倾斜、逐渐倾降的。”」

## §829 句 `66-829-98-102`
- **问题**：术语存疑 — `sīdantarasamudda` 译「山间内海」属解释性新译，传统汉译多作「私陀海／七内海」。本条不算错，但属未登记术语。
- **建议**：保留现译并在 `knowledge/terms.md` 登记；夹注已给巴利原词 ✅。

## §831 句 `66-831-24-37`
- **问题**：原文疑问（不改） — 巴利作 `…sākhāyāmā**ti ’ ubbedhato…`，`ti` 后有孤立的 `’`，且 `ubbedhato` 重复出现两次（`ubbedhato paññāsayojanakkhandhāyāmā , ubbedhato , samantato ca…`）。疑为 OCR/标点残留。译文按「树干就高度五十由旬、枝条在高度与四周各五十由旬」处理，方向正确。
- **建议**：记入 `knowledge/known-issues.md`，译文不动。

## §833 句 `66-833-2-7`
- **问题**：表述（轻） — `paccatte karaṇavacanaṃ` 是「在主格意义上使用的具格」，译文「用具格来表示主格的意思」尚可，但「主格的意思」易被读成语义而非格位。
- **建议**：「所谓**尸利沙树**，这里的具格是在主格的意义上用的。」

## §834 句 `66-834-2-8`
- **问题**：原文疑问（不改） — 巴利作 `caṇḍamaṇḍalaṃ`，下一句即作 `candamaṇḍalaṃ`，且父层 1270 为 `candamaṇḍalaṃ`，此处 `caṇḍa-` 应为 `canda-` 之讹。译文按「月轮」处理，正确。
- **建议**：记入 `knowledge/known-issues.md`。

## §834 句 `66-834-17-22`
- **问题**：存疑 — `yojanantarikāni` 译「彼此相隔一由旬」，把 `yojana` 读作「一由旬」的间距；缺 nissaya 无法核对该复合词是「相隔一由旬」还是「以由旬计的间隔」。
- **建议**：维持现译，把该句 `confidence` 压低；补取 nissaya 后复核。

## §835 句 `66-835-77-82`
- **问题**：准确性 — `vivaṭṭādīnaṃ` 译「对世界展开等等」过于笼统，读者不知所指；下文「后面讲神通的章节」指的是宿住随念智处所说的成劫坏劫（saṃvaṭṭa-vivaṭṭa）。
- **建议**：「不是也应当说到对世界的成立（vivaṭṭa）等等的了知吗？」并在首次出现处夹注巴利原词。
