**风格**：现代书面汉语，无文言虚词、无文言句式，未见 `knowledge/style.md` 第一节禁例表中的任何写法；标点全角、无 ASCII 引号、无工作标记残留。`64-341-10-12` 夹注巴利原词并加「即作用」「即近因」的处理，符合「混合受众」定位。唯一可议的是同句夹注密度偏高（四个括号连排），对一般读者略显拥挤，但不构成扣分项。

**一致性**：扣分集中在两处。其一，`64-339-2-21` 与 `64-339-22-173` 是同一句《无碍解道》引文的连续两段，前段把 `pahānaṃ sīlaṃ, veramaṇī sīlaṃ…` 译作「舍断是戒，离是戒…」，后段结尾重复同一串时也译「舍断是戒，离是戒…」——译法统一，这点是好的；但前段用「关于杀生」引出，后段改用「舍断偷盗、舍断欲邪行…」的动宾式，两段句式没对齐，读者不易看出后段是前段的同构展开（见 warning）。其二，`byāpādassa` 在同段内两次出现，均译「嗔恚」，一致；但 `abyāpādena byāpādassa` 译成「以无嗔舍断嗔恚」，前项用「无嗔」后项用「嗔恚」，同一词根译名不齐（见 suggestion）。

**跨层对齐**：本次只有本文一层，未注入义注/复注，被解释词逐字同译这一硬约束无从核对。若后续补译义注层，需回头复核 `sīlana` / `upadhāraṇa` / `samādhāna` 三词在本文的译名（持守 / 执持 / 安立）是否被义注层沿用——`64-340-30-37` 里 `samādhāna` 译「安立」，而 `64-340-14-29` 里同源的 `samādānaṃ` 译「受持」，本文层内部已有分歧，见 error 3。

## 问题清单

### 🟧 error

- `64-339-22-173`｜错译（词义）｜片段「以厌离随观舍断喜贪」
  - 问题：`nibbidānupassanāya nandiyā` 的 `nandī` 在《无碍解道》这组对治里指「欢喜、喜爱（于有的爱乐）」，与紧随其后的 `virāgānupassanāya rāgassa`（以离贪随观舍断贪）构成「厌离↔欢喜」「离贪↔贪」两组工整对应。译作「喜贪」把 `nandī` 和下一条的 `rāga` 混成一词，破坏了对应关系，也易与前文 `tatiyena jhānena pītiyā`（以第三禅舍断喜）的「喜」相混。
  - 建议：译为「以厌离随观舍断欢喜」或「…舍断爱乐」，与下条「舍断贪」区分开。

- `64-339-22-173`｜错译（词义）｜片段「以尽随观舍断密集想」
  - 问题：`khayānupassanāya ghanasaññāya` 的 `ghanasaññā` 是「坚实想 / 密集想」，指把相续、聚合、作用、所缘四种 `ghana` 误取为一整块实体的想。本段内 `adhipaññādhammavipassanāya sārādānābhinivesassa` 已把 `sāra`（坚实）译作「坚实」，此处 `ghana` 若也用「密集」，读者无法看出二者是相关而不同的概念；更要紧的是「密集想」在汉译传统中并非通行译名，单独出现意思不明。
  - 问题类别同时触及「关键词语意不明确」，按更高级别计入 error。
  - 建议：译为「以尽随观舍断坚厚想（ghanasaññā）」或「…舍断结块想」，首次出现夹注巴利原词；并与「坚实（sāra）」在注中区分。

- `64-340-14-29` / `64-340-30-37`｜义理或用词不一致（同源词译名分歧）｜片段「所以就是受持」与「被称为执持与安立的持守之义」
  - 问题：`samādānaṃ`（340-14-29）译「受持」，而同一论述链条下文的 `samādhāna`（340-30-37）译「安立」。这两处在《清净道论》原文里是同一概念的两次称名（`sīlana` 的第二义），指「令俱生法不散乱地齐置」。译名分裂后，读者读到「所以就是受持……被称为执持与安立的持守之义」会以为前文讲的两义是「执持/受持」，而结论却成了「执持/安立」，前后接不上。
  - 建议：两处统一。建议均作「安立」（或均作「等持/齐置」），并在首次出现处夹注 `samādhāna`；「受持」一词在戒学语境中已固定指 `samādāna`（受戒），此处用它会造成二次误解。

### 🟨 warning

- `64-339-22-173`｜关键词语意不明确｜片段「以省察随观舍断不省察」
  - 问题：`paṭisaṅkhānupassanāya appaṭisaṅkhāya` 直译为「省察↔不省察」，汉语里「不省察」作为被舍断的法（一个所断）读不通，像是把否定前缀原样搬过来。此处 `appaṭisaṅkhā` 指「不加简择、不作省察的状态」。
  - 建议：改为「以省察随观舍断不加简择」或「…舍断无简择的状态」，使被舍断项可作名词读。

- `64-339-2-21` / `64-339-22-173`｜整句逻辑表达不规范（句式不对齐）｜片段「“有五种戒：关于杀生，舍断是戒」
  - 问题：前段用「关于杀生，舍断是戒，离是戒…」的话题句式，后段起首却改为「舍断偷盗、舍断欲邪行…」的动宾罗列，直到段末才补上「舍断是戒，离是戒…」。原文里 `adinnādānassa, kāmesumicchācārassa…` 与前段 `pāṇātipātassa` 是完全同格的属格并列，共享段末那一串 `pahānaṃ sīlaṃ, veramaṇī…`。译文两段句式不同构，读者会误以为后段在讲另一件事。
  - 建议：后段起首改为与前段一致的属格话题式（如「关于偷盗、欲邪行、妄语……」），把「舍断」留到段末统一承接，或在前段末加一句过渡说明该结构贯穿到底。

- `64-339-22-173`｜关键词语意不明确｜片段「以坏灭随观舍断造作」
  - 问题：`vayānupassanāya āyūhanassa` 的 `āyūhana` 指「积集、努力造作（业的积聚）」，译「造作」单看会与 `saṅkhāra`（行/造作）相混，而 `saṅkhāra` 在论书中是另一个关键术语。
  - 建议：译为「舍断积集」或「舍断业的积聚（āyūhana）」。

### 🟦 suggestion

- `64-339-22-173`｜语言风格不统一｜片段「以无嗔舍断嗔恚」
  - 问题：`abyāpādena byāpādassa` 中同一词根的肯定项译「无嗔」、否定项译「嗔恚」，字面上「无嗔」对不上「嗔恚」。相邻各条如「以不散乱舍断掉举」也存在同类情形，但此条最明显。
  - 建议：统一为「以无嗔恚舍断嗔恚」，或前项作「以不嗔」。

- `64-341-10-12`｜该使用而没有使用术语标记 / 夹注过密｜片段「它的相（lakkhaṇa）、味（rasa，即作用）、现起（paccupaṭṭhāna）、足处（padaṭṭhāna，即近因）是什么？」
  - 问题：四个夹注连排，且其中两个额外带「即…」的解释，句子读起来是术语表而非问句。这四相是《清净道论》全书反复出现的固定框架，值得做成段后注释而非全塞进正文。
  - 建议：正文保留「相、味、现起、足处」四词，巴利原词与「即作用/即近因」的说明移入段后小字注（`style.md` 第四节允许的详释段形式）。

- `64-340-38-60`｜复杂的嵌套句整句逻辑理解困难｜片段「以及不违犯上述各项的人所具有的不违犯这几方面来说的」
  - 问题：`taṃ taṃ avītikkamantassa avītikkamanavasena` 的双重「不违犯」在一个定语套定语的结构里连出两次，中文读来绕。语法上没有错，但对读者不友好。
  - 建议：拆为两小句，如「以及，就不违犯上述各项的人来说，是从他的不违犯这方面来说的」。

- `64-339-174-234`｜语言表达不够流畅｜片段「导向资助，导向随从」
  - 问题：`parikkhārāya` / `parivārāya` 译「资助」「随从」虽有传统依据，但在「庄严、资具、眷属、圆满」这组比喻性排比中，「随从」作抽象名词略突兀。
  - 建议：可考虑「导向资具，导向眷属」，与「庄严」「圆满」的语域更齐。
