## 理由

**基准缺位（须先说明）**：本次只拿到复注巴利原文与目标 channel 译文，**未取到 nissaya，也未取到父层义注（《清净道论》本文及其义注）文本**。因此「义注定释义、nissaya 定词法」两条基准都无法直接核对：词法判断只能依原文格位与上下文推断，被解释词与父层的逐字同译约束（复注黑体引自义注）也无法逐条比对。下面的准确性结论据此下调信心；`66-340-28-65`、`66-343-47-56` 两处黑体引文与父层译文是否逐字一致，需在拿到义注层译文后复核。

**准确性**：整体句法判读正确，没有主谓宾判断错误，也没有违背教理的句子，故无 fatal。几处关键句的格位处理是对的——`66-343-57-91` 把 `lābhīnaṃ`（属格，得定者）与 `vuṭṭhitaṃ`（宾格，codenti/tudanti 的对象）分开处理，`66-343-92-121` 把 `manasi karoto` 的属格施事译为「对于把……作意为寂静、殊胜的人」，`66-342-7-32` 对「五分法第二禅中寻虽已离而离得不彻底、故须连伺一并超越」的论理链条复述准确。扣分主要在 `66-341-15-39` 的 `dhura` 取义（详见问题清单）。

**风格**：主体是现代书面汉语，全角标点、全角引号合规，`zh` 字段内未发现 ASCII 引号，译文中无候选/待定类工作标记。扣分点：`66-343-57-91` 出现文言虚词「即」；多处沿用巴利式名词化结构（「想与作意对欲等的侵入」「依照作为五种禅那支分的状态」），读感偏翻译腔；`66-342-2-6` 的多重「的」字定语嵌套对读者不友好。

**一致性**：`kāma` 与 `chanda` 在同一批段落里都译作「欲」，`66-340` 的「与欲俱行」和 `66-341` 的「欲定」并置时读者难以分辨，这是本批最实质的一致性风险。其次是平行句式的处理不齐：`66-343-57-91` 译出了 `tassa`（「由于他那些……」），`66-343-92-121` 的同构句则省略（「由于这些……」）；`66-343-28-37` / `38-46` 两条平行定义句式一致，这点做得好。黑体范围与巴利黑体基本对应，`66-343-92-121` 的黑体译文补入了「想与作意」（原黑体只到 `avitakkasahagatā samudācaranti`），属可接受的补足。

## 问题清单

### 🟧 error
- `66-341-15-39`｜错译（词义）｜片段「当作承担者」
  - 问题：`dhuraṃ katvā` 的 `dhura` 是「轭／重担／主导」，指所负之担或居首的主导地位，不是「承担的人」。译成「承担者」把一个心所（欲）说成了施事主体，也破坏了 `dhura / jeṭṭhaka / pubbaṅgama`（主导／为首／先行）这组同义递进的语感。
  - 建议：改为「把欲当作主导、当作为首者、当作先行者」，或「把欲当作所担之轭」。

### 🟨 warning
- `66-343-122-125`｜代词指代不明确｜片段「与它相应的定」
  - 问题：`Taṃsampayutto` 的「它」上承前句的 `visesabhāginī paññā`（胜进分的慧），但中间隔了一整句长句，单用「它」读者会误以为指第二禅。
  - 建议：改为「与那胜进分的慧相应的定，就是这里所指的」。
- `66-341-40-54`｜关键词语意不明确｜片段「这就叫做欲定」
  - 问题：此处「欲」是 `chanda`（意欲、志欲），而 `66-340-2-9`「与欲俱行」的「欲」是 `kāma`（欲乐、五欲）。同一批段落里两个不同的巴利术语共用一个汉字，且 `kāma` 处没有夹注，读者无从分辨——尤其 `66-343` 大段讨论的正是 `kāma` 侵入。
  - 建议：`chanda` 统一译「意欲」（首现夹注「意欲（chanda）」），或保留「欲定」但在 `66-340-2-9` 首现处补夹注「欲（kāma）」。
- `66-343-57-91`｜文言语体｜片段「即催逼、刺激」
  - 问题：「即」作「也就是」解，属文言虚词，`knowledge/style.md` 第一节列为禁例。
  - 建议：改为「也就是催逼、刺激」。
- `66-340-28-65`｜整句逻辑表达不规范｜片段「“对已得第一禅的人”等这段文句」
  - 问题：原文所引词句只到 `paṭhamassa jhānassā`（第一禅的），`lābhiṃ` 属 `tiādi` 省略的部分。引号内直接铺开成「对已得第一禅的人」，使引号范围大于原文实际所引。
  - 建议：引号只包被引的起始词、其余以「等」带出（如「“第一禅的”等这段文句」）；若为与义注层译文逐字对齐而保留现译，须确认父层该处译文与此完全一致。
- `66-343-28-37`｜不导致误解的汉语语病｜片段「就是从不熟练的第一禅等出定的人，他的想与作意对欲等的侵入」
  - 问题：「……的人，他的……的侵入」是巴利属格＋动作名词的直搬，中心语落在「侵入」上而主语中途换成「他的」，句子失衡。
  - 建议：改为「就是从不熟练的第一禅等出定之后，想与作意钻入欲等之中」。
- `66-343-38-46`｜不导致误解的汉语语病｜片段「就是从熟练的第一禅等出定的人，他的想与作意对第二禅等的侵入」
  - 问题：同上，平行句同一结构问题。
  - 建议：与上条统一改写，保持两条定义句式对称。

### 🟦 suggestion
- `66-342-2-6`｜复杂的嵌套句整句语言逻辑理解困难｜片段「就是在按四种分类来解说定的差别的那一段里」
  - 问题：三层「的」字定语连缀，读者需回读才能断开。
  - 建议：「就是在按四种分类解说定之差别的那一节里」或「就是在依四分法解说定的差别的那一段」。
- `66-340-10-27`｜语言风格不统一｜片段「以无寻为对象」
  - 问题：`visaya` 在佛典汉译中通常作「境／行境」，与前半句的「所缘」（ārammaṇa）构成术语对；「对象」是日常词，与「所缘」不成对。
  - 建议：改为「以无寻为境」。
- `66-340-28-65`｜代词指代可能不够明确｜片段「与那些慧相应的定」
  - 问题：`tāya paññāya` 是单数（具格），指前文所说的那一种慧；译作「那些慧」变成复数，虽可理解为泛指四种慧，但与原文数不合。
  - 建议：改为「与那慧相应的定也有四种」，如需泛指可作「与那（四种）慧相应的定」。
- `66-343-92-121`｜语言风格不统一｜片段「由于这些侵入第二禅中的想与作意」
  - 问题：原文有 `tassa`，与 `66-343-57-91`「由于他那些侵入欲中的想与作意」是同构句，此处略去后两句不再平行。
  - 建议：补为「由于他那些侵入第二禅中的想与作意」。
- `66-341-15-39`｜语言表达不够流畅｜片段「以……为增上」
  - 问题：用省略号占位作被释词，读者看不出所省为何；且与同段结尾「于是以欲为增上」重复。
  - 建议：改为「作为增上」或「使……成为增上」，具体取决于义注层该被解释词的译法（须与父层逐字一致）。
- `66-343-9-27`｜关键词语意不明确｜片段「所以本文这里才说」
  - 问题：`ettha` 指所注的本论（《清净道论》）此处，「本文」在中文里易被读成「这篇文章」。
  - 建议：改为「所以本论这里才说」。
- `66-342-33-41`｜语言表达不够流畅｜片段「分成两个」
  - 问题：`dvidhā bhinditvā` 是把一项拆为两分，「两个」量词空泛。
  - 建议：改为「分成两部分」。
- `66-343-57-91`｜语言表达不够流畅｜片段「想与作意频频现起」
  - 问题：`samudācaranti` 意为现起、现行，「频频」是译者添加的频率义（虽与语境不冲突）。
  - 建议：可作「想与作意现起」，如需保留反复义，在两处保持一致即可（目前两处一致，故仅作建议）。
