**准确性**：整体词覆盖良好，各遍处的神变清单逐项对得上原文并列结构，`evamādīni ijjhanti` 统一处理为「能够成就……等等」，一致且达意。主要扣分点集中在三处：`ummujjananimmujjana`（1081）译作「浮出和潜入」，原文语序为「浮出—潜入」，但该复合词在水遍语境中指在大地中出没自如，「浮出」置前在汉语里失去「钻入地中再冒出」的动作起点，属表达可能致误；`tejasā tejopariyādānaṃ`（1082）译「以火收摄火」，`pariyādāna` 在此传统释为「以自身火界吸尽（他人所放的）火」，「收摄」语意偏虚，读者难解；`Tena tena vā kāraṇena evaṃ pasāreti`（1091-29-35）与下句 `Ālokamiva…`（1091-36-39）在原文中是同一句意的承接（「或出于某种原因如此铺展，犹如欲以天眼见色者铺展光明」），译文把 `Ālokamiva` 的比喻单列为一句并补出「铺展光明」，补足成分虽合理，但两句断开后「或者是出于这样那样的原因」失去被比喻对象，逻辑链条略松。

**风格**：现代书面汉语落实到位，未见文言虚词或文言句式，`此中/彼等/是故/于…之际` 一类禁例均无出现，口语化程度也控制得当。全角标点统一，未见 ASCII 引号，符合 JSON 安全硬约束。`1090-12-17`「这一点是这样说的」属自然现代汉语，未沿用「即所谓」一类旧译腔，值得肯定。扣分来自个别术语未加首现夹注（见问题清单）。

**一致性**：十遍处段落（1080–1089）句式高度齐整，「凭借 X 遍」+「能够成就」+ 并列清单 + 「等等」的模板贯穿全段，被解释词黑体与父层一致。`abhibhāyatanapaṭilābha` 全段统一作「获得胜处」，`subhavimokkhādhigama` 统一作「证得净解脱」，`andhakāravidhamana`（1087/1088）同词同译「驱散黑暗」，`thinamiddhassa dūrabhāvakaraṇa` 两处亦一致。1087 与 1088 原文仅 `rūpadassanatthāya` / `rūpadassanatthaṃ` 一字之差，译文同样处理，合理。

## 问题清单

### 🟧 error
- `64-1082-2-28`｜错译（词义）｜片段「以火收摄火」
  - 问题：`tejasā tejopariyādānaṃ` 中 `pariyādāna` 意为「取尽、吸尽、令穷竭」，此处指以自身火界吸尽外来之火（传统释为扑灭他人所放的火）。「收摄」一词语意含混，既不表「吸尽」也不表「扑灭」，读者无法据此理解该神变内容。
  - 建议：改为「用火吸尽（别人放的）火」或「以火界消尽火」。

- `64-1081-2-14`｜导致误解的表达｜片段「在大地中浮出和潜入」
  - 问题：`ummujjana-nimmujjana` 指在地中如在水中一般出没自如。译文「浮出和潜入」中「浮出」在前，汉语读者会先读到一个无起点的动作，且「浮」字与「大地」搭配突兀，削弱了「视地如水」这一水遍神变的核心意象。
  - 建议：改为「在大地中像在水里一样钻进钻出」或「在大地中出没自如」。

### 🟨 warning
- `64-1080-2-29`｜关键词语意不明确｜片段「依照小与无量的方式获得胜处」
  - 问题：`paritta`（小）与 `appamāṇa`（无量）是胜处（abhibhāyatana）分类中的专门对举，直译为「小与无量」而无任何说明，一般读者无从判断所小、所无量者为何（指所缘相的大小）。
  - 建议：补夹注，如「依照所缘相为小（paritta）或为无量（appamāṇa）的方式」。

- `64-1084-2-13`｜关键词语意不明确｜片段「依照美色与丑色的方式获得胜处」
  - 问题：`suvaṇṇa-dubbaṇṇa` 在胜处语境中指所缘色相的「好色—恶色」，译作「美色」在现代汉语中易被读为「美貌女子」，属二意场合而无注。
  - 建议：改为「依照色相good好与丑陋的方式」，或保留原译并夹注巴利原词。

- `64-1085-2-15`｜关键词语意不明确｜片段「胜解为黄金」
  - 问题：`suvaṇṇanti adhimuccanā` 中「胜解」是法相术语首次在本段出现，按 `style.md` 第二节应于首次出现时夹注巴利原词；且「胜解为黄金」对一般读者而言语意不透明（意为决意将对象认定为黄金而令其成为黄金）。
  - 建议：改为「胜解（adhimokkha）为黄金」并酌情补足动作主体，如「决意把它认定为黄金」。

- `64-1091-29-35`｜整句逻辑表达不规范｜片段「或者是出于这样那样的原因而这样铺展开去」
  - 问题：该句与下一句 `Ālokamiva…`（`64-1091-36-39`）在原文中构成「如此铺展——犹如欲见色者之于光明」的完整比喻。译文断为两句后，本句的「这样铺展开去」缺少指向，下句的「就像……那样」也悬空，读者须回溯两句才能接上。
  - 建议：合并为一句，如「或者出于这样那样的原因而如此铺展开去，就像想用天眼看见色法的人铺展光明那样。」

- `64-1090-2-11`｜关键词语意不明确｜片段「上、下、横、无二、无量这样的分类」
  - 问题：`advaya`（无二）是本段随后专门解释的术语，此处首次出现时读者尚无概念，且「无二」在汉语佛教语境中另有「不二法门」的强烈既有联想，易被误读为中观义的「不二」。
  - 建议：此处可加夹注「无二（advaya）」，与下文 `64-1091-44-51` 的解释呼应。

### 🟦 suggestion
- `64-1082-2-28`｜语言表达不够流畅｜片段「凡是他想烧的，都有能力把它烧掉」
  - 问题：`yadeva so icchati tassa ḍahanasamatthatā` 原为名词性短语（「对凡所欲者的能烧性」），与前后各项并列。译文改为小句后，「他」的指代在通篇第三人称叙述中首次单独出现，且与前后并列项的句式不齐。
  - 建议：调整为名词性表达，如「能够随意烧掉自己想烧的任何东西」。

- `64-1089-2-15`｜语言表达不够流畅｜片段「把被遮蔽的东西变成敞开的」
  - 问题：`paṭicchannānaṃ vivaṭakaraṇaṃ` 指令被遮蔽者显露。「变成敞开的」偏口语且略拗口，与同段其余各项的书面语体略有落差。
  - 建议：改为「使被遮蔽的东西显露出来」。

- `64-1091-52-72`｜语言表达不够流畅｜片段「它里面不会混进别的遍处」
  - 问题：`natthi tassa añño kasiṇasambhedo` 意为「它没有与其他遍处的混杂」。「混进」带有外物侵入的动态意味，与前半句「四面八方都只是水」的静态陈述不完全对称。
  - 建议：改为「它不会与别的遍处相混杂」。
