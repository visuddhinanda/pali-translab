## 理由

**基准缺失（影响信心）**：本次只注入了巴利原文与待评译文，**没有 nissaya、没有义注（对复注而言即《清净道论》本文及其被释词的译文）**。本段是 Paramatthamañjūsā 对《清净道论》缘起部分"evaṃ pucchito sabbadhammesu appaṭihatañāṇacāro devadevo…bhagavā imaṃ gāthamāha"一串德号的逐词解释，**被解释词必须与本文层逐字同译**，而本文层译文未随附，无法核对（如 `antojaṭā`「内结缚」、各德号的定译）。因此词级核对只能依据原文形态与上下文，信心相应下调。

**准确性**：绝大多数句子取义正确，`devā` 的语根释义（kīḷā / vijigīsā / vohāra / juti / gati）六义、`devadevo` 两解、`sakkānaṃ atisakko` 等德号释、38 段"设疑—遮遣"的行文逻辑都译对了，经证出处（ma.ni.1.150、a.ni.4.8、a.ni.10.21、vibha.809、visuddhi.1.123）转写无误。主要扣分在**层次归属错误**：两处把 `dassento…āha / avoca` 的主语补成"（复注作者）"，而这两处说话的是**本文作者（阿阇梨）**——复注在解释本文的用词，不可能是自己说了又自己解释。这属于 error（代词/指代错误），且同一错误重复两次，说明是系统性的补主语习惯，须一并修正。另有若干处复合词辖域不清（`sakkāradānaggahaṇa` 一族）与小词漏译（`tato` 的比较义），归入 warning。

**风格**：整体是现代书面汉语，标点全角、无 ASCII 引号、无直角引号、译文中无任何候选/待定工作标记，符合硬约束。扣分点是残留的文言成分（"之力""以敬信而爱乐""如此而""于此"）以及 66-36-123-177 这一 200 余字的超长单句，对普通读者不友好。

**一致性**：跨句的德号译法完全统一（于一切法中智行无碍 / 天中天 / 诸帝释中的超帝释 / 诸梵天中的超梵天 / 持十力者 / 无障碍智者 / 普眼 / 世尊），`nissaṅgacāra`「智的行进没有黏著」在 36 与 38 两段一致，37 与 38 段末尾两句同源句式（`āgamissati` / `vakkhāma`）也正确区分了"讲到"与"我们将讲述"。粗体标记与原文 lemma 一一对应，无遗漏。

## 问题清单

### 🟧 error
- `66-36-17-36`｜代词指代错误｜片段「（复注作者）以“唯有这样的人才能解答这个问题”之意」
  - 问题：本段是复注在解释《清净道论》本文的德号串，`satthāraṃ guṇato dassento…āha` 的主语是**本文作者（阿阇梨）**——正是他说了"sabbadhammesu appaṭihatañāṇacāro"等语，复注才逐词加以解释。补成"复注作者"把说话人归错了一层。
  - 建议：改为「（阿阇梨）」或「《清净道论》的作者」；全篇统一一种称呼。
- `66-38-125-138`｜代词指代错误｜片段「（复注作者）就说了“世尊”」
  - 问题：同上，`dassento ‘‘bhagavā’’ti avoca` 的主语仍是本文作者；"世尊"是本文德号串的最后一个词，由复注解释其成立之由。
  - 建议：与上一条统一改为「（阿阇梨）」。

### 🟨 warning
- `66-36-50-65`｜代词指代不明确｜片段「世尊的这些不共法也一并被涵摄在内了」
  - 问题：`sesāveṇikadhammā` 是"其余的不共法"，而"这些"紧接在"最初的三种"之后，容易被读成那三种，使整句变成同语反复。
  - 建议：改为「世尊其余的那些不共法也一并被涵摄在内了」。
- `66-36-66-99`｜关键词语意不明确｜片段「他们行使权势财富等恭敬的施与受」
  - 问题：`issariyadhanādisakkāradānaggahaṇaṃ` 是"以权势、财富等敬奉之物作施与受"，"权势财富等恭敬"读不通，"行使…施与受"搭配也不成立。
  - 建议：改为「他们以权势、财富等敬奉之物互相施与、受取」。同类结构见 66-36-123-177，宜一并统一。
- `66-36-66-99`｜文言语体｜片段「因殊胜福德之力而得到的光辉」
  - 问题：文言虚词"之"。
  - 建议：改为「因殊胜福德的力量而获得的光辉」。
- `66-36-66-99`｜文言语体｜片段「如此而行事往来」
  - 问题：「如此而」为文言连接。
  - 建议：改为「他们就是这样往来行事的」。
- `66-36-123-177`｜整句逻辑表达不规范｜片段「心自在、七圣财（sattadhana）等正行，以及不坏净信（aveccapasāda）、恭敬的施与受」
  - 问题：「施与受」的辖域不清——原文是"正行、不坏净信、恭敬"三者共受"施与受"支配，现在的断法读起来像只有后两者。
  - 建议：改为「也就是对心自在、七圣财（sattadhana）等正行，以及不坏净信（aveccapasāda）与恭敬的施与、受取」。
- `66-36-123-177`｜文言语体｜片段「以敬信而爱乐」
  - 问题：半文半白。
  - 建议：改为「因敬信而对他心生爱乐」。
- `66-37-33-74`｜导致误解的表达｜片段「（我看不出有任何根据能据此如法地责难我，因此）」
  - 问题：在"（中略）"之后用括号补出了被 `…pe…` 省略的整段经文，读者会误以为这是复注所引原文的一部分；复注在此是**有意省略**的。
  - 建议：删去补文、只保留「……（中略）……我达到无所畏而安住」，需要说明时放脚注。
- `66-38-33-60`｜关键词语意不明确｜片段「那么这一位又有什么殊胜之处呢」
  - 问题：`tato`（比起帝释）的比较基准未译出，疑问句失去了对照对象，"这一位"也显得悬空。
  - 建议：改为「那么，比起他，这一位（世尊）又有什么殊胜之处呢」。
- `66-38-61-86`｜关键词语意不明确｜片段「那么这一位又有什么超胜之处呢」
  - 问题：同上，`tato` 指"比起常童子等诸梵天"。
  - 建议：改为「那么，比起他们，这一位又有什么超胜之处呢」。

### 🟦 suggestion
- `66-36-100-115`｜语言表达不够流畅｜片段「他们是“可趋往的”（devanīyā）」
  - 问题：`devanīyā` 下面同时由 `gamanīyā`（可前往投靠）、`abhitthavanīyā`（值得赞颂）、`kamanīyā`（令人爱乐）三个同义释共同解释；先把它定译成"可趋往的"，再接"或是值得赞颂的"，字面上自相矛盾。
  - 建议：先给一个中性译（如「他们是应当被趋求的」），再列三释。
- `66-36-123-177`｜复杂的嵌套句｜片段「而世尊具足无与伦比的神通游戏」
  - 问题：整句两百余字一气呵成，六个"具足…"加两个"又因为…"，对读者极不友好；其中"智慧之身"连用两次，"之"的文言味也较重。
  - 建议：拆为三到四句（先列六项具足，再说"因此含天的世间……"，最后收"所以称为天中天"）；"智慧之身"可作「智慧之身（paññāsarīra）」首次夹注后保留，或改为「慧身」并登记术语表。
- `66-37-81-111`｜语言风格不统一｜片段「于此，如来如实地了知处为处」
  - 问题：「于此」是文言译经腔，与全篇现代语体不一致。
  - 建议：改为「在这里，如来如实地了知处为处、非处为非处」。
- `66-36-2-16`｜术语标记｜片段「以“内结缚”等话发问」
  - 问题：`antojaṭā` 引自《清净道论》所载偈颂，属**被解释词**，必须与本文层译文逐字一致；本次未获本文层译文，无法核验。
  - 建议：harmonize 时回查本文层该偈的译法（"内结""内缠"等），两层取同一写法。
