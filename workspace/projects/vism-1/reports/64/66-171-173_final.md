## 理由

**取数条件（降级说明）**：本次评估仅拿到巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未注入**。本文层是《清净道论》/《律》系统的注释体（此处为复注 ṭīkā，book=66 *Paccayasannissitasīlavaṇṇanā*），复注的黑体被解释词本应逐字对齐到义注（Visuddhimagga / Sāratthadīpanī 系）的用词，而义注文本缺失，因此"被解释词与父层逐字同译"这条硬约束**无法核验**。准确性分数只能基于巴利内部文法、复注自身的训诂结构（`X ti Y` 释义链）与教理常识给出，信心指数因此压到 68。下列判断中凡依赖义注措辞的，均已在条目内标注"待义注核对"。

**准确性**：整体训诂链条读得准。复注典型的"以词释词"结构（`Byābādhanaṭṭhena byābādho`、`Natthi ettha byābajjhanti abyābajjhaṃ`）译者都还原成了中文可读的推导句，没有译成词表式堆砌，这点做得好。扣分集中在三处：`paṭiayanaṭṭho` 一句的中文把"相"的归属绑错了对象（fatal 级的主谓宾判断问题）；`Samudānetabbā` 的 `uddhaṃ uddhaṃ` 释义取义可疑；`Bhisakkassa kammaṃ` 一句的复合词解读（属格关系）与下句 `tena anuññātattā` 的逻辑衔接对不上。另有两处黑体被解释词的中文与其后释义自相矛盾（`Parivāropi hoti`、`rakkhaṇato`），属于同段内部一致性失守。

**风格**：现代书面汉语的要求基本守住，没有出现"此中／故为／彼等／是故"一类硬文言。残留的是半文半白的边角：`夺命……乃至……`、`备办`、`四周遮挡`、`沿用该物的名称`。其中"备办"属于旧译腔，`pe`（peyyāla）的省略号处理保留了巴利体例但中文侧没有给读者任何提示。标点全角、无 ASCII 引号残留、无工作标记（候选/待定/问号），这几条硬约束均通过。

**一致性**：`parikkhāra` 在三个句子里出现三种中译——"资具"（`nagaraparikkhārā`、`jīvitaparikkhārā`、`parikkhāro`）与"配备"（`parivāro`）。后者对应的巴利词其实是 `parivāra` 不是 `parikkhāra`，所以差异本身合理，但中文"配备"与"资具"在读者眼里区分不出，需要术语标记或夹注。`dukkha` 统一译"痛苦"、`vedanā` 统一译"受"、`dhātukkhobha` 统一译"界的扰乱"，跨三段稳定。术语首次夹注巴利原词的规则执行得不齐：`byābādha`/`byābajjha`/`samudānetabbā` 夹注了，`paccanīkagamanaṭṭha`、`abyābajjha`、`rasāyana` 没夹。

## 问题清单

### 🟥 fatal

- `66-171-2-9`｜主谓宾判断错误｜片段「**疾病** 以界的扰乱为相，或者以由此引起的苦受为相；与疾病相对立、能够对治疾病，就是 **逆着而行的意思**」
  - 问题：原文 `Dhātukkhobhalakkhaṇassa, taṃhetukadukkhavedanālakkhaṇassa vā rogassa paṭipakkhabhāvo paṭiayanaṭṭho` 中，两个 `-lakkhaṇassa` 是属格定语，修饰同为属格的 `rogassa`，整块是 `paṭipakkhabhāvo` 的对象；主语是 `paṭipakkhabhāvo`，谓语性成分是 `paṭiayanaṭṭho`（"……就是 paṭiayana 的意思"）。译文把黑体 `rogassa` 提到句首作主语另起一句"疾病以界的扰乱为相"，等于把定语关系拆成了独立判断句，主谓宾关系判断错误。更关键的是，被解释词 `rogassa` 在原文是属格（"对于……的病"），译文的"疾病"脱格后失去与 `paṭipakkhabhāvo` 的依存，读者会读成复注在给"疾病"下定义，而复注实际在解释 `paṭiayana`（对治）一词。
  - 建议：按"对于以界的扰乱为相、或以由此引起的苦受为相的**疾病**而言，处于对立的状态，就是 **逆着而行的意思**"重组，使 `rogassa` 保持属格定语身份，主语归还 `paṭipakkhabhāvo`。黑体范围需与义注被解释词逐字对齐（待义注核对）。

### 🟧 error

- `66-171-106-113`｜错译（词义）｜片段「就是应当正当地、不断地取来」
  - 问题：`sammā uddhaṃ uddhaṃ ānetabbā` 中 `uddhaṃ uddhaṃ` 的叠用在此训诂式里是拆解 `sam-ud-ā-nī` 的构词（`saṃ` → `sammā`，`ud` → `uddhaṃ`，`ā-netabbā` → `ānetabbā`），意为"向上、向上地取来"，即从各处收集聚拢；译成"不断地"取了时间频率义，丢了这句作为**词源拆解**的性质。译文读者会以为复注在讲态度，而非在拆词。
  - 建议：译为"就是**正当地、向上向上地（即从各处收聚地）取来**，也就是应当去寻求"，或在括注中点明这是对 `sam-ud-ā-nī` 的逐音节拆释。待 nissaya 核对缅文助词是否支持方向义。

- `66-171-37-41` / `66-171-42-50`｜错译（修饰关系）｜片段「**医生的处置**——因为它要由医生来安排」
  - 问题：`Bhisakkassa kammaṃ tena vidhātabbato` 的 `tena`（具格，"由它/由他"）与下句 `tena anuññātattā`（"由于被它/他所许可"）应同指。译文首句把 `tena` 解为"由医生"，次句"由于是经医生许可的"也解为医生，表面一致；但若 `tena` 指医生，则 `Bhisakkassa kammaṃ`（医生的工作）由医生安排是同语反复，复注不会作此无信息量的注解。更可能的读解是复注在解释为何某物称为 `bhesajja`/医生之业——`tena` 指前文的所缘物。译文的因果链在中文里读成循环论证。
  - 建议：核对义注原句后重订 `tena` 的指代；若确指医生，也应改写为"**医生的处置**——因为这要由医生来决定用法"以避免同语反复。此条依赖义注，待核对。

- `66-171-114-119`｜导致误解的表达｜片段「**也是配备**——因为它能从四周遮挡各种障难」
  - 问题：黑体 `Parivāropi hoti` 译作"也是配备"，但紧接的释义 `parito vāraṇato`（从四周遮挡）讲的是**随从护卫**之义；"配备"是物件义，与"遮挡障难"的施动性对不上，读者无法把黑体词与释义连起来。`parivāra` 在此语境（承接 `nagaraparikkhāra` 守城之喻）应取"随从／护卫"。
  - 建议：改为"**也成为护卫**——因为它能从四周遮挡各种障难"，并与 `66-172-10-20` 的"侍从"意象统一。

- `66-172-10-20`｜代词指代错误｜片段「它也这样 **守护**」
  - 问题：原文 `…ṭhitasevakā viya rakkhaṇato` 是"因为像……侍从那样守护"，`rakkhaṇato` 是夺格因由，承接前一句 `66-171-114-119` 的 `Parivāropi hoti` 作理由。译文补出的主语"它"在本句内无先行词——上一句的主语被译成了"也是配备"（物），此句"它"却在作侍从般的守护（施动者），指代断裂。且 `-to` 的因由语气被译成了陈述"它也这样守护"，丢了"因为……所以称为 parivāra"的论证结构。
  - 建议：改为"因为它**守护**，就像围在自己主人周围站立的侍从不给仇敌留下可乘之机那样"，保留夺格因由并接上前句。

### 🟨 warning

- `66-171-120-131`｜文言语体｜片段「**“夺命……乃至……从而守护（生命）”**」
  - 问题：「夺命」为单音节文言构词，且此处是引述义注原句的截断形式（`jīvita … pe … rakkhaṇato`），`jīvita` 单独出现时未必是"夺命"，译者对省略部分作了不该作的补足。另 `pe`（peyyāla）译作"乃至"属文言虚词。
  - 建议：引述截断处保留巴利词 `jīvita`（生命）不作推断，`pe` 处用"（中略）"。待义注核对被省略的原句。

- `66-171-106-113`｜文言语体｜片段「**应当备办**」
  - 问题：「备办」为旧译腔单音节复合，现代读者不常用。
  - 建议：改为"应当置备"或"应当筹集"。

- `66-172-61-73`｜关键词语意不明确｜片段「可以沿用该物的名称」
  - 问题：`tabbohāro`（对它的称呼／名言施设）是术语性表达，"沿用该物的名称"把 `vohāra`（世俗名言）的术语性抹平了；且"该物"与"与某物相似的东西"在一句内两次转指，中文读者难以定位。
  - 建议：改为"因为对于与某物相似的东西，可以施用**指称那个东西的名言**（vohāra）"，并首次出现夹注巴利原词。

- `66-172-38-60`｜整句逻辑表达不规范｜片段「虽然通过受用药物而被消除的，其实是还没有生起的苦受，而不是已经生起的苦受——因为已经生起的苦受依着自身的自性就会坏灭——但是那些与已生起的相似的苦受，也被称为“已生起的”」
  - 问题：单句 88 字、含一个破折号插入的因由从句与一个"虽然……但是"转折框架，三层嵌套。意思正确但对读者不友好，属复杂嵌套句的可读性问题。
  - 建议：拆为三句：先述"被药消除的其实是尚未生起的苦受"，再述理由，最后述"相似者亦名已生起"。

- `66-172-114-122`｜术语标记不一致｜片段「所以叫作恼害（byābādha）；恼害本身也就是恼害（byābajjha）」
  - 问题：`byābādha` 与 `byābajjha` 两个不同巴利词译成同一个中文"恼害"，靠括注区分，中文读者读到"恼害本身也就是恼害"会认为是排印错误。复注此句正是在建立两词的同义转换，需要在中文侧显出差别。
  - 建议：给 `byābajjha` 另立中译（如"所恼害者／被恼害性"），或改写为"恼害（byābādha）这个词本身，也就是 byābajjha"。

- `66-172-123-129`｜术语标记未用｜片段「所以叫作 **免于恼害**」
  - 问题：`abyābajjhaṃ` 是三段内反复出现的关键术语（`66-172-130-139` 再次出现），首次出现未夹注巴利原词，与同段 `byābādha`/`byābajjha` 的处理不一致。
  - 建议：首次出现处补夹注"**免于恼害**（abyābajjha）"。

- `66-171-73-77`｜关键词语意不明确｜片段「**用戒做资具**」
  - 问题：`Sīlaparikkhāro` 是被解释的复合词（持业释／有财释待定），译作动宾结构"用戒做资具"，与同段其余 `-parikkhāra` 一律译名词短语（"城市的资具""生命的资具"）不一致，读者看不出这是同一构词系列。
  - 建议：统一为"**以戒为资具**"。

### 🟦 suggestion

- `66-171-57-72`｜术语注释缺失｜片段「外围的围障、壕沟、土垒、城墙、门柱、门闩、城墙内侧的平地」
  - 问题：七种守城设施（`vivaṭaparikkhepa` / `parikkhā` / `uḍḍāpa` / `pākāra` / `esikā` / `paligha` / `pākārapatthaṇḍila`）是不常用的古印度城防术语，其中"门柱"（esikā，实为城门前的石柱）与"土垒"（uḍḍāpa）的中译对普通读者不透明，建议编写注释或百科条目。
  - 建议：为该七项列一条段后注，各附巴利原词。

- `66-172-30-37`｜术语标记未用｜片段「作为滋补之物的药」
  - 问题：`rasāyana` 是印度医学专名（回春／长养术），"滋补之物"是义译但丢了专名身份，且下文"能让生命延续很长时间"正依赖该专名的技术含义。
  - 建议：改为"作为**回春药**（rasāyana）的药物"或保留义译并夹注原词。

- `66-171-10-22`｜语言风格不统一｜片段「**“意思就是朝相反的方向而去”**」
  - 问题：同为 `attho` 结尾的释义句，此处译"意思就是……"，而 `66-172-2-9` 译"意思是机会"、`66-172-114-122` 译"意思就是痛苦"，句式在"意思是"与"意思就是"之间摇摆。
  - 建议：统一为一种句式。

- `66-173-29-42`｜语言表达不够流畅｜片段「正因如此，命根才被说成“以使之存续为作用”」
  - 问题："以使之存续为作用"中的"之"为文言虚词残留，且 `rasa`（作用／味）的术语译法未夹注。
  - 建议：改为"以使它存续为作用（pavattanarasa）"。

- `66-172-86-93`｜代词指代可能不够明确｜片段「从（病素）积聚之时起」
  - 问题：译者补出的"（病素）"在原文 `Sañcayato paṭṭhāya` 中无对应词，属推断性补足；虽合医理语境，但与 style.md"不擅自补足省略主语"略有张力。若义注此处有明文，应以义注措辞为准。
  - 建议：保留但在脚注说明补足依据，待义注核对。
