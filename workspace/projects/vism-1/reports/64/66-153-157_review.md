## 一、被解释词与父层逐字核对（首要项）

绝大多数黑体词与父层译文逐字相同，核对通过：绿豆汤似的人 / 抱哄性 / 示意 / 说旁敲侧击的话 / 用十种骂人的事项来责骂 / 贬抑 / 讥笑 / 加谤 / 背后说人坏话 / 油膏 / 像把香料磨碎来寻找香气那样 / 遍净 / 看肢体 / 看征兆 / 看天象变异 / 占梦 / 看体相 / 看鼠咬的痕迹 / 火供 / 杓供 / “等”这个词 / “寻求生活资具的努力”。

不通过或需确认的两处，见下。

### §155 句 66-155-12-17 — **必改（待定层面：词形核实）**
- **问题**：被解释词 — 本层作 `Upekkhanā`，译「舍置」。但父层 nippesikatā 的整份解说（64-187）中**没有** upekkhanā 一词，父层列的是 `ukkhepanā / samukkhepanā`。黑体词若在父层找不到落点，对应关系就断了。
- **依据**：**义注（父层）** 64-187-21-29：`**Ukkhepanā**ti mā etaṃ ettha kathethāti vācāya ukkhipanaṃ`，译「“**抬举**”就是用‘不要在这里说他’这样的话把对方捧高」。
- **建议**：`Upekkhanā` 极可能是 `Ukkhepanā` 的异读/讹形。若确认为异读，黑体须改用父层译名「抬举」，并把复注的释义接上；若确为另一词（upekkhanā，舍置），则须在译文外的报告中注明父层缺对应，不要默默换词。**本条需先核版本再定译，不要凭现译定稿。**
- **附带发现（父层问题，回头处理）**：复注对此词的解释是「把优婆塞们从施主等的身份中排除出去」——这印证 64-187-21-29 的 ukkhepanā 在该处是**排斥、把人剔出去**，而不是「把对方捧高」。父层 64-187-37-51 另起的「或者」句（看见不布施的人喊“啊，施主”）才是反讽式的抬举。**父层 64-187-21-29 的「把对方捧高」疑为误译**，建议列入父层的 revise 清单。

### §154 句 66-154-23-34 — **建议**
- **问题**：黑体 `paccayapaṭisaṃyuttakathā`「与资具相关的话」在父层 64-171 的 nemittikatā 解说里没有对应词（父层只有 nimitta / nimittakammaṃ / obhāso / obhāsakammaṃ / sāmantajappā / parikathā）。
- **建议**：译法本身无误，保留即可，但它属于复注自出的词，不是引自父层的被解释词——确认排版上不宜与真正的引词同样加粗，或在报告中记录其无父层落点。

## 二、跨段一致性

### 本层内部冲突（必改）

- **「讥笑」一词撞车**：§155 `Khipanā`=「讥笑」（父层定名，不可动），同段 66-155-22-34 又把 `avahasitvā` 译成「带着讥笑说出来的话」。同一句里用同一个词译两个不同的巴利词，读者会以为在原地打转。
  → 建议 `avahasitvā` 改「带着嗤笑」或「取笑过后才说出的话」。

- **`nijigīsanaṃ` / `nijigīsanatā` 同译「求取」**（66-156-2-15）：现译「这种欲求就是求取；它的状态就是**求取**」，构词解释自我消解——复注这句的全部作用就是说明 -tā 后缀是「…的状态」。黑体「求取」是父层定名不能改，所以要改的是前一个。
  → 建议：「…想要骗取的这种欲求，就是求取（nijigīsana）；它的状态就是**求取**（nijigīsanatā）。」用夹注把派生关系显出来。

- **`nimitta`「暗示」→ `nemittikatā`「相示」派生链断裂**（66-154-2-12）：现译「靠暗示而行事、或者靠暗示而活命的人，就是行暗示的人；他的状态就是**相示**」。「暗示 → 行暗示的人 → 相示」，最后一跳读者看不出来源。「相示」的「相」正是 nimitta。
  → 建议：`nimittena` 译「靠相（nimitta，暗示）」，或在「**相示**」后夹注（nemittikatā）。黑体本身不动。

- **`parapiṭṭhimaṃsiko` 段内自相不一**（66-155-43-50）：前半「习惯于吃别人**背脊肉**的人」，后半「就是背后吃**人肉**的人」，同一词两译且后者丢了「背」。
  → 建议后半改「就是背后吃人背脊肉的人」。父层 64-187-116-130 用的是「背脊肉」。

- **`sattha` 统一译名**（§157 出现 4 次）：现译「技术」（nimittasattha 看征兆的技术 / supinasattha 占梦的技术 / lakkhaṇajānanasattha 判断相征的技术 / jānanakasattha 知道…的技术），而 `vijjā` 译「明术」。区分 vijjā 与 sattha 的思路是对的，但 **sattha（śāstra）是「论、学、典籍」，不是「技术」**——这是知识体系名，不是手艺。
  → 建议统一：`sattha` 一律译「之学」或「论」（占相之学／占梦之学／相法之学／占知之学），`vijjā` 保留「明术」。此项影响本段 4 句，一并改。

本层三处黑体取的都是父层**义注解释段**的译名，与父层**引文段**不一致。本层不必改，但父层需回头统一，否则读者对不上：

## 三、逐句问题

### §153 句 66-153-49-65 — **必改（文言）**
- **问题**：风格 — 「真实语以外的其他善说**之**语」用了文言虚词「之」，`style.md` 第一节明列为禁例。另「他由此指的是喋喋不休地多说」：主语「他」指代不明（应是义注作者/这句话），且「喋喋不休」与「多说」语义重复。
- **建议**：「这是说喋喋不休地讲个不停；或者应当知道，除真实语之外，其他善说的话也叫做“法”。」（后半「之外」为固定搭配，可留；「之语」必改。）

### §153 句 66-153-18-48 — **建议（引文与上下文矛盾）**
- **问题**：本段正解释 `dhamma` = mattāvacana「有分寸的言说」，引文却把 `dhammaṃ bhaṇe nādhammaṃ` 译成「应当说合法的话，不说不合法的话」——「合法／不合法」是法律语感，且与上句刚确立的释义脱节。末句「这是第二」原文为 `taṃ dutiyaṃ`（承前「最上」而言的第二义），现译突兀，读者读不懂在数什么。
- **建议**：「善人说，善说的话是最上的；说如法的话、不说非法的话，这是第二。」并考虑在「第二」后补出承接（如「这是第二种（最上）」），否则孤立成句不可解。

### §157 句 66-157-66-75 — **必改（指代致误）**
- **问题**：准确性 — 现译「由于活命遍净戒是靠精进来成就的，所以说**它**是“寻求生活资具的努力”」。「它」最近的先行词是「活命遍净戒」，读者会得出「活命遍净戒 = 寻求生活资具的努力」。但**义注（父层）** 64-189-104-113 说的是：`Etaṃ āgamma jīvantīti ājīvo. Ko so, paccayapariyesanavāyāmo.`——被定义为「寻求生活资具的努力」的是**活命（ājīva）**，不是活命遍净戒。复注这句是在解释义注**为什么**用 vāyāma（精进）一词来说 ājīva。
- **建议**：「由于活命遍净戒是靠精进成就的，所以（义注）才把活命说成“寻求生活资具的努力”。」引号内逐字保持父层原样。

### §157 句 66-157-38-49 — **建议（文言）**
- **问题**：风格 — 「在波罗奢木**之**火等等当中」，文言「之」。
- **建议**：「在波罗奢木火等等当中」或「在用波罗奢木烧的火等等当中」。

### §157 句 66-157-26-37 — **建议（句式）**
- **问题**：风格 — 「是指知道衣服等物在某一部分被老鼠咬破时会有什么样的结果**的的**长串定语」，四层嵌套一口气到底，现代汉语读着断不开气。
- **建议**：拆为两句，如「是指这样一门学问：衣服等物在某个部位被老鼠咬破时，会有什么样的后果。」

### §157 句 66-157-21-25 — **建议（用词）**
- **问题**：「判断女人和男人身上**相征**的技术」，「相征」非通行词，生造感强。
- **建议**：「判断女人男人身上各种相的学问」。

### §155 句 66-155-55-72 — **建议（主语滑动）**
- **问题**：准确性 — 「香气不磨碎就得不到」，被磨碎的是香料，不是香气（原文 `anippisite alabbhamānassa gandhassa nipisane lābho`：香气在不磨时得不到，在磨时得到）。
- **建议**：「意思是：香料不磨碎时得不到香气，磨碎了才得到；同样应当知道，不磨碎别人的功德就得不到资具，磨碎了才得到。」后半也顺带去掉「而通过…就得到了资具」的欧化长链。

### §156 句 66-156-16-23 — **建议（逻辑连词）**
- **问题**：现译「**或者**是指那种欲求生起的样子，或者是与它俱生的寻求行为」，把两项都变成并列选项，丢了承上主语。原文 `Tasseva icchanassa pavattiākāro, taṃsahajātaṃ vā gavesanakammaṃ` 是承前句「求取性」续说：它是那欲求的现起样态，或是与之俱生的寻求业。
- **建议**：「（求取性）就是那欲求现起的样态，或者是与它俱生的寻求行为。」

### §156 句 66-156-2-15 — **建议（语义重复）**
- **问题**：`Nikattuṃ` 与 `vañcetvā` 都译成「骗」（「想要行骗，用少许的利养骗取更多」），原文前者是总说（行诈），后者是方式（骗取）。
- **建议**：「以少量的利养骗取大量，这种想要诈得的欲求就是求取（nijigīsana）」，与上文 nijigīsana/nijigīsanatā 的改法合并处理。

### §155 句 66-155-12-17 — **建议（文言味）**
- **问题**：风格 — 「从施主等的身份中**摈弃**出去」，「摈弃」偏文。
- **建议**：「就是把优婆塞们排除在施主等身份之外」，或「就是不再把优婆塞们当作施主看待」。（本句译法待上文词形核实后再定稿。）
