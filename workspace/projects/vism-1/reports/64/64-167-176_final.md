## 理由

**基准说明**：本次注入的资源只有巴利原文与目标 channel 译文，**没有义注、没有 nissaya**。因此释义与词法核对只能依据巴利原文本身的句法框架（尤其是各定义段共用的 `Lābhasakkārasilokasannissitassa … yā paresaṃ …` 属格框架）、被释词与解说词的构词关系，以及本段自身随后的 Vism 解说（174–176）来做。凡涉及传统取义的判断（如 `ukkhepanā`、`ukkācanā`、`pāpanā` 系列同义词串），缺少义注与 nissaya 的裁定，扣分从严但信心相应下调，这是信心只给 78 的主要原因。

**准确性**：叙事与引文主干翻译准确，六条学处（波罗夷／僧残／偷兰遮／波逸提／波罗提提舍尼／突吉罗）与罪名对应无误；`paṭivijānantassa`（对方听懂）、`tadatthikasseva sato`（明明正需要）、`tadanuggahakāmataṃyeva āvikatvā`（只表示为摄受他们）、`api sakaṭabhārehi upanāmanahetubhūtaṃ`（以至于用车载送来的原因）等难点都处理到位，`na mayhaṃ iminā attho` 一句也没有译反。失分集中在三处同义词串：170 段 `sallapanā`／`ukkācanā samukkācanā`、172 段 `ukkhepanā samukkhepanā`。其中 172 段最值得注意——`nippesikatā`（激磨）整串词义都是辱骂贬损（akkosanā / vambhanā / garahanā / avaṇṇahārikā / parapiṭṭhimaṃsikatā），中间冒出「抬举、遍抬举」与上下文语义场直接冲突，且与 170 段把 `ullapanā` 译成「抬举着谈」撞车。另有 175 段 `appiccho` 一词被扩为「少欲知足」，`santuṭṭha` 并不在原文里，而 176 段又同时出现 `appiccho santuṭṭho`，属于不必要的多译。

**风格**：整体是现代书面汉语，禁例表里的「此中／彼等／是故／便／遂／用膳／端坐」一类均未出现，问答体（「沙门要贵重的衣服做什么呢？」）和叙事句都足够白话。残留的文言痕迹仅限「之」字结构（称誉之声、可施之物），属轻度，但按 style.md 第一节硬约束仍须逐处列出。另有三处生硬处：「以三种方式传来的」「才开始了……这样的说法」「绿豆汤性／抱哄性」——后者是逐字硬译加巴利夹注，读者无从理解其比喻（豆汤中生熟混杂喻真伪杂陈；保姆抱哄小儿喻讨好），按未加注的不明确术语记 warning。

**一致性**：跨段被解释词回扣做得不错——169 段定义里的「皱眉作态、皱眉的状态、诡诈、诡诈的行为、诡诈的性质」与 176 段收尾完全逐字同译，175 段引出的「以受用资具所作的」与 169 段用词一致，174 段三个被释词（依赖利养恭敬名声的／怀着恶欲的／被欲望所驱使的）与 169–173 段定义框架用语统一。失分在三点：`saṃ-` 前缀在 170 段译「全面」、172 段译「遍」；`nemittikatā` 译「相示」而其词根 `nimitta` 译「暗示」，构词关联断裂，且「相示」偏离元亨寺／叶均本通行的「现相」；168 段开头引的词目是「为了活命而制定的六条学处」，段末回指却写成「开头所说的“这六条学处”」，引号内文字在前文找不到。

## 问题清单

### 🟧 error
- `64-172-8-28`｜错译（词义）｜片段「抬举、遍抬举」
  - 问题：`ukkhepanā samukkhepanā` 处在 `nippesikatā`（激磨）的定义串中，前后各项（辱骂、贬抑、呵责／讥笑／加谤／散布恶名／背后说人坏话）全是贬损行为，此处取「抬举」义与整串语义场相悖；且与 170 段 `ullapanā` 的「抬举着谈」用同一个词，令两段互相矛盾。
  - 建议：改取「举罪、责难」一系的义项，如「毁訾、极毁訾」或「当面举发、一再举发」，并与 170 段的「抬举」在用词上区别开。

- `64-170-9-31`｜错译（词义）｜片段「善谈」
  - 问题：`sallapanā` 是 `saṃ + lapanā`（交谈、对谈），译作「善谈」像是把 `sal-` 误读为「善于」，与前后 `ālapanā`（搭谈）／`ullapanā`（抬举着谈）的同族递进也对不上。
  - 建议：改为「交谈」或「攀谈」一类，保持与「搭谈」的递进关系。

- `64-170-9-31`｜错译（修饰关系）｜片段「自我炫耀、全面自我炫耀」
  - 问题：整串由 `yā paresaṃ …` 统摄，动作对象是「他人」，本句译文自身也写了「凡是他对他人的」；`ukkācanā samukkācanā` 译成「自我炫耀」把对象换成了自己，与句法框架冲突。
  - 建议：按「对他人」的方向取义，如「吹捧、极力吹捧」或「揄扬、极力揄扬」。

- `64-175-19-76`｜错误多译｜片段「这位尊者少欲知足，什么都不肯接受」
  - 问题：原文居士语只作 `aho ayyo appiccho na kiñci paṭiggaṇhituṃ icchati`，无 `santuṭṭha`；「知足」是添译。176 段 `appiccho santuṭṭho` 两词并列时译文正确区分为「少欲、知足」，此处合并会削弱后段的对应。
  - 建议：改为「这位尊者少欲，什么都不肯接受」。

### 🟨 warning
- `64-169-12-34`｜关键词语意不明确｜片段「凡是他以受用资具所作的，或以旁敲侧击的话语所作的」
  - 问题：两个「所作的」宾语被省略，读者看不出「作」的是什么（原文的核心是后面的「摆置威仪」等诡诈行为）；这也是 175 段要展开解说的三种诡诈事之首，此处含混会让 175 段的回指落空。
  - 建议：补出中心语，如「凡是他以受用资具而作的〔诡诈〕，或以旁敲侧击的话语而作的〔诡诈〕」，或改为「凡是依受用资具、依旁敲侧击的话语，或对威仪所作的摆置、安置、摆布」。

- `64-170-9-31`｜不常用术语无注释｜片段「绿豆汤性（muggasūpyatā）、抱哄性（pāribhaṭyatā）」
  - 问题：两个比喻性术语直译为「绿豆汤性」「抱哄性」，夹注巴利原词但无任何说明，现代读者完全无法索解（前者喻真话假话生熟混杂，后者喻如保姆抱哄小儿般讨好施主）。「…性」的构词也不合现代汉语。
  - 建议：改用可读的意译并加简注，如「真假掺杂的话（muggasūpyatā）」「如乳母哄孩子般的讨好（pāribhaṭyatā）」。

- `64-171-8-23`｜关键词语意不明确｜片段「做暗示、做暗示的举动，做示意、做示意的举动」
  - 问题：`nimitta` 与 `obhāsa` 是两类不同的现相手段（前者偏身业或间接举动，后者偏话语上的明示），译作「暗示／示意」两个近义词，区别被抹平，四项读起来像同义重复。
  - 建议：区分开，如「做相、做相的举动，作明示、作明示的举动」。

- `64-168-81-112`｜代词指代不明确｜片段「开头所说的“这六条学处”，指的就是它们」
  - 问题：段首引的词目原文作「为了活命而制定的六条学处」，此处回指却写成「这六条学处」并加引号，读者在前文找不到这个引文；同时段首已经写过「指的就是这样制定的六条学处」，两处重复。
  - 建议：统一为段首的词目原文，如「段首所引“为了活命而制定的六条学处”，指的就是这六条」，并删去段首那句提前的解释。

- `64-174-11-23`｜文言语体｜片段「称誉之声」
  - 问题：文言「之」字结构（style.md 第一节禁例）。
  - 建议：改为「称誉的名声」或「好名声」。

- `64-176-171-180`｜文言语体｜片段「由于可施之物」
  - 问题：文言「之」字结构。
  - 建议：改为「由于可布施的东西」。

- `64-176-181-206`｜文言语体｜片段「可施之物也现成具备」

  - 建议：改为「可布施的东西也都有」。

### 🟦 suggestion
- `64-172-8-28`｜语言风格不统一｜片段「遍抬举、遍讥笑、遍加谤」
  - 问题：`saṃ-` 前缀在 170 段统一译作「全面」（全面抬举着谈、全面怂恿），在本段改译「遍」，同一构词在相邻两段用了两套译法。
  - 建议：三段（170／172／173）统一取一种，建议都用「极」或都用「遍」。

- `64-171-2-7`｜术语选择｜片段「**相示**」
  - 问题：`nemittikatā` 通行汉译作「现相」（元亨寺本、叶均本），「相示」非通行译名；而本段解说里 `nimitta` 又译成「暗示」，词目与解说词的构词关联断裂，与「被解释词逐字同译」的做法不一致。
  - 建议：词目改「现相」，解说里 `nimitta` 相应译「相」，使「现相／相／相的举动」成串。

- `64-175-2-10`｜语言表达不够流畅｜片段「诡诈之事是依受用资具、旁敲侧击的话语、威仪三方面，以三种方式传来的」
  - 问题：「以三种方式传来的」是 `tividhaṃ … āgataṃ` 的硬译，「传来」在现代汉语里指不出「（典籍中）载有」的意思，且「三方面」与「三种方式」重复。
  - 建议：改为「《大义释》中记载了依受用资具、旁敲侧击的话语、威仪这三种诡诈之事」。

- `64-175-11-18`｜语言表达不够流畅｜片段「才开始了“以受用资具所作的”等这样的说法」
  - 问题：「开始了……说法」不是自然的现代汉语搭配。
  - 建议：改为「才有了“以受用资具所作的”等以下这一段文字」。

- `64-175-19-76`｜复杂嵌套句理解困难｜片段「从此以后，那种令人惊异、以至于居士们用车载着送来供品的作态」
  - 问题：原文是一个以 `vimhāpanaṃ` 为中心语的长定语句，译文把前面的经过铺成叙事、再用「那种……作态」回收，但「那种」跨越了近两百字的叙述，指代边界不清晰。
  - 建议：在回收处点明所指，如「以上这一整套令人惊异的做法——它正是此后居士们用车载着送来供品的原因——应当知道就是……」。

- `64-176-207-213`｜语言表达不够流畅｜片段「不过我是出于对你们的怜悯才接受的」
  - 问题：`tumhākaṃyeva` 的强调语气（「只是出于怜悯你们」）未译出，与 175 段解说里的「这时他才表示自己**只是**为了摄受他们」失去呼应。
  - 建议：改为「不过我只是出于对你们的怜悯才接受的」。

- `64-176-90-107`｜夹注不规范｜片段「诃梨勒（harīṭakī）」
  - 问题：本句巴利原文作 `hariṭakīkhaṇḍena`，夹注却写成 `harīṭakī`，与所注原文的拼写不一致。
  - 建议：夹注与原文取同一拼写 `hariṭakī`，或统一使用词典形并保持全段一致。
