## 理由

**数据基准缺失（影响信心）**：本次注入的资源只有巴利原文与目标 channel 译文，**没有义注（aṭṭhakathā）、也没有 nissaya**。按方法文档，缺哪个就降级用剩下的并在理由中说明——因此准确性判断只能依据巴利原文本身的词法、句法，以及《清净道论》/《阿毗达摩》体系里"定的三法"这一段的通行教理框架。凡涉及"义注取义"与"格/句法角色"的结论都无外部标准可对，信心相应压到 72。

**准确性**：整体忠实，术语体系（近行定、心一境性、有寻有伺、无寻唯伺、俱行、广大、无量）准确且合于论藏通行译法，`paritta / mahaggata / appamāṇa` 三法与 `vitakka / vicāra` 的五分法、四分法换算关系都译对了，没有发现漏译整词或整句。扣分集中在两处句法归属：

- `64-663-2-8` 把 `paṭhamajjhānasamādhi saddhiṃ upacārasamādhinā` 处理成"初禅的定以及近行定"。`saddhiṃ` + 具格是"连同、伴随"，主语是初禅定，近行定是随附项而非并列主语；原文的重心是"初禅定（连同近行定）是有寻有伺的"。译成"以及"读起来像两个并列主语共一个谓语，意思不错但弱化了 `saddhiṃ` 的伴随语义，属可改不属错译，计 suggestion。
- `64-664-14-23` 的 `Tesveva tatiye ca catutthe ca jhāne`，`tesu eva`（处格复数）回指上句的"两种分法（四分法/五分法）"，译文补出"（四分法的）第三禅和（五分法的）第四禅"是正确的教理归属（四分法第三禅 = 五分法第四禅 = 离喜、乐俱），但"还是在这两种分法里"这一回指表达含糊，且括号补注与前句"最初的两个禅／最初的三个禅"的行文体例不统一。
- `64-664-24-26` `Avasāne upekkhāsahagato` 译"在最后一禅中"。`avasāne` 本身只是"在最后"，补出"一禅"是合理的语义补足（指四分法第四禅／五分法第五禅），但风格文档第六节明言"不擅自补足省略主语（除非语义必须）"——此处属语义必须，不扣分，仅记录。
- `64-663-13-30` `kevalaṃ vitakkappahānamattaṃ ākaṅkhamāno` 译"仅仅想要舍断寻"。`kevalaṃ` 与 `-matta-` 两重"仅"在译文中合并为一个"仅仅"，语义未失，但"仅仅想要舍断寻"的辖域可读作"仅仅[想要]"而非"[仅仅舍断寻]这一点"，有轻微歧义，计 suggestion。

**风格**：现代书面汉语，全段无文言虚词、无文言句式，无单音节文言词，`style.md` 第一节禁例表未见违例。标点全角、无 ASCII 引号、无残留工作标记。唯一风格问题是 `64-663-35-48` 与 `64-664-14-23` 两处多重处格状语层层前置，读来吃力。

**一致性**：三法收束句"这样按…三类来分，定有三种"在 662、663、664、665 四处完全统一，是本段最扎实的一致性表现。扣分在术语夹注体例：`paritta / mahaggata / appamāṇa` 三处夹注了巴利原词，而同段同样属于法相术语且同为首次出现的"心一境性（ekaggatā）""近行定（upacārasamādhi）""俱行（sahagata）"都没有夹注，`style.md` 第二节"法相术语首次出现夹注巴利原词"的执行是不均匀的。另外 `64-661-2-2` 标题译"《定的三法》解释"，而正文通篇用"三法"不带书名号，标题的书名号把一个品名当成了独立典籍名，与正文体例不一致。

## 问题清单

### 🟨 warning

- `64-661-2-2`｜不导致误解的汉语语病｜片段「《定的三法》解释」
  - 问题：`Samādhitika` 是《法集论·定三法》这一节的名目，不是独立典籍，加书名号与正文通篇不带书名号的"第一个三法／第二个三法"体例冲突；"解释"作为 `vaṇṇanā` 的对译直接缀在书名号后，读作偏正短语不畅。
  - 建议：与全书其他 `vaṇṇanā` 章节标题体例对齐，去掉书名号，作"定三法解释"或"定的三法·解释"。

- `64-665-2-7`｜该使用而没有使用术语标记（体例不一致）｜片段「近行地中的心一境性是小（paritta）的定」
  - 问题：同一段内 `paritta / mahaggata / appamāṇa` 夹注了巴利原词，而首次出现的法相术语"心一境性（ekaggatā）"（首见于 `64-663-35-48`）、"近行定（upacārasamādhi）"（首见于 `64-663-2-8`）、"俱行（sahagata）"（首见于 `64-664-2-13`）均未夹注，`style.md`"法相术语首次出现夹注巴利原词"未均匀执行。
  - 建议：统一口径——或补齐上述术语的首次夹注，或将 `paritta / mahaggata / appamāṇa` 视为已有稳定汉译而一并不注；这属于跨段体例，宜在 harmonize 层面统一处理。

- `64-664-14-23`｜代词指代不明确｜片段「还是在这两种分法里」
  - 问题：`Tesveva` 回指上句的四分法与五分法两套禅支划分，"还是在这两种分法里"字面指代成立，但"还是"口语色彩偏强，且与紧随其后的括号补注"（四分法的）第三禅和（五分法的）第四禅"信息重复。
  - 建议：改为"仍在这两套分法中"或直接省略回指、只保留括号里的归属说明，避免重复。

### 🟦 suggestion

- `64-663-2-8`｜语言表达不够流畅（句法关系弱化）｜片段「初禅的定以及近行定」
  - 问题：`saddhiṃ upacārasamādhinā` 是具格伴随结构，近行定是随附项，译作"以及"将其提升为并列主语，弱化了原文"初禅定连同近行定"的主从关系。
  - 建议：改为"初禅的定连同近行定"或"初禅的定以及与之相伴的近行定"。

- `64-663-13-30`｜语言表达不够流畅（辖域歧义）｜片段「仅仅想要舍断寻」
  - 问题：`kevalaṃ … vitakkappahānamattaṃ ākaṅkhamāno` 中两重"仅"限定的是"只舍断寻这一点"，译文的"仅仅"紧邻"想要"，可被读作限定意愿强度。
  - 建议：调整语序为"只希求舍断寻这一点"，让限定落在宾语上。

- `64-663-35-48`｜复杂的嵌套句整句语言逻辑理解困难｜片段「至于在四分法里，从第二禅起的三个禅中，在五分法里，从第三禅起的三个禅中，那种心一境性就是无寻无伺的定」
  - 问题：四个处格状语连续前置，中间只用逗号分隔，读者要到"那种心一境性"才等到主语，且两套分法并列却未用连接词标示。
  - 建议：拆为"至于四分法中从第二禅起的三禅、五分法中从第三禅起的三禅，这些禅里的心一境性就是无寻无伺的定"。

- `64-664-24-26`｜语言风格不统一｜片段「在最后一禅中，定是与舍俱行的」
  - 问题：前后三句均为"……中的心一境性是与 X 俱行的定"这一句式，本句改作"定是与舍俱行的"，主语从"心一境性"换成"定"，破坏了四句排比。
  - 建议：改为"最后一禅中的心一境性是与舍俱行的定"，与前后句式对齐。
