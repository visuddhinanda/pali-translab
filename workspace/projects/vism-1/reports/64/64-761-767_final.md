## 理由

**取数条件（须先交代）**：本次评估只拿到巴利原文与目标 channel 译文两项资源，**义注（aṭṭhakathā）与 nissaya 均未注入**。本段正是《清净道论》行道抉择章的义注层文本（book 64 为 Cariyāvaṇṇanā），其自身即释义层，但复注（Paramatthamañjūsā）与缅文 nissaya 缺失，导致以下判断无法做到词级锁定：`adhotavedikaṃ` 的所指（台基／门槛／坛座）、`jatukābharitaṃ` 是"蝙蝠"还是"漆胶／白蚁"、`bilaṅga` 的具体食品、`ujjaṅgala` 的确切地貌。按方法文档规定降级为纯 pali 核对，并相应压低信心指数至 72。凡下文标为 error 的条目，均为不依赖缺失资源即可判定的问题；依赖缺失资源才能定案的分歧，一律只列 warning/suggestion 并注明。

**准确性**：整体词覆盖良好，长复合词（`supariniṭṭhitamālākammalatākamma…`、`hatthikucchipabbhāramahindaguhāsadise`）的成分基本都落到译文里，句法角色（属格 `-assa` 译"他的"、宾格谓语结构）处理准确。扣分主要来自两处：`64-763-20-31` 对 `na vaṭṭati` 辖域的处理使句子语义颠倒了实际归属，以及 `64-761-77-112` 一句里 `ekakule` 的否定范围与 `ehi bhante` 的言者衔接被压缩成了自相矛盾的叙述（详见 error 条）。另有 `64-762-107-121` 漏译 `nānāvirāga` 一层。

**风格符合度**：`knowledge/style.md` 要求现代书面汉语，全段总体做到了（"就像随手扔掉粥饭一样""光是看一眼"等处相当自然）。但残留若干单音节文言词与文言句式，最集中的是"应当是……才合适"的重复框架里夹入的"则是""凡是……全都""至于"，以及 `64-767-9-16` 一句整体近半文半白。按方法文档第三类第 7 条，每处单列 warning，并在此维度显著扣分。

**一致性**：`vaṭṭati` / `sappāya` 统一译"合适／适合"，六种 carita 的术语首现夹注格式统一（贪行／瞋行／痴行／信行／觉行／寻行 + 圆括号巴利原词），`senāsana`="住处"、`iriyāpatha`="威仪"、`ārammaṇa`="所缘" 全段一贯，`kasiṇa`="遍" 一贯。扣分在于 `parivisaka`（761）与 `parivesaka`（762）同一角色译文框架不同（"分食的人也应当是"vs"至于分食的人，则应当是"），以及 `dubbaṇṇa` 在 761 内连续三句都译"颜色难看"而第三次实指钵的材质色，行文重复未作变化。

**标点与 JSON 安全**：全段无 ASCII 引号，引号一律全角 “”，符合硬约束。但 `64-761-2-45`、`64-761-77-112`、`64-762-2-23` 等多句使用了破折号 `——` 承接 `tādisaṃ sappāyaṃ` 的回指，属可接受；`64-763-20-31` 的破折号用法则造成歧义（见 warning）。

**原文讹字**：`64-761-2-45` 与 `64-761-71-76` 的译文出现"崎岖"，正字为"崎岖"之误写，应为"崎嶇／崎岖"→ 规范简体作"崎岖"不成词，须作"崎岖"改"坎坷／崎岖不平"。此为汉字错字，非译义问题，列 warning。

## 问题清单

### 🟧 error

- `64-763-20-31`｜错译（修饰关系）｜片段「他的所缘，小的不合适——像簸箕那么大、像浅盘那么大的都不行。」
  - 问题：原文 `Ārammaṇaṃ panassa parittaṃ suppamattaṃ sarāvamattaṃ vā (khuddakaṃ) na vaṭṭati`，`parittaṃ`、`suppamattaṃ`、`sarāvamattaṃ`、`khuddakaṃ` 是同一主语 `ārammaṇaṃ` 的并列表语，`na vaṭṭati` 统辖全部。译文先总说"小的不合适"再用破折号补出两个例子，读起来像是把 `parittaṃ`（小）与后两项拆成"结论—举例"两层，且"都不行"重复否定，使 `parittaṃ` 与 `suppamatta/sarāvamatta` 的并列关系消失。更关键的是，`64-766-43-46` 处 `Parittaṃ pana vaṭṭati` 译作"小的所缘才合适"——两处 `paritta` 一处不合适一处合适本是原文对痴行与寻行的有意对比，但本句的拆分式译法弱化了 `paritta` 作为同一术语的身份，读者会以为两处说的不是一回事。
  - 建议：改为并列平铺、一次否定的结构，让四个形容词同级，并保持 `paritta` 与 766 段用词一致。
- `64-761-77-112`｜导致误解的表达｜片段「在那里，比丘连一家的食物都没乞到就走出来，人们会说一声“来吧，尊者”，把他请进客堂」
  - 问题：原文 `yattha ekakulepi bhikkhaṃ alabhitvā nikkhamantaṃ "ehi, bhante" ti āsanasālaṃ pavesetvā…` 中，`nikkhamantaṃ` 是宾格现在分词，受 `pavesetvā` 支配——被请进客堂的是"那位一无所得正要离开的比丘"，`ehi bhante` 是招呼他回来的话。译文用"人们会说一声"补出施事后，又与前半句"就走出来"并列成时间顺序，读者会读成"没乞到食物→走出来→有人叫住→进客堂→拿到粥饭"，与后文"连回头看一眼都没有"的冷淡基调冲突：原文要表达的是整个村子对贪行比丘态度漠然，`ehi bhante` 后给的也只是敷衍的粥饭。另外"连一家的食物都没乞到"把 `ekakule…bhikkhaṃ` 译为"一家的食物"，`bhikkha` 此处即乞得之食，尚可，但"连……都没"与随后即得粥饭形成表面矛盾，需要把"这才"的转折关系显化。
  - 建议：把 `nikkhamantaṃ` 的宾格身份显化为"（有人）把正要空手离开的他叫住"，并用转折连接后半句，使冷淡语气与所得之食不矛盾。
- `64-762-107-121`｜漏译｜片段「穿戴着色彩各异而洁净悦意的衣服首饰」
  - 问题：`nānāvirāga-suci-manuñña-vattha-ābharaṇa-paṭimaṇḍitā` 中 `nānāvirāga` 的 `virāga` 在此指"染色／色泽"，`nānāvirāga` 是"各种染色（鲜艳）"，译文"色彩各异"覆盖了 `nānā` 与 `virāga` 的色彩义，但 `suci`（洁净）与 `manuñña`（悦意）后另有 `vattha`（衣服）与 `ābharaṇa`（首饰）两项被修饰，译文"衣服首饰"并列后共享全部三个修饰语，尚可接受；真正漏掉的是与 `sunhātā suvilittā` 并列的层次：`dhūpa-vāsa-kusuma-gandha-surabhino` 三项香源（熏香、涂香料 `vāsa`、鲜花）译文只落"熏香和鲜花"，`vāsa`（香料／香膏）未译。
  - 建议：补出 `vāsa` 一项，作"熏香、香料和鲜花的芬芳"。

### 🟨 warning

- `64-767-9-16`｜文言语体｜片段「这里所说的性行，就从分类、来源、辨明、适宜的判别这几方面作了详细的解说」

- `64-761-2-45`｜关键词语意不明确，或二意场合没有注释｜片段「充满蝙蝠」
  - 问题：`jatukābharitaṃ` 的 `jatukā` 有"蝙蝠"与"漆胶／虫粪"两解，传统注疏多取"蝙蝠"，但本段上下文列举的是尘土、破损、臭虫等可厌之物，两解都通。缺义注与 nissaya，无法定案。译文取"蝙蝠"而未加注，属二意场合无注释。
  - 建议：保留"蝙蝠"译法，补一条简注说明另一解；或在复注／nissaya 到手后定案。
- `64-761-2-45`｜关键词语意不明确｜片段「未经洗刷台基的房舍」
  - 问题：`adhotavedikaṃ` 的 `vedikā` 在建筑语境可指栏杆、坛座、台基、门前的洗足处。此处与 `bhūmaṭṭhakaṃ`（建在地面上）并列描述简陋住处，译"台基"是一种合理取义，但"未经洗刷台基的房舍"读来费解——"未经洗刷"的直译加"台基"的抽象化，普通读者难以想见实景。缺 nissaya 无法锁定所指。
  - 建议：白化为"门前台阶没有洗刷过的"，并在定案后统一。
- `64-761-134-146`｜关键词语意不明确｜片段「配上酸坏的酪浆、酸粥、放久了的菜汤」
  - 问题：`pūtitakkaṃ bilaṅgaṃ jiṇṇasākasūpeyyaṃ` 三项，`bilaṅga` 译"酸粥"缺乏依据的显示——该词一般指酸粥／醋类酸味发酵物，与前项 `pūtitakka`（坏酪浆）语义相邻，两者连译易被读成同一物的重复。且"配上"是译者补出的连接，原文只是并列罗列。
  - 建议：三项改为平行罗列并区分质地，`bilaṅga` 若取"酸粥"宜加简注。
- `64-762-33-40`｜关键词语意不明确｜片段「蛇和老鼠」
  - 问题：`dīghajāti` 字面"长身类"，即蛇的隐讳说法，译"蛇"正确；但 `kīṭa-maṅkuṇa-dīghajāti-mūsikānaṃ` 四项译为"虫子、臭虫、蛇和老鼠"，`kīṭa` 与 `maṅkuṇa` 并列时前者宜作"小虫"以免与后者层级混淆。此外 `nissayaparicchindanatthaṃ` 译"为了不给……留下藏身处"是意译，`nissaya` 此处即"依处／藏身依托"，译法可接受但已偏离字面，宜记录。
  - 建议："虫子"改"小虫"；`nissaya` 的意译保留并在术语表登记。
- `64-763-20-31`｜标点符号使用错误｜片段「小的不合适——像簸箕那么大、像浅盘那么大的都不行。」

- `64-762-2-23`｜整句逻辑表达不规范｜片段「像梵天的宫殿一样，用花串和色彩斑斓的布制天盖装点」
