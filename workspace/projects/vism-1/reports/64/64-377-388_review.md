# Review — 64:377-388（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> ⚠️ **缺义注与 nissaya**，以下意见仅依据巴利原文语法与 `style.md` 作出；取义、格位、传统释义均未经对照标准核实，revise 时若能取到义注/nissaya 须重核一遍，尤其是 §382 四个贬称与 §385 的 `khata`。

## 跨段一致性

- **未来被动分词 `-tabba` 的语气不统一**：§377 `gilitabbā` 译「将在…吞下」（纯将来时），§381 `nivasitabbaṃ` 译「终究要住在」（带必然/不得不）。两处句式完全平行（`yena` + 被动 gerundive），语气应一致 → 建议统一为「终将不得不…」一类说法，§377 改「因为他终将不得不在漫长的岁月里吞下烧得通红的铁丸」。
- **`ādittā`（§377）与 `jalita-`（§379、§381）都译「烧得通红的」**：两个不同巴利词并到同一汉语说法，偈颂里的用词差别被抹平。建议 `ādittā`→「炽燃的」，`jalita-`→「烧得通红的」；若决定合并，请在 `terms.md` 登记为有意为之。
- **`asīlino`（§378）与 `dussīlassa`（§380）都译「破戒的人」**：此处倾向**维持统一**（读者友好，两词所指同一人），但建议登记进 `terms.md`，以免后文出现 `nissīla` / `sīlavipanna` 时译法失控。
- 称谓与语体：全 chunk 第三人称「他」，现代书面语，无文言句式，标点全角、无 ASCII 引号 ✅。

## §377 句 64-377-2-8

- **问题**：语气/一致性 — `gilitabbā` 是未来被动分词（`yena` 为施事具格），表「必须/终将不得不被…」，译文「将…吞下」只剩时间义，与 §381 同型句的处理不一致。
- **建议**：「因为他终将不得不在漫长的岁月里吞下烧得通红的铁丸。」

## §380 句 64-380-2-9

- **问题**：术语 — `saddhādeyya` 译「由信心施舍而来的」偏解释性且略拗口，该词是固定术语（信众以信心布施之物）。
- **建议**：「破戒的人住在信众布施的寺院里，又有什么居住的快乐可言？」；或按 `style.md` 术语策略首次出现夹注：「信施（saddhādeyya）的寺院」。待义注确认后补进 `terms.md`。

## §381 句 64-381-2-7

- **问题**：措辞 — `ayokumbhi-majjhesu` 的 `majjhe` 是「在…之中/里面」，译「铁锅中间」在现代汉语里读成「几口锅之间」，易误解。
- **建议**：「因为他终将不得不住在烧得通红的铁锅里。」

## §382 句 64-382-2-7

- **问题**：增译 — `kasambujāto` 是「秽物丛生／成了污秽之物」（`jāta` = 生/成），译文「内心污秽**如**垃圾」把它变成了明喻，原文无比喻词；「内心」也是补出的。
- **建议**：「秽污丛生」或「内生腐秽」，去掉「如」。
- **问题**：取义可商 — `avassuto` 译「漏泄烦恼」方向朝外，该词传统解作被贪欲浸润、内有漏泄。
- **建议**：暂作「内有漏泄」，**此处必须等义注确认后定稿**。
- **问题**：引语范围 — §382 的四个贬称与 §383 的 `antopūti` 同属世尊所说的那串话（`…ti ca yaṃ … āha`），译文只有 §383 用破折号带出「世间的导师」，读者会以为前四项是译者的叙述。
- **建议**：§382 起用全角引号开引：「“行为可疑、秽污丛生、内有漏泄、邪恶，」，§383 收引。

## §383 句 64-383-2-9

- **问题**：引号与衔接 — `antopūtīti` 的引语未加引号；且 `yaṃ`…（§384 `tassa`）是跨段的关系句，译文在此用句号收尾，与 §384 的衔接断开。
- **建议**：「而且‘内里腐烂’——世间的导师正是这样斥责他的。」句末可改用破折号或省略号留接。

## §385 句 64-385-2-7

- **问题**：句法 — 本句全部是承 §384 `tassa jīvitaṃ` 的属格串（`assamaṇassa`、`vahantassa`）与修饰 `jīvitaṃ` 的 `upahataṃ`，译文拆成三个并列的独立主谓句（「他并不是沙门，生命已被毁坏，只是拖着…活着」），把修饰关系变成了叙述关系。
- **建议**：保持属格串的修饰性，如「——一个不是沙门、生命已毁、只拖着一个被自己戕害的自身的人。」
- **问题**：增译 — `attānaṃ` 是「自己/自身」，译「身心」是加了佛学分析色彩。
- **建议**：改「自身」。

## §386 句 64-386-2-10 ／ §387 句 64-387-2-10

- **问题**：主语重复 — `maṇḍanakāmā`（§386）与 `sīlavanto santo`（§387）在原文是同一主语的两次描述，共用一个动词 `vivajjayanti`；译文两段各说了一遍「躲开他」，读起来像先后有两拨人躲他。
- **建议**：§386 先不点实主语、句末留接：「像躲开粪便、像躲开尸体一样，那些希求庄严的人在这里避开他——」；§387 接上：「避开他的正是持戒的善人；这样的人活着还有什么意义呢？」
- **问题**：增译 — §386「希求**以戒**庄严自己」中的「以戒」是补出的解释（原文只有 `maṇḍanakāmā`）。此读法很可能对，但**须由义注确认**；在确认前建议只译「希求庄严的人」，把这一解释放进脚注。

## §388 句 64-388-2-9

- **问题**：对仗 — `amutto / mutto` 是同词根的反讽对照，译文用「没有摆脱／却摆脱了」保住了对照，但 `mutta` 的定译是「解脱」，「摆脱…之乐」在现代汉语里语感偏白，反讽力度弱。
- **建议**：「他不曾从任何怖畏中解脱，却从一切证悟之乐中‘解脱’了。」（第二处加全角引号点明反讽）
