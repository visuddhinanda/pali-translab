# Review — 64:2186-2197（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入）
> 本批只按巴利原文做词法与语义核对。本层是本文，没有父层，所以不查被解释词。释义没有经过义注核对，格位判断也没有经过 nissaya 核对，两项都需要补审。

## 跨段一致性
- **so**（§2193 / §2195 / §2197）：三处都译成“这个人”。*so* 是阳性单数，指的是同偈前半的 *kāyo*（阳性），也就是身体，不是人。三处要一起改为“身体”（或“它”），见下面各句。
- **pūti-**（§2194 *pūtiyo* / *pūtimukha*）：同一偈里译作“腐臭”和“臭口蛇”，两处用字不一样。四种蛇（kaṭṭhamukha / pūtimukha / aggimukha / satthamukha）在汉译《清净道论》传统里一般作 木口蛇 / 腐口蛇 / 火口蛇 / 刀口蛇。建议统一为“腐口蛇”，定案后登记进 `terms.md`（现在是空的）。
- **kup-**（§2189 *kupita* ↔ §2191/2193/2195/2197 *-ppakopa*）：这些词同一个词根。*-ppakopa* 统一译作“紊乱”没有问题。*kupitena salilena* 译成“暴涨的洪水”，属于意译，可以接受，只是看不出和后文 *pakopa* 同根。可以考虑改成“激荡的水”，也可以不改。
- **yadā 句的指示词**：§2187 用“这是……”，§2189、§2191 用“那是……的时候”。三组偈是平行结构（火 / 水 / 风坏劫），句式建议统一，见 §2187。

## §2187 句 64-2187-2-8
- **问题**：句式不平行（小问题）。原文没有 *yadā*，是处格独立结构 *loke ḍayhamānamhi*（世界被焚烧时）。译文译成判断句“这是……火焰”，和 §2189、§2191 的“那是……的时候”不对应，“这/那”也不统一。
- **建议**：改为“那是世界被火焚烧时，烈火发出的火焰。”，和后两组对齐（同时去掉“所”）。

## §2193 句 64-2193-2-7
- **问题**：误译，指代错误（必改）。*hoti kaṭṭhamukheva so* = *so* (kāyo) *hoti kaṭṭhamukhe iva*，主语是上句的 *kāyo*（身体），译文把它译成了“这个人”。
- **建议**：“由于地界紊乱，身体就像落在木口蛇的口中一样。”

## §2194 句 64-2194-2-9
- **问题**：术语不统一，“臭口蛇”见上面跨段一致性一节。
- **建议**：“身体变得腐臭，就像被腐口蛇咬了一样；”

## §2195 句 64-2195-2-7
- **问题**：误译，指代错误（必改），*so* 指身体，理由同 §2193。术语也要随 §2194 统一。
- **建议**：“由于水界紊乱，身体就像落在腐口蛇的口中一样。”

## §2197 句 64-2197-2-7
- **问题**：误译，指代错误（必改），*so* 指身体，理由同 §2193。
- **建议**：“由于火界紊乱，身体就像落在火口蛇的口中一样。”
