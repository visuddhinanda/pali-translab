## 理由

**资源缺失说明**：本次评估只拿到巴利原文与待评译文，**未注入义注（aṭṭhakathā）与 nissaya**。本层（book 66）是复注（ṭīkā），其"父层"即《善见/清净道论》系的义注文本（此段对应 Visuddhimagga/Sāmaññaphala 系的 kuhana-lapana 释义与 Vibhaṅga-aṭṭhakathā 862），按方法文档应逐句比对被解释词是否与父层逐字同译——**这一条无法核验**。信心指数因此压到 68，准确性分数只能基于巴利词法与内部一致性判定，未与释义标准对照的部分不作扣分但也不作背书。

**准确性**：整体词义把握扎实。判词式（"X 是 Y"）的复注体例处理得当，`sandiṭṭho / sambhatto / sahāyo` 一组、建筑名目一组（vihāra / aḍḍhayoga / pāsāda / hammiya / kūṭāgāra / aṭṭa / māḷa / uddaṇḍa）两说并陈的结构都完整保留，`apare pana bhaṇanti` 的"另有一些人说"转折点得清楚。主要扣分集中在三处：`korajika` 一词的释义链条译得含混（见 error 1），`Mukhasambhāviko` 的复合词解析可疑（error 2），以及 `aṭṭhapanā` 那条把 ā-kāra 的所指括注错了（error 3）。另有若干漏译与增译的小处。

**风格**：现代汉语基调是好的，没有"此中／是故／彼等"一类成句文言。但仍有若干单音节文言残留与半文半白句式（"就是单纯的天然山洞"尚可，"极度诡诈的人"的"极度"连用三处略硬），以及**引号用了全角弯引号但个别条目夹注括号与黑体范围处理不一致**。术语首次夹注巴利原词的规则执行得不彻底——`kaṇṇikā`、`āsanasālā`、`Telakandarikā` 夹注了，而 `sāmantajappana` 之外的 `kuhāyanā`、`kuhito` 等被解释词在译文里以汉译+黑体呈现却未夹注原词，同一段内标准不齐。

**一致性**：`Telakandarikā` 与 `Telakandarika` 在相邻两句中拼写不一（前者夹注带长音，后者不带），虽然如实反映了原文 `telakandarikāya` / `telakandarika-vatthu` 的形态差异，但对中文读者呈现为同一人名的两种写法，属一致性瑕疵。`uddaṇḍa` 统一译"台阁"、`aṭṭa` 统一译"望楼"、`māḷa` 统一译"圆形屋"，两说之间保持了同译，这一点做得好。

## 问题清单

### 🟧 error

- `66-148-2-22`｜错译（词义、修饰关系）｜片段「恶欲本身就是可厌的尘垢；由于这种恶欲而毫无意义地压住身语的躁动，就叫做矜持」
  - 问题：`Kucchitarajabhūtāya pāpicchatāya` 是具格修饰语，整体作"因为那可厌尘垢般的恶欲"，是一个带定语的单一成分；译文拆成两个分句（"恶欲本身就是可厌的尘垢；由于这种恶欲…"），把 `kucchitarajabhūtāya` 从定语提升为独立判断句，改变了句子结构与意思归属。另外 `niratthakaṃ kāyavacīvipphandaniggaṇhanaṃ korajaṃ` 中被释词是 **korajaṃ**（中性），译文作"矜持"尚可，但下文 `korajiko`（有此者）与 `korajikakorajiko` 的递进关系被"矜持—矜持的人—极其矜持"三级压平，`kohaññena saṃyatakāyo`（因虚伪而身收敛）被处理成同位补语而非对 `korajiko` 的第二种解释（`vā` 提示并列异释）。
  - 建议：还原为"因那可厌尘垢般的恶欲而毫无意义地抑制身语的躁动，即是 korajaṃ；有此者为 korajika"，并把 `kohaññena saṃyatakāyo` 与 `ativiya, abhiṇhaṃ vā` 两支异释的并列关系显出来。

- `66-148-38-46`｜错译（词义、修饰关系）｜片段「单凭自己嘴上说说，就受到别人的推崇」
  - 问题：`attano mukhamattena aññehi sambhāviko` 的 `mukhamattena` 是"仅凭（他的）口／仅凭嘴上"，译文方向大致对；但前半 `korajikakorajikādibhāvena pavattavacanehi` 是具格"以极其矜持等状态所发出的话语"，译文作"凭着极其矜持等作态说出的那些话"后，又接"单凭自己嘴上说说"，形成两个并列的"凭"，实际原文是**一个**工具链（以那些话语＝以口）。重复表述使修饰关系变形，读者会误以为是两个不同依据。
  - 建议：合并为单一工具关系，例如"凭着以极其矜持等姿态说出的那些话，仅靠一张嘴就博得他人推崇"。

- `66-150-25-35`｜错译（词义、修饰关系）｜片段「把（ā-ṭhapanā 中）前面的长音 ā 缩短」
  - 问题：原文 `Ā-kārassa rassattaṃ katvā "aṭṭhapanā" ti vuttaṃ`，讲的是 **ā 这个音**被短化。译文括注"ā-ṭhapanā 中"把所指锁定为某个假定的原形 `ā-ṭhapanā`，但此处讨论的词形来自 `ātthapanā`／`āṭṭhapanā` 一系，复注并未给出 `ā-ṭhapanā` 这一拼写；这是译者代为构拟并写进正文的形式，属于无据增补。
  - 建议：删去构拟的原形括注，直译"把 ā 音短化，所以说成 aṭṭhapanā"，构拟如确有必要应入脚注并注明系推定。

- `66-147-84-89`｜漏译｜片段「连敌国的国王也能抵挡得住」
  - 问题：`paṭirājūnampi paṭibāhanayogyo` 中的 `-yogya`（堪能／适于）与 `api`（甚至）都译出了，但 `paṭissayaviseso` 的 `paṭissaya` 本义为"庇护所／避难处"，译文两处（此句与 `66-147-90-94`、`66-147-167-170`）一律作"特殊的住处"，丢失了"可供庇护、防御"的语义，而此句正是靠这层义与"能抵挡敌王"呼应。
  - 建议：`paṭissayaviseso` 统一改为"一种特殊的庇护性建筑／避难居所"，使防御义与上下文贯通。

- `66-152-38-71`｜错译（代词指代／说话人归属）｜片段「那位比丘就自我炫耀说」
  - 问题：上句 `tatreko ekaṃ pucchi`（其中一人问另一人），答话者应是**被问的那一位**，译文"那位比丘"指代不明，且紧接上句末"其中一位比丘问另一位"之后，"那位比丘"在汉语默认回指最近提及的主语（即提问者），造成说话人归属错误。`ukkācesi`（自我标榜）归属错人，整个故事的讽刺点就落空了。
  - 建议：改为"被问的那一位比丘便自我标榜说"。

### 🟨 warning

- `66-149-82-85`｜关键词语意不明确｜片段「是指所谓**摆布**威仪的」
  - 问题：`iriyāpathasaṇṭhapanaṃ` 此前在 `66-149-29-46` 译作"摆弄行走的样子"、"郑重地安排…姿态"，这里却用"摆布"。"摆布"在现代汉语主要义为"任意支配他人"，用于"摆布威仪"语意不明且带负面支配色彩，与 `saṇṭhapana`（安置、摆设）不符。且此处加黑体的理由不明——被解释词是 `iriyāpathasaṅkhātaṃ`，而黑体落在释义侧的"摆布"上。
  - 建议：统一为"摆设／安排威仪"，黑体只标被解释词。

- `66-150-2-16`｜整句逻辑表达不规范｜片段「或者是就那种应当这样称说的受用资具而言的」
  - 问题：`saṅkhātabbena kathitabbena` 两个未来被动分词是对 `saṅkhāta` 的双重训释，译文"应当这样称说的"把两词并成一个，且"就…而言的"与前半"以…而说的"句式不平行，整句读来逻辑断裂，普通读者无法把握这是在解析复合词后项 `-saṅkhāta` 的两种取义。
  - 建议：明确写成"或者，`saṅkhāta` 取'应当称说、应当述说'义，指那受用资具本身"。

- `66-150-36-51`｜关键词语意不明确｜片段「所谓 kuha（诡诈者），就是行诡诈这回事」
  - 问题：同句内 `kuha` 先被括注为"诡诈者"（指人），紧接着释为"行诡诈这回事"（指事），前后矛盾；而下半句又说"诡诈者这个人的举动"。原文 `Kuhanaṃ kuho` 是以 `kuhana`（行为）释 `kuha`，括注"诡诈者"系误加。
  - 建议：删去"（诡诈者）"括注，或改注为"（诡诈／诡诈之事）"。

- `66-152-2-8`｜关键词语意不明确｜片段「是指一再往上捆缚、缠绕」
  - 问题：`unnahanā` 的字面义（往上捆缚）译出了，但作为 `lapanā` 类术语其实指"抬举、吹捧以套取供养"；译文只给字面而无任何提示，读者无法把握该词在戒学语境中的所指，而被解释词汉译"怂恿"与释义"往上捆缚"之间也失去了联系，看不出为何前者可训为后者。
  - 建议：保留字面直译，另以夹注或脚注点明其所指为"抬举、吹捧"。

- `66-147-9-15`｜不导致误解的汉语语病｜片段「是指有大威力，意思是由于证得上人法而有这样的威势」
  - 问题："有大威力"与"有这样的威势"在一句内两次出现近义表述，且"意思是…"引出的 `adhippāyo` 本是点明**省略成分**（即威势之所由来），译文作解释性同语反复，句子显得冗赘。
  - 建议：精简为"是指有大威力——就是说，这威力来自证得上人法"。

- `66-148-23-25`｜整句逻辑表达不规范｜片段「有些人说，这是指过分疑惧顾忌的人」
  - 问题：`Atiparisaṅkitoti keci` 是 `keci`（有些人）对 **korajikakorajika** 的异释，译文用"这"回指，但上一句结尾是"**极其矜持**"这一被解释词，中间隔着长释义链，"这"的指代对读者不明确。
  - 建议：明写回指对象，"关于 korajikakorajika，有些人说是指过分疑惧顾忌的人"。

  - 问题：`uddaṇḍa` 译作"台阁"属未定译名，且与下文 `66-147-167-170` 的"一种特殊的住处"、`66-147-171-181` 的"库房、仓屋"三说并存，读者难以把握。按 `style.md`，罕见术语首次出现宜夹注巴利原词。

- `66-147-67-72`｜语言表达不够流畅｜片段「也有人说是形状像金翅鸟的楼房」
  - 问题：`garuḷasaṇṭhāna` 的 `garuḷa` 译"金翅鸟"可，但未夹注原词，而本段其余建筑术语均属专名系列；此外"形状像金翅鸟的楼房"读来像在描述外观雕饰，实际指屋顶轮廓（迦楼罗形屋顶），表达不够精确。
  - 建议：改为"屋顶呈迦楼罗（garuḷa）形的楼房"。

- `66-148-26-32`｜语言风格不统一｜片段「极度诡诈的人，就叫做**极其诡诈**」
  - 问题：`ativiya` 在相邻三句（148-26-32、148-33-37、148-2-22）分别译作"极度"（两次）与"极度地、或者一再地"，而被解释词一律作"极其X"，释义侧与被释侧用词不统一，读者看不出释义正是在训"极其"。
  - 建议：释义侧与被解释侧统一用"极其"。

- `66-149-70-81`｜复杂的嵌套句整句语言逻辑理解困难｜片段「是指在人们视线所及的地方像入了定的人那样坐着，在众人看得见的显眼处禅坐」
  - 问题：原文 `manussānaṃ āpāthaṭṭhāne … nisīdanto` 与 `āpāthake janassa pākaṭaṭṭhāne jhāyī` 是对 `āpāthaka` 与 `jhāyī` 两个成分的分别训释，译文并列成两个"在…处"的分句，中文读来像同一件事说了两遍，嵌套结构反而模糊。
  - 建议：用破折号或分号区分两层训释，"āpāthaka 即人们视线所及、众人看得见的显眼处；在那里像入定者一样坐着禅思，即是 āpāthakajjhāyī"。
