## 跨段一致性

- **`catubbidhaṃ`**：§136 译「戒有四种」、§137 末「戒有四种」、§138 末「戒有四种」——一致，✅。但三处的前半「按照退分等等的分类／按照比丘戒等等的分类／按照自然戒等等的分类」中「等等」重复叠用，建议统一为「等」（现代汉语列举省略的常用写法，「等等」偏口语且三段连用显拖沓）。
- **`-vasena`**：§136/§137/§138 译「按照…的分类」，§137 内 `niccasīlavasena` 译「作为常戒受持」、`uposathaṅgavasena` 译「按照布萨支」——同一后缀在本 chunk 有三种处理。前两种因语境不同可接受，但 `uposathaṅgavasena` 与 `niccasīlavasena` 是同一句内的并列结构，译法应对称。见 §137-36-53。
- **`saṃvara`**：§139 一律译「防护」（波罗提木叉防护戒／根防护戒／防护眼根／达成防护），✅ 一致。
- **`catukka`**：§137「第二个四法」、§138「第三个四法」、§139「第四个四法」，✅ 一致。
- **`sīla` 复合词的译名结构**：`pakatisīlaṃ`→自然戒、`ācārasīlaṃ`→惯行戒、`dhammatāsīlaṃ`→法性戒、`pubbahetukasīlaṃ`→宿因戒——四者均为「X戒」二字定语，结构整齐，✅。
- **语体**：整体现代汉语，无明显文言句式。个别单音节文言残留见下（§137、§138）。

## §137 句 64-137-2-17

- **问题**：准确性 — `yāni ca nesaṃ bhikkhunīnaṃ paññattito rakkhitabbāni` 的译文「以及那些为比丘尼们制定、而比丘们也应当守护的学处」，与下句 64-137-18-31 的译文「以及那些为比丘们制定、而比丘尼们也应当守护的学处」互为镜像，方向正确；但原文 `nesaṃ`（属格复数，指比丘）与 `bhikkhunīnaṃ paññattito`（从比丘尼的制定而来）的逻辑关系，译文用「而…也应当」表达尚可。**需确认**：`paññattito`（从格/离格）严格义是「由于/从…的制定（而来）」，译「为比丘尼们制定」把 `bhikkhunīnaṃ` 当成了受益对象，语义等价但不是字面结构。此处缺 nissaya 无法验证 `bhikkhunīnaṃ` 的格助词，建议保留现译并降低 confidence。
- **建议**：维持现译；若后续取得 nissaya，核对 `bhikkhunīnaṃ` 是属格（比丘尼的制定）还是与格（为比丘尼制定）。

## §137 句 64-137-36-53

- **问题**：跨段/句内一致性 — 同一并列结构中 `niccasīlavasena`、`uposathaṅgavasena` 译法不对称：「作为常戒受持的五条学处，如果有更大的意愿就受持十条，按照布萨支则是八条」。
- **建议**：改为「优婆塞和优婆夷按常戒受持的五条学处，如果有意愿就受持十条，按布萨支则是八条」——三项统一用「按…」。

- **问题**：准确性 — `sati vā ussāhe` 译「如果有更大的意愿」，「更大的」是添加。`ussāha` 是「精进、意愿、努力」，原文无比较级。
- **建议**：改为「如果有意愿」或「若有精进的意愿」。

- **问题**：风格（文言残留）— 「这样，按照比丘戒等等的分类，戒有四种」中的「这样」承接 `evaṃ` 可保留；但「等等」建议改「等」（见跨段一致性）。

- **问题**：切分 — 本句把 `idaṃ gahaṭṭhasīlanti` 与 `evaṃ bhikkhusīlādivasena catubbidhaṃ` 合为一段译出，中间用句号断开，处理得当，✅。

## §138 句 64-138-2-7

- **问题**：准确性 — `avītikkamo` 译「不违犯的行为」。`avītikkama` 是「不违越/不逾越」的名词，指北俱卢洲人天生不会违犯（无戒可受而自然不犯）。「行为」二字是添加，且弱化了「自然如此」的意味——这正是 `pakatisīla`（自然戒）得名之由。
- **建议**：改为「北俱卢洲的人们天生不违犯，这就是**自然戒**」，或「北俱卢洲的人们的不违犯，就是**自然戒**」。

## §138 句 64-138-8-13

- **问题**：准确性 — `kuladesapāsaṇḍānaṃ` 译「各个家族、各个地方、各个教派」，`pāsaṇḍa` 通常指「外道、异教派」，此处泛指各宗教团体，译「教派」可接受；但 `kula` 在此语境更接近「族姓/家世」。整体可接受。
- **问题**：准确性 — `mariyādācārittaṃ` 是复合词（`mariyādā` 界限/规矩 + `ācāritta` 习行），译「规矩和习惯」把复合词拆成并列，而原文更可能是「界限性的习行/依规矩而行的习惯」（依主释）。
- **建议**：改为「各个家族、各个地方、各个教派各自依规矩而行的习惯，就是**惯行戒**」。此处若有 nissaya 可定复合词关系，建议补取后再定案；现译降低 confidence。

## §138 句 64-138-14-39

- **问题**：准确性 — `na bodhisattamātu purisesu mānasaṃ uppajji kāmaguṇūpasaṃhitaṃ` 译「菩萨的母亲不会对男子生起与欲乐相应的心念」。`kāmaguṇa` 是术语「五欲功德/妙欲」，译「欲乐」偏窄；`purisesu`（处格复数）译「对男子」正确。
- **建议**：改为「不会对男子生起与妙欲（kāmaguṇa）相应的心念」，或至少统一为「欲乐功德」。此词未登记在 `term-glossary.jsonl`，定案后建议补入。

- **问题**：准确性 — `uppajji` 是过去式（aorist），经文原句为「不曾生起」；译文用「不会生起」（将来/习惯）。此为法性陈述句，汉译传统多作「不生起」，可接受，但「不会」略带推测意味。
- **建议**：改为「不生起」。

- **问题**：格式 — 引文用全角双引号 “”，✅ 符合 `style.md` 第五节。但本句引文缺出处标注，而 §139 两处引文均有出处（`vibha.508` 等）。原文本句 pali 无出处标记，故不补，✅。

## §138 句 64-138-40-55

- **问题**：准确性 — `suddhasattānaṃ` 译「清净有情」。`suddhasatta` 指本性清净的众生，译法可接受；但「有情」与「众生」在本 chunk 无冲突，✅。
- **问题**：准确性 — `tāsu tāsu jātīsu` 译「在各个生世中」，`jāti` 此处指「生（轮回中的一生）」，译「生世」略生造。
- **建议**：改为「在一生又一生中」或「在各生中」。

- **问题**：风格（文言残留）— 「而大迦叶等清净有情」句首的「而」对译 `pana`，是转折虚词，现代汉语中此处可省或改「至于」。
- **建议**：改为「至于大迦叶等清净有情，以及菩萨在各生中所持的戒，就是**宿因戒**」。

## §139 句 64-139-2-42

- **问题**：准确性 — `ācāragocarasampanno` 译「具足正行和行处」。`ācāra`（正行）与 `gocara`（行处）为传统定译，✅。
- **问题**：格式 — 出处标注「（分别论 508；长部经 1.193）」中「长部经」应作「长部」（`dī. ni.` = Dīghanikāya，「部」已含「经集」义，加「经」冗余）；`vibha.` = Vibhaṅga 译「分别论」✅。
- **建议**：统一为「（分别论 508；长部 1.193）」。同一问题见下面两句的「中部经」「增支部经」。

## §139 句 64-139-43-76

- **问题**：准确性 — `na nimittaggāhī hoti nānubyañjanaggāhī` 译「不执取相，不执取细相」。`anubyañjana` 传统译「随相/细相」，✅ 可接受。
- **问题**：准确性 — `yatvādhikaraṇamenaṃ ... anvāssaveyyuṃ` 译「由于住于不防护眼根，贪欲和忧恼这些恶不善法会流入他」。原文 `yatvādhikaraṇam`（以此为因）指向的是「因不防护眼根这个缘故」，译文的因果方向正确；但 `abhijjhādomanassā` 译「贪欲和忧恼」——`domanassa` 传统译「忧」，「忧恼」可；`abhijjhā` 译「贪欲」✅。
- **问题**：切分/标点 — 本句以「于眼根达成防护。」结尾，引号未闭合（引文延续到下一句 64-139-77-146 才闭合）。这在逐句切分下是必然的，但读者只看单句会觉得引号不成对。
- **建议**：可接受（跨句引文），但若导出 markdown 时以句为单位呈现，建议在本句末保留不闭合状态并依赖下句闭合，**不要**擅自补闭合引号造成重复。

## §139 句 64-139-77-146

- **问题**：格式 — 出处「（中部经 1.22、411；长部经 1.213；增支部经 4.198）」，同上应作「（中部 1.22、411；长部 1.213；增支部 4.198）」。
- **问题**：准确性 — `manasā dhammaṃ viññāya` 译「用意认识法时」。「用意」易被现代读者误读为「存心、居心」（现代汉语常用义）。
- **建议**：改为「以意根认识法时」或「用意门认识法时」。这是 `style.md`「判定标准」所说的会让现代读者读岔的写法，列为**必改项**。

## §139 句 64-139-147-175

- **问题**：准确性/句法 — 本句译文结构与原文不符。原文 `Yā pana ... vītikkamassa, ... pāpadhammānaṃ vasena pavattā micchājīvā virati, idaṃ ājīvapārisuddhisīlaṃ` 的骨架是：**「对于那种由…而起的邪命的远离（virati），这就是活命遍净戒」**——`virati`（远离）是中心词，`micchājīvā` 是其离格补语。译文作「因违犯…而起的邪命，以及因…等等恶法而起的邪命，远离这些邪命，这就是活命遍净戒」，把一个定语从句拆成了三个分句，「远离这些邪命」成了突兀的插入。
- **建议**：改为「而远离那种因违犯为了活命而制定的六条学处、以及因“诡诈、虚谈、现相、讥刺、以利求利”等恶法而起的邪命，这就是**活命遍净戒**。」

- **问题**：术语 — 五种邪命的译法「诡诈、虚谈、现相、讥刺、以利求利」中，`nippesikatā` 传统译「瞋骂示相/强求」，译「讥刺」偏窄；`nemittikatā` 译「现相」✅；`lapanā` 译「虚谈」✅。
- **建议**：`nippesikatā` 改为「强求」或「激恼取利」；这五词未登记在 `term-glossary.jsonl`，建议定案后整组补入。

## §139 句 64-139-176-213

- **问题**：准确性 — `yāvadeva sītassa paṭighātāya` 译「只是为了防御寒冷」。`yāvadeva` 意为「仅仅、只是为了」，✅；但原经此处通常是省略式（`…ti ādinā nayena`），译文未体现省略，直接以句号收尾。
- **建议**：可在引文末加省略号，作「……只是为了防御寒冷……」，以呼应 `ādinā nayena`（以这样的方式等等）；或维持现状但确保「以这样的方式所说的」能传达省略义——现译已有此意，可接受。
- **问题**：格式 — 出处「（中部经 1.23；增支部经 6.58）」同上应作「（中部 1.23；增支部 6.58）」。
- **问题**：准确性 — `paṭisaṅkhānaparisuddho catupaccayaparibhogo` 译「经过省察而清净的四资具受用」，✅ 准确。
