# Review — 66:547-551（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层对照（book 64 义注，定稿译文）✅／nissaya ❌ **未提供**／本层为复注，其上无更高层注 ❌
> 缺 nissaya 意味着格、数、隐含成分无独立词级基准，下列词法判定只能依父层与语境推定，凡涉及格与指代的条目已标「存疑」。

## 一、被解释词与父层逐字核对（首查项）

**已核对一致**（不再逐条列出）：samathabhāvūpagamanena→由于已经达到止的状态／tatramajjhattupekkhāya kiccavasena upekkhānubrūhanā veditabbā→应当就中舍的作用来理解舍的增长／vimuttirasena→以解脱之味／esa→他／vāhayati→策动／tasmiṃ khaṇe→在那一刹那／āsevanā→反复修习／te ākārā→这些行相／saṃkilesavodānesu→在杂染与清净两方面／taṃ taṃ ādīnavaṃ→各自的过患／ānisaṃsaṃ→功德／disvā→看到／sampahaṃsitattā→使它们喜悦／visodhitattā→使它们清净／yathāha→正如所说的／tathāpaggahitaṃ cittaṃ→这样策励起来的心／sādhukaṃ ajjhupekkhati→好好地保持舍／paññāvasena paññindriyaṃ adhimattaṃ hoti→以慧之力，慧根变得增强／cittaṃ vimuccati→心…解脱／vimokkhavasena→以解脱之力／vimuttattā→由于解脱／te dhammā→那些法／ekarasā→同一味／ñāṇakiccabhūtā sampahaṃsanā pariyosānaṃ→作为智的作用的喜悦就是后／paṭhamaṃ→初／jhānaṃ→禅／pathavīkasiṇaṃ→地遍／ārammaṇūpanijjhānato→因为审虑所缘／paccanīkajhāpanato→因为烧尽了与它敌对的法／sakalaṭṭhena→按遍满一切的意思／gaṇanānupubbatā→数目的次第。

**不一致或对应断裂**（下列逐条在第三节展开）：66-547-2-5、66-547-6-34、66-547-46-71（标点）、66-548-2-7、66-548-35-38、66-548-82-103（**tathā**）、66-548-108-130。

## 二、跨段一致性

- **āsevanā 词族**：§548 句 `66-548-44-53` 译「反复修习」（与父层 64-957 一致），紧邻的 `66-548-62-67` 把 `āsevanapaccaya` 译作「重复缘」，同一词根两个面貌，读者看不出这两句在讲同一件事 → 建议统一为「反复修习缘（āsevanapaccaya）」，首出夹注巴利原词。
- **tattha**：`66-548-8-12` 译「那里」、`66-549-37-41` 译「这里」。**这是有依据的差异**——分别对应父层 64-961「那里生起的」与 64-962「这里，由于智…」。harmonize 时**不要**把两处拉平。
- **pavatta- 词族**：本层一律译「转起」（`66-548-31-34`／`66-548-54-61`／`66-548-62-67`／`66-549-42-59`），父层同词族作「运转」（64-961「互不超越地运转着」、64-959「平稳运转的安止定」）。非黑体，不属硬约束，但属跨层漂移 → 建议 harmonize 时记一次取舍（倾向本层改「运转」向父层靠）。
- **sama- 词族**：「均衡运转」（`66-547-72-95`）／「均衡地转起」（`66-549-42-59`）／「均等相应」（`66-550-29-43`）。三处底词不同（samavāhita／samappavatti／samatā），可接受；若统稿求齐，取「均等」一系。
- **visodhana**：`66-548-82-103` 作「使它们清净」，`66-548-104-107` 作「使之清净」，相隔一句 → 统一为「使它们清净」。

## 三、逐句意见

### §547 句 66-547-2-5
- **问题**：被解释词对应断裂 — 黑体 **Tassā** 译作「它」，但父层 64-960-2-16「因为没有什么再需要清净的了」**根本没有译出这个代词**，读者无法在父层定位本条注的对象。
- **建议**：本层译文保持「“**它**”是指心」不动；把父层缺译记入 harmonize 待办，建议父层补为「因为它（心）没有什么再需要清净的了」。
- **存疑**：lemma 作阴性 `Tassā` 而释为 `cittassa`（中性），疑为异读或转写讹误；无 nissaya 可判，记录备案，不要改动原文。

### §547 句 66-547-6-34
- **问题**：黑体 **byāpāraṃ akaronto** 译「不作任何努力」，父层 64-960-2-16 作「不再在清净上作任何努力」，少一个「再」，非逐字。
- **建议**：改引作「“**不再作任何努力**”」。
- **建议（次要）**：`puggalādhiṭṭhānena āgatā`→「是以人为主体说出来的」可读性尚可，但 puggalādhiṭṭhāna 是固定术语，建议作「是按人（puggala）来立说的」，首出夹注巴利原词。

### §547 句 66-547-46-71
- **问题一**：黑体内部标点与父层不同 — 本层「舍弃了与烦恼的混杂**、**以一性而现起」，父层 64-960-27-41 作「舍弃了与烦恼的混杂**，**以一性而现起」。
- **建议**：改用逗号，与父层完全一致。
- **问题二**：准确性／可读性 — 现译「是指先前以“我该怎样…”而修行的**人**，如今……而以一性现起的那个**禅心**」，句子以「人」起、以「禅心」收，读者会以为在给「人」下定义。原文一串属格最终都落在 `jhānacittassa` 上。
- **建议**：改为「是指那个人的禅心——他先前抱着“我该怎样才能舍弃与烦恼的混杂呢”的想法修行，如今由于止的行道已经舍断了那混杂，这禅心不再与烦恼结伴，以一性而现起」。

### §548 句 66-548-2-7
- **问题**：`Ye panete` 在父层 64-961 未译出（父层直接从「在这样由舍增长之后，那里生起的…成双之法」起句），所以本层「“而那些”应当与“成双之法”连起来读」在父层找不到落点；此外「…连起来读，这就是句子的关联」语义重复。
- **建议**：本句精简为「“而那些”是与“成双之法”相连的」；父层缺译记入 harmonize 待办。

### §548 句 66-548-13-20
- **建议（次要）**：`yuganaddhā`→「成双」与父层「成双之法」一致，保留；但本句的取譬「就像被系缚在同一轭上一样」与「成双」二字之间的理据（yuga=轭）在中文里断了 → 建议作「所以叫做**成双**（yuganaddha，字面即“共轭相系”）」。

### §548 句 66-548-35-38 ⚠ 必改／释义冲突
- **问题**：本层明确释 `assa` = `jhānacittassa`（禅心的），而父层 64-961 把同一个 `cassa` 译成「**他**在那一刹那生起的反复修习」，指向瑜伽行者。**复注定释义**，父层此处与复注相悖：同段前文 `yañcesa … vāhayati` 的 `esa` 才是人（见 `66-548-28-30`），复注特意分辨这两个代词，现有两层译文把分辨抹平了。
- **建议**：本层改为「“**它的**”是指禅心的」，并在 harmonize 时同步把父层 64-961 改为「还有它（禅心）在那一刹那生起的反复修习」。两层必须一起动，单改一层会让对应更乱。

### §548 句 66-548-82-103 ⚠ 必改（三项）
- **问题一（被解释词／释义冲突）**：黑体 **tathā** 译「那样」，父层 64-961 把 `tathā tathā` 译作「**一次次地**」。本层明确读作 `yathā … honti, tathā …` 的相关结构（「如诸法之互不超越等等得以成立那样」），「一次次地」是把它当成反复副词，与复注释义相悖。
- **建议**：本层保留「那样」；父层 64-961 记入 harmonize 待办，改为「从而就那样使它们喜悦、使它们清净、使它们皎洁」。
- **问题二（风格 — 文言虚词，`style.md` 禁例表命中）**：「**各自的过患**即过失、**功德**即优点」连用两个文言「即」。
- **建议**：改为「看到**各自的过患**也就是过失、**功德**也就是优点」。
- **问题三（准确性／可读性）**：「然后**怎样才能使**诸法互不超越等等，就**那样**由修习而…」——`yathā … honti` 被译成疑问兼目的句，读者会理解成「在设法使诸法互不超越」，原意只是「如其成立的那个样子」。
- **建议**：整句改为「就这样，在这杂染与清净两方面，先用能除遣敌对法的智**看到****各自的过患**也就是过失、**功德**也就是优点，然后按照诸法互不超越等等得以成立的那个样子，**那样**由修习而**使它们喜悦**，由那同一个智而**使它们清净**」。
- **存疑**：`pāṭihāriyañāṇa` 译「能除遣敌对法的智」取的是 paṭiharaṇa（除遣）一解，另有「神变智」一读；父层无对应词可校，无 nissaya 可判 → 维持现译，**压低该句 confidence**，定案前不入 `terms.md`。

### §548 句 66-548-104-107
- **问题**：`Visodhanaṃ hettha sampahaṃsanaṃ` 是把上句两个动作划等号，现译「这里所说的使之清净，就是喜悦」把后项由动作降成状态，等号两端不对称。
- **建议**：改为「因为这里所说的“使它们清净”，就是“使它们喜悦”」。

### §548 句 66-548-108-130
- **问题**：黑体收尾 **vuttaṃ** 译「所以才**这样**说」，父层 64-961 作「所以才说」，多一个「这样」，非逐字。
- **建议**：改为「“**诸法……乃至……应当这样知道，所以才说**”」。

### §550 句 66-550-63-73
- **建议（次要）**：「以盖为首的**种种自性的**烦恼」读来生硬，`nānāsabhāvehi` 是说烦恼自性各别 → 改为「从自性各别、以盖为首的种种烦恼中**解脱**出来」。

### §550 句 66-550-88-99
- **问题**：黑体被中文语序拆散 —「所谓**同一味**，就是**成为**作用相同」，「成为」夹在「就是」与「作用相同」之间，句子不通。
- **建议**：改为「“**那些法**”是指信等诸法，尤其是信、慧、精进、定；它们**成为****同一味**，也就是作用相同」。

### §550 句 66-550-116-135
- **问题（歧义）**：「由于得到了殊胜的三种舍的增长」可读成「殊胜的三种」，原文是三种舍的增长本身已臻殊胜（`laddhavisesāya`）。
- **建议**：改为「由于三种行道清净，又由于三种舍的增长已臻殊胜，慧根格外增强，四种喜悦也就成就了」。

### §551 句 66-551-2-11
- **问题（可读性）**：「“**数目的次第**”是指由于数目的次第」——原文是给该词定格（具格义），中文无格变化，照搬成同语反复，读者看不出在说什么。
- **建议**：改为「“**数目的次第**”这个词在这里作“由于数目的次第”解；或者说，这里所谓“初”只不过是数目的次第而已——这就是它的意思」。

### §551 句 66-551-90-103 ⚠ 必改（歧义）
- **问题**：「也就是地的圆轮，**整个地**作为所缘的意思」——前文刚出现「那一块地」，紧接着的「整个地」极易被读成名词「整个大地」，实际 `sakalārammaṇakaraṇaṭṭhena` 是「把它整体作为所缘」。
- **建议**：改为「……也就是地的圆轮，把它整体作为所缘的意思」。

### §551 句 66-551-110-122 / 66-551-123-134
- **建议（次要）**：「床在喧闹」「长矛在走动」两个譬喻在中文里没有出处支撑，读者不明白为何举例 → 建议其一加极简注，如「就像说“床在喧闹”（其实喧闹的是床上的人）一样」，另一处同例可省。
