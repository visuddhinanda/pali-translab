**准确性**：三句均为 5. Ekāsanikaṅgakathā（一坐食支）章末的结颂与结语，整体取义方向正确，无违背教理的判断错误，未见 fatal。主要问题集中在两处：

1. 509/510 本是**一首偈颂的上下句**（`Janayetha visuddhamānaso, ratimekāsanabhojane yatī ti`），语法上 `janayetha` 是唯一谓语（祈使/愿望语气），`ratiṃ` 是它的宾语，`yatī`（行者）是主语，`visuddhamānaso`（心意清净的）是修饰 `yatī` 的形容词。译文把两段各自独立成句，509 译成"心意清净者，应当生起——"、510 译成"行者对一坐食的喜乐。"，导致：`visuddhamānaso` 与 `yatī` 被拆成两个互不相干的指称主体（一个在上句作主语、一个在下句另起），读者会读成两个人；510 单独看则成了一个没有谓语的残句。按坐标分句不可合并是硬约束，但**跨段承接可以靠措辞衔接**（例如上句保留主语悬置、下句以谓语收束），现译的破折号加句号处理没有做到。

2. 511 的 `bheda` 连译问题。`samādāna-vidhāna-ppabheda-bheda-ānisaṃsa-vaṇṇanā` 是《清净道论》十三头陀支各章固定的结语公式，历来解作**受持（samādāna）、规定/作法（vidhāna）、区分（pabheda）、破（bheda）、功德（ānisaṃsa）**五项——译文五项俱全、顺序正确，这点是对的。但"区分、破"二字紧邻并列且均为单字，"破"在此指**头陀支的破损（失坏）**，孤字入文读者无从索解，属于关键词语意不明确。

**风格**：主要扣分在文言语体。511 的"以上就是…的解说"尚属现代书面语，但 509 的"应当生起"与破折号悬置、"心意清净者"的"者"字结构，整体读感偏文。`knowledge/style.md` 第一节明令"此类人、此人"一类"者/此"结构改现代说法，"心意清净者"虽非禁例表原条，但同属单音节文言词+"者"的凝缩式，宜作"心意清净的行者"。全角标点使用正确，未见 ASCII 引号，未见残留工作标记。

**一致性**：三句术语统一（"一坐食"贯穿 510、511，与章题 Ekāsanikaṅga 对应），称谓统一，无跨句漂移。仅 510 用"一坐食"、511 用"一坐食支"，这是原文 `bhojane` 与 `aṅge` 的区别，属正确区分而非不一致。

## 问题清单

### 🟧 error

- `64-510-2-4`｜错译（修饰关系）｜片段「行者对一坐食的喜乐。」
  - 问题：`yatī`（行者，主格）是 509 `janayetha` 的主语，`visuddhamānaso`（心意清净的）是修饰 `yatī` 的定语，二者同指一人。现译把 509 的"心意清净者"当作独立主语、510 的"行者"另起一个指称，读者会理解为两个主体；且本句无谓语，单独成句时是残句。
  - 建议：跨段衔接上补出承接关系，使 509 的主语与 510 的"行者"显为同一人，例如 509 作"心意清净的行者，应当生起——"、510 作"——对一坐食的喜乐。"，或 510 以"…这样的喜乐，行者应当生起"回指。不合并段落，只调措辞。

- `64-509-2-4`｜代词指代错误｜片段「心意清净者，」
  - 问题：同上条的另一面。`visuddhamānaso` 在原文中不是独立的指称名词，而是 `yatī` 的定语；译成"…者"后它变成了本句的主语，与 510 的"行者"形成两个并列指称，指代关系被切断。
  - 建议：与 510 合并考虑指称，见上条建议。

### 🟨 warning

- `64-511-2-5`｜关键词语意不明确｜片段「区分、破与功德」
  - 问题："破"（`bheda`）在头陀支语境中指**该支的破损/失坏**（即因何种行为而丧失此支），单字"破"脱离上下文无法索解，属二意场合无注释。
  - 建议：改为"破损"或"失坏"，或作"区分、破损的情形与功德"；如项目体例要求保持五项单字对仗，则需在首次出现处加简注说明"破"指头陀支的失坏。

- `64-509-2-4`｜文言语体｜片段「应当生起——」
  - 问题：`janayetha` 是愿望/劝诫语气，"应当生起"作为谓语在现代书面汉语中偏文，加上破折号悬置宾语，整句读感近似古文译体；`style.md` 判定标准为"让没有古文基础的读者觉得像文言即不合格"。
  - 建议：改为"就该生起"或"应该培养起"，并把宾语结构理顺到下句，避免破折号悬置。

- `64-509-2-4`｜文言语体｜片段「心意清净者」
  - 问题：单音节词+"者"的凝缩式，同 `style.md` 禁例表中"此类人／此人 → 这样的人／这个人"一类。
  - 建议：改为"心意清净的行者"或"内心清净的行者"。
