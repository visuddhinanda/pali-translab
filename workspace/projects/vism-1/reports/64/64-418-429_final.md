## 理由

**取数说明（降级）**：本次评估注入的资源只有巴利原文与目标 channel 译文。**义注（aṭṭhakathā）与 nissaya 均未注入**——本段本身即《清净道论》头陀支品的论体文（book=64，mūla 层），其复注（Paramatthamañjūsā）与缅文 nissaya 是核定词源释义（nibbacana）取义的主要依据，缺失。因此准确性打分只能依据巴利原文语法与文内自洽性作出，**与"义注定释义、nissaya 定词法"的标准基准相比是降级评估**，信心指数据此压到 62。尤其 `64-426`、`64-427`、`64-429` 三段是密集的词源拆解（piṇḍapāta / apadāna / pattapiṇḍa），传统取义争议大，无复注对照时结论不牢。

**准确性**：主谓宾判断整体正确，未见违背教理原则的 fatal 级问题。十三头陀支名的列举（`64-419-16-43`）覆盖完整、无漏译。主要扣分在三处：`64-424-34-44` 把 `dhāraṇaṃ`（持用）的复合词解释译成"穿着……这件事也叫做粪扫衣"，语序与"得到了词源解释的"这个前置定语叠加后，读者难以还原原文的"paṃsukūlassa dhāraṇaṃ = paṃsukūlaṃ"这一层定义；`64-429-10-17` 的 `Idāni ... pattapiṇḍasaññaṃ katvā` 译作"接下来，对于在钵中取食这件事也作'钵食'之想"，`Idāni` 在此是论主行文的"现在（就此义）"而非时间上的"接下来"，且 `pattapiṇḍagahaṇe`（于钵食之取用）与后半的逻辑衔接被"也"字弄含糊；`64-427-2-12` 以"断"对译 `dāna`（= avakhaṇḍana 切断），与佛教常识中的 dāna（布施）同形异义，译文未作任何提示，普通读者极易误解为"布施"。

**风格**：现代汉语基调达成，无"此中/是故/彼等"一类硬文言。但仍有若干单音节文言词与文言句式残留（"以……为常法"反复出现、"是他的常行/常法"、"离开了'断'"、"带着'不断'"），构成半文半白的夹层；这类词源训释段落最容易滑向文言，需要按 `knowledge/style.md` 第一节改写。另外术语首次出现夹注巴利原词的规则执行不一致（见一致性）。

**一致性**：同一个 `sīlamassa` 结构在 `64-424`/`64-425`/`64-428`/`64-429` 统一译为"以……为常法的人"，良好；但 `64-427-22-31` 同结构译为"是他的常法，所以叫做……"，句式脱节。术语夹注方面，`paṃsukūla`、`piṇḍapātika`、`piṇḍapātī`、`sallekha`、`subharatā` 有夹注，而同属首次出现的 `saṅghāṭi/uttarāsaṅga/antaravāsaka`（僧伽梨、郁多罗僧、安陀会）、`sapadāna`、`pattapiṇḍa`、`dhutaṅga`（头陀支）均无夹注，取舍标准不明。最突出的是 `64-427`：`sapadānacārī` 译"次第行者"、`sapadānacāriko` 译"次第乞食者"，两个中文词形不同却在原文是同词，而 `64-426` 的平行结构 `piṇḍapātī`（乞食行者）/`piṇḍapātiko`（常乞食者）处理方式又不同，跨段落术语对应关系不稳。

## 问题清单

### 🟧 error

- `64-427-2-12`｜导致误解的表达｜片段「“断”（dāna）指的就是切断」
  - 问题：`dāna` 在此处是 `dā-`（切）系的词，义为"切断"，与常见的"布施"（dāna）同形。译文直接写"'断'（dāna）"而未作任何区分说明，有佛教背景的读者会立刻联想到布施，与本段词源训释完全无关，属导致误解的表达。
  - 建议：夹注处加极简提示，或改用不引起歧义的呈现方式，使读者知道此 `dāna` 非彼 `dāna`。需复注/nissaya 确认后定稿。

- `64-424-34-44`｜错译（修饰关系）｜片段「穿着这样得到了词源解释的粪扫衣，这件事也叫做粪扫衣」
  - 问题：原文 `Evaṃ laddhanibbacanassa paṃsukūlassa dhāraṇaṃ paṃsukūlaṃ` 的结构是"〔如此得到词源解释的粪扫衣〕之〔持用〕= paṃsukūla（中性名词）"，是一个定义式等式。译文把定语"这样得到了词源解释的"直接挂到"粪扫衣"上作前置修饰，再用"这件事也叫做"补接，等式关系被打散，且"也叫做"暗示是第二种叫法，而原文是同一名相的另一层指称（衣 → 持衣之行）。
  - 建议：还原"A 之 B 叫做 C"的定义式句式，使"持用"成为被定义项的中心语。

- `64-429-10-17`｜错译（词义）｜片段「接下来，对于在钵中取食这件事也作“钵食”之想」
  - 问题：`Idāni` 在论疏训释语境中指"现在（就此而言）"，是行文转入下一层定义的标记，译"接下来"把它读成了时间顺序；且 `pattapiṇḍagahaṇe pattapiṇḍasaññaṃ katvā` 是"于钵食之取用上作钵食之想"（即把"取用"也名为 pattapiṇḍa），译文的"也作……之想"把施事与逻辑关系都模糊了，与下句"以这样的钵食为常法"的衔接因此变松。
  - 建议：按 `64-424-34-44` 同类定义式统一处理（食物 → 取食之行 → 以之为常法者），并改掉"接下来"。

### 🟨 warning

- `64-427-22-31`｜文言语体｜片段「次第而行是他的常法」
  - 问题：文言句式，且与本 chunk 其余四处同结构（`taṃ sīlamassa`）的统一译法"以……为常法的人"不一致。
  - 建议：统一为"以次第而行为常法的人，就是次第行者"。

- `64-427-13-21`｜文言语体｜片段「带着“不断”，就是“次第”（sapadāna）」
  - 问题：`Saha apadānena` 译作"带着'不断'"，是逐字硬对的半文半白表达，现代读者读不出"与不间断相伴随"的意思。
  - 建议：改为现代汉语的说明式表述。

- `64-427-2-12`｜文言语体｜片段「离开了“断”，就是“不断”（apadāna）」
  - 问题：同上，`apetaṃ dānato` 的"离开了……"是文言式直译。
  - 建议：改为"不带有'断'的"一类现代表述。

- `64-418-2-24`｜关键词语意不明确｜片段「已经受持了戒的修行者就应当受持头陀支」
  - 问题：同一句内"受持了戒"与"受持头陀支"，原文分别是 `samādinnasīlena`（已受持戒）与 `dhutaṅgasamādānaṃ`（头陀支之受持），中文用同一个"受持"没错，但紧邻重复使句子读来含混；另 `dhutaṅga`（头陀支）为全篇核心术语、此处首次出现，未按 `knowledge/style.md` 夹注巴利原词。
  - 建议：首次出现处夹注 `dhutaṅga`；调整句内重复。

- `64-425-2-8`｜该使用而没有使用术语标记｜片段「以称为僧伽梨、郁多罗僧、安陀会的三衣为常法的人」
  - 问题：僧伽梨 / 郁多罗僧 / 安陀会三词首次出现，均为音译法相术语，按风格配置"罕见或有争议的术语用巴利音译，首次出现附简注""法相术语首次出现夹注巴利原词"，此处三个都没有夹注。同 chunk 内 `sallekha`、`subharatā`、`paṃsukūla` 却都夹注了，标准不统一。
  - 建议：补夹注 `saṅghāṭi` / `uttarāsaṅga` / `antaravāsaka`。

- `64-418-35-45`｜整句逻辑表达不规范｜片段「先安住在古来的三种圣种上，然后就有资格证得第四种」
  - 问题：原文 `porāṇe ariyavaṃsattaye patiṭṭhāya ... adhigamāraho bhavissati` 是连续体（gerund）构成的同一动作链，译文加入"先……然后……"把它明确成时间先后的两阶段，语气比原文强。是否构成阶段论，需义注/复注定夺；此处以行文规范计为 warning。
  - 建议：弱化"先/然后"的阶段化表述，或待复注核对后定稿。

### 🟦 suggestion

- `64-426-17-26`｜语言风格不统一｜片段「所以叫做**常乞食者**（piṇḲapātika）」
  - 问题：`piṇḍapātika` 译"常乞食者"，而下一句 `piṇḍapātī` 译"乞食行者"，两个词在原文是同义异形（论主明言 `piṇḍapātī eva piṇḍapātiko`），中文用两个不同词形虽可行，但对照 `64-427` 的 `sapadānacārī`（次第行者）/ `sapadānacāriko`（次第乞食者）时，四个中文术语的对应关系互相错位，读者难以看出哪两个是同一个。
  - 建议：在 `426`/`427` 两段间统一"-ī 形 / -ika 形"的译名配对规则。

- `64-426-27-39`｜复杂嵌套句理解困难｜片段「为团食而落下是他的常行，所以叫做乞食行者（piṇḍapātī）；这里的“落下”就是“行走”的意思」
  - 问题：训释链"落下 → 行走"在中文里断开成两个分句后，读者读到前半会先被"落下"卡住，读到后半才得到解释，属对读者不友好的语序。
  - 建议：把释义前置或改为夹注式说明。

- `64-429-2-9`｜语言表达不够流畅｜片段「由于不用第二个容器，食物就只盛在唯一的一个钵里」

  - 建议：改为"由于遮止了第二个容器，食物只盛在同一个钵里"。

- `64-424-2-33`｜语言表达不够流畅｜片段「就堆起这一点来说」
  - 问题：`abbhuggataṭṭhena`（以高起、堆积之义）译作"就堆起这一点来说"，口语化插入语在训释段中显得突兀，与前后书面语体不匹配。
  - 建议：改为"就其高起堆积之义而言"一类与上下文匹配的表述。

- `64-423-2-7`｜关键词语意不明确｜片段「应当知道（关于头陀支的）抉择」

  - 建议：补足成分移入紧随其后的散文部分，或改为不打断偈颂的处理。
