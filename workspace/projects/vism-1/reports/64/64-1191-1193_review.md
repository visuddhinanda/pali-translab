## 跨段一致性

- `arahaṃ`：§1191 译「阿罗汉」，§1193 译「阿罗汉」→ 一致 ✅（与 `term-glossary.jsonl` 的 `arahant: 阿罗汉` 相符）
- `arayo / arī`：§1191 译「敌」（烦恼之敌），§1192 译「敌人」→ 同源同义，可接受；但 §1191 的黑体词目 `arīnaṃ` 译作「敌人」更妥（见下）
- `hatā / hatattā`：§1191「断除」、§1192「断除」、§1193「断除」→ 用词一致 ✅
- **跨段衔接问题（必改）**：§1192 与 §1193 是同一首偈的上下句，谓语 `hatā` 只有一个，却在两段译文里各出现一次「断除」——连读成「一切敌人都已被断除；被依怙者用智慧之剑断除，所以……」，重复且句法散乱。§1193 的 `paññāsatthena nāthena`（具格＋具格）是 §1192 `hatā` 的施事与工具，不是新的谓语。建议：§1192 收在「……都已被断除——」，§1193 改为「被依怙者以智慧之剑（所断），所以他也被称为阿罗汉。」
- 语体：三段均为现代书面汉语，未发现文言虚词或文言句式 ✅；全角标点、无 ASCII 引号 ✅

## §1191 句 64-1191-2-13

- **问题**：语态／格位 — `arīnaṃ hatattā` 是「属格＋抽象名词从格」，字面为「因敌人之被断除的状态」，施事在前半句已交代（`anena ... maggena`）。译文「因为已断除敌人」把它改成了以阿罗汉为主语的主动句，与词法不合，也削弱了 `ari + hata → arahaṃ` 这一被动式词源分析的成立基础。
- **建议**：改为「因为敌人已被断除」。（此处为黑体词目，若义注／复注引出同一词，须与其译法逐字一致，待资源到位后复核。）

- **问题**：句式 — 因果关系叠加，「由于……所以因为……他也就是……」三重连接词连用，读来绕口。
- **建议**：拆开因果层次，例如：「这些作为敌人的烦恼，已被他用道断除；因此，由于敌人已被断除，他也就是阿罗汉。」

- **问题**：词源可读性 — `arīnaṃ hatattā → arahaṃ` 是谐音式词源解释（ari「敌」＋ hata「已断」），中文读者从「敌人已被断除」看不出与「阿罗汉」的构词关联，整句因此像是无来由的推论。
- **建议**：按 `style.md`「法相术语首次出现夹注巴利原词」，作「阿罗汉（arahaṃ）」；构词理据不写进正文，留给 footnote 步处理。

## §1192 句 64-1192-2-8

- **问题**：`sabbepi` 的 `api` 未落实 — 译文「一切敌人，都已被断除」中的「都」承担的是 `sabbe`，`api` 的强调义（连……也／无一例外）落空。
- **建议**：「因为被称为贪等的一切敌人，无一不被断除——」；末尾标点配合上条跨段衔接建议，由分号改为破折号或逗号。

## §1193 句 64-1193-2-8

- **问题**：句法归属 — 见「跨段一致性」末条，`paññāsatthena nāthena` 是 §1192 `hatā` 的具格施事＋工具，译文另起「被……断除」形成第二个谓语。
- **建议**：「被依怙者以智慧之剑（所断），所以他也被称为阿罗汉。」

- **问题**：术语待定 — `nātha` 译「依怙者」。`terms.md` 与 `term-glossary.jsonl` 均未登记该词，另有「救护者」「怙主」等常见译法。
- **建议**：本次沿用「依怙者」不变（有传统依据），压低该句 `confidence`；待义注给出释义后定案，并补入 `terms.md`。

- **问题**：措辞 — `mato`（√man 过去分词）意为「被认为／被称作」，译「被认为是」略显主观推断；此处是定名，作「被称为」更贴。
- **建议**：「所以他也被称为阿罗汉。」
