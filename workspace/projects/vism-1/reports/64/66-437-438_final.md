## 理由

**基准可用性**：本次未注入义注（aṭṭhakathā）与 nissaya 两项基准。本段是《清净道论》复注（ṭīkā）对地遍解说的注释，其黑体被解释词（Phāsu hoti / Parisodhentena / Akilamantoyeva / Gaṇṭhiṭṭhāna / Chinditvā / Suvisuddha）引自义注《清净道论》本文，按跨层硬约束应与父层译文逐字同译——但父层译文未注入，无法核对同译一致性。词级格与句法角色也缺 nissaya 佐证。因此评分只能基于巴利原文自身的词法句法与风格规范，信心指数相应压低到 62。

**准确性**：整体取义可靠，复注特有的「以…vasena / …ti adhippāyo / …ti attho」释义框架都译出了，没有漏译整句。主要失分在两处词法：`akilantakāyo` 是 bahubbīhi 形容语（「身体不疲劳的」），译文作「身体没有疲劳的人」，把复合词实体化为「人」，而原句是对副词 `akilamanto`（现在分词，与行者同格）的释义，译成「的人」与被释词的词性不对应；另一处是 `suṭṭhu visuddhaṃ` 的拆解被译成元语言式的「“极为”就是“非常”的意思」，把巴利 `su-` 前缀的训释直接搬成汉语词义解释，汉语读者读到的是「极为＝非常」这种无信息的同义反复，实际应释为「彻底地清净」。

**风格**：`knowledge/style.md` 第一节是硬约束，要求现代书面汉语。本段残留数处文言/半文半白：「使它清净」「使它清楚明白」中的「它」尚可，但「因而成为结节的地方」「没有丛生的杂枝、没有纠结」偏文；真正触禁例的是 66-438-61-69 的「十分显明」与整句的训诂体裁，以及多处以「就是」硬接的注释句式虽不违禁但节奏单调。此外「这就是意思」「意思是」「就是…的意思」三种译法在七句内混用，属风格不统一。

**一致性**：`gaṇṭhiṭṭhāna` 前后统一作「疑难的结节」，`adhippāya` 统一作「意趣」，`atthato` 作「意义」，术语内部自洽，这是本段最扎实的部分。但 `adhippāyo`（句末释义套语）与 `adhippāyassa`（被释词「意趣」）同形异用，译文分别作「这就是意思」与「意趣」，处理正确。

## 问题清单

### 🟧 error

- `66-438-23-27`｜错译（词义、修饰关系）｜片段「就是身体没有疲劳的人」
  - 问题：`akilantakāyo eva` 是 bahubbīhi 复合词作形容语，承接被释词 `akilamanto`（现在分词，与修行者同格，作状语「不疲倦地」）。译作「…的人」把形容语实体化为名词，与被释词「毫不疲倦地」词性错位，读起来像在定义一类人而非解释一个状语。
  - 建议：改为与被释词同性的表述，如「就是身体不疲劳」或「就是身体没有疲劳的状态」。

- `66-438-61-69`｜义理或用词与注释书不符｜片段「“极为”就是“非常”的意思，也就是非常清净」
  - 问题：`suṭṭhu visuddhaṃ` 是复注对 `suvisuddha` 中 `su-` 前缀的训释，等式落在巴利词层面。直译成汉语的「“极为”就是“非常”」是把巴利训诂搬进汉语，对汉语读者是无信息的同义反复，且「非常清净」弱化了 `suṭṭhu`（彻底、完全）的语义。
  - 建议：按释义而非按词形译，如「**极为清净**——就是彻底地清净」，`su-` 的训释不必在正文重复。

### 🟨 warning

- `66-438-28-35`｜不导致误解的汉语语病｜片段「这就是意思」
  - 问题：`…ti adhippāyo` 的套语译法在本段出现三次而用了两种写法（「这就是意思」「意思是」），同一套语译法不统一；且「这就是意思」单独成句略显生硬。
  - 建议：全段统一为「意思是…」前置，或统一为「——此即其意趣所在」之外的现代说法，如「意思是：身体疲劳时，对业处的作意就可能受阻」。

- `66-438-61-69`｜文言语体｜片段「十分显明」
  - 问题：「显明」为文言色彩的单音节组合词，`knowledge/style.md` 要求能用双音节现代词就不用文言词。
  - 建议：改为「十分清楚」或与前文「清楚明白」合并，避免重复堆叠。

- `66-438-61-69`｜文言语体｜片段「没有丛生的杂枝、没有纠结」
  - 问题：`nigumba`（无丛林）`nijjaṭa`（无纠结）是比喻性训释，译文保留了比喻但「杂枝」「纠结」并列后语义不明——读者难以判断这是在说文义还是说植物。
  - 建议：点明比喻对象，如「就像没有丛生的枝蔓、没有缠结的乱麻一样，文义毫无窒碍」。

- `66-438-36-45`｜关键词语意不明确｜片段「因而成为结节的地方」
  - 问题：`gaṇṭhibhūtaṃ ṭhānaṃ` 译作「成为结节的地方」，「地方」在汉语里默认指空间处所，此处实指文本中的疑难处，读者易误解。
  - 建议：改为「因而成为疑难症结的地方」或「因而打成死结的文句」。

### 🟦 suggestion

- `66-438-2-14`｜语言表达不够流畅｜片段「在作意上就有安适，也就是随顺修习」
  - 问题：`manasikāraphāsutā bhāvanānukūlatā hoti` 两个抽象名词并列为谓语，译文用「也就是」连接，逻辑关系（前者即后者，还是前者导致后者）不够明确。
  - 建议：明确为「作意就安适，也就是顺于修习」，或「作意得以安适，从而顺应修习」。

- `66-438-15-22`｜该使用而没有使用术语标记｜片段「种种疑难的结节」
  - 问题：`gaṇṭhiṭṭhāna` 是本段反复出现并在下文专门立条训释的关键词，首次出现宜按 `knowledge/style.md` 夹注巴利原词。
  - 建议：首次出现处作「疑难的结节（gaṇṭhiṭṭhāna）」，其后只用汉译。

- `66-438-46-60`｜语言风格不统一｜片段「意思是使它清楚明白、十分显明」
  - 问题：同句内「以…的方式来断除」与「意思是使它…」两种句式叠用，句子重心散落；「清楚明白」与「十分显明」语义重复。
  - 建议：合并为「意思是把意义和意趣如实阐明，使文义清楚明白」。
