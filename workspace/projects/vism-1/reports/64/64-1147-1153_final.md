## 理由

**资源缺口（影响信心）**：本次评估仅注入了巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**，无法按方法文档的首要基准（义注定释义、nissaya 定词法）逐词核对格与句法角色。以下判断依据巴利原文本身的形态与《清净道论》相关语境（本段为 Visuddhimagga 不净业处章末的 mūla 文本，带偈颂收束）作出，属降级评估。涉及词法的判定（如 `vivaratā`、`dvāraṃ datvā`、`sīmasambheda`）若 nissaya 另有取义，结论可能需要修订——信心指数据此压到 72。

**准确性**：整体语义骨架正确，长句拆分得当，引文嵌套（1148 段两重引述义注）的层次处理清楚，`vatvāpi puna anantarameva` 的转折关系译出了「虽然…紧接着却又」，是本段最难的结构，处理到位。主要扣分在两处：`upacārāvahattā` 的因果方向被译反（近行是果不是因，见 error 第 1 条）；`vivaratā` 作抽象名词，译文以「呈现的是有空隙的样子」补出主语与判断，属加译（见 error 第 2 条）。1150–1151 两句偈颂的语序重组虽可读，但把 `subhaguṇo`（美德/善德）归给不净所缘本身，与 `asubhāni` 的并列关系有含混（见 warning）。

**风格**：现代书面汉语的底线基本守住，无「此中／彼等／故为」类硬文言，标点全角、引号用弯引号 “”，未出现 ASCII 引号，符合 JSON 安全硬约束。但残留若干单音节文言虚词与文言句式：「随取一处」「这话」尚可，「不加分别」「只就…本身而被见到时」偏生硬；1149 段「就是这里的例证」前的破折号插入语结构过长。另有两处文言虚词「乃至」类未出现，但「即使」「至于」「而」的连用使 1147 段后半略显板滞。夹注巴利原词的做法（喜（pīti）、悦（somanassa）、界限（sīmasambheda）、杂论（pakiṇṇakakathā））符合 style.md 第二、三节，但**同段内首现夹注的密度偏高**，1148 段 `brahmavihāra`／`asubha` 这类更需夹注的核心术语反而未夹注，取舍标准不统一。

**一致性**：`uggahanimitta`＝取相、`paṭibhāganimitta`＝似相、`nimitta`＝相 三词在 1147、1148 两段贯穿一致，无漂移；`aṭṭhikasaṅkhalikā`＝骨链、`aṭṭhika`＝骨 稳定。跨段代词回指（1152「那些不净」、1153「它们」）指向 1150–1151 偈颂所述对象，链条完整。扣分点是 1147 段「不净」一词兼指所缘类别（puḷavakādīsu 虫聚等不净）与十不净法门，未加区分。

## 问题清单

### 🟧 error

- `64-1147-74-78`｜错译（修饰关系）｜片段「由于能够引生近行定，所以应当是能生起喜（pīti）与悦（somanassa）的」
  - 问题：`upacārāvahattā` 是夺格（-ttā）表**原因**，直译为「因为它能引来近行（定）」。但此处的逻辑是：似相之所以带喜与悦，**正因为**它能导向近行定——译文把「引生近行定」当成前提、「生起喜悦」当成结论，方向本身不错；真正的问题是 `pītisomanassajanakena` 与 `bhavitabbaṃ`（承上句省略）的关系被拆成了两个分句，使「应当是」的规范性语气落在了果上。更稳妥的读法是「而似相则应当是能引生喜与悦的，因为它能导向近行定」。现译的「由于…所以应当」把因果与应然混为一谈。
  - 建议：调整为「而似相则应当是能生起喜（pīti）与悦（somanassa）的，因为它能引来近行定」。此条依赖 nissaya 的格助词确认 `upacārāvahattā` 是否确为原因夺格，建议取到 nissaya 后复核。

- `64-1147-57-62`｜错误多译｜片段「取相显现时呈现的是有空隙的样子」
  - 问题：原文 `uggahanimitte paññāyamāne vivaratā` 是「取相显现时，（有）空隙性」，`vivaratā` 为抽象名词，与下句 `paripuṇṇabhāvo yujjati` 的 `yujjati` 共享谓语。译文补出「呈现的是…样子」，并在下句重复「呈现为…的样子，这才恰当」，把一个共享谓语拆成两个完整判断，属加译。
  - 建议：改为「至于整具骨链，取相显现时是有空隙的，似相显现时则是完整的——这样才恰当」，让两句共用一个 `yujjati`。

- `64-1148-2-13`｜导致误解的表达｜片段「正是留下了余地之后才说出来的」
  - 问题：`dvāraṃ datvāva vuttaṃ` 直译「给了门之后才说」，指义注的说法**留了一道门（即留有进一步解释的余地／有所保留）**。「留下了余地」方向对，但「正是…才说出来的」的强调句式使读者误以为重点在「说出来」这个动作，而原文重点在「带着保留地说」。
  - 建议：改为「是有所保留地说的」或「是留了余地才那样说的」。

### 🟨 warning

- `64-1150-2-8`｜关键词语意不明确｜片段「功德美善、名声受千眼者（帝释）赞颂的」
  - 问题：`subhaguṇo` 与 `asubhāni` 在偈中构成「不净的所缘 / 美善的功德」的对照修辞，译文「功德美善」四字并置，读者难以判断这是在说不净观的功德，还是在说所缘本身美善——而所缘恰恰是「不净」。语意在此处是含混的。
  - 建议：明确为「那些不净（观）虽以不净为所缘，功德却是美善的」，或至少加「其」字点明功德归属。

- `64-1148-32-55`｜整句逻辑表达不规范｜片段「不加分别、只就厌恶的状态本身而被见到时，那才叫作相」
  - 问题：`nibbikappaṃ katvā paṭikkūlabhāveyeva diṭṭhe` 是处格独立结构，译文「而被见到时」用了欧化被动，且「不加分别」与「只就…本身」两个状语堆叠在主语之前，句子重心后移过远，读来吃力。
  - 建议：改为「而在十不净中，是不加分别、只在厌恶的状态上见到它时，才叫作相」。

- `64-1149-2-10`｜不导致误解的汉语语病｜片段「整个女人的身体就作为一堆骨头显现出来——这一类显现等等，就是这里的例证」
  - 问题：破折号前后「显现出来」与「这一类显现」语义重复；「等等」承 `°ādīni` 而来，但夹在「这一类显现」与「就是」之间，句子松散。
  - 建议：改为「……整个女人的身体就现为一堆骨头。诸如此类，都是这里的例证。」

- `64-1147-2-18`｜标点符号使用错误｜片段「正如在这里（骨想中）所说的那样」
  - 问题：（骨想中）是译者补注，非巴利原词夹注。style.md 第三节规定圆括号用于「术语首次出现附巴利原词」，此处用同一形式承载译者增补，与全篇夹注体例（喜（pīti）等）混同，读者无法区分哪些括号是原词、哪些是补注。
  - 建议：改用破折号或直接融入行文「正如上面讲骨想时所说的那样」。

### 🟦 suggestion

- `64-1148-14-26`｜该使用而没有使用术语标记｜片段「在四梵住和十不净中没有似相」
  - 问题：`brahmavihāra`（梵住）与 `asubha`（不净）是本段论旨所系的核心术语，且「十不净」作为固定法数首次出现，按 style.md 第二节「法相术语首次出现夹注巴利原词」应夹注；而同段的「界限（sīmasambheda）」反而给了夹注。取舍标准不一致。
  - 建议：首现处补为「四梵住（brahmavihāra）」「十不净（asubha）」。

- `64-1148-27-31`｜语言表达不够流畅｜片段「只有破除（自他之间的）界限（sīmasambheda）本身才是相」
  - 问题：一个短句里连续两组括号（一组补注、一组夹注原词），视觉割裂严重。
  - 建议：拆开处理——「因为在四梵住中，相就是破除自他界限（sīmasambheda）本身」，把补注融入正文。

- `64-1151-2-7`｜复杂嵌套句理解困难｜片段「十力者所宣说的、每一种各自都能成为一种禅那之因的那些不净——」
  - 问题：两个长定语叠加在「那些不净」之前，加之 1150–1151 为跨句偈颂，中心语被推到句末，读者需回读才能接上 1150 段。
  - 建议：改为「……那些不净，是十力者所宣说的，每一种都各自能成为一种禅那之因——」，让定语后置。

- `64-1147-28-44`｜语言风格不统一｜片段「应当在它们当中随取一处」
  - 问题：「随取一处」是偏文言的紧缩说法，与同段「都能成就」「这样作意」的白话语体不匹配。
  - 建议：改为「应当在它们当中任取一处」或「随便取其中哪一处」。
