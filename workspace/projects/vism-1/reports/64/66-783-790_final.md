## 理由

**取数缺口（先行声明）**：本次评估仅拿到巴利原文与待评译文，**义注（aṭṭhakathā）与 nissaya 均未注入**。本层是复注（ṭīkā），其"释义标准"本应是它所注释的义注（《清净道论》佛随念章义注相应段），词级基准应是 nissaya。二者皆缺，因此本报告的准确性判断只能依据巴利原文词法、上下文与论藏通例，无法完成方法文档要求的"义注定释义、nissaya 定词法"逐句核对。信心指数据此压到 68——尤其是 783-784 偈颂的词源解释（rahānaṃ / araheyyato / rahābhāvā）、786 段 uddesa 与 bahuvacana 的论义，若有义注对照，判断可能变动。

**准确性（88）**：整体对复注文体的把握是到位的——"…ti X" 的释词句式统一译作"**X**，就是…"，格助词关系、被动未来分词（abhiññeyya / pariññeyya / pahātabba / sacchikātabba / bhāvetabba）的译法一致且正确。几处解经难点处理得有水准：`Ekadesassa aggahaṇato` 译"因为并没有限定只取其中一部分"补出了论证方向；`kammavacanicchāya abhāvato` 译"由于并没有要说出宾语的意欲"准确抓住了语法论的要点。扣分集中在 784 `rahābhāvā` 的"没有趣行"（与 783 的"应舍弃之物"取了不同词根，前后自相矛盾，见 🟧）、788 `mūlakāraṇabhāvenā` 一句补出主语"渴爱"缺乏本句依据（该词在被释句中尚未出现，见 🟧），以及 789 末句大幅扩写（见 🟧）。

**风格符合度（82）**：主体是现代书面汉语，禁例表中的"此中/故为/彼等/是故"等未出现，标点全角、无 ASCII 引号、无工作标记，JSON 安全无虞。但残留若干半文半白成分：`所应知`、`值得敬礼`、`诸有`、`在前分…在后分`、`往后的各处`、以及多处"就…"式短促句。其中"诸+单音节"（诸有、诸门、诸蕴、诸遍、诸禅、诸法）属论藏固定译语，不按文言扣；真正的文言虚词残留是 786 的"正因如此"与 790 的"由此就显示出"这类，程度轻，按 warning 各计一条。

## 问题清单

### 🟧 error

- `66-784-2-12`｜错译（词义）｜片段「因为在诸有之中没有趣行」
  - 问题：`rahābhāvā` 是 `raha` + `abhāva`（没有 raha），与 783 句 `rahānaṃ suppahīnattā` 的 `raha` 同一词根。783 把 `raha` 译作"应舍弃之物"，784 却译成"趣行"，同一偈颂内同一词根前后取义不一，读者无从看出这是同一词的三重释义（rahānaṃ / araheyyato / rahābhāvā 正是 arahaṃ 的三种词源解）。"趣行"一义在本句无支持。
  - 建议：与 783 统一，取"（诸有之中）没有应舍弃之物"一类译法，使三句同根呼应可见。此处建议在拿到义注后复核 `raha` 的定释再定稿。

- `66-788-27-36`｜错误多译（补出无据主语）｜片段「但渴爱是连那些原因也要以它为根本的那个原因」
  - 问题：原文 `santesupi avijjādīsu aññesu kāraṇesu tesampi mūlabhūtakāraṇabhāvena` 只是"即便有无明等其他原因存在，（它）也是连那些原因的根本原因"，句中并无 `taṇhā`。主语"渴爱"由下句 `Taṇhā hi…` 才引入。译文把它提前写进本句，等于替复注作了判断；若义注此处所指另有其物（如以 samudaya 泛称），即为指代错误。
  - 建议：保留原句的无主语结构，如"就是说：虽然另外还有无明等原因存在，但它是连那些原因也要以之为根本的那个原因"，让下句 `Taṇhā hi` 自然承接。

- `66-789-49-56`｜错误多译（扩写超出原文）｜片段「则是指：这些唯作法在哪个生命体中生起，作为那个生命体的原因的渴爱就是这里所说的先前的渴爱」
  - 问题：原文 `Kiriyadhammānaṃ pana yattha te tassa attabhāvassa kāraṇabhūtā.` 是承上省略句，只说"至于唯作法，则（先前的渴爱）是它们所在的那个自体的原因"。译文补出"在哪个生命体中生起""就是这里所说的先前的渴爱"两段原文没有的成分，把省略句展开成完整论断，超出 `knowledge/style.md`"不擅自补足省略主语（除非语义必须）"的限度。
  - 建议：压缩为贴近原文的形式，如"至于唯作法，则（先前的渴爱）是它们所在的那个自体的原因"，需要交代的省略成分放注释而非正文。

- `66-786-38-43`｜错译（修饰关系）｜片段「就是由于它们是应以上智了知的，所以他觉悟了它们」
  - 问题：`abhiññeyyabhāvato bujjhi` 的 `-to` 是从格表因由，但因由是"（诸法）具有应以上智了知的性质"，译文的"所以他觉悟了它们"把因果说反了方向——不是因为可被上智了知所以他觉，而是就其应被上智了知这一面而言他觉了。现译容易读成诸法的性质导致了佛的觉悟。
  - 建议：改为"就是就其应以上智了知这一面而觉悟"一类表述，避免读成因果链。

### 🟨 warning

  - 问题：`Tathā hi` 的对译用了四字文言连接语。
  - 建议：改为"正因为这样"或"所以下文才会说"。

- `66-790-44-53`｜文言语体｜片段「由此就显示出」
  - 问题：`Imināssa…dassito` 译作"由此就显示出"，"由此"为文言虚词式连接。
  - 建议：改为"这句话显示出"或"这样就说明了"。

- `66-783-2-6`｜文言语体｜片段「因为对智者们而言值得敬礼」
  - 问题："值得敬礼"属半文半白，且"对…而言值得…"的句式生硬。
  - 建议：改为"因为智者们应当礼敬他"。

- `66-786-44-54`｜关键词语意不明确｜片段「在前分用观慧，在证悟的刹那用道慧，在后分用一切知智等等而了知」
  - 问题："前分""后分"（pubbabhāga / aparabhāga）对一般读者不透明，本项目定位为"兼顾佛学研究者和一般读者"的混合受众；此处未夹注巴利原词也未作解释。
  - 建议：首次出现处夹注，如"在前分（pubbabhāga，即道之前的阶段）"，或改为"在证道之前""在证道之后"。

- `66-785-13-29`｜不该使用术语标记时使用了术语标记｜片段「**saṃ** 这个语词是在表明」
  - 问题：同段内 `saddo` 一词两处译法不一——此处 `saṃ-saddo` 译"这个语词"，787 段 `ca-saddo` 也译"这个语词"，一致；但本句把 `saṃ` 加粗，787 把"以及"加粗而未保留巴利 `ca`，标记体例在同一类结构上不统一。
  - 建议：统一体例——释词元语言中的语素一律保留巴利形并加粗（`saṃ`、`ca`），或一律用汉译加粗后夹注巴利原词。

- `66-786-99-105`｜整句逻辑表达不规范｜片段「而总标是针对那些意义范围还没有确定下来的法来作的」
  - 问题："来作的"与前文"是针对…"搭配松散，`karīyati` 的被动语气在汉语里落空，读起来像未完句。
  - 建议：改为"而总标，是就那些意义范围尚未确定的法而立的"。

- `66-788-2-26`｜整句逻辑表达不规范｜片段「用在诸门中生起的法（连同诸门与所缘）以及诸蕴等等，同样依谛加以分析显示出来」
  - 问题：本句嵌套三重（目的状语 + 工具状语 + 括号插入语），括号把 `dvārārammaṇehi saddhiṃ` 的修饰关系切断，读者难以判断"连同诸门与所缘"修饰的是"法"还是"分析"。
  - 建议：拆句，如"…用诸门与所缘、以及在诸门中生起的法，还有诸蕴等等，同样依谛加以分析显示出来"。

### 🟦 suggestion

- `66-785-60-69`｜复杂嵌套句理解困难｜片段「应当知道 buddha 这个词的成立是不待意义上的特别限定、只就施动者（kattu）而言的」
  - 问题：语法论句，"不待…只就…而言的"三层否定加限定，对读者不友好；`kattu` 夹注用了词干形而非译文中出现的"施动者"对应的 `kattari`，夹注体例可再斟酌。
  - 建议：拆为两句，如"应当知道：buddha 这个词并不需要意义上的特别限定，它的成立只就施动者（kattu）而言"。
