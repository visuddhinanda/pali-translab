# Review — 64:1519-1527（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌／义注 ❌
> 本批未注入 nissaya 和义注，所以这次只能对照巴利原文审，取义与词法都没有外部标准。有义注疑点的地方已标“待义注核对”。
> 本层是 mūla，没有父层。但这里的黑体词（nātisaṇikato / vikkhepapaṭibāhanato / paṇṇattisamatikkamanato / anupubbamuñcanato / appanāto / tayo ca suttantā）引自前文作意善巧的条目清单，那份清单不在本 chunk 里，所以逐字一致无法核查。**必须**在 harmonize 时和清单的译文对齐。

## 跨段一致性
- **`-to manasikātabbaṃ` 的译法不统一**：§1519 译“不太慢**地**作意”，§1520 译“防止散乱**地**作意”，§1522 译“**以**依次舍弃**的方式**来作意”。同一个从格方式句式有三种译法。“防止散乱地作意”还可能被误读成“以散乱的状态作意”。建议统一为 §1522 的格式“以……的方式作意”，至少 §1520 要改。
- **vissajjeti 的译法**：§1524、§1525-58 译“舍弃”“舍去”，§1525-2、§1525-21 译“舍去不去”。前两处是教义说明，后两处是比喻里的“跳过某户”，可以分开，但“舍去不去”本身要改（见下文）。
- **koṭṭhāsa 与 dvattiṃsākāra**：前者译“部分”（§1522、§1524），后者译“三十二种身分”（§1525）。原词不同，分开译有依据。但“身分”在现代读者眼里容易看成“身份”。建议用“三十二个身体部分”，或者沿用“三十二身分”但首次出现夹注（dvattiṃsākāra）。需要在 terms.md 定案。
- **`evaṃsampadamidaṃ daṭṭhabbaṃ`**：§1523 与 §1525-36 译法一致，但句意不清（见 §1523 条）。两处要同步修改。
- **`makuḷatālapaṇṇasūci`**：§1523 与 §1524-83 都译“棕榈嫩叶的叶尖”，两处要同步修改（见 §1523 条）。
- **`ayam(ev)ettha adhippāyo`**：§1526 的原文带 eva，§1527 不带，两处都译成“这就是这里的意思”，强调的语气没有译出来（见 §1526 条）。

## §1520 句 64-1520-43-46
- **问题**：误读风险。“应当防止散乱地作意”可以断成“防止〔散乱地作意〕”。原文 vikkhepapaṭibāhanato 是作意的方式。
- **建议**：“所以作意时应当防止散乱。”或者“所以应当以防止散乱的方式作意。”

## §1521 句 64-1521-2-16 / 64-1521-37-66 / 64-1521-67-74
- **问题**：术语，有两处。
  - paṭikkūla / paṭikkūlabhāva 在这里指所缘本身的性质，也就是“可厌”。“厌恶”偏向主体的情绪。
  - paṇṇatti 译成“名称”，传统多译“概念”或“施设”。
- **建议**：paṭikkūla 考虑改译“可厌”“可厌性”；paṇṇatti 的译法待义注核对后定案，登记进 terms.md。这两处都压低 confidence，暂不强改。

## §1523 句 64-1523-2-65
- **问题一**：漏译。`luddena tatheva kate` 的意思是猎人照样射叶、呼喊。译文作“猎人又同样呼喊”，丢了射叶。
- **建议**：改为“猎人又同样射叶呼喊”，或者“猎人又照样做了一遍”。
- **问题二**：误译存疑。`makuḷatālapaṇṇasūci` 的 sūci 指树冠中央还没展开、像针一样的嫩叶芯，不是“叶尖”。
- **建议**：改为“树中央未展开的棕榈嫩叶芯”。待义注核对。
- **问题三**：句意不清。“应当把这件事看作与此相同”里，“这件事”和“此”分别指什么，读者分不清。原文的意思是：眼前讲的修习应当按这个比喻来理解。
- **建议**：改为“修习的情形也应当这样理解”。§1525-36-38 同步修改。

## §1524 句 64-1524-23-35
- **问题**：语体生硬。“以所缘的方式往来游走”有翻译腔。
- **建议**：改为“修行者的心把三十二个部分当作所缘，在身体里往来游走”。

## §1525 句 64-1525-2-20、64-1525-21-27
- **问题**：语病。“舍去不去”重复了“去”字，读起来别扭。
- **建议**：改为“就跳过后面的一户不去”“就跳过后面的两户不去”。

## §1525 句 64-1525-28-35、64-1525-83-101
- **问题**：用词有歧义。“坐堂”在现代汉语里常指中医坐堂行医。
- **建议**：āsanasālā 改译“座堂”，或者“（寺里的）休息堂”。两处统一修改。

## §1526 句 64-1526-2-13
- **问题**：漏译语气。原文 `ayameva ettha adhippāyo` 带 eva，意思是这里的用意仅止于此，排除了别的理解。
- **建议**：改为“这里的意思只是如此”，或者“这里要说的只是这一点”。“就安止的部分而言”这一句的读法待义注核对。

## §1527 句 64-1527-2-18
- **问题**：专名处理。adhicitta、sītibhāva、bojjhaṅgakosalla 是三部经的经名（一般对应增支部《增上心经》、增支部《清凉经》、相应部觉支相应中讲觉支善巧的那一部），译文没有标成经名。“清凉性”作经名也不自然。
- **建议**：改为“《增上心经》、《清凉经》、《觉支善巧经》这三部经”，首次出现夹注巴利原名。具体对应哪部经，待义注核对。

## §1527 句 64-1527-19-20
- **问题**：无实质问题。“其中——”是引出下一段的起句，要跟下一 chunk 的开头一起看是否衔接。
- **建议**：harmonize 时连同下一段一起检查。
