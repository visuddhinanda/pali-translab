## 跨段一致性

- **vadhaka**：§571 译「杀人者」、§572 同一句内「下手的人」与「杀人者」并用、§576/§578/§580 译「下手杀的人」。父层定译为「下手杀的人」（138-1828-121-133），建议全 chunk 统一；偈颂确需紧凑时可简作「下手的人」，但不要在同一句里两种并用。
- **pāṭha / pāḷi**：§578-100-107 的 `pāṭhe` 译「文句里」，§579-64-94、§580-35-86 的 `pāḷiyaṃ` 译「圣典原文」。nissaya 两处都作 `ပါဠိတော်၌`，所指同一；建议统一为「圣典原文里」。
- **译文内的语法夹注**：§576-2-23 出现「**离开身体**（kāyato，夺格）」，全 chunk 仅此一处在正文标注语法格。`style.md` 的夹注只用于术语首次出现附巴利原词，建议删去「，夺格」，格位说明放审稿意见。

## §572 句 209-572-2-10

- **问题**：取义（nissaya 定义）— `kusalo` 译成「带着善心的」。nissaya `ကုသလော = အပြစ်မရှိသည်`（没有过失／无罪），不是「善心」。
- **建议**：改为「……都会成为无罪的杀人者」。这一句是归谬：按那种主张，连死人、睡着的人都成了无可指责的杀人者。

## §573 句 209-573-2-9

- **问题**：取义（nissaya 定义）— `bhedo` 译成「有差别」。nissaya `ကုသလတ္တိကဘေဒေါ စ = ကုသလတိက်ပျက်သည်`、`ဝေဒနာတ္တိဘေဒေါပိ = ဝေဒနာတိက် ပျက်သည်`，`ပျက်` 是「坏掉、不成立」，指三法分类被打破，而不是「两者有分别」。
- **建议**：改为「而且善三法的分类就会被破坏，受三法的分类也会被破坏」。
- **附**：nissaya 在本句句首补出 `ဧဝံ သတိ = သော်`（这样一来），译文把「这样一来」放到了 §574 句首，建议移回本句。

## §574 句 209-574-2-12

- **问题**：句法（nissaya 格与补出）— 译文「已经成立的说法也会变成那样，亲手下手时的杀害意图也会变成另一回事」没有 nissaya 依据。nissaya 的结构是两个主格各配一个谓语：`တထာဂတော`（以那样的方式得出的〔结论〕，主格）+ `သိဒ္ဓေါ = ပြီး၏`（就成立了）；`ဝဓကစေတနာ = သတ်သော စေတနာသည်`（主格）+ 补出的 `နိယာမေတိ = မှတ်၏`（才算定／才被认定）。`sahatthā` 是具格 `ဖြင့်`（以自己的手）。「变成那样／变成另一回事」是译者加的谓语。
- **建议**：按 nissaya 重译为「那么用那样的方式得出的结论就成立了：杀害的意图要以亲手下手来认定」。本句印本无动词、靠 nissaya 补出，存疑写进报告即可，不要在译文里用含糊的「变成另一回事」兜住。

## §575 句 209-575-2-26

- **问题**：数（nissaya）— `maññe` 译「我认为」，nissaya 两处都作复数 `မညန္တိ = အောက်မေ့ကုန်၏`（他们认为）。
- **建议**：倾向改为「（诸师）认为」。印本 `maññe` 也可读作第一人称插入语，两读并存；若保留「我认为」，请压低该句 confidence，分歧记在报告里。
- **问题**：格 — `aṭṭhakathāya` 译「义注引来并举出的」（作施事），nissaya `အဋ္ဌကထာယံ = ၌` 是处格。
- **建议**：改为「在义注里引来并举出的那五种定律」。

## §575 句 209-575-27-37

- **问题**：主语误定（nissaya 主格明确）— 「一切心念都……归入业定律或者心定律」。nissaya `တေ သဗ္ဗေပိ = ထို အလုံးစုံသော နိယမတို့သည်`，主格是「那一切定律」，不是「心念」。
- **问题**：格 — 「被归入哪一类，就按那一类来算」把 `yena…tena` 读成「哪一类／那一类」。nissaya 补出 `ယေန ကာရဏေန = အကြင်သို့သော အကြောင်းဖြင့်`（以某种理由，具格），`ဘဇာပိယမာနာ = သွင်းသည်ရှိသော်`（被归入时）。
- **建议**：整句改为「正因为可以这样归入，所以应当知道：那一切定律都随各自可能的情形而归入业定律或者心定律」。

## §575 句 209-575-38-68

- **问题**：原文读法分歧（必须定夺）— 印本作 `maraṇavaṇṇadassane na vibhattova`，译文据此作否定句「并没有分开说明」。nissaya 读作 `မရဏဝဏ္ဏဒဿနေန = သေခြင်း၏ ကျေးဇူးကို ပြသဖြင့်`（具格，无 `na`），`အာဒီနဝေါ = ကို`（宾格），`ဝိဘတ္တောဝ = ဝေဘန်အပ်သည်သာလျှင်တည်း`——意思正相反：「对活着的过患，正是通过显示死亡的好处而分别开来的」。两读结论相反，需定夺后再改；定稿前该句 confidence 压低。
- **问题**：句法 — 后半「才没有加以分别，或者才被当作不加分别来处理」把一个谓语拆成两说。nissaya 只有 `အဝိဘာဂါ = မဝေဖန်ခြင်းတို့ကို`（宾格）+ `ကာရိတာ = ပြုအပ်ကုန်၏` 一个谓语。
- **建议**：合并为「或者因为不明显、不显著，才作了不加分别的处理」。另 `idha` nissaya 作 `ဤ သိက္ခာပုဒ်၌`，可明确为「而在这条学处里」。

## §576 句 209-576-33-89

- **问题**：句法（nissaya 主格与谓语归属）— 译文「所谓意图是残暴的，指的是针对重大对象而生起的前分意图；本性平常的杀害意图，并不残暴」把两个成分读成对立两项。nissaya 只有一个主格 `ပဝတ္တပုဗ္ဗဘာဂစေတနာ = ရှေ့အဘို့၌ ဖြစ်သော စေတနာသည်`，`ပကတိသဘာဝဝဓကစေတနာ = …ဝဓကစေတနာဖြစ်၍` 是用 `ဖြစ်၍` 连接的谓语补足，`ဒါရုဏ … နော ဟောတိ` 的主语就是前分意图。按 nissaya，先师的意思是「前分意图不残暴」，与紧接的另一说「唯有杀害的意图才是残暴的」方向一致；现译则让两说互相矛盾。
- **建议**：改为「所谓‘意图是残暴的’：针对重大对象而生起的前分意图，只是本性平常的杀害意图，并不残暴」。印本此处标点可两解，分歧写进报告。

## §576 句 209-576-103-113

- **问题**：补出成分 — `ubho` 译「两个人」。nissaya 指明是 `အဖ, သားရဲ`（父亲与那名战士），即父层 138-1811-22-49 的情形。
- **建议**：可明确为「箭把那个战士和父亲两个人都射穿了」，省去读者回溯。

## §577 句 209-577-33-39

- **问题**：补出成分（具格）— nissaya `ဧတံ ဂါမေ ဌိတန္တိ ဝစနေန = ဖြင့်`，是「以这句话来限定」。
- **建议**：改为「是用‘那个在村里的人’这句话限定的，而且限定的只是人本身」。

## §578 句 209-578-8-21

- **问题**：格 — `ārocane, paṭiggaṇhane` 译「在转告的时候以及在接受的时候」，nissaya 作 `အာရောစနေ = ကြားခြင်းကြောင့်`、`ပဋိဂ္ဂဏှနေ = ဝန်ခံခြင်းကြောင့်`，是因，不是时点。
- **建议**：改为「……各随其情形，因转告、因接受而犯的突吉罗」。

## §578 句 209-578-22-30

- **问题**：句法（条件句被读成判断句）— 译文「接受这件事的人并不限于下手杀的人——谁接受了，谁就犯突吉罗」。nissaya 作条件句：`ဝဓကော = သည်` + `န ပဋိဂ္ဂဏှတိ = အံ့`（若下手的人不接受），`တဿ = အား`（与格）`ဒုက္ကဋံ = ၏`，`သိဒ္ဓံ ဟောတိ`。所以是「若下手杀的人不接受，他就只犯突吉罗——这一点是确定的」。下文「只是因为没有说到的机会，才没有提」「指使者所应犯的罪……所以才说他犯偷兰遮」「如果下手杀的人接受了，那位老师还要再犯偷兰遮」整段都在讲**指使者**的罪，现译把主题换成「谁接受谁犯」，与上下文脱节（「谁接受谁犯」是父层 138-1829 另一段的论点）。
- **建议**：改为「如果下手杀的人没有接受，那么指使者就只犯突吉罗——这一点是确定的」。

## §578 句 209-578-37-49

- **问题**：指代 — `tassa` 译「它（罪）的场合」，nissaya `တဿ = ထိုစေတတ်သောရဟန်း၏`，指的是那位指使的比丘。
- **建议**：改为「因为指使者所应犯的罪，就他而言场合并没有被划定，所以才在那个地方说他犯偷兰遮」。

## §578 句 209-578-70-79 / 209-578-87-89

- **问题**：无据补出 — 「因为**在前一种情形里**，并没有那种能成就事情的意图」。`Kasmā?` 紧接在「如果他转达出去了，就直接犯波罗夷」之后，nissaya 只给 `အတ္ထသာဓကစေတနာယ = ၏`、`အဘာဝါ = မရှိသောကြောင့်တည်`，没有补出任何「前一种情形」的限定。
- **建议**：删去「在前一种情形里」，照原样译「因为没有那种能成就事情的意图」；归属不清的疑点写进报告，不要在译文里替读者判定。

## §579 句 209-579-2-18

- **问题**：句法（让步被读成原因）— 译文「只是因为想说，才在这里费力解说，其实没有什么用处，所以世尊没有说」，既把让步读成原因，又让「解说」成了既成事实。nissaya `ဝတ္တုကာလတာယ စ = ဆိုလိုသောအဖြစ်ရှိသော်လည်း`（虽然有想说的意思），`ကိစ္ဆေန = ငြိုငြင်သဖြင့်`（具格：费力地），`ဧတ္ထ ဝတွာ … ပယောဇနံ … နတ္ထိ`（在这里说了也没有利益）。
- **建议**：改为「虽然有想说的意思，但在这里费力说出来也没有什么用处，所以世尊没有说」。

## §579 句 209-579-61-63

- **问题**：指代不明 — 「因为他是由那能成就事情的意图而犯的」紧接「不是佛护犯的——为什么呢？」，「他」容易误读为佛护。nissaya 无主语。
- **建议**：明确为「因为那位老师是由那能成就事情的意图而犯的」。

## §579 句 209-579-64-94

- **问题**：格（具格关系颠倒）— 译文「由于说到它的场合并不限定在‘指使者不犯’这句话上」。nissaya `“မူလဋ္ဌဿ အနာပတ္တီ”တိ ဣမိနာ = ဤပါဌ်ဖြင့်`（具格：以这句话），`အပရိစ္ဆိန္နောကာသတ္တာ = မပိုင်းခြားအပ်သော အရာရှိသည်၏ အဖြစ်ကြောင့်`（因为其场合未经划定）。
- **建议**：改为「至于指使者所应犯的突吉罗，由于‘指使者不犯’这句话并没有把它的场合划定出来，所以这里就没有提」。

## §580 句 209-580-35-86

- **问题**：时态 — `āpajjissatī` nissaya 作 `ရောက်လတ္တံ့`（将然），译文「而犯罪的」丢掉了将然义。
- **建议**：改为「……然后自己动手夺去对方的性命，才会犯罪」。

## §580 句 209-580-214-248

- **问题**：并列结构（nissaya 两处处格）— 译文「而在这里，在使者层层转达的情形中」把两处合成一处。nissaya 明确并列两段：`ဣဓ ပန = ဤ ဝိသက္ကိယဒူတပဒနိဒ္ဒေသ၌လည်းကောင်း`（这里，即“错传的使者”一段）、`ဒူတပရမ္မရာယ စ = ဒူတပရမ္ပနိဒ္ဒေသ၌လည်းကောင်း`（以及“使者层层转达”一段）。
- **建议**：改为「而在这里（“错传的使者”一段）和在“使者层层转达”那一段里，由于‘你去告诉某某，让某某去告诉某某’这句话说得并没有加以分别……」。
