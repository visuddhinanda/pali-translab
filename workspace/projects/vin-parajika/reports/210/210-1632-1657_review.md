# Review — 210:1632-1657（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层核对

本 chunk 注的是众学法（Sekhiya 第 4–7 品）与灭诤法；所给父层段落（138:2828–2946）是钵学处、不满五处修补、药、雨浴衣、可疑住处诸学处。本 chunk 的黑体被解释词（sapadānaṃ / viññattiyaṃ / aññassatthāya / kukkuṭaṇḍaṃ atikhuddakaṃ / sabbaṃ hatthaṃ / sītīkato / silakabuddho / eseva nayo / tasmā / vilīvacchattaṃ / maṇḍalabaddhāni / tatthajātakadaṇḍakena kataṃ / chattapādukāya / cāpo / kodaṇḍo / rukkhato patito / pāḷiyā / dhīratthu / vinipātanahetunā / tvaṃ / asmā / na kathetabbaṃ / kheḷena cettha…）在父层文本中无一处出现，逐字比对无可比对项。可对齐的只有两层共用的非黑体术语，列入下节。

## 跨段一致性

- `pañcasahadhammika`：本 chunk §1635 译「五众同法者」，父层定稿（138-2836）译「五种同法者（sahadhammika）」 → 建议统一为「五种同法者」。
- `aññātaka-appavārita-ṭṭhāna`：本 chunk §1635 译「在非亲属、又没有邀请过的地方」，父层定稿（138-2895 / 2900）译「从非亲属、又没有邀请过的人那里」。nissaya 作 `အဆွေမတော်ရာ, မဖိတ်သောအရပ်၌`（处格·处所），两种处理都讲得通 → 建议从父层，译「向非亲属、又没有邀请过的人索求」。
- `nillehati`：§1644-26-38 一律译「舔」（舔钵／舔嘴唇），但 nissaya 对钵用 `ခြစ်`（刮、抹），对嘴唇用 `လျက်`（舔），两处词义不同 → 见下逐句意见。
- `evamaññesupi …`：§1636-33-36 译「其他地方」，§1639-20-22 也译「其他类似的地方」，而 nissaya 两处都补出 `သိက္ခာပုဒ်တို့၌`（学处中），§1636 还限定为 `သေခိယပုဒ်`（众学法条） → 两处同改，译法保持一致。
- 释「伞」的体例不一：§1645-2-9 收尾作「……做成的伞」（nissaya 补 `ထီး`），§1645-35-42 同样有 `ပြုသောထီးတည်း` 却只译到「……做成的」 → 补齐。
- 「石」：§1643 `silaka` 译「石头」，§1649-44-47 `asmā` 译「磐石」，nissaya 两处分别作 `ကျောက်` / `ပါသာဏော`，均无「磐」的分量 → 建议都作「石头」。
- 「pāḷi」的称法：§1634「圣典本文」、§1643「圣典里的」、§1649「圣典本文的」 → 建议统一作「圣典本文」。
- 语体：全 chunk 为现代书面汉语，未见文言句式或单音节文言词，译文内也没有工作标记。此项无问题。

## §1633 句 210-1633-2-25

- **问题**：补出成分 — nissaya 在 `saha apadānena sapadānaṃ` 处明确标注补入 `ပဝတ္တံ=ဖြစ်သည်တည်း (ထည့်)`，即「与无中断俱而**进行**者」；译文「带着‘无中断’就是 sapadāna」把这个补出的谓语丢了，读者看不出这是指行食／取食的「进行」。
- **建议**：「与‘无中断’相俱而进行的，就是 sapadāna」。另 `anupaṭipāṭiyā` nissaya 作 `အစဉ်အတိုင်းအားဖြင့်`（具格·按次序），「依着次序」偏文，建议「按着次序」。

## §1634 句 210-1634-24-49

- **问题**：补出成分 — nissaya 为 `yaṃ … paviṭṭhaṃ` 补出主语 `သိတ္တံ`（饭粒／饭团，主格：`ယံ သိတ္တံ=အကြင်ဆွမ်းလုံးသည်`、`တံ=ထိုဆွမ်းလုံးသည်`）；译文作「有一部分……还是进去了」，指称含糊，失掉了 nissaya 指明的主语。
- **建议**：「可是有饭粒在他不愿意的情况下还是进去了，这就叫做非故意进入」。

## §1634 句 210-1634-50-64

- **问题**：格误读（必改） — `tadeva` nissaya 作 `ထိုဆွမ်းကိုသာလျှင်`（宾格，`ကို`），是 `bhuñjane` 的受事：**又吃了那同一份（索求来的）食物**；译文译成「同样的情形」，把宾语当成了泛指状语，句子的事实指向变了。
- **建议**：「如果又吃了那同一份食物，而当时是因为心在别的事上，或者以为‘这不是索求来的’，就叫做**“由于失念”**」。

## §1635 句 210-1635-26-37

- **问题**：无依据的释义 — `akataviññatti`，nissaya 整处只作音转 `အကတဝိညတ္တိဒုက္ကဋ်`，不给释义；译文自行解作「因‘不该作的索求’而得的突吉罗」，词法上 `akata` 修饰的对象在 nissaya 里没有交代。
- **建议**：改为中性处理，如「各部义注依顺经义所说的 akataviññatti 突吉罗」，把这条释义分歧写在报告里即可，不要在译文中落定。

## §1635 句 210-1635-38-47

- **问题**：补出成分 — `aññe ca` nissaya 作 `တပါးသော ရဟန်းတို့သည်`（主格复数，明指**其他比丘**）；译文「他自己和别人」把 nissaya 限定的身份放宽了。
- **建议**：「他自己和其他比丘都免不了邪命」。

## §1636 句 210-1636-2-20

- **问题**：引文形式 — 被解释词译作「**“鸡蛋（大小）……太小”**」，原文 `kukkuṭaṇḍaṃ atikhuddakaṃ` 是连续一句，省略号是译者加的，读者会以为引文有删节。
- **建议**：「**“（饭团小到）像鸡蛋那样就太小”**」或「**“鸡蛋（那么大的饭团）太小”**」，不用省略号。

## §1636 句 210-1636-33-36（§1639 句 210-1639-20-22 同）

- **问题**：补出成分 — `aññesupi` nissaya 补出所指：`တပါးသော သေခိယပုဒ်တို့၌လည်း`（其他众学法条中）、`ဤသို့သဘောရှိသော သိက္ခာပုဒ်တို့၌`（这类学处中）；译文两处都作「其他（类似的）地方」，丢掉了 nissaya 指明的所指范围。
- **建议**：分别作「其他的众学法学处中也应当按各自的情形这样理解」「其他这类学处中也是这样」。

## §1639 句 210-1639-2-19

- **问题**：取义误读（必改） — `anāhaṭe kabaḷe` nissaya 作 `ကဗဠေ=ဆွမ်းလုတ်ကို`（宾格）＋`အနာဟဋေ=မဆောင်မီ`，是「**还没有把饭团送（到口边）之前**」；译文「饭团还没有拿到」读成了「尚未得到饭团」，与 nissaya 的 `ဆောင်`（送、运）不符。
- **建议**：「至于饭团还没有送到嘴边就张开嘴」。

## §1643 句 210-1643-10-13

- **问题**：词义偏轻 — `parihāsavacana` nissaya 作 `ပြက်ရယ်ပြုသော စကား`（讥笑、戏谑之语），带嘲弄义；「开玩笑的话」偏中性。
- **建议**：「这是一句讥笑戏谑的话」。

## §1644 句 210-1644-26-38

- **问题**：词义区分丢失 — nissaya 对两处用了不同的词：`ပတ္တံ … ဟတ္ထေန … နိလ္လေဟိတုံ=ခြစ်ခြင်းငှာ`（用手**刮、抹**钵），`ဩဋ္ဌံ … ဇိဝှါယ … နိလ္လေဟိတုံ=လျက်ခြင်းငှာ`（用舌**舔**嘴唇）；译文两处都作「舔」。
- **建议**：「用手把钵刮净、用舌头舔嘴唇，都是可以的」。

## §1644 句 210-1644-39-46

- **问题**：补出成分错（必改） — `ghanayāguādivirahitaṃ` nissaya 补出的中心词是 `ဘောဇဉ်`（食物）：`တခဲနက်သော ယာဂုအစရှိသည်မှ ကင်းသော ဘောဇဉ်ကို`（宾格），指**不属于稠粥之类的食物**；译文补成「（手或钵）」，补错了对象，整句的允许／禁止范围被改写。
- **建议**：「因为对不是稠粥之类的食物，去舔、去刮是不可以的」。

## §1645 句 210-1645-10-34

- **问题**：结构误读（必改） — nissaya 在 `suttehi baddhāni` 之后另立一个被解释词 `သလာကဗန္ဓနာနီတိ`，并注明「ဤသံဝဏ္ဏေတဗ္ဗပုဒ် ဆဋ္ဌ၌မပါ」（此被解释词第六结集版无）；也就是说第二、第三种说明属于 `salākabandhanāni` 这一条，不属于 `maṇḍalabaddhāni`。译文「**“编成圆圈绑住的”**，有三种：……」把三段释文全归到一个词下，词与释的对应断了。
- **建议**：`maṇḻalabaddhāni` 只保留第一种（在纵向伞骨上横着按环形放伞骨、用线绑住）；第二、三种另起，作 `salākabandhanāni`（用伞骨绑成的）的释文，并在报告里记明该被解释词在第六结集版缺失。另 `dīghadaṇḍakeheva` nissaya 只作 `ရှည်သော တုတ်တံတို့ဖြင့်သာလျှင်`（复数具格，长杆），没有「纵向」的依据 → 改「只靠长杆做成可以收拢的样子」。

## §1645 句 210-1645-35-42

- **问题**：补出成分 — `kataṃ` nissaya 作 `ပြုသော ထီးတည်း`（做成的**伞**）；译文收尾只到「……做成的」，与同段 §1645-2-9 的体例不一致。
- **建议**：「就是连着柄一起割下来的棕榈叶之类做成的伞」。

## §1646 句 210-1646-2-11

- **问题**：修饰语挂错＋对应无据 — nissaya 把两个修饰语平列挂在 `dhanuvikati` 上：`မဇ္ဈေဝင်္ကာ=အလယ်၌ ကောက်သော`（中间弯曲的）、`ကာဇဒဏ္ဍသဒိသာ=ထမ်းပိုးကောက်နှင့် တူသော`（像担杖那样的）；译文「中间像弯曲的担杖那样的一种弓」把「弯曲」挂到了担杖上。另 nissaya 用两个不同的缅文词区分 `cāpa`（`လင်းလေး`）与 `kodaṇḍa`（`ဒူးလေး`），译文「弯弓／弩弓」这组对应在 nissaya 里找不到依据；`kodaṇḍa` 的释文只说 `ဝိဒ္ဓဒဏ္ဍာ`（杆上穿孔），并不含「弩」义。
- **建议**：「**“cāpa”**，是中间弯曲、形状像担杖的一种弓」；`kodaṇḍo` 作「是杆上穿有孔的一种弓」，两处都不引入「弩」，名目分歧写进报告。

## §1649 句 210-1649-34-43

- **问题**：语法术语错（必改） — `upayogatthe` nissaya 作 `ဒုတိယာအနက်၌`（第二格＝业格／宾格之义）；译文作「对格」，汉语语法术语里没有这个格，读者会误解。
- **建议**：「这是用主格（第一格）的形式来表达宾格（第二格）的意思」。

## §1649 句 210-1649-44-47

- **问题**：词义加重 — `asmā` nissaya 仅作 `ပါသာဏော=ကျောက်တည်း`（石）；被解释词译作「磐石」，比 nissaya 多出了「大、厚重」的含义，与同一 chunk §1643 的「石头」也不统一。
- **建议**：被解释词作「**“石”**」，释文「就是石头」。

## §1651 句 210-1651-2-20

- **问题**：读法与并列结构（必改） — nissaya 主读为 `ဟရိတုဒကေသု=မြက်စမ်းရှိရာ, ရေရှိရာတို့၌`（`haritudakesu`：有青草的地方、有水的地方），并另注异读「ဟရိတုံ ဥဒကေသု ဆဍ္ဍေတုံ-（ဆဋ္ဌ）」；而且 nissaya 给的是**两项并列**的允许：① `ဥဒကဂဏ္ဍုသကံ ကတွာ`＋`ဟရိတုဒကေသု ဆဍ္ဍေတုံ`（含一口水后吐在青草处或水处）；② `ဥစ္ဆုကစဝရာဒိံ မုခေနေဝ`＋`ဟရိတုဒကေသု ဆဍ္ဍေတုံ`（甘蔗渣之类只用口吐在青草处或水处）。译文串成一条「含上一口水，用嘴把甘蔗渣之类带出去，吐到水里」，既把两项并成一项，又丢了「青草处」，还把 `harituṃ` 当成了「带出去」。
- **建议**：「应当知道：含上一口水吐在有青草的地方或者有水的地方，以及把甘蔗渣之类只用嘴吐在有青草的地方或者有水的地方，都是可以的」；第六结集版的异读写进报告。

## §1654 句 210-1654-2-10

- **问题**：无依据的增补 — nissaya 只作 `အဓိကရဏသမထ တို့၌`，没有数目；译文「七灭诤法」补了「七」。
- **建议**：「关于灭诤法，这里也没有什么要说的」。

## §1655 句 210-1655-2-5

- **问题**：补出成分 — nissaya 为处格补出中心词 `ဋိကာယံ`（`vimativinodaniyaṃ ṭīkāyaṃ`：在名为《疑惑度脱》的**复注**中）；译文「在《普端严》律藏义注的《疑惑度脱》中」没有点出层次，读起来像是义注的一部分。
- **建议**：「以上，在《普端严》律藏义注的复注《疑惑度脱》中——」。
