## 被解释词与父层对照

注入的父层对照（book=138，§354/382/387/395/400/406 等，内容是僧残篇的陀婆长老分房、无根诽谤、借口诸条）**与本 chunk 不是同一组学处**——本 chunk 是波逸提饮酒品 6–10、有虫品 1–5。两边的章节号（354、382、387、395、400、406）相同只是两书编号撞车。逐一比对本层黑体被解释词（alātaṃ patitaṃ / vijjhātaṃ / nagare thakite / asambhinnena / paṭiladdhanavacīvarena / cammakāranīlaṃ / yena / antamaso hasāpekkhopi / tivedanaṃ / issāso / pāṇe / appamattena vattaṃ kātabbaṃ / udakasaṇṭhānakappadese / tattha / tassa bhikkhuno santikaṃ gantvā / āpattiṃ āpajjatiyeva / vatthupuggalo / koṭi chinnā hoti / dukkhavedanaṃ / rūpasippaṃ / gabbhavīso / nikkhamanīyapuṇṇamāsī / pāṭipadadivase / cattāro māsā parihāyanti / vassaṃ ukkaḍḍhanti / te dve māse gahetvā / nikkaṅkhā hutvā / pavāretvā vīsativasso bhavissati / tasmā / ekavīsativasso / aññaṃ upasampādeti / sopi）与父层诸段，**无一处重合**，因此本次无法做逐字同译核查。对应段的父层译文需另行取回。

顺带可核对的是，与父层定稿用词没有冲突：pācittiya=波逸提、dukkaṭa=突吉罗、pavāraṇā=自恣一致；但 adhikaraṇa 父层定稿作「事件」，本层出现了两种译法（见下）。

## §1475 句 210-1475-2-13

- **问题**：词级依据分歧 — nissaya 把 `aggikapālato` 释为 `အဂ္ဂိကလာပ-တော= မီးအပေါင်းမှ`（从火堆、柴火堆），即读作 aggikalāpato，不是「火盆」；并自注「ထည့်ပါဌ်ဖွင့်ပါဌ်တို့၌ ပတိတ-ဟုရှိကြ၏။ အဋ္ဌကထာနှင့်မညီ」（有些版本作 patita，与义注不合）。译文「火盆」取的是印本 kapāla 读法。
- **建议**：依 nissaya 作「从火堆里掉到外面的燃木」；若保留「火盆」，异读记进报告，不要在译文里兼容两读。注意与下一句 kapālaggi（nissaya 确作 `မီးအိုးကင်း`＝火盆）区分开。

## §1475 句 210-1475-14-31

- **问题 1（必改，格读漏）**：nissaya 作 `ဝိဇ္ဈာတေ= မီးလျှံငြိမ်းပြီးသော။ ကပါလဂ္ဂိမှိ= မီးအိုးကင်း၌`——vijjhāta 是修饰处格 kapālaggi 的，整体＝「在火焰已经熄灭的火盆里」。译文「放进火盆的火里点燃」把火盆当成有火的，丢了 vijjhāte。
- **建议**：「把熄灭的燃木放进火焰已熄的火盆里点燃」。
- **问题 2（必改，无据增补）**：`ဣန္ဓနံ= အလျှံအတောက်မရှိသော မီးစကို`——indhana 是「没有火焰的柴木」（宾格），`ပါတေန္တဿာပိ= ချသောရဟန်းအား`。译文作「投入燃料」，并括注「（而没有放进燃木）」，nissaya 无此依据，且正好反了。
- **建议**：「同样，只是把没有火焰的柴木投进去的人，也犯波逸提」。
- **问题 3（必改，宾格误作定语）**：`ဝိဇ္ဈာတံ= ငြိမ်းပြီးသောမီးစကို`（宾格＝熄了的燃木）＋`ကပါလဂ္ဂိမှိ= မီးအိုးကင်း၌`（处格，nissaya 另注 6th ed. 作 kapālaggiṃ）＋`မုခဝါတာဒိနာ`（具格）。译文「把火盆里熄灭的火重新点燃」把 vijjhātaṃ 当作 kapālaggi 的定语，宾语丢了。
- **建议**：「用嘴吹气等等办法，把火盆里已经熄灭的燃木重新点燃的人」。

## §1475 句 210-1475-32-39

- **问题**：`သမာဒဟနံ= မီးထည့်ခြင်း`＝把火放进去／添火，是动作本身；译文「使火燃起」说成了结果。
- **建议**：「添火」。

## §1478 句 210-1478-35-45

- **问题（必改，隐含成分补错）**：nissaya 为 anaṭṭhena 补出被省略的中心词：`အနဋ္ဌေန= မပျက်သော နံ့သာပျောင်းဖြင့်`＝「以没有损坏的**涂香（香膏）**」；另一具格 `အဂ္ဂဟိတာလင်္ကာရေန= ယူအပ်သည်မဟုတ်သောတန်ဆာဆင်ခြင်းဖြင့်` 才是「没有重新佩戴的装饰」，`ပဗုဒ္ဓမတ္တေန= နိုးကာမျှဖြင့်`＝刚睡醒。译文把两个具格合并成「依旧没有散开的装饰」，把 asambhinna / anaṭṭha 的所指从涂香换成了装饰。
- **建议**：「**没有坏掉的**，是指（涂香）没有损坏；意思是那一天刚睡醒、还没有重新佩戴装饰，涂香仍然完好。」

## §1478 句 210-1478-46-53

- **问题**：`သမယာဒီနံ= အခါအစရှိသည်တို့၏။ အဘာဝေါ= မရှိခြင်း`——nissaya 只说「时节等等的不具备」。译文「不具备**热时**等等的**开缘**时节」两处都是译者的增补。
- **建议**：「不具备（听许的）时节等等」。

## §1482 句 210-1482-2-37

- **问题（读法分歧）**：nissaya 本文读 `အပရိဘုတ္တံ … = မသုံးဆောင်သေးသော`（aparibhuttaṃ＝**还没有**穿用过），并自注 6th ed. 作 paribhuttaṃ；`စီဝရံ= သင်္ကန်းသည်` 为主格。译文「点了净点以后**穿用过**的衣」取的是 6th ed. 读法，与本次的词级基准相反。
- **建议**：依 nissaya 作「别的比丘点了净点、还没有穿用过的衣」；若决定保留现译，异读须记在报告里，不得在译文里含糊处理。

## §1485 句 210-1485-2-15

- **问题**：nissaya 两处都补出省略的中心词：`ယေန= အကြင်ရဟန်းနှင့်`、`ယဿ= အကြင်ရဟန်း၏`——所指是「比丘」，且是关系代词。
- **建议**：「意思是和哪位比丘一起，也就是在那位比丘面前」。

## §1485 句 210-1485-16-26

- **问题**：`ဝိကပ္ပနုပဂစီဝရတာ= ဝိကပ္ပနာလောက်သော သင်္ကန်း၏အဖြစ်`——`လောက်`＝「够得上、达到（说净所需的量）」，是条件判断；译文「属于**应当**说净的衣」换成了义务判断。
- **建议**：「属于够得上要说净的衣」。

## §1503 句 210-1503-34-45

- **问题**：`အာပတ္တိကောဋိ= အာပတ်၏အစွန်းသည်`——koṭi 是「（罪的）那一端」；译文（含黑体被解释词）作「链条」，是意译换喻。
- **建议**：被解释词作「**那一端已经断了**」，正文用「沿着一个个人辗转传下去的罪，就在这里断了端」。

## §1504 句 210-1504-36-54

- **问题（对齐）**：`ဝိရုဇ္ဈတိ= ဆန့်ကျင်၏`（相违）落在本句，译文却把「有矛盾」前置到上一句 210-1504-2-35，本句只剩「这一点应当好好考察一下」，本句的 virujjhati 没有落字。按句对齐，判断语应在本句内。
- **建议**：本句补成「……才叫做他的违犯”（《波逸提义注》82）——这与上面那句话相违，应当好好考察一下」；上一句收回「有矛盾」的判断语，只作引出。

## §1504 句 210-1504-79-86

- **问题**：nissaya 本文读 `ဒုဋ္ဌုလ္လာပတ္တိဆာဒနံ`（…chādanaṃ＝覆藏），自注 6th ed. 作 jānanaṃ，并把 duṭṭhullāpatti 明确释为 `သံဃာဒိသိသ်အာပတ်ကို`＝僧残罪。译文取 jānanaṃ（与第二支「因想覆藏而放下担子」不重复，语义上更顺），但「僧残」这一层限定没有体现。
- **建议**：保留 jānanaṃ 读法，补出 nissaya 的限定：「知道已受具足戒者犯了粗罪（僧残）」；nissaya 的 chādanaṃ 异读记入报告。

## §1507 句 210-1507-2-9

- **问题**：`ဟေရညိကသိပ္ပံ= ငွေမှုတ်အတတ်`＝验银（吹炼银）的技艺。译文把释义提前塞进了被解释词（黑体作「鉴别钱币的技艺」），rūpasippa 本身只是「（辨）形色的技艺」。
- **建议**：被解释词与释义分开：「**辨形色的技艺**，指的是验银人（heraññika）的技艺」。

## §1507 句 210-1507-10-17

- **问题**：nissaya 补出所指与主语：`အဿ= ထိုသာမဏေအား`、`သော သာမဏေရော`，并补出系动词 `အတ္ထိ`——说的是「那位沙弥」。
- **建议**：「……他的第二十年已经满了，所以那位沙弥就叫做**从入胎算起满二十岁的人**（gabbhavīsa）」。

## §1508 句 210-1508-67-85

- **问题**：`ဧကမာသံ= ဝါဆိုတလကို`——nissaya 把 ekamāsaṃ 具体化为（第二个）阿沙荼月，不是泛指「有一个月」。
- **建议**：「就说‘阿沙荼这一个月是闰月’，把它去掉以后再进入雨安居」。

## §1508 句 210-1508-128-151

- **问题（必改，指代错＋数目丢失）**：nissaya 作 `အဓိကမာသေ= လွန်သောခြောက်လတို့ကို`（十八年里共**六个**闰月，宾格）、`တတော= ထိုခြောက်လအနက်မှ`（从**那六个月**里）、`စာတုဒ္ဒသီနံ= စာတုဒ္ဒသီနေ့ တရာ့နှစ်ဆယ်တို့၏`（**一百二十个**十四日）。译文「把十八年当中的闰月算进去，再**从二十年里**……减去四个月」把 tato 的指代错按到「二十年」，并丢掉了六个月与一百二十个十四日这两个关键数目，整条算法读不通。
- **建议**：「……是就下面这种算法说的：把十八年当中（三年一闰、共）六个闰月算进来，再从那六个月里，为了二十年中一百二十个十四日（布萨）减去四个月，这样无论怎样算都是满满的二十岁。」

## §1508 句 210-1508-164-172

- **问题**：`ဂဗ္ဘမာသာပိ= ပဋိသန္ဓေနေသော လတို့သည်လည်း`＝在母胎里住的那些月份（主格）。译文「入胎以后的月份」范围偏大。
- **建议**：「在母胎里住的那些月份也计算在内」。

## §1508 句 210-1508-173-179

- **问题**：`ဝီသတိ ဝဿံ= နှစ် နှစ်ဆယ်ရှိသော သူကို`——sandhāya 的宾语是「满二十岁的**人**」（宾格，nissaya 补出「人」），不是「这一点」。
- **建议**：「是就从出生算起满二十岁的人说的」。

## §1509 句 210-1509-2-14

- **问题**：`အာစရိယော ဝါ= ကမ္မဝါစာဆရာသည်`——nissaya 把 ācariya 限定为念羯磨文的羯磨师，不是泛称阿阇梨。
- **建议**：「是指自己作亲教师（upajjhāya）或者羯磨师（kammavācācariya）给人授具足戒」。
