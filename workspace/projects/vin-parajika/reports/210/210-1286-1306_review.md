# Review — 210:1286-1306（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（210-1295-19-22 一句无 nissaya，已略过）

## 父层被解释词核对

注入的父层对照是 **138:1546 / 1563 / 1566**（随口说话 niruttipatha、野兽吃剩的肉 vighāsa、凳子 pīṭha，属盗戒事例），而本 chunk 的黑体被解释词是 `koṭṭhakāni` / `alajjiṃ nikkaḍḍhati` / `Yassa` / `Sā aparipūrūpacārāpi hoti` / `ālokasandhi` / `Adhiṭṭhātabbaṃ` / `Ujukameva chādanaṃ` / `Tatiyāya maggaṃ` / `Tiṇapaṇṇehi labbhati` / `Tiṇṇaṃ maggānaṃ` / `Tiṇṇaṃ pariyāyānaṃ` / `mātikāyaṃ` / `sakaṭabhāramattañcepi` / `Idaṃ` / `Vuttaṃ`——**没有一个出现在所给父层三段里**。父层段号与本层内容不对应，逐字同译核对本次无法进行，不是译文的问题。请检查配对（本 chunk 对应的父层应是 Samantapāsādikā 中 nikkaḍḍhana / vehāsakuṭi / mahallakavihāra / sappāṇaka 四条学处的注释段）。

下面仅出 nissaya 词法复核意见。

## 跨段一致性

- **pariyāya**：§1296 句 39-71、§1297 句 2-19、§1297 句 48-61 译「间隔覆盖」，§1298 句 44-50 译「三遍间隔覆盖」。nissaya 一律把 `magga` 与 `pariyāya` 都释作 **အစဉ်（次序、一轮）**，只在材料上分工——`ဣဋ္ဌကာဒီဟိ`（砖瓦）走 magga，`မြက်,သက်ကယ်အစဉ်အားဖြင့်`（草、茅的次序）走 pariyāya。「间隔」是无据的引申，读者会误解为「隔开着盖」。建议统一为「（草叶的）一遍」：magga = 一道、pariyāya = 一遍，两系各自到底。
- **koṭṭhaka**：§1287 一句之内先译「门屋」后译「门楼」（`koṭṭhaka` / `dvārakoṭṭhaka` 同词根）。建议统一用「门楼」。
- **属格被解释词的处理不一致**：§1294 句 22-25 把 `vihārassa`（nissaya `ကျောင်း၏`）直译成以「的」收尾的残句「是指住处（vihāra）的」；§1298 句 36-43 同为属格 `tiṇṇaṃ chadanānaṃ`（nissaya `၏`）却译成「是指……三层覆盖」不带属格。建议统一：不硬译属格，用引号圈出被释短语。
- **`vutta` 的说者**：§1288 句 40-57、§1295 句 2-14、§1301 句 48-66 都作「本文里说」，§1298 句 29-35 却作「律中说」。nissaya 在 §1298 只给 `ဝုတ္တာ= ၏`，未指说者；建议统一作「本文说」或不指明。
- **`uttāna`（跨层）**：本层 §1291 句 2-8 译「意思很明白」；父层 138:1546 句 108-114 的 `uttānattha` 译「很明显」，而「明白」在父层用于 `pākaṭa`（138:1566 句 55-59）。建议本层改「意思很明显」，保持 uttāna=明显 / pākaṭa=明白的分工。
- **品末格式**：§1289 / §1292 / §1299 / §1303 均作「……学处的注释结束」，§1304 却作「第二品——卧坐具品结束」。建议作「卧坐具品第二结束」，与全层收尾句式一致。

## §1288 句 210-1288-2-17

- **问题**：格/句法（必改）— `ananurūpato` 是夺格因由，nissaya 作 `အနနုရူပတော= မလျော်ခြင်းကြောင့်`（**ကြောင့်**＝因为）。译文「是就不合适、不应当这样做而说的」把因由读成了对象（相当于 sandhāya），并多出「不应当这样做」这层无据的补充。
- **建议**：「……这句话是因为（那样做）不合适才说的。」

## §1288 句 210-1288-18-34

- **问题**：词义 — `pāpagarahitāya`，nissaya 作 `မကောင်းမှုကို ကဲ့ရဲ့လေ့ရှိသဖြင့်`：`ကဲ့ရဲ့` 是**责备、呵责**，不是「厌恶」；且 `မကောင်းမှု` 无领属，译文「他的恶行」多补了领有者。
- **建议**：「因为出于责备恶行（的本意），用不带怒意的心……」
- **问题**（记录，不必改译）— nissaya 正读作 `နိက္ကဍ္ဎန္တဿ`（亲自驱逐），`နိက္ကဍ္ဎာပေန္တဿ`（使人驱逐）标为第六版异读；注入的 pali 取的是异读 `nikkaḍḍhāpentassa`，译文「让人把他驱逐出去」与所取底本一致，可保留。

## §1288 句 210-1288-35-39

- **问题**：词义（必改）— `aññāpekkhā`，nissaya 作 `အကြောင်းတပါးကို ငဲ့သော`＝「顾及**别的原因**的」。译文「依别的学处而成立的罪」把 `aññā` 定作「学处」，nissaya 无此依据。
- **建议**：「也看不出有顾及别的缘由而成立的罪。」

## §1288 句 210-1288-58-71

- **问题**：句法（轻）— `upasampannassa bhaṇḍanakārakabhāvādivinimuttatā` 是**一个**条件（属格 `ပဉ္စင်း၏` 修饰 `ဝိနိမုတ္တတာ`），译文拆成「被驱逐的是已受具足戒者，而且他并不属于争吵者等一类人」两句，并补出「被驱逐的」。总数「三个条件」与 nissaya `ဤသုံးပါး` 相符，不必改数。
- **建议**：合为一项，如「所驱逐者是已受具足戒、且不属于争吵者等一类的人」。

## §1291 句 210-1291-9-25

- **问题**：词义 — `apaṭāṇidinne`，nissaya 作 `စို့မနှက်အပ်သော`＝「未钉入木栓（paṭāṇi）的」。译文「没有加固」过于笼统，丢掉了 nissaya 指明的具体做法。
- **建议**：「在没有钉入木栓（apaṭāṇidinna）的插脚床（āhaccapādaka）上坐下或躺下」。

## §1294 句 210-1294-22-25

- **问题**：可读性 — 属格直译成「是指住处（vihāra）的」，以「的」收尾，句子未完。
- **建议**：「**它的**（yassa）指的是「住处的」。」（与 §1298 句 36-43 的处理统一，见跨段一致性）

## §1294 句 210-1294-43-51

- **问题**：词义/句法 — nissaya 以宾格点明受名者是门扇：`ကဝါဋံ= တံခါးရွက်ကို … အာလောကသန္ဓီတိ ဝုစ္စတိ`，`sandhi` 在此是「使（窗口）接合者」，不是处所。译文「采光接合处」把它当成一个地方，与后半句「这里说的就是门扇」自相矛盾。
- **建议**：「所以（门扇）被叫作**采光接合（ālokasandhi）**；这里说的就是门扇。」

## §1296 句 210-1296-18-38

- **问题**：原文疑问（记录，不要改）— pali 作 `Iminā pana yena`，nissaya 作 `ဣမိနာ ပန နယေန`（＝ iminā … nayena，「依这个办法」）。疑 pali 脱 `na`。
- **建议**：译文「依这个说法」可改「依这个算法」以贴 `nayena`；原文讹误另记。

## §1297 句 210-1297-20-47

- **问题**：隐含成分 — nissaya 在末句补出 `သကလဝိဟာရဆာဒနံ … ဂဟေတွာ န ဝုတ္တံ`＝「不是**取**整座住处的覆盖（为一道）而说的」。译文「而不是指整座住处的覆盖」丢了「算作一道」这个被否定的对象。
- **建议**：「……而不是把整座住处盖一遍算作一道。」

## §1298 句 210-1298-15-18

- **问题**：词义（轻）— `ပါဌော= ရှိရင်းပါဌ်တည်း`＝「本来的（原有的）读法」，译文「正确的读法」把价值判断加强了。另外译文直出裸巴利 `tatiyaṃ maggaṃ`，前文已把该词译为「第三道」。
- **建议**：「或者说，本来的读法就是「第三道」（tatiyaṃ maggaṃ，宾格）。」

## §1298 句 210-1298-29-35

- **问题**：隐含成分 — nissaya 只给 `ဝုတ္တာ= ၏`，未指说者；译文补「律中说」属无据补出（且与本 chunk 他处「本文里说」不一致）。
- **建议**：「因为只是单纯的草屋，（本文）说是不犯的。」

## §1298 句 210-1298-44-50

- **问题**：黑体范围不一致 — 被解释词只是 `Tiṇṇaṃ pariyāyānaṃ`（三遍），译文在黑体内塞进原文没有的「覆盖」，与上一句「**三道**」的处理不一致。另「间隔」见跨段一致性。
- **建议**：「**三遍**，这里也是同样的道理。」

## §1298 句 210-1298-51-61

- **问题**：隐含成分 — `uttari adhiṭṭhānaṃ`，nissaya 补出具体限度：`နှစ်ထပ် သုံးထပ်လွန် စီရင်ခြင်း`＝「指定超过两三道（层）」。译文「超出限度地指定」把 nissaya 给的内容抹平了。
- **建议**：「超过两三道而指定」。

## §1301 句 210-1301-2-16

- **问题**：格（必改）— nissaya 两处都作具格：`တိဏေန ဝါ= မြက်ဖြင့်`、`မတ္တိကာယ ဝါ= မြေညက်ဖြင့်`（**ဖြင့်**＝以、用），所浇的宾语是 `ဥဒကံ= ရေကို`。译文「把有虫的水浇在草上或泥土上」按宾格/处格读，与本句 nissaya 相反。
  对照：§1302 句 42-67 同一行为 nissaya 作 `မြက်အစရှိသည်သို့ သွန်းခြင်း`（**သို့**＝浇到草上），可见两处格确实不同——§1301 句 48-66 把 mātikā 引作 `tiṇaṃ vā mattikaṃ vā`（宾格），而句 2-16 的底本作 `tiṇena vā mattikāya vā`（具格），原文本身有异读。译文应各随其句的 nissaya。
- **建议**：「……意思是：用草或用泥土浇洒有虫的水，也就是把水泼掉。」原文两处格不一的情况另记（不改 pali）。

## §1301 句 210-1301-17-35

- **问题**：连接词（必改）— `tasmiñca udake`，nissaya 作 `ထိုရေ၌လည်း`（**လည်း**＝并且、也），是与前句并列，不是另一种选择。译文「或者把草、泥土拿来放进那水里」与句首的「或者（atha vā）」重叠，读成了二择一。
- **建议**：「……把水取来泼在外面，并且把草或泥土拿来放进那水里。」

## §1302 句 210-1302-2-11

- **问题**：无据补出 — 「如浇洒」「如饮用」两处夹注在 nissaya 中无对应（`ကိုယ်ပ／ကိုယ်တွင်း အသုံးအဆောင်` 只说身外、身内的使用）。译文正文不应夹入译者的举例。
- **建议**：删去两处举例，或移入报告/脚注。

## §1302 句 210-1302-12-31

- **问题**：数与所指（必改）— `Tadubhayampi`，nissaya 作 `ထိုသပ္ပာဏကသိက္ခာပုဒ်နှစ်ခုအပေါင်းကိုလည်း`＝「那**两条**有虫水**学处**合起来」，指本条与上句说的「后面会另外讲到」的那条。译文「这两种情形」把学处读成了情形。
- **建议**：「这两条学处都是把水当作“有虫的”……」

## §1302 句 210-1302-32-41

- **问题**：隐含成分 — `sikkhāpadantarena`，nissaya 点明是 `သဉ္စိစ္စပါဏ`（故意杀生学处）。译文「另一条学处」笼统。
- **建议**：「那就是依另一条学处（故意杀生学处，sañcicca pāṇa）犯波逸提」。

## §1302 句 210-1302-42-67

- **问题**：数（必改）— 译文说「这里有这四个条件」，却只列出三项（水有虫／知道会死／无杀意而为某事浇在草等上）；nissaya 也作 `ဣတိ ဣမာနိ တီဏိ= ဤသုံးပါးတို့သည်`（三项）。只有 pali 作 `cattāri`。本 chunk 其余三处（§1288 三、§1291 四、§1298 三）译文与 nissaya 均相符，唯此处不自洽。
- **建议**：依 nissaya 改「这里有这三个条件」，pali `cattāri` 与 nissaya 数目不符一并记为原文疑问（不改 pali）。

## §1305 句 210-1305-2-10

- **问题**：语气（轻）— `etasseva`，nissaya 作 `ဤသေနာသနဝဂ်၏သာလျှင်`，`သာလျှင်`（eva）的「正是」语气与所指（卧坐具品）译文都压没了。
- **建议**：「“草木品”（Bhūtagāmavagga）也正是这一（卧坐具）品的名称。」
