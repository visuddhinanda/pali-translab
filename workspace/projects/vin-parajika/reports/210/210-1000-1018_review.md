# Review — 210:1000-1018（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 一、被解释词与父层逐字核对

绝大多数黑体词与父层（138:2604-2633）译文逐字一致：「在时限内指定了而给与的」「这段时间里得到的所指望的衣料」「原有衣料」「纳入自己的期限」「所指望的衣料也可以受持为资具布」「比丘尼每做一个动作，比丘就犯一个恶作罪」「做个身体的示意」「十二肘以内」「只在一众中受了具足戒的人」「暂时借去」「在这条学处还没有制定的时候」「身体各部分的美好」「只把衣放在手掌上交给他」「窘迫得手足无措」「深受刺痛」「用来交换的衣」「钵袋」「直到第七代祖父辈」「不是亲戚的」「祖母」「外祖父」「一辈」——均核对通过。

**不一致（必改）两处：**

### §1004 句 210-1004-46-62
- **问题**：被解释词与父层不一致 — 黑体引自父层 138-2611-34-39「Aññaṃ paccāsācīvaraṃ labhitvāyeva kālabbhantare kāretabbaṃ」，父层定稿作「另一块所指望的衣料」，本层作「另外所指望的衣料」。
- **建议**：改为「**“得到另一块所指望的衣料……乃至……把衣做成”**」。

### §1010 句 210-1010-2-6
- **问题**：被解释词与父层不一致 — 父层 138-2621-2-11「ekena vatthunā nissaggiyaṃ」定稿作「第一件犯舍堕」，本层标目作「由第一件事」，多出「由」「事」。
- **建议**：标目改为「**“第一件”**」，释义仍作「指的是最先做的那一件」。

## 二、跨段/跨层一致性

- **vaṇṇanā**：本层五处标题与结尾（§1000/1005/1006/1012/1013/1018）作「解释」，父层同一标题作「注释」（138-2604「第三迦絺那学处的注释」、138-2613/2627「……的注释结束」）。两层标题文字相同，译名不同会让读者看不出是同一章节的注与疏 → 建议统一为「注释」。
- **数字标题格式**：§1017 首行「513-4.」译作「五一三至五一四、」，而本 chunk 其余标号（497. / 499-500. / 503-5. / 506. / 507. / 508. / 510.）一律用阿拉伯数字加半角点 → **必改**，统一为「513-4.」。
- **acittaka**：本层 §1016（210-1016-40-55）作「无心」「无心也犯」，父层 138-2626 定稿作「不需要有犯意」 → 建议首次出现处夹注对齐，如「无心（acittaka，即不需要有犯意）」。
- **kiriyā / akiriyā**：本层 §1017（210-1017-44-49）作「作」「非作」，父层 138-2626 作「属于作犯」 → 建议作「作犯」「非作犯」，单字「作」孤立出现可读性差。
- **bhisi**：父层 138-2625 作「褥垫」，本层 §1017（210-1017-19-35）作「坐垫套」 → bhisicchavi 为「褥垫的套子」，建议改「褥垫套」以与父层同源词对齐。
- **upacāraṃ muñcitvā**：父层 138-2620-57-69 作「近处范围以外」，本层 §1009、§1016 作「离开（十二肘的／她的）近处」 → 建议统一表述为「离开近处范围」。
- **pitāmaha（层内）**：§1007（210-1007-39-65）释为「祖父母」，紧接着 §1007（210-1007-66-75）又作「祖父」，同一词相邻两句两译 → 建议前句加巴利夹注「**祖父母**（pitāmahā）」，后句保留「“祖父”这个说法」（与父层 138-2615-35-41 一致），使读者看出这正是本句要讲的「以 pitāmaha 一词统摄」。
- **tika / catukka**：父层 138-2621 把 catukka 译为「四句组」，本层 §1017（210-1017-5-12）把 tika 译为「三句」「三句一组」 → 建议作「三句组波逸提」「波逸提的三句组」。
- **语体**：「径取 ekādasāhe 这个读法」「径取 aññaṃ aññaṃ 这个读法」（§1004 两处）中的「径取」为单音节文言用法 → 建议改「直接采用……这个读法」。其余各段语体为现代书面汉语，未见文言句式或工作标记。

## 三、逐句意见

### §1007 句 210-1007-5-24
- **问题**：词序与 nissaya 不合 — nissaya 依次给出 `ဝိဿဇ္ဇနံ=စွန့်ခြင်း`（vissajjana）/ `ပဝေသနံ=သွင်းခြင်း`（送入）/ `အဇ္ဈောဟရဏံ=မျိုခြင်း`（咽下）/ `ဘတ္တကိစ္စ=ဆွမ်းစားခြင်းကိစ္စ`（吃饭这件事），译文作「咽下、进食」，把 pavesana 与 ajjhoharaṇa 对调；且用「进食」译 pavesana，与标目「**进食**」（bhattavissagga）同词，释义回到标目，读者看不出在解释什么。
- **建议**：「意思是把饭食送进肚子里，也就是送下去、咽下去、吃饭这件事」；标目另择一词（如「**吃完饭**」）以避开循环。末句 vissajjana 的第二说 `ဝိဿဇ္ဇနံ=စွန့်ခြင်း`（舍、了结）译作「把饭食打发掉」太随意，建议「吃完东西，也就是把这顿饭了结」。

### §1007 句 210-1007-25-38
- **问题**：格误读 — `tāya nāma tvaṃ` 的 tāya 是阴性具格/处格，nissaya 作 `တာယ နာမ= ထို…ရဟန်းမိန်းမကို`（以 `ကို` 标为动作所涉对象），不是目的；译文「你竟然为了她」读成了目的语。
- **建议**：改为「或者‘你竟然跟她（这样）’」，或依语境作「你竟然叫她（做这事）」。

### §1008 句 210-1008-2-21
- **问题**：范围略宽 — nissaya 把 `payogassa` 明确释为 `ပုဗ္ဗပယောဂကို`（预备动作），译文作「与之相应的一切动作」。
- **建议**：「与之相应的一切预备动作就全都算是被吩咐过的」。

### §1009 句 210-1009-2-41
- **问题**：句法结构误读（必改）— nissaya 把 `တဒဝိနာဘာဝတော` 释为 `ထို ပုဗ္ဗပယောဂနှင့် ကင်း၍ မဖြစ်ခြင်းကြောင့်`，即「tad」指上文（§1008）的**预备动作**，与「vuttattā」是**两条并列的理由**（`ကြောင့်` 各出现一次）：①洗这件事离不开那些预备动作，②（义注）说了「做个身体的示意」和「在十二肘以内」。译文「由于让她洗这件事离不开这两点——义注既说了……又说了……」把 tad 改指「这两点」，两条理由并成一条。
- **建议**：「因为洗衣这件事离不开那些预备动作，又因为（义注）说了**“做个身体的示意”**和**“在十二肘以内”**，所以……」。

### §1016 句 210-1016-17-39
- **问题**：成分误读（必改）— nissaya 补出 `ယံ စီဝရံ=အကြင်သင်္ကန်းကို` 与 `တံ စီဝရံ=ကို`，即 yaṃ…taṃ 指的是**那件衣**（gaṇhāti 的宾语），parivattakaṃ 是「作为交换」的补语（`ပရိဝတ္တကံ=ဖလယ်သည်ကို ကတွာ=ပြု၍ ဂဏှာတိ=ယူ၏`）。译文「而取得交换之物，这种情形除外」把「衣」丢掉、把 taṃ 改指「情形」。
- **建议**：「哪怕只给一小块诃子（harīṭaka），或者心里存着‘我会给的’这样的打算，作为交换而取得的那件衣——把那件衣除外」。

### §1015 句 210-1015-2-13
- **问题**：取义与 nissaya 不合 — nissaya 把 `vihatatāya` 读作 `ဝိဂတဟတ္ထတာယ=လက်ယှက်ရခြင်းမှကင်းသောကြောင့်`（无可攀附、无所倚傍），与下文 `အမိဿိတတာယ`（无人相与）、`အပဋိသရဏတာယ`（无所依靠）同属一组近义释语；译文「被打垮了」在这一组里语义跳脱。
- **建议**：「意思是无所倚傍，也就是无人相伴、无所依靠」。（巴利文本作 vihatatāya，若保留「被打垮」，宜在报告层面记其与 nissaya 读法不同，不在译文里留标记。）

### §1001 句 210-1001-16-26
- **问题**：标目译法与本句结论相抵 — 本句依 nissaya（`ကရုဏဝစနဿ=တတိယာဝိဘတ်၏`、`သာမိဝသေနေဝ=သမ္ဗာန်၏ အစွမ်းအားဖြင့်`）判定 `bhikkhunā` 这个具格要按属格理解，而标目却译成「比丘在衣做完以后」，把比丘处理成施事。
- **建议**：标目作「**“比丘的衣做完以后”**」或「**“衣做完了的比丘”**」，后半仍作「这里的具格应当像第二迦絺那学处那样，按属格的意思来理解」。

### §1001 句 210-1001-2-15
- **问题**：标目与释义不同构，语法要点被抹平 — 本句的要点是把 `cīvarapaccāsā` 读作 `cīvarapaccāsāya satiyā`（nissaya：`စီဝရပစ္စာသာယ=…သည် / သတိယာ=ရှိသော်`，即「在……存在时」）。译文标目作「因为指望得到衣料而存放」（因果），释义作「在还有得到衣料的指望时存放」（时间），读者看不出前后是同一结构的改写。
- **建议**：标目改为「**“为指望得到衣料而存放”**」或直接「**“有衣料的指望而存放”**」，使释义显出所补出的「satiyā」。

### §1003 句 210-1003-55-74
- **问题**：补出了原文与 nissaya 都没有的施事 —「不让人把原有衣料按最多一个月的期限存放」中的「人」无据；adatvā 的主语是所指望的衣料本身。
- **建议**：「不让原有衣料按最多一个月的期限存放下去」。

### §1007 句 210-1007-39-65
- **问题**：数的限定无据 — nissaya 作 `တေ ဧဝ=ထို အဘိုး အဘွားတို့သည်သာလျှင်`（复数，未限于两人），译文「他们两人成对」添了「两人」。
- **建议**：「正是他们成对，所以叫做**“一辈”**」。

## 四、备查（本层不改，供父层复核）

- **§1003（210-1003-40-45／46-54／75-84）与父层 138-2610-18-46 的主宾相反**：本层依 nissaya 明确标注——前一句的 `paccāsācīvaraṃ` 是 `ပစ္စတ္တဝစနံ=ပထမာဝိဘတ်`（主格）、`mūlacīvaraṃ` 是 `ဥပယောဂဝစနံ=ဒုတိယာဝိဘတ်`（宾格），后一句的 `mūlacīvaraṃ` 才是主格；210-1003-55-74 的释义（所指望的衣料不让原有衣料按一个月存放，而按自己的十天安立它）也印证这一点。父层定稿译作「由原有衣料把它纳入自己的期限；从那天以后，则是由所指望的衣料把原有衣料纳入自己的期限」，施受恰好相反。**本层译文正确，不要改**；请记入父层复核清单。
- **§1003（210-1003-85-111）nissaya 按语**：nissaya 在 `ဒသာဟပရမတာဒိဝသေန` 下注明「（မာသပရမတာဒိဝသေန ရှိရမည်ထင်သည်）」，与巴利 `navāhaparamatādivasena` 不同。译文从巴利作「按最多九天等等的算法」，处理恰当，仅记录待核。
- **§1014（210-1014-24-31）**：父层把 `hatthataleyeva dassetvā` 定稿为「只把衣放在手掌上交给他」（dassetvā 作「交给」），本层释义依 nissaya 作「除了手掌以外，身体其余的部分都没有让他看见」（`အဒဿနံ=မမြင်စေခြင်း`）。标目须与父层逐字一致，故不改；两句并读仍可通，记录备查。
