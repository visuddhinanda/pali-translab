# Review — 210:184-190（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 审查范围：仅 nissaya 词法复核（格、数、主宾属关系、隐含成分）＋ chunk 内一致性。

## 跨段一致性

- **整句缺译**：`210-187-24-50` 没有 `zh` 字段，整句（maggassa niyyānaṭṭho / hetvaṭṭho / dassanaṭṭho / adhipateyyaṭṭho 四项）未译出。这是本 chunk 最严重的问题，必须补译；nissaya 已给出完整词法（`အယံ= ဤသမုဒယသည်` 主格、`ဒုက္ခဿ ... ဟေတု`、`နိဗ္ဗာနပ္ပတ္တိယာ ... ဟေတု`、`အဓိကပကာ ဒုက္ခဿ` 等），可据以补。
- **「（某谛的）X 之义」的属格补出不统一**：nissaya 在这一串里几乎每句都补了属格主体（`တဿ/အဿ= ထိုဒုက္ခသစ္စာ၏`、`တာဝ= ထိုသမုဒယသစ္စာ၏`）。译文时补时不补——§186 句 41-52「苦的炽燃之义」✅、句 81-85「（集的）结合之义」✅、§187 句 12-23「（灭的）无为之义」✅，但句 31-40「有为之义」、句 53-59「变坏之义」、句 86-91「障碍之义」都没补。建议统一按 nissaya 补出，格式统一用括号「（苦的）／（集的）／（灭的）」。
- **`tassa / tasseva` 属格的落点不统一**：§187 句 2-11 译「它的**远离之义**」正确（nissaya `တာဝ= ထိုနိရောဓသစ္စာ၏သာလျှင်`）；§186 句 70-80 同样结构却把属格挪到了宾语上（见该句条目），两处必须一致。
- **`niyyāna` 与 `nissaraṇa` 译名未区分又未统一**：§187 句 2-11 `nissaraṇaṭṭho` 译「出离之义」；§186 句 86-91 `niyyānabhūtassa maggassa` 译「作为导出的道」。nissaya 两处都作 `ထွက်မြောက်` 系。建议定一组：`nissaraṇa`＝出离，`niyyāna`＝导出（出离之道），并在补译 `210-187-24-50` 的 `niyyānaṭṭho` 时沿用同一译名。
- **粗体包住了标点**：`210-185-84-104`、`210-187-12-23` 的译文里出现 `**，**`（原文坐标里的 `**,**` 被照搬加粗）。标点不应带粗体标记，去掉两侧星号，只保留全角逗号。
- **巴利夹注体例不统一**：同一批法相术语，upanāha / makkha / palāsa / māyā / sāṭheyya / thambha / sārambha / mada / papañca / agati / taṇhuppāda / cetokhila / cetovinibandha / taṇhākāya / parissaya 都加了夹注，而同列的 māna（慢）、atimāna（过慢）、pamāda（放逸）、micchatta（邪性）、diṭṭhigata（见）、vipariyesa（颠倒）都没加；§184 句 83-85 只给 rāga 加夹注，同句的 dosa / moha 不加。按 `style.md`「法相术语首次出现夹注巴利原词」应统一处理（建议：同一枚举列表内要么全加、要么只给罕见词加，不要半数加半数不加）。

## §184 句 210-184-25-31

- **问题**：属格修饰关系 — nissaya `ပုဗ္ဗကာရိတာလက္ခဏ= ရှေးဦးစွာပြုလေ့ရှိသည်၏အဖြစ်လျှင် လက္ခဏာရှိသော` ＋ `ဂုဏဿ= ကျေးဇူးကို`，即「以『先前曾施作』为特相的**功德**」，lakkhaṇa 是 guṇa 的属性修饰语。译文「他人先前施恩这一特相的功德」读起来像把「特相」与「功德」并列同指。
- **建议**：改为「抹掉他人**以先前施恩为特相的**功德，叫做覆（makkha）」。

## §184 句 210-184-32-38

- **问题**：**主宾方向译反（必改）** — nissaya `အတ္တနာ= မိမိနှင့်` ＋ `သမကရဏံ= အတူပြုခြင်းသည်`，即「使（对方）与**自己**相等」；pali `attano samakaraṇaṃ` 同指——把他人拉低到与己平齐。译文「把自己摆到和他们同等的地位」方向相反（成了自抬）。
- **建议**：「与多闻者等并驾争先、把（对方）压到和自己同等，就是恼（palāsa）」。`yugaggāha` 按 nissaya `အစုံကိုယူခြင်း` 作「并驾、争一高下」，比单说「相争」更贴。

## §184 句 210-184-72-76

- **问题**：擅自补出数词 — nissaya 只作 `ကာမဂုဏေသု= ကာမဂုဏ်တို့၌`（处格复数），没有「五」。
- **建议**：改「把心放纵在诸欲乐上」或「在欲乐（kāmaguṇa）上」；若要保留「五种」，需另有依据。

## §184 句 210-184-86-90

- **问题**：句子结构 — nissaya 在 `teyeva` 与 `kāyaduccaritādayo` 之间标了异释 `ဝါ= ကား`，即「正是那三垢（是三种不正）；**或说**是身恶行等」，两组是并列的两种说法，不是一组加另一组。译文「这三者，以及身恶行等，都是三种不正」合并成一组，且与「三种」的数目对不上。
- **建议**：「正是那三者（贪瞋痴）就是三种不正；或说是身恶行等（三者）。」按 `style.md`，异释可取主译、异释入脚注。

## §184 句 210-184-101-103

- **问题**：取义偏窄 — nissaya `ဖောက်ပြန်သောအားဖြင့် ရှာမှီးခြင်း`，把 vipariyesa 解为「以颠倒的方式**追求**」，含「求」义。
- **建议**：「以为净、以为乐、以为常、以为有我而**颠倒追求**，就是四种颠倒（vipariyesa）」。

## §184 句 210-184-104-106

- **问题**：nissaya 补出的数词被漏掉 — `အဂတီ= လေးပါးသော အဂတိတို့မည်ကုန်၏`（四种 agati），同一枚举里其余各项都保留了数词。
- **建议**：「……就是**四种**非行处（agati）」。另 nissaya 把 `chandādayo` 读作 `ဆန္ဒဂတိအစရှိသည်`，即「随欲而行等」，译文「因贪欲等而走上不该走的路」方向无误，可保留。

## §184 句 210-184-107-112

- **问题**：数不符 — nissaya `လောဘာ= တို့သည်` 为复数主格（诸贪），对应衣、食、住、药四资具各一。译文作单数「贪」。
- **建议**：「对衣服等（四）资具的**诸贪**，就是四种爱的生起（taṇhuppāda）」。

## §184 句 210-184-153-156

- **问题**：`aṭṭha` 的归属 — nissaya `အဋ္ဌမဂ္ဂင်္ဂပဋိပက္ခာ= မဂ္ဂင်ရှစ်ပါး၏ ဆန့်ကျင်ဘက်ဖြစ်သော တရားတို့သည်`，「八」属格修饰 maggaṅga（八道支），`micchattā` 的「八」由 nissaya 另行给出（`မိစ္ဆတ္တ ရှစ်ပါး`）。译文「与八支圣道相违的**八种**」把数词挂在被修饰项上，属格关系错位。
- **建议**：「邪见等与**八道支**相违的诸法，就是**八种**邪性（micchatta）」。

## §184 句 210-184-157-194

- **问题**：`ajjhosāna` 的取义 — nissaya `ငါ့ဥစ္စာဟု စွဲလမ်းခြင်း`（执为「我所有」）。译文「耽著」未体现「执为我所」这一层。
- **建议**：可作「执取为己有（ajjhosāna）」，或保留「耽著」并在首次出现处夹注巴利原词。

## §185 句 210-185-2-18

- **问题**：异文，记录即可 — pali 作 `gahitam atthaṃ`，nissaya 却读作 `ဒီပိတံ`（dīpitaṃ，所显示的）。译文「所摄取的意义」从 pali。
- **建议**：译文可不改，但此处 nissaya 与底本有异读，存疑记录；若要从 nissaya 则作「这两个词所**显示**的意义」。

## §185 句 210-185-84-104

- **问题**：nissaya 补出的行为主体未译 — `ဂစ္ဆတော= ကြွသောဘုရားရှင်၏`、`ကရောတော ဝါ= ပြုသောဘုရားရှင်၏`，两个属格分词的主体 nissaya 明确补为「世尊」。译文作无主句，读者会误以为是泛指任何人。
- **建议**：「无论（世尊）是经由空中行走，还是做其他任何事情……」。另：译文里 `**，**` 的加粗标记需去掉（见跨段一致性）。

## §185 句 210-185-115-125

- **问题**：**定义句的主谓译反（必改）** — nissaya 明确 `ဣစ္ဆိတံ= အလိုရှိအပ်သော အကျိုးမည်၏`、`ပတ္ထိတံ= တောင့်တအပ်သော အကျိုးမည်၏`，即 icchita / patthita 是**被定义的词**，`lahusādhanaṃ taṃ taṃ kālikaṃ` 与 `garusādhanaṃ cirakālikaṃ buddhattādi` 是**释义**。译文「容易成就的，是各随其时所希求的东西」把释义与被释词颠倒，并丢掉了「名为……」的定义结构；又 `garusādhana` nissaya 作 `ဖြေးဖြေးနှေးနှေးပြီးစေအပ်သော`（缓慢才成就），不是「难以成就」。
- **建议**：「容易成就、随各各时节（而得）的，叫做『所欲』（icchita）；须经长时缓慢成就的、如佛果等所求的，叫做『所愿求』（patthita）。」

## §185 句 210-185-126-140

- **问题**：`idaṃ` 的指称 — nissaya `“ဘဂဝါ”တိ ဣဒံ= ဘဂဝါဟူသော တဒ္ဓိတ်ရုပ်သည်`，idaṃ 指**「bhagavā」这个（派生）词形**，不是「这个解释」；`sesaṃ sabbaṃ` nissaya 亦作 `ကြွင်းသောခပ်သိမ်းသောရုပ်သည်`（其余一切**词形**）。
- **建议**：「『他有诸福，所以称为世尊』——应当知道，**『世尊』这个词形**是依语法学（声论）之法成立的，其余一切**词形**都是依词源解释之法成立的。」

## §186 句 210-186-31-40

- **问题**：(1) `taṃ` 的格 — nissaya `တံ= ထိုဒုက္ခသစ္စာကို`（宾格，指苦）＋ `သမုဒယေန`（施事），即「集造作了它（苦）」；译文「由它的集所造作」把 taṃ 当成修饰 samudaya 的「它的」。(2) 属格主体漏补 — nissaya `တဿ= ထိုဒုက္ခသစ္စာ၏`。
- **建议**：「由于**它**（苦）是由集所造作的，所以（苦的）**有为之义**就通过见到集而显明了。」

## §186 句 210-186-70-80

- **问题**：**属格落点错（必改）** — nissaya `တာဝ= ထိုသမုဒယသစ္စာ၏သာလျှင်` ＋ `ဒုက္ခဒဿနေန= ဒုက္ခသစ္စာကို မြင်သဖြင့်`，`tasseva` 是修饰 `nidānaṭṭho` 的属格（正是**它的**因缘之义），`dukkha` 只是「见苦（谛）」的宾语，nissaya 没有「由它而生」这层。译文「通过见到由它而生的苦，因缘之义就显明了」把属格挪到了苦上，并擅自补出因果关系。
- **建议**：「……而通过见到苦，**正是它的因缘之义**就显明了。」（与 §187 句 2-11 的处理保持一致）

## §186 句 210-186-86-91

- **问题**：属格主体漏补（见跨段一致性）；另 `niyyānabhūtassa` nissaya 作 `ထွက်မြောက်ကြောင်းဖြစ်သော`（作为出离之因）。
- **建议**：「通过见到作为**出离之因**的道，（集的）**障碍之义**就显明了。」

## §187 句 210-187-12-23

- **问题**：异释未处理 — nissaya 对 `amataṭṭho` 给了两读：`အမြိုက်အရသာဟူသော အနက်`（甘露味之义）／`ဝါ= မသေတတ်သော အနက်`（不死之义）。译文只取后者，未备列前者。
- **建议**：主译保留「不死之义」，把「甘露（味）之义」作脚注备列（依 `style.md` 第四节）。另：译文里 `**，**` 的加粗标记需去掉。

## §187 句 210-187-24-50

- **问题**：**整句未译（必改）**，`zh` 字段缺失。
- **建议**：按 nissaya 补译，四项依次为：道的**出离之义**是其自性；通过见到集（知）「这集只是苦的因，而唯有此道才是证得涅槃的因」，故**因之义**显明；通过见到极微细的灭（知）「唯有此道是见（的途径）」，故**见之义**显明；通过见到孤苦无依之苦，**主宰之义**显明。
