# Review — 210:37-41（channel: 73c03e1a）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照

- 注入的父层段落（138:618-626）与本 chunk 的被解释词**不对应**：父层讲的是 `yena / upasaṅkamitvā / sammodanīyaṃ / ekamantaṃ / nisīdi / jiṇṇe…vayo anuppatte / abhivādeti` 一系列词，而本层 210:37-41 的黑体词是 `tatthā / tāva / vavatthapetabbo / tenetaṃ vuccatī / assā / mātikā / vuttaṃ yenā / tattha vuttaṃ yenā / idan / hi / attapaccakkhavacanaṃ na hotī`，两边没有一个重合项。因此**本 chunk 的黑体词无法用所给父层译文校验**，配对需要换成覆盖这些词的父层段落。
- 唯一可比的交叉项是引文中的地名：本层 §39「住在**毗兰若**」与父层「**毗兰若**婆罗门」一致 ✅。

## 跨段一致性

- `nidāna`：§37 标题译「外**缘起**的叙说」，§39/§40/§41 一律译「因缘」「因缘之语」 → 同一词两种译法，建议统一为「因缘」，标题改「外因缘的叙说」。
- **虚词词头的处理方式不一致**：§38 把 `tāva-saddo` 意译成「**首先**这个词」，§41 把 `hi-saddo` 保留原形「**hi** 这个词」。父层对同类情形保留巴利原形（「“vā”这个词」「**“d”这个字母**」）→ 建议 §38 统一为「**tāva**（先）这个词」。
- `karissāmi` 的第一人称：§38「之后**我**再对它作解说」保留，§39 末句「这样来对律作意义上的解说」丢了施事（nissaya `ကရိဿာမိ= ပြုအံ့`，第一人称将来）→ 建议 §39 补回「我要这样来对律作意义上的解说」。
- `tattha` 的处格：§38 句 25-30 与 §41 句 13-17 都把 nissaya 的 `၌`（locative）处理成「是指 X」，两处一并改为「是指在 X 里」更合（见下）。

## §38 句 210-38-25-30

- **问题**：格 — nissaya `ယထာဝုတ္တာသု ဂါထာသု= တို့၌` 是处格复数（在那些偈颂**里**），译文「是指前面所说的那些偈颂」把处格读成了同位语。
- **建议**：「这里的**其中**，是指在前面所说的那些偈颂里。」

## §38 句 210-38-31-48

- **问题**：指代 — nissaya 把 `tena` 释为 `ထို ပဌမံ-ဟူသောပါဌ်ဖြင့်`，即「以**“paṭhamaṃ”（先）这个释语**」为工具，而非指 `tāva` 本身。译文「他用这个词表明」最自然的读法是 `tāva`，与 nissaya 的指代相反。
- **建议**：「他用“先”这个释义表明：先把律确定下来，之后我再对它作解说。」

## §38 句 210-38-72-75

- **问题**：取义 — nissaya `ဥဒ္ဒေသော= အကျဉ်းပြခြင်းတည်း`，强调「简略地揭示」；「纲目」偏向条目清单，丢了「略说」这一层。
- **建议**：译作「略说（提要）」，或「就是略示纲要」。

## §39 句 210-39-12-58

- **问题**：补出成分 — nissaya 对两个动词都补出了具体内容：`ဓာရိတံ= နှုတ်၌ဆောင်အပ်၏`（以口受持、口口传持）、`အာဘတံ= သီဟိုဠ်ကျွန်းသို့ဆောင်အပ်၏`（传到师子洲）。译文「由谁所受持的、由谁所传来的」把这两处都读空了，`ābhata` 更会让读者不知传往何处。
- **建议**：「由谁口口传持的、由谁传到（师子洲）的」；传入地点若不进正文，至少把「口口传持」补上。
- **问题**：人称 — 末句丢掉 `karissāmi` 的第一人称（见跨段一致性）。
- **建议**：「……这样我要来对律作意义上的解说。」

## §40 句 210-40-2-47

- **问题**：所指 — nissaya `ဧတ္ထ= ဤမာတိကာ၌`，明示是「在这本母里」；译文只作「这里」，上下文容易误读成「在这段注里」。
- **建议**：「而且，在这本母里，**由谁所说、在何时、因何缘由**这句话……」
- **问题**：漏译 — `nidānavacana**mattaṃ**` 的「仅」未译出（nissaya 以 `နိဒါန်းအစဉ်ကို` 限定范围）。
- **建议**：「……只着眼于“那时候，佛陀世尊”等等这一段因缘之语……」

## §40 句 210-40-48-56

- **问题**：格与范围 — nissaya `သဗ္ဗတ္ထ= ခပ်သိမ်းသော ပုဒ်တို့၌`，`sabbattha` 指「（本母的）一切词句中」；译文「在一切处都能和这些条目关联得上」把处格虚化成「一切处」，又另起「这些条目」，等于把同一成分说了两遍。主语判定没问题（nissaya `ဝိနယပိဋကံယေဝ= သည်သာလျှင်` 为主格，译文以「律藏」作主语 ✅）。
- **建议**：「因为本母里所说的“这个”就是律藏本身，所以总的来说，它在本母的一切词句上都能关联得上。」

## §41 句 210-41-2-12

- **问题**：所指 — nissaya `တံ= ထိုနိဒါန်းကို`，明示 `taṃ` 指「那段因缘」；译文作「那一段」，指代悬空。
- **建议**：「不过现在，为了把那段因缘单独提出来加以指明……」

## §41 句 210-41-13-17

- **问题**：格 — nissaya `တေသု မာတိကာပဒေသု= ထိုမာတိကာပုဒ်တို့တွင်` 为处格复数。
- **建议**：「**其中**，是指在那些本母的词句当中。」
