# Review — 210:325-328（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照

- 本 chunk 的黑体全是典籍名（**bhikkhunīvibhaṅgaṭṭhakathāyaṃ** / **sāratthadīpaniyaṃ** / **paramatthajotikāya** / **gaṇṭhipadesu** / **suttapiṭakādiaṭṭhakathāsu**），在所给父层段（138:947–949）中并未出现，因此没有可逐字比对的被解释词。
- 与父层共用的术语译法一致，无须改动：`lokavajja`=世间所谴责的、`paṇṇattivajja`=因制戒而成为过失的、`sacittakapakkhe`=在有心的那一类情形里、`cittaṃ akusalameva`=心必定是不善的。
- 附带记录（不是译文问题）：父层段 138:947–949 的内容是 Makkaṭīvatthu／anupaññatti，本层 210:325–328 通篇讨论 surāpāna，两边主题不对应，父层配对坐标值得复核。

## 跨段一致性

- `sutta` / `suttādi`：326-129-147 译「律本文（sutta）、随顺律本文（suttānuloma）」在律学四大教法的语境下恰当；但 326-148-174 与 328-70-79 的 `suttādi` 覆盖两藏（下句自言「律藏里看不到…经藏等里也没有」），译成「律本文等」自相矛盾。nissaya 两处都作 `သုတ္တာဒိကံ= ပါဠိအစရှိသည်`（圣典本文等）→ 建议这两处改「圣典本文（sutta）等」，与 326-129-147 的律学术语区分开。
- `aṅga`：325-386-391「各支」、325-392-429「四支」、326-87-94「支分」、328-42-69「支分」混用 → 建议统一作「支」（`jānanaṅga` 了知支、`payogaṅga` 加行支）。
- `visaya`：325-21-30 / 328-128-134 作「范围」（sikkhāpadavisaya 学处的范围）正确；328-30-41 的 `visayānuguṇaṃ` nissaya 作 `အာရုံအားလျော်စွာ`（随顺所缘）→ 建议改「随着所缘」，免与「范围」混为一词。
- 人物属格/与格一律被译成时间状语（见 327-94-109、328-12-29 两条），处理方式应统一为「在…的人身上」。
- `ca` 的处理：325-204-214 引文内把 `ca` 译作「并且」，同句解释又说它「相当于『再者』」，前后打架 → 引文内改「再者」，与解释一致。

## §325 句 210-325-2-20

- **问题**：施事成分丢失 — `vadantena` 是 gerundive `vattabbaṃ` 的施事具格，nissaya `ဝဒန္တေန= ဆိုသော ဆရာသည်`（说的那位论师，主格施事）。译文把它化成无主语的条件句「如果只是在重复说……」，施事「论者」被抹掉。
- **建议**：补出施事，如「再者，重说已说过之义的论者，本应按前面说过的次序说『……』」。

## §325 句 210-325-31-65

- **问题**：省略成分未补 — `na evaṃ surāpānassa` 的省略内容 nissaya 已补齐：`သုရာပါနဿ … သစိတ္တကပက္ခေ ဧဝ … လောကဝဇ္ဇတာ စ … အကုသလစိတ္တတာ စ … ဝိသေသေတွာ န ဝုတ္ထာ`，即「对饮酒，并没有把『世间所谴责』『不善心』限定在有心的那一类里来说」。译文只作「对于饮酒却不是这样说的」，指代过虚。
- **建议**：照 nissaya 补出宾语：「对于饮酒，却没有这样把两者限定在有心的那一类情形里来说。」

## §325 句 210-325-109-140 【必改】

- **问题**：主句谓语整条丢失，并且主宾关系倒置。
  1. nissaya 在本句内就把被省略的主句补出：`ယံ ဝစနံ= ကို။ ဝုတ္တံ= ၏။ တမ္ပိ= ထိုစကားကိုလည်း။ ပဋိသိဒ္ဓိ= တားမြစ်အပ်သည်။ ဟောတိ= ၏`——`yaṃ … vuttaṃ` 的落脚处是「这段话**也被否定了**」（与下一句 141-190 的 `tampi paṭisiddhaṃ hoti` 同一结构）；句首 `eteneva` nissaya 更明确注「(ပဋိသိ၊ ဟောတိ-၌စပ်လေ။)」，即须与 `paṭisiddhaṃ hoti` 相接。译文把 yaṃ-从句写成了一句完整的陈述，整句变成「《显扬要义》这样说了」，驳斥的结论没了。
  2. `etaṃ` / `imasseva adhippāyassa` 的角色反了：nissaya `ဧတံ= ဤ အကုသလေနေဝစသောဝါကျသည်`（主格，指义注「akusaleneva…」那句）作 `paṭipādakaṃ` 的主语，`ဣမာဝ အဓိပ္ပါယဿ= ဤအဓိပ္ပါယ်ကိုသာလျှင်`（作宾格）是被成立的那个意趣。即「以为**义注那句话**正是在成立**它（《显扬要义》）所说的这个意趣**」。译文作「《显扬要义》里所说的『…』这句话，是因为以为它正是在阐明上面说的那同一个意趣才这样说的」，成立者与被成立者互换。
- **建议**：重组为「正由（义注）这句话，《显扬要义》里所说的『在有心的那一类情形里……所以是世间所谴责的』——那是因为以为义注的『由于必定是以不善心饮用，所以是世间所谴责的』正是在成立它这个意趣；确实，正是出于这个意趣，在其他属于世间所谴责而又是无心的学处里，也只说是不善心，而不说三种心——**这段话也被否定了**。」

## §325 句 210-325-141-190

- **问题 1**：使役关系未译出 — `bhikkhunīādīhi ummaddanaparimaddanāni`，nissaya `ဘိက္ခုနီအာဒီဟိ= ဘိက္ခုနီအစရှိသည်တို့**ကို**`（宾格）+ `ဥမ္မဒ္ဒနပရိမဒ္ဒနာနိ= နယ်**စေ**သော သိက္ခပုဒ်`（使役），即「令比丘尼等人揉搓按摩」的学处。译文「由比丘尼等人揉搓按摩」只写出施事，使役义丢失。
  - **建议**：改「令比丘尼等人揉搓按摩」。
- **问题 2**（记录，不要改原文）：`saṅghāṇi` nissaya 作 `သင်္ဃာတီ`（saṅghāṭī，重衣），与 pali 词形不合，且未给释义；译文「腰饰」依 pali 读法。两读差异记此备查。

## §325 句 210-325-255-267

- **问题**：`viseso` 的比较对象未补 — nissaya `ဝိသေသော= သစိတ္တကပက္ခမှ ထူးသော အဖြစ်သည်`，指「相对于有心那一类而言的特别之处」。
- **建议**：「在『无心』这一点上，这里并没有与有心的那一类相比的特别之处。」

## §325 句 210-325-359-385

- **问题 1**：数词省略未补 — `sesā`，nissaya `သေသာ= ကြွင်းသော သိက္ခာပုဒ်**ငါးပါး**တို့သည်`（其余**五条**学处）。译文作「其余的」，且「其余的是远离因制戒而成为过失的离」句法残缺。
  - **建议**：「其余五条则是远离因制戒而成为过失之事的离。」
- **问题 2**：句末「——本性罪就是前文所说的世间所谴责的」是译者自加的复述；nissaya `လောကဝဇ္ဇတာသင်္ခါတာ ပကတိဝဇ္ဇတာ` 的同位关系在前半句「所谓『世间所谴责』的本性罪性」中已表达。
  - **建议**：删去这段重复。

## §325 句 210-325-392-429 【必改】

- **问题**：词义误译 — `pīte ca pavisati`，nissaya `ပဝိသတိ စ= **ဝမ်း**သို့လည်း ဝင်၏`（进入**腹中**）。译文作「进入咽喉」，与 nissaya 的处所词不符。
- **建议**：改「喝下去时（酒）进入腹中」。

## §326 句 210-326-2-68 【必改】

- **问题 1**：喻与所喻颠倒 — nissaya 明示 `ပါဏာတိပါတော ဟောတိ **ယထာ**= ဖြစ်သကဲ့သို့`（杀生成立是**喻**），`**ဧဝံ** … အကုသလမေဝ ဟောတိ`（饮酒是**所喻**）。译文把饮酒放在「就像」一侧、杀生放在「同样」一侧，整个类比方向反了；下半句（蛇/木头→酒/椰子汁）方向却是对的，一句之内两种取向自相冲突。
  - **建议**：恢复为「就像有人想『我要杀死这个众生』，却杀了躺在同一处的另一个众生，由于同样都是生命，仍然成立杀生；同样，有人想『我要喝这种酒』，却喝了另一种酒，由于同样都是酒，仍然是不善的。」
- **问题 2**（记录）：`etaṃ sattaṃ` / `etaṃ majjaṃ`，nissaya 本文读 `ဧကံ သတ္တံ` / `ဧကံ မဇ္ဇံ`（一个众生／一种酒），并各自注出第六结集本作 `ဧတံ`。译文「这个众生／这种酒」与第六结集读法一致，可保留，异读备查。

## §326 句 210-326-87-94

- **问题**：指代过虚 — `bhinnānaṃ` nissaya 补出所指：`ဘိန္နာနံ= ပြားကုန်သော **ပါဏာတိပါတ အစရှိသည်**တို့၏`（各不相同的**杀生等**）。译文作「本来就各不相同的事项」。
- **建议**：改「把在加行、支分等方面本来就各不相同的杀生等各条混在一起……」。

## §327 句 210-327-94-109

- **问题 1**：`taṃ` 的指涉被虚化 — nissaya `တံ နိသေဓာယ= ထို**အကုသိုလ်သာတည်းဟူသော အယူ**ကို မြစ်ခြင်းငှါ`，`taṃ` 明指「（不知而饮也）唯是不善」这一主张。译文「没有什么需要引用这段经文去加以否定的了」丢了指涉。
  - **建议**：「也就没有理由引这段经文去否定『唯是不善』这一说法了。」
- **问题 2**：`ajānantassa` 是人物属格/与格（nissaya `အဇာနန္တဝ= မသိသော သူ**အား**ပင်လျှင်`），译文转成时间状语「正是在还没有按名称、种类等方式了知的时候」。
  - **建议**：改「正是在还不能按名称、种类等方式了知的人身上，五识心路中也有善、不善的速行生起」。

## §328 句 210-328-12-29

- **问题**：同上的属格人物被译成时间状语 — nissaya `တုဏှိဘူတာနံ … သူတို့**အား**`、`ပဿန္တာနမ္ပိ= မြင်မက်သောသူတို့**အား**`（对沉默不语的人、对睡梦中的人）。译文作「即使在沉默不语的时候、在睡着做梦的时候」。
- **建议**：改「即使在沉默不语的人身上、在睡着做梦的人身上」，与 327-94-109 的处理统一。

## §325 句 210-325-310-338（低优先）

- **问题**：书名重复 — 译文先在夹注里写「《小诵经义注》二·后五学处解说」，紧接着又写「即《小诵义注》的学处解说里说」，同一部书两种名称连出。nissaya 对 `sikkhāpadavaṇṇanāya` 另给了更具体的定位：`သိက္ခာပဒံ သမာဒိယာမိကို ဖွင့်ရာ၌`（释「sikkhāpadaṃ samādiyāmi」处）。
- **建议**：保留一处书名，正文作「《胜义光明》即《小诵》义注，在释『sikkhāpadaṃ samādiyāmi』的学处解说里说」。
