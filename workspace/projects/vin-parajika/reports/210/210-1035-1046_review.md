# Review — 210:1035-1046（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 一、被解释词与父层（book 138）比对

逐条核对本 chunk 全部黑体词。以下四处与父层译文不一致，**必改**：

| 句 id | 黑体词 | 现译 | 父层定稿 |
|---|---|---|---|
| 210-1040-2-16 | `Yatassa cīvaracetāpannaṃ` | 买衣的资财是从谁那里为他送来的 | 从哪里为他送来了买衣的资财（138-2685-2） |
| 210-1041-2-10 | `mukhavevaṭiko` | 口头指定的净人 | 当面自任的净人（138-2686-32、138-2693-34） |
| 210-1041-53-68 | `Kappiyakārakānaṃ hatthe` | 在处理合宜事务的人手里 | 在净人手里（138-2692-64） |
| 210-1041-29-52 | `meṇḍakasikkhāpadaṃ` | 羊商学处 | 梅那卡学处（Meṇḍakasikkhāpada）（138-2692-57） |

- 210-1041-2-10 不只是对应断裂，还是**实质误译**：mukhavevaṭika 属 `aniddiṭṭha`（未经指定）一类，本句自己也译作「没有经任何人指出」，再冠以「口头指定的」前后矛盾。连带 `meṇḍakaseṭṭhivatthumhi` 应随黑体改作「梅那卡长者的事例」。
- 其余黑体词（`Avicāretukāmatāya` / `ettha ca codanāya pamāṇaṃ natthi` / `Piṇḍapātādīnaṃ atthāya` / `Eseva nayo` / `Saṅghaṃ vā…anāmasitvā` / `Saṅgho sampaṭicchati` / `Codeti` / `Cattāro paccaye saṅgho paribhuñjatūti deti, vaṭṭati` / `Hatthe` / `Ṭhapethāti vutte` / `udakaṃ vāretuṃ labbhati` / `Puna deti` / `Udakavasena` / `Suddhacittānaṃ` / `Kappiyakāraṃ ṭhapetuṃ na vaṭṭati` / `Lajjibhikkhunā` / `Navasasse` / `Kahāpaṇe` / `Ṭhānaṃ bhañjati`・`ṭhānaṃ` / `āgatakāraṇaṃ bhañjati` / `sikkhāpade` / `ajja ekadivasaṃ amhākaṃ`）与父层逐字相同，核对无误。

## 二、跨段一致性

- **kappiyakāraka**：§1041-2「净人」、§1046-32「净人」（与父层一致），但 §1037-5、§1037-116、§1038-39、§1039-63、§1039-142、§1041-53、§1042-20 一律作「处理合宜事务的人」→ **必改，全部统一为「净人」**。父层 138-2681-2 已定「净人（kappiyakāraka）」，§1039-142 更是近乎逐字引用父层 138-2692-137「也可以另外安排一位净人去把东西取来」。
- **gaṇa**：§1043-26 译「众人等」；父层 138-2695-2 作「小众（gaṇa）」→ 改为「小众等」。
- **引文出处体例**：§1038-2 作「（sārattha. ṭī. 2.537-539 → 显扬真义·复注 2.537-539）」，§1043-44 作「（sārattha. ṭī. 2.537-539）」。两点必改：一是体例不统一；二是「→ 显扬真义·复注 2.537-539」是加工痕迹（译文里留了工作标记），须删。
- **codeti**：§1039/§1040/§1041 作「催讨」、§1043-71 作「责备」——这是随父层语境分别取义（138-2692-120 催讨／138-2696-75 责备），**正确，不必统一**。
- **`Saññatto` 引文**：§1039-39 作「我已经交代清楚了」，父层 138-2681-9 定稿为「我已经向他交代清楚了」。虽非黑体，建议对齐。

## 三、逐句意见

### §1037 句 210-1037-5-100
- **问题**：句法（成分归属）— nissaya 明示 `taṃ` 为宾格并批注「ဒဿနတ္ထိ ဝုတ္တံ-မှာ စပ်လေ」（与下一句的 `dassanatthaṃ vuttaṃ` 相连）。现译「这段话的意思是：……」把它改成了释义引导语，§1037-101 又补出一句「这是为了显示这一点才说的」，结果同一个谓语被拆成两处。
- **建议**：「纲要义注这段话，是为了显示以下两点才说的：……」，让 §1037-5 与 §1037-101 共用一个谓语。
- **问题**：风格（文言）— 「替某某比丘置衣」中「置衣」是单音节文言词组。
- **建议**：改「替某某比丘备办衣服」。
- **问题**：指代 — `tadanusārena` 的 `taṃ`，nissaya 明确为「ထို စီဝရဉ္စ ခေါ စသော စကားကို」（指「而我们是接受衣服的」那句话）；现译「照这个道理」指代过虚。
- **建议**：「顺着那句话也就不可以指出净人」。

### §1037 句 210-1037-101-115
- **问题**：补出成分 — nissaya 把 `sabbaṃ` 具体化为「说『而我们是接受衣服的』等语、指出执事人」；现译「做这一切」读者无从知道指什么。
- **建议**：「也可以照学处里所说的方式把这些都做了（说那句话、指出执事人）」。

### §1038 句 210-1038-39-66
- **问题**：格 — `pesitassa dūtassa … vadato` nissaya 作「ဒူတာပိ= တမန်အားလည်း」（与格，「对这位使者也……」）；现译把使者处理成了纯粹的条件分句，丢了「对他」这一层。
- **建议**：「……那么对这样的使者也应当指出净人」。

### §1038 句 210-1038-135-151
- **问题**：取义 — `cīvaraṃ kiṇitvā dātuṃ pesita`，nissaya 作「ကိဏိတွာ= ဝယ်၍ ဒါတုံ= လှူခြင်းငှါ」（买了之后布施／供养）；现译「被派来买衣服给人的」，「给人」过松。
- **建议**：「他是被派来买衣服供养（比丘）的」。

### §1039 句 210-1039-20-38
- **问题**：取义 — `sādiyana`，nissaya 作「သာယာခြင်း」（甘心领受、乐著），与 `paṭiggaṇhāti`（接受）不是一回事；现译「接受不合宜财物的过失」把两词混为一词。
- **建议**：「是为了免除对不合宜财物生起领受之心才说的」。

### §1039 句 210-1039-63-126
- **问题**：取义（异读）— `rūpiyassa pakatattā`，nissaya 正读作 `sakattā`，释为「မိမိဥစ္စာ၏ အဖြစ်ကြောင့်」（因为那银钱已成了自己的所有），另出异读 `pakatattā`＝「ရူပိယ…ပြုအပ်သည်၏ အဖြစ်ကြောင့်」（因为是用银钱办成的）。现译「由于那本来就是银钱」两个释义都不沾。
- **建议**：取 nissaya 正读，作「因为那笔银钱已算是自己的了」，异读可弃。
- **问题**：格（施事）— `rūpiyapaṭiggahaṇena saṅghamajjhe nissaṭṭharūpiye viya`，nissaya 把 `rūpiyapaṭiggahaṇena` 标为施事「ရွှေငွေကို ခံသော ရဟန်းသည်」（接受银钱的那位比丘），且 `nissaṭṭha` 是已舍出，不是「须舍弃」。现译「就像因接受银钱而须在僧团中舍弃的那笔银钱那样」把施事读成了原因、把完成读成了将然。
- **建议**：「就像接受银钱的比丘在僧团中舍出的那笔银钱那样」。
- **问题**：主语漂移 — nissaya 以「ဝဒန္တော= ဆိုသော ရဟန်းသည်」点明说话者是比丘，`niddiṭṭhakappiyakārakattā` 是表因的从格（因为他是自己指定的净人）。现译「……由自己指出的那位处理合宜事务的人，如果对他说『把衣服给我……』」，前半句主语看上去是净人，读者分不清谁在说话。
- **建议**：改为「因为比丘为了接受使者送来的银钱，对那位由自己指定的净人说『把衣服给我……乃至……替我换取衣服』，那么……」。

### §1039 句 210-1039-127-141
- **问题**：指代 — `tattha`，nissaya 释为「舍银钱那位比丘所舍的银钱（那条文）」；现译「在那里」太空。
- **建议**：「因为在那条（舍出银钱的）文里说过……」。

### §1041 句 210-1041-2-10
- **问题**：同位结构 — `byāvaṭabhāvaṃ veyyāvaccakarattaṃ`，nissaya 合为一语「ကြောင့်ကြပြုတတ်သော ဝေယျာဝစ္စကရအဖြစ်」（为人办事的执事人身份）；现译拆成「成了办事的人、取得了执事人身份的」，重复且像两件事。另，nissaya 补出主语为「净人」。
- **建议**：「没有经任何人指出，只凭自己开口就取得为人办事的执事人身份的净人，就是**当面自任的净人**」。夹注巴利原词应对应黑体词，写（mukhavevaṭika），不是（kappiyakāraka）。

### §1041 句 210-1041-11-28
- **问题**：取义 — `vijjamānampi dātuṃ anicchantā`，nissaya 作「ဒါတုံ= ပေးခြင်းငှါ」（给出、交付），现译「不愿意安排」与上文 `avicāretukāmatā`（不想费事安排）重复，把两层意思压成一层。
- **建议**：「即使有净人，却不愿意把他给出来的时候」。

### §1043 句 210-1043-26-43
- **问题**：句法（误拆为并列项）— `gaṇādīsupi saṅghassatthāya sampaṭicchantesupi` nissaya 读为一个独立处格结构：「ဂဏာဒီသုပိ…သည်」是施事，「သံဃဿ အတ္ထာယ」是目的，「သန္ဓေသုပိ」是谓语，即「在小众等为僧团接受的时候」。现译「在众人等接受、以及为僧团而接受的时候」拆成两个并列情形，是误读。
- **建议**：「在小众等为僧团接受的时候，接受和受用也都一样犯突吉罗」。

### §1046 句 210-1046-2-5
- **问题**：风格（生硬）— 「就是为了用水受用」不成话。
- **建议**：「就是为了受用水」。

### §1046 句 210-1046-21-31
- **问题**：补出成分 — nissaya 在 `sassasampādanatthaṃ` 后补出「အာဏာပေဿာမိတိ」（心想「我来吩咐」），现译「这样说是指」把被解释的那句话悬空了。
- **建议**：「『为了种出庄稼（我来吩咐）』——这样说是指：……」。

### §1046 句 210-1046-85-105
- **问题**：取义 — `payoge`，nissaya 作「ပယောဂပြုဆဲ၌」（在加行、着手去做的当下）；现译「即使他只是加以指使」把加行换成了指使，而「指使」已由上句的 uṭṭhāpeti 承担。
- **建议**：「而且在要人交出谷物这件事上，即使只是在加行阶段也只犯突吉罗」。

## 四、核对后判定不改

- **210-1040-37-58「催讨七次」**：nissaya 此处作「အကြိမ်တရာ」（一百次），与 pali `sattakkhattumpi` 冲突，属缅文本讹误；译文从 pali 取「七次」正确，保留。
