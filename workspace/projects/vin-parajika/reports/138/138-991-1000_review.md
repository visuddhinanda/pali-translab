# Review — 138:991-1000（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§997-241-253、254-262、263-282 的 nissaya 行内容残缺，只剩一个字母，这三句按规则略过）
> 本层原文无黑体被解释词，父层对照无逐字可核项；跨层术语一致性见下。
> 本轮只做 nissaya 词法复核（格、数、句法角色、隐含成分）。

## 跨段一致性

- **olokento 的主语**：§991-2-19 起六处同一句式，nissaya 一律补出施事为「ဝိနည်းဓိုရ် ပုဂ္ဂိုလ်သည်」（持律／断事比丘，主格），译文一律作「查看…的人」。虽前后一致，但施事被弱化成泛指的「人」，与 §997 开头「凡是通达四种毗奈耶…的比丘」接不上 → 建议统一为「查看…的持律比丘」。
- **tika- 前缀**：§994 同一句内 `tikapariccheda` 译「三句分判」，而 `tikasaṅghādisesa / tikapācittiya / tikadukkaṭa` 译「三类僧残／三类波逸提／三类恶作」 → 同一前缀两种译法，建议统一为「三句僧残／三句波逸提／三句恶作」。
- **ācariya**：本层译「老师」（§997-115-153、154-192、193-206），父层已定稿译「阿阇梨」（213-79「我不如舍弃阿阇梨」）→ 建议统一为「阿阇梨」，或至少首现夹注。`antevāsika` 本层「近住弟子」与父层「近住的弟子」一致 ✅。
- **amhākaṃ / tumhākaṃ 的数**：§997-115-153 `amhākaṃ ācariyaṃ` 译「我的老师」（nissaya：အမှာကံ = တို့၏，复数），§997-154-192 `tumhākaṃ ācariyo` 译「您的老师」，而 §997-207-220 `amhehi saha` 译「和我们一同」→ 同一组对话里「我／您／我们」混用。建议按 nissaya 的复数统一：「去问我们的阿阇梨」↔「你们的阿阇梨对我说…」。
- **pārājikacchāyā 的属格归属**：§997-87-101 译成「看出他身上有波罗夷的影子」（影子属于犯者），§997-283-297 译成「在那位年轻比丘看来…只是波罗夷的影子」（影子现于判断者心中）→ 两处同一结构处理相反，nissaya 两处都注在判断者的心／智（见下条）。
- **sādhu suṭṭhu**：§997-154-192 / 221-240 / 263-282 三处同一句式都译「很好，很好，…」，nissaya 把 `suṭṭhu` 挂到 `karohi` 作状语 → 三处应一并改（见 §997-154-192）。
- **vūpasamessati**：§991–995 五处一律译「来平息那件诤事」，nissaya 作 ဝူပသမေဿတိ = ငြိမ်းစေလတ္တံ့（未来式）→ 可统一为「就能平息那件诤事」，保留原文的未来断定；一致，非必改。

## §993 句 138-993-2-15、138-993-16-51
- **问题**：取义（必改）— `akkhayite sarīre` 译「在没有腐坏的尸体上」、`yebhuyyena khayite sarīre` 译「在大部分已经腐坏的尸体上」。nissaya 对这组词有明确的词义界定：`အက္ခယိတေ= ခွေး မြေခွေး စသည်တို့ မခဲစားအပ်သေးသော`（尚未被狗、野干等咬食的）、`ခယိတေ= ခွေး မြေခွေးစသည်တို့ ခဲစားအပ်ပြီးသော`（已被狗、野干等咬食的）。khāyita 是「被动物啃食」，不是「腐坏」。
- **建议**：改为「在尚未被（狗、野干等）咬食的尸体上」「在大部分已被（狗、野干等）咬食的尸体上」。两句须同改，保持对偶。

## §994 句 138-994-2-23
- **问题**：跨段一致性 — 见上「tika- 前缀」一条。
- **建议**：`tikasaṅghādisesaṃ vā … aññataraṃ vā āpattiṃ` 四个 ဝါ 并列、全是 `ကို`（宾格），译文「三类僧残、三类波逸提、三类恶作，或者其他某一种罪」的并列关系正确 ✅，只需统一前缀译法。

## §995 句 138-995-2-34
- **问题**：取义 + 词法（必改）— `paṭilātaṃ ukkhipati` 译「把已经交还的东西拿起来」，把 `paṭilāta` 解作 paṭi-lāta（交还之物）。nissaya 作 `ပဋိလာတံ = အောက်သို့ လျှောကျသောမီးစကို`（滑落到下面的火把／燃木，宾格）、`ဥဒ္ဓိပတိ(ukkhipati)= မြှောက်တင်အံ့ ဝါ ထိုးပေးအံ့`（举起／拨上去）。所举例句讲的是把落下的火把重新拨起，与「交还」无关。
- **建议**：改为「把落下来的火把拨起来，就犯恶作罪」。另记一条原文疑问（不要改）：nissaya 读出的「火把」义指向 `ālāta`，此处 `paṭilātaṃ` 疑为 `patitaṃ ālātaṃ` 一类读法的讹并，留待原文核对。

## §996 句 138-996-2-49
- **问题**：句法角色（必改）— 译文「比丘，对于不领受的人…都不犯」把 `bhikkhu` 当成呼格插入语。nissaya 把它读作整串属格的中心语：`ဘိက္ခု= ရဟန်း။ အသာဒယန္တဿ= မသာယာသော ရဟန်း၏။ အထေယျစိတ္တဿ= ထေယျစိတ် မရှိသော ရဟန်း၏…`，即「不乐受的比丘无犯、无盗心的比丘无犯…」，每条都是「比丘＋属格修饰语」。
- **建议**：改为「不乐受的比丘、没有偷盗心的比丘、…都不犯」，去掉句首的呼格「比丘，」。
- **问题**：取义 — `asādiyantassa` 译「不领受」，nissaya 作 `မသာယာသော`（不乐、不耽享，即不随顺其事）；`anullapanādhippāyassa` 译「没有意图自我宣称」，nissaya 作 `ဝါကြွားခြင်း၌ ဖြစ်သော အလိုမရှိသော`（不以自夸、炫耀为意图）。
- **建议**：分别改为「不乐受的比丘」「没有自夸意图的比丘」。其余各条（na maraṇādhippāya / na mocanādhippāya / asañcicca / assatiyā / ajānanta）与 nissaya 的属格、具格补出（`ကရောန္တဿ`「作此事者」）吻合 ✅。

## §997 句 138-997-87-101
- **问题**：属格归属（必改）— 译「如果看出他身上有波罗夷的影子」。nissaya 作 `အဿ = ပုဂ္ဂိုလ်၏（စိတ်၌）`，即影子是在（断事）人的心里现起的；平行句 §997-283-297 的 nissaya 更明确：`ဒဟရဿာပိ = ပညာရှိ ရဟန်းငယ်၏（ဉာဏ်၌）လည်း…ပါရာဇိကစ္ဆာယာဝ…ဥပဋ္ဌာတိ`。
- **建议**：改为「如果在他（断事比丘）看来隐约现出波罗夷的影子」，与 §997-283-297 的处理保持一致。

## §997 句 138-997-104-109
- **问题**：取义 — `oḷāriko` 译「粗显的」。nissaya 作 `သြဠာရိကော= ထင်ရှား၏` 并加注 `[သိလွယ်၏ = ဟူလို]`（明显，意即容易判别），与下句 `sukhumā`（微细、难知）正好成对。「粗显」在汉语里偏向体性粗重，丢了「易判别」这一层，而这正是上下文要的意思。
- **建议**：改为「这两种是明显的、容易判别的」。

## §997 句 138-997-110-114
- **问题**：取义（必改）— `cittalahukā` 译「全凭心念的细微转动而定」。nissaya 释 `စိတ္တလဟုကာ= လျင်မြန်သော စိတ်ရှိကုန်၏`，并在 `သုခုမာ` 的注里说明理由：心本身难知、`သီဃပရိဝတ္တိတာယ`（因转变迅速）。lahu 是「快」，不是「细」；「细」已由 sukhumā 承担，译文把两个词合成一个意思，丢了「迅速」。
- **建议**：改为「而违犯不与取和违犯杀人这两种却很微细，心念转变迅速（因此难以判定）」。

## §997 句 138-997-115-153
- **问题**：格（必改）— `sukhumeneva āpajjati, sukhumena rakkhati` 译「只在微细处犯，也只在微细处守住」，按处格处理。nissaya 作 `သုခုမေနေဝ = သိမ်မွေ့သော စိတ်ဖြင့်သာလျှင်`（唯以微细的心，具格），`တေ`（宾格复数，指上文两种违犯）是 āpajjati 的宾语。
- **建议**：改为「只因微细的心念才犯这两种，也只凭微细的心念才守得住」。
- **问题**：数（必改）— `amhākaṃ ācariyaṃ pucchā` 译「去问我的老师」。nissaya `အမှာကံ = တို့၏`（复数属格）。
- **建议**：改为「去问我们的阿阇梨」，并与 §997-154-192「你们的阿阇梨」对应。
- **问题**：属格归属 — `sacassa ācariyo dharati` 译「如果这位比丘自己的老师还在世」，「这位比丘」在上下文里易被读成前来发问的犯戒比丘。nissaya：`အဿ= ထို ဝိနည်းဓိုရ်ပုဂ္ဂိုလ်၏`（断事者的）。
- **建议**：明确为「如果这位断事比丘自己的阿阇梨还在世」。
- 另：`pucchiyamāno` nissaya 校作 `ပုစ္ဆိယမာနေန`（具格，与 tena 同指断事者，「被问到时」），译文「当有人…来请教、说自己心里的疑悔时，不要直接说『有罪』」的施受关系与之相符 ✅。

## §997 句 138-997-154-192
- **问题**：句法角色（必改）— 「很好，很好，老师怎么说，你就怎么做」把 `sādhu suṭṭhu` 当成叠用的感叹。nissaya 把两词分开：`သာဓု= ပြီ`（好）独立，而 `သုဋ္ဌ = ကောင်းစွာ`＋`ကရောဟိ= ပြုပေတော့`，suṭṭhu 是 karohi 的状语。
- **建议**：改为「好，阿阇梨怎么说，你就好好照着做」。§997-221-240、§997-263-282 同句式一并改为「好，照他的话好好去做」。
- **问题**：取义 — `nayato` 译「推论」，nissaya 作 `နယတော = မဟာပဒေသနည်းအားဖြင့်`（依大指示／四大教法之理）；`satekiccho` 译「还有救」，nissaya 作 `ကုစားခြင်းနှင့်တကွ ဖြစ်၏ ဝါ ကုစားကောင်းသေး၏`（尚可救治、还可补救）。
- **建议**：`nayato` 译「按照（大指示的）推断之理」；`satekiccha` 改为「尚可补救」一类较稳的术语说法（口语的「还有救」与同段「不可推翻的判决」语体不合），三处一并统一。

## §997 句 138-997-193-206
- **问题**：属格归属 — `Atha panassa ācariyo natthi` 译「如果他已经没有老师了」，「他」指向不明。nissaya：`အဿ = ထိုဝိနည်း[ဓို]ရ်ပုဂ္ဂိုလ်၏`（断事者的）。
- **建议**：改为「如果这位断事比丘已经没有阿阇梨了」。后半 `saddhiṃ uggahitatthero`（`အတူတကွ စာသင်ဖက် ထေရ်`，一同受学的长老）与 `tassa santikaṃ pesetabbo` 的派遣关系均与 nissaya 相符 ✅。

## §997 句 138-997-298-309
- **问题**：取义（必改）— `dullabho hi buddhuppādo` 译「佛陀出世是难得的」。nissaya 明文指定读法并明文禁止译成「佛出世（这件事）」：`ဗုဒ္ဓပ္ပါဒေါ= ဗုဒ္ဓုပ္ပါဒ နဝမ ခဏကို ဝါ မြတ်စွာဘုရား ပွင့်ရာအခါကို`，并注 `[「ဘုရားပွင့်တော်မူခြင်းကို」ဟု မပေးနှင့်]`——所指是「值遇佛出世的时节」（九难得之一），宾格。
- **建议**：改为「值遇佛出世的时节是难得的，而出家和受具足戒比这更难得」。另 nissaya 把 `pabbajjā / upasampadā` 释为身分（`ရှင့်အဖြစ် / ရဟန်းအဖြစ်`），可酌补为「得沙弥身分与得比丘身分（受具足戒）」。

## §997 句 138-997-314-330
- **问题**：格（必改）— `divāvihāraṃ nisīditvā` 译「坐下来作白天的静修」，把它当成所作之事。nissaya 作 `ဒိဝါဝိဟာရံ = နေ့နေရာ၌`（在白天的住处，处所），`နိသီဒိတွာ`（坐下）。
- **建议**：改为「打扫出一处安静的地方，在白天的住处坐下」。
- **问题**：补出成分 — `sīlāni sodhetvā` 译「使自己的戒清净」。nissaya 补出范围：`ကြွင်းသောသီလတို့ကို သောဓေတွာ`，并注明是把引起疑悔的那条戒放在一边不作意，清理「其余的」诸戒。
- **建议**：改为「把其余的诸戒清理清净」。`dvattiṃsākāraṃ tāva manasi karohi` 译「先思惟三十二身分」与 nissaya（`တာဝ မနသိ ကရောဟိ`）一致 ✅。

## §997 句 138-997-354-360
- **问题**：补出成分 — `divasātikkame upaṭṭhānaṃ āgato` 译「等一天过去，他来问候的时候」。nissaya 作 `ဒိဝသာတိက္ကမေ = နေ့ကိုလွန်ရာအခါ၌（ညချမ်းအခါ၌）`（白天过去，即傍晚）、`ဥပဋ္ဌာနံ = ဆည်းကပ်ခြင်းငှာ ဝါ ဆည်းကပ်ရာအရပ်သို့`（为侍奉／到侍奉处）。
- **建议**：改为「到了傍晚，他来侍奉的时候」。

## §998 句 138-998-2-26、138-998-40-50、138-998-51-75
- nissaya 词法逐项核对无误：`na ghaṭayati`（业处接不上心相续）、`patodābhitunnaṃ viya`（如被刺棒刺）、`vippaṭisāragginā ḍayhati`（被后悔之火所烧）、`tattapāsāṇe nisinno viya`、`raho nāma … pakubbato`（属格，对造恶者而言无隐秘处）、`attanā jānāti`（nissaya 注明此具格作主格用，「自己知道」）、`tvaṃyeva … tava sotthiṃ pariyesāhi` 均与 nissaya 的格助词相符 ✅，不列问题。
