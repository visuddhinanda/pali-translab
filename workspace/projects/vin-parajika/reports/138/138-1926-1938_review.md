# Review — 138:1926-1938（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层对照（book 213 定稿译文）✅
> 本次只做 nissaya 词法复核 + 被解释词与父层逐字核对。无 nissaya 的句（138-1926）略过。

## 跨段一致性

- **attupanāyika（被解释词）**：§1928 黑体译「**归到自己身上**」，而 §1928-49-69／§1930-2-9／§1930-33-66 均作「归于自己」，父层 213-557 定稿也是「**归于自己**」 → **必须统一为「归于自己」**（详见下文 §1928 句 138-1928-9-23）。
- **byākaroti / byākaraṇa**：§1933-2-14 译「宣称」，与黑体术语 samudācarati 的定译「宣称」撞车；§1934-26-56 同族词译「所说的话」，§1935-61-79 译「应答」 → 建议 §1933-2-14 改「说自己证得了上人法」，把「宣称」留给 samudācarati。
- **sodheti**：§1933-15-21「查核清楚」、§1934-2-7「查核」、§1934-8-25「经不起查核」，但 §1933-269-295 同一词译成「答得无可挑剔」 → 建议统一到「查核／交代清楚」一系。
- **arūpa**：§1932-49-56、§1933-49-99 均译「非色法」，nissaya 两处都作 `အရူပေ= နာမ်တရား၌`（名法） → 建议统一改「名法」。
- **ettaka / ettāvatā 的所指**：§1933-2-14「仅凭这一点」、§1933-269-295「即使到了这个地步」、§1935-2-8「即使到了这个地步」——nissaya 分别补出所指为「这么多的**说辞**」`ဧတ္တာဝတာဝ= ဤမျှ…ပြောဆိုခြင်းဖြင့်သာလျှင်`、「这么多的**回答**」`ဤမျှ…အဖြေစကားဖြင့်လည်း`、「这样的**相合**」`ဤမျှ…ညီညွတ်ခြင်းဖြင့်လည်း` → 三处宜各自点明，否则读者看不出每处指什么。
- **人物指称**：nissaya 一律以「比丘」指代（`ဧကစ္စဿ= အချို့သော ရဟန်း၏`、`အယံ= ဤရဟန်းသည်`），译文则时作「这个人」「有些人」（§1927-10-24、§1935-11-26、§1937-10-29） → 建议统一作「这位／有些比丘」。
- **paṭhamamagga 与 sotāpattimagga**：nissaya 明说 `ပဌမ မဂ္ဂဝဇ္ဈာ= သောတာပတ္တိမဂ်သည် ပယ်အပ်ကုန်သော`（初道即须陀洹道），而译文 §1932-122-129、§1933-182-223 作「初道／第二道」，§1933-224-268 作「须陀洹道／斯陀含道」 → 建议首次出现处点明同指；另 sotāpattimagga 有夹注巴利而 sakadāgāmimagga 无，宜照 style.md 一致处理。
- **引自父层的 padabhājana 文句**：§1929-50-63／64-74 译「凡是智，就是见」「凡是见，就是智」，父层 213-558 定稿为「凡是智，**那**就是见」「凡是见，**那**就是智」 → 建议补回「那」，与父层逐字一致。
- **chambhitatta**：§1935-27-41／42-60／61-79 统一译「惊慌」，但 nissaya 作 `ဆမ္ဘိတတ္တံ= ကိုယ်တုန်လှုပ်သည်၏ အဖြစ်`（身体战栗） → 建议统一改「身体发抖／战栗」，与 bhaya（恐惧）、lomahaṃsa（毛发竖立）形成身心三层。

## §1927 句 138-1927-2-9

- **问题**：补出成分 — nissaya 把 `na abhijānaṃ` 读作伴随式并补出主句动词：`န အဘိဇာနံ= မသိပါဘဲလျက်။ (သမုဒါစရေယျ= ပြောပြအံ့။)`，即「在并不知道的情况下（而宣称）」；译文「就是没有证知」作名词性等义句，丢了让步语气与补出的 samudācareyya。
- **建议**：改「**并未证知**，就是在并不知道的情况下（宣称）」。

## §1927 句 138-1927-10-24

- **问题**：格与句法 — nissaya 主读为 `ယံ= အကြင် ဥတ္တရိမနုဿဓမ္မကို`（yaṃ 为宾格关系代词，指上人法），并明确反对 `ayaṃ` 的读法（`အယံဟု မရှိသင့်`），主语「比丘」是省略的；译文「这个人是……宣称的」把 ayaṃ 当人作主语。
- **建议**：依 nissaya 作「由于凡是他在并未证知的情况下所宣称的（那个上人法），在他自己的相续中并没有生起……」。后半「他所宣称的那法」与 nissaya `သော= ထို ဥတ္တရိမနုဿဓမ္မကို` 一致，可保留。

## §1927 句 138-1927-25-45

- **问题**：漏译属格 — nissaya `အဿ= ထို အနဘိဇာနံဟူသောပုဒ်၏`，assa 指「**anabhijānaṃ 这个词**的」分别解说；译文作「在本文的分别解说里」，既漏了 assa，又添了「本文」。
- **建议**：改「所以在对这个词的分别解说里……」。

## §1928 句 138-1928-9-23

- **问题**：被解释词与父层不一致（必改） — 黑体 `Attupanāyikan` 父层 213-557 定稿译「**归于自己**」，此处译「**归到自己身上**」，对应关系断了；且本层 §1930-2-9 自己也用「归于自己」，层内即不自洽。
- **建议**：黑体改「**归于自己**」，释义句内的 `attani taṃ upaneti` 仍可作「把那法归到自己身上」。
- **问题**：格与句法 — 句末 `taṃ attupanāyikaṃ` nissaya 标明保留第二格（`ဝိဘတျန္တခံသည်`，`တံ အတ္တုပနာယိကံ= ထိုမိမိ၌ ကပ်ဆောင်၍`），是下句 samudācareyya 的宾语+状语；译文「那样的法就是归于自己的法」改成判断句，与下句「这样做了以后宣称」的连接断开。
- **建议**：改「……所以叫做归于自己的；（于是）把那归于自己的（上人法）——」，让下句的 sambandha 接得上。

## §1928 句 138-1928-70-83 / 138-1928-84-97

- **问题**：词义 — nissaya 两处都把 sandissati 释为「显现、明明白白地在」（`သန္ဒိဿန္တိ= ထင်ရှားကုန်၏`、`သန္ဒိဿာမိ= ၏`），不是被动的「被看到」；父层 213-560 定稿作「看得出」。
- **建议**：改「这些法在我身上明明白白地显现」「我在这些法之中明明白白地显现」，或直接沿用父层的「看得出」，三处取一。

## §1929 句 138-1929-18-23

- **问题**：释义结构 — nissaya 把 `ariyaṃ` 的释词定为 visuddhaṃ、uttamaṃ，整句是「（这）是清净的、最上的智见」（`အရိယံ ဝိသုဒ္ဓံ= စင်ကြယ်သော။ ဥတ္တမံ= မြတ်သော။ ဉာဏဒဿနံ= ဉာဏ်အမြင်တည်း`）；译文「这智见是圣的、清净的、最上的」把被释词「圣的」混进释词列表，成了用 ariya 释 ariya 的循环。
- **建议**：改「（这）是清净的、最上的智见，所以叫做**圣者的智见**」。

## §1929 句 138-1929-24-42

- **问题**：修饰语归属错误（必改） — nissaya 把 `ဈာနာဒိဘေဒေ` 与 `ဧတ္ထ ဥတ္တရိမနုဿဓမ္မေ= ၌` 合为同一处格短语，归在**第一**（七格多财释）解里；第二解只有属格 `အဿ= ထိုဥတ္တရိမနုဿဓမ္မ၏`。译文反过来：第一解漏译「禅那等种种」，却把它挪到第二解「就禅那等各种上人法而言」。
- **建议**：第一解补全「在禅那等种种上人法之中，有充分的、能够摧毁烦恼的圣者的智见」；第二解只作「或者说，它（这上人法）有充分的圣者的智见」。
- **问题**：句法 — 句末 `taṃ alamariyañāṇadassanaṃ uttarimanussadhammaṃ` nissaya 补出 `(သမုဒါစရေယျ= အံ့)`，是宾格承 samudācareyya；译文作判断句「那样的上人法就是……」，与 §1928-9-23 同类错误。
- **建议**：改「（于是宣称）那具有足以摧毁烦恼的圣者智见的上人法——词义的连接关系应当这样理解」。另「“足以”就是充分、胜任」一句，nissaya 把 alaṃ=pariyattaṃ=kilesaviddhaṃsanasamatthaṃ 三者全作修饰 ariyañāṇadassanaṃ 的定语，不必拆成独立释义句后又在下文重复「足以摧毁烦恼」。

## §1929 句 138-1929-43-49

- **问题**：指代 — nissaya `သော= ထို ဥတ္တရိမနုဿဓမ္မကို`，`so` 指**那个上人法**；译文「它之所以被称为」前句主语是「智见」，指代会被读成智见自称智见。
- **建议**：改「那上人法之所以被称为『具有足以成为圣者的智见的』，是由于某种智见」。

## §1930 句 138-1930-33-66

- **问题**：漏译属格 — nissaya `အဿ= ထို ဣတိဇာနာမိ ဣတိပဿာမိပုဒ်၏`，指「**iti jānāmi iti passāmi 这一句**的」分别解说；译文作「在本文的分别解说里」，同 §1927-25-45。
- **建议**：改「而在对这一句的分别解说里……」。

## §1931 句 138-1931-2-10

- **问题**：术语 — āpatti 父层定稿作「罪」（213-564「**犯了罪**」、「犯了波罗夷罪」）；译文「承认犯罪」在现代汉语里是刑事用语，且与父层术语不接。
- **建议**：改「这是显示承认所犯之罪的时间」。

## §1932 句 138-1932-49-56

- **问题**：词义 — nissaya `အရူပေ= နာမ်တရား၌`，arūpa 在此释为**名法**，与下文 `ရူပါရူပ…= ရုပ်တရား, နာမ်တရား…` 一致；译文「非色法」是构词直译。
- **建议**：改「在色法上……还是在名法上」，并与 §1933-49-99 统一。

## §1933 句 138-1933-269-295

- **问题**：词义（必改） — nissaya 对 uggahaparipucchākusalā 的释义是 `သင်ယူအပ်သော ပါဠိ, အဖန်ဖန် မေးမြန်းအပ်သော အဋ္ဌကထာ၌ ကျွမ်းကျင်ကုန်သော`，即「精通所学的巴利圣典、与反复请问得来的义注」；译文「善于读诵与问难」把两者都读成了修学行为，丢了「圣典／义注」这层所指。
- **建议**：改「因为博学、精通所学圣典与所问义注的比丘，是有能力把这六个方面都交代清楚的」。
- **问题**：用词一致 — `sodhetuṃ sakkonti` 译「答得无可挑剔」，与前文 sodheti 的「查核清楚」脱节（见跨段一致性）。

## §1934 句 138-1934-67-92

- **问题**：句法（必改） — nissaya 读作「世尊为弟子们**善施设了**通向涅槃的道」（`နိဗ္ဗာနဂါမိနီ ပဋိပဒါ= ကို။ သုပညတ္တာ= ကောင်းစွာ ပညတ်တော်မူအပ်ပါ ပေပြီ`），随后才是 `နိဗ္ဗာနဉ္စ…ပဋိပဒါစ…သံသန္ဒတိ`；译文把 supaññattā 降成定语，又给「道」另加一个「也是相合一致的」谓语，saṃsandati 被用了两次，成了冗余。
- **建议**：改「同样，世尊为弟子们善加施设了那条通向涅槃的道；涅槃与道相合一致」。

## §1935 句 138-1935-11-26

- **问题**：所指 — nissaya `ဧကစ္စဿ= အချို့သော ရဟန်း၏`，主体是「有些**比丘**」，不是泛指的人。
- **建议**：改「因为有些比丘虽然还是凡夫……」。
- **问题**：增译 — 「以作考验」原文与 nissaya 均无（nissaya 只到 `ဥတ္တာသေတဗ္ဗော= ထိတ်လန့်စေထိုက်၏`）。
- **建议**：删去，意图留给下文自然显出；需要说明时写进脚注。

## §1936 句 138-1936-30-39

- **问题**：格与句法（必改） — nissaya 把 apakato / abhibhūto / pārājito 三词并列为同一串被动过去分词，施事都是那恶欲：`တာယဣစ္ဆာယ= ထိုအလိုဆိုးသည်။ အပကတော= သမ္မာအာဇီဝမှ ကင်းသူကို ပြုအပ်သည်။ အဘိဘူတော= လွှမ်းမိုးအပ်သည်။ ပါရာဇိတော= ရှုံးစေအပ်သည်`（并在 §1937 方框注里说明「ပရာဇိတော」是「被压得落到波罗夷」的加强说法）。译文把第三个词转成「成了犯波罗夷的人」，与前两项的并列关系断开；apakato 的「使之偏离正命」这层释义也丢了。
- **建议**：改「**被欲望驱使**，是指被那种恶欲弄得偏离正命、被它征服、被它彻底打垮」。黑体词保持与父层 213-564「被欲望驱使」一致。

## §1937 句 138-1937-10-29

- **问题**：所指 — nissaya `အယံ= ဤရဟန်းသည်`，作「这位比丘」；又对 bhikkhubhāva 注明 `ဝါ= ရဟန်းယောင်ဆောင်၍ နေခြင်းသည်`、「不是真比丘的身份，而是他自称的比丘身份」，译文「只要还保持比丘的身份」会让读者以为他仍是比丘。
- **建议**：改「因为这位比丘已经犯了波罗夷，所以只要还以比丘的身份住着，就不可能证得禅那等法；对他来说，这样的比丘身份既是生天的障碍，也是道的障碍」。
