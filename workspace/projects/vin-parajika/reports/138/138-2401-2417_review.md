# Review — 138:2401-2417（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 被解释词与父层（book 213）核对

逐条机械比对全部黑体引词，**全部与父层定稿译文逐字相同，无不一致**：

- `Tena samayena buddho bhagavā` → 那时候，佛陀世尊 ✅
- `atha kho devadatto` → 当时，提婆达多 ✅
- `Sādhu bhante` → 尊者，希望 ✅
- `Bhikkhū yāvajīvaṃ āraññikā assū` → 比丘们尽形寿都住在林野 ✅
- `Yo gāmantaṃ osareyya vajjaṃ naṃ phuseyyā` → 谁到村落附近去，谁就犯过失 ✅
- `Janaṃ saññāpessāmā` → 说服民众 ✅
- `alaṃ devadattā` → 够了，提婆达多；`yo icchati āraññiko hotū` → 愿意的就住在林野 ✅
- `tikoṭiparisuddhaṃ` → 三方面清净；`adiṭṭhaṃ / asutaṃ / aparisaṅkitaṃ` → 没有看见／没有听说／没有怀疑 ✅
- §2410 非黑体引文 `yo icchati gāmante viharatū` → 愿意的就住在村落附近，亦与父层一致 ✅

## 跨段一致性

- **中心语「鱼肉／肉」被略去**（跨 §2412–§2414，recurring）：nissaya 一律把指示代词的中心语点明为「ငါးအမဲ（鱼肉）／အသား（肉）」——`idaṃ`＝「这被怀疑的鱼肉」、`etaṃ`＝「这因见而疑的鱼肉」、`yaṃ … taṃ`＝「凡这样不被怀疑的鱼肉」、§2414-102 `katepi`＝「〔为此而〕做的肉上」。译文多处作「这样的东西」「而做的」，§2415 却补出了「做了肉」。 → 建议统一补出中心语：「这样的鱼肉不可以接受」「像这样没有怀疑的鱼肉就可以接受」「为死者做追荐、或为吉庆等事而做的肉，也照这个方法」。
- 其余术语与语体前后一致：araññe=林野、gāmanta=村落附近、dukkhassantaṃ kātuṃ=使苦终结、padaparama=只能到文句为止、saddhivihārika=同住弟子、samacchamaṃsaṃ piṇḍapātaṃ=带鱼带肉的食物、rājayuttādi=国王的臣属等人、dhutaṅga=头陀支，均无漂移；通篇为现代书面汉语，未见文言句式。

## §2402 句 138-2402-56-61

- **问题**：焦点词 — `tattheva` 的 `eva` 未译出。nissaya `တတ္ထေဝ= သံဃဘေဒက္ခန္ဓက၌ပင်`（就在破僧犍度里）。译文「也会在那里讲到」把 `eva` 化成了「也」，强调点移位。
- **建议**：「虽然这一段正是在那里（破僧犍度）才讲到」。

## §2402 句 138-2402-62-72

- **问题**：指代范围 — `idhāpi` 与 `ettha` 被合并成同一个「这里」。nissaya 分指两处：`ဣဓာပိ= ဤသိက္ခာပုဒ်၌လည်း`（在本学处里也）、`ဧတ္ထ= ဤပဉ္စဝတ္ထုယာစနကထာ၌`（在这段请求五事的话里）。
- **建议**：「但因为本学处里也出现了，所以这段请求五事的话里该说的部分，就先说了再往下走。」

## §2403 句 138-2403-7-25

- **问题**：语气／补出成分 — `hontu` / `vasantu` 的祈使语气未落到译文。nissaya `ဟောန္တု= ဖြစ်ပါစေကုန်`、`ဝသန္တု= နေပါစေကုန်`（愿／让他们…）。译文「所有比丘在活着的期间都做住林野的人，只住在林野里」读成陈述句，丢了提婆达多「请令…」的祈请语气。
- **建议**：「……让所有比丘在活着的期间都做住林野的人，只住在林野里。」

## §2403 句 138-2403-26-59

- **问题**（必改）：释义窄化 — `nivāsatthāya` 译作「为了居住」。nissaya `နိဝါသတ္တာယ= အမြဲနေခြင်းငှာ`（为了常住／定居），并明确加注：`ဤနိဝါသတ္ထာယဖြင့် ဆွမ်းခံသွားခြင်းစသည်ကို မဆိုလိုကြောင်းပြသည်`（指出这不包括为乞食往来等）。译作「为了居住」会让读者以为短暂进村也算，正好是 nissaya 要排除的那层意思。
- **建议**：「为了定居而到村落附近去」（或「为了长住」）。
- **附带**：`āpattiyā naṃ bhagavā kāretu`，nissaya 作具格 `အာပတ္တိယာ= ဖြင့်` + `ကာရေတု= ပြုစေတော်မူပါ`，直意为「愿世尊依罪治他」；现译「让世尊给他结罪」可通，若求贴合 nissaya 可作「让世尊按罪处理他」。

## §2404 句 138-2404-2-19

- **问题**：词形 — `appicchatādibhāvaṃ` 的 `bhāva` 未译出。nissaya `အပ္ပိစ္ဆာဒိဘာဝံ= အပ္ပိစ္ဆ အစရှိသည်တို့၏ အဖြစ်ကို`（少欲等的「状态」），属格 `အမှာကံ= တို့၏`。
- **建议**：「让民众知道我们少欲等等的情况（／我们有少欲等品德）」，不作「我们是少欲等等的人」。

## §2406 句 138-2406-2-11

- **问题**：中心语 — nissaya `ပဋိရူပံ= လျောက်ပတ်သော အကျင့်ကို`（合适的「行持」），译文「知道什么对自己合适」把中心语抹掉了。
- **建议**：「良家子应当了解世尊的意图，知道对自己合适的行持。」

## §2410 句 138-2410-30-36

- **问题**：指称过虚 — nissaya 把三个成分都点实了：`ဣမိနာ ပုဂ္ဂလေန= ဤရွာ၌နေနိုင်သော ပုဂ္ဂိုလ်တစ်မျိုးတည်းဖြင့်`（凭这一种能住村落的人）、`အညေသမ္ပိ= အခြား ပုဂ္ဂိုလ် ၃ မျိုးတို့အားလည်း`（也给其他三种人）、`ဒွါရံ= ရွာကျောင်း၌ နေနိုင်ခြင်း၏ အကြောင်းကို`（住村落附近寺院的门）。现译「因为有这种人，也就给其他人开了方便之门」三处都虚化了。
- **建议**：「而且凭这一种人，也就给其他三种人开了住在村落附近的门。」

## §2411 句 138-2411-86-91

- **问题**：补出成分 — `cattāro māse`，nissaya `စတ္တာရော မာသေ= မိုး ၄ လ တို့ပတ်လုံး`（雨季四个月整），与前句「八个月」构成雨季／非雨季之分。译文「那四个月」未点明是雨季，读者需自行反推。
- **建议**：「至于雨季那四个月里以树下为住处，那是被禁止的。」

## §2412 句 138-2412-70-94

- **问题**：格／隐含成分 — `nesaṃ … paviṭṭhānaṃ` 是受益与格。nissaya `နေသံ= ထိုရဟန်းတို့ဖို့`（给那些比丘），所修饰的分词 `ပဝိဋ္ဌာနံ` 也与之同格。译文把它处理成时间从句「他们进那个村子乞食的时候，那些人拿来了……」，「给比丘们」这层关系丢了。
- **建议**：「第二天，那些人给进那个村子乞食的比丘们端来带鱼带肉的食物。」

## §2412 句 138-2412-95-116

- **问题**：语义强度 — `kataṃ nu kho`，nissaya `ကတံ နုခေါ= တမင်တကာပြုအပ်လေသလော`（是特意做的吗）。译文「这是不是为了比丘们做的呢」少了「特意／专为」这一层，而全段判准正在于是否 `uddissa`（指定）。
- **建议**：「这是不是特意为比丘们做的呢？」（§2413-24-47 的同句同改）
- **附带**：`tena diṭṭhena` 是单数具格（nissaya `ထိုဒိဋ္ဌကြောင့်`，并注明即前一天所见那一事），译文「所看见的这些」宜作「因为所看见的那件事」。

## §2413 句 138-2413-24-47

- **问题**：省略成分未补 — 巴利此句以 `pe` 省去「（施主）送来带鱼带肉的食物」，nissaya 同样用 `ပေ` 回指 §2412。译文直接从「进村乞食的时候」跳到「怀疑」，中间缺一环，读来突兀。
- **建议**：照 §2412 补出：「第二天，那些人给进那个村子乞食的比丘们端来〔带鱼带肉的食物〕，他们就怀疑『……』」。

## §2413 句 138-2413-2-6（并 §2414 句 138-2414-2-10）

- **问题**：强调未译 — `na heva`，nissaya 两处都作 `အမှန်ပင် မမြင်ကုန်` / `အမှန်ပင်မကြားကုန်`（确实没有见／确实没有听）。
- **建议**：「比丘们确实没有看见」「比丘们确实既没有看见，也没有听说」。

## §2414 句 138-2414-54-101

- **问题**：术语可读性 — `pavattamaṃsa`，nissaya 复注释为「为出售而杀、买主未到前就已有的肉（`ဝိက္ကယိကမံသံ`）」。现译「本来就有的肉」方向正确但偏虚。
- **建议**：「也可能是得到了本来就已有的、如法的肉（pavattamaṃsa，即市上现成出售的肉），才为比丘们备办的。」

## §2416 句 138-2416-83-90

- **问题**：情态偏移 — `rūpaṃ sallakkhentenapi`，nissaya `သလ္လက္ခေန္တေနပိ= မှတ်သားနိုင်ပါသော်လည်း`（虽然**能够**辨认），讲的是能力让步，不是已完成的动作。译文「即使已经仔细辨认过外形」把它说成了已然事实。
- **建议**：「所以怕犯罪的比丘，即使自己能辨认出〔肉的〕外形，也还是要问过以后再接受肉。」

## nissaya 疑似讹字（译文无需改动，仅记录）

- §2412 句 138-2412-41-54：`အသုတံ= အကြားအပ်သော သားငါးတည်း` 当为 `မကြားအပ်သော`（未听闻的）。译文「没有听说」依巴利 `asutaṃ` 为正。
- §2415 句 138-2415-22-32：nissaya 作 `ယေ … နဇာနန္တိ`，与巴利 `Ye jānanti` 相反，且同条下文把 `itaresaṃ` 释为「其他不知道的比丘们」，自相矛盾——`န` 应为衍字。译文「知道的人不可以接受，其他人可以接受」依巴利为正。
