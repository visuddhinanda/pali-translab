# Review — 138:959-976（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 本次只做 nissaya 词法复核。无 nissaya 的句子（138-965-92 以下、138-970-74～90、138-971、138-973、138-974 多数句）未出意见。

## 被解释词与父层对照

- §960 **“任何”的意思是：无论是谁，无论什么模样** — 与父层 213-73「45. **“任何”**的意思是：无论是谁，无论什么模样」逐字相同 ✅
- 本 chunk 其余黑体（catubbidho vinayo / āhaccapadaṃ / raso / ācariyavaṃso / adhippāyo / suttaṃ / suttānulomaṃ / ācariyavādo / attanomati）均不在父层 73–79 的范围内，由本层自定译法，无须对齐。

## 跨段一致性

- **sakavādī / paravādī**：§970-26-39 译「自方的论者／对方的论者」，而 §970-66-73、§972-2-10、§973-2-10、§974-2-9 的 `ayaṃ` / `paro` 一律译「这一方／另一方」。nissaya 在两处都点明是同一组人（`သကဝါဒီ=မိမိဂိုဏ်း၏ အယူဝါဒရှိသူ`、`အယံ=ဤ သကဝါဒီပုဂ္ဂိုလ်`、`ပရော=ပရဝါဒီပုဂ္ဂိုလ်`）。→ 建议全篇统一为「本部的论者／他部的论者」（或统一都用「这一方／另一方」，但不能混用），依据：nissaya 把 ayaṃ/paro 直接回指 sakavādī/paravādī，且释为「本部派／他部派的持说者」，不是泛指的辩论双方。
- **gārayha**：§970-91-97、§972-27-50 均译「应该被否定」；nissaya 两处都作 `ကဲ့ရဲ့ထိုက်သော`（应受呵责）。→ 统一改为「应受呵责的」，依据：nissaya 的词义是「可呵责」，不是「被判定为不成立」。
- **khepa / garahā**：§970-40-50 nissaya 分得很清——`ခေမံ=အယူဝါဒကို ပစ်ပယ်ခြင်း`（贬斥对方的**主张**）、`ဂရဟံ=ပုဂ္ဂိုလ်ကို ကဲ့ရဲ့ခြင်း`（责难对方**其人**）。译文「互相责难或贬斥」把两者糊成一团。→ 建议统一译为「互相贬斥对方的主张、责难对方其人」，并同步改 §970-74-84、§971-11-22 两处同句式（那两句无 nissaya，但与本句是同一套话的重复，必须跟着改）。
- **theravāda vs attanomati**：§968-2-13 把 `theravādo` 译作「各位长老**自己的**说法」，与同句结论「也都叫做‘自己的见解’」撞词，读者分不清被定义项与定义项。nissaya 作 `ထေရဝါဒေါ … ဝါ=ဆရာတို့၏ ပြောဆိုကြောင်း စကား`。→ 建议译「长老们的说法（theravāda）」，去掉「自己的」。
- **dhammasaṅgāhaka**：§962「从前结集法藏的那些人」与 §966「结集法藏的五百位阿罗汉」译法一致 ✅
- **otarati / sameti / gahetabba**：全篇一律「放得进去／相符／可以采用」，一致 ✅
- **ācariyavāda**：全篇一律「老师们的说法」，一致 ✅

## §960 句 138-960-2-19

- **问题**：属格所指 — `assa` 译作「它」，指代悬空。nissaya：`အဿ = ထို သိက္ခာပုဒ်၏`（那条**学处**的，属格），明确回指上文的学处而非泛指的「它」。
- **建议**：「现在，在分别解释**那条学处**的意思时，就说了……」

## §960 句 138-960-20-34

- **问题**：定语辖域 — 「全部律的判定」易被读成「全部律」的判定。nissaya：`သကလေ=သော` 修饰 `ဝိနယဝိနိစ္ဆယေ စ=ဝိနည်း အဆုံးအဖြတ်၌`，即「律的**全部**判定（之上）」。
- **建议**：「以及在律的全部判定上都娴熟的人」。

## §962 句 138-962-2-7

- **问题**：动词取义 — `nīharitvā` 译「整理出来」。nissaya 的释义是「从教典／圣典中抽出、引出」：`= ပရိယတ္တိသာသနာတော်မှ ထုတ်ဖော်၍။ ဝါ = ပါဠိတော်မှ ထုတ်ဖော်၍`，并举例说明「因为这段圣典里有 sutta、suttānuloma 的字样，所以能从这段圣典中把它们抽出来」。「整理」丢掉了「自圣典中抽出」这一关键来源义。
- **建议**：「……从圣典中抽取出来加以阐明的。」
- **问题**：`purā` 的挂靠 — nissaya 作 `ပုရာ = ရှေးအခါ၌`（时间处格，修饰 `pakāsesuṃ` 的发生时间），译文挂在人身上（「从前结集法藏的那些人」）。
- **建议**：「……是有大神通的大长老们、也就是结集法藏的那些人，**从前**从圣典中抽取出来加以阐明的。」

## §963 句 138-963-13-16

- **问题**：代词所指过窄 — 「正是针对**这一点**」。nissaya：`ယံ = ယင်း လေးပါး အပြားရှိသော ဝိနည်းကို`（指「那四种律」，宾格），不是前一句的某个论点。
- **建议**：「正是针对这四种律才说了——」

## §963 句 138-963-17-45

- **问题**：省略谓语未补 — 引文「依直接的文句、依意味、依师承、依意趣」四项都是具格（nissaya 逐项 `…ဖြင့်လည်းကောင်း`），nissaya 补出了被省略的主句：`(အတ္ထော = အနက်အဓိပ္ပာယ်ကို။ သမ္ပဋိစ္ဆိ တဗ္ဗော = လက်ခံထိုက်၏။)`（意义应当依这些来领受）。译文只剩四个光杆状语，读者看不出这是一句什么话。
- **建议**：「应当依直接的文句、依意味、依师承、依意趣来领受（经文的）意义。」
- **问题**：`raso` 译「意味」偏向「言外之意」，与 nissaya 的释义不合。nissaya：`ရသေန = သာမည လက္ခဏာ ဖြစ်သော မဟာပဒေသလေးပါးဖြင့်`，即「作为**共通相**的四大教法」。
- **建议**：保留「意味」可行，但宜在本句首次出现处夹注巴利原词「意味（rasa）」，并确保与下文「**意味**指的是随顺经」同词；若要贴 nissaya，可作「依通则（rasa）」。

## §965 句 138-965-7-11

- **问题**：句法误读 — 译「世尊**对**这四大教法是这样说的」，读成「谈论它们」。nissaya：`ယေ = ယင်း မဟာပဒေသလေးပါးတို့ကို`（宾格，被说出的内容本身）＋ `ဘဂဝတာ = သည်`（施事）＋ `ဝုတ္တာ`（被动）。即「这四大教法是世尊这样说出来的」。
- **建议**：「这四大教法是世尊这样说的——」

## §965 句 138-965-12-32（及 33-40、41-58、59-65、66-86）

- **问题**：`kappiya` / `akappiya` 译作「许可的一边／不许的一边」，把事物说成了方位。nissaya 一律释为事物：`အကပ္ပိယံ = မအပ်သော အရာဝတ္ထုကို`、`ကပ္ပိယံ = အပ်သောအရာဝတ္ထုကို`（均为宾格，是 `anulometi` / `paṭibāhati` 的宾语）。
- **建议**：「如果它顺应**不许可的事物**、排斥**许可的事物**，那对你们就是不许的」，四处平行句同步改。

## §966 句 138-966-2-11

- **问题**：`okkantavinicchayappavattā` 译「按照确定下来的判定流传下来」，`okkanta` 的施动者丢了。nissaya：`သြက္ကန္တဝိနိစ္ဆယပ္ပဝတ္တာ = ဉာဏ်ဖြင့် သက်ရောက် အပ်သော အဆုံးအဖြတ်ဖြစ်သော`（以**智慧**契入而作出的判定）。
- **建议**：「……以智慧深入而作出判定、这样流传下来的义注传承。」

## §967 句 138-967-2-11

- **问题**：三个具格的内容被译空了。nissaya 逐一限定：`အနုဗုဒ္ဓိယာ = သုတ္တ စသည်သို့ အစဉ် လိုက်သော ဉာဏ်ဖြင့်`（随顺经等而生的理解）、`နယဂ္ဂါဟေန = သုတ္တစသည်မှ ရအပ်သောနည်းကို ယူခြင်း ဖြင့်`（采取从经等得来的方法）。译文「凭着自己的理解、凭着对道理的把握」把「随顺经等」这一限定整个抹掉，变成纯凭己意，与下文「要放到老师们的说法里去核对」的逻辑脱节。另 `attano` 是属格，按 nissaya 挂在 `anubuddhiyā` 上。
- **建议**：「……凭着推论、凭着自己随顺（经等）而得的理解、凭着从（经等）中取得的方法，把呈现在心里的样子说出来。」

## §968 句 138-968-2-13

- **问题**：`Apica` 译「另外」。nissaya 对这个词专门出注，明确否定「另一种说法」的读法：`“အပိစ- တစ်နည်းကား”ဟု မပေးဘဲ “စင်စစ်ကား”ဟု ပေးသည်`（不作「一说」解，作「其实、确切地说」解），因为此处是把前面的概说进一步**特别指实**（`တမေဝ ဝိသေသေတွာ ဒဿန္တော`）。
- **建议**：「**其实**，经藏、论藏和律藏的义注里传下来的长老们的说法（theravāda），也都叫做‘自己的见解’。」（「各位长老自己的说法」见跨段一致性第 4 条）

## §968 句 138-968-25-35

- **问题**：`atthena` 的所指未补。nissaya 两处都限定为「自己所取的意义」：`အတ္ထေန = မိမိယူအပ်သော အနက်အဓိပ္ပာယ်နှင့်`、`အတ္ထံ စ = မိမိယူအပ်သော အနက်အဓိပ္ပာယ်ကို`。整段讲的是持自己见解的人该怎么做，译成中性的「意义」就看不出要拿去对照的正是**他自己理解的那个意思**。
- **建议**：「应该先看清理由，用自己所理解的意义去对照圣典原文，又用圣典原文去对照自己所理解的意义，然后再讲说。」

## §969 句 138-969-6-14

- **问题**：`itaro` 译「另一种」过虚。nissaya 补足了所指：`ဣတရော = အခြားသော သုတ္တာနုလောမ၌ မသက်ဝင် မညီညွတ်သော အာစရိယဝါဒကို`（在随顺经里放不进去、也不相符的那种老师们的说法）。
- **建议**：「……才可以采用；放不进去、又不相符的那种，就不可以采用。」§970-6-14 的 `itaraṃ`（nissaya 同样补出「在经里放不进去、不相符的那种随顺经」）一并同改。

## §970 句 138-970-40-50

- **问题**：`khepaṃ` / `garahaṃ` 两词的分工丢失，详见跨段一致性第 3 条。nissaya：`ခေမံ ဝါ = အယူဝါဒကို ပစ်ပယ်ခြင်းကို`、`ဂရဟံဝါ = ပုဂ္ဂိုလ်ကို ကဲ့ရဲ့ခြင်းကို`。
- **建议**：「他们不应该互相贬斥对方的主张、责难对方其人，而要把随顺经放到经里去核对。」

## §970 句 138-970-91-97

- **问题**：`gārayha` 译「应该被否定」，见跨段一致性第 2 条；nissaya `ကဲ့ရဲ့ထိုက်သော` 是「应受呵责」。另句式偏欧化被动。
- **建议**：「放不进去又不相符、应受呵责的那种老师们的说法，就不可以采用；」

## §972 句 138-972-27-50

- **问题**：`siloko` 的限定漏译 — 译「或者只是一首诗偈」。nissaya：`သိလောကော ဝါ = သာသနာတော်မှအပ ဖြစ်သော ဂါထာ`（教**外**的偈颂），与前一项 `ဗာဟိရကသုတ္တံ = သာသနာတော်မှအပဖြစ်သော သုတ်` 同属「教外」一类，译文把这层限定只给了前一项。
- **建议**：「……而是教外的经文，或是教外的偈颂，或是别的应受呵责的经文，出自《秘密须大拏》《秘密律》《毗陀罗》这一类当中的某一种……」
- **问题**：`bāhiraka` 译「外道的」比 nissaya 的 `သာသနာတော်မှအပ`（教外的）为重——教外不必然是外道所造。
- **建议**：统一作「教外的」。
