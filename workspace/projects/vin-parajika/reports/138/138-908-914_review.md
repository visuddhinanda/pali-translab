## 一、被解释词与父层逐字对照

- **必改** §908 句 138-908-25-45：被解释词 `**Yaṃ** **tvan**`，父层 213-55-128-152 作「正是由于这件恶业，你」（`yaṃ`→「正是由于这件恶业」，`tvaṃ`→「你」）。译文只黑体「**你**」，丢了 `yaṃ` 的父层译法，而整条注正是在解释 `yaṃ` = `yena pāpena`（nissaya：`ယေန ပါပေန= ကြောင့်`，并注明 `ယန္တိ ဟေတုအတ္ထ နိပါတော`）。
  → 改为「“**正是由于这件恶业，你**……”以下这一段，应当这样理解……」
- **建议** §909 句 138-909-2-10：被解释词 `**Tattha** **nāma** **tvan**`，父层作「可是在这种事上，你竟然是这样」。译文黑体止于「可是在这种事上，你」，`nāma` 的父层对应词（「竟然」）被挪到了释义里。
  → 黑体补足为「**可是在这种事上，你竟然**」。
- 其余黑体均与父层逐字相符，已核：`Alañhi te… kukkuccāya`→「善施贤友，这确实够让你懊悔」、`nanu āvuso bhagavatā`→「贤友，世尊不是」、`Anekapariyāyena`→「用许多方式」、`Virāgāya / No sarāgāya / Visaṃyogāya / No saṃyogāya / Anupādānāya / No saupādānāya`→「导向离贪／而不是导向有贪／导向解缚／而不是导向系缚／导向无取著／而不是导向有取著」、`Sarāgāya cetessasi`→「你却要起有贪的心」、`rāgavirāgo / madanimmadana / pipāsavinayo / ālayasamugghāto / vaṭṭupacchedo / taṇhakkhayo virāgo nirodho`→「贪欲止息／能破除骄慢／调伏渴望／根除执藏／断绝轮转／灭尽爱欲、离贪、寂灭」、`Kāmānaṃ pahānaṃ akkhātaṃ / Kāmasaññānaṃ pariññā / Kāmapipāsānaṃ / Kāmavitakkānaṃ / Kāmapariḷāhānaṃ`→「讲说了舍断诸欲／遍知诸欲想／诸欲渴望／诸欲思惟／诸欲热恼」、`Netaṃ āvuso / Atha khvetaṃ / Aññathattāya`→「贤友，这种事不能／这种事反而／改变心意」、`Bhagavato etamatthaṃ ārocesuṃ`→「就把这件事报告给世尊」、`Etasmiṃ nidāne etasmiṃ pakaraṇe`→「因这个缘由、因这件事情」、`Vigarahi buddho bhagavā`→「佛陀、世尊责备他说」、`ananucchavikaṃ / ananulomikaṃ / appatirūpaṃ / assāmaṇakaṃ / akappiyaṃ / akaraṇīyaṃ`→「不恰当的／不相称的／不适宜的／不是沙门所应做的／不允许的／不该做的」、`Kathañhi nāma`→「怎么」。

## 二、跨段一致性

- **pipāsā**：§909-86-101 译「渴望」（与父层「调伏渴望」一致），§910-22-29 释义却改用「贪饮／饮取」。nissaya 两处同解为 `သုံးဆောင် ခံစားလိုခြင်း`（想要受用），且明确 `ပါဓာတ်သည် ပရိဘောဂအနက်ကိုဟော၏`（pā- 此处取「受用」义，不是「饮」）。→ 统一为「渴望／想要受用」，删去「饮」。
- **garahati / vigarahati**：§913 内先后作「责备」（48-56、119-135）、「呵责」（106-118）、「责难」（48-56）。父层统一用「责备」。→ 统一为「责备」（`garahitabbaṃ garahati eva` 作「该责备的就责备」）。
- **avaṇṇa**：§912-15-50 作「坏名声」，§913-57-64 作「贬斥」。nissaya 两处均作 `အပြစ်`（过失）。→ 统一为「过失」类译法（「宣扬那位具寿的过失」／「该说过失的就说其过失」）。
- **kappiya / kappati**：§914-78-80「不允许的」，§914-81-90「不许可的」，§914-91-93 又回到「不允许」。nissaya 均作 `မအပ်`。→ 统一（建议全用「不允许」）。
- **te / tuyhaṃ + pāpa(kamma)** 的属格处理：§908-2-18 作「你所做的这件恶业」（属格作定语），§908-25-45 作「那件恶业足够让你懊悔」（属格变成了受事者）。nissaya 两处都是 `တုယှံ= ၏` / `တေ = ၏`（属格修饰 `pāpaṃ`）。→ 统一为「你的那件恶业足以引生懊悔」。
- **etaṃ pāpakammaṃ** 的指称：§908-2-18「这件恶业」、§911-2-17「你的恶业」、§911-18-24「这件事」。nissaya 在 §911-18-24 明确补出 `ဧတံ = ဤ မကောင်းမှုသည်`（这件恶行）。→ §911-18-24 建议作「就是“然而这件恶业”」。
- **aggahaṇa / saṅgahaṇa** 这对反义词译法不对称：§908-119-122「不执取」／§908-123-128「摄取执持」。→ 建议对称化（「不执取」／「并不是为了执取」）。

## §908 句 138-908-79-99

- **问题**：复合词被拆 — `sabbabhavabhogesu`，nissaya 作 `အလုံးစုံသော ဘဝစည်းစိမ်တို့၌`（一切「有的受用／生存的享乐」，一个复合概念），译文「对一切生存状态、一切享乐」拆成两项并列。
- **建议**：「对一切生存中的种种享乐离贪」。
- **问题**：隐含主语 — `adhippāyo` 的所属者，nissaya 明确补出 `အဓိပ္ပာယော= ရဟန်းတို့၏ အလိုတည်း`（是那些比丘的用意）。译文「这就是其中的用意」含混，读者容易读成世尊的用意。
- **建议**：「这就是那些比丘话里的用意。」

## §908 句 138-908-104-107

- **问题**（必改）：取义与 nissaya 相反 — `pariyāyavacanamattaṃ`，nissaya 释为 `ပရိယာယ်အနက်မျှကို ပြဆိုခြင်းတည်း`（只是在解说词义），并明确排斥「同义词／换说法」这一读法（`သဒ္ဒါပရိယာယ်ဟု မမှတ်လင့်`，并以 `ဝိမတိ` 释作 `သဒ္ဒတ္ထကထနမတ္တံ`）。译文「只是换一种说法罢了」正落在被排斥的那一解上。
- **建议**：「不过这里的这些只是就词义作解说而已（不再逐一点出用意）。」

## §908 句 138-908-113-118 / 119-122

- **问题**：nissaya 补出的宾语被漏掉 — 113-118 用括号从上句承接 `(ကိလေသေဟိ= တို့နှင့်)`；119-122 作 `ကိလေသာတို့ကို မယူခြင်း အကျိုးငှာ`（不执取烦恼）。
- **建议**：「就是不为了与烦恼相系」／「就是为了不执取（烦恼）」。
- **问题**：`saṃyujjana` 译作「被系缚」带了被动施事；nissaya 为中动式 `မယှဉ်ခြင်း`（不相系）。
- **建议**：改「不相系」。

## §909 句 138-909-2-10

- **问题**：隐含成分 — `tasmiṃ` 的所指，nissaya 补出 `တသ္မိံ (ဓမ္မေ…ဒေသိတေ)`（在那已被宣说的法上）。译文「在那种情形下」把处格虚化了。
- **建议**：「就是说：在世尊宣说了那法的情况下，你竟然……」
- **问题**（建议，见第一节）：黑体缺 `nāma` 的父层对应词。

## §909 句 138-909-11-21

- **问题**（必改）：取义与 nissaya 明文相反 — `cetessasi kappessasi pakappessasi`，nissaya 注明 `စိတဓာတ်သည် ဥဿာဟ…အနက်ကိုဟော၏`、`ကပ္ပဓာတ်၏ ကြံစည်ခြင်းအနက်ကို ယူမည် စိုးသောကြောင့်…“ဧတဒတ္တံ ဝါယမိဿသိ”ဟု ဥဇုကတ္ထဖွင့်သည်`、`“စေတေဿသိ”အရ စေတနာ မယူနှင့်, ဝီရိယယူပါ`——即此处不取「思量/计划」义，也不取「起心(cetanā)」义，而取「发力、着手去做」。译文「起心、计划、谋划」三词全落在被排斥的一侧。
- **建议**：「就是你为那与贪一同发生的不净法而发起心力、动手去做、一再地做」（黑体「你却要起有贪的心」沿父层不动）。
- **问题**：`nāma` 的语气 — nissaya 在 `စေတေဿသိ` 后标 `(နာမ)`。释义句里可补「竟然」。

## §909 句 138-909-22-25

- **问题**：`etadatthaṃ` 的指称 — nissaya 作 `ဤ မေထုန် အကျိုးငှာ`（为这件不净法）。译文「为这件事」过虚。
- **建议**：「意思是：你竟要为这件不净法而努力。」

## §909 句 138-909-30-37

- **问题**（必改）：`nibbattita` 误解 — nissaya 作 `သင်္ခါရတို့မှ နှစ်စေအပ်သော`（从诸行中分出、脱离诸行的），并引 `သင်္ခါရေဟိ နိက္ခန္တ ဝိဝိတ္တံ`。译文「所证得的出世间涅槃」把它读成了「证得」。
- **建议**：「都是就那脱离诸行的出世间涅槃而说的。」
- **问题**：隐含主语 — nissaya 补出 `(ဘိက္ခုဟိ= တို့သည်)`（是那些比丘说的）。译文的无主被动句易被读成世尊所说。
- **建议**：「……那些比丘都是就……而说的。」

## §909 句 138-909-54-69

- **问题**：`taṃ āgamma` 的词法 — nissaya 注明 `အာဂမ္မ` 不是以身到达，而是 `အာရုံပြုသောအားဖြင့် ရောက်၍`（以涅槃为所缘而到达）。译文「依靠涅槃、缘于涅槃、凭借涅槃」三个同义铺排，反而把「以之为所缘」这一关键取义冲淡了。
- **建议**：「因为以涅槃为所缘、缘于涅槃，贪就止息、不再生起」；后面 §909-70-85 起各句的「依靠涅槃」同此处理（至少首次出现处点明）。

## §909 句 138-909-70-85

- **问题**：`nimmadā amadā honti` 是系词+形容词（nissaya `ထောင်လွှားခြင်း မရှိကုန်သည် / ဟောန္တိ`），译文「都被破除」加了被动施事。
- **建议**：「……各种骄慢都不再骄举、归于无骄、彻底消失」。
- **问题**：`mānamada / purisamada` 过简 — nissaya 作 `ငါမြတ်၏ အစရှိသည်ဖြင့် ထောင်လွှား…မာန်` / `ငါ ယောက်ျားဟု ထောင်လွှား…မာန်`。「慢骄、男子骄」读者无从索解。
- **建议**：「由我慢而生的骄、自恃是男子的骄」等。

## §909 句 138-909-86-101

- **问题**（必改）：`vinayaṃ abbhatthaṃ yāti` 的词法 — `vinayaṃ`/`abbhatthaṃ` 是 `yāti` 的方向宾格（nissaya `ဝိနယံ = ပျက်စီးခြင်းသို့` / `အဗ္ဘတ္ထ = ချုပ်ပျောက်ခြင်းသို့` / `ယာတိ = ရောက်ရ၏`），主语是 `kāmapipāsā` 自身趋于灭没；译文「都被调伏」变成了被动受事。
- **建议**：「一切对欲的渴望都趋于消灭、归于止息，所以称为**调伏渴望**」（黑体名目沿父层不动）。

## §909 句 138-909-128-146

- **问题**（必改）：谓语主语错配 — 三个动词 `khayaṃ gacchati / virajjati / nirujjhati` 的主语都是 `taṇhā`（nissaya `တဏှာ = သည်`、`ဝိရဇ္ဇတိ = ပျက်လည်း ပျက်စီး၏ / ကင်းလည်းကင်း၏`）。译文「爱欲完全灭尽、离贪、寂灭」里「爱欲离贪」读不通——「离贪」是名目，不是此处的谓语。
- **建议**：「爱欲完全灭尽、消散、止息，所以称为**灭尽爱欲、离贪、寂灭**。」

## §909 句 138-909-147-177

- **问题**：夹注格式违反 `style.md` — 「“vāna（缠缚）”」把巴利词放正文、汉译入括号，与规定的「汉译（巴利）」相反。
- **建议**：「因而得到“缠缚（vāna）”这个名称」。
- **问题**：`vinanato ābandhanato saṃsibbanato` 三词译序与 nissaya 的层层递释（`ဝိနနတော`→`အာဗန္ဓနတော 捆绑`→`သံသိဗ္ဗနတော 缝接`）不对应，译文作「缝合、捆绑、串连」。语义不误，建议按 nissaya 递进序改为「缠结、捆绑、缝接」。

## §910 句 138-910-22-29

- **问题**（必改）：`pātabyatā / pātuṃ icchā` 取义 — nissaya 明确 `ပါဓာတ်သည် ပရိဘောဂအနက်ကိုဟော၏`（pā- 取「受用、享用」义），并作 `သုံးဆောင်ခံစားတတ်သော ပုဂ္ဂိုလ်၏…တဏှာတို့ကို` / `ပါတုံ = သုံးဆောင်ခံစားခြင်းငှာ`。译文「贪饮」「想要饮取诸欲」取了被排除的「饮」义。
- **问题**：nissaya 补出的所指被漏 — `pātabyatā` 实指 `တဏှာ`（爱欲），`kāmesu` 兼指 `ဝတ္ထုကာမ, ကိလေသာကာမ`；`kāme vā` 是单数处格，nissaya 作 `ဝတ္ထုကာမ၌`。
- **建议**：「**诸欲渴望**，是指对诸欲（事欲、烦恼欲）贪着受用的那种爱欲；或者说，是想要受用事欲的那种欲望。」

## §910 句 138-910-30-33

- **问题**：nissaya 把 `kāmupasañhita` 定为 `ကိလေသာ ကာမနှင့် စပ်ယှဉ်ကုန်သော`（与烦恼欲相应），译文「与欲相连」未落实这一限定。
- **建议**：「是指与（烦恼）欲相应的那些思惟。」

## §910 句 138-910-40-46

- **问题**：`eva` 的限定力 — nissaya `လောကုတ္တရ မဂ္ဂါဝ = ကိုသာ`，并注 `ဧဝဖြင့် လောကီမဂ်ကို ကန့်သည်`（以 eva 排除世间道）。译文「都是……出世间道」弱化了排他。
- **建议**：「在这五处所讲说的，唯是能灭尽烦恼的出世间道。」

## §911 句 138-911-2-17

- **问题**：释义句语序不合汉语 — `na etaṃ āvuso` 译作「这不是，贤友」，照搬巴利语序。
- **建议**：「就是“贤友，这并不……”」。
- **问题**：夹注用法 — 「这样的人（没有信心的人）」用圆括号作汉语补释，`style.md` 规定圆括号夹注只用于巴利原词。
- **建议**：「也就是不能让这样（还没有信心）的人生起信心。」

## §911 句 138-911-18-24

- **问题**：nissaya 补出 `ဧတံ = ဤ မကောင်းမှုသည်`（这件恶行），且注明与 `hoti` 相连；译文「这件事」过虚（参见跨段一致性第 6 项）。
- **建议**：「就是“然而这件恶业”。」

## §911 句 138-911-30-35

- **问题**（必改）：同位语被拆成两件事 — nissaya 作 `ပသာဒညထာဘာဝါယ = ကြည်ညိုခြင်းမှ တစ်ပါးသော အပြား၏ အဖြစ်ဟူသော`（「ဟူသော」＝名为），修饰后面的 `ဝိပ္ပဋိသာရာယ`；即「那名为『信心变异』的悔恨」是一件事。译文「会使信心发生变异，引生悔恨」读成了两个结果。
- **建议**：「是说会引生那种信心变异的悔恨。」

## §911 句 138-911-44-58

- **问题**：`yattha…bhikkhū` 是修饰 `dhammavinaye` 的关系从句（nissaya `ယတ္ထ= အကြင် သာသနာ၌` ↔ `(တတ္ထ) ဓမ္မဝိနယေ = ထို သာသနာ၌`），译文把它拆成了并列的第二句，从属关系断了。
- **建议**：「我们竟然对这样的法与律生起了信心——那里面的比丘们居然这样行为不端。」

## §912 句 138-912-2-14

- **问题**：`paṭivedayiṃsu` 是致使态（nissaya `သိစေကြကုန်ပြီ`＝使之得知），译文「禀告世尊」丢了致使义，且与前一词「告知」重复。
- **建议**：「就是把这件事告知世尊、使世尊得知。」

## §912 句 138-912-15-50

- **问题**（必改）：`kalisāsanāropana` 误解 — nissaya 作 `ကောဓ ပြောဆိုအပ်သော အပြစ်တင်ခြင်း အကျိုးငှာ`，并注 `ကလီတိ ကောဓဿ…အဓိဝစန`（kali 此处即「瞋怒」）。译文「把罪过加在他身上」把 kali 读成了「罪过」，瞋怒这一关键义全失。
- **建议**：「也不是为了含着怒气加以责难」。
- **问题**：`piyakamyatā` 的指向 — nissaya/ṭīkā 作「（对自己）求得导师的喜爱」（`အတ္တနိ သတ္ထု…ပိယဘာဝကာမတာယ`）。译文「为了讨好谁」指向不明。
- **建议**：「既不是为了讨得世尊的欢心」。
- **问题**：`bhedapurekkhāratā` 的对象 — nissaya 作「以（世尊与那比丘之间的）不和为先」。译文「存心制造分裂」未指明离间对象。
- **建议**：「也不是存心离间（世尊与他）」。
- **问题**：`avaṇṇa` 译「坏名声」，nissaya 作 `အပြစ်ကို ထင်ရှားပြခြင်း`（显露过失）；见跨段一致性第 3 项。
- **问题**：`nikkaḍḍhāpessati` 是致使态（nissaya `နှင်ထုတ်စေ တော်မူလတ္တံ့`），译文「会把他赶出去」丢了「使人驱逐」。
- **建议**：「会命人把他赶出去」。

## §912 句 138-912-51-72

- **问题**：`abbuda` 取义与 nissaya 不同 — nissaya 作 `ဤခိုးမှုကို`（并补 `ဤ ခိုးကြောင်ခိုးဝှက် ပြုမှုကို`，即暗中偷作之事），译文作「祸患」。此处记下分歧，按 nissaya 为词级基准宜改。
- **建议**：「世尊知道教法中出现了这件暗中发生的恶事」（若保留「祸患」，须在报告中留存此分歧）。
- **问题**：`velaṃ mariyādaṃ āṇaṃ` 三个同位宾格，nissaya 一律补出「以学处为……」（`သိက္ခာပုဒ် တည်းဟူသော ကမ်း/စည်း/အမိန့်`）。译文「界限、规范和律令」未体现三者同指学处。
- **建议**：「会立下以学处为堤岸、为界限、为律令的规定」，或至少「会立下界限、规范、律令（即学处）」。

## §913 句 138-913-57-64

- **问题**（必改）：属格归属错位 — `vaṇṇāvaṇṇārahānaṃ` 是「应受赞叹／应受责备者」的属格，统摄 `vaṇṇaṃ ca avaṇṇaṃ ca`（nissaya `ဂုဏ်ကို ပြောဆို ထိုက်, အပြစ်ကို ပြောဆိုထိုက်သူတို့၏` + `ဝဏ္ဏဉ္စ/အဝဏ္ဏဉ္စ = ကို`）。译文「在该赞叹时赞叹、该贬斥时贬斥的人当中」把属格读成了时机。
- **建议**：「正如在对该赞叹的人说其功德、对该责备的人说其过失的人当中，他是最上的人一样。」

## §913 句 138-913-65-105

- **问题**（必改）：`yasassī` 取义 — nissaya 作 `များသော အခြံ အရံရှိသော ပုဂ္ဂိုလ်`，并注明 `ဉာတောပါဌ်ဖြင့် ကိတ္တိယသကို ပြပြီးဖြစ်သောကြောင့် ယသဿီကို မဟာပရိဝါရော ဟု ဋီကာဖွင့်သည်`——名声义已由 `ñāto` 承担，`yasassī` 指徒众众多。译文「出名、有声望」两词同义重复，丢了「徒众」。
- **建议**：「……而出名、徒众众多」。

## §913 句 138-913-106-118

- **问题**：`garahitabbaṃ / pasaṃsitabbaṃ / ayaṃ` 的所指 — nissaya 均补为人（`ကဲ့ရဲ့ထိုက်သူကို` / `ချီးမွမ်းထိုက်သူကို` / `ဤ ရှင်သုဒိန်ကို`）。译文「该呵责的……这个人」未落实「人」与「善施」。
- **建议**：「该责备的人他就责备，该赞叹的人他就赞叹；而这位善施是该责备的」（译词统一见跨段一致性第 2 项）。

## §913 句 138-913-119-135

- **问题**：`tādilakkhaṇe ṭhito` — nissaya 释为 `ဣဋ္ဌာရုံ အနိဋ္ဌာရုံတို့၌ တုန်လှုပ်ခြင်း မရှိသော ပုဂ္ဂိုလ်၏ အမှတ်အသား၌`（对可意、不可意所缘都不动摇者之相）。译文「不为所动的品格」偏抽象，未点出所缘。
- **建议**：「安住于对可意、不可意都不动摇的品格」。

## §914 句 138-914-2-35

- **问题**：`chaviṃ chāyaṃ` 的对译 — nissaya/ṭīkā 作 `ပဘာဿရကရဏံ ဆဝိ`（光彩）、`ဆာယံ…တေသံ ပကာသကံ သြဘာသံ`（显发它们的光辉）。译文「光彩、容色」把 `chāyā` 读成了容貌。
- **建议**：「跟不上、配不上这些法的光彩、光辉和美好」。

## §914 句 138-914-104-119

- **问题**：句法结构与 nissaya 不同 — nissaya 把六个形容词一律标为 `ကို`（宾格，作 `kataṃ` 的宾语），`te` 标为 `သည်`，即「愚痴人，你做了不恰当的、不相称的……不该做的事」。译文作「你所做的这件事是不恰当的……」（表语式）。
- **建议**：按 nissaya 改为「所以说：愚痴人，你做了对比丘来说不恰当的……乃至……不该做的事。」（父层 213-56-60-78 处无 `te…kataṃ`，不构成与父层定稿的冲突）

## §914 句 138-914-120-133

- **问题**（必改）：隐含谓语缺失 — nissaya 两处都补出 `(န သက္ခိဿသိ) နာမ`（竟然不能），并注明 `နာမပုဒ်ကို ပါဠိတော် “န သက္ခိဿသိ”နှင့် တွဲပေး`。译文「究竟出于什么理由，究竟看到了什么理由」两个状语悬空，没有谓语。
- **建议**：「意思是说：你究竟出于什么理由、究竟看到了什么理由，竟然不能（终身修行圆满清净的梵行）。」
