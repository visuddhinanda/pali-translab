## 二、跨段一致性

- **methuna dhamma**：§944-66-72 译「行不净法」，§945-11-25 译「交合的意图」 → 建议统一为「行不净法」（父层通篇作"行不净法"，§945 改为「想行不净法的意图」）。nissaya 此处亦作 `မေထုန်မှီဝဲလိုခြင်း`（想行不净法）。
- **duṭṭhulla**：§946-55-63 / 64-68 译「粗鄙」，父层 213-64-196-212 译「粗恶的」 → 非黑体，但同一术语宜随父层，建议统一为「粗恶」。
- **tiracchānagata**：§947-2-20 黑体作「雌性动物」（随父层学处文 213-65），§946 作「畜生类的雌性」（随父层 213-63）。**两处各自对应父层，均不要改**——这是父层自身的两种译法，本层擅自统一反而会断掉对应关系。此项记录备案，若要统一须先动父层。
- **anupaññatti**：全 chunk 一致作「追加的制定」✅。
- **lokavajja / paṇṇattivajja**：§947 内一致作「世间所谴责的」/「因制戒而成为过失的」✅，但见下 947-87-101 的混用问题。
- **语体**：全 chunk 为现代书面汉语，未见文言虚词与文言句式；标点全角，`zh` 内无 ASCII 引号 ✅。

## 三、必改项

### §947 句 138-947-87-101
- **问题**：词义取义错 — `paññattigatikāva hoti` 译作「所以仍然属于因制戒而成为过失的那一类」。nissaya 明确：`ပညတ္တိဂတိကာဝ = မူလပညတ်နှင့် အလားတူသည်သာ`（**与根本制定同类**），不是 `paṇṇattivajjaṃ`。随后的注释块进一步说明：`ပဏ္ဏတ္တိဝဇ္ဇဖြစ်သော်လည်း … အနုပညတ်က လျော့အောင် မပြုနိုင်`——这类追加虽出现在 paṇṇattivajja 的学处上，却**不起放宽作用**，而与本制同其趣向。现译把"同本制之类"误读成"属 paṇṇattivajja"，正好取消了本句要讲的分辨，与前文 §947-69-86「放宽、解开、留出门路」直接矛盾。
- **建议**：「不过，**“乃至与临时妻子”**这类追加的制定，由于是在已经发生违犯之后才出现的，所以与根本制定同属一类。」

### §946 句 138-946-55-63
- **问题**：格误读 — nissaya 作 `မနုဿိတ္ထိယာပိ = လူမကိုလည်း`，`ကို` 是**宾格**，人类女子是 dassana / gahaṇa / āmasana / phusana / ghaṭṭana 的**动作对象**（看她、抓她、摸她…）。译文「对人类女子来说，看也好、抓也好…」把她读成了评断的范围（与格/关于格），动作对象落空。
- **建议**：「因为即便是人类女子，看她、抓她、抚摸她、触碰她、身体相磨，都是粗恶的。」
- **附（补出成分）**：nissaya 的注释块界定 `ဒဿနံ = ရာဂဖြင့် ကြည့်ခြင်း`（带着贪染去看），`ဖုသန`＝比 āmasana 更重的接触，`ဃဋ္ဋန`＝身体与身体相磨。译文「看」可补成「带着贪欲去看」，「接触／摩擦」宜改「触碰／身体相磨」，五个层级才见递进。

### §946 句 138-946-64-68
- **问题**：同上 — nissaya `တိရစ္ဆာနဂတိတ္ထိယာပိ = ကိုလည်း`，宾格。译文「对畜生类的雌性来说」同样把对象读成范围。
- **建议**：「对畜生类的雌性也一样，这一切都是粗恶的。」（`taṃ sabbaṃ` nissaya 作主格 `ထို ကိုင်ခြင်းစသော အလုံးစုံသည်`，译「这一切」✅ 保留。）

### §945 句 138-945-11-25
- **问题**：格误读 + 指代丢失 — nissaya `ယေန နိယာမေန` / `ယာယ ကိရိယာယ` 均带具格（**凭**那样一种方式、**以**那样一种动作），`တံ = ထိုသိကြောင်း အမှတ်အသားကို`（那个**作为知道之因的标记**，宾格）才是 `akāsi` 的宾语。译文「它做出了那样一种方式、那样一种动作」把两个具格当成并列宾语，`taṃ` 回指的"标记"（nimitta）整个丢掉了——而这句正是在释 `nimittaṃ`。
- **建议**：「意思是：它做出了这样一个标记——凭这样一种方式、这样一种动作，他们就能知道它有行不净法的意图。」

### §947 句 138-947-43-68、138-947-111-122
- **问题**：取义偏 — `sotaṃ pacchindamānā` 译「截断去路」。nissaya 作 `သောတံ = အဆက်ဆက် ကျူလွန်မှုဟူသော အလျဉ်ကို`（**接连违犯的"流"**），注释块亦作 `ဥပရူပရိ ဝီတိက္ကမသောတံ ပစ္ဆိန္ဒမာနာ`。「去路」把水流隐喻换成了通路隐喻，与紧邻的 `dvāraṃ pidahantī`（关门）重复，三个并列动作塌成两个。另 `dvāraṃ` nissaya 明指是**（找借口的）门** `လွန်ကျူးကြောင်း အရိပ်အမြွက်၏ တံခါးကို`。
- **建议**：两处同改为「堵住违犯、关上（找借口的）门、截断接连违犯的水流、把规定做得更紧」。两句并列句式必须同步改，不要只改一处。

## 四、建议项

### §944 句 138-944-2-25
- **问题**：隐含成分 — nissaya `အညံ = မူလဝတ္ထုမှ တစ်ပါးသော`，`aññaṃ` 是"**与根本事例（须提那事例）不同的**另一件"。译文「另外发生的那件事例」未带出对照项。另 nissaya 括注补出施事为 `သံဂီတိကာရော`（结集者），不是世尊。
- **建议**：「现在，为了显示除根本事例之外另有一件事例发生，就说了**“那时候”**等等这段话。」施事按 `style.md`「不擅自补足省略主语」可不补。

### §944 句 138-944-42-52
- **问题**：语序 — nissaya 结构为 `တတြ`（那些动物当中，处格）→ `ဧကံ မက္ကဋိံ`（宾格）→ `ယာဂုဘတ္တခဇ္ဇကာဒိနာ အာမိသေန`（具格）。译文「其中有一只母猴，他用粥…去引诱」先把母猴立为存在句主题再转作宾语，读成了两截。
- **建议**：「在那些动物当中，他用粥、饭、点心之类的食物引诱其中一只母猴——意思就是说笼络它。」

### §944 句 138-944-53-56
- **问题**：层次可读性 — `bhummavacana` nissaya 释作 `သတ္တမီဝိဘတ် ရှိသောသဒ္ဒါ`（带第七格语尾的词），说的是巴利词 `tassā` 本身的格。译文「**与它**是处格形式」会让读者以为"与它"这个汉语译法是处格。黑体不可改，故宜加巴利原词。
- **建议**：「**与它**（tassā）是处格形式。」

### §944 句 138-944-62-65
- **问题**：格的方向 — nissaya `ပစုရတ္တေ = ကြိမ်ဖန်များစွာဟူသော အနက်၌`（处格，"在屡次之义上"）为状语，`ဝတ္တမာနဝစနံ` 为主格。译文「因为现在时的说法可以表示屡次反复的意思」把处格化成了宾语，陈述方向与 nissaya 相反（nissaya 是"在此义上用现在时"）。
- **建议**：「因为在屡次反复的意义上也可以用现在时。」

### §944 句 138-944-125-133
- **问题**：句式 — nissaya 用比况结构：`ဝိဿာသိကဘိက္ခုဿ … (ဒဿတိ) ဣဝ`（**如同**向自己亲近的那位比丘显示那样）→ `တေသမ္ပိ … ဒဿေသိ`。译文「就把它只对自己所亲近的那个比丘做的那种动作，也对他们做了出来」改成了定语套宾语，`eva` 的落点也从"正如…那样"移到了"只对…"。另 `vikāra` nissaya 作 `ဖောက်ပြန်သော အမူအရာ`（反常的举动）。
- **建议**：「走到以后，就像平时对自己亲近的那位比丘那样，也向他们做出了那种反常的举动。」

### §946 句 138-946-69-72
- **问题**：隐含成分 — nissaya 把 `ettha` 的所指明白补出：`ဤ လူမ မျောက်မကို မှီဝဲရာ၌`（在对人女与对母猴行此事这件事上），文末校注亦作 `မနုဿတိရစ္ဆာနဂတိတ္ထီသု`。译文「这里面」过虚。
- **建议**：「这两者之间（对人类女子与对母猴）又有什么差别呢？」

### §946 句 138-946-73-77
- **问题**：取义与收句 — `lesaṃ oḍḍesi` nissaya 作 `အမြွက်ကို ထောင်ဘိ၏`（**张设**口实），动词与前文母猴 `kaṭiṃ oḍḍi`（翘起）同一个 `oḍḍ-`，义注这里是有意呼应。译「硬找漏洞」把呼应与"张设"的动作感都磨掉了。另 nissaya `ဣတိ = ဤသို့ ပြောကုန်ပြီ` 补出"（他们）这样说了"，而译文这段比丘的话没有引号收束。
- **建议**：「你竟在无从张设口实的地方张设口实。」——并与 §946-36-54 起的引语配成完整引号，或在句末加「——他们这样说。」

### §947 句 138-947-21-28
- **问题**：术语首现未夹注 — 按 `style.md` 法相术语首次出现应夹注巴利原词。
- **建议**：「学处有两种——世间所谴责的（lokavajja），和因制戒而成为过失的（paṇṇattivajja）。」其后各处只用汉译。

### §947 句 138-947-43-68
- **问题**：补注超出所据 — 括注「（增上慢 adhimāna，指未证得而自以为已经证得）」中的释义不出于 nissaya；nissaya 此处只说明该 anupaññatti 属第四波罗夷、因无违犯意图而开许。
- **建议**：压缩为「**“除了增上慢（adhimāna）的，除了梦中的”**」，释义留到有依据时再补。

### §947 句 138-947-69-86
- **问题**：术语 — `gaṇabhojana` / `paramparabhojana` 译「结众进食」「辗转受食」，传统汉译分别作「别众食」「展转食」。
- **建议**：「就像别众食（gaṇabhojana）、展转食（paramparabhojana）等处的追加制定那样。」

### §948 句 138-948-2-15
- **问题**：隐含成分 — nissaya 补出 `ဒွေပိ ဝတ္ထူနိ = သုဒိန္နဝတ္ထု, မက္ကဋီဝတ္ထုတို့ကို`（须提那事例与母猴事例）；`အပရမ္ပိ = ထိုနှစ်ဝတ္ထုမှ အခြားလည်းဖြစ်သော` 是修饰 `vajjiputtakavatthu` 的形容词（**另一件**事例），译文把它当成了修饰"追加制定"的"再一次"。
- **建议**：「这样，世尊把两件事例（须提那的事例与母猴的事例）合在一起，以从根本断除的方式把第一条波罗夷制定得更加严格以后，又有另一件事例——跋耆子的事例——发生，以便再作一次追加制定。」

### §948 句 138-948-32-46
- **问题**：指代 — nissaya `ဣဒံ ဝတ္ထု = ဤ ဝဇ္ဇီပုတ္တကဝတ္ထုသည်`，`idaṃ` 是"**这件**（跋耆子）事例"，`aññampi` 才是"另外的"。译文「又发生了另外一件事例」把 `idaṃ` 的近指丢了。
- **建议**：「……而且这另外一件事例也发生了。」
