# Review — 138:862-871（channel: 73c03e1a…，义注层 Sudinnabhāṇavāravaṇṇanā）

> 资源：pali ✅／nissaya ✅（本次只作 nissaya 词法复核：格、数、主宾属、隐含成分）

## 被解释词核对（与父层 book=213 定稿逐字比对）

逐条核过，以下黑体与父层译文逐字一致，**无必改项**：

- `tena kho pana samayena vesāliyā avidūre` → 那时候，在离毗舍离不远的地方 ✅
- `Kalandagāmo` → 迦兰陀的村子 ✅／`Kalandaputto` → 迦兰陀子 ✅
- `Sambahulehi` → 许多 ✅／`Sahāyakehi` → 朋友 ✅／`Saddhiṃ` → 一起 ✅
- `Kenacideva karaṇīyena` → 因为有些事情要办 ✅
- `Addasa kho` → 看见 ✅／`Disvānassa` → 看见以后，他 ✅／`Etadahosi` → 心里这样想 ✅／`suṇeyyaṃ`·`yaṃnūna` → 我还是也听一听法吧 ✅
- `Atha kho sudinno kalandaputto yena sā parisā` → 于是迦兰陀子须提那朝那群人所在的地方 ✅
- `Ekamantaṃ nisinnassa …` → 坐在一旁的迦兰陀子须提那心里这样想 ✅／`Yathā yathā kho` → 我越是按世尊讲法的方式去理解 ✅
- `Saṅkhalikhitaṃ` → 像擦亮的螺贝一样 ✅／`Pabbajeyyaṃ` → 出家 ✅
- `Aciravuṭṭhitāya parisāya yena bhagavā tenupasaṅkami` → 那群人离开不久，迦兰陀子须提那就走到世尊那里 ✅
- `taṃ karaṇīyaṃ tīretvā` → 办完那件事 ✅／`Amma tātā`·`ammā`·`tātā` → 妈妈，爸爸 ✅
- `Tvaṃ khosi` → 你是 ✅／`Ekaputtako` → 唯一的儿子 ✅／`Piyo` → 疼爱 ✅／`Manāpo` → 喜欢 ✅／`Sukhedhito` → 在安乐中养育 ✅／`Sukhaparihato` → 在安乐中照顾着长大 ✅
- `Na tvaṃ, tāta sudinna, kiñci dukkhassa jānāsi` → 须提那孩子，你一点苦都不懂 ✅

## 跨段一致性

- **`Kiṃ ahosi?`**：§864（138-864-84-86）译「出现了什么想法呢？」，§865（138-865-117-119）译「他想了什么呢？」。nissaya 两处同作 `ကိံ=အဘယ်အကြံသည်`（「什么想法」作主格主语）→ 建议统一为「生起了什么想法呢？」，依据：nissaya 把 `kiṃ` 处理为 `ahosi` 的主语而非宾语。
- **连写拆分（padaccheda）注的体例不统一**：§864-70-74 作「就是 disvāna（…）和 assa（…）两个词连在一起」，§869-48-54 作「就是“你确实是”」。两处 nissaya 都是纯粹的 `ပုဒ်ဖြတ်` 拆词注 → 建议统一体例（都写成「是 X 和 Y 两个词的连写」，再附意思）。
- **`parisā`**：§864-36-54 作「四众」，§865-32-48 作「（显贵的）人」，§865-49-58、§867 作「那群人」。父层定稿作「一大群人」→ 建议叙事处统一用「那群人／会众」，`catubbidhā parisā` 处见下条。
- **`brahmacariyaṃ carituṃ`（跨层）**：父层定稿作「修习梵行」，本层 §866 三处作「修行」（必须完全圆满地修行／要完全圆满地……修行）→ 建议统一为「修习」，与父层呼应。
- **`jānāsi`（§870 同句内）**：黑体部分沿用父层「你一点苦都不懂」，解释句却作「你连一丁点……都不知道」。同一词两译 → 解释句改「都不懂」。
- **`bhaṇḍappayojana-uddhāra-sāraṇa`**：§863-90-96 与 §869-23-33 译法一致（好）。若按下文建议修订，两处须同改。

## §863 句 138-863-31-41

- **问题**：格／叙述方向 — nissaya 用格助词标出被命名者与名称：`ကာဠကာ= ရှဉ့်တို့ကို`（宾格，被称呼的对象＝松鼠）、`ကလန္ဒကာ= ကတို့ဟူ၍`（引号式，作名称）、`ဝုစ္စန္တိ`（被动）。译文「迦兰陀（kalandakā）指的是黑松鼠」把名称当作了主题，方向与 nissaya 相反。
- **建议**：「黑松鼠（kāḷaka）被称为迦兰陀（kalandaka）」——这样接下句「村子依它们得名」也更顺。

## §863 句 138-863-42-50

- **问题 1**：取义 — `rājasammatassa`，nissaya 作 `မင်းဟု သမုတ်အပ်သော`／`လူကြီးမင်းဟု အခေါ်ခံရသော`，即「被（人们）称作『王』／被尊为大人」，`rāja-` 是称呼的内容，不是施事。译文「受国王敬重的」把 `rāja` 读成了施事者。
- **建议**：「被尊称为『王』的／被称作大人的迦兰陀富商」。
- **问题 2**：增译 — 「四十俱胝（一俱胝为一千万）」中的换算，pali 与 nissaya（`ကုဋေလေးဆယ် စည်းစိမ်`）都没有。
- **建议**：删去括注，或移为段后小字注释。

## §863 句 138-863-71-85（必改）

- **问题**：词法误读 — `sukhadukkhāni saha āyanti upagacchanti`，nissaya 作 `သုခဒုက္ခာနိ= သုခဒုက္ခတို့သို့`（`သို့` 标趋向）＋`အယန္တိ ဥပဂစ္ဆန္တိ= ကပ်ရောက် တတ်ကုန်၏`——`upagacchanti` 是 `āyanti` 的同义互释，两个动词共用同一宾语「苦乐」。译文「一同经历苦乐、**一同前来**」把互释词当成了第二件事，`upagacchanti` 失去宾语。
- **建议**：「一同趋赴（同受）苦乐，所以叫做朋友（sahāya）」。另 nissaya 注明 `ကပစ္စည်း သွတ္ထ`（ka 为同义后缀），「sahāya 就是 sahāyaka」可补一句「加 ka 后意思不变」。

## §863 句 138-863-86-89

- **问题**：`ekato`，nissaya 作 `တစ်ပေါင်းတည်း`（结伴、一同），是方式而非处所。译文「就是在一处」读成了地点。
- **建议**：「就是一同、一块儿（与朋友结伴）」。

## §863 句 138-863-90-96

- **问题**：复合词三支与 nissaya 对不齐。nissaya：`ဘဏ္ဍပ္ပယောဇန`＝令货物投入买卖（经营货物）；`ဥဒ္ဓါရ`＝到约定之日前往取回（本利）；`သာရဏ`＝提醒对方某日该还（令其忆起）。译文「收取借出的财物、催讨债款」把后两支都做成了「收债」，`sāraṇa` 的「提醒还期」义丢失。
- **建议**：「经营货物、到期收取（本利）、提醒还期」。§869-23-33 同一串须同改。

## §864 句 138-864-36-54

- **问题**：`catubbidhāya parisāya`，nissaya 明说是四类会众（刹帝利/婆罗门/居士/沙门，或比丘/比丘尼/优婆塞/优婆夷两读）。译文「四众」在汉语里已固指后一组，缩窄了。
- **建议**：「被四类会众围绕着」。

## §864 句 138-864-58-69

- **问题**：引文截断点 — pali 引到 `desentaṃ` 为止（父层语序为 `…parivutaṃ dhammaṃ desentaṃ nisinnaṃ`，`nisinnaṃ` 在引文之外），译文末尾却带上了「坐在那里」。
- **建议**：末尾改作「……（中略）……讲法。」

## §864 句 138-864-70-74

- **问题**：`disvāna` 的语法功能 — nissaya 作 `ဒိသွာန= ကြောင့်`，并附注 `ဟေတု အတ္ထော အယံ ဒိသွာန သဒ္ဒေါ`，明确是**因义**（因为看见，才生起这想法），不是时间先后；`assa` 作属格 ✅ 已对。黑体部分须照父层保留「看见以后，他」，但括注里的释义宜改。
- **建议**：「就是 disvāna（因为看见）和 assa（他的）两个词的连写」。§865-76-94 的 `sutvā`（nissaya 同样作 `နာရခြင်းကြောင့်`，并注 `ဣဓာပိ သုတွာ သဒ္ဒါ ဟေတု`）同理，可改「而是因为听了世尊一小段与三学有关的法谈才有的」。

## §865 句 138-865-49-58

- **问题**：时态 — nissaya 读作 `ဥပသင်္ကန္တော`（过去分词，并注「因为是 `nisīdi` 的解释，故用过去义的 ta 后缀」），刊本的 `upasaṅkamanto` 在它看来是现在分词形。译文「就只走到那群人那里去」偏未完成义。
- **建议**：「所以他就只走到了那群人那里」。

## §866 句 138-866-46-58

- **问题**：隐含成分未补 — nissaya 把 `idaṃ` 补成 `ဣဒံ ဗြဟ္မစရိယံ`（这个三学梵行），并把它系到 `carituṃ` 作宾语。译文「这是不容易的」指代悬空，读者易误以为指上句的「螺贝」。
- **建议**：「这个梵行是不容易修的——住在家里的人，也就是生活在家庭中的人，要完全圆满地……（中略）……修习」。

## §866 句 138-866-77-89

- **问题**：`agārassa hitaṃ`，nissaya 先把 `agāra` 释为 `အဂါရဝါသော အဂါရံ`（省略后词的「居家生活」），再说「对居家生活有增益的事业」。译文「对家有益」易读成「对房屋有益」。
- **建议**：「因为对居家生活有益的耕作、经商等事情叫做『家业』」。

## §866 句 138-866-104-107（必改）

- **问题**：`paribbajeyyaṃ` 的前缀取义 — nissaya 作 `လူ ကိစ္စများ, စွန့်ခွာ ထား၍, သွားရောက်`，并明注 `ပ နှင့် ပရိဗ္ဗဇေယျ၌ ပရိတို့သည် ပရိစ္စာဂ အနက် ဟောတည်း`（pa- 与 pari- 在此都表**舍弃**）。译文「出去四处游行」把 pari- 读成了「周遍、到处」，与 nissaya 相悖。
- **建议**：「就是舍弃在家的种种事务而出离」。

## §867 句 138-867-21-66

- **问题**：`sarīrakicca-lesena` 的 `lesa` — nissaya 释为 `ကျင်ကြီး ကျင်ငယ်စသော အနည်းငယ်သော ကိုယ်ကိစ္စကြောင့်`，并专门注 `လေသသဒ္ဒါ အနည်းငယ် အနက်ဟော`（lesa 取「少许」义）。译文「借着身体上有点事要办的**理由**」把 lesa 读成了「借口、托词」。
- **建议**：「又因为一点身体上的事（如大小便之类）折回来」。

## §869 句 138-869-55-59

- **问题**：隐含谓语未补 — nissaya 在 `ဧကောဝ ပုတ္တကော` 后补出 `(အသိ= ၏)`，即第二人称「你是」。译文「就是只有一个儿子」把主语换成了父母，与下句「你没有别的兄长或弟弟」的主语脱节。
- **建议**：「就是（你是）唯一的一个儿子」。

## §869 句 138-869-68-85（必改）

- **问题 1**：`-ka` 后缀取义 — nissaya 作 `အနုကမ္ပာဝသေန`，并给出构词 `အနုကမ္ပိတော + ဧကပုတ္တော = ဧကပုတ္တကော`，即 ka 是**怜爱的爱称**后缀，与「大小」无关。译文括注「ekaputtako（小儿子）」译反了后缀义，且与父层定稿「唯一的儿子」冲突。
- **建议**：「这里本来该说 ekaputto（唯一的儿子），因为怜爱，才说成带爱称后缀的 ekaputtako」。
- **问题 2**：`vuttaṃ` 的施事，nissaya 补出 `မာတာပိတူဟိ`（父母）；译文「才说成」无主语。
- **建议**：补「父母才说成……」。

## §869 句 138-869-94-98

- **问题**：语态 — `edhito`／`saṃvaḍḍhito`，nissaya 均作 `ကြီးပွားစေအပ်သော`（被使成长，使役被动）。译文「在安乐中成长起来的」作了自动词，施事（父母、乳母）隐去。
- **建议**：「就是被安乐地养育长大的；意思是在安乐中被养大的」。

## §869 句 138-869-107-121（必改）

- **问题**：两处使役被动被改成了主动 — nissaya 对 `kīḷamāno` 明确读作 `ကီဠာပိယမာနော`（被逗着玩），并附注说主动形与施事 `ဓာတီဟိ`（乳母们，具格施事）不合，当作使役被动；`bhojiyamāno` 作 `စားစေအပ်သည်／ကျွေးအပ်သည်`（被喂）。译文「玩着小马、小车……吃着味道鲜美的食物」把施事转给了孩子，`dhātīhi` 失去管辖范围（nissaya 把抱、逗、喂三项都归到乳母们名下）。
- **建议**：「从出生起就由乳母们从一人怀里抱到另一人怀里，拿小马、小车这些儿童玩具逗他玩，喂他味道鲜美的食物，这就是在安乐中被照料」。

## 原文疑问（记下，不改）

- §865-76-94 `sittayūpasaṃhitaṃ`、§866-2-40 `sittayabrahmacariyaṃ`：nissaya 两处都读作 `သိက္ခာ ၃ ပါး`（sikkhattaya），刊本 `sittaya-` 疑为 `sikkhattaya-` 的讹误。译文按 nissaya 处理为「三学」是对的。
- §863-106-110 nissaya 把 `ettha` 释作 `ဤ ဝေရဉ္စာမြို့၌`（毗兰若城），按上下文应为毗舍离，疑 nissaya 自身笔误。译文作「这里」未受影响。
