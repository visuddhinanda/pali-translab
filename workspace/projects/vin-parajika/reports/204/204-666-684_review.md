# Review — 204:666-684（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次仅作 nissaya 词法复核：格、数、主宾属关系、隐含成分；无 nissaya 的句子未审）

## 跨段一致性

- **pītavaṇṇa / harivaṇṇa**：§676 句 `204-676-135-140` 译「黄色」，`204-676-141-147` 同一句内先「黄色」后「金色」。nissaya 两处均作 `ပီတဝဏ္ဏံ= ရွှေသောအဆင်းရှိသော`、`ဟရိဝဏ္ဏစန္ဒနံ= ရွှေအဆင်းနှင့်တူသော`（金色）→ 建议统一为「金色」，`haricandana` 的被解释词也随之改为「金色檀香」，不要头词作「黄檀香」而释义作「金色的檀香」。
- **gositacandana**：`204-676-148-153`／`165-173`／`174-184` 一律译作「凉如水的檀香」，但后两处 nissaya 用 `ဂေါသိတစန္ဒနံ= မည်၏`（「名为」）——这是**立名**，不是再作释义，照字面译就成了「像水一样清凉的檀香就是凉如水的檀香」的同义反复。建议立名处保留名称：「…就叫做 gositacandana（凉如水的檀香）」。
- **bhājanavikati**：`204-676-102-112`／`113-119` 均译「器皿样式」。nissaya 作 `ဘာဇနဝိကတိ= ခွက်အထူး`（特制的器皿）→ 建议统一改「特制器皿」/「特制的金器皿」，「样式」会被读成图样而非实物。
- **pupphayaṭṭhi / sakuṇayaṭṭhi**：`204-666-35-47`、`65-78` 译「花杖」「鸟杖」。nissaya 作 `ပုပ္ဖယဋ္ဌိမည်သောလှံတံ၌`（名叫 Pupphayaṭṭhi 的杖）——是专名。建议统一为「名叫“花杖”（Pupphayaṭṭhi）的杖」一类处理，首次出现夹注巴利原词，后文从简。
- **agada**：`204-676-188-193` 译「解毒药（agada）」，`204-677-37-48` 译「解毒药」。nissaya 在前者只作 `ဆေးဖြစ်သော`（作药用的），在后者才作 `အဆိပ်အစရှိသည်ကို ပယ်တက်သော`（能除毒）→ 前者宜降为「作药用的」，避免把两处不同的注文拉平。
- **yaṭṭhi「杖」、muttā「珍珠」、dussayuga / vatthayuga「一对衣料」、candana「檀香」** 全 chunk 一致，无需调整。

## §666 句 204-666-14-26

- **问题**：语序 — `taṃ rajatavaṇṇaṃ yaṭṭhiṃ` 是 `alaṅkaritvā` 的宾语（nissaya `တံ ယဋ္ဌိံ= ထိုလှံတံကို`+`အလင်္ကရိတွာ= ၍`），译文把「装饰」挪到句首当headword、句末又补「装点着那根杖的藤蔓」，同一成分出现两次，读起来像两件事。
- **建议**：「**装饰它而生出的藤蔓**，是说装饰那根银色的杖、就像在杖上彩绘出来一样生出的藤蔓。」

## §666 句 204-666-35-47

- **问题**：成分切分 — nissaya 把 `ဧတာနိ နီလပုပ္ဖာဒီနိ` 作一条合并释义（「那些青色等的花」），`etāni` 是 `nīlapupphādīni` 的指示定语；译文插入判断词「这些东西，就是…」，把它拆成主语＋表语。
- **建议**：「应当这样理解：花杖上那些青色等的花，以及鸟杖上各种各样的野兽和飞鸟，都像是就在那杖上彩绘出来的一样显现。」

## §667 句 204-667-2-20

- **问题**：加字 — `ūmivegābhijātamariyādavaṭṭi` 的 nissaya 是 `လှိုင်း…အဟုန်တို့ကြောင့်ဖြစ်သော အပိုင်းအခြားဟု ဆိုအပ်သော လုံးသော အနားရေး`（因波浪之力而成、称为界限的**环形边沿**）；译文「天然堤岸」的「天然」无依据，`vaṭṭi`（圆/环）也没译出。
- **建议**：「在海边像波浪冲力堆成的那道环形边沿一样生起」。

## §676 句 204-676-11-16（必改）

- **问题**：误读 — `sabbattha` 的 nissaya 是 `အလုံးစုံကုန်သော ရထမုတ္တ အစရှိကုန်သော ပုလဲတို့၌`（在车形珍珠等一切**珍珠**上），处格所指是珍珠，不是名称；译文作「所有这些名称」，把 `taṃtaṃsaṇṭhānavasena muttābhedo` 的立论对象错换了一层。
- **建议**：「车形珍珠等其余各种珍珠，也都应当这样理解：珍珠的分类是按各自的形状来定的。」

## §676 句 204-676-69-72

- **问题**：加字 — `alaṅkāracuṇṇaṃ` 的 nissaya 是 `တန်ဆာဆင်ကြောင်း ဖြစ်သော အမှုန့်`（作装饰用的粉末），没有「香」的成分。
- **建议**：改「就是装饰用的粉末」。

## §676 句 204-676-87-96

- **问题**：词义过窄 — `kaṇṇacūḷikaṭṭhāne` 的 nissaya 是 `နားစွန်းအရပ်၌`（耳端部位），另出异释 `ဝါ= နားကို တန်ဆာဆင်ရာ၌`（在装饰耳部之处）；译文「耳垂」把部位限定到耳珠。
- **建议**：正译取「耳端」，异释（「在耳部佩饰之处」）按 `style.md` 第四节作脚注备列。

## §676 句 204-676-120-123

- **问题**：释义偏移 — `khattiyakumāriṃ` 的 nissaya 是 `မင်းသမီးတည်း`（王女／公主），译文「刹帝利族的女子」失掉「王族之女」这一层。
- **建议**：「**少女**，就是刹帝利王族的女儿。」

## §676 句 204-676-185-187

- **问题**：颜色词 — `aruṇavaṇṇa` 的 nissaya 是 `အရုဏ်အဆင်းနှင့်တူသော`（色如曙光），译文「朱红色」改换了比喻来源。
- **建议**：「**曙色的泥土**，是出自龙宫的。」

## §676 句 204-676-194-198（必改）

- **问题**：数与所指 — nissaya 补出主语 `တံ ဖလံ= သည်`（那**果实**，单数），指的是上句的诃子与庵摩勒果；译文「那些东西」既丢了 nissaya 补出的 `phalaṃ`，又把单数改成泛指复数。
- **建议**：「那种果实能很快清除身上的污垢等等。」

## §677 句 204-677-15-18

- **问题**：被解释词与释义相悖 — `vatthakoṭikaṃ` 的 nissaya 只作 `ဝတ္ထယုဂမေဝ= ပုဆိုးအစုံသာလျှင်`（就只是一对衣料），译文头词「衣端」会让读者以为讲的是布的边缘。
- **建议**：头词保留音译并夹注，如「**vatthakoṭika（衣料一副）**，就是一对衣料而已。」

## §677 句 204-677-49-56

- **问题**：三处词级偏差 —
  - `mukhasodhana`：nissaya `မျက်နှာသစ်သည်၏အဆုံး`（洗脸之后），译文作「清洁口腔」；
  - `parihārena`：nissaya `မြတ်သော အဆောင်အရွက်ဖြင့်`（以隆重的仪从／排场，具格），译文作「仪轨」，把随从排场读成了仪式程序；
  - `rājūnaṃ`：nissaya `တို့၏` 属格**复数**，译文「国王」单指。
- **建议**：「那种药丸要在诸王洗脸、沐浴结束的时候，以隆重的仪从呈上。」

## §677 句 204-677-57-77（必改）

- **问题**：数词修饰对象错位 — nissaya 作 `ဒွီဟိ တီဟိ အဂဒေါသဓရင်္ဂတိလကာဟိ= နှစ်ခု သုံးခုကုန်သော … တက်စွမ်းခြင်းတို့ဖြင့်`，「两三」修饰的是具格复数的 `tilakā`（点饰／涂点），不是药的种类；译文「用两三种解毒药制成的彩色点饰」把数词挂到了药上。
- **建议**：「用解毒药点出两三处彩色点饰」。另 `sajjetvā` 的 nissaya 是 `သုတ်သင်၍`（擦净、整理），不是「装点」——宜作「先把额头、肩头、胸部中央这几处擦净，再行涂身」。

## §678 句 204-678-2-45（必改）

- **问题**：复合词类型误判为处格 — `adhigatamagge`／`sacchikatanirodhe` 的 nissaya 是 `ရအပ်ပြီးသော အရိယာမဂ် ရှိကုန်သော`／`မျက်မှောက်ပြုအပ်ပြီးသော နိဗ္ဗာန်ရှိကုန်သော`，即有财释（bahubbīhi）复数，与 `paṭipajjamāne`、`apatamāne` 同为 nissaya 补出的宾语 `သတ္တေ= တို့ကို`（众生）的修饰语；译文读成处格「在已证得的道、已现证的灭上…」，把「已证道、已证灭」的主体从众生转成了修行的处所。
- **建议**：「…护持那些已证得道、已现证灭、依所教导而修行、因而不堕恶趣的众生，因此得到“法”这个称号的…」
- **问题（同句，建议）**：
  - nissaya 补出的是 `satte`（众生），译文作「人」，宜用「众生」；
  - `bhajiṃ seviṃ` 的 nissaya 是 `မှီဝဲပြီ`（第一人称已完成），译文「也就是亲近、依止」丢了人称与时态，宜作「也就是我已亲近、已依止」；
  - `pariyattiyā saddhiṃ nava lokuttaradhammaṃ`：nissaya 是「**与教典一起**的九种出世间法」，译文「连同教典在内的九种出世间法」容易被读成教典算在九法之内，宜作「九种出世间法连同教典（pariyatti）」。

## §678 句 204-678-81-91

- **问题**：所指笼统 — `bhavakantārā` 的 nissaya 是 `ဘဝသုံးပါးတည်းဟူသော ခရီးခဲမှ`（从三有这条险途中，夺格），译文「生死的旷野」漏掉「三有」。
- **建议**：「使众生渡出三有这片险途」。

## §678 句 204-678-92-101

- **问题**：词义过窄 — `kārānaṃ` 的 nissaya 是 `ကောင်းမှုတို့၏`（属格复数，善行／所作），译文「供养」限定到了财施。
- **建议**：「僧也因为使众生即使所作微小也能获得广大的果报…」

## §678 句 204-678-102-114（必改）

- **问题**：格读误 — nissaya 明示 `ရတနတ္တယံ= ရတနာသုံးပါးအပေါင်းကို`（宾格），它是 `gato avagato jānaṃ`（了知）的宾语；译文作「三宝就是归依」，把宾格读成了主语，后半句又另起「把它当作归依而前往」，整句的主谓宾全错位。
- **建议**：「依这个意思，三宝就是归依；正由于这个缘故，“saraṇaṃ gato”里的 gato 是 avagato、jānaṃ——即『了知三宝为归依』的意思。」
