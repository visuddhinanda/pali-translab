# Review — 204:127-132（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 说明：本次只做 nissaya 词法复核（格、数、句法角色、隐含成分）。
> nissaya 对齐情况：§129 整段引文（`Ettha ca ñatticatutthakammaṃ … karomā`）的 nissaya 以 `။ပ။` 省略，无逐词依据，故该段不出词法意见；而 §128 句 13-50 尾部（`ñatticatutthena … saṅkhipitvā vaṇṇayissāma`）的 nissaya 单元实际排在 §129 的三行里，已按此错位对应核查。

## 跨段一致性

- **指示代词 tattha / idha / ettha**（6 处，本 chunk 最成系统的问题）：nissaya 每处都点出具体所指——`တတ္ထ= ထိုနှစ်ပါးကုန်သော သမ္ဗန္ဓတို့တွင်`（两种关联之中）、`ဣဓ= ဤ အဋ္ဌကထာ၌`（这部义注中）、`တတ္ထ ဝစနေ= ထို စူဠဂဏ္ဌိစကား၌`（《小难句解》的那段话中）、`ဣဓ ပန= ဤ မဇ္ဈိမဂဏ္ဌိစကား၌ကား`（《中难句解》这段话中）、`ဧတ္ထ= ဤနှစ်ပါးကုန်သော ဝိကပ်တို့တွင်`（这两种解释之中）、`ဧတ္ထာပိ= ဤဝဏ္ဏနာ အစရှိသောပါဌ်၌လည်း`（「vaṇṇanā」等这段文句中也）。译文一律作「这里／那里」，指代全部落空。→ 逐处按下列各句落实。
- **被引颂文 `tato ca bhāsantaramevā…`**：§127 三处处理不一——句 2-36 给中文括注且用「〔舍弃〕」补字，句 46-63 只留巴利无中文，句 104-128 给中文。建议统一为同一中文括注，补字改用全角圆括号。
- **`vattum arahati`**：句 75-89 译「不可能」，句 176-215 译「是讲不通的」，两处不一致，且都偏离 nissaya 的 `န အရဟတိ= မထိုက်`（不应当／不配）。建议统一为「不应当这样说」一类。
- **小词 api / pi**：多数已译出（「也／连…也／都」），但句 127-2-36（`သံဝဏ္ဏနာပိ`）、128-13-50（`ကမ္မာနမ္ပိ`）、131-9-26（`အဝုတ္တာနံ`…`ဝစနာနမ္ပိ`）三处漏译。
- **bhāsantara(pariccāga)**：nissaya 一律释为 `သီဟိုဠ်ဘာသာကို စွန့်ခြင်း`（舍弃僧伽罗语），译文作「语言差别」；§128 句 6-12 已点明是僧伽罗语，建议其余各处（127-129-158 / 127-159-175 / 131-35-53 / 131-54-71）与之呼应，首次出现处补出「（僧伽罗语）」。
- **语体**：§130 句 2-18「即不使有所剩余」半文半白（即／所），与同句「哪怕一点点也不舍弃」的现代语体不一致 → 「也就是不让它有剩余」。
- 术语映射（aṭṭhakathā=义注／vaṇṇanā·saṃvaṇṇanā=注释／pamāṇa=权威／sambandha=关联／anusikkhitabba=随学／vinicchaya=判定）在本 chunk 内无漂移。

## §127 句 204-127-2-36

- **问题**：隐含成分 — `တတ္ထ= ထိုနှစ်ပါးကုန်သော သမ္ဗန္ဓတို့တွင်`，tattha 是「在那两种关联之中」，译「这里」丢了「两者之中取其一」的限定，下文「先说的／后说的」两种关联因此失去落点。
- **建议**：「在那两种关联之中，按先说的那种…」。
- **问题**：漏译小词 — `သံဝဏ္ဏနာပိ= သည်လည်း`，vuccamānāpi saṃvaṇṇanā 的 api 未译。
- **建议**：「现在要讲的这部注释**也**只是在言辞上与义注不同」。
- **问题**：格式 — 补字用「〔舍弃〕」，与 style 规定的全角圆括号不一致。

## §127 句 204-127-37-45

- **问题**：指代 — `ဣဓ= ဤ အဋ္ဌကထာ၌`，idha 指「这部义注」，译「这里所讲的」读不出所指。
- **建议**：「这部义注中所讲的为什么也是权威呢」。
- **问题**（可选补出）：`ဝုတ္တသမ္ဗန္ဓဝသေန= ဝဇိရဗုဒ္ဓိ၌ ဆိုအပ်သော သမ္ဗန်၏ အစွမ်းအားဖြင့်` — nissaya 点明「后说的关联」出自《金刚觉》（Vajirabuddhi）。若补出，宜用夹注，勿并入正文。

## §127 句 204-127-75-89

- **问题**：语气词义 — `န အရဟတိ= မထိုက်` 是「不应当／不配」，译「他不可能这样混乱地来讲」改成了可能性判断。
- **建议**：「他不至于／不应当这样混乱地讲」。
- **问题**：隐含成分 — `ယထာဌိတဿ သမ္ဗန္ဓဝသေနေဝ= တည်တိုင်းသောပုဒ်၏ စပ်ခြင်း၏ အစွမ်းအားဖြင့်သာလျှင်`，nissaya 补出属格的中心词 `ပုဒ်`（pada，文句），且有 `သာလျှင်`（唯）。
- **建议**：「只按文句原样的关联方式来说明」。

## §127 句 204-127-90-91

- **问题**：隐含成分 — `ကထံ ဒဿယိဿာမ= မူကား`，nissaya 补出省略的谓语 dassayissāma。
- **建议**：「怎样说明呢？」

## §127 句 204-127-176-215

- **问题**：同一词两译 — `ဝတ္တုံ န အရဟတိ= မထိုက်` 译「是讲不通的」，与句 75-89 的「不可能」不一致（后半的「也不恰当」对应 `ယုတ္တရူပါ … နာပိဟောတိ`，可保留）。
- **建议**：「…却说…应当恭敬随学，是不应当的」。

## §128 句 204-128-13-50

- **问题**：漏译小词 — `စတုန္နံ= ကုန်သော။ ကမ္မာနမ္ပိ= တို့၏လည်း`，catunnampi 的 pi 未译。
- **建议**：「对白告羯磨（apalokana）等四种羯磨**也**作的详细讲说」。
- 其余按错位对应到 §129 各行的 nissaya（`ဝိတ္ထာရကထာ ဝိယ` / `ဝိတ္ထာရမဂ္ဂံ … သင်္ခပိတွာ` / `ဝဏ္ဏယိဿာမ= ကုန်အံ့`）核过，词法无误。

## §128 句 204-128-51-54

- **问题**：主语误导（必改）— nissaya 明给施事 `အဋ္ဌကထာစရိယော= သည်။ ဝက္ခတိ= လတ္တံ့`，vakkhati 的主语是义注的作者；而前一句句尾主语是「我们」，译文「他后面会说」把指代引向了错处。
- **建议**：「确实如此，义注的作者后面会说：」。

## §131 句 204-131-9-26

- **问题**：漏译小词 — `အဝုတ္တာနံ= မဆိုအပ်ကုန်သေးသော`，与 `ဝစနာနမ္ပိ` 的 pi 一并未译出。
- **建议**：「…只说“这是经师们的责任”而**连**这些都还没有解释的那些经藏语句的意义」。

## §131 句 204-131-35-53

- **问题**：隐含成分 — `ဧတ္ထ= ဤနှစ်ပါးကုန်သော ဝိကပ်တို့တွင်`，ettha 是「在这两种解释之中」，译「这里」未交代与下一句「后一种」的对举关系。
- **建议**：「在这两种解释之中，就第一种意义解释来说…」。

## §131 句 204-131-90-96

- **问题**：指代丢失兼改读 — `တတ္ထ ဝစနေ= ထို စူဠဂဏ္ဌိစကား၌`，tattha 指《小难句解》的那段话；译「照那样连接」换成了方式状语，所指没了。
- **建议**：「在《小难句解》的那种说法中，“api”一词把前面所说的殊胜功用与权威性两点合并起来」。

## §131 句 204-131-97-109

- **问题**：句法误读（必改）— `အနုသိက္ခိတဗ္ဗာပိ= သင်လည်း သင်ထိုက်၏` 是缅文为承载 api 而重复动词的惯用格式，并非两个谓语；译文「应当恭敬地随学，而且也是应当随学的」据此拆成两句，重复且走义。api 的落点在 anusikkhitabbā 上。
- **建议**：「所说的关联是“所以**也**应当恭敬地随学”」。

## §131 句 204-131-110-124

- **问题**：指代 — `ဣဓ ပန= ဤ မဇ္ဈိမဂဏ္ဌိစကား၌ကား`，ettha 指《中难句解》这一说法；译「这里概括的是」易被读成「本文此处」。
- **建议**：「而《中难句解》这一说法所概括的是这样一层意思：…」。

## §131 句 204-131-125-132

- **问题**：指代 — `ဧတ္ထာပိ= ဤဝဏ္ဏနာ အစရှိသောပါဌ်၌လည်း`，指「『vaṇṇanāpi』等这段文句中也」。
- **问题**：正文插入推断 — `ယထာဌိတဝသေနေဝ= ထည်တိုင်းသောပါဠိ၏ အစွမ်းအားဖြင့်` 只说「按所立的圣典文句原样」，译文括注「（即“api（也）”原本所在之处）」是译者推断，不是 nissaya 的说法。
- **建议**：「在「vaṇṇanāpi」等这段文句里也应当按圣典文句原样来理解“api”一词的意思」，括注删去或移入脚注。
