## 被解释词（父层逐字核对）

父层注入段落为 138:639–649、659–692，中间 138:650–658 不在本次注入范围内；本 chunk 的黑体词多数（etaṃ / tannissaraṇato / kāmadhātu / nekkhammaṃ / uttarapadepi / ito / esa daṭṭhabbo / sādhāraṇavacanena / tadaṅgavivekādayo / kāyavivekādayo / niddese / tattheva / evañhi sati / vatthukāmehipi / tena / purimena / ettha / etesaṃ / saṃkilesavatthuppahānaṃ / lolabhāvo / bālabhāvo / payogasuddhi / āsayaposanaṃ / kāmesu / anekabhedo / kāmacchandoyeva / akusalapariyāpannopi / jhānapaṭipakkhato）落在该区间，无法比对，不作结论。可比对的部分如下。

**必改（与父层不一致）**

- 句 204-1352-38-55：**chandarāgo** 译“意欲之贪”；父层 138-648-36-44 定作“**意欲贪**”（“意欲是欲，贪是欲，意欲贪是欲”）。→ 改“意欲贪”。
- 句 204-1352-112-122：**saṅkapparāgo** 译“思量之贪”；父层 138-648-45-57 定作“**思量贪**”。→ 改“思量贪”。

**已核一致**（无需改）：kiñcāpi tattha katame kāmā（虽然…这里，什么是欲）／chando 意欲／rāgo 贪／saṅkappo 思量／kāmā 欲／seyyathidaṃ 就是这样／viviccitvā 分离／vinā hutvā apasakkitvā 不和它们在一起、从它们那里退开／vivicceva kāmehi 远离各种欲望／vivicca akusalehi dhammehi 远离各种不善法／paṭhamajjhānaṃ 第一禅／kathaṃ 怎么说呢／yathāha 正如所说／vibhaṅge 《分别论》。

## 跨段一致性

- **“欲贪”一名两用**：kāmacchanda（§1355 句 204-1355-24-27“指的是从欲贪”，nissaya 作 ကာမစ္ဆန္ဒနီဝရဏမှ；§1357 句 204-1357-9-19“正是欲贪”）与 kāmarāga（§1354 句 204-1354-82-99“由于是欲贪的对立面”、114-123、124-148）在本 chunk 都译“欲贪”，读者无法分辨。父层 138-648-63-73 已把 kāmacchanda 定作“欲贪”。→ 建议 kāmacchanda 保留“欲贪”，kāmarāga 首次出现夹注巴利原词区分（如“欲贪（kāmarāga）”），或改“欲染”；§1357 句 204-1357-9-19 的 lemma 与其释语（“以欲为本性的意欲”）之间也宜补夹注“欲贪（kāmacchanda）…意欲（chanda）”，否则释义与词形脱节。
- **vacana 译法不一**：句 204-1354-2-21 译“决定语”（avadhāraṇavacanaṃ）、句 204-1356-61-64 译“属格”（sāmivacanaṃ），而句 204-1355-35-38 译“通用的说法”（sādhāraṇavacanena）。nissaya 三处均作 သဒ္ဒါ／ဝိဘတ္တိ，即“词／语”。→ 统一为“通用的词”。
- **bālabhāva 译法不一**：句 204-1356-83-86 作“愚痴状态”，句 204-1356-87-102 作“愚痴”，同一词同一上下文。→ 统一（建议都作“愚痴的状态”，与 nissaya မိုက်မဲသောအဖြစ် 对应）。
- **语体**：“浓厚之贪”“意欲之贪”“思量之贪”（句 204-1352-38-55、112-122）用文言“之”字结构；后两处按上条改作“意欲贪／思量贪”，前一处改“浓厚的贪”。
- **kāmā 的出离方向前后相反**：见下句级 §1354 条。

## §1352 句 204-1352-2-37

- **问题**：格 — `pāḷiyā` nissaya 作具格（`ပါဠိယာ= ပါဠိအားဖြင့်`），全句是“想按义注的方式解说那段以‘远离各种欲望’等方式展开的**圣典所说的**、《禅分别》里也讲过的意思”；译文“对于…圣典文句，它的意思”把具格降为话题，`pāḷiyā–vuttaṃ atthaṃ` 的施事关系丢失。
- **问题**：专名 — `vibhaṅgapāḷiyaṃ` nissaya 作 `ဈာနဝိဘင်းပါဠိတော်၌`，同句前面 `jhānavibhaṅge` 已译“《禅分别》”，此处却作“《分别论》圣典”，一句之内同一书两名。
- **建议**：“现在，对于以‘远离各种欲望’等方式展开的圣典文句所说、《禅分别》（《分别论》508）里也讲过的那个意思，义注作者想要按义注的方式来解说，为了说明不采用《禅分别》圣典所用的那种方式的理由，就说了……”（`saṃvaṇṇetukāmo` 作主格、主语补出“义注作者”，与 nissaya `အဋ္ဌကထာဆရာသည်` 一致，这部分正确，保留。）

## §1352 句 204-1352-64-82

- **问题**：格 — `uparūpari kilesuppattiyā` nissaya 作原因（`ကိလေသုပ္ပတ္တိယာ= ကိလေသာ၏ ဖြစ်ခြင်းကြောင့်`），译文“**为了**让烦恼一层一层地生起”读成目的。
- **问题**：格（次要）— `avayave` nissaya 作处格（`အဝယဝေ= အစိပ်အစိပ်၌`），译文“把各个肢体部分合拢起来”作宾语。
- **建议**：“……就是在各个肢体部分上把它们合拢起来，按‘女人、男人’等等当作一个整体，由于烦恼一层一层地生起而对相所作的构想。”

## §1353 句 204-1353-2-12

- **问题**：数 — nissaya 把 `taṃ` 释为“那个（义注里所说的）**方法**”（`ထိုအဋ္ဌကထာ၌ ဆိုအပ်သောနည်းဟူသည်`），单数指一法；译文“那是**哪些**呢”作复数。
- **建议**：“意思是‘那（方法）是哪一种呢’，或者‘那是怎样的呢’。”

## §1354 句 204-1354-2-21

- **问题**：指称不清，自相矛盾 — `pubbapade` nissaya 指“vivicceva kāmehi”这一前句；`avadhāraṇassa akatattā` nissaya 明确作“没有把决定语作成‘**kāmehi eva**’”（`"ကာမေဟိ ဧဝါ"တိ ... အဝဓါရဏဿ ... အကတတ္တာ`）。译文先说“只用在**前一句**上”，再说“并没有对**那一句**用决定语”，两处所指在中文里会被读成同一句，反成自相矛盾。
- **建议**：“……指的是只用在前一句上的决定语（eva）；不过不应当把它理解成‘唯独是各种欲望’，因为并没有把决定语加在‘各种欲望’这个词上。”

## §1354 句 204-1354-32-36（连带 37-46）

- **问题**：格／方向 — nissaya 把答语 `kāmā` 释为从格（`ကာမာ= ကာမရာဂမှ ... နိဂ္ဂစ္ဆန္တိ`），即“从欲（贪）脱出”；译文句 204-1354-32-36 作主格“是各种欲望（脱出）”，而紧接的句 204-1354-37-46 又译“那些欲望的出离”（欲望为所离）。两句在中文里方向相反。
- **建议**：依 nissaya 统一为“从…脱出”的方向，如“脱出的是从什么脱出呢？——是从各种欲望。”；若保留主格读法，则句 204-1354-37-46 须改成“那些欲望的被脱除”一类明确说法，不能两存。

## §1354 句 204-1354-47-68

- **问题**：术语所指偏宽 — `kāmānameva` nissaya 作 `ကိလေသကာမတို့၏သာလျှင်`（烦恼欲），译文作“各种欲望”，而本段正在分辨事欲／烦恼欲（句 204-1355-67-98 已出现“烦恼欲”）。
- **建议**：“为什么这只是**烦恼欲**的出离，而不是瞋等的出离呢”。

## §1354 句 204-1354-100-113

- **问题（必改）**：隐含成分 — nissaya 对 mettā／karuṇā 两小句补出的谓语是 `နိဿရဏံ`（出离），即“就像慈是瞋的出离、悲是害的出离”（`မေတ္တာ= ... ဗျာပါဒဿ= ... နိဿရဏံ ယထာ`）；只有第三小句才是 `ujuvipaccanīkabhūtaṃ`（直接相违）。译文把前两小句也拉平成“直接相违”，补出的成分与 nissaya 不符，也抹掉了本段“出离／对立面”两个层次的递进。
- **建议**：“就像慈是瞋的出离、悲是害的出离，同样，这个禅就是与欲贪（kāmarāga）直接相违的。”

## §1355 句 204-1355-35-38

- **问题**：见“跨段一致性”第二条，`vacana` 作“说法”与前后“决定语／属格”不一致。
- **建议**：“**用通用的词**，是指用对一切分离都通用的那个词。”

## §1356 句 204-1356-21-48

- **问题**：语气 — nissaya 在 `vutto` 后补 `သိယာ ... ဣတိ ဝဒေယျ`（当作“就会说／就该说”的假设），全句是“若…则与烦恼欲的分离无论如何都算说到了”；译文“都已经被说到了”把假设说成既成。
- **问题**：夹注格式 — “选别（从整体中指出其中一部分）”用中文括注解释语法术语；按 style，夹注只附巴利原词。
- **建议**：“……那么无论哪一种说法，与烦恼欲的分离就都算已经说到了，所以他说……”；括注改为“选别（niddhāraṇa）”，后文 204-1356-61-64、204-1356-140-144 两处“选别”不再重复夹注。

## §1356 句 204-1356-55-60

- **问题**：格 — nissaya 在 `padānaṃ` 上标 `တွင်`（在…当中），与紧接的句 204-1356-61-64“这个属格是用在选别上的”相呼应；译文“那两句**的**”只给了普通属格，选别义未出。
- **建议**：“**这些当中**，指的是上面所说那两句当中。”

## §1356 句 204-1356-70-82

- **问题**：释义 — nissaya 把 `lolabhāvo` 释为 `လျပ်ပေါ်လော်လီသော အဖြစ်`（心摇荡、到处贪求的轻躁），与下文“对各处的色等生起贪爱”相合；译文“贪婪”丢了“到处摇荡”这一层。
- **建议**：“所谓**到处贪求的轻躁**，就是对各处的色等生起贪爱。”

## §1356 句 204-1356-103-109

- **问题（必改）**：指代 — `tabbivekena` nissaya 明确作“与**杀生等**（不清净行为）分离”（`တဗ္ဗိဝိဝေကေန= ထိုပါဏာတိပါတအစရှိသည်တို့မှကင်းဆိတ်သဖြင့်`）；译文作“与那些**欲**分离”，指代对象被换掉，与“显明行为的清净”这一结论也接不上。
- **建议**：“因为为了得到五欲的享受，就会有杀生等不清净的行为，所以与那些行为分离，就显明了**行为的清净**。”

## 备注：nissaya 疑有讹误（译文按正读处理，无须改）

- 句 204-1354-69-75：nissaya 作 `သမတိက္ကမပဋိပဒါဘာဝတော= ... မဖြစ်ခြင်းကြောင့်`（否定），与 `samatikkamapaṭipadābhāvato` 不合；译文“因为它是超越整个欲有的道路”为正读。
- 句 204-1354-76-81：nissaya 作 `ကာမပရိညဘာဝံ= ... မရှိခြင်းကို`（否定），与上下文相违；译文“这个禅就是对各种欲望的遍知”为正读。
- 句 204-1353-45-78：nissaya 对 `kāmavivekappahānassa` 的释语（`ကာမတို့၏ ကင်းဆိတ်ခြင်းကိုပယ်သဖြင့်`）不通，词级无从取准；译文按“离欲·舍欲”并列读出，可通。
