## 被解释词与父层对照

- `Dubbhikkhakathā`（§1589）：父层 138-765 作「饥荒一节」，本层「饥荒一节结束」逐字一致 ✅
- `Evaṃdubbhikkhe`（§1580）：父层 138-766 **Dubbhikkhā** 作「闹饥荒」，本层「在这样闹饥荒的」沿用「闹饥荒」✅
- `imāya sallahukavuttitāya`（§1580）：父层 138-773 `sallahukavuttitā` 用「简省」，本层「简省的生活」用词一致 ✅
- `Verañjā`（§1588 释文）：父层一律「韦兰若」，本层一致 ✅

## 跨段一致性

- **vighāta / cittavighāta / cittapīḷā 三词同译「苦恼」**：§1580-120-129「内心苦恼」(cittavighāta)、§1580-176-189「苦恼」(vighāto vā)、同句「内心的苦恼」(cittapīḷā)。nissaya 对 cittapīḷā 作 `စိတ်၏ နှိပ်စက်ခြင်း`（心的逼迫），对 vighāta 作 `ပင်ပန်းခြင်း`（疲损）→ 建议 vighāta 统一「苦恼」，cittapīḷā 改「内心的煎迫」，使 §1580 末两句「或者思虑／或者苦恼」与释文的区分看得出来。
- **icchācāra 译名不统一**：§1580-142-163 黑体作「贪欲的行径」，同句释文与 §1587-17-46 作「贪欲行径」→ 统一为「贪欲行径」。
- **paṭipatti / paṭipadā**：§1588-57-64 作「行持」，§1588-65-72 作「行道」。两词确属近义，但同一段内两种译名易被读成不同概念 → 建议统一「行道」，或保留区分而在 §1588-65-72 加夹注。
- **atimāna 译名**：§1588-92-95 与 96-111 均作「傲慢」，而 nissaya 两处都作 `အလွန်မာန်မူခြင်း`（过度的骄慢）→ 建议统一作「过慢」，否则「正是因为傲慢是卑下的，才把它叫做下慢」一句读者看不出 ati- 与 o- 的对举。
- **圆括号三种用法混杂**：§1580-58-70 / 71-75 的「（时候、地方）」是补足语，§1588-51-56「（svāyaṃ）」、§1588-92-95「（omāna）」是夹注原词。style.md 规定圆括号用于首次夹注巴利原词 → 补足语不要入括号（改为「在这样闹饥荒的时候或地方」），括号只留给原词夹注。
- **同一篇名两种写法**：§1581-17-55 作《入雨安居篇的注释》，§1581-84-109 作《入雨安居篇》→ 建议统一主名《入雨安居篇》，注释层加「义注」或「的注释」后缀即可。

## §1580 句 204-1580-2-14

- **问题**：隐含成分／格 — nissaya 把被释词标为 `ပဒေန`（具格，「以『没有什么要说的』这一语」），主格主语是 `ဝစနံ= သည်`（可说的新话）。译文「**没有什么要说的**，是表明……」把被释词当话题，具格的「以此句显示」关系丢失。
- **建议**：改「用**没有什么要说的**这句话表明：由于前面已经讲过同样的道理，这里没有什么新的话需要说」。

## §1580 句 204-1580-25-40

- **问题**：格 — `pasaṃsāyaṃ` 的 nissaya 是 `ချီးမွမ်းခြင်း အနက်၌`（在赞叹的**义**上），译文「赞叹时使用的重复语」把「义」读成了时间。
- **建议**：改「这是表示赞叹义的重复语」。

## §1580 句 204-1580-48-57

- **问题**：漏译 — nissaya 保留 `ဓမ္မံဝါဒေသေဿာမာ` 的 `ဝါ`（或），译文「我们要说法」把 `vā` 丢了，与上句「两种理由」的对举接不上。
- **建议**：改「就是取“我们或者说法”这样说到的那一种理由」。

## §1580 句 204-1580-71-75

- **问题**：属格所指 — nissaya 明确 `ဧတဿေဝ= ထိုဒုဗ္ဘိက္ခေဟူသော ပုဒ်၏သာလျှင်`（正是前面 evaṃdubbhikkhe **一词**的），译文「对同一个意思的说明」把属格对象换成了「意思」，atthadīpana（词义说明）的对象消失。**必改**
- **建议**：改「这是对前面『在这样闹饥荒的』一词的词义说明」。

## §1580 句 204-1580-76-87

- **问题**：句法层次 — nissaya 作 `ဘာဇနာဒိပရိဟရဏဝသေန`（方式状语）+ `ဗဟုဘဏ္ဍိကတာယ ၏`（属格受 `အဘာဝတော` 支配），即「没有**因携带器皿等而物品繁多**的情形」。译文拆成「不必带锅碗 → 所以没有器物累赘」两层因果，把方式状语升成了独立原因。
- **建议**：改「因为并没有由于携带钵盂等器物而积攒许多物品的情形，所以说**“凭着这样简省的生活”**」。

## §1580 句 204-1580-104-119

- **问题 1**：主谓方向 — nissaya 以 `အဘာဝေါ= မဖြစ်ခြင်းသည်`（主格）为主语、`ဒုဗ္ဘိက္ခံ= မည်၏`（名为）为谓语，即「乞食的缺乏**叫做**饥荒」。译文「饥荒就是乞食的缺乏」方向反了，且与 §1588-8-14「……的饭，就是**米肉饭**」的处理不一致。**必改**
- **问题 2**：增译 — 「词头表示“缺少”」在巴利原文与 nissaya 中都没有依据，nissaya 对本句只给 `နိမ္မက္ခိကန္တိအာဒီသုဝိယ= ကဲ့သို့`。**必改**
- **建议**：改「**饥荒被征服了**——这里，乞食的缺乏就叫做**饥荒**，就像“无蝇（nimmakkhika）”等说法那样」；要保留前缀的解释就移入脚注。

## §1580 句 204-1580-120-129

- **问题**：隐含成分 — `vase vattito` 的 nissaya 是 `ဝသေ= မိမိတို့၏အလိုသို့ / ဝတ္တိတော= လိုက်စေ၏`（被使之随顺比丘们自己的意愿）。译文「被置于掌控之下」掩掉了「随顺谁的意愿」。
- **建议**：改「乞食的缺乏本身就被比丘们征服了，被使之随顺他们自己的心意」。

## §1580 句 204-1580-164-175

- **问题**：语体 + 隐含成分 — 「针对……这一点，所以说」句式生硬（「针对」与「所以」并用）；`cittuppādamatta` 的 nissaya 是 `စိတ္တုပ္ပါဒမတ္တဿပိ`（连仅仅生起一念这件事），译文「这样的心念」弱化了「仅仅／连……都」。
- **建议**：改「正是针对连这样的念头都没有生起过，才说**“或者思虑”**」。

## §1581 句 204-1581-17-55

- **问题**：词义 — `vippavāsa` 的 nissaya 是 `ညဉ့်ကင်း၍ နေခြင်းကို`（离宿、夜不在住处），译文「离开住处」把核心的「过夜」丢了，而本段正是在解释「断**夜**」为何这样称呼。**必改**
- **建议**：改「把因七日事外出而在外离宿称为“断夜”，这是义注的用语」。

## §1581 句 204-1581-71-83

- **问题**：格 — `aññathā` 的 nissaya 是 `အညထာ= အားဖြင့် / နဟောတိ`（不是以别的方式／由别的缘故而有），译文「不是别的情况」偏泛。
- **建议**：改「所谓断夜是因七日事而有的，不是由别的缘故而有」。

## §1583 句 204-1583-24-45

- **问题**：句法角色 — nissaya 把义注这段话标为 `ဝစနေနပိ= နှင့်လည်း`（具格／共格，比较的对象），`သံသန္ဒနတော`（相符）的主体是上文「有断安居理由时也许可七日事」这一主张。译文「因为这段义注的话也与上面所说一致」把义注之语当成了主语，论证方向反了。
- **建议**：改「因为这一说法也与这段义注的话相符」。

## §1584 句 204-1584-2-6

- **问题**：所指 — nissaya 对 `kenaci` 给出具体人：`အချို့သော ဝဇီရဗုဒ္ဓိပုဂ္ဂိုလ်သည်`（金刚觉 Vajirabuddhi 某人），译文只作「有人」，下文 §1586 对这一说法的严厉驳斥失去对象。
- **建议**：改「不过**有人**（指金刚觉 Vajirabuddhi）这样说过」，或在脚注注明 nissaya 的指认。

## §1586 句 204-1586-9-20

- **问题 1**：指代 — nissaya 把 `aṭṭhakathāya virujjhanato`、`yuttiabhāvato` 两个原因挂在「持律者们的不赞同」上（`ဝိနယဓရာနံ အနိစ္ဆာယ ကာရဏံ န ဒိဿတိ`，后接 `ကသ္မာ ဟူမူကား`）。译文「那种说法既与义注相违」中的「那种说法」极易被读成前文 eke 的主张（而作者是支持该主张的），指反了。**必改**
- **问题 2**：语体 — 「理由何在」是文言句式（style.md 禁例）。**必改**
- **建议**：改「因为看不出持律者们不赞同的理由在哪里——这种不赞同既与义注相违，也没有道理」。

## §1586 句 204-1586-39-56

- **记录**（不改）：`anurūpaparivitakkanapaadīpanaṃ` 疑为 `-paridīpanaṃ` 之讹（对照同句 `visesatthaparidīpanaṃ`），nissaya 作 `ပရိဝိတက္ကန ပအဒီပနံ`，同样带此讹形。译文按 paridīpana 理解，处理正确。

## §1586 句 204-1586-57-65

- **问题**：格 — `purimikāya` 的 nissaya 是 `ပုရိမိကာယ= ၌`（处格，在前安居期间），译文「就前安居来说」读成了论题范围。
- **建议**：改「所以在前安居期间，即使断了安居也不犯」。

## §1586 句 204-1586-66-74

- **问题**：语体 — 「而因为不想入后安居而离开」一句两个「而」，读来绕口。
- **建议**：改「至于后安居，因为不想入安居而离开，也没有过失，因为后安居的入雨安居日还没有到」。

## §1587 句 204-1587-2-11

- **问题**：格 — `kismiñci guṇe` 的 nissaya 是 `ကိသ္မိဉ္စိဂုဏေ= ၌`（处格，在任何功德上），译文「因为自己有什么功德就推崇自己」把处格读成了原因；同时黑体「不在任何方面自许」与释文「不会因为……推崇自己」接不上。**必改**
- **建议**：改「**他们不在任何方面自许**，是说他们在任何功德上都不以推崇的方式看待自己」。

## §1587 句 204-1587-12-16

- **问题**：格 — `paṭiladdhajjhānādiguṇavasena` 的 nissaya 是 `ဂုဏဝသေန= အားဖြင့်`（具格，以……为方式），译文把「功德」当成了「宣称」的宾语。
- **建议**：改「**宣称**，就是以自己所证得的禅定等功德来宣说」。

## §1588 句 204-1588-8-14

- **问题**：词义 — `sālitaṇḍula` 的 nissaya 是 `သလေးဆန်`（sāli 米，即粳米），「上等米」是引申。
- **建议**：改「用粳米（sāli）做成、浇上肉的饭，就是**米肉饭**」。

## §1588 句 204-1588-51-56

- **问题**：冗赘 + 体例 — nissaya 只给 `သောအယံဇနပဒေါ= သည်`（主格「这个地区」），并未逐词区分 so／ayaṃ。译文「就是 so ayaṃ（那个、这个），指的是这个地区」把连声拆解搬进正文，且拉丁转写裸露在正文中（style.md 规定原词用圆括号夹注）。
- **建议**：改「**这个**（svāyaṃ = so ayaṃ），指的是这个地区」。

## §1588 句 204-1588-92-95

- **问题**：词义 — `atimāna` 的 nissaya 是 `အလွန်မာန်မူခြင်း`（过度的骄慢），「傲慢」丢了 ati-，下一句的对举因此看不出来。
- **建议**：改「**下慢**（omāna），就是过慢（atimāna，过度的骄慢）」，并与 §1588-96-111 统一。

## §1588 句 204-1588-96-111

- **问题**：增译 — `hīḷetvā maññanaṃ` 的 nissaya 是 `ဟီဠေတွာ= ရှုတ်ချ၍ / မညနံ= ကို`，没有「别人」这一受者。
- **建议**：改「而不是指轻蔑地看待（而说的 omāna）」，受者不要补出。
