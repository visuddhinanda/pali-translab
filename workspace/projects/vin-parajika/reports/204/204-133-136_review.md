# Review — 204:133-136（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次仅作 nissaya 词级复核：格、数、主宾属关系、隐含成分）

## 被解释词与父层对照

- 已可逐字核对的三处，与父层定稿**完全一致**，无须改动：
  - §135 引 `tena samayena buddho bhagavā verañjāyaṃ viharati` → “那时，佛陀、世尊住在毗兰若”（父层 138-494-37-53、138-506-11-24：“佛陀、世尊住在毗兰若”“**住在**​**毗兰若**”）
  - §135 引 `nidānena ādikalyāṇaṃ … nigamanena pariyosānakalyāṇaṃ` → “以序分而言是开头好……以结语而言是结尾好”（父层 138-614-17-27 同字）
  - §135 `vinayassa atthavaṇṇanaṃ karissāmi` → “这样来作律的义释”（父层 138-493 “作律的义释”）；`anekappakārato dassayanto` → “从种种方面显示”（父层 138-492/493 “从种种方面”“加以显示”）
  - §133 `Bāhiranidānakathā` → “外缘起的叙说”（父层 138-69 同字）；§136-148-155 “第一次大结集”（父层 138-76 同字）
- 本 chunk 其余黑体词（tattha / tāva / vavatthapetabbo / mātikā / vuttaṃ yena / idaṃ / hi / attapaccakkhavacanaṃ / kenaci / gaṇṭhipade / āyasmatā / tañca）引自父层 138 的第 70–75 段，不在本次父层对照范围内，故未作机械核对；chunk 内部这些词的译法前后统一（见下）。

## 跨段一致性

- **“他”的指代混用（必改，全 chunk）**：nissaya 把说话主体分得很清楚——§134-2-33 `kattukāmo`、§135-2-15 `dassento`、§136-2-16 `dassento`、§136-122-134 `karonto` 一律补作 `အဋ္ဌကထာဆရာသည်`（义注师，主格施事）；而 §136-67-84 `attano`、§136-101-117 `attano` 作 `ကိုယ်တော်၏`（敬语属格，专指世尊）。译文四处“他说了……”与“他自己当着面说出来的话”“他自己在世的时候”混在同一 chunk 里，读者会把义注师与世尊读成同一个“他”。
  建议：nissaya 标 `အဋ္ဌကထာဆရာ` 处首次明示“义注师”（其后可用“他”）；nissaya 标 `ကိုယ်တော်` 处一律写“世尊”。
- `mātikā`→“纲目”（§134-85-88、§135-73-136、§136-2-16、§136-17-22 “纲目的词句”）、`uddesa/niddesa`→“总说/细说”、`niyameti/niyametabba`→“限定”、`vinayapiṭaka`→“律藏”、`satthu`→“导师”：前后一致，无漂移。
- `nidāna` 在 §133 题名作“外缘起”、在 §135 作“序分”。两种译法分别与父层定稿对应（138-69“外缘起的叙说”、138-614“序分”），**保持现状**，不要统一。
- §136-135-147 的词条 **“而那”** 与 §136-148-155 的展开“而优波离长老所说的那些话”不呼应；nissaya 两处都指明 `တံ ဝစနံ` = “那时……”等语。建议词条作 **“而那（些话）”**，展开句明示“而优波离长老所说的‘那时……’等等这些话”。

## §134 句 204-134-2-33

- **问题**：补出成分 — nissaya 为 `paṭiññātattā` 补出所承诺的对象：`ဝိနယသံဝဏ္ဏနာယ= ဝိနည်းပါဠိ၏ ဖွင့်ရာဖြစ်သော အဋ္ဌကထာသစ်၏`（律本文的解说，即这部新义注）。译文只靠引文承载，“承诺”本身无宾语。
- **建议**：“……已许下‘我要解释那部律’这样的承诺，要作律的义释”，或在“承诺”后补“作律的解说”。其余格关系与 nissaya 一致（`vinayo`=`ဝိနည်းကို` 宾格、`idha`=`ဤအရာ၌` 处格、`saṃvaṇṇetabbabhāvena`=`အဖြင့်အားဖြင့်` 具格，均已译出）。

## §134 句 204-134-47-56

- **问题**：补出成分丢失 — `tena` 的 nissaya 是 `ထို တာဝသဒ္ဒါဖြင့်`（具格，明指“用 tāva 这个词”），不是泛指的“由此”。
- **建议**：“他用这个词表明：我先确定什么是律，然后再对它作解释。”

## §134 句 204-134-85-88

- **问题**：取义偏松（可不改）— `uddeso` 的 nissaya 作 `အကျဉ်းပြကြောင်းဖြစ်သော စကားအစဉ်`（略示的语句次第），译文作“总说”。
- **建议**：与下句“细说语句”成对，“总说”可保留；若要贴 nissaya 可作“略说”。

## §135 句 204-135-16-72

- **问题**：补出成分 — `yena ca ābhataṃ` 的施事，nissaya 补作 `ဆရာအဆက်ဆက်သည်`（历代师承），译文“由谁所传来的”把它与前面的 `yena puggalena`（单一个人）混同了。
- **建议**：“由哪些代代相承的师长所传来的”。
- **问题**：词义 — `yathāvuttavidhānaṃ` 的 nissaya 是 `အစီအရင်ကို`（次第、安排），译“条目”偏窄。
- **建议**：“先把上面这样的次第说出来”。

## §136 句 204-136-2-16

- **问题**：指代 — `taṃ` 的 nissaya 明作 `ထိုမာတိကာကို`（宾格，那纲目），译文“那一点”指代不明。
- **建议**：“而现在，为了把那纲目单独提出来加以显示……”。

## §136 句 204-136-23-36

- **问题**：漏译限定词 — nissaya 作 `ဣဒမေဝ ဝစနံ= ဤတေန သမယေနအစရှိသော စကားကိုသာလျှင်`，既有 `eva`（သာလျှင်，“正是／只”），又明示“这一句话”即“那时……”等语。
- **建议**：“那么，为什么说是**正是**针对‘那时，佛陀、世尊’这一句话而说的呢？”

## §136 句 204-136-67-84

- **问题**：nissaya 覆盖与 pali 不同（记录，不必改）— 本句 nissaya 的第二个 `adhippāya` 作 `အာဟစ္စ ဘာသိတံ … န ဟောတိ`（不是亲口发声说出的话），没有 `bhagavatā` 的对应释义；而 pali 作 `bhagavatā vuttavacanaṃ na hoti`，`āhacca bhāsitaṃ` 一说在 pali 中归在下一句（`kenaci` 之说）。
- **建议**：译文依 pali 作“它不是世尊所说的话”，正确，保留；此处系注本归属差异，记在报告即可。另按 nissaya `attano`=`ကိုယ်တော်၏`，“他自己当着面说出来的话”宜明示为“世尊自己当面说出来的话”。

## §136 句 204-136-85-100

- **问题**：词义偏薄 — `āhacca bhāsitaṃ` 的 nissaya 是 `ဌာန်ကရိုဏ်းကို ထိစေ၍ ဟောအပ်သောစကား`（触及发音部位而发声说出的话），指“亲口出声说出”，译文“直接讲出来的话”把这层词义抹掉了。
- **建议**：“意思是说它不是（世尊）亲口发声说出来的话”。
- **问题**：补出成分 — `kenaci` 的 nissaya 指明为 `ဝဇိရဗုဒ္ဓိဋီကာဆရာသည်`（《金刚觉疏》的作者）。
- **建议**：“有人（指《金刚觉疏》的作者）说……”，与下一句的 **《难句解》** 形成两家对举，才看得出“这两种说法”指谁。

## §136 句 204-136-101-117

- **问题**：指代误 — `attano` 的 nissaya 是 `ကိုယ်တော်၏`（敬语属格，专指世尊），`dharamānakāle` = `ထင်ရှားရှိတော်မူသော ကာလ၌`（处格，在世之时）。译文“他自己在世的时候”，紧接上一句的“他”（义注师），会被读成义注师在世时。
- **建议**：“意思是说它不是在**世尊**在世的时候所说的话。”
