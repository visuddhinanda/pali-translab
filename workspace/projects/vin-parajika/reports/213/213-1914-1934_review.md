# Review — 213:1914-1934（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分段无 nissaya 单元，已略过）
> 本次为 nissaya 词法复核：只核格、数、主宾属关系与隐含成分，以及跨段术语/语体一致性。

## 被解释词对齐（同层 padabhājana ↔ §1921 戒条正文）

逐字核对 §1922–1927 的黑体引词与 §1921 戒条译文：

| 被解释词 | §1921 正文译法 | 释义段译法 | 结论 |
|---|---|---|---|
| Niṭṭhitacīvarasmiṃ | 衣已做成 | §1922 衣已做成 | ✅ |
| Ubbhatasmiṃ kathine | 迦絺那已撤去 | §1923 迦絺那已撤去 | ✅ |
| Dasāhaparamaṃ | 最多……十天 | §1924 最多十天 | ✅ |
| Atirekacīvaraṃ | 多余的衣 | §1925 多余的衣 | ✅ |
| Cīvaraṃ | 衣 | §1926 衣 | ✅ |
| Taṃ atikkāmayato nissaggiyaṃ | 超过这个期限的，犯尼萨耆波逸提 | §1927 超过这个期限就成为应舍之物 | ⚠ 不一致，见下 |

- **§1927-2-24 必改**：引词只到 `nissaggiyaṃ hoti`（无 `pācittiya`），但译文把 §1921 的 `nissaggiyaṃ pācittiyaṃ` 译作「犯尼萨耆波逸提」、把这里的 `nissaggiyaṃ` 译作「成为应舍之物」，同一个词在正文与释义段译法断开。nissaya 对 `nissaggiyaṃ` 一律释为 `စွန့်အပ်စွန့်ထိုက်သည်`（应舍、当舍），是动形容词而非罪名。建议 §1927 引词改为「**超过这个期限的，就成为应舍之物**」，与正文前半逐字对齐。

## 跨段一致性

- **`nissaggiya` 译法**：`nissaggiyā pācittiyā`（§1915 / §1918 / §1921 / §1932–1933 复合罪名）译「尼萨耆波逸提」，单用的 `nissaggiyaṃ`（§1927-2-24 / §1927-59 / §1928-15 / §1929-26 / §1930-12 / §1931-21 / §1933-2）译「应舍之物 / 应舍的」。分工本身与 nissaya 一致（复合为罪名，单用为「应舍」），但 §1927-2-24 的引词混用了两套，须按上条统一。
- **§1932 系列处格宾语「衣」的补出不一致**：nissaya 对每条的处格都明确标为「……的**衣**（သင်္ကန်း）＋၌」。译文 §1932-44/50/56/62 补出了「衣没有遗失／毁坏／被烧掉／被抢走」，而 §1932-2/12/19/26/32/38 未补（「已经超过十天」「没有受持」「没有说净」「没有送给别人」）。同一组平行句须统一补出受事，建议全部作「对已超过十天的衣……」「对没有受持的衣……」。
- **`dhāreti/dhāretabba` 一律译「收存」**：各段统一（§1917-65 / §1918 / §1920-49 / §1920-130 / §1921 / §1924），一致性没问题。但 nissaya 释为 `ဆောင်`（持、蓄）并括注 `ဝတ်ရုံသုံးစွဲ`（穿用、使用），语义含「持用」而不止于「存放」；§1917-65 诃责句处尤其偏窄，建议该处作「持用多余的衣」，或全篇统一为「持（用）」。
- **称呼**：`bhante`→「大德们」、`āvuso`→「贤友」、`āyasmantā`→「诸位尊者」，全 chunk 统一 ✅。
- **语体**：全 chunk 为现代书面汉语，未发现文言虚词或文言句式。

## §1917 句 213-1917-2-16
- **问题**：词级取义 — nissaya 把 `cetiye` 释为 `စေတီ၌` 并括注 `(နတ်ကွန်း)`，即「祠／庙」，并非舍利塔。译文「瞿昙迦塔庙」中的「塔」会让读者误以为是佛塔。
- **建议**：改「瞿昙迦庙（Gotamaka cetiya）」或「瞿昙迦神祠」。

## §1917 句 213-1917-17-26
- **问题**：补出成分 — nissaya 作 `ဘိက္ခူနံ= တို့အား／တို့အတွက်`（与格：为比丘们）、`တိစီဝရံ= …သည်`（主格，被许可者）、`အနုညာတံ= ခွင့်ပြုထားအပ်သည်`（被动）。译文「允许比丘拥有三衣」补出了 nissaya 没有的动词「拥有」。
- **建议**：「那时，世尊已经为比丘们许可了三衣。」

## §1917 句 213-1917-30-52
- **问题**：格与句法 — nissaya 作 `နဟာနံ= ရေချိုးရာအရပ်သို့`（括注 `ရေဆိပ်သို့`）＋`ဩတရန္တိ= သက်ဆင်းကြကုန်၏`，即 `nahānaṃ` 是表方向的宾格「洗浴处／水边」，`otarati` 是「下到」。译文「下水洗浴」把地点读成了动作。
- **建议**：「……用另一套三衣下到洗浴处。」
- 另：`aññeneva` 处 nissaya 专门加注，须按「与（寺院用的、洗浴用的）之外另一套」理解——译文三处「另一套三衣」已合此意 ✅。

## §1921 句 213-1921-2-16
- **问题**：格与句法 — 本句无 nissaya，但其 padabhājana §1922 的 nissaya 把 `Niṭṭhitacīvarasmiṃ` 释为 `ဘိက္ခု‌နော= ၏`＋`စီဝရံ`，即「**比丘的**衣已做成」（属格归于衣）。译文把「比丘」挂到了后半句（「比丘最多可以把多余的衣收存十天」），`bhikkhunā` 与前面的处格独立结构脱开。
- **建议**：「**比丘的衣已做成**、**迦絺那已撤去**时，最多可以把多余的衣收存十天。」

## §1923 句 213-1923-2-17
- **问题**：补出成分 — nissaya 把 `antarā` 释为 `တပေါင်းလ မပြည့်မီအကြား၌`（迦絺那期限未满之前的中途），并把僧团撤去的方式补为 `ကမ္မဝါစာဖြင့်`（以羯磨）。译文「由僧团在中途撤去」中的「中途」无所指，读者无法知道是相对什么的中途。
- **建议**：「……或者在（迦絺那期限）未满之前由僧团（以羯磨）撤去。」

## §1926 句 213-1926-2-11
- **问题**：句法角色 — nissaya 把 `vikappanupagaṃ`（`ဝိကပ္ပနာပြုလောက်သော`）与 `pacchimaṃ`（`နောက်ဆုံး၌ဖြစ်သော`）并列作 `cīvaraṃ` 的两个定语。译文「达到可以说净的最小尺寸」把 `pacchimaṃ` 转成了量度表述，丢掉它修饰「衣」的身份。
- **建议**：「**衣**，是指六种衣中的任何一种，即可以说净的最小一种衣。」

## §1927 句 213-1927-77-80
- **问题**：取义偏宽 — nissaya 释 `desetabbā` 为 `ဒေသနာပြောထိုက်၏`，并括注「不隐瞒、如实说出」，只含「发露」义，无「忏悔」。译文「发露忏悔」多出一层动作（§1929-45 / §1931-39 同）。
- **建议**：统一作「应当发露这项犯」；若保留「发露忏悔」，三处须一致（目前三处已一致，仅取义偏宽）。

## §1927 句 213-1927-81-87
- **问题**：取义 — nissaya 释 `byattena` 为 `ထက်မြက်သော`（聪敏干练）、`paṭibalena` 为 `ပီသစွာရွတ်စွမ်းနိုင်သော`（能准确流利念诵），并括注 `paṭiggahetabbā` 实指在对方发露时回答「sādhu bhante」等，不是另行「受取」什么。译文「明白事理、有能力」偏泛，「受理」略像行政动作。
- **建议**：「应当由一位聪敏、能如法应对的比丘来接受这项犯的发露。」

## §1928 句 213-1928-15-22
- **问题**：格与句法 — nissaya 作 `ဣတ္ထန္နာမဿ`＋`ဘိက္ခုနော= ၏`（属格修饰 `cīvaraṃ`）、`နိဿဂ္ဂိယံ …(ဟုတွာ)`（成为应舍）、`သံဃဿ= အား`（与格）、`နိဿဋ္ဌံ= စွန့်အပ်ပါပြီ`。译文「这件衣是某某比丘应舍的」把属格并入了「应舍的」这个定语，衣属于谁的关系被压扁。
- **建议**：「某某比丘的这件衣是应舍之物，已经舍给僧团。」（§1930-12-19 平行句同改，保持一致）

## §1932 句 213-1932-2-11（必改，并适用于全组平行句）
- **问题**：隐含主动词漏译 — nissaya 把 `dasāhātikkante` 释为处格的**衣**（`ဆယ်ရက်ကိုလွန်ပြီးသော သင်္ကန်း၌`），并专门加注从 `yo pana bhikkhu … dhāreyya` 补出 pāṭhasesa `ဓာရေတိ`（＝仍持用），再以 `တဿ`（那位比丘的）＋`(တံ စီဝရံ)` 承接 `nissaggiyaṃ`。译文「已经超过十天，也认为已经超过，犯尼萨耆波逸提」缺了「仍持用」这个成犯条件，读起来像「超过十天本身即犯」，与条文结构不符。
- **建议**：「对已经超过十天的衣，认为已经超过而仍持用的，（衣）应舍，犯波逸提。」或保留罪名译法：「……仍持用，犯尼萨耆波逸提。」
- **适用范围**：§1932-2 / -12 / -19 / -26 / -32 / -38 / -44 / -50 / -56 / -62 九条，以及 §1933-10 / -16 / -22 三条平行句（后者无 nissaya，依 §1932 nissaya 的 `[နောက်၌ ဤနည်းမှီ၍ ပေးပါ]` 指示沿用同一结构）。
- 附：`nissaggiyaṃ pācittiyaṃ` 处 nissaya 给两解——主解「其衣应舍 ＋ 犯波逸提」，另解「有舍罪羯磨的波逸提」。译文取的是第二解，有据，可保留。

## §1932 句 213-1932-19-25
- **问题**：取义 — 本条 nissaya 把 `dasāhātikkante` 换读为时间从句（`ဆယ်ရက်ကို ကျော်လွန်ပြီးလသော်`＝超过十天时），与 §1932-2 的「衣·处格」读法不同。译文目前统一按时间读，与本条相合、与 §1932-2 不合。
- **建议**：按上一条的处格读法统一全组；本条的时间读法作为 nissaya 内部异读，不必在译文体现。

## §1934 句 213-1934-2-29
- **问题**：格与补出 — nissaya 把各项的归属补得很细：`နဿတိ／ဝိနဿတိ／ဒယှတိ` 的主语是 `ယဿ စီဝရံ`（某人的衣），`အစ္ဆိန္ဒိတွာ ဂဏှန္တိ`／`ဝိဿာသံ ဂဏှန္တိ` 的主语是他人（复数），`ဥမ္မတ္တကဿ／အာဒိကမ္မိကဿ` 是属格。译文整体合 nissaya ✅。唯 `vissāsaṃ gaṇhanti`，nissaya 作 `အကျွမ်းဝင်၍／အကျွမ်းဝင်သောအားဖြင့်`（以亲厚的方式／出于亲厚），是取者的取法，不是「心」。
- **建议**：「别人以亲厚（vissāsa）取走」。

## §1915 句 213-1915-2-9（低优先）
- **问题**：定语与中心词跨行拆开 — nissaya 作 `တိံသ= သုံးဆယ်‌သော`、`နိဿဂ္ဂိယာပါစိတ္တိယာ= …မည်ကုန်သော`，两者都是 §1916 `dhammā` 的定语。译文把 §1915 收为完整句（「以下是这三十条尼萨耆波逸提：」），§1916 另起「这些条文现在要诵出来了」，造成同一指称说两遍。
- **建议**：行界限制下可接受；若要更贴，§1916 作「这些（法）要被诵出。」
