# Review — 213:469-480（channel: 73c03e1a）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- `maraṇādhippāyo`：§470/472/474 译「起了要害死对方的心」，§476/478 同；§475「我没有要害死他的心」、§477「没有要害死他的心」。叙述句用「对方」、否定句用「他」，指称不统一。nissaya 一律只作 `သေစေခြင်းငှာ အလိုရှိသည်ဖြစ်၍`（为使死而有欲求），原文无「对方／他」这一宾语成分。建议统一为「起了杀心」／「没有杀心」，或统一为「要害死他的心」，并避免补出原文所无的指称。
- `aññataro`（nissaya `မထင်ရှားသော` = 不显著的、某一位）：全 chunk 译「有一位」尚可，但 §477 的 `aññataro bhikkhu taṃ bhikkhuṃ` 译「有一位比丘对那位比丘」与 §475 的 `aññataraṃ bhikkhuṃ` 译「另一位比丘」混用。§477/478 原文是 `taṃ`（指前句那位），§475/476 是 `aññataraṃ`（另一位），现译区分正确，保留；但建议全 chunk 把 `aññataro bhikkhu` 统一为「有一位比丘」（现已统一，记录以备 revise 时勿改）。
- `kukkucca`（nissaya `အလို့လို့`）：全 chunk 一律「心里起了疑悔」，一致。
- `anāpatti, bhikkhu, asañciccā`：§469/471/473 一律「比丘，不犯，因为不是故意的」，一致。
- `āpatti thullaccayassa`：全 chunk 一律「犯偷兰遮」，一致。

## §469 句 213-469-2-13

- **问题**：词义（动词） — `uṭṭhāpenti` nissaya 作 `ထစေကုန်၏`（使……立起），即「使墙立起来／砌起墙」。译「砌墙」方向正确，但 `kuṭṭaṃ` nissaya `နံရံကို` 为宾格、`vihārassa` 为属格 `ကျောင်း၏`，属格修饰关系在译文中已体现为「寺院的墙」，无误。此句仅记录确认，无必改。
- **建议**：无需改动。

## §469 句 213-469-14-20

- **问题**：词义 — `uccāresi` nissaya 作 `အထက်သို့ ကမ်း၏`（向上递送）。译「把砖递了上去」与 nissaya 一致。
- **建议**：无需改动。

## §469 句 213-469-21-29

- **问题**：句法（主格／工具格误读）— nissaya 给 `uparimena bhikkhunā` = `ရဟန်းသည်`（这里缅文给的是主格助词 `သည်`，对应巴利具格的施事用法），`duggahitā` = `မကောင်းသဖြင့် ကိုင်အပ်သော`（被不善地握持的，过去分词作 `iṭṭhakā` 的修饰语），`iṭṭhakā` = `အုတ်သည်`（主格）。原文句式是「被上面比丘没拿稳的砖，压在下面比丘头上」——砖是主语，「没拿稳」是砖的修饰语。
- **问题**：词义 — `avatthāsi` nissaya 作 `ဖိမိ၏`（压到、压住），不是「掉下来砸」。「掉下来」是译者补出的动作，原文与 nissaya 都无「落下」义（§475 的「掉下来」才有 `paripatitvā` = `လိမ့်ကျ၍` 对应）。
- **建议**：改为「上面的比丘没有拿稳，砖就压在下面那位比丘的头上。」去掉「掉下来砸」，保留 `avatthāsi` 的「压」义；§471（手斧）、§473（椽子）同一句式同改。

## §470 句 213-470-20-28

- **问题**：句法（成分补出）— `maraṇādhippāyo` nissaya 作 `သေစေခြင်းငှာ အလိုရှိသည်ဖြစ်၍`，是以 `ဖြစ်၍`（连续体）接下来的主句动词，语法上是主语的同位形容词（「怀着使其死的意欲」），不是一个独立的「起心」动作。译「起了要害死对方的心，把砖丢在……」把它处理成前后两个连续动作，并补出原文所无的「对方」。
- **问题**：词义 — `muñci` nissaya 作 `လွှတ်လိုက်၏`（放手、松手让其落下），不是「丢」（投掷）。此处与 §469 的区别在于「有意松手」而非「失手」，译「丢」偏向投掷，偏离 nissaya 的「松手放开」。
- **建议**：改为「上面的比丘怀着杀心，朝下面那位比丘的头上松手放掉了砖。」§472（手斧）、§474（椽子）同改。

## §470 句 213-470-40-53

- **问题**：句法（名词化谓语）— nissaya 把 `anāpatti` 扩为 `အနာပတ္တိ အနာပဇ္ဇနံ= မရောက်ခြင်းသည်။ ဟောတိ= ဖြစ်၏`，即「（对波罗夷的）不触犯是（成立的）」，`pārājikassa` 为与格／属格 `ပါရာဇိကအာပတ်သို့`（向波罗夷罪）。译「不犯波罗夷」语义正确，与格关系已隐含。
- **建议**：无需改动。

## §475 句 213-475-20-29

- **问题**：句法（处格指示）— `atra` nissaya 作 `ဤအရပ်၌`（在**这个**地方，近指），`ṭhito` = `ရပ်လျက်`（站着，连续状语）。译「站在这里」与 nissaya 一致。
- **建议**：无需改动。

## §475 句 213-475-30-36

- **问题**：句法（指示词缺失）— `so tatraṭṭhito`，nissaya 本句只给 `ဌိတော= ရပ်လျက်` 而未列 `tatra`（§476 对应句 nissaya 补全为 `တတြ= ထိုအရပ်၌`，远指「那个地方」）。译「站在那里」正确，与 §476 nissaya 一致。
- **建议**：无需改动。

## §475 句 213-475-37-52

- **问题**：句法（主语与词序）— nissaya 给 `tvaṃ` = `သင်သည်`（主格），`kiṃcitto` = `အဘယ်စိတ်ရှိသနည်း`（有什么心），谓语 `ပုစ္ဆိ= မေးတော်မူ၏`（世尊提问）。译「比丘，你当时是什么心？」中的「当时」是译者补出的时间成分，nissaya 无对应。此处补出有助可读性但属添加。
- **建议**：可改为「比丘，你是什么心？」若保留「当时」，在 revise 时统一处理添加原则。

## §475 句 213-475-53-63

- **问题**：句法（否定范围）— nissaya 作 `န မရဏာဓိပ္ပါယော= သေခြင်းငှာ အလိုမရှိပါ`，否定落在「有杀的意欲」整体上，且无宾语「他」。译「我没有要害死他的心」补出「他」。另：此处 nissaya 与 §470 等处略异，作 `သေခြင်းငှာ`（为死）而非 `သေစေခြင်းငှာ`（为使死），不影响汉译取舍。
- **建议**：改为「世尊，我没有杀心。」或「我没有要害死人的心。」

## §477 句 213-477-2-11

- **问题**：句法（连续体时序）— `chādetvā` nissaya 作 `မိုး၍`（覆盖／盖顶后），`otarati` = `သက်ဆင်း၏`（现在时，正往下走）。译「盖好寺院的屋顶后往下走」与 nissaya 时序一致。「盖好」的完成义由 `-etvā` 支持。
- **建议**：无需改动。

## §477 句 213-477-28-33

- **问题**：句法（具格=路径）— `tena` nissaya 作 `ထိုအရပ်ဖြင့်`，具格 `ဖြင့်` 在此表「经由那个地方」。译「从那边下来」语义对，但建议用「从那里下去」以贴合「经由该处」且与 §477-18-27 的「从这边下来吧」（`ito` = `ဤအရပ်မှ`，离格 `မှ`）形成近指／远指对应。
- **问题**：用词 — `otaranto` = `သက်ဆင်းသည်ရှိသော်`（正在下行时），`paripatitvā` = `လိမ့်ကျ၍`（滚落）。译「掉了下来」可，但「滚落」更贴 `လိမ့်ကျ`。
- **建议**：「那位比丘从那里下去的时候，摔了下来，死了。」§478 对应句同改。

## §479 句 213-479-2-19

- **问题**：句法（被动施事）— nissaya 给 `anabhiratiyā` = `မမွေ့လျော်ခြင်းသည်`（这里缅文用主格助词 `သည်` 标出被动句的施事），`pīḷito` = `နှိပ်စက်အပ်သည်ဖြစ်၍`（被压迫而）。译「被厌倦的心情折磨」施事关系正确，但「心情」是添加；nissaya 作「不喜乐／不乐于梵行」。
- **问题**：词义 — `papāte papatanto` nissaya 作 `ပပါတေ= တောင်ကမ်းပြတ်၌`（处格，在崖上）＋ `ပပတန္တော= လှိမ့်ချသည်ရှိသော်`（正投身下坠时），是现在分词表「正在下坠之际」，不是已完成的「跳下去」。后接 `ottharitvā`（`ဖိမိ၍` 压住）、`māresi`（`သေစေ၏` 致死）。译「从悬崖上跳下去，压在……身上，把他压死了」把分词处理为并列动作，时间关系（下坠途中压到人）被拉平。
- **建议**：改为「那时，有一位比丘因不乐于梵行而苦恼，登上灵鹫山，从悬崖上投身坠落，坠落时压住一个编竹器的人，把他压死了。」

## §479 句 213-479-34-41

- **问题**：句法（被动当为式）— nissaya `attānaṃ` = `မိမိကိုယ်ကို`（宾格），`na pātetabbaṃ` = `န ပါတေတဗ္ဗံ= မချအပ်`（不应使之坠落）。译「不可以投身跳下」把宾语「自身」吞掉了，而原文的要点正是以「自己」为宾语的使役（使自身坠落）。
- **建议**：改为「比丘们，不可以让自己坠落。」或「不可以投身坠落。」宜保留「自己」这一宾格成分。

## §479 句 213-479-42-50

- **问题**：句法（关系小句与与格）— nissaya 补出 `tassa bhikkhuno` = `ထိုရဟန်းအား`（与格，对那位比丘），`yo pāteyya` 为 `အကြင်ရဟန်းသည်… ချငြားအံ့`（愿望式）。译「谁要是投身跳下，就犯突吉罗」关系正确；但与上一句同样省掉了 `attānaṃ` 隐含的「自己」。
- **建议**：改为「谁要是让自己坠落，就犯突吉罗。」与上句一致。

## §480 句 213-480-2-15

- **问题**：词义（与格表目的）— `davāya` nissaya 作 `မြူးထူးလိုသဖြင့်`（出于嬉戏取乐之意），译「为了玩耍」与之一致。
- **问题**：词义 — `pavijjhiṃsu` nissaya 作 `လှိမ့်ကုန်၏`（滚下、推滚），不是「扔」。`silaṃ` 是石块，从山上是「推滚下去」。
- **建议**：改为「那时，六群比丘爬上灵鹫山，为了取乐把石头往下推滚。」

## §480 句 213-480-16-21

- **问题**：数（动词与主语不一致）— nissaya 本句作 `မာရေသိ= သေစေကုန်၏`，缅文 `ကုန်` 标复数，施事承前指六群比丘（石头是工具）；但巴利 `sā … māresi` 是单数阴性主语（`sā` 指 `silā`），动词单数。nissaya 的复数标记与巴利不符，此处**以巴利为准**，主语是那块石头。另 nissaya 本句未列 `sā`。
- **问题**：句法 — `ottharitvā`（`ဖိမိ၍`）＋ `māresi`（`သေစေ၏`），连续体表「压住而致死」。译「石头压在一个放牛人身上，把他压死了」语法主语正确（石头），与巴利一致。
- **建议**：无需改动；nissaya 复数标记的分歧仅记录，不据以改译。
