## 二、跨段一致性

- **nissaya 同一释义被译成两样**：§248 `brahmappatta` 与 §262 `aggappatta` 的 nissaya 释义完全相同（`မြတ်သည်၏အဖြစ်သို့ ရောက်` ＝ 到达至上／最胜之境），译文却分别作「已到达梵境的」与「已达最上的」。nissaya 并未把 brahma 读成梵天界 → 建议 §248 改「已达至上境的」，与 §262 对齐。
- **veda 一词两处都被模糊成「明智」**：§237 `veda` 的 nissaya 是「知四谛」（宾格 `သစ္စာလေးပါးကို`），§250 `viditaveda` 的 nissaya 是「有已被知之法者」。译文「具足明智的」「已彻知明智的」把两处不同的词法结构压成同一个含糊词 → 建议分别处理（见下）。
- **`X eva Y` 定义句式不统一**：§284-25「无时的本身就是**不待时节**」、§283-87「所看见的本身就是亲见」都用「A 本身就是 B」；§283-2 却作「就这亲见本身来说，它就是**现见**的」。建议统一为「亲见本身就叫做现见」。
- **`sandiṭṭha(ṃ)` 名词／动词短语混用**：§283-87 译作名词「亲见」，§283-99 同一词却译成动词短语「值得被这样亲自看见」。nissaya 两处都是宾格 `ရှုမြင်ခြင်းကို` → §283-99 建议「值得获得亲见」。
- **`ettha` 的句法位置不统一**：§282-2 译成定语「这里的圣道」，§283-59 译成状语「这里圣道凭着……」。nissaya 两处都是处格副词（`ဤပါဠိရပ်၌`／`ဤ"သန္ဒိဋ္ဌိကော"ဟူသောပါဠိရပ်၌`），修饰整句而非主语 → §282 改「就此而言，圣道……」。
- **语体**：全篇为现代书面汉语，仅 §261「饶益世间的」一处偏文雅（且「世间」是补出），建议改「带来利益的」，与前后语体一致。

## 三、逐句意见

### §237 句 205-237-2-4
- 【建议】**取义/宾格** — `vedassa` 的 nissaya 为 `သစ္စာလေးပါးကိုသိတော်မူတတ်သော`（宾格「四谛」＋动词「知」），译文「具足明智的」既丢了宾语又把动词名词化。
- 建议：「通达四谛的」。

### §238 句 205-238-2-4
- 【必改】**宾格漏译** — `saṃvutattassa` 的 nissaya 是 `ဣန္ဒြေတို့ကို ကောင်းစွာစောင့်ရှောက်တော်မူတတ်သော`，宾格助词 `ကို` 明确标出宾语是「诸根（indriya）」，译文「守护自身的」把宾语换成了「自身」。
- 建议：「善护诸根的」。

### §239 句 205-239-2-4
- 【建议】**夺格补出** — `muttassa` 的 nissaya 是 `ကိလေသာ အပေါင်းမှ လွတ်မြောက်`，`မှ` 是夺格，明确「从烦恼聚中」解脱；§242 的 `muttassa` nissaya 同样是 `ကိလေသာတို့မှ`。译文两处都只作「已得解脱的」，未体现 nissaya 补出的夺格对象。
- 建议：至少一处作「已从烦恼中解脱的」。
- 【记录】`saṅgātigassa` 的 nissaya 作「已超越魔军众」（`မာရ်နတ်၏ စစ်သည်အပေါင်းကိုကျော်လွန်`），与译文「超越了系着的」取义不同；译文取的是 saṅga＝系着，词法上可通，此处只作记录。

### §241 句 205-241-2-6
- 【建议】**取义** — `nāgassa` 的 nissaya 是 `ရဟန္တာ ဖြစ်တော်မူထသော`（＝是阿罗汉者），并非取龙象之喻。译文「如龙象一般的」与 nissaya 的传统取义不合。
- 建议：「已成阿罗汉的」，或保留龙象而在报告备案；若保留须注意与 §253「已成圣的」等不重复。

### §243 句 205-243-2-4
- 【建议】**取义相反** — `paṭimantakassa` 的 nissaya 是 `နောက်ထပ်တဖန် မတိုင်ပင်ထသော`（＝不再须与人商议／无须再问），是否定式；译文「善于应对问难的」是肯定式的另一读。
- 建议：按 nissaya 作「无须再向人请问的」。

### §245 句 205-245-2-4
- 【建议】**语态** — `dantassa` 的 nissaya 是 `ဆုံးမအပ်သော`（被动：已被调伏的），译文「已调御自身的」补出了受事「自身」并转成主动。建议「已调伏的」。
- 【必改】**取义** — `nippapañcassa` 的 nissaya 是 `ကင်းပြီးသော ကိလေသာရှိတော်မူထသော`，明确把 papañca 释为「烦恼」，是有财释（有已离之烦恼者）；译文「没有戏论的」取的是另一义。
- 建议：「烦恼已尽的」。

### §247 句 205-247-2-7
- 【建议】**取义** — `akuhassa` 的 nissaya 是 `ထောင်လွှားခြင်းရှိတော်မမူသော`（＝无矜高自夸），译文「不虚伪欺诈的」与之不同。
- 建议：「不自夸矜高的」。

### §248 句 205-248-2-4
- 【建议】见「跨段一致性」第一条：`brahmappatta` 按 nissaya 应为「已达至上境的」，非「已到达梵境的」。

### §249 句 205-249-2-4
- 【必改】**宾格误读** — `nhātakassa` 的 nissaya 是 `မကောင်းမှု အကုသိုလ်ကို ဆေးကြောသုဓ်သင်ပြီးထသော`，宾格 `ကို` 标出所洗净的是「恶不善（法）」，译文「已洗净自身的」把宾语换成了「自身」。
- 建议：「已洗净恶不善的」。

### §250 句 205-250-2-4
- 【建议】**有财释结构** — `viditavedassa` 的 nissaya 是 `သိတော်မှုအပ်ပြီးသော တရားရှိတော်မူထသော`＝「有已被了知之法者」（被动分词＋`ရှိ`），译文「已彻知明智的」丢了「法」这个被知的对象。
- 建议：「所应知之法已尽知的」。

### §251 句 205-251-2-4
- 【必改】**宾格与取义全错** — `purindadassa` 的 nissaya 是 `နိဗ္ဗာန်ကို ရှေးဦးစွာ မြင်တော်မူပြီးထသော`，宾格 `ကို` 标出宾语是「涅槃」，动词是「最先见到」。译文「先行布施的」与 nissaya 无一处相合。
- 建议：「最先见到涅槃的」。
- 【记录】`sakkassa` 的 nissaya 只作音译（`သက္ကဖြစ်တော်မူထသော`），译文「有大能力的（sakka）」的释义无 nissaya 依据，仅记录。

### §256 句 205-256-2-5
- 【建议】**补出施事无据** — 译文「既不被贪爱拉近、也不被嫌恶推远的」补出了「贪爱」「嫌恶」两个施事并改为被动。该段 nissaya（`မလိုအပ်သည်ကို ကြောက်လန့်` ／ `မပြေးတတ်သော`）本身可疑，不支持这两个施事。按 `style.md`「不擅自补足」，
- 建议：「不倾向、也不背离的」。

### §257 句 205-257-2-5
- 【记录】`anejassa` 的 nissaya 作 `မရှာမှီးတတ်ထသော`（＝不追求、不寻觅），译文「没有动摇的」取 ejā＝动摇。两读皆有传统依据，仅记录。

### §259 句 205-259-2-6
- 【必改】**宾格漏译** — `jhāyissa` 的 nissaya 是 `နီဝရဏတရားတို့ကို ဖုတ်ကျည်းတော်မူထသော`，宾格 `ကို` 标出宾语是「诸盖（nīvaraṇa）」，动词取 jhāyati＝烧。译文「修习禅定的」既换了取义也丢了宾语。
- 建议：「烧尽诸盖的」。

### §261 句 205-261-2-4
- 【建议】**补出无据＋语体** — `hitassa` 的 nissaya 仅作 `အကျိုးစီးပွါးရှိတော်မူထသော`（＝有利益），译文「饶益世间的」补出「世间」且用词偏文雅。
- 建议：「带来利益的」。

### §263 句 205-263-2-4
- 【建议】**夺格补出** — `tiṇṇassa` 的 nissaya 是 `သံသရာမှ ကူးမြောက်ပြီးထသော`，夺格 `မှ` 明示「从轮回」。
- 建议：「自己已渡过轮回、又能使他人渡过的」。

### §267 句 205-267-2-4
- 【记录】`sugatassa` 的 nissaya 作 `ကောင်းသောစကားကိုဆိုတော်မူတတ်သော`（＝善说语者，宾格 `ကို`＋动词「说」），与译文「善逝」取义不同；`tathāgatassa` 的 nissaya 作「善来」。译文用的是传统固定译名，此处只作记录，不建议在偈颂里改动。

### §271 句 205-271-2-7
- 【建议】**宾格漏译＋夹注** — `buddhassa` 的 nissaya 是 `အလုံးစုံသောတရားတို့ကိုသိတော်မူပြီးထသော`，宾格 `ကို` 标出「一切法」为所知对象。译文「已觉悟者（buddha）」丢了宾语；且 buddha 属常见术语，按 `style.md` 不需夹注巴利原词（父层定稿作「佛」）。
- 建议：「已遍知一切法的」，去掉夹注。

### §273 句 205-273-2-4
- 【建议】**取义** — `yakkhassa` 的 nissaya 是 `နတ်နှင့်တူတော်မူထသော`（＝与天神相似），译文「具有大威力的」是另一读。
- 建议：「如天神一般的」。

### §274 句 205-274-2-4
- 【记录】`atulassa` 的 nissaya 是 `တူသောပုဂ္ဂိုလ်ရှိတော်မမူထသော`（＝无与之相等之人），与 §268 `asamassa` 的 nissaya 几乎同释。译文「不可称量的」偏离 nissaya，但好处是与 §268「无与等同的」不撞词。若改，需同时重排 §268 的措辞。

### §278 句 205-278-34-46
- 【建议】**施事** — `sañjānanahetuttā` 的 nissaya 是 `ကောင်းစွာသိတော်မူတတ်သောအကြောင်း၏အဖြစ်ကြောင့်`，敬语 `တော်မူ` 表明「知」的施事是世尊本人（＝因为它是世尊遍知的因由）；译文「让人认知的依据」把施事定成了他人。
- 建议：「由于它是（世尊）遍知的因由，所以叫做智（paññāṇa）」。
- 另：`etassa` 译作「这智属于他」与 nissaya `ဧတဿ ဘဂဝတော…အတ္ထိ` 一致，✅。

### §278 句 205-278-47-56
- 【必改】**格误读** — `dhiyā paññāya` 的 nissaya 是 `ဉာဏ်ပညာကို`，宾格 `ကို`，即「智慧」是 `rāti gaṇhāti / sevati` 的**宾语**；译文「用智慧去执取、……去亲近」把它当成了具格工具。
- 【建议】**补出主语** — nissaya 两次补出施事 `ယော ပုဂ္ဂလော／သော ပုဂ္ဂလော`（那个人），译文无主语，读来悬空。
- 建议：「执取智慧、或者说亲近智慧的人，所以叫做**坚毅者**。」

### §278 句 205-278-57-59
- 【建议】**补出主语** — nissaya 补出 `သော ဘဂဝါ`（世尊）为主语，译文「所以是**摧破心中荒秽者**」主语缺失。
- 建议：「……所以世尊是**摧破心中荒秽者**。」

### §278 句 205-278-60-66
- 【建议】**处格** — `sabbaputhujjane` 的 nissaya 释义以 `၌`（处格）收尾，译文「征服一切凡夫」当成了宾格。
- 建议：「在一切凡夫中曾取胜、正取胜、将取胜」。
- 【建议】**指代** — 「这几者」所指此句尚未出现（下一句才问「它们是哪些呢」），指代落空。建议改「那些……者」。
- 【记录】本行 nissaya 把主语定为世尊（`သော ဘဂဝါ…ဝိဇယော`），与紧接的 §278-67 nissaya（`တေ`＝那些被征服的魔）自相矛盾；译文取后者，与 §278-70「死魔、烦恼魔、天子魔」及 §278-72 的被动句一致，可。

### §278 句 205-278-72-79
- 【建议】**具格所指** — `etena` 的 nissaya 是 `ထိုသဗ္ဗညုတဉာဏ်တော်ဖြင့်`，具格 `ဖြင့်` 所指为「一切知智」，译文笼统作「被他」。
- 建议：「这些征服者（诸魔）都被他以一切知智征服了」。

### §279 句 205-279-22-73
- 【建议】**有财释** — `durakkhātadhammā` 是形容外道们的有财释（所说之法恶劣者），译文「所说之法并不如实的人」把 durakkhāta 读成了「不如实」。
- 建议：「那些外道就成了所说之法恶劣的人」。（nissaya 此条作 `ကျင့်နိုင်ခဲသော`＝难行，与 durakkhāta 不符，见第四节。）

### §282 句 205-282-2-16
- 【建议】见「跨段一致性」：`ettha` 为处格副词，不是「圣道」的定语 → 「就此而言，圣道不落入两个极端……」。

### §283 句 205-283-2-29
- 【建议】句式 — 「就这亲见本身来说，它就是**现见**的」改为「亲见本身就叫做**现见**」，与 §283-87、§284-25 的同构句一致。

### §283 句 205-283-30-48
- 【建议】**宾格＋动词漏译** — `gantabbataṃ` 的 nissaya 是 `သွားအပ်သည်၏အဖြစ်ကို`（宾格＋「行、趣」），`parasaddhāya` 是具格 `သူတစ်ပါးတို့၏ သဒ္ဓါတရားဖြင့်`。译文「不必靠对他人说法的信任去认取」既改了动词（认取／行），语序也绕。
- 建议：「舍弃了必须依凭对他人的信赖而行这一点，而是……」。
- 【建议】**补出无据** — 「九种出世间法（四道、四果与涅槃）」的括注内容原文与 nissaya 都没有；按 `style.md`，圆括号夹注只用于附巴利原词。建议删去或移入报告。
- 【记录】`paccakkhañāṇena` 的 nissaya 作 `ပစ္စဝေက္ခဏာဉာဏ်ဖြင့်`（观察智），与译文「现量的智」用词不同；具格关系一致，仅记录。

### §283 句 205-283-87-98
- 【必改】**自相矛盾＋取义** — 前半句已说 `diṭṭha` 指 dassana（看见的作用），nissaya 也明确 `ဒိဋ္ဌမေဝ= ရှုမြင်ခြင်းသည်သာလျှင်`（见的作用本身）；译文后半却作「所看见的本身就是亲见」，把 diṭṭha 转成了被看见的对象，与自己前半句相悖。
- 建议：「“见”指的是看见的作用；这见本身就是亲见，意思就是亲自看见。」

### §283 句 205-283-99-102
- 【建议】见一致性：`sandiṭṭhaṃ` 宾格，与 §283-87 同词 → 「它值得获得亲见，所以叫做**现见**」。

### §284 句 205-284-43-56
- 【必改】**漏译两个修饰语** — nissaya 对 `patto`（`ရောက်အပ်သော`＝已到达的）与 `upanīto`（`ကပ်ဆောင်အပ်သော`＝被引近的）都给了释义，译文「有一段遥远长久的时间要经过」只保留了 `vippakaṭṭho dūro`，两个过去分词全部落空。
- 建议：「在给出自己的果上，有一段已经到来、被引近的遥远时间，这样的就叫做有时的」。

### §284 句 205-284-2-10
- 【记录】`assa` 的 nissaya 作 `ထိုပုဂ္ဂိုလ်အား`（那个人，与格），译文作「它（法）」；但同段 §284-11 的 nissaya 把对应的 `etassa` 释为 `ထိုလောကုတ္တရာတရားအား`（那出世间法）。nissaya 自身不一致，译文取「法」在上下文（§284-63「这个法……」）中自洽，不改，仅记录。

## 四、nissaya 疑有讹误（仅记录，不据以改译）

- §244 `pannaddhajassa` → `မြဲမြန်သော တံခွန်ရှိသော`（有坚固旗幢），与 panna（放下）相反，译文「已放下骄慢旗幢的」可。
- §260 `ananugatantarassa` → `အစဉ်ဝင်စားအပ်သောဈာန်အထူးသို့ ရောက်`，否定前缀失落。
- §261 `asitassa` → `ထွေးအန်အပ်သော`（被吐出），似把 asita 读作「吐」。
- §279 `durakkhātadhammā` → `ကျင့်နိုင်ခဲသော`（难行），与 akkhāta（说）无关。
- §283 `anaññaneyyena` → `သူတစ်ပါးကို မသိသဖြင့်`（不知他人），译文「不靠别人引导」才合 anañña-neyya。
- §283-103 `vatthaṃ` → `ဝတ္တံ= ဆုတ်နစ်ခြင်းကို`，似读作 vatta；译文取 vattha（衣服）→「有衣者」可。
- §278-60 `sabbaputhujjane` → `ကိလေသာတို့ကို ဖြစ်စေခြင်း၌`，与 puthujjana 不符。
