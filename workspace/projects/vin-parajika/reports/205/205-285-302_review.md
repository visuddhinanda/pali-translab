# Review — 205:285-302（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§292、§293 无 nissaya，按规则略过；§301、§302 本次未注入译文行，不在审查范围）

## 被解释词与父层（book 138）对照

逐条机械比对，**全部与父层定稿译文逐字相同，无不一致**：

- `ehipassiko` → 可以请人来看的（138-1056）｜`opaneyyiko` → 引导趣向的（138-1056）
- `paccattaṃ veditabbo viññūhi` → 智者各自能体证的（138-1056）｜`asaṅkhataṃ` → 无为｜`amataṃ` → 不死
- `ekadhammakkhandhassapi nāmaṃ` → 哪怕一个法蕴的名称（138-1056）
- `suppaṭipannaṃ / ujuppaṭipannaṃ / ñāyappaṭipannaṃ / sāmīcippaṭipannaṃ` → 善行道的／正直行道的／如理行道的／如法行道的（138-1057）
- `catupurisayugo` → 四双的｜`aṭṭhapurisapuggalo` → 八辈的｜`āhuneyyo` → 应受供养的｜`pāhuneyyo` → 应受款待的｜`dakkhiṇeyyo` → 应受布施的｜`añjalikaraṇīyo` → 应受合掌恭敬的｜`anuttaraṃ puññakkhettaṃ` → 世间无上福田（138-1057）
- `bhikkhusikkhaṃ bhikkhunīsikkhaṃ` → 比丘学处、比丘尼学处（138-1058）｜`paṭhamaṃ pārājikaṃ` → 第一条波罗夷（138-1059）
- `yo maṃ pabbājesi` / `yassa mūlena` / `yassamūlikā`（138-1062）、`yo maṃ anusāvesi` / `yāhaṃ nissāya vasāmi` / `yāhaṃ uddisāpemi` / `paripucchāmi`（138-1063）、`tassa mūle`（138-1066）→ 均与父层一致
- 非黑体引文也对得上：§297-81-107 引「善行道的僧团」、§288-30-65 引「我舍弃善说之法」与父层同。

戒师（upajjhāya）／同住者（saddhivihārika）／阿阇梨（ācariya）／别称（vevacana）／犯（āpatti）等术语与父层无漂移。

## 跨段一致性

- **`purisayuga`**：§290-2-11 译「四对人」，§290-34-42 黑体译「四双的」，§290-43-57 解说又作「八个人」。黑体须保留父层「四双」，但解说句宜同步用「双」，否则读者看不出解说的是同一个词 → 建议 §290-2-11 改「……算作一双，这样就有四双人」。
- **`hutaṃ / hutassa`**：§291-49-60 译「供在那火里的东西」、§291-61-68「供品」、§291-69-73「供在僧团里的供品」、§294「祭火」。nissaya 一律作动名词 `ဟုတံ= ပူဇော်ခြင်းသည်`（供养之事），非供物 → 统一为「所作的供养／火供」，见下列各条。
- **`dakkhiṇā`**：§297-2-13 译「施物」，§297-14-26 同一词译「布施」 → 建议统一作「施物」（指所施之物），动作义另用「布施」。
- **`sikkhā`**：§298-2-40 一句之内「学处的称呼」与「本身就是学」并用 → 后者统一为「学处」（父层 `sikkhā` 作「学处」）。
- **「值得……的做法」**：§285-2-16／§285-17-22／§285-85-110 三处同一搭配，「值得」后接名词「做法」读不通 → 建议改「配得上……这种请人来看的做法」或「可以对它说……」。
- **夹注体例**：§290-65-77「purisa（人）」、§295-2-27「āhavanīyo（应供奉的）」用「巴利（汉译）」，§299-43-49「后缀派生（taddhita）」用「汉译（巴利）」。词形讨论处倒置可接受，但同一 chunk 内宜统一说明体例。

## §285 句 205-285-49-50

- **问题**：补出成分／词义 — 译「因为那东西根本不存在」，主语与限定语都靠猜。nissaya 在上一句 `Kasmā?` 处已补出主语与限定：`ဟိရညံ ဝါ= 银`、`သုဝဏ္ဏံ ဝါ= 金`、`ပရမတ္ထတော= 依胜义`，本句 `အဝိဇ္ဇမာနတ္တာ= ထင်ရှားမရှိသည်၏ အဖြစ်ကြောင့်တည်း`。「根本」是译者添加，nissaya 的限定是「在胜义上」。
- **建议**：「因为那银子或金子在究竟意义上并不存在。」

## §285 句 205-285-83-84

- **问题**：补出成分 — nissaya 在前一 `Kasmā?` 补出 `တဿ ဝတ္ထုဿ= 那东西的`，译文「因为它不清净」指代稍虚。
- **建议**：「因为那东西不清净。」（非必改）

## §285 句 205-285-85-110

- **问题**：词义分歧（必改）— `paṇḍukambale` 译「黄色毛毯」，nissaya 作 `ပဏ္ဍကမ္ဗလေ= ပဏ္ဍုကမ္ဗလာ မြကျောက်ဖြာ၌`，即帝释的「巴恩杜甘婆罗」翠石板（石座），不是毛织物；`နိက္ခိတ္တဇာတိမဏိ= 放置的上妙宝石（ပတ္တမြား 红宝石）`。
- **建议**：依 nissaya 改「像放在巴恩杜甘婆罗宝石板（paṇḍukambala）上的上妙宝石一样」；若保留「毛毯」一读，须有别的依据，不能与 nissaya 无声分歧。
- **问题**：补出成分 — 末句 `vijjamānattā parisuddhattā ca` 译「因为真实存在、因为清净」，nissaya 此处明确补 `ပရမတ္ထတော= 依胜义`（与 §285-23-27 同）。
- **建议**：「所以，因为在究竟意义上真实存在、因为清净……」

## §286 句 205-286-26-45

- **问题**：格（非必改）— `asaṅkhato` 译作主语「至于无为法，它值得……」；nissaya 读作处格 `အသင်္ခတေ ပန= 在无为法上则……`，主语另有所指。意思不受影响，记录备案。

## §286 句 205-286-46-62

- **问题**：主语 — 「正因为是能引、应引的（upaneyya），才叫做引导趣向的」把主语悬置；nissaya 作 `ဥပနေယျော ဧဝ= 应引的道、果、涅槃法本身`。
- **建议**：「正是这应引的道、果、涅槃，才叫做引导趣向的。」

## §287 句 205-287-26-66

- **问题**：格与主宾关系误读（必改）— 「同住者也不会因为戒师的果定而住得安乐」把 `so` 当同住者、`tassa` 当戒师，与 nissaya 相反：`သော= ထိုဥပဇ္ဈာယ်ဆရာသည်`（主格＝戒师）、`တဿ= ထိုသဒ္ဓိဝိဟာရိကတပည့်အား`（与格＝为那同住者）、`ဖလသမာပတ္တိယာ= 以果定（具格）`。三句主语按 nissaya 一贯是戒师。
- **建议**：「戒师也不能靠自己的果定让那位同住者住得安乐。」
- **问题**：格（存疑）— 「更不能把戒师所作证的涅槃也作证」把 `tena` 当戒师；nissaya 作 `တေန= ထိုသဒ္ဓိဝိဟာရိက တပည့်သည်`（＝同住者）。按 nissaya 本句当是「（戒师）也不能把那同住者所作证的涅槃作证」，与上句主语链一致。两读都通，但不能默默取与 nissaya 相反的一读。
- **建议**：采 nissaya 读法改写，或维持原译并在定稿记录里写明依据。
- **问题**：指代（存疑）— 「所以这个法不应当像看别人头上的装饰品那样去看」，nissaya 读 `esa` 为人：`ဧသ ဧသော ပုဂ္ဂလော= ဤပုဂ္ဂိုလ်သည်`。
- **建议**：若依 nissaya 作「这个人（证得的法）不应当……」；至少记录分歧。

## §288 句 205-288-2-15

- **问题**：补出成分 — 译文主语用「它」，nissaya 明确补出 `နိဗ္ဗာနံ= 涅槃သည်`。另「不是由众缘以聚合……的方式汇集起来，再由相应的诸缘所造作」句子过长，读来绕。
- **建议**：「**无为**，是说涅槃并不是众缘聚合、会合，以众缘和合为特相地汇集起来，再由相应的诸缘造作、生起的，所以叫无为。」

## §290 句 205-290-34-42 ／ 205-290-58-64

- **问题**：补出成分 — 两处 `ettha` 译「这里」，nissaya 都补出所指：`ဧတ္ထ ဧတသ္မိံ သံဃေ= 在那僧团中`。
- **建议**：「因为在僧团中有四对人……」「因为在僧团中有八个人……」

## §290 句 205-290-43-57

- **问题**：漏译（轻）— `purisapuggalavasena` 译「按个人来算」，nissaya 作 `ယောက်ျားပုဂ္ဂိုလ်၏ အစွမ်းအားဖြင့်`（按「人—个人」这一对词），与下句「purisa 和 puggala 意思相同」呼应，丢掉 purisa 会使后文失去着落。
- **建议**：「是说按『人』这一个个来算」或保留「按人、按个人来算」。

## §291 句 205-291-33-48

- **问题**：补出成分 — `ettha` 译「在这里」，nissaya 作 `ဧတ္ထ= ဤသံဃာ၌`（在此僧团中）。
- **建议**：「也值得把全部财产都供奉在僧团中」。

## §291 句 205-291-49-60

- **问题**：词义（必改）— `hutaṃ` 译「供在那火里的东西」，nissaya 作 `ဟုတံ= မီးပူဇော်ခြင်းသည်`（火供这件事，动名词），不是供物。
- **建议**：「他们认为在那火里所作的火供会有大果报。」

## §291 句 205-291-61-68 ／ 205-291-69-73

- **问题**：词义（必改，同上）— 「供品有大果报」「供在僧团里的供品」；nissaya 两处都是 `ဟုတံ / ဟုတဿ= ပူဇော်ခြင်း`（供养之事）。§291-69-73 的 `Saṅghe` nissaya 作 `သံဃေ= သံဃာအား`（向僧团）。
- **建议**：「如果是因为所作的供养有大果报才叫应供奉的……」「因为向僧团所作的供养才有大果报。」

## §291 句 205-291-74-75

- **问题**：补出成分 — `Yathāha` 译「正如经中所说」，nissaya 补出施动者 `ဘဂဝါ= မြတ်စွာဘုရားသည် ... ဟောတော်မူပြီ`（世尊所说）。
- **建议**：「正如世尊所说——」

## §293 句 205-293-2-7

- **问题**：取义分歧（存疑）— 「供养一位已修养自身的人」取 `bhāvitattānaṃ ekaṃ` 为人；§294 所附、覆盖整首偈的 nissaya 读作修习：`ဘာဝိတတ္တာနံ= ပွါးများစေအပ်ကုန်သော ဘာဝနာတို့တွင်`、`ဧကဉ္စ= တစ်ခုသော ဘာဝနာကိုလည်း`、`သာယေဝ ပူဇနာ= ထိုဘာဝနာကို ပူဇော်ခြင်းသည်`。
- **建议**：现译与《法句经》一〇七通行读法一致，可维持；但须把这一分歧写入定稿记录，不要无声取舍。

## §296 句 205-296-17-31

- **问题**：语气词 eva 弱化 — `saṅghasseva ... yuttaṃ` 译「最适合施给僧团」，nissaya 作 `သံဃဿေဝ= သံဃအားသာလျှင်`（唯独僧团）。
- **建议**：「就只该施给僧团，也只有僧团适合接受它。」

## §296 句 205-296-37-56

- **问题**：主语误读（必改）— 「这样的客人要等一个佛与佛之间的间隔过去才见得到一次」把 `esa` 当客人，下半句又换成僧团，一句之内主语跳换。nissaya 明确：`ဧသ ဧသော သံဃော= ထိုသံဃာသည်`、`ဧကဗုဒ္ဓန္တရေ ဝီတိဝတ္တေယေဝ ဒိဿတိ= 唯在一佛的间隔过去时才出现`。
- **建议**：「正因如此，这样的僧团要经过一佛与一佛之间的间隔才出现一次；而它又不间断地具足能使人可爱可意的戒等功德。」（`tathā hi` nissaya 作 `ထိုအကြောင်းကြောင့်သာလျှင်`＝正因如此，优于「事实上」）

## §297 句 205-297-45-66

- **问题**：指代扩大 — 第二个 `rañño` 译成「各自的稻田、麦田」；nissaya 只作 `ရညော= မင်း၏`（国王的）。
- **建议**：「就像国王或大臣种稻、种麦的地方，被称作国王的稻田、麦田一样……」

## §297 句 205-297-81-107

- **问题**：文字错乱（必改）— 「等处处处配上『僧』这个词」连出三个「处」，不可读。
- **建议**：「『善行道的僧团』等等，各处都配上『僧』这个词，是为了显示……」

## §298 句 205-298-2-40

- **问题**：术语不统一（见跨段一致性）— 同句内「学处的称呼」与「本身就是学」并用。
- **建议**：后者改「增上戒等本身就是学处」。
- **问题**：存疑 — `sīsaṃ eti` 两处译「才算成立／也照样成立」属意译，nissaya 仅作字面 `သီသံ= အထွတ်အထိပ်သို့ ဧတိ= ရောက်၏`（到达顶点）。意译在上下文（舍戒成立）可通，但宜记录。

## §300 句 205-300-2-31

- **问题**：措辞 — `upajjhaṃ adatvā` 译「没有充当戒师」，nissaya 作 `ဥပဇ္ဈံ= ဥပဇ္ဈာယ်ကို၊ အဒတွာ= မပေးမူ၍`（没有把戒师之分给他）。
- **建议**：「没有把自己给他作戒师，只是作为阿阇梨让他出家」。

## §300 句 205-300-55-60

- **问题**：词义（轻）— `pāṭhaṃ` 译「经文」，nissaya 作 `ပါဌံ= ပါဠိကို`（圣典巴利文句）。与 §300-61-66「所学经文」内部一致，可保留；若要贴 nissaya，可作「圣典文句」。
