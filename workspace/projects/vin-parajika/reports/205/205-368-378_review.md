## 一、被解释词核对（对父层 138 定稿）

逐条比对了本 chunk 全部黑体词（369-2-7 / 40-49 / 50-57 / 58-87 / 98-101 / 102-105 / 110-113 / 114-130、370-2-11、372-2-7 / 8-11 / 12-16 / 17-21 / 64-75、373-2-12 / 13-29 / 78-82 / 89-100、374-2-8 / 9-12、375-2-17、376-2-18 / 29-37、377-2-14 / 84-104、378-2-17 / 35-39 / 40-48），**正文用字与父层逐字一致，无不符**；375-53-84 的 `**yamakapakaraṇe**`→「**《双论》**」父层未出现，属本层自定，可。非黑体的引文（376-110-124、377-61-75、377-15-60 末引、374-13-46 末句）也与父层一致。

三处例外见下：

- **必改｜自造黑体**：§373 四句（13-29 / 30-38 / 39-58 / 59-77）译文把 pali 中**没有** `**` 的词也加了粗。黑体是从父层引出的被解释词标记，自行加粗会让「这条注在注哪个词」的对应关系失效，也让机械核查失灵。只有 `**Vaṇṇapokkharatāyā**`（13-29）、`**vaṇṇapokkharatāya**`（39-58、59-77）该保留黑体；373-30-38 整句 pali 无黑体，译文的「**身体**」「**肤色**」两处粗体必须去掉。
- **建议｜章名书名号**：205-368「已被判定的事例的解释」，父层 138-1153 作「《已被判定的事例》的解释」。同一章名，建议补书名号统一。
- **可不改**：378-2-17「两人都犯共宿罪」与父层 138-1161-2-23 正文逐字相同，仅父层带首现夹注「（sahaseyya）」。参见下文夹注一致性一项。

## 二、跨段一致性

- **methunaṃ dhammaṃ paṭisevati**：本层 370-78-121、371-2-47 译「行不净法」，父层定稿一律作「**性交**」（138-1132「行性交」、138-1151「与性交相关的欲想」「性交的心」）；而父层把「不净法」专留给 **asaddhamma**（138-1156「怀着行不净法意图」，本层 373-89-100 黑体引用时也用了「行不净法」）。照现译，两个不同巴利词在汉译里撞成同一个词，读者分不开。→ 建议 methuna dhamma 统一回「性交」，「不净法」只用于 asaddhamma。
- **kāyasaṃsaggarāga**：父层 138-1155-72-78 定稿作「身体接触的染心（kāyasaṃsaggarāga）」，sāratta 作「起了贪欲」；本层 372-12-16 作「因身体接触而起的贪欲」、372-22-33 / 34-61 作「身体接触的贪欲」。尤其 372-12-16 一句内自相矛盾：黑体「**他的这种染心**」（=父层）后面却用「贪欲」释义，等于把被释词换了名字。→ 统一为「身体接触的染心（kāyasaṃsaggarāga）」。
- **uttama / hīna**：父层 138-1160-2-17 定稿「男性的性征是**高**的／女性的性征是**低**的」；本层 376-2-18 释义改用「殊胜／低劣」，376-19-28 用「低劣与殊胜之分」。ṭīkā 的论点正是「性征的高低来自根的高低」，译文两套词会让这层推论断掉。→ 释义里承接父层用字，如「说的是男根为高、女根为低」，必要时再括注「（殊胜／低劣）」。
- **pokkharatā**：373-13-29 一句之内三个译法——「美好（pokkharatā）」「美妙的状态」「肤色的美满」，而 vaṇṇasampatti 也译「美满」。→ pokkharatā 固定一词（如「美好」），sampatti 另用「圆满／具足」，避免与 pokkharatā 混。
- **夹注策略不统一**：译文给 kusa、pāradārika、vaṇṇapokkharatā、pokkharatā 夹注了巴利，但 purisindriya/itthindriya（「男根／女根」，与 liṅga「性征」是两个层次的概念，汉语「男根」又易误读为生殖器）、paṭisandhi（结生）、pavatti（生命过程）、catujarūpa（四因生色）、santāna（相续）、pācittiya（波逸提）、sahaseyya（共宿）首现均无夹注。按 `style.md`「法相术语首次出现夹注巴利原词」，建议至少给男根／女根、结生、生命过程、四因生色补上。
- 语体检查：未发现文言／半文半白句式，标点均为全角，无 ASCII 引号，译文无工作标记。

## §369 句 205-369-8-12

- **必改**：`Vinītāni vinicchitāni vatthūni **vinītavatthūni**` 是复合词解析（vigraha），vinīta 的释义词就是 vinicchita。nissaya 把两词合成**一条**释义：`ဝိနီတာနိ ဝိနိစ္ဆိတာနိ= မြတ်စွာဘုရား ကိုယ်တော်တိုင်ဆုံးဖြတ်အပ်ကုန်သော`（世尊亲自判定的），并无「引导／调教」一义。现译「被引导、被判定过的事例」把释义词当成了并列的第二个属性，等式关系没了，「被引导」也无据。
- **建议**：改为「被判定、被裁决过的事例，就是**已被判定的事例**」，或显化等式：「vinīta 就是 vinicchita（被判定）——被判定的事例就是**已被判定的事例**」。

## §370 句 205-370-31-51

- **分歧记录（建议不改）**：`aññe bhikkhū` 形态上主格/宾格同形，nissaya 标 `ဘိက္ခူ= တို့ကို`（宾格）；译文按主格施事译「是别的比丘看见以后责问那位比丘的」。但 nissaya 自己在 `ဒိသွာ= တွေ့မြင်ကြကုန်၍`、`စောဒေသုံ= စောဒနာကြကုန်ပြီ` 上都加了复数施事标记，施事只能是「别的比丘」，且作宾格读则 disvā 无施事。判定：译文的主格读法可取，nissaya 的 ကို 视为讹误。此处备案，不改。
- 另：nissaya 补出了责问的内容（`သစ္စံ= မှန်လေသလော`，「这话是真的吗」），属 nissaya 补足语，原文无，译文不补正确。

## §371 句 205-371-2-47、205-371-48-74

- **建议**：两句的 `ye`／`te` nissaya 均补出被省略的中心词 `ဘိက္ခူ`（`ယေ ဘိက္ခူ= အကြင်ဝဇ္ဇိပုတ္တကရဟန်းတို့သည်`／`တေ ဘိက္ခူ= ထိုဝဇ္ဇိပုတ္တကရဟန်းတို့ကို`），指的是跋阇子**比丘**；译文作「有些人」「另一些人」「这些人」，身份信息丢了，而这段的要点恰在他们出家身份的存续（没舍戒行淫、一类还俗一类未还俗）。→ 改为「那些跋阇子比丘」「这些比丘」。
- **建议**：371-48-74 `saliṅge` nissaya 作 `ရဟန်းပဉ္ဇင်း၏ အသွင်သဏ္ဌာန်၌`（比丘的形相），译文「出家人的形相」略泛，可作「仍旧保持着比丘的形相」。（此处 liṅga=形相，与本层 375-377 的 liṅga=性征分开处理是对的，保留。）

## §371 句 205-371-75-92

- **必改**：`Keci pana` nissaya 明确补出 `ဆရာ`（`ကေစိ ပန= အချို့သော ဆရာတို့သည်ကား`），指的是**别的阿阇梨/诸师**的异说，不是泛指的「有些人」。这是义解传统里的他说，身份要点明。
- **建议**：「不过有些老师（阿阇梨）不明白这个意思，就说……」。

## §372 句 205-372-2-7

- **问题**：夹注 — 黑体「**把茅草编结起来**」已承父层定译，释义词 kusatiṇa 又译成同一个「茅草」，再把「（kusa）」挂在释义上，整句成了「把茅草编结起来，是说把茅草编结起来」，释义等于空转。
- **建议**：夹注改挂释义并显出草名，如「是说把 kusa 草（茅草）编结起来」。

## §373 句 205-373-30-38

- **必改**：除上文的自造黑体外，本句方向也译反了。nissaya：`သရီရံ= ခန္ဓာကိုယ်ကို`（宾格）＋`ပေါက္ခရန္တိ= "ပေါက္ခရ"ဟူ၍`＋`ဝဒန္တိ`——是「古师们把**身体**叫作 pokkhara」，sarīra 是宾语、pokkhara 是名称；译文「**身体**（pokkhara）指的是身体」把名称当成了被释词，成了同语反复。
- **建议**：「不过古师们把身体叫作 pokkhara，而 vaṇṇa 就只是颜色（肤色）。」（`ဝဏ္ဏံ= အဆင်းသည်။ ဝဏ္ဏမေဝ= အဆင်းသာလျှင်တည်း` 为主格判断句，「就只是」要保留 eva。）

## §373 句 205-373-83-88

- **分歧记录（建议不改）**：`kathaṃ` nissaya 作 `အဘယ်ကြောင့်`（为何），译文作「怎样」。但本句所引的答文（`asaddhammādhippāyena … khāṇukā viya`）给的是「如何坐」的譬喻，答的是方式；判定：保留「怎样」，nissaya 此处为宽泛套语。备案。

## §374 句 205-374-13-46

- **问题**：`abbhantare` nissaya 作 `ခန္ဓာကိုယ် အတွင်း၌`（身体内部／自身之内），译文作「内心」，把处格的所指收窄到心，无 nissaya 依据。
- **建议**：「凡是在自身内部不被这两种欲沾染的人」。其余格助词（莲叶/针尖处格、水珠/芥子主格、二欲具格、`tasmiṃ puggale` 处格）均与 nissaya 相符，无须改。

## §375 句 205-375-99-120

- **建议**：`kañci kālaṃ` nissaya 作 `စိုးစဉ်းအနည်းငယ်သောကာလ၌`（极短的一段时间），译文「又持续了一段时间」丢了「短暂」。→「又持续了很短一段时间然后灭去」。

## §376 句 205-376-19-28、205-376-38-48

- **分歧记录（建议不改）**：`tannissayassa liṅgassa` 两处 nissaya 都把 tad- 解作「那个人」（`ထိုပုဂ္ဂိုလ်ကို မှီ၍ဖြစ်သော` / `ထိုပုဂ္ဂိုလ်ကိုမှီသော`），译文解作「依靠它（根）的性征」。本段的推论正是「根无胜劣→依根的性征不可能有胜劣」「根坏灭/生起→依根的性征才消失/建立」，以根为所依才讲得通；判定保留现译，nissaya 异读在此备案。
- **建议（可读性）**：「因为如果根本身没有低劣与殊胜之分」—「根本身」易被误读成「根本+身」。→「因为如果根自身没有高下之分」（高下用字另见跨段一致性第三条）。

## §377 句 205-377-15-60

- **必改｜具格施事读反**：`katupacita-balavakusalakammena āhitasāmatthiyaṃ` 的具格是**施事**——nissaya 给它加的是施事标记 `ကတုပစိတဗလဝကုသလကမ္မေန= ဆည်းပူးအပ်သော အားရှိသော ကုသိုလ်ကံသည်`，`āhita-` 是被动（力量被赋予）。即：另造积的强善业**给**那个微弱善业加力。现译「这个善业……造作并积累了强有力的善业，使它获得了力量」把微弱善业当成了造业者，变成「善业去造善业」，施受颠倒。同一结构在 376-59-89 译得是对的（「有……不善业得到了机会，损坏了它的力量」），此处属前后不一的滑手。
- **建议**：「……而到了生命过程中，由于安住梵行、远离邪淫，或者由于祈愿得到男身而造作、积累起来的强有力的善业，使这个微弱的善业获得了力量，于是它有能力产生男根，不再产生女根，而产生与它自己的力量相应的男根——……」
- **建议（可读性）**：同句「产生女人女根的那个微弱的善业」宜作「产生女人的女根的」（`ဣတ္ထိယာ= မိန်းမ၏` 属格）。
