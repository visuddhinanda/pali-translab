# Review — 116:1195-1205（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（116-1202-84-90 无 nissaya 行）／父层对照 ✅（154:244-276，已定稿）
> ⚠ 本层就是义注，没有注入更高一层的释义标准（复注）。释义以义注原文自身的语境和 nissaya 为准。

## 被解释词与父层逐字核对

逐条比对了以下黑体词，**全部与父层译文逐字相同**：
- 慈心 / 整个世界 / 心 / 培养 / 无量
- 向上 / 向下 / 向四周 / 没有障碍 / 没有怨恨 / 没有敌意
- 应当对整个世界培养慈心
- 无论站着、走着 / 无论站着、走着、坐着
- 都应当保持这份正念
- 人们说，这就是此世的梵住

本层没有必改项。

**发现一处跨层释义冲突（需回头改父层，本层不动）**：
- 116-1205-29-60 的义注把 *idha* 解释为“在这里，也就是在圣者的法与律中”（**义注**：idha ariyassa dhammavinaye）。
- 父层 154-271 却把 *idha* 译成“此世”。父层的译法与义注的解释相悖，读者对照时会看到“此世”被解释成“法与律中”，对应关系断了。
- 建议：父层改为“人们说，这就是这里的梵住”，或者“……在这（法与律）中的梵住”。这需要在 revise/harmonize 时回改 154-271。
- 同一处的 *āhu*：nissaya 作 `အာဟု= ဟောတော်မူကုန်၏`（尊者们／诸佛宣说，敬语复数），不是泛指的“人们”。这是次要分歧，一并记录。

**次要的跨层观察**：
- 116-1197-71-78、116-1198-82-102 里义注对 *sambādha* 的解释（bhinnasīma 打破界限、okāsalokavasena 就空间世界而言），以及 nissaya `ကျဉ်းမြောင်း`（狭窄、局促），取义都偏向“局限、狭窄”。
- 父层把 *asambādhaṃ* 译成“没有障碍”，与此只是部分吻合。本层已照父层对齐，不改；建议父层定稿复核时考虑。

## 跨段一致性

- **paccatthika**：
  - 1197-79-87 译“敌对的人”；
  - 1197-97-100、1197-101-123 译“敌人”；
  - 1197-124-130 译“敌对者”，并且在这一句里明确拿“敌对者”和 sapatta“敌人”对举为同义词。
  - 前面把 paccatthika 也译成“敌人”，会让 1197-124 的同义词说明落空。
  - 建议 paccatthika 统一为“**敌对者**”，sapatta 保留“敌人”。依据是 1197-124 的对举结构。
- **pe 的译法**：1200 译作“……”，1202-20-71 译作“……乃至……”。建议统一为“……”。
- **mettābhāvanā**：1196 译“慈的修习”，1200、1202、1204 译“慈修习”。建议统一为“慈的修习”。
- **Tassattho／Tassāyamadhippāyo**：1201、1205 译“它的意思是”，1203 译“这里的意旨是”。tassa 指偈颂，建议 1203 改为“它的意旨是”，与前两处平行。

## §1197 句 116-1197-29-33
- **问题**：取义不清。前一句刚把 mānasaṃ 译作“心”，这句又说“它与心相应”，读起来像“心与心相应”。义注的意思是：这里称为 mānasa 的是慈（心所），因为它与心（citta）相应，所以说它“存在于意中”。
- **依据**：nissaya `တံ= ထိုမာနသိဘဝံဟူသော ဝစနတ္ထကို`、`စိတ္တသမ္ပယုတ္တတ္တာ= ကုသိုလ်စိတ်နှင့်သမ္ပယုတ်`。
- **建议**：“之所以这样说，是因为它（慈）与心相应。”

## §1197 句 116-1197-47-54 / 116-1197-55-62 / 116-1197-63-70
- **问题**：风格（必改）。“以此涵盖”中的“以”作文言虚词用。
- **建议**：三处都改为“用它来涵盖……”。

## §1197 句 116-1197-63-70
- **问题**：可读性。“向四周，就是中间”字面忠实，但读者难以理解。
- **建议**：可改为“**向四周**，就是中间一层”，以呼应上、下两层（无色有、欲有）。属于可选修改。

## §1197 句 116-1197-88-96
- **问题 1**：误读。*antarantarāpi* 是“时而、偶尔”，不是“间隙之中”。
- **问题 2**：法相术语 cetanā 首次出现，没有夹注。
- **建议**：“意思是说，即使偶尔，也不会生起怨恨的思（cetanā）。”

## §1198 句 116-1198-2-33
- **问题**：句法生硬。“对这无量的慈心，应当在整个世界培养”中，“对”字结构不通。
- **建议**：“就是这无量的慈心，应当在整个世界培养、增长，使它达到增长、增盛、广大。”

## §1198 句 116-1198-34-35
- **问题**：取义稍窄。nissaya `ကထံပါပယေ= အဘယ်သို့ရောက်စေရာသနည်း`，问的是“怎样使它达到（广大）”。
- **建议**：“怎样使它达到呢？”，或者“怎样做呢？”。

## §1198 句 116-1198-66-81
- **问题**：语序别扭（“使它成为……的，在……的同时来培养”）。另有一处 nissaya 分歧：nissaya 把 *taṃ* 解作“一切处所”（`ထိုအရပ်ခပ်သိမ်း`），但 1198-103 的 `taṃ … mettaṃ mānasaṃ` 显示指的是心。译文取“心”正确，不必改。
- **建议**：“这样培养时，还要消除障碍、怨恨和敌人，让它没有障碍、没有怨恨、没有敌意，用这种方式来培养。”

## §1198 句 116-1198-82-102
- **问题**：“随着空间世界而没有障碍”不通。*okāsalokavasena* 意为“就空间世界而言”。
- **建议**：“就空间世界（okāsaloka）而言，它在一切处都没有障碍”。

## §1201 句 116-1201-2-43
- **问题**：增译与措辞。
  - *bādhanavinodanaṃ* 是“消除不适”。译文的“加以调换”是推出来的做法，原文没有。
  - “疲累”比原词窄。nissaya 作 `နာကြင်ခြင်းကိုဖျောက်ခြင်း`（消除疼痛、不适）。
- **建议**：“随自己方便，消除这种或那种威仪带来的不适”。

## §1202 句 116-1202-20-71
- **问题 1**：取义（低信心）。“atha vā tiṭṭhaṃ vā…”里的 *atha*，nissaya 作 `အထ= ထိုအခါ၌`（这时），不是另起一解的“或者说”。下文“站立等姿势不会成为障碍”也是承接前句，不是另一种解释。
- **问题 2**：“在这上面他没有任何迟钝”生硬。
- **建议**：
  - “……就能做到；这时，无论站着、走着……躺着，站立等姿势都不会成为他的障碍”；
  - 结尾改为“他在这件事上毫不迟缓”。

## §1204 句 116-1204-2-29
- **问题**：时态误读。*dassento* 是现在分词（在说明的时候），不是 *dassetvā*（说明之后）。真正表示“之后”的是 *niyojetvā*。
- **建议**：“这样在说明慈的修习的自在时，用‘都应当保持这份正念’使人致力于这种慈住之后，现在为了赞叹这种安住，说了……”

## §1205 句 116-1205-2-28
- **问题**：断句。这一句只是关系从句，没有主句（yvāyaṃ … mettāvihāro，主句在下一行 *Etaṃ …*）。译文用“。”收尾，形成残句。
- **建议**：句末改为“——”或“，”，下一行以“这种慈住”起头承接。

## §1205 句 116-1205-29-60
- **问题**：句法不通。“因为他……都应当保持这份正念”把原因和“应当”混在一起。*yato*，nissaya 作 `ယသ္မိံ ကာလေ`（当……时）。
- **建议**：“……是最殊胜的安住，因为他是持续不断、毫无间断地，无论站着、走着、坐着还是躺着，只要没有昏沉，都保持着这份正念。”信心中等。
- *idha*、*āhu* 的跨层冲突见第一节。
