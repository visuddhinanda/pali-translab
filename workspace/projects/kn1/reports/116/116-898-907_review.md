# Review — 116:898-907（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层对照（154:87-152 定稿译文）✅／义注：本层就是义注，没有更上层的释义标准（复注未注入），释义判断以义注原文和 nissaya 为准

## 被解释词与父层对照

逐条核对结果：varo / varaññū / varado / varāharo / idampi buddhe / khīṇaṃ purāṇaṃ / purāṇaṃ / navaṃ / natthi sambhavaṃ / virattacittā / āyatike bhavasmiṃ / te / khīṇabījā / avirūḷhichandā / nibbanti / dhīrā / yathāyaṃ padīpo / idampi saṅghe，**均与父层逐字一致**。只有一处不够贴：

- **khīṇaṃ**（§904 句 116-904-45-49）：父层 §140 的译法是「旧业**已经灭尽**」，这里被解释词只取了「灭尽」，没有带上「已经」。同一 chunk 中 virattacittā 取的是「**已经**离贪」，khīṇabījā 取的是「种子**已经**灭尽」，都带了「已经」。建议改为「“**已经灭尽**”，是指已被彻底断除。」，与父层原样对应。

## 跨段一致性

- **工具格 -ena 与 nissāya 混译为「依据」**：§899 `pariyattidhammena … lokuttaradhammena` 译作「依据教法……依据出世间法」，§902 同样结构的 `navavidhena lokuttaradhammena` 却译作「以九种出世间法」。§902、§904 的 `nissāya` 也译作「依据」，`buddhādhiṭṭhānaṃ` 又译作「以佛陀为依据」。同一个「依据」对应三个不同的巴利成分，读者分不清。nissaya 在 §899 用的是 `ဖြင့်`，是具格，不是「依止」。→ 建议 §899 改为「世尊这样**以**教法说了以佛陀为依据的真实语之后，现在开始**以**出世间法来说」，与 §902 统一；「依据」只留给 nissāya 和 adhiṭṭhāna。
- **vara 修饰「道」的译法**：§899 句 69-76 `varassa maggassa` 译「最殊胜的**道**」，句 77-98 `purāṇamaggavaraṃ` 译「古老而殊胜的**道路**」，§901 `varaṃ maggasaccaṃ` 译「最殊胜的道谛」。varāharo 带来的正是这条道，这几处应当同词同译。→ 句 77-98 改为「古老而最殊胜的道」，与句 69-76 对齐。
- **adhiṭṭhāna 两义**：本 chunk 里，`buddhādhiṭṭhānaṃ`（§899、§902、§904）作「以…为依据」，`upasamādhiṭṭhāna` 等四项（§901）作「决意」。这两处本来就是两个词义，分开译是对的；但 §901 的四 adhiṭṭhāna 是固定法数（sacca / cāga / upasama / paññā，传统译「四依处」或「四决定」），宜在 `terms.md` 中定案。本次不强制修改。
- **「殊胜」同时对应 vara 与 paṇīta**：这是父层带下来的格局（父层 paṇīta→殊胜，dhammavara→殊胜之法）。§899 句 22-44 用 `paṇītādhimuttikehi`「倾心于殊胜之事」来解释 varo，结果解释词和被解释词都落在「殊胜」上，释义的层次感被削弱了。父层已定稿，这里不改，记录备案，统稿时再看。
- **sāvaka**：父层 §108 译「弟子」，§901 句 20-54 译「声闻弟子」。这里不是被解释词，可以接受，但建议统稿时统一。

## §898 句 116-898-2-3

- **问题**：标题对应不全。原文 `Varo varaññūti` 引的是两个词，译文只引了「最殊胜的那一位」。§899 正文引出的是「最殊胜的那一位，了知最殊胜者」，标题和正文对不上。
- **建议**：改为「“最殊胜的那一位，了知最殊胜者”偈注释」。

## §899 句 116-899-61-68

- **问题**：风格。「最殊胜之法」中的「之」是文言虚词。父层的「殊胜之法」是定稿的被解释词，那边不能动；但这里的 `varadhamma` 不是被解释词，可以用现代写法。
- **建议**：改为「最殊胜的法」。
- **附**：`nibbedhabhāgiya` / `vāsanābhāgiya` 传统译「顺抉择分」「顺熏习分」。现译「有助于洞察的法」「有助于熏习的法」通俗可读，但宜首次出现时夹注巴利原词，并登记到 `terms.md`。

## §900 句 116-900-2-15

- **问题**：风格（必改）。「解脱之乐」「至上的修行之道」中有文言虚词「之」。
- **建议**：改为「因为给予众生解脱的快乐」「因为带来至上的修行道路」。

## §901 句 116-901-2-19

- **问题**：术语。`upasama` 译「寂止」，容易和 samatha（止）的通行译法混淆。nissaya 原词作 `ဥပသမ`，义为平息、寂静。
- **建议**：改为「寂静的决意」（是否改成「依处」见上文跨段一致性一节）。

## §901 句 116-901-20-54

- **问题**：漏译。漏了 `tadatthāya`（为了那个目的，也就是为了成为声闻弟子）。影响较轻。
- **建议**：可以补为「为追求成为声闻弟子的人，为了这一目的而宣说……」，也可以保持现状，因为前文「追求成为声闻弟子」已经蕴含了这层意思。

## §902 句 116-902-54-60 ／ §906 句 116-906-60-66

- **问题**：误译（数字）。`koṭisatasahassa` = koṭi（千万，10⁷）× satasahassa（十万，10⁵）= 10¹²，即一万亿。nissaya 作 `ကုဋေတစ်သိန်း`（十万俱胝），也印证了这一点。译文「千亿」（10¹¹）差了一个数量级。两处相同。
- **建议**：改为「一万亿个世界」，或沿用传统译法「十万俱胝个世界」。两处同改。

## §904 句 116-904-45-49

- 见上文「被解释词与父层对照」：「灭尽」改为「已经灭尽」。

## §904 句 116-904-105-108

- **问题**：存疑（不改）。义注原文 `dhitisampannā` 中，dhiti 字面义是坚毅、坚定，所以「具足坚毅」是直译，并不算错。但 nissaya 把 dhiti 释为 `ပညာ`（智慧）。两说并存，而义注原文字面支持「坚毅」，故保留现译。
- **建议**：可以加脚注备列 nissaya 的读法（dhiti 作「慧」解），以说明为什么「智者」被释为「具足坚毅」。§905 句 94-125 的「由于具足坚毅，他们是智者」同此处理。

## §905 句 116-905-6-32

- **问题**：句法。`yesaṃ` 是关系代词，要和后文 `te khīṇāsavā bhikkhū` 呼应。译成「对于某些人来说」，就丢了这层指代，读起来像泛指。
- **建议**：改为「而对于那些人来说——阿罗汉道已经使他们渴爱的润泽干涸——这旧业……已经灭尽」，或者改成「对于那些已由阿罗汉道使渴爱的润泽干涸的人，这旧业……」。

## §905 句 116-905-94-125

- **问题**：风格（必改）。「最后之识」中有文言虚词「之」。
- **建议**：改为「最后的识」。
- **附**：译文漏了 `puna`（「再」，意思是不会再被称为有色或无色）；「一切施设的范围」中的「一切」是原文没有的增译。建议改为「不再落入“有色的”或“无色的”等等施设的范围」。

## §905 句 116-905-126-147

- **问题**：措辞（轻微）。`nagaradevatānaṃ` 译「城中诸神」，「诸」略带文言色彩。nissaya 作 `မြို့စောင့်နတ်`（守护城市的神）。
- **建议**：改为「城里的守护神」。

## §906 句 116-906-2-39

- **问题**：句法，读起来有歧义。`desanaṃ samāpesi ‘idampi saṅghe’ti` 的意思是「以『这也是僧伽中』这句话结束了开示」。现译「结束了这次开示：“这也是僧伽中”」，容易读成结束之后又说了这句话。
- **建议**：改为「……运用以僧伽为依据的真实语，以“**这也是僧伽中**”结束了这次开示。」

## §906 句 116-906-46-59

- **问题**：存疑。「所证得的」是增译，「这个」所指模糊。nissaya 把 `nibbānasaṅkhātaṃ` 释为「称为入涅槃（般涅槃）的」，指的是漏尽者的般涅槃，与偈中的 `nibbanti`（熄灭）呼应，不只是指所证得的涅槃本身。
- **建议**：改为「按上面所说的方式，漏尽比丘们称为涅槃的这种熄灭，也是僧伽中殊胜的宝」。保留被解释部分「这也是僧伽中殊胜的宝」。
