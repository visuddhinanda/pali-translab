# Review — 116:547-554（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层对照（154:48-86 吉祥经本文定稿）✅
> ⚠ 本 chunk 本身就是义注层，没有更上层的释义标准（未注入复注）。下面的释义判断依据是 nissaya 与父层本文，取义类意见的把握程度相应较低。

## 被解释词与父层对齐

- 本 chunk 的黑体有两处：§548 是义注自己的纲目偈，§554 是 Kolāhalaṃ… 和 kappakolāhalaṃ 的定义词。两处都不是从父层引出的被解释词，所以没有需要逐字对齐的黑体。
- **必改**：§548 纲目偈里的 evam(iccādipāṭha) 指的是父层 154:49 开头的 “Evaṃ me sutaṃ”。父层定稿译作“我是这样听说的”，本层译作“‘如是’”，对应关系断了，而且“如是”是文言（见 §548 句 2-10）。
- 可以对上的部分：§553 的 maṅgalāni cintayiṃsu 译“思索什么是吉祥”，与父层 154:51 maṅgalāni acintayuṃ 的“思索什么是吉祥”一致。§554 的 mātaraṃ/pitaraṃ upaṭṭhahatha 译“奉养”，mā pamādattha 译“不要放逸”，分别与父层“奉养父母”（154:63）、“不放逸”（154:70）一致。这几处都好。

## 跨段一致性

- **sirī / phussa 与 maṅgala 撞译名（必改）**：maṅgala 全篇固定译“吉祥”，但以下几处也用了“吉祥”，读者无法区分哪一个才是 maṅgala：
  - §550 句 57-92：sirī 译“吉祥”，sirivaḍḍhā 译“吉祥增长”。
  - §551 句 48-91：phussa- 连续四处译“吉祥的”（齿木、泥土、衣服、头巾）。
  - 建议：sirī 改“福运”（或音译“室利”），sirivaḍḍhā 改“福运增长”；phussa- 改“吉利的”。
- **phussa 前后译法不一**：§550 phussā 译“弗沙”（星宿名），§551 phussa- 译“吉祥的”。nissaya 对 §551 的解释是 `ဖုဿ…= အတွေ့ကောင်းသော`（触感好的），与“弗沙吉日”的理解不同。建议两段统一取一个解释：要么都按弗沙吉星理解，要么 §551 按 nissaya 理解。该句 confidence 压低。
- **muta 系列译名不对称**：
  - 动词义：diṭṭha 译“看见的”，suta 译“听到的”，muta 译“感触到的”。
  - 人名：diṭṭhamaṅgalika 译“见吉祥者”，suta- 译“闻吉祥者”，muta- 译“触吉祥者”。
  - 问题：mutaṃ 按 §551 句 43-47 的定义包括香、味、所触三种（nissaya：`မုတံ= ဂန္ဓရသဖောဋ္ဌဗ္ဗ…အာရုံ`），“触”和“感触到”只对应其中的触，把意思译窄了。
  - 建议：统一按传统“见闻觉”体系，muta 译“觉知到的”，人名译“觉吉祥者”。§548、§549、§551、§552、§553 各处同步修改。
- **abhimaṅgala**：全篇统一译“非常吉利”，这一点是一致的。但 maṅgala 本身用“吉祥”，这里换成“吉利”。如果采纳上面 phussa 改“吉利的”的建议，可以考虑把这里改成“极为吉祥”，以免再撞名。属于可选项。
- **tassāpi 的 api 漏译**：§550 句 93-101、§551 句 118-126 都译成“有些人接受了他的说法”，与 §549 句 69-77 完全相同，漏掉了“也”。建议改为“对他的说法，同样有些人接受，有些人不接受”。

## §548 句 116-548-2-10
- **问题**：文言 + 跨层引用断裂。“‘如是’等经文”中，“如是”是文言词，而且与父层“我是这样听说的”对不上。
- **建议**：改为“解释以‘我是这样听说的’开头的经文的种种意义时”，或“解释‘这样’等经文……”。另外，tattha 按 nissaya 是 `ထိုမင်္ဂလသုတ္တန်၌`（在这部吉祥经里），“在这里”可以改为“关于这部经”。后一点可改可不改。

## §549 句 116-549-22-68
- **问题**：存疑，两个词的取义与 nissaya 分歧，需在报告里记录并压低该句 confidence。
  - beluvalaṭṭhiṃ：译文作“木橘树苗”。nissaya 原文读作 vemupalaṭṭhi，释为“拿着莲茎束的人”，读法与本文不同。laṭṭhi 本义是杖、枝，“树苗”是推测。
  - kapilaṃ：译文作“褐色的牛”。nissaya 释为 `မျောက်`（猴子）。不过原文 gāviṃ vā kapilaṃ vā 各带 vā，是并列的独立项，译成“褐色的（牛）”有依据。
- **建议**：beluvalaṭṭhi 改为较中性的“木橘树枝”。kapila 暂时保留现译，分歧留待复注或其他译本核定。

## §549 句 116-549-2-21 / §550 句 116-550-2-8 / §551 句 116-551-2-21
- **问题**：存疑。“名叫……”是把 nāma 当作人名标记。nissaya 在 §549 和 §551 也作“名叫”（`အမည်ရှိသော`），但在 §550 作“持闻吉祥见解的”（`သုတမင်္ဂလာအယူရှိသော`）。
- **建议**：现译可以保留，记作异读。如改为“一个主张‘见吉祥’的人”，三段要同步修改。

## §550 句 116-550-28-37 / §551 句 116-551-22-31
- **问题**：句法。tena 被译成具格“用眼睛／用耳朵”。nissaya 两处都作 `တေန= ထိုကြောင့်`（因此），是表原因的连接词。另外，nissaya 把 sabbaṃ 补作“一切好的、不好的所缘”，现译“一切都成了吉祥”交代不够清楚。
- **建议**：改为“因此，如果看见的就是吉祥，那么（好的坏的）一切都会是吉祥”。§551 同样改。

## §550 句 116-550-57-92
- **问题**：
  - 撞名问题见“跨段一致性”。
  - sumanā 译“好心”，这里列举的是吉兆用语，“好心”不通。sumanā 可以是素馨花，也可以是人名。nissaya 只做了音写 `သုမန`。
- **建议**：sumanā 音译“须摩那”，首次出现夹注巴利原词；或者译“素馨花”。两种都要压低 confidence。

## §553 句 116-553-112-127 / §554 句 116-554-2-14
- **问题**：存疑。kolāhala 译“骚动”，带有混乱、动乱的意味。但 §554 描述的五种 kolāhala 都是天神事先四处宣告、引起轰动，不是动乱。
- **建议**：可以考虑改为“哄传”或“轰动”（劫哄传、转轮王哄传……）。如果改，§553、§554 的五个复合词和黑体要一起改。这一项不是必改。

## §554 句 116-554-15-83
- **问题**：风格，轻微。“满面哭容”偏书面。
- **建议**：改为“哭丧着脸”。

## OCR / 原文疑问
- §549 beluvalaṭṭhiṃ：nissaya 所据底本读作 vemupalaṭṭhi，疑似异读。只作记录。
- §551 phussadantakaṭṭhaṃ vā khādati：nissaya 把动词释为 `ဃာယတိ= နမ်းရအံ့`（闻），与原文 khādati（嚼）不符，疑似 nissaya 抄误。译文按原文译“嚼”是对的。
