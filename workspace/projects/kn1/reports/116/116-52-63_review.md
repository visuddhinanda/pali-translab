# Review — 116:52-63（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／父层（154:4-14，已定稿）✅／**释义标准 ❌**：本 chunk 本身就是义注层，审它需要复注（ṭīkā），本次未注入。下面的取义判断只以 nissaya 和义注上下文为依据，凡标“存疑”的地方都需要复注来定。

## 被解释词核对（父层 + 本层内引）

- **父层**：§52 `Saraṇattaya`译“三皈依”，与父层 154-4 一致 ✅。本 chunk 其余黑体词都不引自父层：§54 的黑体引自本义注卷首的偈，§59 的黑体引自 §58 所引的《义释》文。
- **本层内引**：§59 各黑体词（bujjhitā saccāni / bodhetā pajāyā / sabbaññutāya … / abuddhivihatattā … / buddhoti netaṃ nāmaṃ）与 §58 的译法逐字核对，**全部一致** ✅。
- §62 黑体`saraṇagamanādīsu`译“皈依等”，与 §61 标题“皈依与皈依者”一致 ✅。

## 跨段一致性

- **saraṇa / saraṇagamana / gamaka（必改，首要）**：本 chunk 的主旨就是区分这三者。saraṇa 指皈依处，即三宝（§62 44-50）；saraṇagamana 指皈依这个行为，即心的生起（§62 51-58）；gamaka 指皈依者。现在译文把 saraṇa 和 saraṇagamana 都译成“皈依”。结果 §62 44-50 的“那三宝也是皈依”和 §62 51-58 的“……的心，就是皈依”读不出区别，义注的辨析也就落空了。
  - 建议：saraṇa（名词，指对象）译“皈依处”，saraṇagamana 仍译“皈依”，gamaka 译“皈依者”。
  - 父层只有动词短语 saraṇaṃ gacchāmi，译作“我皈依”，没有单独译 saraṇa，所以改了不会破坏被解释词对应。
  - 涉及：§62 2-20 的“是皈依（saraṇa）”、§62 44-50 的“也是皈依”、§62 59-83 的“这是我的皈依”。
- **paññatti**：§54 两处 paññattito 译“得名”，§58 61-129 和 §59 154-174 译“施设” → 建议统一为“施设”（§54 改为“依……而施设”）。
- **sacca**：§54 的 saccābhisambodhi 译“真谛现观”，§55、§58、§59 的 saccāni 都译“诸谛” → 建议 §54 改为“对诸谛的现观”。
- **upakkilesa / parikkilesa**：
  - upakkilesa 在 §58 8-60（nirupakkilesa）译“随烦恼”，在 §62 163-202（saraṇagamanupakkilesa）译“杂染”。
  - parikkilesa 在 §62 2-20 也译“杂染”，与 upakkilesa 撞名。
  - 建议：upakkilesa 统一为“随烦恼”或“染污”；parikkilesa 按 nissaya 另译（见下面 §62 2-20 条）。
- **buddhi**：§59 28-36、37-45 译“觉智”；§59 123-131 译“觉”（与“无觉”对举）；§59 132-153 译“觉的性质”。建议统一为一个译法，以 123-131 的“觉”为准，因为它是同义词释义，又和被解释词“无觉”配套。
- **“为了表明……而说”句式**（dassetuṃ vuttaṃ / ñāpetuṃ vuttaṃ hoti / bodhanatthaṃ vuttaṃ）：
  - §59 81-101 和 132-153 译成“这是为了表明……，所以这样说”，语义重复。
  - §59 154-174 译成“是为了表明……而说的”。
  - 建议统一为后一种。
- **“正如……一样，同样，……”**（§59 2-15、16-27、81-101、132-153）：yathā…evaṃ 的“一样”和“同样”叠用，是翻译腔。建议统一成“正如……，同样……”，或“就像……一样，……”。
- **§57 与 §58 的“-ti buddho”句式**：§57 译“因觉悟而是佛”，§58 同一类 -ti 句式译“……，所以是佛”。建议 §57 改为“觉悟，所以是佛；使人觉悟，所以是佛”。
- **§56 与 §60 的结语**：§56 是“以上首先是从意义上……”，§60 是“这是从文字上……”。§60 的 byañjanato**pi** 带“也”，建议改为“以上是从文字上对佛的说明”，与 §56 平行。

## §54 句 116-54-2-29

- **问题**：风格（必改）— “无碍之智”的“之”、“依于蕴相续”“依于真谛现观”的“依于”都是文言写法。
- **建议**：改为“无碍的智”“依据蕴相续”“依据……现观”。
- **问题**：取义（存疑）— 复合词 appaṭihatañāṇa-nimitta-anuttaravimokkha 中的 nimitta，译文理解为“无碍智之因”。nissaya 作 `အာရုံဖြစ်သော`（作为……的所缘），理解为“所缘”，两者有出入。
- **建议**：暂维持译文，但压低信心；待复注定案。另外，sattaviseso 译“特殊的众生”偏口语，可考虑“殊胜的众生”。

## §55 句 116-55-2-47

- **问题**：取义 — sayambhū 译“自觉者”，和下文 buddha（觉）的词义混在一起。nissaya 作 `မိမိအလိုလိုထင်ရှားစွာဖြစ်` = 自然而成、自己生成。
- **建议**：改为“自成者”或“自然而成的人”。
- **问题**：原文异读（记录，不改）— pali 作 `balesu`（诸力），nissaya 作 `ဖလေသု`（phalesu，诸果）。译文跟随 pali，没有问题。

## §58 句 116-58-61-129

- **问题**：风格 — “在获得一切知智的同时，在解脱究竟时得到的、亲身证得的施设”，两个“在……时”叠用，读起来拗。
- **建议**：改为“这是诸佛世尊在菩提树下证得一切知智的同时、在解脱的终点亲身证得的施设，这就是‘佛’”。

## §59 句 116-59-37-45

- **问题**：取义（存疑）— sabbadhammabodhanasamatthāya 中的 bodhana，译文取使役义“能使人觉悟一切法”。nissaya 作 `သိစွမ်းနိုင်သော`（能够知），取非使役义。前一句 sabbaññutā 用 bujjhana，这一句用 bodhana，到底是“自知 / 令他知”的对比，还是同义换词，需要复注定案。
- **建议**：暂维持译文，压低信心，待复注确认。

## §59 句 116-59-123-131

- **问题**：准确性 — buddhi 和 buddhaṃ 都译“觉”，读者看不出这里列了三个不同的词；bodha 译“菩提”，又容易和 bodhi 混淆。
- **建议**：改为“觉（buddhi）、觉悟（buddha）、觉知（bodha），这些都是同义词”。另外，nissaya 此处读作 bodheti，属于异读，只记录不改。

## §59 句 116-59-154-174

- **问题**：风格（必改）— “符合其意义”中的“其”是文言虚词。
- **建议**：改为“与它的意义相符”或“随顺意义”。

## §62 句 116-62-2-20

- **问题**：术语 — saraṇa 译“皈依”，见跨段一致性第一条。
- **问题**：取义 — parikkilesa 译“杂染”。nissaya 作 `အဖန်တလဲလဲပူပန်ခြင်း`（反复的忧恼、折磨），这里与恐怖、痛苦、恶趣并列，指的是苦恼，不是烦恼染污。
- **建议**：改为“折磨”或“苦恼”。另外，nissaya 把 nirodheti 读作 nibbāpeti（使寂灭），属于异读，只记录不改。

## §62 句 116-62-51-58

- **问题**：句法 — vihataviddhaṃsitakileso 是修饰 cittuppāda 的有财释（意为“烦恼已被摧毁的心”）。译文却写成“烦恼被摧毁、消除，”断成了一个独立分句，主干“……的心就是皈依”被冲散。“它”指的是三宝，也不明确。
- **建议**：改为“由于对三宝的净信和尊重而摧毁、消除了烦恼，并以三宝为归宿的方式生起的心——或者说不依赖他缘的心——就是皈依”。另外，nissaya 对 aparappaccaya / parappaccaya 给出两读，复注可以定。

## §62 句 116-62-59-83

- **问题**：风格 / 标点 — 引语“这是我的皈依，这是我的归宿”悬在句中，没有引导词；“趋近于它”的“于”可以省掉。
- **建议**：改为“以上面所说的那种心，想着‘这是我的皈依处，这是我的归宿’，这样去趋近它”。这里外层是双引号，内层按规则用单引号。

## §62 句 116-62-84-162

- **问题**：术语 — Tapussa 译“多布沙”，不是通行译名。
- **建议**：查定后登记进 `terms.md`。南传常见的有“帝须／多波斯”等，北传作“提谓”，请人工定案。
- **问题**：风格 — “把上衣偏袒一肩”语序生硬。nissaya 作 `လက်ဝဲတစ်ဖက်ပုခုံးထက်၌…တင်၍`（搭在左肩上）。
- **建议**：改为“把上衣披在一边肩上”。

## §62 句 116-62-163-202

- **问题**：术语 — saraṇagamanupakkilesa 中的 upakkilesa 译“杂染”，见跨段一致性。
- **建议**：随统一译名修改。
