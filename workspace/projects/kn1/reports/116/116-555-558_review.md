# Review — 116:555-558（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 —（本层即义注，以本层上下文与父层 154 定稿为释义参照）／父层对照 ✅（154:48-86）

## 被解释词对齐（父层）

- §557 句 116-557-75-105：**bahū devā manussā cā** 译 **“许多天神和人类”**，父层 154-51-2-12 同处译“许多天神和人类”，**逐字相同** ✅
- 本 chunk 其余黑体（cakkavattikolāhalaṃ / buddhakolāhalaṃ / maṅgalakolāhalaṃ / moneyyakolāhalaṃ）不引自父层，由本层自定，见下方一致性检查。

## 跨段一致性

- **mārisa / mārisā**（呼格）：§556 译“尊者”，§557 译“诸位”，应统一为“贤友”（单数）和“诸位贤友”（复数）。依据：mārisa 是天神之间、天神对帝释的称呼。“尊者”在汉译里通常对应 bhante / āyasmā，会让读者误以为说话对象是出家人（详见 §556 条）。
- **moneyya**：§555 黑体 moneyyakolāhalaṃ 译“牟尼**行**的喧传”，同段 moneyyappaṭipadaṃ 译“牟尼**的行道**”，前后不对应。建议后者改为“牟尼行的修行之道”，或统一用“牟尼行道”，让读者看出黑体指的就是前句的事。
- **maṅgalapañha**：§556 和 §557 译“吉祥的问题”，§558 译“吉祥问题的缘起”。这项是轻微问题，建议统一为“吉祥的问题”，§558 相应改为“这就是吉祥的问题的缘起”；也可以全部统一为“吉祥问题”。
- **kolāhala → “喧传”**：本 chunk 内四处一致 ✅。五种喧传的第一种 kappakolāhala 在本 chunk 之外（§554 及之前），需要核对那里是否也译作“喧传”。
- **sakka devānaminda / devānaminda / devarājā / deva（呼格）**：分别译为“天帝释”“天帝”“天王”“天王”，这几种对应可以接受，不作修改。

## §555 句 116-555-100-108

- **问题**：句法误读（nissaya）。`ဒေဝ မနုဿာနံ= နတ်လူတို့အား` 是与格（“对天神和人类”），不是修饰 loke 的属格。译文“在天神和人类的世间出现了”把 devamanussānaṃ 和 loke 绑在了一起。
- **建议**：改为“在这五种喧传当中，这吉祥的喧传在世间出现，传遍了天神和人类。”也可译作“……在世间的天神和人类当中出现了。”

## §556 句 116-556-2-61

- **问题**：风格（轻度文言）。“我们何不去请问天帝释这件事呢”中，“何不”偏文言。另外，samacintesuṃ（nissaya `သဟစိန္တေသုံ` 作“共同思量”）译“这样思量”，丢了“一起”的意思。
- **建议**：前一处改为“我们不如去请问天帝释这件事吧”。后一处改为“一起这样商量”。

## §556 句 116-556-62-126

- **问题 1**：称谓误导。mārisa 译“尊者”，理由见“跨段一致性”。
- **建议 1**：改为“贤友，请您知道……”。
- **问题 2**：术语所指过窄。mutaṃ 译“感触到的”，只剩触觉。muta 在本义注体系中指嗅、尝、触三类所觉知的对象，本书下文解释“觉知吉祥论者”时会展开。
- **建议 2**：改为“觉知到的是吉祥”，必要时首次出现时夹注（muta）。
- **问题 3**：主语范围。eke 译“有些人”，nissaya `ဧကေ= အချို့သောနတ်တို့သည်` 补出的是“有些天神”。这里是天神在向帝释转述各方的说法，“有些人”会让读者以为只指人类。
- **建议 3**：改为中性的“有的说……”，三处一并修改。

## §557 句 116-557-33-74

- **问题**：措辞。“丢下火焰，却去点亮萤火虫”中，ujjāletha 的意思是“使之燃旺、吹亮”，但萤火虫并不能“点亮”，比喻读起来别扭。sassirikaṃ 译“精彩的”，语感偏轻。
- **建议**：改为“丢下火焰，却去吹萤火虫想让它发亮呢？”；“精彩的解答”改为“圆满的解答”或“光辉的解答”。这一条非必改。

## OCR / 原文疑问（只记录，不改）

- §556-2-61：pali 作 `vicinitvā vicinitvā`，nissaya 作 `ဝိစရိတွာ`（vicaritvā）。pali 作 `samacintesuṃ`，nissaya 作 `သဟစိန္တေသုံ`（sahacintesuṃ）。译文依 pali，没有问题。
- §555-49-69：pali 作 `devamanussānaṃ cittaṃ`，nissaya 只作 `မနုဿာနံ`（manussānaṃ），疑似 nissaya 脱字。
- §556-142-154、§556-155-174：nissaya 补出了 `သန္တိကာ`（santikā，“从……那里”），pali 原文没有这个词。译文已按补出的意思译为“从……那里听来的”，处理得当。
