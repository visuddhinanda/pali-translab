## 跨段一致性

- **vimutti / vimokkha**：§236 vimutti 译「解脱」，§238 vimokkha 也译「解脱」，两个不同术语混成一个汉译。义注 §1122 明确 vimokkha 指八解脱。
  → 建议 §238 作「解脱（vimokkha）」，用首次夹注区分，并同步义注 §1121 被解释词。
- **夹注体例**：本 chunk 只有 §238 的 paṭisambhidā 夹注了巴利原词。vimokkha、sāvakapāramī、paccekabodhi 等法相术语首次出现都没有夹注，与 `style.md`「法相术语首次出现夹注」不一致。
  → 至少补 vimokkha（见上），其余可按术语表定。
- **deva 的译法（跨层）**：§223 devamanussānaṃ 译「天人和人类」。义注 §1110、§1113 把 deva 译作「天神」。而且「天人」在汉语佛典中常指「天与人」合称，与后面的「人类」叠在一起容易误读。
  → 建议统一为「天神和人类」，同步义注 §1083、§1088（其中的「天人和人类」）。
- **dibbesu / devaloke**：§230 dibbesu 与 §232 devaloke 都译「天界中」。可以接受，但义注 §1110 把 dibbesu 解作「天界身类中（天上众生）」，§232 的 devaloke 则是「天神的世界」。
  → 不强求改。如要区分，§230 可作「天神中」，需同步义注 §1110 被解释词「还有天界中」。
- **sunihito**：§202「妥善地埋」、§212「妥善地埋下了」、§217「妥善埋藏的」，同一词三种译法。三处都已被义注逐字引用，差异只在动词尾巴，不影响理解。
  → 不建议为统一而改。
- **叠句**：「这一切都能借它得到」在 §224、227、230、233、236、239 一致。✅

## §196 句 154-196-2-9

- **问题**：取义 — 「一旦有事需要用钱」把 atthe kicce 窄化成「用钱」，原文没有这个意思。
  - **义注**：atthā anapetanti atthaṃ, atthāvahaṃ hitāvahanti vuttaṃ hoti … Tasmiṃ atthe kicce samuppanne（不离于利益的、带来好处的事）。
  - nissaya：`အတ္ထေကိစ္စေ= အကျိုးစီးပွါးနှင့်စပ်သောအမှုကိစ္စသည်`（与利益相关的事务）。
  - 两者都指「有利益关系的必办之事」，不限于钱。
- **建议**：改为「一旦有关乎利益的事要办，它就能派上用场」。「心想」是据 nissaya 的 `ဣတိမနသိကတွာ` 补出，合理，可以保留。
  - 同步义注 §1034 被解释词「**一旦有事需要用钱**」。

## §198 句 154-198-2-9

- **问题**：取义（必改）— 「摆脱国王的责难」把 durutta（被恶言诬告）的施事理解成了国王。
  - **义注**（§1040）：paccatthikehi paccāmittehi duruttassa me sato rājato vā pamokkhāya，即被仇敌诬告时，借宝藏免遭国王（治罪）。说坏话的是仇敌，不是国王。
  - nissaya：`ဒုရုတ္တဿ= ရန်သူတို့သည်စွပ်စွဲအပ်သည်` … `ရာဇာတောဝါ= မင်းဘေးမှမူလည်း`（被敌人诬陷的我，从国王的祸患中），也明确施事是「敌人」。
- **建议**：改为「被人诬告时，为了免遭国王治罪；被盗贼逼迫时，为了摆脱盗贼，」。
  - 同步义注 §1037（偈文引句）、§1040（「帮我摆脱国王的责难」）、§1043（「为了摆脱国王的责难」）。

## §208 句 154-208-2-9

- **问题**：语态 — appiyā dāyādā 译「不喜欢他的继承人」，把方向弄反了。
  - nissaya：`အပိယာ= မချစ်အပ်ကုန်သော`，是被动式「不被喜爱的」，即他所不喜爱的、不肖的继承人，不是「继承人不喜欢他」。
  - **义注** §1040 appiyadāyādato 也只说「不可爱的继承人」，没有支持「继承人厌恶他」的读法。
- **建议**：改为「或者他所不喜爱的继承人」（或「不肖的继承人」）。信心中等，可在统稿时定案。
  - 同步义注 §1040（「不喜欢自己的继承人」）、§1053（偈文引句）、§1054 被解释词「**不喜欢他的继承人**」。

## §218 句 154-218-2-8

- **问题**：取义（必改）— 「当他舍下一切必须离去时」正是义注**明确驳斥**的那种解释。
  - **义注**（§1079）先引「死亡来临时，在一切财物都必须舍下、离去的时候」，标 kira（据说），随即说 So pana na yujjati（这个解释说不通），理由是财物带不走。
  - 义注采用的解释是：pahāya maccaṃ bhogesu gacchantesu，即财物舍弃这个凡人而离去的时候。
  - nissaya：`ပဟာယ= ဥစ္စာရှင်ကိုစွန့်၍` `ဂမနိယေသု= သွားတတ်ကုန်သောဥစ္စာတို့တွင်`（财物舍弃主人而去），与义注一致。
  - 「一切」在原文中也没有。
- **建议**：改为「当财物舍他而去时，他却带着这份宝藏走。」
  - 同步义注 §1077（偈文引句）、§1079 被解释词。被解释词改后，义注 §1079 先引后驳的论证依然成立。

## §235–236 句 154-235-2-27 / 154-236-2-8

- **问题 1**：取义（必改）— 「明、解脱和自在」把 vijjāvimuttivasībhāvo 拆成三个并列项。
  - **义注**（§1118）：vijjāvimuttīsu vasībhāvo，是「在明与解脱上的自在」，属于依主释，只有一项。义注 §1118 现行中译「在明与解脱上的自在，就是**明、解脱和自在**」自相矛盾，正好暴露了这个问题。
  - nissaya：`ဝိဇ္ဇာ…နိဗ္ဗာန်၌လေ့လာသောဝသီတော်ရှိသော အဖြစ်`（于三明、八等至、涅槃上具自在的状态），同样是一项。
- **建议**：改为「对明与解脱的自在，这一切都能借它得到。」
  - 同步义注 §1118 被解释词。
- **问题 2**：句法 — payuñjato 是与格 / 属格「对于修行者」（nissaya `ပယုဉ္ဇတောအား`）。现译「……精进修行的人，明、解脱和自在……」悬空，缺少关系词。
- **建议**：改为「对于依靠具足善友、如理精进修行的人来说，」。这样「依靠具足善友」「精进修行的人」两个被解释词保持连续，义注无需改。

## §241 句 154-241-2-9

- **问题**：被解释词断裂（必改）— 义注 §1125 分别解释 esā「**就是**」、yadidaṃ「**也就是**」。
  - 本文译文「福德的具足就是这样有大利益」中没有「也就是」，yadidaṃ 被吞掉了。
  - 句中的「就是」是语气强调，也不对应 esā。
- **建议**：改为「这样有大利益的就是它，也就是福德的具足；」。这样「这样」「有大利益」「就是」「也就是」「福德的具足」五个被解释词都能逐字落在本文里。
  - 同步义注 §1124 引句「福德的具足就是这样有大利益」。

## §242 句 154-242-2-8

- **问题**：取义（轻）— katapuññataṃ 是「已造福德的状态」（**义注**：katapuññabhāvaṃ；nissaya：`ပြုအပ်ပြီးသောကောင်းမှုရှိသောသူ၏အဖြစ်ကို`）。现译「已经造作的福德」偏指福德本身，与义注原意有落差，但不算误读。
- **建议**：可改为「称赞造作了福德这件事」。如改，需同步义注 §1125 被解释词。优先级低。
