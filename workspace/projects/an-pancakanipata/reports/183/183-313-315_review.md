# Review — 183:313-315（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本段未注入）／父层（义注）❌（未注入）
> ⚠ 本层是**复注（ṭīkā）**，正文中加粗的 `satthavaṇijjā` / `āvudhabhaṇḍaṃ` / `kāretvā` / `tassa` / `vikkayo` / `sūkaramigādayo` / `posetvā` / `tesaṃ` 都是从**义注**原样引出的被解释词，而义注译文本次未提供。
> 因此「被解释词与父层逐字同译」这一首要项**无法核查**，下列只能查复注内部的自洽性。待父层译文可取时，必须回头逐字比对下列词：satthavaṇijjā=武器买卖／āvudhabhaṇḍa=武器用品／kāreti=让别人制造／sūkaramiga=猪、鹿／poseti=饲养／vikkaya=卖出／vaṇijjā=买卖／vaṇṇanā=注释。

## 跨段一致性

- **vaṇijjā**：§313、§315 标题译「**商业**经」，§314 正文一律译「买卖」（武器买卖、众生买卖、酒类买卖）→ **必改**。同一词在同一 chunk 内两种译法，且标题与所注释的内容脱节。建议统一为「买卖」，标题作《买卖经》（依据：§314 内连续五处均作「买卖」，且 AN 5.177 的传统汉译亦作「贩卖/买卖」，非「商业」）。
- **vikkayo（被解释词）**：§314-21-29、§314-30-41 两处都把加粗落在「它／它们」上，而真正对应 `vikkayo` 的「卖出去」在加粗之外 → 见下逐句条目，属被解释词标注错位。
- **四个 ablative 理由的句式**：§314-42-57 里 `-nimittatāya / -karaṇato / -hetuto / -ṭhānato` 原文是同一套平行结构，译文却分别作「会成为…的原因／造成了…的身份／以…为缘由／是…的根源」，平行性丢失。建议统一为「因为它（们）会成为…的原因」一类同构句式。
- kāretvā 在 §314-6-20 与 §314-21-29 均译「让别人制造」——一致，可保留。

## §314 句 183-314-21-29

- **问题**：被解释词标注错位（必改）— 原文四个独立被解释词 `**Āvudhabhaṇḍaṃ**` `**kāretvā**` `**tassa**` `**vikkayo**`，译文作「**让别人制造**武器**用品**，然后把**它**卖出去」：`āvudhabhaṇḍaṃ` 的译文被「武器」「用品」劈成两截、中间夹入非该词的内容，`vikkayo` 对应的「卖出去」完全没加粗。加粗是本层与义注的对应关系凭证，断开即对应关系断裂，可机械核查。
- **建议**：按词边界各自成块，例如「把**武器用品****让别人制造**出来，然后把**它****卖出去**」；若汉语语序不允许逐词紧贴，至少保证每个加粗块是该被解释词的完整译文、不夹入他词（如「**让别人制造****武器用品**，然后把**它****卖出去**」）。
- **问题**：`idaṃ pana` 的转折（pana）未落地 — 「这只是举一个例子而已」漏掉与上句的对比语气（上句给定义，本句说明定义里的说法只是示例、并非限定）。
- **建议**：「不过，这只是举例说明而已。」

## §314 句 183-314-30-41

- **问题**：被解释词标注错位（必改）— 原文是 `**Sūkaramigādayo**` `**posetvā**` `**tesaṃ**` `**vikkayo**` 四个词，译文「**饲养猪、鹿等**，然后把**它们**卖出去」把前两词合并进一个加粗块（且语序把 poseti 提到 sūkaramiga 之前），`vikkayo` 的「卖出去」又漏加粗。
- **建议**：「**猪、鹿等****饲养**起来，然后把**它们****卖出去**」——四块分别对应，不合并、不漏。
- **问题**：`tesaṃ maṃsaṃ sampādetvā` 的「sampādeti」译作「取得」偏轻 — 该词指把肉**整治、加工出来**（宰杀后备办成肉），「取得」读起来像从别处买来，恰好抹掉复注要点（自己养、自己弄出肉来卖）。
- **建议**：「把它们的肉整治出来，然后卖出去」。

## §314 句 183-314-42-57

- **问题**：误译（必改）— `visa` 译作「**毒品**」。visa 指毒物、毒药，「毒品」是现代汉语的毒品（麻醉品）专称，与原意不符，且会让读者以为律中禁的是毒品贸易。
- **建议**：改「毒药买卖」（五种买卖作：武器买卖、众生买卖、肉类买卖、酒类买卖、毒药买卖）。
- **问题**：因果方向读反的风险（必改）— `maṃsavisavaṇijjā vadhahetuto` 译「是因为它们**以杀害为缘由**」。`vadhahetuto` 是「因为（它们）是杀害的原因」，即这类买卖会导致杀生；译文「以杀害为缘由」读成了「它们的缘由是杀害」，主从颠倒。
- **建议**：「因为它们会成为杀生的原因」——与前文「会成为伤害他人的原因」同构。
- **问题**：`abhujissabhāvakaraṇato` 译「造成了不自由的身份」偏模糊 — bhujissa 是「自由人」，abhujissabhāva 指落为不自由（奴仆）的状态；另「造成了」的完成态不合此处泛指说理的语气。
- **建议**：「因为它使人落入不自由（为奴）的处境」。
- **问题**：`pamādaṭṭhānato` 译「放逸的根源」— ṭhāna 此处是「立足处、所依之处」，「根源」尚可，但与上文三处的「原因」并列时语义层级不齐（见跨段一致性）。
- **建议**：「因为它是放逸的根由」，并与其余三句统一句式。

## §313 句 183-313-4-4 ／ §315 句 183-315-2-4

- **问题**：术语不一致（必改）— 「《商业经》等的注释」「《商业经》等的注释结束」中的「商业」与正文「买卖」冲突，见跨段一致性第一条。
- **建议**：统一作「《买卖经》等的注释」「《买卖经》等的注释结束」；若父层义注的标题译法另有定本，以父层为准，连带回改 §314 正文。

## OCR / 原文疑问（记录，不改）

- §314-42-57 `paroparādhanimittatāya`：按构词应为 `para + aparādha`（→ paraparādha）或 `para + uparodha`（→ paroparodha，损害他人）；现形 `paroparādha` 两头都不严整，疑为版本异读或讹字。两种读法都指向「加害／损害他人」，故现译「伤害他人的原因」可用，不必改，仅备查。

## 存疑处

- 「第七经」「第八经」依 `Sattame` / `Aṭṭhamaṃ` 译出，指的是该品第七、第八经（对应 §314 开头的 177-178）。若父层义注对经号另有表述（如「第七经中」「第八显而易见」），以父层为准。
- 本层加粗词的最终译法全部待父层义注译文落定后复核；在此之前不宜据本报告单方面改动加粗词的用字（标注位置的错位可以先改，用字先不动）。
