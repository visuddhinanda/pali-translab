## 二、跨段一致性

- **khetta**：§300 黑体作「田**产**等」（随父层），同句释文作「田**地**等」——同一个词在同一句里两种译法。建议释文保持「田地等」（这是 khetta 的本义），并把父层「田产等」登记给 harmonize 统一；黑体本身不要动。
- **-cārika**：父层 dīghacārika 作「游行」、anavatthacārika 作「游荡」；§300 释文把 anavatthānacārika 译成「到处**游行**」。建议释文改「到处游荡」，与黑体「四处游荡」一致。
- **āgamanadiṭṭhi**：§302 作「期待果报**之见**」，§303 同一概念作「相信业和果报」。建议 §302 改为「相信将来会有果报的见解」，与黑体「（不）相信业与果报」呼应。
- **「与」/「和」**：§303-60-74 黑体「相信业**与**果报」，紧接释文「相信业**和**果报而布施」。统一为「与」。
- **dakkhiṇeyya**：§303 两处均作「应受供养的人」 ✅ 一致。
- **cittīkāra**：§302「不敬重的心」／§303「敬重的心」 ✅ 一致。
- **篇题格式**：§299「六、朋友经释义」／§301「七、不善人布施经释义」 ✅ 一致；§300「第六经中」／§302「第七经中」 ✅ 一致。
- **标点**：全篇全角，引号为 “”，无 ASCII 引号 ✅ 符合 style.md 与 JSON 安全约束。

## 三、§300 句 101-300-2-12（父层越层问题，留给 harmonize）

- **问题**：跨层对应 — 父层本文把本层义注的解释**预先搬进了本文译文**，导致本层出现「A，是指 A」的空转。四处：
  - 「让人经营**田产等**的事务」← 本层 `khettādikammantaṃ`
  - 「**名闻四方**的上首比丘」← 本层 `disāpāmokkhesu`
  - 「不恭敬、**不洁净**地布施」← 本层 `suciṃ katvā`
  - 「**不相信业与果报**而布施」← 本层 `kammañca vipākañca saddahitvā`（实出自 §303）

  读者读本文已得释义，再读义注会觉得这条注什么也没注。**义注是解释，不是本文**，本文译文不应吸收义注内容。
- **建议**：本层不动（黑体必须与父层逐字一致）。记入 harmonize 待办：父层回改为贴近原文的译法（如「让人经营事务」／「上首比丘」／「不恭敬地布施」／「不抱果报之见而布施」），同步更新本层黑体。**本步不改任何译文。**

## 四、§300 句 101-300-26-33

- **问题**：指代不明 — 「是指由于采取敌对的立场而与**他们**相违」，本句黑体仅「对立」，句内没有「他们」的先行词，读者不知指谁。
- **问题**：风格 — 「相违」是文言词，`style.md` 第一节要求双音节现代词。
- **建议**：「是指因为处处持反对的立场，而跟那些上首比丘作对。」

## 五、§300 句 101-300-13-19

- **问题**：释义偏简 — 「四种诤事」未说明是哪四种，读者无从索解（义注原文也只说 `cattāri adhikaraṇāni`，不是漏译）。
- **建议**：正文不必加字；交 footnote 步补注（诤事、责难事、犯罪事、义务事）。属建议项，非必改。

## 六、§302 句 101-302-38-51

- **问题（必改）**：风格 — 「这样的**期待果报之见**」，「之」为文言虚词，`style.md` 明列禁用。
- **建议**：「是指不生起‘所做的事将来一定会有果报’这样期待果报的见解，就布施。」
- **问题（OCR / 原文疑问，只记录不改）**：原文作 `na evaṃ āgamanadiṭṭhiṃ na uppādetvā deti`，`na … na` 双重否定，与上下文（这是「不善人」一侧）矛盾；通行本当为 `evaṃ āgamanadiṭṭhiṃ anuppādetvā deti`。现译按单重否定处理，**语义方向正确**。建议登记到 `knowledge/known-issues.md`「OCR / 原文问题」。

## 七、§302 句 101-302-18-24

- **问题**：风格 — 「以不敬重的心、以没有恭敬的方式布施」，两个「以……」叠用，且「不敬重／没有恭敬」语义重复，读来绕口。
- **建议**：「是指怀着不敬重的心、带着轻慢的态度布施。」（`acittīkārena` 对「心」，`agāravavasena` 对「态度」）

## 八、§302 句 101-302-25-37

- **问题**：与黑体不搭 — 第二释「布施的时候像是想把东西丢掉一样」与黑体「断断续续地布施」字面无关，读者会以为注错了行。根因同第三节（父层只取了第一释 `na nirantaraṃ` 去译 `apaviddhaṃ`）。
- **建议**：本层照译无误，不动。随第三节一并交 harmonize：父层若改作「像丢弃一样地布施」，两释就都能挂上。

## 九、§303 句 101-303-14-24 与 101-303-25-32

- **问题（必改）**：主谓搭配不通 — 「……布施**的人**，就叫做对所施的物品**生起敬重的心**」「挑选受施的人再布施**的人**，就叫做对应受供养的人**生起敬重的心**」。主语是「人」，谓语是「生起……心」，「叫做」两端接不上（人 ≠ 心）。两句同病。
- **建议**：
  - 「这里，把所施的物品做得精美、富有滋养再布施，这就叫做对所施的物品存着敬重的心。」
  - 「挑选堪受供养的人再布施，这就叫做对应受供养的人存着敬重的心。」
- **附**：§303-25-32「挑选受施的人」宜作「挑选堪受供养的人」，否则易被读成择施、挑拣施主，与 `dakkhiṇeyya`（应受供养者）的语义相反。

## 十、§303 句 101-303-33-59

- **问题**：可读性 — 「我要成就轮回的解脱、生存的出离」，两个「……的……」偏正结构并列，「生存的出离」尤其生硬（`vaṭṭamokkhaṃ bhavanissaraṇaṃ karissāmi`）。
- **建议**：「我要从轮转中解脱出来、从生存中出离。」属建议项。
- **已核**：`vicarantena me`（具格）译作「在无始的轮回中流转的我」，与 `aladdhakālassa pamāṇaṃ natthi` 的归属关系处理正确；待 nissaya 补入后复核格助词。

## 十一、§303 句 101-303-2-13

- **问题**：术语显化 — 「在善的一面」对 `sukkapakkhe`，意思对，但未点明这是与前段「黑分（不善人一侧）」相对的结构标记，读者可能不知为何突然换边。
- **建议**：「在善的一面（即善人布施这一组）」或「反过来，在善的一面」。属建议项。
