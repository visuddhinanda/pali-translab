# Review — 88:566-574（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位核对无法进行）／义注 ✅（book 101 §166–167）
> 本层为本文（mūla），无父层对照；下面「义注」均指 book 101 对应段，是解释，不是本文的说法。

## 跨段一致性

- **五个称号**：569-66 的总列与 570/571/572/573/574 的分释译法完全一致（已举起门闩／已填平壕沟／已拔出柱子／没有门栓／放下旗帜、放下重担、已经解开束缚的圣者）✅ 一致性没问题。但其中三项的译名本身要改（见下），改时 **569-66 与对应分释段必须同步**，否则这条一致性会被破坏。
- **`ucchinnamūla / tālāvatthukata / anabhāvaṃkata / āyatiṃ anuppādadhamma`** 定型句在 570-12、571-12、572-12、573-13、574-15 五处译文逐字相同 ✅。该句若按下面「风格」项调整，同样五处同步。
- **`saññā` 的构词不统一**：569-7 内部「厌逆的想」「不喜乐的想」与「死想」三种结构混用，同一术语成分译法不一。建议统一为「食物厌逆想」「一切世间不可乐想」「死想」，或统一都用「对…作…想」。
- **`paligha`（门闩）与 `aggaḷa`（门栓）** 分别译「门闩」「门栓」，汉语里两词几乎无法分辨，读者会以为是同一件东西重复说。建议至少让其中一个具象化（`paligha` 作「横木／门闩」），并在首次出现处夹注巴利原词。

## §569 句 88-569-66-115

- **问题**：义注释义（术语所指）— `niraggaḷo` 译「没有门栓的人」方向译反。**义注**：`**Niraggaḷo**ti nīvaraṇakavāṭaṃ ugghāṭetvā ṭhito`（把盖障的门扉**打开**之后而住立）；§167 又作 `pañcorambhāgiyasaṃyojanaaggaḷaṃ ugghāṭetvā`。即「门栓已被打开／除去」，是成就的结果；译成「没有门栓」会让读者以为本来就没有栓，与本文 573 所说「五下分结已断除」的因果脱节。
- **建议**：改为「已除去门栓的人」或「门闩已开的人」；569-66 与 573-2、573-28 三处同步。

- **问题**：义注释义（术语所指）— `abbūḷhesiko` 译「已拔出柱子的人」，「柱子」过泛。**义注**：`taṇhāsaṅkhātaṃ **esikāthambhaṃ** abbuyha luñcitvā ṭhito`；§167 的喻中是城门前竖立的 `esikāthambha`，被剑砍断。这是界标石柱，不是一般柱子。
- **建议**：改为「已拔出石柱的人」或「已拔除界柱（esika）的人」；569-66 与 572-2、572-28 三处同步。

- **问题**：义注释义（取义）— `visaṃyutto` 译「已经解开束缚」。**义注**：`**Visaṃyutto**ti vaṭṭena visaṃyutto`（与轮转离系）。译文把它读成「解开了捆着自己的东西」，离系的对象（vaṭṭa 轮转）丢了；又与 573 的 `saṃyojanāni`「结」同源却译得像两回事。
- **建议**：改为「已离系的圣者」或「不再被系缚的圣者」；569-66 与 574-2、574-29 三处同步。

- **问题**：风格（style.md 第二节）— 五个称号属法相术语，首次出现未夹注巴利原词。
- **建议**：569-66 首次出现处按「沙门（samaṇa）」的格式夹注 `ukkhittapaligha` 等原词，其后只用汉译。

## §568 句 88-568-2-29

- **问题**：准确性／可读性 — `-phalā ca … -phalānisaṃsā ca` 译「既以心解脱为果，也以心解脱为利益」。`ānisaṃsa` 是「由此带来的功德利益」，与「果」确有分别，但「为果／为利益」两句在汉语里近乎同义反复，读者看不出差别在哪。
- **建议**：「既以心解脱为果，也以心解脱为功德利益」，或首次出现时夹注「利益（ānisaṃsa，即由此果带来的好处）」。569-45 同句同步。

- **问题**：风格 — 「多作」（bahulīkata）是旧译的单音节文言式表达，现代读者不易懂。
- **建议**：「修习、反复练习之后」或「经过修习、多次修习」。568-2、569-45 两处同步。

- **问题**：格式 — 经号 `71.` 译作「七一、」。同 chunk 的品名「（八）三、」是篇章序号，译成中文数字合理；但经文编号转成中文数字会妨碍检索定位。
- **建议**：保留「71.」。属可选项，若保留中文数字，至少与全书其他经号取同一规则。

## §569 句 88-569-7-44

- **问题**：准确性（搭配）— `sabbasaṅkhāresu aniccānupassī` 译「对一切行怀着无常的观」。`anupassī` 是「观察…为无常」，不是「怀有一种叫无常的观」；汉语「怀着无常的观」不成搭配。
- **建议**：「于一切行观无常」或「观一切行为无常」。同句前面的 `asubhānupassī kāye viharati`「安住于观身不净」译法是对的，两处句式应拉齐。

- **问题**：风格 — 「死想在他内心里确立得很稳固」口语化，且「确立得很稳固」是补语式口语。
- **建议**：「而且他内心已经牢固地建立起死想」。

## §570 句 88-570-12-25

- **问题**：风格（半文言）— 「已归于无有」（anabhāvaṃkata）是半文半白，按 style.md 总原则应改。
- **建议**：「已使它不再存在」或「已彻底灭除」。另「根已切断」语序生硬，建议「连根断除」。整串可统一为：「已经断除，连根拔起，像截去顶端的棕榈树那样（不再生长），已彻底灭除，将来不会再生起。」—— 570-12、571-12、572-12、573-13、574-15 五处必须同步改。

- **问题**：准确性 — `tālāvatthukata` 译「像被截断的棕榈树那样」。该喻指截去顶端后不能再生长的棕榈树残桩，「被截断」没有传出「不能再生」这一关键点（也正是它与下文 `anuppādadhamma` 呼应的地方）。
- **建议**：「像截去顶端的棕榈树那样」，五处同步。

## §571 句 88-571-12-35

- **问题**：可读性 — 「那导致再有的生死轮回」中「再有」（punabbhava）未经解释，现代读者看不懂；「那」作定语起头也生硬。
- **建议**：「比丘那导致再生的生死轮回已经断除…」，或「会带来后有（punabbhava）的生死轮回」。

## 核对通过、但需留意的点

- 569-66 `Yato kho` 译「当…的时候」与**义注**`**yato** **kho**ti yadā kho` 一致 ✅（未误读为「因为」）。
- 570 以「无明」释 `ukkhittapaligha`、571 以「生死轮回」释 `saṃkiṇṇaparikha`、572 以「渴爱」释 `abbūḷhesika`、574 以「我慢」释 `pannaddhaja`，均与义注的 `avijjāpaligha / saṃsāraparikhā / taṇhāsaṅkhātaṃ esikāthambhaṃ / mānaddhaja` 对应一致 ✅。
- 全角引号使用正确，连续引语按「每段首加前引号、末段收尾」处理，569-66 与 574-29 的收尾与原文 `’’’`、`’’ ti` 位置相符 ✅；未发现 ASCII 引号，未发现译文内的工作标记 ✅。
