# Review — 88:901-904（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未注入，词级格位核对降级为凭原文与义注判断）／义注 ✅（101:274–276）
> 本层为本文（mūla），**无父层**，故「被解释词与父层逐字同译」一项不适用。但义注黑体词（ubhato / saṃsuddhagahaṇiko / yāva sattamā pitāmahayugā / akkhitto / anupakkuṭṭho / jātivādena / aḍḍho / mahaddhano / mahābhogo / paripuṇṇakosakoṭṭhāgāro / assavāya / ovādapaṭikarāya / paṇḍito / byatto / medhāvī / paṭibalo / atthe cintetuṃ / vijitāvīnaṃ / vimuttacittānaṃ）将来译义注时须与本文此处逐字相同，**本次修订定下的译法即是义注的约束**，下列必改项尤须先定案。

## 跨段一致性

- **dhamma**：§903 句 60-65 与 66-94 译「条件」（「这四种条件」「以名望为第五的这些条件」），§904 句 137-143 与 144-155 同一词译「法」（「这四种法」「以解脱为第五的这些法」）。本经全篇靠王与比丘的对偶结构立意，同词异译会把对偶拆散 → **统一为「法」**；§902 的 `aṅgehi` 另是一词，可保留「条件」或改「支」，但不要与 `dhamma` 共用「条件」。
- **samannāgato + dhammena（单数）**：§903「这些条件」、§904「这些法」都作复数。原文为单数合成词（yasapañcamena / vimuttipañcamena dhammena），意即「以名望/解脱为第五的（整套）法」→ 建议统一为「具备了以名望为第五的这一组法」「……以解脱为第五的这一组法」。
- **medhāvī 与 paññavā 同译「有智慧」**：§903 句 48-59 `medhāvī`→「有智慧」，§904 句 122-136 `paññavā`→「他有智慧」。义注对 medhāvī 有专解（`**Medhāvī**ti ṭhānuppattikapaññāya samannāgato`，具备临机即生之慧），与 paññavā 不是一回事 → medhāvī 改「机敏」或「有临机的智慧」，「有智慧」留给 paññavā。
- **paripuṇṇakosakoṭṭhāgāra**：§903 句 32-37 与 §904 句 65-102 均作「库藏和仓廒」，译法一致 ✅，但「仓廒」为旧词（见下风格项），两处要一并改。
- **bahussuta**：§904 句 65-102 内先译「博学多闻」、后译「多有听闻」。同句两译，建议后半改「这样的法他听闻得多」或统一用「多闻」。
- 其余对偶要素（灌顶刹帝利王／无论住在哪个方向／事情就是这样）前后一致 ✅。

## §901 句 88-901-2-4

- **问题**：风格 — 经题「《无论哪个方向经》」读来拗口，不像书名。
- **建议**：改《随所住方经》或《无论何方经》（经文内「yassaṃ yassaṃ disāyaṃ viharati」仍译「无论住在哪个方向」，不必与经题字面一致）。

## §903 句 88-903-8-31

- **问题**：义注释义错 — `saṃsuddhagahaṇiko` 译「母系血统纯净」。**义注**：`**Saṃsuddhagahaṇiko**ti saṃsuddhāya mātukucchiyā samannāgato`（具备清净的母胎）；下文又辨 `gahaṇī` 在「samavepākiniyā gahaṇiyā」里才指业生火界。义注给的是「母胎」，不是「血统」；「血统」已被上句 ubhato sujāto 的三代刹帝利说涵盖，重复且失准。
- **建议**：改「所出的母胎清净」／「具有清净的母胎」。
- **问题**：义注释义错 — `akkhitto` 译「没有被人指摘」。**义注**：`**Akkhitto**ti ‘‘apanetha etaṃ, kiṃ iminā’’ti evaṃ akkhitto anavakkhitto`（不曾被人说「把这人赶走，要他干什么」那样排斥、驱逐）；`**Anupakkuṭṭho**ti na upakkuṭṭho na akkosaṃ vā nindaṃ vā pattapubbo`（不曾遭受辱骂或责备）。译文把两词都处理成「指摘／非难」，近义重复，义注刻意做出的「排斥」与「辱骂责备」之分被抹平。
- **建议**：「不曾因出身之说而被排斥、被辱骂」——或展开为「没有人因为出身说他『把这人赶走』，也不曾遭受辱骂责备」。
- **问题**：取义可商 — 「上溯到第七代祖先」只管住了 akkhitto / anupakkuṭṭho。**义注**：`Evaṃ yāva sattamo puriso, tāva saṃsuddhagahaṇiko, atha vā akkhitto anupakkuṭṭho jātivādenāti dasseti`——义注明说「直到第七代」可连 saṃsuddhagahaṇika，**或**（atha vā）连 akkhitta anupakkuṭṭha，译文取了后一解。
- **建议**：取义可保留，但语序宜让「上溯到第七代祖先」不至于被读成只修饰末句，例如「上溯到第七代祖先为止，不曾因出身之说被排斥、被辱骂」。此处两解分歧记入本报告，不在译文留痕。
- **问题**：风格 — 「比丘们，这里，」三字孤立成句，是「Idha」的硬译，现代读者会卡住。
- **建议**：「比丘们，就以这样的灌顶刹帝利王来说：」或「比丘们，在这里：」。§904 句 40-64 同样开头，要一并改。

## §903 句 88-903-32-37

- **问题**：风格（旧词）— 「仓廒」属旧式书面语，违反 `style.md`「能用现代词就不用旧词」。
- **建议**：「府库和粮仓都很充实」。**义注**：`koso vuccati bhaṇḍāgāraṃ ... dhaññena ca paripuṇṇakoṭṭhāgāro`（koso 是库房，装满积存的财物；koṭṭhāgāra 装满谷物）——「府库／粮仓」正合义注之分。§904 句 65-102 同词同改。

## §903 句 88-903-38-47

- **问题**：义注释义偏轻 — `ovādapaṭikarāya` 译「听从教诲」。**义注**：`‘‘idaṃ vo kattabbaṃ, idaṃ na kattabban’’ti dinnaovādakarāya`（照所下达的教诫去做），重点在「照做」，不只是「听」。
- **建议**：「奉行教诫」。前半 `assavāya` 译「服从命令」与**义注**（给再多钱也不听者为 anassavā，不给也听者为 assavā）相合 ✅。

## §903 句 88-903-48-59

- **问题**：义注释义窄 — `atthe cintetuṃ` 译「思量……的事务」。**义注**：`**Atthe cintetun**ti vaḍḍhiatthe cintetuṃ`（思量增益之事），并举 `‘‘atītepi evaṃ ahesuṃ, anāgatepi evaṃ bhavissantī’’ti cinteti`。「事务」丢了 vaḍḍhi（增长、利益）这一层。
- **建议**：「能够思量过去、未来和现在的利益」。
- **问题**：术语区分 — `paṇḍito viyatto medhāvī paṭibalo` 四词译作「贤明、能干、有智慧，能够……」，其中 `byatto`（**义注**：`paññāveyyattiyena yutto`，具备智慧上的练达）译「能干」偏日常，`medhāvī` 见跨段一致性项。
- **建议**：「贤明、通达、机敏，有能力思量过去、未来和现在的利益」（paṭibalo＝**义注** `samattho`，宜显出「有能力」）。

## §903 句 88-903-60-65 / 88-903-66-94

- **问题**：跨段一致性 — 「条件」应改「法」，见上。
- **建议**：「这四种法使他的名望成熟」「他具备了以名望为第五的这一组法……」。

## §903 句 88-903-99-105

- **问题**：取义偏 — `vijitāvīnaṃ` 译「征服者」。**义注**：`**Vijitāvīnan**ti vijitavijayānaṃ, mahantena vā vijayena samannāgatānaṃ`（已取得胜利者，或具备大胜利者）。「征服者」带现代侵略色彩，义注落点在「已得胜」。
- **建议**：「对于已经取得胜利的人来说，事情就是这样」。与 §904 句 160-169「对于心已解脱的人来说」构成对偶 ✅。

## §904 句 88-904-40-64

- **问题**：文言残留（必改）— 「受持学处并依之修学」中的「之」是文言虚词，违反 `style.md` 硬约束。
- **建议**：「受持学处，照着学习」。
- **问题**：漏译／翻译腔 — `pātimokkhasaṃvarasaṃvuto viharati` 的 `viharati` 未译出，且「以……的防护而自我防护」同词根连用，读来绕口。
- **建议**：「依波罗提木叉的防护守护自己而住」。
- **问题**：术语 — `ācāragocarasampanno` 译「行为和交往处都完备」，`gocara` 传统汉译作「行处」（托钵与亲近的范围），「交往处」是自造词。
- **建议**：「正行与行处都具足」。

## §904 句 88-904-65-102

- **问题**：句法归属 — 「有意义、有文句，宣说完全圆满、清净的梵行」把 `sātthaṃ sabyañjanaṃ` 挂在「法」上，与 `kevalaparipuṇṇaṃ parisuddhaṃ brahmacariyaṃ` 割开。这两组形容词同属 brahmacariyaṃ，传统读法一致。
- **建议**：「……宣说具有意义、具有文句、完全圆满清净的梵行」。
- **问题**：用词 — 「用心思量」（manasānupekkhitā）偏弱，anupekkhita 是反复审察；「口头熟习」（vacasā paricitā）宜显出诵习义。
- **建议**：「口诵纯熟，心中反复审察，以见解善加通达」。

## §904 句 88-904-122-136

- **问题**：用词 — 「这智慧是圣的、能穿透的」中「圣的」「能穿透的」作谓语偏生硬。
- **建议**：「具备观照生灭的智慧——那是圣的、能洞穿（烦恼）的、能正确导向苦之灭尽的智慧」。

## §904 句 88-904-137-143 / 88-904-144-155
