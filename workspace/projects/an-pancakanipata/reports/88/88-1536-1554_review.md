# Review — 88:1536-1554（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **sivathikā**：§1536 标题、§1537–1542 正文译“墓地”，§1550 摄颂译“冢墓经” → 统一为“墓地”（“两部墓地经”）。
- **vāḷānaṃ amanussānaṃ / vāḷāvāsa**：§1537、§1541 两处都把 vāḷa 当作并列名词，译成“猛兽和非人”；§1541 的 vāḷāvāsa 译成“猛兽住处”。依 nissaya，vāḷānaṃ 是修饰语（见下文各句），三处应一起改。
- **āpatti**：§1544、§1545 译“罪”，术语表登记 āpatti=“犯”（confirmed） → 按术语表统一，或者把“罪”报告给术语表修订，不要两套并存。
- **经号格式**：§1537 作“二四九、”，§1544 作“二五〇、”，§1554 作“251.” → 统一为汉字数字加顿号：“二五一、”。
- **经末标记**：§1542 作“第九。”，§1546 作“第十经。”，§1554 作“第一经。” → 统一为“第九经。”。
- **“Katame/Katamehi pañca?”**：§1537、§1538、§1544 作“哪五种呢？”，§1554 作“是哪五种呢？” → 统一为“哪五种呢？”。
- **结句 Ime kho … pañca ādīnavā**：§1537、§1542 作“这就是”，§1546 作“以上就是” → 统一为“这就是”。
- **连接词语体**：§1539 用“便”（“坏名声便传扬开来”），其余各段都用“就” → 改为“就”。
- **Idha**：§1538 译出了“这里”，§1554 漏译（见下文 §1554 句 88-1554-28-37） → 两处都译出。

## §1537 句 88-1537-31-53
- **问题**：句法误读 — nissaya：`ဝါဠာနံ= ကြမ်းတမ်းကုန်သော။`（凶暴的，修饰语）`အမနုဿာနံ= ဘီလူးသားရဲတို့၏။`（属格，被修饰的名词）。vāḷānaṃ 是 amanussānaṃ 的定语，不是与它并列的“猛兽”。
- **建议**：“……是凶恶的非人（amanussa）的住处……”

## §1539 句 88-1539-2-19
- **问题**：属格关系没有译出 — nissaya：`တဿ= ထိုပုဂ္ဂိုလ်၏။`（属格，“那个人的”）。三个 samannāgatassa 都是修饰 tassa 的属格定语，主语是 `ကိတ္တိသဒ္ဒေါ`（名声）。现译把“他”当成全句主题，“坏名声”的归属不清。另外“便”属文言虚词。
- **建议**：“具有不洁净的身业、不洁净的语业、不洁净的意业的这个人，他的坏名声就传开了。”

## §1540 句 88-1540-2-20
- **问题**：词义偏窄 — nissaya：`ပေသလာ= သီလကိုချစ်မြတ်နိုးကုန်သော။`（珍爱戒行的）。“善良的”没有表达出“持戒”的意思。§1542 句 88-1542-2-28 同词同问题。
- **建议**：两处都改为“品行端正、爱护戒律的同梵行者们”或“持戒良善的同修们”，并统一。

## §1541 句 88-1541-22-26
- **问题**：句法误读，表达生硬 — nissaya：`ဝါဠာဝါသသ္မိံ= ကြမ်းတမ်းဆိုးသွမ်းသောဘီလူးသားရဲတို့၏နေရာဌာန၏အဖြစ်ဟူ၍။`（作为“凶恶的非人的住处”这一状态）。vāḷa 是修饰语，问题同 §1537；“他像猛兽住处的地方”在语义上也不通。
- **建议**：“我说这就是他作为凶恶非人住处的一面。”

## §1541 句 88-1541-27-37
- **问题**：句法误读 — 同 §1537，vāḷānaṃ 是 amanussānaṃ 的定语。
- **建议**：“比丘们，就像那墓地是凶恶的非人的住处；”

## §1542 句 88-1542-2-28
- **问题**：词义偏差 — nissaya：`ခီယနဓမ္မံ= ကဲ့ရဲ့ရှုတ်ချခြင်းသဘောသို့။ အာပဇ္ဇန္တိ`（陷入非难、谴责）。“抱怨”只表达了自己不满，没有表达出对这个人的指责。
- **建议**：“……就埋怨指责起来——”

## §1542 句 88-1542-43-46
- **问题**：语义归属误导 — nissaya：`ဣဒံ= ဤသီတင်းသုံးဖော်တို့ကကဲ့ရဲ့ရှုတ်ချခြင်းကို။`（同梵行者的这种非难，宾格）`အာရောဒနာယ= ငိုကြွေးရာဌာန၏အဖြစ်ဟူ၍။`（作为“哭泣之处”的状态）。哭泣的是别人，这个人是让人哭泣的“处所”。“他的哭泣之处”容易读成他自己在哭。
- **建议**：“我说这就是他成为众人哭泣之处的一面。”

## §1544 句 88-1544-19-37
- **问题**：程度词译偏 — nissaya：`အဘိပ္ပသန္နော= အလွန်အကဲကြည်ညိုသည်။`（过度、过分地信敬）。本经讲的正是过分信赖的过患，“深深信赖”是褒义，弱化了这层意思。nissaya 还点明被信赖者 `အကြင်ရဟန်းဖြစ်သောပုဂ္ဂိုလ်`（是一位比丘）。此外“罪”与术语表不一致，见跨段一致性一节。
- **建议**：“比丘们，一个人过分信赖某个人，而那个人犯了僧团会因此对他作举罪（ukkhepanīya）的那一类犯。”§1545 句 88-1545-2-26、§1546 句 88-1546-2-31 的“深深信赖”同步改为“过分信赖”。

## §1544 句 88-1544-55-58
- **问题**：词义与所指 — nissaya：`ဘိက္ခူသု= (ကြဉ်ဖယ်ထုတ်သော)ရဟန်းတို့၌။ အပ္ပသာဒဗဟုလော= များစွာမကြည်ညိုမကျေနပ်ခြင်းရှိသည်။`（对作出举罪的比丘们多生不信敬、不满）。“大为失去信赖”表达不出“多生不满”这种持续的状态。
- **建议**：“于是他对比丘们多生不满。”同句型在 §1544 句 88-1544-59-66 和 §1545 中同步调整。

## §1554 句 88-1554-2-24
- **问题**：补出成分 — nissaya：`ဥပသမ္ပာဒေတဗ္ဗံ= (ဥပဇ္ဈာယ်ဖြစ်၍သာမဏေကို)…`（作为戒和尚，为沙弥授具足戒）。nissaya 补出了授戒者的身份。经号格式不一致，见跨段一致性一节。
- **建议**：“二五一、［律藏大品·84］‘比丘们，具备五种法的比丘可以（作为戒和尚）为人授具足戒。’”§1554 句 88-1554-58-71 同步修改。

## §1554 句 88-1554-28-37
- **问题**：漏译 — nissaya：`ဣဓ= ဤသာသနာတော်၌။`（在这教法中）。译文没有译出 Idha。
- **建议**：“比丘们，在这里，有比丘具备无学的戒蕴；”
