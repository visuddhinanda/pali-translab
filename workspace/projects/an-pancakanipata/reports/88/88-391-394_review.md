# Review — 88:391-394（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（391、392-2-15、393-39-62、394-46-71 无 nissaya，略过）

## 跨段一致性
- pajjhāyanto / pajjhāyantaṃ：§393 与 §394 都译「沉思着」，两处一致。但词义需要修正（见 §393 句 88-393-63-75），改时两处要同步。
- pattakkhandho / pattakkhandhaṃ：§393 与 §394 都译「垂着肩膀」，两处一致。若按 nissaya 调整，也要两处同步。
- 其余重复描写语（dukkhī / dummano / adhomukho / appaṭibhāno）在 §393 与 §394 的译法前后统一，称谓「憍萨罗国王波斯匿」全 chunk 统一，没有问题。

## §393 句 88-393-32-38
- **问题**：增译 — `ဥပကဏ္ဏကေ= နားအရင်း၌။ ဝါ= နားအနီး၌။`（在耳根处，或在耳边），nissaya 只标处格「在耳边」，没有补出「低声」。「低声」是从语境推出来的，不算错，但属于原文没有的成分。
- **建议**：可以保留（耳边报告本来就暗含低声），也可以收紧为「在憍萨罗国王波斯匿的耳边报告说——」。属于可选项。

## §393 句 88-393-63-75
- **问题**：词义偏差 — `ပဇ္ဈာယန္တော= ထိုထိုဤဤကြံစည်မှိုင်တွေလျက်။`，意思是「想这想那、愁闷发呆」，带有忧郁、出神的色彩。译成「沉思着」偏中性，像是在冷静思考，丢了愁闷的意味。
- **建议**：改为「愁闷地想来想去」或「闷闷地出神」。§394 同步修改。
- **问题**：词义待酌 — `ပတ္တက္ခန္နော= အောက်သို့ငိုက်ဆိုက်ကျသောလည်ကုပ်ရှိသည်။`，nissaya 把 khandha 释为 `လည်ကုပ်`（后颈），意思是「颈项向下耷拉」，而不是「肩膀」。
- **建议**：参考 nissaya 改为「耷拉着脖子」；如果术语表另定以「肩」为准，就在报告里登记这个分歧，不必强改。§394 同步。
- **问题**：补出成分 — nissaya 在 adhomukho 之后补 `(ဟုတွာ= ဖြစ်၍)`，表示前四项（dukkhī…adhomukho）是先成立的状态，pajjhāyanto、appaṭibhāno 是伴随 nisīdi 的方式。现译把六项平铺并列，层次不明显。
- **建议**：可用分号或语序体现层次，例如「……痛苦，心情沮丧，耷拉着脖子，低着头；他愁闷地想来想去，一句话也说不出来，就那样坐着。」属于可选项。

## §394 句 88-394-2-20
- **问题**：随 §393 同步 — pattakkhandhaṃ「垂着肩膀」、pajjhāyantaṃ「沉思着」，问题同上。nissaya 对这两个词同样释为 `ရှိသည်ကို`（宾格）和 `ထိုထိုဤဤကြံစည်မှိုင်တွေနေသည်ကို`。
- **建议**：与 §393 一起改。宾格结构（全部作 viditvā 的宾语）译文处理正确，不需要动。

## §394 句 88-394-21-42
- **问题**：轻微漏译 — `pañcimāni` 含指示词 imāni（这些），译文作「有五件事」，没有把「这」译出来。nissaya 在下句 `ဣမာနိ ပဉ္စ= တည်း` 也把 imāni 落实了。
- **建议**：改为「大王，这五件事……」。属于可选项。
- **说明**：`သမဏေန ဝါ= သည်လည်းကောင်း`，nissaya 用 သည် 把具格标为 alabbhanīya 的施事；`လောကသ္မိံ= ၌` 和 `ကေနစိ ဝါ` 连读。译文「……或者世间的任何人都得不到」与此相符，不需要改。
