# Review — 88:1518-1535（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（只有部分句带 nissaya：1519、1520、1522、1524、1526、1529 的若干句；其余句不出词法意见）

## 跨段一致性

- **ādīnava**：§1519、§1522、§1524、§1526 译“过患”，§1528、§1531、§1533、§1535 译“危险”。前后八经是同一组对称的经，同词应同译。建议统一为“过患”，依据是首见译法和传统汉译。
- **anuvicca viññū garahanti / pasaṃsanti**：
  - §1519 译“会受到智者的审察和谴责”，§1520 和 §1526 译“会受到智者的审察和称赞”；
  - §1528 译“明智的人们了解之后会谴责他”，§1529 和 §1535 译“明智的人们了解之后会赞扬他”。
  - 两种译法的句式、主语和动词都不一样。从原文结构看，viññū 是主格施事，anuvicca 是前置的连续体（“审察之后”），§1528 那种主动句更贴近原文；§1519 那种被动句把“审察”变成了和“谴责”并列的名词。建议统一为主动句，例如“智者经过审察，会谴责他”／“……会称赞他”，并统一用“称赞”或“赞扬”其中一个。
- **pāpako / kalyāṇo kittisaddo abbhuggacchati**：§1519 和 §1520、§1526 译“坏名声／好名声会传播开来”，§1528 和 §1529、§1535 译“坏的名声／好的名声传扬开来”。建议统一为“坏名声会传播开来”和“好名声会传播开来”。
- **pe（省略号）**：§1522、§1524、§1526 译“……乃至……”，§1531、§1533、§1535 译“……（中略）……”。建议全书统一用一种写法。句末标点也不一致：§1522 和 §1524 以“……乃至……。”结尾，§1531 和 §1533 结尾没有句号。
- **经名中的 Paṭhama / Dutiya**：§1518、§1521、§1523、§1525 是“恶行经第一”“身恶行经第一”，序数放在后面；§1527、§1530、§1532、§1534 是“第二恶行经”“第二身恶行经”，序数放在前面。建议统一词序，例如都改为“第一恶行经”“第一身恶行经”……“第二意恶行经”。
- **saddhamma / asaddhamma 的取义**：§1528、§1529、§1535 都译作“正法”和“非正法”。依据和处理方式见下文 §1529 句 88-1529-27-29。三处要一起改。

## §1529 句 88-1529-27-29

- **问题**：数据对齐 — 挂在这一句（asaddhammā vuṭṭhāti）下的 nissaya 带着 `၂၄၅(စာပိုဒ်)။ ၅-ဒုတိယဒုစ္စရိတသုတ်` 的段首标题，注的是 `သဒ္ဓမ္မာ`，实际对应的是 §1528 的 `saddhammā vuṭṭhāti`（88-1528-30-32），并不是本句。修改时不要按这里的挂接方式去机械对照。
- **问题**：取义（nissaya 词级） — `သဒ္ဓမ္မာ= သူတော်ကောင်းတို့၏ကုသိုလ်ကမ္မပထတရားဆယ်ပါးမှ` 的意思是“从善人们的十善业道”（夺格）。nissaya 把 saddhamma 读成 sataṃ dhamma，即“善人的法”，具体指十善业道。译文的“正法”在汉语里通常指佛陀的教法，所指范围偏了。
- **问题**：`ဝုဋ္ဌာတိ= ထသွား၏။ ဝါ= ခွဲခွာထွက်သွား၏` 的意思是“起身离去／脱离而出”。译文“离开”与此相符，没有问题。
- **建议**：saddhamma 改译为“善人的法”，asaddhamma 改译为“不善人的法”。也可以保留“正法”和“非正法”，另加注说明这里指十善业道和十不善业道。§1528、§1529、§1535 三处要同步修改。

## §1529 句 88-1529-30-32

- **问题**：数据对齐 — 本句是 `saddhamme patiṭṭhāti`，但挂在下面的 nissaya 注的是 `အဿဒ္ဓမ္မေ= သူယုတ်မာတို့၏အကုသိုလ်ကမ္မပထတရားဆယ်ပါး၌`，即“在不善人们的十不善业道中”（处格），实际对应 §1528 的 `asaddhamme patiṭṭhāti`（88-1528-33-35）。
- **问题**：取义 — 与上一条同理，asaddhamma 按 nissaya 应理解为“不善人的法（十不善业道）”，现在的“非正法”取义不准。`ပတိဋ္ဌာတိ= တည်နေ၏` 的意思是“住立于”，译文“立足于”在词法上没有问题。
- **建议**：随上一条一起改。本句改为“他立足于善人的法”；§1528 的对应句改为“他立足于不善人的法”。
