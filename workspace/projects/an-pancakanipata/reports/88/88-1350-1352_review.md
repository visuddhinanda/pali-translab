# Review — 88:1350-1352（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 未注入 nissaya，词级格位与隐含成分无法核验，下列判断仅据巴利原文与义注）／义注 ✅（book 101 §401–409 Mahāsupinasuttavaṇṇanā）
>
> 义注覆盖说明：§409 末「Sesaṃ pāḷivaseneva veditabban ti」（其余依巴利原文自明）——第四、第五梦义注不另释义，但 §409 开头给出了**全段的结构定性**，这是本 chunk 最关键的释义依据（见下）。

## 跨段一致性

- `pubbeva sambodhā anabhisambuddhassa bodhisattasseva sato`：§1350／§1351／§1352 一律译「在正觉以前，还没有现证正觉、还是菩萨的时候」 → ✅ 统一
- `Tassa abhisambodhāya ayaṃ … mahāsupino pāturahosi`：§1350／§1351 一律译「这第 N 个大梦，是为了他将要现证正觉而出现的」 → ✅ 句式统一（但释义待改，见 §1350 句 46-52）
- `pāturahosi / pāturahesuṃ`：§1350「出现的」、§1351「出现的」、§1352「出现了」 → ✅ 一致，且与义注 `**Pāturahesun**ti pākaṭā ahesuṃ`（变得显明）相合
- ⚠ **`yampi … ; <果> …` 这一结构在 §1350、§1351 都译成「这是因为…」** → 两段**一致地取了同一个错解**（见下必改项）。改的时候两段必须同改、同一句式，否则会从「一致地错」变成「不一致」

## §1350 句 88-1350-27-45

- **问题**：释义错误（因果倒置）— **必改**。译文「比丘们，**这是因为**有刹帝利、婆罗门、吠舍、首陀罗这四种姓，他们…证得了无上的解脱」把后半句读成梦的**原因**。义注对这整组句子的定性正相反：
  **义注**：`Evaṃ ettakena ṭhānena pubbanimittāni dassetvā idāni saha pubbanimittehi paṭilābhaṃ dassetuṃ **yampi , bhikkhave**tiādimāha .`（以上这一段先显示诸前兆，现在为了把**前兆与所得**一并显示出来，才说「yampi, bhikkhave」等语。）
  也就是说 `yampi …`（所梦）与 `cattārome … sacchikaronti`（四种姓证解脱）是**前兆—所应验之事**的关系，不是果—因关系。梦不是「因为」四种姓将证解脱才出现；四种姓证解脱是这个梦所预示的 `paṭilābha`。译成「这是因为」会让读者以为梦由后事所致，方向反了。
- **建议**：用预示／应验的说法接住 `yampi … ;` 的相关结构，例如：「比丘们，如来…还是菩萨的时候，曾梦见四只颜色各异的鸟…全都变成了纯白色；比丘们，**这预示着**刹帝利、婆罗门、吠舍、首陀罗这四种姓，在如来所宣说的法和律中，从在家出家而过无家的生活，证得无上的解脱。」
- **问题**：时态 — `sacchikaronti` 是现在时的通则陈述，译文「证得**了**无上的解脱」加「了」成了已然事实。
- **建议**：去掉「了」，作「证得无上的解脱」。
- **问题**：行文重复 — 「从在家走向无家而出家」，「走向无家」与「出家」语义叠套。
- **建议**：「从在家出家、过无家的生活」或「舍离家庭生活而出家」。

## §1350 句 88-1350-2-26

- **问题**：义注信息未落地（可加注）— `nānāvaṇṇā` 译「颜色各异」不错，但义注明确列出是哪四色，而四色正对应下文四种姓，是本梦读得通的关键。
  **义注**：`**Nānāvaṇṇā**ti eko nīlavaṇṇo , eko pītavaṇṇo , eko lohitavaṇṇo , eko paṇḍupalāsavaṇṇoti evaṃ nānāvaṇṇā .`（一只青色、一只黄色、一只赤色、一只枯叶色。）
- **建议**：正文保留「颜色各异」，另出脚注写明义注所列青、黄、赤、枯叶四色。
- **问题**：`sabbasetā` 译「纯白色」偏单薄。**义注**：`**Setā**ti paṇḍarā parisuddhā .`（白，即洁白、清净。）义注取的是「洁白清净」这层。
- **建议**：作「全都变成了洁白的颜色」或「全都变得洁白清净」（程度轻，可不改，但勿再弱化为「白」）。

## §1350 句 88-1350-46-52

- **问题**：释义偏移 — **必改项的连带处**。`Tassa abhisambodhāya … pāturahosi` 译「是**为了**他将要现证正觉而出现的」，读起来像梦有意图／有目的。按义注通篇的 `pubbanimitta` 框架（`**Pubbanimittato** passanto … uppajjitukāmassa atthassa … pubbanimittabhūtaṃ supinaṃ passati`；`taṃ ekantaṃ saccameva hoti` 前兆之梦必定真实），这里是「他现证正觉的前兆」。
- **建议**：「这第四个大梦，是**预示他将现证正觉**而出现的。」§1351 句 79-86 同句同改。

## §1351 句 88-1351-2-23

- **问题**：`uparūpari` 的落点丢失 — **义注**：`**Uparūpari** **caṅkamatī**ti matthakamatthake caṅkamati .`（在**最顶面上**经行。）义注紧接着用长寿佛作反衬：`Dīghāyukabuddhā pana tiyojanike mīḷhapabbate anupavisitvā nisinnā viya honti .`（长寿佛则像陷进三由旬的粪山里坐着。）可见 `uparūpari` 的要点是**只踩在最上层、不陷进去**，与下句 `alippamāno`（不被沾染）相扣。译文「在一座大粪山**上面**来回经行」把 `uparūpari` 弱化成普通的「上面」，经行的位置信息没了。
- **建议**：「在一座大粪山的**最顶上**来回经行」。
- **问题**：`mahato mīḷhapabbatassa` 的规模可补注 — **义注**：`**Mahato** **mīḷhapabbatassā**ti tiyojanubbedhassa gūthapabbatassa .`（三由旬高的粪山。）
- **建议**：正文维持「大粪山」，脚注补「义注作三由旬高」。
- **问题**：文言虚词「所」— 「却不被粪**所**沾染」。按 `style.md` 第一节，`所` 作文言虚词时应改或省。
- **建议**：「却不被粪沾染」。

## §1351 句 88-1351-24-78

- **问题**：释义错误（因果倒置）— **必改**，与 §1350 句 27-45 同一处病。译文「比丘们，**这是因为**如来能够得到衣服…」。按义注 §409 的 `saha pubbanimittehi paṭilābhaṃ dassetuṃ`，`lābhī bhikkhave tathāgato …` 是这个梦所预示的**所得**（如来四事供养具足而受用无染），不是梦的原因。
- **建议**：「比丘们，**这预示着**如来将得到衣服、饮食、坐卧处和病缘医药等资具，而且在受用的时候不贪著、不迷恋、不耽溺，看得见其中的过患，带着出离的智慧去受用。」
- **问题**：`senāsana` 译「住处」偏窄。该词是坐卧处／坐卧具，四事供养中的标准项。
- **建议**：「坐卧处」（或「住处和坐卧具」），并在 `terms.md` 登记定译。
- **问题**：`lābhī` 译「能够得到」加了情态 — `lābhī` 是「得者」，陈述事实上得到，不是「有能力得到」。
- **建议**：直接作「得到」／「是…的受得者」。
- **说明（不是问题）**：原文中的异读括注 `[ tattha ca (sī. syā. kaṃ. pī.)]`、`[ agadhito …]`、`[ anajjhāpanno …(anajjhopanno …)]` 未译 → ✅ 处理正确，校勘异读不入正文。

## §1352 句 88-1352-2-22

- **问题**：无（`ime pañca mahāsupinā pāturahesuṃ` 译「出现了这五个大梦」与义注 `pākaṭā ahesuṃ` 相合）。
- **建议（可选）**：`mahāsupinā` 译「大梦」✅，若要加注可引 **义注**：`**mahāsupinā**ti mahantehi purisehi passitabbato mahantānañca atthānaṃ nimittabhāvato mahāsupinā .`（因为是由大人物所见、又是大事的前兆，所以叫大梦。）

## 给下游（义注层翻译）的定译基准

本层是父层，义注黑体引自本文，翻译义注时须与此逐字相同。按上面改定后应为：

| 义注黑体 | 本文定译 |
|---|---|
| `Nānāvaṇṇā` | 颜色各异 |
| `Setā` | 洁白（清净） |
| `Mahato mīḷhapabbatassa` | 大粪山 |
| `Uparūpari caṅkamati` | 在最顶上来回经行 |
| `Pāturahesuṃ` | 出现 |
| `yampi, bhikkhave` | 比丘们，…（预示着）… |

⚠ `Uparūpari caṅkamati` 必须先在本文改定（见 §1351 句 2-23），否则义注层无法与父层对齐。

## 必改项汇总
