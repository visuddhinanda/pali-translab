## 跨段一致性

- **ābhicetasika**：1202 / 1204 / 1205 / 1206 / 1207 / 1208 共七处全作「属于高尚心境」→ 译法本身一致，但与义注相悖，须**整组统一改**，不可只改其中几处。
- **diṭṭhadhammasukhavihāra**：同上七处全作「在现世就能安乐而住」→ 一致，须整组统一改。
- **saṃvutakammanta**：1202「在五条学处上约束着自己的行为」／1203「在哪五条学处上…」「在这五条学处上…」／1208 同 → 一致 ✅
- **aveccappasāda**：1204 / 1205 / 1206 均作「坚定不坏的信心」→ 一致 ✅
- **「avisuddhassa cittassa visuddhiyā…」套语**：1204-43 / 1205-30 / 1206-48 / 1207-23 四处译文完全相同 → 一致 ✅（但四处共用同一语法误读，见 §1204 条，必须四处同改）
- **gihi**：1201 经名译「居士经」，1202 / 1208 正文译「在家人」→ 同词两译。经名沿用传统「居士经」可接受，但建议正文首次出现处夹注，或正文统一用「在家居士」以显出与经名的对应。
- **parivajjaye**：1209「远远避开种种恶行」／1210「远远避开这些恶行」→ 同一偈内重复词译法一致 ✅
- **五戒项目名**：1203 的五项与 1211 / 1212 偈颂的对应项（不伤害众生／不说谎／不取不与）用词不同体系（「远离杀生」vs「不要伤害各种有生命的众生」；「远离偷盗」vs「不要去拿取没有给予的东西」）。偈颂与长行体裁不同，不必强行统一，但「adinnādāna / adinnaṃ na parāmase」建议在偈颂处保留可识别的对应（如「不拿取没有给予的东西」），现译已可，仅记录。

## §1202 句 88-1202-2-18
- **问题**：风格（翻译腔被动句）—「由五百位左右的在家信众围绕着，走到世尊那里」，「由…围绕着」是西式被动。另 `upāsaka` 译「在家信众」偏宽，该词特指优婆塞（男居士）。
- **建议**：「那时，给孤独长者在大约五百位优婆塞的围绕下，来到世尊那里」；`upāsaka` 首次出现可夹注「优婆塞（upāsaka）」。

## §1202 句 88-1202-32-67
- **问题**：取义 — **Ābhicetasikānaṃ**。**义注**：`uttamacittanissitānaṃ`（依于最上心的）。现译「属于高尚心境」把 uttama 读成道德评价（高尚），而义注取的是「最上／殊胜」之心，指圣道心，不是品德义。
- **建议**：统一改「依于殊胜心的」或「属于增上心的」，七处同改。
- **问题**：取义 — **Diṭṭhadhammasukhavihārānaṃ**。**义注**：`paccakkheyeva dhamme pavattikkhaṇe sukhavihārānaṃ`（就在现见的法上、在它现起的当刻安乐住）。现译「在现世就能安乐而住」把重点落在「现世（此生）」这个时间段，义注的重点是「可亲自现见（paccakkha）的法」+「现起的那一刻」。
- **建议**：统一改「在当下现见之法中安乐而住的」，七处同改；若要保留传统译名「现法乐住」，须在脚注引义注说明「现法」指 paccakkha（亲自现见）而非「现世」。

## §1202 句 88-1202-68-82（同 §1208 句 88-1208-33-48）
- **问题**：语态／词法 —「我已经断尽地狱、断尽畜生道…」。`khīṇanirayo amhi` 是「〔于我〕地狱已尽」，khīṇa 是形容已尽状态，主语是「地狱」等四趣，不是以「我」为施动者去「断尽」。现译把入流者写成主动断灭地狱的施动者，语法与义理都偏。待 nissaya 复核格位。
- **建议**：「对我来说，地狱已尽、畜生趣已尽、饿鬼境已尽、恶处恶趣的堕落已尽」。两处同改。
- **问题**：术语 — `tiracchānayoni` 译「畜生道」，yoni 为「胎／趣」，与下文「饿鬼境界（pettivisaya）」体例不齐。
- **建议**：统一为「畜生趣」。

## §1203 句 88-1203-10-35
- **问题**：取义／成分 —「远离饮用谷酒、果酒等致人放逸的酒类」。`surāmerayamajjapamādaṭṭhāna` 的末项 `pamādaṭṭhāna` 是独立的「放逸之处（根源）」，现译降格为修饰语「致人放逸的」，且 `majja`（醉品）被并吞进「酒类」，三项并列塌成一项。
- **建议**：「远离谷酒、果酒等醉品——那是放逸的根源」。旁证：**义注**（101-368，释偈颂处）`catubbidhaṃ merayaṃ pañcavidhañca suraṃ`，meraya 与 surā 是分列的两类（四种果酒、五种谷酒），译文保留分列是对的，不应再把 majja 吞掉。
- **问题**：风格（翻译腔）—「舍利弗，在这里，圣弟子…」。`idha` 在此指「在此（佛陀的教法中）」，不是空间上的「这里」。1204-14 同。
- **建议**：「舍利弗，在这〔教法〕中，圣弟子…」，或直接省略为「舍利弗，圣弟子…」；1203 / 1204 两处同改。

## §1204 句 88-1204-24-42
- **问题**：句法 —「无上者、调御众生的御者」。`anuttaro purisadammasārathi` 是一个词组：anuttaro 修饰 purisadammasārathi，意为「无上的调御者」，现译拆成两个并列称号。另 `purisadamma` 是「应受调御的人」，译「众生」扩大了范围（巴利是 purisa，人）。
- **建议**：「无上的调御者，能调御应受调御的人」；若为保全传统「无上士、调御丈夫」的十号数目而分列，须加脚注说明巴利语法上二者为一。
- **问题**：术语 — `vijjācaraṇasampanno` 译「明与行都已圆满者」，传统译「明行足」。现译可读，保留即可；仅建议首次出现夹注「明行具足（vijjācaraṇasampanna）」。

## §1204 句 88-1204-43-55（同 §1205-30-42、§1206-48-61、§1207-23-35）
- **问题**：句法（与格误作结果）—「…的法，它使不清净的心得到清净，使不洁白的心变得洁白」。`visuddhiyā` / `pariyodapanāya` 是表目的的与格，意为「为了使不清净的心清净、为了使不洁白的心洁白」，是修证的目的，不是该法自动产生的结果。现译读作「这个法具有净化心的功效」，方向反了。待 nissaya 复核格位（预期为缅文目的格形式）。
- **建议**：「他为了净化不清净的心、洁净不洁白的心，证得了这第一种……」四处套语同改。

## §1205 句 88-1205-16-29
- **问题**：取义 — `sandiṭṭhiko` 译「当下就能见到的」，把「亲自现见」挪成了时间义，与紧随其后的 `akāliko`（不待时节）重复，且丢了「自己可亲见」这一层。参照**义注**对 `diṭṭhadhamma` 的释语 `paccakkheyeva`（就在现见上），同一词根此处应取「亲见」。
- **建议**：「是可以亲自见证的」。
- **问题**：增译 — `opaneyyiko` 译「可以引导人趋向涅槃的」。「趋向涅槃」是注释传统补出的内容，字面只是「应导向〔自身／内心〕的」。本 chunk 的义注未覆盖此词。
- **建议**：正文作「是应当导向自身的」，把「引导趋向涅槃」的释义放脚注；若保留现译，须在报告中记明依据为后世注释而非本句义注。

## §1206 句 88-1206-16-47
- **问题**：歧义 — `dakkhiṇeyyo` 译「值得布施」，中文读来像「值得（向别人）布施」，主宾颠倒。
- **建议**：「值得受施」或「应受布施」。
- **问题**：术语 — `sāmīcippaṭipanno` 译「如法而修行」，与前一项 `ñāyappaṭipanno`（依正理而修行）界线模糊。sāmīci 指「和敬、相应合宜」。
- **建议**：「世尊的弟子僧团的修行恰如其分」或沿用传统「和敬行道」并夹注巴利原词。

## §1210 句 88-1210-2-7
- **问题**：取义不足 — **Ariyadhammaṃ** **samādāya**。**义注**：`ettha ariyadhammoti pañca sīlāni kathitāni`（此处「圣法」说的是五戒）。现译「圣者的法」字面无误，但读者会读成泛指的教法，与义注的限定（五戒，正好回应 1203 的五学处）失联。
- **建议**：正文保留「受持圣者的法」，加段后小字注：「**义注**：此处的『圣法』指五戒。」——这样偈颂与 1203 的五学处的呼应才立得起来。
- **问题**：偈行关系 — 1209 与 1210 是同一偈的前后两行，`parivajjaye` 实为承上共用（宾语 pāpāni），现译在 1210 补「这些恶行」是合理的补出，但两行各自成独立句、且都用「就应该远远避开」，重复感强。
- **建议**：1210 可作「智者受持圣者的法，就该避开它们」，避免同一偈内整句重复。

## §1211 句 88-1211-2-10
- **问题**：取义存疑（必查）—「只要还有努力的余地，就不要伤害各种有生命的众生」。`vijjamāne parakkame` 是处格独立结构，「在有力量／堪能〔施为〕的时候」，一般读作「纵然有能力〔伤害〕，也不要伤害众生」。现译「还有努力的余地」把 parakkama 读成「努力改善的空间」，句义含混，读者不知所指。本 chunk 的义注未覆盖此句（义注 101-368 从 **Ariyadhammaṃ samādāya** 直接跳到后续偈颂词条），无释义标准可依。
- **建议**：暂译「即使有能力〔下手〕，也不要伤害有生命的众生」，并把本句列入待查项——须取 101 后续段或复注确认 parakkama 的传统取义后定稿。该句 `confidence` 应压低。
