# Review — 88:637-644（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- kuppati（kuppeyya / kuppeyyuṃ）：§640 同一句内，pitta、semha 译「失调」，vātā 译「发作」→ 建议统一为「失调」或「紊乱」。依据：nissaya 三处同作 `ကုပ္ပေယျ / ကုပ္ပေယျုံ= ဖောက်ပြန်`（紊乱、失调），是同一个动词。
- 其余复现句式在 §638–644 各段译法一致，包括 anāgatabhaya、sampassamānena alameva…viharituṃ、handāhaṃ vīriyaṃ ārabhāmi…、tena me assa kālaṅkiriyā, so mamassa antarāyo，以及称谓、语体，无需改动。

## §638 句 88-638-2-46
- **问题**：词法（偏弱） — `ပဟိတတ္တေန= (ကိုယ်နှင့်အသက် မငဲ့ကွက်ဘဲ) ရဲဝံ့စွန့်စား စွန့်လွှတ်ထားအပ်သောစိတ်ရှိလျက်`，意思是「不顾身命、心已全然舍出」。译文「努力」与前面的「精勤」（ātāpinā）意思几乎重合，pahitatta「把心全然投入」的意味没有译出来。
- **建议**：改为「专心致志」或「全心投入」。各段复现句（§639/640/641/642/643/644）要同步改。
- **问题**：隐含成分（供参考） — nissaya 为 appatta / anadhigata / asacchikata 补出宾语 `တရားထူး`（殊胜法：禅那、观、道果）。译文「尚未达到的」等只是虚指。
- **建议**：可保持现状（style 规定不擅补）。如果觉得读者难以理解，可在首次出现时补作「尚未达到的境界」，补了之后全章统一。

## §639 句 88-639-7-15
- **问题**：词义（供参考） — `ဣဓ= ဤသာသနာတော်၌`（在这教法中）。译文「在这里」字面上没错，但没有体现 idha 在这里的传统所指。
- **建议**：可改为「在这教法中」。如果全书惯例是「在这里」，也可以保留。

## §639 句 88-639-24-72
- **问题**：属格 — `မမ= ငါ၏ … အန္တရာယော= (အသက်စသည်၏) အန္တရာယ်သည်`，so mamassa antarāyo 是「那会成为我的（生命等的）障碍」，主语 so 指被蛇等咬这件事。译文「那对我就是障碍」可以接受，但「那」的所指稍显模糊。
- **建议**：可改为「这就会成为我的障碍」。§640–643 同句同步。

## §639 句 88-639-73-84
- **问题**：增译 — `ဟန္ဒ= ယခု`（现在、那么），`အာရဘာမိ= အားထုတ်ပေတော့အံ့`（我要努力了）。原文没有「下决心」的成分。
- **建议**：改为「那么，我现在就发起精进，……」。§640/641/642/643 的复现句一并改。

## §640 句 88-640-22-61
- **问题**：格与动词 — kuppeyyuṃ 译为「发作……风症」，而 nissaya 是 `ဝါတာ ဝါ= လေတို့သည်လည်း။ ကုပ္ပေယျုံ= ဖောက်ပြန်ကုန်ရာ၏`（诸风紊乱）。vātā 是主格主语，不是「发作」的宾语。
- **建议**：改为「或者像刀一样切割关节的风可能失调」，与 pitta、semha 句式对齐。
- **问题**：词义 — `သတ္ထကာ= ဓားလက်နက်ကဲ့သို့ အဆစ်အဖွဲ့တို့ကို ဖြတ်တောက်တတ်ကုန်သော`，指像刀一样切割关节连接处。译文「关节筋腱」中的「筋腱」是增出的。
- **建议**：改为「切割关节」即可。

## §642 句 88-642-22-48
- **问题**：句法与词义 — nissaya 把 `ကတကမ္မေဟိ ဝါ … အကတကမ္မေဟိ ဝါ … မာဏဝေဟိ` 作为 māṇava 的定语（已作过盗事的，或尚未作过盗事的盗贼）。译文拆成「有的已经作完案，有的正要去作案」，是分述结构。其中「正要去」比 nissaya 的「尚未作过」多了即将行动的意思。
- **建议**：改为「可能遇到盗贼——不论是已经作过案的，还是还没作过案的」。

## §643 句 88-643-22-41
- **问题**：语气词 — `သန္တိ ခေါ= ရှိကုန်သည်သာ`（确实有），kho 表示强调，译文没有体现。另外 vāḷā 的 nissaya 是 `ကြမ်းတမ်း`（凶猛），只有一个义项，「恶毒」是增出的。
- **建议**：改为「而森林里确实有凶暴的非人（amanussa），……」。
