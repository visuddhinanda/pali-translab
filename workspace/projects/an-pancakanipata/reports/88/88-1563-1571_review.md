## §1564 句 88-1564-23-46（及 §1565-19-45 / §1567-52-75 / §1568-40-64 / §1570-24-48 / §1571-19-46，同型六处）

- **问题**：句法 — `ime kho, bhikkhave, pañca dhamme appahāya abhabbo…` 中 `ime pañca dhamme` 是 `appahāya`（绝对分词）的宾语，整句是「比丘们，不舍弃这五种法，就不可能……」。译文「确实有这五种法，不舍弃它们，就不可能……」把 `ime … dhamme` 处理成了一个独立的存在句（「有这五种法」），再用「它们」回指，等于凭空加出一个原文没有的谓语。`kho` 是语气虚词，不是「确实有」里的「有」。
- **建议**：统一改为「比丘们，不舍弃这五种法，就不可能进入初禅并安住其中。」（相应地，`pahāya` 句改为「比丘们，舍弃了这五种法，就能够……」。）六处同型句一并改，保持句式统一。

## §1564 句 88-1564-2-19（及 §1565-2-15 / §1567-6-48 / §1568-2-36 / §1570-2-20 / §1571-2-15，同型六处）

- **问题**：句法 — 开头 `Pañcime, bhikkhave, dhamme appahāya abhabbo…` 同上，`pañcime dhamme` 是 `appahāya` 的宾语。译文「有这五种法，不舍弃它们」是同一处理方式的前半。此处作为开篇总说，拆成两小句尚可读，但与结句不统一时会显得前后两套句式。
- **建议**：与结句取同一句式，改为「比丘们，不舍弃这五种法，就不可能进入初禅并安住其中。」若为照顾开篇语气要保留「有这五种法」的铺垫，则六处开篇句一致处理，不要与结句混用两种句法。

## §1570 句 88-1570-24-48（及 §1571-19-46）

- **问题**：准确性／数目 — 列举项为 `āvāsamacchariyaṃ, kulamacchariyaṃ, lābhamacchariyaṃ, vaṇṇamacchariyaṃ, akataññutaṃ akataveditaṃ`，前四项吝惜 + 第五项。`akataññutaṃ akataveditaṃ` 在此经中合为**第五法**（`akataññutā` 与 `akataveditā` 是同义复词，传统作一法计；比较 §1564 的第五项是 `dhammamacchariyaṃ`，此经以「不知恩不报恩」替换「法吝」）。译文用顿号把「不知恩、不报恩」与前四项并列，读起来是六项，与同句的「五种法」直接矛盾。
- **建议**：把第五项合并书写，如「对住处的吝惜、对施主家的吝惜、对利养的吝惜、对赞誉的吝惜、不知恩不报恩」，或「……、不知恩不感恩（akataññutā akataveditā）」。§1570 与 §1571 同改。
- **存疑**：`akataññutā` / `akataveditā` 是否当作一法，需义注核实；若义注分作两法，则「五种法」的计数需另作说明。本次无义注，暂按同义复词合一处理，`confidence` 应下调。

## §1564 句 88-1564-23-46（术语，及所有同型句）

- **问题**：术语 — `kulamacchariyaṃ` 译「对施主家的吝惜」。`kula` 本义是「家、家族」，「施主」是依语境补出的解释性成分。在无义注佐证时属于加译。
- **建议**：若义注确以「檀越家」释之，保留并可于首次出现夹注巴利原词「对（护持）家的吝惜（kulamacchariya）」；若无据，改为较中性的「对家族（檀越）的吝惜」。待义注补入后定案。
- **存疑**：同样地，`vaṇṇamacchariyaṃ` 译「对赞誉的吝惜」——`vaṇṇa` 可指容色、赞誉、称誉。此处取「赞誉」是常见读法，但须以义注为准。

## §1569 句 88-1569-2-4

- **问题**：术语／体例 — `Aparapaṭhamajhānasuttaṃ` 译「另一初禅经」。`apara-` 在经题中习惯译作「第二…」「后…」或「又…」，「另一」口语味偏重，且与正文的经序号体例（第六经、第十三经、第十四经）风格不统一。
- **建议**：改为「又初禅经」或「后初禅经」；若项目体例倾向可读性，用「初禅经（二）」亦可，但须在 `terms.md` 登记统一译法，避免同书其他 `Apara-` 经题各译各的。

## §1567 句 88-1567-6-48

- **问题**：术语 — `arahattaṃ sacchikātuṃ` 译「现证阿罗汉果」。原文是 `arahattaṃ`（阿罗汉性／阿罗汉位），异读 `arahattaphalaṃ`（sī.）才是「阿罗汉果」。译文直接取了异读的意思，却未加说明。
- **建议**：正文依底本译「现证阿罗汉（位）」，或保留「阿罗汉果」而在首次出现处说明底本作 `arahattaṃ`、锡兰本作 `arahattaphalaṃ`。至少应前后一致，并与 `sotāpattiphalaṃ` 等确实带 `-phala` 的四处区分开。
- **补充**：原文中的异读括注 `[ arahattaphalaṃ ( sī .)]` 在译文中被整体略去。校勘括注是否入译文，属体例问题，`style.md` 未规定；建议统一处理（全略或全保留为脚注），不要逐处随机。

## §1565 句 88-1565-46-47 / §1568-65-66 / §1571-47-48

- **问题**：体例 — `Chaṭṭhaṃ. / Terasamaṃ. / Cuddasamaṃ.` 译「第六经。／第十三经。／第十四经。」。原文是序数词，「经」字是补出的。此处补出合理且可读，但 §1566 的 `Dutiyajhānasuttādisattakaṃ` 译「第二禅经等七经」中的「经」是原文 `sutta-` 自带的，两种「经」来源不同。
- **建议**：保持现译即可，但在 `knowledge/terms.md` 登记「篇末序数词统一补『经』字」的体例，避免后续章节出现「第六」「第六经」混用。

## §1567 句 88-1567-6-48（语体）

- **问题**：风格 — 「……中略……」用六个点加「中略」，与 `… pe …` 的位置对应良好，无文言问题。但整段由六个 `…` 省略号串联，中文读者容易把「不可能进入第三禅」误读为独立句。
- **建议**：可在每个省略号段之间保持「不可能……」的完整主语结构（现译已如此），建议维持；若后续 harmonize 统稿，注意不要为「更顺」而删去重复的「不可能」。
