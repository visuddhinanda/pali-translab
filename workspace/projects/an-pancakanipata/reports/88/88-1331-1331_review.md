## 被解释词核对

义注 101:391–397 的黑体被解释词（`kāraṇapālī` / `kammantaṃ kāretī` / `piṅgiyāniṃ brāhmaṇaṃ` / `etadavoca` / `divā divassa` / `paṇḍito maññe` / `ko cāhaṃ bho` / `pasatthappasattho` / `atthavasaṃ` / `seyyathāpi bho puriso` / `aggarasaparititto` / `madhupiṇḍikaṃ` / `asecanakaṃ` / `udānaṃ udānesi` 等）全部落在本段之前的段落，**本段无被解释词可比对**，此项无必改。

唯一同形词 `Seyyathāpi`（§1331-14-46）与义注 101-396-2-15 的 `**seyyathāpi** **, bho, puriso**` 不是同一处出现（后者是譬喻段），不构成对应关系约束；但译法「就好比」与譬喻段的处理应保持同一套措辞，建议后续 harmonize 时一并核。

## 段内一致性

- **`bhavaṃ / bhotā / bhavantaṃ`（同一敬称，本段出现 7 次）译法不统一**：对宾吉亚尼一律译「先生」（§1331-2-13、14-46、47-53、54-66、67-80），对乔达摩却译成「世尊」（§1331-54-66）。同一个敬称在同一段里译成两个词，且其中一个窜到了另一层级的尊号上 → **必改**，详见下条。
- `Abhikkantaṃ` 两次复说均译「太好了」，一致 ✅。
- 归依三宝的「归依」用字前后一致 ✅。

## §1331 句 88-1331-54-66

- **问题**：术语／称谓误译（必改）— `taṃ bhavantaṃ gotamaṃ` 译作「那位乔达摩**世尊**」。「世尊」只对应 `bhagavā`，是佛弟子的尊号；`bhavaṃ gotamo` 是**婆罗门对佛的外道式敬称**，此刻迦勒那巴利还没归依，正在说归依辞，用「世尊」等于预先把说话人立场换成了佛弟子。义注旁证：本篇义注通篇用婆罗门视角的 `samaṇaṃ gotamaṃ` / `samaṇassa gotamassa paññāveyyattiyaṃ`（§101-393-12-26、27-41、42-66、101-394-40-68），从未以 `bhagavā` 称之；`bhagavā` 只出现在义注自己的叙述口吻里（§101-395-79-93 `bhagavā "pasatthappasattho"ti vuccati`）。
- **建议**：改「我现在就归依那位**乔达摩尊师**，也归依法和比丘僧团。」（`bhavaṃ` 统一作「尊师／先生」一类敬称，与段内对宾吉亚尼的「先生」同源不同层级可接受，但不得用「世尊」）。

## §1331 句 88-1331-67-80

- **问题**：术语未登记且译宽（建议改）— `upāsakaṃ ... dhāretu` 译「把我看作在家居士」。`upāsaka` 的标准译名是「优婆塞」（或「在家信士」），「居士」是后起的汉地泛称，范围比 `upāsaka` 宽；`dhāretu` 是「受持、记住（我为…）」，「看作」把正式的归依认定弱化成了主观看法。
- **建议**：改「请宾吉亚尼先生记住我是优婆塞（upāsaka）」（按 `style.md` 二、三节，法相术语首次出现夹注巴利原词）。该词 `terms.md` 未登记，定案后补进术语表。
- **问题**：漏译／时体丢失（建议改）— `ajjatagge pāṇupetaṃ saraṇaṃ gataṃ` 译「从今天起终生归依」。`pāṇupeta` 是「尽此一生、直到命终」，「终生」可接受；但 `gataṃ` 是完成态、且与前句 `maṃ ... dhāretu` 同一宾语结构（「请记住我……是已归依者」），现译断成了一句独立的誓愿句。
- **建议**：改「请宾吉亚尼先生记住我是优婆塞，从今天起，我已尽此一生归依。」

## §1331 句 88-1331-47-53

- **问题**：语序使译文与譬喻脱钩（建议改）— `evamevaṃ bhotā piṅgiyāninā ... dhammo pakāsito` 译「宾吉亚尼先生用种种方式阐明法，也正是这样。」`evamevaṃ`（正是这样）是承接上句长譬喻的关联词，放到句末后，读者读到「也正是这样」时已经离开譬喻一整句，承接关系变弱；`pakāsito` 的完成态也没有译出。
- **建议**：改「正是这样，宾吉亚尼先生以种种方式阐明了法。」

## §1331 句 88-1331-81-82

- **问题**：增译（建议改）— `Catutthaṃ` 是经末序号标记，只是「第四」，「经终」二字原文没有，且「…终」偏书册文言体，与 `style.md` 第一节要求的现代书面语不协调。
- **建议**：改「第四。」若本项目约定要补「经」字，应在 `knowledge/style.md` 里统一立规后全书一致，不在单段自行添加。

## 存疑与待确认（不列为必改）

- `Abhikkantaṃ` 译「太好了」符合现代汉语要求，但与南传常见译法（「奇妙啊」「稀有啊」）距离较大。本段义注未释此词，无释义标准可依，建议在 `terms.md` 立一条固定译法后全书统一。
- `bho piṅgiyāni` 的音译「宾吉亚尼」与义注 §101-392-34-42 的 `**Piṅgiyāniṃ** **brāhmaṇan**ti`（义注说明他是**已立于不还果的圣弟子婆罗门**）对应。音译本身无误，但**义注**：`anāgāmiphale patiṭṭhitaṃ ariyasāvakaṃ brāhmaṇaṃ` 这一身份信息对读者理解本段「婆罗门向婆罗门请求归依」很关键，建议 footnote 步在此段补注。
- 本段缺 nissaya，`nikkujjitaṃ vā ukkujjeyya`、`paṭicchannaṃ vā vivareyya` 等动词的格位与隐含宾语无法做词级核对。现译「把倒放的东西翻转过来／把遮盖着的东西揭开」语义方向正确，但「倒放」偏日常器物义，传统作「倒覆」；若后续取到 nissaya，须复核这两处的隐含宾语是否该补出。
