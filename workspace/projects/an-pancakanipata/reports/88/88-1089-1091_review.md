# Review — 88:1089-1091（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未注入，词级格位核对缺失，下列格位判断仅凭原文与义注）／义注 ✅（101:329-331）

## 跨段一致性

- **āghātapaṭivinaya**：§1090 标题译「嗔恨消除」（第一嗔恨消除经），§1091 正文译「消除嗔恨的方法」 → 两处是同一复合词，建议统一。标题宜作「第一消除嗔恨经」，或正文作「这五种嗔恨的消除」；取其一即可，不要一词两译。
- **dāyāda**：§1091 句 115-135 内，`kammadāyādo` 译「业的继承者」，而同句 `tassa dāyādo bhavissati` 译「他都要承受其后果」 → 同一词在同一句里一个译「继承者」一个译「承受后果」，对应关系断了。建议统一为「他将成为那业的继承者」。
- **ime / 这·那**：§1091 句 2-21 译「有这五种」，句 142-159 译「这就是那五种」 → 原文两处都是 `ime`（近指），后句的「那」是误指，应为「这就是这五种」或「以上这五种」。
- **Yasmiṃ … jāyetha** 句式（5 处：25-37 / 44-56 / 63-75 / 82-94 / 101-114）：五处译法本身一致，但一致地丢了愿望语气（见下「必改项」），需五处同时改。

## 必改项

### §1091 句 88-1091-2-21（及 142-159 同句式）

- **问题**：义注释义不符 — `yattha` 的所指被译错。**义注**：`**Yattha** **bhikkhuno** **uppanno** **āghāto** **sabbaso** **paṭivinetabbo**ti yattha ārammaṇe bhikkhuno āghāto uppanno hoti, tattha so sabbo imehi pañcahi paṭivinodetabbo` —— 义注明确把 `yattha` 释为 **`yattha ārammaṇe`（在某个所缘／对象上）**，`tattha`（就在那里）回指该所缘。译文「比丘**心里**生起的嗔恨」把处格关系挪到了内心，与义注给的「所缘」解相悖，而本经通篇讲的正是「对某个人（puggala）」这一对象。
- **建议**：「比丘们，有这五种消除嗔恨的方法，比丘**对某个对象**生起的嗔恨，应当就在那里用这五种彻底消除。」（`sabbaso`「彻底／全部」与「用这五种」均有义注 `so sabbo imehi pañcahi` 支持，可保留；但「它们」宜明确为「这五种」。）句 142-159 结语同此改法，并把「那五种」改为「这五种」。

### §1091 句 25-37 / 44-56 / 63-75 / 82-94 / 101-114

- **问题**：语气漏译 — `jāyetha` 是愿望语气（optative），全句是假设条件句；义注亦作条件读（`yattha … uppanno hoti, tattha …`）。译文「对某个人生起了嗔恨」陈述为已然事实，读者会误以为在描述某一具体事件，而非给出通则。
- **建议**：五处统一补出条件连词，如「比丘们，**如果**对某个人生起了嗔恨，**就**应当对这个人修习慈（mettā）」。按 `style.md`，用「如果…就」，不要用「若…则」。

### §1091 句 115-135

- **问题**：标点 — 内层引语用了与外层相同的全角双引号。原文 `‘ kammassako ayamāyasmā … bhavissatī ’ ti` 是嵌在世尊话语（外层 `‘‘ … ’’`）内部的第二层引语；译文外层自句 2-21 起已用 “ ”，此处内层再用 “ ” 会造成引号层级混乱。按 `style.md` 第五节，内层应用全角单引号 ‘ ’。
- **建议**：改为「…确立业属于各自（kammassakatā）—— ‘这位尊者的业归他自己所有，…他将成为那业的继承者。’」；句末「。”；」三标点连用也应简化为「。’」，分号可省（原文 `;` 只是列项分隔，中文已有分段）。

## 建议项（非必改）

### §1091 句 101-114

- **问题**：`kammassakatā` 译「业自有的观念」中「观念」是增译，且「业自有」不易读懂。`-tā` 是抽象名词后缀（「业为己有」这一状态），`adhiṭṭhātabbā` 是「应当确立／决意」。
- **建议**：「应当对这个人确立『业属于各自』（kammassakatā）」或「…确立业自作性（kammassakatā）」。该词未登记在 `terms.md`，定案后请补入。

### §1091 句 82-94

- **问题**：`asatiamanasikāra` 译「不忆念、不思量」可通，但 `manasikāra` 的通行汉译是「作意」。**义注**：`yathā so puggalo na upaṭṭhāti, kuṭṭādīhi antarito viya hoti, evaṃ tasmiṃ asatiamanasikāro āpajjitabbo`（使那个人不现起于心，如同被墙壁等遮隔一样）——义注指向的是「令其不现起」，而非单纯「不去想」。
- **建议**：可作「不念、不作意（asatiamanasikāra）」；若保留现译，须在后续译义注时与本文用字完全一致（义注该处黑体 `**Asatiamanasikāro**` 是从本文原样引出的被解释词）。

### §1091 句 115-135

- **问题**：`kammayoni` 译「以业为生源」、`kammappaṭisaraṇa` 译「以业为依靠」——意思无误，但 `yoni`（胎／出生处）与 `paṭisaraṇa`（归依处、所依托）在南传汉译中多作「业为生因／业为母胎」「业为归依处」。
- **建议**：可沿用现译（可读性更好），但需登记进 `terms.md` 以免后续段落漂移。
