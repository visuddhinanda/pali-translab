# Review — 88:1195-1200（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句有，无 nissaya 的句子未出意见）

## 跨段一致性

- **-hetu 因由句的施事补出**：§1196「因为他杀生」、§1197「因为他偷盗」、§1198「因为他行了欲邪行」，§1199 却作「因为妄语」，§1200 作「因为饮酒放逸之事」，后两段没有补出「他」。建议统一补出「他」：§1199 改为「因为他说妄语」，§1200 改为「因为他饮酒放逸」。依据：nissaya `တမေနံ`（那个人，宾格）贯穿全句，`-hetu`＝`…ဟူသောအကြောင်းကြောင့်`（由于……这一原因），原因指的就是该人的行为。
- **-hetu 从句的位置**（§1196–§1200 全部 `Tamenaṃ rājāno gahetvā …hetu hananti vā …` 句，共 10 处）：现译「国王们把他抓住，因为他……，或者杀掉他，或者……」，把原因从句插在「抓住」与「或者」并列项之间，读者容易以为原因只管「抓住」。nissaya 的 `ဝေရမဏိဟေတု` / `ပါဏာတိပါတဟေတု` 修饰的是 `ဟနန္တိ / ဗန္ဓန္တိ / ပဗ္ဗာဇေန္တိ / ကရောန္တိ` 整组动词。建议全部统一为「国王们因为他……，就把他抓起来，或者杀掉他，或者囚禁他，或者把他驱逐出境，或者按情况处置他」。
- **yathāpaccayaṃ karonti**：各段一律译「随自己的心意处置他」。nissaya 的主释是 `ယထာ ပစ္စယံ= အကြောင်းအားလျော်စွာ`（依照原因、相应地），`အလိုရှိသလို`（随心所欲）是 `ဝါ=` 引出的异释。按 style.md 第四节「取主译，异释作脚注」，建议全 chunk 统一改为「按情况处置他」或「依案情处置他」。
- **cārittaṃ āpajji**：§1198 句 104-120 与 §1200 句 143-160 都译「侵犯了」，两处须同步修改，见下文 §1198。
- **atthaṃ pabhañji**：§1199 句 104-135 与 §1200 句 161-172 都译「毁坏了……的财物」，两处须同步修改，见下文 §1199。
- **含文言虚词「之」的译名**：「饮酒放逸之事」（§1200 全段）、「居士之子」（§1199、§1200）。建议改为「饮酒放逸的事」或其他现代说法、「居士的儿子」。「饮酒放逸」这一译名本身宜登记进 `terms.md` 统一。

## §1196 句 88-1196-49-67
- **问题**：增译 — 「国王们**却**把他抓住」里的「却」，pali 与 nissaya 都没有转折成分（`တမေနံ … ရာဇာနော … ဂဟေတွာ`），这是译者加的语气。
- **建议**：删去「却」，按跨段一致性一节调整原因从句的位置。§1197、§1198、§1199、§1200 的同型问句与转述句（句 26-44、78-94 等）一并处理。

## §1196 句 88-1196-68-76
- **问题**：所指模糊 — nissaya：`ဧတံ= ဤသို့မြင်ခြင်းကြားခြင်းသည်`，即「这样的见、闻」不存在。现译「没有这样的事」容易读成「世上没有这种事」，而原意是「我们没有见过、听过」。
- **建议**：改为「大德，我们没有见过，也没有听过。」§1197、§1198、§1199、§1200 的同句同步修改。

## §1196 句 88-1196-119-148
- **问题**：词义偏窄或偏移 — `ပါပကမ္မံ= ယုတ်မာသောအမှုလုပ်ငန်းကို`（卑劣的行为，宾格）。这里指他犯下的具体罪行，译「恶业」会引向业报义。
- **问题**：动词力度 — `ပဝေဒေန္တိ= သိစေကြကုန်၏ / ဝါ= သိအောင်ပြောကြကုန်၏`（使人知道、说出来让人知道），语境是揭发罪行。
- **建议**：改为「然而，人们确实会照他所做的那样，揭发他的恶行——」。nissaya 补出的施事 `(အညေ)`（其他人）现译作「人们」，可保留。各段同句同步修改。

## §1196 句 88-1196-183-195
- **问题**：补出成分 — nissaya：`ဧဝရူပံ= ဤသို့သဘောရှိသောပြစ်ဒဏ်ပေးခြင်းကို`（这一类的施加刑罚）。现译「这样的事」可以接受，但不如 nissaya 明确。
- **建议**：可选改为「这样的惩处」。同句各段同步修改。此项非必改。

## §1197 句 88-1197-102-121
- **问题**：补出成分 — `အဒိန္နံ= ပိုင်ရှင်ကမပေးအပ်သောပစ္စည်းဥစ္စာကို`（物主没有给的财物），给予者是物主。现译「没有给他的东西」没有交代是谁没给，读来含混。
- **建议**：改为「以盗心拿走了别人没有给的东西」。§1200 句 122-142 同步修改。

## §1198 句 88-1198-104-120
- **问题**：误译 — nissaya：`ပရိတ္တိသု= သူတပါးတို့၏ဇနီးမိန်းမတို့၌` / `ပရကုမာရီသု= …သမီးပျိုတို့၌`（处格：在他人妻子、他人少女身上），`စာရိတ္တံ= မေထုန်ပျော်ပါးသွားလာသူ၏အဖြစ်သို့`、`အာပဇ္ဇ= ရောက်ပြီ`（陷入行淫者的状态）。原文讲的是与对方行淫，不含强制义。「侵犯」带有暴力、强迫的意味，译窄并译偏了。
- **建议**：改为「这个人与别人的妻子、别人家的少女有了不正当的性关系」。§1200 句 143-160 同步修改。

## §1199 句 88-1199-104-135
- **问题**：词义译窄 — `အတ္တံ= အကျိုးစီးပွားကို`（利益、福祉），不限于「财物」。
- **问题**：属格的两解 — nissaya 对 `ဂဟပတိဿ / ဂဟပတိပုတ္တဿ` 给了两种读法：一是 `ကို` 读，连 `မုသာဝါဒေန`（对居士说妄语）；二是 `ဝါ= ၏` 读，连 `အတ္ထံ`（居士的利益）。现译取了后一种，这也是主流读法，可以接受。
- **问题**：文言 — 「居士之子」用了文言虚词「之」。
- **建议**：改为「这个人用妄语损害了居士或居士儿子的利益」。§1200 句 161-172 同步修改。
- **数据疑问**：本句与句 136-149 的 nissaya 混入了 §1200 的内容（`ထိုသေရည်အရက်သောက်သောသူကို`、`သုရာမေရယ…`），疑为对齐错位。这只影响本次核对，不影响译文。

## §1199 句 88-1199-136-149
- **问题**：漏补施事 — nissaya `တမေနံ` 指那个说妄语的人，原因是他的行为。现译「因为妄语」没有补出「他」，与其他各段不一致。
- **建议**：改为「国王们因为他说妄语，就把他抓起来，……」。
