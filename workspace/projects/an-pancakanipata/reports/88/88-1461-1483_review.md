# Review — 88:1461-1483（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- ānisaṃsa：§1463、§1470 译「利益」，§1473 译「好处」 → 统一为「利益」（4 处中占 3 处，且与「过患」对仗）。
- atinivāsa：§1462 译「久住一处」，§1481 摄颂译「过久居住」 → 摄颂改为「久住一处」，与经文对应。
- Ussūrabhatta 经名：§1471 标题「过时饭经（ussūrabhatta）」，§1482 摄颂「饭食经」 → 统一。标题里的巴利夹注要去掉，其他经题都没有夹注。经题按 nissaya 取义建议作「晚饭经」或「迟炊经」，见 §1472 句 88-1472-2-16。
- dāsakammakaraporisa：§1470 译「奴仆、雇工和随从」，§1472、§1473 译「奴仆、雇工和帮佣」 → 统一为一种。nissaya：`ဒါသကမ္မကရပေါရိသာ= ကျွန်အခကြေးစားအလုပ်သမားမှီခိုအသက်မွေးသူတို့` 意为奴仆、受雇工人、依附谋生者，建议用「奴仆、雇工和依附的人」或「随从」。
- samaṇa 夹注：§1470 已在首次出现处作「沙门（samaṇa）」，§1472 又夹注一次 → §1472 删去「（samaṇa）」，只在首次出现时夹注。
- 序号格式：经题 §1461–§1468 用「4. / 5. / 6. / 7.」，§1471–§1476 改用「八、 / 九、 / 十、」；经号 §1462–§1469 用「224. / 225. / 226. / 227.」，§1472–§1477 改用「二二八、 / 二二九、 / 二三〇、」；§1483 品题「（二四）第四 常住比丘品」又是另一种写法 → 全 chunk 统一为同一种体例。
- 结句「Ime kho, bhikkhave, pañca ādīnavā …」：§1462、§1465、§1467、§1469 译「这就是……的五种过患」，§1472 句 88-1472-65-74 译「在……人家里就有这五种过患」 → 巴利句式相同，统一为「这就是……的五种过患」。
- mittadubbhī：§1475、§1477、§1478 都译「背害朋友」。「背害」不是现代常用词，有文言味 → 三处统一改为「伤害朋友」或「加害朋友」，见 §1475 句 88-1475-18-37。
- vikālabhojanā 一句：§1473 句 88-1473-33-44 与 §1472 句 88-1472-41-53 文字相同，有同样的结构误读，需要同步修改，见下。
- na kālena paṭipūjenti：§1472 三处的「不按时……」与 §1473 的「按时……」应按 nissaya 一起改成「没法 / 能够」，见 §1472 句 88-1472-20-30。

## §1465 句 88-1465-33-55
- **问题**：补出成分 — anāmantacāre 的 nissaya 是 `ထင်ရှားရှိနေသောရဟန်းကိုမပန်ကြားဘဲ…သွားခြင်း`，意为「没有向在场的比丘告假就去」。告假的对象是在场的比丘，译文只写「没有告假」，对象缺失。nissaya 还在 raho nisajjāya 处补出 `တယောက်ချင်းချင်း`（一对一、单独），译文作「与女人共坐」，「单独」的意思没有译出。
- **建议**：改为「会犯没有告知在场比丘就……到俗家走动的罪，会犯在隐秘处与女人单独同坐的罪……」。

## §1467 句 88-1467-2-19
- **问题**：格与句法 — `ကုလေသု= လူဒါယကာအိမ်တို့၌` 是处格（在俗家里），`သံသဋ္ဌဿ= လူတို့နှင့်ရောနှောလျက်` 意为与俗人混杂。译文「与俗家过从亲密」把处格读成了交往对象。「过从」也偏文言。
- **建议**：改为「亲近俗家的比丘在俗家里与俗人交往过密、待得太久，有这五种过患」。

## §1467 句 88-1467-23-40
- **问题**：补出成分 — nissaya 补出了 otāra 与 otiṇṇacitta 的施动者和主体：`သြတာရော= ရာဂဘီလူးပူးကပ်ခွင့်` 意为让贪欲（如鬼魅）附身的机会，`သြတိဏ္ဏစိတ္တဿ= ရာဂဘီလူးပူးကပ်အပ်သောစိတ်ရှိသောရဟန်း` 意为心被贪欲侵入的比丘。译文「下手的机会」没有说明是谁下手，「心已被侵入的人」既缺「贪欲」，又把「比丘」泛化成了「人」。
- **建议**：改为「……有了亲密，贪欲就有了乘虚而入的机会；对于心已被贪欲侵入的比丘，这是可以预料的——」。

## §1467 句 88-1467-41-56
- **问题**：误译（术语所指） — `သိက္ခံ= အဓိသီလသိက္ခာ` 指增上戒学，即「学」本身，不是 sikkhāpada（学处）。sikkhaṃ paccakkhāya 是「舍戒 / 舍学」，译作「舍弃学处」把所指缩窄成了具体某条戒。`ဟီနာယ= ယုတ်နိမ့်သောလူ့ဘဝ` 明确指低劣的在家生活，译文「低下的生活」不够明确。
- **建议**：改为「要么会舍戒，还俗回到低劣的在家生活」。

## §1469 句 88-1469-18-34
- **问题**：语态歧义 — `အပ္ပိယေဟိ= မချစ်ခင်အပ်ကုန်သော`（不被喜爱的），nissaya 的异释是 `မုန်းတီးဖွယ်`（可厌的），是被动义。译文「不喜爱的继承人」可以读成「不喜爱（他）的继承人」，主动被动关系不清。
- **建议**：改为「不讨人喜欢的继承人」或「可厌的继承人」。

## §1472 句 88-1472-2-16
- **问题**：取义过度具体 — `ဥဿူရဘတ္တေ= အလွန်မြင့်တက်သောနေရှိရာအခါ၌ချက်အပ်သောထမင်းရှိသော`，异释 `ထမင်းချက်အလွန်နေမြင့်သော`，意思都是太阳升得很高时才煮饭，没有「过了午时」的意思。译文「过了午时」是额外加的界限，容易和比丘的非时食（过午）混淆。同样的问题也出现在 88-1472-65-74 和 §1471 经题。
- **建议**：改为「在太阳升得老高才做饭的人家里」或「开饭很晚的人家里」，三处同步。

## §1472 句 88-1472-20-30
- **问题**：格与句法 / 补出成分 — `အတိထီ= …အာဂန္တုကဖြစ်ကုန်သော` 是修饰 `ပါဟုနာ`（客人）的定语，意为从外地临时来的客人，只有一类人。译文「不期而至的客人和远来的宾客」拆成了两类。另外 `န ပဋိပူဇေန္တိ= မပူဇော်နိုင်ကြကုန်` 是「没法、不能款待」，nissaya 的注说明原因是饭做得晚，没法在喝粥时上粥、吃饭时上饭。译文「不按时」像是主观上不肯。
- **建议**：改为「对那些从外地临时来访的客人，他们没法按时招待」。88-1472-31-40、88-1472-41-53 同样改作「没法按时……」。§1473 对应三句作「能按时……」，并同步合并「客人和宾客」。

## §1472 句 88-1472-41-53
- **问题**：句法误读 — nissaya 把三项分开列出：`ဧကဘတ္တိကာ`（只吃早上一餐）、`ရတ္တူပရတာ= ညဉ့်၌စားခြင်းမှရှောင်ကြဉ်`（不在夜里吃）、`ဝိကာလဘောဇနာ ဝိရတာ= နေမွန်းလွဲချိန်၌စားခြင်းမှရှောင်ကြဉ်`（不在过午的时候吃），三者并列。译文用「也就是」把「离非时食」说成「夜间不食」的同义复述，结构译错了。
- **建议**：改为「对那些一天只吃一餐、夜里不吃、也不在过午的非时进食的沙门和婆罗门，他们没法按时供养」。§1473 句 88-1473-33-44 同步修改。

## §1475 句 88-1475-2-14
- **问题**：词义（可选） — `ကဏှသပ္ပေ= မြွေဟောက်` 意为眼镜蛇。译文按字面译「黑蛇」，不算错，但 nissaya 指的是具体蛇种。
- **建议**：可以保留「黑蛇」，在首次出现处（§1474 经题或本句）加脚注说明 nissaya 解作眼镜蛇。不建议改正文。

## §1475 句 88-1475-18-37
- **问题**：取义 / 用词 — sabhīru：`ကြောက်မက်ဖွယ်အိပ်ခြင်းနှင့်တကွဖြစ်၏`，异释 `ကြောက်မက်ဖွယ်ကောင်းလောက်အောင်အလွန်အအိပ်ကြီး၏`。nissaya 的重点是嗜睡到了可怕、危险的程度，附注说明过度睡眠会招来敌人击杀，是一种可怕的危险。译文「贪睡」丢了「可怕、危险」这一层。mittadubbhī：`(အစာကျွေးသော)မိတ်ဆွေကိုသော်မှပင်ညှဉ်းဆဲနှိပ်စက်တတ်၏` 意为连喂它的朋友也会伤害，「背害」不是现代常用词。
- **建议**：「贪睡」改为「嗜睡得危险」或「睡得过沉、招来危险」；「背害朋友」改为「伤害朋友」。88-1475-50-71、§1477、§1478 同步修改。

## §1478 句 88-1478-27-40
- **问题**：句法 / 语体 — `တတြ= ထိုကောဓနော အစရှိသောစကား၌; ဣဒံ= ဤသည်ကား` 意为在易怒等五项当中，这一项是指……；nissaya 还补出 `(ဣဒံ…ဃောရဝိသတာ)`，即「这种贪欲强烈就是毒性剧烈」。译文「就在这里」是逐字直译，读起来是翻译腔，「在这五项中」的范围也没有交代。
- **建议**：改为「比丘们，这当中，所谓女人毒性剧烈，是指：女人大多贪欲强烈」。88-1478-41-54、88-1478-55-69 采用同一句式。
