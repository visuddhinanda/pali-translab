# Review — 88:3-22（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§3–6、§10、§17、§20 的标题句，以及 §11 前三句、§13–16 与 §19 的部分句子、§21 与 §22 的部分句子没有 nissaya，这些句子不出意见）

## 跨段一致性
- **ariya-sāvaka 句首的 idha**：§11–15 都译成“在这（佛法）中”，§18、§19、§21、§22 都译成“在这（教法）中”。nissaya 的释义是 `ဣဓ= ဤသာသနာတော်၌`（在这个教法中），建议统一为“在这（教法）中”。
- **hirī / hirimā / ahiriko**：§8、§11、§12 译作“惭力”“感到羞惭”，§18 却译“没有羞耻心（hirī）”，§19 和 §22 译“有羞耻心”。同一个词前后脱节，读者看不出这里的“羞耻心”就是前面的“惭力”。建议统一用“惭”这一系：“有惭”“无惭”，或者“有惭心”“没有惭心”。
- **ottappa / ottappī / anottappī**：§8 与 §13 译作“愧力”“感到愧惧”，§18 却译“不怕作恶（ottappa）”，§19 和 §22 译“怕作恶”。建议统一用“愧”这一系：“有愧”“无愧”，或者“会感到愧惧”“不会感到愧惧”。
- **夹注巴利原词的位置**：五力在 §8 第一次出现时没有夹注，到 §18 才加注，而且 §18 注的是正面名词（saddhā、hirī、ottappa、paññā），原文却是否定形容词（assaddho、ahiriko、anottappī、duppañño）。只有 kusīta 一个保持原词形，体例不统一。建议把夹注移到 §8 第一次出现的地方，或者删掉 §18 的夹注。
- **Evañhi (kho / vo) … sikkhitabbaṃ**：§9 译“你们就应当这样学习”，§16 译“你们确实应当这样学习”。nissaya 两处都是 `ဧဝံဟိ= …သာလျှင်`（正是这样、唯有这样），并且都补出了 `ဝေါ= သင်တို့သည်`（你们）。建议两处统一，比如都译成“你们正应当这样修学”。
- **sikkhitabbaṃ**：§9 与 §16 都译成“学习”。nissaya 的释义是 `ကျင့်ကြံအားထုတ်ရမည်`（要实践、要努力修习），说的是实修，不是学知识。建议改成“修学”，各处统一。
- **yathābhataṃ nikkhitto evaṃ niraye / sagge**：§21 和 §22 共四处同一个句式，问题都一样（见下面 §21 句 88-21-2-19），要一起改。其中 88-21-45-58 和 88-22-2-16 没有 nissaya，但要跟着改。§20 的标题“如被带去经”也要相应核对。
- **章节编号体例**：§4 用“1.”，§5 起用“一、”，前后不一致。

## §7 句 88-7-2-22
- **问题**：格 / 处所 — `သာဝတ္ထိယံ= သာဝတ္ထိမြို့တော်အနီး၌`，这是表邻近的处格，意思是“在舍卫城附近”。祇园在城外，译文“住在舍卫城的祇树给孤独园”把祇园说成了城里的地方。
- **建议**：改为“世尊住在舍卫城附近的祇树给孤独园”。

## §7 句 88-7-23-28
- **问题**：取义 — nissaya 的主释是 `တတြ= ထိုအခါ၌`（在那时），“在那个寺院里”只是 `ဝါ=` 后面的异释。译文“在那里”取的是异释。
- **建议**：按主释改成“那时，世尊对比丘们说——”。如果要保留处所义，按体例把异释列进脚注。

## §9 句 88-9-2-11
- **问题**：漏译成分 — nissaya 把 `တသ္မာတိဟ` 拆成 `တသ္မာ + ဣဟ`，`ဣဟ= ဤသာသနာတော်၌`（在这个教法中），并补出 `ဝေါ= သင်တို့သည်`（你们）。另外，`ဧဝံ= ဤသို့နှလုံးသွင်း၍` 指的是“这样作意之后去修学”。译文只译了“所以”。
- **建议**：改为“所以，比丘们，在这里你们应当这样修学——”。§16 句 88-16-2-11 同样处理。

## §11 句 88-11-48-65
- **问题**：取义 — nissaya 的主释把 `အနုတ္တရော`（无上者）和 `ပုရိသဒမ္မသာရထိ`（调御丈夫）分成两个德号，合成一个德号的读法放在 `[တနည်း …]`（另一种解法）里，是异释。译文“能调御可以受调御的人的无上御者”取的是异释。另外，每个德号前都有 `ဣတိပိ= …ဤအကြောင်းကြောင့်လည်း`（由于这个缘故，也……），表示“也被称为”，译文统一写成“就是……”，这层意思没了。
- **建议**：按主释分开译：“……世间解、无上者、调御丈夫、天人师……”，合读作脚注备列。“这位世尊就是……”可以改成“这位世尊因此也被称为……”。

## §14 句 88-14-10-30
- **问题 1**：取义 — `ဥပသမ္ပဒါယ= ပြီးစီးပြည့်စုံစေခြင်းငှာ`，主释是“为了使（善法）成就圆满”，“获得”只是 `ဝါ=` 异释。
- **建议**：改为“为了成就善法”。
- **问题 2**：格 — `ကုသလေသု ဓမ္မေသု= …တရားတို့ကြောင့်`，异释作 `တရားတို့ကို ရဖို့ အကြောင်းကြောင့်`，是因由（为了得到善法），不是处所。译文“在善法上从不放下担子”取成了处所。
- **建议**：改为“对于善法从不放下担子”，或者“为了善法从不放下担子”。

## §15 句 88-15-10-25
- **问题**：补出成分超出依据 — nissaya 给 `နိဗ္ဗေဓိကာယ` 补的是 `(လောဘအတုံးအခဲ စသည်ကို)`（贪的团块等），只点了“贪”一项，后面用“等”概括。译文补成了“（贪、瞋、痴）”。
- **建议**：照 nissaya 补“（贪等）”，或者干脆不补。

## §18 句 88-18-35-54
- **问题**：术语与词法 — `အဟိရိကော= အကုသိုလ်ဒုစ္စရိတ်ကို မစက်ဆုပ်သည်`（不厌恶恶行），`အနောတ္တပ္ပီ= …ကြောင့် မကြောက်လန့်သည်`（不因恶行而畏惧）。这两个词就是 §12、§13 的“惭”“愧”加上否定，但译文换成了“没有羞耻心”“不怕作恶”，和前文对不上（见“跨段一致性”）。另外，“没有信”不太通顺。
- **建议**：改为“没有信心、无惭、无愧、懈怠、缺乏智慧”。§19、§21、§22 的相应句子同步修改。

## §21 句 88-21-2-19
- **问题**：句法误读（必改） — nissaya 把句子拆成比喻和合喻两部分：
  - 比喻：`ဘိက္ခု= ရဟန်းကို`（比丘，宾格），`အာဘတံ= …ဆောင်ယူ၍`（被带到某处），`နိက္ခိတ္တော ယထာ= ချထားအပ်သကဲ့သို့`（就像被放下一样）。
  - 合喻：`ဧဝံ= ဤအတူ`（同样），补出施事 `(အတ္တနော ကမ္မနာ= မိမိ၏ အကုသိုလ်ကံသည်)`（被自己的不善业），`နိရယေ နိက္ခိတ္တော= ချထားအပ်သည်သာ`（必定被放进地狱）。

  也就是说，“像东西被带来放下一样”只是比喻，被放进地狱是实说。译文“如同已被带去放置在地狱中”把比喻套到了“地狱”上，下地狱就成了虚拟的，意思反了；补出的施事（自己的业）也没有体现。
- **建议**：改为“比丘们，具备五种法的比丘，就像被人带来放下一样，必定被放进地狱”。如果要补出施事：“……必定被自己的恶业放进地狱”。

## §22 句 88-22-40-56
- **问题**：句法误读（必改） — 和 88-21-2-19 是同一个问题。nissaya 补出的施事是 `(အတ္တနော ကမ္မနာ= ကုသိုလ်ကံသည်)`（自己的善业），`သဂ္ဂေ နိက္ခိတ္တော= ချထားအပ်သည်သာ`（必定被放进天界）。
- **建议**：改为“比丘们，具备这五种法的比丘，就像被人带来放下一样，必定被放进天界。”88-22-2-16 同步修改。
