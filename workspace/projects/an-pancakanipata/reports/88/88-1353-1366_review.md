# Review — 88:1353-1366（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（88-1358-32-54 无 nissaya，略过）

## 跨段一致性
- **单复数与指代**：§1362 首句的 sīlavanto pabbajitā 是复数主格。§1362 句 28 起的 sīlavante pabbajite … upasaṅkamante 是**单数处格独立结构**，nissaya 特意注明取「သတ္တမီ ဧကဝုစ်」（处格单数），读作「ရဟန်းသည်…ကြွရောက်လာလသော်」（当那位比丘来到时）。译文在 §1362 句 28 写「看见他们」，在 §1363 写「请他们坐下」，用了复数代词，与 nissaya 不合。§1364–1366 没有用代词，所以没有暴露这个问题。→ 建议在 §1362–1366 这五个处格句里统一用单数指代（「他」「这位出家人」），或者改写成不用代词的句子。
- **Katame/Katamehi pañca(hi)**：§1354 译「哪五种呢？」，§1360 译「是哪五个条件呢？」，§1362 译「是哪五个方面呢？」。三处句式不统一 → 建议统一为「哪五…呢？」或「是哪五…呢？」二者之一。

## §1354 句 88-1354-2-33
- **问题**：词义（轻）— nissaya：`ဝဿဿ= မိုးရွာခြင်း၏`（降雨的），`နေမိတ္တိကာ … န အနန္တိ= ကြိုတင်၍မသိနိုင်`（不能预先知道）。译文「雨的障碍」「所不知道的」都偏泛。
- **建议**：可考虑改为「降雨的障碍」「占相者无法预知的」。若采纳「降雨」，§1354–1358 各句「第 N 种雨的障碍」要同步改。非必改。

## §1356 句 88-1356-2-16
- **问题**：补出成分 — nissaya：`ပါဏိနာ= လက်ခုပ်ဖြင့်`（用掬起的双手），`ဥဒကံ= မိုးရေကို`（雨水，宾格）。译文「用手接住水」没有译出「掬捧」，也没有点明是雨水。在讲降雨障碍的语境里，「水」指什么不够清楚。
- **建议**：改为「阿修罗王罗睺用双手捧接雨水，把它倒进大海里」。

## §1357 句 88-1357-2-13
- **问题**：用词重复 — nissaya：`ဝဿဝလာဟကာ= ဝဿဝလာဟကမည်ကုန်သော … ဒေဝါ= နတ်တို့သည်`（名为「雨云」的诸天）。「雨云天的天神们」中「天」重复出现。
- **建议**：改为「雨云天神们放逸了」或「名为雨云的天神们放逸」。

## §1360 句 88-1360-2-38
- **问题**：取义（提示）— nissaya 对 `pañcahi aṅgehi samannāgatā` 给出两解：
  - 主解：`အင်္ဂေဟိ= အကြောင်းတို့ကြောင့်`（从格，「由五种因」）＋ `သမန္နာဂတာ= ကောင်းစွာသင့်လျော်စွာဖြစ်ပေါ်လာသော`（如理生起的）
  - 异解：`အင်္ဂေဟိ= အစိတ်အပိုင်းတို့နှင့် … ယှဉ်တွဲသော`（具格，「与五个组成部分相应」）

  译文「具备五个条件」接近异解的结构，但「条件」既不是「因」，也不是「部分/要素」。
- **建议**：若取异解，改作「具备五项要素（五支）的话语」；若取主解，改作「由五种因而如理说出的话语」。所选读法要在 §1360 的句 2、39、68 三处保持一致。

## §1360 句 88-1360-42-67
- **问题**：语法 / 格 — nissaya：`မေတ္တစိတ္တေန= မေတ္တာနှင့်ယှဉ်သောစိတ်ဖြင့်`（具格，「以与慈相应的心」），`အတ္ထသံဟိတာ= အကျိုးစီးပွားနှင့်ဆပ်စပ်လျက်`（与利益相关联地）。
  - 「说得怀着慈心」不通：「说得」后面只能接形容性补语，「怀着慈心」是方式状语，应该放在动词前。
  - 「对人有益」补出了「对人」，nissaya 没有这一成分。
  - 原文五个 `… ca bhāsitā hoti` 是被动谓语，主语是 vācā。
- **建议**（必改）：改为「它是在适当的时候说的，是真实的，是柔和的，是与利益相关的，是怀着慈心说的」，或者用「…地说出」的并列结构。至少要把「说得怀着慈心」改成「怀着慈心说出」。

## §1362 句 88-1362-2-24
- **问题**：格（轻）— nissaya：`ဌာနေဟိ= အကြောင်းတို့ဖြင့်`（具格，「通过五种缘由」）。译文「从五个方面」可以接受，但没有体现具格的手段义。
- **建议**：可改为「通过五种途径（缘由）」。§1366 句 31 要同步改。非必改。

## §1362 句 88-1362-28-64
- **问题**：数 — 理由见跨段一致性：nissaya 取处格单数「ရဟန်းသည်…ကြွရောက်လာလသော်」（当那位比丘来到时），译文「看见他们」用了复数。
- **建议**（必改）：改为「人们看见他而心生净信」。
- **问题**：动词体（轻）— nissaya：`ပဋိပဒံ= အကျင့်ကို။ ပဋိပန္နံ= ကျင့်သည်။ ဟောတိ= ဖြစ်၏`（正在实践这种行道）。「走上了……道路」带完成体「了」，与「在那个时候」的时点用法稍有偏差。
- **建议**：可改为「就是在实践导向生天的行道」。§1363–1366 要同步。非必改。

## §1363 句 88-1363-2-30
- **问题**：词义 / 数 — nissaya：`အဘိဝါဒေန္တိ= ရှိခိုးကြကုန်၏`（礼拜、顶礼），`အာသနံ= နေရာထိုင်ခင်းကျောင်းကို … ဒေန္တိ= ပေးလှူကြကုန်၏`（布施座位）。
  - 「恭敬问候」把「礼拜」译轻了。
  - 「请他们坐下」把「献座」改成了「请坐」，而且用了复数代词（见跨段一致性）。
- **建议**（必改）：改为「人们起身迎接、向他礼拜、为他设座」。

## §1366 句 88-1366-2-30
- **问题**：补出成分 / 词义（轻）— nissaya：`ပရိပုစ္ဆန္တိ= သိလိုသောတရားဓမ္မကိုမေးမြန်း`（询问想了解的法），`ပရိပဉ္စန္တိ= … စစ်ဆေး`（审察、探究）。「追问」与「审察」义有偏差，两个动词的宾语也没有补出。
- **建议**：可改为「人们请教、探究想了解的法义，并且听法」。
