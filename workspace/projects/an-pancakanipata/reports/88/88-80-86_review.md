# Review — 88:80-86（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格助词无法核对，以下语法判定仅依巴利形态与义注）／义注 ✅（book 101 §41 释第一经、§43 释第二经；§39/40/42 为品题与经题）

## 必改项（通项，贯穿全 chunk）

### 1. 人称与语式误读：`paripūressatī` 是第三人称，不是比丘自己“说”的话

`So vata, bhikkhave, bhikkhu agāravo … ‘… paripūressatī’ti netaṃ ṭhānaṃ vijjati` 的结构是：
**“一个……的比丘竟会圆满……”——这种情形不存在**。引号里的 `ti` 标记的是**被否定的那个命题**，`paripūressatī` 是 3sg. fut.（“他将圆满”），不是 1sg.。

现译把它处理成比丘的发言、并改成第一人称（「却说‘我要……’」／「说‘我圆满了……’」），有两处连带错误：

- 凭空加出一个“说”的动作主体和一段自述，原文没有；
- 把“他将……”改成“我要……”，人称与语式双误。读者会理解为“比丘发了这样的愿/夸了这样的口，所以不可能”，而原文说的是“这种事态本身不成立”。

**影响句（全部）**：`88-82-2-29`、`88-82-30-50`、`88-82-51-62`、`88-82-63-73`、`88-82-74-84`、`88-83-2-23`、`88-83-24-35`、`88-83-36-46`、`88-83-47-56`、`88-83-57-69`、`88-85-2-28`、`88-85-29-41`、`88-85-42-53`、`88-85-54-64`、`88-85-65-75`、`88-86-2-22`、`88-86-23-34`、`88-86-35-44`、`88-86-45-56`、`88-86-57-69`

**建议统一改法**（以 `88-82-2-29` / `88-82-30-50` / `88-83-2-23` 为模板，余句照推）：

- 否定式首句：「比丘们，一个不敬重、不顺从、生活方式与同修不一致的比丘，会在同修当中圆满行仪之法——这种情形是不存在的。」
- 否定式后续句：「不圆满行仪之法而能圆满学人之法——这种情形是不存在的。」
- 肯定式首句：「比丘们，一个敬重、顺从、生活方式与同修一致的比丘，会在同修当中圆满行仪之法——这种情形是存在的。」
- 肯定式后续句：「圆满了行仪之法而后圆满学人之法——这种情形是存在的。」

后续句原文无主语（`aparipūretvā … paripūressatī` 承前省略），**按 `style.md` 第六节不要补「他」/「我」**，用无主语的“不圆满 A 而能圆满 B”即可。

### 2. `ābhisamācārikaṃ dhammaṃ` 译「基本的行为规范」与义注相悖

**义注**（101-41-17-23）：`**Ābhisamācārikaṃ** **dhamman**ti uttamasamācārabhūtaṃ vattavasena paññattasīlaṃ.`——“是指**最上行仪**（uttama-samācāra）、依义务行持（vatta）而制定的戒”。

义注明确把它定为 **uttama**（最上／优良）行仪，现译「**基本的**行为规范」正好取了相反的那一极（现代学界常见的 “minor/basic observances” 一路），按本项目“冲突以义注为准”的规矩，这是**错，不是风格问题**。同时「行为规范」把 `sīla`（戒）虚化成了世俗词。

**影响句**：`88-82-2-29`、`88-82-30-50`、`88-83-2-23`、`88-83-24-35`、`88-85-2-28`、`88-85-29-41`、`88-86-2-22`、`88-86-23-34`

**建议**：统一译「**行仪之法**」（义注释为“依义务行持而制定的最上行仪之戒”，这一释义放脚注，不进正文）。若要更贴近义注可作「增上行仪之法」；不论取哪个，八处必须完全一致——这个词是义注的被解释词（黑体），义注层译文要逐字引用它。

### 3. `asabhāgavuttiko` / `sabhāgavuttiko` 译「行为不合群／合群」偏离义注

**义注**（101-41-2-16）：`**asabhāgavuttiko**ti asabhāgāya visadisāya jīvitavuttiyā samannāgato.`——“具有不相同（asabhāga = visadisa）的**生活行持**（jīvita-vutti）”。

义注把 `vutti` 定为 **jīvitavutti**（生活行持方式），指与同修的行止不一致；现译「不合群」是性情／人际层面的现代口语词，丢了“生活行持方式”这一所指，容易被读成“性格孤僻”。

**影响句**：`88-82-2-29`、`88-83-2-23`、`88-85-2-28`、`88-86-2-22`

**建议**：「生活方式与同修不一致」／肯定式「生活方式与同修一致」（义注的被解释词，四处须逐字相同）。

## 跨段一致性

- `ābhisamācārika dhamma`：§82/83/85/86 一律作「基本的行为规范」——**用词前后一致，但依据义注整体错**，见上「必改项 2」，八处须一并替换，不要只改一半。
- `sekha dhamma`：四段一律「学处之法」，译法一致。但**义注**（101-41-24-28）`**Sekhaṃ** **dhamman**ti sekhapaṇṇattisīlaṃ`——“为学人所制定（sekhapaṇṇatti）的戒”，重心在“学人”（sekha = 有学者）而非“学处”。「学处之法」会被读成“学处（sikkhāpada）所摄的法”，与义注所指错位。建议统一改「**学人之法**」，义注释义入脚注。
- `sīlāni`（§82-51-62 / §82-63-73）译「各项戒」，而 §85/86 的 `sīlakkhandha` 译「戒蕴」——**原文本身不同（第一经列 sīlāni，第二经列三蕴），分译是对的**，无需统一。但「各项戒」宜改「**诸戒**」：**义注**（101-41-29-33）`**Sīlānī**ti cattāri mahāsīlāni`——指**四大戒**，是有定数的一组，「各项」把它散化了。
- `sīlakkhandha / samādhikkhandha / paññākkhandha`：§85/86 一律「戒蕴／定蕴／慧蕴」，与**义注**（101-43-2-10）`**sīlakkhandhan**ti sīlarāsiṃ`（戒的聚集）相符，一致 ✅。
- `agārava / appatissa`：四处一律「不敬重／不顺从」，肯定式「敬重／顺从」，一致 ✅。
- `sabrahmacārīsu`：四处一律「同修行者当中」，一致 ✅（可简作「同修当中」，但不改也不算问题；若改需四处同改）。
- `netaṃ ṭhānaṃ vijjati` / `ṭhānametaṃ vijjati`：一律「这种情形是不可能的／是可能的」，一致。但**语义偏移**：`vijjati` = “存在／有”，说的是“**无此事**”而非“无此可能”。建议统一为「这种情形是不存在的／是存在的」，与上面的句式改写配套。
- 语体：全 chunk 为现代书面汉语，未见文言虚词与文言句式 ✅。标点全角、引号用 “” ‘’、无 ASCII 引号 ✅。译文无工作标记 ✅。
- 经题：§81「第一不敬经」／§84「第二不敬经」，§80「五支品」——与义注品题（101-39 `Pañcaṅgikavaggo`、101-40/42 `…agāravasuttavaṇṇanā`）对应一致 ✅。

## §82 句 88-82-2-29

- **问题**：漏译 — 语气词 `vata`（确实、真的）未体现。它加强的是“这种事绝无”的断定语气。
- **建议**：句末落在「——这种情形**确实**是不存在的」上即可，不必另加副词堆叠。

## §83 句 88-83-24-35、88-83-36-46、88-83-47-56、88-83-57-69

- **问题**：时序关系 — `paripūretvā`（绝对分词，先行动作）现译「我圆满了 A，再要圆满 B」，把先后关系落在“再要”这个意愿词上，与肯定式“此事存在”的论断语气不合。
- **建议**：「圆满了 A 而后圆满 B——这种情形是存在的。」（§86 对应四句同改）

## §85 句 88-85-42-53

- **问题**：跨段对照 — 与 §82-51-62 并列阅读时，第一经作 `sīlāni`、第二经作 `sīlakkhandhaṃ`，是两经的实质差别（四大戒 vs 三蕴），**义注**（101-43-15-21）`Ime pana tayopi khandhā missakāva kathitāti`（这三蕴也是混合说的）正点在此。现译「各项戒」/「戒蕴」虽未译错，但读者看不出两经的对照点。
- **建议**：译文不加说明（`style.md` 不留标记），但 §82 用「诸戒」、§85 用「戒蕴」的区分要守住，并在导言或脚注交代两经差异。

## 存疑待定（不改译文，留待 revise / 术语表定案）

1. `ābhisamācārika` 的定译：义注取 “uttama-samācāra（最上行仪）”，与巴英学界主流的 “abhi- = 小小、基本” 一路相反。本项目规矩是以义注为准，故建议「行仪之法」并在 `term-glossary.jsonl` 立条（`status: pending`，note 记明与通行译法的分歧），避免后续章节反复。
2. `sekha dhamma` 译「学人之法」后，与 §82 的 `sīlāni`（四大戒）、§85 的三蕴构成同一递进序列，三者的汉译层级感需在 harmonize 步统一检视。
3. 缺 nissaya，`sabrahmacārīsu`（处格，“在同修当中”还是“对同修”）与 `appatissa` 的格关系未得词级印证；`sabrahmacārīsu` 取处格“在……当中”从语境可通，但建议 revise 前补一次 nissaya 查对。
