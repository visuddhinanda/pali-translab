# Review — 88:829-840（channel: 73c03e1a…b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位核对无法做，格与隐含成分的判断仅据巴利本身）／义注 ⚠ 部分（book 101 §254 仅释第六、第七经 116–117 的 `saddhādeyyaṃ vinipāteti`、`issukinī`；第八、第九经 118–119 义注作「Sesaṃ sabbattha uttānameva」未另释，故无释义标准可依）
>
> 本层为本文（mūla），无父层。义注黑体 **saddhādeyyaṃ** / **vinipātetī** / **issukinī** 均引自本层，本文译法将约束义注译法，相关核对见 §830-24-52 与跨段一致性第 2、4 条。

## 跨段一致性

1. **nikkhittā**：地狱句译「被扛走后**扔下**」（§830-2-20、§830-53-66、§833-2-19、§833-52-65、§836-2-19、§836-45-58、§839-2-19、§839-45-58），天界句译「被扛走后**安放**」（§831-2-15、§831-51-67、§834-2-15、§834-44-60、§837-2-17、§837-45-61、§840-2-15、§840-43-58）。巴利两侧是同一个 `nikkhittā`，褒贬全靠后面的 `niraye` / `sagge` 承担；译文把词义本身分化了 → 建议统一为「安置」，对比交给「地狱／天界」自然呈现。依据：同词同译，且该句式在五集中高频复现，分化会在全书级扩散。
2. **saddhādeyyaṃ vinipāteti**：全 chunk 八处一律作「浪费／不浪费别人出于信心施与的东西」，与义注释义不合（见 §830-24-52），须八处同步改，不可只改一处。
3. **分段引语的闭引号**：§830-53-66、§833-52-65、§836-45-58、§839-45-58 的译文末尾都收了「”」，但这四句巴利原文**没有** `’’`（闭引号在 §831-51-67、§834-44-60、§837-45-61、§840-43-58 的 `’’ ti`）。结果同一部经的引语在中文里被切成两段独立引语。中文分段引语惯例是每段开头用「“」、只在最后一段收「”」 → 建议删掉这四句末的「”」。
4. **`… ca hoti` 系表并列项的译法不统一**：§833「心怀嫉妒／心怀吝啬」、§836「持有邪见／怀着邪思惟」、§837「持有正见／怀着正思惟」、§839「说邪语／行邪业」、§840「说正语／行正业」。同一句法位置用了三套结构。另 **义注**：`**issukinī**ti issāya samannāgatā`（「具备嫉妒」），用的正是本文句首 `samannāgatā` 一词，而本文把 `samannāgatā` 译作「具备」 → 建议 §833/§834 改为「具备嫉妒／不具备嫉妒」或至少与义注译法可对应，并把五支并列项统一成同一句式（如「具备嫉妒／持邪见／言语邪恶」）。
5. **dhammehi 译「品质」**：出现在全 chunk 每段首末句。「品质」在现代汉语里偏褒义，接「堕入地狱」读来别扭（「具备五种品质的比丘尼……必定堕入地狱」） → 建议改中性的「具备五种性质」或「具备五法」，善恶两侧同用一词。

## §830 句 88-830-24-52

- **问题**：取义（义注） — `saddhādeyyaṃ vinipāteti` 译作「浪费别人出于信心施与的东西」。**义注**：`Chaṭṭhe **saddhādeyyaṃ** **vinipātetī**ti parehi saddhāya dinnapiṇḍapātato aggaṃ aggahetvā parassa deti .`——义注把这一支定义为对信施之物的**错置、转手给别人**（就他人以信心所施的钵食，把上品转给他人），落点在「施物没有用在该用的地方」，不是「消耗、糟蹋」。译作「浪费」把行为误读成资源损耗，与义注的解释相悖，属必改。
- **建议**：改为「挪用别人出于信心施与的东西」或「错置别人出于信心施与的东西」；否定式作「不挪用……」。§831-19-50、§833-23-51、§834-19-43、§836-23-44、§837-21-44、§839-23-44、§840-19-42 同步改。
  附存疑（写在此处，不进译文）：义注 `aggaṃ aggahetvā` 可读为 `a-gahetvā`（不取上品）或 `aggaṃ gahetvā`（取上品），两读的落点都是「转给了别人」，故取「挪用／转给他人」不受此分歧影响；该分歧宜记入 `knowledge/known-issues.md`。
- **问题**：取义 — `appasādanīye ṭhāne pasādaṃ upadaṃseti` 译「对不值得信任的事表示信任」。`pasāda` 是净信、信服（对人或法生起的信心），译「信任」偏窄且偏世俗；`ṭhāne` 是场合、情况，译「事」过实。
- **建议**：「在不该生起净信的地方显出净信／在该生起净信的地方不显出净信」；§831-19-50 的两支同步改。

## §830 句 88-830-2-20

- **问题**：增译 — `yathābhataṃ nikkhittā evaṃ niraye` 的 `nikkhittā` 既是喻体也是结果（「如被带去安置在那里一般，就这样在地狱里」）；译文拆成「就像被扛走后扔下那样」＋「**必定**堕入地狱」，「必定」是原文所无的断定语气。
- **建议**：「就像被带去安置在那里一样，就这样落在地狱里」。此句式在 §830/831/833/834/836/837/839/840 共十六处复现，改则全改。

## §831 句 88-831-19-50

- **问题**：歧义 — `avaṇṇārahassa avaṇṇaṃ bhāsati` 译「贬斥不值得称赞的人」，中文读来易解成「本不该贬斥却贬斥」，恰与句意相反（这是善法一侧）。`avaṇṇāraha` 字面是「该受贬斥的」。
- **建议**：「该受贬斥的人」，即「查明深究后才贬斥该受贬斥的人」。§834-19-43、§837-21-44、§840-19-42 同处；§830-24-52、§833-23-51、§836-23-44、§839-23-44 的「称赞不值得称赞的人」可相应作「称赞该受贬斥的人」，使善恶两侧共用一个译名。

## §833 句 88-833-23-51

- **问题**：原文异读 — `saddhādeyyaṃ [ saddhādeyyañca ( syā .)]` 中括号是暹罗本异读。译文未把它带进正文，处理正确；此处仅作记录，异读不影响译义。
