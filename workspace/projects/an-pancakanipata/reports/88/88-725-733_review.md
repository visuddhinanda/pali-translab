# Review — 88:725-733（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，这些句子略过）

## 跨段一致性

- **经号格式**：§726 作「九十六、」、§728 作「九十七、」、§730 作「九十八、」，§732 却作「99.」 → **必改**：统一为「九十九、」。
- **yathāvimuttaṃ cittaṃ paccavekkhati**：§726、§728、§730 都译作「他观察心如何得到解脱」，三处的句法误读相同（详见 §726 句 88-726-75-78） → 三处要一并改，并统一为同一译法。
- **āsevanto / bhāvento / bahulīkaronto**：三经的区分点是这三个动词，分别译作「勤修 / 修习 / 多修习」，方向对。但「勤修」的「勤」在 nissaya 里没有依据（见 §726 句 88-726-2-20）。改动时，§726 句 79-97 的复述句要同步改。
- **复数标记**：§733 各句的受众分别译作「比丘们 / 比丘尼们 / 优婆塞们 / 优婆夷们」，唯独 puthujjanānaṃ 译作「凡夫」，没有加「们」。nissaya 作 `ပုထုဇ္ဇနာနံ= ပုထုဇဉ်ပုဂ္ဂိုလ်တို့အား`，`တို့` 表示复数 → 建议统一为「凡夫们」。

## §726 句 88-726-2-20

- **问题**：词义偏差。āsevanto 的 nissaya 是 `အာသေဝန္တော= မှီဝဲလသော်`，意思是亲近、依止、反复从事，没有「勤」的意思。「勤修」容易和精进类词语混淆，三经并列时也会让 āsevanto 与 bahulīkaronto 的界限变模糊。
- **建议**：改为「亲近修习入出息念」或「熟习入出息念」。§726 句 79-97 的复述句同步改。

## §726 句 88-726-24-35

- **问题**：程度副词译过了头。`သုသန္တောသော= ကောင်းစွာရောင့်ရဲနိုင်သည်`，意思是「能够很好地知足」。su- 表示「善、好」，不是「极为」。另外，`ဇီဝိတပရိက္ခာရေသု= …ပစ္စည်းလေးပါးတို့၌` 说明「生活资具」指四种资具，属格、处格关系译文处理得没有问题。
- **建议**：「对生活资具极为知足」改为「对生活资具善于知足」或「很能知足」。§728、§730 的同一句同步改。

## §726 句 88-726-75-78

- **问题**：句法误读，**必改**。nissaya 作 `ယထာဝိမုတ္တံ= သော။ စိတ္တံ= ကို။ ပစ္စဝေက္ခတိ= ဆင်ခြင်၏။`。yathāvimuttaṃ 带定语标记 `သော`，是修饰 cittaṃ 的形容词；cittaṃ 带宾格 `ကို`，是 paccavekkhati 的直接宾语。原句的意思是「省察那如其所解脱的心」，不是间接问句「心如何得到解脱」。现译把定语改成了疑问状语，结构译错了。paccavekkhati 的 nissaya 是 `ဆင်ခြင်`（思惟、省察），译作「观察」偏于泛泛。
- **建议**：改为「他省察那已如此解脱的心」或「他省察如其所解脱的心」。§728 句 69-72、§730 句 50-53 同步改。

## §730 句 88-730-46-49

- **问题**：译文补出了 nissaya 没有的义项。`ပသေနာသနော= အလွန်ဝေးကွာခြားအစွန်အဖျားကျသောအိပ်ရာနေရာကျောင်း…` 强调的是「极远、边地」的卧坐处（senāsana）。「僻静」是译文自己加的。
- **建议**：改为「住在林野，住在边远的卧坐处」，或保留「边远」、去掉「僻静」。此条为轻微问题，可酌情处理。

## §732 句 88-732-2-16

- **问题 1**：经号格式与前文不一致（见跨段一致性），**必改**。
- **问题 2**：词义收窄。`အာသယာ= (ရွှေဂျူစသော)နေရာဌာနမှ`，意思是「从（金洞等）住处」。āsaya 泛指栖身处，「洞穴」只是其中一例。
- **建议**：「99.」改为「九十九、」。āsayā 可译作「从栖身处」或「从巢穴」，§732 句 17-20 同步改。

## §732 句 88-732-97-109

- **问题**：格与句法正确，`ဟတ္ထိဿ= ဆင်အား` 为与格，`စေ ဒေတိ` 为让步条件句。需要注意 sakkaccaṃ 的两种解释：主释是 `ဂရုစိုက်၍`（用心、专注），异释是 `မလွဲချော်စေမူ၍`（不使失手）。在狮子扑击的语境里，「郑重地」稍嫌偏向礼敬。
- **建议**：为了和 §733 如来说法的 sakkacca 保持一致，可以保留「郑重」。如果想贴近这里的语境，可改为「专注地全力出手」，但两段要连动考虑，不要只改一边。此条非必改。

## §732 句 88-732-187-194

- **问题**：动词义偏差。nissaya 作 `မာ နဿ= မပျက်စီးစေသတည်း`，意思是「愿不坏失」，指已练成的东西不要丧失、荒废。「落了空」在现代汉语里指「没有结果、白费」，意思不同。yoggapatho 的主释是「所做的车行之道」，异释是「所发起的精进势头之道」。nissaya 脚注说明两种解释都指历练所成的惯性、功夫，所以译作「练就的本领」可以接受。
- **建议**：改为「不要让我练就的本领荒废」或「……退失」。

## §733 句 88-733-2-13

- **问题 1**：句法。nissaya 中 `အရဟတော= …သော` 与 `သမ္မာသမ္ဗုဒ္ဓဿ= …သော` 都是带 `သော` 的定语，修饰 `တထာဂတဿ= မြတ်စွာဘုရား၏`。也就是说，「阿罗汉、正等正觉」是如来的修饰语，不是同位语的补充说明。
- **问题 2**：风格。这里的「即」是文言虚词，属于 style.md 禁例表中的写法。
- **建议**：改为「比丘们，所谓‘狮子’，这是对阿罗汉、正等正觉的如来的称呼」。

## §733 句 88-733-93-117

- **问题**：误译，**必改**。nissaya 作 `အန္နဘာရနေသာဒါနမ္ပိ= သူတောင်းစားနှင့်ငှက်မုဆိုးတို့အားသော်မှလည်း`，意思是「乞丐与捕鸟人」。nissaya 括注还说明 annabhāra 指为口食所累、靠讨要为生的人。
  - 「乞食者」在佛典语境里很容易被理解为托钵的比丘（piṇḍapātika），与原义正好相反。
  - nesāda 在这里的 nissaya 是 `ငှက်မုဆိုး`（捕鸟人），「猎人」译得太宽。
- **建议**：改为「哪怕只是为乞丐和捕鸟人」。同句「凡夫」改为「凡夫们」（见跨段一致性）。
