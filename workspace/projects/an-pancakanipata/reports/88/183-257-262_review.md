# Review — 183:257-262（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层（义注 book 101:274-276）定稿译文 ✅／nissaya ❌（本次未注入，词级格位判断只能依原文与父层释义，格与句法一项无法独立核验）／本层为复注（ṭīkā），所引黑体词出自义注，下文「父层」即指义注。

## 被解释词与父层逐字核对

已逐条比对，以下黑体词与父层译文**完全一致**，通过：

- **ubhato sujāto** → 「父母双方出身都高贵」（父层 101-275-40-47）
- **mātito ca pitito cā** → 「从母亲方面和从父亲方面」（101-275-13-29）
- **saṃsuddhaggahaṇiko** → 「所出的母胎清净」、**saṃsuddhāya mātukucchiyā samannāgato** → 「他所出生的母胎是清净的」（101-275-48-53）
- **yāva sattamā pitāmahayugā** → 「上溯到第七代祖先为止」（101-275-68-79）
- **tato uddhaṃ … pitāmahaggahaṇeneva gahitā** → 「从那以上，所有的祖先都已经包含在‘祖父’这个说法里了」（101-275-92-98；内层引号由 “祖父” 改为 ‘祖父’ 属嵌套引号的正常处理，不算改动）
- **Akkhitto** → 「不曾被排斥」、**Anupakkuṭṭho** → 「不曾被辱骂」、**Jātivādena** → 「因为出身之说」（101-275-114/130/145）
- **Anavakkhitto** → 「不曾被贬低」（父层 101-275-114-129 内以「贬低」对 anavakkhitta，对应正确）
- **yo koci attano santakena vibhavena aḍḍho hotī**、**mahatā aparimāṇasaṅkhena dhanena samannāgato**、**pañcakāmaguṇavasenā**、**dhaññena ca paripuṇṇakoṭṭhāgāro**、**atha vā**、**tividhaṃ koṭṭhāgāraṃ**（101-276-2/12/25/32/48）
- **paṇḍiccena samannāgato** → 「具有通晓事理的智慧（paṇḍicca）」、**veyyattiyaṃ** → 「明辨能力」、**medhāvī** → 「机敏」、**ṭhānuppatti** → 「当场应机而生」、**vaḍḍhiatthe** → 「能带来增益的事」（101-276-107/112/117/127）

## 跨段一致性

- **yuga**：§258 同一句内先译「一代」后译「一对」（183-258-124-137），183-258-148-162 又作「一代」——本层的全部论证就是 yuga = dvanda（一对），译法必须统一。详见下文必改项。
- **mātukucchi**：§258 作「母腹部位」（183-258-87-94），紧接下一句作「母胎」（183-258-95-104，父层定译）→ 统一为「母胎」，依据：父层定稿与本层 95-104 行已用「母胎」。
- **byatta / byattabhāva**：父层定译「通达」（101-276-112-116），本层 183-261-26-30 作「明白」→ 统一为「通达」。
- **tenāha / āha 引述套语**：§258 全部作「所以说」，§260 则「所以说」（64-73）与「因此说」（41-54、109-128）混用 → 统一为「所以说」。
- **kosa / gahaṇī 的音译处理**：两词在本层与父层均保留巴利原形不译，前后一致 ✅；koṭṭhāgāra 一律「粮仓」✅；akkosa 一律「咒骂」、khepa/akkhitta 一律「排斥」✅。

## §258 句 183-258-124-137

- **问题**：术语译法内部自相矛盾（必改） — 本层对 pitāmahayuga 的分析是：`Pitūnaṃ pitaro pitāmahā`（父母双方的父母都叫 pitāmaha）→ `Tesaṃ yugo pitāmahayugo` → `pitāmahadvandā`，即 yuga = **一对**。父层取的是另一解（`Yuganti āyuppamāṇaṃ vuccati`，yuga = 一代/寿量），这是本层有意提出的不同分析。译文却把 `tesaṃ yugo pitāmahayugo` 译成「他们的一代就是祖父这一代」，再接「直到第七对祖父母为止」，读者看到的是同句内「一代」突然变成「一对」，本层的论证整个失效。
- **建议**：非黑体的 yuga 一律译「一对」并首次夹注原词：「他们的一对就是祖父母这一对（pitāmahayuga）；所以**“上溯到第七代祖先为止”**，这里的意思应当这样来理解：直到第七对祖父母为止。」黑体引文**保持**父层的「上溯到第七代祖先为止」不动——父层与本层取义不同，正是本层要说明的，不要为了「顺」而动黑体。建议 footnote 步在此加一条注，说明义注读 yuga 为「一代（寿量）」、复注读为「一对」。

## §258 句 183-258-148-162

- **问题**：同上（必改） — 「一代和一代合说成一代」照本层 ekasesa 的分析应是父系一对与母系一对合说为一对，译作「一代」后整句不可解。
- **建议**：「而这里“一对（yuga）”这个词应当按照同形留一的方式来理解，即“一对和一对合说成一对”。」

## §258 句 183-258-163-169

- **问题**：指称过窄（建议） — `dvinnaṃ` 承上文指「两者」（父系与母系各一对，或祖父与祖母两人），译「两个人」把它锁定成人数，与上句「第七对祖父母」的读法未必吻合。
- **建议**：改「每一处都把两者都包含进去了」。

## §258 句 183-258-87-94

- **问题**：术语不一致（建议） — `mātukucchippadeso` 译「母腹部位」，与下一句及父层定译「母胎」不统一。
- **建议**：「也就是母胎中被称为胎宫的那个部位」。

## §258 句 183-258-2-67

- **问题**：释义略有增饰（建议） — `ārohasampattipariyāyo` 是「身高具足的同义语」，译文作「身材高大匀称」，「匀称」为 pariṇāha 一侧的意思，原文无。
- **建议**：改「是指身材高大的意思」。另 `sujātatā paññāpeyya` 为使役「会显示出」，建议把「那就可能被理解成是由随便哪两方面而显出出身高贵」改为「那所显示的就可能只是由随便哪两方面而来的出身高贵」，更贴近「ettake vutte」的归谬语气。

## §258 句 183-258-188-198

- **问题**：措辞（建议） — `samatthitaṃ hoti` 是「得以成立／被证成」，「得到了支持」偏弱。
- **建议**：「圣典里“从母亲方面”这句话才得以成立」。

## §259 句 183-259-2-5

- **问题**：注解与被解释词同词重复，注失其用（必改） — 「**不曾被排斥**是说不曾遭到排斥」在汉语里完全同义，等于没注。本层 `appattakkhepo` 是把 akkhitta 拆解为「未曾招致 khepa（排斥）」，重点在「未落到那个地步」。
- **建议**：「**不曾被排斥**是说不曾招致排斥，即从未落到被人排斥的地步。」

## §259 句 183-259-6-13

- **问题**：同类重复（建议） — 「**不曾被贬低**是说……不曾被贬低、不曾被弃置」中前半仍是同词复述；「不曾被贬低」是父层定译，不能改，所以要在释义侧区分。
- **建议**：「**不曾被贬低**是说，在遇到争论等场合时不曾被人贬斥、不曾被人推开弃置。」

## §259 句 183-259-14-26

- **问题**：引文与父层不逐字（必改，标点） — 父层 101-275-141-144 作「那是就什么事由说的呢？」，本层引文漏掉句末「？」。
- **建议**：改为 **“那是就什么事由说的呢？”**。

## §259 句 183-259-27-44

- **问题**：措辞偏离原词（建议） — `yonidosa` 是「所出之胎的过失」，与紧接的「所出的母胎清净」正相呼应；译「出身方面的过失」把这条呼应冲淡了，且易与 jātivāda（出身之说）混。
- **建议**：「表明了刹帝利没有所出之胎方面的过失，因为其中称说了他所出的母胎清净」。

## §260 句 183-260-2-24

- **问题**：漏译 sampannatā（建议） — `vibhavasampannatā` 是「家产充足」，译「拥有家产」丢了「具足／充足」，而下一句「取的是它最高的程度」正是靠这个程度义推进的。
- **建议**：「所谓富有，就是家产充足」。

## §260 句 183-260-109-128

- **问题**：父子层原文异读，无法逐字对齐（原文疑问，**译文不必改**） — 本层所引作 `catubbidho koso hatthī assā rathā **pattī**`（步兵），父层 book 101:276-48-62 的原文作 `… rathā **raṭṭhan**ti`，定稿译「象、马、车、**国土**」。本层译文忠于本层原文译「步兵」，是对的：本层上句明确把 koso 释为 `caturaṅginī senā`（四支军队），四支军的常规构成正是象、马、车、步，`raṭṭha` 在此与「军队」说不合，疑为父层原文讹字（或两系传本不同）。
- **建议**：保留「步兵」。请 harmonize 步**不要**依父层把它改成「国土」——这不是译法不统一，是底本不同。建议记入 `knowledge/known-issues.md`「OCR / 原文问题」一节，并由 footnote 步加注：「义注此处作 raṭṭha（国土），复注所据本作 pattī（步兵）；复注以四支军释 kosa，与 pattī 合。」父层译文是否复议，另案处理，本次不动。
- **附（风格）**：`tikkhabhāvaparihāraṃ katvā` 译「保全了国王的锐势」略偏文雅，可作「也同样护持着国王的锋锐威势」；上句 `paṭicchado` 的「套子」可明确为「刀鞘」。

## §261 句 183-261-26-30

- **问题**：被解释词与父层不一致（必改） — `byattabhāvo` 的 byatta 就是父层定译「**通达**」（101-276-112-116），本层译「明白」，读者看不出这句注的是「通达」那个词，父子层对应断了。
- **建议**：「在各种“这件事该这样做”的事务上的熟练、通达，就是**明辨能力**。」

## §261 句 183-261-31-40

- **问题**：搭配不自然（建议） — 「能伤害、摧毁迷乱」中「伤害迷乱」不成汉语搭配（`hiṃsati` 在此是「击破」）。
- **建议**：「能击破、摧毁迷乱，所以叫做 medhā」。
