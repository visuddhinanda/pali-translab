# Review — 88:230-260（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **ṭhāna**：§231 译“五种利益”，§250/§251 译“五点”，§255 译“这些”。nissaya 两处都作 `ဌာနာနိ= အကြောင်းတရားတို့ / အကြောင်းတို့`（缘由、事项），没有“利益”的意思。§231 译成“利益”，还会和 §237 的 *ānisaṃsā*“利益”撞词。→ 建议统一为“五事”或“五点”，§231 不用“利益”。
- **Katamāni / Katame pañca**：§231 译“是哪五种呢？”，§237、§250 译“哪五种呢？”。§250 的正文说“五点”，后面却问“哪五种”，同一经内前后不对应。→ 统一句式，并和 ṭhāna 的译法挂钩，例如“是哪五点呢？”。
- **santo sappurisā**：§237 译“有德的善士”，§256 译“寂静的善士”。两处巴利完全相同，译法不同。nissaya §237 作 `သန္တော= ကိလေသာတို့ကိုငြိမ်းစေ…`（使烦恼止息的）。→ 建议两处统一为“寂静的善士”。
- **saddha**：§237–§238 都译“有信心的（人／良家子）”，§260 却译“有信（saddhā）”。措辞不一致；巴利夹注放在末次出现而不是首次；夹注的词形（名词 saddhā）也和原文的形容词 saddho 不符。→ §260 改为“有信心”，删去夹注。如需夹注，应放在 §237 首次出现处。
- **sīlasampanna / sīlena sampanno**：§243 译“戒行清净”，§260 译“具足戒行”。nissaya 两处都是 `သီလနှင့်ပြည့်စုံ`（与戒具足）。→ 统一为“具足戒行”。
- **“亲近”对应两个不同的巴利词**：§237 *upasaṅkamanti*（nissaya `ကြွရောက်လာ`，前来、走访）和 §241、§246 *sevanti*（nissaya `မှီခို`，依附、依止）都译成“亲近”。→ §237 建议改为“前去拜访”，*sevanti* 保留一个固定译法。
- **dhamma**：§237、§247 译“佛法”，§248 译“那法”。→ 统一。
- **经题格式**：§230 作“九、饮食经”，§236 作“第八　信经”（全角空格），§249 作“九、子经”。→ 统一为“X、XX经”。
- **经号格式**：§231 作“三七、”，§237 作“38　”（阿拉伯数字加全角空格），§250 作“三九、”。→ 统一为汉字数字加顿号。
- **经末序号**：§235 作“（第七）”，§248 作“第八。”，§260 作“第九经。”。→ 三处统一一种格式。
- **偈颂引号**：§233 句末加了闭引号“”。”，但同样不是最后一节的 §240、§242、§244、§246 都没有加，体例不一。巴利 §233 也没有 ’’。→ 删去 §233 的闭引号。

## §231 句 88-231-2-19

- **问题**：词义 — *pañca ṭhānāni* 的 nissaya 是 `ငါးမျိုးကုန်သော အကြောင်းတရားတို့ကို`（五种事项），没有“利益”义。
- **建议**：改为“给予受施的人五种东西／五事”。同段 88-231-99-113 的“这五种利益”一并改。

## §233 句 88-233-2-9

- **问题**：句法（指代） — nissaya 作 `သော= ထိုအသက်အလှူစသော ငါးမျိုးကို ပေးလှူသောပညာရှိသည်`，可见 *so* 指“施予寿命等五者的智者”，*dhīro*（§232）和 *medhāvī* 是同一施主。现译文先说“贤者给予……”，再说“有智慧的人给予安乐，他自己也获得安乐”，读起来像两个人，“他”也只指施予安乐的人。另有引号问题，见上节。
- **建议**：例如“这位明智的人也给予安乐，他（施予这五者的人）自己就获得安乐”，让 *so* 承接全部五施。

## §235 句 88-235-2-11

- **问题**：词义 — `ယသဝါ= များသောအခြံအရံရှိသည်`，意思是“有众多随从／眷属”，不是“有名望”。
- **建议**：改为“……都长寿，而且随从众多”。

## §237 句 88-237-20-37

- **问题**：词义 — *santo* 的 nissaya 是 `ကိလေသာတို့ကိုငြိမ်းစေ…`（使烦恼止息的），译成“有德的”不合。*tathā* 的 nissaya 是 `ထိုသဒ္ဓါတရားရှိသောသူနှင့်…အလားတူပင်`（与对有信者一样地），“不是那样扶助”的语义不够清楚。
- **建议**：改为“世间那些寂静的善士，首先关怀的是有信心的人，不会像这样去关怀没有信心的人”。后面 38-46、47-55、56-65 三句的“而不是那样……”照此统一。

## §237 句 88-237-38-46

- **问题**：词义 — *upasaṅkamanti* 的 nissaya 是 `ကြွရောက်လာတော်မူ`（前来、走访），“亲近”和 *sevanti* 撞词。
- **建议**：改为“首先前去拜访的是有信心的人”。

## §238 句 88-238-2-15

- **问题**：词义 — *subhūmiyaṃ* 的 nissaya 是 `ညီညာသောမြေအပြင်၌`（在平整的地面上），不是“土地肥沃”。*catumahāpathe* 的 nissaya 是 `လေးခုသောလမ်းမအဆုံ၌`（四条大路交会处），“四通八达”属于引申。*paṭisaraṇa* 的 nissaya 是 `ခိုကိုးရာ`（栖身、依靠处），“归依处”带三归依的宗教色彩，用在鸟身上不妥。
- **建议**：改为“就像在四条大路交会处一块平整的地面上，有一棵大榕树，成为四方鸟儿的栖身依靠之处”。88-238-16-36 的 *paṭisaraṇa*（nissaya `အားကိုးအားထားရာ`）相应改为“依靠”。

## §240 句 88-240-2-8

- **问题**：风格 — “栖息之处”中的“之”是文言虚词。*mūlavā* 的 nissaya 是 `ခိုင်မြဲသောအမြစ်ရှိသော`（根牢固的），“根系发达”偏离原意。
- **建议**：改为“根基牢固、果实累累，成为鸟儿栖息的地方”。

## §241 句 88-241-2-10

- **问题**：风格 — “聚集之处”中的“之”是文言虚词。*āyatane* 的 nissaya 是 `ငှက်အပေါင်းတို့၏ပေါင်းဆုံစုဝေးရာဌာန၌`（鸟群会聚的地方），译文没有点出这是鸟群会聚之地。
- **建议**：改为“在那令人愉悦、鸟群会聚的地方，鸟儿们依附着它”。

## §242 句 88-242-2-15

- **问题**：增译 — “只有……才……”带出排他义。nissaya 只说 `ဆာယတ္ထိကာ…ဆာယံ ယန္တိ`（想要荫凉的鸟去荫凉处）、`ဖလတ္တာ…ဖလဘောဇိနော`（想要果实的鸟吃果实），没有限定义。
- **建议**：改为“想要荫凉的鸟来到荫凉下，想要果实的鸟来吃果实”。

## §243 句 88-243-2-9

- **问题**：词义 — *sīlasampannaṃ* 的 nissaya 是 `သီလနှင့်ပြည့်စုံသော`（与戒具足），没有“清净”义。
- **建议**：改为“具足戒行、有信心的人”。

## §244 句 88-244-2-8

- **问题 1**：句法 — 从 nissaya 的 `…ကို`（宾格）看，§243–§245 中的 *purisapuggalaṃ / tādisaṃ naraṃ* 及其修饰语都是 §246 *sevanti* 的宾语。本句以“。”收尾，把宾语链截断了。
- **问题 2**：词义 — *sorataṃ* 的 nissaya 是 `…သုစရိတ်သီလ၌မွေ့လျော်သော`（乐于清净的善行与戒），不是“性情柔和”。*sakhilaṃ* 的 nissaya 是 `စကားအားဖြင့်သိမ်မွေ့သော`（言语柔和），“和悦可亲”没有点出言语。
- **建议**：改为“举止谦和，不因忿怒与我慢而刚硬，乐于善行，言语和婉，性情柔软，”，句末用逗号。

## §248 句 88-248-2-12

- **问题**：句法 — nissaya 作 `အနာသဝေါ…(ဟုတွာ= ဖြစ်၍) ပရိနိဗ္ဗာတိ`（成为无漏者之后般涅槃）。“就已无漏”有时态偏差，句子也不顺。*yaṃ dhammaṃ* 的 nissaya 是 `ယင်းပုဂ္ဂိုလ်တို့ဟောကြားအပ်သောတရားကို`（他们所说的法），“那法”指代不明。
- **建议**：改为“他在此世了知了他们所说的法，成为无漏者，证入涅槃”。

## §250 句 88-250-41-48

- **问题**：增译与冗余 — *anuppadassati* 的 nissaya 是 `ပေးလတ္တံ့`（将给予），没有“持续”义。*petānaṃ kālaṅkatānaṃ* 是两个同指的与格，现译文“在我们死后……已故的我们”重复了一遍。
- **建议**：改为“或者，他会为去世的我们作布施，把功德回向给我们”。

## §251 句 88-251-2-16

- **问题**：补出成分 — 依 nissaya（§250 末 `ပဏ္ဍိတာ= ပညာရှိသောမိဘတို့သည်`），*paṇḍitā* 指“明智的父母”。现译“有智慧的人”泛化了。
- **建议**：改为“明智的父母希望有儿子，是着眼于这五点”。§255 同改。

## §253 句 88-253-2-10

- **问题**：时态 — *tiṭṭhe* 的 nissaya 是 `တည်မြဲလတ္တံ့`（将会长存），并注明是时态互换（作将来义），不是祈愿。译成“愿家系长久维持”错了。*paṭipajjati* 的 nissaya 同样作将来义 `လတ္တံ့`。
- **建议**：改为“家系会长久维持，他会继承家业”，与 §250 的“我们的家系会长久维持”保持一致。

## §254 句 88-254-2-10

- **问题**：增译与冗余 — 和 88-250-41-48 相同。本句巴利只有 *petānaṃ*（nissaya `တမလွန်ဘဝသို့ပြောင်းသွားသောငါတို့အား`），译文却写了“在我们死后”和“已故的我们”，还加了“持续”。
- **建议**：改为“或者，他会为去世的我们作布施，把功德回向给我们”。

## §255 句 88-255-2-10

- **问题**：一致性 — *ṭhānāni* 前后不统一，*paṇḍitā* 的问题同 §251。nissaya `ဤအကြောင်းငါးမျိုးတို့ကို` 意为“这五点”。
- **建议**：改为“明智的父母希望有儿子，正是着眼于这五点”。

## §256 句 88-256-2-8

- **问题**：一致性 — *santo sappurisā* 和 §237 的译法不同，见“跨段一致性”一节。
- **建议**：和 §237 统一为“寂静的善士”。

## §260 句 88-260-2-12

- **问题 1**：词义 — *pasaṃsiyo* 是动词适合分词，nissaya 作 `ချီးမွမ်းထိုက်သည်`（值得称赞），不是“受人称赞”。
- **问题 2**：词形与一致性 — 见上文“有信（saddhā）”一条。
- **建议**：改为“有信心、具足戒行，这样的儿子值得称赞”。

## OCR／原文疑问

- §230 经题作“9. Bhojanasuttaṃ”，但 §235 经末是 *sattamaṃ*（第七）。§236 “8.”、§249 “9.” 与 *aṭṭhamaṃ*、*navamaṃ* 相符，说明 §230 的经号疑为“7.”之讹。译文“九、饮食经”照录了这个可疑编号，和经末“（第七）”自相矛盾，需定案。
