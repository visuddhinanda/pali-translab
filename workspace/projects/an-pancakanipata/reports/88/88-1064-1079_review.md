# Review — 88:1064-1079（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **dukkathā / sukathā**：全 chunk 统一译「不好谈 / 好谈」，经题译「难谈经」。nissaya 作主格名词述语：`ဒုက္ကထာ= မကောင်းသောစကားသည်`（不好的话），`သုကထာ= ကောင်းသောစကားသည်`（好的话）。它说的是话本身不当或得当，不是「难以开口」。「不好谈」在现代汉语里偏「难谈」，与词义有偏差。
  - 建议全 chunk 统一改为「是不恰当的谈话 / 是恰当的谈话」（或「不好的谈话 / 好的谈话」）。
  - 经题随之改为「不当谈话经」一类。
  - 涉及 §1065–§1076 全部含 dukkathā / sukathā 的句子，须一次改齐。
- **puggale puggalaṃ upanidhāya**：§1065、§1070 用「跟五种人谈话」，§1070 末句与 §1076 末句用「对这五种人谈话」，介词前后不一，建议统一为「对」。另外词法问题见 §1065 句 88-1065-2-31，§1070、§1071、§1076 三处须同步改。
- **dussīla**：§1065–§1067 译「不持戒」，§1078 译「破戒」。nissaya 两处都是 `သီလမရှိ`（没有戒），建议统一为「不持戒」。
- **appassuta**：§1065、§1068 译「少闻」，§1078 译「寡闻」。建议统一为「少闻」。
- **duppañña / dupañña**：§1065、§1070 译「缺乏智慧」，§1078 译「智慧低劣」。nissaya `ပညာမရှိ`（没有智慧），建议统一为「缺乏智慧」。
- **paññavant**：§1071、§1076 译「有智慧」，§1079 译「具足智慧」。建议统一为「有智慧」。
- **sārajja / visārada**：§1077 经题与 §1078 译「怯弱」，§1079 译「无所怯惧」，同一组对立概念用了两个词根，建议统一为「怯惧」，理由见 §1078 句 88-1078-2-25。

## §1065 句 88-1065-2-31

- **问题**：词法误读，涉及 puggalaṃ 的重叠义与 upanidhāya。
  - nissaya 把 puggalaṃ 读作重叠形：`ပုဂ္ဂလံ ပုဂ္ဂလံ= ပုဂ္ဂိုလ်တိုင်း ပုဂ္ဂိုလ်တိုင်းကို`（每一个人，宾格）。它还附注此处应作重叠读法 puggalaṃ puggalaṃ，即「各个人」，不是「一个人对另一个人」。
  - `ဥပနိဓာယ= ထောက်ဆ၍`（依据、衡量），异释 `ဝါ= မျက်မြင်ထောက်ရှုသက်သေပြု၍`（当面对照作为凭据）。
  - 译文「拿一个人跟另一个人相比」把它译成两人之间的比较，与 nissaya 不合。
  - `ပုဂ္ဂလာနံ= ပုဂ္ဂိုလ်တို့အတွက်`（为、对于这些人），`ကထာ= စကားသည်`（话，主格）。
- **建议**：「比丘们，按各人的情况来衡量，对五种人来说，（某些）谈话是不恰当的。」§1070 末句、§1071 首句、§1076 末句按同一结构改。

## §1065 句 88-1065-35-41（同型：88-1065-42-45 / 46-49 / 50-64 / 65-68）

- **问题**：dukkathā 词义偏差，见跨段一致性一节。格关系本身无误：`အဿဒ္ဓဿ= …အတွက်`（对于），`သဒ္ဓါကထာ= …စကားသည်`（主格）。
- **建议**：改为「对没有信的人谈信，是不恰当的谈话」。其余四句同改。

## §1065 句 88-1065-50-64

- **问题**：可留意的取义。`စာဂကထာ= စွန့်ကြဲပေးကမ်းလှူဒါန်းမှုနှင့်စပ်သောစကား`，含「舍弃、施与」之义，译「布施」可以接受。
- **建议**：维持「布施」。如果术语表另定 cāga 为「舍」，则全 chunk 同改。

## §1066 句 88-1066-13-27（同型：§1067–§1070 的 13–27/28 句；否定式 §1072–§1076 的 13–31/32 句）

- **问题**：四个动词的取义与 nissaya 有出入。
  - `အဘိသဇ္ဇတိ= ဒေါသဖြင့်ငြိတွယ်၏`：因瞋而纠缠不放，补出「像荆棘一样钩挂」。译「起反感」偏轻，缺少「纠缠、黏着」的意思。
  - `ဗျာပဇ္ဇတိ= ဖောက်ပြန်ခြင်းသို့ရောက်၏`：陷入变异、心态变坏。译「心怀恶意」大体可以接受。
  - `ပတိတ္ထီယတိ= ဒေါသဖြင့်ကြမ်းတမ်းခက်ထန်၏`：因瞋而粗暴强硬。译「顽固抵触」偏离较大，必改。
  - `ကောပ= အားနည်းသောဒေါသ`（弱的瞋）、`ဒေါသ= အားကြီးသောဒေါသ`（强的瞋）：译「忿怒、瞋恨」，轻重次序基本对应。
  - `အပ္ပစ္စယ= မနှစ်သက်မှုဒေါမနဿ`（不喜悦、忧恼）：译「不满」略偏，「不悦」更贴切。
- **建议**：「……就会恼怒纠缠、发火、心态变坏、变得粗暴强硬，表现出忿怒、瞋恨和不悦。」否定式各句同步改为「不恼怒纠缠……也不表现出忿怒、瞋恨和不悦」，五组正反十句须一致。

## §1070 句 88-1070-53-65

- **问题**：nissaya 本身有疑点。该行 nissaya 作 `သုကထာ= ကောင်းသောစကားသည်`（好的话），但 pali 是 dukkathā，疑似 nissaya 错配了 §1076 的对应句。译文按 pali 译作否定，方向正确。其余问题同 88-1065-2-31（puggalaṃ puggalaṃ / upanidhāya）。
- **建议**：按 pali 维持否定义，结构按 88-1065-2-31 的建议改。nissaya 这一处错配记入报告备查。

## §1071 句 88-1071-18-24（同型：25-28 / 29-32 / 33-36 / 37-40）

- **问题**：sukathā 词义偏差，见跨段一致性一节。另外 `စာဂဝတော= စွန့်ကြဲပေးကမ်းလှူဒါန်းမှုရှိသောသူ`（具有施舍的人），译「乐于布施的人」可以接受。
- **建议**：改为「……是恰当的谈话」。

## §1078 句 88-1078-2-25

- **问题**：取义偏差。`သာရဇ္ဇံ= ကြောက်ရွံ့ခြင်းသို့`（进入恐惧），补出「不离恐惧、心中苦恼的忧」。核心义是「畏惧」，不是「软弱」，译「怯弱」偏离。`ဩက္ကန္တော= သက်ရောက်သည်`（落入），「陷入」正确。
- **建议**：「……的比丘会陷入怯惧。」§1078 末句与经题「怯弱经」同改为「怯惧」，与 §1079「无所怯惧」对应。

## §1078 句 88-1078-29-48

- **问题**：术语前后不一（破戒 / 寡闻 / 智慧低劣），见跨段一致性一节。nissaya：`ဒုဿီလော= သီလမရှိသည်`、`အပ္ပဿုတော= နည်းသောပရိယတ္တိဓမ္မသုတရှိသည်`、`ကုသီတော= ပျင်းရိသည်`（懈怠），「懈怠」正确。
- **建议**：「比丘们，有的比丘没有信，不持戒，少闻，懈怠，缺乏智慧。」

## §1079 句 88-1079-18-37

- **问题**：「具足智慧」与 §1071、§1076 的「有智慧」不一致。
- **建议**：改为「有智慧」。
