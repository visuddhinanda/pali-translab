# Review — 88:521-552（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性
- **经号写法**：§522「五九」、§524「六〇」、§531「六一」、§533「六二」、§535「六三」、§551「六七」，但 §541 写「六十四」、§547「六十五」、§549「六十六」。→ 统一为「六四」「六五」「六六」。依据：本 chunk 多数用这种写法。
- **经题序数位置**：§521「第一篇年长出家经」、§523「第二篇年长出家经」、§540「第二增长经」、§550「第一神足经」，而 §530「想经第一」、§532「想经第二」、§534「增长经第一」。→ 全部统一为「第一○○经」式，即「第一想经」「第二想经」「第一增长经」。
- **经末标记**：§522「第九篇经」、§524「第十篇经」，其余各处是「第一经」「第二经」…「第七经」。→ 统一为「第九经」「第十经」。
- **dhamma（dhammehi samannāgato）**：§522、§524 译「品质」，§547、§549、§551、§552 译「法」。→ 建议统一为「法」。
- **bahulīkata / bahulīkaroti**：§531、§533 译「反复修习」，§551、§552 译「多所修习」。nissaya 两处释义相同（ကြိမ်ဖန်များစွာအလေ့အလာပြု，意为一再反复地串习）。→ 统一为「反复修习」。「多所」也带文言色彩。
- **samādhi**：§547 译「定（具足）」，§552 译「三摩地」（欲三摩地、精进三摩地…）。→ 统一为「定」（欲定、精进定、心定、观定）。这也是神足的传统译法。
- **suta / cāga / paññā**：§535、§537 译「多闻、布施、智慧」，§541、§543 译「闻、舍、慧」。两经是成对经，句式全同。→ 统一为「多闻、布施、智慧」。nissaya：စာဂေန= စွန့်ကြဲပေးကမ်းလှူဒါန်းမှုကုသိုလ်စေတနာ（舍施布施的善思），译「布施」更贴切。
- **sāra / varādāyī**：§535、§539 译「精华」「最上之物」，§541、§545 译「精髓」「这身体中最好的」。→ 统一用词（见 §535 条）。
- **Katamāhi pañcahi**：§535 译「以哪五种呢？」，§541 译「是哪五种呢？」。→ 统一。
- **§535 与 §541 同句异译**：§535「就以圣的增长而增长」，§541「以圣的增长而增长」，后者少了「就」。→ 统一。
- **§536 与 §542 同句异译**：§536「以信和戒而增长」，§542「在信与戒上增长」。→ 统一句式。
- **idheva（§539 / §545）**：§539 译「就在这里」，§545 译「就在这一生中」。→ 统一为「就在今生」（依据见 §539 条）。
- **vinayadharo（§522 / §524）**：两处都译「持守戒律」，需一并改正（见 §522 条）。
- **anabhiratasaññā（§531 / §533）**：两处都译「厌离想」，需一并改正（见 §531 条）。

## §522 句 88-522-20-39
- **问题**：误译 — vinayadharo 的 nissaya 是 ဝိနည်းကိုဆောင်သော，意为「承持律藏的」。这里指通晓、受持律藏的持律者，和前面的 bahussuto（受持经教）、dhammakathiko（能说法）同属学识一类。译「持守戒律」把它读成了守戒，意思偏了。
- **建议**：改为「通晓戒律（持律）的稀有难得」或「持律者稀有难得」。§524 同句一并改。
- **问题**：取义偏 — nipuṇo 的 nissaya 是 သိမ်မွေ့သောအကြောင်းအရာကိုသိသော，意为「能了知微细道理的」。「心思细密」偏向性格描写，没有译出「通达微细义理」。
- **建议**：改为「能通达微细义理的年长出家者稀有难得」。
- **问题**：词义 — ākappasampanno 的 nissaya 是 ရဟန်းတို့၏အမူအရာအသွင်အပြင်နှင့်ပြည့်စုံသော，意为「具足比丘的举止仪容」。译文作「沙门威仪」，本句语境说的是出家比丘。
- **建议**：改为「举止威仪合乎比丘身份的」，或至少把「沙门」换成「比丘」。

## §524 句 88-524-20-39
- **问题**：误译 — vinayadharo「持守戒律」，同 §522。
- **建议**：同 §522 改为「通晓戒律（持律）的」。

## §525 句 88-525-2-4
- **问题**：术语 — nīvaraṇa 的传统汉译是「盖」（五盖）。译「障碍品」和 §527 摄颂的 āvaraṇa「障碍」撞成同一个词，两个巴利词的区分就看不出来了。
- **建议**：改为「盖品，第一」。

## §531 句 88-531-26-72
- **问题**：取义偏 — anabhiratasaññā 的 nissaya 是 မမွေ့လျော်ခြင်းသဘောအားဖြင့်ရှုမှတ်သောသညာ，意为「以不喜乐的方式观察的想」；sabbaloke 是 (ကာမရူပအရူပဓာတ်သုံးပါးဟူသော)အားလုံးသောလောက၌，即三界一切世间。「厌离」通常对应 nibbidā，与「不乐」不是同一个词。
- **建议**：改为「对一切世间的不乐想」。§533 同句一并改。

## §535 句 88-535-2-25
- **问题**：词法、风格 — kāyassa 的 nissaya 是 ခန္ဓာကိုယ်၏，属格，意为「身体的」，同时修饰 sāra 和 vara。varādāyī 的 nissaya 是 မွန်မြတ်သောတရားကိုယူ，意为「取得殊胜之法」。「最上之物」一来没有译出「法」，二来用了文言虚词「之」，属必改项。
- **建议**：改为「而且他取得身体的精华，也取得身体中殊胜的法」。§535-29-66 同句一并改，§541 两处按同一译法统一。

## §535 句 88-535-29-66
- **问题**：风格 — 句末「取得最上之物」用了文言虚词「之」，必改。
- **建议**：同上条。

## §537 句 88-537-2-6
- **问题**：句法误读 — nissaya 把 cāgena 释为 စွန့်ကြဲလှူဒါန်းမှုလည်းဖြစ်သော（也是布施的），把 sutena 释为 ပရိယတ္တိဓမ္မသုတလည်းဖြစ်သော（也是多闻的），再把 ubhayaṃ 读作具格 ubhayena = နှစ်မျိုးစုံဖြင့်（以两者）。可见 ubhayaṃ 总括的是「布施、多闻」这两项。译文「前后这两类都增长」理解成前后两行，与 nissaya 不合。
- **建议**：改为「并以智慧、以布施和多闻这两者而增长；」。§543 同句一并改。

## §538 句 88-538-2-6
- **问题**：句法 — nissaya 把 tādiso 释为 ထိုသို့သဘောရှိသော，vicakkhaṇo 释为 စူးစမ်းဆင်ခြင်မြော်မြင်တတ်သော，两者都是修饰语（သော）。主语是 so sappuriso = ထိုအရိယာသူတော်ကောင်းသည်（§539 行），谓语在下一句 ādīyati。译文加了「是」，成了判断句，主谓结构断开了。
- **建议**：改为同位修饰：「这样有明察力的善人，」，下接 §539。

## §539 句 88-539-2-8
- **问题**：词法 — idheva 的 nissaya 是 ဤပစ္စုပ္ပန်ဘဝ၌ပင်，意为「就在今生」。「就在这里」所指不明。
- **建议**：改为「就在今生取得自己的精华。」§545 统一为「就在今生取得自己的精华」，并把「为自己」改成「自己的」，因为 attano 是属格，nissaya 作 ၏。

## §541 句 88-541-2-26
- **问题**：经号「六十四」与 chunk 其余写法不一。sāra、vara 的译法与 §535 不一（见跨段一致性）。「这身体中最好的」偏口语，也没有译出 nissaya 的「殊胜之法」。
- **建议**：改为「六四、“比丘们，依这五种增长而增长的圣女弟子，就以圣的增长而增长，而且她取得身体的精华，也取得身体中殊胜的法。」末句 §541-30-67 同改，并按 §535 统一 suta、cāga、paññā 的译法。

## §551 句 88-551-2-60
- **问题**：取义 — nissaya 把 upādisese 释为 ဥပါဒါန်အကြွင်းအကျန်，即「执取的残余」，夹注明言 upādi = upādāna。「余依」容易和有余依涅槃（指残余五蕴）混淆。aññā 的 nissaya 是 အရဟတ္တဖိုလ်（阿罗汉果），「究竟智」可以保留，但「现法」对一般读者不够明白。nissaya 释 diṭṭheva dhamme 为 ယခုမျက်မှောက်ဘဝ၌ပင်（就在当下这一生）。
- **建议**：改为「…或是就在今生得到究竟智（阿罗汉果），或是若还有执取的残余，就成为不还者。」「多所修习」改为「反复修习」。§552-37-75 同改。

## §552 句 88-552-7-36
- **问题**：术语一致 — 「三摩地」与 §547 的「定」不一。
- **建议**：改为「修习具足欲定与勤行的神足，修习精进定……略……心定……具足观定与勤行的神足，并修习第五项——极度的精进（ussoḷhi）。」nissaya：ဥသောဠှိ ဧဝ= အလွန်အကဲအားထုတ်သောဝီရိယကိုပင်（正是格外努力的精进）。「增上精进」可以保留，但与「增上」类术语容易混淆，可考虑改用「极度的精进」。
