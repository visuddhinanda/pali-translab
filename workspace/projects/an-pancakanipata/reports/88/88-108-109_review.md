# Review — 88:108-109（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 未注入 nissaya，词级格位核对无法进行，以下所有词法判断仅凭原文与义注）／义注 ✅（101:51-52 *Vimuttāyatanasuttavaṇṇanā*）

## 总体判断

语体合格——通篇现代书面汉语，未见文言腔或半文半白，无工作标记。**主要问题集中在释义层：义注对本经四个关键词（vimuttāyatana / samādhinimitta / kāya / dhamma-paṭisaṃvedī）都给了明确定义，而译文有四处与义注相悖**，属必改项，不是风格问题。

## 跨段一致性

- **vimuttāyatana**：§108 译「解脱的处所」，§109 同译「解脱的处所」——译法本身前后一致，但与义注相悖（见下 必改 1），两处须一并改。
- **dhamma**：§108-2-46 译「佛法」，§108-59-83 译「那个法」「法义」，§109 无。同一词在一个 chunk 内从「佛法」漂移到「法义」，且后者按义注应指「圣典文句」——须按义注分别定译（见下 必改 4）。
- **appamattassa ātāpino pahitattassa viharato** 整串在 §108-106-137 与 §109-2-36 译法逐字相同（「不放逸、精勤努力、全心投入地安住其中」），一致 ✅。
- **suggahita / sumanasikata / sūpadhārita / suppaṭividdha** 四连在 §108-47-58 与 §108-59-83 两次出现，译法一致（把握／注意／受持／透彻了解）✅，但受 必改 2 影响需同步调整。
- 连续引语标点处理正确：§108 开引号不闭、§109 闭合 ✅。

## 必改项（与义注相悖）

### §108 句 88-108-106-137、§109 句 88-109-2-36 — vimuttāyatana
- **问题**：义注释义错 — **义注**：`**vimuttāyatanānī**ti vimuccanakāraṇāni`（解脱的**原因**）；又 `**Yatthā**ti yesu vimuttāyatanesu`（yattha 指「在这些解脱因之中」）。译文「解脱的**处所**」是把 -āyatana 当处所义，正与义注给的取义相反。义注末句 `pañcapi vimuttāyatanāni arahattaṃ pāpetvā kathitāni`（五种解脱因都是就导向阿罗汉果而说的）也印证它说的是致解脱之因。
- **建议**：改为「解脱之因」或「导致解脱的因由」，§108「第五种解脱之因」、§109「这五种解脱之因」。后接的 `yattha…viharato` 相应调整为「比丘在其中不放逸、精勤努力、全心投入地安住时」——「安住其中」目前勉强可通，但前句一旦改为「因」，须改成「在其中（修习）时」一类说法，不要留「安住处所」的暗示。首次出现按 `style.md` 夹注巴利原词：解脱之因（vimuttāyatana）。

### §108 句 88-108-47-58、88-108-59-83 — samādhinimitta
- **问题**：误译（句法误读）— **义注**：`**samādhinimittan**ti aṭṭhatiṃsāya ārammaṇesu aññataro samādhiyeva samādhinimittaṃ`——三十八所缘中任一所缘上所得的**定本身**就是 samādhinimitta。译文「某一个定的**所缘**」把定与所缘的关系颠倒了：定相不是定的所缘，而是以某一所缘修得的定。
- **建议**：改为「某一种定相」，首次出现夹注并可加段后小字注说明义注的界定：「定相（samādhinimitta）——即在三十八种所缘之一上所得的定本身」。相应地「他对某一个定的所缘已经很好地把握」→「他对某一种定相已经善加把握」。

### §108 句 88-108-94-97、88-108-98-101 — kāya
- **问题**：义注释义错（取义窄）— **义注**：`**Kāyo**ti nāmakāyo`——这里的 kāya 指**名身**（心法的聚集），不是肉身。译文「身体变得轻安」「身体轻安的人」把它读成了色身，读者会理解为生理上的放松，与义注相悖。
- **建议**：改为「名身（nāmakāya，即心的聚集）止息下来」「名身止息的人感受到快乐」；若顾虑可读性，可译「身心（名身）平静下来」并在段后小字注注明义注释为 nāmakāya。另 `passambhati` 义注作 `paṭippassambhati`（完全止息），「轻安」尚可（passaddhi 传统作轻安），但「止息／平静下来」更贴义注。

### §108 句 88-108-59-83、88-108-84-89 — atthapaṭisaṃvedī / dhammapaṭisaṃvedī / tasmiṃ dhamme
- **问题**：义注释义错 — **义注**：`**Atthapaṭisaṃvedino**ti pāḷiatthaṃ jānantassa`（知道圣典的**义**）、`**Dhammapaṭisaṃvedino**ti pāḷiṃ jānantassa`（知道**圣典文句本身**）、`**Tasmiṃ** **dhamme**ti tasmiṃ kammaṭṭhānapāḷidhamme`（那个**业处的圣典文句**）。义注在这里把 attha／dhamma 明确分成「义理」与「文句」两边，而译文「体会到它的意义，也体会到它的**法义**」把 dhamma 也译成了义理一侧，两者的分工塌成了同义重复；「在那个**法**上」也失掉了义注限定的「业处圣典文句」。
- **建议**：`so tasmiṃ dhamme atthapaṭisaṃvedī ca hoti dhammapaṭisaṃvedī ca` → 「他就越能领会那个法（即业处的圣典文句）的**义理**，也越能领会它的**文句**」；§108-84-89 相应作「他领会了义理、领会了文句，就生起欢悦」。

## 建议项（义注补出的内容，宜入注释）

### §108 句 88-108-84-89、88-108-90-93 — pāmojja / pīti
- **问题**：取义偏粗 — **义注**：`**Pāmojjan**ti taruṇapīti`（幼嫩的、初起的喜）、`**Pītī**ti tuṭṭhākārabhūtā balavapīti`（表现为欣悦相的强盛之喜）。译文「欢悦」→「喜」的递进在字面上看不出强弱关系，读者易以为是同义反复。
- **建议**：译法可保留（欢悦／喜），但首次出现宜夹注并加小字注：欢悦（pāmojja，义注释为初起的微弱之喜）、喜（pīti，义注释为强盛之喜）。

### §108 句 88-108-102-105 — cittaṃ samādhiyati
- **问题**：义注补出的所指未体现 — **义注**：`**Cittaṃ** **samādhiyatī**ti arahattaphalasamādhinā samādhiyati`，并有一整段说明：听法者在所到之处了知禅、观、道、果，由此生喜，不让这喜中途退堕，成为近行业处者，增长观而证阿罗汉（`vipassanaṃ vaḍḍhetvā arahattaṃ pāpuṇāti`），「就此而说『心得定』」。译文「心得到安定」本身不错，但义注指的是**阿罗汉果定**，这是本经五因「都导向阿罗汉果」的关键。
- **建议**：正文可保留「心得到安定」，段后小字注注明：**义注**：此处「心得定」指以阿罗汉果定而得定。

### §108 句 88-108-2-46 — satthā dhammaṃ deseti
- **问题**：义注的限定未出 — **义注**：`**Satthā** **dhammaṃ** **desetī**ti catusaccadhammaṃ deseti`（讲说四谛法）。译文「讲说佛法」不算错，但义注给了具体所指。
- **建议**：正文保留「讲说佛法」（本段后文三处 `yathāsutaṃ yathāpariyattaṃ dhammaṃ` 需同一译法，不宜都塞进「四谛」），在段后小字注注明义注释为四谛法即可。

### §108 句 88-108-47-58 — suggahita 一串的背景
- **问题**：义注补出的背景缺失 — **义注**：`**Suggahitaṃ** **hotī**tiādisu ācariyassa santike kammaṭṭhānaṃ uggaṇhantena suṭṭhu gahitaṃ hoti…`——善取等是指「在阿阇梨跟前学取业处时」善取、善作意、善忆持。又 `**Suppaṭividdhaṃ** **paññāyā**ti paññāya suṭṭhu paccakkhaṃ kataṃ`（以慧善作**现证**，不止是「了解」）。
- **建议**：`suppaṭividdhaṃ paññāya` 由「用智慧很好地透彻了解」改为「以智慧善加现证」；取得业处的背景入段后小字注。

### §108 句 88-108-106-137、§109 句 88-109-2-36 — āsava
- **问题**：术语偏宽。`āsava` 译「烦恼」与 kilesa 撞车，`term-glossary.jsonl` 未登记此词。
- **建议**：改为「漏（āsava）」或「诸漏」，§108 首次出现夹注；定案后补进 `knowledge/terms.md`。同句 `anuttaraṃ yogakkhemaṃ` 译「无上安稳」可接受，首次出现建议夹注（yogakkhema）。

### §108 句 88-108-2-46 — 句内赘余
- **问题**：风格（非文言，属冗赘）。「也不**用心思**对所听闻、所学过的佛法反复思索、反复考察、反复**用意念**观察」——`cetasā` 与 `manasā` 两个工具格在一句里各自译出「用心思」「用意念」，中文读来重复；且「所听闻、所学过的佛法」在本句三度整串重复，跟随原文可以，但第三处可省。
- **建议**：「也不在心里对所听闻、所学过的佛法反复思索、反复考察、反复审视」。

## 存疑与原文问题

- **§109 句 88-109-37-38**：`Chaṭṭhaṃ.` 译「第六经。」——这是经末序号标记。本 chunk 单看无法判定全书统一体例，建议与同书其他经末标记统一（「第六。」或「第六经。」择一），列入 harmonize 时核对。
- **pali 原文**：未发现疑似讹误。`yogakkhemaṃ`、`anupāpuṇāti` 与义注用词相容，不作改动。
- **nissaya 缺失的影响**：§108-59-83 的 `yathā yathā … tathā tathā` 相关从句、§108-84-89 的属格独立结构（`tassa atthapaṭisaṃvedino…`）目前的读法来自原文形态推断，未经 nissaya 格助词验证。若后续能取到本段 nissaya，建议对这两处的主宾属关系复核一遍。
