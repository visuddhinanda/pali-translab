## 二、义注功能失效：黑体与释义同语反复（本 chunk 最重的问题）

父层本文把义注的释义直接搬进了正文，于是义注层的解释句退化为同义重复，读者看不出这条注在注什么：

- `101-187-56-59`：**以戒等为首的殊胜之法**，指谈论以戒等为首的最上之法 — 黑体与释义几乎同字
- `101-187-60-64`：**与喜解相应而夹杂智慧的论说**，指与明（veda）相应、夹杂着智慧的论说 — 同上
- `101-188-10-13`：**阐明出世间法的**，指阐明出世间法 — 黑体与释义完全同字
- `101-188-2-5` / `101-188-6-9`：**文句深奥的** → 指圣典的文句深奥；**意义深奥的** → 指意义深奥 — 程度稍轻，但仍是重复

对照正常的样子：`101-188-14-17` **与空性（suññatā）相应的** → 指与蕴、界、处、缘起相应——父层取直译，义注给出内容，分工清楚。

**成因**在父层，不在本层：父层把 `abhidhammakathā` 译成“以戒等为首的殊胜之法”、`lokuttarā` 译成“阐明出世间法的”、`gambhīrā` 译成“文句深奥的”，这些都是本层 `sīlādiuttamadhammakathaṃ` / `lokuttaradhammadīpakā` / `pāḷigambhīrā` 的释义。按“被解释词与父层逐字同译”的硬约束，本层黑体不能单独改。

**建议（交 harmonize 跨层决策，本层不动）**：父层本文回到直译——
- `abhidhammakathaṃ` → 阿毗达摩的论说（abhidhammakathā）
- `vedallakathaṃ` → 毗陀罗的论说（vedallakathā）
- `lokuttarā` → 出世间的
- `gambhīrā` → 深奥的

释义全部留给本层义注；父层的夹注同步落到黑体内（本层 `suññatāpaṭisaṃyuttā` 已是这种处理方式，可作样板）。父层改定后，本层黑体随之同步。

另：父层 `88-656-19-32` 与 `88-657-17-54` 的 `zh` 里内嵌了 `**义注**：…` 小字注，内容正是本层 `101-187-65-73`、`101-187-74-86`、`101-188-14-17` 的译文——同一段义注在两层各存一份，且措辞不一致（见 §三）。要么父层删掉内嵌注只留本层，要么两处取同一文本，不要各写一遍。

## 三、跨段／跨层一致性

- **uttamadhamma**（`101-187-56-59` 一句之内）：黑体作“殊胜之法”，释义作“最上之法” → **必改**，同一句里同一个词必须同一译法。黑体受父层约束不能动，故释义改为“指谈论以戒等为首的殊胜之法”。
- **veda**（`101-187-60-64`）：黑体作“喜解”，释义作“明（veda）” → **必改**。一句之内两译；且“明”是 `vijjā` 的固定对译（三明），用在这里会把读者引向错处，`veda` 与 `ñāṇa`（智慧）在本句并举，取的是“喜悦、满足”一侧。改为“指与喜解（veda）相应、夹杂着智慧的论说”，与父层黑体对齐。
- **kaṇhadhammaṃ okkamamānā**：本层两处都作“陷入黑法”（`101-187-65-73`、`101-187-74-86`），与父层本文“陷入黑法”一致 ✅；但父层 `88-656-19-32` 内嵌义注注两处写“落入黑法” → 建议统一为“陷入”，改父层内嵌注（或按 §二末直接删除内嵌注）。
- **kavitā / katā**（`101-188-36-41`）：黑体“由诗人创作的”，释义“由诗人们所作” — 动词用字不同但不构成误读，可留；若求齐整，释义改“由诗人们创作”。
- **sāsana / bāhira**（`101-188-47-52`、`53-57`）：“处在教法之外”“教法之外的弟子”前后一致 ✅。
- **gambhīra**：两句都作“深奥” ✅。
- 语体检查：全 chunk 无文言句式、无文言虚词滥用，义注体“**X**，指 Y”格式统一，标点全角、无 ASCII 引号、无工作标记 ✅。唯“殊胜之法／最上之法”的“之”系承父层四字格而来，不单独计为文言问题。

## 四、逐句问题

### §187 句 101-187-22-36
- **问题**：释义不足 — “五种律”（`pañcavidho vinayo`）对混合受众是无解的硬术语。此处与下句的 `saṃvaravinaya`（防护律）形成对举：止观不成熟则五种断除律（镇伏断、彼分断、正断、止息断、出离断）不得成立，破戒则防护律不得成立。译文照字面译“五种律”，读者无法知道指的是断除律一系。
- **建议**：加极简夹注，如“五种律（指镇伏断等五种断除律）就不存在”；或由 harmonize 统一决定是否在本经首次出现处加注。不必在译文里展开五支名目。

### §187 句 101-187-74-86
- **问题**：存疑处未暴露 — `taṃ kaṇhadhammaṃ attano dahantā` 译“把那黑法据为己有”。`attano dahati` 是“归到自己身上、安放于自己”，“据为己有”带有“占有、不让给别人”的意味，与上下文（以恶意攻击他人、为利养说法）所指的“自身染上黑法”不完全贴合。无 nissaya、无复注可裁，取义不能确定。
- **建议**：改“把那黑法安在自己身上”一类中性说法，并压低该句 `confidence`；若日后取到本段复注再定案。

### §187 句 101-187-51-55
- **问题**：语序使“应当这样来理解”的宾语悬在句外，读起来像两件事。
- **建议**：“由于律的败坏也会有法的败坏，这一点应当这样来理解。”或“反过来，由于律的败坏而有法的败坏，也应当这样理解。”（非必改）

### §188 句 101-188-6-9
- **问题**：释义与黑体同字（见 §二），纯粹重复。巴利本身只是把复合词前后拆开（`gambhīratthā` → `atthagambhīrā`），汉语里无法靠语序体现。
- **建议**：释义改“指它所含的意义深奥”，至少让这条注有可读的信息量。

### §188 句 101-188-18-27
- **问题**：`cittaṃ na ṭhapessanti` 译“不会……安住自己的心”，“自己的”是补出的，原文无对应词；且“安住心”与父层黑体“专注起来”用词脱节。
- **建议**：“指不会为了了知而把心安立起来。”（非必改，但去掉“自己的”更稳）

### §188 句 101-188-28-35
- **问题**：释义 `uggahetabbe ca vaḷañjetabbe ca` 是与 `dhamme` 同格的处格形容语，译文作“指应当学习、应当加以运用”，丢了所修饰的对象，读起来像另起的祈使。
- **建议**：“指（这些法）是应当学习、应当加以运用的。”

### §188 句 101-188-42-46
- **问题**：“是前一个词的同义词”——“前一个词”指 `kavitā`，译文未点明，读者需回看。
- **建议**：“就是前一个词（**由诗人创作的**）的同义词。”（非必改）
