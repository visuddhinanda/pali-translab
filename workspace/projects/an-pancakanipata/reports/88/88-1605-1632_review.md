# Review — 88:1605-1632（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **yathābhataṃ nikkhitto evaṃ niraye**：§1606（2 处）、§1608（2 处）都译成“就像被搬去安放在那里一样，就这样在地狱里”。这个句式把谓语 nikkhitto 丢了，“就这样在地狱里”不成句，读起来是翻译腔。nissaya 给 ājīvaka 等主语都标宾格 `ကို`，说明它们是“被带去、被安放”的受事，nikkhitto 是主句谓语，niraye 是处格“于地狱”。→ 四处统一改为：“……就像被人带去放下一样，被放进地狱里。”
- **peyyāla**：§1609 译“学处**略说**”，§1610、§1618 译“贪欲**重复品**”。nissaya 两处都作 `မြှုပ်ကွက်`（略去的部分），是同一个词，§1610 还多出一个“品”字。→ 建议统一为“学处略说”“贪欲略说”。
- **virāga**：§1616 两句和摄颂 §1622 都译“离贪”。nissaya 作 `ဝိရာဂါယ= ကင်းကွာပျောက်ပျက်ခြင်းငှာ`（为了脱离、消退），不专指贪。在 dosassa / mohassa … virāgāya 中译成“离贪”，就成了“对嗔……为了离贪”，意思错了。→ 三处统一为“离染”或“褪去”。
- **经号格式**：§1606 作“293.”，§1608 作“294—302.”（阿拉伯数字加句点），§1611 起作“三〇三、”“三〇八至一一五一、”（汉字数字加顿号），§1607 作“九—十七、”。范围连接也有“—”和“至”两种。→ 全 chunk 统一为一种体例。

## §1606 句 88-1606-2-20

- **问题**：句法 — nissaya `အာဇီဝကော= …ပရိဗိုဇ်ကို`，宾格 `ကို` 标明 ājīvaka 是被安放的受事。译文“就这样在地狱里”丢了谓语 nikkhitto，主谓不完整。
- **建议**：“比丘们，具备五种法的阿耆毗迦（ājīvaka），就像被人带去放下一样，被放进地狱里。”（同句式的各处见跨段一致性。）
- **附**：nissaya 把 ājīvaka 释为 `အဝတ်မဝတ်သောပရိဗိုဇ်`（不穿衣的游方者），与 §1608 的 paribbājaka `အဝတ်ဝတ်သော ပရိဗိုဇ်`（穿衣的游方者）对举。首次出现时可考虑补出“裸行”之意，由译者斟酌。

## §1608 句 88-1608-6-38

- **问题**：句法 — 与 §1606 相同，nikkhitto 谓语缺失（见跨段一致性）。
- **问题**：取义偏窄 — muṇḍasāvaka 在 nissaya 中作 `ဦးပြည်းခေါင်းတုံးသောနိဂဏ္ဌ၏တပည့်`（剃光头的**尼乾子的**弟子），属格 `၏` 标明是谁的弟子。“剃发弟子”看不出是尼乾子门下。
  - **建议**：“尼乾子的剃发弟子（muṇḍasāvaka）”。
- **问题**：词义 — tedaṇḍika 的主释是“名为 tedaṇḍika 的外道”。两条异释 `ဝါ=` 都是手持**一根**杖头分三叉（或系三道布结）的杖的人。“三杖者”容易读成“持三根杖的人”。
  - **建议**：改为“三叉杖者（tedaṇḍika）”，或按主释音译，异释按 style.md 作脚注备列。

## §1611 句 88-1611-21-50

- **OCR / 原文疑问**（不改）：pali 作 `anabhiratasaññā`，带编者注 `[sabbatthapi evameva dissati]`；nissaya 作 `အနဘိရတိသညာ`（anabhirati-）。记录备查。

## §1615 句 88-1615-2-18

- **数据对齐问题**（不是译文问题）：这一行挂的 nissaya 是 `သဒ္ဓါဗလံ … ပညာဗလံ`，内容属于 88-1615-22-44 的五力列举，坐标对错了行。核对结果：信力、慧力的译法与 nissaya（`သဒ္ဓါဗိုလ်`／`ပညာဗိုလ်`）一致。

## §1616 句 88-1616-6-32

- **问题**：词义 — virāgāya 译“为了离贪”。在 rāgassa 后面，意思变成“为了贪欲的离贪”，语义重复（见跨段一致性）。
  - **建议**：“为了离染”。
- **问题**：语体 — “为了尽”“为了灭”是单音节，读来不完整。nissaya：khayāya `ကုန်ခန်းခြင်း`（耗尽），nirodhāya `ချုပ်ငြိမ်းခြင်း`（止息）。
  - **建议**：“为了灭尽”“为了止息”，与“遍尽”区分开。
- **附**：nissaya 的格分两类。pariññā / pahāna / cāga 前的 rāgassa 作宾格 `ကို`（了知贪、断贪、舍贪）；parikkhaya / khaya / vaya 前作属格 `၏`（贪的耗尽、贪的坏灭）。现在的汉译不带宾语，并列结构对两类都不构成误读，无需改动。

## §1616 句 88-1616-33-87

- **问题**：漏序 / 错位（必改）— 巴利顺序是 dosa、moha、kodha、upanāha…，nissaya 顺序相同。译文作“嗔……恨……愚痴……忿……”，把 upanāha（`ရန်ငြိုးဖွဲ့ခြင်း`，结怨）提到了第二位。
  - **建议**：改为“嗔……愚痴……忿……恨……覆……”。
- **问题**：词义（必改）— makkha 在 nissaya 中作 `သူတပါးဂုဏ်ကိုချေဖျက်ခြင်း`（抹杀他人的功德），译成“覆藏”成了隐瞒自己的过失。隐瞒自己过失正是 nissaya 给 māyā 的释义（`မိမိ၏အပြစ်အနာကိုဖုံးကွယ်`），两词因此混淆。
  - **建议**：“贬抑（makkha）”，或“抹杀他人功德”。
- **问题**：词义 — paḷāsa 在 nissaya 中作 `ကိုယ့်ထက်သာသူတန်းတူယှဉ်တုဂုဏ်ပြိုင်မှု`（与胜过自己的人攀比、争功德），“恼”表达不出这层意思。
  - **建议**：“攀比（paḷāsa）”或“竞胜”。
- **问题**：词义 — māyā 是掩饰自身过失的欺瞒（见上）。“虚诳”偏向说谎，容易与 musāvāda 混同。
  - **建议**：“欺瞒”或“伪诈”。
- **问题**：词义（必改）— 与上句相同，“为了离贪”接在嗔、痴、忿等后面意思不通。
  - **建议**：改“离染”。“为了尽”“为了灭”同上句一并改。
- **问题**：语体 — “骄”是单音节。nissaya 对 mada 的释义是 `မာန်ယစ်ခြင်း`（因慢而陶醉）。
  - **建议**：“骄醉”或“骄傲”。
- **问题**：句法 — nissaya 中 dosassa 等都是宾格 `ကို`，作 abhiññāya 等的宾语。“对于嗔……，为了彻底了知……”把宾语提成了话题，结构松散。
  - **建议**：“为了彻底了知……遍知……完全舍离嗔……愚痴……放逸，应当修习五种法。”或按 §1616 首句的格式，写成“为了彻底了知嗔……”。

## §1618 句 88-1618-2-4

- **问题**：术语不一致 — nissaya `ရာဂနှင့်စပ်သောမြှုပ်ကွက်`（与贪相关的略去部分），与 §1609 的 Sikkhāpadapeyyāla 同为 `မြှုပ်ကွက်`。
- **建议**：“贪欲略说结束。”§1610 的品题同步改。
