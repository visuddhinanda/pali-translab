# Review — 124:1664-1678（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层译文（158:1147-1162）✅／nissaya ❌（未注入，词级核对无法进行）／释义标准 ❌（本层即义注，其复注未注入）。以下意见只依据巴利原文、父层译文和 knowledge。

## 被解释词（与父层逐字核对）
- **byāpādassa** → 「瞋恚」，与父层 158-1151「瞋恚已经离去」一致 ✅
- **thinamiddhassa** → 「昏沉睡眠」，与父层 158-1151「昏沉睡眠已经离去」一致 ✅
- 本层其余黑体词（arati / tandī / vijambhitā / bhattasammado / cetaso līnattaṃ / ārambhadhātu / nikkamadhātu / parakkamadhātu）都引自本层所引的《相应部》5.232，不是引自父层。它们在 §1675 与 §1676、§1677 与 §1678 之间的译法一致 ✅（但「呵欠」一词本身有问题，见 §1675）

## 跨段一致性
- **asubhārammaṇa / paṭighārammaṇa**（同一句式）：§1664 译「以不净为对象的所缘」，§1670 译「瞋碍的所缘」。两句是平行结构，译法应统一。建议都改成「X的所缘」，也就是 §1664 改为「不净的所缘」。原译「以不净为对象的所缘」语义重复（所缘本来就是对象），而且容易被误读成另一层结构。
- **pahānaṃ hoti**（同一句式）：§1664 译「……才能断除」，§1672、§1677 译「就能断除」。原文没有「唯有如此才能」的意思，建议统一为「就能断除」。
- **懈怠**一词撞车：§1675 用「懈怠」译 kāyālasiya（身体的懒惰），§1677 又用「懈怠」译 kosajja。两个巴利词不同，建议 §1675 改为「身体的慵懒」，把「懈怠」留给 kosajja。
- **kāmacchanda「欲贪」与父层 abhijjhā「贪欲」**：两个词不同，不算被解释词，不是必改项。但两词只是字序相反，读者容易以为同一个词前后译法不一。建议在 harmonize 时确认上一 chunk 是否已经交代 abhijjhā 与 kāmacchanda 的对应关系；没有交代的话，可以考虑把 kāmacchanda 换成字面差别更明显的译法（如「欲欲」「爱欲」），并登记进 `terms.md`。

## §1664 句 124-1664-2-12
- **问题**：语气添加。「要用它的对治……才能断除」给原文加了「必须如此、唯有如此」的意思。另外 tappaṭipakkhato 指不净相是净相的对立面，原译把「对治」挂在整个修法上，归属略有偏移。
- **建议**：「这样，在净相上以不如理作意而生起的欲贪，以与净相相对的不净相上的如理作意，就能断除。」

## §1664 句 124-1664-13-41
- **问题**：(1) 「以不净为对象的所缘」，见跨段一致性一节。(2) pathamanasikāra 译「走在正道上的作意」，「正道」在本书语境里容易被读成「八正道／道（magga）」。这里 patha 只是「正确的路径、途径」的意思。
- **建议**：(1) 改为「不净的所缘」。(2) 改为「合乎正途的作意」或「循正路的作意」。

## §1670 句 124-1670-15-19
- **问题**：sabbattha 在这里指「在所有情形下」（贪、瞋、昏沉等各处），不是空间上的「任何地方」。
- **建议**：「不如理作意在所有情形下都只有同一种特相。」

## §1672 句 124-1672-30-32
- **问题**：误译结构。vuttalakkhaṇo 是「具有前面所说特相的」，原译「如理作意就是……特相」把作意本身说成了特相。
- **建议**：「如理作意的特相就是前面所说的那样。」或「如理作意具有前面所说的特相。」

## §1674 句 124-1674-2-21
- **问题**：kammassakatāpaccavekkhaṇā 译「省察业是自己的所有」，读起来生硬，「所有」容易被读成「全部」。
- **建议**：「省察各人以业为自己的所有物」或「省察自己是业的主人」，并与同段后文「省察自己和别人双方的业都是各自所有的」统一措辞。

## §1674 句 124-1674-71-128
- **问题**：人名 Assaguttatthera 译「阿沙古达长老」，`terms.md` 未登记，常见译法不止一种。
- **建议**：先保留现译，把这个人名记进术语待定清单，定案后补入 `terms.md`；同书再出现时按定案统一。

## §1675 句 124-1675-8-30
- **问题**：(1) vijambhitā 译「呵欠」，但义注的定义是 kāyavinamanā（身体的弯曲伸展）。「呵欠」与「身体的伸屈扭动」对不上，读者会觉得定义和词不搭。传统译法是「欠伸／频申」，兼指打呵欠和伸懒腰。(2) kāyālasiya「身体的懈怠」与 §1677 kosajja「懈怠」撞车，见跨段一致性一节。
- **建议**：(1) vijambhitā 改为「欠伸」，同时改 §1676 句 124-1676-2-14 的列举，保持黑体词与引文逐字一致。(2) 改为「身体的慵懒」。

## §1676 句 124-1676-2-14
- **问题**：随 §1675 联动。
- **建议**：「呵欠」改为「欠伸」，与 §1675 黑体词保持逐字相同。

## §1677 句 124-1677-9-28
- **问题**：nikkamadhātu 译「出离界」，与常用于 nekkhamma 的「出离」同形，阅读本书其他章节时可能混淆。这里不算误译，「出离界」也是通行译法。
- **建议**：保留现译时，在 `terms.md` 注明「出离界 = nikkamadhātu（精进之一种），不同于 nekkhamma」，以免下游统稿误统一。
