# Review — 124:1699-1709（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 未提供，词级核对降级为纯巴利判断）／义注——本层即义注，释义以本层巴利原文自身为准／父层本文（158:1163-1194）定稿译文 ✅

## 被解释词与父层对齐

已逐条核对 **loko / abhisambuddho / lokasmā / visaṃyutto / lokasamudayo / pahīno / lokanirodho / sacchikato / lokanirodhagāminī paṭipadā / yaṃ, bhikkhave / diṭṭhaṃ / sutaṃ / mutaṃ / viññātaṃ / pattaṃ / pariyesitaṃ / anuvicaritaṃ manasā / sadevakassa … sadevamanussāya / sadevakassa**。

这些词的黑体译法都能在父层译文同一处逐字找到，**没有断链**。只有两点需要处理：

- 1703 句末多出一处黑体「所以说**彻底觉悟**」，原文句末的 abhisambuddho 不是黑体被解释词。见下条。
- 1708 中「看到／听到／获得／寻求」不带「被」，「被心随之思察」带「被」。这与父层自身的用字一致（父层是「被看到、听到……被获得、被寻求、被心随之思察」），**不必改**。

## 跨段一致性

- **gata（tathāgata 词源中的「去」）**：§1705 译「如实地**通达**了」，§1707 一律译「去、去到」。1705 是 tathā+gata 释名的第一处，不出现「去」，读者就看不出释名的落点。→ 建议统一为「去到」，1705 改为「如实地去到了」。
- **āhāra**：§1701「一切众生都依靠**食物**而存续」，同句下文作「四种**食**」。这里的 āhāra 是四食的「食」，不是吃的食物。→ 统一为「食」。
- **引文出处格式**：§1701 作「（《大义释》3；…）」，§1706 作「（《相应部》5.1090）」，§1708 作「《增支部义注》（增支部义注2.4.23）」，书名重复，括号内也没有书名号。→ 统一为「（《书名》编号）」。

## §1701 句 124-1701-2-90

- **问题**：风格（必改）——「衰败的有**之**起因世界」「成就的有**之**起因世界」用了文言虚词「之」。
- **建议**：改为「衰败有的起因世界」「成就有的起因世界」，或整组统一为「衰败有世界、衰败有起因世界、成就有世界、成就有起因世界」。
- **问题**：准确性——āhāraṭṭhitikā 译「依靠食物」，范围译窄了（见跨段一致性）。
- **建议**：「一切众生都依靠食而存续」。

## §1702 句 124-1702-54-75

- **问题**：取义——yaṃ pana na lujjatīti gahitaṃ 的 gahita，在取蕴的语境里是「被（渴爱、邪见）执取为」，不是一般的「被认为」。正是这层意思才把 loka 一词收窄到「取蕴」。译作「被认为」，前后论证的衔接就弱了。
- **建议**：「但是，被执取为‘不会毁坏’的东西，其实并不是那样……」。

## §1703 句 124-1703-2-76

- **问题**：取义存疑——vaṭṭappamāṇasaṇṭhānādibhedato 译「轮回的范围、形态等差别」。这一组分类与前两组对应三种世界：意乐、随眠等对应有情世界，善、不善等对应行世界，此组应对应空间世界。这里的 vaṭṭa 更可能是「圆（形）」，指世界的圆形、大小、形状，而不是「轮回」。
- **建议**：改为「以及圆形、大小、形状等差别」。若能查到复注或平行文献，再定案。
- **问题**：格式——句末「所以说**彻底觉悟**」的黑体在原文里没有对应。
- **建议**：去掉句末黑体，只保留句首被解释词的黑体。

## §1704 句 124-1704-2-5

- **问题**：准确性（轻）——yathāvuttalokato 是从格「从……世界」，对应本文「脱离了世界」的「从」义。现译「就是上面所说的世界」没有体现从格。
- **建议**：「**世界**：就是从上面所说的那个世界（脱离）。」

## §1704 句 124-1704-19-30

- **问题**：术语——abhisaṅkhārehi 译「诸业行」。「诸」偏文言，「业行」也不是 abhisaṅkhāra 的通行译名。
- **建议**：「连同各种行作（abhisaṅkhāra）在内的一千五百种烦恼」。

## §1705 句 124-1705-2-11

- **问题**：释名断链——yāthāvato gato 译「如实地通达了」，见跨段一致性。
- **建议**：「到这里，已经表明了这样的意思：彻底觉悟了各种真实，如实地去到了，所以称为‘如来’。」

## §1708 句 124-1708-2-21

- **问题**：风格——「以觉悟其中所看到的等等的方式」，「的等等的」堆叠，读起来不通顺。
- **建议**：「现在又要从觉悟其中被看到的事物等方面来显示这一点」。

## §1708 句 124-1708-22-48

- **问题**：格式——「《增支部义注》（增支部义注2.4.23）」书名重复。
- **建议**：「不过，《增支部义注》（2.4.23）中说的是……」。

## §1708 句 124-1708-120-127

- **问题**：风格（必改）——「它的，就是‘包括天神的’」是翻译腔，没有古文或语法背景的读者读不懂。这里讲的是 sadevaka 的属格 sadevakassa。
- **建议**：「其中，‘包括天神’是指与天神在一起；这里用的是它的属格，即‘**包括天神**的’。」黑体仍只落在「包括天神」上，与父层一致。
