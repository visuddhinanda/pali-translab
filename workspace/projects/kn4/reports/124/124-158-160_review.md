# Review — 124:158-160（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠ 部分缺（124-158-2-5、124-160-2-4 无 nissaya）／释义标准 ❌ 未注入（本层即义注，上层释义未提供）／**父层译文 ❌ 未注入**。所以**被解释词与父层逐字同译一项无法核查**：158 的 **sāsanasampattippakāsanatthaṃ**，以及 159 的 **satthuno / pamāṇabhāvappakāsanena / sāsanassa / pamāṇabhāvadassanatthaṃ**，需要补跑跨层对齐。

## 跨段一致性
- **nidānavacana**：§158 句 2-5、47-56，§159 句 2-8、25-28 都译作动词性的“说因缘”；§158 句 32-41 的 nidānavacanehi 译作名词性的“因缘语”。同一个复合词，一处名词化，其余是动宾结构，读者会以为是两个概念。建议统一。较稳妥的办法是：各处都用“说因缘”，32-41 改为“各处说因缘的文句中”。如果父层（本文或上层义注）已有定译，以父层为准。
- **paresaṃyeva / attahitā 的“只”**：§158 句 6-14 给 attahitā 补了“只”，译作“只为自己利益”；紧接着句 15-31 的 paresaṃ**yeva**（强调“唯独为他人”）却没有译出“只”。限定词放错了位置，见下面两条。
- 其余术语前后统一：pamāṇabhāva 译“权威地位”，pakāsana 译“显明”，satthu 译“导师”，apadesa 译“说明”。

## §158 句 124-158-6-14
- **问题**：准确性 — “也没有**只**为自己利益的行持”中的“只”是原文没有的。原文是 `natthi … attahitā vā`，意思是“也没有为自己利益的（行持）”。nissaya 作 `အတ္တဘိတာ= ကိုယ်တော်၏အစီးအပွါးသည်။ နတ္ထိ= မရှိ။`，即“自身的利益是没有的”，否定的是自利本身。补上“只”，就把“无自利”弱化成了“不单为自利”，也和下一句“唯为他人”对不上。
- **建议**：改为“……他没有无意义的行持，也没有为自己利益的行持。”

## §158 句 124-158-15-31
- **问题①**：准确性 — `paresaṃyevatthāya` 中的强调词 eva 漏译。nissaya 作 `ပရေသံဧဝ= သူတပါးတို့၏ သာလျှင်`，意为“唯独他人的”。
- **建议**：改为“正等正觉者的一切作为都只是为了他人而进行的”。
- **问题②**：存疑 / 标准分歧 — `diṭṭhadhammikasamparāyikaparamatthehi` 的切分有两种读法。
  - 译文按三项读：现世利益、来世利益、究竟利益。
  - nissaya 作 `မျက်မှောက်၌ဖြစ်သောမြတ်သောအကျိုး တမလွန်ဘဝ၌ဖြစ်သောမြတ်သောအကျိုး`，把 parama 当作形容词，读成两项：“现世的殊胜利益、来世的殊胜利益”。
  - 注疏中通行的是三利（diṭṭhadhammikattha / samparāyikattha / paramattha），译文的读法有据。但本层没有更上层的释义可以裁定，建议保留现译，压低该句 confidence，并在报告中记下这一分歧。
- **问题③**：原文疑问 — pali 作 `na kabbaracanā`（不是诗文创作），nissaya 底本作 `ပုဗ္ဗရစနာ= ရှေး၌စီရင်ခြင်း`（pubbaracanā，“预先编排”），是异读。译文按 pali 底本译出没有问题，记入 known-issues 第二节即可，不改。

## §158 句 124-158-32-41
- **问题**：句法（轻微）— nissaya 把 `kāladesadesakaparisāpadesehi` 和 `nidānavacanehi` 都读作具格“通过”（两处都是 `ဖြင့်`），是并列的两个手段。译文把 nidānavacanehi 处理成处所“在……因缘语中”，意思大体不错，但结构关系变了。
- **建议**：连同上面的统一术语一起改为：“导师的这种行迹，通过各处说因缘的文句，以及其中对时间、地点、说法者和听众的说明，按照适宜的方式显明出来。”

## §158 句 124-158-42-46
- **问题**：准确性 — `yojetabbaṃ` 是“应当连读、配合”的意思，指要和上句的 pakāsiyati 连起来读。nissaya 补出了 `ပကာသိယတိ= ပြအပ်၏`。译作“理解为”，就丢掉了“与谓语连读”这层语法指示，读者看不出括引的短语要接到哪里。
- **建议**：改为“但在这里，应当连读为‘通过对说法者和听众的说明而显明’。”

## §159 句 124-159-2-8
- **问题**：被解释词标记 — 原文四个黑体词分别是 satthuno / pamāṇabhāvappakāsanena / sāsanassa / pamāṇabhāvadassanatthaṃ。译文只加了两段粗体，而且把“为了”“通过”“来”这些虚词也包了进去，粗体和词条对不齐，下一层引用时没法逐字对照。
- **建议**：调整语序，让每个被解释词各有一段粗体。参考写法：“此外，说因缘是**为了显示****教法的****权威地位**，方法是**显明****导师的****权威地位**。”具体措辞须与父层对齐后定稿，并补跑跨层对齐。

## §159 句 124-159-9-24
- **问题**：漏译 — `Tañcassa` 中的 assa 没有译出。nissaya 作 `အဿ= ထိုမြတ်စွာဘုရား၏`，即“这位世尊的”。译成“这种对权威地位的显示”，就分不清显示的是导师的权威还是教法的权威，而下文以“世尊”“阿罗汉”为证，指的正是导师。
- **建议**：改为“应当了解，世尊的这种权威地位的显示，已经依照前面所说的方式，由‘世尊’‘阿罗汉’这些词表明了。”另外，这里所引的 bhagavatā / arahatā 应与本文律文中这两个词的译法逐字相同，需要对照父层核实。
