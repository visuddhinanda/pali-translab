## 被解释词对齐（义注黑体 ↔ 本文）

逐条核对 §863–868 的义注黑体，以下全部与本文逐字一致：两种 / 邪见 / 缠缚 / 天人 / 有些人 / 退缩不前 / 冲过了头 / 而 / 有眼的人 / 能够看清 / 有 / 喜爱有 / 乐于有 / 因有而欢喜 / 灭除有 / 不投入 / 不生信心 / 不安住 / 感到苦恼 / 羞愧 / 厌恶 / 非有 / 欢喜 / 朋友们 / 这个我 / 断灭 / 毁灭 / 死后不再存在 / 这才是寂静的 / 殊胜的 / 真实的 / 已生的 / 看作已生的 / 厌离 / 离贪 / 灭尽 / 那些把已生的看作已生的 / 也看到了对已生的超越 / 由于有爱的灭尽 / 那位彻底了知已生的人 / 种种有 / 离了渴爱 / 比丘 / 由于已生的 / 不再存在 / 不再进入 / 再生。

对齐本身没有断。问题在于下面两处被解释词的**取义与义注相悖**（yato、yathābhūte），需要两层一起改。

## 跨段一致性
- bhava 系列：全 chunk 的 bhava 一律译“有”（有、喜爱有、乐于有、灭除有、非有、种种有、有爱），只有 §453 punabbhava 译“再生”，脱出了“有”的系列。建议改为“再有”，让读者看出它和前面诸“有”是同一个词。依据是全 chunk 的 bhava 译法统一。此项为可选，若改，义注 124-868-36-53 的黑体“再生”须同步改。
- 其余关键词（已生的／有眼的人／看清／退缩不前／冲过了头／邪见）前后一致。语体也统一。

## §448 句 158-448-12-48
- **问题**：义注取义＋漏译。
  - yato 的取义与义注相悖。**义注**：*Tattha yato ti yadā*（“既然”就是“当……的时候”），nissaya 作 `ယတော= အကြင်အခါ၌`（在……之时），两者都取时间义。译文作“既然”，是因果义，与义注相悖。义注 124-865-43-47 自己把黑体“既然”释作“当……的时候”，读起来也自相矛盾。
  - kira 漏译。nissaya 在每个动词后都标了传闻语气 `ကိရ … သတဲ့`（据说），译文没有译出。这个“据说”是断见者转述、自我标榜的口吻，属于实义。
- **建议**：改为“……于是欢喜非有，认为：‘朋友们，据说当这个我在身体坏灭、死亡之后断灭、毁灭，死后不再存在的时候，这才是寂静的……’”。
  - 义注 124-865-36-42 的黑体须同步改为“**朋友们，据说当**”。
  - 义注 124-865-43-47 的黑体须同步改为“**当**”。该句释义可作“这里，‘**当**’（yato）就是 yadā，‘在……的时候’”。

## §451 句 158-451-2-7
- **问题**：义注取义。**义注**：*Yathābhūte ti aviparītasaccasabhāve nibbāne*，把 yathābhūte 释为处格名词，指“如实者＝涅槃”。nissaya 也作 `…နိဗ္ဗာန်၌`（于涅槃中）。译文“依照如实而得解脱”把它读成了方式状语（照实情），与义注不合。“而得”也偏文言。
- **建议**：改为“由于有爱的灭尽，在如实中得到解脱。”义注 124-867-42-46 的黑体须同步改为“**在如实中**”。124-868-11-23“他确信如实的涅槃”可不动。

## §456 句 158-456-2-3
- **问题**：误译（所指）。Tassuddānaṃ 的 tassa，nissaya 作 `ထိုဒုကနိပါတ်၏`（那个二集的）。这首摄颂列的是 10＋12＝22 经，涵盖整个二集，不是“本品”。§461“共宣说了二十二部经”也证明了这一点。
- **建议**：改为“二集的摄颂——”，或依原文作“它的摄颂——”。

## §460 句 158-460-2-8
- **问题**：误译（经名）。dhātusallānaṃ，nissaya 作 `နိဗ္ဗာနဓာတုသုတ်နှင့် ပဋိသလ္လာနသုတ်`，指“涅槃界经”与“独坐经”。sallāna 是 paṭisallāna（独坐、禅思）的略称，不是 salla（箭）。“离箭经”是把词源认错了。
- **建议**：改为“不生经、界经、独坐经，学经与警醒经；”。

## §459 句 158-459-2-9
- **问题**：风格。“法经为第五”的“为”是文言判断用法。
- **建议**：改为“寻经、说法经、明经，慧经、法经是第五；”，或“……慧经，第五是法经；”。

## §446 句 158-446-2-16（存疑，不必改）
- **问题**：olīyanti 的取义偏窄。**义注**：*avalīyanti allīyanti saṅkocaṃ āpajjanti, na tato nissaranti*，nissaya 作 `ကပ်ငြိတွယ်တာ`（黏着、贪恋），重心在“黏着于有、不肯出离”。“退缩不前”只译出了 saṅkoca（畏缩）一面。
- **建议**：维持现译亦可，因为它与义注黑体一致，义注释文也已补出“陷在其中、黏着不放”。若要改，可作“滞留不前”，但须连同义注 124-863-103-132、124-864-102-107 一起改。
