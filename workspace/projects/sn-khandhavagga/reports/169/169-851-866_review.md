# Review — 169:851-866（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分句子附 nissaya，无 nissaya 的句子略过）

## 跨段一致性

- **Sāvatthinidānaṃ**：§852、§854 译“舍卫城因缘。”，§861、§863、§865 译“因缘在舍卫城。” → 建议统一为“舍卫城因缘。”。依据：`သာဝတ္ထိနိဒါနံ= တည်း။` 把它当作一个名词性复合词，表示“（这是）舍卫城的因缘”，不是“因缘在舍卫城”这样的主谓句。
- **pe 的译法**：§852-24-46、§854-24-63 译“（中略）”，§861 起各段一律译“（略）” → 统一为“（略）”。
- **ajjhattaṃ … sukhadukkhaṃ**：§861 各句都译成定语“内在的苦乐”。nissaya 把 ajjhattaṃ 当处格状语（见下文 §861 句 169-861-9-27）。§861 内各句要一并改，保持同一译法。
- **so attā, so loko, so pecca bhavissāmi …**：§865-28-46、§865-75-91、§865-117-135、§866-64-82、§866-153-170 共五处，都译成“死后我将会是那个常、恒、永久、不会变化的自我”，句法误读相同（见下文 §865 句 169-865-28-46）。五处要按同一改法统一修订，篇名 §864“‘那就是自我’经”随之核对。
- **dukkhānupassī / anattānupassī**：§852、§854 都译“观察……是苦的／无我的”，两经译法一致。是否补出“反复”见下文 §852、§854 两条，改的话两经要同步。

## §852 句 169-852-47-48（关联 169-852-9-23、169-852-24-46）

- **问题**：词法（建议项）。nissaya 给本经补注：`ဒုက္ခာနုပဿီ= ဆင်းရဲ၏ဟု အဖန်ဖန် ရှုလေ့ရှိသည်ဖြစ်၍`，意思是“惯于一再观察（它）是苦的”。-anupassī 是表示习惯、反复的施事名词，作 vihareyya 的伴随主语补语。现译“他应当观察色是苦的，这样安住”没有译出反复、惯常的意思。
- **建议**：改为“他应当反复观察色是苦的，这样安住”；§852-24-46 的“对受……对识”一句同步改。

## §854 句 169-854-111-112（关联 169-854-9-23、169-854-24-63）

- **问题**：词法（建议项），与 §852 相同。nissaya：`အနတ္တာနုပဿီ= အတ္တမဟုတ်ဟု အဖန်ဖန် ရှုလေ့ရှိသည်ဖြစ်၍`，意思是“惯于一再观察（它）不是自我”。
- **建议**：改为“反复观察色是无我的，这样安住”。§854-24-63 中“他观察色是无我的而安住……”同样补“反复”，与 §852 保持一致。

## §855 句 169-855-2-4

- **问题**：原文疑问（只记录，不改）。pali 作 `Kukkuḷavaggo cuddasamo`（第十四），nissaya 作 `စတုတ္ထော= တည်း။`（第四，即 catuttho）。nissaya 底本的品序可能是按本篇（蕴篇某五十经）内部计算的。现译“第十四品”与 pali 一致，不改。

## §857 句 169-857-2-9

- **问题**：格与句法。nissaya：`အနိစ္စေန= အနိစ္စအမည်ဖြင့်`、`ဒုက္ခေန= ဒုက္ခအမည်ဖြင့်`。aniccena、dukkhena 是具格，意思是“以‘无常’为名／以‘苦’为名”，指经名，不是经的内容。现译“说无常的三经”“说苦的另外三经”把它读成了内容描述。
- **建议**：改为“热灰经，以‘无常’为名的三经，以‘苦’为名的另外三经；”

## §858 句 169-858-2-9

- **问题**：格与句法，问题同 §857。nissaya：`အနတ္တေန= အနတ္တအမည်ဖြင့်`、`ဝုတ္တာ= ဟောတော်မူအပ်ကုန်သော`、`ကုလ ပုတ္တေန= ကုလပုတ္တအမည်ဖြင့်`、`ဒွေ ဒုကာ= ၂x၂= ၄-သုတ်`。anattena 是具格，表示“以‘无我’为名”；vuttā 是“所说的”，修饰 tayo；kulaputtena 同样是具格，表示经名。“两组、每组两经、共四经”这一点现译已正确译出。
- **建议**：改为“以‘无我’为名所说的三经，以‘善男子’为名的两组经，每组两经。”，与 §857 的句式统一。

## §861 句 169-861-9-27

- **问题**：格与句法。
  1. nissaya：`အဇ္ဈတ္တံ= အဇ္ဈတ္တသန္တာန်၌`，带处格助词 ၌，意思是“在自身的相续中”，作 uppajjati 的处所状语。主格只有 `သုခဒုက္ခံ= ချမ်းသာဆင်းရဲသည်`。现译“内在的苦乐”把 ajjhattaṃ 读成了 sukhadukkhaṃ 的定语。
  2. sukhadukkha 的语序是“乐苦”（`ချမ်းသာဆင်းရဲ`），现译倒成了“苦乐”。
- **建议**：改为“比丘们，有什么存在时，依于什么，乐与苦才会在内（自身）生起呢？”。§861 其余含 ajjhattaṃ sukhadukkhaṃ 的句子（28-51、52-71、116-133、192-210）按同一句式统一。

## §861 句 169-861-28-51

- **问题**：格与句法，问题同上。nissaya：`အဇ္ဈတ္တံ= ၌။ သုခဒုက္ခံ= သည်။`，ajjhattaṃ 是处格，sukhadukkhaṃ 是主格。前半句 `နော= တပည့်တော်တို့၏`（属格）、`ဓမ္မာ= တရားတို့သည်`（主格）、`ဘဂဝံမူလကာ`（谓语）现译“我们的法以世尊为根本”没有问题。
- **建议**：后半句改为“比丘们，色存在时，依于色，乐与苦就会在内生起。”

## §861 句 169-861-116-133

- **问题**：格与句法。
  1. ajjhattaṃ 是处格，同上。
  2. nissaya：`ယံ ပန= အကြင်ရုပ်သည်ကား`、`တံ= ထိုရုပ်ကို`。yaṃ / taṃ 指色，taṃ 是 anupādāya 的宾格；现译“如果不依于它”在宾格关系上没有问题。`အနုပါဒါယ= မစွဲလန်းမူ၍` 是“不执取（它）”的意思，与前文 upādāya 的“依于”对应，可以保留。
- **建议**：改为“凡是无常、苦、会变化的，如果不依于它，乐与苦还会在内生起吗？”。§861-192-210 同步改。

## §863 句 169-863-206-207（关联 169-863-8-23、169-863-41-76）

- **问题**：词法（建议项）。nissaya：`ကိံ= အဘယ်ကို`（宾格），`အဘိနိဝိဿ= မှားသောအားဖြင့် နှလုံးသွင်း၍`，意思是“错误地放在心上、执取了之后”，而且注明后文 etaṃ mama 等照前例解释。现译“执著于什么”“执著于色／识”在宾格关系上正确，但“错误地执取”这一层义没有体现。
- **建议**：可以保留“执著于”，但 §863、§865、§866 全部 abhinivissa 要用同一个词；如果要显出“错执”，统一改为“错误地执取……”。

## §865 句 169-865-28-46

- **问题**：格与句法（必改）。nissaya：`သော= ထိုငါသည်။ အတ္တာ= အတ္တတည်း။ သော= ထိုငါသည်။ လောကော= လောကတည်း။ သော= ထိုငါသည်။ ပေစ္စ= တမလွန်ဘဝသို့ ရောက်၍။ နိစ္စော= မြဲသည်။ … အဝိပရိဏာမဓမ္မော= … ဘဝိဿာမီတိ= ဖြစ်အံ့`。
  1. 三个 so 都是主格，指说话者自身，意思是“那个我”。nicco、dhuvo、sassato、avipariṇāmadhammo 是 bhavissāmi 的主格补语，表示“（我）将是常的……”。
  2. 现译“死后我将会是那个常、恒、永久、不会变化的**自我**”有三处偏差：凭空补出原文没有的“自我”作中心名词；把主格 so 挪成了“那个……自我”的定语；“我”与 so 重复出现。
  3. 现译“那就是自我，那就是世界”把 so 读成了泛指的“那”，nissaya 明确作“那个我”。
- **建议**：改为“‘那个我就是自我，那个我就是世界；那个我死后将会是常、恒、永久、不会变化的’呢？”。如果顾及读者可读性要保留“那就是自我，那就是世界”，至少第三分句必须删去“的自我”，改成“死后我将会是常、恒、永久、不会变化的”。§865-75-91、§865-117-135、§866-64-82、§866-153-170 四处同步统一。
- 补充：nissaya `ဒိဋ္ဌိ= သဿတအယူသည်` 说明此处的 diṭṭhi 指常见。现译“这样的见解”可以保留，不必在译文里补出“常见”。
