## 理由
- **资源**：本次注入的数据里没有义注（aṭṭhakathā），也没有 nissaya。因此没能按「义注定释义、nissaya 定词法」逐句核对，准确性只能对照巴利原文判断，信心指数相应压低。下面凡是涉及释义取舍的条目，都要等补取义注后再定案。
- **准确性**：主谓宾结构、否定关系和各句的意思归属基本正确，没有发现 fatal。有三点需要注意：
  - 在 490 和 491 两段里，同一句定型句「so pecca bhavissāmi」的译法不一样。490 译为「我将成为那个我」，491 译为「我将是常住的」。两种理解不能同时成立。
  - 491 的「so attā」没有译出指示词 so。
  - 490 末句增加了原文没有的情态「能」和动词「达到」，没有体现原文属格 jānato / passato「对于这样知、这样见的人」的结构。
- **风格**：通篇是现代书面汉语，没有发现文言虚词或文言句式。标点为全角，引号层级正确，译文里也没有残留工作标记。490-30-46 破折号后面接「……的」，读起来有些悬空。
- **一致性**：这是本评估的主要扣分项。490 和 491 是平行的定型文，但下面这些地方两段译法不同：
  - 「那个我／自我」
  - 「变异／变易」
  - 「感受／受」
  - 「触及／触动」
  - 「没有听闻正法／没有听闻过正法」
  - 「而生／产生」
  - 「这样看来／因此」
  - 问句一处用问号分隔，另一处用逗号分隔
  - 末句一段用无主语结构，另一段用「对于……的人来说」

  harmonize 应该统一这些译法，但没有统一。

## 问题清单

### 🟧 error
- `169-491-36-51`｜漏译｜片段「自我就是世界；死后我将是常住的」
  - 问题：原文「so attā so loko, so pecca bhavissāmi」有两个 so，本句都没有译出，平行句 490-30-46 则译出了。另外，本句把 so pecca bhavissāmi 理解为「我将是常住的」，490 理解为「我将成为那个我」。同一句定型文出现了两种句法理解，至少有一处有误。
  - 建议：先补取义注，确认 so 指的是「我（ahaṃ）」，还是「那个我（attā）」作为 bhavissāmi 的补语，然后按义注统一两段的译法。如果 so 指 attā，本句要补出「那个」；如果 so 指 ahaṃ，就改 490-30-46。

### 🟨 warning
- `169-490-30-46`｜整句逻辑表达不规范｜片段「死后我将成为那个我——常住、恒久、永恒、不会变异的。」
  - 问题：破折号后面的「常住、恒久、永恒、不会变异的」以「的」结尾，悬空了，修饰对象不清楚。而且这里对 so pecca bhavissāmi 的理解与 491-36-51 不一致，见上一条。
  - 建议：按义注定案后改成完整的判断句，例如「死后我将成为那个常住、恒久、永恒、不会变易的我」，或者「死后我将是常住、恒久、永恒、不会变易的」。
- `169-490-101-124`｜整句逻辑表达不规范｜片段「这样知、这样见，也能紧接着达到诸漏的灭尽」
  - 问题：原文 jānato … passato 是属格，意思是「对于……的人」；khayo hoti 是陈述句，没有「能」的意思。译文缺少主语，还增加了情态「能」和动词「达到」，并且与 491-153-168 的译法不一致。
  - 建议：改为「比丘们，对于这样知道、这样看见的人来说，诸漏的灭尽也就紧接着到来」，与 491 保持一致，同时保留 evampi 的「也」。
