## 被解释词对照（与父层逐字比对）

全部 33 处黑体词都能在父层定稿译文里找到逐字相同的原文，没有必改项。逐条如下：

破坏了防护 / 圣者 / 同一回事 / 属于同一类 / 就是我 / 没有分别的同一个东西 / 或者看作色在自我之中 / 或者看作自我在色之中 / 执取所缠缚 / 处在缠缚 / 也是同样的道理 / 单纯以色 / 非色 / 在四蕴中每蕴各有三处 / 这五处说的是断见 / 常见 / 障碍道 / 不障碍生天 / 身体 / 也同样是有病的 / 被贪、嗔、痴所随逐 / 这里 / 显示 / 因为没有烦恼 / 有学则既不是心有病 / 所趋向的，正是心没有病的状态

有几处黑体词截取了父层的半个短语，读起来不顺，列在下面的建议项里（§22 句 197-22-2-8、§23 句 197-23-29-39）。

## 跨段一致性
- diṭṭhigatika：§21、§22 都译为“持邪见的人”，前后一致。
- mahājana：§23 译为“随轮回流转的一般大众”，和父层 §36 的“世间的一般大众”说法一致。
- 父层把 advaya 引作“没有分别的同一个东西”，§21 句 197-21-72-98 却简称“看作没有分别”，前后说法不统一。建议见该句。
- 其余术语（执取、相续、显示、心有病 / 心没有病、断见 / 常见）前后统一。
- 语体：全段是现代书面汉语，没有发现文言腔。

## §20 句 197-20-24-27
- **问题**：格式（轻微）。“原文 ariye 就是 ariyo（圣者）”中，巴利词形直接夹在正文里，和 style.md 规定的“圆括号夹注”体例不同。这句是语法说明，巴利词形不能省。
- **建议**：可改成“**圣者**：这里原文的 ariye 就是 ariyo（圣者）。”或保留原样。不是必改项。

## §21 句 197-21-11-21
- **问题**：取义（轻微）。nibandhana 意思是“以……为依据、系于……”，译成“紧密相连”，意思偏弱。
- **建议**：可改为“自我是以‘我’这个认知为依据的”。

## §21 句 197-21-72-98
- **问题**：跨段一致性。advayadassana 引的是父层 §34 的“看作没有分别的同一个东西”，这里只写了“看作没有分别”，读者不容易对上父层的原话。
- **建议**：改成“所以说这是‘看作没有分别的同一个东西’”。

## §21 句 197-21-110-117
- **问题**：可读性。这句针对的是父层“或者把自我看作拥有色”（rūpavantaṃ attānaṃ），原文没有点明。现在的译文单独读，容易被理解成与“拥有色”相矛盾。
- **建议**：harmonize 时可以考虑轻度补出语境，例如“（把自我看作拥有色时，）他并不是……”。如果坚持不补，就在报告里存疑。这一项信心偏低。

## §21 句 197-21-137-155
- **问题**：取义（轻微）。diṭṭhitaṇhāhi 是具格，表示“凭着 / 以”，父层 §34 也译作“以贪爱和邪见”。这里译成“被……所驱使”，增加了原文没有的被动驱使义。
- **建议**：改为“因为他凭着已经达到缠缚程度的邪见和贪爱，以‘色是自我，自我拥有色’等方式错误地执取五蕴，并且一直停留在这种执取中”。

## §22 句 197-22-2-8
- **问题**：可读性。父层原句是“说的是单纯以色为自我”，黑体只截了“单纯以色”，后面直接接“指……色本身”，读起来不通。
- **建议**：黑体仍保持“单纯以色”不变，释义改成“**单纯以色**：是说只以不与非色混杂的、纯粹的色本身（为自我）”。

## §22 句 197-22-59-89
- **问题**：术语。ekaccasassata 通常译作“一分常见”。现在的“执取部分常住的那一种”意思没错，但读者难以对上这个术语。
- **建议**：改为“……他也仍然有**常见**，至少也是一分常见（ekaccasassata）的执取”。术语定下来后补进 terms.md。

## §23 句 197-23-29-39
- **问题**：可读性。黑体词“有学则既不是心有病”是从父层截来的半句，有“既”而没有下文的“也”，读起来悬空。
- **建议**：黑体不动，句式可调为“说**有学则既不是心有病**（也不是心没有病），是因为：就已经断除的烦恼而言，他们不是心有病；就还没有断除的烦恼而言，他们是心有病的”。
