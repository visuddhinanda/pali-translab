# Review — 169:417-439（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分句有 nissaya，无 nissaya 的句子不出意见）

## 跨段一致性

- **seṭṭhā / brahmabhūtā 撞译**：§424 brahmabhūtā 译“最殊胜的人”，§430 seṭṭhā 也译“最殊胜的人”，§419 seṭṭhā 译“最殊胜的”。两个不同的词在同一组偈里译成同一个词，读者分不出来。nissaya 对两者的区分很清楚：`ဗြဟ္မဘူတာ= မြတ်သည်ဖြစ်၍ ဖြစ်ကုန်၏`（是尊贵的，没有最高级），`သေဋ္ဌာ= အမြတ်ဆုံးပုဂ္ဂိုလ်တို့တည်း`（是最尊贵的人，有最高级）。→ seṭṭhā 保留“最殊胜”，brahmabhūtā 改用不带最高级的译法（见 §424）。
- **aggā**：§419 译“最高的”，§439 译“最上的” → 建议统一为“最高的”。
- **lokasmiṃ（§419 / §439 同一句）**：§419 译“在这个世间里”，§439 译“在世间” → nissaya `တသ္မိံ လောကသ္မိံ= ထိုဘဝဂ်တိုင်အောင်သော သတ္တာဝါသလောက၌`（在那个直到有顶的有情居世间里），指的是前面所说的范围。建议统一为“在这个世间里”。
- **Sāvatthinidānaṃ**：§418 译“本经的因缘在舍卫城。”，§438 译“因缘在舍卫城。” → 统一为一种。
- **nesohamasmi**：§418 译“这不是我”，§438 译“我不是这个” → 统一为一种（两处巴利文完全相同）。
- **§419 与 §439 是同一段套语，译法多处漂移**：
  - Evaṃ passaṃ：“这样观察的” 和 “这样看的” 不一致。
  - saṅkhāresu：“对行” 和 “对诸行” 不一致。
  - 小品词 pi：§419 只在识上译出“也”，§439 每一项都译出“也”。
  - Nibbindaṃ virajjati：“厌离了，就会离染” 和 “厌离的时候，就离染” 不一致。nibbindaṃ 是现在分词，“厌离的时候”更贴近原文。
  - vimuccati：“就得到解脱” 和 “就解脱” 不一致。
  - Vimuttasmiṃ：“解脱之后” 和 “解脱了” 不一致。
  - Khīṇā jāti：“穷尽” 和 “断尽” 不一致。
  - nāparaṃ itthattāya：“不会再有下一世了” 和 “以后不会再有这样的生存了” 不一致。
  
  → 这些句子应当逐字统一，以其中一段为准。

## §420 句 169-420-5-11

- **问题**：句法 — nissaya 中 `သုဂတော= ကောင်းသောစကားကို ဆိုတော်မူတတ်သော`（说善语的，是修饰语）直接修饰 `သတ္ထာ= ဆရာဘုရားသည်`（导师，主格）。sugato 是 satthā 的修饰语，两者同指一人。现译“善逝说完……以后，导师又……”读起来像两个人。
- **建议**：表明二者同指一人，例如“善逝说完这些话以后，这位导师又这样说：”。

## §424 句 169-424-2-8

- **问题**：词义 — `ဗြဟ္မဘူတာ= မြတ်သည်ဖြစ်၍ ဖြစ်ကုန်၏`，意思是“是尊贵的”，没有最高级。nissaya 另记的异释是“到达梵的状态”或“借殊胜的道智生于圣种”。现译“最殊胜的人”多出了最高级，又与 §430 的 seṭṭhā 撞译。
- **建议**：改为“已经成为尊贵者（brahmabhūta）”之类不带最高级的译法。

## §426 句 169-426-2-8

- **问题**：句法 — nissaya 把这两行偈处理成主语“他们”（`တေ`）带三个并列的表语，每个都以 `တည်း` 收尾：
  - `သတ္တသဒ္ဓမ္မဂေါစရာ … တို့တည်း`
  - `ပသံသိယာ … သပ္ပုရိသာ= သူတော်ကောင်းတို့တည်း`
  - `ဩရသာ ပုတ္တာ= … သားတော်တို့တည်း`
  
  sappurisā 是表语。现译“这些值得称赞的善人，是佛陀的嫡子”把它误读成了主语。
- **建议**：“他们是值得称赞的善人，是佛陀亲生的儿子。”orasā 的 nissaya 是 `ရင်၌ဖြစ်ကုန်သော`（生于胸前），“亲生”或“嫡出”都可以。

## §428 句 169-428-2-6

- **问题**：词义 — `မဟာ ဝီရ= ကြီးသော လုံ့လရှိကုန်သည်ဖြစ်၍`，意思是“具有大精进”，作伴随状态，不是称号。现译“这些大英雄”把它译成了主语称号，词义也偏了。
- **建议**：“他们具有大精进，已经断除了大大小小的恐惧，四处游行，毫无畏缩。”pahīnabhayabheravā 的 nissaya 是 `ဘေးငယ် ဘေးကြီး`（小怖畏、大怖畏），可以据此调整。

## §432 句 169-432-2-8

- **问题**：增译 — nissaya 的解释是：`ယော သာရော= … ဖိုလ်`（作为精髓的果）；`တသ္မိံ= ထိုဖိုလ်အနှစ်ကြောင့်`；`အပရပစ္စယာ= (မိမိမှတစ်ပါး) အခြားယုံကြည်စေအပ်သူမရှိကုန်`（不需要别人使他们相信）。注里还引了“tasmiṃ ariyaphale na aññaṃ pattiyāyanti”。原文没有“已经亲自证知”这个成分，属于增译。
- **建议**：删掉增译，改为“对于梵行的精髓，他们不必依靠别人而相信。”

## §435–436 句 169-435-2-12

- **问题**：词义 — nissaya 对 tiriyaṃ 的解释是 `ယင်း ၂-ခုတို့၏အလယ်၌`（这两者的中间），以身体上下为界：uddhaṃ 是从发梢往上，apācīnaṃ 是脚底往下。注里另记的异释是过去、未来、现在。现译“四方”是按世界方位理解的，与 nissaya 的两种解释都不合。
- **建议**：“在上、在中间、在下，他们都没有喜爱（nandī）；”保持巴利原文的词序 uddhaṃ → tiriyaṃ → apācīnaṃ。

## §436 句 169-436-2-12

- **问题**：句法（必改） — nissaya 补出了 `(ဣတိ= ဤသို့)`，把 `ဗုဒ္ဓါ= ဘုရားရှင်တို့သည်`（主格）和 `အနုတ္တရာ= မိမိထက် သာလွန်သူမရှိကုန်`（表语）解读为狮子吼的内容，然后才接 `တေ= ထိုရဟန္တာတို့သည် … သီဟနာဒံ … နဒန္တိ`。现译“他们发出狮子吼，是世间无上的觉悟者”把 buddhā 当成了 te 的同位语，主谓关系错了。
- **建议**：“他们发出狮子吼：‘觉悟者在世间是无上的。’”最后补上闭合的全角引号”。
