# Review — 169:1424-1433（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ❌（未注入）
> 本批为本文（mūla），无父层，不做被解释词对照。缺义注，下列涉及取义的意见都是**存疑项**，需取 SN 34 义注核对后才能定案。

## 跨段一致性

- **samādhismiṃ … kusala** 句式（§1425 / §1427 / §1429）：译作「善于所缘」「善于行处」「善于引发」，都是「善于 + 名词」，不太合汉语习惯。「善于」后面通常接动词（善于入定），接名词时读者难以明白「善于所缘」指什么。建议三经统一改为「善巧于所缘」「善巧于行处」「善巧于引发」，或统一补一个动词（如「善于把握所缘」）。无论选哪种，三经必须同式。
- **samādhismiṃ**：四句都重复译作「在定方面」，而且同一句前后分句各出现一次（如「在定方面善于入定，但在定方面不善于所缘」）。原文确实重复了，但汉语读来冗赘。如要精简，§1425–§1433 全部 20 句必须同时改，不能只改一部分。
- **samāpatti「入定」与 samādhi「定」**：两词都含「定」字，「在定方面善于入定」容易被读成同义反复。可以考虑 samāpatti 首次出现时夹注巴利原词，即「入定（samāpatti）」，放在 §1425 首句或经题。本 saṃyutta 前 13 经如已定了译法，以前文为准。
- **经题中的 mūlaka**（§1424 / §1426 / §1428 / §1430 / §1432）：「入定与X经」省掉了 -mūlaka（以入定为基准的系列）。五题一致，本身没有问题，但要与同品前面的 Samādhimūlaka… 各经题的译法核对是否同式。
- 其余重复句式（「因缘在舍卫城」「有这四种禅修者」「是哪四种呢」「比丘们，这里又有一类禅修者」「在这四种禅修者当中……（中略）……也是最殊胜的」「第十X经」）各段一致，无问题。

## §1429 句 169-1429-19-33（同段 34-48 / 49-65 / 66-81，及经题 169-1428-2-4）
- **问题**：取义存疑。abhinīhāra 本义是「导向、发愿、专注于」，英译通行作 resolution / directing the mind。「引发」偏向「引起、生起」，可能把意思译偏了。
- **建议**：取义注核对 abhinīhārakusala 的解释，候选译法有「导向」「转向」。定案后五处（含经题）一起改，并写进 `terms.md`。

## §1427 句 169-1427-20-34（同段 35-49 / 50-66 / 67-83，及经题 169-1426-2-4）
- **问题**：取义存疑。gocara 在禅修语境下，义注通常另有专指，可能指业处，也可能指托钵行处。「行处」字面没有错，但读者不明所指。
- **建议**：取义注核对。若义注确有专指，可在首次出现时夹注巴利原词，或加段后注释说明。

## §1431 句 169-1431-19-32（同段 33-47 / 48-64 / 65-80，及经题 169-1430-2-4）
- **问题**：取义存疑。sakkaccakārī 在修习语境下，一般理解为「认真、彻底地做」（英译 works carefully），「恭敬」偏重对人的敬意，放在「修定」上略显不合。
- **建议**：取义注核对。若义注解作「认真、专注地修习」，改为「认真地修习」，经题相应改为「入定与认真经」之类。

## §1425 句 169-1425-81-90（§1427 / §1429 / §1431 / §1433 同句）
- **问题**：补出成分。原文只有 Tatra … pe … pavaro ca，「这四种禅修者」是按完整套语补出的，处理合理。「也是最殊胜的」对应 pavaro ca，也没有问题。
- **建议**：维持不改，仅记录备查。
