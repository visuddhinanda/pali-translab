# Review — 169:1430-1443（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅 §1437、§1439、§1441、§1443 的结语句有 nissaya）

## 跨段一致性
- **ekacco jhāyī**：§1431、§1433 译“一类禅修者”，§1435、§1437、§1439 译“一种禅修者” → 建议统一为“一类禅修者”。ekacca 指“某些人”，说的是人，不是种类；而且“四种禅修者”已经用了“种”，再用“一种”会和分类混在一起。
- **samāpattimūlaka（经题）**：§1430 译“入定与认真经”，§1432 译“入定与持续经”，§1434 译“以入定为首的做适宜事经”。§1434 的结语“以入定为首”和 §1436、§1438、§1440、§1442 的“以住定／出定／调柔／所缘为首的…经”都用了 mūlaka = “以…为首” → 建议 §1430、§1432 改为“以入定为首的认真经”“以入定为首的持续经”。依据是 nissaya 对 mūlaka 的处理：`ပုရိမမူလကာနိ ဝိယ= ရှေးဖြစ်သော မူလကတို့ကဲ့သို့`，即把 mūlaka 作为成组的“以某项为根本”来理解。
- **pavaro**：§1431-81-90、§1433-83-92 的“…pe… pavaro cā”译“也是最殊胜的”，而 §1435 的完整句中 seṭṭho = “最殊胜的”、pavaro = “最卓越的” → 这两处的 pavaro 应改为“最卓越的”，否则会和 seṭṭho 混同。
- **pe 的译法**：§1431、§1433 译“（中略）”，§1437、§1439、§1441、§1443 译“（略）” → 建议统一为一种，比如都用“（略）”。
- **省略句的处理不一致**：§1431、§1433 的 Tatra…pe… 只保留 pavaro，译成“……也是最殊胜的”；§1437 等保留 uttamo ca pavaro ca，译成“……最高的、最卓越的”。这两种处理分别对应原文，各自都不错。但 §1431、§1433 的“也是”是原文没有的词，建议改成和后面一致的形式：“……（略）……最卓越的。”

## §1437 句 169-1437-100-115
- 对照 nissaya 核查：`ပုရိမမူလကာနိ ဝိယ`（像前面的各组 mūlaka）、`ယာဝ … ၂၇-သုတ်မြောက်…တိုင်အောင်`（直到第 27 经）、`အဋ္ဌ သုတ္တာနိ= ၈-သုတ်တို့ကို`（八经，宾格）、`ပူရေတဗ္ဗာနိ`（应补全，被动义务分词）。译文“这八部经都要依样补全”与这些格位和语态都吻合，没有问题。nissaya 开头的说明句（“这些经以 ṭhitikusalo 为根本”）是注者自己的话，不属于本文，译文没有译进去，处理正确。

## §1443 句 169-1443-64-79
- **问题**：原文疑问／资源错位，不是译文问题。这一条 nissaya 和本句巴利原文对不上：nissaya 写的是 `ဧကူနပညာသမံ`（第四十九）、`ဂေါစရမူလကံ`（以行处为首），说明文字也是“以 gocarakusalo 为根本，引出 abhinīhārakusalo 等”。但本句原文是 Ekacattālīsamaṃ（第四十一）和 Ārammaṇamūlakaṃ（以所缘为首）。可见这条 nissaya 应属于下一组（gocaramūlaka）的结语，是挂错了坐标。
- **建议**：译文按巴利原文译为“第四十一经……第四十五经……五部经……以所缘为首”，是正确的，不要按这条 nissaya 修改。这个错位应记入 `known-issues.md` 的“OCR / 原文问题”，供以后核对 nissaya 坐标时参考。
