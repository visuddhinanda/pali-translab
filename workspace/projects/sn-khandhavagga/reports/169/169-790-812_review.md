# Review — 169:790-812（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅 §792、§798 两处经末标记有 nissaya）

## 跨段一致性

本 chunk 是同一组问答（无明／明）的七次重复。前半（§791–801）和后半（§803–812）出自两种译法，句式在重复处明显分裂，必须统一。

- **avijjāgato / vijjāgato**：§792、§797、§798 译“进入了无明”，§795、§800、§801 译“进入了明”；§803、§804、§809、§810 译“陷入了无明”，§806、§807、§811、§812 译“达到了明”。
  - 同一个 -gata 在后半按褒贬分成两个动词，在前半是一个动词。
  - 建议统一为“进入了无明／进入了明”。理由：一词一译，出现次数也更多。
- **kittāvatā**：§791、§794、§797、§800 译“到什么程度才算是”，§803、§806、§809、§811 译“怎样才算是”。
  - 建议统一为“到什么程度才算是”。它与 ettāvatā“到这个程度”成对，更贴合 -āvatā 的量度义。
- **ettāvatā**：§792、§795、§798、§801 译“到这个程度，就算是”，§804、§807、§810、§812 译“这样就算是”。
  - 建议统一为“到这个程度，就算是”。
- **assutavā puthujjano**：§792、§798 译“没有听闻正法的凡夫”，§804、§810 译“无闻的凡夫”。
  - 建议统一为“没有听闻正法的凡夫”。“无闻”偏文言。
- **sutavā ariyasāvako**：§795、§801 译“听闻正法的圣弟子”，§807、§812 译“多闻的圣弟子”。
  - 建议统一为“听闻正法的圣弟子”，与 assutavā 形成对称。“多闻”另对应 bahussuta，不宜混用。
- **vuccati**：前半作“叫做”，§804、§807、§810、§812 作“叫作”。
  - 建议统一为一种写法。
- **pe（省略）**：前半只用“……”，§803、§804、§806、§807、§809、§810、§812 作“……（略）……”。
  - 建议统一为“……”。
- **经末标记**：§792、§795、§798、§801 作“第二经。”等，§804、§807、§812 作“第六经完。”等。
  - 原文都只是序数词，建议统一为“第X经。”，不加“完”。
- **ekamantaṃ nisinno … etadavoca**：§791、§794、§797 作“坐在一旁后，尊者摩诃拘絺罗对……说”，§806、§809 作“坐在一旁的尊者摩诃拘絺罗／舍利弗对……说”。
  - 建议统一为前一种。
- **开篇省略主语**：§797、§800 作“……住在波罗奈……”，没有补出主语；§803、§806、§809 补了“他们住在……”。
  - 建议统一。原文无主语，可统一不补，或统一补作“他们”。
- **五蕴略说句式**：§798、§801 作“也（不能）如实了知受……想……诸行……识的乐味、过患和出离”；§804、§807、§810、§812 作“对于受……想……诸行……识，他（不能）如实了知它们各自的……”。
  - 原文 Vedanāya … viññāṇassa 是属格，修饰 assādañca 等，并不是“对于”。
  - 建议统一为前一种属格结构，并删去后半补出的“他”和“各自”。

## §792 句 169-792-103-104

- **问题**：无。
- nissaya 注明本段与前经体例相同，`ဒုတိယံ တတိယံ= တည်း။` 只是序数后加系词，译“第二经。”与原文一致。

## §798 句 169-798-42-43

- **问题**：原文对齐疑问，记录备查，不改译文。
- 该 nissaya 单元除 `စတုတ္ထံ=` 外，还连带出了以下内容：
  - `ပ။ ဒသမံ= တည်း။`，即“……第十”；
  - `အဝိဇ္ဇာဝဂ္ဂေါ= သည်။ တတိယော= တည်း။`，即“无明品第三”；
  - 品末摄颂（uddāna）的全部逐词释义：`တီဏိ` / `သမုဒယဓမ္မေ` / `အဿာဒေါ` / `အပရေဒုဝေ` / `သမုဒယေ` / `ဒွေ စ` / `ကောဋ္ဌိကေ` / `အပရေ တယော`。
- 这些内容在本段 pali（仅 “Catutthaṃ .”）中都没有，应属于本品末（第十经之后）的品名与摄颂段落。nissaya 底本在此把后文合并到了第四经末。
- 译文“第四经。”与本段原文一致，无须改。
- **建议**：审到品末时，按本 nissaya 核对品名“无明品第三”和摄颂译文。摄颂的经数分组如下：
  - 生起法三经；
  - 乐味二经；
  - 集起二经；
  - 拘絺罗三经。
- 这一分组也印证了本 chunk 各经标题的对应关系：“生起法经”系列、“乐味经”系列、“集起经”系列、“拘絺罗经”系列。
