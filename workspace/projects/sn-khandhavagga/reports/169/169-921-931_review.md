# Review — 169:921-931（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本作业没有提供 nissaya，词级格位核对降级为只看巴利原文）／义注 ✅（book 135 §408–411《Mārasuttādivaṇṇanā》，只有原文，没有中译）
>
> 注入数据的问题：义注各行的 `layer` 字段标成了 `mula`，实际内容是义注（book 135），请在执行层修正标注。本层是本文，没有父层，所以不查被解释词是否与父层逐字同译。义注译出后，要反过来核对义注里的黑体词 **māro**、**rūpaṃ kho rādha māro**、**māradhammo** 与本文的译法是否一致（见 §924 / §925 两条）。

## 跨段一致性
- **-dhamma 复合词，经名和正文译法不一致**：§924 经名译“魔法经”，§925 正文译“魔的法”；§928 经名译“无常法经”，§929 正文译“无常的法”。建议经名和正文用同一个结构，统一方案见 §924 / §925 两条。
- **-dhamma 复合词的解读要全品统一**：义注说“**māradhammo**ti maraṇadhammo. Etenupāyena sabbattha attho veditabbo”，意思是其余各经的 -dhamma 都按同一方式理解。§925 的 māradhammo 和 §929 的 aniccadhammo 应采用同一种结构（“会……的／有……性质的”）。本品后面的 dukkhadhamma、anattadhamma 等也要照此处理。
- **māra 的所指**：各段一律译作“魔”，写法本身一致，但义注有专门的释义，处理见 §923 句 169-923-19-31。

## §923 句 169-923-19-31
- **问题**：释义 — 按义注，这里的 māra 指死亡。**义注**：“māro, māro ti maraṇaṃ pucchati. Yasmā pana rūpādivinimuttaṃ maraṇaṃ nāma natthi, tenassa bhagavā rūpaṃ kho, rādha, māro tiādimāha”（罗陀问的“魔”是死亡；离开色等五蕴就没有所谓死亡，所以世尊回答“色是魔”等等）。只译“魔”，读者容易理解成魔王、天魔，和义注的解释不合。
- **建议**：“魔”是传统译法，经文里可以保留，但必须在首次出现处（本句或 §922 经名）加脚注，说明“**义注**：这里的魔指死亡（maraṇa）”，交给 footnote 步处理。本经其他各句的“魔”保持不变。

## §924 句 169-924-2-4
- **问题**：误导性译名 — “魔法经”在现代汉语里很容易读成“魔法（magic）经”，违反 style.md“把译文读给现代读者”的判定标准。另外，按义注 māradhammo = maraṇadhammo，这是“具有死亡性质”的复合词（多财释），不是“魔的法”。
- **建议**：改为“会死之法经”或“死法经”，与 §925 正文的改法保持一致。

## §925 句 169-925-17-29、169-925-30-40、169-925-41-61
- **问题**：释义错误（属格误读）— “魔的法”把 māradhamma 读成了“属于魔的东西”。**义注**：“**māradhammo**ti maraṇadhammo”，意思是“会死的、受死亡支配的”，与 aniccadhamma（“会无常的”）结构相同。
- **建议**：改为“会死的（法）”，例如“人们常说‘会死的、会死的’”“到底什么是会死的呢？”“色是会死的，受是会死的……”。如果想保留“魔”字，可以译作“受魔（死亡）支配的”，但措辞要全文统一，并加脚注引义注。

## §928 句 169-928-2-4
- **问题**：跨段不一致 — 经名作“无常法经”，正文作“无常的法”。
- **建议**：与 §924 的改法保持同一格式，例如“会无常之法经”或“无常性经”。定下以后，全品的 -dhamma 经名都照此处理。

## §929 句 169-929-16-28、169-929-29-39、169-929-40-61
- **问题**：释义 — “无常的法”读起来像“（关于）无常的教法”，没有表达出“具有无常性质”的意思。**义注**要求所有 -dhamma 复合词都比照 māradhammo = maraṇadhammo 来理解（“Etenupāyena sabbattha attho veditabbo”）。
- **建议**：改为“会无常的”或“具有无常性质的”，例如“色具有无常的性质，受具有无常的性质……”。句式与 §925 保持平行。
