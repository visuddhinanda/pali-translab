# Review — 169:1404-1415（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（各经 nissaya 只附在经末“第N经”一行，用 `ဤသုတ်၌` 给出本经关键词的释义；下面按本经正文里该词出现的句子出意见）

## 跨段一致性

- **samādhikusalo**：§1405（第4经）译“善于辨明定”，§1407–1415（第5–9经）译“善于定” → 建议统一为“善于定”。本组十经是同一套句型，只换后半的复合词，前半应当逐字一致；§1405 的“辨明”在 nissaya 中没有对应。
- **samādhismiṃ**：§1405–1413 译“在定方面”，§1415 译“在定上” → 建议统一为“在定方面”。§1415 还把“在定上”重复放进每个分句（“不在定上善于定”），与其他各经句式不同，应一并对齐。
- **ekacco**：§1405、§1415 译“有的（禅修者）”，§1407–1413 译“有一类（禅修者）” → 统一为“有一类”。§1415 另多出“这里又有的”，其他各经是“又有一类”，“idha pana”的译法也应统一。
- **aggo ca seṭṭho ca mokkho ca uttamo ca pavaro ca**（五个形容词并列）：
  - §1405 译“最上的、最胜的、首要的、最高的、最优的”
  - §1407–1413 译“最上、最胜、最首要、最高、最殊妙”
  - §1415 译“最首要的、最殊胜的、最主要的、最高的、最卓越的”
  - → 统一为§1407–1413 的译法（出现次数最多）。§1415 把 aggo 译成“最首要”、把 mokkho 译成“最主要”，与其他各经的词义对应错了位，必须改。
- **Seyyathāpi … gavā khīraṃ … pe …**：
  - §1405 译“就像从牛产出乳……乃至……最优的”
  - §1407–1413 译“譬如从牛产生乳……乃至……最殊妙的”
  - §1415 译“就好比从牛产出牛奶……（略）……最卓越的”
  - → 统一为“譬如从牛产生乳……乃至……最殊妙的”。“pe”统一译“乃至”，不用“（略）”。
- **Sāvatthinidānaṃ**：§1405 译“因缘发生在舍卫城”，其余各经译“因缘在舍卫城” → 统一为后者。
- **Katame cattāro**：§1415 译“哪四种呢？”，其余各经译“是哪四种呢？” → 统一为“是哪四种呢？”。
- **经题里的 Samādhimūlaka-**：§1404 译“定与调心经”，§1406–1414 都译“以定为根本的…经” → §1404 改为“以定为根本的…经”的格式（具体用词见下文 §1405 kallita 一条）。
- **总结句的结构**：§1405 用“在这四种禅修者当中，……的禅修者，是最上的……”，§1407–1415 用“其中那位……的禅修者，是这四种禅修者中最上……” → 统一为后者。
- **经题与正文用词**：§1412 经题译“恭敬实行”，正文译“恭敬认真地实行” → 建议两处一致。第9经的题目与正文都用“持续用功”，可以作参照。

## §1405 句 169-1405-19-32 / 33-47 / 48-65 / 66-81 / 82-110（kallitakusalo）

- **问题**：词义偏移。“调心”的意思是驯服、调伏心，而 nissaya 释的是心已经处于适宜、能用的状态，并在这种状态上善巧。依据如下：
  - nissaya 释为 `ကလ္လိတကုသလော= ပြစ်သော ခန့်ကျန်းမှုရှိသောစိတ်၌ လိမ်မာသည်`，意为“在具有健全、堪任状态的心上善巧”。
  - nissaya 所引**义注**：`cittaṃ hāsetvā kallaṃ kātuṃ akusalo`，意为“不善于使心欢喜，从而使它堪任”。
  - nissaya 所引**复注**：`kallaṃ jātaṃ assāti kallitaṃ`，意为“生起了堪任性，所以叫 kallita”。
  - 另外，`စိတ်၌` 是处格，说明“善巧”的对象是心的这种状态。
- **建议**：改为“善于使心堪任”（或“善于令心适宜”）。§1404 经题相应改为“以定为根本的堪任经”。五句里同一个词要同步修改。

## §1407 句 169-1407-20-33 / 34-48 / 49-65 / 66-82 / 83-110（ārammaṇakusalo）

- **问题**：所指偏窄，不算错，属于轻微问题。nissaya 释为 `ကသိုဏ်းအာရုံတို့၌ လိမ်မာသည်`，意为“在诸遍处所缘上善巧”，处格、复数，明确指遍处（kasiṇa）所缘。译文只说“善于所缘”，读者不容易知道指什么。
- **建议**：正文可以保留“所缘”。首次出现时，按 style.md 加段后注，说明“指遍处等所缘”。

## §1409 句 169-1409-19-32 / 33-47 / 48-65 / 66-81 / 82-109（gocarakusalo）

- **问题**：一词两指，提示性意见。nissaya 释为 `ကမ္မဋ္ဌာန်းဟူသော ကျက်စားရာ, ဆွမ်းခံလှည့်လည်ရာဟူသော ကျက်စားရာ၌ လိမ်မာသည်`，意为“在业处这一行处、在托钵游行处这一行处都善巧”，并列给出两种所指。“行处”这个译法可以保留。
- **建议**：首次出现时加段后注，说明两种所指（业处、托钵游行处）。正文不改。

## §1411 句 169-1411-20-33 / 34-48 / 49-67 / 68-83 / 84-111（abhinīhārakusalo）

- **问题**：缺了方向和对象。nissaya 释为 `ကမ္မဋ္ဌာန်းသို့ ရှေးရှူဆောင်ခြင်း၌ လိမ်မာသည်`，意为“在把心朝向业处引去这件事上善巧”，`သို့` 是向格，标出了方向。译文“善于引导”没有对象，容易被读成引导他人。
- **建议**：改为“善于（把心）导向（业处）”，正文可以简作“善于导向”。§1410 经题相应改为“以定为根本的导向经”。五句要同步修改。

## §1413 句 169-1413-19-32 / 33-47 / 48-64 / 65-81 / 82-109（sakkaccakārī）

- **问题**：缺了隐含成分，属于轻微问题。nissaya 释为 `ဈာန်ကို ဝင်စားခြင်းငှါ ရိုသေစွာပြုလေ့ရှိသည်`，意为“为了入禅，习惯于恭敬地去做”。这里有两点：
  - `ငှါ` 是目的格，补出了“为入禅”这个目的。
  - `လေ့ရှိ` 表示惯常体，对应 -kārī 的惯常施事义。
  - 译文“恭敬认真地实行”没有宾语，“实行”什么不清楚。“认真”在 nissaya 中也没有对应。
- **建议**：改为“恭敬地修习”。也可以首次出现时加注，说明“指为入禅而恭敬地修习”。经题与正文要统一。

## §1415 句 169-1415-19-32 / 33-47 / 48-66 / 67-82 / 83-111（sātaccakārī）

- **问题**：同样缺了隐含成分，属于轻微问题。nissaya 释为 `ဈာန်ကို ဝင်စားခြင်းငှါ အမြဲမပြတ်ပြုလေ့ရှိသည်`，意为“为了入禅，习惯于不间断地去做”，与第8经的结构平行。
- **建议**：正文“持续用功”可以保留。如果第8经采用加注的处理方式，本经也加同样格式的注（“指为入禅而持续用功”），让两经保持平行。

## §1415 句 169-1415-83-111

- **问题**：词义错位，是必改项。aggo 译成了“最首要的”，mokkho 译成了“最主要的”，与其他各经“最上 / 最首要”的对应关系相反。
- **建议**：改为“是这四种禅修者中最上、最胜、最首要、最高、最殊妙的”。
