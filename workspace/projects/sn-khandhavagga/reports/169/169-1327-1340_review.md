# Review — 169:1327-1340（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§1334 全段有；其余各段只有经末“第 N 经”一句有）

## 跨段一致性

- **天众名（-valāhakā devā）**：§1328 译“云天众”，§1330／§1332／§1334 译“冷云天／热云天／阴云天／风云天／雨云天”，§1336／§1338／§1340 译“热云天神／阴云天神／风云天神”并夹注巴利原词。
  → 建议统一为“X云天”，去掉“神”字。
  → 夹注已在后文出现，不符合“首次出现夹注”的规则。§1332 已经出现过“热云天”“阴云天”“风云天”且没有夹注，因此 §1336／§1338／§1340 的夹注应删去。如需夹注，应放在 §1328 首次出现的 valāhakakāyikā 处。
- **经题**：§1333 译“冷云天经”，§1335／§1337／§1339 译“热云经／阴云经／风云经”。
  → 建议统一为“热云天经／阴云天经／风云天经”，与 §1333 及正文的天众名一致。
- **品题加字**：§1329 题“冷云天布施助益十经”，§1331 题“热云天等布施助益四十经”。巴利 Uṇhavalāhaka- 没有“等”。
  → 建议去掉“等”，与 §1329 同构。如果想表明这四十经包括四类天，应写进审稿说明，不要加在题目里。
- **Ekamantaṃ nisinno kho so bhikkhu bhagavantaṃ etadavoca**：§1328／§1330／§1332／§1334 译“那位比丘在一旁坐下后，对世尊这样说”，§1336／§1338／§1340 译“坐在一边的那位比丘对世尊这样说”。
  → 建议统一为前者。依据是出现次数较多，并且 nissaya `နိသိန္နော= နေသော` 只表示已坐，两种译法都可以，取多数即可。
- **Tesaṃ yadā evaṃ hoti**：§1334 译“当他们心里这样想：”，§1336／§1338／§1340 译“当他们这样想：”。
  → 建议统一为“当他们心里这样想：”，与经内另一句 Tassa evaṃ hoti 的译法“他心里这样想”一致。
- **sakāya ratiyā vaseyyāma**：§1334 译“按自己的喜好过日子”，§1336／§1338／§1340 译“沉浸在自己的欢乐中度日”。nissaya 为 `ရတိယာ= မွေ့လျော်ခြင်းဖြင့်`，意思是以喜乐、享乐的方式，属具格，是享受，不是“喜好”（偏好）。
  → 建议统一为“我们不如享受自己的喜乐过日子吧”。“沉浸在……中度日”也可以接受，但四经须一律。
- **taṃ cetopaṇidhiṃ anvāya**：§1334 译“由于他们的这个心愿”，§1336／§1338／§1340 译“随着他们心中的这个意愿”。nissaya 为 `အနွာယ= စွဲ၍`，意思是依于、凭借，表示因由，不表示伴随。
  → 建议统一为“由于他们的这个心愿”。“随着”带出时间上的伴随义，偏离了 nissaya 所给的依止义。
- **yenekadā … hotī 问句**：§1334 译“使得天气有时会变冷？”，§1336／§1338／§1340 译“使得有时候天气炎热呢？”等，“有时／有时候”的位置不同，句末“呢”也有有无之别。
  → 建议统一为“使得有时候 X 呢？”这一句式，答句同步调整。
- **Santi … nāma devā**：§1334 译“有一类天神名叫冷云天。”，§1336／§1338／§1340 译“有一类天神，叫作热云天神（…）。”
  → 建议统一为“有一类天神，名叫 X 云天。”

## §1334 句 169-1334-52-81

- **问题**：词法／取义。“按自己的喜好”把 `ရတိယာ= မွေ့လျော်ခြင်းဖြင့်`（以喜乐的方式，具格）译成了“偏好”，失去了享乐的意思。另外，`သကာယ= မိမိဥစ္စာဖြစ်သော` 是修饰 ratiyā 的“属于自己的”，作“自己的喜乐”讲，不是“自己的意愿”。
- **建议**：改为“‘我们不如享受自己的喜乐过日子吧’的时候，由于他们的这个心愿，天气就会变冷。”与 §1336／§1338／§1340 的统一译法保持一致，见上节。

## §1336 句 169-1336-53-67 ／ §1338 句 169-1338-51-65 ／ §1340 句 169-1340-53-67

- **问题**：词法。cetopaṇidhiṃ anvāya 译作“随着……意愿”，“随着”表示伴随。§1334 的 nissaya `အနွာယ= စွဲ၍` 表示依于、因为，这三句与 §1334 句式完全相同，应据此统一。
- **建议**：三处都改为“由于他们的这个心愿，……”

## §1338 句 169-1338-16-35 ／ 169-1338-51-65 ／ 169-1338-66-82

- **问题**：取义偏窄。nissaya 为 `အဗ္ဘံ၊ တိမ်သည်`，即“云（主格）”，说的是起云、有云。译文“天色转阴”能说得通，但把主语从“云”换成了“天色”，比较间接。
- **建议**：可以保留。如果要更贴近 nissaya，可改为“天空会起云”，三句同步修改。
