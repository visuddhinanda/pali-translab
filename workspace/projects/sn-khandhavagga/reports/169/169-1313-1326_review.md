# Review — 169:1313-1326（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（只覆盖部分句；没有 nissaya 的句子不出意见）

## 跨段一致性

- **pe**：§1314 译“……（略）……”，§1316 译“……（略）……”，§1318 译“……乃至……” → 建议统一为“……（略）……”。“乃至”偏文言，而且本 chunk 里多数段用的是“（略）”。
- **pheggugandha**：§1314 译“白木香”，§1318 译“边材香” → 建议统一，二选一。pheggu 指心材外层的软木，“边材”更贴近原义。
- **rasagandha**：§1314 译“汁香”，§1318 译“汁液香” → 建议统一为“汁液香”，这样与“心材香 / 树皮香”等双音节加“香”的格式一致。
- **gandhagandha**：§1314 译“香的香”，§1318 译“香料香” → 必改。两处必须统一。“香的香”读起来不通，建议统一为“香料香”。
- **kāyassa bhedā**：§1314、§1316 译“身体毁坏”，§1318 译“身体崩坏” → 建议统一为“身体毁坏”，出现次数多。
- **ekacco**：§1314、§1316 译“有人”，§1318 译“某人 / 这里的某人” → 建议统一为“这里有人”。
- **yena midhekacco … upapajjati**：§1314、§1316 译“使这里有人……”，§1318 译“使得这里的某人……” → 随上一条一起统一。
- **sucaritaṃ carati**：§1314、§1316 译“做善行”，§1318 译“行善” → 建议统一。
- **Ekamantaṃ nisinno**：§1314、§1316 译“在一旁坐下后”，§1318 译“坐在一旁后” → 建议统一为“在一旁坐下后”。
- **dīghāyukā vaṇṇavanto sukhabahulā**：§1314、§1316 译“寿命长，容貌美好，享有很多快乐”，§1318 译“寿命长久、容貌美好、充满快乐” → 建议统一，标点也要统一（逗号还是顿号）。
- **seyyaṃ**：§1316 译“床座”，§1318 译“床铺” → 建议统一为“床座”。
- **padīpeyyaṃ**：§1316 译“灯明”，§1318 译“灯火” → 建议统一为“灯明”（理由见下文 §1316 一条）。
- **愿望句句末标点**：§1314、§1316 的 ‘…’ 以句号收尾，§1318 用感叹号“！” → 建议统一。
- **Suddhika(sutta)**：§1322 摄颂译“纯粹经”，§1325 经题译“单纯经” → 建议全书统一为一个译名。摄颂里的“纯粹经”还要与乾闼婆众相应第一经的实际经题（不在本 chunk）逐字相同。
- **dātā**：§1313 品题译“布施者”，§1322 摄颂译“施者经” → 建议统一为“布施者”，让摄颂与品题对得上。
- **devā**：乾闼婆众相应（§1314–1318）译“天神”，云天相应（§1326）的各类 valāhaka devā 都只译“…天”，“valāhakakāyikā devā”译“云天众”，devā 没有单独译出 → 建议统一处理方式（见下文 §1326 各条）。

## §1316 句 169-1316-96-128

- **问题**：词义（偏窄）— 依据是 §1316 段末的 nissaya（169-1316-165-166）对本句的补释：`ပဒီပေယျံ= ဆီမီး၏အစီးအပွါး ဆီ, မီးစာစသည်ကို`，意思是“灯所需的东西：油、灯芯等”。padīpeyya 指供灯用的物品，不是火光本身。§1318 译作“灯火”，偏离了这个意思。
- **建议**：两段统一译为“灯明”（传统译法，能涵盖灯用物品）。不要用“灯火”。

## §1322–1323 句 169-1322-2-9 / 169-1323-2-7

- **问题**：句法（谓语管辖范围）— nissaya 的分析是：`သုဒ္ဓိကဉ္စ= သုဒ္ဓိကသုတ်ကို၎င်း`、`သုစရိတံ= …၎င်း`、`ဒါတာ= …၎င်း`、`ဒါနူပကာရာ= …၎င်း` 四项由 `၎င်း`（“以及”）并列，共同接谓语 `သုပ္ပကာသိဘာ= ကောင်းစွာပြအပ်ကုန်ပြီ`（都已善为宣说）。现在的译文是“布施助益经一百部，在乾闼婆众相应中已经讲得很清楚”，读起来像只有“布施助益经”被讲清楚，前面三项落了空。
- **建议**：在 §1323 让谓语明确统摄全部。例如：“布施助益经一百部——这些都在乾闼婆众相应中讲得很清楚。”§1322 保持列举。

## §1326 句 169-1326-12-21

- **问题**：成分省并 — nissaya：`ဝလာဟကကာယိကေ= ဝလာဟကအမည်ရှိသော နတ်အပေါင်း၌ဖြစ်ကုန်သော`（属于名为 valāhaka 的天众的〔修饰语〕），`ဒေဝေ= ကောင်းကင်၌ကျက်စားကုန်သောနတ်တို့ကို`（诸天〔宾格中心词〕）。原文结构是“属于云天众的诸天”，kāyika 是修饰语，devā 才是宾语中心。现在的译文“讲说云天众”把中心词 deve 并进了“众”字。
- **建议**：译成“比丘们，我要为你们讲说属于云天众的天神。”或者把 valāhakakāyikā devā 定为“云天众的天神”，后面各句随之统一。

## §1326 句 169-1326-22-24

- **问题**：漏译成分 — nissaya：`တံ= ထိုတရားဒေသနာတော်ကို`（那个教说〔宾格〕）。宾语 taṃ 没有译出。
- **建议**：“你们要听这个教说。”或“你们听吧”。至少要让“听”的对象有着落。这一条优先级低。

## §1326 句 169-1326-25-32

- **问题**：主语中心词 — nissaya：`ဒေဝါ= နတ်တို့သည်`（诸天〔主格〕），`ဝလာဟကကာယိကာ= …ယှဉ်ကုန်သော`（属于……的〔修饰语〕）。“什么是云天众”把主语从“天神们”换成了“天众”。
- **建议**：“比丘们，什么是属于云天众的天神呢？”要与 12-21 句的定稿译法一致。

## §1326 句 169-1326-33-39 至 169-1326-52-68

- **问题**：中心词 devā 未单独译出 — nissaya 对每一类都分两层：`သီတဝလာဟကာ= အအေးကိုပြုလုပ်ဆောင်ကြဉ်းတတ်သောကြောင့် သီတဝလာဟကမည်ကုန်သော`（因为能造冷，所以名叫冷云的〔修饰语〕），`ဒေဝါ= …နတ်တို့သည်`（天神们〔主格〕）。热、阴、风、雨四类同理。“冷云天”这类译法可以当作专名，但和前文“……的天神”的格式不统一。另外，52-68 句里的 `ဣမေ= ဤနတ်တို့ကို`（这些天神〔宾格〕）、`ဒေဝါ= …တို့ဟူ၍`（称为“……天神”），被称呼的对象同样是天神。
- **建议**：定一个格式全章通用。可以都译作“冷云天神 / 热云天神 / 阴云天神 / 风云天神 / 雨云天神”，结句为“这些就叫作‘属于云天众的天神’”。也可以保留“…天”的简称，但要在 12-21 首次出现时明确“云天众的天神”，后面不再变动。
