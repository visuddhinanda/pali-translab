## 理由

**依据有缺失。** 本次注入的数据只有巴利原文和现有译文，没有义注和 nissaya。所以准确性只按巴利原文核对，没有逐词对照 nissaya 的格位，也没有核对义注的释义。信心指数因此压低。下面凡是涉及义注取义的条目（sāramaya、velāmikā、vatthakoṭi），都应在补齐义注后复核。

**准确性。** 整段是重复句式：“在那八万四千……之中，我那时……的只有一……”。各句都把主语、谓语、宾语和“tena samayena”（那时）对应得很好，关系从句 yamahaṃ … ajjhāvasāmi / paribhuñjāmi / abhiruhāmi / paridahāmi 的动词也分别译成了“居住 / 使用 / 乘坐 / 穿”，没有漏译。最后三句 aniccā / addhuvā / anassāsikā 译为“无常 / 不恒久 / 不能给人慰藉”，结尾 nibbindituṃ / virajjituṃ / vimuccituṃ 译为“厌离 / 离贪 / 解脱”，取义都妥当。扣分的地方有三处：
- 一处限定词可能是多出来的：sāramaya 译成了“红檀木”，限定为“红”色缺少依据。
- 一处有小幅增译：vipariṇatā 译成了“变异而消失”。
- yāvañcidaṃ … alameva 的强调语气没有译出来。

**风格。** 全段是现代书面汉语，没有文言虚词或文言句式。“在……之中”“其中”都是现代常用说法，不扣分。标点统一用全角，引号用弯引号，开头和结尾的引号成对。扣分主要有两点：
- 音译词没有附简注：“纳利”没有任何说明；“韦拉弥迦女”只夹注了巴利原词。
- “八万四千千万套”数字叠在一起，读起来吃力。

**一致性。** 各重复句的句式、称谓（“比丘”）和量词都统一。saṅkhārā 在“所有那些行”和“诸行”两种译法之间切换，前一处是对译 sabbe te，属于合理差异，不算问题。

## 问题清单

### 🟨 warning
- `169-668-65-91`｜错误多译（待义注核实）｜片段「或是红檀木做的」
  - 问题：sāramaya 字面义是“用心材（坚实木料）做的”。原文没有“红”的限定，义注通常把它解释为旃檀心材。译成“红檀木”把所指说得过窄，可能不符合义注。
  - 建议：核对义注后改为“或是旃檀木做的”，或者“或是坚实的心材做的”。
- `169-668-152-174`｜关键词语意不明确，或二意场合没有注释｜片段「韦拉弥迦女（velāmikā）」
  - 问题：这个音译词对一般读者是完全陌生的，只附了巴利原词，没有说明是什么身份，不符合 style.md 中“罕见术语音译，首次出现附简注”的要求。
  - 建议：按义注的解释补一条简注，可以放在脚注里，说明 velāmikā 所指的身份（有注家解释为刹帝利与婆罗门通婚所生的女子，需以义注为准）。
- `169-668-201-227`｜关键词语意不明确，或二意场合没有注释｜片段「一纳利的米饭」
  - 问题：“纳利”（nāḷi）是容量单位，读者无从知道它有多少。
  - 建议：在首次出现处用圆括号夹注巴利原词，再加简注说明它是量米的容量单位，例如：“一纳利（nāḷi，量米的容量单位）的米饭”。

### 🟦 suggestion
- `169-668-175-200`｜复杂的嵌套句整句语言逻辑理解困难｜片段「八万四千千万套衣服」
  - 问题：“八万四千”和“千万”两个数词连在一起，读者很难看出这是 84000 × koṭi，容易读断。
  - 建议：改为“八万四千个千万套衣服”，或者“八万四千千万（koṭi）套衣服”，并按义注核实 koṭi 在这里的所指。
- `169-668-228-239`｜语言表达不够流畅｜片段「变异而消失了」
  - 问题：vipariṇatā 的意思是“变异”，“而消失”是译者增补的，和前面的“灭尽”意思重复。
  - 建议：改为“都已经过去、灭尽、变异了”。
- `169-668-264-281`｜语言表达不够流畅｜片段「这足以让人」
  - 问题：yāvañcidaṃ … alameva 带有强调语气（“实在是足以……”），现在的译文把语气译平了，和上面层层递进的结论衔接偏弱。
  - 建议：改为“比丘，这实在足以让人对一切行生起厌离，足以让人离贪，足以让人解脱。”
