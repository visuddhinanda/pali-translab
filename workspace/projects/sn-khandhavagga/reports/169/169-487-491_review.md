# Review — 169:487-491（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句子）

## 跨段一致性

- **so attā so loko, so pecca bhavissāmi nicco dhuvo sassato avipariṇāmadhammo**：这句在本章出现三次，有两种译法。§489、§490 译“那个我就是世界；死后我将成为那个我——常住、恒久、永恒、不会变异的”，§491 译“自我就是世界；死后我将是常住的、恒久的、永恒的、不会变易的”。avipariṇāmadhamma 也一处作“变异”、一处作“变易”。→ 三处统一，按下文 §489 句 169-489-33-48 的改法改。
- **paṭiccasamuppanna**：§487、§488 译“缘生的”，§491 句 117-128、129-134、135-140、141-146、147-152 译“缘起的”。→ 统一为“缘生的”。“缘起”通常对应 paṭiccasamuppāda，用在这里容易和缘起法混淆。
- **iti kho**：§487、§488 译“这样看来”，§491 句 117-128 译“因此”。nissaya：`ဣတိ ခေါ= ဤသို့လျှင်။`（像这样），不表示因果。→ 统一为“这样看来”。
- **jānato passato … anantarā āsavānaṃ khayo hoti**：§487、§488、§489、§490 都译成“这样知、这样见，（也）能紧接着达到诸漏的灭尽”，以知见者为主语、灭尽为宾语。§491 译“对于这样知道、这样看见的人来说，诸漏的灭尽就紧接着到来”。nissaya 把 jānato、passato 释作属格“知者的／见者的（相续中）”，主语是 `ခယော= …သည်`（灭尽），§491 的结构才对。→ 各段统一按 §491 的句式；“知／见”与“知道／看见”也统一，建议用“知、见”。
- **kiṃnidāno kiṃsamudayo kiṃjātiko kiṃpabhavo**：§487、§490 是四个问号，jātika 译“从什么而生”。§491 句 94-101 用逗号连成一句，并改译“从什么产生”。→ 统一为 §487 的格式。
- **tatojo**：§487、§488、§490 译“从渴爱而生的”，§491 句 113-116 译“从渴爱产生的”。→ 统一为“而生的”。
- **assutavato puthujjanassa / vedayita**：§487、§488、§490 译“没有听闻正法的凡夫被无明触所生的感受触及时”，§491 句 102-112 译“没有听闻过正法的凡夫被无明触所生的受触动时”。→ 统一为前一种。
- **sā / so（taṇhā、vedanā、phasso、avijjā 前的指示词）**：§487、§488 译“那渴爱也……”，§491 译“这个渴爱也……”。→ 统一，建议用“这个”，和“这个行”一致。

## §489 句 169-489-33-48
- **问题**：格与句法有误。nissaya（见 27-32 行）：`သော= ထိုငါသည်။ အတ္တာ= အတ္တတည်း။ သော= ထိုငါသည်။ လောကော= လောကတည်း။ သော= ထိုငါသည်။ ပေစ္စ= တမလွန်ဘဝသို့ရောက်လတ်သော်။ နိစ္စော= မြဲသည်။ … ဘဝိဿာမီတိ= ဖြစ်အံ့`。
  1. 三个 so 都是主格“那个我”。so attā、so loko 是两个并列的判断，即“那就是我（自我）”“那就是世界”。译文把它们并成一句“那个我就是世界”，漏掉了 attā 这个判断。
  2. 第三分句的 so 也是主格主语，nicco dhuvo sassato avipariṇāmadhammo 是 bhavissāmi 的表语。译文“我将成为那个我”把 so 译成了宾语（表语），主宾关系错了。
- **建议**：改为“‘那就是我，那就是世界；那个我死后将是常住的、恒久的、永恒的、不会变异的。’”§490 句 30-46、§491 句 36-51 照此统一。

## §490 句 169-490-30-46
- **问题**：译文和 §489 句 33-48 相同，错误也相同：so 的格读错，attā 的判断被并掉。nissaya 本句以 `ပ` 省略，内容同 §489。
- **建议**：照 §489 的改法改。

## §491 句 169-491-70-79
- **问题**：用词区分不够。nissaya：`ကင်္ခီ= ယုံမှားခြင်းရှိသည်`（有疑惑），`ဝိစိကိစ္ဆီ= မဆုံးဖြတ်နိုင်သောသဘောရှိသည်`（无法下决断）。nissaya 把 vicikicchī 释作“无法下决断”，和 kaṅkhī 不同；译文“疑惑、怀疑”两词几乎同义，区分不出来。saddhamme 是处格，管全部三个词，译文放在句首没有问题。
- **建议**：“但是他对正法心存疑惑、犹豫不决、没有得出定论。”句首“但他”同时改为“但是他”，和 §487、§488、§489、§490 一致。

## §491 句 169-491-80-93
- **问题**：要跟上句同步。nissaya：`ဝိစိကိစ္ဆိတာ= …မဆုံးဖြတ်နိုင်သောသဘောရှိသည်၏အဖြစ်`（无法下决断的状态）。上句如果改，这里也要改，否则这几个词的对应就断了。另外“没有定论”与上句“没有得出定论”不一致。
- **建议**：“比丘们，这种对正法的疑惑、犹豫不决和没有得出定论，就是行。”

## §491 句 169-491-117-128
- **问题**：iti kho 和 paṭiccasamuppanna 的译法与前几段不一致，见“跨段一致性”。
- **建议**：“比丘们，这样看来，这个行也是无常的、有为的、缘生的。”

## §491 句 169-491-94-101
- **问题**：标点和用词与 §487、§490 不一致（逗号连句；“从什么产生”）。
- **建议**：“那么，这个行以什么为因缘？以什么为集起？从什么而生？以什么为根源？”

## §489 句 169-489-61-80 / §490 句 169-490-101-124
- **问题**：句法结构不对。nissaya：`ဇာနတော= သိသူ၏။ (သန္တာန်၌။) … ခယော= ကုန်ရာဖြစ်သော အရဟတ္တဖိုလ်သည်။ ဟောတိ= ၏။`。jānato、passato 是属格（知者、见者的相续中），主语是灭尽。译文“这样知、这样见，也能紧接着达到诸漏的灭尽”把知见者当成主语、灭尽当成宾语。§487 句 90-102、§488 句 174-186 也是这个问题。
- **建议**：“比丘们，对这样知、这样见的人来说，诸漏的灭尽也紧接着就会到来。”（§488、§491 句末没有“也”，因为原文作 evaṃ kho，不是 evampi kho。）

## 原文 / nissaya 疑问
- §489 句 27-32 的 nissaya 开头有一组受蕴的四种看法（`ဝေဒနံ= … ဝေဒနာဝန္တံ= … ဝေဒနာယ= …`），那是 §488 的内容，§489 的巴利原文里没有。疑似 nissaya 录入时串入了相邻段落，只记录，不影响本段的审查结论。
