# Review — 135:300-304（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供）／复注 ❌（未提供；本层是义注，释义只能对照本文和义注原文自身）／父层对照 ⚠️ 不完整。父层只给到 169:593-605，**606-607 缺失**。§304 的被解释词（ācikkhituṃ…uttānīkātuṃ、saṭṭhimattānaṃ therānaṃ）和 §304 引用的本文偈句都出自那两段，**本次无法做逐字核对**，要补取 169:606-607 再核一遍。

## 被解释词与父层的逐字核对

已核对且一致的有：我所 / 来回奔走 / 去到（602）/ 学友，我并不把色（602）/ 仍然有 / 细微残留 / 灰碱 / 盐碱 / 浸透搓洗 / 同样地。

- §301 `135-301-12-20`：译作 ‘**我是**’……**存有**，两个词都能在父层找到（169-598、602：“存有‘我是’的慢”），但写法有两处问题：
  - 本句是义注层的正文，不在引语里面，第一层引号应当用 “” 而不是 ‘’。
  - 语序和父层相反，读者不容易认出注的是哪一句。
  - **建议**：改为 **存有**“**我是**”，与父层“存有‘我是’”对应。
- §304 全部黑体（告知 / 宣示 / 施设 / 建立 / 开显 / 分别 / 阐明 / 约六十位长老）：**父层 606-607 未提供，暂时无法核对**，列为待核项。

## 跨段一致性

- **thera（单数，指差摩迦）**：§301-59、§301-91、§301-105、§302-36、§304-48 都只译作“长老”。同一段里又有 therā（复数）译作“长老们”，两者很容易混淆，§301-59“长老住的地方”尤其明显。
  - **建议**：每段第一次出现时写作“差摩迦长老”，后面可以用“差摩迦”或“这位长老”。
- **saṭṭhimattānaṃ**：§301-59 译作“大约六十位”，§304-33 译作“约六十位”。
  - **建议**：统一为“约六十位”，最后以父层 607 的译法为准。
- **单引号用在第一层引语**：§301-12（‘**我是**’）、§302-22（“另有‘我是’”）、§302-36（“存有‘我是’”）都在义注正文的第一层用了 ‘’。§301-12 的释义部分用的是 “我是”，前后不一致。
  - **建议**：第一层一律改成 “我是”，只有嵌在双引号里面时才用 ‘我是’，例如 §302-2 的写法是对的。
- **aññatra rūpā … vadati**：§302-22 译作“离开色另有‘我是’”，而这里对应的父层 602 是“离开色另说‘我是’”。
  - **建议**：改为“离开色另说“我是”的人”，与父层同步。
- **gandhakaraṇḍaka / gandhaparibhāvita**：§303 译作“香箱”“用香熏过的衣服”，父层 605 是“用香料熏过的衣箱”。
  - **建议**：“香箱”改为“熏香的衣箱”，“用香熏过”改为“用香料熏过”。
- **父层自身不一致（上游问题，交 harmonize 处理）**：
  - 169:593-597 用“差摩迦 / 陀娑迦 / 学友”，598 以后改成“差摩 / 达沙卡”，603 以后又把 āvuso 译成“朋友”。
  - 本层统一用的是差摩迦、陀娑迦，本身没有问题。但父层改定以后，§302-2 的黑体“学友”要跟着核对。
  - 建议父层统一为“差摩迦 / 陀娑迦 / 学友”。

## §301 句 135-301-12-20
- **问题**：义注释义和父层译文不一致（上游问题）。
  - **义注**：asmīti evaṃ pavattā taṇhāmānā adhigatā，意思是以“我是”的方式转起的**爱和慢**。
  - 父层 598、599、602 把 adhigataṃ 译成“存有‘我是’的**慢**”，把义注说的“爱”漏掉了，范围译窄了。
- **建议**：本层暂时保持“存有”不动，另请父层考虑改为“仍然存有‘我是’（的爱与慢）”，或删掉“的慢”只保留“存有‘我是’”。另外，“运作”可以改成“生起”，更贴近 pavattā。

## §301 句 135-301-26-32
- **问题**：背景补出。这条注的是 169:602 差摩迦拄着手杖去见长老们，但译文没有写出主语。紧接着下一句是“而陀娑迦长老……”，读者可能会把前一句误读成陀娑迦走的路。
- **建议**：改为“**去到**：是指差摩迦长老从枣园走了大约一牛呼（gāvuta）的路，去了瞿师罗园。”

## §302 句 135-302-2-21
- **问题**：释义措辞和父层句式不一致。“只有色是‘我是’”和父层“把色说成‘我是’”对不上，读者看不出注的是同一句。
- **建议**：改为“只把色说成‘我是’的人，就排除了其余四蕴。”也可以考虑把“排除”改成“否定”（paccakkhātā）。

## §302 句 135-302-48-51
- **问题**：原文疑问。义注的词条读作 Hotevā，父层 605 读作 hoti yeva，属于连写或异读，不影响翻译。只作记录，不改。

## §302 句 135-302-64-68
- **问题**：义注与父层有分歧（上游问题）。
  - **义注**：temetvā khādetvā，意思是“浸湿，让碱蚀去污垢”，没有“搓洗”的意思。
  - 父层 605 的“浸透搓洗”是按 sammaddati 的字面译的，和义注的解释有偏差。
- **建议**：本层黑体按硬约束保持“浸透搓洗”。父层是否改为“浸透、让碱蚀去污垢”，交由 harmonize 判断；如果父层改了，本层黑体要同步。

## §303 句 135-303-2-63
- **问题**：存疑。“听了开示、经过搓洗而安住的阿那含的心理活动”一句有两个疑点：
  - desanāya madditvā ṭhito 的“desanāya”更可能是“按（本经）所开示的（三种随观）”，译成“听了开示”是添加的内容。
  - 把“搓洗”直接放在“心理活动”上面，比喻和被比喻的东西混在了一起。
- **建议**：改为“依照本经所说、经三种随观搓磨过而安住的阿那含的心”。这一句的 confidence 应当压低。

## §304 句 135-304-48-54
- **问题**：术语。vipassanāsahagatacitta 里的 sahagata 是“俱行、伴随”，不同于 sampayutta（相应），译成“与观相应的心”偏了。
- **建议**：改为“伴随着观的心”。

## §304 句 135-304-63-78
- **问题**：待核。这一句是 Tena vuttaṃ 引出的本文原句（169:607），译文应当与父层逐字相同，但父层 607 未提供。另外“诸漏”偏文言。
- **建议**：取到 169:607 后照父层原文改，父层没定稿时可以先写“心从各种漏中解脱了”。

## §304 句 135-304-60-62
- **问题**：“因此经中说”里的“经中”是添加的，原文只有 Tena vuttaṃ。
- **建议**：改为“所以（经里）说”，或直接写“所以说：”。
