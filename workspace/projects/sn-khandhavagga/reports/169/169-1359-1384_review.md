# Review — 169:1359-1384（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本 chunk 的 nissaya 只出现在各五经组的结尾行，形式是“ဤသုတ်တို့၌ X= …ဟု ပေး”，意思是“在这几部经里，X 释为……”。它给出的是整组关键词的词级释义，下面的意见据此覆盖整组各段）

## 跨段一致性

- **lakkhaṇa 系与 pekkhaṇa 系译名交叉混用（必改）**：nissaya 把两组词根分得很清楚。
  - lakkhaṇa 系释为 `မှတ်သား`（标记、辨识）：
    - sallakkhaṇā = ကောင်းစွာ မမှတ်သား（没有好好辨识）
    - upalakkhaṇā = ကပ်၍ မမှတ်သား（没有贴近辨识）
    - paccupalakkhaṇā = တဖန် မမှတ်သား（没有再次辨识）
  - pekkhaṇa 系释为 `ရှု`（观看、观照）：
    - samapekkhaṇā = ကောင်းစွာ မရှု（没有好好观看）
    - paccupekkhaṇā = တဖန် မရှု（没有再次观看）
  - 现译的问题：
    - §1376 asallakkhaṇā 译“观察”，§1382 asamapekkhaṇā 译“正确观察”，两系共用“观察”。
    - §1378 anupalakkhaṇā 译“审察”，§1384 appaccupekkhaṇā 译“仔细审察”，两系共用“审察”。
    - 结果是读者无法分辨这四组经的区别。
  - 建议：lakkhaṇa 系统一用“辨识”，pekkhaṇa 系统一用“观照”；前缀按 nissaya 的副词区分：`ကောင်းစွာ`→“善加”，`ကပ်၍`→“就近／细加”，`တဖန်`→“反复”。具体译法见下文各句。
- **因由格（-ā 从格表原因）的译法前后不一**：
  - §1360–1366 用“由于没有……”。
  - §1368–1378 用“是因为不……”。
  - §1380–1384 用“正是由于对……没有……”。
  - nissaya 统一释为 `…ခြင်းကြောင့်`（因为没有……），只是从格表原因，`kho` 不必译成“正是”。建议全 chunk 统一为“婆蹉，由于没有……X……”。
- **句式“不 X 色”与“对色没有 X”不一致**：
  - 标题：§1359–1377 作“不见色／未现观色／不随觉色……等五经”，§1379–1383 作“对色没有……等五经”。
  - 正文：§1360–1366 作“没有见到色”，§1368–1378 作“不随觉色”，§1380–1384 作“对色没有……”。
  - 建议标题与正文都统一为“没有 X 色”的格式。
- **pe 的译法不统一**：§1360–1366 用“（略）”，§1368–1378 用“乃至”，§1380–1384 用“（中略）”。建议统一为“……（略）……”。“乃至”偏旧译文体。
- **hetu / paccaya**：§1360 译“什么因、什么缘”，§1368、§1374 译“什么原因、什么条件”。建议统一为前者。
- **vacchagotto paribbājako**：§1360 译“游方者婆蹉衢多”，§1368 译“婆蹉氏游方者”。建议统一为“游方者婆蹉衢多”。
- **nirodhagāminī paṭipadā**：§1360 译“通往色灭尽的道路”，§1368、§1372 译“导向色灭的道路”。建议统一为前者。
- **引号缺失**：§1380、§1382、§1384 的世尊答语没有加“”，其余各组都有。建议补上。
- **经号连接符混用**：§1359–1362、§1379–1384 用半角连字符“-”，§1367–1378 用“–”。建议统一。

## §1360 句 169-1360-105-106

- **问题**：无词法问题。nissaya 释 adassanā = မမြင်ခြင်းကြောင့်（因为没有看见），本组译“由于没有见到”，格与语义都相合；标题“不见色”与正文“没有见到”的句式不一致，已列入跨段一致性。
- **建议**：标题改为“没有见到色等五经”，或与全 chunk 统一后的句式保持一致。

## §1366 句 169-1366-14-15

- **问题**：无词法问题。anabhisamayā = ရှေးရှုမသိခြင်းကြောင့်（因为没有直面了知），“没有现观”相合。
- **建议**：只需按跨段一致性统一句式与 pe 的写法。

## §1372 句 169-1372-16-17

- **问题**：无词法问题。ananubodhā = လျော်စွာ မသိခြင်းကြောင့်（因为没有随顺了知），“不随觉”相合。§1369–1371 原文省略了 ananubodhā，译文补出，这与 nissaya “只有该词不同”的说明一致。
- **建议**：把“是因为不随觉……”改为统一句式“由于没有随觉……”。

## §1374 句 169-1374-43-44

- **问题**：无词法问题。appaṭivedhā = ထိုးထွင်း၍ မသိခြင်းကြောင့်（因为没有穿透了知），“不通达”相合。
- **建议**：句式改为“由于没有通达……”。

## §1376 句 169-1376-27-28

- **问题**：词义译窄，且与 pekkhaṇa 系撞名。nissaya 释 asallakkhaṇā = ကောင်းစွာ မမှတ်သားခြင်းကြောင့်（因为没有好好标记、辨识）。词根是 lakkhaṇa（标记、辨识），不是“观察”；前缀 saṃ- 对应 `ကောင်းစွာ`（好好地），现译“不观察”把它丢了。
- **建议**：§1375 标题和 §1376 正文改为“没有善加辨识”，如“婆蹉，由于没有善加辨识色……（略）……”。

## §1378 句 169-1378-28-29

- **问题**：词义偏移，且与 pekkhaṇa 系撞名。anupalakkhaṇā = ကပ်၍ မမှတ်သားခြင်းကြောင့်（因为没有贴近辨识）。“审察”偏向“观看”义，又和 §1384 的“仔细审察”（paccupekkhaṇā）混同。
- **建议**：§1377 标题和 §1378 正文改为“没有细加辨识”或“没有就近辨识”。

## §1380 句 169-1380-28-29

- **问题**：前缀误读。appaccupalakkhaṇā = တဖန် မမှတ်သားခြင်းကြောင့်。`တဖန်` 是“再次、反复”（对应 paṭi-），不是“逐一”。
- **建议**：§1379 标题和 §1380 正文改为“没有反复辨识”。正文同时去掉“正是”，补上引号。

## §1382 句 169-1382-27-28

- **问题**：与 lakkhaṇa 系撞名。asamapekkhaṇā = ကောင်းစွာ မရှုခြင်းကြောင့်（因为没有好好观看）。“正确观察”的“正确”不是 `ကောင်းစွာ` 的本义，而且“观察”已经被 §1376 用掉。
- **建议**：§1381 标题和 §1382 正文改为“没有善加观照”，与 §1376 的“善加辨识”形成成对区分。正文去掉“正是”，补上引号。

## §1384 句 169-1384-28-29

- **问题**：前缀误读，且与 lakkhaṇa 系撞名。appaccupekkhaṇā = တဖန် မရှုခြင်းကြောင့်（因为没有再次观看）。“仔细”不是 `တဖန်` 的意思，“审察”又和 §1378 混同。
- **建议**：§1383 标题和 §1384 正文改为“没有反复观照”，与 §1380 的“反复辨识”形成成对区分。正文去掉“正是”，补上引号。
