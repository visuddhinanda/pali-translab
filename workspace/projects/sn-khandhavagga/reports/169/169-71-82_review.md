# Review — 169:71-82（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次没有提供，词级核对没做，格与句法只按巴利原文判断）／义注 ⚠️（只有义注巴利原文 book 135 §55-56，没有义注译文）
> 本层是本文（mūla），没有父层，所以不用查被解释词是否与父层逐字同译。反过来，义注以黑体引用了本文的 abhinandati / abhivadati / ajjhosāya tiṭṭhati / yā rūpe nandī / tadupādānaṃ / nābhinandati / nābhivadati。义注译文出来以后，要和本章的“欢喜 / 称赞 / 执着……而住 / 对色的喜爱 / 就是取 / 不欢喜 / 不称赞”逐字对齐。

## 跨段一致性
- **pe 省略句的补法前后不一致**：§75 句 169-75-2-21 译成“他欢喜受……想……他欢喜行……”，“想”前没有动词。与它对应的 §81 句 169-81-2-14 译成“他不欢喜想……他不欢喜行……”，保留了动词。巴利原文两处都有动词（saññaṃ abhinandati / saññaṃ nābhinandati），建议 §75 统一成 §81 的补法（见下文该句）。
- **法相术语首次出现没有夹注**（style.md 第二节）：只有“定（samādhi）”加了夹注。下面这些术语在 §72-74 首次出现时都没有夹注：色（rūpa）、受（vedanā）、想（saññā）、行（saṅkhāra）、识（viññāṇa）、集起（samudaya）、灭没（atthaṅgama）、喜爱（nandī）、取（upādāna）、有（bhava）、苦蕴（dukkhakkhandha）。其中“有”最需要补，理由见 169-74-30-32。后文不必重复夹注。
- 其余术语各段一致，不用改：samudaya“集起”、atthaṅgama“灭没”、nirodha“灭”、paccayā“由于”、abhinandati“欢喜”、abhivadati“称赞”、ajjhosāya tiṭṭhati“执着……而住”、kevala dukkhakkhandha“整个苦蕴”。

## §72 句 169-72-67-89
- **问题**：夹注 — 这里是五蕴和“集起 / 灭没”在本经的首次出现，没有夹注巴利原词。
- **建议**：改为“色（rūpa）的集起（samudaya）与灭没（atthaṅgama），受（vedanā）的……想（saññā）的……行（saṅkhāra）的……识（viññāṇa）的……”。

## §73 句 169-73-28-37
- **问题**：释义（提示，不是必改）—
  - **义注**：*Abhinandatī*ti pattheti。义注把 abhinandati 解为“希求、渴求”，带贪爱色彩。现代汉语的“欢喜”偏向单纯的喜欢，语义偏弱。
  - **义注**：*Ajjhosāya tiṭṭhatī*ti gilitvā pariniṭṭhapetvā gaṇhāti。义注解为“吞下、完全占为己有而抓住”。“执着而住”的意思没有错，但强度不够。
  - abhivadati 的“称赞”与义注相符，不用改。**义注**：tāya abhinandanāya “aho piyaṃ iṭṭhaṃ kantaṃ manāpan” ti vadati（由于这种欢喜，说出“啊，可爱、可意……”）。
- **建议**：“欢喜”是传统译法，可以保留，但全章要统一。如果想更贴近义注，可以考虑改成“贪求”，全章一起换。“而住”略带书面腔，现代读者一般也能懂，可以保留。定案后登记进 terms.md，义注译文照此逐字对齐。

## §74 句 169-74-16-24
- **问题**：夹注 / 释义 — nandī 在这里首次出现，没有夹注。**义注**：yā sā rūpe balavapatthanāsaṅkhātā nandī（称为“强烈渴求”的那种 nandī）。“喜爱”偏弱，但全章已经统一使用。
- **建议**：首次出现改为“喜爱（nandī）”，全章译名是否改强交给术语定案。

## §74 句 169-74-25-29
- **问题**：夹注 — 取（upādāna）首次出现，没有夹注。释义与义注相符。**义注**：taṃ gahaṇaṭṭhena upādānaṃ（在“抓取”的意义上是取）。
- **建议**：改为“对色的喜爱，就是取（upādāna）。”

## §74 句 169-74-30-32
- **问题**：可读性 / 夹注 — “由于他的取，就有了有”连用两个“有”，第二个“有”是术语 bhava，一般读者读起来像笔误。
- **建议**：改为“由于他的取，就有了有（bhava）；”。后文 §75、§79-82 的“有”不再夹注。

## §74 句 169-74-42-47
- **问题**：夹注 — 苦蕴（dukkhakkhandha）首次出现，没有夹注。
- **建议**：改为“这整个苦蕴（dukkhakkhandha）就是这样集起的。”

## §75 句 169-75-2-21
- **问题**：漏译 — 原文是 saññaṃ abhinandati … saṅkhāre abhinandati …，译文“……想……”漏了“saññaṃ abhinandati”里的动词“欢喜”，读起来像“欢喜受想”连成一个宾语。这句也和 §81 的补法不一致。**必改**。
- **建议**：“他欢喜受……他欢喜想……他欢喜行……他欢喜识、称赞识、执着于识而住。”

## §80 句 169-80-10-22
- **问题**：原文疑问（记下，不改）— 巴利原文作 anajjhosā tiṭṭhato，同一句式在 §79、§81、§82 都作 anajjhosāya tiṭṭhato，这里疑似脱落了“ya”。译文已经按 anajjhosāya 译出，不用改，建议登记到 known-issues.md 的“OCR / 原文问题”。
