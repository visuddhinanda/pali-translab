# Review — 169:752-762（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分句有 nissaya，无 nissaya 的句子不出意见）

## 跨段一致性

- **saṃyojaniya / upādāniya 译法不平行**：§759–760 译“（会）引生结缚的法”，§761–762 译“所取法”。nissaya 对两词的解释结构完全相同：`သံယောဇနိယေ= သံယောဇဉ်တို့၏ အစီးအပွါးဖြစ်ကုန်သော`（有益于结、助长结的），`ဥပါဒါနိယေ= ဥပါဒါန်တို့၏ အစီးအပွါးဖြစ်ကုန်သော`（有益于取、助长取的）。“所取法”是被动的“被取之物”，与 nissaya 的“助长取的”不符，也和前一经的译法不平行 → 建议统一为同一结构，例如“会引生结缚的法／会引生取的法”。两经经名同步改为“引生结缚的法经／引生取的法经”。
- **tattha … tattha 句式不一致**：§760 译“对它的欲贪，就是系在它上面的结缚”。§762-34-48 译“对色的欲贪，就是对色的取”，§762-61-68 译“对它们的欲贪，就是对它们的取”。nissaya 中 `တတ္ထ= ထိုရုပ်၌`（在那色上）是处格，并且对每一蕴单独说，应当用单数 → 建议§762 仿照§760 统一为“对它的欲贪，就是系在它上面的取”。“对它们”改为“对它”。
- **编号格式不统一**：§752–760 用阿拉伯数字（“5. 束缚经”“120. 因缘在舍卫城。”），§761–762 改用汉字（“九、所取法经”“一二一、因缘在舍卫城。”）→ 统一为阿拉伯数字格式：“9. …经”“121. 因缘在舍卫城。”
- **Taṃ suṇātha**：§760 译“你们听好。”，§762 译“你们要仔细听。” → 统一为一种。
- **pe 的处理**：§760-49-61 译“受……乃至……想……行……识”，§762-49-60 译“受……想……行……识”，漏了“乃至” → 统一补出“乃至”。

## §753 句 169-753-38-85

- **问题**：格与句法 — 复合词 `ရူပဗန္ဓနဗဒ္ဓေါ= ရူပါရုံဟူသော အနှောင်အဖွဲ့သည် နှောင်ဖွဲ့အပ်သူ`，nissaya 用 `ဟူသော`（“名为…的”）表示同位关系：色本身就是束缚。译文“被色的束缚绑住”中的“的”容易被读成属格（属于色的束缚）。同句的 `သန္တရဗာဟိရ…= အတွင်း အပြင်နှင့်တကွသော အနှောင်အဖွဲ့`（连同内外的束缚）没有这个问题。
- **建议**：改为“被色这一束缚绑住”，或“被名为色的束缚绑住”。§753-97-119（受）、§753-120-154（识）、§754 否定句同步修改。
- **备注**：nissaya 把 `jīyati / mīyati / gacchati` 名词化（`အာချာတ်နာမ်ကြံ၍`），和 `rūpabandhanabaddho` 等一起作 `vuccati` 的表语。译文用“这就叫作凡夫：他……”展开，语义没有偏差，可以保留。

## §760 句 169-760-70-83

- **问题**：隐含成分 — nissaya 补出 `ဣမေ= ဤဥပါဒါနက္ခန္ဓာ ၅-ပါးတို့ကို`（这些＝五取蕴），`ဣဒံ= ဤဥပါဒါနက္ခန္ဓာ ၅-ပါးတို့၌ လိုချင်တပ်မက်ခြင်းကို`（这＝对五取蕴的欲贪）。译文“这些……这……”的指代虽然可以从上文推出，但 idaṃ（单数）指的是欲贪，读者容易误以为它指前面的法。
- **建议**：可以保留原句。如果要消除歧义，可改为“这些叫作会引生结缚的法，这种欲贪叫作结缚。”不强制修改。
