## 理由
- **评估基准**：
  - 本次评的是义注层。注入的数据里没有它的释义标准（复注），也没有 nissaya，所以释义和词法只能依据巴利原文判断，信心分因此下调。
  - 父层（本文 SN 22.62）的译文也没有注入。黑体被解释词是否与本文逐字同译，这次无法核对。建议在 harmonize 报告里单独确认以下词条：“没有被舍弃 / 过去也不曾被舍弃 / 现在不被舍弃 / 将来也不会被舍弃 / 不驳斥 / 乌卡拉 / 瓦萨和般尼亚”。
- **准确性**：
  - 整体理解正确。几处难点都译对了：
    - niruttipatha 的两种语法分析；
    - “kiṃ ekekassa diyaḍḍhā”（每人一种半）的问答；
    - 以四禅为例说明一人兼起三见；
    - garahati / paṭikkosati 的区分。
  - 主要错误是 appaṭikuṭṭhā 被译成了主动语态，与后面的被动释义自相矛盾。
  - mūladiṭṭhigatikā 译作“创始者”依据不足，需要复注确认。
- **风格**：
  - 通篇是现代书面汉语，没有明显的文言句式。
  - 有两处可以再斟酌：“言语之路”里的“之”（属于固定术语名，影响小）；“诸蕴”（佛学惯用语）。
  - 有几个术语对一般读者不够清楚：“邪性决定”“四地”“没有布施”。
- **一致性**：
  - 前后用词统一：
    - ekantakāḷaka / accantakāḷaka 都译作“彻底黑暗”；
    - paṭikkosati 与 appaṭikuṭṭhā 同根，都用“驳斥”；
    - 三组“舍弃”的时态排列整齐。
  - 品名的格式与经名的写法不太协调。

## 问题清单

### 🟧 error
- `135-165-73-76`｜错译（词义、修饰关系）｜片段「不驳斥」
  - 问题：appaṭikuṭṭhā 是过去被动分词，意思是“未被驳斥”，本文原意是“不被智者沙门婆罗门驳斥”。译成主动的“不驳斥”，与同句释义“没有被拒斥”的被动语态自相矛盾，也会让人误以为主语是驳斥者。
  - 建议：改为“**不被驳斥**”（须与本文同一处的译法同步修改）。

### 🟨 warning
- `135-166-13-17`｜代词指代不明确｜片段「这些邪见的创始者」
  - 问题：
    - “这些邪见”在前文没有出现过，三种见要到下一句才列出，指代悬空。
    - mūladiṭṭhigatikā 字面是“根本见的持有者 / 最初的邪见者”，译作“创始者”依据不足，建议对照复注确认。
  - 建议：改为“因为这两个人都是根本邪见的持有者”，或按复注取义；如果确认是“创始者”，就把“这些”改成“下面这几种”。
- `135-166-44-52`｜关键词语意不明确，或二意场合没有注释｜片段「没有布施」
  - 问题：natthi dinnaṃ 否定的是布施的果报，不是布施这件事本身。直译成“没有布施”，一般读者容易误解为否认有人布施。
  - 建议：保留引文原貌，首次出现时加注（“即认为布施没有果报”）。`135-166-113-134` 中同样的引文随之统一。
- `135-166-104-112`｜关键词语意不明确，或二意场合没有注释｜片段「邪性决定」
  - 问题：micchattaniyāma 是专门的法相术语，一般读者看不懂“邪性决定”指什么。
  - 建议：首次出现时附巴利原词并加注，例如“邪性决定（micchattaniyāma，指必定堕入恶趣、不可能证得解脱的状态）”。
- `135-167-2-28`｜整句逻辑表达不规范｜片段「……**认为**」
  - 问题：巴利原文的被解释语是连续的“na garahitabbaṃ nappaṭikkositabbaṃ amaññiṃsu”，中间没有省略。插入“……”并把“认为”孤立出来，读起来不通。
  - 建议：按本文译法整体引用，例如“在‘**他们认为不应当指责、不应当驳斥**’这句中”（须与本文逐字一致）。
- `135-167-82-88`｜关键词语意不明确，或二意场合没有注释｜片段「四地诸蕴的施设」
  - 问题：“四地”（catubhūmika：欲界、色界、无色界、出世间）和“施设”（paññatti）对一般读者都不清楚，而且 paññatti 是法相术语，首次出现时没有附巴利原词。
  - 建议：改为“属于四地（欲界、色界、无色界、出世间）的诸蕴的施设（paññatti）”，或另加脚注。
