## 理由

**资源缺失**：这次注入的数据只有巴利原文和译文，没有义注（aṭṭhakathā）和 nissaya。以义注定释义、以 nissaya 定词法的核对都没做，准确性只能按巴利原文的语法和上下文判断，所以信心指数偏低。这一层是复注，被解释词要和义注译文逐字相同。本次看不到义注译文，这一点无法核对。下面几条涉及黑体被解释词的问题，要先回到义注层对照，再决定在哪一层改。

**准确性**：
- 整体取义可靠。难点处理得比较好：
  - 171 段对 nirutti / adhivacana / paññatti 的三组词源解释，以及“否则……”的反证；
  - 172 段邪见固化过程的长句，前后两次 santiṭṭhati 的主语（先是邪念，再是被称为邪念的渴爱）没有混淆；
  - 172 段七个速行心的次第。
- 主要问题有两处，都出在被解释词：
  - `197-171-153-164`：achaḍḍitā 是否定式，译文却成了肯定式“而把它们丢掉”；
  - `197-171-177-181`：appaṭikuṭṭhā 是被动分词，却译成主动的“不驳斥”，和后面的释义“没有被拒绝”对不上。
- asaṃkiṇṇa 在经文里的本义接近“不混杂”。这里译为“没有被舍弃”，是跟着义注的释义（avijahitā … achaḍḍitā）走的，有依据，不扣分。
- 171 段的“并不增加意义”是对 padavaḍḍhana（扩充词语）的合理补充说明，不算多译。

**风格**：
- 通篇是现代书面汉语，没有发现文言句式或文言虚词。“尚未”“其中”属于现代通用写法；标题里“言语之路”的“之”是固定题名，都不算问题。
- 标点全用全角，引号统一用弯引号。
- 扣分主要在几处句子逻辑不清：
  - 171 段“越过了坏灭的东西”有歧义；
  - 171 段“应当这样理解：”把 evaṃ 的指向从前文错指到了后文；
  - “人名的称呼才算称呼”同语反复；
  - 172 段长句嵌套太深。

**一致性**：
- 术语前后统一：言语 / 称呼 / 施设（paññatti 和 paṇṇatti 同译为施设）、吉祥增长者 / 财富增长者、瓦萨和般尼亚、速行心、邪念、邪寻。
- patha 在 171 段前面译“路”，在 `197-171-25-29` 译“道路”，略有出入。
- 被解释词要和义注逐字相同，这次无法核对，没有计入扣分。

## 问题清单

### 🟧 error
- `197-171-153-164`｜导致误解的表达｜片段「而把它们丢掉」
  - 问题：引文结尾对应 achaḍḍitā（没有被丢弃），是否定义。这里截断后读起来是肯定句“把它们丢掉”，和前文“没有被舍弃”的意思正好相反。
  - 建议：先核对义注层这句的完整译文。引文省略号后的部分要保留否定，比如“……没有被丢掉”。义注层如果也有同样问题，要一起改。
- `197-171-177-181`｜错译（词义、修饰关系）｜片段「不驳斥」
  - 问题：appaṭikuṭṭhā 是被动完成分词，意思是“没有被驳斥”。译成主动的“不驳斥”，和后面的释义“没有被拒绝”（na paṭikkhittā）语态不一致。
  - 建议：改为“**没有被驳斥**”，并同步核对义注层和本文层的对应译法。

### 🟨 warning
- `197-171-25-29`｜整句逻辑表达不规范｜片段「又因为是……道路」
  - 问题：巴利原文 Pathā ca 只是“又是路”。黑体里多出“因为”和省略号，读者看不出要解释的是哪句话；patha 在这里译“道路”，前文却译“路”。
  - 建议：对照义注层的原句，保证被解释词逐字相同。如果义注原文没有“因为”，就改为“**又是路**”，patha 统一译“路”。
- `197-171-104-113`｜整句逻辑表达不规范｜片段「应当这样理解：言语等词适用于一切说法」
  - 问题：evaṃ 指的是前面几种词源解释（“照这样解释”）。冒号让“这样”变成指向后文，前后的逻辑关联断了。
  - 建议：改为“按照上面这样的解释，应当理解言语等词适用于一切说法。”
- `197-171-114-128`｜不导致误解的汉语语病｜片段「这类人名的称呼才算称呼」
  - 问题：同语反复。原文 abhilāpana 指说法、表达，不是“称呼”。
  - 建议：改为“这类人名式的说法才算称呼”。
- `197-171-182-197`｜整句逻辑表达不规范｜片段「因为越过了坏灭的东西，也就必然越过了生起等阶段」
  - 问题：原文 bhaṅgaṃ atikkantaṃ 是“已经越过坏灭的东西”。译文可以读成“（某人）越过了正在坏灭的东西”，后半句也缺主语。
  - 建议：改为“因为已经越过坏灭的东西，也必然已经越过了生起等阶段”。
- `197-172-2-4`｜关键词语意不明确｜片段「因为他们的族姓是瓦萨和般尼亚」
  - 问题：原文用族姓 Vasabhaṇa 来解释 vassabhaññā，是一个词源说明。译文把两者译成同一个词，解释变成了循环论证，读者看不出两者的关联。
  - 建议：改为“因为他们属于瓦萨巴纳（Vasabhaṇa）族姓，所以称为**瓦萨和般尼亚**”。
- `197-172-127-134`｜关键词语意不明确｜片段「他还可以救治」
  - 问题：satekiccha 的意思是“还可救治的（人）”。译文容易读成“他能救治别人”。
  - 建议：改为“他还有救”或“他还可以被挽回”。

### 🟦 suggestion
- `197-172-135-141`｜语言表达不够流畅｜片段「他就无法救治了」
  - 问题：和上一句对应，也有主动、被动两种读法的轻微歧义。
  - 建议：改为“他就没救了”或“他就无法挽回了”，和上一句配套。
- `197-172-15-87`｜复杂的嵌套句整句语言逻辑理解困难｜片段「对于从传闻中得来的“没有因”等意义，他按照相应的样子反复思量」
  - 问题：整段是一个长句，嵌了四五层条件，一般读者很难跟上。
  - 建议：在不改变意思的前提下，按“学习、探究 → 邪念安立 → 反复思量、呈现在心前 → 认可、执取 → 渴爱安立”这几个阶段拆成几句。
- `197-173-24-32`｜该使用而没有使用术语标记｜片段「也**认为**不应当指责」
  - 问题：巴利原文加黑的是 **na maññiṃsu** 整体，译文只加黑了“认为”，和被解释词的范围对不上。
  - 建议：按义注层的对应译文调整加黑范围。
- `197-173-33-41`｜语言风格不统一｜片段「他们反而说：过去」
  - 问题：原文被解释词只有 atītaṃ panā 两个词，黑体里多出了“他们……说”。
  - 建议：确认和义注层译文逐字相同；如果不同，按义注层改。
- `197-175-2-4`｜不常用术语编写注释或者百科｜片段「趋近品」
  - 问题：upaya 在这一品里指由爱和见而产生的趋近、执着。“趋近”这个直译，读者不容易理解。
  - 建议：在品名首次出现处加注，说明 upaya 的含义；或者对照传统汉译统一品名，定下来后登记到 terms.md。
