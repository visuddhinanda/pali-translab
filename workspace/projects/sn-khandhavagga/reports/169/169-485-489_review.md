## 跨段一致性

- **so saṅkhāro / sopi saṅkhāro**：各段里“So pana saṅkhāro kiṃnidāno…”译成“**这个**行”，紧接着的“tatojo so saṅkhāro”“sopi saṅkhāro anicco…”却译成“**那个**行”（§485–489 都是这样）。同一个指代词在同一个论证里前后不一，建议统一为“这个行”。
- **vedanā**：§488 作为五蕴时译“受”（把受视为我…）；§485/486/487/488 缘起链中的 “sāpi vedanā” 译“感受”。义注说 sāpi vedanā 指“taṇhāya paccayabhūtā vedanā”，也就是作为渴爱之缘的受，这是法相术语。建议链中也统一为“受”：“那受”。vedayita 仍可译“感受”，与它区分开。
- **saṅkhāra 的两种所指**：§488 把五蕴里的 saṅkhārā 译为“诸行”，紧接着“samanupassanā saṅkhāro so”又译“就是行”。读者容易把这两个“行”看成同一个东西。义注说后者是 **diṭṭhisaṅkhāro**（见行）。正文保留“行”，这样能与被解释词对齐；建议由 footnote 步骤加注：“**义注**：这里的行指见行（diṭṭhisaṅkhāra）。”
- **paṭiccasamuppanna**：全 chunk 都译“缘起的”，本身一致；但术语不准，见下文，改动时全 chunk 一并改。

## §485 句 169-485-18-28（同见 169-486-24-35、169-487-28-38、169-488-112-122）
- **问题**：术语所指（轻）。samanupassanā 前文作动词译“视为”，这里作名词译“看法”，太宽泛。**义注**：samanupassanā ti diṭṭhisamanupassanā，指把五蕴视为我的那种见。
- **建议**：可改为“这种视为（我）的看法”或“这种随观”。定下译法后，四处要一起改，义注黑体也要照改。改不改由统稿决定，不是必改项。

## §485 句 169-485-48-51（同见 169-486-55-58、169-487-59-62、169-488-143-146）
- **问题**：取义不明。“由此”指什么没有交代，读者可能理解成“由这种看法”或“由上面整句”。**义注**：tatojo so saṅkhāro ti tato taṇhāto so saṅkhāro jāto，“由此”明确指渴爱。
- **建议**：改为“这个行就是从它（渴爱）生出来的”，或“这个行就是从渴爱而生的”。指代词同时统一为“这个”（见跨段一致性）。

## §485 句 169-485-52-62（同见 169-486-59-69、169-487-63-73、169-488-147-157）
- **问题**：术语。paṭiccasamuppanna 是“缘所生”（依缘而生起的法），“缘起”一般对应 paṭiccasamuppāda。把形容词译成“缘起的”，会让两者混为一谈。
- **建议**：改为“缘生的”或“依缘而生的”。§485/486/487/488 的 “Sāpi taṇhā…” 句和 §485–489 各处要同步改。

## §485 句 169-485-63-77（同见 169-486-70-84、169-487-74-89、169-488-158-173）
- **问题**：① vedanā 译“感受”，与五蕴的“受”不一致（见跨段一致性）。② 原文每一项都带 pi（sāpi / sopi），译文只在末尾出现一个“也”，前几项读起来像是没说完。
- **建议**：“那渴爱也……那受也……那触也……那无明也是无常的、有为的、缘生的。”

## §485 句 169-485-78-90（同见 169-486-85-97、169-489-61-80）
- **问题**：取义（轻）。**义注**：anantarā āsavānaṃ khayo ti maggānantaraṃ arahattaphalaṃ，意思是道之后无间就是阿罗汉果。“紧接着”没有交代紧接在什么之后，不过作为本文直译可以接受。
- **建议**：保留“紧接着”，由 footnote 步骤补上义注的说法（**义注**：指紧接着道心而来的阿罗汉果）。§488 原文是 evaṃ kho（没有 pi），译作“就会”，与其他段的“也会”区分得正确，不要统稿成一样。

## §489 句 169-489-33-48
- **问题**：误读／漏译（必改）。① “so attā so loko”不是“这就是我，这就是世间”，意思是“那个我就是世间”（我与世间是同一的）。② “so pecca bhavissāmi”里的 so 被漏译了。原意是“死后我将成为那个（我）”，而且那个我是常住的……。③ avipariṇāmadhamma 译成“不会变坏的”太窄，vipariṇāma 指的是变异。
- **建议**：“‘那个我就是世间；死后我将成为那个——常住、恒久、永恒、不会变异的。’”（没有 nissaya 可对照，这里是依原文和通行解读作出的判断，建议译者复核）

## §489 句 169-489-49-60
- **问题**：格式。sassatadiṭṭhi 在本 chunk 首次出现，按 style.md，法相术语首次出现要夹注巴利原词。
- **建议**：“比丘们，而这种常见（sassatadiṭṭhi），就是行。”（如果前面的段落已经夹注过，可以忽略这一条）

## §485 句 169-485-2-10（同见 §486–489 各段首句）
- **问题**：风格（轻）。“Na heva kho … api ca kho …”是让步句式，“确实不……但是……”稍显生硬。
- **建议**：可改为“他虽然不把色视为我，但是……”。五段首句要一起改，保持一致；不是必改项。
