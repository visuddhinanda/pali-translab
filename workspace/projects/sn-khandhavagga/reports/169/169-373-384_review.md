# Review — 169:373-384（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya）

## 跨段一致性

第二经（妄想经）、第三经（贪着经）、第四经（无常经）的套语巴利文完全相同，但第二经的译法和第三、四经不一样。第三、四经之间已经一致，建议以它们为准统一第二经，下面个别条目另有说明。

- **Sāvatthinidānaṃ**：§374 译“本经的因缘在舍卫城。”，§378、§382 译“因缘在舍卫城。” → 建议统一为“因缘在舍卫城。”。nissaya 只把它当作套语标题括出，没有补出“本经”。
- **Atha kho**：§374 译“这时”，§378、§382 译“那时” → 建议统一为“那时”。
- **etadavoca**：§374 译“对世尊说”，§378、§382 译“对世尊这样说” → 建议统一为“这样说”。依据：nissaya `ဧတံ= ဤစကားကို`（这话【宾格】），宾语 etaṃ 应译出。
- **… pe … 省略号**：§374、§376 只用“……”，§378、§380、§382、§384 用“……（略）……” → 建议全章统一一种写法。
- **pahitatto**：§374 译“专心致志”，§378、§382 译“坚决” → 两处是同一个词，必须统一，建议取一种后全书一致。
- **sādhu me … vihareyyan 句式**：§374 译“希望世尊为我简要地说法……安住。”，§378、§382 译“如果世尊能为我……让我能……安住，那就好了。” → 建议统一句式。
- **Aññātaṃ bhagavā, aññātaṃ sugatā**：§374 译“我明白了，世尊！我明白了，善逝！”，§378、§382 译“世尊，我明白了；善逝，我明白了。” → 建议统一为后者。
- **baddho mārassa / mutto pāpimato**：
  - §374–376 译“被魔束缚／摆脱了波旬的束缚”。
  - §378–380 译“就被魔系缚／就从波旬的束缚中解脱了”。
  - 两经巴利文相同，只有动词前的分词不同（maññamāno 与 abhinandamāno），译法应完全一致。建议统一为“被魔束缚／摆脱了波旬的束缚”，“束缚”与“系缚”只用一个。
  - mutto 在两处分别译“摆脱”和“解脱”，也要统一。nissaya 两处都作 `မုတ္တော= လွှတ်အပ်၏`（被放开、得脱）。
- **Yathā kathaṃ pana tvaṃ … ājānāsī**：§375 译“那么，比丘，我简要说的话，你是怎样详细理解它的意义的呢？”，§379、§383 译“比丘，那么你是怎样详细理解我简要所说的意义的？” → 建议统一为后者。
- **Imassa khvāhaṃ … ājānāmī**：§375 译“世尊简要说的这些话，我是这样……”，§379、§383 译“对于世尊简要所说的，我就是这样……” → 建议统一。
- **Sādhu sādhu, bhikkhu**：§376 译“很好，很好”，§380、§384 译“好啊，好啊” → 建议统一。
- **Sādhu kho tvaṃ … ājānāsi**：§376 译“……你详细理解它的意义，理解得很好。”，§380、§384 译“你很好地详细理解了我简要所说的意义。” → 建议统一。
- **Imassa kho … attho daṭṭhabbo**：§376 译“我简要说的这些话，应当……”，§380、§384 译“对于我简要所说的，应当……” → 建议统一。
- **aññataro ca pana so bhikkhu arahataṃ ahosi**：§376 译“那位比丘成了阿罗汉中的一位”，§380、§384 译“而那位比丘成了众阿罗汉中的一位” → 建议统一为后者。

## §374 句 169-374-8-23
- **问题**：句法。nissaya 作 `ဧကမန္တံ= ၌`（处格）、`နိသိန္နော= သော`（定语分词：“坐在……的”），nisinno 是修饰 so bhikkhu 的定语。译文“在一旁坐下后，那位比丘……”把它处理成先后两个动作，与 nissaya 的结构不同，也和 §378、§382 的译法不一致。
- **建议**：改为“那时，有一位比丘……（略）……坐在一旁的那位比丘对世尊这样说：”，与 §378、§382 一致。

## §374 句 169-374-45-54 / 169-374-55-61
- **问题**：格与句法（分歧记录）。nissaya 作 `ဘိက္ခု= ကို`（宾格），整句读作“起妄想的比丘，被魔这个羂索束缚”，也就是把 bhikkhu 当作被束缚者，而不是呼格。译文按呼格读成“比丘，起妄想的人……”。从巴利文表面看（kho 后面跟 bhikkhu 并用逗号隔开），呼格读法也成立。同一套语在 §375、§376 中对应的是“bhante”和“bhikkhu”，正是呼格。所以这里不作必改，只记录分歧。
- **问题**：补出成分。nissaya 对 maññamāno 补出 `(တဏှာ မာန ဒိဋ္ဌိတို့၏ အစွမ်းအားဖြင့်) အလွဲထင်သော`，意思是“凭贪爱、我慢、邪见而错误地认定”。“妄想”在现代汉语里容易被理解为“空想、幻想”，看不出它指的是凭贪爱、我慢、邪见而起的执取。
- **建议**：保留呼格读法。“妄想”可在本经首次出现时夹注巴利原词，例如“起妄想（maññati）”，和 §378 对 abhinandati 的夹注做法一致；也可改译为“妄执”。这个词是否改译、改成什么，交由术语定案。

## §374 句 169-374-62-72
- **问题**：补出成分。nissaya 补出 `(မယာ= သည်)`（施事主语：“我”），aññātaṃ 是被动完成义（“已经被我知道了”）。译文“我明白了”已经补出了“我”，处理正确。
- **建议**：只需按跨段一致性一节改句式：“世尊，我明白了；善逝，我明白了。”

## §378 句 169-378-41-50 / 169-378-51-57
- **问题**：与 §374 相同的格读法分歧。nissaya `ဘိက္ခု= ကို` 把 bhikkhu 当作被束缚者；`မာရဿ= မာရ်တည်းဟူသော ကျော့ကွင်းသည်`（魔这个羂索【主格】）。译文按呼格读，可以成立，不作必改。
- **问题**：词义。nissaya 对 abhinandamāno 释作 `(တဏှာ မာန ဒိဋ္ဌိတို့၏ အစွမ်းအားဖြင့်) လွန်စွာနှစ်သက်သော`，意思是“凭贪爱、我慢、邪见而过度欢喜”。“贪着”可以接受。夹注用的是动词原形 abhinandati，而原文是现在分词 abhinandamāno，作为词典形可以，但要和 §374 的处理方式统一。
- **问题**：用词。“系缚”“从……的束缚中解脱了”与 §374 的“束缚”“摆脱了……的束缚”不一致，见跨段一致性一节。
- **建议**：改为“比丘，贪着（abhinandati）的人被魔束缚；不贪着的人摆脱了波旬的束缚。”

## §382 句 169-382-54-61
- **问题**：词义。nissaya 作 `ဆန္ဒော= တဏှာဆန္ဒကို`，指明这里的 chanda 是“贪爱性的欲”（taṇhā-chanda），不是中性的“想做、意欲”。“欲求”在现代汉语里偏中性，所指偏宽。
- **格**：`တတြ= ထိုမမြဲသော သဘောတရား၌`（处格：“在那无常法上”），`တေ= သင်သည်`（施事：“你”），`ဆန္ဒော= ကို`（宾格：舍弃的对象）。译文“你应当舍弃对它的欲求”的格关系正确。
- **建议**：可以考虑把“欲求”改为“欲贪”或“贪欲”。如果保留“欲求”，§383、§384 各处要同步保持一致；本句的夹注（chanda）可以保留。

## §383 句 169-383-30-34 / 169-383-44-48
- **问题**：无格位问题。`မေ= တပည့်တော်သည်`（施事：“弟子我”）对应“我应当舍弃”，处理正确。chanda 的译词随 §382 的定案同步。
- **建议**：只需按 §382 的定案同步“欲求”一词。
