# Review — 135:324-327（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位无从核对）／义注 —（本层就是义注，没有更上一级的释义标准；未提供复注）／父层本文 ✅（book=169 §640-663，定稿译文）

> 被解释词核对：13 处黑体全部与父层译文逐字相同（**想** / **里面还没有长出坚实的芯** / **有眼力的人** / **深广智慧者** / **命根** / **体温** / **成为其他生物的食物** / **这个过程就是这样** / **这是让愚人胡言乱语的幻术** / **杀戮者** / **一切结缚** / **不灭的境界**），这一项没有必改项。

## 跨段一致性
- marīci / marīcikā：本 chunk 统一译作“阳焰”，与父层 §644 一致；但父层偈颂 §650 把 Marīcikūpamā 译成“海市蜃楼”。父层已经定稿，本层不改。建议 harmonize 时报给父层统稿，考虑把 §650 改成“阳焰”，让本文、义注的比喻对得上。
- lakkhaṇa：§325 句 135-325-53-57 译“特征”（芭蕉树干），句 135-325-58-85 译“特相”（触、思）。这两处是同一个比喻的两边，用词不同，读者就看不出是在类比。建议统一，比如两处都用“相状”，或者树干一处也改成“特相”。属于建议，不是必改。
- saṃyoga / saṃyojana：黑体“一切结缚”随父层，释义里译“十种结”。两个译法都成立，但读者可能看不出“结缚”和“结”是一回事。建议改成“全部十种结（saṃyojana）”，并加一句“结缚就是结”作承接，或者直接写“全部十种结缚（saṃyojana）”。属于建议。
- “这样，……也像X”这个收尾句：§324 译“这样，……想也像阳焰”，§325 译“这样，行蕴也像芭蕉树干”，§326 两处都译“这样看，识也像幻术”。建议统一成“这样，……也像……”。属于轻微问题。

## §326 句 135-326-90-103
- **问题**：误译（主语错了）。原文是 Teneva hi cittena āgacchantaṃ viya … nisinnaṃ viya katvā gāhāpeti，意思是识让人把**那个人**看成是凭同一个心在来、去、站、坐。宾语是人，不是心。现译“让人以为是同一个心在来、在去、在站着、在坐着”，变成了心在来去。这样也和前面句 135-326-43-56 的“人看起来好像是以同一个心来、去……”对不上。
- **建议**：改成“因为它让人以为，一个人是以同一个心在来、在去、在站着、在坐着。”句首的 hi 最好也译出来（“因为”），和 43-56 句保持平行。

## §326 句 135-326-57-64、135-326-104-111
- **问题**：语句不通顺。“去等时候又是另一个心”里的“去等时候”不是自然的现代汉语。
- **建议**：两句统一改成“其实来的时候是一个心，去的时候以及其他时候又是另一个心。”

## §326 句 135-326-43-56
- **问题**：漏译（轻微）。句首的 hi 表示原因，接的是上一句“识比幻术还要短暂”，现译没有译出，因果关系断了。
- **建议**：改成“因为人看起来好像是以同一个心来、去、站着、坐着。”

## §327 句 135-327-2-8
- **问题**：表达重复。vipulavitthatapañña 译成“广大深广智慧”，“广大”和“深广”意思重叠，“深广”又和黑体“深广智慧者”撞词，读起来像同语反复。
- **建议**：改成“是指具有精细的智慧，又具有广博宽阔的智慧的人。”

## §327 句 135-327-9-12
- **问题**：释义成了同语反复。父层已经把 āyu 译成“命根”，所以这句变成“**命根**，就是指命根”，读者看不出这条注解释了什么。黑体按规定不能改。
- **建议**：在黑体后面补上原词和字面义，把“āyu（寿命）就是命根”这层意思交代出来。例如：“**命根**（āyu，字面是‘寿命’），是指命根（jīvitindriya）这种根。”

## §327 句 135-327-25-36
- **问题**：取义存疑。原文 etādisī ayaṃ paveṇī matakassa yāva susānā ghaṭṭīyati 里，ghaṭṭīyati 的主语是 paveṇī（相续），更可能是说死者的这种相续一直延续到坟场为止。现译“死者一直被拖送到坟场”把主语换成了死者，“拖送”也是译者补出的意思。没有 nissaya，无法确定。
- **建议**：改成“是说死者的这种相续就是这样，一直延续到坟场为止。”这一句的 confidence 应当调低。

## §324 句 135-324-23-38
- **问题**：
  1. 语句不通顺：“想也分为青想等各种，”的“各种”后面缺名词。
  2. 用词可能混淆：anubhavana 译成“感受”，容易和五蕴里的“受”（vedanā）混在一起，而这里说的是想蕴。
- **建议**：改成“同样，分为青想等各种类别的想，也为了体验青色等而晃动、闪烁。”

## §324 句 135-324-39-71
- **问题**：术语问题（建议）。subhaṃ sukhaṃ niccaṃ 对应的是颠倒想里“净、乐、常”这组固定说法。现译“美的、乐的、常的”里，“美的”和“乐的”“常的”不是同一套术语，研究型读者可能认不出是四颠倒。
- **建议**：改成“是清净的、是乐的、是常的”，或者“是净的、是乐的、是常的”。

## §325 句 135-325-15-42
- **问题**：取义偏了（轻微）。upanītampi na tathā hoti 的意思是即使拿去了，也不会成为那样（成不了椽子），不是“不能那样用”。改过来之后，也能和后半句“即使被执取了，它们也不是那样”对应上。
- **建议**：改成“即使拿去了，也成不了那样的东西”。

## §327 句 135-327-18-24
- **问题**：用词偏窄（轻微）。kimigaṇa 是各种虫类的群，译成“蛆虫”范围太窄。
- **建议**：改成“是说成为各种虫类等的食物”。
