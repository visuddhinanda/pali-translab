# Review — 135:59-60（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 被解释词与父层对照（逐字）

所有黑体都与父层译文逐字相同，**没有必改项**：

| 被解释词 | 本层黑体 | 父层出处 |
|---|---|---|
| upādāparitassanaṃ | 因执取而生焦虑 | §87、§88 ✅ |
| anupādāaparitassanaṃ | 因不执取而没有焦虑 | §87 ✅ |
| rūpavipariṇāmānuparivatti viññāṇaṃ hoti | 识就随着色的变坏而转 | §88 ✅ |
| vipariṇāmānuparivattijā | 追随色的变坏而转的心所生的 | §88 ✅（见下方说明1） |
| paritassanā / dhammasamuppādā | 焦虑 / 以及不善法的生起 | §88 ✅（见下方说明2） |
| cittaṃ | 心 | §88 ✅ |
| pariyādāya / tiṭṭhanti | 占据 / 盘踞不去 | §88 ✅ |
| uttāsavā / vighātavā / apekkhavā | 惊恐 / 苦恼 / 眷恋 | §88 ✅ |
| upādāya ca paritassati | 并且因为执取而焦虑 | §88 ✅ |
| na rūpavipariṇāmānuparivatti | 不会随着色的变坏而转 | §92 ✅ |
| 标题 | 因执取而焦虑经注释 | §86「因执取而焦虑经」✅ |

**说明1**：这个黑体词在义注里是 vipariṇāmānuparivattijā，前面没有 rūpa；但黑体里有「色的」。这是为了与父层逐字对齐而保留的，属于可以接受的对齐代价。不建议改动。

**说明2（问题出在父层，本层不改）**：父层 §88 把 dhammasamuppādā 译成「不善法的生起」，其中「不善」是本条义注的释义（akusala-dhammasamuppādā），被提前放进了本文。结果本层的黑体词和解释读起来一模一样：「**以及不善法的生起**：是指……以及不善法的生起」，读者看不出这条注解释了什么。
- **建议**：交给 harmonize 在父层处理，考虑把父层改回只按巴利原文的「诸法的生起」。父层一改，本层黑体也要同步改。

## 跨段一致性

- **本层内部没有问题**：
  - gahaṇa / gaṇhitvā 都译「抓取」，与被解释词里的「执取」有意区分，前后一致。
  - bheda 都译「坏灭」（§60 的 19-51 句、100-113 句），和 vipariṇāma 的「变坏」区分清楚。
- **父层内部有漂移，会影响本层的对应关系**（提交 harmonize 在父层统一）：
  - vipariṇāma：§88–93 译「变坏」，§94–95 译「发生变化」。
  - paritassanā：§88–93 译「焦虑」，§94–95 译「渴爱焦虑」。其中「渴爱」同样是义注的释义（taṇhāparitassanā）被放进了本文。
  - saṅkhārā：§90 译「行」，§94 译「诸行」。
  - anupādā aparitassanaṃ：§87 译「因不执取而没有焦虑」，§95 结句译「不执取而不焦虑」。

  本层黑体目前对齐的是 §88/§92 的译法。父层统一时如果选了另一种，本层黑体要跟着改。

## §60 句 135-60-52-59

- **问题**：准确性（轻微）。原文 vipariṇāmassa anuparivattito … jātā 中，jātā（所生）同时管两个从格。现在的译文「由追随变坏而来，也就是由以变坏为所缘的心所生」把前一半译成「而来」，两个从格的并列关系不够清楚。
- **建议**：改为「是说从追随变坏，也就是从以变坏为所缘的心所生起的」。

## §60 句 135-60-91-99

- **问题**：风格（轻微）。原文 paritassako nāma hoti 中的 nāma 译成「所谓」，「成了所谓焦虑的人」读起来生硬。
- **建议**：改为「是说抓取之后，就称为焦虑的人」。

## §60 句 135-60-60-67

- **问题**：风格（轻微）。taṇhāparitassanā 译作「渴爱带来的焦虑」，意思没错，但和父层 §94–95 的「渴爱焦虑」不统一。
- **建议**：父层统稿后跟着统一。倾向保留本层这种分析性的译法，并把父层的「渴爱」去掉（见上文说明2）。
