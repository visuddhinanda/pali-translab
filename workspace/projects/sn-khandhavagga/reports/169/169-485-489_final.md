## 理由

**评估依据**：注入的数据里只有巴利原文和译文，没有义注（aṭṭhakathā），也没有 nissaya，所以只能按巴利原文逐句核对，评不了“义注定释义、nissaya 定词法”这两条。信心指数因此压低。补齐义注和 nissaya 后，应重点再核两处：489 段的常见表述（so attā so loko … so pecca bhavissāmi），以及 saṅkhāro so 里“行”指什么。

**准确性**：
- **句法主干**：这几段的主干都判断正确，没有发现漏译、多译或主谓宾判断错误。
- **各句核对**：
  - samanupassati 的四种句式区分清楚，分别是“视为我”“视为拥有”“视为在我之中”“视为在……之中”。
  - tatojo 补出“从渴爱而生”，解释合理。
  - Evampi 译“也能”，Evaṃ 译“就能”，488 段的差别处理得当。
  - saṅkhāre（复数）译“诸行”，saṅkhāro（单数，指这种看法）译“行”，两者区分得当。
  - 与 vedanā 译“受”相对，vedayita 译“感受”，原词不同，译法也不同，合理。
- **扣分点**：
  - na heva kho … api ca kho … 带让步语气，译成“确实不……但是……”，读起来像在陈述事实，让步的意味没有译出来。
  - 488 段连用 api ca kho，列的是几种可以择一的看法，译文用顿号并列，容易读成同一个人同时持有这几种看法。

**风格**：通篇是现代书面汉语，没有发现文言虚词或文言句式。标点全部是全角，内层引号用 ‘’，符合规范。段首的 “ 不闭合，与巴利原文一致，属于跨段引语的惯例，不扣分。扣分点有两处：
- “行”一词有两种意思，没有加注；
- “常见”在现代汉语里容易被读成“常常见到”。

**一致性**：各段重复的句式译法完全统一，包括凡夫句、因缘四问、无常有为缘生句、漏尽句。只有两处小问题：
- 指示词不统一：sopi saṅkhāro 译“这个行”，sāpi taṇhā 却译“那渴爱”；
- 489-33-48 译作“那个我”，与其他句子的指称习惯略有不同。

- `169-485-2-10`｜整句逻辑表达不规范｜片段「他确实不把色视为我」

  - 建议：改为“即使他不把色视为我，他却把我视为拥有色”一类的让步句式。

- `169-485-18-28`｜关键词语意不明确，或二意场合没有注释｜片段「就是行」
  - 问题：这里的“行”（saṅkhāro）指这种看法本身是造作出来的行，与五蕴中的行蕴不是一回事。本章紧接着又出现“诸行”（行蕴），读者容易混淆。
  - 建议：第一次出现时加脚注，说明这里的“行”指这种看法本身是一种造作（具体解释待与义注核对后再定），不是五蕴里的行蕴。
- `169-488-24-52`｜整句逻辑表达不规范｜片段「但是他把受视为我，把我视为拥有受，把受视为在我之中，把我视为在受之中」
  - 问题：原文连用四个 api ca kho，列的是几种可以择一的看法，译文用顿号并列，容易读成同一个人同时持有这四种看法。
  - 建议：改为“但是他或者把受视为我，或者把我视为拥有受，或者……”。
- `169-488-53-85`｜整句逻辑表达不规范｜片段「他把诸行视为我，把我视为拥有诸行，把诸行视为在我之中，把我视为在诸行之中」
  - 问题：同上，择一的意思没有译出来。
  - 建议：与上一句统一，用“或者……或者……”。
- `169-488-86-111`｜整句逻辑表达不规范｜片段「他把识视为我，把我视为拥有识，把识视为在我之中，把我视为在识之中」

### 🟦 suggestion
- `169-485-78-90`｜代词指代可能不够明确｜片段「这样知、这样见，也能紧接着达到诸漏的灭尽」
  - 问题：jānato / passato 是属格，指“这样知、这样见的人”。译文省掉了这个主体，结合上文容易读成前面那位凡夫“也能”达到漏尽。`169-486-85-97`、`169-488-174-186`、`169-489-61-80` 也有同样的问题。
  - 建议：改为“对这样知、这样见的人来说，诸漏也会紧接着灭尽”。
- `169-485-63-77`｜语言风格不统一｜片段「那渴爱也……那受也……那触也……那无明也」
  - 问题：前一句 sopi saṅkhāro 译“这个行”，这里的 sāpi 却译“那”，同类指示词前后不一致。
  - 建议：统一成“这渴爱也……这受也……这触也……这无明也”，或者前后都用“那”。另外三段的同一句（`169-486-70-84`、`169-487-74-89`、`169-488-158-173`）也要一起改。
- `169-489-33-48`｜语言表达不够流畅｜片段「死后我将成为那个我」
  - 问题：“成为”带有“转变成别的东西”的意思，而常见主张的是“我”死后恒常存在。“那个我”的说法也有些生硬。
  - 建议：改为“我死后将是那个我，是常住、恒久、永恒、不会变异的”。补齐义注后，再核对 so pecca bhavissāmi 中 so 的解释。
- `169-489-49-60`｜不常用术语编写注释或者百科｜片段「常见（sassatadiṭṭhi）」
  - 问题：“常见”在现代汉语里通常指“常常见到”，一般读者容易误解。
  - 建议：加脚注，或改成“常见（认为我与世界永恒存在的见解，sassatadiṭṭhi）”。
- `169-485-29-36`｜语言表达不够流畅｜片段「以什么为集起」
  - 问题：“集起”对一般读者比较生僻，读着有点拗口。
  - 建议：可以保留这个传统译法，但在术语表里定案；或者改为“由什么集起”。
