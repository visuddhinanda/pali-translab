# Review — 169:96-112（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，这些句子不单独出意见）

## 跨段一致性

- **paritassanā**：§96 经名、§97、§98 都译作“忧惧”，§108 摄颂译作“焦虑” → **必改**：§108 统一为“忧惧”。摄颂里的经名必须与正文经名一字不差。
- **upādāparitassanā / anupādāaparitassanā 的句式**：§97 用“因执取而忧惧”（表原因），§98 用“不执取就不忧惧”（表条件）。nissaya 对两者用的是同一结构：`စွဲလမ်းခြင်းဖြင့် တပ်မက်ခြင်း` 与 `မစွဲလမ်းခြင်းဖြင့် မတပ်မက်ခြင်း`，都带具格 `ဖြင့်`（凭借、由于） → 建议 §98 改为“因不执取而不忧惧”，跟 §97 对称。
- **Sāvatthinidānaṃ**：§97、§100、§102 译作“因缘发生在舍卫城”，§104 译作“以舍卫城为缘起” → 统一为前一种，三处都这样译。
- **anapekkho hoti**：§100、§102 译作“不再留恋”，§104 译作“不留恋”。nissaya：`အနပေက္ခော= ငဲ့ကွက်တွယ်တာခြင်းမရှိသည်`，意思是“没有留恋”，原文里没有“再”的意思 → 统一为“不留恋”。
- **nābhinandati**：§100、§102 译作“不再期待”，§104 译作“不欢喜”。nissaya：`နာဘိနန္ဒတိ= မနှစ်သက်မတောင့်တ`，即“不喜爱，也不渴望” → 建议统一为“不期待”或“不欢喜”，选一个三经通用；同样去掉“再”。
- **virāga / virajjati**：§100、§102、§112 译作“离染”，§104 译作“离贪” → 统一为“离染”。
- **nirodha**：§100、§102 译作“灭除”，§104 译作“灭尽” → 统一为“灭除”。
- **paccuppannassa … nibbidāya … paṭipanno hoti 的句式**：§100、§102 是“并且为了厌离、离染、灭除现在的色而修行”，§104 是“对于现在的色，他为了……而修行” → 三部同型经，§104 改成与 §100、§102 相同的句式。
- **atītānāgata 的位置**（省略句）：§100-46-58 只在“行”前加“过去和未来的”；§102-47-60 只在“识”前加；§104-48-60 在“受”前和“识”前都加 → 建议三经采用同一做法。
- **pe 的译法**：§97、§100 译作“……（略）……”，§112 译作“……乃至……”，§98-45-70、§102、§104 只用“……” → 统一一种。建议原文写 pe 的地方用“……（略）……”，原文只有 “…” 的地方用“……”。
- **passaṃ**：§100、§102、§104 译作“这样观察”，§112 译作“这样看的时候”。nissaya 两处都是 `ပဿံ= ရှုမြင်သော` → 统一为“这样观察”。
- **主语引入**：§97 是“这里有一个无闻的凡夫”，§98 是“这里有多闻的圣弟子” → 两句是对仗句，建议统一（都加“一个”或都不加）。

## §97 句 169-97-20-31
- **问题**：取义（供参考） — nissaya：`ဥပါဒါပရိတဿနာ= စွဲလမ်းခြင်းဖြင့် တပ်မက်ခြင်း`，把 paritassanā 释作 `တပ်မက်ခြင်း`（贪求、渴求），不是“恐惧”。§98 的 `မတပ်မက်ခြင်း` 也一样。
- **建议**：现在的译法“忧惧”与 nissaya 的取义不同。是否沿用要定案；不论定哪个，全章（经名、正文、摄颂）都要统一。

## §98 句 169-98-39-44
- **问题**：句式不对称 — nissaya：`တဿ= ထိုအရိယသာဝက၏ … ရူပဝိပရိဏာမညထာဘာဝါ= …ဖြစ်ခြင်းကြောင့်`，与 §97-59-63 结构相同（从格表原因，“由于……”）。可是 §97 译作“由于色发生变化……他就生起”，§98 译作“色发生变化……他却不会因此生起”，正反两句没有对上。
- **建议**：改为“由于色发生变化、变成另一个样子，他不会生起愁、悲、苦、忧、恼。”§98-78-83（识）同样改。

## §109 句 169-109-2-7
- **问题**：指涉 — nissaya：`တေန= ထိုသုတ်အများကိုစုထားခြင်းကြောင့်။ ဝဂ္ဂေါ= နကုလပိတုဝဂ်ဟူ၍။ ပဝုစ္စတိ= ဆိုအပ်၏`，意思是“由于汇集了这些经，（本品）被称为那拘罗父品”。tena 指的是上面列出的全部经，不是只指“过去、未来、现在”这一句。“本品由此得名”容易让人以为品名来自最后一句。
- **建议**：改为“……过去、未来、现在，汇集这些经，称为本品。”或者类似说法，让“由此”明确指整组经。

## §112 句 169-112-67-71
- **问题**：标点（必改） — 这句在佛陀的话里面（§112-13-37 已经用“开引号），内层引号应该用单引号。同经的 §112-72-90 已经用了 ‘’，这一句却用 “已经解脱”。
- **问题**：补出成分 — nissaya 补出了主语：`(မေ= ငါ၏။ စိတ္တံ= စိတ်သည်။) ဝိမုတ္တန္တိ`，即“我的心已经解脱”。
- **建议**：改为“解脱了，就生起‘（心）已经解脱’的智。”至少要把引号改成 ‘’。补不补“心”可以由译者决定。

## §112 句 169-112-72-90
- **问题**：取义（主释与异释） — nissaya 的主释是：`ဣတ္ထတ္တာယ= ဤမဂ်ကိစ္စအကျိုးငှါ။ အပရံ= တစ်ပါးသောမဂ္ဂဘာဝနာကိစ္စသည်။ နာတိ= မရှိ`，即“为了这件事（道的作用），再没有别的修道要做了”。“这一身之后不再有别的身”只是括号里的异释 `(ဣတ္ထတ္တာယ= ဤအတ္တဘောမှ။ အပရံ= တစ်ပါးသောအတ္တဘော…)`。译文“不会再有下一世了”取的是异释。
- **建议**：按 style.md 的规定（主译放正文，异释放脚注），正文可以改为“为了达到这个状态，再没有别的要做了”，“不会再有下一世”放进脚注。如果项目有意沿用通行的“不受后有”这一路解释，就在 terms.md 里登记定案。

## §105 句 169-105-2-4
- **问题**：补出成分（轻微） — nissaya 补出 `နိဋ္ဌိတော= ပြီးပြီ`（已经结束），意思是“第一品那拘罗父品完”。
- **建议**：可以改为“第一品那拘罗父品完。”，把品末的结束标记译出来。这一处可选。
