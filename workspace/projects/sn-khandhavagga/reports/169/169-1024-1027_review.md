# Review — 169:1024-1027（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位核对从缺）／义注 ✅（135:429–431 Hetusuttavaṇṇanā）
> 注：注入的义注各行都标成了 `layer=mula`，但它们实际是义注（book 135），本报告按义注处理。
> 本 chunk 是本文层，没有父层，所以不做被解释词与父层逐字同译的核对。下面的义注黑体词在本文里的译法，就是日后义注层必须逐字沿用的译法。发现的相关问题一并列在「跨层对应」一节。

## 跨段一致性
- **bhūtā / abhijāti 同译「生类」**：§1025 句 65-84 把 bhūtā 译成「一切生类」，同句又把 abhijāti 译成「六种生类」。§1025 句 112-126、150-165 和 §1026 各句的「六种生类」也是同样的译法。这是两个不同的词，义注对两者的解释也完全不同。
  - **义注**：bhūtā 指 “aṇḍakosavatthikosesu bhūte”（在卵壳、胎膜中生成的）。
  - **义注**：abhijāti 是邪命外道的六种阶层，saṅgati 就是 “channaṃ abhijātīnaṃ tattha tattha gamanaṃ”（在六种阶层中到处流转）。
  - 建议：abhijāti 全 chunk 统一改为「六种阶层（abhijāti）」，首次出现时夹注巴利原词；bhūtā 保留「生类」。共涉及 7 处，要一起改。
- **natthi hetu, natthi paccayo**：§1025 的完整句译「没有因，也没有缘」，各处省略句译「没有因，没有缘」。建议统一为「没有因，也没有缘」。
- **句末标点**：§1025 句 65-84 是世尊整个问句的结尾（Pali 以 `’’’ ti ?` 收尾），译文却是「感受苦乐。’”」。§1026 的同类问句都是「’？”」，建议统一。

## 跨层对应（供 harmonize 用）
- 义注的被解释词依次是：Natthi hetu / natthi paccayo / Natthi balaṃ / Natthi vīriyaṃ / Sabbe sattā / pāṇā / bhūtā / jīvā / Avasā abalā avīriyā / Niyatisaṅgatibhāvapariṇatā（niyatī / saṅgatī / bhāvo 还要分开解释）/ Chasvevābhijātīsu。本文的译法要能逐个切出来：
  - avasā abalā avīriyā：本文译成「都不能自主，没有力量，没有精进」，其中「都」是 sabbe 带出来的。义注引用时应只取「不能自主，没有力量，没有精进」，本文不用改。
  - niyati / saṅgati / bhāva：本文三个词各有独立译名，可以对上，但取义要按下文 §1025 句 65-84 修正。
- 标题「7. 因经」：义注层的标题应作「7. 因经注释」，hetu 统一作「因」。

## §1025 句 169-1025-2-8
- **问题**：术语混淆。「缘起」是 paṭiccasamuppāda 的固定译名，用来译 nidāna（因缘、说法的地点）容易让人误读成教义用语。
- **建议**：改为「因缘在舍卫城。」或「（本经）在舍卫城宣说。」

## §1025 句 169-1025-65-84
- **问题 1**：义注取义。saṅgati 译成「际遇」，取了「偶然遭遇」的意思，与义注不合。
  - **义注**：“Saṅgatī ti channaṃ abhijātīnaṃ tattha tattha gamanaṃ”，指在六种阶层中到处流转。
- **问题 2**：义注取义。niyati 译成「命运」，范围太宽泛。
  - **义注**：“niyatī ti niyatatā”，意思是「命定、定数」，重点在已经定死。
- **问题 3**：pariṇatā 译成「被……所转变」，没有译出义注的意思。
  - **义注**：“nānappakārataṃ pattā”，意思是转变成种种不同的状态。
- **问题 4**：abhijāti 与 bhūtā 撞译，见「跨段一致性」一节。句末标点应是问号，同见该节。
- **建议**：「……都不能自主，没有力量，没有精进，由命定、在各阶层间的流转和本性而转变成种种状态，只在六种阶层（abhijāti）中感受苦乐’？”」

## §1025 句 169-1025-65-84（附带）
- **问题**：用词偏旧。sabbe jīvā 译成「一切有命者」，稍带文言味。
  - **义注**：jīvā 指稻、麦等作物，外道因为它们会生长，就把它们看作有生命的东西。
- **建议**：改为「一切有生命者」，不属必改。

## §1026 句 169-1026-19-36
- **问题**：取义偏窄，语气也不对。
  - vipariṇāmadhamma 是「会变化的」，译成「会变坏的」把意思缩窄了。
  - 这半句属于世尊的问话，被省略的部分是「凡是无常、苦、会变化的……」。现在的译文「是会变坏的」读起来像一句陈述。
- **建议**：「“是无常的，大德。”……“……凡是会变化的，如果不执取它，还会生起这样的见解吗：」

## §1026 句 169-1026-120-139
- **问题 1**：翻译腔。连用七个「被……」，读着生硬。
- **问题 2**：数的问题。tampi 是单数，意思是「那也」，译成「这些」不准确。
- **建议**：「“凡是看到的、听到的、感觉到的、认识到的、得到的、寻求过的、内心反复思索过的，这一切是常还是无常？”」

## §1027 句 169-1027-2-45
- **问题 1**：漏译或合并。niyato（已确定）和 sambodhiparāyano（以正觉为归宿）两个词被合并成「必定会证得正觉」，niyato 没有单独译出。
- **问题 2**：增译。avinipātadhammo 是「不会堕入恶道」，原文没有「再」字。
- **问题 3**：术语待定。sotāpanna 译作「入流者」，与传统的「预流者」「须陀洹」不一致，而 `terms.md` 还没有登记这个词。这不算必改，定案后请补进术语表。
- **建议**：「……这样的圣弟子就叫做入流者（sotāpanna），不会堕入恶道，已经确定，以正觉为归宿。”」
