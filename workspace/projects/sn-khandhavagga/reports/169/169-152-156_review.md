## 跨段一致性

- **ayaṃ / idaṃ（“这”）**：§153 同一组排比句里写法不统一。“乐味”句（103-115、136-154、174-191、220-230）译作“就是……”，“过患”“出离”句（116-125、126-135 等）译作“这就是……”。原文三句都有指示代词 ayaṃ / idaṃ，**建议统一为“这就是……”**。依据是原文句式一致，而且这是排比句。
- **sambodhi / abhisambuddha（正觉 / 证悟）**：§153 把 sambodhā 译作“正觉”、anabhisambuddhassa 译作“尚未证悟”，§154 把 abhisambuddho 译作“证悟了”。这两个词同根，建议**固定一种对应关系**：名词 sambodhi 译“正觉”，动词 abhisambujjhati 及其分词一律译“证悟”，并登记进 `terms.md`。
- **assāda / ādīnava / nissaraṇa**：全 chunk 一律译作“乐味 / 过患 / 出离”，前后一致。`terms.md` 目前是空的，**建议登记**，一并登记 upādānakkhandha = 取蕴、chandarāga = 欲贪。
- 语体方面没有发现文言或半文半白的写法。“乃至”是 pe 的固定译法，“之前 / 之后 / 之中”是现代汉语固定词，都不算问题。

## §153 句 169-153-9-39

- **问题**：措辞 / 术语衔接。“在我正觉之前”把“正觉”当动词用，读起来生硬；紧接着的“尚未证悟的菩萨”又用了另一个词，两者关系不清楚。
- **建议**：改为“比丘们，在我正觉以前，还是尚未证悟的菩萨时，我曾这样想：”。或者统一改为“在我证得正觉以前，还是尚未证悟的菩萨时……”。

## §153 句 169-153-116-125（同类：155-164、192-210、231-240）

- **问题**：取义偏窄。vipariṇāmadhamma 字面意思是“有变易性质的”，“会变坏的”带有“往坏处变”的附加意思，比原文窄。这里缺义注，没法确认传统解释。
- **建议**：四处统一改为“会变易的”或“必然变化的”。这一项等拿到义注后复核。

## §153 句 169-153-136-154

- **原文疑问（不改）**：异读注 `[ yā ( ka .)]` 放在 assādo 之后，所指不明，按理应当是对句首 Yaṃ 的异读。先记下来备查。

## §153 句 169-153-192-210

- **原文疑问（不改）**：Yaṃ 后面跟复数主格 saṅkhārā，另有异读 `[ye (sī. ka.)]`。现在译文按连接词 yaṃ 处理，与 rūpa、vedanā 各句的译法一致，可以接受，这里只作记录。

## §154 句 169-154-2-44

- **问题①**：漏译。原文 `evaṃ assādañca assādato…`（“像这样把乐味了知为乐味……”）里的 evaṃ 没有译出来，它承接的是 §153 的分析。
- **问题②**：措辞。“乐味就是乐味、过患就是过患”容易被读成同义反复。原文的结构是“把 X 作为 X 来了知”（assādaṃ assādato）。
- **建议**：改为“比丘们，只要我还没有像这样把这五取蕴的乐味如实了知为乐味、把过患如实了知为过患、把出离如实了知为出离，比丘们，我就始终没有宣称……”。“neva tāva”译作“始终没有 / 还没有”，比“就没有”更贴切。
- **存疑（缺义注，待复核）**：sadevake loke…pajāya 这组处格短语，现在的译文把它挂在“证悟”上。它也可能修饰“宣称”，也就是“向这个世间宣称”。拿到义注后要确认归属。

## §154 句 169-154-45-63

- **问题**：同上，漏译 evaṃ，“X 就是 X”的问题也一样。
- **建议**：改为“比丘们，而当我像这样把这五取蕴的乐味如实了知为乐味、把过患如实了知为过患、把出离如实了知为出离之后，”。

## §156 句 169-156-145-165

- **问题**：与 §154 的对应句同构，需要跟着一起改。这里原文没有 evaṃ，不用补“像这样”。
- **建议**：改为“比丘们，只要我还没有把这五取蕴的乐味如实了知为乐味、把过患如实了知为过患、把出离如实了知为出离……乃至……如实了知了。”

## §156 句 169-156-72-91

- **问题**：结构。原文在每个蕴后面都重复了 `…āhaṃ, bhikkhave …`，省略号代表的是整组“乐味 / 过患 / 出离”的探求。现在的译文把它压成“探求受的……想的……识的乐味”，读起来像一个定语串，看不出每个蕴都省略了整段内容。
- **建议**：改为“比丘们，我曾去探求受的……比丘们，我曾去探求想的……比丘们，我曾去探求行的……比丘们，我曾去探求识的乐味。”
