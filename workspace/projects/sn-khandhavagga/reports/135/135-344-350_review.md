## 跨段一致性

- **vicarati（走动）**：§345（135-345-243-256）小鸡「在村子一带**四处走动**」，§349（135-349-17-36）复述同一画面时作「在村子一带**来回走动**」。两处是同一譬喻的前后呼应，建议统一为「四处走动」。
- **vipassanā**：§346 作「观智」「增长观」，未加夹注；§350（135-350-63-67）作「修观（vipassanā）」才首次夹注。
  - 夹注应移到 §346 首次出现处。
  - §350 的「修观」与 §346 的「观」也应统一。建议都作「观」，§350 改为「观（vipassanā）的利益」只保留在首次出现处的夹注，或改为「观的利益」。

## §345 句 135-345-20-27
- **问题**：句法 — nissaya：`ကဏှပက္ခဥပမာ= ကဏှပက္ခဥပမာသည်` 为主格，`အတ္ထဿ= …အစီးအပွားကို`、`အသာဓိကာ= မပြီးစေတတ်`。也就是说，主语是譬喻本身「不能成就所要的意义」。译文「说的是达不到目的」把它变成了譬喻的内容，主语关系不对。
- **建议**：「其中，反面的譬喻不能成就所要表达的意义，另一个能成就。」

## §345 句 135-345-28-41
- **问题**：词义 — api 这里取 sambhāvana（nissaya：`ဤသို့ဖြစ်သင့်ရာ၏ဟု ကြံဆသော အနက်`，推想「应当如此」）。括注「（也）」是 api 的常义，和下文「表示推想」相抵。
- **建议**：去掉「（也）」，作「**api** 表示推想的意思」。

## §345 句 135-345-49-73
- **OCR / 原文疑问**：pali 黑体作 `aṭṭha vā dasa vā dasa vā dvādasa vā`，「dasa vā」重复了一次。nissaya 与父层都只有一次，疑为讹衍。译文按一次处理是对的，原文只记录，不改。

## §345 句 135-345-105-116
- **问题**：补出成分 — nissaya：`ဥတုံ= မိမိ၏ကိုယ်ငွေ့ကို`，即「自己的体温」。译文「让蛋得到温度」没有点明热源是母鸡自身。
- **建议**：「是说母鸡时时让蛋吸收自己的体温……」

## §345 句 135-345-130-145
- **问题 1**：译文末尾的「（小鸡仍然能钻出来）」是原文没有的补语。下一句 146-160 紧接着就解释了这一点，这里属于重复补出。
- **建议**：删去括注。
- **OCR / 原文疑问**：pali 作 `upajjeyya`，nissaya 与父层作 uppajjeyya，疑为脱字。只记录，不改。

## §345 句 135-345-161-242
- **问题**：主语误读（必改）— `sayampi pariṇāmaṃ gacchanti`，nissaya：`သယမ္ပိ= ကြက်ငယ်ဟူသော မိမိသည်လည်း`，`ပရိဏာမံ= ရင့်ခြင်းသို့`。成熟的主语是「小鸡自己」（sayaṃ 指 te，即小鸡，动词为复数 gacchanti），不是蛋。译文「蛋自己也发育成熟」把主语弄错了。
- **建议**：「小鸡自己也长成熟了」。
- **问题（次要）**：`saṅkuṭitahatthapādā`，nissaya：`ကွေးသော လက်ခြေရှိကုန်သည်`（手脚蜷曲）。译文「蜷缩着身子」把手脚泛化成了身子。
- **建议**：「我们蜷缩着手脚……」

## §346 句 135-346-8-112
- **OCR / 原文疑问 1**：pali 作 `bhāvānuyogaṃ`，nissaya 作 bhāvanānuyogaṃ，疑为脱字。只记录。
- **OCR / 原文疑问 2**：`vaḍḍhitakālo`，nissaya 读作 `ဝုဋ္ဌိတကာလော= ဝုဋ္ဌာနဂါမိနိဝိပဿနာဖြစ်ရာအခါ`（vuṭṭhitakālo，出起观生起之时）。译文「增长」依 pali 原文，可以保留。这是异读，写入报告备查。
- **问题**：`vipassanāñāṇagabbhaṃ gaṇhāpetvā`，nissaya：`ဂဗ္ဘံ= မဂ်ဉာဏ်တည်းဟူသော ကိုယ်ဝန်ကို`，`ဂဏှာပေတွာ= ယူစေ၍`，即让观智怀上道智之胎（使役）。译文「让观智成胎」意思模糊，读者不容易看出「胎」指的是什么。
- **建议**：「让观智怀胎以后四处行走」，或「让观智孕育成胎以后……」，与前文「成胎的时候」保持呼应。

## §346 句 135-346-113-129
- **问题**：句法（必改）— 本句主语 `satthāpi` 的谓语是 §349 的 `paharati`（nissaya 349：`ဖရိတွာ= ဖြန့်တော်မူ၍`、`ပဟရတိ= ပုတ်ခတ်တော်မူ၏`，敬语动词，主语是佛陀）。中间夹着偈颂，`ādinā nayena` 修饰的是 paharati。译文在这里补了原文没有的「也会说——」，结果：
  - §349 的谓语丢了主语；
  - 「以上面所说等方式」与「说」语义重复。
- **建议**：本句改为「……同样，导师知道这样的比丘的智已经成熟，也会——」，谓语留到 §349 补出。

## §348 句 135-348-2-19
- **问题**：句法 — 依 349 行内偈颂 nissaya：`နိဗ္ဗာနံ= နိဗ္ဗာန်သို့`，`ပတ္ထုကာမော= ရောက်တော်မူခြင်းငှာအလိုရှိသည်ဖြစ်၍`，`သန္တိမဂ္ဂမေဝ= …အဋ္ဌင်္ဂိကမဂ်ကိုသာလျှင်`，`ဗြူဟယ= ပွားစေလော့`。nibbānaṃ 是目标：「为了到达善逝所说的涅槃，只管培育寂静之道（八支圣道）」。译文「那寂静就是善逝所教导的涅槃」把 nibbānaṃ 处理成了 santi 的同位语，与 nissaya 的句法分析不同。
- **建议**：「只管培育通往寂静的道路，去往善逝所教导的涅槃。」
- **次要**：§347 `ucchinda … pāṇinā`，nissaya 作 `ဖြတ်` / `ဥစ္ဆိန္ဒတိ ဣဝ`（摘断、割断）。「拔掉」可以改为「摘断」，与「断除」相呼应。

## §349 句 135-349-2-9
- **问题**：补出成分 — 承接 §346 的修改，本句需要补出主语「导师」（nissaya 动词带敬语 `တော်မူ`）。「以上面所说等方式」中的「上面所说」也与引偈直接相连，显得多余，「以」字偏文言。
- **建议**：「用这首偈颂等方式放出光明，以偈颂敲击他的无明蛋壳」，或整句作「——用这样的方式放出光明，用偈颂敲击他那无明的蛋壳。」（主语已在 §346 交代）

## §350 句 135-350-22-41
- **问题 1**：`pabbajjāsaṅkhepena`，nissaya：`ရဟန်းအဖြစ်ဟူသော … ကောင်းစွာကုန်ကြောင်းဖြစ်သော အကျင့်ဖြစ်လည်းကောင်း`。这是与后面四项并列的工具格之一（`…လည်းကောင်း`），并没有「仅仅」的意思。译文「单凭出家本身」中的「单凭」是多加的，而且与下文「以及」相矛盾。
- **建议**：「凭着出家本身，以及……」
- **问题 2**：`uddesena`，nissaya：`ပါဠိသင်ခြင်း`（学习圣典）；`paripucchāya`，nissaya：`အဋ္ဌကထာသင်ခြင်း`（学习义理）。「诵习、请问」可以接受，但「请问」没有交代问的对象。
- **建议**：「诵习圣典、请问义理」。
