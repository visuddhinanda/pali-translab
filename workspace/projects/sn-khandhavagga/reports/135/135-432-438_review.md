# Review: 135:432-438（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（433–438 各句；432 标题段无 nissaya，略过）

## 被解释词与父层对照

全部黑体被解释词都已逐条比对父层（169:1028-1031）译文，各条都是父层同一处译文的原样片段，**没有发现不一致**。核对过的词条：akaṭā / akaṭavidhā / animmitā / animmātā / vañjhā / kūṭaṭṭhā / esikaṭṭhāyiṭṭhitā / na iñjanti / na vipariṇamanti / na aññamaññaṃ byābādhenti / nālaṃ / pathavīkāyo / sattannaṃtveva kāyānaṃ / yonipamukhasatasahassāni / pañca ca kammuno satāni / pañca ca kammāni tīṇi ca kammāni / kamme ca aḍḍhakamme ca / dvaṭṭhipaṭipadā / dvaṭṭhantarakappā / chaḷābhijātiyo / aṭṭha purisabhūmiyo / ekūnapaññāsa ājīvakasate / paribbājakasate / nāgavāsasate / vīse indriyasate / tiṃse nirayasate / rajodhātuyo / satta saññīgabbhā / satta asaññīgabbhā / nigaṇṭhigabbhā / satta devā / satta pesācā / sarā / pavuṭā / papātā / papātasatāni / supinā / supinasatāni / mahākappino。

## 跨段一致性

- **vadanti / vadati 的主语**：本 chunk 的“他们说”（vadanti）一般指持此见者（邪命外道一方），“他说”（vadati）指末伽梨。§435 句 135-435-71-79 的 vadanti 按 nissaya 指的是**另一些解释者**（见下），译文仍作“他们说”，读者会误认为说话的还是同一方。这一句须单独改，其余各句的“他们说”保持现状。
- **-sata（百）的处理不统一**：
  - §437 paribbājakasate、nāgavāsasate 译作“……，以百计数”。
  - §437 vīse indriyasate、tiṃse nirayasate 译作“二十个一百／三十个一百，也就是……”。
  - §438 papātasatāni、supinasatāni 译作“数百个／数百种”。
  - 释文的作用都是把 -sate 还原为 -satāni（复数“百”）。建议统一一种说法，例如一律作“成百的……”，或一律只给出数目。

## §435 句 135-435-71-79

- **问题**：主语误读。nissaya 末尾补出了 `ဣတိ= ဤသို့သော အနက်ကို။ အပရေ= တစ်ပါးသော သူတို့သည်။ ဝဒန္တိ= ဖွင့်ကုန်၏။`，即说话的是“另一些人”，他们给出的是另一种解释，不是邪命外道自己的说法。nissaya 还补出了两点：
  - `ဗာဟိရဿ`（佛教以外的）
  - `တေ= … နီလာဘိဇာတိ မည်ကုန်၏`（这些人才是青生类）

  现译“或者，他们说有一类出家人就叫作‘以荆棘为生的人’”没有交代说话者已经换了人，也看不出这一句是在为“青生类”换一种解释。
- **建议**：改为“或者，另有人解释说：有一类出家人本来就叫作‘以荆棘为生的人’，青生类指的是他们。”如需交代“佛教以外”，可写作“有一类外道出家人”。

## §435 句 135-435-118-128

- **问题**：人名切分与 nissaya 不同（存疑，不定为错）。nissaya 把五个名字逐一列出：
  - `နန္ဒော`、`ဝစ္ဆော`、`ကိသော`、`သံကစ္ဆော`、`မက္ခလိဂေါသာလော`，各带一个 `လည်းကောင်း`
  - 下一句 135-435-129-133 的 nissaya 又明说 `ငါးဦးသော ဆရာကြီးတို့`（五位大师）

  现译“难陀·婆蹉、吉舍·桑吉叉、末伽梨·瞿舍罗”按三人译出。巴利标点（Nando vaccho , kiso saṃkicco , makkhali gosālo）支持三人的读法。
- **建议**：维持三人译法，但压低这一句的 confidence，把 nissaya 作五人解的分歧记录在案。

## §436 句 135-436-97-114

- **问题**：词义与句法。
  - nissaya：`ဇိနော(ဇိဏ္ဏော)= အိုးမင်းထိုင်းမှိုင်းသည် ဖြစ်၍`。jino 读作 jiṇṇo（衰老），现译“困乏了”不对。
  - `ပန္နကော … ကျသော` 是修饰 bhikkhu 的定语（衰落的比丘），不是与“衰老”并列的两个谓语。
  - `အလာဘီ= နည်းသောလာဘ်ရှိသော` 是“少有所得”，不是完全“得不到供养”。
- **建议**：改为“‘衰落的比丘已经衰老，什么话也不说’——他们把这样少有供养的沙门称为衰落阶段。”

## §437 句 135-437-17-22 ／ 135-437-23-28

- **问题**：数目与 nissaya 不同（存疑）。
  - nissaya：`ဝီသ ဣန္ဒြိယသတာနိ= တစ်ရာ့နှစ်ဆယ်သော`（一百二十）
  - nissaya：`တိံသ နိရယသတာနိ= တစ်ရာ့သုံးဆယ်သော`（一百三十）

  按巴利语法，vīsa…satāni 应是“二十个百”。父层已定稿作“两千种根”“三千种地狱”，被解释词必须与它一致，不能改。
- **建议**：被解释词维持原样。释文中“也就是两千种／三千种”是译者补的，可以保留，但要把 nissaya 的异读记录在案。

## §437 句 135-437-37-43

- **问题**：pasu 译成“家畜”，是一个统称，夹在一串具体动物名里不协调。nissaya 在 aja（`ဆိတ်မြတ်မာ`，山羊）之后单列 pasu 为 `ဆိတ်ကုလား`，是另一种羊。
- **建议**：pasu 改译“绵羊”，全句作“骆驼、牛、驴、山羊、绵羊、鹿、水牛”。

## §437 句 135-437-44-50

- **问题**：谷物名与 nissaya 不符。nissaya 的对应是：
  - varaka = `ပြောင်း`（高粱／蜀黍类），不是“菜豆”
  - kudrūsaka = `လူး`（一种小粒黍）
- **建议**：varaka 改译“高粱”。kudrūsaka 维持“黍”。

## §437 句 135-437-78-86

- **问题**：mahantamahantā 的取义与句子结构有误。
  - nissaya：`မဟန္တမဟန္တာ= အလွန်များပြားကုန်သည်ဖြစ်လျက်`，意思是“极其众多”，不是“巨大”。
  - 句末 `ဝဒတိ= မသိ၍ဆို၏`（因为不知道才这样说）。
  - 现译“毕舍遮有很多巨大的”把“很多”和“巨大”混在一起，句子也不通。
- **建议**：改为“**七种毕舍遮**：毕舍遮多得很，他却说只有七种。”

## §436 句 135-436-91-96

- **问题**：jānana 的宾语译得太泛。nissaya：`ဇာနနကာလေ= ဝတာဝတကို သိရာကာလ၌`，意思是懂得应做与不应做（行持的对错）的时期。现译“获得知识”过于笼统。
- **建议**：改为“亲近老师、懂得什么该做什么不该做的时期，叫作了知阶段。”
