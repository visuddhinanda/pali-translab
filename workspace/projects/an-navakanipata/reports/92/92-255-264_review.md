# Review — 92:255-264（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **āvuso 的数**：§256 开头一段（句 22-29、30-39）译「贤友们」。从 §256 句 77-82 起到 §264，nissaya 一律释为 `အာဝုသော= ငါ့ရှင်တို့`（复数），而且 §256 句 65-76 后的方括号注明这里是舍利弗转向众比丘继续说，但这些句子的译文都作「贤友」（单数）。只有 §256 句 65-76 的 nissaya 是 `ငါ့ရှင် ဥဒါယီ`，单称优陀夷，这一句译「贤友」是对的。→ 建议：§256 句 77 以后各句（包括没有 nissaya 的同式句）统一改为「贤友们」。
- **-sahagatā 的译法（系统性问题）**：kāma- / vitakka- / pīti- / upekkhā- / rūpa- / ākāsānañcāyatana- / viññāṇañcāyatana- / ākiñcaññāyatana-sahagatā 全部译成「与 X 相应的」。nissaya 一律释为 `X ဟူသော အာရုံနှင့် တကွ`（伴随着 X 这一所缘）或 `X အာရုံရှိကုန်သော`（以 X 为所缘）。§257 的长注还明说这里 sahagata 取「所缘」义（`သဟဂတ သဒ္ဒဿ အာရမ္မဏတ္ထော`），想与作意同 kilesakāma 才是「相应」（sampayutta）关系。「相应」是 sampayutta 的定译，用在这里就把所缘关系译成了相应关系。→ 建议：八处（包括没有 nissaya 的同式句 §259 句 50-55）统一改为「以 X 为所缘的想和作意」。
- **sukha / somanassa / pīti 的译名**：§256 句 124-141 把 sukhaṃ somanassaṃ 译作「快乐和喜悦」，§259 句 2-20 把 pīti 译作「喜」。「喜悦」与「喜」在读者看来是同一个东西，但原文是两个法。→ 建议：somanassa 改用「悦」或「心的愉悦」，与 pīti「喜」分开（见该句意见）。
- **ābādha 前后不一**：比喻句中 yāvadeva ābādhāya 译作「受到损害」，紧接的 svassa hoti ābādho 译作「病患」。同一个词在同一个比喻里分成两译，比喻与合法（evameva…）之间的呼应就看不出来了。nissaya 前者作 `ညှင်းပန်းနှိပ်စက်ခြင်း`（折磨、逼迫），后者作 `အနာရောဂါ`（病）。→ 建议：比喻句改为「只会折磨他」，至少不要用意思偏弱的「损害」。各段比喻句（§257–264，多数没有 nissaya）一并改。

## §256 句 92-256-15-21
- **问题**：词法 — `တတြ= ထိုအခါ၌`，nissaya 把 tatra 取时间义（"那时"），括注是"世尊……住在竹林时，在那时"。译文「在那里」取的是处所义。
- **建议**：改为「那时，尊者舍利弗对比丘们说——」。

## §256 句 92-256-22-29
- **问题**：异释未列 — `ဝါ= ဤဒုက္ခခပ်သိမ်း ချုပ်ငြိမ်းခြင်းသည်`，nissaya 另释 idaṃ nibbānaṃ 为"一切苦的止息"。
- **建议**：正文不改。按 style.md 第四节，异释可在脚注里备列（交 footnote 步处理）。

## §256 句 92-256-48-64
- **问题**：词法 — 有两处。
  - `ဝေဒိယိတံ= အာရုံကို ခံစားရခြင်းသည်`：vedayitaṃ 是"领受所缘这件事"，即感受本身。译文「被感受的东西」把它译成了所感受的对象。
  - `ယံ (ယေန)= အကြင်အကြောင်းကြောင့်` … `(တေန= ထို့ကြောင့်)`：yaṃ 作原因读（"既然……所以"），译文的「那」承接得太弱。
  - 另外，`ဧတ္ထ= ဤနိဗ္ဗာန်၌`：ettha 指涅槃，可以考虑译明。
- **建议**：「舍利弗贤友，既然在这里（涅槃中）没有感受，那么这里的快乐又是什么呢？」

## §256 句 92-256-65-76
- **问题**：词法 — vedayitaṃ 同上句，应是"感受"，不是"被感受的东西"。`ဧတဒေဝ= ထိုအာရုံခံစားရမှုမရှိခြင်းသည် ပင်လျှင်`，"正是这没有感受"本身就是乐。
- **建议**：「贤友，正因为这里没有感受，这里才是快乐的。」或者保留原句式，只把「没有任何被感受的东西」改为「没有感受」。与上一句保持同一译法。

## §256 句 92-256-86-123
- **问题**：格 — `စက္ခုဝိညေယျာ= စက္ခုဝိညာဏ်ဖြင့် သိအပ်ကုန်သော`。具格的施事是眼识，不是眼。耳、鼻、舌、身各句同此。
- **建议**：「眼识所识知的色……耳识所识知的声……」。如果为了可读性保留「眼所能识」，至少五处要统一。

## §256 句 92-256-124-141
- **问题**：词法与术语 — `ယံ သုခံ= ကာယိကသုခဝေဒနာ`（身乐受）、`ယံ သောမနဿံ= စိတ်ချမ်းသာမှု သောမနဿဝေဒနာ`（心悦受），nissaya 明确分为身、心两种。译文「快乐和喜悦」既没有体现身心之分，「喜悦」又与 §259 的 pīti「喜」相混。
- **建议**：「贤友们，依这五种欲境而生起的乐与悦，贤友们，这叫做欲乐。」

## §257 句 92-257-17-33
- **问题**：词法 — 有两处。
  - `ကာမသဟဂထာ= ဝတ္ထုကာမဟူသော အာရုံနှင့် တကွဖြစ်ကုန်သော`／`ဝါ= ဝတ္ထုကာမဟူသော အာရုံရှိကုန်သော`：sahagata 是所缘义，「与欲相应」译错了关系（见跨段一致性）。
  - 另外，`သမုဒါစရန္တိ` 有异释"驱迫他趋向欲境"（`ထိုးနှက် မောင်းနှင်`）。
- **建议**：「……以欲为所缘的想和作意如果出现，那对他来说就是病患。」异释可以作脚注备列。

## §257 句 92-257-34-43
- **问题**：词法 — 有两处。
  - `ဥပ္ပဇ္ဇေယျ သေယျထာပိ= ဖြစ်ရာသကဲ့သို့`：这是假设式（"就像……会生起那样"）。译文「也会生起」读起来像在陈述常态。
  - `ယာဝဒေဝ အာဗာဓာယ= ညှင်းပန်းနှိပ်စက်ခြင်းတိုင်ရုံ အကျိုးငှာ သာလျှင်`："仅仅为了折磨"，「受到损害」的语义偏弱。
- **建议**：「贤友们，就好比一个安乐的人如果生起了痛苦，那只会折磨他；」（后面各段的同式句一并改。）

## §257 句 92-257-44-49
- **问题**：词法 — kāmasahagatā 的问题同 §257 句 17-33。
- **建议**：「同样地，那些以欲为所缘的想和作意在他身上出现。」

## §258 句 92-258-20-37
- **问题**：词法 — `ဝိတက္ကသဟဂတာ= ပဌမဈာန်ဝိတက်ဟူသော အာရုံနှင့် တကွ`／`ဝါ= ဝိတက်ရှိသော ပဌမဈာန်အာရုံရှိကုန်သော`：所缘是有寻的初禅，nissaya 注明这是以寻代指整个初禅（upalakkhaṇa）。第二禅中本来就没有寻，译成「与寻相应」会让人误解为二禅里还有寻在相应。
- **建议**：「……以寻为所缘的想和作意……」，另出脚注说明"指有寻的初禅"。

## §258 句 92-258-48-54

## §259 句 92-259-21-38
- **问题**：词法 — `ပီတိသဟဂတာ= ဒုတိယဈာန်ပီတိဟူသော အာရုံနှင့်တကွ`／`ဝါ= ပီတိရှိသာ ဒုတိယဈာန်ဟူသော အာရုံရှိကုန်သော`：所缘是有喜的第二禅。

## §260 句 92-260-21-37
- **问题**：词法（必改）— `ဥပေက္ခာသဟဂတာ= တတိယဈာန်တတြမဇ္ဈတ္တုပေက္ခာ ဟူသော အာရုံနှင့် တကွ`：所缘是第三禅的中舍。第四禅本身就有舍，译成「与舍相应的想和作意是病患」，等于说第四禅自身的成分是病患，意思自相矛盾。
- **建议**：「……以舍为所缘的想和作意……」，脚注说明"指有中舍的第三禅"。

## §261 句 92-261-23-39
- **问题**：词法（必改）— `ရူပသဟဂတာ= ရူပဈာန်ဟူသော အာရုံနှင့်တကွ`／`ဝါ= ရူပဈာန်ဟူသော အာရုံရှိကုန်သော`：rūpa 在这里指色界禅，不是色法或色境。「与色相应」会让读者理解成"与色法相应"。
