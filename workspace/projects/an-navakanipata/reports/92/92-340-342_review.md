# Review — 92:340-342（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核）

## 跨段一致性

- **upekkhāsukhe / upekkhāsahagatā**：§342 把 upekkhāsukhe 译作“舍俱的乐”，同段 upekkhāsahagatā 译作“与舍俱行”。两者字面上都带“舍俱”，读者会以为结构相同，但按 nissaya 两者结构不同（见下文 §342 句 92-342-87-108）。upekkhāsukhe 改为并列结构后，这个混淆随之消除。共 3 处，需统一修改。
- **vitakkesu / avitakke 与 vitakkavicārānaṃ**：§340 中 vitakkavicārānaṃ 译作“寻与伺”，但 vitakkesu 译作“寻”，avitakke 译作“无寻”。nissaya 明确指出这里的 vitakka 连带伺一并包括（见下文 §340 句 92-340-82-104），所以本段对同一组法的译法前后不一。建议全段统一为“寻伺”／“无寻伺”。
- **pasīdati 的译法**：§340–342 各处的 nappasīdati / pasīdati / pasīdeyya 一律译作“净信”。nissaya 一律作 ကြည်လင် = 澄清、明净，指心在禅定中澄净，并非对人或法生起信心。三段的译法虽然一致，但取义偏了，建议统一改为“澄净”（非必改，修订时请一并斟酌）。

## §340 句 92-340-82-104

- **问题**：数／所指 — 原文 vitakkesu 是复数。nissaya 注：`[ဝိတက္ကသဒ္ဒါဖြင့် ထိုဝိတက်နှင့် အတူတကွ ဖြစ်ဖက် ဝိစာရကိုပါယူရ၏၊ ထို့ကြောင့်ပင် "ဝိတက္ကေသု" ဟု ဗဟုဝုစ်ဖြင့် ဟောတော်မူသည်]`，意思是“寻”这个词也包括与寻同起的伺，所以用复数。nissaya 也写明 `ဝိတက္ကေသု= ဝိတက်ဝိစာရတို့`。avitakke 同样释作 `ဝိတက်ဝိစာရ မရှိသော ဒုတိယဈာန်၌` = 在没有寻伺的第二禅中。译文“寻的过患”“无寻的利益”只译出了寻，把伺漏掉了。
- **建议**：改为“寻伺的过患”“无寻伺的利益”。本段同类句子一并修改：92-340-26-43、51-74、105-120、128-160、161-179、180-194 中的“无寻的境界”“寻的过患”。

## §340 句 92-340-26-43

- **问题**：隐含成分 — nissaya 补出 avitakke 所指：`ဝိတက်ဝိစာရမရှိသော ဒုတိယဈာန်၌`（在无寻伺的第二禅中）；etaṃ 释为 `ဤအဝိတက္ကဒုတိယဈာန်သည်`（这无寻的第二禅）。译文补出的“境界”能读通，但没有点明所指的是第二禅。另外，na vimuccati 在 nissaya 中释为 `ဆန့်ကျင်ဘက်တရားတို့မှ မလွတ်မြောက်`（不从对立的法中解脱），补出了“从对立法”这个成分。
- **建议**：“无寻的境界”可以改为“无寻伺的禅定”。vimuccati 的补足成分不必进正文，但修订时要知道这里的“解脱”指心脱离对立法（寻伺），不是最终解脱，措辞上不要让读者误读成证果。§341、§342 对应句（nippītike = `ပီတိမရှိသော တတိယဈာန်`，adukkhamasukhe = `စတုတ္ထဈာန်`）同样处理。

## §342 句 92-342-87-108

- **问题**：复合词结构误读（必改） — nissaya 释 upekkhāsukhe 为 `တတြမဇ္ဈတ္တုပေက္ခာနှင့် သုခဝေဒနာ၌` = 在中舍性的舍**与**乐受之中。`နှင့်`（与）表明这是相违释（并列），两项是第三禅中并存的舍和乐。译文“舍俱的乐”按依主释读成“伴随舍的乐”，把两项读成了一项，与 nissaya 不符。
- **建议**：改为“舍与乐的过患”。

## §342 句 92-342-133-167

- **问题**：同上（必改） — nissaya `တံ= ထိုဥပေက္ခာသုခ အပြစ်ကို ရှုမြင်ခြင်းကို`，upekkhāsukha 仍是并列复合词。译文“舍俱的乐的过患”需要修改。
- **建议**：改为“如果我看见了舍与乐的过患……”。

## §342 句 92-342-168-185

- **问题**：同上（必改） — upekkhāsukhe 译作“舍俱的乐”。
- **建议**：改为“阿难，后来我看见了舍与乐的过患……”。

## §340 句 92-340-224-228

- **问题**：主语 — nissaya `သော= ထိုဝိတက္ကသဟဂတသညာမနသိကာရတို့ ဖြစ်ပေါ်လာခြင်းသည်`，主语 so 指“与寻俱行的想和作意的现起”这件事；`အဿ မေ= ထိုငါ၏` 是属格“我的”。译文“这对我来说就是一种病患”中的“这”可以承指上句，词法上没有错误。若 vitakka 按上文改为“寻伺”，上句 92-340-212-223 的 vitakkasahagatā 要同步斟酌：nissaya 在此处未注明包括伺，可以保留“与寻俱行”。本句无需修改，仅提示改动时保持连贯。
