# Review — 92:291-295（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句子没有 nissaya，已略过）

## 跨段一致性

- **tattha（指禅定）**：§291 句 47-71、§293 句 54-77、§294 句 50-73 译作“在那种状态里”，§291 句 103-109、§293 句 109-115、§294 句 106-112 译作“在那里”。nissaya 两处都明确指禅定：`တတ္ထ= ထိုအာကာသာနဉ္စာယတနဈာန်ခဏ၌`（在那空无边处禅定的刹那）、`တတ္ထ= ထိုအာကာသာနဉ္စာယတနဈာန်၌`（在那空无边处禅定中）。另外，同一 chunk 里 `tattha parinibbāyī` 的“在那里”指的是投生的世界，是另一个所指。现在三处都用“那里/那种状态”，读者分不清。
  → 建议：指禅定的两类句子统一译为“在那（空无边处／无所有处）禅定中”；`tattha parinibbāyī` 保留“在那里”。
- **ṭhito 与 viharati 撞词**：`upasampajja viharati` 译“进入并安住于”，`tattha ṭhito` 也译“安住在那里”（§291 / §293 / §294 共三处）。nissaya 给 ṭhito 的释义是 `ဌိတော= ရပ်တည်လျက်`（立足、站定），和 viharati 不是同一个动作。
  → 建议：ṭhito 统一改为“立足于”，把“安住”留给 viharati。
- **aniccato … anattato 列举词性不齐**：§291 / §293 / §294 三处都译作“无常的、苦的、疾病、脓疮、毒箭、祸患、病痛、异己的、会毁坏的、空的、无我的”，形容词和名词混在一起。nissaya 对整串用同一个并列格式（`အနိစ္စတော= လည်းကောင်း။ … အနတ္တတော= ကောင်း။`），十一项是同等地位的“作为……”。
  → 建议：统一成同一词性，例如“看作无常、苦、病、痈、箭、祸、疾、他者、坏灭、空、无我”。三处要同步修改。
- **引号层级**：§291 句 2-21、§293 句 2-30 的内层引语用“‘…’”嵌套，§292 句 67-87、§294 句 135-153 的同类引语（处在佛陀讲话之内）却用了外层“…”。§291 句 26-46、句 88-102 等处的内嵌引语也用了“…”。
  → 建议：整个 chunk 统一层级。佛陀讲话用“ ”，讲话里的引语一律用‘ ’。

## §291 句 92-291-2-21

- **问题**：隐含成分 — nissaya 补出了施事者：`(မယာ= ငါသည်။) ဝုတ္တံ= ပြီ။`（“已由我说过”）。译文“这是前面说过的话”丢掉了说话人。
- **建议**：改为“这是我说过的话”，或“我曾这样说过”。§293 句 2-30 同此。

## §291 句 92-291-47-71

- **问题**：处格所指不清 — `တတ္ထ= ထိုအာကာသာနဉ္စာယတနဈာန်ခဏ၌`，“在那种状态里”没有点出是空无边处禅定。nissaya 还注明 `vedanāgataṃ` 等是“与该禅定相应的受……”，`te dhamme= ထိုဝေဒနာစသော နာမ်ခန္ဓာ တရားလေးပါးတို့ကို`（受等四名蕴）。
- **建议**：改为“在那空无边处禅定中”。列举词性的问题见“跨段一致性”。

## §291 句 92-291-103-109

- **问题**：处格所指 + 用词撞车 — `ထတ္ထ= ထိုအာကာသာနဉ္စာယတနဈာန်၌`、`ဌိတော= ရပ်တည်လျက်`。nissaya 还补出了 `(တံ ဗလဝဝိပဿနံ ဝဍ္ဎေတွာ)`（增长那强力观智之后）。
- **建议**：改为“他立足于那禅定中，就达到了诸漏的灭尽”。补出成分按 style.md 的规定不进正文。

## §292 句 92-292-67-87

- **问题**：隐含成分 — nissaya `(မယာ) ဝုတ္တံ`，施事者是“我”。译文“前面说的这句话”可以接受，但和 §291 的处理一样缺了说话人。
- **建议**：可以改为“我说过的这句话，就是针对这个说的”，与 §291 / §293 的修改保持一致。

## §294 句 92-294-135-153

- **问题**：原文疑问（记录，不改） — pali 作 `Ākiñcaññāyatanampāhaṃ , nissāya`，缺 `bhikkhave`。nissaya 的引语作 `အာကိဉ္စညာယတနမ္ပါဟံ ဘိက္ခဝေ။ပ။`，平行句 §292 句 67-87 也有 `bhikkhave`，疑为原文脱字。译文按 pali 不译“比丘们”，这样处理没有问题。
- **建议**：译文暂不改，在 known-issues 里登记一笔。

## §295 句 92-295-2-13

- **问题**：术语译窄或含糊 — nissaya `အညာပဋိဝေဓော= အရဟတ္တဖိုလ်ကို ထိုးထွင်းမြင်သိ ရရှိခြင်း`，aññā 指阿罗汉果（究竟智），不是泛指的“智”。译文“智的洞察”容易被读成一般的 ñāṇa。
- **建议**：改为“对究竟智的通达”，或“对阿罗汉果的通达”。
- **问题**：yāvatā / tāvatā 的范围义 — nissaya 把 yāvatā 解为“明显到观智能够观照的程度”，把 tāvatā 解为“只要（这样的有想等至）存在”（`ဝါ= ရှိနေသရွေ့`）。“达到哪里……就达到哪里”大体可以接受，但容易读成空间意义。
- **建议**：可以改为“只要还有有想的等至，就能通达究竟智”，或者“有想的等至到什么程度，对究竟智的通达也就到什么程度”。

## §295 句 92-295-14-46

- **问题**：句法误读 — nissaya 把 `yāni imāni dve āyatanāni`（宾格）`nissāya` 解为连续体“依靠……”，并补出省略的谓语 `(āsavānaṃ khayaṃ ahaṃ vadāmi)`，即“依靠这两种处（我说能达到诸漏的灭尽）”。nissaya 的方括号注明，这是沿用经首那句“āsavānaṃ khayaṃ vadāmi”来补的。译文“这两个可以依靠的处”把 nissāya 处理成了定语“可依靠的”，和前文“依靠××处……达到诸漏的灭尽”的呼应就断了。
- **建议**：改为“比丘们，至于依靠这两种处——非想非非想处等至和想受灭——（能否达到诸漏的灭尽），……”，让“依靠”承接前文的句式。补出部分是否放进正文，由 revise 决定。
- **问题**：akkhātabbāni 的释义 — nissaya `အက္ခာတဗ္ဗာနိ= သန္တပဏီတဟု ချီးမွမ်းစကားပြောကြားနိုင်ကုန်၏`（能够称说它们是寂静、殊胜的）。“讲解”偏向“解释内容”，没有体现“称说、称述”。
- **建议**：“正确地讲解”改为“正确地称说”。
- **问题**：施事者格 — nissaya `ဈာယီတိ= …ပုဂ္ဂိုလ်တို့သည်`，`samāpattikusalehi samāpattivuṭṭhānakusalehi` 是修饰 jhāyī 的定语。译文“由那些善于入定、善于出定的修禅者”在结构上是对的，不需要改。
