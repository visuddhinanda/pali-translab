# Review — 92:75-91（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **Ekamidāhaṃ … bhagavā … viharāmi**：§77 句 92-77-2-14 与 §81 句 92-81-2-14 是同一句，两处都把「我」当成主语、把「世尊」当成呼格。按 nissaya 应以世尊为主语（见下 §77 意见）。→ **两处须同步改**。§81 无 nissaya，但必须与 §77 逐字一致。
- **tatra**：§77 句 92-77-15-25 与 §81 句 92-81-15-25 都译为「在那里」。nissaya 释为时间（ထိုအခါ၌ = 那时）。→ 两处同步改为「那时」。
- **Kacci metaṃ … bhagavato sussutaṃ …**：§77 句 92-77-107-120 与 §81 句 92-81-89-102 都译为「我这些话」，把话的归属弄错了（见下 §77 意见）。→ 两处同步改。
- **etaṃ（单数）**：§77 译「这些话」，§78 / §82 译「这些」。nissaya 作单数「这番话」（ဤ စကားတော်ကို）。→ 建议四处统一为「这番话」或「这话」。
- **rājagahe**：§76 句 92-76-2-13 与 §80 句 92-80-2-13 同句。若按 nissaya 改为「王舍城附近」，两处须同步。
- **佛 / 法 / 僧团**：§82 句 92-82-27-90 中「否弃佛」「否弃法」「否弃僧团」，三宝并列而单双音节不齐。→ 建议「僧团」改「僧」，与「佛」「法」对齐（非必改）。

## §76 句 92-76-2-13

- **问题**：词法 — 处格取义。nissaya：`ရာဇဂဟေ= ရာဇဂြိုလ်မြို့အနီး၌`（在王舍城**附近**），`ပဗ္ဗတေ= တောင်ပေါ်၌`（在山**上**）。译文「住在王舍城的鹫峰山」把鹫峰山说成在城里，与 nissaya 的邻近处格不符。
- **建议**：「有一次，世尊住在王舍城附近的鹫峰山上。」§80 同步。

## §76 句 92-76-27-33

- **问题**：词义偏移（轻微）。nissaya：`သမ္ဗောဒနီယံ`= 令人欢喜的，`သာရဏီယံ`= 值得一再忆念的。译文「友好亲切」漏掉了「值得忆念」一义。
- **建议**：「说完令人欢喜、值得记住的话之后，他坐在一旁。」（非必改；若改，§80 同步）

## §77 句 92-77-2-14

- **问题**：**主语误读（必改）**。nissaya：`ဘာဂဝါ= မြတ်စွာဘုရားသည်`（世尊，主格），谓语 `ဝိဟရတိ= သီတင်းသုံးနေတော်မူပါ၏`（世尊住）。nissaya 附注逐条分析了「我为主语、世尊为呼格」的读法，结论是否定它：`idāhaṃ` 应作无义的小品词组（နိပါတ်အစုအဝေး），并引 Gopakamoggallāna 经、Cūḷasuññata 经的同类句为证。译文「大德，世尊，有一次我就住在这里」正是被否定的那种读法。另外 `ဂိရိဗ္ဗဇေ= ဂိရိဗ္ဗဇမည်သော`（名为 Giribbaja 的）是修饰王舍城的定语。译文「住在这里，住在王舍城，也就是山围」重复了一次「住在」，略显冗赘。
- **建议**：「大德，有一次，世尊就住在这王舍城，也就是山围城（giribbaja）。」§81 同步。

## §77 句 92-77-15-25

- **问题**：词法 — tatra 取义。nissaya：`တတြ= ထိုအခါ၌`，并补出「世尊住在王舍城的那个时候」，是时间义，不是处所义。另外 `သမ္မုခါ= အထံတော်မှောက်၌` 是「在…面前」（处格），译文「从世尊面前」把处格译成了来源格。
- **建议**：「大德，那时，我在世尊面前亲耳听到、亲自领受了这样的话——」§81 同步。

## §77 句 92-77-26-106

- **问题**：词义（轻微）。
  - `parikkhīṇabhavasaṃyojano`：nissaya 作 `ဘဝအနှောင်အဖွဲ့`（生存〔有〕的束缚）。译文「轮回的束缚」换了概念。
  - `sammadaññāvimutto`：nissaya 拆为 `သမ္မာ`（正确地）+ `အညာယ`（了知）+ `ဝိမုတ္တော`（解脱）。「正智」已经涵盖了 sammā，译文另加的「完全」没有对应的词。
- **建议**：「生存的束缚已经彻底断尽，以正智而解脱」。§78 / §81 / §82 中同一套语共五处，须同步。（非必改，但若改须全改）

## §77 句 92-77-107-120

- **问题**：**属格归属误读（必改）**。nissaya：`မေ= တပည့်တော်သည်`（我，施事），`ဘဂဝတော= မြတ်စွာဘုရား၏`（世尊的），`ဧတံ= ဤ စကားတော်ကို`（这番〔世尊的〕话，宾格）。也就是说，话是世尊的，「我」是听受的人。译文「我这些话」把话归给了苏多瓦。
- **建议**：「大德，世尊的这番话，我是不是听得准确、领会得准确、思维得准确、记持得准确呢？」§81 同步。

## §82 句 92-82-27-90

- **问题**：词义。nissaya：`သိက္ခံ= အကျင့်သိက္ခာကို`，指学（sikkhā，修学 / 戒学），不是学处（sikkhāpada）。「学处」把范围译窄了。
- **建议**：「漏尽的比丘不可能否弃所学」，或「否弃戒学」。

## §82 句 92-82-125-126

- **问题**：nissaya 疑问。nissaya 作 `ပဌမံ`（第一），与原文 `Aṭṭhamaṃ`（第八）不符，应是 nissaya 的抄误。译文「第八经」正确，不用改。

## §84 句 92-84-2-16

- **问题**：漏译（轻微）。nissaya 把 `သန္တော= ထင်ရှားရှိကုန်၏`（存在）和 `သံဝိဇ္ဇမာနာ= ရအပ်ကုန်၏ / သိမြင်အပ်ကုန်၏`（可以找到、可以见到）分开释义，译文只译了「存在」。
- **建议**：「比丘们，世间确实有这九种人，可以见到。」句 92-84-21-57 句末同步。（非必改）
