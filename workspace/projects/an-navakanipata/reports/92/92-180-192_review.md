# Review — 92:180-192（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **khaḷuṅka**（assakhaḷuṅka / purisakhaḷuṅka）：全 chunk 一律译「劣马」「劣人」，与 nissaya 不合。nissaya 作 `အဿခဠုင်္ကေ= မြင်းပျို မြင်းငယ်တို့ကို`（幼马、小马），并附注 `အဿခဠုင်္ကောတိ အဿပေါတော`（assakhaḷuṅka 即 assapotaka，马驹）；`ပုရိသခဠုင်္ကေ= ယောင်္ကျားပျိုး ယောင်္ကျားငယ်တို့ကို`（年轻男子）。「劣」是负面评价，原词只表示年幼、未成熟。→ 建议统一改为「马驹」「年轻人」（或「幼马」「少年」），经题「劣马经」随之改为「马驹经」。涉及 §180、§181、§182、§183、§184、§185、§186 全部 khaḷuṅka 句。
- **java / vaṇṇa / ārohapariṇāha 的马、人对译断裂**（必改）：这三个词在马的段落译为「速度／毛色／身材高大匀称」，在人的段落却译为「速度／外表／丰足的供养」。本经的结构是先用马的三项特征类比人，再由「idamassa … vadāmi」逐项点明「我把这个称为他的 java / vaṇṇa / ārohapariṇāha」。nissaya 在人的段落仍保留比喻字面：`န အာရောဟ ပရိဏာဟသ္မိံ= မြင့်မတ်သည်အဖြစ်, လုံးဝိုင်းသည်၏ အဖြစ်မဟုတ်။ ဝါ= အရပ်အလုံးမဟုတ်`（不是高度与圆满体围），`ဝဏ္ဏသ္မိံ= အဆင်းရောင်`（容色），`ဇဝသမ္ပန္နော= လျင်မြန်သော ဉာဏ်အရှိန်အဟုန်နှင့် ပြည့်စုံသည်`（具足智慧的迅疾势头）。现译把比喻提前解成谜底，造成两个问题：
  1. §183 的「没有丰足的供养」在佛陀尚未解释时就出现了；
  2. §184–§192 的「我说这就是他没有丰足的供养」紧接在「他得不到衣服、饮食……」之后，成了同义反复，「我说这是他的……」这一判定也就落了空。
  
  → 建议马、人两边统一用同一组带比喻的词，例如 java「迅捷」、vaṇṇa「容色」、ārohapariṇāha「身量（高度与体围）」。人的段落随之译为「他具足迅捷，却不具足容色、身量」「我说这是他的迅捷／容色／身量」「我说这不是他的容色」。
- **saṃsādeti**：各段一律译「含混应付」，不合 nissaya，见 §184 句 92-184-60-86。§185、§186、§189、§192 的「不会含混应付」需同步改。
- **purisaparassa「良人」**：现代汉语里「良人」多指丈夫，容易误读。nissaya 作 `ယောင်္ကျားအပေါင်း၌ သာလွန်ထူးချွန်သော ယောင်္ကျား`（在众人中出众的男子），相应地 assaparassa 是在马群中出众的马。→ 建议改为「出众的人」，马的一侧改为「出众的马」，这样两边对称。涉及 §181、§188、§189。
- **purisājānīya「骏人」**：「骏人」不是现代汉语词。nissaya 作 `ယောင်္ကျားအာဇာနည်`，异释 `ဝါ= အကြောင်းဟုတ်သည်, အကြောင်းမဟုတ်သည်ကို သိတတ်သော ယောင်္ကျား သူရဲကောင်း`（能分辨合理与不合理的人中英杰）。→ 建议改为「良种之人」或「人中良驹」，马的一侧作「良种骏马」。涉及 §181、§191、§192。「贤良的」用来修饰马也不自然，bhadda 在 nissaya 作 `ကောင်း`（好、优良），建议改为「优良的」。

## §181 句 92-181-2-71
- **问题**：词义 — 「劣马、劣人、良人、骏人」四处均有误，具体见上文跨段一致性一节。
- **建议**：改为「我要为你们讲说三种马驹和三种年轻人，三种出众的马和三种出众的人，三种优良的良种骏马和三种优良的良种之人」。

## §181 句 92-181-72-74
- **问题**：漏译成分 — nissaya 作 `တံ= ထိုသုံးမျိုးစီ … ကို`，宾格 taṃ 指上面列出的各三种，译文没有译出；nissaya 还补出了隐含的 `သာဓုကံ= ကောင်းစွာ`（好好地），并注明后面还省略了「sādhukaṃ manasi karotha, bhāsissāmī」这一套惯用语。
- **建议**：改为「你们好好听这些。」

## §182 句 92-182-12-27
- **问题**：词义偏窄 — ārohapariṇāha，nissaya 作 `မြင့်မတ်သည်၏ အဖြစ်, လုံးဝိုင်းသည်အဖြစ်`（高度与圆满体围），异释 `အရပ်, အလုံး`（身高、体围）。「匀称」表示比例协调，与 pariṇāha（围度、粗壮）的意思不同。
- **建议**：改为「身量高大浑圆」或「身量」，并在 §182、§187、§190 统一。

## §183 句 92-183-14-28
- **问题**：词义 — javasampanno 的 nissaya 是 `လျင်မြန်သော ဉာဏ်အရှိန်အဟုန်နှင့် ပြည့်စုံသည်`（具足智慧的迅疾势头）；vaṇṇasampanno 的 nissaya 是 `ဂုဏ်အရောင်အဆင်း`（德行的光彩）。「外表」把意思引向了相貌，「丰足的供养」则是提前解谜，理由见上文跨段一致性一节。
- **建议**：改为「他具足迅捷，却不具足容色，也不具足身量」。

## §184 句 92-184-17-54
- **问题**：词义偏差 — dukkhasamudaya 的 nissaya 是 `ဒုက္ခဖြစ်ကြောင်း သမုဒယသစ္စာ`（苦生起的原因，即集谛），并点明 `ဤတဏှာသည်သာ`（就是贪爱）。「苦的生起」容易被读成「苦正在生起」这件事本身，而 nissaya 说的是苦的起因。
- **建议**：改为「这是苦的起因」或「这是苦集」，§185、§186 的省略句随之统一。

## §184 句 92-184-60-86
- **问题**：误译 — saṃsādeti 的 nissaya 是 `ပြဿနာကို ရပ်တန့်သွားစေ၏`（使问题卡住、停顿下来），no vissajjeti 的 nissaya 是 `မဖြေဆိုနိုင်`（答不上来）。「含混应付」带有敷衍、搪塞的意味，nissaya 没有这层意思。另外 `ပန= ထိုမှတပါး`（此外）只是递进，不是转折，现译「可是」与 nissaya 不合，不过这一点可以从宽。
- **建议**：改为「此外，被问到阿毗达摩（abhidhamma）、阿毗毗奈耶（abhivinaya）方面的问题时，他会卡住，答不上来」。

## §184 句 92-184-87-91
- **问题**：比喻断裂 — nissaya 作 `ဤမဖြေဆိုနိုင်ခြင်းသည် … ဂုဏ်အဆင်းရောင်မဟုတ်`（这种答不上来，不是他的容色），「好的外表」不合。
- **建议**：改为「我说这不是他的容色」。

## §184 句 92-184-92-98
- **问题**：用词 — cīvara 的 nissaya 是 `သင်္ကန်း`（僧衣），piṇḍapāta 的 nissaya 是 `ဆွမ်း`（托钵所得的饭食），「衣服」「饮食」偏泛。
- **建议**：改为「衣、钵食、住处和病人所需的医药用品」，§185、§186、§189、§192 的同句一并统一。

## §184 句 92-184-99-103
- **问题**：比喻断裂、同义反复 — nissaya 作 `ဤ … ပစ္စည်းလေးပါး မရခြင်းသည် … မြင့်မတ်သည်အဖြစ်, လုံးဝိုင်းသည်၏ အဖြစ်မဟုတ်`（这种得不到四资具，不是他的身量）。现译「我说这就是他没有丰足的供养」只是重复了上一句。
- **建议**：改为「我说这不是他的身量」，§185 句 92-185-69-73 同步改。

## §185 句 92-185-46-57
- **问题**：误译 — 理由同 92-184-60-86，nissaya 为 `နော သံသာဒေတိ= ပြဿနာကို ရပ်တန့်မသွားစေ`（不会让问题卡住）。
- **建议**：改为「他能解答，不会卡住」，§186、§189、§192 同句一并改。

## §185 句 92-185-58-61
- **问题**：比喻断裂 — nissaya 作 `ဤ ပြဿနာကို မရပ်တန့်စေဘဲ ဖြေဆိုနိုင်ခြင်းဂုဏ်သည် … အဆင်းရောင်တည်း`（这种不卡住、能解答的德行，就是他的容色）。
- **建议**：改为「我说这是他的容色」，§186、§189、§192 同句一并改。

## §186 句 92-186-69-72
- **问题**：比喻断裂 — nissaya 作 `ဤသို့ ပစ္စည်းလေးပါးရရှိခြင်းသည် … အရပ်အလုံးတည်း`（这种得到四资具，就是他的身量）。
- **建议**：改为「我说这是他的身量」，§189、§192 同句一并改。

## §189 句 92-189-21-38
- **问题**：词义 — parinibbāyī 的 nissaya 是 `ပရိနိဗ္ဗာန်ဝင်စံသည်`，异释 `ခန္ဓာခပ်သိမ်း ချုပ်ငြိမ်းသည်`（诸蕴全部寂灭），这是般涅槃，「证得涅槃」不够准确。opapātiko 的 nissaya 补出了处所 `(သုဒ္ဓါဝါသဗြဟ္မာ့ဘုံ၌)`（在净居天），译文不加也可以。
- **建议**：改为「在那里般涅槃，具有不再从那个世界回来的性质」。

## §190 句 92-190-13-30
- **问题**：数据对齐（不改译文，记录在案）— 挂在这一行（良种骏马）下的 nissaya，内容实际是 §192 贤良之人的「āsavānaṃ khayā anāsavaṃ cetovimuttiṃ…」一句和「Idamassa javasmiṃ」，坐标错挂了，不能拿它当本句的依据。按这条 nissaya 核对 §192 句 92-192-21-40：abhiññā 的主释是 `သိ၍`（了知之后），异释是 `ထူးသော ပစ္စဝေက္ခဏာဉာဏ်ဖြင့်`（以殊胜的省察智），现译「以证智」大致可以接受；upasampajja 是 `ရောက်၍`（到达之后），viharati 是 `နေ၏`（安住），现译相符。
- **建议**：本句译文不用改。坐标错挂的问题请反馈到 nissaya 数据源。
