## 跨段一致性
- **段号后标点**：§355 / §356 / §358 / §365 / §366 / §367 / §368 用「、」（七—八、／二七—二八、），§359 / §360 / §363 / §364 用「。」（十—十一。／三〇—三一。） → 建议统一为「、」，依据：本 chunk 多数用法。
- **kāraṇa**：§358「原因」，§360-6「缘由」，§360-12 与 §366-32「理由」 → 建议名词「…的原因」统一为「原因」（§358、§360-6）。§366 的 kāraṇena 是工具格，可以保留「理由」（见下）。
- **yathā … evaṃ na + 动词 句式**：§368-11 译成「没有让前脚稳稳地站好」，把 yathā…evaṃ 的方式结构丢掉了；§368-30 同一句式译成「不按照使它……的方式去……」 → 两处统一按「不按能……的方式去……」译。
- **su-adhiṭṭhita**：被解释词用「稳固地」（父层），§368-30 释义里用「牢牢」 → 释义也用「稳固地」，和被解释词呼应。

## §356 句 102-356-6-14
- **问题**：词法 — puggalaveraṃ 的 nissaya 是 `ပုဂ္ဂိုလ်တည်းဟူသောရန်သူ`，意思是「作为人的仇敌」，属于同位关系，即「来自人的怨敌」。译文「针对个人的怨恨」把关系译反成了指向对象。被解释词「招来怖畏和怨恨」在父层是「招来现世的怖畏和怨恨」中省去 diṭṭhadhammikampi 后的部分，可以接受。
- **建议**：「……意思是得到内心惊怖的怖畏，以及来自他人的怨仇。」

## §360 句 102-360-53-70
- **问题**：原文疑问／词法 — nissaya 所据底本这里读作 paṭikopaṃ（`အမျက်တုံ့`，意为反过来发怒），pali 是 kopaṃ，记下备查。laddhabbaṃ 的 nissaya 是 `ရအပ်၏`（应当得到），译文「凭什么理由就该是这样」把宾语虚化了。
- **建议**：「凭什么理由应当这样做呢？」

## §360 句 102-360-75-91
- **问题**：补出成分 — ettha 的 nissaya 是 `ဤပုဂ္ဂိုလ်၌`（对这个人），译文「在这里发怒」意思不清。这一行 nissaya 的 tasmiṃ / ke 释读与 pali 的格不合（把 kuto lābhā 误抄成 labbhā），所以句末结构仍按 pali 理解，译文现有的「能有什么好处……所谓好处又会是些什么」不必改。
- **建议**：「如果我对这个人发怒，那么我这样发怒能有什么好处呢？……」

## §360 句 102-360-92-98
- **问题**：被解释词（必改） — nissaya `တံဟူသောပုဒ်` 指的是 taṃ 这个词。父层「可是对此又能怎么办呢」里的「此」对应的是 ettha，不是 taṃ。黑体用「此」，对应关系就错了。另外，括注「（本文“可是对此又能怎么办呢”中的“此”）」形同工作说明，不应留在译文里。
- **建议**：父层把 taṃ 处理成转折语气词「可是」，被解释词改为「**可是**」，删去括注：「按照这种解释，**可是**（taṃ）只是一个语助词而已。」

## §364 句 102-364-82-86
- **问题**：词法 — nissaya `ချီးမြှောက်အပ်သောလက်အုပ်ကို ကတွာ` 的意思是「作出举起的合掌」。译文「……的样子」偏描写，没有译出 hutvā 的动作。
- **建议**：「意思是举起合掌。」

## §366 句 102-366-2-10
- **问题**：原文疑问 — nissaya 写作 `ကာလုဒါယီ`（Kāḷudāyī），pali 是 lāḷudāyi，二者人物不同。译文按 pali 译不错，记下备查。

## §366 句 102-366-11-17
- **问题**：被解释词（必改） — 父层是「这里的快乐就在于这一点」。黑体「就在于这一点，就在这里」多出「就在这里」，和父层不是逐字相同。另外 nissaya 说明这条是拆词（padaccheda：khvettha = kho ettha），ettha 指 `ဤနိဗ္ဗာန်၌`（在涅槃中），译文没有交代拆词，也没有补出所指。
- **建议**：「**就在于这一点**，这里应拆读为 etadeva kho ettha，意思是：正是这一点，就在这里（涅槃之中）。」

## §366 句 102-366-27-31
- **问题**：数据对齐 — 本行的 nissaya 混入了 samudācaranti 的释义（`မနောဒွါရေ…သံစရန္တိ`），属于上一行。另外 ābādhāya 的缅文 `ကြင်နာခြင်း` 疑为讹字。译文按 pali 译「造成损害、造成压迫」，与 `ပီဠနာယ`（为了压迫）相合，不必改。

## §366 句 102-366-32-35
- **问题**：词法 — kāraṇena 的 nissaya 是 `အကြောင်းအားဖြင့်`（凭理由）。译文「按着某个理由」里的「某个」是多加的，而且和被解释词「这个角度」相抵。
- **建议**：「意思是凭理由。」或「意思是从理由上说。」

## §368 句 102-368-2-10
- **问题**：词法 — pabbatacārinī 的 nissaya 是 `တောင်တက်လေ့ရှိသော`，有「惯于」的意思（-cārin 表习性），译文没有译出。
- **建议**：「意思是惯于在山上行走的。」

## §368 句 102-368-11-22
- **问题**：句法 — nissaya 是「以什么方式能立稳，就没有按那种方式去立」（`ယထာ…ဧဝံ…န ပတိဋ္ဌာပေတွာ`），译文漏掉了方式结构，见跨段一致性。
- **建议**：「意思是没有按照能稳稳站住的方式把前脚放好。」

## §368 句 102-368-30-42
- **建议**：「牢牢确立」改为「稳固地确立」，与被解释词统一。

## §368 句 102-368-48-69
- **问题**：属格归属 — assa 的 nissaya 是 `ထိုယောဂီပုဂ္ဂိုလ်၏`，修饰的是「第四禅心」（他的心），不是「神通」。译文「作为他神通基础的第四禅心」把「他」挂到了「神通」上。
- **建议**：「同样地，他那作为神通基础的第四禅心也变得柔软、能够运用自如。」

## §368 句 102-368-70-93
- **问题**：原文疑问 — nissaya 读作 `အပ္ပဂုဏသမာဓိ`（appaguṇa，未熟练的定），与 pali 的 suppaguṇa 意思相反，应是 nissaya 讹误，译文按 pali 译不错，记下备查。被解释词「无量的定」在父层被拆成「无量的、修习得很好的定」，没有逐字连续的出处，可以接受。

## §368 句 102-368-94-107
- **问题**：句法 — nissaya 在被解释词后补出 `ဣတိ ဝေဒိတဗ္ဗော`（应当这样理解），随后另起一句 `ဣမသ္မိံ ဌာနေ`（在这一处）。可见后半句不是释义，而是说明经文讲到这里时比丘已经证果。译文用「意思是」引起，误把它当成了词义解释；「在这个地方」也容易被读成空间上的地点。
- **建议**：「**他凭着这修习得很好的无量定**：讲到这里，这位比丘已经增长毗婆舍那，证得了阿罗汉果。」

## §368 句 102-368-108-116
- **问题**：补出成分 — āha 的 nissaya 是 `ဟောတော်မူ၏`，用的是尊敬语，说明主语是世尊。译文「就说了」没有主语。另外，khīṇāsava 的 nissaya 是 `ရဟန္တာ`，「漏（āsava）已灭尽者」的译法偏长。
- **建议**：「现在世尊为了显示漏尽者的神通次第，就说了**无论……哪一种**等等的话。」
