## 理由

**资源缺失（降级评估）**：本次注入的资源只有巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此释义标准与词级基准都无法逐句核对，准确性一项只能凭原文形态、格位与传统注释义读判断。信心指数据此显著下调；若要作为验收结论，建议补齐义注与 nissaya 后重评。

**准确性**：定型句（satipaṭṭhāna 四支、阿罗汉九德语、`Kevalo hāyaṃ … yadidaṃ –` 句型）的词覆盖完整，格位处理基本无误：`kāyassa yathābhūtaṃ ñāṇāya` / `kāyassa pariññāya` / `kāyena visaṃyuttā` 三组与位格、属格、具格的对应都译对了，学人段与阿罗汉段的目的语差别（如实了知 → 遍知 → 离系）分得清楚，这是本段最容易塌的地方。`appattamānasā` 译「尚未证得阿罗汉果」取的是注释书传统义读（mānasa = arahatta），无义注在手，但此取义有据，不扣分，在此注明。`vineyya loke abhijjhādomanassaṃ` 取「除去」而非「已除去」，与通行读法一致。扣分主要来自 `navā` 的漏译（见问题清单）。

**风格**：现代书面汉语，无文言虚词与文言句式，无「此中／故为／彼等／即／遂」一类禁例；标点全角，引号统一为全角 “” ‘’，`zh` 字段内无 ASCII 引号，符合 JSON 安全约束；无残留工作标记。「随观身而住」「心专注于一境」属既有汉译定式，不按文言处理。扣分来自个别冗赘与逻辑含混的句子：`Kevalo hāyaṃ …` 前的「正确地说，就是指……而说」四处同型表达都读不顺；「束缚于生存的结缚」同词重复。

**一致性**：四念住四支的并列结构、`ātāpino sampajānā …` 四支修饰语在 892/893 全部十二个并列句中用词完全一致，`Yepi … tepi` 的「那些……他们也」呼应贯通，892 无 `imesaṃ` / 894 有 `imesaṃ` 的「这」也如实区分。唯一的一致性瑕疵是术语夹注不成体系：`sekha`、`nīvaraṇa` 加了巴利夹注，同段的 khīṇāsava、pariññā、visaṃyutta 等法相术语没有，取舍标准看不出来。

## 问题清单

### 🟧 error
- `171-892-2-28`｜漏译｜片段「刚出家不久、新近来到这法与律中的比丘」
  - 问题：`navā acirapabbajitā adhunāgatā` 三个并列形容词只译出后两个，`navā`（新学、新来的）未落到字面上。定型句里三支并举，专业读者会察觉少了一支。
  - 建议：改为「那些新学、出家不久、新近来到这法与律中的比丘」。
- `171-894-2-33`｜漏译｜片段「刚出家不久、新近来到这法与律中的比丘」
  - 问题：同上，`navā` 未译；此句与 892 首句是首尾呼应的同一定型句，两处需同改，否则改一处反而破坏一致性。
  - 建议：与 `171-892-2-28` 采用同一改法。

### 🟨 warning
- `171-892-32-51`｜关键词语意不明确｜片段「心专一、心清净、内心安定、心专注于一境」
  - 问题：`ekodibhūta` 译「心专一」、`ekaggacitta` 译「心专注于一境」，两个不同术语的汉译几乎同义，读者无法区分，四支修饰语读起来像同一件事说了两遍。该串在 892（八句）、893（四句）的全部并列句中重复出现，属全段性问题。
  - 建议：拉开层次，如 `ekodibhūta`→「心归于一」／「一趣」，`ekaggacitta`→「心一境性」，并对其中一个首次出现处加巴利夹注；十二处统一替换。
- `171-893-2-34`｜不导致误解的汉语语病｜片段「束缚于生存的结缚已完全断尽」
  - 问题：「束缚」与「结缚」同义反复，一个短语里出现两次「缚」，冗赘拗口。
  - 建议：改为「对生存的结缚已完全断尽」或「生存的结缚已彻底断尽」。
- `171-896-14-29`｜整句逻辑表达不规范｜片段「正确地说，就是指五盖（nīvaraṇa）而说」
  - 问题：`vadamāno … sammā vadamāno vadeyya` 的条件式语义（若他说的是五盖，那他就说对了）被压成「正确地说……而说」，「说」字三现、主谓失落，整句逻辑读不出来。
  - 建议：改为「比丘们，说‘不善的积聚’的人，如果说的是五盖（nīvaraṇa），那就说对了。」
- `171-896-56-70`｜整句逻辑表达不规范｜片段「正确地说，就是指这五盖而说」
  - 问题：同 `171-896-14-29` 的同型句，须与之同改。
  - 建议：「……如果说的是这五盖，那就说对了。」
- `171-897-2-17`｜整句逻辑表达不规范｜片段「正确地说，就是指四念住而说」
  - 问题：同型句，善品一侧的对应表达。
  - 建议：「……如果说的是四念住，那就说对了。」
- `171-897-69-83`｜整句逻辑表达不规范｜片段「正确地说，就是指这四念住而说」
  - 问题：同型句，全经四处须一并统一。
  - 建议：「……如果说的是这四念住，那就说对了。」

### 🟦 suggestion
- `171-891-14-23`｜语言表达不够流畅｜片段「世尊唤比丘们」
  - 问题：`āmantesi` 译「唤」偏生硬，后接「……（中略）……说了这样的话」时语流断裂。
  - 建议：「世尊对比丘们说」或「世尊告诉比丘们」。
- `171-892-2-28`｜语言表达不够流畅｜片段「你们应当使他们受持、安住、确立于四念住的修习」
  - 问题：`samādapetabbā`（劝导令取）译「受持」偏弱，三个使动并列共用一个「于……的修习」，读起来挤。
  - 建议：「你们应当劝导他们修习四念住，使他们安住其中、确立其中」。894 对应句同步调整。
- `171-896-30-41`｜语言表达不够流畅｜片段「因为这纯粹就是不善的积聚」
  - 问题：`kevala` 传统释为「全部、整个」，「纯粹」偏向「纯净／单纯」，语感有偏移。同型句见 `171-896-71-82`、`171-897-18-29`、`171-897-84-98`。
  - 建议：「因为这整个就是不善的积聚」，四处统一。
- `171-896-45-55`｜语言风格不统一｜片段「掉举追悔盖」
  - 问题：同一列五盖中，其余四支用的都是传统定译（瞋恚、昏沉睡眠、疑惑），`kukkucca` 单独取「追悔」，与传统「恶作」不一致。
  - 建议：统一为「掉举恶作盖」，或首次出现处加巴利夹注说明取义。
- `171-897-33-48`｜语言风格不统一｜片段「贪欲和忧恼」
  - 问题：`domanassa` 译「忧恼」比传统「忧」多一层情绪色彩，与本段其他术语的克制取向不一致。
  - 建议：「贪欲和忧」；`171-897-49-68` 同步。
- `171-892-94-122`｜该使用而没有使用术语标记｜片段「学人（sekha）、尚未证得阿罗汉果的比丘」
  - 问题：本段夹注只给了 `sekha`，同段 `khīṇāsava`、`pariññā`、`visaṃyutta`、`yogakkhema` 等同级法相术语都没有，夹注取舍看不出标准。
  - 建议：按 `knowledge/style.md` 第二节明确一条线（如只给非通行汉译的术语加夹注），全章统一执行；`yogakkhema` 译「无上的安稳」尤其值得补注。
