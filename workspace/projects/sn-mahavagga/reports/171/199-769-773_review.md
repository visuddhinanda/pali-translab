## 二、跨段一致性

- **byañjana**：§770 句 17-20 与引文译「字」（承父层），句 21-45 同一词译「辅音」。两处都对，但汉语读者看不出是同一个词，导致该句论证断链 → 详见下文必改项，处理办法是加巴利夹注，**不要**把「辅音」改成「字」。
- **vaṇṇa / akkhara 都译「字母」**：承父层定稿，属硬约束，不改；但本层句 2-10 与 11-16 是在**区分**二者，纯汉字读者会以为同义反复。建议保留两处夹注（现已有），revise 时不要删。
- **sabhāva=自性 / bhāva=状态**：§770、§772 全篇一致 ✅（「集等的自性」vs 父层「集等的状态」对应 sabhāva/bhāva 之别，正确）。
- **vitatha=虚妄 / musā=虚假**（§772 句 32-36 vs 句 50-61）：原文确是两个词，分译可接受；但同段内「不虚妄」「不是虚假的」并列，建议 musā 处补夹注「虚假（musā）」以示非重复。
- **Netti=《导论》**：§770 句 46-50、92-101 一致 ✅。
- **「只要提到 X，Y 也就一并…」**句式：§770 句 51-57、72-77 统一 ✅。
- **Tenāha 译「因此（义注）说」**：§770、§772 三处统一 ✅。

## 三、必改项

### §772 句 199-772-24-27 —— 被解释词不符 + 汉语不成句
- **问题**：被解释词偏离父层。父层定稿作「由于**自性**不虚」，本层黑体译「**自性的**」，多一个「的」，已非逐字相同；且「是指苦的自性的」在现代汉语中不成句（悬空的属格）。
- **建议**：改为「**自性**，是指苦的自性。」属格关系由上下文承接，不必在译文里硬留「的」。

### §772 句 199-772-62-70 —— 截引不可读
- **问题**：「因此（义注）说了“**因为不**”等等。」「因为不」单独成引不可读，读者无法对应到父层任何一句。
- **建议**：按父层被引句起首取足，作「因此（义注）说了“**因为苦不会**……”等等。」（父层 137-893-28-33：「因为苦不会变成集等的状态。」）保持黑体覆盖「因为苦不会」即可。

### §770 句 199-770-51-57 —— 复合词拆分错误（三项误并为两项）
- **问题**：`ākāraniruttiniddesā` 译作「方式解说和语词解说」，把三个并列名目并成两个偏正词组。此处 gahitā 是复数主格，ākāra / nirutti / niddesa 是《导论》名目序列中的**三个独立项**（与前文 vaṇṇa、akkhara、byañjana 同属一列），不是「ākāra-niddesa」与「nirutti-niddesa」。
- **依据**：本层论证格式为「提到 A，则 B、C、D 也一并被摄」，只有三项并列才讲得通；无 nissaya 可核，请 revise 时以《导论》名目表复验。
- **建议**：「应当明白，这里只要提到字，方式（ākāra）、语词（nirutti）、解说（niddesa）也就一并包含在内了。」

### §770 句 199-770-78-91 —— 文言虚词「之」（style.md 禁例）
- **问题**：「意义之句也就一并被包含在内了」——「之」为文言虚词，`knowledge/style.md` 第一节明列为禁例。
- **建议**：改「义句（atthapada）」或「意义的句子」。同句「理由施设」建议补夹注作「理由施设（kāraṇapaññatti）」。
- **附带**：本句 `vivaranti` 译「来开显的」，但没点出「开显（vivaraṇā）这一项也因此被摄」，论证目的丢失。建议：「因为各种语尾变化正是以说明意义的方式开显（vivaraṇā）的，由它们，理由施设（kāraṇapaññatti）也就说到了；所以由它们，义句（atthapada）也就一并被包含在内了。」

### §770 句 199-770-21-45 —— 论证在汉语中断链
- **问题**：「因为 a 等叫做元音，ka 等叫做辅音，而两者都叫做字母，所以说“或者说，字母的一部分就是所谓的字”」。结论里的「字」与前提里的「辅音」在原文是同一个 byañjana，汉译分家后，「所以」二字失去支撑，读者读不出推论。
- **建议**：前提处补夹注——「ka 等叫做辅音（byañjana，即上文的“字”）」。引文本身是父层定稿，**不得改动**。

## 四、建议项（可读性 / 语体，非错译）

- **199-770-11-16**：「就是那些，按引申的说法，由于被发出声音，所以是**字母（akkhara）**。」三重插入，主干断裂。建议：「正是那些字母，换一种说法，由于会被发出，就叫做**字母（akkhara）**。」
- **199-770-58-63**：「分部分地使人了知意义」→「逐部分地使人了解意义」（bhāgaso 取「一部分一部分地」，且避开「了知」这类半文言）。
- **199-770-92-101**：「这里所说的是简略的部分」→「这里只是略说」。
- **199-770-102-105**：「以同分等的分别阐明的方式」连用两个「的」→「以同分（sabhāga）等分别阐明的方式」。
- **199-772-2-13**：「不舍弃自己的苦的自性」连用两个「的」→「不舍弃自身的苦自性」。
- **199-770-118-130**：「**才这样说**，是说（世尊）这样说了……」黑体「才这样说」是为逐字承父层而留，但脱离「所以」后单独成句略显突兀；若 revise 时判断可容，补作「（所以）**才这样说**」，括号内不加黑体。

## 五、存疑处（不改译文，记录待定）

1. **`akkharaṇato`（§770 句 11-16）**：译「由于被发出声音」是一种取义（读作 akkharati「被发出」）；传统另有「不消尽（na khīyati）」的词源解释。无 nissaya、无本层义注可定，建议保留现译并压低该句 confidence，待查《导论》义注后定案。
2. **`Nettiyaṃ pana vākye byañjanasamaññā`（§770 句 46-50）**：现译「把句子叫做字」。亦可读作「在《导论》里，byañjana 之名施于句（vākya）上」——意思相近，但若《导论》原文另有分类，措辞需调。
3. **`musā na hotīti`（§772 句 50-61）**：现译把「不是虚假的」挂在 `aññabhāvānupagamana` 之下。此句也可能是回指上文 avitatha 的补说。句法归属存疑，无 nissaya 可判。
4. **OCR / 原文格式**：§770 句 21-45、§772 句 14-23、37-49、62-70 的巴利原文中，引号被切成独立的 `‘‘` / `’’` 并各自带黑体标记（`**‘****‘**`）。属源数据标记噪声，译文已正确忽略，**不要**在 revise 时试图对译这些符号。
