## 理由

**基准缺失（影响信心）**：本次评的是义注层（book=137），但注入的资料只有巴利原文与译文——
没有 nissaya（词级基准），没有复注（对义注而言的上层释义标准），也**没有本文（mūla）译文**。
因此两条通常最硬的核对做不了：一是格与句法角色无法逐词验证（如 `137-655-18-35` 的
`upadduto` 究竟修饰谁，只能靠句法推断）；二是**「被解释词与父层逐字同译」这条硬约束无法核对**——
所有黑体词条（`viyattā`→通达、`appossukko`→你不必再为这件事费心了、`sambhava`→能招致后有的……）
是否与本文译文一致，报告里只能按义注内部自洽性判断，不能确认跨层对齐。下面凡涉及黑体词条的
条目都标注了「需与本文核对」，信心指数据此压到 68。

**准确性**：句义把握整体可靠，义注特有的「词条 + ti + 释义」结构处理稳定，长句拆解得当。
`137-654-17-36`（不是像扔土块那样舍寿行，而是只在三个月内入果定）、`137-655-36-39`
（`Tassokāso mā hotū`ti 补出「不给这种说法留下余地」）、`137-656-89-113` 的总结长句，
都译对了逻辑重心。扣分主要在三处增译：`jhānassāda` 多出「法」、`niyakajjhatta` 多出「所缘」、
`buddhamuni` 后多出「即佛陀」——原文均无对应成分。另有若干轻度增补（「成道后」「魔」「诸有」「株」）
属于必要或可接受的隐含成分补出，不扣分，但「诸有」「株」建议移入脚注。

**风格**：绝大部分是合格的现代书面汉语，口语化程度拿捏得当（「怎么说呢？」「据说那时候」
「从今天起」都很自然）。但有两处明确的文言残留：`137-651-41-47` 连用两个「之」且三层嵌套，
`137-654-17-36` 的「便」。按 `knowledge/style.md` 第一节禁例表，这两处直接构成扣分项。
此外术语夹注密度偏高（本 chunk 内 appossukko / vipassanā / mahaggata / punabbhava /
upacāra / appanā / buddhamuni 七处），且 `appossukko` 用的是主格形而非词干形，体例不统一。

**一致性**：主要问题是**同一巴利词在词条与释义里译法不同**，削弱了义注「以词释词」的功能：
`viyattā`/`byattā` → 通达/明达，`suṭṭhu`/`su-` → 很好地/清楚地，`abhindi` → 破开/破除/击破。
反向的毛病也有：`sāmīci`→「相称的道路」而 `anucchavika` 也译「相称的道路」，
`iddha`→「兴盛」而 `samiddha` 也译「兴盛」——词条与释义同词，等于没解释。
这类问题 harmonize 阶段本该统一，建议回一轮 harmonize 集中处理。

## 问题清单

### 🟧 error

- `137-652-8-12`｜错误多译｜片段「由于有禅那的法味而充实兴盛」
  - 问题：`jhānassāda` 是「禅那的乐味（禅悦）」，原文无「法」（dhamma）这一成分，加「法」会被读成「以法为味」，取义偏移。
  - 建议：改为「由于有禅那的乐味」。

- `137-656-68-71`｜错误多译｜片段「乐于自身之内的所缘」
  - 问题：`niyakajjhattarato` 只说「乐于自内（己身之内）」，「所缘」（ārammaṇa）是原文没有的成分，凭空缩小了范围。
  - 建议：改为「乐于自己身内」。

- `137-656-64-67`｜错误多译｜片段「即佛陀」
  - 问题：原文 `buddhamuni` 已由夹注给出巴利原词，再加「即佛陀」属译者增补，正文里没有对应。
  - 建议：删去，或移作脚注。

### 🟨 warning

- `137-651-41-47`｜文言语体｜片段「作为圣法之随顺法的观（vipassanā）之法」
  - 问题：连用两个文言虚词「之」，且「作为……的……之法」三层嵌套，普通读者读不下来。
  - 建议：改为「他们所行的是随顺圣法的观（vipassanā）」。

- `137-654-17-36`｜文言语体｜片段「此后便生起这样的心」
  - 问题：「便」是禁例表中的文言虚词。
  - 建议：改为「此后就生起了这样的心」。

- `137-655-18-35`｜不导致误解的汉语语病｜片段「这样地扰迫，出于恐惧才舍弃了寿行的」
  - 问题：`upadduto` 是被动，主语是世尊；上一句的「被」隔了一整段引语后已经不起作用，此处读起来像世尊在扰迫别人，被动关系断掉了。
  - 建议：改为「受到这样的逼迫，出于恐惧才舍弃了寿行」。

- `137-651-48-52`｜关键词语意不明确｜片段「**走上相称的道路**是说，他们所行的是相称的道路」
  - 问题：词条与释义用了同一个词，`anucchavika`（适宜、得当）对 `sāmīci` 的解释作用完全落空。
  - 建议：释义改为「他们所行的是适宜得当的道路」，与词条区分开（需与本文对 `sāmīcippaṭipannā` 的译法核对）。

- `137-652-8-12`｜关键词语意不明确｜片段「**兴盛**是说，……而充实兴盛」
  - 问题：同上，`iddha` 与 `samiddha` 都译「兴盛」，释义等于重复词条。
  - 建议：词条「兴盛」，释义用「充实丰足」。

- `137-654-50-54`｜关键词语意不明确｜片段「**大地震**是说，大地的巨大震动」
  - 问题：「大地震」在现代汉语里是地震灾害的固定名词，`mahābhūmicāla` 此处指大地剧烈震动这一事件；且词条与释义再次同义重复。
  - 建议：词条「大地的震动」或保留「大地震动」，与释义拉开距离（需与本文核对）。

### 🟦 suggestion

- `137-651-2-7`｜语言风格不统一｜片段「**通达**是说凭着圣道而明达」
  - 问题：`viyatta` 与 `byatta` 是同一个词的两种写法，译成「通达」「明达」两词。
  - 建议：统一为一词，或明确以词条译法为准。

- `137-651-63-68`｜语言表达不够流畅｜片段「**能够宣说**」
  - 问题：`ācikkhissanti` 是将来时（将会宣说），「能够」加进了原文没有的情态。
  - 建议：按本文黑体的译法回改；需与本文核对后统一。

- `137-653-2-6`｜语言风格不统一｜片段「**你不必再为这件事费心了**（appossukko）是说，没有挂念」
  - 问题：其余词条都是短语，此处词条被译成一个完整祈使句，「X 是说 Y」的体例被打破；且与 `137-653-7-40` 的「不要再为这件事用心了」用词不一（费心/用心）。另外夹注用的是主格形 `appossukko` 而非词干 `appossukka`。
  - 建议：词条取短语形（如「无所挂虑」），完整句意留给释义；夹注统一用词干形。

- `137-652-42-58`｜语言风格不统一｜片段「很好地宣说了」……「全都清楚地宣扬了它」
  - 问题：`suppakāsita` 与 `suṭṭhu pakāsita` 同词，译作「很好地宣说」「清楚地宣扬」两套。
  - 建议：统一为「很好地宣说」。

- `137-656-77-83`｜语言风格不统一｜片段「如同击破铠甲一般地击破」
  - 问题：同一个 `abhindi`，本 chunk 内出现「破开」「破除」「击破」三种译法（另见 `137-656-89-113`）。
  - 建议：统一为「破开」。

- `137-656-41-46`｜语言表达不够流畅｜片段「果报小的是可衡量的，果报大的是不可衡量的」
  - 问题：`appa`/`bahu` 是少/多，不是小/大。
  - 建议：改为「果报少的……果报多的……」。

- `137-656-47-54`｜语言表达不够流畅｜片段「使诸有成团、成堆地积聚起来」
  - 问题：`piṇḍakāraka rāsikāraka` 无宾语，「诸有」是译者补出的。
  - 建议：改为「使它们成团、成堆地积聚起来」，或把「有」的解释放脚注。

- `137-652-13-19`｜语言表达不够流畅｜片段「就像整株树的花全都开放那样」
  - 问题：`sabbapāliphulla` 直译是「整排（枝条）开满花」，「株树」为增补。
  - 建议：保留亦可，建议加脚注说明直译。
