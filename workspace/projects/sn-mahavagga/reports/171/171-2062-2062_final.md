## 理由

**基准缺失**：本次注入的数据只有巴利本文（mūla）与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此释义标准与词级基准都无法核对，准确性评分只能依据巴利原文自身的词形、句法与本经（SN 55.6 Thapatisutta，两位王家 thapati Isidatta 与 Purāṇa）上下文推定。`thapati` 的所指、`appaṭivibhatta` 的取义两处都需义注定案，本报告按"疑而不判"处理：只记录分歧与内部矛盾，不据此重扣准确性分。

**准确性**：无 fatal。主谓宾判断整体正确，六句无漏译、无明显多译。`buddhe aveccappasādena samannāgatā`（对佛具备不坏的净信）、`katividhā … samasamā`（有几类人……完全一样）、`Yesaṃ no bhagavā evaṃ pajānāti`（世尊这样了解我们）的格与句法角色都对。扣分主要来自两点：`appaṭivibhattaṃ sīlavantehi kalyāṇadhammehi` 的具格被处理成"施与……的人"，把"与持戒者**共享/不分彼此**"的语义压成了单向布施；以及 `bhagavāti` 的 `ti` 标示的内嵌引语在译文里没有任何标记，与外层引号混在一起。

**风格**：主体是现代书面汉语，无文言句式堆积，标点为全角、无 ASCII 引号，符合 JSON 安全约束。扣分在"得着了好处"这种旧白话/半文腔，以及 `pe` 一律译作"……乃至……"对普通读者语义不明。

**一致性**：最主要的失分项。同一段内 `thapatayo` 先译"工匠们"、后译"侍臣们"，同一批说话对象在同一次对话里换了称谓，普通读者会误认为是两拨人——这是本段唯一的 error 级问题，须回 harmonize 统一（定案前应先取义注确认 thapati 所指）。

## 问题清单

### 🟧 error

- `171-2062-2-23`｜导致误解的表达（术语/称谓前后不一）｜片段「工匠们」
  - 问题：同段 `171-2062-44-65` 把同一个 `thapatayo` 译作"侍臣们"，同一批受话人在一次对话内出现两个互不相容的称谓，读者会理解成两组不同的人。
  - 建议：取义注核定 `thapati` 所指后统一为一个译名（两处同改），并登记进 `knowledge/terms.md`。属 harmonize 职责，不在本步骤修改。

- `171-2062-24-43`｜错译（修饰关系 / 具格处理）｜片段「全都不加分别地施与持戒的、具有善法的人」
  - 问题：`appaṭivibhattaṃ` 的核心义是"不分割、不留私、与人共有"，`sīlavantehi kalyāṇadhammehi` 为具格（共同者），原句说的是家中可施之物**与**持戒具善法者**共享**；译文改成单向的"施与……人"，丢了"不分彼此、共同享用"这一层，也使 `appaṭivibhatta` 被读成"不挑对象"。
  - 建议：改为"全都与持戒的、具备善法的人共享，不分彼此"一类表述。**此条取义须以义注为准**，本次义注缺失，定案前请先取义注复核。

### 🟨 warning

- `171-2062-2-23`｜关键语意不明确（内嵌引语未区分）｜片段「这位世尊……乃至……是天人之师、佛、世尊。」
  - 问题：`itipi so bhagavā … buddho bhagavāti` 是"净信"内容的引述语（由 `ti` 收尾），译文把它直接接在外层引号内，与世尊本人的话语混为一体，层次不清。
  - 建议：内嵌引述用全角单引号标出，如"……具备不坏的净信——‘这位世尊……是天人之师、佛、世尊’。"

- `171-2062-2-23`｜关键词语意不明确｜片段「……乃至……」
  - 问题：`pe`（peyyāla，省略反复文）译作"乃至"沿袭旧译惯例，但对无巴利背景的读者不表示"此处省略重复段落"，反而会读成"甚至/以至于"。同一问题见 `171-2062-24-43`。
  - 建议：统一改为"（中略）"或"（以下从略）"，或在该章首次出现处加一次译注说明。

- `171-2062-24-43`｜关键词语意不明确｜片段「……乃至……」
  - 问题：同上，本句连用两处。
  - 建议：与前句统一处理。
