# Review — 171:882-885（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注 ✅（book 137, §327-386）

## 跨段一致性
- `sato … sampajāno`：§884 句 2-11 与 §885 句 66-73 是同一句原文，译文完全相同（「应当保持正念、具足正知地生活」）✅
- `sampajānakārī hoti`：§885 内 7 处全部统一译「保持正知而行」✅，§885 句 57-65 收句亦同 ✅
- `Ayaṃ vo amhākaṃ anusāsanī`：§884、§885 两处译法一致 ✅
- `sampajāno`：§884 句 2-11 译「具足正知」，句 25-41／42-60 的四念住定型句中译「正知」，§885 译「有正知」。四念住定型句用单字「正知」是惯例，可接受；但同一 chunk 内 `sato hoti`／`sampajāno hoti` 译「有正念」「有正知」而开头总说句译「保持正念」「具足正知」，建议问答呼应更紧：见下 §884 句 17-24 条。

## §884 句 171-884-2-11
- **问题**：语体 — 「比丘应当保持正念、具足正知地生活」中「保持…、具足…地生活」三层叠加，且 `vihareyya` 在下文问答里对应的是 `sato hoti` / `sampajāno hoti`（状态），不是「生活」这个动作。义注未释此句，但整经结构是「总说—分释」，总说的用词应能被分释接住。
- **建议**：改为「比丘们，比丘应当具念而住，正知而住。」或「…应当保持正念、保持正知地安住。」——与下文「怎样才算有正念/有正知」对得上。

## §884 句 171-884-17-24 / 句 61-69
- **问题**：语体（口语化）— 「怎样才算有正念呢」「这样比丘就算有正念了」。`Kathañca … sato hoti` 是义注体系里的定义式问答，「才算」「就算」带有「勉强够格」的口语意味，与经文的界定语气不合。
- **建议**：「比丘们，比丘如何具有正念？」…「比丘们，这样比丘就具有正念。」（§885 句 2-11、57-65 同样处理：「如何保持正知而行？」…「这样比丘就是保持正知而行。」）

## §884 句 171-884-25-41
- **问题**：语序造成语义重复 — 「比丘热忱、正知、具念地观察身体，安住于对身的观察」把 `kāye kāyānupassī viharati` 译了两遍（「观察身体」+「安住于对身的观察」）。原文只有一个 `kāyānupassī viharati`，`ātāpī sampajāno satimā` 是三个修饰主语的形容词。
- **建议**：「比丘们，在这里，比丘热忱、正知、具念，于身随观身而住，除去对世间的贪欲和忧恼；」或走白话路线：「…热忱、正知、具念地安住于对身体的观察，除去对世间的贪欲和忧恼」——二者取一，不要叠加。
- **另**：`abhijjhādomanassaṃ` 译「贪欲和忧恼」可，但义注在 §355 引《增支部》时用的是 `abhijjhādomanassā pāpakā akusalā dhammā`，此处保持「贪欲和忧恼」即可，无须改。

## §884 句 171-884-42-60
- **问题**：同上句的叠加问题（「观察诸法，安住于对法的观察」）；另外前半「观察感受……略……观察心……略……」把省略部分补成了动词短语，而原文 `vedanāsu … pe … citte … pe …` 只是处格词头，后面整句由 `dhammesu dhammānupassī` 一句带出。
- **建议**：与上句改法保持平行：「于受……略……于心……略……于法随观法而住，热忱、正知、具念，除去对世间的贪欲和忧恼。」省略号前只出词头，不要各自补出「观察」。

## §885 句 171-885-12-56
- **问题 1**：`ālokite vilokite` 译「向前看向旁看」——**义注**：「`Ālokite` `vilokite`ti ettha pana ālokitaṃ nāma purato pekkhanaṃ , vilokitaṃ nāma anudisāpekkhanaṃ」（§353），即 ālokita = 向前看，vilokita = 看斜方（anudisā，四维/斜角方位），不是泛指的「向旁」。义注并说明上下后方的 olokita / ullokita / apalokita 此处不取，可见二词是**方位对举**，译文宜显出这层对举。
  - **建议**：「前视、侧视时」或「向前看、向斜旁看时」——「斜」字是义注 `anudisā` 的着落点。
- **问题 2**：`samiñjite pasārite` 译「弯屈伸展」——**义注**：「`Samiñjite` `pasārite`ti pabbānaṃ samiñjanapasāraṇe」（§365），主语是 `pabbānaṃ`（肢节），并在 §365 以下通篇讲手足（`hatthapādānaṃ`）的屈伸。译文「弯屈伸展」没有着力点，读者不知屈伸什么。
  - **建议**：「屈伸肢体时」或「弯屈、伸展肢节时」。另「弯屈」是生造搭配，现代汉语用「弯曲」或「屈」。
- **问题 3**：`saṅghāṭipattacīvaradhāraṇe` 译「穿持僧伽梨、钵和衣」——**义注**：「ettha saṅghāṭicīvarānaṃ nivāsanapārupanavasena , pattassa bhikkhāpaṭiggahaṇādivasena paribhogo dhāraṇaṃ nāma」（§369），即 `dhāraṇa` 对衣是「穿、披」，对钵是「受食等使用」，是一个动词统辖两类不同用法。现译「穿持…钵」字面上成了「穿钵」，不合义注。另外「僧伽梨、钵和衣」把 saṅghāṭi 与 cīvara 并列成两物又不作说明，读者会误以为是三样不相干的东西。
  - **建议**：「持用僧伽梨（saṅghāṭi）、钵与衣时」——「持用」可同时覆盖穿披与受用；或分说「披着僧伽梨与衣、使用钵时」。
- **问题 4**：`sutte jāgarite` 译「睡着、醒着」。**义注**：「Kiriyamayacittānañhi appavattaṃ suttaṃ nāma , pavattaṃ jāgaritaṃ nāmāti」（§384-36-44）——此处 sutta/jāgarita 依义注是就「作用心转起与不转起」立名，且 §384 描述的是行者「躺着诵习、作意业处而入睡，后来起身」，即**入睡与醒觉**这两个转换，译作状态词「睡着、醒着」尚可，但「睡着」在现代汉语里易读成「睡熟了」的结果义。
  - **建议**：「睡眠、醒觉时」。
- **问题 5**：`uccārapassāvakamme` 译「大便小便时」。**义注**：「uccārassa ca passāvassa ca karaṇe」（§379），`kamma` = 作、行。「大便小便」作动词可，但与前后各项的「…时」搭配读来突兀。
  - **建议**：「大小便时」（已够；若要贴 `kamma`，作「行大小便时」）。
- **问题 6**：跨句用词 — 本句七项排比里前六项用「时」引出，第七项「行走、站立、坐着、睡着、醒着、说话、沉默时」在一串之内又混用「着」尾与光杆动词（行走／站立 vs 坐着／睡着／醒着 vs 说话／沉默），节奏不齐。
  - **建议**：统一为双音节：「行走、站立、坐卧、睡眠、醒觉、说话、沉默时」——但注意 `nisinne` 是坐、`sutte` 是卧/睡，不要合成「坐卧」而丢掉 sutta；建议「行走、站立、坐着、卧着、醒觉、说话、沉默时」，`sutte` 依义注取「睡」则作「睡眠」。

## §885 句 171-885-82-83
- **问题**：`Dutiyaṃ` 译「第二经」。这是品内计数尾标，前文标题已作「二、念经」，此处再出「第二经」与标题重复且体例不一。
- **建议**：统一为「第二。」或「（第二经）」——与全书其他经的尾标体例保持一致（此项属体例决定，需与前后经对齐后统一，不宜单段自行定）。

## 存疑与说明
- **本段无父层黑体被解释词可机械核对**：义注（137）的黑体被解释词 `sato` / `sampajāno` / `abhikkante paṭikkante` / `ālokite vilokite` / `samiñjite pasārite` / `saṅghāṭipattacīvaradhāraṇe` / `asite` `pīte` `khāyite` `sāyite` / `uccārapassāvakamme` / `gate` `ṭhite` `nisinne` `sutte` `jāgarite` `bhāsite` `tuṇhībhāve` 全部出自本文 §884-885，逐一核对如下：
  - `sato`→「正念」、`sampajāno`→「正知」✅
  - `abhikkante paṭikkante`→「前进后退」✅（义注 §328：abhikkanta=gamana 去，paṭikkanta=nivattana 返，且四威仪中皆有——译「前进后退」不排斥义注的宽义，可）
  - `ālokite vilokite`→「向前看向旁看」⚠ 见上，`vilokita` 应显「斜方」
  - `samiñjite pasārite`→「弯屈伸展」⚠ 见上，缺 `pabbānaṃ`（肢节）
  - `saṅghāṭipattacīvaradhāraṇe`→「穿持僧伽梨、钵和衣」⚠ 见上，`dhāraṇa` 对钵非「穿」
  - `asite pīte khāyite sāyite`→「吃、喝、嚼、尝」✅（义注 §375 逐一释为 piṇḍapātabhojane / yāguādipāne / piṭṭhakhajjakādikhādane / madhuphāṇitādisāyane，四者对得上）
