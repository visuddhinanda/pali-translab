# Review — 171:797-853（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本 chunk 只有 §798 句 171-798-6-17 一条 nissaya，而且是品级说明，不是逐词释义；其余各句没有 nissaya，按要求不出逐句意见）

## 跨段一致性

- **ninna / poṇa / pabbhāra**：§798 三处译「低倾、倾斜、斜落」，§831 译「低倾、斜趋、倾落」，§841 又译「倾流」→ 建议统一为 §798 的「低倾、倾斜、斜落」（本 chunk 出现最多）；§801 与 §841 是同一句摄颂（「六条向东低倾」/「六经说向东倾流」），也应统一。
- **vossaggapariṇāmiṃ**：§798 译「趋向于舍遣（vossagga）」，§831 译「导向舍弃」→ 建议统一一个译法；夹注只在首次出现时保留。
- **… pe …**：§798、§813 译「……（中略）……」，§831 译「……乃至……」→ 建议统一为「……（中略）……」。
- **vitthāretabbaṃ / vitthāretabbā(o)**：同一套语在各段的译法是「应当照此详细展开」(§805)、「应当按……详细展开」(§810)、「（以下应当照此详加展开。）」(§821)、「应当这样详细展开」(§829)、「类推广说」(§843)、「逐项展开」(§851)、「广说」(§798)→ 建议统一为一种，例如「应当照此详细展开」。§821 把这句放进括号，§805 与 §829 用破折号接在句后，格式也应一致。
- **Tassuddānaṃ**：§800 译「本品的摄颂是——」，§807、§823 译「本品的摄颂——」，§815 译「这一品的摄颂是——」，§833 译「本品摄颂——」→ 建议统一为「本品的摄颂——」。§840、§848 的原文是 Uddānaṃ，译「摄颂——」可以保留。
- **品末题**：「恒河略说品第九」(§799)、「洪流品第十三」(§832) 没有逗号；「不放逸品，第十」(§806)、「……品，第十一」(§814)、「寻求品，第十二」(§822) 有逗号；「第十四品」(§839)、「第十五」(§847) 又是另一种格式→ 建议统一为「××品第×。」。
- **段号数字**：§798、§805、§813、§821、§829、§831 用汉字数字加顿号（「二五八至二六九、」），§837、§845 用阿拉伯数字加半角连字符（「312-323」），§853 用阿拉伯数字加破折号（「334—345」）→ 建议统一为汉字数字加顿号，例如「三一二至三二三、」。
- **经题格式**：§838 加了书名号（「《重说恒河等经》」），其余经题都不加（「恒河等经」「如来等经」等）→ 建议去掉书名号。§812 Balādisuttaṃ 译「力等十二经」，多出「十二」，与其他「××等经」不一致→ 建议改为「力等经」。
- **Puna- 品名**：§836 译「重说」，§844 译「再说」，§852 译「第二」→ 建议统一。§852 还把 Balakaraṇīya 译成「力所应作」，而 §811、§814、§818 都译「需要力气才能做的事」→ 品名应统一。
- **bhava**：§821、§824 译「生存」，§829 bhavogha 译「有的洪流」→ 同一术语前后不一，建议统一。
- **同一首摄颂的重复（§808-809 与 §849-850）**：candimasūriyā 一处译「月与日」(§809)，一处译「日月」(§850)；vatthena 一处译「布」(§809)，一处译「衣」(§850)；前者用分号结句，后者用逗号→ 同一首颂应逐字同译。
- **重复的说明句（§810 与 §818）**：句式相同（bojjhaṅgasaṃyuttassa … bojjhaṅgavasena vitthāretabbā），§810 译「觉支相应的不放逸品，应当按觉支的方式详细展开」，§818 译「应当依照觉支相应中的觉支来详细展开」，属格 bojjhaṅgasaṃyuttassa 的归属不同→ 建议按 §810 的结构统一（属格修饰品名）。
- **rāgavasena**：§843 译「按‘贪（rāga）’那一组类推广说」，§851 译「按贪（rāga）等逐项展开」→ 建议统一。
- **peyyāla**：§799、§836 译「略说品」，§826 译「寻求略说段」，§843 译「恒河略说」→ 「段」与「品」的称呼不一，建议统一。

## §798 句 171-798-6-17

- **问题**：nissaya 体例说明 — 这一条 nissaya 不是逐词释义，而是品级说明：
  `(ဂင်္ဂါပေယျာလဝဂ် အစ ပုနဩဃဝဂ် အဆုံးရှိသော ၁၀-ဝဂ်တို့၌ ၁၀၈-သုတ် တို့၏အနက်များကို မဂ္ဂသံယုတ်အတိုင်း သမ္ဗန်၊ မဂ္ဂင်ပါဠိနေရာ၌ ဗောဇ္ဈင်ပါဠိ လွှဲပြောင်းသည်သာ ထူး၏။)`
  意思是：从恒河略说品到再说洪流品这十品、一百零八经的词义，都照道相应（Maggasaṃyutta）的方式对读；唯一的区别是把道支经文换成觉支经文。本句译文的格位与主宾关系没有错。
- **建议**：这十品既然按 nissaya 照道相应同段的词法对读，ninna/poṇa/pabbhāra、vivekanissita、vossaggapariṇāmi、rāgavinayapariyosāna、amatogadha 等套语应与本 channel 道相应恒河略说品的定稿译法逐字一致（参见上节第一、二条）。
