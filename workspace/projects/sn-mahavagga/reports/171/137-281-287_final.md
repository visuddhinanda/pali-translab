## 理由

**基准缺失（影响信心）**：本次待评的就是义注层（book=137）本身，而上文未注入任何**复注/ṭīkā**、**nissaya** 与**本文（mula）层译文**。因此：
- 词级格位、隐含成分无法用 nissaya 核对，词义判断只能依巴利原文与《清净道论》《无碍解道》的通行释义作内部一致性推断；
- 「义注黑体引自本文、逐字同译」这条硬约束**无法验证**——凡黑体被解释词的译法问题，下面只能按义注内部自洽性判定，标为"需与本文层核对"。
这是信心只给 70 的主要原因，不是译文可疑度高。

**准确性（82）**：整体取义稳，四梵住—八解脱/无色定的 upanissaya 结构、六支舍、appaṭikūla/paṭikūlasaññī 的双向操作（asubha-pharaṇa / anicca-manasikāra 对 iṭṭha，mettā-pharaṇa / dhātu-manasikāra 对 aniṭṭha）以及两处《无碍解道》引文都译对了，引文出处 `paṭi. ma. 2.17` 保留完整。扣分集中在四处：`kiṃ gatikā` 被译成「以什么为成就」，与其释义 `kiṃ nipphatti`（成果/成就）撞成同义循环，丢掉了 gati（趣、归趋）的本义；`maggasambojjhaṅgānaṃ` 是"道支与觉支"两项，译文合成「道觉支」一词，实质漏译一项；两处在正文括号里增补了原文没有的解释（三/四禅的分法注、"那一种（解脱）"），其中「（解脱）」还与紧接的 287 段矛盾——karuṇā 的亲依缘是空无边处，并非解脱；`Idhapaññassa` 在同一句里出现两种译法。

**风格（89）**：语体达标，通篇现代书面汉语，未见"此中/故为/彼等/于…之际"一类禁例，标点全角、引号统一用 “ ”，`zh` 字段内无 ASCII 引号，术语首出夹注（saṅkhāra / vipassanā / dhātu / upanissaya）符合体例。只有「对那对象住于舍」保留了以「于」为虚词的半文言写法。扣分另一部分来自可读性：284-2-25、287-2-27 两句嵌套过深，读者需要回读才能理清主干。

**一致性（80）**：主要问题是同一巴利词在本 chunk 内多译。`upasaṃharati` 出现三种译法（引向／从…角度去观察／把心投向），而这三处在巴利里是同一个平行公式；`satta` 在 283 段作「有情」、286 段作「众生」；四问公式「以什么为…」在 `kiṃ phalā` 一条上断裂为「有什么利益」。这些都属于 harmonize 本该抹平的跨段漂移，建议回一轮 harmonize 统一，再重评。

## 问题清单

### 🟧 error
- `137-282-49-56`｜错译（词义）｜片段「它以什么为成就」
  - 问题：`kiṃ gatikā` 是"以什么为趣（归趋、结局）"，不是"成就"；译成「成就」后与其释义 `kiṃ nipphatti`（已译「成果」）语义重合，整条注释变成"成就就是成果"的同义循环，读者读不出义注在解释什么。
  - 建议：黑体改为「以什么为趣」（并与本文层该词译法核对），释义保留「就是有什么样的成果」。

- `137-284-2-25`｜漏译｜片段「道觉支」
  - 问题：`maggasambojjhaṅgānaṃ` 是 magga（道支）与 sambojjhaṅga（等觉支）两项并列，译文压缩成「道觉支」一个词，少了一项，且易被误读为某种叫"道觉支"的单一法。
  - 建议：改为「道支与觉支」。

- `137-284-2-25`｜错误多译｜片段「（即四分法中的前三禅、五分法中的前四禅）」
  - 问题：巴利仅有 `tikacatukkajjhānaṃ`，括号内是译者的教理补注，不在原文中；按体例，正文圆括号只用于术语首次出现夹注巴利原词，解释性内容应作段后注释。
  - 建议：正文保留「三禅与四禅（tika-catukka-jjhāna）」，把分法说明移到段后小字注释。

- `137-285-10-26`｜导致误解的表达｜片段「慧不出世间」
  - 问题：同一个 `idhapañña` 在本句内先译作黑体「慧不出世间」，随后释义又译作「慧只在此世间的人」，读者看不出这是同一个被解释词；且黑体本应与本文层（`idhapaññassa bhikkhuno`）逐字同译，"不出世间"是意译加否定式，与本文层大概率不一致。
  - 建议：黑体与释义统一为同一形式（如「慧在此世间的」），全句作「所谓**慧在此世间的**，是说他的慧只在这里，不超越这个世间，所以叫做慧在此世间的人」；并与本文层译法核对。

- `137-286-9-13`｜错误多译｜片段「那一种（解脱）的亲依缘」
  - 问题：`tassa tassa` 只是"各自那一种（所说的最上者）"，括号补入「解脱」超出原文，并与下一段矛盾——287 段说 karuṇā 的亲依缘是空无边处，而空无边处并不称为解脱。
  - 建议：删去括号，作「它们各自都是各自那一种的亲依缘（upanissaya）」。

### 🟨 warning
- `137-282-63-68`｜关键词语意不明确｜片段「有什么利益」
  - 问题：`kiṃ phalā` 是"以什么为果"，译成「有什么利益」既偏离 phala 的本义，又与其释义 `kiṃ ānisaṃsā`（已译「功德」）职能混淆；同时打断了 49–74 四条「以什么为…」的并列公式（成就／最上／利益／终点），四问结构在译文里看不出是一组。
  - 建议：改为「以什么为果」，释义保留「就是有什么样的功德」。

- `137-283-76-98`｜关键词语意不明确｜片段「或者从界的角度去观察」
  - 问题：`upasaṃharati` 在本 chunk 三处同一公式里被译成三个不同说法——`137-283-42-54`「或者把它引向无常」、本句「从界的角度去观察」、`137-286-14-32`「把心投向」。巴利是同一动词的平行用法，译法分裂后读者无法识别这是成对的操作公式。
  - 建议：统一为「引向」类译法，如「或者引向界」「把心引向…」，全 chunk 一致。

- `137-282-23-40`｜代词指代不明确｜片段「这句话也是他们照前面同样的方式」
  - 问题：「他们」首次出现时上文尚未点明主语，指的是外道（titthiyā），须到下一句「因为在外道的宗义里」才能回推。
  - 建议：改为「也是那些外道照前面同样的方式…」。

- `137-283-129-171`｜文言语体｜片段「对那对象住于舍」
  - 问题：「住于」以「于」作文言虚词，属半文半白写法；「那对象」也缺量词。
  - 建议：改为「对那个对象保持舍心而安住，正念正知」。

### 🟦 suggestion
- `137-282-23-40`｜该使用而没有使用术语标记｜片段「朋友们」
  - 问题：`āvuso` 的通行汉译是「贤友」（复数「诸贤友」），「朋友们」偏日常口语，且黑体部分需与本文层一致。
  - 建议：改为「诸位贤友」，并与本文层译法对齐。

- `137-282-2-22`｜语言风格不统一｜片段「与慈俱行的心」
  - 问题：本文层 `mettāsahagatena cetasā` 是具格（"以与慈俱行的心"），黑体译文取了主格式名词短语，可能与本文层不逐字同。
  - 建议：核对本文层，若本文作「以与慈俱行的心」则此处同步。

- `137-286-14-32`｜语言风格不统一｜片段「众生都是不可厌的」
  - 问题：`satta` 在 `137-283-2-10`（「有情的不可厌」）译作「有情」，此处及 `137-287-2-27` 译作「众生」。
  - 建议：全 chunk 统一取一个（建议「有情」，与 283 段的分类术语保持一致）。

- `137-283-21-25`｜语言表达不够流畅｜片段「他是怎样这样安住的呢」
  - 问题：「怎样这样」两个指示词连用，拗口。
  - 建议：改为「他是如何做到这样安住的呢？」。

- `137-284-26-45`｜语言表达不够流畅｜片段「既然这样的人的慈不是以阿罗汉果为最上的」
  - 问题：「这样的人的」两个「的」连缀。
  - 建议：改为「既然这种人的慈并不以阿罗汉果为最上」。

- `137-287-2-27`｜语言表达不够流畅｜片段「由于悲由此现起」
  - 问题：「由于…由此」重复，且因果关系表达含糊。
  - 建议：改为「由于悲心因此得以现起」。

- `137-284-2-25`｜复杂的嵌套句整句语言逻辑理解困难｜片段「由于与观一同生起的道觉支以及圣神变都已经显示出来了，这段说法本来可以到此结束」
  - 问题：全句连缀"修禅—作基础—增长观—证果—显示道支觉支与圣神变—说法可结束"六层，单句过长，主干（说法本可结束）被推到句末。
  - 建议：在「证得阿罗汉果」后断句，另起一句陈述"至此，与观俱起的道支、觉支和圣神变都已说明，这段开示本来可以结束"。

- `137-282-69-74`｜语言表达不够流畅｜片段「以什么为终点**，就是以什么为终结」
  - 问题：「终点」与「终结」近义，释义读来像重复（巴利 `pariyosāna` / `niṭṭhā` 本就近义，但汉译可拉开区别）。
  - 建议：释义改为「就是以什么为最后的归结」。
