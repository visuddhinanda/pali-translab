**准确性**：绝大多数被解释词的对译与原文相符，释义句（`X ti Y` 结构）一律处理为「**X**，是说/就是 Y」，方向正确，没有把被释词与释词颠倒。`Idañca paccatte sāmivacanaṃ`（属格用于主格义）、`sāvasesapāṭhanaya`（有余读法）两处语法术语理解到位，是本段最难的地方。扣分主要来自三处：`Jaṅgalānaṃ` 的对译与释义之间被译成同义反复而丢了原文语义层次；`samodhānaṃ gacchanti` 的释词 `odhānaṃ upakkhepaṃ` 两词在译文里合成一句同义叠加，两个释词各自的分工消失；`mahantattena` 与 `guṇavasena` 的对举中，后半「品质殊胜」把 `guṇa` 的释读窄化了。

**风格**：现代书面汉语基调是守住了的，没有「此中/故为/彼等」一类明显文言腔。但叙事段（88-10-40 起的跋提耶王故事）仍残留若干半文半白成分——「伏在地上」「面朝」「匣子」尚属可接受的书面语，但「说道」「说得真好啊」与前文的叙述语体略有落差，且「涂饰地面」「取来」偏紧缩。真正需要处理的是一处单音节文言连接与一处文言式判断句，已在问题清单列出。标点全角，未见 ASCII 引号，符合 JSON 安全约束；未见任何残留工作标记。

**一致性**：`vassika` 在 88-6-9 译「茉莉花」、其释词 `sumanapuppha` 译「素馨花」，而 88-41-51、88-57-70 两处又分别出现「素馨花的香气」与「茉莉花是其中最上的」——同一物在同段内在两个名目间来回切换，读者会误以为是两种花。这是本段最实质的一致性问题。此外夹注巴利原词的做法不统一：「素馨花（sumanapuppha）」与「跋提耶大王（Bhātiya）」加了夹注，而「茉莉花」「大塔」「织机」未加，取舍标准看不出规律。

## 问题清单

### 🟧 error

- `137-86-2-9`｜错译（词义）｜片段「**陆地上**，是说住在地面上的」
  - 问题：`jaṅgalānaṃ` 是属格复数形容词，修饰下一句的 `pāṇānaṃ`，指「陆生的（动物）」；释词 `pathavītalavāsīnaṃ` 才是「住在地面上的」。译文把被释词译成处所状语「陆地上」，与释词「住在地面上的」构成同义反复，被解释词的属格身份与形容词性质都丢了。此处「被解释词与父层逐字同译」的对齐也因此无法成立——本文若作「陆生动物的」，此处黑体应当同形。
  - 建议：被释词改为「**陆生的**」一类属格形容词译法，使其与下句「**动物的**」连读成「陆生动物的足迹」；释词保留「是说住在地面上的」。

- `137-86-19-25`｜漏译 / 错译（修饰关系）｜片段「意思是归入其中、被纳入其中」
  - 问题：释词是 `odhānaṃ upakkhepaṃ gacchanti` 两个并列的宾语名词（`odhāna` 收纳、`upakkhepa` 置入），共用动词 `gacchanti`；义注在此用两个近义词分别锚定 `samodhāna` 的两重意思。译文「归入其中、被纳入其中」两句同义，且后半改成被动，`upakkhepa`（主动置入）的语义与两词的分工都消失了，实质是把两个释词并成一个。
  - 建议：让两个释词各自落地，如「意思是进入收纳、进入置入」过于生硬时，可作「意思是被归拢在一起、被安置在其中」，但需保证两者不同义；并统一语态，勿一主动一被动。

- `137-86-31-40`｜义理或用词与注释书不符｜片段「不是因为它品质殊胜」
  - 问题：`na guṇavasena` 中 `guṇa` 在此与 `mahantatta`（体量之大）对举，指的是德性/功德（象足之所以为最上仅因其大，而非因其有德），译作「品质殊胜」偏向物品优劣的世俗评价，把对举的教理意味削平了。同句前半「因为体积巨大」把 `mahantabhāva` 落在「体积」上亦偏窄——原文只说「大」，兼含体量与身量。
  - 建议：改为「不是因为它有什么德性」或「不是就功德而言」；前半「因为体积巨大」可改「因为它大」。

### 🟨 warning

- `137-88-6-9`｜关键词语意不明确（同物异名，未加注）｜片段「**茉莉花**，就是素馨花（sumanapuppha）」
  - 问题：`vassika` 与释词 `sumanapuppha` 在译文里成了「茉莉花」与「素馨花」两个不同的花名，读者无法看出这是同一物的释义；而下文 88-41-51 用「素馨花的香气」、88-57-70 又回到「茉莉花」，同一段内两名交替，加重混乱。
  - 建议：全段统一用一个主名（建议「茉莉花」），释词处作「就是素馨花（sumanapuppha），也叫茉莉」或直接说明二名同指；88-41-51 的「素馨花的香气」随之统一。

- `137-88-104-115`｜整句逻辑表达不规范｜片段「或者说，在织在织机上的布当中的某些布——这里的意思也可以按这种表示部分（有余）的读法来理解」
  - 问题：「在织在织机上的布当中的某些布」连用三个「的」和两层「在…当中」，是未消化的直译；破折号把原文的「…ti evaṃ …attho daṭṭhabbo」结构硬接，整句读不通顺。`sāvasesa`（有余、未尽）译作「表示部分（有余）」尚可，但夹注位置使句子更重。
  - 建议：拆为两句，如「或者，也可以把它理解成「织在织机上的那些布里的某几种布」——即按有余（sāvasesa）读法来解。」

- `137-88-52-56`｜不导致误解的汉语语病 / 标点｜片段「他就在大露台上，面朝大塔伏在地上，」
  - 问题：`mahātalasmiṃyeva` 的 `yeva` 强调义（就在大露台上、当场）在译文里由「就」承担，但「他就在…上」易被读成判断句「他就在那里」；「伏在地上」与「在大露台上」并置，地点重复。另本句以逗号结尾、由下一句续完，跨句读时衔接可以，但独立成句 id 后该逗号使本句不成句。
  - 建议：改为「他当下就在大露台上朝着大塔俯身拜下，」或把地点与动作合并为「他就地在大露台上面朝大塔俯伏下来，」。

- `137-88-75-82`｜关键词语意不明确｜片段「也有作“khuddarājāno”的异读」
  - 问题：全段其余巴利词或译出、或夹注在汉译之后，此处单独留一个未转写、未解释的裸巴利词 `khuddarājāno`，普通读者不知其与上句「小王」的关系（`kuṭṭa-` 与 `khudda-` 的异文之别）。
  - 建议：补一句说明，如「也有作 khuddarājāno（小王）的异读」，使异文与正文的对应关系显现。

- `137-88-93-96`｜关键词语意不明确｜片段「这里的属格是用来表示主格的」
  - 问题：`paccatte sāmivacanaṃ` 的判断对象是上句的 `tantāvutānaṃ`，译文用「这里的属格」指代，但「这里」范围不明（是指 `tantāvutānaṃ` 还是连 `vatthānaṃ` 一起）；且「表示主格」按语法学惯例宜作「用在主格义上」。
  - 建议：明示对象，如「这里的属格（tantāvutānaṃ）是用在主格义上的」。

### 🟦 suggestion

- `137-88-10-40`｜语言表达不够流畅｜片段「就在一间内室里用四种香料涂饰地面，让人取来各种芳香的花」
  - 问题：`catujātigandhehi paribhaṇḍaṃ kāretvā` 是「命人用四种香料把地面涂抹整饰」，译文「用四种香料涂饰地面」丢了 `kāretvā` 的使役（是命人做，非亲手做），而紧接的「让人取来」又把使役译出，同句内使役处理前后不一。整句一气到底约六十字，嵌套偏长。
  - 建议：统一使役，如「就让人在一间内室里用四种香料把地面涂饰过」；并在「然后关上门走到外面」前断句。

- `137-88-57-70`｜语言风格不统一｜片段「说得真好啊。”说着就礼拜了大塔」
  - 问题：「真好啊」的口语叹词与本段其余部分的书面叙述语体落差较大；`sukathitaṃ`（说得好、说得贴切）本身是平实的赞语。「说着就礼拜了大塔」中「说着」与前面的「说道」重复交代言说动作。
  - 建议：改为「…说得真贴切。”于此礼拜了大塔」或把引语与礼拜合并为一次动作交代。

- `137-86-15-18`｜该使用而没有使用术语标记｜片段「**足迹**，就是脚印」
  - 问题：`padajātāni` 的 `-jāta` 有「所成、种类」义，义注以 `padāni` 为释，说明重点在「即是 pada 而已」；译文「足迹／脚印」二词在现代汉语中几乎同义，释义显得多余，读者看不出义注在澄清什么。
  - 建议：可作「**足迹之类**，就是足迹」，或在释词后加极简夹注说明 `-jāta` 不另立一义。

- `137-89-2-4`｜语言风格不统一｜片段「不放逸品第八。」
  - 问题：品题译法本身正确，但与 85-2-4「二、足迹经的解释」、87-4-4「顶尖经等的解释」的标题体例不一致——前者用「序号、+经名+的解释」，此处为古籍体「X品第八」。全书标题体例宜统一登记。
  - 建议：确认项目标题体例后统一，如「第八、不放逸品」或保留现译但在 `knowledge/style.md` 中登记品题例外。
