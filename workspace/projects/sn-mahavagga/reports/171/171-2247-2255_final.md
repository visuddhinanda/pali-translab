## 理由

**数据条件（先交代）**：本次评估**未取到义注（aṭṭhakathā）**，也**未取到 nissaya**，注入的资源只有巴利原文与 channel 译文。因此"义注定释义、nissaya 定词法"两条基准都无法执行，词法判断（格、句法角色、隐含成分）与术语取义只能依巴利原文本身与南传通行释义推断。信心指数据此压到 70——尤其 `devapada`、`nibbedhika`、`pariyodapana` 三处的取义需要义注确认，本报告中相关条目只列为 suggestion，不作扣分性定论。

**准确性**：本段为《增支部》四法经典套语段，结构简单、省略（`…pe…`）多，译文对 `cattāro / katame cattāro / ayaṃ paṭhamo / ime kho` 的数目与序次处理正确（2249 段两项省略、2250 段接"第四"的编号链完整，未出现错序）。主要扣分来自一处**核心套语的主谓判断错误**：`itipi so bhagavā` 译成"他就是世尊"，把 `bhagavā`（同位语）当成了谓语，而该套语的真正谓语是被 `…pe…` 省略掉的 `arahaṃ sammāsambuddho…` 一串。此句是佛随念（buddhānussati）定型句，误读会让整句变成"确认他是世尊"，与原意（"这位世尊是这样的：应供、正等正觉……"）相去甚远。该错误在 2248、2253 两处一致出现，属同一处译法而非漂移。其余词汇层面：`udayatthagāminī paññā` 译"通达生起与灭没的智慧"、`sammā dukkhakkhayagāminī` 译"能正确地导向苦的灭尽的"、`ariyakantehi sīlehi` 译"圣者所喜爱的戒"、`samādhisaṃvattanika` 译"能导向定"均可接受，无漏译、无多译。

**风格符合度**：整体为现代书面汉语，句子平白，未见"此中/故为/彼等/是故"一类硬性文言腔。扣分集中在经题：`第一天之足迹经` 用了文言虚词"之"，且"第一天"在现代汉语里会先被读成"the first day"，是本段唯一明显的语体与歧义双重问题。另有 `能穿透（烦恼）的` 用圆括号补出原文没有的词——`knowledge/style.md` 第三节规定圆括号只用于首现术语夹注巴利原词，此处属体例外用。`快乐的食粮` 的偏正关系在汉语里会被读成"食粮是快乐的"，语意不够明确。标点方面全篇用全角，未出现 ASCII 引号、未出现「」，符合硬约束；唯 2253 段起首缺连续引语的开引号，与 2249/2250/2252/2254/2255 各段的处理不一致。

**一致性**：同一巴利套语在不同段落的译法高度统一——`avisuddhānaṃ sattānaṃ visuddhiyā apariyodātānaṃ sattānaṃ pariyodapanāya` 在 2252、2253、2255 三段四次出现，用字完全一致；`puññābhisando kusalābhisando sukhassāhāro` 三次出现亦完全一致；佛随念套语两处逐字相同（虽然两处都错，但错得一致，harmonize 后统一修一处译法即可）。扣分只在两篇经题的构词风格不统一（"第三福德流注经"无"的"、"第一天之足迹经"用"之"），以及 `visuddhi/pariyodāta` 译为"清净/洁净"两词在汉语里区分度太低，读者难以察觉原文是两个不同的词。

## 问题清单

### 🟧 error

- `171-2248-19-39`｜错译（修饰关系）｜片段「他就是世尊」
  - 问题：`itipi so bhagavā` 的 `bhagavā` 是 `so` 的同位语，不是谓语；真正的谓语是随后被 `…pe…` 省略的 `arahaṃ sammāsambuddho…` 一串德号（本句末尾保留的 `satthā devamanussānaṃ buddho bhagavā` 就是这串德号的尾部）。译成"他就是世尊"把同位语误判为谓语，整句变成在确认"他是世尊"，而原意是"这位世尊是这样的：……"，随念的对象（诸德号）被架空。
  - 建议：改为"这位世尊是这样的：……（中略）……天与人的导师、佛、世尊"，让后面的德号列表落在谓语位置上。

- `171-2253-6-27`｜错译（修饰关系）｜片段「他就是世尊」
  - 问题：同 `171-2248-19-39`，同一佛随念套语的同一误读。
  - 建议：与 2248 处一并改，保持两处逐字一致。

### 🟨 warning

- `171-2251-2-4`｜文言语体｜片段「天之足迹」
  - 问题：用了文言虚词"之"。`knowledge/style.md` 第一节明确"之/其/乃/便/即"作文言虚词时禁用。
  - 建议：改"天的足迹"。

- `171-2251-2-4`｜关键词语意不明确｜片段「第一天之足迹经」
  - 问题："第一天"在现代汉语里会被优先读成"the first day"，序号"第一"与"天（deva）"粘连产生歧义；同系列另一篇译作"第三福德流注经"（序号+题名，无歧义），此处结构相同却因"天"是单音节而失效。
  - 建议：改"天的足迹经（一）"或"第一·天的足迹经"，把序号与题名切开。

- `171-2248-2-15`｜关键词语意不明确｜片段「快乐的食粮」
  - 问题：`sukhassa āhāra` 是"（带来）快乐的滋养品"，属格表结果；译作"快乐的食粮"在汉语里会被读成"食粮本身是快乐的"，偏正关系走反。该译法在 2248-40-45、2250-20-25、2250-26-38 一致沿用，改则四处同改。
  - 建议：改"滋养快乐的食粮"或"带来快乐的滋养"，并在 `knowledge/terms.md` 登记 `sukhassāhāra` 的定译。

- `171-2250-2-19`｜标点符号使用错误｜片段「能穿透（烦恼）的」
  - 问题：圆括号里补出的"烦恼"不是原文词。`knowledge/style.md` 第三节规定圆括号只用于首现术语夹注巴利原词，用它补出隐含宾语会让读者误以为"烦恼"是原文括注。
  - 建议：去掉括号直接写"能洞穿烦恼的"，或译"有抉择力的（nibbedhika）"，把所穿透的对象留给脚注——具体取义请以义注对 `nibbedhikā` 的解释为准。

- `171-2253-2-5`｜标点符号使用错误｜片段「哪四种呢？」
  - 问题：这是 2253 段的起首句，处于 2252 段开启的连续引语之内，但缺开引号。同一段连续引语的其他各段（2249、2250、2252、2254、2255）起首都补了"。
  - 建议：补为"哪四种呢？"。

- `171-2250-26-38`｜不导致误解的汉语语病｜片段「这就是那四种」
  - 问题：`ime`（这些）是近指，"这就是那四种"近指与远指混用，汉语不顺。`171-2255-31-48` 同样问题（片段「这就是那四种」）。
  - 建议：两处均改"比丘们，这就是四种……"。

### 🟦 suggestion

- `171-2251-2-4`｜不常用术语编写注释或者百科｜片段「天之足迹」
  - 问题：`devapada` 直译"天的足迹"对读者不构成理解线索——它指的是"使人成为天（生天／如天者）的行迹、道迹"。这是本经题眼，首现处无注。
  - 建议：首现加简注说明 `devapada` 指趣向天界／令众生如天的行迹。**取义须以义注为准**，本次未取到义注，请 revise 前补查。

- `171-2252-9-21`｜语言风格不统一｜片段「为了使还没有洁净的众生洁净」
  - 问题：`visuddhi` 译"清净"、`pariyodāta/pariyodapana` 译"洁净"，两词汉语几乎同义，读者无法看出原文是两个不同的词，排比也因此显得重复。该译法在 2253-28-38、2255-20-30、2255-31-48 一致沿用。
  - 建议：`pariyodapana` 改用"遍净"或"净化"一类有区别度的译法，首现夹注 `（pariyodāta）`；四处同改。

- `171-2250-2-19`｜语言表达不够流畅｜片段「这智慧是圣的、能穿透（烦恼）的、能正确地导向苦的灭尽的」
  - 问题：三个"的"字定语并列收尾，句末"的"堆叠，读起来拖沓。
  - 建议：改为"这智慧是圣的，能洞穿烦恼，能正确导向苦的灭尽"，把后两项改成谓语性表达。

- `171-2250-2-19`｜语言表达不够流畅｜片段「圣弟子有智慧，具有通达生起与灭没的智慧」
  - 问题：`paññavā hoti ... paññāya samannāgato` 原文本就重复"慧"，但汉语连用两个"智慧"显得赘。
  - 建议：前半改"圣弟子具足智慧"，后半改"他所具有的智慧能通达生起与灭没"，避免同词紧邻复现。

- `171-2247-2-4`｜语言风格不统一｜片段「3. 第三福德流注经」
  - 问题：与 `171-2251-2-4`「4. 第一天之足迹经」构词不一致——一处"福德流注"无助词、一处用文言"之"；且经题里的"福德流注"与正文"福德的流注"用字不统一。
  - 建议：两篇经题统一为"序号 + 题名（序次）"格式，题名用字与正文一致。

- `171-2252-2-8`｜语言表达不够流畅｜片段「本经的因缘在舍卫城」
  - 问题：`Sāvatthinidānaṃ` 是定型的出处标记，"本经的因缘在舍卫城"读来像陈述句而非标记，且"因缘"在此指说法缘起地点。
  - 建议：可改"（本经）缘起于舍卫城"或按本书既定体例统一处理这一标记句——建议在 `knowledge/terms.md` 固定该定型句译法，避免后续章节各译一套。
