## 理由

**基准缺失（影响信心）**：本次只注入了巴利原文与待评译文。本层本身就是义注（book=137），**没有注入复注（ṭīkā）**，也**没有 nissaya channel** 可对齐词法；因此「以义注定释义、以 nissaya 定词法」两条基准都无法直接执行，词法判断只能依据原文形态与《清净道论》的平行段落（本段自己引了 Visuddhi. 1.15）。信心指数据此压到 62——准确性结论中，词级（格/句法角色）部分未经 nissaya 复核。

**准确性**：三段七句，主谓宾判断与教理表述没有发现 fatal 级问题；骸骨想的定义、相未生/相已生时 chavi-camma 的显现与不显现、骨聚显现如螺色，这些核心命题都译对了。扣分集中在两处：
1. `Sattamādīsu` 被译作「第七**品**」。本段是 `Aṭṭhikamahapphalasuttādivaṇṇanā`（骸骨大果经**等**的解释），`sattama-ādi` 的所指是本品内的第七**经**及以下诸经，不是第七个品——而且译文本身前一句刚把 `Ānāpānavaggo` 译成「入出息品」，同一处上下文出现两个不同层级的「品」，读者会误读成跨品指称。
2. `Sati vā upādisese` 的 `vā` 未译。这是经文定型句（`diṭṭheva dhamme aññā, sati vā upādisese anāgāmitā`）中的选择连词「或」，译文作「若尚有残余的执取」，把选择关系换成了条件关系，同时丢了 `vā`。

另有一处不算错但削弱了注释功能：被释词 `upādisese` 与释词 `upādānasese` 译成了同一个「残余的执取」，使这条注释在汉语里变成自我解释（用「残余的执取」解释「残余的执取」）。原文两个释词 `gahaṇasesa` / `upādānasesa` 是用同义语并列来界定被释词，译文需要让被释词与释词在字面上区分开。

**风格**：现代书面汉语达标，**未发现文言或半文半白用例**（无「此中/故为/彼等/是故/于…之际/答以」之类）；标点全为全角，`zh` 字段内无 ASCII 引号，JSON 安全。扣分主要在 `137-298-27-51`：两个 `viya` 从句各自套着长定语（「望着骑在象背上的法帝须王（Dhammikatissa）的沙弥」），中心语被推到句末，属于对读者不友好的嵌套；且比较项不对等——原文比的是「显现的情形」，译文比成了「人」。

**一致性**：`aṭṭhika` 全程作「骸骨」（骸骨大果经／骸骨想／骸骨聚合体），`Tissa` 全程作「帝须」（法帝须王／帝须长老），专名夹注用全角圆括号且只在首次出现——都合 `style.md`。术语标记的使用偏保守：`nimitta`（相）、`upādisesa` 这两个有歧义或有传统定译的词首次出现均未夹注巴利原词。译文中**没有**残留候选、待定、问号等工作标记。

## 问题清单

### 🟧 error
- `137-298-2-13`｜错译（词义、导致误解的表达）｜片段「在第七品等当中」
  - 问题：`Sattamādīsu` 指本品内的第七经及以下各经（呼应标题 `Aṭṭhikamahapphalasuttādi`），译成「第七品」把所指层级抬高到了 vagga；与同段前句的「入出息品」并置后，读者会误解为指别的品。
  - 建议：改为「在第七经等当中」或「在（本品）第七经以下诸经中」。

- `137-298-63-70`｜漏译 / 错译（句间逻辑关系）｜片段「若尚有残余的执取」
  - 问题：被释词 `Sati vā upādisese` 中的 `vā`（或）未译。该句出自经文定型句「diṭṭheva dhamme aññā, sati vā upādisese anāgāmitā」，`vā` 承担「或者」的选择关系；译作「若…」变成条件句，既丢词又改了逻辑关系。
  - 建议：被释词按「或者，当尚有余执取时」处理（保留「或」），条件义交给后面的释文承担。

### 🟨 warning
- `137-298-63-70`｜关键词语意不明确（被释词与释词同形，注释自我循环）｜片段「是说在残余的抓取、残余的执取还存在的时候」
  - 问题：被释词 `upādisesa` 已译作「残余的执取」，释词 `upādānasesa` 又译作「残余的执取」，同一注释里被释与释文字面重合，汉语读者看不出这条注在解释什么；`upādisesa` 另有传统定译（有余／余依，如「有余涅槃」）可用来区分。
  - 建议：被释词取传统译法（如「尚有余执取」「有余依」），释词维持「残余的抓取、残余的执取」，并在被释词首次出现处夹注（upādisesa）。

- `137-298-27-51`｜整句逻辑表达不规范（比较项不对等）｜片段「就像那位望着骑在象背上的法帝须王（Dhammikatissa）的沙弥」
  - 问题：原文 `…upaṭṭhāti … sāmaṇerassa viya … tissattherassa viya` 比较的是「（骨聚）显现的情形」，译文的比较对象落成了人（就像那位沙弥），谓语省略过头，读起来像在把骨聚比作沙弥。
  - 建议：补足比较的落点，如「就像那位沙弥望着骑在象背上的法帝须王时所见的那样，也像住在塔山的帝须长老望着迎面路上笑着的女人时所见的那样」。

### 🟦 suggestion
- `137-298-14-26`｜该使用而没有使用术语标记｜片段「在相还没有生起之前」
  - 问题：`nimitta`（相）是本段禅修语境的关键术语，且汉语「相」单用歧义大（lakkhaṇa / nimitta / saññā 都可作「相」），首次出现未夹注巴利原词。
  - 建议：首次出现作「相（nimitta）」，其后沿用「相」。

- `137-298-14-26`｜关键词语意不明确（二意场合缺区分）｜片段「表皮和皮肤都还会显现出来」
  - 问题：`chavi` 与 `camma` 在《清净道论》身分观语境中是外层／内层两种皮的对举，「表皮和皮肤」两词不构成同一层级的对举，后者范围反而更大，层次关系读不出来。
  - 建议：按对举关系处理，如「外皮和内皮」，或「外皮和皮层」。

- `137-298-2-13`｜错误多译（轻微增字）｜片段「是指不断作意“骸骨、骸骨”而修习的人所生起的想」

  - 建议：「是指修习“骸骨、骸骨”的人所生起的想」，是否保留「不断」视全书体例统一而定。

- `137-298-52-62`｜语言表达不够流畅｜片段「这些故事在《清净道论》（Visuddhi. 1.15）中有详细叙述」

  - 建议：「这两则事例在《清净道论》（Visuddhi. 1.15）中有详细叙述」。
