# Review — 171:1177-1195（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **段号格式**：§1178 作“480.”，§1189 作“四八一、”，§1195 作“482.” → 统一为阿拉伯数字“481.”。
- **pañcindriyāni / indriyāni**：§1178 译“有这五根”“这些就是五根”，§1189、§1195 译“有这五种根”“这些就是五种根”，§1195-18-30 又作“这就是五根” → 统一为“五根”（“五根”是固定法数，不必加“种”）。
- **… pe …**：§1178、§1180、§1189 译“乃至”，§1195-18-30 译“中略” → 统一为“乃至”。
- **saddho hoti, saddahati**：§1178 译“圣弟子有信，他相信如来的觉悟”，§1189 译“圣弟子是有信的，他信受如来的觉悟” → 统一为 §1178 的写法。
- **如来十号（itipi so bhagavā …）**：
  - §1178 译“这位世尊就是这样的：阿罗汉……无上士调御丈夫……’”，§1189 译“这位世尊就是阿罗汉……无上的调御丈夫……。’”，两处起句、十号写法和句末标点都不同。
  - nissaya 每个名号前都有 `ဣတိပိ= …ဤအကြောင်းကြောင့်လည်း`（“由于这个缘故也……”），§1189 把 itipi 完全略去了。
  - nissaya 把 `အနုတ္တရောပုရိသဒမ္မသာရထိ` 作为一个名号来释（“无人胜过他、最殊胜，调御一切应调伏的人”），§1178 写成“无上士调御丈夫”，中间不断开，读者分不清是一号还是两号。
  - → 两处统一，建议都作：“这位世尊就是这样的：阿罗汉、正等正觉者、明行具足者、善逝、世间解、无上调御丈夫、天人师、佛、世尊’”。
- **cittassa ekaggataṃ**：§1181 译“心的专一”，§1192 译“心的一境性” → 统一（nissaya `တခုတည်းသော အာရုံရှိသည်၏အဖြစ်` 意为“只有单一所缘的状态”），建议都作“心的专一”。
- **ārammaṇa 夹注**：§1192 作“所缘（ārammaṇa）”，但本 chunk 首次出现是 §1181-10-23，那里没有夹注 → 夹注移到 §1181，§1192 删去。
- **paññavā / udayatthagāminiyā / ariyāya / nibbedhikāya**：§1182 与 §1193 是同一句：
  - paññavā：§1182 译“有慧”，§1193 译“有智慧”；
  - udayatthagāminiyā：§1182 译“能洞察生灭”，§1193 译“通达生灭”；
  - ariyāya：§1182 译“圣的智慧”，§1193 译“它是圣的”；
  - nibbedhikāya：§1182 译“能穿透烦恼”，§1193 只作“能穿透”；
  - 两处句式也不同（破折号补述 vs 冒号列举）。
  - → 按 §1182 统一（见该句建议）。
- **mudutara**：品名（§1187）译“较柔软”，正文（§1195）mudutarehi 译“更弱” → nissaya `နုသော` 意为“柔、嫩”，建议统一为“柔”系，品名“较柔品”，正文“更柔弱”；或两处都用“弱”。

## §1178 句 171-1178-41-65
- **问题**：词法 — `anuttaro purisadammasārathi` 写成“无上士调御丈夫”，不加断开，nissaya 把它作一个名号（无上的、调御应调伏之人者）。
- **建议**：改为“无上调御丈夫”，或按十号传统断为“无上士、调御丈夫”，全书取一种并与 §1189 一致。

## §1179 句 171-1179-11-31
- **问题**：用词一致 — āraddhavīriyo 译“精勤努力”，而同段 vīriyaṃ ārabhati 一律译“发起精进”。nissaya `အာရဒ္ဓဝီရိယော= အားထုတ်အပ်သော လုံ့လရှိသည်` 意为“具有已发起的精进”，两处同源。
- **建议**：“……而发起精进安住”或“……精进发起而住”，与下文“发起精进”呼应。

## §1180 句 171-1180-27-38、171-1180-39-64
- **问题**：风格（必改）— “于身随观身而住”“于受……于心……于诸法随观法而住”用文言介词“于”，属于 style.md 禁用的单音节文言虚词。
- **建议**：“他在身上随观身而住……”；“在受上……在心上……在诸法上随观法而住……”。

## §1181 句 171-1181-54-81
- **问题**：句法误读 — 译文把引语“具有舍与念、安住于乐”当作修饰第三禅的定语。按 nissaya：
  - `ယံ= အကြင် (တတိယဈာန်ဟူသော)အကြောင်းကြောင့်`：yaṃ 是“由于这第三禅”；
  - `တံ= ထို တတိယ ဈာန်ရပုဂ္ဂိုလ်ကို`：taṃ 指“得第三禅的那个人”；
  - `ဥပေက္ခကော… သတိမာ… သုခဝိဟာရီ` 三词都是描述那个人的（“能舍的人、有念的人、乐住的人”），是圣者们称赞此人的话，不是第三禅的属性。
  
  此外，upekkhako 与 satimā 被合并成“具有舍与念”，漏了一个独立的称谓。
- **建议**：“……以身体感受着乐；正因为这一禅，圣者们称他为‘有舍者、具念者、安住于乐者’——他进入并安住于这第三禅。”

## §1182 句 171-1182-11-26
- **问题**：轻微 — nibbedhikāya 译“能穿透烦恼”，nissaya 作 `လောဘ ဒေါသ မောဟအစုအခဲကို ဖောက်ခွဲနိုင်သော`（能破开贪、瞋、痴的团块），方向一致，可保留。
- **注**：本段 nissaya 的 ariyāya 作 `ပြတ်သော`，§1193 同句作 `မြတ်သော`（殊胜、圣），前者疑似 nissaya 抄误，以 §1193 为准，译文“圣的”不受影响。
- **建议**：§1193 照本句统一为“具备能洞察生灭的智慧——那是圣的智慧，能穿透烦恼，能正确导向苦的灭尽”。

## §1182 句 171-1182-27-68
- **问题**：词义偏窄 — 两处：
  - `ဒုက္ခသမုဒယော= ဆင်းရဲ၏ ဖြစ်ကြောင်း`：nissaya 释为“苦的生因”，并补出 ayaṃ 指“这贪爱”。译文“苦的生起”只表示过程，没有译出“起因”。
  - `ပဋိပဒါ= …အကျင့်`：paṭipadā 是“修行、行持”，译文“道路”偏离。
- **建议**：“这是苦的起因（或‘苦的集起’）”；“这是导向苦灭的修行之道”。全书四谛译法应一并确定后登记进 terms.md。

## §1185 句 171-1185-2-10
- **问题**：误译（必改）— dve sotā 译“两部《流》经”。nissaya 作 `ပဌမ သောတာပန္နသုတ်၊ ဒုတိယ သောတာပန္န သုတ်`，指第一、第二《须陀洹经》，sotā 是经名 Sotāpanna 的缩略，不是“流”。
- **建议**：“两部《须陀洹》经”。

## §1189 句 171-1189-45-69
- **问题**：漏译 — itipi 没有译出（nissaya 每个名号前都有 `ဣတိပိ`）；“无上的调御丈夫”与 §1178 不一致；句末“。’”与 §1178 的“’——”标点不同。
- **建议**：照 §1178 统一后的写法改（见跨段一致性）。

## §1195 句 171-1195-18-30
- **问题**：数 — imāni 是复数，nissaya 作 `ဣမာနိ… ဤသည်တို့ကား`（这些），译文“这就是五根”丢了复数，且与 §1182、§1193 的“这些就是……”不一致。
- **建议**：“比丘们，这些就是五根。”

## §1195 句 171-1195-31-70
- **问题**：格 — mudutarehi 是具格/因格，nissaya 作 `နုသော ဣန္ဒြေတို့ကြောင့်`（因为较柔弱的诸根）。tato 是比较的基准，nissaya 释为“比那（阿罗汉等）在观、道、果中所含的诸根”。译文第一句点明了“诸根”，后五句只说“再比那些更弱一些”，“以较弱的诸根而成为……”的因果关系不明显。
- **建议**：“……就成为阿罗汉；以比这更弱的诸根，就成为阿那含；以比那更弱的诸根，就成为斯陀含；……”，同时按跨段一致性一节确定“弱 / 柔弱”的用字。
