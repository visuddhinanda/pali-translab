# Review — 171:533-541（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供）／义注 ⚠️ **部分**——仅注入 book 137 §186-187（Taṇhakkhayasuttādivaṇṇanā），只覆盖第六经（§540-541）。第四经（§533-536）、第五经（§537-538）**无义注可对**，这两经的意见仅凭原文与术语表，判定强度较低。词级形态因缺 nissaya **未能独立核验**。

## 跨段一致性

- **saṃvattati**：§534/535 译作「会增长广大」（动词被吞）、§540 译作「导向」、§541 无。同一动词在同 chunk 内一处译出一处丢失 → 建议统一显化为「导向」（详见 §534 条）。
- **taṇhakkhaya**：§539 篇名「渴爱灭尽」、§540「渴爱灭尽／渴爱的灭尽」两种、§541「渴爱灭尽」。建议正文一律「渴爱的灭尽」，篇名保留「渴爱灭尽经」。
- **vepulla / vipula / mahaggata 三词撞车**：§534-535 的 `vepullāya` 译「广大」，§541 的 `vipulaṃ` 也译「广大」，而 `mahaggataṃ` 译「高远」。义注对后两词给出的是明确分工：`patthaṭattā **vipulo**`（因遍布故为 vipula）、`mahantabhāvaṃ gatattā **mahaggato**`（因达到「大」的状态故为 mahaggata）。**「高远」含有纵向高度义，义注里没有任何依据**。建议：`vipulaṃ`→「广大」（遍布），`mahaggataṃ`→「宏大」（达大），`vepullāya`→「广大」可留（与 vipula 同根，同译反而对）。**必改项，见 §541。**
- **从格因果句式**：§541 段内用「由于渴爱被舍断，业就被舍断了」，收尾 §541-95-108 却改成「渴爱灭尽就有业的灭尽」。同一因果链两种句式，建议统一为「由于…」。
- **pahīyati「舍断」/ khaya「灭尽」** 全 chunk 一致 ✅；五盖、七觉支诸名全 chunk 一致 ✅。
- 文言腔扫描：**未发现**文言虚词或文言句式，语体合格 ✅。全角标点与引号合格，`zh` 字段内无 ASCII 引号 ✅。译文内无工作标记 ✅。

## §534 句 171-534-2-24（及 25-37 / 38-48 / 49-58 / 59-70 同型五句）

- **问题**：准确性（漏译动词） — `bhiyyobhāvāya vepullāya saṃvattati` 是「导向增多、导向广大」，`saṃvattati`（导向、转起）被压缩掉，译成了「会增长广大」，读起来像贪欲自己在增长，而原文说的是「不如理作意」这件事**导向**贪欲的增多。同一动词在 §540 已译作「导向」，此处丢失属不一致。
- **建议**：改为「已生起的贪欲会导向增多与广大」；余下嗔恨、昏沉睡眠、掉举恶作、疑四句同样处理。

## §534 句 171-534-2-24

- **问题**：句法 — `manasikaroto` 是属格独立结构（「对作意者而言」），译作「一个人不如理地作意」把它变成了并列小句，与后半「未生起的贪欲就会生起」之间的条件关系变弱。缺 nissaya，无法用格助词独立复核，仅据形态判断。
- **建议**：可改为「比丘们，对不如理作意的人来说，未生起的贪欲会生起…」；若保留现译，至少把「一个人」改为「谁不如理地作意」以显条件义。§535「而一个人如理地作意」同此。

## §536 句 171-536-2-30

- **问题**：准确性（动词被吞） — `bhāvanāpāripūriṃ gacchati` 是「走向／达到修习的圆满」，译作「会修习圆满」丢了 `gacchati`，而且「修习圆满」的主语读起来成了觉支自己在「修习」。
- **建议**：「已生起的念觉支会达到修习的圆满」。

## §540 句 171-540-2-23

- **问题**：冗余 — 原文 `Yo maggo yā paṭipadā taṇhakkhayāya saṃvattati` 只有一个 `saṃvattati` 统辖「道」与「行道」两个主语，译文把「导向渴爱灭尽」重复了两遍。
- **建议**：「比丘们，凡是导向渴爱灭尽的道与行道，你们就要修习那条道、那种行道。」

## §540 句 171-540-53-59

- **问题**：背景缺失 — **义注**：`**etadavocā**ti ‘‘imissaṃ parisati nisinno udāyitthero nāma anusandhikusalo bhikkhu atthi, so maṃ pucchissatī’’ti bhagavatā osāpitadesanaṃ ñatvā desanānusandhiṃ ghaṭessāmīti pucchanto etaṃ avoca`——义注说明优陀夷是「善于接续（anusandhi）」的比丘，看到世尊把说法收束了，为了接上法义的脉络才发问。译文本身不误，但「这样说了以后」主语悬空，读者不知是谁说完了。
- **建议**：`Evaṃ vutte` 是处格独立结构，指世尊说完。改为「世尊这样说了之后，尊者优陀夷对世尊说——」。义注给的问答背景宜作脚注，不进正文。

## §540 句 171-540-60-79

- **问题**：语域 — `bahulīkatā` 译作「多多练习」，「练习」在修行语境里偏俗，且与前半「修习」（bhāveti）不成对。
- **建议**：「七觉支要怎样修习、怎样多加修习」，或沿传统作「怎样修习、怎样多所修习」。

## §541 句 171-541-2-31（及 32-45 / 51-69 / 70-89 四句同型）

- **问题（必改）**：术语违背义注 — `mahaggataṃ` 译作「高远」。**义注**：`So hi patthaṭattā **vipulo**, mahantabhāvaṃ gatattā **mahaggato**, vaḍḍhipamāṇattā **appamāṇo**, nīvaraṇānaṃ dūrībhāvena byāpādarahitattā **abyāpajjho** nāma hoti.`——义注把 `mahaggata` 明确释为「达到『大』的状态」，是体量义，不含「高」。「高远」无义注依据，且与 `vipulaṃ`「广大」的分工被抹平（义注给 vipula 的是 `patthaṭatta` 遍布义）。
- **建议**：`vipulaṃ`→「广大」，`mahaggataṃ`→「宏大」；四句一并改。

- **问题**：`abyāpajjaṃ` 译作「没有嗔恨」，**义注**：`byāpādarahitattā`——取义正确 ✅，与本文 `byāpādo`「嗔恨」同源对应也成立。但作为修饰觉支的定语，「没有嗔恨」读来偏口语，且与「广大、宏大、无量」的四字并列不齐。
- **建议**：改为「无嗔」或「无嗔恚」（保留与「嗔恨」的词根呼应）。非必改，但四项并列宜统一为术语式。

- **说明（不必改）**：`abyāpajjhaṃ (sī. syā. pī.)` 是版本异读，译文未译，处理正确 ✅。

## §541 句 171-541-46-50 / 51-69 / 90-94

- **问题**：义注补出的限定未在译文体现 — **义注**：`**Taṇhāya** **pahānā** **kammaṃ** **pahīyatī**ti yaṃ taṇhāmūlakaṃ kammaṃ uppajjeyya, taṃ taṇhāpahānena pahīyati`（被舍断的是**以渴爱为根本的**业）；`**Kammassa** **pahānā** **dukkhan**ti yampi kammamūlakaṃ **vaṭṭadukkhaṃ** uppajjeyya`（被舍断的是**以业为根本的轮回苦**）。译文「业就被舍断了」「苦就被舍断了」字面无误，但读者容易读成一切业、一切苦。
- **建议**：正文不改（保持与原文对等），把义注这两处限定作脚注补出：「义注：指以渴爱为根本的业」「义注：指以业为根本的轮回苦（vaṭṭadukkha）」。

## §541 句 171-541-95-108

- **问题**：句式不一致 + 从格因果弱化 — `taṇhakkhayā kammakkhayo, kammakkhayā dukkhakkhayo` 是从格因果，译作「渴爱灭尽就有业的灭尽」，与同段前文「由于渴爱被舍断，业就被舍断了」两种句式并存。
- **建议**：「优陀夷，就是这样：由于渴爱的灭尽而有业的灭尽，由于业的灭尽而有苦的灭尽。」
- **补充（脚注）**：**义注**：`Taṇhakkhayādayo taṇhādīnaṃyeva khayā, atthato panetehi nibbānaṃ kathitanti veditabbaṃ`——义注指出「渴爱灭尽」等在义理上说的就是涅槃，宜作脚注。

## 存疑与待核

- **缺 nissaya**：`manasikaroto`（§534/535 属格独立）、`vossaggapariṇāmiṃ`（§541 译「趋向于舍弃」）、`bhāvayato`（§541 属格独立，译「当他修习…时」）三处的格与句法角色**未经词级基准复核**，上述判断仅据形态推定。§541-32-45 的超长定语（四个「依于」＋四项形容）在汉语里已到可读性边缘，若 nissaya 显示 `bhāvayato` 与后续成分另有切分，句子结构应重议。
- **第四、第五经（§533-538）无义注**：`aparihāniya`「不退失」、`kāmacchanda`「贪欲」等取义未与义注对照，暂依传统译法，待义注到位后复核。
- 术语表 `knowledge/term-glossary.jsonl` 未登记 `taṇhā`（渴爱）、`bojjhaṅga`（觉支）、`mahaggata`、`abyāpajja`、`aparihāniya`。本 chunk 定案后建议补入，尤其 `mahaggata` 一条须记明义注依据。
