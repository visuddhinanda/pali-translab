## 理由

**资源缺口（直接压低信心）**：本次只注入了义注层自身的巴利原文与译文，**没有 nissaya**（无法做词级格/句法核对与覆盖核对），也**没有注入所解释的本文（Bījasutta / Nāgasutta 经文）**。因此两项硬标准无法执行：一是「与 nissaya 吻合」一项只能靠原文语法自行判断；二是**黑体被解释词与父层逐字同译**无法验证——`**种子类和植物类**`、`**获得力量**`、`**下到小水洼**`、`**同样地**` 这四处引自本文的词，是否与本文译文用字完全一致，本报告不能背书，需在 harmonize 阶段另行对齐后再确认。评分中这部分按「未核」处理，不计扣分，但信心相应下调。

**准确性**：主谓宾判断整体正确，无教理性错误，故无 fatal。核心譬喻的方向判对了——`himavantapabbato viya catupārisuddhisīlaṃ daṭṭhabbaṃ` 一组四项（戒=雪山、瑜伽者=小龙、圣道=小水洼等、涅槃=大海）对应关系与格位都没有译反，这是本段最容易出错的地方。扣分主要来自一处指代错误（137-97-62-71 的「它们」把「达到巨大」的主语滑向母龙，与 137-98-23-48 的 `nāgapotakā … kāyamahantattaṃ āpajjanti` 冲突），以及 `sambhajjamukhadvāraṃ` 中 `sambhajja-` 的语义未落实。后者原文读法本身存疑（或为「冲破/破开河口」，或为专名），无 nissaya 佐证，只按 warning 立条、不按漏译重罚。

**风格**：现代书面汉语的硬约束守得不错，通篇未见「此中/故为/彼等/是故/于…之际/答以」一类文言腔，也没有单音节文言虚词充当连词；「就想：」「据说」「于是」都是现代说法。标点全角，引号统一用 “”，译文内无 ASCII 引号，符合 JSON 安全要求。译文中也没有残留任何候选、待定、问号之类的工作标记。扣分项是两处：137-97-2-61 一句约 180 字、五重连动不断句，对读者不友好；「达到巨大」这一搭配三次出现，汉语上偏生硬（其中 137-97-62-71 因是本文用语 `mahantattaṃ vepullattaṃ` 的对译，可以保留，但 137-98-23-48 的「使功德身达到巨大」多出了致使义，`pāpuṇanti` 是自身获得，不是「使…达到」）。

**一致性**：跨句术语稳定——`kusobbha` 全段作「小水洼」，`nāgapotaka` 全段作「小龙」，`supaṇṇa` 与 `garuḷa` 两个同义词统一译「金翅鸟」（合理，不视为问题）。唯一不齐的是 137-96-2-16 内部：同一个词根，被解释词作「获得力量」、释语作「取得力量」，义注「以 `gaṇhanti` 释 `gāhenti`（使役形按一般现在读）」的用意在汉语里落空，读起来像同义反复。术语夹注策略执行不完整：`catupārisuddhisīla`、`yogāvacara` 附了巴利原词，同属法相术语的 `bījagāma / bhūtagāma` 没有附。

## 问题清单

### 🟧 error
- `137-97-62-71`｜代词指代错误｜片段「它们住在那里」
  - 问题：上一句（137-97-2-61）把 `ñatvā … pāpuṇanti` 的主语补成「母龙们」，本句「它们」按汉语只能回指母龙。但据 137-98-23-48 `nāgapotakā himavante patiṭṭhāya … kāyamahantattaṃ āpajjanti`，住在大海、身量增至十万寻、「达到巨大、广大」的是小龙，不是母龙。譬喻的对应项（小龙=瑜伽行者）也要求主语是小龙，指代错位会连带破坏下文譬喻的可读性。
  - 建议：明写主语，作「小龙们住在那里」。

### 🟨 warning
- `137-96-2-16`｜整句逻辑表达不规范｜片段「**获得力量**，就是取得力量」
  - 问题：义注是用 `gaṇhanti` 解释本文的使役形 `gāhenti`（说明此处不取使役义），译成「获得力量，就是取得力量」在汉语里是循环解释，读者看不出这条注在注什么，「获得／取得」还造成同词异译。
  - 建议：统一用字并把注释意图显出来，如「**获得力量**，就是（它们自己）取得力量；也就是已经取得力量、身体变得强健」。
- `137-96-29-61`｜关键词语意不明确｜片段「到达河口」
  - 问题：原文为 `sambhajjamukhadvāraṃ patvā`，译文只落实了 `mukhadvāra`（河口），`sambhajja-`（破开／冲开，或为专名）无对应。无 nissaya 可判，但现译等于把一个成分静默吞掉。
  - 建议：按「冲开河口」处理，或确认为专名后音译；两种都在报告/脚注里注明原文读法存疑。
- `137-98-23-48`｜不导致误解的汉语语病｜片段「使功德身达到巨大」
  - 问题：`pāpuṇanti` 是主语自身获得，译文的「使」引入了多余的致使义；「达到巨大」以形容词作宾语，搭配不稳。
  - 建议：改为「功德身变得广大」或「获得功德身的广大」。

### 🟦 suggestion
- `137-94-2-20`｜该使用而没有使用术语标记｜片段「五种种子都叫做种子类」
  - 问题：`bījagāma` / `bhūtagāma` 是律藏法相术语，与同段落其他术语（已夹注巴利原词的 `catupārisuddhisīla`、`yogāvacara`）处理不一致。
  - 建议：首次出现时夹注，作「种子类（bījagāma）」「植物类（bhūtagāma）」。
- `137-96-17-28`｜语言表达不够流畅｜片段「关于这些有下面这样按次序的说法」
  - 问题：`ayamanupubbikathā` 译得迂回，三个虚词叠在一起。
  - 建议：「等等，下面按次序说明」或「等等，这是其中的次第说明」。
- `137-96-17-28`｜代词指代可能不够明确｜片段「在交配期怀了胎」
  - 问题：`utusamaye` 本义是「到时节时」，译作「交配期」是一层解释性收窄；无 nissaya 佐证。
  - 建议：可作「在时节到来时怀了胎」，把解释留给脚注。
- `137-97-2-61`｜复杂的嵌套句整句语言逻辑理解困难｜片段「就用自己的威力兴起大云，让天降雨，使整个雪山几乎成为一片水，又造出金、银等做成的船」
  - 问题：整句约 180 字、七八个连动，中途不断句，读者难以跟上主语与动作层次。
  - 建议：在「几乎成为一片水」后断句，另起「然后造出金、银等做成的船……」。
- `137-97-62-71`｜不常用术语编写注释或者百科｜片段「身量渐渐达到十寻、百寻、千寻、十万寻」
  - 问题：「寻」（byāma）是一般读者不熟悉的长度单位。
  - 建议：首次出现加简注（张开双臂的长度，约合一人身高）。
- `137-98-2-22`｜语言风格不统一｜片段「把瑜伽行者（yogāvacara）看作小龙」
  - 问题：「瑜伽行者」易与大乘瑜伽行派混读；南传汉译通行作「瑜伽者」。同句「四种遍净戒」亦可统一为通行的「四遍净戒」。
  - 建议：改「瑜伽者（yogāvacara）」，并与 137-98-23-48 的「瑜伽行者」一并统一。
