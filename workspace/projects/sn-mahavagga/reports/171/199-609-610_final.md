## 理由

**基准缺失（降级说明）**：本次只注入了巴利原文与 channel 现有译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。本段是复注（ṭīkā），其黑体词 `kaṇḍakī` / `Sahassalokaṃ` / `Dasacakkavāḷasahassaṃ ekāvajjanassa āpāthaṃ āgacchati` 是从义注引来的被解释词，按硬约束须与父层逐字同译——**这一项本次无法核验**。词级的格与句法角色也只能凭原文形态判断，不能靠 nissaya 确认。因此信心指数压到 55，下面的准确性扣分只针对原文形态与内部逻辑能独立判定的部分。

**准确性**：两处实质问题。一是 `199-610-6-12` 把 `kaṇḍakī` 译成「棘」，丢掉了 `-ī` 所属后缀——这一句正是在讲派生（有刺 → 有刺者），译成「棘」后「因为有刺所以叫做棘」变成同义反复，讲解目的落空。二是 `199-610-31-38` 补出施事「长老」，原文 `tathā ālokavaḍḍhanassa katattā` 是无施事的属格 + `katattā`，补主语属擅自补足（`style.md` 第六节明列禁止）；缺义注无法确认该段施事是谁，若不是长老则此条应升为 fatal。此外 `199-609-4-4` 把 `Kaṇḍakīsutta` 译作「棘林经」，「林」在经名里无对应词（`vana` 出现在下一段的 `kaṇḍakīvana`），属增译。`199-610-31-38` 中 `ekāvajjanassa āpāthaṃ` 的属格关系被改写成条件句并另补「所见」，方向不错但偏离原结构。

**风格**：现代书面汉语落实得好，通检无文言虚词、无文言句式、无单音节文言词，**文言语体一项零扣分**。标点为全角，引号用弯引号 “”，未出现 ASCII 双/单引号，符合 JSON 安全约束。译文中无任何候选/待定/问号等工作标记。夹注格式「药草（osadhi）」合规。扣分主要在 `paññāyittha`（著称、为人所知）被弱化为「被称为」，`teva` 的强调未体现，以及个别句子表述可再紧一点。

**一致性**：`kaṇḻakī`→棘、`kaṇḍakīvana`→棘林 内部自洽；但同为段号的 `199-609-2-3`「四至七、」与 `199-610-2-5`「902-905.」处理方式不一（一处汉字化+顿号，一处保留西文数字+半角句点）。术语「轮围界」两句一致，惟首次出现未夹注巴利原词。黑体范围处理正确：原文四个加粗词 `Dasacakkavāḷasahassaṃ ekāvajjanassa āpāthaṃ āgacchati` 位置连续，属同一段引文，译文整体加粗无误。

## 问题清单

### 🟧 error
- `199-610-6-12`｜错译（词义）｜片段「所以叫做**棘**（kaṇḍakī）」
  - 问题：`kaṇḍakī` 是带所属后缀 `-ī` 的派生词「有刺者」，「刺」是 `kaṇḍaka`。译成「棘」后整句成了「因为有刺，所以叫做棘」的同义反复，`Kaṇḍakā etissā atthīti` 这一派生解释完全落空。
  - 建议：改为「所以称为有刺者（kaṇḍakī）」一类译法，并与下段「棘林」的处理协调（棘林即多刺灌木之林）。定稿前须与义注该词的译法对齐。
- `199-610-31-38`｜错误多译（擅自补出施事）｜片段「这是因为长老已经把光明扩展到了那样的程度」
  - 问题：原文 `tathā ālokavaḍḍhanassa katattā` 只说「因为如此作了光明的增长」，无施事；「长老」为译者所补，违反 `style.md` 第六节「不擅自补足省略主语」。因缺义注，无法确认该段施事确为长老——若不是，本条应升为 🟥 fatal（主语判断错误）。
  - 建议：改为不带施事的说法「因为已经把光明扩展到了那样的程度」；确需点出施事，须先在义注中找到依据。

### 🟨 warning
- `199-609-4-4`｜关键词语意不明确（经名增译）｜片段「第一棘林经等的注释」
  - 问题：`Kaṇḍakīsutta` 中没有 `vana`（林），「林」是补出的；经名与下段的地名 `kaṇḍakīvana` 被混为一体。
  - 建议：按父层经名译法统一，如「第一 Kaṇḍakī 经等的注释」，或在确有依据时注明「经以棘林得名」。
- `199-610-6-12`｜关键词语意不明确，未加注释｜片段「迦兰陀灌木丛」
  - 问题：`karamanda`（刺黄果，Carissa carandas）音译作「迦兰陀」，极易与 Kalandaka（迦兰陀迦，竹林精舍得名者）混淆；且属罕见植物名，首次出现未附巴利原词或简注，违反 `style.md` 第二节。
  - 建议：改为「karamanda 灌木丛」并附简注（一种多刺小灌木），或「迦兰陀（karamanda）灌木丛」并注明与迦兰陀迦无关。
- `199-610-13-26`｜关键词语意不明确｜片段「所以用了阴性的词形」
  - 问题：未点明是哪个词取阴性，读者不知道说的是 `kaṇḍakī`。
  - 建议：补足所指，如「所以 kaṇḍakī 一词用了阴性词形」。
