## 理由

**基准缺失（影响信心）**：本次注入的资源只有巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此释义标准与词级基准都无法逐句核对，准确性评分只能依据巴利词形、格变与本经内部的自释结构（1649–1655 各段是对 1648 的逐项定义）作出。凡涉及注释书传统取义的判断（尤其 `ākāra / liṅga / nimitta` 三词的分工、`upadhāraṇa` 的具体所指）都属于**待义注复核**项，信心因此压到 66。

**准确性**：本段主体结构译得完整可靠——四神足的四支（chanda / vīriya / citta / vīmaṃsā）、四种偏失（atilīna / atippaggahita / ajjhattaṃ saṃkhitta / bahiddhā vikkhitta）与其定义段（1649–1652）严格对应，术语在定义段与被定义段之间用词一致，读者能自行串起来。1654 的三十一身分列举**逐项无漏、无增**，顺序与原文完全吻合，这是本段最扎实的一处。主要扣分集中在 1655：`ākāra / liṅga / nimitta` 译作「部分 / 形状 / 现起之相」，前两项偏离词义（`ākāra` 是行相、样态，不是身体或修法的「部分」；`liṅga` 是特徵、标记，不是「形状」），这是可判定的词义错误。另一处是 1653 的 `sūpadhāritā`（善忆持）译作「好好确立」，把「持于心中」滑成了「建立起来」。

**风格**：**未发现文言或半文半白**——全段是干净的现代书面汉语，「凡是伴随懈怠、与懈怠相应的意欲」「里面装满各种不干净的东西」这类处理都合 `style.md` 的要求，无禁例表中的任何一项。标点全用全角，译文内无 ASCII 引号、无候选/待定等工作标记，JSON 安全。扣分主要在两点：一是夹注策略不均衡——按 `style.md` 第二节「法相术语首次出现夹注巴利原词」，`iddhipāda`（神足）、`vīmaṃsā`（审察）、`uddhacca`（掉举）、`thinamiddha`（昏沉睡眠）这些真正需要夹注的都没给，反而给了最容易懂的「五种欲境（pañca kāmaguṇā）」；二是 1653 一句之内连用被动加副词（「已被好好把握、好好作意、好好确立」），读起来偏翻译腔。

**一致性**：偈式重复句（`yathā pure tathā pacchā` 四组）在 1648 两次出现与 1653–1655 的回指段中**完全逐字一致**，复合词 `chandasamādhippadhānasaṅkhārasamannāgataṃ` 在 1648、1655 共四次出现也统一译作「具足意欲定和努力之行的神足」，这是跨段统稿到位的表现。唯一裂缝是「四种神足」（1647）与「四神足」（1648）同一对象两种写法。

## 问题清单

### 🟧 error
- `171-1655-22-49`｜错译（词义）｜片段「哪些部分、哪些形状、哪些现起之相」
  - 问题：`ākārehi liṅgehi nimittehi` 三词指昼夜修习时所凭的**行相、特徵、徵相**。译作「部分」把 `ākāra`（样态、行相）误解为身体或修法的组成部分；「形状」把 `liṅga`（特徵、标记）误解为外形。后半句「同样的部分、同样的形状」同误。
  - 建议：改为「哪些行相、哪些特徵、哪些徵相」，回指处作「同样的行相、同样的特徵、同样的徵相」；`171-1655-50-74` 一并同步。三词分工待义注复核后定稿。

- `171-1653-23-36`｜错译（词义）｜片段「好好确立」
  - 问题：`sūpadhāritā`（su- + upadhāreti）意为**善加忆持、牢记于心**，与前面 `suggahitā`（善取）、`sumanasikatā`（善作意）构成「取—作意—忆持—以慧通达」的递进。译作「好好确立」滑向「建立起来」，递进链断了。
  - 建议：改为「好好忆持」或「好好记住」。

### 🟨 warning
- `171-1654-37-74`｜关键词语意不明确｜片段「骨髓、肾、心、肝」
  - 问题：`hadaya` 是器官「心脏」。本经通篇在讲 `cittasamādhi`（心定）、`sappabhāsaṃ cittaṃ`（有光明的心），单用「心」会与心识义的「心」混读。
  - 建议：改为「心脏」。

- `171-1648-2-17`｜语言风格不统一｜片段「四神足」
  - 问题：与 `171-1647-2-20` 的「这四种神足」指同一对象却两种写法，且 1647 是本段首次出现。
  - 建议：统一为「四神足」或「四种神足」，建议随后文取「四神足」，并在 1647 首次出现处补夹注。

- `171-1650-12-27`｜关键词语意不明确｜片段「过于振奋」
  - 问题：`atippaggahita` 的本义是「过度提举、用力过猛」，本段自释为与掉举（uddhacca）相应，是需要纠正的偏失。汉语「振奋」是褒义词，读者容易读成好事，与「过于松弛」的贬义不对称。
  - 建议：改为「过于紧张」或「用力过度」，并与 1648 两处「不会过于振奋」一并统一。

  - 问题：一句内三个被动加同一副词「好好」，翻译腔明显，且施事（比丘自己）被隐掉。
  - 建议：改为主动式，如「比丘对前后想善加把握、善加作意、善加忆持，并以智慧通达」。

- `171-1654-20-36`｜该使用而没有使用术语标记｜片段「里面装满各种不干净的东西」
  - 问题：`asuci`（不净）在身念处语境里是固定法相，「不干净的东西」偏口语，削弱了观身不净的定位。
  - 建议：改为「充满种种不净之物」，视需要夹注（asuci）。

- `171-1647-2-20`｜语言表达不够流畅｜片段「经过多次实践」
  - 问题：`bahulīkata` 指「多所修习、反复修习」，落在修行行为上；「实践」是现代通用词，与「修习」并列时语域不齐。
  - 建议：改为「反复修习」，与前面「经过修习」合为「经过修习、反复修习」。

- `171-1648-100-111`｜整句逻辑表达不规范｜片段「精进定……（中略）……心定」
  - 问题：原文 `Vīriyasamādhi … pe …` 是省略式，缩略后「精进定……心定……他修习……」在汉语里主谓悬空，读者不易看出这两项与后面「具足……的神足」同构。
  - 建议：补成「（精进定……中略……心定，同前）」一类括注，或在两项后各带「……（余同上）」提示同构。

- `171-1648-92-99`｜语言表达不够流畅｜片段「以敞开、不被覆盖的心意」
  - 问题：`vivaṭena cetasā apariyonaddhena` 的传统取义是「心无遮蔽、不为（盖障）所缠覆」，「敞开」偏日常义，「不被覆盖」被动生硬。另本句以「心意」译 `cetas`、下半句以「心」译 `citta`，同句两词易被读成两物。
  - 建议：改为「以无遮蔽、不为缠覆的心」，并统一 `cetas` / `citta` 的译法（待义注复核后定）。
