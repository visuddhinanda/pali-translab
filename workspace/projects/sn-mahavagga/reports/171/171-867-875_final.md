## 理由

**取数缺口（先交代）**：本次注入的资源只有巴利原文与 channel 现有译文，**没有义注（aṭṭhakathā）、没有 nissaya**。本段是《相应部》觉支相应末尾的品名、摄颂与结语，属于目录/摄颂性质的文本，多数本就无义注与 nissaya 覆盖。因此准确性判断只能依据巴利词形、相应部体例惯例与《觉支相应》既有译名，词级（格、句法角色）核对无外部基准，信心指数据此下调至 72。

**准确性**：结构句（品名、卷末结语、`Uddānaṃ`）译法与相应部体例相符，序号（`aṭṭhārasamo`→第十八、`dutiyaṃ`→第二）无误，`vitthāretabbo/vitthāretabbaṃ` 的「应当详细展开」取义正确，被动未来分词的义务语气译出。主要问题集中在摄颂两句的术语选择：`nīvaraṇā` 译「盖」在现代汉语读者面前几乎不可解（该词即五盖/五障，通行作「障」或「盖（障）」），属关键词语意不明确；`oruddhambhāgiyāni` 译文拆成「顺下分结和顺上分结」，原文是一个复合词，此处把 `orambhāgiya`（顺下分）与 `uddhambhāgiya`（顺上分）合璧的省缩形式展开为两项是合理的，但未加任何提示，读者无从知道原文只有一词——建议在报告的问题清单里留档，正文不必改。`Punaogha` 译「再说暴流」可通（`puna` + `ogha`，与前面第十七品重出故称「再」），但品名与经名两处译法一致，无内部矛盾。

**风格**：通篇现代书面汉语，未见文言虚词与文言句式，标点为全角，无 ASCII 引号，无残留工作标记，符合 `style.md` 硬约束。夹注格式统一用全角圆括号附巴利原词，与配置一致。扣分处在夹注策略不统一：摄颂内 `yoga / gantha / anusaya / kāmaguṇa / nīvaraṇa / khandha` 都加了夹注，而同列的 `ogha`（暴流）、`upādāna`（取）未加；`khandha`（蕴）属常见术语，按 `style.md`「常见术语用传统汉译」本不需夹注，而 `ogha` 反倒更需要。摄颂是一行罗列十项法门的助记偈，六个夹注挤在一句里已影响可读性。

**一致性**：`ogha` 在 867（品名「再说暴流品」）、869（经名《再说暴流等经》）、872（摄颂「暴流」）三处译名一致。`bojjhaṅgasaṃyutta` 在 870 与 875 两处均作「觉支相应」，一致；但 870 的 `Bojjhaṅgasaṃyutassa` 是属格，译「觉支相应的再说暴流品」正确，875 的 `Bojjhaṅgasaṃyuttaṃ dutiyaṃ` 为卷末结语，译「觉支相应，第二」符合体例。868 的 `357-366` 译作「357～366」，把 ASCII 连字符改成全角波浪号，与全角标点要求一致。主要不一致是上述夹注取舍标准不统一，以及 873 句内「以及」与 872 句末分号的衔接——摄颂两句原为一偈两行，872 以分号收尾、873 以句号收尾，读来像两句独立句，偈颂的分行结构在译文里丢失了（`style.md` 要求偈颂保留分行）。

## 问题清单

### 🟨 warning

- `171-873-2-7`｜关键词语意不明确，或二意场合没有注释｜片段「盖（nīvaraṇa）」
  - 问题：`nīvaraṇa`（= nīvaraṇa/nīvāraṇa，即通称五盖、五障）单用「盖」字，现代汉语读者无法理解其义，夹注巴利原词也不解决可读性；相应部同类语境通行作「障」或「盖（障）」。
  - 建议：改用「障（nīvaraṇa）」，或保留「盖」但加一字成「五盖」类可解形式，待 `terms.md` 定案后统一。

- `171-873-2-7`｜整句逻辑表达不规范｜片段「以及顺下分结和顺上分结。」
  - 问题：原文 `oruddhambhāgiyāni` 是 `orambhāgiya` 与 `uddhambhāgiya` 合璧的一个省缩复合词，译文展开为两项（取义正确），但读者与后续校者无从知道原文只有一词；且句中已有「、」列举，又叠用「以及…和…」，层级混乱。
  - 建议：理顺为「以及顺下分结、顺上分结」，并在 `known-issues.md` 记一条该复合词的省缩体例，避免下轮被误判为多译。

- `171-872-2-9`、`171-873-2-7`｜偈颂处理｜片段「还有结缚（gantha）和随眠（anusaya）；」
  - 问题：摄颂（`Uddānaṃ`）原为一偈两行，`style.md` 第五节要求偈颂保留分行；现两句分属两条坐标各自成句，872 以分号收、873 以句号收，译文读来是散文列举而非摄颂，偈颂体例丢失。
  - 建议：本条属坐标切分带来的固有限制，正文不改；导出 markdown 时（`/export`）按偈颂分行排版即可。

### 🟦 suggestion

- `171-872-2-9`｜术语标记使用不统一｜片段「暴流、轭（yoga）、取，」
  - 问题：同一句罗列的十项法门中，`yoga / gantha / anusaya` 加了巴利夹注，而同样非通行的 `ogha`（暴流）、`upādāna`（取）未加；取舍标准不一致。
  - 建议：统一为「只夹注罕见或易歧义者」一条标准；若保留 `yoga` 的夹注，`ogha`、`upādāna` 宜同样处理。

- `171-873-2-7`｜不该使用术语标记时使用了术语标记｜片段「蕴（khandha）」
  - 问题：「蕴」是 `style.md` 第二节所列常见传统汉译一类，按「常见术语用传统汉译，其后只用汉译」不必夹注；此处夹注与同句另外两个夹注叠加，一句内六处括号，可读性下降。
  - 建议：删去 `（khandha）`，摄颂句内夹注总量压到两三处以内。

- `171-867-2-4`、`171-869-2-2`｜语言表达不够流畅｜片段「十八、再说暴流品」
  - 问题：`Punaogha` 的「再说」是为区别于前一「暴流品」重出而加，读者看到品名「再说暴流品」会以为品中有「再说」的内容；译名达意但不够自然。
  - 建议：可考虑「暴流品（重）」或「再论暴流品」，属译名偏好，待与相应部前后品名一并定案后统一，不必单独改本段。
