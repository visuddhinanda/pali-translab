## 理由

**基准可用性**：本次评估**既无义注（aṭṭhakathā）也无 nissaya** 注入，只有巴利原文与现有译文。按方法文档降级处理——准确性只能凭巴利词法句法与《相应部》《增支部》标准套语判断，不能核对传统取义。这是信心指数压到 70 的主要原因；`uddhaccaṃ`、`oruddhambhāgiyā` 等处若义注另有取义，结论可能变动。

**准确性**：套语骨架（`Pañcimāni…Katamāni pañca?…imāni kho…abhiññāya pariññāya parikkhayāya pahānāya…cattāro iddhipādā bhāvetabbā`）翻译准确完整，四神足的 `chanda/vīriya/citta/vīmaṃsā` 四项与 `padhānasaṅkhārasamannāgata` 的处理都对。扣分集中在两处：`uddhaccaṃ` 译作"掉举"——此字标准形为 `uddhacca`（= `uddhata` 的抽象名词），巴利三藏五上分结的定型表述是 `rūparāgo arūparāgo māno uddhaccaṃ avijjā`，"掉举"是 `uddhacca` 的通行汉译，判定为正确；但 `uddhambhāgiya` 译"上分结"与摄颂里 `oruddhambhāgiya` 的"下分与上分"未统一到同一术语形态。更实质的是 `parikkhayāya` 译"灭尽"、`pahānāya` 译"舍断"——四项并列的汉译序列"证知、遍知、灭尽、舍断"可接受，但 `pariññā` 与 `abhiññā` 的区分（证知/遍知）在没有义注支持下属于沿用传统译法，标为分歧而非扣分。

**摄颂（1759-1760）**：这是本段最薄弱处。`yoga` 译"轭"、`gantha` 译"系"、`nīvaraṇa` 译"盖"，都是单字直译，脱离了各自相应品的标准汉译（`yoga` → 轭/结缚，`gantha` → 系缚/缚，`nīvaraṇa` → 盖/障；`nīvaraṇa` 与 `nīvaraṇā` 在此实指五盖/五障，与常见的 `nīvaraṇa`=盖 一致）。摄颂本是各品品名的缩略回指，译名应与前文各品品名逐字一致；此处无法核对前文各品译名，故按 suggestion 而非 error 处理。`Kāmaguṇā` 译"妙欲"是传统译法（五妙欲），正确。

**风格**：整体现代书面汉语，无文言腔，标点全角，无 ASCII 引号，无残留工作标记。夹注巴利原词的做法（慢（māna）、欲定（chandasamādhi）、观定（vīmaṃsāsamādhi））符合 `style.md`，但**夹注标准不一致**：同一句里 `māna` 夹注了而 `uddhacca`、`avijjā`、`rūparāga` 没有；四神足四项里只夹注了第一项和第四项，中间两项（精进定、心定）没有。这不是错误，但一致性维度据此扣分。

**一致性**：`vīriyasamādhi` 译"精进定"而 `chandasamādhi` 译"欲定"——`vīriya` 与 `chanda` 都是四神足名，两者一个用双音节意译一个用单字，可接受；但 1755-56-78 里"具备欲定与勤行的神足"与"具备观定与勤行的神足"结构对称，中间省略号段落只写"精进定……心定……"而没有补出结构，是忠实于原文 `pe` 的省略，处理得当。

**标题与结语**：`Oghavaggo aṭṭhamo` → "洪流品第八"、`Iddhipādasaṃyuttaṃ sattamaṃ` → "神足相应第七"，形制正确。`Tassuddānaṃ` → "它的摄颂是——"，"它的"指代略松（指代的是"洪流品"还是"神足相应"），按 warning 立一条。

## 问题清单
按级别从高到低排列。

### 🟨 warning
- `171-1758-2-3`｜代词指代不明确｜片段「它的摄颂是」
  - 问题：`Tassa` 的指代对象在译文里不明。摄颂 1759-1760 列的是整个神足相应各品品名（洪流、轭、取…），所指是"神足相应"而非紧邻上文的"洪流品"；译作"它的"会让读者按就近原则误指洪流品。
  - 建议：补出所指，如"神足相应的摄颂是——"；或依 `terms.md` 定案后统一此类 `tassuddānaṃ` 的译法。

- `171-1755-19-36`｜不该使用/该使用术语标记不一致｜片段「慢（māna）」
  - 问题：同一并列序列里只有 `māna` 夹注巴利原词，`rūparāga`、`uddhacca`、`avijjā` 都没夹注。按 `style.md`，法相术语首次出现夹注，判断标准应一致；此处取舍无据，读者会以为"慢"比"掉举""无明"更需要标注。
  - 建议：要么该序列五项首次出现全部夹注，要么只对最易误解的项夹注并在 `terms.md` 记下取舍标准。

- `171-1755-56-78`｜不该使用/该使用术语标记不一致｜片段「修习精进定……乃至……心定……乃至……」
  - 问题：四神足四项中，第一项"欲定（chandasamādhi）"与第四项"观定（vīmaṃsāsamādhi）"夹注了原词，中间"精进定""心定"没有。四项是同级并列术语，夹注应齐。
  - 建议：四项统一夹注，或四项统一不夹注（原词已在同句巴利里）。

### 🟦 suggestion
- `171-1759-2-9`｜该使用而没有使用术语标记；语言风格不统一｜片段「洪流、轭、取，系与随眠；」
  - 问题：摄颂是品名缩略回指，`yoga`/`gantha` 译成单字"轭""系"，脱离各自相应品品名的完整译名，孤立阅读几乎无法还原所指。且"轭""系"是单音节文言味词，与 `style.md`"能用双音节现代词就不用单音节"的总原则相左。
  - 建议：改用与各品品名一致的双音节译名（如 轭缚、系缚、随眠），并与前文各品标题逐字对齐。

- `171-1760-2-7`｜该使用而没有使用术语标记；语言风格不统一｜片段「妙欲、盖、蕴，下分与上分。」
  - 问题：同上。`nīvaraṇā` 译单字"盖"，`oruddhambhāgiyā`（= ora + uddhambhāgiya）译"下分与上分"，与 1755 正文的"上分结"术语形态不一致——正文有"结"字，摄颂无。
  - 建议：统一为"下分结与上分结"（或摄颂受字数限制时，在 `terms.md` 登记摄颂缩略形与正文全称的对应关系）；"盖"改为"五盖"或与该品品名一致的译名。

- `171-1755-37-52`｜不常用术语编写注释或者百科｜片段「为了证知、遍知、灭尽、舍断」
  - 问题：`abhiññāya pariññāya parikkhayāya pahānāya` 四项汉译"证知、遍知、灭尽、舍断"沿用传统译法，但"证知"与"遍知"的差别对一般读者不可辨（两者字面都是"知"），属二意场合。
  - 建议：首次出现时夹注原词（`abhiññā` / `pariññā`），或加段后小字注说明"证知"是直接体证、"遍知"是周遍透彻地了知。

- `171-1756-2-9`｜语言表达不够流畅｜片段「（应当像道相应那样详细展开。）」
  - 问题：`vitthāretabbaṃ` 译"详细展开"可，但整句是编辑指示语（告诉诵者此处按道相应的体例补全全部十经），译文读来像对读者的祈使，读者不知"展开"什么。
  - 建议：明确指示对象，如"（此下诸经应依道相应的体例逐一补全。）"
