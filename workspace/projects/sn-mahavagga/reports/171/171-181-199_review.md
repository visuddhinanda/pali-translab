# Review — 171:181-199（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§181-2-3、§187-2-3、§188-2-5、§198、§199 各句无 nissaya，已略过）

## 跨段一致性

- **bahulīkaroti / bahulīkarissati**：§184、§186、§190 译“反复修习”，§197 译“多多修习” → 建议统一为“反复修习”。依据：nissaya `ကြိမ်ဖန်များစွာပြု`（多次反复地做），而且“反复修习”的出现次数占多数。
- **ariya aṭṭhaṅgika magga**：§182、§184、§186、§188、§197 译“圣八正道”，§190 三句（13-30、31-46、66-85）译“八正道”，漏了 ariya → 必改，统一为“圣八正道”。依据：nissaya 逐处有 `အရိယံ= သော`。
- **vivekanissitaṃ … vossaggapariṇāmiṃ**：
  - 两处译法不一：§184 译“依靠远离、依靠离贪、依靠灭，走向舍弃”（同位补述：“这正见依靠……”）；§197 译“依于远离、依于离贪、依于灭尽、趋向于舍离”（前置定语）。
  - 建议统一为 §184 的译法与句式。“依于”“趋向于”的“于”偏文言，不宜采用。
  - nirodha 也要统一，在“灭”和“灭尽”中二选一。
- **rāgavinayapariyosānaṃ 等**：§186 译“以调伏贪为终点”，§190 译“以调伏贪、调伏瞋、调伏痴为终极” → 统一为一种译法，句式也随 §186（逐项重复“以……为终点”）。
- **pāṭikaṅkhaṃ**：三处表述不一，建议统一为“可以预期：他会……”。
  - §184、§186：“对……的比丘可以预期：他会……”
  - §190：“对于……的比丘，可以预期这一点——他会……”
  - §197：“对于……的比丘，可以预期这样的结果：他将……”
- **bhāvessati**：§184、§186、§190 译“会修习”，§197 译“将修习” → 统一为“会修习”。
- **kalyāṇamitta(tā)**：§186 译“结交善友（的比丘）”，§197 译“有善友（的比丘）” → 建议统一为“有善友”。依据：nissaya `ကလျာဏမိတ္တဿ= ကောင်းသောမိတ်ဆွေရှိသော`（具有好朋友的）、`ကလျာဏမိတ္တတာ= ကောင်းသောမိတ်ဆွေရှိသည်၏အဖြစ်`（有好朋友的状态），说的是“具有”，不是“结交”的动作。
- **pubbaṅgamaṃ / pubbanimittaṃ**：§182、§184、§186、§188 的太阳句译“走在前面的先兆、预先出现的征相”，同段道句却译“先兆和预先出现的征相”，同一对词在同一段里两种译法。另外，“先兆”与 pubbanimitta 的意思重合，两个词没有区分开。
  - 建议 pubbaṅgama 固定译“前导”，pubbanimitta 固定译“先兆”，两句都用同一组译法。
  - 依据：nissaya `ပုဗ္ဗင်္ဂမံ= ရှေ့သွားရှေ့ပြေး`（在前行走、在前奔跑者，即前导）。
- **经号格式**：
  - §182“五十至五十四．”、§184“五十五．”、§186“五十六．”
  - §190“62.”（阿拉伯数字加半角点）
  - §197“六三、”（数字简写，后接顿号）
  - → 统一为“五十至五十四．”式（中文数字全称，后接全角点）。
- **经题格式**：§183“七、如理作意具足经”，§189“7. 如理作意具足经” → 统一为“七、”。
- **经末标记**：§184“第七经。”，§190“（第七）” → 统一为“第七经。”。
- **pe**：§182、§184、§186、§188、§197 译“……乃至……”，§190 译“……（中略）……” → 统一为“……乃至……”。
- **引号**：§190、§197 有开头的“和结尾的”，§182、§184、§186、§188 太阳句前没有开引号，经末也没有收引号；pali 各处都有 ‘‘ … ’’ti → 统一加上全角引号。
- **peyyāla**：§191 译“略说品”，§195 译“广说品”，两者意思正好相反 → 必改，统一为一种（建议“略说品”）。品题格式也不一致：§191 是“日轮略说品第六”，§195 是“七、一法广说品”，应统一。
- **夹注巴利原词**：§182-42-66 中，chandasampadā、attasampadā 带夹注，diṭṭhisampadā、appamādasampadā 没有；按首次出现夹注的规则，四个词应一致处理。

## §182 句 171-182-22-41（§184-23-41、§186-23-42、§188-23-69 同）
- **问题**：格与句法。“对比丘来说”把 bhikkhuno 译成了与格（“对……来说”）。nissaya 为 `ဘိက္ခုနော= ၏`，是属格，修饰后面的“道”。
- **建议**：改为“比丘的圣八正道生起的前导、先兆，就是……”。如嫌“的”字连用拗口，可保留现译，但四处要一致。

## §182 句 171-182-42-66
- **问题**：译文里插入了“（以下各经依次换作：）”。这是正文以外的编辑说明，pali 和 nissaya 都没有对应成分；§188 同样插入了这句。
- **建议**：删除。若确实需要提示读者，改放脚注。
- **参考**：nissaya 把 attasampadā 释为 `ပြည့်စုံသောစိတ်`（具足的心），说明 atta 在这里指心。可考虑把“自身具足”改为“自心具足”，或在夹注里加以说明。

## §190 句 171-190-2-12
- **问题**：风格（必改）。“即：如理作意具足”中的“即”是文言单音词，冒号的用法也和其他段的“就是……”不一致。
- **建议**：改为“……就是如理作意具足。”（引号按上面的统一方案处理）。

## §190 句 171-190-13-30 / 31-46 / 66-85
- **问题**：漏译 ariya（nissaya 有 `အရိယံ= သော`）。
- **建议**：三句都把“八正道”补为“圣八正道”，其余措辞按跨段一致性一节统一。

## §194 句 171-194-2-10
- **问题**：误译。“正见和不放逸”中的“正见”多出了“正”（sammā），原文只有 Diṭṭhi。nissaya 为 `ဒိဋ္ဌိ စ= ဒိဋ္ဌိသမ္ပဒါသုတ်`，指的是见具足经。
- **建议**：改为“见和不放逸”，与“见具足”的译法保持一致。

## 原文疑问（只记录，不改）
- §184-23-41 的 pali 作 `pubbanimmittaṃ`，同类句都作 `pubbanimittaṃ`，疑为 OCR 多出一个 m。
