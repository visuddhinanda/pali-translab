# Review — 171:2442-2453（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

## 跨段一致性

- `yathābhūtaṃ`：全 chunk 一律「如实地」→ 一致，保持。
- `abhisameti`「通达」／`abhisambojjhati`「彻底觉悟」／`pakāseti`「宣说」：三词各自译法在 §2443–2453 内部一致，且相互有别 → 区分正确，保持。
- 过去式收句一律「他们全都**是**……了四圣谛」，现在/未来式一律「他们全都……四圣谛」→ 时态标记法前后统一，保持。
- `dukkhasamudayaṃ ariyasaccaṃ`：仅 §2444 出现一次，译「苦生起圣谛」；同 chunk 其余各段均以「……乃至……」省略，无对照面。但与「苦圣谛／苦灭圣谛／通向苦灭之道圣谛」并列时，「苦生起」是四谛中唯一未用定型汉译的一支 → 建议统一为「苦集圣谛」（`terms.md` 已登记「四圣谛」为定型译法，四支宜同一体系）。
- `agārasmā anagāriyaṃ pabbajitā`：§2443 三处 + §2444 一处一律译「从家庭生活出家、过上无家的生活」→ 译法一致，但「过上」有「达成」义，此处是状态而非达成，四处应一并改为「过无家的生活」。
- `Tasmātiha, bhikkhave`：§2445 / §2449 / §2453 一律「因此在这里应当努力」→ 一致，但三处同样需改（见下）。
- 段号标点：§2443「一〇七四**.**」、§2447「一〇七五**.**」、§2451「一〇七六**.**」三处一律用 ASCII 半角句点 → 一致地违规，三处同改。
- 引号闭合：三部经的引述均在 §2445 / §2449 / §2453 末尾以 `’’ti` 收，三处译文都缺收尾全角右双引号 → 一致地缺失，三处同改。

## §2451 句 171-2451-2-30（必改·义注释义）

- **问题**：义注取义 — `abhisambuddhaṃ pakāsesuṃ` 译作「宣说了如实彻底觉悟的**内容**」，把 `abhisambuddhaṃ` 当成 `pakāseti` 的中性宾语（所宣说之事）。**义注**：`abhisambuddhaṃ pakāsesun ti abhisambuddho ahanti evaṃ attānaṃ abhisambuddhaṃ pakāsayiṃsu`（「宣说已彻底觉悟」是说：他们这样宣称**自己**——「我是已彻底觉悟者」）。义注明确补出 `attānaṃ`（自己）为 `pakāseti` 的宾语、`abhisambuddhaṃ` 为其宾补。所以本句说的是「**宣称自己已彻底觉悟**」，不是「宣说觉悟的内容」；`cattāri ariyasaccāni` 则是 `abhisambuddhaṃ` 所觉之对象，不是「宣说」的范围，「就四圣谛宣说」的处理也随之落空。这不是风格问题，是取义与义注相悖。
- **建议**：「……凡是有沙门或婆罗门宣称自己已如实彻底觉悟的，他们全都是宣称自己已如实彻底觉悟了四圣谛。」

## §2451 句 171-2451-31-53（必改·同上）

- **问题**：同上，「将会宣说如实彻底觉悟的内容」「将会就四圣谛宣说如实彻底觉悟的内容」。
- **建议**：「……将会宣称自己已如实彻底觉悟的，他们全都将会宣称自己已如实彻底觉悟四圣谛。」

## §2451 句 171-2451-54-76（必改·同上）

- **问题**：同上，现在式三处。
- **建议**：「……宣称自己已如实彻底觉悟的，他们全都宣称自己已如实彻底觉悟四圣谛。」

## §2452 句 171-2452-17-48（必改·同上 + 三时错置）

- **问题一**：`pakāsesuṃ … pakāsessanti … pakāsenti` 三处仍作「宣说……的内容」，同 §2451，一并改为「宣称自己已如实彻底觉悟」。
- **问题二**：三时错置 — 原文 `… pe …` 省略的是「未来世」「现在」两个时间状语连同其从句，译文却把「将会宣说的」「正在宣说的」两个时态直接挂在开头唯一的时间状语「过去世」之下，读成了「过去世……将会宣说的」，自相矛盾。
- **建议**：省略处补出被省的时间状语（用括注或直接补出），如「比丘们，过去世凡是有沙门或婆罗门宣称自己已如实彻底觉悟的……乃至……（未来世……）将会宣称的……乃至……（现在……）正在宣称的，他们全都就这四圣谛宣称自己已如实彻底觉悟。」——末句 `imāni cattāri ariyasaccāni` 的处理也随义注改（「已如实彻底觉悟这四圣谛」）。

## §2444 句 171-2444-20-51（必改·三时错置）

- **问题**：同上类 — `abhisamesuṃ … pe … abhisamessanti … pe … abhisamenti`，译文「过去世凡是有善家子……通达了的……乃至……将会通达的……乃至……正在通达的」，三个时态共用「过去世」一个时间状语，逻辑矛盾。
- **建议**：省略处补出「未来世」「现在」，或至少在括注中标明，使三时各归其位。

## §2448 句 171-2448-16-47（必改·三时错置）

- **问题**：同上，`abhisambojjhiṃsu … abhisambojjhissanti … abhisambojjhanti` 三时共挂「过去世」。
- **建议**：同上处理。

## §2445 句 171-2445-2-29（必改·引号与标点）

- **问题一**：原文 `‘idaṃ dukkhan’ti` / `‘ayaṃ dukkhanirodhagāminī paṭipadā’ti` 是带引号的所修习内容，译文「应当努力：这是苦……这是通向苦灭之道」把引语直接铺开，被引内容与说话层次混在一起。`style.md` 规定单引号用全角 ‘ ’。
- **问题二**：本句是第四经引述的收尾（`’’ti`），§2443 开首的全角左双引号「“」在此应闭合，译文无右双引号，整部经的引述始终不闭口。
- **问题三**：`Tasmātiha` 译「因此在这里」——`-iha` 在此是句中虚化的语气/处所小词，译作实指的「在这里」使读者误解为某个地点。
- **建议**：「所以，比丘们，应当这样努力：‘这是苦’……乃至……‘这是通向苦灭之道’。”」

## §2443 句 171-2443-2-29（必改·标点；建议·措辞）

- **问题一**（必改）：段号「一〇七四**.**」用了 ASCII 半角句点，违 `style.md` 第五节「一律用中文全角标点」。§2447、§2451 同病。
- **问题二**（建议）：`agārasmā anagāriyaṃ pabbajitā` 是一个动作的两面（从有家的状态出家，进入无家的状态），译文「从家庭生活出家、过上无家的生活」拆成两个并列动作，语义重复；且「过上」含达成义。
- **建议**：段号改「一〇七四．」（或统一改用阿拉伯数字 + 全角标点）；「正确地从家出家、过无家的生活」。同一表述在 171-2443-30-54、171-2443-55-76、171-2444-20-51 共四处，一并改。

## §2442 句 171-2442-2-4（建议·术语）

- **问题**：`kulaputta` 译「善家子」。该词南传常见汉译为「良家子」，汉译佛典传统作「善男子」，「善家子」是三者的混合形，`terms.md` / `term-glossary.jsonl` 均未登记。译名本身不算错，但属未定译名。
- **建议**：择一定案后补进 `terms.md`；首次出现（经题或 §2443 首句）按 `style.md` 第二节夹注巴利原词「善家子（kulaputta）」。经题与 §2443、§2444 内文须同一译法（目前已一致）。

## §2447 句 171-2447-2-28（存疑·义注背景，不必改译文）

- **问题**：**义注**：`Imasmiñhi sutte sabbaññubuddhā ca samaṇagahaṇena gahitā`（在这部经里，一切知佛也被「沙门」这一称法所摄）。此说见于第六经义注，按其体例同样管到第五、第六两经的 `samaṇā vā brāhmaṇā vā`。译文作「沙门或婆罗门」不误，但现代读者读「沙门」不会想到其中含摄诸佛，可能低估经文的涵盖面。
- **建议**：译文不动。按 `style.md` 第四节，宜在第五经首处加一条段后小字注，注明义注的这一界定（须以「**义注**：」标明层次，不可写成经文自说）。此项留待 footnote 步处理，不属 revise 范围。
