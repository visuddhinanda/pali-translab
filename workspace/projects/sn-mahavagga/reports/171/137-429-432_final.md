## 理由

**取数说明**：本次未注入 nissaya 与更上一层（复注 / ṭīkā）资源，评估仅以巴利原文 + 义注自身文脉为准。词级格位与句法角色的核对因此缺少独立基准，凡涉及格位判断的结论信心下调；下文问题清单中标出的格位相关条目（如 `137-429-13-19`、`137-429-86-94`）若 nissaya 可得应复核。被解释词与本文层（Nālandasutta 经文）的逐字同译一致性也无法在本次校验（未注入 mūla 层译文），`**贤明**` `**通达**` `**机敏**` `**巡道**` 等黑体引词是否与经文译文完全一致，需 harmonize 阶段另行确认——这是本次信心指数偏低的主因。

**准确性**：整体取义与义注文脉相符，术语选择稳妥（观 / 道 / 阿罗汉果 / 声闻波罗蜜智 / 法的推知）。主要扣分在三处：`pākārasandhi` 的黑体被解释词译文擅自扩写（把释义塞进被解释词），`missakā` 的括号补注未有据、且与义注上下文的「混合」所指不符风险高，以及 `137-432-2-29` 末尾「世尊才接着这样教诫他」是译者补出的、原文 `tasmā` 之后并无此语。另有 `ṭhānuppattikapaññā` 译作「临机而生的智慧」尚可，但 `medhāya samannāgato` 的「具备」被省略成「具备…睿智」后，`medhāvī` 与 `medhā` 的同源关系在汉语里断掉，属可提升。

**风格符合度**：现代书面汉语，无文言腔，未见 `之/其/乃/便/即/遂` 等文言虚词，未见 `此中/故为/彼等` 等禁例，`是说` 作为义注释义句式的统一标记使用得当，非文言。扣分点在标点：多处使用直角引号或本该用全角弯引号处的处理，以及破折号用法（`137-431-83-86` 与 `137-431-87-103` 两句各自以破折号起收，拆成两句后单独读均不成句）。

**一致性**：`atītānāgatapaccuppannā` 统一译「过去、未来、现在」，`oḷārike pāṇe` 统一译「体型大的生物」，`pākaṭabhāva` 统一译「显明」，`dovārika` 统一译「守门人」，`anupariyāyapatha` 统一译「巡道」——跨段一致性良好。`nīvaraṇa` 一词在 `137-429-36-56` 译「五盖」、`137-429-57-77` 译「诸盖」、`137-430-46-57` 译「诸盖」，数与定指随原文变化，属合理；但「盖」这一译名本身未在术语表登记，建议定案。

## 问题清单

### 🟧 error

- `137-429-25-30`｜错误多译｜片段「**城墙有砖块松脱的裂缝**」
  - 问题：被解释词 `Pākārasandhi` 是复合词「城墙的接缝」，黑体部分应只译被解释词本身，此处把后面的释义（两块砖脱落的地方）提前塞进了黑体词里，造成黑体词与本文层被引词无法逐字对应——违反「被解释词与父层逐字同译」硬约束。且 `sandhi` 是「接缝/接合处」，不是「裂缝」；「砖块松脱」是释义内容而非词义。
  - 建议：黑体改为「城墙的接缝」，释义部分保留「是说两块砖脱落的地方」。

- `137-429-31-35`｜错误多译｜片段「**断开的缺口**」
  - 问题：被解释词 `Pākāravivara` 是「城墙的缺口」，黑体译文丢掉了 `pākāra`（城墙），却补进了释义里的「断开」（`chinnaṭṭhāna`）。同样破坏与本文层的逐字对应，且与上一句同类结构处理方式不一致。
  - 建议：黑体改为「城墙的缺口」。

- `137-430-12-21`｜义理或用词与注释书不符｜片段「觉支是指混合的（兼通世间与出世间）」
  - 问题：`bojjhaṅgāmissakā` 的 `missaka` 在此处义注语境中指前一句方案里「道」与「一切知智」两者混说、即觉支兼摄道与一切知智，并非「兼通世间与出世间」。括号补注引入了原文与义注都没有的判定，属无据增义，且会误导读者。
  - 建议：删去括号补注，译作「觉支是混合说的」，如需说明另在报告/脚注交代，不进正文。

- `137-432-2-29`｜错误多译｜片段「正因为这样，世尊才接着这样教诫他。」
  - 问题：原文只到 `tasmā`（所以），义注在此仅解释 `tasmā` 所承的原因，并未出现「世尊教诫他」这一谓语。「世尊才接着这样教诫他」是译者补出的主谓宾，属增译；`tasmā` 的后续内容在下一句（`abhikkhaṇaṃ bhāseyyāsi`）才出现。
  - 建议：末句收作「正因为这样。」或「所以（才有下面的话）。」，不补出「世尊教诫」。

### 🟨 warning

- `137-429-13-19`｜关键词语意不明确｜片段「是说具备被称为“临机而生的智慧”的那种睿智」
  - 问题：`ṭhānuppattikapaññā` 是传统术语（当场即生之慧、临事而生的智慧），此处加了引号却未给注释，一般读者无从判断这是术语还是译者措辞；且「睿智」与前句「机敏」（`medhāvī`）同源关系在汉语中断裂。
  - 建议：保留「临机而生的智慧（ṭhānuppattikapaññā）」夹注巴利原词，或首次出现加简注；「睿智」可改为与「机敏」呼应的「机敏之慧」。

- `137-429-86-94`｜整句逻辑表达不规范｜片段「**七觉支**、**如实**，是说依照七觉支的本来自性来修习。」
  - 问题：黑体用顿号并列「七觉支」与「如实」，但原文 `Satta bojjhaṅge yathābhūtan ti` 是一个连续被引语段，不是两个并列的被解释词；顿号会让读者以为在分别解释两个词。
  - 建议：黑体合并为「**七觉支如实**」或按本文层译文原样引一整段，去掉顿号。

- `137-431-83-86`｜整句逻辑表达不规范｜片段「到此为止，尊者舍利弗就向世尊——」
  - 问题：该句以破折号收尾、下一句 `137-431-87-103` 又以破折号起首，两句在 channel 中是独立单元，单独读时均为残句（「向世尊——」无谓语，「——就自己的狮子吼作了这样的交代」无主语）。逐句呈现的译文不应依赖跨单元续接。
  - 建议：本句补足为「到此为止，尊者舍利弗就向世尊交代了自己那番狮子吼的根据：」，下一句独立成句。

- `137-431-87-103`｜标点符号使用错误｜片段「——就自己的狮子吼作了这样的交代：“我就是这样」
  - 问题：句首破折号承前一单元，同上；且原文语序是引语在前、`attano sīhanādassa anuyogo dinno hoti` 在后，译文把引语后置又用冒号引出，与上一句重复交代了同一层意思（「作了这样的交代」）。
  - 建议：本句独立译为「“我就是这样站在声闻波罗蜜智上，凭借法的推知、凭借循理而得的把握而了知的。”——他就这样为自己的狮子吼给出了根据。」

- `137-430-2-11`｜不该使用术语标记时使用了术语标记｜片段「念处是指观（vipassanā）」
  - 问题：`vipassanā` 夹注巴利原词无误，但同句中「道」`maggo`、「阿罗汉果」`arahattaṃ` 同为首次出现的法相术语却未夹注，处理不一致；`style.md` 规定法相术语首次出现夹注巴利原词。
  - 建议：要么三者统一夹注，要么只对最易歧义的「观」夹注并在全章保持同一取舍。

### 🟦 suggestion

- `137-429-36-56`｜语言表达不够流畅｜片段「是说五盖染污心、使心污浊、使心烦恼、使心受扰」
  - 问题：四个动词并列时「染污心」与后三个「使心…」结构不齐，`upakkilissanti / kiliṭṭhaṃ karonti / upatāpenti / viheṭhenti` 四项在汉语里读作层层重复，句子节奏偏散。
  - 建议：改为「是说五盖污染心、使心变得污浊、使心烦热、使心受扰」，四项结构对齐。

- `137-430-22-45`｜语言表达不够流畅｜片段「那么这个解答就圆满了」
  - 问题：`sundaro pañho bhaveyya` 直指「这个问答/这一问就精妙了」，译作「解答圆满」偏离了 `pañha`（问）的着落点，读者不易看出长老评论的对象是舍利弗那一问答的构成。
  - 建议：改为「那么这一问答就精妙了」。

- `137-430-46-57`｜复杂的嵌套句整句语言逻辑理解困难｜片段「就像从中间剖开的金块和银块，两半分毫不差一样，彼此没有差别」
  - 问题：譬喻与结论之间「一样…没有差别」语义重复，且「两半分毫不差」是译者补出的解释性内容，使长句更绕。
  - 建议：精简为「就像从中间剖开的金块银块那样毫无差别」，去掉重复的「彼此没有差别」。

- `137-432-64-95`｜代词指代可能不够明确｜片段「他们对如来的疑惑或动摇，都会消除。」
  - 问题：「他们」承接的是前面「有人会这样想」的那些人（`cintentānaṃ`），中间隔了整段引语，代词回指距离过长。
  - 建议：改为「这样思量的人，对如来的疑惑或动摇都会消除」。

- `137-431-43-82`｜语言风格不统一｜片段「法将军就像贤明的守门人」
  - 问题：`dhammasenāpati` 译「法将军」偏白，同章其他称谓（尊者舍利弗、声闻波罗蜜智）取传统译法；南传常见作「法将」。
  - 建议：统一为「法将」，并补入 `knowledge/terms.md`。
