## 问题清单

### 🟧 error

- `199-130-26-29`｜错误多译｜片段「即“凭着这种诸法和合”」
  - 问题：原文 `Yāya dhammasāmaggiyāti sambandho` 只说「（义注里的）yāya 应与 dhammasāmaggiyā 连读」。译文给出连读关系后又把结果整句复述一遍，属添加。另：同句直接嵌入拉丁转写的巴利词，与 133-2-13「“支分”这个词」的处理体例不一致，也与 `knowledge/style.md` 第三节「显示巴利原文：否」相左。
  - 建议：「（义注中的）“凭着它”要与后面的“诸法和合”连读。」

- `199-134-20-26`｜错译（词义）｜片段「**使它显现出来**」
  - 问题：`abhinibbatteti` 是 `nibbatteti`（使生起）的 `abhi-` 强化式，意为「使……生起」，不是「显现」。更关键的是同句把 `nibbatteti` 译作「使它生起」——被释词与释词用了两个不同的动词，复注正在分析的「abhi- 带来格外殊胜义」这条线索在中文里断掉了，读者看不出这句在讲什么。
  - 建议：被释词改为「**使它生起**」，释词保持「以格外殊胜的方式使它生起」。该词是引自义注的黑体被释词，定稿前须与义注层核对同译（本次义注未注入，无法核对）。

### 🟨 warning

- `199-130-30-35`｜关键词语意不明确｜片段「**过度努力**」
  - 问题：`āyūhanā` 本义为「奋力、努力、积聚（业）」，「过度」是译者补上的评价成分；`appatiṭṭhaṃ anāyūhaṃ oghamatari` 的传统读法是「不住立、不奋力而渡瀑流」。该译法在 130-36-41 / 130-42-47 / 130-48-53 / 131-2-9 / 131-10-24 / 133-64-67 反复出现，是术语级决定。
  - 建议：改「奋力」或「挣扎」；若保留现译，须在首次出现处加夹注（āyūhanā）并说明取义依据。

- `199-132-2-8`｜代词指代不明确｜片段「应当按照它们在那里所说的方式来理解」
  - 问题：`veditabbo` 的主语（此处 patiṭṭhāna / āyūhanā 之义）没译出来，「理解」缺宾语；「它们」表面上回指「方式」，读成了「按方式来理解方式」。
  - 建议：「上面所说的各种方式当中，这里没有说到的那几种，其义也应当按《渡瀑流经》的解释中所说来理解。」

- `199-132-18-22`｜整句逻辑表达不规范｜片段「显示的是与道、果一同生起的那些法」
  - 问题：原文承前省略 `bojjhaṅgabhāvaṃ dasseti`，译文只落到「……那些法」，丢了「也具有觉支的性质」这个落点，与紧邻的上一句（132-9-17）句式脱节。
  - 建议：「……显示的是与道、果一同生起的念等法也具有觉支的性质。」

- `199-132-47-54`｜不导致误解的汉语语病｜片段「军队的支、车的支」
  - 问题：「……的支」不成词。同一 chunk 内 `aṅga` 别处译作「支分」（130-22-25、133-2-13），复合词处译作「禅支、道支」（132-39-46），此处两种都没沿用。
  - 建议：「就像军支、车支等一样」，或「就像军队的支分、车的支分等一样」。

- `199-133-73-78`｜整句逻辑表达不规范｜片段「正因为这样，才说念在一切处都有用」
  - 问题：`Tathā hi sā sabbatthikā vuttā` 中的 `tathā hi` 是为前句（念在两方面都需要）**举证**——「事实上，念正被说为一切处所需」。译文反转成「因为念两方面都需要，所以才这样说」，把结论当成了经说的原因。
  - 建议：「事实上，念正是被说为在一切处都需要的。」

- `199-134-73-80`｜关键词语意不明确，二意场合没有注释｜片段「由于在各处都是确定的，所以应当知道，举出遍禅」
  - 问题：两处含混。（a）`tattha tattha nicchayatāya` 的「确定」指什么、在哪些「各处」，译文没交代，读者无从索解。（b）`kasiṇa` 兼有「遍处（业处）」与「全部、整个」二义，取「遍禅」须以义注实际举出的是否为地遍等为据；若义注是泛指整个禅那，此处即为错译。
  - 建议：核对义注该句后定译，并对「遍禅」加简注；（a）处补出所确定的内容。

### 🟦 suggestion

- `199-133-31-57`｜复杂的嵌套句整句语言逻辑理解困难｜片段「像这样，这些词是用上位的诸道来标示各自特殊的事相的」
  - 问题：单句 130 余字，三个「所以说……」并列之后再接两层转折，「这些词」回指前面哪三个词（随觉／通达而觉／正觉）读者难以定位；「以现前的方式正对着觉」也不够顺。另 `uparimaggehi` 一词无 nissaya 可核，取义存疑。
  - 建议：拆成三小句分别对应「随觉／通达而觉／正觉」，另起一句讲「觉悟」的总说与收摄。

- `199-130-30-35`｜不常用术语编写注释或者百科｜片段「就渴爱而言是**停滞**」
  - 问题：`patiṭṭhāna` 本义是「住立、立足、执取」，「停滞」偏向「停滞不前」的状态义；它与 `āyūhanā` 是引自《渡瀑流经》义注的成对术语，脱离出处后这对译名读者不易理解。
  - 建议：首次出现处加夹注（patiṭṭhāna / āyūhanā）并一句说明出处；或改「住立／奋力」。

- `199-131-10-24`｜语言风格不统一｜片段「由渴爱与见而有停滞」
  - 问题：同一段引文内四个并列小句用了两种句式（「由……而有」与「就……而言」），而 130 的六个平行句一律作「就……而言」。
  - 建议：统一为「就渴爱与见而言是停滞，就其余的烦恼和造作而言是过度努力」。

- `199-132-23-38`｜语言风格不统一｜片段「**正如经中所说**」
  - 问题：`yathāha` 直译为「正如（世尊）所说」或「如说」，「经中」是补入的限定。这是引自义注的黑体被释词，补入成分会让本层与义注层不一致。
  - 建议：「**正如所说**」；定稿前与义注该词的译法比对。

- `199-132-18-22`｜代词指代可能不够明确｜片段「**四**（圣谛）」
  - 问题：「（圣谛）」是补注。`Cattārī`tiādi 引自义注，所指也可能是四念住等别的四法；虽有 132-23-38「通达诸谛」旁证，但本段内不能定案。
  - 建议：核对义注该句原文后再决定是否保留这个补注。

- `199-132-9-17`｜语言风格不统一｜片段「毗钵舍那」
  - 问题：本 chunk 里 bodhi（130-2-21）、avijjamānapaññatti（132-47-54）都给了圆括号巴利夹注，而首次出现的毗钵舍那、择法、轻安、掉举、遍禅等法相术语都没给，夹注体例前后不一。
  - 建议：按 `knowledge/style.md` 二、三节，在全章首见处统一夹注一次。
