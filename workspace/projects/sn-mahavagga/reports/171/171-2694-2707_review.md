# Review — 171:2694-2707（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核）

## 跨段一致性

本 chunk 在 §2700 前后用了两套译法。前半是 §2694–2699（莲池经、第一合流经、第二合流经），后半是 §2700–2707（第一大地经、第二大地经、第一大海经、第二大海经）。八部经属于同一组比喻经，句式完全平行，应当全部统一。下面各项建议统一为前半的译法，因为前半与 nissaya 的逐词结构贴合得更紧。

- **经题编号**：§2694 / §2696 / §2698 用「二、」「三、」「四、」，§2700 / §2702 / §2704 / §2706 用「5. 」「6. 」「7. 」「8. 」。建议统一为「五、第一大地经」「六、第二大地经」「七、第一大海经」「八、第二大海经」。
- **段号格式**：§2695 / §2697 / §2699 用「一一二二　」「一一二三　」「一一二四　」（汉字数字加全角空格），§2701 / §2703 / §2705 / §2707 用「1125.」「1126.」「1127.」「1128.」（阿拉伯数字加 ASCII 句点）。建议统一为「一一二五　」「一一二六　」「一一二七　」「一一二八　」。
- **bhante**：§2695、§2697、§2699 译「大德」，§2701、§2703、§2705、§2707 译「尊者」。建议统一为「大德」。
- **evameva kho**：§2695、§2697、§2699 译「同样地」，§2701、§2703、§2705、§2707 译「正是这样」。建议统一为「同样地」。
- **pe**：§2695、§2697、§2699 译「……乃至……」，§2701、§2703、§2705、§2707 译「……略……」。建议统一为「……乃至……」。
- **yogo karaṇīyo**：前半译「应当精勤努力」，后半译「所以应当努力修行」。后半多出的「所以」对应的是被 pe 省略的部分，不应在省略号之后单独补出。建议统一为「应当精勤努力」。
- **Taṃ kiṃ maññatha … katamaṃ nu kho bahutaraṃ**：前半译「你们怎么想呢？哪一个更多——是…，还是…？」，后半译「你们怎么想——哪一个更多呢：是…，还是…？」。建议统一为前半的句式。
- **Etadeva … bahutaraṃ, yadidaṃ**：前半译「更多的是这个，就是…」，后半译「这个更多，也就是…」或「这个更多，就是…」。nissaya 释 `ဧတဒေဝ= ဤ…သည်သာလျှင်`（正是这个），前半的语序更能体现 eva 的强调。建议统一为「更多的是这个，就是…」。
- **appamattaka / appamattikā**：前半译「极少的」，后半译「微不足道的」。建议统一为「极少的」。
- **Saṅkhampi na upeti / upenti … upanidhampi … kalabhāgampi**：前半译「算不上数目，也不能相比，连其中一分都不及」，后半译「算不上数目，算不上比拟，连一小部分也算不上」。
  - nissaya（§2707 94-121）的释义是：`သင်္ခမ္ပိ= ရေတွက်အပ်သည်၏ အဖြစ်သို့လည်း`（够不上被计数）／`ဥပနိဓမ္ပိ= ထောက်ဆအပ်သည်၏ အဖြစ်သို့လည်း`（够不上被比较）／`ကလဘာဂမ္ပိ= တစိတ်အဖို့လည်း`（够不上一个部分）。
  - 两套译法都合乎这个释义，但「算不上比拟」不是通顺的现代汉语。建议统一为前半的译法。
- **ubbhata**：前半译「取出的」，后半译「取出来的」。建议统一为「取出的」。

## §2695 句 171-2695-2-26
- **问题**：风格（轻微）——「池水盈满」中的「盈满」偏书面文雅。
- **建议**：改为「池水满满的」或「池里装满了水」，可酌情处理。

## §2701 句 171-2701-2-19
- **问题**：词义（轻微）——guḷikā 译作「小丸」，材质不明确。nissaya 在下一句的补足语里把它说成 `ထိုမြေလုံးခုနစ်လုံး`（那七个土丸），可见指的是土块或泥丸。
- **建议**：改为「土丸」，并在本经及 §2703 同步修改（2701-20-44、57-62、63-83，2703-2-22、23-50、63-68、69-91）。

## §2701 句 171-2701-63-83
- **问题**：风格——「算不上比拟」搭配不当，读起来生硬。
- **建议**：按跨段一致性一节，改为「也不能相比」。§2703 69-91、§2705 70-93、§2707 94-121 同样处理。

## §2703 句 171-2703-23-50 / 171-2703-51-62 / 171-2703-69-91
- **问题**：原文疑问（记录，不改）。
  - nissaya 在这三句的括注里都说原文应作 `yā vā mahāpathavī parikkhīṇā pariyādinnā`（阴性主格）和 `mahāpathaviṃ`（宾格），见 `ရှိသင့်၏`（应作）。
  - 但 nissaya 同时也按现行读法 `mahāpathaviyā= မြေကြီး၏`（大地的，属格）加 `parikkhīṇaṃ` 给出了释义。
- **建议**：现译「大地已经消尽枯竭的部分」与现行原文的属格结构一致，不必改。异读记录在案即可。

## §2705 句 171-2705-2-21
- **问题**：原文疑问（记录，不改）——nissaya 词条作 `ဥဒ္ဓရိတာနိ`（uddharitāni，被动分词），原文作 uddhareyya（祈愿式）。
- **建议**：现译「取出」按原文的祈愿式比喻句译出，没有问题。
