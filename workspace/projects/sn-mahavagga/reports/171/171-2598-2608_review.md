# Review — 171:2598-2608（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未注入，**词级格与句法未做核对**，下列意见仅据原文形态与义注判断）／义注 ⚠️ 部分——只有第三经（137:913 Daṇḍasuttavaṇṇanā）与第五经（137:915 Sattisatasuttavaṇṇanā）有释文，**第四经 Celasuttaṃ 无义注**，§2601–2604 属无对照标准审查。

## 被解释词与父层对照

义注引出的黑体词共两处，逐字核对结果：

- **`asmā lokā` / `paraṃ lokaṃ`**（义注 137:913）→ 本文 §2599 译「这个世界」／「另一个世界」。✅ 兼容。义注把 `paraṃ lokaṃ` 展开为地狱、畜生趣、鬼界、**人间**、天界五处（`paraṃ nirayampi, tiracchānayonimpi, pettivisayampi, manussalokampi, devalokampi`），所以此处**不能**译成「来世／后世／彼世」——那样义注列出「人间」时对应关系就断了。现译正好留住了余地，后续翻译义注时须沿用「这个世界／另一个世界」原字。
- **`evañcetaṃ, bhikkhave, assa`**（义注 137:915）→ 本文 §2607 译「比丘们，即使真是这样，」。❌ 见下 §2607 条，为必改项。

## 跨段一致性

- **`seyyathāpi`**：§2599 译「就像」，§2606 译「譬如」 → 同一引譬套语，建议统一。依据：两处句式完全相同（`Seyyathāpi, bhikkhave, …`）。按 `style.md` 现代汉语取向，建议统一为「就像」。
- **`vassasatāyuko vassasatajīvī`**：§2606-2-15 译「寿命一百年，能活一百年」（双词分译），§2606-37-63 同一对复合词却压缩成「活满一百年的寿命」 → 同一段内两种译法，建议后者也作「寿命一百年、能活一百年」，或前者也压缩，二者取一。
- **`sattippahāra` 系列**：§2606 作「用一百支矛刺」（动词式），§2607-22-37 作「矛击、剑击、箭击、斧击」（名词式）。原文本身一为动词 `hanissanti` 一为名词 `-ppahāra`，分译有据，**不算错**；但若后续统稿要建术语条，建议登记为「矛击」以免摇摆。
- **经题与内文**：§2605 题作「百矛经」，内文作「一百支矛」。经题从简可接受，记录备查。
- **已核一致，无需处理**：`ariyasacca`→圣谛、`abhisamaya/abhisameti`→现观、`anabhisameta`→尚未现观的、`Taṃ kissa hetu?`→这是什么缘故呢、`Katamesaṃ catunnaṃ?`→哪四种呢、`bhikkhave`→比丘们、`bhante`→尊者、`dukkha/domanassa`→苦/忧、`sukha/somanassa`→乐/喜、三处 `Tasmātiha … yogo karaṇīyo` 结尾套语字字相同。标点全角、无 ASCII 引号，符合 `style.md` 第五节。

## §2607 句 171-2607-38-43

- **问题**：取义（义注）+ 语体断裂 — 必改项。译文「比丘们，即使真是这样，」把 `evañcetaṃ … assa` 读成让步（即使），但**义注**明确读为条件：`evaṃ ce etaṃ bhaveyya, nirantaraṃ sattisatehi haññamānassa dukkhadomanassehi sahevesa saccābhisamayo bhaveyya ceti attho`——「如果这样的话，对于不断被一百支矛所刺的人来说，谛的现观就成了伴随苦与忧的了」。即此句是**假设前提**，其结论（现观伴随苦忧）正是紧接下句要否定的东西。译成让步「即使真是这样」会让读者以为佛陀承认了那个前提。
- 另：本句以逗号收尾，下一句（171-2607-44-59）又起「但是比丘们」，连读成「比丘们，即使真是这样，但是比丘们，我并不说……」——呼语重复、逗号后接转折连词，句子结构失衡。
- **建议**：本句改为「比丘们，假如真是这样的话。」（句号收束，去掉悬空逗号）；下一句起首改「不过，比丘们，我并不说……」避免「比丘们」连续两现。若要把义注补出的结论显化，可在 review 定案后于译文作「比丘们，假如真是这样，（那现观岂不就伴随着苦与忧了。）」——但按 `style.md` 第六节不擅自补足，**推荐只改前半**，把义注的补足留给脚注步骤。

## §2603 句 171-2603-2-36

- **问题**：句法误读 — 必改项。译文「对着了火的衣服或头**可以**暂且不管、不去在意」把祈使降成许可。原文 `Ādittaṃ … celaṃ vā sīsaṃ vā ajjhupekkhitvā amanasikaritvā … karaṇīyaṃ`：两个连续体（`ajjhupekkhitvā` / `amanasikaritvā`）与后面的意愿精进等同受末尾 `karaṇīyaṃ`（应作）统辖，是「**应当**置之不顾、不加理会，而为了……应当生起……」，不是「可以不管」。对照 §2602 的答语（衣头着火应当极力扑救），此处正是以更重者相形，语气必须是规定而非容许。
- **建议**：改作「比丘们，应当对着了火的衣服或头置之不顾、不加理会，而为了如实现观尚未现观的四圣谛，生起极强的意愿、精进、努力、奋发、不退转、念和正知。」

## §2606 句 171-2606-20-36

- **问题**：漏译 — `ehambho purisa` 中的 `ehi`（来吧）未译，只出「喂，这个人啊」。`ehi bho purisa` 是招呼语全式，`ehi` 是实义祈使动词，不是语气词。（nissaya 缺席，无法据缅文助词复核，但形态无疑义。）
- **建议**：改作「来吧，这个人啊，……」或「喂，过来，这个人啊，……」。

## §2600 / §2604 / §2608 句 171-2600-2-30、171-2604-2-29、171-2608-2-30

- **问题**：搭配不通（三处同文，需一并改）。「应当努力修习‘这是苦’」——「修习」的宾语不能是一个命题句。原文 `‘idaṃ dukkhan’ti yogo karaṇīyo` 是「为了（如实知）『这是苦』而应当精勤努力」，`yoga` 指用功、致力，落点在努力本身。
- **建议**：统一改作「应当为‘这是苦’而精勤努力……乃至……应当为‘这是趣向苦灭之道’而精勤努力」，或「应当在‘这是苦’上精勤用功」。三处必须同步改，否则破坏本 chunk 唯一的完全重复套语。

## §2599 / §2603 / §2607 句 171-2599-69-77、171-2603-40-48、171-2607-78-86

- **问题**：风格（文言虚词「之」）待定。「趣向苦灭之道圣谛」中的「之」按 `style.md` 第一节属禁用文言虚词，但「苦灭之道／趣苦灭道」是 `dukkhanirodhagāminī paṭipadā` 的传统汉译构词，属术语而非行文虚词。
- **建议**：这是术语层决定，不宜由本次审稿单方面改。**请定案后登记进 `knowledge/term-glossary.jsonl`**：保留「趣向苦灭之道」（传统译法优先），或按现代汉语取向统一改为「通向苦灭的道路」。定哪一个都可以，但三处 + §2600/2604/2608 的「这是趣向苦灭之道」共六处必须同时改，否则前后不一。

## §2607 句 171-2607-22-37

- **问题**：无据补出。译文「**众生所受的**矛击、剑击、箭击、斧击」——原文只有四个属格复数名词，没有「众生」这个成分，也无义注支持（第五经义注只解 `evañcetaṃ … assa`）。按 `style.md` 第六节不擅自补足主语。
- **建议**：改作「这些矛击、剑击、箭击、斧击，其最初的起点是无法知晓的。」

## §2607 句 171-2607-2-11

- **问题**：补出成分所指不明。`alaṃ upagantuṃ` 译「值得接受**这样的条件**」，「条件」一词为增添；原文只说「值得前往／值得接受」，宾语靠上文那个提议回指。
- **建议**：改作「值得接受这个提议」（回指更明确），或「就该去接受（这样的交换）」。次要项，不改亦可通。
