## 理由

**基准缺失（先说明降级）**：本次只注入了巴利本文与待评译文，**没有义注（aṭṭhakathā）、也没有 nissaya**。因此无法按方法文档「义注定释义、nissaya 定词法」逐句核对，格/句法角色与传统取义均只能据巴利原文与通行解读判断。信心指数据此压到 60。三处待与义注核对的点：① `caṇḍālavaṃsika / caṇḍālavaṃsa` 的具体所指（竿技/旃陀罗竿）；② `Medakathālikā` 一名的释义（义注对此名有解说，译文只作音译，未加注）；③ `āsevanā / bhāvanā / bahulīkamma` 三词在此处的分工。

**准确性**：叙事骨架、主谓宾判断、人物指代全段无误，两次「保护自己／保护他人」的教诫句式与结语句译得准确且前后一致，没有漏译整句的情况。扣分集中在一处：`anudayatā` 被译成「随喜饶益」并夹注 `（muditā）`——这是词义错译，且把原文没有的巴利词塞进了译文，同一处产生两条 error。另有 `āsevanāya, bhāvanāya, bahulīkammena` 三词区分不清、且未补出所修对象，属待提升。

**风格符合度**：现代书面汉语，通读无文言腔——未见「此中／故为／彼等／是故／于…之际／便／遂／答以」等禁例，单音节文言虚词也基本清除，「就能表演技艺」「平安地从竹竿上下来」这类处理符合 style.md 的白话要求。标点全为中文全角，引号一律 “” ‘’，未出现直角引号，也未出现 ASCII 引号（JSON 安全）。跨段的引号层级平衡正确：世尊说话的外层 “ 在 `171-982-22-34` 开、`171-982-155-174` 以 ’” 收；`171-982-175-193` 重开、`171-982-207-221` 收；`171-983-2-13` 重开、`171-983-70-85` 收——无错配。扣分主要来自法相术语首现未夹注巴利原词（style.md 第二节要求）与个别不顺的搭配。

**一致性**：重复出现的两组套语（`Attānaṃ … rakkhissāmīti satipaṭṭhānaṃ sevitabbaṃ` / `Attānaṃ … rakkhanto paraṃ rakkhati`）在 982 与 983 中逐字同译，人名「梅达卡塔利卡」、称谓「老师／贤友」、「爬竿艺人」全段统一，未见漂移。扣分点是「修习」一词同时承担 `āsevanā` 与 `sevitabba` 两个不同巴利词，同段内一词二用；以及并列四项中两项带巴利夹注、两项不带，术语标记使用不统一。

## 问题清单

### 🟧 error
- `171-983-39-56`｜错译（词义）｜片段「通过随喜饶益（muditā）」
  - 问题：原文该项为 `anudayatāya`，`anudayā` 义为哀愍、悲悯、顾念利益，属对他人的悲护之心；译作「随喜饶益」把它换成了四梵住中的「喜」，取义错误。此处四项 `khanti / avihiṃsā / mettacittatā / anudayatā` 是「保护他人即保护自己」的四种心行，末项应与前三项同属悲护一路。
  - 建议：改为「通过悲悯」或「通过哀愍顾念」；待义注取到后按义注释义定稿。

- `171-983-39-56`｜导致误解的表达（夹注巴利原词与原文不符）｜片段「（muditā）」
  - 问题：原文此处并无 `muditā`。夹注本应回指原文词形以便读者复核，这里凭空引入一个原文没有的术语，即使汉译改对，夹注仍会误导读者以为经文讲的是四梵住的「喜」。
  - 建议：删去该夹注，或改作「（anudayā）」。

### 🟨 warning
- `171-983-14-29`｜关键词语意不明确｜片段「通过修习、通过培育、通过反复修习」
  - 问题：两个毛病叠在一起。其一，`āsevanā / bhāvanā / bahulīkamma` 是递进的三个修行动词，译文把 `bhāvanā` 的常规汉译「修习」给了 `āsevanā`，`bhāvanā` 反而译成「培育」，`bahulīkamma` 译成「反复修习」——三者界限被抹平，且「修习」又与下文 `satipaṭṭhānaṃ sevitabbaṃ` 的「修习念处」撞词，同段一词二用。其二，三项均无宾语，读者无从知道修的是什么（承上指念处）。
  - 建议：按「通过熟习、通过修习、通过多修」一类区分译法处理，并考虑补出对象（如「通过对念处的熟习、修习、多修」）；三词的确切分工需取义注/nissaya 后定案。

- `171-983-39-56`｜术语标记使用不一致｜片段「通过安忍、通过不害、通过慈心（mettā）、通过随喜饶益（muditā）」
  - 问题：四个并列项中后两项带巴利夹注、前两项（`khanti` 安忍、`avihiṃsā` 不害）不带，同一句内体例不统一，读者会误以为只有后两项是术语。
  - 建议：四项统一处理——要么都夹注，要么都不夹注。

### 🟦 suggestion

  - 建议：改为「老师，可是事情不会像你说的那样。」
