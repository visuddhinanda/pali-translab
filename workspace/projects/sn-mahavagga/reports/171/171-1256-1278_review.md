# Review — 171:1256-1278（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§1257–1262、§1270、§1278 末两句有逐词 nissaya；§1264、§1272 的 nissaya 只有一条体例说明，指出该经与前经相同）

## 跨段一致性

三部分别经（第六、七、八经）的文句完全相同。nissaya 在 §1264 写明 `ပဉ္စိမာနိ-မှ စ၍ … ဥပေက္ခိန္ဒြိယံ-အထိ ရှေးသုတ်နှင့်တူ၏`（从 Pañcimāni 到 upekkhindriyaṃ 都与前经相同），在 §1272 写明 `… ဒဋ္ဌဗ္ဗာ-အထိ ပေးမြဲ`（照前经释读）。依据这两条说明，三经的相同句应当逐字同译。目前三经各用一套词汇，需要统一。建议以第六经 §1257–1262 为基准，再按下列建议修订基准本身。

- **bhikkhave**：§1257–1270 译“比丘们”，§1272–1278 译“诸比丘” → 统一为“比丘们”。“诸比丘”略带文言色彩，而且使用段落较少。
- **kāyika**：§1258/1259 译“身的”，§1265/1266 译“身体的”，§1273/1274/1277 译“身体上的” → 统一为“身的”。nissaya 作 `ကိုယ်၌ဖြစ်သော`（在身上生起的），三种译法都对得上，取第六经的译法。
- **cetasika**：§1260/1261 译“心的”，§1267/1268/1269 译“内心的”，§1275/1276/1277 译“心上的” → 统一为“心的”。nissaya 作 `စိတ်၌ဖြစ်သော`（在心中生起的）。
- **sāta / asāta**：§1258–1262 译“甘美 / 不甘美”，§1265–1269 译“舒适 / 不适”，§1273–1277 译“适意 / 不适意” → 建议统一为“适意 / 不适意”。nissaya 作 `သာယာအပ်သော`（可乐享的、合意的）/ `သာယာဖွယ်မရှိသော`（不合意的），“适意”最贴切；“甘美”偏指味觉，“舒适”偏指身体感受，用在心受（§1260）上不合适。
- **kāyasamphassaja / manosamphassaja**：§1258/1260 译“由身触所生 / 由意触所生”，§1265/1267 译“由身触生起 / 由意触生起”，§1273/1275 译“由身体接触所生 / 由心意接触所生” → 统一为“由身触所生 / 由意触所生”。“身触”“意触”是固定术语，不宜拆成白话。
- **nevasātaṃ nāsātaṃ**：§1262 译“既非甘美也非不甘美”，§1269 译“既不是舒适的、也不是不适的”，§1277 译“既不感到适意、也不感到不适意” → 统一为“既不适意也不不适意”，与上一条的 sāta 译法连动。§1277 加了“感到”，把形容词译成了动词，与 nissaya 的 `သာယာအပ်သည်လည်းမဟုတ်`（不是可乐享的）不合。
- **Pañcimāni … indriyāni**：§1257、§1272 译“有这五种根”，§1264 译“这是五种根” → 统一为“有这五种根”。
- **Katamāni pañca**：§1257、§1264 译“哪五种呢”，§1272 译“是哪五种呢” → 统一为“哪五种呢”。
- **Imāni kho … pañcindriyāni**：§1262 译“这就是这五种根”，§1270 译“这就是五种根” → 统一为“这就是五种根”（理由见 §1262 句 171-1262-30-39）。
- **Tatra**：§1270 译“其中”，§1278 译“在这些根当中” → 统一为“在这五种根当中”。nissaya 作 `ထို ၅-ပါးကုန်သော ဣန္ဒြေတို့တွင်`（在那五种根之中）。
- **句式**：§1278 的三个 Tatra 句把主题提前，用“……，应当把它们看作乐受”；§1270 用“……应当看作是乐受” → 统一为 §1270 的句式。
- **巴利夹注**：“身的（kāyika）”“心的（cetasika）”只在第六经首次出现时加注，这符合体例。统一用词后，第七、八经不必重复加注。

## §1258 句 171-1258-11-34
- **问题**：句法（轻微）。nissaya 把整串成分都系在同一个中心词 `ယံ … သုခံ= အကြင်ချမ်းသာသည်` 上：`kāyikaṃ`、`sātaṃ`、`kāyasamphassajaṃ`、`vedayitaṃ` 都带定语助词 `သော`，`vedayitaṃ= ခံစားအပ်သော`（被感受的）是修饰“乐”的分词。结句 `ဣဒံ= ဤသုခဝေဒနာကို` 也回指这个“乐”。现译“由身触所生的乐、甘美的感受”用顿号分开，容易读成“乐”和“甘美的感受”两项并列；而且中心词换成了“感受”，与 nissaya 的结构不一致。
- **建议**：用逗号或破折号把三组同位语排开，让“感受”收束全句，例如“凡是身的乐、身的适意，由身触所生的、适意的乐受”。如果保留现在的中心词，至少把顿号改成“……所生的、适意的乐的感受”，避免读成两项并列。同类问题见 §1259、§1260、§1261 的对应句。

## §1259 句 171-1259-10-32
- **问题**：句法（轻微）。与 §1258 相同：nissaya 以 `ယံ ဒုက္ခံ` 为中心词，`asātaṃ`、`vedayitaṃ` 是它的定语。“由身触所生的苦、不甘美的感受”有被读成两项并列的歧义。
- **建议**：按 §1258 的改法处理，同时把“不甘美”改为“不适意”。

## §1260 句 171-1260-10-32
- **问题**：句法与用词。中心词问题与 §1258 相同。另外，nissaya 作 `သာတံ= သာယာအပ်သော`，指心中的合意感受。“甘美”多指味觉，用在心受上不贴切。
- **建议**：改为“……由意触所生的、适意的乐受”，“甘美”改为“适意”。

## §1261 句 171-1261-10-32
- **问题**：句法（轻微）。与 §1259 相同。
- **建议**：同 §1259。

## §1262 句 171-1262-10-29
- **问题**：词法（仅备注，不必改正文）。nissaya 把 `kāyikaṃ vā` 释为 `ကာယပသာဒကို မှီသည်`（依身净色的），并附注说明：依身净色的舍受实际上并不存在，这里说“身的”，是因为舍受依眼等四种净色生起。现译“身的”与巴利字面一致，正文无误。另外，`ယံ ခေါ ဝေဒယိတံ= အကြင်ဝေဒနာသည်` 在这一句里把 vedayitaṃ 当作中心名词，现译“……的感受”与之相符。
- **建议**：正文不改。nissaya 的这条说明可交给 footnote 步作为脚注候选。

## §1262 句 171-1262-30-39
- **问题**：风格。“这就是这五种根”重复了“这”，读起来不顺。nissaya 作 `ဤ ၅-မျိုးတို့တည်း`（这就是五种），只有一个指示词。
- **建议**：改为“比丘们，这就是五种根。”，与 §1270 一致。

## §1264 句 171-1264-2-13
- **问题**：一致性。nissaya 注明本经从这句起与前经相同，但现译“这是五种根”与 §1257 的“有这五种根”不同。
- **建议**：改为“506”同式的“比丘们，有这五种根。”。§1265–1269 也按 nissaya 的“同前经”说明，全部改成与 §1258–1262 逐字相同（编号除外），见跨段一致性一节。

## §1270 句 171-1270-2-17
- **问题**：补出成分（可选）。nissaya 把 `sā` 释为 `ထိုဣန္ဒြေ ၂-ပါးကို`（那两种根，宾格），把 `sukhā vedanā` 释为 `အနုဘဝနလက္ခဏာအားဖြင့် သုခဝေဒနာဟူ၍`（就领受的特相而言，视为乐受）。“就领受的特相而言”是 nissaya 补出的限定语，说明根和受同一的依据。现译没有补出，句意并不因此出错。
- **建议**：正文可以不补。如果要补，作为脚注说明“就领受的特相而言”。Tatra 的译法按跨段一致性一节统一为“在这五种根当中”。

## §1272 句 171-1272-2-13
- **问题**：一致性。nissaya 用 `ပေးမြဲ` 注明本经到 `adukkhamasukhā sā vedanā daṭṭhabbā` 为止都照前经释读，因此 §1272–1278-32-44 应当与第七经逐字同译。现译却另用一套词：“诸比丘”“是哪五种”“身体上的”“心上的”“适意”“身体接触”“心意接触”“在这些根当中”等。
- **建议**：按跨段一致性一节的统一译法，整体改成与第六、七经相同的译文。

## §1278 句 171-1278-45-66
- **问题**：词法与用词。
  1. nissaya 把 `iti kho` 释为 `ဤသို့`（就这样，如此），作用是总结上文。“这样一来”带有“因此导致”的意味，与原意有偏差。
  2. nissaya 把 `pariyāyena` 释为 `ပရိယာယ်အားဖြင့်`（依某种方式、从某一角度）；它在两个分句里重复出现，分别修饰 `tīṇi honti` 和 `pañca honti`。“就某种说法而言”容易被理解成“有一种说法认为”，而且现译只放在句首，看不出它同时管着两个分句。
  3. bhikkhave 的译法需按跨段一致性一节统一。
- **建议**：改为“比丘们，就这样，从某种角度来说，这五种根是五种而成为三种，是三种而成为五种。”
