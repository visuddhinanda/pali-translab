# Review — 171:20-39（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§23 后半、§26 末两句、§27–34 偈颂、§39 末句无 nissaya，已略过）

## 跨段一致性

- **Sāvatthinidānaṃ**：§21 译“四、地点在舍卫城。”，§36 译“5. 舍卫城因缘。”。nissaya 两处都作 `သာဝတ္တိနိဒါန်း`（舍卫城因缘）→ 建议统一为“舍卫城因缘。”，编号格式也一并统一。
- **经题编号格式**：§20 用“四、生闻婆罗门经”，§35 用“5. 为了什么目的经”，§36 也用“5.” → 统一为“四、”“五、”这种中文序号。
- **etadavoca / etadavocuṃ 引语导入**：§22 句 171-22-22-29 译“对世尊这样说道——”，§36 句 171-36-21-28 译“对世尊说：”。同一套语出现了两种译法和两种标点 → 建议统一为“对世尊这样说：”。
- **pariññāya（为了遍知）**：§38 译“能遍知这苦”，§39 译“可以遍知这苦”。两处措辞不一，而且都把与格目的译成了能力（见下文 §38、§39 各句）→ 统一为“为了遍知这苦的”。
- **sahadhammiko vādānuvādo … gārayhaṃ ṭhānaṃ āgacchati**：§37 译“会使我们落到应受责备的地方”，§38 译“会招致应受责备的地方”。同一句式两段不同，且两处都有句法问题（见 §37 句 171-37-53-89）→ 按改后的译法同步。
- **ariya aṭṭhaṅgika magga**：§24、§26、§39 一致译“八支圣道”，但 `term-glossary.jsonl` 已确认 aṭṭhaṅgika magga = “八正道” → 二选一：要么改从术语表，要么把“八支圣道”作为 ariyo aṭṭhaṅgiko maggo 的全称登记进术语表。
- **brahmaṃ vata yānaṃ / brahmayānarūpaṃ**：§23 两句（无 nissaya）是 §21 的复述，§21 修改后要同步改。
- **parivāra / parivāraṇa**：§21、§23 的 setaparivāro 与 §30 偈颂的 parivāraṇaṃ 都译“围饰”。如果按 nissaya 把 §21 改为“车罩”，需要一并决定 §30 跟不跟着改。

## §21 句 171-21-37-72
- **问题**：词义。`သေတာပရိဝါရော= ဖြူသောအဖုံးအကာရှိသော`，意思是“有白色的覆盖物”，nissaya 所附注解也说 parivāra 在这里取覆盖义（paṭicchādana）。所以它说的是车篷、车罩，不是“围饰”。另外，nissaya 把它解作修饰 ratho 的形容词。
- **问题**：词义（次要）。`အဿာ= မြင်းမတို့သည်`，指母马，与上句“四匹母马”呼应；译文只作“马”。`ဥဏှီသံ= နဖူးသင်းကျစ်`，指额上的缠带或头巾，译“束发的头带”偏离了这个所指。
- **建议**：改为“……车是白的，车罩是白的……”；“所套的马”改为“所套的母马”；“束发的头带”改为“头巾”或“额带”。§23 句 171-23-27-62 同步修改。

## §21 句 171-21-78-86
- **问题**：句法。`ယာနံ= ရထားယဉ်သည်။ ဗြဟ္မံ ဝတ= မြတ်ပေစွတကား`：yānaṃ 是主语，brahmaṃ 是表语形容词（“殊胜”），整句意思是“这车真殊胜啊”。译文“这真是梵车啊”把两个词读成了复合词 brahmayāna，而复合词要到下一句才出现。
- **建议**：改为“诸位，这车真是殊胜（brahma）啊！”。§23 句 171-23-68-75 同步修改。

## §21 句 171-21-87-95
- **问题**：句法与翻译腔。`ဗြဟ္မယာနရူပံ ဝတ= မြတ်သောရထားယာဉ်နှင့်တူပေစွ`：-rūpaṃ 在这里表示“像”，整句是“真像殊胜的车啊”。“梵车的样子”是硬译。
- **建议**：改为“诸位，真像一辆梵车啊！”。§23 句 171-23-76-83 同步修改。

## §22 句 171-22-2-15
- **问题**：词义（次要）。`ပိဏ္ဍပါတပဋိက္ကန္တော= ဆွမ်းရှာရာမှဖဲ`，意思是从乞食这件事上退回，不是从某个处所回来。
- **建议**：“饭后从乞食处回来”改为“饭后乞食回来”。

## §23 句 171-23-2-14
- **问题**：增译。`ဣဓ= ဤသာဝတ္တိပြည်၌`：idha 指“在这舍卫城”，表示处所。译文没有译出这个处所义，却加了原文没有的“今天”。
- **建议**：删去“今天”，改为“大德，我上午在这里穿好下衣……”。

## §23 句 171-23-84-97
- **问题**：词义。`ပညပေတုံ= ပညတ်ခြင်းငှါ`，意思是施设、安立。译文“能不能也说有梵车”里的“也”是增译，“说有”也弱化了“施设”的意思。
- **建议**：改为“大德，在这法与律中，能不能施设一种梵车呢？”

## §25 句 171-25-2-18
- **问题**：词义（可选）。`ရာဂကို ပယ်ဖျောက်သည်ဖြစ်၍ မိမိကိစ္စကိုပြီးဆုံးစေ`：nissaya 释为“断除贪，完成自身的作用”，附注更明说是正断（samucchedavinaya）。“调伏”的力度偏弱。
- **建议**：可以考虑把“调伏”改为“断除”。如果改，§25 全部八句都要同步，否则保留现译。

## §37 句 171-37-53-89
- **问题**：句法与词义。`ဝါဒါနုဝါဒေါ= ဘုရားရှင်၏ဝါဒ, ထိုဝါဒသို့ အတုလိုက်သော ဝါဒသည်`：vādānuvādo 指世尊的说法以及随之而来的说法，是句子的主语，由它“落到”（`ကျရောက်`）该受责备的境地。译文译成“如法的辩驳”，把它读成了对方的反驳；又说“使我们落到”，换掉了主语。
- **问题**：词义。`ဓမ္မဿ= အကြောင်းအား။ အနုဓမ္မံ= လျော်သောအကြောင်းကို`，意思是所答与法相符、相随。“依法随法而回答”语义含糊，近于翻译腔。`ဂါရယှံ ဌာနံ= ကဲ့ရဲ့အပ်သော အကြောင်း`，意思是可受指责的理由、地步，译“地方”不准确。
- **建议**：后半改为“……回答的内容与法相符，也没有任何一种有根据的说法或随之引出的说法会落到应受指责的地步呢？”

## §38 句 171-38-2-36
- **问题**：句法与词义。与 §37 句 171-37-53-89 相同：“如法的辩驳会招致应受责备的地方”把主语换了，也误读了 vādānuvādo；“依法随法而回答”同样含糊。
- **建议**：按 §37 的改法同步，改为“……你们回答的内容与法相符，也没有任何一种有根据的说法或随之引出的说法会落到应受指责的地步。”

## §38 句 171-38-54-80
- **问题**：格。`ဧတဿဒုက္ခဿ= ဤဆင်းရဲကို။ ပရိညာယ= ပိုင်းခြား၍သိခြင်းငှာ`：pariññāya 是表目的的与格（`ငှာ`），意思是“为了遍知这苦”。译文“有道、有道迹能遍知这苦吗”把道说成了能知的主体。
- **建议**：改为“那么各位朋友，有没有为了遍知这苦的道、为了遍知这苦的道迹呢？”

## §38 句 171-38-81-98
- **问题**：格与语气。与上句相同，pariññāya 是目的格。另外 `အတ္ထိ ခေါ= ရှိသည်သာတည်း` 表示肯定强调（kho），译文没有体现。
- **建议**：改为“各位朋友，确实有为了遍知这苦的道，有为了遍知这苦的道迹。”

## §39 句 171-39-2-16
- **问题**：格。`ပရိညာယ= ငှါ`，是目的格，“可以遍知这苦”同样把道说成了能知的主体。
- **建议**：改为“比丘们，那么，为了遍知这苦的道是什么？道迹是什么？”

## §39 句 171-39-30-41
- **问题**：格。与上句相同。
- **建议**：改为“比丘们，这就是为了遍知这苦的道，这就是道迹。”
