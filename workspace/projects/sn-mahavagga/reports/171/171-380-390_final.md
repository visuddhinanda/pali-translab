**准确性**：这五部经（Ogha/Yoga/Upādāna/Gantha/Anusaya）是 Maggasaṃyutta 尾部的高度公式化短经，句式固定、术语密集，翻译的主要风险不在句法而在术语选词与结构一致性。译文对四暴流、四轭、四取、四身系、七随眠的名相处理基本准确：`kāmupādāna/diṭṭhupādāna/sīlabbatupādāna/attavādupādāna` 译「欲取、见取、戒禁取、我语取」合传统定译；七随眠的七项无缺漏、次序与原文一致；`abhiññāya pariññāya parikkhayāya pahānāya` 四个与格译「为了证知、遍知、灭尽、断除」准确且四经统一。

主要扣分在 `kāyagantha` 一句（`171-388-18-38`）：译文把「身系」的教义解释直接写进正文夹注，这既超出本段原文所载，也与全篇「首次出现只夹注巴利原词」的体例不符；且四个身系只在第一项标注「是身系」的解释，后三项省略，读者会误以为解释只限第一项。另外 `sīlabbataparāmāso` 译「戒禁取著」与同组 `171-386-18-33` 的 `sīlabbatupādāna`「戒禁取」字面几乎相同，而巴利是 parāmāsa 与 upādāna 两个不同词，译文未作有效区分。

**一致性**：跨五经的公式句处理一致性很好——`Cattārome, bhikkhave, X` 一律译「比丘们，有这四种 X（pali）」，`ime kho...` 一律译「比丘们，这就是四种 X」，结尾序号一律「第 N 经」。不一致处：`171-382-38-71` 把 `Paṭhamaṃ .` 与正文合并在同一句 id 内（因原文切分如此，可接受），但其余四经的 `Dutiyaṃ/Tatiyaṃ/Catutthaṃ/Pañcamaṃ` 均为独立句，格式上第一经与后四经不齐；更实质的是品名 `Ganthasuttaṃ` 译「系缚经」而经内 `kāyagantho` 译「身系」，同一词根在标题与正文用了两个不同译名。

## 问题清单

### 🟧 error

- `171-388-18-38`｜义理或用词与注释书不符｜片段「（kāyagantha，这里的“身”指名身，即心法的聚合）」
  - 问题：本段巴利原文只有 `abhijjhā kāyagantho` 等四项名相，并无任何对「身」的界定；「身指名身，即心法的聚合」是义注层面的教义解说，被直接写入本文层译文。本文层应只译原文所载，义注的解释归义注层或脚注。且本次评估未取到义注，该解说的具体表述也无从核对。
  - 建议：正文只保留「贪欲是身系（kāyagantha）」，把「身」的界定移入脚注或交由义注层译文承载；若确需保留，也应由 `/pali-footnote` 步骤处理，不占正文。

- `171-388-18-38`｜错译（词义）｜片段「戒禁取著是身系」
  - 问题：此处巴利是 `sīlabbataparāmāso`（parāmāsa，执取／误执），与 `171-386-18-33` 的 `sīlabbatupādānaṃ`（upādāna，取）是两个不同的词，译文「戒禁取著」与「戒禁取」仅一字之差，读者无法分辨，实际上抹掉了 parāmāsa 与 upādāna 的区别。
  - 建议：`sīlabbataparāmāsa` 改译「戒禁执取」或「戒禁误执」，与四取中的「戒禁取」明确拉开距离。

### 🟨 warning

- `171-387-2-4` / `171-388-2-14`｜关键词语意不明确｜片段「四、系缚经」
  - 问题：标题 `Ganthasuttaṃ` 译「系缚经」，`171-388-2-14` 的 `ganthā` 译「系缚」，但同段 `171-388-18-38` 的 `kāyagantho` 译「身系」——同一 gantha 词根在标题与正文中出现「系缚」「身系」两种译名，读者难以看出是同一名相。
  - 建议：统一为「系」或统一为「结缚」，如标题作「四、身系经」、正文 `ganthā` 作「四种系」，使 `gantha` 与 `kāyagantha` 在字面上可串联。

- `171-388-18-38`｜整句逻辑表达不规范｜片段「贪欲是身系（kāyagantha，这里的“身”指名身，即心法的聚合），瞋恚是身系，戒禁取著是身系，坚执“唯有这才是真实”是身系」
  - 问题：四项并列，第一项插入一段长夹注后再接三个短句，句子重心被打散；且「是身系」重复四次，汉语并列表达显得笨重。
  - 建议：夹注移出后，可作「贪欲、瞋恚、戒禁执取、坚执“唯有这才是真实”，这四者都是身系（kāyagantha）」，或保留四个分句但去掉重复的「是身系」。

- `171-382-38-71`｜标点符号使用错误｜片段「（如同“寻求”（品）一样，全部都应照此详细展开。）」
  - 问题：括号内再套括号，「（品）」这一补字方式在中文标点体例中不规范，读者也不易判断「品」是原文所有还是译者所补。
  - 建议：改为「（如同“寻求品”一样，全部都应照此详细展开。）」，或「（照“寻求”一品的体例，全部都应详细展开。）」。

### 🟦 suggestion

- `171-382-2-9`｜语言表达不够流畅｜片段「一七二、因缘在舍卫城。」
  - 问题：`Sāvatthinidānaṃ` 译「因缘在舍卫城」略显生硬，「因缘」在此是「缘起／序分所在地」之义，现代读者容易误读为佛教术语「因缘」（hetu-paccaya）。
  - 建议：改为「缘起于舍卫城。」或「〔本经〕缘起于舍卫城。」

- `171-382-10-18`｜该使用而没有使用术语标记｜片段「有这四种暴流（ogha）」
  - 问题：`ogha`「暴流」在中文里不是自明词，首次出现只夹注巴利原词而无任何提示，一般读者不知其喻义（如洪流般漂没众生）。同组 `yoga`「轭缚」、`anusaya`「随眠」同此。
  - 建议：若项目允许，由 `/pali-footnote` 为「暴流」「轭缚」「随眠」三词补首次出现脚注；正文不动。

- `171-388-18-38`｜语言表达不够流畅｜片段「坚执“唯有这才是真实”是身系」
  - 问题：`idaṃsaccābhiniveso` 译「坚执“唯有这才是真实”」意思到位，但「这」指代空泛，且引语直接嵌入并列项中，与前三项的名词性结构不对称。
  - 建议：改为名词性表述，如「执“唯此为真”之见」的现代说法——「坚持“只有这个才是真实的”这种执著」，或简作「真实执」并夹注巴利原词。

- `171-382-38-71`｜语言风格不统一｜片段「应当修习这条八正道。”（如同“寻求”（品）一样，全部都应照此详细展开。）第一经。」
  - 问题：第一经把经文、编者按语、经序号三种性质不同的内容挤在同一句译文里，而后四经的「第二经／第三经」等均为独立单元，排版观感不一致。
  - 建议：受原文切分所限不宜拆句，但可在按语与「第一经。」之间加换行或用不同标点分隔，使三部分层次可辨。
