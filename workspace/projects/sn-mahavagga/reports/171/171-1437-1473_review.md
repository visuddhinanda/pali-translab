# Review — 171:1437-1473（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅 §1453 首句、§1458、§1462、§1463 有 nissaya；其余句无 nissaya，不出单句意见，只参与跨段一致性核查）

## 跨段一致性

- **ogha**：§1437、§1439、§1441 译“暴流”，§1451、§1452、§1454、§1456 译“瀑流”。建议统一为“暴流”，因为它是南传通行译法，本 chunk 前半也都用这个。
- **Gaṅgāpeyyālavagga**：§1443、§1446 译“恒河重复品”，§1460、§1464 译“恒河略说品”。peyyāla 指省略重复，两种译法所指相同，但同一品名必须统一。建议统一为“恒河略说品”。
- **ninnā / poṇā / pabbhārā**（三词连用的同一譬喻）：
  - §1445 译“低倾、斜落、倾注”。
  - §1463 译“趋向、倾向、朝向”。
  - 摄颂 §1448 作“向东低倾”，§1466 作“趋向东方”。
  - nissaya（§1463）给的三词是 `ပါစီနနိန္နာ= အရှေ့ဘက်သို့ညွတ်သည်`（弯向）/ `ပါစီနပေါဏာ= …ကိုင်းသည်`（倾斜）/ `ပါစီနပဗ္ဘာရာ= …ရှိုင်းသည်`（斜垂）。三词都带“向下倾斜”的形象。§1463 的“朝向”只表方向，丢了倾斜义。
  - 建议全 chunk 统一用 §1445 那组“低倾、斜落、倾注”，摄颂随之一致。
- **pahānāya**：§1438、§1462、§1463 译“舍断”，§1453 译“断除”。建议统一为“舍断”。
- **rāga/dosa/mohavinayapariyosānaṃ**：§1445 译“以调伏贪为终极”，§1453 译“以调伏贪为最终目标”。建议统一为一种。§1453 又把定语改成了后置分句，句式也应与 §1445 一致。
- **Pācīnādisuttadvādasakaṃ**：§1444 译“东方等十二经”，§1461 译“以《向东经》为首的十二经”。建议统一，同时与 §1437/§1452 的“暴流等十经”格式对齐，例如统一作“向东等十二经”。
- **bahulīkaronto**：§1445 译“多修五根”，§1463 译“多多修习四正勤”。建议统一为“多多修习”。
- **Katamāni pañca**：§1438 译“哪五种呢”，§1453 译“哪五根呢”。同一句式应一致。
- **peyyāla 省略号**：§1438、§1445 作“……乃至……”，§1453 作“……（中略）……”。建议统一为“……乃至……”。
- **Tassuddānaṃ**：§1440 作“本品的摄颂是——”，§1447、§1465、§1470 作“它的摄颂是——”，§1455 作“本品的摄颂——”。建议统一为“本品的摄颂是——”。
- **品末题**：§1439 作“暴流品，第十二。”（带逗号），§1446、§1454、§1464 作“××品第十三。”（不带逗号）。建议统一去掉逗号。
- **摄颂 §1441/§1442 与 §1456/§1457 是同一偈**，两处译法不一：
  - §1441 作“系”，§1456 作“系（gantha）”。
  - §1442 作“妙欲、诸盖、诸蕴，还有下分与上分”，§1457 作“妙欲（kāmaguṇa）、盖（nīvaraṇa）、蕴，以及下分结与上分结”。
  - 巴利夹注按“首次出现”规则应放在前一处（§1441/§1442），或两处都不加。建议两处正文逐字统一，并补出“结”字。
- **vaggo tena pavuccati**：§1449 译“因此称为一品”，§1467 译“因此这一品就这样称说”。同一偈句应统一。“称说”偏书面，建议两处都用“因此称为一品”。
- **vitthāretabba(ṃ/ā/o)**：
  - §1438 作“应当照此详加展开”。
  - §1450 作“都应照此详细展开”。
  - §1463、§1469 作“应当按照／依照……详细展开”。
  - 建议统一作“应当……详细展开”。

## §1462 句 171-1462-12-16
- **问题**：词法/取义。nissaya 作 `တတြ ခေါ= ထိုအခါ၌`（“在那时”），把 tatra 读作时间处格，不是地点。译文“在那里”取了处所义。
- **建议**：改为“那时，世尊这样说道——”。

## §1462 句 171-1462-75-92
- **问题**：词法误读，并列项数错。nissaya 把两词合为一个释义单元：`ဘာဝနာယ ပါရိပူရိယာ= ပွါးခြင်း၏ပြည့်ခြင်းငှါ`（“为了修习的圆满”）。其中 bhāvanāya 是属格，修饰 pāripūriyā；全句的目的只有五项：ṭhiti / asammosa / bhiyyobhāva / vepulla / bhāvanāpāripūri。译文“安住、不忘失、增长、广大、修习、圆满”拆成了六项，把属格修饰语当成了独立的并列目的。
- **建议**：改为“为了使已经生起的善法安住、不忘失、增长、广大、修习圆满，而……”。

## §1463 句 171-1463-94-112
- **问题**：同 §1462 句 171-1462-75-92。nissaya 仍把 `ဘာဝနာယ ပါရိပူရိယာ` 作为一个单元，译文同样误拆成“修习、圆满”两项。
- **建议**：改为“……增长、广大、修习圆满，而……”，与 §1462 同步修改。

## §1463 句 171-1463-2-13
- **问题**：词义。nissaya 的 `ညွတ် / ကိုင်း / ရှိုင်း` 都是“弯斜、倾垂”义。译文“趋向、倾向、朝向”只表方向，尤其“朝向”丢了 pabbhāra 的“斜垂”义。它与 §1445 的同句也不一致（见跨段一致性）。
- **建议**：改为“比丘们，就像恒河向东低倾、向东斜落、向东倾注；”。

## §1463 句 171-1463-14-30 / 171-1463-31-46 / 171-1463-113-132
- **问题**：nibbānaninno / nibbānapoṇo / nibbānapabbhāro 的译法随 171-1463-2-13 一并失准。nissaya 作 `နိဗ္ဗာန်သို့ ညွတ်သည် / ကိုင်းသည် / ရှိုင်းသည်`。
- **建议**：统一改为“向涅槃低倾、向涅槃斜落、向涅槃倾注”，与 §1445 一致。
