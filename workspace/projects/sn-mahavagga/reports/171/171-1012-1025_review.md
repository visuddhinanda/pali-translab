# Review — 171:1012-1025（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句无 nissaya，已略过）

## 跨段一致性

- **satipaṭṭhāna**：§1013、§1014、§1016、§1017、§1019、§1020 译“四念住”，§1025（171-1025-2-30）译“四念处”。建议统一为“四念住”，本 chunk 中这一译法占多数。
- **念住定型句**：前后两种句式并存。
  - §1014、§1017、§1020 译“观察身体、安住于对身体的观察，勤奋、正知、具足正念，除去对世间的贪欲和忧恼”。
  - §1024、§1025 译“安住于在身上观察身，勤奋、有正知、有正念，去除对世间的贪欲和忧恼”。
  - nissaya 的结构是 `ကာယေ= ရူပကာယ၌` + `ကာယာနုပဿီ= ၍` + `ဝိဟရိဿာမိ`：kāyānupassī 是修饰 viharati 的状态语，后一种句式更贴合，也没有前一种“观察身体、安住于对身体的观察”的重复。
  - 建议全 chunk 统一为后一种句式，ātāpī / sampajāno / satimā 统一为“勤奋、有正知、有正念”，vineyya 统一为“去除”。
- **pe 省略号**：§1014、§1017、§1020 译“对于各种感受……略……对于心……略……”，§1024、§1025 译“在各种感受上……在心上……”，丢了“略”。建议统一保留“……略……”，介词框架与上一条的定型句保持一致。
- **Taṃyeva nidānaṃ**：§1016、§1019 都译“缘起和前面一样”。两处一致，但措辞有问题，见 §1019 条。
- **etadavoca 前的标点**：§1013、§1016、§1019 用破折号“——”，§1022、§1023 用冒号“：”。巴利原文两处都是“–”。建议统一为冒号“：”。
- **ekamantaṃ nisinno**：§1013、§1016、§1019 译“坐在一旁的尊者舍利弗……”，作定语；§1022（171-1022-129-138）译“坐在一旁以后，那个人……”，作先后关系。nissaya 给的是 `နိသိန္နော ခေါ= သော`，即定语。建议统一为定语式。
- **sirasā vandati**：171-1022-53-61 译“以头礼拜”，171-1022-72-80 与 171-1022-139-156 译“用头礼拜”。建议统一为“用头礼拜”（或“头面礼拜”）。“以”作文言虚词属必改。
- **bhante**：本 chunk 中“尊者”既译 āyasmā，又译 bhante。bhante 的对象不同时（僧人 / 主人）不能同译，见 §1022 句 171-1022-104-121。

## §1019 句 171-1019-2-8

- **问题**：措辞 — nidāna 在此指经的开头背景，nissaya 释为 `တံယေ၀ နိဒါနံ= ထိုနိဒါန်းပင်`，即“就是那段开头（因缘）”。译为“缘起”容易与 paṭiccasamuppāda（缘起）混淆。
- **建议**：改为“背景（因缘）和前面一样”或“开头的情节同前”。§1016 同句一并改。

## §1020 句 171-1020-54-70

- **问题**：数 / 名词结构 — sahassaṃ lokaṃ 是单数宾格。nissaya 释为 `သဟဿံ= တထောင်စီသော` / `လောကံ= ကမ္ဘာလောကကို`，即“千数的世界（界）”，是一个整体。译文“一千个世界”把它读成了一千个单独的世界。nissaya 括注“（ကာလ ၃-ပါး၌）”（三时中各一千）是补出成分，不进正文。
- **建议**：改为“能证知千世界”。“以神通”可以保留，abhijānāmi 的 nissaya 是 `ရှေးရှူ သိနိုင်၏`（直接知、证知），改成“证知”更贴切。

## §1022 句 171-1022-41-52

- **问题**：语体 — ambho purisa 的 nissaya 是 `အမောင်ယောက်ျား`，是对下人较和缓的呼语。“喂，你这个人”语气粗鲁，与“你到尊者阿难那里去”连用后，“你”出现了两次。
- **建议**：改为“来，好人，你到尊者阿难那里去；”。

## §1022 句 171-1022-104-121

- **问题**：称谓误译（必改）— 这里的 bhante 是仆人对居士施利瓦达的称呼。nissaya 作 `ဘန္တေ= အရှင်`，意为“主人”，与对阿难用的 `အရှင်ဘုရား`（尊者）有明确区分。译文译成“尊者”，等于把居士称为尊者。
- **建议**：改为“好的，主人。”

## §1022 句 171-1022-129-138

- **问题**：句法 — nisinno 作定语修饰 so puriso，这里没有 nissaya，依据是同式句 §1019 `နိသိန္နော ခေါ= သော`。译文“坐在一旁以后”把它改成了先后关系，也和本 chunk 其他各处不一致。
- **建议**：改为“坐在一旁的那个人对尊者阿难这样说：”。

## §1023 句 171-1023-2-15

- **问题**：词义收窄 — pattacīvaraṃ 的 nissaya 是 `သပိတ်သင်္ကန်းကို`，即钵和袈裟（衣），没有限定为外衣。
- **建议**：改为“拿着钵和衣”。

## §1023 句 171-1023-29-47

- **问题**：补出成分（可选）— yāpanīyaṃ 的 nissaya 为 `ဣရိယာပုတ်ကို ဖြစ်စေနိုင်၏လော`，意为“能维持（行住坐卧的）姿势吗”。译文“还能维持下去吗”可以通，但意思比 nissaya 宽泛。
- **建议**：可改为“还撑得住吗”，或保留原译。

## §1023 句 171-1023-48-56

- **问题**：主语 / 属格 — nissaya 作 `အာသာနံ= ထိုဝေဒနာတို့၏` / `ပဋိက္ကမော= နောက်သို့ ဆုတ်ခြင်းကို`，即“这些（痛苦）感受的减退”。属格指向前句的 dukkhā vedanā。译文用“病势”作主语，指代对象换掉了。
- **建议**：改为“看得出这些感受在减退，而不是在加剧吗？”

## §1023 句 171-1023-68-76

- **问题**：句法 — nissaya 中 bāḷhā 是定语 `ကြီးမားကုန်သော`，修饰 dukkhā vedanā，谓语只有 abhikkamanti / no paṭikkamanti。译文把它拆成了谓语“很剧烈”。
- **建议**：改为“我剧烈的痛苦感受在加剧，没有减退；”。

## §1023 句 171-1023-77-85

- **问题**：主语 / 属格 — 与 171-1023-48-56 相同，`အာသာနံ= ထိုဝေဒနာတို့၏` 指这些感受，不是“病势”。
- **建议**：改为“看得出这些感受在加剧，而不是在减退。”

## §1025 句 171-1025-2-30

- **问题**：增译 — 原文与 nissaya 都没有强调词，nissaya 只作 `သံဝိဇ္ဇန္တိ= ရှိကုန်၏` 与 `သန္ဒိဿာမိ= ထင်မြင်ပါ၏`。译文两处加了“确实”。此外 satipaṭṭhāna 译成“四念处”，与全 chunk 不一致。
- **建议**：改为“尊者，世尊所教导的这四念住，在我身上都有，我也在这些法中显现出来。”

## §1025 句 171-1025-89-100

- **问题**：措辞 — nissaya 作 `လာဘာ= လာဘ်တို့ပေတည်း`（真是利益）、`သုလဒ္ဓံ= ကောင်းစွာရအပ်စွ`（得得真好啊）。“这是你的收获”“你得到的真好”字面生硬，宾语也悬空。
- **建议**：改为“居士，你真是得到了利益！居士，你真是得到了善妙的利益！”
