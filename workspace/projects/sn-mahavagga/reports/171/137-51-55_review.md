## 跨段一致性

- **paṭhamabodhiyaṃ / paṭhamābhisambuddho**：§54-9-15 作「**刚证得正觉**（时）」（父层已定），§54-53-80、§55-2-45、§55-46-56 却作「刚成道」 → **必改**，统一为「刚证得正觉时」。依据：义注自身即以 `abhisambuddho hutvā paṭhamaṃyeva ekūnapaññāsadivasabbhantare` 训 paṭhamābhisambuddho，与 paṭhamabodhi 同指那四十九天，中文两套说法会让读者以为是两个时期。
- **samāpatti**：§53-16-58 译「果定」，§55-66-75 译「（安住的）等至」 → 建议统一，§53 改「果等至的快乐」。
- **padesa / ekadesa / nippadesa 三词对立**：padesa 全篇作「一部分」✅；但 ekadesa 也译「一部分」，导致 §55-2-45 出现「缘的一部分，就……而言是缘的一部分」这样的同语反复；nippadesa 译「毫无遗漏地全部」，与「一部分」的反义关系没显出来。建议：padesa =「一部分」，ekadesa =「其中一分」，nippadesa =「不留一分地／整体无余地」。这一组对立是 §54-§55 整段论证的骨架。
- **paccayākāra（§54-31-38「缘起」）vs paccaya（§55-2-45「缘」）**：§55 是对 §54 名目表的逐项展开，两处名目应能对上。建议 §54 作「缘的行相（缘起）」，或 §55 首次出现时写「缘起中缘的一分」。
- **称谓**：原文 Bhagavā（§54-53-80）译「世尊」、satthā（§53）译「导师」，忠于原文 ✅；但 §53-2-5、§54-39-42、§54-81-90、§54-91-120、§55 多处只用代词「他」，跨段读下来主语不明。建议在各段首句补明「世尊」。
- **vasena / vaseneva 的 eva**：§55-2-45 六处「就……而言」未体现 `eva`（唯、只就）。低优先，若统一处理，建议对带 `-eva` 的三处作「唯就……而言」。

## §52 句 137-52-2-29

- **问题**：漏译 — 释义句 `ekaṃ aḍḍhamāsaṃ` 的 `ekaṃ` 未译出。
- **建议**：作「整整半个月」。
- **问题**：语义重复 — 释义部分「独自静居、隐居，只一个人安住」，`paṭisallīyituṃ`（静居）的「独自」与 `ekova hutvā`（只一个人）叠床架屋。黑体 lemma 处必须保留父层的「独自静居」，但后面的释义展开可以调整。
- **建议**：释义部分改为「我想要整整半个月静居、隐居，独自一人安住」。

## §52 句 137-52-30-64

- **问题**：句法 — 原文是 `yo … upanāmeyya, taṃ … ekaṃ bhikkhuṃ ṭhapetvā` 的关系—相关结构（「把那个……的一位比丘除开」）。译文「谁不自己开口向人索求，而是把……送到我面前，那么除了这一位……」把「谁」悬在句首没有着落，读者到「那么」处才发现前半句是定语。
- **建议**：改为「除了这样一位送施食的比丘——他不自己开口向人索求，而是把信众家里为我准备好的施食取来送到我面前——以外，任何别的比丘或在家人都不要来见我」。
- **问题**：术语 — `payuttavācā` 指「暗示性的索求话」（律典义），「开口向人索求」略宽。
- **建议**：作「不自己说出暗示索求的话」。待 nissaya 复核。

## §53 句 137-53-13-15 / 137-53-16-58

- **问题**：句法与主语 — 原文 `Atha satthā ‘‘…’’ti iminā kāraṇena evamāha` 是一句，`satthā` 是 `evamāha` 的主语。译文把 §53-13-15 处理成「于是导师**想**——」，到句末又另起「**他**是出于这个原因才这样说的」，一个主语说了两遍，而且「想」与「说」对不上。
- **建议**：§53-13-15 作「于是导师心里这样考虑——」；§53-16-58 句末作「导师正是出于这个原因才这样说的」。
- **问题**：术语一致 — 「果定」见跨段一致性。

## §53 句 137-53-67-75

- **问题**：可读性 — `pātova`（一大早）与 `tasmiṃ khaṇe`（就在那一会儿、当即）两个时间状语连排成「清早就在那个时候做完……」，读者无法理解「那个时候」指什么。
- **建议**：「那位比丘一大早就把打扫香室庭院、供给洗脸水和齿木等一切事务在很短的时间里做完，然后就离开。」
- **问题**：术语 — `dantakaṭṭha` 译「牙木」，传统汉译作「齿木」。
- **建议**：统一作「齿木」，并登记进 `terms.md`。

## §54 句 137-54-2-8

- **问题**：**被解释词与父层不一致（必改）** — 黑体译「我以那种」，父层 171-72-13-27 此处作「我刚证得正觉时所安住的那种住法」，父层是意译，没有「我以那种」这个字串，对应关系断了。
- **问题**：释义失效 — 原文 `yena svāhanti yena so ahaṃ` 是**拆连声**（svāhaṃ = so + ahaṃ）。译文「就是“以那种（住法），我”（yena so ahaṃ）」既没说明这是拆词，又把巴利原词直接塞进正文（`style.md` 第三节：不显示巴利原文，夹注只用于术语首次出现），读者看到的是一句同义反复。
- **建议**：改为「**我……所安住的那种（住法）**，这里的 svāhaṃ 是 so 与 ahaṃ 的连声，意思是“那样的我”。」——拆词类注解保留巴利形式是必要例外，但必须点明「是……的连声」。黑体部分需与 harmonize 阶段一并定夺：或改本层向父层靠拢，或在父层留出「那种……我」的可对应字串。

## §54 句 137-54-39-42 / 137-54-43-52

- **问题**：可读性与主语 — 「他是针对这全部——才说“依其中的一部分安住”。」破折号跨句衔接生硬，「这全部」偏生。
- **建议**：「世尊是针对上面这一切，才说“依其中的一部分安住”的。」（引文保持与父层逐字一致）

## §54 句 137-54-53-80

- **问题**：句式冗余 — 「因为世尊在……之内，就像……那样安住；**世尊也正是这样**，把五蕴……而安住。」主句主语出现两次、「安住」出现两次；原文 `yathā nāma … vihareyya, evameva … vihāsi` 的喻依/喻体结构在中文里不必两边都带主语。
- **建议**：「因为世尊在刚证得正觉的四十九天之内，把五蕴不留一分地整体思察、观察而安住，就像一位刚登上王位的国王，为了查看自己财富的精华，叫人一间间打开库房，一一察看金、银、珍珠、宝石等珍宝那样。」
- **问题**：译词 — `nippadese katvā` 译「毫无遗漏地全部」丢了与 padesa 的反义对照（见跨段一致性）。

## §55 句 137-55-2-45

- **问题**：同语反复 — 「缘的一部分，就以触为缘的受而言是缘的一部分」，padesa 与 ekadesa 同译所致。
- **建议**：按跨段一致性的分工改为「诸缘的一部分，就以触为缘的受而言，是缘中的一分」；其余五项（法处、法界、苦谛、禅支、名）同法处理。
- **问题**：增译 — `dvādasāyatanāni nippadesāneva katvā vihāsi` 原文无「观察」，译文补出「全部观察而安住」。承上文语境可以接受，但与同段末尾的 `paccavekkhanto vihāsi` 撞车。
- **建议**：首句作「把十二处整体无余地纳入而安住」。

## §55 句 137-55-46-56

- **问题**：句法 — 原文两个动作是 `kusalādidhamme nippadese katvā`（把善法等诸法作成无余）＋ `anantanayāni satta pakaraṇāni paccavekkhanto`（观察义理无穷的七部论）。译文「毫无遗漏地全部观察，观察了……」把前一个动作也译成「观察」，「观察」连用两次。
- **建议**：「因为在刚证得正觉的四十九天之内，他把善法等诸法整体无余地纳入，观察了义理方法无穷无尽的七部论而安住。」
- **问题**：术语 — 「七部论书」传统作「七部论」（阿毗达摩七论）。
- **建议**：首次出现作「七部论（阿毗达摩七论）」。

## §55 句 137-55-57-65

- **问题**：术语首出无注 — `vedanāttika`「受的三法」指论母中「乐受、苦受、不苦不乐受」三法聚，读者难以索解。
- **建议**：「也就是受三法（乐受、苦受、不苦不乐受这一组三法）」，并登记进 `terms.md`。

## §55 句 137-55-66-75

- **问题**：译词 — `tasmiṃ tasmiṃ ṭhāne` 的 ṭhāna 指上文一一列举的各个项目（蕴、处、界、谛……），译「场合」偏向时空义。
- **建议**：「在上面所说的每一个项目上，各种住等至都是凭受的力量而生起的。」
