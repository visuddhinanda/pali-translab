## 理由

**基准缺失（先行交代）**：本次只注入了本文（mūla）层的巴利原文与译文，**没有义注（aṭṭhakathā）、也没有 nissaya**。方法文档要求「义注定释义、nissaya 定词法」，两者皆缺，本次评估降级为「巴利原文 + 术语表 + 风格文件」三项对照。因此：

- 信心指数据此压到 68。若需要出版级验收结论，应补齐这 11 段的义注与 nissaya 后重评。

**准确性**：本段是 Saccasaṃyutta 的三部短经，句式高度公式化，译文的主谓宾判断、四谛名目、`netaṃ ṭhānaṃ vijjati`（「这样的情形是不可能有的」）都处理正确，省略号 `…pe…` 的补足位置与原文一致，未见漏译或凭空多译的整句。扣分集中在两处系统性处理：`Tasmātiha` 的 `iha` 被实译为处所「在这里」；`netaṃ … yaṃ samaṇena gotamena desitaṃ` 被改写成「A 并不是真正的 A」的同语反复句式，原文的否定对象（「沙门乔达摩所宣说的那个」）在汉语里被同时放进了主语和谓语。

**风格符合度**：无文言虚词、无文言句式，未出现 `knowledge/style.md` 第一节禁例表中的任何一项；标点全角、引号统一用 “” ‘’，`zh` 字段内无 ASCII 引号，JSON 安全无隐患；`samaṇa` 首次出现夹注巴利原词、其后只用汉译，符合术语策略。扣分主要是几处不够自然的汉语：`avijjāgato / vijjāgato` 译成「到了无明」「到了明」，「明」单字作名词又跟在「到了」后面，读起来不成词；`aññāṇaṃ / ñāṇaṃ` 是名词，被动词化为「不了知 / 了知」后再接「这就叫做无明」，主语与判断项不同类。

### 🟧 error

- `171-2515-2-29`｜导致误解的表达｜片段「所以在这里，对于‘这是苦’应当努力修习」
  - 问题：`Tasmātiha` 的 `iha` 是加强语气的虚词，不指处所；译成「在这里」会被读成「在此处、在这个地方」，普通读者会以为世尊在指某个场所或某段经文。
  - 建议：改为「因此，比丘，你应当努力修习‘这是苦’……」，把 `iha` 并入「因此」不另译。

- `171-2518-2-29`｜导致误解的表达｜片段「所以在这里，对于‘这是苦’应当努力修习」

  - 建议：同上，三经此句应一并改动以保持公式一致。

### 🟨 warning

- `171-2513-47-56`｜整句逻辑表达不规范｜片段「沙门乔达摩所宣说的那个苦第一圣谛，并不是真正的苦第一圣谛」
  - 问题：原文是 `netaṃ … ariyasaccaṃ yaṃ samaṇena gotamena desitaṃ`——否定的是「沙门乔达摩所宣说的那个」；译文把这个限定语挪到主语位置，又在谓语里补出「真正的」，结果成了「A 并不是真正的 A」的同语反复，汉语读者难以抓住否定的落点。
  - 建议：改为「沙门乔达摩所宣说的，并不是苦第一圣谛。」补出的「真正的」可以删去。

- `171-2513-108-118`｜整句逻辑表达不规范｜片段「沙门乔达摩所宣说的那个趣向苦灭的道第四圣谛，并不是真正的趣向苦灭的道第四圣谛」

- `171-2514-49-58`｜整句逻辑表达不规范｜片段「沙门乔达摩所宣说的那个苦第一圣谛，并不是真正的苦第一圣谛」

### 🟦 suggestion

- `171-2517-42-68`｜语言表达不够流畅｜片段「对苦不了知，对苦的生起不了知」
  - 问题：`aññāṇa` 是名词（无知），译文动词化为「不了知」后，与后文「这就叫做无明」形成「动词短语＝名词」的判断句，主语与判断项不同类。
  - 建议：改为「对苦的无知，对苦的生起的无知……」；若嫌拗口，可作「不了知苦、不了知苦的生起……这种无知就叫做无明」。

- `171-2520-57-84`｜语言风格不统一｜片段「对苦了知，对苦的生起了知」
  - 问题：同上，`ñāṇaṃ`（智／知）被动词化；且与 2517 的处理须同步，否则明／无明两经对读时不对称。
  - 建议：与 2517 一并改为名词性结构（「对苦的智」或「了知苦……这种智就叫做明」）。

- `171-2513-47-56`｜该使用而没有使用术语标记｜片段「沙门乔达摩」
  - 问题：`Gotama` 取「乔达摩」，南传汉译传统多作「瞿昙」（尤其在外道称呼佛陀的语境里，「沙门瞿昙」是固定搭配）。两种译法都有依据，但 `knowledge/terms.md` 未登记，属未定译名。
  - 建议：定案后补进 `terms.md`；若沿用「乔达摩」，建议首次出现夹注巴利原词「沙门乔达摩（samaṇa Gotama）」。

- `171-2511-2-4`｜不常用术语编写注释或者百科｜片段「第二持经」
  - 问题：`Dhāraṇa` 在本经语境是「受持、记持（所闻之法）」，「持经」二字过简，读者难以从标题看出经义；且经文内 `dhāreti` 一律译「记住」，标题却用「持」，标题与正文用词不呼应。
  - 建议：作「第二受持经」或「第二记持经」，并加一条简注说明本经讲如何受持四圣谛。

- `171-2517-2-13`｜代词指代可能不够明确｜片段「那位比丘坐在一旁」
  - 问题：无明经开头承前省略了「有一位比丘来到世尊处、礼敬后坐在一旁」的完整套语（巴利原文即如此省略），「那位比丘」骤然出现，脱离前一经单读时无所指。对照 `171-2520-2-13` 有完整套语，两经落差明显。
  - 建议：加译者脚注说明此处依例省略了趋近礼敬的套语，或在「那位比丘」后补注「即前经中的那位比丘」。

- `171-2513-57-73`｜语言表达不够流畅｜片段「另外建立一个苦的第一圣谛」
  - 问题：`paññapessāmi`（`paññāpeti`）侧重「宣示、施设、使人知」，「建立」偏向 construct，语义略有偏移；此句在本段出现四次，一改则四处同改。
  - 建议：改为「另行宣说一个苦的第一圣谛」或「另立一个苦的第一圣谛加以宣示」。

- `171-2517-14-25`｜语言表达不够流畅｜片段「大德，人们说‘无明、无明’。」
  - 问题：`vuccati` 是被动式，译文补出施事「人们」，原文并无；style 第六节有「不擅自补足省略主语」之规。
  - 建议：改为「大德，常说到‘无明、无明’。」或「大德，所谓‘无明、无明’……」。
