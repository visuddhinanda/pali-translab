- `137-379`、`137-381` 大量被解释词（**大小便时** / **行走** / **站立** / **坐着** / **睡眠** / **醒觉** / **说话** / **沉默**）是引自本文的黑体 lemma，**「与父层逐字同译」这条硬约束本轮无法核对**——若本文层译作「行时／住时／坐时／卧时」等，此处需回头统一。这是信心分压到 70 的主要原因，不是译文本身的扣分项。
- 涉及《清净道论》食厌想十相的内容（`137-378-2-28`）按 Vism 1.294 段的通行释义核对。

**准确性**：绝大多数长句的句法骨架判断正确，尤其 `137-377-58-75` 那串「下齿为臼／舌为手／上齿为杵」的比喻同位结构、`137-380-15-39` 两个 yathā 明喻的对称，都译对了，没有主谓宾级别的误判，无 fatal。扣分集中在一处与注释书释义不符（`āsayato` 译作「分泌」），以及具格 + 不及物动词（`vāyodhātuyā ... pavisati` / `tejodhātuyā ... paccati`）被改写成「界」作施事主语的句法角色偏移——意思不至误解，但与紧邻的 `vāyodhātuvaseneva tiṭṭhati`（保留食物作主语）处理不一致。

**风格符合度**：现代书面汉语的要求执行得好，没有「此中／故为／彼等／于…之际」一类文言腔；`akāmatāya` 译「不由自主地」、`chaḍḍentassa` 译「倒掉」都是现代词。全角标点、全角弯引号 “”，`zh` 字段内无 ASCII 引号，符合硬约束。仅「适宜之处」一处带文言虚词残留。

**一致性**：`Abbhantare attā nāma koci ... natthi` 在 `137-377-2-27` 与 `137-380-2-14` 两处译法完全一致，`cittakiriyavāyodhātuvipphārena` 统一译「心的作用所生起的风界的扩散」，`evaṃ pavattapaṭisaṅkhānavasena ... veditabbaṃ` 三处收束句式统一，跨段漂移控制良好。失分点是四种正知的命名体例不齐（三个带「的」、一个不带），以及上述界作主语与否的摇摆。

## 问题清单

### 🟧 error
- `137-378-2-28`｜义理或用词与注释书不符｜片段「从分泌（āsaya）」
  - 问题：`āsaya` 在《清净道论》食厌想十相中不指「分泌」，而指食物入体后所到的**所依处**（胆、痰、血、脓四种 āsaya 之一），因此可厌；译作「分泌」把方位义读成了生理过程义，且与下一项「从贮藏（nidhāna）」的区分被抹平。
  - 建议：改为「从所依处（āsaya，指食物落入胆、痰、血、脓等积聚处）」，并在夹注中点出与「贮藏」（存于胃中）的分别。

### 🟨 warning
- `137-377-58-75`｜整句逻辑表达不规范｜片段「只是风界把它送了进去」
  - 问题：`vāyodhātuyāva pavisati` 中 `pavisati` 是不及物动词，主语仍是那口食团，`vāyodhātuyā` 是具格「由于风界」；译文改以风界为施事、食团为宾语，句法角色发生偏移。与同组 `137-377-76-88`「只是凭着风界它才停留在那里」（保留食物作主语）体例不一。
  - 建议：统一为「只是靠着风界，它才进去」。
- `137-377-89-102`｜整句逻辑表达不规范｜片段「只是火界把它煮熟」
  - 问题：同上，`tejodhātuyāva paccati` 的 `paccati` 是「被煮熟」，主语是食物；本组四句（进入／停留／煮熟／排出）原文刻意用「具格 + 不及物」表达「无人作，唯界故尔」，译文三种句式混用，削弱了这层修辞。
  - 建议：改为「只是靠着火界，它才熟」，并与上一条一起校齐整组句式（`nīharati` 一句原文确以风界为主语，可保留及物译法）。
- `137-377-48-57`｜代词指代不明确｜片段「这样，在那里，」
  - 问题：`tattha` 承上指**口中**，译文「在那里」在中文里失去回指对象，读者易误以为指钵中或上一句的颌骨。
  - 建议：明确译出「在口腔里」。
- `137-377-118-135`｜关键词语意不明确｜片段「又把它送过去」
  - 问题：`vītiharati` 与前面的 `atiharati` 构成「搬入／转运」一对，译作「送进来／送过去」后两者的分工完全看不出来，「送过去」指向何处不明。
  - 建议：区分为「把食物搬进来，又在口中来回移送」之类，让两个动作各有所指。
- `137-380-15-39`｜关键词语意不明确，二意场合没有注释｜片段「积存在熟脏和膀胱里的大小便」
  - 问题：「熟脏」（pakkāsaya）是南传论书的专门译名，一般读者无法理解，且与「生脏」成对才可辨义，此处首次出现无任何夹注。
  - 建议：首次出现处夹注，如「熟脏（pakkāsaya，即已消化物所在的大肠）」。
- `137-377-160-169`｜关键词语意不明确，二意场合没有注释｜片段「识界依照各处恰当的加行而现起」
  - 问题：`sammāpayoga` 译「加行」是术语化处理，但「加行」在汉传语境另有专义，此处指的只是「恰当的运作／努力」，未夹注易生歧解；同句内「而现起」与紧接的「依着现起的省察」两个「现起」所指不同层次，叠用后指代模糊。
  - 建议：正文改为「识界随处依着恰当的运作而起作用」，术语需保留则夹注巴利原词；后半改「依着对这一过程的省察」以区分。
- `137-379-59-68`｜文言语体｜片段「这就是这里的适宜之处」
  - 问题：「之处」保留了文言虚词「之」，与 style.md 第一节禁例表（「之」作文言虚词时须改）相悖；同段其余收束句均已用「这就是这里的意思」这类现代说法，体例也不齐。
  - 建议：改为「这就是这里说的适宜」。

### 🟦 suggestion
- `137-379-40-45`｜语言风格不统一｜片段「有利益的正知」
  - 问题：四种 sampajañña 的命名体例不一致——「有利益的正知」「适宜的正知」「行处的正知」三者带「的」，而「不迷惑正知」不带；且前三者是意译展开，后者是黏合式术语。
  - 建议：统一为「有益正知／适宜正知／行处正知／无痴正知」，或统一都作「……的正知」，全书一律。
- `137-377-58-75`｜语言表达不够流畅｜片段「被唾液这样的水浸湿」
  - 问题：`kheḷaudaka` 是「唾液之水」的偏正复合，不是本句比喻系列（臼／手／杵）中的一员，译成「这样的水」把它拉进比喻同位结构，读起来突兀。
  - 建议：改为「被唾液浸湿」或「被口中的唾液润湿」。
- `137-381-33-61`｜该使用而没有使用术语标记｜片段「色法与非色法」
  - 问题：`rūpārūpadhammā` 中的「非色法」即名法（心、心所），直译后一般读者难以把握，本段是全文唯一交代观照对象的地方，值得夹注。
  - 建议：首次出现处作「色法与非色法（即名法，指心与心所）」。
- `137-382-2-33`｜复杂的嵌套句整句语言逻辑理解困难｜片段「或者一边作意业处」
  - 问题：「一边……或者一边……或者一边……站立了很久，之后坐下」这一串连动读起来松散，三个「一边」与主句「站立了很久」的时间关系不够清楚；「作意业处」术语未注。
  - 建议：改为「有人诵读，或者解答问题，或者思惟业处，就这样站了很久，之后坐下」，并为「业处」补一处夹注。
- `137-379-46-58`｜语言表达不够流畅｜片段「恶名会增长」
  - 问题：`ayaso vaḍḍhati` 直译为「恶名增长」，中文里「恶名」与「增长」搭配生硬。
  - 建议：改为「名声会变坏」或「会招来恶名」。
