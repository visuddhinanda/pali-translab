# Review — 171:219-237（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§229–235 有 nissaya；§219–228、§236–237 无，这些段只参与跨段一致性核查）

## 跨段一致性

- **ariyo aṭṭhaṅgiko maggo**：§220 译“八支圣道”，§224、§231、§235、§237 译“圣八正道” → 建议统一为“圣八正道”。依据：术语表 aṭṭhaṅgika magga = 八正道，ariya 加“圣”；本 chunk 多数段也是这个译法。§220 全段 5 处需改。
- **bahulīkaroti / bahulīkaronto**：§220 译“多多修习”，§224 译“多修习”，§231、§235、§237 译“多加修习” → 建议统一为“多加修习”。nissaya 也支持这个译法：`ဗဟုလီကရောန္တော= အကြိမ်များစွာပြုသော`（反复多次地做）。
- **ninnā / poṇā / pabbhārā（河流譬喻与涅槃合法）**：河流句译“朝东低倾、朝东**流去**、朝东**倾注**”，涅槃句译“朝涅槃低倾、**倾向**涅槃、**趣入**涅槃”。同一组三个词在喻体和合法里译法不同，譬喻的对应关系就断了。nissaya 两边用的是同一组缅文动词：`ပါစီနနိန္နာ= အရှေ့ဘက်သို့ညွတ်သည်`／`နိဗ္ဗာနနိန္နော= နိဗ္ဗာန်သို့ညွတ်သည်`（弯向），`…ပေါဏာ= …ကိုင်းသည်`（倾斜），`…ပဗ္ဘာရာ= …ရှိုင်းသည်`（斜下、倾下）。另外，“流去”“倾注”“趣入”都添加了原词没有的“流动、进入”义。
  - 建议两边用同一组词，例如“朝东低倾、朝东倾斜、朝东斜下”／“朝涅槃低倾、朝涅槃倾斜、朝涅槃斜下”。
  - 涉及 §231、§233、§235、§237 所有河流句和涅槃句，§236 标题也应随之核对。
- **rāga/dosa/mohavinayapariyosāna**：§220 译“以调伏贪欲／瞋恨／愚痴为归结”，§224 译“以调伏贪／瞋／痴为终极” → 两段词形与语序都要统一。建议用“以调伏贪为归结、以调伏瞋为归结、以调伏痴为归结”，修饰语放在“正见／正定”之前（与 §231 的 vivekanissita 句式一致）。
- **…pe…**：§220、§222 译“……略……”，§224 译“……（中略）……”，§231、§233、§235、§237 译“……乃至……” → 建议全书统一为一种，推荐“……乃至……”（本 chunk 多数）。
- **pāṭikaṅkhaṃ**：§220 译“可以期待这样的事”，§224 译“这是可以预期的” → 建议统一。
- **-sampadā**：§222 译“戒具足、意欲具足、自身具足、见具足、不放逸具足”，§223/§224 译“正确思考的成就”，§227 摄颂译“自身的成就” → 同一复合词结构，建议统一为“××具足”，即“如理作意具足”或“正确思考具足”。
- **chanda**：§222 译“意欲”，§227 译“意愿” → 统一为“意欲”。
- **经末题记**：§220 “第一经。”、§222 “第六经。”、§224 “第七经。”，§231、§233、§235、§237 “第一经终。”／“第五经终。”／“第六经终。” → 建议统一，推荐去掉“终”或全部加“终”，二选一。
- **经号数字体例**：§220 “八四、”、§222 “八五至八九、”，§224 “九十、”、§231 “九十一、”、§233 “九十二至九十五、” → 统一为“八十四、”“八十五至八十九、”这类完整写法。
- **peyyāla**：§225 “一法**重复**品”，§229 “恒河**广说**品” → 同一术语译法不一，建议统一。
- **河名音译体例**：yamunā 译“亚穆那河”（现代音译），aciravatī 译“阿夷罗跋提河”（传统译名）→ 体例混用。依 style.md，常见专名优先传统汉译，yamunā 建议改为“阎牟那河”；sarabhū、mahī 也一并按传统译名核定。
- **Idha 漏译**：§220、§224 都译出“在这里”，§231、§235、§237 的同一句式都漏了（详见下文逐句）。

## §231 句 171-231-9-20
- **问题**：词义 — `ပါစီနပေါဏာ= အရှေ့ဘက်သို့ကိုင်းသည်` 是“向东倾斜”，不是“流去”；`ပါစိနပဗ္ဘာရာ= အရှေ့ဘက်သို့ရှိုင်းသည်` 是“向东斜下”，“倾注”带出了倒水、灌入的意思。三个词都是表示地势走向的形容性谓语，nissaya 以 `ဟောတိ သေယျာထာပိ= ဖြစ်သကဲ့သို့`（是……那样）收句。
- **建议**：“比丘们，就像恒河朝东低倾、朝东倾斜、朝东斜下；”（与合法句同步统一，见跨段一致性）

## §231 句 171-231-21-39
- **问题**：词义 — `နိဗ္ဗာနပဗ္ဘာရော= နိဗ္ဗာန်သို့ရှိုင်းသည်`（斜下向涅槃）被译成“趣入涅槃”，“入”义过重，而且与喻体用词不对应。`နိဗ္ဗာနပေါဏော= နိဗ္ဗာန်သို့ကိုင်းသည်` 译“倾向涅槃”，与喻体“朝东流去”也不对应。
- **建议**：“……的比丘，也朝涅槃低倾、朝涅槃倾斜、朝涅槃斜下。”

## §231 句 171-231-40-58
- **问题**：同上，nibbānapoṇo / nibbānapabbhāro 的译法要随之统一。
- **建议**：“……是怎样朝涅槃低倾、朝涅槃倾斜、朝涅槃斜下的呢？”

## §231 句 171-231-59-79
- **问题**：漏译 — `ဣဓ= ဤသာသနာတော်၌သာလျှင်`（就在这个教法里），译文没有译出 Idha。§220、§224 同一句式都有“在这里”。
- **建议**：句首补“比丘们，在这里，比丘修习……”
- **参考**：vossaggapariṇāmiṃ 的主释是 `ကိလေသာတို့ကိုပယ်စွန့်၍ နိဗ္ဗာန်သို့ကိုင်းညွတ်သော`（舍弃烦恼而倾向涅槃）；异释是 `…ရင့်ကျက်ဆဲရင့်ကျက်ပြီးဖြစ်သော`（为舍离而正在成熟、已经成熟）。“趣向舍离”可以保留；按 style.md 第四节，异释可以作为脚注备列。

## §231 句 171-231-80-101

## §233 句 171-233-6-17
- **问题**：词义 — 同 §231 句 9-20，`ပါစီနပေါဏာ= …ကိုင်းသည်`、`ပါစီနပဗ္ဘာရာ= …ရှိုင်းသည်` 不是“流去”“倾注”。另外 yamunā 的音译见跨段一致性。

## §235 句 171-235-2-34
- **问题**：词义 — pācīnapoṇā / pācīnapabbhārā 的译法同上。nissaya 用 `…ကိုင်းကုန်သည်`、`…ရှိုင်းကုန်သည်`（复数），主语是 `သဗ္ဗာ= အလုံးစုံကုန်သော。တာ= ထိုမြစ်တို့သည်`，译文“它们全都”与此相合，无需改动。
- **建议**：“……它们全都朝东低倾、朝东倾斜、朝东斜下；”
