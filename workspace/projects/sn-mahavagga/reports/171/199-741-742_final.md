## 理由

**基准缺失（影响信心）**：本次只注入了巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。ṭīkā 层的核心校验点——「黑体被解释词与父层（义注）逐字同译」——无法对照父层文本核实，只能从巴利词形本身反推；nissaya 的格/句法核对也无从做起。因此下列判断全部基于巴利内证，准确性分数与问题清单在拿到义注后应复核。

**准确性**：句法骨架（「因为 X，所以是 Y；所以义注说了 Z」这一 ṭīkā 定式）整体把握正确，`742-39-54`、`742-60-73` 的因果层次都译出来了，`742-83-87` 干净准确。主要失分集中在**黑体被解释词（lemma）的处理**：共 3 处把 lemma 译成了同句里义注引语的意思，等于把「被解释的词」和「解释它的词」译成同一件事，ṭīkā 的训诂结构整段塌掉——

- `742-2-27`：lemma 是 `Na kho panetaṃ`（这并不是…），译成「我们并没有」，把后半句才引出的 `amhehi` 提前塞进 lemma；
- `742-39-54`：lemma 是 `māriso`，译成「被死亡系住的」，而这正是义注引语 `maraṇapaṭibaddho` 的意思，`marissati → māriso` 的词源推导因此不成立；
- `742-55-59`：lemma 是 `adhimuccehi`（决意、倾心），译成「安放」，而「安置」是下一句义注引语 `ṭhapehi` 的意思。

另有一处独立词义错误：`742-2-27` 把 `no` 当成否定词译作「没有」，但此处 `no` 是等于 `amhehi` 的附着人称代词（「由我们」），ṭīkā 正是在讲这件事，译文因此自相矛盾。

**风格符合度**：现代书面汉语基本达标，未见「此中／故为／彼等／是故」类文言硬伤；全角标点与全角引号使用正确，`zh` 字段内无 ASCII 引号，JSON 安全。扣分项是 `742-55-59` 的「（读作 adhimuccehi）」——「读作」是异读注记的写法，这里并非异读，夹注体例应按 style.md 第三节「术语首次出现用圆括号附巴利原词」处理；另有一两处半书面化的「借着…而得安心」。

**一致性**：三层同译要求无法验证；chunk 内部的一致性问题即上述 lemma/引语互串——「安放」与「安置」、「被死亡系住的」与「被死亡束缚住的人」这两对，读者无法判断是同一个词还是两个词。译文中未发现残留的工作标记（候选、待定、TODO）。

## 问题清单

### 🟧 error
- `199-742-2-27`｜错译（词义）｜片段「“没有”（no）一词含有“我们”（amhehi）的意思」
  - 问题：`no` 在此不是否定词，而是等于 `amhehi` 的附着人称代词（「由我们／我们的」）。译成「“没有”一词含有“我们”的意思」既错解词义，也使整句读不通。
  - 建议：按「而 `no` 一词的意思就是“我们（amhehi）”」之类处理，明确它是代词而非否定词。
- `199-742-2-27`｜错误多译 / 被解释词与父层不同译｜片段「**我们并没有**，就是并没有这个」
  - 问题：黑体 lemma 是 `Na kho panetaṃ`（这并不是…），其中并无「我们」；「我们」来自后半句对 `no` 的解释。lemma 提前掺入 `amhehi`，与紧随的解语「就是并没有这个」重复且错位。
  - 建议：lemma 依父层原文译出（如「**而这并不是**」），「我们」留到 `no` 的解释处再出现。拿到义注后须与义注同一词条逐字比对。
- `199-742-39-54`｜错译（词义）｜片段「**被死亡系住的**」
  - 问题：黑体 lemma 是 `māriso`，ṭīkā 的论证是「因为他将死（marissati），所以叫 māriso」；「被死亡系住的」是义注引语 `maraṇapaṭibaddho` 的意思，译在此处使词源推导变成同语反复，且与句末「**被死亡束缚住的人**」撞车。
  - 建议：lemma 保留巴利词形或直译其构词义（如「**māriso（将死者）**」），把「被死亡系住／束缚」留给句末的义注引语。
- `199-742-55-59`｜错译（词义）｜片段「**安放**（读作 adhimuccehi）」
  - 问题：`adhimuccehi` 是「决意、倾心」（与下文解语 `adhimuttiṃ uppādehi` 同根），不是「安放」；「安放／安置」对应的是下一句义注引语 `ṭhapehi`。两句的 lemma 因此无从区分。
  - 建议：lemma 按「**倾心／决意**（adhimuccehi）」处理，与 `742-60-73` 的「**安置**」区别开。

### 🟨 warning
- `199-742-28-38`｜代词指代不明确｜片段「因为人们借着这些法而得安心」
  - 问题：「这些法」在本句内无先行词，且原文只是工具格的 `etehi`（隐含），读者不知所指。
  - 建议：或依上文补出所指（如「借着这些所说的法」），或改为不带指示词的说法（「凭这些而感到安心」）。
- `199-742-55-59`｜夹注格式不规范（不该使用标记处使用了标记）｜片段「（读作 adhimuccehi）」
  - 问题：「读作」是异读／校勘注记的写法，此处并非异读，只是标出被解释的巴利词。与 style.md「术语首次出现用圆括号附巴利原词」的体例不合。
  - 建议：改为「**倾心**（adhimuccehi）」，去掉「读作」。
- `199-742-60-73`｜整句逻辑表达不规范｜片段「就是心那样的趣向、就是安置」
  - 问题：两个「就是」并列，`paṇidhāna` 与 `ṭhapana` 的同位关系被切成两段并列语，读者难以判断是两件事还是一件事的两种说法；「趣向」一词也偏生硬。
  - 建议：合成一句同位表述，如「就是把心这样地定向、安置下来」。
- `199-742-74-77`｜关键词语意不明确、无注释｜片段「前分的功德」
  - 问题：「前分」（pubbabhāga）是专门术语，未加任何说明，混合受众中的一般读者无法理解。
  - 建议：首次出现时附简注或改为可读表述，如「前分（即证果之前的阶段）的功德」。
- `199-742-78-82`｜被解释词句式被改写｜片段「**是无可计量的**」
  - 问题：lemma 是 `Pamāṇaṃ nāma natthi`（并没有所谓的限量），名词否定句被改写成判断句。ṭīkā 黑体须与义注原句逐字同形，改写后无法与父层字面对应。
  - 建议：改为「**并没有所谓的限量**」一类与原句结构一致的译法，并在拿到义注后核对。
