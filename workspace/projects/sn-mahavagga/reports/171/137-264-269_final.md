## 理由

**基准缺失说明**：本次评估对象本身就是义注层（book 137，`1._Āhārasuttavaṇṇanā`），没有更高一层的释义标准可比对；本次也未注入 nissaya 单元。因此词级格/句法角色的核对只能依据巴利原文本身与注释书惯用体例（Vism / 各部注对五种过食、五盖对治六法、三道断惑的定型说法），信心指数据此下调。

**准确性**：18 句逐句核对，未发现漏译、错误多译或主谓宾判断错误。定型内容处理正确——五种过食（āhārahatthaka / bhuttavamitaka / tatravaṭṭaka / alaṃsāṭaka / kākamāsaka）译法与注释书传统解释一致；三道断惑的分派（昏沉睡眠→阿罗汉道，掉举→阿罗汉道、追悔→不还道，疑→入流道）与教理完全相符；`catupañcaālopaokāsaṃ ṭhapetvā`「留出四五口的余地」、`ciṇṇavasībhāva`「已修习到熟练自在」等难点都译到位。扣分点集中在两处释义偏软：`atibhojane nimittaggāho`「对过量饮食取相」未把「取相」所指（认清食量的限度）传达出来，读者无从索解；`desanaṃ tīhi bhavehi nivattetvā`「让教说不停留在三有」把「使教说从三有转出」的方向性动作弱化为状态描述，义理不误但力度失真。

**风格**：语体完全是现代书面汉语，禁例表所列文言虚词与句式（之/其/乃/便/即/遂、…者…也、于…之际、答以…）无一出现，`tiādi vuttatthameva` 一律译作「意思和前面说过的一样」而非「如前所说」，处理得当。`一部乃至五部尼柯耶` 中的「乃至」对应原文 `…pe…` 省略号，且属现代书面语常用词，不计入文言。标点全部全角，引号统一为 “”，无 ASCII 引号，JSON 安全。译文中无任何候选/待定标记。扣分来自被解释词的粗体切分紧贴成串（`**有****不乐**`、`**有****心****的止息**`），以及个别长句（265-2-40 一句近 130 字）对读者不友好。

**一致性**：三段六法清单（264 / 266 / 268）措辞对齐，清单条目与 265 / 267 / 269 的展开互相呼应，逐句重复的 `…ssāpi … pahīyati` 统一处理为「…的人也能舍断」，节奏稳定。扣分点：同一词根 `adhimokkha` / `adhimutta` 分别译作「决信」与「胜解」；夹注巴利原词的取舍不齐（阿罗汉道、入流道、尼柯耶、头陀支有夹注，首次出现的「不还道」没有）；清单里的「多向人请教」在展开段变成「多多请教」。

## 问题清单

### 🟨 warning
- `137-264-8-29`｜关键词语意不明确｜片段「对过量饮食取相」
  - 问题：「取相」是术语式直译，265 段展开后读者才知道指的是认清「过量」这条界线；清单条目独立出现时含义不明，且「对…取相」的搭配在现代汉语里不成立。
  - 建议：改为「认清过量饮食的界限」一类说法，或保留「取相」但补出所指。

- `137-269-70-81`｜整句逻辑表达不规范｜片段「让教说不停留在三有（tayo bhavā）」
  - 问题：`nivattetvā` 是「使…从…转出、折回」的动作，原句意为世尊把教说从三有中引出、以阿罗汉果结顶；「不停留在三有」只描述状态，方向性与「转出→结顶」的连贯逻辑被削弱。
  - 建议：改为「把教说从三有中引出（转离三有）」，与后半「以阿罗汉果作为顶点」构成完整动作链。

- `137-268-7-27`｜关键词语意不明确｜片段「多有决信」
  - 问题：`adhimokkha` 通行汉译为「胜解」，「决信」非标准术语，读者难以对应；同一词根在 `137-269-2-45` 又译作「胜解」（「以信为胜解」），前后不统一。
  - 建议：统一为「胜解」，或在此处首次出现时夹注巴利原词并与 269 段的译法对齐。

### 🟦 suggestion
- `137-264-2-7`｜语言表达不够流畅｜片段「**有****不乐**」
  - 问题：被解释词按词切分加粗后紧连成串，中间无停顿，读起来像断裂的词块。
  - 建议：在保持与本文层逐字同译的前提下，把相邻粗体合并为一个连续片段（如「**有不乐**」）。

- `137-266-2-8`｜语言表达不够流畅｜片段「**有****心****的止息**」
  - 问题：同上，三段粗体紧贴，且「有／心／的止息」被割裂成三块。
  - 建议：合并为「**有心的止息**」。

- `137-265-2-40`｜复杂的嵌套句整句语言逻辑理解困难｜片段「因为吃了要人伸手来拉才起得来的量、吃到要呕吐出来的量」
  - 问题：全句一气呵成近 130 字，五个并列长定语后接「这样吃完以后」再转折再收束，读者需回读才能理清主干。
  - 建议：在「昏沉睡眠就像大象压下来一样袭来」后断句，把转折句和结论句独立成句。

- `137-267-2-44`｜语言表达不够流畅｜片段「在律的制定上已修习到熟练自在而通晓律的人」
  - 问题：`vinayapaññatti` 指律中制定的学处条文，「律的制定上」易被读成「制定律这件事」；后半「而通晓律的」与前半语义重叠，句子头重。
  - 建议：改为「对律所制定的学处已修习得熟练自在、因而通晓律的人」。

- `137-267-58-73`｜该使用而没有使用术语标记｜片段「追悔要靠不还道」
  - 问题：同段的「阿罗汉道（arahattamagga）」与 `137-269-59-69` 的「入流道（sotāpattimagga）」都夹注了巴利原词，唯独首次出现的「不还道」没有，夹注体例不齐。
  - 建议：补为「不还道（anāgāmimagga）」。

- `137-269-2-45`｜语言风格不统一｜片段「以信为胜解的婆迦离长老」
  - 问题：`saddhādhimutta` 是「信解第一」的定型称号，「以信为胜解」是逐词硬译，读来生硬；`Vakkali` 通行汉译为「跋迦梨」，「婆迦离」属非常见音译。
  - 建议：改为「以信解著称的跋迦梨长老」，并把译名登记进 `terms.md`。

- `137-266-9-28`｜语言风格不统一｜片段「多向人请教」
  - 问题：清单条目作「多向人请教」，`137-267-2-44` 与 `137-269-2-45` 展开处作「多多请教」，同一 `paripucchakatā` 三处两种说法。
  - 建议：统一为「多多请教」或「常向人请教」。
