# Review — 171:1554-1566（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§1560 后两句、§1561 正文、§1563 全段、§1564 前两句无 nissaya，已略过）

## 跨段一致性

- **四神足定型句**（chandasamādhippadhānasaṅkhārasamannāgataṃ iddhipādaṃ …）：§1555、§1558 译“具备依欲而生起的定与勤行的神足”，§1561、§1564、§1566 译“具备欲求定和精勤行的神足” → 本 chunk 内须统一为一种。建议统一为“具备欲定与勤行的神足”这类紧凑式：nissaya 对该复合词只给整体 `= သော`（作定语修饰 iddhipādaṃ），没有展开出“依……而生起”的成分。另外“勤行 / 精勤行”也要二选一。
- **idha**：§1555、§1558 译“在这里”，§1561、§1564、§1566 译“在这法中” → 建议统一为“在这里”（nissaya：`ဣဓ= ၌` 只是处格“于此”）。“这法中”不顺口，也不像现代汉语。
- **pe**：§1555、§1558 译“……略……”，§1561、§1564、§1566 译“……乃至……” → 建议统一，取一种即可。
- **bhāvitā / bhāvitattā bahulīkatattā**：§1555、§1557、§1558 译“修习、多加修习”，§1560、§1561、§1563、§1564、§1566 译“修习、多修” → 建议统一为“修习、多加修习”。
- **atītamaddhānaṃ / anāgatamaddhānaṃ**：§1557、§1558 译“在过去的时代／在未来的时代”，§1560、§1561、§1563、§1564 译“过去世／未来世” → 建议统一。nissaya 为 `အတိတ်အခါ၌`（于过去时），是处格时间状语，两种都可以，但不能并存。
- **iddhi**：§1556–1558 的 iddhipadesa 译“神通的一分”（经题“神通一分经”），§1559–1561 的 samattaṃ iddhiṃ 译“圆满的成就” → 同一个 iddhi 前后分别译成“神通”和“成就”，padesa（一分）与 samatta（圆满）的对照就看不出来了。依据有两条：
  - nissaya 对 iddhipadesa 的括注把它指为道果 `(မဂ် ၃ပါး ဖိုလ် ၄-ပါးတည်း။)`；
  - nissaya 对 samattaṃ iddhiṃ 的括注（转引 ဋ္ဌ.）指为阿罗汉果。
  
  所以这里的 iddhi 不是神变意义上的“神通”。建议两经统一作“成就”：“部分的成就／圆满的成就”，经题相应改为“部分成就经／圆满（成就）经”。
- **主句谓语补出**：§1560、§1561、§1563、§1564 句末补出“才达成的／才证得的”，§1557、§1558 没有补，只说“他们全都是因为……”，句子悬空 → 统一补出（见下方 §1557 条）。
- **catunnaṃ iddhipādānaṃ（无 imesaṃ）**：§1557 译“这四种神足”，§1560、§1563 译“四神足” → 无 ime 的句子统一不加“这”。这样有 imesaṃyeva 的 §1558、§1561、§1564 的“正是这四种”才有对照。
- **samaṇa 夹注**：§1557、§1560 两处都夹注（samaṇa），§1563 起不再出现 → 如果按全书首次出现的原则，§1560 的夹注应删；如果按每经首次出现，则保留。需要定下规则。

## §1557 句 171-1557-2-27 / 171-1557-28-49 / 171-1557-50-69

- **问题**：补出成分 — nissaya 在句末补出被省略的主句谓语 `(အဘိနိပ္ဖါဒေသုံ= ကုန်ပြီ။)`／`(အဘိနိပ္ဖါဒေဿန္တိ= ကုန်လတ္တံ့။)`／`(အဘိနိပ္ဖါဒေန္တိ= ကုန်၏။)`，意思是“他们都是因为修习……而成就的”。`ဘာဝိတတ္တာ= ကြောင့်` 只是原因状语。译文只有“他们全都是因为修习、多加修习了这四种神足”，缺谓语，句子没有收尾。
- **问题**：词级 — 本句 pali 没有 ime，nissaya 是 `စတုန္နံ= ၄-ပါး ကုန်သော`，没有 ဤ。译文多出了“这”。
- **建议**：过去句改为“他们全都是因为修习、多加修习四种神足才成就的”，未来句、现在句分别作“才将成就的／才正在成就的”，或统一作“才成就的”。

## §1558 句 171-1558-29-50 / 171-1558-51-72 / 171-1558-73-97

- **问题**：补出成分 — 与 §1557 相同。nissaya 补出了 `(အဘိနိပ္ဖါဒေသုံ= ကုန်ပြီ။)` 等主句谓语，译文缺。
- **问题**：语序与语体 — “修习、多加修习了正是这四种神足”中，“正是”放在宾语里，属于翻译腔。nissaya 为 `ဣမေသံယေဝ ဣဒ္ဓိပါဒါနံ= တို့ကို`，强调的是“就是这四种”。
- **建议**：改为“他们全都正是因为修习、多加修习这四种神足才成就的”，与 §1561 的句式对齐。

## §1564 句 171-1564-29-56 / 171-1564-57-85 / 171-1564-86-117

- **问题**：词级 — `အဘိညာ= ထူးသောဉာဏ်ဖြင့်`（以殊胜智，具格），`သစ္ဆိကတွာ= မျက်မှောက်ပြု၍`（使之现前、作证）。译文“以证智证知”，两个“证”叠用，sacchikatvā 被译成“证知”，与 abhiññā 混淆。
- **建议**：改为“亲自以证智作证”。
- **问题**：补出成分（轻）— nissaya 补出的主句谓语是 `(ဝိဟရိံသု= ကုန်ပြီ။)`（安住了），译文句末作“才证得的”，换掉了谓语。可以接受，但不如“才这样安住的”贴近原文。可酌改。

## §1566 句 171-1566-17-37

- **问题**：跨段一致性 — 定型句与 §1555 不一致，见上方“跨段一致性”一节的“四神足定型句”“idha”“pe”三条。
- **建议**：按统一后的译法改。

## §1566 句 171-1566-38-46

- **问题**：句法 — nissaya 为 `ဣဒ္ဓိပါဒါ= တို့သည်။ ဣမေ ခေါ စတ္တာရော= ဤ ၄-ပါးတို့တည်း။`，即“诸神足就是这四种”。译文“这就是这四种神足”中“这……这”重复。
- **建议**：改为“比丘们，这些就是四种神足。”

## §1566 句 171-1566-47-67

- **问题**：句法存疑，不必改 — nissaya 把 ti 系在 tathāgato 上（`တထာဂတောတိ= မြတ်စွာဘုရားဟူ၍`），arahaṃ、sammāsambuddho 作它的定语（`သော`），整体读成“被称为‘阿罗汉、正等正觉的如来’”，主语隐含为世尊。底本引号把 tathāgato 放在引语之外作主语，译文是按底本译的，语法上成立。
- **建议**：维持现译，这里只记录分歧。
