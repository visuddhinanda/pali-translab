## 理由

**基准缺失说明**：本次评估未注入义注（aṭṭhakathā）与 nissaya 数据，仅有本文（mūla）巴利原文与译文可比对。因此「义理或用词与注释书不符」「格/句法与 nissaya 冲突」两类问题**无法核查**，准确性一项只能基于原文词法与南传通行释义判断，信心指数据此压低到 72。义注可查后建议重评，重点复核 `amacca`、`ñāti`、`sālohita`、`aveccappasāda`、`nivesetabbā / patiṭṭhāpetabbā` 五处。

**准确性**：主谓宾判断整体正确，未见 fatal 级错误。词覆盖良好，`… pe …`（peyyāla）略写、`Pañcamaṃ / Chaṭṭhaṃ / Sattamaṃ` 结尾标记都照应了。主要扣分在两处：`171-2118-42-44` 所在经中 `ñātī`/`sālohitā` 的译法（「姻亲」对 `ñāti` 有添义之嫌，`ñāti` 通指亲属、亲族，`sālohita` 才是血亲，两者构成「亲族与血亲」的惯用对举，译成「姻亲还是血亲」把 `ñāti` 窄化了）；以及 `171-2121-53-75` 一句把前段 `Dhamme … saṅghe …` 的省略骨架接到了 `samādapetabbā` 系列上，而该经此处原文本身即如此（VRI 排印），译文忠实照录无误，但中文读者会看不出这是与 2121 前半 `siyā … aññathattaṃ` 句式并列的省略——属表达层面而非取义错误，记作 warning。

**风格符合度**：现代书面汉语达标，未发现文言虚词（之/其/乃/便/即/遂）作虚词使用，无「此中/故为/彼等/是故」等禁例，无「于…之际」「答以」类文言句式。全角标点、全角引号使用规范，`zh` 字段内未出现 ASCII 引号，JSON 安全。扣分点为「怜念」一词：`anukampeyyātha` 译作「怜念」偏书面古雅，现代读者可能不解，宜作「悲悯」「关心爱护」一类。

**一致性**：这是本次最主要的扣分项，同一段套语在相邻三经里译法不统一：
- 经六标题「朋友与同僚经」与正文「不论是朋友、伙伴、姻亲还是血亲」中，`amacca` 标题作「同僚」、正文作「伙伴」，同一词两译。
- `samādapetabbā, nivesetabbā, patiṭṭhāpetabbā` 三动词在 `171-2118-45-64` 展开为「劝导…使安住于这净信、确立于这净信」（补出宾语），在 `171-2118-65-85`、`171-2121-53-75` 则作「在…戒上劝导他们、使他们安住、使他们确立」（不补宾语），在 `171-2118-2-41` 作「使他们确立于四种入流支」。虽各自通顺，但同一套语在数行之内三种句式，跨段读来像三个译者。
- `sotāpattiyaṅga` 统一译「入流支」，`aveccappasāda` 统一译「不动摇的净信」，`aññathatta` 统一译「改变」，这几项一致性良好。

`terms.md` 与 `pitfalls.md` 均为空，`term-glossary.jsonl` 未登记 `amacca` / `ñāti` / `sālohita` / `sotāpattiyaṅga` / `aveccappasāda` / `anukampati`。上述分歧定案后应补进术语表，否则后续章节会重复漂移。

## 问题清单

### 🟧 error

- `171-2118-2-41`｜错译（词义）｜片段「不论是朋友、伙伴、姻亲还是血亲」
  - 问题：`ñātī` 意为亲属、亲族（泛指同族亲眷），译作「姻亲」缩窄并改换了词义——姻亲是婚姻关系所结之亲，原词不含此限定。`ñātī vā sālohitā vā` 是巴利惯用对举「亲族与血亲」。
  - 建议：改为「亲属还是血亲」或「亲族还是血亲」；同时确认 `amacca` 的定译（见下条）。待义注可查时复核 `sālohita` 是否另有窄义。

- `171-2120-2-40`｜错译（词义）｜片段「不论是朋友、伙伴、姻亲还是血亲」
  - 问题：同上，`ñātī` 误作「姻亲」。
  - 建议：与 `171-2118-2-41`、`171-2118-86-124`、`171-2121-124-161` 一并统一改正。

- `171-2118-86-124`｜错译（词义）｜片段「不论是朋友、伙伴、姻亲还是血亲」
  - 问题：同上。
  - 建议：同上。

- `171-2121-124-161`｜错译（词义）｜片段「不论是朋友、伙伴、姻亲还是血亲」
  - 问题：同上。
  - 建议：同上。

### 🟨 warning

- `171-2117-2-4`｜语言风格不统一（术语跨段漂移）｜片段「朋友与同僚经（一）」
  - 问题：标题把 `amacca` 译作「同僚」，同经正文 `171-2118-2-41` 等处作「伙伴」，同一词在标题与正文里两译，读者无法把标题与经文对应起来。
  - 建议：择一定译后全章统一（`amacca` 传统作「同僚」「僚友」，指共事的官吏、同僚；若取「同僚」则正文四处「伙伴」应随改），并登记进 `knowledge/term-glossary.jsonl`。

- `171-2119-2-4`｜语言风格不统一（术语跨段漂移）｜片段「朋友与同僚经（二）」
  - 问题：同上，标题「同僚」与正文「伙伴」不一致。
  - 建议：同上。

- `171-2118-45-64`｜整句逻辑表达不规范｜片段「使他们安住于这净信、确立于这净信」
  - 问题：同一组 `samādapetabbā, nivesetabbā, patiṭṭhāpetabbā` 在本句补出宾语「这净信」并重复两次，在 `171-2118-65-85`、`171-2121-53-75` 却不补宾语（「使他们安住、使他们确立」），在 `171-2118-2-41` 又作「使他们确立于四种入流支」。三种句式在相邻数行内并存，套语的复现感丢失。「确立于这净信」中「这净信」紧接前句重复，也略显累赘。
  - 建议：确定一种套语句式贯穿全章，例如统一为「应当劝导他们、使他们安住、使他们确立于……」，宾语只在句首或句末出现一次。这属 harmonize 范围。

- `171-2118-65-85`｜整句逻辑表达不规范｜片段「应当在圣者所喜爱的戒上劝导他们、使他们安住、使他们确立」
  - 问题：与同段 `171-2118-45-64` 的「劝导他们对佛生起……净信」句式不平行；且「在……戒上劝导他们」中「在……上劝导」搭配勉强——`samādapetabbā` 的对象是戒本身，而非「在戒上」进行劝导。
  - 建议：调整为「应当劝导他们受持圣者所喜爱的戒、使他们安住于其中、确立于其中」一类，与前句句式对齐。

- `171-2121-53-75`｜整句逻辑表达不规范｜片段「应当在圣者所喜爱的戒上劝导他们、使他们安住、使他们确立」
  - 问题：同上的搭配问题。另外本句在 2121 段中夹在两组 `siyā … aññathattaṃ`（四大可变、圣弟子不变）句式之间，中文读者看不出它是承接经六套语的省略骨架，段内逻辑出现断裂感。原文确实如此排印，译文未误，但可读性受损。
  - 建议：句式与前述统一；可考虑在此句译文中不作额外补充（保持忠实），改由脚注说明此处承前省略——脚注属 footnote 步骤的事。

- `171-2118-2-41`｜关键词语意不明确｜片段「你们所怜念的人」
  - 问题：「怜念」偏古雅书面，非现代常用词，一般读者难解；`anukampeyyātha`（anukampati）意为悲悯、关怀爱护。按 `style.md` 第一节「能用双音节现代词就不用文言词」的总原则，宜换用现代常用词。尚不构成文言句式，故按 warning 处理。
  - 建议：改为「你们所悲悯的人」或「你们所关爱的人」；四处（`171-2118-2-41`、`171-2118-86-124`、`171-2120-2-40`、`171-2121-124-161`）一并统一。

### 🟦 suggestion

- `171-2116-43-60`｜语言表达不够流畅｜片段「对法……（中略）……对僧……（中略）……也具有这样的净信；并且具备圣者所喜爱的戒」
  - 问题：「也具有这样的净信」是译者补出的衔接语，原文 `Dhamme … pe … saṅghe … pe …` 只是省略号骨架；补语本身无误且有助理解，但与 `171-2118-65-85` 等平行处（未补衔接语）做法不一，体例不齐。
  - 建议：统一体例——要么各平行处都补一句简短衔接，要么都不补、一律靠省略号承前。

- `171-2116-2-18`｜语言表达不够流畅｜片段「已经超越了一切恶趣与堕处的怖畏」
  - 问题：`sabbaduggativinipātabhayaṃ` 是 `duggati`（恶趣）+ `vinipāta`（堕落、下坠）的复合，「恶趣与堕处」把 `vinipāta` 处理成处所名词「堕处」，与「恶趣」并列；南传通行理解多作「恶趣恶生」或「一切恶趣与堕落之怖畏」，`vinipāta` 偏动作义。此处取义可通，但需义注定案。
  - 建议：待义注可查时核实 `duggativinipāta` 是并列复合还是同义连缀；若义注作同义连缀，可改为「一切堕入恶趣的怖畏」，与本经标题「堕入恶趣之怖畏经」的处理方式保持一致——目前标题（作动词性「堕入恶趣」）与正文（作并列名词「恶趣与堕处」）对同一复合词的理解不同。

- `171-2121-29-52`｜语言表达不够流畅｜片段「那位对佛具有不动摇净信的圣弟子竟会投生地狱、投生畜生界或投生饿鬼界」
  - 问题：「投生」重复三次稍显拖沓；`vata` 的语气（表示「竟然」的惊异/反事实假设）靠「竟会」传达，方向正确。
  - 建议：可作「竟会投生地狱、畜生界或饿鬼界」，动词只出一次。`171-2121-102-123` 同处一并处理。

- `171-2116-22-42`｜该使用而没有使用术语标记｜片段「圣弟子对佛具有不动摇的净信」
  - 问题：`aveccappasāda`（不动摇的净信、证净）为四入流支核心术语，`sotāpattiyaṅga`（入流支）亦然，二者首次出现均未按 `style.md` 第二节「法相术语首次出现夹注巴利原词」加注。
  - 建议：首次出现处加夹注，如「不动摇的净信（aveccappasāda）」「入流支（sotāpattiyaṅga）」；`171-2118-2-41` 的「四种入流支」为该词首现处。同时补入 `knowledge/term-glossary.jsonl`。
