## 跨段一致性

- **经号格式**：§367「一六七、」、§382「一七二、」及以后都用汉字数字加顿号，§369/371/373/375 却写成「168.」「169.」「170.」「171.」 → 统一为「一六八、」「一六九、」「一七〇、」「一七一、」
- **dosa**：§367「瞋是垢」，§369「嗔是苦恼」，§375「以调伏嗔为终点」，§388「瞋恚」，§390「瞋随眠」 → 统一用「瞋」
- **ariyo aṭṭhaṅgiko maggo**：五种写法并存。§367 作「这八支圣道」；§369/371/373/375 作「这条八支圣道」；§382/384/386/388/390 作「这条八正道」；§392 作「这圣八正道」 → 全 chunk 统一为一种，建议用术语表的「八正道」，写作「这条八正道」
- **pahānāya**（nissaya：ပယ်ခြင်းငှါ，为了舍弃）：§367-375 译「舍断」，§382-392 译「断除」 → 统一，建议用「舍断」
- **…pe… 省略标记**：§367-375 与 §392 用「……乃至……」，§382-390 用「……（中略）……」 → 统一为「……乃至……」
- **列举标点**：§367「贪是垢、瞋是垢、痴是垢」用顿号，§369「贪是苦恼，嗔是苦恼，痴是苦恼」用逗号 → 统一用顿号
- **总结句**：§367「这就是那三种垢」多一个「那」，其余各经都作「这就是 N 种 X」 → 删去「那」
- **首现夹注巴利原词**：§382 起 ogha / yoga / upādāna / gantha / anusaya / kāmaguṇa 都夹注了原词；§367-375 的 mala、nīgha、vedanā、taṇhā、tasinā 都没有 → 按 style.md 的夹注规则统一处理

## §375 句 171-375-2-15

- **问题**：取义偏差（轻）— nissaya：`တသိနာ= မွတ်သိပ် (ဆာလောင်)ခြင်းတရား`，意为「饥渴、渴求」。§375-25-56 的 nissaya 也注明这是 taṇhā 的同义换说（`တဏှာကို ပရိယာယ်လဲလှယ်၍ဟောတော်မူသည်`）。「贪求」偏向「贪」，渴的意象没了，也容易和本品的「寻求」（esanā）混淆
- **建议**：可考虑改为「渴求」，并连带修改 §374 经名、§375-19-24 三支名称、§379 摄颂。若维持「贪求」，就把这一分歧记入术语报告

## §382 句 171-382-38-71

- **问题**：误译 — nissaya：`ဧသနာ= ဧသနာသုတ်ကို`、`ယထာ ... ဝိတ္ထာရေတဗ္ဗာ`，意为「如《寻求经》那样展开」。所指是寻求品第一经《寻求经》，不是品。译文「如同“寻求”（品）一样」把所指译错了
- **建议**：改为「（如同《寻求经》那样，全部都应详细展开。）」。同时按跨段一致性统一「断除」「（中略）」「八正道」三处

## §388 句 171-388-18-38

- **问题**：正文混入注释 — 「（kāyagantha，这里的“身”指名身，即心法的聚合）」出自 nissaya 内嵌的义注引文（`နာမကာယဿ ဂန္ထော`），不是经文本身的内容。夹在正文里，读者会误以为经文就这样说。按 style.md 第四节，这类内容应进注释，不进正文
- **建议**：正文只保留「身系（kāyagantha）」，「身指名身（受等四无色蕴）」移到段后注释

## §392 句 171-392-17-57

- **问题 1**：词义误读 — piyarūpā，nissaya：`ချစ်အပ်သောသဘောရှိကုန်သော`，意为「具有可爱的性质」。这里的 rūpa 是「性质、样子」，不是「形色」。译成「形色惹人喜爱的」会让读者把声、香、味、触也理解为「形色」，前后矛盾
- **建议**：改为「令人喜爱的」或「性质可爱的」
- **问题 2**：近义重复 — iṭṭhā 译「合意的」，manāpā 译「可意的」，两词几乎同义，读者分不出差别。nissaya 的分别是：`ဣဋ္ဌာ= ရှာမှီးအပ်/အလိုရှိအပ်`（所希求的），`မနာပါ= စိတ်ကိုတိုးပွါးစေအပ်`（令心增喜的）
- **建议**：iṭṭhā 改为「所希求的」或「可欲的」，与 manāpā「可意的」拉开距离
- **问题 3**：夹注不均 — kanta、manāpa、piyarūpa 加了夹注，同列的 iṭṭha、kāmūpasaṃhita、rajanīya 都没有
- **建议**：要么六词一起夹注，要么全部不注
