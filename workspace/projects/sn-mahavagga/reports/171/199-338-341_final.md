## 理由

**基准缺失（先交代）**：本次只注入了巴利原文与待评译文，**义注（本层为复注 ṭīkā，其父层即《大念处经》义注）与 nissaya 均未提供**。因此释义标准与词级基准都无法逐句核对，评估只能依据：巴利原文本身的形态/句法、段内与跨段的自洽性、以及《清净道论》行走六分位与四界强弱这一段成说的教理常识。准确性一栏的结论把握相应下调，信心指数因此压在 64；若要作为验收定论，建议补齐义注与 nissaya 后重评。

**准确性**。本段最容易翻错的三处结构，译文都做对了，这是主要加分项：
1. `X-dhātuyā anugatā Y-dhātu`（具格 + 过去分词与主格同性）的随从方向，四处全部正确——「由风界随从的火界是提脚的缘」「由火界随从的风界，是向前移脚和跨步的缘」「由地界随从的水界，是放下脚的缘」「在那里也是水界随从地界」，并且后半句的 `tassā anugatabhāvo` 回指也都指对了主界，没有出现常见的主客颠倒。
2. `uddharaṇa / atiharaṇa / vītiharaṇa / vossajjana / sannikkhepana / sannirumbhana` 六分位的定义句（341-2-13、14-21、22-38）拆解正确，`Yāva patiṭṭhitapādo, tāva` 的「移到站住的那只脚为止」限度关系没有丢。
3. 340-11-63 三种执取（见执／慢执／爱执）与「爱为二者共因」的推论链完整，`taṃ dassento … tiādimāha` 的目的从句归属正确。
4. 339-24-52 的劫数与阿僧祇配属（独觉二阿僧祇＋十万、上首声闻一阿僧祇＋十万、大声闻十万、其余抉择分善）逐项对得上，未串行。

主要扣分在 `adhimattatā / omattatā` 译作「量多／量少」（三处＋引文一处）：`sāmatthiyato`（按功能／力量而言）说的是四界势力的**强弱**，不是数量多少，译文自己接的「量多而有力」也暴露了这一内部矛盾（`balavatiyo` 才是「有力」，`adhimattā` 应作「增强／强盛」）。这是同一处概念性错译的重复出现，按 error 记。其次是 340-11-63 的 `tathā asammuyhanto` 译作「他不这样迷惑」：`tathā` 指前述那种迷惑，而紧邻的 340-6-10 刚把 `evaṃ`（这样）定义为「显示接下来要说的那种方式」，同一个「这样」两指相反方向，读者会读错；分词也被补主语改成了完整句，与风格文件「不擅自补足省略主语」相违。另有 `yasmā … tasmā` 跨句对应中 `yasmā` 未译出，因果外壳在两条坐标间错位。

**风格符合度**。现代书面汉语达标，`knowledge/style.md` 第一节的文言禁例（此中／故为／彼等／是故／于…之际／答以／用膳…）**一处未见**，全角标点与弯引号「“”」使用正确，`zh` 字段内无 ASCII 引号，译文中无候选、待定、问号等残留工作标记。「谁随从、谁被随从这一点上有差别」这类处理很好地把复注的层层属格拆成了现代汉语。扣分在：法相术语基本未按「首次出现夹注巴利原词」处理（独觉菩提、亲依止、抉择分、慢、四界名全无夹注，而 asaṅkhyeyya 与 Bāhiya Dārucīriya 又夹注了，标准不一）；个别句子仍偏生硬（「举止令人生信地前进」「引来加以连接」「显示对反面的排除」「离了渴爱」）。

**一致性**。术语在段内大体贯通（六分位名称四段统一），但有三处漂移：同一句内 `vīthiyo` 先译「街道」后在被解释词里译「各条街道」（复注黑体须与父层义注逐字同译，此处自身就先不一致）；`ghaṭṭana` 在 341-14-21 作「碰」、在 341-83-104 作「挤压作用」；`tathā` 与 `evaṃ` 都落到「这样」。另外「跨步」作为 `vītiharaṇa` 的定名，与同句给出的释义「把脚从旁边移过去」相冲突，容易被读成「迈大步」。

## 问题清单
按级别从高到低排列。

### 🟧 error

- `199-340-72-101`｜错译（词义）｜片段「按功能来说是量多的」
  - 问题：`adhimattatā / omattatā` 指四界势力的**增强／减弱**，不是数量多寡；前缀 `sāmatthiyato`（就功能／力量而言）与「量多」自相矛盾，功能不论多少。
  - 建议：改为「按功能来说是增强的，另外两界是减弱的」（或「强盛／羸弱」）。

- `199-340-72-101`｜错译（词义）｜片段「量多而有力」
  - 问题：被解释词引文中 `adhimattā balavatiyo` 应为「增强而有力」，「量多」把 `adhimattā` 误作数量。此系被解释词，须与父层义注译文逐字一致。
  - 建议：统一改为「增强而有力」，并与义注译文核对后同步该黑体引文（341-46-74 的同一引文一并改）。

- `199-340-111-137`｜错译（词义）｜片段「按功能来说是量多的」
  - 问题：同上，`adhimattatā` 误译为「量多」。
  - 建议：随 340-72-101 一并改为「增强的／减弱的」。

- `199-341-46-74`｜错译（词义）｜片段「按功能来说是量多的」
  - 问题：同上；本句「量多而有力」引文亦同。
  - 建议：随 340-72-101 一并统一。

- `199-340-11-63`｜导致误解的表达｜片段「他不这样迷惑」
  - 问题：`tathā asammuyhanto` 的 `tathā` 回指前文所述那种迷惑，应作「那样」；而紧邻的 `199-340-6-10` 已把 `evaṃ` 定为「这样」并明说是指下文，两处同用「这样」造成指代反向。且 `asammuyhanto` 是分词，译文补出主语「他」并改成完整句，与「不擅自补足省略主语」相违。
  - 建议：改为「不那样迷惑（的人）」一类处理，并核对父层义注该黑体词的译法，保持逐字同译。

### 🟨 warning

- `199-338-54-107`｜代词指代不明确｜片段「使它具足了」
  - 问题：`samannāgataṃ katvā` 的受事在本句未出现（所指为受用饮食这一行为），译文的「它」无着落，读者不知何物具足八支。
  - 建议：按义注上文补明所指，如「使这样的受用具足了……八支」。

- `199-340-11-63`｜关键词语意不明确｜片段「由于对慢的执取而有的迷惑」
  - 问题：`māna` 单用「慢」在现代汉语里与「缓慢」同形，一般读者无法识读；且该句「见」「慢」「渴爱」三词只有「渴爱」是自明的。
  - 建议：作「我慢（māna）」，并顺势给「见（diṭṭhi）」加夹注，与「渴爱」齐平。

- `199-340-11-63`｜关键词语意不明确，或二意场合没有注释｜片段「由破除密集而成的」
  - 问题：`ghanavinibbhoga`（破除密集／分解聚合）是专门术语，「密集」在现代汉语中完全是另一个意思，无注释读者不可解。
  - 建议：夹注并略释，如「破除密集（ghanavinibbhoga，即把看似整块的身体分解开来看）」。

- `199-341-14-21`｜关键词语意不明确｜片段「跨步」
  - 问题：`vītiharaṇa` 是为避障或避免碰到支撑脚而**从旁移过**，本句自己的释义也是「从旁边移过去」，但定名「跨步」指向大步前迈，与释义冲突，也与 `atiharaṇa`（向前移脚）界限模糊。
  - 建议：改用「侧移脚／移过」一类译名，并在 341-22-38、340-102-110、340-111-137 同步。

- `199-340-64-71`｜整句逻辑表达不规范｜片段「由风界随从的火界是提脚的缘」
  - 问题：`Yasmā` 未译出，而下一坐标 199-340-72-101 又以「因为」起首（对应的是 `hi`），致使巴利 `yasmā … tasmā` 的因果外壳在两条坐标间错位，中文读成两段互不相属的因果。
  - 建议：本句补出「因为……」，下句的 `hi` 改用「毕竟／盖因」之外的轻连接，保证「因为—所以」只有一套。

- `199-341-39-45`｜整句逻辑表达不规范｜片段「由地界随从的水界，是放下脚的缘」
  - 问题：同上，`Yasmā` 未译出，与 341-46-74 的因果结构脱节。
  - 建议：随 340-64-71 一并统一处理。

### 🟦 suggestion

- `199-338-2-18`｜语言风格不统一｜片段「一开始就应当先观察街道」
  - 问题：同句内 `vīthiyo` 前作「街道」、被解释词作「各条街道」；且「一开始就……先」语义重复。复注黑体须与父层义注译文逐字同，本句自身先不一致。
  - 建议：统一为「各条街道」，并删掉「一开始／先」之一。

- `199-339-2-10`｜该使用而没有使用术语标记｜片段「如果具足了亲依止的条件」
  - 问题：「亲依止」「独觉菩提」首次出现均未夹注巴利原词，而同批 339-24-52 又夹注了 asaṅkhyeyya，标准不一。
  - 建议：按 style.md 给首现法相术语补圆括号夹注：亲依止（upanissaya）、独觉菩提（paccekabodhi）、抉择分（nibbedhabhāgiya）。

- `199-338-24-31`｜语言表达不够流畅｜片段「举止令人生信地前进」
  - 问题：`pāsādikena abhikkantena` 是具格短语，中文「令人生信地前进」作状语头重脚轻，读来生硬。
  - 建议：调整为「以令人净信的仪态前进」一类说法，并与义注该句译文对齐。

- `199-338-108-113`｜语言表达不够流畅｜片段「显示对反面的排除」
  - 问题：`paṭikkhepadassana` 译作「对反面的排除」连用两个抽象名词，语义模糊。
  - 建议：作「是从反面加以排除」或「显示所要排除的情形」。

- `199-339-11-23`｜语言表达不够流畅｜片段「引来加以连接」
  - 问题：`upanetvā sambandhitabbaṃ` 直译痕迹明显。
  - 建议：作「也应当照样把这一句补进去连读」。

- `199-340-11-63`｜语言表达不够流畅｜片段「这两者离了渴爱就不会生起」
  - 问题：「离了」偏口语且略带文言味。
  - 建议：作「这两者没有渴爱就不会生起」。

- `199-341-83-104`｜语言风格不统一｜片段「靠地界的挤压作用」
  - 问题：`ghaṭṭana` 在 341-14-21 译「碰」、此处译「挤压作用」，同词两译。
  - 建议：统一为「触压」或「碰压」，两处一致。
