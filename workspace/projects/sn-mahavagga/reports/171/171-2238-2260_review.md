# Review — 171:2238-2260（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅 nissaya 复核）

## 跨段一致性

- **puññābhisanda / kusalābhisanda**：§2239–2246 译“福流、善流”，§2248–2250 译“福德的流注、善的流注” → 建议统一为“福流、善流”。依据：nissaya `ပုညာဘိသန္ဒာ= ကောင်းမှုတည်းဟူသော အမြဲစီးသည့် မြစ်ကြီး`（以福德为体、长流不断的大河），“流”比“流注”贴切；这个译法出现次数也更多。经题也要随之统一：§2247“3. 第三福德流注经”应改为“三、福流经（第三）”。
- **sukhassāhāra**：§2239–2246 译“是快乐的因缘”，§2248–2250 译“快乐的食粮” → 建议统一为“是快乐的因缘”。依据：nissaya `အာဟာရာ= အကြောင်းဖြစ်ကုန်သော`（作为原因的），并没有取“食”的字面义。“食粮”与 nissaya 不符，是**必改项**。
- **devapada**：§2252–2255 译“天的足迹”，§2257–2260 译“诸天的天处” → 建议统一为“天的足迹”。依据：nissaya `ဒေဝပဒါနိ= …ပဋိဝေဓဉာဏ်ဖြင့် နင်းရာ ခြေရာ`（以通达智踏出的足迹），`ခြေရာ` 就是“足迹”，“天处”与 nissaya 不符，是**必改项**。经题也要统一：§2251“4. 第一天之足迹经”含文言虚词“之”，应改为“四、天的足迹经（第一）”；§2256“五、天处经（第二）”应改为“五、天的足迹经（第二）”。
- **devānaṃ**：§2252–2255 译“天的”，§2257–2260 译“诸天的” → 随 devapada 统一为“天的”。
- **经题编号格式**：§2238 和 §2243 用“一、”“二、”，§2247 和 §2251 用“3.”“4.”，§2256 用“五、” → 统一为“一、…五、”。
- **aveccappasāda**：§2239 和 §2244 译“不动摇的净信”，§2248、§2253、§2258 译“不动摇的信心” → 建议统一为“不动摇的净信”。依据：nissaya `သက်ဝင်၍ ကြည်ညိုခြင်း`（深入而生的明净信），“净信”更贴近 `ကြည်ညို`（澄净、敬信）。
- **itipi so bhagavā … bhagavāti**：§2239 和 §2244 译“他确实是这样的世尊”，§2248 和 §2253 译“他就是世尊”，§2258 译“‘这位世尊就是这样：……’” → 建议统一为“‘这位世尊就是这样：……是天与人的导师、佛、世尊。’”，各处统一加引号。依据：nissaya `“ဣတိပိ။ ပ။ ဘဂဝါတိ= ဘဂဝါ” ဟူ၍`，用 `ဟူ၍` 标出这是一段引述的忆念文句。另外，“是天与人的导师”（§2239、§2244）与“天与人的导师”（§2248、§2253、§2258）也要统一。
- **saṅgha**：§2241、§2245、§2259 译“僧团”，§2249 和 §2254 译“僧” → 统一为“僧团”。
- **samannāgata（戒）**：§2242 译“具足”，§2255 译“具有”，§2260 译“具备” → 统一为“具足”。
- **samādhisaṃvattanika**：§2242 和 §2260 译“能引生定”，§2255 译“能导向定” → 统一为“能引生定”。依据：nissaya `ဖြစ်စေတတ်ကုန်သော`（能使生起的）。
- **Sāvatthinidānaṃ**：§2239 译“缘起在舍卫城”，§2252 译“本经的因缘在舍卫城” → 统一为一种，建议用“因缘在舍卫城”。依据：nissaya `သာဝတ္ထိနိဒါန်း`（舍卫城的因缘、缘起处）；“缘起”容易与 paṭiccasamuppāda 混淆。
- **visuddhiyā / pariyodapanāya**：§2252–2255 译“为了使还没有清净的众生清净、为了使还没有洁净的众生洁净”，§2257–2260 译“能使不清净的众生清净，能使不洁白的众生洁白” → 统一为前者。依据：nissaya `ဝိသုဒ္ဓိယာ= …စင်ကြယ်ခြင်းငှါ`，`ငှါ` 是为格，表目的，“为了使”正确，“能使”把目的改成了能力，属于**必改项**。“洁白”与“洁净”也要一并统一。
- **结语句 Ime kho … ti**：§2242 和 §2246 译“以上这四种就是”，§2250 和 §2255 译“这就是那四种”，§2260 译“这就是四种” → 统一为一种，建议用“比丘们，这就是那四种……”。

## §2239 句 171-2239-11-20
- **问题**：无实质错误。nissaya 把 `သုခဿ အာဟာရာ` 作为 `ပုညာဘိသန္ဒာ` 的定语（`ဖြစ်ကုန်သော`，“作为……的”），译文“是快乐的因缘”作为同位说明，可以接受。
- **建议**：保持，作为全 chunk 统一的基准译法。

## §2246 句 171-2246-2-19
- **问题**：格与句法 — `ဝိဂတမလမစ္ဆေရေန= ကင်းသော ဝန်တိုခြင်းမစ္ဆေရအညစ်အကြေးရှိသော`，nissaya 把 mala 与 macchera 读作同位关系，意思是“以悭吝为垢”，指的是一种垢。译文“远离了垢染与吝啬”拆成了两项，属于误读。另外 `စေတသာ= စိတ်ဖြင့်` 是具格（以……心），译文“心中远离了”把它变成了主谓结构。
- **建议**：改为“圣弟子以远离悭吝之垢的心住在家中……”。如果“之”嫌文言，可写作“以远离了悭吝这种污垢的心住在家中”。
- **问题**：`ယာစယောဂေါ= သူတပါးတို့တောင်းခြင်းငှါ လျောက်ပတ်သည်`，意思是“适于他人前来求取”。译文“凡有人来求都乐于给予”与后面的“乐于布施和分享”在语义上重叠，而且偏离了 nissaya 的读法。
- **建议**：改为“适合他人前来求取”。

## §2258 句 171-2258-53-63
- **问题**：误译 — `တသံဝါ= ထိတ်လန့် တတ်သည်`（会惊惧的）、`ထာဝရံ ဝါ= မထိတ်မလန့် မြဲခိုင်ခံ့သည်`（不惊惧、坚固的）。nissaya 取的是“有怖畏 / 无怖畏”这一义，不是“会动 / 不动”。另外 `ကိဉ္စိ= တဦးတယောက်သောသူကိုမျှ` 指“任何一个人”。
- **建议**：改为“而我确实不恼害任何人，无论是有怖畏的还是坚定无畏的”。§2260 句 171-2260-46-55 同步修改。

## §2258 句 171-2258-64-71
- **问题**：句法 — `ဒေဝပဒဓမ္မသမန္နာဂတော= …တရားနှင့် ပြည့်စုံသည်ဖြစ်၍ ဝိဟရာမီ= နေ၏`，意思是“具足……法而住”，“住”不带处所宾语。译文“安住于其中”补出了“其中”，nissaya 没有这个成分。“天处”也要按跨段一致性一节改。
- **建议**：改为“我确实是具足天的足迹之法而安住”。如果要避免“之”，可写作“我确实具足了通往天的足迹的法，这样安住”。§2260 句 171-2260-56-61 同步修改。

## §2257 句 171-2257-2-20
- **问题**：漏译 — 原文 `Cattārimāni`（imāni，“这些”），译文“有四种”漏了“这”。§2252 作“有这四种”。
- **建议**：改为“比丘们，有这四种天的足迹……”，其余按跨段一致性一节统一。
