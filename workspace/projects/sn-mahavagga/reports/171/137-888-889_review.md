## 跨段一致性

- **desanā**：§888 句 137-888-9-26 译「教说之智」，同段 137-888-33-41 却把 `imāya desanāya` 译作「这段解说」。而「解说」在父层已被 `veyyākaraṇa` 占用（171-2484「在这段解说正在宣说时」），两个不同的巴利词撞同一个汉语词，读者会以为是同一概念 → 建议 137-888-33-41 改为「世尊通过这场**教说**把它们显明出来」，使 desanā 在本 chunk 内统一，「解说」专留给父层的 veyyākaraṇa。
- **anusāveti / saddaṃ anussāveti**：黑体处译「出声传告」（与父层一致），但 137-889-13-22 的 `anusāvayiṃsu` 改译「把消息传扬开去」。同一动词在同一条注释里前后两样 → 建议统一为「传告」：「说着“世尊在……”等等这些话向外传告」。
- **pavatteti / pavattita**：137-888-42-64 用「转动」译进行态、「转起」译完成态，靠换词来承担时态对立；但父层 171-2485 的 `pavattitaṃ` 译的是「转动了」，同一组词在父子两层的分工正好相反，容易误读为两个不同的动作 → 建议本句统一动词、用体标记区分：「世尊就还在**转着**这法轮；等到……才叫做法轮**已经转起**」。
- **四谛 / 四圣谛**：137-888-9-26 作「四谛」（原文 `catūsu saccesu` 无 ariya），父层作「四圣谛」（原文有 ariya）——对应关系正确，保持现状。

## §888 句 137-888-42-64

- **问题**：数字误译（必改） — `aṭṭhārasahi brahmakoṭīhi` 是「十八俱胝（koṭi）梵天」，1 koṭi = 一千万，十八俱胝 = **一亿八千万**。译文作「一千八百万」，少了一个数量级。
- **建议**：改为「和一亿八千万梵天一起」（或保留传统读法「和十八俱胝梵天一起」并夹注数目）。
- **问题**：翻译腔 / 半文半白（必改） — 「确立于须陀洹果」。`sotāpattiphale patiṭṭhāti` 的「于」字结构是直搬格位的译法，不是现代书面汉语（对照 `style.md` 第一节：文言虚词「于」）。同句「等到确立了」也承此病。
- **建议**：「只要阿若憍陈如长老还没有和一亿八千万梵天一起**证得须陀洹果**，世尊就还在转着这法轮；等到**证得了**，才叫做法轮已经转起。」

## §888 句 137-888-33-41

- **问题**：指代不明 — 「世尊用这段解说把**它**显明出来」，「它」在上一句里最近的指称是「智」，但上一句主语为「这两者（两种智）」，读者不易确定所指。
- **建议**：「世尊通过这场教说把**这两种智**显明出来，这就叫做转起了法轮。」（同时解决上面 desanā 的一致性问题）

## §888 句 137-888-9-26

- **问题**：省略了智的归属者 — `Bodhipallaṅke nisinnassa … isipatane nisinnassa` 两处属格指的是「坐在菩提座上／坐在仙人堕处的**世尊**」，译文「在菩提座上坐着时」把人省成了时间状语，读者不知道这智是谁的（缺 nissaya，属格判定仅据原文形态）。
- **建议**：「因为**世尊坐在菩提座上时**，对四谛生起的十二行相的通达之智，以及**坐在仙人堕处时**……」——补一次主语即可，后一处承前省。

## §888 句 137-888-27-32

- **问题**：语气词 `eva` 未译出 — `ure pavattañāṇam**eva**` 的 eva 是「无非就是、正是」，强调两者同归一事。
- **建议**：「这两者**无非都是**在十力者胸中转起的智。」

## §888 句 137-888-65-77

- **问题**：添加了原文没有的语气 — `Taṃ sandhāya` 只是「针对这一点」，译文的「**才**说了」多出一层转折强调。
- **建议**：删「才」：「针对这一点，说了“……”等等这些话。」

## §889 句 137-889-2-6

- **备注**（非必改）：黑体只覆盖 `bhummā` 一词，译文「地居天神」把父层 `devā` 的「天神」也包了进来，于是词条与释义「住在地上的天神」近乎同语反复。因与父层「地居天神们」逐字相符，对应关系不断，可维持现状；若要更贴合，可作「**地居**（bhummā）的天神，指住在地上的天神」——但这会让黑体缩短，需与 harmonize 步一并决定，不宜在本步单改。

## §889 句 137-889-7-12

- **问题**：`sādhukāraṃ datvā` 的「sādhukāra」指发出「善哉」之声（喝彩、称善），译作「赞叹的呼声」偏泛；另「同时一齐」对 `ekappahāren**eva**` 属重复堆叠。
- **建议**：「**出声传告**，是说他们**一齐称善（sādhukāra，“善哉”之声）**——」

## §889 句 137-889-27-34

- **问题**：文言式连接 — 「超过了天神们的威力**而**照耀」，「…而…」是文言句式接法（对照 `style.md` 第一节总原则）。
- **建议**：「因为那时它**胜过天神们的威力，光耀四方**。」（「超过了天神们的威力」这一短语与父层 171-2486 一致，改动限于后半句连接方式，可保留原短语作「因为那时它超过了天神们的威力，照耀开来」。）

## §889 句 137-889-35-48

- **问题**：同上的「…而…」接法 — 「遍满了一万个世界**而**持续着」。`pharitvā aṭṭhāsi` 是「遍满之后持续不散」。
- **建议**：「……的声响也遍满一万个世界，久久不散。」（「一万个世界」与父层 171-2486「这一万个世界」一致，保留。）
