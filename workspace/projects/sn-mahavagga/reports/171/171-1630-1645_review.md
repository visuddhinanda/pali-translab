# Review — 171:1630-1645（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分段落无 nissaya，相应句略过）

## 跨段一致性

- **yāva brahmalokāpi kāyena vasaṃ vatteti**：§1631–1636 译“乃至在梵天界，也能用身体随意自在”，§1642 译“乃至能以身在梵天世界中运用自在”。两处“梵天界／梵天世界”不统一，“用身体／以身”的语体也不统一。另外两种译法都把 yāva…pi（ဗြဟ္မာ့ပြည်တိုင်အောင် = 直到梵天界为止）译成了处所“在梵天界”，见 §1631 句 171-1631-99-111。**建议**：各段统一为“乃至远到梵天界，都能以身体自在掌控”。
- **ekopi hutvā bahudhā hoti, bahudhāpi hutvā eko hoti**：§1631–1636 译“由一身变为多身，又由多身变为一身”，§1642 译“或由一身而成多身，或由多身而成一身”。**建议**：统一为前者。nissaya 用 ဟုတွာ = 是…之后，表示先后，不表示选择，“或…或”与之不合。
- **iddhividhaṃ paccanubhoti**：§1631–1636 译“体验种种神通”，§1642 译“体验到种种神通变化”。**建议**：统一为“体验种种神通”。
- **bahulīkatattā**：§1631–1636 译“反复修习了”，§1638、§1639 译“多次修习了”。**建议**：统一为一种，推荐“反复修习了”，出现次数多。
- **catunnaṃ iddhipādānaṃ**：§1631–1633 译“四神足”，§1634–1636、§1638–1639 译“四种神足”。**建议**：统一为“四神足”。
- **四神足定型句**（chanda/vīriya/citta/vīmaṃsā-samādhippadhānasaṅkhārasamannāgataṃ）：两处译法不一致，对照如下。

  | 项目 | §1634 | §1639、§1644 |
  |---|---|---|
  | 具足 | 具足 | 具备 |
  | 欲定 | 欲定 | 欲三摩地 |
  | 精进定 | 勤定 | 精进三摩地 |
  | 心定 | 心定 | 心三摩地 |
  | 观定 | 观定 | 观察三摩地 |
  | 勤行 | 勤行 | 精勤之行 |
  | 中略标记 | ……（中略）…… | ……中略…… |
  | 句首 | 比丘在此 | 在这里，比丘 |

  - §1634 把 vīriyasamādhi 译成“勤定”，与 padhāna（勤）混淆。nissaya 把 padhānasaṅkhāra 释为 သမ္မပ္ပဓာန်ဝီရိယ（正勤精进），vīriya 应作“精进”。
  - **建议**：全 chunk 统一为“具足欲定与勤行的神足……精进定……心定……观定”，中略统一写“……（中略）……”。“精勤之行”另有文言问题，见 §1644。
- **paṭipadā**：§1641、§1643、§1645 都译“道路”。§1643 同句 maggo 已译“道”，paṭipadā 再译“道路”，两词混而难分。nissaya 释 maggo 为 လမ်းစဉ်（道），paṭipadā 为 ကျင့်စဉ်／အကျင့်（修行、行持）。**建议**：paṭipadā 三处统一改为“行道”，例如“通向神足修习的行道”。
- **经尾计数**：§1636 译“第七。”，§1639 译“第八经。”，§1645 译“第九经。”。nissaya 作 သတ္တမံ = ခုနစ်ခုမြောက်သောသုတ်（第七经）。**建议**：§1636 改为“第七经。”。
- **经题与段号体例**：经题 §1630 作“7. 第二沙门婆罗门经”，§1637 作“八、比丘经”，§1640 作“九、神通等宣说经”；段号 §1631 作“829.”，§1638 作“八三〇、”，§1641 作“八三一、”。**建议**：经题和段号各统一为一种体例。

## §1631 句 171-1631-72-79
- **问题**：词法 — pallaṅkena kamiṃsu：nissaya 为 ပလ္လင်္ကေန = ထက်ဝယ်ဖွဲ့ခွေသဖြင့်（以结跏趺坐的姿势），具格表示行进时的身姿。“盘腿而行”容易被读成盘着腿走路。
- **建议**：改为“在空中也能盘腿坐着飞行，就像有翅膀的鸟一样”。§1632、§1633 同句一并改。

## §1631 句 171-1631-99-111
- **问题**：词法 — yāva brahmalokāpi = ဗြဟ္မာ့ပြည်တိုင်အောင်လည်း（直到梵天界为止），表示范围的终点，不是处所。“在梵天界”把能力的范围缩成了“在梵天界里”。vasaṃ vattesuṃ = 使随己意而转，是使役，“随意自在”弱化了这一层。
- **建议**：改为“乃至远到梵天界，都能以身体自在掌控”。§1632–1636 同句一并改。

## §1636 句 171-1636-42-43
- **问题**：漏译 — nissaya：သတ္တမံ = ခုနစ်ခုမြောက်သောသုတ်တည်း（第七经），译文漏了“经”字，与 §1639、§1645 不一致。
- **建议**：改为“第七经。”。

## §1638 句 171-1638-2-28
- **问题**：跨段一致 — bahulīkatattā 译“多次修习了”，与 §1631–1636 的“反复修习了”不一致；“四种神足”与“四神足”不一致。格位与语序无误。
- **建议**：改为“由于修习了、反复修习了四神足”。

## §1642 句 171-1642-11-44
- **问题**：句法 — ekopi hutvā：nissaya 为 ဟုတွာ = ဖြစ်လျက်（是…之后），表示先后。“或由一身而成多身，或由多身而成一身”改成了选择关系。“乃至能以身在梵天世界中运用自在”的毛病同 §1631（yāva…pi 是范围终点），措辞也与前文定型句不一致。
- **建议**：改为“比丘体验种种神通——由一身变为多身，又由多身变为一身……（中略）……乃至远到梵天界，都能以身体自在掌控——比丘们，这就叫做神通”。

## §1643 句 171-1643-12-30
- **问题**：词义区分 — yo so maggo yā paṭipadā：nissaya 区分 မဂ္ဂေါ = လမ်းစဉ်（道）与 ပဋိပဒါ = ကျင့်စဉ်（修行的次第）。译“那条道、那条道路”，两词几乎同义，paṭipadā 的“修行”义丢失了。
- **建议**：改为“凡是能导向获得神通、证得神通的那条道、那种行道”。

## §1644 句 171-1644-11-38
- **问题**：风格（必改）— “精勤之行”用了文言虚词“之”。另有术语问题：nissaya 释 chandasamādhippadhānasaṅkhāra 为“以欲为主导的定，以及作为行的正勤精进”，译文与 §1634 的术语不统一，见跨段一致性一节。
- **建议**：改为“修习具足欲定与勤行的神足，修习具足精进定……（中略）……心定……（中略）……修习具足观定与勤行的神足——比丘们，这就叫做神足的修习”。§1639 句 171-1639-7-27 同样改。

## §1641 句 171-1641-2-19
- **问题**：词义 — iddhipādabhāvanāgāminiñca paṭipadaṃ：nissaya 为 ပဋိပဒဉ္စ = အကျင့်ကို（修行，宾格）。“道路”没有译出“修行”义，与 §1643 的 maggo 也难以区分。
- **建议**：改为“以及通向神足修习的行道”。§1645 句 171-1645-2-12 同样改。

## §1645 句 171-1645-13-46
- **问题**：漏译 — nissaya：အရိယော = မြတ်သော（圣的），ariyo 是实词，“就是这八正道”漏译了。ayameva 的 eva 带强调（သာလျှင် = 唯有），“就是”稍弱。
- **建议**：改为“正是这圣八正道，也就是：……”。“通向神足修习的道路”同上改为“行道”。
