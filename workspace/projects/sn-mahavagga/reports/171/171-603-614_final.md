**准确性**：绝大多数句子词覆盖完整，格与句法角色处理正确。`abhāvitattā abahulīkatattā`（从格·原因）译作「正因为没有修习、没有多修」准确；`vivekanissitaṃ virāganissitaṃ nirodhanissitaṃ vossaggapariṇāmiṃ` 四支修饰语全数译出且顺序正确。主要扣分点有二：一是 `Ādiccassa udayato`（属格 + 从格）译成「太阳升起之前」，把「以……为前导」的关系误处理成时间状语，且 `udayato` 的从格在此是「对于太阳的升起而言」，译文的「之前」是加译；二是 `eḷamūga` 译作「言语不成的人」，该词传统解释为「愚钝如聋哑」（`eḷa`=唾/`mūga`=哑），译文只取了「言语」一面，丢了「愚钝、如聋如哑」的核心义，且与 `duppañño`（劣慧）构成的并列关系变得重复难解。

**风格**：现代书面汉语基本达标，未见「此中/故为/彼等/是故」等禁例，未见文言虚词与文言句式。标点为全角，引号用全角 “” ‘’，译文内无 ASCII 引号，符合 JSON 安全约束。「劣慧」「具慧」属可接受的佛教固定译法。扣分处为 `Idha` 译作「在这教法中」——意思对，但在同一 chunk 内属唯一一处补足性解释，且与前后「比丘们」重复堆叠，读来略滞。

**一致性**：平行经文（604/606/608/610/612）的套语处理高度一致，`Kittāvatā nu kho` 一律「究竟到什么程度才说是」，`… pe …` 一律「……乃至……」，经末序数一律「第 N 经」，`satta bojjhaṅgā` 一律「七觉支」。术语与 `term-glossary.jsonl` 无冲突。唯一不一致是 `duppañño eḷamūgo` / `paññavā aneḷamūgo` 这对反义词的译法不对称：前者「言语不成」是否定式短语，后者「言语通达」是肯定式褒义词，两者不是同一语素的正反，读者看不出它们是一对。

## 问题清单

### 🟧 error
- `171-614-2-22`｜错译（修饰关系）｜片段「太阳升起之前有一个前导、一个先兆」
  - 问题：`Ādiccassa udayato etaṃ pubbaṅgamaṃ` 的结构是「这（曙光）是太阳升起的前导」，`udayato`（从格/属格）与 `pubbaṅgamaṃ` 直接构成修饰关系，不是时间状语。译文「升起之前」既加译了原文没有的「之前」，又把「前导/先兆」的归属对象说糊了——变成「在某时间点存在某物」，丢掉了「曙光是日出的前相」这一核心比喻结构。同句下文 614-23-40 译作「七觉支的生起也有一个前导」，属格关系处理正确，本句与之不一致。
  - 建议：改为「太阳升起的前导、先兆是这个，那就是曙光」一类结构，与下句「七觉支的生起……的前导」保持平行。

- `171-606-24-39`｜错译（词义）｜片段「劣慧而言语不成的人」
  - 问题：`eḷamūga` 传统释为「愚钝、如聋如哑者」（`mūga` 哑，引申迟钝无知），重点在心智愚钝，不在「言语能力」。译成「言语不成」把一个心智缺陷词窄化成语言障碍词，且与前面的 `duppañño`（劣慧）失去语义呼应。同一误译出现在 606-40-55、606-56-72、606-77-102 四处。
  - 建议：统一改为「愚钝」「愚钝如哑」或「劣慧愚钝的人」一类译法，并在首次出现处夹注巴利原词。**改前建议先取义注核对该词释义**，本次评估无义注可据。

- `171-608-2-20`｜错译（词义）｜片段「具慧而言语通达的人」
  - 问题：`aneḷamūga` 是 `eḷamūga` 的否定式，应与上条译法构成严格正反对应。「言语通达」既承袭了上条的窄化误读，又用了褒义色彩更强的「通达」，与否定式的构词不符。出现在 608-2-20、608-21-36、608-37-53、608-57-81 四处。
  - 建议：随上条一并修正为「不愚钝」一类否定式译法，保证与 `duppañño eḷamūgo` 的译法在字面上可辨认为一对。

### 🟨 warning
- `171-604-28-32`｜关键词语意不明确｜片段「就是这七觉支」
  - 问题：`Yadidaṃ – satta bojjhaṅgā` 中的 `yadidaṃ` 是提示语「也就是」，`satta bojjhaṅgā` 前无指示词。译文加了「这」，但此处七觉支尚未列举，用近指「这」在汉语里指向落空——下一句才问「哪七种呢」。
  - 建议：删去「这」，作「就是七觉支」。

- `171-606-2-23`｜整句逻辑表达不规范｜片段「坐在一旁的那位比丘对世尊这样说道——」
  - 问题：`ekamantaṃ nisinno kho so bhikkhu` 在原文是承接前面省略段（顶礼后坐于一旁）的完整叙事链，译文把它压成一个定语「坐在一旁的那位比丘」，使「坐下」这个动作从事件退化为属性，与前半句「来到世尊那里」的动作叙述在时体上脱节。
  - 建议：改为「……坐在一旁。坐在一旁的那位比丘对世尊说道——」或「……在一旁坐下后，那位比丘对世尊说道——」。

- `171-614-70-87`｜关键词语意不明确｜片段「在这教法中」
  - 问题：`Idha` 在此定型句中指「在此（佛陀的教法/僧团）中」，译作「在这教法中」并无错误，但「这」缺少先行词，前文未提及任何「教法」，孤立读来指代落空。
  - 建议：改为「在这佛法中」或「在此佛陀的教法中」，或按惯例简作「在这里」；无论取哪个，需与全书其余 `Idha` 译法统一。

- `171-604-2-16`｜关键词语意不明确｜片段「击破魔军的道路」
  - 问题：`maggaṃ` 在七觉支语境中是「道」（修行之道），译作「道路」偏向物理义。同段「魔军」与「道路」搭配，读者易理解为战场上的通路，而非修行道。
  - 建议：改为「击破魔军之道」或「摧破魔军的修行之道」；该词在 604 段出现三次（604-2-16、604-20-27、604-36-52），需一并统一。

### 🟦 suggestion
- `171-606-56-72`｜语言表达不够流畅｜片段「正因为没有修习、没有多修七觉支」
  - 问题：「多修」是 `bahulīkata` 的紧缩译法，单独成词时汉语读感生硬，且「没有多修」易被误读为「修得不多」（程度）而非「未反复修习」（未做）。该译法在本 chunk 出现 8 次。
  - 建议：考虑「没有反复修习」或「没有多加修习」；若沿用「多修」，建议在首次出现处夹注 `bahulīkata`。

- `171-614-41-55`｜语言表达不够流畅｜片段「可以预期这样的结果——他将会修习七觉支」
  - 问题：`pāṭikaṅkhaṃ` 的定型译法通常是「可以预期」，但译文补出的「这样的结果」加上破折号再接「他将会」，一句里出现两层预告，略显拖沓。
  - 建议：简作「一位有善友的比丘，可以预期他将修习七觉支、多修七觉支」。

- `171-613-2-4`｜语言风格不统一｜片段「八、太阳经」
  - 问题：`Ādicca` 译「太阳」在经题中可行，但南传汉译经题惯用「日经」；同一书内若其他经题用音译或古译（如「日轮」），此处会不统一。
  - 建议：确认全书经题译名体例后统一；无体例约束则保留「太阳经」，因正文 614 段已作「太阳」，前后一致。
