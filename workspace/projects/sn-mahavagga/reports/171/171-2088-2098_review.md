# Review — 171:2088–2098（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，词级格位核对无法进行）／义注 ✅（仅覆盖 §2088–2091 与 §2095；§2092–2094 义注只作 `Sesaṃ sabbattha uttānamevāti`「其余各处都已明白」，无逐词释义）

## 跨段一致性

- **三个数量词处理不一致**：§2091 `Paropaññāsa` 译「五十多」、`Sādhikanavuti` 译「九十多」，都取「概数」；同句 `Chātirekāni ... pañcasatāni` 也译成「五百多」，但义注对前两个给的是 `atirekapaññāsa` / `atirekanavuti`（概数），对第三个给的却是 `chahi adhikāni`（**多出六个**，确数）。三者不能一律作「多」。详见 §2091 条。
- **`vinipāta` 一词两译**：§2092/2093/2094 同一句内 `khīṇāpāyaduggativinipāto` 译作「堕入恶处、恶趣的可能已经断尽」（把 vinipāta 化进「的可能」），紧接着 `avinipātadhammo` 又译作「不会再堕入恶趣」，而 §2091 `avinipātadhammā` 同样译「不会再堕入恶趣」。建议：apāya / duggati / vinipāta 三词分别固定为「苦界／恶趣／堕处」，`avinipātadhamma` 固定为「不会堕入恶处」，避免 duggati 与 vinipāta 共用「恶趣」。
- 一致且无须改动的：`ñātike`→「那提迦」（§2089–2091 一致）、`kālaṅkata`→「去世」（全 chunk 一致）、`sotāpanna`→「入流者」（§2091 首见夹注巴利原词，其后不注，合 `style.md`）、`upāsaka` 首见夹注（§2089）其后不注。
- 全角标点与引号合规，`zh` 字段内无 ASCII 引号。

## §2089 句 171-2089-32-100

- **问题**：音译回写错误 — `nikato` 的词干是 **nikata**（齿音 t），译文夹注写作「（Nikaṭa）」用了卷舌 ṭ，与原文不符；汉字「尼迦**吒**」也是照 ṭ 音选的字。同段其余诸名（Kakkaṭa / Kaṭissaha / Tuṭṭha / Santuṭṭha / Bhadda / Subhadda）的转写均正确。
- **建议**：改为「尼迦多（Nikata）」，§2090 对应处同改。

## §2089 句 171-2089-25-31 / 171-2089-101-109

- **问题**：语体 — 「来世的归趣怎样」中「归趣」偏文言，且与前半「去处」语义重叠（`gati` 去处 / `abhisamparāya` 来世的去向），读来像同义反复。
- **建议**：「他去往何处，来世会生在哪里？」或「他的去处是哪里，来世将往生何处？」两处（§2089 两句）统一。

## §2090 句 171-2090-22-83

- **问题**：准确性 — 编者按 `Sabbe ekagatikā kātabbā` 中 `sabbe` 是「全部」，译文作「**其余**各位」，缩小了范围。
- **建议**：「（以上各位都应作同一去处来说。）」

## §2091 句 171-2091-43-59（必改）

- **问题**：义注释义核对 — **义注**：`**Chātirekānī**ti chahi adhikāni`（「Chātirekāni」意为「多出六个」）。义注把 `chātirekāni` 明确释为「以六为超出」，即 `chātirekāni pañcasatāni` = **五百零六**，是确数，不是概数。译文作「五百多位」取消了义注给定的取义。同段义注对 `paropaññāsā` / `sādhikanavutī` 给的才是 `atireka-`（概数），可见义注是有意区分三者的。
- **建议**：改为「阿难，那提迦有五百零六位优婆塞去世了……」。若要保留直译感，可作「有超出六个的五百位优婆塞」，但概数「五百多」必须去掉。

## §2092 句 171-2092-15-23

- **问题**：准确性 — `ce`（如果）译为「可是……都要」，把条件句读成了陈述加转折；与下句 `assa`（虚拟「就会是」）的呼应也随之断掉（§2092-24-31 译「就是一种烦扰」，原文是「那就会成为一种烦扰」）。
- **建议**：两句连读改为「如果每有一人去世，你们都要来我这里追问这件事，／阿难，那对如来来说就会是一种烦扰。」

## §2092 句 171-2092-47-61（§2093-21-34、§2094-60-75 同句，一并改）

- **问题**：准确性／可读性 — `khīṇanirayomhi` 是 `khīṇa-nirayo amhi`（我是「地狱已尽」者，即我已断绝地狱趣），译文「**我的**地狱已经断尽」把复合词前项读成了领属，中文读来不成话；后三项同此。另 `khīṇāpāyaduggativinipāto` 三个并列词只译出两个（见「跨段一致性」第 2 条）。
- **建议**：统一改为「‘我已断绝地狱，断绝畜生趣，断绝饿鬼界，断绝苦界、恶趣、堕处；我是入流者，不会堕入恶处，必定趋向正觉。’」三处（§2092 / §2093 / §2094）必须逐字相同。

## §2092 句 171-2092-39-46（§2093-13-20、§2094-51-59 同句）

- **问题**：术语 — `byākareyya` 译「作出判定」。此词在经中是弟子「记说／宣说」自己的证果，「判定」带有裁断意味，语感偏移。
- **建议**：「就能自己为自己作出记说」或「就能自己宣说自己的所证」；三处同改，保持逐字一致。

## §2097 句 171-2097-2-7

- **问题**：存疑 — 摄颂词 `ogadha` 译作《梵行的归趣》，是按经文全称（Brahmacariyogadha）补出的，摄颂本身只有 `ogadha`；同行其余经名（《王》《长寿》《舍利弗》）都按摄颂词直译，体例不齐。
- **建议**：或统一按摄颂词作《所入》/《深入》，或全部按经文全称补出；本条待定案后记入 `terms.md`。**不要在译文里留标记**，目前译文无标记，符合要求。

## §2098 句 171-2098-2-7

- **问题**：存疑 — `thapati` 译《木匠》。相应部此经（Thapatayo）中的 thapati 通常指侍奉波斯匿王的一类职官（旧译「木匠」「工师」并存）。义注此处未提供释义，无法定夺。
- **建议**：暂留「木匠」，压低该句 confidence；待取到对应义注后定案。
