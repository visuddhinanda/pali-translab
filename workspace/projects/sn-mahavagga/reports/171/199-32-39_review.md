## 被解释词核对（与父层逐字比对）

逐条核对 32 处黑体引词，**与父层 137 定稿译文逐字一致**：
已经用一种方式分别解说过八支圣道 / 想要再用另一种方式加以分别解说 / 通过听闻、思量、通达、省察 / 业处的着手处 / 是可乐的、可爱的、可意的 / 一次现观 / 他的 / 就作用而言（2 处）/ 以它为所缘的通达 / 把握 / 因为难以见到 / 因为苦谛 / 两者 / 努力 / 去够有顶 / 对苦的了知 / 这智只有一个 / 因为它与欲相违 / 因为它是从欲中出离的状态 / 在思量欲的人心中 / 欲的立足处 / 斩断欲的立足处 / 使欲平息下来 / 远离欲 / 在远离欲的境地中生起 / 出离的思惟 / 方法也完全相同 / 出离的思惟等等 / 等等 / 远离欲……（中略）……的想 / 各不相同 / 在这三处 / 已生起的 / 斩断立足处 / 立足处 / 使它们不再生起 / 只有一个善的思惟生起 / 在这四处 / 为了得到嚼食、啖食等 / 依靠佛所赞许的生计 / 在这七种情形中 — **全部对齐，无断链**。

## 跨段一致性

- **pada（立足处）**：§37 句 199-37-21-37 先译「就叫做**足处**；欲的**足处**就是**欲的立足处**」，同段及 §38（199-38-53-56 / 199-38-57-62）均作「立足处」→ **必改**，同一词在一句内出现两种译法，读者会以为「足处」与「立足处」是两个概念。建议全部作「立足处」：「凭它而行走、而运作的，就是立足处；就欲而言的立足处，就是**欲的立足处**」。
- **aṭṭhaṅgika magga**：§33 句 199-33-2-40 黑体作「八支圣道」（与父层 137:31 定稿一致，不能动），紧接的转述却作「圣八支道」→ **必改**，统一为「八支圣道」。附带：`term-glossary.jsonl` 登记 `aṭṭhaṅgika magga=八正道`，而父层定稿用「八支圣道」，建议给术语表补一条 note 说明本书系沿用「八支圣道」，避免后续步骤照术语表回改。
- **nekkhammasaṅkappa**：§37、§38 黑体作「出离的思惟」，199-37-77-85 转述作「出离思惟」→ 建议统一为「出离的思惟」。
- **eseva nayo / esa nayo**：199-38-2-12 黑体「方法也完全相同」（父层定），199-38-48-52 非黑体作「方法也是这样」→ 非硬约束，但同一 chunk 内建议统一为「方法也完全相同」。
- **vāyāma**：199-36-25-31 把 `vāyāmo` 译作「勤奋」，而父层 137:39 定稿 `Vāyamatī / vāyāmaṃ` 作「付出努力／做出努力」。此处 `payogo` 已占用「努力」（父层所定，不能改），故「勤奋」是权宜；建议改成「或者说是勤勉、用力」，并避免用「勤奋」（现代汉语里偏指品格，不指一次具体的用功）。
- **ṭhāna（处／情形）**：§38 作「在这三处」、§39 作「在这四处」，而「在这七种情形中」作「情形」——这是**跟随父层 137:35-38 各处定稿的结果，不要为求统一而回改**，改了就与父层断链。
- 语体与称谓整体统一（第三人称叙述、现代书面汉语、全角标点），未发现 ASCII 引号、直角引号或工作标记。

## §36 句 199-36-45-67

- **问题**：逻辑倒反（必改） — 「正如前面那两谛一样，由于后两谛在任何方面都不明显」自相矛盾：**义注**明说前两谛「就它的生起而言是明显的」（137:34「Dukkhasaccañhi uppattito pākaṭaṃ」「Samudayampi … uppattito pākaṭaṃ」），后两谛才需伸手够有顶般的努力。原文 `Yathā purimaṃ saccadvayaṃ viya kenaci pariyāyena apākaṭatāya` 是**反面对比**（不像前两谛那样在某一方面还算明显），不是类比。
- **建议**：改为「**不像**前面那两谛那样在某个方面还算明显，后两谛在任何方面都不明显、极其深奥，所以……」。
- **问题**：歧义 — 「分作四种来说」紧跟在「依学习等等方式……的运作差别」之后，易被读成「四种方式」，而父层 137:31 明说后两谛「因为没有思量这一项，所以只有三种方式适用」，读者会觉得三四相冲。`catubbidhaṃ` 指的是对苦、集、灭、道各别的四种智。
- **建议**：改为「分成（对苦、对集、对灭、对道）四项来说」。

## §38 句 199-38-45-47

- **问题**：误译／误导（必改） — `Bhūmiladdhauppannaṃ` 译作「已经取得**地位**而算作生起的那一种」。`bhūmi` 是所依之地（得地已生，与「现行已生」「随眠已生」等相对的传统分类），「地位」在现代汉语里指身份、名位，直接把术语带偏。
- **建议**：「这里所指的是已经获得所依之地而算作已生起的那一种（得地已生）」。

## §39 句 199-39-46-52

- **问题**：指代错误（必改） — 「**他**确实是斩断了它的立足处」。`so` 承前指 `sammāājīvo`（父层 137:38 段末「Ayaṃ **sammāājīvo** nāma」），是「正命」，不是人。译成「他」，读者会以为是比丘或上文「所以**他**说」的义注师。
- **建议**：「因为对于没有构成业道的不正当谋求，正命同样斩断了它的立足处」。

## §36 句 199-36-11-19（以及 199-36-32-44 / 199-37-38-45 / 199-39-9-21 / 199-39-22-34）

- **问题**：指代不明（学术风险） — 这几处「因此**他**说……」「**他**用……比喻」「所以**他**说……」，主语始终未点明。本层是复注，被引的黑体出自**义注**，而读者很容易把「他说」读成世尊说——这正是把义注的说法当成经律本身说法的那类混淆。
- **建议**：首次出现处点明一次，如「因此义注师说**“因为苦谛”**等等」，其后可继续用「他」。

## §38 句 199-38-63-72

- **问题**：指代不明 — 「要让那思惟将来不再生起」。所指是**不善**思惟（父层 137:35「uppannassa akusalasaṅkappassa」），而同段末句讲的是善思惟生起，两句紧邻，「那思惟」易指错。
- **建议**：「要让那**不善**思惟将来不再生起」。

## §38 句 199-38-21-29

- **问题**：切分歧义 — 「与**远离欲的寻**等等相应的出离等等的想」。`kāmavitakkādiviratisampayuttānaṃ` 的结构是「与〔对欲寻等的**远离**〕相应」，现译可被读成「与〔远离欲的寻〕等等相应」，把 virati 的位置读丢了。
- **建议**：「就是与对欲寻（kāmavitakka）等的远离相应的出离等等的想」。

## §36 句 199-36-2-10

- **问题**：表述含混 — 「以**尚未获得的智**无法从如实的自性相上见到它们」，读者不知「尚未获得的智」是谁的、指什么。`anadhigatañāṇena` 指还没有证得（道）智的人所具的智。
- **建议**：「用还没有证得（道）智的人那样的智，无法从如实的自相上见到它们」。附带：父层 137:34 把 `lakkhaṇa` 译作「特相」，本层 `sarasalakkhaṇa` 译作「自性相」，二者不冲突，但若要让读者看出对应，可作「如实的自相（特相）」。

## §35 句 199-35-24-33

- **问题**：语体偏文（建议） — 「**岂**不是……吗？」。`Nanu` 的反问用现代口吻更稳，也免得与全篇现代书面语的基调打架。
- **建议**：「难道说，学习等等的通达不也确实是通达，而它并不是出世间的吗？」

## §37 句 199-37-21-37

- **问题**：语体偏文（建议） — 「凭它**而**行走、**而**运作」连用文言连词「而」。
- **建议**：「因为凭它可以行走、可以运作，所以叫做立足处」。（同句的「足处／立足处」统一见「跨段一致性」第 1 条。）

## §34 句 199-34-6-11

- **问题**：表述过简 — 「句子的连接是：把前两谛学到以后。」`sambandho` 是提示读者该把这句接回上文哪里，现译像残句。
- **建议**：「这里要这样连起来读：把前两谛学到以后（再口头反复念诵）」。

## §34 句 199-34-30-40

- **问题**：衔接缺失 — 「以唯一一种方式成为通达诸谛的因缘，这种朝向它们的状态就是与它们的会合」，前半句是理由，却没有连词，读起来像两句并列。
- **建议**：「由于是以唯一一种方式成为通达诸谛的因缘，这种朝向它们的状态就是与它们的会合，所以叫做**一次现观**」。

## §37 句 199-37-13-20

- **问题**：术语未交代 — 「思量**两种欲**」。`duvidhaṃ kāmaṃ` 指事欲与烦恼欲，本 chunk 首次出现且再无解释。
- **建议**：按 `style.md` 的夹注办法首次附出：「两种欲（事欲与烦恼欲）」。
