# Review — 171:291-297（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§293–295 正文与 §297 后半无 nissaya 行，这些句子仅在跨段一致性中检查）

## 跨段一致性

§292–295 这四段是同一组重复句式，译法统一。§297（足迹经）的译法与之偏离较多，需要回到前面的定式：

- **ariyaṃ aṭṭhaṅgikaṃ maggaṃ**：§292–295 译「圣八正道」，§297-53-68 / 69-83 / 84-125 译「八正道」，漏了 ariyaṃ。nissaya 在 §292 对 `အရိယံ= သော` 单独给了释义，说明这是独立的修饰成分，不能省 → **必改**，§297 三句统一为「圣八正道」。
- **bahulīkaroti / bahulīkarissati**：§292–295 译「反复修习」，§297 译「多修习」 → 统一为「反复修习」。
- **pāṭikaṅkhaṃ**：§292–295 译「可以期待这样的事」，§297-53-68 译「可以预期这样的结果」。nissaya `ဧတံ= ဤအကြောင်းကို`（这件事，宾格）、`ပါဋိကင်္ခံ= အလိုရှိအပ်၏`（可期待） → 统一为「可以期待这样的事」。
- **appamādasamosaraṇā**：§292–295 译「以不放逸为汇归」，§297-33-47 译「都汇集于不放逸」 → 统一为「以不放逸为汇归」。
- **ye keci kusalā dhammā, sabbe te**：§292–295 译「任何善法，全都……」，§297-33-47 译「一切善法都……」。nissaya 把这句拆成两层：`ယေ ကေစိ … သန္တိ`（凡有的善法）再接 `သဗ္ဗေ တေ`（那一切），§297 的译法把它压成了一层 → 统一为 §292 的译法。
- **evameva kho**：§292–295 译「同样地」，§297 译「同样」 → 统一为「同样地」。
- **appamādo tesaṃ dhammānaṃ aggamakkhāyati**：§292–295 译「在这些法当中，不放逸被称为最上」，§297-48-52 译「不放逸被称为这些法中最上的」 → 统一为前者。
- **vivekanissitaṃ … vossaggapariṇāmiṃ**：§292 译「依于……趣向于舍离」，§297 译「依止……趋向于舍离」 → 统一为「依于」「趣向于」。
- **… pe …**：§292–295 译「……（中略）……」，§297 译「……乃至……」 → 统一为「……（中略）……」。
- **appamatto（Kathañca / Evaṃ kho 两句）**：§292–295 译「不放逸地修习」，§297 译「以不放逸修习」 → 统一，取法见下文 §292 句 171-292-93-107。
- **Paṭhamaṃ / Dutiyaṃ**：§295 译「第一。」，§297 译「第二经。」 → 统一，见下文 §295 句 171-295-124-125。

## §292 句 171-292-93-107
- **问题**：句法 — 译文把 appamatto 处理成状语（「不放逸地修习」）。nissaya 作 `အပ္ပမတ္တော= သော` `ဘိက္ခု= သည်`，即「不放逸的比丘」，appamatto 是修饰主语 bhikkhu 的定语，与上句 `အပ္ပမတ္တဿ ဘိက္ခုနော`（不放逸的比丘）一致。
- **建议**：改为「那么，比丘们，不放逸的比丘怎样修习圣八正道、反复修习圣八正道呢？」。§293–295、§297 的同句一并修改。

## §292 句 171-292-129-147
- **问题**：句法 — 与上句相同。nissaya `အပ္ပမတ္တော= သော` `ဘိက္ခု= သည်`，appamatto 是定语。
- **建议**：改为「比丘们，不放逸的比丘就是这样修习圣八正道、反复修习圣八正道的。”」。§293–295、§297-84-125 的结句一并修改。

## §295 句 171-295-124-125
- **问题**：补出成分 — nissaya `ပဌမံ= ရှေ့ဦးစွာသောသုတ်တည်း`（第一部经），补出了「经」。译文只有「第一。」，又与 §297「第二经。」不一致。
- **建议**：改为「第一经。」。

## §297 句 171-297-33-47
- **问题**：句法 / 一致性 — nissaya 注明「余同上经」（`အကြွင်း အထက်သုတ်နှင့်တူပြီ`），本句应与 §292-56-70 逐字相同。现译「同样，比丘们，一切善法都以不放逸为根本，都汇集于不放逸」，句式和用词都不同。
- **建议**：改为「同样地，比丘们，任何善法，全都以不放逸为根本、以不放逸为汇归；」。
