# Review — 171:2438-2457（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **kulaputta**：§2438 标题、§2439 译“良家子”，§2442 标题、§2443、§2444 译“善家子”。另外 §2443 又加了一次夹注“（kulaputta）”，但它在本 chunk 已不是首次出现。nissaya 两处都作 `အမျိုးကောင်းသား`（好家族之子），没有区别。→ 统一为“良家子”，§2443 删去重复夹注。
- **abhisamaya / abhisameti**：§2439–2440 译“现观（abhisamaya）”，§2443–2444 译“通达”。nissaya 两处都作 `ထိုးထွင်း၍ သိ`（穿透而知），是同一词根的名词与动词。→ 统一为“现观”（动词作“现观了／将会现观／正在现观”）。
- **四谛名称**：本 chunk 出现三套译法：
  - §2440 / §2441：苦生起圣谛、苦止息圣谛、通向苦止息的道路圣谛／苦的生起、苦的止息
  - §2444 / §2445 / §2448 / §2449 / §2452 / §2453：苦集圣谛、苦灭圣谛、通向苦灭之道圣谛
  - §2456 / §2457：苦的集起、苦的灭尽、导向苦灭的修行之道
  
  → 统一为一套，建议“苦集、苦灭、导向苦灭的道路”（谓词形式作“这是苦的集起／这是苦的灭／这是导向苦灭的道路”）。“之道”是半文言，按 style.md 改为“的道路”。
- **yogo karaṇīyo**：§2441 译“应当致力于通达”，§2445 / §2449 / §2453 译“应当这样努力：……”，§2457 译“应当精勤修习”。同一句式有三种译法。§2441 的“通达”在原文中没有对应（yoga 是努力、修习）。→ 统一为“对于‘这是苦’，应当努力修习……”。
- **pe**：§2440 译“……（略）……”，其余各段都译“……乃至……”。→ 统一为“……乃至……”。
- **经号与段号格式**：
  - 段号：§2439 “1073.”、§2455 “1077.”用阿拉伯数字加半角点；§2443 / §2447 / §2451 用“一〇七四．”等汉字数字加全角点。→ 统一一种格式。
  - 标题：§2438 作“三、第一良家子经”（序数前置），§2442 / §2446 / §2450 作“……经（第二）”（序数后置括注）。→ 统一一种格式。
- **Tasmātiha**：§2441 译“因此”，§2445 / §2449 / §2453 / §2457 译“所以”。→ 统一为“所以”。

## §2443 句 171-2443-2-29

- **问题**：句法 — nissaya `ပဗ္ဗဇိတာ= ဝင်ရောက်ကုန်သည်ဖြစ်၍` 表示“出家之后”，是从属于 `abhisamesuṃ` 的先行分词。译文用“并且”把出家与通达并列，弱化了先后与依存关系。§2443-30-54、§2443-55-76、§2444-20-51 有同样问题。
- **建议**：改为“……出家、过无家的生活之后，如实地现观了的……”（术语按跨段一致性一节统一）。

## §2447 句 171-2447-2-28

- **问题**：补出成分 — nissaya 把 `samaṇā / brāhmaṇā` 释为 `သာသနာဝင် ရဟန်း／ပုဏ္ဏား`（教法之内的沙门、婆罗门），并附注 `sāsanāvacarā adhippetā`。译文直译“沙门或婆罗门”，读者容易理解为外道沙门婆罗门。§2451 也是同样情况。
- **建议**：正文不改，在本经首次出现处加脚注，说明这里指佛教教法之内的修行者。

## §2451 句 171-2451-2-30

- **问题**：词义 — `pakāsesuṃ` 在 nissaya 中作 `ထင်ရှားပြ`（使显明、显示）。“宣称”在现代汉语里常带“自称、未必属实”的意味，与原意有偏差。§2451 其余两句以及 §2452-17-48 都有同样问题。
- **建议**：“宣称”改为“表明”或“显示”，例如“表明自己已如实彻底觉悟了四圣谛”。

## §2455 句 171-2455-2-36

- **问题**：词义 — `kāmavitakkaṃ` 在 nissaya 中作 `ကာမကို ကြံစည်တတ်သော`（思念欲乐对象的），译“贪欲的思维”偏向内心烦恼而不是所思对象。`byāpāda` 在 nissaya 中作 `သတ်ဖြတ်ရန် ကြံစည်`（想要加害、毁坏），“瞋恨”可以接受，但“恶意”更贴切。另外 vitakka 是法相术语，首次出现没有夹注巴利原词。
- **建议**：改为“欲乐的思维、恶意的思维、伤害的思维”；“思维”首次出现时夹注（vitakka）。

## §2455 句 171-2455-41-64

- **问题**：误译 — `na atthasaṃhitā` 在 nissaya 中作 `အကျိုးနှင့်မစပ်ယှဉ်ကုန်`（不与利益相连），§2456 对应处作 `အကျိုးစီးပွါး`（利益、福祉）。attha 在这里是“利益”，不是“意义”，译“没有意义”是误读。
- **建议**：改为“比丘们，这些思维不带来利益，不是梵行的基础……”。“基础”依据 nissaya 异释 `ဝါ= … အခြေခံ`，“起点”也可以保留，但前后两段须一致。

## §2456 句 171-2456-45-62

- **问题**：误译 — `atthasaṃhitā` 在 nissaya 中作 `အကျိုးစီးပွါးနှင့် စပ်ယှဉ်ကုန်၏`（与利益福祉相连），译“有意义”是误读，与 §2455 是同一个问题。
- **建议**：改为“这些思维带来利益”。
