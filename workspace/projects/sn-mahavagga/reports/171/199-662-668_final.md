## 理由

**基准缺口（必须先说明）**：本次只注入了巴利原文与 channel 译文，**义注（aṭṭhakathā）与 nissaya 都没有取到**。按方法文档降级为「巴利原文 + 译文」对读，后果有两条：一是词级格/句法角色只能凭原文形态判断，没有 nissaya 的格助词可核；二是本层为**复注（ṭīkā）**，其中所有黑体被解释词都引自义注，「被解释词与父层逐字同译」这条硬约束**无法核对**，下面凡涉及黑体词的条目都只能按本段内部自洽性判定，并标注了需回查义注的点。信心指数因此压到 62。

**准确性**：无 fatal。主谓宾判断与教理层面未见违背，逐句意思大体可靠，语源式释义（issara/issariya、adhipati/ādhipacca、sota/sotāpatti）处理得当，夹注巴利原词的用法符合 style。扣分集中在四类：
1. **抹掉论点型误译**。`199-666-56-71` 把被省略的 `bhujissehi` 直接译成「能带来自由」，而全句的要点正是「这是省掉后语的表述，所以义注补作 bhujissabhāvakarehi」——译文提前补出被省的部分，整句变成同义反复，读者看不出省略在哪。
2. **同一词在一句内前后矛盾**。`199-666-7-12` 的 `sadisavasena` 被解释词译「比喻的方式」、释义却译「相似的方式」，`sadisa` 没有「比喻」义。
3. **因果倒置加凭空增译**。`199-668-81-89` 的 `tasmā`（所以）被译成「因为」，方向反了；「两人说的都很好，所以这样说」在原文中完全没有对应。
4. **具格修饰关系丢失**。`199-666-80-91` 的 `asakkuṇeyyehi`（具格复数，修饰「戒」）译成「别人没办法…」，把修饰对象从戒挪到人，且与后半句重复。`199-666-56-71` 同属这一类。

另有一条术语链问题：`aveccappasāda` 译「不动的净信」，但本句给的正是语源释义 `avecca = pavisitvā`（深入），译名与释义打架；紧接的 `199-665-11-22` 用「不动摇的净信」解释它，于是「不动的净信…因此说了不动摇的净信」读成循环论证。「不动」虽有传统依据，在本段这个语境里必须让位于语源。

**风格符合度**：语体合格——通篇现代书面汉语，未见「此中／故为／彼等／是故／于…之际」等文言禁例，无单音节文言虚词，标点全角、引号统一用 “”，译文里没有 ASCII 引号、没有候选或待定标记。扣分在可读性：若干释义句因为被解释词已被意译，出现自我循环（`199-665-32-36`「同时生起、不分先后就是一并发生」、`199-668-41-50`「入流的各个支分就是入流的支分」）；`199-665-86-91` 用双破折号插入成分，句子读不顺；`199-666-72-79` 擅自补出第二人称「你」，与下一句的「别人」人称打架，且违反 style 第六节「不擅自补足省略主语」。

**一致性**：同一巴利词在相邻句异译较多——`anuggaṇha-` 一处「让步认可」一处「姑且认可」；`adhigacchati / pāpuṇāti` 一处「获得」一处「证得」；`vatthu` 与 `ādhāra` 都译「所依」，读者无法区分「三宝」与「所依之人」。被解释词的体例也不统一：有的用「：」引出释义，有的直接接「就是」，有的用「这是」。此外多处在黑体引文内部补词（「四大洲」「由道」「没有边缘的布」），这些补词是否与义注一致无法验证，属遗留风险。

## 问题清单

### 🟧 error
- `199-666-56-71`｜导致误解的表达｜片段「“能带来自由”这个说法是省略了后一个词的表述」
  - 问题：`bhujissehi` 本身只是「自由的（诸戒）」，全句要点是它省略了后语 `-bhāvakarehi`，义注才补全为 `bhujissabhāvakarehi`。译文把被省略的成分提前补进第一个引文，整句变成同义反复，「省略」这一论点消失。
  - 建议：第一个引文按字面译（如「“自由的”这个说法是省略了后一个词的表述」），把「能造成自由的状态」留给义注那一侧。
- `199-666-7-12`｜错译（词义）｜片段「**按照比喻的方式**」
  - 问题：`sadisa` 是「相似、相同」，无「比喻」义；同一句的释义已译作「相似的方式」，被解释词与释义在一句内自相矛盾。
  - 建议：统一为「按照相似的方式」。
- `199-668-81-89`｜错译（逻辑关系）｜片段「因为两位长老都是博学多闻的智者」
  - 问题：原文 `tasmā` 是「所以」，结论是「因此两位长老都是博学多闻的智者」；译文改成「因为」，因果方向反转。
  - 建议：改为「…所以两位长老都是博学多闻的智者」。
- `199-668-81-89`｜错误多译｜片段「两人说的都很好，所以这样说」
  - 问题：原文 `tasmā ubhopi therā paṇḍitā bahussutā` 中没有任何对应成分，属凭空增译；同句被解释词前的「应当说」也无原文依据。
  - 建议：删去增译部分，被解释词照字面作「**这是混合的净信**」。
- `199-665-2-10`｜义理或用词与注释书不符｜片段「**不动的净信**：就是如实地深入三种所依的功德之后生起的净信」
  - 问题：本句给出的正是语源解释 `avecca = pavisitvā`（深入而入），译名却取「不动」，与释义冲突；并使紧接的 `199-665-11-22`「因此说了不动摇的净信」变成循环论证，读者看不出复注在推什么。
  - 建议：被解释词改为体现「深入」的译法并首现夹注原词（如「深入而生的净信（aveccappasāda）」），把「不动摇」留给 `acalappasāda`。需回查义注确认该词在父层的既定译法。
- `199-666-80-91`｜错译（修饰关系）｜片段「**别人没办法这样来指责**：就是没办法这样说」
  - 问题：`asakkuṇeyyehi` 是具格复数，修饰的是「戒」——「（这些戒）是别人无法这样指摘的」；译文把修饰对象换成人，具格关系丢失，且前半句与后半句「没办法这样说」完全重复。
  - 建议：改为「**（这些戒）是别人无法这样指摘的**：即无法说“这就是对戒的违犯”」。

### 🟨 warning
- `199-664-64-67`｜关键词语意不明确｜片段「**没有边缘的布**就是布边已经不存在的布」
  - 问题：原文 `anantakāni ... antarahitāni` 只说「无边的／边不存在的」，「布」这个所指在本段没有依据，是译者补出的；同时「没有边缘的布…就是…的布」自我循环。
  - 建议：先回查义注确认所指；未确认前按字面译「**没有边的**就是边已经不存在」。
- `199-664-14-27`｜关键词语意不明确｜片段「**“四大洲……”**」
  - 问题：引文只有 `catunnaṃ`（四…的），「大洲」是据上下文（`catunnaṃ dīpānaṃ`）补出的，且补成「大洲」而非「洲」。引文里悄悄补词，读者无法与义注对读。
  - 建议：按义注原句取足引文，或作「**“四〔洲〕……”**」明示补出成分。
- `199-665-2-10`｜关键词语意不明确｜片段「三种所依」
  - 问题：`vatthuttaya` 指佛、法、僧三事，「所依」在汉语里指向不明；本段又用「所依」译 `ādhāra`（`199-668-2-11`），两词撞车。
  - 建议：首次出现处夹注说明（如「三事（即佛、法、僧）」），并与 `ādhāra` 的译名区分开。
- `199-665-47-55`｜整句逻辑表达不规范｜片段「就按这三者分成三种来说」
  - 问题：`vutto` 的主语（净信）在译文中缺失，读者不知道「被分成三种来说」的是什么。
  - 建议：补出主语，如「所以〔这净信〕就按这三者分三种来说」。
- `199-665-56-66`｜导致误解的表达｜片段「它从意义上说**是一种**」
  - 问题：`eko` 是「同一个」，「是一种」在汉语里读作「是一类」，与下文「没有任何差别」的论证脱节；两个「它」也未点明所指。
  - 建议：改为「这净信从意义上说是同一个」。
- `199-665-86-91`｜整句逻辑表达不规范｜片段「**这种情况**——分开来一项项说——**是不存在的**」
  - 问题：插入成分打断句子，「这种情况」指代不明（实指净信在各处的差别），整句不易读懂。
  - 建议：改为「**这一点**并没有可分别之处，因为它在一切处都相同」。
- `199-666-2-6`｜不导致误解的汉语语病｜片段「就是指即使转生到另一世也不会破坏这些戒这一点」
  - 问题：`akopanīyatāya` 是「由于（戒）不可被破坏」——被动且表原因；译文改成主动、补出宾语「这些戒」，并丢掉因果关系；句末「…这一点」与前文「就是指」叠用累赘。
  - 建议：改为「**这样**是就（这些戒）即使转生到他世也不会被破坏而言的」。
- `199-666-72-79`｜不导致误解的汉语语病｜片段「**你犯了这一条**就是这一条戒也被你违犯了」
  - 问题：原文 `idaṃ vītikkantaṃ` 无第二人称，「你」为擅自补出（style 第六节禁止擅补主语），且与紧接的 `199-666-80-91`「别人没办法这样来指责」人称不协调。
  - 建议：去掉人称，作「**这一条被违犯了**就是这一条戒也被违犯了」。
- `199-667-2-4`｜关键词语意不明确｜片段「二、深入梵行经的注释」
  - 问题：`brahmacariyogadha` 是「为梵行所涵摄／归于梵行」，主语是入流支；译成「深入梵行」把方向反过来，读成修行者深入梵行。
  - 建议：改为「梵行所摄经」或「归入梵行经」。
- `199-668-77-80`｜代词指代错误｜片段「**已经证得的道**就是已获得的道」
  - 问题：`āgatamaggassa / adhigatamaggassa` 是属格，多半是有财释修饰「已得道者（的）」，译文把「道」当中心词，属格关系整条丢失；且释义与被解释词几乎同字，等于没解释。
  - 建议：回查义注确认所修饰的是人还是道；若为人，作「**已得道者的**就是已证得道的人的」。
