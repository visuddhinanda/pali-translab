## 跨段一致性

- **`ariyo aṭṭhaṅgiko maggo`**：全 chunk 一律译「八支圣道」（`171-400-36-52`、`171-400-53-57`、`171-400-76-97`、`171-401-32-50`、`171-401-51-56`、`171-401-81-101`），但 `knowledge/term-glossary.jsonl` 登记 `aṭṭhaṅgika magga → 八正道`（`status: confirmed`），`style.md` 第二节亦把「八正道」列为应用传统汉译的常见术语 → **必改**：统一为「八正道」（`ariyo…` 作「圣八正道」或径作「八正道」，全 chunk 一致）。依据：术语表 confirmed 条目优先级高于译者自拟。
- **`uddhambhāgiya`**：§399 经名译「上分结」，§400／§401 正文一律译「向上的结缚」，§405 摄颂译「上分」 → 同一巴利词在本 chunk 有三种中译，**必改**。建议统一为「上分结」：经名「上分结经」，正文首次出现作「上分结（uddhambhāgiya saṃyojana）」，摄颂作「下分结与上分结」。依据：经名与正文必须能对上，否则读者无法把摄颂／经名与正文挂钩。
- **`gantha` 与 `saṃyojana`**：§404 `ganthaṃ` 译「系缚」，§400/§401 `saṃyojanāni` 译「结缚」——两词中译仅差一字，读者无从分辨，且两者在同一品内是并列的不同经题。建议 `gantha`→「缠结」，`saṃyojana`→「结缚」（或依术语表定案后统一）。**存疑（待义注核）**：两词的传统辨异应以义注为准。
- **「趋向」一词承担两个不同巴利词**：`171-400-58-75` 以「趋向舍弃」译 `vossaggapariṇāmī`，`171-401-57-80` 又以「趋向涅槃」译 `nibbānaninna` → 建议 `vossaggapariṇāmī` 改作「导向舍离」或「以舍离为归结」，避免撞车。
- **摄颂品名格式不统一**（§407–§410）：「无明品第一」「外道品是第五品」「多所作品是第七品」带「品」字，而「第二品讲的是住」「邪性是第三品」「第六品讲的是太阳」「第八品讲的是生起」不带 → 同一份摄颂内两种句式、两种命名粒度混用。**必改**：统一为「X 品第 N」（住品第二、邪性品第三、行道品第四、日品第六、生起品第八），或统一为「第 N 品是 X 品」。
- **品名未与前文核对**：§404–§410 出现的 `ogha / yoga / upādāna / gantha / anusaya / kāmaguṇa / nīvaraṇa / khandha / vihāra / micchatta / paṭipanna / titthiya / sūriya / bahukata / uppāda` 都是各经／各品定名，本 chunk 之前的正文应已有译法。**请比对 §399 之前的既有译文，凡不一致以正文为准回改摄颂**——摄颂是目录，必须字字对得上正文标题。

## §400 句 171-400-18-35

- **问题**：误译（增字） — `māno` 译作「我慢（māna）」。`māna` 是「慢／骄慢」，「我慢」对应的是 `asmimāna`，原文无「我」。五上分结的传统汉译作「色贪、无色贪、慢、掉举、无明」。
- **建议**：改「慢（māna）」。
- **问题**：取义存疑（待义注核） — `rūparāga / arūparāga` 译「对色的贪／对无色的贪」。此处 `rūpa / arūpa` 依传统释为色界、无色界（生存界），现译易被一般读者读成「对色法／形色的贪」。
- **建议**：倾向改「对色界的贪（rūparāga）／对无色界的贪（arūparāga）」；**此项须以义注的界定为准，义注注入后复核**。
- **问题**：指代 — `imāni kho … saṃyojanāni` 译「这就是**那**五种向上的结缚」。`imāni` 是近指，「那」与之相反且多余。
- **建议**：改「比丘们，这就是五种上分结。」（§401-14-31 同病，一并改。）

## §401 句 171-401-57-80

- **问题**：取义存疑（待义注核） — `amatogadhaṃ` 译「以不死为立足处」。`ogadha` 意为「潜入、沉入」，传统解作「深入不死／沉浸于不死」，「立足处」偏离字面且引入了原文没有的「据点」意象。
- **建议**：改「深入不死」或「潜入不死」；**义注注入后以义注释义定案**。
- **问题**：喻象丢失（可接受，但记录） — `nibbānaninnaṃ nibbānapoṇaṃ nibbānapabbhāraṃ` 三词是地势隐喻（低洼／倾斜／陡坡），译「趋向、倾向、朝向」成了三个近义副词的堆叠，读者只感到重复。
- **建议**：若义注支持喻象，可作「低向涅槃、斜向涅槃、陡落于涅槃」一类处理；否则保留现译，但把「趋向」换掉（见撞车项）。**存疑（待义注核）**。
- **问题**：行文冗赘 — 「……的正定……的正定……的正定」三度重复「的正定」，中文读来拖沓。
- **建议**：首段出「修习……的正定」，后两组以「同样，修习……的正定」或分号并列，避免同一中心语连续三现。
