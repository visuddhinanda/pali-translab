# Review — 171:1945-1949（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1945、1946 后四句、1949 第 13–50 词无 nissaya，略过；1949-2-12 的 nissaya 与原文错位，见下）

## 跨段一致性
- āsava：§1948 句 50-69 的 āsavānaṃ khayāya 译“烦恼的灭尽”，句 70-96 的 khīṇāsavā 译“烦恼已灭尽”。同一句里 arahanto 的 nissaya 是 `ကိလေသာတို့မှ ဝေးကုန်၏`（远离 kilesa），也就是说“烦恼”已对应 kilesa。āsava 再译“烦恼”，两个词就混同了 → 建议两处统一为“漏”：“诸漏的灭尽”“诸漏已尽”。依据：`အာသဝါနံ= အာသဝတို့၏`，nissaya 保留 āsava 原词，不以 kilesa 代替。
- tatra / atha：§1946 句 14-19 的 tatra kho 译“在那里”，nissaya 作时间解（`ထိုအခါ၌` 那时）。§1947 句 2-13 的 atha kho 译“那时”。两处开场套语的取义应一致，见下条。
- bahulaṃ：§1947 句 26-49 与句 50-62 都译“多半”，两处一致，但措辞有歧义，见下条。
- §1948 句 2-69 与 §1949 句 2-50 是重复段（“正确地说…圣住、梵住、如来住”）。§1948 按下列意见修改后，§1949 句 2-12、13-27、28-32、33-50 必须逐字同步，否则重复句式前后不一。

## §1946 句 171-1946-14-19
- **问题**：取义 — nissaya 把 tatra kho 解为时间：`တတြ ခေါ= ထိုအခါ၌`（在那时）。译文“在那里”取的是处所义。
- **建议**：改为“那时，世尊对比丘们说：”。

## §1947 句 171-1947-26-49
- **问题**：措辞歧义 — bahulaṃ 的 nissaya 是 `များစွာ`（多、频繁），修饰 vihāsī。“多半”在现代汉语里常作“大概、很可能”，容易被读成揣测语气。另外 vassāvāsaṃ 的 nissaya 是 `ဝါတွင်း ၃-လပတ်လုံး`（雨季三个月全程），是时段宾格。
- **建议**：“沙门乔达摩在雨季安居期间，大多以哪一种安住而住？”

## §1947 句 171-1947-50-62
- **问题**：漏译强调成分 — `အာနာပါနဿတိသမာဓိနာ ခေါ= အာနာပါနဿတိသမာဓိဖြင့်သာလျှင်`，kho 在此作限定强调（正是、唯以），译文没有体现。bahulaṃ 的问题同上句。
- **建议**：“朋友们，世尊在雨季安居期间，大多正是以入出息念定而住。”

## §1947 句 171-1947-63-72
- **问题**：误译 — idha 的 nissaya 是 `ဣဓ= ၌`（于此、在这里），译文译成“就是这样”，凭空加了指示和强调。sato 的 nissaya 是 `သတိနှင့် ပြည့်စုံသည်ဖြစ်၍`（具足念而…），译“保持正念地”可以接受。
- **建议**：“比丘们，在这里，我具足正念地吸气，具足正念地呼气。”

## §1947 句 171-1947-109-134
- **问题**：译窄／误导 — sabbakāyappaṭisaṃvedī 的 nissaya 是 `အလုံးစုံသော ဝင်လေ ဟူသော ရှူမှု၏ အစ အလယ် အဆုံးကို ထင်ရှားသိသည်ဖြစ်၍`（清楚了知全部入息的始、中、末）。这里的 kāya 指“息身”，“体验全身”会让读者理解成肉身全身。
- **建议**：改为“我要觉知全部息身而吸气”，或“我要了知整个入息（的始、中、末）而吸气”。
- **备注**：nissaya 附注说明本经用 pajānāmi 而不用 sikkhāmi（学），是因为世尊已学成无余。译文作“我知道”是对的，修改时不要改成“我学习”。

## §1948 句 171-1948-2-13
- **问题**：句法缺成分 — `ယံ ဟိ တံ= တစုံတခုသောတရားကို`，yaṃ taṃ 是宾格“某一法”，是 vadeyya 的称说对象。译文“凡是正确地说时可以称为——”丢了“某法”这个宾语，主干不完整，读者看不出“称为”的对象是什么。
- **建议**：与下两句合起来重组，例如：“比丘们，如果有一种法，正确地说可以称为‘圣住’‘梵住’‘如来住’，那么正确地说，入出息念定就可以称为‘圣住’‘梵住’‘如来住’。”

## §1948 句 171-1948-14-29
- **问题**：取义 — nissaya 对三词的释义：
  - `ဗြဟ္မဝိဟာရော= မြတ်သောနေခြင်း`（殊胜的住）。这里的 brahma 取“殊胜”义，不是慈悲喜舍的四梵住。
  - `အရိယဝိဟာရော= ဖြူစင်သော နေခြင်း`（清净的住）。
  - `တထာဂတဝိဟာရော= မြတ်စွာဘုရား၏နေခြင်းနှင့်တူသော နေခြင်း`（与佛之住相似的住）。

  “梵的安住”很容易被读成“四梵住”。“圣的安住”“梵的安住”的“的”字结构也显生硬。
- **建议**：统一为术语式“圣住”“梵住”“如来住”。“梵住”在报告或脚注里说明此处取“殊胜之住”义，不指四无量。三处并列可作“可以称为‘圣住’，也可以称为‘梵住’，也可以称为‘如来住’”，让三个 itipi 平行。

## §1948 句 171-1948-30-34
- **问题**：句法误读 — nissaya 语序是 `သမ္မာ= ကောင်းစွာ။ ဝဒမာနော= ဆိုသည်ရှိသော်။ ဝဒေယျ= ဆိုရာ၏။ အာနာပါနဿတိသမာဓိံ= ...ကို`，ānāpānassatisamādhiṃ 是 vadeyya（称为）的宾语，不是 vadamāno（说）的宾语。译文“正确地谈论入出息念定的人，就可以称它为”，把入出息念定挂到了“谈论”上。句首“那么”也是原文没有的连接词。
- **建议**：“正确地说的人，会把入出息念定称为——”。或者按上文建议与 2-13 句合并重组。

## §1948 句 171-1948-50-69
- **问题 1**：主语错置 — nissaya 中 `တေသံ= ထိုရဟန်းတို့၏`（属格），`ဘာဝိတော ဗဟုလီကတော အာနာပါနဿတိသမာဓိ= သည်`（主格），即“他们所修习、多修习的入出息念定”导向漏尽。译文“他们修习、多多修习入出息念定，就会导向…”让“他们”成了“导向”的主语。
- **问题 2**：译窄 — appattamānasā 的 nissaya 是 `မရောက်သေးသော အရဟတ္တဖိုလ်ရှိကုန်သော`（尚未到达阿罗汉果），“心愿尚未达成”没有点出所指。yogakkhemaṃ 的 nissaya 是 `ယောဂ ၄-ပါးတို့၏ကုန်ခန်းရာ`（四轭尽处），“无上安稳”可以保留。
- **问题 3**：āsava 译“烦恼”，见跨段一致性。
- **建议**：“比丘们，那些还是有学（sekha）、尚未达到目标（阿罗汉果）、正希求无上离轭安稳而住的比丘，他们所修习、多修习的入出息念定，导向诸漏的灭尽。”

## §1948 句 171-1948-70-96
- **问题 1**：主语错置，同上句 — `တေသံ`（属格）＋`အာနာပါနဿတိသမာဓိ= သည်`（主格）。
- **问题 2**：khīṇāsavā 的 nissaya 是 `ကုန်ပြီးသော အာသဝရှိကုန်၏`（漏已尽），译“烦恼已灭尽”与 arahanto 的释义（远离 kilesa）重叠，见跨段一致性。
- **问题 3**：parikkhīṇabhavasaṃyojanā 的 nissaya 是 `ကုန်ပြီးသော ဘဝသံယောဇဉ်`（有结已尽），“对生存的系缚”可以接受，但宜与传统“有结”对得上。
- **建议**：“……已尽漏、……已彻底断尽有结（bhavasaṃyojana）、以正智解脱的比丘，他们所修习、多修习的入出息念定，既导向现法乐住，也导向正念与正知。”

## §1949 句 171-1949-2-12
- **问题**：nissaya 错位 — 本句所附 nissaya 是 `ဝဒေယျာတိ= ဆိုရာ၏ဟူ၍။ အာမန္တေသိ= မိန့်တော်မူပြီ။`，与原文 Yañhi taṃ … vadeyya 不对应（āmantesi 不在本句），无法据此核对词法。
- **建议**：本句及 §1949 后续三句是 §1948 的重复段，与 §1948 句 2-13 / 14-29 / 30-34 / 35-49 修改后的译文逐字同步。
