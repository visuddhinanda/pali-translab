## 理由

**取数缺口（信心压低的主因）**：本次只注入了本文（mūla）层的巴利原文与译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。因此「义注定释义、nissaya 定词法」两条基准都无法执行，准确性判断只能依据巴利原文本身的词形、格与句法，以及本组五经之间的平行段互校。术语所指（如 assāda 在此三项/五项观察法门中的确切义读）、隐含成分的补出是否合传统取义，均未经注释书核验——信心指数据此从 90 档降到 72。

**准确性**：五经结构高度平行，译文对结构的处理是可靠的。最值得肯定的一点：1156 与 1160 的巴利正文是 `assādañca … ādīnavañca nissaraṇañca`（三项），方括号内 `samudayañca atthaṅgamañca assādañca` 是异文；1158 与 1162 的正文才是五项。译文严格按各段正文译出（1156/1160 三项、1158/1162 五项），没有把异文混进正文，也没有让四经趋同——这正是这两对经的区别所在，处理正确。格与句法方面：`yato … pajānāti / viditvā … hoti` 的「当…时／…之后」句式、`anupādāvimutto`（因不执取而解脱）、阿罗汉九项定型语的并列关系，均与原文吻合。1160 主语为 `ariyasāvako` 而结论句为 `bhikkhu`，译文照原文译出「圣弟子…这位比丘」，未擅自统一，忠实度正确（但对中文读者构成指代跳脱，见问题清单）。扣分集中在几个关键词的汉语义项偏移：`assāda` 译「滋味」、`atthaṅgama` 译「消灭」。

**风格符合度**：全篇为现代书面汉语，**未发现文言虚词、文言句式或单音节文言词**，无「此中／故为／彼等／于…之际／答以」之类禁例，语体检查通过。标点全角，无 ASCII 引号，符合 JSON 安全约束。译文内无任何候选、待定、问号等工作标记，符合「不留工作标记」硬约束。扣分项：`bhavasaṃyojana` 译为「彻底断尽了导向轮回再生的结缚」属解释性增译，超出词义本身；夹注策略不一致（只给 āsava 夹注，sotāpanna 等同样需要的术语未给）。

**一致性**：跨五经的定型语（「比丘们，有这五种根。」「哪五种呢？」「信根、精进根、念根、定根、慧根」、阿罗汉九项）逐字一致，经末「第一经…第五经」体例统一，1156/1158 与 1160/1162 两组的结论句分别自洽。唯一不统一处是术语夹注的取舍。

**关于「诸漏已尽」**：`khīṇāsavo` 译「诸漏已尽」中的「诸」虽为文言复数标记，但「漏尽／诸漏已尽」是佛教定型术语而非文言腔，本次**不按文言语体扣分**，此处明确交代判断依据。

## 问题清单

### 🟨 warning

- `171-1152-2-4`｜关键词语意不明确｜片段「单纯品」
  - 问题：suddhika 在此指「不加增说的基础版本」（这一品的诸经只列五根、不展开），Bodhi 作 "Simple Version"。现代汉语「单纯」首义是性格天真质朴，读者难以联想到「简略版」。
  - 建议：改为「简略品」或「纯说品」；若沿用「单纯品」，须在品题下加一句注说明 suddhika 指「不作增广的基础形式」。

- `171-1153-2-4`｜关键词语意不明确｜片段「单纯经」
  - 问题：同上，经题与品题同词，误解风险一致。
  - 建议：与品题取同一改法，保持「品—经」同词同译。

- `171-1156-27-77`｜关键词语意不明确，或二意场合没有注释｜片段「滋味」
  - 问题：`assāda` 在 assāda / ādīnava / nissaraṇa 三支观察中指对所缘的「可爱悦乐、爱味」，是与「过患」相对的贪着面；「滋味」在现代汉语偏中性（食物的味道），关键义项（悦乐、可贪着）失落。同一译法见于 `171-1158-27-60`、`171-1160-27-85`、`171-1162-27-64`，四处并存，一并处理。
  - 建议：改为「悦味」或「爱味」，首次出现夹注（assāda）；或保留「滋味」但加注说明指「令人贪着的悦乐」。

- `171-1158-27-60`｜不导致误解的汉语语病｜片段「生起、消灭」
  - 问题：`samudaya / atthaṅgama` 是一对自动词性的生灭，而现代汉语「消灭」是及物动词（消灭某物），与自动的「生起」并列不对称，读来像有施动者在消灭五根。同一译法见于 `171-1162-27-64`。
  - 建议：改为「生起、灭没」或「生起、消失」，与「生起」保持同为自动的对称结构。

- `171-1156-27-77`｜关键词语意不明确，或二意场合没有注释｜片段「如实了知这五种根的滋味、过患与出离时」
  - 问题：本段正文为三项，而下一经 `171-1158-27-60` 正文为五项，方括号异文（samudayañca atthaṅgamañca assādañca）恰与下一经正文相同。译文对异文既未采纳也未出注，读者会以为第二、第三入流者经内容重复或某处漏译。此为典型「二意场合」。
  - 建议：在 1156（及同构的 1160）加脚注：「另有传本作『生起、消灭、滋味…』，即下一经之形式。」既交代异文，也点明两经的区别所在。

- `171-1160-27-85`｜代词指代不明确｜片段「就因不执取而解脱——比丘们，这位比丘就被称为阿罗汉」
  - 问题：本句前半主语是「圣弟子」（原文 `ariyasāvako`），结论句却换成「这位比丘」（原文 `bhikkhu`）。译文忠于原文，但中文读者会误以为换了对象，或疑心译文出错。对照 `171-1162-27-64`，该经前后都是 `bhikkhu`，两经并读更显突兀。
  - 建议：不改译文主语（原文如此），加脚注说明「原文前作『圣弟子』、后作『比丘』，部分传本前后均作『比丘』」。

### 🟦 suggestion

- `171-1154-12-19`｜该使用而没有使用术语标记｜片段「有这五种根」
  - 问题：`pañca indriyāni` 的定型汉译是「五根」，通篇作「五种根」读作临时计数短语，术语感偏弱；`171-1154-23-42` 的「这就是五种根」同。
  - 建议：首次出现作「五根（pañca indriyāni）」，其后统一用「五根」；需要强调数目时才用「这五种根」。

- `171-1156-27-77`｜该使用而没有使用术语标记｜片段「已入流者」
  - 问题：`sotāpanna` 是四果第一果的核心术语（传统亦作「预流者／须陀洹」），属首次出现应夹注之列，但全篇未给巴利原词；经题「第一入流者经」（`171-1155-2-4`）亦同。
  - 建议：首次出现作「已入流者（sotāpanna）」。

- `171-1160-27-85`｜语言表达不够流畅｜片段「彻底断尽了导向轮回再生的结缚」
  - 问题：`bhavasaṃyojana` 字面为「有（存在／再生）的结缚」，「导向轮回再生的」是解释性扩充，属增译；且定语过长，与同句其余八项的短促节奏不协。`171-1162-27-64` 同。
  - 建议：正文作「彻底断尽了有（bhava）的结缚」，把「导向轮回再生」的解释移入脚注。

- `171-1160-27-85`｜语言风格不统一｜片段「诸漏（āsava）已尽」
  - 问题：全篇仅此一处使用圆括号夹注巴利原词，而同等甚至更需夹注的 sotāpanna、assāda、bhavasaṃyojana 均未夹注，夹注取舍看不出统一标准。
  - 建议：按 `knowledge/style.md` 第二节，把「罕见或有争议」与「法相核心」两类统一处理：要么 āsava / sotāpanna / assāda 都夹注，要么都只出脚注，避免单点夹注。
