## 理由

**基准缺失（影响信心）**：本次注入的资源只有巴利原文与目标 channel 译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。释义标准与词级基准都缺位，准确性一栏只能靠原文形态、并行段落互校与通行译解传统判断，`sappāṭihāriya` / `sāmīcipaṭipanna` / `visārada` 这类恰恰需要义注定夺的词无法核实。因此信心压到 60，低于可作最终验收的水平——建议补齐义注后重跑一次评估。

**准确性**：叙事段（1578 前半）逐词覆盖完整，`acirapakkante āyasmante ānande` 的独立处格、`uṭṭhāyāsanā / abhivādetvā / padakkhiṇaṃ katvā` 的动作序列、`avidūre aññatarasmiṃ rukkhamūle` 的地点状语都处理正确，`yassa dāni kālaṃ maññasi` 取了通行解读，未见漏译或增译。主要扣分在两处：一是 `māro pāpimā` 把形容性称号 `pāpimā` 当作专名并列在意译的「恶魔」之后，形成两个名号的读感；二是 1582 的 peyyāla（`upāsakā … pe … upāsikā`）合并处理后，把阴性的「女弟子」同时管辖到「男居士」头上，句子在汉语里读不通——这是原文省略体例造成的陷阱，1583 用「男居士弟子……女居士弟子」躲开了，1582 没有。四字格长串（`viyattā … anudhammacārino` 九项）整体对位准确，但「走上相称的道路」「已受调练」两项语义已明显磨损。

**风格符合度**：无文言虚词、无文言句式，代词与称谓稳定，标点为全角，`zh` 字段无 ASCII 引号，符合硬约束。扣分集中在术语层：九项德目连排成清一色四字格，其中「精熟自信」「已受调练」是为凑字数造的词，不是现代书面汉语里能自解的搭配；「依法随法而行」与「习于随法而行」相邻出现却几乎同形，普通读者无法区分二者所指。另外 `…pe…` 译作「……乃至……」属通行体例，可接受，但正文里出现三次而全无说明，非专业读者不知其为省略号式套语。

**一致性**：五处 `Parinibbātu dāni … Parinibbānakālo dāni` 套语完全一字不差，比丘 / 比丘尼 / 居士三组德目串也逐字对齐，跨段一致性很好，这是本批的强项。唯一的不一致来自引号体例：1580 / 1581 / 1582 / 1583 段首都随巴利 `‘‘` 开了左引号，1579 段首没有；内层单引号在 1578-108-168、1580-13-60、1582-13-64 收了 `’` 却没有相应闭合外层 `”`。巴利底本本身体例不整，但汉译应自行统一。

## 问题清单

### 🟧 error

- `171-1582-13-64`｜导致误解的表达｜片段「我的男居士……乃至……女居士还没有成为这样的女弟子」
  - 问题：`upāsakā … pe … upāsikā` 是两段省略并置，前半省掉的是阳性系列（`sāvakā … anudhammacārino`），后半才是 `sāvikā … anudhammacāriniyo`。译文只保留了阴性的「女弟子」，结果「男居士」被判给「女弟子」，汉语读不通，也让读者以为男居士要成为女弟子。
  - 建议：拆开承担两组，或改用中性表述，如「只要我的男居士……乃至……女居士还没有成为这样的弟子——」，把性别信息交给「男居士／女居士」本身。
- `171-1583-2-49`｜不导致误解的表达但同源｜片段「男居士弟子……乃至……女居士弟子」
  - 问题：此处并置处理得当，但原文 `sāvikā` 同样只覆盖后半；译文以「弟子」统摄两者已属合理，只是「男居士弟子」这一叠称生硬。
  - 建议：改为「如今世尊已经有了这样的男居士……乃至……女居士弟子——」，与 1582 的修法保持同一策略。

### 🟨 warning

- `171-1578-48-60`｜关键词语意不明确｜片段「恶魔（māra）波旬（pāpimā）」
  - 问题：`māra` 意译为「恶魔」、`pāpimā` 音译为「波旬」并列夹注，两种策略混用，读起来像「恶魔」与「波旬」是两个所指；`pāpimā` 实为「恶者」这一称号，不是名字。
  - 建议：统一为「恶魔波旬（māra pāpimā）」一处夹注，或「魔罗（māra）这个恶者」，避免两名并列的读感。后文呼格「波旬」照此保持不变即可。
- `171-1578-108-168`｜关键词语意不明确，二意场合没有注释｜片段「宣说能导向出离的法」
  - 问题：`sappāṭihāriya` 传统有两读（一读近 saniyyānika「能导出离」，一读为「无瑕／有效验」），译文取前者而未出注。义注未注入，无法核定取义是否与释义标准相符。
  - 建议：保留现译并加一处译注说明异读；待义注可查时复核，若义注取另一读则须改译。
- `171-1578-108-168`｜关键词语意不明确｜片段「走上相称的道路」
  - 问题：`sāmīcipaṭipanna` 译作「走上相称的道路」，「相称」无所对——与什么相称，读者无从判断，语义几近空转。
  - 建议：补出所与相称者，如「行于与法相顺的道路」「如法而行」，并在术语表登记统一译法。
- `171-1578-108-168`｜关键词语意不明确｜片段「已受调练」
  - 问题：「调练」非现代书面汉语常用词，`vinīta` 的「受过训导」义在此不易读出。
  - 建议：改为「受过教导」「善学有素」一类现代表述，九项德目全段同步替换。
- `171-1578-108-168`｜标点符号使用错误｜片段「在此之前，我是不会入般涅槃的。’」
  - 问题：内层引语收了 `’`，但作为魔所述话语的外层 `”` 未闭合；`171-1580-13-60`、`171-1582-13-64` 同。同时 `171-1579-2-41` 段首缺左引号，而 1580 / 1581 / 1582 / 1583 段首都有，体例不齐（巴利底本本身不齐，汉译应自行统一）。
  - 建议：按汉语规范——同一段引语跨段时每段开左引号、仅末段闭合右引号——统一全六段；内层单引号结束处按是否收束魔语决定是否补 `”`。

### 🟦 suggestion

- `171-1578-108-168`｜语言表达不够流畅｜片段「习于随法而行」
  - 问题：与同串中「依法随法而行」（`dhammānudhammappaṭipanna`）几乎同形，`anudhammacārī` 与前者的区别在译文里消失，读者会以为重复。
  - 建议：让两者形态分开，如前者「依法随法而行」、后者「言行都顺乎法」。
- `171-1578-108-168`｜语言风格不统一｜片段「精熟自信」
  - 问题：`visārada` 的「精熟」与「自信」被压进四字格，属为对齐句式而造的词。整串九项全用四字，节奏单一，牺牲了可读性。
  - 建议：允许长短不齐，把 `visārada` 译为「临事不怯」或「应对从容」一类可自解的表述。
- `171-1579-2-41`｜整句逻辑表达可优化｜片段「可是如今世尊已经有了这样的比丘弟子」
  - 问题：`Santi … bhagavato sāvakā` 原为「（现在）有世尊的比丘弟子」，译文改成「世尊已经有了」，主语由弟子转为世尊，与下句「请世尊入般涅槃」的施压逻辑略隔一层。
  - 建议：可作「尊者，如今世尊的比丘弟子中，已经有这样的人——」，1581 / 1583 三处并行段同步。
