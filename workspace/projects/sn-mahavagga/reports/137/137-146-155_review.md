# Review — 137:146-155（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **被解释词与父层对照**：已逐条核对。sīlasampannā / samādhi·paññā / vimutti / vimuttiñāṇadassana / dassanampāhaṃ / savana / upasaṅkamana / anussati / taṃ dhammaṃ / anussarati / anuvitakketi / pavicinati / pavicarati / parivīmaṃsamāpajjati / satta phalā sattānisaṃsā / diṭṭheva dhamme…ārādheti / antarā- / upahacca- / sasaṅkhāra- / asaṅkhāraparinibbāyī 均与父层逐字一致。payirupāsana（父层“随侍那些比丘请法”）、anupabbajja（父层“跟随那些比丘出家”）两处，父层在被解释词中间插入了宾语，注层取“随侍请法”“跟随出家”，词本身没有改动，可以接受。不一致的共三处：§151 āraddho hoti、§152 atha maraṇakāle、§154 akaniṭṭhagāmī，分别列在下文对应句下，均为必改项。
- ovādānusāsanī：§149 三处译“教诫教导”，§151 译“教诫和教导” → 建议统一为“教诫教导”，§149 出现次数多。
- uddhaṃsoto akaniṭṭhagāmī：§154 改为“**到达色究竟天**的人”之后，§155 非黑体的两处“上流者、到达色究竟天者”也要同步改成同一说法，避免同一术语出现两种写法。

## §151 句 137-151-19-24
- **问题**：被解释词与父层不一致（必改）。本条的 āraddho hoti 对应父层 sambojjhaṅgo…āraddho hoti，父层译作“就已在这位比丘身上完备了”，父层没有“已经完备”这个连续字串。父层能逐字找到的是“已完备”（171-439-40-51“就已完备”）。
- **建议**：改为“**已完备**，就是已经圆满。”nissaya：ပရိပုဏ္ဏော ဟောတိ= 是圆满的，释义部分不用改。

## §152 句 137-152-30-36
- **问题**：被解释词与父层不一致（必改）。父层原文是“那么他会在临终的时候”，注层黑体“那么在临终的时候”在父层里不是连续字串。
- **建议**：黑体改用父层的连续片段，例如“**在临终的时候**，就是（那么）在临近死亡的时候。”如果要把 atha 也包进黑体，就整段取“**那么他会在临终的时候**”。

## §154 句 137-154-34-46
- **问题**：被解释词与父层不一致（必改）。akaniṭṭhagāmī 在父层译作“最终到达色究竟天”，没有“者”字，注层黑体写成“**到达色究竟天者**”，多了一个字。
- **建议**：黑体只保留父层原字，例如“……就叫做**上流者**、**到达色究竟天**的人。”另外，原文 Avihādīsupi 的 -pi 没有译出，可补“也”，即“投生在无烦天等处的人也……”，这一点可改可不改。

## §148 句 137-148-25-42
- **问题**：格与句法。nissaya 把三个具格逐一分配到各自的宾语上：vipassanāya 对应看见 lakkhaṇa（ဉာတပရိညာ／တီရဏပရိညာ 见自相、共相）；maggaphalehi 对应 paṭividdhassa paṭivijjhanaṃ，即通达谛／涅槃的真实相；jhānena 对应看见遍处等（nissaya 补出 ပထဝီကသိဏာဒီနိ）。现译文把“以禅那、以观、或以道果”笼统地并列在两个动作前面，看不出这种对应关系。
- **建议**：按对应关系拆开，例如：“而以观看见诸圣者所见的相，以道果通达诸圣者所通达的〔真谛〕，或以禅那看见〔地遍处等〕，这叫做智见。”nissaya 补出的宾语可以视情况保留。

## §149 句 137-149-78-90 / 137-149-91-106
- **问题**：补出成分。nissaya 把 aññattha 释为“教外的隐士、游方者等人那里”，把 aññesu 释为“教内僧人以外的隐士、游方者等”。现译“别处”“另外一些人”指向不明，读者看不出说的是外道出家。
- **建议**：可译为“在别处（教外的隐士、游方者那里）出家”“对其他人（教外的隐士、游方者等）有净信”，或者在报告层面加注说明。

## §151 句 137-151-25-31
- **问题**：句法。nissaya 把 tattha 释为“在那教诫教导之法上”。现译“在那里”容易被理解成地点。
- **建议**：改为“**简择**等等，全都是就智在那个法上的运作而说的。”

## §152 句 137-152-10-29
- **问题**：格与句法。nissaya 把 ārādhento 释为 ပြီးစေသည်ရှိသော်，是“当他成就时”的时间／条件分句，不是名词化的“证得阿罗汉果的人”。另外，夹注“（attabhāva，此身）”把巴利词和汉语释义混在一个括号里，读起来不清楚。
- **建议**：改为“意思是：他证得阿罗汉果时，就在这一生（attabhāva）中证得，而且是提前证得，也就是在临终的时候还没有到来时就证得。”

## §154 句 137-154-2-11
- **问题**：补出成分。“也就是过了寿命的中段以后”这一句原文里没有。nissaya 给 upahaccaparinibbāyī 这个词的释义（အသက်အထက်အပိုင်းသို့ ရောက်၍，到达寿命的上半段）可以支持这层意思，但它是对术语的解释，不是本句的内容。现在的写法让读者以为这是原文本身的话。
- **建议**：删去，或者改用括号标出是补充说明，例如“超过第五个一百劫（即过了寿命的中段）才证得阿罗汉果的人”。属低优先级。

## §155 句 137-155-53-62 / 137-155-65-77
- **问题**：词义。nissaya 把 jeṭṭha／kaniṭṭha 释为 အကြီး／အငယ်，指年辈上的长与幼，判断依据分别是寿命和证果先后。现译“最大的／最小的”在汉语里容易被理解成体量或地位。另外，kaniṭṭha 和 akaniṭṭha 在原文里是双关，用“最年幼”比用“最小”更贴近原意。
- **建议**：改为“既是所有人当中最年长的，也是最年幼的”；后句相应改为“按寿命说他是所有人当中最年长的……所以他是所有人当中最年幼的”。

## §155 句 137-155-78-88
- **问题**：句法。nissaya 把 pubbabhāgavipassanā 处理成 bojjhaṅgā 的修饰语（ဝိပဿနာဖြစ်ကုန်သော，作为前分观的）。现译“诸觉支……是……属于阿罗汉道前分的观”中修饰语过长，读起来像是在判断“觉支就是观”。
- **建议**：改为“这部经讲的是作为阿罗汉道前分观（vipassanā）的诸觉支：它们不分先后，生起在同一个心刹那中，各有不同的相。”

## OCR / 原文疑问（记录，不改）
- §150：pali 原文的传承链是 Candagutta → Sūriyagutta → Assagutta，nissaya 漏掉了 Sūriyagutta，直接写成“Candagutta 的弟子 Assagutta”。这是 nissaya 文本本身的缺漏，译文依照 pali 译出，没有问题。
- §151 句 137-151-14-18：nissaya 中 vitakkāhataṃ 释作 ဝိဘတ်ဖြင့်，疑为 ဝိတက်（vitakka）之误。
- §155：同一段内 aṭṭhacattārīsa（55-2-9）与 aṭṭhacattālīsa（36-52）写法并存，属于异体，不算讹误。
