# Review — 137:793-806（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅
> 父层对照：§794 **王园**、§806 **一切恶趣的怖畏**／**已经超越了**，与父层 171:2101、171:2114 的译文逐字一致 ✅。§804 的两处被解释词（udayagāminin、maraṇaṃ āgameyyāsi）出自婆罗门经（171:2103–2112），这部分父层译文不在本次对照里，**无法逐字比对，定稿前须对照父层补核**。

## 跨段一致性

- **vaṇṇanā**：§793 译“……经的**解释**”，§803、§805 译“……的**注释**” → 建议统一为“注释”（3 处里占 2 处）。
- **经名书名号**：§803 用《婆罗门经》，§793、§805 的经名不加书名号 → 建议统一为不加，与父层“千位比丘尼僧团经”“恶趣怖畏经”的体例一致。
- **引语后的 pucchi 重复**：§794 句 81-89 已写“国王说：‘这是什么？’”，句 90-91 又写“他这样问道”；§795 句 19-40“……说：‘……’”与句 41-43“他这样问道”也是同样情况 → 读起来像说了两遍。建议前句不用“说”，只保留主语和引语，例如“国王：‘这是什么？’”，或者改成“国王问起这件事：‘这是什么？’”，后句保留“他这样问道”。两处要用同一种处理。
- **被解释词的排版**：§794、§806 的被解释词不加引号，多个被解释词之间用“、”；§804 句 13-21 却写成“‘**死亡**，**你应当希求**’”，加了引号，中间用逗号 → 建议统一为 §806 的体例（不加引号、用“、”）。
- **经序引导语**：§794“在第二品的第一经中”、§806“在第四经中”，§804 写成“第二经中”，缺“在” → 建议统一补“在”。
- **巴利原词夹注**：跋鲁王第一次出现在 §798 句 2-11（“名叫跋鲁的国王”），那里没有夹注；夹注“（Bharurāja）”却放在了 §800 → 如果要夹注，应移到 §798 第一次出现的地方，§800 删去。
- **讲本事时的引号**：§797 句 31-83 末尾和句 84-93 是佛陀对国王说的话，没加引号；紧接着的句 94-96 是国王的回答，却加了引号 → 两人的对话一边有引号一边没有。建议佛陀这两句也加引号，或者国王的回答也去掉引号。§798 以下是长篇本事叙述，可以不加。

## §794 句 137-794-49-66
- **问题**：词义 — bhūmisīsaṃ = ‌မြေတကာတို့ဦးခေါင်းမြတ်သော အရပ်ကို，意思是“各处地方中最好的地段”，并不指某一块特定的土地。译文“那块土地上最好的地方”多了一个“那块”的限定，读起来像是在说某块已经提到过的地。
- **建议**：改为“他其实只是占到了一块最好的地段”。

## §794 句 137-794-67-80
- **问题**：术语 — kahāpaṇe = အသပြာ，这是一种货币名称，“十万钱”太泛，读者看不出是什么钱。
- **建议**：可以考虑译作“十万迦哈波那（kahāpaṇa）”，也可以保留“钱”。这一项不是必改，定案后登记进 terms.md。

## §796 句 137-796-9-21
- **问题**：隐含成分 — nissaya 补出了主语 အမစ္စာ = 大臣们，译文写成“有人”。
- **建议**：可以改为“大臣们向国王报告说”。这一项不是必改。

## §797 句 137-797-11-30
- **问题**：词义 — sārapallaṅke = မြတ်သော ပလ္လင်၌，nissaya 把 sāra 解作“上好的、珍贵的”，指的是座位的品级。译文“坚木做的座椅”取了 sāra“心材”的意思，与 nissaya 不合。另外 nivesanaṃ = နန်းတော်（王宫），“住处”太泛。
- **建议**：改为“把导师请进宫中，请他坐在上好的宝座上”。

## §798 句 137-798-51-78
- **问题**：句法 — 这里的 ti 是心想的标记。nissaya 写作 ဣတိ = ဤသို့နှလုံးပြု၍（这样想着），可见是仙人们心里的念头，并没有说出口。译文写成“说：‘这棵树很大……’”，把心里想的变成了说出口的话。
- **建议**：改为“来到的那些仙人心想：‘这棵树很大，容得下我们，也容得下他们。’”

## §798 句 137-798-222-228 ／ §799 句 137-799-71-76
- **问题**：指代 — 两处“那些仙人”“他们”都没说清是哪一群，读者容易搞混。nissaya 补得很明确：前一处是 လုနေသော ရသေ့ = 占着树下的那群仙人，后一处是 ရှေးဦးတံစိုးပေးသော ရသေ့ = 先前送了贿赂的那群仙人。
- **建议**：前一处改为“把占着树下的那些仙人赶了出去”，后一处改为“把先前送礼的那群仙人赶了出去”。

## §802 句 137-802-65-68
- **问题**：指代 — taṃ = ထို……ကျောင်းတော်ကို，指的是波斯匿王建的那座精舍；etaṃ = ရာဇကာရာမေ ဟူသောဤစကားကို，指经文里“王园”这个词。译文“这句话就是针对那件事说的”把 taṃ 译成了“那件事”，也没有点明 etaṃ 指的是被解释词。
- **建议**：改为“经中说的‘王园’，指的就是这座精舍。”

## §804 句 137-804-6-12
- **问题**：隐含成分 — nissaya 补出了被修饰的名词：（ပဋိပဒံ = 行道 ／ ပညပေန္တိ = 施设）。vaḍḍhigāminiṃ 修饰的是“行道”，译文“趋向增长的那一种”没有交代“那一种”是什么。另外，被解释词“**趋向上升的**”还要按父层 171:2103–2112 的译文核对。
- **建议**：改为“是指（他们）在自己的教义里所施设的、导向增长的行道”。

## §804 句 137-804-13-21
- **问题**：词义与语气 — nissaya 用了两个不同的词来解释被解释词：iccheyyāsi = အလိုရှိလေသော（想要），pattheyyāsi = တောင့်တလေသော（渴求）。可是被解释词 āgameyyāsi 本身也译成了“希求”，和第二个释词撞了字，读起来像是用一个词自己解释自己。再者，nissaya 的 -လေသော 是祈愿语气，译文“应当”带上了义务的意思，与 nissaya 不合。被解释词的译法还要按父层核对。
- **建议**：先按父层定下被解释词的译法，再让两个释词与它错开，例如“是说你会想要死亡，或者会渴求死亡”。

## §806 句 137-806-2-13
- **问题**：句法 — nissaya 把整个被解释语作具格理解（ဟူသော ပါဌ်ဖြင့်），意思是“用这句话排除了人间的不幸”。译文“是指……”把它改成了判断句，说法不准确。另外，原文没有 pi，“也被排除了”里的“也”没有依据。
- **建议**：改为“以这句话排除了人间的不幸（manussadobhagga）”。
