## 跨段一致性

- **Tissa 名号的语序**：§1844 句 102-178 里有「帝须比丘尼」「帝须沙弥尼」，也有「式叉摩那帝须」「沙弥帝须」，同一组列举里名字前置和后置混用。同章 §1845 句 60-79 统一用「帝须比丘」「帝须沙弥尼」（名字前置）→ 建议全部统一为名字前置：帝须比丘、帝须比丘尼、帝须式叉摩那、帝须沙弥、帝须沙弥尼。
- **学处名称的写法**：
  - §1846 写「第一迦絺那学处」，§1856 写「断人命学处」，§1860 写「浇洒学处」，都带“学处”。
  - §1850 句 60-62 只写「等起等与不与取相同」，缺“学处”，容易被读成“与不与取这种行为相同”。
  - → 建议改为「不与取学处」。
- **sammukhā / parammukhā 的对译**：「当面」和「间接」不成对，读者看不出两者是同一组对立概念。参见下文 §1845 句 207-1845-2-5。
- **§1844–1845 中“对方 / 另一方 / 那位比丘”的指代**：
  - 「那位比丘」在 §1844 句 188-220 和 §1845 句 80-110、120-147 中都指受托作净施的比丘。
  - §1845 句 46-59 的「对方」也指这位比丘。
  - §1845 句 60-79 的「另一方」却指衣主。
  - 同一段里两个人轮流出现，「对方 / 另一方」的指代不稳定。参见下文对应句。

## §1844 句 207-1844-16-55

- **问题**：取义 — sannihitāsannihitabhāva 译成「在场还是不在场」。nissaya 的解释是「放在近处 / 不放在近处」（သံ= 近处 + နိဟိတ），并把 imaṃ / etaṃ 分别标为「近处一件」「远处一件」的说法。“在场”容易让人理解为衣主或受者是否在场，偏离了原意（衣放得近还是远）。§1844 句 102-178 和 §1845 句 6-45 也有同样的译法。
- **建议**：三处统一改为「放在近处还是远处」。

## §1844 句 207-1844-69-101

- **问题**：准确性 — 「这是属于我的，这些是属于我的」把单数（mayhaṃ santakaṃ）和复数（mayhaṃ santakāni）译成了两句并列的话。原文是按衣的件数二选一的说法，与前文「这件衣 / 这些衣」对应。
- **建议**：改为「属于我的这件衣（或：这些衣），你可以穿用、送出，或者随意处置」，或者用「或」把两种说法连起来。
- **附**：出处标注「（《波逸提》374）」宜按项目统一的引文体例书写，例如「《波逸提》第374段」。

## §1845 句 207-1845-2-5

- **问题**：术语存疑。nissaya 的语法注把 sammukha 解释为「以自己的口作净施」，把 parammukha 解释为「以他人之口作净施」（မိမိ၏နှုတ် / သူတစ်ပါး၏နှုတ်）。它还特别指出：第二种 sammukhā 是向不在面前的人提名，也仍然叫 sammukhā（§1844 句 102-178 的 nissaya 注）。这样看，「当面」只抓住了字面意思，第二种「当面净施」里受者其实不在面前，读者会困惑。「间接」与「当面」也不成对。
- **建议**：这一项不强制改动，请定案后写进 `terms.md`。可选方案：
  - 「当面净施 / 背面净施」：保持字面对称。
  - 「自说净施 / 他说净施」：贴合 nissaya 的解释。
  - 维持现译，但在首次出现处夹注巴利原词。

## §1845 句 207-1845-46-59 / 207-1845-60-79

- **问题**：指代不清。
  - 句 46-59 的「对方应当问」：tena 指受托比丘（nissaya：ကိုယ်စား ဝိကပ္ပနာပြုပေးမည့် ရဟန်း）。
  - 句 60-79 的「另一方」：itarena 指衣主（nissaya：သင်္ကန်းရှင်ရဟန်း）。
  - 读者无法从「对方 / 另一方」分辨这两个人是谁。
- **建议**：句 46-59 改为「受托的比丘应当问」；句 60-79 改为「然后衣主应当按前面的方法说……」。

## §1845 句 207-1845-152-179

- **问题**：句法和可读性 — 后半句「或者没有凭着与共同完成这项律制程序（vinayakamma）的那个人之间的亲信关系去取用就穿用」结构缠绕。「与共同完成……的那个人」重复表达了“共同”，句子不通顺。nissaya 的读法是：yena (saddhiṃ) vinayakammaṃ kataṃ, tassa vissāsena aggahetvā，即“没有凭着与自己一起作这项律事的那位比丘的亲信关系去取用”。
- **建议**：改为「或者没有凭着与自己一起作这次净施的那位比丘之间的亲信关系去取用，就穿用了，犯波逸提」。另外，vinayakamma 的译名「律制程序」是新词，需要在 `terms.md` 定案。

## §1846 句 207-1846-29-36

- **问题**：句法 — nissaya 把 paccuddhāraṇasaññissa 和 vissāsena paribhuñjantassa 分成两种不犯的情况（各带一个「လည်းကောင်း」）。译文「以为已经解除的、凭着亲信而穿用的」中间用顿号连接，容易被读成同一个人同时满足两个条件。
- **建议**：改为「但以为已经解除而穿用的，凭着亲信而穿用的，以及疯狂者等，不犯」，让两种情况明确分开。

## §1855 句 207-1855-10-22

- **问题**：措辞 — upakkama 译成「所下的功夫」，口语化，而且偏离了律学术语（加行，指为达到目的所采取的手段、动作）。
- **建议**：改为「由于所用的加行（手段）大」，或「由于杀它所费的力气大」。

## OCR / 原文疑问（只记录，不改）

- **§1844 句 12-15 和 §1845 句 2-5**：原文作 sammukhā- / parammukhā-vikappanā。nissaya 的语法注明确说，在这条学处里不应读作带 -ā 的不变词形式，应作 sammukha- / parammukha-。
- **§1846 句 2-28**：原文 appaccuddhāraṇaṃ。nissaya 的语法注认为应读 apaccuddharaṇaṃ（不作 vuddhi），并说 ṭīkā 写作 akatapaccuddharaṇaṃ。§1845 句 152-179 的 akatappaccuddhāraṃ 也有同类异读。
