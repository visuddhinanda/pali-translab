## 跨段一致性

- **Thullanandā**：§2292 译“偷兰难陀”，§2306 译“偷罗难陀” → **必改**，统一为“偷兰难陀”（传统通行译名，且本 chunk 先出现）。
- **vaṇṇanā（标题）**：§2290 / §2293 / §2294 / §2296 / §2301 译“释”（厚外衣学处释、舍堕释完毕），§2297 / §2300 / §2304 / §2307 / §2308 / §2311 / §2312 / §2315 / §2316 / §2319 / §2320 / §2323 译“释义” → **必改**，统一为“释义”（多数用法）。
- **samuṭṭhānādīni … sadisāni 中的参照学处名**：§2292 “媒合学处”、§2306 “羊毛学处”、§2314 “第一波罗夷”用简名；§2310 用描述性引号“‘和比丘尼相约走同一条远路’的学处” → 建议统一为简名，如“与比丘尼同行远路学处”，不加引号。
- **rāga / kāmarāga**：§2317 kāmarāga 与 §2321 rāga 都译“爱欲” → 可接受；如要区分，kāmarāga 作“爱欲”、rāga 作“贪欲”。非必改。

## §2291 句 207-2291-42-53
- **问题**：术语 — `nissaggiyaṃ` 在父层统一作“舍堕”，这里译“应舍物”，读者不易把它和“舍堕”对上。nissaya：`နိသဂ္ဂိယံ= စွန့်ထိုက်သည်`（应舍的）。
- **建议**：改为“得到之后，那件外衣就成为应舍的（犯舍堕）”，或至少写“应舍弃的”，以便和父层“舍堕”呼应。

## §2292 句 207-2292-2-15
- **问题**：术语所指 — 本学处属舍堕，`tikapācittiyaṃ` 指的是三种情形犯**舍堕**（尼萨耆波逸提）。直接写“犯波逸提”，读者会误以为是单堕。
- **建议**：改为“有三种情形犯舍堕”。§2306、§2322 属单堕篇，保持“波逸提”不变。

## §2292 句 207-2292-42-53
- **问题**：取义偏窄 — `ananuññātaṭṭhāne viññatti` 中 ṭhāna 指“对象/处所”。nissaya 注：`ဉာတကပဝါရိတ မဟုတ်သူတို့ အထံ၌`，即向非亲戚、非曾邀请者乞求。“向不被允许的对象乞求”的意思大致对，但“不被允许”像是在说对方被禁止。
- **建议**：改为“向未获开许的对象（非亲戚、非曾表示可随意索取的人）乞求”。

## §2306 句 207-2306-14-38
- **问题 1**：术语策略不一 — palaṇḍuka 意译为“洋葱”，bhañjanaka、haritaka 却音译，cāpalasuṇa 又半音半意（“遮波蒜”）。四个名称并列，处理却各不相同。nissaya 的解释是：palaṇḍuka = 一瓣的黄葱，bhañjanaka = 两瓣的红葱，haritaka = 三瓣的青葱，cāpalasuṇa = `ကြက်သွန်မြိတ်`（蒜苗/韭类）。这正好与 §2305 的“一瓣、两瓣或三瓣”对应，现译文让读者接不上。
- **建议 1**：统一用意译加夹注，例如“洋葱（palaṇḍuka）、红葱（bhañjanaka）、青葱（haritaka）、蒜苗（cāpalasuṇa）”，并压低 confidence；分歧留待定入 terms.md。
- **问题 2**：取义与 nissaya 不符 — `sāḷave` 的 nissaya 是 `ကြက်သွန်ဖြူထည့်၍ ပြုအပ်သော ဆီးယို`（加蒜做的枣酱/果酱，nissaya 读本作 padarasāḷava）；`uttaribhaṅge` 则是 `လက်သုတ်ဟင်းလျာ`（加蒜的拌菜）。译文把 sāḷava 译成“凉拌菜”，更接近 uttaribhaṅga 的意思。
- **建议 2**：sāḷava 改为“加在果酱（或调味酱）里的”，uttaribhaṅga 改为“加在拌菜里的”。

## §2310 句 207-2310-2-19
- **问题**：释义偏差 — `āpattibhedo natthi` 的 nissaya 注是：不分“隐处作隐处想 / 作非隐处想 / 怀疑”三种波逸提，也没有非隐处作隐处想之类的恶作。意思是**犯戒类别不作细分**，不是“等级”。
- **建议**：改为“犯戒的类别没有细分”。§2314-2-15 同句同改，§2314-16-25 的“这种区分”随之一致。

## §2313 句 207-2313-2-14
- **问题**：漏译 — 原文 `muttakaraṇassa talaghātane muttakaraṇamhi pahāradāne` 先解释 talaghātaka 就是“拍击小便处的表面、对小便处施以拍打”，然后才说“乃至用花须”。译文把这层释义并掉了，只剩举例。
- **建议**：“意思是，拍打小便处的表面，也就是对小便处施加拍击，哪怕只是用一根青莲花的花须，都犯波逸提。”

## §2314 句 207-2314-16-25
- **问题**：误导 — “我们就不再说明，直接略过”容易读成整条学处都略过。原意是：以后凡没有犯戒类别细分的学处，就不再特别写“āpattibhedo natthi”这句话。nissaya：`"အာပတ္တိဘေဒေါ နတ္ထိ" ဟု မဆိုတော့ဘဲ`。
- **建议**：“从这里往后，凡是犯戒类别没有细分的学处，我们就不再特别指出这一点。”

## §2317 句 207-2317-9-17
- **问题**：用词 — `vatthuvasena` 的 vatthu 在本 chunk 其他各处都指制戒因缘（“…一事而制定”）。这里译“根据事件”稍泛。
- **建议**：“这是按照制戒因缘中的情形来说的”。非必改。

## §2318 句 207-2318-2-11
- **问题**：取义偏窄 — `sādiyana` 是“受用、享受”，nissaya 作 `သာယာခြင်း`，“使用”丢掉了享乐的意味。不过父层 679 也用了“使用”。
- **建议**：可改为“享用”。若要与父层同步，应在父层一并修订，本层不单独改。

## 对父层的提示（不在本层改，供父层修订参考）
- **saṃharāpeyya「让人剃除」**：§2309 义注列出的工具有剃刀、镊子、剪刀，可见 saṃharaṇa 包括拔、剪、剃，“剃除”偏窄，建议父层考虑改为“除去”。因为被解释词必须逐字同译，父层若改，本层 §2309、§2310 的黑体和条件句要同步改。
- **jatu「树胶」**：nissaya 作 `ချိပ်`，指紫胶（虫胶），不是植物树胶。如要修订，应从父层 678/679 开始，再同步到本层 §2316–2319。
