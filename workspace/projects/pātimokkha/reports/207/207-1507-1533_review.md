# Review — 207:1507-1533（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 部分缺（§1507、§1511、§1518、§1522、§1526、§1530 及 207-1529-69-85 无 nissaya）／父层对照（本文 §97-110）✅／复注 ❌ 未提供。本层是义注，释义标准本应取复注；以下释义判断依据 nissaya 内转引的 **复注**（ṭīkā）及 nissaya 自身的解说。

## 被解释词与父层逐字核对

逐条核对了 14 处黑体（kosiyamissakaṃ / santhataṃ / kārāpeyya nissaggiyaṃ / suddhakāḷakānaṃ / dve bhāgā / ādātabbā / gocariyānaṃ / orena ce channaṃ vassānaṃ / aññatra bhikkhusammutiyā / purāṇasanthataṃ / samantā / anādā ce / addhānamaggappaṭipannassa / tiyojanaparamaṃ / sahatthā / asante hārake），全部与父层译文逐字相同，**无必改项**。

需要说明的是，父层本身对 santhata 的译法不统一：§97/§99/§101 译“敷具”，§103/§105 译“毡褥”。本层照父层分别跟随，所以 §1509-1517 用“敷具”，§1520-1525 用“毡褥”。这在本层是合规的，但读者会以为是两种东西。**建议上游先统一本文 santhata 的译法**，统一后本层要跟着同步改，包括 207-1517-15-23 的“这三种敷具”。

## 跨段一致性

- **santhata**：§1509-1517 译“敷具”，§1520-1525 译“毡褥”。原因在父层，见上一节。不在本层单独改。
- **nissaggiyaṃ hoti**：§1509（28-37）和 §1516（40-48）译“成为舍堕”，§1520（15-34）译“犯舍堕”，同一短语出现了两种译法。建议统一为“犯舍堕”，与父层的“犯舍堕”一致。
- **kārāpita / kārāpeyya**：§1509 黑体译“让人制作”，同段引语里 kārāpitaṃ 却译成“让人做的”。不是黑体，不算硬伤，但建议引语改为“让人制作的”，前后呼应。
- **vidatthi**：父层 §105 译“一佛搩手”，§1524（13-29）的 vidatthimattaṃ 译“一搩手大小”。原文这里没有 sugata，字面上没错。不过 nissaya 指明这里说的就是学处中的 sugatavidatthi，建议改为“一佛搩手大小”，免得读者以为是另一种尺度。
- **pācittiya 单用**：“四句波逸提”（§1510）、“三句波逸提”（§1529）用的是音译“波逸提”，terms.md 未登记。建议登记 catukka-/tika-pācittiya 的固定译法，全书统一。

## §1510 句 207-1510-2-29
- **问题**：取义偏窄。依据 nissaya 解说：catukkapācittiya 指四种情形，即“自己做了一半的，自己完成或让别人完成；别人做了一半的，自己完成或让别人完成”。现译“按自己开了头而未完成、再把它做完这一类方式”只说了自己开头这一种，读者看不出为什么是“四句”。
- **建议**：改为“按‘做了一半的由自己或别人来完成’这种方式来算，是四句波逸提”，或者把四种情形直接列出。

## §1509 句 207-1509-38-71
- **问题**：漏译成分。依据 nissaya：`သဗ္ဗသန္ထတံ= အလုံးစုံ သန္ထတ စွန့်ပုံအစီအရင်ကို`，即“一切敷具的舍出做法”。现译“此后所有的敷具，都应当依照这段话来了解”，读者会理解成了解敷具本身。
- **建议**：改为“此后所有敷具的舍出做法，都应当依照这段话来了解”。

## §1513 句 207-1513-2-9
- **问题**：词义。依据 nissaya：`အညေဟိ= အခြားအဆင်းတို့နှင့်`，即“与别的颜色”。现译“没有掺进别的羊毛的”，把颜色换成了羊毛。
- **建议**：改为“是指纯粹是黑色的、没有掺进别的颜色的”。

## §1529 句 207-1529-47-68
- **问题**：误译，必改。现译把“往返携带”列为犯戒的要素，但 207-1529-21-46 明说“带去三由旬又带回来……不犯”，两句自相矛盾。nissaya 读作 `အဟရဏပစ္စာဟရဏံ= အသွားဆောင်မှု, အပြန်ဆောင်မှု မဟုတ်ခြင်း`，意思是“不是往返携带”。
- **建议**：改为“不是往返携带”。原文 āharaṇa- 疑为 ahāraṇa- 之讹，见文末 OCR 一节。

## §1528 句 207-1528-52-70
- **问题**：句子结构重复。“带着越过三由旬时，一只脚越过界限犯恶作”里，“越过”出现两次，读起来像是两个动作。
- **建议**：改为“……塞在耳孔里的羊毛，带着让一只脚越过三由旬的界限，犯恶作；第二只脚越过时，犯舍堕”。

## §1520 句 207-1520-2-14
- **问题**：语体。“在六年的这一边”对一般读者很费解，属于翻译腔。
- **建议**：改为“是指在六年以内这一侧，也就是在六年之内”，或者直接写“是指六年之内”。

## 存疑处（不改译文，供定案）
- **Āḷavī**：译“阿拉维”，传统多作“阿罗毗”。terms.md 未登记，建议定案后补登。
- **207-1510-48-51**：原文只说 dhovāpanasikkhāpada，译文补成“令洗旧衣学处”。依义注体例，这里应当就是指 purāṇacīvaradhovāpana，补得合理。但需要核对它与本文那条学处的标题译法逐字一致，那条不在本次父层对照范围内。
- **§1523 / §1526 标题**：义注标题是 Nisīdana-，译“坐具学处释”。本文 §104 标题是“坐具毡褥学处”。按原文字面译不算错，但读者可能对不上，可在 harmonize 时考虑统一。

## OCR / 原文疑问（只记录，不改）
- **207-1510-2-29**：vippakatapaayosāpana 疑为 vippakatapariyosāpana 之讹。nissaya 的引文作 ပရိယောသာပန。
- **207-1529-47-68**：āharaṇapaccāharaṇaṃ 疑为 ahāraṇapaccāharaṇaṃ（a- 否定）。nissaya 作 အဟရဏ，与上一句的不犯条款相合。
- **207-1516-19-39**：nissaya 注明 tulayitvā 一词“大义注中无”，属于异读。
- **207-1509-38-71**：nissaya 依复注，指出应读 sabbasanthataṃ，不应读 sabbatthasanthataṃ。本版原文已作 sabbasanthataṃ，无误，仅记录备查。
