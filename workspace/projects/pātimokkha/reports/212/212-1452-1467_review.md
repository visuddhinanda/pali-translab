# Review — 212:1452-1467（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§1461、§1462 无 nissaya，仅凭 pali 审）／父层（义注 207:1587-1599 定稿译文）✅
> 本层为复注 ṭīkā，释义以父层义注为准。

## 被解释词与父层对照

逐条核对了全部黑体被解释词，与父层定稿译文**均逐字相同**：
僧团的 / 因为它 / 它 / 在某种意义上 / 将会得到的 / 利养 / 衣等物品 / 已经回向 / 我们要供养、我们要做 / 把它转过来归给自己的 / 在动作时 / 僧团、塔、个人 / 别的僧团等 / 认为是未回向的 / 供养物 / 故意说妄语的 / 事先 / 事先就知道、说话时也知道 / 所谓的‘说’ / 不真实的 / 释迦子诃多迦 / 否认之后又承认等事件 / 为了宣称上人法 / 没有考虑就仓促说出的 / 想说这个却说成了那个的 / 以欺骗为目的。

无必改项。

## 跨段一致性

- **aṅga**：父层 §1589、§1598 统一译“支”（“这里有这三支／两支”）；本层 §1464 句 212-1464-82-95 把 aṅgabhūtaṃ 译作“构成条件”，与父层脱节。建议改为“支”，例如“因为这两者是（犯戒的）支”。依据：父层定稿译法。
- **sampajāna**：被解释词定为“故意”，§1464 句 212-1464-2-27 的释句 sampajānassa musāvādo 却译“明知的人所说的妄语”，读者会以为“故意”和“明知”是两个概念。建议改为“明知而说的妄语，就是**故意说妄语**”，让“明知”明确作为“故意”的解释。说明：§1453 的 jānaṃ 是另一个词，译“明知”没问题。
- **pariṇāmeti**：被解释词处译“转过来归给自己”，非黑体处译“转向（自己／别的僧团）”。父层本身也是这样两用，可以接受，不必改。

## §1453 句 212-1453-47-55
- **问题**：误译 — cuṇṇapiṇḍa 译成“一点药粉”。nissaya 作 `စုဏ္ဏပိဏ္ဍမ္ပိ= ရေချိုး မှုန့်တုံး`，意思是洗浴用的粉团，不是药粉。
- **建议**：改为“哪怕只是一团洗浴用的粉”。

## §1453 句 212-1453-68-88
- **问题**：指代不清 — tassa atthaṃ 译成“它的意思”，“它”容易被读成上文的利养。nissaya 作 `တဿ ပဒဿ = ထိုပရိဏတဟူသောပုဒ်၏`，指的是“pariṇata 这个词”。
- **建议**：改为“……并借此说明“已经回向”这个词的意思”。

## §1453 句 212-1453-111-134
- **问题**：取义 — 舍出文句末尾的 nissaggiyaṃ，nissaya 作 `စွန့်အပ်, စွန့်ထိုက်ပါ၏`（应舍、该舍），是“应当舍出”的意思。译成名词“是舍堕物”偏离了舍出文句的口吻。
- **建议**：改为“……把它转向了自己，（这）应当舍出。”

## §1454 句 212-1454-2-19
- **问题**：风格 — “连一条狗算在内”语序别扭。
- **建议**：改为“哪怕是一条狗也算在内，任何众生都算是“个人””。

## §1459 句 212-1459-2-3
- **问题**：格式 — Līnatthappakāsanī 是书名（本复注的别名），没有加书名号。
- **建议**：改为“《律义宝函》（即《显明隐义》）中的”，或写作“《律义宝函·显明隐义》中的”。

## §1464 句 212-1464-82-95
- **问题**：① aṅga 的译法与父层不一致，见“跨段一致性”。② “也就是说完之后知道自己说了妄语”是译者补出的内容。nissaya 补的是 `အနာဂတ်အသိဉာဏ်`（事后之知），补得有依据，但直接写进正文读起来像原文。
- **建议**：保留这层意思，但改用破折号或括注的形式，与原文区分开。

## §1464 句 212-1464-96-108
- **问题**：原文疑问 — nissaya 末尾的按语指出，六结集本现行读法 nanu cetaṃ 不妥，应读作 *na ce taṃ bhaṇanameva*。现在的译文按反问句理解，意思与改读后相近，可以保留。
- **建议**：译文不改，把这条异读登记到 `known-issues.md` 的“OCR／原文问题”一节。

## §1465 句 212-1465-81-90
- **问题**：用词 — “所犯罪类的区别”不够顺。父层统一用“犯”。
- **建议**：改为“为了说明所犯的类别有哪些不同”。

## §1466 句 212-1466-60-128
- **问题**：取义（低优先级）— dārusakaṭa，nissaya 列了三种理解：柴车、用木头套成的车、装着柴的车。译成“木车”意思含糊。
- **建议**：可改为“柴车”。另外 āpattiṃ āpajjatiyeva，nissaya 明确是 `ပါစိတ်အာပတ်`（波逸提），可以考虑补成“就确实犯波逸提”。

## §1466 句 212-1466-129-177
- **问题**：取义 — musāvādova 中的 -va 是强调词，表示“正是”。译成“同样是妄语”，多出了与前文比较的意思。
- **建议**：改为“这就是妄语”。
