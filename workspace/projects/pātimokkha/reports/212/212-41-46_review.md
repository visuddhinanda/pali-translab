# Review — 212:41-46（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（逐句内联）／父层对照 ✅（book 207 §1299–1341，已定稿）
> 本层是复注，没有更高一层的义注可作释义标准，取义以 **nissaya + 父层译文**为准。

## 父层被解释词核对

- 本 chunk 的黑体词（desanākkamo / pahānakkamo / paṭipattikkamo / uppattikkamo / sauddesapaññatti / sapuggalaniddesā / apuggalaniddesā / adassitāpattikā / dassitāpattikā）都是复注自己立的术语，父层 §1299–1341 里**没有对应的黑体**，所以不涉及逐字核对。
- 下面这些非黑体引文与父层对得上，无需改动：
  - “凡是比丘尼出于意愿行淫法”（对应 207-1335-113）
  - “是波罗夷，不得共住”（对应 207-1316-34/43）
  - “未生制”（对应 207-1324-40）
- 有两处与父层用语不一致，见下一节第 1、2 条。

## 跨段一致性

1. **sādhāraṇa**：212-43-114 译作“共通的”，父层 207-1324-33、207-1335-113 译作“共制”。这里说的正是父层所讲的共制，建议改为“凡是比丘与比丘尼共通（共制）的学处”，让读者能接上父层。
   - **nissaya**：sādhāraṇaṃ = ရဟန်း ရဟန်းမတို့နှင့် ဆက်ဆံ၏（与比丘、比丘尼共通）
2. **paññāpanavidhāna**：212-44-2 译作“制定方式”，父层 paññattividhi 译作“制定的方式”。所指相同，建议统一为“制定的方式”。
3. **-paññatti 复合术语的译法模式不统一**：
   - 同一 chunk 里，212-43-142 用“未生制”（沿用父层的“X制”格式）。
   - 212-44-34 的 sauddesapaññatti 却译成“有诵说的制定”。
   - 建议统一按父层体例改为“有诵说制”，下文 sapuggala-/apuggalaniddesā 相应作“指明人制”“不指明人制”，或者至少在首次出现时说明对应关系。属建议项，可交 harmonize 定案。
4. **niddesa 与 dassita 共用“指明”**：212-44-43 起，“指明人”（niddesa）和“已指明犯／未指明犯”（dassita）用的是同一个词，在上下文里不会引起误解。如果要区分术语层次，可考虑把 niddesa 译作“标示”。低优先级。

## §42 句 212-42-2-10
- **问题**：取义偏差。kamabhedo 指次第的种类，即下句列出的四种，不是“次第上的区别”。
  - **nissaya**：သမဘေဒေါ = အစဉ်အပြား（次第的分类）
- **建议**：改为“说明各学处次第的种类”。

## §42 句 212-42-70-76
- **问题**：句法。nissaya 把 pucchanto 读作原因：ပုစ္ဆန္တော = မေးလိုသောကြောင့်（因为想问）。现译“在问犯聚时”只是时间关系，“从同类之处着手”也含糊。
- **建议**：改为“因为想从同类的犯聚开始问，所以问了二十犍度”。

## §42 句 212-42-159-164
- **问题**：背景补出不足。“长老”指的是谁不清楚，而前一句的主语是优波离，读者容易误以为是优波离。
  - **nissaya**：ထေရော = အရှင်မဟာကဿပထေရ်（大迦叶长老）
- **建议**：改为“所以，大迦叶长老只问了两部分别”。

## §42 句 212-42-60-69
- **问题**：语体（轻微）。“此后”偏书面文言。
- **建议**：改为“在这之后”。

## §43 句 212-43-50-71
- **问题**：格与句法。sīlasaṃvarakena 是具格的施事，指守护戒律的比丘，不是工具“戒律防护”。
  - **nissaya**：သီလသံဝရကေန = သီလကို စောင့်စည်းသော ရဟန်းသည်（守护戒的比丘）
  - **nissaya**：ပရိဝဇ္ဇနေန = ရှောင်ကြဉ်ခြင်းဖြင့်（以回避）
- **建议**：改为“……应当由守护戒律的比丘如实地以回避来断除，所以……”。

## §43 句 212-43-142-161
- **问题**：清晰度。“其中没有未生制”里的“其中”指代不明。
  - **nissaya**：တသ္မိံ = ထိုပါရာဇိကသိက္ခာပုဒ်၌（在这条波罗夷学处中）
  - 另外，“所以附随中说……，并不矛盾”容易被读成“附随的说法本身不矛盾”。
- **建议**：改为“所以附随说‘这条学处中没有未生制’（《附随》201-202），这个说法与此并不矛盾”。

## §43 句 212-43-162-195
- **问题**：句法。paṭhamuppannattā 是原因（“因为在波罗夷诵中最先发生”），现译把它降成了修饰语“最先发生的”，因果关系没了。sabbapaṭhamaṃ（在一切之前最先）也只译出了“最先”。
- **建议**：改为“这样，依前面三种次第应当最先讲说的那条学处，因为在波罗夷诵中最先发生，尊者优波离长老想把淫法波罗夷放在一切学处之前最先讲说，就用……”。

## 原文疑问
