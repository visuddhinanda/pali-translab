# Review — 146:1106-1170（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **sacca / saccavācā**：§1107 把 `sacce kate`（nissaya 作 သစ္စာကို ပြုအပ်，并补出 သစ္စကိရိယာ，意思是“作了真实誓”）译成“说出真实语”；§1129 把 `saccavācā`（真实的话）也译成“真实语”。两个不同的词混成了一个译法。建议把 §1107 改为“我立下真实誓言的同时”，“真实语”只给 saccavācā 用。
- **Saccena / Mettāya me samo natthi**（§1109、§1130、§1159）：三处都译“没有人能在……上与我相等”。三处一致，但都有同一个词法问题（见 §1109），改的时候要三处一起改。
- 其余词三处以上都统一：porisāda 都译“食人者”，pavane 都译“大森林”，cariya 都译“所行”，punāparaṃ 都译“又，”，mettā 都译“慈心”。这些不需要改。

## §1107 句 146-1107-2-13
- **问题**：取义偏差。nissaya 是 `ကတေ= ပြုအပ်သည်ရှိသော်` 并补出 `သစ္စကိရိယာယ`，意思是“作了真实誓”，不是“说出一句真话”。
- **建议**：“就在我立下真实誓言的同时，……”。

## §1109 句 146-1109-2-13（§1130、§1159 同）
- **问题**：主语改了。nissaya 是 `မေ= ငါ၏`（属格，“我的”）、`သမော= တူသောဂုဏ်သည်`（“相等的德”，主格）。原意是“没有能与我的真实相等的（德）”，主语是德，不是人。译文“没有人能……与我相等”把主语换成了“人”，比较的对象也从“我的真实”变成了“我”。
- **建议**：“没有什么能和我的真实相比，这是我的真实波罗蜜。”§1159 照此改为“没有什么能和我的慈心相比”。

## §1117 句 146-1117-2-8
- **问题**：取义。nissaya 是 `ယညတ္တေ= ယဇ်ပူဇော်အံ့ဟုစီရင်ရာအရပ်သို့`，意思是“到准备举行祭祀的地方”，是处所，不是“用作祭品”。
- **建议**：“又把我带到要举行祭祀的地方”。

## §1122 句 146-1122-2-11
- **问题 1**：句法有歧义。nissaya 是 `တဿ= ထိုပေါရိသာဒအား`、`မမ အာဂမနံ ပဋိသုဏိတွာန`，意思是“向食人者承诺我会回来”，回的是食人者那里。译文“约定清晨回来，回到美丽的城里”接连用了两个“回”，读者容易以为约定的是回城。
- **问题 2**：异读。nissaya 读作 `ပန္ထေ`（panthe，“在路上”），VRI 原文作 paṇhe（清晨）。译文按 paṇhe 译，可以保留，在这里记下异读。
- **建议**：“我答应他清晨再回到他那里，然后回到美丽的城里，……”。

## §1123 句 146-1123-2-9
- **问题**：隐含成分。nissaya 的 `နိယျာဒယိံ= မယ်တော်ခမည်းတော်တို့အားအပ်နှင်းပြီ` 补出了接受的人是“父母”。“把王国交了出去”容易读成被迫交出。
- **建议**：“把王国托付出去”，或者“把王国交给了父母”。

## §1125 句 146-1125-2-10
- **问题 1**：文言虚词。“善人之法”中的“之”是文言用法，按 style.md 属必改项。
- **问题 2**：取义。nissaya 是 `ဇိနသေဝိတံ= ဘုရားအလောင်းတော်တို့သည်မှီဝဲအပ်သော`，把 jina 解作“菩萨们”，sataṃ dhammaṃ 解作“说到做到的真实话”。“诸胜者”可以保留，取义不同的地方在这里记下。
- **建议**：“我想起善人的法，那是从前的胜者们奉行的”。

## §1128 句 146-1128-2-13
- **问题 1**：句法误读。nissaya 是 `ဃာတယိဿတိဝါ နဝါ ဣတိ သံသယော … နတ္ထိ`，“他杀不杀我”是“疑虑”的内容（由 ဣတိ 引出），整句意思是“我不担心他杀不杀我”。译文用冒号把这两种可能列成“我确信的事”，读起来不通。
- **问题 2**：`tattha` 在 nissaya 里是 `ထိုအခါ၌`（那时），不是“对这件事”。
- **建议**：“那时我毫不担心他会不会杀我；”。

## §1134 句 146-1134-2-13
- **问题**：取义。nissaya 是 `သက္ကေန အဘိနိမ္မိတော= ဥပဒေသနည်းပေးသောအားဖြင့်ဖြစ်စေအပ်သော`，意思是“帝释用指点的办法促成（他）出生”，不是帝释用神通变化出来的。“由帝释化现出生”是误读。
- **建议**：“当我是林中的睒摩，因帝释的指点而出生的时候，”。

## §1135 句 146-1135-2-7
- **问题**：词法（次要）。nissaya 是 `သီဟဗျဂ္ဃေစ= ခြင်္သေ့ ကျားအစရှိသောသားရဲတို့ကိုလည်း`（宾格，“狮子、老虎等猛兽”）、`ဥပနာမယိံ= နှုန့်စေ၏`（使它们温顺）。“施以慈心”没有表达出“使它们驯服”。
- **建议**：“我用慈心使狮子、老虎等猛兽变得温顺”。

## §1138 句 146-1138-2-7（含 §1137）
- **问题**：词义。nissaya 是 `မဟိသေဟိ= တောကျွဲ`，指野水牛。单说“水牛”容易被理解为家养的水牛。
- **建议**：§1137 的“水牛”改为“野水牛”。

## §1145 句 146-1145-2-10
- **问题 1**：标点硬伤。这句已在外层“ ”之内，里面又用了双引号“一王”，按 style.md 内层应该用单引号。
- **问题 2**：“之名”中的“之”是文言用法。
- **建议**：“又，当我是名叫‘一王’、远近闻名的国王时，”。

## §1152 句 146-1152-2-9
- **问题**：动词形态。nissaya 是 `အစ္ဆိန္ဒန္တော= လုယက်လိုသည်ဖြစ်၍`，现在分词，意思是“想要夺取”，不是已经完成的动作。这句的主要动词是 §1155 的 nikhaṇī（埋）。译文把“夺取了我的都城”写成完成的事，和 §1155 的“全都掌握在手中”重复，时间顺序也提前了。
- **建议**：“……这时达巴塞那（Dabbasena）领兵前来，要夺取我的都城。”

## §1154 句 146-1154-2-10
- **问题**：修饰关系误读。nissaya 是 `ရာဇူပဇီဝေ= မင်းကိုမှီ၍အသက်မွေးကုန်သော`，形容词，修饰 `နိဂမေ`（城镇里的大臣、婆罗门、长者等人）；`သဗလဋ္ဌေ သရဋ္ဌကေ` 修饰补出的 `မဟာဇနေ`（连同军队、国土的民众）。译文把“依附国王为生的人”和“城镇”拆成了两项并列，“军队和国土”也成了独立的东西。
- **建议**：“依附国王生活的城镇居民，连同军队和各地的民众，”。

## §1157 句 146-1157-2-10
- **问题**：修饰关系。nissaya 是 `အမစ္စမဏ္ဍလံ= အမတ်အပေါင်းနှင့်တကွဖြစ်ထသော`、`ဖိတံ= ဗိုလ်ပါဆင်မြင်းနှင့်ပြည့်စုံထသော`，这两个都修饰 `ရဇ္ဇံ`（王国）。“繁盛”说的是王国，不是后宫；“大臣们”也不是单独一项。
- **建议**：“连同群臣在内的繁盛王国，以及我的后宫，”。

## §1158 句 146-1158-2-8
- **问题**：语法角色（次要）。nissaya 是 `ဂဟိတံ= ယူသောဒဗ္ဗသေနမင်းကို`，宾格，意思是“那个夺走（这些）的人”，是“我看”的宾语。现在的让步句意思相同，可以保留。

## §1163 句 146-1163-2-12
- **问题**：词义过宽。nissaya 是 `ဆဝဋ္ဌိကံ= လူ၏ဦးခေါင်းခွံကို`，人的头骨，单数。
- **建议**：“用死人的头骨当枕头”。

## §1164 句 146-1164-2-20
- **问题**：用词。nissaya 把 `ရူပံ` 解释为大小便、吐口水等侮辱人的举动，`အနပ္ပကံ= များစွာသော`。“种种不少的丑态”有重复，“丑态”也不准确。
- **建议**：“对我做出许多侮辱的举动”。

## §1167 句 146-1167-2-6（含 §1166）
- **问题 1**：句法。nissaya 是 `ဥပါယနာနိစ= ထိုမှတပါးများစွာသောလက်ဆောင်တို့ကိုလည်းကောင်း`，upāyanāni 是和香、花鬘、食物并列的第三个宾语（“还有其他许多礼物”），不是“当作礼物”。
- **问题 2**：nissaya 把 §1166 的 `အပရေ` 补出为 `အချို့သောသူငယ်တို့`（另一些孩子），译文只写了“另一些人”。
- **建议**：§1166 改为“另一些（孩子）则把香、花鬘、各种丰富的食物”，§1167 改为“和许多礼物送来给我，他们满心欢喜，内心深受触动。”
