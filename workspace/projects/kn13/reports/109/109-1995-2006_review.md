## 跨段一致性
- **mahāsatta / mahāpurisa**：§1995 把 mahāsatta 译作“大士”，§1996、§1998 把 mahāpurisa 也译作“大士”，两个巴利词合成了一个译名，读者无法区分。
  - 建议：mahāsatta 保留“大士”，mahāpurisa 改为传统译名“大人”（如“大人相”），或者在 `terms.md` 中明确登记两者合译。
- **garu / sambhāvanīya**：§2004 把 garu 译作“所尊重”、bhāvanīyo 译作“所敬仰”，而 §2003、§2006 又把 sambhāvanīyo 译作“受人尊重”“受众生尊重”。“尊重”一词同时对应两个巴利词。
  - 建议：sambhāvanīya 统一译作“受人敬重”，garu 保留“尊重”。
- **anāsaṅkanīya / aparisaṅkanīya**：§1999 译作“不被别人怀疑”，§2000 译作“不被猜疑”。两个巴利词近义而不同形，分开译可以接受，但语式不统一。
  - 建议：统一为“不被人怀疑”“不被人猜疑”的同一格式。
- 其余重复句式在各段保持一致，无需修改：
  - piyo manāpo → “所喜爱、所悦意”
  - lakkhaṇavisese → “殊胜的相好”
  - vāsanaṃ samucchindati → “断除……的习气”
  - mahesakkho mahānubhāvo → “大威势、大威力”
  - ādeyyavacano → “说的话为人所接受”
  - paṭipākatika → “恢复如初”
  - paṭipattikkamo → “修行次第”
