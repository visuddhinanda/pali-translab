# Review — 109:1307-1317（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 各句都没有 nissaya，按要求不出句级词法意见；以下只列父层被解释词核对和跨段一致性）

## 被解释词与父层对照

- §1310–1317 的黑体被解释词逐条比对父层 146:815–834 的定稿译文，**全部逐字一致**，没有必改项。
- §1308 句 `109-1308-103-113`（**我看见那个虚伪者**）和 §1309 全部黑体词（**像没有米粒的谷糠堆** / **像树** / **里面** / **空洞** / **像芭蕉树一样没有实心** / **沙门性** / **离开** / **舍弃了惭这一白法** / **为了维持生计** / **被边民** / **苦行严厉** / **结发苦行者** / **不要怠慢** / **随他的心意** / **侍奉**）引自 146:814 之前的偈颂。本次注入的父层对照没有覆盖这些偈颂，**无法核对**。harmonize 时需要补取父层原文比对。

## 跨段一致性

- **aṅka**：父层 146:831 把 *mātuaṅke* 译为「母亲**怀里**」，本层 §1308 两处（`attano aṅke nisīdāpitaṃ`、`mātu aṅkato`）和 §1316 句 `109-1316-68-89`（`attano aṅke`）都译作「**膝上**」。被解释词本身已经对齐，但同一个词在同一段情节里父层说「怀里」、注里说「膝上」，读者会以为是两回事。→ 建议本层 *aṅka* 统一为「怀里」。§1316 句 `109-1316-48-58` 的 *ucchaṅge* 是另一个词，可以保留「膝上」，也可以一并改为「怀里」。
- **sarīra（被砍成块的躯体）**：父层 146:827 作「把**尸体**砍成四块」，本层 §1308 句 `109-1308-35-50`、§1315 句 `109-1315-8-35` 作「把他的**身体**砍成……」。这不是黑体词，属于可选统一，建议跟随父层用「尸体」或同时保留「身体」，二选一后全层一致。
- 其余重复成分前后一致：*kāraṇika*「行刑的人」、*coraghātaka*「刽子手」、*kuhaka*「虚伪者」、*sāmika*「师父」、*rathiyā rathiyaṃ*「一条条街道」、*rājakicca*「王事」。

## §1316 句 109-1316-68-89
- **问题**：被解释词呈现 — 黑体「**我拖走了**」虽然是父层「把正坐在母亲怀里的我拖走了」的连续子串，但单独抽出来读像「我把（别人）拖走了」，主宾颠倒，看不出它注的是 *ākaḍḍhitvā nayanti maṃ*（他们把我拖走）。
- **建议**：保持逐字，改为不连续标示：「**把**……**我拖走了**」，同 §1312 用「**今天**……**你**」的做法。

## §1316 句 109-1316-2-15
- **问题**：被解释词与释义错位（父层问题）— 父层 146:830 把 *tattha* 译为「于是」，本层逐字沿用「**于是**」，这符合硬约束。但这条注把 *tattha* 解释为处所义（「在国王的这道命令下／在侮辱苦行者这件事上」），「于是：就是在……下」读起来答非所问。
- **建议**：本层不动，保持与父层一致。提交 harmonize 时考虑把父层 *tattha* 改为能承接处所义的译法（如「在这件事上」），两层同步修改。
