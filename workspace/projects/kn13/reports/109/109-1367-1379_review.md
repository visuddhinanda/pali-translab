# Review — 109:1367-1379（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 各句均未带 nissaya 数据，所以逐句词法复核略过；下面只列被解释词对父层的核对和跨段一致性）

## 被解释词 × 父层逐字核对

逐条比对了 15 处黑体被解释词：Kāsīnaṃ puravaruttame / Bhaginī ca bhātaro satta… / etesaṃ pubbajo āsin（两处）/ Hirīsukkamupāgato / Bhavaṃ disvāna bhayato… / Pahitā / Ekamānasā / Kāmehi maṃ nimantenti / Kulavaṃsaṃ dhārehi / Yaṃ tesaṃ vacanaṃ vuttan / Gihidhamme sukhāvahan / Taṃ me ahosi kaṭhinan / Te maṃ tadā ukkhipantan / pucchiṃsu / Patthitaṃ mama / Hitesinan / Pitu mātu ca sāvayun / Mātāpitā evamāhu / sabbeva pabbajāma bho。

结论是**全部与父层译文逐字一致，没有必改项**。下面三处虽然逐字一致，但父层的取法和本层的释文对不上。本层不能单独改，需要回到父层（146）在 harmonize 时一起处理：

- **§1373 Hirīsukkamupāgato**：父层译作“具足惭愧与清白之法”，把 hirī 和 sukka 当成并列的两项。本层释文的结构是 `sukkaṃ … hiriṃ bhusaṃ āgato`，sukkaṃ 和 hiriṃ 同为宾格，sukkaṃ 修饰 hiriṃ，意思是“清白的惭”，不是并列关系。本层译文的解释部分也照此译成“称为清白…具足了这样的惭”，结果被解释词和解释自相矛盾。建议父层改为“具足清白的惭”之类，然后两层同步改。
- **§1376 Te maṃ tadā ukkhipantan**：父层“那时我拒绝他们”把主格 te 当成了宾语。从格位看，te 是主格，作 pucchiṃsu 的主语；maṃ ukkhipantaṃ 是宾格，作 pucchiṃsu 的宾语；被拒绝的是 kāme，不是“他们”。本层释文正确地译成“把这些欲乐一再抛开…朋友们就来问我”，和被解释词“我拒绝他们”冲突。建议父层改为“那时我拒绝（欲乐），他们就问我…”，然后同步。
- **§1377 Atthakāmo**：父层把这个词译成“我希望他们得益”。本层释文是 `attano atthakāmo`，即希望自己得益，与父层的“他们”相反。本层为了避开冲突，只截取了“得益”两个字作被解释词，丢掉了 -kāmo（希望）。截取虽然没有违反逐字约束，但对应关系已经不完整。应先修正父层，再把被解释词补全为父层的完整对应片段。
- 另外记录一条：§1369 父层原文作 *sotthiye*（吉祥），义注读作 *sottiye*（博学的婆罗门），所以本层译文出现了“因为专心诵习吠陀咒语，所以被称为吉祥的家族”这种推理不通的句子。这是父层与义注之间的读法分歧，按约束沿用了父层的“吉祥”。是否在本层加注说明，交给 harmonize 定。

## 跨段一致性

- **hirī**：§1373 被解释词作“惭愧”，同一句释文作“惭” → 等父层改定后统一（hirī 单独出现时宜作“惭”）。
- **bhātaro（六人）**：§1378 句 109-1378-115-135 作“六个兄弟”，§1379 句 109-1379-40-58 作“六个弟弟” → 建议统一为“六个弟弟”，因为他们都是大士的弟弟，后一种说法更明确。
- **异读用语**：§1377 `pāḷi` 译“也有经文读作”，§1378 `pāṭho` 译“也有读作”，§1377 `paṭhanti` 译“有些人读作” → 建议 pāḷi / pāṭho 统一为“也有版本读作”。
- **异读引文的大小写**：§1377 “attakāmo”小写，§1378 “Pabbajāma kho”首字母大写 → 统一用小写。
- **mahāsatta / mahāpurisa**：§1371、§1378 的 mahāsatta 和 §1379 的 mahāpurisa 都译成“大士”，两个词在译文里区分不开 → 建议 mahāpurisa 改作“大人”，或在术语表里明确两者合译为“大士”。

## §1378 句 109-1378-25-48

- **问题**：称谓 — 这句话的说话人是大士的朋友们，`ammatātā` 是呼格，用来称呼大士的父母。直译成“妈妈，爸爸”，读者会以为是子女在说话。
- **建议**：改为“伯父、伯母”或“二老”。
