# Review — 109:1063-1085（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本 chunk 各句均未提供 nissaya，逐句词法复核全部略过）

## 被解释词与父层对照

逐条核对的结果如下：

- §1066 **ācikkhi**：本层译为「说了出来」，父层 146:645 也是「说了出来」，一致 ✅
- §1084 **yāvatā karaṇaṃ**：本层译为「事情的全部经过」，父层 146:648 相同，一致 ✅
- §1084 **pakappayī**：本层译为「搭箭对准了他」，父层 146:649 相同，一致 ✅
- §1084 **mittadubbhiṃ**：本层译为「出卖朋友的」，父层 146:650 相同，一致 ✅

§1077–1078 的黑体词（niplavitaṃ / ekacciyo / seyyo / kaṭṭha / migānaṃ / garahasi / pakkhīnaṃ / bhayañhi maṃ vindatinapparūpaṃ / vāhane / mahodake salile / tatonidānaṃ / bhayamāgataṃ）引自本层所引的《本生》偈（§1068–1075），父层里没有这些词。它们与本层偈文译法逐一一致：捞起、有些人、更好、木头、鹿类、责备、鸟类、我感到了不小的恐惧、奔流、大水中、由此而来、恐惧 ✅

## 跨段一致性

- **§1083 引父层偈文的标点与父层不一致**：父层 146:650 是「‘我就在这里杀了这个出卖朋友的卑劣小人。’」，国王的话用了内层单引号。本层 §1083 缺少开头的 ‘，结尾直接写成 ”。
  - 建议改为「‘我就在这里杀了这个出卖朋友的卑劣小人。’”」，与父层逐字逐标点相同，并与 §1082 末尾的冒号衔接。
- **mahāpuriso／mahāsatto 同译「大士」**：§1067 和 §1085 的 mahāsatto 译作「大士」，§1073 的 mahāpuriso 也译作「大士」，两个称谓混为一个。§1067 的 bodhisatto 另译作「菩萨」，这一处没有问题。
  - 建议 §1073 的 mahāpuriso 改译「大人」，与 mahāsatto 区分开；如果全书已有统一约定，就按约定处理。
- **āha 的译法**：§1076 原文只有 Āha，译文写成「说了这首偈」。§1070 和 §1073 的 Gāthamāha 也译作「说了这首偈」。语境上可以接受，但 §1076 补出的「这首偈」原文没有对应词。保持现状也可以，只在此备注。
