## 跨段一致性

- **多词粗体 lemma 的呈现方式不统一（必改）**：
  - `175-415-60-69` 把 `**Na** **upamāya** **vuttattā**` 合并为单一粗体「**因为不是用比喻说的**」；
  - 而 `175-415-2-8`、`175-415-19-37`、`175-415-83-108` 逐词分割，中文无词间空格，产生 `**慢的****与见相似的**`、`**成为比喻****，**`、`**就像是部分一样****，**` 这样 `****` 相连的串。
  - 后果：markdown 渲染时 `****` 会被吞掉或错配，粗体标记失效。
  - 建议：**统一按 60-69 的做法**，把一处 lemma 合并为一个粗体区间；标点（`，`）一律移出粗体。
- **`naya`**：§414 标题译「理趣」（catumagga-**naya**-sahassa），§415 正文译「方式」（yathāvutta-**naya**ena / vutta-**naya**ena）。语境不同尚可，但需确认标题的「理趣」与父层／同书他处标题译法一致（标题译名以父层为准）。
- **`…ti` 释词句式**：§415 混用「**X**，就是…」（38-42）与「**X**，是指…」（54-59 / 60-69 / 70-82）。建议统一为「是指」。
- 一致且正确的：`pavatti`＝生起（2-8 / 9-18 / 19-37）、`upamā`＝比喻（19-37 / 60-69 / 70-82）、`aṭṭhakathā`＝义注、`sutta`＝经、句末释语「——这就是这里的意思／——应当这样理解」体例统一。
- 标点全部为全角，译文内无 ASCII 引号，符合 JSON 写入约束 ✅。

## §415 句 175-415-2-8

- **问题**：语序／可读性 — 「**慢的****与见相似的****生起**」把两个定语叠在「生起」前，现代汉语读不通，且是 lemma（父层原句），首句就别扭会连累后文。原文 `Mānassa diṭṭhisadisā pavatti` 意为「慢的生起与见相似」。
- **问题**：格式 — 三段粗体相连成 `****`，见「跨段一致性」。
- **建议**：改为单一粗体的完整句：「**慢的生起与见相似**。」修订后须与父层复注该句译文逐字比对。

## §415 句 175-415-9-18

- **问题**：术语 — `adhipati` 译「主宰者」。阿毗达摩语境中 `adhipati` 是定型术语（增上、增上缘 adhipatipaccaya），此处虽取其「君主／主宰」的譬喻义，但直接用「主宰者」会与「增上」体系脱钩。
- **建议**：保留譬喻义但补夹注：「慢如同主宰者（adhipati）一样，不会与另一个主宰者即见一同生起」。（`terms.md` 未登记 `adhipati`，建议定案后补入。）
- 其余：`aññādhipatinā diṭṭhiyā` 的同位关系译作「另一个主宰者即见」，处理正确；义理（慢与见不俱起）也对。

## §415 句 175-415-19-37

- **问题**：逻辑／误译（必改） — `itarathā … āpajjeyya` 是**反面推论、导出不欲之过失**（「否则就会推出／就会招致…」），译文作「也**应当会**生起…了」，「应当」在现代汉语里读作「理应如此」，把归谬说成了肯定主张，方向相反。
- **建议**：「否则的话，就会推出：正像太阳落山时黑暗笼罩一样，在最上道隐没的时候也会生起遮蔽诸谛的黑暗——这就是这里的意思。」
- **问题**：格式 — `**成为比喻****，**`，逗号被裹进粗体且与前一粗体相连。
- **建议**：逗号移出粗体，lemma 合并为「**一分**……乃至……**成为比喻**，」。
- **问题（低）**：`aggamagga` 译「最上道」可读性偏低，`tirodhāna` 本义偏「遮蔽、隐蔽」，与下文 `paṭicchādaka`（遮蔽）呼应。
- **建议**：可作「最上道（阿罗汉道）被遮蔽的时候」，若父层已有固定译法则从父层。

## §415 句 175-415-38-42

- **问题**：可读性 — `aññe aññe` 译「彼此相异的各个」，「各个」单用作名词悬空。
- **建议**：「**互相**，是指一个个各不相同的（诸法）。」同时把「就是」统一为「是指」。

## §415 句 175-415-83-108

- **问题**：格式 — `**就像是部分一样****，**`，同前，逗号移出粗体、lemma 合并。
- **问题（低）**：「系属于心」中「系属」偏文言／术语化，与 `style.md` 的现代汉语要求擦边；`niyutta` 此处即「与心相应、依附于心」。
