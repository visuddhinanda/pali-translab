# Review — 175:500（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入）／义注·父层 ⚠️ 仅注入 `172-498-2-2`「Uddesavaṇṇanā = **总说的解释**」一行章节标题，本 chunk 全部黑体被解释词（mahantena vāyāmena / mahābhūtāni / Evaṃ / paṭiccasamuppannatā vuttā hoti / Upādāyati / ekantanissitassa / Bhavati hi nissayarūpānaṃ sāmibhāvo）在父层（172）对应段落**均未注入**，故「被解释词与父层逐字同译」这一硬项**本次无法核查**。下列黑体词的译法建议仅供参考，最终须以父层 ṭīkā 定稿译文为准，定案前不要据本报告改动黑体词。

## 跨段一致性

- **bhūta / mahābhūta**：句 `175-500-10-32` 内 `bhūtāni` 译「元素」，同句 `mahābhūtāni` 译「大种」。本句正是在拆解复合词 `mahā + bhūta`，译名不同源，读者看不出「大种」= 「大的 + 种」。建议统一作「种」：「……是大的、是众多的**种**（bhūta）……因此叫做**大种**」。
- **upādāya 系列**：句 `33-48` 引文内译「依**大种**而转起」，句 `49-54` 译「**依取**」，同一词根两种译法，且前者在引号内擅自补入原文没有的「大种」。建议引文统一作「依取而转起」，补出的说明放到引号外。
- **sāmibhāva**：句 `63-88` 一句之内先译「所有者的**性质**」，后译「所有者的**身份**」。同一术语同句异译，建议统一为「所有者（sāmī）的身份」。
- **nissita / nissaya**：句 `55-62` 作「依止者」，句 `63-88` 作「所依的色法」。二者指涉相反（前者是能依的所造色，后者是被依的大种），词根同为 nis-si，译文虽不算错，但建议明确成「一向依止者（=所造色）」与「所依色（=大种）」，避免读者混淆方向。

## §500 句 175-500-2-9

- **问题**：格式 — `**巨大的****努力**` 连续两组星号相邻（`****`），部分 markdown 解析器会把中间读成空强调，渲染不稳定。原文两个黑体词间有空格，中文没有。
- **建议**：合并为 `**巨大的努力**`。
- **问题**：擅自补足 — `catudhātuvavatthānavasena` 译作「依四界差别的**修习**来说」，「修习」原文无据（`vasena` 只是「就……而言／依……的方式」）。
- **建议**：改「或者只就四界差别（catudhātuvavatthāna）而言」。
- **问题**：行文 — 「这件事情非常重大，所以说是以巨大的努力」中「所以说是以」句读别扭，且丢了 `mahākiccatāya` 与被释词的直接因果绑定。
- **建议**：「……由于（这）是一件大工程，因此（说）**以巨大的努力**」。

## §500 句 175-500-10-32

- **问题**：准确性 — `anekasatasahassakalāpa` 译作「成百上千的色聚」，数量被压低。`aneka-sata-sahassa` 是「无数百千／数十万」，此处正是论证「大 = 多」的量的依据，弱化后论证力度消失。
- **建议**：改「由于在同一相续中一时便有无数百千色聚生起」。
- **问题**：取义 — `mahantāni bahūni bhūtāni` 是在训「mahā」即「多」（故下文以 `mahājano`「大众」为例，那里的「大」正是「多」）。译文作「是大的、是众多的」两个并列形容词，读者读不出这是同位训释。
- **建议**：改「所以这些种是『大』的，也就是**众多**的」，让「大＝多」的等式显形。
- **问题**：取义 — `bhūtāni paramatthato vijjamānāni` 是在训「bhūta」＝「实有」（bhū 义为「存在」）。译文「或者说，从胜义上看它们是真实存在的」把它处理成与前一读并列的另一种解释，但从构词看它训的是复合词的后半，与前半的「大＝多」是同一分析的两截。
- **建议**：保留 `vā` 的选择义，但把训释对象点明：「或者说，（种）是从胜义上真实存在的（bhūta）」。若最终判定 `vā` 承接的是更前面的另一种释义，此处存疑请在定稿前据父层 ṭīkā 复核。

## §500 句 175-500-33-48

- **问题**：引文失真（必改）— `‘‘upādāya pavattan’’ti` 是原样引出的语段，译文作「依**大种**而转起」，在引号内塞入原文没有的「大种」。引文必须逐字，补出的成分不能进引号。
- **建议**：改「在取『依取而转起』这个意思的时候」；若要点明所依取者，写在引号外，如「（即依取大种而转起）」。
- **问题**：行文 — 「由于它显示了由缘而生起，**缘生性**也就**被说到了**」语序倒装、被动生硬。
- **建议**：「因为它显示了由缘而生（这一点），所以**缘生性**也就**说到了**」（若 `vuttā hoti` 是父层黑体词，措辞须服从父层定稿）。

## §500 句 175-500-49-54

- **问题**：擅自补足 — 「确实就是依取（大种）而有的」中括号内「大种」为补出内容。按 `style.md`，圆括号夹注留给巴利原词，补出的成分不宜用同一形式，易被读成原文自带。
- **建议**：改「**依取**：意思是，正是『依取（upādāyati）』（大种）而有」，或径直去掉括号补语，让语境承担。

## §500 句 175-500-55-62

- **问题**：指代不明 — `āha` 译「他才说」，「他」在译文里无先行词，读者不知是谁在说。此处主语是所注释的义注／ṭīkā 作者。
- **建议**：改「正因为如此，（论师）才说**“完全依止者的”**」，或省作「因此才说**“……”**」。
- **问题**：术语 — `ekantanissita` 译「完全依止者」可通，但南传常译作「一向依止（的所造色）」。此词是父层黑体引出，译法须以父层定稿为准，本次无法核对。

## §500 句 175-500-63-88

- **问题**：术语取义 — `ādhārādheyyasambandha` 译「依处与**被依处**」。`ādheya` 是「被安置／被承载者」，不是「处」，译作「被依处」与「依处」字面雷同，反而使能所关系模糊。
- **建议**：改「能持与所持（ādhāra-ādheya）的关系」或「依处与被安置者的关系」。
- **问题**：取义 — `ādhārabhūtopi attho` 译「作为依处的那个**意义**」。此处 `attha` 指所诠之事物／所指对象，不是「意义」。
- **建议**：改「即便是充当依处的那个事物」。
- **问题**：术语一致 — 「所有者的性质」/「所有者的身份」同句异译（见「跨段一致性」）。
- **建议**：统一作「所有者的身份」。
