## 二、跨层问题（需上报，本层无法自行解决）

- **175-36-2-20 `sarīra` 与父层释义冲突（重要）**：本层明确把它解为「宣说期间**世尊的身体**是怎样维持下来的」（desanākāle bhagavato sarīrassa yāpitākāravicāro），而父层 172-37-2-10 把 `Desanāya sarīrassa` 译成「**教说的整体**」。本层译文本身忠实于原文，但读者对照父层会看到「教说的整体」的注文却在讲身体如何维持，对应关系断裂。父层此处疑为误读（`sarīra` 应指佛的色身，即《殊胜义》中三个月连续说法期间以化佛、赴托钵维持身体一节）。**建议回改父层 172-37-2-10**（如「教说时身体的维持，以及领受」），父层改定后本层黑体随之对齐；在父层未改前，本层不要单方面改动。

## 三、跨段一致性

- `naya`＝方式（35、41）、`pakāra`＝方式（39、41）、`ākāra`＝方式（36）三词共用「方式」：与父层用法一致，故不必改，但 175-41-16-39「脱离了阿毗达摩方式的分别“离”的方式」一句内两种「方式」叠出，建议后者改为「分法」以免读者混淆。
- `paccayabhāva`：本层 175-40-2-39 造词「缘性」，父层 172-47 一律作动词式「是…的缘」。术语首现处未夹注巴利原词。→ 见必改项 1。
- `pariyatti`：本层 175-37-20-67 作「圣典之法」；父层同一词在 172-67-102 作「圣典」、在 172-65-59 作「学习」（父层自身即不统一）。本层此处取「圣典」义正确，建议首现夹注「圣典之法（pariyattidhamma）」以固定对应。
- 以下术语与父层完全一致，无漂移：教说 / 教诵方式 / 总说 / 经分别 / 论分别 / 问难 / 圣典文句 / 前缀 / 词根词 / 超过 / 殊胜 / 离 / 缘生法 / 未知当知根。

## 四、必改项

### §40 句 175-40-40-53
- **问题**：被解释词不一致 — 黑体 `paccayabhāvo uddiṭṭho` 引自父层，父层 172-47-118-153 定稿作「**总说了各个缘法是各个缘生法的缘**」，本层译作「总说了缘性」，读者无法看出这条注在注哪一句。
- **建议**：黑体改为与父层同形，如「所以才说**“总说了…是…的缘”**」；再在紧接处以夹注交代本层的名词化用法：「（即此处所说的『缘性』，paccayabhāva）」。相应地把 175-40-2-39 内首现的「所谓“缘性”」改为「所谓的“缘性”（paccayabhāva，父层译作「是…的缘」）」，其余出现处沿用。

### §38 句 175-38-9-15 与 175-38-16-42
- **问题**：误译，且与下文自相矛盾 — `atimālā` 译作「超量的花鬘」，把 `ati` 读成限定「花鬘」的量；而紧接的 175-38-16-42 恰恰说「ati 这个词限定的是并未明白显出的『行进』这一动作，**而不是限定花鬘**」。译文与它自己要论证的语法点相反。`atimālā` 是 atyādi 复合（atikkantā mālaṃ），意为「超出了花鬘的（那个）」。
- **建议**：两处统一改为「超出花鬘」并首现夹注：「就像“超出花鬘（atimālā，即『越过了花鬘』）”等说法里的 ati 这个词等等那样」。改后与下文「限定的是『行进』这一动作，而不是限定花鬘」即可自洽。

### §37 句 175-37-68-81
- **问题**：修饰语错位造成语义反转 — 原文 `visesato abhidhammo viya suttantopi “dhammo”ti vuccati`，`visesato` 修饰的是「阿毗达摩（特指的那个）」，不是「被称为」。现译「所以经藏也像阿毗达摩一样，**特别地被称为**“法”」读成了经藏被特别地称为法，与全段论旨（正因为「法」不专属，才需要用 abhi- 把经藏简别出去）相悖。
- **建议**：「其中，由于“法”这个词并不专指某一样东西，所以就像特指的阿毗达摩一样，经藏也被称为“法”。」

### §36 句 175-36-45-66
- **问题**：省略成分未补，句子悬空 — `yo ca therassa desitākāro, so atisaṃkhittatāya`（后面承前省略 `na vācanāyoggo`）。现译「而长老所宣说的那种方式，则是因为过于简略。」句子没有落点，读者不知道「因为过于简略」怎么了。
- **建议**：「而长老所宣说的那种方式，则因为过于简略，同样不适合教诵。」

## 五、建议项（非必改）

### §35 句 175-35-11-30
- **问题**：「对**方式之海**所作的考察」中 `nayasāgara` 直译后不成词，读者难解；且全句作「…是指用…的方式，连同水海等等一起对方式之海所作的考察」，长定语套长定语。
- **建议**：术语首现夹注并改写语序：「…是指用“为了了知这部阿毗达摩的甚深，应当知道有四种海”等等的说法，把方式之海（nayasāgara）连同水海等等一起加以考察。」

### §35 句 175-35-31-48
- **问题**：「以百分、以千分」（satabhāgena sahassabhāgena）字面直译，现代读者读不出意思。
- **建议**：改为「以百种、以千种的分法」或「用百倍千倍的开合」。

### §36 句 175-36-2-20
- **问题**：「对宣说期间世尊的身体是怎样维持下来的所作的考察」——「对…所作的考察」中间塞入长小句，读来吃力。
- **建议**：「…就是考察在宣说期间世尊的身体是怎样维持下来的，这就是**教说……乃至……领受**。」

### §38 句 175-38-100-112
- **问题**：「这句话才站得住」偏口语，与本 chunk 其余段落的书面语体不齐。
- **建议**：「…这句话才得以成立。」

### §38 句 175-38-121-124
- **问题**：`nipāta` 首现未夹注，「不变词」不是通用译名，读者无从对应。
- **建议**：「因为这类不变词（nipāta）是有多种意义的。」

### §38 句 175-38-125-128
- **问题**：「**因为能显示出那种**，就是因为能显示出超过和殊胜」——黑体译文「那种」宾语悬空（父层此处并入长句，无独立对应形）。
- **建议**：补一个中性名词而不改父层用词：「**因为能显示出那种性质**，就是因为能显示出超过和殊胜的性质。」

### §41 句 175-41-40-59
- **问题**：`anupadadhammasammasana` 译作「逐句思惟诸法」，`anupada` 此处指「一法接一法地（逐一）」，不是「逐句」。
- **建议**：「逐一思惟诸法的论述」。

## 六、存疑与原文问题（记录，不改）

1. **175-39-64-83 复合词切分存疑**：`bhūmantaraparicchedapaṭisambhidā` 现译「地界差别与无碍解」，把 `bhūmantara + pariccheda` 合并为一项。也可切作「地的差别、划分、无碍解」三项。父层与义注均未提供切分依据，建议核对《分别论》相应品目后定案，暂按现译，`confidence` 宜压低。
2. **175-37-11-19 / 20-67 引文拼接**：`sikkhitaṃ sikkhiṃsu` 与 `dve bhikkhū abhidhamme nānāvādā` 分属不同经段（后者见《如何经》一类「两比丘于阿毗达摩持异说」的语境），现译合成一句「有两位比丘对阿毗达摩持不同的说法而学习了所应学的」，容易被读成一件事。原文本身即以 `…pe…` 压缩，若要保守处理可在两段间断开：「……乃至……他们就这样学了；『有两位比丘对阿毗达摩持不同的说法』」。
3. **175-37-82-122 出处疑误**：所引「Yo vo, ānanda, mayā dhammo ca vinayo ca desito paññatto」出自《大般涅槃经》，通行编号为 dī. ni. **2**.216，而原文作 `dī. ni. 1.216`。疑为底本／OCR 讹误，译文照录即可，另行记入 `known-issues.md`。
4. **175-36-45-66 拼写**：`atisaṃkhittatāya` 通行作 `atisaṅkhittatāya`（ṃ/ṅ 异写），不影响释义。
