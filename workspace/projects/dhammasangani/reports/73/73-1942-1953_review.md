# Review — 73:1942-1953（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／现有译文 ✅／义注 ✅／nissaya ❌（**本次没有提供 nissaya，所以没做词级的格与句法核对**）
> 义注对应段：96:2310–2325（盖组注释）。另外，96:2263（前际、后际、此缘性）和 96:2284（欲的八个词）注释的是本书前文里完全相同的词组，一并用来核对被解释词。

## 跨段一致性

- **kāmacchanda / kāmarāga 译名撞车**：§1943、§1944 把 kāmacchanda 译成「欲贪」，kāmarāgo 译成「欲染」。但义注 §2284 里「欲贪」是 **kāmarāgo** 的黑体译名，§2308、§2328、§2332 的 kāmarāga 也都译「欲贪」（例如「欲贪结」）。现在「欲贪」一个词对着两个巴利词，必须拆开。**建议**：kāmarāga 固定译「欲贪」；kāmacchanda 统一译「欲欲」（义注 §2325、§2328 已经这样译，§2325 还夹注了原词），所以盖名改成「欲欲盖」。定下来后登记到 `terms.md`。义注这边要同步改的：§2284 的「欲意欲」和 §2321 的「欲贪盖」。
- **idaṃ vuccati**：全 chunk 都译「这称为…」，但义注 §2311 黑体引用的是「**这就叫作**昏沉睡眠盖」（§2284 也是「**这就叫作**」）→ 全部统一为「这就叫作…」。
- **cetaso**：§1950 译「意的散乱」，§1951 译「心的懊悔」。义注 §2323 是「**心的**追悔」→ cetaso 统一译「心的」；「意的」留给 mano（manovilekho）。
- **manovilekho**：§1951、§1952 都译「意的刮扰」，义注 §2323 的黑体是「**意的刮划**」→ 两处都改成「意的刮划」。
- **akammaññatā**：§1947、§1948 都译「不堪用」，义注 §2310、§2311 的黑体是「**不堪任**」→ 两处都改。
- **apariyogāhanā**：§1952 译「不能深入」，§1953 译「不深入」→ 统一，建议用「不深入」。
- **idappaccayatā paṭiccasamuppannesu dhammesu**：§1952、§1953 都译成「此缘性、缘起诸法」。paṭiccasamuppanna 是「缘生（缘所生）」，不是「缘起」（paṭiccasamuppāda）；义注 §2263 也是「此缘性与**缘生**诸法」，并解释为「诸缘以及缘所生诸法」→ 两处都改成「此缘性与缘生诸法」。
- **pubbante / aparante / pubbantāparante**：§1952、§1953 译「前际、后际、前际与后际」，义注 §2263 的黑体译「关于过去、关于未来、关于过去与未来」，两层对不上。**建议保留本文的「前际、后际、前际与后际」**，改义注那边的黑体：它的释义本身就是「已经过去的那一部分」，黑体再译成「过去」就成了同义反复。这一项交给 harmonize 定。
- **-anā / -itattaṃ 的构词**：同一种构词，译法各不一样。例如 kaṅkhāyanā 译「怀疑」、kukkuccāyanā 译「追悔」、līyanā 译「退缩着」、thiyanā 译「昏沉着」、supanā 译「入睡」、kujjhanā 译「发怒」、dussanā 译「瞋恨」。义注的固定体例是「X 的样态／X 的状态」（行慈的样态、悭吝的样态、恶作的样态、昏沉的样态、入睡的样态）。被义注黑体引到的几个词见下文逐句的必改项；其余的（§1945 的 kujjhanā、dussanā、byāpajjanā，§1952 的 kaṅkhāyanā）建议同样照这个体例统一。
- **byāpatti**：同一段 §1945 里，第一次（cittassa byāpatti）译「心的变坏」，第二次（byāpatti byāpajjanā…）译「恶意」。巴利原文是同一个词，要统一。
- **vicikicchā / kaṅkhā**：§1952 盖名里 vicikicchā 译「疑」，列举里又译「疑惑」，而 kaṅkhā 也译「疑」。一个「疑」对着两个巴利词。义注 §2308、§2325、§2333 都把 vicikicchā 译成「疑」→ vicikicchā 固定为「疑」，kaṅkhā 改用别的词（如「疑虑」），动词 kaṅkhati / vicikicchati 也要相应区分。
- **前缀 pa- / sam-**（建议）：§1945 pakopo 译「激愤」、padoso 译「极瞋」，sampakopo 译「大怒」、sampadoso 译「遍瞋」；§1953 pamoho 译「极痴」、sammoho 译「遍痴」。建议统一成「极～ / 遍～」，例如「怒、极怒、遍怒」。

## §1943 句 73-1943-9-30
- **问题**：格式 — 译文正文里夹了一个校勘注「〔暹罗版作 nīvaraṇāni〕」。这个异读只是语法性别不同，意思没有差别，放在给读者看的正文里属于体例不当。另外 kāmacchandanīvaraṇaṃ 译「欲贪盖」，与义注里的 kāmarāga 撞车（见上）。
- **建议**：删掉方括号里的异读，需要保留的话交给 footnote 步转成脚注；盖名按统一方案改成「欲欲盖」。

## §1944 句 73-1944-2-9
- **问题**：术语 — 「欲贪盖」，与跨段统一方案不一致。
- **建议**：改成「其中，什么是欲欲盖？」

## §1944 句 73-1944-10-24
- **问题**：被解释词不一致（必改）。义注 §2284 逐词黑体注释了这同一串词，本文译法差了五处，其中 kāmacchando 和 kāmarāgo 还是错位的：
  - kāmesu：本文「对各种欲的」，义注 §2328 引全句作「凡是**对诸欲的**欲欲」
  - kāmacchando：本文「欲贪」，义注「**欲意欲**」（§2325、§2328 作「欲欲」）
  - kāmarāgo：本文「欲染」，义注「**欲贪**」
  - kāmasineho：本文「欲恋」，义注「**欲爱恋**」
  - kāmamucchā：本文「欲迷醉」，义注「**欲迷恋**」
  - kāmajjhosānaṃ：本文「欲执著」，义注「**欲耽溺**」
- **建议**：「凡是对诸欲的欲欲、欲贪、欲喜、欲爱、欲爱恋、欲热恼、欲迷恋、欲耽溺——这就叫作欲欲盖。」义注 §2284 的「欲意欲」也要同步改成「欲欲」。

## §1945 句 73-1945-71-106
- **问题**：一致性 — byāpatti 前后两译（「变坏」和「恶意」）；-anā / -itattaṃ 的构词没有按「样态／状态」体例；pa- / sam- 前缀译法不统一；「这称为」要改。
- **建议**：byāpatti 统一成一个译法（如「恶意」，第一处就作「心的恶意」）；kujjhanā、dussanā、byāpajjanā 改成「发怒的样态」「瞋恨的样态」「起恶意的样态」这一类；句末改成「这就叫作瞋恚盖」。

## §1947 句 73-1947-9-27
- **问题**：被解释词不一致（必改）。对照义注 §2310：
  - akammaññatā：本文「不堪用」，义注「**不堪任**」
  - olīyanā：本文「沉没」，义注「**垂坠**」（取蝙蝠倒挂、罐子吊在木桩上的比喻）
  - sallīyanā：本文「萎缩」，义注说它是 olīyanā 加前缀扩展出来的，译名应该和「垂坠」同根
  - līnaṃ：本文「退缩」，义注「**萎缩**」。本文把「萎缩」错放在 sallīyanā 上，两个词错位了
  - līyanā、līyitattaṃ：义注说这两个是「样态、状态」的说明 → 应该是「萎缩的样态」「萎缩的状态」
  - thiyanā：本文「昏沉着」，义注「**昏沉的样态**」
  - 「退缩着」「昏沉着」的「着」尾缀读起来也很生硬
- **建议**：「凡是心的不适、不堪任、垂坠、彻底垂坠、萎缩、萎缩的样态、萎缩的状态、昏沉、昏沉的样态、昏沉的状态——这就叫作昏沉。」其中 sallīyanā 的具体用字交 harmonize 定。

## §1948 句 73-1948-9-26
- **问题**：被解释词不一致（必改）。对照义注 §2311，§2312 的引文也一样：
  - akammaññatā：本文「不堪用」，义注「**不堪任**」
  - onāho：本文「笼罩」，义注「**遮盖**」（像云遮盖天空）
  - pariyonāho：本文「遍笼罩」，义注「**全面遮盖**」
  - antosamorodho：本文「内部闭塞」，义注「**内部围困**」（用的是城被围困的比喻，「闭塞」丢了这个意象）
  - soppaṃ（出现两次）：本文「瞌睡」，义注「**睡意**」
  - supanā：本文「入睡」，义注「**入睡的样态**」
- **建议**：「凡是身的不适、不堪任、遮盖、全面遮盖、内部围困、睡眠、睡意、打盹、睡意、入睡的样态、入睡的状态——这就叫作睡眠。」

## §1948 句 73-1948-27-37
- **问题**：被解释词不一致（必改）。义注 §2311 黑体是「**这就叫作昏沉睡眠盖**」，本文是「这称为昏沉睡眠盖」。
- **建议**：「像这样，这是昏沉，这是睡眠——这就叫作昏沉睡眠盖。」

## §1950 句 73-1950-9-21
- **问题**：一致性 — cetaso vikkhepo 译成「意的散乱」，与 §1951 的 cetaso 译「心的」不一致。
- **建议**：「凡是心的掉举、不平静、心的散乱、心的动荡——这就叫作掉举。」

## §1951 句 73-1951-10-21
- **问题**：被解释词不一致（必改）。义注 §2322 黑体是「**对不许可的，认为是许可的**」，后文 kappiye akappiyasaññitā 等也都照这个句式引用。本文用的是「允许」和「把…当作…」。
- **建议**：「对不许可的，认为是许可的；对许可的，认为是不许可的；对无过失的，认为是有过失的；对有过失的，认为是无过失的。」

## §1951 句 73-1951-22-35
- **问题**：被解释词不一致（必改）。对照义注 §2323：
  - kukkuccāyanā：本文「追悔」，义注「**恶作的样态**」
  - kukkuccāyitattaṃ：本文「追悔的状态」，义注「**恶作的状态**」
  - cetaso vippaṭisāro：本文「心的懊悔」，义注「**心的追悔**」。本文把「追悔」错放在 kukkuccāyanā 上，两个词错位了
  - manovilekho：本文「意的刮扰」，义注「**意的刮划**」（像锥尖刮划铜钵）
- **建议**：「凡是这样的恶作、恶作的样态、恶作的状态、心的追悔、意的刮划——这就叫作恶作。」

## §1951 句 73-1951-36-46
- **问题**：用语统一 — 「这称为」。
- **建议**：改成「这就叫作掉举恶作盖」。

## §1952 句 73-1952-9-43
- **问题**：
  1. 误译（必改）：paṭiccasamuppannesu dhammesu 译成「缘起诸法」，应该是「缘生诸法」。义注 §2263 也是「此缘性与缘生诸法」。
  2. 术语：「前际、后际、前际与后际」与义注 §2263 的黑体对不上，处理见跨段一致性。
  3. 准确性（存疑，建议）：sikkhāya 译成「学处」。「学处」对应的是 sikkhāpada，sikkhā 一般译「学」（三学）。本次没有这一句的义注和 nissaya 可以核对，建议查 nissaya 后定。
  4. 术语：kaṅkhati 和 vicikicchati 的译法要按 vicikicchā 统一译「疑」的方案重新分配。
- **建议**：「…对学怀疑、疑惑……对此缘性与缘生诸法怀疑、疑惑。」动词译法等 kaṅkhā / vicikicchā 定名后再统一。

## §1952 句 73-1952-44-65
- **问题**：一致性 — vicikicchā 译「疑惑」，与盖名「疑盖」不一致；kaṅkhā 译「疑」，与 vicikicchā 撞车；kaṅkhāyanā 没有按「样态」体例；apariyogāhanā 与 §1953 不一致；manovilekho 要改成「意的刮划」（必改，被解释词）；「这称为」要改。
- **建议**：「凡是这样的疑虑、疑虑的样态、疑虑的状态、犹豫、疑、两可、歧路、狐疑、不能确定、彷徨、徘徊、不深入、心的僵滞、意的刮划——这就叫作疑盖。」kaṅkhā 的具体用字交 harmonize 定。

## §1953 句 73-1953-9-66
- **问题**：误译（必改）：「缘起诸法」应该是「缘生诸法」，同 §1952。「前际」等处理同上。pamoho / sammoho 的前缀译法与 §1945 对齐（建议）。「这称为」要改。
- **建议**：「…对此缘性与缘生诸法无知；……——这就叫作无明盖。」

- onāho / pariyonāho / antosamorodho：§2311 黑体译「遮盖、全面遮盖、内部围困」，§2313 的引文却是「覆盖、遍覆盖、内部闭锁」。
