# Review — 96:1790-1797（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层译文（book 73，§866-940）✅／nissaya ❌（本次未提供，词级核对只能靠巴利原文，格位判断没有 nissaya 佐证）
> 本层是义注，对照的父层是本文。

## 被解释词与父层逐字核对（首要）

- 大部分黑体被解释词与父层一致：§375 心一境性（73-877）、邪见条（73-883）、贪条（73-891）、痴条（73-892）都逐字相同。
- **§384 这一组（96-1791）要看父层怎么统一。** 96-1791 的 **不散乱／不动乱／心意不散乱的状态** 与 73-886（§384 邪定）逐字相同，这一处本身不算错。但同一串巴利词，**父层各段译法不一样**：

  | 巴利 | 73-877 / 897 / 899 | 73-879 / 886 / 888 |
  |---|---|---|
  | avaṭṭhiti | 确立（877）／稳住（897、899） | 稳住 |
  | avisāhāro | 不散漫 | **不散乱** |
  | avikkhepo | 不散乱 | **不动乱** |
  | avisāhaṭamānasatā | 心意不散漫的状态（877）／心不散漫的状态（897、899） | 心意不散乱的状态 |

  “不散乱”在父层一会儿对 avisāhāro，一会儿对 avikkhepo。可是 avikkhepo 列在各段的心所清单里（“有不散乱”），译名早已定为“不散乱”。所以 879／886／888 这一组的译法是错的。
  → **必改（交给 harmonize）**：父层统一为 avisāhāro＝不散漫、avikkhepo＝不散乱、avisāhaṭamānasatā＝心意不散漫的状态，avaṭṭhiti 也统一为一个译法。父层改完后，96-1791 这几处要跟着改：
  - 96-1791-2-15 的“不散乱”改为“不散漫”（avisāhāra 的反义），句中 visāhāra 改为“散漫”
  - 96-1791-16-21 的 **不散乱** 改为 **不散漫**
  - 96-1791-22-25 的 **不动乱** 改为 **不散乱**，“不动乱”改为“不散乱”（na vikkhipati）
  - 96-1791-26-31 的 **心意不散乱的状态** 改为 **心意不散漫的状态**，句中“不散乱”也改为“不散漫”
  - 96-1790-2-11 的 **确立** 跟随父层统一后的 avaṭṭhiti 译法；96-1790-16-33 引文里的“确立”同步改
- **邪见条父层也不一致**：73-883 与 73-894 对同一串词的译法不同（见稠林／见的密林、见险野／见的荒野、见违逆／见的刺戳、见摇摆／见的摇摆、见结／见的束缚、歧途／卑劣的道路）。96-1793、96-1794 目前与 73-883 一致。
  → **必改（交给 harmonize）**：父层先统一，96-1793-21-27、37-43、52-61、75-79 和 96-1794-30-39 的被解释词跟着统一。建议取 73-894 的 kummaggo 译法“卑劣的道路”：义注用 kucchito maggo（卑劣的道路）解释 kummaggo，本层 96-1794-30-39 的释义正是“卑劣的道路”。黑体却是“歧途”，读者看不出注释和被解释词的关系。

## 跨段一致性

- **引号层级**：96-1790-16-33、96-1792-2-22 最外层引文用单引号 ‘’，96-1794-43-67 用 “”。按 style.md，外层应一律用 “”，嵌套时才用 ‘’。→ 前两处改为 “”。
- **ākāra 的译法**：96-1796-9-12 lubbhanākāro 译“贪求的**样态**”，96-1796-26-28 sārajjanākāro 译“染着的**方式**”。→ 统一为“样态”，与父层“贪的样态／染着的样态”对应。
- **dassana 与 diṭṭhi 混译**：96-1793-9-16 dassanaṃ 译“见解”，96-1793-44-51 micchādassanaṃ／sammādassanaṃ 却译“邪见／正见”，与 micchādiṭṭhi／sammādiṭṭhi 的译名撞在一起。→ 建议 96-1793-44-51 改为“邪的见解……正确的见解”，或者全都用“见解”。

## §1790 句 96-1790-16-33
- **问题**：标点。最外层引文用了 ‘’。
- **建议**：改为 “深入所缘、进入其中而住立，所以是确立”。

## §1792 句 96-1792-2-22
- **问题**：标点。最外层引文用了 ‘’。另外 ceso（ca + eso）没有译出。
- **建议**：改为 “而这奋起是为了驱除诸欲” 等解释方式……

## §1794 句 96-1794-23-29
- **问题**：误译倾向。parato āmasati 的意思是“把它当成它本来不是的样子去把握”（越过诸法自性，执为常等），不是空间上的“从另一边”。
- **建议**：“因为越过诸法的自性，把它当作常等别的样子来执取，所以是**妄执**。”

## §1794 句 96-1794-30-39
- **问题**：“因为会带来无益”搭配不当。黑体与释义对不上，见上文。
- **建议**：“因为会带来祸害，是卑劣的道路；或者是通往卑劣的恶趣的道路，所以是**卑劣的道路**（以父层统一后的译法为准）。”

## §1794 句 96-1794-71-77
- **问题**：句子不通，语义断裂。原意是愚人以为在这里能渡过，其实只是在原地打转，所以叫“渡处”。现在的译文把 taranti 生硬地放进引号，读者看不懂。
- **建议**：“愚人以为在这里可以渡过，其实只是在原地来回打转，所以叫渡处（tittha）。”

## §1794 句 96-1794-78-83
- **问题**：风格。“无益之事”是半文半白的写法。另外释义说的是“渡处”，黑体却是“外道的依处”，词源关系没交代。
- **建议**：“它既是渡处，又是种种祸害的依处，所以是**外道的依处**。”词源断开是受父层译名所限，这句 confidence 应调低，要不要在父层加注请 harmonize 定。

## §1797 句 96-1797-9-18
- **问题**：语序别扭。“不能面对着与法相合、相会”读不通。
- **建议**：“因为不能面向诸法、与法相合相会，所以是**不现观**。”
