## 理由

**基准缺失说明（影响信心）**：本次评估对象本身就是义注层（book 96 Tikamātikāpadavaṇṇanā），注入数据里**既无 nissaya，也无所解释的本文（三法论母原句）与复注（mūlaṭīkā）**。因此两项核心核对无法执行：一是词级格/句法角色的 nissaya 核对，二是「被解释词与父层逐字同译」的硬约束核对（如 **atītārammaṇā / ajjhattā / bahiddhā / sanidassanasappaṭighā** 是否与本文论母句用词逐字一致，无法验证）。下述判断只能依据巴利原文自身结构、义注内部自释（如 `daṭṭhabbabhāvasaṅkhāta` 对 `nidassana` 的自我定义）与通行汉译传统，故信心压在 70。

**准确性**：整体扎实。引文出处（ma. ni. / dī. ni. / dha. sa. / dha. pa.）全部正确转换为中文书名与编号；`ajjhatta` 四义（gocara / niyaka / ajjhattajjhatta / visaya）分列与末尾「此处取 niyakajjhatta」的收束准确；`upasampajja viharati`→「具足…而住」、`phalasamāpatti`→「果定」、`attano santāne pavattā pāṭipuggalikā dhammā`→「在自己的相续中转起的、属于各自个人的法」均为可靠译法。主要扣分点有二：一是 `96-870-2-29` 把 `gahaṇaṃ`（执取）与 `adhippāyena`（意图）合并成「以…执取为意图」，原文这是并列的两项，合并后句子的逻辑主干被改写；二是 `96-872-11-15` 把 `paṭigha` 译作「阻碍性」，与同句自释「撞击的状态」（`paṭihananabhāva`）不吻合，义注正是要用后者定义前者，译文使定义链断开。`adhikāraṃ katvā`→「当作依据」也偏软，原意是「以自我为主导／使自我成为所关涉的中心」。

**风格**：基本达标，是现代书面汉语，无「此中／彼等／是故／年方／端坐」之类禁例，无工作标记残留，全角标点与弯引号使用规范，`zh` 字段内无 ASCII 引号（JSON 安全）。个别处仍有翻译腔与文言残余：「由那位比丘应当…安住心」是巴利具格施事的硬搬；「自在之处」用了文言虚词「之」，两处重复出现。

**一致性**：主要问题在夹注体例。`style.md` 规定圆括号只用于首次出现的**巴利原词**，但译文里出现了三处**中文补充说明**入括号（「有情所摄的」「非有情所摄的」「内、外、内外」），与 `（ajjhatta）`「（nidassana）」「（paṭigha）」两种用法混在一起，读者无法区分哪些是原词标注、哪些是译者增补。粗体也不统一：`96-870-191-199` 巴利原文无粗体而译文给 **内法** 加粗，同段其余各处则严格随原文。术语形态亦有摇摆：「有见／有对」与「**有见有对法**／**无见有对法**」在同一段内一处带「法」一处不带。

## 问题清单

### 🟧 error

- `96-870-2-29`｜错译（修饰关系）｜片段「以“这样转起的我们就是自我”这样的执取为意图」
  - 问题：原文 `‘…’ti gahaṇaṃ` 与 `iminā viya adhippāyena` 是分列的两项——前者是「执取」本身，后者是「像『我们要去』那样的意图」这一比况状语，共同说明「以自我为主导而转起」。译文把执取当成意图的内容，合并为一物，改变了句子的语法主干。
  - 建议：拆开处理，如「有『这样转起的我们就是自我』这样的执取；就像说『我们要去』时所含的那种意图一样，以自我为主导而转起，所以叫**内法**」。

### 🟨 warning

- `96-872-11-15`｜关键词语意不明确｜片段「与称为“撞击的状态”的阻碍性（paṭigha）在一起」
  - 问题：义注此句正是用 `paṭihananabhāva`（撞击的状态）来定义 `paṭigha`，译文却把 `paṭigha` 另译作「阻碍性」，定义项与被定义项不同词，定义链断裂；且与上一句「可被看见的状态／可见性」的对应处理不一致。
  - 建议：统一为「与称为『撞击的状态』的撞击（paṭigha）在一起，所以叫有对」。

- `96-870-2-29`｜义理或用词与注释书不符｜片段「把自我当作依据而转起」
  - 问题：`attānaṃ adhikāraṃ katvā` 的 `adhikāra` 指「主导、所关涉的中心」，「当作依据」弱化为认识论上的凭据，与「以我为主而起」的原意有偏差。
  - 建议：改为「以自我为主导而转起」或「把自我当作所关涉的中心而转起」。

- `96-870-200-209`｜不该使用术语标记时使用了术语标记｜片段「与根相连的（有情所摄的），还是与根不相连的（非有情所摄的）」
  - 问题：`style.md` 规定圆括号夹注只用于首次出现的巴利原词；此处括号内是中文的另一种译法，形同保留了候选译名，且与同批译文中「（ajjhatta）」「（nidassana）」的用法冲突。
  - 建议：择定一个说法进正文（如「有情所摄的」或「与根相连的」），另一说法若需保留则移入报告或注释，不入正文括号。

- `96-871-2-14`｜不该使用术语标记时使用了术语标记｜片段「以前面那三种法（内、外、内外）为所缘」
  - 问题：同上，括号内为译者增补的中文说明而非巴利原词。此处补充本身正确（`teyeva tippakāre dhamme` 确指内、外、内外三者），但体例不合。
  - 建议：并入正文，如「以前面所说的内、外、内外这三种法为所缘」。

- `96-870-191-199`｜不该使用术语标记时使用了术语标记｜片段「就是**内法**」
  - 问题：该句巴利原文 `ajjhattāti veditabbā` 未加粗，译文却加粗，与同段其余各处「随原文加粗」的做法不一致；粗体在本层承担「被解释词引自父层」的标识功能，随意添加会干扰跨层对齐。
  - 建议：去掉此处加粗，保持与原文粗体一一对应。

- `96-870-43-84`｜不导致误解的汉语语病｜片段「由那位比丘应当就在先前的那个定相上，就在内安住心」
  - 问题：巴利具格施事 + 未来被动分词直搬成「由…应当…」，中文不成句；一句内连用两个「就」，节奏滞涩。
  - 建议：改为「阿难，那位比丘应当把心安住在先前的那个定相上，安住于内」。

- `96-870-177-179`｜文言语体｜片段「自在之处」
  - 问题：用文言虚词「之」构成偏正结构；同一表达在 `96-870-180-185`「诸佛的自在之处」再次出现，属重复出现的语体问题。
  - 建议：统一改为「自在的处所」或「得自在的地方」。

### 🟦 suggestion

- `96-872-2-10`｜复杂的嵌套句整句语言逻辑理解困难｜片段「与称为“可被看见的状态”的可见性（nidassana）在一起，所以叫有见」
  - 问题：「称为X的Y」嵌套后近乎循环定义（可被看见的状态→可见性），读者不易看出这是「以 daṭṭhabbabhāva 释 nidassana」的释词结构。
  - 建议：改为「因为有被称为『可被看见的状态』的『见』（nidassana）相伴随，所以叫有见」。

- `96-869-2-10`｜代词指代可能不够明确｜片段「在紧接着的三法中」
  - 问题：`anantarattika` 指「紧接前一个三法之后的那个三法」，单说「紧接着的三法」缺少参照点，读者不知紧接何者。
  - 建议：改为「在紧接其后的那个三法中」或「在下一个三法中」，并与 `96-871` 的「紧接着的这个三法」统一措辞。

- `96-872-41-45`｜语言表达不够流畅｜片段「以上就是对三法论母各句逐一作的解释」

  - 建议：改为「以上先是对三法论母逐句所作的解释」。

- `96-872-16-22`｜语言风格不统一｜片段「所以叫**有见有对法**」
  - 问题：同段内「有见」「有对」不带「法」，合称时却作「有见有对法」「无见有对法」，术语形态摇摆。
  - 建议：择一形态贯穿全段（建议合称也不带「法」，或单称也补「法」）。
