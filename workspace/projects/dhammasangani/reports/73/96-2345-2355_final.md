## 问题清单

### 🟧 error

- `96-2352-16-21`｜导致误解的表达｜片段「全部的名，也就是四蕴和涅槃，都是名」
  - 问题：原文 `‘Nāmanaṭṭhena’ sabbampi nāmaṃ`，`sabbampi` 是"一切（即上文的四蕴与涅槃）"，作主语；译文把它读成"全部的名"，于是整句成了"名……都是名"的同义反复，读者无法理解这一义与前两义的分工。补出的"也就是四蕴和涅槃"本身方向对（下两句正是分说四蕴与涅槃），但挂在错误的主语上反而加重了循环。
  - 建议：主语回到中性指称，例如"依'使倾向的意义'，四蕴与涅槃也都称为名"；若要保留补注体例，把"四蕴和涅槃"放进括注而非同位语。

### 🟨 warning

- `96-2351-2-14`｜关键词语意不明确｜片段「依作名的意义、依倾向的意义、依使倾向的意义」
  - 问题：`nāmakaraṇa` / `namana` / `nāmana` 三义是本段（2351–2352）的全部骨架，但"倾向"与"使倾向"在汉语里仅差一字，且"使倾向"不是现成词，读者很难把它与下文"四蕴互相使对方倾向""涅槃使无过失的法倾向于自己"挂起来。三个词均未夹注巴利原词，违背 style.md"法相术语首次出现夹注巴利原词"。
  - 建议：首次出现处夹注，如"依作名的意义（nāmakaraṇaṭṭha）、依倾向的意义（namanaṭṭha）、依使倾向的意义（nāmanaṭṭha）"，后文只用汉译。

- `96-2347-2-10`｜关键词语意不明确｜片段「上千个名字里都能举得出来」
  - 问题：`Guṇena nāmamuddheyyaṃ, api nāmasahassato` 的意思是"（他的）名可依功德而举称，乃至可举出上千个名"；译文"上千个名字里都能举得出来"把"举出千名"说成"在千名之中能举得出来"，方向反了，且作为偈颂下半句读来含糊，与上半句"有无数的名字"的递进关系没有立住。
  - 建议：改为"依功德为他举名，乃至可举出上千个名号"之类，让"无数名—依德可举千名"的递进显出来。

- `96-2354-26-35`｜关键词语意不明确｜片段「第二种见（无有见）」
  - 问题：原文 `Dutiyā` 只是"第二种（见）"，"无有见"是译文补入。此补注很可能正确（本文此处正是 bhavadiṭṭhi–vibhavadiṭṭhi 二法），但一句之内连出"第二种见—无有见—断见"三个名目而无任何交代，读者分不清三者是同指还是递进；且圆括号在本项目体例中用于夹注巴利原词，这里改作汉语补注，体例不统一。
  - 建议：**先与本文（Dhammasaṅgaṇī）该 duka 的译名核对**。确系本文名目就写成"第二种是'无有见'（vibhavadiṭṭhi）：以'将不会存在'这种方式确立的断见"，并与本文用字逐字一致；无据则删去括注。

- `96-2348-2-28`｜整句逻辑表达不规范｜片段「亲属们先恭敬供养应供者，然后站在旁边斟酌再三」
  - 问题：`samīpe ṭhitā ñātakā` 是"站在近旁的亲属们"，作主语的定语；译文把它改写成继"供养"之后的第二个连续动作，凭空造出一条时间线。原文的动作序列只有"供养—斟酌—命名"三步。
  - 建议：还原定语，如"站在近旁的亲属们先恭敬供养应供者，再三斟酌之后给他起名说……"。

- `96-2348-29-48`｜关键词语意不明确｜片段「在前一劫中」
  - 问题：`purimakappe` 指"过去的劫"（泛指先前诸劫），译文"前一劫"收窄为紧邻的上一劫。本句要论证的是名称跨劫恒常沿用，收窄后论证力度受损。
  - 建议：改为"在过去的劫中"。

### 🟦 suggestion

- `96-2349-39-46`｜语言风格不统一｜片段「一法遍及一切法，一切法都归入一法」
  - 问题：原文是 `nipatati` / `nipatanti` 的严整对句，同一动词；译文一句"遍及"、一句"归入"，对称结构被打散。同一动词在 2348-29-48 作"沿用为"、2351-161-163 作"归入"，全段三种译法。
  - 建议：在本对句内统一用同一个动词（如都用"归入"），跨段也尽量收敛到一两种译法，让义注的这条论证线索在中译里连得上。

- `96-2349-49-57`｜语言风格不统一｜片段「因为名字施设这一法」
  - 问题：`nāmapaññatti` 译作"名字施设"，与 2351 的 `opapātikapaññatti`→"自生施设"构词不齐（一个用"名字"，一个用双音节法相词）。另原文"这名施设是一法；它遍及一切四地法"两个分句被合并，"是一法"的断定被弱化。
  - 建议：统一作"名施设"；可拆回两句"名施设是一法，它遍及四地的一切法"。

- `96-2349-30-38`｜不常用术语编写注释或者百科｜片段「增语所及的范围之内」
  - 问题：`adhivacana`（增语）是本 duka 的核心术语，首次出现未夹注巴利原词，混合受众中的一般读者难以理解"增语"何指。
  - 建议：首次出现处作"增语（adhivacana）"。

- `96-2350-7-27`｜不常用术语编写注释或者百科｜片段「“佉陀罗树”、“波罗奢树”」
  - 问题：`khadira` / `palāsa` 用了音译但未附巴利原词或简注，与 style.md"罕见术语用巴利音译，首次出现附简注"不符；两个树名对读者是纯粹的空符号。
  - 建议：作"佉陀罗树（khadira）""波罗奢树（palāsa）"，或加一句极简脚注说明是常见树种。

- `96-2352-29-34`｜语言表达不够流畅｜片段「以所缘增上缘的身份」
  - 问题：`ārammaṇādhipatipaccayatāya` 是"由于（作为）所缘增上缘性"，"身份"一词带拟人色彩，用于缘起法相略显随意。
  - 建议：改为"涅槃则由于是所缘增上缘，使无过失的法倾向于自己"。

- `96-2350-2-6`｜语言表达不够流畅｜片段「也是由当地乡民来负责称呼的」
  - 问题：`jānapadānaṃ bhāro` 字面是"是地方人的担当"，译文补出"称呼"这一宾语。补得合上下文（下句正说他们如何报树名），但"负责称呼"读来像行政分工，与义注语气不合。
  - 建议：改为"也归当地乡民去说它的名字"或"叫什么也得问当地乡民"。

- `96-2355-2-13`｜语言表达不够流畅｜片段「以前际为所缘」
  - 问题：被释词 `Pubbantaṃ ārabbha` 的汉译直接采用了释文的说法，于是"'以前际为所缘'是指以过去的部分作为所缘"变成了近乎同义的复述，义注"举词—释义"的体例在中译里看不出来。
  - 建议：被释词按本文用语译（如"依于前际""缘于前际"），释文保留"以过去的部分作为所缘"。**此处同样须与本文译文核对后定字**。

- `96-2349-18-25`｜语言表达不够流畅｜片段「所以称为文句」
  - 问题：`tasmā evaṃ vuttaṃ` 是"所以这样说"，译文具体化为"所以称为文句"。意思不错，但把义注泛指的"这样说"落实成了一个具体判断，属轻度增译。
  - 建议：可保留现译（更易读），若追求贴合则作"所以才这样说"。
