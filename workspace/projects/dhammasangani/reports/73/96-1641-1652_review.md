# Review — 96:1641-1652（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层本文（73:758-826 定稿译文）✅／nissaya ❌（未提供，词级核对只依巴利原文）／本层就是义注，无更上层的释义标准
> ⚠ 缺 nissaya：格与句法没有外部基准，下面的词法判断都来自原文本身，可信度低一档。

## 被解释词对照父层（首要项）

逐一核对了所有黑体词，**全部与父层 §759 译文逐字相同**，没有必改项：

| 黑体（义注） | 父层 §759 译法 | 结果 |
|---|---|---|
| katame dhammā kusalā | 哪些法是善的 | ✅ |
| lokuttaraṃ | 出世间（禅） | ✅ |
| jhānaṃ bhāveti | 修习……禅 | ✅（父层中间隔着修饰语，词素一致） |
| niyyānikaṃ | 能导向出离 | ✅ |
| apacayagāmi（非黑体，句末定名） | 导向消减 | ✅ |
| diṭṭhigatānaṃ pahānāya／diṭṭhigatānaṃ／pahānāya | 为了断除各种见趣 | ✅ |
| paṭhamāya／bhūmiyā／paṭhamāya bhūmiyā／pattiyā | 为了证得初地 | ✅ |
| viviccā | 远离（了各种欲） | ✅ |
| dukkhapaṭipadaṃ dandhābhiññaṃ | 行道艰难、证知迟缓 | ✅ |
| phasso hoti | 有触 | ✅ |
| maggaṅgaṃ | 道支 | ✅ |
| anaññātaññassāmītindriyaṃ | 未知当知根 | ✅ |

**父层自身不一致，要提交 harmonize 处理（不是本层的错）：** 义注对齐的是 §759，这样做是对的，因为它注的就是 §759。但父层 §822-826 把同一批词换了译法，义注就对不上后面这几段了：

- dukkhapaṭipadaṃ dandhābhiññaṃ 等四种行道：§759 译“行道艰难、证知迟缓”，§822-825 译“苦行道速通达／乐行道迟通达／乐行道速通达”。本层 §1650“后面三种行道”指的正是这几种，**建议把父层 §822-825 统一回 §759 的句式**（例如“行道艰难、证知迅速”“行道容易、证知迟缓”“行道容易、证知迅速”）。
- Suddhikapaṭipadā：§758 译“单纯行道”，§826 译“纯粹行道”。本层 §1644 的 suddhikanaya 译作“单纯的讲法”，跟 §758 一致，**建议父层 §826 改成“单纯行道”**。
- 另外，父层 §822-825 的“导向出离／趋向减损／诸见／第一地”与 §759 的“能导向出离／导向消减／各种见趣／初地”也不一致，同样应以 §759 为准统一。

## 跨段一致性
- dukkhā paṭipadā／dandhābhiññā：§1644-1650 都译作“行道艰难、证知迟缓”，前后一致。
- vipassanāparivāsaṃ vasanto：§1645-1650 都译作“在修观的阶段中停留”，一致。
- dukkhena kasirena kilamanto：§1646-1650 都译作“艰难、吃力、疲惫地”，一致（§1645 对应的巴利词不同，另作译法是对的）。
- samuccheda：§1643 两处都译作“正断”，一致。
- paṭhama：黑体译“初”，释义句里译“第一”（§1643-73-78、§1643-158-170）。原文是在解释计数义，用“第一”可以接受，不强求统一。
- 文言扫描：没有发现文言虚词或文言句式。

## §1643 句 96-1643-79-106
- **问题**：误译 — anantarahitāya bhūmiyā（《波罗夷》27）指“直接在地面上、中间没有铺垫的地”，也就是光地。“无间隔的地面”会让读者理解成“连成一片的地”。
- **建议**：改为“在没有铺垫的地面上”（或“在光地上”）。

## §1643 句 96-1643-107-122
- **问题**：语序和术语 — “在乐地的欲界”把修饰关系弄反了：这里的 bhūmi 就是 cittuppāda，也就是“欲界的乐地”。另外“指的是心生起”读起来像动词短语，不像名词。
- **建议**：改为“在‘欲界的乐地中’（《法集论》988）等处，地指的是心的生起（cittuppāda）”。

## §1643 句 96-1643-32-37
- **问题**：提前释义 — 原文 diṭṭhiyā gataṃ etesaṃ 只说“它们有见的行进”，“相似”这层意思是下一句（§1643-38-41）才解释出来的。现在的译文先说了一遍，下一句就成了重复。
- **建议**：改为“或者，因为它们有见那样的行进，所以也称为见趣。”，把“相似”留给下一句。

## §1643 句 96-1643-154-157
- **问题**：句法 — tassā paṭhamāya bhūmiyā 是属格，接的是下一句的 pattiyā（“为了证得这个初地”），并不是一个判断句。“这就是那个初地”显得突兀。
- **建议**：改为“（为了证得的）就是这个**初地**。”，或者直接写“这个**初地**。”

## §1644 句 96-1644-2-25
- **问题**：语病 — “离不开行道才能成就”把“离不开”和“才能”叠在一起，语义重复。
- **建议**：改为“虽然世间禅也不是没有行道就能成就的”。

## §1645 句 96-1645-30-37
- **问题**：易误解 — “任何一种情形都被称为……”读起来像是说所有情形一律叫这个名字。原文的意思是：按上面的定义，凡是符合这个条件的情形，都可以叫这个名字。接着才问哪一种是古师们认可的。
- **建议**：改为“这样说来，凡是符合这种条件的情形，都可以称为行道艰难、证知迟缓。”

## §1647 句 96-1647-2-30
- **问题**：主语错位 — tassāpi dukkhā paṭipadā dandhābhiññā nāma hoti 的意思是这个人的行道和证知被这样称呼，不是这个人本身被称为什么。§1648-1650 用的是“这样也称为”，没有这个问题。
- **建议**：改为“他的行道也称为艰难，证知也称为迟缓”，或者与后几段统一，写成“这样也称为行道艰难、证知迟缓”。

## §1649 句 96-1649-2-29
- **问题**：所指不明（轻微）— lakkhaṇāni 在这里指无常、苦、无我三相，只写“诸相”，一般读者看不出指什么。
- **建议**：改为“三相”，或首次出现时写作“诸相（lakkhaṇa，指无常、苦、无我）”。

## §1642 句 96-1642-13-31
- **问题**：跨层用词（轻微）— sacchikaronto 译作“证悟”，父层 §778 的 asacchikata 译作“亲证”。
- **建议**：改为“在亲证灭的同时出离”，和父层保持一致。
