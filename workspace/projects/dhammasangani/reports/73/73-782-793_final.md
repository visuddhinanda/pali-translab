## 理由
- **资源**：这次评估只有巴利原文和译文，没有义注（Aṭṭhasālinī）和 nissaya。准确性只能逐词对照巴利原文来核对。setughāto 等词的释义依据的是通行的 Aṭṭhasālinī 解释，没有拿原文逐字比对。所以信心指数压在 70。
- **准确性**：12 段 24 句都逐词核对过同义词串，没有漏译，也没有多译。
  - 783、784、785、786、787、788、789、790、791 各段的项数与巴利原文一一对应。791 慧力一段巴利 33 项，译文也是 33 项。
  - 主谓结构、疑问句式和“ayaṃ/idaṃ … hoti”的收束都判断正确。
  - 792、793 两段把惭、愧解释成“羞耻”“畏惧”，符合注释书“lajjā / bhaya”的说法。
  - 主要的准确性问题：783 把 setughāto 译成“断除系缚”。setu 在注释书里讲作“足处、因缘”（padaghātana / paccayaghātana），不是“系缚”。782 同一个词译成“断除它们的根源”，这个译法是对的。
- **风格**：通篇是现代书面汉语，没有文言虚词或文言句式。“道所摄”是通行的法相译语，不算文言。标点都是全角，译文里也没有残留的工作标记。
- **一致性**：这是扣分最多的一项。
  - 782 和 783 用的是同一个定义公式（ārati … setughāto … maggapariyāpannaṃ），但同一批巴利词两段译得不一样。其中“不作”在 782 对应 akaraṇaṃ，在 783 却对应 akiriyā，读者会看混。
  - 782 用的是“在那个时候”，还把后面几项并列成“正业、道支、道所摄”。其余 11 段都用“那时”和“，是道支，归属于道”，782 是唯一不统一的一段。
  - 783 标题句单独给“正命”加了巴利原词夹注，同类术语都没有加。
  - 784 与 788、785 与 789、786 与 790 这三组段落里同一个同义词串的译文完全一致，这一点做得好。

## 问题清单

### 🟧 error
- `73-783-11-33`｜义理或用词与注释书不符｜片段「断除系缚」
  - 问题：setughāto 里的 setu 在注释书中讲作邪命等恶行的“足处、因缘”，setughāta 就是断除它们的因缘、根源。译成“系缚”，意思偏离了注释书。同一个词在 782 译成“断除它们的根源”，两段对不上。
  - 建议：与 782 统一，改为“断除它们的根源”，或者“断除其因缘”。

### 🟨 warning
- `73-783-11-33`｜整句逻辑表达不规范｜片段「远离、离开、回离、戒绝、不作、不为、不犯、不越界限」
  - 问题：这组词和 `73-782-12-35` 里的「远离、离开、退离、戒除、不做、不作、不违犯、不逾越界限」对应同一串巴利词（paṭivirati / veramaṇī / akiriyā / akaraṇaṃ / anajjhāpatti / velāanatikkamo），两段译法却各不相同。“不作”在 782 对应 akaraṇaṃ，在 783 对应 akiriyā，同一个汉语词对应了两个不同的巴利词，容易让人误会。“回离”也不是常见的说法。
  - 建议：以 782 为准统一成“退离、戒除、不做、不作、不违犯、不逾越界限”。
