# Review — 96:2261-2265（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未提供，格与句法没有经过 nissaya 逐词核对）／父层对照 ✅（本文 73:1829-1862 定稿译文）
> 本层是义注，所以用父层对照代替“义注释义标准”，第一项查被解释词是否与父层一致。
> 被解释词对应的父层段：§1062 对 73-1833，§1063 对 73-1834，§1065 对 73-1837（都是父层中**第一次**出现的那一段）。

## 被解释词逐字核对

一共查了 38 个黑体被解释词。它们与父层对应处**全部逐字相同**，没有必改项。

- 核对范围：metti … anukampā（对 1833），dukkhe ñāṇaṃ … idappaccayatāpaṭiccasamuppannesu dhammesu ñāṇaṃ（对 1834），rāgo … jālinī（对 1837）。
- 父层 1834 的“此缘性（idappaccayatā）”带夹注，本层黑体省去了夹注，这个处理可以接受。

⚠ 提醒 harmonize：父层同一定义的第二次出现（73-1847/1848/1849）用的是另一套译法，与第一次出现不一致：

| 巴利词 | 73-1833 / 1834 | 73-1847 / 1848 / 1849 |
|---|---|---|
| adussanā | 不瞋恨的样态 | 不瞋恚 |
| abyāpādo | 无瞋恚 | 无恶意 |
| pubbante / aparante | 过去 / 未来 | 前际 / 后际 |
| paṭipadā | 通往苦灭的道路 | 趣向苦灭的行道 |
| paññāpāsādo | 慧楼 | 慧殿 |
| 结句 | 这就叫作 | 这称为 |

- 本层黑体跟的是第一次出现，这是对的。
- 如果统稿时父层改用第二套译法，本层 §2262、§2263 的黑体也要跟着一起改。

## 跨段一致性

- **引经格式**：“hi vuttaṃ”的译法不统一。§2265-30 译成“因为……这句话，正是……说的”，§2265-65 和 §2265-90 都译成“因为经中说”。
  - 巴利原文只有 vuttaṃ（“曾说”），“经中”是译者补的。
  - §2265-90 注了出处（《相应部》），补“经中”没问题。
  - §2265-65 的引文（ejā …）原文没有注出处，不宜断定是“经中”。建议改成“因为有这样的说法：”。
- **黑体加引号**：§2263-12 写成 “**关于苦集**”等句，加了引号；其余黑体被解释词都不加引号。建议去掉引号，统一为 **关于苦集**等句。
- **句式**：-vasena / -aṭṭhena 一律译“就……而言，叫作 X”；-ti 词源句一律译“（凭借它）……，所以叫 X”。全 chunk 都一致，没有问题。
- **术语区分**：ārammaṇa 译“所缘”，visaya 译“境界”，bhava 译“有”，rañjana 译“染色”。各段都一致，没有问题。
- **文言检查**：逐句扫过虚词和句式，没有发现文言或半文半白写法。

## §2261 句 96-2261-2-2
- **问题**：译名。“二法概说论”里的“论”容易让人误以为这是一部独立的论书。这里的 kathā 是义注对“二法概说”这一部分的解说。
- **建议**：改成“二法概说的解说”。

## §2262 句 96-2262-30-33
- **问题**：语体、指涉。“已护念者的状态”里的“者”偏文言，而且指成了“人”。前面 mettāyitattaṃ 一句（§2262-13）说的是“心的状态”，这一句结构相同，指涉应该一致。
- **建议**：改成“处于护念中的心的状态，就是**护念的状态**。”

## §2262 句 96-2262-34-37 ／ 96-2262-38-40
- **问题**：用词。
  - 释义词 anukampana 与被解释词 anukampā 同根，译文却一个用“怜悯”、一个用“怜恤”，词源上的对应关系看不出来了。
  - 两句都补了“他人”，原文没有。
- **建议**：
  - §2262-38 改成“就怜恤而言，叫作**怜恤**。”
  - “他人”可以删掉。如果保留，两句要保持一致。

## §2263 句 96-2263-17-23
- **问题**：术语。sammasana 译作“遍观”，不是通行译法。南传传统一般译“思惟”（sammasanañāṇa 即思惟智），也有译“触知”的。
- **建议**：改成“听闻、思惟、通达、省察”。§2263-27 的同一组词随之统一。

## §2264 句 96-2264-2-13
- **问题**：漏译。Lobhaniddese**pi** 的 pi（“也”）没有译出来。这个词表示“贪的解说中也照这个办法处理”，承接前文。
- **建议**：改成“1065. 在贪的解说中也一样，前面没有出现过的词语，意思如下：……”

## §2264 句 96-2264-22-27
- **问题**：用词冲突。“意思是贪求”的“贪求”在父层 73-1833 已经用来译 lubbhanā（“不贪求的样态”）。这里拿它译 kāmeti，同一个汉语词对应了两个巴利词。
- **建议**：改成“意思是爱欲”或“意思是渴望”。

## §2265 句 96-2265-13-17
- **问题**：增译。“就像……那样地”是译者加的比喻框架，原文是直接描述：gilitvā pariniṭṭhapetvā gahaṇa（吞下、吞尽，这样地执取）。“那样地”读起来也有些拗口。
- **建议**：改成“就像吞下并彻底吞尽一样地执取而言，叫作**耽溺**。”也可以去掉“就像”，直接说“就吞下并彻底吞尽地执取而言”。

## §2265 句 96-2265-65-80
- **问题**：句法歧义。引文中的 Ejā 是主语名词，这句引文正是用来证明 ejā 的意思是“牵引”。译文“牵引拖拽着这个人”容易被读成动词连用（“牵引、拖拽”），名词主语就看不出来了。另外，“经中说”的问题见上面跨段一致性一节。
- **建议**：改成“因为有这样的说法：“牵引（ejā）拖拽着这个人，让他在这一有、那一有中投生。””

## §2265 句 96-2265-139-146
- **问题**：复合词结构（存疑，没有 nissaya 可以核对）。taṇhāvipphanditanivesa 译成“爱的颤动与安住”，是把它当作并列复合词来理解。从意思看，更可能是依主复合词：“爱的挣动所形成的盘结”。nivesa 在这里是“盘踞、缠结”的意思，不是“安住”；“安住”在汉语里还带正面色彩，放在这里意思不对。
- **建议**：改成“或者说有一张称为‘爱的挣动所形成的盘结’的网，所以叫**具网者**。”这一句请人工或对照 nissaya 再确认一次。

## §2265 句 96-2265-26-29 ／ 96-2265-30-41（仅备注，不必改）
- gedha 的第二义是“浓密”，但被解释词固定译“贪婪”，所以“就浓密而言，也叫贪婪”读起来会断裂。
- §2265-30 已经用“茂密（gedha）”夹注补上了这个联系，处理得当。
- 如果还想让读者更明白，可以在 §2265-26 句末也夹注 gedha，或者在这里加一个脚注。
