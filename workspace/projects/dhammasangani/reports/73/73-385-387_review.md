## §385 句 73-385-2-7
- **问题**：增译 — 原文 `( Kha ) anuppāde ñāṇanti .` 没有任何连接词（无 `ca`、无 `api`），末尾 `ti` 只是引语/列举收束标记；译文开头的「以及」是凭空补出的连接词，违反 `style.md`「不擅自补足」。
- **建议**：删去「以及」，作「（乙）……」。

- **问题**：术语 — 「不生智」有两处隐患。①`anuppāde` 是处格，指「关于不生（这件事）的智」；「不生智」在现代汉语里极易被读成「智不生起」，主谓关系译反。②这是论母固定术语 `anuppāde ñāṇaṃ`（与前项 `khaye ñāṇaṃ` 成对），传统汉译作「**无生智**」（对应「尽智」），`style.md` 规定未登记术语优先沿用传统汉译。
- **建议**：改为「（乙）无生智（anuppāde ñāṇaṃ）。」；若保留直译路线，至少改为「关于不生的智」以消除主谓歧义。**须先核对 §384（不在本 chunk）`khaye ñāṇaṃ` 的译法**，两项必须成对（尽智／无生智），定案后补进 `knowledge/terms.md`。

- **问题**：体例（低优先）— `( Ka ) / ( Kha )` 是巴/缅字母序号，译文域化为「（甲）（乙）」本身可接受，但项目无成文规则。
- **建议**：沿用「（甲）（乙）」并与 §384 保持一致，在 `knowledge/translation-rules.md` 登记此约定。

## §386 句 73-386-2-10
- **问题**：夹注符号冲突 — 原文 `[ suttantamātikā ( syā .)]` 是异读校勘，译文用圆括号「（异读：经论母，泰国本）」承载；但 `style.md` 规定圆括号专用于「术语首次出现夹注巴利原词」，同一符号在同句体系内承担两种功能，读者无法区分校勘与夹注。
- **建议**：改用全角方括号保留校勘形态，如「经藏二法论母［异读：suttantamātikā，暹罗本］」，并把异读的巴利原形留出（异读的价值在词形，只给汉译「经论母」读者无从比对）。同时在 `knowledge/translation-rules.md` 登记「异读统一用［］」。

- **问题**：版本简称译名 — `syā.` = Syāmaraṭṭha（暹罗本），学界惯用「暹罗本」；「泰国本」虽可懂，但属自创译名且未登记。
- **建议**：统一为「暹罗本」，并把 `syā. / sī. / ka. / ma.` 等版本简称一次性登记进 `knowledge/terms.md`。

- **问题**（低优先）：本句是篇章标题（义注 §889 以 `…padavaṇṇanā` 对应之），译文末尾保留句号「。」。标题行一般不带句末句号。
- **建议**：与 §387 的尾跋一并定规则——若视为标题则去句号，若一律随原文标点则保留现状；二者取一，写进规则文件即可，不必逐句改。
