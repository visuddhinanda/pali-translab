## 理由

**资源情况**：这次只注入了巴利原文和现有译文，没有义注和 nissaya。准确性只能对照巴利原文核对，并参考阿毗达摩汉译的通行术语。所以信心指数压到 78。建议有条件时补取义注（Dhammasaṅgaṇī-aṭṭhakathā · Rūpakaṇḍa 的 Catukka 部分），再复核一遍。

**准确性**：本段是《法集论》色品“四法”部分的排列格式：
- 以“所造 / 非所造”交叉“执受 / 非执受、执受顺取 / 非执受顺取、有对 / 无对、粗 / 细、远 / 近”
- 以“执受 / 非执受”交叉“有见 / 无见、有对 / 无对、大种 / 非大种、粗 / 细、远 / 近”

逐句核对结果：
- 22 句全部没有漏译，也没有多译，主宾关系都正确。
- `Yaṃ taṃ rūpaṃ X, taṃ atthi A, atthi B` 统一译成“凡是 X 的色，其中有的是 A 的，有的是 B 的”，与巴利句法一一对应。
- `no upādā` 译为“非所造”，`atthi na mahābhūtaṃ` 译为“有的不是大种”，否定范围都没有错。
- 段号“586.”保留了下来。
- 73:1264 的巴利原文在 `sappaṭighaṃ` 后少了逗号，译文照常补上了标点，处理正确。

**术语**：所造（upādā）、执受（upādiṇṇa）、执受顺取（upādiṇṇupādāniya）、有对 / 无对、有见 / 无见、粗 / 细、远 / 近、大种都是阿毗达摩汉译的通行译法，没有取义错误。本段没有夹注巴利原词。这些术语应该在前面的二法、三法部分首次出现过，本段不夹注是合规的，但这一点没有核实。

**风格**：通篇是现代书面汉语，没有文言虚词或文言句式。“其中”是现代汉语常用词，不属于文言“其”的禁例。标点全部是全角，没有残留工作标记。美中不足有两处：
- 标题句“以四种方式对色的归类”略显生硬。
- “执受顺取 / 非执受顺取”对一般读者比较晦涩，而且缺少注释。

**一致性**：句式在 22 句里完全统一。“的”字的用法也统一：形容词性的术语加“的”，“大种”这个名词不加，处理合理。

## 问题清单

### 🟦 suggestion
- `73-1257-2-6`｜语言表达不够流畅｜片段「以四种方式对色的归类」
  - 问题：“以……方式对色的归类”是介宾短语修饰名词，读来生硬。另外，没法确认它与前面“一法 / 二法 / 三法”各部分的标题句（`Ekavidhena / Duvidhena / Tividhena rūpasaṅgaho`）译法是否一致。
  - 建议：可以改为“色依四种方式的归类：”或“色的四种归类：”。另外，harmonize 需要对照前面各部分的标题句，统一成同一种句型。
- `73-1259-2-13`｜不常用术语编写注释或者百科｜片段「执受顺取」
  - 问题：upādiṇṇupādāniya 的意思是“被业所执受，又是取的所缘”。“执受顺取”是沿用的旧译，一般读者单看字面很难理解。
  - 建议：在本段首次出现的位置加一条脚注，说明它的含义；也可以在百科里立一个条目。
- `73-1259-2-13`｜代词指代可能不够明确｜片段「非执受顺取」
  - 问题：anupādiṇṇupādāniya 的意思是“非执受而顺取”。汉语字面上容易读成“非（执受顺取）”，否定范围不清楚。
  - 建议：译名维持不变，在上一条的同一个脚注里一并说明：“非执受顺取”指不被业所执受、但仍是取的所缘的色。
