## 理由

**评估基准缺失（先说明降级情况）**：本次只注入了巴利原文与目标 channel 译文，**没有 nissaya、没有父层（义注 / 复注）文本**。本批是复复注（anuṭīkā，book 175），其黑体被解释词全部引自父层；「被解释词与父层逐字同译」这一硬约束**本次无法核验**，例如 `175-89-2-9` 的「**随其可能之处**」、`175-89-201-205` 的「**这样一些**」、`175-90-14-23` 的「**就不会成为六法了**」等，是否与父层译文逐字一致，需回头比对后再定案。词级核对因此只能依巴利本身的格与句法结构、以及批内的内部一致性来做，信心指数据此压低。

**准确性**：整体解读可靠。四相（特相 / 作用 / 现起 / 近因）一节（`175-89-115-126`～`175-89-137-144`）对 `kiccaṭṭha` / `sampattiattha` 两义、`ñāpakahetu` 与 `kāraka` 的区分处理得当；`175-92-43-58` 这类「限定成分与被限定成分」的双重否定长句，逻辑层次译得清楚，没有译反。主要扣分在两类：一是 `175-89-2-9` 把只能归给 `sāvajjā` 的释义「saha avajjenāti sāvajjā」挂到了被解释词「Yathāsambhavaṃ」名下，属意思归属错误；二是三处**原文没有依据的增译**（`175-90-50-53` 的词义括注、`175-92-73-87` 的括注与整句补充），其中「这三个名字指的是同一位天神」是完整补出的一句话。这类背景说明本身不错，但按体例应走脚注，不该进正文。

**风格**：现代书面汉语基本达标，全批**未见文言句式**（无「此中／是故／彼等／之际／者…也」），标点全为全角，`zh` 字段内无 ASCII 引号，译文里也没有残留任何候选/待定标记——这几项硬约束都过了。个别处如「使之成立」属可接受的现代书面用法，不计文言。扣分主要在术语标记不成体系（`rasa` / `paccupaṭṭhāna` / `padaṭṭhāna` 都夹注了巴利原词，唯独同组的「特相」没有），以及少量口语化收尾（「算进…里去」）与冗语（「——这是就此而说的」）。

**一致性**：术语在批内是统一的——`visesana / visesitabba` 全批一律作「限定成分／被限定成分」，`abhidheyya`「所要表达的东西」、`vohāra`「名言」、`samaññā`「名称」、`paññatti`「施设」均无漂移，跨段（89→93）也没有走样。扣分点是被解释词的处理方式不统一：`175-91-7-28` 的省略式引文译成了中文（「**前面……乃至……就成了……**」），`175-90-88-97` 则原样留巴利（「**vini**……乃至……**mānā**」）。后者因是词中截断确实难译，但应有统一交代。

**关于「转起」**：`pavatti` 全批译「转起」，这是评估细则明确点名的二意词，首次出现处没有夹注巴利原词也没有注释，按 warning 记一条。

### 🟧 error

- `175-89-2-9`｜错译（词义、修饰关系）｜片段「就是照上面所说的方式这样来配合：与过失在一起，所以叫作有过失（sāvajja）」
  - 问题：原文 `Yathāsambhavanti saha avajjenāti sāvajjā, garahitabbabhāvayuttā.` 中，「saha avajjenāti sāvajjā」是对 `sāvajja` 一词的语源释义，不是对被解释词 `yathāsambhavaṃ` 的解释。译文用破折号加冒号把两者串成一句，读起来变成「随其可能之处」的意思就是「与过失在一起」，释义归属错误。此外「照上面所说的方式这样来配合」在巴利里没有任何对应成分，属增译。
  - 建议：断开两个释义单元，`yathāsambhavaṃ` 若父层无对应展开则据实处理，不要补出无据的「配合」句；另「随其可能之处」的「之处」多出了处所义，可考虑改为传统的「随其所应」——但须先与父层译名对齐。

- `175-90-50-53`｜错误多译｜片段「（既指月份，也指豆类、重量单位）」
  - 问题：原文 `māsa-saddābhidheyyabhāvena` 只说「是 māsa 一词所表达的对象」，并未列举 māsa 的诸义。括注内容虽属实且有助理解，但不是译文，按体例夹注圆括号只用于附巴利原词。
  - 建议：括注只保留巴利原词，多义说明移到脚注（交由 footnote 步骤处理）。

- `175-92-73-87`｜错误多译｜片段「；这三个名字指的是同一位天神。」
  - 问题：原文以 `evaṃ kiriyāguṇādipariggahavisesena` 收尾，没有这一句。「三名同指一神」是正确的背景知识，但整句为译者补出。
  - 建议：删出正文，需要时作脚注。

- `175-92-73-87`｜错误多译｜片段「（inda，即帝释）」
  - 问题：括注中「即帝释」同样是补出的说明，超出「夹注巴利原词」的体例。
  - 建议：改为「（inda）」，等同关系写进脚注。

### 🟨 warning

- `175-89-76-85`｜关键词语意不明确，或二意场合没有注释｜片段「用“有过失”这个词显示不善法在转起的时候是苦的」
  - 问题：`pavatti`「转起」是评估细则点名的二意词（生起/相续现行），全批出现三次（另见 `175-89-29-43`、`175-89-86-94`），首次出现未附巴利原词也无注释，一般读者难以确定所指。
  - 建议：首次出现改作「转起（pavatti）」，必要时加一句脚注区分「转起时苦」与「异熟时苦」。

- `175-93-16-27`｜关键词语意不明确，或二意场合没有注释｜片段「蜜蜂、木炭、杜鹃鸟等上面那种共通的青的性质」
  - 问题：`nīla` 兼含深蓝与黑，用于蜜蜂、木炭、杜鹃时汉语「青」不自然，读者会以为举例失当，反而看不出该段「共通性质」的论证。
  - 建议：保持译名「青」不变（与上句「青莲花」呼应），但首次出现处夹注「青（nīla，兼指深蓝、黑）」或加脚注说明。

- `175-92-59-65`｜代词指代不明确｜片段「那些词是为了解释尚未显明的语词意义而使用的」
  - 问题：「那些词」在汉语里没有明确先行词，上一句谈的是「限定成分与被限定成分」，此处实指同义词（pariyāya）一类的语词。原文主语省略，译文照省后歧义更大。
  - 建议：补明所指，如「那些同义的语词」。

### 🟦 suggestion

- `175-89-44-55`｜该使用而没有使用术语标记｜片段「而“有异熟”这一特相」
  - 问题：同组的「作用（rasa）」「现起（paccupaṭṭhāna）」「近因（padaṭṭhāna）」都夹注了巴利原词，唯独「特相」首次出现时没有，四相术语标记不成体系。
  - 建议：首次出现改为「特相（lakkhaṇa）」。

- `175-89-177-185`｜语言风格不统一｜片段「也应当算进“有苦的异熟”里去」
  - 问题：`yojetabbā` 在批内其他处均译作「配合理解／连起来理解」（见 `175-92-68-72`、`175-93-28-33`），此处改用口语化的「算进…里去」，语体偏低且与前后不一致。
  - 建议：改为「也应当配合到“有苦的异熟”上来理解」。

- `175-91-49-62`｜语言表达不够流畅｜片段「所以并不承认它们是同一个意义——这是就此而说的」
  - 问题：破折号后的「这是就此而说的」承接 `iti vuttaṃ`，但在汉语里成了空转，读者无法确定「就此」指什么。
  - 建议：并入前句处理，如「所以才说不承认它们是同一个意义」。

- `175-93-68-71`｜不常用术语编写注释或者百科｜片段「就是“使可厌的法动摇”等等的状态」
  - 问题：`kucchitasalana` 是 `kusala` 的语源释（kucchite salayati），汉语「善」与「使可厌者动摇」之间的联系对读者完全不透明，缺注则整句无从理解；另「可厌的法」中的「法」为原文所无。
  - 建议：加脚注说明该语源释，正文可作「使可厌的（事物）动摇」。

- `175-89-201-205`｜语言表达不够流畅｜片段「所谓**这样一些**」
  - 问题：`evaṃpakārānaṃ` 的重心在「种类」（pakāra），译作「这样一些」把类别义丢成了数量义。
  - 建议：作「这样种类的（诸法）」——但须先确认父层被解释词的译法，逐字对齐优先。

- `175-90-88-97`｜语言风格不统一｜片段「所谓“**vini**……乃至……**mānā**”」
  - 问题：`175-91-7-28` 的省略式引文译成了中文（「**前面……乃至……就成了……**」），此处保留巴利。两种处理并存，读者不易判断体例。
  - 建议：词中截断确实不宜硬译，可保留原样但补一句说明所引为何语，或在批内统一为「引文首尾照录巴利＋随后给出中译」。
