## 理由

**基准可用性（影响信心）**：本次评估对象本身是义注层（book 96，Dhammasaṅgaṇī 的 Aṭṭhasālinī），按「义注定释义」的原则，其上位参照应是复注（Mūlaṭīkā）；本次未注入复注，也未注入 nissaya。实际只能以巴利原文 + 译文对读，词法（格、句法角色）与传统取义没有独立基准可核。因此信心压到 70，词级判断（尤其 `teneva`、`eteyeva` 一类指代词的所指）标注为存疑而非定谳。

**准确性**：段 875–878 是纯定义性文本（词源释义 + 二法母组合逻辑），译文对 `-ti … iti` 释义句式（"X 者，因为 Y，所以是 Z"）的处理稳定且正确，`ceva … ca` / `na ca` / `kho pana` 等组合式母题的推演逻辑完整译出，无漏译、无增译。词源解析链（`loko → lokiyā`、`uttarā → lokuttarā`、`āsavanti → āsavā` 的四重释义）都保住了原文的推导关系。扣分主要来自一处指代：`eteyeva bhavitumarahanti` 的"这些"在汉语里最近先行词是同句的"酒等"，与原文所指（无明等烦恼）相反，构成会被读反的表达。

**风格符合度**：整体是现代书面汉语，未见文言句式、未见工作标记、标点为全角、`zh` 字段内无 ASCII 引号，符合硬约束。扣分集中在两类：一是 `-aṭṭhena` 一律译作"依…的意义"（"依根本的意义""依长久存放的意义"），"依"作单音节文言虚词，且"由于败坏破散的意义"一处已经不成句；二是正文内解释性圆括号偏多（（两词分写）、（同生、同灭、同一所依、同一所缘）、（八）不相离色、（陈酒一类的）），`knowledge/style.md` 规定圆括号夹注只用于首次出现的术语附巴利原词，解释性补充应按"段后小字注释"处理。

**一致性**：三层被解释词与母论词条对齐良好，加粗 lemma 与巴利黑体一一对应。不一致有两处体例层面的：因聚/小中间部分的二法一律译作"有…的／无…的"（有因的、无缘的、有色的），到漏聚改成不带"的"的"有漏／无漏"；`okāsa` 在 96-878-20-30 译"处所"、96-878-31-38 译"范围"。都不影响理解，但同一批次内应统一。

## 问题清单

### 🟧 error
- `96-878-61-68`｜导致误解的表达（代词指代）｜片段「那么正是这些才配称为漏」
  - 问题：`eteyeva` 指的是无明等烦恼漏（下文随即引《增支部》证"无明前际不可知"，即比陈酒更久存），但汉语中"这些"最近的先行词是同句前半的"酒等"，读者极易理解成"酒才配称为漏"，与原意相反。
  - 建议：把所指补出，如"那么正是这些烦恼才配称为漏"。

### 🟨 warning
- `96-877-92-103`｜代词指代不明确｜片段「那同一种识」
  - 问题：`teneva` 直译为"那同一种识"，与上一句"可以被某一种识…了知"并置，字面像是说同一识既能知又不能知，读者无从判断所指为眼识还是耳识。
  - 建议：明确为"不能被上面那一识以外的识"或改为"就那一识而言则不可知"，必要时加简注说明色被眼识知而不被耳识知。
- `96-877-55-62`｜不导致误解的汉语语病｜片段「由于败坏破散的意义」
  - 问题：「由于…的意义」搭配不成立，`lujjanapalujjanaṭṭhena` 是"因为有败坏破散的意思"。
  - 建议：改为"因为有败坏破散的意思，轮回被称为世间"。
- `96-875-11-19`｜文言语体｜片段「依根本的意义」
  - 问题：「依」作单音节文言虚词，`knowledge/style.md` 要求能用双音节现代词就不用单音节文言词。
  - 建议：改为"按照根本这个意思"或"就作为根本这一点而言"。
- `96-878-47-50`｜文言语体｜片段「依长久存放的意义」
  - 问题：同上，`-aṭṭhena` 统一译成"依…的意义"，属半文言表达。
  - 建议：改为"按照长久存放这个意思"，并与上一条统一处理。
- `96-877-30-35`｜整句逻辑表达不规范｜片段「就（八）不相离色而言」
  - 问题：孤立的圆括号数字"（八）"在正文中形似注释编号，且"（八）不相离色"读起来不成词。
  - 建议：改为"就八不相离色而言"，或"就不相离色（共有八种）而言"。
- `96-878-47-50`｜不该使用术语标记时使用了术语标记｜片段「酒等也叫做漏（āsava）」
  - 问题：`āsava` 首次出现在 96-878-5-9（"所以叫做**漏**"）未夹注巴利原词，到第四次出现才补夹注，违反"首次出现夹注、其后只用汉译"的体例。
  - 建议：夹注上移到 96-878-5-9，此处删去（āsava）。

### 🟦 suggestion
- `96-878-112-120`｜语言风格不统一｜片段「所以是**有漏**」
  - 问题：同批次其他二法一律作"有因的／无因的""有缘的／无缘的""有色的／无色的"，漏聚改为不带"的"。
  - 建议：统一为"有漏的／无漏的"，或反向统一全批次。
- `96-878-31-38`｜语言风格不统一｜片段「这个范围」
  - 问题：`okāsa` 在 96-878-20-30 译"处所"，此处译"范围"。
  - 建议：统一译名，此处作"这个处所"。
- `96-875-20-23`｜语言表达不够流畅｜片段「（两词分写）」
  - 问题：译者补充的解释直接进正文括号，与术语夹注格式混用。
  - 建议：移作段后小字注释，正文只留"也有读作 hetū dhammā 的异读"。
- `96-875-44-48`｜语言表达不够流畅｜片段「（同生、同灭、同一所依、同一所缘）」
  - 问题：`ekuppādāditā` 的四支展开是正确的，但整串塞进正文括号使句子中断。
  - 建议：正文作"由于同一生起等的关系"，四支移到段后注释。
- `96-876-41-59`｜复杂的嵌套句整句语言逻辑理解困难｜片段「并非只有“不是因的法”才如此，其他的法也如此」
  - 问题：两处"如此"所指不同（前指"也有有因也有无因"，后指同一命题成立），读者需回读才能理清。
  - 建议：把第二处展开，如"其他的法也同样有有因的、有无因的"。
- `96-877-63-68`｜语言表达不够流畅｜片段「属于世间，所以是**世间的**」
  - 问题：`loke niyuttā → lokiya` 的构词解释在汉语里成了同义反复，读者看不出这是词源分析。
  - 建议：改为"由于系属于世间（loka），所以叫做世间的（lokiya）"。
- `96-878-20-30`｜关键词语意不明确｜片段「从法上一直流到种姓（gotrabhū）」
  - 问题："从法上"字面直译 `dhammato`，读者难以理解是"就所缘之法而言"。
  - 建议：改为"就法而言一直流到种姓，就处所而言一直流到有顶"，与下半句对仗。
- `96-875-141-146`｜语言表达不够流畅｜片段「与“与因相应”这一组二法组合的情形」
  - 问题："与…与因相应…"连用两个"与"，读来拗口。
  - 建议：改为"同"与因相应"这一组二法搭配时，道理也是一样"。
- `96-875-5-10`｜语言表达不够流畅｜片段「在三法母中没有出现过的词」
  - 问题：`tikesu` 直指前面已注释的诸三法，译作"三法母"是就整篇立名，语境虽通但与原文颗粒度不同。
  - 建议：改为"在前面诸三法中没有出现过的词"。
