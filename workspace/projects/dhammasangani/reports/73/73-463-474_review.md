## 跨段一致性

- **saṃ- / saṃ 前缀构词处理不一致（必改）**：§468 `phasso phusanā saṃphusanā saṃphusitattaṃ` 把前缀译出为「触／接触／遍触」，§469 `cetanā sañcetanā cetayitattaṃ` 却把 `sañcetanā` 译成「意愿」，脱离同根递进串。同一 chunk 内两组结构完全平行的同义词串，构词法必须同样处理。建议 §469 改为「思、等思、已思的状态」。
- **`parakkama` 一词两译（必改）**：§474 中 `parakkamo` 译「勇猛」，同段 `asithilaparakkamatā` 却译「不松懈的努力」。建议后者改「不松懈的勇猛」。
- **`vāyāma` 与 `parakkama` 撞车**：§474 `vāyāmo` 译「努力」，`asithilaparakkamatā` 也用「努力」，两个不同巴利词共用一个汉译词，在同义词串里会让读者以为原文重复。随上一条一并修正。
- **`dhura` 一词两译（必改）**：§474 `anikkhittadhuratā`「不放下担子」与 `dhurasampaggāho`「承担重任」，同一 `dhura` 前后作「担子／重任」。建议统一为「重担」：不放下重担、策持重担。
- **术语待登记**：`somanassindriyaṃ`→「喜根」、`mānasaṃ`→「意所」、`paṇḍaraṃ`→「洁白」、`tajjā`→「与之相应」均未见于 `knowledge/terms.md` 与 `term-glossary.jsonl`，本 chunk 内部用法一致，建议定案后补录。
- **段首编号体例**：原文作 `67.`–`76.`，译文一律作「六七、」…「七六、」。chunk 内一致，但需与本书其他 chunk 的体例核对后统一（本次无跨 chunk 数据，仅记录）。
- §464 与 §470 巴利完全相同（`cittaṃ mano mānasaṃ …` 串），译文亦逐字相同，仅结句术语随本段不同 ✅

## §474 句 73-474-11-38

- **问题**：**译项数与原文不符** — 原文 17 项：`cetasiko vīriyārambho / nikkamo / parakkamo / uyyāmo / vāyāmo / ussāho / ussoḷhī / thāmo / dhiti / asithilaparakkamatā / anikkhittachandatā / anikkhittadhuratā / dhurasampaggāho / vīriyaṃ / vīriyindriyaṃ / vīriyabalaṃ / sammāvāyāmo`；译文 18 项（属于心的发起精进／出离／勇猛／奋起／努力／热忱／勤奋／坚毅／力量／**坚持**／不松懈的努力／不放下欲愿／不放下担子／承担重任／精进／精进根／精进力／正精进）。「坚持」一项在原文中无对应词，属增译。
- **建议**：删去「坚持」，使译项与原文逐项对齐。

- **问题**：**`thāmo` / `dhiti` 疑似对调** — `thāma` 是力、势力，`dhiti` 是坚忍、持守；译文作「坚毅／力量」，次序与词义相反。
- **建议**：改为 `thāmo`＝力量（或势力）、`dhiti`＝坚忍。与上一条合并后此处三项收缩为两项。

- **问题**：**`nikkamo` 译「出离」有术语混淆风险（待核义注）** — 此处 `nikkama` 是精进同义词串的一员，指从懈怠中奋出；单译「出离」会被读者直接读成 `nekkhamma`（出离、离欲），指向完全不同的法相。
- **建议**：改为「奋发」，或译「出离懈怠」把语境限死。定案前需核 cittuppādakaṇḍa 义注对 `nikkamo` 的释文（本次未注入）。

- **问题**：`ussoḷhī` 译「勤奋」，与前项 `ussāho`「热忱」区分度偏低，且 `ussoḷhī` 传统取「勇健、奋励」义。
- **建议**：`ussāho`＝热忱／奋勉，`ussoḷhī`＝勇健，待核义注后定。

- **问题**：`sammāvāyāmo` 译「正精进」（八正道固定译名，符合 `terms.md`），但同串前面 `vāyāmo` 译「努力」，读者看不出二者同根。
- **建议**：保留「正精进」不动，改 `vāyāmo` 为「精勤」以外的现代词并在术语表登记该对照即可，不必为迁就串内一致而动固定译名。

## §464 句 73-464-11-31（及 §470 句 73-470-12-32，同一词串）

- **问题**：`hadayaṃ` 译「心脏」（待核义注）。此串是心的同义词罗列，`hadaya` 在此取「内、内心」义，非解剖学器官；夹在「意所／洁白／意处」之间出现「心脏」，一般读者会读成生理心脏，属误导。
- **建议**：改译「内心（hadaya）」，或保留「心」并加段后小字注说明取义。定案需核前文义注对 `hadaya` 的释文。

- **问题**：`paṇḍaraṃ` 译「洁白」（待核义注）。传统汉译作「净白」，且此词在义注传统中指清净、指向有分心，「洁白」作为独立名词项在汉语里读不通。
- **建议**：改「净白」，并按 `style.md` 第四节把取义放进段后小字注。

- **问题**：`tajjāmanoviññāṇadhātu` 译「与之相应的意识界」——「之」是 `style.md` 第一节禁例表列出的文言虚词。
- **建议**：改「与此相应的意识界」或「相应的意识界」。

## §469 句 73-469-11-23

- **问题**：`sañcetanā` 译「意愿」，脱离 `cetanā / sañcetanā / cetayitattaṃ` 同根递进串，也与本段术语「意思食」（`manosañcetanāhāro`）的用字断开（见跨段一致性第一条）。

## §466 句 73-466-2-8 ／ §471 句 73-471-2-8

- **建议**：改「以上就是那时的两种界／三种食」，chunk 内两处一并改。属可选优化，非必改。
