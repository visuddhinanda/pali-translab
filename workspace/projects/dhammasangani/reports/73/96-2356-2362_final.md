- **「被解释词与父层逐字同译」这条硬约束本次无法核验**——义注中的黑体 lemma（`sahadhammike vuccamāne`、`dovacassāyaṃ`、`taṃsampavaṅkatā`、`pañcapi āpattikkhandhā` 等）是否与本文层译文逐字一致，缺父层无从比对。下列涉及 lemma 的条目按「译法本身是否稳妥」出具，级别相应压低。

**一致性（81）**：本段最弱的一维，问题成系统而非偶发：

1. `saṃ-` 前缀译法三取其三——`saṃsevanā`→「全面亲近」、`sambhajanā`→「深交」、`sambhatti`→「全面亲爱」，其中「深交」与紧随其后的自释「从各个方面结交」直接矛盾；
2. 同一个「X-kusalatā / X-vuṭṭhāna-kusalatā」构词，译出了「犯的善巧 / 出犯的善巧」「入等至善巧 / 出等至善巧」「界善巧」「处善巧」四种格式，带「的」与不带「的」、`samāpattikusalatā` 独自多一个「入」字；
3. 同一句内抽象名词与人称名词共用一个汉语词（不尊重 / 不尊重、乐于对抗的人 / 乐于对抗），造成循环定义；同句内又出现「不敬重 vs 不恭敬」「不听从 vs 不顺从」的释义词与 lemma 不对榫。

这些不影响取义，但跨段连读时明显，属 harmonize 该收而未收干净的部分。

## 问题清单

### 🟧 error

- `96-2357-17-25`｜导致误解的表达｜片段「戒并没有带 du 的名字」
  - 问题：`sīlassa dunnāmaṃ natthi` 的意思是「并不存在『恶的戒』这种东西」——此处的 `du-` 不表「坏」而表「无」，所以 `dussīla` 等于 `nissīla`。译文把它逐字搬成「戒并没有带 du 的名字」，混入未加说明的拉丁字母，中文读者读不出任何意思，且会误以为是在讲拼写。
  - 建议：改为「并没有『恶戒』这回事（戒不会是恶的），所以意思就是没有戒」，或「这里的 du- 不是『恶』而是『无』的意思，所以就是没有戒」。

### 🟨 warning

- `96-2357-63-67`｜关键词语意不明确｜片段「“**深交**”：就是从各个方面结交」
  - 问题：lemma 译「深交」（取 saṃ- 为「深」），自身释义却作「从各个方面」（`sabbatobhāgena`），一句之内自相矛盾；且与平行的 `saṃsevanā`→「全面亲近」、`sambhatti`→「全面亲爱」不统一。
  - 建议：统一 `saṃ-` 为「全面」，改作「全面结交」。
- `96-2356-86-91`｜整句逻辑表达不规范｜片段「由于不接受教诫而不尊重的人，他的状态就是**不尊重**」
  - 问题：`anādara`（人／性质）与 `anādariya`（其状态）被译成同一个词，句子退化为「不尊重的人的状态就是不尊重」，读者看不出在定义什么。
  - 建议：拉开层级，如「……不加敬重者的状态，就是**不敬**」，使 lemma 与释义词形不同。
- `96-2356-100-105`｜整句逻辑表达不规范｜片段「不敬重的状态，就是**不恭敬**」
  - 问题：释义用「不敬重」，lemma 却落在「不恭敬」，同句两词不对榫，读者会以为是两个概念。
  - 建议：二者择一统一（建议释义与 lemma 同用「不恭敬」）。
- `96-2356-106-111`｜整句逻辑表达不规范｜片段「不听从的状态，就是**不顺从**」
  - 问题：同上，`appaṭissava-bhāva` 译「不听从」而 lemma `appaṭissavatā` 译「不顺从」。
  - 建议：统一为「不顺从」。
- `96-2357-40-42`｜关键词语意不明确｜片段「从亲近的意义上说，是**亲近**」
  - 问题：`sevanaka-vasena sevanā` 译成循环句，中文读者读到「从亲近的意义上说，是亲近」得不到任何信息。
  - 建议：点出是「以亲近这一行为（而立名）」，如「就亲近这一行为而言，称为**亲近**」。
- `96-2360-8-14`｜关键词语意不明确，二意场合没有注释｜片段「连同遍作一起了知安止的界限的慧」
  - 问题：「遍作」（parikamma）、「安止」（appanā）都是禅修专门术语，按 `knowledge/style.md` 二之「罕见或有争议的术语首次出现附简注」应加夹注，此处首次出现却无任何提示，一般读者无法理解。
  - 建议：首次出现改为「遍作（parikamma，即入定前的预备作业）」「安止（appanā）」。
- `96-2362-2-10`｜关键词语意不明确｜片段「称为**处善巧**」
  - 问题：该句巴利作 `…paricchedajānanakapaññā latā nāma`，`latā` 是 `āyatanakusalatā` 的脱字残形。译文补全正确，但未留任何标注，后人核对时会以为原文即如此。
  - 建议：译文可维持现状，但须把「book 96, para 2362：`latā` 疑为 `āyatanakusalatā` 之脱」登记进 `knowledge/known-issues.md`。
- `96-2356-2-35`｜不导致误解的汉语语病｜片段「你犯了这样的犯」
  - 问题：「犯了……犯」同词叠用，别扭；同句「指出事由、判定他的犯」亦同。
  - 建议：改为「你犯了某某罪」，或「你所犯的是这一条」；上文作「指出事由、判定所犯的罪」。
- `96-2356-36-47`｜整句逻辑表达不规范｜片段「或者反过来指责对方，或者不恭顺地领受」
  - 问题：`paṭicodanāya vā appadakkhiṇagāhitāya vā` 是表原因的具格，修饰「成为难说者（dubbaca）」；译文拆成与前面主语并列的两个「或者」分句，主语链断开，读起来像在罗列三件并列的事。
  - 建议：还原因果，如「这样被举罪时，由于反过来指责对方、或者不恭顺地领受而成为难以教导的人——这种人的行为，就是难教」。

### 🟦 suggestion

- `96-2359-40-48`｜语言风格不统一｜片段「**犯的善巧**」
  - 问题：与同批的「界善巧」「处善巧」「作意善巧」「缘起善巧」构词不一致，多一个「的」；`96-2359-49-55`「出犯的善巧」同。
  - 建议：统一为「犯善巧」「出犯善巧」。
- `96-2360-8-14`｜语言风格不统一｜片段「**入等至善巧**」
  - 问题：`samāpattikusalatā` 本身只是「等至善巧」，译文多补一个「入」字以对仗下文的「出等至善巧」；但同一构词在 2359 处理为「犯的善巧 / 出犯的善巧」（前项不补字），两处规则相反。且 `96-2360-2-7` 刚把 `samāpatti` 定名为「等至」，紧接着 lemma 变成「入等至」。
  - 建议：统一作「等至善巧 / 出等至善巧」。
- `96-2360-15-35`｜语言风格不统一｜片段「我就出定」
  - 问题：同一句内「出定」与 lemma「出等至」并用，术语与口语混杂。
  - 建议：正文也用「从等至出起」，或在首次出现处注明「出等至（即出定）」，此后统一。
- `96-2357-92-101`｜语言风格不统一｜片段「“**身心都倾向于他们**”」
  - 问题：lemma `taṃsampavaṅkatā` 被译成一个描述性短句，且提前把释义里的「身与心」并入词头，词条与释义重复；注意此处**是否与本文层同译本次无法核验**（父层未注入），若本文层作「倾向他们」则违反逐字同译的硬约束。
  - 建议：lemma 收紧为「倾向他们」之类的词形，把「身、心」留给释义；并在下一轮 harmonize 时对照本文层 1333 的译文核定。
- `96-2359-2-21`｜语言风格不统一｜片段「戒经本母（mātikā）的解说」
  - 问题：`mātikāniddesena` 只作「依本母的解说」，「戒经」二字为原文所无的补足；同句「五犯聚也好」的「也好」偏口语。
  - 建议：改为「按照本母（mātikā）的解说」；`pañcapi/sattapi` 两句改为「所谓『五犯聚』……」「所谓『七犯聚』……」。
- `96-2357-50-54`｜语言表达不够流畅｜片段「这只是加了前缀让词变长了」
  - 问题：口语化，且该句在本批重复三次（另见 `96-2357-68-72`、`96-2357-82-86`），同一固定套语宜定型。
  - 建议：统一作「或者说，这只是用前缀把词加长而已」。
- `96-2357-2-10`｜语言风格不统一｜片段「所以称为**没有信心**」
  - 问题：`assaddhā`、`maccharino`（`96-2357-30-35`「所以称为**悭吝**」）在原文都是指人的复数主格，译文一律作性质名词；性质化译法在本批内部一致，故不作扣分，但「没有信心」口语度明显高于同列的「不持戒」「少闻」「悭吝」「缺乏智慧」。
  - 建议：改为「无信」，与其余四项的书面度拉齐。
- `96-2359-40-48`｜复杂的嵌套句整句语言逻辑理解困难｜片段「连同事由一起了知这些犯的界限的慧」
  - 问题：「……的……的慧」三层定语连缀，本批共出现五处同型句（另见 `96-2359-49-55`、`96-2360-8-14`、`96-2361-2-12`、`96-2361-13-17`），连读吃力。
  - 建议：拆为「能连同事由一并判定这些犯的界限，这样的慧就称为**犯善巧**」的句式，整批统一改写。
- `96-2356-56-59`｜代词指代可能不够明确｜片段「剩下的“难教”一词」
  - 问题：`itaraṃ` 指本文列举中未单独解释的那个同义词（此处应为 `dovacassatā`），译文以「难教」指代，但「难教」在上文已被用作 `dovacassāyaṃ` 的译名，读者分不清指的是哪一个词。
  - 建议：点名所指，如「另一个词（难教性）只是它的同义词」；`96-2356-92-95` 处理方式（直接点出「不尊重的状态」）更清楚，可作统一范式。
