## 被解释词核对

本 chunk 只有一处黑体：`96-1036-39-46` 的 **kāyakammadvāraṃ** → 译「**身业门**」。
但所给父层区间（73:390-450，句分别章）中**没有出现 kāyakammadvāra 这个词**，无法做逐字比对。
→ **必须补核**：取父层中真正含 kāyakammadvāra 的段落，确认定稿译法是否为「身业门」。若父层作「身业之门」或其他，本层须逐字跟随。在核实前不能算通过。

## 跨段一致性

- **kamma（业）在四组平行偈中译法三样**（最严重问题）：
  §1041「kāyakamma → **身业**」、§1043「sūcikamma → **针工**」、§1045「vāsikamma → **斧工**」、§1047「purisakamma → **人工**」。
  这四偈是同一个论式的排比：正因为四处都是同一个 kamma 词，才推得出「作者与所作各别安立」。中文换成「业／工」两套词，排比断裂，读者看不出论证结构。
  → 统一为「针业」「斧业」「人业」，或全部作「针所作的业」「斧所作的业」「人所作的业」。同理 §1043/1045/1047 的谓语「所做的活儿／所做的事」要与 §1041「所造的业」统一。
- **vavatthita 与 ṭhapetabba 都译成「确定」**：§1037-25-44 / §1037-45-56 用「确定」译 ṭhapetabba（安立、判定归属），§1039 / §1042 / §1044 / §1046 用「各别确定」译 vavatthitā（彼此有别、各别安立）。同一中文词承担两个不同术语，且两者在同一段落群内交替出现，容易混读。
  → 建议 vavatthitā 一律改「彼此各别安立」或「彼此有别」，「确定」留给 ṭhapetabba。
- **kāya 时而「身」时而「身体」**：§1037-25-44「身体是门」、§1040-66-79「身体是一回事…由身体所造的」，但同语境的复合词作「身门」「身业」「身业门」。讨论的正是「kāya 与 kāyakamma 的关系」，术语词与散文词不同形会削弱这层关系。
  → 建议这两句改用「身」：「身是门」「身是一回事，业是另一回事，因为是由身所造，所以叫身业」。
- **porāṇā 与 aṭṭhakathācariyā 都译成「师父」**：§1037-89-91「古代的师父们」、§1040-80-82「义注的诸位师父」。二者是不同的引述权威（古师／义注师），且「师父」是现代口语称呼，用于引述论典权威不当。
  → 建议分别作「古师们说」「诸位义注师说」（或「古代的论师们」「义注的诸位阿阇黎」），两处保持体例一致。
- **语体前后不一**：散文部分是规范现代书面语，但偈颂部分出现「活儿」「斧子」等口语词，与同偈中「彼此各别确定」的书面语不搭。→ 「活儿」改「所做的业」，「斧子」改「斧」。

## §1036 句 96-1036-2-10

- **问题**：术语误导 —「tisamuṭṭhāniko」译作「**三生的**身体」。中文「三生」现代读者第一反应是「三世」，与原意（由三种等起因所生）相去甚远；且与同句「心生的身体」构词不对称（一个是「心」，一个是数量「三」）。
- **建议**：改为「由三种等起（因）所生的身」并首次夹注，例如「那么，当心等起的身动的时候，由其余三种因（业、时节、食）等起的身是动还是不动呢？」。三因的具体所指依阿毗达摩四等起说推得，**缺复注佐证，属存疑**——若不能确证，至少退一步作「三种等起所生的身」，不要写「三生」。
- 另：「cittasamuṭṭhānika」本段译「心生的」、`96-1036-39-46` 亦作「心生的色法」，内部一致 ✅；但建议与上条一并统一为「心等起的／心所生的」。

## §1036 句 96-1036-15-18

- **问题**：指代不清 —「它随着那个走，只是跟着那个转」，两个「那个」连用，读者要回溯两句才知道指心等起的身。
- **建议**：「它以心等起的身为归趣，只是随着它转。」

## §1036 句 96-1036-19-38

- **问题**：措辞重复 — 本句结尾「这件事应当这样来理解」，紧接的下一句又以「应当这样来理解」开头，短距离内同一说法出现两次。
- **建议**：本句改「这里的情形应当照此理解」，把「应当这样来理解」留给下一句的结论。

## §1036 句 96-1036-39-46

- **问题**：术语未加注 —「这个**表**」。viññatti（身表）是法相术语，单独一个「表」字现代读者无法解读；`style.md` 规定法相术语首次出现须夹注巴利原词。
- **建议**：「这样的表（viññatti）」或「这一身表（kāyaviññatti）」，其后再用「表」。
- **建议**（次要）：语序上把 Evam 的结论口吻理顺——「因此应当知道：在心所生的色法当中，这样的表就叫做身业门。」

## §1037 句 96-1037-2-24

- **问题**：措辞 —「取不与取」。「不与取」本身已是「取」的译名，再加「取」字成了叠床架屋；且这里 adinnaṃ ādiyati 是动作描述，不是术语列举。
- **建议**：「拿取没有给予的东西」，或沿用传统「偷盗（不与取）」。
- **问题**（次要）：「远离杀生等等」的「等等」偏口语，且句子主干「而在那个门里成就的思……这就叫做身业」被中间的长定语切断。
- **建议**：「而在那个门里成就的思——人凭着它杀生、拿取没有给予的东西、行邪淫，或者远离杀生等（恶行）——这就叫做身业。」

## §1037 句 96-1037-25-44

- **问题**：术语 —「paravādi」译「反对者」过泛，读起来像日常争执中的对方。此处指论争中持异说的论师。
- **建议**：改「他论者」，首次出现夹注：「在有他论者（paravādī）的场合」。
- 关联：「身体是门」按上文跨段一致性建议改「身是门」。

## §1037 句 96-1037-45-56

- **问题**：语体 —「**凑成**三项来确定」。「凑」带有勉强拼补的意味，而 tikaṃ pūretvā 是把三法（善／不善／无记）补足完整这一体例动作。
- **建议**：「而在没有他论者的场合，则应当补上‘或是无记的’，使三法完整之后再作安立。」（同时按跨段意见把「确定」的用法与 vavatthita 区分开。）

## §1039 句 96-1039-2-8

- **问题**：术语 —「是彼此各别确定的」，见跨段一致性第二条。此外原文语序是「所以诸业与诸门」，译文作「门与业」，与上句「诸业在门里往来，门却不是……」的主次顺序倒置了一次。
- **建议**：「所以诸业与诸门，是彼此各别安立的。」

## §1040 句 96-1040-36-61

- **问题**：树名考订存疑 — simbali／palāsa／pucimanda／phandana 分别译「木棉树／紫矿树／苦楝树／榈木树」。前三个有传统依据，**phandana 译「榈木树」缺乏依据**（该词的比定在各家注疏与辞书间不一致）。
- **建议**：保留现译但需查证；若查不到确据，可改用音译加注（如「phandana 树」）。**不要在译文里留问号或候选标记**，存疑记在本报告即可。
- 另：本句无其他问题，「因为这棵树那棵树而得名」与前段「这道门那道门」的处理一致 ✅。

## §1042 / §1044 / §1046 句（96-1042-2-8、96-1044-2-8、96-1046-2-8）

- **问题**：同跨段一致性第一、二条 —「针工／斧工」与「各别确定」。
- **建议**：三偈统一为「那么针和针业，是彼此各别安立的」「那么斧和斧业，是彼此各别安立的」，与 §1042「那么身和身业，是彼此各别安立的」形成整齐排比。

## §1047 句 96-1047-2-9

- **问题**：除术语统一外，本 chunk 在此处**从偈颂中间断开**——§1047 只是「若…则…」的前半，对应的后半（purisa 与 purisakamma 各别安立）落在下一 chunk。
- **建议**：不是本 chunk 的错误，但下一 chunk 提交时必须沿用此处敲定的「人／人业」译法，否则一联偈的上下半会用两套词。
