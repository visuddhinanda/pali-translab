## 理由

**基准资源缺失（降级评估）**：本次只注入了巴利原文与目标 channel 的译文，**没有 nissaya、没有义注（aṭṭhakathā），也没有本层所解释的父层（复注）文本**。本书为复复注（anuṭīkā），其黑体被解释词全部引自复注，无父层就无法核对「被解释词与父层逐字同译」这条硬约束，也无法用义注定释义、nissaya 定词法。因此下列判断基本只依据巴利原文本身的词法与段内自洽性，词级覆盖率与传统取义两项没有独立基准，信心指数相应压低到 72。

**准确性**：整体高于一般水平。最见功力的是 para 134 那组语法辨析——134-38-53 把 `neva dassanena na bhāvanāya pahātabbo hetu etesaṃ atthi` 处理成「它们没有应当由见断除、也没有应当由修断除的因」（否定存在，与 134-28-37「两个 pahātabbahetu 词分别相连」的解释一致），134-77-86 把 `napahātabbo hetu` 处理成「它们的因不应当由见和修断除」（na 与 pahātabba 复合），两种读法分得清楚，没有混淆。134-2-8 也正确区分了 `appahātabbahetu` 与 `appahātabbahetuka`。139 段的语源解说（parito khaṇḍitā → 微小、mahāpamāṇabhāvena gatā → 广大、agocarabhāva → 无量）也都到位。

主要扣分在两处：一是 134-54-58 / 134-59-68 把 `pahātabbahetukapada`（带 -ka）与 134-28-37 的 `pahātabbahetusadda`（不带 -ka）一律译成「“应断之因”这个词」，抹掉了整段辨析赖以成立的 hetu / hetuka 之别——而 134-2-8 本已把这一区别译对，属段内自相矛盾；二是 134-54-58 的 `Tehi`（与 yutta 搭配的具格，表「与…相连」）译成「由它们」，与同句下半「与它们相连」打架。另有 135-84-94 把 `tathā ... phalaṃ`（果也同样三分）译成「分为几种」，把确定的三分说成不定数。

**风格**：绝大部分是通顺的现代书面汉语，标点全角、无 ASCII 引号、无工作标记，符合 `knowledge/style.md` 的 JSON 安全与信心标记要求。扣分集中在残留文言：「应断之因」（之，出现 3 次）、「随其可能」（其）、137 段引经处的「依…而行持圆满」「…而住」。137 是引《增支部》原经，旧译腔最容易渗入，但风格约束是硬性的，仍按 warning 计。此外 138-2-7 是承 136「难道不是——」而来的反诘问句，译文用句号收尾，问答结构断掉。

**一致性**：术语大体统一（apacayagāmī 一律「导向离积」并首出夹注、apariyāpanna 一律「不所属」、mahaggata 一律「广大」、ācaya 一律「积聚」）。不统一的有三处：hetu / hetuka 的合并（见上，同时是准确性问题）、paritta 在 139-15-30 作「小法」而在 139-90-95 作「微小」、ārammaṇakaraṇa 在 135 段「以它为所缘」与「取它为所缘」并用（后者可容忍，因分别对应引文与释文）。

`apacayagāmī`→「导向离积」、`ekasesa`→「只保留其一」、`byattaya`→「语形变换」均为未登记译名，译文选定一种并夹注巴利原词、未留标记，处理方式合规；建议定案后补进 `knowledge/terms.md`。

## 问题清单

### 🟧 error

- `175-134-54-58`｜错译（词义）／漏译｜片段「与它们相连的“应断之因”这个词」
  - 问题：原文是 `pahātabbahetukapadena`，带 -ka，指「以应断者为因的」这个词，不是 134-28-37 的 `pahātabbahetusadda`（应断之因）。134-2-8 已把 `appahātabbahetu` / `appahātabbahetuka` 分别译为「不应断除的因」「以不应断除者为因的」，此处却把两个词形合并成同一个中文，整段（samāsa 是否成立、两词如何分别相连）的辨析核心随之消失。
  - 建议：改为「与它们相连的“以应断者为因的”这个词」，与 134-2-8 的处理保持一致。

- `175-134-59-68`｜错译（词义）／漏译｜片段「把“应断之因”这个词分别与“见”和“修”这两个词相连」
  - 问题：同上，`pahātabbahetukapadassa` 带 -ka，被译成不带 -ka 的「应断之因」。
  - 建议：改为「把“以应断者为因的”这个词分别与“见”和“修”这两个词相连」。

- `175-134-54-58`｜错译（修饰关系）｜片段「所谓**由它们**」
  - 问题：`Tehi` 是与 `yuttena` 搭配的具格，表「与…相连」的对象，不是施事或工具；译作「由它们」与同一句下半的「与它们相连」互相矛盾。
  - 建议：改为「所谓**与它们**，是指“见”和“修”这两个词」。

### 🟨 warning

- `175-134-28-37`｜文言语体｜片段「“应断之因”这个词要分别与两处相连」
  - 问题：「应断之因」用文言虚词「之」，且与 134-2-8「不应断除的因」的构词不一致。
  - 建议：统一为「应断的因」。（134-54-58、134-59-68 两处同病，按上列 error 改写时一并处理。）

- `175-138-12-22`｜文言语体｜片段「随其可能」
  - 问题：`yathāsambhavaṃ` 译作「随其可能」，「其」为文言虚词，且中文语意不明。
  - 建议：改为「按各自的情况」或「在可能的范围内」。

- `175-137-38-70`｜文言语体｜片段「前夜后夜都致力于修习菩提分法而住」
  - 问题：「…而住」是 viharati 的旧译文言句式。
  - 建议：改为「前半夜后半夜都精勤修习菩提分法」。

- `175-137-38-70`｜文言语体｜片段「他依随顺的行道而行持圆满」
  - 问题：「依…而行持圆满」为半文半白句式。
  - 建议：改为「他按照随顺的行道完整地实践」。

- `175-138-2-7`｜标点符号使用错误｜片段「就也应当称为有学法了。」
  - 问题：这一句承 136-2-15「难道不是——」而来，巴利以 `vuccantīti?` 收尾，是反诘问句；译文用句号收尾，问答结构断裂，138-8-11「不能这样说」失去所答对象。
  - 建议：改为「就也应当称为有学法了吗？」

- `175-135-84-94`｜关键词语意不明确｜片段「果也依所应被知道的等等而分为几种」
  - 问题：`tathā` 承上文「因有三种」，指果也相应地有三种；「分为几种」把确定的三分改成不定数，读者无法与前半句对应。
  - 建议：改为「同样，果也依所应被知道的等等而有三种」。

- `175-135-239-255`｜关键词语意不明确｜片段「它们拆解（轮回的）转起」
  - 问题：`apacinanti` 的宾语靠括号补出，「拆解…转起」在中文里搭配不通，且与紧接着的「成为离积而行进、转起」中的「转起」撞词。
  - 建议：改为「它们不再积聚（轮回），所以叫做离积」。

- `175-139-105-126`｜代词指代不明确｜片段「也无法以它们为行境，所以它们无论如何都不被那些烦恼所限定」
  - 问题：句子的语法主语是「烦恼」，两个「它们」却都指出世间法，中间又出现「那些烦恼」，三个指称交错，读者难以辨认。
  - 建议：把主语改回法：「那些法即使对作限定的微细烦恼也不成为行境，所以无论如何都不被烦恼限定，已经超越了它们」。

- `175-135-165-173`｜整句逻辑表达不规范｜片段「所谓**前后两句的**，意思是这个三法中被第一句和第二句所摄取的那些意义」
  - 问题：`purimapacchimānaṃ` 修饰的是 `atthānaṃ`（意义），词条译作「前后两句的」，随即释义又说它指「那些意义」，同一句内自相牴牾。
  - 建议：词条改为「所谓**前后两者的**」。

### 🟦 suggestion

- `175-139-90-95`｜语言风格不统一｜片段「所以叫做**微小**」
  - 问题：`paritta` 在 139-15-30 译作「小法」，此处的释词结论却作「微小」，同段两名。
  - 建议：统一为「小」／「小法」，如「所以叫做**小（paritta）**」。

- `175-139-41-56`｜不常用术语编写注释或者百科｜片段「这样取作持业释」
  - 问题：原文只说「按“广大的果就是广大果”这样取义时」，并未出现 kammadhāraya（持业释）这一术语，属增译；虽然语法判断正确，但把注释性判断混入正文。
  - 建议：正文改为「这样来取义」，「持业释」放进脚注。

- `175-134-130-141`｜语言表达不够流畅｜片段「因为那个意思由于被说成“应当取这样的意思”，所以就是应当取的意思」
  - 问题：「因为…由于…所以」三重因果叠加，句子拖沓。
  - 建议：改为「那个意思既然被说成“应当取这样的意思”，所以就是应当取的意思」。

- `175-134-18-27`｜语言风格不统一｜片段「所谓**所指的那些法**」
  - 问题：词条 `yesaṃ` 是属格关系代词，译文以「所指的那些法」代之，而同句释义又落在「那些法的」，属格标记前后不一。
  - 建议：词条译为「所谓**那些…的**」，与释义的「那些法的」呼应。

- `175-134-18-27`｜语言表达不够流畅｜片段「作为第三句（第三类）而被说到的法」
  - 问题：`tatiyarāsi` 本义是「第三类（聚）」，译文以「第三句」为正文、「第三类」为夹注，主次颠倒；且 135-165-173 已用「第一句／第二句」对译 `paṭhamapada / dutiyapada`，两个不同的巴利词在中文里合成了「句」。
  - 建议：改为「作为第三类而被说到的法」。

- `175-135-62-69`｜语言表达不够流畅｜片段「正是凭这句作为标示特殊之处的依据的话」
  - 问题：「这句…的话」重复，且连用三个「的」，读来滞涩。
  - 建议：改为「正是凭这句标示了特殊之处的话」。

- `175-139-72-89`｜语言表达不够流畅｜片段「粗的烦恼在转起的时候」
  - 问题：`oḷārika` 单用「粗的」偏口语，且本句「…的时候，就像…一样，所以说…」三段式衔接松散。
  - 建议：改为「粗重的烦恼在转起时，就像在给众生划定…一样，所以说它们是“造成限量的”」。
