## 理由

**评估依据**
- 本次评估的是义注层（《法集论》义注 Dukanikkhepakathā），义注本身就是被评对象，所以“以义注定释义”这条标准用不上。这一层的释义标准应该是复注，但本次没有注入复注。
- 也没有注入 nissaya，词级核对只能直接对照巴利原文，没有缅文逐词释义作基准。
- 五种悭的业报、悭吝的特相这类义理，参照的是《清净道论》第二十二品等通行解释。
- 依据不足，信心指数相应压低。

**准确性**
- 整体取义可靠，这些难点都处理正确：
  - 法悭只发生在经典传承的法上；
  - “为护持法而不传授”和“为护持人而不传授”的区分；
  - aññaṃ byākaritvā 译作“自称已经证得究竟智”；
  - 结的两种断除次序；
  - “除了戒禁取”的理由。
- 结的断除表逐项核对，和原文一致。
- 疑点只有 2300 段的“破坏经典”一处。句中有两个动词 bhinditvā（破坏）和 āluḷissati（搅乱），宾语怎么分配有歧义，原文不一定是说“破坏经典”。归为 error 时信心偏低，建议拿到复注后再定。

**风格**
- 通篇是现代书面汉语，没有文言句式；标点全部是全角，没有 ASCII 引号，没有残留工作标记。
- 只有“此是真实的执着”这个被解释词里的“此”属于禁例表。它是被解释词，必须和本文同译，改的话要连同本文一起统稿。

**一致性**
- 术语前后统一：欲贪／瞋碍、入流道、嫉妒／悭吝、身系。
- 三个平行句 Yo hi bhikkhu … / Yo pana … / Yo pana … 的主语补法不统一（比丘／比丘／有人）。
- 本次没有注入本文层，这些被解释词没法核对是否和父层《法集论》本文逐字同译：
  - 悭吝的样态、悭吝的状态
  - 吝惜、吝啬
  - 紧缩
  - 心的紧抓不放

- 所以一致性分保守给出。

**文字游戏没有交代**
这一段有几处词源上的文字游戏，译文都没有加注。读者会看不出为什么这样解释：
- kaṭuka + añc → kaṭukañcuka
- kaṭacchu（饭勺）
- mā acchariya → macchariya

## 问题清单

### 🟧 error
- `96-2300-19-45`｜错译（修饰关系）｜片段「破坏师承传下来的经典，破坏其中细致微妙的法义」
  - 问题：原文 paveṇiāgataṃ tantiṃ … dhammantaraṃ bhinditvā āluḷissati 只有 bhinditvā、āluḷissati 两个动词。较通行的读法是：先破坏（混淆）细微的法义，再搅乱师承传下来的经典。译文把“破坏”同时加给经典和法义，多出一层“破坏经典”。
  - 建议：改成“这个人会破坏其中细致微妙的法义，把师承传下来的经典搅乱”。拿到复注后再核对宾语的归属。

### 🟨 warning
- `96-2301-66-95`｜关键词语意不明确，或二意场合没有注释｜片段「对容貌的称誉和德行的称誉所起的悭吝」
  - 问题：vaṇṇa 一词两义，既指容色（sarīravaṇṇa），也指称誉（guṇavaṇṇa）。本句换着用“称誉”“美好”，`96-2302-15-23` 又用“容色”，却没有注释。读者看不出“称誉悭”为什么会招来“相貌丑陋、没有好的容色”的果报。
  - 建议：在“称誉悭”首次出现处加脚注，说明 vaṇṇa 兼指容色和称誉。本句可改成“对容貌之美和德行之称誉所起的悭吝”。
- `96-2306-2-10`｜关键词语意不明确，或二意场合没有注释｜片段「所以叫作紧缩的人」
  - 问题：这句是按 kaṭuka（苦涩）+ añcati（弯曲）解释 kaṭukañcuka 的词源，“紧缩”只体现了后半，前面的“一阵苦涩”和名称对不上，读者看不出推导关系。
  - 建议：保留和本文同译的“紧缩”，加脚注说明巴利词由“苦涩”与“弯曲收缩”组成。
- `96-2309-14-25`｜文言语体｜片段「此是真实的执着」
  - 问题：“此”是禁例表里的文言代词。
  - 建议：改成“这是真实的执着”或“唯此真实的执着”。这是被解释词，必须和本文 idaṃsaccābhinivesa 的译名同步，由 harmonize 跨层一起改。
