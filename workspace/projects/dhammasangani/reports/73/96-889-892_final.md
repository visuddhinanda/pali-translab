## 理由

**评估基准的降级说明（重要）**：本批本身就是义注层（book 96，Aṭṭhasālinī 之 Suttantikadukamātikāpadavaṇṇanā），注入数据里**没有 nissaya**，也没有作为释义标准的更上层注释；同时**本文层（Dhammasaṅgaṇī 论母）的译文未注入**。因此本次评估只能以巴利原文与内部一致性为准，两条关键核对做不了：一是词级格/句法的 nissaya 比对，二是黑体被释词与本文层是否逐字同译（`vijjābhāgino` / `avijjābhāgino` / `bālā` / `paṇḍitā` / `kaṇhā` / `sukkā` / `tapanīyā` / `adhivacanā` / `nirutti` / `paññatti` 全部涉及）。信心指数据此下调；黑体词的跨层一致性建议在 harmonize 阶段另行核。

**准确性**：整体覆盖完整，44 句无漏译、无明显多译，数目类信息（八明、四无明、其余七/三）与原文一致，引文出处（saṃ. ni. 3.79 → 《相应部》3.79、dha. sa. 7 → 《法集论》7）处理得当，末句 `hetugocchake vuttanayeneva` 的回指也译准了。扣分集中在两处派生释义（nirutti-style 词源解说）的处理：`Bālesu ṭhitattā … tadupacārena bālā` 一组把"以所住处转称"的第一重派生直接写成了第二重派生的意思，使随后的 `Bālakarattā vā bālā` 变成同义反复，是本批最实质的错误；`vijjābhāge … vattantīti**pi** vijjābhāgino` 一组则因为把两重派生的结果都译成同一个"分有明"，让第二重推理在汉语里读不通。这类句子是义注的骨架（列举同一个词的多重成立方式），译名必须与推理分离，否则读者看不出注释在做什么。

**风格符合度**：主体是合格的现代书面汉语，没有"此中／故为／彼等／是故"一类禁例，也没有文言句式，标点全部全角、无 ASCII 引号（JSON 安全无问题），译文里没有残留任何工作标记。扣分主要来自"诸X"这个单音节文言复数标记的四处使用（"诸经藏二法""诸名称的路径""诸词的路径""诸施设的路径"），按 style.md 第一节总原则应改为"各种／这些"或直接省略；此外 `anajjhottharaṇabhāvena` 译作"笼罩不住烦恼的黑暗"用词偏离且施受关系易被误读。

**一致性**：句内与句间的平行结构处理得很整齐（明／无明两大段、黑／白、使人悔恼／不使人悔恼、三对"X 与 X 之路"的句式完全对称），"**X**的法"这一构词法全批统一，黑体只包住被释词、不含"的法"，这点是对的。扣分在术语层面：`adhivacana` 取"名称"，而同组的 `nirutti`、`paññatti` 取传统汉译"词""施设"，三对术语一半传统一半意译，风格不齐；夹注巴利原词的规则也只在 `kaṇhābhijāti`、`hetugocchaka` 上执行了，几个更需要夹注的法相术语反而没给。

## 问题清单

### 🟧 error

- `96-891-19-25`｜错译（词义、修饰关系）｜片段「所以叫做**使人成为愚者**的法」
  - 问题：本句给的是第一重派生——`Bālesu ṭhitattā yattha ṭhitā tadupacārena`，即"因为住在愚者身上，就以所住之处（愚者）的名称转称之，故名**愚**"。译作"使人成为愚者"是把下文 `bālakarattā`（使成为愚者）的第二重派生提前搬到了这里，理由与结论对不上，读起来是非推理（"因为它在愚者身上，就借地方来称呼它，所以它使人成为愚者"）。
  - 建议：结论改回被释词本身，如"就借它所在之处的名称来称呼，所以叫做**愚**（的法）"；"所在的地方"也宜改为"所在之处（即愚者）"，避免"地方"指人时的含糊。
- `96-891-26-29`｜错译（词义、修饰关系）｜片段「由于存在于智者身上，所以叫做**使人成为智者**的法」
  - 问题：同上，`Paṇḍitesu ṭhitattā paṇḍitā` 是"住于智者故（转称为）**智**"，不是"使人成为智者"。
  - 建议：改为"由于存在于智者身上（依同样的转称），所以叫做**智**（的法）"。
- `96-891-30-37`｜导致误解的表达｜片段「由于使人成为愚者，所以叫做使人成为愚者的法」
  - 问题：`Bālakarattā vā bālā` 的 `vā` 标示这是与前句并列的**另一重**派生。前两句既已把结论译成"使人成为愚者"，本句就成了"因为 A 所以 A"的同义反复，义注列举两重派生的用意在译文里完全消失。
  - 建议：前两句按上两条改回"愚／智"后，本句自然成立，可作"或者，由于它们使人成为愚者，所以叫做愚（的法）；由于使人成为智者，所以叫做智（的法）"。

### 🟨 warning

- `96-890-11-15`｜整句逻辑表达不规范｜片段「又因为存在于明的一分、也就是明的部分之中，所以也叫做分有明的法」
  - 问题：`vijjābhāge vijjākoṭṭhāse vattantīti**pi**` 是对同一个词 `vijjābhāgī` 的第二重拆解——把 `bhāga` 读作"部分"，即"存在于明这一部分中者"。译名固定作"分有明"后，"存在于明的部分之中→所以分有明"在汉语里推不出来，读者看不到这是另一种拆词。
  - 建议：第二重派生处改用扣住"分／部分"的译法（如"所以也叫做**有明分**的法"），或保留统一译名但补一句说明这是就 bhāga＝部分而言；两种拆法的落点必须在汉语里可辨。
- `96-890-62-66`｜整句逻辑表达不规范｜片段「又因为存在于无明的一分、也就是无明的部分之中，所以也叫做分有无明的法」
  - 问题：同 `96-890-11-15`，无明段的平行句同样丢失了第二重拆词。
  - 建议：与明段同步修改，保持两段对称。
- `96-891-2-11`｜关键词语意不明确｜片段「由于笼罩不住烦恼的黑暗，因而无力摧毁它」
  - 问题：`anajjhottharaṇabhāvena` 是"不能压伏／不能覆压（烦恼）"，译作"笼罩不住…黑暗"用词偏离，且"笼罩"是贬义动作，容易被读成"这些法本该笼罩黑暗却没做到"，施受关系反了；下句 `vajirūpamā` 用"毫无残余地摧毁"作对照，此处的对照点应是"压伏／摧毁"的程度差别。
  - 建议：改为"由于不能压伏烦恼的黑暗、无力将它摧毁"。
- `96-892-10-20`｜关键词语意不明确｜片段「这些就叫做**作为名称**的法」

  - 建议：统一为"增语"，首次出现夹注巴利原词；若坚持"名称"，则三对术语应作同一取向的处理，并把该决定登记进 `knowledge/terms.md`。

### 🟦 suggestion

- `96-890-5-10`｜该使用而没有使用术语标记｜片段「所以叫做**分有明**的法」
  - 问题：`vijjābhāgī`／`avijjābhāgī` 是本批的核心法相术语，且"分有明"并非通行译名（传统多作"明分"），首次出现未按 style.md 第二节夹注巴利原词，读者无从回查。
  - 建议：首次出现处夹注，如"**分有明**（vijjābhāgī）的法"；同理 `nirutti`、`paññatti`、`adhivacana` 首次出现也应夹注——目前只有 `kaṇhābhijāti`、`hetugocchaka` 给了夹注，规则执行不一致。
- `96-892-10-20`｜语言表达不够流畅｜片段「像“吉祥增长”“财富增长”这一类人的名字」
  - 问题：`Sirivaḍḍhako dhanavaḍḍhako` 是人名，本句的用意恰恰是"只取称呼本身、不问名实是否相符"。全部意译成汉语词组后，读者看到的是两个有意义的词，而不是两个名字，例证的力度被削弱（补的"这一类人的名字"是必要的补救，但仍不够醒目）。
  - 建议：改为音译加夹注，如"像“西利跋陀迦（Sirivaḍḍhaka，意为吉祥增长）”“陀那跋陀迦（Dhanavaḍḍhaka，意为财富增长）”这一类人名"。
- `96-890-57-61`｜语言风格不统一｜片段「同样，因为以相应的方式分有无明」
  - 问题：`Sampayogavasen**eva**` 的 `eva` 是限定"唯以相应"，与明段起首句 `sampayogavasena`（无 `eva`）恰成对照；译作"同样"只传达了段落衔接，丢了这层限定。
  - 建议：改为"这里则只是因为以相应的方式分有无明"或"仅仅因为以相应的方式…"。
- `96-892-59-76`｜不常用术语编写注释或者百科｜片段「“推度、寻、思惟”」
  - 问题：`takko vitakko saṅkappo` 引自《法集论》第 7 节对 vitakka 的同义词串，`takka` 通行译作"寻求"；"推度"可通，但与后面的"寻"并列时，读者易误以为是三个不同心所，而原文是同一心所的三个同义称呼。
  - 建议：改用"寻求、寻、思惟"，或在句末补一句说明这是同一法的数种称呼——这正是 `paññatti`（以种种方式令知）的例证所在。
