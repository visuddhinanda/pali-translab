## 理由

**基准可用性**：本次评估对象即义注层（book=96 Suttantikadukamātikāpadavaṇṇanā）本身，注入资料中**未提供 nissaya，也未提供上层复注**，因此无法按词级基准逐词核对格与句法角色，只能以巴利原文的构词/格位与义注体例内部一致性为准。这是信心指数压到 72 的主要原因：几条关于修饰关系的判断（如 `96-896-26-31` 的 `-bhūta`、`96-895-66-71` 的 `appaṭisaṅkhāne`）若有 nissaya 可对，结论会更硬。

**准确性**：本段是典型的论母逐词训释（`X-saṅkhāto Y-bhāvo → Z`、`…ti Z`），译文对这一体例把握稳定，绝大多数训释链（能立词 → 释义 → 被释术语）的归属正确，未见主谓宾判断错误或违背教理的句子，故无 fatal。扣分集中在三处：`96-896-26-31` 把 `diṭṭhipāripūribhūtaṃ ñāṇaṃ`（本身即是见之圆满的智）读成使役的“使见得以圆满的智”；`96-896-89-96` 的论母引文加译了“修习”并漏掉了 `ca`；`96-895-66-71` 的 `-aṭṭhena` 处理成“……的意思”，句子结构失衡。

**风格符合度**：整体是现代书面汉语，全角标点、无 ASCII 引号、无 `「」`、译文中无残留工作标记，符合硬约束。但仍有若干文言残留：“温和之人”“与之相违”“与之相应”的文言虚词“之”，以及“款接”这一今人几乎不用的文言词。另外“被称为……的那种……”句式在 20 余句中反复出现，虽忠实于 `-saṅkhāta`，但读感单调，属可提升项。

**一致性**：这是本段最弱的一维，且问题都出在**论母二法配对**上——配对词条必须同构，否则读者会误以为是两个不同范畴。`sampadā` 一处译“成就”（戒成就）、一处译“具足”（见具足）；`khaye ñāṇaṃ` 译作复合词式的“灭尽智”，配对的 `anuppāde ñāṇaṃ` 却译成介词式的“对于不生起的智”；连数字区间的连接号也一段用全角破折号、一段用连接号。这些不涉及理解错误，但必须在下一轮 harmonize 中统一。

**术语标记**：`knowledge/terms.md` 目前为空，本段出现的“悚惧”“思择力”“款接”等罕用法相词均未按 `style.md` 第二节夹注巴利原词，而“见（dassana）／见（diṭṭhi）”“相（nimitta）”“财物（āmisa）”处又做了夹注，标记策略前后不一致，列为 suggestion。

## 问题清单

### 🟧 error

- `96-896-89-96`｜错误多译｜片段「对于善法的修习不知足」
  - 问题：论母引文原文为 `Asantuṭṭhitā ca kusalesu dhammesu`，只有“对诸善法不知足”，“修习”是下文释义 `kusaladhammapūraṇe`（圆满善法）里的成分，被提前搬进了引文。引文与释义因此重复，训释关系被抹平。
  - 建议：引文回到字面“对于诸善法不知足”，把“圆满／修习”留在释义句里。

- `96-896-89-96`｜漏译｜片段「对于善法的修习不知足」
  - 问题：引文中的 `ca` 未译。同段相邻的 `96-896-81-88`、`96-896-97-106` 两条引文都译出了“以及”，此处独缺，论母条目的并列体例断裂。
  - 建议：补作“以及对于诸善法不知足”。

- `96-896-26-31`｜错译（词义、修饰关系）｜片段「使见得以圆满的那种智」
  - 问题：`diṭṭhipāripūribhūtaṃ ñāṇaṃ` 的 `-bhūta` 是“成为／即是”，指该智本身就是见的圆满，不是使役的“使见得以圆满”。译文引入了原文没有的能所关系。
  - 建议：改为“本身即是见之圆满的那种智”。

- `96-896-17-25` / `96-896-26-31`｜导致误解的表达｜片段「是戒的成就」／「是见的具足」
  - 问题：同一个 `sampadā` 在紧邻的一对论母词条中分别译成“成就”和“具足”，`sīlasampadā`／`diṭṭhisampadā` 是配对二法，用词分歧会让读者以为二者是不同性质的范畴。
  - 建议：二者统一（建议都用“具足”或都用“成就”），并同步更新 `knowledge/terms.md`。

- `96-896-113-119` / `96-896-120-130`｜导致误解的表达｜片段「灭尽智」／「对于不生起的智」
  - 问题：`Khaye ñāṇaṃ` 与 `Anuppāde ñāṇaṃ` 是配对二法，两条引文的处置方式不同——前者压缩成复合词“灭尽智”，后者展开成介词结构“对于不生起的智”，配对关系在译文里看不出来。
  - 建议：两条采用同一格式，如“于灭尽的智”／“于不生起的智”，或统一取传统译名“尽智”／“无生智”并在首次出现处夹注巴利原词。

### 🟨 warning

- `96-895-15-18`｜文言语体｜片段「温和之人」
  - 问题：文言虚词“之”，且与后面的“的状态”混用，半文半白。
  - 建议：改为“性情温和的人的状态”。

- `96-895-80-83`｜文言语体｜片段「与之相违的诸法」
  - 问题：文言虚词“之”。
  - 建议：改为“那些相违的诸法”。

- `96-895-80-83`｜代词指代不明确｜片段「与之相违的诸法」
  - 问题：`paccanīkadhamme` 指与“止”敌对的诸法（五盖等），译文“与之”的所指在句中没有先行词，读者无从判断“之”指什么。
  - 建议：点明所指，如“使那些与止相违的诸法止息”。

- `96-895-104-108`｜文言语体｜片段「与之相应的诸法」
  - 问题：同上，文言虚词“之”。
  - 建议：改为“与它相应的诸法”或直接“诸相应法”。

- `96-895-104-108`｜代词指代不明确｜片段「与之相应的诸法」
  - 问题：“之”的先行词缺失，`sampayutta` 的相应对象（心心所）未在译文中交代。
  - 建议：补出所指后再译。

- `96-895-23-34`｜文言语体｜片段「款接」
  - 问题：“款接”是文言词，现代读者难以理解，且作为论母词条会被反复引用。
  - 建议：改用“亲切款待”或“摄受招待”一类现代词，并在首次出现处夹注 `paṭisanthāra`。

- `96-895-23-34`｜关键词语意不明确｜片段「不留缝隙」
  - 问题：`chidda` 在此指人际交往上的破绽、隔阂，“不留缝隙”字面化，语意含糊，读者会往“物理缝隙”上理解。
  - 建议：改为“不让自己与他人之间产生隔阂（破绽）”。

- `96-895-66-71`｜整句逻辑表达不规范｜片段「由于不为不思择所动摇的意思」
  - 问题：`-aṭṭhena`（以……之义）被处理成“由于……的意思”，“由于”与“的意思”搭配不成句；同时 `appaṭisaṅkhāne` 是处格（在不思择方面），译作“不为……所动摇”的施动者读法缺乏依据（无 nissaya 可核，故只按汉语与格位判断）。
  - 建议：改为“就在不思择的场合也不动摇这一意义而言，这种被称为思择的力就是思择力”。

- `96-896-51-67`｜整句逻辑表达不规范｜片段「也就是持有适当见解、持有善好见解的人」
  - 问题：引文中的 `yathādiṭṭhissa` 已先行译成“持有相应见解的人”，而义注正是用 `anurūpadiṭṭhissa`（相应见）来解释它，于是译文变成“持有相应见解的人，也就是持有适当见解……的人”，训释成了同义反复，读者看不出义注在解释什么。
  - 建议：引文取字面（如“依其所见者所作的精勤”），把“相应见／善好见”留给释义句。

- `96-895-2-4` / `96-896-2-4`｜标点符号使用错误｜片段「124—134。」
  - 问题：同类的段号区间，`96-895-2-4` 用全角破折号“—”，`96-896-2-4` 用连接号“–”（片段「135–142。」），体例不统一，且破折号在中文里不表数字区间。
  - 建议：统一为“124～134”或“124-134”一种写法。

### 🟦 suggestion

- `96-895-5-7`｜语言表达不够流畅｜片段「率直的状态」
  - 问题：“率直”在现代汉语中偏日源、也偏口语，用来解释论母词条“正直”不够贴切。
  - 建议：改为“正直坦率的状态就是正直（ajjava）”，或“不歪曲的状态”。

- `96-895-19-22`｜复杂的嵌套句整句语言逻辑理解困难｜片段「被称为令人欢喜的柔和的那种和蔼的状态」
  - 问题：三重定语连续叠加（令人欢喜的／柔和的／那种和蔼的），中间没有停顿，读者难以切分。
  - 建议：拆句，如“和蔼的状态，也就是被称为令人欢喜的柔和，就是言语亲切”。

- `96-895-90-99`｜复杂的嵌套句整句语言逻辑理解困难｜片段「止本身把握了那一行相」
  - 问题：`samathova` 作主语后连接“把握行相—成为止之相—故名止相”三层关系，一句到底，逻辑跳转略陡。
  - 建议：在“成为”前断句，明确“正因为如此，所以叫作止相”。

- `96-896-68-75`｜该使用而没有使用术语标记｜片段「悚惧」
  - 问题：`saṃvega` 属罕用法相术语，且本段后续 `saṃvejaniyaṭṭhāna`、`saṃviggassa` 三条连续依赖它，首次出现未夹注巴利原词，与同段“见（dassana）”“相（nimitta）”的处理不一致。
  - 建议：首次出现处作“悚惧（saṃvega）”，其后只用汉译，并登记进 `knowledge/terms.md`。

- `96-896-97-106`｜语言风格不统一｜片段「在精勤上不退转、不畏缩」
  - 问题：引文把 `appaṭivānitā` 译作“不退缩”，释义里 `anosakkanatā` 又译作“不畏缩”，两词读感几乎相同，`anivattanatā`／`anosakkanatā` 的区别（不折返／不退缩）没有拉开。
  - 建议：引文用“不退转”，释义作“不折返、不退缩”。

- 全段｜语言风格不统一
  - 问题：`-saṅkhāta` 一律译为“被称为……的那种……”，在 895、896 两段中出现二十余次，句式高度重复。
  - 建议：视上下文交替使用“即……”“所谓……”“也就是……”，保留训释关系但减少同型句堆叠。
