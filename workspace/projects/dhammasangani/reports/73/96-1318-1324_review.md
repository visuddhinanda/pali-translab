# Review — 96:1318-1324（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层本文+定稿译文（73:390-450）✅／现有译文 ✅／**nissaya ❌ 未提供**／**复注 ❌ 未提供**。
> 本层是义注（Atthasālinī），下列判定全部依据巴利原文与父层定稿译文；词级形态无 nissaya 可比对，格与句法类问题的把握度相应降低。

## 一、被解释词与父层对齐（首查项）

对照父层 `73-403`（精进根）与 `73-404`（念根）定稿译文，本 chunk 全部黑体被解释词**逐字一致，无一处断链**：

- §1318–1323（精进根）：属于心的 / 精进的发起 / 奋出 / 奋励 / 策励 / 努力 / 奋发 / 加倍奋发 / 毅力 / 坚忍 / 不松懈的奋励 / 不放弃意欲 / 不卸下重担 / 坚定地担起重担 / 精进根 / 精进力 / 正精进 ✅
- §1324（念根）：念 / 随念 / 追念 / 忆念的状态 / 忆持的状态 / 不浮泛而深入所缘的状态 / 不忘失的状态 / 念根 / 念力 / 正念 ✅

黑体词本身不必改。**下面所有问题都出在非黑体部分与黑体词的呼应上**。

## 二、跨段一致性

1. **`ārambha` 六义的引证链整体断裂（必改，本 chunk 最重要的问题）**
   §1318-83-97 立了六义「业、犯、行为、精进、伤害、毁损」，§1319–1321 逐条举经证。但六处引文里的 `ārambha` 派生词分别译成了六个互不相干的中文——造作（§1319-1320）／犯了戒（§1321-11）／操办（§1321-39）／努力吧（§1321-70）／杀生（§1321-92）／损害（§1321-114）——读者完全看不出这些引文举的是**同一个词**，整段词义辨析因此失效。
   建议：每处引文在对应汉词后加圆括号夹注原形（ārambhapaccayā / ārambhati / mahārambhā / ārambhatha / ārabhanti / samārambhā），并让该汉词与后句判词同字（详见各段条目）。

2. **「努力」被两个巴利词占用（必改）**
   `vāyāma` = 努力，是父层 `73-403` 锁定的黑体译法（§1321-179、§1323-132 均用）。§1321-70-91 却把 `ārambhatha` 也译成「努力吧」，同一 chunk 内直接撞车，且恰好撞在「此处 ārambha 作精进解」这条举证上。

3. **「策励」被两个巴利词占用**
   `uyyāma` = 策励（父层锁定，§1321-175 黑体），而 §1323-121-125 的 `paggahalakkhaṇa` 也译作「策励这一相」。父层自身即有此碰撞（`73-446` 定 `paggāho` = 策励），本层无权改黑体，但 §1323-121 不是被解释词，可加夹注区分。**该冲突应记入术语报告，留待 harmonize 或父层修订统一处理。**

4. **`cetasika` 一词三译（必改）**
   §1318-2-14 黑体作「属于心的」，§1318-15-33 同词作「心里的」，§1318-34-73 与之对举的 `kāyika` 又在「身体上的／属于身体的」之间摇摆。这一段的全部论证就是「名为 kāyika 而实无 kāyika，唯是 cetasika」，术语一旦浮动，论证读不通。

5. **`dhura` 在譬喻中换词**
   §1323-61-87「不卸下**重担**」→ §1323-88-120 譬喻里作「车轭」→ 结句又回到「重担」。譬喻正是为解释 `dhura` 而设，中途换词会让读者以为在讲别的东西。建议譬喻首次出现处写「车轭（dhura，即上文的“重担”）」。

## 三、逐段

### §1318

- **96-1318-15-33**
  - **问题**：术语不一致（必改）——`cetasikaṃ vīriyaṃ` 译「心里的精进」，与本句上文黑体 `cetasiko`「属于心的」脱节。
  - **建议**：改「凡是属于心的精进」；配套把 `kāyikaṃ` 改为「属于身的精进」，与「属于心的」构成对举。

- **96-1318-34-73**
  - **问题**：承上，「被叫做“身体上的”」「真正属于身体的精进」两处用词仍与上句不齐。
  - **建议**：统一为「被叫做“属于身的”」「像身识那样真正属于身的精进」。

- **96-1318-2-14**
  - **问题**：夹注体例。`style.md` 规定圆括号夹注放**巴利原词**，此处「属于心的（心所）」放的是汉语同义词。
  - **建议**：「是为了表明精进必定是属于心的（cetasika，即心所法）」。

### §1319 / §1320

- **96-1319-2-11、96-1320-2-19**
  - **问题**：术语链断裂（必改）——偈中 `ārambha` 译「造作」，紧接的 §1321-2-10 判词却说「业被称为“发起”」。读者在偈里找不到「发起」，举证落空。
  - **建议**：偈文改「全都以发起（ārambha）为缘」「由于种种发起的息灭」；若坚持保留「造作」的可读性，至少加夹注（ārambha），并把 §1321-2-10 改为「这里的“造作”（ārambha）指的就是业」。

### §1321

- **96-1321-70-91**
  - **问题**：术语撞车（必改）——`Ārambhatha` 译「努力吧」，占用了 `vāyāma` 的固定译法「努力」；且此句是「ārambha 作精进解」的唯一证据，用「努力」反而指向 vāyāma。
  - **建议**：「奋起吧（ārambhatha），奋出吧，投身于佛陀的教法吧」。

- **96-1321-114-142**
  - **问题**：`samārambha` 译「损害」，而本条判词是「毁损」（`vikopana`），二字不一。
  - **建议**：「他远离对种子类和植物类的毁损（samārambha）」——与判词同字。

- **96-1321-39-69**
  - **问题**：`mahārambhā` 译「有大操办」，判词是「行为（kiriyā）」。语义方向对，但读者仍看不出这是 ārambha。
  - **建议**：加夹注「大祭祀有大操办（mahārambha）」。另「它们没有大果报」建议改「都没有大果报」，句子更顺。

- **96-1321-169-174**
  - **问题**：`paraṃ paraṃ ṭhānaṃ akkamanavasena` 译「一步步迈向更高的**地位**」。`ṭhāna` 此处是「处所／阶位」，中文「地位」易被读成社会身分。
  - **建议**：「因为是一步步跨向更前面的位置」。

- **96-1321-191-199**
  - **问题**：语义重复——「使善的相续不间断地运转下去，**能够持住善的相续**」把主句宾语说了两遍；原文结构是「以执持心心所故，或以不间断令转起故，**执持善的相续**」。
  - **建议**：「因为它执持心和心所，或者因为它使之不间断地运转，从而执持善的相续，所以叫**坚忍**。」

- **96-1321-11-38**
  - **问题**：文体（`style.md` 第一节）——「心怀追悔」属半文半白。
  - **建议**：「他既犯了戒（ārambhati），又心生悔恨」。

### §1322

- **96-1322-2-38**
  - **问题**：`avaṭṭhitikāritāya` 译「因为能使**心**稳固地安住」，「心」为原文所无的补出成分（`style.md` 六：不擅自补足）。此处无 nissaya 可核，暂列为存疑。
  - **建议**：「因为它令〔心心所〕稳固地安住」，或径作「因为能使之稳固安住」。

### §1323

- **96-1323-121-125**
  - **问题**：「在**策励**这一相上」与 §1321-175 黑体的 `uyyāma`「策励」同字异词（见跨段一致性 3）。
  - **建议**：本层改「在策励（paggaha）这一相上」加夹注；同时把 uyyāma / paggāha 同译「策励」这一父层冲突写进术语报告。

- **96-1323-88-120**
  - **问题**：`dhura` 中途换译「车轭」（见跨段一致性 5）。
  - **建议**：「也要担起车轭（dhura，即上文的“重担”）」，结句「把重担扛起来、撑住它」保持不变。

- **96-1323-2-55**
  - **问题**：OCR / 原文疑问——黑体标记把行末分号一并包入（`**asithilaparakkamatā** **;**`）。译文已按正常「；」处理，**记下不必改**。

### §1324

- **96-1324-18-24**
  - **问题**：误译且自相矛盾（必改）——「因为是像**迎面走上去**那样地忆念，即**回头去**忆念」。`abhimukhaṃ gantvā viya` 与「回头」方向正相反；`paṭi-` 在此取「相向、对着」义（正是下句 §1324-25-28 所说「只是加前缀扩充」的那个前缀），不是「回返」。
  - **建议**：「因为是像迎面走上去那样地忆念，即相向而忆念，所以叫**追念**。」（黑体「追念」不动。）

- **96-1324-51-54**
  - **问题**：`sutapariyatti` 译「所听闻的圣典」。`pariyatti` 指所学得的教法／经教，「圣典」偏指书册，且与本层他处「教法」不齐（§1321-70「佛陀的教法」）。
  - **建议**：「因为能忆持所听闻的教法」。
