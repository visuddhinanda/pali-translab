## 跨段一致性

- **parikissati**：偈颂 §809、§819 以及引句 §813-2-5、§816-55-68 都译作「受苦」（“就像愚人一样受苦”）。但 §813-6-16 起的同义词链 kissati / parikissati / parikilissati 译作「受苦 / 备受苦恼 / 饱受折磨」，偈颂里的 parikissati 在释文中对应的是「备受苦恼」，读者看到的却是「受苦」配 kissati，对应关系断了。义注 118-1055-108-113 同样用 **Parikissatī** = 「备受苦恼」，与 118-1052-2-18 的「就像愚人一样受苦」自相矛盾。
  → 建议偈颂和全部引句统一为「就像愚人一样备受苦恼」（§809 / §813-2-5 / §816-55-68 / §819），义注 118-1052-2-18 的被解释词随之改。依据：本文自身的同义词链，以及义注 118-1055 的逐词释义。
- **adhiṭṭhito**：§808、§811 全部、§818 统一译作「立志」，用词前后一致，但词义有问题，见 §808。如果要改，四处要同时改。

## §807 句 149-807-2-5
- **问题**：漏译。本行没有 zh，偈号「55.」没有写入。
- **建议**：补写「55.」。

## §808 句 149-808-2-16
- **问题**：取义偏窄。adhiṭṭhito 是过去分词，意思是「已受持、已奉行」，nissaya 释作 `အဓိဋ္ဌိတော= ဆောက်တည်သော`（受持、奉行）。本文 §811 的自释也是在描述已经实际出家、独居林野，不是只发了志愿。「立志」只表达意愿，和自释对不上。
- **建议**：改为「奉行独行」或「过着独行的生活」，§811、§818 同步改。
- **备注（分歧，不改）**：nissaya 把 ekaccariyaṃ 释作 `မြတ်သောအကျင့်`（殊胜的行持）。本文 §811 自释为出家、离群独住，而且有异读 ekacariyaṃ（sī. syā.），所以「独行」有据，保留。

## §810 句 149-810-13-37
- **问题**：风格。「他是智者、聪明、有智慧……的人」把名词「智者」和一串形容词并列，句子不顺。
- **建议**：改为「他是有智慧、聪明、明慧、多闻、言辞精妙、辩才出众的人」。

## §810 句 149-810-38-47
- **问题**：风格（半文半白）。「为人所知、为人所识」用了文言被动「为…所」。
- **建议**：改为「他就这样为人知晓、广为人知、被人公认」，保留 ñāto / paññāto / samaññāto 的递进。

## §811 句 149-811-6-15
- **问题**：用词。「离开群众」里的「群众」在现代汉语中是政治色彩明显的词（「人民群众」），违反 style.md 第六节。gaṇa 在这里指同伴、徒众，nissaya 释作 `ဂိုဏ်းအခြွေအရံကိုစွန့်`（舍弃群伴随从）。
- **建议**：改为「从远离人群来说」或「从舍离群伴来说」，§811-32-36、§811-37-54 同步改。

## §811 句 149-811-37-54
- **问题**：省略处理。「住在」对应的动词（senāsanāni paṭisevati）在 …pe… 省掉的部分里，译文把它提到「乃至」之前，看起来像是本句原文就有。
- **建议**：改为「他这样出家以后，独自……偏远的林野住处……乃至……」，或者保留现译但不再补其他成分。属于轻微问题。

## §812 句 149-812-8-20
- **问题**：风格（文言）。「村野之法」用了文言虚词「之」。
- **建议**：改为「粗俗的村野行为」或「鄙俗的行为」。

## §812 句 149-812-27-54
- **问题**：术语误译。sikkhaṃ paccakkhāya 的 sikkhā 指学（三学），nissaya 释作 `သိက္ခံ= အဓိသီလ အစရှိသောသိက္ခာကို`（增上戒等学）。「学处」是 sikkhāpada（具体条文），把范围译窄了。
- **建议**：改为「舍弃了佛、法、僧和学」，律藏惯用的说法是「舍戒」。
- **问题**：冗余。「还俗回到低下的生活」里，「还俗」和「回到低下的生活」意思重复。
- **建议**：改为「退回到低下的在家生活」。
- **问题**：同义词链区分度弱。yutto / payutto / āyutto / samāyutto 译作「沉溺 / 投身 / 耽溺 / 深陷」，前后两个都带「溺」，层次不清。nissaya（按 sī. 本有 saṃyutto）的释义是「结合 / 特别结合 / 反复结合 / 极度结合」。
- **建议**：可调为「沉溺于淫欲，投身其中，反复耽溺，深陷其中」。属于轻微问题。

## §813 句 149-813-46-143
- **问题**：取义（义注）。sunakhehipi khādāpenti 是使役动词，意思是「让狗吃」。**义注**：katipayāni divasāni āhāraṃ adatvā chātasunakhehi khādāpenti … aṭṭhisaṅkhalikameva karonti（几天不喂狗，让饿狗吃他，吃到只剩骨架）。「咬」比原意弱。
- **建议**：改为「让狗吃他」，义注 118-1055-87-95 的被解释词同步改。
- **问题**（可选）：kārenti 是使役动词，义注专门说明是「听命于国王的人」施刑。现译「施加」可以接受，如果改成「让人施以种种刑罚」更贴合义注。但改动会牵连义注被解释词，由统稿时决定。

## §814 句 149-814-2-155
- **问题**：译名。「爪哇」是现代地名，等于替原文断定了 java 就是今天的爪哇岛。按 style.md，罕见地名应当音译。
- **建议**：改为传统音译「阇婆」。
- **问题**：取义。daripathaṃ 译作「岩洞道」。nissaya 释作 `ခြောက်ထောင်ကြား`（峡谷、山涧之间），dari 在这里指岩缝或峡谷，不是洞穴。
- **建议**：改为「峡谷道」。
- **问题**：原文存疑。「saramataṃ gaṇaṃ」两个宾格连用，译文合成了一个译名「萨拉玛达迦那」。按义注「二十四个词」点数，这里确实应算一项，但文本可能有讹误（nissaya 也重复了一行）。
- **建议**：现译可以保留，存疑记入 known-issues，见下节。

## §815 句 149-815-2-10
- **问题**：轻微漏译。alābhamūlakampi 的 -pi（「也」）没有译出。**义注**：avindanamūlakampi … paṭilabhati（义注 118-1058 译作「也会遭受」）。
- **建议**：不改。此句是义注被解释词，而且义注已经补出「也」，改动的收益不大。

## OCR / 原文疑问
- §814「saramataṃ gaṇaṃ gacchati」：疑有讹误，两个宾格连用，nissaya 也重出一行。记下，不改。
