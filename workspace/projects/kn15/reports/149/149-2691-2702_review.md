## 被解释词逐字核对（父层 = 义注 book 118）

义注黑体的被解释词与本文译法逐字相同的有：他应当有怎样的言语 / 舍弃妄语 / 说真实的话 / 坚守真实 / 诚实可靠 / 值得信赖 / 不欺骗世人 / 舍弃离间语 / 来离间这些人 / 他使不和的人重归于好 / 使和睦的人更加和睦 / 喜爱和合 / 乐于和合 / 欣喜于和合 / 说促成和合的话 / 没有过失 / 悦耳 / 可爱 / 深入人心 / 文雅 / 为众人所喜爱 / 为众人所欢喜 / 说合时的话 / 真实的话 / 有意义的话 / 合乎法的话 / 合乎律的话 / 值得珍藏的话 / 适时而说 / 有理有据 / 有分寸 / 有意义 / 四种语善行 / 具备 / 说远离四种过失的话 / 什么是非行境 / 行境 / 非行境 / 常去妓女那里 / 寡妇 / 大龄未嫁的女子 / 黄门 / 比丘尼 / 酒馆 / 与国王……混在一起 / 国王 / 大臣 / 外道 / 外道弟子 / 以不相宜的交往 / 或者，有些人家 / 没有信心 / 不生净信 / 辱骂诃责 / 不希望他们得到利益 / 不希望他们得到好处 / 不希望他们安乐 / 不希望他们安稳离轭 / 这样的人家 / 亲近 / 结交 / 侍奉 / 这叫做 / 比丘们，不要在非行境……游行 / 他人的领域 / 就会找到 / 魔罗 / 机会 / 不常去妓女那里。

这些都**无不符**。不过下面「跨段一致性」第 1、2 条是**两个不同巴利词共用了同一译法**，对应关系因此有歧义。改的时候两层要同步改。

## 跨段一致性

1. **saccavādī / bhūtavādī 撞译**：§2694 句 20-33 把 saccavādī 译作「说真实的话」，句 99-118 把 bhūtavādī 译作「真实的话」，读者分不出这是两个词。
   - 依据：**义注**：bhūtaṃ tacchaṃ sabhāvameva vadati（说确实、真切、如实的事）。
   - 建议：bhūtavādī 改为「说如实的话」。义注 118-1746-11-16 的黑体同步改。
2. **atthavādī / atthasaṃhitaṃ 撞译，且 atthavādī 取义偏离义注**：§2694 句 99-118 中，atthavādī 译「有意义的话」，atthasaṃhitaṃ 译「有意义」。
   - 依据：**义注**：diṭṭhadhammikasamparāyikatthasannissitameva katvā vadati。这里的 attha 是现世、来世的**利益**，不是「意义」。atthasaṃhitaṃ 义注解作「意义丰富、无法穷尽」，才是「意义」。
   - 建议：atthavādī 改为「说有益的话」，atthasaṃhitaṃ 保留「有意义」。义注 118-1746-17-22 黑体、118-1746-100-121「那位说有意义的话的人」同步改为「说有益的话」。
3. **saṃvara / saṃvuta / rakkhati / gutta / paṭiyatta 译法交叉**：
   - §2694 句 169-180：paṭiyatto「防护」、gutto「守护」、rakkhito「保护」、saṃvuto「约束」。
   - §2697、§2702：asaṃvuto / saṃvuto 译「不加约束 / 有约束」。
   - §2698：asaṃvutaṃ「不防护」，saṃvarāya、saṃvaraṃ「防护」，rakkhati「守护」。
   - 问题：saṃvuta 一词出现「约束」「防护」两译；「防护」又同时用于 paṭiyatto 和 saṃvara；「守护」同时用于 gutto 和 rakkhati。
   - 建议：saṃvara / saṃvuta 统一为「防护」（根防护的传统译法）；rakkhati / rakkhito 统一为「守护」。§2694 七词序列可改为：克制、自制、戒备（paṭiyatto）、守卫（gutto）、保护（gopito）、守护（rakkhito）、防护（saṃvuto）。§2697 / §2702 相应改为「不加防护地行走 / 有防护地行走」。
4. **vacīpārisuddhi**：§2694 句 7-16、17-19、169-180 译「言语的清净」，句 181-189 译「言语清净」。建议统一为「言语的清净」。

## §2694 句 149-2694-20-33（theto，涉及两层）
- **问题**：义注释义 — **义注**：theto ti thiro, thirakatho（稳固，说话稳固；刀砍头也不说两样话）。「诚实可靠」把意思推向了 sacca / paccayika，还和紧接着的「值得信赖」（paccayiko）意思重叠。
- **建议**：改为「说话稳固」或「言语坚定」，义注 118-1736-2-8、118-1736-40-43 同步改。本条不算硬错，可交 harmonize 定夺。

## §2694 句 149-2694-181-189
- **问题**：句法 — Niddesa 套语「…ti – X」的意思是「『…』，这就是 X 的意思」。译成「所以说」，读起来像是由前因推出这句偈，逻辑倒了。
- **建议**：改为「‘他应当具备这样的言语的清净’——这就是“他应当有怎样的言语”。」（「言语的清净」同时按跨段一致性第 4 条统一。）

## §2698 句 149-2698-11-41
- **问题**：语序 — 原文是 yatvādhikaraṇamenaṃ … pe … manindriyaṃ asaṃvutaṃ viharantaṃ，省略号前后应是「由于他……乃至……对意根不加防护而住」。现译「因为不防护……乃至……意根」把「不防护」挪到了省略号前面，被省略的那一大段好像也被「不防护」管着了。
- **建议**：改为「由于他……乃至……意根不加防护而住，贪欲、忧恼这些恶的不善法就会侵入他」。

## §2701 句 149-2701-41-69
- **问题**：误译 — isivātapaṭivātāni 的意思是「仙人往来带起的风吹拂其中」，形容出家人不断进出这户人家。「仙人往来如风」多出了原文没有的比喻（「如风」），把风说成了往来的方式。
- **建议**：改为「仙人往来，处处吹拂着他们带起的风」，或者「充满仙人往来的气息」。

## §2697 句 149-2697-2-68
- **问题**：译法不顺 — antarāpaṇaṃ olokento 译「看着店铺之间」，现代读者不知所指。antarāpaṇa 指市集、商铺街。
- **建议**：改为「看着市集」。

## §2700 句 149-2700-9-18 / 19-32（涉及两层）
- **问题**：风格 — carati 译「游行」，现代汉语里「游行」主要指示威游行、巡游，容易误解。
- **建议**：改为「走动」或「出入」（如「不要在非行境、在他人的领域中走动」）。义注 118-1758-2-11、118-1758-16-22 的黑体同步改。属建议项，可交 harmonize 定夺。

## §2694 句 149-2694-119-139
- **问题**：术语 — tiracchānakathā 译「畜生论」是传统译法，但一般读者会理解成「谈论畜生的话」，其实指的是无益于出离的低俗闲谈。
- **建议**：保留「畜生论」并在首次出现处加夹注 tiracchānakathā，或改为「低俗闲谈（tiracchānakathā）」。术语表未登记，定案后补进 `terms.md`。
