# Review — 149:293-298（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§293 2-11 的 nissaya 缺 yapento / yāpento 两词）／义注 ✅（book 118 §619、§700–702 与本 chunk 相关；注入数据里义注行的 `layer` 被标成 `mula`，§620–699 与本 chunk 无关）
> 父层：本书是《大义释》，它解释的是《经集·洞窟八偈经》。经集原文与译文**没有注入**，所以被解释词只能和本 chunk 内引出的偈颂（§296–297）对照，没能和经集译文核对。

## 被解释词核对

**本文黑体与本 chunk 内偈颂对照**：
- 行 → 偈颂“不放逸地行”，一致。
- 不放逸 → 一致。
- 不希求此世与他世 → 一致。
- 拔除了箭，不放逸地行 → 一致。

**与子层（义注）黑体对照**：
- **saññaṃ pariññā（必改）**：§296 译“彻底了知想”，义注 118-619 的黑体译“以遍知了知想”，对应关系断了。
  - 建议本文改为“遍知想”，理由有三：
    - 依 **义注**：tīhi pariññāhi parijānitvā（用三种遍知来遍知）；
    - 依 nissaya：`ပရိညာ= သုံးပါးသောပရိညာတို့ဖြင့်သိ၍`（以三种遍知知道之后）；
    - §293 的 parijāneyyaṃ 也译“遍知”。
  - 义注黑体同步改为“**遍知想**”。
- **sakattabhāva / parattabhāva**：义注 118-702 的黑体“他人的身心存在”是照搬本文的误译，见 §294 句 149-294-2-14。本文改后，义注黑体与 118-619 的正文要同步改。
- **§294 72-99 的六个词**：去处 / 投生 / 结生 / 存在 / 轮回 / 轮转，与义注 118-702 黑体逐字一致。但“存在”“去处”建议改译，见 §294 句 149-294-72-99。改的话，两层一起改。
- **§293 12-22 与 23-65 的整组术语**：认真地做……不放逸，与义注 118-701 黑体逐字一致。

## 跨段一致性
- **pariññā / parijānāti**：§293 句 138-188 译“遍知”，§296 译“彻底了知” → 统一为“遍知”。依据是义注“三种遍知”，以及 §293 已经这样用。
- **para-**：§294 句 2-14 和 15-24 把 parattabhāva、pararūpa… 译成“他人的”，同一段里 paraloka 又译“他世” → 统一为“他世的”。依据是 **义注**：paraloke attabhāvaṃ / paraloke pañcakkhandhe。
- **bhava**：§294 句 72-99 译“存在”。义注同一处的释义用“业有”，前句的 kāmadhātu 释为“欲有”，118-625 有“有暴流” → 建议统一为术语“有”。
- **sacchikaroti**：§293 句 138-188 译“证悟”。传统术语是“作证”（义注 118-671、693 也作“作证”） → 建议改“作证”。属低优先级，义注内部也不统一，留给 harmonize 一并处理。
- **章末题名**：§298 作“《洞窟八偈经》的义释”，义注 118-704 作“《洞窟八偈经》义释” → 建议去掉“的”，两层统一。

## §293 句 149-293-2-11
- **问题**：取义偏窄。caranto 译“行走”，把义项限成了身体移动。
  - nissaya：`စရန္တော= ကျင့်သောသူသည်` 意思是“修行、行持的人”。
  - 偈颂与义注 118-619 都只作“行”，义注的意思是“不放逸地修行”。
- **建议**：改为“行持”，或者直接译“行”，与偈颂保持一致。其余几个词与 nissaya 相符，不用改。

## §293 句 149-293-23-65
- **问题 1**：义注取义。yo tattha 的 tattha 被译成“在这件事上”，后面又接“对各种善法”，处所说了两遍。
  - **义注**（118-701）：yo tesu kusaladhammesu… 意思是“对那些善法”。
  - nissaya：`တတ္ထ= ထိုဓမ္မတို့၌`（在那些法上）。
  - 也就是说，tattha 指的就是那些善法，不是“这件事”。
- **建议**：改为“对那些善法所具有的意欲、精进……”。义注 118-701 的黑体“在这件事上的意欲、精进”要同步改。
- **问题 2**：风格。句尾“……专注修习、不放逸，就是不放逸”同词连用，读起来像同义反复。
  - 原文列举到 appamādo 为止，结论是隐含的，nissaya 只补了 `ဟောတိ`。
- **建议**：改为“……专注修习、不放逸——这就是‘不放逸’的意思”，或者用破折号把结论隔开。句 91-137 和 138-188 是同一个句式，三处要一起改。
- **存疑**：tattha tattha paññāya anuggaṇheyyaṃ 译“用智慧在各处护持”。
  - nissaya 把 tattha tattha 读作“在各相关善法上”。
  - nissaya 对 anuggaṇheyyaṃ 前后释义不一：本句作“抉择、省察”（`စူးစမ်းဆင်ခြင်`），句 66-90 作“扶持、增益”（`ချီးမြှောက်`）。
  - “护持”符合词典义，可以保留，但置信度应当压低；“在各处”建议改为“在各种情况中”。

## §294 句 149-294-2-14
- **问题**：误译，与义注相悖。parattabhāvaṃ 译“他人的身心存在”。
  - **义注**（118-702）：Parattabhāvan ti paraloke attabhāvaṃ，意思是“（自己）在他世的身心存在”。
  - nissaya：`ပရတ္တဘာဝံ= ပရလောက၌အတ္တဘောဖြစ်သော`（在他世的自体），与义注一致。
  - 现译把“此世 / 他世”的对立变成了“自己 / 他人”的对立。
- **建议**：改为“不希求他世，也就是他世的身心存在”。另外，黑体建议整体覆盖“**不希求此世与他世**”，因为原文黑体是连续的三个词，不必拆开加粗。

## §294 句 149-294-15-24
- **问题**：误译，与上一句同源。pararūpavedanāsaññāsaṅkhāraviññāṇaṃ 译“他人的色、受、想、行、识”。
  - **义注**（118-702）：pararūpavedanādayo ca paraloke pañcakkhandhe，意思是“在他世的五蕴”。
- **建议**：改为“他世的色、受、想、行、识”。

## §294 句 149-294-72-99
- **问题**：术语。
  - bhava 译“存在”，与“有”这一术语体系脱节。**义注**：bhavaṃ vā ti kammabhavavasena（就业有而言）。
  - gati 译“去处”。**义注**作“五趣”，传统译法是“趣”。
- **建议**：bhava 改为“有”，gati 改为“趣”。义注 118-702 的黑体要同步改。其余词与义注、nissaya 相符。

## §296 句 149-296-2-13
- **问题 1**：被解释词与义注断开，pariññā 前后译法不一致，见上文“被解释词核对”。
- **建议 1**：前半句改为“遍知想，就能渡过暴流”。
- **问题 2**：术语撞车。pariggaha 译“执取”，而 upādāna 在义注中译“取”，gahaṇa 在 118-651 中译“执取”，读者分不清。
  - **义注**：taṇhādiṭṭhipariggahesu，指渴爱与见的执取、占有。
- **建议 2**：改为“摄取”或“占有”，比如“牟尼不被种种摄取所染污”。是否改由术语表定案；不改的话，至少要在报告里登记这次撞车。
