## 被解释词对照（本文 ↔ 义注黑体）

逐条比对义注黑体与本文译法，除下面 §2293 的 aniccatāya 外全部逐字相同：samantamasāro loko、disā sabbā sameritā、icchaṃ bhavanamattano、nāddasāsiṃ anositaṃ、asāro / nissāro / sārāpagato、niccasārasārena、ye puratthimāya disāya saṅkhārā、eritā / sameritā / calitā / ghaṭṭitā、jātiyā anugatā、jarāya anusaṭā、byādhinā abhibhūtā、maraṇena abbhāhatā、atāṇā / aleṇā / asaraṇā / asaraṇībhūtā、attano bhavanaṃ / tāṇaṃ / leṇaṃ / saraṇaṃ / gatiṃ / parāyanaṃ、ajjhositaṃyeva addasaṃ、sabbaṃ yobbaññaṃ、jarāya ositaṃ。

## 跨段一致性
- **samerita**：偈颂 §2288 / §2306 与总结句 §2300 译作“动摇”，释文 §2293 译作“被震动”，而 eritā 译作“被摇动”。这样一来，“动摇”和“摇动”分别对应 samerita 和 erita，读者分不清。**义注**：*Sameritā ti sammā kampitā*（彻底地被摇动），又以 kampitā 释 eritā，可见 samerita 是加强义。→ 建议偈颂改为“一切方位都在剧烈动摇”，或至少让偈颂与释文统一用一个词。因为这是被解释词，**须在 harmonize 时与义注 118:1621 / 1622 同步改**，不能只改本文。
- **pakampita / samerita**：§2299 pakampito 译“震动”，与 §2293 sameritā“被震动”撞词，两个不同的巴利词用了同一个汉译。建议 pakampito 改为“颤动”或“摇撼”。
- **jarā**：§2293 作“老”（被老追逐），§2296 / §2301 作“衰老”。**byādhi**：§2293 作“病”，§2301 作“疾病”。**maraṇa**：§2293 作“死”，§2301 作“死亡”。两边都受义注黑体锁定（118:1622 用“老 / 病 / 死”，118:1623 用“被衰老占据”），只改本文会断掉对应关系。→ 列为 harmonize 跨层统一项，建议统一为“老 / 病 / 死”，或统一为“衰老 / 疾病 / 死亡”，两层同步改。
- **sassata**：§2290 起 sassatena 译“永久”，§2303 asassatā 译“不能长久”。建议 §2303 改为“不是永久的”，与前文呼应。
- **文言虚词“之”**：“不变易之法”在 §2290（两句）、§2291、§2292（两句）共 5 处重复出现，须一并修改（见下）。

## §2290 句 149-2290-6-29
- **问题**：术语 — tiracchānayoniloka 译“畜生界世间”，pettivisayaloka 译“饿鬼界世间”，同句又有 dhātuloka“界世间”。这里的“界”分别对应 yoni / visaya 和 dhātu，三个不同的词共用一个“界”字，容易让人误读为“畜生的界世间”。
- **建议**：改为“畜生世间、饿鬼世间”，“界”字只留给 dhātu。§2290-49-91、§2292-2-27 同步改。

## §2290 句 149-2290-30-48
- **问题**：风格（必改）— “不变易之法”用了文言虚词“之”。
- **建议**：改为“不变易的法”。同样的改法适用于 149-2290-49-91、149-2291-78-98、149-2292-2-27、149-2292-28-63。

## §2291 句 149-2291-2-77
- **问题**：存疑 — setakaccha 译“白迦奢树”，依据不明，译文却写得很确定。udumbara 译“优昙婆罗树”，此处实指无花果类的树（Ficus glomerata），用作“无心材”的譬喻。传统译名可以沿用，但读者容易联想到“优昙花”。
- **建议**：setakaccha 查词典确认所指，并压低该句 confidence；udumbara 可考虑改为“无花果树”或“优昙钵树”，定案后登记到 terms.md。
- **原文**：udakapubbuḷaṃ 带异读 [bubbulakaṃ (sī.), pubbuḷakaṃ (syā.)]，只记录，不改。

## §2293 句 149-2293-7-32
- **问题**：取义 / 句法（必改）— 译文把 aniccatāya 接到后面，译成“被无常性跟随”，与 jātiyā anugatā 并列，并且凭空补了一个“跟随”。依据如下：
  - **义注**：*Disā sabbā sameritā ti sabbā disā aniccatāya kampitā*（一切方位都因为无常而动摇）。
  - **义注**：*Aniccatāyā ti hutvā abhāvatāya*。

  这说明 aniccatāya 是具格 / 因格，修饰前面的 eritā sameritā calitā ghaṭṭitā，表示“因无常而被摇动……”，并不受 anugatā 支配。
- **建议**：改为“东方的那些诸行，也都因为无常性而被摇动、被震动、动荡不定、受到撞击，被生追随，被老追逐……”。“无常性”保持与义注黑体逐字相同。149-2293-33-106 同样改。
- **问题**：风格 — “立足于苦中”的“于”偏书面。
- **建议**：改为“立足在苦中”。

## §2293 句 149-2293-33-106
- **问题**：同上，aniccatāya 被误接到后面（必改）。
- **问题**：译法 — “东方中间方位”对 puratthimāya anudisāya 的处理比较生硬，读者不知道指的是哪个方位。
- **建议**：改为“东方的偏方”或“东方的隅方”，四个 anudisā 统一用这种格式。

## §2295 句 149-2295-2-13
- **问题**：存疑 — raṇa 译“争斗”是字面义。注释传统中，raṇa 常解作尘垢 / 烦恼，所谓“色中的过患”。本 task 没有注入解释这一偈的义注，无法确认，但译文写得很确定。
- **建议**：查这首偈原出处的义注后再定，暂时压低 confidence。
- **原文**：§2294 开头有 ‘‘，§2295 末尾没有对应的 ’’ti。译文同样只有开引号没有闭引号，与原文一致；原文这里可能有脱漏，只记录。

## §2297 句 149-2297-2-14
- **问题**：译法 — “被欲望的烟熏燃着”中，“熏燃”不成词。icchādhūmāyita 的意思是被欲望之烟所熏、所笼罩。
- **建议**：改为“总是被欲望的烟熏着”或“总是被欲望的烟雾笼罩”。

## §2303 句 149-2303-2-12
- **问题**：一致性 — asassatā 译“不能长久”，与前文 sassata“永久”不呼应。
- **建议**：改为“不是永久的，是会变易的法”。
