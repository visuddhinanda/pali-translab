# Review — 118:1389-1399（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅（义注原文）／父层 Mahāniddesa 149:1652-1701 定稿译文 ✅／nissaya ❌（未提供，本次未做词级格位核对）／复注 ❌（没有释义标准，取义只能依据父层与义注自身的上下文）

## 被解释词与父层逐字核对

- 绝大多数黑体与父层译文逐字相同，或者是父层译文的连续片段，核对通过。
- **§1389 句 118-1389-65-79**：黑体范围超出了原文。巴利只有 sayameva / vedagū / dhīro / hoti 是黑体，**atha 不是黑体**，译文却把「如果」也加了黑体 → **必改**：去掉「如果」的黑体。
- **§1397 句 118-1397-25-33**：黑体「抬高论说……与别人」和父层 149-1693-33-49 逐字相同，但父层的取义与本条义注相冲突，详见下文 §1397。

## 跨段一致性

- viraddhā：§1391 译为「偏离」（“错失、偏离了清净之道”），§1392 黑体译为「失误了」（与父层一致）→ 建议 §1391 统一为「失误了」，依据是父层 149-1664 和本 chunk 的黑体。
- medhaga：§1395 黑体为「争论」（随父层第 128 颂），§1396 黑体为「纷争」（随父层第 129 颂）。同一个巴利词在本层黑体里出现两种译法，根源在父层。**这是父层问题，本层不能单独改**，建议交 harmonize 回父层统一后再同步本层。
- kalaha / bhaṇḍana / viggaha / vivāda 的对应关系在父层前后不一：149-1685 是 口角／争吵／冲突／争辩，149-1693 是 争吵／口角／争执／争论。本层 §1395 的 kalaha 译为「争吵」，跟的是 1693，而 §1395 注释的是 1685 → 同上，交 harmonize 在父层统一。
- bāla：§1389 正文译为「愚者」（“他人是愚者”“说他是‘愚者’”），同段黑体（父层第 125 颂）却是「愚人」。父层第 125 颂用「愚人」，第 128 颂用「愚者」→ 同属父层问题，建议父层统一后本层跟进。
- uddhaṃ（第 129 颂）：父层依义释「uddhaṃso vuccati anāgataṃ」译为「今后」，本层 §1396 的义注把它读作 uddhaṃ so = so bhiyyo（“他更加”）。这是两层释义本身就不同，不是误译。黑体必须保留「今后」，但读者会看到「今后」被解释成「更加」→ 建议由 pali-footnote 加注说明义注在这里另作一解。

## §1389 句 118-1389-2-15
- **问题**：取义 — kiñca bhiyyo 在义注里是承上启下的套语，意思是“再者”，并不是真的提问。“此外还有什么呢？”读起来像在发问。
- **建议**：改为“……这首偈颂的承接与意义是：再者，”，或者“还有一点：”。

## §1389 句 118-1389-16-53
- **问题**：指代 — tassa 与前面的 yo 相呼应，“别人”指的是那位下判断的人（对被骂者来说他是“别人”）。译文的“如果因为别人的话”和前面“那个……的人”之间断开了，读者看不出“别人”是谁。
- **问题**：取义 — 义注把 sahā 解释为 teneva saha（“和那人一起／和那人一样”）。“他也凭这一点同样成为……”沿用了父层 1655 对正文的理解，但在本层这一句属于义注自己的解释，不受黑体约束，应当照义注翻译。
- **建议**：“……的人，**如果因为**他这个**别人的话**，被他这样说的那人**就成了低劣者**，**那么他自己也同样是慧低劣的人**——他也和那人一样是慧低劣的人。”

## §1390 句 118-1390-18-21
- **问题**：用词 — upavāda 指责难、非难，不一定是捏造的。“诽谤”带有“说假话中伤”的意思，范围译窄了。
- **建议**：改为“由于被责难”。

## §1391 句 118-1391-54-79
- **问题**：风格（必改）— “与此不同**之**见解”，未加黑体的部分出现了文言虚词“之”。
- **建议**：改为“与此不同的见解”。“偏离”同时统一为“失误”，见跨段一致性一节。

## §1392 句 118-1392-25-31、118-1392-32-36
- **问题**：直译腔 — ṭhitā 在这里表示“处于……的状态”，“而停在那里”是逐字硬译，读来费解。
- **建议**：分别改为“是指偏离了上面所说的那种道”“是指出了差错”。

## §1392 句 118-1392-65-69
- **问题**：风格（必改）— “正理**之**道”，未加黑体的部分出现了“之”。
- **建议**：改为“意思是：在正理、正道上失误了”。

## §1393 句 118-1393-2-13
- **问题**：取义 — “Evaṃ abhirattā ca –” 是接着往下说，表示他们这样贪着，并且（如偈颂所说）……。“于是有……这首偈颂”说成了因果关系，好像偈颂是因为贪着才产生的。
- **建议**：“127. 他们这样深深贪着，而且——这就是‘**唯有这里才有清净**……’这首偈颂。”

## §1395 句 118-1395-74-90
- **问题**：漏译 — sopi 的 pi（“他也”）没有译出。
- **建议**：“他也一样，说他人‘这人是愚者、是不净法的人’，就是自己给自己招来争吵。”

## §1396 句 118-1396-26-45
- **问题**：句法误读 — ariyamaggena 修饰的是 hitvāna（以圣道舍弃）。译文“以圣道‘舍弃一切定见……’”把圣道放到了引文前面，句子不通，读起来像“以圣道”是这句偈颂的名称。
- **建议**：“然而，像这样知道了定见的过患，以圣道**舍弃一切定见**，**人在世间不制造纷争**——世尊用这句偈颂，以阿罗汉果为顶点结束了这次开示。”

## §1397 句 118-1397-25-33
- **问题**：取义冲突（涉及父层）— 义注把 uddhaṃ vādena saddhiṃ 解释为 attano upari kathentena saha，意思是“和压在自己之上发言的人（争）”，抬高的是**对方**。父层 149-1693-33-49 译成“他抬高论说，与别人争吵”，抬高的是**自己**，与义注相悖；按义注为准的原则，父层取义有误。目前本层黑体照搬父层，紧接着的解释却说的是对方，读者看到的是自相矛盾。另外，“一起”让人联想到合作，不符合争吵的语境。
- **建议**：先交 revise / harmonize 改父层 1693-33-49，例如“或者，他与压过自己发言的别人争吵……”；父层定稿后，本层黑体同步修改。解释部分可改为“是指与压在自己之上发言的人（争吵）”。
