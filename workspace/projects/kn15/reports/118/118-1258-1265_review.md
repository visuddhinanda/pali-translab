# Review — 118:1258-1265（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未提供，词级核对从缺）／义注：本层就是义注，没有复注可作对照，释义以本层自身的解释和父层原文为据／父层对照 ✅（book 149, §1194–1235）

## 被解释词核对（对父层 149 逐字）

逐条比对了 38 处黑体。除下面两项外，其余都与父层同一处逐字相同（「不善」「无记」「欲界」等只截取父层「不善触」等的前半，与巴利只引 `akusalo` 一致，不算断裂）。

- **§1260 句 118-1260-32-35 / 118-1260-36-42 / 118-1260-43-53**：`Appagabbho` / `Ajeguccho` / `Pesuṇeyye ca no yuto`
  - 问题：父层自身不一致。偈颂 §1208 译作「**不鲁莽**」「**不惹人厌恶**」「**也不从事离间**」，释文 §1216 / §1229 / §1231 和重诵 §1235 译作「不放肆」「不令人厌恶」「也不陷于离间语」。本层 §1260 带「87.」，注的是偈颂，严格说应对 §1208；现在的译法对的是 §1216 等处。
  - 建议：**回改父层 §1208**，统一为「不放肆」「不令人厌恶」「也不陷于离间语」（多数用法，也和 niddesa 释文一致）。如果父层不改，本层这三处必须改成 §1208 的译法。同类问题：§1207「退隐」与 §1234「退隐独处」也不一致，请一并统稿。
- **§1264 句 118-1264-30-37**：`bhākuṭiko`
  - 问题：父层 §1214 把 `bhākuṭika`（`bhākuṭikabhākuṭiko`）译作「故作严肃」，本层黑体却译「**装模作样的人**」。本句是构词说明（bhākuṭika 的状态 → bhākuṭiya），现译「装模作样的人的状态，就是**故作严肃**」让派生关系断了，读者看不出两者的联系。
  - 建议：改为「习惯于皱眉的人，是**故作严肃的人**；故作严肃的人的状态，就是**故作严肃**」，与 §1214 对齐。根本问题在父层，见下文「反哺父层」。

## 跨段一致性

- **taṇhā**：§1260 `patthanātaṇhāya` 译「希求的**贪爱**」，但本句注的是 `apihālu`，父层 §1215 释 pihā 时用的是「**渴爱**」 → 建议统一为「渴爱」。父层 §1197 用「贪爱」、§1215 用「渴爱」，父层也需要统稿。
- 其他已核对、前后一致的项：vimhāpana 都译「令人惊叹」（§1260 / §1262 / §1264），sahajāta「俱生」与 sampayutta「相应」按巴利原文区分，vipassantassa「修观的人」，「其余……也是同样的道理」句式统一。

## §1258 句 118-1258-35-47

- **问题**：误译 — `sayaṃ piṭṭhivaṭṭakā hutvā` 的意思是「自己被排除在外、不在其列」，不是「作为伴随者」。这句说的是：三无色蕴自己不取这个名称，而把「增语触」的名称给了与自己俱生的触。
- **建议**：「因为三种无色蕴自己置身在外，而给与自己俱生的触取名为‘增语触’。」

## §1258 句 118-1258-15-26

- **问题**：措辞 — `sabbo catubhūmako phasso` 是对意触的判定（意触就是一切四地的触），「涵盖」把它说成了包含关系。
- **建议**：「……也有没有所依的，意触就是一切四地的触。」

## §1260 句 118-1260-43-53

- **问题**：文言（必改）— 「离间**之**事」。
- **建议**：「不从事要以两种方式传播的离间的事。」也可以写成「……传播的离间行为」。

## §1261 句 118-1261-9-18

- **问题**：文言句式（必改）— 「**以**‘我是’**而**自我高举的慢，**以**正断的方式断除了」，「以……而……」是文言句式。
- **建议**：「认为‘我是’而自高自大的慢，已经被彻底断除了（正断）。」

## §1263 句 118-1263-29-45 / 118-1263-49-53

- **问题**：译文里的「（单数）」「（复数）」是译者加的语法标签，不符合夹注体例；而且 118-1263-11-24 的黑体「邀请」没有标注，前后对不上。
- **建议**：讨论异读时改用巴利夹注：「也有人读作‘邀请’（nimanteti）或者‘说’（vadanti）」「应当看出，‘邀请’（nimantenti）这一读法是成立的」。

## §1263 句 118-1263-46-48

- **问题**：存疑 — `Tādise nimantāpenti` 的语义归属不明，现译「在那种情况下，是让人去邀请」译得像很确定。
- **建议**：保留现译，压低 confidence。待有复注时再核。

## §1263 句 118-1263-111-115

- **问题**：义注释义与父层冲突 — 义注把 `tadupādāya` 释为 `tato paṭṭhāya`（从那时起），父层 §1211 却译作表示因果的「因此」。本句黑体「**因此**」后面紧跟「从那时起」，读者会以为注文在自相矛盾。
- **建议**：见下文「反哺父层」。父层改定后，本句黑体随之改为「**从那以后**」。

## §1263 句 118-1263-127-133

- **问题**：措辞 / 释义 — 「当前现前」重复累赘；`vijjamānatā` 是「存在」，译成「具备」偏了。
- **建议**：「**就在眼前**：由于出现在面前，也就是由于存在的意思。」

## §1263 句 118-1263-138-149

- **问题**：病句 — 「因为**有**信心就在眼前才能做到」。
- **建议**：删去「有」：「因为信心就在眼前才能做到，所以说了……」

## §1264 句 118-1264-2-14

- **问题**：术语表述不清 — `nissakkatthe karaṇavacanaṃ` 是「用在从格（离开）意义上的具格」，「表示离开意义的具格」容易被读成具格本身就有离开义。
- **建议**：「‘**福德**’是用作从格（表示‘离开’）意义的具格。」

## §1264 句 118-1264-20-29

- **问题**：误译 — `padhānapurimaṭṭhitabhāvadassanena` 里的 padhāna 是「精勤」，整个复合词意为「显出自己是站在精勤前列的人」，不是「面容紧绷、专注于前」。
- **建议**：「**装模作样**：通过显出自己是精勤修行走在前面的样子而皱眉，也就是皱起面孔。」

## §1265 句 118-1265-19-29

- **问题**：语体 — 「着意经营……举止」偏书面雅化。
- **建议**：「刻意安排前进等行走的动作，意思是说让自己显得庄严、令人起信。」

## 反哺父层（book 149，供 harmonize 处理）

- **§1211-109-126 / §1211-225-237** `Tadupādāya`：义注释为「从那时起」，父层「因此」与义注相悖 → 改为「从那以后」。
- **§1211-238 等** `bhākuṭikā` / `bhākuṭiyaṃ`：义注释为「皱眉、皱起面孔」，父层「装模作样 / 故作严肃」偏宽，而且同源的两个词被拆成了不相关的两种译法 → 建议改为「皱眉作态 / 皱眉的样子」一类，与 §1214 `bhākuṭika` 统一。改了父层，本层 §1264 的黑体要同步。
- **§1208** 偈颂三处与 §1216 / §1229 / §1231 不一致（见上文）。
- **§1211-12 等** `icchāpakato`：义注释为 `upadduta`（受困扰），父层「被欲望驱使」略有偏离，优先级低，供参考。

## OCR / 原文疑问

- §1262 `tadanuggahakāmataṃyeva avikatvā`：疑为 `āvikatvā`（显露）的讹误，《清净道论》同文作 āvikatvā；现译「只装作是为了成全他们」按 āvikatvā 理解，是对的。
- §1263 `āpaṇadvāre patikāni`：疑为 `patitāni`（掉落的）。
- §1264 `mukhānaṃ padhāna…`：《清净道论》同文没有 mukhānaṃ，疑为衍文，待核。
- 父层 §1211-200 `tumhe … bhavissanti`：人称不合，本层引文作 `bhavissatha`，父层原文疑有讹误。
