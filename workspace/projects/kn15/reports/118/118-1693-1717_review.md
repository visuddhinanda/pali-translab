# Review — 118:1693-1717（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层对照（book 149 本文定稿）✅／nissaya ❌（未提供）／释义标准 ❌（本层就是义注，没有更上层的解释可对照；复注未提供）
> 被解释词逐字核对：共 45 处黑体，**全部与父层译文逐字相同**。下面列出的问题大多是「字面对上了，但意思和义注冲突」，根子在父层。

## 跨段一致性
- **vimokkhanta**：§1693-46-60 译作“解脱的终点”，同段 70-75、76-83 译作“解脱圆满时”，读者看不出两者是同一个词。建议在 46-60 处补一句衔接，例如“解脱的终点（也就是解脱圆满）”，后文统一用“解脱圆满时”。依据：被解释词须随父层用“解脱圆满时”。
- **异读的处理方式不统一**：
  - §1696-23-34 保留巴利原词 “kuvanto”。
  - §1698-36-42 把异读 amataṃ disaṃ 直接译成“不死的方向”。
  - §1700-9-14 在正文里插入说明“这里读作 anavasekaṃ”。
  - 建议统一为：异读保留巴利原词，后面加括号附中文义。正文里不加原文没有的说明。
- **kīvatakā / kīvabahukā**：§1697-31-34 和 §1697-35-38 两个被解释词都译作“数量有多大”，义注对两者的界定不同（分别是“问范围”和“问数量与范围”）。见下方 §1697 条和父层问题第 2 条。

## §1693 句 118-1693-2-18
- **问题**：格式 — 黑体外层的双引号里又套了双引号：“**“佛陀”这个名称**”。
- **建议**：内层改用单引号：“**‘佛陀’这个名称**”。只是换引号层级，被解释词的文字不动。

## §1693 句 118-1693-46-60
- **问题**：跨段一致性 — 见上。另外“就叫作‘在解脱圆满时’的名称”读起来别扭。
- **建议**：改为“在这解脱的终点（也就是解脱圆满时）产生的名称，就叫作 vimokkhantika（‘在解脱圆满时’的）名称”，或用其他方式点明 vimokkhantikaṃ 是由 vimokkhante 派生的形容词。

## §1693 句 118-1693-61-69
- **问题**：准确性（轻）— sijjhati（现在时，“由……来成就”）和 siddhaṃ hoti（“已成就”）分别对应道和果两个时点。现在的译文“是由阿罗汉道成就的，在阿罗汉果生起时就已经成就了”把两者说成了同一件事。
- **建议**：改为“一切知的状态是靠阿罗汉道来成就的，到阿罗汉果生起时才算成就”。

## §1694 句 118-1694-11-15
- **问题**：准确性（轻）— vivittaṃ 译作“远离人群的”，“人群”是译者补出的。父层 §2633 对 ritta/vivitta 的解释是远离不适宜的色、声和五欲，不只是远离人群。
- **建议**：改为“僻静的床和椅子”，或沿用父层的“远离的”。

## §1697 句 118-1697-31-34 / 118-1697-35-38
- **问题**：被解释词对应关系断了 — 两个不同的巴利词，黑体都是“数量有多大”。读者分不清哪条注在注哪个词。另外 31-34 的黑体说的是“数量”，注文却说“问范围”，两者自相矛盾。
- **根因**：父层 §2641-51-60 把 kati / kittakā / kīvatakā / kīvabahukā 四个词只译成了三个短语。
- **建议**：先改父层，把四个词分别译出（参照义注：kati 是一般提问，kittakā 问数量，kīvatakā 问范围，kīvabahukā 问数量和范围）。再让本层四个黑体逐字跟上，§1697-46-60 的 **Kīvabahukā** 也一起改。

## §1698 句 118-1698-36-42
- **问题**：异读处理 — 这一句的要点是文本异读（agataṃ 还是 amataṃ），译成“不死的方向”后，读者看不出异读在哪里。
- **建议**：改为“也有读作 amataṃ disaṃ（不死的方向）的版本”，与 §1696 的 kuvanto 处理一致。

## §1700 句 118-1700-9-14
- **问题**：必改。有两处问题：
  1. 正文插入了原文没有的“这里读作 anavasekaṃ”，这是译者的说明，应该移到脚注或审稿记录，不能进正文。
  2. 黑体“一点不剩”（对应父层的 anavasesaṃ）与义注的释义“不溅出、不洒出”（对应 anavasekaṃ）意思冲突。读者会看到“一点不剩，就是不溅出”这样前后不搭的说法。
- **依据**：**义注**：Anavasekan ti anavasiñcanakaṃ aparisiñcanakaṃ katvā。义注读作 anavasekaṃ，意思是“不洒出”。Telapatta 本生的偈颂也作 anavasekaṃ。按规则，冲突时以义注为准。
- **建议**：回传父层 §2683，把“一点不剩”改为“一滴不洒”或“不溅不洒”。本层黑体随之逐字更新，删去插入的说明。

## §1713 句 118-1713-2-7
- **问题**：存疑（轻）— anavassuta / ananvāhata 被补译成“不被贪欲浸染”“不被瞋恚侵扰”。这个取义出自《法句经》义注，本段义注没有这样说。
- **建议**：可以保留，因为这是传统取义，但该句 confidence 宜压低。也可以改用中性译法：“心不渗漏”“心不受侵扰”。

## §1715 句 118-1715-2-4
- **问题**：风格（轻）— “所以对这——”读起来残缺。etaṃ 是后面 ujuṃ karoti 的宾语。
- **建议**：改为“所以，这——”或“所以，对这样的心——”。

## 父层问题（回传 book 149 revise / harmonize）
以下是义注揭示出的父层问题。父层一改，本层的黑体要跟着同步。
1. **§2633-51-63 nisevato / saṃsevato / paṭisevato 与义注冲突**：
   - **义注**说 nisevato = sammā sevantassa（正确地依止），父层译作“常依止”。
   - **义注**说 saṃsevato = punappunaṃ sevantassa（一再依止），父层译作“全然依止”。
   - **义注**说 paṭisevato = upagantvā sevantassa（走近之后依止），父层译作“受用”。
   - 本层 §1695 的注文因此与黑体词意思对不上，比如“常依止就是正确地依止”。建议父层按义注重译。
2. **§2641-51-60 漏译一个词**：四个疑问词只译出三个。另外 §2650-7-13 同一组词译作“几个、多少、若干、有多少”，与 §2641 不一致，属于父层内部的跨段漂移。
3. **§2683 anavasesaṃ「一点不剩」**：见 §1700 条。
4. **§2606-97-130 amaccā「同僚」**：**义注** §1693-23-25 释为 bhaccā（仆从、家臣），父层的“同僚”与此不符。建议父层改为“臣仆”或类似译法，本层黑体同步。
5. **§2688-2-6 缺译文**：zh 字段为空，channel 漏了这一条。
6. **§2649「边远的住处」与 §2687 / §2690「偏远的卧坐处」不一致**：pantamhi sayanāsane 在父层有两种译法，建议统一。
