# Review — 68:835-839（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 这一批没有 nissaya 和义注，只能对照巴利原文审读，**释义和词法都没有外部标准可核**。本层是本文（mūla），没有注入父层，所以**没有查被解释词是否与父层逐字同译**。

## 跨段一致性
- 836–839 是同一首偈（四个 pāda），译文把它断成了三个独立句：836 以“，”结尾，837 以“；”结尾，839 以“。”收住。836 和 837 本来是一个关系从句（aññā … yā āsuṃ，“那些曾经……的其他注释”），现在译成了两个并列分句，结构对不上。建议 836 与 837 合成一个带定语的名词短语，见下面 §836 和 §837。
- 语体和称谓全段统一，没有发现文言虚词或文言句式。

## §836 句 68-836-2-6
- **问题**：术语（未登记）— 《波遮利》（Paccarī）和《俱伦提》（Kurundī）是僧伽罗古注的书名，`terms.md` 和 `term-glossary.jsonl` 都没有登记。已有的汉译并不统一（Paccarī 也有按字义译成“筏疏”的），而且没有义注可以参照。
- **建议**：译名暂时保留。首次出现时按 style.md 的规定用圆括号夹注巴利原名：《波遮利》（Paccarī）、《俱伦提》（Kurundī）。定案后补进 `terms.md`，让后面各段和三层译文都沿用同一个译名。
- **问题**：句法 — aññā … samaññitā-ādī 是主语，被 837 的关系从句 yā … āsuṃ 修饰。现在的“还有其他……的注释，”读起来像是一个已经说完的判断句。
- **建议**：和 837 连起来改成名词短语，例如：“还有名为《波遮利》《俱伦提》等其他注释——它们曾是这座岛上律学的明灯——”，或者把 837 前置成定语：“还有曾在这座岛上为律学点亮明灯的《波遮利》《俱伦提》等其他注释”。

## §837 句 68-837-2-8
- **问题**：取义（存疑）— dīpaṃ padīpakaraṇī 很可能是双关：dīpa 既可以指“岛”（锡兰），也可以指“灯”。现在的译法“像明灯一样照亮这座岛屿”取的是“岛”义，说得通。不过“这座岛屿”没有交代是哪座岛，一般读者看不出指的是锡兰（楞伽岛）。
- **建议**：可以改成“这座岛（楞伽岛）”，或者在段后加注说明指锡兰。双关的问题写进注释就行，译文不用改。
- **问题**：句法 — yā … āsuṃ 是修饰 836 主语的关系从句，现在译成了独立分句。
- **建议**：同 §836，把这一句改成定语或插入语。

## §838 句 68-838-2-7
- **问题**：补出成分 — 原文没有第一人称代词，“我”是译者补的。偈颂是作者自述，补出来意思没问题，但 style.md 第六节要求“不擅自补足省略主语（除非语义必须）”。主动词在后面的偈颂里，要看后文才能判断这里该不该补。
- **建议**：先看紧接的 840 及以后几段。如果主句主语在后文才出现（比如“我将撰述……”），这里可以不补“我”，写成“把这些注释中所有的义理方法，以及长老们的”。

## §839 句 68-839-2-6
- **问题**：句法（必改）— saṅgayha 是独立式（absolutive，“收集之后”），不是主动词。这首偈没有主句，主动词在下一首偈里。现在的译文“……收集起来，就像把珍珠宝石串在同一根线上。”用句号收住，而且把独立式译成了完结的谓语，和后文的主句断开了。
- **建议**：改成未完成的状语，句末用逗号或破折号接下一首偈，例如：“……论说收集起来，像把珍珠宝石串在同一根线上那样，”。收尾的标点和写法要等对照 840 以后的译文再定。
- **问题**：OCR／原文（只记录，不改）— mekasutte 是 ekasutte 加了连音 -m-（muttaratanāni iva ekasutte）。838 的 tāsa ’ makhila° 是 tāsaṃ akhila° 的连音写法，837 的 yā ’ suṃ 是 yā āsuṃ。这几处都是正常的连音加省略号，不是讹误。只是原文在省略号、逗号前后有多余的空格（“samaññitādī ,”、“’ suṃ ;”），属于录入格式问题。
