# Review — 208:1357-1364（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注 —（本层没有父层；释义参照下一级**复注** Vinayālaṅkāra-ṭīkā（book=211，1837–1880），它只用来校对，本 task 不译）
>
> 被解释词对照：复注黑体从本层引出的词，有 catuvaggakaraṇe / anissāritā / parisuddhasīlā / avasesā…chandārahāva honti / na tesaṃ chando vā pārisuddhi vā eti / ekādasahi ākārehi… / apalokanakammaṃ katamāni pañca ṭhānāni gacchati / etarahi sacepi sāmaṇero / micchādiṭṭhiko / antaggāhikāya diṭṭhiyā samannāgato / taṃ laddhiṃ vissajjāpetabbo / kāyasambhogasāmaggī / sorato / nivātavutti / tassāpi dātabbo。只有 **chandārahā** 一处与复注不逐字相同，见下文 §1358；其余全部一致。

## 跨段一致性
- **chandāraha**：§1358 句 208-1358-10-29 译“应当与欲者”，句 208-1358-50-87 和 208-1358-88-114 译“应当与欲的人”。建议统一为“应当与欲者”。依据：复注 211-1838-60-98 引这个被解释词时作“都是应当与欲者”，并且它和“适合参加羯磨者”“羯磨的对象”是并列的一组术语，需要定型。
- **apalokanakamma**：本层 §1359、§1361、§1363 一律译“告白羯磨”，这是对的。但复注 211-1848（“求听等四种羯磨”“求听羯磨”）和 211-1880-35-43（“求听羯磨”）用的是另一个译名，复注内部也不统一。harmonize 时应把复注改成“告白羯磨”，并把这个词登记进 `terms.md`。
- **yāvatatiyaṃ**：§1359 译“多达三次”，§1361 译“多达三次”，前后一致。但“多达”这个说法不准确，见下文，两处要一起改。

## §1358 句 208-1358-50-87
- **问题**：被解释词与复注不一致 + 释义偏差。
  1. “至于其余的比丘……就全部都只是**应当与欲的人**”，复注引这个词时作“**都是应当与欲者**”，两边不是逐字相同（必改）。
  2. “他们的与欲或清净也**不能托人转达**”：这里 eti 的意思是“（送来的与欲）生效、算数”。**复注**（211-1839-39-64，转引《心义灯》）解释说：“āhaṭāpi anāhaṭāva hoti”，即“即使已经转达过来，也等于没有转达”。所以重点是“送来了也无效”，不是“不能托人转达”。现译把可以做到的动作说成了不能做。
- **建议**：
  - 把“应当与欲的人”改为“应当与欲者”。
  - 后半句改为“他们的与欲或清净也不算数（送来也无效）”之类的表达。
  - 这个词是复注 211-1839-39-64 的被解释词，复注那一句要同步改字，交给 harmonize 处理。
  - 另外，“交付与欲和清净”与上句“托人转达”的用词不同。建议统一为“送来与欲和清净”，与复注 211-1838-60-98 的“送来意欲或清净”取齐。复注那里的“意欲”也应改为“与欲”。

## §1358 句 208-1358-10-29
- **问题**：
  - 风格：“其中**若**要说明”用了文言连词“若”（必改）。
  - “**已经在后面**……说过了”，“后面”和“已经说过”在时间上自相矛盾。parato 指后文，即本书后面引的附随原文。
- **建议**：改为“如果要说明其中适合参加羯磨者与应当与欲者的特征，这一点在后文以‘四位本性比丘适合参加羯磨’等方式也有说明”。

## §1358 句 208-1358-30-49
- **问题**：
  - 风格：“四位本性比丘，**即**没有被举罪……”中的“即”作文言单字用。
  - 后半句“是这个羯磨有资格、相称的主人”把 arahā / anucchavikā / sāmino 三个并列谓语硬塞成了一个定中结构，读起来不通。nissaya：`အရဟာ= ထိုက်ကုန်၏။ အနုစ္ဆဝိကာ= လျောက်ပတ်ကုန်၏။ သာမိနော= ကံပြုခြင်းငှာ ပိုင်ကုန်၏။`，即“相称／适当／有权作羯磨”，三者是并列关系。
- **建议**：改为“……四位本性比丘，也就是没有被举罪、没有被驱出、戒行清净的四位比丘，适合参加这个羯磨：他们有资格、相称，是有权作这个羯磨的人”。被解释词“本性者适合参加羯磨”“没有被驱出”“戒行清净”“在需要四人僧团完成的羯磨中”保持原样，不要改动。

## §1358 句 208-1358-88-114
- **问题**：术语。kammāraha 译“羯磨的对象”，意思没错，但它与本段的 kammappatta（适合参加羯磨者）、chandāraha（应当与欲者）同属 -araha / -patta 术语组，现在的译法看不出这种对应关系。
- **建议**：改为“所以称为应受羯磨者（kammāraha）”，或者保留“羯磨的对象”但首次出现时夹注巴利原词。句中的“应当与欲的人”按跨段一致性统一为“应当与欲者”。

## §1357 句 208-1357-69-91
- **问题**：风格。“**如此**就是界标没有断缺”，“如此”偏书面。
- **建议**：改为“这样，界标就没有断缺”。

## §1357 句 208-1357-106-126
- **问题**：
  - 风格：“等其中**之**一”。
  - 释义：tacasārarukkha 的 nissaya 作 `အပ၌ အနှစ်တည်သော သစ်ပင်`，即“坚实部分在外层的树”，指竹、棕榈一类没有心材的植物。现译“外皮坚硬而无心材的树”大体可以，但“外皮坚硬”是添出来的意思。
- **建议**：改为“……以外皮为坚实部分的树（竹、棕榈之类）、树桩、土堆或沙堆等其中的一种……”。这句压低 confidence 即可。

## §1359 句 208-1359-37-47
- **问题**：存疑（专名）。kaṇṭaka sāmaṇera 译作“犍陀迦沙弥”。“犍陀迦／犍陟”通常对应 Kaṇḍaka / Kanthaka，这个人名的传统汉译需要另行核对（对照《律藏·波逸提70》的汉译）。`terms.md` 里没有登记。
- **建议**：核对后登记进 `terms.md`。在定案前不要在译文里留标记，只压低这句的 confidence。

## §1359 句 208-1359-48-83
- **问题**：
  - 措辞：yāvatatiyaṃ 的意思是“直到第三次”，现译“劝止他**多达**三次”带有“最多”的含义，与原意不符。
  - nissaya 分歧：nissaya 把 antaggāhikāya diṭṭhiyā 释为 `ဥစ္ဆေဒဒိဋ္ဌိ`（断见）。**复注**（211-1878-85-113）明确驳斥了“常见、断见中的某一种”这个解释，认为这里指的是颠倒理解佛语意趣。现译“具有边执见”没有限定为断见，与复注一致，应当保留。
- **建议**：改为“就应当劝止他，直到第三次，让他舍弃那个主张”。§1361 的“让他乞求多达三次”也同样改为“让他乞求，直到第三次”。被解释词“现在如果有沙弥”“持有邪见”“具有边执见”“让他舍弃那个主张”都不要动。

## §1361 句 208-1361-2-32
- **问题**：误译倾向。alakkhikatāya 译为“不善”，太泛。nissaya：`အလက္ခိကတာယ= ယုတ်သဖြင့်`，意思是“因为卑劣、鄙陋”，原词也有“不吉、倒霉”的意思。
- **建议**：改为“因为愚痴、无知、鄙劣”。

## §1362 句 208-1362-2-56
- **问题**：可读性。kāyasambhogasāmaggidāna 译作“身体受用与和合”，读起来像是两件事。实际上它是一个复合词，意思是“在身体方面共同受用的和合”。**复注**（211-1878-114-118）解释为“同宿、接受等”；nissaya 的附注也说是“同宿、供给饭食等”。
- **建议**：被解释词必须与复注逐字相同，所以本层不要单方面改动。如果要改得更清楚，例如改为“在身体方面共同受用的和合”，需要在 harmonize 时连同复注 211-1878-114-118 一起改，不能只改一边。
