# Review — 208:540-550（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（208-541-111-114 无独立 nissaya 单元，其释义并在 208-542-2-15 开头）／义注 ❌（未提供，本报告的释义判断只依据 nissaya 与上下文，涉及取义的条目已注明有待义注核定）
>
> 本层为本文 mūla，无父层对照，不做被解释词逐字核查。

## 跨段一致性
- **āpucchati**：§540 译“请求允许”（句 208-540-97-112），§540 译“请求许可”（句 208-540-113-116），§548 译“告假”（句 208-548-2-16）→ 建议统一为“请求许可”。依据：§540 的“一切请求许可的事”已把它当作概括性用语，§548 用“告假”会让读者以为是另一种程序。
- **samannāgata**：§542–546 的总句译“具有”，§542 句 208-542-16-39 译“具足” → 建议统一为“具有”。
- **upasampadāya pañcavasso / ūnapañcavasso**：§540、§541 译“受具足戒（满）五年”，§546 句 208-546-15-35 译“受戒不满五年” → 建议统一为“受具足戒不满五年”。
- **bahussuta / appassuta**：§541 译“多闻”，§544 译“学识浅薄” → 这两个词是一对，建议 appassuta 改为“少闻”，与“多闻”对应。
- **adhisīla / ajjhācāra / atidiṭṭhi**：在 §544 里这三个是并列的“增上”三项，译文分别作“增上戒 / 正行 / 见解”，前后不对称 → 建议统一为“增上戒 / 增上行 / 增上见”（见下文 §544 条）。
- **byatta / paṭibala**：byatta 在全 chunk 都译“有能力”（§540、§541、§547–548 的 abyatta 译“无能 / 没有能力”），这一点是统一的；但 §540 同时出现 paṭibala，译“有才干”，两词与译名的对应不清楚（见下文 §540 条）。
- **mātikā / pātimokkha**：§541 的 dve mātikā 与 §545 的 ubhayāni pātimokkhāni 都译“两部波罗提木叉”。nissaya 把 mātikā 注为比丘、比丘尼两部戒本，两处所指相同，可以接受；但原文用词不同，如果想保留这个区别，可以把 §541 译作“两部戒本（mātikā）”。属于可选项。

## §540 句 208-540-2-47
- **问题**：术语 — byatta 与 paṭibala 两个词译作“有能力、有才干”。下文 byatta 一律译“有能力”，读者无法判断这里哪个词对应哪个译名。nissaya 对 byatta 的注释是 `ဗျတ္တိရှိသော`（具有 byatti，即通达、善巧），paṭibala 是“能胜任”。
- **建议**：改为“有能力、能胜任的比丘”，让 byatta 与全 chunk 保持“有能力”，paṭibala 另用一词区分。

## §540 句 208-540-48-96
- **问题 1**：格式 — 出处“（《大品》义注103）”插在“如果”和“他”之间，把条件句截断了，读起来很别扭。
- **建议**：把出处移到句末，或者移到整句开头。
- **问题 2**：风格 — “资浅”是偏书面的单音节组合。
- **建议**：改为“比自己年资浅”或“戒腊比自己小”。
- **问题 3**：OCR — pali 原文作 `ācariyo me, āvuso, hoti`，nissaya 作 `ဟောဟိ`（hohi，命令式）。从语义看应为 hohi。译文“请您做我的阿阇梨”已经按 hohi 理解，译文不用改，这里只记录原文的疑似讹误。

## §541 句 208-541-14-96
- **问题 1**：误译（句法）— `pakkhadivasesu dhammassavanatthāya` 译成“为了在半月的日子听法”，这样主语变成了比丘自己去听法。nissaya 作 `တရားနာစိမ့်သောငှါ`，其中 `စိမ့်` 是使役，意思是“为了让（大众）听法”。上下文中的四个诵分是比丘要为大众诵说的内容。
- **建议**：改为“为了在每半月的斋日让大众听法（为大众诵法）”。
- **问题 2**：表达 — “半月的日子”意思不清楚。nissaya 注为 `လပြည့် လကွယ်နေ့`（满月日、新月日）。
- **建议**：改为“每半月的布萨日”或“满月日与新月日”。
- **问题 3**：取义存疑 — kammākammavinicchaya 译作“关于羯磨合法与不合法的抉择”，而 nissaya 作 `ကံကြီး ကံငယ်`（大羯磨、小羯磨），两者理解不同。nissaya 还说明此项出自《附随》末尾。由于没有义注可以核定，建议先保留现译，降低该句 confidence，等取得义注后再定。
- **问题 4**：格式 — 三部经名用粗体，没有“经”字，也没有书名号。“安玻吒”也不是常见译名，传统译作《阿摩昼经》。
- **建议**：改为《安达迦温达经》《大教诫罗睺罗经》《阿摩昼经》。粗体是否保留按项目对原文黑体的处理惯例决定。

## §544 句 208-544-15-32
- **问题**：误译 / 不对称 — adhisīla、ajjhācāra、atidiṭṭhi 是并列的“增上”三项，译文只有第一项译出了“增上”。另外 `diṭṭhivipanno` 译成“正见有毁损”，“正见”是增译，说不通，因为毁损的是“见”，而不是“正见”。
- **建议**：改为“他在增上戒上戒毁损，在增上行上行为毁损，在增上见上见解毁损，少闻，缺乏智慧。”（“少闻”见跨段一致性一节。）

## §545 句 208-545-16-50
- **问题**：结构 — 冒号前的“熟习”是增译，原文 vitthārena 管的是后面四项（svāgata / suvibhatta / suppavatti / suvinicchita），并没有一个总括的动词。
- **建议**：改为“两部波罗提木叉他都没有详细地好好传承，没有好好分析，没有好好诵习，也没有依据条文和细节好好判定。”

## §547 句 208-547-17-24
- **问题**：nissaya 分歧（记录）— nissaya 把 `te` 注为 `ထိုဆရာဥပဇ္ဈာယ်တို့`（那些阿阇梨与和尚），但根据下文 §548 引的《大品》原文，离开的显然是弟子。译文取“弟子”，是正确的，不必改。
- **建议**：可以把主语明确为“如果这些弟子没有得到许可就走”，避免读者把“他们”误解为上一句的阿阇梨和和尚。

## §548 句 208-548-35-46
- **问题**：表达 — `aññe bāle abyatte apadiseyyuṃ` 译为“说出的是另外一些愚钝无能的人”，“说出”含义模糊。apadisati 在这里的意思是“举出（同行的人）”，nissaya 作 `ညွှန်း`（指明）。
- **建议**：改为“如果这些愚钝无能的比丘举出的同行者也是另外一些愚钝无能的比丘，”

## §549–550 句 208-549-2-3 / 208-550-2-4
- **问题 1**：句法 — 两句连起来读是“以上是《巴利外律抉择摄》中的依止抉择论结束。”，“以上是……”与“……结束”杂糅在一起，不成句。
- **建议**：549 改为“以上，《巴利外律抉择摄》中的”，550 改为“依止抉择论到此结束。”
- **问题 2**：术语存疑 — kathā 译作“论”，与术语表中 abhidhamma 的译名“论”冲突，容易让读者误以为这是论藏。
- **建议**：先确认全书各章 kathā 的统一译法（例如“章”或“论述”）再定；在定案之前，降低该句 confidence。
