# Review — 211:2334-2395（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 仅 §2335–2343 有，§2334 与 §2344–2395（复注作者结语偈）无／义注 —— 本层是复注，没有更高一层的释义标准；被解释词以父层 208:1658–1673 已定稿的译文为准
> 已核对父层被解释词：§2336 的 teneva / kārite / ramme / pāsādasatamaṇḍite / nānādumagaṇākiṇṇe / bhāvanābhiratālaye / sītalūdakasampanne / jetavane / vasaṃ / sohaṃ / yogīnaṃ hitaṃ / sāraṃ / imaṃ / vinayasaṅgahaṃ 全部与父层逐字一致；§2337 中只有 **nāthaṃ** 一处不一致，见下。

## 跨段一致性
- **parakkamabāhu narinda**：§2335 译“人间之王波罗迦摩巴忽”（与父层 1659 相同），§2336 译“波罗迦摩巴忽人间之王”。建议统一为父层的语序“人间之王波罗迦摩巴忽”。
- **aggaphala / aggaṃ phalaṃ**：§2337 用父层的“最高的果位”，§2338-109、§2342-30 改成“最上果”。§2342-30 是在重新串解父层同一句，建议统一为“最高的果位”。
- **yojanā**：§2335“文句串解”，§2336“文句的串解”，§2337“文句串解”，§2342“串解”。建议统一为“文句串解”。
- **abhidhamma**：§2338-84 译“论藏”，§2338-146 书名里用“阿毗达摩”。term-glossary 记为“论（阿毗达摩）”。建议 §2338-84 改为“《阿毗达摩·双论》”，与书名一致。
- **pariyatti**：§2341 译“教典”（sabbapariyattidharo → 通达一切教典），§2368、§2395 译“教理”。建议统一为“教理”，dhara 改译“受持”，即“受持全部教理”。
- **bhāvanā**：父层与 §2336 都译“修习”，§2359 译“修习禅修”，语义重复。建议改为“适合修习”。
- **sīlācāraguṇa**：父层 1667 作“持戒、善行与德行”，§2342-2 少了顿号，作“持戒善行与德行”。复述父层句时建议保留顿号。
- **人名书名的夹注**：§2347 铜洲国、§2353 吉祥妙法王有夹注，而首次出现的《心义灯》（Sāratthadīpanī）、《阿毗达摩义广释》（Abhidhammatthavibhāvinī）、香醉山（Gandhamādana）、摩尼窟（Maṇiguhā）、曼殊沙树（Mañjūsaka）都没有。建议统一为首次出现时夹注。
- **lañchana / ketu**：§2365“两次获得封号”与 §2380“两次获得荣誉的旗幡”说的是同一件事。可以统一为“封号”，或者在 §2380 加注说明。

## §2336 句 211-2336-2-44
- **问题**：语义说明 — **我**，就是那个我。sohaṃ → so ahaṃ 只是连音拆写，“那个我”在现代汉语里读不通。
- **建议**：改为“**我**，原文是 so（那位）与 ahaṃ（我）的连写，指的就是前面受请的那位作者”。也可以把拆解放进脚注，正文只保留“**我**”。
- **问题**：语义说明 — vasaṃ 的两种解释区分得不够清楚。第一种是 vasanto hutvā，作状语，相当于“住在那里时”；第二种是 vasanto，作定语修饰“我”。nissaya 也分别释为 `နေတော်မူသည်။ ဟုတွာ` 和 `နေတော်မူသော`。
- **建议**：后半句改为“或者，**居住时**也可以理解为修饰后文的“我”，即“正在居住的我””。

## §2337 句 211-2337-2-63
- **问题**：**被解释词与父层不一致（必改）**。nāthaṃ 在父层 1670 译作“**众生的依怙者**”，本句只作“**依怙者**”。另外漏译了释词 nāthabhūtaṃ。nissaya 的释义是 `လူသုံးပါးတို့၏ အားထားကိုးကွယ်ရာ`（三界众生依靠皈依之处），与父层补出“众生的”是一致的。
- **建议**：改为“……世间最上的人、**众生的依怙者**，也就是作为依怙的那一位、乐于利益一切众生的……”。
- **问题**：格式（必改）。“**成就的****功德**”“**我所积累的****其他**”“**证得****最高的果位**”这几处，两个黑体首尾相接，产生了 `****`，在 markdown 里会渲染出错。
- **建议**：相邻的黑体合并成一个，如“**成就的功德**”“**我所积累的其他**”“**证得最高的果位**”。
- **问题**：漏译释词。adhigantvā 的释词 labhitvā（获得）和 sobheyyaṃ 的释词 sobhāpeyyaṃ（使显耀）都没有译出。前一句的格式是“被解释词，也就是……”，这里前后不一致。
- **建议**：补为“**证得**，也就是获得……”。sobhāpeyyaṃ 的使役义译文已经体现了，可以不补，但要在报告中说明。

## §2338 句 211-2338-84-108
- **问题**：取义。satteva anusayā anusenti 的意思是“七种随眠全都潜伏”，即从色界死后投生欲界的只能是七种随眠全部具足的凡夫，因此圣者不会这样投生，论证正是靠这一点。译成“只有七种随眠潜伏”，容易被读成“数量被限制在七种”，论证就断了。nissaya `ခုနစ်ပါးသာလျှင်` 是字面释义，按义理应以论证脉络为准。
- **建议**：改为“……的人，七种随眠全都潜伏着”。

## §2338 句 211-2338-139-145
- **问题**：原文疑问。Na hi bhikkhubhūto sāsanaṃ sobhāpetuṃ sakkoti 照字面是“成为比丘的人不能使教法显耀”，与上下文正好相反，疑为 abhikkhubhūto 脱了 a-。nissaya 照字面释为 `ရဟန်းဖြစ်၍ဖြစ်လျက်…မစွမ်းနိုင်`。译文按文意译成“不是比丘的人”，方向是对的。
- **建议**：译文保留，降低该句的 confidence，并把这一处登记到 known-issues 的“OCR / 原文问题”。

## §2339–2340 句 211-2339-2-11 / 211-2340-2-11
- **问题**：背景补出不足。
  1. “光大他的教法”中的“他”指弥勒佛。这首偈是从《阿毗达摩义广释》里截出来的，读者没有上下文，看不出“他”指谁。nissaya：`တဿ ဘဂဝတော`。
  2. “舍利所生的那一位”读者无法理解。nissaya 释为 `ဆရာမြတ်ဖြစ်သောသာရိပုတ္တရာထေရ်မဟာ`，即作为老师的舍利弗大长老，也就是《律摄》的作者本人，不是佛陀的弟子舍利弗。
- **建议**：“他的教法”改为“那位世尊的教法”。“舍利所生的那一位”改为“舍利所生者（Sārisambhava），即舍利弗长老”，再加脚注说明这是《律摄》作者，以免与佛弟子舍利弗混淆。

## §2341 句 211-2341-5-61
- **问题**：语体。“身为一位佛的弟子的圣者”连用两个“的”，读起来拗口。
- **建议**：改为“已经是某一位佛的弟子的圣者”，或“作为某一位佛的弟子的圣者”。

## §2342 句 211-2342-2-29 / 211-2342-30-58
- **问题**：误译省略起点。iminā … pe … 是从父层 1665 的 iminā（由这部著作）开始省略的，译文却写成“凭着这些……乃至……”，把 1666 的 etena puññakammena 提到了前面。
- **建议**：两句都改为“由这部著作……乃至……”。
- **问题**：与 nissaya 的分歧（仅记录）。§2342-2 这一种串解把 paṭhamaṃ phalaṃ 重新解释为“前面所说的果报（ānisaṃsa）”。nissaya 仍释为须陀洹果，还多出原文里没有的 labhitvā。这一种串解的用意正是避开“第二生就证初果”的难题，所以译文按原文取“果报、利益”是对的，不需要改。

## §2347 句 211-2347-2-7
- **问题**：句法。“坐落于铜洲国（Tambadīpa）的，有一座……”中，“的”字结构悬空，句子不通。
- **建议**：改为“在缅甸国土中的铜洲国（Tambadīpa），有一座名叫宝城（Ratanapura）的城市”。

## §2370 句 211-2370-2-7
- **问题**：背景补出不足。§2364–2368 用第三人称介绍三藏庄严长老，§2370 的 sohaṃ（so ahaṃ）是作者表明“这位长老就是我”。只译一个“我”，读者看不出前面那位长老就是作者本人。
- **建议**：改为“这位长老就是我。我受到有惭愧心、戒行端严的比丘们的恳请，”

## §2376–2377 句 211-2376-2-8 / 211-2377-2-6
- **问题**：背景补出不足。kaliyuga 在缅甸文献里指缅历（Sakkarāj）。一〇〇九年相当于公元 1647 年，正与佛历 2191 年相合。直接译成“迦利纪年”，读者会理解成印度的迦利时代。另外，原文的年份是用“物数词”（rūpa=1、chidda=9 等，倒读）写成的，译文直接换算成了数字，没有交代。
- **建议**：正文可以保留，但要加脚注：“原文用物数词纪年；此处 kaliyuga 指缅历，一〇〇九年即公元 1647 年。”
