# Review — 211:2255-2266（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 部分缺（2256 句 39-54、55-99、100-111、112-136、137-162 只有巴利切分，没有缅文释义）／义注 ❌ **父层对照错配**
>
> **父层错配，须先处理**：注入的父层是 208:1631-1633，内容是“四大准则”（mahāpadesa，《大品》305）。本 chunk 的复注注的是《大品》267 药犍度里煮油、发汗、放血、涂脚油、疮病这几节的义注。两者没有对应关系，本 chunk 所有黑体被解释词（atipakkhittamajjāni / aṅgavāto / sambhārasedaṃ / mahāsedaṃ / bhaṅgodakaṃ / udakakoṭṭhakaṃ / pabbavāto hoti / pajjaṃ abhisaṅkharituṃ / tilakakkena attho / kabaḷikaṃ / sāsapakuṭṭena / vaḍḍhamaṃsaṃ / loṇasakkharikāya chindituṃ / vikāsikaṃ / sabbaṃ vaṇapaṭikammaṃ / sāmaṃ gahetvā）**都无法与父层逐字比对**。下面只核对了本层内部的一致性（黑体与同段经文引语的译法是否一致）。父层配对需要在 `plan_scan` / `layers.py` 一侧排查，排查后重审被解释词这一项。
>
> 唯一可比的重叠是 lohatumba / kaṭṭhatumba / phalatumba：父层译“铁壶、木壶和果壳壶”，本层译“铁壶、木壶、果壳壶”，用词一致。

## 跨段一致性
- **vaṇa**：2264 与 2265 各处都译“伤口”（vaṇamukha、vaṇabandhanacoḷa、vaṇapaṭikamma、vaṇaruhanatela），唯独 vaṇatela（2265 句 65-88）译“疮油”。“疮”在本 chunk 已经用来对应 gaṇḍa（疮病）。→ 建议 vaṇatela 统一译“伤口油”，“疮”只留给 gaṇḍa。
- **abbhañjana**：2256 句 112-136 中，经文引语译“涂身油”，同句的复注正文译“涂身用的油”。→ 建议统一为“涂身油”。
- **tumba**：父层 208-1633 译“三种水壶”，本层 2256 句 137-162 译“三种壶”。本层语境是装油，用“壶”合理，这里只记录，不必改。
- **pac-**：telapāka 译“煮油”，pacitabba（2262、2265）译“熬制”。语境都是熬药油，可以接受，统稿时可考虑统一为一个动词。

## §2256 句 211-2256-112-136
- **问题**：用词 — adhiṭṭhātuṃ 译“确定为”。这里的意思是把这种油改作涂身之用，“确定”读起来不明所以。
- **建议**：改为“指定为涂身油”，引语和正文同改，正文同时统一为“涂身油”（见上）。

## §2258 句 211-2258-88-113
- **问题**：风格 / 翻译腔 — “再用抹了油的身体躺在上面”，“用……身体躺”是照搬具格 telamakkhitena gattena 的结构。
- **建议**：改为“在身上抹油后躺在上面，翻来覆去地让身体出汗”。

## §2258 句 211-2258-155-180 / 211-2258-181-197
- **问题**：术语所指 — udakakoṭṭhaka 译“热水槽”偏窄。复注的解释是“在 udakakoṭṭha（浴房）里把缸或槽装满热水，进去发汗”，可见 koṭṭhaka 指的是房间，缸和槽只是房间里的器具。nissaya 也释为 `ဥဒကကောဋ္ဌကံ= ရေချိုးရုံ`（浴房）。另外，解释句里的“浴水间”不是通行词。
- **建议**：被解释词与经文引语统一译“浴房发汗”（或“热水浴房”），解释句写成“在浴房里把缸或槽装满热水……”。两处必须同步修改，保证黑体与引语逐字相同。

## §2262 句 211-2262-51-71
- **问题**：被解释词格式 — 原文把 **Tattha** 也标成了黑体（应是排版讹误），译文跟着把“这里”放进了引号和黑体：“**这里，调制足药**”。“这里”不是被解释词。
- **建议**：改为：这里，“**调制足药**”，意思是……
- **问题**：句法 — “用来使裂开的脚恢复正常的东西，就是在椰子壳等里面……”，主语和判断结构没有对上原文（taṃ … pajjaṃ abhisaṅkharituṃ）。
- **建议**：改为“意思是：在椰子壳等里面放入各种药物，调制能使裂开的脚恢复正常的足药，也就是熬制适合双脚的药。”
- **分歧记录**：nissaya 把 pajja 释为“裂开的脚”（ကွဲသောခြေ），即“修治裂脚”。复注本身把 pajja 解释为药物，以复注为准，现译“足药”不改。

## §2265 句 211-2265-65-88
- **问题**：术语 — vaṇatela 译“疮油”，与全 chunk 的 vaṇa=伤口不一致。
- **建议**：改为“比丘们，我允许伤口油”。

## §2266 句 211-2266-2-22
- **问题**：取义偏宽 — daṭṭhavisa 是“被咬所中的毒”，译成“中了毒”就丢掉了“被咬”这一层。本句的意思是：被蛇以外的东西咬伤中毒，同样可以自己取用；其他原因（如误食中毒）则必须经过受取。译“中了毒”会让读者以为任何中毒都适用。
- **建议**：改为“如果被别的东西咬伤中毒，也可以自己取来服用”。

## OCR / 原文疑问（只记录，不改）
- 2264 句 125-148：`kuṇḍavatī` 疑为 `kaṇḍuvatī`（发痒）之讹，nissaya 也随讹释为“菌状”。译文按“发痒”译，取义正确。
- 2264 句 46-67、68-74：nissaya 把 tila 释为“芥子”（မုန်ညင်း），并把 piṭṭhehi / tilehi 拆成“粉”和“油”两样，与复注“磨碎的芥麻”不合，属于 nissaya 本身的误释。译文“磨碎的芝麻”正确。
- 2262 句 51-71：黑体范围包含了 Tattha，见上。
