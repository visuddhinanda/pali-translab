# Review — 211:1596-1605（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§1597–1599 羯磨文只有分词，没有缅文释义；§1601、§1602、§1605 有几处释义疑似误析，见文末）／父层义注对照（book=208 §932–937）✅
> 本层是复注，父层义注既作被解释词的对齐基准，也作释义标准。

## 被解释词对齐（与父层逐字比对）

逐条比对了所有黑体词：Tumhākan / Kimhī / Kimhi nampi na jānāsī / Nāssa anuyogo dātabbo / Kimhi naṃ nāmā / Tassa nayo dātabbo / tassā / kimhi-naṃ-padānaṃ / Kimhi nan / alajjīniggahatthāya…paññattan / Ehitī / Diṭṭhasantānenā / Alajjissa paṭiññāya eva kātabban / Tadatthadīpanatthan / atthapaccatthikā / Saññaṃ datvā / Vinicchinituṃ ananucchaviko / Tathā nāsitakova bhavissatī / Ekasambhogaparibhogā / Viraddhaṃ hotī / Ādito paṭṭhāya alajjī nāma natthī / Paṭiññaṃ na detī / Ṭhāne na tiṭṭhatī / vinicchayo na dātabbo。

结果：**全部与父层译文逐字一致，没有必改项。** 以下两处需要说明：

- **kimhi naṃ** 在父层本身有两种译法：§933 译“根据什么举他”，§934 译“在哪一方面举他”。本层 §1601、§1602-72 跟随 §933，§1602-15 跟随 §934，对应关系都正确。父层的不统一应当在 harmonize 阶段回到父层处理，本层不要擅自改动。
- **ehiti**：父层把它并进了“会借此强压对方”，本层黑体“会”与父层一致。但本层的解释是“ehiti 即 eti（来）”，读者看到的却是“会就是‘来’”，见下文 §1602 句 211-1602-107-119。

## 跨段一致性

- **paṭiññā**：本 chunk 一律译“承认”。§1605-79 指的是同党的 paṭiññā，而父层 §937 把同一处（tesaṃ paṭiññāya）译成“担保”。本层若译“承认”，就与父层对不上，而且意思也错了，因为同党并没有承认过失。建议这一处改为“担保”，依据是父层 §937 的译法。
- **cuditaka**：本层统一译“被举者”，与父层 §932、§933 一致。父层 §935 写“被举罪的那个人”，§937 写“被举罪者”，这是父层自身的差异，本层不受影响。
- **引号层级**：§1596–1600 与 §1601 两处的引号开合没有对上，见下文对应条目。

## §1599 句 211-1599-2-27
- **问题**：标点。§1596 开头用“开启了佛陀说的话，羯磨文到 §1599 结束（nissaya 注明“ကမ္မဝါစာပါဠိတော်အနက်လွယ်ပြီ”，即羯磨文到此为止），但译文只用’收了内层引号，外层的“一直没有收。
- **建议**：句末改为“……我就这样记住这件事。’”

## §1600 句 211-1600-2-26
- **问题**：标点。这一句已经回到注释者的口吻，不在佛陀的话里，内部引语应当用顶层双引号。
- **建议**：改为“……宣布“其他人一句话都不要说”，然后……”。

## §1601 句 211-1601-2-8
- **问题**：标点（必改）。巴利原文 ‘‘ 在这里开启了《心义灯》的引文，到 §1601-20-64 的 “dātabbā ’’ ti sāratthadīpaniyaṃ” 才结束。译文开头写成‘**根据什么**’，结果 §1601-20-64 的”没有对应的开引号。
- **建议**：改为“**根据什么**是指在什么事情上。”这样，引文内部 §1601-9-19 的‘根据什么举他’用单引号也就正确了。

## §1602 句 211-1602-87-106
- **问题**：用词。“dummaṅkūnaṃ puggalānaṃ niggahāya”出自制戒十利，属于律文，译成“经文”不准确。
- **建议**：改为“根据‘为了制伏难以调伏的人’等律文”，或者直接写“等语”。

## §1602 句 211-1602-107-119
- **问题**：存疑。注释的对象是 ehiti 这个词形本身（hi 是增音，意思是“将会来”），而黑体“会”是父层的意译，读者会读成“‘会’就是‘来’”，看不懂。
- **建议**：黑体保持“会”不变，括注补出原词字面，例如“**会**（ehiti，字面是‘将来到’）就是 eti（来）……”。父层 §934 把“来”的意思吃掉了，这一点记进父层报告。

## §1602 句 211-1602-146-176
- **问题**：轻微的跨层用语差异。“etaṃ natthi”译为“我没有这件事”，而父层同类说法译作“这也没有”。
- **建议**：可以改为“说‘这件事没有’”，更贴近父层的语气。不改也行。

## §1603 句 211-1603-2-11
- **问题**：添译。kātabbatā-dīpanatthaṃ 中的 -tā 是抽象名词后缀，不是 ādi（等），译文里的“等道理”没有原文依据。
- **建议**：改为“……也只能依他承认过失的承认来处理这一点”。

## §1603 句 211-1603-26-39
- **问题**：风格。“就此而说的”偏文。
- **建议**：改为“是针对这一点说的”。

## §1604 句 211-1604-2-18
- **问题**：术语。liṅganāsanā 是三种驱摈之一，在本 chunk 首次出现，按 style.md 应当夹注巴利原词。
- **建议**：改为“形相驱摈（liṅganāsanā）”。

## §1605 句 211-1605-10-30
- **问题**：释义分歧。nissaya 把 karaṇavacanaṃ 解作“ကရိုဏ်းဝိဘတ်”（具格），但这里注释的是一整句话，按具格讲不通。译文取了“说明原因的话”（相当于 kāraṇavacana），这个取义合理。
- **建议**：保留现译。疑似是 kāraṇa/karaṇa 的讹写，记入已知难点。

## §1605 句 211-1605-79-100
- **问题**：误译（必改）。pakkhikānaṃ paṭiññāya 指的是同党出面担保（父层 §937 原文“tesaṃ paṭiññāya”，译“凭他们的担保”），译成“同党的承认”会让读者以为同党承认了过失。
- **建议**：改为“以前的诤事虽然凭他同党的担保而平息了……”

## OCR / 原文疑问（记录，不改）
- §1603-12：本层作 **attha**paccatthikā，父层 §935 作 **atta**paccatthikā，两本异读。本层的注释（vivādavatthusaṅkhāte atthe）支持 attha。
- §1605-10：karaṇavacanaṃ 疑为 kāraṇavacanaṃ，见上。
- nissaya 误析：§1602-43 把“Na hi bālo… sakkoti”析成“不是愚人吗……能够”，否定落错了位置；§1602-146 把 niratthakatta-āpattito 拆成“āpatti（犯）”；§1601-65 第一个 pucchā 后多出“na hoti”。这几处译文都按巴利原文译出，是正确的，不必跟着 nissaya 改。
