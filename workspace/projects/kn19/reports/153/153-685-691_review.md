# Review — 153:685-691（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／义注 ✅（本文 mūla 的义注，来自 book 121）／nissaya ❌（本次未提供，词级核对从略）

## 跨段一致性
- **被解释词与义注黑体不一致（必改）**：
  - **tikkhindriya / majjhindriya / mudindriya**：本文译“利根的人／中根的人／软根的人”，义注 §652 引作“**为利根的人开示出离**”，一致。
  - **Mudukaṃ / Mudutikkhaṃ**（§685）：本文“柔和的／柔和兼锐利的”，义注同，一致。
  - **Saṃkhittena / saṃkhittavitthārena / vitthārena**：本文“简略的教诫／简略兼详细的方式／详细的方式”，义注同，一致。
  - **Yaṃ ettha ñāṇaṃ**（§686）：义注 §653 为“**在这里……这种智**”，本文为“在这里……了知……这种智”，基本对应，见下条。
  - **dibbacakkhu**：§688 译“天眼”，§689 也译“天眼”，一致。
- **kappa 系列**：§687“许多坏劫、许多成劫、许多坏成劫”对应义注 §656“坏劫／成劫”，一致；但 §688、§689 的 **kappakoṭi 译“俱胝劫”**，义注 §668 译“俱胝劫”，一致。
- **“眷属”“力”“根”**：§685 与义注 §651 一致。
- **同一句式“在这里，世尊……”重复**：§685 全部用“在这里，世尊”，语体统一，无问题。
- **“具足”**：§688 与 §689 的 samannāgata 均译“具足”，与义注 §662“具足”一致。
- **§688 与 §689 的 “saggūpagesu…pasādena vā” 一整段**：两处译文相同，一致。

## §685 句 153-685-2-37
- **问题**：句法与取义 — 译文“依它们的软、中、强，就有：这是软根的人，这是中根的人，这是利根的人。”
  - 原文 mudindriyo / majjhindriyo / tikkhindriyo 的顺序是“软、中、利”，译文顺序一致，没有问题。但“mudumajjhādhimattatā”中的 **adhimatta** 义注 §651 解释为“强，也就是有力的，称为‘利’”，译文取“强”，可接受。
  - **义注**（§651）：“**Mudumajjhādhimattatā**：不明晰的是软，不太明晰的是中，非常明晰的是强。”译文没有体现“明晰”这一释义，属于信息缺省而非错误，不必改。
- **建议**：可保留原译。

## §685 句 153-685-55-73
- **问题**：取义 — 译文“为利根的人开示柔和的说法，为中根的人开示柔和兼锐利的说法，为软根的人开示锐利的说法”。
  - 与原文对应，且与义注 §652 一致。注意**这里 mudu 是“柔和”，而前句的 mudindriya 是“软根”**，同一词根 mudu 在两处分译为“柔和／软”，是义注的区分（义注 §651 的 mudu 是“软”，§652 的 mudukaṃ 是“柔和的”），建议保持，不必统一。
- **建议**：无需修改。

## §686 句 153-686-2-37
- **问题 1（取义）**：原文 hetuso ṭhānaso anodhiso 译“依原因、依处所、毫无限制地”。**anodhiso** 意为“无界限、不加区分”，译“毫无限制地”可以。但“依处所”中 **ṭhāna** 在十力语境里通常译“处”（是处／非处），此处与第一力的“处”有关；建议核对 `terms.md`（当前为空）后统一。属存疑，非必改。
- **问题 2（句法）**：“应当在这个时候、用这样的教诫来教导”——原文 imāya velāya imāya anusāsaniyā 并无“应当……来教导”的情态成分，也无“教导”的动词。
  - **义注**（§653）：“在这个时候，就是在这个时机；用分为软、中、利这样的教诫。”义注只是解释这两个词，没有补出“应当教导”。
  - 译文中的“应当……教导”是译者补出的，原文是对 bhūmiṃ bhāvanañca gato 的并列修饰（这个人已经达到这样的地与修习，在这个时候，以这样的教诫……），属于过度补充，**建议改为**：“这个人已经达到这样的地与这样的修习，（适合）在这个时候、用这样的教诫（教导）”——或者更保守：“……在这个时候，借这样的教诫，具有这样的界……”。需与 nissaya 对照后定，此处存疑。
- **问题 3（引号）**：开头引号 “ 与结尾 ”——译文中 “这个人已经达到……这是他的随眠。” 之后接“——这种智，称为……”，引号闭合正确。
- **问题 4（术语）**：indriyaparopariyattavemattatā 译“诸根高下差别”，与义注 §653／§654 一致。

## §687 句 153-687-2-8
- **问题**：主语补出 — “这样，在这里，世尊随念种种的宿住。”
  - 原文 iti tattha yaṃ anekavihitaṃ pubbenivāsaṃ anussarati，**没有显式主语 bhagavā**。译文补出“世尊”。
  - **义注**（§655）：“凡是世尊以随念种种宿住的方式所具有的智……”，义注明确主语是世尊，补出有据。
  - 但原文有关系代词 **yaṃ**（“凡是……”），义注指出它与“这是如来的第八力”相连（“yaṃ…idaṃ aṭṭhamaṃ tathāgatabalanti sambandho”）。译文把 yaṃ 吞掉，整句成了独立陈述，没有交代它与第八力的联系；而 §689 末句“这是世尊的两种智……就是如来的第八力与第九力”才出现力。
- **建议**：可保留，但在报告里记一笔：本句的 yaṃ 与第八力的连接在译文中不显。如要修，可译为“这样，在这里，凡是世尊随念种种宿住的（智），……”。优先级低。

## §687 句 153-687-47-60 / 153-687-61-82
- **问题 1（引号）**：§687-47 以 “ 开头，但整段引语到 §687-61-82 末尾才以 ” 结束，中间跨 chunk 行，**引号在本行内没有闭合，是跨句引语，可以接受**。
- **问题 2（取义）**：Tatrāpāsiṃ 译“我在那里也曾名字是这样……”，语序别扭，**不通顺**。
  - **义注**（§656）：“或者是说：我在那个生存或那个众生类别中也曾存在过。”（tatrāpi bhave vā sattanikāye vā ahosiṃ）
  - 译文“我在那里也曾名字是这样”把 āsiṃ（曾存在）与 evaṃnāmo 硬拼成“曾名字是这样”，不合现代汉语。
- **建议**：改为“我在那里也曾存在，名字是这样，种姓是这样，容貌是这样，食物是这样，所感受的苦乐是这样，寿命的极限是这样；我从那里死去，生到了这里。”
- **问题 3（句法）**：“这样，连同相貌与名称，随念种种的宿住。”原文 sākāraṃ sauddesaṃ 译“连同相貌与名称”。
  - **ākāra** 义注 §656 解释为“忆念的方式”（saraṇākāra），且 uddesa 在 §652 义注里是“标举”。此处 sākāraṃ sauddesaṃ 通常指“连同行相、连同提示（名称等细节）”，“相貌”易被误解为外貌。**建议**改为“连同行相与名称”或“连同种种细节与名称”。存疑，需义注/nissaya 进一步确认。
  - 另，本句主语再度缺省，与 §687-2 相同，随前句，可接受。

## §688 句 153-688-2-80
- **问题 1（句法，必改）**：本句译文结构混乱。
  - “这个人的贪等强盛，无贪等微弱；这个人的无贪等强盛，贪等微弱；或者哪些强盛，或者哪些微弱”——原文 ye vā pana ussannā ye vā pana mandā 是“或者那些强盛的、或者那些微弱的”（指代前述的法），译文“或者哪些强盛，或者哪些微弱”读来像疑问，**应改为“或者无论哪些强盛，哪些微弱”**，或“或者，凡是强盛的、凡是微弱的”。
  - “这个人的这些根已经积集，这个人的这些根还没有积集”——与 §689 的对应处一致；但本句末尾“由于这样的放逸或这样的净信”前缺少谓语，整句**没有主干动词**，读者不知道在说什么。原文本来也是承接上一段（该句是第八第九力的开场，其谓语在下一句 anussaranto…jānāti），译文把“是在某个俱胝劫……当中”硬插成判断句，易误解。
- **建议**：将“是在某个俱胝劫，或……片刻当中，由于……”改为“（这些根）是在某个俱胝劫、或十万劫……或片刻之中，由于这样的放逸或这样的净信而（积集的）”，把“积集”补回谓语位置；译者需再核对原文断句。
- **问题 2（术语）**：“趣向天界的众生”saggūpagesu 译“趣向天界”，而 manussūpagesu 译“趣向人间”，与义注 §668“用‘善趣’一词也包括了人趣，用‘天界’一词则只指天趣”一致，无问题。
- **问题 3（术语）**：antarakappa 译“中间劫”，upaḍḍhakappa 译“半劫”，saṃvacchara 译“一年”，可接受。

## §688 句 153-688-81-134
- **问题 1（被解释词，必查）**：与义注 §661–§662 黑体对照：
  - **Hīne / Paṇīte / Suvaṇṇe / Dubbaṇṇe / Sugate / Duggate**：本文译“低劣的、胜妙的，好看的、难看的，善趣的、恶趣的”，义注依次为“低劣的／胜妙的／好看的／难看的／善趣的／恶趣的”，**逐字一致**。
  - **Yathākammūpage**：“随着各自的业而去”，一致。
  - **Kāyaduccaritena samannāgatā**：“具足身恶行”，一致；**Ariyānaṃ upavādakā**：“毁谤圣者”，一致；**Micchādiṭṭhikā**：“持有邪见”，一致；**Micchādiṭṭhikammasamādānā**：“受持邪见的业”，一致。
  - **Kāyassa bhedā / Paraṃ maraṇā**：“身体坏灭／死后”，一致。
  - **Apāyaṃ duggatiṃ vinipātaṃ nirayaṃ**：“苦界、恶趣、堕处、地狱”，与义注 §666 “苦界／恶趣／堕处／地狱”一致。
  - **Cavamāne upapajjamāne**：“死去、出生”，一致。
  - **Upapannā**：本文“生到了”，义注 §667“生到了”，一致。
  - **Atikkantamānusakena**：“超越常人”，一致；**visuddhena**：“清净”，一致。
  - 结论：本句被解释词与义注黑体无不一致。
- **问题 2（句法）**：“世尊随念那一个个的生存，毫无遗漏地了知”——“那一个个的生存”taṃ taṃ bhavaṃ 译得生硬，建议“世尊随念各个生存，毫无遗漏地了知”。属润色。
- **问题 3（句法）**：本句 “看见众生死去、出生，低劣的、胜妙的……” 与“了知众生随着各自的业而去”之后，引语以“诸位，……”开启，开引号 “ 在“诸位”前，结尾是句号而无闭引号，**引语在 §689 句末闭合**，跨段合理。
- **问题 4（文言）**：无明显文言。

## §689 句 153-689-2-75
- **问题 1（引语闭合与结构，必改）**：译文“……生到了善趣、天界。”在“天界”之后以 ” 闭合，随后“在这里，在趣向天界的众生……”接续，结构正确。
- **问题 2（术语）**：原文 **sugatiṃ saggaṃ lokaṃ** 译“善趣、天界”，**丢掉了 lokaṃ（界）**。
  - **义注**（§668）：“这一切都以毁坏、崩坏的意义而称为**界**（loka）”，并把 sugati、sagga、loka 分别解释。译文“善趣、天界”漏了 loka，**漏译**。
  - **建议**：改为“生到了善趣、天界、世间”——注意义注 §668 的译文把 loka 译成“界”，若按义注逐字则为“善趣、天界、界”，读来不通；建议用“善趣、天界、世间”，并在报告中记：义注译“界”，与本文译法需统一，待 `terms.md` 定案。
- **问题 3（对称）**：与 §688 的“苦界、恶趣、堕处、地狱”相对，本句正面一组应当是“善趣、天界、世间”三项，**译文仅两项，不对称**，印证漏译。
- **问题 4（句法）**：“这个人在某个俱胝劫积集了这样的业”，与 §688 对应处不同——§688 是“这个人的这些根已经积集”，此处 kammaṃ upacitaṃ 是“业积集”，译文各自对应原文，无问题。末尾 “由于这样的放逸或这样的净信。”同样缺谓语，**与 §688 同一问题**，应同步修。

## §689 句 153-689-76-87

- **问题 2（术语）**：“宿住随念智与天眼，就是如来的第八力与第九力”，与义注 §668“第八力与第九力”一致。**注意**：原文 dibbacakkhu 在此作“天眼”，而义注 §668 对应处说的是“第八力与第九力智的作用”，其中第九力实指“死生智”（cutūpapātañāṇa），原文径称 dibbacakkhu，译文照译，无问题。

## §690 句 153-690-2-23
- **问题 1（被解释词，必改）**：义注 §669 的黑体：
  - “**在菩提树下降伏了魔**”（Nihato māro bodhimūle）——本文译“在菩提树下降伏了魔”，一致。
  - “**这是世尊的第十力**”——本文“这是世尊的第十力”，一致。
  - “**一切漏尽智**”（sabbāsavaparikkhayaṃ ñāṇaṃ）——本文“一切漏尽智”，一致。
  - “**世尊已经获得一切知性**”（义注引 yaṃ sabbaññutā pattā）——本文“世尊已经获得一切知性”，一致。
- **问题 2（句法）**：“生起了无尘、离垢的一切知智”——原文 virajaṃ vītamalaṃ uppannaṃ sabbaññutañāṇaṃ，意思是“无尘、离垢的一切知智生起”，译文可接受。
- **问题 3（取义，存疑）**：译文把“已经获得一切知性，已经了知一切法，生起一切知智，降伏魔”全部并列为世尊的行为，再说“这是第十力，即一切漏尽智”。
  - **义注**（§669–§670）特别强调：**第十力漏尽智与一切知智不是一回事**（“十力智是一回事，一切知智是另一回事”）。译文“这是世尊的第十力，即一切漏尽智”中“即”字没有问题，但前面铺陈的“一切知智”可能让读者误以为第十力就是一切知智。**这是原文结构所致**，译文无须改动，但在评审时记一笔：义注 §670 明确驳斥“十力只是一切知智之分类”的说法，译文断句应避免暗示这一点。
- **建议**：保持现译，不改。

## §691 句 153-691-2-5
- **问题 1（句法）**：Niyutto vicayo hārasampāto 译“抉择理趣（vicaya）的会合讲述完毕”。
  - 原文 **niyutto**（已结合/已完成）、**vicayo hārasampāto**（“抉择”与“理趣会合”，指 Vicaya 与 Hārasampāta 两个章节）。**义注**（§672）：“**抉择理趣会合的解释完毕**”。
  - 译文只在“vicaya”处夹注，而“抉择理趣的会合”把 vicaya 与 hāra 两个概念合并成“抉择理趣”，**hāra（理趣）与 vicaya（抉择）的对应不清**。
- **建议**：与义注 §672 逐字一致，改为“抉择理趣会合完毕”，或：“抉择（vicaya）与理趣会合（hārasampāta）完毕”；“niyutto”译“完毕”即可，“讲述”属于补出，可去。**需与 `terms.md` 定译后统一。**
