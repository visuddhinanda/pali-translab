## 被解释词与父层逐字对照

对照父层 153 译文，以下黑体词不一致或需核查：

- **anantaṃ**：父层偈颂 153-437「anataṃ」（`asaṅkhataṃ anataṃ`）译作“无倾向”；本层 121-477-15-20 黑体为 anantaṃ，译“无倾向”，字面一致。但本层释文“没有终结、没有毁灭”与“无倾向”不相应（ananta 释为 na anto），**译文自相矛盾**：黑体沿用父层“无倾向”无误，释文则应保持原义。见下方 §477 句 121-477-15-20。
- **sāro / maṇḍo / uddhāro / esikā / pasūnaṃ surabhi**（§481）：父层 153-448 译“众生的精华、众生的醍醐、众生的救拔者、众生的柱石、众生的芬芳花朵”，本层黑体与之一致，通过。
- **uttamaṅgopasobhanaṃ**（121-482-2-10）：父层 153-449 原文为 `uttamaṅgopasobhaṇatāya`，父层译“因为它能庄严头顶”，本层黑体译“庄严头顶”，一致，通过。
- **nidhānañca sīlaṃ sabbadobhaggasamatikkamanaṭṭhena**（121-482-11-26）：父层译“戒是宝藏，因为它能让人超越一切厄运”，本层引文一致，通过。
- **sippaṃ / dhaññaṃ / dhammavolokanatāya / volokanaṭṭhena / sabbabhūmānuparivatti**：父层译“技艺”“谷物”“照见法”“眺望”“随顺一切地”，本层黑体一致，通过。（父层“戒是镜子，因为它能照见法”，本层“照见法”对应，通过。）
- **jeṭṭhaṃ**（121-480-31-37）：父层 153-444 译“最尊”，一致。
- **leṇaṃ / tāṇaṃ / araṇaṃ / anaṅgaṇaṃ / akācaṃ / vimalaṃ / dīpo / sukhaṃ / appamāṇaṃ / patiṭṭhā / akiñcanaṃ**：与父层 153-445/446 一致。其中 **akācaṃ**：父层偈颂原文 `akāca`，译“无瑕”，一致。
- **saccaṃ / pāraṃ / nipuṇa / sududdasaṃ / ajajjaraṃ / dhuvaṃ / apalokitaṃ / anidassanaṃ / nippapañcaṃ / santaṃ**：与父层 153-437/438 一致。
- **amataṃ / paṇītaṃ / sivaṃ / khemaṃ / taṇhakkhayo / acchariyaṃ / abbhutaṃ / anītikaṃ / anītikadhammaṃ**：与父层 153-439/440 一致。
- **ajātaṃ / abhūtaṃ / anupaddavaṃ / akataṃ / asokaṃ / visokaṃ / anupasaggaṃ / anupasaggadhammaṃ**：与父层 153-441/442 一致。
- **gambhīraṃ / duppassaṃ / uttaraṃ / anuttaraṃ / asamaṃ / appaṭisamaṃ**：与父层 153-443/444 一致。

**结论**：被解释词与父层逐字相同，无必改项。

## 跨段一致性
- “所缘”“境界”：§477“诸漏的所缘”、§480“智慧的境界”，用法一致，无问题。
- “轮回”：§477“轮回的对岸”、§478“业轮转、烦恼轮转与果报轮转”（vaṭṭa 译“轮转”，saṃsāra 译“轮回”），区分有据，无问题。
- “因为……所以是……”句式全篇统一，无问题。
- 其余无。

## §477 句 121-477-15-20
- **问题**：释义 — “它没有终结、没有毁灭”译的是 anta = vināsa，本身准确，但黑体沿用父层“无倾向”，两者读者无法对应。
- **建议**：被解释词必须与父层一致，故黑体不改；释文可保留，但宜在译文中不加解释地如实呈现。此条为提示，非必改项。

## §477 句 121-477-32-36
- **问题**：原文疑问 — 巴利原文黑体为 `nipuṇa` 且标点错位（`**.**` 被包进黑体），疑似 OCR/排版讹误；译文“**微妙**”无误。
- **建议**：记下，不改。

## §477 句 121-477-9 之类（§479 句 121-479-9-13）
- **问题**：准确性 — “这两个词合起来是说：没有生起。”“两个词”指 ajātaṃ 与 abhūtaṃ，译文未点明，读者易不知所指；原文 `ubhayenāpi` 即“两者”。
- **建议**：改为“这两个词（不生、不成）合起来是说：没有生起。”——注意括号内词须与父层译法一致。

## §478 句 121-478-12-16
- **问题**：准确性 — “没有不吉祥的业轮转、烦恼轮转与果报轮转”：asivānaṃ 修饰全部三轮，译文断句可读成“没有不吉祥的业”，有歧义。
- **建议**：改为“因为没有不吉祥的三种轮转——业轮转、烦恼轮转与果报轮转，所以是**吉祥**”。

## §478 句 121-478-7-11
- **问题**：准确性 — atappakaṭṭhena 译“令人不会满足的意义”，语义含糊；其义为“令人不厌足/越享用越不满足”（atappaka，不使人满足而生厌），传统取义是“使人不生厌足”。
- **建议**：改为“就最上的意义、就令人百看不厌（不会生起满足）的意义来说，是**殊胜**”，并对照义注原文核实。此处拿不准，宜降低该句 confidence。

## §478 句 121-478-36-38
- **问题**：准确性 — anantarāyattā 译“没有障碍”。antarāya 常译“障碍/危难”，与 §479 anupaddavaṃ“无危难”区分尚可；但“没有障碍”与 §479 anantarāyabhāvahetuto 的“没有障碍的原因”一致，通过。无需改。

## §480 句 121-480-38-41
- **问题**：准确性 — “受轮回之苦逼迫的人要藏身其中”：letabbato 指“应当依附/隐入”，译“藏身”略带“躲藏”意，与“洞窟（leṇa）”的庇护义相符，可接受。
- **建议**：可改为“要前往栖身其中”，更中性。非必改。

## §480 句 121-480-66-75
- **问题**：风格 — 同一黑体 appamāṇaṃ 两个释义，译文各重复“是**无量**”，忠实原文，无问题。

## §480 句 121-480-80-87
- **问题**：准确性 — “因为没有贪等障碍”：kiñcana 作“障碍”不妥，kiñcana 在此指“贪等所有物/烦恼的牵挂”，与黑体 akiñcanaṃ 的“无所有”对应；父层译“无所有”。“障碍”会与上文 antarāya（障碍）混淆。
- **建议**：改为“因为没有贪等烦恼的牵挂，也没有执取，所以是**无所有**”。

## §481 句 121-481-19-24
- **问题**：风格 — “正是凭着精华功德，应当从众生中被拔举出来”语序拗口，且“被拔举”略显生硬；原义为“因其精华功德，应从众生中被提拔出来”。
- **建议**：改为“因为凭着精华功德，应当被从众生中拔举出来，所以是**众生的救拔者**”。（注：“救拔者”按 uddhāro 的传统理解，义注此处实为“被拔举者/杰出者”，译文取了父层的“救拔者”以保持被解释词一致，这是合规的。）

## §481 句 121-481-29-35
- **问题**：风格 — “因为功德光彩而芬芳”略生硬。
- **建议**：改为“因为功德的光彩与芬芳，所以是**众生的芬芳花朵**，意思是众生中芬芳的花”。非必改。

## §482 句 121-482-2-10
- **问题**：准确性 — “慧是头顶”：uttamaṅga 为“最上之肢＝头”，此处以头比喻慧，译文可保留，但读者不易理解为比喻。
- **建议**：改为“在各种功德中，慧如同头顶”。非必改。

## §482 句 121-482-11-26
- **问题**：准确性 — 释文“没有什么功德是求不到的”译 anijjhantā，意为“不成就的”，译“求不到”稍偏；与下文引《愿经》“愿望能够实现”相呼应，宜用“实现”。
- **建议**：改为“对于圆满持戒的人来说，没有什么功德是不能成就的”。

## §482 句 121-482-27-41
- **问题**：术语 — “《愿经》”：ākaṅkheyyasutta 中部第6经，传统常译“愿经”（元亨寺《希望经》）。此处未在 terms.md 登记。
- **建议**：保持“愿经”，定案后补入 terms.md。另注：此处“中部1.64”为引文页码标记，格式与句 121-482-45-82 一致，通过。

## §482 句 121-482-87-90
- **问题**：准确性 — “应当被当作财富来珍视的东西”：dhanāyitabbaṃ 意为“应被视为财富/应被珍爱”，译文可接受。无需改。

## §482 句 121-482-97-108
- **问题**：准确性 — “七层等楼阁”：sattabhūmakādipāsāde，“七层等的楼阁”，“等”字位置易读成“七层等”，建议调整。
- **建议**：改为“就像站在七层楼阁等高楼上一样”。

## §482 句 121-482-109-114
- **问题**：准确性 — “四地的善法”：catubhūmakakusalassāpi 指“四界（欲界、色界、无色界、出世间）的善”，“地”（bhūmi）在传统译法中多译“地”，但此处读者易与“十地”混淆。
- **建议**：首次出现时可夹注：“四地（四界）的善法”，并核对术语表。非必改。
