# Review — 191:182-208（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层（book=121 译文）✅／nissaya ❌（未提供）／义注 ❌（本层为复注，未另给义注）。本次仅依父层定稿译文核对被解释词，其余按巴利原文与 style.md 审查。

## 被解释词与父层一致性（首要）

本 chunk 复注（191）黑体引自父层 121 §136–139。父层黑体译法：法、近因、范围、加以区分、共通、不共通、应当知道这是区分；所说的、已修习的、已断除的、都转到对立面上；同义语、许多、经中说了、同一法、通晓经的人知道这些、这种方式名为同义语；施设、种种、这种样式、应当知道……这名为施设方式。

- 191-185-5-40：黑体 **法 / 近因 / 范围** 与父层一致 ✅。
- 191-191-5-46：**已修习的**（bhāvite）、**已断除的**（pahīne）、**所说的**（niddiṭṭhe）一致 ✅。**对立面**（paṭipakkhe）：父层 121-137 黑体为“都转到对立面上”，本层作“对立面”，属拆分引用，可接受。**转到**（parivattati）与父层“转到”一致 ✅。
- 191-197-5-44：黑体 **同一法**（ekadhammassa）：父层译“同一法”，本层作“**同一法**”但随后改写为“同一个词义”，黑体部分一致 ✅。**所说的**（vuttāni）父层 121-138 为“经中说了”（sutte vuttāni），本层写作“所说的”——**必改**：黑体 vuttāni 应与父层“说了”对应；建议在 sutte vuttāni 处译为“**经中说了**……”以对齐，并将 **许多** 作为 bahūni 的译法（本层已作“许多”✅）。
- 191-197-5-44：**通晓经的人知道这些**（yo jānāti suttavidū）父层黑体为整句；本层此处拆成“通晓经的人凭……知道”，已不再是黑体原样，读者看不出对应关系。**必改**：至少在 191-196（偈颂）已与父层相同（“通晓经的人知道这些”✅），复注解释处建议保留“通晓经的人”“知道”字样（已有），可不动；但 **同义语** 在 191-197 译为“同义语”✅。
- 191-203-5-34：**一个**（ekaṃ）、**种种**（vividhāhi）与父层“种种”一致 ✅；**这种样式**（so ākāro）父层 121-139 黑体为“这种样式”，本层 191-203 释文用“应当施设的样式”“那种应当施设的样式”，191-202 偈颂中为“这种样式”✅，释文中不黑体，可接受。
- 191-204：**种种施设**（vividhāhi paññattīhi）与父层 121-139“种种”+“施设”一致 ✅。
- 191-197-5-44 **施设方式 / 区分方式 / 同义语方式 / 反转方式**：父层 121 译“反转方式”“同义语方式”“施设方式”“区分方式”，本层一致 ✅。

## 跨段一致性

- **atthayojanā**：§185、§191、§197、§203 均译“这是义理的配合”，一致 ✅。
- **saṃvaṇṇanāviseso**：全 chunk 统一译“解释上的特别方式”，一致 ✅；但 §185 用“以某种解释上的特别方式”，§197 用“凭某种……”，介词“以/凭”混用，建议统一为“凭”。
- **vibhaṅgavāre**：§192、§198 均译“分别部分”，§207 的 **vibhaṅge** 译“分别部分”，一致；但父层 121 对应处称“分别”（如“教说理趣分别”“抉择方式分别”），建议统一为“分别”或明确“分别部分”即指《导论》分别分，保持即可。
- **Netti 书名**：§186 作“《导论》（第33至34段）”，§192 作“（《导论》第35段以下）”，括注格式不一。建议统一为“（《导论》第N段）”。
- **“应当问”句式**：§187、§193、§199、§208 均为“……接着应当问‘什么是……’，因此——”，一致 ✅。
- **名称“入方式”**（otaraṇahāra）：父层未出现，§208 仅出现一次，无冲突。

## §186 句 191-186-2-101

- **问题**：术语 — vāsanābhāgiyā / nibbedhabhāgiyā 译“熏习分 / 抉择分”，“抉择分”易与 vicaya（抉择方式）混淆。 
- **建议**：nibbedhabhāgiya 传统常译“顺抉择分”（通达分）；若全局已有定译请按术语表；否则建议改“顺抉择分”，并在报告中登记。
- **问题**：长句语序 — 末尾“凭这些加以区分的，就名为区分方式”可读，但“应当采用《导论》……的这种区分的做法”稍绕。
- **建议**：改为“应当采用《导论》（第33至34段）中详细展开的区分做法。”

## §189、§190 偈颂

- **问题**：191-189-2-11 “善与不善的法，所说的、已修习的和已断除的。”与父层偈颂风格一致 ✅，无需改。但 191-190 “都转到对立面上”与父层一致 ✅。

## §192 句 191-192-2-53

- **问题**：语体/准确性 — “戒除诸欲，对他们来说是非法”：原文 kāmehi veramaṇī tesaṃ adhammo，前面是“应当享用的诸欲”，“非法”宜明确为“不是法”以免误读为“违法”。
- **建议**：改为“戒除诸欲，对他们来说是非法（不是法）”或“被视为非法”。
- **问题**：“因为将在分别部分中说到，所以这里没有详细展开”主语隐含，读来略断。 
- **建议**：改为“……来说明在对立面上的反转；因为（《导论》）将在**分别部分**中说到，所以这里没有详细展开。”

## §198 句 191-198-2-25

- **问题**：准确性/可读性 — 原文意思是：yo 与 so 两词指代对象可以不同（故先说 yo suttavidū，再说 so saṃvaṇṇanāviseso）。“因为 yo 和 so 这两个词的所指可以不同”是对的，但“凡是通晓经的人”之后“再说……”不自足，且巴利词 yo/so 在译文中未加夹注格式。
- **建议**：改为“这里，yo（凡是）和 so（那个）这两个词所指可以不同，所以先说‘凡是通晓经的人’，再说‘那种解释上的特别方式’。”并按 style.md 对巴利原词用统一格式。

## §198 句 191-198-26-96

- **问题**：术语一致/重复 — 译文中“超越束缚者”出现两次（对应 bandhanātīto 与 bandhanātivatto），读者看不出两词区别。
- **建议**：bandhanātivatto 可译“越过束缚者”，bandhanātīto 保留“超越束缚者”；或在术语表中定译并统一。
- **问题**：“舍离战斗者”（raṇañjaho）与前面“结束了战斗者”（ṭhapitasaṅgāmo）近义重复，属原文如此，可接受；但 raṇa 本义为“过失/烦恼”，建议核对。
- **建议**：将 raṇañjaho 译为“舍离过失者”或标注存疑写入报告，不在译文中加标记。
- **问题**：“应供、正等正觉者……”与 knowledge/term-glossary 的 sammāsambuddha=“正等正觉者”一致 ✅。

## §197 句 191-197-5-44

- **问题**：语序冗长 — “知道在经中对同一法……所说的、确实许多的同义语”中，“确实”对应 eva，但与黑体 **所说的** / **许多** 夹杂，影响阅读，并且 **tu** 与 eva 被译成“确实”，漏掉 tu 的限定义（父层 121-138 明确“tu 表示限定”）。
- **建议**：改为“……凭某种解释上的特别方式，知道在经中对**同一法**即同一个词义**所说的**、**许多**的同义语（这里的 tu 与 eva 都表示限定，意思是只取经中所说、数量众多的同义语）……”

## §204 句 191-204-2-14

- **问题**：术语复合缺空格/断词 — 原文 “nikkhepapaññatti…” 的译法顿号并列正确，但“提出施设、根源施设、遍知施设、断除施设、修习施设、作证施设、灭施设、厌离施设”中 **灭施设**（nirodhapaññatti）与 §207 “作证施设是灭的”并存无冲突。✅无需改。
- **问题**：“以此为特相的解释上的特别方式”结构沿用父层“以此为特相的就是……”，一致 ✅。

## §205–§207 施设分项

- **问题**：术语一致 — nikkhepapaññatti 在 §205 译“提出施设”，§207 末尾“提出施设是闻所成慧的”一致 ✅；pabhavapaññatti“根源施设”一致 ✅；pariññāpaññatti“遍知施设”一致 ✅。
- **问题**：191-205-2-27 “六界”：原文 channaṃ dhātūnaṃ（六界）与 aṭṭhārasannaṃ dhātūnaṃ（十八界）并列，译法无误 ✅。
- **问题**：191-207-2-75 引文引号错位：原文中“pahānapaññatti samudayassa … nirodhassā ’’ ti”整段在一对引号内，译文为“……是苦的**遍知施设**；‘**断除施设**是集的……作证施设是灭的’”，引号开合与原文不对应，且“‘**断除施设**”前的开引号位置在分号之后，结构含混。
- **建议**：重排为：“……是苦的**遍知施设**；‘**断除施设**是集的，**修习施设**是道的，**作证施设**是灭的’；又如‘……’等。”并确认全角弯引号成对。
- **问题**：anaññātaññassāmītindriya 译“‘我将知未知’之根”，传统译“未知当知根”，建议按术语表/传统译法统一为“未知当知根”，在报告中登记。
