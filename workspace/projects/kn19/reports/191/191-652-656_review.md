# Review — 191:652-656（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层对照（book=121）✅／nissaya ❌（未提供）／义注 ❌（本层为复注，未提供更上层义注）。以下以父层译文为被解释词基准，释义依据为巴利原文及父层上下文。

## 被解释词与父层逐字对照（必改项）

- **§652 `okappanalakkhaṇā`**：父层 121-385-103-112 译“**以确信为特相**”，本层 652-2-8 黑体为“**以确信为特相者**”。多出“者”字，不逐字相同。→ 黑体改为“**以确信为特相**”，句子相应调整（如“以确信为特相的信，就是**以确信为特相**的信”，或将“者”移到黑体之外）。
- **§652 `anāvilalakkhaṇo`**：父层 121-385 只出 `Anāvilatā`（**不浑浊**），“以不浑浊为特相”是同一套译法。本层“**以不浑浊为特相者**”带“者”，与上一条同样应去掉“者”。
- **§652 `adhimuttipaccupaṭṭhānā` / `sampasīdanapaccupaṭṭhāno`**：父层无此词，自定。但“以…为现起者”结构应与上两条统一，全部改为不带“者”的形式。
- **§652-41-78 `aveccapasādo`**：父层译“**不坏净**”，本层同，一致 ✅。
- **§652-41-78 `okappanalakkhaṇā saddhā`**：本层“**以确信为特相**的信”，与父层一致 ✅。
- **§652-41-78 `satipaṭṭhānaṃ`**：父层 121-385 “**念处**”，一致 ✅。
- **§653-34-38 `ayonisomanasikārassa`**：父层 121-385 `Yonisomanasikāra` 译“如理作意”，此处“不如理作意”可接受 ✅。
- **§653-34-38 `assādamanasikāra`**：本层“作意于乐味”，父层 121-386-2-7 黑体“**作意于乐味**” ✅。
- **§653-45-132 `punabbhavavirohanalakkhaṇā`**：父层 121-386-8-16 `Punabbhavavirohaṇā` 译“**使再有生长**”，本层“以使再有生长为特相”✅。
- **§653-45-132 `opapaccayika` / `nibbattilakkhaṇaṃ`**：父层“**随缘而生**”“**以随缘而生起为特相**”。本层“被称为**随缘而生**、以受生有的方式**以生起为特相**”，已拆开，黑体“以生起为特相”与父层“以随缘而生起为特相”不同。→ 建议黑体与父层的黑体划分对齐，写作“**随缘而生**、**以…生起为特相**”，并核对父层对应 `Opapaccayikanibbattilakkhaṇaṃ` 是否应整体保留。
- **§653-45-132 `nāmakāyarūpakāyasaṅghātalakkhaṇaṃ`**：父层“**以名身与色身的聚合为特相**”，本层同 ✅。
- **§653-45-132 `chaḷāyatanaṃ`**：本层“六处”；父层 121-385 未出，自定。
- **§654-2-13 `opapaccayikaṃ`**：本层“**随缘而生**”✅。
- **§654-105-117 `odahanakārako`**：父层 121-386-59-62 `Odahanaṃ` 译“**沉重压抑**”，本层“**引起沉重压抑**”黑体多包了“引起”，但 `kārako` 未入黑体，**译文黑体应只含“沉重压抑”**。→ 改为“引起**沉重压抑**”。
- **§654-58-73 `ussukkakārako`**：父层 121-386-55-58 `Ussukkaṃ` 译“**焦虑**”，本层“引起焦虑”一致 ✅（本层未加黑，原文也非黑体）。
- **§654-74-84 `lālappakārako`**：译“引起哀号”，父层无，自定。
- **§655-2-13**：“**有的**”应为被解释词 `Bhavassā`，父层 121-386-63-77 译“有”，本层“有的”可接受。
- **§655-14-24 `bhavaṅgāni`**：父层 121-386-78-85 译“**有支**”✅。
- **§655-14-24 `kileso bhavassa aṅgaṃ`**：父层“烦恼是有的支分”✅。
- **§655-45-67 `niyyānikalakkhaṇo`**：此处译“以出离为特相”，父层无此词，自定。
- **§656 `titthaṃ`**：父层 121-387-2-11 “**渡口**”✅；`titthaññutā` “**懂得渡口**”✅；`pītaññutā` 父层“**懂得饮水**”✅；`pattaññutā` 父层“**懂得钵**”✅；`attaññutā` 父层“**懂得自己**”✅。
- **§656-64-75 `pubbekatapuññatāya`**：父层 121-387-48-64 “**过去曾作福德**”，本层“**过去曾作福德**”✅。
- **§656-2-25 `ñū`**：本层“**知者**”，自定。

## 跨段一致性

- **“者”的有无**：§652 的 `…lakkhaṇā/…paccupaṭṭhānā` 全译作“…者”（以确信为特相者），而 §653、§654 同样的 `lakkhaṇaṃ` 结构一律译“以…为特相的 X”。→ §652 统一为“以…为特相的信/净信”，不用“…者”。
- **`vibhattāni`/`padaṭṭhānaṃ` 译法**：全文一律“近因”，一致 ✅。
- **“俱生”与“依止”**：§653 一致 ✅。
- **`kāyika dukkha`**：§654 译“身体之苦”“身体的苦”，同段两处用字略有出入，建议统一为“身体的苦”。
- **`pītaññutā` 解释**：§656-2-25 译“与法相应的愉悦”后紧接“知饮水者”，§656-26-53 解释更长，两处术语一致 ✅。
- **“业轮转／烦恼轮转／异熟轮转”**：§653、§655 一致 ✅。

## §652 句 191-652-2-8
- **问题**：被解释词 — 黑体“以确信为特相者”与父层“以确信为特相”不一致（多“者”）。
- **建议**：“以确信为特相的信，就是**以确信为特相**的信。”并统一 §652 前四句句式。

## §652 句 191-652-9-16、191-652-17-24、191-652-25-32
- **问题**：同上；且“也是以胜解为现起者”等“者”字读起来像文言/生硬。
- **建议**：改为“以胜解为现起的信，也是**以胜解为现起**的信。”（其余两句同理）。

## §652 句 191-652-41-78
- **问题**：语体 — 整句是一个分号长句，信息密度很高，但没有错。“**以渴望为特相的信**”与父层 `Abhipatthiyanā`（**渴望**）✅。
- **问题（小）**：“因为伴随禅的定以专一为特相，所以寻等诸禅是定的近因”读着清楚，但“伴随禅的定”宜核对 `jhānasahitassa samādhissa` 是否应为“与禅相伴的定”，可保留。

## §653 句 191-653-2-33
- **问题**：语序略拗 — “论师所解析了近因的那些无明等”。
- **建议**：“论师已解析过其近因的那些无明等”。

## §653 句 191-653-45-132
- **问题1**：被解释词 — 见上，“以生起为特相”与父层“以随缘而生起为特相”不对应。
- **问题2**：语体 — “是**受**的近因，即依次是与那六种触俱生的六种**受**的**近因**”句子极长且有重复；“即依次是”这类补释不自然。
- **建议**：断句，如“以眼净色、色所缘与眼识等和合为特相的六种**触**，是**受**的**近因**；即依次是与那六种触俱生的六种受的近因，由于俱生等缘的性质。”`taṇhāya`、`upādānassa` 两处同理。黑体标记的位置也请与原文黑体对齐（原文 `taṃ vedanāya` 的 `taṃ` 未黑体）。
- **问题3**：“结生**识**”——原文 `paṭisandhi viññāṇaṃ`，译“结生识”可接受 ✅。

## §653 句 191-653-133-163
- **问题**：语义 — “或者可能是性的颠倒用法”过于生硬。`liṅgavipallāsaniddeso` 指“性（阴阳）的错位表述”。
- **建议**：“或者是性（liṅga）的错用式表述”，并说明原文用阳性/中性代指阴性；译文也可更白话地写成“或者是把词的性用错了的说法”。

## §654 句 191-654-2-13 至 191-654-35-45
- **问题**：句式 — 一连串“那个……，那个……”是照 `yaṃ…taṃ` 直译，读起来绕且重复，有翻译腔；同时“那个衰**老**是**死**的**近因**”里黑体切在词中间（“衰”未黑体）。
- **建议**：改为“凡是……的取，该取是……”，如“**随缘而生**、能生起受生诸蕴的**取**，是两种**有**的**近因**。”各句同理；“衰老”黑体应整体加粗或统一只加粗 `jarā` 对应的“老”（建议统一规则）。

## §654 句 191-654-46-57
- **问题**：“某人的世俗死……那个死也是他的愁的近因”——`yassa` 与 `tassa` 指同一人，“某人”“他”可，但译文使“愁”像是死者自己的愁。
- **建议**：明确为“某人的世俗死……也是**愁**的**近因**”，可参照父层 121-386-42-54“想到所爱之人的死亡时……生起愁”，注明是活着的人的愁。

## §654 句 191-654-58-73
- **问题**：“因为想到所爱之人的死亡时，大多会生起愁；那个……的愁”，“因为”与分号后句子衔接不畅，主句不明。
- **建议**：“因为想到所爱之人的死亡时大多会生起愁，所以那个对亲属等所爱之人引起焦虑的愁，是**悲**的**近因**。”

## §654 句 191-654-105-117
- **问题**：被解释词 — 见上，“**引起沉重压抑**”黑体应只含“沉重压抑”。另“恼”（`upāyāsa`）与父层一致需另核。
- **建议**：“那个引起**沉重压抑**、即引起煎熬的恼……”

## §655 句 191-655-2-13
- **问题**：“为了说明**‘有的’**中所说的有”，读着别扭；父层 121-386-63-77 用“为了说明这里所说的有”。
- **建议**：“为了说明‘**有的**’一语中所说的有，才说了‘**这些**’等语。”

## §655 句 191-655-14-24
- **问题**：“有支”一句中“烦恼是有的支分，即原因”——`kāraṇaṃ` 作“原因”可，但与父层 121-386-86-90“烦恼是有的支分”相比多了解释，不算错。
- **建议**：保留。

## §655 句 191-655-25-44
- **问题**：“在现在等时间中”——`paccuppannādikāle` 宜译“在现在等时期”；“它们全都和合生起”指有支，译文主语不清。“在‘有的’这里应当看作有”生硬。
- **建议**：“当它们在现在等时期全部和合生起时，那由烦恼轮转、业轮转、异熟轮转构成的法的聚合，在‘有的’一语中应当看作‘有’。”

## §655 句 191-655-45-67
- **问题1**：“**那个**称为有的……三者”——黑体 `Taṃ` 译为“那个”，意义轻，不必黑体。
- **问题2**：“因为由前前各生所形成的烦恼等轮转，使轮回不间断地生起”——父层 121-386-103-108 是“前前各生中所形成的烦恼等轮转是它的原因”，本层逻辑方向（谁使谁生起）应与父层一致，当前译法可接受。
- **问题3**：“使人到达的因”——`sampāpakahetubhāvato` 父层 121-386-118-129 译“使人到达灭的因”，本层缺“灭”的宾语。
- **建议**：改为“因为它是使人到达（灭）的因”。

## §656 句 191-656-2-25
- **问题**：语体 — “多闻者因为是所有弟子等的依靠，就像渡口一样，所以是渡口”较绕；同时“**知者**”“**知渡口者**”是对 `ñū`/`titthaññū` 的字面拆解，可接受。
- **建议**：“多闻者是所有弟子等的依靠，就像渡口一样，所以称为**渡口**”。

## §656 句 191-656-26-53
- **问题**：“这样，通过听闻适宜的法而知道饮水的人，是**知饮水者**”——“知道饮水”不通；父层用“懂得饮水”。`pītiṃ jānāti`（知道喜）这里 `pīti` 作饮水喻，宜说明。
- **建议**：“……通过听闻适宜的法而懂得饮水的人，是**懂得饮水者**……”，或保留“知饮水者”但与上文“知渡口者”同模式，统一。

## §656 句 191-656-60-63、191-656-64-75
- **问题**：“退缩与掉举”与父层 121-387-12-31“退缩和掉举”一致 ✅；但“了知修习中的退缩与掉举，是**懂得自己**的近因”——`pattaññutā` 已在前句译为“懂得钵”，本句主语 `bhāvanāpattajānanatā` 实指“知钵”，译文把它解释成“了知退缩与掉举”，需与前句 `pattaññutā` 的“钵”对应说明清楚（否则读者看不出“钵”与“退缩掉举”的关系）。
- **建议**：参照父层，在首次出现处加简注，或在本句写明“即懂得钵”。

## OCR / 原文疑问

- §652-17-24 `anāvilalakkhaṇo`：原文 `Anāvilaṃ lakkhaṇaṃ yassa pasādassāti` 与 `anāvilalakkhaṇo ti pasādo` 之间格式正常，无讹误。
- §654-35-45 `jiṇṇa jarā`、§654-24-34 `kamma bhavo` 等处，原文中间有空格（`jiṇṇa **jarā**`、`kamma **bhavo**`），属 OCR/排版断词，非讹误，译文勿受其影响而把黑体切碎。
- §653-133-163 `So vedanāyā`/`sā taṇhāyā`：原文这里的“应作”读法，是复注作者对前文 `taṃ` 的校订，非 OCR 问题。
