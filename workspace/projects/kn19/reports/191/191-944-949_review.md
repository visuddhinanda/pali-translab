# Review — 191:944-949（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层对照（book 121 §534-542，已定稿译文）✅／nissaya ❌（缺，词级核对已跳过，格与句法的判断只凭巴利原文）。本层是复注，下文“父层”指 book 121 的义注译文。

## 被解释词与父层逐字核对
- **不一致（必改）**：“资具有什么特相？”（`kiṃlakkhaṇo`）
  - 父层 §535：“就说了“**资具有什么特相？**”等句”。
  - §946 句 191-946-38-57 译“**有什么特相**”，句 191-946-61-98 引义注原文，同样译成“就说了‘有什么特相’等句”，脱了“资具”，句末的“？”也没了。
  - §946 句 191-946-122-149 译“**其中，有什么特相**”，也要同步。
  - 建议：三处统一为父层的写法。其中句 191-946-61-98 是整句引文，应与父层 §535 该句逐字相同，只把外层引号“”换成嵌套的‘’。
- 其余核对一致：
  - “其中，什么是资具导法？”
  - “某一法产生某一法，这个法就是那个法的资具”（句 191-946-61-98 引文其余部分逐字相同）
  - “因以不共为特相”“共通的”“自性是因”“又好比”“这个轮回”
  - “前面的无明是后面的无明的因”“就像种子对芽一样”
  - “无间因”“辗转因”“缠”“随眠”“作意”“资具”“因”“缘”“不共”
- 句 191-947-61-87 引文与父层 §537 逐字相同。

## 跨段一致性
- **资具导法分别 / 资具分别**：§945 句 191-945-53-88 译“资具分别”，同段及标题都是“资具导法分别”。巴利原文确实是 `parikkhāravibhaṅgo`，但读者会当成两个概念。建议在该处写成“资具导法分别”，或加注说明是同一术语的简称。
- **janayati / janeti / nibbatti**：§946 句 191-946-20-37 把 `janayati` 译“产生”、`janeti` 译“生起”，在同一句里并列。父层里 `janayati` 是“产生”，`nibbatti` 才是“生起”。建议 `janeti` 也用“产生”。
- **“叫做”与“称为”**：§945 两句混用（“称为资具导法分别的”“就叫做资具分别”），建议统一为“叫做”。
- “因为需要问/需要说明……所以说了……”的套式前后统一，无问题。

## §945 句 191-945-2-37
- **问题**：误译句法。原文是 `yena yena … vibhaṅgena … vibhattā, so … paripuṇṇo` 这样的关系从句加主句，译文断成了问句：“以哪一种……分别了苦谛等的一体性等等？那种……是完整的。”
- **建议**：改为“凭借哪些作为特殊解释的分别，苦谛等的一体性等已被分别，那些作为特殊解释的分别已经完整；因为需要问‘什么是资具导法的分别？’，所以说了‘**其中，什么是资具导法？**’等句。”

## §945 句 191-945-38-52
- **问题**：“其中，**其中**就是……”叠词生硬。`tatthā` 在这里指“在那些已列举的（十六种导法）之中”。后半句“问：**什么**特殊解释是**资具导法**，也就是称为……”也不通顺。
- **建议**：改为“其中，**其中**是指在那些已经列举的十六种教导导法等之中；问：**什么**特殊解释是**资具导法**，也就是叫做资具导法分别的？”

## §945 句 191-945-53-88
- **问题**：“对于……的说明，现在由我所要说的……”读起来像翻译腔，`niddesa` 与 `vibhaṅga` 的关系不清。
- **建议**：改为“对‘凡是法产生某法’等说明，我现在所要说的‘某一法产生某一法，这个法就是那个法的资具’等，是对作为资具的因和缘所作的详细的特殊解释，这就叫做资具导法分别。”

## §946 句 191-946-236-243
- **问题**：语义不通，需核对原文。“因为是一切果的缘，所以……种子是不共的”，因果颠倒。“一切果的缘”应指共通的缘（地、水等），而不是种子。
- **建议**：补出主语，译成“由于（地、水等）是一切果的缘（所以是共通的），因此对于芽来说，种子是不共的、能生的因”。这一句请与上下文及义注（若可取）再核。

## §946 句 191-946-267-275
- **问题**：“使平等相同的果成为存在”不自然。
- **建议**：`samaṃ samānaṃ phalaṃ bhavāpeti` 可译“使同类的果生成，所以是**自性**”。

## §947 句 191-947-94-109
- **问题**：“意思是：应当这样理解：”两个冒号叠用，啰嗦。
- **建议**：改为“意思是：应当这样理解，因为这个轮回是作为有因缘的而生起的，所以在内在事物中，作为资具的因缘也是合理的。”

## §948 句 191-948-161-172
- **问题**：`bījaṅkuro` 的复合词解释译成了“种子的芽就是种子芽”，是循环解释，与前后“种子对芽”也不连贯。
- **建议**：译成“**种子对芽**——种子和芽合称种子芽；因为种子是**无间因**，所以芽得以生起，**就像**这样”，或按原文复合词拆分意思重写，但黑体“种子对芽”保持不变。

## §948 句 191-948-173-190
- **问题**：`yaṃ phalaṃ` 与 `assa phalassa` 指同一个果，译文“那个果……这个果”读成了两个果。
- **建议**：改为“**在**树等**之中**，生起什么果，对于在那棵树等之中生起的**那个**果来说，**这个**种子则是以**辗转因**的方式作为**因**。”

## §949 句 191-949-63-86
- **问题**：误读句法。“作为种子的不共因，与地、水等共通的缘，其差别是明显的”中的“与”把两项并列成了修饰关系。原文是：种子是不共因，地、水等是共通缘，这个差别很明显。
- **建议**：改为“就像‘作为种子的是不共的因，地、水等是共通的缘’这样的差别是明显的那样，同样，应当这样看待差别：无明随眠是不共的**因**，不如理作意是共通的**缘**。”
