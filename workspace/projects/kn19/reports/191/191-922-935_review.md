# Review — 191:922-935（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／父层对照（book=121 §513-533）✅／nissaya ❌（本次未提供，未核词级格助词）。本层是复注，父层是义注，下文引用父层时标作 **义注**。

## 被解释词与父层逐字核对

黑体词与父层逐字比对，只有一处不同：

- §924（191-924-38-64）：黑体 **tathā dhārayitabbā** 在父层 121-514-13-26 作“**就应当怎样去把握它们**”，本层拆成“**照样**……**把握**”，“怎样”变成了“照样”。
  - **建议**：用字向父层靠拢，例如“应当**怎样**去**把握**”，或把“照样”改成“怎样”。至少“去把握”要与父层一致。
  - §923（191-923-51-82）的引文已经是“就应当怎样去把握它们”，与父层一致，所以同层内也该统一。
- 其余黑体词与父层一致，未发现不同：
  - 其中，什么是确立论式 / 同一性 / 差别性
  - 苦灭 / 苦集 / 道 / 色（以及 §928 的“导向苦灭的道路”）
  - 无明 / 对苦的无知 / 无明门闩 / 痴 / 不善根
  - 明 / 对苦的智 / 择法觉支 / 道支 / 道所摄
  - 简择灭 / 导向地狱的 / 涅槃
  - 无想等至 / 禅修者 / 以慧为主的禅修者

## 跨段一致性

- **sāmaññatā（共相性）**
  - §925、§928、§932、§933、§935 译“共通性”，§929、§930、§931、§934 译“一般的……性”，同一个词两种译法。
  - **建议**：统一为“共通性”（或“……的共相”）。
  - §925（191-925-2-24）的“共相的设想”也属同一组词。父层 121-514 把 sāmañña/visesa 译作“共相与别相”，三者宜统一。
- **visesa 与 vemattatā 都译“差别”**
  - “不考虑生等**差别**”（visesa）与“**差别性**”（vemattatā）同字，读者分不出被解释词。
  - **建议**：visesa 一律改作“特殊点／细分”之类，不用“差别”。与现有的“特殊性”（visesatā）也要对齐。
- **“问……之后，说……”这个套语**
  - §925（191-925-39-57）作“被问到‘…’时，回答说‘…’”（pucchitā），§926-§935 全部作“问‘…’之后，说‘…’”。
  - **建议**：统一成“问……之后，说……”。
- **niddiṭṭha**
  - §923（191-923-35-50）作“已列出”，§923-51、§924 作“指出”。
  - **建议**：统一为“指出”。
- **niddesa**
  - §923（191-923-51-82）的“这一段指示”，对应父层 niddesavāra 的“释分”。
  - **建议**：核对是否同指，同指则与父层统一。
- **父层自身有一处不一致**：121-532/533 里 adhiṭṭhānahāra 译作“依处方式”，121-514 等处译“确立论式”。本层用“确立论式”是对的，建议顺带请父层统一。

## 标题 §922 句 191-922-2-4

- **问题**：漏译 — 标题 Adhiṭṭhānahāravibhaṅgavibhāvanā 含 vibhaṅga（分别），译文“确立论式的诠释”丢了“分别”。父层标题是“确立论式的分别注释”。
- **建议**：改作“确立论式分别的阐释”，或“确立论式分别的诠释”。“诠释”或“阐释”对应 vibhāvanā，全书要统一。

## §923 句 191-923-2-34

- **问题**：可读性 / 结构 — 破折号夹着“通过哪一种……厘清，而那种……是完整的”，层层嵌套，读者难以看出主干。paripuṇṇo 挂在哪个从句上也不清楚，这里理解的把握不大。
- **建议**：先核对巴利语法，再拆成两句，主干为“由于应当问‘什么是确立论式的分别’，所以说了‘其中，什么是确立论式’等”。

## §923 句 191-923-35-50

- **问题**：术语存疑 — paṭiniddesato 译“依逐项解说来说”。paṭiniddesa 是 Netti 里与 uddesa、niddesa 并列的技术词（复述、反释），“逐项解说”未必准确。
- **建议**：核对 Netti 体例后定译，并登记进 `terms.md`。

## §924 句 191-924-38-64

- **问题**：风格 — “即去辨识”里的“即”是文言虚词，属必改项。
- **建议**：改为“也就是去辨识”。
- **问题**：语气 — 191-924-2-37 里 aññathāpi vikappayitabbā 译“也可以另作揣度改动”，原文是 vikappayitabbā（应当），语气偏弱。
- **建议**：改为“还是也应当另作揣度改动”，或“还是可以另作……”并核对语气。

## §925 句 191-925-39-57、191-925-58-58、191-925-59-59、191-925-60-76

- **问题**：结构 — “pe .”被拆成三行，其中 58、59 两行 pali 只有“.”，没有 zh。
  - 开头引号在 39-57 行不闭合，要到 60-76 行才收。
  - 这是原文切分造成的，译文内容没丢，但属“个别句子无译文”的情形，写入后会有空条目。
- **建议**：按坐标逐条回读核对。

## §927 句 191-927-2-23、191-927-24-57

- **问题**：术语混淆 — “对那**同一**渴爱的无余离贪”（tassāyeva taṇhāya）里的“同一”会与“同一性”（ekattatā）撞车，让读者误以为在讲 ekattatā。
- **建议**：改为“对那渴爱本身的无余离贪、灭”。

## §928 句 191-928-19-52

- **问题**：准确性 — “就是这圣……（略）……正定”，“圣”字悬空。原文 ayameva ariyo 后面承接 aṭṭhaṅgiko maggo。
- **建议**：改为“就是这圣（八支）道……（略）……正定”，补出被省略的“道”。

## 原文疑问（OCR）

- 191-932-19-55 的 avijjālaṅghī：父层 121-522-82-104 作 avijjālaṅgī（门闩）。译文按“门闩”译、与父层一致，但本层 pali 拼写疑为讹误（laṅghī 有“跨越”义）。建议核对原典再决定是否改原文，暂不动译文。
