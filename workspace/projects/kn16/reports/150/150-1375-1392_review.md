# Review — 150:1375-1392（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1375、1377、1388–1391 各句没有 nissaya，已略过；1386-18-28 的 nissaya 附在下一句 1386-29-41 的行内，已按它审读）

## 跨段一致性

- **pajahati / pajahitvā**：§1386-6 `pajahati` 译“舍断”，§1386-18 `pajahatha` 译“舍断”，§1381、§1386 `pahīnā` 译“被舍断”；§1382、§1383 `pajahitvā` 却译“断除”。nissaya 两处都作 `စွန့်`（舍弃）一系（`pajahitvā= အပြားအားဖြင့်စွန့်၍` 彻底舍弃）。→ 建议统一为“舍断”。§1382、§1383 的动词串改作“舍弃、抛弃、舍断、驱除、终结”，和 §1386-6 的“舍断、驱除、终结”对上。
- **anabhāvaṃ gameti / gametvā / anabhāvaṃkata**：§1382、§1383 译“使之不复存在”，§1386-6 译“使它不复存在”，§1381、§1386-29、§1386-67 译“被弄得不复存在”。nissaya 作 `တဖန်မဖြစ်ခြင်းသို့ရောက်စေ`（使它到达不再产生的状态）。“之”“不复”是文言成分，“弄得”又偏口语，三处语体不统一。→ `gameti / gametvā` 建议统一译“使它归于不存在”，`anabhāvaṃkata` 建议统一译“已归于不存在”。
- **ye / yesaṃ（关系代词）**：§1378、§1382、§1387 译“凡是……的人”；§1381-28 `yesaṃ` 译“他们的”；§1386-67 `yesaṃ` 译“谁的……他们就……”。→ 建议统一为“凡是……的人”这一句式，§1386-67 改作“凡是这些漏已被舍断……的人，他们……”。
- **anekarūpa**：§1379、§1383、§1391 都译“种种形态的一切”。nissaya 作 `ကောတုဟလမင်္ဂလာစသောများသောအပြားရှိသော`（以稀奇吉兆等为代表、有多种类别的），这里的 `rūpa` 指类别，不是形态。→ 建议三处统一改为“种种类别的一切”，§1383 的被解释词同步改。
- **tīreti / tīrayitvā 与术语“度遍知”**：§1385、§1386 的动词译“审察”，术语却译“度遍知”，名称和动词对不上。nissaya 把 `tīreti` 释为 `လွန်၏`（越过），和“审察”也不一致。→ 建议动词改为“推度”，和“度遍知”同字；采用“推度”还是 nissaya 的“越过”，在报告里注明分歧。
- **偈中的“的人”**：§1378 / §1382 被解释词 / §1390 在“舍弃了一切”后面加“的人”，§1379 / §1391 又以“的人”收尾，同一个关系从句（`ye … pahāya … pahāya …, taṇhaṃ pariññāya anāsavāse`）里出现了两个“的人”，读起来像两类主语。→ 建议 §1378、§1382 被解释词、§1390 三处同步去掉“的人”，只在 §1379 / §1391 句末保留一次。

## §1378 句 150-1378-2-14

- **问题**：格与句法 — 原文只有一个 `pahāya`，`sabbaṃ` 是它的宾语，用来总括前面列出的各项（nissaya：`သဗ္ဗံ= အလုံးစုံကို။ ပဟာယ= စွန့်၍။`）。译文“舍弃了……，舍弃了一切”把动词重复了一遍，`sabbaṃ` 变成了另一个宾语。另外，nissaya 把 `ye` 补出为 `အကြင်ရဟန်းပုဏ္ဏားတို့သည်`（那些沙门、婆罗门）；`idha= ဤလောက၌`（在这世间）。
- **建议**：改为“凡是在这世间舍弃了所见、所闻、所觉或戒禁这一切”（“的人”的处理见跨段一致性一节）。§1382 被解释词和 §1390 同步改。

## §1382 句 150-1382-2-25

- **问题**：补出成分 — nissaya 把 `diṭṭhasuddhiyo` 释为 `မြင်ရခြင်းသည် စင်ကြယ်၏ဟူသော…အယူတို့ကို`（认为“见即清净”的种种见解），被舍弃的是“见解”。译文“依所见而得的清净”漏了这一层，容易读成清净本身被舍弃。复数（`sabbā … -iyo`）也没体现出来。
- **建议**：改为“舍弃了一切认为‘所见即清净’的见解”。

## §1382 句 150-1382-26-74

- **问题**：补出成分 — 同上。`suta- / muta- / diṭṭhasutamuta- / sīla- / vata- / sīlabbatasuddhiyo` 这几项，nissaya 都补出 `…စင်ကြယ်၏ဟူသောအယူတို့ကို`（认为“……即清净”的见解）。
- **建议**：按同一句式改成“一切认为‘所闻即清净’的见解……一切认为‘戒禁即清净’的见解”，和上一句保持一致。

## §1383 句 150-1383-2-24

- **问题**：词义层次 — nissaya 对三组词的释义很整齐：`suddhi` 清净 / `visuddhi` 特别清净 / `parisuddhi` 在一切方面清净；`mutti` 解脱 / `vimutti` 特别解脱 / `parimutti` 在一切方面解脱。译文“净化”把名词状态译成了过程，“脱离”太弱，三级递进没有译出来。`-maṅgalena` 是具格（`ဖြင့်`），“依靠”可以保留。
- **建议**：改为“清净、极清净、遍清净、解脱、极解脱、遍解脱”。被解释词“种种形态”的改法见跨段一致性一节。

## §1385 句 150-1385-5-22

- **问题**：词义 — `tīreti` 译“审察”，nissaya 作 `လွန်၏`（越过），和术语“度遍知”也对不上（见跨段一致性一节）。
- **建议**：改为“推度渴爱”，§1386-6 的 `tīrayitvā` 同步改为“推度之后”。

## §1386 句 150-1386-15-17

- **问题**：漏词 — nissaya 把 `hi` 释为 `သစ္စံ= မှန်၏`（确实），译文没有体现。
- **建议**：可改为“世尊确实这样说过：”。

## §1386 句 150-1386-18-28

- **问题**：格 — nissaya（附在下一句的行内）：`တဏှာယ= တဏှာ၌`，是处格（在渴爱上），`yo chandarāgo atthi`（凡是有的那种欲贪）。“对于渴爱的欲贪”里的“的”容易读成属格。
- **建议**：改为“比丘们，凡是对渴爱的欲贪，你们要舍断它”，或“比丘们，在渴爱上的欲贪，你们要舍断它”。

## §1386 句 150-1386-29-41

- **问题**：时态与句法 — nissaya 把 `evaṃ` 释为 `ဤသို့စွန့်ကုန်သည်ရှိသော်`（你们这样舍断时），表示条件；`bhavissati`（将会）管到后面全部谓语（nissaya 在末尾又重复了一次 `ဘဝိဿတိ`）。译文先说“就会被舍断”，接着用“根已断除”的已然语气，前后时态混杂。
- **建议**：改为“你们这样舍断了，那渴爱就会被舍断、根被断除，像截断的棕榈树桩一样，归于不存在，将来不再生起”。

## §1386 句 150-1386-67-86

- **问题**：句法 — nissaya：`တေ= ထိုသူတို့ကို။ အနာသဝါ= အနာသဝဟူ၍။ ဝုစ္စန္တိ`，意思是他们被称为“无漏”。接着用 `ယေဟိ= ယေဟူသည်ကား … ခီဏာသဝါ … အရဟန္တော` 说明这些人就是漏已尽的阿罗汉，`arahanto khīṇāsavā` 是补充说明，不是并列的三个称号。译文“被称为无漏者、阿罗汉、漏尽者”把它们当成了三个称号。关系句“谁的”的问题见跨段一致性一节。
- **建议**：改为“凡是这些漏已被舍断……将来不再生起的人，他们被称为无漏者，也就是漏已尽的阿罗汉”。

## §1387 句 150-1387-2-48

- **问题**：多译、误译 — 原文共六个同义词：`tiṇṇā uttiṇṇā nittiṇṇā atikkantā samatikkantā vītivattā`。译文“渡过……，已经越过、渡出、超出、超越、完全超越、远离”有七项，多出一个词。“远离”也不合 `vītivattā`，nissaya 作 `အထူးသဖြင့်လွန်`（特别越过）。nissaya 的释义：`uttiṇṇā` 特别渡过，`nittiṇṇā` 无余渡过，`atikkantā` 越过，`samatikkantā` 完全越过，`vītivattā` 特别越过。nissaya 还把主语 `ye / te` 补出为“那些阿罗汉”。
- **建议**：后半改为“渡过、渡出、彻底渡过、越过、完全越过、超越了一切轮回之路”，严格保持六项，并删掉“远离”。
