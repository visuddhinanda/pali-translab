# Review — 150:550-625（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句没有 nissaya 单元，已略过。有的 nissaya 单元覆盖了前一行的词，这些词并到所在单元一起核对）

## 跨段一致性
- apunabbhavāya：§553 和 §561 都译作“不再有来生”，两处一致。但 nissaya 两处都标为目的格（`ငှါ`，“为了……”），§561 还解释为“为了涅槃的利益”。建议两处同步改成“为了不再有来生”，不要只改一处。
- 本 chunk 中以下译法前后一致，无需处理：bhūripaññāṇa“广大智慧”、bhūrimedhasa“广大明慧”（§590/§607/§613/§619）；pārāyana“彼岸道”（§563/§564/§586/§587/§589）；tamonudo / tamanudo“驱除黑暗”；呼格 brahme / brāhmaṇa“婆罗门啊”；upāgacchuṃ / upāgamuṃ“来到……面前”；apāra(to)“此岸”（§583/§585）；§609/§615/§621 和 §610/§616/§622 的重复偈。

## §553 句 150-553-2-12
- **问题**：补出成分（建议改）。nissaya 把 jahassu 释为 `တင်ခြင်းကိုစွန့်` = 舍弃执着，说明要舍的是对色的执着，不是色本身。apunabbhavāya = `တဖန်ဖြစ်စေခြင်းငှါ`，是目的格。
- **建议**：改为“……你要不放逸，舍弃对色的执着，为了不再有来生。”§561 的“舍弃渴爱”本身就是舍弃对象，不需要补“执着”。
- **附注**：本单元还释了 §552 的 ပမတ္တာ = `မေ့လျော့ကုန်၏`，作谓语（“他们是放逸的”）。§552 译成定语“放逸的人们”，意思没变，可以不改。

## §557 句 150-557-2-12（含 §555 的词）
- **问题**：格与句法（必改）。nissaya 把 §555 的方位词全释为处格：catasso disā / vidisā / uddhaṃ adho 都带 `၌`，ime dasa disā = `ဤဆယ်ပါးသော အရပ်တို့၌`（在这十方中）。也就是说，十方是 §556“没有你未见、未闻……的”的范围状语，不是独立的判断句。§555 译成“这就是十方”，把处格读成了主格判断。
- **建议**：§555 改为“在四方与四维，在上方与下方，在这十方之中，”，§556 接“世间没有什么是你没有见过……的”。
- **问题**：句法（必改）。nissaya：yaṃ = `အကြင်နိဗ္ဗာန်တရားကို`（我能了知的那个涅槃之法，宾格），vippahānaṃ 是 yaṃ 的定语（舍断生老的那个法），taṃ dhammaṃ = 那个涅槃之法，作 ācikkha 的宾语。所以了知的对象是“舍断生老”这个法本身，不是“如何舍断”。现译“了知如何在这里舍断生与老”把定语读成了方法疑问。
- **建议**：改为“请为我开示那法——我能了知的、就在这里舍断生与老的法。”idha 在 nissaya 里释为“就在尊者您的足下”，“在这里”可以保留。

## §561 句 150-561-2-13（含 §559、§560 的词）
- **问题**：格与句法（建议改）。nissaya 里 taṇhādhipanne / santāpajāte / parete 都是 manuje（宾格复数，`ကုန်သော`）的定语，jarasā 是具格（`ဖြင့်`）。§560 单独成行，“生起焦恼，被衰老所逼迫”的主语不清楚，读者可能以为是宾吉耶或说话人。
- **建议**：§560 改为“那些生起焦恼、被衰老逼迫的人们；”，把定语关系明确回指 §559 的“人们”。apunabbhavāya 的处理见“跨段一致性”。

## §564 句 150-564-2-35
- **问题**：格与句法（必改）。nissaya 把 brāhmaṇānaṃ 释为 avoca 的与格（`ပုဏ္ဏားတို့အား`，对婆罗门们说），请求的施事另由 tesaṃ（`ထိုပုဏ္ဏားတို့သည်`）表示。现译只把婆罗门当成请求者，丢了“对谁说”。另外 paricāraka 在 nissaya 里是“巴瓦利婆罗门的侍从，连宾吉耶共十六人”。
- **建议**：改为“这是世尊住在摩揭陀国的巴沙那卡塔庙时，对巴瓦利的十六位侍从婆罗门所说的：世尊受他们请求，每次被问到，都解答了问题。”

## §564 句 150-564-36-47
- **问题**：取义 / 复合词结构（必改）。nissaya：dhammaṃ = `ပါဠိကို`（经文、巴利原文），不是泛指“法”；dhammānudhammaṃ = `လောကုတ္တရာနှင့်လျော်သောအကျင့်ကို`（与出世间法相应的修行），是一个依主复合词，不是“法与随法”并列。
- **建议**：改为“……了知它的义理，了知它的经文，实践与出世间法相应的修行，就一定能到达老死的彼岸。”

## §574 句 150-574-2-8
- **问题**：动词漏译（必改）。pucchantā = `မေးလိုကုန်သည်ဖြစ်၍`（想要询问），是表目的的现在分词。“带着精微的问题”丢了“问”这个动作。
- **建议**：改为“为了询问精微的问题，来到最殊胜的佛陀面前。”
- **附注**（§573）：nissaya 把 sampannacaraṇaṃ 释为“具足通往涅槃的修行”。caraṇa 指行（修行），“德行”偏向道德品格，可以考虑改成“具足善行”。

## §580 句 150-580-2-6（含 §579 的词）
- **问题**：语法（必改）。nissaya：buddhena = `ဗုဒ္ဓေန`，具格施事；tositā = `နှစ်သက်စေအပ်ကုန်သော`（被佛陀使之满意的）。§579“被……佛陀所满意”不是正常的汉语，“满意”不能这样用于被动。cakkhumatā 在 nissaya 里是“具五眼者”，译成“具眼者”可以。
- **建议**：§579 改为“具眼者、太阳的亲族——佛陀使他们心满意足，”。

## §583 句 150-583-2-9（含 §582 的词）
- **问题**：补出成分（建议改）。nissaya 补出了 byākaraṇaṃ = `အဖြေကို`（解答），所以“佛陀怎样开示”开示的是每个问题的解答。apārato = `သံသရာမှ`（从轮回），“此岸”可以保留。
- **建议**：§582 改为“对于每一个问题的解答，佛陀怎样开示，”。

## §591 句 150-591-2-17
- **问题**：取义分歧（存疑，暂不改）。nissaya 把 nibbano 释为 `ငြိမ်းပြီးသောအကုသိုလ်ရှိထသော`（不善已经止息的），读法近于 nibbuto（Syā 本异读）。现译“没有贪爱丛林”是按 nis + vana 拆词，有原文字面依据。记下这处分歧，如果采用 nissaya 的读法，就改为“已经寂灭”。
- **附注**：nissaya 补出了 kissa hetu musā bhaṇe 的后半：说妄语所依的烦恼他已经断了（§594 单元：ပဟီနာ）。现译用反问句处理，可以。

## §594 句 150-594-2-7（含 §593 的词）
- **问题**：复合词结构（必改）。nissaya 把 pahīnamalamohassa 释为 `ပယ်အပ်ပြီးသော မောဟဟူသော အညစ်အကြေးရှိထသော`（已断除“愚痴”这一污垢的），是同位持业复合词，即“愚痴这种污垢”，不是“污垢与愚痴”并列。另外，pahīnamalamohassa 和 mānamakkhappahāyino 都是属格（`မြတ်စွာဘုရား၏`），修饰 §594 的 vaṇṇūpasañhitaṃ giraṃ（赞颂他功德的言辞）。§593 拆成独立句后，属格关系要靠 §594 的“他”回指，勉强接得上。
- **建议**：§593 改为““对于那位已断除愚痴之垢、舍弃了骄慢与覆藏的人，”，§594 接“来吧，我要宣扬赞颂他功德的言辞。”

## §600 句 150-600-2-9（含 §599 的词）
- **问题**：取义（必改）。nissaya：kubbanakaṃ = `နည်းသော အသီးရှိသောတော`（果实稀少的树林），它和 bahupphalaṃ（果实丰盛）是一组对照。“小树林”丢了“果少”这个要点，比喻就不成立了。
- **建议**：§599 改为“就像鸟儿离开果实稀少的树林，栖息到果实丰盛的森林；”
- **问题**：取义 / 词形（建议改）。nissaya：mahodadhiṃ = `များသော ရေအစုရှိသော အနဝဒတ် အိုင်စသည်`（水量丰沛的阿耨达池等大湖），不是大海。ajjhapatto 被拆成 ajja（如今）+ patto（飞到），补出了“如今”。appadasse = 慧见少的人，“见识浅少的人”可以。
- **建议**：改为“……如今我就像天鹅飞到了大湖。”如果坚持译“大海”，要在报告里记下这处分歧。

## §604 句 150-604-2-9（含 §602、§603 的词）
- **问题**：漏译（必改）。§602 的 yeme = ye + me，nissaya 释 me = `အကျွန်ုပ်အား`（对我），ye 指“巴瓦利等婆罗门”。现译“那些人曾经解说”丢了“对我”。
- **建议**：§602 改为“在乔达摩的教法之前，那些曾对我解说的人说：”。要不要补出“巴瓦利等”可以斟酌，至少要把“对我”译出来。
- **问题**：取义（建议改）。nissaya：takkavaḍḍhanaṃ = `ကာမဝိတက်စသည်ကိုပွါးစေတတ်၏`（增长欲寻等寻思），takka 指寻思（vitakka），不是“臆测”。
- **建议**：改为“全都只会增长欲寻等种种寻思”，或者“全都只会增长妄想”。
- **附注**：nissaya 把 itihītihaṃ 释为“使人这样困苦劳累”，把 §603 的 iccāsi 读作 icchāsi（“所希望的”）。两处都和通行读法不同，像是 nissaya 自己的切分问题。现译“辗转相传”“过去是这样”保留，这里只记下分歧。

## §607 句 150-607-2-7（含 §606 的词）
- **问题**：取义（建议改）。nissaya：eko = `တုဘက်မရှိမြတ်၏`（无可比拟、殊胜），重点是“无与伦比”，不是“只有他”。jutimā = `တန်ခိုးအာနုဘော်ရှိ`（有威力）；pabhaṅkaro = 发出慧光者。
- **建议**：§606 改为““那独一无二者驱除黑暗而安坐，他具有威光，带来智慧的光明；”。“光辉灿烂”可以保留，重点是把“唯有他”改掉。

## §610 句 150-610-2-10（含 §609 的词）
- **附注**：nissaya 把 §609 的 me 释成 `တေ= သင်အား`（对你），和原文 Yo me 不合，像是从 §615 抄串了，以原文为准，§609 保留“为我”。nissaya 把 yassa 释为“那个涅槃”，所以“没有能与它相比的”的“它”指的是涅槃这个法，现译没有问题。

## §613 句 150-613-2-7（含 §612 的词）
- **附注**：nissaya 补出了说话人 iti bāvarī āha（巴瓦利这样说）。原文本行没有括注说话人，现译没有补，可以接受。如果读者分不清 §612 是谁问的，可以考虑参照 §589 的括注体例加上。

## §624 句 150-624-2-12
- **问题**：句法（建议改）。nissaya：appamatto = `မမေ့မလျော့သည်ဖြစ်၍`（不放逸地），rattindivaṃ = 日日夜夜，两者都修饰 passāmi。现译把“日日夜夜都不放逸”拆成另一个并列谓语，削弱了“不放逸地看见他”的关系。
- **建议**：改为““婆罗门啊，我日日夜夜不放逸地用心看见他，就像用眼睛看见一样。”
