# Review — 150:733-747（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§733、§734 无单独 nissaya 行；§734 偈句由 §735 行的 nissaya 一并覆盖）

## 跨段一致性

- **“欲贪”一词对应三个巴利词**：chandarāga（§738 “欲贪是欲”、§746 “欲贪已经断除”）、kāmarāga（§738 “欲贪”）、kāmacchanda（nīvaraṇa）（§738 “欲贪盖”）。同一段内并列出现，读者无法区分。另外 kāmacchanda 单列时又译作“欲乐欲”，与“欲贪盖”的 chanda 部分不一致。建议统一为：chandarāga “意欲贪”、kāmarāga “欲贪”、kāmacchanda “欲意欲”、kāmacchandanīvaraṇa “欲意欲盖”（或另定一套），定案后登记到 `terms.md`。chanda 已在 §738 译作“意欲”，这样能与之呼应。
- **rāga 与 lobha 都译“贪”**：§741-7 “就是贪、强烈的贪……贪婪、贪、不善根”，rāgo 和 lobho 在同一句里都是“贪”。§738 的 rāgo 以及 §741-21 的 vīta/vigata…rāgo 也用“贪”。建议 lobha 保留“贪”（对应“贪不善根”），rāga 全 chunk 改为“贪染”：§738 “贪染是欲”，§741-21 “离开贪染、去除贪染……”。
- **“迷醉”对应两个词**：§737 madanīya 译“可迷醉”，§738 kāmamucchā 译“欲迷醉”，§741-21 amucchito 译“不迷醉”。nissaya 的释义不同：madanīya = ယစ်ခြင်းကိုဖြစ်စေတတ်（令人沉醉），mucchā = မိန်းမောခြင်း（昏迷、迷闷）。建议 madanīya 改为“可令陶醉”，mucchā / amucchito 保留“迷醉 / 不迷醉”。
- **“耽溺”对应两个词**：§738 kāmajjhosāna 译“欲耽溺”，§741-21 anajjhāpanno 译“不耽溺”。nissaya：anajjhāpanno = မလွန်ကျုး（不越犯、不陷入）。建议 anajjhāpanno 改为“不陷入”，与 ajjhosāna 区分。
- **“X vuccati Y”句式主宾颠倒**：§741-7 和 §746-2 都把被称名的词当成了主语，详见各句。同一句式在 §737-79、§741-2 译作“这些称为事欲 / 烦恼欲”，方向是对的。应全 chunk 统一为“Y 称为‘X’”。
- **bhanta 译“迷乱”**：在 §742-22、§742-33、§742-94（abhanto “不迷乱”）共三处。nissaya 作 ပြင်းစွာလှုပ်（剧烈摇动），见 §742-22。三处要同步修改。
- **mano 被解释词与列举项不一致**：§742-6 被解释词 **Mano** 译“心”，但同一句列举中的 mano 两次都译“意”，citta 才译“心”。见 §735 / §742-6。

## §735 句 150-735-2-8（含 §734 偈句 150-734-2-7）

- **问题**：格与句法。manasā 的 nissaya 是 မနသာ= စိတ်ဖြင့်（以心，具格）。anāvilo 是阳性主格，与比丘一致，不与 mano 一致。“心应不浑浊”把具格的心当成了主语。
- **问题**：被解释词与列举项不一致。§742-6 对 mano 的列举把 mano 译作“意”，偈句却用“心”。
- **建议**：被解释词改为能体现具格、并与“意”一致的译法，例如“**以意不浑浊**”或“**意念上不浑浊**”。§734、§742-2、§742-6、§742-94 四处的被解释词须逐字同步。
- **问题**：取义。paribbaje 的 nissaya 是 ခပ်သိမ်းသောဣရိယာပုတ်၌နေရာ၏（应在一切威仪中而住）；bhikkhu 是 ရဟန်းအဖြစ်သို့ရောက်သည်ဖြစ်၍（已成为比丘）。“游行”偏窄。
- **建议**：保留“游行”时压低 confidence；也可考虑改为“行住”或“生活”。若改，§747-2 被解释词要同步。

## §736 句 150-736-20-68

- **问题**：词义。vatthu 的 nissaya 是 ယာ（旱地、园地），与 khetta = လယ်（水田）成对，“宅地”与此不符。vaḷavā 的 nissaya 是 မြည်း（驴），与译文“母马”有分歧。
- **建议**：vatthu 改为“园地”；vaḷavā 可保留“母马”，但在报告中记录这一分歧。

## §737 句 150-737-2-78

- **问题**：取义。nimmitā / paranimmitā 的 nissaya 是 နိမ္မာနရတိဘုံ / ပရနိမ္မိတဘုံ၌ဖြစ်（化乐天、他化自在天中的欲），指天界，不是“自己化现 / 他人化现”。
- **建议**：改为“化乐天的欲、他化自在天的欲”。
- **问题**：词义。taṇhāvatthukā 的 nissaya 是 တဏှာ၏တည်ရာ（渴爱的依处、立足处），不是“对象”。“对象”与后面的“所缘”意思重叠。
- **建议**：改为“作为渴爱的依处、渴爱的所缘”。

## §738 句 150-738-5-35

- **问题**：术语重叠。chandarāga / kāmarāga / kāmacchandanīvaraṇa 都含“欲贪”，kāmacchanda 又单独译“欲乐欲”，见跨段一致性第一条。
- **问题**：kāmasineho 译“欲爱着”，与 kāmataṇhā “欲爱”只差一个字。nissaya 作 ချစ်ခြင်း（爱恋）。
- **建议**：kāmasineho 改为“欲爱恋”。

## §740 句 150-740-2-10

- **问题**：宾语所指。taṃ 的 nissaya 是 ထိုအထူးအပြားကြံခြင်းကို（那种分别思维），na saṅkappayissāmi 是“不再作那种思维”。译文“我不再思维你”把宾语当成了欲。
- **建议**：改为“我不再起那种思维；欲啊，这样你就不会再生起”。

## §741 句 150-741-7-20

- **问题**：主宾颠倒。nissaya 是 တဏှာ= တဏှာကို / ဂေဓော= ဂေဓဟူ၍ / ဝုစ္စတိ（渴爱被称为“贪求”）。“‘贪求’称为渴爱”方向反了。rāga 与 lobha 同译“贪”，见跨段一致性。
- **建议**：改为“渴爱称为‘贪求’，就是贪染、强烈的贪染……乃至……贪婪、贪、不善根”。

## §741 句 150-741-21-73

- **问题**：语态。na palibundheyya 的 nissaya 是 အဖန်တလဲလဲမဖွဲ့ရာ（不应反复系缚，主动），“不应被它们缠缚”是被动。
- **建议**：改为“不应纠缠于它们”。
- **问题**：取义。brahmabhūtena 的 nissaya 是 မြတ်သောသဘောရှိသော（具有殊胜性质的），“已成为梵的”过于字面。
- **建议**：改为“以成为殊胜（梵）的自身而安住”，或至少压低 confidence。
- 另见跨段一致性：amucchito、anajjhāpanno、rāga。

## §742 句 150-742-6-21

- **问题**：被解释词 **Mano** 译“心”，与列举中的 mano “意”不一致，见 §735。
- **问题**：风格（必改）。“与之相应的意识界”中的“之”是文言虚词。
- **建议**：改为“与它相应的意识界”。

## §742 句 150-742-22-32

- **问题**：词义。bhantaṃ 的 nissaya 是 ပြင်းစွာလှုပ်（剧烈摇动），不是“迷乱”。
- **建议**：改为“晃荡”或“剧烈摇动”，§742-33 和 §742-94（abhanto）同步修改。

## §742 句 150-742-33-93

- **问题**：词义。nissaya 释义与译文的差异如下：
  - sārambha：nissaya 作 ချုပ်ချယ်（压制、争强），译“激愤”。
  - santāpa：nissaya 作 ပူလောင်（燃烧），译“苦恼”，偏离了“热”的系列（ḍāha / pariḷāha / santāpa）。
  - makkha：nissaya 作 သူကျေးဇူးကိုချေ（抹杀他人恩德），“覆”是旧译，可保留，但应在报告中注明。
- **建议**：sārambha 改为“争强”；santāpa 改为“炽燃”。
- **问题**：术语冲突。sabbākusalābhisaṅkhārehi 的 nissaya 是 အကုသိုလ်တည်းဟူသော အဘိသင်္ခါရ（不善的造作），“不善行”与 duccarita “恶行”、§743 saṅkhāra “行”容易混淆。
- **建议**：改为“一切不善的造作”。

## §742 句 150-742-94-153

- **问题**：格与句法。cittena 的 nissaya 是 စိတ်ဖြင့်（以心，具格）。anāvilo、aluḷito……vūpasanto 都是阳性主格，描述的是比丘，不是心。“心应当不浑浊——不动荡……平静”把一连串形容词都挂到了心上。
- **建议**：改为“应当以心不浑浊——不动荡、不晃荡……平静”，主语是比丘。被解释词按 §735 的结论同步修改。

## §744 句 150-744-2-109

- **问题**：取义。aghamūlato 的 nissaya 是 ဆင်းရဲခြင်း၏အကြောင်း（苦的根源），译文“恶的根源”是顺着 aghato “恶”（nissaya：မကောင်းမှု၏တည်ရာ）译的。nissaya 对这两处 agha 的取义不同。
- **建议**：aghamūlato 改为“从苦的根源”，或保留原译并压低 confidence。

## §746 句 150-746-2-43

- **问题**：主宾颠倒。nissaya 是 ဒွါဒသာယတနာနိ= …အာယတနတို့ကို / သဗ္ဗဓမ္မာ= သဗ္ဗဓမ္မတို့ဟူ၍ / ဝုစ္စန္တိ（十二处被称为“一切法”）。
- **建议**：改为“或者，十二处称为‘一切法’——眼与色……意与法”。

## §746 句 150-746-44-70

- **问题**：词义。tālāvatthukato 的 nissaya 是 ထန်းပင်ငုတ်တို့ကဲ့သို့ပြုအပ်（如同棕榈树桩），“截去顶端的棕榈树”与此不完全一致。
- **建议**：改为“如同棕榈树桩”。
