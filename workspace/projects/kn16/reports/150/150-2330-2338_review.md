# Review — 150:2330-2338（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（§2330、§2331、§2337 无 nissaya 行；偈颂 §2331–2332、§2337–2338 的 nissaya 分别并在 §2332、§2338，按整偈核对）

## 跨段一致性

- **被解释词对照**：§2333、§2335、§2336 引出的偈句（黑体及段末“这就是……”）与 §2331–2332 偈颂译文逐字相同，§2337–2338 重颂也一致。**无问题。**
- **sattā / asattā（√sañj）**：§2333 把 sattā 和 visattā 合并成“互相缠结”，§2336 的反义词 asattā 却译“不粘着”。同组的 laggā/alaggā（挂连/不挂连）、palibuddhā/apalibuddhā（受到阻碍/不受阻碍）都是正反对译，唯独这一对断了。建议 §2333 的 sattā 也译“粘着”，与 §2336 的 asattā、sajjati 词族保持一致（见 §2333 句 11-36）。
- **“缠缚”一词两用**：visattikā 全 chunk 定译“缠缚”，§2336 的 na palibajjhati 又译“不被缠缚”，读者会误以为是同一个词。建议 palibajjhati 改译，依据 nissaya `န ပလိဗဇ္ဈတိ= အဖန်တလဲလဲမဖွဲ့`（不反复缚），可译“不被紧缚”或“不被重重系缚”。
- **“欲求”重复**：§2333 的 icchā 与 nikāmanā 都译“欲求”，同义词列表里出现重复译名。依据 nissaya：`နိကာမနာ= နှစ်သက်သောအခြင်းအရာရှိသော`（有喜好之相的），建议 nikāmanā 改译“喜求”或“爱求”，与紧邻的 nikanti“爱乐”区分。
- **yasa**：§2334、§2336 都译“名声”。nissaya 两处都作 `ယသေ= အခြံအရံ၌`（在随从眷属上），建议两处统一改为“随从”或“眷属”。
- **visatā**：§2334 句 7-35 译“散布”，同段句 36-83 的 visatā vitthatā 译“宽广、扩展”，“宽广”又和 visālā 撞车。建议统一为“散布”（见下文）。
- **nikkhanta / vippamutta**：§2336 句 9-35 译“伸出、……完全解脱出来”，同段句 155-169 译“出离、……解脱”。竹笋句保留“伸出”的形象可以接受，但 vippamutta 建议两处统一（都作“解脱”，或都作“完全解脱”）。
- **“X vuccati Y”的体例**：§2333 作“竹（vaṃsa）是指竹丛”“缠缚（visattikā）是指渴爱”，§2336 作“竹是指竹丛”，§2335 却加了引号：“‘妻’是指妻子们”“‘挂念’是指渴爱”。建议统一，比如一律不加引号，首次出现的词夹注巴利原词。
- **著 / 着**：§2333 用“耽著”“执著”，§2332、§2336 用“粘着”，建议统一用“着”。

## §2332 句 150-2332-2-16

- **问题**：补出成分（轻微）。nissaya 在 `ဧဝံ`（同样）之后补了主语性的 `အသဇ္ဇမာနော= တဏှာဒိဋ္ဌိအားဖြင့်မငြိ`（以渴爱、见不粘着而住）。也就是说，“不粘着”的是修行者，竹笋只是比喻。现译“像竹笋一样不粘着”在偈颂里语义清楚，句法上没有误读。
- **建议**：偈颂可以保持原样，不必补字。

## §2333 句 150-2333-11-36

- **问题**：漏译，加上用词偏离 nissaya。
  - 巴利有六个分词：sattā / visattā / āsattā / laggā / laggitā / palibuddhā。nissaya 逐一出释：`သတ္တာ= ငြိရှက်`、`ဝိသတ္တာ= အထူးသဖြင့်ငြိရှက်`、`အာသတ္တာ= စပ်ယှဉ်`、`လဂ္ဂါ= ငြိတွယ်`、`လဂ္ဂိတာ= ငြိတွယ်ခြင်းသို့ရောက်`、`ပလိဗုဒ္ဓါ= ရစ်ပတ်ဖွဲ့ရှက်`。
  - 现译只有五项（互相缠结、攀附、挂连、勾连、受到阻碍），sattā 和 visattā 被合并了。
  - palibuddhā 在 nissaya 里是“缠绕束缚”，不是“受阻碍”。
  - nissaya 还补出 `ပေါရာဏကာဝံသာ= ဝါးရုံဝင်ဟောင်း`（竹丛中的老竹）作主格。现译已经补出，没有问题。
- **建议**：改为“就像竹丛里的老竹粘着、缠结、攀附、挂连、勾连、被缠绕束缚那样，同样地，缠缚（visattikā）是指渴爱。”§2336 的 apalibuddhā 相应改为“不被缠绕束缚”。

## §2333 句 150-2333-37-145

- **问题 1**：同形词没有区分。巴利本身两次出现 rūpataṇhā，nissaya 给了两个不同的所指：
  - 第一次与 arūpataṇhā 并列：`ရူပတဏှာ= ရူပဘုံ၌တပ်တတ်သော`（贪着色界地的渴爱）
  - 第二次与 sadda/gandha 等并列：`ရူပတဏှာ= ရူပါရုံ၌တပ်တတ်သော`（贪着色所缘的渴爱）

  现译两处都作“色爱”，看起来像衍文。
- **建议**：第一处改为“色界爱”，与“无色界爱”配对（arūpataṇhā 相应改为“无色界爱”）；第二处保留“色爱”。
- **问题 2**：风格，属于必改项。“贪好之欲”“渴爱之河、渴爱之网、渴爱之绳、渴爱之海”用了文言虚词“之”。
- **建议**：改为“爱好的欲求”，以及“渴爱的河流、渴爱的罗网、渴爱的绳索、渴爱的大海”。
- **问题 3**：icchā 与 nikāmanā 同译“欲求”，见跨段一致性一节。

## §2334 句 150-2334-7-35

- **问题**：两个词的取义与 nissaya 不合。
  - `ဝိသံဟရတိ= ဆင်းရဲကိုဆောင်တတ်၏`：nissaya 拆作 visa（苦）+ harati（带来），意为“带来苦”。现译“夺取”没有依据。
  - `ဝိသက္ကတိ= ရွေ့တတ်၏`：意为“移动、游移”。现译“蔓延”和前面的 visatā、visaṭā（散布、扩散）语义重叠，使这一组十个词源解释失去区分度。
  - 另外，nissaya 对 visamūlā、visaphalā、visaparibhogā 里的 visa 都释为“苦”（ဆင်းရဲ/ဒုက္ခ）。“以毒为根”等字面译法可以保留，但可以考虑在段后加注说明 visa 取“苦”义。
- **建议**：visaṃharati 改为“因为带来苦（visaṃharati）”；visakkati 改为“因为游移（visakkati）”。

## §2334 句 150-2334-36-83

- **问题**：词级对应错位。nissaya 的结构是：`ဝိသာလာ= နှံ့တတ်သော`（遍及的）作定语修饰 taṇhā，句末 `ဝိသဋာ= နှံ့တတ်၏`、`ဝိတ္တတာ= ပြန့်တတ်၏` 是两个谓语。现译句末的“宽广、扩展”只对上两个谓语中的一个；句首的 visālā 没有单独译出，而“宽广”又和本段 7-35 句 visālā 的译法重复。此外 yasa 译“名声”，与 nissaya `အခြံအရံ` 不合，见跨段一致性一节。
- **建议**：改为“或者说，渴爱是宽广的：它在色、声……上散布、扩展，所以称为缠缚。”“名声”改为“随从”。

## §2336 句 150-2336-9-35

- **问题**：句末缺主语。nissaya 在 `ဧဝမေဝံ= ဤအတူလျှင်` 之后补了 `အသဇ္ဇမာနော= တဏှာမာနဒိဋ္ဌိအားဖြင့်မကပ်ငြိ`，即“同样，（辟支佛）以渴爱、慢、见不粘着而住”。现译以“那样，也是这样”收尾，读者看不出是谁“也是这样”。
- **建议**：改为“……那样，同样地，（他）也不粘着。”

## §2336 句 150-2336-65-154

- **问题**：两处用词撞车。
  - na palibajjhati 译“不被缠缚”，与 visattikā 的定译“缠缚”冲突。nissaya 作 `အဖန်တလဲလဲမဖွဲ့`（不反复缚）。
  - yasa 译“名声”，与 nissaya `အခြံအရံ` 不合。
- **建议**：改为“不被紧缚”（或“不被重重系缚”）；“名声”改为“随从”。

## OCR / 原文疑问（记录，不改）

- §2333 句 37-145：nissaya 比巴利原文多出 pasaṅgo、pāso、baḷisaṃ 三条（例如 `ပသင်္ဂေါ`、`ပါသော`、`ဗဠိသံ`），是版本差异。译文按巴利原文译，没有问题。
- §2336 句 155-169：巴利作 visaññutto，nissaya 作 `ဝိသံယုတ္တော`（visaṃyutto），疑为同一词的拼写异文。译文“离系”两读皆通。
