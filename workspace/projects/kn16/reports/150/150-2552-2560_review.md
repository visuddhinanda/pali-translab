# Review — 150:2552-2560（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（2552、2553 没有单独的 nissaya 行；2553 偈颂的词由 150-2554-2-23 行的 nissaya 一并覆盖）

## 跨段一致性
- **tadupādāya**：§2557 句 119-132 和句 239-255 都译成「从此」（时间义）。两处 nissaya 都是 `တံ= ထိုများစေလိုသောအဖြစ်ကို။ ဥပါဒါယ= အကြောင်းပြု၍။`，意思是“因为那种想要更多的心”，是因果义。两处都必须改，改法要一致，见下文。
- **gilānapaccayabhesajjaparikkhāra**：§2557 句 6-40 译「病者所需的医药资具」（2 次），句 100-104、119-132、153-157、239-255 译「病者医药资具」。建议统一成一种，推荐「病者所需的医药资具」，因为 nissaya 是 `သူနာ၏…ဖြစ်သောဆေး`（病人的、作为资助的药）。
- **…so samaṇo mahesakkho’’ti bhaṇati**：几句结构相同，处理却不一样。§2559 句 24-37、85-97 是「他说：“……”」，引语前置；句 38-84、98-121、122-179 是「“……”，他这样说」，引语后置。巴利原文都是 ti bhaṇati 收尾，建议统一成一种句式。
- **bhākuṭikā / bhākuṭiyaṃ / bhākuṭika**：§2557 句 256-267、§2558 句 70-97、§2560 句 33-44 译「装模作样、作态」，§2560 句 2-32 译「极其装模作样」，各处用词一致。但 nissaya 都是 `မျက်မှောင်တွန့်ခြင်း`（皱眉、蹙额），见下文。如果改，四处要一起改。
- **upajjhāya / ācariya**：§2559 句 85-97、98-121 里，upajjhāya 意译为「戒师」，ācariya 却音译为「阿阇梨」，处理不一致。建议成对处理：「和尚／阿阇梨」或「戒师／老师」。

## §2553 句 150-2553-2-8
- **问题**：取义 — nimmakkho 译成「不覆藏」。nissaya：`နိမ္မက္ခေါ= သူကျေးဇူးကိုချေခြင်းမှကင်းသည်`，意思是“没有抹杀他人恩德的毛病”。makkha 指贬低、抹杀别人的好处，不是“隐藏”。
- **建议**：改为「不抹杀他人恩德」或「不忘恩」。nissaya 还补了 `ဟောတိ= ဖြစ်၏`，说明这一行是“（他）是……”的表语。现在的译法已经能读出这层意思，不需要改。

## §2554 句 150-2554-2-23
- **问题**：格式 — zh 里「**在整个世间****都无所希求**」「**应当****独自****游行**」有连续的 `****`，markdown 渲染时可能出错。
- **建议**：相邻的两个粗体片段合并成一个，或者中间留出非粗体字符。

## §2555 句 150-2555-10-19
- **问题**：句法 — nissaya 用 `…သည်လည်းကောင်း` 把各项并列成关系从句（凡是……，凡是……）。其中 `ယံ အကုသလမူလံ` 是单独一项，后面由 §2555 句 20-32 的 Sā 承接。译文「贪这一不善根」把 akusalamūlaṃ 当成 lobho 的同位语，还多出一个「贪」。这样 rāgo「贪」和 lobho「贪欲」之外，句尾又冒出一个「贪」，词义混在一起。
- **建议**：改为「凡是贪、深贪……（略）……觊觎、贪欲、不善根，」与下一句的「这种……」呼应。

## §2555 句 150-2555-20-32
- **问题**：词义 — tālāvatthukatā 的 nissaya 是 `ထန်းပင်ငုတ်ကဲ့သို့ပြုအပ်ပြီ`，意思是“像多罗树的残桩一样”，重点是只剩树桩、不能再长。译文「截去顶端的多罗树」偏离了这个意思。另外，loluppā 的 nissaya 是 `အာဟာရ၌လျှပ်ပေါ်သော`（对食物躁动贪求的），是修饰 taṇhā 的定语。「贪求之爱」用了文言的「之」。
- **建议**：改为「像只剩残桩的多罗树一样」；「贪求之爱」改为「贪求的贪爱」；「已被弄得不复存在」口语化，可改为「已使它不复存在」。

## §2556 句 150-2556-2-15
- **问题**：语体 — 「旁敲侧击之语」里的「之」是文言虚词。§2559 句 2-6、§2560 句 33-44 也一样。
- **建议**：统一改为「旁敲侧击的话」。三处一起改。

## §2557 句 150-2557-6-40
- **问题**：词义 — icchāpakato 的 nissaya 是 `မကောင်းသောအလိုဖြင့်နှိပ်စက်သည်`（被恶欲所压迫），明说是“恶”欲。译文「被欲望所驱使」没有译出这一层。§2558 句 6-69、§2559 句 7-23 也一样。
- **建议**：改为「被恶欲所逼」。三处一起改。

## §2557 句 150-2557-72-80
- **问题**：句法 — nissaya 是 `ဥဉ္ဆာစရိယာယ= ဆွမ်းခံဝတ်ဖြစ်သော။ ပိဏ္ဍိယာလောပေန= ရသောဆွမ်းလုပ်ဖြင့်`。uñchācariyāya 是修饰 piṇḍiyālopena 的定语，意思是“行乞所得的饭团”。译文把它拆成两个并列的「靠……、靠……」，句法关系弄错了。
- **建议**：改为「靠行乞得来的一团团饭食维持生活」。

## §2557 句 150-2557-86-99
- **问题**：词义 — nissaya 是 `ရုက္ခမူဆောက်တည်ခြင်း`、`အဗ္ဘောကာသိကဓုတင်ဆောက်တည်သည်`，说的是受持树下住、露地住等头陀支的人。译文「住在树下」只译出了动作，丢了“受持”这层意思。
- **建议**：可改为「做一个树下住者，或坟场住者，或露地住者」。如果为了好读保留原译，也可以接受，这里不算必改。

## §2557 句 150-2557-105-118
- **问题**：词义 — pūtimutta 的 nissaya 是 `နွားကျင်ပုပ်`（腐坏的牛尿），译文「陈尿」没有点出是牛尿。
- **建议**：改为「腐坏的牛尿」。

## §2557 句 150-2557-119-132
- **问题**：句法（必改）— Tadupādāya 的 nissaya 是 `ဣတိ= ဤသို့။ တံ= ထိုများစေလိုသောအဖြစ်ကို။ ဥပါဒါယ= အကြောင်းပြု၍`，意思是“因为那种想要更多的心”，是因果。译文「从此」把它理解成了时间。原文的讽刺正在这里：他是为了得到更多，才穿粗劣的衣。
- **建议**：改为「就这样，因为想得到更多，他穿粗劣的衣，吃粗劣的钵食……」。

## §2557 句 150-2557-239-255
- **问题**：句法（必改）— 同上。nissaya 是 `တံ= ထိုများစေလိုသည်၏အဖြစ်ကို။ ဥပါဒါယ= အကြောင်းပြု၍`，这里的「从此」也是误读。
- **建议**：改为「就这样，因为想得到更多，他接受很多衣……」，和句 119-132 的改法一致。

## §2557 句 150-2557-256-267
- **问题**：词义 — bhākuṭikā 的 nissaya 是 `မျက်မှောင်တွန့်ခြင်း`（皱眉），bhākuṭiyaṃ 的 nissaya 是 `မျက်မှောင်တွန့်သောသူ၏အဖြစ်`（皱眉者的样子），指故意摆出严肃苦修的面容。「装模作样、作态」太泛，具体的“皱眉”不见了。kuhāyanā 的 nissaya 是 `…အခြင်းအရာ`（方式、样子），译「诡诈的行为」大体可以。
- **建议**：改为「皱眉、皱眉作态、诡诈、诡诈的样子、诡诈的状态」。§2558 句 70-97、§2560 句 2-32（bhākuṭikabhākuṭiko 改为「极其爱皱眉」）、§2560 句 33-44 一起改。

## §2558 句 150-2558-6-69
- **问题**：词义 — samāhito viya 的 nissaya 是 `ဥပစာရသမာဓိရှိသောသူကဲ့သို့`（像得了近行定的人）。译文「好像入定一样」可以接受，但容易让人理解成“入了安止定”。
- **建议**：可改为「好像心已得定一样」。不算必改。

## §2559 句 150-2559-122-179
- **问题**：词义 — uddaṇḍa 的 nissaya 是 `ရေစင်ထင်းစင်`（放水、放柴的架棚），译文「长屋」对不上。
- **建议**：改为「放水和柴的棚屋」。

## §2560 句 150-2560-2-32
- **问题**：词义（必改）— vihārasamāpattīnaṃ 的 nissaya 是 `ဝင်စားအပ်သောဝိဟာရသမာပတ်`（所入的“住”与等至），vihāra 在这里指禅定中的安住，不是住所。译文「寂静的住处与等至」把它误读成了居所。
- **建议**：改为「证得了这类寂静的安住与等至」。另外 korajikakorajiko 的 nissaya 是 `အလွန်မျက်မှောင်ကြုတ်လေ့ရှိ`（总是紧锁眉头），bhākuṭikabhākuṭiko 也是皱眉义，两个词意思相近。现在译成「极其矫饰」，可以保留以示区别，但要和上面 bhākuṭika 的改法一起统一。

## §2560 句 150-2560-45-57
- **问题**：语体 — 「智慧之火」用了文言的「之」。
- **建议**：改为「智慧的火」或「智火」。
