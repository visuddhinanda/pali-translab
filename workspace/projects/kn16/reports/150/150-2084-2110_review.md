# Review — 150:2084-2110（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次仅做 nissaya 词法复核）

## 跨段一致性
- **“黑暗”一词两用**：§2102 用“黑暗”译 tama（tamonudo＝驱除黑暗者），§2090 又用“黑暗者”译魔的称号 kaṇha。读者会把魔误读成“黑暗本身”。nissaya 对 kaṇha 的释义是 `ကဏှံ= မကောင်းသော`（不善的、邪恶的），与 tama（`အမိုက်တိုက်` 愚暗）不同。→ **必改**：§2090 的 kaṇha 改为“黑魔”或“邪恶者”，“黑暗”只留给 tama。
- **“光辉”一词两用**：§2085、§2106 用“有光辉者”译 jutimā，§2106 又用“放光辉者”译 obhāsakaro。→ 建议 obhāsakaro 改为“作照耀者”，“光辉”只留给 juti。
- **“灭尽”一词两用**：§2098 用“灭尽”译 khaya（jātikhaya），§2101 也用“灭尽的性质”译 nirodhadhamma。→ 建议 nirodha 改为“灭”，即“全都会灭去／都有灭的性质”，与 khaya 区分。
- **ariyo aṭṭhaṅgiko maggo**：§2097 译“八支圣道”，与术语表 `aṭṭhaṅgika magga = 八正道（confirmed）` 不符。→ **必改**：统一为“八圣道”或“八正道”，以术语表为准。
- **同一偈两半体例不一**：§2085 把 eko / tamonudāsīno / jutimā / pabhaṅkaro 译成名词性称号（“独一者、驱除黑暗者……”），§2086 却把 bhūripaññāṇo / bhūrimedhaso 译成谓语句（“乔达摩以广慧为标志，乔达摩具有广大的睿智”）。nissaya 对整首偈都按谓语处理（`…ရှိတော်မူ၏`、`…မြတ်၏`）。→ 建议两半统一：要么都用称号式，要么都用谓语式。被解释词（§2087、§2106、§2107 的黑体）要随之同步。

## §2086 句 150-2086-2-7
- **问题**：取义参考 — nissaya 把 tamonudāsīno 的 āsīno 释为 `…ဖျောက်ခြင်းကိုတောင့်တတော်မူတတ်၏`（渴望驱除众生的愚痴），也就是取 āsiṃsati“希求”一义；而本文 §2102 把 āsīno 释为 nisinno“坐”。
- **建议**：译文“安坐者”依的是本文自己的解释，可以保留，不必改。此条只记录 nissaya 的另一读法。

## §2090 句 150-2090-8-54
- **问题**：词义 — pamattabandhuṃ 的 nissaya 是 `မေ့လျော့ခြင်းဖြင့်ဖွဲ့တတ်သော`（以放逸来束缚人的），把 bandhu 读作“束缚者”，不读作“亲族”。namuciṃ 的 nissaya 是 `ယုတ်မာသော`（卑劣的），作形容词用。另外，kaṇha 被译作“黑暗者”的问题见上文“跨段一致性”。
- **建议**：kaṇha 必改。pamattabandhu 可以保留传统译法“放逸者的亲族”，但要知道 nissaya 有“以放逸束缚人者”的读法。
- **问题**：原文疑问 — nissaya 对 `anabhāvaṃ gamesi` 的释义是 `တဖန်ဖြစ်ခြင်း‌သို့ရောက်စေပြီ`，疑脱一个否定词 `မ`（§2102 同一短语作 `တဖန်မဖြစ်ခြင်း`，即“不再生起”）。这一点不影响译文。

## §2092 句 150-2092-2-6（偈 §2091–2092）
- **问题**：格误读（**必改**）— nissaya 是 `ဣတ္ထဘာဝညထာ ဘာဝံ= ဤသို့သောအပြားတစ်ပါးသောအပြားရှိသော။ သံသာရံ= သံသရာကို။`。itthabhāvaññathābhāvaṃ 是宾格，作 saṃsāraṃ 的定语，意思是“具有此种状态与他种状态的轮回”。译文把它当成处所状语“在此生与他生的种种状态中”，句法关系错了。
- **建议**：改为“无法超越这种存在、那种存在不断更替的轮回”。

## §2094 句 150-2094-2-11（偈 §2093–2094）
- **问题**：句法 — nissaya 把 `ဧတမာဒီနဝံ= ဤသို့အပြစ်ရှိသော` 作 taṇhaṃ 的定语，意思是“具有这种过患的渴爱”，ñatvā 只有一个宾语。译文拆成两个“知道”，成了“知道了这种过患，知道渴爱……”。
- **问题**：词性 — vītataṇho / anādāno / sato 是 bhikkhu 的定语，表示状态（`တဏှာမရှိသော`，没有渴爱的）。译文“离开渴爱、不再执取”读起来像动作过程。
- **建议**：改为“知道渴爱有这样的过患、是苦的根源，已离渴爱、无所执取、具足正念的比丘，应当游行。”

## §2099 句 150-2099-2-34（偈 §2098–2099）
- **问题**：复合词误读（**必改**，涉及 §2098 行）— jātikhayantadassī 的 nissaya 是 `ဇာတိ၏ကုန်ရာနိဗ္ဗာန်ကိုရှုလေ့ရှိသောသူ`（常观见生的尽处即涅槃的人）。khayanta 是“灭尽的终点”这一个整体，译文“生的灭尽与终结”把它拆成了两个并列项。
- **建议**：§2098 改为“见到生之灭尽处（涅槃）、心念利益的人，了知这条……道路”。
- **问题**：句法 — nissaya 末尾是 `ဣတိ= ဤသို့။ ပဇာနာတိ= သိ၏။`，把第二行“过去依此道渡过……”当作 pajānāti 的内容。译文把它译成了独立陈述。
- **建议**：可以考虑把第二行处理成所了知的内容，例如“……了知：过去的人们依靠这条道路渡过了暴流……”。
- **问题**：取义参考 — ekāyana 的 nissaya 在本 chunk 有几种释法：§2099、§2100 作“通往涅槃的（道路）”，§2097 作“经由寂静处所到达的道”。三处都没有取“唯一”义。译文统一用了“唯一的道路”。这一点不必改，只作记录。

## §2102 句 150-2102-2-25
- **问题**：原文疑问 — nissaya 在 mohatamaṃ 之后多出一条 `မာနတမံ= မာနဟူသောအမိုက်တိုက်ကို`（慢的黑暗），本段巴利原文没有 mānatamaṃ。应是 nissaya 所据的版本不同。译文随巴利原文，不必增补。

## §2102 句 150-2102-26-41
- **问题**：词义参考 — pāsāṇake cetiye 的 nissaya 是 `မြတ်စွာဘုရားတို့၏နေရာဖြစ်သောကျောက်ဖျာ၌`（在诸佛坐处的石板上）。译文按专名处理为“巴沙那迦塔庙”，可以保留，只记录 nissaya 的释法。

## §2104 句 150-2104-2-7（偈 §2103–2104）
- **问题**：格 — nissaya 是 `အာသီနံ= နေတော်မူသော`、`ပါရဂုံ= …ရောက်တော်မူပြီးသော`、`မုနိံ= မြတ်စွာဘုရားသို့`。三个词都是宾格：āsīnaṃ 和 pāraguṃ 是修饰 muniṃ 的定语，muniṃ 是 payirupāsanti 的宾语。译文 §2103 写成“牟尼，已经到达苦的彼岸”，成了主谓结构，只靠 §2104 的“他”才回指上宾语。
- **建议**：改为“坐在山边、已到苦之彼岸的牟尼，具有三明、舍离死亡的弟子们恭敬地侍奉他”，让 pāraguṃ 回到定语位置。
- **问题**：词义参考 — nagassa 的 nissaya 作 `ရာဇဂြိုဟ်ပြည်၏`（王舍城的），似读作 nagara。译文“山边”取 naga 的本义。两说都记下，这一处不强制修改。

## §2106 句 150-2106-18-31
- **问题**：用字 — obhāsakaro 译“放光辉者”，与 jutimā 撞词（见上文“跨段一致性”）。nissaya 把整组词都释为“作（智慧之）……”的同构句式（`…ကိုပြုတတ်၏`），译文却用了作／造／放／点／举／发六种动词，读起来像是有意分别。
- **建议**：obhāsakaro 改为“作照耀者”。整组可以考虑统一用“作…者”的格式。

## §2107 句 150-2107-2-25（§2110 同）
- **问题**：指代 — taccarito … tadadhipateyyo 中的 tad，nissaya 全部释为 `ထိုပညာ`（那个慧）。译文用“此”，所指不明。
- **问题**：语体 — tabbahulo 译“以此为多”，是翻译腔，不通顺。nissaya 是 `ထိုပညာကိုများသောအားဖြင့်ပွါးစေ၏`（多多修习那个慧）。
- **建议**：“此”明确为“慧”，或在首次出现时点明；tabbahulo 改为“多修习慧”或“常修于此”。§2107 与 §2110 要同步修改，保持逐字一致。
- **问题**：原文疑问 — §2110 的 nissaya 把 samokkhāyanadhammo 写作 `သမောက္ခာယနဗဟုလော`（samokkhāyanabahulo），与巴利原文不一致，疑为 nissaya 底本的异读。译文随巴利原文。
