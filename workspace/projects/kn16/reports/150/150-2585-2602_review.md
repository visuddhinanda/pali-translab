# Review — 150:2585-2602（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（2585、2586、2593、2595、2596、2601 各行没有 nissaya，已略过；这几段的偈颂与 2587、2594、2597、2602 同文，相关意见一并适用）

## 跨段一致性

- **alaṅkaritvā 与 vibhūsā 都译成“装饰”**：§2587／2589／2594 的 analaṅkaritvā 译“不以为装饰”，§2587／2590／2592／2594 的 vibhūsā(-ṭṭhānā) 也译“装饰”。nissaya 把两者分得很清楚：`အနလင်္ကရိတွာ= အမြတ်အားဖြင့်မယူမူ၍`（不当作珍贵的东西），`ဝိဘူသာ= တန်ဆာ`（装饰品）。现在两个不同的词共用“装饰”，读者会以为是同一个概念 → 建议 analaṅkaritvā 改译“不看重”或“不视为珍贵”。偈颂 §2586／2593 与 lemma §2589 要同步修改。
- **kāmaguṇa 与 kāma 都译成“欲”**：§2588 的 kāmaguṇā 译“五种欲”，§2597／2600 的 kāma 也译“欲”（分为“事欲”“烦恼欲”）。nissaya 对两者分别作 `ကာမဂုဏ်`／`ကာမ`，指的不是同一层概念 → 建议 kāmaguṇa 统一译作“五种欲境”或“五欲功德”，“欲”只留给 kāma。§2588 中 54-61 与 94-101 两句要同步修改。
- **vilepana 前后译法不同**：§2590 同一句里，前面译“涂身的香膏”，后面的 mālāgandhavilepanaṃ 译“花鬘香料与涂香” → 建议统一为“涂香”。
- **“装饰之事”有文言虚词“之”**：出现在 §2587／2590／2592／2594 → 建议四处统一改为“装饰这类事”或“种种装饰”。

## §2587 句 150-2587-2-26
- **问题**：风格。“装饰之事”中的“之”是文言虚词。另外，nissaya 把 vibhūsaṭṭhānā 读作从格：`တန်ဆာဆင်ခြင်းတည်းဟူသောမေ့လျော့ခြင်းအကြောင်းမှ`（从“装饰”这种令人放逸的缘由离开），ṭhāna 的意思是“缘由”。
- **建议**：改为“远离装饰这类事”。§2590、§2592、§2594 同步修改。

## §2588 句 150-2588-54-61
- **问题**：术语。kāmaguṇā 的 nissaya 作 `ကာမဂုဏ်တို့သည်`，译成“欲”丢掉了 guṇa，而且和 §2600 的 kāma 混在一起（见跨段一致性）。
- **建议**：改为“比丘们，有这五种欲境”（或“五欲功德”）。150-2588-94-101、150-2588-102-120 中的“五种欲”同步修改。

## §2589 句 150-2589-2-21
- **问题**：词义。analaṅkaritvā 的 nissaya 是 `အမြတ်အားဖြင့်မယူမူ၍`（不当作珍贵的东西），不是“不当作装饰”。这里 alaṅkaroti 取的是“看重、推崇”的意思。
- **建议**：改为“不看重、毫无顾恋”。lemma 与偈颂（§2586／2587／2593／2594）同步修改，以保证逐字一致。

## §2590 句 150-2590-30-88
- **问题**：句法。`ဩဒါတာနိ= ဖြူကုန်သော`、`ဒီဃဒသာနိ= ရှည်သောအဆာရှိကုန်သော` 都带定语标记 `ကုန်သော`，共同修饰 `ဝတ္ထာနိ`，说的是同一件衣服。译文拆成“白色衣服、长边衣服”两项，是误读。
- **建议**：合为一项：“带长穗的白色衣服”。
- **问题**：词义。ādāsaṃ 的 nissaya 是 `ကြေးမုံကြည့်ခြင်း`（照镜子），añjanaṃ 是 `မျက်ရေးကွင်းခြင်း`（画眼线），都是动作，不是物品。
- **建议**：改为“照镜子、涂眼膏”，和前后的“搽香粉、按摩、沐浴”保持一致。
- **问题**：词义。uṇhīsaṃ 的 nissaya 是 `နဖူးသင်းကျပ်`（额带），译“头冠”不合。而且 veṭhana 已经译成“头巾”（`ဦးရစ်`），两项应分开。
- **建议**：uṇhīsa 改为“额带”。
- **问题**：词义。nāḷikaṃ 的 nissaya 是 `အဆန်းတကြယ်ပြုသောဆေးကျည်`（做工精巧的药筒），“小筒”说得太含糊。
- **建议**：改为“精巧的药筒”。
- **参考（不改）**：nissaya 所据底本在这个位置读作 sayanāsanaṃ（`အိပ်ရာနေရာ`，卧具与坐具），而 pali 正文是 pārupanañca，属于异读。译文按正文译“披巾”，可以保留。

## §2597 句 150-2597-2-9
- **问题**：句法。nissaya 把 puttañca、dārañca、pitarañca、mātarañca、dhanāni、dhaññāni、bandhavāni 都标成宾格（`ကို`），和 kāmāni 一起作 `ဇဟိတွာန`（舍弃）的宾语。译文把偈颂拆成两行，前一行没有动词，后一行“舍弃了…种种欲”看起来只管“欲”，前一行列出的亲人和财物就和“舍弃”失去了联系。
- **建议**：在保留分行的前提下补出动词关系。比如前一行末用逗号，后一行开头改为“舍弃这些，以及依各自分际的种种欲”；也可以直接在前一行开头加“舍弃”。§2596、§2601、§2602 同步修改。

## §2598 句 150-2598-9-35
- **问题**：词义。dinnako 的 nissaya 是 `ဥစ္စာပေး၍ရသော`（付给财物而得到的），译“领养的”没有译出这层意思。
- **建议**：改为“以财物换来的儿子”或“过继来的儿子”。
- **参考**：khettajo 的 nissaya 作 `အခိုက်အတန့်ဖြစ်သော`，意思不清楚，没法据此判定译文“妻子所生的儿子”有误，先保留。

## §2599 句 150-2599-2-27
- **问题**：词义。silā 的 nissaya 是 `ကျောက်သလင်း`（水晶），译“宝石”太宽。masāragallaṃ 的 nissaya 是 `ပတ္တမြားပြောက်`（带斑点的宝石），而 nissaya 把“猫眼”（`ကြောင်မျက်ရှင်`）给了 veḷuriya。译文却把“猫眼石”配给 masāragalla，对应关系错了。
- **建议**：silā 改为“水晶”，masāragalla 改为“斑纹宝石”。veḷuriya 保留传统译法“琉璃”。

## §2599 句 150-2599-28-32
- **问题**：词义。aparaṇṇaṃ 的 nissaya 是 `ပဲမျိုး`（豆类），下一句 sūpeyyaṃ 也是“做羹汤的豆类”。译“杂粮”不准确，和下一句也对不上。
- **建议**：改为“谷物是指谷类与豆类”。150-2599-33-49 的“主粮是指…”、150-2599-50-54 的“杂粮是指…”同步改为“谷类是指…”“豆类是指…”。

## §2599 句 150-2599-33-49
- **问题**：词义。varako 的 nissaya 是 `ပြောင်း`（高粱一类），译“稗子”不合。vīhi 的 nissaya 是 `ကောက်`（稻谷），译“糙米”偏窄。
- **建议**：varaka 改为“高粱”，vīhi 改为“稻谷”。

## §2599 句 150-2599-55-76
- **问题**：句法。nissaya 把 ñāti-/gotta-/mitta-/sippa-bandhavā 都解作“以某种关系结成的”（`အဆွေအမျိုးအားဖြင့်ဖွဲ့ခြင်းရှိသော` 等），带工具意味。译文“亲属亲族是亲人”同义反复，看不出四种亲族的区别在哪里。
- **建议**：改为“因血亲结成的是亲人，因同族姓结成的是亲人，因友谊结成的是亲人，因技艺结成的是亲人”。

## §2600 句 150-2600-44-61
- **问题**：句法。`တေ ကိလေသေ= ထိုကိလေသာတို့ကို` 是宾格，三个动词都以“那些烦恼”为宾语。译文“他对那些烦恼……不再回来、不再返回”没有把宾语关系表达出来，“对……回来”也说不通。
- **建议**：改为“他不再走向、不再走近、不再回到那些烦恼”。150-2600-62-96 句末同一组动词同步修改。

## §2600 句 150-2600-30-43
- **参考（不改）**：parijānitvā 的 nissaya 作 `စွန့်၍`（舍弃），是取义上的意译。译文按字面译“彻底了知”，与 pali 相符，保留。
