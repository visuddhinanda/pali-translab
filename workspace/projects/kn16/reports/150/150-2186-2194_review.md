# Review — 150:2186-2194（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（2186、2187、2193 无 nissaya 单元，略过）

## 跨段一致性
- **pariphandamāno**：偈颂 §2187 / §2193、被解释词 §2189-2-7、§2189-35-354 词头都译“挣扎”。但同一段内基本词 phandamāno 也译“挣扎”，段末同义词串里 pariphandamāno 又译“周遍挣扎”。结果同一个词在一段之内有两种译法，pari- 与基本词也分不开。nissaya：`ပရိဖန္ဒမာနော= ထက်ဝန်းကျင်မှတုန်လှုပ်သော`（四面八方地颤动）。→ 建议 pariphandamāno 统一为“辗转挣扎”（或“四处挣扎”），phandamāno 保留“挣扎”。偈颂 §2187、§2193、被解释词 §2189 各处、段末结语“这就是‘躺在泥沼中……’”要同步改，保持逐字相同。
- **byasana**（§2189-35-354 末尾五项）：ñāti- / bhoga- / roga- 译“败亡”，sīla- / diṭṭhi- 译“败坏”，同一组排比用了两种译法。nissaya 对其中四项都用 `ပျက်စီးခြင်း`（毁坏、丧失）。→ 建议五项统一，例如“亲属的丧失、财产的丧失、健康的丧失、戒的丧失、见的丧失”。
- **sota / kaṇṇa**（§2189-35-354）：sotarogena 译“耳病”，kaṇṇarogena 译“耳朵病”，读者分不出差别。nissaya：`သောတ= နား`（耳，听觉器官），`ကဏ္ဏ= နားရွက်`（耳廓）。→ 建议 sota 译“耳病”，kaṇṇa 译“耳廓病”。
- **upallaviṃ**：被解释词 §2190 译“漂（到）”，同义词串里译“漂荡”。差别不大，可以保留。若要严格对应，可把同义词串调为“漂流、漂到、四处漂泊”。

## §2189 句 150-2189-35-354
- **问题**：格与句法。“ratto rāgena / duṭṭho dosena / mūḷho mohena / vinibandho mānena / parāmaṭṭho diṭṭhiyā / vikkhepagato uddhaccena / aniṭṭhaṅgato vicikicchāya / thāmagato anusayehi”这八项里，nissaya 把具格名词挂在前面的过去分词上，例如 `ရာဂေန= ရာဂဖြင့်။ မုတ္တော= တပ်သည်ဖြစ်၍`（因贪而染着），然后才接 phandamāno。现译“被贪染着的人因贪而挣扎”把 rāgena 挂到了“挣扎”上，“贪”说了两遍，而“染着”与“贪”之间的因果关系丢了。
- **建议**：改为“被贪所染而挣扎，被瞋所坏而挣扎，被痴所迷而挣扎，被慢所缚而挣扎，被见错误执取而挣扎，因掉举陷于散乱而挣扎，因疑无法决断而挣扎，因随眠变得坚固而挣扎”。
- **问题**：thāmagato 的词义。nissaya 作 `အားရှိခြင်းသို့ရောက်`（变得有力、坚固），指随眠根深蒂固，不是人的性格“顽固”。
- **建议**：改为“随眠变得坚固而挣扎”，见上条。
- **问题**：aṃsāya 译“痔疮”。nissaya 作 `ပခုံးအနာ`（肩病）。译文取了另一个解，但没有依据说明。
- **建议**：改用 nissaya 的“肩病”；若坚持“痔疮”，须在报告中写明依据。
- **问题**：visamaparihārajena 译“照护不当”。nissaya 作 `မညီညွတ်သောဣရိယာပုဒ်ကြောင့်`（因姿势、威仪不调）。
- **建议**：改为“因姿势失调引起的病”。
- **问题**：jātassūpanibandhakena 译“出生后随之而来的苦”，太泛。nissaya 作 `ကပ်၍ဖွဲ့သော`（紧附系缚的），并举洗浴等婴儿护理为例。
- **建议**：改为“出生后被系缚的苦”或“出生后与之相系的苦”。
- **问题**：vitacchikā 译“皮疹”，太泛。nissaya 作 `ခြေဖဝါးလက်ဖဝါးတို့၌ပေါက်သောအနာ`（手掌、脚掌上长出的疮）。
- **建议**：改为“手足疮”或“掌跖疮”。
- **问题**：rogabyasanena 译“疾病败亡”，语义不通。nissaya 作 `အနာနှိပ်စက်ခြင်း`（疾病的逼迫）。
- **建议**：改为“健康的丧失”或“病患之灾”，与跨段一致性一节的 byasana 统一一并处理。
- **问题**：yasena / ayasena 译“名誉 / 失去名誉”。nissaya 作 `အခြံအရံရှိ / မရှိ`（有随从眷属 / 无随从眷属）。可以保留“名誉”，但应知道 nissaya 取的是眷属义。
- **建议**：可改为“名望（眷属）”；若保留现译，就压低该句 confidence。

## §2189 句 150-2189-8-34
- **问题**：parivasamāno 译“周遍地住着”。nissaya 作 `အမြဲနေ`（一直住着、常住）。
- **建议**：改为“一直住着”。

## §2190 句 150-2190-2-25
- **问题**：词义与句法。dhammakkhānato dhammakkhānaṃ 被译成“从一种法的宣说到另一种法的宣说”。nissaya 作 `တရားကိုကြားတတ်သောသူတစ်ပါးမှ … သို့`（从一位说法者到另一位说法者），把这个词读作人，和前面的 satthāra（导师）、后面的 gaṇa（团体）平行。
- **建议**：改为“从一位说法者到另一位说法者”。

## §2191 句 150-2191-24-42
- **问题**：隐含成分。nissaya 在 yadidaṃ buddho 后补出 `နာမံ`（名称），并说明 sacchikā paññatti 是 `နာမပညတ်`（名称施设）。现译“也就是‘佛陀’”没有补出“名称”，前面“是证悟而来的施设”就失去了主语所指。
- **建议**：改为“……这个名称是由现证而成立的施设，也就是‘佛陀’这个名称”。

## §2192 句 150-2192-5-42
- **问题**：误译（必改）。so vutthavāso 译“他已住完梵住”。nissaya 作 `အရိယာတို့၏နေခြင်းဖြင့်နေတော်မူပြီ`（已经以圣者的方式住过、圆满了住），意思是梵行已经完成，与 brahmavihāra（梵住、四无量心）无关。用“梵住”会和那个专门术语混淆。
- **建议**：改为“他已经圆满住立（圣住）”或“他已度过（修行的）生活”。
- **问题**：句法。nissaya 把 jātimaraṇasaṃsāro 和 punabbhavo 都作为 natthi 的主语（`…သည်လည်းကောင်း … သည်လည်းကောင်း … နတ္ထိ`），意思是“生死轮回与再有，对他都已不存在”。现译“……乃至……生死轮回，他不再有后有”把“生死轮回”悬空了。
- **建议**：改为“……乃至……生死轮回与后有，对他都已不存在”。

## §2192 句 150-2192-56-67
- **问题**：句法与语体。tālāvatthukatā 的意思是“被做成像截断的棕榈树桩那样”，nissaya 作 `ထန်းပင်ငုတ်တို့ကဲ့သို့ပြုအပ်ကုန်ပြီ`，这是谓语，和 pahīnā、ucchinnamūlā 并列。现译“就像被截断的棕榈树桩”成了游离的比喻。“已不复存在”中的“不复”略带文言色彩。
- **建议**：改为“……它们的根已被斩断，已被弄得像截断的棕榈树桩，已被弄得不再存在，将来不会再生起”。

## §2188 句 150-2188-2-6
- **问题**：句法（轻微）。nissaya 中 oghatiṇṇaṃ、anāsavaṃ 都是宾格，修饰 `တံဗုဒ္ဓံ ကို`（那位佛陀），是宾语的定语。现译“他已渡过暴流、无漏”改成了独立分句，可以接受。
- **建议**：可以保留。若改成“见到了已渡过暴流、无漏的正觉者”，§2192 被解释词和 §2194 要同步改。

## 原文疑问（nissaya 底本异读，仅记录，不改）
- §2187 / §2190 / §2194：pali 作 dīpā dīpaṃ，nissaya 底本作 `ဒိသာ ဒိသံ`（disā disaṃ），并释为“从一处依止之所到另一处”。
- §2189-8：pali 作 kāmapariḷāhe，nissaya 作 `ကာမုပက္ကိလေသေ`（kāmupakkilese）。
- §2189-35：pali 作 payogaphandanāya，nissaya 作 `သံယောဂ`（saṃyoga）。pali 作 ratto，nissaya 作 `မုတ္တော`，疑为抄误。
- §2188：nissaya 把 atha 释为 `ထိုပါသာဏစေတီ၌`（在那座 Pāsāṇaka 塔庙），是随文的情境释义，与 §2191 把 atha 解释为连接词的说法不同。译文作“后来”可以保留。
