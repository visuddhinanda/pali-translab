## 理由

**准确性**：逐句核对巴利原文、nissaya 与词义未见误译。四种"人"（tamotamaparāyano / tamojotiparāyano / jotitamaparāyano / jotijotiparāyano）的译名"从暗入暗者／从暗入明者／从明入暗者／从明入明者"在整批八段中前后统一，且与每段末尾"puggalo ... hoti"的定性句一一对应，未见错位。种姓词（caṇḍāla / vena / nesāda / rathakāra / pukkusa）逐一核对 nissaya：值得指出，`rathakāra` 字面为"造车者"，但 nissaya 释作"သားရေနယ်သမား"（皮革匠），译文取"皮匠家"而非字面"车匠"，正确遵循了 nissaya 词级基准而非字面直译，是好的处理。`seyyāvasathapadīpeyyassa`（卧具/住处/灯具）、`apāyaṃ duggatiṃ vinipātaṃ nirayaṃ`（苦界/恶趣/堕处/地狱）等四词并列结构均逐词对应，无漏译。升降喻（1566 段登阶：地面→床座→马背→象背→楼阁；1568 段下阶：楼阁→象背→马背→床座→地面→黑暗）方向与逐级对应关系核对无误，`āroheyya`(登/上)与`oroheyya`(下)、`paviseyya`(进入)三个动词也分别译作"登上/下到/进入"，未混用。

**风格**：通篇未见 `knowledge/style.md` 禁例表中的文言虚词或半文半白句式（未见"曰/云/之/其/乃/便/遂/於"等），标点全部用全角，译文字段内未见 ASCII 引号，符合 JSON 安全约束。"以身……、以语……、以意……"这一固定句式贯穿全篇，属于佛典常见的规范表达，非文言腔，不计入扣分。

**一致性**：两处结构相同、巴利原文相同的说明段落（1563 段"卑贱家庭"描述 vs 1565 段同一描述；1563/1567 段"以身行恶行……"结论句）译文逐字一致，处理得当。但发现一处贯穿三段的**标点（引号）不一致**：巴利原文中每次以"‘‘"重新起讲的段落（如 1563-2-10、1565-2-11、1567-2-11 的"Kathañca"设问段）译文都补了开引号"“"，但结构完全平行、同样以"‘‘"起讲的三处比喻段（1564-2-24、1566-2-28、1568-2-33 的"Seyyathāpi"譬喻段）却都没有补开引号，造成同一篇讲话内引号补法前后不一。这是格式一致性问题，不影响文义，按 warning 处理。
