# Review — book=167:3370-3379（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分段落）／义注 ✅（book=133, 仅对应 §3372 首现的三词及标题）

## 跨段一致性

- **manussadaliddo / manussakapaṇo / manussavarāko** 这组三词在 §3372（首现，94-138，含帝释引述）与 §3373（26-52，帝释复述）中重复出现，译文均统一为「人间的穷人，人间的乞丐，人间的可怜人」——**用词前后一致**，值得保留（无需改动一致性本身），但见下方「义注核对」——一致地译错也仍是问题。
- **so aññe deve atirocati vaṇṇena ceva yasasā ca** 一句三次出现：
  - §3372(74-82) 世尊叙述版：「他以容色和威望超越了其他诸天神。」
  - §3372(126-138) 诸天抱怨引语版：「他**竟**以容色和威望超越了其他诸天神。’”」
  - §3373(79-91) 帝释复述版：「他**竟**以容色和威望超越了其他诸天神。’”」
  → 世尊叙述版没有「竟」，两处引语版有「竟」。原文三处巴利完全相同，加「竟」是译者揣摩语气所加，不算错，但**建议統一**：要么三处都不加「竟」（更贴近字面、更安全），要么在世尊叙述版里说明为何唯独此处不加。当前处理并非明显错误，但值得核对是否有意为之。

## §3372 句 167-3372-2-29（id）

- **问题**：术语取义 — `manussakapaṇo` 与 `manussavarāko` 的汉译疑似与义注定义错位。
  - **义注**：「manussakapaṇoti manussakāruññataṃ patto」（manussakapaṇo = 达到值得人怜悯的境地）；「manussavarāko ti manussalāmako」（manussavarāko = 人中卑劣者/低劣者）。
  - 译文将 `manussakapaṇo` 译作「人间的乞丐」，`manussavarāko` 译作「人间的可怜人」——两词的汉译语义**与义注的对应关系错位**：义注中「值得怜悯」对应 kapaṇo，而「可怜」这一语义被安在了 varāko 身上；varāko 本义是「卑劣/低下」（lāmako），却完全没有译出，被「乞丐」（一个义注未提及的具体身份词）取代。
  - **建议**：改为更贴近义注的三段式，例如「是人间的穷人，是令人怜悯的人，是人间的卑贱者」——kapaṇo → 令人怜悯的人/惹人怜悯的人；varāko → 卑贱的人/低贱的人。此改动会连带影响 §3372(103-112)、§3373(26-52) 两处重复段，需同步统一修改（保持跨段一致性）。

## §3372 句 167-3372-103-112（id）

- **问题**：同上「manussakapaṇo/manussavarāko」取义问题，重复出现，与首现处保持了一致但错误也随之复制。
- **建议**：与 §3372-2-29 一并修正。

## §3373 句 167-3373-26-52（id）

- **问题**：同上，帝释复述中再次出现「人间的乞丐，人间的可怜人」。
- **建议**：一并修正为与前两处统一的新译法。
