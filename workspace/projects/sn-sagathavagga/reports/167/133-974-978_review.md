# Review — 133:974-978（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅（各行内嵌）／nissaya ✅（逐句内嵌）／父层译文 ✅（book 167，用于核对黑体被解释词）
> 本层无更上层复注可对照，僅以父层（mūla）译文核对黑体词。

## 跨段一致性

- **dhi / dhikāra 词根**：§974 内同一词根三次出现，译法不统一——
  - 133-974-109-128：`dhi kokālika` → “呸，拘迦利”（保留词根“呸”）
  - 133-974-129-134：`dhi-kāraṃ` → “呸斥之声”（仍含“呸”）
  - 133-974-135-143：`ekadhikāro` → “一片同声的**呵斥**”（丢了“呸”这个词根）
  
  nissaya 对 `ekadhikāro` 的释义是 `တစ်ပြိုင်နက်ထွီထွီအသံ`（“同时的‘呸呸’之声”），说明这三处是同一意象的延续（村民喊“呸”→护卫天神发出“呸”声→一路传到色究竟天的同一声“呸”）。第三处改用“呵斥”把词根线索断掉了，建议统一改为“一片同声的**呸斥**”或类似含“呸”字的表述。

- 其余术语（拘迦利 / 红莲地狱 / 阿浮陀 / 尼罗浮陀 / 俱胝系列单位 / 钵他系列单位）在全 chunk 内前后一致，无问题。
- 未发现文言/半文半白用词——本 chunk 在这一项上是干净的。

## §974 句 133-974-94-103
- **问题**：准确性 — “像吞了**毒饵**的鱼一样”里的“饵”是译文添加的具体情节（暗示钩饵下毒），nissaya 只作 `ဝိသဂိလိတော = အဆိပ်ကိုမျိုမိသော`（“吞了毒药”），未提及“饵/钩”。
- **建议**：改为更贴近原文的“像吞了毒药的鱼一样”，若确认“毒饵”是固定譬喻可保留，但建议在术语表标注依据。

## §974 句 133-974-109-128
- **问题**：标点 — 这是村民的直接引语（不是术语训释），却用了单引号‘ ’；本 chunk 其余术语训释（如 ‘**离去**’‘**红莲地狱**’）也用单引号，导致“训释引号”和“对话引号”混用无区分，且与父层（book 167）对话统一用全角双引号“”的惯例不一致。
- **建议**：改为“呸，拘迦利！呸，拘迦利！他做了不该做的事，只因自己的口而招致了灾祸不幸。”他们这样说。（双引号），与父层对话引号惯例统一。

## §974 句 133-974-104-108（次要，可选）
- **问题**：准确性（轻微）— `āgatāgatā`（重叠形式，“一批批／陆续前来”）的重复语气未体现，现译“前来听法的人们”读起来像一次性到场。
- **建议**：可改为“陆续前来听法的人们”，非必改，视是否需要保留这层细节。
