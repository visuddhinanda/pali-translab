# Review — 167:1027-1034（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅覆盖偈颂部分 §1029-1030、§1031-1034，§1027-1028 无逐词释义属正常）／义注 ✅（仅逐词释义 veṇḍū / payirupāsiyā / anusikkhare / siṭṭhipade / kāle te appamajjantā，非逐句疏文）
> 说明：本层是 mūla（本文），无父层，"被解释词与父层逐字同译"一项不适用；下方按义注/nissaya 释义标准核对译文。

## 跨段一致性
- **sikkh-（学/训练）词根**：§1030「sikkhare」译「修学」，§1032「anusikkhanti」译「随学不倦」。**义注**（133-535-18-22）明确将 anusikkhare 释为 sikkhanti，即二者同义；nissaya（167-1034 附）也把 anusikkhanti 释作「ကျင့်ကုန်၏」（践行），并无「不倦」之义。两处应统一译法，且不应附加原文没有的「不倦」修饰 → 建议统一为「修学」（或都改「践行」），删去「不倦」。

## §1029 句 167-1029-2-23
- **问题**：准确性 — 「sugataṃ payirupāsiya」是简单的动名词/原因状语（**义注**：payirupāsiyā = parirupāsitvā，「亲近之后」；nissaya：ပရိယူပါသိယ = ဆည်းကပ်ခြင်းကြောင့်，「因为亲近」），并无「能够」（可能性/能力）之义，译文「能够亲近善逝之后」中的「能够」是无据添加。
- **建议**：删去「能够」，改为「亲近善逝之后」或「因为亲近善逝」。

## §1032 句 167-1032-2-4
- **问题**：准确性 — 「Anusikkhanti」按**义注**（anusikkhare = sikkhanti）与 nissaya（ကျင့်ကုန်၏，践行）均只是「修学/践行」之义，译文「随学不倦」中的「不倦」为无据添加；且与 §1030 的「修学」译法不一致（见上方跨段一致性）。
- **建议**：改为「这些禅修者修学不辍」中的「不辍」也宜删，直接译「这些禅修者随学」或与 §1030 统一为「修学」。

无其他问题的句子未列出（§1027、§1028、§1031、§1033、§1034 经核对文言/术语/义注-nissaya 依据均无误）。
