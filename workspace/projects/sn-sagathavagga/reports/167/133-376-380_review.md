# Review — 133:376-380（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／义注：本层即为义注本身，父层 book=167（mula，段 491-507）译文对照完整。

## 跨段一致性

- **被解释词核对**（本层黑体词 vs 父层 book 167 译文）：绝大多数一致，逐字核对通过——具念正知 / 七百位 / 说出…感兴语 / 龙象 / 具有龙象般的品质 / 狮子 / 良种马 / 牛王 / 能负重的牛 / 已调伏者 / 看 / 定力 / 善解脱 / 既不倾向前，也不倾向后 / 也不是靠刻意压制、强行抑制而成的 / 冒犯 / 没有看清真相 / 五部吠陀 / 百年 / 修苦行 / 并未真正解脱 / 这种低劣的人无法到达彼岸 / 执迷于渴爱 / 被戒禁所束缚 / 耽溺我慢的人，均与父层逐字相同。唯 133-376-2-7（脚/叠脚）父层是整句意译（"一脚叠在另一脚上"），没有可逐字比对的拆分点，见下方单独说明。
- **"之"作文言领属助词**在本 chunk 反复出现（阿罗汉果**之**定 / 果位**之**定 / 无与伦比**之**故），且与同段内"…的缘故"并存（378 段一句"因为无与伦比的缘故"、另一句"因无与伦比之故"），跨段/段内均不统一，属高频问题，逐处见下。

## §376 句 133-376-2-7
- **问题**：准确性 — "“**脚**”“**叠脚**”"把下一词条 accādhāya 才有的"叠"义提前加到了 pādaṃ 头上。nissaya 该条只给"ဒက္ခိဏပါဒေ=右脚（处格）／ဝါမပါဒံ=左脚（宾格）"，没有"叠"的意思，"叠"是下一条"**Accādhāyā**ti"单独交代的。
- **建议**：改为"“**脚**”“**脚**”是指：右脚上，左脚"，把"叠"留给下一条"**叠放**"单独解释，避免两条词义重叠。

## §376 句 133-376-8-16
- **问题**：风格（文言）— "即稍微越过而放置"的"即"是 style.md 明文禁用的单字文言虚词。
- **建议**：改为"也就是稍微越过而放置"。

## §377 句 133-377-34-77
- **问题**：风格（文言）— "在这样的苦受持续生起**之时**"、句末"这样的感兴语**便**生起了"，"之时"“便”均是 style.md 表中明确列出的禁例。
- **建议**：改为"在这样的苦受持续生起的时候"；"便生起了"改"就生起了"。

## §378 句 133-378-2-12
- **问题**：义注释义存疑 — "“**尊者**”是恭敬的称呼语"，nissaya 原文只说 bho 是"不含催促、无过失的自然称呼语"（dhammālapana），并未特别点出"恭敬"这层语气，"恭敬"是译者自行加上的判断。
- **建议**：如无更明确依据支撑"恭敬"，建议改为语气更中性的"习惯性的称呼语"，或保留但在报告存疑区标注待核实。

## §378 句 133-378-34-44
- **问题**：术语处理不合规 — "百牛之首称为“usabho”，千牛之首称为“vasabho”"把拉丁字母原词直接嵌入译文正文，不符合 style.md 的术语策略（罕见术语须**汉语音译**并首次夹注巴利原词，不能是裸露的拉丁词根）。
- **建议**：改为"百牛之首称为“乌萨波”（usabho），千牛之首称为“瓦萨波”（vasabho），十万牛之首才称为“尼萨波（nisabho，牛王）”"。

## §378 句 133-378-45-51
- **问题**：①准确性/连贯性 — "āsabhaṃ ṭhānaṃ"（与紧接的"nisabho"同源，直译"牛王/至尊之地位"）被抽象译成"至上的地位"，导致下一句"正因如此，这里才说“牛王”"读起来像是逻辑跳跃，看不出"至上的地位"为何能推出"牛王"这个称号。②风格（文言）— "因无与伦比**之故**"，与同段前一句"因为无与伦比的缘故"（133-378-31-33）用词不统一，且"之故"偏文言。
- **建议**：①译出与"牛王"呼应的意象，如"自称已达至尊（牛王）的地位"；②统一改为"因为无与伦比的缘故"。

## §379 句 133-379-6-9
- **问题**：风格（文言）— "阿罗汉果**之**定"用"之"作领属助词。
- **建议**：改"阿罗汉果**的**定"。

## §379 句 133-379-33-51
- **问题**：风格（文言）— "以果位**之**定而摄持安住，这就是**其**含义"，"之"“其”均是 style.md 禁用单字文言虚词。
- **建议**：改为"以果位的定摄持安住，这就是这句话的意思"。

## §380 句 133-380-69-78
- **问题**：准确性（误译）— "ajavata"被译成"**牛**戒"。原文 aja＝山羊，nissaya 明确给"ဆိတ်၏အကျင့်"（山羊的行为），不是牛。
- **建议**：改为"**羊**戒、狗戒等禁戒"。

## 存疑处
- 133-378-2-12 "bho" 是否确有"恭敬"义（见上，建议核实）；
- 133-378-45-51 "āsabhaṃ ṭhānaṃ" 的"牛/王"意象是否需要保留（见上）。
两处均建议在 revise 阶段一并核实定案。
