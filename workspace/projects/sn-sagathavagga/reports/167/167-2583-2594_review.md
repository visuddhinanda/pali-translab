# Review — 167:2583-2594（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分段落，见各条）／义注 ✅（取自 book 133 对应段落，仅供校对；本层为 mūla，无父层译文可比对"被解释词逐字同译"）

## 跨段一致性
- `vātehābādhiko`：§2584、§2587 均译「风病」——译法本身一致，但均存在同一处准确性问题（见下），需同步修正。
- `pattacīvara` → §2584 译「大衣」，与 §2585 `saṅghāṭi` → 「僧伽梨衣」的「大衣」用字冲突，产生混淆，见下。
- 其余术语（阿罗汉、善逝、比丘等）跨段一致，无问题。

## §2584 句 167-2584-9-16
- **问题**：准确性 — `vātehābādhiko` 译作笼统的「风病」，丢失了义注的限定。
  **义注**（133-1110-2-10）：`vātehī ti udaravātehi` ——明确将 `vāta` 限定为**腹内（udara）之风**，并有背景说明（133-1110-11-24）：世尊苦行六年、饮食失调导致的腹部气疾，此后时时发作。这是对佛陀病症的具体医学指认，不是泛泛「风病」。
- **建议**：改译为能体现「腹内之风/肠胃胀气」义的说法，如「患了腹部气疾」「患了肠胃胀气之病」，并在 §2587 同步统一。

## §2584 句 167-2584-45-65
- **问题**：准确性/跨段一致性 — `pattacīvaramādāya` 中 `cīvara` 是泛指「衣（衣物）」，译作「大衣」把它坐实成了 `saṅghāṭi`（僧伽梨），而 §2585 恰好又将 `saṅghāṭi` 精确译为「僧伽梨衣」。同一「大衣」字样先后指代不同的巴利词，会让读者误以为二者是同一件衣。
- **建议**：改为「拿着钵和衣」或「拿着衣钵」，把「大衣／僧伽梨衣」这个更精确的译法留给真正对应 `saṅghāṭi` 的地方。

## §2587-2588 句 167-2587-2-10 / 167-2588-2-9
- **问题**：准确性 — 同 §2584，`vātehābādhiko` 再次译作「风病」，同一处理不精确的问题（义注依据同上）。
- **问题**：标点/格式（可机械核查）— 这两段是同一偈颂的跨段引语（§2587 以 “ 开引号、无收），但 §2588 结尾「……请给这位牟尼吧。」**缺少收尾引号 ”**。对照本 chunk 其余跨段引语（§2585→§2586 以 ” 收尾；§2589→§2590 以 ” 收尾；§2593→§2594 以 ” 收尾），此处是唯一未闭合的一处，属遗漏。
- **建议**：改为「……请给这位牟尼吧。”」

## §2589-2590 句 167-2589-2-9 / 167-2590-2-24
- **问题**：准确性（首要）— `Pūjito pūjaneyyānaṃ`、`sakkareyyāna sakkato`、`Apacito apaceyyānaṃ` 三组并列的属格结构，现译均处理为「受……中的供养/敬重/礼敬」，即把属格读作**部分格**（世尊是「值得供养者」这一群体之中的一员，因而受供养）。
  **义注**明确否定这一读法：`pūjaneyyā` = `asītimahātherā`（八十大长老，133-1111-71-79）；`sakkareyyā` = `teyeva sakkātabbā`（就是那些大长老应受礼敬，133-1111-80-83）；`apaceyyā` = `tesaṃyeva apaciti kattabbā`（还是同一批大长老应受礼敬，133-1111-84-88）。紧接着的关键句（133-1111-89-102）：`Bhagavā tesaṃ pūjito sakkato apacito ca` ——「世尊被**他们（tesaṃ，即那些大长老）**供养、敬重、礼敬」。`tesaṃ` 是**施动属格**（by them），可见 `pūjaneyyānaṃ` 等三个属格同理，是「被……（这些本身就值得供养的大长老）供养」的施动结构，不是「在……之中」的部分格。
  这不是措辞问题：现译读作"世尊只是众多值得供养者之一"，义注确认的原意是"连本身已值得供养的大长老们，都反过来供养/敬重世尊"——这是抬高世尊地位的修辞重点，现译的部分格读法恰恰抹去了这一点。
- **建议**：三处一并改为施动结构，如：
  - 「受到应受供养者的供养，受到应受敬重者的敬重；」
  - 「受到应受礼敬者的礼敬，我愿意为他送去这些。」
