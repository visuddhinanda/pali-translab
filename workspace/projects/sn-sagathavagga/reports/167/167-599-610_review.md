# Review — 167:599-610（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅（全段）／ nissaya 部分（§601、§603、§605、§610 有；§599、§600、§602、§604、§606、§607、§608、§609 缺，不拿相邻段落凑）／ 义注 部分（借自 book 133 对应偈颂的注释，覆盖 maccharino / kadariyā / paribhāsakā / antarāyakarā / samparāya / ratī / khiḍḍā / diṭṭhe dhammesa vipāko 等词的释义；book 133 与本段落无逐段坐标对应，仅作释义参考，不作被解释词逐字核对）

## 跨段一致性

- **samparāyo / samparāye**（"来世"）：§602 译「未来的去处」，§610 译「来世」→ 用词不统一。依据：义注 book133-428「**Samparāyo**ti paraloko」（即"他世／来世"）；§603 nissaya 释同词为「တမလွန်လောကအကျိုး」（来世之果）。建议统一改为「来世」。
- **maccharino / kadariyā**：§600、§604 均译作并列近义词「悭吝、吝啬」，未体现两词的等级差异。义注 book133-427 明言：maccharino 是"软性悭吝"（mudumacchariyaṃ，外表仍像在给予，实则未给）；kadariyā 是"硬性悭吝"（thaddhamacchariyaṃ，如石柱、树桩般生硬拒绝，且出言辱骂）。现译文把二者译成同义堆叠，抹去了这一分级，且在 §600/§604 两处重复，应一并统一改法。

## §600 句 167-600-2-11（问题重复见于 §604 句 167-604-2-10）

- **问题**：释义误取——"kadariyā" 与 "maccharino" 被译成同义并列的「悭吝、吝啬」，未体现义注区分的软硬两级悭吝（见上「跨段一致性」）。
- **建议**：拉开译法层级，如「悭吝」（maccharino）／「顽固吝啬」（kadariyā），并在 `knowledge/terms.md` 中登记这对术语。

- **问题**：添加原文没有的对象——"paribhāsakā" 被译为「斥骂**施主**的人」，把"施主"（布施者）当成了挨骂的对象，与义注不符。**义注**（book133-427）：「**paribhāsakā**ti bhikkhū gharadvāre ṭhite disvā, ‘kiṃ tumhe kasitvā āgatā…’tiādīhi saṃtajjakā」——挨骂的是上门乞食、站在门口的比丘，不是"施主"；nissaya（§601）「ပရိဘာသကာ= ဆဲရေးရေရွတ်တတ်ကုန်၏」也未指定对象为施主。
- **建议**：改为不预设错误对象的译法，如「又好斥骂上门乞食者的人」，或省去具体对象「又好谩骂的人」。

## §602 句 167-602-2-12

- **问题**：跨段用词不一致（见上）——"samparāyo" 译作「未来的去处」，与 §610 的「来世」不统一。
- **建议**：改为「来世的（果报/去处）」或直接「来世」，与 §610 保持一致。

## §604 句 167-604-2-10

- 与 §600 相同问题（重复出现，见上）。

## §606 句 167-606-2-9

- **问题（可选，非必改）**：nissaya 将 "yamalokaṃ" 具体注为「ယမမင်း၏ ပြိတ္တာဘုံ」（琰摩王的饿鬼／鬼道），现译「阎罗的世界」较笼统，但属常见惯用译法，不算错。
- **建议**：可考虑改为「阎罗的境界（鬼道）」以更贴合 nissaya 的具体所指，非必改项。

## §609 句 167-609-2-23

- **问题（较轻）**："āsīsare" 的 nissaya 释「တောင့်တကုန်၏」（渴望、盼望），现译「仰望别人来乞求」把"乞求"这一主动行为加得偏重，原意更偏向"指望/盼望从别人那里得到"。
- **建议**：可改为「愚痴的人只能盼望从别人那里得到，可即使这样，他们也得不到那些东西」，减弱"乞求"的主动意味。
