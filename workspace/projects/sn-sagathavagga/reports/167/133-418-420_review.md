# Review — 133:418-420（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅／本层义注 ✅／**父层译文缺口**——仅取得经题坐标（167-580-2-4，“种林经”），未取得含被解释词（dhammaṭṭhā、sīlasampannā、ārāmaropā、vanaropā、setukārakā、papaṃ、udapānaṃ、upassayaṃ、sadā、puññaṃ、pavaḍḍhati 等）的偈颂坐标译文。本次**无法核对黑体被解释词与父层译文是否逐字相同**，只核对了本层（418–420）内部各段之间被解释词译法是否一致。

## 跨段一致性
- dhammaṭṭhā：§419（“哪些人是住于法者”）与 §420（“住于法者、具戒者”）均译“住于法者” → 一致
- sīlasampannā：§419、§420 均译“具戒者” → 一致
- ārāmaropā：§419-17-24、§419-25-29 均译“种植园林者” → 一致
- vanaropā：仅一见（§419-30-44 译“种林者”），与经题“种林经”词根呼应，无跨段问题
- setukārakā / papaṃ / udapānaṃ / upassayaṃ：各仅一见，无跨段比对对象
- 与父层（167:580 偈颂）黑体词的一致性**无法核对**，见上方资源缺口说明

## §419 句 133-419-17-24
- **问题1**：风格——“世尊为了阐明这个问题，以常存不朽之物**加以说明**”中，“阐明”与“加以说明”重复表达同一个 dīpento（说明/阐明），读来累赘
- **建议1**：改为“世尊以常存不朽之物阐明这个问题”，只保留一个说明动词
- **问题2**：文言虚词——“不朽**之**物”的“之”属 `style.md` 明确列入禁例的文言虚词
- **建议2**：改为“不朽**的**事物”
- **附注**：该处 nissaya（thāvaravatthunā 的两条子释义）文本有重复的次级标题结构（“ထာဝရဝတ္ထုနာ (ဆဋ္ဌ)”出现两次、分属两套释义），疑似 OCR/排版讹误，不影响本条判断，仅供留意，不需改译文

## §419 句 133-419-60-64
- **问题**：文言虚词——“任何蓄水**之**处”的“之”属禁例文言虚词
- **建议**：改为“任何蓄水**的**地方”

## §420 句 133-420-15-24
- **问题**：文言虚词——“那时功德**便**随之增长”中的“便”是 `style.md` 明确列入禁例的文言词（便=于是）
- **建议**：改为“那时功德**就**随之增长”

## §420 句 133-420-25-36
- **问题**：疑似工作标记——“针对这一意趣，**(故)**说……”。原文“Imamatthaṃ sandhāya … vuttaṃ”本身没有表因果的词，译文加的“故”本不必要；用括号单独标出的写法更像译者留下的未决备选，`style.md` 明确要求译文不留任何工作标记
- **建议**：删去括注，直译为“针对这一意趣，说“功德常增长”。”；如确需因果连接，直接用“由此”而非带括号的“(故)”

## §420 句 133-420-49-63
- **存疑**：“十种善法”对应 nissaya 的 kusalā dhammā（善法），但紧接下句单独另提 sīla，语境上更像专指“十种福业事”（dasa puññakiriyavatthu）而非笼统的“善法”；`knowledge/terms.md` 未登记该术语，无法定案，建议后续核实后补入术语表
- **附注**：该处 nissaya 原文中“တေသု”一条写作“那十种**不善**法（အကုသိုလ်）”，与 Pali“dasa kusalā dhammā”（十种**善**法）相反，疑似 nissaya 转录/OCR 讹误（误加“အ”否定前缀）；译文正确依循了 Pali 原文而非此处有误的 nissaya，不算翻译错误，仅记录供留意
