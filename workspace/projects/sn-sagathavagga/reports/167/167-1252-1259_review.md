# Review — 167:1252-1259（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya 部分覆盖（重复列举句多处缺失，语义已由本 chunk 内同词的其他 nissaya 条目覆盖，未见需要单独降级说明的空白段）／义注 ✅（book 133，巴利原文，本作业不译，仅作释义标准）
> 说明：本层为本文（mūla）根层，其上无更高"父层"可供逐字核对被解释词；义注（book 133）的黑体是从本文引出的被解释词，故改为核对——本层译文对义注黑体术语的解释是否准确、以及在本 chunk 内是否自洽统一。以下发现的问题按此展开。

## 跨段一致性

十六项德目（paṇḍito / mahāpañño / puthupañño / hāsapañño / javanapañño / tikkhapañño / nibbedhikapañño / appiccho / santuṭṭho / pavivitto / asaṃsaṭṭho / āraddhavīriyo / vattā / vacanakkhamo / codako / pāpagarahī）在 §1254、§1255、§1257（列举句）、§1258（列举句）四处的译法逐词一致，顺序也与原文一致——**跨段一致性本身没有问题**。但其中 hāsapañño 的译法本身有误（见下），因为四处一致地错，不会被"跨段比对"发现，须单独列为准确性问题。

## §1254 句 167-1254-42-55（及其同词的 167-1255-45-50 / 167-1257-35-97 内 / 167-1258-23-71 内）
- **问题**：义注释义核对（必改）——`hāsapañño` 译作"敏悟智慧的"，与义注释义不符。
  **义注**（133-581）：`hāsabahulo vedabahulo tuṭṭhibahulo pāmojjabahulo sīlaṃ paripūreti…`，释 hāsapaññā 为"喜悦、满足、欣悦极多而圆满戒等"之慧，重点在"喜/悦"（hāsa = 欢喜、笑悦），不是"敏悟"（敏锐领悟）。
  nissaya 同一段亦作：`ဟာသပညော= ရွှင်သောပညာလည်းရှိ၏` = "具有欣悦（ရွှင်=喜悦、愉悦）之慧"，同样指向"喜悦"而非"敏悟"。
  "敏悟"（反应快、领悟快）更接近 javana／tikkha 一类的语义，与 hāsa 无关，四处（1254/1255/1257 列举内/1258 列举内）统一用了这个误译，是系统性错误而非偶发。
- **建议**：改为"喜悦智慧的"或"欣悦智慧的"，并同步更新 `knowledge/terms.md`。

## §1254 句 167-1254-91-97（同类：167-1255-81-86 / 167-1257 列举内 / 167-1258 列举内）
- **问题**：义注释义核对——`pavivitto` 译作"乐于独处的"，只覆盖了义注三种远离中的"身远离"一面。
  **义注**（133-587）：`kāyaviveko ca … cittaviveko ca … upadhiviveko ca … imesaṃ tiṇṇaṃ vivekānaṃ lābhī`，明确 pavivitta 是身、心、依（烦恼所依）三种远离皆具足，不只是物理上的"独处"。
- **建议**：译法可保留"独处"作为核心意象，但宜在术语表注明此处实指身心俱寂之远离，或改译为更涵盖三重远离的说法（如"寂静远离的"），供后续统稿参考。

## §1254 句 167-1254-133-139（同类：167-1255-118-123 / 167-1257 列举内 / 167-1258 列举内）
- **问题**：义注释义核对——`pāpagarahī` 译作"厌恶恶行的"，遗漏了义注中"呵斥恶人"（pāpapuggala）一面，只剩"呵斥恶法"（pāpadhamma）一面。
  **义注**（133-594、133-597）：先释 `pāpagarahī` 为不见恶人、不闻恶人之言、不与恶人同处一世界（**pāpapuggale** 一面），再释以呵斥自身贪嗔痴等恶法为第二面（**pāpadhamme** 一面），"dvīhi kāraṇehi ‘pāpagarahī’ti vadati"——两个理由并举，是"恶人＋恶法"合成的呵责，不是单纯的"厌恶"。
- **建议**：改为"厌恶恶人恶法的"或"呵责恶人恶法的"，以覆盖义注给出的两面。

## §1258 句 167-1258-2-17
- **问题**：漏译"pi"（也）。原文 `Ahampi hi, bhante, …` 的 `pi` 表示"我也（和其他天众一样）"，nissaya 明确标出：`အဟမ္ပိ= သည်လည်း`（"……也"）。现译"大德，凡是我所去到的天子众会，我都听到这样多的言论——"未体现"也"，弱化了苏尸摩呼应前文"其他天众都在称扬"这一层意思。
- **建议**：改为"大德，我也一样：凡是我所去到的天子众会，都听到这样多的言论——"。

## §1257 句 167-1257-2-12
- 无实质问题，仅记录：`sugata`（善逝）与 `bhagavā`（世尊）分列两个称呼句"正是如此，世尊！正是如此，善逝！"译法准确，且与 §1255-2-12 的对应句式（对 ānanda 的回应）结构呼应一致。
