# Review — 167:1561-1568（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya 大部分行齐全，部分重复段（167-1565-42-70、167-1567-58-70/71-91、167-1568-42-50）未附 nissaya，视为源数据省略重复内容，不影响判断／义注 ✅（book 133:740-744，覆盖本 chunk 涉及的「卑贱家族」「身体缺陷」等被解释词）

## 跨段一致性

- **rathakāra 系列必改项（见下）**：167-1563-11-54 与 167-1565-12-41 均译「车匠家」，两处**一致但一致地错**——义注与 nissaya 都明确改释为皮匠/制革匠，需同步改。
- **kuṇī 系列必改项（见下）**：167-1563-55-86 与 167-1565-42-70 均译「手足畸形」，同样一致但一致地错，需同步改。
- **tamo/tama 译法不统一**：技术术语「从暗入暗者」等（167-1562-49-58 及各段小标题）里 *tamo* 译作「暗」；但 167-1564-2-24 譬喻句里同一词根 *tamā vā tamaṃ* 译作「幽暗」，与术语用字不一致，容易让读者看不出这是同一概念的呼应。建议统一为「暗」，或明确保留「幽暗」但确认这不会削弱「从暗入暗者」这一术语与譬喻之间的呼应。
- 「刹帝利大富家 / 婆罗门大富家 / 居士大富家」「金银 / 财物用具 / 财谷」等排比结构在 167-1567-12-38 内部用词稳定，各段方位譬喻（地面→床座→马背→象背→楼阁 / 逆序）在 167-1566、167-1568 间用词也保持一致，无问题。

## §1563 句 167-1563-11-54（及 167-1565-12-41 同一问题）

- **问题**：义注取词错误（必改）——`rathakārakule` 译作「车匠家」，是按字面「造车者」直译。
  **义注**：Rathakārakuleti cammakārakule（义注明确改释为「制革匠家」）。
  nissaya：ရထကာရကုလေ= သားရေနယ်သမားအမျိုး（皮革/制革匠家），与义注一致，两重标准都不支持字面「车匠」。
- **建议**：改译为「皮匠家」或「制革匠家」，167-1563 与 167-1565 两处同步改。

## §1563 句 167-1563-55-86（及 167-1565-42-70 同一问题）

- **问题**：义注取词错误（必改）——`kuṇī` 译作「手足畸形」，把「手」的畸形误扩大成「手足」，与后面 `khañjo`（腿部跛脚）语义重叠。
  **义注**：Kuṇīti ekahatthakuṇī vā ubhayahatthakuṇī vā（仅指一手或双手畸形，不涉足部）。
  nissaya：ကုဏီ= လက်ကောက်（手部弯曲/畸形），同样只指手部。
- **建议**：改为「手部畸形」或「手残」，与下一项 `khañjo`＝「跛脚」（腿部）区分开，167-1563 与 167-1565 两处同步改。

## §1567 句 167-1567-12-38

- **问题**：术语选用可商——`gahapatimahāsālakule` 译作「居士大富家」。此处 `gahapati` 是与刹帝利、婆罗门并列的种姓/阶层用词（富有的居家大户），并非佛教术语「居士」（近事男/在家信众）的技术义，二者容易混淆。
- **建议**：改译为「长者大富家」或「居家大富家」，避免与「居士」这一专有佛教身份词冲突。

## 存疑/次要项（不构成必改，供确认）

- 167-1563-11-54 / 167-1565-12-41：`pukkusakule` 译作「除粪工家」。义注/nissaya 均释为「弃花/弃物者之家」（pupphachaḍḍakakule／ပန်းမှိုက်သွန်），并非字面「除粪」。「除粪工」是南传常见传统译法，可以保留，但请确认是否要改得更贴合义注字面（如「除花工家」「清扫工家」）。
- 同处 `venakule` 译作「竹匠家」，义注为 vilīvakārakule（劈竹篾者），nissaya 为「席匠/编织匠」，「竹匠」大致贴切，仅供留意是否需更精确为「竹篾匠家」。
