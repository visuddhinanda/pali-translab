# Review — 167:2221-2227（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句子的 nissaya 归并标注在同一 nissaya 语块的末句 id 上，属数据切分方式，非缺失）／义注 ✅（book 133:957，为本 sutta 同段"brahmapārisajja / aññepi / tevijjā / iddhipattā / cetopariyāyakovidā / bahū"诸词的定义，已比对，均与译文一致，未发现取义偏差）

## 跨段一致性

- **kassapo 未随身份加尊称**：nissaya（167-2221-73-83）将 `kassapo` 明确注为 `မဟာကဿပ`（大迦叶／摩诃迦叶），但两处出现（§2221:73-83 与 §2221:123-132）均只译作"迦叶"，未加"大"字。与此形成对照的是，同一并列名单里的 `moggallāno` 在全篇其余各处（如 §2221:133-141 起首的"大目犍连尊者"）都稳定译作"大目犍连"。同一名单内厚此薄彼，读者容易把"迦叶"误认成优楼频螺迦叶等其他同名比丘。
- **平行句式标点不统一**：§2221:57-72（梵天转述指示天神该说的话）结尾用破折号"——"引出后续列举（"…大威力的弟子——"），而 §2221:107-122（天神照原话对目犍连复述）是同一句式的第二次出现，却改用分号"；"（"…大威力的弟子；"）。两处内容几乎逐字重复，标点应统一。

## §2221 句 167-2221-73-83
- **问题**：术语一致性 —"kassapo"译作"迦叶"，未依 nissaya 明确标注的"大迦叶"身份加尊称前缀，与同名单中"大目犍连"的处理方式不一致。
- **建议**：改译为"大迦叶"（或"摩诃迦叶"），与"大目犍连"对齐。

## §2221 句 167-2221-123-132
- **问题**：同上——"kassapo"复述处仍未加"大"字前缀。
- **建议**：同上，统一改为"大迦叶"。
