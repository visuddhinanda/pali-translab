# Review — 167:1497-1507（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分段落）／义注 ✅（book 133:714-716，与本段一一对应）

## 跨段一致性
- `samadhiggayha ... tiṭṭhati`（167-1498/1499/1500/1501×2）：五处均只译出「把握」，系统性漏译 `tiṭṭhati`（nissaya: တိဋ္ဌတိ= တည်၏，"安住/持续保有"）。虽然五处译法彼此一致，但都同样漏掉了义注确认的第二个动作，建议统一改为「把握……并安住其中」或「持续把握……」一类，把 `tiṭṭhati` 的语义找补回来。
- `appamādo` → 不放逸、`paṇḍita` → 智者、`dhīra` → 贤者、`diṭṭhadhammika/samparāyika attha` → 现世的利益／来世的利益：以上术语在全 chunk 内译法统一，无漂移。

## §1501 句 167-1501-22-53
- **问题**：文言虚词 —「因其巨大而被称为其中最殊胜的」中的「其」属 `style.md` 明确禁例的文言虚词。
- **建议**：改为「象的足迹因为巨大，被称为其中最殊胜的」或「象的足迹体积巨大，因此被称为其中最殊胜的」。

## §1507 句 167-1507-2-10
- **问题**：义注冲突 ——「Atthābhisamayā」译作「通达了利益」，取的是 `abhisamaya` 常见教理义（洞察/证悟），但**义注**（133-716）明文重新界定：“Atthābhisamayāti atthapaṭilābhā.”（= 利益的获得/证得），把它限定为「获得」而非「通晓/领会」。译文取了教理泛义而非本段义注给出的专门释义，属必改项。
- **建议**：改为「由于获得了（两种）利益，贤者才被称为智者」或「因证得（两种）利益，贤者被称为智者」，与 §1505「能把握这两种利益」的「获得/把握」义呼应，而非「理解、通达」。

## §1502-1503 句 167-1502-2-10 / 167-1503-2-7
- **问题**：句法结构错位。原文 `patthayantena`（"企求……的人"，与格/工具格，统摄前面所列的寿命、健康、美貌、天界、尊贵出身、喜乐等全部所欲之物，并引出后面"智者赞叹不放逸"这一结果句）被译成了与前面抽象名词并列的一个条目——"寿命、无病、美貌，天界与尊贵的出身，以及企求不断增长的殊胜喜乐的人"，读起来像是把"一个人"和"寿命、美貌"等并列枚举，逻辑类别不一致，容易让读者误读整句结构。
- **建议**：把 1502-1505 作为一个跨行的因果／目的句处理，例如：「对于渴望长寿、无病、美貌、天界与尊贵出身，以及种种不断增长的殊胜喜乐的人来说，智者们在诸善业中都赞叹不放逸；不放逸的智者，能把握这两种利益。」（可分行排版，但需在语义上体现"渴望……的人"统领并引出"智者赞叹不放逸"这一结果，而不是把"人"塞进枚举列表）。
```

阿, 补充一点：以上问题里 §1507 与 §1502-1503 是内容/结构性必改项，§1501-22-53 是纯文言虚词必改项；`tiṭṭhati` 漏译是全篇一致的系统性缺项，建议一并处理，不必逐句单独列。
