# Review — 133:754-756（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（随行内嵌）／父层（167 本文，段 1612-1630）定稿译文对照 ✅。本层本身即义注层，无更高层级义注可供对照。

## 跨段一致性

无。`senāsana` 在 133-755-2-12（译作“住处”）与 133-755-13-17（译作“卧具”）两处译法不同，但对应的是同一巴利词在不同语境下的两个不同义项——前者指僧坊/住所，后者由义注明确释为床椅等家具——义注自身也是这样区分的，不属于漂移，无需统一。

## §755 句 133-755-2-12
- **问题**：黑体被解释词与父层译文不一致。本句黑体引自偈颂 “Annaṃ pānaṃ khādanīyaṃ…”（书167:1622），**父层译文已将 annaṃ + pānaṃ 合译为固定复合词“饮食”**，未逐词拆分。本句却将其拆成两个独立黑体词“**食**”“**饮**”，无法与父层的“饮食”逐字对应。
- **建议**：改用父层已定稿的“饮食”引出下文，如「便说出以“饮食”等语开头的话」，不要拆成两个单字。

- **问题**：文言虚词残留。“便说出”中的“便”属 `style.md` 明列的禁用文言虚词（表“于是/就”之意）。
- **建议**：改为“就说出”或“于是说出”。

其余各句黑体被解释词逐一核对均与父层译文（167:1618/1620/1621/1622/1623/1624/1626/1628/1629/1630）逐字相同（忍耐与阿罗汉性 / 住处 / 荒野 / 险阻之处 / 桥梁通道 / 卧具 / 清净 / 雷鸣 / 百峰 / 备好 / 心生欢喜 / 分施 / 福流 / 施主 / 充盈滋润），nissaya 词级核对（格助词、隐含成分）与准确性、风格均未见其他问题。
