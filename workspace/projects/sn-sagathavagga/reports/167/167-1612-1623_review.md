# Review — 167:1612-1623（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya 部分缺（§1612、§1618、§1620、§1622 未附 nissaya，其余段落有）／义注 ✅（book 133 aṭṭhakathā，覆盖到 §1623；其后 133-755-30 起的黑体词对应 §1624 之后尚未纳入本次审查范围的段落，不适用于本 chunk）

## 跨段一致性

- **asikkhito / akatahattho / akatayoggo / akatūpāsano**（及其正面对应 susikkhito / katahattho / katayoggo / katūpāsano）：§1613（167-1613-130-142）与 §1614（167-1614-17-29、167-1614-62-87）译法前后一致（"没有受过训练／没有练过身手／没有练过阵法／没有实战经验" 及其正面版本），**一致但一致地取义有误**——两处都丢失了义注 133-751-113~132 明确限定的"专指弓箭术训练"之义（详见下方逐句问题）。这是"箭术经"通篇的核心比喻，两处需同步改正。
- **bhare**：§1613/1614 对话体中统一译"雇用"（"你会雇用这样的人吗"等），但 §1617（167-1617-2-9）偈颂后半句 "nāsūraṃ jātipaccayā" 改译为"认定"（判断勇敢），与前半句延续的"雇用"动词断了呼应，是同一动词在同一偈内的不一致。

## §1613 句 167-1613-31-43
- **问题**：义注释义核对（取义）— 原文 "Yattha kho, mahārāja, cittaṃ pasīdatī" 中的 "yattha" 是**被解释词**，**义注**（133-750-116-130）明确释为 "yasmiṃ **puggale** cittaṃ pasīdati, tasmiṃ dātabbaṃ"——指"哪个**人**心生欢喜"，而非哪个"地方"。译文"凡是心生欢喜清净的**地方**"把对象由人改成了处所，取义与义注相悖。
- **建议**：改为"大王，凡是能让心生起欢喜清净的**人**"（或"无论对方是谁，只要能使心生欢喜清净"），避免"地方"。

## §1613 句 167-1613-104-129 / §1614 句 167-1614-2-16
- **问题**：义注释义核对 — "samupabyūḷho" 是被解释词，**义注**（133-751-109-112）释为 "rāsibhūto"（聚集成堆，即两军已列阵集结），并未含"交锋"之义。译文"两军就要交锋"把"已集结列阵（尚未接战）"译成了"即将交锋（已进入接战）"，越过了义注给定的语义边界。
- **建议**：改为"两军已经列阵集结"或"两军已经集结待战"，不用"交锋"。（两处需同步改。）

## §1613 句 167-1613-130-142 / §1614 句 167-1614-17-29、167-1614-62-87
- **问题**：义注释义核对（取义，首要）— 这四个被解释词都是**专指弓箭术**的训练状态，义注与 nissaya 双重印证：
  - **asikkhito**：**义注**"dhanusippe asikkhito"＝**未曾学习弓箭之术**；nissaya「သင်အပ်သော လေးအတတ်မရှိသော」同义。译文"没有受过训练"是泛化的通用训练，丢失"弓箭"限定。
  - **akatayoggo**：**义注**"tiṇapuñjamattikāpuñjādīsu akataparicayo"＝**未曾在草堆、泥堆等靶子上练习过（射箭靶术）**。译文"没有练过阵法"（阵法＝战术队形）与原意完全不同，是明显误译。
  - **akatūpāsano**：**义注**"rājarājamahāmattānaṃ adassitasarakkhepo"＝**未曾在王与大臣面前展示过射箭**（即缺乏正式的箭术历练/声誉）。译文"没有实战经验"方向大致接近但把"箭术展示"泛化为一般"实战"，精确度不足。
  - **akatahattho**：义注"muṭṭhibandhādivasena asampāditahattho"＝**握弓的手法（如握拳法）未曾练成**。译文"没有练过身手"过于笼统，弓箭手法的专指性丢失。
- **建议**：整组改为强调箭术专指的译法，例如：
  - asikkhito → 未曾学习射箭之术
  - akatahattho → 未曾练成持弓的手法
  - akatayoggo → 未曾练过靶术（未在草垛、泥堆等靶子上操练过）
  - akatūpāsano → 未曾在王侯大臣面前展示过箭术
  正面版本（susikkhito 等，§1614）同步对调改正。

## §1617 句 167-1617-2-9
- **问题**：义注释义核对 — **义注**（133-753-20-36）明确 "nāsūraṃ jātipaccayā" 释为 "'ayaṃ jātisampanno' ti evaṃ jātikāraṇā **asūraṃ na bhareyya**"，即"不应仅因出身高贵这一理由而**雇用**怯懦之人"，动作核心仍是"雇用"（承接前半句 bhare）。译文"而不是仅凭出身就认定谁勇敢"把"雇用"改写成"判断/认定勇敢"，偏离了义注给定的动作对象，也与跨段"bhare=雇用"的既定译法不一致。
- **建议**：改为"国王不应仅因出身高贵就雇用怯懦之人"一类，保留"雇用"这一动作。

## §1618 句 167-1618-2-10
- **问题一（义注释义核对，取义，重要）**：偈颂被解释词 "soraccaṃ" 在**义注**（133-754-2-12）中明确释为 "**arahattaṃ**"（阿罗汉果/阿罗汉性），是本段的专门术语用法，不是日常义的"温和/柔和"。译文"柔和"取了字面常义，与义注给定的专门释义相悖，是取义错误，非风格问题。
- **建议一**：按义注改为体现"阿罗汉（果/性）"的译法，例如"忍耐与阿罗汉之德"或加注"soraccaṃ（此处义注释为阿罗汉性）"，不用"柔和"。
- **问题二**：**义注**（133-754-13-18）"dhammā" 明确释为 "ete **dve** dhammā"（**这两种**法，即上文的 khanti 与 soracca），是封闭的二法，不是开放列举。译文"忍耐与柔和**等**美德"中的"等"字暗示还有其他美德，与义注"仅此二法"的限定不符。
- **建议二**：去掉"等"字，明确是"这两种法"，如"凡是安住于忍耐与阿罗汉性这两种法的人"。
