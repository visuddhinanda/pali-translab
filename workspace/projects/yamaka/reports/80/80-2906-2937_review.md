# Review — 80:2906-2937（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（本次未注入，词级核对缺失）／义注 ⚠️（注入的是《根双论》整章的义注，98:1853-1864，只给通则，没有逐段对应；以下凡引义注，都是按通则推到本段）
> 本层是本文（mūla），没有父层，所以不做被解释词逐字比对。但义注会以黑体原样引用本文的 **sacakkhukānaṃ / ñāṇavippayuttānaṃ / vinā somanassena / upekkhāya / ahetukānaṃ / sahetukānaṃ** 等词，所以这些词在本文的译法定下之后，义注层必须逐字照抄。因此本文这里的统一要在 harmonize 之前完成。

## 跨段一致性

- **upapajjantānaṃ**：在“A 而 B 的众生”这个句型里译成“……的众生在投生时”（§2906、2908、2911、2913、2915、2917、2919、2922、2924、2926、2928、2930、2932、2934、2936 的第一句）；在“所有正在死没的众生，以及……”这个句型里又译成“……而正在投生的众生”（各段第二句）。同一个分词、同一个格，却用了两种句法。→ 建议统一为“……、正在投生的众生”。例：§2906 改为“与智不相应、有眼、正在投生的众生，他们的慧根不生起，但他们的眼根并非不生起。”
- **yassa / tassa（问句）**：问句译成“……不生起的**人**，**他**的……”，答句却一律用“众生 / 他们”。巴利 yassa 是泛指，包括梵天、无想有情和畜生（例如 §2908 答句里的“无心而正在投生的众生”），译成“人”就把范围缩窄了。在女根问句（§2910 等）里用“他的女根”也不合适。→ 建议问句统一为“对于眼根不生起的众生，意根也不生起吗？”。涉及的句子：§2907、2909、2910、2912、2914、2916、2918、2920、2921、2923、2925、2927、2929、2931、2933、2935、2937。
- **somanassena / vinā somanassena，upekkhāya / vinā upekkhāya**：正面译成“以喜（投生）”“以舍（投生）”，反面却译成“不带喜”“不带舍”，正反两面没有对应起来。**义注**：vinā somanassena 指“与舍俱行的四种大异熟结生”，vinā upekkhāya 指“与喜俱行的结生”。也就是说，这两个词讲的是结生心是否与喜（或舍）俱起。→ 建议成对统一为“以喜投生 / 不以喜投生”“以舍投生 / 不以舍投生”。涉及：§2922、2924、2926、2928。
- **itthī / purisa**：译成“女人 / 男人”。**义注**说明 na itthīnaṃ 包括色界梵天以及男性、无性者，na purisānaṃ 包括色界梵天以及女性、无性者。“非女人”“非男人”在现代汉语里容易读成只说人类。→ 建议统一为“女性 / 非女性”“男性 / 非男性”。涉及：§2911、2913、2915、2917。

## §2922 句 80-2922-2-16
- **问题**：冗余。“无鼻而以喜投生的众生在投生时”里“投生”出现了两次。
- **建议**：改为“无鼻、以喜投生的众生，他们的鼻根不生起，但他们的喜根并非不生起。”

## §2926 句 80-2926-2-16
- **问题**：同上。“无鼻而以舍投生的众生在投生时”里“投生”重复。
- **建议**：改为“无鼻、以舍投生的众生，他们的鼻根不生起，但他们的舍根并非不生起。”

## §2911 句 80-2911-2-16、§2915 句 80-2915-2-16
- **问题**：用词偏窄，见上方跨段一致性中的 itthī / purisa 一条。
- **建议**：“无鼻、正在投生的女性，她们的鼻根不生起，但她们的女根并非不生起。”男性一句照此改。

## §2909 句 80-2909-16-20
- **问题**：括号里的“（以眼根为根本）”是这一部分（以眼根为根本的方法，cakkhundriyamūlaka naya）的结束标记，单看像是对“是的”的补充说明。
- **建议**：改为“（以眼根为根本的部分）”或“（眼根根本门完）”，让读者看出这是分段标记。全书的同类标记要统一。

## 全 chunk：cavantānaṃ“死没”
- **问题**：“死没”是旧译里的文言双音词，没有古文基础的读者可能看不懂。这一条不是必改项，请定一个译法后登记进 `terms.md`。
- **建议**：可以考虑改成“正在死去的”。如果按阿毗达摩旧译惯例保留“死没”，就在 `terms.md` 里登记 cavati / cuti 的定译。
