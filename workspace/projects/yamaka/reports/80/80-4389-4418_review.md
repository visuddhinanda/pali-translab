# Review — 80:4389-4418（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入，词级核对从缺）／义注 ✅（book 98 Indriyayamakavaṇṇanā；对本 chunk 只有 §1858「281. Anāgatavāre」一条直接相关的释义，其余是通则）
> 注：注入的义注条目 `layer` 字段标成了 `mula`，实际是义注（aṭṭhakathā），取数环节需要核查。

## 跨段一致性

- **pacchimabhavika**：§4389 / 4393 / 4397 / 4401 / 4405 / 4409 译“最后有者”，§4413 / 4417 译“最后有的女人”。后一种会被读成“最后有了女人”，有歧义。→ 建议统一为“处于最后一生的人／女人”。如果保留“最后有者”这个术语，女性的情形就写作“身为最后有者的女人”。
- **cavantānaṃ**：§4391 / 4395 / 4399 / 4403 / 4407 / 4411 / 4415 一律译“正在死殁的人”。译法前后一致，但“殁”是文言单音节词。→ 建议统一改为“正在死去的人”。
- **eteneva bhāvena … katici bhave dassetvā parinibbāyissanti**：§4389、§4393、§4413 三处句式一致，但都带“之身”（见下文）。这两个短语是义注 §1858 的**被解释词**，义注译文必须逐字照搬本文的译法。改定后，要同步核对 Yamaka 本文 281 段（anāgatavāra）的同一短语，保证两处译法相同，否则义注的被解释词对不上任何一处本文。
- **Pacchimabhavikānaṃ … upapajjantānaṃ, ye ca …, ye ca …, tesaṃ upapajjantānaṃ** 列举句式：§4389 / 4393 / 4401 / 4405 / 4413 都译成“X 正在投生时，以及那些……的人，以及……的男人，在他们正在投生时”。这句把时间从句和名词并列在一起，语法上不通，见 §4389 句。五处要一并改。

## §4389 句 80-4389-2-31

- **问题**：风格（文言虚词）— “以这同一男性之身”里的“之”是文言虚词，属于必改项。义注说明了这个短语的意思：**义注**：etena purisabhāveneva, antarā itthibhāvaṃ anāpajjitvā purisapaṭisandhiggahaṇeneva（就是以这个男性身份，中间不转为女性，始终以男性身份受生）。现在的译文只译出了“同一”，“中间不转为女性”这层意思偏弱。
- **建议**：改为“一直保持这个男性身份、再经历若干次投生之后将般涅槃的男人”。
- **问题**：句法 — “最后有者正在投生欲界时，以及那些……的人”把时间从句和名词短语并列了。原文三组都是 `tesaṃ upapajjantānaṃ` 的同位属格，并列的是三类人。
- **建议**：改为“对于正在投生欲界的最后有者、那些投生色界或无色界之后将般涅槃的人，以及那些……的男人来说，在他们投生的时候，他们的鼻根生起，但女根不会生起。”

## §4393 句 80-4393-2-31

- **问题**：同 §4389 — “以这同一女性之身”带文言虚词“之”；列举句式不通。
- **建议**：改为“一直保持这个女性身份、再经历若干次投生之后将般涅槃的女人”，并按 §4389 的方式重组列举句。

## §4401 句 80-4401-2-22

- **问题**：句法 — 列举句式同 §4389。
- **建议**：改为“对于正在投生欲界的最后有者，以及那些将以舍受投生、之后般涅槃的有鼻者来说，在他们投生的时候……”。

## §4405 句 80-4405-2-22

- **问题**：句法 — 同 §4401。
- **建议**：照 §4401 改，把“舍受”换成“喜受”。

## §4413 句 80-4413-2-32

- **问题**：风格 — “以这同一女性之身”带文言虚词“之”；“最后有的女人”有歧义（见跨段一致性）；列举句式同 §4389。
- **建议**：改为“对于正在投生的、处于最后一生的女人，那些投生色界或无色界之后将般涅槃的女人，以及那些一直保持这个女性身份、再经历若干次投生之后将般涅槃的女人来说，在她们投生的时候，她们的女根生起，但男根不会生起。”

## §4417 句 80-4417-2-15

- **问题**：术语一致 — “最后有的女人”有歧义。
- **建议**：与 §4413 统一，改为“处于最后一生的女人”。

## §4411 句 80-4411-16-26

- **问题**：术语（存疑）— Ghānindriyamūlakaṃ 译作“以鼻根为首”。义注里反复出现 `cakkhundriyamūlake naye` 这类说法，`-mūlaka` 将成为被解释词的一部分。“为首”和“根本”取义不同。
- **建议**：先核对前面各章（眼根、耳根等）的 `-mūlaka` 标题怎么译，全书统一。如果前面没有定案，建议译作“鼻根为根本”，与义注的 mūlaka 对应得更直接。定案后登记进 `terms.md`。
