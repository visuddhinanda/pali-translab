# Review — 79:2656-2665（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ❌（未注入，本报告不含词级核对）／义注 ✅（双论注 Anusayayamakavaṇṇanā，book 98 §1764–1822；注入数据的 `layer` 字段误标为 `mula`，内容实为义注）

## 跨段一致性
- **kāmadhātuyā tīsu vedanāsu／dvīsu vedanāsu**：§2658、§2662 把 `kāmadhātuyā tīsu vedanāsu` 拆成“在欲界、在三种受中”。同一个 chunk 里，`kāmadhātuyā dvīsu vedanāsu`（§2658 句 63-85、105-126；§2662 句 63-85）又译成“在欲界的两种受中”。同一个结构译出两种句法，建议统一为“在欲界的三种受中”，依据见下文 §2658 句 79-2658-2-25。
- **paṭighānusaya** 全 chunk 统一译作“瞋恚随眠”，内部没有漂移，但译名本身有问题。义注 §1779 把 paṭigha 与 byāpāda 并列，并作了区分（`pāṇātipātacetanāya saddhiṃ uppannopi byāpādo …, evaṃ paṭighānusayo na hoti`）。“瞋恚”是 byāpāda 的通行译名，拿它译 paṭigha 会把两者混淆。建议全 chunk 改为“瞋随眠”，并补进 `terms.md`（需要与本书前文的译名一起统一，属于跨章决定，请人工定案）。

## 全 chunk 共性问题：yato／tato 译成了处所
涉及的句子：79-2656-2-22、79-2657-2-23、79-2658-2-25 / 26-41 / 42-62 / 63-85 / 86-104 / 105-126 / 127-144、79-2659-2-20、79-2660-2-23 / 24-39、79-2661-2-21、79-2662-2-25 / 26-41 / 42-62 / 63-85 / 86-104、79-2663-2-23、79-2664-2-24 / 25-41、79-2665-2-22

- **问题**：义注取义 — 原文 `yo yato … so tato` 用的是从格（ablative），译文一律译成“在某处……在该处”，变成了处所。义注专门点明了这一点：**义注**：`Okāsavāre ‘yattha tatthā’ti avatvā yato tatoti nissakkavacanena desanā katā`（处所分不说 yattha/tattha，而用 yato/tato 这种从格说法）。它还给出了释义：**义注**：`Yato kāmarāgānusayaṃ pajahatīti yato uppajjanakaṃ kāmarāgānusayaṃ pajahatīti attho`（§1801），以及 `yato uppannena kāmarāgānusayena sānusayo`（§1797）。也就是说，tato 指的是“从该处生起的”随眠，标的是随眠的生起处，不是这个人在哪里做遍知。译成“在该处不遍知”，读者会理解为遍知这件事发生的地点，正是义注要排除的那种读法。
- **建议**：把 yato／tato 改译成“从某处（生起的）”和“从该处（生起的）”。示例：
  - 问句：“如果某人不遍知从某处生起的欲贪随眠……，那么他也不遍知从该处生起的有贪随眠吗？”
  - 答句：“第八人在欲界的三种受中、在色界、在无色界，不遍知从该处生起的有贪随眠……”
  - 答句里的处所格（`kāmadhātuyā …`、`apariyāpanne`）保留“在……中”的译法。义注 §1797 说，在无限定的处所上只用处所格：`nippadesaṭṭhānesu bhummavacanameva kataṃ`。

## §2658 句 79-2658-2-25
- **问题**：句法 — 译文把 `kāmadhātuyā tīsu vedanāsu` 译成“在欲界、在三种受中”，拆成了两个并列处所。实际上 kāmadhātuyā 修饰 vedanāsu，是一个处所，不是两个。**义注**：`Kāmadhātuyā tīsu vedanāsūti ca vedanāggahaṇena … sabbesampi kāmāvacaradhammānaṃ gahaṇaṃ veditabbaṃ`（§1793），把“欲界的三种受”当作一个整体，概括全部欲界法。
- **建议**：改为“第八人在欲界的三种受中、在色界、在无色界……”

## §2662 句 79-2662-2-25
- **问题**：句法 — 与 79-2658-2-25 相同，“在欲界、在三种受中”拆错了。
- **建议**：改为“在欲界的三种受中”。

## §2660 句 79-2660-40-58
- **问题**：准确性 — “除了**这**两种具足道的人和第八人以外”。在 §2660 的答句里，前文只出现了具足最上道的人，没有出现具足不还道的人，所以“这两种”找不到所指。dvinnaṃ maggasamaṅgīnaṃ 泛指两种具足道的人（具足不还道的人与具足最上道的人），**义注**：`Dvinnaṃ maggasamaṅgīnanti dve maggasamaṅgino ṭhapetvāti attho`（§1801）。
- **建议**：去掉“这”，改为“除了两种具足道的人和第八人以外”。§2658 句 145-162、§2662 句 105-126 虽然前文提到过两种人，也建议同样去掉“这”，三处统一。

## §2664 句 79-2664-42-60
- **问题**：准确性 — 与 79-2660-40-58 相同，本答句前文只有具足最上道的人，“这两种”找不到所指。
- **建议**：改为“除了两种具足道的人和第八人以外”。

## §2658 句 79-2658-2-25（补充）
- **问题**：存疑 — “第八人”译法本身可以接受。按**义注**，它指须陀洹道者，是从阿罗汉果者往下倒数的第八位（`arahattaphalaṭṭhato paṭṭhāya paccorohanagaṇanāya gaṇiyamāno sotāpattimaggaṭṭho aṭṭhamako nāma`，§1801）。不过本 chunk 是它在本节的首次出现，一般读者看不出指的是谁。
- **建议**：请核对本书前文有没有说明过这个称谓。如果没有，在首次出现处加段后注：“第八人：须陀洹道者，从阿罗汉果者往下倒数第八。”译文正文不要改动。
