# Review — 128:3239-3260（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（3239、3240-10-12、3247-2-4、3249、3250-12-14、3259-2-4 无 nissaya，略过）
>
> ⚠ **父层对照段不匹配，被解释词无法核对**：本 chunk 注释的是 Theragāthā 133–134（罗陀，*Yathā agāraṃ ducchannaṃ…*）与 135–136（须罗陀，*Khīṇā hi mayhaṃ jāti…*），注入的父层却是 162:749–752（132 偈，美拉耆那）与 162:769–772（137 偈，乔达摩），没有一个黑体词能在其中找到对应。以下黑体词的「与父层逐字相同」检查**全部未做**：屋舍／盖得不好／渗透／未修习的／贪欲／善修习的／我的／生／确实／已尽／胜者的教法／已经修完／称为网的／已被断除／引向有的／已被根除／我为之／出家／从家／无家／那／目的／达到。需要换成正确的父层段（133–136 偈所在段）重跑这一项。

## 跨段一致性

- **agāra / geha**：§3247-5-10 中 agāra 译「屋舍」、geha 译「房屋」；§3259-64-77 中 agārasmā 译「家」、gehato 译「屋舍」，对应关系正好颠倒。「屋舍」已被 agāra 占用，gehato 不应再用。nissaya 在 §3259 把两词都释作 `အိမ်ရာထောင်သောလူ၏ဘောင်မှ`（从在家人的生活圈），这里指的是在家生活，不是建筑。建议 §3259 的 gehato 改为「在家生活」，例如「**从家**——也就是从在家生活——」。
- **paṭibhāneyyaka / paṭibhānajānanaka**：§3240-13-44、§3246-29-55 译「启发辩才者」，§3246-2-15 译「懂得启发辩才的人」。「懂得」是误读（见 §3246 句 2-15），改正后两处可以统一为「启发辩才」一系的说法。
- **khīṇā hi mayhaṃ 引文**：§3250-2-11 译「**我的****生****确实****已尽**」，§3258-2-18 译「**我的**（生）**确实****已尽**」。后者用括号补「生」，近似工作标记，体例也和前者不一致。建议改为「以“**我的**生**确实****已尽**”开头」（生不加黑，因为本句原文没有 jāti）。
- **samativijjhati / ativijjhati 的比喻**：§3247-21-32 作「就像雨水渗透那屋舍一样」，§3247-45-62 作「就像雨水无法穿透盖得好的房屋一样」。前句承接被解释词 samativijjhati，用「渗透」；后句对应 ativijjhituṃ，用「穿透」。两处各有依据，可保留；但「那屋舍」与「房屋」同指 agāra 的比喻，建议后者也作「屋舍」。

## §3240 句 128-3240-50-77
- **问题**：词法（轻）— tato cuto 的 nissaya 是 `ထိုဘဝမှ`（从那一生），译「从那里死去」，指代不清。
- **建议**：改为「从那一生死去」。

## §3240 句 128-3240-78-153
- **问题 1**：风格（必改）— 「他**便**到导师那里」中「便」是文言虚词。
- **建议**：改为「他就到导师那里」或「于是他到导师那里」。
- **问题 2**：句法 — `… pūretun ti paṭikkhitto` 中的 iti，nissaya 释为 `ဤသို့နှလုံးသွင်း၍`（这样考虑后），是比丘们心里的判断，不是说出口的话。译「他们说：……拒绝了他」不合。
- **建议**：改为「他们认为：‘这位婆罗门年纪老了，没有能力履行大大小小的义务。’就拒绝了他」。
- **问题 3**：词义 — apasādito，nissaya `ခြိန်းမောင်းအပ်သည်` 是「被呵斥、被斥责」，译「轻视」偏弱。
- **建议**：改为「被妻子儿女呵斥嫌弃」。
- **问题 4**：风格（轻）— 「具足」偏书面文言。
- **建议**：改为「具备」。

## §3242 句 128-3242-2-7
- **问题**：原文疑问 — pali 作 pādaphalaṃ，nissaya 读作 `အမ္ဗဖလံ`（ambaphalaṃ，芒果），与本文故事（§3240 供养芒果）相合。pādaphalaṃ 疑为讹文（记录，不改原文）。
- **建议**：译文「果子」不算错；如果按 nissaya 的读法，可以作「芒果」。

## §3245 句 128-3245-2-16／§3257 句 128-3257-2-16
- **问题**：词法 — kataṃ buddhassa sāsanaṃ，nissaya `အဆုံးအမတော်ကို … လိုက်နာပြုကျင့်ရပြီ` 是「佛陀的教导已被遵行」。译「佛陀的教法已经完成」容易误解为教法本身完结了。
- **建议**：两处统一改为「佛陀的教导已经奉行」。

## §3246 句 128-3246-2-15
- **问题**：误译（必改）— paṭibhānajānanakānaṃ 的 nissaya 是 `ပညာပဋိဘာန်ကိုဖြစ်စေတတ်သောပုဂ္ဂိုလ်တို့`（能使辩才生起的人），读作 janana（生起），不是 jānana（懂得）。「懂得启发辩才的人」译错了。原文 jānanaka 疑为 jananaka 的讹写，记录备查。
- **建议**：改为「在那些成为导师说法辩才之因缘、能引发辩才的人当中，他成了第一」。

## §3246 句 128-3246-16-25
- **问题 1**：词义 — diṭṭhisamudācāra，nissaya `မြင်တိုင်းပြောဆိုခြင်း` 是「照自己所见而说」，译「所表露的见解」偏离。另外 ca 没有译出。
- **建议**：改为「因为依着长老照自己所见说出的话，十力者心中就会涌现一次又一次新的说法」。
- **问题 2**：原文疑问 — nissaya 有 `ဝိနာ`（vinā）、`နပဋိဘာတိ`（na paṭibhāti），意思是「离了世尊，说法就不显现」，与本句 pali（navanavā dhammadesanā paṭibhāti）不合，疑为另一底本或 nissaya 误植。记录，译文仍依 pali。

## §3250 句 128-3250-15-36
- **问题**：用词／重复 — katādhikāro 的 nissaya 是 `ပြုခဲ့ဘူးသောကုသိုလ်အထူး`（曾作殊胜的善行）；「积累功德行」不通，而且紧接着又是「积累福德」，「积累」重复。
- **建议**：改为「他也曾在过去诸佛座下立下殊胜的善行，在一生又一生中积累福德」。

## §3253–3254 句 128-3253-2-10／128-3254-2-8
- **问题**：句法（轻）— 两行只有一个动词 adāsiṃ。dakkhiṇeyyassa vīrassa 是 satthuno 的同位与格（nissaya 无独立动词），译文却「供养」了两次。
- **建议**：3253 作「我拿着香橼果，供养导师——」，3254 作「那应受供养的英雄；我满怀净信，亲手供养。」或保留现状，但把「值得布施的」改作「应受供养的」，与 nissaya `မြတ်သောအလှူကိုခံတော်ထိုက်သော`（堪受殊胜供养）相合。

## §3259 句 128-3259-20-29
- **问题**：被解释词与释义用词脱节 — 黑体 vusitaṃ 译「已经修完」，释义 vuṭṭhaṃ parivuṭṭhaṃ 却译「已经住过、圆满地住完了」，读者看不出释义在解释哪个词。nissaya 把两词都释作 `သုံးအပ်ပြီ`（已实践）。
- **建议**：释义随黑体的动词，作「已经修过、圆满地修完了」（黑体本身待父层核对后再定）。

## §3259 句 128-3259-64-77
- **问题 1**：风格（必改）— 「我为之出家」中「之」是文言虚词（黑体，需同时与父层核对）。
- **建议**：改为「我为了它而出家」，或依父层译法。
- **问题 2**：句法 — yassa atthāya 是关系代词（nissaya `အကြင်…အကျိုးငှာ`，为了哪一个），与下句 so attho 呼应。译「为了那个目的」把关系结构改成了指示，下一句「那个目的」就失去了呼应。
- **建议**：改为「是说我为了什么目的，**从家**……**出家**……」。
- **问题 3**：gehato 译「屋舍」，见跨段一致性。

## §3259 句 128-3259-78-94
- **问题**：误译 — orambhāgiyuddhambhāgiyappabhedānaṃ 的 pabheda 是「分为……的」，nissaya `အားဖြင့်ပြားကုန်သော`（按……分类的），译「下分结、上分结等」多出一个「等」，意思变成还有别的种类。bandhanānaṃ 是 saṃyojanānaṃ 的同位释词（nissaya 两处同释），不是「束缚」作为总类。
- **建议**：改为「也就是分为下分结与上分结的一切结——也就是束缚——灭尽之处、称为涅槃的胜义目的……」。
- **附注**：nissaya 把 **So** 释作 `ထိုသုရာဓမထေရ်သည်`（那位须罗陀长老），但按语法应与 attho 连读（同为阳性主格，黑体 So … attho 相配），译文的处理正确，不改。
