# Review — 128:860-879（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（偈颂上半行 §862/864/866/868/870/872/874 的 nissaya 合并在下半行一条里，按整颂核对）

## 被解释词与父层对照

本 chunk 的黑体被解释词都与父层（162:147–148）译文逐字相同，**无必改项**：
- anuvassiko pabbajito →「出家才一年」（§861、§877）✅
- passa / dhammasudhammataṃ →「**看**啊，**这法的善妙**」（§878-57-72）✅
- tisso vijjā / anuppattā →「三明」「证得」（父层「我已证得三明」）✅
- kataṃ buddhassa sāsanaṃ →「已完成了佛陀的教导」（§878-73-101，§876 也一致）✅

## 跨段一致性
- **pasādeti / pasādayiṃ**：§861-36-59 译「使自己的心清净起来」，§867 译「对足迹生起了净信」。两处是同一件事，散文复述偈颂。→ 建议统一为「生起净信」。§861 可改为「……供养了足迹，对它生起了净信」。
- **dvānavute / dvenavute ito kappe**：§861-12-28 译「距今九十二劫以前」，§875 译「从现在往前九十二劫」。nissaya 两处都作 `ဤဘဒ္ဒကပ်ကမ္ဘာမှ ကိုးဆယ့်နှစ်ကမ္ဘာထက်၌`，意思相同。→ 建议统一为「距今九十二劫以前」。
- **vassa**：§878 内「雨安居」与「夏腊」混用。§878-16-26 把 ekavassika 译成「只有一个夏腊」，§878-40-56 把 avassika 译成「还没有夏腊的」。nissaya 两处都只作 `ဝါ`。用「夏腊」容易让读者以为注释前后矛盾。→ 建议 vassa 一律译「雨安居」，ekavassika 译「只有一个雨安居」。「夏腊」只留给 gaṇanūpagata（计入的雨安居数）这一层意思。

## §861 句 128-861-36-59
- **问题**：风格 — 「最上之人」中的「之」是文言虚词。
- **建议**：改为「最上的人」。
- **问题**（次要）：词法 — sadevake loke 的 nissaya 是 `ဗြဟ္မာမလပ်နတ်နှင့်တကွသော။ လောကေ= လောကသုံးပါး၌`，即包括天神（及梵天）在内的世间。译成「天界与人间」把它变成了两个并列的处所。
- **建议**：可改为「这是包括天神在内的世间中最上的人的足迹」。

## §861 句 128-861-60-90
- **问题**：nissaya 疑点（记录，不改译文）— `သတ္ထုစ= တိဿမြတ်စွာဘုရားအား` 把此处的 satthu 注成帝沙佛。但本句的时代是迦叶世尊，nissaya 应是笔误。
- **建议**：译文「导师」不改，不要跟着 nissaya 改成帝沙。

## §861 句 128-861-91-101
- **问题**：补出成分 — nissaya 补出了呼格 `ဘဂဝါ= မြတ်စွာဘုရား`（世尊啊），说明愿文是对佛说的。`ဧဝံ= ဤဂေါသိတ စန္ဒဂူးအတူ` 又把 evaṃ 落实为「像这牛头栴檀一样」。
- **建议**：可改为「世尊，愿我在每一次投生的地方，身体都像这栴檀一样芬芳。」至少把「像这样」落实为「像这栴檀一样」。

## §862–863 句 128-862-2-9 / 128-863-2-9
- **问题**：取义 / 格 — pitumātumatena 的 nissaya 是 `အမိအဘသေလွန်ခြင်းကြောင့်`（因父母去世），把 mata 读作「死」（具格表原因）。译文「遵从父母的意愿」把 mata 读作「意见」，与 nissaya 不合。
- **建议**：依 nissaya 改为「因为父母去世」，例如「我从前是林中的猎人，因为父母去世，」。若坚持「意愿」一解需有依据，并压低信心。
- **问题**：词义 — pasumārena 的 nissaya 是 `သားငှက်ကိုသတ်သဖြင့်`（杀鸟兽）。「牲畜」指家养动物，与猎人身份不合。
- **建议**：改为「靠杀害鸟兽为生」。

## §864–865 句 128-865-2-8
- **问题**：补出成分 — nissaya 补出 anukampāya 的对象 `မံ= ငါ့ကို`（对我）。
- **建议**：可改为「那位具眼者出于对我的怜悯，显示了三个足迹」。

## §874–875 句 128-875-2-7
- **问题**：词义 / 补出成分 — nābhijānāmi 的 nissaya 是 `မသိရ`，意思是「未曾经历」，不是「不知道有」。nissaya 还补出原因 `တဿကမ္မဿ ဝါဟသာ`（由于那份业的力量）。译文「从此不知有恶趣」容易被读成「不知道恶趣存在」。
- **建议**：改为「由于那份业，我从未经历过恶趣，这就是供养足迹的果报。」

## §878 句 128-878-16-26
- **问题**：词义 — upagatavassamatto 的 nissaya 是 `ဝါသို့ရောက်သော…တစ်ဝါသာရှိသေးသော`，意思是只是进入了雨安居、仅有一个雨安居，不是「度过」。「度过」暗示已经圆满，与下一句「因为没有圆满而不计入」冲突。
- **建议**：改为「出家以后刚进入一个雨安居，意思是只有一个雨安居」（另见跨段一致性中的「夏腊」一条）。

## §878 句 128-878-27-39
- **问题**：格与句法 — nissaya 把 vassaṃ 处理为 anugataṃ / pacchāgataṃ / apagataṃ 的参照对象：`ဝဿံ= ဝါသို့ … ကင်း၍ဖြစ်သည်`、`လွန်ပြီးသောဝါမှ။ပစ္ဆာ= နောက်၌…`、`ချုပ်ပြီးဝါမှ။အပဂတံ= ဖဲကြဉ်၍ဖြစ်သည်`。也就是说，anuvassa 指「在雨安居之后、离开了雨安居」的那种状态，而不是「随后而来……的雨安居」。译文把 vassa 当成被修饰的主体（「……的雨安居」），主从关系颠倒。
- **建议**：改为「或者说，跟在雨安居之后、在雨安居过后才有、离开了雨安居，叫作 anuvassa；他具有这一点，所以叫 anuvassika。」

## §878 句 128-878-73-101
- **问题**：风格 — 「你已经依之学成」中的「之」是文言虚词，属必改项。
- **建议**：改为「你已经照着它学成了」。「长老依据自己所作已办」中的「依据」可改为「因为」，更贴近 nissaya `နိဿာယ= အမှီပြု၍` 表原因的用法。
