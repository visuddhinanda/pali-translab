# Review — 128:699-710（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词核对（对照父层 162:93-101）

逐个比对，黑体被解释词与父层译文**全部逐字相同**：

- yathāpi bhaddo ājañño → “就像一匹优良的骏马”（§700、§708）✅
- yathāpi → “就像” ✅；bhaddo → “优良的” ✅；ājañño → “骏马” ✅
- naṅgalāvattanī → “翻转着犁头” ✅；sikhī → “竖着鬃毛” ✅
- appakasirena → “毫不费力地” ✅；rattindivā → “日日夜夜” ✅
- sukhe laddhe nirāmise → “因为已经获得了不染世欲的安乐” ✅

**下面三条需要反馈到父层**。本层按约束保持与父层一致，不在本层改：

1. **ājañño 父层译“骏马”**：nissaya 明说此处取 `ဥသဘာဇညော= ဥသဘအာဇာနည်ကို … အလိုရှိအပ်၏`，指良种公牛。本层§709 先把“**骏马**”解释为良种牲畜，接着又说“这里所指的是良种牛”，读者会看到自相矛盾。建议父层把 ājañño 改为不限定物种的译法（如“良种牲畜”），或直接改为“良种公牛”。
2. **sikhī 父层译“竖着鬃毛”**：nissaya 把 sikhā 释为 `သိင်္ဂါ= ဦးချို`（角），异说把 kakudha 释为 `လဘို့`（肩峰），都不是鬃毛。本层§709-84 出现“**竖着鬃毛**：……也就是角”，前后对不上。建议父层改为“头顶有角的”一类译法。
3. **sukhe laddhe nirāmise 父层译“因为已经获得了…”**：本层§709-238/248 给出第二种解读，即时间义，nissaya 作 `လဒ္ဓေ= ရသည်။ သတိ= ရှိသော်` 与 `ပဋ္ဌာယ= စ၍`（从……起）。父层的“因为”只合第一解，引到§709-248 处就与“从获得它的时候开始”冲突。建议父层改为中性的“已经获得了不染世欲的安乐”。

## 跨段一致性

- **usabhājañña**：§709-23、§709-29 译“良种牛”，§709-138 译“良种公牛”。建议统一为“良种公牛”，依据是 usabha 即公牛，nissaya 作 `ဥသဘအာဇာနည်`。
- **āmisa / nirāmisa**：§708 和§709-175 把 nirāmisa 译为“不染世欲”，§709-186 却把 kāmāmisa / lokāmisa / vaṭṭāmisa 译成“欲染、世染、轮回染”。同一个 āmisa，一处译“世欲”，一处译“染”，读者看不出两处是同一个词。建议统一 āmisa 的译法，比如“不受（欲乐、世间、轮回的）染着”，并让 nirāmisa 与之呼应。
- **释词格式**：§709 的被解释词后，“就像 / 优良的 / 骏马 / 毫不费力地 / 日日夜夜”都用“，是（指）……”，唯独“**竖着鬃毛**：”用冒号。建议统一为一种格式。

## §700 句 128-700-52-97
- **问题**：格与句法。nissaya 作 `ဥရုဝေလကဿပဒမနေ= ဥရုဝေလကဿပကိုဆုံးမသော` 修饰 `အာဒိတ္တပရိယာယဒေသနာယ= …၌`，意思是“在调伏优楼频螺迦叶的《燃烧经》开示中”证果。译文把它拆成时间状语“在世尊调伏……的时候”，又补出“他听了”，结构与原文有出入。另外，`သုဂတိတော … သုဂတိံ … ဥပဂစ္ဆန္တော` 是“从善趣往生善趣”，译文“从善趣到善趣”缺了动词。
- **建议**：改为“……从善趣往生到善趣……在调伏优楼频螺迦叶的那次《燃烧经》开示中，和原先的一千名结发外道一起证得了阿罗汉果”。出处 mahāva. 建议标为《律·大品》，以免与《长部·大品》相混。

## §701–702 句 128-701-2-9 / 128-702-2-7
- **问题**：分行错位与修饰关系。nissaya 中 `ဇောတန္တံ` 修饰迦尼迦罗花，`ဇလန္တံ` 修饰灯树，`အဒ္ဒသံ= ဖူးမြင်ရ၏ … လောကနာယကံ` 在第二行。译文却把“我看见了世间的导师”提到 701 行，702 行没有谓语和宾语，违反“偈颂保留分行”。
- **建议**：701 行改为“像光耀的迦尼迦罗花，像满月时的月亮，”；702 行改为“又像燃烧的灯树——我看见了世间的导师。”

## §703–704 句 128-703-2-10 / 128-704-2-8
- **问题**：重复增译。`သေဟိပါဏိဘိ= မိမိလက်တို့ဖြင့်` 只出现在第二行，译文第一行已经写了“亲手”，第二行又写“用自己的双手奉上”。另外 `ဂဏှ= ဆွတ်ယူခဲ့၍` 是“摘取”。
- **建议**：703 行删去“亲手”，可改为“我摘下一颗枸橼果，献给了导师，”。

## §705–706 句 128-705-2-12 / 128-706-2-7
- **问题**：关系词漏译。`ယံဖလံ= အကြင်ရှောက်ချိုသီးကို`，后接 `တဿကမ္မဿ ဝါဟသာ`（由那业力），yaṃ 引导的是关系从句，译文“我那时供养了果子”没有译出这层关系。
- **建议**：改为“我那时供养了那颗果子，”；706 行的“从那以后”可改为“由于那份善业”，与 nissaya 一致。

## §707 句 128-707-2-16
- **问题**：句法。`သာသနံ= အဆုံးအမတော်ကို။ ကတံ= လိုက်နာပြုကျင့်ရပေပြီ`，意思是“已经奉行了佛陀的教导”。译文“佛陀的教导已经完成”容易被误读为教导本身结束了。
- **建议**：改为“我已经奉行了佛陀的教导。”

## §709 句 128-709-16-22
- **问题**：词义。nissaya 把 `အာဇာနိယော` 与 `အာဇာနနော` 都释为“极能了知的”，这是从 ā-jānāti 出发的语源释。译文用“良种的牲畜”译 ājānīyo，丢掉了“能了知”这层意思，与后半句“能够分辨”的呼应也断了。
- **建议**：改为“**骏马**，是指 ājānīya，即出身纯正、能够透彻了知什么合理、什么不合理的良种。”这里的物种矛盾见上文父层第 1 条。

## §709 句 128-709-33-46
- **问题**：用词。`နိယုတ္တော= ယှဉ်သော` 意为“被套用于”，nissaya 只说 `ကသနကိစ္စ`（耕地工作）。“熟练的耕地工作”把 cheka（熟练）挂在工作上，读起来别扭。
- **建议**：改为“这头良种公牛被用来做需要技巧的耕地工作”。

## §709 句 128-709-47-59
- **问题**：语序不通。“它是翻转犁也就是犁铧的”是翻译腔。
- **建议**：改为“意思是：它能翻转犁，也就是犁铧，把犁这里那里来回翻转，在田里耕地。”

## §709 句 128-709-84-92
- **问题**：取义。`သိခါသဒိသတာယ= မီးအလျှံနှင့်တူသည်၏အဖြစ်ကြောင့်`，nissaya 把 sikhā 取作“火焰”，译文取“冠”。两者都通，但这里同时牵涉父层的“鬃毛”问题（见父层第 2 条）。
- **建议**：保留“冠”也可以，但最好在审定父层时一并统一。

## §709 句 128-709-97-121
- **问题**：取义分歧（存疑）。nissaya 把 padhānaṅga 释为 `လုံ့လအားထုတ်ခြင်း၏အင်္ဂါ`（精进努力的支分），译文取“最主要的部位”。
- **建议**：从上下文看（角、肩峰都是显著部位），译文的取义可以成立，暂不改。分歧记录在案。

## §709 句 128-709-138-174
- **问题**：yāva 漏译或误读。nissaya 作 `ယာဝ … ပရိက္ခယံ … အတ္ထိ တာဝ`，意思是“一直到要耕除的草除尽为止”。pali 本作 parissamaṃ，nissaya 读作 parikkhayaṃ。译文“充分显示出它耕地除草的功夫”两种读法都对不上，而且丢了“直到”的范围义。另外“良种公牛”与前文“良种牛”不一致，见跨段一致性。
- **建议**：改为“……来回转向前进，直到把要耕除的草都除尽为止”。异读 parissamaṃ / parikkhayaṃ 记入 known-issues。

## §709 句 128-709-175-185
- **问题**：增译。`တတ္ထ= ထိုသို့လွန်စေရာ၌` 指“对此（日夜流逝这一点）”，原文没有“接着”。
- **建议**：改为“对此说出原因：‘**因为已经获得了不染世欲的安乐**’。”

## §709 句 128-709-238-247
- **问题**：误译，必改。`တတောပဘုတိ= ထိုနေ့မှစ၍` 是“从那时起”，不是疑问。`ဝိစာရဏာယ` 指为说明这一点而说。译文“从什么时候起……”把陈述译成了疑问。
- **建议**：改为“或者，为了说明‘是从那时起，日日夜夜毫不费力地过去’，所以说：”。

## §709 句 128-709-248-265
- **问题**：句法冗复。`လဒ္ဓေ … သတိ= ရှိသော်` 是独立处格，意为“当已获得时”，`ပဋ္ဌာယ` 意为“从……起”。译文“获得……之后，从获得它的时候开始”把同一层意思说了两遍。
- **建议**：改为“意思是：已经获得了不染世欲的安乐，就从获得它的那时开始。”句首引文的“因为”问题见父层第 3 条。
