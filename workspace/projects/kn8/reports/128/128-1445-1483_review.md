# Review — 128:1445-1483（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1445、1446、1447-14-14、1451、1453、1454、1459-11-13 等行无 nissaya；偈颂上句的 nissaya 挂在下句行上，按整首偈核对）

## 被解释词与父层译文对照

逐条比对父层（162:330–336）译文，**全部逐字一致**，无必改项：

- ko kuṭikāyaṃ → “谁在小茅屋里” ✅
- bhikkhu kuṭikāyaṃ → “是比丘在小茅屋里” ✅
- vītarāgo → “已离贪” ✅
- susamāhitacitto → “心善入定” ✅
- āvuso → “朋友” ✅
- evaṃ jānāhi → “你要这样知道” ✅
- amoghā te kuṭikā katā → “你建的小茅屋没有白建” ✅
- ayamāhu purāṇiyā → “人们说这是一座旧茅屋” ✅
- ayan → “这”；āhu → “人们说”；purāṇiyā → “旧” ✅
- aññaṃ patthayase navaṃ kuṭiṃ → “你却想要另一座新茅屋” ✅
- āsaṃ kuṭiyā virājaya → “舍弃对茅屋的希求吧” ✅
- dukkhā bhikkhu puna navā kuṭī → “比丘啊，新的茅屋又会带来苦” ✅
- kuṭivihārī → “茅屋住者” ✅

⚠ **反馈父层（本层不改）**：§1460 本层把 āhu 释为 ahosi（nissaya：`အာဟူတိ= … အဟောသိ= ဖြစ်၏` “是／曾是”），而父层 162:335 把 āhu 译作“人们说”。本层受逐字同译约束只能沿用“人们说”，于是出现“‘人们说’的意思是‘曾是’”这种自相矛盾的句子。建议父层复核 āhu 的译法，父层改定后本层 §1460 两处（1459-69-83 的“人们说这是”、1460-11-15 的“人们说”）随之同步。

## 跨段一致性

- **vītarāgo**：§1446、§1449 译“已离贪”，§1455 译“远离贪欲” → 统一为“已离贪”。依据：与父层被解释词同一译法；nissaya 三处都是 `ကင်းပြီးသောရာဂရှိသော`，含义相同。
- **iti manasikatvā（心里想）**：§1459、§1482 译作“想”，§1450 却译作“说：”，§1470 前也用冒号接引语，读来像出声说话 → 统一为“心想／心里想着”（见下文逐句）。
- **kuṭivihārī tveva samaññā …**：§1456 译“就有了‘茅屋住者’这个称号”，§1482 译“也被称为‘茅屋住者’”。两处是平行句式 → 建议统一为前者的说法。
- **kuṭikā／kuṭi／tiṇakuṭi(kā)**：kuṭikā 一般译“小茅屋”、kuṭi 译“茅屋”，但有两处例外：
  - §1459-38-68 同一句里 purāṇakuṭikā 译“旧茅屋”，后面 kuṭikā 又译“小茅屋”；
  - §1460 tiṇakuṭi(kā) 译“草屋”，读者容易误以为和“茅屋”是两间屋。
  - 建议 tiṇakuṭi 译“草茅屋”或直接用“茅屋”，与全章保持同一所指。属于低优先级。

## §1449 句 128-1449-19-25
- **问题**：句法／赘词 — tassa 按 nissaya 是“对那位看田人”（`တဿခေတ္တပါလဿ= ထိုလယ်စောင့်ယော်ကျားကို`），译文已经用“给他”译出，句首的“对此”是重复翻译。
- **建议**：删去“对此”，改为：“‘是比丘在小茅屋里’是长老给他的回答。”

## §1449 句 128-1449-46-83
- **问题1**：句法 — imañca atthaṃ 按 nissaya 是 vadāmi 的宾语（`ဣမဉ္စအတ္ထံ= ဤအနက်ကိုလည်း … ဝဒါမိ= ဆို၏`），即“我所说的这个意思”。译文把它处理成话题“对于这个意思”，并漏了 ca。
- **建议1**：改为“朋友，看田人啊，正如我说的这个意思那样，你要这样知道——要相信，要确信。”
- **问题2**：措辞 — “心善妥地入定”中的“善妥”生硬。suṭṭhu 的 nissaya 是 `အလွန်လျှင်`（很、极）。
- **建议2**：改为“心很好地入定”。
- **问题3**：标点 — 两个呼格“朋友、看田人啊”之间用了顿号。
- **建议3**：改用逗号。

## §1449 句 128-1449-102-112
- **问题**：指代不明 — taṃ 按 nissaya 是 `တံအနုမောဒနံ`（那份随喜），译成“这件事”太泛。
- **建议**：改为“这份随喜将为你带来长久的利益和安乐”。

## §1450 句 128-1450-2-28
- **问题**：句法误读 — 引语后的 iti 按 nissaya 是 `ဣတိမနသိကတွာ= ဤသို့နှစ်ခြိုက်နှလုံးပိုက်၍`（这样欢喜地想着），是心里的念头，不是说出口的话。译文的“说：”把它当成了说话。
- **建议**：改为“看田人听了，心里想：‘……’于是心生净信，随喜着站在那里。”

## §1452 句 128-1452-2-8（nissaya 覆盖 §1451–1452 整首偈）
- **问题**：隐含成分漏译 — nissaya 补出了 `တဝ= သင်လယ်စောင့်ယောက်ျား၏`（你的），即比丘住在“你的”茅屋里。§1451 译文作“住在茅屋里”，与下句“由于这业的果报”之间的因果联系就断了。
- **建议**：§1451 改为“有一位比丘住在你的茅屋里，他心已寂静，没有漏；”

## §1455 句 128-1455-2-11（nissaya 覆盖 §1453–1455）
- **问题1**：句法 — vītarāgo 按 nissaya 是修饰 paccekabuddho 的定语（`ဝီတရာဂေါ= ကင်းပြီးသောရာဂရှိသော`），译文把它拆成句末的并列谓语；译法也与全章不一致（见跨段一致性）。
- **问题2**：隐含成分 — nissaya 补出 `အန္တိမေ အတ္တဘာဝေ`（在最后一生），可以考虑补出。
- **建议**：改为“在最后一生，你将成为已离贪的辟支佛，名叫宝茅屋（Ratanakuṭi）。”

## §1460 句 128-1460-2-10
- **问题**：风格 — “近在眼前之物”中的“之”是文言虚词。
- **建议**：改为“表示近在眼前的事物的指示词”。

## §1460 句 128-1460-45-64
- **问题1**：风格 — “不起贪着之心”用了文言“之”。
- **问题2**：指代 — tattha 按 nissaya 是 `ထိုကုဋီသစ်၌`（在那新茅屋里），译成“对那里”太含糊。
- **建议**：改为“对新茅屋要完全不起贪着的心”。

## §1460 句 128-1460-94-133 / 128-1460-134-162
- **问题1**：风格（必改）— “自身之屋”反复出现，“之”是文言虚词。
- **建议1**：改为“自身这座屋子”，或“以自身为屋”。
- **问题2**：风格 — §134-162 的“不起贪着之心”同上。
- **建议2**：改为“不起贪着的心”。
- **问题3**：指代 — §134-162 的 tattha 按 nissaya 是 `ထိုအတ္တဘာဝကုဋိယံ`（在那自身之屋里）。
- **建议3**：“对那里”改为“对自身这座屋子”。

## §1462 句 128-1462-2-8（覆盖 §1461–1462）
- **问题**：格 — Padumuttarabuddhassa … nisinnassa … upasantassa tādino 都是与格，nissaya 作 `ပဒုမုတ္တရမြတ်စွာဘုရားအား`（向／给莲华上佛），是下一首偈 upanāmesiṃ（献上）的对象。译文拆成两个独立的判断句，§1462 句末又用句号断开，“献给谁”的关系就看不出来了。
- **建议**：改为“莲华上佛陀是世间至尊、如如不动者；当他坐在草垫上，寂静而如如不动的时候，”，句末不用句号，接下一首偈。

## §1464 句 128-1464-2-7（覆盖 §1463–1464）
- **问题**：词义 — naḷamālaṃ 的 nissaya 是 `ကျူပန်း`（芦苇花），译文作“芦苇”，漏了“花”。
- **建议**：§1463 改为“我拿来芦苇花，编成一把扇子，”。

## §1468 句 128-1468-2-8（覆盖 §1467–1468）
- **问题**：取义 — pariḷāho 的 nissaya 是 `ကိလေသာဟူသောပူပန်ခြင်း`（烦恼的燥热），不只是身体上的燥热。
- **建议**：可保留“燥热”，以便与“身体清凉”呼应，但最好让读者看出它也指烦恼，例如“不再有燥热的烦恼”。请斟酌。

## §1470 句 128-1470-2-7（覆盖 §1469–1470）
- **问题**：句法 — nissaya 补出 `ဣတိမနသိကတွာ`（这样想着），引语是天神们心里的念头。§1469 用“聚集而来：”直接接引语，像是说出口的话。
- **建议**：§1469 改为“所有依林而住的天神心想”，§1470 的引语后接“于是都聚集而来”。

## §1472 句 128-1472-2-8（覆盖 §1471–1472）
- **问题**：措辞 — devasaṅghapurakkhato 的 nissaya 是 `နတ်အပေါင်းခြံရံအပ်သည်`（被天众围绕），“簇拥在前”的“在前”不准确。
- **建议**：改为“天众围绕着他”。

## §1478 句 128-1478-2-6（覆盖 §1477–1478）
- **问题**：误译 — kappasatasahassampi 的 nissaya 是 `ကမ္ဘာတစ်သိန်းအတွင်း၌`（十万劫之内）。“即使经过十万劫”会被读成“十万劫以后”。
- **建议**：改为“在十万劫中，他都不会堕入恶趣”。

## §1480 句 128-1480-2-6（覆盖 §1479–1480）
- **问题1**：时间 — tiṃsakappasahassamhi 的 nissaya 作 `ကမ္ဘာသုံးသောင်းထက်၌`，有“三万劫之前”的意思；动词 nissaya 作 `အဟိံသု`（曾经出现过）。“在三万劫中，有……”丢了过去时。
- **建议1**：考虑改为“在三万劫前，曾有三十八位名叫善誓的转轮王；在二万九千劫前，曾有八位名叫摩鲁多的转轮王。”
- **问题2**：原文疑问 — nissaya 把 aṭṭhatiṃsa 释为 `အဋ္ဌ`（八），漏了“三十”。译文按 pali 作三十八是对的，不改，只记下。

## §1481 句 128-1481-2-16
- **问题**：误译 — kataṃ buddhassa sāsanaṃ 的 nissaya 是 `အဆုံးအမတော်ကို … လိုက်နာပြုကျင့်ရပြီ`（佛陀的教导我已奉行）。“佛陀的教法已经完成”会被读成教法本身完结了。
- **建议**：改为“佛陀的教导我已经奉行了”。

## §1482 句 128-1482-24-31
- **问题**：跨段一致 — 与 §1456 的平行句式不统一（见跨段一致性）。“也被称为”的“也”是从 ca 来的，但会被误读为他另外还有一个名号。
- **建议**：改为“由于他因关于茅屋的教诫获得了殊胜的成就，他就有了‘茅屋住者’这个称号。”
