# Review — 128:3342-3377（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（3342、3345、3347-14-16、3352、3353、3354-9-11、3375 无 nissaya，已略过）

## 被解释词与父层对照

逐条核对了本 chunk 的黑体被解释词与父层（162:777-794）定稿译文，**全部逐字一致**，无必改项：

- pubbe hanati attānaṃ → “他先伤害自己” ✓
- pacchā hanati so pare → “然后再伤害别人” ✓
- suhataṃ hanti attānaṃ → “他彻底伤害了自己” ✓（3348-63-76、3348-188-197 两处）
- vītaṃseneva pakkhimā → “就像用媒鸟诱捕鸟的猎人一样” ✓；vītaṃso → “媒鸟” ✓；pakkhimā → “猎人” ✓
- na brāhmaṇo → “不是婆罗门” ✓；vaṇṇa → “颜色” ✓；brāhmaṇo → “婆罗门” ✓
- yasmiṃ / pāpāni kammāni / kaṇho / sujampati → “谁身上有” / “恶业” / “黑的” / “娑阇之夫（帝释）啊” ✓
- sussūsā → “乐于聆听” ✓

## 跨段一致性

- **Vasabha**：本层 §3350 译“婆娑婆”，与父层标题 §777 一致。但父层 §784、§789 译作“婆娑跋”，父层内部不统一。建议 harmonize 时三层统一为一个译名（本层暂不动）。
- **dakkhiṇā 的果**：§3348-166-187 译“回报”，§3348-22-62、§3348-151-162、§3361、§3372 都用“果报”。建议统一为“果报”。
- **taṭṭika / pāti**：§3360 把 taṭṭike 拆成“器皿”和“盘子”两种，§3361 又把 pātiyo 译作“器皿”，同一个“器皿”对应了两个巴利词。建议 taṭṭika 译“碗盘”，pāti 译“杯钵”（nissaya：ဖလား／သောက်ရေခွက်）。
- **sāri**：§3354-40-61 中 rūpasāriyā 译“鲁帕萨利”，同句 sāriputta 译“舍利弗”，同一词素音译不一致。建议改为“鲁帕舍利”。
- **vaṇṇa（与父层的义理冲突，仅报告）**：§3349-34-39 明说此处 vaṇṇa 是“完美、具足”（nissaya：`ဝဏ္ဏသဒ္ဒေါ= … သမ္ပတ္တိအတ္ထော`）。父层 §782 却译作“好颜色／好品德”，读者会觉得本层的解释与父层译文对不上。受逐字约束，本层黑体保留“颜色”。建议回头复核父层 §782 的译法。

## §3348 句 128-3348-22-62

- **问题**：句法 — `အတ္တနိ= မိမိ၌` 表明 attani 指欺诈者本人（供养是对他做的）。译文“使他们对自己所做的供养”中的“自己”容易被读成“他们自己”。另外 pesalo…ariyo…ti vā 在 nissaya 里是两项并列选择（`…လည်းကောင်း … လည်းကောင်း`），译文合成了一句。paccayavināsanena 的意思是“糟蹋了布施来的资具”，“毁坏资具”太字面。
- **建议**：改为“那些认为‘这位比丘品行端正’或‘是圣者’而恭敬他、向他行供养的人……使他们供养他的那些善行得不到大果报，以糟蹋资具的方式毁掉了他们”。

## §3348 句 128-3348-103-150

- **问题**：词义 — `ပစ္စ= တမလွန်ဘဝ၌`：pacchā 在这里指“来世”，与前文 samparāyaṃ 对照。译文作“在事后”，丢了今生与来世的对照。
- **建议**：“却不能在来世再伤害那些鸟”。“以欺诈欺骗世人”可改为“用欺诈手段欺骗世人”。

## §3348 句 128-3348-166-187

- **问题**：误译 — `မနုဿဘူတဿ= လူသားစင်စစ်ဖြစ်သောသူအား`：manussabhūtassa 意为“身为人类的”。“凡人”会被读成 puthujjana，与原文不符。dakkhiṇā 译“回报”也与全 chunk 的“果报”不一致。
- **建议**：“布施给破戒的人，可以期待千倍的果报。”

## §3354 句 128-3354-2-8

- **问题**：数 — `သုဿုသာနီတိအာဒိကာ … ဂါထာတို့တည်း`：gāthā 是复数，指以 sussūsā 开头的几首偈（§3377 nissaya 也说 gāthādvayaṃ）。
- **建议**：“**乐于聆听**：以这句开头的是尊者摩诃周那长老的偈。”

## §3354 句 128-3354-62-76

- **问题**：风格 — “修起观”是半文言说法。
- **建议**：“开始修观”。

## §3356 句 128-3356-2-7

- **问题**：术语 — `အနာသဝံ= ကင်းပြီးသောအာသဝေါရှိ`：anāsava 是“无漏”。译成“没有烦恼”，就和 virajaṃ（nissaya：离烦恼之尘）重复了，āsava 这个术语也丢了。
- **建议**：“我见到了离尘、已渡暴流、无漏的佛陀。”
- **原文疑问（记录）**：pali §3355 作 haṃsavatiyā，nissaya 作 `ဗန္ဓုမတိယာ`（Bandhumatī，与毗婆尸佛的时代相合），两者底本不同。译文按 pali 译，不改。

## §3358 句 128-3358-2-8

- **问题**：句法 — `ဒတွာ= ပေးလှူရသောကြောင့်`：datvā 是连续体，表示原因，承接下一首偈的果报。译文译成独立的完成句，与上句重复，也断了与 §3359 的因果关系。
- **建议**：“因为把钵献给了正直、如如不动的世尊，”（句末用逗号，接 §3359）。

## §3360 句 128-3360-2-9

- **问题**：句法 — nissaya 中 `ရူပိမယေ / သောဝဏ္ဏေ / မဏိမယေ` 三项都修饰 `တဋ္ဋိကေ= ဖလား`。译文把同一个名词拆成“器皿”和“盘子”两样东西。
- **建议**：“还有银制、金制和宝石制的碗盘。”

## §3362 句 128-3362-2-8

- **问题**：词义 — `ယသာနဉ္စ= အခြံရံတို့၏`：nissaya 把 yasa 解作“随从、眷属”，译文作“名声”。§3361 的 pātiyo（nissaya：饮水杯）译“各种器皿”也偏泛。
- **建议**：§3362 改为“在随从和财富上”。§3361 改为“我享用各种杯钵”。

## §3364 句 128-3364-2-8

- **问题**：词义 — `သမ္မာဓာရံ= အရည်ထန်စွာ`：意思是雨下得充沛，不是“适时”。
- **建议**：“只要雨水充沛地降下”。

## §3366 句 128-3365-2-9

- **问题**：句法 — 句首“同样”已经承接了上面的比喻，再加“就像”就重复了。nissaya 把 pattadāna 当作种子本身（`သပိတ်အလှူတည်းဟူသောမျိုးစေ့`），直接陈述即可。
- **建议**：“同样，这次献钵种在佛陀这块福田里，”。

## §3372 句 128-3372-2-7

- **问题**：词义 — `နာဘိဇာနာမိ= မသိရပေ`：这是“不曾经历”的惯用说法。“不知道有恶趣”容易读成“不知道恶趣存在”。
- **建议**：“从此不曾堕入恶趣，这是献钵的果报。”

## §3373 句 128-3373-2-16

- **问题**：误译 — `သာသနံ= အဆုံးအမတော်ကို … ကတံ= လိုက်နာပြုကျင့်ရပြီ`：意思是佛陀的教导我已遵行完成。“佛陀的教法已经完成”像是在说教法本身完结了。
- **建议**：“佛陀的教导我已奉行完成。”

## §3374 句 128-3374-2-12

- **问题**：误译 — `ဂရူပနိဿယံ= ဆရာတည်းဟူသော ဥပနိဿယ`：garu 指师长，不是“重要”。“重要依止（善知识）”译窄了，括注也不够准确。
- **问题**：增译 — 原文以 kittento 收尾，后面接偈。“说了这首偈”是补出来的谓语，而且 nissaya（§3377）明说是两首偈（gāthādvayaṃ abhāsi）。
- **问题**：风格 — “所得成就之因”用了文言“之”，是必改项。
- **建议**：“他成为具足六神通的人后，为了称赞成就他所得果位的原因——师长这一依止，以及远离独处的生活——说道：”。
