# Review — 162:859-936（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性
- **taṇhā**：§882 译“渴爱”，§885 jāliniṃ（nissaya：`ဇာလိနိံ= တဏှာတည်းဟူသော ကွန်ယက်ကို` 即“渴爱这张网”）译“贪爱的罗网” → 统一为“渴爱的罗网”。
- **ājañña / ājānīya**：§930、§934 都译“良种骏马”，两处一致，但 nissaya 都释为公牛（`နွားလား ဥသဘ`），见下文 §930、§934。
- **ekarattiṃ**：§899、§902 都译“在一夜之间”，两处一致，但与 nissaya 的读法不同，见下文 §899。
- **偈颂开头的引号**：§863、§893、§933 的巴利原文以 ‘‘ 开头，译文缺少开头的 “（这三偈的结尾引号都在下一段）→ 补上，与其他各偈的体例保持一致。
- **attā asamāhito / susamāhito**：§868、§869、§871、§872 都译为“自己的心……”，四段一致。nissaya 释 attā 为 `မိမိသည်`（自己），原文没有“心”字。可以保留，如要贴近原文可改为“自己不得定／自己善得定”，四段需同步修改。

## §863–864 句 162-863-2-7 / 162-864-2-11
- **问题**：补出成分 — 原文 upāyakusalena buddhena ādiccabandhunā 是具格，nissaya 作 `ဗုဒ္ဓေန= မြတ်စွာဘုရားကြောင့်`（因为/依靠佛陀），并没有“引导”这个动词。译文补出“引导我”，又把句子拆成两个主语。此外 nissaya 明确说心原本沉溺于有中：`ဘဝေ= သံသရာ…ညွန်ပြောင်း၌။ နိရဂ္ဂံ= နစ်သော။ စိတ္တံ`。§863 还缺开头的引号。
- **建议**：“依靠善巧方便的佛陀、太阳的亲族，我如理修行，把沉溺在诸有中的心拔了出来。”（开头补 “）

## §883 句 162-883-2-9
- **问题**：语序 — “诸漏的灭尽我已达到”读起来生硬。nissaya：`ပတ္တော အဓိဂတော= ရအပ်ပြီ`（已证得）。
- **建议**：“我已修习诸觉支，已证得诸漏的灭尽。”

## §890 句 162-890-2-12
- **问题**：误译 — yūpo 在 nissaya 中释为 `ပြဿာဒ်`（宫殿，pāsāda），不是“祭柱”。§891 的 nissaya 接着写 `တဿပါသာဒဿ`（那座宫殿的），可以互相印证。**必改**。
- **问题**：漏补隐含主语 — nissaya 作 `သောအဟံ= ထိုငါသည်။ … ရာဇာ= မင်းသည်။ အဟောသိံ= ဖြစ်ဘူး၏`，意思是“我曾是那位名叫波那陀的国王”。长老在讲述自己的前世，译文成了第三人称叙述。
- **建议**：“我曾是名叫波那陀的国王，我的宫殿是纯金造成的；”

## §891 句 162-891-2-34
- **问题**：取义 — nissaya 把 sahassadhā … āhu 读作“据说有一千层”（见 §893 行：`သဟဿဓာ သဟဿကဏ္ဍပမာဏံ= တထောင်သော ဘုံဆင့်ရှိ၏ ဟူ၍ အာဟု`）。译文“高达一千”没有量词，读者无法理解。“横宽十六”同样缺量词，nissaya 在数词后给出了单位（`တဆဲ့ခြောက်မင်းပယ်စား`）。
- **建议**：“它横宽十六（单位按 nissaya 补出），据说向上有一千层。”单位的确切所指拿不准，可以写入报告待查，译文中不留标记。

## §893 句 162-893-2-9
- **问题**：词义 — satageṇḍu 的 nissaya 是 `များစွာသော အထွဋ်`（许多尖顶），sata 在这里表示“众多”，不是确数“一百”。haritāmayo 的 nissaya 是 `ရွှေစင်သိင်္ဂနိတ်ဖြင့် ပြီး၏`（用纯净的上等金造成），“绿金”没有依据。开头缺引号。
- **建议**：“它有一千层，有许多尖顶，插满旗幡，由纯金造成；”（开头补 “）

## §894 句 162-894-2-11
- **问题**：词义 — gandhabbā 的 nissaya 是 `ကချေသည်တို့`（舞者、乐舞艺人），是人间的表演者，不是天界的乾闼婆。sattadhā 的 nissaya 是 `ပြသာဒ်၏ ခုနစ်ပါးသော အရပ်၌`（在宫殿的七处），是处所义，不是“分作七组”。
- **建议**：“六千名舞者在那里，分在宫殿的七处起舞。”

## §898–899 句 162-898-2-9 / 162-899-2-7
- **问题**：句法 — nissaya 中 satimā / paññavā / bhikkhu / āraddhabalavīriyo 都带 `ထသော`，是修饰 ahaṃ 的同位语。整首偈的主语是“我”，译文把前半句拆成了独立的另一个主语。
- **问题**：复合词 — āraddhabalavīriyo 的 nissaya 是 `သဒ္ဓါဗလဝီရိယဗလနှင့် ပြည့်စုံ`（具足信力与精进力），是并列结构，不是“精进之力”。
- **问题**：取义 — ekarattiṃ 的 nissaya 是 `ဧကရတ္တိံ ဝိယ= တညဉ့်တည်းကိုကဲ့သို့`（如同一夜），anussariṃ 的 nissaya 是 `တခုသော ဝီထိ အစဉ်ဖြင့် အောက်မေ့နိုင်၏`（能以一个心路过程忆起）。意思是忆起五百劫就像忆起一夜那样容易，不是“在一夜之间”。
- **问题**：格式 — 译文里“**有念**、**有慧**”的粗体是照搬巴利数据中的 `**` 残留，本文译文不该带粗体。
- **建议**：“我这个有念、有慧、发起了信力与精进力的比丘，忆起五百劫，就像忆起一夜一样。”去掉粗体。

## §901–902 句 162-901-2-11 / 162-902-2-10
- **问题**：句法 — bhāvayaṃ 的 nissaya 是 `ဘာဝယန္တော= ပွါးစေသောကြောင့်`（因为修习），与下半句是因果关系，译文丢了这层关系。ekarattiṃ 的问题同 §899。
- **建议**：“由于修习四念处、七觉支与八正道，我忆起五百劫，就像忆起一夜一样。”

## §909 句 162-909-2-10
- **问题**：称谓 — tvaṃ 的 nissaya 是 `ကမ္မဋ္ဌာန်းကို ပေးတတ်အရှင်ဘုရား`（授业处的尊者），§910 也作 `တွံ=အရှင်`，是对师长说话。
- **建议**：“请您为我指示道路……”

## §910 句 162-910-2-11
- **问题**：词义 — monena 的 nissaya 是 `မောနေနဉာဏေန= အရဟတ္ထမဂ် ဉာဏ်ဖြင့်`（以阿罗汉道智），monissaṃ 的 nissaya 是 `နိဗ္ဗာန်ကို သိလတ္တံ့`（将了知涅槃）。mona 在这里是“智”，“以寂默之行成就寂默”与 nissaya 不合。ogāhati 是“流入”，“归向”的意思偏弱。
- **建议**：“我将以道智（mona）证知涅槃，就像恒河的水流注入大海。”

## §914 句 162-914-2-12
- **问题**：词义 — olikhissanti 的 nissaya 是 `ဖြတ်သဖြင့် ပြုပြင်လိုသည်ဖြစ်၍`（想要修剪整理）。长老当时还是在家人，理发师来是为他修剪头发。“剃除头发”会被读成出家剃度。
- **建议**：“理发师走上前来，要为我修剪头发；”

## §917 句 162-917-2-12
- **问题**：格 — nissaya 把 andhakāre 读作处格：`အန္ဓကာရေ= အမိုက်ကိုပြုရာဖြစသော ကိုယ်၌`（在这造成黑暗的身体中）。tamo 的 nissaya 是 `အဝိဇ္ဇာဟူသော အမိုက်`（无明的黑暗）。译文把两个词合成“愚痴的黑暗”，丢了处所义，也没有点明是无明。
- **建议**：“身体显现为空无实质，在这昏暗的身体中，无明的黑暗已经消散；”

## §922–923 句 162-922-2-10 / 162-923-2-6
- **问题**：格（**必改**）— ñāṇadassanaṃ 的 nissaya 是 `ဉာဏဒဿနေန= ဉာဏ်တည်းဟူသော မျက်စိဖြင့်`（具格：以智慧之眼），attano 的 nissaya 是 `အတ္တနော= မိမိ၏။ ကာယေ= ကိုယ်၌`（自己的身体）。译文“照见自己的智见”把智见当成被照的宾语，又把 attano 挂到了智见上，句法读反了。
- **问题**：词义 — yogakkhema 的 nissaya 是 `ယောဂ၏ ကုန်ရာ ဖြစ်သော နိဗ္ဗာန်`（诸轭止息处，即涅槃）。“瑜伽安稳”容易被现代读者误读为瑜伽。
- **建议**：“为了证得离轭的安稳，我舍弃了五盖；以智见之眼拿起法的镜子，观照自己的身体，”

## §926 句 162-926-2-12
- **问题**：取义（可选）— ajjhattaṃ 的 nissaya 是 `မိမိသန္တာန်၌`（在自身相续中），bahiddhā 的 nissaya 是 `အပသန္တာ၌`（在他人相续中）。“内在／外在”太笼统。
- **建议**：“无论在自己身上还是在他人身上，身体都显现为空无实质。”

## §930 句 162-930-2-10
- **问题**：词义 — bhaddo ājañño 的 nissaya 是 `နွားလားဥသဘ`（良种公牛），与 §931 的 vahate dhuraṃ（负轭拉重担）相合。“骏马”与 nissaya 不符。
- **建议**：“就像一头良种公牛，失足之后又重新站稳，”

## §933 句 162-933-2-8
- **问题**：格 — dassanasampannaṃ 与 sammāsambuddhasāvakaṃ 都是宾格，和 §934 的 maṃ 同位，作 dhāretha 的宾语。译文把它们译成主格陈述句“我……是……弟子”。dassana 的 nissaya 是 `မဂ်ဉာဏ်အမြင်`（道智之见），译成“正见”多了“正”字。开头缺引号。
- **建议**：与 §934 合成一句：“同样，请你们把我——这个具足道智之见的正等正觉者弟子——……”（开头补 “）

## §934 句 162-934-2-12
- **问题**：词义 — ājānīyaṃ 的 nissaya 是 `…နွားလား ဥသဘနှင့်တူ၏`（如同良种公牛），同 §930。
- **建议**：“……看作一头良种公牛、佛陀亲生的儿子。”
