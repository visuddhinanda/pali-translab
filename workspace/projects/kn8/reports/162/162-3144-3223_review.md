# Review — 162:3144-3223（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **khīyati 的主语**：§3167、§3174、§3181、§3188、§3195、§3202 都译作“痛苦随之减损”。nissaya 在这六处一致把主语补为烦恼轮转，例如 `ခိယျတိ= အလုံးစုံသော ကိလေသာဝဋ်သည်ကုန်ခြင်းသို့ ရောက်၏`（一切烦恼轮转趋于尽灭）。苦（dukkhaṃ）要到下一句才作主语出现。建议六处统一改为“烦恼随之耗尽而不再增长”。
- **ca api 译作“乃至”**：§3166、§3173、§3180、§3187、§3194、§3201 都用了“乃至”。nissaya 作 `သေဝတောစာပိ= …ပုဂ္ဂိုလ်အားလည်း`（对……的人也），是并列的“也、以及”，没有递进或极限的意思。建议六处统一改为“以及”。
- **tañca 的所指**：§3150、§3157、§3164、§3171、§3178、§3185、§3192、§3199 都译作“它”。nissaya 一律把它释为所缘境，例如 `တဉ္စ= ထိုဖောဋ္ဌဗ္ဗာရုံကိုလည်း`（那所触境），§3164 则是“那色境”。现在“它”紧跟在“去感受”之后，读者会理解成指感受。建议按各段所缘明确写出：“那所触 / 那法 / 那色 / 那声音 / 那气味 / 那滋味”。
- **abhijjhā 句多出“增长”**：§3146、§3153、§3160 都译作“贪求与恼害也随之增长”。nissaya 把 abhijjhā 和 vihesā 作主格，配谓语 upahaññati（`စိတ္တံ= စိတ်ကို။ ဥပဟညတိ= ညှဉ်းဆဲနှိပ်စက်၏`，意为折磨他的心），没有承接上一行的 vaḍḍhanti。三处应统一删去“也随之增长”（详见 §3146）。
- **ācinato dukkhaṃ 的句法**：§3147、§3154、§3161 三处问题相同（详见 §3147），需要统一改。
- **动词带不带“到”**：同一感官，前后两颂措辞不一。
  - §3184 作“尝到滋味”，§3187 作“品尝滋味”；
  - §3191 作“接触到所触”，§3194 作“接触所触”；
  - §3198 作“认知到法”，§3201 作“认知法”。
  
  而嗅觉一组（§3177 和 §3180）都作“嗅到气味”。建议各组统一为“V 到 X”。
- **sujāta**：§3207 和 §3210 都译“出身高贵”。按 nissaya，§3207 指身形（见下文）。建议两处统一改为与身相有关的译法。
- **人称**：Sela 偈（§3207–3223）通篇用第二人称“您”，只有 §3216 作“这位比丘”（见下文）。
- **语体**：“染著于种种色/声音/气味/滋味/所触/法”（§3163、§3170、§3177、§3184、§3191、§3198）和“追随于您”（§3222）中的“于”带文言色彩。建议统一删去，改为“不染著种种色”“追随您”。

## §3146 句 162-3146-2-8
- **问题**：格与句法。按 nissaya，`အဘိဇ္ဈာစ= …လောဘသည်လည်းကောင်း`、`ဝိဟေသာစ= …ဒေါသသည်လည်းကောင်း` 是主格，`စိတ္တံ= စိတ်ကို` 是宾格，`ဥပဟညတိ= ညှဉ်းဆဲနှိပ်စက်၏` 是主动态谓语，意思是贪求与恼害折磨他的心。译文给贪求、恼害另加了“随之增长”，又把心改成被动的主语，两处都与 nissaya 的句法不合。
- **建议**：改为“贪求与恼害损害他的心；”

## §3147 句 162-3147-2-8
- **问题**：格与句法、补出成分。
  - nissaya 给 ācinato 的宾语是补出的 `ဘဝါဘိသင်္ခါရကို ပွါးစေသော သူအား`（增长导致来生的行），并没有把 dukkhaṃ 当作它的宾语。
  - dukkhaṃ 被单独析为主格 `ဒုက္ခံ= ဝဋ်ဆင်းရဲသည်`，后面补出谓语 `ပဝတ္တတိ= ဖြစ်၏`（生起）。
  - 译文“积聚痛苦的人”把 dukkhaṃ 当成了 ācinato 的宾语。
  - 另外，nissaya 的结构是“对他而言，涅槃被说为在远处”（`တဿ … နိဗ္ဗာနံ … အာရာ … ဝုစ္စတိ`）；译文改成“人离涅槃远”，意思大体相当，可以保留。
- **建议**：改为“像这样积聚的人，苦就随之生起，说他离涅槃很远。”

## §3149 句 162-3149-2-14
- **问题**：句法（因果顺序）。nissaya 的语序是 `ပိယံနိမိတ္တံ … မနသိကရောတော= …နှလုံးသွင်းခြင်းကို ပြုသော သူအား` 在前，`သတိမုဋ္ဌာ= သတိ၏ လွတ်ခြင်းသည်` 在后，意思是对作意可爱之相的人，正念就失去了：作意在先，是失念的条件。译文写成“失去了正念，去作意可爱的相”，因果颠倒了。
- **建议**：改为“接触到所触后，因作意可爱的相而失去正念，”

## §3156 句 162-3156-2-13
- **问题**：同 §3149。
- **建议**：改为“认知到法后，因作意可爱的相而失去正念，”

## §3150 句 162-3150-2-8
- **问题**：
  - tañca 的所指，见跨段一致性。
  - “停留其中”的“其中”是 nissaya 没有的处所成分：`တိဋ္ဌတိ= တည်၏` 只是“住、停留”。
- **建议**：改为“并且执取那所触而住。”§3157 也照此改。

## §3164 句 162-3164-2-8
- **问题**：原文疑问。pali 作 vedeti（肯定），nissaya 词头却作 `နဝေဒေတိ= သာယာနှစ်သက်သော အားဖြင့် အာရုံကို မခံစား`（不以喜乐的方式去感受）。其余各颂（§3171、§3178 等）的 nissaya 都是 vedeti 加“不带喜乐地感受”，意思一致，所以译文“以离染的心去感受”可以保留。这一处只记作底本异读，不改。

## §3166 句 162-3166-2-11
- **问题**：
  - “乃至”，见跨段一致性。
  - 句法：nissaya 把本颂析为 `…အဘိဇ္ဈာဒယော … နပဝတ္တန္တိယထာ / ဧဝံတထာ …`，即“正如看色时贪求等不起，同样受用感受时……”，是 yathā…evaṃ 的对比结构，并非单纯的时间从句。
  - 补出成分：nissaya 把 passato 释为以无常等行相去观看，`သေဝတော` 释为“受用”。
- **建议**：至少把“乃至”改为“以及”，可作“当他看见色、以及受用感受的时候，”。§3173、§3180、§3187、§3194、§3201 同此。

## §3167 句 162-3167-2-9
- **问题**：
  - 主语误读，见跨段一致性。nissaya 在上一句（§3166）末行补出 `ခိယျတိ= အလုံးစုံသော ကိလေသာဝဋ်၏ ကုန်ခြင်းသို့ ရောက်၏`，主语是烦恼轮转，不是苦。
  - “减损”力度不够：nissaya 的 `ကုန်ခြင်းသို့ ရောက်` 是“趋于尽灭”。
  - `စရတိဝိဟရတိ= နေ၏`（住、安住），“而行”可以考虑改为“安住”。
- **建议**：改为“烦恼随之耗尽而不再增长，他就这样具足正念而安住；”§3174、§3181、§3188、§3195、§3202 同此。其中 §3195 的 nissaya 主语作 `ဝဋ်`（轮转），可酌情译为“轮转之苦随之耗尽……”。

## §3201 句 162-3201-2-12
- **问题**：原文疑问。pali 作 sevato，nissaya 词头却作 `အသေဝတောစာပိ= တဏှာ၏ အစွမ်းဖြင့် မမှီဝဲသော`（不以渴爱受用），是底本异读，只作记录。译文按 pali 译出，无误。另有“乃至”的问题，同 §3166。

## §3187 句 162-3187-2-11
- **问题**：原文疑问。pali 作 sāyarato，疑为 sāyato 之讹；nissaya 词头正作 `သာယ‌တော`，只作记录。另有“乃至”的问题，以及与 §3184 措辞不一的问题，见跨段一致性。

## §3207 句 162-3207-2-9
- **问题**：词义取解。nissaya 释 sujāto 为 `လုံးရပ်သဏ္ဌာန်နှင့် ပြည့်စုံသော ကောင်းစွာဖြစ်သော ကိုယ်ရှိသည်`（身材体态圆满、生得端好的身体），指身形，不是出身。前后几个词都在描写身相，译作“出身高贵”是误译。
- **建议**：改为“您身体圆满，光彩照人，体态匀称，容貌端严；”

## §3210 句 162-3210-2-11
- **问题**：
  - 补出成分：nissaya 把 narassa 释为 `ယောင်္ကျားမြတ်ဖြစ်သော စင်္ကြာမင်းအား`（作为大人的转轮王），把 viyañjanā 释为三十二大人相和八十随形好，不是泛指“人”的特征。
  - `ဟိ= သစ္စံ`（确实）漏译。
  - sujāta 与 §3207 统一。
- **建议**：改为“确实，凡是生得完美的大人所具有的种种相，”

## §3211 句 162-3211-2-9
- **问题**：句法。nissaya 把 `သဗ္ဗေ … တေမဟာပုရိသလက္ခဏာ … သန္တိ` 析为一个主语（那些大人相全部）加补出的谓语“在”，大人相是同位的主语成分。译文用破折号写成“那就是大人相”，像是在下判断，结构不对。
- **建议**：改为“这些大人相全都具足在您的身上。”

## §3216 句 162-3216-2-8
- **问题**：格与人称。nissaya 作 `ဘိက္ခုဘိက္ခူနံ= ရဟန်းတို့၏`，把 bhikkhu 析为复数属格“诸比丘之中”。后面两项都用敬语谓语 `ရှိတော်မူ၏`，仍是在对世尊称“您”。译文“这位比丘”是第三人称，与前后的“您”不一致，句法也读错了。
- **建议**：改为“在比丘当中，您容貌端好，皮肤如同黄金一般；”

## §3217 句 162-3217-2-8
- **问题**：补出成分。nissaya 补出谓语 `ကိံသောဘတိ`，问的是沙门身份对您是否“相称”（sobhati），不是“有什么用”。
- **建议**：可改为“您有如此殊胜的容色，做沙门哪里配得上您呢？”

## §3219 句 162-3219-2-11
- **问题**：
  - rathesabho 的 nissaya 是 `ရထားစီးသော သူတို့တွင် … မြတ်သော`（乘车作战者之中最殊胜的），“雄牛”是比喻义，“车乘中”则误把范围理解成车辆。
  - 句法：nissaya 把 cakkavattī、rathesabho（连同 §3220 的各项）都作为 rājā 的修饰语，不是并列的几个“做……”。
- **建议**：改为“您应当成为国王，做转轮王、车战者中的至尊，”

## §3220 句 162-3220-2-14
- **问题**：
  - 词义：nissaya 释 cāturanto 为 `သမုဒ္ဒရာလေးစင်းအဆုံးရှိသောမြေအပြင်ကို အစိုးရ`（统治以四海为界的大地），释 vijitāvī 为 `ရန်အပေါင်းကို အောင်`（战胜一切敌人）。译文“征服四方的胜利者”把两个词揉成了一个。
  - jambusaṇḍassa：nissaya 按异读 jambumaṇḍa 释为 `ဇမ္ဗုဒိပ်ကျွန်း`（阎浮提洲）。“阎浮林”是字面直译，与 nissaya 不合。
- **建议**：改为“统治以四海为界的大地，战胜一切敌人，做阎浮提的主宰。”

## §3222 句 162-3222-2-27
- **问题**：
  - 格与句法：nissaya 把 `ဘောဂါ … ခတ္တိယာ … ရာဇာနော` 析为一个名词组（享有财富、出身刹帝利种姓的诸王），不是“刹帝利们和诸王”两组人。
  - 句法分歧：nissaya 以 `တွံ`（您）为主语、诸王为宾格（`ကို`），把 anuyantā 释为“使之随从”（causative），即“您使诸王随从”。译文作“诸王追随您”，大意相同，可以保留。
  - “追随于您”的“于”宜删。
- **建议**：改为“享有财富的刹帝利诸王，都会追随您；”
