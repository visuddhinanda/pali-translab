# Review — 162:3064-3143（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 词法复核）
> 本层是本文 mūla，没有父层，所以不查被解释词是否与父层一致。

## 跨段一致性

- **kāma / kāmaguṇa**：§3066、§3072、§3098、§3107 的 kāma 都译作“欲乐”，§3099 的 kāmaguṇa 也译作“（种种）欲乐”，两个词混成了一个译名。nissaya 对 kāmaguṇa 的释义是 `ကာမဂုဏ်`（欲的诸种对象）。建议 kāmaguṇa 改译“五欲”或“欲乐对象”，与 kāma 区分开。
- **vitta / bhoga**：§3065、§3083 的 vitta 译作“财物”，§3077 的 bhoga 也译作“财物”，两词撞名。建议 bhoga 改作“财产”，或者把 vitta 统一成“钱财”。dhana 一律译“财富”，前后一致，可以保留。
- **moha / bālya**：§3065、§3090 的 mohā 译“愚痴”，§3087 的 bālyā 也译“愚痴”。nissaya 把 bālyā 释为“处在愚人的状态”（`သူမိုက်အဖြစ်`），和 moha 不是同一个概念。建议 bālyā 改译“愚昧”或“愚蠢”。
- **时态“了”**：§3071“走向了死亡”、§3072“舍弃了身体”、§3080“拿走了”、§3121/3128/3135/3142“失去了正念”，说的都是普遍道理或条件句，pali 用的是现在时（upenti / jahanti / haranti），加“了”就读成了一次过去的叙事。建议去掉这几个“了”。
- **摩罗迦子四组重复句**：§3122/3129/3136/3143、§3124/3131/3138、§3125/3132/3139、§3126/3133/3140 的译法彼此一致。下面各句的修改建议要在同组所有段落**同步**改，不能只改一处。
- **haññati**：§3095 和 §3096 都译“受害”，前后一致，但词义偏弱（见 §3095）。改的时候两处一起改。

## §3066 句 162-3066-2-11
- **问题**：nissaya 异读，仅作记录。nissaya 把 luddhā 释为“猎人们”（`မုဆိုးတို့`），还补出 `မိဂေ ဟန္တွာ`（杀了野兽），这是把 luddha（贪婪）误读成了 luddaka（猎人）。
- **建议**：保留现译“贪婪地”，不跟 nissaya 改。

## §3072 句 162-3072-2-12
- **问题**：漏译句法连接词。“na hatthi” = na **hi** atthi，nissaya 也是按因果说明来理解这一句的。现译“在世间，欲乐是无法使人满足的”丢了 hi 表示的“因为”。
- **建议**：改为“……舍弃了身体，因为在世间，欲乐无法带来满足。”

## §3077 句 162-3077-2-21
- **问题**：用词。sūla，nissaya 释作 `တစူး`（尖桩、尖签），“木叉”不够准确。另外 nissaya 采用的是异读 `etena gattena`（带着这个身体），并补出 `ဂစ္ဆန္တိ`（离去）。现译依照的是正文读法 ekena vatthena，这样做没错。
- **建议**：“木叉”改为“尖桩”。“舍下了**所有**财物”里的“所有”在原文中没有，可以删掉。

## §3080 句 162-3080-2-14
- **问题**：指称错位。satto 指的是这位死者本人，nissaya 释为 `သေသော သတ္တဝါ`（那个死去的有情），现译“众生”读起来像泛指所有人。
- **建议**：改为“而死者本人则随着自己的业而去”，或“而这个有情则随业而去”。

## §3081 句 162-3081-2-20
- **问题**：主宾关系变了。nissaya：`မိယျမာနံ= သေသောသူကို`（临死者，宾格），`ကိဉ္စိ … ဝတ္ထုသည်`（任何财物，主格），`နအနွေတိ`（不跟随）。也就是说，主语是财物，临死的人是宾语。现译“临死的人，什么财富也带不走”把临死者变成了施事，和后半句“……都不会跟随他”的句法也不对称。另外 nissaya 后半句读作 `raṭṭhaṃ janañca`（国中的人民），和正文 dhanañca raṭṭhaṃ 不一样，仅作记录。
- **建议**：改为“任何财富都不会跟随临死的人，儿女、妻子、财富和国土也都不会跟随他。”

## §3084 句 162-3084-2-9
- **问题**：原文疑似讹误，只记录不改。pali 作“Appappaṃ hidaṃ”，nissaya 拆成 `အပ္ပံအပ္ပံ`。照格律看，应当是“Appaṃ hidaṃ”。
- **建议**：译文不用改。

## §3086 句 162-3086-2-16
- **问题**：补出成分，也是可读性问题。nissaya：`ဖဿံ= … သေခြင်းဟူသော အတွေ့သို့`（死亡这种接触），`ဖုဋ္ဌော= သေခြင်းဖြင့် တွေ့အပ်၏`（被死亡触及）。现译光写“遭遇触”“被触”，读者看不出指的是什么。
- **建议**：改为“富人和穷人都会遭受（死亡的）触击，愚者和智者也同样被它触及”。

## §3087 句 162-3087-2-14
- **问题**：小品词误读。nissaya 把 `ဝဋ္ဌိတောဝ` 里的 va 释为 `သာလျှင်`（= eva，“正是、确实”），不是 iva（像）。所以“像被击倒一样”不合 nissaya。nissaya 的意思是：被忧恼折磨，处在愚昧之中，辗转反侧地躺着。另外句首 hi 表示“因为”，现译漏了。
- **建议**：改为“因为愚者由于愚昧，确实受到打击，辗转躺卧；智者被触时却不会动摇。”

## §3090 句 162-3090-2-10
- **问题**：nissaya 歧读，仅作记录。nissaya 把 mohā 释为 `မိုက်သော သူသည်`（愚人，主格），现译按从格理解为“由于愚痴”。现译与 §3065 nissaya 对 mohā 的从格释义一致，可以保留。
- **建议**：维持现译。

## §3092 句 162-3092-2-12
- **问题**：句法关系。āpajja 是独立式，nissaya 的语序是：`သံသာရံ အာပဇ္ဇ`（陷入轮回之后）→ `ဂဗ္ဘဉ္စ … ဥပေတိ`（进入母胎、去往他世）。现译把“流转轮回”放在最后，当成并列结果，先后关系反了。
- **建议**：改为“他一次又一次陷入轮回，进入母胎，又去往他世；”。

## §3095 句 162-3095-2-13
- **问题**：比喻结构被打散，用词也偏弱。nissaya 里的 pāpadhammo 就是那个被抓住的盗贼，haññati 释作“用藤条抽打、用刀枪砍刺”来折磨，指的是盗贼受刑。现译把 pāpadhammo 译成泛指的“作恶的人”，和 §3096 重复；“受害”也没有表达出“受刑罚”的意思。
- **建议**：改为“就像在墙洞口被抓住的盗贼，这个作恶的人因自己的行为而受刑罚；”。

## §3096 句 162-3096-2-11
- **问题**：主语拆错了。pajā 和 pāpadhammo 是同一个主语（谓语是单数 haññati），nissaya 也只出现一个施事。现译把“众生……作恶的人”写成了两个主语，读起来别扭。haññati 在这里 nissaya 释为受五种刑缚之类的折磨。
- **建议**：改为“同样，作恶的众生死后在他世，也因自己的业而受折磨。”

## §3099 句 162-3099-2-10
- **问题**：术语，见“跨段一致性”里的 kāmaguṇa 一条。
- **建议**：“种种欲乐中的过患”改为“五欲中的过患”。

## §3102 句 162-3102-2-11
- **问题**：“也”的位置不对，句子也连成了一串。nissaya：`ဧတမ္ပိ ကာရဏံ`（这个缘由**也**），pi 跟的是 etaṃ，不是“我”。现译“我也看到了这一点”容易读成“我也（和别人一样）”。“所以”在原文中没有。后半句是独立判断，用逗号接上去显得含混。
- **建议**：改为“也是看到了这一点，大王，我才出家。毫无疑问，唯有沙门生活才更好。”

## §3104 句 162-3104-2-9
- **问题**：nissaya 取义。upeto，nissaya 释为 `ကောင်းသော အကျင့်နှင့် ပြည့်စုံ၏`（具足善行）；现译取的是“投入”。
- **建议**：可以改为“在胜者的教法中具足善行”。现译也说得通，这一条是低优先级。

## §3105 句 162-3105-2-9
- **问题**：**误译，必改**。nissaya：`အဝဉ္ဇာ= အရဟတ္တဖိုလ် … သားမွေးသောကြောင့်မမြုံ`，意思是“没有白费、不是不结果”：因为它结出了阿罗汉果。nissaya 读作 avañjhā（不空、不徒劳），现译“没有过失”是按 avajja（有过失）来理解的，意思错了。另外 nissaya 补出了 `တတော`（因此），说明下半句和上半句是因果关系；`အနဏော`（无债），nissaya 释为“没有烦恼之债”。
- **建议**：改为“我的出家没有白费，所以我无债地享用饮食。”

## §3108 句 162-3108-2-7
- **问题**：句子悬空，主句没有补出。§3107 和 §3108 都是“看到……”的分词结构，nissaya 在本句末补出了 `အဟံ ပဗ္ဗဇိတော အမှိ`（我出家了）。现译用“；”收尾，没有主句。
- **建议**：句末改为“……以及地狱中的大怖畏，我就出家了。”

## §3110 句 162-3110-2-10
- **问题**：语体。“了知了”里两个“了”重叠，读起来拗口。
- **建议**：改为“知道了这些过患，那时我生起了悚惧；”。

## §3111 句 162-3111-2-9
- **问题**：**误译，必改**。nissaya：`ဝိဒ္ဓေါ= ရာဂဟူသော ငြောင့်တံသင်း … စူးအပ်သည်`（被贪欲之刺扎中），`သန္တော= ဖြစ်လျက်`（是、处于，as 的现在分词），然后补出 `ဣဒါနိ`（如今）。santo 在这里不是“寂静”的意思；viddho 是“被刺中”，不是“深受触动”。整句的结构是“那时（在家时）被刺中，如今已达漏尽”。
- **建议**：改为“那时我被贪欲之刺扎中，如今已达到了诸漏的灭尽。”

## §3113 句 162-3113-2-11
- **问题**：nissaya 异读，仅作记录。nissaya 读作 sattā（众生），释作“对众生修习了慈等”，和正文的 satthā（导师）不同。
- **建议**：保留现译“我已侍奉了导师”。

## §3114 句 162-3114-2-8
- **问题**：用词偏窄。nissaya：`ဘဝနေတ္တိ= ဘဝသုံးပါးသို့ ဆောင်တတ်သော တဏှာဟူသော ကြိုး`（引向三有的渴爱之绳）。bhava 指“有、存在”，译成“再生”范围窄了。
- **建议**：改为“引向诸有的绳索已经根除”。

## §3121 句 162-3121-2-23（§3128 / 3135 / 3142 同步改）
- **问题**：因果关系颠倒，还有添字。manasi karoto 是现在分词与格，nissaya：`မနသိကရောတော= … နှလုံးသွင်းခြင်းရှိသောသူအား`（对于作意可爱之相的人），`သတိ … လွတ်ခြင်းသည် ဟောတိ`（正念会失去）。也就是：去作意可爱的相，才导致正念失去。现译“失去了正念，一心想着可爱的相”把顺序说反了，“一心”也是原文没有的。“了”的问题见跨段一致性。
- **建议**：改为“看见色后，若去注意可爱的相，正念就会失去；”。声、香、味三段照此同改。

## §3122 句 162-3122-2-8（§3129 / 3136 / 3143 同步改）
- **问题**：直译生硬。ajjhossa tiṭṭhati，nissaya 释作“把它当作乐吞下去（紧紧执取）而停住”。“停住在那里”读起来像翻译腔。
- **建议**：改为“他以染着的心去感受，并且紧紧执取着它不放。”

## §3124 句 162-3124-2-11（§3131 / 3138 同步改）
- **问题**：添加了成分。tassa，nissaya 释作 `ပုဂ္ဂိုလ်အား`（对那个人），原文没有“心中”。
- **建议**：改为“由色而生的种种感受，在他身上不断增长；”。

## §3126 句 162-3126-2-15（§3133 / 3140 同步改）
- **问题**：主宾关系与 nissaya 不同，请 revise 时决定取舍。nissaya：`အာစိနတော= … ဘဝါဘိသင်္ခါရကို ပွါးစေသော သူအား`（积聚有行的人），`ဒုက္ခံ= ဆင်းရဲသည်。ပဝတ္တတိ`（痛苦作主格，补出“生起”），`နိဗ္ဗာနံ … အာရကာ … ဝုစ္စတိ`（说涅槃离他很远）。按 nissaya，dukkhaṃ 不是 ācinato 的宾语，vuccati 的主语是涅槃而不是这个人。现译“积聚痛苦的人”是另一种通行读法，但“被说成是远离涅槃的”把主语换成了人。
- **建议**：至少改为“这样积聚痛苦的人，可以说涅槃离他很远。”如果完全依照 nissaya，可改为“这样积聚（业行）的人，痛苦就会生起，可以说涅槃离他很远。”

## §3142 句 162-3142-2-13
- **问题**：原文用词疑问，仅作记录。“bhotvā”是 VRI 的写法，nissaya 释作 `လျက်၍`（舔、尝）。译“尝到”没有问题。
- **建议**：除了 §3121 那组的同步修改，这一句不用另外改。
