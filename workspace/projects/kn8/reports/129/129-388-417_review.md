# Review — 129:388-417（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照

- §398 **比丘走到尸林**：父层 162-1507 译“我这个比丘走到尸林……”。黑体引的是 bhikkhu sivathikaṃ gantvā，“我这个”是父层补出的成分，不在引文范围内。“比丘走到尸林”与父层逐字相同，✅
- §398 **罗阇达多**：与父层篇题“罗阇达多长老偈”一致，✅
- §392–393 的黑体词（**为了谋生** / **受了具足戒后** / **从那以后我获得了信心** / **我以坚固的精进努力** / **任凭** / **让它坏掉吧** / **这个身体** / **让肌肉散落吧** / **让我的双腿连同两个膝关节一起掉落吧**）引自穆迪多长老偈 311–313。这几首偈不在本次提供的父层范围（162:1493 起）内，**无法逐字核对**，需要对照 162 中穆迪多偈的定稿另行核查。
- §389–390、§407–417 是重引的偈文，与父层译文一致（父层的异读夹注在本层原文中本来就没有，不带是对的）。

## 跨段一致性

- **人称**：§392 各条解释里，第一人称动词（pabbajiṃ / paṭilabhiṃ / parakkamiṃ）一律译作“我”。§393-2-15 的 yathā pana parakkamiṃ 却译成“他是怎样努力的”。这里 parakkamiṃ 是承接偈文的第一人称，建议统一为“为了说明我是怎样努力的”。
- **劫数的说法**：§398 译“距今第十四劫”，§402 译“从现在算起第三十一劫”。两处数字不同是原文本身的差异，应保留；但说法建议统一为“距今第……劫”。
- **buddha / paccekabuddha**：§398 译“辟支佛”。§400 偈中的 buddhaṃ，nissaya 释为 ပစ္စေကဗုဒ္ဓါ（辟支佛），译文却作“佛陀”。现代读者容易把“佛陀”理解为乔达摩佛，建议改为“那位佛”，或与 §398 呼应。

## §392 句 129-392-9-24
- **问题**：词法 — ettha 的 nissaya 释为 `ဧတ္ထ= ဤသာသနာတော်၌`（在这个教法中）。译文作“在这里”，所指不清。
- **建议**：改为“在这个教法里出家后……”。

## §392 句 129-392-81-105
- **问题**：词法 — saccapaṭivedhāya 的 nissaya 是 `သစ္စါလေးပါးတရားကိုထိုးထွင်း၍သိခြင်းငှါ`（为了通达四谛）。译文“通达真谛”所指偏泛。
- **建议**：改为“为了不久就通达四谛”。
- **附记**：nissaya 的词头写作 အာရဒ္ဓဝီရိယော（āraddhavīriyo），与 pali 的 daḷhavīriyo 不同，属于底本异读，仅作记录。

## §393 句 129-393-16-23
- **问题**：误译 — ekaṃsato 意为“一定、断然”，译成“毫无保留地”语义有偏差。nissaya 只释了 `ယထာကာမံ= အလိုရှိတိုင်း`（随意）和 `ဝါ= တနည်းကား`（或者说），ekaṃsato 应按“一定”理解。
- **建议**：“**任凭**，是说随它怎样，或者是‘一定’的意思：**让它坏掉吧**。”

## §393 句 129-393-24-39
- **问题**：用词 — pūtikāyo 的 nissaya 是 `ကိုယ်ခန္ဓာအကောင်ပုပ်`（腐臭的躯体）。“腐朽”偏指老旧朽坏，没有译出“腐臭”的意思。
- **建议**：改为“我这个腐臭的身体”。

## §393 句 129-393-40-55
- **问题**：词义 — maṃsapesī 的 nissaya 是 `သားတစ်တုန်း`（肉块），译作“肌肉”偏于解剖学词汇。
- **建议**：倾向译为“肉块”。但这个黑体词必须跟随父层穆迪多偈的定稿：父层若作“肌肉”就保持不动，改动应在父层统稿时一并进行。

## §393 句 129-393-56-74
- **问题**：句法误读（必改）— nissaya 为 `ဥဘောဇင်္ဃာယောစ= မြင်းခေါင်းနှစ်ဘက်တို့သည် လည်းကောင်း`（两条小腿，以及）、`ဦရူစ= ပေါင်တို့သည်လည်းကောင်း`（大腿，也）。jaṅghāyo 与 satthiyo 是**并列主语**，不是同位语。译文“两条腿——也就是大腿”把两者当成了同一个东西。另外，ūrubandhato 的 nissaya 是 `ဖွဲ့ရာခြဉ်စပ်ဆက်ရာအရပ်မှ`（从连接处）。
- **建议**：“是说让我的两条小腿和大腿，连同两个膝关节一起，从大腿的连接处断开，掉落在地上。”

## §398 句 129-398-16-53
- **问题 1**：语体（必改）— “作为出离轮回**之**依靠的福德”中的“之”是文言虚词。另外，upanissaya 的 nissaya 是 `အားကြီးသော အကြောင်း`（强有力的因），“依靠”译得偏弱。
- **建议 1**：改为“积累能成为出离轮回的有力助缘的福德”。
- **问题 2**：词法 — vanantaṃ 的 nissaya 是 `တောအတွင်းသို့`（到森林里面），译文作“走到森林边上”，方位相反。
- **建议 2**：改为“走进森林”。
- **问题 3**：用词 — katādhikāro 的 nissaya 是 `ကဲလွန်သောကုသိုလ်အထူး ကျေးဇူးရှိသည်`（曾经做过殊胜的善业）。“立下了宿愿”只说到发愿，没有说到所行的善业。
- **建议 3**：改为“在过去诸佛座下做过殊胜的善业”。

## §398 句 129-398-54-64
- **问题**：措辞 — “到了这一尊佛出世的时代”读起来生硬。nissaya 是 `ငါတို့ဂေါတမမြတ်စွာဘုရားပွင့်တော်မူသောအခါ၌`（我们的乔达摩佛出世的时候）。
- **建议**：改为“到了现今这位佛陀出世的时代”。

## §399 句 129-399-55-64
- **问题**：词义 — ocarakamanusse 的 nissaya 是 `ခိုးသူယောက်ျားတို့`（偷偷行事的人），侧重“潜行”。译作“密探”偏重刺探情报，与下文夜里潜入杀人的情节不太贴合。
- **建议**：改为“派出了暗中行事的人”。

## §399 句 129-399-78-131
- **问题**：格位 — tattha 的 nissaya 是 `ထိုသူ၌`（对那个人），表示欲贪的对象，不是处所。译文作“在那里生起了欲贪”。
- **建议**：改为“对她生起了欲贪”。

## §402 句 129-402-2-11
- **问题**：原文 / nissaya 疑问 — pali 作 ekatiṃse（第三十一劫），nissaya 这一行却作 `စတုဒ္ဒသေကပ္ပေ`（第十四劫），并且混入了下一句的 `တဿကမ္မဿ= …ဝါဟသာ`。看起来 nissaya 是从 §398 的散文误抄过来的。译文按 pali 译作“第三十一劫”是对的，不改，仅作记录。

## §411 句 129-411-2-8
- **问题**：存疑 — nissaya 把 savatī 释为 `ကိုးပါးသောဒွါရတို့မှမစင်မကြယ်ရွံဘွယ်ရာယိုစီး၏`（尸体从九孔流出污秽），主语是尸体；译文“随它流去”的主语是“我”。两种理解冲突。本句与父层 162-1511 逐字相同，**不要在本层单独改动**，应在 harmonize 时连同父层一起定夺。

## §413 句 129-413-2-10
- **问题**：存疑 — oraṃ odanapākamhā 的 nissaya 是 `ထမင်းချက်သောကာလမှ…အယုတ်ဖြစ်သော ကာလပတ်လုံး`（不到煮一顿饭的时间），说的是时间短，不是实际在煮饭。译文“在饭煮好之前”容易被读成真的在煮饭。本句同样与父层 162-1513 一致，建议在 harmonize 时连同父层考虑改为“不到煮一顿饭的工夫，我就离开了那个地方”。
