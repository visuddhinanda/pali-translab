# Review — 129:5371-5419（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次只做 nissaya 复核）

## 被解释词与父层对照

- 本 chunk 没有引自父层的黑体被解释词。唯一的黑体 **apadāne** 是出处书名，不是被解释词。
- 5418 引了“kataṃ buddhassa sāsanaṃ”，译作“已经完成了佛陀的教导”，与父层 162-3914 的译文逐字相同 ✅
- ⚠ 父层对照取的是 book 162 §3913–3920（阿难长老偈、三十偈集终、摄颂），本 chunk 注的却是大迦叶长老偈的缘起，两者对不上。建议核查 layers 映射是否错位。这一点不影响本次审出的问题。

## 跨段一致性

- **buddhānaṃ**：§5372 句 98-130 译“诸佛”，泛指所有佛，没有问题。§5373 句 51-86 同一句里先译“诸佛穿用过的衣服”，后译“在佛陀身边”。这里指的是眼前这位佛的衣服，是尊称复数（nissaya 两处都是 `မြတ်စွာဘုရားတို့၏`）→ 建议本句统一为“佛陀”。
- **kūṭāgāra / niyyūha**：§5392、§5396 的 kūṭāgāra 译“尖顶楼阁”，§5394 的 niyyūha 译“尖楼”。两个词不同，译名却几乎一样，读者会以为是同一种建筑。nissaya：`နိယျူဟာ= နန်းဦးစန္နဆောင်` 指宫殿顶部的阁楼，不同于 `ကူဋာဂါရ` → 建议 niyyūha 改译“角楼”或“顶阁”。
- **indalaṭṭhi**：§5387、§5405 都译“因陀罗幢”，两处一致。但 nissaya §5405 释为 `ဣန္ဒလဋ္ဌီ= လျှပ်စစ်သည်`（闪电），“像闪电那样亮起”与“照亮四方”“高耸”的比喻也更贴切 → 建议两处一起改为“闪电”。如果保留“因陀罗幢”，要压低 confidence。
- **由旬单位**：§5406、§5408 都省略了单位，nissaya 两处都补出 `ယူဇနာ`（由旬）→ 建议统一补“由旬”。
- **“以”字句**：§5371（以三十二大人相庄严／以七种大人相装饰）、§5371 句 101-106（以三项教诫）、§5384、§5393 多处用“以…”，§5371 还把“庄严”当动词用，书面气偏重。全段语体不太统一，建议改成“用…”“有…装饰”。

## §5371 句 129-5371-76-89

- **问题**：句法误读。jānatā 是具格分词，与 tayā 同格，意思是“明知如来功德如此之大的你”。整个分句修饰“你所行的顶礼”，是这句的主语部分，不是并列的一句话。译文“你知道……，你对我行的顶礼，却连……”拆成两句，又加了原文没有的转折“却”，因果关系就反了。另外 nissaya `မယှံ= ငါဘုရား၏` 是属格，接下文 `လောမမ္ပိ`，意思是“我的汗毛”，不是“对我行的”。
- **建议**：“你明知如来的功德如此伟大，你所行的这种顶礼，连我的一根汗毛也动不了。”另记：nissaya 读作 `ဇာန= သိလေလော`（命令式 jāna，“要知道”），与本文 jānatā 有异读，见文末。

## §5372 句 129-5372-98-130

- **问题**：漏了 hi。nissaya `ဟိ= ထင်စွာပြဦးအံ့` 表示这一句在解释上一句的反问（“你能穿得住吗？”），译文没有译出这层因果。
- **建议**：句首补“因为”：“因为在我取得这件粪扫衣的那一天……”

## §5374–5375 句 129-5374-2-9 / 129-5375-2-8

- **问题**：补出成分。§5374 是属格（nissaya `ဘဂဝတော= …၏`），§5375 的 nissaya 补出 `ကာလေ= လက်ထက်တော်၌`，意思是“在莲华上世尊的时代”。又补出 `သရီရံ`，供养的对象是导师的遗体，不是导师本人。译文把 §5374 译成独立的称呼语，属格关系丢了；“供养导师”与“般涅槃之后”在语义上也有冲突。
- **建议**：§5374“在莲华上世尊——世间最尊、如如不动者——的时代，”；§5375“这位世间怙主般涅槃之后，人们供养导师的遗体。”

## §5377 句 129-5377-2-8

- **问题**：取义偏了。saṃvega 的 nissaya 是 `ပူဇော်လိုလား လှုပ်ရှားခြင်း`（想要供养而内心激动），不是恐惧。“悚惧”会让读者以为是害怕。
- **建议**：“在他们心中激动、急切想要供养的时候，我心中也生起了喜悦。”

## §5380–5381 句 129-5380-2-12 / 129-5381-2-7

- **问题**：引语归属不清。§5381 的 nissaya 结尾补出 `ဣတိ မန္တေတွာ`（这样商量之后），说明“我们要积累功德”是亲友们一起商定的话，并接到 §5382 的“精心建造”。译文用“这让我更加欢喜：‘……’”，读起来像是“我”心里的话。
- **建议**：§5380“他们答应说：‘好！’这让我更加欢喜。”§5381“‘我们要在世间怙主佛陀那里积累功德。’（大家这样商定。）”或在 §5382 开头补“商定之后”。

## §5382–5383 句 129-5382-2-9 / 129-5383-2-6

- **问题**：一是词义：agghiya 的 nissaya 是 `ရတနာစေတီအိမ်`（宝塔殿、宝龛），是一座建筑，不是“供物”。二是句法：vimānaṃ 的 nissaya 是 `ဗိမာန်သဖွယ်ဖြစ်သော`（像宫殿一样的），在句中修饰 agghiya，是比况，不是判断。译文“是一座耸入天空的宫殿”把它当成了谓语。
- **建议**：§5382“我们精心建造了一座宝塔殿，高一百肘，”；§5383“宽一百五十肘，像天宫一样耸入天空。”

## §5386 句 129-5386-2-10

- **问题**：词义。kiṃsuka 的 nissaya 是 `ပင်လုံးကျွတ်ပွင့်သော…သစ်ပင်`（满树开花的树），比的是整棵树，不是一朵花。
- **建议**：“像开满花的紧叔迦树”。

## §5389 句 129-5389-2-7

- **问题**：误读，必改。pubbakamma 的 nissaya 是 `ရှေးကပြုခဲ့ဘူးသော ကုသိုလ်ကံ`，指这一生早先做的善业，即前面讲的造塔供养，不是“前世”的业。nissaya 还补出了时间 `မရဏကာလေ`（临终时）。
- **建议**：“临终时忆念先前所做的善业，我往生到了三十三天。”

## §5400 句 129-5400-2-9

- **问题**：补出成分。khattiya 的 nissaya 是 `စကြာမင်း`（转轮王），而不只是一般的刹帝利。这与 §5401 的“以四海为界”相呼应。
- **建议**：保留“刹帝利”也可以，但 §5401 要译出统治四海的含义，见下条。

## §5401 句 129-5401-2-8

- **问题**：误读，必改。āvasiṃ 的 nissaya 是 `စိုးအုပ်ပြီ`（统治了），不是“住在”。cāturanto 的 nissaya 是 `သမုဒ္ဒရာလေးဖြာအဆုံးရှိသော`（以四海为边界的），vijitāvī 的 nissaya 是 `အောင်အပ်ပြီးသော ရန်ရှိသော`（已经战胜敌人的），两者都是修饰“我”的形容语。译文把它们译成了并列的谓语。
- **建议**：“我是以四海为界、战胜了一切敌人的君主，统治着大地。”

## §5403 句 129-5403-2-6

- **问题**：词义。sakakammābhiraddha 的 nissaya 是 `မိမိအမှု၌အားထုတ်အပ်သော`（致力于自己本分的），与译文“因自己的业而欢喜”意思不同。“业”还容易被读成业报的业。
- **建议**：“是致力于自己本分的大力转轮王”。拿不准就压低 confidence。

## §5406 句 129-5406-2-10

- **问题**：漏了 nissaya 补出的单位 `ယူဇနာ`（由旬）。
- **建议**：“长二十四由旬，宽十二由旬，”

## §5407 句 129-5407-2-7

- **问题**：专名有异读。nissaya 读作 `ရမ္မက`（Rammaka），本文是 Rammaṇa，同一异读在 §5413 也出现。译文按本文译“兰玛那”，§5407 和 §5413 两处一致，可以保留，但有异读要记下。
- **建议**：不改，压低 confidence。

## §5408 句 129-5408-2-9

- **问题**：同 §5406，漏了单位。
- **建议**：“长五百由旬，宽是它的一半；”

## §5411 句 129-5411-2-8

- **问题**：漏译，必改。laṅkataṃ（=alaṅkataṃ，装饰华美的）没有译出来。nissaya 指明 ākiṇṇaṃ 的主语是 `လင်္ကတံ= တန်ဆာဆင်အပ်သော ပြည်သည်`（那座装饰华美的城市），意思是城市像针筒一样拥挤，不是针挤满了针筒。译文“挤得满满当当”接在针后面，主语跟着错了。
- **建议**：“互相碰撞；装饰华美的城市也这样拥挤。”另记：nissaya 把 paṇṇavīsati 读作 āpaṇa（`ဝင်နေရောင်းဝယ်သောအိမ်ဈေး`，店铺），与本文“二十五”不同，见文末。

## §5419 句 129-5419-70-78

- **问题**：补出成分。pakāsento 是现在分词，这句话的主要动词在下一段，不在本句。译文自己补了“说了以下偈颂”，下一段如果也译出“说”，就会重复。
- **建议**：改为“……同时显示自己的修行，（说了以下偈颂）——”这样的承接式；或者去掉“说了”，由下一段的动词承接。下一段翻译时核对，避免重复。
