# Review — 129:356-387（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（本次为 nissaya 词法复核）

## 父层被解释词核对

- 偈颂复录 §357–§362、§380–§387：与父层 162:1475–1492 译文逐字相同 ✅
- §365 被解释词：「在那里，有谁会不欢喜呢……乃至……就在我的洞窟后面」及句内黑体「我／后面／河岸／那里／蒲桃树／在那里／谁／不欢喜／呢」：与父层一致 ✅
- §366 被解释词：「那些已完全摆脱了交配狂热的成群蛙类」「青蛙们」「低沉地」「鸣叫着」「今天不是离开山间河流的时候」「安稳」「阿迦羯罗尼」「吉祥」：与父层一致 ✅
- §370「出家」：与父层 1485 一致 ✅
- §363–§364 的被解释词（yadā / balākā / sucipaṇḍaracchadā / kāḷassa meghassa bhayena tajjitā / palehiti / ālaya / ālayesinī / tadā nadī ajakaraṇī rameti maṃ / suvisuddhapaṇḍarā / pariyesati / leṇa / aleṇadassinī）引自第 307–308 偈，不在本次提供的父层范围内，**未核对**。
- **父层问题（需上报父层，本层不改）**：162:1478 把 *Tāmatamadasaṅghasuppahīnā* 译成「那些已完全摆脱了交配狂热的成群蛙类」。本层 §366 义注把这个词拆成 *tā* + *amatamada-saṅgha* + *suppahīnā*，意思是「那些（雌蛙）已远离了蛇群」。nissaya 也是这样拆的：`အမတမတသံဃသုပ္ပဟိတာ= အမတမည်သောစပါးကြီးမြွေတို့၏ အပေါင်းမှ ကောင်းမွန်လွန်စွာပယ်ခွါ…`，也就是「从名为 amata 的大蟒蛇群中远远离开」。「群」（saṅgha）指的是蛇群，不是蛙群；「交配狂热」在注文里没有依据。父层译法与本层注文冲突，读者会看不出 §366 注的是什么。按硬约束，本层黑体只能沿用父层，建议回到父层重审 1478（同时 1479 *panādayanti* 的宾语 *taṃ ṭhānaṃ*，见下文 §366 句 24-36）。

## 跨段一致性

- *mañca*：§370、§372、§375 译「床」，§374 *mañcaka*、§376 *mañcadāna* 译「床座」。建议统一为「床」（「布施床座」改为「布施床」或「供养床」）。
- *dadāti / dāna*：§370、§372、§375 译「供养」，§374、§376 译「布施」。同一件事前后用词不同，建议统一为「供养」。
- *leṇa*：§364 译「住处」（鸟的栖身处），§365 译「洞窟」（长老的居所）。两处语境不同，可以接受，不必统一。

## §363 句 129-363-2-7
- **问题**：格与句法 — *yasmiṃ kāle* 是关系代词处格，nissaya 作 `ယသ္မိံကာလေ= အကြင်အခါ၌`（「在……的那个时候」），与后文 *tadā*（那时）相呼应。译「在某个时候」就成了不定指，关系结构丢了。
- **建议**：「**当**：是指在……的时候。」

## §363 句 129-363-16-29
- **问题 1**：句法 — *kāḷassa … gajjato pāvussakameghassa* 是属格，修饰 *vuṭṭhibhayena*（对降雨的恐惧，具格）。译文把它拆成「雨季的云……乌黑……雷声隆隆」几个独立分句，修饰关系断了。
- **问题 2**：词义 — *nibbijjitā* 在这里指鸟被逼迫、受困扰，nissaya 作 `ပီဠေတွာ`（受逼迫）。译「心生厌离」会让读者联想到法义上的厌离（nibbidā），不合语境。
- **建议**：「它们被因饱含雨水而乌黑、像安阇那山一样、雷声隆隆的雨季之云所带来的降雨恐惧所逼迫、惊吓。」句子过长的话，可以先描述云，再用「对这种云下雨的恐惧」承接。

## §363 句 129-363-49-71
- **问题**：漏译 — *utu-padesa-visesa-kittana*，nissaya 作 `ဥတုအထူးအရပ်အထူး`，意思是「季节与地方的特色」。译文只有「季节特色」，漏了 *padesa*（地方）。
- **建议**：「借着描述季节和地方的特色」。

## §365 句 129-365-2-40
- **问题 1**：格 — *āpagākūlaṃ* 是 *sobhentiyo* 的宾格宾语（装点河岸），与父层「装点着河岸」一致。译文改成「在……**河岸**上……装点着」，宾语变成了处所。
- **问题 2**：格与风格 — *sabbaṃ ramentiyeva*，*sabbaṃ* 是宾格，nissaya 作 `ရမေန္တိယေဝ= မွေ့လျော်စေကုန်သည်သာလျှင်`（必定使之欢喜）。「被它们所悦」是被动加文言「所」，句子生硬。
- **问题 3**：风格 — 「此处彼处」用了文言的「此／彼」。
- **建议**：「……长在阿迦羯罗尼河两岸、枝条常年被果实压弯、叶荫浓密的**蒲桃树**，**那里**、**那里**，也就是到处，装点着**河岸**……它们会令**谁** **不欢喜** **呢**？它们一定会令一切众生欢喜。」

## §366 句 129-366-2-23
- **问题**：原文与 nissaya 不一致（记录，不改）— pali 作 *amataṃ vuccati agadaṃ, tena majjantīti amatamadā*（解毒药叫作 amata，为它而迷醉的就是 amatamada）。nissaya 作 `အဇဂရံ= …အမတံ…ဝုစ္စတိ … နမရန္ထိ`（大蟒叫作 amata，因为它们不死），依据的是另一种读法。译文依 pali 译出是对的。另外，句末「就是这个意思」在原文里没有对应的 *ti attho*，可以删掉。
- **建议**：保留现译，删去「就是这个意思」。底本异读记入 known-issues。

## §366 句 129-366-24-36
- **问题 1**：格 — *mandavatī* 由 *saravatiyo*（有声音的，阴性复数主格）解释，nissaya 作 `ညှင်းညှင်းသောအသံရှိကုန်သည်ဖြစ်၍`（是有柔和声音者），是修饰主语的形容词，不是副词。黑体必须沿用父层的「低沉地」，但释文「就是发出叫声地」既不通顺，也不合语法。
- **问题 2**：宾语 — *panādayanti* 的宾语 *taṃ ṭhānaṃ* 译文译出了，没有问题。
- **建议**：「**低沉地**，是说它们有（低柔的）叫声」。

## §366 句 129-366-37-56
- **问题**：句法 — nissaya 作 `အဇကရဏီနဒီ= …သည်`（主格）/ `ခေမာ= ဘေးကင်း၏`（谓语），*khemā* 是谓语。译文写成「尤其是阿迦羯罗尼河……所以是安稳的阿迦羯罗尼河」，把它当成定语，主语还重复了一遍。
- **建议**：「……而**阿迦羯罗尼**河尤其**安稳**，因为那里没有凶猛的鱼、鳄鱼等。」

## §366 句 129-366-60-70
- **问题**：强调词漏译 — *tattheva*，nissaya 作 `ထိုလိုဏ်ရှိရာအရပ်၌သာလျှင်`（唯独在那里）。「就喜爱在那里」没有表达出 *eva* 的「唯独」义。
- **建议**：「所以我的心只喜爱那里——这是长老的意思。」

## §367 句 129-367-11-17
- **问题**：句法与措辞 — *idameva* 指这些偈本身，nissaya 作 `ဣမမေဝ= ဤဂါထာသည်ပင်လျှင်`。*aññābyākaraṇa* 译「宣说证悟的表白」，「宣说」与「表白」重复。nissaya 释 *aññaṃ* 为 `အရဟတ္တဖိုလ်`（阿罗汉果）。
- **建议**：「这些偈表明了长老乐于空屋独处，这本身也就是长老对证悟（aññā，即阿罗汉果）的宣告。」

## §370 句 129-370-151-169
- **问题**：重复与漏译 — 「他立誓说……他发了这样的誓愿」把立誓说了两遍；*tiādinā*（以……等语）的「等」也没有译出。
- **建议**：「他以“不证得阿罗汉果，我就不走出这间住室”等话立下誓言，精进修观，证得了阿罗汉果。」

## §373 句 129-373-2-9
- **问题**：措辞（轻）— *yāna*，nissaya 作 `ယာဉ်`（车乘、坐骑）。「象乘／马乘／天乘」容易被一般读者误解为教义上的「乘」。
- **建议**：可考虑改为「象车、马车与天车」；如果为了与譬喻经传统译法一致而保留现译，也可以。
