## 跨段一致性

偈颂引文以 801 偈（§3567 / 父层 3145）为界，前后是两套译法。这个漂移是从父层原样带进来的：

- **manasi karoto**：§3543/3550/3557/3564 译「一心想着可爱的相」，§3571/3578 译「去作意可爱的相」。
  nissaya 解作「以不如理的方式作意，认为它美好」（`မသင့်သော နှလုံးသွင်းခြင်း`），带术语色彩。
  → 建议统一。「去作意」更贴合 nissaya；「一心想着」更白话。取哪个由父层定，两种不能并存。
- **sāratta-**：「染着」（§3544/3551/3558/3565）与「染著」（§3572/3579），以及「不染著」（§3585 起）混用。→ 统一用字，建议都用「着」。
- **ajjhossa tiṭṭhati**：§3544–3565 译「执取它而停住在那里」，§3572/3579 译「贪著它而停留其中」；否定式 §3586 等译「不贪著它而停留其中」。
  → 肯定式与否定式应当用同一组词，建议统一为「贪着它而……」一组（否定式的歧义见下文 §3586）。
- **upahaññati**：§3547/3554/3561 译「使他的心受到伤害」，§3568/3575/3582 译「他的心因此受到损害」。→ 统一为一种，「伤害」与「损害」二选一。
- **ārā nibbāna vuccati**：§3548/3555/3562 译「被说成是远离涅槃的」，§3569/3576/3583 译「被说成离涅槃很远」。
  后者与 santike 句「被说成离涅槃很近」（§3590 等）正好成对。→ 建议统一为「离涅槃很远」。
- **evaṃ**：「这样积聚痛苦的人」（§3548–3562）与「像这样积聚痛苦的人」（§3569 起）不一致。→ 统一，并与 apacinato 句「像这样减损痛苦的人」保持一致。
- **所缘名称**：794–805 偈作「声／香／味」，806–812 偈作「声音／气味／滋味」。
  同一偈组内也混用：§3567「由味而生」，§3606 却是「尝到滋味」。动词也不统一：§3550「听到声」，§3592「听见声音」。
  → 统一为一套。建议都用单字「色声香味触法」，与「由声而生」等复合说法相配。
- **句末标点**：§3546「种种感受，在他心中增长；」，§3567「种种感受在他心中增长，」。断句方式和行尾标点前后不一，建议统一。

## §3541 句 129-3541-2-12
- **问题**：词法 — `…tiādikā` nissaya 作「以……开头的**偈颂**」（`ဂါထာတို့သည်`），译文作「等句」，与后面的「偈颂」各指一物，容易让读者以为只是几句话。
- **建议**：改为「以**看见色时失去了正念**开头的偈颂，是尊者摩罗迦子的偈颂」，或「**看见色时失去了正念**等偈，是……」。黑体部分保持不动。

## §3541 句 129-3541-208-223
- **问题**：词法 — `na tattha`：nissaya 解为「在那些色等所缘上，（贪等）不生起」（`တတ္ထ= ထိုရူပါရုံစသည်၌။ နဟောတိ= တပ်ခြင်းစသည်မဖြစ်`），是处格「在其中」。译文「不会停留在那里」补出了「停留」这一动作，原文没有。
- **建议**：可改为「你就不在其中」，这样也与下句的「既不在这里……」呼应。属于次要问题。

## §3541 句 129-3541-224-257
- **问题**：词法 — nissaya 把 `ubhayamantarena` 释为「由于两种原因」（`နှစ်ပါးသော အကြောင်းကြောင့်`），把 `idha` 释为「非现在」，与通行读法不同。
- **建议**：译文「也不在两者之间」是通行读法，**保留不改**。这里只记录 nissaya 的分歧。

## §3548 / 3555 / 3562 / 3569 / 3576 / 3583（Evamācinato dukkhaṃ）
- **问题**：句法分歧 — nissaya 认为 `ācinato` 积聚的对象是「有行（`ဘဝါဘိသင်္ခါရ`）」，`dukkhaṃ` 则是隐含动词 `pavattati` 的主语（「对这样积聚的人，苦就生起」）。译文按通行读法，把 dukkhaṃ 当作 ācinato 的宾语（「积聚痛苦的人」）。
- **建议**：通行读法语法上成立，而且父层已经定稿，**可以不改**。在报告里记下这处分歧即可。

## §3568 / 3575 / 3582（Abhijjhā ca vihesā ca, cittamassūpahaññati）
- **问题**：句法 — nissaya 把 abhijjhā 和 vihesā 都作为 `upahaññati` 的施动者：贪求与恼害**折磨他的心**（`ညှဉ်းဆဲနှိပ်စက်၏`）。译文「贪求与恼害也随之增长」把它们挂到了上一行的 vaḍḍhanti，「也随之增长」是增译，nissaya 不支持。§3547 等前半组「贪求和恼害，使他的心受到伤害」的读法是对的。
- **建议**：先在父层 162-3146/3153/3160 改为与前半组同构，再同步到本层。这一处属于必改。

## §3586 / 3593 / 3600 / 3607（tañca nājjhossa tiṭṭhati）
- **问题**：句法 — nissaya：不以爱、慢、见去吞取它（`မသက်မမျိုမူ၍`），而住立（`တိဋ္ဌတိ= တည်၏`）。否定只管 ajjhossa，tiṭṭhati 是肯定的。
  译文「不贪著它而停留其中」可以读成「不（贪着它而停留其中）」，也可以读成「不贪着它，（却）停留其中」。第二种读法把「停留在所缘里」变成了肯定，与原意正好相反。
- **建议**：改为「也不贪着它、不滞留其中」之类没有歧义的说法。需要先改父层 162-3164/3171/3178/3185。

## §3588 / 3595 / 3602（Yathāssa … sevato cāpi vedanaṃ）
- **问题 1**：词法 — `cāpi` nissaya 作「也」（`အားလည်း`），表示并列。译文用「乃至」，这个词在汉译佛典里表示省略或范围，会误导读者。
  → 改为「以及」或「也」。
- **问题 2**：句法 — `yathā` nissaya 作「正如……那样」，与 evaṃ 构成方式对应：他这样观照时，贪等不生起；领受感受时也是如此。译文「当……的时候」把方式关系改成了时间关系。
- **问题 3**：nissaya 把 `passato` 释为「以无常等相观照」（`အနိစ္စအစရှိသော အခြင်းအရာအားဖြင့် ရှု`），是观照，不是一般的「看见」。
- **建议**：三处都在父层 162-3166/3173/3180，先改父层再同步。最低限度要改「乃至」。

## §3589 / 3596 / 3603（Khīyati nopacīyati）
- **问题**：词法 — nissaya 认为 khīyati 的主语是「一切烦恼轮（`ကိလေသာဝဋ်`）」。译文补成「痛苦」，那是取下一行 dukkhaṃ 的通行读法。
- **建议**：通行读法可以保留。这里记录分歧，不列为必改。
