## 跨段一致性

- **ajjhottharati**：§1290（53-81）译“淹没”，§1291（35-53，anajjhottharaṇīyaṃ）也译“淹没”，但 §1291（12-34）译成“覆盖”（“一层又一层地覆盖你”）→ 建议统一为“淹没”，改为“一层又一层地淹没你”。
- **kāmaguṇa / kāmasukha**：§1293（2-17）kāmaguṇabandhanāni 译“欲乐的束缚”，§1293（32-54）kāmasukhānuyogo 也译“欲乐”，两个词混成了一个 → 依据 nissaya `ကာမဂုဏ်`，kāmaguṇa 建议改为“五欲的束缚”（或“欲功德的束缚”），“欲乐”只留给 kāmasukha。
- **saṅga 与 upādāna 混用“执”**：§1292（2-30）pañcavidhasaṅga 译“五种执着”，而 upādāna / ādiyati 在本层和父层都用“执取”。两者容易被读者看成同一个概念 → saṅga 建议改为“五种染着”（nissaya `ကပ်ငြိခြင်း` 意为黏着）。
- **āha 的主语**：全 chunk 都用“导师”指称 satthā，只有 §1294（2-25）写成“他说” → 建议改为“导师说”（nissaya `ဆိုတော်မူ၏` 是敬语，主语是佛）。
- **黑体相邻标记**：§1291（35-53）“**为自己****造**”、§1292（31-58）“**致力于****修行**”、§1294（26-53）“**证得****无上**”中，相邻的 `****` 在 markdown 里渲染异常 → 必改：分别合并为“**为自己造**”“**致力于修行**”，或在两个黑体之间加正常字符隔开。

## §1290 句 129-1290-37-45
- **问题**：句法 — niddābahulo 与 niddābhibhūto 是同位解释关系：nissaya 只给出 `နိဒ္ဒါဘိဘူတော= အိပ်ခြင်းဖြင့်နှိပ်စက်အပ်သည်` 来解释前一个词。译文“不要贪睡，不要被睡眠压倒”读起来像两条并列的禁令。
- **建议**：改为“**不要贪睡**，就是不要贪睡，也就是不要被睡眠压倒”。

## §1290 句 129-1290-53-81
- **问题**：格与句法 — taṃ / ananuyuñjantaṃ / alasaṃ / kusītaṃ 都是宾格，描写的是被征服的“你”；pamattabandhu 是主格，与 maccurājā 同位（nissaya `ပမတ္တဗန္ဓု= သေမင်းသည်`）。现译“你不致力于警醒，懒惰、懈怠，放逸者的亲族——死王”把宾格成分写成了主语，“放逸者的亲族”也容易被读成修饰“你”。
- **建议**：改为“意思是：放逸者的亲族——死王，不要像猎人**用陷阱**捕捉鹿或鸟那样，用老和病来征服那不致力于警醒、懒惰、懈怠的你，不要压倒你、淹没你。”

## §1291 句 129-1291-2-6
- **问题**：词法 — nissaya 说明这是拆词：`သေယျထာအဝိဟူ၍။ ဆေဒေါ= ဖြတ်အပ်၏`（拆作 seyyathā api），不是同义释义。现译“就是‘如同’”把拆词说明误译成了释义。
- **建议**：改为“**就像**，拆开来是 seyyathā 和 api 两个词。”

## §1291 句 129-1291-35-53
- **问题**：nissaya 把 sudīpaṃ 处写成 `ပုရိသံ`（人），这是 nissaya 自身的讹误；§1291（66-85）、§1292 也有同样的情况。译文按巴利原文译作“好洲渚”是正确的，不必依 nissaya 改。格式问题见“跨段一致性”。

## §1292 句 129-1292-31-58
- **问题**：句法 — daḷhañca karohi 的宾语承前省略，指 bhāvanaṃ（nissaya `ဒဠှံဝ= မြဲစွာသာလျှင်။ ကရောဟိ= ပြုလော`）。现译“并且要坚定地去做”没有交代做的是什么。
- **建议**：改为“并且要把修习修得坚固”。

## §1294 句 129-1294-26-53
- **问题**：语气 — 原文 parinibbāhisi 是将来时（“你将”），nissaya 却按命令式理解（`ပရိနိဗ္ဗာန်ပြုလေလော`）。译文按原文译作“你将般涅槃”，可以保留。分歧记录在此，仅供参考。

## §1295 句 129-1295-47-58
- **问题**：格与句法 — Māraṃ 是宾格，是 niddhunāhi 的宾语（nissaya `မာရံ= မာရ်ကို … နိဒ္ဓုနာဟိ= ဖျက်ဆီးလော`）。现译把“魔罗——”放在句首，成了悬空的话题；同时 tassa 指的是魔罗，译文“他的掌控”的指代不清楚。
- **建议**：改为“因为不落入魔罗的掌控，又不执取，所以说**什么都不执取**；**抖落**魔罗，就是驱散、摧毁魔罗。”

## §1295 句 129-1295-80-93
- **问题**：句法 — desanāya katāya 是独立处格，pāpetvā 是它的方式（nissaya `နိဗ္ဗာနံ … ပါပေတွာ … ဒေသနာယ ကတာယ`）。现译“把开示引向无余依涅槃，作了这番开示”把同一个动作说了两遍。
- **建议**：改为“导师这样以无余依涅槃作为归结，开示完毕之后，长老在开示结束时增长观智，证得了阿罗汉果。”

## §1298 句 129-1298-12-34
- **问题**：取义 — 对 katādhikāro，nissaya 的解释是 `ပြုခဲ့ဖူးသော ကုသိုလ်အထူး ကျေးဇူးရှိသည်`（曾经做过殊胜的善业），不是“立下誓愿”。
- **建议**：改为“他也是在过去诸佛座下行过殊胜的善业”。

## 父层译文疑点（本层引述必须与父层逐字相同，所以本层不改，交父层 revise / harmonize）
- **162-1854 vinamyate“低伏”**：verse nissaya 作 `လွှင့်ဘိသကဲ့သို့`（像被吹走一样）。本层义注 §1295（22-40）也把它解释为 vidhamiyyati viddhaṃsiyyati，即“被风吹散、摧毁”。父层“被风吹得低伏”只取了“弯曲”一义，与义注的解释不衔接。
- **162-1870 anupassano**：nissaya 作 `မြင်စေတတ်၏`，是使役义（使人看见），与同一颂的 viññāpano“令人了知”平行。父层“它以智慧观察诸有”没有译出使役义。
- **162-1864 visamūlaṃ āghātanaṃ**：nissaya 释为“苦的因”“业轮转与烦恼轮转”。父层“有毒的根、杀戮的根源”偏重字面，可酌情调整。
