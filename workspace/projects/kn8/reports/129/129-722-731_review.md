# Review — 129:722-731（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层对照

- 730 段的被解释词与父层 162:1620-1621 定稿译文逐字一致：
  - ogayhā → 浸入
  - aṭṭhaṅgikaṃ sotaṃ → 八支圣道之流
  - sabbapāpaṃ pavāhayiṃ → 冲洗掉一切恶
  - tisso vijjā … sāsanaṃ → 我证得了三明，佛陀的教导已经完成
- 723–724 偈文与父层逐字一致。
- 其余黑体词（pāto / yaṃ mayā / idha / pavāhemi / pure / evaṃdiṭṭhi / ahuṃ / dhammatthasahitaṃ padaṃ / tathaṃ / ninhātasabbapāpomhi / suddhassa / dāyādo / oraso 等）引自前几首偈，不在本次父层范围内，未核对。其中 §729 的 suddhassa 一处见下文，应以前偈父层译文为准对齐。

## 跨段一致性

- **pāpa**：
  - §723、§729、§730 都译「恶」，§726 的 ‘pāpapavāhana’ 译「冲洗罪恶」。
  - 建议改为「冲洗恶」或「冲洗恶业」，与偈文的「恶」统一。
- **pavāheti**：
  - §727 的 pavāhemi 译「冲走」，§723、§730 的 pavāhayiṃ / pavāhana 译「冲洗掉」「冲洗」。
  - 两处引自不同偈颂，但动词相同。nissaya 的释义也相同（ပဝါဟေမိ= မျှော၏「使漂走」，§730 的 pakkhālesiṃ 也释为 မျှောပြီ）。
  - 建议核对 §727 所引前偈的父层译法，二者至少在动词上保持一致。
- **sāsana**：
  - §727 的 satthu sāsanupagamana 译「导师的教法」，§724、§730（父层锁定）译「佛陀的教导」。
  - 非黑体处可以改，建议改为「归入导师的教导之前」，与锁定译法统一。
- **suddha**：
  - §729 的 suddho 译「清净的」（谓述长老），紧接着的 suddhassa 译「清净者」，也被当成谓述长老。
  - 这样读者会以为两个词说的是同一个人。实际上 suddhassa 修饰佛陀（见下 §729 句 28-35）。

## §726 句 129-726-26-58

- **问题**：格与句法。nissaya 的分析如下：
  - mahājanassa= လူများအပေါင်း၏（属格），修饰 pāpapavāhanaṃ，意思是「大众的恶在此被冲洗」。
  - 「公认」的施事另由 abhisammate= လူတို့သည်သမုတ်အပ်သော（被人们公认的）表达。
  - 译文「大众公认能‘冲洗罪恶’的伽耶渡口」把属格的大众误读成了「公认」的施事。
- **建议**：改为「被人们公认为能‘冲洗大众之恶’的伽耶渡口」。
- **问题**：补出成分。
  - nissaya 释 uttaraphaggunīnakkhatte 为「与北颇勒求那星宿相合的颇勒求那月满月日」，phaggunīmāsassa= တပေါင်းလ၏（属格）。
  - 译文「在颇勒求那月北颇勒求那星宿的时节」漏了属格关系，也没补出「满月日」，读起来像两个并列的时间。
- **建议**：改为「在颇勒求那月、月亮与北颇勒求那星宿相合的那一天」。

## §727 句 129-727-47-55

- **问题**：格式。「**曾是****持这种见解的人**」两段黑体紧贴，`****` 在常见 markdown 渲染器里不能可靠解析，可能显示为字面星号。
- **建议**：中间加分隔，或调整语序，例如「我**曾是**一个**持这种见解的人**」。

## §728 句 129-728-2-7

- **问题**：误译，必改。
  - vibhatti-alopa 中的 alopa 是「不省略」。nissaya 释为 ဝိဘတ်မကျေသောအားဖြင့်（以格尾不脱落的方式）。
  - 译文「是省去格尾的表述」把意思译反了。
- **建议**：改为「是保留格尾（不省略格尾）的表述」。
- **问题**：格式。「**合乎法与义的****言句**」两段黑体紧贴，问题同 §727。
- **建议**：合并为「**合乎法与义的言句**」，前提是与前偈父层译法一致。

## §728 句 129-728-8-66

- **问题**：主宾关系误读，必改。
  - nissaya：တေန= ထိုမြတ်စွာဘုရားသည်（具格施事 = 世尊），pakāsitaṃ= ဟောတော်မူအပ်သော（被宣说的）。
  - 意思是「由他（世尊）所阐明的」。译文「对**它**所阐明的苦等义理」把施事译成了「它」，指代成了前面的言教。
- **建议**：改为「对世尊所阐明的苦等义理」。
- **问题**：原文异读，只记录，不改。
  - nissaya 所据底本与 VRI 本文有出入：
    - yāthāvakaṃ 的释由，nissaya 作 pavattita-upāya-bhāvena vibhāvitato，本文作 pavattinivattiupāyabhāve byabhicārābhāvato。
    - paccavekkhisaṃ，nissaya 作 paccavekkhitaṃ（被动）。
    - patiavekkhiṃ，nissaya 作 paṭipattiṃ avekkhi。
  - 本文 ‘patiavekkhiṃ’ 疑为 ‘paccavekkhiṃ’ 之讹。
  - 译文按 VRI 本文译出，可以保留。

## §729 句 129-729-18-27

- **问题**：句法对应。nissaya 逐一分配三个理由与三个结果：
  - parisuddhakāyasamācāratāya → payato
  - parisuddhavacīsamācāratāya → suci
  - parisuddhamanosamācāratāya → suddho
  - 译文把三个理由并列放前、三个结果并列放后，读者看不出一一对应。
- **建议**：改为「由于身行清净，所以是**自制的**；由于语行清净，所以是**纯洁的**；由于意行清净，所以是**清净的**」。

## §729 句 129-729-28-35

- **问题**：格误读，必改。
  - nissaya：suddhassa= စင်ကြယ်တော်မူသော（「清净的」，修饰下文的 bhagavato= မြတ်စွာဘုရား၏，属格）。
  - savāsana…visuddhiyā 说明的是佛陀为何清净：连同习气一并断尽，只有佛陀如此。
  - 译文「所以是**清净者**」把它当成长老自己的谓语，主属关系错了。
- **建议**：改为「是**清净者**——由于连同习气在内的一切烦恼污垢都已清除而清净的佛陀世尊——的**继承者**」。
  - 黑体「清净者」须与前偈父层译法逐字对齐。
- **问题**：词义误读，必改。
  - nissaya：lokuttaradhammadāyassa= လောကုတ္တရာတည်းဟူသောတရားအမွေကို，「出世间法这份遗产」，作 ādiyanato（ခံယူတတ်သောကြောင့်，因领受）的宾语。
  - dāya 是「遗产、所赠之分」，不是「施予者」。
- **建议**：改为「因为领受了出世间法这份遗产，所以是他的**继承者**」。

## §729 句 129-729-36-42

- **问题**：复合词结构。
  - nissaya：ဒေသနာဉာဏ်လျှင်အကြောင်းရင်းရှိသော ရင်တော်၌လုံ့လ，即「以说法智为根源的胸膛之努力」。
  - desanāñāṇasamuṭṭhāna 修饰 urovāyāma，二者不是并列的两个原因。
  - 译文「由他的说法智所生起、由他胸膛的努力所生出」把它们拆成了并列。
- **建议**：改为「因为他有着由佛陀以说法智为源起的胸膛之努力所生出的高贵出身」。
- **补充**：oraso 是由 uro（胸）释出的。nissaya 释为 ရွှေရင်တော်နှစ်သားတော်စစ်（由胸所生的真子）。若前偈父层译作「亲生」，这里可以保留；但最好让读者看出「胸」与「亲生」的关联。
