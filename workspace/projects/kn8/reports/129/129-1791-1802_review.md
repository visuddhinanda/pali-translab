# Review — 129:1791-1802（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（1791、1792、1793、1795、1802 及 1794 句 12-12 无 nissaya，已略过）
> 父层对照：book=162 §2118–2127（第 493 偈）

## 父层被解释词核对

本 chunk 中引自第 493 偈的黑体词都与父层译文**逐字相同**：

| 黑体词 | 父层译文 | 本层译文 | 结果 |
|---|---|---|---|
| Yasmin / yasmiṃ（§1799 两处） | 依着这条道路 | **依着这条道路** | ✅ 一致 |
| Nivattate | 止息了 | **止息了** | ✅ 一致 |
| anantakaṃ | 无穷无尽的 | **无穷无尽的** | ✅ 一致 |
| Bhedā（…tiādinā） | 随着这个身体的崩坏 | **随着这个身体的崩坏** | ✅ 一致 |

§1796–1798 的黑体词（yeneva maggena、gato、Vipassī、Kakusandhā、tenañjasena、anādānā、khayogadhā、yehāyaṃ desito dhammo、dhammabhūtehi、tādibhi、cattāri ariyasaccāni）引自第 491–492 偈，不在本次父层对照范围内，无法逐字核对。

⚠ **父层译法与 nissaya 冲突（须回到父层修订，本层不能单方面改）**：父层把 yasmiṃ 译成“依着这条道路”。nissaya 对它给了两种读法，都不是“道路”：
- §1794 偈颂 nissaya：`ယသ္မိံ= အကြင်ခန္ဓာအစရှိသည်ဖြင့်သမုတ်သော။`（被称为蕴等的那个〔轮回〕）
- §1799 nissaya：`ယသ္မိံ နိရောဓေ= အကြင်နိဗ္ဗာန်၌။`（在那个灭／涅槃中）

结果是本层两处被解释词与紧接着的释义自相矛盾：§1799 句 2-8 的被解释词是“道路”，释义却是“证得灭、涅槃的时候”；§1799 句 52-81 的被解释词是“道路”，释义却是“轮回”。建议在父层把 yasmiṃ 改为与“灭／涅槃”相容的译法（例如“在那里”），再让本层两处黑体同步更新。

## 跨段一致性

- 被解释词的释义引导语：“**X**，是说…”（§1796 句 2-11、12-17，§1797 句 25-38、39-44，§1799 句 2-8）和“**X**，就是…”（§1796 句 18-22、36-41，§1797 句 2-7、8-12、13-24）混用。§1798 句 15-19、20-23 又写成“**X**是…”，没有逗号。两种引导语意思相同，建议统一为一种，或者至少统一加逗号。
- 其余术语前后一致：maggena→道路、añjasa→正路、ariyamagga→圣道、desita→宣说、nirodha→灭、punabbhava→再生、dhammabhūta→成为法者、yojanā→文句的连贯。

## §1794 句 129-1794-2-11
- **问题**：句法（父层问题）— nissaya 补出了因果连接：`ယသ္မာ= အကြင့်ကြောင့်` …`နတ္ထိ= မရှိ` …`တသ္မာ= ထို့ကြောင့်` …`သုဝိမုတ္တော= ကောင်းစွာ လွတ်သည်`，即“因为不再有再生，所以我已完全解脱”。`အညော= ဤဒုက္ခမှတစ်ပါးသော` 也说明“另一次”是“这次苦之外的另一次”。译文“不会再有另一次再生，我已在一切处完全解脱”把两句并列，丢了因果关系。§1799 句 82-102 的释义也明确写了 tasmā（所以）。
- **建议**：本句是偈颂转录，必须与父层同步。请在父层考虑改为“……不会再有另一次再生，所以我已在一切处完全解脱”，本层随之更新。

## §1797 句 129-1797-13-24
- **问题**：格／关系代词 — `ယေဟိသမ္မာသမ္ဗုဒ္ဓေဟိ= အကြင်မြတ်စွာဘုရားတို့သည်` 是关系代词“那些（佛）”，nissaya 用的是 အကြင်（关系性“那些…”），不是指示代词。译文“这七位正等正觉者”把关系代词译成了近指的“这”。
- **建议**：改为“就是七位正等正觉者所宣说、所宣示的这教法”，去掉“这七位”的“这”。

## §1797 句 129-1797-25-38
- **问题**：补出成分 — `ဓမ္မံ= လောကုတ္တရာတရားကိုးပါးသို့` 指明 dhammaṃ pattehi 的“法”就是九种出世间法。译文只写“已经证得了法”，读者不容易看出它和前一解的“九种出世间法”是同一个所指。
- **建议**：可补为“或者是已经证得了〔九种出世间〕法”，用正文表达，不加方括号。属可选项。

## §1798 句 129-1798-15-19、129-1798-20-23
- **问题**：句法 — nissaya 两处都以 `သဒ္ဒါ`（词）收尾：`ဂဏနပရိစ္ဆေဒေါ= …ကိုပြကြောင်းဖြစ်သောသဒ္ဒါတည်း`、`ပရိစ္ဆိန္နဓမ္မဒဿနံ= …ကိုပြသောသဒ္ဒါတည်း`。意思是“‘四’这个词表示数目的限定”“‘圣谛’这个词显示被限定的法”，说的是词的功能，不是事物本身。译文“**四**是数目的限定”容易被读成“四本身就是限定”。
- **建议**：“这里，**四**这个词表示数目的限定。”“**圣谛**这个词显示被限定的法。”

## §1798 句 129-1798-52-59
- **问题**：格 — `ဧတသ္မာ= ထိုတဏှာကြောင့်` 是从格表原因／来源，指渴爱，不指处所。译文“从这里生起”的“这里”像是在说地点。
- **建议**：“那苦由它生起，所以是**集**，就是渴爱。”

## §1798 句 129-1798-60-72
- **问题**：词义 — `နိဗ္ဗာနတ္ထိကေဟိ= နိဗ္ဗာန်ကိုအလိုရှိကုန်သော…` 的意思是“希求涅槃的人”。译文“为寻求涅槃的人所寻求”与后面的 maggīyati（寻求）重复，混淆了 atthika（想要）和 maggati（寻求）。
- **建议**：“或者为希求涅槃的人所寻求”。

## §1798 句 129-1798-73-91
- **问题**：原文／读法分歧（记录，不改）— nissaya 作 `သံသာရစရဏသင်္ခါတော`（saṃsāracaraṇa-，被称为在轮回中往来的），并把 rodha 释为 `တဏှာ`（渴爱）。pali 原文作 saṃsāracāraka-（轮回牢狱）。译文“被称为轮回牢狱的拘禁”依从 pali 原文，可以保留。
- **建议**：译文不动；把这处读法分歧记进 known-issues。

## §1799 句 129-1799-2-8
- **问题**：被解释词与释义矛盾 — 见上文“父层译法与 nissaya 冲突”。黑体按硬约束沿用父层“依着这条道路”，但 nissaya `ယသ္မိံ နိရောဓေ= အကြင်နိဗ္ဗာန်၌` 与释义“证得了那个灭、那个涅槃的时候”都指涅槃，不指道路。
- **建议**：等父层改定后同步黑体，本层暂不单改。

## §1799 句 129-1799-9-31
- **问题**：读法分歧（记录）— nissaya 被解释词作 `နိဗ္ဗတ္တတေတိ`（nibbattate），pali 作 Nivattate。译文依 pali 译“止息了”，与父层一致，可以保留。
- **建议**：不改；记入 known-issues。

## §1799 句 129-1799-32-51
- **问题**：引文一致性 — “病已见到”引自 rogo diṭṭho（第 492 偈前后的本文），须与父层对应偈句的译文逐字一致。该偈不在本次对照范围内，未能核对。
- **建议**：核对父层对应偈句的译法，按父层统一。

## §1799 句 129-1799-52-81
- **问题 1**：被解释词与释义矛盾 — 黑体“**依着这条道路**”沿用父层，但这里的 yasmiṃ 修饰 saṃsāre（`ယသ္မိံ သံသာရေ= အကြင်သံသရာ၌`，在那个轮回中），所以“所谓依着这条道路，……指……轮回”读不通。处理同 §1799 句 2-8，待父层修订。
- **问题 2**：句法（必改）— 本句末尾的 punabbhavo 是主语，谓语 natthi 在下一句（句 82-102）。nissaya 的 `အညော= တစ်ပါးသော` / `ပုနဗ္ဘေဝါ= …ဖြစ်ခြင်းသည်`（主格）也显示它是主语，没有谓语。译文用句号把它断成“另一次因一再成为有而称为再生。”，成了没有谓语的残句，下一句的“此后就不再有了”又缺主语。
- **问题 3**：读法分歧（记录）— nissaya 作 `ဣတောဒုက္ခပ္ပဝတ္တိတော`（dukkhappavattito，这次苦的生起），pali 作 dukkhappattito。nissaya 把 so 释为 `ထိုသရဘင်္ဂ မထေရ်သည်`（那位舍罗槃伽长老），但从性数看 so 应与 punabbhavo 呼应。译文把 so 略去未译。
- **建议**：句末改为逗号或破折号，让主语接进下一句，例如“……就在其中生起；与这次苦的生起不同、因一再成为有而称为再生的那个——”，再接句 82-102 的“随着这个命根的终尽……此后就不会再有了”。

## §1799 句 129-1799-82-102
- **问题**：格 — `သဗ္ဗေဟိ ကိလေသေဟိ= …ကိလေသာတို့မှ`、`ဘဝေဟိ= …ဘဝများတို့မှ` 是“从……（解脱）”的离格义。译文“对一切烦恼、对一切有……解脱”的“对”不准确。
- **建议**：“所以我在一切处——从一切烦恼、从一切有中——都已完全解脱、脱离了束缚。”另外“此后就不再有了”要和上句的主语接上，见 §1799 句 52-81。

## §1796 句 129-1796-36-41
- **问题**：风格（必改）— “即圣道”中的“即”是文言虚词。
- **建议**：“就是依着那同一条正路，也就是圣道。”
