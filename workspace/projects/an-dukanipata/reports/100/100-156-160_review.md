# Review — 100:156-160（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 被解释词与父层逐字核对

逐条比对了本 chunk 的黑体被解释词与父层 85:86-91 的定稿译文：**idha / sīlavā hoti / pātimokkhasaṃvarasaṃvuto / ācāragocarasampanno / aṇumattesu / vajjesu / bhayadassāvī / samādāya / sikkhati sikkhāpadesu / aññataraṃ devanikāyaṃ / āgāmī hoti / āgantā itthattaṃ / aññataraṃ santaṃ cetovimuttiṃ / anāgantā itthattaṃ / kāmānaṃyeva nibbidāya / virāgāya / nirodhāya / paṭipanno hoti / bhavānaṃyeva / taṇhākkhayāya paṭipanno hoti / so lobhakkhayāya**。这些词的译法均与父层逐字相同。

有一处**格式问题，属必改**：§156 句 100-156-124-137 的 pali 中 `sīlavāti` 没有加黑，译文却把「**持戒**」加黑了。详见该句条目。

## 跨段一致性

- **maggaphala 的计数说法**：§157 句 100-157-123-131 译「两个道和两个果」，§158 句 100-158-52-62 译「三个道和三个果」，§160 句 100-160-2-76 却译「两种道果」「三种道果」。建议统一为「两个道和两个果／三个道和三个果」。依据：pali 在 §157、§158 分列 maggadvaya / phaladvaya、tayo maggā tīṇi ca phalāni，§160 的 maggaphalāni 是同一所指的复数并称。
- **upari … vipassanā 的句式**：§160 的四个分句中，第 1、3、4 句作「为了灭尽……而修的、趣向更上的××道的观」，第 2 句（so bhavānaṃyeva）作「为了趣向更上的××道而修的观」，结构不一致。建议统一为前一种句式。
- **sesāni 的所指**：§156 句 100-156-93-106 与句 100-156-107-123 都把 sesāni 译成身体的「其余部分」，与 nissaya 的所指不符，两句须同步修正，见下。

## §156 句 100-156-43-48

- **问题**：补出成分。`ဥဘယတ္ထာပိ= နှစ်ပါးစုံသော ဥဒ္ဒေသ,နိဒ္ဒေသ ၌လည်း` 指的是「略说（uddesa）和详说（niddesa）这两处」。译文「在这两处」所指不明，读者无从知道是哪两处。
- **建议**：改为「在略说和详说这两处，说的都只是波罗提木叉律仪。」

## §156 句 100-156-49-92

- **问题**：语气与逻辑误读，属必改。前一分句是「只有波罗提木叉律仪才是戒」，后一分句 `itarāni pana tīṇi sīlanti vuttaṭṭhānaṃ nāma atthī` 是 nāma 加 atthi 的反诘：「哪里有说其余三种是戒的地方呢？」，意思是没有。nissaya 按字面作 `ရှိ၏`，但紧接的 `အနုနုဇာနန္တော= ခွင့်မပြုလိုသည်ဖြစ်၍`（不认可）表明这是在否定。译文加了「确实」，写成「确实有把它们说成戒的地方」，与前句「只有……才是戒」自相矛盾，也与下文对其余三种的贬抑（「只不过是……而已」）相悖。
- **建议**：改为「……至于其余那三种，哪里有说它们是戒的地方呢？”」。「他不同意苏摩长老的说法」中补出的宾语可以保留，也可改为「他不认可（其余三种是戒）」。
- **问题**：用词。`နိပ္ပရိယာယေန= မုချအားဖြင့်` 意为严格意义上、不借方便说。「就不加转义的直接意义来说」偏生硬。
- **建议**：改为「严格来说」。

## §156 句 100-156-93-106

- **问题**：句法误读，属必改。nissaya 的结构是两层：先说「如同不能说一个断了头的人还会守护手脚」（`ယတ္ထပါဒေ= လက်,ခြေ,တို့ကို … န ဝတ္တဗ္ဗော ဝိယ`），再说「不能说这个人还会守护其余的戒」（`သေသာနိ= ကြွင်းသော ဣန္ဒြိယသံဝရသီလအစရှိသည်တို့ကို`）。sesāni 指根律仪等其余三种戒，不是身体的其余部分。译文「守护手脚等其余部分」把比喻和本义并成了一句，sesāni 的所指译错了。
- **建议**：改为「一个人如果这个戒已经毁坏，就像不能说一个被砍了头的人还会守护手脚那样，也不能说他还会守护其余的戒。」

## §156 句 100-156-107-123

- **问题**：句法误读，属必改，与上句同理。`ဇီဝိတံ … သက္ကောတိ ဝိယ`（如同能保住性命）是比喻；`သေသာနိ= ကြွင်းသောဣန္ဒြိယသံဝရသီလ အစရှိသည်တို့ကို … ရက္ခိတုံ သက္ကောတိ`（能守护其余的戒）是本义。译文把「保住性命」和「恢复其余的部分」都安在断头比喻里的那个人身上。
- **建议**：改为「但是一个人如果这个戒完好无损，就像一个头没有被砍断的人能保住性命那样，他也能把其余的戒重新恢复原状并加以守护。」

## §156 句 100-156-124-137

- **问题**：格式，属必改。pali 中 `Tasmā sīlavāti iminā` 的 sīlavā 不是黑体被解释词，只是引述。译文把「**持戒**」加黑，会让读者误以为这里另起一条注。
- **建议**：去掉加黑，改用引号：用“持戒”这一句。
- **问题**：补出成分。`(အာဟ= ဆို၏)` 末尾的 iti 收束的是小龙长老这段话，`ဟောတော်မူ၏` 的主语是舍利弗长老。译文没有主语，也没有表明长老的话到此为止。
- **建议**：改为「所以（舍利弗长老）是用“持戒”这一句举出波罗提木叉律仪，……才说了“具足波罗提木叉的律仪”等等。」并在句末交代这是小龙长老的话，例如以「小龙长老这样说」收尾，或用引号收束。

## §157 句 100-157-25-28

- **问题**：词法。`ဘယဒဿီ= ဘေးအားဖြင့် ရှုလေ့ရှိသည်` 意为习惯把它们看作危险。bhayadassī 是「视……为怖畏」的习性词。「见到怖畏」丢了「把它们看作」这层宾语关系，「怖畏」一词也偏文。
- **建议**：改为「把它们看作危险」。

## §157 句 100-157-43-62

- **问题**：补出成分。nissaya 在 `အပိစ(အပရော)` 后补出 `နယော … ဝုစ္စတေ`（再说另一种解释方式），说明 apica 引出的是另一种释法，不是追加内容。
- **建议**：「此外」改为「另一种解释是：」。

## §157 句 100-157-96-102

- **问题**：补出成分。`ဟေဋ္ဌာ= အောက်ဖြစ်သော ကာမဘုံသို့` 指下方的欲界，译文「回到下面来」所指模糊。
- **建议**：改为「他会回到下面的欲界来」。

## §157 句 100-157-123-131

- **问题**：语序。`သုက္ခဝိပဿကဿ`（修纯观的）与 `ဓာတုကမ္မဋ္ဌာနိကဘိက္ခုနော`（以界为业处的比丘）同为属格，并列修饰同一个比丘。译文「纯观行者比丘」把「行者」和「比丘」叠在一起，读起来像两个人。
- **建议**：改为「以界为业处、修纯观（sukkhavipassaka）的比丘」。§160 同步修改。

## §159 句 100-159-2-9

- **问题**：补出成分，属可选。nissaya 补出了 `ကာမာနံ= ဝတ္ထုကာမ,ကိလေသကာမတို့ကို`，即事欲与烦恼欲。
- **建议**：可写作「两种欲（事欲和烦恼欲）」，让读者知道是哪两种。

## §159 句 100-159-48-59

- **问题**：词法。`သောတာပန္နသကဒါဂါမီနံယေဝ= …တို့၏သာလျှင်` 带强调小词 yeva，意为「正是须陀洹和斯陀含的」。译文漏了这层强调。
- **建议**：改为「……用这一句讲的也正是须陀洹和斯陀含为了……」。

## §160 句 100-160-2-76

- **问题**：句式不一致，见跨段一致性。第 2 分句的 `ဥပရိ= အထက်၌` 修饰的是 vipassanā，与其他三句同构。
- **建议**：改为「讲了阿那含为了灭尽对有的贪而修的、趣向更上的阿罗汉道的观」。注意：pali 本句的 so bhavānaṃyeva 分句没有 bhavarāgakkhayāya，所以也可以只改句式，写作「讲了阿那含所修的、趣向更上的阿罗汉道的观」，不补「灭尽对有的贪」。
- **问题**：一致性。「两种道果」「三种道果」与 §157、§158 的说法不一致。「纯观行者比丘」同 §157 句 100-157-123-131 的问题。
- **建议**：统一改为「下面两个道和两个果」「三个道和三个果」，并按 §157 的建议改写「以界为业处、修纯观的比丘」。
