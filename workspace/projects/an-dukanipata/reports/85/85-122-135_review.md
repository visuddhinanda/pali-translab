# Review — 85:122-135（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅部分句有 nissaya，无 nissaya 的句子未单独出意见）

## 跨段一致性

- **parisā**：§122–§125（至 85-125-33-61）译“众”，§125（85-125-62-91 起）至 §129 改译“集会”，§130 品名与 §132–§133 摄颂又回到“众”。→ **必改**，全 chunk 统一为“众”。依据：品名“众品”，摄颂也用“众”，前半段已用“众”。统一后，“在某个集会中”“这就是两种集会”等句式也随之改为“某个众中”“这就是这两种众”。
- **经号格式**：§123“49.”、§125“50.”，§127“五十一、”、§128“五十二、”。→ 统一为一种写法。建议沿用阿拉伯数字加点：“51.”“52.”。
- **dippanti / na dippanti**：§125 与 §126 都译“大行其道 / 不彰”。nissaya：`ဒိပ္ပန္တိ= တောက်ပြောင် ထင်ရှားကုန်၏`（光耀、显明）。“大行其道”带贬义，在 §126 用于如法的羯磨（“如法的羯磨大行其道”）不妥；“不彰”是单音节文言词。→ **必改**，两段统一为“显扬 / 不显扬”或“彰显 / 不彰显”。
- **saññatti / nijjhatti 系列**：
  - §128 译“不使彼此明白……不让人明白为力量……不让人审察为力量”。
  - §129 译“以达成了解为力量，以使人审察为力量”。
  - 两段的 saññattibalā 与 asaññattibalā 只差否定前缀，nissaya 也是对称释义：`ကောင်းစွာ သဘောပေါက်စေခြင်းဟူသော စွမ်းအား` / `ကောင်းစွာ သဘောမပေါက်စေခြင်းဟူသော စွမ်းအား`。
  - → 统一为对称译法：§128“以不让人明白为力量，以不让人审察为力量”，§129“以让人明白为力量，以让人审察为力量”。
- **引语前的破折号 “–”**：§123 与 §124（“称赞说——”）用破折号，§128 与 §129（“坚持说：”）用冒号。原文同为 “–”。→ 统一用一种标点。
- **etadaggaṃ 句式**：§122 与 §124 作“这两种众里面，最上的是……的众”，§126、§127、§129 作“这两种集会当中，……的集会是最上的”。→ 统一句式。建议用前者：“这两种众里面，最上的是……”。

## §124 句 85-124-61-66

- **问题**：句法 / 隐含成分 — nissaya 补出了 `တေန= ထိုသို့ မပြောဆိုကြခြင်းကြောင့်`（因为不那样说）。现在的译文“他们由此得到利养”与 §123 同一句字面完全相同，读者容易把“由此”理解成“由于互相称赞”。
- **建议**：可选改为“他们也由此（不作那样的称赞）得到利养”，或改为“他们因为不那样说而得到利养”，明确“由此”指的是不称赞。

## §124 句 85-124-67-77

- **问题**：风格 — “不吞执不放”是双重否定叠在一起，读起来别扭，像是“不放”被否定了。nissaya：`အနဇ္ဈာပန္နာ= တဏှာသည် အလွန်အကဲမဖိစီးမလွှမ်းမိုးအပ်ကုန်ဘဲ`（不被贪爱过度压覆）。
- **建议**：改为“不沉溺其中”，同时把 §123（85-123-91-129）的“吞执不放”改为“沉溺其中”。这样两处正反对称，也更贴近 nissaya 的主释义。

## §128 句 85-128-46-66

- **问题**：隐含成分 — nissaya 在 nijjhāpenti 前补出 `(တံ အဓိကရဏံ= ကို။ အညမညံ= ချင်း)`，即“使彼此审察那桩诤事”。译文“使对方审察思量”漏掉了宾语“诤事”，“对方”也与前半句的“彼此”（aññamaññaṃ）不一致。
- **建议**：改为“……也不让彼此审察那桩诤事，也不为了让彼此审察而聚到一起”。§129（85-129-26-41）照此对称修改。

## §128 句 85-128-67-87

- **问题**：词义 — `အပ္ပဋိနိဿဂ္ဂမန္တိနော= အဓမ္မိက အဓိကရုဏ်းကို စွန့်လွှတ်ခြင်းငှာ မတိုင်ပင်ကြကုန်ဘဲ`。nissaya 的意思是“不为舍弃（不如法的）诤事而共同商议”，mantin 指“商议”。译文“从不考虑放弃”把它译成了个人的考虑，失去了“相互商议”的意思。
- **建议**：改为“不商议放弃那桩诤事”。§129（85-129-42-54）的“会考虑放弃”相应改为“会商议放弃”。

## §129 句 85-129-42-54

- **问题**：跨段一致 — “以达成了解为力量”与 §128 的 asaññattibalā 不对称，见上文跨段一致性一节。
- **建议**：改为“以让人明白为力量，以让人审察为力量，会商议放弃……”。
