**基准缺失（降信心的主因）**：本次只注入了巴利原文与 channel 译文，**没有 nissaya，也没有本段所释的义注原文**。按方法文档，准确性应「以义注定释义、nissaya 定词法」逐句核对；此处两条基准都不可用，只能依巴利原文本身的句法与上下文判断，故信心压到 62。尤其是「被解释词与父层逐字同译」这条硬约束无法真正比对——下面三条 error 是从**本层注解文的自洽性**（被解释词 vs. 其释义）推出的，不是与义注文本对读得出的结论。另：注入数据里本段标注为复注（ṭīkā），但每条记录的 `layer` 字段写的是 `mula`，层次标注自相矛盾，建议上游核一下。

**准确性**：取义整体可靠。vossagga 两义（pariccāga/pakkhandana）与 tadaṅga/samuccheda、tanninna/tadārammaṇa 两组四分的对应关系（51-17-35、51-53-59、51-73-78、51-79-84）处理得准确且前后一致；`tanninna` 补出「涅槃」、`ārammaṇakaraṇa` 补出「以涅槃为所缘」属有据的解释性补足，可接受。53–54 段四种修定目的（心一境性 / 观的基础 / 神通基础 / 灭尽定基础 / 殊胜有）层次清楚，经典出处夹注原样保留。55 段 `padaṭṭhānapadaṭṭhānampi hi padaṭṭhānaṃ` 与「饭靠草煮成」的譬喻译得到位。扣分集中在**被解释词（黑体 lemma）被塞进了释义内容**：`Sabbesaṃ`→「一切有为法的」、`Tañca kho`→「而且念觉支」，把下文才给出的解释提前写进了所释词，结果整句变成循环说明；`Ayaṃ satisambojjhaṅgo` 的 `ayaṃ` 则直接漏译。这类处理会让读者看不出复注究竟在释哪个词。

**风格**：主体是现代书面汉语，禁例表里的文言虚词与句式基本没有出现，标点全部全角，译文内**未出现 ASCII 引号**（JSON 安全无隐患），也没有残留任何工作标记。扣分在：一处「安乐**而**住」为半文半白（同一组译文另一处已作「安乐地住」）；夹注政策不统一——`sukkhavipassaka`、`padaṭṭhāna` 规范地附了巴利原词，而「彼分」「断除」「遍处的预备工作」「殊胜的生存状态」等法相术语首次出现都没附；51-2-9 直接在译文里用拉丁拼写「vossagga 一词」，与同句的汉译「舍遣」并置而未作括注，形式上偏离 style 第三节。

**一致性**：术语面很稳（舍遣 / 觉支 / 等至 / 禅那 / 现法乐住 / 漏尽者 全书一致，无同词异译）。不一致主要在**句式处理**：53-25-44 把 `samāpajjitvā` 读进引语内（「我们进入等至以后，要…」），54-2-60 / 54-61-87 同样位置的 `samāpajjitvā` 却处理成引语外的先行动作；两种读法各自讲得通，但平行句型应取同一种。另加上述 lemma 译法三处不统一（有的照字面、有的掺入释义）。

## 问题清单

### 🟧 error

- `182-51-45-52`｜漏译｜片段「**念觉支**，说的是」
  - 问题：被解释词是 `Ayaṃ satisambojjhaṅgo`（含指示代词 `ayaṃ`），黑体部分只译出「念觉支」，`ayaṃ` 未译；而后半释义又用「那个念觉支」回指，与原文 `ayaṃ`（这个）方向相反。
  - 建议：黑体改作「**这就是念觉支**」，释义相应改为「指的是按世间与出世间相混杂的方式所说的这个念觉支」。

- `182-52-28-31`｜错误多译｜片段「**一切有为法的**，这里的“一切”指的就是诸有为法。」
  - 问题：所释词只是 `Sabbesaṃ`（一切的），译文把释义里的「有为法」提前塞进黑体，导致「一切有为法的」被「一切指的就是诸有为法」解释，整句成了循环；读者也无法看出复注在释哪个词。
  - 建议：黑体只保留「**一切的**」，释义作「指的是诸有为法」。

- `182-52-41-46`｜错误多译｜片段「**而且念觉支**」
  - 问题：所释词 `Tañca kho` 是代词短语（而这个／而它），黑体里却直接写出「念觉支」，与紧随其后的释义「说的就是上文所说的那个念觉支」重复，同样构成循环说明。
  - 建议：黑体作「**而这个**」或「**而它**」，释义保留现有内容。

### 🟨 warning

- `182-51-108-115`｜代词指代不明确｜片段「**“也就是说，这位”**」
  - 问题：`ayañhi` 的 `ayaṃ` 在此语境中更可能回指前句的「成熟／觉支」而非某个人，「这位」把它限定成了人；且 `hi` 译作「也就是说」与句首「所以才说」语义重叠，读起来像两层连接词叠加。
  - 建议：无法确定所指时译为中性形式，如「**“因为这个”**」或「**“这个嘛”**」，人／法的指向留给上下文；此处确有歧义，宜压低该句 confidence 并在术语报告里记一条待查义注原文。

- `182-54-61-87`｜标点符号使用错误｜片段「证得寂灭、涅槃」
  - 问题：`nirodhaṃ nibbānaṃ` 是同指（灭即涅槃）的同位结构，用顿号并列会被读成「寂灭」和「涅槃」两样东西。
  - 建议：改为「证得称为涅槃的寂灭」或「证得寂灭即涅槃」。

- `182-53-2-14`｜文言语体｜片段「安乐而住」
  - 问题：「而」作文言虚词，属半文半白；同组译文 `182-54-61-87` 已作「安乐地住」，前后不统一。
  - 建议：统一改为「安乐地住」或「安乐地安住」。
