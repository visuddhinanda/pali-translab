# Review — 85:16-34（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅

## 跨段一致性

- **经名在摄颂里与经题不一致**（摄颂 nissaya 逐一标为「某某经」，应与经题同名）：
  - upaññāta：§18 经题译「领悟经」，§33 摄颂译「自觉知」 → 统一为「领悟」
  - saṃyojana：§20 经题译「结缚经」，§34 摄颂译「结合」 → 统一为「结缚」
  - sukka：§25 经题译「白净经」，§34 摄颂译「明净」 → 统一为「白净」
  - kaṇha：§23 经题译「黑法经」，§34 摄颂译「黑」 → 可保留简称，但建议写「黑法」，与经题对应
- **sukka 术语漂移**：§26 译「白净的」，§28 译「明净法（sukka）」。nissaya 两处都作 `သုက္ကာ= ဖြူစင်ကုန်သော`（洁白的），是同一个词 → 统一为「白净」。§28 的巴利夹注也应移到首次出现处（§26）或删去。
- **hirī / ottappa 夹注重复**：§26 已经夹注「惭（hirī）和愧（ottappa）」，§28 又夹注一次 → §28 删去夹注。
- **经末标记**：§17「第四经。」、§19「第五经。」、§22「第六经。」、§24「第七经。」、§26「第八经。」，但 §28 是「第九经结束。」、§30 是「第十经结束。」。巴利原文只有序数词，nissaya 作 `…ခုမြောက်သုတ်တည်း`（是第…经） → 统一为「第九经。」「第十经。」
- **经文序号前缀**：§17、§19、§21、§24、§28、§30 的开头都带「四、」「五、」等序号，只有 §26 漏了「八、」 → 补上。
- **「Katame dve?」**：§17、§21、§24、§26 译「哪两种呢？」，§28、§30 译「是哪两种呢？」 → 统一为「哪两种呢？」
- **「Dveme, bhikkhave, …」开头句式**：§17 译「有两种法不会让人懊悔」，§21、§24 译「有这样两种（黑）法」，§26 译「有两种法是白净的」，§28 译「有两种明净法」，§30 译「有两种入雨安居」。nissaya 一律作 `ဣမေ ဒွေ`（这两种） → 统一为「有这两种…」，或者都用「有两种…」。
- **「Ime kho, bhikkhave, dve … ti」结尾句式**：§17 译「这就是…的两种法」，§22、§24 译「这就是上面所说的两种（黑）法」，§26 译「以上就是两种白净的法」，§30 译「这就是两种入雨安居」 → 统一为「比丘们，这就是两种…」。「上面所说的」「以上」在原文里没有对应的词，建议删去。

## §17 句 85-17-2-14
- 无词法问题。atapanīyā = `မနှိပ်စက်တတ်ကုန်သော`（不折磨人的），句 85-17-86-103 的 na tappati = `နောင်တ တစ်ဖန် မပူပန်`（事后不再懊恼），「不会让人懊悔」与 nissaya 相符。此条从略。

## §19 句 85-19-2-26
- **问题**：隐含成分漏补 — nissaya 在 `ဒွိန္နံ ဓမ္မာနံ` 后补出 `(ဂုဏံ= ဂုဏ်ကို)`：dvinnaṃ dhammānaṃ 是属格，所修饰的是一个省略的「功德」。upaññāsiṃ 是 `ကပ်ရောက်၍သိ`（亲近而知）。所以句意是「我亲身体会到两种法的功德」，不是「领悟到两种法」。
- **建议**：「我亲身体会到两种法的功德——……」
- **问题**：增译 — 「对**已证得的**善法不知满足」中，「已证得的」在原文和 nissaya 里都没有。nissaya 对 kusalesu dhammesu 只释作「善法」，补出的隐含成分是 `(အရဟတ္တမဂ်ကို မရသေးသမျှ)`（在还没证得阿罗汉道之前），这是时限，不是限定「已证得的」善法。
- **建议**：删去「已证得的」，改作「对善法不知满足」。如果要补，按 nissaya 补时限：「在证得阿罗汉道之前，对善法不知满足」。

## §19 句 85-19-88-95
- **问题**：小品词归属 — nissaya 注明 cepi 的 pi 应当与下句连读，作 `ဧဝံ သတိပိ`（如果这样努力的话）。真正修饰「你们」的「也」在下一句的 tumhepi。本句「如果你们**也**能」把 pi 提前挂到了 tumhe 上，下句又有「你们……也将」，「也」重复出现。
- **建议**：本句作「比丘们，如果你们能不退缩地精勤努力——」，「也」只留在下句。

## §19 句 85-19-96-149
- **问题**：释义偏弱 — sammadeva = `အကြောင်းမှန် နည်းလမ်းမှန်အားဖြင့်သာလျှင်`（正是以正确的理由、正确的方式）。nissaya 还补出，所指是出于对生老死的厌怖（saṃvega）而依教出家，与因负债、怕危险、谋生而出家相对。译作「**真正**舍离家庭」，丢了「以正当理由」这一层。
- **建议**：「良家子弟以正当的理由，从家庭出家、过无家生活，所要追求的……」

## §28 句 85-28-2-17
- **问题**：动词增译 — pālenti = `စောင့်ရှောက်ကုန်၏`（守护），nissaya 只有这一个义项，译文「维系并守护」多出了「维系」。lokaṃ = `သတ္တလောကကို`（有情世间）。
- **建议**：「……有两种白净法守护着世间。」句 85-28-25-51「不维系守护世间」、句 85-28-74-109「维系并守护着世间」同样改为「守护」。

## §28 句 85-28-74-109
- **问题**：连接词漏译 — 句首 ca 在 nissaya 里作 `ထိုသို့မဟုတ်မူ၍`（然而事实并非如此），与上句的假设构成转折。译文直接以「正因为」起句，转折没有译出。
- **建议**：「然而，比丘们，正因为这两种白净法守护着世间，所以……」

## §31 句 85-31-2-4
- **问题**：增译 — 原文是 Kammakaraṇavaggo paṭhamo，nissaya 作 `ပဌမော= ရှေးဉီးစွာသော`（第一）、`ကမ္မကရဏဝဂ္ဂေါ`（刑罚品）。原文没有 niṭṭhito，译文的「结束」是多出来的。
- **建议**：「第一 刑罚品」或「刑罚品第一」。

## §33–34 句 85-33-2-10 / 85-34-2-9（摄颂，nissaya 合在 §34 一条）
- **问题**：所指不清 — dve tapanīyā 在 nissaya 里作 `တပနီယသုတ်, အတပနီယသုတ်တို့`，指《令人懊悔经》和《不令人懊悔经》两部。译文「两部‘令人懊悔’」读起来像两部同名经，也和 §16 的经题「不令人懊悔经」对不上。
- **建议**：「令人懊悔、不令人懊悔两部」
- **问题**：经名不一致 — 「自觉知」「结合」「明净」见上方跨段一致性一节 → 改为「领悟」「结缚」「白净」。
- 说明：nissaya 自注这首摄颂只是记诵用的目录，格变化不必计较，所以格这一层不提意见。
