## 理由

**资源降级（影响信心指数）**：本次只拿到巴利原文与目标 channel 的现有译文。

- **无 nissaya**：格、句法角色、隐含成分全部靠原文自判，下面凡涉及格与修饰关系的判断（如 `100-28-29-32` 一组的夺格、`100-24-77-90` 的具格分词归属）均无词级基准背书，故不按 error 顶格计，多列为 warning / suggestion。
- **无父层本文（AN 二集本文）**：被评的这一层本身就是义注，其"释义标准"应是复注（ṭīkā），同样缺失；更要紧的是**被解释词与本文逐字同译这条硬约束无法核验**——本段几乎每句都是 `X ti ...` 的词释，黑体引自本文，引文是否与本文译文逐字一致本次只能从内部一致性侧面判断。下面 `100-28-53-56`、`100-26-24-28`、`100-23-44-52` 等几条就是从"引文明显多出本文没有的成分"这个角度立的，若本文层译文另有写法，需在 harmonize 时一并回看。

**准确性（82）**：主谓宾判断整体正确，无违背基本教理的句子，fatal 为零。扣分集中在三类：一是黑体引文里**添进了原文没有的限定成分**（`已证得的`、`我就是这样`、`那个无上目的`），破坏引文的逐字性；二是 `100-23-53-64` 把主句谓语 `uppādesiṃ` 降成时间从句"一直到……为止"，整句"我"失去谓语，语义虽未颠倒但判断关系已变形；三是 `100-23-99-111` 把纯虚词 `sudaṃ` 译成实义时间副词"曾"，随即又说它"只是个虚词，没有特别的意思"，译文自相矛盾，且给原文平添过去时。词释部分（`appamādādhigatā` / `sambodhi` / `yogakkhema` / `hiri`-`ottappa` / `vaṭṭavivaṭṭa`）取义与义注传统一致，`satiavippavāsa`→"念不离失"、`nipphattikāḷatā`→"结果上的黑"这类抽象名词处理得当。

**风格（91）**：这是本批最好的一项。通篇现代书面汉语，未发现文言虚词、文言句式或单音节文言词，`style.md` 第一节禁例表零命中；"纵使皮"的"纵使"属书面连词，不算文言腔，可接受。标点全角，`“ ”` 成对（`100-23-53-64` 开引号与 `100-23-75-92` 收引号跨句对应正确），`zh` 字段内无 ASCII 引号，JSON 安全。扣分项是 `100-23-2-11` 的省略号用法与几处同词连用造成的回环（"不退缩的意思是……不退缩"）。

**一致性（83）**：`padhāna`→"精勤努力"、`anuttara`→"无上"、`purisathāma`→"凭人的力量"全批统一，经末"第五经／第六经／第七经"体例一致，`pajahati`／`pahāya` 的"断除／断除了"时体区分到位。扣分有三处系统性问题：(1) `appaṭivānitā` 与 `anosakkanā` 共用"不退缩"，导致 `100-23-93-98` 自我循环；(2) 愁悲苦忧恼五支改译成"忧愁／悲叹／身苦／心苦／极度的困苦"，其中"忧愁"给了 `soka`、"心苦"给了 `domanassa`，与南传通译（愁／悲／苦／忧／恼）错位，读者易把两者混同；(3) 同一 `dukkha` 在 `100-28-53-56` 作"身苦"、在 `100-28-65-68` 作"苦"，同批内不统一。另外 `paṭipadā` 在 `100-24-91-98` 是"修行之道"、`100-25-2-12` 是"那条道路"。

## 问题清单

### 🟧 error

- `100-23-44-52`｜错误多译｜片段「对已证得的善法不知满足」
  - 问题：原文 `asantuṭṭhitā kusalesu dhammesu` 只有"对善法不知满足"，"已证得的"在巴利里没有对应成分。此处是引自本文的黑体引文，多加限定既是多译，也破坏被解释词与本文逐字同译。
  - 建议：改为"对善法不知满足"；"不满足于已得之善"这层意思本就由紧接的引号释义段（`100-23-53-64`）承担，不必塞进引文。

- `100-23-53-64`｜错译（修饰关系）／导致误解的表达｜片段「而是一直到生起了阿罗汉道为止」
  - 问题：`arahattamaggameva uppādesiṃ` 是本句主句谓语（我生起了阿罗汉道），`eva` 为强调。译文把它降为时间状语"一直到……为止"，"我"在整句中失去谓语，读起来像半截话，`eva` 的强调也丢了。
  - 建议："我不曾因为只得到禅那、只得到光明相就满足，而是一直修到生起了阿罗汉道。"

- `100-23-99-111`｜导致误解的表达／错误多译｜片段「我曾不退缩地精勤努力」
  - 问题：`sudaṃ` 是纯虚词，`padahāmi` 为现在时。译文用"曾"去占 `sudaṃ` 的位置，再声明"只是个虚词（nipāta），没有特别的意思"——既与自己的释义矛盾，又给原文添了过去时。
  - 建议：引文照本文作"比丘们，我不退缩地精勤努力"，释义改为"这里的 sudaṃ 只是个虚词，没有特别的意思"，把虚词留在巴利形态上说，不在汉译里给它派一个实义词。

- `100-25-2-12`｜错译／引文与原文不符｜片段「比丘们，我就是这样」
  - 问题：黑体引文对应 `tassa mayhaṃ, bhikkhave`（比丘们，我那……的），本文原句是"比丘们，我那正觉是由不放逸而证得的"。"我就是这样"在原文里没有依据，且后文 `100-25-13-23` 紧接着就释 `appamādādhigatā`，引文错位会让读者对不上。
  - 建议：改为"**比丘们，我那……**"或"**比丘们，我的那个（正觉）**"，以本文层译文的实际用词为准。

### 🟨 warning

- `100-23-93-98`｜关键词语意不明确｜片段「不后退，不退缩」
  - 问题：被释词 `appaṭivānitā` 译"不退缩"，释义词 `anosakkanā` 也译"不退缩"，整句成了"不退缩的意思是：不后退，不退缩"，释义自我循环，读者得不到任何新信息。同一组词在 `100-23-112-124`"不退缩地坚持"、`100-26-50-59`"不退缩的精勤努力"处也混用。
  - 建议：两个词分开：`appaṭivānitā` 作"不退转"，`anosakkanā` 作"不萎缩"或"不松懈"，本句即"不退转的意思是：不后退、不萎缩"。

- `100-23-2-11`｜标点符号使用错误｜片段「两种法……我」
  - 问题：`dvinnāhaṃ` 是 `dvinnaṃ` 与 `ahaṃ` 两个相邻词的连声合写，中间并无省略。用"……"会让读者以为引文中间省掉了一段本文。另"法"（`dhammānaṃ`）不属于这个合写词。
  - 建议：形如"**dvinnāhaṃ** 是 dvinnaṃ（两种的）与 ahaṃ（我）的连写"，省略号去掉。

- `100-23-12-21`｜整句逻辑表达不规范｜片段「知道了它们的功德，也就是知道了、通达了」
  - 问题：`aññāsiṃ` 已译成"知道了"，`jāniṃ paṭivijjhiṃ` 又译成"知道了、通达了"，形成"知道了……也就是知道了"的回环。另"它们的"所指（那两种法）在本句内无先行词。
  - 建议："走近那两种法而了知了它们的功德，也就是亲自认识、通达了它们。"三个动词各给一个不重复的汉语词。

- `100-28-53-56` / `100-28-57-60`｜关键词语意不明确（术语体系错位）｜片段「身苦」、「心苦」
  - 问题：愁悲苦忧恼五支里，`soka` 在 `100-28-41-45` 译"忧愁"，而 `domanassa` 在这里译"心苦"——"忧"在南传通译中正是 `domanassa`，两者交叉会让熟悉通译的读者认错。同时 `dukkha` 的黑体引文加了"身"，与 `100-28-65-68` 的"从苦中"在同一批内不一致。
  - 建议：五支统一作"愁／悲／苦／忧／恼"（或至少首次出现各附巴利原词），引文只写"**苦**""**忧**"，"身体受到压迫的苦""内心受到打击的忧"留在释义里。

- `100-25-38-45`｜整句逻辑表达不规范｜片段「由不放逸而获得了正觉」
  - 问题：`appamādādhigatā sambodhi` 是名词句，`sambodhi` 作主语、"由不放逸而证得"作谓语。译文改成动宾句后主语脱落，且与 `100-25-13-23` 的引文"由不放逸而获得"措辞不接榫——这是同一句本文的两次引用。
  - 建议："“正觉是由不放逸而证得的”。"

- `100-28-29-32`（及 `100-28-33-36`、`100-28-37-40` 同型）｜整句逻辑表达不规范｜片段「指的是诸蕴的生起」
  - 问题：本文此处是离格连用（从生、老、死……解脱），义注释义词 `khandhanibbattito` / `khandhaparipākato` / `khandhabhedato` 也都带 `-to` 离格。译文这几条按主格处理，而到 `100-28-65-68` 又写成"**从苦中**指的是从整个轮转的苦中"，同一串并列词的格处理前后不一。缺 nissaya，格判断仅凭 `-to` 词尾，故按 warning 计。
  - 建议：整串统一，或全部保留离格（"**从生**指的是从诸蕴的生起"），或全部按主格并把 `100-28-65-68` 一并改齐。

### 🟦 suggestion

- `100-26-24-28`｜该引文不宜增字｜片段「那个无上目的」
  - 问题：`tadanuttaraṃ` = `taṃ` + `anuttaraṃ`，没有"目的"这个成分；"目的"是下一句 `uttamattha` 的意思。引文宜保持素净。
  - 建议："**那个无上的**（tadanuttaraṃ）是 taṃ（那个）与 anuttaraṃ（无上的）的连写。"

- `100-25-46-57`｜不常用术语未编写注释｜片段「无上的安稳」
  - 问题：`yogakkhema` 是罕见术语，按 `style.md` 第二节应在首次出现时夹注巴利原词。同段的"证智"（`100-26-35-42`）、"一切知性""轮转与还灭"（`100-28-81-85`）同理。
  - 建议："无上的安稳（yogakkhema）"，其后只用汉译。

- `100-24-77-90`｜修饰关系可更明确｜片段「具备了前面那四支，这样决意下来的精进」
  - 问题：`samannāgatena hutvā` 是具格分词，指"具备四支的人"，而非精进本身具备四支。现译把"具备"挂到了"精进"上，末句又说这精进"叫做具备四支的精进决意"，两处"具备"主体不同却同形。
  - 建议："所以应当知道：由具备前面那四支的人如此决意的精进，就叫做具备四支的精进决意。"

- `100-23-53-64`｜错误多译（轻）｜片段「光明的禅相」
  - 问题：`obhāsanimitta` = 光明相，"禅"字是添加的；上文已另有"禅那"（`jhāna`），两者并列时加"禅"会让读者以为光明相专属禅那。
  - 建议：作"光明相"。

- `100-24-34-42`｜语言风格不统一｜片段「停下来」
  - 问题：`saṇṭhānaṃ` 是名词，本批其余引文（"不知满足""不退缩""正觉"）都按名词或名词性短语处理，这里换成动词短语，体例不齐。
  - 建议：引文作"**停止**"，释义保留"搁置、不再进行、退缩，也就是止息"。

- `100-29-2-4`｜语言风格不统一｜片段「黑法经的注释」
  - 问题：`Kaṇhasutta` 直译为"黑经"；加"法"虽合经义（两种黑法），但与同批 `100-22-2-4`"领悟经"、`100-27-2-4`"结缚经"的素译体例不齐。
  - 建议：统一作"黑经的注释"，或三题一并按内容加字。

- `100-22-2-4` / `100-23-12-21`｜语言风格不统一｜片段「领悟经的注释」
  - 问题：经题 `Upaññāta` 译"领悟"，而正文同词根 `upaññāsiṃ` 译"亲自领悟到"（`100-23-12-21`）。同词根在题与文之间宜呼应。
  - 建议：经题作"亲自领悟经"，或正文首见处夹注巴利原词 `upaññāta`。

- `100-25-2-12`｜语言风格不统一｜片段「凭那条道路所获得的功德」
  - 问题：`paṭipadā` 在 `100-24-91-98` 是"修行之道"，这里是"那条道路"，两句紧邻。
  - 建议：统一为"修行之道"。

- `100-30-2-18`｜语言表达不够流畅｜片段「就这结果上的黑而叫做黑」
  - 问题："就……而叫做……"的框架较生硬，且一句之内"黑"出现四次。
  - 建议："而是因为它们把人导向黑暗的果报，所以从结果上说是黑的。"

- `100-24-25-33`｜语言表达不够流畅｜片段「智慧的力量、智慧的精进和智慧的奋发」
  - 问题：三个"智慧的"连排，略显拖沓。
  - 建议："说的是人在智慧上的力量、精进和奋发。"

- `100-30-25-32`｜语言表达不够流畅（轻微增义）｜片段「心就不再明净了」
  - 问题：原文 `cittaṃ pabhassaraṃ na hoti` 只说"心不明净"，"不再"隐含了心本明净这一前提。虽与 `pabhassara` 的教义脉络相合，仍属译文加出来的判断。
  - 建议："因为它们一生起，心就不明净了。"
