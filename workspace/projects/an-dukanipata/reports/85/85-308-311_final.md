## 理由

**取数情况（降级说明）**：本次评估只注入了本文（mūla）层的巴利原文与译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。按方法文档，缺哪个就降级用剩下的并在理由中交代——因此本报告的准确性判断仅基于巴利原文词法、句法与律藏通行译例（《Parivāra》/《Kaṅkhāvitaraṇī》系统的汉译传统），**不能作为"与义注释义相符"的结论**。特别是 `atthavase`、`āsava` 在此处的释义、以及 `osāraṇīya / nissāraṇīya` 一组的所指，律注有明确解释，未核对即无法定案。信心指数据此压到 62。

**准确性**：句子骨架（主谓宾、`paṭicca` 的因由关系、`paññatta` 与各名词的性数一致）整体处理正确，29 项 `peyyāla` 的羯磨名目无漏项、无多译，顺序与原文一致。扣分集中在两处：`atthavase paṭicca` 被拆译成"目的"与"原因"两重（原文是一个词组、两条理由，不是两种范畴），属于错误多译；`āsava` 译"祸患"与下文 `vera/vajja/bhaya` 的并列关系尚可，但 `āsava` 在律藏此语境指"漏失、流漏"（注释书作"烦恼之漏"或"过失"解），译"祸患"偏弱且与 `bhaya`（恐惧）之外的 `vajja`（罪过）界限模糊——未核义注故按 warning 而非 error 计。

**风格**：现代书面汉语的要求基本达成，无"此中/故为/彼等"一类硬禁例。但仍有几处单音节文言残留与半文半白句式（"为了摄持律"、"为了正法的久住"），以及"自恣"这一古译用字（现代读者无法辨识，且与"自恣"的本义 pavāraṇā=邀请/自由陈请 相去甚远）。标点与全角规范合格，无 ASCII 引号，无残留工作标记。

**一致性**：309 与 310 两段的 `peyyāla` 公式译文逐字一致，这是本段最关键的一致性要求，达成良好。唯一不一致是夹注策略：309 段给 `āsava` 加了巴利夹注，310 段同一公式复现时未加（这是对的，首次夹注原则），但 310 段的 `mānatta`、`abbhāna` 等却各自都加了夹注——夹注密度在一句内过高，削弱可读性。

## 问题清单

### 🟧 error

- `85-309-2-20`｜错误多译｜片段「是出于这两种目的、针对这两种原因」
  - 问题：`dve atthavase paṭicca` 是"依据两条理由/着眼两种利益"一个意思，`atthavasa`（attha + vasa）本身即"理由、着眼点"。译文把它展开成"目的"与"原因"两个并列范畴，读者会误以为原文列举了两类不同的东西（两个目的 + 两个原因 = 四项），而下文 `Katame dve?` 答的只有两项。属错误多译。
  - 建议：统一作"基于这两条理由"或"着眼这两种利益"，不要拆成双重并列。
- `85-309-93-108`｜错误多译｜片段「正是出于这两种目的、针对这两种原因」
  - 问题：同上，结句重复同一问题；且此句的 `Ime kho` 是回指总结，译"正是"尚可，但双重并列须与起句一同改正。
  - 建议：与 `85-309-2-20` 统一改为"正是基于这两条理由"。
- `85-310-6-107`｜错误多译｜片段「是出于这两种目的、针对这两种原因」
  - 问题：同一误译在 310 段起句复现。
  - 建议：三处（含 `85-310-185-200`）一并统一。
- `85-310-185-200`｜错误多译｜片段「正是出于这两种目的、针对这两种原因」
  - 问题：同上，310 段结句。
  - 建议：同上统一。

### 🟨 warning

- `85-310-6-107`｜关键词语意不明确｜片段「制定了自恣（pavāraṇā）」
  - 问题：`pavāraṇā` 此处即 `pavāraṇa`/自恣日的请举罪制度（犍度中的"自恣"），但"自恣"二字在现代汉语里字面意思是"放纵自己"，与制度实义（请他人举出自己的过失）完全相反，普通读者必然误解。虽属传统译名，仍需注释或改译。
  - 建议：改作"自请举罪（pavāraṇā）"，或保留"自恣（pavāraṇā）"但加简注说明"即于自恣日请僧众举出自己过失"。下文"遮自恣"同步处理。
- `85-309-24-92`｜关键词语意不明确｜片段「为了防堵现世的祸患（āsava）」
  - 问题：`āsava` 译"祸患"偏泛，与同组的 `vajja`（罪过）、`bhaya`（恐惧）界限不清；`āsava` 在律藏此语境有"漏失/过失之漏"的特定所指。此处为二意场合，仅给夹注不足以消歧。**未核义注，无法定案，故按 warning 立条**。
  - 建议：核对义注对 `diṭṭhadhammikānaṃ āsavānaṃ` 的释义后定译；若义注作"烦恼漏"解，宜译"烦恼的流漏"或"过患之漏"。
- `85-309-24-92`｜文言语体｜片段「为了摄持律」
  - 问题：`vinayānuggahāya` 译"摄持律"是半文半白——"摄持"为单音节化的文言复合，且动宾倒装感强，现代读者读来像古文。
  - 建议：改作"为了扶助戒律的施行"或"为了维护戒律"。
- `85-309-24-92`｜文言语体｜片段「为了正法的久住」
  - 问题："久住"为文言单音节化表达（`saddhammaṭṭhiti` = 正法的安住/长存）。
  - 建议：改作"为了正法长久存续"。
- `85-310-111-184`｜文言语体｜片段「为了摄持律」
  - 问题：同 `85-309-24-92`，310 段复现。
  - 建议：与 309 段同步改，保持两段公式逐字一致。
- `85-310-111-184`｜文言语体｜片段「为了正法的久住」
  - 问题：同上，310 段复现。
  - 建议：与 309 段同步改。
- `85-308-1-4`｜关键词语意不明确｜片段「三、律的中略段」
  - 问题：`peyyāla` 指经文的"中略/略说"省文格式（即 `…pe…` 所代表的重复省略），译"中略段"作为章节标题，读者无从知道这是什么。品题处宜加注。
  - 建议：保留"律的略说"并加一句脚注说明 peyyāla 为重复段落的省略体例；或译"律的省文品"。
- `85-311-2-4`｜关键词语意不明确｜片段「律的中略段结束」
  - 问题：同上，与 308 标题呼应，同一术语问题。
  - 建议：与 308 同步定译。

### 🟦 suggestion

- `85-310-6-107`｜语言风格不统一｜片段「制定了波罗提木叉的说出（pātimokkhuddesa，即说戒）」
  - 问题：这一项用了"音译 + 意译 + 夹注 + 又一个意译（即说戒）"四重叠加，而同句其他 28 项都是"汉译（巴利）"两重。风格在同一句内不统一，且"的说出"是生硬的名词化翻译腔。
  - 建议：统一作"说戒（pātimokkhuddesa）"，把"波罗提木叉的说出"这层字面义移入脚注。
- `85-310-6-107`｜语言表达不够流畅｜片段「制定了别住的给予（parivāsadāna）」
  - 问题：`-dāna` 的"的给予"是直译的名词化结构，汉语不自然；同句"制定了摩那埵（mānatta）的给予"同病。
  - 建议：改作"制定了给予别住（parivāsa）的办法"，或径作"制定了别住羯磨"。
- `85-310-6-107`｜该使用而没有使用术语标记｜片段「制定了召入（osāraṇīya）……制定了驱遣（nissāraṇīya）」
  - 问题：这一对是律藏专门术语（召入众/摈出众），"召入""驱遣"是字面义译，与前后"羯磨"系列的译名体例不一致，且无注释，读者难以归入羯磨法体系。
  - 建议：核义注后定作"召入羯磨（osāraṇīya）""摈出羯磨（nissāraṇīya）"，或加简注。
- `85-310-6-107`｜复杂的嵌套句整句语言逻辑理解困难｜片段「对于尚未制定的作了制定……对于已经制定的作了随制」
  - 问题：`apaññatte paññattaṃ / paññatte anupaññattaṃ` 的"作了制定""作了随制"过于凝缩，"随制"未加夹注（同句其他术语都有），读者不易理解这是"追加补充规定"。
  - 建议：改作"对尚未制戒之处作了制戒……对已制之戒作了随制（anupaññatti，即补充规定）"。
- `85-310-6-107`｜语言表达不够流畅｜片段「制定了本日治（mūlāya paṭikassana）」
  - 问题：古译"本日治"现代读者完全无法索解（义为"退回原点重算别住日数"），同句的"下意羯磨""苦切羯磨"亦同类，但本条最不透明。
  - 建议：保留古译并加脚注解释，或在夹注里加极简释义。
- `85-309-24-92`｜语言表达不够流畅｜片段「为了僧团的美好」
  - 问题：`saṅghasuṭṭhutā` 译"美好"偏虚，汉语读来像评价性形容，不像制戒理由（义为"僧团的完善/妥善"）。
  - 建议：改作"为了僧团的完善"。
- `85-310-185-200`｜语言表达不够流畅｜片段「如来为弟子们制定如草覆地」
  - 问题：`tiṇavatthāraka` 是灭诤法名，直接作"制定如草覆地"动宾搭配，缺少类名支撑，读来不成话。
  - 建议：改作"制定如草覆地（灭诤）法"。
