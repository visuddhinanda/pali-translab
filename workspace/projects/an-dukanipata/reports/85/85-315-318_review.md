# Review — 85:315-318（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（仅 85-315-6-48、85-315-49-51、85-317-2-4、85-318-2-4 四句有 nissaya）

## 跨段一致性
- 校勘注版本略称：§316 的 sī.／syā.／kaṃ. 分别译为“僧伽罗本／暹罗本／柬埔寨本”，但 pī. 保留了原略称“pī. 本”，同一条注里的处理方式前后不一致。pī. 在 VRI 校勘体例中指 PTS（巴利圣典协会）本，建议统一意译为“PTS 本”。
- 其余无。abhiññāya / pariññāya / parikkhayāya / pahānāya / khayāya / vayāya / virāgāya / nirodhāya / cāgāya / paṭinissaggāya 在各组的起句与结句（含与格 -āya 形和缩略形 -ā）中译法一致；“Katame dve? / Samatho ca vipassanā ca.” 全段统一为“是哪两种呢？／止和观。”

## nissaya 核对结果

**§315 句 85-315-6-48**：无问题。
- 列举的各项烦恼在 nissaya 中都带宾格 `ကို`，例如 `ဒေါသဿ= ဒေါသကို`、`မောဟဿ= မောဟကို`。这说明巴利属格（-assa / -āya）是 abhiññāya 的宾语，译文“为了证知瞋……放逸”中“证知”和对象的关系是对的。
- 各词的义读与 nissaya 相符：
  - kodha = 生气（`စိတ်ဆိုးခြင်း`），译“忿”
  - upanāha = 结怨（`ရန်ငြိုးဖွဲ့ခြင်း`），译“怨”
  - thambha = 因忿与慢而粗硬，译“刚硬”
  - sārambha = 力求胜过他人两倍三倍的慢，译“争胜”
  - atimāna = 过分高看自己的慢，译“过慢”
  - mada = 慢的醉傲，译“憍”
  - pamāda = 忘失、懈怠，译“放逸”
- “（中略）”只放在“瞋”之后，与原文 pe 的位置一致。

**§315 句 85-315-49-51**：无问题。

**§317 句 85-317-2-4**：无问题。nissaya 解作 `ရာဂပုဒ်၏ မြှုပ်ကွက်သည်`（“贪”这一项的略说部分，主格）、`နိဋ္ဌိတံ= ပြီးပြီ`（完毕），与“贪略说结束”相符。

**§318 句 85-318-2-4**：无问题。nissaya 主释为“二集巴利圣典”。异释 `ဝါ=` 解作“收录两两成组之法的章节”，按 style.md 可在脚注中备列，不必改动正文。

## 原文／nissaya 数据疑问（记录，不改）
- 85-315-6-48 的 nissaya 中，`ဧကာဓဿ` 应是 `ကောဓဿ`（kodhassa）之讹；`မေးလျော့ခြင်း` 应是 `မေ့လျော့ခြင်း` 之讹。这两处不影响译文。
- 85-315-6-48 的末行 `အဘိညာယ ဒွေ ဓမ္မာ ဘာဝေတဗ္ဗာ=` 释义为空，nissaya 在这里不完整。
