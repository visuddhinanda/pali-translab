## 理由

**基准缺失（影响信心）**：本次只注入了巴利原文与 channel 译文，**未提供义注（aṭṭhakathā）与 nissaya**。因此：
- 「释义是否与义注相符」只能依据复注自身引用的义注片段（`‘‘jāṇussoṇīti ṭhānantaraṃ kirā’’`、`‘‘rañño santike ca laddhajāṇussoṇisakkārattā’’`、`‘‘uppaṭipāṭiyā…byañjananti vuccatī’’`、`‘‘ubhayametaṃ pāḷiyāva nāman’’`）作间接判断；
- **「被解释词与父层逐字同译」这条硬约束本次无法核验**——复注黑体引自义注，没有义注译文就无法比对 `Ādimhi` / `Koṭiyaṃ` / `Vihāraggena` / `Dunnikkhittaṃ` / `Pāṇehi upetaṃ` 等黑体词是否与义注层译法一致。下轮应带义注译文重评。
- 下列扣分均基于巴利词法与复注内部自洽性，不依赖缺失资源；信心指数据此压到 62。

**准确性（78）**：主要问题集中在两处词法，且都成系统：
1. **karmadhāraya 复合词被译成属格关系**。段 92 三句的释词公式是 `upāsakova ratanaṃ` / `upāsakova padumaṃ`——复注明说「优婆塞本身就是珍宝/红莲」，即同格释（这位优婆塞即珍宝），译文自己上半句也这样译了；但黑体词却落成「优婆塞**中的**珍宝／红莲／白莲」，变成「众优婆塞里的那一个」，与紧邻的释义自相矛盾。属 error 第 3 类（修饰关系错译），同一句内前后打架，读者会以为复注在讲别的事。
2. **`upeta` 的主宾关系倒置**。段 94 两句把 `saraṇaṃ upetaṃ`（归依被趣向／归依与命相连）译作「（我）与归依相连」，又把阳性现在分词 `Upento`（趣向归依的**人**）译作抽象的「这种相连」。句义大体方向未失（终身不只是口头），但施受关系与词性都读反了，且错误从前句传染到后句。

其余各句释义取向可靠：`pada` / `byañjana` 译「句」/「文」合传统法相译法；`pakaṭṭhānaṃ vacanappabandhānaṃ āḷiyeva pāḷi` 的 āḷi–pāḷi 语源双关处理得当（「言语篇章排成的行列（āḷi）」）；`kakudhabhaṇḍa` 译「王家标志的器物」、`ṭhānantara` 译「官位」、`purohita` 夹注「国师（purohita）」均无误；`uttāna`、`natthi vattabbaṃ` 一类套语译法准确自然。

**风格（88）**：**无文言腔**——通查未见「此中／故为／彼等／是故／于…之际／答以」一类禁例，单音节文言虚词也未出现，符合 `knowledge/style.md` 第一节硬约束。标点全为全角，引号统一「“ ”」，译文内无 ASCII 引号，JSON 安全。译文中也无候选、待定、问号等工作标记。扣分来自两处汉语不规范：「被颠倒次序地」（「被…地」不成句）、「受持得次序错乱」（「得」字结构别扭），以及「舍出生命」这类半生造搭配。

**一致性（80）**：被解释词的处理体例不统一是主要失分点——绝大多数黑体词给出汉译（「与命相连」「一个官位」「句」「文」），但 `182-93-31-36` 的 `Ajjataṃ` 直接留巴利转写「**ajjataṃ**」，而该词可直译；同一词在同句内两译（`koṭi`→「顶端」又「尖头」，`dunnikkhitta`→「受持得次序错乱」又「放置得不好」），使读者看不出后半句正是前面黑体词的释义。另外「圣典」首现（`96-42-57`）未夹注巴利原词，到第三次出现（`96-58-63`）才补「圣典（pāḷi）」，夹注位置与 style 第三节「首次出现附巴利原词」相反。引述义注的提示语「义注说…等等这段话」全段统一，这一点良好。

## 问题清单

### 🟧 error

- `182-92-7-17`｜错译（修饰关系）｜片段「优婆塞中的珍宝」
  - 问题：`upāsakaratanaṃ` 是同格复合（karmadhāraya），复注用 `upāsakova ratanaṃ` 明确标出「这位优婆塞**就是**珍宝」，译文上半句也如此译；黑体词却作「优婆塞**中的**珍宝」，改成属格关系（众优婆塞里的珍宝），与本句释义直接矛盾。
  - 建议：黑体词改为「**优婆塞珍宝**」或「**如珍宝的优婆塞**」，与前半句「这位优婆塞本身就是珍宝」呼应。
- `182-92-18-22`｜错译（修饰关系）｜片段「优婆塞中的红莲」
  - 问题：同上，`upāsakapadumaṃ` 为同格复合，`upāsakova padumaṃ` 已排除属格解。
  - 建议：改为「**优婆塞红莲**」或「**如红莲的优婆塞**」。
- `182-92-23-25`｜错译（修饰关系）｜片段「优婆塞中的白莲」
  - 问题：`upāsakapuṇḍarīko` 承前两句的同格释（`Tathā`＝同样），译文沿用了错误的属格译法。
  - 建议：改为「**优婆塞白莲**」或「**如白莲的优婆塞**」，三处用同一构词译法。
- `182-94-40-52`｜错译（修饰关系／主宾倒置）｜片段「就一直与归依相连」
  - 问题：`tāva saraṇaṃ upetaṃ` 的中心语是 `saraṇaṃ`（中性主格）、`upetaṃ` 是其表语——「归依就一直是（与命）相连的／归依就一直持续」。译文把人当作与归依相连的一方，关系反了；复注此句正是要说明 sutta 中「归依」才是被 `pāṇehi` 修饰的对象。
  - 建议：改为「只要我的命还在，这一归依就一直相随（存续）」。
- `182-94-53-70`｜错译（词义／词性）｜片段「而这种相连并不只是口头上说一说」
  - 问题：`Upento` 是阳性主格现在分词，指**趣向归依的人**，不是「这种相连」这一抽象状态；下文「也终身与它相连」同样沿用了上一条的倒置读法（应为「归依终身相随」）。
  - 建议：改为「而且，趣向归依的人并不只是口头上说一说，也不只是一次心念生起而已，而是即使舍弃生命，这一归依也终身相随——这里的意思应当这样理解」。

### 🟨 warning

- `182-94-2-39`｜关键词语意不明确｜片段「尊奉那三种对象」
  - 问题：`vatthuttaya` 指佛、法、僧三事（三宝），「三种对象」过于空泛，普通读者读不出所指。
  - 建议：改为「尊奉佛、法、僧三宝」或「尊奉那三事（佛、法、僧）」。
- `182-94-2-39`｜代词指代不明确｜片段「表明他的归依是以生命为限的」
  - 问题：「他」在本句首次出现时尚无先行词，婆罗门要到后半句才点出；读者需回读才能确定指代。
  - 建议：前移身份，如「表明这位婆罗门的归依是以生命为限的」，后文再用「他」。
- `182-93-6-9`｜关键词语意不明确（同词异译）｜片段「用于顶端」
  - 问题：黑体词译「顶端」，紧随的释义 `pariyantakoṭiyaṃ` 却译成「末端的尖头」，同一个 `koṭi` 在一句内两种说法，释义与被释词的对应关系被切断。
  - 建议：统一用字，如「**用于末端**，就是用在边际的末端这个意思上」。
- `182-96-6-15`｜关键词语意不明确（同词异译）＋汉语语病｜片段「受持得次序错乱」
  - 问题：黑体词 `dunnikkhittaṃ`（恶置、安置得不好）被提前意译为「受持得次序错乱」，把后面才给出的 `padapaccābhaṭṭha`（词句倒置）塞进了被释词；而紧接的释义又作「放置得不好」，前后两译并列，读者看不出是同一词。另「受持得次序错乱」的「得」字结构不合现代汉语。
  - 建议：黑体词改为「**安置得不好**」，释义顺接「就是放置得不妥，把词句前后倒置后记在心里」。
- `182-96-29-41`｜不导致误解的汉语语病｜片段「被颠倒次序地」
  - 问题：「被……地」不成句，`uppaṭipāṭiyā` 是具格状语「按颠倒的次序」。
  - 建议：改为「**“按颠倒的次序……（中略）……所以叫做文”**」。
- `182-96-42-57`｜整句逻辑表达不规范（引文内补译）｜片段「句和文这两个名称，说的都是圣典」
  - 问题：义注原引文为 `ubhayametaṃ pāḷiyāva nāmaṃ`（「这两者都只是圣典的名称」），译文把「句和文」直接写进了黑体引文内部。黑体引文须与义注层逐字同译，补充成分不应进引号。
  - 建议：引文回归「**“这两者都只是圣典的名称”**」，需要点明时在引文外加「即句与文」。
- `182-93-31-36`｜体例不一致（被解释词未译）｜片段「ajjataṃ」
  - 问题：全段其余黑体被解释词都给出汉译，此处独留巴利转写；`ajjataṃ` 并非罕见或有争议的术语，可直译。复注要点是「`ajjataṃ` 与 `ajja` 同义」，纯音译使这层说明落空。
  - 建议：改为「**今天**，意思就是“今天”（ajjataṃ 即 ajja）」一类写法，保持被解释词有汉译。

### 🟦 suggestion

- `182-95-6-28`｜不常用术语缺注｜片段「生漏」
  - 问题：Jāṇussoṇi 为人名／官位名，汉译界并存「生漏」「生闻」两种，且本段内容正是在讲这个名字的由来；不附巴利原词，读者无法对应，也看不出「生漏位」这一官位名的音译来历。
  - 建议：首次出现夹注，如「**生漏（jāṇussoṇi）**」。
- `182-96-42-57`｜夹注位置｜片段「并没有另外一个叫做圣典的东西」
  - 问题：「圣典」首现于此却未夹注巴利原词，到 `182-96-58-63` 第三次出现才补「圣典（pāḷi）」，与 style「首次出现附巴利原词、其后只用汉译」相反。
  - 建议：把夹注移到本句首现处，后文去掉重复夹注。
- `182-92-7-17`｜夹注过长｜片段「四众（parisā，指比丘、比丘尼、优婆塞、优婆夷）」
  - 问题：圆括号内除巴利原词外还加了四众的列举，属译者补释，体例上超出「夹注只附巴利原词」的约定，也使句子中段变重。
  - 建议：括号内只留「（parisā）」，四众的说明若要保留，放段后注释。
- `182-93-10-30`｜补译｜片段「按各个居住处所的份额来分配」
  - 问题：「来分配」是原文没有的补足动词（`taṃ taṃ vasanaṭṭhānakoṭṭhāsena` 只是具格「按各住处的份额」）。语境上虽成立，但 style 第六节不主张擅自补足。
  - 建议：改为「就是按各个居住处所的份额（来算）」或直接收在「按各个居住处所的份额」。
- `182-94-2-39`｜表达不够流畅｜片段「即便舍出生命」
  - 问题：「舍出生命」搭配生硬，`pariccajana` 常译「舍弃／舍命」。
  - 建议：改为「即便舍弃生命」。
