## 理由

**资源情况（影响信心）**：本次只注入了巴利原文与目标 channel 译文。被评的 book=100 本身就是义注层，而**其父层（本文 AN 经文）译文与复注均未提供**，**nissaya 也未提供**。因此两项关键基准缺位：
1. 无法核对「黑体被解释词与父层逐字同译」这条硬约束——下面相关条目按义注文本自身的结构判定（黑体词是否吞并了注释内容），不是与本文译文字面比对；
2. 格、句法角色、隐含成分无 nissaya 可校，词法判断只能依原文自身形态。
故信心压在 70。

**准确性**：主谓宾判断整体正确，没有违背教理的句子，**无 fatal**。四种 agatigamana（chanda / dosa / moha / bhaya）在分配物品与裁决事务两个场合的对应关系全部译对；`100-184-84-107` 与 `163-187` 两处引语内的"若给…则会害我""若判为重罪则会害我"的施受关系也处理正确；`100-185` 一长串释词逐条对得上。主要扣分在一类系统性问题：**释词的黑体部分把注释内容并了进去**（gambhīrā→"文句深奥的"、lokuttarā→"阐明出世间法义的"、paṭivicaranti→"也不为求问而四处寻访"、bāhirakā→"教法之外的"、sāvakabhāsitā→"各家弟子所说的"），结果黑体词已带着释义，后半句的"就是…"变成同义反复，且必然与本文层的朴素译法脱钩。另有两处 `Itaraṃ`（"另一词"）被径自替换成推定的词并加粗。

**风格**：**现代书面汉语达标，全段未见文言腔**——无"此中/故为/彼等/于…之际/答以"等禁例，"就/于是/这就叫做"等均为现代写法；标点全角，`zh` 字段内无 ASCII 引号，JSON 安全。扣分在：`100-185-59-66` 残留了一处句法注"（原文此处为处格）"，按 `style.md` 四、句法注只作译者参考、不进正文；以及"叫做四种走偏的做法一种也不犯"这类句子的汉语不顺。

**一致性**：同一概念 agati / agatigamana 在段内出现三种译法——"不应行的事"（黑体词）/"不应行之处"/"走偏的做法"，这是 harmonize 本应拉平的；akkhara 与 byañjana 都译作"字句"，两词的区别被抹掉；āpatti 在 `term-glossary.jsonl` 登记为"犯"，译文一律用"罪"（重罪/轻罪/出罪）——属已登记译法与实际用法不符，须二选一定案。

## 问题清单

### 🟧 error
- `100-185-19-24`｜错误多译｜片段「**文句深奥的**，是就文句而言深奥」
  - 问题：黑体被解释词只是 `gambhīrā`（深奥的），"文句"来自注释 `pāḷivasena`，被提前塞进了黑体词，导致"文句深奥的…就文句而言深奥"同义反复，也使黑体词无法与本文层的"深奥的"逐字对上。
  - 建议：黑体保持为与本文一致的"深奥的"，释义仍作"是就（圣典）文句而言深奥"。
- `100-185-31-35`｜错误多译｜片段「**阐明出世间法义的**，就是把出世间的意义显示出来的」
  - 问题：`lokuttarā` 本身只是"出世间的"，"阐明…法义"是注释 `lokuttaraatthadīpakā` 的内容，被并入黑体词，整句成为自我循环。
  - 建议：黑体改为"出世间的"，后半保留"就是显示出世间之义的"。
- `100-185-122-130`｜错误多译｜片段「**也不为求问而四处寻访**，就是不为了求问而外出游访」
  - 问题：`na ca paṭivicaranti` 的黑体部分不含"为求问"（它来自注释 `pucchanatthāya`），并入后与释义重复，且与本文层用词脱钩。
  - 建议：黑体按本文作"也不（反复）寻究"之类不含目的状语的译法，目的留在释义里。
- `100-185-73-76`｜错误多译｜片段「**属于诗作的**是它的同义词」
  - 问题：原文是 `Itaraṃ`（指"另一个词"），译文径自补出所指词并加粗。该词的译法未经本文层核对，属于在义注里增设原文没有的被解释词。
  - 建议：译作"另一个词是它的同义词"；若确要点明所指，补出的词必须与本文层译法逐字一致，并以非黑体或括注形式出现。
- `100-185-81-84`｜错误多译｜片段「**文采绚丽的**是它的同义词」
  - 问题：同上，`Itaraṃ` 被替换为推定词并加粗。
  - 建议：同 `100-185-73-76` 处理。

### 🟨 warning
- `100-185-59-66`｜不该出现的工作标记｜片段「（原文此处为处格）」
  - 问题：句法注漏进了正文译文。`style.md` 四明确：句法注只作译者参考，不进正文；译文里不得留任何工作标记。
  - 建议：删去该括注；需要交代格位就压低该句 confidence 或写进报告，正文用"在那些应该学习、应该熟习的（法）上"即可。
- `100-184-108-133`｜整句逻辑表达不规范｜片段「这样的人就叫做四种走偏的做法一种也不犯」
  - 问题："叫做"后面接一个完整的否定小句，汉语不通；"四种…一种也不犯"与"叫做"搭配失当。
  - 建议：改为"这样的人就是四种偏行一种也不犯"或"这样的人不犯四种偏行中的任何一种"。
- `100-184-188-200`｜整句逻辑表达不规范｜片段「这样的人就叫做四种走偏的做法一种也不犯」
  - 问题：同上，同一病句复现。
  - 建议：与 `100-184-108-133` 一并改成同一句式。
- `100-184-20-30` / `100-184-35-44`｜关键词语意不明确｜片段「因为偏爱而走上不应行之处（agati）」、「这四种走偏的做法」
  - 问题：agati / agatigamana 是定型教法项目（四种偏行），段内出现"不应行的事"（黑体）、"不应行之处"、"走偏的做法"三种译法；"走偏的做法"过于口语、丢掉术语感，且与黑体词不一致。
  - 建议：全段统一一个术语（如"偏行／非正行"），黑体词与叙述用语保持同一词形；三处以上需回到 harmonize 统一。
- `100-185-73-76` / `100-185-81-84`｜代词指代不明确｜片段「是它的同义词」
  - 问题："它"指前一个被解释词，距离较远且中间夹有释义，普通读者难以定位。
  - 建议：明写"是前一词的同义词"或点明所指词名。
- `100-185-77-80` / `100-185-131-140`｜关键词语意不明确｜片段「**字句华美的**，就是字句绚丽多彩的」、「这个字句应该怎样安立」
  - 问题：`akkhara`（字／音节）与 `byañjana`（文句／辅音）都译成"字句"，两词的分别被抹平；`cittakkharā` 与 `cittabyañjanā` 的对举随之失效（后者在 `100-185-81-84` 又作"文采绚丽的"）。
  - 建议：akkhara 作"字（音）"、byañjana 作"文句"，两条释词与 `131-140` 的"字句"一并校准。
- `100-184-134-145` / `100-184-155-162`｜术语与已登记译法不符｜片段「把自己所照顾的人所犯的重罪说成轻罪来讲」、「不懂得犯戒之后的出罪办法」
  - 问题：`term-glossary.jsonl` 将 āpatti 登记为"犯"（status: confirmed），译文一律用"罪"（重罪／轻罪／出罪）。规则 `translation-rules.md` 一.2 规定术语以项目术语表为先。
  - 建议：要么按术语表改为"重犯／轻犯／出犯（āpattivuṭṭhāna）"，要么把"罪"定为正式译法并更新术语表——不能两套并存。
- `100-185-85-89` / `100-185-90-96`｜整句逻辑表达不规范｜片段「**教法之外的**，就是处在佛陀教法之外的」、「**各家弟子所说的**，就是由各个教派的弟子们所说的」
  - 问题：与上面 error 条同源但程度较轻：黑体词已吸收注释信息（"教法"来自 `sāsanato`，"各家"来自 `tesaṃ tesaṃ`），释义沦为复述。
  - 建议：黑体按本文作"外（道）的""弟子所说的"，补充信息留在释义中。

### 🟦 suggestion
- `100-185-12-18`｜语言表达不够流畅｜片段「**不经提问受训导**，就是不经过提问而受到训导」
  - 问题："不经提问受训导"可能被误读成"没有受到训导"；且黑体与释义几乎同字复述，读者得不到额外信息。
  - 建议：黑体作"不是以反问受训导的"，释义展开为"不是通过（师徒）往复提问而受教导的"。
- `100-184-45-61`｜语言表达不够流畅｜片段「分配的人见自己所照顾的比丘分到了不合心意的物品」
  - 问题：原文是处格独立结构（物品落到某人份上），译文补入"见"这一感知动作，略多于原文；补主语"分配的人"本身属语义必须，可保留。
  - 建议：改为"自己所照顾的比丘分到了不合心意的物品时"，去掉"见"。
- `100-185-166-170`｜语言表达不够流畅｜片段「**没有讲明白的**，就是没有被讲清楚的」
  - 问题：黑体与释义同义复述，汉语里看不出 `anuttānīkata` 与 `apākaṭaṃ kataṃ` 的差别，且被动式"没有被讲清楚的"略生硬。
  - 建议：黑体作"没有显明的"，释义作"就是没有讲清楚的"，两层用词分开。
- `100-185-184-187`｜不常用术语编写注释或者百科｜片段「正面的那一类，应当按照上面所说的相反讲法来理解」
  - 问题：`sukkapakkha`（白分／善的一面）是成对术语（对 kaṇhapakkha），译作"正面的那一类"虽通俗但丢术语且首次出现无注；"相反讲法"略拗。
  - 建议：译为"善（白分）的那一面，应按上文所说反过来理解"，并为 sukkapakkha 加一次夹注或注释。
- `100-184-20-30`｜不常用术语编写注释或者百科｜片段「因为偏爱而走上不应行之处（agati）」
  - 问题：句内同时出现整词夹注"（chandāgatiṃ gacchanti）"与单词夹注"（agati）"，一句两处夹注偏密；agati 作为非独立术语夹注价值有限。
  - 建议：保留 chandāgati 的首次夹注，删去句中的"（agati）"。
