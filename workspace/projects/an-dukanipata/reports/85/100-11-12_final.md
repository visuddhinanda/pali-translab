## 理由

**基准可得性（影响信心）**：本次评估的待评层次本身就是义注（book 100, 1. Vajjasuttavaṇṇanā），注入数据中**没有 nissaya**（无 `type=nissaya` channel 数据），也**没有被注释的本文（mūla）译文**。因此两条基准都缺：
- 词级格/句法只能靠巴利原文自行判读，无 nissaya 交叉核对；
- **被解释词（黑体）与父层逐字同译**这一硬约束**无法验证**——涉及 `Pāpako` / `Dukkho` / `Kiñca taṃ` / `Yāhaṃ` / `Suddhaṃ attānaṃ pariharati` / `Etaṃ pāṭikaṅkhaṃ` / `Yaṃ` 等全部黑体引词。问题清单中与此相关的条目（`100-11-20-24`、`100-12-25-34`、`100-12-35-46`）只能按"自身是否可读、是否混入注释内容"判定，等本文译文到位后需再核一遍。信心分主要因此压低。

**准确性**：绝大多数句子取义正确，`100-12-57-68`（道=正在解脱／果=已经解脱）、`100-12-77-95`（漏尽者旧业只在此生成熟、来世无业果）这类有教理分量的句子处理准确，三恶行／三善行的"三种／四种"数目与 `pāṇātipātādi` / `musāvādādi` / `abhijjhādi` 的对应都对，`akusalaṃ kāyakammaṃ` 与 `akusalakammaṃ` 的差别也如实跟随了原文，没有拉平。扣分集中在一处**反复出现的修饰关系误读**：`suddhaṃ attānaṃ pariharati` 的 `suddhaṃ`（及 `suddhaṃ nimmalaṃ`）是修饰 `attānaṃ` 的形容词，意思是"维持（保有）清净的自己"，译文一律处理成"守护自己的清净"，把形容词当成了名词宾语；在 `100-11-115-133` 加上 `nimmalaṃ` 后变成"自己的清净无垢"，汉语已明显拧住。此句是本段（也是本经）的核心句式，四处连带，故按 error 计。另有一处增译（"三宝"）与一处时态偏移（`parimuccissati` 未来式译成完成口吻）。

**风格符合度**：整体是现代书面汉语，没有出现"此中／故为／彼等／是故"等禁例，标点全为全角，译文内无 ASCII 引号、无任何残留工作标记（候选／待定／TODO 均无），这几条硬约束均通过。扣分点：`100-11-87-114` 连用"以…、以…、以…"的工具格文言虚词串（style.md 第一节明列 `以` 作文言虚词时禁用）；`pariyāyato / nippariyāyato` 译作"不彻底／彻底意义上"，对普通读者易误读为"清净得不够"，而这两个词的实义是"方便（间接、有条件）说"与"究竟（直接）说"；`100-11-115-133` 五个"让它们…"排比读起来偏机械。

**一致性**：术语内部基本统一（漏尽者、阿罗汉道／阿罗汉果、三种／四种…前后一致）。扣分在两处混用：`sotāpatti` 取意译"入流"而 `arahatta` 取音译"阿罗汉"，且"入流道／入流果"属法相术语首次出现而未夹注巴利原词；被解释词的处理方式也不统一——多数译出汉语，`100-12-35-46` 独留巴利词形 `yaṃ`。

## 问题清单

### 🟧 error

- `100-11-66-78`｜错译（修饰关系）｜片段「守护自己的清净」
  - 问题：`suddhaṃ` 是修饰 `attānaṃ` 的形容词（suddhaṃ attānaṃ = 清净的自己），不是 `pariharati` 的名词宾语。译文把被解释词改读成"守护……的清净"，与原文词法不符；后半句"这里的清净有两种"对应 `duvidhā suddhi`，本身正确，不受影响。
  - 建议：被解释词改为「**保持自身清净**」（或「**维持清净的自己**」），后半句保留不动。同一句式在 `100-11-79-86`、`100-11-87-114` 的「在不彻底的意义上守护自己的清净」处一并改为「…保持自身清净」。

- `100-11-115-133`｜错译（修饰关系）｜片段「守护、照料自己的清净无垢」
  - 问题：`suddhaṃ nimmalaṃ attānaṃ pariharati paṭijaggati` 中 `suddhaṃ nimmalaṃ` 双形容词修饰 `attānaṃ`，意为"守护、照料清净无垢的自己"。译成"自己的清净无垢"后，宾语成了抽象名词串，汉语也不成话。
  - 建议：改为「…就是在究竟的意义上守护、照料清净无垢的自己」。

### 🟨 warning

- `100-11-66-78`｜关键词语意不明确（二意场合无注释）｜片段「不彻底意义上的（pariyāyato）和彻底意义上的（nippariyāyato）」
  - 问题：`pariyāyato / nippariyāyato` 指"方便说（间接、带条件的说法）／究竟说（直接、无保留的说法）"，是说法层次之分，不是清净程度之分。"不彻底／彻底"会让普通读者读成"清净得不够完全"，而下文恰恰把入流道乃至阿罗汉道都列入 `pariyāyato`，照这个译法会读出"阿罗汉道的清净不彻底"的邪见风险。
  - 建议：改为「方便（间接）意义上的（pariyāya）和究竟（直接）意义上的（nippariyāya）」，并在首次出现处加一句注释说明二者是说法层次之别；后续 `100-11-79-86`、`100-11-87-114`、`100-11-115-133` 的"不彻底／彻底的意义上"同步替换。

- `100-11-79-86`｜增译（原文无对应词，轻度多译）｜片段「归依（saraṇagamana）三宝」
  - 问题：原文只有 `saraṇagamanena`，"三宝"是补出的。义注语境确为三归依，故不至于错，但 style.md 要求不擅自补足；补充成分也应与夹注形式区分开。
  - 建议：改为「因为归依（saraṇagamana），就叫做…」，需要交代对象时放进脚注，而不是写进正文。

- `100-11-87-114`｜文言语体｜片段「以五戒、以十戒——以四种遍净戒，以初禅」
  - 问题：连用工具格虚词"以"，属 style.md 第一节禁例（`以` 作文言虚词时）；一句之内出现六七次，语体明显偏半文半白。
  - 建议：改为「同样，通过五戒、通过十戒——通过四遍净戒，通过初禅……通过非想非非想处，通过入流道、入流果……通过阿罗汉道，也都叫做…」。

- `100-12-25-34`｜被解释词混入注释内容（整句逻辑表达不规范）｜片段「**必定可以期待这样的结果**」
  - 问题：被解释词只是 `etaṃ pāṭikaṅkhaṃ`（这是可以期待的），"必定"来自后面的注释词 `avassaṃbhāvī`。把注释结论塞进黑体引词，一方面与本文逐字同译的硬约束冲突，另一方面使"意思是：…这是必然会实现的"变成同语反复。
  - 建议：黑体改为「**可以期待这样的结果**」（最终以本文译文为准逐字对齐），注释部分保持「这是应当期待的，这是必然会实现的」。

- `100-12-47-51`｜不导致误解的汉语语病（时态偏移）｜片段「他是由于什么原因解脱的呢」
  - 问题：`parimuccissati` 是未来式，上一句已译作"他将从一切过失中解脱出来"，这里转成"…解脱的呢"的完成口吻，前后时间指向不一致。
  - 建议：改为「那么，他将由于什么原因解脱呢？」。

- `100-11-20-24`｜关键词语意不明确｜片段「**使我**，意思是“由于那个原因，我……”」
  - 问题：黑体"使我"单看不成词、方向也可疑（`yāhaṃ` = `yaṃ ahaṃ`，义注释作 `yena ahaṃ`"由于那个原因，我…"，并无"使"的致使义）；注释部分以省略号收尾，句子残缺，读者无法知道省略了什么。
  - 建议：黑体按本文译文逐字对齐（如「**我由于……**」），注释改为「意思是：由于那个原因，我（才会…）」，把承接的动词从本文补回来，去掉悬空省略号。

### 🟦 suggestion

- `100-11-87-114`｜该使用而没有使用术语标记／语言风格不统一｜片段「以入流道，以入流果……以阿罗汉道」
  - 问题：`sotāpatti` 取意译"入流"，`arahatta` 取音译"阿罗汉"，同一组道果术语两套路线；且"入流道／入流果"属法相术语首次出现，未按 style.md 夹注巴利原词。
  - 建议：首次出现写「入流道（sotāpattimagga）」「入流果（sotāpattiphala）」，并把该组译名定案后补进 `knowledge/terms.md`。

- `100-11-115-133`｜复杂嵌套句对读者不友好／不常用术语无注释｜片段「让它们吃嚼食、让它们吃正食、让它们坐下、让它们躺卧」
  - 问题：五个"让它们"排比机械；"嚼食／正食"（khādanīya／bhojanīya）对一般读者不明确。
  - 建议：合并主语，如「给已断根的五蕴洗浴、喂它们吃嚼食和正食、让它们坐下躺卧时」，并为"嚼食／正食"加一条简注（副食／主食）。

- `100-11-32-38`｜代词指代可能不够明确｜片段「就是与那相反的三种善业」
  - 问题："与那相反"的"那"回指上一句的"身的恶行"，跨句指代偏弱，汉语也略生硬；`100-11-46-52`、`100-11-59-65` 同样处理。
  - 建议：分别写作「与身恶行相反的」「与语恶行相反的」「与意恶行相反的」，或改为「与之相反的」。

- `100-12-35-46`｜语言风格不统一｜片段「**yaṃ**，只是一个语助词」
  - 问题：其余被解释词均译出汉语，此处独留巴利词形，与 style.md"显示巴利原文：否"及黑体逐字同译的处理方式不一致。
  - 建议：改为「**那**（yaṃ），只是一个语助词；…」，具体用字与本文译文对齐。

- `100-12-15-18`｜语言表达不够流畅｜片段「**畏惧过失的人**，就是害怕过失的人」
  - 问题：原文 `vajjabhīruno ti vajjabhīrukā` 本身就是近义换词，但汉语照搬后成了同语反复，读者看不出注释做了什么。
  - 建议：释义侧稍作区分，如「就是对过失心存畏惧的人」。

- `100-12-96-97`｜语言风格不统一｜片段「第一经。」
  - 问题：`Paṭhamaṃ` 是卷末的经次标记，直接写"第一经。"在正文末尾略突兀。
  - 建议：统一体例为「（第一经终）」或「第一经〔完〕」，并在 `knowledge/style.md` 里固定这一处理。
