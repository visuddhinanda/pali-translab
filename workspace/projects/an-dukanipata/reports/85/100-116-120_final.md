## 理由

**取数缺口（先交代）**：本次只拿到义注层（book=100）的巴利原文与译文。**nissaya 未取到**，词级格/句法角色无法独立核对；**本文（mūla）层译文也未注入**，而 116–119 段密集出现黑体被解释词（`ko nu kho, bho gotamā` / `na kho ahaṃ` / `tena hi, brāhmaṇa` / `āyasmā` / `ekaṃsena` / `anuvicca` / `viññū` / `garahanti` / `dunnikkhittaṃ padabyañjanaṃ` / `attho ca dunnīto`），**「被解释词与父层逐字同译」这条硬约束本轮无法验证**，问题清单中相关条目已注明「待与本文核对」。准确性分按巴利原文自身可判定的部分给出。

**准确性**：叙事段（116 全段、117-2-6 至 117-102）扣词稳，`ubhayakāraṇenāpi ekaṭṭhāne nibbattiyā kathitattā`、`mānaṃ paggayha siṅgaṃ ukkhipitvā`、`sakavādaṃ pahāya … anuvattitvā`、`dunnayā dunnīhārā dukkathā`（三词三译）都落实了，没有漏句。主要扣分集中在**黑体被解释词的处理方式**：119 段三处 lemma 把义注的释语（`uppaṭipāṭiyā gahita`「颠倒次序地受持」）搬进了被解释词本身，`dunnikkhitta`（安置不当／错置）的字面义消失，结果「X：X 就是 X」成了循环释义，义注「以释语解被释语」的结构被抹平。117-48-89 的 lemma「我不能」与本段末 109-119 的「你不懂这番简略说出的话的意思」互相矛盾——`na kho ahaṃ …` 后面接的应是「不了解／不懂」类动词，「能」字无据。

**风格**：现代书面汉语达标，**未发现文言或半文半白**（无 之/其/乃/便/遂/此中/彼等/者…也 类用法），长句切分得当，口吻统一为第三人称叙述。全角标点与弯引号合规，`句（pada）`、`文（byañjana）` 的夹注格式符合 style.md 第三节。`zh` 字段**未出现 ASCII 引号**，JSON 安全。扣分点是个别处略松（「说坏话」偏口语）、一句双「就」的小语病、章末无句末标点。

**一致性**：`satthā`→导师、`samaṇo gotamo`→沙门乔达摩、`katattā/akatattā`→做了一些事／没有做一些事（116 与 117 两处一致）都稳定。失分在 `dunnikkhitta` 一词同段内出现两种译法（「被颠倒次序地受持」vs「受持得次序错乱」），以及 117-24-47 的「再一次」与「就用同样的说法」语义重复。

## 问题清单

### 🟧 error
- `100-117-48-89`｜错译／义理与注释书不符｜片段「说出了**我不能**等等这段话」
  - 问题：`na kho ahaṃ` 是截断引语，后接动词按本段末 109-119 的解释（`saṃkhittena bhāsitassa atthaṃ ajānanto`）应是「不了解／不懂」，译成「我不能」补出了无据的「能」，且与同段后文的「你不懂……」自相矛盾。
  - 建议：改为与本文黑体逐字同译的形式（如「**我不了解**」），并与 mūla 层该句译文核对后定稿。
- `100-119-2-19`｜导致误解的表达／被解释词混入释语｜片段「**圣典文句被颠倒次序地受持**：被颠倒次序地受持的」
  - 问题：lemma `dunnikkhittañca padabyañjanaṃ` 的「dunnikkhitta」本义是「安置／放置得不好」，译文直接搬用了下文释语 `uppaṭipāṭiyā gahita`（颠倒次序地受持），导致「被解释词＝释义」的循环句，义注的释义动作消失；另 `ca` 未译。
  - 建议：lemma 回到字面（如「**文句安置不当**」），释语保留「被颠倒次序地受持的圣典句」，使「被释—释」两端可区分；并与本文该句译法对齐。
- `100-119-24-32`｜被解释词混入释语｜片段「**义理被颠倒次序地解说**」
  - 问题：同上，`attho ca dunnīto` 的 `dunnīta`（被错误引导／错引）被译成释语里的「颠倒次序」，与后句把 `dunnaya` 译为「难以推引」的词族处理也不一致。
  - 建议：lemma 改为「**义理被错误引申**」一类字面译法，「颠倒次序」只留在释语中。
- `100-119-33-53`｜错误多译｜片段「**比丘们，文句受持得次序错乱，它的义理也就难以正确推引、难以讲说**」
  - 问题：黑体引文只含 `dunnikkhittassa padabyañjanassa atthopi dunnayo hoti`，「难以讲说」来自释语 `dukkathā`，被提前塞进了 lemma（引文多译）；同时「受持得次序错乱」与 119-2-19 的「被颠倒次序地受持」对同一 `dunnikkhitta` 给出两种译法。
  - 建议：lemma 删去「难以讲说」，统一 `dunnikkhitta` 的译法，释语里再给「难以推引、难以引出、难以讲说」三项。

### 🟨 warning
- `100-117-109-119`｜整句逻辑表达不规范（增译）｜片段「所以我才为你详细解说」
  - 问题：巴利只到 `tasmāti attho`——「所以」就是（`tena hi` 的）意思；译文替义注补出了一个原文没有的主句。
  - 建议：改为「……所以。’ 这就是它的意思。」保留义注「某词＝某义」的格式。
- `100-117-48-89`｜漏译｜片段「算了吧」
  - 问题：`alaṃ, bho` 的呼格 `bho` 未译出。
  - 建议：「算了吧，先生」或按自语语境处理为「罢了」。
- `100-117-48-89`｜不导致误解的汉语语病｜片段「既然来到这样一位人物面前，就不该不弄明白就走」
  - 问题：一个分句内两个「就」，加上「不该不……」双重否定，读起来拗口。
  - 建议：「既然已经来到这样一位人物面前，不弄明白就走是不合适的」。
- `100-118-21-24`｜关键词语意不明确（待与本文核对）｜片段「**深入查明后**的意思是深入考察以后」
  - 问题：lemma `anuvicca`（查明后／考察后）里的「深入」来自释语 `anupavisitvā`，被解释词与释义几乎同形，义注的区分失效；且 lemma 是否与本文黑体同译未能核验。
  - 建议：lemma 用「**查明后**」，释语作「深入考察以后」。
- `100-120-2-4`｜标点符号使用错误｜片段「诤事品第二」
  - 问题：品末标题句缺句末标点，与全段中文标点体例不一致。
  - 建议：「诤事品第二。」或「《诤事品》第二。」

### 🟦 suggestion
- `100-116-2-28`｜语言风格／增译｜片段「用两种相反的原因」
  - 问题：`ubhayakāraṇena` 只说「两种原因」，「相反」是译者据上下文补的判断。
  - 建议：「用这两种原因」，相反之义由前句的「做了／没有做」自然显出。
- `100-117-7-18`｜语言表达不够流畅／义蕴流失｜片段「用后面这个问题去弄懂前面那个问题」
  - 问题：`uparipañha / heṭṭhāpañha` 的「上（天界）／下（地狱）」对举被改成时间上的「后／前」。所指对象没错（后问天界、前问地狱），但原文的上下对照不见了。
  - 建议：「用上面（天界）这个问题去弄懂下面（地狱）那个问题」，或保留前后并在首次出现处夹注。
- `100-116-42-66`｜语言表达｜片段「高高地抬起傲慢的头角」
  - 问题：`mānaṃ paggayha`（高举我慢）与 `siṅgaṃ ukkhipitvā`（竖起角）两个连续动作被合为一个比喻，词对应度下降。
  - 建议：「怀着高举的傲慢、竖起角去的」一类分列处理。
- `100-117-24-47`｜语言风格不统一（语义重复）｜片段「就用同样的说法」
  - 问题：此处 `punapi` 已由「再一次说」承担，「用同样的说法」与「还是像先前那样」重复三次同一信息。
  - 建议：删去「就用同样的说法」。
- `100-118-25-28`｜语言表达｜片段「**有智慧的人**就是智者」
  - 问题：被解释词与释义在汉语里近乎同义反复，读者看不出义注在解释什么。
  - 建议：lemma 用更贴字面的「**识者**／**有识之人**」，释语保留「就是智者」。
- `100-118-29-35`｜语言风格不统一｜片段「说坏话」
  - 问题：`avaṇṇaṃ bhāsanti` 译为口语的「说坏话」，与周围书面语体略有落差。
  - 建议：「说他的坏处」或「讲不好的话」。
