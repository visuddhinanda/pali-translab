# Review — 85:293-307（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ✅（部分句子有）

## 跨段一致性

- **upanāha / anupanāha**：§294、§295、§296–§303 译「怨恨／不怨恨」，§306 句 85-306-84-105 译「不怀恨」 → 统一为「怨恨／不怨恨」。依据：本 chunk 多数译法；nissaya `ရန်ငြိုးမဖွဲ့ခြင်း`（不结怨）两者皆通，取多数。
- **makkha / amakkha**：§294–§303 译「抹杀他人的功德」，§306 译「不贬抑他人」 → 统一为「（不）抹杀他人的功德」。依据：nissaya `မက္ခေါ စ= သူတပါးဂုဏ်ကျေးဇူးကို ချေဖျက်ခြင်း`（抹杀他人的功德恩惠），「贬抑他人」把对象从「他人的功德」译窄成「他人」。
- **macchariya / amacchariya**：§294–§303 译「悭吝」，§306 译「不吝啬」 → 统一为「悭吝／不悭吝」。
- **māyā / amāyā**：§294–§303 译「掩饰恶行」，§306 译「不掩饰过失」 → 统一为「掩饰恶行」。依据：nissaya `မာယာစ= မိမိ၏ မကောင်းမှုအပြစ်ကို ဖုံးဖိလှည့်စားခြင်း`（掩盖自己的恶行过失来欺瞒），两译都有据，取多数。
- **sāṭheyya / asāṭheyya**：§294–§303 译「奸诈」，§306 译「不虚夸自己」 → 统一为「（不）奸诈」。依据：nissaya 主释 `စဉ်းလဲ ကောက်ကျစ်သူ၏ အဖြစ်`（狡诈奸猾者的状态）；「把自己没有的功德说成有」是 `ဝါ=` 异释。按 `style.md` 第四节，正文取主译，异释只入脚注。
- **hirī / ottappa（ahirika / anottappa）**：§294–§303 译「有羞耻心／畏惧责难」「没有羞耻心／不畏惧责难」，§306 译「惭／愧」 → 统一为「有羞耻心／畏惧责难」。§306 与同章肯定、否定两组的对应关系断了，读者看不出「惭」就是「有羞耻心」。
- **paḷāsa 的夹注拼写**：§294 夹注「palāsa」，取的是校勘异读（ka.）；§295 夹注「apalāsa」，§306 夹注「apaḷāsa」 → 统一用底本读法「paḷāsa／apaḷāsa」。
- **夹注重复**：§306 句 85-306-84-105 又给 amakkha、apaḷāsa、amāyā、asāṭheyya、hirī、ottappa 加了巴利夹注。这些词在 §294／§295 已首次出现并夹注过，按 `style.md` 第二节「其后只用汉译」，§306 应删去夹注。
- **品题体例**：§293「1. 愤怒略说」与 §305「二、不善略说品（akusalapeyyāla）」不一致，序号格式（1. 与 二、）、是否带「品」字、是否夹注都不同；结尾 §304「愤怒略说结束」与 §307「不善略说品结束」也不统一 → 两品采用同一体例，如「1. 愤怒略说品」「2. 不善略说品」，结尾对应「……品结束」。依据：nissaya `ကောဓပေယျာလံ= ကောဓပုဒ်၏ မြှုပ်ကွက်`、`အကုသလပေယျာလံ= အကုသလပုဒ်၏ မြှုပ်ကွက်`，两者结构完全平行。
- **经号体例**：§294–§303 用阿拉伯数字「181.」…「190.」，§306 用「一九一至二〇〇。」 → 统一为「191-200.」。

## §294 句 85-294-19-48
- **问题**：nissaya 疑问（记录，不改）。`ဣဿာစ= ပြုစုတတ်သော တရား` 字面是「照料／侍奉的法」，与 issā（嫉妒）不合，疑为 `ငြူစူတတ်သော`（嫉妒的）的讹写。译文作「嫉妒」不误。
- **建议**：译文不动，这条 nissaya 记入 `known-issues.md` 的原文/资料问题一节。

## §300 句 85-300-2-18
- **问题**：隐含成分漏补，导致语义不明。nissaya 补出了施事：`(အတ္တနော= မိမိ၏။ ကမ္မုနာ= အကုသိုလ်ကံသည်)`（被自己的不善业），并把句子读为 `အာဘတံ= တနေရာရာသို့ ဆောင်ယူ၍။ နိက္ခိတ္တော ယထာ= ချထားအပ်သကဲ့သို့။ ဧဝံ= ဤအတူ … နီရယေ= ငရဲ၌။ နိက္ခိတ္တော`（就像被带到某处放下一样，同样地，被〔自己的不善业〕放在地狱里）。译文「就像被带去放下一样，就这样被安置在地狱里」没有交代是谁、凭什么被安置，比喻落空，读者难以理解。
- **建议**：改为「比丘们，具备两种法的人，就像被人带来放下一样，被自己的不善业安置在地狱里。」本经结尾句 85-300-47-61 同步改。

## §301 句 85-301-50-64
- **问题**：与 §300 同类。nissaya 补出 `(အတ္တနော= ၏။ ကမ္မုနာ= ကုသိုလ်ကံသည်)`（被自己的善业），`သဂ္ဂေ= နတ်ပြည်၌`（在天界），译文未补施事。
- **建议**：改为「比丘们，具备这两种法的人，就像被人带来放下一样，被自己的善业安置在天界里。”」本经开头句 85-301-2-20 同步改，与 §300 保持平行。

## §302 句 85-302-2-24
- **问题**：用词。nissaya `ဥပပဇ္ဇတိ= လားရောက်၏`（前往、去到），指的是业力导致的投生。「往生」在汉语里多用于往生净土等正面语境，用在「地狱」上语感不当。另外 `ဣဓ= ဤလောက၌`（在这个世间），「这里」略显含糊。
- **建议**：改为「……在这世间有的人具备两种法，身体坏灭、死亡以后，会投生到苦界、恶趣、堕处、地狱里。」§302 结尾句与 §303 两句（善趣、天界）同步把「往生」改为「投生」，保持一致。

## §306 句 85-306-6-80
- **问题**：词义译虚。nissaya `သဗျာဗဇ္ဈာ= အမျိုးမျိုး နှိပ်စက်တတ်သော ဒုက္ခနှင့်တကွ ဖြစ်ကုန်သော`（与种种逼恼之苦相伴的），`အဗျာဗဇ္ဈာ= … ဒုက္ခမရှိကုန်သော`（没有逼恼之苦的）。「带着苦的」与前面「果报是苦的」「会使痛苦增长」区分不开，丢掉了「逼恼」这一层。
- **建议**：sabyābajjha 译「伴有逼恼的」，abyābajjha 译「没有逼恼的」。句 85-306-106-117「不带苦的两种法」同步改为「没有逼恼的两种法」。
- **问题**：dukkhudraya 的结构可以译得更准。nissaya `ဒုက္ခုဒြယာ= ဒုက္ခ၏ တိုးပွားခြင်း ရှိကုန်သော`（具有苦之增长的），是多财释，即「以苦的增长为其结果」。「会使痛苦增长」意思不错，可以保留。
- **建议**：不强制修改。如要贴近 nissaya，可译「带来痛苦增长的／带来快乐增长的」。

## §306 句 85-306-84-105
- **问题**：本句术语译法与前文多处不一致，详见「跨段一致性」一节（upanāha、makkha、macchariya、māyā、sāṭheyya、hirī/ottappa、夹注）。其中「不虚夸自己」取的是 nissaya 的 `ဝါ=` 异释而不是主释，属于必改。
- **建议**：改为「不愤怒和不怨恨……不抹杀他人的功德和不争强好胜……不嫉妒和不悭吝……不掩饰恶行和不奸诈……有羞耻心和畏惧责难。」
