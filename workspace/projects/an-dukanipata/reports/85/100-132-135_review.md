## 一、被解释词与父层逐字核对（首要项）

已核对一致（无需改动）：不善的人的立足之处 / 善的人的立足之处 / 不知恩 / 不表明所受的恩 / 所称赞的 / 不知恩、不表明所受的恩 / 整个 / 母亲和父亲 / 比丘们，把母亲放在一边肩头上侍奉 / 把父亲放在另一边肩头上侍奉 / 生在人寿百岁的时代、活满整整一百年 / 还为他们涂香除臭、用手揉按解除疲劳、用热水冷水洗浴、屈伸手脚推拿 / 而父母就在他的肩上 / 作统领四方的君主 / 抚养子女 / 让子女得以见到这个世间。

**Āpādakā** 一条的切分亦已核过：父层 `āpādakā posakā dassetāro` 对三词出了四个汉语短语，本层把「养育子女，守护子女」整体派给 **Āpādakā**、「抚养子女」派给 **Posakā**，与义注自身的 `vaḍḍhakā anupālakā`（成长者＋看护者）二释、`posakā` 一释正好对位，判定正确，保留。

### §134 句 100-134-124-140 —— 必改（逐字不符）
- **问题**：被解释词断句 — 本层作「**比丘们，即便这样也算不上**」，父层定稿为「比丘们，即便这样**，**也算不上为父母做了什么」，少一个逗号，不是逐字相同。
- **建议**：改为「**比丘们，即便这样，也算不上**」。

### §135 句 100-135-81-84 —— 建议
- **问题**：**Samādapetī** 在父层的落地形式是致使式「使没有信心的父母**受持**信心的成就」，本层单抽「**受持**」作被解释词，读者不易看出注的是致使动词；义注 `gaṇhāpeti` 正是致使义（使取）。
- **建议**：被解释词写作「**使……受持**」，译文作「**使……受持**，就是使他们取受（信等）。」

## 二、义注释义核对

### §133 句 100-133-45-55 —— 必改（释义译反）
- **问题**：语义错误 — `pākaṭaṃ katvā ajānanañca` 译成「以及不把它表明出来**而知道**」，否定落点错，整句自相矛盾（既「不表明」又「知道」）。**义注**：`akataññutā akataveditā` 分释为 `ajānanaṃ`（不知）＋ `pākaṭaṃ katvā ajānanaṃ`（不使之显明而知），两项都是「不知」。
- **建议**：「就是不知道别人所做的帮助，以及不把它显明出来让人知道。」并与 100-133-26-33 的措辞统一（见第四节）。

### §133 句 100-133-40-44 —— 必改（释义空转）
- **问题**：**义注**：`yadidaṃ` = `yā ayaṃ`，这是语法训释——把中性连读形 `yadidaṃ` 还原为与阴性 `bhūmi` 相应的「关系代词＋指示代词」。译文作「意思就是指这个」，等于没有释义，读者看不出注的是什么。
- **建议**：「**这**，就是“凡是这”——指与“立足之处”（bhūmi，阴性）相应的“凡是这……”。」若嫌夹注过重，至少改为「就是“凡是这个”」，保住关系代词这一层。

### §134 句 100-134-81-109 —— 建议
- **问题**：`aṃsakūṭesu ṭhitānaṃyeva` 译为「正**坐在**他肩头上的时候」，`ṭhita` 是「处/在」，不是坐；「坐」是下一条 100-134-110-123 的 `nisinnāva`。两条用同一个动词，义注刻意的用词差别就看不见了。
- **建议**：改为「就在他肩头上的时候」。

### §135 句 100-135-91-97 —— 建议
- **问题**：`tesu patiṭṭhāpeti` 的 `tesu` 指上句的信、戒、施、慧，译文补出「让**父母**确立」。按本经文脉（父层 85-76-128-181 正是「使父母……确立于其中」）补出是对的，但「这些成就」一语在本层没有先行词——本层上句用的是「信、戒、施、慧」，没有出现「成就」。
- **建议**：「……才算是让父母确立在这信、戒、布施、智慧之中。」

### §135 句 100-135-21-28 —— 存疑（不作必改）
- **问题**：`hadayalohitaṃ pāyetvā` 直译「让他们喝自己心头的血」。义注此处指母乳（传统释为心血所化），直白直译易被一般读者读成字面的血。
- **建议**：维持直译，按 `style.md` 第四节加段后小字注说明传统释义；或译「让他们喝自己心头的血（指乳）」。

## 四、跨段一致性

- `cāga` / `paññā`：父层定稿作「**布施**的成就」「**智慧**的成就」，本层 100-135-85-90 作「信、戒、**施**、**慧**」，缩成单音节且与父层不一致 → 建议统一为「信、戒、布施、智慧」（依据：父层定稿译法 + `style.md`「能用双音节现代词就不用单音节文言词」）。
- `akatavedī` 的释义措辞：§133 两处不一致 —— 100-133-26-33 作「不把……表明出来而让人知道」，100-133-45-55 作「不把它表明出来而知道」（且后者否定落点错）→ 统一为「不把……显明出来让人知道」。
- `dassetāro`：被解释词作「让子女得以见到这个世间」，而 100-135-62-80 句末收结作「让他见到这个世间的人」，同一词两种说法 → 句末改为「让他得以见到这个世间的人」，与被解释词同形。
- `ṭhita` / `nisinna`：见 100-134-81-109，两条都译「坐」，建议分开。
- 其余术语（立足之处、知恩/表明所受的恩、所缘、可喜和不可喜、肩头、涂香、推拿）本 chunk 内前后一致，与父层也一致。
