## 理由

**基准缺失（影响信心）**：本次注入的资源只有巴利原文与 channel 现有译文，**义注（aṭṭhakathā）与 nissaya 均未提供**。本品正是靠义注判定一串近义词（nimitta / nidāna / hetu / saṅkhāra / paccaya / rūpa）各自取义的典型段落，缺此基准，下列词义类判断只能依据原文序列与通行义理推定，故信心压到 62。涉及取义的结论请在补齐义注后复核。

**准确性**：句子骨架处理正确——`sanimittā … uppajjanti pāpakā akusalā dhammā` 的主语（恶不善法）与表语（有…的）关系译对，`Tasseva … pahānā` 的离格因由义也译对，无主谓宾判断错误，无违背基本教理的句子，故无 fatal。

主要扣分在两处词义：

1. **`sarūpā` 译作「有因由」**（85-173）。本品十支的排列是 … saṅkhāra（171）… **rūpa（173）→ vedanā（174）→ saññā（175）→ viññāṇa（176）**，连同 171 的 saṅkhāra 恰好覆盖五蕴，且 174–176 的 vedanā / saññā / viññāṇa 本译文都按蕴名译为「受 / 想 / 识」。同一序列里只把 rūpa 抽出来当作「因由」类抽象词，既与紧邻三支的译法自相矛盾，也使「舍断那个因由」失去所指。按蕴序应作「色」。

2. **`saṅkhāra` 译作「造作之因」**（85-171）。`sa-` 前缀表「具有、伴随」，原文并无「之因」这一层；本品前三支（nimitta / nidāna / hetu）已承担因由义，此处再叠一个「因」属增译，且与五蕴序列中的「行」相冲突。

**一致性（本项扣分最重）**：
- 五个近义词被译成「起因 / 缘由 / 原因 / 缘 / 因由」，而**只有第一处（85-168）附了巴利原词夹注**。其余四处在汉语中几近同义，读者无法分辨所据原词为何，整品十支的层次因此塌陷。按 `knowledge/style.md` 第二节，此类「罕见或有争议的术语」应逐支首次出现时夹注巴利原词。
- 否定分句句式不统一：168–176 为「不是无…**就**生起的」，177 为「不是以无为法为所缘**而**生起的」。
- 「有缘」（85-172）在现代汉语里首读是「有缘分」，作为 `sappaccaya` 的对译语意不明确。

**风格符合度**：语体合格，为现代书面汉语，**未发现文言 / 半文半白写法**（无「此中 / 故为 / 彼等 / 是故 / 于…之际」等禁例），标点全角、引号用弯引号、`zh` 字段内无 ASCII 引号，均符合约定。译文中无残留工作标记（候选 / 待定 / 问号）。扣分来自「不是无起因就生起的」这类双重否定叠「就」的句子略显生硬，以及术语标记缺位。

## 问题清单

### 🟧 error
- `85-173-2-19`｜错译（词义）｜片段「有因由」
  - 问题：`sarūpā` 译为抽象的「因由」。按 171→176 的 saṅkhāra / rūpa / vedanā / saññā / viññāṇa 序列，此处 rūpa 应为五蕴之色；同段 174–176 已按蕴名译出「受 / 想 / 识」，唯独此支取抽象义，序列断裂。
  - 建议：改为「有色」，并首次出现夹注巴利原词；待义注注入后以义注释义终审。
- `85-173-21-34`｜错译（词义）｜片段「那个因由」
  - 问题：同上，`tasseva rūpassa` 的所指应与上句一致；译作「那个因由」使「舍断」的对象无从落实。
  - 建议：与上句统一改为「那个色」。
- `85-171-2-19`｜错误多译｜片段「有造作之因」
  - 问题：`sasaṅkhārā` 的 `sa-` 只表「具有／伴随」，「之因」为原文所无的增译；本品前三支已承担因由义，此处再叠「因」造成层次重复。
  - 建议：改为「有造作（saṅkhāra）」或「有行」，去掉「之因」。
- `85-171-20-33`｜错误多译｜片段「那些造作之因」
  - 问题：同上，承前句增译。
  - 建议：与上句统一，去掉「之因」。

### 🟨 warning
- `85-169-2-19`｜关键词语意不明确（近义词未加区分）｜片段「有缘由」
  - 问题：`sanidāna` 译「缘由」，与同品「起因 / 原因 / 缘」在汉语中几乎同义，未夹注巴利原词，读者无法分辨所据原词。
  - 建议：首次出现处夹注「（nidāna）」。
- `85-170-2-19`｜关键词语意不明确（近义词未加区分）｜片段「有原因」
  - 问题：`sahetuka` 译「原因」，与「起因 / 缘由」无法区分，且 hetu 是有定译的法相术语。
  - 建议：按术语表取定译（「因」）并夹注「（hetu）」。
- `85-172-2-20`｜关键词语意不明确｜片段「有缘」
  - 问题：`sappaccaya` 译「有缘」，现代汉语首读为「有缘分」，歧义明显；且与 169「缘由」字面过近。
  - 建议：作「有缘（paccaya）」并加夹注，或改为「有助缘」。
- `85-172-21-34`｜关键词语意不明确｜片段「那个缘」
  - 问题：单音节「缘」独立作宾语，承前歧义未解。
  - 建议：随上句统一处理。
- `85-177-20-33`｜整句逻辑表达不规范｜片段「不是以无为法为所缘而生起的」
  - 问题：与 168–176 一律的「不是无…就生起的」句式不一致，同品内句式应统一。
  - 建议：改为「不是以无为法为所缘就生起的」。
