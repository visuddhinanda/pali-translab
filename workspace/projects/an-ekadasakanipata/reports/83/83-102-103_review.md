# Review — 83:102-103（channel: 73c03e1a-f333-11f0-808a-438f0af4b9e9）

> 资源：pali ✅／nissaya ⚠️ 部分段缺（83-102-73-89、83-102-90-105、83-103-179-194 无 nissaya 单元）

## 跨段一致性

- `ujugata` / `ujugatacitta`：§102-65-72 与 §103-154-161 译「变得正直」，§102-73-89 与 §103-162-178 译「心正直的」——译文内部一致 ✅，但与 nissaya 取义不符（见下「ujugata 取义」条）。若采纳改法，四处须同时改。
- `veda`（atthaveda / dhammaveda）：§102-73-89 与 §103-162-178 均译「感动」——内部一致 ✅，但译词本身存疑（见下条）。
- **夹注不对称（必改）**：§102-106-126 的 `cāgānussati` 作「舍随念（cāgānussati，即随念自己的布施）」，而 §103-195-219 的 `devatānussati` 只作「天随念」，首次出现未夹注巴利原词。按 `style.md` 第三节「术语首次出现用圆括号附巴利原词」，两处应同规格；且前者多出的「即随念自己的布施」属译者解释，按 `style.md` 第四节应移出正文。建议统一为「舍随念（cāgānussati）」「天随念（devatānussati）」。
- `pajā`→「人群」（§102-14-37 / §102-106-126 / §103-195-219）✅；`pariyuṭṭhita`→「缠缚」✅；`devatā`/`devā`→「天神」✅；`cāga`→「舍施」、`dāna`→「布施」分工稳定 ✅；§102 与 §103 的套语段（`labhati atthavedaṃ…` / `Pamuditassa pīti jāyati…` / `Ayaṃ vuccati…`）逐字平行 ✅。

## §102 句 83-102-14-37

- **问题**：补出成分 / 取义 — `suladdhaṃ vata me` 译「我真是得了大好处」。nissaya 把隐含宾语补成「人身」并以「善得」解 `suladdha`：`သုလဒ္ဓံဝတ= (ဤသာသနာတော်၌ လူ့ဘဝကို) ကောင်းစွာ ရအပ်ပါပေစွာ့တကား`（在此教法中，真是善得了人身啊）。译文把它处理成与前句 `lābhā vata me` 近义的重复（两句都是「我真是得了…」），丢掉了「善得（所得之物得当）」与「所得者是人身」这一层。
- **建议**：区分两句，如「我真是有所得，我真是善得了（这人身）」；

- **问题**：取义 — `payatapāṇi` 译「随时准备施与」。nissaya 主译为「手洁净」：`ပယတပါဏိ= သန့်ရှင်းစင်ကြယ်သော လက် ရှိလျက်`，异释 `ဝါ= ဆေးကြောအပ်သော လက် ရှိလျက်`（洗净的手）。译文取的是 PED 一类「净手＝随时可施」的引申义，与 nissaya 给的词面义不同，且「随时准备施与」与前项 `muttacāgo`（慷慨舍施）、后项 `vossaggarato`（乐于舍弃）语义重叠，五个并列项被压成三个意思。
- **建议**：依 nissaya 作「双手洁净」，引申义按 `style.md` 第四节作脚注；异释「洗净了手」亦备列脚注。

- **问题**：取义偏软 — `yācayogo` 译「乐于应人所求」。nissaya 主译 `တောင်းရမ်းအလှူခံခြင်း ငှာသင့်လျော်လျက်`（适于被乞求），异释 `ဝါ= တောင်းရမ်းအလှူခံသူတို့နှင့် ယှဉ်တွဲမှု ရှိလျက်`（与乞者相应）。「乐于」是前项 `rato` 的语义，`yāca-yoga` 是「有求必应／可以向他乞求」。
- **建议**：改「有求必应」或「别人来求都应得上」。

## §102 句 83-102-65-72（并同 §103 句 83-103-154-161）

- **问题**：取义 — `ujugatamevassa … cittaṃ hoti cāgaṃ ārabbha` 译「他的心缘着舍施而变得正直」。nissaya 把 `ujugata` 解为「直趣（业处）」而非「正直」：`ဥဇုဂတမေဝ= စာဂါနုဿတိ ကမ္မဋ္ဌာန်းသို့ ဖြောင့်တန်းစွာ သွားသည်သာလျှင်`（径直趣向舍随念业处），§103 作「径直趣向天随念业处」。译文作状态义（「变得正直」），nissaya 作运动义（「直趋向…」）。
- **建议**：此项牵动四句，不要只改一处。

## §102 句 83-102-73-89（并同 §103 句 83-103-162-178）

- **问题**：术语 — `atthavedaṃ` / `dhammavedaṃ` 译「对义理的感动」/「对法的感动」。本句缺 nissaya。`veda` 在本套语中传统释为「喜悦（somanassa）与智」，且与紧随其后的 `pāmojja → pīti → passaddhi → sukha → samādhi` 构成渐次喜悦链；「感动」是现代情绪词，容易被读成一般意义上的受感染，与法数序列脱节。
- **建议**：改「对义的欣悦」/「对法的欣悦」，或沿用传统「得义悦／得法悦」。

## §103 句 83-103-46-61（并同 76-89、90-103、104-119 四句）

- **问题**：指称放宽 — `tatthūpapannā` 译「往生到了天上」。nissaya 作 `တတ္ထ= ထိုဗြဟ္မာအပေါင်း၌`（在那梵众之中／上文所列的那一处）。`tattha` 回指前句枚举的具体诸天，译成笼统的「天上」丢了回指关系。
- **建议**：改「往生到了那里」或「往生到了那些天界」。四句平行，须同改。

## §103 句 83-103-195-219

- **问题**：风格（轻度） — 「在走上歧途的人群中，他安住于平正；在怀有恼害的人群中，他安住于无恼害」（§102-106-126 同）。「安住于X」是佛学惯用，可保留；但「无恼害」作名词性宾语略生硬，`abyāpajjo` 是述人的形容词。
- **建议**：可调为「…他不怀恼害地安住」，与前半「他安住于平正」句式对称即可，非必改。

## §103 句 83-103-220-221

- **问题**：体例 — `Paṭhamaṃ` 译「第一经。」原文只是品内经次标记，「经」字是补出的。
- **建议**：若 channel 内其他经的尾标已统一作「第一经」，保持不变；否则建议作「第一。」或「〔第一经〕」，与全书体例一致。
