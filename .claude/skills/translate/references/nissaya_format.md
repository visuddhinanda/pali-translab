# 缅文 Nissaya 格式

> 占位文件。完整内容待从项目 `knowledge/concepts/nissaya.md` 迁移确认后填入。

Nissaya 是缅文逐词释义体例，6 类结构元素：

1. **逐词释义** — 巴利词紧跟缅译
2. **异释** `ဝါ=` — 同一词的另一种解释
3. **补足语** `(...)` — 补出省略成分
4. **句法注** `[...]` — 句法说明
5. **详释段** `` ``...`` `` — 段落级展开解说
6. **被释词高亮** `**词**` — 标注当前在解释的巴利词

"注释"定义 = 详释段 + 句法注。
