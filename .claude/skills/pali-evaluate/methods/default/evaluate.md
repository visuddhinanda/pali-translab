# Evaluate (最终评估，非侵入)

## 目标
从目标 channel 读回译文，逐句评估，**只产出一份 markdown 报告**（总分 / 信心 / 理由 / 问题清单）。

**不改译文、不写 channel、不在译文里插任何标记。** 要改是 revise / harmonize 的事。

本步骤是流水线的**最后一步**，排在 translate / review / revise / harmonize 之后——
评的是定稿，不是半成品。

## 评估基准：义注定释义，nissaya 定词法

**义注（aṭṭhakathā）是释义标准**——词句该作何解、术语指什么，以义注为准；译文与义注的
解释相悖就是错。**nissaya 是词级基准**——格、句法角色、隐含成分，按 `(word_start, word_end)`
对齐到每一句核对。两者冲突以义注为准。缺哪个就用剩下的，并在理由中说明。
体例见 `references/nissaya_format.md`。

- **准确性打分**依据两条：与义注释义是否相符（取义、术语所指、意思归属），
  与 nissaya 是否吻合（词覆盖、格/句法角色）。
- 与**义注**的解释相悖 → 降准确性分，问题清单里立一条（多为 error「义理或用词与注释书不符」）。
- 与 **nissaya** 冲突且无更优依据 → 降准确性分，立一条（多为 error 词义/修饰关系错误）。
- 偏离二者但**确有依据**（如别本、上下文）→ 不扣分，但在理由中注明分歧。

## 定位方法

问题清单里每一条必须能让人**在译文里精确找到位置**，靠两样东西：

- **句 id**：`book-para-word_start-word_end`（如 `216-35-2-17`），取自读回的译文坐标，**不能编造**
- **问题片段**：从该句译文里原样摘出**有问题的最小片段**，用「」引起来

摘片段时原样照抄，不要顺手改写——片段要能在原句里字符串匹配到。

译文里**不该出现任何工作标记**（候选、待定、问号之类）。发现残留的，按 warning 立一条，
让 revise 清掉。

**级别与 emoji**：

| 级别 | emoji |
|---|---|
| fatal | 🟥 |
| error | 🟧 |
| warning | 🟨 |
| suggestion | 🟦 |

## 问题分级

级别取自下表；`问题类别` 从对应级别的条目中择一。

**第一类 严重错误 fatal**（零容忍；增长普通读者邪见、降低普通读者对译文的评价）
1. 主谓（含非谓语动词）宾有一项判断错误
2. 句子意思违背基本教理原则

**第二类 错误 error**（专家有举必究；只要发现一定要改、只有巴利专家能发现）
1. 漏译
2. 错误多译
3. 错译（词义、修饰关系）
4. 导致误解的表达
5. 义理或用词与注释书不符
6. 代词指代错误


**第三类 待提升 warning**（出版社编辑视角）
1. 关键词语意不明确，或二意场合没有注释（稣息、转起）
2. 代词指代不明确
3. 不导致误解的汉语语病
4. 标点符号使用错误
5. 不该使用术语标记时使用了术语标记
6. 整句逻辑表达不规范
7. **文言 / 半文半白语体**：出现文言虚词（之/其/乃/便/即/谓/於/遂…）、文言句式（…者…也／于…之际／经…后／答以…）、或单音节文言词（食用→吃、用膳→吃、端坐、盛装、年方…）。**按 error 处理**：每处单列一条（类别填「文言语体」），并在理由的"风格"维度据此显著扣分。译文须为现代书面汉语，详见 `knowledge/style.md` 第一节禁例表。

**第四类 可提升 suggestion**（有佛教背景的读者视角）
1. 语言表达不够流畅
2. 代词指代可能不够明确
3. 语言风格不统一
4. 该使用而没有使用术语标记
5. 不常用术语编写注释或者百科
6. 复杂的嵌套句整句语言逻辑理解困难（对读者不友好）

## 报告格式

写到 `workspace/reports/{book}/{start}-{end}_final.md`：

```markdown
# Evaluate — {book}:{start}-{end}（channel: {name}）

## 总分
- 准确性: X/100
- 风格符合度: X/100
- 一致性: X/100
- **综合**: X/100

## 信心指数
N / 100

## 理由
<分维度说明；义注/nissaya 缺失、与义注或 nissaya 的分歧等都在这里交代>

## 问题清单
按级别从高到低排列。

### 🟥 fatal
- `216-35-2-17`｜<问题类别>｜片段「<原样摘出的译文片段>」
  - 问题：<问题简述>
  - 建议：<修改建议>

### 🟧 error
- ...

### 🟨 warning
- ...

### 🟦 suggestion
- ...
```

无该级别问题时省略对应小节；整段没有问题就写「无」，不要为凑数硬找。

## 不要做

- **不要写 channel**，不要输出任何要提交的 JSONL
- **不要在译文里插 span、标记或改动一个字**——评估是非侵入的，且是流水线最后一步
- 不要为了"看起来权威"虚标高分
- 不要编造句 id；片段要能在原句里字符串匹配到
