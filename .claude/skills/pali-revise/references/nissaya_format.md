# 缅文 Nissaya 格式

Nissaya（နိဿယ）是缅甸传统的巴利**逐词对译注解**：把一段巴利原文拆成词/词组，逐一给出缅文释义。释义里嵌入的缅文助词同时编码了该词的**格、数、句法角色**与传统义读。它是审校巴汉译文时最可靠的"词级标准答案"。

## 取数

```
GET /api/v2/sentence?view=paragraph&book={book}&para={para}&channel_type=nissaya&lang=my&format=text
```

- 也可先用 `fetch_channels.py --view paragraphs --book B --para P --type nissaya --lang my` 取 channel uid，再用 `--channels` 调 `fetch_sentence.py`。
- `format=text` 用 `= ` 分隔词与释义；`format=html` 用缅文逗号 `၊` 分隔。两者内容相同。

## 响应结构

`data.rows[]`，每个 row 是覆盖原文某词段的 nissaya 单元：

| 字段 | 含义 |
|---|---|
| `word_start` / `word_end` | 该单元覆盖原文的词序号区间 |
| `content` | 逐词条目，换行分隔（见下） |
| `content_type` | `markdown` |
| `html` | 同内容，缅文逗号分隔版 |

**对齐 key**：`(book, paragraph, word_start, word_end)`——按此把 nissaya 单元对齐到译文句。

## 条目格式（content / text）

每行一条，形如：

```
巴利词或词组= 缅文逐词释义။
```

- `= ` 左侧是巴利词形（可能是词组或带 `ti` 引语标记）。
- `= ` 右侧是缅文释义，以缅文句号 `။` 结束。
- 释义末尾的缅文助词编码语法角色，例如 `သည်`=主格施事、`၏`=属格、`ကို`=宾格、`၌`=处格、`ဖြင့်`=具格。

示例（book 132, para 7）：

```
ဘဂဝါ= မြတ်စွာဘုရားသည်။          世尊【主格·施事】
တေသံ= ထိုနိဂဏ္ဍတို့၏။            那些尼乾子的【属格】
အဇာနနဘာဝံ= မသိမမြင်သည်၏အဖြစ်ကို။   不知不见的状态【宾格】
ပုစ္ဆတိ= မေးတော်မူ၏။             提问【动词·主句谓语】
```

## 结构元素

1. **逐词释义** — 巴利词 `= ` 缅译，最常见。
2. **异释** `ဝါ=` — 同一词的另一种解释（缅文 `ဝါ` = "或"）。
3. **补足语** — 缅文释义中补出的省略成分（隐含主语、连接词等）。
4. **句法注** — 说明该词在句中的句法功能。
5. **详释段** — 段落级展开解说（少见）。
6. **引语标记** — 巴利原文中的 `…ti`（如 `မယန္တိ`）标示被引述/被解释的语段。

## 审校/评估用法

- **覆盖核对**：原文每个实词都应能在 nissaya 找到对应释义；译文漏译的词，nissaya 会暴露。
- **格与句法**：以 nissaya 的格助词为准判断主/宾/属关系，纠正译文的语法误读。
- **歧义取义**：原文一词多义时，nissaya 给出传统取义——译文若取了别义需有据。
- **补出成分**：nissaya 补出的隐含主语/连接词提示译文该不该补、补什么。
