# Review (审稿，不改译文)

## 目标
从目标 channel 读回一个 chunk（连续若干段）的现有译文，逐句审查，输出审稿意见 md。
**不要直接改译文、不要写 channel**——revise 步才改。

## 输入

一次取齐、按 chunk 审查（`layer` 字段区分层次）：

- `layer=mula`：本文。`pali` 原文 / `nissaya` 词级注解 / `zh` 现有译文，
  按 `(word_start, word_end)` 已对齐到同一行
- `layer=atthakatha`：义注原文，`for` 字段指出它解释的是本文哪一段

nissaya 体例见 `references/nissaya_format.md`。

## 两重标准

**义注管「是什么意思」，nissaya 管「这个词在句子里是什么成分」。**

- **义注（aṭṭhakathā）是释义标准**：词句该作何解、术语指什么、句子的意思归属，
  以义注的解释为准。译文与义注的解释相悖，就是错，不是风格问题。
- **nissaya 是词级基准**：格、数、主宾属关系、隐含成分，以 nissaya 的格助词为准。

两者冲突时**以义注为准**，并在审稿意见里写明分歧。缺哪个就用剩下的，在报告开头注明缺了什么。

⚠ **义注是解释，不是本文。** 引用义注时必须标明层次（`**义注**：…`）。把义注的说法
当成经律本身的说法是学术错误，不是措辞问题。

## 检查清单

1. **义注释义核对**（首要）：
   - **取义**：原文一词多义、或结构可两解时，译文取的是不是义注给的那个解？
   - **术语所指**：义注对术语的定义、分类、辨异，译文有没有译反或译窄？
   - **背景补出**：义注补出的隐含背景（谁对谁说、指涉何事），译文有没有译得让读者误解？
   - **被解释词**：义注里的黑体是从本文原样引出的被解释词——它在本文的译法与义注的
     译法必须逐字相同，不同就是对应关系断了（可机械核查）
2. **nissaya 词级核对**：
   - **覆盖**：原文每个实词在 nissaya 都有释义；译文若漏了某词，nissaya 会暴露。
   - **格与句法**：以 nissaya 的格助词（`သည်`主格 / `၏`属格 / `ကို`宾格 / `၌`处格 / `ဖြင့်`具格等）判定主/宾/属关系，纠正译文语法误读。
   - **补出成分**：nissaya 补出的隐含主语/连接词，提示译文该不该补、补什么。
3. **准确性**：是否漏译、误译？术语是否符合 `knowledge/terms.md`？
4. **风格**：是否符合 `knowledge/style.md`？**重点查文言 / 半文半白**——逐句扫描文言虚词（之/其/乃/便/即/谓/於/遂）、文言句式（…者…也／于…之际／经…后／答以…）、单音节文言词（食用/用膳/端坐/盛装/年方）。发现即作为**必改项**列出，给出现代汉语改法（对照 `style.md` 第一节禁例表）。这是高频问题，务必逐处揪出。
5. **跨段一致性**（chunk 审查的意义所在）：同一巴利词在本 chunk 各段中译法是否一致？
   语体、称谓、重复句式是否前后统一？逐段孤立审永远发现不了这类问题——**这一项要专门查一遍**。
6. **存疑处**：有没有拿不准却译得像很确定的地方？译文里**不该出现任何工作标记**（候选、待定、问号），发现就作为必改项列出——存疑要写在审稿意见里，不是写进译文。
7. **OCR / 原文疑问**：pali 原文是否有疑似讹误？（记下，不要改）

审稿意见涉及依据时要引出来：义注写 `**义注**：<原文或释义>`，nissaya 写 `巴利词= 缅文释义`。

## 输出格式

输出到 `workspace/reports/{book}/{start}-{end}_review.md`：

```markdown
# Review — {book}:{start}-{end}（channel: {name}）

> 资源：pali ✅／nissaya ✅／义注 ✅（缺哪个在这里写明）

## 跨段一致性
- <巴利词>：§{para_a} 译「A」，§{para_b} 译「B」 → 建议统一为「A」，依据：<义注/术语表/出现次数>
- （没有就写「无」）

## §{para} 句 <id>（id = book-para-word_start-word_end）
- **问题**：<分类> — <说明，带义注/nissaya 依据>
- **建议**：<具体修改方向>

## §{para} 句 <id>
- ...
```

无问题的句子不必列出；跨段一致性一节**始终保留**，没问题就写「无」。
