# 引用规范

## 绝对底线

**任何观点陈述都必须有对应的巴利文引用。**
只有中文转述、没有巴利原文的句子，一律不合格。

如确实无法从该段提取可引句，须注明「（原文为纯叙事，节录如下）」
并**仍然给出原文片段**。没有例外。

## 标准格式

```
《文献中文名》在《章节中文名》中<动词>："*巴利文原文*"（中文翻译及必要说明）。{{para|id=<book>-<para>|title=<巴利书名> <para>|style=reference}}
```

引用动词：指出、解释、说明、定义、描述、强调、阐述、论述。

示例：

```
《疑惑度脱新注（Vimativinodanī-ṭīkā）》在《杂论释》中指出："*Kiriyākiriyato hi idaṃ samuṭṭhāti*"（此〔罪〕实从作-不作等起）。{{para|id=210-839|title=vimativinodanī-ṭīkā 839|style=reference}}
```

## 截断引文时最常犯的错：`…ti` 前的长音

引语标记 `ti` 与前词连声时会把末音节拉长。想在 `ti` 之前收尾，**必须保留那个长音**：

| 原文 | 错误截法 | 正确截法 |
|---|---|---|
| `dissatīti attho` | `dissati` | `dissatī` |
| `vasantīti sambandho` | `vasanti` | `vasantī` |
| `upāgamīti sambandho` | `upāgami` | `upāgamī` |
| `byākarotīti adhippāyo` | `byākaroti` | `byākarotī` |
| `nasijjhatīti dassetuṃ` | `nasijjhati` | `nasijjhatī` |

同理，`ti` 在语料中常与前词**分写**（`Sāvatthiyan ti`、`Isisaṅghanisevitan ti`），
照抄时不要并成一个词。这两类错误占了引文核对失配的绝大多数。

## 模板必须紧跟在它的引文之后

顺序固定为 **中文陈述 → "*巴利原文*" → （译文） → 模板**，中间不插入别的模板。
把模板写在引文**前面**（「《甲》{{para|A}}、《乙》{{para|B}} 均作：『……』」）会让
引文失去归属——校验时它会被算到后面那条不相干的模板名下。

多部文献说法相同时，这样写：

```
《甲》说："*原文*"（译文）。{{para|A}}《乙》所说全同{{para|B}}；
《丙》作："*异文*"（译文）{{para|C}}，《丁》亦同{{para|D}}。
```

即：**引一次原文、跟一个模板**，其余用「所说全同」带过并各自附模板；
文字有出入的，另引其异文，不要用一段引文覆盖措辞不同的几处。

## 多出处

同一观点有多个出处时，链接模板**连排**，中间不加空格、不加标点：

```
…（译文）。{{para|id=165-145|title=majjhimanikāyapāḷi 145|style=reference}}{{para|id=189-313|title=sādhuvilāsinī 313|style=reference}}
```

## 引用处理规则（按优先级）

1. **有明确论断句** — 直接引用该句：
   ```
   《X》在《Y》中指出："*巴利文原文*"（译文）。{{para|…}}
   ```

2. **叙事段落，无单一论断句** — 从段落中选最能代表核心意思的**一个完整句**作代表句，
   不得跳过巴利文：
   ```
   《X》在《Y》中记载，<中文概述主要内容>；原文云："*巴利文代表句*"（该句译文）。{{para|…}}
   ```

3. **段落过长** — 截取开头或核心句，以省略号表示省略：
   ```
   "*巴利文开头……*"（译文，并说明省略范围）。{{para|…}}
   ```

## 链接模板

`{{para|id=<book>-<paragraph>|title=<巴利书名> <paragraph>|style=reference}}`

| 参数 | 取值 | 来源 |
|---|---|---|
| `id` | `<book>-<paragraph>` | search 行的 `book` / `paragraph` |
| `title` | **巴利书名 + 空格 + 段号**，如 `sādhuvilāsinī 313` | 书名取 `path[0].title`；段号同 `id` 的后半 |
| `style` | 恒为 `reference` | — |

`title` 是**站点上的显示文本**，不是内部键，所以要给读者看得懂的东西——
用巴利书名而非重复一遍 id。书名用语料里的原拼写（小写、带变音符号），
**不要**换成中文名、不要加书名号。

- **原样输出**：不包 markdown 链接、不改大小写、不调字段顺序、不在 `|` 两侧加空格
- 禁止在成文中出现 `link`、`引用链接`、`[1]`、`[link]` 等占位符

## 巴利原文来源

引用文本**只能**来自 `wikipali get <book>:<paragraph> --json` 的 `content` 字段，
剥除 `<span>` 等标签后使用。

**不得**引用 `wikipali search` 的 `highlight` 字段——它是按 `--width` 截断的
HTML 片段，且含 `<span class='hl'>` 高亮标记，直接用会得到残句。

排版：巴利原文加引号并用 `*…*` 斜体；一律罗马转写。

## 参考文献

格式：`[序号] 文献全称缩写, 具体章节, 标题, 段落编号`

- 缩写取 `wikipali books --json` 中同 `book` 记录的 `related_name`；
  为 `null` 时用巴利书名的通行缩写，仍无则写巴利全名
- 段落编号写 `<book>-<paragraph>`，与正文链接模板的 `id` 一致
