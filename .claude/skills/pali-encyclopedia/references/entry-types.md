# 词条类型

不同类型的词条，结构与检索重点都不一样。先判定类型，再照相应模板写。

判定依据：调用时给的 `--category`；没给就从检索结果自行判断
（人名看是否作主语/呼格出现在叙事中，地名看是否跟 `viharati` / `nagara` / `gāma` 等搭配）。

---

## A. 义项分析型（术语、教理概念、语法术语）

默认类型。结构见 SKILL.md「词条结构」一节：
定义段 → 目录 → 词源与定义 → 按文献实际内容分出的主题小节 → 参考文献 → 相关条目。

重点在**分辨义项**：同一个词在语法书、经藏、阿毗达摩、律藏里往往不是一个意思，
分节要按义项走，不要按文献顺序走。

---

## B. 人名

### 检索重点

除常规检索外，必须额外做**按经文聚合**：把 search 命中按
`(book, paliTitle)` 分组，统计每篇经/每章的命中数，据此列出「相关经文」。
`path[]` 给出完整层级（丛书 › 部 › 品 › 经），列表里用得着。

### 结构

```
{{quality|pending}}
<简短定义段：身份、别名、所属僧团/家族、最著名的一件事>

## 目录

## 生平
   按文献叙述的次第写；每个事件都要有巴利原文引用。

## 相关经文
   **不用表格。**每部经一个 `###` 小标题，标题写**经文中译名**，
   正文一到三句说明该人在经中做了什么，句末给出处模板：

   ```
   ### 指鬘经（Aṅgulimālasuttaṃ）

   指鬘尊者于舍卫城次第乞食时见一妇人难产……{{para|…}}
   ```

   凡工作集里出现的经，一篇都不能漏。同一部经的多条坐标合在一节里，
   模板连排。

## <该人的特点／教说／被佛陀称许之处>
   如「第一」称号（etadagga）、专长、与其他弟子的关系。

## 参考文献

## 相关条目
```

### 硬要求

- **相关经文表必须列出经文标题**，且每行带 `{{para|…}}` 引用模板
- 经名首次出现给「巴利经名（中译）」对照
### 同名多人：消歧页 + 分立词条

一个巴利名往往指多人（`kassapa` 可指迦叶佛、大迦叶、富兰那迦叶、十力迦叶……）。
**不要合成一篇，也不要只写一个消歧页。**做法是：

1. **先从文献判定有几位所指**。依据是文献本身——看命中段落里这个名字
   跟什么定语、什么事迹、什么身份连用，不是按中文译名习惯来分。
   把工作集按所指分组，记下每组的坐标。

2. **消歧页**：文件名即该词本身（`kassapa.md`）。内容是一个简短的定义段
   说明此名有数位所指，然后每位一个 `###` 小节：一句话身份 + 最具区别性的
   一条文献引用 + 指向分立词条的链接。消歧页不展开生平。

3. **分立词条**：每位所指各一个文件，各自是完整的人名条目
   （生平 / 相关经文 / 特点 / 参考文献）。

4. **文件命名**用**巴利文全名**，不用中译，不用编号：
   `kassapabuddha.md`（迦叶佛）、`mahākassapa.md`（大迦叶）、
   `pūraṇakassapa.md`（富兰那迦叶）、`dasabalakassapa.md`（十力迦叶）。
   若某位所指在词表里已单独立项（如 `mahākassapa` 本就是一行），
   消歧页直接指向它，不要重复建文件。

5. **工作集要分完**。每条命中都要归到某一位名下；确实无法判定所指的，
   在消歧页末尾列出并说明「文献中未见足以判定所指的信息」，不要硬塞。

6. 分立词条彼此在「相关条目」中互指，并都指回消歧页。

同名的**地名**同理（如 `cetiya` 既是通名又是具体地名，`tissa` 亦有多人）。

## C. 地名

### 检索重点

同人名，按经文聚合。另需查该地作为**说法地**出现的频次
（常见语式 `... viharati <地名>`），这是地名条目的核心。

### 结构

```
{{quality|pending}}
<简短定义段：今地望、所属国、性质（城／精舍／山／园林）>

## 目录

## 地理与沿革
   位置、建置由来（如祇园的购地故事、竹林的布施）。

## 与佛陀及僧团的关系
   **本节是地名条目的重点，不可省。**至少要交代：
   - 佛陀是否在此住过、住了多久、有何因缘
   - 此地发生的重要事件（说法、制戒、结集、神变）
   - 与此地相关的主要弟子、施主、国王
   每一条都要巴利原文引用。

## 相关经文
   同人名条：**每经一个 `###` 小标题（经文中译名）+ 一到三句简介 + 出处模板**，
   不用表格。列出以此地为说法地或叙事场景的经。

## 参考文献

## 相关条目
```

### 硬要求

- 「与佛陀及僧团的关系」一节**必须有实质内容**，只写地理沿革不合格
- 若某地在文献中与佛教并无关联（如纯地理罗列的山名、河名），
  如实说明「文献中未见与佛陀或僧团直接相关的记载」，不要编造关联
- 拼写变体（如 `sāvatthī` / `sāvatthi`）合为一条，检索时两个词形一起给，
  在词条开头注明变体

---

## 按 category 限定义项

调用时给了 `--category`（如「人名」「地名」）时：

- **只写该类别下的义项**，其他义项一律不写，也不要顺带提一句
- 检索命中里属于其他义项的段落**不进工作集**——例如
  `cetiya` 作「支提／塔」是建筑通名，作地名时才指具体的支提；
  `nanda` 作人名与作形容词「喜悦」无关
- 剔除时记账：在输出末尾注明「另有 N 条命中属其他义项（<简述>），
  按 category 限定未采用」
